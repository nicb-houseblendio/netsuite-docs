After you customize your support rep roles, set up sales rules and territories so cases are routed to support reps in the proper subsidiary.

You can create rules for each subsidiary. You can base your rule on the Subsidiary field, create territories for each subsidiary, and assign the support reps responsible for those subsidiaries.

Important:

If you don't create case rules and territories based on subsidiary, support reps could be assigned cases they don't have access to. These cases wouldn't appear in lists, saved searches, reports, or KPIs.

For more information, see [Assignment Rules & Territories](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2426488.html).
