A case issue is any issue you list as one you offer support for. Knowing what issue a case is about helps your support team get key information about a case quickly.

For example, Wolfe Electronics creates a support issue called Installation. When customers or support reps enter cases about installing parts or setting up systems, they select Installation in the Issue field on case records.

Issues you offer support for are different from items you offer support for. Items are the goods and services you sell, and you can choose which ones you want to offer support for. For example, an electronics company might offer support for stereos as an item and sound quality as an issue. To offer support for an item, go to _Lists > Accounting > Items_. Click Edit next to the name of the item. On the item record, click the Preferences subtab. Check the Offer Support box, and click Save.

If you use the Issue Management feature, case issues are also different from issue records you use to track problem with items or products. Case issues cover common case topics, while issue records track problems that need to be addressed by an engineering team.

On a case record, enter case issues in the Issue field.

#### To create a case issue: {#procedure_N2422932}

1.  Go to _Setup > Support > Case Issues > New_.
    
2.  In the **Case Issue** field, enter a name for this support issue.
    
    For example, if you want to support people having trouble on your website, enter website.
    
3.  You can customize the order in which this case issue appears on case records and online forms by choosing an item in the **Insert Before** field, above which this case issue will be inserted.
    
4.  In the **Description** field, enter a brief description of what types of cases fall under this issue.
    
5.  Click **Save**.
    

To change your support issues, go to _Setup > Support > Case Issues_. Click Edit next to the name of the case issue you want to change.

To inactivate support issues, check the Inactive box on issue records. These issues no longer appear on new cases. To see inactive issues, check the Show Inactives box at the top of the Support Issue list.

You can base case rules on support issues. For example, one of your support reps handles all questions about deliveries, and another answers all questions about take out. You can set up your case rules, and then territories, by case issue.
