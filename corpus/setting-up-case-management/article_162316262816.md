Custom HTML form templates are saved by default in the Marketing Templates folder in the File Cabinet. To use a different folder for your templates, an administrator can go to _Setup > Company > Email Preferences_. Click the Templates subtab and select another folder in the Template Folder field.

#### To upload an HTML template: {#procedure_N2430650}

1.  Go to _Documents > Templates > Template Files_.
    
2.  Click **Templates** and then **Marketing Templates**.
    
3.  Click **Add File**.
    
4.  In the popup window, locate your HTML template on your computer.
    
5.  Select the file.
    
    Make sure it's an HTML file before adding it to the File Cabinet.
    
6.  Click **Open**.
    

After you've uploaded your HTML template to the File Cabinet, you can create a template record.
