You can reassign existing cases to your case territories, which is useful when you're restructuring your case territories.

#### To reassign cases to new case territories: {#procedure_N2427102}

1.  Go to Setup > Support > Territory Reassignment.
    
2.  On the **Criteria** subtab, select criteria that will return a list of the cases you want to reassign.
    
    The reassignment is determined using your current set of assignment rules and territories.
    
3.  On the **Results** subtab, you can customize what information displays in the list of found cases.
    
4.  To use the **Audience** subtab, click the **Public** box above the subtabs. Select who should be able to use this update again with your criteria. You must save the update for it to be available to this audience.
    
    If you check the **Public** box but don't select audience members, the update is available to all users in your account by default.
    
5.  Click **Preview**.
    
6.  In the **Apply** column, clear the box next to any cases you don't want to reassign.
    
7.  Click **Perform Update** to reassign the cases, or click **Save** to reassign the cases and save the update for later use.
    

Now, these cases are reassigned according to your case territories in priority order.

To access a saved reassignment update, go to _Lists > Mass Update > Saved Mass Updates_.
