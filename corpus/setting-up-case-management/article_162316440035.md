You can write a message in the Template field on the email template record if your template file wasn't created outside of NetSuite.

#### To upload your email template and create a template record: {#procedure_N2433224}

1.  Go to _Setup > Company > Email > System Email Templates_.
    
2.  Click **New**.
    
3.  Enter a name and description for this template.
    
4.  On the **Templates** subtab:
    
    -   Enter a subject for this template.
        
    -   If you created your template outside of NetSuite, select **File** and click the plus icon next to the **Template File** field. In the File window, select the file you want to upload, and click **Save**.
        
    -   To write your template text here, select **Text Editor** and enter your message in the **Template** field. You can use the Insert Field tool to automatically insert fields that pull information from fields on the case record.
        
5.  On the **Restrict Access** subtab, you can designate this template as private so only you can use it, or you can select a group to have exclusive access to the template.
    
6.  Click **Save**.
    

Your notification template is now ready to be assigned to a notification type. You can set these preferences on the Notification subtab when you set up support preferences at _Setup > Support > Preferences > Support Preferences_.
