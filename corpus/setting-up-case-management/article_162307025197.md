When customers click the link to your online case form, they enter information about the question or issue they have. They can also upload images or documents to help support reps resolve their case. When a customer clicks Submit, a case record is automatically created in your account with their provided information.

#### To create an online case form: {#procedure_N2428365}

1.  Go to _Setup > Support > Online Case Forms > New_.
    
2.  Click **Default Form Template** to use NetSuite default format for an online form.
    
    You can also click **Custom HTML Template** if you've uploaded a template for this form to the File Cabinet. For more information about custom HTML forms, see [Custom HTML Form Templates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2429943.html).
    
3.  Enter a title for this form.
    
    This title appears at the top of the form.
    
4.  If you're creating a form using the default template:
    
    -   Enter a message in the **Message** field for your customers to see at the top of the form.
        
        This message can include up to 500 HTML characters.
        
    -   In the **Detail Message** field, enter a message you'd like to appear at the bottom of the form.
        
        This message can include up to 4000 HTML characters.
        
5.  If you're using a custom HTML form template:
    
    -   Select the template you're using for this form.
        
    -   To have NetSuite add field labels to your form, check the **Include Field Labels** box.
        
        This adds labels based on the tags in your custom template like Name, Company or Subject.
        
6.  Check the **Enable Online** box to be able to link to this form from a website.
    
7.  On the **Select Fields** subtab, in the **Field** column, select a field you want to include on the form.
    
    Note:
    
    To allow customers to upload files through the form, add the **File** field.
    
    1.  In the **Label** column, you can edit the field name as it appears on the form.
        
    2.  In the **Section** column, select the subtab you want this field to appear on. See _Customization > Forms > Subtabs_.
        
    3.  In the **Help** column, enter any text you'd like to appear below the field to assist your customers fill out the form.
        
    4.  In the **Width** column, enter the width for the field.
        
    5.  To make a field required, check the box in the **Mandatory** column.
        
    6.  Check the **Search** box if you don't have duplicate detection enabled on the **Set Up Workflow** subtab. (Step 8.)
        
        NetSuite will index that field against existing records and suggest matches.
        
        If the information matches another record, the new information is added to the existing record. You can determine what NetSuite does when it finds duplicate information in an existing record using the **Handle Duplicate Records** field.
        
        This option is required for **Contact First** and **Last Name** fields. You can also search for duplicate company names, email addresses, phone numbers, and information in custom fields.
        
    7.  In the **Hide** column, check the box next to any field you want to hide on the form.
        
        Hidden fields are useful if you pass information into the form through the URL in the link. For more information, see [Linking to Online Forms](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2429074.html).
        
    8.  Check the box in the **Select** column if you want your customer to choose from a dropdown or popup list in this field.
        
    9.  Click **Add**.
        
    10.  Repeat these steps for each field on the form.
         
    11.  Use the **Move Up**, **Move Down**, **Move to Top** and **Move to Bottom** buttons to change the order of fields on your form.
         
8.  Click the **Set Up Workflow** subtab.
    
    1.  Check the **Create Customers as Companies** box if you want new contacts created as a company rather than as an individual when there's no match to an existing record.
        
    2.  In the **Default Case Profile** field, select the profile that you want to assign to cases submitted trough this online case form. You can also set the profile on case forms. Add the profile as a parameter to the form URL, or allow those submitting the form to set the profile manually.
        
        Profiles determine:
        
        -   The **From Name** and **From Email Address** shown on notifications sent for this case.
            
        -   The notification templates used when the case is created, updated, or closed.
            
        
        You can create new case profiles at _Setup > Support > Case Profiles > New_.
        
    3.  In the **Set Case Origin** field, select the origin you want to use for cases created through this form.
        
        You can create new case origins at _Setup > Support > Case Origins > New._.
        
    4.  Fill in the **Redirect to URL** field with the URL you want customers redirected to after completing the form. This is required.
        
        Your web store home page URL appears here by default.
        
    5.  In the **Handle Duplicate Records** field, select what to do if a duplicate record is found.
        
    6.  Check the **Use Duplicate Detection Criteria** box if you want to use the standard criteria set in the company setup page.
        
    7.  Select a template from **Send Auto-Reply Email** if you want to send an auto-generated reply to the sender when the form is submitted. This requires the **Marketing Automation** feature to be enabled. See _Setup > Company > Enable Features > CRM_.
        
        To create email templates, choose **New** from the dropdown menu, or see _Documents > Templates > Email Templates > New_.
        
    8.  Add a subject for the auto-generated message in the **Subject** field.
        
    9.  From the **Notification Template** field, select the template to use when notifying people listed in the **Email Address of Recipients** field. To create a new template, choose **New** from the dropdown menu.
        
    10.  In the **Email Address of Recipients** field, enter the email addresses of those to be notified when a customer submits the form. Enter the full email address separated by commas or semicolons.
         
9.  Click the **Set Up Appearance** subtab.
    
    Note:
    
    Many of the options listed below don't appear on custom HTML template forms. If you're creating an online form with a custom HTML form template, include style and appearance settings in the HTML code of the template.
    
    1.  In the **Number of Columns Shown** field, choose how many columns you want the form to be displayed in.
        
    2.  "In the **Color Theme** field, select a color theme for the form.
        
    3.  "In the **Font** field, select a font for the form.
        
    4.  Check the **Unlayered Sections** box if you want your form to appear without tabbed sections.
        
    5.  In the **Button Alignment** field, choose where to place the buttons on the form.
        
    6.  In the **Form Logo** field, select a logo to show at the top of the form. Logos should be uploaded to the images folder in the File Cabinet. See _Documents > Files > File Cabinet_.
        
10.  If you intend to use SuiteScript features, click the **Custom Code** subtab to:
     
     -   Choose a JavaScript file with your scripts in the **Script File** field. Client scripts or scripts referenced in client scripts, such as library files, can't have the **Hide in SuiteBundle** preference enabled on the script file record.
         
     -   In the **Page Init Function** field, select a script from your file that's called when the form first loads.
         
         If you're using an online HTML form template for this form, include this script in your HTML template file.
         
     -   In the **Save Record Function** field, select a script from your file that's called when the form is saved.
         
     -   In the **Validate Field Function** field, select a script to call from your file when a field on the form is changed.
         
     -   In the **Field Changed Function** field, select a script to call from your file when a change to a form field is accepted.
         
11.  Save the form.
     

After you save the form, click Preview Form to see how it looks.

Now customers can submit support cases on your website, and case records are automatically created in NetSuite.

After you complete your online case form, you can choose to publish the form or link to the form. To publish the form, create a case form information item at _Commerce > Site Builder > Content > Information Items > New_. For more information, see [Case and Customer Forms](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2591690.html).

To link to the form, click the External subtab on the form record. You can use the provided URL to link to this form on your website. When you link to the form, the form pops up in a new window.

Cases created using the Online Case Form get the Not Started status by default.

If you use NetSuite OneWorld, see [Setting Up Online Case Forms for NetSuite OneWorld](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N2433912.html) for information about setting up online case forms to track subsidiaries.
