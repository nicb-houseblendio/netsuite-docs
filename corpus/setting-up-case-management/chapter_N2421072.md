To set up and handle support cases, you should first create case types and case origin types to organize your cases. Then you can decide which items and issues you want to offer support for.

Next, set up case rules and territories to automatically assign cases to support reps. Then you can complete the rest of the [Setting Up Support Checklist](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2421296.html).
