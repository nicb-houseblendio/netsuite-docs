To generate and send electronic invoices in Brazil, you must create an e-document package record.

You can use the same e-document package record to generate and send electronic invoices for both goods and services.

#### To create the Brazilian e-document package:

1.  Go to Setup > E-Documents > E-Document Package > New.
    
2.  In the **Name** field, enter **BRHub E-Document**.
    
3.  (Optional) In the **Description** field, enter a short description for the e-document package record.
    
4.  In the **Inbound Validation Plugin** field, don't select anything.
    
5.  Click **Save**.
    

For more information about creating e-document package records, see [Creating E-Document Packages](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4576918342.html).
