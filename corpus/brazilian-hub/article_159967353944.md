Set up your preferences to process electronic bank payments with the Centro Nacional de Automação Bancário (CNAB) system on your subsidiary's informação complementar da subsidiária (subsidiary complementary information) record. You should set up these preferences for all the subsidiaries that process electronic bank payments with CNAB.

For more information about setting up the informação complementar da subsidiária record, see [Enabling CNAB Features for a Brazilian Subsidiary (Brazilian Hub SuiteApp)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160398895642.html).
