Taxes levied on the purchase of shipping services vary depending on the type of fiscal document you enter in NetSuite.

-   **PIS and COFINS** - If you're posting the Conhecimento de Transporte Eletrônico (CT-e) document, template number 57, you must set up PIS and COFINS calculation on shipping expenses. For more information see [PIS and COFINS Calculation on Goods (Brazilian Hub SuiteApp)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160581802662.html).
    
-   **ICMS** - If you're posting the Conhecimento de Transporte Eletrônico (CT-e) document, template number 57, you must set up ICMS calculation on shipping expenses. For more information see [ICMS Calculation (Brazilian Hub SuiteApp)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160581807419.html).
    
-   **INSS** - If you're posting the Conhecimento de Transporte Eletrônico de Outros Serviços (CT-e OS) document, template number 67, you must set up INSS calculation on shipping expenses. For more information see [Setting Up INSS Calculation for Shipping Expenses (Brazilian Hub SuiteApp)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160494392317.html).
