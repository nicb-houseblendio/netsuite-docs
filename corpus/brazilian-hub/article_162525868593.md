A Pix key is an alias that identifies a checking account. With the Pix key, the Brazilian Central Bank can find the beneficiary's account and personal data.

In NetSuite, you can add Pix keys in the banco contas (bank account) record, which stores your subsidiary's banking information.

The following types of Pix keys are available:

-   CNPJ (tax registration)
    
-   Email address
    
-   Mobile phone number
    
-   Random key
    

For more information about adding Pix keys in banco contas records, see [Creating Banco Contas Records in Brazil (Brazilian Hub SuiteApp)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_159967359068.html).
