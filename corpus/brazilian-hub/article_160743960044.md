A tax type is associated with a nexus, and tells NetSuite where to post the tax amounts on the balance sheet. You must create a tax type record for each Brazilian tax supported by the Brazilian Hub SuiteApp that your business uses on its transactions.

#### To create tax type records for Brazil in an account without SuiteTax:

1.  Go to _Setup > Accounting > Taxes > Tax Types > New_.
    
    If you've multiple nexus records on your account, you must choose a country to associate with the tax type. If not, NetSuite opens a new tax type record.
    
2.  Click **Brazil**.
    
3.  In the **Name** field, enter the name exactly as described in the [Brazilian Tax Type Records Chart for Accounts Without SuiteTax](#subsect_160743991574).
    
4.  In the **Description** field, enter the description exactly as described in the [Brazilian Tax Type Records Chart for Accounts Without SuiteTax](#subsect_160743991574).
    
5.  In the **Liability/Sales Tax Account** column, select the tax control account on which to post tax collected on sales.
    
    -   If you're creating a tax type record for a tax due, select a liability account.
        
    -   For CIDE-DEVIDO, COFINS-IMP-SERV, IRRF-IMP-RETIDO, IRRF-IMP-SERV, ISS-IMP-SERV, and PIS-IMP-SERV, select a liability account.
        
    -   For other tax codes, you aren't required to select an account from a specific group.
        
6.  In the **Asset/Purchase Tax Account** column, select the tax control account on which to post tax on purchase transactions.
    
    -   If you're creating a tax type record for a tax due, select an asset account.
        
    -   For CIDE-DEVIDO, COFINS-IMP-SERV, IRRF-IMP-RETIDO, IRRF-IMP-SERV, ISS-IMP-SERV, and PIS-IMP-SERV, select an asset account.
        
    -   For other tax codes, you aren't required to select an account from a specific group.
        
7.  Click **Save**.
    

Repeat the previous steps until you create all the Brazilian tax type records. For more information about tax type record creation, see [Creating a Tax Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1811821.html).
