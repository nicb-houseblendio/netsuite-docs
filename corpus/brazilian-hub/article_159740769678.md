This topic guides you through the installation of the Brazilian Hub (BRHub) SuiteApp.

Note:

BRHub is a shared bundle and it can only be installed in previously authorized accounts. For more information, contact your account manager.

-   [Brazilian Hub Feature Prerequisites](#subsect_158584615682)
    
-   [Brazilian Hub SuiteApp Prerequisites](#subsect_158093701350)
    
-   [Installing the Brazilian Hub SuiteApp](#subsect_158093749925)
    

## Brazilian Hub Account Prerequisites {#subsect_158093464896}

To install BRHub, the following account requirements must be set up:

-   NetSuite OneWorld account
    
    BRHub is only available for installation in NetSuite OneWorld accounts. If your account isn't a NetSuite OneWorld account, contact your account manager.
    
-   A Brazilian subsidiary
    
    You only need to set up a Brazilian subsidiary before installing BRHub if there are multiple international subsidiaries on your account. If there are no existing international subsidiaries, you can set up the Brazilian subsidiary after installing the SuiteApp. For more information about setting up a Brazilian subsidiary, see [Setting Up the Brazilian Subsidiary (Brazilian Hub SuiteApp)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_159742897023.html).
    

## Brazilian Hub Feature Prerequisites {#subsect_158584615682}

After you've established your account, you must enable the required features to use BRHub.

#### To enable features for Brazilian Hub:

1.  Go to _Setup > Company > Setup Tasks > Enable Features_.
    
2.  On the **Company** subtab, check the following boxes:
    
    -   **Multi-Language**
        
    -   **File Cabinet**
        
    -   **Multiple Units of Measure**
        
3.  On the **Tax** subtab, under Tax & Compliance, check the **Advanced Taxes** box.
    
4.  If your company uses SuiteTax, on the **Tax** subtab, under Tax & Compliance, check the **SuiteTax** box.
    
    Important:
    
    If you use SuiteTax, you must enable SuiteTax before installing BRHub. For more information about SuiteTax, contact your account manager.
    
5.  On the **Items & Inventory** subtab, check the following boxes:
    
    -   **Inventory**
        
    -   **Inventory Status**
        
6.  On the **CRM** subtab, check the **Online Forms** box.
    
7.  On the **SuiteCloud** subtab, check the following boxes:
    
    -   **Custom Records**
        
    -   **Advanced PDF/HTML Templates**
        
    -   **Client SuiteScript**
        
    -   **Server SuiteScript**
        
    -   **SuiteFlow**
        
    -   **Custom GL Lines**
        
    -   **Custom Transactions**
        
    -   **REST Web Services**
        
8.  When you've finished, click **Save**.
    

For additional information, see [Enabling Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N232138.html).

## Installing the Brazilian Hub SuiteApp {#subsect_158093749925}

The Brazilian Hub SuiteApp (Bundle ID: 334878) is a managed bundle. Whenever there are enhancements or new features added, NetSuite automatically updates your account.

#### To install the Brazilian Hub SuiteApp:

1.  Go to _Customization > SuiteBundler > Search & Install Bundles_.
    
2.  In the **Keywords** field, enter **Brazilian Hub**, or the bundle ID **334878**.
    
3.  Click **Search**. Brazilian Hub, Bundle ID 334878, should appear in the search result.
    
4.  Click **Brazilian Hub**.
    
5.  On the Bundle Details page, click **Install**.
    

For more information about installing SuiteApps, see [Installing a Bundle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3395142.html).

To uninstall the bundle, see [Uninstalling a Bundle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3400972.html).
