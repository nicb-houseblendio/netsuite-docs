The Contribuições de Intervenção no Domínio Econômico (CIDE) tax applies to imported and exported services.

-   [Setting Up CIDE Calculation on Exported Services](#subsect_160501289992)
    
-   [Setting Up CIDE Calculation on Imported Services](#subsect_160501333175)
    

## Setting Up CIDE Calculation on Exported Services {#subsect_160501289992}

The Contribuições de Intervenção no Domínio Econômico (CIDE) tax applies to services provided abroad.

#### To set up CIDE calculation on exported services:

1.  Go to BRHub > Fiscal > Parametrização de Impostos de Serviço.
    
2.  Click **Edit**.
    
3.  Click the **CIDE** subtab.
    
4.  Click the **CIDE - Saída** sublist.
    
5.  In the **Item** column, select the service item provided abroad.
    
6.  In the **Alíquota** column, enter the CIDE rate on the service.
    
7.  In the **Data Inicial Vigência** column, enter or select the start date for the effectiveness of the parameter.
    
    The start date is the date on which the parameter takes effect for transactions subject to CIDE. The date is usually defined by law.
    
8.  (Optional) If the parameter expires on a date predetermined by law, in the **Data Final Vigência** column, enter or select the end date for the effectiveness of the parameter.
    
    The end date is the date on which the parameter expires, losing its effect. You can edit this field later if the law changes and affects the effectiveness of the parameter.
    
9.  (Optional) If the parameter should only apply to a certain subsidiary, in the **Subsidiária** column, select the subsidiary the parameter applies to.
    
10.  Click **Add**.
     
11.  Repeat the previous steps to add parameters for as many services as required.
     
12.  Click **Save**.
     

## Setting Up CIDE Calculation on Imported Services {#subsect_160501333175}

The Contribuições de Intervenção no Domínio Econômico (CIDE) tax applies to services hired from abroad.

#### To set up CIDE calculation on imported services:

1.  Go to BRHub > Fiscal > Parametrização de Impostos de Serviço.
    
2.  Click **Edit**.
    
3.  Click the **CIDE** subtab.
    
4.  Click the **CIDE - Entrada** sublist.
    
5.  In the **Item** column, select the service item hired from abroad.
    
6.  In the **Alíquota** column, enter the CIDE rate on the service.
    
7.  In the **Data Inicial Vigência** column, enter or select the start date for the effectiveness of the parameter.
    
    The start date is the date on which the parameter takes effect for transactions subject to CIDE. The date is usually defined by law.
    
8.  (Optional) If the parameter expires on a date predetermined by law, in the **Data Final Vigência** column, enter or select the end date for the effectiveness of the parameter.
    
    The end date is the date on which the parameter expires, losing its effect. You can edit this field later if the law changes and affects the effectiveness of the parameter.
    
9.  (Optional) If the parameter should only apply to a certain vendor, in the **Fornecedor** column, select the vendor the parameter applies to.
    
10.  Click **Add**.
     
11.  Repeat the previous steps to add parameters for as many services as required.
     
12.  Click **Save**.
