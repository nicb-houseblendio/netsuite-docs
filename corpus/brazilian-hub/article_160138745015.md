After you create an e-document package and sending method, you must create the e-document template records. In Brazil, municipal governments are responsible for certifying electronic invoices for services. For this reason, each city has its own e-document templates.

With the Brazilian Hub SuiteApp, you can send electronic invoices for the following operations:

-   Certification
    
-   Cancellation
    

You must create an e-document template record for each operation and for each city to which you generate electronic invoices for services. To create the templates, you can use the predefined e-document templates available in the File Cabinet of your NetSuite account. For more information, see [Predefined E-Document Template Files for Brazil (Brazilian Hub SuiteApp)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161773143849.html).

See how to create the electronic invoice for services template records in the following topics.

-   [Creating an Electronic Invoice for Services Certification Template (Brazilian Hub SuiteApp)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161903042662.html)
    
-   [Creating an Electronic Invoice for Services Cancellation Template (Brazilian Hub SuiteApp)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161903041046.html)
    
-   [Creating an Electronic Invoice for Services Status Request Template (Brazilian Hub SuiteApp)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161903028579.html)
    
-   [Electronic Invoice for Services Templates Association with Subsidiaries (Brazilian Hub SuiteApp)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161903027042.html)
    

For more information about creating e-document template records, see [Creating E-Document Templates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4536871429.html).
