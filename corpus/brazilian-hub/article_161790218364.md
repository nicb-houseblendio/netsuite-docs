The Brazilian Hub (BRHub) SuiteApp provides predefined records that enable you to process electronic payments from some Brazilian banks. If you make or receive payments in accounts from banks that aren't predefined by the SuiteApp, you can create a custom bank implementation to process your electronic payments.

The following topics describe how to implement a custom Brazilian bank, leveraging the infrastructure provided by BRHub.

-   [Payment Slip Plug-in Creation (Brazilian Hub SuiteApp)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161790220322.html)
    
-   [Payment Slip Template Creation (Brazilian Hub SuiteApp)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161790222095.html)
    
-   [Creating Bancos Records in Brazil (Brazilian Hub SuiteApp)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161359549473.html)
    

After you implement a bank, you must set up your account to use CNAB features. For more information, see [Setting Up CNAB Preferences (Brazilian Hub SuiteApp)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_159966342902.html).
