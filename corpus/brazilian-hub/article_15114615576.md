You can download predefined e-document template files for electronic invoices for services from your account's File Cabinet.

The SuiteApp separates tax authorities' template files in folders by state or third-party standard:

-   Tax authorities that use their own e-document templates are grouped by state.
    
-   Tax authorities that use third-party standards are grouped by standard.
    

#### To find the predefined e-document template files for electronic invoices for services: {#procedure_0511114552}

1.  Go to _Documents > Files > File Cabinet_.
    
2.  In the sidebar or list, click **SuiteApps**.
    
    The files and folders within this folder appear.
    
3.  Click the **com.netsuite.brazilcertificationtaxauth** folder.
    
    The folders within this folder appear.
    
4.  If you're downloading an e-document template file for the following cities or standards, click the **brazil templates** folder:
    
    -   ABRASF v2.03 e v2.04
        
    -   Barueri (SP)
        
    -   GIAP
        
    -   Nota Fiscal de Serviços (NFS-e) Nacional
        
    -   São Paulo (SP)
        
    
    The templates for Barueri (SP), São Paulo (SP), and NFS-e Nacional can be used with SuiteTax and without SuiteTax accounts.
    
    1.  If you're downloading an e-document template file for a tax authority that uses its own templates, do the following:
        
        1.  Click the **Services** folder.
            
        2.  Find the state in which the tax authority is located, and then click its folder name.
            
        3.  Find the city from the tax authority you want, and then click its folder name.
            
    2.  If you're downloading an e-document template file for a tax authority that uses a third-party template or the NFS-e Nacional standard, do the following:
        
        1.  Click the **Services** folder.
            
        2.  Find the standard that the tax authority uses to generate e-documents, and then click its folder name.
            
        3.  Click the folder named after the version of the standard that the tax authority adopts.
            
5.  If you're downloading an e-document template file for other tax authorities, click the **templates** folder.
    
    1.  Click the **Service** folder.
        
    2.  Find the state in which the tax authority you want is located, and then click its folder name.
        
    3.  Find the city from the tax authority you want, and then click its folder name.
        
    4.  Click the folder that corresponds to your account's tax accounting:
        
        -   For an account with SuiteTax, click the **With SuiteTax** folder.
            
        -   For an account without SuiteTax, click the **Legacy Tax** folder.
            
6.  Find the template file you want to download and click **Download**.
    
    The folder may contain e-document template files to be used in a tax authority's test environment. These files are identified by the prefix **Test**.
