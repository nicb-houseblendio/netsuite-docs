After you create an e-document package and sending method, you must create the e-document template records.

With the Brazilian Hub SuiteApp, you can send electronic invoices for the following operations:

-   Certification
    
-   Outras operações fiscais
    
-   Correction letter
    
-   Cancellation
    
-   Number voiding
    
-   Receiver acknowledgment
    

You must create an e-document template record for each operation. To create the templates, you can use the predefined e-document templates available in the File Cabinet of your NetSuite account. For more information, see [Predefined E-Document Template Files for Brazil (Brazilian Hub SuiteApp)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161773143849.html).
