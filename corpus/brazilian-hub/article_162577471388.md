The Brazilian Hub SuiteApp provides a custom transaction to enable you to generate debit notes in NetSuite.

#### To generate a debit note:

1.  Go to BRHub > Transações > Nota de Débito > New.
    
2.  In the **Date** field, select the date of the debit note.
    
    By default, NetSuite populates the field with the current date.
    
3.  In the **Posting Period** field, select the period corresponding to the debit note.
    
    By default, NetSuite populates the field with the current period.
    
4.  In the **Entidade** field, select the customer for the debit note.
    
5.  In the **Subsidiária** field, select the subsidiary associated with the customer.
    
    By default, NetSuite populates the field with the customer's primary subsidiary.
    
6.  In the **Currency** field, select the currency of the transaction.
    
    By default, NetSuite populates the field with the currency set in the customer record.
    
7.  In the **Exchange Rate** field, enter the exchange rate for the selected currency.
    
    By default, NetSuite populates the field with the standard exchange rate for the selected currency.
    
8.  In the **Conta de Débito** field, select an account to which to post the debit amounts of the debit note.
    
    If you set a default account in the subsidiary's complementary information record, NetSuite populates the field with the default option. For more information, see [Setting Up the Informação Complementar da Subsidiária Record (Brazilian Hub SuiteApp)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160035217915.html).
    
9.  In the **Conta de Crédito** field, select an account to which to post the credit amounts of the debit note.
    
    If you set a default account in the subsidiary's complementary information record, NetSuite populates the field with the default option. For more information, see [Setting Up the Informação Complementar da Subsidiária Record (Brazilian Hub SuiteApp)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160035217915.html).
    
10.  In the **Conta de Pagamento** field, select a bank account to which to post the payment of the debit note.
     
     If you set a default account in the subsidiary's complementary information record, NetSuite populates the field with the default option. For more information, see [Setting Up the Informação Complementar da Subsidiária Record (Brazilian Hub SuiteApp)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160035217915.html).
     
11.  In the **Valor Total da Nota** field, enter the total amount of the debit note.
     
12.  In the **Data de Vencimento** field, enter the expiration date of the debit note.
     
13.  To add classification information to the transaction, do the following:
     
     1.  In the **Memo** field, enter a comment about the transaction for internal use.
         
     2.  In the **Class** field, select a class for the transaction.
         
     3.  In the **Location** field, select the subsidiary's location.
         
     4.  In the **Descrição** field, enter details about the expense or reimbursement of the debit note.
         
         The debit note file displays this information in the Referente field.
         
     5.  To associate an invoice with the debit note for internal purposes, do the following:
         
         1.  In the **Data Emissão Fatura** field, enter the date in which the invoice was generated.
             
         2.  In the **Número Fatura** field, enter the number of the invoice you want to associate.
             
         
         When you add this information, the debit note transaction displays the invoice information, but no systemic link is created between the transactions.
         
14.  Click **Save**.
     
     NetSuite saves the debit note transaction and opens it in view mode. The transaction displays the **Aprovada** (Approved) status.
     
15.  (Optional) To view the debit note file, click **Visualizar Nota de Débito**.
     
     Tip:
     
     To display your company's logo on the debit note file, you must configure it on the subsidiary record. For more information, see [Creating Subsidiary Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N272471.html).
