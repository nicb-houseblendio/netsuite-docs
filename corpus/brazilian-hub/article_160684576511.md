In Brazil, you can send cartas de correção eletrônicas (electronic correction letters) to your state's tax authority to correct errors on certified electronic invoices for goods.

In a NetSuite account with the Brazilian Hub (BRHub) SuiteApp installed, you can send correction letters for the following transactions:

-   Invoice
    
-   Vendor Return Authorization
    
-   Return Authorization
    
-   Outras Operações Fiscais
    

Warning:

You can't use BRHub to send correction letters for notas fiscais de serviço eletrônicas (electronic invoices for services).

See the following topics for information about sending correction letters.

-   [Correcting Electronic Invoices on Invoices and Returns (Brazilian Hub SuiteApp)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_162213238113.html)
    
-   [Correcting Electronic Invoices on Outras Operações Fiscais (Brazilian Hub SuiteApp)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_162213236437.html)
