The Código Especificador de Substituição Tributária (CEST) code identifies which products are subject to the Substituição Tributária do Imposto sobre Circulação de Mercadorias e Serviços de Transporte Interestadual, Intermunicipal e de Comunicação (ICMS ST) tax.

You can find information about CEST codes on government documents, such as ICMS ST agreement charts or protocols. You must create the CEST records based on these documents.

#### To create a CEST record:

1.  Go to BRHub > Fiscal > CEST > New.
    
2.  In the **Name** field, enter a name for the CEST code.
    
3.  In the **Segmento** field, enter the segment name of the item associated with the CEST code.
    
4.  In the **NCM** field, select the Mercosur Common Nomenclature (MCN) code for the item subject to ICMS ST.
    
5.  In the **Descrição** field, enter a description for the CEST code.
    
6.  In the **CEST** field, enter the CEST code.
    
7.  Click **Save**.
