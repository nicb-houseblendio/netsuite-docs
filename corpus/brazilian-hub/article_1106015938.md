The Contribuição sobre Bens e Serviços (CBS) and Imposto sobre Bens Serviços (IBS) taxes apply to services that your company provides or receives.

## Setting Up CBS and IBS {#subsect_66140109080}

In NetSuite, you must set CBS and IBS parameters for each service and city in which you do business.

#### To set up CBS and IBS:

1.  Go to BRHub > Fiscal > Parametrização de Impostos de Serviço.
    
2.  Click **Edit**.
    
3.  Click the subtab that corresponds with the tax you want to set up:
    
    -   To set up CBS, click **CBS**.
        
    -   To set up IBS, click **IBS**.
        
4.  In the **Código Serviço** field, select the federal code that applies to the service you provide or receive.
    
    The field lists the service codes as described in the attachment of Brazil's federal law no. 116, of July 31, 2003.
    
5.  (Optional) If you want to apply these parameters to a specific service, in the **Item Serviço** field select the item.
    
6.  In the **Código NBS** field, select the Nomenclatura Brasileira de Serviços (NBS) code that applies to the service.
    
7.  In the **Classificação Tributária** field, select the tax classification code (cClassTrib) that applies to the service.
    
    When you generate an electronic invoice for services (NFS-e), the system determines the CST code by the first 3 digits of the cClassTrib code.
    
8.  In the **Código Tributação** field, enter the municipal taxation code.
    
    Each city government assigns different taxation codes to services. The taxation code indicates the type of service provided or received.
    
9.  In the **Alíquota** field, enter the tax rate that applies to the service.
    
10.  If the service provided or received is subject to a reduced tax rate, in the **Redução da Alíquota** field, enter the percentage of the tax rate reduction.
     
11.  In the **Município** field, select the city in which you provided or received the service.
     
12.  In the **Data Inicial Vigência** field, enter or select the effective for these parameters.
     
     On this date, the information you set up takes effect. This date can be determined by law.
     
13.  (Optional) If these parameters have a legal expiration date, enter or select the expiry date in the **Data Final Vigência** field.
     
     If legislation changes and the parameter is no longer valid from a certain point in time, you must edit this record to reflect the change.
     
14.  Click **Add**.
     
15.  Click **Save**.
