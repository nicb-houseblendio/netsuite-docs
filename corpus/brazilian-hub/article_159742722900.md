If you use the Brazilian Hub SuiteApp, you must set up your personal user preferences according to this procedure. The date and time preferences are required for using Brazil-specific features.

#### To set up user preferences for Brazil:

1.  Go to _Home > Set Preferences_.
    
2.  Click the **General** subtab.
    
3.  In the **Language** field, select **Português (Brasil)**.
    
4.  In the **Time Zone** field, select **(GMT-03:00) Brasília**.
    
5.  In the **Date Format** field, select **DD/MM/YYYY**.
    
6.  In the **Long Date Format** field, select **DD Month YYYY**.
    
7.  In the **Time Format** field, select **hh:mm (24 hours)**.
    
8.  Click **Save**.
    

For more information about localizing preferences in NetSuite, see [Setting Personal Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N475297.html).
