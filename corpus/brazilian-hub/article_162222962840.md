## Best Practices for the Brazilian Hub SuiteApp {#subsect_162222965391}

When using the Brazilian Hub SuiteApp, be guided by the following recommendations:

-   When installing the SuiteApp, enable all the required features before installing the required SuiteApps for Brazil.
    
    For more information, see [Brazilian Hub SuiteApp Installation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_159740769678.html).
    
-   When installing the SuiteApp, install the required SuiteApps for Brazil before installing the Brazilian Hub SuiteApp.
    
    For more information, see [Brazilian Hub SuiteApp Installation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_159740769678.html).
    
-   When setting up the electronic invoicing features provided the SuiteApp, ensure that the digital certificate you upload to NetSuite meets the following requirements:
    
    -   Is within its expiration date
        
    -   Includes exportable private key
        
    -   Includes all certificates in certification path
        
    
    For more information, see [Digital Certificates Upload for Brazil (Brazilian Hub SuiteApp)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161133630982.html).
    
-   If you use multiple SuiteCloud Processors to send your e-documents for certification, review the Script Invoice (Script ID `customdeploy _sit_invoice_ue`) script deployment record.
    
    For more information, see the script deployment review guide. It's available in the **Admin Documentation** field of Brazilian Hub's Bundle Details page. For more information about the Bundle Details page, see [Bundle Details](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3393046.html).Before setting up the electronic bank payments feature provided by the SuiteApp, create a case with NetSuite Customer Support to request the CNAB segment fields' CSV f
    
-   iles.
    
    For more information, see [Creating CNAB Segment Fields (Brazilian Hub SuiteApp)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161825569805.html).
    
    Note:
    
    This applies only if you use one of the banks predefined by the Brazilian Hub SuiteApp.
    
-   When entering item descriptions on invoices that you send to the Barueri (SP) tax authority for certification, press Enter to insert line breaks. The SuiteApp automatically removes other forms of line breaks, such as pipes, `<br />`, and `\n`.
    

## Known Limitations of the Brazilian Hub SuiteApp {#subsect_162222966206}

When using the Brazilian Hub SuiteApp, keep in mind the following limitations:

-   Brazilian Hub supports the generation of electronic invoices for services (NFS-e) for items with tax classification codes starting in **000** and **200**, except **200022** and **200024**. For the other classifications, NFS-e generation isn't supported.
    
-   Brazilian Hub supports the generation of electronic invoices for goods (NF-e) for items with tax classification codes starting in **410**. For the other classifications, NF-e generation isn't supported.
    
-   The calculation of CBS and IBS tax amounts is supported only for service transactions. The SuiteApp doesn't support calculating these taxes for goods transactions.
    
-   Importing or exporting items requires additional Electronic Invoicing licenses.
    
    For more information, see [Electronic Invoicing SuiteApp Availability and License Client](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4615669958.html).
    
-   Direct import of goods with tax benefits isn't supported.
    
-   The nota de débito (debit note) transaction only supports the Brazilian Real (BRL) currency.
    
-   The tax calculation feature can't post taxes to the general ledger separated by type revenue and cost center.
    
-   The tax calculation feature doesn't support the recognition nor the deferral of revenues and expenses.
    
-   PIS, COFINS, and CSLL (PCC) withheld on payments aren't posted to the general ledger when you apply a vendor credit from the bill payment page. However, PCC withheld on payments amounts are posted when you create a vendor credit transaction and then apply it to a vendor bill, or when you click the Credit button in the vendor bill.
    
    For more information, see [Entering a Vendor Credit Manually](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1493669913.html) and [Creating a Vendor Credit Directly From a Vendor Bill](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2392547.html).
    
-   The tax calculation feature doesn't support additional tax types and tax codes other than those provided by the Brazilian Hub SuiteApp.
    
    For more information, see [Creating Tax Type Records for Brazil in Accounts Without SuiteTax (Brazilian Hub SuiteApp)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160743960044.html) and [Brazilian Tax Types in Accounts With SuiteTax (Brazilian Hub SuiteApp)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160339614128.html).
    
-   Kit/Package and Assembly/Bill of Materials items aren't supported. However, you can link service items to compose something similar to service kits.
    
    For more information, see [Setting Up Service Items for Brazil (Brazilian Hub SuiteApp)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_159838228962.html).
    
-   The SuiteApp doesn't provide any customizations to localize the following features:
    
    -   Accounting-related reports, such as the general ledger
        
    -   Cash flow features
        
    -   Financial statements, such as the balance sheet and the income statement
        
    -   Fixed asset features
        
        If you want, you can customize the features to suit your business needs.
        
-   Brazilian Hub doesn't support the e-document series, e-document sending preferences, and municipal taxation code records, all from the LATAM E-Document Certification SuiteApp.
    
    If you have Brazilian Hub and LATAM E-Document Certification installed on your account, don't use the aforementioned records.
