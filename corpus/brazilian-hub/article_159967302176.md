The CNAB 240 payment file enables you to pay vendors, utility companies, government authorities that collect taxes with barcodes, and reimburse employee expenses.

With the Brazilian Hub (BRHub) SuiteApp, you can perform the following payment operations:

-   [Paying Vendors with CNAB (Brazilian Hub SuiteApp)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_159984756530.html)
    
-   [Paying Utility Bills and Tax Collection Forms with CNAB (Brazilian Hub SuiteApp)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_159984758184.html)
    
-   [Reimbursing Employee Expenses with CNAB (Brazilian Hub SuiteApp)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_159984760086.html)
    
-   [Generating a CNAB 240 Delivery File (Brazilian Hub SuiteApp)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160043870015.html)
    
-   [Processing a CNAB 240 Return File (Brazilian Hub SuiteApp)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160043870476.html)
    

Before you perform these tasks, ensure that you've set up the entities you're going to pay. For more information about setting up entity records for electronic bank payment with BRHub, see [Setting Up Entity Records for Electronic Bank Payments with CNAB (Brazilian Hub SuiteApp)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_159984755841.html).
