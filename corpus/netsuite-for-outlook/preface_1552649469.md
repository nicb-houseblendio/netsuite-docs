Important:

Issue fixes and enhancements are no longer expected for NetSuite for Outlook. Existing customers who have installed NetSuite for Outlook in their NetSuite account can continue to use the SuiteApp and its features. All data synced with NetSuite for Outlook will continue to be available without any interruption.

Outlook integration used to provide functionality to attach your emails to NetSuite records directly from Outlook.

You can use a third-party integration to sync emails and calendar events between Outlook and NetSuite. For enhanced performance and experience, use SuiteApps developed and supported by SDN Partners and other third parties. For more information, see [Third-party SuiteApps (not provided by Oracle)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4452517827.html).

Previously, you can use NetSuite for Outlook to sync emails and calendar events between Outlook and NetSuite but support for the SuiteApp has ended and it's no longer available for installation.

For more information about the NetSuite for Outlook bundle, see [NetSuite for Outlook](https://system.netsuite.com/app/help/helpcenter.nl?fid=NetSuiteOutlook.pdf).

## NetSuite Connector for Outlook {#subsect_0413011508}

Alternatively, you can use NetSuite Connector for Outlook. NetSuite Connector for Outlook is a Microsoft Outlook add-in that syncs emails and events from Microsoft Outlook to corresponding NetSuite records.

For information about using NetSuite Connector for Outlook, see [Managing NetSuite Connector for Outlook](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0413120748.html).
