In NetSuite OneWorld, you must assign a subsidiary to each entity record before you can enter transactions for the entity. A transaction inherits its subsidiary from its entity. Other records referenced on the transaction, such as items or departments, are limited by values associated with that subsidiary.

This requirement applies to the following records:

-   Employee - See [Assigning a Subsidiary to an Employee](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N276604.html)
    
-   Vendor - See [Assigning Subsidiaries to a Vendor](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4180576581.html)
    
-   Partner - See [Assigning a Subsidiary to a Partner](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N276702.html)
    
-   Customer - See [Assigning Subsidiaries to a Customer](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N276747.html)
    

To assign an entity to a subsidiary, open the record, and select a subsidiary in the Subsidiary field. The selected subsidiary determines the fields visible on the form, the address format, tax fields, and other information.

You can assign a single subsidiary to employee and partner entities. If these entities have relationships with multiple subsidiaries, you must create a record for each subsidiary relationship. You can assign a primary and multiple secondary subsidiaries to vendor and customer entities.

You can associate entities from one subsidiary to an entity associated with a different subsidiary in these cases:

-   Contacts on Customer, Partner, Vendor, Group, Competitor, and Project records
    
-   Employees and Contacts on Group records
    
-   Employees on Project records
    

Note:

After a transaction is posted for the entity, you can't change the primary subsidiary selected on the entity record.

For more information associating subsidiaries with entities, see the following help topics:

-   [Customers](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1076428.html)
    
-   [Creating a Vendor Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2362161.html)
    
-   [Entering an Address for an Employee](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N895137.html)
    
-   [Creating a Partner Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1166599.html)
    
-   [Enabling Intercompany Time and Expenses](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1476983.html)
    

In OneWorld, you can add fields to item records so that items can be shared by several subsidiaries. You can also assign a shipping item to a subsidiary so that it can be used for transactions. See [Associate Subsidiaries With Items](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N276948.html) and [Associate Subsidiaries With Shipping Items](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N277674.html).
