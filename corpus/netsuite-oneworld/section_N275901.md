In NetSuite OneWorld, the Inventory feature functions the same way as the Multi-Location Inventory feature. If you enable Inventory, Multi-Location Inventory enables automatically. For information about this feature, see [Multi-Location Inventory](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2303574.html).

After you enable the Inventory feature, you must associate each location with only one subsidiary. If you do not use the Inventory feature, you have the option to associate each location with no subsidiary, one subsidiary, or multiple subsidiaries.

In OneWorld, you can't enter initial quantities on hand when you create an item record. You must first create the item record, and then afterward, you must enter an inventory adjustment to specify the initial quantities in each location. See [Creating Item Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2166469.html) and [Inventory Adjustments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2259648.html) for more details.

## Import Inventory Data into OneWorld {#bridgehead_N275970}

NetSuite doesn't support importing historical data that is dated prior to the date of the OneWorld upgrade. Importing historical data may cause inaccuracies in your inventory data. Best practice is to import data that is dated after the date of OneWorld upgrade. In addition, you should set the initial Multi-Location Inventory distribution to maintain accurate inventory information.
