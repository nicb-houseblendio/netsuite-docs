Before you install Subsidiary Navigator, make sure that the following NetSuite features are enabled:

-   Client SuiteScript
    
-   Server SuiteScript
    
-   Subsidiary
    

Subsidiary Navigator is available for installation as a SuiteApp:

-   Name - Subsidiary Navigator
    
-   Bundle ID - 44281
    
-   Location - Production (Account ID 3802169)
    

Subsidiary Navigator is a managed SuiteApp and updates automatically whenever there are changes. These issue fixes and enhancements are available after the SuiteApp is updated in your account.

For information about installing SuiteApps, see [Installing a Bundle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3395142.html).
