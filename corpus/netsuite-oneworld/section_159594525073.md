If you are an administrator, you can set the following required permissions on the Role page. Go to _Setup > Users/Roles > Manage Roles > New_. For information about customizing a role, see [Customizing and Creating Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N286284.html).

| On the Permissions subtab, click the Transactions subtab. | 
-   You must have the Netting Settlement permission to view and create intercompany netting. This permission defaults to Full level.
-   You must have the Netting Settlement Approval permission to approve a netting statement. This permission defaults to Edit level.
