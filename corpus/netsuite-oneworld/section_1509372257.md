Following are best practices for using the Multi-Subsidiary Customer feature:

-   If you use anonymous customers with Web Store workflows, assign only one subsidiary to the anonymous customer record.
    
-   Set up tax rounding at the Nexus level rather than for individual customers with multiple different subsidiaries. For more information, see [Setting Tax Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1813668.html).
