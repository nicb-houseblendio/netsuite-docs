There are prerequisites to set the Automatically Create Representing Entities preference. Users of the Automated Intercompany Management feature must also enable the Multi Subsidiary Customer feature. In addition, if you use the Multiple Currencies feature, you must also enable the Multi-Currency Vendor and Multi-Currency Customer features. If you meet these prerequisites, NetSuite can generate and maintain representing entities for all of your non-elimination subsidiaries.

After you enable the required features, the Setup Manager page displays an Information bar at the top. The message states that your account meets the prerequisites to use the **Automatically Generate Representing Entities** intercompany preference. The message provides a link to the Intercompany Preferences page, where you can set the preference. When you save the preference, another Information message appears at the top of the page. This message states that NetSuite is creating and updating representing entities, and provides a link to the Processed Records page. See [Processed Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_159067372130.html).

Note:

You can stop NetSuite from generating and maintaining representing entities by clearing the **Automatically Generate Representing Entities** box. The **Is Autogenerated Representing Entity** is automatically cleared on all autogenerated customers and vendors. You can then manually edit, update, and delete them.
