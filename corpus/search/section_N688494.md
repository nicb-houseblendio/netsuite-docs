The information about execution of saved searches is available through the saved search Execution Log and the Saved Searches list. For information about changes made to saved searches see [Auditing Changes to Saved Searches](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N688421.html).

## Saved Search Execution Log {#bridgehead_N688515}

The saved search Execution Log subtab provides a rolling usage history for the past 60 days. This history lists each user who has run or exported the saved search, and the date and time when this has occurred. A box indicates whether the search was exported.

![Execution Log subtab](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Search/execution1.png)

You must be an administrator or have at least Create level of the Publish Search permission to view the saved search Execution Log subtab.

Note:

Execution log is available for saved searches only, not for reports.

#### To view the saved search Execution Log: {#procedure_N688550}

1.  Go to Reports > Saved Searches > All Saved Searches.
    
2.  Click **Edit** next to the required saved search.
    
3.  Click the **Execution Log** subtab.
    

Note:

Each saved search log includes executions that are scheduled, that are customized quick searches based on the saved search, that are from scripts, and that are in dashboard portlets, including saved search, KPI, and trend graph portlets.

## Saved Search List {#bridgehead_N688587}

Not all users have access to the saved search Execution log. You must be an administrator or have at least Create level of the Publish Search permission to view it. Alternatively, you can view the Saved Searches list page, which includes the following columns:

-   Last Run By: displays the user who last run the saved search
    
-   Last Run On: displays the date and time it's been run.
    

![Last Run By and Last Run On columns.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Search/scheduledby1.png)

#### To view the Saved Searches list page: {#procedure_N688636}

1.  Go to Lists > Search > Saved Searches.
    

You do not need this permission to see the columns on the Saved Searches list page.
