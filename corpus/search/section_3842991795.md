If you try to use a saved search to change what's shown on Customer Center lists, such as **See All Transactions** or **See Orders**, NetSuite resets the list to its original setup. You can't override the definition for lists that are specifically designed for Customer Centers.

Instead, use permissions to control which Customer Center lists are visible. For example, to make **See Orders** show only invoices, change the role used by customers as follows:

-   Remove the Transactions : Sales Order permission.
    
-   Set the Transactions : Find Transaction permission to View level.
    
-   Set the Transactions : Invoice permission to View level.
