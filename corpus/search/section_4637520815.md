NetSuite treats invoices, bills, orders, cash sales, and many other records as transactions. To find any of these records, use the Transaction search type.

#### To search for invoices, bills, orders, and other transactions:

1.  Go to _Reports > New Search_.
    
2.  Select **Transaction** as the search type.
    
3.  In the **Type** list, select the type of transaction you're looking for. You can choose **Invoice**, **Bill**, **Cash Sale**, **Purchase Order**, or any other available type.
    
    To select more than one type, hold the Ctrl key and select the types you want.
    
4.  Set any other search options if you need to.
    
5.  Click **Submit**.
    

If you're creating a saved search, you can add a Type filter on the **Criteria** subtab and set it to Invoice, Bill, Purchase Order, or any other type you need. To learn more about saved searches, see [Saved Searches](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N675442.html).

See also [Finding Transactions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N560124.html).
