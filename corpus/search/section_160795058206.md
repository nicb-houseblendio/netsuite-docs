You can select how many rows in list segments are shown in search results. Change the number to fit your preferences.

#### To change the number of rows in list segments:

1.  Go to the Set Preferences page under the **General** tab.
    
2.  Set the number of rows you want to display in the list segment as shown below.
    
    ![Number of Rows in List Segments box.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Search/listsegments.png)
3.  Click **Save**.
