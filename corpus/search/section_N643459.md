You can add a Quick Search portlet to most pages. In it, enter keywords to search for data in the selected field.

![Quick Search portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Search/QuickSearch.png)

After you add the portlet, click its setup link to choose the type of data to search. You also can set preferences to include inactive data or change how keyword matching works.

For information about using Quick Search, see:

-   [To add a Quick Search portlet:](#bridgehead_N643588)
    
-   [To set up a Quick Search portlet:](#bridgehead_N643616)
    
-   [To set Quick Search preferences:](#bridgehead_N643683)
    
-   [Finding Records with the Quick Search Portlet](#bridgehead_N643729)
    
-   [Customizing Quick Search Results](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4615880073.html)
    

#### To add a Quick Search portlet: {#bridgehead_N643588}

1.  Go to your dashboard and click **Personalize**.
    
2.  In the **Standard Content** tab of the **Personalize Dashboard** palette, click the **Quick Search** icon or drag it onto the dashboard.
    

#### To set up a Quick Search portlet: {#bridgehead_N643616}

1.  Hover over the three-dot menu icon ![Three dot menu](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Search/setupicon.png) and click **Set Up**. The Quick Search Setup popup window opens.
    
    ![Quick Search Setup portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Search/QuickSearchPopup.png)
2.  In the **Search Type** list, select the type of search you want.
    
    -   **General** searches for records such as customers, campaigns, and vendors.
        
    -   **Transaction** searches for transactions such as cash sales, sales orders, and purchase orders.
        
3.  In the **Default General Search Type** list, select a record type to search. If you don't choose one, it searches all records.
    
4.  In the **Default Transaction Search Type** list, select a type of transaction to search. If you don't choose one, it searches all transactions.
    
5.  Click **Save**.
    

#### To set Quick Search preferences: {#bridgehead_N643683}

1.  Go to _Home > Set Preferences_, and click the **Analytics** subtab.
    
2.  To include inactive records in searches, check the **Include Inactives in Global and Quick Search** box. By default, it searches active records only.
    
3.  If you want Quick Search to find both records with names or IDs that start with your keywords and records that contain them, check the **Quick Search Uses Keywords** box.
    
    If you don't enable this, the Quick Search portlet shows **Starts With** and **Contains** buttons. Searches can find records that **either** start with **or** contain your keywords,depending on the button you choose. Enabling this preference removes the buttons.
    
4.  Click **Save**.
    

#### Finding Records with the Quick Search Portlet {#bridgehead_N643729}

1.  In the Quick Search portlet, enter keywords to match to the name or ID of the record you want to find.
    
    If available, select the **Starts With** or **Contains** button to set how keywords are matched. For more information, see [To set Quick Search preferences:](#bridgehead_N643683).
    
2.  In the **Search For** list, select the field name or ID you want to use for keyword matching.
    
3.  Click the **Search** button.
    
    A results page opens. Depending on your permissions, you can do the following:
    
    -   Click **Edit** or **View** to open a record.
        
    -   Click **Return to Criteria** to open a search form with your entered keywords.
        
    -   Click **Save this Search** to create a saved search.
        
    -   Click one of the export icons ![Export icons](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Search/ExportIcons.png) to export the list of results.
        
    -   Click the print or email icons ![Email and print icons](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Search/EmailPrintIcons.png) to print or email the search results.
