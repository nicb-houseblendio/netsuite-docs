If you use the **Preferred Vendor** field as a filter in an item search in a OneWorld account with the Multiple Vendors feature enabled, you may notice that items with more than one preferred vendor only appear under the first preferred vendor listed. This happens because with the Multiple Vendors feature, each subsidiary can have its own preferred vendor in a OneWorld account.

To avoid this issue, use both the **Vendor** field and the **Vendor is Preferred** field as filters in your item search instead of only **Preferred Vendor**. Set the **Vendor** filter to include any vendors you want, and set **Vendor is Preferred** to **Yes**. This setup returns all items where at least one subsidiary has one of your chosen vendors set as the preferred vendor.
