You can apply settings from a saved search you own to customize your quick search results. To do so, click **More Options** and then check the **My Preferred Search Results** box on the **Results** subtab of the saved search definition page.

![My Preferred Search Results box.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Search/GSMyPreferredSearch.png)

Administrators and users with the Publish Search permission can set a saved search's settings to customize quick search results for other users on the **Roles** subtab of the saved search definition page.

![The Public and Preferred Search Results boxes.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Search/GSRolPrefSrchRslt.png)

-   To set a saved search's settings to customize quick search results for users with a certain role, check the **Results** box for that role.
    
-   To set a saved search's settings to customize quick search results for all roles, ensure the **Public** box is checked, and check the **Preferred Search Results** box.
    

Note:

The **My Preferred Search Results** option for a user overrides any preferred search results set on the **Roles** subtab by other users.
