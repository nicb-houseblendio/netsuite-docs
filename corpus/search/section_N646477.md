You can set up advanced filters for both advanced and saved searches. Select filter fields and set their values on the **Standard** and **Summary** sublists located on the **Criteria** subtab.

![Saved opportunity search example.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Search/OpportunityCustomSearch.png)

A standard search filter finds results based on each record's value for a field. You can set up expressions for standard filters by checking the **Use Expressions** box.

If you add a field you don't have permission for, you'll see this message: 'Your formula contains a reference to a field for which you do not have a permission.'

A summary search filter finds results based on calculated summary values for a group of records. You can only use this if you've set a summary type for a field on the **Results** subtab.

-   [Defining Standard Search Filters](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N646693.html)
    
-   [Using Expressions in Search Criteria](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N647582.html)
    
-   [Summary Search Filters](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N647835.html)
    

Important:

If you set up more than one date filter, the one with the most recent date is used to calculate exchange rates, no matter what order you list them in.
