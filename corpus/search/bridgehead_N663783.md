Reference System Notes fields in numeric and text formulas by using the following format:

{systemnotes.field\_name}

Select a field to be included in a formula expression from the **Field** dropdown list in the **Formula** popup window. Join fields appear at the end of the dropdown list. When you select the field from the list, the system automatically enters the correct ID in the formula.
