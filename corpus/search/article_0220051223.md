In saved and advanced searches, Integer Number fields on the **Results** subtab show only the first 13 characters. If a value has 14 digits or more, the search displays pound signs (#) instead of the value. This is a NetSuite display and formatting limit for large integer number values in search results.

To avoid this, do the following:

1.  Open the search definition page in edit mode and go to the **Results** subtab.
    
2.  In the **Columns** sublist, add **Formula (text)** instead of the Integer Number type field.
    
3.  In the **Formula** column, click the **Set Formula** icon ![Set Formula](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Search/filter_set_description_button.png). The formula window opens.
    
4.  In **Field**, select the Integer Number type field you want to display. Then, click **Set**.
    
5.  Click **Save & Run**.
    

Note:

This workaround changes how the value is displayed in the results, not the underlying data.
