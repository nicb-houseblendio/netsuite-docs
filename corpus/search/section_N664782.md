Note:

You can use SuiteAnalytics Workbook to query your NetSuite data using the analytics data source, which offers advanced query capabilities. For more information about SuiteAnalytics Workbook and how you can recreate your existing saved searches to workbooks, see the following topics:

-   [Getting Started with SuiteAnalytics Workbook](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158874665729.html)
    
-   [Analytics Data Source Changes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1543418431.html)
    

To make searching easier, some records have select list fields that show popup menus with search links. For example, the following figure shows, on an Opportunity record, a popup menu with a link to search items.

![Popup search window.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Search/customer6.png)

When you click a search link in a popup menu, it opens a new popup window. A popup search shows as either simple or advanced based on which one you used most recently for that record type. For information about completing this search, see either [Defining a Simple Search](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N645582.html) or [Defining an Advanced Search](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N646177.html).

Popup searches are different from other search pages in these ways:

-   They don't have the **Use Advanced Search** box, so you can't switch between simple and advanced.
    
-   They don't have the **Export**, **Reset**, **Customize**, or **Create Saved Search** buttons.
    
-   Their results pages display in the popup window.
    
-   Their results pages don't include **Export**, **Email**, or **Create Saved Search** buttons.
