The table below shows each summary tool you can use for search results, with examples from a sales order transaction search.

| Summary Type | Purpose | Example for Sales Order Transaction Search |
| --- | --- | --- |
| Group | Rolls up search results by the field to which you apply this type. Note: Some fields contain values that can't be grouped together. The **Group** summary type isn't available for these fields. | You can group transactions by customer name. |
| Count | Counts the number of results found that apply to this column. | You can count the number of items purchased by each customer. |
| Sum | Sums search results for the column. | You can sum the dollar amount of sales orders for each customer. |
| Minimum | Displays the minimum amount, or the earliest date value. | You can show the minimum amount sold in a transaction for each customer. |
| Maximum | Displays the maximum amount, or the most recent date value. | You can show the maximum amount sold in a transaction for each customer. |
| Average | Calculates the average amount found for the column. | You can show the average amount sold in a transaction for each customer. |
