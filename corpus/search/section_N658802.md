Advanced and saved searches can use criteria and results based on files attached to records. You can use file field values as filters in your search criteria, and add fields stored for the attached file, including file names, as columns in your search results.

#### To define a field from an attached file (such as the file's name) as a search filter:

1.  On the Search page's **Criteria** subtab, select File Fields... in the **Filter** dropdown list.
    
2.  In the popup window that appears, select a field from the **File Filter** dropdown list.
    
3.  Click the **Set Options** button and in the popup window, enter or select a value for the filter field, and click Set.
    

#### To select a field from an attached file to be displayed as a results column:

1.  On the Search page's **Results** subtab select File Fields... in the **Field** dropdown list.
    
2.  In the popup window that appears, select a field from the **File Field** dropdown list.
    

Searching by file attachments is available for these types of searches:

-   Activity
    
-   Campaign
    
-   Case
    
-   Contact
    
-   Custom Record
    
-   Customer
    
-   Employee
    
-   Entity
    
-   Event
    
-   Issue
    
-   Project
    
-   Opportunity
    
-   Partner
    
-   Phone Call
    
-   Task
    
-   Transaction
    
-   Vendor
