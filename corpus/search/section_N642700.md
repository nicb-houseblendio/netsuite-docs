When **Global Search Auto Suggest** is on, which it is by default, NetSuite suggests matches as you type in the search field. You can select from the list of suggested records to go directly to the record you want. Here are some tips for using the auto suggest feature:

-   If your keywords match too many records, you don't see suggested matches and you're asked to narrow your search. If you don't want to refine your keywords, click **Go** to see all results.
    
-   You can scroll through suggested matches with the mouse or the up and down arrows, and select one using the mouse, Enter, or Tab.
    
-   You can select from the list, or click **Go** to see all matches.
    
-   Each suggested match shows the record type before the name.
    
-   To view a suggested match, click the record name.
    
-   To edit a suggested match, click **Edit** on the right.
    
-   To open a record in a new tab or window, right-click its name or **Edit**, and choose **Open in New Tab** or **Open in New Window**.
    
-   To open the customer dashboard for a suggested customer record match, click the View Dashboard icon on the right.
    
-   The suggestion box shows up to 8 results. If there are more, click **Show More Items** to see the rest.
    
-   If there's only one suggested match, NetSuite selects that record by default.
    
    Note:
    
    If you've enabled the **Show List When Only One Result** preference on the **Analytics** subtab of _Home > Set Preferences_, NetSuite doesn't select a single match automatically.
    
-   If you don't want suggested matches to appear as you type, disable auto suggest by clearing the **Global Search Auto Suggest** box on the **Analytics** subtab of _Home > Set Preferences_.
