You can set the following user preferences for global search at _Home > Set Preferences_ on the **Analytics** subtab:

-   **Include Inactives in Global & Quick Search** - Enable this option to include inactive records in global search and quick search portlet results. This option is disabled by default, so you see only active records for these searches.
    
-   **Global Search Auto Suggest** - When this option is enabled, NetSuite suggests matches as you type in the search field. You can select from the list of suggested records to go directly to the record you need. This option is enabled by default. For more information, see [Notes about Global Search Auto Suggest](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N642700.html).
    
-   **Global Search Sort by Name/ID** - Enable this option to sort results by name. This option is disabled by default, so results are sorted by record type first, then by name.
    
-   **Global Search Customer Prefix Includes Leads and Prospects** - Enable this option to include also leads and prospects, together with customers, when you use the **cu:** prefix. This option is disabled by default, so **cu:** returns only customers.
