You can set search results display options for advanced searches and saved searches on the **Results** subtab.

![Search Result display options.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Search/customcustomer1.png)

On the **Results** subtab, you can:

-   Choose which fields to show on the search results page. For details, see [Selecting Fields to Display in Search Results](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N648349.html).
    
-   Add custom labels for results fields to show instead of field names, and add translations if needed. For details, see [Entering Custom Labels for Search Results Columns](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N648659.html).
    
-   Set summary types for results fields to calculate values for groups of records. For details, see [Defining Summary Types to Roll Up Search Results](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N648820.html).
    
-   Set up 'when ordered by' fields to maximize another field's value. For details, see [Using When Ordered By Field for Search Results](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N649095.html).
    
-   Show totals in your search results. For details, see [Showing Totals in Search Results](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N649366.html).
    
-   Add functions to results fields. For details, see [Applying Functions to Search Results Columns](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N649633.html).
    
-   Set the sort order for fields and overall formatting. For details, see [Defining Order and Overall Formatting for Search Results](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N651604.html).
    

For transaction searches in NetSuite OneWorld accounts with the Multiple Currency feature, you can also select the consolidated exchange rate type. For details, see [Consolidated Exchange Rate Types for Transaction Searches](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1409190.html).
