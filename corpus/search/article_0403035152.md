To evaluate HTML code within a saved search, you need to use a Formula(HTML) field. To ensure that Formula(HTML) fields are displayed correctly in saved searches, go to _Setup > Company > Enable Features_. On the **Analytics** subtab, check the **Enable** **HTML Formulas in Search** box.

The HTML Formulas in Search feature enables users with the Administrator role to assign the Create HTML Formulas in Search permission. You need this permission to create saved searches with HTML formulas. To do so, the formula containing HTML must be used within a Formula(HTML) field.

The Create HTML Formulas in Search permission was initially assigned to all roles with Create level access for the SuiteScript permission and Full level access for the Perform Search permission. You can manually enable it for other users on the Role page, on the **Setup** subtab of the **Permissions** subtab.

If a user without the Create HTML Formulas in Search permission tries to edit a saved search that uses a Formula(HTML) field, all Formula(HTML) columns are removed. Additionally, the user will only be able to save a copy of the search using the Save As function.

Formula(Text) fields that contain HTML code only display results as plain text. To view a list of saved searches in your account that currently contain HTML code in Formula (Text) fields, go to _Lists > Search > Saved Searches with HTML in Formula(Text)_.

Important:

If you have customized your NetSuite center to remove or rename the Lists tab from the navigation menu, you may not see the Saved Searches with HTML in Formula(Text) list.

To access the list in your account:

1.  Go to _Customization > Center and Tabs > Center Categories_.
    
2.  Edit the **Search and Center Tab Lists** category.
    
3.  In the **Link** section, select **Saved Searches with HTML in Formula** from the list and click **Add**.
    
4.  Click **Save**.
