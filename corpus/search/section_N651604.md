On the **Results** subtab, you can set the column order, row sorting, and overall formatting for search results.

#### To set the order in which fields appear as results page columns: {#procedure_N651617}

1.  Select a field in the grid, and use **Move Up**, **Move Down**, **Move To Top**, or **Move To Bottom** to reorder it.
    
2.  Click **Done**.
    

#### To define primary, secondary, third sort fields for a search's returned records: {#procedure_N651640}

1.  Select a field in the **Sort By** and **Then By** dropdown lists.
    
2.  Check the **Descending** boxes to sort in reverse order, if needed.
    

Note:

By default, search results are sorted alphabetically according to your NetSuite language settings, but you can switch to U.S. English order. To learn more about the Search Sorting option, see [General Personal Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N475661.html).

Important:

Make sure you sort by a field that has the most unique values, or use multiple fields. Sorting by a field with duplicate values can cause the order to change each time the search is run.

## To define the format for a search results page: {#procedure_N651663}

-   Select one of the following options from the **Output Type** dropdown list:
    
    -   **Normal** - shows a list page layout.
        
    -   **Report** - shows results formatted like a report.
        
    -   **Grid** - shows a worksheet format with grid lines.
        
    -   **Graph** - shows search results as bar graph.
        

Note:

The graph option isn't the preferred view option for reports and saved searches anymore. To see your data in a graph, use SuiteAnalytics Workbook chart instead. For more information, see [Workbook Charts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544211366.html).
