The **Results** subtab for advanced or saved searches has a **Show Totals** box. Check it to add a total line to the results page. This line shows a total for any column with quantities.

![Showing totals in the search results.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Search/ShowTotSearchResultsEdit.png)

For example, **Show Totals** was checked for this search:

![Example customer total search results.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Search/totalsearch1.png)

If a search also includes a summary type that groups results, the total line also shows on drill-down pages. The summary page always shows the total line, even if **Show Totals** isn't checked.

![Summary custom search results.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Search/totalsearch2.png)

For information about grouping and summing search results, see [Defining Summary Types to Roll Up Search Results](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N648820.html).
