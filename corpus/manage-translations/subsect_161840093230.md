The scoped view feature helps you work with translation strings from a specific custom object. In the **Strings** subtab, click the object name in the **Used In** column to filter and show only strings from that object. This scoped view also shows the object ID and lets you import translations for it. You can click **Reset** to go back to the unfiltered Strings subtab.
