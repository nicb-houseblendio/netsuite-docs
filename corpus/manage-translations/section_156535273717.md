For information about the terms and concepts described in this topic, see [Manage Translations Glossary](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_157608114727.html#subsect_157468616084).

You can use the Bundle Builder to create bundles. Bundles are packages of custom or configuration objects you can install in other NetSuite accounts. You can use the Bundle Builder at _Customization > SuiteBundler > Create Bundle_ if the SuiteBundler feature is enabled and you have the SuiteApp Marketplace permission. You can add Translation Collections to customization bundles.

For information about creating bundles, see [Creating a Bundle with the Bundle Builder](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3374254.html).

After you install the bundle, the bundle ID appears in the SuiteApp field when you view or edit the Translation Collection in the target account.

The Multi-Language feature needs to be enabled in the source account to bundle Translation Collection objects. If the Multi-Language feature isn't enabled in the target account, the objects are installed and scripts can access them. However, the Translation Collections doesn't appear in the NetSuite UI.

During bundle installation, the script ID could be renamed. If there's a script ID conflict and the default locale is different, the script ID for the Translation Collection object is automatically renamed. Unlike other script ID conflicts, you can't replace the existing object during installation.
