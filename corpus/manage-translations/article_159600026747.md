You can use SDF to share translation strings for supported fields.

You can manage these translation strings in the Manage Translations application.

You can also create references to collections and parent strings for these translation strings.

For more information, see [Translatable Fields on SDF Custom Objects](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156951732735.html).

For more information about the Manage Translations application, see [Manage Translations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_158572305264.html).

## Validation of Translation Strings Distributed Through SDF {#subsect_53094207079}

Starting in NetSuite 2021.2, SDF supports two new validation types for translation strings: length and uniqueness.

SDF checks translation string slinked to translation fields, like custom list names, during SuiteApp installation. These checks make sure string lengths don't go over field limits and that each string is unique.

For a list of the uniqueness rules and length limits for each translatable field, see [Uniqueness Constraints and Length Restrictions in Translatable Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0729010159.html).

NetSuite checks uniqueness by comparing translation strings in the default account language to other fields in the account and to translation strings in the SuiteApp. NetSuite checks uniqueness by comparing translation strings in the default account language to other fields in the account and to translation strings in the SuiteApp.

To pass validation, a translation string can't have the same value as any other string in the account or SuiteApp. If it does, you'll get an error message.

For more information about translation strings,see [Manage Translations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_158572305264.html).

For more information about validations in SDF, see [Translation Collection Strings in SuiteCloud Projects](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557770229.html).
