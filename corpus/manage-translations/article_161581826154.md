The **Import Jobs** subtab shows information about translations you've imported into NetSuite. You can import collections from either the **Import Jobs** subtab or the **Strings** subtab.

View information about importing strings:

-   **File Name** - The name of the translation file.
    
-   **Collection** - The name of the collection. Click the name to view the collection.
    
-   **Language** - The file's target language. The target language is specified in the target-language XML element.
    
-   **Date** - When the collection was imported.
    
-   **Status** - The status of the collection import.
    
-   **Strings** - The number of strings in the imported collection.
    
-   **Imported** - The number of strings that were imported.
    
-   **Errors** - The number of errors during import. Click the number to see the errors.
    

You can import translations from the **Import Jobs** subtab by selecting one or more files in the Import Translations interface. For more information about mass update of translations into Translation Collections, see [Importing Translations into a Translation Collection](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544396501.html).
