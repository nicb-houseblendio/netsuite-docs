Translation strings used in NetSuite translations are of two types:

## Custom Strings {#subsect_159964458870}

You can create a custom string in either the Manage Translations UI or in SDF as part of a Translation Collection. A custom string is part of a collection, and you can edit its contents-like the description and translations.

## Stand-Alone Strings {#subsect_159964459841}

A stand-alone string is created when you create a custom object or record. When you delete the custom object or record, the corresponding stand-alone string is also deleted. So, the stand-alone string's life-cycle is tied to the object's life-cycle. You can't create or delete stand-alone strings in the Manage Translations UI. A stand-alone string can't be included in a Translation Collection.

You can link custom strings and stand-alone strings to create a hierarchy.

If you want to see stand-alone strings in the **Strings** subtab, select **Without Collection** in the **Collection** dropdown.

For information about how translation strings can form a hierarchy, see [String Hierarchy and Translation String Linking](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_159238895117.html).
