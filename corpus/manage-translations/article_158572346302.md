With SuiteCloud Development Framework, developers can use file-based definitions of Translation Collections and term translations outside NetSuite, and in their own development environment.

## Translation Collections in SuiteCloud Development Framework {#subsect_159007419978}

This section covers Translation Collections provided in SDF that help make other parts of NetSuite translatable.

You can include Translation Collections and their translations in SDF SuiteApps or projects to set up or customize NetSuite automatically with customization bundles.

For more information about using Translation Collections in SDF, see the following:

-   For information about the import of Translation Collections, see [Importing Translation Collections into SuiteCloud Projects](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1552071708.html#subsect_1557769612).
    
-   For information about deploying SuiteCloud projects with Translation Collections, see [Deploying SuiteCloud Projects Containing Translation Collections](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1552071708.html#subsect_1557769629).
    
-   For information about the inclusion of Translation Collections in SDF SuiteApps, see [Including Translation Collections in SDF SuiteApps](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1552071708.html#subsect_1557769656).
    
-   For information about the translationcollection object, see [Translation Collection Object Fields in XML Definitions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557770163.html)
    
-   For information of use of translation strings in SuiteCloud projects and an example, see [Translation Collection Strings in SuiteCloud Projects](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557770229.html).
    

In SDF SuiteApps or projects, Translation Collections and strings are defined by translationcollection custom objects and XLIFF files.

For more information about SuiteCloud Development Framework (SDF), see [SuiteCloud Development Framework](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4702622163.html).

## Translatable Fields in SuiteCloud Development Framework {#subsect_159007422425}

With SuiteCloud Development Framework (SDF), you can reference a translation string from a Translation Collection in a translatable field on a custom object.

In the UI, this is called linking translation strings. For more information, see [String Hierarchy and Translation String Linking](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_159238895117.html).

For more information about the use of translation strings from Translation Collections in a translatable field, see [Translatable Fields on SDF Custom Objects](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156951732735.html).

These topics give an ovierview of using translatable fields on custom objects and related information:

-   For more information about referencing translation strings from Translation Collections in SDF, see [Using Translatable Fields in SDF Custom Objects](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156951732735.html#subsect_157659424931).
    
-   For a list of supported translatable fields, see [Translatable Fields Supported in SDF Custom Objects](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156951732735.html#subsect_157659429943).
    
-   For information about using translatable fields in XML definitions, see [Considerations For Translatable Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156951732735.html#subsect_157659437878).
    
-   For information about reference format, see [Translation Reference Format](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156951732735.html#subsect_156952316781).
    
-   For an example of a workflow custom object referencing a term in a Translation Collection, see [Translatable Field XML Examples](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156951732735.html#subsect_157011276520).
