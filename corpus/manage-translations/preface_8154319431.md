NetSuite Globalization features support:

-   **Internationalization -** NetSuite's ready to support users around the globe.
    
-   **Localization -** Set up NetSuite to show content in different languages and use region-specific formatting.
    
-   **Translatability -** Manage object, field, or record strings so they're ready for translation.
    

Important:

To use globalization features in NetSuite, go to _Setup > Company > Enable Features_ and enable the **Multi-Language** feature.

For more information about NetSuite globalization features, see:

-   [Internationalization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_158572281325.html)
    
-   [Localization Context](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_158572284997.html)
