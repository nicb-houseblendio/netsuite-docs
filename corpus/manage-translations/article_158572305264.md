NetSuite has features that support translating SuiteScript, SuiteFlow, SuiteBundler and other customizations. In addition, you can also use features that help manage those translations.

The Manage Translations feature lets you work with Translation Collections, which are storage repositories for translation strings. A translation collection is a repository where you can store the strings you use in your NetSuite customizations. Translation strings are containers for source language strings, which can be a single word or several sentences. If the source language version of the string requires a translation, you'll also store the translated values in these containers. When you create a string, you'll assign a key value to it as it's unique identifier. A translation collection is a set of translation string containers, and the string's source language matches the collection's default language. For more information about the Manage Translations Terminology, see [Manage Translations Glossary](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_157608114727.html#subsect_157468616084).

Translation collections and strings can be:

-   created,
    
-   edited,
    
-   deleted,
    
-   imported,
    
-   exported into an XLIFF file,
    
-   downloaded to XML,
    
-   and copied to another account.
    

Note:

To access the Manage Translations page, go to _Customization > Translations > Manage Translations_.

On the Manage Translations page, you can:

-   See information about Translation Collections.
    
-   Create, modify, or delete Translation Collections.
    
-   Export Translation Collections or translation strings.
    
-   Import translation files.
    
-   See string information.
    
-   See Translation Collection information.
    
-   Download Translation Collections as XML files.
    
-   Copy Translation Collections to another account.
    
-   See statistics Translation Collection statistics.
