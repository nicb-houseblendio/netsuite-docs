You can create, edit, and delete Translation Collections from the **Collections** subtab.

#### To create a Translation Collection:

1.  Go to _Customization > Translations > Manage Translations_.
    
2.  Click **Create New**.
    
3.  In the New Collection window, set these properties:
    
    -   **Name -** Enter a descriptive name for the collection.
        
    -   **ID -** Enter a unique ID for the collection.
        
    -   **Description -** (Optional) Enter a description for the collection.
        
    -   **Default Language -** Choose a default language for the collection.
        
    
    Note:
    
    You can't change the default language after you save the collection.
    
4.  Click **Save**.
    

#### To edit a Translation Collection:

1.  Go to _Customization > Translations > Manage Translations_.
    
2.  Find the collection you want to edit, then click its name or the ellipsis (**...**) next to it.
    
3.  Edit these properties as needed:
    
    -   **Name**
        
    -   **ID**
        
    -   **Description**
        
4.  Click **Save**.
    

#### To deleting a Translation Collection:

1.  Go to _Customization > Translations > Manage Translations_.
    
2.  Click the ellipsis (**...**) next to the collection you want to delete.
    
3.  Click **Delete**.
    
4.  Click **Yes** when prompted to confirm.
    
    Warning:
    
    When you delete a Translation Collection, you'll also delete all its translation strings, translations, and import records.
