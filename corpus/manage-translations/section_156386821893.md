For information about the terms and concepts in this topic, see [Manage Translations Glossary](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_157608114727.html#subsect_157468616084).

You can use SDF for Translation Collections to store translation strings and their translations in NetSuite. A Translation Collection is defined in a SuiteCloud project by `translationcollection` objects and XLIFF files.

For detailed information about translationcollection objects, see [Translation Collections as XML Definitions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1552071708.html) and [Translation Collection Object Fields in XML Definitions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557770163.html).

You can download a Translation Collection as XML from the UI and work with it in a SuiteCloud project.

#### To download a Translation Collection to XML:

1.  Go to _Customization > Translations > Manage Translations_.
    
2.  On the **Collections** subtab, click the ellipsis **...** next to the collection you want to download to XML.
    
3.  Click **Download XML**.
    
4.  Pick where you want to save the file on your computer, then click **OK**.
