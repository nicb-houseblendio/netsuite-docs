The **Strings** subtab shows information about the strings in your account. You can see all strings in every collection, or filter to see strings in a specific collection. You can also see information about specific strings.

View information about the strings in the Manage Translations UI:

-   **Source String** - The translation string in the source language.
    
-   **Description** - The translation string's description. This helps translation vendors understand the context so they can provide an accurate translation. It explains when, where, and why users see the source string in the app.
    
-   **Translations** - The number of languages the term's been translated into. An exclamation mark means some translations are missing. If you pick a language in the **Language** dropdown list above, this column shows translations into that language.
    
-   **Collection** - The collection that includes the string.
    
-   **Used In** - Where this string is used in NetSuite. This field gives helpful context for customers, partners, or translators.
    
-   **Used As** - The cateogry of this string in NetSuite. This field gives helpful context for customers, partners, or translators.
    

You can add or edit source string descriptions by clicking the translation string in the **Description** column.

For more information about editing strings, see [Modifying Translation Collection Strings](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1544553776.html).

You can manage strings in Translation Collections from the Strings subtab. For more information, read [Working with Translation Collection Strings](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544553733.html).
