Location ID is a value you can use to help work with translation strings tied to a specific custom record.

When you create a custom record in NetSuite, all related custom fields are automatically added to the Manage Translations application.

For example, when you create a custom entry for, other translatable fields like subtabs, field groups, or actions are created automatically. You can see these new translation strings by clicking the **Strings** subtab in the Manage Translations application and scrolling to the end of the list.

Location ID is the name of the custom record or translatable field text, shown in the **Used In** column next to strings for that record. You can use it to group or filter those strings.

To see all translation strings for a specific custom record, go the Manage Translations page. On the Strings subtab, click the custom record name in the **Used In** column.
