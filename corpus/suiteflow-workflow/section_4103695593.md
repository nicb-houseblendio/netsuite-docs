Actions are specific tasks that you're adding to a workflow's state. When a record enters a state, the workflow executes the actions as you've configured them.

| Action | Description | More Information |
| --- | --- | --- |
| Add Button | Add a button to a record form. | [Add Button Action](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2740335.html). |
| Confirm | Display a popup message with OK and Cancel buttons. | [Confirm Action](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2744159.html). |
| Create Record | Create a new record. | [Create Record Action](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2741165.html). |
| Go To Page | Redirect users from a record in a workflow to a specified page in NetSuite. | [Go To Page Action](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2742608.html). |
| Go To Record | Redirect users to a specific record in NetSuite. | [Go To Record Action](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2742767.html). |
| Initiate Workflow | Initiate another workflow instance from the current workflow instance. | [Initiate Workflow Action](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2743465.html). |
| Lock Record | Lock the record for the workflow instance. | [Lock Record Action](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2743672.html). |
| Remove Button | Remove a button from a record form. | [Remove Button Action](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2740901.html). |
| Return User Error | Display an error message to users. | [Return User Error Action](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2745741.html). |
| Send Campaign Email | Send an email as part of a marketing initiative. | [Send Campaign Email Action](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2746219.html). |
| Send Email | Send an email. | [Send Email Action](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2746447.html). |
| Set Field Display Label | Change the UI label of a field in a workflow or sublist. | [Set Field Display Label Action](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2750428.html). |
| Set Field Display Type | Change the display type of a field. | [Set Field Display Type Action](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2750629.html). |
| Set Field Required | Set whether a record form field is required or not. | [Set Field Required Action](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2750923.html). |
| Set Field Value | Set the value of a record field. | [Set Field Value Action](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2751166.html). |
| Show Message | Display a message to the user. | [Show Message Action](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2743889.html). |
| Subscribe To Record | Track a workflow or state field that contains a reference to a record. | [Subscribe To Record Action](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2751816.html). |
| Transform Record | Transform a transaction record instance of one type into a transaction record instance of another type. | [Transform Record Action](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2743016.html). |
| Custom | Define an action with a Workflow action script. | [Custom Action](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2752089.html). |
