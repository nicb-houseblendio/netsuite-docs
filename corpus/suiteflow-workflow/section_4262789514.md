Use workflow templates as a starting point for customized workflows to fit your business processes. Select a template and then edit the workflow definition properties, states, actions, and transitions as needed.

![A screenshot of the available workflow templates, including the template definitions and the Select buttons.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteFlowWorkflow/CreateWorkflowFromTemplate_19.1.png)

Important:

This procedure assumes you're familiar with workflow elements. For more information, see [Workflow Elements](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4071953058.html). For more information about workflow templates, see [Workflow Templates Reference](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4190307127.html).

#### To create a workflow from a template:

1.  In NetSuite, go to _Customization > Workflow > Workflows > New_.
    
2.  Click **From Template**.
    
3.  Click **Select** for one of the following workflow template types:
    
    -   [Journal Entry Basic Approval Template](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4262810512.html)
        
    -   [Purchase Order Basic Approval Template](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4262814339.html)
        
    -   [Sales Order Basic Approval Template](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4262814660.html)
        
    -   [Lead Nurturing Template](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4490910080.html)
        

NetSuite creates the workflow in the Workflow Manager, where you can edit its properties, states, actions, and transitions.

For more information about editing a workflow after you create it from a template, see [Editing a Workflow](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4101529978.html).

Note:

When you create a workflow from a template, its Release Status is set to **Not Initiating** by default. You must change the release status to **Testing** to test the workflow. See [Release Status for Workflow Instances](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2779229.html).
