Finished, skipped, and failed scheduled workflows are accompanied by the following status notes on the Scheduled Log subtab:

| Status note | Description |
| --- | --- |
| No note | All records processed in the scheduled run. |
| Records skipped due to an infrastructure shutdown. Skipped records will be processed in the next run. | Scheduled tasks, including scheduled workflows, are stopped during maintenance. Any records not processed during this scheduled run were skipped and will be processed in the next scheduled run. For more information, see [Error Handling for Scheduled Workflows](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3862207934.html). |
| Workflow skipped due to another run currently in process. | The workflow associated with this scheduled run is still being processed by another run. The **Total Records** column for this scheduled run will display -. |
| Saved search timed out before returning any records. Workflow not processed. | The saved search associated with the workflow timed out before returning any records. This is not the same as the saved search returning no results. If no results were returned, the criteria for the search need to be revised. The **Total Records** column for this scheduled run will display -. |
