You can use a SuiteScript 2.x workflow action script to programmatically initiate a workflow on demand. Use the numeric workflow internal ID or custom script ID, the script ID of the base or subrecord types, and the internal ID of the record to identify the workflow and the record on which the workflow initiates. The workflow custom script ID is specified in the ID field of the workflow definition page. For more information about workflow action scripts, see [Creating and Using Workflow Action Scripts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158378266601.html).
