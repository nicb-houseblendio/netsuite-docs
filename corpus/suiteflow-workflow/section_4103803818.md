Use the following examples for sample workflow definition settings that initiate a workflow instance or run actions and transitions for a specific event type.

## Print Event Type {#bridgehead_4156684652}

Use the following sample settings to initiate a workflow and run actions and transitions when a user clicks **Print** in view mode on an existing Customer record.

| Task Type | Description | Settings |
| --- | --- | --- |
| Workflow initiation | Initiate workflow instance on a Customer record printed in view mode. | **Record Type:** Customer **Trigger On:** Before Record Load **On Create:** unchecked **On Update:** checked **Event Types:** Print |
| Action, Transition | Action or transition executes on a Customer record printed in view mode. | **Trigger Type:** Before Record Load **Event Types:** Print |

## Mark Complete Event Type {#bridgehead_4156688053}

Use the following sample settings to initiate a workflow and run actions and transitions when a user clicks **Mark Complete** in view mode on an existing Task record.

| Task Type | Description | Settings |
| --- | --- | --- |
| Workflow initiation | Initiate workflow instance on a Task record marked complete in view mode. | **Record Type:** Task **Trigger On:** Before Record Submit **On Create:** unchecked **On Update:** checked **Event Types:** Mark Complete |
| Action, Transition | Action or transition executes on a Task record marked complete in view mode. | **Trigger Type:** Before Record Submit **Event Types:** Print |

## Drop Ship Event Type {#bridgehead_4156689790}

Use the following sample settings to initiate a workflow and run actions and transitions when a user clicks **Approve** in view mode on an existing Purchase Order record.

| Task Type | Description | Settings |
| --- | --- | --- |
| Workflow initiation | Initiate workflow instance on a Purchase Order record approved in view mode. | **Record Type:** Transaction, Purchase Order **Trigger On:** After Record Submit **On Create:** checked **On Update:** checked **Event Types:** Drop Ship |
| Action, Transition | Action or transition executes on a Purchase Order record approved in view mode. | **Trigger Type:** After Record Submit **Event Types:** Drop Ship |
