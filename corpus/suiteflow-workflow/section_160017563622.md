If your workflow fails randomly, review the following information and try the suggested resolutions.

## Issue Description {#subsect_160017623286}

A workflow executes as expected on multiple transactions or records, but then it randomly doesn't process properly. The rate that the workflow fails to run at is extremely low: the workflow fails to process properly on approximately one out of every thousand transactions or records. When you check the workflow history for the transaction or record, it shows that the workflow and actions executed but there's no corresponding effect on the transaction or record.

## Cause {#subsect_160017688404}

The workflow fails to process properly because the Workflow Instance Data and Record Data aren't in sync. This behavior is referred to as a Transaction Management problem. The Workflow Instance Data and Record Data are initially synchronized, but when any error occurs, the transaction or record is rolled back by the Transaction Management process. However, the workflow data isn't rolled back. The workflow remains in its current state, which isn't the same state that the transaction or record is in. Consequently, the Workflow Instance Data and Record Data become out of sync.

For example, if this error occurred with an approval workflow, the workflow would remain in the approved state and the record would be in a state pending approval.

## Resolution {#subsect_160017707627}

If you have transactions or records that appear to be stuck in a workflow state, try any of the following to resolve the issue:

-   Use the Mass Updates feature to move the workflow to the same state that the transaction or record is in. For more information about transitioning an active workflow on a record outside of the defined workflow execution path, see [Mass Transitioning Workflow Instances](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1536603582.html).
    
-   Cancel the current instance of the workflow. Rerun the workflow on the transaction or record.
    
-   Recreate the transaction or record.
