Use basic search to perform a search based on a subset of the workflow properties. The following screenshot shows the workflow properties that you can use as criteria in a basic search:

![A portion of the basic workflow definition search showing search criteria. Search options shown include Name, Description, Trigger on Create, Trigger on Update, Run as Admin, Release Status, and Inactive status.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteFlowWorkflow/BasicWorkflowSearch.png)

#### To perform a basic workflow definition search:

1.  Go to _Reports > New Search_.
    
    On the Search page, click **Workflow**.
    
2.  On the Workflow Search page, clear the **Use Advanced Search** box.
    
3.  Enter the following search criteria. For the **Name**, **Description**, and **Release Status** properties, you must also select a comparison operator.
    
    | Criteria | Description |
    | --- | --- |
    | Name | The **Name** property on a workflow definition. Search by whole words only. |
    | Description | The **Description** property on a workflow definitions. Search by whole words only. |
    | Trigger On Create | Searches for workflows with the **On Create** event type selected. See [Initiating a Workflow on an Event](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2730601.html). |
    | Trigger On Update | Searches for workflows with the **On Update** event type selected. See [Initiating a Workflow on an Event](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2730601.html). |
    | Run As Admin | Searches for workflows with the **Execute As Admin** property enabled. See [Execute as Admin for Workflow Instances](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2780140.html). |
    | Release Status | Searches for workflows by the **Release Status**. See [Release Status for Workflow Instances](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2779229.html). |
    | Inactive | Searches for workflows with the **Inactive** property enabled. See [Inactivating a Workflow](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4103046356.html). |
    
4.  (Optional) To customize the results page, click **Personalize Search**. See [Personalizing a Search Form](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N666183.html).
    
5.  (Optional) To create a saved search from the search criteria entered on the page, click **Create Saved Search**. NetSuite opens the search criteria on the **Saved Workflow Search** page. For more information about working with saved searches, see [Defining a Saved Search](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N676039.html).
    
6.  Do one of the following:
    
    -   To perform the search and display the results in NetSuite, click **Submit**.
        
    -   To perform the search and then export the results and view them as a comma-separated file, click Export > Export Data Only.
