Custom fields include workflow fields and state fields. These fields are variables that you can use in workflows. Workflow fields apply to a single workflow instance whereas state fields apply to a single state in a workflow.

The following table describes where you can find more information about working with workflow and state fields:

| Task | For more information |
| --- | --- |
| Creating and using workflow fields | [Creating and Using Workflow Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4103078253.html) |
| Creating and using state fields | [Creating and Using State Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4108151274.html) |
| Storing Workflow Action script return value in a workflow field | [Storing a Return Value from a Custom Action Script in a Workflow Field](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2807069.html) |
