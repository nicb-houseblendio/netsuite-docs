The following table describes the elements of a workflow:

| Element | Description |
| --- | --- |
| Base record | The record type you're creating the workflow for. See [Workflow Base Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4071953533.html). |
| States | These are the stages or statuses a record goes through in a business process. See [Workflow States](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4071953710.html). |
| Triggers | These are events that happen when processing a record or when a user interacts with it. See [Workflow Triggers](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4071954788.html). |
| Actions | These perform specific tasks based on a record's properties. See [Workflow Actions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4071954161.html). |
| Transitions | Moves a record to another state in a workflow. See [Workflow Transitions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4071954244.html). |
| Conditions | Requirements that must be met for a workflow to initiate, or for an action or transition to execute. See [Workflow Conditions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4071954369.html). |
| Custom fields | Variables that you can use in workflows, actions, and transitions. See [Workflow Custom Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4071955161.html). |
| Revisions | The changes made to a workflow's definition or any of its children. See [Workflow Revisions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1497973389.html). |

Workflows can initiate and actions and transitions can process based on specific event types and context types. See [Workflow Event Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4071954657.html) and [Execution Contexts and Workflows](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4080817850.html).
