After you've created a sublist action group, you can start adding actions to it. For information about creating and using sublist action groups, see [Creating a Sublist Action Group](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1007022314.html).

#### To add an action to a sublist action group:

1.  In the context panel's **State** tab, hover over to a sublist action group name. You'll see icons to add, edit, or delete the group from the state.
    
2.  Click the **+** icon.
    
3.  In the New Action window, click the action type you want to add to the group. You can select from the following actions:
    
    -   [Create Record Action](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2741165.html)
        
    -   [Return User Error Action](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2745741.html)
        
    -   [Send Email Action](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2746447.html)
        
    -   [Set Field Value Action](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2751166.html)
        
4.  Configure the selected action. See [Configuring Actions for Sublist Action Groups](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_1515013170.html).
