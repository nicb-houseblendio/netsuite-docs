This subtab provides log information about your scheduled workflows. For each workflow, the log includes the start and completion date, the number of records processed, skipped, or failed, and the status of each scheduled run.

The following statuses are possible:

Note:

For details about records that are skipped or that fail as part of each scheduled run, see [Scheduled Workflow Status Notes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0217122413.html).

| Run Status | Description |
| --- | --- |
| Finished | The scheduled run started and ended. A finished run can include failed, skipped, and processed records. You will receive an email with details about any failed records. For more information, see [Error Handling for Scheduled Workflows](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3862207934.html). |
| Running | The scheduled run is still processing records. |
| Skipped | The scheduled run was skipped and no records were processed, either due to an infrastructure shutdown or because the records were being processed by another scheduled run. In cases where the run was skipped because of another scheduled run, there might not be an accompanying status note. For more information about status notes, see [Scheduled Workflow Status Notes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0217122413.html). |
| Failed | The scheduled run failed because the saved search associated with the workflow timed out before returning any records. |
