The following table describes the server triggers and their functionality. See [Workflow Triggers](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4071954788.html) and [Server Triggers](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4071954788.html#bridgehead_4074679460) for general information about server triggers.

| Trigger Type | Applies To | Description |
| --- | --- | --- |
| All | 
-   Workflow initiation

 | Initiates a workflow instance for any triggering event for a workflow. See [All Trigger](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4103737707.html). |
| Entry | 

-   Actions
-   Transitions

 | Executes the first time a record enters a state in a workflow. See [Entry Trigger](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4103738042.html). |
| Before Record Load | 

-   Workflow initiation
-   Actions
-   Transitions

 | Executes before a record loads into the browser. See [Before Record Load Trigger](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4103738307.html). |
| Before Record Submit | 

-   Workflow initiation
-   Actions
-   Transitions

 | Executes after a user clicks **Save** on a record, but before NetSuite saves the data to the database. See [Before User Submit Trigger](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4103742240.html). |
| After Record Submit | 

-   Workflow initiation
-   Actions
-   Transitions

 | Executes after NetSuite saves the record data to the database. See [After Record Submit Trigger](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4103739018.html). |
| Exit | 

-   Actions

 | Executes the first time a record exits a state in a workflow. See [Exit Trigger](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4103739227.html). |
| Scheduled | 

-   Workflow initiation
-   Actions
-   Transitions

 | Directs NetSuite to initiate a workflow or run an action or transition on a schedule. See [Scheduled Trigger](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4103739399.html). |
