The order of the workflow actions on the **Actions** subtab of the Workflow State window controls the order actions run for each trigger type. If two actions use the same trigger type, the action listed first on the subtab runs before the second, provided the condition requirements are met.

Beginning in 2015.2, there are rules that control how you can reorder actions within a state. For more information, see [Ordering Actions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4344885256.html).

Note:

For more information about the order that actions run within a state, see [Action Triggers](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4071954161.html#bridgehead_4074297007) and [SuiteFlow Trigger Execution Model](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4077993199.html)

There are two ways reorder the actions. You can click and drag the icon to the left of **Edit Actions** subtab in the Workflow State window. Or, you can use the **Insert Before** property for the workflow action.

#### To reorder actions:

1.  Open the existing workflow that contains the actions that you want to reorder.
    
    See [Viewing Existing Workflows](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4101532858.html) or [Workflow Searches](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4103089023.html).
    
2.  In the diagrammer, select the state with the actions you want to reorder and click the **Edit** icon for the state in the context panel.
    
3.  On the Actions subtab, click **Edit** beside the action, and drag it to a new location. If you try to move an action somewhere it can't go, you see an error explaining where you can move it.
    
4.  (Optional) To reorder an action with the **Insert Before** property, click **Edit** next to the action you want to reorder.
    
    In the Workflow Action window, select a new value for the **Insert Before** property, and click **Save**.
    
5.  Click **Save**.
