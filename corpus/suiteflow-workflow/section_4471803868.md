Use the following examples for more details about how to use the workflow execution log to view information and troubleshoot a workflow:

-   Actions didn't run. Use this example to get more information about how to troubleshoot a workflow when certain actions didn't run. See [Workflow Actions Did Not Execute Example](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4471797820.html).
    
-   Viewing an approval workflow. Use the workflow execution log to verify that a workflow initiated and that the actions for an approval workflow run. See [Approval Workflow Example](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4471800640.html).
