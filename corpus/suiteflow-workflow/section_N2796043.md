Use the NetSuite Mass Update feature to work with multiple workflow instances simultaneously. To use the Mass Updates feature with workflow instances, create a mass update that identifies the records on which you want to update and then save or perform the update immediately. The record type of the records that you mass update matches the base record type of the workflow you select.

Use the Mass Updates feature to do the following tasks with workflow instances:

-   Initiate instances of the workflow. See [Mass Initiating Workflow Instances](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2796163.html).
    
-   Execute transitions. See [Mass Processing Records in a Workflow](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2796312.html).
    
-   Cancel workflow instances. See [Mass Canceling Workflow Instances](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4103260636.html).
    
-   Transition an active workflow on a record outside of the defined workflow execution path. See [Mass Transitioning Workflow Instances](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1536603582.html).
    

For each record type, the Mass Updates page lists the workflows that you can initiate, process, cancel, or transition. For example, the following screenshot shows that there are two workflows based on the Item record:
