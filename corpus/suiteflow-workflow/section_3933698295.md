The workflow execution log indicates which workflow tasks were processed asynchronously. Workflow tasks that run asynchronously are placed in the scheduling queue and run in the order in which they're placed in the queue. You can direct the Workflow Manager to process workflow tasks asynchronously using the `task.WorkflowTriggerTask` object. For more information, see [task.WorkflowTriggerTask](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345799266.html).

For example, for asynchronous execution, the workflow execution log displays the following message:

`Running ONENTRY trigger under AFTERSUBMIT (Event: CREATE; Context: WEBSTORE) Asynchronous execution`
