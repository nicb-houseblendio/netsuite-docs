Use workflow administration in SuiteFlow to perform searches, initiate, process, and cancel workflow instances, and bundle workflows.

The following table lists the workflow administration tasks:

| Task | Description |
| --- | --- |
| Search workflows | Search for workflow definitions or workflow instances. See [Workflow Searches](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4103089023.html). |
| Initiate, process, or cancel workflows | Use the Mass Update feature in NetSuite to initiate workflows, process workflow instances, or cancel workflow instances. See [Workflow Mass Updates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2796043.html). |
| Workflow governance | Check workflow governance to view the unit usage limits for workflows and workflow actions. See [Script Type Usage Unit Limits](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3351480.html). |
| Bundle workflows | Use SuiteBundler to bundle a workflow and install it into a different NetSuite account. See [Bundling a Workflow](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4103266281.html). |
| Specify when workflow instances and history records are kept for a workflow | Choose if you keep workflow instances and history records Only When Testing, Never, or Always. See [Disabling History for a Workflow](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1515097346.html). |
| Delete workflow instances and history records | Use the History Record Statistics feature to delete workflow instances and history records. See [Deleting Workflow Instances and History Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4671506167.html). |
