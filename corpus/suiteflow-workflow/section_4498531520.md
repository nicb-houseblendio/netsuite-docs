The Fields subtab on the Workflow Definition page shows all of the fields created for the workflow. Use this subtab to view and create workflow fields.

#### To create a workflow field from the Workflow Definition page Fields subtab:

1.  If you haven't already, open the workflow you want to create a field in at Customization > Scripting > Workflows.
    
2.  In the Workflow Context Panel, click the edit icon to open the Workflow Definition page. By default, the Fields subtab displays at the bottom of the page.
    
3.  Click **New Field**.
    
4.  For detailed information about creating a workflow field, see [Creating and Using Workflow Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4103078253.html).
