After you create a workflow, you'll need to test it to make sure it works correctly and to troubleshoot any issues. When you're testing a workflow, you can use activity information from NetSuite to see current workflow instances for a record, current and past workflow states, and the actions and transitions performed by a workflow instance. Use this activity information to troubleshoot the behavior of the workflow.

**Troubleshooting Example**

A workflow button can appear even after the record moves to another state. If the button doesn't work as expected, review Workflow History and the workflow execution log. Check whether the Add Button action ran during record load. Also check whether a transition moved the record to another state.
