You can use the workflow execution log to test if a Send Email action executes. You can use your own email address in the **Cc** fields in both the **Sender** and **Recipient** sections of the Send Email action definition page. Verify that the Send Email action works correctly by viewing the results on the workflow execution log and checking your email account. If it works as designed, you can reset the correct email address before you set the workflow to a **Released** status.

For more information about the workflow execution log, see [Workflow Execution Log](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4472471134.html).
