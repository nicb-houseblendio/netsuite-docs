To create a workflow, first you define it on the workflow definition page. Then, you use the diagrammer and context panel to create and edit states, actions, transitions, conditions, and custom fields. For more information about each of the basic elements of a workflow, see [Workflow Elements](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4071953058.html).

To view, create, and edit workflows, you must have the correct permission and permission level for working with the base record types in the workflow. If you want access to all SuiteFlow functionality, you need the Administrator role. For more information, see [Required Permissions for SuiteFlow](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1489429737.html).

The following table describes the basic steps for creating a workflow:

| Task | Description |
| --- | --- |
| Creating and editing a workflow | Create the workflow on the workflow definition page. Specify the workflow basic properties, event definition, and workflow initiation properties. You can also schedule a workflow, view and edit existing workflows, and copy and inactivate workflows. Optionally, you can create a workflow based on a template. For information, see:
-   [Creating a Workflow](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4101527388.html)
-   [Creating a Workflow from a Workflow Template](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4262789514.html)
-   [Scheduling a Workflow](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4108268619.html)
-   [Viewing Existing Workflows](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4101532858.html)
-   [Editing a Workflow](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4101529978.html)

 |
| Create and editing states | Use the workflow diagrammer to create states, and then use the diagrammer, context panel, or **Workflow State** window to edit or delete them. See [Working with States](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4103045609.html). |
| Create and edit actions | Use the context panel or **Workflow State** window to create, edit, or delete actions. You can also reorder, move, or copy actions, use action groups to use a share condition, or schedule an action. See [Working with Actions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4103048460.html). |
| Create and edit transitions | Use the workflow diagrammer or **Workflow State** window to create, edit, delete or schedule transitions. See [Working with Transitions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4103063317.html). |
| Create conditions | You can create conditions for starting a workflow or for running actions or transitions. Build conditions with the Condition Builder, or create formulas with the Formula Builder. See [Working with Conditions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4103074843.html). |
| Create custom fields | You can create or edit workflow and state fields in the context panel or **Workflow State** window. See [Working with Custom Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4103077743.html). |
