After you create a workflow, you can edit its script ID on the workflow definition page. You can edit the ID to change the script ID that you set when you created the workflow, or override the one that NetSuite generated automatically.

#### To edit the script ID for a workflow definition:

1.  Go to Customization > Workflow > Workflows to open the Workflow list page or search for a workflow.
    
    See [Viewing Existing Workflows](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4101532858.html) and [Workflow Searches](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4103089023.html).
    
2.  Click **Edit** to open the workflow in the Workflow Manager.
    
3.  On the workflow definition page, click **Change ID**.
    
    ![A portion of the workflow definition page highlighting the Change Id button located at the top of the page.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteFlowWorkflow/EditWorkflowChangeScriptID.png)
4.  In the **Change Script ID** window, enter a new script ID. You can prefix the ID with an underscore (\_) for readability.
    
    ![A portion of the Change Script ID window showing the new script ID field.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteFlowWorkflow/EditWorkflowChangeScriptIDWindow.png)
5.  Click **Save**.
