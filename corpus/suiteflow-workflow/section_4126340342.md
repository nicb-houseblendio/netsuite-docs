You can copy a workflow action within the same workflow state. After you copy it, the copy opens in the Workflow Manager so you can edit it.

You can also copy actions from an action group. When you do, the copy appears at the end of the action group list. For more information about action groups, see [Using Action Groups](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4103059250.html).

#### To copy an action:

1.  Open the existing workflow that contains the action that you want to copy.
    
    See [Viewing Existing Workflows](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4101532858.html) or [Workflow Searches](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4103089023.html).
    
2.  In the diagrammer, select the state with the action that you want to copy. Hover over the action in the context panel and click the **Edit** icon.
    
3.  In the Workflow Action window, click **Make Copy**. The copy of the action opens in the Workflow Action window.
    
4.  Edit the copy and click **Save**. See [Editing an Action](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4103051878.html).
