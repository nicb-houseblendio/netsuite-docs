See the following topics for reference information about triggers in SuiteFlow:

-   Server triggers. Server triggers occur when a record is read from or written to the NetSuite database or when a record enters or exits a state in a workflow. See [Server Triggers Reference](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4103734459.html).
    
-   Client triggers. Client triggers run when a user interacts with a record form in NetSuite. See [Client Triggers Reference](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4103739850.html).
