Use the Workflows list page to view your existing workflows. By default, the list page shows all workflows except those marked as inactive. To view inactive workflows, check the **Show Inactives** box.

To access a workflow, you must have the full permission level for the base record the workflow was built on. Also, the related feature must be enabled in your account.

The following screenshot shows the Workflows list page:

![A portion of the Workflows list page showing example workflows and the corresponding workflow details.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteFlowWorkflow/WorkflowListPage.png)

The following table describes the tasks you can complete from the Workflow list page:

| Task | Description |
| --- | --- |
| Create a new workflow | Click **Create Workflow** to open the workflow definition page. See [Creating a Workflow](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4101527388.html) and [Scheduling a Workflow](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4108268619.html). |
| Edit a workflow | Click **Edit** to change a workflow. See [Editing a Workflow](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4101529978.html). |
| Search for workflows | Click **Search** to find workflows definitions. See [Workflow Searches](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4103089023.html). |
| Filter the workflows list | Use the **Filters** section to show only workflows with specific properties. See [Filtering the Workflow List Page](#bridgehead_4101533297). |
| Mark workflows as inactive | Use the **Inactive** column to mark workflows as inactive. See [Inactivating a Workflow](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4103046356.html). |
| Customize the workflow list page | You can customize which columns appear on the Workflow list page. See [Customizing Sublist Views](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N496633.html). |

## Filtering the Workflow List Page {#bridgehead_4101533297}

Use the **Filters** list on the Workflows list page to refine the workflows shown and find a specific workflow or workflow type.

![A screenshot of the Filters options on the Workflows list page: Record Type, Owner, Release Status, Style, and From Bundle.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteFlowWorkflow/WorkflowFilters.png)

The following tables describes the available filters:

| Filter Name | Description |
| --- | --- |
| Record Type | Base record type for a workflow. If you want to see workflows for Customer, Transaction, or Item record types, the list shows all workflows based on their sub types. You can't filter by sub type. See [Workflow Base Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4071953533.html). |
| Owner | User account set as the Owner of the workflow. |
| Release Status | Release status of the workflow. You can select **Not Initiating**, **Suspended**, **Testing**, and **Released**. See [Release Status for Workflow Instances](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2779229.html). |
| Style | Style for the display. Select **Normal**, **Grid**, or **Report**. The default view is **Normal**. |
| From Bundle | If your account has workflows installed as part of a bundle, this filter lets you find them by bundle ID. You can select **Any**, **None**, or a specific bundle ID. |

#### To filter the workflows on the Workflow list page:

1.  Go to Customization > Workflow > Workflows.
    
2.  Expand the **Filters** section and select the filters you want.
    
    The Workflows list page automatically updates with the appropriate filters.
