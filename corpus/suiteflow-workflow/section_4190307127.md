Workflow templates create predefined workflows that you can use as a starting point to create customized workflows to define typical or common business processes. Each template includes predefined workflow states, actions, and transitions. You can create a workflow based on a template and then customize it, depending on your business requirements.

For more information about creating a workflow based on a template, see [Creating a Workflow from a Workflow Template](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4262789514.html).

The following tables describes the workflow templates provided by SuiteFlow:

| Name | Record Type | For more information, see ... |
| --- | --- | --- |
| Journal Entry Basic Approval | Transaction > Journal Entry | [Journal Entry Basic Approval Template](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4262810512.html) |
| Purchase Order Basic Approval | Transaction> Purchase Order | [Purchase Order Basic Approval Template](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4262814339.html) |
| Sales Order Basic Approval | Transaction > Sales Order | [Sales Order Basic Approval Template](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4262814660.html) |
| Lead Nurturing | Lead > Campaign Email | [Lead Nurturing Template](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4490910080.html) |

Important:

For the templates to appear in the Workflow Manager, you must have the proper role to view the record type for the template. In addition, the features associated with the record type must be enabled in your account. For more information, see the topic for the appropriate template type.
