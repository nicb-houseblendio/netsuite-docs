The following table describes the client triggers and their functionality. See [Workflow Triggers](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4071954788.html) and [Client Triggers](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4071954788.html#bridgehead_4074679790) for general information about client triggers.

| Trigger Name | Description |
| --- | --- |
| Before User Edit | Executes after a record form loads into the browser and before the user makes any changes to the form. See [Before User Edit Trigger](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4103740292.html). |
| Before Field Edit | Executes before a user completes changes to a field on a record form. See [Before Field Edit Trigger](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4103740384.html). |
| After Field Edit | Executes after a user completes changes to a field on a record form. See [After Field Edit Trigger](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4103740438.html). |
| After Field Sourcing | Executes after all required field values on a record form have been populated. See [After Field Sourcing Trigger](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4103740504.html). |
| Before User Submit | Executes after a user clicks **Save** on a record and before the Before Record Submit server trigger executes. See [Before User Submit Trigger](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4103742240.html). |
