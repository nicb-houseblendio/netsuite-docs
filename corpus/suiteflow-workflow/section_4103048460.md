Each state in a workflow can contain actions. The actions used in a workflow depend on the business processes you're automating. Each state can contain one or more actions. Each action has a basic set of properties that apply to all actions. Each action also has specific properties based on the values of the record in the workflow, which you use to configure the action. For an overview of actions in SuiteFlow, including action properties, triggers, and conditions, see [Workflow Actions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4071954161.html).

For a list of all actions available in SuiteFlow, see [Workflow Actions Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4103695593.html).
