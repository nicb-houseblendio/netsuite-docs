Define the file to attach in the Send Email action's **Attachment** section. You can attach files from the File Cabinet or from a joined field containing a file. Files from Image field cannot be attached. To attach multiple files, zip all the files into one folder and attach the ZIP file to the email.

#### To send a file as an attachment with the Send Email action:

1.  Create a Send Email action.
    
2.  Fill the required fields from the **Basic Information** section.
    
3.  Fill the required Send Email action parameters. For more information, see [Send Email Action Parameters](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2746447.html#bridgehead_4148812453)
    
4.  In the **Attachment** parameter, select to attach either a:
    
    -   **File Cabinet file:** Select the **File** option and search for the file in the file cabinet.
        
    -   **Join Field file**: Select the **From Field** option and choose the joined record type and the field from the joined record that contains the file to send.
