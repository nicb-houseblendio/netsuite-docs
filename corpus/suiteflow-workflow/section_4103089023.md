You can use NetSuite to search for workflow definitions and instances. You can either use either a basic or advanced search for definitions and instances. When you perform a basic search, you use an interface unique to SuiteFlow. When you use an advanced search, you use the standard NetSuite search interface to search for workflow definitions and instances.

Use a workflow search to find out which workflows are running or inactive, which record types they use, which employees are using certain workflows, or which workflows came from a bundle.

The type of search you use depends on the type of information you want to view:

| Type of Search | Type of Search Results | More Information |
| --- | --- | --- |
| Workflow definition | For basic searches, look for all workflow definitions that match your search criteria, such as workflow name, description, trigger type, and other properties. For advanced searches, you can search by any workflow definition property. | [Workflow Definition Search](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2790157.html) |
| Workflow instance | For basic searches, look for all workflow instances that match your search criteria, such as workflow name, last state entered, date entered and exited workflow, and the date the instance entered a specific state. For advanced searches, you can also search for fields specific to the record for the workflow instance, buttons added with the Add Button action, custom fields, and workflow history fields. | [Workflow Instance Search](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2790287.html) |

After you run a workflow search, you can save the search and then add a shortcut to the search results on your dashboard. See [Adding Workflow Search Results to the Dashboard](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2790587.html).

Note:

If you want to search for workflows by the date the workflow was modified, you should audit the System Notes instead of running a workflow search. For more information, see [Searching System Notes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N673560.html).
