Delete a workflow action so it won't process on subsequent workflow runs. You can delete an action from the **Workflow State** window or the context panel.

Note:

You can also make an action inactive to temporarily stop it from running. See [Editing an Action](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4103051878.html).

#### To delete an action:

1.  Open the workflow that contains the action that you want to delete.
    
    See [Viewing Existing Workflows](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4101532858.html) or [Workflow Searches](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4103089023.html).
    
2.  In the diagrammer, select the state with the action you want to delete. Hover over the action in the context panel and click the **Delete** icon.
    
3.  (Optional) Select the state in the diagrammer and click the **Edit** icon for the state in the context panel.
    
    In the Workflow State window, click **Edit** next to the action and select **Delete** from the Actions menu.
