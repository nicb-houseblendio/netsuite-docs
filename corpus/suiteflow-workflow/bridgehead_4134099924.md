Use advanced search to perform a search based on all workflow properties available on the workflow definition page. An advanced search uses the standard NetSuite search interface to search for workflows.

The following screenshot shows the advanced workflow search interface:

![A portion of the Advanced Workflow Search instance.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteFlowWorkflow/AdvancedWorkflowSearch.png)

Note:

For more general information about running searches in NetSuite, see [Simple and Advanced Searches](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N643948.html).

#### To perform an advanced workflow definition search:

1.  Go to _Reports > New Search_.
    
    On the Search page, click **Workflow**.
    
2.  On the **Workflow Instance Search** page, check the **Use Advanced Search** box.
    
3.  Optionally, on the **Criteria** subtab, enable **Use Expressions** to use NOT, AND, OR, and parentheses in the search filters.
    
4.  On the **Criteria** subtab, define the standard and summary search filters:
    
    | Subtab | Description |
    | --- | --- |
    | Standard | Select results based on the individual workflow property values. For more information, see [Defining Standard Search Filters](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N646693.html). |
    | Summary | Select results based on calculated summary property values for a group of workflows. This filter is available only if you set a summary type for a field on the **Results** subtab. For more information, see [Summary Search Filters](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N647835.html). |
    
5.  On the **Results** subtab, set sort values and the search results fields to display, define summary types for results fields, and additional search result options.
    
    For more information, see [Search Results Display Options](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N648053.html).
    
6.  Optionally, to customize the results page, click **Personalize Search**. See [Personalizing a Search Form](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N666183.html).
    
7.  Optionally, to create a saved search from the search criteria entered on the page, click **Create Saved Search**.
    
    NetSuite opens the search criteria on the **Saved Workflow Search** page. For more information about working with saved searches, see [Defining a Saved Search](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N676039.html).
    
8.  To perform the search and display the results in NetSuite, click **Submit**. You can then export the results or edit the workflow definition.
    
    \-OR-
    
    To perform the search and then export the results and view them as a comma-separated file, click Export > Export Data Only.
