The following table lists common workflow action issues and their associated solutions:

| Issue | Solution |
| --- | --- |
| You added or edited workflow actions, but the actions don't run. | Take one of the following actions:
1.  Refresh your browser. If you add an action with a server trigger, but the action doesn't run when you test the workflow, refresh your browser. For example, you add a Set Field Mandatory action to a state, but the action doesn't appear to run.
2.  Make sure the trigger type for the action is compatible with the trigger on which the record enters the state. This error can occur when you have a state that includes an action set to trigger on Entry or Exit but the server trigger isn't supported by the action. For example, Add Button actions don't run when the record enters the state on a Before Record Submit trigger. For more information, see [SuiteFlow Trigger Execution Model](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4077993199.html).

For more information about triggers on actions, see [Action Triggers](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4071954161.html#bridgehead_4074297007) |
