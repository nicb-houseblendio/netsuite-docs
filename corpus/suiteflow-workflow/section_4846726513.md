You can edit a workflow that's been locked after installing a bundle using the Basic Information dialog. This dialog lets you change the workflow release status and enable or disable logging for the workflow.

#### To edit a locked workflow:

1.  Go to _Customization > Workflow > Workflows_.
    
2.  On the Workflows page, click **Edit** next to a locked workflow. The Basic Information dialog appears.
    
3.  To edit the release status of the dialog, select the appropriate status from the **Release Status** dropdown list.
    
4.  To enable or disable logging for the workflow, check or clear the **Enable Logging** box. When logging is enabled for the locked workflow, you can view log information about the workflow on the record's System Information > Workflow History subtab.
    
5.  To specify when to keep workflow history, in the **Keep Instance and History** dropdown list, click **Always**, **Never**, or **Only When Testing**. For details, see [Disabling History for a Workflow](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1515097346.html).
    

Note:

A padlock icon indicates that a workflow is locked on the Workflows page.
