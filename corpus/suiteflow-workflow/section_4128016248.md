The order of the workflow transitions on the **Transitions** subtab of the Workflow State window determines when each transition runs for each trigger type. If two transitions run on the same trigger type, the first transition listed runs before the second, if the condition requirements are met. Reorder the transitions on the **Transitions** subtab to specify the order they run.

Note:

For more information about the order of transition processing in a state, see [Transition Triggers](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4079591327.html) and [SuiteFlow Trigger Execution Model](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4077993199.html).

There are two ways to reorder transitions. You can click and drag the icon to the left of **Edit** on the **Transitions** subtab of the Workflow State window and to move an action. Each workflow transition also has the **Insert Before** property you can use to change its order in a state.

#### To reorder transitions:

1.  Open the existing workflow with the transitions you want to reorder.
    
    See [Viewing Existing Workflows](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4101532858.html) or [Workflow Searches](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4103089023.html).
    
2.  In the diagrammer, select the state with the transitions you want to reorder and click the **Edit** icon for that state in the context panel.
    
3.  Click and drag the icon to the left of **Edit** on the **Transitions** subtab to move the action to a new location.
    
4.  (Optional) To reorder an transition with the **Insert Before** property, click **Edit** next to the transition you want to move.
    
    In the Workflow Transition window, select a new **Insert Before** value, then click **Save**.
    
5.  Click **Save**.
