You can use the Scheduled trigger with a transition to create a scheduled transition. You can schedule a transition to run after a certain number of hours or days after the record enters the state. For more information about how scheduled transitions work, see the [Scheduled Trigger](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4103739399.html).

You can add a delay to a transition for any trigger type. However, using the Scheduled trigger type gives you more control over when a transition runs. For example, if you set a delay on a transition and use the After Record Submit trigger, the delay starts only after that trigger runs. If you use the Scheduled trigger, the transition runs after the delay, starting when the record enters the state.

#### To schedule a transition:

1.  Create a transition. See [Creating a Transition](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4103065793.html).
    
    Note:
    
    Make sure you set the **Trigger On** property to **Scheduled**.
    
2.  In the diagrammer, double-click the state with the transition that you want to schedule and click **Edit** to the left of the transition on the **Transitions** subtab.
    
3.  In the **Workflow Transition** window for the transition, set the following properties:
    
    | Property | Description |
    | --- | --- |
    | Delay | Number of time units specified in the **Unit** property until the transition runs. |
    | Unit | Unit of time for the **Delay**. Select **Hour** or **Day**. |
    
4.  Click **Save**.
