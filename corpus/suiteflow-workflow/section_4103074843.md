You can use conditions on workflow initiation, workflow actions, and workflow transitions. Use these conditions to limit who, when, and which record instances start a workflow or execute actions and transitions. To create conditions you can use the:

-   **Condition Builder:** see [Defining a Condition with the Condition Builder](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4103075208.html).
    
-   **Formula Builder:** see [Defining a Condition with Formulas](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4103077064.html).
    
-   **Saved Search:** see [Saved Searches](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N675442.html).
    

Note:

You can create composite conditions, meaning, one condition with field value comparisons, a formula, and a saved search. In these cases, all conditions must be true for the workflow instance to initiate or an action or transition to process. If the condition includes a saved search, the workflow action or transition only executes on the record instances the search returns.

For examples of using conditions see:

-   [Referencing Old Record Values in a Workflow](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4103799808.html) and
    
-   [Defining Conditions for Customer Credit Hold Field](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4103800262.html)
