## 2025.2.10 Minor Release of SuiteCommerce, SuiteCommerce MyAccount, and SuiteCommerce Advanced {#subsect_82071724762}

### Enhancements {#subsect_36071712796}

#### CAPTCHA Secret Key Moved from SuiteCommerce Configuration Record to API Secret Manager {#subsect_1103112827}

**Applies to**: SuiteCommerce, SuiteCommerce Advanced, SuiteCommerce MyAccount

With the 2025.2.10 release, CAPTCHA secret keys are stored in the API Secrets area of NetSuite. Starting 2025.2.10, you must enter the secret key in API Secrets and only its ID in the SuiteCommerce Configuration record.

This change enhances security by removing plaintext secrets from configuration and enabling stricter access control. At runtime, NetSuite retrieves the secret key using its ID, and CAPTCHA verification continues.

To create a CAPTCHA secret key, go to Setup > Company > API Secrets and follow the instructions provided in [Creating Secrets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160216498405.html). Then, enter the secret key's ID in the SuiteCommerce Configuration record by following the instructions provided in [How to Enable and Configure SuiteCommerce CAPTCHA](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0902103700.html).
