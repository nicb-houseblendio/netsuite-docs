If you are upgrading an existing Reference Implementation to a newer release, refer to the following PDF: [Release Notes Prior to SuiteCommerce Advanced Denali](https://system.netsuite.com/app/help/helpcenter.nl?fid=SCAReleaseNotesPreDenali.pdf) for details on changes between releases.
