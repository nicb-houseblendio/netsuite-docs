Commerce themes enable you to change the layout and style of your web store. The following release notes describe new or enhanced Commerce themes developed and supported by NetSuite.

Important:

Commerce themes are only available if they are **provisioned and set up in your account**. Some Commerce themes may be dependent on the **latest release of NetSuite**. Check that your account has been upgraded to the latest release. For more information, see [Commerce Themes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_158386920036.html).

### Horizon V4 Theme {#subsect_15213439583}

Horizon V4 is an upgraded version of the Horizon custom theme that continues to provide a framework for your outdoor supply web store, while also taking advantage of the latest SC Base Theme releases. This means that Horizon V4 can receive future updates, including fixes, enhancements, and new features, released through the SC Base Theme just by reactivating Horizon V4 in the Extension Manager.

To activate Horizon V4, go to the Extension Manager (Commerce > Extensions > Extension Manager), check the box for the Horizon V4 theme, and click **Activate**.

Note that if you have made customizations to your existing Horizon (or other) theme, these changes will not be carried over to Horizon V4.

For more information, see [Horizon Theme](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158386965797.html).

### Manor Theme {#subsect_161107296177}

Version 3.1.0 of the Manor Theme includes the following fixes and enhancements:

-   Two additional layouts are available for the home page. This includes the Home CMS and Home Flex layouts.
    
-   The Menu and Cart buttons are now sticky buttons, fixed to the top of the page for both mobile and desktop.
    
-   Theme Settings in Site Management Tools includes the option to display the search input bar in an open state. For details, see [Editing a Theme Skin](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158497653583.html).
    
-   During checkout on mobile, the shipping and billing addresses are displayed in a collapsed view with a summarized description of each.
    
-   When viewing the Product Details page on mobile, the Add to Cart button is now a sticky button fixed to the bottom of the page.
    
-   Mobile now supports the zoom functionality.
    
-   An issue with the Out of Stock Behavior using structured data markup has been fixed.
    
-   An issue preventing some translations from appearing has been resolved.
    
-   User interface improvements have been made to the following:
    
    -   The facet selection boxes on the Product Listing page.
        
    -   The caption position and arrows in the carousel.
        
    -   A spacing issue with related items on the Product Details page.
        
    -   The details section on the Product Details page.
        
    -   The PayPal button in the shopping cart.
        
    -   The Follow Us section in the footer.
        
-   CMS and data-view placeholders have been added to templates in the following areas:
    
    -   My Account
        
    -   Shopping
        
    -   Checkout
        
    
    For more information, see [Templates and Theme Areas for SuiteCommerce Themes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_161521710124.html).
    

For more information about this theme, see [Manor Theme](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158386968178.html).
