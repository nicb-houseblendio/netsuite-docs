Following are the 2026.2 manufacturing enhancements to SuiteApps:

## Manufacturing Mobile Enhancements {#subsect_18130922341}

The Manufacturing Mobile SuiteApp version 2026.2 includes the following enhancements:

-   [Access Work Orders Across Subsidiary Locations](#subsect_0807102119)
    
-   [Control Work Order Transaction Dates](#subsect_0807102154)
    

### Access Work Orders Across Subsidiary Locations {#subsect_0807102119}

The Manufacturing Mobile SuiteApp now supports work order access across all locations within an employee's mapped subsidiary.

Administrators can enable the new **Allow Access to All Locations** preference on the Manufacturing Mobile-Preferences page.

When you enable this preference, operators can access work orders at any location associated with their mapped subsidiary.

When you disable this preference, the SuiteApp retains the existing behavior by providing access to the location mapped to an employee record.

This enhancement provides operational flexibility for organizations that require employees to work across multiple manufacturing locations.

### Control Work Order Transaction Dates {#subsect_0807102154}

The Manufacturing Mobile SuiteApp now introduces the **Use Real-Time Date for Work Orders** preference on the Manufacturing Mobile-Preferences page.

This preference controls transaction dates for Assembly build, Work order completion, and Work order issue transactions.

When you enable this preference, the SuiteApp automatically posts transactions using the current system date and does not allow you to select a date.

When you disable this preference, you can select a transaction date to support backdated transactions.

For more information, see the help topic [Manufacturing Mobile](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/part_158644016906.html)
