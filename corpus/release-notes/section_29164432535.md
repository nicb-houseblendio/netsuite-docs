## 2026.1.20 Minor Release of SuiteCommerce, SuiteCommerce MyAccount, and SuiteCommerce Advanced {#subsect_0609032148}

### Subsidiary Date Formats Respected on SuiteCommerce Websites with CDN Caching {#subsect_0609032302}

SuiteCommerce and SuiteCommerce Advanced websites that use CDN caching now display dates according to the **Date Format** preference configured on the shopper's subsidiary. Previously, when CDN caching was enabled, a web store could display a cached date format that did not match the shopper's subsidiary date format.

This change helps ensure that date fields, such as **Supply Required By**, use the expected format for shoppers associated with subsidiaries in different countries.
