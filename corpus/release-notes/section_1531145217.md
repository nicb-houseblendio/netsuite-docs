Welcome to the 2018.2 release of SuiteCommerce and SuiteCommerce Advanced!

Important:

If implementing SuiteCommerce Advanced, you **must** install the 2018.2 release of SCA in a **NetSuite 2018.2** account. Many of the features and enhancements in this release have dependencies on NetSuite 2018.2.

Note:

If implementing SCA, take advantage of new features in existing SCA implementations by migrating the new code to your existing code base. For details, see [Migrate SuiteCommerce Advanced](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1559073362.html).
