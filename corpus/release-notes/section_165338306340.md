## 2022.2.1 Minor Release of SuiteCommerce, SuiteCommerce MyAccount, and SuiteCommerce Advanced {#subsect_165338302896}

### Enhancements {#subsect_63115013560}

-   The Strike-Through Pricing feature is now available for matrix items as well as non-matrix items. See [Strike-Through Pricing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159190992483.html).
    
-   Updated the SuiteCloud library referenced in the `package.json` file to SuiteCloud Command Line Interface (CLI) for Node.js version 1.6.2.
    
    For SuiteCommerce and SuiteCommerce Advanced versions 2022.2.1 and later, you should use Node.js version 14.19.0. See [Install Node.js](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4183926623.html).
    

### Fixes {#subsect_165338305187}

-   Fixed an issue that caused items searched not to be displayed with the number of results on the Search Results page.
    
-   Fixed an issue that caused inconsistent information about cut-off time and pick-up day to be displayed on some Commerce websites when customers order an item for pick up in store.
    
-   Fixed an issue causing incorrect payment processing profiles to be used when paying an invoice in the following situations:
    
    -   At least two payment processing profiles use the same payment method.
        
    -   The Payments Instrument feature is enabled.
        
-   Fixed an issue with promo codes that prevented customers from placing an order when items in their shopping cart were ineligible for promotion.
    
-   Fixed an issue that caused error messages not to be displayed when customers paid an invoice using 3D Secure 2 and an error occurred.
    
-   Unlocked files in the following folder:
    
    Web Site Hosting Files > Live Hosting Files > SSP Applications > NetSuite Inc. - SCA 2022.2.0 > Development
