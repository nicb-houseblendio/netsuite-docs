### SuiteCommerce Extension Management {#subsect_0616105553}

With the 2025.2.0 release, a new feature is available as a custom preference for your company. The **SCEM Enable Code Optimization** field lets you optimize your extension's JavaScript code for improved performance and security.

When enabled, this feature automatically minifies and obfuscates JavaScript code during extension activation.

This field is enabled by default and doesn't require any action from you. You can disable the field at any time by going to Setup > Company > General Preferences > Custom Preferences.

For more information, see [Optimizing Extension Code with SCEM Enable Code Optimization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510954484.html#subsect_0616114035).

## Product Feeds {#subsect_0616105656}

Product Feeds now includes support for the **Google UCP Product Feed**, which lets SuiteCommerce product catalogs be exposed to Google for Gemini-powered shopping experiences.

With this feed, shoppers can discover and browse SuiteCommerce products through AI-driven conversations. When shoppers are ready to purchase, they are redirected to the SuiteCommerce website for checkout.

NetSuite generates a secure feed URL that can be submitted through Google Merchant Center as part of the Google Universal Commerce Protocol onboarding process. The feed automatically includes products currently displayed on the SuiteCommerce site.

The Google UCP Product Feed uses a predefined saved search and standardized feed structure. Customers with custom product feed configurations should review related customizations and workflows for compatibility.

For more information, see [Configure Google UCP Product Feeds](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0616042155.html).

### Cookie Consent {#subsect_162992992475}

The Cookie Consent extension lets you set up a banner and menu that shoppers can utilize to accept or reject cookies on a web store site.

It gives shoppers the ability to give informed consent to the collection of data that might include personally identifiable information (PII). The extension provides areas for you to enter information about the cookies used, identify whether some cookies are strictly necessary for functioning of the site, and include links that direct shoppers to a web store's unique privacy policy page. For more information, see [Configure the SC Cookie Consent Extension](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_162429920925.html).

The extension is required if the SuiteCommerce Analytics Data feature is enabled. It is also available for other SuiteCommerce web store setups. For more information, see [SuiteCommerce Analytics Data Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160260490967.html).
