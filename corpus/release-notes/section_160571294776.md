## 2021.1.7 Minor Release of SuiteCommerce, SuiteCommerce MyAccount, and SuiteCommerce Advanced {#subsect_163463778302}

### Fixes {#subsect_163463781390}

-   Fixed an issue where the URL gclid parameter was being removed when using the setDisplay function of the Extensibility API.
    
-   Fixed an issue where an item with a free gift promotion was reverting from a pickup in store to a shipping delivery method.
    

## 2021.1.6 Minor Release of SuiteCommerce, SuiteCommerce MyAccount, and SuiteCommerce Advanced {#subsect_163463768787}

### Fixes {#subsect_163463775593}

-   This release provides updates affecting background processing in NetSuite but does not impact the end user.
    

## 2021.1.5 Minor Release of SuiteCommerce, SuiteCommerce MyAccount, and SuiteCommerce Advanced {#subsect_162919008936}

### Fixes {#subsect_162919024048}

-   Fixed an issue where recently viewed items were not displayed in the customer's Shopping Cart page.
    
-   Fixed an issue where discounts were not being applied to the customer's subtotal, total, or final payment of an invoice.
    
-   Fixed an issue where only four items were displayed in dropdown search results.
    
-   Fixed an issue where the status column on the Quotes page displayed incorrect values.
    

## 2021.1.4.1 Minor Release of SuiteCommerce and SuiteCommerce Advanced {#subsect_162854046242}

### Fixes {#subsect_162854049621}

-   Fixed an issue where customers received the following error when attempting to checkout as Guest: **NOT ALLOWED - Sorry you have no permission to view this page**. This issue occurred when **Customer Registration** was configured as **Disabled** on the Website record.
    

## 2021.1.4 Minor Release of SuiteCommerce, SuiteCommerce MyAccount, and SuiteCommerce Advanced {#subsect_162610128950}

### Fixes {#subsect_162610409584}

-   Fixed an issue with the Store Locator feature causing Google Maps to display the incorrect store location.
    

## 2021.1.3 Minor Release of SuiteCommerce, SuiteCommerce MyAccount, and SuiteCommerce Advanced {#subsect_162383317123}

### Fixes {#subsect_162383326548}

-   Fixed an issue in My Account where the **Back** and **Submit** buttons were disabled and customers could not edit and submit their credit card payment information.
    
-   Fixed an issue in My Account preventing the language selector from displaying.
    
-   Fixed an issue with Extension Management to include item options in query parameters so that URLs can update without reloading the page.
    
-   Fixed a permissions issue that prevented customers from viewing their transaction history on the web store.
    
-   Fixed an issue to prevent related items from overlapping on the Product Details Page.
    
-   Fixed an issue that caused a number of strings in the My Account menu items area not to be translated.
    

## 2021.1.2 Minor Release of SuiteCommerce, SuiteCommerce MyAccount, and SuiteCommerce Advanced {#subsect_162014608988}

### Fixes {#subsect_162014614942}

-   Fixed an issue preventing the SuiteCommerce Extension Manager from functioning as expected when used with 2020.2 and earlier versions of SuiteCommerce Advanced.
    
-   Fixed an issue preventing the EN\_CA translation key from displaying in the Translations subtab of the SuiteCommerce Advanced Multi-Domain configuration tab.
    
-   Fixed an issue preventing Terms and Conditions from displaying for Invoice payments during checkout.
    
-   Fixed an issue preventing items added to the shopping cart from displaying when the SuiteCommerce domain configuration includes an integration with Google Tag Manager.
    

## 2021.1.1 Minor Release of SuiteCommerce, SuiteCommerce MyAccount, and SuiteCommerce Advanced {#subsect_160571296910}

### Fixes {#subsect_161824818833}

-   Fixed a SuiteCommerce Extension Manager issue preventing the extension developer tools from creating a list of available extensions to fetch when running `gulp extension:fetch`.
    
-   Fixed a SuiteCommerce Extension Manager issue preventing the SCDeployer role from authenticating properly when fetching from or deploying to NetSuite using the theme or extension developer tools.
    
-   Other minor, internal fixes and improvements.
