These enhancements typically apply to SuiteCommerce, SuiteCommerce MyAccount, and SuiteCommerce Advanced; however, some features could apply to a subset of each. The following enhancements explain the implementations to which they apply.

## Ability to Make URLs Public on Password Protected and SuiteCommerce MyAccount Sites {#subsect_0703111018}

**Applies to:** SuiteCommerce, SuiteCommerce Advanced, SuiteCommerce MyAccount

With the 2024.2.0 release, you can specify URLs that can be accessed publicly by anonymous users, even if your website requires a user to log in first. This applies if your site is a SuiteCommerce MyAccount site or if your web store has the **Password-Protect Entire Site** setting checked.

To make some of your pages publicly accessible, enter their paths into the **Public URLs** table in your site's SuiteCommerce Configuration record. For example, you may want to make your home page, a product category page, or your Advanced Sign Up page, publicly available.

For more information, see [Set Public URLs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0926024004.html).

## Node.js Requirement {#subsect_30125121954}

**Applies to:** SuiteCommerce, SuiteCommerce MyAccount, and SuiteCommerce Advanced

With the 2024.2.0 release, the developer tools continue to support Node.js version **20.10.0**. To use the Theme, Extension, or core SCA 2024.2 developer tools, you must use this Node.js version.

For more information, see [Install Node.js](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4183926623.html).
