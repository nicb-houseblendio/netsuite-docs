## SuiteTax SuiteApps {#subsect_37133721869}

### Philippines Tax Reports Now Available for Accounts with SuiteTax {#subsect_0804085943}

The Philippines Tax Reports SuiteApp is now available in the SuiteApp Marketplace. Accounts with SuiteTax can now use the SuiteApp to generate ready-to-file tax audit files for key books of account directly from NetSuite, in compliance with the Bureau of Internal Revenue's (BIR) requirements. The SuiteApp also automatically populates all required company and period details.

The following tax audit files are included in the SuiteApp:

-   General Ledger
    
-   General Journal
    
-   Sales Journal
    
-   Purchase Journal
    
-   Cash Receipts Journal
    
-   Cash Disbursements Journal
    
-   Inventory Book
    

Before you install the Philippines Tax Reports SuiteApp, you must enable the **SuiteTax**, **Custom Records**, and **Server SuiteScript** features. For more information, see [Enabling Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N232138.html). You must also install the following SuiteApps:

-   Southeast Asia Localization SuiteApp. See [Installing the Southeast Asia Localization SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_1532417449.html).
    
-   Tax Reporting Framework SuiteApp. See [Installing Tax Reporting Framework](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1528245293.html).
    
-   Localization Assistant SuiteApp (only if you require localization assistant registration). See [Installing the Localization Assistant SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163092361565.html).
    

To generate a Philippines Tax Audit File, go to Reports > Tax > Country Tax Reports.

For more information, see [Philippines Tax Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0804082242.html).

### Southeast Asia Localization Adds SuiteTax Support for Philippines Invoicing Features {#subsect_55170541437}

Southeast Asia Localization now supports Philippines invoicing features in accounts with SuiteTax.

You can now configure Philippines document printing preferences and print supported transactions with the Ease of Paying Taxes (EoPT) invoice template. With this update, you can complete the following Philippines invoicing tasks in accounts with SuiteTax:

-   Set up document numbering
    
-   Map Philippines document types and templates to transaction forms
    
-   Print supported Philippines transactions with BIR-required document details
    
-   Use Advanced PDF/HTML Templates for printing
    

For more information, see [Philippines Invoicing with SuiteTax in Southeast Asia Localization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0811032321.html).
