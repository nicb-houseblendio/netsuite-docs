Welcome to the 2025.2 release of SuiteCommerce, SuiteCommerce MyAccount, and SuiteCommerce Advanced (SCA)!

Important:

Features and enhancements in this release have dependencies on NetSuite 2025.2. You must implement this release in a **2025.2** NetSuite account.

The 2025.2 release incorporates periodic updates to the application. Refer to the following release notes for updates included in the major release and any subsequent minor releases. How you use these release notes depends on your web store:

-   **SuiteCommerce** and **SuiteCommerce MyAccount** - These changes automatically apply to your SuiteCommerce account according to a scheduled update. Use these release notes as an informative guide to understand the changes applied to your account.
    
-   **SuiteCommerce Advanced** - These changes don't automatically apply to your SCA account. To update your site, you must manually migrate your website to the latest SCA release. Use these release notes to determine if migration is necessary for your SCA implementation. This update doesn't alter the existing bundle ID. If you determine an update is necessary, see [Migrate SuiteCommerce Advanced](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1559073362.html) for instructions.
    
    Note:
    
    For more information about updates to this release, see [Commerce Patches and Upgrades](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4043708822.html).
