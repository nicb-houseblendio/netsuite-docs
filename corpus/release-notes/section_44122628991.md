The 2025.1.0 major release includes the following features and enhancements:

-   [Ability to Return Assembly Items](#subsect_0430014955)
    
-   [Configuration Properties Updates](#subsect_88123127321)
    
-   [Node.js Requirement](#subsect_65123222518)
    
-   [Third-Party Library Updates](#subsect_77123258698)
    
-   [Issue Fixes](#subsect_73123334147)
    

These enhancements typically apply to SuiteCommerce, SuiteCommerce MyAccount, and SuiteCommerce Advanced; however, some features could apply to a subset of each. The following enhancements explain the implementations to which they apply.

## Ability to Return Assembly Items {#subsect_0430014955}

**Applies to**: SuiteCommerce, SuiteCommerce Advanced, SuiteCommerce MyAccount

With the 2025.1 release, your customers can now return assembly items. For more information about assembly items, see [Assembly Items](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N2319010.html).

## Configuration Properties Updates {#subsect_88123127321}

No new SuiteCommerce configuration properties have been added with the 2025.1.0 release.

## Node.js Requirement {#subsect_65123222518}

**Applies to:** SuiteCommerce, SuiteCommerce MyAccount, and SuiteCommerce Advanced

With the 2025.1.0 release, the developer tools continue to support Node.js version **20.10.0**. To use the Theme, Extension, or core SCA 2025.1 developer tools, you must use this Node.js version.

For more information, see [Install Node.js](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4183926623.html).

## Third-Party Library Updates {#subsect_77123258698}

No library updates have been made for this release.

### SuiteCommerce Extension Management {#subsect_0527103328}

Version 2025.1.0 of the SuiteCommerce Extension Management bundle includes the following enhancements:

-   Enhanced error messages to provide more clear context
    
-   Extended DevTools support to be compatible with more domains
    
-   Improved handling of activation origin triggers
    

## Issue Fixes {#subsect_73123334147}

**Applies to:** SuiteCommerce, SuiteCommerce MyAccount, and SuiteCommerce Advanced

The 2025.1.0 release includes all minor release fixes, improvements, and security updates of the previous release. See [2024.2.x Minor Releases](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_94125440796.html) for details.
