## 2020.2.5 Minor Release of SuiteCommerce, SuiteCommerce MyAccount, and SuiteCommerce Advanced {#subsect_161521184342}

### Enhancements {#subsect_161521195771}

-   Moved field locations to give SuiteCommerce MyAccount (SCMA) administrators access to configure field IDs for transaction records on the customer webstore. SCMA administrators did not have access to the configuration settings on the **Shopping Catalog** tab > **Item Options** subtab.
    
    The **Show only items listed in: item options and custom transaction column fields** checkbox and the **Item options and custom transaction column fields** configuration fields have moved from this location to the **Advanced** tab > **Items Options** subtab. The **Item Options** subtab under the **Shopping Catalog** tab is renamed **Item Options Templates**.
    
-   Fixed **Out of Stock Behavior** that was not honored when set to "Disallow backorder but display out of stock message." Out of stock items went into backorder when the **Multi-Location Inventory** and **Make Inventory on Web Site** features were enabled.
    

### Fixes {#subsect_161521197513}

-   Fixed an issue where the gift wrapping price was not included on the transaction record.
    
-   Fixed a page loading error where the loading icon did not display and it was unclear that the page was loading.
    
-   Fixed an issue where token-based authentication was not supported for sandbox accounts.
    
-   Fixed an issue to remove memorized sales orders (transactions set up to recur in the future) from the list of transactions displayed in My Account.
    

## 2020.2.4 Minor Release of SuiteCommerce, SuiteCommerce MyAccount, and SuiteCommerce Advanced {#subsect_161245069756}

### Enhancements {#subsect_161245073880}

Theme and extension developer tools have been updated to support token-based authentication when connecting with NetSuite. This update is required so that the Commerce developer tools, including the extension, theme, and SuiteCommerce Advanced command-line developer tools, are compliant with the mandatory 2FA policy for NetSuite administrators and other highly privileged roles. Commerce developer tools will no longer accept NetSuite user credentials for authentication with NetSuite and instead will require token-based authentication.

For SuiteCommerce implementations, you should download and set up the most recent version of the theme and extension developer tools as described in the [Set Up the Commerce Developer Environment](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4183925632.html) topics. The updated developer tools require tokens when connecting with NetSuite. For more information about using token-based authentication, see [Token Based Authentication](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160997054391.html).

For SuiteCommerce Advanced implementations, you need to apply a patch to prepare your installation of SuiteCommerce Advanced to use token-based authentication. Successful completion of the patch is required before continuing to use the developer tools. Be sure to follow the patch instructions appropriate for the version of SuiteCommerce Advanced you have implemented. See [Enable Token-Based Authentication](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161109340483.html) for details. After successfully completing the patch, you need to supply tokens for developer tool authentication when connecting with NetSuite. For more information about using token-based authentication, see [Token Based Authentication](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160997054391.html).

### Fixes {#subsect_161245078037}

-   Issue preventing multi-language translations, as entered on the SC Configuration record, from translating on the website (**Multi-Domain** tab, **Translations** subtab).
    
-   Issue preventing users from adding Maestro credit cards as valid payment methods using the My Account interface on the site.
    
-   Issue causing inconsistencies for items with multiple images. After users add an item to the cart and continue shopping on the site, the item details page displays incorrect images when users click on other product items.
    
-   Issue causing the site to display a blank page when users with over 1000 open invoice records attempt to view invoices in My Account.

## 2020.2.1 Minor Release of SuiteCommerce, SuiteCommerce MyAccount, and SuiteCommerce Advanced {#subsect_160443706498}

### Fixes {#subsect_161050435808}

-   Added a new Extensions subtab to the Advanced Tab of the Configuration Record. The new Extensions subtab includes an **Extensibility Layer Safe Mode** option. Enabling this option is recommended so that you are aware of extensions developed in a way other than as recommended via the Extensibility API layer and can take action to revise them. When enabled, this option causes a notification to display in the web browser console at runtime when an extension that directly customizes or imports private core modules is being loaded into your site. An error is generated when an extension customizes or imports a core module that is disallowed. A warning is generated when an extension customizes or imports a core module that is allowed for now, but will be disallowed in the future. For more information, see [Extensibility Layer Safe Mode](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160461219470.html#subsect_160467436691).
    
-   Fixed an issue preventing customers from disabling the **Same as Shipping Address** option for the Billing Address during checkout.
    
-   Fixed an issue causing 404 errors for CMS landing pages and CMS zones to display without content when the **Multi-Language** option is disabled for a company.
