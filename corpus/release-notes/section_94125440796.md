This release provides updates affecting background processing in NetSuite but does not impact customers.

## 2024.2.30 Minor Release of SuiteCommerce, SuiteCommerce MyAccount, and SuiteCommerce Advanced {#subsect_68121959130}

### Enhancements {#subsect_38122403566}

-   For SuiteCommerce and SuiteCommerce Advanced versions 2024.2 and later, you can now specify if you want to let your customers view and create product reviews on your Commerce website. A new checkbox, **Enable Product Reviews**, has been added to the SuiteCommerce Configuration record. This setting is enabled by default. If you do not want your customers to view and create product reviews, you can clear the **Enable Product Reviews** box. See [Enable Product Reviews](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4667043852.html#subsect_0313123451).
    
    For SuiteCommerce Advanced versions 2024.1 and earlier, install the Reference Review Records SuiteApp. See [Product Reviews for SuiteCommerce Advanced 2024.1 and Earlier](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3844716106.html#subsect_0313124610)
    

### Fixes {#subsect_36122424699}

-   Fixed an issue that caused the shipping cost to be set to $0 when PayPal was selected as the Payment Method.
    
-   Fixed an issue that caused the shipping price on the Review Your Order page to change from the one displayed on the Order Summary page.
    
-   Fixed an issue in which custom records of product reviews were incorrectly created after customers updated the SuiteCommerce bundle.
    
-   Corrected the See Help link under **Public URLs** so that they point to the correct place in the NetSuite Help center, instead of the homepage.
    

## 2024.2.20 Minor Release of SuiteCommerce, SuiteCommerce MyAccount, and SuiteCommerce Advanced {#subsect_53193618476}

### Enhancements {#subsect_15125701403}

-   Changed the word "Tweet" to "post" on product description pages of Commerce websites with Twitter/X integrations.
    

### Fixes {#subsect_79125706663}

-   Fixed an issue that caused shoppers to be directed to the home page instead of the order confirmation page after they clicked **Place Order** on the checkout page of some Commerce websites. This issue occurred in SuiteCommerce and SuiteCommerce Advanced accounts where Google Tag Manager was configured and Google AdWords was added as a service.
    

## 2024.2.10 Minor Release of SuiteCommerce, SuiteCommerce MyAccount, and SuiteCommerce Advanced {#subsect_6125628925}

### Fixes {#subsect_0217103704}

-   Fixed an issue in My Account that caused cancelled return requests not to update to a status of **Cancelled**.
    
-   Fixed an issue in My Account, which caused a blank page to display when new customers clicked on **My List**. Now, customers will now see the following message, 'You don't have items in this list yet. Explore the store or search for an item you would like to add.'
    
-   Fixed an issue in My Account > Purchases > Purchase History that caused FedEx tracking links not to redirect to the correct page.
    
-   Fixed an issue with strike-through pricing that caused matrix child items to display with the default price level struck through in web stores. The struck-through price is now not displayed for matrix child items when the default price level is empty, equal to, or lower than the online price.
    
-   Fixed an issue that prevented customers from checking out items in their shopping carts if a phone number was not entered in their customer profiles. Now, customers who do not enter a phone number can check out items.
