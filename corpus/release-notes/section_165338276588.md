The 2022.2.0 major release includes the following features and enhancements:

-   [3D Secure 2.0 Available in the Make a Payment Flow](#subsect_052404190596)
    
-   [Google Analytics 4 Supported by SuiteCommerce Websites](#subsect_11124441308)
    
-   [Missing Translations Added to SuiteCommerce Application Areas](#subsect_16124845985)
    
-   [Configuration Properties Updates](#subsect_165338293599)
    
-   [Node.js Requirement](#subsect_165338295419)
    
-   [Third-Party Library Updates](#subsect_165338297350)
    
-   [SuiteCommerce Extension Management Issue Fixes](#subsect_64122146409)
    
-   [Issue Fixes](#subsect_165338299677)
    

These enhancements typically apply to SuiteCommerce, SuiteCommerce MyAccount, and SuiteCommerce Advanced; however, some features could apply to a subset of each. The following enhancements explain the implementations to which they apply.

## 3D Secure 2.0 Available in the Make a Payment Flow {#subsect_052404190596}

**Applies to:** SuiteCommerce, SuiteCommerce MyAccount, and SuiteCommerce Advanced

With the 2022.2 release, 3D Secure 2.0 functionality is available in the Make a Payment and Quote Purchase flows.

See [3D Secure Payment Authentication for Commerce Web Stores](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1503444797.html) for more information about 3D Secure.

## Google Analytics 4 Supported by SuiteCommerce Websites {#subsect_11124441308}

**Applies to:** SuiteCommerce, SuiteCommerce MyAccount, and SuiteCommerce Advanced

Introduced a new configuration setting to support Google Analytics 4 (GA4) on SuiteCommerce websites. Google will no longer support Universal Analytics and the feature will be replaced with GA4.

See [Google Analytics 4](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0104849037.html) for more information about GA4.

## Missing Translations Added to SuiteCommerce Application Areas {#subsect_16124845985}

**Applies to:** SuiteCommerce, SuiteCommerce MyAccount, and SuiteCommerce Advanced

As a step toward improving Oracle's translatability compliance, missing translations have been added to the following application areas:

-   Shopping > Item > Product Detail Page: "No Reviews yet"
    
-   Shopping > Item > Add item to cart > Confirmation modal: "Quantity"
    
-   Submitting a Product Review: "Back to xxxxxxx" (xxxxxx being the product name)
    
-   Billing > Invoices > Make a Payment: "SELECT INVOICES TO PAY" and the Wizard breadcrumb (1. SELECT INVOICES TO PAY / 2. PAYMENT AND REVIEW)
    
-   Billing > Account Balance: "Deposits:", "Other Credits:", "Term:" and "Currency:"
    

See [Manage Translations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_158572305264.html) for more information about the NetSuite translation process.

## Node.js Requirement {#subsect_165338295419}

**Applies to:** SuiteCommerce, SuiteCommerce MyAccount, and SuiteCommerce Advanced

With the 2022.2.0 release, the developer tools continue to support Node.js version **12.21.0**. To use the Theme, Extension, or core SCA 2022.2 developer tools, you must use this Node.js version.

For more information, see [Install Node.js](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4183926623.html).

## Third-Party Library Updates {#subsect_165338297350}

**Applies to:** SuiteCommerce, SuiteCommerce MyAccount, and SuiteCommerce Advanced

With the 2022.2.0 release, the following third-party library has been added:

-   dotenv 16.0.1
    

No other library updates have been made for this release.

## SuiteCommerce Extension Management Issue Fixes {#subsect_64122146409}

**Applies to:** SuiteCommerce, SuiteCommerce MyAccount, and SuiteCommerce Advanced

With the 2022.2.0 release, the following fixes were made:

-   Fixed an issue with that caused an error downloading extension files when using the gulp commands `gulp extension:fetch` or `gulp extension:deploy`.
    
-   Fixed an issue with the SuiteCommerce Extension Management and SuiteCommerce Advanced developer tools that caused some users to receive a CORS-related message after running their local setup on Chrome or Edge browsers.
    

## Issue Fixes {#subsect_165338299677}

**Applies to:** SuiteCommerce, SuiteCommerce MyAccount, and SuiteCommerce Advanced
