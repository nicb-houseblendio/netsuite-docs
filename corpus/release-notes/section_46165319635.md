## 2023.1.2 Minor Release of SuiteCommerce, SuiteCommerce MyAccount, and SuiteCommerce Advanced {#subsect_93113634625}

### Enhancements {#subsect_16113721293}

-   The following Google Analytics 4 (GA4) tracking events have been integrated with the Google Tag Manager Commerce extension:
    
    -   **Add Payment Information** - This event signifies a user has submitted payment information.
        
    -   **Add Shipping Information** - This event signifies a user has submitted their shipping information.
        
    -   **Refund** - This event signifies a refund was issued.
        
    -   **Remove from Cart** - This event signifies that an item was removed from a cart.
        
    -   **Search** - Use this event to contextualize search operations. The search event helps you identify your application's most popular content.
        
    -   **Share** - This event signifies a user has shared content.
        
    
    See the following help topics for more information about GA4 events:
    
    -   [Google Analytics 4 (with Google Tag Manager Commerce Extension)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_164686123841.html#subsect_164686146557)
        
    -   [Supported Google Tag Manager Services](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1535724805.html)
        
    -   [Tracked Events](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1531508071.html)
        
-   Added a new configuration property, **Add Headers to SSP Responses**, to provide a field in which to enter your security headers. This new property appears in the **Advanced** tab under the **Security** subtab.
    
    See the following help topics for more information about security headers:
    
    -   [HTTPS Header Information](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4418229131.html#subsect_1558529145)
        
    -   [Security Subtab](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159051175325.html)
        
-   Updated text and translation context notes to comply with Oracle translatability requirements.
    

## 2023.1.1 Minor Release of SuiteCommerce, SuiteCommerce MyAccount, and SuiteCommerce Advanced {#subsect_96170858280}

### Enhancements {#subsect_48184450436}

-   The Underscore.js library has been updated to version 1.13.1.
    
-   The Handlebars library has been updated to version 4.7.7.
    
-   The VM2 (oraclesuitecloud-cli) library has been updated to version 1.7.2.
    

### Fixes {#subsect_10170905346}

-   Fixed an issue in the raw request of the Cardholder Authentication event that caused the security code to be null instead of displaying the tokenized value of the CSC entered on the payment page.
    
-   Fixed an issue that prevented customers from enabling the 3DS2 feature for Make A Payment, Quotes, and Reorder flows.
    
-   Fixed an issue that caused the CUR parameter under Shopping to be null instead of being set to ShoppingUserEnvironment.Service.ss.
    
-   Fixed an issue that caused invoices to display $0.00 under Payment Summary.
    
-   Fixed an issue that prevented shoppers from viewing the Transaction History section by updating ActivationContext and SuiteScript2 services.
