## 2019.2.5 Release of SuiteCommerce Advanced {#section_159054933496}

The following apply to SuiteCommerce Advanced implementations only.

## Fixes {#bridgehead_160495155535}

-   Issue causing customers who try to place an order from a Quote Detail page to be redirected to the Thank You page instead of the External Payment page.
    
-   Issue where enabling the Payment Instruments feature for your company causes blank pages to be displayed for users who try to access the My Account and Checkout pages.
    
-   Issue preventing cash sales made via SuiteCommerce InStore from displaying in Purchase History for My Account.
    
-   Issue preventing the `cartView` event being triggered on the Cart page in the Google Tag Manager data layer when using the Criteo service.
    

## 2019.2.4 Release of SuiteCommerce and SuiteCommerce Advanced {#section_158274051259}

## Fixes {#bridgehead_160495156865}

-   Password reset issue. The Reset Password link (sent through a customer's email) briefly sends users to the Reset Password page, but immediately redirects users to a Log In page, preventing them from resetting their password.
    
-   Issue when ordering an item whose order quantity exceeds the quantity available for the item. Users in this situation received the following error: **An Error Has Occurred** instead of a message explaining how to correct their order.
    
-   Issue preventing users from returning specific items from the entire Sales Order. Instead, users receive the following error: **Error: The minimum quantity for this item is x**. This issue occurred on items with a minimum quantity set in the Item record in NetSuite.
    
-   Issue preventing users from editing multiple item options in the product details page, resulting in the following message: **Sorry, there is a problem with this Item and can not be purchased at this time. Please check back later**.
    

## 2019.2.3.a Release of SuiteCommerce and SuiteCommerce Advanced {#section_158022926424}

## Fixes {#bridgehead_160495158556}

-   SEO issue where canonical URL, meta description, meta keywords, and title tags are missing for a site.
    
-   Issue preventing site search/links from working properly. This issue resulted in customers needing to click on result/link multiple times to select the item.
    
-   Issue preventing Google Analytics tags from appearing when the SC Google Tag Manager extension is activated on a domain. This issue occurred the first time a customer accessed the site only.
    
-   Issue preventing customers from selecting a shipping address during Checkout. This issue appeared for customers with a default shipping address saved.
    
-   This release also rolls back one issue to its previous state prior to the 2019.2.3 release: **Issue creating duplicate customer/lead shipping addresses**, as described in [2019.2.3 Release of SuiteCommerce and SuiteCommerce Advanced](#section_157841586024).
    

## 2019.2.3 Release of SuiteCommerce and SuiteCommerce Advanced {#section_157841586024}

## Improvements {#bridgehead_160495160253}

-   Updated the SuiteCommerce bundle installation script to deploy the SuiteCommerce SS2 SSP application to the same domains or sites as the SuiteCommerce SSP application. This is expected behavior and was not functioning properly in the 2019.2.2 release of SuiteCommerce. See [Install Your Commerce Website Applications](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2675216.html) for more details on SS2 SSP applications.
    
-   Application Performance Management (APM) data collection is now enabled for SuiteCommerce and SuiteCommerce Advanced, regardless of whether the **SuiteCommerce Real User Monitoring** feature is enabled or disabled (Enable Features record).
    

## Fixes {#bridgehead_160495161882}

-   Issue preventing updated Item Options on matrix items in a wishlist from updating in the Cart.
    
-   Console error on gulp local command using the core SCA developer tools: **jQuery.Deferred exception: generator.childViewInstance.getContextDataRequest is not a function TypeError**
    
-   Issue creating duplicate customer/lead shipping addresses. This duplication occurs on the website and in the Customer record when a new user registers on a site configured for One Page Checkout and the user sets the Billing Address Same as Shipping Address.
    
-   Issue when deploying SuiteCommerce or SuiteCommerce Advanced causing all files in the file cabinet to be incorrectly marked as "available without login".
    
-   Issue preventing the Shipping Estimator from displaying the correct shipping rate during Checkout.
    
-   Issue preventing SEO generator errors from logging. This caused a **ReferenceError: Can't find variable: Map** error.
    

## 2019.2.2 Release of SuiteCommerce and SuiteCommerce Advanced {#section_157590589996}

## Improvements {#bridgehead_160495163752}

-   Removed a redundant Development folder from the SuiteCommerce Advanced 2019.1 bundle.
    

## Fixes {#bridgehead_160495166258}

-   The See More link was removed from the Product Details Page (PDP) in this release of the SuiteCommerce Base Theme. If you have SCA 2019.2 implemented, you will need to remove the link from any other theme developed on top of this Base Theme release.
    
-   Checkout issue preventing shoppers from checking out as guest using Firefox in Private Window mode.
    
-   Issue preventing shoppers from using the browser to navigate back to the home page after performing a keyword search from the site's Home page.
    
-   Issue preventing Analytics Blockers from working with Google Universal Analytics.
    
-   Web store item display issue, resulting in items not displaying after logging in to Site Management Tools.
    
-   Commerce Category issue resulting in category title being replaced by bread crumb information.
    
-   Custom Transaction Item Option issue erroneously displaying a non-functioning **Add to Cart** button in Product List Pages.
    
-   Auto-apply SuitePromotion issue when requesting a quote resulting in the following error: `An nlobjSearchFilter contains an invalid operator, or is not in proper syntax: internalid`.
    
-   Category collapse/expand issue. Clicking the Category collapse/expand caret symbol influences the facet list behavior.
    
-   Shipping Address issue resulting in a disabled delivery method after editing the shipping address during checkout review.
    
-   Google AdWords parameter issue where the `&gclid=[Unique Code]` parameter was removed from the URL. (SuiteCommerce Advanced Only Issue)
    
-   Issue involving SCA 2019.1 Development SSP folder moving outside of the expected location upon bundle installation, resulting in Web Store Page Not Found message. (SuiteCommerce Advanced Only Issue)
    
-   Invoice details issue resulting in the following internal error: `An nlobjSearchColumn contains an invalid column, or is not in proper syntax: ccexpdate`. (SuiteCommerce Advanced Only Issue)

## Fixes {#bridgehead_160495169588}

-   Translation issues on My Account and Checkout pages
    
-   Home page URL parameters stripping issue
    
-   Incorrect shipping cost issue on Sales Orders
    
-   Purchase History date picker translation issue
    
-   Token payment method display issue during checkout
    
-   Return Authorization issue allowing the return of items that are greater than the fulfilled quantity
