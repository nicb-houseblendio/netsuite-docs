Welcome to the 2019.1 release of SuiteCommerce and SuiteCommerce Advanced!

Important:

If implementing SuiteCommerce Advanced (SCA), you **must** install the 2019.1 release of SCA in a **NetSuite 2019.1** account. Many of the features and enhancements in this release have dependencies on NetSuite 2019.1.

Note:

If implementing SCA, take advantage of new features in existing SCA implementations by migrating the new code to your existing code base. For details, see [Migrate SuiteCommerce Advanced](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1559073362.html).
