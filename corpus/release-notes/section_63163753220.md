Welcome to the 2026.1 release of SuiteCommerce, SuiteCommerce MyAccount (SCMA), and SuiteCommerce Advanced (SCA). This release includes updates that improve security, clarify configuration, and support ongoing platform maintenance. Some changes apply automatically, but others may require action from your administrator or developer.

Important:

Some features in this release depend on NetSuite 2026.1. To use these updates, your account must be on NetSuite 2026.1.

This release includes both the main 2026.1 update and later minor updates. How you use these release notes depends on your web store type and how your site is maintained.

-   **SuiteCommerce** and **SuiteCommerce MyAccount** - If you use SuiteCommerce or SCMA, these updates are applied automatically during the scheduled release. Use these notes to understand what's changing and whether any follow-up action is needed.
    
-   **SuiteCommerce Advanced** - If you use SCA, these changes don't apply automatically. You must manually migrate your site to the latest SCA release. Use these release notes to decide whether an upgrade is needed for your implementation. This update doesn't change the existing bundle ID. If you decide to upgrade, see [Migrate SuiteCommerce Advanced](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1559073362.html) for instructions.
    
    Note:
    
    For more information about release updates and patch timing, see [Commerce Patches and Upgrades](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4043708822.html).
