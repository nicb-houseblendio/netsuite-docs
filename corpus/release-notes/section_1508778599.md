Following are the 2026.2 administration enhancements to SuiteApps:

## Compliance 360 Enhancements {#subsect_55192943630}

Compliance 360 SuiteApp version 3.0.0 includes the following enhancements:

-   [New Compliance Audit Supporter Role for Audit Control Work](#subsect_0526065057)
    
-   [Audit Control Line Item Attachments](#subsect_0526100945)
    
-   [Total Audit Trend Portlet on the Dashboard](#subsect_74185133388)
    
-   [New Filters in the Audit List](#subsect_72185139445)
    

### New Compliance Audit Supporter Role for Audit Control Work {#subsect_0526065057}

The SuiteApp now includes the Compliance Audit Supporter role for users who help complete audits but do not need the broader access granted to a Compliance Officer role. If you have the Administrator role, you can assign this role to users who help complete audits but do not need access to the dashboard or activity logs.

Compliance Audit Supporters can help complete audits by marking assigned audit controls as passed or failed.

Users with the Compliance Audit Supporter role can be assigned audit control line items. When assigned, they receive an email notification with audit details, the audit control ID, and a link to the audit. For details about assigning audit control line items, see [Adding Audit Controls Manually](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_0128043009.html).

### Audit Control Line Item Attachments {#subsect_0526100945}

You can now upload, edit, and view attachments for individual audit control line items. These attachments help you keep supporting documents or evidence with the related audit control line item.

You can attach multiple files to an audit control line item. Supported file types are PDF, DOC, DOCX, XLS, XLSX, JPG, PNG, TXT, and ZIP. The total file size must not exceed 10 MB. For more information, see [Audit Control Attachments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0512040247.html).

### Total Audit Trend Portlet on the Dashboard {#subsect_74185133388}

The Total Audit Trend portlet is now available on the dashboard. It displays a bar graph showing the audit count for each month over the last 12 months. You can click a month or a bar in the graph to view the audit count and audit status for that month.

For more information, see [Total Audit Trend](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0925033610.html#subsect_0512061248).

### New Filters in the Audit List {#subsect_72185139445}

The Audit list now includes filters for audit type, audit supporter, subsidiary, department, class, and location. You can use these filters to narrow the Audit list and find specific audits.

For more information about viewing and filtering audits, see [Applying Filters to the Audits List](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_0517123459.html).
