SuiteCommerce InStore (SCIS) uses a phased release process to distribute managed-bundle upgrades. Each phase consists of a different group of customers that receive the latest SCIS release. Administrators set up for customers within a phased group receive an email notification listing when their upgrade will occur.

Note:

Contact your account representative or Customer Support if you have questions about the availability of SCIS 2026.2.

## Release Summary {#subsect_11163630382}

SCIS 2026.2 provides improvements and fixes for processing that occurs in the background. The release has no new features or functional changes that are visible at the point-of-sale (POS).
