In NetSuite, you can delete an unlimited number of support case records. If you're using other role than Administrator, you can only delete cases you're the organizer or owner of.

#### To perform the mass delete update: {#procedure_3739683151}

1.  Go to _Lists > Mass Update > Mass Updates_.
    
2.  Click **Customer Support and Service**, and then click **Delete Cases**.
    
3.  On the **Criteria** subtab, define which cases you want to delete.
    
4.  Click **Preview**.
    
5.  In the Delete Cases Preview Results list, clear the box in the **Apply** column for each case you don't want to delete.
    
6.  Click **Perform Delete**, or **Return To Criteria** if you want different search results.
    

Note:

If you want to keep data from duplicate cases, consider merging them with the original case record. See [Merging Cases](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3739683565.html).
