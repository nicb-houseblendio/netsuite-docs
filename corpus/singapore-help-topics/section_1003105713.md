The Singapore PEPPOL-Ready e-Invoicing SuiteApp supports PEPPOL e-document exchange and Goods and Services Tax (GST) InvoiceNow processing in Singapore

The SuiteApp provides the following capabilities

-   Exchanges e-documents with customers and vendors through the DataPost PEPPOL access point in Singapore.
    
-   Generates outbound e-documents from invoices and credit memos and sends them to the Singapore PEPPOL API.
    
-   Sends invoices and credit memos to Singapore government agencies for business-to-government (B2G) transactions.
    
-   Receives inbound e-documents from the Singapore PEPPOL API and converts them into sales orders, vendor bills, or vendor credits in NetSuite.
    
-   Sends and receives transaction responses.
    
-   Helps you meet GST InvoiceNow requirements by connecting to the InvoiceNow network and the Inland Revenue Authority of Singapore (IRAS) system.
    
-   Uses the PEPPOL GST InvoiceNow framework, with IRAS as an endpoint in the transaction flow.
    
-   Supports secure communication with IRAS and GST-related e-document processing.
    

Before you install the Singapore PEPPOL-Ready e-Invoicing SuiteApp, you'll need to install the NetSuite SuiteApps License Client, Electronic Invoicing SuiteApp, and Localization Assistant SuiteApp first. The Electronic Invoicing SuiteApp is the main component for processing and exchanging electronic documents. For more information, see [NetSuite SuiteApps License Client](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4635371374.html), [Electronic Invoicing Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4536869579.html), and [Localization Assistant SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_163092114640.html).

The Singapore PEPPOL-Ready e-Invoicing SuiteApp includes preformatted e-document templates for both outbound and inbound documents, a pre-configured sending method plug-in, plus other configuration records and scripts. For more information, see [Understanding E-Document Components and Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1004125910.html).

Note:

Before using the SuiteApp, consider the following:

-   This SuiteApp is only for companies in Singapore-you can't use it in other countries.
    

PEPPOL or the Pan-European Public Procurement OnLine, is a platform connecting businesses and agencies to exchange business documents through a secure network ([https://peppol.eu/](https://peppol.eu/)). In Singapore, the SuiteApp uses the PEPPOL standards specified at [https://www.peppolguide.sg/](https://www.peppolguide.sg/).

## PEPPOL Standard Processes {#subsect_0110123319}

The PEPPOL standard is a template for e-invoices and credit notes on the PEPPOL network. It gives you the specifications you need to set up PEPPOL business processes.

The SuiteApp supports the following PEPPOL standards to handle e-invoice transactions:

-   **Business Interoperability Specifications (BIS) Billing 3.0 specification standard**
    
-   **PEPPOL International (PINT) standard**
    
    **PEPPOL International Singapore (PINT-SG) standard**\- This template standard is used to manage transactions within Singapore entities.
    

## PEPPOL International (PINT) {#subsect_0115011804}

The PEPPOL International (PINT) standard helps you manage and simplify international e-invoicing. Following are the key benefits of PINT standards:

-   This standard lets businesses exchange invoices internationally through the Singapore PEPPOL network.
    
-   It also makes cross-border invoice exchange easier, with customizations for different regions.
    

Note:

Transactions with Singapore government agencies (B2G) aren't supported with the PINT SG standard.
