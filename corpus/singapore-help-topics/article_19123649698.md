## Issues When Submitting the GST F5 Return and GST F8 Return {#bridgehead_75174237533}

The following table lists issues you may encounter when you submit the GST F5 Return and GST F8 Return.

| Error Message or Scenario | Suggested Action | Related Help Topic |
| --- | --- | --- |
| The **Submit** button is not showing in the GST F5 Return header. | Verify if the report you are trying to submit is valid. The **Submit** button becomes unavailable if:
-   The role you use does not have the Tax Filing permission.
-   The base currency of the account you use to generate the report is not in SGD.
-   The status of the GST F5 Return or GST F8 Return you are currently viewing is **Submitted**.

 | [Roles and Permissions in Tax Reporting Framework](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1528249899.html) [Submitting Singapore GST F5 and F8 Returns](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_19121237394.html) |
| The submission status is not updating, or the status is showing as **Submission Results Pending**. | The GST F5 Return or GST F8 Return has been submitted to IRAS, but the status from IRAS is still pending. You will receive a notification when the submission process is completed. | [Submitting Singapore GST F5 and F8 Returns](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_19121237394.html) |
| The status shows as **Authorization Failed**. | The GST F5 Return or GST F8 Return was not submitted because the request for permission for NetSuite to interact with IRAS was not granted. To submit the report:

-   Click **View** to reopen the GST F5 Return or GST F8 Return, complete the required actions, and click **Submit**.
-   After you log in to the IRAS website, on the Request for permission page, you must authorize NetSuite to interact with IRAS.

 | [Submitting Singapore GST F5 and F8 Returns](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_19121237394.html) |
| The status shows as **Authorization Required**. | The GST F5 Return or GST F8 Return was not submitted because the Singpass ID and password entered do not have the permission to interact with IRAS. Contact your system administrator to verify your Singpass credentials. | [Submitting Singapore GST F5 and F8 Returns](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_19121237394.html) |
| The status shows as **Submission Failed**. | The GST F5 Return or GST F8 Return was submitted to IRAS, but the validation failed. If the submission of your GST F5 Return or GST F8 Return fails, a Submission Failed email with an error report is sent to your email address. An error message with a download link to the Error.txt file that lists the corresponding NetSuite fields is also displayed. To complete the submission, you must:

-   Review and resolve the error listed in the Error.txt file.
-   Generate a new GST F5 Return or GST F8 Return.
-   Click **View** to open the new GST FT Return or GST F8 Return, complete the required actions, and click **Submit**.

 | [GST F5 Return and GST F8 Return API Error Messages](#bridgehead_16175936066) [Submitting Singapore GST F5 and F8 Returns](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_19121237394.html) |
