A response is a business level transaction where an e-document recipient responds with the acknowledgment of a receipt or a confirmation that the e-document is received. You need transaction response support in a PEPPOL environment to automate responses from suppliers and customers for sent and received transactions.

To send the transaction responses, you must first setup the Transaction Response feature.

#### To setup transaction response:

Note:

Currently, the Transaction Response feature works only with the DataPost access point.

1.  Go to Setup > E-Documents > Electronic Invoicing Preferences.
    
2.  On the Electronic Invoicing Preferences page, click on the required Subsidiary.
    
3.  Click **Edit** on the Subsidiary page, and check the **Transaction Response Support** box.
    
4.  From the **Transaction Response Sending Method** list, select the **Singapore PEPPOL DataPost Sending Method**.
    
    The sending method is used to send responses for the applicable transactions.
    
5.  Click **Save**.
    

The e-documents transaction response uses a custom record to send and receive transaction response acknowledgments. A Transaction Response custom record has the following fields:

-   Response Issue Date - Shows the transaction response issue date
    
-   Direction - Shows if the response is inbound or outbound direction
    
-   Response Status - Shows the status of the response. The following are the available statuses:
    
    -   Acknowledged
        
    -   Accepted
        
-   Transaction ID - Shows the transaction Ids for sent or received responses
    
-   Response Body - This is a message field displaying the body of the incoming or outgoing message
    
-   Inbound E-Document - This field indicates the reference of the inbound e-document to which the response belongs.
    
-   Response Sent Status - This field indicates the status if the transaction response is sent or not sent to the recipient.
    
-   Response Sent Date - This field indicates the date when the transaction is sent to the Singapore PEPPOL network.
