Consider the following scope, limitations, and best practices for using Singapore PEPPOL-Ready e-Invoicing SuiteApp.

## Scope {#subsect_29235432950}

The scope of the SuiteApp is:

-   You can only use the Singapore PEPPOL-Ready e-Invoicing SuiteApp for exchanging e-documents with PEPPOL Singapore.
    
-   You can use the SuiteApp for companies in Singapore only.
    

## Limitations {#subsect_66235712932}

The limitations of the SuiteApp are:

-   Inbound e-document processing is not supported for credit memos.
    
-   A line item cannot have more than one discount and more than one markup; otherwise, you'll get an error.
    
-   The following Item types are not supported:
    
    -   Description
        
    -   Subtotal
        
    -   Payment
        
    -   Group
        
    -   Gift Certificate
        
-   You can't use tax groups in invoices or credit memos.
    
-   For inbound e-document processing, header discounts aren't supported because NetSuite doesn't show discounts in the vendor bill amount.
    

## Best Practices {#subsect_88001928034}

Best practices for using the SuiteApp are:

-   The first item on a transaction must not be a discount or markup.
    
-   The tax code of discount or markup items should match the tax code of the parent item.
    
-   A header discount must have a negative value.
    
-   For inventory items in inbound e-documents, make sure you select a Location on the Item record.
    
-   If you want the vendors bills created from inbound e-documents, to have consistent values for the required fields across all vendors, you can edit the inbound e-document template and in the field mapping, add the required fields and set default values for them. For more information, see [Understanding Inbound E-Document Templates in JSON Format](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1116122306.html).
    
-   After receiving the email containing the API key from the Singapore PEPPOL, you should copy the credentials and paste them directly into their corresponding fields on the SG PEPPOL E-Invoicing Configuration record.
    

## Other Considerations {#subsect_43002431968}

A positive line level item discount is treated as an additional item charge; and a negative item charge will be treated as line level item discount.
