Before using the Singapore PEPPOL-Ready e-Invoicing SuiteApp, you must complete the following:

-   After installing the SuiteApp, enter the PEPPOL ID and API key on the custom record, SG PEPPOL E-Invoicing Configuration. For more information, see [Creating a Singapore PEPPOL E-Invoicing Configuration Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1003114217.html).
    
-   Contact the customers and vendors your company is going to exchange e-documents with, and ask for their PEPPOL ID. After you receive it, enter the Id in the **PEPPOL ID** field available in the E-Document subtab for customer and vendor record.
    
-   Make sure the item SKU names in NetSuite match the SKU names from the other parties that you will exchange e-documents with.
    
-   You'll need to enter the right Singapore tax code in the **SG PEPPOL Tax Code** field. For more information, see [Entering Singapore Tax Code](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1004052001.html) and [Singapore Tax Codes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1983994.html).
    
-   Set the **E-Document Country for Free Use** field to **Singapore**. For more information, see [Defining the E-Document Country for Free Use](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4613215788.html).
    
-   For the inbound e-document process, before you import them, you must ensure the following:
    
    -   For a single vendor, the item name in the inbound e-document must match the value in the **Vendor Code/Name** field on the Item record.
        
    -   If you've enabled Multivendor feature, the same item name must match the value in the **Vendor** column on the **Vendors** subtab.
        
        For more information, see [Importing Inbound E-Documents and Converting them to Transactions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1004031654.html).
