You can send electronic invoices to Singapore government agencies using InvoiceNow network to the Accountant-general's Department's (AGD) access point.

#### To submit e-invoices to Singapore government agencies:

1.  In the E-Document subtab on a customer record, select any one of the following option from the **SG PEPPOL B2G End Point** list.
    
    -   **Production**
        
    -   **Test**
        
    
    Note:
    
    The customer PEPPOL ID is automatically generated. The following endpoint Ids are used for sending invoices to the AGD:
    
    -   Test invoices - **0195:SGTSTT08GA0028A**
        
    -   Production invoices - **0195:SGUENT08GA0028A**
        
    
2.  Select a value from the **SG PEPPOL BUYER REFERENCE** list.
    
    The **SG PEPPOL BUYER REFERENCE** value is retrieved from the customer record and is added to the invoice and credit memo records.
