If the customer or vendor PEPPOL ID in the imported inbound e-document does not match an entity record in NetSuite, the inbound e-document is created without an entity. The inbound e-document is marked as **Incomplete**. You can find it on the Electronic Invoicing dashboard with an **Incomplete** status. The e-document contains information about the inbound sales order, vendor bill, or vendor credit transaction.

-   XML document sent by Singapore PEPPOL
    
-   Inbound e-document template
    
-   Reference and other records
    

#### To handle inbound e-documents without matching entities: {#procedure_1004032858}

1.  Go to the Electronic Invoicing portlet on your dashboard.
    
2.  Click **Incomplete Inbound E-Documents**.
    
3.  Open an inbound e-document that has an Incomplete status.
    
4.  Make sure the entity PEPPOL ID is entered correctly on the corresponding entity record. Make the appropriate changes if necessary, and then save the entity record.
    
5.  Edit the inbound e-document record with Incomplete status and select the entity from the **Entities** list.
    
6.  Click **Save**.
    
    The corresponding inbound e-document status changes to For Conversion, and you can manually convert the record to the right transaction type.
    
7.  On the Inbound E-document record, click **Convert**.
    
    For more information, see [Converting Individual Inbound E-Documents into Vendor Bills](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1495534686.html) and [Converting Failed Inbound E-Documents](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1495540642.html).
    
    If no errors are encountered, the transaction record will be created.
    
8.  Repeat steps 3-6 for other incomplete inbound e-documents.
