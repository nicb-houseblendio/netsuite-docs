You need to register and enroll your company with the Singapore PEPPOL through an access point provider. NetSuite supports DataPost Pte Ltd as an access point.

## DataPost Access Point {#subsect_44145844965}

Register your company with DataPost access point at [https://peppol.datapost.com.sg/app/peppol/main/register](https://peppol.datapost.com.sg/app/peppol/main/register). In registering, complete a form, and list any subsidiaries involved in e-invoicing. If you have other companies or businesses involved in e-invoicing, you must register each separately. After successfully registering and enrolling to Singapore PEPPOL, you will receive through email a PEPPOL API key and API secret.

After you've registered and enrolled, install the SuiteApp and enter your PEPPOL ID and credentials in the SG PEPPOL E-Invoicing Configuration record. For DataPost, you'll need the PEPPOL ID, API key, and the API secret. For more information, see [Installing Singapore PEPPOL-Ready e-Invoicing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1003112634.html) and [Creating a Singapore PEPPOL E-Invoicing Configuration Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1003114217.html).

After installing the SuiteApp, you can also register and enroll your other businesses or companies right from the SuiteApp. To do this, go to Setup > Singapore Localization > DataPost Access Point Registration.
