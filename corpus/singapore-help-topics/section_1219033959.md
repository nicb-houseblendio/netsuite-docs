Before installing Singapore Localization, you must enable additional features and install required SuiteApps.

## Required Features {#bridgehead_19155243348}

Enable the required features for Singapore Localization.

#### To enable features {#procedure_0106094433}

1.  Go to Setup > Company > Setup Tasks > Enable Features.
    
2.  Click the **SuiteCloud** subtab and check the box for each of the following features:
    
    1.  Item Option
        
    2.  Custom Records
        
    3.  Advanced PDF/HTML Templates
        
    4.  Client SuiteScript
        
    5.  Server SuiteScript
        
    6.  SOAP Web Services
        
    7.  SuiteCloud Development Framework
        
3.  Click **Save**.
    

For more information, see [Enabling Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N232138.html).

## Required SuiteApps {#bridgehead_64164447728}

After you enable the required features, install the following SuiteApps:

-   SuiteTax Engine
    
-   Tax Reporting Framework
    

For more information about these SuiteApps, see [SuiteTax Engine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1557396965.html), and [Tax Reporting Framework](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1528262949.html).

For more information about installing SuiteApps, see [Installing from the SuiteApp Marketplace](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1539799323.html).

Note:

For accounts without OneWorld, when you add a Singapore nexus for the first time, you must run the tax record provisioning manually. For more information, see [Running Tax Record Provisioning Manually](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557735917.html#subsect_1559711289).

After you've completed the prerequisites, you can install the **Singapore Localization SuiteApp**. For information about how to install the **Singapore Localization SuiteApp**, see [Installing the Singapore Localization SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1219045538.html).
