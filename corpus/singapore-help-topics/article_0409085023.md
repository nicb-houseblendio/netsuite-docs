After you've imported inbound e-documents from the Singapore PEPPOL API, the SuiteApp creates an inbound e-document record for each XML file you receive.

A transaction response record is created under the E-Document subtab in the E-Document Transaction Response section. On the transaction response record, the **Response Sent Status** is set to **Not Sent** and the **Response Status** is set to **Acknowledged**.

On converting the approved inbound e-document to vendor bill, vendor credit or sales order records, the SuiteApp creates another transaction response record with the status **Accepted**.

## Sending a Transaction Response {#bridgehead_0409094042}

First, transaction response is created with the status set to **Not Sent**. The **Transaction Response Send MR** script is used to send the transaction responses. You can schedule the script based on your requirement. For more information about scheduling the MR script, see [Scheduling a Map/Reduce Script Submission](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1509578930.html). After the transaction response is sent, the **Response Sent Status** is set to **Sent** status on the transaction record.
