The Singapore Localization SuiteApp provides the tax report template to generate a GST F8 report. It also enables you to submit the report to the Inland Revenue Authority of Singapore (IRAS). After you install the Singapore Localization SuiteApp, you can generate the GST F8 Return report from the Country Tax Report page. To generate the GST F8 report, see [Generating a Singapore GST F8 Return](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0107043305.html).

The GST F8 Return report displays the following filters that the Tax Reporting Framework uses to get the values for each of the boxes on the report:

-   **Search Type**
    
-   **Transaction Types**
    
-   **Tax Codes**
    
-   **Tax Transaction Types**
    
-   **Tax Item Types**
    

The filters are automatically set up but can be modified. If you want to customize the report and configure the filters, see [Customizing Localized Tax Returns](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1528248236.html).
