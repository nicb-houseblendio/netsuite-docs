You can include more fields in sales order created from inbound e-documents. For example, you can add Class, Department, or Location fields. To do this, you can edit the inbound e-document template. Then, in the field mapping, add lines of code for the additional fields. For more information, see [Understanding Inbound E-Document Templates in JSON Format](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1116122306.html).
