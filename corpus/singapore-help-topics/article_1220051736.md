With Singapore Localization, you can generate a text version of the IRAS Audit File (IAF) for your accounts and subsidiaries with a Singapore nexus. IAF is generated from data entries in general ledgers or chart of accounts, core data of customers and suppliers, details of invoices, orders, payments, and adjustments.

#### To generate an IAF report: {#procedure_1220052021}

The file you download contains the report generated and an Error.txt file that shows details of errors found in the report. For more information, see [Troubleshooting the IAF Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0104020156.html#subsect_47155520196) and [Singapore IRAS Audit File](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0104020156.html).

1.  Go to Reports > Tax > Country Tax Reports.
    
2.  From the **Subsidiary** list, select your subsidiary.
    
3.  From the **Nexus** list, if you have multiple nexuses in your subsidiary, select your Singapore nexus.
    
4.  From the **Report Name** list, select **IRAS Audit File (TXT)**.
    
5.  Select the **Start Period** and **End Period** dates to include in the report.
    
6.  Click **Generate**.
    
7.  On the **Report Execution** subtab, locate the generated report. The latest generated report appears at the top of the list.
    
8.  In the **View | Download** column, wait for the loading bar to complete and change to a **Download** link.
    

Important things to note to ensure that your IAF report is compliant with IRAS requirements:

-   Complete the setup requirements for Singapore Localization before generating the report. For more information, see [Setting Up Singapore Localization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1219051338.html).
    
-   If the functional currency of transactions is not Singapore Dollar (SGD):
    
    -   Ensure that the system converts the value of supply and output tax to SGD.
        
    -   Ensure that the system converts the SGD value based on prevailing exchange rates.
        
-   Provide values for all the custom fields for Singapore:
    
    -   **Import Permit Number** - Enter the import permit number indicated in your cargo clearance permit. This field appears when a Singapore subsidiary is selected on purchase transaction forms and journals.
        
    -   **Document Date** - Use this field to select a date other than the transaction's posting date. This field appears when a Singapore subsidiary is selected on purchase transaction and sales forms. Note that the document date is used in generating the IRAS audit file.
        
-   Provide details in the transaction memo field for each transaction.
