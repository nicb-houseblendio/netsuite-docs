By default, the Administrator and the CFO roles can configure the SuiteApp, accounts, custom records, as well as enter PEPPOL ID and API key.

You can also create or customize other roles to give them access to the SuiteApp. For more information, see [Customizing and Creating Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N286284.html) and [Setting Permissions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N288727.html).
