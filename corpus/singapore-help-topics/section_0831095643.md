Important:

You must install the Singapore Localization SuiteApp before using the Singapore (SG) PEPPOL ID Bulk Update functionality.

The PEPPOL ID Bulk Update page shows entities with associated Unique Entity Numbers (UENs) but no PEPPOL IDs.

On this page, you can do the following:

-   View the list of entities that are not associated with PEPPOL IDs.
    
-   Select multiple entities to update PEPPOL IDs in bulk. As you load the page, all the entities are selected by default for bulk update.
    
-   Apply filters to view the relevant entities with their subsidiaries and update them.
    

When bulk processing is complete, you'll see the updated PEPPOL IDs on the customer and vendor records.

#### To assign PEPPOL IDs to entities in bulk:

1.  Go to Setup > Singapore Localization > SG PEPPOL ID Bulk Update.
    
2.  Check the box next to the entities for whom PEPPOL ID update is required. The number of selected entities appears next to the **Bulk Update** button in the **Entities Selected** field.
    
    (Optional) To filter entities based on customer, vendor, or a subsidiary:
    
    1.  In the **Entity Filter** dropdown list, select any of the following:
        
        -   **Customer** - To view customer records.
            
        -   **Vendor** - To view vendor records.
            
        -   **All** - To view complete list of entities.
            
    2.  In the **Subsidiary Filter** dropdown list, select any subsidiary associated with the customer or vendor. Select **All** to list all the subsidiaries.
        
3.  In the Bulk PEPPOL ID Update Confirmation pop-up window, confirm your submission by clicking **OK**.
    
4.  Click **Bulk Update**.
    

After processing the request, the customer and vendor records are updated with PEPPOL IDs. If the bulk update is partially successful, you'll see a banner message with the count of updated and failed entities.

Tip:

If all customers and vendors already have PEPPOL IDs, you'll see a notification message when you open the PEPPOL ID Bulk Update page.
