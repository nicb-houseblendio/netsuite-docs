The Singapore Localization SuiteApp allows accounts with the SuiteTax feature enabled to generate the following reports using the Country Tax Reports page:

-   [Singapore IRAS Audit File](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0104020156.html)
    
-   [Singapore GST F5 Return](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1220053809.html)
    
-   [Singapore GST F8 Return](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0107042831.html)
    

The SuiteApp also supports report generation for accounts with the Multi-Books Accounting feature enabled.

Important:

Before you generate Singapore reports for the first time, you must:

-   Use tax codes specific to Singapore. For more information about Singapore-specific tax codes, see [Singapore Localization Tax Codes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1220015842.html).
    
-   Set the default report preferences for each subsidiary with a Singapore nexus. For more information, see [Setting Up Country Tax Reporting Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_1557127083.html).
    

To generate a report, go to Reports > Tax > Country Tax Reports. For more information, see [Generating Localized Country Tax Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1528250223.html).
