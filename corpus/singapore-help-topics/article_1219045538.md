Note:

To run properly, this SuiteApp requires SuiteTax and the Tax Reporting Framework installed in your account. To avoid installation errors, make sure you've SuiteTax enabled, and the Tax Reporting Framework installed before installing this SuiteApp. For more information, see [Prerequisites for Installing the Singapore Localization SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1219033959.html).

## Installation {#subsect_50095346059}

Any role with access to the SuiteApp Marketplace in NetSuite can install the Singapore Localization SuiteApp. For more information about the SuiteApp Marketplace, see [SuiteApp Marketplace in NetSuite](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1539797981.html).

#### To install the Singapore Localization SuiteApp: {#procedure_0106095238}

1.  Go to SuiteApps.
    
    Note:
    
    The SuiteApps menu is not available for the following centers:
    
    -   Advanced Partner Center
        
    -   Employee Center
        
    -   Partner Center
        
    -   Vendor Center
        
    
2.  From the listed SuiteApps, search **Singapore Localization SuiteApp** in the **Search Apps** field.
    
3.  Click the Singapore Localization SuiteApp tile.
    
4.  On the top right area of the Singapore Localization SuiteApp details page, click **Install**.
    

For more information about installing a SuiteApp from the SuiteApp Marketplace, see [Installing from the SuiteApp Marketplace](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1539799323.html).

Alternatively, you can install Singapore Localization using the **Localization Assistant SuiteApp**. For more information, see [Managing the Localization SuiteApps](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163092473907.html).
