Before installing the Singapore PEPPOL-Ready e-Invoicing SuiteApp, you must complete the following:

-   Register with the Singapore PEPPOL access point, and enroll to get a registration or PEPPOL ID and credentials (API key, secret, and so on). For more information, see [Registering and Enrolling to PEPPOL Singapore](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1003111201.html).
    
-   Install the NetSuite SuiteApps License Client. For more information, see [NetSuite SuiteApps License Client](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4635371374.html).
    
-   Install the Electronic Invoicing SuiteApp. For more information, see [Installing and Setting Up Electronic Invoicing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4592549826.html).
    
    The Electronic Invoicing SuiteApp will be the main component for processing outbound and inbound e-documents.
    
-   Install the Localization Assistant SuiteApp. For more information, see [Installing the Localization Assistant SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163092361565.html).
