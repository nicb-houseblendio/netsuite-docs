A NetSuite Connector's user account access is determined by the selected permissions. As an administrator, you can manage each user's account access.

#### To manage a user's permissions:

1.  Log in to [app.farapp.com](https://app.farapp.com).
    
2.  On the top-right corner of the page, hover over your account name to show the dropdown list. Then, select **Account Settings**.
    
3.  Click the **Manage Users** tab and locate the user whose permissions you want to update in the **Account users** section.
    
4.  Check the permissions you want to grant the user. For more information, see [NetSuite Connector User Permissions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0121052844.html)
    
5.  Click **Save**.
