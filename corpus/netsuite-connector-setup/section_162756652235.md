Install the NetSuite Connector SuiteApp from the SuiteApps Marketplace. For more information, read [Installing from the SuiteApp Marketplace](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1539799323.html)

If you run into issues after installing, double-check that you finished all the installation steps. Incomplete installation steps can cause problems with invoice creation or order sync.

After installing, check that your SKU field is mapped for product sync. If not, set up the mapping.

You'll also need to create a custom field for each connector account to use as a storefront flag. See [NetSuite Connector Storefront Flag Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163015507111.html) for more information.

## Setting a Test Item to Sync in NetSuite {#bridgehead_162762824231}

Select a test item in NetSuite to test product sync.

For more information, read [NetSuite Connector Product Sync Tests](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163108717577.html).

Note:

Be aware that your marketplace or cart data might change during testing and could be incorrect. Choose an item where incorrect data sync won't cause major issues.

Review the following guidelines for price and quantity version of product sync:

-   The test item must exist in your marketplace or cart with a matching SKU in NetSuite. Price and quantity sync only work for existing items.
    
-   To verify data sync, ensure that the price and quantity data on the item in marketplace or cart is different from the data in the order.
    

Review the following guidelines for full product sync version of product sync:

-   Test with an item that exists in your marketplace or cart with a matching SKU in NetSuite
    
-   To verify data sync, ensure that the price and quantity data on the item in marketplace or cart is different from the data in the order.
    
-   Avoid using matrix items for your first tests.
    

#### To set a test item to sync to NetSuite:

1.  In the global search, enter the SKU of your test item.
    
2.  Click on the matching item search result to open the item record..
    
    Note the value in the **Item Name/Number** field. This is the default SKU of the item. You'll need this value for product sync testing. You can edit the SKU field if needed.
    
3.  Click **Edit**.
    
4.  Click the subtab with the name of your marketplace or cart that you are syncing (for example, Shopify).
    
    This subtab was created during SuiteApp installation.
    
5.  Under the **Required** subtab, from the **Flag** list, select **Add/Update Item**.
    
6.  Click **Save**.
    

Note:

For full product sync testing with matrix items, repeat these steps for the parent and all child items.
