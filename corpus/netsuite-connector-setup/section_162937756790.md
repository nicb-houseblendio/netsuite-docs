With the implementation of Two-Factor Authentication (2FA), you may find it difficult to share accounts with other users. To add a new user to your account, follow these steps.

Note:

You need to be logged in as the Primary user to add, edit, or delete users.

#### To add a user to a NetSuite Connector account:

Important:

When you add a new user to your NetSuite Connector account, the created user is an Administrator user by default. See [NetSuite Connector User Permissions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0121052844.html) to configure new user access.

1.  Log in to [app.farapp.com](https://app.farapp.com).
    
2.  On the top-right corner of the page, hover over your account name to show the dropdown list. Then, select **Account Settings**.
    
3.  Click the **Manage Users** tab.
    
4.  Click **Add New User**.
    
5.  Fill out the following fields:
    
    -   Username
        
    -   Email
        
    -   Full Name
        
    -   Password
        
    -   Verify Password
        
6.  Click **Save User**.
    
    The new user appears on the list.
