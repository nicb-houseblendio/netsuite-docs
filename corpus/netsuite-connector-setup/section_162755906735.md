1.  Enable the **Show Internal IDs** box in the Set Preferences page. For more information, read [Setting the Show Internal IDs Preference](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3420345.html).

## Configuring Taxes {#bridgehead_162756063418}

Configure taxes for the United States in NetSuite. For other countries, keep the default setup.

#### To configure taxes:

1.  Go to Setup > Accounting > Set Up Taxes.
    
2.  (Optional) If you have multiple countries set up, select the **United States** subtab.
    
3.  Check the following boxes:
    
    -   Enable Tax Lookup on Sales Transactions
        
    -   Customers Default to Taxable
        
        For more information, read [Tax Setting for Customers](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164744121972.html#subsect_164878969393).
        
        Ensure existing customers are set to taxable
        
    -   Respect Discount Item Tax Preference.
        
4.  Verify that **Charge Sales Tax on Store Orders** is set to **Always**.
    
    Note:
    
    Note that these settings don't mean tax will always be charged, they enable NetSuite Connector to assign sales tax when needed. These settings let NetSuite Connector assign sales tax when the marketplace or cart does.
    
5.  Click **Save**.
    
    Note:
    
    Consider the following when configuring your tax preferences:
    
    -   Ensure items that may be taxed are set to use a taxable tax schedule. For more information, read [Taxable Items](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164744121972.html#subsect_164878454367).
        
    -   If you use VAT in your marketplace or cart, read [Configuring VAT in NetSuite Connector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162971420334.html).
        
    

## Configuring Shipping Methods {#bridgehead_162756531936}

Set up shipping methods in NetSuite to match your storefront shipping methods Mapping shipping methods is important because without a shipping method on an order, NetSuite doesn't accept shipping cost.

Note:

NetSuite might include default shipping items that need more setup. Although they're listed, you can't use these shipping items until they're fully set up. YEdit and save shipping items before using them with order sync.

For more information, read [Configuring Shipping for NetSuite Connector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162944951251.html).

## Configuring Payment Methods {#bridgehead_162756696082}

Without a payment method, some NetSuite operations might be affected. For instance, sales orders without a payment method will always be invoiced, not treated as cash sales. Set up payment methods for use with order sync.

Note:

NetSuite might include default payment methods that need more setup. Although they're listed, you can't use these payment methods until they're fully set up. Edit and save payment methods before using them with order sync.

For more information, read [Specifying Payment Methods](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162564195954.html).

## Syncing Amazon FBA Orders {#bridgehead_162756699354}

For Amazon FBA order sync, set a fixed customer in NetSuite.

For more information, read [Managing Fulfillment by Amazon (FBA) Items in NetSuite Connector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162937968270.html).
