When you create a new user in NetSuite Connector, the created user has all the permissions checked. You need to clear the boxes for the permissions the user does not need, then check only the appropriate permissions.

| Permission Group | Permission Name | Description |
| --- | --- | --- |
| **Admin Permissions** | **Administrative Privileges** | When checked, the user gets access to all screens and all operations. |
| **General Permissions** | **Manage Data Syncs** | When checked, the user is able to access the **Manage Data Syncs** screen. The selected user can enable and disable connectors and data syncs. |
| **Credentials** | When checked, the user is able to access the **Credentials** screen. The user can view or update storefront-specific credential information. |
| **Notifications** | When checked, the user can manage storefront notifications. |
| **Order Permissions** | **Orders (Data Flows)** | When checked, the user can access the **Data flows > Orders** screen and storefront-specific screens under Data Flows. Can view, edit, delete, post, and perform other operations on orders and other related data. |
| **Orders (Settings/Mappings)** | When checked, the user can access screens relevant to order mappings and orders settings, **Mappings > Orders** and **Settings > Orders**. Storefront-specific screens under Mappings are also accessible. Can view, add, edit and delete mappings. Can modify settings related to orders. |
| **Fulfillment (Settings/Mappings)** | When checked, the user can access the **Mappings > Fulfillments** and **Settings > Fulfillment** screens. Can view, add, edit and delete mappings. Can modify settings related to fulfillments. |
| **Product Permissions** | **Products (Data Flows)** | When checked, the user can access the **Data Flows > Products** screen. Can view, edit, delete, post, and perform other operations on products and related data. |
| **Products (Settings/Mappings** | When checked, the user can access screens relevant to product mappings and product settings, **Mappings > Products** and **Settings > Products**. Can view, edit, delete, post, and perform other operations on products and related data. |
| **Other Permissions** | **Other Transactions (Data Flows)** | When checked, the user can access the **Data Flows > Other Transactions** screen. Can view, edit, delete, post, and perform other operations on the data |
| **Other Transactions (Settings/Mappings)** | When checked, the user can access the **Mappings > Other Transactions** and **Settings > Other Transactions** screens. Can view, add, edit and delete mappings, as well as modify settings. |
