Norway VAT Return report is available for accounts with and without SuiteTax. The scope of coverage of the Norway VAT Return for accounts with SuiteTax and without SuiteTax differs. See the following table for information about supported features.

## Accounting Features {#bridgehead_043012250910}

| Feature | Accounts with SuiteTax | Accounts without SuiteTax |
| --- | --- | --- |
| Multi-Book | ✗ | ✓ |
| Multi-Currency | ✗ | ✓ |
| Discounts | ✗ | ✓ |
| Deductible and Partially Non-Deductible Items | ✗ | ✓ |

## Transactions {#bridgehead_043012251210}

| Feature | Accounts with SuiteTax | Accounts without SuiteTax |
| --- | --- | --- |
| Journals | ✗ | ✓ |
| Cash Sales | ✓ | ✓ |
| Cash Refund | ✓ | ✓ |
| Customer Credit | ✓ | ✓ |
| Customer Invoice | ✓ | ✓ |
| Vendor Bill | ✓ | ✓ |
| Vendor Credit | ✓ | ✓ |
| Expense Report | ✓ | ✓ |

## Export, Validation, and Submission {#bridgehead_043012254310}
