To map accounts to the Norway Income Statement Category Using via CSV import, perform the following steps:

#### To map your accounts: {#procedure_159108663745}

1.  Create a saved search of the subsidiary's accounts which will be used in the standard account mapping step before CSV import
    
    -   Go to Lists > Search > Saved Searches > New.
        
    -   Click **Account**.
        
    -   On the **Criteria** subtab, set the filter for the subsidiary and select your Norway subsidiary.
        
    -   On the **Results** subtab, set the results to only include the Internal ID and Name columns.
        
    -   Click **Preview**.
        
    -   On the Results page, click the icon for **Export - CSV**.
        
    -   Save the CSV file with the account search results.
        
2.  Create a mapping template by coping and pasting data into an Excel spreadsheet from the table on this page: [Norway Income Statement 1.30 Mapping Template](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0701120730.html).
    
3.  Open the Norway Income Statement 1.30 Mapping Template and make sure that special characters are displayed correctly. If they're not displaying properly, perform the following steps to set the proper character encoding for the special characters:
    
    -   Open a new Excel file.
        
    -   Go to **Data**.
        
    -   Click **Get Data** > **From File** > **From Text/CSV**.
        
    -   Choose the income statement template that you've downloaded from the system.
        
    -   Under **File Origin**, select **65001: Unicode (UTF-8)**.
        
    -   Click **Load**.
        
    -   Save the file in CSV format.
        
4.  To perform the mapping in the template, follow these steps:
    
    -   Open the account search created from Step 1 and copy both the Internal IDs and Names of the account search to the template.
        
        ![Account search table with Internal ID and Name columns](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/CountrySpecificFeatures/Norway_mapping_10.PNG)
    -   Paste the copied Internal IDs and Names of the account search from the previous step to the standard account mapping template you opened. The columns should be pasted after the Mapping Key column.
        
        ![Mapping Template with Internal ID and Name columns added](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/CountrySpecificFeatures/Norway_mapping_24.PNG)
    -   To map your NetSuite accounts to your Norway income statement accounts, copy your account's internal ID and paste it on the Mapping Key column of the applicable Norway income statement account.
        
        ![MApping Template with MApping Key column filled in](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/CountrySpecificFeatures/Norway_mapping_25.PNG)
    -   Different accounts can also be mapped to the same standard account if appropriate. Insert a new row, copy paste the applicable standard account line in the new row to map another account to the same standard account.
        
        ![Mapping Template with copied row](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/CountrySpecificFeatures/Norway_mapping_26.PNG)
    -   When done with the mapping, delete the Internal ID and Name columns.
        
        ![Mapping Template with highlighted Internal ID and Name columns](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/CountrySpecificFeatures/Norway_mapping_27.PNG)
    -   Save the CSV file with the final values of Mapping Category, Mapping Value and Mapping Key columns.
        
        ![Final CSV file](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/CountrySpecificFeatures/Norway_mapping_28.PNG)
5.  Import the saved CSV file from previous step to NetSuite. Go to Setup > Import/Export > Import CSV Records. Select the following options for CSV import:
    
    -   Import Type = Custom Records
        
    -   Record Type = TAF Mapping
        
    -   Character Encoding = Unicode (UTF-8)
        
    -   CSV Column Delimiter = Comma
        
    
    Note:
    
    On the Import Options screen, choose the Add or Update radio button. Expand the Advanced Options link and check the **Run Server SuiteScript and Trigger Workflows** box.
    
    For more information about importing CSV files, see [Importing CSV Files with the Import Assistant](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N343158.html).
    
6.  Verify if the record submitted using CSV import is mapped correctly.
    
    -   Go to Setup > Tax Audit Files > Audit Files Field Mapping.
        
    -   Select **NO-SAFT: Income Statement 1.30** in the **Category** field.
        
    -   In the **Subsidiary** field, select your Norway subsidiary.
        
7.  In the **Account Type** field, select an account type. Verify the accounts under each account type.
