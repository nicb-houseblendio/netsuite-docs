Norway Tax Report SuiteApp enables you to generate the following reports:

-   Norway Standard Audit File for Tax (SAF-T) Financial
    
-   Norway VAT Return
    

Submitting Norway Standard Audit File for Tax (SAF-T) Financial report is mandatory upon request in connection with an audit. This applies to all companies with a turnover exceeding 5,000,000 Norwegian Krone (starting January 1, 2020).

Norway Tax Reports is compliant with version 1.30 of the Norwegian Tax Administration's (Skatteetaten) SAF-T Financial format.

Norway Standard Audit File for Tax (SAF-T) Financial is supported in accounts without SuiteTax only.

For more information, see [Norway Standard Audit File for Tax (SAF-T) Financial](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_43132133850.html) [Norway Standard Audit File for Tax (SAF-T) Financial](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_43132133850.html).

Important:

Retrospective reporting starting in 2018 isn't supported and not required by the Norwegian tax authority.

Submitting Norway VAT Return report is mandatory for periods starting January 1, 2022 for VAT submissions to all customers.

Norway VAT Return is supported both for accounts with and without SuiteTax.

For more information, see [Norway VAT Return](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164078694374.html).

## Known Limitations {#subsect_041811400410}

Norway Tax Reports can be installed in accounts with SuiteTax as well as without SuiteTax.

Norway Standard Audit File for Tax (SAF-T) report is supported in accounts without SuiteTax only.

Norway VAT report is supported in accounts with as well as without SuiteTax, with differences in supported features. For a list of supported features, see [Norway VAT Return Supported Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_042509220910.html).

Norway Tax Reports is supported in OneWorld accounts only. For more information, see [Introduction to NetSuite OneWorld](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N266468.html).

Neither Norway VAT Return reports nor Norway SAF-T reports support customization of the filters used through the Tax Return setup page feature.

Number formatting options other than '1,000,000.00' aren't currently supported in General Preferences.

Norway Tax Reports is supported in the following languages:

-   English
    
-   Norwegian
