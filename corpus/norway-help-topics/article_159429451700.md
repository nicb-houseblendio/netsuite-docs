To complete the following steps, you must have an account administrator role or the SuiteBundler permission.

#### To install the Norway Localization SuiteApp in your account:

1.  Go to Customization > SuiteBundler > Search & Install Bundle.
    
2.  Search for the **NetSuite Norway Localization SuiteApp**. For more information about installing SuiteApps, see [Installing a Bundle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3395142.html).
    
3.  Review the **Components** subtab.
    
    This page lists the SuiteApp objects that will be installed. Here you can:
    
    -   Indicate how to resolve conflicts between SuiteApp objects and target account objects with the same names or script IDs
        
    -   Set installation preferences for some objects
        
    -   Lock some objects so target account users cannot change them
        
4.  To begin the installation process, click the **Install** button.
    
5.  If your NetSuite account is using SuiteTax, please install the following SuiteApps from the SuiteApp Marketplace:
    
    1.  Go to Customization > SuiteCloud Development > SuiteApp Marketplace.
        
    2.  Find and install the following SuiteApps:
        
        -   **NetSuite Nordics Localization Foundation for SuiteTax**
            
        -   **NetSuite Norway Localization for SuiteTax**
