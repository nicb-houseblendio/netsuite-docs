Note:

This content is relevant for accounts without SuiteTax only.

The Norway SAF-T is a standard file format for exporting various types of accounting and tax data in XML format. The report structure is based on the SAF-T standard format by the Organization for Economic Cooperation and Development (OECD).

Norway Standard Audit File for Tax (SAF-T) Financial is supported in accounts without SuiteTax only.

Norway SAF-T financial report is comprised of three main sections:

| Section | Description |
| --- | --- |
| **Header** | General information about the company and audit file |
| **Master Files** | Information about general ledger account, suppliers, customers, and tax table |
| **General Ledger Entries** | Accounting transactions |

The Norwegian tax administration, Skatteetaten, lists the primary purposes of the Norway SAF-T Financial data to serve as the following:

-   An export format for accounting data after request from the Norwegian Tax Administration, public accountants and other parties.
    
-   An archiving format for the necessary accounting data for those who are obliged to keep accounts as stated in the Norwegian bookkeeping legislation.
    
-   Format for moving data when changing accounting software.
    
-   Format for moving data from accounting software to other financial systems such as year-end closing systems, tax computation systems, business intelligence software, advisory systems, and so on.
    

## Known Limitations {#subsect_4132133954}

Norway Standard Audit File for Tax (SAF-T) is supported in accounts without SuiteTax only.

Norway Standard Audit File for Tax (SAF-T) is supported in OneWorld accounts only. For more information, see [Introduction to NetSuite OneWorld](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N266468.html).

Norway Standard Audit File for Tax (SAF-T) is supported in the following languages:

-   English
    
-   Norwegian
