Setting up an account for an organization doing business in Norway usually requires enabling several features and installing some additional SuiteApps.

## Enabling Features {#bridgehead_157916771591}

Some features available in your NetSuite account can be important or even essential for users in Norway. If they're inactive, you should consider enabling them. Follow the instructions below to enable the most common features beneficial for users in Norway. However, if you want to get access to some specific product area, go to the [Functional Areas](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_157907863207.html#bridgehead_160681351731) help topic and check the exact requirements.

If you don't have sufficient permissions to enable features, please contact your account administrator.

#### To enable most common features: {#procedure_159012110289}

1.  Go to _Setup > Accounting > Accounting Preferences_
    
2.  Enable **Use Account Numbers** for the Norway SAF-T Financial Report.
    
3.  Go to _Setup > Company > Setup Tasks > Enable Features_.
    
4.  On the **Company** subtab, go to the **International** subtab, and check the **Multi-language** and **Multiple Currencies** boxes.
    
5.  On the **Accounting** subtab, go to the **Basic features** subtab, and check the **GL Audit Numbering** box.
    
6.  (Optional) On the **Accounting** subtab, go to the **Advanced features** subtab, and check the **Period End Journal Entries** and **Foreign Currency Variance Mapping** boxes.
    
7.  On the **SuiteCloud** subtab, enable the following features:
    
    -   SuiteBuilder
        
    -   SuiteScript
        
    -   SuiteGL
        
    -   SuiteFlow
        
    
    For more information about SuiteCloud features, see [SuiteCloud Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N239332.html).
    
8.  Click **Save**.
    

## Available SuiteApps {#bridgehead_160690110400}

Some additional features will only become active if you install a specific SuiteApp to your NetSuite account. SuiteApps are applications that extend NetSuite for specific industry and business needs. If you'd like to get access to some specific product area, go to the [Functional Areas](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_157907863207.html#bridgehead_160681351731) help topic and check which SuiteApps are required to be installed. Norway-specific features are currently available in the following SuiteApps:

| SuiteApp | Area | Description |
| --- | --- | --- |
| [Electronic Bank Payments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N1585433.html) | Payments | Enables bank payments of vendor bills, employee expenses, partner and employee commissions, customer refunds, and customer payments within Norway. |
| [International Tax Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2051341.html) | Taxation (Accounts without SuiteTax) | Generates Norwegian VAT return in Norwegian or English, sales and purchase reports by tax code, the generic EU sales list report, and the generic Intrastat report. If your account has the SuiteTax feature enabled, you do not need to install this SuiteApp. |
| Supplementary Tax Calculation | Taxation (Accounts without SuiteTax) | Manages EU reverse charges though automatic posting of notional VAT to the GL, and provides support for the calculation of non-deductible input tax. This SuiteApp works in conjunction with the International Tax Reports SuiteApp and isn't compatible with SuiteTax. For more information, see [Setting Up Tax Codes to Post Notional Tax Amounts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4702880164.html) and [Recording Nondeductible Input Tax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1822590.html). This SuiteApp also supports VAT on prompt payment discounts ([Recording Tax on Prompt Payment Discount](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4702990460.html)) If the SuiteTax feature is enabled in your NetSuite account, do not install the Supplementary Tax Calculation SuiteApp. |
