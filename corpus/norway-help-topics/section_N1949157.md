Note:

This topic is for VAT reports generated from the Tax Reports (International) page. If you are using the Country Tax Report page, see [Norway Tax Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_159005737735.html).

If you have a Norway subsidiary and nexus, you can generate the Norway VAT Return for historical reports prior 2022 from Reports > VAT/GST > Tax Reports (International).

Important:

The International Tax Reports SuiteApp maintains the tax code provisioning for Norway and supports historical reports. The Norway Tax Reports SuiteApp supports the new Norway eVAT reporting. For more information, see [Norway Tax Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_159005737735.html).

NetSuite gets the values in the report from your transactions, but some boxes in the form may require you to enter data manually. It is important that you save a PDF file of the report for your own records because NetSuite can't audit manually entered data. For information, see [Generating VAT/GST Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2064551.html).

You should review all the values in the report. You can click the values in the boxes of the VAT report to view drilldown details. To understand how NetSuite uses the tax codes to get the values for the Norway VAT report, see [What goes into each box - Norway VAT Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4035805431.html)

![Screenshot of Norway VAT Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/CountrySpecificFeatures/NorwayVATReport.png)

Note:

You can also use saved reports provided by the International Tax Reports SuiteApp to view both detail and summary reports for purchases or sales, grouped by tax code. For more information, see [Sales and Purchase Reports Grouped by Tax Code](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2067748.html).
