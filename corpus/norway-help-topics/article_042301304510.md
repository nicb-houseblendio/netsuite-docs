Norway Tax Codes are automatically added by SuiteTax Engine when you create a Norway Subsidiary. See below for supported Norway Standard Tax Codes for accounts with SuiteTax.

Important:

If a tax code isn't listed in the below table, or is listed as **Unsupported**, it's not supported for use in Norway VAT Return for accounts with SuiteTax. SuiteTax tax codes are only supported as provided by NetSuite. Renaming a tax code automatically renders it unsupported.

| SuiteTax Tax Code | Rate | Transaction Type | Origin | Norway Standard Tax Code |
| --- | --- | --- | --- | --- |
| NO\_ZR Zero rate for Norway | 0% | Sales |  | 5\_NO No output VAT - Zero rate |
| Purchases | Import goods | 85\_NO Importation of goods, not applicable for VAT - Zero rate |
| NO\_SR Standard rate for Norway | 25% | Sales |  | 3\_NO Output VAT - Regular rate |
| Purchases | Domestic | 1\_NO Input VAT deductible (domestic) - Regular rate |
| Import | 14\_NO Input VAT deductible (payed on import) - Regular rate |
| NO\_RR Reduced Rate for Norway | 15% | Sales |  | 31\_NO Output VAT - Reduced rate, middle |
| Purchases | Domestic | 11\_NO Input VAT deductible (domestic) - Reduced rate, middle |
| Import | 15\_NO Input VAT deductible (payed on import) - Reduced rate, middle |
| NO\_SRR Super-reduced rate for Norway | 12% | Sales |  | 33\_NO Output VAT - Reduced rate, low |
| Purchases | Domestic | 13\_NO Input VAT deductible (domestic) - Reduced rate, low |
| NO\_NL Not liable for tax in Norway |  | Ignored (won't appear in the report) |
| NO\_SR\_RC Reverse charge - Standard rate for Norway | 25% | Unsupported |
| NO\_SRR\_RC Reverse charge - Super-reduced rate for Norway | 12% | Unsupported |
| NO\_RR\_RC Reverse charge - Reduced rate for Norway | 15% | Unsupported |
| NO\_RCS Reverse charge for Sales for Norway | 0% | Unsupported |
