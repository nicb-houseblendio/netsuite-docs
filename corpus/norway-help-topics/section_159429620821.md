## Invoice Print Layout {#subsect_159429623192}

To print invoices in Norwegian layout, the Invoice Template must be linked with the Invoice Transaction Form.

#### To customize invoices for printing:

1.  Go to Customization > Forms > Transaction Forms.
    
2.  Click **Edit** on the Nordics Invoice Form. If you don't have one, click **Customize** on the **Standard Invoice Form** and save it as a custom invoice form. However, if your NetSuite account is using SuiteTax, you may want to customize the transaction forms included in the SuiteApps which are **Norway Invoice (EN) - SuiteTax** or **Norway Invoice (NO) - SuiteTax.**
    
3.  From the **Print Template** list, if your NetSuite account is using Legacy tax, select **Nordic Countries Invoice PDF/HTML Template**. If your NetSuite account is using SuiteTax, select **Norway Invoice PDF/HTML Template (SuiteTax)**.
    
4.  Click **Save**.
    

There is a single (consolidated) PDF/HTML template that reads the language of the Customer and prints the invoice accordingly.

Also, the customer's language must be set to Norwegian. Open a Customer record and go to the **Preferences** subtab.

Note:

The languages can only be added if they are first set under Setup > Company > General Preferences on the **Languages** subtab.

## Printing Invoice in Customer's Language {#bridgehead_159661607849}

If the customer's language is set to Norwegian language, the invoice is printed accordingly.

Click on the Print icon and select **Print**.

## Subsidiary Specific Fields {#subsect_159429706515}

Company information (name, phone, IBAN etc.) is displayed in the footer of the Invoice Layout. To set which information should be displayed, go to Setup > Company > Subsidiaries and click **Edit** next to the respective subsidiary. Enter the values you want to get printed.

You can find the following fields on an invoice:

-   Subsidiary Logo (Forms): This value is required for the template to print correctly as otherwise an error is thrown.
    
-   Company VAT: This is created as a separate field in case the standard field is no longer available, for example if changes are required.
    
-   Company Business ID
    
-   Bank Account No: Local bank account number for local currency.
    
-   Company IBAN
    
-   Company IBAN 2: For payments in other currency, if required.
    
-   Company IBAN 3: For payments in additional currency, if required.
    
-   Company BIC
    
-   Company BIC 2: Linked to IBAN 2.
    
-   Phone Number for Invoice
    
-   Company Email for Invoice
    
-   Overdue Interest
