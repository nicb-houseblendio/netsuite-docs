To set up Labor Expense Allocation, perform the following tasks:

1.  Create an employee pay type record. For details, see [Setting Up Employee Pay Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159118767859.html).
    
2.  (Optional) By default, the SuiteApp provides three employee pay frequencies. However, you can also create custom employee pay frequencies. For details, see [Creating Employee Pay Frequency](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159125438804.html).
    
3.  Set up your Labor Expense Allocation Preferences. For details, see [Setting Up Labor Expense Allocation Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159125411811.html).
    
4.  Create an allocation period for your labor expenses. For details, see [Managing Labor Expense Allocation Periods](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159127182919.html).
    
5.  Set up your allocation source.
    
    If you are allocating your labor expense based on employee rates, create employee rates either through CSV import or manually creating an employee rates record. For details, see [Creating Employee Rates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159125466116.html).
    
    If you are allocating your labor expenses based on employee pay, create employee pay transactions either through CSV import or manually creating an employee pay transaction record. For details, see [Creating Employee Pay Transactions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160189469991.html).
    
6.  Create, import, or fetch your employee timesheets. For details, see [Employee Timesheets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159127196924.html).
    
7.  Process your employee timesheets. For details, see [Processing Labor Expense Allocation Periods](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159134040854.html).
    
8.  After a successful processing of timesheets, the SuiteApp automatically creates a labor expense allocation transaction in NetSuite. For more information about how to manage your labor expense allocation transactions, see [Approving Labor Expense Allocation Transactions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159134783984.html).
