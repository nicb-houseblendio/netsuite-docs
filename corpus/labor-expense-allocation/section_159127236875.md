You can import the employee timesheets CSV file from the Employee Timesheets CSV page. The File Cabinet has the following templates and sample CSV files for importing employee timesheets:

| File name | Path in File Cabinet |
| --- | --- |
| TemplateImportTimesheets.xlsx | SuiteBundles > Bundle 305364> com.netsuite.payrollallocation > Templates folder |
| SampleImportTimesheetsCSV.csv | SuiteBundles > Bundle 305364> com.netsuite.payrollallocation > CSV files folder |

Download the template and sample files, then update the sample CSV file with your employee timesheet records. The following table shows a CSV file with sample records:

![A CSV employee timesheet file sample.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteApps/TimesheetCSVSample.png)

Note:

When creating your CSV file, take note of the following:

-   You need to enter the Internal ID of the employees in the CSV file. To show the internal ID on the employee record, check the **Show Internal IDs** box on the Set Preferences page. For more information, read [Setting the Show Internal IDs Preference](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3420345.html).
    
-   The date format in your CSV file needs to match the date format set in your NetSuite user preferences (Home > Set Preferences > Date Format). The SuiteApp supports all date formats in NetSuite user preferences except for **DD Month, YYYY** and **D Month, YYYY**.
    

After creating the CSV file, import the file in the application.

#### To import an employee timesheets CSV file:

1.  Open the Employee Timesheets CSV page:
    
    -   If you're using Employee Pay Transactions, go to Expense Management > Allocate Using Employee Pay Transactions > Import Employee Timesheets CSV > New.
        
    -   If you're using Employee Rates, go to Expense Management > Allocate Using Employee Rates > Import Employee Timesheets CSV > New.
        
2.  In the **Name** field, enter the timesheet name.
    
3.  Click the plus icon next to the **Timesheets CSV File** field.
    
    A popup window opens for attaching the CSV file.
    
4.  From the **Folder** list, select the folder in which you want to save the employee timesheets CSV file.
    
5.  Click the **Choose File** button and attach the employee timesheets CSV file.
    
6.  In the popup window, click **Save**.
    
7.  In the Employee Timesheets CSV page, click **Save**.
    
8.  To check the status of the import, click **Track Status**.
    
    The Employee Timesheet CSV Status page opens. The **Status** field displays the status of the import.
    

## Viewing Employee Timesheet Import Error Details {#bridgehead_160259555788}

To view import errors, download the CSV error file from the Employee Timesheet CSV Status page.

#### To view employee timesheet import error details:

1.  From the Employee Timesheet CSV Status page, click **List**.
    
2.  In the **Error File** column of the Employee Timesheet CSV Status List page, click **Download**. The error file is downloaded into your local directory.
    
3.  Open the CSV error file to review and fix the errors as needed.
    
4.  Import the timesheet CSV file again.
