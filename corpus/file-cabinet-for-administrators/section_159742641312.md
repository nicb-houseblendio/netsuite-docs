If you have administrative permissions, you can use the Expense Report Attachments Migration Tool to move existing expense attachments to the dedicated employee expense folders in the File Cabinet. The migration tool automatically searches all expense reports for files that need to be moved to the predefined user folders. You can automatically schedule the migration, or you can use the migration tool to schedule the migration later.

Note:

Before completing this migration, you should test the expense changes with your customizations in a sandbox account.
