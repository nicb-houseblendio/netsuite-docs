Only users with the Administrator role and users with the Documents and Files permission can use the File Cabinet. For more information, see [Setting Permissions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N288727.html).

This section includes information about the tasks that are common to users with the Administrator role. For information about tasks that are common to all users, regardless of their roles, see [File Cabinet Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N541319.html).

For information about how to make your files accessible on any URL listed on the file, see [Making Web Site Hosting Files Always Available](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4799275557.html).

For information about the Hide Attachment Folders preference, see [Hiding Attachment Folders](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163759199565.html).

For information about how to predefine dedicated folders where employee-specific expense report attachments are automatically saved, see [Enabling the Use of Employee-Specific Expense Folders](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163759207606.html).

For information about how to upload a logo, see [Uploading and Setting Your Logo](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N542584.html).

For information about using the Expense Report Attachments Migration Tool that allows you to migrate existing expense attachments to the File Cabinet dedicated employee expense folders, see [Expense Report Attachments Migration Tool](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159742641312.html).
