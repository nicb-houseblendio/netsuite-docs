To support your activity in the system, NetSuite creates folders in the File Cabinet and automatically adds relevant files to these folders. Some system folders include, but aren't limited to:

-   Attachments Sent
    
-   Attachments Received
    
-   SuiteBundles
    
-   SuiteApps
    
-   User Documents
    
    Only users with the Administrator role can see this folder.
    
-   Web Site Hosting Files
    

Note:

Some system folders don't allow creating new folders, making folders private or inactive, or restricting access to the contents in the folder.

Note:

To prevent performance issues, you shouldn't permanently store large numbers of work files in SuiteBundles, SuiteScript, and other system folders. Instead, you should create dedicated folders for such files in the File Cabinet. For more information, see [Creating File Cabinet Folders](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N541665.html).

Users with the Administrator role can restrict access to attachment folders. For more information, see [Hiding Attachment Folders](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163759199565.html).

For information about the Web Site Hosting Files and the SuiteBundles folders, see [Making Web Site Hosting Files Always Available](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4799275557.html).
