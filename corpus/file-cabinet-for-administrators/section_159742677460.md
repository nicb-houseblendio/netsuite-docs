Use the Expense Reports Attachments - Migration Tool link on the Enable Features page to open the migration tool. You can use the migration tool to schedule or cancel a migration and view migration details. Before you can use this feature, you must enable it.

#### To enable the migration tool feature:

1.  Go to _Setup > Setup Tasks > Company > Enable Features_.
    
2.  Click the **Company** subtab.
    
3.  Under **Data Management**, check the **Enhanced File Security** box.
    
    ![Data Management with the Enhanced File Security feature outlined in red.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/AccountAdministration/FileCabinetforAdministrators/EnableMigrationToolEnhancedFileSecurity.png)
4.  On the message that appears, select an option:
    
    -   To automatically schedule the migration, click **OK**. NetSuite schedules the migration for the next available time slot, and you can check the migration status on the Migration Details subtab of the Expense Report Attachments - Migration Tool.
        
    -   To schedule the migration manually later using the migration tool, click **Cancel**.
        
5.  Click **Save**.
    

You can now access the Expense Report Attachments Migration Tool using the Expense Report Attachments - Migration Tool link. If you try to open this page before saving the setting on the Enable Features page, you'll get a message instructing you to enable the feature.

Note:

If you disable the Enhanced Security feature, any scheduled migrations will be cancelled.

Note:

You can enable and disable this feature as needed without affecting the existing file structure. Enabling and disabling the feature affects only affects how new expense attachments are created.
