Important:

After migration, you can't revert to the file structure before migration. You can't remove new attachments from the User Documents structure. Only users with the Administrator role can restore the original file structure manually. Additionally, files in the User Document structure keep the new access rights behavior, even if the Enhanced File Security feature is disabled.

To schedule an expense attachment migration, open the Expense Report Attachments Migration Tool. For more information, see [Enabling and Configuring the Expense Report Attachments Migration Tool](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159742677460.html).

When the migration tool lists expense attachment files available for migration, you can schedule an expense report attachments migration. Migrations are scheduled to run during your maintenance window. The time of the maintenance window can vary, with Pacific Time being the default. In the Expense Report Attachments Migration Tool, click **Schedule Migration**. You'll see a confirmation message letting you know the migration was scheduled, and the button will become inactive.

The scheduled migration appears as Queued on the Migration Details subtab. If you schedule a migration when there aren't any files available to move, the Migration Details subtab still shows the Queued status, but no files will be migrated.

For large jobs, the migration automatically splits into one-hour runs. When one run ends, the tool schedules another run for the next day. These runs keep going until all expense attachments are migrated. If the migration tool encounters any unexpected issues, it reschedules the migration for the next day. After a migration is finished running, an email notification is sent to the account administrator to confirm if the migration was successful or if it failed. The Migration Details subtab shows the migration as processed, and the migrated files no longer appear in the Expense Attachments subtab.
