Open the Expense Report Attachments Migration Tool using the Expense Report Attachments - Migration Tool link on the Enable Features page. The Expense Report Attachments Migration tool opens in a new window and lists any files ready for migration. For more information, see [Enabling and Configuring the Expense Report Attachments Migration Tool](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159742677460.html).

Use the migration tool to move existing employee expense files to their dedicated folders. You should only have to run this migration one time. However, you might need to run the migration tool multiple times if there are too many files to move or if you encounter any issues. For more information, see [Scheduling an Expense Report Attachments Tool Migration](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159743017965.html). After the migration is completed, employee expense files are automatically saved to the appropriate employee expense folders.

Use the migration tool to:

-   View a list of files ready for migration
    
-   Open and view attached files
    
-   View applicable related expense reports
    
-   Schedule a migration or cancel a scheduled migration
    
-   View migration details, such as the progress or status of a migration job and history of previous migrations
    

For more information about using the migration tool, refer to the following topics:

-   [Expense Report Attachments Migration Tool Subtabs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159742929988.html)
    
-   [Scheduling an Expense Report Attachments Tool Migration](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159743017965.html)
