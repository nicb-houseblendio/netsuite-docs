If your company uses cost centers, you can include this information in your reports for Brazil. With the Brazil Reports SuiteApp, cost centers correspond to department records in NetSuite.

Brazil Reports includes the cost center information when generating the following reports:

-   Brazil general ledger
    
-   Brazil general journal
    
-   Brazil balance sheet
    
-   Brazil trial balance
    
    For more information, see [Country Tax Reports for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0924014747.html).
    
-   ECD file
    
-   EFD Contribuições file
    
    For more information, see [Generating SPED Files](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_164874849258.html).
    
-   PIS and COFINS assessment report
    
    For more information, see [Assessing PIS and COFINS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0513020736.html).
    

To include the cost center information in your reports, do the following:

-   Enable the Departments feature.
    
    For more information, see [General Company Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N232470.html).
    
-   Create department records equivalent to your cost centers.
    
    For more information, see [Creating Departments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N262248.html).
    
-   If you generate the ECD or EFD Contribuições files, ensure you include the department code for Brazil.
    
    For more information, see [Adding Department Codes for Brazil](#subsect_0710030958).
    
-   Associate your transactions with departments.
    

## Adding Department Codes for Brazil {#subsect_0710030958}

To ensure Brazil Reports includes all of your cost center information in the reports, when creating the department records, add the code that identifies the cost center.

#### To add a code for Brazil to a department:

1.  Go to _Setup > Company > Classifications > Departments_.
    
2.  Next to the department to which you want to add the code, click **Edit**.
    
3.  In the **Department Code for Brazil** field, enter the code you want to use to identify this department in reports for Brazil.
    
4.  Click **Save**.
    

For more information, see [Creating Departments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N262248.html).
