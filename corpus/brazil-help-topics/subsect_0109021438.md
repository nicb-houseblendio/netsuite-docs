Note:

To access the Brazil Banking Integration SuiteApp documentation in Brazilian Portuguese (Português do Brasil), see [Brazil Banking Integration](https://system.netsuite.com/app/help/helpcenter.nl?fid=BrazilBankingIntegration_pt_BR.pdf).

Before installing the Brazil Banking Integration SuiteApp, you must meet the following requirements:

-   Ensure you're using a OneWorld account.
    
    For more information, see [Introduction to NetSuite OneWorld](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N266468.html).
    
-   Enable several features in NetSuite.
    

#### To enable features:

1.  Go to _Setup > Company > Enable Features_.
    
2.  On the **Company** subtab, check the **Multi-Language** box.
    
3.  On the **Accounting** subtab, check the **Accounting** box.
    
4.  On the **SuiteCloud** subtab, check the following boxes:
    
    -   Custom Records
        
    -   Server SuiteScript
        
5.  Click **Save**.
