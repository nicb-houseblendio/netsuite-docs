You need specific permissions to access the custom records provided by the Brazil Localization SuiteApp.

By default, the Administrator role is granted full permissions to the custom records and transactions. The SuiteApp also grants access to selected custom transactions for the A/P Clerk and A/R Clerk roles. If other roles need to view, access, or edit the custom records, an administrator can grant permission to the roles.

If a role needs to generate and certify e-documents with Brazil Localization, grant the role the following permissions:

| Category | Permission | Access Level |
| --- | --- | --- |
| Custom Record | E-Document Series | View |
| Custom Record | Special Tax Regime on Simples Nacional | View |
| Custom Record | Tax Assessment on Simples Nacional | View |

If a role needs to create or edit transactions for Brazil, grant the role the following permissions:

| Category | Permission | Access Level |
| --- | --- | --- |
| Custom Record | Additional Information Preset | View |
| Custom Record | CFOP Determination Rule | View |
| Custom Record | CFOP Rule Additional Criteria | View |
| Custom Record | Field Mapping for CFOP Determination | View |
| Custom Record | Transaction Nature | View |
| Setup | Accounting Preferences | Full |

If a role needs to import CNAB return files, grant the role the following permissions:

| Category | Permission | Access Level |
| --- | --- | --- |
| Custom Record | Banking Information | View |
| Custom Record | Bank in Brazil | View |
| Lists | Documents and Files | View |
