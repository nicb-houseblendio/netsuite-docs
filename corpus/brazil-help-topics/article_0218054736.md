Note:

To access the Brazil Deferred Revenue Recognition SuiteApp documentation in Brazilian Portuguese (Português do Brasil), see [Brazil Deferred Revenue Recognition](https://system.netsuite.com/app/help/helpcenter.nl?fid=BrazilDeferredRevenueRecognition_pt_BR.pdf).

To use the Brazil Deferred Revenue Recognition SuiteApp, you must create deferred revenue settings.

Create settings for all subsidiaries in Brazil, either by creating specific settings for each subsidiary, or by applying the same settings to multiple subsidiaries.

#### To create deferred revenue settings for Brazil:

1.  Go to Setup > Brazil Deferred Revenue > Deferred Revenue Settings > New.
    
2.  In the **Subsidiary** field, select one or more subsidiaries to which you want to apply the settings.
    
3.  In the **Type of Revenue Recognition Event** field, select the type of revenue recognition event you want to create when processing deferred revenue.
    
    For more information, see [Creating a Custom Revenue Recognition Event](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4821833004.html).
    
4.  Choose the recognition plan for which NetSuite should create revenue recognition events when processing deferred revenue.
    
    -   To create revenue recognition events for the actual recognition plan, check the **Create Revenue Recognition Event for the Actual Recognition Plan** box.
        
        The actual plan controls when revenue is posted.
        
    -   To create revenue recognition events for the forecast recognition plan, check the **Create Revenue Recognition Event for the Forecast Recognition Plan** box.
        
        The forecast revenue plan is used only for forecasting and in forecast reports.
        
    
    For more information, see [Revenue Recognition Plans](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4594678231.html#bridgehead_4595555164).
    
5.  Click **Save**.
