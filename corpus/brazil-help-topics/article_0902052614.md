Note:

To access the SuiteTax Latam Engine - Brazil Records documentation in Brazilian Portuguese (Português do Brasil), see [SuiteTax Latam Engine - Brazil Records](https://system.netsuite.com/app/help/helpcenter.nl?fid=SuiteTaxLatamEngineBrazil_pt_BR.pdf).

The CIDE Importação Brazil plug-in enables you to calculate the Contribuições de Intervenção no Domínio Econômico (CIDE) tax on:

-   Imports of goods
    
-   Purchases and sales of fuels
    
-   Royalties
    

The following table summarizes the plug-in requirements and capabilities.

| **Plug-in Implementation** | CIDE Importação Brazil |
| --- | --- |
| **Tax Code's Internal Name** | CIDE\_IMPORTACAO\_BR |
| **Requires Parent Tax Determination Rules** | Yes Requires a parent tax determination rule with settings to calculate IRRF on services acquired from abroad. |
| **Requires Parameter Types** | No |
| **Supports Tax Basis and Tax Rate Override** | Yes |
| **Adds Expenses** | No |
| **Changes the Tax Calculation Basis** | Yes Adds the IRRF tax amount to the CIDE tax calculation basis if:
-   The tax determination rules record has a parent.
-   The parent tax determination rules have tax determination settings with an IRRF tax code with the standard internal name.

 |
| **Records Tax Calculation History** | No |
