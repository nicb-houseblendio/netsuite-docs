The Brazil Localization SuiteApp provides the following items to account for taxes on tax bill transactions:

-   COFINS
    
-   FCP
    
-   FCP ST
    
-   ICMS Próprio
    
-   ICMS ST
    
-   ICMS DIFAL
    
-   IPI
    
-   ISS
    
-   PIS
    

You must set up these items to ensure they work properly in your account. You should define the Brazilian subsidiaries to which they apply and the expense account to which to post their amounts.

If you have the Multiple Vendors feature enabled in your account, you can define a default vendor for each tax item. For more information, see [Enabling Item Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1111112254.html).

#### To set up tax items for Brazil:

1.  Go to _Lists > Accounting > Items_.
    
2.  Next to the tax item you want to set up, click **Edit**.
    
    NetSuite opens the item record.
    
3.  If you've got subsidiaries in more than one country, in the **Subsidiary** field, clear out any subsidiaries outside Brazil.
    
    Brazilian tax items shouldn't be associated with subsidiaries outside of Brazil. Keep the selection to Brazilian subsidiaries only.
    
4.  (Optional) Click the **Purchasing** subtab.
    
    1.  In the **Vendor** column, under the Vendors subtab, select the tax authority that you want to define as the default for this tax.
        
        The system populates this tax authority in the Vendor field of tax bills you generate with this item.
        
    2.  Click **Add**.
        
5.  Click the **Accounting** subtab.
    
6.  In the **Expense Account** field, select the account to which to post the tax amounts.
    
    Tip:
    
    By default, this field only lists expense accounts. If you want to post your tax amounts to a different type of account, check the **Expand Account Lists** box in your accounting preferences. For more information, see [General Accounting Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1385293.html).
    
7.  Click **Save**.
    
    Repeat these steps to set up the items for all taxes you pay.
