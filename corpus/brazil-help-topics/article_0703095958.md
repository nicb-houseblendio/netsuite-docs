By default, the Brazil Banking Integration SuiteApp includes standard templates to:

-   Generate bank slip files
    
-   Send email messages with bank slip or Pix information
    
-   Send email messages about batches of accounts payable payments pending approval
    

You can use these standard templates as a reference to create customized templates.

#### To customize a bank slip or email template for Brazil:

1.  Download the standard template.
    
    1.  Go to _Documents > Files > File Cabinet_.
        
    2.  In the sidebar or list, click **SuiteApps**.
        
        The files and folders within this folder appear.
        
    3.  Click the **com.netsuite.bankingintegrationservice** folder.
        
    4.  For the templates of bank slip files, do the following:
        
        1.  Click the **Bank Slip Templates** folder.
            
        2.  Click the **Banco do Brasil** folder.
            
        3.  Next to the template, click **Download**.
            
    5.  For the templates of email messages for bank slip and Pix information or pending approvals, do the following:
        
        1.  Click the **Email Templates** folder.
            
        2.  Next to the email template you want, click **Download**.
            
2.  Customize the standard template.
    
    Open the template you downloaded on your local device with your preferred text or code editor. When saving the customized template, make sure you name the file sufficiently different from the standard template.
    
3.  Upload the customized template to NetSuite.
    
    For more information, see [Uploading Files to the File Cabinet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N542268.html).
    
    Important:
    
    Don't save the customized templates to File Cabinet folders created by default in your account. For example, don't save the templates to the **com.netsuite.bankingintegrationservice** folder. Your template files can be overwritten if you save them to SuiteApp's folders.
    
    Instead, create your own File Cabinet folder to which to save the customized template. You can store this folder inside the **SuiteApps** or **SuiteScript** folders. For more information, see [Creating File Cabinet Folders](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N541665.html).
