Note:

To access the Brazil Reports documentation in Brazilian Portuguese (Português do Brasil), see [Brazil Reports](https://system.netsuite.com/app/help/helpcenter.nl?fid=BrazilReports_pt_BR.pdf).

Before you generate ECF files, ensure you meet the following prerequisites:

-   If you need to include account information in reports, set up your accounts.
    
    For more information, see [Setting Up Accounts to Appear in Reports for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0816091931.html).
    
-   If you want to include information about customers who are part of the federal government, set up their customer records.
    
    For more information, see [Setting Up Customers for Brazil Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_69173854800.html).
    
-   Create the IRPJ and CSLL assessment record.
    
    For more information, see [Assessing IRPJ and CSLL](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0513020754.html).
