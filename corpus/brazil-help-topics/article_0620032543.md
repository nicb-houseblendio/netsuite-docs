Note:

To access the Brazil Certification Tax Authorities SuiteApp documentation in Brazilian Portuguese (Português do Brasil), see [Brazil Certification Tax Authorities](https://system.netsuite.com/help/helpcenter/shared_resources/PDF/BrazilCertificationTaxAuthorities_pt_BR.pdf).

The Brazil Certification Tax Authorities SuiteApp provides predefined e-document template files to enable you to convert inbound e-documents to transaction records. You can use the predefined e-document template files to create your e-document template records.

For more information, see [Predefined E-Document Template Files for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0915021206.html).

#### To create an inbound e-document template for Brazil: {#procedure_65154200534}

1.  Go to Setup > E-Documents > E-Document Templates > New.
    
2.  In the **Name** field, enter a name for the template.
    
3.  In the **E-Document Package** field, select the e-document package with which you want to associate with the template.
    
4.  In the **Inbound Custom Data Source Plug-in Implementation** field, select **Brazil Inbound E-Document Data Source**.
    
5.  In the **Transaction Type** field, select **Bill**.
    
6.  In the **Subsidiary** field, select the subsidiaries that receive e-documents.
    
7.  Under Template Content, in the **Content Type** field, select **XML**.
    
8.  In the **Field Mapping for Inbound E-Documents** field, enter the XML content of the inbound e-document template.
    
    If available, you can paste in this field the content of the predefined e-document template file from the Brazil Certification Tax Authorities SuiteApp.
    
9.  Click **Save**.
