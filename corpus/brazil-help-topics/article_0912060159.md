Note:

To access the SuiteTax Latam Engine - Brazil Records documentation in Brazilian Portuguese (Português do Brasil), see [SuiteTax Latam Engine - Brazil Records](https://system.netsuite.com/app/help/helpcenter.nl?fid=SuiteTaxLatamEngineBrazil_pt_BR.pdf).

The FCP ST Brazil plug-in enables you to calculate the Fundo de Combate à Pobreza por Substituição Tributária (FCP ST) tax on the purchases and sales of goods.

The following table summarizes the plug-in requirements and capabilities.

| **Plug-in Implementation** | FCP ST Brazil |
| --- | --- |
| **Tax Code's Internal Name** | FCP\_ST\_BR |
| **Requires Parent Tax Determination Rules** | Yes Requires a parent tax determination rule with settings to calculate FCP, except when you set the CST 60 parameter. |
| **Requires Parameter Types** | Yes Requires the following parameters:
-   A CST code
-   MVA The MVA isn't required when you set the CST 60 parameter

For more information, see [Parameter Types for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_163664116234.html). |
| **Supports Tax Basis and Tax Override** | Yes Except when you set the CST 60 parameter. |
| **Adds Expenses** | Yes Adds shipping and handling costs, as well as expenses included in the Expenses subtab, to the tax calculation basis. |
| **Changes the Tax Calculation Basis** | Yes Adds the FCP tax amount to the FCP ST tax calculation basis if:

-   The tax determination rules record has a parent.
-   The parent tax determination rules have tax determination settings with an FCP tax code with the standard internal name.

 |
| **Records Tax Calculation History** | No |
