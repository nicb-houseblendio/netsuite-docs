Note:

To access the SuiteTax Latam Engine - Brazil Records documentation in Brazilian Portuguese (Português do Brasil), see [SuiteTax Latam Engine - Brazil Records](https://system.netsuite.com/app/help/helpcenter.nl?fid=SuiteTaxLatamEngineBrazil_pt_BR.pdf).

To create the predefined tax determination rules that the SuiteTax Latam Engine - Brazil Records SuiteApp provides, you must import the CSV files to your account.

Before you import the CSV files, unzip the ZIP file you downloaded from your account's File Cabinet. For more information, see [Finding the Predefined Tax Determination Rules Files for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_162870772972.html).

Also, ensure the date format set on your user preferences is **DD/MM/YYYY**. For more information about setting your user preferences, see [General Personal Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N475661.html).

Important:

If you don't use the **DD/MM/YYYY** date format, you may run into issues when importing. After the import is complete, you can switch back to any date format you prefer.

For each set of rules, you must upload two CSV files:

-   Start by uploading the CSV file that creates the tax determination rules records
    
-   Then, upload the CSV file that creates tax determination settings related to those rules
    

You must import first the tax determination rules and then the tax determination settings. If you don't follow this order, you might run into issues during the import.

To import CSV files, you must have the proper permissions to do the imports and access the record types you're creating. For more information about the permissions required to access the custom records, see [Roles and Permissions for the SuiteTax Latam Engine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_162040661540.html).

For more information about how to import the files, see the following topics.

-   [Importing Predefined Tax Determination Rules for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_162870787289.html)
    
-   [Importing Predefined Tax Determination Settings for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_162870790503.html)
