To access the SuiteTax Latam Engine - Brazil Records documentation in Brazilian Portuguese (Português do Brasil), see [SuiteTax Latam Engine - Brazil Records](https://system.netsuite.com/app/help/helpcenter.nl?fid=SuiteTaxLatamEngineBrazil_pt_BR.pdf).

The SuiteTax Latam Engine - Brazil Records SuiteApp provides several parameter types that you can use to modify how NetSuite calculates a tax.

To use them, you must:

-   Associate the parameter type with a tax determination settings or a tax code record.
    
    Depending on the parameter type, you may need to set a parameter value when associating it with another record. For more information about associating parameter types with other records, see [Creating Tax Determination Rules in the SuiteTax Latam Engine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_162153526964.html) and [Adding Tax Parameters to a Tax Code](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_163163783049.html).
    
    Tip:
    
    See the table on this topic to learn which predefined parameter types require parameter values.
    
-   Ensure that the SuiteTax Latam Engine plug-in associated with the tax code considers the parameter type when determining a tax.
    
    The predefined plug-ins provided with the SuiteApp are already prepared to consider the predefined parameter types associated with their respective taxes.
    

See the following table to learn more about the predefined parameter types for Brazil. It includes the taxes to which the parameters apply and whether you must set a parameter value for them or not. If the Parameter Value column is blank, you don't need to enter a value. For more information about parameter types in general, see [Creating Parameter Types in the SuiteTax Latam Engine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_163163688028.html).
