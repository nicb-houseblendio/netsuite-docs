Note:

To access the Brazil Reports documentation in Brazilian Portuguese (Português do Brasil), see [Brazil Reports](https://system.netsuite.com/app/help/helpcenter.nl?fid=BrazilReports_pt_BR.pdf).

When using the Brazil Reports SuiteApp, keep in mind the following limitations:

-   When assessing taxes and generating reports, Brazil Reports doesn't consider taxes on transactions with SuiteTax's Tax Details Override box checked. The SuiteApp doesn't support this SuiteTax feature.
    
    However, Brazil Reports does support the tax base and tax rate override feature from the SuiteTax Latam Engine SuiteApp. For more information, see [Overriding Tax Bases and Tax Rates for the SuiteTax Latam Engine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0116111646.html).
    
-   Due to a system limitation, you can only download XLS files of the following reports for Brazil if they're 10 MB or smaller.
    
    -   Auxiliary reports
        
        -   Simples Nacional assessment
            
        -   Withheld taxes on services
            
    -   Tax assessments
        
        -   ICMS assessment
            
        -   IPI assessment
            
        -   ISS assessment
            
        -   PIS and COFINS assessment
            
    
    If the file is bigger, download the PDF version instead.
