Note:

To access the SuiteTax Latam Engine - Brazil Records documentation in Brazilian Portuguese (Português do Brasil), see [SuiteTax Latam Engine - Brazil Records](https://system.netsuite.com/app/help/helpcenter.nl?fid=SuiteTaxLatamEngineBrazil_pt_BR.pdf).

The SuiteTax Latam Engine - Brazil Records SuiteApp automatically creates a set of tax code and tax type records for Brazil. For the list of the predefined tax codes and tax types, see [Tax Codes and Tax Types for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0425094127.html).

The predefined tax code and tax type records cover the standard taxation scenarios for Brazil. If you have special taxation scenarios for the taxes covered by the SuiteApp, you can create copies of the predefined tax code and tax type records.

For example, the predefined CSRF\_RETIDO\_BR tax code includes parameters for the PIS, COFINS, and CSLL tax rates that make up the CSRF tax.

If your company qualifies for the Regime Especial de Incentivos para o Desenvolvimento da Infraestrutura (REIDI) benefit, the predefined PIS and COFINS tax rate doesn't apply.

In this scenario, you would need to create a new tax code record with the PIS and COFINS tax rate parameter set as **0%**. Plus, you would need a matching tax type record with which to associate the tax code.

If you have specific accounting scenarios, you can also create copies of the predefined tax code and tax type records.

For example, you may want to post the ICMS tax on diesel fuel to a different account than the ICMS on other products. In this case, you could create new tax code and tax type records and select the ledger accounts to which you want to post the ICMS levied on diesel.

For more information about creating tax code and tax type records for Brazil, see the following topics:

-   [Creating Tax Types for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1019112529.html)
    
-   [Creating Tax Codes for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1019112537.html)
    

After creating new tax code and tax type records for the special taxation or accounting scenarios, to properly calculate the tax, you also need to:

-   Create copies of the applicable parameter types.
    
    For more information, [Copying Parameters Types from Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1009051816.html).
    
-   If the copied parameter types are set as available for tax codes, add the applicable tax parameters to the new tax codes.
    
    For more information, see [Adding Tax Parameters to Tax Codes for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1019112537.html#subsect_37112938272).
    
-   Create or edit tax determination rules for the new tax codes.
    
    Tax determination rules provided by the SuiteTax Latam Engine - Brazil Records SuiteApp don't apply to new tax types and codes by default.
    
-   If you have the Brazil Localization SuiteApp installed on your account, create copies of the applicable tax alias and parameter type mappings.
    
    For more information, see [Setup for Special Taxation and Tax Accounting for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1010052645.html).
