In Brazil, services can be categorized through numeric codes defined by municipal or national authorities. Municipal codes are 4 digits long and national codes are 6 digits long.

You can further classify services according with:

-   The Nomenclatura Brasileira de Serviços (NBS).
    
-   The operation indicator code (cIndOp).
    

With the Brazil Localization SuiteApp, you can assign one combination of NBS and cIndOp codes per service code.

#### To add NBS and cIndOp codes to service codes for Brazil:

1.  Go to Lists > Brazil Tax Information > Service and MCN Codes.
    
2.  Next to the national service code you want, click **View**.
    
    The item code record for the service opens.
    
3.  Click the **Classification for Brazil** subtab.
    
4.  Click **New Item Code Classification for Brazil**.
    
    A new item code classification for Brazil record opens.
    
5.  In the **Item Code** field, select the service code.
    
6.  In the **NBS Code** field, select the code from the NBS you want to associate with the service code.
    
7.  In the **Operation Indicator Code** field, select the cIndOp code you want to associate with the service code.
    
8.  Click **Save**.
