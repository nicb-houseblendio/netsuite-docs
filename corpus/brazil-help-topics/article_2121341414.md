To access the Brazil Localization SuiteApp documentation in Brazilian Portuguese (Português do Brasil), see [Brazil Localization](https://system.netsuite.com/app/help/helpcenter.nl?fid=BrazilLocalization_pt_BR.pdf).

The Brazil Localization SuiteApp includes several custom transaction types to meet local needs. Each transaction type is designed for a specific business purpose and can affect the general ledger differently.

For example, the SuiteApp includes the correction letter transaction type. With it, you can enter the amended or additional information for the original electronic invoice, then generate and certify the electronic correction letter. Because correction letters don't change the tax basis, tax rate, or the transaction's amount, this type of transaction doesn't post to the general ledger.

The following table demonstrates whether each type of transaction posts to the general ledger and which status is required to create GL entries:

| Custom Transaction Type | Posts to the General Ledger? |
| --- | --- |
| Cancellation journal | Yes, when the transaction status changes to Certified. |
| Correction letter | No. |
| Delivery journal | Yes, after saving, given this transaction doesn't have statuses. |
| E-document cancellation | Yes, when the transaction status changes to Certified. |
| Fine and interest on purchases | Yes, after saving, given this transaction doesn't have statuses. |
| Fine and interest on sales | Yes, after saving, given this transaction doesn't have statuses. |
| Goods return | Yes, when the transaction status changes to Certified. |
| Import bill | Yes, when the transaction status changes to Certified. |
| Inbound delivery | No. |
| Outbound delivery | No. |
| Sales discount | Yes, after saving, given this transaction doesn't have statuses. |

Important:

Avoid changing the transaction status manually. If you change the status manually, NetSuite may be unable to create the GL entries.
