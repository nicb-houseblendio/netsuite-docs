To send EFD-Reinf events with NetSuite, set up the monitoring plug-in, operations, and certification settings on the predefined tax authority record.

Before you edit the tax authority, make sure you uploaded a digital certificate to your account. For more information, see [E-Document Digital Signature](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160640208369.html).

#### To set up the EFD-Reinf tax authority:

1.  Go to Setup > E-Document Certification > Tax Authority Certification Service.
    
2.  Next to the EFD-Reinf Tax Authority record, click **Edit**.
    
3.  In the **Certification Monitoring Plug-in Implementation** field, select **EFD-Reinf Monitoring**.
    
4.  Click **Save**.
    
    NetSuite saves the record and displays it in view mode.
    
5.  Click the **Operations** subtab.
    
    The subtab lists the existing certification operation records.
    
    1.  Next to an operation, click **Edit**.
        
    2.  In the **E-Document Template** field, select the e-document template record that corresponds to the operation.
        
        For example, if you're editing the R-1000 Sending Operation, select the template you created for the R-1000 event.
        
        For more information about creating e-document templates, see [Creating E-Document Templates for EFD-Reinf Events](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0113015811.html).
        
    3.  (Optional) To validate that the EFD-Reinf event contains all required elements and attributes before sending, check the **Enable XSD Validation** box.
        
        The XSD validation helps you avoid certification failures from XML schema issues. Don't enable XSD validation for checking status operations.
        
    4.  Click **Save**.
        
        Repeat these steps for each operation that represents an event supported by the Brazil Reports SuiteApp. For more information about supported events, see [EFD-Reinf Events](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1231090648.html).
        
6.  Click the **Certification Settings** subtab.
    
    The subtab lists the existing e-document certification settings records.
    
    1.  Click **New E-Document Certification Settings**.
        
        A new record opens.
        
    2.  In the **Subsidiary** field, select the subsidiary to which these certification settings apply.
        
        Note:
        
        If you have more than one parent subsidiary, create e-document certification settings for each. Settings for a parent subsidiary also apply to its child subsidiaries.
        
    3.  In the **E-Document Category** field, select **EFD-Reinf Report Events**.
        
    4.  In the **E-Document Folder ID**, enter the internal ID of the file cabinet folder on which to save the responses from the tax authority.
        
    5.  In the **Certification Environment** field, select the **Production** or **Test** environment.
        
    6.  In the **Digital Certificate** field, select the certificate you want to use to authenticate the EFD-Reinf events you send to the tax authority.
        
        For more information about uploading digital certificates to NetSuite, see [E-Document Digital Signature](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160640208369.html).
        
    7.  Click **Save**.
