After you generate a delivery file with the CNAB 240 standard, you can still remove one or multiple installments from the file. You can't remove installments from delivery files generated with the CNAB 400 and CNAB 750 standards.

Removing installments from a delivery file may be necessary in the following scenarios:

-   Before you send the delivery file to the bank, you notice one or multiple installments shouldn't be included in the file.
    
    You must remove the installments from the CNAB delivery file record, generate the file again, and send the new file to the bank.
    
-   After you send the delivery file to the bank, the banking institution rejects one or multiple installments from the file.
    
    Rejected installments haven't been registered with the bank and you must include them on a new delivery file. To make them available to be included in a new delivery file, you need to remove the installments from the existing CNAB delivery file record. You don't need to generate the file again.
    

#### To remove installments from a CNAB delivery file: {#procedure_0329054413}

1.  Go to Transactions > Bank > CNAB Delivery Files.
    
2.  Click **Edit** next to the delivery file from which you would like to remove installments.
    
    The CNAB delivery file record opens.
    
3.  Click the **Installments** subtab.
    
4.  Check the **Check to Remove** box next to each installment you would like to remove from the delivery file.
    
    You can only remove installments that have not been registered with the bank.
    
5.  Click **Save**.
    
    The status of the CNAB delivery file record changes to **Removing Installments from the Delivery File**.
    
6.  Refresh the page until the **Status** field is **Ready to be Generated Again**.
    
    When the status is **Ready to be Generated Again**, NetSuite has already removed the installments from the CNAB delivery file record.
    
7.  (Optional) To generate the file without the removed installments, click **Generate Again**.
    

After you remove an installment from a delivery file, it becomes available to be included in a new delivery file. For more information, see [CNAB Delivery File Generation for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0509034618.html).
