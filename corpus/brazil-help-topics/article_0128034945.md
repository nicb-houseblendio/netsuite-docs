To make a tax revenue code available in tax bills, you must associate the code to a type of tax assessment. The tax bill only lists the revenue codes associated with the tax assessment you're billing.

Brazil Reports associates predefined tax revenue codes with some tax assessments by default. You can associate additional assessments to these predefined codes to fit your business needs.

#### To associate a revenue code with tax assessments for Brazil:

1.  Go to Lists > Brazil Reports > Revenue Codes.
    
2.  Next to the tax revenue code you want to set up, click **Edit**.
    
3.  In the **Default Tax Assessment** field, review the tax assessments associated to this revenue code by default.
    
4.  In the **Tax Assessment** field, select the additional tax assessments for which you want make this revenue code available.
    
5.  (Optional) In the **Effective Until** field, enter or select the date in which the revenue code stops being effective.
    
    NetSuite doesn't list expired revenue codes on tax bills.
    
6.  Click **Save**.
