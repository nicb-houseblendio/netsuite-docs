To access the Brazil Certification Tax Authorities SuiteApp documentation in Brazilian Portuguese (Português do Brasil), see [Brazil Certification Tax Authorities](https://system.netsuite.com/help/helpcenter/shared_resources/PDF/BrazilCertificationTaxAuthorities_pt_BR.pdf).

The Brazil Certification Tax Authorities SuiteApp provides predefined PDF templates to create PDF versions of e-documents generated with NetSuite. The following table lists the available PDF templates:

| E-Document Type | Tax Authority Certification Service | Operation Type | PDF Template |
| --- | --- | --- | --- |
| Outgoing electronic invoices for goods | State tax authorities For example, São Paulo State Tax Authority | Send E-Document | Electronic Invc. for Goods PDF Template |
| Cancel | Electronic Invc. for Goods PDF Template |
| Update | Electronic Correction Letter PDF Template |
| Outgoing electronic invoices for services that adopt the NFS-e Nacional standard | Secretaria de Finanças Nacional Tax Authority | Send E-Document | National Electronic Invoice for Services PDF Template |
| Cancel | National Electronic Invoice for Services PDF Template |
| Electronic declarations of contents | State tax authorities for DC-e For example, São Paulo State Tax Authority for DC-e | Send E-Document | Declaration of Contents PDF Template |
| Cancel | Declaration of Contents PDF Template |
| Incoming electronic invoices for goods | Receiver Acknowledgment Tax Authority | Check Status | Electronic Invc. for Goods PDF Template |

You must associate predefined PDF templates with certification service operation records used to certify e-documents and send receiver acknowledgment events. For more information, see [Setting Up Certification Service Operations for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0327111232.html).

The SuiteApp enables you to customize PDF templates with additional information from the e-document certification request. For more information, see [PDF Templates Customization for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0626024017.html).

## Subsidiary Logo on PDF Templates for Brazil {#subsect_0408045712}

By default, NetSuite prints the logo set in the **Subsidiary Logo (for Forms)** field on your PDF files. This field appears on the subsidiary record. For more information, see [Creating Subsidiary Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N272471.html).

The subsidiary logo for forms can have the following maximum dimensions:

-   **Height** - 72 pixels
    
-   **Width** - 259 pixels
    

To display the logo from the Company Information page instead, leave the subsidiary logo for forms field empty. For more information, see [Enter Basic Company Information](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_156710108009.html).
