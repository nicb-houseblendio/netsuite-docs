Note:

To access the SuiteTax Latam Engine - Brazil Records documentation in Brazilian Portuguese (Português do Brasil), see [SuiteTax Latam Engine - Brazil Records](https://system.netsuite.com/app/help/helpcenter.nl?fid=SuiteTaxLatamEngineBrazil_pt_BR.pdf).

The IRRF Importação Brazil plug-in enables you to calculate the Imposto de Renda Retido na Fonte (IRRF) tax on services acquired from natural persons.

The following table summarizes the plug-in requirements and capabilities.

| **Plug-in Implementation** | IRRF PF Brazil |
| --- | --- |
| **Tax Code's Internal Name** | IRRF\_PF\_RETIDO\_BR |
| **Requires Parent Tax Determination Rules** | Yes Requires a parent tax determination rule with settings to calculate INSS PF. |
| **Requires Parameter Types** | Yes Requires the Maximum Taxable Amount parameter. For more information, see [Parameter Types for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_163664116234.html). |
| **Supports Tax Basis and Tax Override** | Yes |
| **Adds Expenses** | No |
| **Changes the Tax Calculation Basis** | Yes Subtracts the INSS PF tax amount from the IRRF PF tax calculation basis if:
-   The tax determination rules record has a parent tax determination rules.
-   The parent tax determination rules have tax determination settings with an INSS PF tax code with the standard internal name.

 |
| **Records Tax Calculation History** | No |
