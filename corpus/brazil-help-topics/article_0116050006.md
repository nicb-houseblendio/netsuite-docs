Note:

To access the Brazil Banking Integration SuiteApp documentation in Brazilian Portuguese (Português do Brasil), see [Brazil Banking Integration](https://system.netsuite.com/app/help/helpcenter.nl?fid=BrazilBankingIntegration_pt_BR.pdf).

After you set up the Brazil Banking Integration SuiteApp, NetSuite automatically imports bank statements from Banco do Brasil.

After the SuiteApp imports bank statements, you can:

-   Monitor import statuses and troubleshoot errors.
    
    For more information, see [Banking Import History](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159622181091.html) and [Viewing Bank Statement Import Errors for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0124033525.html).
    
-   Review the imported bank statement.
    
    For more information, see [Viewing Imported Data on the Match Bank Data Page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163164999188.html).
    
-   Reconcile your bank statement with your NetSuite transactions.
    
    -   For more information about automatically matched transactions, see _Viewing Transactions To Be Submitted_.
        
    -   For more information about transactions that require manual matching, see [Matching Bank Data](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_32131451402.html).
