To access the SuiteTax Latam Engine - Brazil Records documentation in Brazilian Portuguese (Português do Brasil), see [SuiteTax Latam Engine - Brazil Records](https://system.netsuite.com/app/help/helpcenter.nl?fid=SuiteTaxLatamEngineBrazil_pt_BR.pdf).

The ISS Brazil plug-in enables you to calculate the Imposto Sobre Serviços (ISS) tax on services acquired from abroad.

The following table summarizes the plug-in requirements and capabilities.

| **Plug-in Implementation** | ISS Importação Brazil |
| --- | --- |
| **Tax Code's Internal Name** | ISS\_IMPORTACAO\_BR |
| **Requires Parent Tax Determination Rules** | No |
| **Requires Parameter Types** | Yes Requires the ISS on Imported Services parameter. For more information, see [Parameter Types for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_163664116234.html). |
| **Supports Tax Basis and Tax Override** | Yes |
| **Adds Expenses** | No |
| **Changes the Tax Calculation Basis** | Yes Adds the amount of ISS due to the tax calculation basis if you set the ISS on Imported Services parameter. |
| **Records Tax Calculation History** | No |
