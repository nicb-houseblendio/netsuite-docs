To access the Brazil Localization SuiteApp documentation in Brazilian Portuguese (Português do Brasil), see [Brazil Localization](https://system.netsuite.com/app/help/helpcenter.nl?fid=BrazilLocalization_pt_BR.pdf).

In Brazil, assigning a new number to an e-document can be necessary when you're required to void the number first assigned to the e-document.

In NetSuite, you can assign new numbers to rejected electronic invoices for goods associated with the following transactions:

-   Goods return
    
-   Import bill
    
-   Inbound delivery
    
-   Invoice
    
-   Outbound delivery
    

#### To assign a new number to an e-document: {#procedure_1115061537}

1.  Access the transaction to which you want to assign a new e-document number.
    
2.  Click **View** next to the transaction you want.
    
3.  Click **Assign New E-Document Number**.
    
4.  Click **Generate E-Document**.
    
5.  Click **Certify E-Document**.
