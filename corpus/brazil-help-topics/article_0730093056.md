To generate Centro Nacional de Automação Bancária (CNAB) delivery files more quickly when they include many transactions and installments, increase the number of SuiteCloud Processors available for the following scripts:

-   **CNAB 240** - BRL MR CNAB 240 Delivery File Processing (script ID: `customdeploy_brl_mr_cnab_delivery_file`)
    
-   **CNAB 400 and CNAB 750** - BRL MR CNAB 400 and 750 Delivery File Processing (script ID: `customdeploy_brl_mr_cnab_file_400_750`)
    

Adjust the capacity of each script according to your business needs. For example, you include more transactions in CNAB 400 delivery files than in CNAB 240 delivery files. Then, you should assign more SuiteCloud Processors to the BRL MR CNAB 400 and 750 Delivery File Processing script deployment.

For more information about SuiteCloud processors, see the following help topics:

-   [Map/Reduce Script Deployment Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1509578980.html)
    
-   [SuiteCloud Processors Processor Allotment Per Account](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1518131145.html)
    

#### To set the CNAB file generation capacity:

1.  Go to _Customization > Scripting > Script Deployments_.
    
2.  Next to the script deployment that you want to update, click **Edit**.
    
    Tip:
    
    To find the script deployment records for CNAB file generation, under Filters, in the **Type** list, select **Map/Reduce**.
    
3.  In the **Concurrency Limit** field, enter the number of SuiteCloud Processors available to generate CNAB delivery files.
    
    The default number is **1**.
    
4.  Click **Save**.
