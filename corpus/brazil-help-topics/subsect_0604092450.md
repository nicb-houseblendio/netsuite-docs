Note:

To access the Brazil Reports documentation in Brazilian Portuguese (Português do Brasil), see [Brazil Reports](https://system.netsuite.com/app/help/helpcenter.nl?fid=BrazilReports_pt_BR.pdf).

When using the Brazil Certification Tax Authorities SuiteApp, be guided by the following recommendations:

-   When setting the subsidiary logo for forms, upload an image with these maximum dimensions:
    
    -   **Height** - 72 pixels
        
    -   **Width** - 259 pixels
        
    
    NetSuite includes the subsidiary logo in the PDF version of accounting reports, auxiliary reports, financial statements, fiscal books, and tax assessments.
    
    For more information, see [Setting Up Subsidiaries for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_164139168385.html).
    
-   When setting up your accounts for Brazil through a CSV import, check the **Run Server SuiteScript and Trigger Workflows** box.
    
    This option appears on step 2 of the Import Assistant, under Advanced Options. It enables the system to run validations on the **Parent Account in the Brazil Chart of Accounts** field.
    
    For more information, see [Set Advanced CSV Import Options](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N345887.html).
