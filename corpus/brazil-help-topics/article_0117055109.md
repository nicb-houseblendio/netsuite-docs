Before using the SuiteTax Latam Engine - Brazil Records SuiteApp, be aware of the current limitations and best practice recommendations.

## Best Practices for the SuiteTax Latam Engine - Brazil Records SuiteApp {#subsect_1204043414}

When using the SuiteTax Latam Engine - Brazil Records SuiteApp, be guided by the following best practices:

-   The same best practices from the SuiteTax Latam Engine SuiteApp.
    
    For more information, see [SuiteTax Latam Engine Best Practices and Known Limitations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_162085034633.html).
    
-   When creating or updating custom records through CSV import, check the **Run Server SuiteScript and Trigger Workflows** box.
    
    This option appears on step 2 of the Import Assistant, under Advanced Options. It enables the system to run validations on the custom records that can prevent configuration mistakes. For more information, see [Set Advanced CSV Import Options](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N345887.html).
    

## Known Limitations of the SuiteTax Latam Engine - Brazil Records SuiteApp {#subsect_1204043037}

When using the SuiteTax Latam Engine - Brazil Records SuiteApp, keep in mind the following limitations:

-   The same known limitations from the SuiteTax Latam Engine SuiteApp.
    
    For more information, see [SuiteTax Latam Engine Best Practices and Known Limitations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_162085034633.html).
    
-   SuiteTax Latam Engine - Brazil Records only supports CBS and IBS calculation for tax classification codes (cClassTrib) for CST codes 000, 200, 410, and 550, except for:
    
    -   410014
        
    -   410014
        
    -   410016
        
    -   410026
        
    -   410030
