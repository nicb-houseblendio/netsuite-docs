To access the Brazil Reports documentation in Brazilian Portuguese (Português do Brasil), see [Brazil Reports](https://system.netsuite.com/app/help/helpcenter.nl?fid=BrazilReports_pt_BR.pdf).

Before you generate ECD files, ensure you meet the following prerequisites:

-   If you need to include account information in reports, set up your accounts.
    
    For more information, see [Setting Up Accounts to Appear in Reports for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0816091931.html).
    
-   If you use cost centers:
    
    -   Enable the Departments feature.
        
        For more information, see [General Company Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N232470.html).
        
    -   Create department records for your cost centers.
        
        For more information, see [Creating Departments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N262248.html).
        
    -   Add codes to your department records.
        
        For more information, see [Cost Centers in Reports for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0708093202.html).
        
    -   Associate the departments to your transactions.
        
-   If you want to include the accounting book number in your ECD files, set up the book number and year of your last ECD submission.
    
    For more information, see [Setting Up Accounting Book Numbers for ECD Files](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0908040036.html).
    
-   Identify the journal entries used for closing income accounts and to post amounts after the end of the posting period.
    
    For more information, see [Setting Journals Entries as Closing Journals for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1226043455.html).
    
-   Include additional federal registration numbers assigned to your subsidiaries.
    
    For more information, see [Adding Other Federal Registration Numbers to ECD Files](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1208041829.html).
