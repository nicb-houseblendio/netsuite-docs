Note:

To access the SuiteTax Latam Engine - Brazil Records documentation in Brazilian Portuguese (Português do Brasil), see [SuiteTax Latam Engine - Brazil Records](https://system.netsuite.com/app/help/helpcenter.nl?fid=SuiteTaxLatamEngineBrazil_pt_BR.pdf).

The SuiteTax Latam Engine - Brazil Records SuiteApp provides a set of predefined SuiteTax Latam Engine plug-ins. The predefined plug-ins enable you to calculate several taxes on goods and services in Brazil with the SuiteTax Latam Engine tax engine.

For the plug-ins to run on transactions, the applicable tax determination rules and settings must meet requirements such as:

-   Tax code's internal name
    
    For more information about internal names, see [Associating a SuiteTax Latam Engine Plug-in Implementation With a Tax Code](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_162645934764.html).
    
-   Parameter types
    
    For more information, see [Parameter Types for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_163664116234.html).
    
-   Subsidiary tax information
    
    For more information, see [Setting Tax Information in Subsidiary Records for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_164149942864.html).
    

Consider the requirements and parameters of each tax plug-in when you create and set up your tax determination rules and settings.

For more information about the predefined plug-ins, see the following help topics:

-   [SuiteTax Latam Engine Plug-ins for Taxes on Goods for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1024094616.html)
    
-   [SuiteTax Latam Engine Plug-ins for Taxes on Services from Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1024094853.html)
    
-   [SuiteTax Latam Engine Plug-ins for Taxes on Goods and Services from Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1024095241.html)
