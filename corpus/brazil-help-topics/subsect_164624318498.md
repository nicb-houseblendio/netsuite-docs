Note:

To access the Brazil Reports documentation in Brazilian Portuguese (Português do Brasil), see [Brazil Reports](https://system.netsuite.com/app/help/helpcenter.nl?fid=BrazilReports_pt_BR.pdf).

The Brazil Reports SuiteApp is a managed SuiteApp. Whenever there are enhancements or new features, NetSuite automatically updates your account.

To install this SuiteApp, you must have permission and access to the SuiteApp Marketplace. For more information, see [Viewing SuiteApps in the SuiteApp Marketplace](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1539797977.html).

#### To install the Brazil Reports SuiteApp:

1.  In NetSuite, go to SuiteApps.
    
2.  In the **Search SuiteApps** field, enter **Brazil Reports**.
    
3.  Click **Brazil Reports**.
    
4.  In the top-right corner of the SuiteApp details page, click **Install**.
    
5.  Wait for the installation to complete.
    
    Tip:
    
    After the installation is done, verify the status of the import that creates the predefined records. For more information, see [Verifying the Import Status of the Brazil Reports Predefined Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_72100339883.html).
    

For more information about the SuiteApp installation process, see [Installing from the SuiteApp Marketplace](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1539799323.html)..
