Note:

To access the Brazil Deferred Revenue Recognition SuiteApp documentation in Brazilian Portuguese (Português do Brasil), see [Brazil Deferred Revenue Recognition](https://system.netsuite.com/app/help/helpcenter.nl?fid=BrazilDeferredRevenueRecognition_pt_BR.pdf).

The Brazil Deferred Revenue Recognition SuiteApp is a managed SuiteApp. Whenever there are enhancements or new features added, NetSuite automatically updates your account.

As a shared SuiteApp, Brazil Deferred Revenue Recognition is only available for installation on authorized accounts. For more information, contact your account manager.

To install this SuiteApp, you must have permission and access to the SuiteApp Marketplace. For more information, see [Viewing SuiteApps in the SuiteApp Marketplace](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1539797977.html).

Before you attempt to install Brazil Deferred Revenue Recognition, ensure you meet the prerequisites for installation. For more information, see [Prerequisites for Installing the Brazil Deferred Revenue Recognition SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_84165652987.html).

#### To install the Brazil Deferred Revenue Recognition SuiteApp:

1.  In NetSuite, go to SuiteApps.
    
2.  In the **Search SuiteApps** field, enter **Brazil Deferred Revenue Recognition**.
    
3.  Click **Brazil Deferred Revenue Recognition**.
    
4.  At the top-right area of the SuiteApp details page, click **Install**.
    
5.  Wait for the installation to complete.
    

For more information about the SuiteApp installation process, see [Installing from the SuiteApp Marketplace](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1539799323.html).
