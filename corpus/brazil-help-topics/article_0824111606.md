Create e-document templates to generate and certify electronic invoices for Brazil.

In Brazil, because each tax authority can define specific requirements for certification, e-document templates vary according with:

-   E-document category
    
-   Tax authority
    
-   Certification operation
    

The Brazil Certification Tax Authorities SuiteApp includes predefined e-document template files to meet the requirements from several Brazilian tax authorities. You can use the predefined e-document template files to create your e-document template records. For more information, see [Predefined E-Document Template Files for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0915021206.html).

#### To create an e-document template for Brazil: {#procedure_0824114149}

1.  Go to Setup > E-Documents > E-Document Templates > New.
    
2.  In the **Name** field, enter a name for the template.
    
3.  In the **E-Document Package** field, select the e-document package with which you want to associate with the template.
    
4.  In the **Digital Signature Plug-in Implementation** field, select **E-Document Digital Signature Plug-in**.
    
5.  In the **Custom Data Source Plug-in Implementation** field, select **Brazil E-Document Data Source Plug-in**.
    
6.  In the **Transaction Type** field, select the types of transaction in which you want to use the template.
    
    In Brazil, the transaction types depend on the e-document's category and certification operation:
    
    | E-Document Category | Certification Operation | Transaction Type |
    | --- | --- | --- |
    | Electronic invoice for goods | Send | Bill credit, Cash sale, Inbound delivery, Invoice, Import bill, Goods return, Outbound delivery |
    | Cancel | E-document cancellation, Delivery journal |
    | Check status | \- |
    | Update | Correction letter |
    | Void number | Inbound delivery, Invoice, Import bill, Goods return, Outbound delivery |
    | Electronic invoice for services | Send | Invoice |
    | Cancel | E-document cancellation |
    | GNRE tax collection form | Send | Bill credit, Cash sale, Goods return, Import bill, Invoice, Inbound delivery, Outbound delivery |
    | Check status | \- |
    
7.  In the **Subsidiary** field, select the subsidiaries that generate and certify e-documents for Brazil with the template.
    
8.  Under Template Content, in the **Content Type** field, select **XML**.
    
9.  In the **Template for Outbound E-Documents** field, enter the XML content of the outbound e-document template.
    
    If available, you can paste in this field the content of the predefined e-document template file from the Brazil Certification Tax Authorities SuiteApp.
    
10.  Click **Save**.
     

For more information about e-document templates, see [Creating E-Document Templates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4536871429.html).
