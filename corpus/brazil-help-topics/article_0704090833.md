To access the SuiteTax Latam Engine - Brazil Records documentation in Brazilian Portuguese (Português do Brasil), see [SuiteTax Latam Engine - Brazil Records](https://system.netsuite.com/app/help/helpcenter.nl?fid=SuiteTaxLatamEngineBrazil_pt_BR.pdf).

The SuiteTax Latam Engine - Brazil Records SuiteApp provides a set of predefined records for all the Código Fiscal de Operações e de Prestações (CFOP) codes.

You can associate CFOP codes with NetSuite transactions and tax determination rules to apply the tax calculation to specific business scenarios.

To further specify the applicability of a tax determination rule, you can create your own CFOP code records in NetSuite to fit your business needs. For more information, see [Creating Tax Determination Rules for Specific CFOP, MCN, or Service Codes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_164760698762.html).

For example, you use the 5.102 CFOP code when selling goods for both resale and to the final consumer. You may want to apply different tax determination rules to transactions with this CFOP in each scenario.

You can create a CFOP code record for the resale scenario and then create tax determination rules restricted to this operation code. Next, you can create another CFOP code record for the final consumer scenario, and restrict tax determination rules to it.

#### To create a CFOP code:

1.  Go to Lists > Brazil Tax Information > CFOP Codes > New.
    
2.  In the **Name** field, enter a name for the code.
    
    Choose a name that differentiates this record from the existing records. For example, **5.102 para Revendas**.
    
3.  In the **Code** field, enter the CFOP.
    
    For example, **5.102**.
    
4.  In the **Group** field, select the group of the code.
    
    Groups indicate the direction (incoming or outgoing) and location (same state, different states, different countries) of the operation.
    
5.  In the **Category** field, select the category of the code.
    
    Categories indicate the type of goods or services involved in the operation.
    
6.  In the **Transaction Type** field, select the type of transaction to which the code applies.
    
    Transaction types indicate the direction of the movement of goods or services involved in the operation.
    
7.  In the **Description** field, enter a description for the code.
    
8.  In the **Effective From** field, enter or select the date when the code starts being effective.
    
9.  (Optional) In the **Effective Until** field, enter or select the date when the code stops being effective.
    
    When the CFOP code is no longer effective, the system stops considering it in the tax determination process. This date may be defined by a government authority.
    
10.  Click **Save**.
