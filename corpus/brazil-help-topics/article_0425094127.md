Before you start calculating taxes, be aware that:

-   The predefined tax types must be set up before use.
    
    For more information, see [Adding Tax Accounts to the Tax Types for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0425094310.html).
    
-   The predefined tax codes are ready to use.
    
    For the applicable cases, tax code records can include parameters relevant for tax determination, such as CST codes or minimum amounts for collection. For more information about parameter types, see [Parameter Types for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_163664116234.html).
    
-   You can also create your own tax code and tax type records.
    
    For more information, see [Tax Type and Tax Code Creation for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0425094314.html).
