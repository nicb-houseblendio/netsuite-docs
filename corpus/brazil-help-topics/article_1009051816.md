Note:

To access the SuiteTax Latam Engine - Brazil Records documentation in Brazilian Portuguese (Português do Brasil), see [SuiteTax Latam Engine - Brazil Records](https://system.netsuite.com/app/help/helpcenter.nl?fid=SuiteTaxLatamEngineBrazil_pt_BR.pdf).

The parameter types provided by SuiteTax Latam Engine - Brazil Records aren't editable.

If you have special taxation or accounting scenarios that require new tax codes, you must also create copies of the relevant parameter types. Before making a copy, create the new tax code to which to apply the parameter type copy. For more information about creating tax codes for Brazil, see [Tax Type and Tax Code Creation for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0425094314.html).

To identify which parameter types to copy, look for the predefined tax codes to which the parameter types apply on the table on [Parameter Types for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_163664116234.html). Copy the parameter types that apply to the new tax code you created.

For example, if you create a tax code based on the predefined CSRF\_RETIDO\_BR tax code, you'll need to copy the following parameter types:

-   CSLL Rate on CSRF
    
-   COFINS Rate on CSRF
    
-   PIS Rate on CSRF
    
-   Type of Date
    

#### To copy a parameter type from Brazil: {#procedure_1009051839}

1.  Go to Setup > Latam Tax Determination > Parameter Type.
    
2.  Click **View** next the parameter type you want to copy.
    
3.  From the **Actions** dropdown, select **Make Copy**.
    
    A new parameter type record opens, with most of the fields already filled in.
    
4.  In the **Name** field, enter a name for the parameter type.
    
5.  In the **Tax Code** field, clear the selection and select the new tax code you created.
    
6.  (Optional) In the **Description** field, enter additional information to differentiate the copied parameter type from the predefined parameter type.
    
7.  Click **Save**.
    

Important:

If the **Available For** field is set as **Tax Code**, add the copied parameter type to the new tax code record. For more information, see [Adding Tax Parameters to Tax Codes for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1019112537.html#subsect_37112938272).
