Note:

To access the Brazil Localization SuiteApp documentation in Brazilian Portuguese (Português do Brasil), see [Brazil Localization](https://system.netsuite.com/app/help/helpcenter.nl?fid=BrazilLocalization_pt_BR.pdf).

The Brazil Localization SuiteApp is a managed SuiteApp. Whenever there are enhancements or new features added, NetSuite automatically updates your account.

As a shared SuiteApp, Brazil Localization is only available for installation on authorized accounts. For more information, contact your account manager.

To install this SuiteApp, you must have permission and access to the SuiteApp Marketplace. For more information, see [Viewing SuiteApps in the SuiteApp Marketplace](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1539797977.html).

#### To install the Brazil Localization SuiteApp:

1.  In NetSuite, go to SuiteApps.
    
2.  In the **Search SuiteApps** field, enter **Brazil Localization**.
    
3.  Click **Brazil Localization**.
    
4.  At the top-right area of the SuiteApp details page, click **Install**.
    
5.  Wait for the installation to complete.
    
    Tip:
    
    After the installation is complete, verify the status of the import that creates the predefined records. For more information, see [Verifying the Import Status of the Brazil Localization Predefined Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_164002769902.html).
    

For more information about the SuiteApp installation process, see [Installing from the SuiteApp Marketplace](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1539799323.html).
