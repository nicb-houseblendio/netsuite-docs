Note:

To access the SuiteTax Latam Engine - Brazil Records documentation in Brazilian Portuguese (Português do Brasil), see [SuiteTax Latam Engine - Brazil Records](https://system.netsuite.com/app/help/helpcenter.nl?fid=SuiteTaxLatamEngineBrazil_pt_BR.pdf).

The FCP Brazil plug-in enables you to calculate the Fundo de Combate à Pobreza (FCP) tax on the purchases and sales of goods. FCP is an additional tax rate on the ICMS tax.

The following table summarizes the plug-in requirements and capabilities.

| **Plug-in Implementation** | FCP Brazil |
| --- | --- |
| **Tax Code's Internal Name** | FCP\_BR |
| **Requires Parent Tax Determination Rules** | No |
| **Requires Parameter Types** | Yes Requires a CST code. For more information, see [Parameter Types for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_163664116234.html). |
| **Supports Tax Basis and Tax Override** | Yes |
| **Adds Expenses** | Yes Adds shipping and handling costs, as well as expenses included in the Expenses subtab, to the tax calculation basis. |
| **Changes the Tax Calculation Basis** | Yes Adds the IPI tax amount to the FCP tax calculation basis if:
-   The tax determination rules record has a parent.
-   The parent tax determination rules have tax determination settings with an IPI tax code with the standard internal name.

 |
| **Records Tax Calculation History** | No |
