Note:

To access the Brazil Reports documentation in Brazilian Portuguese (Português do Brasil), see [Brazil Reports](https://system.netsuite.com/app/help/helpcenter.nl?fid=BrazilReports_pt_BR.pdf).

Before installing the Brazil Reports SuiteApp, you must meet the following requirements:

-   Ensure you're using an OneWorld account.
    
    For more information, see [Introduction to NetSuite OneWorld](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N266468.html).
    
-   Install the Tax Reporting Framework SuiteApp.
    
    Important:
    
    When you install the Tax Reporting Framework SuiteApp, you're required to install the SuiteTax Engine and SuiteTax Data Records SuiteApps. But if you only generate reports for Brazil, you don't need to install SuiteTax Engine or SuiteTax Data Records.
    
    For more information, see [Installing Tax Reporting Framework](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1528245293.html).
    
-   Install the LATAM File Builder SuiteApp.
    
    For more information, see [LATAM File Builder SuiteApp Installation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_37103202145.html).
    
-   Install the Brazil Localization SuiteApp.
    
    For more information, see [Brazil Localization SuiteApp Installation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_164002765830.html).
    
-   Check the **Use Account Numbers** box on your account's Accounting Preferences page.
    
    For more information, see [Chart of Account Numbering](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1440268.html).
    
-   Enable several features in NetSuite.
    

#### To enable features:

1.  Go to _Setup > Company > Enable Features_.
    
2.  On the **Company** subtab, check the **Multi-Language** box.
    
3.  On the **Accounting** subtab, check the **Accounting** box.
    
4.  On the **CRM** subtab, check the **Customer Relationship Management** box.
    
5.  On the **SuiteCloud** subtab, check the following boxes:
    
    -   Custom Records
        
    -   Advanced PDF/HTML Templates
        
    -   Client SuiteScript
        
    -   Server SuiteScript
        
6.  Click **Save**.
