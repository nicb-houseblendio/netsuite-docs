A tax alias mapping can include several parameter type alias mappings. Tax alias mappings are parent records of parameter type alias mappings.

Parameter types modify how NetSuite calculates a tax. A parameter type alias mapping matches a parameter type with a parameter alias. A parameter alias is a placeholder for the parameter in e-document templates. The alias indicates to NetSuite in which tag to enter the value you defined for the parameter type.

After you copy a tax alias mapping record, you must create the applicable parameter type alias mapping records.

For example, you copy the tax alias mapping for the csrfRetido tax alias and associate it with the tax code you created.

Then, from the copy, you must create the parameter alias mapping records for the applicable parameter aliases. To know which parameter types apply, you can check the original tax alias mapping record.

For the csrfRetido tax alias, the following parameters apply:

-   cofinsRetido
    
-   csllRetido
    
-   pisRetido
    
-   typeOfDate
    

#### To create a parameter type alias mapping for Brazil: {#procedure_1010095849}

1.  Open the predefined parameter type alias mapping for reference.
    
    1.  Go to Setup > Brazil Localization > Tax Alias Mapping.
        
    2.  Next to the tax alias mapping you used for reference, click **View**.
        
        The tax alias mapping record opens in view mode.
        
    3.  Click the **Parameter Alias Mapping** subtab.
        
    4.  Click **Edit** next to the parameter type alias mapping.
        
    5.  Review and take note of how the fields are filled.
        
2.  Create the parameter type alias mapping.
    
    1.  Go to Setup > Brazil Localization > Tax Alias Mapping.
        
    2.  Next to the tax alias mapping copy, click **View**.
        
        The tax alias mapping copy opens in view mode. For more information about tax alias mapping copies, see [Copying Tax Alias Mappings from Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1010110859.html).
        
    3.  Click the **Parameter Alias Mapping** subtab.
        
    4.  Click **New Parameter Type Alias Mapping**.
        
        A new parameter type alias mapping opens.
        
    5.  In the **Parameter Type** field, enter the new parameter type's name.
        
        For more information, see [Copying Parameters Types from Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1009051816.html).
        
    6.  In the **Parameter Alias** field, enter the parameter alias exactly as defined on the parameter type alias mapping you're using as reference.
        
    7.  In the **Value** field, enter the value exactly as defined on the parameter type alias mapping you're using as reference.
        
    8.  Click **Save**.
        
3.  Repeat the previous steps for all the applicable parameter aliases associated with the tax alias mapping.
