After you create a revenue recognition treatment for Brazil Deferred Revenue Recognition, define the corresponding recognition treatment rule. Define a rule for each revenue recognition treatment record you create.

For more information, see [Defining a Recognition Treatment Rule](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_155967498846.html).

#### To define a recognition treatment rule for Brazil:

1.  Go to _Setup > Accounting > Revenue > Recognition Treatment Rules > New_.
    
2.  In the **Rule Name** field, enter a unique name for the rule.
    
3.  In the **Description** field, enter a description of the rule.
    
4.  In the **Recognition Treatment** field, select the revenue recognition treatment record you created.
    
    For more information, see [Creating Recognition Treatments for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0713113814.html).
    
5.  In the **Criteria** subtab, select the fields and values required for applying the recognition treatment to a revenue element.
    
    For Brazil Deferred Revenue Recognition, do the following:
    
    1.  Set criteria for the source type field.
        
        1.  In the **Field** column, select **Source Type**.
            
            The Recognition Treatment Rule window opens.
            
        2.  In the **Source Type** field, select **any of**.
            
        3.  In the field below Source Type, select **Third Party**.
            
        4.  Click **Set**.
            
    2.  Set criteria for the subsidiary field.
        
        1.  In the **Field** column, select **Subsidiary**.
            
            The Recognition Treatment Rule window opens.
            
        2.  In the **Subsidiary** field, select **any of**.
            
        3.  In the field below Subsidiary, select the subsidiaries from your deferred revenue settings record.
            
        4.  Click **Set**.
            
6.  Click **Save**.
