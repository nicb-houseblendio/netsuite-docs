Note:

To access the Brazil Banking Integration SuiteApp documentation in Brazilian Portuguese (Português do Brasil), see [Brazil Banking Integration](https://system.netsuite.com/app/help/helpcenter.nl?fid=BrazilBankingIntegration_pt_BR.pdf).

The predefined bank connection for Banco do Brasil includes the required settings to connect your bank accounts with NetSuite. You must add the application credentials from your registration with the Banco do Brasil portal to complete these settings.

Before you complete the required bank connection settings, ensure you created the necessary API secrets to store the credentials. For more information, see [API Secrets for Bank Application Credentials](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0223051436.html#subsect_0223054911).

#### To add application information to a bank connection setting for Brazil:

1.  Go to Setup > Brazil Banking Integration > Bank Connection.
    
2.  Next to the bank connection for the purpose you want, click **View**.
    
3.  Click the **Settings** subtab.
    
4.  Add the application key information.
    
    1.  Next to the **BB\_APP\_KEY** setting, click **Edit**.
        
    2.  In the **Setting Value** field, enter the application key, as provided by Banco do Brasil.
        
    3.  Click **Save**.
        
        NetSuite saves the bank connection setting and returns to the bank connection record.
        
5.  Add the client ID credential.
    
    1.  Next to the **BB\_API\_CLIENT\_ID** setting, click **Edit**.
        
    2.  In the **Setting Value** field, enter the ID of the API secret you created to store the client ID.
        
    3.  Click **Save**.
        
        NetSuite saves the bank connection setting and returns to the bank connection record.
        
6.  Add the client secret credential.
    
    1.  Next to the **BB\_API\_SECRET** setting, click **Edit**.
        
    2.  In the **Setting Value** field, enter the ID of the API secret you created to store the client secret.
        
    3.  Click **Save**.
        
        NetSuite saves the bank connection setting and returns to the bank connection record.
