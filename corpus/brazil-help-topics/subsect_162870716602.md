Note:

To access the SuiteTax Latam Engine - Brazil Records documentation in Brazilian Portuguese (Português do Brasil), see [SuiteTax Latam Engine - Brazil Records](https://system.netsuite.com/app/help/helpcenter.nl?fid=SuiteTaxLatamEngineBrazil_pt_BR.pdf).

Before installing the SuiteTax Latam Engine - Brazil Records SuiteApp, you must meet the following requirements:

-   Ensure you're using a OneWorld account.
    
    For more information, see [Introduction to NetSuite OneWorld](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N266468.html).
    
-   Add **Portuguese (Brazil)** and **Latin American Spanish** as languages enabled for translation in the General Preferences page.
    
    If your account's default language is either Portuguese (Brazil) or Latin American Spanish, it won't appear on the list. If the language isn't listed, you don't need to add it. For more information, see [Enabling the Entry of Translation Strings for a Specific Language](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4164392746.html).
    
-   Install the SuiteTax Latam Engine SuiteApp.
    
    For more information, see [SuiteTax Latam Engine SuiteApp Installation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161970356182.html).
    
-   Enable the required features in NetSuite.
    

#### To enable features:

1.  Go to _Setup > Company > Enable Features_.
    
2.  On the **Tax** subtab, check the following boxes:
    
    -   Advanced Taxes
        
    -   SuiteTax
        
3.  On the **SuiteCloud** subtab, check the following boxes:
    
    -   Custom Records
        
    -   Client SuiteScript
        
    -   Server SuiteScript
        
4.  Click **Save**.
    

Important:

These prerequisites also apply to SuiteApp updates. To avoid update issues, keep these settings as specified on this topic.
