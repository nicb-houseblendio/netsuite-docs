Tax authorities require you to include the ICMS and FCP tax rates for transactions performed in the same state in the EFD ICMS IPI file.

The SuiteApp provides predefined ICMS intrastate tax rate records for each Brazilian state with rates for both ICMS and FCP. If you want to adjust the tax rates for a state, or set different rates for specific items, you can edit the predefined records.

Warning:

NetSuite doesn't consider the tax rates you enter in ICMS intrastate tax rate for SPED records when calculating ICMS or FCP tax amounts on any transactions. The system only uses these records to include the rates in EFD ICMS IPI files, as required by tax authorities.

#### To adjust the ICMS intrastate tax rate for SPED reports:

1.  Go to Setup > Brazil Reports > ICMS Intrastate Tax Rate for SPED.
    
2.  Next to the state for which you want to change the ICMS and FCP tax rates, click **Edit**.
    
3.  In the **ICMS Tax Rate** field, enter the ICMS tax rate for the selected state.
    
4.  In the **FCP Tax Rate** field, enter the FCP tax rate for the selected state.
    
    This percentage is an additional part of the ICMS and may not apply in every state. If not applicable, enter **0**.
    
5.  If you want to set intrastate ICMS and FCP tax rates for specific items, click the **Tax Rate per Item** subtab.
    
    1.  In the **Item Code** field, select an item code to define ICMS and FCP intrastate tax rates.
        
        The item code list includes Mercosur Common Nomenclature (MCN) and service codes.
        
    2.  In the **ICMS Tax Rate** field, enter the ICMS tax rate for the selected state.
        
    3.  In the **FCP Tax Rate** field, enter the FCP tax rate for the selected item.
        
        This percentage is an additional part of the ICMS and may not apply in every state. If not applicable, enter **0**.
        
    4.  Click **Add**.
        
        Repeat these steps to add rates for specific items.
        
6.  Click **Save**.
