To cover taxation scenarios that apply to specific items in your transactions, you can create tax determination rules records for the following types of codes:

-   Mercosur Common Nomenclature (MCN) or service codes
    
-   Código Fiscal de Operações e de Prestações (CFOP) codes
    

For example, you can create rules to apply a lower or zero IPI tax rate on products with MCN codes that qualify for a tax benefit.

Before you create tax determination rules applicable for specific codes, do the following:

-   If you want to apply the rules to MCN or service codes, ensure you associated the code with the items to which the rules should apply.
    
    For more information, see [Creating Items for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_164684791452.html).
    
-   If you want to apply the rules to CFOP codes, you may want to create specific CFOP code records.
    
    For more information, see [Creating CFOP Codes for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0704090833.html).
    

#### To create tax determination rules for specific CFOP, MCN, or service codes:

1.  Go to Setup > Latam Tax Determination > Tax Determination Rules > New.
    
    Tip:
    
    To cover similar scenarios, copy an existing tax determination rules record and only adjust the fields you need, instead of creating a new record.
    
2.  Fill in the relevant information.
    
    For more information, see [Creating Tax Determination Rules in the SuiteTax Latam Engine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_162153526964.html).
    
3.  To apply the rules to an item associated with a specific MCN or service code, in the **Item Code** field, select the MCN or service code.
    
4.  To apply the rules to items with a specific CFOP, in the **Operation Code** field, enter the name of the CFOP code record.
    
5.  Click **Save**.
    

After you create the tax determination rules, you should complete them by creating the necessary tax determination settings. In the settings, you can define the taxes to which the rules apply, add tax rates, and additional parameters for tax calculation. For more information, see the following help topics:

-   [Creating Tax Determination Settings in the SuiteTax Latam Engine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_162153528705.html)
