Note:

To access the Brazil Localization SuiteApp documentation in Brazilian Portuguese (Português do Brasil), see [Brazil Localization](https://system.netsuite.com/app/help/helpcenter.nl?fid=BrazilLocalization_pt_BR.pdf).

Before installing the Brazil Localization SuiteApp, you must meet the following requirements:

-   Ensure you're using an OneWorld account.
    
    For more information, see [Introduction to NetSuite OneWorld](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N266468.html).
    
-   Ensure the following standard roles are active in your account:
    
    -   A/P Clerk
        
    -   A/R Clerk
        
-   Install the Electronic Invoicing SuiteApp.
    
    For more information, see [Installing and Setting Up Electronic Invoicing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4592549826.html).
    
-   Install the LATAM E-Document Certification SuiteApp.
    
    For more information, see [LATAM E-Document Certification SuiteApp Installation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160320094693.html).
    
-   Install the Brazil Certification Tax Authorities SuiteApp.
    
    For more information, see [Brazil Certification Tax Authorities SuiteApp Installation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160518990089.html).
    
-   Install the SuiteTax Latam Engine SuiteApp.
    
    For more information, see [SuiteTax Latam Engine SuiteApp Installation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161970356182.html).
    
-   Install the SuiteTax Latam Engine - Brazil Records SuiteApp.
    
    For more information, see [SuiteTax Latam Engine - Brazil Records SuiteApp Installation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_162870562095.html).
    
-   Install the Localization Assistant SuiteApp.
    
    For more information, see [Installing the Localization Assistant SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163092361565.html).
    
-   Install the LATAM File Builder SuiteApp.
    
    For more information, see [LATAM File Builder SuiteApp Installation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_37103202145.html).
    
-   Add **Portuguese (Brazil)** and **Latin American Spanish** as languages enabled for translation in the General Preferences page.
    
    If your account's default language is either Portuguese (Brazil) or Latin American Spanish, it won't appear on the list. If the language isn't listed, you don't need to add it. For more information, see [Enabling the Entry of Translation Strings for a Specific Language](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4164392746.html).
    
-   If you have the Automated Intercompany Management feature enabled, define a default cost category to associate with new item records you create.
    
    The default cost category is an accounting preference. For more information, see [Accounting Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1384948.html) and [Items/Transactions Accounting Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1387022.html).
    
-   Enable several features in NetSuite.
    

#### To enable features:

1.  Go to _Setup > Company > Enable Features_.
    
2.  On the **Company** subtab, check the following boxes:
    
    -   Multiple Units of Measure
        
    -   Multi-Language
        
    -   Multiple Currencies
        
    -   File Cabinet
        
3.  On the **Accounting** subtab, check the following boxes:
    
    -   Accounting
        
    -   Accounting Periods
        
    -   Installments
        
4.  On the **Tax** subtab, check the following boxes:
    
    -   Advanced Taxes
        
    -   SuiteTax
        
5.  On the **Transactions** subtab, check the **Advanced Shipping** box.
    
6.  On the **Items & Inventory** subtab, check the **Inventory** box.
    
7.  If you manufacture goods, on the **Items & Inventory** subtab, check the **Assembly Items** box.
    
8.  On the **CRM** subtab, check **Opportunities** box.
    
9.  On the **SuiteCloud** subtab, check the following boxes:
    
    -   Custom Records
        
    -   Advanced PDF/HTML Templates
        
    -   Client SuiteScript
        
    -   Server SuiteScript
        
    -   Custom GL Lines
        
    -   Custom Transactions
        
    -   REST Web Services
        
10.  Click **Save**.
     

Important:

These prerequisites also apply to SuiteApp updates. To avoid update issues, keep these settings as specified on this topic.
