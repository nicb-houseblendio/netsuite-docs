To access the SuiteTax Latam Engine - Brazil Records documentation in Brazilian Portuguese (Português do Brasil), see [SuiteTax Latam Engine - Brazil Records](https://system.netsuite.com/app/help/helpcenter.nl?fid=SuiteTaxLatamEngineBrazil_pt_BR.pdf).

The IRRF Importação Brazil plug-in enables you to calculate the Imposto de Renda Retido na Fonte (IRRF) tax on services acquired from legal entities.

The following table summarizes the plug-in requirements and capabilities.

| **Plug-in Implementation** | IRRF PJ Brazil |
| --- | --- |
| **Tax Code's Internal Name** | IRRF\_PJ\_RETIDO\_BR IRRF\_PJ\_RETIDO\_COMPRA\_BR |
| **Requires Parent Tax Determination Rules** | No |
| **Requires Parameter Types** | Yes Requires the following parameters:
-   Minimum Collection Amount
-   Type of Date

For more information, see [Parameter Types for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_163664116234.html). |
| **Supports Tax Basis and Tax Override** | Yes |
| **Adds Expenses** | No |
| **Changes the Tax Calculation Basis** | No |
| **Records Tax Calculation History** | Yes Stores information about each transaction on which the plug-in runs, such as:

-   Customer or vendor
-   Date
-   Tax amount
-   Tax rate

The tax calculation history record enables NetSuite to keep track of the IRRF PJ amounts calculated for each subsidiary and vendor in a day. When the amount reaches the minimum, NetSuite adds the IRRF PJ to the first item from the transaction on which the minimum amount was reached. If you create more transactions after the minimum amount is reached, the system withholds IRRF PJ on each transaction. |
