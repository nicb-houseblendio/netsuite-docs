Before you generate EFD ICMS IPI files, ensure you meet the following prerequisites:

-   Review the ICMS and FCP tax rates for transactions performed within the same state and adjust them as needed.
    
    For more information, see [Adjusting the ICMS Intrastate Tax Rate for SPED Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0911104931.html).
    
-   If required by the state tax authority, define posting notes for the ICMS tax.
    
    For more information, see [Defining ICMS Posting Notes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1018030229.html).
    
-   Create the ICMS assessment record and generate the ICMS assessment report.
    
    For more information, see [Assessing ICMS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0512043231.html).
    
-   Create the inventory assessment record and generate the inventory ownership and custody report.
    
    For more information, see [Inventory Ownership and Custody Report for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0509045326.html).
    
-   If you manufacture goods:
    
    -   Ensure you've enabled manufacturing-related features, such as:
        
        -   Advanced Bill of Materials
            
        -   Assembly Items
            
        -   Manufacturing Work in Progress
            
        -   Outsourced Manufacturing
            
        -   Work Orders
            
        
        For more information, see [Manufacturing Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1506100009.html) and [Enabling Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N232138.html).
        
    -   Create the IPI assessment record and generate the IPI assessment report.
        
        For more information, see [Assessing IPI](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0513020340.html).
        
-   Ensure that the transactions you enter in NetSuite meet these criteria for inclusion in the EFD ICMS IPI file:
    
    | \- | **Sales transactions** | **Purchase transactions** |
    | --- | --- | --- |
    | **Calculated taxes** | 
    -   ICMS
    -   IPI
    -   Both ICMS and IPI
    
     | 
    
    -   ICMS
    -   IPI
    -   Both ICMS and IPI
    
     |
    | **E-document category** | 
    
    -   Electronic invoice for goods
    -   SAT cash receipt
    
     | 
    
    -   Electronic bill of lading
    -   Electronic invoice for goods
    -   Tax, expense, or utility bill
    
     |
    | **E-document model** | 
    
    -   Model 55 required for the electronic invoice for goods category
    -   Model 55, 59, or 65 required for the SAT cash receipt category
    
     | 
    
    -   Model 57 or 67 required for the electronic bill of lading category
    -   Model 55 required for the electronic invoice for goods category
    -   Model 06, 66, 28, 29, or 21 required for the tax, expense, or utility bill category
    
     |
    | **E-document status** | Certified status required for electronic invoices for goods | Certified status required for electronic invoices generated from import bills |
