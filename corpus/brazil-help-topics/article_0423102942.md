Note:

To access the Brazil Localization SuiteApp documentation in Brazilian Portuguese (Português do Brasil), see [Brazil Localization](https://system.netsuite.com/app/help/helpcenter.nl?fid=BrazilLocalization_pt_BR.pdf).

If you receive electronic bank payments with Brazil Banking Integration, you must enable the SuiteApp to gather information from your account's records. For more information about the Brazil Banking Integration SuiteApp, see [Brazil Banking Integration](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_140904677.html).

To make the data retrieval possible, Brazil Localization provides the Brazil Data for Banking plug-in file, and you must create the plug-in implementation record to run it.

The Brazil Data for Banking plug-in finds information in your customer and transaction records and provides this data to Brazil Banking Integration. Then, the SuiteApp leverages this information when communicating your receivable payments to the bank.

The script file for the Brazil Data for Banking plug-in is available in your account's File Cabinet. For more information about plug-in implementations, see [Creating a New Plug-in Implementation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4232566030.html).

#### To create the Brazil Customer Data for Banking plug-in implementation:

1.  Go to _Customization > Plug-ins > Plug-in Implementations > New_.
    
2.  In the **Script File** field, enter **brl\_pl\_bis\_data\_retrv.js**, then select the matching result.
    
3.  Click **Create Plug-in Implementation**.
    
4.  On the Select Plug-in Type page, click **Brazil Banking Data Retrieval**.
    
5.  On the New Plug-in Implementation page, do the following:
    
    1.  In the **Name** field, enter **Brazil Data for Banking**.
        
    2.  In the **ID** field, enter **brl\_banking\_data\_retrieval**.
        
    3.  In the **Status** field, select **Released**.
        
    4.  In the **Log Level** field, select **Debug**.
        
    5.  In the **Description** field, enter **Retrieves data from NetSuite records that is required during banking integration.**.
        
6.  Click **Save**.
