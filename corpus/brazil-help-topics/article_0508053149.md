Brazil Reports provides SPED file types that you can associate with file layouts.

By default, the SuiteApp associates the SPED file types with their respective predefined file layouts. For example, the EFD - Contribuições file type is associated with the EFD Contribuições v6 Consolidado and EFD Contribuições v6 Detalhado file layouts.

When you create a custom file layout, you must associate it with a SPED file type so you can generate SPED files with it.

Note:

When you clone a file layout, NetSuite automatically associates the clone with the SPED file type from the original layout. For more information, see [Cloning File Layouts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0419045916.html).

For more information about file layouts, see [Creating File Layouts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0929115539.html).

#### To associate file layouts with a SPED file type:

1.  Go to Setup > Brazil Reports > SPED File Type.
    
2.  Next to the SPED file type you want to associate with the file layout, click **Edit**.
    
3.  In the **Custom File Layout** field, select one or multiple file layouts to associate with this type of SPED file.
    
4.  Click **Save**.
    

NetSuite lists the file layout as an option in the File Layout field in SPED file records with this type. For more information, see [Generating SPED Files](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_164874849258.html).
