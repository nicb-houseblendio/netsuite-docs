Note:

To access the Brazil Banking Integration SuiteApp documentation in Brazilian Portuguese (Português do Brasil), see [Brazil Banking Integration](https://system.netsuite.com/app/help/helpcenter.nl?fid=BrazilBankingIntegration_pt_BR.pdf).

Create banking integration preferences to define account-wide settings to use the Brazil Banking Integration SuiteApp. You can only have one banking integration preferences record in your NetSuite account.

Before you define your banking integration preferences, ensure you created an API secret to encrypt sensitive banking information, such as your account number. For more information, see [API Secret for the Banking Integration Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0223051436.html#subsect_0223054825).

#### To define banking integration preferences for Brazil:

1.  Go to Setup > Brazil Banking Integration > Banking Preferences > New.
    
2.  In the **API Secret for Encryption** field, enter the ID of the API secret you want to use for encryption.
    
3.  In the **Banking Data Retrieval Plug-in Implementation** field, select **Brazil Data for Banking**.
    
    For more information about creating this plug-in implementation, see [Creating the Brazil Data for Banking Plug-in Implementation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0423102942.html).
    
4.  Click **Save**.
