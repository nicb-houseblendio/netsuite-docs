If you have the Brazil Banking Integration SuiteApp installed in your account, you can use it to pay the following tax bills:

-   Documento de Arrecadação de Receitas Federais (DARF)
    
-   Guia da Previdência Social (GPS)
    
-   Guia de Recolhimento da União (GRU)
    

For more information, see [Brazil Banking Integration](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_140904677.html).

Important:

If you installed the Brazil Reports SuiteApp before the Brazil Banking Integration SuiteApp, you must import the predefined records that enable tax bill payments. For more information, see [Importing Banking Integration Records for Tax Bills](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0312050654.html).

To make the payments, you need to add banking integration information to your tax bills.

#### To add banking integration information to tax bills:

1.  Go to Transactions > Payables > Tax Bills.
    
2.  Next to the tax bill you want, click **Edit**.
    
3.  Review the **Revenue Code** field. If it's empty, select the revenue code that applies to the payable tax.
    
    If the revenue code you want isn't on the list, create a record for it. For more information, see [Creating Tax Revenue Codes for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0123020924.html).
    
4.  If the bank requires a reference number to enable the payment integration, in the **Reference Number for Tax Collection Form** field, enter the reference number.
    
    You're only required to enter the reference number for the payment of the GRU and for DARF with specific revenue codes.
    
5.  Click the **Banking Integration for Brazil** subtab.
    
6.  In the **Payment Method** column, select a payment method with banking integration.
    
    -   If the tax bill represents a DARF, **DARF com Integração Bancária**.
        
    -   If the tax bill represents a GPS, **GPS com Integração Bancária**.
        
    -   If the tax bill represents a GRU, **GRU com Integração Bancária**.
        
7.  If the tax bill represents a GRU tax collection form, in the **Bar Code for Banking Integration** field, enter the string of characters that represents the GRU bar code.
    
8.  Click **Save**.
    
    Tip:
    
    After you finish adding the banking information to your tax bills, you can process them for accounts payable automation. For more information, see [Processing Accounts Payable Payments for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0902020810.html).
