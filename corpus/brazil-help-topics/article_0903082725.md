Note:

To access the SuiteTax Latam Engine - Brazil Records documentation in Brazilian Portuguese (Português do Brasil), see [SuiteTax Latam Engine - Brazil Records](https://system.netsuite.com/app/help/helpcenter.nl?fid=SuiteTaxLatamEngineBrazil_pt_BR.pdf).

The COFINS Brazil plug-in enables you to calculate the Contribuição para o Financiamento da Seguridade Social (COFINS) tax on the purchases and sales of goods and services.

The following table summarizes the plug-in requirements and capabilities.

| **Plug-in Implementation** | COFINS Brazil |
| --- | --- |
| **Tax Code's Internal Name** | COFINS\_BR |
| **Requires Parent Tax Determination Rules** | No |
| **Requires Parameter Types** | Yes Requires a CST code. For more information, see [Parameter Types for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_163664116234.html). |
| **Supports Tax Basis and Tax Rate Override** | Yes |
| **Adds Expenses** | Yes Adds shipping and handling costs, as well as expenses included in the Expenses subtab, to the tax calculation basis. |
| **Changes the Tax Calculation Basis** | Yes
-   Reduces the COFINS tax calculation basis if the tax determination rules have:
    -   A tax determination settings record with:
        -   A COFINS tax code with the standard internal name.
        -   A CST code parameter type that enables the COFINS calculation. Some CST codes don't calculate COFINS.
    -   A tax determination settings record with:
        -   A COFINS tax code with the standard internal name.
        -   The Reduced PIS or COFINS Calculation Basis parameter type associated with a parameter value that represents the reduced tax calculation basis.
-   Subtracts the ICMS tax amount from the COFINS tax calculation basis if:
    -   The tax determination rules record has a parent.
    -   The parent tax determination rules have tax determination settings with an ICMS tax code with the standard internal name.
    -   The ICMS Exclusion parameter type is associated with the COFINS tax code.
-   Subtracts the ISS tax amount from the COFINS tax calculation basis if:
    -   The tax determination rules record has a parent.
    -   The parent tax determination rules have tax determination settings with:
        -   An ISS tax code with the standard internal name.
        -   The ISS Exclusion parameter type.

 |
| **Records Tax Calculation History** | No |
