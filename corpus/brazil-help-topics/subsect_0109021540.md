Note:

To access the Brazil Banking Integration SuiteApp documentation in Brazilian Portuguese (Português do Brasil), see [Brazil Banking Integration](https://system.netsuite.com/app/help/helpcenter.nl?fid=BrazilBankingIntegration_pt_BR.pdf).

The Brazil Banking Integration SuiteApp is a managed SuiteApp. Whenever there are enhancements or new features added, NetSuite automatically updates your account.

As a shared SuiteApp, Brazil Banking Integration is only available for installation on authorized accounts. For more information, contact your account manager.

To install this SuiteApp, you must have permission and access to the SuiteApp Marketplace. For more information, see [Viewing SuiteApps in the SuiteApp Marketplace](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1539797977.html).

Before you attempt to install Brazil Banking Integration, ensure you meet the prerequisites for installation. For more information, see [Prerequisites for Installing the Brazil Banking Integration SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_0109021438.html).

#### To install the Brazil Banking Integration SuiteApp:

1.  In NetSuite, go to SuiteApps.
    
2.  In the **Search SuiteApps** field, enter **Brazil Banking Integration**.
    
3.  Click **Brazil Banking Integration**.
    
4.  At the top-right area of the SuiteApp details page, click **Install**.
    
5.  Wait for the installation to complete.
    
    Tip:
    
    After the installation is complete, verify the status of the import that creates the predefined records. For more information, see [Verifying the Import Status of the Brazil Banking Integration Predefined Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_0109021611.html).
    

For more information about the SuiteApp installation process, see [Installing from the SuiteApp Marketplace](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1539799323.html).
