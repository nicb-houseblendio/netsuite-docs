Before you generate electronic invoices in NetSuite for Brazil, you must set up the generation and certification of your e-documents.

-   Ensure you have the required SuiteApps installed:
    
    -   Electronic Invoicing
        
    -   LATAM E-Document Certification
        
    -   Brazil Certification Tax Authorities
        
    
    These SuiteApps are prerequisites for installing Brazil Localization. For more information, see [Prerequisites for Installing the Brazil Localization SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_164002766279.html).
    
-   Set up accounting periods.
    
    For more information, see [Manage Accounting Periods Page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1445839.html).
    
-   Upload your digital certificate to NetSuite.
    
    Brazil Localization is compatible with A1 certificates. Before uploading the digital certificates, ensure the certificates include the private key and all the certificates in the certification path. For more information, see [Uploading Digital Certificates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1542656620.html).
    
-   Set up your electronic invoicing preferences.
    
    You should set up preferences such as the email template and sender. For more information, see [Setting Up Electronic Invoicing Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0619104200.html).
    
-   Create an e-document package for Brazil.
    
    For more information, see [Creating E-Document Packages](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4576918342.html).
    
-   Create an e-document sending method for Brazil.
    
    For more information, see [Creating the E-Document Sending Method for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0824111532.html).
    
-   Create e-document templates for each tax authority and type of operation you perform.
    
    For more information, see [Creating Outbound E-Document Templates for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0824111606.html).
    
-   Create additional information presets for electronic invoices.
    
    For more information, see [Creating Additional Information Presets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0804022657.html).
    
-   Create estimated taxes for electronic invoices
    
    For more information, see [Creating Estimated Taxes for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0805015551.html).
    
-   Set up transaction natures for Brazil.
    
    For more information, see [Setting Up Transaction Natures for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_164139202330.html).
    
-   (Optional) To narrow down the application of CFOP codes, create CFOP determination rules.
    
    For more information, see [CFOP Determination Rules](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0112044242.html).
    
-   Associate the Brazil Certification Monitoring Plug-in with tax authorities to which you send e-documents for certification.
    
    For more information, see [Associating the Brazil Certification Monitoring Plug-in with Tax Authorities](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1116114637.html).
    
-   Associate certification service operations with e-document templates.
    
    For more information, see [Setting Up Certification Service Operations for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0327111232.html).
    
-   Define e-document certification settings for your Brazilian subsidiaries.
    
    For more information, see [Defining E-Document Certification Settings](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160527596799.html).
    
-   Create e-document series for your e-document certification settings.
    
    For more information, see [Creating E-Document Series](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_164200031457.html).
    
-   Define e-document sending preferences for your e-document certification settings.
    
    For more information, see [Defining E-Document Sending Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_164200056155.html).
    
-   If you certify electronic invoices for services, add municipal taxation codes for the tax authorities with which you certify the e-documents.
    
    For more information, see [Adding Municipal Taxation Codes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0503085557.html).
    
-   If you send a high volume of electronic invoices for certification, set up your account's e-document certification processing capacity.
    
    You can set up the processing capacity of the script records that send your e-documents for certification. For more information, see [Setting the E-Document Certification Requests' Processing Capacity](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161012535356.html).
    
-   If you must certify electronic invoices in sequential order, set up e-document sequential order sending.
    
    For more information, see [Setting Up Sequential Order Sending](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161037151577.html).
    
-   If you certify electronic invoices with the following tax authorities or third-party standards, add the certification custom fields.
    
    -   Florianópolis (SC)
        
    -   GIAP standard
        
    -   Rio Branco (AC)
        
    -   SAATRI standard
        
    
    For more information, see [Certification Custom Fields for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0703051829.html).
    
-   If you certify electronic invoices for services with Manaus (AM), set up the service codes that apply to your business.
    
    For more information, see [Service Codes for Manaus (AM)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_2115311951.html).
    
-   If you want to send certified e-documents to customers using a specific email template, define the template for each of your subsidiaries.
    
    If you don't define an e-document email custom template, NetSuite uses a standard template to send the e-document. For more information, see [E-Document Email Custom Templates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158045349260.html).
    
-   If you want a specific employee to appear as the sender of the emails of the e-documents you certify with the subsidiary, define the employee on the subsidiary's electronic invoicing preferences.
    
    If you don't define an employee, the name and email address of the user who sent the e-document will be shown as the sender. For more information, see [Selecting a Designated E-Document Sender](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4592468256.html).
