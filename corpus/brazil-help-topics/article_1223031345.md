If you generate and register bank slips with the Brazil Localization SuiteApp, set up the bank slip file generation.

#### To set up bank slips generation with Brazil Localization:

1.  Go to Setup > Brazil Localization > Bank.
    
2.  Next to the bank you want, click **Edit**.
    
3.  In the **Bank Slip Folder ID** field, enter the internal ID of the File Cabinet folder in which to save the generated bank slips.
    
    To find a File Cabinet folder's internal ID:
    
    1.  Set the **Show Internal IDs** preference.
        
        For more information, see [Setting the Show Internal IDs Preference](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3420345.html).
        
    2.  Go to _Documents > Files > File Cabinet_.
        
    3.  Find the folder to which you want to save the bank slips.
        
    4.  Verify the folder's internal ID on the **Internal ID** column.
        
        Take note of the ID to enter it in the **Bank Slip Folder ID** field.
        
        When you enter an internal ID in this field, the **Bank Slip Folder** field displays the name of the folder that matches the ID you entered.
        
    
    If you don't select a folder, NetSuite saves bank slips in the User Documents folder (ID -20).
    
4.  In the **Bank Slip Plug-In** field, select the Bank Slip plug-in implementation you want to use with this bank.
    
    The plug-in implementation contains the methods and parameters required to generate the bank slips for this bank. This field only lists plug-in implementation records with the Bank Slip plug-in type.
    
5.  In the **Bank Slip Template** field, select the bank slip template from your account's file cabinet.
    
    NetSuite uses the template to generate bank slips for the bank. The Brazil Localization SuiteApp provides predefined templates for a few banking institutions. For more information, see [Finding Predefined Bank Slip Templates for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0512054058.html).
    
6.  In the **Logo** field, select or upload the logo image you want to use on all bank slips generated for this bank.
    
    If you've already uploaded the logo your File Cabinet, select it. If not, you can upload it directly from the bank record. NetSuite supports common image file formats like BMP, GIF, JPG, and PNG.
    
    To upload the logo image:
    
    1.  Hover over the **File** field.
        
    2.  Click the plus icon ![Plus sign icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/CountrySpecificFeatures/Plus_Icon.png).
        
        The File window opens.
        
    3.  In the **Attach From** field, select **Computer** to attach a file from your local storage, or **Web** to attach a file by linking it from the internet.
        
    4.  In the **File Name** field, enter a name for the logo.
        
    5.  In the **Folder** field, select the File Cabinet folder to which to save the file.
        
    6.  If you're attaching a file from the web, in the **URL** field, enter the URL to the file.
        
    7.  If you're attaching a file from your computer, in the **Select File** field, click **Browse** and find the file you want to upload to NetSuite.
        
    8.  In the **Character Encoding** field, select the proper character encoding for the file.
        
    9.  Click **Save**.
        
7.  Click **Save.**
