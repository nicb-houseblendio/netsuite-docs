To access the Brazil Localization SuiteApp documentation in Brazilian Portuguese (Português do Brasil), see [Brazil Localization](https://system.netsuite.com/app/help/helpcenter.nl?fid=BrazilLocalization_pt_BR.pdf).

The Brazil Localization and SuiteTax Latam Engine - Brazil Records SuiteApps provide predefined settings to support standard taxation and tax accounting scenarios.

For special taxation or tax accounting scenarios for the taxes covered by the SuiteApp, you can define the settings to calculate the taxes.

Examples of special tax scenarios include tax benefits, such as the Regime Especial de Incentivos para o Desenvolvimento da Infraestrutura (REIDI) benefit.

Special tax accounting scenarios could be choosing to post a tax on a given context to a different account. For example, you may want to post the ICMS tax on diesel fuel to a different account than the ICMS on other products.

If you need to calculate or account for taxes in similar scenarios, you must:

-   Create a new tax type record.
    
    For more information, see [Creating Tax Types for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1019112529.html).
    
-   Create a new tax code record.
    
    For more information, see [Creating Tax Codes for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1019112537.html).
    
-   Copy the applicable parameter types.
    
    For more information, see [Copying Parameters Types from Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1009051816.html).
    
-   If the copied parameter types are set as available for tax codes, add the applicable tax parameters to the new tax codes.
    
    For more information, see [Adding Tax Parameters to Tax Codes for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1019112537.html#subsect_37112938272).
    
-   Create or edit tax determination rules for the new tax codes.
    
    By default, the SuiteTax Latam Engine - Brazil Records SuiteApp's tax determination rules don't apply to new tax types and codes.
    
-   Copy the applicable tax alias mappings.
    
    For more information, see [Copying Tax Alias Mappings from Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1010110859.html).
    
-   Create the applicable parameter type alias mappings.
    
    For more information, see [Creating Parameter Type Alias Mappings for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1010110920.html).
