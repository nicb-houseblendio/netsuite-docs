To classify revenues subject to ICMS or ISS, you need to create records for the revenue codes defined by the states or municipalities where you do business.

#### To create a tax revenue code for Brazil:

1.  Go to Lists > Brazil Reports > Revenue Codes > New
    
2.  In the **Tax Assessment** field, select the tax assessments for which you want this tax revenue code to appear.
    
    If you want to list this revenue code for all types of assessments, leave this field blank.
    
    When you generate a tax bill, NetSuite displays the revenue codes associated with the tax assessment you're billing.
    
3.  In the **Code** field, enter the code as defined by the tax authority.
    
4.  In the **Description** field, enter a description for the revenue code.
    
5.  (Optional) In the **Effective Until** field, enter or select the date in which the revenue code stops being effective.
    
    NetSuite doesn't list expired revenue codes on tax bills.
    
6.  Click **Save**.
