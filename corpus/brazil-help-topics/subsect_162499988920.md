Note:

To access the Brazil Certification Tax Authorities SuiteApp documentation in Brazilian Portuguese (Português do Brasil), see [Brazil Certification Tax Authorities](https://system.netsuite.com/help/helpcenter/shared_resources/PDF/BrazilCertificationTaxAuthorities_pt_BR.pdf).

When using the Brazil Certification Tax Authorities SuiteApp, be guided by the following recommendations:

-   When installing the SuiteApp, enable all the required features before installing the required SuiteApps for Brazil Certification Tax Authorities SuiteApp.
    
    For more information, see [Brazil Certification Tax Authorities SuiteApp Installation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160518990089.html).
    
-   When installing the SuiteApp, install the required SuiteApps for Brazil before installing the Brazil Certification Tax Authorities SuiteApp.
    
    For more information, see [Brazil Certification Tax Authorities SuiteApp Installation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160518990089.html).
    
-   When available, enable the XSD validation for the e-documents you generate and send for certification with the Brazil Certification Tax Authorities SuiteApp.
    
    For more information, see [Predefined E-Document Validation Files for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_163283858825.html).
    
-   When entering item descriptions on invoices that you send to the Barueri (SP) tax authority for certification, press Enter to insert line breaks. The SuiteApp automatically removes other forms of line breaks, such as pipes, `<br />`, and `\n`.
    
-   When setting up the receiver acknowledgment feature, enable the automatic sending of e-document awareness events.
    
    For more information, see [Adding Receiver Acknowledgment Custom Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0612114344.html).
    
-   When sending a receiver acknowledgment event, ensure you're sending it before the deadline set by the Secretaria da Fazenda. The tax authority defines different deadlines for each type of event.
