Create a new tax code if you have special taxation or accounting scenarios.

#### To create a tax code for Brazil: {#procedure_0425022851}

1.  Open the predefined tax code for reference.
    
    1.  Go to _Setup > Tax > Tax Codes_.
        
    2.  Click **View** next to the tax code.
        
    3.  Review and take note of how the fields are filled.
        
2.  Create a new tax code.
    
    1.  Go to _Setup > Tax > Tax Codes_.
        
    2.  In the **Name** field, enter a name for the tax code.
        
        The name must be different from the existing tax code. For example, if you're creating an alternate of the CSRF\_RETIDO\_BR tax code for the REIDI benefit, you could name it CSRF\_RETIDO\_REIDI\_BR.
        
    3.  In the **Description** field, enter a summary about the tax code.
        
    4.  In the **Tax Type** field, select the corresponding tax type.
        
    5.  In the **Internal Name** field, enter the internal name exactly as defined on the tax code you're using as a reference.
        
        The internal name enables the SuiteTax Latam Engine plug-in to identify this tax code during the tax determination process.
        
    6.  Click **Save**.
        
        NetSuite saves the tax code record. More fields appear after saving.
        
    7.  Click **Edit**.
        
    8.  In the **SuiteTax Latam Engine Plug-in Implementation** field, select the same plug-in that's selected on the tax code you're using as a reference.
        
    9.  Click **Save**.
        

## Adding Tax Parameters to Tax Codes for Brazil {#subsect_37112938272}

After you create a tax code, add the applicable tax parameters to modify how NetSuite calculates the tax.

Before adding tax parameters to a tax code, ensure your account has the parameter types that apply to the tax code. You may need to copy the predefined parameter types to apply them to a new tax code. For more information, see [Copying Parameters Types from Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1009051816.html).

#### To add tax parameters to tax codes for Brazil: {#procedure_1019112653}

1.  Go to _Setup > Tax > Tax Codes_.
    
2.  Click **Edit** next to the tax code you created.
    
3.  Click the **Tax Parameters** subtab.
    
4.  In the **Parameter Type** column, select the type of parameter you want.
    
5.  If the parameter type requires a value, in the **Parameter Value** column, enter the corresponding value.
    
6.  Click **Add**.
    
7.  Click **Save**.
