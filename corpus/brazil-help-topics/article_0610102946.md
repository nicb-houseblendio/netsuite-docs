Note:

To access the Brazil Localization SuiteApp documentation in Brazilian Portuguese (Português do Brasil), see [Brazil Localization](https://system.netsuite.com/app/help/helpcenter.nl?fid=BrazilLocalization_pt_BR.pdf).

Before you start using Brazil Localization's features, complete the required settings:

-   Enable and set up the Brazil GL lines plug-in.
    
    The Brazil GL lines plug-in posts additional lines to the general ledger impact, ensuring that your general ledger complies with Brazilian accounting requirements. For more information, see [Brazil GL Lines Plug-in Deployment](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_164746251448.html).
    
-   To split withheld amounts equally between the installments from your transactions, enable the splitting option on the tax types for withheld taxes.
    
    For more information, see [Enabling Withheld Tax Amounts Splitting Between Installments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_3152139661.html).
    
-   Add tax accounts to the tax types for Brazil.
    
    For more information, see [Adding Tax Accounts to the Tax Types for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0425094310.html).
    
-   If you have special taxation or tax accounting scenarios, create additional tax-related records.
    
    For more information, see [Setup for Special Taxation and Tax Accounting for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1010052645.html).
    
-   Set up tax determination rules for Brazil.
    
    For more information, see [Tax Determination Rules Setup for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_162870753966.html).
    
-   If you generate reports with the Brazil Reports SuiteApp, set up your account records to appear in Brazilian reports.
    
    For more information, see [Setting Up Accounts to Appear in Reports for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0816091931.html).
    
-   If you perform inbound or outbound deliveries and need to report your inventory to local authorities, define the inventory ownership and custody of your locations.
    
    For more information, see [Adding the Type of Inventory Ownership and Custody to Locations for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0412023139.html).
    
-   If you import goods into Brazil, define the import bill default account to which to post amounts from import bill transactions.
    
    For more information, see [Defining the Import Bill Default Account](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1001100152.html).
    
-   Set up subsidiaries for Brazil.
    
    Set tax registration numbers, e-document certification preferences, addresses, and other relevant information. For more information, see [Setting Up Subsidiaries for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_164139168385.html).
    
-   Set up customers for Brazil.
    
    Set the tax registration numbers, e-document sending recipient, address, and other relevant information. For more information, see [Setting Up Customers for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0822115335.html).
    
-   Set up vendors for Brazil.
    
    Set the tax registration numbers, e-document sending recipient, vendor payment preferences, and other relevant information. For more information, see [Setting Up Vendors for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0822013432.html).
    
-   Set up employees for Brazil.
    
    Set the tax registration number, address, and other relevant information. For more information, see [Setting Up Employees for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_164141315213.html).
    
-   Set up contacts for Brazil.
    
    Set the federal tax registration and the Conselho Regional de Contabilidade (CRC) registration number for accountants and company partners. For more information, see [Setting Up Contacts for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0713115925.html).
    
-   Set up the expense account and subsidiaries for the predefined expense categories provided by the Brazil Localization SuiteApp.
    
    For more information, see [Setting Up Predefined Expense Categories for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1109063409.html).
    
-   Create item records for Brazil.
    
    Set codes to change how taxes are levied and accounts to which to post item amounts. For more information, see [Creating Items for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_164684791452.html).
    
-   If you create lot numbered or assembly items, define the origin information for these grouped items.
    
    For more information, see [Origin Information in Assembly, Lot, and Serial Numbered Items for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1001085741.html).
    
-   Set up electronic invoicing for Brazil.
    
    Define e-document generation and certification settings. For more information, see [Setup for Electronic Invoicing for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0610103134.html).
    
-   Set up payments for Brazil.
    
    Set up fine and interest items, banking information and other details for electronic payments. For more information, see [Setup for Payments for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0610103119.html).
    
-   Review the current limitations and best practices.
    
    For more information, see [Brazil Localization Known Limitations and Best Practices](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0510025817.html).
