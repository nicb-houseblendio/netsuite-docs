Note:

To access the Brazil Certification Tax Authorities SuiteApp documentation in Brazilian Portuguese (Português do Brasil), see [Brazil Certification Tax Authorities](https://system.netsuite.com/help/helpcenter/shared_resources/PDF/BrazilCertificationTaxAuthorities_pt_BR.pdf).

To send receiver acknowledgment events, make sure you've set up these records and preferences in your account:

-   Upload your digital certificate to NetSuite.
    
    If you've already uploaded a digital certificate for e-document certification, you don't need to upload another one. Upload an A1 certificate if you haven't already. For more information, see [Uploading Digital Certificates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1542656620.html).
    
-   Download the predefined e-document templates to send receiver acknowledgment events.
    
    For more information, see [Predefined E-Document Template Files for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0915021206.html).
    
-   Create outbound e-document templates for the receiver acknowledgment operations.
    
    For more information, see [Creating Outbound E-Document Templates for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0824111606.html).
    
-   Set up the operations on the receiver acknowledgment tax authority certification service.
    
    For more information, see [Setting Up Certification Service Operations for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0327111232.html).
    
-   Set a template to generate PDF representations of incoming electronic invoices for goods.
    
    For more information, see [Predefined PDF Templates for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0724013953.html).
    
-   Associate the Receiver Acknowledgment Monitoring plug-in with the receiver acknowledgment tax authority.
    
    For more information, see [Associating the Receiver Acknowledgment Monitoring Plug-in with the Tax Authority](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_15114506524.html).
    
-   Create and set up the receiver acknowledgment certification custom fields.
    
    For more information, see [Adding Receiver Acknowledgment Custom Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0612114344.html).
    
-   Validate your inbound e-document records.
    
    For more information, see [Inbound E-Document Validation Setup for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0623101116.html).
    
-   Create inbound e-document template records to convert inbound e-documents into vendor bills.
    
    For more information, see [Creating Inbound E-Document Templates for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0620032543.html).
    
-   Set up inbound e-document settings for your subsidiary.
    
    For more information, see [Defining Inbound E-Document Settings](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0517104202.html).
