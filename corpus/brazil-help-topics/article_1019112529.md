Note:

To access the SuiteTax Latam Engine - Brazil Records documentation in Brazilian Portuguese (Português do Brasil), see [SuiteTax Latam Engine - Brazil Records](https://system.netsuite.com/app/help/helpcenter.nl?fid=SuiteTaxLatamEngineBrazil_pt_BR.pdf).

Create a new tax type if you have special taxation or accounting scenarios.

#### To create a tax type for Brazil: {#procedure_0425033734}

1.  Open the predefined tax type record for reference.
    
    1.  Go to _Setup > Tax > Tax Types_.
        
    2.  Click **View** next to the tax type.
        
    3.  Review and take note of how the fields are filled.
        
2.  Create a new tax type record.
    
    1.  Go to _Setup > Tax > Tax Types > New_.
        
    2.  In the **Country** field, select **Brazil**.
        
    3.  In the **Name** field, enter a name for the tax type.
        
        The name must be different from the existing tax type. For example, if you're creating an alternate of the CSRF\_RETIDO\_BR tax type for the REIDI benefit, you could name it CSRF\_RETIDO\_REIDI\_BR.
        
    4.  Fill out the other relevant fields.
        
        For more information, see [Creating a Tax Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1811821.html).
        
    5.  (Optional) If you use the Brazil Localization SuiteApp and want to split the withheld tax amount equally between installments, enable withheld tax amount splitting.
        
        For more information, see [Enabling Withheld Tax Amounts Splitting Between Installments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_3152139661.html)
        
    6.  Click **Save**.
        
3.  Add the tax accounts to the new tax type.
    
    For more information, see [Adding Tax Accounts to the Tax Types for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0425094310.html).
