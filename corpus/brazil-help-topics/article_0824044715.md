The Brazil Localization SuiteApp enables you to enter electronic invoicing information in transactions that precede invoices and cash sales, such as estimates and sales orders.

Adding electronic invoicing information to estimates and sales orders helps you to anticipate details about future sales and can facilitate electronic invoice generation and certification.

When you convert estimates and sales orders into other transactions, NetSuite carries over the electronic invoicing information you already filled. You can edit this information both in the estimates or sales orders and the invoices or cash sales.

#### To add electronic invoicing information to an estimate or a sales order: {#procedure_0824044808}

1.  Create the transaction and fill the relevant information.
    
    For more information, see:
    
    -   [Preparing an Estimate](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1069843.html)
        
    -   [Creating Sales Orders](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1216500.html)
        
2.  In the **E-Document Category** field, select the type of e-document you want to associate with the transaction.
    
    If you set a default e-document category for the subsidiary, NetSuite populates the default in this field. You can select a different e-document category.
    
3.  In the **Transaction Nature** field, select the transaction nature that applies to the transaction.
    
    NetSuite populates the transaction nature based on the selected e-document category. You can select a different transaction nature if you want. Be aware that NetSuite only lists in this field the transaction natures associated with the e-document category. For more information, see [Setting Up Transaction Natures for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_164139202330.html).
    
4.  Click the **Items** subtab.
    
    1.  Add the items you plan to sell.
        
        For more information, see [Adding Items on a Sales Transaction](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4588373194.html).
        
    2.  When adding the items, in the **CFOP Code** column, select the Código Fiscal de Operação e Prestação (CFOP) code that identifies the type of transaction.
        
        If you associated the selected e-document category with a transaction nature record, NetSuite automatically populates the CFOP code with the corresponding default option. You can select a more suitable CFOP code, according with the type of transaction you're performing. For more information, see [Setting Up Transaction Natures for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_164139202330.html).
        
5.  Click the **Billing** subtab.
    
    1.  If you're creating a sales order, add the term of payment and other relevant payment details.
        
        For more information, see [Adding Payment Information in Invoices for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0913030538.html).
        
    2.  Under Billing Address, in the **Bill To Select** field, select the billing address for the transaction.
        
        NetSuite displays the billing address in the Bill To field. For more information, see [Adding Billing Information to a Transaction](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4588267772.html).
        
6.  Click **Save**.
