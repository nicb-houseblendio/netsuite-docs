If you manually zero your income accounts at the end of a posting period, you can set the journal entry created for this process as a closing journal.

If the period already closed and you need to add or adjust amounts, you can set journal entries as post-closing journals.

NetSuite includes information about closing and post-closing journals in the I200 section of the ECD file generated for that posting period.

Important:

If you generate period end journals, NetSuite automatically identifies them as income accounts closing journals in the ECD file. In this case, you don't need to manually set a journal entry as an income accounts closing journal. For more information, see [Period End Journal Entries](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1531269686.html).

#### To set a journal entry as a closing journal for Brazil:

1.  Go to _Transactions > Financial > Make Journal Entries > List_.
    
2.  Next to the journal entry you want to edit, click **Edit**.
    
    The journal entry opens.
    
3.  Choose the type of closing journal you want to set for this entry:
    
    -   If you want to set this entry as an income accounts closing journal for a Brazilian subsidiary, check the **Set as an Income Accounts Closing Journal for Brazil** box.
        
        In general, Brazilian subsidiaries create income accounts closing journals at the end of the month or the year.
        
    -   If you want to set this entry as a post-closing journal, check the Set as a **Post-Closing Journal for Brazil** box.
        
        You can create post-closing journals for Brazilian subsidiaries to add amounts or make adjustments after the posting period closes.
        
4.  If you set this entry as a post-closing journal, in the **Post-Closing Journal Posting Date** field, enter or select the date in which to post the journal.
    
5.  Click **Save**.
