Brazil Reports provides the following file layouts for this report:

-   **EFD ICMS IPI v20 Com Bloco K Completo** - Includes all sections and records supported by the SuiteApp.
    
    This file layout may apply to manufacturing companies that need to report the whole building and assembling process.
    
-   **EFD ICMS IPI v20 Sem Bloco K** - Includes all sections supported by the SuiteApp, except for K section records related to inventory and manufacturing.
    
    This file layout may apply to service providers with state tax registration, companies that aren't comparable to a manufacturer, or those that don't manage inventory.
    
-   **EFD ICMS IPI v20 Com Bloco K Restrito ao Estoque** - Includes all sections supported by the SuiteApp, but only includes the inventory records in the K section.
    
    This file layout may apply to companies comparable to a manufacturer or wholesalers, that need to report their inventory balances.
    

NetSuite generates the EFD ICMS IPI files based on version 20 of the layout.
