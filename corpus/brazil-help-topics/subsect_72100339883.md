After the Brazil Reports SuiteApp installation is complete, the import of the predefined records provided by the SuiteApp starts automatically.

A script deployment record runs in your account to import the predefined records. The script is named **BRR SC SDF Installer** (Script ID `customdeploy_brr_sc_sdf_installer`).

The import creates predefined records for the following record types:

-   Cost of goods account code
    
-   CSLL calculation basis adjustments
    
-   CSLL deduction code
    
-   CSLL presumption rate
    
-   Data source for file layout parameter
    
-   EFD-Reinf event
    
-   EFD-Reinf event position
    
-   EFD-Reinf nature of the income
    
-   Feature for file layout parameter
    
-   File layout
    
-   File layout parameter
    
-   ICMS adjustment code
    
-   ICMS intrastate tax rate for SPED
    
-   ICMS ST adjustment code
    
-   IPI adjustment code
    
-   IRPJ calculation basis adjustments
    
-   IRPJ deduction code
    
-   IRPJ presumption rate
    
-   Item ownership and custody indicator
    
-   Layout section
    
-   Nature of the credit calculation basis
    
-   Related section source
    
-   Related source field
    
-   Section source
    
-   Sequence of EFD-Reinf events
    
-   Signer qualification
    
-   Source field
    
-   SPED EFD item type
    
-   SPED file type
    
-   Tax revenue codes
    

If you have the Brazil Banking Integration SuiteApp installed in your account, Brazil Reports also creates predefined records for these record types:

-   Field mapping for banking integration
    
-   Transaction for banking integration
    

For more information, see [Brazil Banking Integration](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_140904677.html).

Tip:

If you notice any predefined records are missing, view the script's execution log to verify if there were any errors. For more information, see [Using the Script Execution Log Subtab](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4375896105.html).

Before you start using the Brazil Reports SuiteApp, you must verify the status of the import. The SuiteApp's ready to use after the import finishes.

#### To verify the import status of the Brazil Reports predefined records: {#procedure_0525100419}

1.  Go to _Setup > Import/Export > View CSV Import Status_.
    
2.  In the Job Status list, verify the status of these jobs:
    
    -   CUSTOMRECORD\_BRR\_COSTGOODS\_ACCOUNT\_CODE
        
    -   CUSTOMRECORD\_BRR\_CSLL\_CALC\_BASIS\_ADJUST
        
    -   CUSTOMRECORD\_BRR\_CSLL\_DEDUCTION\_CODE
        
    -   CUSTOMRECORD\_BRR\_CSLL\_PRESUMPTION\_RATE
        
    -   CUSTOMRECORD\_BRR\_EFD\_REINF\_EVENT
        
    -   CUSTOMRECORD\_BRR\_EFD\_REINF\_EVENT\_POS
        
    -   CUSTOMRECORD\_BRR\_EFD\_NATURE\_INCOME
        
    -   CUSTOMRECORD\_BRR\_ICMS\_ADJ\_CODE
        
    -   CUSTOMRECORD\_BRR\_ICMS\_INTRASTATE\_RATE
        
    -   CUSTOMRECORD\_BRR\_ICMS\_ST\_ADJ\_CODE
        
    -   CUSTOMRECORD\_BRR\_IPI\_ADJUSTMENT\_CODE
        
    -   CUSTOMRECORD\_BRR\_IRPJ\_CALC\_BASIS\_ADJUST
        
    -   CUSTOMRECORD\_BRR\_IRPJ\_DEDUCT\_CODE
        
    -   CUSTOMRECORD\_BRR\_IRPJ\_PRESUMPTION\_RATE
        
    -   CUSTOMRECORD\_BRR\_ITEM\_OWNERSHIP\_CUST\_IND
        
    -   CUSTOMRECORD\_BRR\_NAT\_CRED\_CALC\_BASIS
        
    -   CUSTOMRECORD\_BRR\_SEQ\_EFD\_REINF\_EVENTS
        
    -   CUSTOMRECORD\_BRR\_SIGNER\_QUALIFICATION
        
    -   CUSTOMRECORD\_BRR\_SPEDEFD\_ITEM\_TYPE
        
    -   CUSTOMRECORD\_BRR\_SPED\_FILE\_TYPE
        
    -   CUSTOMRECORD\_BRR\_TAX\_REVENUE\_CODE
        
    -   CUSTOMRECORD\_LFB\_BASE\_SOURCE\_FIELD
        
    -   CUSTOMRECORD\_LFB\_DATA\_SOURCE
        
    -   CUSTOMRECORD\_LFB\_FILE\_LAYOUT
        
    -   CUSTOMRECORD\_LFB\_FILE\_LAYOUT\_FEATURE
        
    -   CUSTOMRECORD\_LFB\_FILE\_LAYOUT\_GEN\_PARAMS
        
    -   CUSTOMRECORD\_LFB\_LAYOUT\_SECTION
        
    -   CUSTOMRECORD\_LFB\_SECTION\_SOURCE
        
    -   CUSTOMRECORD\_LFB\_SECTION\_SOURCE\_REL
        
    -   CUSTOMRECORD\_LFB\_SOURCE\_FIELD
        
3.  If you have the Brazil Banking Integration SuiteApp installed in your account, verify the status of these jobs:
    
    -   CUSTOMRECORD\_BIS\_FIELD\_MAP\_BANK\_INTEG
        
    -   CUSTOMRECORD\_BIS\_TRAN\_BNK\_INTEGRATION
        
4.  Wait until you can see the following information for the jobs:
    
    -   The **Status** column shows **Complete**
        
    -   The **Percent Complete** column shows **100%**
        
    -   The **Message** column says all records were imported successfully
