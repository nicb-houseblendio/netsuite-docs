To access the Brazil Reports documentation in Brazilian Portuguese (Português do Brasil), see [Brazil Reports](https://system.netsuite.com/app/help/helpcenter.nl?fid=BrazilReports_pt_BR.pdf).

Before you start generating reports for Brazil, you may have to set up records or preferences that NetSuite provides for specific business scenarios.

| Setup | Related Reports |
| --- | --- |
| If your company needs to include account information in reports, set up your accounts. For more information, see [Setting Up Accounts to Appear in Reports for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0816091931.html). | Brazil balance sheet Brazil trial balance Brazil income statement ECF ECD |
| If your company uses cost centers, you can include this information in your reports for Brazil. For more information, see [Cost Centers in Reports for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0708093202.html). | Brazil general ledger Brazil general journal Brazil balance sheet Brazil trial balance ECD EFD Contribuições PIS and COFINS assessment |
| If you want to assess PIS or COFINS credits or contributions from sources other than your main business activity, set up e-document categories for the sources. For more information, see [Setting Up E-Document Categories for Other PIS and COFINS Sources](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0711015217.html). | PIS and COFINS assessment |
| If you need to provide additional information about your customer in a report, edit the customer record and fill in the relevant fields. For more information, see [Setting Up Customers for Brazil Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_69173854800.html). | ECF EFD Contribuições IRPJ and CSLL assessment PIS and COFINS assessment |
| If you want to use the tax revenue codes provided by Brazil Reports with additional tax assessments, associate the codes with the relevant assessments. For more information, see [Associating Revenue Codes with Tax Assessments for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0128034945.html). | IPI assessment IRPJ and CSLL assessment PIS and COFINS assessment |
| If you want to create tax bills for payable ICMS or ISS, create tax revenue code records for those taxes. For more information, see [Creating Tax Revenue Codes for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0123020924.html). | ICMS assessment ISS assessment |
| If you want to populate revenue codes on transactions listed in your IRPJ and CSLL assessments, set up transaction natures for the revenue codes. For more information, see [Setting Up Default Revenue Codes for IRPJ and CSLL](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1223023453.html). | ECF IRPJ and CSLL assessment |
| If you want to assess PIS or COFINS credits from the purchase of electricity, natural gas or water, set up the nature of the calculation basis for credit. For more information, see [Setting Up the Nature of the Calculation Basis for Credit](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0528093103.html). | EFD Contribuições PIS and COFINS assessment |
| If you classify the items according with the SPED system, set up the item records. For more information, see [Associating SPED EFD Types with Items](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_93152340066.html). | EFD Contribuições EFD ICMS IPI |
| If your subsidiary manufactures goods or is comparable to a manufacturer, set the subsidiary as a manufacturer. For more information, see [Setting the Subsidiary Classification for Manufacturing for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0804104337.html). | EFD ICMS IPI |
| If you want to add different ICMS and FCP tax rates in SPED reports, edit the predefined ICMS intrastate tax rate for records. For more information, see [Adjusting the ICMS Intrastate Tax Rate for SPED Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0911104931.html). | EFD ICMS IPI |
| If state tax authorities require you to provide annotations on the collection of the ICMS tax, define ICMS posting notes. For more information, see [Defining ICMS Posting Notes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1018030229.html). | EFD ICMS IPI |
| If you want to generate and send the EFD-Reinf, do the following:
-   Create e-document templates for EFD-Reinf events. For more information, see [Creating E-Document Templates for EFD-Reinf Events](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0113015811.html).
-   Set up the EFD-Reinf tax authority. For more information, see [Setting Up the EFD-Reinf Tax Authority](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0113105137.html).

 | EFD-Reinf |
| If you want to include the accounting book number in your ECD files, set up the book number and year of your last ECD submission. For more information, see [Setting Up Accounting Book Numbers for ECD Files](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0908040036.html). | ECD |
| If you want to include additional federal registration numbers in your ECD files, such as those assigned by Banco Central do Brasil or Tribunal Superior Eleitoral, create other federal registration number records. For more information, see [Adding Other Federal Registration Numbers to ECD Files](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1208041829.html). | ECD |
| If you want to generate SPED reports using your own custom file layout, associate the file layout with a SPED file type. For more information, see [Associating File Layouts with SPED File Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0508053149.html). | ECD ECF EFD Contribuições EFD ICMS IPI |
| If you want to pay your tax bills with the Brazil Banking Integration SuiteApp, import the predefined records that enable the integration. For more information, [Importing Banking Integration Records for Tax Bills](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0312050654.html). | ICMS assessment IPI assessment ISS assessment PIS and COFINS assessment |
