With Brazil Reports, you can generate several statutory reports standardized by Sistema Público de Escrituração Digital (SPED).

The following SPED files you generate in NetSuite are ready for submission to the federal government:

-   ECD
    
-   ECF
    
-   EFD ICMS IPI
    
-   EFD Contribuições
    

To generate and send the EFD-Reinf, see [Generating and Sending the EFD-Reinf](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_9091344046.html).

#### To generate a SPED file: {#procedure_0510114845}

1.  Go to Reports > Brazil Reports > SPED Files > New.
    
2.  In the **File Type** field, select the type of SPED file you want to generate.
    
3.  In the **Subsidiary** field, select the subsidiary for which you want to generate the file.
    
4.  In the **File Layout** field, select the layout of you want for the file.
    
    For more information about the file layouts provided by the Brazil Reports SuiteApps, see [Available Statutory Reports for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0509052242.html).
    
5.  If you're generating an EFD Contribuições or EFD ICMS IPI file, in the **Accountant** field, select the contact of one or more accountants who are responsible for the information in the file.
    
6.  In the **Start Date** field, select the start date for the period the file covers.
    
7.  In the **End Date** field, select the end date for the period the file covers.
    
8.  If you're generating an EFD ICMS IPI file and need to report an inventory of your stock, in the **Reason for Inventory** field, select the reason for reporting the inventory.
    
9.  If you selected a reason for inventory, in the **End Date for Inventory** field, select the end date for the inventory of your company's stock.
    
10.  If you're generating ECD or ECF files, click the **Signers** subtab.
     
     1.  In the **Signer** column, select a signer for the file.
         
         This field displays contact records. For more information about setting up contacts for Brazil, see [Setting Up Contacts for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0713115925.html).
         
     2.  In the **Signer Qualification** column, select the signer's qualification according to the SPED system.
         
     3.  If the signer qualification is **900 - Contador**, in the **Accountant License Number column**, enter the accountant's Conselho Regional de Contabilidade (CRC) number.
         
     4.  If the signer qualification is **900 - Contador** and you're generating an ECD file, do the following:
         
         1.  In the **Issuing State of the License** column, select the state of the CRC that issued the accountant's license.
             
         2.  In the **Accountant Regularity Certificate** column, enter the number of the accountant's professional regularity certificate.
             
             The professional regularity certificate attests the accountant's compliance with their CRC. Enter the number in the following format: State acronym/Year/Number. For example, AC/0000/00000000. There's no length limit.
             
         3.  In the **Certificate Expiration Date** column, enter the date on which the accountant's regularity certificate expires.
             
     5.  If you want to list the signer as the legal representative in the SPED file, check the **Legal Representative** box.
         
     6.  Click **Add**.
         
         Repeat these steps to add more signers.
         
11.  Click **Save**.
     
     NetSuite saves the record and displays it in view mode.
     
12.  If you have full multi-book accounting enabled in your account, and you're generating an ECD, ECF, or EFD Contribuições file, click the **Parameters** subtab.
     
     1.  In the **Accounting Book** field, select the accounting book from which you want to retrieve the transactions to include in the SPED file.
         
     2.  Click **Save**.
         
         NetSuite saves the record and displays it in view mode.
         
13.  Click **Generate File**.
     
     NetSuite starts generating the SPED file. You can verify the progress in the **Status** field.
     
14.  Refresh the page to update the **Status** field.
     
15.  If the status is **Completed**, in the **File** field, click **Download** to save the file to your device.
     
16.  If the status is **Failed**, in the **Generation Details** field, review the error message.
     
     Depending on the error, you may need to edit your transaction records and generate the SPED file again.
     

Tip:

You can leverage other reports to review the following SPED files:

-   **ECD** - Brazilian general ledger and general journal.
    
-   **ECF** - Brazilian income statement and balance sheet.
    
-   **EFD ICMS IPI** - Inbound and outbound goods fiscal books.
    

For more information, see [Country Tax Reports for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0924014747.html).
