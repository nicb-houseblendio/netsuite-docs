Note:

To access the Brazil Certification Tax Authorities SuiteApp documentation in Brazilian Portuguese (Português do Brasil), see [Brazil Certification Tax Authorities](https://system.netsuite.com/help/helpcenter/shared_resources/PDF/BrazilCertificationTaxAuthorities_pt_BR.pdf).

The SuiteApp provides a predefined inbound e-document validation plug-in implementation to enable you to validate inbound e-documents before converting them to NetSuite transactions.

For more information, see [Inbound Validation Plug-ins](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1495190263.html).

After you create the inbound e-document validation plug-in, associate it to an e-document package. For more information, see [Associating the Validation Plug-in with an E-Document Package](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0623011829.html).

#### To create an inbound e-document validation plug-in for Brazil: {#procedure_0623101150}

1.  Go to Setup > E-Documents > Inbound E-Document Validation Plugin > New.
    
2.  In the **Name** field, enter a name for the plug-in.
    
3.  In the **Inbound E-Document Validation Plug-in Implementation** field, select **Brazil Inbound E-Document Validation**.
    
4.  Click **Save**.
