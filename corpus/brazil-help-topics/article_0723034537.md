To access the Brazil Certification Tax Authorities SuiteApp documentation in Brazilian Portuguese (Português do Brasil), see [Brazil Certification Tax Authorities](https://system.netsuite.com/help/helpcenter/shared_resources/PDF/BrazilCertificationTaxAuthorities_pt_BR.pdf).

To certify your e-documents, the Brazil Certification Tax Authorities SuiteApp communicates with tax authorities' web services.

When the system is unable to connect with a web service, due to instabilities or maintenance, for example, the certification process fails.

The Certification Web Services Availability portlet displays information about the status of the connections with the tax authorities with which you certify e-documents. The portlet enables you to identify whether the web services are available, which can help you understand why the certification process may be unsuccessful.

The portlet lists the status information from up to five web services at a time.

#### To add the Certification Web Services Availability portlet to a dashboard:

1.  Go to the home page.
    
2.  Click **Personalize**.
    
3.  On the Personalize Dashboard menu, select **SuiteApps**.
    
4.  Click the Certification Web Services Availability portlet, or drag the icon to the dashboard.
    
    The Certification Web Services Availability portlet appears on your dashboard. The portlet lists the web services of the tax authorities for which you have e-document certification settings records and displays the following columns:
    
    -   **Subsidiary** - Displays the name of the subsidiary with which you send e-documents for certification to the tax authority.
        
    -   **Tax authority** - Displays the name of the tax authority certification service.
        
    -   **Certification environment** - Displays the tax authority's certification environment.
        
    -   **Status** - Displays the current status of the web service.
        
        -   If the web service is available for communication, the column displays a green check mark icon.
            
        -   If the system is unable to connect with the web service, the column displays a red warning sign.
            
    -   **Date of the test** - Displays the date and time at which NetSuite last checked the availability of the web service.
        
        By default, the system tests the connection with each web service every 12 hours.
        
5.  If your account has more than five e-document certification settings records, click the arrow icon at the upper-left corner of the portlet to see more statuses.
    

For more information about dashboard portlets, see [Dashboards](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4320707520.html).
