Note:

To access the Brazil Localization SuiteApp documentation in Brazilian Portuguese (Português do Brasil), see [Brazil Localization](https://system.netsuite.com/app/help/helpcenter.nl?fid=BrazilLocalization_pt_BR.pdf).

With Brazil Localization, you can generate Centro Nacional de Automação Bancária (CNAB) delivery files with the 400 standard to receive payments from the following types of transaction:

-   Custom sales transactions for which you enabled CNAB payments
    
    For more information, see [Enabling Payments for Brazil in Custom Transactions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0328020130.html).
    
-   Invoices
    
    Important:
    
    If your transaction requires approval, make sure it's approved before trying to include the transaction or its installments in the CNAB delivery file. Brazil Localization doesn't allow you to include transactions that are rejected or pending approval.
    
    For more information, see [Approval Routing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N2394992.html).
    

The Brazil Localization SuiteApp provides predefined layouts for the 400 standard from the following banks:

-   Banco Bradesco
    
-   Banco do Brasil
    
-   Banco Itaú
    
-   Banco Santander
    

To add discount information to the payments you received, apply discounts before generating the delivery file. For more information, see [Applying Discounts to the Payments of Sales for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0115113716.html).

For more information about generating delivery files with the 400 standard, see [Generating CNAB 400 Delivery Files](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0927033437.html).
