Note:

To access the SuiteTax Latam Engine - Brazil Records documentation in Brazilian Portuguese (Português do Brasil), see [SuiteTax Latam Engine - Brazil Records](https://system.netsuite.com/app/help/helpcenter.nl?fid=SuiteTaxLatamEngineBrazil_pt_BR.pdf).

The SuiteTax Latam Engine - Brazil Records SuiteApp is a managed SuiteApp. Whenever there are enhancements or new features, NetSuite automatically updates your account.

As a shared SuiteApp, SuiteTax Latam Engine - Brazil Records is only available for installation on authorized accounts. For more information, contact your account manager.

To install this SuiteApp, you must have permission and access to the SuiteApp Marketplace. For more information, see [Viewing SuiteApps in the SuiteApp Marketplace](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1539797977.html).

Before you install SuiteTax Latam Engine - Brazil Records, ensure you meet the prerequisites for installation. For more information, see [Prerequisites for Installing the SuiteTax Latam Engine - Brazil Records SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_162870716602.html).

#### To install the SuiteTax Latam Engine - Brazil Records SuiteApp:

1.  In NetSuite, go to SuiteApps.
    
2.  In the **Search SuiteApps** field, enter **SuiteTax Latam Engine - Brazil Records**.
    
3.  Click **SuiteTax Latam Engine - Brazil Records**.
    
4.  In the top-right corner of the SuiteApp details page, click **Install**.
    
5.  Wait for the installation to complete.
    
    Tip:
    
    After the installation completes, verify the status of the import that creates the predefined records. For more information, see [Verifying the Import Status of the Brazil Predefined Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_162870726411.html).
    

For more information about the SuiteApp installation process, see [Installing from the SuiteApp Marketplace](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1539799323.html).
