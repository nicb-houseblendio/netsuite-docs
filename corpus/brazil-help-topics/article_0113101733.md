The Brazil Reports SuiteApp provides a custom tax bill transaction type to record taxes payable to Brazilian tax authorities.

Tax bills enable you to register the following taxes payable in Brazil:

-   COFINS
    
-   FCP
    
-   FCP ST
    
-   ICMS
    
-   ICMS ST
    
-   ICMS DIFAL
    
-   IPI
    
-   ISS
    
-   PIS
    

Brazil Reports provides a list of predefined item records for the aforementioned taxes for you to add to your tax bills. Set up these items before you add them to your tax bills. For more information, see [Setting Up Tax Items for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0115032038.html).

Additionally, before you create tax bills, ensure you created vendor records for the tax authorities for which you make payments. For more information, see [Setting Up Vendors for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0822013432.html).

You can generate tax bills in bulk through tax assessment records and the Tax Bills Generation page or create standalone tax bills manually:

-   [Generating Tax Bills for Brazil from Tax Assessments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0113045018.html)
    
-   [Generating Tax Bills for Brazil in Batch](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0113020903.html)
    
-   [Creating Standalone Tax Bills for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0113105258.html)
    

If you have the Brazil Banking Integration SuiteApp installed in your account, you can use it to pay some types of tax bills. For more information, see [Adding Banking Integration Information to Tax Bills for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0311050920.html).
