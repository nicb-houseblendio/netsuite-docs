Before you start using the Brazil Deferred Revenue Recognition SuiteApp, ensure you complete the required settings:

-   Create deferred revenue settings for your subsidiaries located in Brazil.
    
    For more information, see [Creating Deferred Revenue Settings for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0218054736.html).
    
-   If you have the Rule-Based Recognition Treatment feature enabled in your account, do the following:
    
    -   Create revenue recognition treatments with the same types of revenue recognition event you selected in your deferred revenue settings.
        
        For more information, see [Creating Recognition Treatments for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0713113814.html).
        
    -   Define recognition treatment rules for the revenue recognition treatments you created.
        
        For more information, see [Defining Recognition Treatment Rules for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0713115326.html).
