To access the SuiteTax Latam Engine - Brazil Records documentation in Brazilian Portuguese (Português do Brasil), see [SuiteTax Latam Engine - Brazil Records](https://system.netsuite.com/app/help/helpcenter.nl?fid=SuiteTaxLatamEngineBrazil_pt_BR.pdf).

The ICMS Importação Bens Brazil plug-in enables you to calculate the Imposto sobre Circulação de Mercadorias e Serviços (ICMS) tax on the imports of goods.

The following table summarizes the plug-in requirements and capabilities.

| **Plug-in Implementation** | ICMS Importação Bens Brazil |
| --- | --- |
| **Tax Code's Internal Name** | ICMS\_IMPORTACAO\_BENS\_BR |
| **Requires Parent Tax Determination Rules** | No |
| **Requires Parameter Types** | Yes Requires the following parameters:
-   A CST code
-   Modalidade ICMS 3 - Valor da Operação

For more information, see [Parameter Types for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_163664116234.html). |
| **Supports Tax Basis and Tax Override** | Yes |
| **Adds Expenses** | Yes Adds shipping and handling costs to the tax calculation basis. |
| **Changes the Tax Calculation Basis** | Yes Adds the COFINS, II, IPI, and PIS amounts to the tax calculation basis if:

-   The tax determination rules record has a parent tax determination rules.
-   The parent tax determination rules have tax determination settings with an COFINS, II, IPI, and PIS tax code with the standard internal name.

 |
| **Records Tax Calculation History** | No |
