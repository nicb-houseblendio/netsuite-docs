When you send receiver acknowledgment events in NetSuite, the system creates a batch of requests to send the events for certification. Each request in the batch can contain up to 20 events.

NetSuite enables you to view the status of each receiver acknowledgment request and event, as well as details from their related incoming e-documents.

#### To verify the status of a receiver acknowledgment request: {#procedure_0823112940}

1.  Go to Transactions > Purchases > Receiver Acknowledgment.
    
    The list of receiver acknowledgment requests batches opens.
    
2.  Click **View** next to the batch of requests you want.
    
3.  In the **Status of the Requests Batch** field, verify the processing status of the batch of receiver acknowledgment requests.
    
4.  To verify the status of specific requests from the batch, click the **Requests** subtab.
    
    NetSuite lists the status of each request in the batch in the Status of the Request column.
    
5.  To view additional information, such as the events and incoming e-documents associated with a request, do the following:
    
    1.  In the **Receiver Acknowledgment Request** column, click the ID of the request you want to view.
        
    2.  To learn more details about the certification status of the request, verify the **Status** field:
        
        -   If the status is **Sent**, in the **Certification Return** field, click the ID of the e-document certification return.
            
            The e-document certification return record opens. In it, you can review more details about the certification of the receiver acknowledgment events.
            
        -   If the status is **Failed**, in the **Certification Request** field, click the ID of the e-document certification request.
            
            The e-document certification request record opens. In it, review the details about the processing of the receiver acknowledgment events.
            
    3.  If you want to view the incoming e-documents included in the request and any justification applied to them, click the **Custom** subtab.
        
    4.  To verify the status of each event included in the request, click the **Incoming E-Documents** subtab.
        
        NetSuite lists the status of the event you sent for each the e-document in the Status column.
