Inventory details store information about bin numbers and serial or lot numbers of items. The inventory detail subrecord is available if you have the Advanced Bin / Numbered Inventory Management feature enabled.

If you have both the Lot Auto Numbering and Brazil Localization SuiteApps installed, you can also define the following information when setting inventory details for lot and serial numbered items:

-   **Origin** - The origin code that identifies where the item comes from.
    
-   **FCI control number** - The number from the Ficha de Conteúdo Importado (FCI) you filled when importing the item.
    
    The FCI form helps calculate the share of imported goods in the final value of a product. It also identifies the imported goods and the taxpayer.
    

For more information about the transactions supported by the Lot Auto Numbering SuiteApp, see [Lot Auto Numbering SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_162780241331.html).

#### To define the origin and FCI control number in inventory details:

1.  Go to _List > Accounting > Items_.
    
2.  Next to the lot or serial numbered inventory item you want, click **View**.
    
    Tip:
    
    To search only for inventory items, under Filters, in the **Type** list, select **Inventory Item**.
    
3.  Click the **Inventory Detail** subtab.
    
4.  In the **Number** column, click a number to open the lot or serial number record.
    
5.  Click **Edit**.
    
6.  In the **Origin** field, select the origin of the items.
    
    NetSuite automatically populates this field if you included an origin code in the transactions to which you added the item. You can enter a different origin code. When you add this lot or serial numbered inventory item to a new transaction, the origin code appears after you click Add.
    
    -   In sales transactions, you can't change the origin code directly on the transaction record.
        
        To set a different origin, you must either:
        
        -   Edit the inventory details and select a different origin code.
            
        -   Create or edit the transaction through an integration or import.
            
    -   In purchase transactions, you can enter different origin codes directly on the transaction record.
        
7.  If the items are imported, in the **FCI Control Number** column, enter the control number of the FCI form you filled.
    
8.  Click **Save**.
