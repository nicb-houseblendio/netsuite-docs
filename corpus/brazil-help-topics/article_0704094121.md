Note:

To access the SuiteTax Latam Engine - Brazil Records documentation in Brazilian Portuguese (Português do Brasil), see [SuiteTax Latam Engine - Brazil Records](https://system.netsuite.com/app/help/helpcenter.nl?fid=SuiteTaxLatamEngineBrazil_pt_BR.pdf).

Access to the custom records provided by the SuiteTax Latam Engine - Brazil Records SuiteApp requires specific permissions. By default, the Administrator role is granted full permissions to the custom records. If other roles need to view, access, or edit the custom records, an administrator can give them permission.

See the following table for more information about the default permissions granted with the SuiteTax Latam Engine - Brazil Records SuiteApp.

| Role | Category | Permission | Access Level |
| --- | --- | --- | --- |
| Administrator | Custom Record | Brazil City | Full |
| Administrator | Custom Record | CFOP Code | Full |
| Administrator | Custom Record | Complementary Account | Full |
| Administrator | Custom Record | CRT Code | Full |
| Administrator | Custom Record | Special Tax Regime on Simples Nacional | Full |
| Administrator | Custom Record | Tax Assessment on Simples Nacional | Full |

If any roles needs to edit subsidiary records, you aren't required to grant it permission to the custom records. However, grant the role the following permission:

-   **Category** - Lists
    
-   **Permission** - Custom Record Entries
    
-   **Access level** - Full
