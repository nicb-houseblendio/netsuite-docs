Note:

To access the Brazil Certification Tax Authorities SuiteApp documentation in Brazilian Portuguese (Português do Brasil), see [Brazil Certification Tax Authorities](https://system.netsuite.com/help/helpcenter/shared_resources/PDF/BrazilCertificationTaxAuthorities_pt_BR.pdf).

The Brazil Certification Tax Authorities SuiteApp provides predefined e-document template files for Brazilian tax authorities.

The template files are available in your account's File Cabinet. You can download the predefined template files to your device and, if you want, customize them according to your business needs.

Important:

The predefined e-document templates provided by Brazil Certification Tax Authorities may not include all XML elements supported by a tax authority. Verify whether your business scenario requires additional information that isn't included in the predefined templates. If so, customize the template or plug-in implementation to include the XML elements required for certification.

For more information about custom tax authority plug-in implementations, see [Certification Tax Authority Implementation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161280473835.html).

| Electronic invoices for services (NFS-e) | [Downloading E-Document Template Files for Electronic Invoices for Services for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_42105327142.html) |

After you download and optionally customize the templates, you must:

-   Create e-document template records for each template file you downloaded.
    
    For more information, see [Creating E-Document Templates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4536871429.html).
    
-   Set up certification service operation records.
    
    For more information, see [Setting Up Certification Service Operations for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0327111232.html).
