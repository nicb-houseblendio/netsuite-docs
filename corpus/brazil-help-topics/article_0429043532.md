Note:

To access the Brazil Localization SuiteApp documentation in Brazilian Portuguese (Português do Brasil), see [Brazil Localization](https://system.netsuite.com/app/help/helpcenter.nl?fid=BrazilLocalization_pt_BR.pdf).

Before you generate Guia Nacional de Recolhimento de Tributos Estaduais (GNRE) forms with Brazil Localization, ensure you do the following:

-   Create e-document templates for GNRE.
    
    For more information, see [Creating Outbound E-Document Templates for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0824111606.html).
    
-   Associate the GNRE e-document templates with the corresponding certification service operations.
    
    For more information, see [Setting Up Certification Service Operations for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0327111232.html).
    
-   Associate the Brazil Certification Monitoring Plug-in with the **GNRE Tax Authority**.
    
    For more information, see [Associating the Brazil Certification Monitoring Plug-in with Tax Authorities](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1116114637.html).
    
-   Set up revenue information by creating GNRE preferences for each subsidiary for which you generate the tax collection form.
    
    For more information, see [Setting GNRE Subsidiary Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0124125544.html).
