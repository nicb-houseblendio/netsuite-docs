Brazil Reports enables you to generate the following financial statements:

-   Brazil balance sheet
    
-   Brazil income statement
    

#### To generate a financial statement for Brazil:

1.  Go to Reports > Tax > Country Tax Reports.
    
2.  In the **Subsidiary** field, select a Brazilian subsidiary.
    
    NetSuite automatically populates the **Nexus** field with the nexus associated with the subsidiary.
    
3.  If your subsidiary has more than one nexus and the default isn't from Brazil, in the **Nexus** field, select the Brazilian nexus.
    
4.  In the **Report Name** field, select the financial statement you want to generate.
    
5.  In the **Start Date** field, select the start date for the report.
    
6.  In the **End Date** field, select the end date for the report.
    
    Each type of report has its own periodicity. Select the dates according to the report you're generating.
    
7.  If you have multi-book accounting features enabled in your account, in the **Accounting Book** field, select the book from which you want to generate the report.
    
    For more information, see [Multi-Book Accounting and Adjustment-Only Book Support in Tax Reporting Framework](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160222998474.html).
    
8.  (Optional) If you want the report to use account names and numbers from a specific accounting context, in the **Accounting Context** field, select the context.
    
    For more information, see [Accounting Contexts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4640155582.html).
    
9.  If you want to apply additional filters and preferences to the report, click **Open Brazil Reports Settings**.
    
    The Brazil Reports Settings popup window opens.
    
    1.  For balance sheet reports:
        
        1.  If you want to leave zero-balance accounts out of the report, check the **Leave Out Zero-Balance Accounts** box.
            
        2.  If you want to add the signers' details to the report:
            
            1.  In the **Accountant** field, select the accountant that should sign the report.
                
            2.  In the **Legal Representative** field, select the legal representative that should sign the report.
                
        3.  If you want to remove department information from the report, check the **Generate Report Without Departments** box.
            
            This option only applies to accounts that have the Departments feature enabled. For more information, see [Cost Centers in Reports for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0708093202.html).
            
    2.  If you want to generate a consolidated balance sheet or income statement, check the **Consolidate Information from the Parent and Child Subsidiaries** box.
        
        Consolidated reports include information from the parent subsidiary and all its child subsidiaries.
        
    3.  Click **Save**.
        
        The system displays a success message.
        
    4.  Click **OK**.
        
        The Brazil Reports Settings popup window closes.
        
10.  Click **Generate**.
     
     NetSuite starts generating the report.
     
11.  On the **Report Execution Log** subtab, locate the generated report.
     
     The latest report appears at the top of the list.
     
12.  In the **View | Download** column, wait for the loading bar to complete.
     
     If the report covers a long period, it may take a few minutes to finish. You're notified through email when the report is ready.
     
13.  To download the report in XLS format, click **Download**.
