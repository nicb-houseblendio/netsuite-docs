Note:

To access the SuiteTax Latam Engine - Brazil Records documentation in Brazilian Portuguese (Português do Brasil), see [SuiteTax Latam Engine - Brazil Records](https://system.netsuite.com/app/help/helpcenter.nl?fid=SuiteTaxLatamEngineBrazil_pt_BR.pdf).

After the SuiteTax Latam Engine - Brazil Records SuiteApp installation completes, the import of predefined records provided starts automatically.

Two script deployment records run in your account to import these records.

The **FTEBR SDF Installer** script (Script ID `customscript_ftebr_sdf_installer`) directly creates the following record types:

-   Nexus
    
-   Tax code
    
-   Tax type
    
    For the complete list of tax types, see [Tax Codes and Tax Types for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0425094127.html).
    

The **FTEBR SC SDF Installer** script (Script ID `customscript_ftebr_sc_sdf_installer`) triggers the CSV import that creates the predefined records for the following record types:

-   CFOP code
    
-   Brazil City
    
-   CRT code
    
-   Item code
    
-   Line of business
    
-   Parameter type
    
    For the complete list of parameter types, see [Parameter Types for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_163664116234.html).
    
-   Special tax regime on Simples Nacional
    
-   Tax assessment on Simples Nacional
    
-   Tax information mapping
    
-   Tax parameter
    
-   Tax regime
    

Before you start using the SuiteTax Latam Engine - Brazil Records SuiteApp, you must verify the status of the import. The SuiteApp is ready to use after NetSuite completes the import.

#### To verify the import status of the predefined records:

1.  Go to _Setup > Import/Export > View CSV Import Status_.
    
2.  In the Job Status list, verify the status information for the following jobs:
    
    -   CUSTOMRECORD\_FTEBR\_CFOP
        
    -   CUSTOMRECORD\_FTEBR\_CITY
        
    -   CUSTOMRECORD\_FTEBR\_CRT
        
    -   CUSTOMRECORD\_FTEBR\_SPECIAL\_TAXREGIME
        
    -   CUSTOMRECORD\_FTEBR\_TAX\_ASSESSMENT
        
    -   CUSTOMRECORD\_FTE\_ITEMCODE
        
    -   CUSTOMRECORD\_FTE\_LOB
        
    -   CUSTOMRECORD\_FTE\_PARAMTYPE
        
    -   CUSTOMRECORD\_FTE\_TAXMAPPING
        
    -   CUSTOMRECORD\_FTE\_TAXPARAMETER
        
    -   CUSTOMRECORD\_FTE\_TAXREGIME
        
3.  Wait until you can see the following information for the jobs:
    
    -   The **Status** column shows **Complete**
        
    -   The **Percent Complete** column shows **100%**
        
    -   The **Message** column says all records were imported successfully
        

Tip:

If you notice that the predefined records are missing from your account, view their respective script's execution log. In the execution log, you can verify if errors occurred. For more information, see [Using the Script Execution Log Subtab](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4375896105.html).
