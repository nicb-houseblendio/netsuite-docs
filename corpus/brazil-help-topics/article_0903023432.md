Note:

To access the SuiteTax Latam Engine - Brazil Records documentation in Brazilian Portuguese (Português do Brasil), see [SuiteTax Latam Engine - Brazil Records](https://system.netsuite.com/app/help/helpcenter.nl?fid=SuiteTaxLatamEngineBrazil_pt_BR.pdf).

The COFINS Importação ServiçosBrazil plug-in enables you to calculate the Contribuição para o Financiamento da Seguridade Social (COFINS) tax on services acquired from abroad.

The following table summarizes the plug-in requirements and capabilities.

| **Plug-in Implementation** | COFINS Importação ServiçosBrazil |
| --- | --- |
| **Tax Code's Internal Name** | COFINS\_IMPORTACAO\_SERVICOS\_BR |
| **Requires Parent Tax Determination Rules** | Yes Requires a parent tax determination rule with settings to calculate ISS on services acquired from abroad. |
| **Requires Parameter Types** | Yes Requires the following parameters:
-   A CST code
-   PIS Rate on Imported Services

For more information, see [Parameter Types for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_163664116234.html). |
| **Supports Tax Basis and Tax Rate Override** | Yes |
| **Adds Expenses** | No |
| **Changes the Tax Calculation Basis** | Yes

-   Adds the ISS amount to the tax calculation basis if:
    -   The tax determination rules record has a parent tax determination rules.
    -   The parent tax determination rules have tax determination settings with an ISS on acquired services tax code with the standard internal name.
-   Adds the PIS tax rate to the tax calculation basis based on the parameter value of the PIS Rate on Imported Services parameter entered in the tax determination settings.

 |
| **Records Tax Calculation History** | No |
