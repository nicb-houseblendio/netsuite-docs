Note:

To access the Brazil Certification Tax Authorities SuiteApp documentation in Brazilian Portuguese (Português do Brasil), see [Brazil Certification Tax Authorities](https://system.netsuite.com/help/helpcenter/shared_resources/PDF/BrazilCertificationTaxAuthorities_pt_BR.pdf).

To install the Brazil Certification Tax Authorities SuiteApp, you need to meet these requirements:

-   Ensure you're using a OneWorld account.
    
    For more information, see [Introduction to NetSuite OneWorld](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N266468.html).
    
-   Install the Electronic Invoicing SuiteApp
    
    For more information, see [Installing and Setting Up Electronic Invoicing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4592549826.html).
    
-   Install the LATAM E-Document Certification SuiteApp.
    
    For more information, see [LATAM E-Document Certification SuiteApp Installation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160320094693.html).
    
-   Enable several features in NetSuite.
    

#### To enable features:

1.  Go to _Setup > Company > Enable Features_.
    
2.  On the **Company** subtab, check the following boxes:
    
    -   Multi-language
        
    -   File Cabinet
        
3.  On the **SuiteCloud** subtab, check the following boxes:
    
    -   Advanced PDF/HTML Templates
        
    -   Client SuiteScript
        
    -   Server SuiteScript
        
4.  Click **Save**.
