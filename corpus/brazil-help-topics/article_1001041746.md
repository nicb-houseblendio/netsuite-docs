If you manufacture assemblies in Brazil, you may need to define the origin of the assembly item. With Brazil Localization, you can define the origin of the assembly item when you build the assembly.

#### To define the origin of an assembly item:

1.  Go to _Transactions > Manufacturing > Build Assemblies_.
    
2.  Enter the relevant information for building the assembly.
    
    For more information, see [Building Assembly Items](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2321340.html).
    
3.  Review the origin of the components.
    
    The assembly's origin depends on the proportion of domestic and imported goods that make up the final product.
    
    1.  Click the **Lot Items Details** subtab.
        
    2.  Review the **Item**, **Lot Number**, **Expiration Date**, **Origin Code**, and **Quantity** columns to assess the origin of the assembly.
        
        Note:
        
        Origin codes identify the place of origin of items. The codes are defined by Brazilian authorities.
        
4.  Under Primary Information, in the **Origin Code** field, select the origin code that identifies the items in the lot.
    
    The origin code appears after you add this assembly item to the transaction.
    
    -   In sales transactions, you can't change the origin code directly on the transaction record.
        
        To set a different origin, you must either:
        
        -   Edit the assembly build and select a different origin code.
            
        -   Create or edit the transaction through an integration or import.
            
    -   In purchase transactions, you can enter different origin codes directly on the transaction record.
        
5.  Click **Save**.
