The Brazil Localization SuiteApp provides the import bill transaction to enable companies in Brazil to register the purchase of goods from international vendors. You can create standalone import bills or bill them out of purchase orders.

Before creating import bills from purchase orders, you must define the default account to which to post import bill amounts.

#### To define the import bill default account:

1.  Go to _Setup > Accounting > Preferences > Accounting Preferences_.
    
2.  Click the **Items/Transactions** subtab.
    
3.  Under Accounts, in the **Import Bill Default Account** field, select the account to which to post amounts from import bills.
    
4.  Click **Save**.
