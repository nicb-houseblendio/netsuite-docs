Note:

To access the SuiteTax Latam Engine - Brazil Records documentation in Brazilian Portuguese (Português do Brasil), see [SuiteTax Latam Engine - Brazil Records](https://system.netsuite.com/app/help/helpcenter.nl?fid=SuiteTaxLatamEngineBrazil_pt_BR.pdf).

The CSRF Brazil plug-in enables you to calculate the Contribuições Sociais Retidas na Fonte (CSRF) tax withheld on the purchases and sales of services.

CSRF is only withheld after the amount calculated in your transactions in a day reaches a given minimum.

The following table summarizes the plug-in requirements and capabilities.

| **Plug-in Implementation** | CSRF Brazil |
| --- | --- |
| **Tax Code's Internal Name** | CSRF\_RETIDO\_BR CSRF\_RETIDO\_COMPRA\_BR |
| **Requires Parent Tax Determination Rules** | No |
| **Requires Parameter Types** | Yes Requires the following parameters:
-   COFINS Rate on CSRF
-   CSLL Rate on CSRF
-   Minimum Collection Amount
-   PIS Rate on CSRF
-   Type of Date

For more information, see [Parameter Types for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_163664116234.html). |
| **Supports Tax Basis and Tax Rate Override** | Yes |
| **Adds Expenses** | No |
| **Changes the Tax Calculation Basis** | No |
| **Records Tax Calculation History** | Yes Stores information about each transaction on which the plug-in runs, such as:

-   Customer or vendor
-   Date
-   Tax amount
-   Tax rate

The tax calculation history record enables NetSuite to keep track of the CSRF amounts calculated for each subsidiary and vendor in a day. When the amount reaches the minimum, NetSuite adds the CSRF to the first item from the transaction in which the minimum amount was reached. If you create more transactions after the minimum amount is reached, the system withholds CSRF on each transaction. |
