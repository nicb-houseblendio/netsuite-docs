Note:

To access the SuiteTax Latam Engine - Brazil Records documentation in Brazilian Portuguese (Português do Brasil), see [SuiteTax Latam Engine - Brazil Records](https://system.netsuite.com/app/help/helpcenter.nl?fid=SuiteTaxLatamEngineBrazil_pt_BR.pdf).

The ICMS ST Brazil plug-in enables you to calculate the Substituição Tributária do Imposto sobre Circulação de Mercadorias e Serviços (ICMS) tax on the purchases and sales of goods and specific services.

The following table summarizes the plug-in requirements and capabilities.

| **Plug-in Implementation** | ICMS ST Brazil |
| --- | --- |
| **Tax Code's Internal Name** | ICMS\_ST\_BR |
| **Requires Parent Tax Determination Rules** | Yes Requires a parent tax determination rule with settings to calculate ICMS, except when you set the CST 30 or CST 60 parameter. |
| **Requires Parameter Types** | Yes Requires the following parameters:
-   A CST code
-   A modality parameter
-   MVA Except when you set the CST 30 or CST 60 parameter.

For more information, see [Parameter Types for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_163664116234.html). |
| **Supports Tax Basis and Tax Override** | Yes |
| **Adds Expenses** | Yes Adds shipping and handling costs, as well as expenses included in the Expenses subtab, to the tax calculation basis. |
| **Changes the Tax Calculation Basis** | Yes

-   Adds the ICMS amount to the tax calculation basis if:
    -   The tax determination rules record has a parent tax determination rules.
    -   The parent tax determination rules have tax determination settings with an ICMS tax code with the standard internal name.
-   Changes the tax calculation formula if you set the ICMS on Electricity parameter.

 |
| **Records Tax Calculation History** | No |
