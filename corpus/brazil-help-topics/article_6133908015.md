Brazil Reports enables you to generate the following auxiliary reports:

-   Brazil Simples Nacional
    
-   Withheld taxes on services
    

#### To generate an auxiliary report for Brazil:

1.  Go to Reports > Tax > Country Tax Reports.
    
2.  In the **Subsidiary** field, select a Brazilian subsidiary.
    
    NetSuite automatically populates the **Nexus** field with the nexus associated with the subsidiary.
    
3.  If your subsidiary has more than one nexus and the default isn't from Brazil, in the **Nexus** field, select the Brazilian nexus.
    
4.  In the **Report Name** field, select the auxiliary report you want to generate:
    
5.  In the **Start Date** field, select the start date for the report.
    
6.  In the **End Date** field, select the end date for the report.
    
    Each type of report has its own periodicity. Select the dates according to the report you're generating.
    
7.  If you want to apply additional filters and preferences to the report, click **Open Brazil Reports Settings**.
    
    The Brazil Reports Settings popup window opens.
    
    1.  If you're generating a Simples Nacional assessment, in the **Assessment Method** field, choose which method you use to assess the amounts.
        
        -   **Accrual Basis** - Considers the amounts earned from e-documents certified in the period.
            
        -   **Cash Basis** - Considers the amounts paid by customers to your company during the period.
            
    2.  If you're generating a withheld taxes on services report, do the following:
        
        1.  Choose the assessment method you use to withhold CRSF on outgoing transactions:
            
            -   If you withhold CSRF on certification, check **Include CSRF Withheld on an Accrual Basis for Outgoing Transactions**.
                
            -   If you withhold CSRF on payment, check **Include CSRF Withheld on a Cash Basis for Outgoing Transactions**.
                
        2.  Choose the assessment method you use to withhold CRSF on incoming transactions:
            
            -   If you withhold CSRF on certification, check **Include CSRF Withheld on an Accrual Basis for Incoming Transactions**.
                
            -   If you withhold CSRF on payment, check **Include CSRF Withheld on a Cash Basis for Incoming Transactions**.
                
        
        Important:
        
        You must choose the assessment method based on the withholding method set for the **Type of Date** parameter type in your tax determination rules. NetSuite uses this parameter to identify whether the taxes were withheld on certification or payment. For more information, see [Parameter Types for Brazil](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_163664116234.html).
        
    3.  Click **Save**.
        
        The system displays a success message.
        
    4.  Click **OK**.
        
        The Brazil Reports Settings popup window closes.
        
8.  Click **Generate**.
    
    NetSuite starts generating the report.
    
9.  On the **Report Execution Log** subtab, locate the generated report.
    
    The latest report appears at the top of the list.
    
10.  In the **View | Download** column, wait for the loading bar to complete.
     
     If the report covers a long period, it may take a few minutes to finish. You're notified through email when the report is ready.
     
11.  Click **View**.
     
     The download page opens.
     
     -   To download the report as a PDF, click ![Adobe Reader icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/CountrySpecificFeatures/PDF_icon.png).
         
     -   To download the report as a XLS, click ![XLS file icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/CountrySpecificFeatures/XLS_Icon.png).
         
         Due to a system limitation, you can only download XLS files with sizes up to 10 MB.
