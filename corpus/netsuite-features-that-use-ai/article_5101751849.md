You may have questions about how NetSuite features use artificial intelligence (AI). AI is computer software that simulates how humans think and reason. Machine Learning (ML) lets computer systems learn and improve from experience, without explicit programming.

Oracle NetSuite is continuously enhancing features powered by AI. Learn more about these features in the release notes and help topics in the NetSuite Help Center, in SuiteAnswers, and in the Oracle Help Center.

NetSuite also uses AI behind the scenes, monitoring for anomalies to help keep your NetSuite account secure.

The following sections list NetSuite features that use AI with links to help topics for more information.

-   [Generative AI Features](#subsect_1030011603)
    
-   [SuiteScript AI Modules](#subsect_1030011943)
    
-   [Skills and Agents](#subsect_0330112450)
    
-   [AI Integration Features](#subsect_1030011018)
    
-   [Machine Learning Features](#subsect_1030011336)
    

Important:

These AI features have not yet been assessed for compliance with the U.S. Health Insurance Portability and Accountability Act (HIPAA).

**You should not use these AI features to process or store electronic Protected Health Information (ePHI).**

Tip:

You can take the free _AI in NetSuite_ learning path to learn about AI features in NetSuite and how to use them. Go to the [NetSuite MyLearn](https://mylearn.oracle.com/netsuite/home) home page and search for **AI**.

## NetSuite Generative AI SuiteApps and Modules {#subsect_0402103421}

SuiteApps and modules are add-ons for use in your NetSuite account. Features that use generative AI include the following:

-   **Audit Summarization:** see [Audit Summarization using Generative AI](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_0923090009.html). The Audit Summarization feature requires the purchase of the [Compliance 360 SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_7153807491.html).
    
-   **Bill Capture:** see [Bill Capture](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_164726334180.html) for more information about this module.
    
    Note:
    
    The ability to email vendor bills is implemented through the [Transaction Email Capture SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_9121955260.html).
    
-   **NetSuite Connector:** interacts with NetSuite Expert, allowing the NetSuite Connector to query SuiteAnswers. See [NetSuite Connector Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_164681347904.html).
    
-   **NetSuite CPQ AI Assistant:** see [NetSuite CPQ AI Assistant](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_9094751090.html). The NetSuite CPQ AI Assistant requires the purchase of the [NetSuite CPQ Configurator](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_7121343557.html) SuiteApp.
    
-   **Subscription Metrics SuiteApp:** The Summary portlet uses Prompt Studio. See [Subscription Metrics](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1215935976.html) for more information about this SuiteApp.
    

Note:

To learn more about the generative AI models, see the SuiteAnswers article [LLM Mapping for Generative AI Features](https://suiteanswers.custhelp.com/app/answers/detail/a_id/1023335). Be aware that you must be logged in to NetSuite to access articles in SuiteAnswers.

## Skills and Agents {#subsect_0330112450}

Note:

Skills are tools or techniques that do one kind of job well. Agents are decision makers that use skills to achieve a goal. Skills are building blocks; agents orchestrate.

This section contains information about agents and skills that you can use with NetSuite and contains links for more information.

-   **SuiteCloud Agents Skills:** a platform-agnostic skill collection (tools) for coding assistants, built to be compatible with the [agentskills.io](https://agentskills.io/specification) specification. These skills are focused on SuiteCloud and NetSuite development workflows, including SuiteScript, SDF, UIF SPA components, security, documentation, and deployment best practices. See [SuiteCloud Agent Skills Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_7122549123.html) for more information. See also [SuiteCloud Agents Skills](https://github.com/oracle/netsuite-suitecloud-sdk/tree/master/packages/agent-skills) in GitHub.
