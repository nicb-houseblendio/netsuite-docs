In accounts where the Dunning Letters SuiteApp is installed, the **Dunning** tab is available to Dunning Director, Dunning Manager, Accountant, and A/R Clerk roles.

The **Dunning** tab provides links to the following:

-   Dunning Overview - To display the Dunning dashboard. See [Using the Dunning Dashboard](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4035801314.html).
    
-   Setup
    
    -   Setup > Bulk Update Customer Records - See [Bulk Updating Customer Records for Dunning](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4416049146.html).
        
    -   Setup > Dunning Configurations - See [Configuring Subsidiaries for Dunning](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4114440269.html).
        
    -   Setup > Dunning Level Rules - See [Creating Dunning Level Rules](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4043761763.html).
        
    -   Setup > Dunning Templates - See [Understanding Dunning Letter Templates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4022915731.html).
        
    -   Setup > Dunning Procedures - See [Creating Dunning Procedures](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4023009552.html).
        
    -   Setup > Dunning Bulk Assignment - See [Bulk Assigning Dunning Procedures](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4026429134.html).
        
    -   Setup > Dunning Procedure Priority - See [Setting the Priority Order of Dunning Procedures](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4043762880.html).
        
    -   Setup > Dunning Pause Reasons - [Creating Reasons for Pausing Dunning](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4035800285.html#bridgehead_4030781493).
        
-   Letters
    
    -   Email - See [Sending Dunning Letters Manually](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4047184180.html).
        
    -   PDF - See [Printing Dunning Letters](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4047183789.html).
        
-   Customer - To see the Customers list, to create a customer record, and to search for customers
    
-   Invoice - To see the Invoices list, to create an invoice record, and to search for invoices
    
-   Invoice Group - To see the Invoice Groups list, to create an invoice group record, and to search for invoice groups.
    
-   Document
    
    Email Template - See [Creating Dunning Letter Email Templates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4417696173.html).
    

For information about permissions to access to the dunning pages, see [Dunning Permissions and Access](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4429887110.html#section_4053299665)
