NetSuite recommends the following file naming and organization guidelines for the FreeMarker template files used for the dunning letter PDF.

## Dunning PDF Template File Naming Guidelines {#bridgehead_4047166388}

-   Use a descriptive name
    
-   Include the dunning level
    
-   Include the two-letter language code
    
-   Include the two-letter country code
    
-   Add the file name extension **.xml**
    

**Examples**

-   dunningbody\_level1\_en\_US\_pdf.xml
    
-   dunningheader\_level1\_en\_US\_pdf.xml
    
-   dunningfooter\_level1\_en\_US\_pdf.xml
    

## Dunning PDF Template File Organization {#bridgehead_4047166816}

Place your template files in the appropriate file cabinet folders provided by the Dunning Letters SuiteApp:

-   SuiteBundles > Bundle 392827 > Templates > PDF Templates > header
    
-   SuiteBundles > Bundle 392827 > Templates > PDF Templates > footer
    
-   SuiteBundles > Bundle 392827 > Templates > PDF Templates > body
