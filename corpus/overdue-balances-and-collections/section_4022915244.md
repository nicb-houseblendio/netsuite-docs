As part of automating the dunning process, you must first create dunning procedures and then assign them to customers, invoices and invoice groups. In a dunning procedure, you define the escalation points or dunning levels, the letter templates to use for each dunning level, and the minimum number of days interval for sending letters. Dunning levels define the thresholds for overdue amounts and days overdue.

Setting up dunning procedures involves the following steps:

1.  Create dunning templates. A template is assigned to each dunning level in a dunning procedure. You must create dunning templates and dunning template records before you can define dunning levels in a dunning procedure. See the following topics:
    
    -   [Creating Dunning Letter Email Templates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4417696173.html)
        
    -   [Creating Dunning Letter PDF Templates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4417694364.html)
        
    -   [Creating Dunning Template Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4047158704.html)
        
    
    Note:
    
    Creating templates requires knowledge of XML and FreeMarker.
    
2.  Create dunning level rules. A dunning level rule defines the thresholds of a dunning level. You must create dunning level rules before you can add dunning levels to a dunning procedure. See [Creating Dunning Level Rules](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4043761763.html).
    
3.  Create dunning procedures. A dunning procedure defines the dunning levels or escalation points that determine how and when a customer, invoice or invoice group will be dunned. See [Creating Dunning Procedures](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4023009552.html).
    
    1.  (Optional) Define selection criteria. You can define selection criteria to filter the invoices, invoice groups and customers to which the dunning procedure can be applied. See [Defining Dunning Selection Criteria](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4043764102.html).
        
    2.  Define dunning levels. Each dunning procedure must have at least one dunning level. Assign a dunning letter template record to each dunning level. See [Adding Dunning Levels to a Dunning Procedure](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4043763417.html).
        
4.  (Optional) Set the dunning procedure priority. After creating dunning procedures, you must order them according to priority if you're using automatic assignment or semiautomatic assignment of dunning procedures. In cases where more than one dunning procedure can be assigned to a customer, invoice or invoice group automatically or semiautomatically, the system will use the dunning procedure with the highest priority. See [Setting the Priority Order of Dunning Procedures](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4043762880.html).
    

When the dunning procedures have been set up, assign them to customers, invoices or invoice groups. See [Assigning Dunning Procedures](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4026415283.html).
