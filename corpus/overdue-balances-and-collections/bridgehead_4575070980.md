To create a multi-language dunning template record, refer to the following guide:

1.  Add languages to your company general preferences page. See [Configuring Multiple Languages](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N247147.html).
    
2.  In the **Language** field of customer records, select the customer's preferred language. See [Setting Preferences on the Customer Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1079031.html).
    
3.  Create a dunning template record and add a template for each language. See [Creating a Dunning Template Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4575072229.html).
    
4.  Create a dunning procedure and assign the dunning template record you created in Step 3. See [Creating Dunning Procedures](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4023009552.html).
    
5.  Assign the dunning procedure you created in Step 4 to the customer who should receive dunning letters based on this template. See [Assigning a Dunning Procedure to a Customer](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4023045916.html).
    

Be sure to read the following topics:

-   [Supported Languages for Dunning](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4575052821.html)
