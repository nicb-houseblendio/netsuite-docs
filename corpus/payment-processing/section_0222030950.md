You can import multiple agreement details into NetSuite for one or multiple rebate agreements using a single CSV file. Agreement Details records follow the applicable rebate preferences you set for the rebate agreement.

Important:

Ensure that the agreement names in the CSV file are unique and accurate to associate the agreement details to the correct rebate agreement that is already in NetSuite. In the CSV file, agreement details belonging to one rebate agreement should have similar rebate agreement name and external ID.

#### To import rebate agreement detail records:

1.  Go to Rebate Management > Rebate Agreements > CSV Rebate Data Imports > New
    
2.  On the CSV Rebate Data Imports page, in the **Import Type** field, select Rebate Agreement Detail.
    
3.  In the **CSV File** field, locate and select the CSV file with the data which you want to import.
    
    Note:
    
    You need to use the CSV template provided by the SuiteApp when importing rebate agreement records. To know where you can download the template, see [CSV Template Locations of Rebate Agreement Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_54085355988.html).
    
    If you add a file using the File explorer, click **Save** after you attach a file.
    
4.  On the CSV Rebate Data Import page, verify that the file is attached.
    
5.  Click **Save**.The following import details appear:
    
    | Field | Description |
    | --- | --- |
    | **ID** | This field shows the import ID. |
    | **Import Type** | This field shows whether you imported an agreement detail or a volume rebate tier. |
    | **CSV File** | This field shows the CSV file name. |
    | **Status** | This field shows import status of the rebate agreement details. |
    | **Message** | This field shows the number of records imported successfully. |
    | **CSV Response** | This field shows the system response for the CSV import process. |
    

If the data imports successfully, you can verify the imported records by going to Rebate Management > Rebate Agreements > Rebate Agreements. Then, select the record for which the you associate the agreement details.

If the data import fails, click the corresponding **CSV Response** link of the CSV file to view the errors you need to fix.
