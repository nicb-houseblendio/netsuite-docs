Custom roles are added to your account after installing the SFTP Connector SuiteApp. You can assign the custom role to employees who are going to transfer, download and decrypt payment files using the SuiteApp. The administrator has full permissions to all the roles and access in NetSuite. The following roles are specific to SFTP Connector SuiteApp:

-   **SFTP Set Up Role** - Users assigned to this role have full permissions to configure the SFTP Connector features and perform transfers, downloads and decryption of payment files.
    
-   **SFTP Operational Role** - Users assigned to this role can only view the account's SFTP Connector configuration and perform transfers, downloads and decryption of payment files. SFTP Operational role has full permissions to access the file cabinet.
    

The following table shows the default permissions assigned to the SFTP Set Up Role. If you're an administrator, you can configure these permissions and customize the role's level of access to the SFTP Connector SuiteApp. For more information, see [Customizing or Creating NetSuite Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N285937.html).

| Permission | Subtab Type | Minimum Permission | Permission Restriction |
| --- | --- | --- | --- |
| Certificate Management | Setup | Full | Full |
| Custom Sublists | Setup | Full | Full |
| File Cabinet | List | Full | Full |
| Perform Search | List | Full | Full |
| Outbound Configuration | Custom record | Full | Full |
| SFTP Folder Mapping | Custom record | Full | Full |
| Inbound Configuration | Custom record | Full | Full |
| Inbound Folder Mapping | Custom Record | Full | Full |
| Decryption Configuration | Custom Record | Full | Full |
| Payment Files Download Status | Custom Record | Full | Full |
| SuiteScript | Setup | Full | Full |

The following table shows minimum permissions required for a SFTP operational role to set up the SFTP SuiteApp, SFTP connector configuration and initiate transfer, download and decryption of payment files.
