You can schedule a payment file download for a specific date and time by using the **Inbound - Schedule** button on the Inbound Configuration page. This feature of the SFTP connector gives you the flexibility to download payment files in a scheduled manner. When you schedule a payment file download, all files in the processing folder are downloaded. If there are multiple folder mappings, then the files under all the folder mappings are downloaded when the schedule download is triggered.

#### To schedule a payment file download:

1.  Go to SFTP > SFTP Records > Inbound Configurations.
    
2.  Next to a record, click **View**.
    
3.  On the Inbound Configuration page, click the **Inbound-Schedule** button.
    
4.  A Script Deployment page is displayed. You can schedule the file download from this page.
    
    To know more about scheduling the file download from the Script Deployment page, see [Map/Reduce Script Deployment Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1509578980.html).
    
5.  Click **Save**.
