## Payment Processing with the Payment Instruments Feature Turned On {#subsect_1538484358}

The Payment Instruments feature makes it easier to use different payment methods and adds extra security for payment cards. A payment instrument is a set of fields you can use to charge a shopper without them needing to do anything.

The Payment Instrument feature substitutes sensitive data with tokens. Tokenization decreases the scope of Payment Card Industry (PCI) compliance considerations.

For information about payment processing with the Payments Instruments feature, see [Payment Instruments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1538492538.html).

## Payment Processing with the Payment Instruments Feature Turned Off {#subsect_1538484778}

NetSuite payment processing offers several options to capture and disburse payments.

See [Payment Processing Options](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/preface_4289351924.html) for a list of payment processing options in NetSuite.

Users with an A/R Clerk role can perform the following tasks:

-   Accept customer credit card payments. See [Accepting Credit Card Payments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1569326.html).
    
-   Manage payment holds. See [Managing Payment Holds](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1570238.html).
    
-   Apply payments to invoices. See [Customer Payments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1285644.html)
    
-   Email or print payment receipts. See [Payment Receipts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1293235.html).
    
-   Approve customer payments. See [Approving Customer Payments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4373987935.html).
    
-   Record Customer Deposits. See [Customer Deposits](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1296349.html).
    
-   Manage payments and deposits for a customer-subcustomer hierarchy. See [Consolidated Payments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1288474.html).
    
-   Process chargebacks. See [Chargeback Workflow](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4652069802.html).
    

Users with an A/P Clerk role can perform the following tasks:

-   Process direct deposits for employee payroll. See [About Direct Deposit](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N945815.html#chapter_N956015).
    
-   Process bank payments of vendor bills, employee expenses, partner and employee commissions through Electronic Payments. See [Electronic Bank Payments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N1585433.html).
    

Administrators can setup payment processing options and preferences. For more information, see the following topics:

-   [Alternative Non-Credit Card Payment Methods for Web Store Orders](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4213266422.html)
    
-   [Creating a Payment Method](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1292421.html)
    
-   [Maintaining Recurring Credit Card Payments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3887850446.html)
    
-   [Restricting Payment Processing Profiles by Customer Data](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1572588.html#bridgehead_4335053679)
