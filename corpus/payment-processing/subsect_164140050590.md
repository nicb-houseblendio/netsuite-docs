To print settlement transactions in PDF format, you need a PDF viewer such as Adobe® Acrobat® Reader. You can download the latest version for free from the Adobe website.

To print the vendor credit and vendor bill records, you need to enable the Advanced PDF/HTML feature. See [Enabling the Advanced PDF/HTML Templates Feature](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_1496243531.html).

#### To print a settlement transaction record: {#procedure_0927101327}

1.  Go to Rebate Management > Settlement > Settlement History.
    
2.  On the Settlement History List page, under the **Settlement Transaction #** column, click the link of the record that you want to open.
    
3.  On the settlement transaction record, hover over the print icon, and select **Print** from the list.
    
    Note:
    
    If you get an error message for an invalid PDF layout, follow the steps in [Editing a Rebate Management Custom Form](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_164009546662.html).
    
    -   If your preferences are set to print to PDF, a preview of the settlement transaction record opens in Adobe Reader.
        
    -   If your preferences are set to print to HTML, a preview of the settlement transaction record opens in your web browser.
        
    -   If the **Download PDF Files** preference is enabled on the Set Preferences page, you need to save the file to your computer, open it from there, and print it. If this preference is not enabled, NetSuite opens the settlement transaction PDF in your web browser.
        
4.  To print the record:
    
    -   When printing from PDF, click the Print button in Adobe Reader.
        
    -   When printing from HTML, print the page from your web browser.
