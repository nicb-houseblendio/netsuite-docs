When selecting a variable or function name, the following words and character sequences should not be used in your advanced templates:

-   \_2663\_ : as a prefix (for example, '\_2663\_name')
    
-   pfa
    
-   cbank
    
-   ebanks, ebank
    
-   entities, entity
    
-   payments, payment
    
-   transactions, transaction
    
-   sequences, sequence
    
-   currencies, currency
    
-   creditsHash, credit\_line
    
-   any word used in the function declarations and data from the [FreeMarker Template Library for Electronic Bank Payments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4002359161.html)
