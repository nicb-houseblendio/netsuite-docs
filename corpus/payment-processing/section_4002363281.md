-   isPrintOnCheckAs - flag to prioritize the **printoncheckas** entity field

## formatAmount(amount,format,separator) {#bridgehead_4002375005}

Formats a specified amount to be inserted into the payment file.

## Parameters {#bridgehead_4002375371}

-   amount - amount to be formatted
    
    -   Whole numbers or rational numbers
        
    -   Maximum of two decimal places
        
-   format - the format to be used
    
    -   Accepts any one of the following values - `dec`, `noDec`, `truncDec` or `decLessThan1`
        
    -   Default value is `noDec`
        
    -   `dec` and `decLessThan1` - absolute value, then round to two decimal places
        
    -   `noDec` - absolute value, then remove the decimal point
        
    -   `truncDec` - absolute value, then remove the decimal portion
        
    -   `currency` - absolute value, round to two decimal places and retain comma symbol
        
-   separator - used to split the integer portion and the decimal portion
    
    -   Default value is '.'
        
    -   Available for `dec` and `currency` format
        

## Returns {#bridgehead_4002380036}

-   String with formatted amount
    

## Example {#bridgehead_4002380416}

**Commands**

          `${formatAmount(-100.50,"dec")} ${formatAmount(100.50,"noDec")} ${formatAmount(100.50,"decLessThan1")} ${formatAmount(-100.50,"truncDec")} ${formatAmount(-1000.50,"currency")} ${formatAmount(100.50,"dec",",")}  ${formatAmount(1234.50,"currency",".")} ${formatAmount(0.50,"currency",".")} ${formatAmount(123.45,"currency",".")} ${formatAmount(1234567.89,"currency",".")} ${formatAmount(-1234567.89,"currency",".")}` 
        

**Output**

![Printed output of the previous code sample.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/OrderManagement/PaymentProcessing/formatAmountOutput.png) ![Printed output of the previous code sample.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/OrderManagement/PaymentProcessing/formatAmountOutput2.png)

## getSequenceId(forTodaySequenceOnly) {#bridgehead_4002385349}

Returns the raw sequence ID from search of the PFA record.

Note:

This function can be used for EFT and Direct Debit transactions only. Currently, it is not available for Positive Pay transactions.

## Parameters {#bridgehead_4002385726}

-   forTodaySequenceOnly - flag to filter today's PFA records only
    
    Accepts Boolean values `true` or `false`
    

## Returns {#bridgehead_4002386718}

-   Sequence ID number based on PFA search results
    

## Example {#bridgehead_4002398006}

**Commands**

## setPadding(data,padSide,padChar,length) {#bridgehead_4002404175}

Puts a padding to a string value.

## Parameters {#bridgehead_4002404536}

-   data - string to be processed
    
-   padSide - the side on which the padding is to be inserted
    
    Accepts values `left` or `right`
    
-   padChar - the character padding to be inserted
    
-   length - length to be set
    
    If length is less than data, data is truncated depending on the padSide value. For `left` padding, truncation is applied on the left side. For `right` padding, truncation is applied on the right side.
    

## Returns {#bridgehead_4002406839}

-   String with character padding
    

## Example {#bridgehead_4002407151}

**Commands**

The following commands cover all padding options for data with varying lengths:

          `${setPadding("abcde","left","0",10)} ${setPadding("abcde", "right", "0", 10)} ${setPadding("abcde", "right", "0", 3)} ${setPadding("abcde", "left", "0", 3)}` 
        

**Output**

![Printed output of the previous code sample.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/OrderManagement/PaymentProcessing/setPaddingOutput.png)
