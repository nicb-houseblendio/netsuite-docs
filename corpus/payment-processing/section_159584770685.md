The following are the known limitations of the SFTP Connector SuiteApp:

-   Supports both single-factor and multi-factor authentication by using one of the following methods:
    
    -   Username and password
        
    -   Username and certificate
        
    -   Username and SSH
        
    -   Username, password and certificate
        
    -   Username, password and SSH
        
-   Supports the following host key types:
    
    -   RSA
        
    -   DSA
        
    -   ECDSA
        
-   Supports SFTP with disabled IP allow list.
