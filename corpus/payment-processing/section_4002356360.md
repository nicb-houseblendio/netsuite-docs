The following NetSuite records can be included in custom payment file advanced templates by adding the corresponding keywords:

| Record | Keyword |
| --- | --- |
| [Company Bank Details Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4002426200.html) | cbank |
| [Payment File Administration Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_0810023408.html) | pfa |
