After creating a Suitelet file, you must save the file and add it to your account. For more information, see [Creating a Suitelet File](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0724122810.html)

#### To save the Suitelet file and add it to your account: {#procedure_0724090737}

1.  Go to Customization > Scripting > Scripts > New.
    
2.  Select the required file from the **Script File** list.
    
3.  Click **Create Script Record**.
    
4.  On the Script page, enter the required details.
    
5.  In the **Scripts** subtab, select the **EP API Plugin SS2** plug-in from the **Custom Plug-In Type** column.
    
    Note:
    
    If the custom plug-in **EP API Plugin SS2** status is not set to Release, then it is not displayed in the **Custom Plug-In Type** list.
    
6.  Click **Save**.
    
7.  Click **Deploy** to use the custom plug-in type.
