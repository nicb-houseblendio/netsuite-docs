After you generate a pro forma or settlement, the system generates and attaches a CSV and PDF files to the settlement record. You can use the CSV file to review the list of related transactions included in the pro forma or rebate settlement of a rebate agreement.

To set a default user for receiving the email notification with the CSV and PDF file attachments, go to List > Employees > Default User

The spreadsheet displays the following information:

| 
-   Transaction #
-   Transaction Date
-   Transaction Type
-   Subsidiary
-   Line #
-   Vendor Name/Customer Name
-   Item
-   Quantity
-   Units

 | 

-   Rate
-   Amount
-   Department
-   Class
-   Location
-   Rebate Amount
-   Payment-Transaction Type
-   Rebate Agreement

 |
| --- | --- |

## Accessing the CSV Files in the File Cabinet {#subsect_164265052820}

You can access or download the CSV files later if you didn't download them right after generating a pro forma or settlement.

#### To access the CSV files in the file cabinet: {#procedure_0927100133}

1.  Go to _Documents > Files > File Cabinet_.
    
2.  Click the **Rebate Settlement History** folder.
    
3.  Use the search bar on the left pane to enter one of these search queries:
    
    -   Name of the payee or payer
        
    -   Name of the payee or payer, underscore, and settlement type
        
        Example: PayerName\_Claim or PayeeName\_Disbursement
        
    -   To narrow the results, you can add a few digits for the claim or disbursement transaction # after the settlement type
        
        Example: PayerName\_Claim\_101 or PayeeName\_Disbursement\_201
        
4.  Do one of the following as needed:
    
    -   On the first column, click **Edit** next to the file you want to edit
        
    -   On the last column, click **Download** on the corresponding file
        
    -   Under the Name column, click the file name to download the file
