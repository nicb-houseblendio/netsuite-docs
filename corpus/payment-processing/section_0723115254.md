Using Electronic Bank Payments custom plug-in implementation you can create custom payment processing Suitelets for all the standard Suitelets. For more information about using custom plug-ins, see [Custom Plug-in Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_3976781171.html). Using the custom plug-in implementation, you can customize the standard payment processing Suitelet as per your requirements. You can add or remove filters and columns. You can also create your own custom Suitelet for all standard Suitelets.
