Undeploy rebate-related scripts used in the SuiteSolutions bundle to ensure that you don't have unnecessary scripts running in the background. The Rebate and Trade Promotions SuiteApp contains its own scripts which do not have to run alongside the scripts in the SuiteSolutions bundle.

Real-time Calculation Scripts:

-   NSTS | RM - Asnc Proces Script 1
    
-   NSTS | RM - Asnc Proces Script 2
    
-   NSTS | RM - Asnc Proces Script 3
    
-   NSTS | RM - Asnc Proces Script 4
    
-   NSTS | RM - Asnc Proces Script 5
    

Real-time Calculation Scripts:

-   NSTS | RM - ASync Process Script Sched Run
    
-   NSTS | RM - ASync Process Script SS
    
-   NSTS | RM - ASync Process Script Sched Run
