You must create the Electronic Bank Payments custom plug-in in your account. For more information, see [Custom Plug-in Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_3976781171.html)

Note:

If the custom plug-in is not added in your account then EP API SS2 plug-in is not displayed.

#### To create an Electronic Bank Payments plug-in: {#procedure_0724121118}

1.  Go to Customization > Plug-ins > Custom Plug-in Types > New.
    
2.  Select the **17239\_ep\_api\_plugin.js** script file from the **Script File** list.
    
3.  Click **Create Custom Plug-in Type**.
    
4.  On the Custom Plug-In Type page, enter the following details:
    
    -   Name - **EP API Plugin SS2**
        
    -   ID - **\_17239\_ep\_api\_plugin**
        
5.  In the **Methods** subtab, enter **getEPForm**.
    
    Note:
    
    **getEPForm** is case sensitive.
    
6.  Select **Release** status from the **Select** list.
    
7.  Click **Save**.
