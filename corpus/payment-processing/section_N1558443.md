Warning:

The ACH Processing integration with Coastal Software is no longer supported.

The ACH Processing integration was used by the [ACH Vendor Payments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1578816.html) and [Electronic Funds Transfer (EFT)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1564990.html) features.

If you are still using these features, you should implement other solutions. See the following topics for other payment solutions you should consider: [Payment Automation SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_7081807195.html), [Electronic Bank Payments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N1585433.html), and [Payment Instruments Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157062877911.html).

For additional options, go to SuiteApp.com to view available SuiteApps for [Accounts Payable](https://www.suiteapp.com/search?keywords=accounts%20payable), [Accounts Receivable](https://www.suiteapp.com/search?keywords=accounts%20receivable) and [SuitePayments Partner Solutions](https://www.suiteapp.com/search?keywords=suitepayments).

Note:

The ACH processing feature does not apply to the ACH payments feature for Commerce websites. See [ACH Payments on Commerce Web Stores](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162737287771.html) for information about the Commerce feature.
