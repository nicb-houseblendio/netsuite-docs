Note:

Electronic Bank Payments API is only available if you have an active Electronic Bank Payments license and the NetSuite SuiteApps License Client installed.

You can create custom Payment Processing Suitelet for all standard Suitelets using a custom plug-in implementation. For more information, see [Custom Payment Processing Suitelet for All Standard Suitelets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0723115254.html). Every custom Payment Processing Suitelet is identical to the standard processing Suitelets available in Electronic bank payment SuiteApp.
