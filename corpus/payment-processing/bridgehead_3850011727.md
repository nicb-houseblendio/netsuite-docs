Electronic Bank Payments supports direct debit payment formats listed in the following table:

| Country | Direct Debit Format | Required SuiteApps |
| --- | --- | --- |
| **Australia** | ABA DD |  |
| **Belgium** | SEPA Direct Debit (ABN AMRO) | [EMEA Localization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_157122959910.html) For more information, see [EMEA Localization Payment Templates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158858392029.html) and [Belgium Payment Formats](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156742828189.html). |
| **France** | SEPA Direct Debit (ABN AMRO) | [EMEA Localization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_157122959910.html) For more information, see [EMEA Localization Payment Templates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158858392029.html) and [France Payment Formats](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557744471.html). |
| **Germany** | DTAUS DD | [EMEA Localization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_157122959910.html) Germany Localization For more information, see [EMEA Localization Payment Templates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158858392029.html) and [Germany Electronic Bank Payments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1554985535.html). |
| SEPA Direct Debit (Germany) |
| **Italy** | CBI Collections |  |
| SEPA Direct Debit (CBI) |
| **Luxembourg** | SEPA Direct Debit (ABN AMRO) | [EMEA Localization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_157122959910.html) For more information, see [EMEA Localization Payment Templates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158858392029.html). |
| **Netherlands** | SEPA Direct Debit (ABN AMRO) | [EMEA Localization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_157122959910.html) For more information, see [EMEA Localization Payment Templates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158858392029.html) and [Netherlands Localization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157537910220.html). |
| **Singapore** | DBS - IDEAL DD (DBS Bank) UoB - BIB-IBG DD (United Overseas Bank) | [Southeast Asia Localization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1532415717.html) |
| **Spain** | SEPA Direct Debit (ABN AMRO) | [EMEA Localization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_157122959910.html) For more information, see [EMEA Localization Payment Templates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158858392029.html). |
| **United Kingdom** | BACS DD | [EMEA Localization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_157122959910.html) [United Kingdom Localization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157131293913.html) For more information, see [EMEA Localization Payment Templates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158858392029.html) and [United Kingdom Payment Formats](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156922746724.html). |
| **United States** | ACH - PPD (NACHA) |  |

Note:

To distinguish between direct debit formats with the same name as EFT formats, the direct debit formats will have the **DD** suffix.
