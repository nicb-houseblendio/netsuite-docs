After you've installed the SuiteApp and set up the required item, customer, and vendor records, you must create a Rebate Preferences record. The system uses this record to categorize which records contain the same criteria for applying rebates when you import rebate agreements. See, [Setting Rebate Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163653866086.html).
