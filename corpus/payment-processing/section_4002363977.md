The Electronic Bank Payments SuiteApp uses the following data in payment file templates:

| Data | Description |
| --- | --- |
| [transHash](#bridgehead_4002419916) | Hash containing transaction search results (sequence) as values with payment internal ID as keys |
| [creditsHash](#bridgehead_0729092344) | Hash containing applied credits transaction query results (sequence) as values with payment internal ID as keys |

## transHash {#bridgehead_4002419916}

Hash containing transaction search results (sequence) as values with payment internal ID as keys

## Example {#bridgehead_4002421604}

Map of payments and transactions:

![Block diagram showing 2 payments, each with 2 mapped transactions.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/OrderManagement/PaymentProcessing/transHash.png)

**Command**

Transaction IDs for Payment #2 can be printed using the following command:

          `<#list transHash["2"] as transaction>  ${transaction.tranid} </#list>` 
        

**Output**

![Printed output of the previous code sample.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/OrderManagement/PaymentProcessing/DataOutput.png)

## creditsHash {#bridgehead_0729092344}

Hash containing applied credits transaction query results (sequence) as values with payment internal ID as keys.

## Example {#bridgehead_0729092440}

Map of payments and applied credit transactions:

![Block diagram showing 2 payments, each with 2 mapped applied credit transactions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/OrderManagement/PaymentProcessing/creditsHash.png)

**Command**

Credit Transaction IDs for Payment #2 can be printed using the following command:

          `<#list creditsHash["2"] as credit_line> ${credit_line.tranid} </#list>` 
        

**Output**

![Printed output of the previous code sample.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/OrderManagement/PaymentProcessing/creditsHashDataOutput.png)
