Use PayPal Express Checkout to capture funds if you process orders from a web store. Express Checkout enables you to offer PayPal as a payment method to your customers.

For information about setting up and using Express Checkout, see [PayPal Integration and Express Checkout for Commerce Web Stores](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2470255.html).
