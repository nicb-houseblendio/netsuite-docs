The rebate agreement record has the following subtabs:

| Subtab | Description |
| --- | --- |
| **Related Transactions** | Review the list of all posting transactions with rebates created for the rebate agreement. Use these filters to display specific transactions:
-   Transaction Date
-   From
-   To
-   Transaction #
-   Entity
-   Item

 |
| **Journal** | View all posting transactions related to the accrual record of a rebate agreement. The following columns show up on the journal subtab:

-   Date
-   Document Number
-   Amount
-   Amount (Foreign Currency)
-   Currency
-   Status

 |
