NetSuite lets you add multiple rebate agreements through CSV import. You need to use a unique name for the agreement name that is not yet present in the system.

#### To import a rebate agreement using a CSV file:

A confirmation message with a link to view the **Import Job Status** appears above the Import Assistant header.

If the data imports successfully, you can verify the imported records by going to Rebate Management > Rebate Agreements > Rebate Agreements.

If the data import fails, click the corresponding **CSV Response** link of the CSV file to view the errors you need to fix.

1.  Go to Rebate Management > Rebate Agreements > Import Agreement
    
    Alternatively, you can go to Setup > Import/Export > Saved CSV Imports. Then, on the Saved CSV Imports page, click the file **Rebate Agreement Import (DO NOT DELETE)**.
    
    Both pathways take you to the Import Assistant page with pre-populated field values for the rebate agreement import steps.
    
2.  On the Scan & Upload CSV File step, verify that the following fields contain the required values:
    
    1.  **Import Type:** Custom Record
        
    2.  **Record Type:** Rebate Agreement
        
    3.  **Character Encoding:** Western (Windows 1252)
        
    4.  **CSV Column Delimiter:** Comma
        
    5.  **CSV File(s):** One File to Upload
        
3.  Click **Select** to add a CSV file with the data which you want to import.
    
    Note:
    
    Consider the following:
    
    -   You must use the CSV template provided by the SuiteApp when importing rebate agreement records. To know where you can download the template, see [CSV Template Locations of Rebate Agreement Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_54085355988.html).
        
    -   In creating a Rebate Agreement through CSV import, you cannot enter a multiple type record (such as a customer that is also be a vendor) with a Partner as primary entity.
        
    -   The Rebate Agreement name should be unique to avoid any conflicts.
        
    
4.  Click **Next**.
    
5.  On the Import Options step, the following fields contain the required values:
    
    1.  Under Data Handling, the **Add** is preselected.
        
    2.  Under Advanced Options, verify that the following boxes are checked and the fields contain the required values:
        
        | Field/Checkbox | Value |
        | --- | --- |
        | **Validate Mandatory Custom Fields** | Checked |
        | **Ignore Read-only Fields** | Checked |
        | **Run Trigger SuiteScript and Trigger Workflows** | Checked |
        | **CSV Decimal Delimiter** | Period |
        | **Custom Form** | CSV Rebate Agreement Form |
        
    3.  Click **Next**.
        
        The File Mapping step also completes and proceeds to Step 4.
        
    4.  On the Save mapping & Start step, verify the CSV file name in the **Import Map Name** field.
        
    5.  Click **Save & Run**.
