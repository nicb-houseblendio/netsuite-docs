Removes an existing (default) field from the Payment Information group of the Bill Payment Processing page. Note that some default fields cannot be removed. See [Default Fields - Custom Bill Payment Processing Page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4024135775.html) to determine whether a particular default field can be removed.

## Parameters {#bridgehead_4000008539}

-   `id` {string} \[required\] - The field ID of the existing field that you want to remove.
    

## Returns {#bridgehead_4448299441}

-   void
    

## Throws {#bridgehead_4448299544}

-   `EP_MISSING_FIELDS` - Thrown when a required argument is missing. Logs 'Please enter required id of field to be removed.'
    
-   `EP_INVALID_VALUE` - Thrown when an invalid argument is passed. Logs 'Field custpage\_2663\_xxxxx cannot be deleted.'
    

## Example {#bridgehead_4000883073}

          `var epPaymentSelectionForm = new EPPaymentSelectionForm();  epPaymentSelectionForm.RemoveField('custpage_2663_aggregate');`
