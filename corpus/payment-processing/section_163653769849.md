Administrators can create new roles or customize roles to use in the Rebates and Trade Promotions SuiteApp. For more information, see [Assigning Roles to an Employee](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N897798.html) and [Customizing or Creating NetSuite Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N285937.html).

## Rebates and Trade Promotions Roles {#subsect_22140451268}

There are no custom roles included when you install the SuiteApp. The following groups describe what the users can set up or create in the SuiteApp, depending on what the Administrator allows.

-   **Sales Users** - These users create, select, or modify rebates on sales transactions.
    
-   **Rebate Administrators** - These users set up the preferences and create new rebate agreements used to calculate rebates on transactions created by sales users.
    

Important:

Before upgrading or installing a new version of the SuiteApp, set some roles to active by going to Setup> Users/Roles> Manage Roles. Then, clear the box for these roles:

-   accountant
    
-   accountant\_reviewer
    
-   bookeeper
    
-   ceo
    
-   ceo\_hands\_of
    
-   customrole41
    
-   customrole42
    
-   cusomrole43
    

The system requires these roles to be active to install the custom forms in the SuiteApp. After the upgrade or installation, you can set the roles to inactive again.
