A settlement transaction record, which is a claim transaction or a disbursement transaction, is listed in the settlement record. Settlement transaction records include invoice, credit memo, bill, and bill credit. You can't edit settlement records for claims, disbursements, or pro formas.

Read the following topics for more information about rebate settlement records:

-   [Contents of a Pro Forma or a Settlement Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_164009412884.html)
    
-   [CSV and PDF Files Attachment on the Pro Forma or Settlement Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_164009375608.html)
    
-   [Accessing the CSV Files in the File Cabinet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_164009375608.html#subsect_164265052820)
    
-   [Printing a Settlement Transaction Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_164140050590.html)
    
-   [Editing a Rebate Management Custom Form](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_164009546662.html)
    

Important:

Avoid editing invoices or transaction records after you generate a settlement.

An entry in the Settlement History list can contain one of the these statuses:

-   Claim- Pro Forma
    
-   Disbursement- Pro Forma
    
-   Claim- Completed
    
-   Claim- Error
    
-   Disbursement- Completed
    
-   Disbursement- Error
    

To print a settlement transaction record, see [Printing a Settlement Transaction Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_164140050590.html).
