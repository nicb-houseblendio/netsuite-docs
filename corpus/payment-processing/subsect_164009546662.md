You can edit the following rebate management custom forms:

-   RM Invoice Claim
    
-   RM Vendor Credit
    
-   RM Credit Memo Disbursement
    
-   RM Vendor Bill
    

#### To edit the RM custom form: {#procedure_0927101440}

1.  Go to _Customization > Forms > Transaction Forms_.
    
2.  On the Custom Transaction Forms page, click **Edit** next to the custom form you want to edit.
    
    1.  For RM Invoice Claim and RM Credit Memo Disbursement:
        
        -   In the **PDF Layout** field, select **Standard Transaction Layout**.
            
        -   In the **HTML Layout** field, select **Standard HTML Transaction Layout**.
            
        -   In the **Email Message Template** field, select **Default Email Template**.
            
    2.  For RM Vendor Credit:
        
        -   In the **Print Template** and **Email Template** fields, select **Standard Vendor Credit PDF/HTML Template**.
            
    3.  For RM Vendor Bill Disbursement:
        
        -   In the **Print Template** and **Email Template** fields, select **Standard Vendor Bill PDF/HTML Template**.
            
3.  Click **Save**.
