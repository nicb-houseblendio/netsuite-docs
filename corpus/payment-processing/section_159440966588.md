## Prerequisites {#bridgehead_159440972816}

You must make sure the following features are enabled in your account before you install the SFTP Connector SuiteApp:

-   File Cabinet
    
-   Custom Records
    
-   Client SuiteScript
    
-   Server SuiteScript
    

For more information, see [Enabling Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N232138.html)

## Installing the SFTP Connector SuiteApp {#bridgehead_159440983066}

**Installing SFTP Connector**

Install the SFTP Connector SuiteApp from the SuiteApp Marketplace in NetSuite to perform the following tasks on installing the SuiteApp, see [Installing from the SuiteApp Marketplace](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1539799323.html).

-   Directly transfer payment files from NetSuite to the bank server
    
-   Directly download payment files from bank server to NetSuite
    

The SFTP Connector SuiteApp is a not a managed SuiteApp. You have to manually update the SuiteApp from the SuiteApp Marketplace whenever there are updates. The issue fixes and enhancements are available after the SuiteApp is updated in your production or Sandbox account. For information about upgrading the SuiteApp, see [Upgrading from the SuiteApp Marketplace](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1562350978.html).
