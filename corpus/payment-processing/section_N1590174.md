You need to create folders in the NetSuite File Cabinet to store payment files used by the Electronic Bank Payments SuiteApp. You can create folders for each type of payment file, or create one folder to store all payment files regardless of the format used.

Important:

You must not choose the **Attachments Sent** or **Attachments Received** folders as a file cabinet location, including their subfolders. Files generated from these folders can't be properly attached to payment file administration records. For more information, see [Attaching Files to Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N490137.html).

#### To create a folder in the NetSuite file cabinet: {#procedure_N1590186}

1.  Go to _Documents > File > File Cabinet > New_.
    
2.  In the **Folder Name** field, enter a name for the folder to be used by the Electronic Bank Payments SuiteApp. For example, **EFT File Repository**.
    
3.  Enter information in the optional fields as necessary. For more information, see [File Cabinet Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N541319.html).
    
4.  Click **Save**. The folder that you created is now displayed in the File Cabinet Folders list.
