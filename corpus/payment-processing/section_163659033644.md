Use the pro forma to review the details of the upcoming settlement before you approve a claim or generate a disbursement. You can edit the settlement details to apply needed adjustments, then proceed to generating a settlement.

A pro forma includes the agreement's primary information, total settlement amount, settlement details, and a list of supporting transactions.

-   **Claim Pro Forma** - You can generate a claim pro forma for rebate agreements when receiving rebates.
    

-   **Disbursement Pro Forma** - You can generate a disbursement pro forma for rebate agreements when paying rebates.
    

You can click **Generate Claim** or **Generate Disbursement** from the pro forma record to directly process a settlement.

Pro forma records are generated on the Settlement page, and the process uses the same filters as generating a rebate settlement. To generate a pro forma, read [Generating Settlements Manually](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_163659120846.html).

## Multiple Pro Forma for One Rebate Agreement {#subsect_164027152680}

You can generate multiple pro forma records for one rebate agreement when processing partial settlements. You cannot reuse the transactions you included in the previous pro forma.

If a pro forma exists for the total unsettled amount, you can't generate another pro forma or settlement for the same agreement. You can rerun the search to process additional rebate agreements or generate a claim or disbursement within the pro forma record.

Alternatively, you can delete the existing pro forma record to create a new one, then generate a settlement on the Settlement page.
