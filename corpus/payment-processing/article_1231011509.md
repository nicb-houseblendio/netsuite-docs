To set up the Rebates and Trade Promotions SuiteApp, you should perform these steps:

1.  Enable required features in your NetSuite account. See [Prerequisites for Rebates and Trade Promotions SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163653688363.html).
    
2.  Install the Rebates and Trade Promotions SuiteApp. See [Installing the Rebates and Trade Promotions SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163653731704.html).
    
3.  Configure the roles and permissions for the Rebates and Trade Promotions SuiteApp. See [Rebates and Trade Promotions Roles and Permissions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163653769849.html)
    
4.  Set up accounting item records. See [Creating Accounting Item Records for Rebates and Trade Promotions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164207784255.html).
    
5.  Set up vendor and customer records. See [Creating Vendor and Customer Records for Rebates and Trade Promotions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163647652806.html).
