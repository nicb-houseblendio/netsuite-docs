The following example shows how you can enter multiple agreement details in a CSV file.

For each group of agreement details, you can assign a unique External ID. An External ID provides a means to reference an object by its foreign key in an external database. See, [External IDs Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3433806.html).

The first group with 5 rows are assigned to External ID 101. Then, for the remaining 4 rows of agreement details has an external ID of 102.

Note:

Each rebate agreement detail can only have one value for Calculation Method and Calculation Basis.
