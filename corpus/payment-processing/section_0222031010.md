Similar with importing agreement details, you can import rebate tiers using CSV Rebate Data Imports.

A tier data must include a range or structure of values for sales targets and the corresponding rebates.

Important:

Tier names are case-sensitive. Create a unique tier name that is not yet present in the system. NetSuite associates a rebate tier to an agreement detail if the tier names match in the agreement details and volume rebate tiers CSV files.

#### To import volume rebate tiers:

1.  Go to Rebate Management > Rebate Agreements > CSV Rebate Data Imports > New
    
2.  On the CSV Rebate Data Imports page, in the **Import Type** field, select Rebate Volume Tier.
    
3.  In the **CSV File** field, locate and select the CSV file with the data which you want to import.
    
    Note:
    
    You must use the CSV template provided by the SuiteApp when importing rebate volume tier records. To know where you can download the template, see [CSV Template Locations of Rebate Agreement Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_54085355988.html).
    
4.  If you add a file using the File Explorer, click **Save** after you attach a file.
    
5.  On the CSV Rebate Data Import page, verify that the file is attached.
    
6.  Click **Save**.
    

If the data imports successfully, you can verify the imported records by going to Rebate Management > Rebate Agreements > Rebate Volume Tiers.

If the data import fails, click the corresponding **CSV Response** link of the CSV file to view the errors you need to fix.
