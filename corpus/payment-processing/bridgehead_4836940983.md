In setting up Queue Management, be guided by the following best practices:

-   Make sure declared script deployments in a row is in the same queue.
    
-   Subsidiaries shouldn't be sharing the same queue. This means that a queue will only run the processes of a particular subsidiary, which will be more efficient.
    
-   Avoid declaring blank value in the subsidiary column.
    
-   Assign the Scheduler script deployment value to the least used queue.
