You can import multiple rebate agreements, agreement details, or rebate tiers into NetSuite through CSV import for each group of records. The SuiteApp gives you a CSV template for each record type with all the same fields which are in NetSuite.

Before you import any CSV file, ensure that you set the preferences for your chosen rebate type.

Read the topic [Guidelines for Importing Rebate Agreement Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_51202105201.html) to learn the prerequisites and considerations in importing rebate agreement records.

You can import your data in this order:

| Record | Help Topic |
| --- | --- |
| 1\. Rebate Agreements | [Importing Rebate Agreements Using a CSV File](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0222030923.html) |
| 2\. Agreement Details | [Importing Agreement Details Using a CSV File](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0222030950.html) Important: For volume rebates, make sure you import the Rebate Volume Tiers record first before you import agreement details. For transactional rebates, you can import agreement details after you import rebate agreements. |
| 3\. Rebate Volume Tiers | [Importing Rebate Tiers Using a CSV File](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0222031010.html) |
