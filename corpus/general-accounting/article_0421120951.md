Before you install the Account Matching Report SuiteApp, you must enable the following features in your NetSuite account. To enable features, go to _Setup > Company > Enable Features_. For more information, see [Enabling Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N232138.html).

| Feature | Enable Features Subtab |
| --- | --- |
| Multi-Language | Company |
| Multiple Currencies |
| Multiple Calendars | Accounting |
| Accounting |
| A/R (Accounts Receivable) |
| A/P (Accounts Payable) |
| Server SuiteScript | SuiteCloud |
