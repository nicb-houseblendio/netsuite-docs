You can edit direct budget exchange rates for periods that are not closed. Direct rates are those between child and parent subsidiaries. Indirect rates, also known as implied rates, between subsidiaries more than one hierarchical level removed from each other can't be edited.

You can't edit rates for elimination subsidiaries.

Your user role must have the Currency permission with Full permission level to work with budget exchange rates. You can edit a budget exchange rate between two subsidiaries only if you have access to both subsidiaries.

The Budget Exchange Rates page supports inline editing. For information, see [Using Inline Editing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N495192.html). If this is not an option in your account, use the following procedure.

#### To edit budget exchange rates:

1.  Go to _Lists > Accounting > Budget Exchange Rates_.
    
2.  Click **Edit** to the left of the open period and subsidiary pair you want to edit.
    
    If the rates are not eligible for editing, you receive an error.
    
    Tip:
    
    If you don't see the budget exchange rate you want to edit, check the Filters at the top of the list.
    
3.  Enter new rates in one or more of the following fields, as appropriate:
    
    -   **Average Exchange Rate**
        
    -   **Current Exchange Rate**
        
    -   **Historical Exchange Rate**
        
4.  Click **Save**.
    

The Budget Exchange Rates list stores three rate type values for each period, accounting book, and subsidiary pair. You can see only those subsidiaries and accounting books to which you have access. The rate types correspond with the consolidated exchange rate types. For an explanation of these rate types, see [Consolidated Exchange Rate Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1405625.html).
