Close manager task records help you assign, track, and manage Intelligent Close Manager (ICM) tasks outside the dashboard portlet. A close manager task record can represent one or more tasks for the same task name, accounting period, and subsidiary.

To view or edit close manager task records, you must have the Manage Accounting Periods permission and enable the Intelligent Close Manager feature.

To access close manager task records, you can do either of the following:

-   Go to Lists > Accounting > Close Manager Tasks (Administrator). On the Close Manager Tasks list page, click **Edit** or **View** next to the task record.
    
-   In the Intelligent Close Manager portlet, click the **Prioritized tasks** tab, and then click the link in the Name column.
    

Task record links in the ICM portlet are available only when the portlet is filtered to the first open accounting period and you're viewing the Prioritized tasks tab.

To complete system-generated tasks, you can do either of the following:

-   From the Intelligent Close Manager portlet, click the number in the Tasks column.
    
-   From the close manager task record, click the link in the Task field.
    

Both links open the page where you can complete the tasks.

For system close manager task types created by NetSuite, the following fields are read-only. For custom tasks, you can edit the following fields.

| Field | Description |
| --- | --- |
| Task Name | This field identifies the close manager task record. For example, if the related tasks are Approve journal entries, the task name is Approve journal entries. If it's a custom task, enter a task name that helps you quickly identify the task. |
| Task Type | This field identifies the type of close manager task record. All close manager task records are system-generated. The type is either System for system-generated or Custom for tasks created by users. |
| Task | This field is only available for system-generated tasks. This field contains a link to the page where you can complete the tasks associated with the task record. For example, if you're on an Invoice sales orders task record, the link is named Invoice sales orders and opens the Invoice Sales Orders page. The page shows the sales orders that need to be invoiced for the corresponding subsidiary and accounting period. |
| Category | This field identifies the task category, such as A/R, A/P, Accounting, or General. General tasks are created by the user and appear in the Custom tab in the ICM portlet. |
| Subsidiary | This field identifies the subsidiary associated with the task record. For system-generated tasks, the value corresponds to the subsidiary of the tasks associated with the task record. |
| Accounting Period | This field identifies the accounting period associated with the task record. For system-generated tasks, the value corresponds to the accounting period of the tasks associated with the task record. |

You can edit the following fields when the task record's accounting period is open or locked:

| Field | Description |
| --- | --- |
| Assigned To | This field identifies the person or team assigned to complete the task. It's blank by default. |
| Send Email | This box indicates whether NetSuite sends an email notification to the assignee. If it's checked, a notification email is sent to the assignee. The assignee must have a valid email address before you can save the task record. It's blank by default. |
| Status | This field identifies the status of the task record. The default status is Not Started. You can update the status to In Progress or Completed. NetSuite changes the status to Completed when no tasks remain in the task record or when the record's accounting period is closed. If the record's accounting period is reopened, NetSuite changes completed task records to In Progress. |
| Start Date | For system generated tasks, this field defaults to the date when NetSuite created the task record. You can change this field to any date that is on or before the due date. For custom tasks, this field defaults to the first day of the first open accounting period. |
| Due Date | For A/R and A/P tasks, this field defaults to the start date. For Accounting tasks, the due date defaults to the accounting period end date unless that date is earlier than the start date. In that case, the due date defaults to the start date. For custom tasks, this field defaults to the last day of the first open accounting period. You can change this field to any date that is on or after the start date. |
| Date Completed | This field is populated automatically with the date the task record status is set to Completed. You can change this date after the status is set to Completed. If you edit this field before the status is set to Completed, your changes aren't saved. |
