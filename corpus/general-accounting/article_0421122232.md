By default, only the Administrator can access the Account Matching Report page. An Administrator can create or customize roles for the Account Matching Report SuiteApp. For more information, see [Assigning Roles to an Employee](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N897798.html) and [Customizing or Creating NetSuite Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N285937.html).

Important:

To avoid issues, the AMR Customized Model role of the SuiteApp should not be customized.

The following permissions are required to access the Account Matching Report page:

| Subtab | Permission | Minimum Access Level |
| --- | --- | --- |
| Transaction | Find Transaction Note: To avoid issues with reconciling balances, make sure you grant permissions for the transaction types included in the Administrator role. | View |
| Lists | Accounts | View |
| Fiscal Calendars | View |
| Perform Search | View |
| Subsidiaries | View |
| Currency | View |
| Setup | Accounting Book Note: This permission is only available if the Multi-Book Accounting features are enabled. For more information, see [Enabling Multi-Book Accounting Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4842473026.html). | View |
| Manage Accounting Periods | View |

The Administrator must grant custom roles access to the Account Matching Report page using the Single Page Application (SPA) record.

Warning:

The Administrator should only edit the **Release Audience** section in the SPA record. Editing other fields may cause issues within the application.

#### To grant access to the Account Matching Report page:

1.  Go to _Customization > Scripting > Single Page Applications_.
    
2.  Click the **Account Matching Report** link.
    
3.  Click the **Configuration** tab.
    
4.  In the Release Audience section, click **Set Up Audience**.
    
5.  On the Audience Setup window, check the box next to the role that you want to grant access.
    
6.  Click **Save**.
