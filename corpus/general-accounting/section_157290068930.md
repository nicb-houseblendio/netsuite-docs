The Currency Exchange Rate Types feature is available only in NetSuite OneWorld accounts. To enable the Currency Exchange Rate Types feature, you must first enable the Multiple Currencies feature. For information about this feature, see [Multiple Currencies](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1395463.html).

Additionally, you must enable one or both of the following features:

-   **Intercompany Framework** - For information about this feature, see [Intercompany Framework](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_158142795285.html).
    
-   **Subscription Metrics SuiteApp** - For information about this SuiteApp, see [Subscription Metrics](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1215935976.html).
    

When you enable the Currency Exchange Rate Types feature, NetSuite assigns your existing exchange rates a currency exchange rate type called Default Currency Exchange Rate Type. Currency exchange rate records gain a new required field called Exchange Rate Type. NetSuite automatically sets the value of the Exchange Rate Type field to the default on all existing currency exchange rate records.

You can use an alternate currency exchange rate type as your Corporate Exchange Rate Type for intercompany cross charges. You select your Corporate Exchange Rate Type on the Accounting subtab of the Intercompany Preferences page at _Setup > Accounting > Preferences > Intercompany Preferences_. For more information, see [Intercompany Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1549982657.html).

All currency exchange rates in NetSuite, except intercompany cross charges, use the default currency exchange rate type.

Note:

After you enable the Currency Exchange Rate Types feature, you can't disable it.

#### To enable the Currency Exchange Rate Types feature:

1.  Go to _Setup > Company > Enable Features_ again.
    
2.  On the **General** subtab, in the International section, check the **Currency Exchange Rate Types** box, and click **Save**.
