## Best Practices {#subsect_159307226403}

-   You must only install Sequential Liability during off-peak hours. Installation runs scheduled scripts and modifies records. It may take some time to finish.
    
-   The results table in the Project A/P - A/R Summary and Project A/P - A/R Details pages is at optimum performance with a maximum of 50 vendors, having a maximum of 10 transactions each.
    
-   When using CSV Import, be sure to set the **Run Server SuiteScript and Trigger Workflows** preference in two places so existing records are shown when you use Sequential Liability.
    
    1.  Go to Setup > Import/Export > CSV Import Preferences and check the **Run Server SuiteScript and Trigger Workflows** box.
        
    2.  Go to Setup > Import/Export > Import CSV Records. In the Import Options of the Import Assistant, check the **Run Server SuiteScript and Trigger Workflows** box.
        
    
    Note:
    
    You must set the preference in both the CSV Import Preferences and Import Options pages.
    
-   Click **Refresh** on the Sequential Liability custom portlet to include recent transactions and to update the A/P Balance, A/R Balance, Receipts, and Payments KPI tiles on the dashboard.
    
-   When the Approval Routing feature is enabled, you must approve posting transactions so they are included in the Sequential Liability computations.
    

## Limitations {#subsect_159307228043}

-   When entering vendor bills and vendor credits, you must associate each expense line or item line in a vendor bill or vendor credit to the same project. For instructions on associating a vendor bill or vendor credit to a project, see [Associating Vendor Bills and Vendor Credits to a Project](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158071367737.html).
    
    In instances where the project isn't the same for each expense line or item line, Sequential Liability only considers the first project in the expense line. The total amount of the vendor bill or vendor credit is calculated and billed to the first project in the expense line. If there is no project association in any of the expense lines, Sequential Liability then considers the first project in the item line. The total amount of the vendor bill or vendor credit is then calculated and billed to the first project in the item line.
    
-   The bank balance amount displayed when using this SuiteApp is always shown in the subsidiary's currency.
    
-   You can display a maximum of 25 collapsed rows in the results table of the Project A/P - A/R Summary page, Project A/P - A/R Details page, and in the A/P - A/R Details subtab of the project record.
    
-   The Sequential Liability custom portlet is only available for Accounting Center roles, such as financial users in the organization. Roles that do not belong in the Accounting Center, such as consultants, cannot set up the Sequential Liability custom portlet.
    
-   Sequential Liability reports can handle a maximum of 20,000 of the following related records combined:
    
    -   Customers
        
    -   Projects
        
    -   Vendors
        
    -   Bills mapped to a customer or project record
        
    -   Invoices mapped to a customer or project record
