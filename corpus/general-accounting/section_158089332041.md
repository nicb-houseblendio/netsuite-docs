Before installing Sequential Liability, an administrator must first do the following:

-   Disable the **Consolidate Projects on Sales Transactions** preference. For more information about this preference, read [Using the Project Consolidation Preference](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1186943.html).
    
-   Enable the required features. See the following table for a list of required features for this SuiteApp. For information about enabling features, read [Enabling Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N232138.html).
    
    | Subtab | Feature |
    | --- | --- |
    | Company | Departments |
    | Locations |
    | Classes |
    | Projects |
    | Project Management |
    | Accounting | Accounting |
    | A/R |
    | A/P |
    | SuiteCloud | Custom Records |
    | Client SuiteScript |
    | Server SuiteScript |
