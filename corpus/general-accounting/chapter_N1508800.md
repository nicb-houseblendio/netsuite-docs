An account register is a list of transactions for a particular account, for a selected date range, with the ending balance. NetSuite provides registers for posting and non-posting accounts. Each register includes detailed information about all transactions affecting the account for a selected time period, including balance information.

You can use registers to review and manage account transactions. You can access and edit transaction records from registers, reconcile accounts, and mark transactions as cleared. For information about how to access and use account registers, see [Viewing Account Registers](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1509014.html).

For information about the types of account registers available to you in NetSuite, see [Available Account Registers](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1511955.html).

In addition to single account registers, NetSuite provides several register reports. Each of these reports combines data for all registers of a specific type. Register reports offer more display options than single account registers, but don't provide access to transaction editing or account reconciliation. For a list of available register reports, see [Register Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1518725.html).

For more information about controlling access to account registers, see [Controlling Access to Account Registers](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164810963247.html).
