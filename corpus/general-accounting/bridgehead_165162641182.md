Note:

This topic only applies if you've selected record types you want to save as a draft using the Enable Draft Status preference. For more information, see [Setting Up Prerequisites for Supported Record Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_1556694406.html).

The Enable Draft Status preference only supports transaction records created in the NetSuite user interface.

If you enable the draft status preference for a record type, the approval process won't start automatically when you save a record. Instead, the records are saved in draft state. For information about enabling draft status, see [Enabling Draft Status for Record Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0603023548.html).

You can edit records in draft state. You can also check the approvers on the approval rules before submitting the record for approval.

To start the approval process for a draft record, click the **Submit for Approval** button.
