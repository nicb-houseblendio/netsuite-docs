Important:

Only users with Administrator roles or custom permissions can set up group approver records. For more information, see [Creating or Customizing Roles for SuiteApprovals](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_1504492890.html).

You can route supported record types, including Engineering Change Orders, to one or all members of an employee group. To add the **Group (Any)** and **Group (All)** approver types to an approval matrix, you must set up group records.

For guidelines on creating group records, see [Working with Groups](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N492945.html).

## Guidelines for Setting Up Group Approvers {#subsect_39084620249}

Take note of the following guidelines for group approvers:

-   To avoid errors when adding these approver types to approval chains, make sure group members' employee records are active.
    
-   Inactive employees, employees from different subsidiaries, or those without login access are considered invalid members. These employees won't be added as approvers when the group they belong to is selected as a group approver.
    
-   You can set an approver's access to one or more subsidiaries to allow cross-subsidiary approvals. For more information, see [Setting Approvers' Access to Subsidiaries for SuiteApprovals](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_157062113959.html).
    
-   You don't need to create groups based on roles. For more information, see [Setting Up Role Approvers](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_1505997760.html).
