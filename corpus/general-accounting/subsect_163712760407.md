The Records for Approval portlet lets you see purchase orders, vendor bills, expense reports, and journal entries you need to approve.

To add this portlet to your dashboard, click **SuiteApprovals | Records for Approval** from the SuiteApps tab of the Personalize Dashboard palette. For detailed steps, see [SuiteApp Portlets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4629724453.html).

Click a record type name to open the Review Documents Awaiting Approval page and view the full list of records pending your approval.

Note:

The Review Documents Awaiting Approval page displays a maximum of 1,000 records, whether accessed from the Records for Approval or SuiteApprovals Reminders portlet. If you access it from the Records for Approval portlet, filtering is not available. Approve the items shown, then refresh the page to load the remaining approvals.

The following table describes the columns you'll see on the Review Documents Awaiting Approval page when accessed from the Records for Approval portlet.

| Column Name | Description |
| --- | --- |
| View | Shows the link to open the record in a new browser tab. |
| Date | Shows the transaction date. |
| Document Number | Shows the document or transaction number. |
| Vendor (header varies by transaction type) | The column header and value vary by transaction type:
-   **Vendor** - Shows the vendor. This column appears only on purchase orders and vendor bills.
-   **Posting Period** - Shows the posting period. This column appears only on journal entries.
-   **Employee** - Shows the employee selected on the expense report. This column appears only on expense reports.

 |
| Memo | Shows the transaction memo. |
| Amount | Shows the transaction amount. |
| Currency | Shows the transaction currency. |
