The Intelligent Close Manager (ICM) portlet provides a centralized view of your close tasks, transaction amounts, and exceptions. From the portlet, you can manage AI-prioritized tasks, resolve exceptions, monitor close progress, and lock transaction types and accounting periods. You can also generate AI insights that provide a contextual summary of overall close progress, task coverage, and A/R and A/P activity.

The portlet displays both system-generated and user-created tasks. System-generated tasks appear when NetSuite identifies qualifying close work. For example, suppose 50 sales orders are pending billing for U.S. Subsidiary in the January 2027 accounting period. Intelligent Close Manager displays an **Invoice sales orders** task with a count of 50. NetSuite doesn't create a corresponding close manager task record immediately. When January 2027 becomes the first open accounting period, NetSuite creates one **Invoice sales orders** close manager task record representing all 50 pending sales orders for U.S. Subsidiary and that accounting period.

You can also create custom tasks for close activities that NetSuite does not generate automatically. Each custom Close Manager task record represents one task in the ICM portlet. For more information about close manager task records, see [Close Manager Task Record Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_9095712283.html).

Users with permissions for operational workflows and managing accounting periods can view and act on tasks.

The tasks, KPIs, and exceptions that appear in the Intelligent Close Manager depend on the features and preferences enabled in your account. For more information, see [Mapping Tasks and KPIs to Features and Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_203743279.html).

Note:

When **Exception Management** is enabled, posting transaction amounts that trigger an exception are counted as exceptions in the Intelligent Close Manager and are excluded from the posted transaction amount totals. For example, a $100 exception on Invoice 1 adds $100 to the invoice exception amount and one task. Exception amounts and posted amounts are never duplicated. For more information about exceptions, see [Exception Management Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_5094345081.html).

The Intelligent Close Manager portlet displays data only for the primary accounting book.

All transaction amounts in the Estimated Impact column of the Intelligent Close Manager are shown in the subsidiary's base currency. If a transaction was created in a foreign currency, amounts are converted to the base currency based on the entered exchange rate on the transaction or the most up-to-date exchange rate. Child subsidiary tasks aren't shown.

System-generated tasks and KPIs in the portlet refresh every hour. The timestamp indicates when the data was last refreshed. Custom tasks appear immediately after you create them.

The Intelligent Close Manager provides AI generated insights for A/R, A/P, and overall close progress to help you understand your company's performance. For more information, see [Generating Close Manager Insights](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_2144137227.html).

You can enable the Intelligent Close Manager feature on the Enable Features page. For more information, see [Enabling the Intelligent Close Manager Feature](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_7203104321.html). The Intelligent Close Manager portlet is automatically added to your Home page after enabling it. For more information about using the portlet, see [Using the Intelligent Close Manager Dashboard Portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_3203353024.html).

Note:
