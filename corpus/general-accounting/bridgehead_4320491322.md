You select your exchange rate provider from the Exchange Rate Integration section of the General subtab on the Accounting Preferences page. Other choices that you make in this section determine the method by which your exchange rates are obtained. For more information about changing your exchange rate provider, see [Enabling the Currency Exchange Rate Integration Feature](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4322310757.html).

NetSuite includes the following integrated exchange rate providers:

-   **HSBC** - For information, go to [https://www.hsbc.com](https://www.hsbc.com/). The following link provides access to a Microsoft Excel worksheet listing the currency pairs that HSBC supports. You can use this list to check if HSBC supports your desired currency pair through the Currency Exchange Rate Integration feature. To access the worksheet, click this link: [HSBC\_SupportedCurrencyPairs](https://nlcorp.app.netsuite.com/core/media/media.nl?id=327820049&c=NLCORP&h=GJhzYB_bVNo8093BjZPa2-2EbBgp05MvOv-ZvUyO08S6OK8-&_xt=.xls).
    
    Important:
    
    This is a list of supported HSBC pairs that a user can receive through NetSuite. Oracle has generated this list from data provided by HSBC, and this list is subject to change without notice.
    
-   **Xignite** - For information, go to [https://www.xignite.com](https://www.xignite.com).

Note:

If you have questions about exchange rate providers, please contact NetSuite Customer Support. You **shouldn't** contact the exchange rate providers.

Each exchange rate provider supports a different number of currency pairs. If you aren't receiving an exchange rate for your desired currency pair, you can try one or more of the following options:

-   Turn on triangulation. Triangulation is useful when the two currencies involved in a pair aren't available as standard pairs from the selected exchange rate provider. Triangulation will help you maximize the number of exchange rates that are returned. You should test triangulation to ensure that all of your desired exchange rates are covered. For more information, see [Triangulation Calculation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4322231734.html#bridgehead_4322232118).
    
-   Change exchange rate providers.
    
-   Manually import your desired exchange rates. For more information, see [Currency Exchange Rates Import](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N359131.html).
    

Changing your exchange rate provider doesn't impact any existing data or workflows. When you change your exchange rate provider, you only update the source from which you receive exchange rates from that point in time moving forward.

If you change your rate provider, you must re-agree to the Notice at _Setup > Company > Enable Features_ on the Company subtab.

At update time in your selected time zone, NetSuite uses a web services call to contact your specified integrated rate provider.

Important:

To automatically update exchange rates using the Currency Exchange Rate Integration feature, you must enter the appropriate three-letter International Standards Organization (ISO) currency code in the **ISO Code** field on the Currency page. NetSuite won't automatically update exchange rates if the currency isn't listed in the Forex Data of your specified exchange rate provider. For information about creating currency records, see [Creating Currency Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1395911.html).

If you use the Currency Exchange Rate Types feature, note that rate provider integration works only with the default currency exchange rate type.
