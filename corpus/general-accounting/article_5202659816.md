To enable the Intelligent Close Manager feature, you must have the following features and permissions:

-   The Accounting Periods feature enabled. For more information, see [Accounting Period Management](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N1445226.html).
    
-   The Administrator role or another role that includes the Enable Features permission. For more information about roles and permissions, see [Customizing or Creating NetSuite Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N285937.html).
    

To use the Intelligent Close Manager feature, you must have the View level or higher of the Manager Accounting Periods permission. For more information, see [Permissions Documentation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N326485.html).

You can't take action on certain tasks if you don't have the necessary permissions. If you don't have access, a permission violation error is displayed indicating the permissions you need to access the page.
