You can manually edit an existing budget in NetSuite.

#### To edit an existing budget:

1.  Go to _Transactions > Financial > Set Up Budgets > List_.
    
2.  Click the **Edit** link next to the budget you want to change.
    
    Tip:
    
    If you don't see the budget you want to edit, check the Filters at the top of the list.
    
3.  Modify the fields and each budget record as required.
    
    To delete this budget, from the **Actions** list, select **Delete**. Click **OK** to confirm the deletion.
    
4.  Click **Save**.
    

Tip:

To modify existing NetSuite budget data in an external application, you can export the data, make changes, and reimport the changed data. You can export data from reports or saved search. The Budget Income Statement is convenient for income and expense accounts. Set the Column footer to Accounting Period before you export. The CSV file you use to update a budget **must** contain values in each field to prevent existing budget data from being lost. For information about exporting data, see [Exporting a Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N736119.html) and [CSV Imports Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N342646.html).
