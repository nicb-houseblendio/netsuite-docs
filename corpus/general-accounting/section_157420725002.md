On reports, you can select your balancing segment in the Column list in the report footer options. For help, in the Report Footer Options topic, see [Column](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N724112.html).

You can also add the column when you customize a report. For help, see [Adding Persistent Matrix Columns to Financial Statements](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2109761.html).

Some major financial reports that support custom segments in the report footer or as persistent matrix columns are as follows:

-   Balance Sheet - For help, see [Balance Sheet Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2098310.html).
    
-   Income Statement - For help, see [Income Statement Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2093552.html).
    
-   Cash Flow Statement - For help, see [Cash Flow Statement Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2103273.html).
    

## Identifying Transactions Balanced by Segments in Transaction Searches {#subsect_161097701134}

To quickly identify transactions that are not balanced by segments, use the Balanced by Segments field in transaction searches as a field filter or a result field. The field has the following values:

| Field Value | Description |
| --- | --- |
| Yes | This transaction was balanced by segments for all subsidiaries and accounting books. |
| Yes (Outdated) | This transaction was balanced by segments for all subsidiaries and accounting books, but a GL-impacting change occurred after the process was run. |
| Partially | This transaction was balanced by segments only for some subsidiaries or accounting books. |
| Partially (Outdated) | This transaction was balanced by segments only for some subsidiaries or accounting books, but a GL-impacting change occurred after the process was run. |
| No | This transaction was not balanced by segments. Transactions that have not been affected by the balancing by segments process display this status in transaction searches. The transaction form for these transactions does not display a status. |
