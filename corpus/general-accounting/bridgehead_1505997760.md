You can route supported record types, including Engineering Change Orders, to approvers based on NetSuite roles. For more information, see [Assigning Roles to an Employee](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N897798.html).

In an approval rule, choose **Role (Any)** to accept approval from any employee, or **Role (All)** to require approval from every employee. This approver type supports both standard and custom roles. For more information about approval rules, see [Creating Approval Rules](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_1505999631.html).

## Guidelines for Setting Up Role Approvers {#subsect_31090132250}

Take note of the following guidelines for role approvers:

-   When adding the Role (Any) and Role (All) approver types to approval chains, take note of the following:
    
    -   Make sure the role records are active.
        
    -   Make sure the role has access to relevant transaction records.
        
-   Only active employees in the same subsidiary as the approval rule will be added as approvers for any Role approver type. However, you can set approvers' access to one or more subsidiaries to allow cross-subsidiary approvals. For more information, see [Setting Approvers' Access to Subsidiaries for SuiteApprovals](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_157062113959.html).
