Set up the Sequential Liability custom portlet to display the Sequential Liability Quick View. The Sequential Liability Quick View shows the A/P balance, A/R balance, total amount received, and total amount paid for a project or subsidiary as KPI tiles on the dashboard. For more information, see [Navigating the Sequential Liability Quick View](#subsect_159074497859).

Note:

The Sequential Liability custom portlet is only available to Accounting Center roles, such as financial users in the organization. Roles that do not belong in the Accounting Center, such as consultants, cannot set up the Sequential Liability custom portlet.

#### To set up the Sequential Liability custom portlet:

1.  Click **Personalize** on the upper right corner of your dashboard.
    
2.  On the **Standard Content** tab of the Personalize Dashboard palette, click the **Custom Portlet** icon.
    
3.  Click **Set Up** on the portlet.
    
4.  In the **Source** field of the Custom Content dialog, select **SEQL PL APAR Dashboard Tile**, and click **Save**.
    

## Navigating the Sequential Liability Quick View {#subsect_159074497859}

The Sequential Liability Quick View shows the A/P balance, A/R balance, total amount received, and total amount paid for a project or subsidiary as KPI tiles on the dashboard. To set up the Sequential Liability Quick View, see [Setting Up the Sequential Liability Custom Portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159073822857.html).

Note:

Click **Refresh** on the portlet to include all recent transactions.

See the following tables for a list of fields and tiles available in the Sequential Liability Quick View and their corresponding descriptions.

| Field | Description |
| --- | --- |
| Subsidiary | This field lets you select a subsidiary. You can only select from subsidiaries that have outstanding payable and receivable balances. The subsidiary associated with your account is selected by default. For administrators, all subsidiaries are displayed. When you select a subsidiary, the total A/P balance, A/R balance, receipts, and payments to date for that subsidiary are displayed in the custom portlet as tiles. All amounts are in the currency of the selected subsidiary. |
| Project | This field lets you select a project or all projects in the subsidiary. You can only select from projects that have outstanding payable and receivable balances. All projects within the subsidiary is selected by default. When you select a project, the total A/P balance, A/R balance, receipts, and payments to date for that project are displayed in the custom portlet as tiles. All amounts are in the currency of the subsidiary where the project belongs. |

| Tile | Description |
| --- | --- |
| A/P Balance | This tile shows the payable balance amount for a project or subsidiary. The amount is in the subsidiary's currency. |
| A/R Balance | This tile shows the receivable balance for a project or subsidiary. The amount is in the subsidiary's currency. |
| Receipts | This tile shows the total amount received for a project or subsidiary to date. The amount is in the subsidiary's currency. |
| Payments | This tile shows the total amount paid for a project or subsidiary to date. The amount is in the subsidiary's currency. |
