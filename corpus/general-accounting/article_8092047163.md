Important:

Exception Management (EM) is currently not available to all customers. The Exception Management feature depends on sufficient data volume and model training readiness. If you can't access Exception Management, contact your NetSuite Account Manager for guidance and next steps.

As an administrator, you can set company-wide Exception Management preferences. To set these preferences, go to Setup > Accounting > Accounting Preferences, then click the **Exception Management** subtab.

These preferences control which exceptions appear on the Exception Management page. Vendor Information Change preferences can also control whether new Vendor Information Change exceptions are generated for selected criteria. Preferences do not change underlying transactions.

For Incorrect Amount, Incorrect Account, Missing Transactions, and Vendor Information Change exceptions, you can:

-   Exclude the exception type entirely by clearing the box next to it.
    
-   Select specific transaction types to exclude from the exception type.
    
-   Set a minimum dollar threshold. Exceptions below this amount are not shown on the EM list page.
    

For Vendor Information Change exceptions, preferences apply to Vendor Bills and Vendor Payments. You can exclude selected transaction types and set the minimum threshold amount used when EM evaluates vendor data changes.
