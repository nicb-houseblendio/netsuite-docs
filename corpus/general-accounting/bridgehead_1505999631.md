You can create approval rules using the Approval Rule page or the Approval Rule Assistant. Both options contain the same fields and settings, except the Approval Rule Assistant lets you create approval rules step by step.

To view, create, or edit approval rules, you must use an Administrator role or a role with appropriate permissions. For more information, see [Creating or Customizing Roles for SuiteApprovals](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_1504492890.html).

Important:

Make sure you set up Engineering Change Order (ECO) types before creating approval rules for ECOs. For more information, see [Setting Up Engineering Change Order Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1531289991.html).

The following table describes the steps in creating approval rules.

| Step | Description |
| --- | --- |
| Entering basic information | Create an approval rule for any supported record type, including Engineering Change Orders. Enter the rule name, record name, start date, end date, and priority. For more information, see [Entering Basic Information](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_5122951727.html). |
| Defining approval routing settings | Set up the approval routing for supported record types on the Approval Rule page. You can choose to route approvals based on amount or define custom approval chain. For more information, see [Defining Approval Routing Settings](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_2132718543.html). |
| Defining record locking and reapproval settings | Set the record locking and reapproval setting on the Approval Rule page. Important: The record locking and reapproval feature is not available for Engineering Change Orders. For record locking, you can choose between allow record editing regardless of record status and lock record for editing based on status. For reapproval settings, you can choose between no approval rerouting regardless of change in record amount and tolerance. For more information, see [Defining Record Locking and Reapproval Settings](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_53132710234.html). |
