You can create custom close manager tasks to track close activities that are specific to your company. For example, you can create tasks for checklist items, reviews, operational reminders, or other tasks that aren't system-generated.

Custom tasks appear on the **Custom** tab in the Intelligent Close Manager portlet. You can assign tasks, set start and due dates, track their status, and mark them complete as part of your close process.

For more information about custom tasks, see [Close Manager Task Record Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_9095712283.html).

#### To create close manager tasks:

1.  Go to Lists > Accounting > Close Manager Tasks > New.
    
2.  In the Primary Information section, enter a task name that clearly identifies the close activity.
    
3.  Select an assignee.
    
4.  Optional: Check the **Send Email** box to notify the assignee by email.
    
5.  Select a status.
    
6.  Select a category. Custom tasks default to **General** and appear on the **Custom** tab in the Close Manager portlet.
    
7.  In OneWorld accounts, select a subsidiary.
    
8.  Select an accounting period.
    
9.  In the Schedule section, select a start date and due date.
    
10.  If the task status is Completed, enter or select a completed date.
     
11.  Add instructions and attach files in the **Message** and **Communication** tabs, as needed.
     
12.  Click **Save**.
     

After saving a task, it appears in your Intelligent Close Manager portlet in the corresponding period and subsidiary.
