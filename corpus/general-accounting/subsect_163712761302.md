This portlet shows vendor bills, purchase orders, expense reports, and journal entries. The number of records that are pending approval or rejected are also shown for each record type in your NetSuite account.

Use this portlet to check aging records awaiting approval and identify records that may need reapproval. The aging value counts only the days a record has been awaiting approval from the next approver. The value excludes the total time the record has been in pending approval status.

Important:

To improve performance, set the row limit in the **Number of Rows in List Segments** field. To change this value, go to _Setup > Company > Preferences > General Preferences_. For more information, see [Setting General List and System Notes Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1117125619.html) and [Optimize NetSuite Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_75113057043.html).

To add this portlet to your dashboard, click **SuiteApprovals | Records for Approval** from the SuiteApps tab of the Personalize Dashboard palette. For detailed steps, see [SuiteApp Portlets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4629724453.html).

Click a status (pending approval or rejected) to open the Review Documents Awaiting Approval page, where you can review all associated records.

When viewing the Review Documents Awaiting Approval page, you can sort the columns on this page in ascending or descending order:

-   To sort only the current page, click a column header. The same sorting applies to all pages, so some records may move to a different page.
    
-   To sort records across all pages, click **Apply Filters**.
    

Note:

The Review Documents Awaiting Approval page displays a maximum of 1,000 records, whether accessed from the Records for Approval or SuiteApprovals Reminders portlet. Use filters to refine your results if there are more than 1,000 records. If additional records remain, refresh the page to load the next set.

The following table describes the columns on the Review Documents Awaiting Approval page when accessed from the SuiteApprovals Reminders portlet.

| Column Name | Description |
| --- | --- |
| View | Shows the link to open the record in a new browser tab. |
| Date | Shows the transaction date. |
| Document Number | Shows the document or transaction number. |
| Vendor (header varies by transaction type) | The column header and value vary by transaction type:
-   **Vendor** - Shows the vendor. This column appears only on purchase orders and vendor bills.
-   **Posting Period** - Shows the posting period. This column appears only on journal entries.
-   **Employee** - Shows the employee selected on the expense report. This column appears only on expense reports.

 |
| Employee | Shows the employee selected on the expense report. |
| Memo | Shows the transaction memo. |
| Amount | Shows the transaction amount. |
| Currency | Shows the transaction currency. |
| Aging Days | Shows the number of days the transaction has awaited approval. Tip: To prevent processing delays, don't leave transactions in Pending Approval status. |
| Next Approver | Shows the name of the next approver as a link. If a Group or Role has more than five approvers, you can click the link to open a new browser tab that lists all approvers. |
