The following type of preferences are available on the Accounting Books subtab of the Accounting Preferences page. This subtab is only visible when you have the Full Multi-Book Accounting feature enabled. For more information, see [Using Multi-Book Accounting](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_3831569045.html).

## Chart of Accounts Mapping {#bridgehead_158452330434}

The following preferences are only available when you have the Chart of Accounts feature enabled. For more information, see [Chart of Accounts Mapping](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3851620232.html).

| Field | Description |
| --- | --- |
| Custom Item COA Mapping Dimension | Select a field from the list to include as a custom dimension for Item Account Mapping. For more information, see [Item Account Mapping](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3884899997.html). |
| Custom Transactino COA Mapping Dimension | Select a field from the list to include as a custom dimension for Global Account Mapping. For more information, see [Global Account Mapping](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3884899929.html). |
