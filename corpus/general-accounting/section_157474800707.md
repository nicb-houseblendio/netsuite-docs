You can do the following in Sequential Liability:

1.  View a summary of project-related payable and receivable transactions per subsidiary. For more information, read the following topics:
    
    -   [Viewing the Project A/P - A/R Summary](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157474805242.html)
        
    -   [Navigating the Project A/P - A/R Summary Page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158339885730.html)
        
2.  View more details about the payable and receivable transactions for a specific project. For more information, read the following topics:
    
    -   [Viewing the Project A/P - A/R Details](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157948518283.html)
        
    -   [Navigating the Project A/P - A/R Details Page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158339893998.html)
        
3.  View A/P - A/R details from the project record. For more information, read the following topics:.
    
    -   [Viewing A/P - A/R Details from the Project Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158806212164.html)
        
    -   [Navigating the A/P - A/R Details Subtab of the Project Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158806212164.html#subsect_159186072590)
        
4.  View the A/P balance, A/R balance, total amounts received and paid for a project or subsidiary as KPI tiles on the dashboard. For more information, read the following topics:
    
    -   [Setting Up the Sequential Liability Custom Portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159073822857.html)
        
    -   [Navigating the Sequential Liability Quick View](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159073822857.html#subsect_159074497859)
