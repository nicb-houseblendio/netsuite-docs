The Account Matching Report SuiteApp is free and managed, and the SuiteApp automatically updates whenever new features or enhancements are added.

Before you install this SuiteApp, read [Account Matching Report Prerequisites](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0421120951.html).

You can install the SuiteApp from the SuiteApp marketplace. For more information, see [Installing from the SuiteApp Marketplace](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1539799323.html).

#### To install the Account Matching Report SuiteApp:

1.  Go to _SuiteApps_.
    
2.  In the **Search SuiteApps** field, enter **Account Matching Report**, then press enter.
    
3.  Click the Account Matching Report SuiteApp tile.
    
4.  On the top right corner of the page, click **Install**.
    

For more information about the installation status, see [Viewing SuiteApp Installation or Uninstallation Status](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1539867271.html).
