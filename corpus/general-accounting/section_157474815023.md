Refer to the following table for more information about the workflow tasks in Sequential Liability.

| Task | Details | Help Topic |
| --- | --- | --- |
| Create a customer record | Create a customer record to track customer information. | [Customers](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1076428.html) |
| Create a project record | In Sequential Liability, a project record is required. Note: You can only view payable and receivable balances and details when A/P and A/R transactions are tied to a project. When creating a project record, you must select the customer associated with the project. Selecting a customer in the Customer field isn't required in the project record but it is required so you can enter customer invoices for a vendor bill. | [Creating a Project Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1183012.html) |
| Enter vendor bills | Enter vendor bills or payable transactions for the project. | [Vendor Bills](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N2370131.html) |
| (Optional) Enter vendor credits | Enter vendor credits against the vendor bill. A vendor credit transaction shows credits from the vendor that can be applied toward your payable account. | [Entering Vendor Credits](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2392083.html) |
| Enter customer invoices | Enter customer invoices or receivable transactions for the project. | [Creating an Invoice](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1238506.html) |
| (Optional) Issue credit memo | Issue a credit memo against a customer invoice. You may need to issue a credit memo to reverse a charge invoiced to a customer. | [Issuing a Customer Credit Memo](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1311510.html) |
| Associate vendor bills, vendor credits, customer invoices, and credit memos to a project. | You must associate vendor bills, vendor credits, customer invoices, and credit memos to a project. Take note of the following guidelines:
-   When you enter vendor bills, you must associate each expense line or item line in the vendor bill to the same project.
-   There are three ways to enter a vendor credit. When you manually enter a vendor credit, you must associate each expense line or item line in the vendor credit to the same project.
-   When you enter a customer invoice or issue a credit memo, you must associate the customer invoice or credit memo to a project.

 | [Associating Vendor Bills and Vendor Credits to a Project](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158071367737.html) |
| [Associating Customer Invoices and Credit Memos to a Project](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158278781626.html) |
| View project A/P - A/R summary | View a summary of project-related payable and receivable transactions per subsidiary. | [Viewing the Project A/P - A/R Summary](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157474805242.html) |
| [Navigating the Project A/P - A/R Summary Page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158339885730.html) |
| View project A/P - A/R details | View more details about a project's payable and receivable balances. | [Viewing the Project A/P - A/R Details](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157948518283.html) |
| [Navigating the Project A/P - A/R Details Page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158339893998.html) |
| View A/P - A/R details from project record | View A/ P - A/R details from the project record. This is only available when the project record is in View mode. | [Viewing A/P - A/R Details from the Project Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158806212164.html) |
| Set up the Sequential Liability custom portlet | Set up the Sequential Liability custom portlet to view the A/P balance, A/R balance, receipts, and payments for a project or subsidiary as KPI tiles on the dashboard. Note: The Sequential Liability custom portlet is only available for Accounting Center roles, such as financial users in the organization. Roles that do not belong in the Accounting Center, such as consultants, cannot set up the Sequential Liability custom portlet. | [Setting Up the Sequential Liability Custom Portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159073822857.html) |
| [Navigating the Sequential Liability Quick View](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159073822857.html#subsect_159074497859) |
