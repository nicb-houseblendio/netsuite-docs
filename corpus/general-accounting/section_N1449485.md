The Multiple Calendars feature applies to accounting periods and tax periods. This feature is available only in NetSuite OneWorld and isn't enabled by default. The Multiple Calendars feature determines the rollup structure for tax periods. For more information, see [Setting Up Tax Periods Using a Fiscal Calendar](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1799689.html).

When the Multiple Calendars feature is enabled, you can filter accounting and tax period searches by fiscal calendar.

Before you enable Multiple Calendars, if you have any open, standalone adjustment periods you must change them to overlap existing non-adjustment periods. For more information, see [Adjustment Periods](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1450241.html).

Review the guidelines below to determine whether you should make changes to other standalone adjustment periods:

-   future adjustment periods - recommended
    
-   open adjustment periods - required
    
-   historical, closed adjustment periods - optional
    

You can disable this feature only if you haven't assigned any new fiscal calendars to subsidiaries.

#### To enable the Multiple Calendars feature: {#procedure_N1449529}

1.  Go to _Setup > Company > Enable Features_.
    
2.  On the **Accounting** subtab, under Advanced Features, check **Multiple Calendars**.
    
3.  Click **Save**.
