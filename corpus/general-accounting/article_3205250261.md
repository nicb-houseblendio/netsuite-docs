The Intelligent Close Manager portlet provides key performance indicators (KPIs) that offer insight into your business performance and the progression of close tasks. KPIs update dynamically based on the period and subsidiary you select.

The KPIs available depend on the features and preferences enabled in your account. For more information, see [Mapping Tasks and KPIs to Features and Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_203743279.html).

The following table summarizes each KPI and its definition:

| Key Performance Indicators (KPIs) | Description |
| --- | --- |
| Task completion | Shows the percentage of completed task. The percentage is calculated by dividing completed task items by total tasks. |
| Potential variance | Shows the total value of tasks that still require completion. |
| Net income change | Shows the percentage change in net income from the previous period to the current period for the selected subsidiary, showing how your profitability is trending. |
| Open tasks | Shows the total number of outstanding A/R, A/P, and Accounting tasks, excluding any tasks that are categorized as exceptions. |
| Exceptions | Shows the total number of outstanding A/R, A/P, and Accounting exceptions. |
| Largest outstanding task | Shows the task with the largest amount value, including exceptions. |
| % A/R | Shows the percentage of A/R tasks that are completed, calculated as the number of completed A/R tasks divided by the total number of A/R tasks. |
| % A/P | Shows the percentage of A/P tasks that are completed, calculated as the number of completed A/P tasks divided by the total number of A/P tasks. |
| % Accounting | Shows the percentage of accounting tasks that are completed, calculated as the number of completed accounting tasks divided by the total number of accounting tasks. |
| % Custom | Shows the percentage of custom tasks that are completed, calculated as the number of completed custom tasks divided by the total number of custom tasks. |

For more information about the Intelligent Close Manger, see [Intelligent Close Manager Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_7202210350.html).
