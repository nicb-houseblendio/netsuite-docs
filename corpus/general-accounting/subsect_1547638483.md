After you've enabled the Balancing Segment feature, you can create a balancing segment from a new or existing custom segment.

Balancing segments must have general ledger impact. You can have only two active balancing segments at one time. For instructions to make balancing segments inactive or to delete them, see [Inactivating a Custom Segment](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4520740541.html) or [Deleting a Custom Segment Definition](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4392098880.html).

You need the Balancing Journals permission with access at the Create level to make a custom segment a balancing segment. You also need the Custom Segments permission at Edit level or higher

After you create a balancing segment, you can't clear the GL Impact box for the custom segment. For details about GL impact for custom segments, see [Configuring GL Impact for a Custom Segment Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4385199949.html).

Note:

To create a balancing segment, follow the general instructions in [Creating a Custom Segment](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4313465979.html). Those instructions include a description of all fields in the custom segment. The following procedure includes the fields that are required for balancing segments.

#### To create a balancing segment:

1.  Go to _Customization > List, Record, & Fields > Custom Segments_.
    
2.  Click **New Custom Segment**.
    
3.  Keep the **Type** field set to its default value of **List/Record**.
    
    Balancing segments must have GL impact, and custom segments with GL impact must be of the List/Record type.
    
4.  Check the **GL Impact** box. This box must be checked for balancing segments. For more details about GL impact, see [Configure a Segment to Appear on the GL Impact Page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4471745392.html).
    
5.  Enter additional configuration settings on the following subtabs:
    
    -   **Values** - Create values for the balancing segment by adding lines to the sublist. These values are the options that are available in the balancing segment list on transaction records. For details about each column in the Values sublist, see [Creating Values Within the Segment Definition](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4380806824.html).
        
    -   **Application & Sourcing** - This subtab doesn't relate specifically to balancing segments. For information, see [Applying a Custom Segment to Record Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4384305776.html) and [Dynamic Default Value Sourcing for Custom Segments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4384326119.html).
        
    -   **Validation & Defaulting** - This subtab doesn't relate specifically to balancing segments. For information, see [Making a Custom Segment Mandatory](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4385117425.html) and [Configuring Static Defaults for Custom Segments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4384398405.html).
        
    -   **Permissions** - Complete this subtab as follows:
        
        1.  Add the roles that can run the balancing by segments process to the sublist.
            
        2.  Set the **Record Access Level** to **Edit** for each role.
            
        3.  Set the **Search/Reporting Access Level** to a value other than the default.
            
        
        For more information about this subtab, see [Granting a Role Permission to Manage Custom Segment Values](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4365642580.html) and [Granting Roles Permission to Use Segments in Searches and Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4317000329.html).
        
    -   **Dependent Segments** - This subtab doesn't relate specifically to balancing segments.
        
    -   **Display Order** - This subtab doesn't relate specifically to balancing segments. For details see [Setting Display Order of All Custom Segments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4527888154.html).
        
    -   **Translation** - This subtab doesn't relate specifically to balancing segments. This subtab shows only when the Multi-Language feature is enabled.
        
6.  Click **Save**.
    
7.  Go to _Setup > Accounting > Preferences > Accounting Preferences (Administrator)_ and click the Balancing Segments subtab.
    
8.  In the Segments list, click **Add Row**.
    
9.  Select the custom segment you created or want to use as a balancing segment.
    
10.  (Optional) If you use the Enable Intersegment Elimination preference, select an elimination value to use with this custom segment. NetSuite uses this balancing segment value to reverse auto-balancing lines posted by balancing journals in your intersegment accounts. For more information, see [Reversing Balancing Segment Intersegment Lines](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159281288387.html).
     
11.  Click **OK**, then **Save**.
     

Upon save, NetSuite creates the balancing segment and an associated custom record type. The custom record type has the same name as the balancing segment and is available on the Custom Record Types list page. You can edit the custom record type directly to add values to the custom segment.

For instructions to continue setup, see [Configuring Intersegment Accounts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157247561203.html).
