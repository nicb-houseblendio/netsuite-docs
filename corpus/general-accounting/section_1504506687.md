Before setting up SuiteApprovals, consider how your company manages approval for specific record types. For more information about the supported record types, see [SuiteApprovals Terminology](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_95074055417.html).

Review the business requirements that define how you create and enforce approval processes for these records. You can set up multiple approval rules to match your business requirements, including iterations based on variable criteria.

For more information about how to set up SuiteApprovals, see the following help topics:

-   [Creating or Customizing Roles for SuiteApprovals](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_1504492890.html)
    
-   [Guidelines for SuiteApprovals Scripts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_162022228360.html)
    
-   [Setting Up Script Deployment for Record Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_1544003700.html)

-   [Setting Approvers' Access to Subsidiaries for SuiteApprovals](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_157062113959.html)
