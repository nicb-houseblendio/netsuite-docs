NetSuite includes financial statements that include budget information. These reports are included in the group of reports called Banking/Budgeting. The following links go to the help topics for these reports:

-   [Budget Income Statement Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2095701.html)
    
-   [Budget Income Statement Detail Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2096390.html)
    
-   [Budget vs. Actual Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2097218.html)
    

Use the footers of these reports to select refilter report data. From the Column list, you can choose to display report amounts by an additional dimension, including time period, class, department, location, or subsidiary. Custom segments are not included in the Column list. Click the More arrow button to display all footer lists. For more information, see [Setting Report Footer Options](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N720025.html).

Use the Financial Report Builder to customize the budget-related reports in the Financial Report Builder. With the Financial Report Builder, you can do the following:

-   Add, reorder, and change the hierarchy of rows
    
-   Use dynamic criteria for section data, including account name, account number, account type, class, department, location, and subsidiary
    
-   Group section data by account type, class, department, location, and subsidiary
    

For details, see [Financial Report Builder](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N2105415.html). The Allow Web Query option is not available for these reports.

Note:

Custom segments are not included in the Budget and Financial fields of the Financial Report Builder for budget-related reports.
