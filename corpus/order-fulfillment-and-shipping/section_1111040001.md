Create items or update existing ones that you want to use for Ship Central. For each item, you can set the fields required for additional capabilities or system rules that you want to use on the app. You can also create items that ship individually.

You can set up supported item types for packing to specify dimensions and weight. You can also enable settings to ship items individually and internationally. For local shipping through USPS, you can enable HazMat/Dangerous Goods shipping for inventory items, including inventory assembly items. For more information, see [Ship Central Supported Transactions and Item Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_90092747693.html#subsect_14092812049).

If you have package types, you can assign them to specific items. For more information, see [Updating Shipping Settings](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0808031602.html).

For international shipping, you can add details for the manufacturer tariff. You can also enter the description of goods in the **Display Name/Code**, **Sales Description**, or **International Description of Goods** fields. On the app, you can select one that you want to apply to a shipment and appear on shipping documents.

If you have existing items that you use for the Warehouse Management or other features, you can follow the instructions in this topic to update them with settings for Ship Central.

To create or update item records through the Import Assistant, see [Importing CSV Files with the Import Assistant](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N343158.html) or [Items Import](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N370470.html).

#### To create items for Ship Central: {#procedure_1111040119}

1.  Using the Administrator role, _Lists > Accounting > Items > New_
    
2.  On the New Item page, select one of the supported item types:
    
    -   Assembly/Bill of Materials (also Lot Numbered or Serialized)
        
    -   Inventory Item (also Lot Numbered or Serialized)
        
    -   Kit/Package or Non-inventory Item (For Sale or For Resale only)
        
3.  On the item page, in the Primary Information section, enter or select values in the following fields:
    
    -   **Item Name/Number** -Enter a unique identifier for the item.
        
    -   **UPC** - To set up GS1 bar code scanning for this item, enter the 14-digit GTIN for the item's GS1 bar code.
        
        For more information, see [Bar Code Scanning for Ship Central](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0726023627.html).
        
4.  To add description of goods for international shipping, set values in any of these fields:
    
    -   **Display Name/Code** field in the Primary Information section
        
    -   **Sales Description** field on the **Sales/Pricing** subtab
        
    -   **International Description of Goods** field on the **Custom** subtab
        
    
    When you process an international shipment on the app, select one of these fields as the source of the description of goods.
    
5.  On the **Sales/Pricing** subtab, set the following fields depending on your fulfillment requirements:
    
    1.  **Ships Individually** - Check this box to pack and ship this item individually.
        
        On the app, items that ship individually display the box icon.
        
    2.  **Item Weight** - Enter the default weight of the item.
        
        By default, when you pack the item through the app, the item weight serves as the pack carton weight. If you activate the **Calculate default carton weight** rule, you include this weight in the calculation of the total weight of a pack carton.
        
        Ship Central uses kilogram as the default unit. It automatically converts the value of a different unit into kilograms. If you use the Weighing Scale Support capability, you can activate the rule to change the default unit.
        
        For more information about these rules, see [Configuring Ship Central Rules](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111041523.html).
        
    3.  **Package** - (Optional) If you add packages for shipping, you can choose a default one for this item.
        
        For more information about default packages, see [Updating Shipping Settings](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0808031602.html).
        
6.  To specify the item's tariff code for international shipping, set values in the following fields:
    
    -   **Manufacturer Country -** Select the manufacturer's country.
        
    -   **Manufacturer Tariff** - Enter the 4-15 code for the Harmonized System or Harmonized Tariff Schedule.
        
    
    For more information about manufacturing settings, see [Entering Manufacturing Details](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1504284475.html).
    
7.  To fulfill kit/package and non-inventory item types, on the **Preferences** subtab, check the **Can Be Fulfilled/Received** box.
    
8.  (Optional) On the **Custom** subtab, you can enter more packing details for the item:
    
    -   For items that ship as is, you can enter the default dimensions of the pack carton in the following fields: **Pack Carton Length**, **Pack Carton Width**, or **Pack Carton Height**.
        
        NetSuite automatically allots one pack carton for each ordered quantity of items that ship as is. It uses these dimensions, as well as the item weight you enter in step 4b, to automatically close each pack carton. If you leave any of the fields blank, you have to manually enter the dimensions on your kiosk device.
        
    -   To display packing instructions for this item, in the **Packing Instructions** field, enter the instructions.
        
        The Multiple Shipping Routes feature provides additional support for packing instructions. If you use line item shipping for this feature, you can also enter instructions in the line item of an order. You can activate the Show Packing Instructions rule to automatically display both instructions on the app. See [Configuring Ship Central Rules](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111041523.html).
        
9.  If you use Warehouse Management and activate the Tally Scanning rule, you can enable it for items created before you activated the rule. On the **NS WMS** subtab, check the **Use Tally Scan** box.
    
    Checking this box enables you to tally scan items within the supported WMS mobile processes. For new items and items that you want to tally scan through Ship Central packing, you do not have to check this box. See [Configuring Ship Central Rules](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111041523.html).
    
10.  If you enable shipping of hazmat items through USPS, enable it for the supported item types, by doing the following:
     
     1.  Click the **HazMat/Dangerous Goods** subtab.
         
     2.  Check the **Hazmat/Dangerous Goods** box.
         
     
     Note that other settings on this subtab do not apply to Ship Central shipping. For more information, see [HazMat or Dangerous Goods Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0808031849.html#subsect_0809110808).
     
11.  (Optional) You can enter other item details and configure settings for other features.
     
     See [Creating Item Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2166469.html) or [Creating Items for NetSuite WMS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1541433512.html).
     
12.  Click **Save**.
