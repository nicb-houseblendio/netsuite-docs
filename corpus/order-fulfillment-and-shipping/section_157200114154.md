## Adding Center Category and Center Types {#bridgehead_157200142608}

For the custom role, add the Route Management center category and links for Routes and Trucks. Use the following information when creating the center category:

-   **Center category label** - Label the center category as Route Management.
    
-   **Center Type** - Select the desired center type.
    
-   **Center Tab** - Select the desired center tab.
    
-   Add the following links:
    
    -   **Route** - Label the link as Routes.
        
    -   **Truck** - Label the link as Trucks.
        
    -   **Shipment Report** - Label the link as Manage Route Shipments.
        

For more information, see [Creating Center Categories](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2890916.html) and [Creating Center Links](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2891250.html).
