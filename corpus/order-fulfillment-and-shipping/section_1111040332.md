The shipping item record provides settings that you can specify for shipping services, including the shipping plugin, labels, and tax schedule. Create shipping items for the services from carriers that you have integrated with Ship Central. You can view the list of shipping services available to you by going to Setup > Ship Central Setup > Manage ShipStation API Integration.

Depending on the features or settings that you use, you can set up the following capabilities on each shipping item:

-   You can enable the setting to display shipping items for selection on your Commerce website.
    
-   If you use the Shipping Label Integration feature for FedEx, UPS, or USPS, you can set up packing and shipping directly on item fulfillments. For more information, see [Setting Up Direct Packing and Shipping on Fulfillments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0219030324.html).
    
    You can also assign a flat, markup, or discount rate to shipping items for these carriers. For more information, see [Setting Ship Central Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0219032354.html).
    
    If you set the **Print Return Labels** preference, you can specify the shipping service you want to use for returns shipping for these carriers. For more information, see [Setting Ship Central Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0219032354.html).
    

Instead of creating one shipping item at a time, you create a CSV file that you can import into your NetSuite account. For instructions and guidelines, see [Importing Shipping Items for NetSuite Ship Central](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0401023430.html).

## Ship Central Plugins for Shipping Items {#subsect_0219024811}

Based on your shipping requirements, you can assign one of the following Ship Central Plugins to your shipping items:

-   **PackShip - Shipping Plugin** - Lets you choose a carrier account associated with the shipping service you want to assign to the shipping item.
    
-   **PackShip - Advanced Shipping Plugin** - Lets you choose a carrier that provides the shipping service you want to assign to the shipping item. After you set up the shipping item, you can assign specific accounts from the carrier per location. For more information, see [Assigning Carrier Accounts to Locations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0219021754.html).
    

On orders, you can choose shipping methods associated with shipping items that use a specific plugin based on the display name you provide. Those that use the Advanced Shipping Plugin enable you to charge a specific carrier account assigned to a location.

To enable these plugins for your NetSuite account, see [Registering and Integrating Your Carrier Accounts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111034346.html).

#### To create shipping items for your shipping services: {#procedure_1111040359}

1.  Using the Ship Central Manager role, go to Ship Central Setup > Packing & Shipping Records > Shipping Items > New.
    
2.  On the Shipping Item page, set the following fields:
    
    1.  **Ship Name** - Enter a unique name for the shipping service.
        
    2.  **Display Name/Code** - Enter a unique name that you want to appear in the Shipping Method or Ship Via fields on printed forms, your web store, and all centers, such as the Customer Center. Otherwise, the value in the Ship Name field is displayed.
        
        Tip:
        
        If you use both Ship Central Plugins, provide names that enable you to distinguish between the plugins used for a shipping item.
        
    3.  **Subsidiaries** - (Optional) You can change the default subsidiary setting for this shipping item.
        
    4.  If you have a Commerce website, check the **Display in Website** box to use this shipping item created for Ship Central.
        
        After you enable this setting, make sure that you also enable the **Charge for Shipping** setting on the Set Up Shipping page. See [Updating Shipping Settings](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0808031602.html).
        
3.  Click the **Shipping Rate** subtab, and then set the following fields:
    
    1.  In the **Account (Shipping)** field, select the account you want to associate with this shipping item.
        
    2.  Choose **Shipping Partner Rate**.
        
    3.  In the Shipping Partner Rate section, select values in the following fields:
        
        -   **Shipping Partner** - Select **PackShip - Shipping Plugin** or **PackShip - Advanced Shipping Plugin**.
            
            For more information, see [Ship Central Plugins for Shipping Items](#subsect_0219024811).
            
        -   **Service Group** - Based on your Shipping Partner choice, select the carrier account for PackShip - Shipping Plugin or the carrier for PackShip - Advanced Shipping Plugin.
            
        -   **Service** - Select the shipping service you want to associate with this shipping item.
            
4.  If you use the Shipping Label Integration feature, on the **Shipping Labels** subtab, you can set the following fields:
    
    1.  In the following fields, be sure to select the same field values as ones you select in step 3: **Shipping Partner, Service Group, and Service**
        
    2.  **Return Service** - For FedEx, UPS, or USPS only, if you can print return labels, you can select the shipping service that you want to use for returns shipping.
        
        You can choose a different service instead of the one you use for outbound local shipments. This setting applies to direct shipping on item fulfillments only.
        
    3.  **Shipping Label Integration** - If you select the FedEx, UPS, or USPS carrier or carrier account, you can check this box. When checked, you can enable direct packing and shipping on item fulfillments.
        
5.  Click the **Shipping Rules** subtab, and then in the **Charge Tax on this Shipping Portion of Item** field, select the tax schedule you want to use to calculate the tax on the shipping charge.
    
6.  (Optional) Click the other subtabs to apply more settings to your shipping item.
    
    For more information about the subtab fields, see [Creating Shipping Items](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1259213.html).
    
    Tip:
    
    On the **Packaging** subtab, even if you check the **Omit Packaging** box, it does not apply to orders that you process through NetSuite Ship Central.
    
7.  Click **Save**.
    

To continue your setup, you can specify shipping modes and rates on preferences records. For instructions, see [Ship Central Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0808031849.html).

When you create orders, you can choose the shipping method associated with a shipping item for Ship Central. Orders submitted through your Commerce website include the preferred shipping method of your customer.
