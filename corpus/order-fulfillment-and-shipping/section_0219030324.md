If you use the Shipping Label Integration feature, you can set up shipping items to process orders for shipping within Ship Central. You can apply additional preferences to use them for packing and shippring directly on item fulfillments only, without using the app.

This capability applies to shipping items for FedEx, UPS, or USPS only. Before you set it up, be sure to connect or sync your shipping accounts for these carriers with your NetSuite ShipStation API account. For instructions, see [Registering and Integrating Your Carrier Accounts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111034346.html) or [Managing Your Shipping Integration](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111034346.html#subsect_20092856968).

Note:

If you do not use the Pick, Pack, and Ship feature and want to ship only through the NetSuite UI, refer to the table on [Direct Packing or Shipping on Fulfillments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0324093230.html). On this table, you can also review the options to pack through the NetSuite UI and ship through the app, or vice versa.

For FedEx, UPS, or USPS carriers, you can set up this capability through the following required and optional configurations:

1.  **Shipping Mode** - On the standard preference record or a custom one, you can select the **Integrated Shipping Only** mode or **Integrated Shipping per Order** mode. Based on the shipping mode, you enable direct shipping on fulfillments for all or specific orders for which a preference record applies to.
    
    Optionally, you can set the following label preferences:
    
    -   **PDF or ZPL Label Printing Format** - You can change the default PDF printing format for any of the three carriers that you use.
        
    -   **Print Return Labels** - You can set this preference to print or save return labels for local shipments.
        
    -   **Billing Other Parties** - You can enable this preference to enter third party or recipient billing account details on orders, order lines, or item fulfillments.
        
    
    Preferences apply to specific subsidiaries or locations that you select on a preference record. You can set other preferences that suit your shipping requirements. For more information about these preferences, see [Setting Ship Central Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0219032354.html).
    
2.  On shipping items that you create for Ship Central, you can enable the following settings for labels that you can print or save directly through fulfillments:
    
    -   **Shipping Label Integration** - For shipping labels, you must enable this setting.
        
        On item fulfillments, Ship Central automatically checks the **Integrated Shipping Label** box to enable direct label generation.
        
    -   **Return Service** - If you set the Print Return Labels preference, you can specify the shipping service that you want to use for return labels. For more information, see [Return Label Setup for Local Shipping](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0808031849.html#subsect_0408023536).
        
    
    To create shipping items, see [Creating Shipping Items for your Shipping Services](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111040332.html).
    
3.  **Integrated Shipping Mode** - If you select the **Integrated Shipping per Order** mode, you must check this box on an order for which the preference record applies to. To generate labels, you must also use a shipping item created for Ship Central.
    
    If you check this box on an order, you can pack and ship the order or specific lines directly on an item fulfillment only. You cannot process it through the Ship Central app.
