Ship Central uses the company name and email address from your Company Information record to register and integrate your account with ShipStation API. If you want to set up Ship Central Shipping, make sure that you provide the correct company details.

To integrate with your NetSuite sandbox account, you must provide a different email address to register a separate NetSuite ShipStation API account.

From this record, Ship Central also uses the return address, or main address alternatively, if you enable return labels for shipping. See [Return Label Setup for Local Shipping](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0808031849.html#subsect_0408023536).

If you charge tax to the shipper for international shipments, Ship Central may use the company's tax registration number. Note that it prioritizes tax registration numbers on subsidiary records that you may have set up for different countries. For more information about tax registration numbers, see [International Shipping Setup for Ship Central](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0808031849.html#subsect_67151942691).

#### To enter company information for shipping:

1.  Go to _Setup > Company > Company Information_.
    
2.  On the Company Information page, set values in the following fields:
    
    -   **Company Name** - Enter the company's name that you want to use for the NetSuite ShipStation API account creation. If this name exceeds 30 characters, only the first 30 characters are used, following ShipStation API's limit.
        
    -   **Country** - Select the name of the country.
        
    -   **Return Email Address** - Enter the email address you want to use for the NetSuite ShipStation API account. If you are setting up a NetSuite sandbox account, be sure to use a separate email address.
        
3.  If you charge tax for shipments to the shipper and you want to enter the company's tax registration number, you can enter it in the appropriate field. The name of one or more fields for this number may vary, depending on the country.
    
    United States, for example, includes fields for both an Employer Identification Number and SSN or TIN.
    
4.  To provide addresses for shipment processing and returns, see [Enter Company Address Information](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_156710111536.html).
    
5.  To set other fields for your company, see [Enter Basic Company Information](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_156710108009.html).
    
6.  Click **Save**.
    

To create and register a NetSuite ShipStation API account, see [Registering and Integrating Your Carrier Accounts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111034346.html).
