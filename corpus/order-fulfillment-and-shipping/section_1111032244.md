After you install the SuiteApps, you must enable the required features. Verify that the required features for SCM Mobile are also enabled on your account.

You may also enable features for additional order, inventory, or shipping capabilities that suit your business requirements.

#### To enable features for NetSuite Ship Central: {#procedure_1111032309}

1.  Using the Administrator role, go to _Setup > Company > Enable Features_.
    
2.  On the Enable Features page, check the box next to the following required features:
    
    | Subtab | Feature Name | Remarks |
    | --- | --- | --- |
    | Company | 
    -   **Locations**
    -   **Multiple Units of Measure**
    
     | To set up locations for shipping, see [Creating Locations for Ship Central](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111035559.html). |
    | Transactions | 
    
    -   **Shipping Partners**
    
     |  |
    | SuiteCloud | 
    
    -   **Custom Records**
    -   **Advanced PDF/HTML Templates**
    -   **Client SuiteScript**
    -   **Server SuiteScript**
    
     | For more information about features for SCM Mobile, see [SCM Mobile SuiteApp Installation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161495429711.html#subsect_161495552374). |
    
3.  (Optional) You can check the box next to additional features that you may need to support your business processes, such as the following:
    
    -   To pack orders before you ship them out through the Ship Central app or the NetSuite UI, check the **Pick, Pack and Ship** box.
        
        Note:
        
        If you enable this feature, verify that you have the **Default Item Fulfillment Stage** preference set to **Picked**. You cannot pack items associated with fulfillments in Packed or Shipped status. See [Pick, Pack, and Ship Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1229796.html).
        
        If you do not enable this feature and you want to ship only through NetSuite UI, see [Setting Up Direct Packing and Shipping on Fulfillments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0219030324.html) or [Direct Packing or Shipping on Fulfillments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0324093230.html).
        
    -   To use bins, check the **Bin Management** and **Advanced Bin/Numbered Inventory Management** boxes.
        
    -   To set up bar code scanning, check the **Bar Coding and Item Labels** box.
        
    -   For Advanced Inventory Management users, to include the **Expected Ship Date** field in order transactions, check the **Supply Allocation** box. For more information about this field, see [Setting Demand Preferences for Supply Allocation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156425133807.html).
        
    -   To enter different shipping routes on an order transaction, check the **Multiple Shipping Routes** box and other required features.
        
    -   To enable the following shipping capabilities, check the **Shipping Label Integration** box:
        
        -   Direct packing and shipping on item fulfillments
            
        -   International shipping - Additionally, you must check the **Multiple Currencies** box. See [Enabling the Multiple Currencies Feature](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1395677.html).
            
        -   HazMat/Dangerous goods shipping through USPS
            
        -   Shipping label generation
            
        -   Return label generation
            
        -   Packages that you can assign to items
            
        
        After you enable these additional features, you must set up the related capabilities for the app. For instructions, see [Ship Central Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0808031849.html).
        
    -   To display the image of your items on the app, check the **Site Builder (Website)** and **Site Builder (Web Store)** boxes.
        
        If you do not see these features in your account, contact your NetSuite account manager.
        
    
    For the complete list of NetSuite features, see [Enabling Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N232138.html).
