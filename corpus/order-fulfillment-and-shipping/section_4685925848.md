Use order fulfillment automation in NetSuite to do the following:

-   Assign fulfillment locations to sales order lines, determined by location attributes, item attributes, and one or more location assignment rules in a configuration.
    
-   Create fulfillment requests for locations, based on the fulfillment location entered on a sales order line.
    

Automation relies on the occurrence of events in the order management workflow, such as the creation of a sales order or the deletion of an item fulfillment.

Automation includes usage limits, which NetSuite tracks on each sales order. It's free up to a certain number of automated sales orders - after that, you'll need to purchase additional automation capacity. See [Automation Capacity and Usage Fees](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156390342045.html).

Automatic location assignment can run in response to events included with the Automatic Location Assignment (ALA) feature, or events defined in a script that calls a macro. See [Automatic Location Assignment Macro](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156864454936.html) for more information about the macro.

## Automatic Location Assignment {#bridgehead_4642540541}

Automatic Location Assignment (ALA) is a feature that lets you manage how NetSuite assigns fulfillment locations to sales order lines automatically. Locations can be assigned in either of the following ways:

-   **Asynchronously** - If automatic location assignment relies on business events, the process runs asynchronously. This means you keep working in NetSuite while the automatic location assignment engine processes sales orders in the background.
    
-   **Synchronously** - If you run automatic location assignment with a macro, the process runs synchronously. This means that if you've configured other processes in a workflow or a script on the sales order, each process must wait until the previous one has run.
    

Note:

With the macro you can trigger automatic location assignment to run in response to other events that are not included with the Automatic Location Assignment feature. See [Business Events](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1498061964.html) for more information about ALA events.

Any locations in your NetSuite account can be used as fulfillment locations, which can be classed as warehouses or stores, or left as undefined. Automatic location assignment fulfills orders automatically based on the items in the order and the delivery address, thereby reducing shipping costs and improving customer satisfaction.

NetSuite determines the ideal fulfillment location according to how the feature is configured. Setting up regions and locations lets you define fulfillment locations within a specific geography as well as exclude locations. Defining automatic location assignment rules lets you choose the business criteria you want the system to evaluate to find the ideal fulfillment location. See [Automatic Location Assignment](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4440622680.html) for more information about configuring the system for automatic location assignment.

For example, you might have a customer in San Diego who orders an item that is available at a warehouse in both northern Mexico and the State of Washington. The northern Mexico location may be closer to San Diego, but it is possible that items from that location cannot ship to San Diego or the cost may be prohibitive. You can therefore set up automatic location assignment rules to prevent fulfillment from Mexico to the United States or even to a specific region with the United States.

## How Automatic Location Assignment Runs {#bridgehead_156683554303}

Automatic location assignment can be triggered by the following:

-   Business events. Business events is a framework that helps to automate business processes such as assigning locations to sales order lines in an asynchronous way. See [Business Events](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1498061964.html) for more information
    
-   A script that calls a macro. The macro for automatic location assignment offers an additional way to assign fulfillment locations automatically. See [Automatic Location Assignment Macro](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156864454936.html) for more information.
    

Note:

Business events and the macro work independently. Even if you haven't configured business events for automatic location assignment, the macro still runs.

You can also trigger automatic location assignment by clicking the **Auto Assign Locations** button on the sales order form.

## Fulfillment Requests {#bridgehead_4642541135}

The Fulfillment Request feature adds the fulfillment request transaction to your order fulfillment workflow. A fulfillment request is a demand to fulfill an order at a location. You can create a fulfillment request from a sales order after line items have a fulfillment location, the sales order status is Approved, and there's no payment hold.

When you automate fulfillment requests, NetSuite creates a fulfillment request immediately after a sales order is created or after an expected ship date is reached. In addition, the sales order must be approved and there must be no payment hold. See [Fulfillment Request Creation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4642548703.html), and [Fulfillment Requests](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4658324065.html) for more information.
