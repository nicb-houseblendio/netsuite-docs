After you pack cartons, you can print or save labels, lists, and other documents for carton packing in bulk. If you have activated the Pallet rule at any time to use pallets, you can also print existing labels and related documents for multiple pallets at the same time.

If you activate rules for reuse, you can choose which carton numbers to print based on their associated order numbers or pallet numbers based on the cartons they contain. For more information about the pallet and reuse rules, see [Configuring Ship Central Rules](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111041523.html).

You can print carton or pallet labels in bulk outside of their packing flows. Without PrintNode integration, you can generate and save them to your file cabinet. For information about printing settings and templates, see the following topics:

-   [Mobile Printing and Weighing Scale Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0131112602.html)
    
-   [SCM Mobile Printing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161495837530.html)
    

#### To print multiple packing labels and documents:

1.  On the Ship Central app, from the Options menu, tap **Print Packing Labels & Docs**.
    
2.  On the Select page, in the **Label or List Type** field, select either **Carton** or **Pallet**.
    
3.  To enter or select the cartons or pallets, do one of the following:
    
    Tip:
    
    If you scan or enter a number associated with an order outside of the date filter, the **Scan/Enter** field clears automatically. To change the date filter, tap the table icon. On the popup window, in the **Filter by Date** field, select **All** or a different number of months. Then, tap **Done**. For more information, see [Filtering Table Data by Date](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0307034044.html).
    
    -   In the **Scan/Enter** field, scan or enter each carton or pallet number. After you enter each number, press Enter to automatically select it from the list.
        
    -   From the Select list, check the box next to each carton or pallet number.
        
4.  Tap the appropriate **Print** button for the carton or pallet.
    
5.  On the Print popup window, set the printer, template, and number of copies. Then, tap **Print**.
    
    Tip:
    
    Without PrintNode integration, be sure to select **Print to File** in the **Printer** field.
    
    If you do not want to print a carton list, you can tap **Skip**. By default, the next report type and template, for the bill of lading, appear in their corresponding fields.
    
    After you print or save a list, you can repeat this step for other related documents. Otherwise, you can tap **Skip** to discontinue printing. For more information about printing settings, see [Manually Printing Labels from Your Mobile Device](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158681903713.html).
    

If you want to reprint labels or other related documents, see [Reprinting Labels](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158681935610.html).
