Aside from using the Void option within the shipping process flow, you can void shipping and return labels through the Void Shipping Label facility.

For local shipments for which you can enable the return label preference, you can void shipping and return labels separately. Note the following for orders or shipments that have both a shipping and return label:

-   If you void a shipping label, remember to void its associated return label.
    
-   If you do not use the label ID to search for labels and the order has both a shipping and return label, the app voids the return label first. You can use the same criteria, a different one, or the label ID to search for and void the associated shipping label.
    

#### To void shipping and return labels: {#procedure_0921101609}

1.  On the app, tap the menu icon, and then tap **Void Shipping Labels**.
    
2.  On the Void Shipping Label page, do one of the following:
    
    -   In **the Scan/Enter Label ID** field, scan or enter the label ID, order number, tracking number, or carton number. If you enter the data, tap **Void Shipping Label** to proceed.
        
    -   From the list of labels, tap the row of the shipping or return label that you want to void.
        
    
    The app displays a reminder to check with your carrier if any fees apply when you void labels.
    
3.  On the Warning popup window, review the reminders and voiding details, and then tap **Confirm**.
    
4.  If you want to view the list of voided labels on the NetSuite UI, do the following:
    
    1.  Using the Ship Central Manager role, go to Ship Central Reports > Shipping Labels > Voided Labels Search.
        
    2.  On the Voided Labels List: Results page, you can apply filters to narrow down the list of voided labels.
        

On the app, you can process the shipment or order again for shipping with a new shipping and return label. For more information, see [Shipping Orders Through the App](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111051146.html).
