Only users with Administrator roles or with **SuiteApp Marketplace** permission can install the SuiteApp. Following are the bundle details:

-   Bundle Name: Static Route Management
    
-   Bundle ID: 290640
    

For more information about installing a bundle, see [Installing a Bundle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3395142.html).

Static Route Management is a managed SuiteApp that is automatically updated whenever enhancements or new features are added.

## Prerequisites {#bridgehead_157250264347}

The Static Route Management SuiteApp is developed and tested for use primarily with NetSuite OneWorld.

You need to enable certain features to use the Static Route Management SuiteApp.

#### To enable the features:

1.  Go to _Setup > Company > Enable Features_.
    
2.  Check the boxes next to all the features listed in the following table:
    
    | Subtab | Feature Name |
    | --- | --- |
    | **Company** | Locations |
    | **SuiteCloud** | 
    -   Custom Records
    -   Client SuiteScript
    -   Server SuiteScript
    
     |
    
3.  Click **Save**.
    

Note:

The Static Route Management SuiteApp is independent of the Multiple Shipping Routes feature. For more information, read [Multiple Shipping Routes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1263041.html).
