You can generate and print a return label during local shipment processing for each package through the app. You can also print multiple labels at a time after you have shipped the packages. The time frame for return label generation may vary depending on your carrier.

Before you print or save a label, you can choose the shipping method you want to use for returns. Otherwise, the shipping method remains the same as the one used for the shipping label.

To set up return label generation and return addresses, see [Return Label Setup for Local Shipping](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0808031849.html#subsect_0408023536).

To print return labels directly from fulfillment records for UPS, USPS, or FedEx, see [Direct Packing or Shipping on Fulfillments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0324093230.html).

If you want to create and send return labels from generated RMAs, see [Generating Return Labels from an RMA](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0717031709.html).

To generate return labels for one shipment or package at a time, see [Shipping Orders Through the App](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111051146.html).

#### To generate and print return labels:

1.  From the Options menu, tap **Generate Return Label**.
    
2.  On the Print Return Label page, do one of the following:
    
    -   In the **Scan/Enter Label** field, scan or enter the shipping label, order number, tracking number, or pack carton. If you enter the data, tap **Print Return Label** to proceed.
        
    -   From the Labels list, tap the shipping label for which you want to generate and print return labels.
        
    
    The app displays a popup window to confirm additional charges that may apply to return labels.
    
3.  On the popup window, you can do the following:
    
    1.  Tap the box next to each package that you want to select.
        
    2.  If you want to choose a different method for the return shipping, tap **Change Shipping Method**. After you select a method, the Print window appears. Skip step 3.c.
        
    3.  Tap **Confirm & Generate**.
        
    4.  On the Print popup window, you can change the default settings for the printer, template, and number of copies.
        
        Tip:
        
        Without PrintNode integration, be sure to select **Print to File** in the **Printer** field.
        
    5.  Tap **Print**.
        

After the return labels have been generated and printed or saved, a Success message appears with the printing details.

In case you want to void return labels, see [Voiding Shipping and Return Labels](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0921101257.html).
