To pack orders through the mobile app, both the order transaction and fulfillment record must have the same shipping carrier and method. Otherwise, you cannot access these orders on the mobile app.

If you use Ship Central shipping and you want to pack third-party billing orders, be sure to set up the billing details on a preference record or order. See [Third-party or Recipient Billing Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0808031849.html#subsect_19152430936).

The instructions in this topic start from the Main Menu of the Ship Central app. If you use other SCM mobile apps, make sure you switch to the Ship Central app to access its Main Menu. You can also verify that the correct location is selected. See [SCM Mobile App Access](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161497091941.html). If you want to pack items that you have set up for individual shipping, see [Packing Items that Ship Individually](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_27093732538.html).

You can skip the steps or options that do not apply to your app settings. For example, if you activate the **Add shipping option** rule, you can proceed to shipping right after you process an order or orders for packing. Orders that you pack at the same time are processed in a single shipment. For more information about app settings and shipping, see the following topics:

-   [Ship Central Shipping](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111051105.html)
    
-   [Mobile Printing and Weighing Scale Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0131112602.html)
    
-   [Configuring Ship Central Rules](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111041523.html)
    

#### To pack items into cartons: {#procedure_1111043955}

1.  From the Ship Central app, access packing by doing the following:
    
    1.  From the Main Menu, tap **Packing**.
        
    2.  On the Select Order page, tap one of the following order types: **Sales Order** or **Transfer Order**.
        
    
    The names and labels on succeeding pages depend on the order transaction that you select.
    
2.  If you use Warehouse Management and your location has multiple bins, on the Select Bin page, do the following:
    
    Tip:
    
    If you want to hide the bins list from this page, tap **Show Bins** to switch off the toggle. Without waiting for bins to load, you can tap **Show Orders from All Displayed Bins** to proceed.
    
    1.  If you want to change the bin filter, tap the table icon. Then, in the **Bin Type** filter, you can select **Outbound Staging Bins**, which is the default setting. Otherwise, select **All Bins** to also display other bin types, including Inbound Staging, Picking, and None.
        
    2.  From the Bins list, tap the bin that contains the picked items you want to pack. Alternatively, tap **Show Orders from All Displayed Bins** to display orders from all the bins displayed in the list.
        
    
    Even if you select a bin, you must pack all the picked items from the same order that may be contained in other bins. Regardless of your filter, the list also includes orders for non-inventory items.
    
3.  On the Order page, select the orders you want to pack by doing the following:
    
    1.  If you want to change the pick status filter, tap the table icon. Then, in the **Pick Status** field, select one of the following options: **Include Partially Picked** or **Exclude Partially Picked**, which is the default setting.
        
    2.  From the orders list, tap the box next to the order you want to select.
        
        Tip:
        
        To continue packing an order in a previous session, tap the order in Started pack status. Then, select other orders that may appear in the list. These orders have been previously selected for packing at the same time.
        
        Alternatively, in the **Scan/Enter Order** field, scan or enter an order associated with the items you want to pack. If you use waves or pick cartons for Warehouse Management, you can scan or enter the wave number or pick carton that contains the items. If you enter the data, press **Enter Order**. The order that you scan or enter is automatically selected on the table.
        
        To process other orders or orders within the same wave, for the same customer, shipping details, that remain on the table, do one of the following:
        
        Tip:
        
        To remove the wave filter, tap the x icon beside the wave number that appears above the table.
        
        With the preference enabled, you can select orders or order lines with the same third party billing account that appears in the **Other Billing Account #** column.
        
        -   You can select, scan, or enter those that you want to pack at the same time, and then press **Enter Order**.
            
        -   To select all orders in the list, tap the box on the table header, and then press **Enter Order**.
            
    3.  If you have other orders for the same customer and shipping details, you can select, scan, or enter those that you want to pack at the same time. To select all of these orders, tap the box on the table header. If you enter the data, press **Enter**.
        
    4.  After you select all the orders that you want to process at the same time, tap **Enter Order**.
        
    5.  For orders that have items in separate bins or pick cartons, the Order Details page appears. You can view the list of bins or cartons per order. Then, tap **Pack Order** to continue.
        
    
    The Pack Items into Cartons page appears.
    
4.  To add a carton, tap **Add Carton**, and then on the Add Carton popup window, do the following:
    
    1.  In the **Scan/Enter Carton** field, scan or enter the pack carton.
        
        Alternatively, for autogenerated carton IDs, you can edit or change the ID. For more information, see [Defining Autogenerated ID Formats](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161704561857.html).
        
    2.  (Optional) To print a pack carton label, tap **Print Label**.
        
    3.  Tap **Add Carton**.
        
    
    In the panel beside the Items Packed table, the new carton appears.
    
    Repeat this step to add more cartons. If you want to delete a pack carton, see [Deleting a Carton](#subsect_19093724355).
    
5.  To add an item to a pack carton, do the following:
    
    Tip:
    
    If you want to temporarily stop packing and save your task, tap **Save & Close**. When you leave a task unfinished, another operator can access and process it.
    
    1.  From the cartons panel, tap the pack carton.
        
    2.  From the Items to Pack table, tap **Pack** next to the item you want to add to the carton.
        
        Alternatively, in the **Scan/Enter Pick Carton or Item** field, scan or enter the item, UPC, lot number, or serial number. You can also scan the GS1 DataMatrix bar code if configured for the item. If you use pick cartons for Warehouse Management, you can scan or enter the pick carton. If you enter the data, press Enter to proceed. For more information, see [Bar Code Scanning for Ship Central](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0726023627.html) or [Picking Orders](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1541442950.html).
        
        Tip:
        
        If you tally scan items, including lot or serial numbers, scan each item or number until you reach the quantity you want to add to the pack carton. Repeat from step 6.a to add items to another pack carton. After you add all the items, skip step 7 for entering the quantity.
        
    3.  If you activate the **Show Packing Instructions** rule, you can view the instructions on the popup window, and then tap **OK**.
        
        Item, order line, or both instructions appear on the popup window. To display packing instructions and item descriptions on this table, tap the table icon. On the popup window, from Visible Columns list, tap **Packing Instructions** or **Item Description**. To close the window, tap **Done**.
        
    
    To enter the quantity for regular or lot items, see step 7. For serialized items, see step 8.
    
6.  If you need to enter the quantity, on the Item popup window, do the following:
    
    1.  For lot items, tap the **Show All Lot Number** toggle, and then tap the lot number you want to select. Alternatively, in the **Scan/Enter Lot Number** field, scan or enter the lot number. If you enter the data, tap **Enter Lot Number**.
        
    2.  In the **Enter Qty** field, enter the number of items you want to add to the carton. Then, tap **Enter Quantity** or **Save**.
        
    3.  For serialized items, tap the **Show All Serial Numbers** toggle. From the list, tap the box next to each serial number, or next to the header to select all the numbers. This list displays only the serial numbers from the associated fulfillment record.
        
        Alternatively, in the **Scan/Enter Serial Number** field, scan or enter the serial number. If you enter the data, press Enter after each serial number entry.
        
    4.  Tap **Enter Serial Number**.
        
    
    To add more items to the same or another carton, repeat from step 5. To add a new carton, repeat from step 4.
    
7.  To close a carton and enter the carton weight and size, do the following:
    
    Tip:
    
    If you want to remove items or unpack an open carton, see [Removing Items from an Open Carton](#subsect_22093617576) or [Unpacking an Open Carton](#subsect_68093715825), respectively.
    
    1.  In the panel beside the Items Packed table, tap the carton.
        
    2.  Tap **Pack Carton**.
        
    3.  (Optional) If you use package weight calculation, in the **Tare Weight** field, enter the tare weight of the carton.
        
    4.  In the **Carton Weight** field, enter the numeric value of the carton's weight. If you set up calculated default weights, you can edit it.
        
        Alternatively, if you set up your weighing scale, tap **Capture Weight**. If you change the unit after tapping this button, tap it again to display the converted weight value. If you use package weight calculation, the app displays the scale weight's variance from the calculated weight in the Weight Variance field.
        
        For more information, see [Package Weight Entry or Calculation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111042907.html#subsect_16085704157) or [Weighing Scale Support](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161523537011.html).
        
    5.  In the **Carton Size** field, select a predefined size or select **Custom** to enter the length, width, and depth.
        
        For more information about predefined pack carton sizes, see [Creating Packing Items for Cartons and Pallets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_72093515569.html).
        
    6.  To manually print or save a pack carton label, lists, and other documents, tap **Print Label**.
        
    7.  Tap **Pack Carton**.
        
    
    Repeat this step to close all the open cartons. If you want to edit the carton details of a closed carton, tap **Open Carton**, before you repeat this step.
    
8.  After you close all the open cartons, tap **Next**.
    
9.  On the Packing Summary page, you can review the list of packed orders and cartons.
    
    On this page, additional options may appear depending on the rules and capabilities that you use and their settings.
    
    For example, you activate both the Enable pallet packing and Allow staging rules. With a Mandatory setting for the Enable pallet packing rule, you can perform staging only after you complete the pallet packing. In this case, the Staging button does not appear on the page.
    
    Make sure you complete additional or optional tasks before you submit the packed cartons or proceed to another process.
    
    1.  **Print Carton List** - Tap this button to print the carton list, including other documents, such as the bill of lading, that you have set up for mobile printing.
        
    2.  **Go to Staging** - If you use Warehouse Management, you can tap this button, and then on the Enter Staging Bin page, do one of the following:
        
        Note:
        
        You can stage packed cartons right away or transfer them onto pallets first before you stage them. If you stage packed cartons right away, you cannot transfer them onto a pallet anymore.
        
        -   In the **Scan/Enter Staging Bin** field, scan or enter the outbound staging bin. If you enter the data, tap **Enter Staging Bin**.
            
        -   From the Staging Bins list, tap the outbound staging bin you want to select. On the Staging Summary page, you can review the staging details.
            
        
        On the Staging Summary page, you can review the staging details.
        
    3.  On the Packing Summary or Staging Summary page, do one of the following:
        
        -   **Go to Shipping** - If you activate the Add shipping option rule, you can tap this button to process the packed orders for shipping. To continue, see step 5 of the instructions under [Shipping Orders Through the App](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111051146.html).
            
            Alternatively, you can process the orders for shipping after you transfer the packed cartons to a pallet.
            
        -   **Mark as Shipped** - If you activate the **Show Mark as Shipped option** rule, you can tap this button to change the associated item fulfillment's status from Picked to Shipped.
            
        -   **Add to Pallet** - Before or after you print the packing documents, you can tap this button to proceed to pallet packing. For instructions, see [Transferring Packed Cartons onto Pallets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_26093746962.html).
            
        -   **Complete Packing** - Tap this button to complete the current orders and go back to the order selection page for carton packing. To pack other orders, return to step 4.
            

On the NetSuite user interface, you can view the updated fulfillment records and order transactions. To view the packing details, see [Viewing Packing and Shipment Details](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111053025.html). You can search for orders or shipments using the carton number, transaction number, or other such details.

## Removing Items from an Open Carton {#subsect_22093617576}

You can remove items from cartons before you submit them.

Tip:

To remove items from a closed carton, you must open it first. In the carton panel, tap the closed carton, and then tap **Open Carton**.

#### To remove items from an open carton: {#procedure_43094607117}

1.  In the carton panel, tap that carton that contains the item.
    
2.  From the Items Packed table, tap **Unpack** next to the item you want to remove.
    
3.  If there are multiple quantities of the item, on the Item popup window, in the **Enter Qty** field, enter the number of items you want to remove from the carton.
    
4.  If you select a lot or serialized item, do one of the following:
    
    -   In the **Scan/Enter Lot Number** or **Scan/Enter Serial Number** field, tap the lot or serial number of the item. If you enter the data, tap **Enter** to proceed.
        
    -   To select from the list, tap the **Show All Lot Numbers** or **Show All Serial Numbers** toggle, and then tap the number. For serialized items, tap **Enter Serial Number** to proceed.
        

Items that you remove from a carton return to the Items to Pack table.

## Unpacking an Open Carton {#subsect_68093715825}

You can unpack cartons that you have not yet submitted.

Tip:

To unpack a closed carton, you must open it first. In the carton panel, tap the closed carton, and then tap **Open Carton**.

#### To unpack an open carton: {#procedure_30094613144}

1.  In the carton panel, tap that carton you want to unpack.
    
2.  Tap **Unpack Carton**.
    
3.  On the popup window, tap **Unpack Carton** to confirm that you want to unpack all the items.
    

All the items from the unpacked carton return to the Items to Pack table.

## Deleting a Carton {#subsect_19093724355}

You can delete cartons that you have not yet submitted.

#### To delete a carton: {#procedure_24094616409}

1.  In the carton panel, tap the carton.
    
2.  Tap **Delete Carton**.
    
3.  On the popup window, the message informs you that any items in the carton return to the Items to Pack list. To confirm, tap **Delete Carton**.
    

The pack carton is deleted from the panel.
