You can ship orders that you pack directly through the NetSuite UI or through the app, separately. If you don't use the Pick, Pack, and Ship feature, you can ship available items immediately after you create the orders.

Before you start shipment processing on the app, you can shop for rates and choose one to rerate an order or order line. If enabled for the app, you can also rerate during shipment processing. See [Rerating Orders](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0304032152.html) or [Rate Shopping Setup for the App](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0808031849.html#subsect_0219032022).

Ship Central provides these shipping options using the app or NetSuite UI depending on the features and settings enabled for your account:

-   [Shipping Orders Through the App](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111051146.html)
    
-   [Generating Labels Through Bulk Shipping](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0717014902.html)
    
-   [Direct Packing or Shipping on Fulfillments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0324093230.html)
    

During shipment processing on the app, if you want to apply filters, sort data, or display columns, see [SCM Mobile App Basics](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161556703949.html).

Order transactions must use the shipping methods associated with shipping items that you create for Ship Central. For more information about these shipping methods, see [Creating Shipping Items for your Shipping Services](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111040332.html). To view shipping services available from your synced carriers, see [Managing Your Shipping Integration](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111034346.html#subsect_20092856968).

Using shipping services or methods available from your carriers, you can ship orders locally. Based on preferences enabled for the app, you can use services that support international shipping and third party billing. If you set the third-party billing preference, you can update the billing account on orders or order lines before you pack or ship them. Other preferences enable you to print return labels, add shipment references, set up rates, and use additional shipping options. For more information, see [Ship Central Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0808031849.html) or [Setting Ship Central Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0219032354.html).

If you set the preference for hazmat or dangerous goods, be sure to select a local shipping method from USPS that supports these items. Otherwise, you may encounter an issue when you try to print a label. For more information, see [HazMat or Dangerous Goods Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0808031849.html#subsect_0809110808).

Aside from preferences, system rules provide these shipping capabilities for the app: shipping insurance, package codes, advanced options, brand names, and delivery confirmation, among others. To view and activate shipping rules, see [Configuring Ship Central Rules](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111041523.html).

## Shipping Address Validation {#subsect_98094927605}

The app obtains the shipping or ship to address from a sales or transfer order. It goes through ShipStation API's automatic validation before it's sent to the carrier for shipping label generation and rate calculation. See the following address validation options:

-   After you select a shipping method on an order, you can click the calculate icon beside the Shipping Cost field to view the shipping cost estimate. It serves as an initial address validation to provide a cost estimate on the order based on the shipping address and method.
    
-   For orders that you ship through the app, full address validation includes searching for matching addresses that have already been used successfully for shipping. You can choose whether to use this address for a specific shipment, without changing the one on the order. It also includes automatic identification of residential addresses.
    
-   Paid address validation service on the NetSuite UI. For information, see [Validating Shipping Addresses on Orders](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0423105825.html).
    

Before you process orders on the Ship Central app, note the following guidelines for address details:

-   On the **Shipping** subtab of an order, make sure that you provide the complete address details of the recipient. These details also include the attention line, addressee, and phone number.
    
-   For carriers that require an email address to generate shipping labels and documents, make sure that you provide a valid one on the associated customer record. For instructions, see [Creating a Customer Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161860867711.html).
    
-   When you choose a residential address on the order transaction, the app displays a message about additional charges that may apply. It displays the same message on the app. When you shop for rates, you can view shipping methods available for residential addresses.
    
    Even if you don't enable the **Residential Address** setting of a customer's address, the app determines separately whether an address is residential. Note that Ship Central doesn't consider the same setting on item fulfillments. During address validation, it indicates whether the original and suggested addresses are residential. They may not always match the Residential Address setting of the customer's address on the order transaction.
    
-   You can disable ShipStation API's full shipping address validation by the setting the **Address Validation** preference through one of the following ways
    
    -   On a Ship Central preferences record, you can set your preference for all or a specific location.
        
    -   On the app, you can set your preference for a specific shipment or order.
        
    
    Without full address validation, you must double-check the Address 1 details on the order and shipping labels before you ship the packages. Also, verify that the order has the correct Residential Address setting. For instructions, see [Setting Ship Central Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0219032354.html).
    
-   The app obtains the ship from address from a location record. On location records, provide the complete address details that you want to use for the sender. On the **Address** subtab, in the **Address** field, enter the address along with the attention line, addressee, and phone number. For instructions, see [Creating Locations for Ship Central](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111035559.html).
    

For more information, see the following topics:

-   [Adding Location Addresses With Address Validation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0219015224.html)
    
-   [NetSuite Ship Central FAQs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0831022109.html)
    

## Weight Calculation for Shipments {#subsect_0809043550}

To obtain the total weight, Ship Central uses the item weight that you specify on item records. If you use the Shipping Label Integration feature and set up a default package for an item, it adds the package weight to the item weight. After you ship an order, item fulfillments display the total weight per package on the **Packages** subtab.

Note the following if you do no set weights:

-   If you do not set any item weight, Ship Central uses the default 1 lb weight and adds it to the package weight.
    
-   If you do not select a package type on the item record and do not set a default package type on the Set Up Shipping page, the total weight reflects only the item weight.
    
    The package type on item records reflects the corresponding weight on the Set Up Shipping page. If you do not specify the weight of a package type on this page, the total weight does not include any package weight.
    
-   If you do not set both item and package weights, the total weight defaults to 1 lb.
    

Refer to the following table for examples of total weight calculation based on a package weight and varying item weight settings:

|  | Case 1 | Case 2 | Case 3 | Case 4 | Case 5 | Case 6 |
| --- | --- | --- | --- | --- | --- | --- |
| Item weight | Item record: 2 | Set Up Shipping page: 2.5 (not set on item record) | Default weight: 1 (not set on item record & Set Up Shipping page) |
| Package weight | Item record: 2.5 | Set Up Shipping page: 3.5 | Item record: 2.5 | Set Up Shipping page: 3.5 | Item record: 2.5 | Set Up Shipping page: 3.5 |
| Total weight | 4.5 | 5.5 | 5 | 6 | 5.5 | 4.5 |

If you enter or capture the carton weight during packing, the app uses it as the total weight regardless of your item or package settings For more information, see [Package Weight Entry or Calculation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111042907.html#subsect_16085704157).

When you ship through the app, changing the package code may also update the total weight.

## Package Codes and Sizes {#subsect_0304111212}

If you pack through the app, you carry over the size of the carton during shipment processing. If you use the Shipping Label Integration feature, you can set up package types and specify the dimensions for each of them. You can choose a default package type for all your items or assign one to each item. You can use them for orders that you pack directly through item fulfillments. If you ship through the app, you also carry over the size of the package type.

For single shipments or a multi-package shipment for a single order, you can use package codes if available from your carrier. During shipping through the app, you can choose a package code to replace your predefined carton sizes or package types. To enable package codes, see [Configuring Ship Central Rules](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111041523.html). To assign default package codes, see [Setting Ship Central Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0219032354.html).

## Details on Shipping Labels and Documents {#subsect_85095144742}

Labels display shipping, order, and address details along with other information based on your shipping preferences and rules.

For domestic shipments of hazmat or dangerous goods, the USPS shipping label displays the '**H**' tag at the upper left corner.

For domestic shipments through UPS, when the declared value of a package exceeds 1000 USD, UPS generates the High Value or Control Log form. When you print the shipping label, this form is automatically printed along with other documents.

Note:

You cannot customize label templates to add details, since shipping labels are generated by carriers. You can use the standard label templates to set the default format, whether PDF, ZPL, or letter size (PDF or PNG) on print reports. For more information, see [Shipping Labels and Documents for Mobile Printing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0131112602.html#subsect_53113621200) or [Standard Report Types in Mobile Apps](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161496026645.html#subsect_76102234507).

If you enable international shipping, you can print the Certificate of Origin and Commercial Invoice if you do not use the electronic or paperless submission services that your carrier may provide. If you use shipping services that include electronic submission of these forms, you may see any of these codes on shipping labels generated by the carrier: **EDI** for UPS, **PLT** for DHL Express, or **ETD** for FedEx. To set up, see [International Shipping Setup for Ship Central](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0808031849.html#subsect_67151942691).

Ship Central provides the following preferences and rules that you can enable to add details to shipping labels or documents:

-   You can enable preferences for adding a company logo or shipment references to shipping labels.
    
    By default, shipping labels display the carton ID or number as the first shipment reference. Depending on the services provided by your carrier, you may display up to two more references on labels. You can choose the fields that you want to set up as the source of your second and third references. Ship Central automatically obtains the values from these fields. You can manually enter reference values on the app for each shipment. However, make sure that they correspond to the reference fields that you set up. Also, note that shipping labels display only the first 30 characters of the actual reference values.
    
-   You can set a preference for generating label QR codes through Stamps.com for USPS shipments.
    
-   For shipments from Great Britain, your Shipment Type and At Risk Declaration preferences add these details on commercial invoices.
    
-   You can activate the **Print brand name** rule to print a brand name on shipping labels. You can provide a default brand name or enter a different one on each shipment. It replaces the sender's name on the printed label.
    
-   You can activate the **Set delivery confirmation of shipments** rule to choose a delivery confirmation on the app. The shipping label displays the delivery confirmation or its acronym.
    
-   You can activate the **Set advanced options from carriers** rule to include additional services that may be available from your carrier. Details of some advanced options appear on shipping labels.
    
-   On the app, you can choose the home delivery or Saturday delivery options that display on shipping labels.
    
    For international shipments, you can add customs details that appear on shipping documents. These include the declaration statement and non-delivery instructions, among others.
    

To set up these additional capabilities, see the following topics:

-   To activate the rules, see [Configuring Ship Central Rules](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111041523.html).
    
-   To set the preferences, see [Setting Ship Central Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0219032354.html).
    

Note:

Some of these capabilities and settings do not apply to labels that you print directly on item fulfillments for FedEx, UPS, or USPS. If you want to set up shipping directly on item fulfillments for these carriers, see [Setting Up Direct Packing and Shipping on Fulfillments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0219030324.html).

Based on your Mobile Printing setup, to print or save labels and documents for shipping, see the following topics:

-   If you do not enable Automatic printing for a print report, see [Manually Printing Labels from Your Mobile Device](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158681903713.html).
    
-   For FedEx, UPS, or USPS only, to ship and generate labels on fulfillments instead of the app, see [Direct Packing or Shipping on Fulfillments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0324093230.html).
    
-   To reprint labels, see [Reprinting Labels](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158681935610.html).
    
-   If you enable return labels, see [Generating and Printing Return Labels](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0812082039.html) or [Generating Return Labels from an RMA](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0717031709.html).
