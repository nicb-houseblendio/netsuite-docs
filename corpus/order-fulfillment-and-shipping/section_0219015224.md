On a location record, you can enter a single address and return address for each of your locations. Ship Central provides the Packship - Location Address record that lets you enter multiple address and related details for a location. For information about locations, see [Creating Locations for Ship Central](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111035559.html).

On the app, you can select an additional location address as your Ship From address instead of the address or return address on a location record. The address and its related details appear on shipping labels and documents.

After you save a location address, you can validate it through the paid service available for your NetSuite ShipStation API account.

#### To add location addresses with address validation:

1.  In the global search box, enter **Packship - Location Address**, and then select **New Packship - Location Address**.
    
2.  On the Packship - Location Address page, in the Primary Information section, set the following fields:
    
    -   **Name** - Enter a unique name to identify this location address record.
        
        When you change the Ship From address on the app, you can select this address by its name.
        
    -   **Location** - Select the location to which you want to associate this address.
        
    -   **Inactive** - Keep this box cleared to enable this address for use on the app.
        
3.  In the Address section, set the location address and details by doing the following:
    
    -   If the address is for a residence, check the **Residential Address** box.
        
    -   In the **Attention** field, enter the name of the person within an organization that should be notified of shipments from this address.
        
    -   In the **Addressee** field, enter the name of the organization or person that should be notified of shipments from this address.
        
        In the Ship From section of shipping labels, the addressee's name appears below the name you enter in the Attention field.
        
    -   In the following fields, enter your location address details: **Country**, **Address 1**, **Address 2**, **City**, **State**, **Zip**.
        
        Note:
        
        Before you request the paid address validation service, be sure to enter the complete address fields and check for spelling errors. This service does not verify whether the address is a residential one.
        
    -   In the following fields, enter the contact details: **Phone** and **Email**.
        
4.  Click **Save**.
    
5.  If you want to request the paid address validation service provided by your carrier, do the following:
    
    1.  Review the address details in the Address section fields. See step 3.
        
    2.  Click **Validate Address**.
        
    3.  In the **Valid Address** field, verify that the box is checked to confirm that the address has been verified.
        
    4.  t the page header, review the message for any details regarding the status of the address validation. If you see any issues, be sure to update the necessary details, especially if you want to revalidate the address.
