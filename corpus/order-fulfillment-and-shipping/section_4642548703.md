Fulfillment request creation is one of the two automation capabilities provided with the Advanced Order Management features. Setting up automated fulfillment requests involves two steps. First, you choose automation settings, and then you run the automation processes. Even when automation is running for fulfillment requests, you can continue creating fulfillment requests manually from sales orders - see [Fulfillment Requests](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4658324065.html) for more information.

Before you set up automated fulfillment requests in your account, make sure you have set the correct location type (store or warehouse) on location records. To set the location type on a location record, go to _Setup > Company > Classifications > Locations_. Click Edit next to the location record you want to work with. In the Location Type field, select either Store or Warehouse, and then click Save. (You can also leave the location type blank.)

To set up automation for fulfillment requests, complete the following steps:

1.  Choose automation settings for fulfillment requests.
    
2.  Run automation. See [Running Automation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4482799780.html).
    

When you automate the fulfillment request creation process, NetSuite creates the fulfillment request when the selected business events occur on the sales order. For more information about the business events that trigger the creation of fulfillment requests, see [Business Events](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1498061964.html).

Note:

Fulfillment requests are created only if the sales order is approved and there is no payment hold on the sales order.

After a fulfillment request is created, the sales order associated with it cannot be canceled.

#### To set up automation for fulfillment requests:

1.  Go to _Setup > Order Management > Setup Tasks > Advanced Order Management_.
    
2.  On the **Fulfillment Requests** tab, choose the location types that will use fulfillment requests. Make sure you have set the correct location type on location records.
    
3.  To create fulfillment requests automatically for shipping orders:
    
    1.  On the Automation tab, select the **Shipping Orders** subtab.
        
    2.  Under Automation Process, ensure **Fulfillment Request Creation** is selected.
        
        If the Automatic Location Assignment feature (ALA) is enabled, you can also select **Both (Automatic Location Assignment and Fulfillment Request Creation)**. See [Automatic Location Assignment](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4440622680.html) for more information about configuring ALA.
        
    3.  Under Fulfillment Request Creation, choose the business events that will trigger the creation of fulfillment requests. The options available are:
        
        -   Sales Order Approved
            
        -   Payment Hold Released
            
        -   Expected Ship Date is Reached
            
            If you choose this option, you cannot choose Sales Order Approved or Payment Hold Released.
            
        
        See [Business Events](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1498061964.html) for more information about the business events for fulfillment requests.
        
    4.  To delay the creation of fulfillment requests, check the **Wait Period Between Sales Order Creation and Fulfillment Request Creation** box and enter the delay interval (in minutes) in the **Wait Period Duration** field. See [Delaying Fulfillment Request Creation with a Wait Period](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_157960950753.html) for more information about setting a wait period.
        
4.  To create fulfillment requests automatically for store pickup orders:,
    
    1.  On the Automation tab, select the **Pickup Orders** subtab.
        
        Note:
        
        The Pickup Orders subtab only appears if the Store Pickup feature is enabled in your account. See [Store Pickup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4817102617.html) for more information.
        
    2.  Under Fulfillment Request Creation, choose the business events that will trigger the creation of fulfillment requests. The options available are:
        
        -   Sales Order Approved
            
        -   Payment Hold Released
            
        
        See [Business Events](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1498061964.html) for more information about the business events for fulfillment requests.
        
5.  Click **Save**.
    
    After choosing settings for fulfillment request creation, ensure automation is running - see [Running Automation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4482799780.html).
