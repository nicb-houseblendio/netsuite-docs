To create and fulfill store pickup orders, you must enable the Store Pickup feature in your account and complete additional setup tasks.

## Store Pickup Setup Steps {#bridgehead_1515411426}

Complete the following steps to set up store pickup:

1.  Enable the Store Pickup feature.
    
2.  Configure locations to allow store pickup.
    
3.  Verify store pickup settings for items.
    
4.  Create a customized sales order form.
    
5.  Turn on store pickup email notifications.
    
6.  Configure automation for store pickup orders.
    

These steps describe the minimum requirements to set up the Store Pickup feature. See the help topics related to each step for additional details.

## Step 1. Enable the Store Pickup feature. {#bridgehead_1518021090}

To create and fulfill store pickup orders in NetSuite, you must enable the Store Pickup feature.

#### To enable Store Pickup

1.  Go to _Setup > Company > Setup Tasks > Enable Features (Administrator)_.
    
2.  Click the **Transactions** subtab.
    
3.  Under Shipping & Receiving, check the **Store Pickup** box.
    
    The Store Pickup feature uses the Pick, Pack, and Ship feature. If not already enabled, you must enable it.
    
4.  Click **Save**.
    

See [Enabling Store Pickup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4833712390.html) for more information about enabling the Store Pickup feature.

## Step 2. Configure locations to allow store pickup. {#bridgehead_1515165290}

You must configure store locations to allow store pickup. You can also enter the business hours of the location. See [Configuring Locations for Store Pickup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4817104906.html).

#### To allow store pickup at a location:

1.  Go to _Setup > Company > Classifications > Locations (Administrator)_.
    
2.  Click **Edit** next to the location you want to set up.
    
3.  Click the Store Fulfillment tab and check the **Allow Store Pickup** box.
    
4.  On the Business Hours tab, enter the daily opening and closing hours of the location. See [Defining Store Business Hours](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4817104906.html#bridgehead_4817113183) for more information.
    
5.  Click **Save**.
    

## Step 3. Verify store pickup settings of items. {#bridgehead_1515165377}

Verify store pickup settings for individual items. All items are eligible for store pickup by default. See [Configuring Items for Store Pickup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4817105218.html).

#### To verify the store pickup settings of items:

1.  Go to _Lists > Accounting > Items (Administrator)_.
    
2.  Click **Edit** next to the item you want to modify.
    
3.  On the Purchasing/Inventory subtab, verify the **Allow Store Pickup** box in the Locations sublist for each location at which you want to enable store pickup. All items are enabled for store pickup by default.
    
    Clearing the Allow Store Pickup box prevents store pickup fulfillment for the item at the location.
    
4.  Click **Save**.
    

## Step 4. Create a customized sales order form. {#bridgehead_1515165464}

Customize the sales order form by adding the Fulfillment Choice and Location columns to the Items sublist. See [Customizing the Sales Order Form for Store Pickup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4817105427.html).

#### To customize a sales order form for store pickup:

1.  Go to _Transactions > Sales > Enter Sales Orders (Administrator)_.
    
2.  Click **Customize** at the top of the form and then select **Customize Form**.
    
3.  In the **Name** field, enter a name to identify the new form.
    
4.  Click the **Screen Fields** tab.
    
5.  Click the **Columns** subtab and add both the Location and the Fulfillment Choice columns to the form by checking the **Show** box for each item.
    
6.  Click **Save**.
    

## Step 5. Turn on store pickup email notifications. {#bridgehead_1515165728}

Optional. Send email notifications to customers when their order is ready for pickup. See [Store Pickup Email Notifications](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4817105615.html).

Note:

The Fulfillment Request feature must be enabled to send automatic email notifications - see [Enabling Store Pickup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4833712390.html).

## Step 6. Configure automation for store pickup orders. {#bridgehead_1515166094}

Optional. Create fulfillment requests automatically for stores after sales orders are saved in the system. See [Fulfillment Request Creation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4642548703.html) for more information.

After you complete the setup tasks for store pickup, you can create sales orders for store pickup (see [Creating Store Pickup Sales Orders](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4835438208.html)) and then fulfill the orders (see [Fulfilling Store Pickup Orders](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4817106057.html)).

Important:

Additional configuration steps are required if you want to offer store pickup as a fulfillment method on a SuiteCommerce Advanced web store. See [Store Pickup for SuiteCommerce Websites](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4793321418.html).

## Store Pickup and SuiteCommerce {#bridgehead_1515166602}

When both the Store Pickup and the **SuiteCommerce Advanced** features are enabled in your account and you want to enable store pickup on a SuiteCommerce web store, you must complete additional configuration steps. See [Store Pickup for SuiteCommerce Websites](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4793321418.html) for more information about the prerequisites and configuration steps for a SuiteCommerce Advanced web store.

## Store Pickup and Cross-Subsidiary Fulfillment {#bridgehead_1516011929}

When both the Store Pickup and the **Intercompany Cross-Subsidiary Fulfillment** features are enabled in your account, you can fulfill store pickup orders from store locations in other subsidiaries, as well as locations in the current subsidiary. You use the Inventory Location column (in the Items sublist) on a sales order to specify the store pickup location. The Inventory Location column appears on all sales order forms after you enable the Intercompany Cross-Subsidiary Fulfillment feature.

For more information about cross-subsidiary fulfillment, see [Intercompany Cross-Subsidiary Fulfillment](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1515621767.html).
