For bar code scanning setup procedures and guidelines, see the following topics:

1.  [Setting Ship Central Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0219032354.html) - Set your preference for whether you want to use your bar code's application identifier 01 or 02.
    
2.  [Creating Items for Ship Central](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111040001.html) - Configure the item's GTIN-14 in the **UPC** field of the item record.
    
    Note:
    
    If you use the Warehouse Management feature, you must configure the GTIN on item alias records instead. See [Bar Code Setup for NetSuite WMS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158264895870.html).
    
3.  [Scanning Item Bar Codes in Apps](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156382538378.html#subsect_156382537880) - If available for your device, you can set it up to automatically enter and submit data after you perform a scan.
    
4.  [Setting Up Custom Application Identifiers for GS1 Bar Code Scanning](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158264983840.html) - (Optional) You can configure custom application identifiers for item bar codes in the supported GS1 formats.
    
    For the list of standard and custom application identifiers, see [Standard GS1 Application Identifiers](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158264983840.html#subsect_158265001707).
