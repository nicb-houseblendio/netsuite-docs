Only users with an Administrator role or with SuiteBundler permission can install the SuiteBundle. The following are the bundle details:

-   Bundle name: Bill of Lading
    
-   Bundle ID: 312584
    

For more information, see [Installing a Bundle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3395142.html).

Bill of Lading is a managed SuiteBundle that automatically updates whenever enhancements or new features are added.

After the installation completes, you can start creating or customizing roles to use in bill of lading. Read [Creating or Customizing Roles to Use in Bill of Lading](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158590747588.html)
