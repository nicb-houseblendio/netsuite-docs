Instead of using the Shop for Rates option on the app, you can rerate a sales or transfer order, or any of its order lines through the NetSuite UI. Ship Central displays a list of shipping methods and rates available from your carriers. You can choose one that may belong to the same carrier or a different one. Either way, any updates to the shipping method and cost reflect on the corresponding fields in the order transaction. If you set the Calculate Tax preference for international shipments, you can also see updates to the estimated tax in the order.

When you rerate an order, you can choose a rate associated with shipping items that you set up for Ship Central. Available rates are provided by any of the carriers connected to your NetSuite ShipStation API account. For more information, see [Managing Your Shipping Integration](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111034346.html#subsect_20092856968).

Note the following settings or preferences that may affect estimated shipping cost calculation when you rerate:

-   Ship Central follows rate preferences that apply to the shipping method associated with a new rate that you select. These include flat, discount, or markup rates that you set on preference records for shipping items. For more information, see [Adding Shipping Item Settings](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0219032354.html#subsect_0219033648).
    
-   If you set the Calculate Tax preference for international shipments, you can also see updates to the estimated tariff on the order.
    

For other settings that affect shipping costs, see [Calculated Shipping Costs Within Ship Central](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0809043322.html).

Note:

This capability does not include any options to reset or reapply a rate that you may have set prior to performing a rerate.

You can either search for orders that you want to rerate or rerate directly on the order transaction. If you use the Multiple Shipping Routes features, you can select rates for specific order lines. For instructions, refer to the following procedures:

-   [To search for and rerate orders:](#procedure_0304032257)
    
    This option does not enable you to rerate an order already associated with item fulfillments. In this case, you can activate the rerate rule for the app. When you ship the order through the app, you can choose a different rate for the order or for the associated shipment. For more information, see [Shipping Orders Through the App](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111051146.html).
    
-   [To rerate directly on the order transaction:](#procedure_20082623078)
    

#### To search for and rerate orders: {#procedure_0304032257}

1.  Using the Ship Central Manager role, you can go to Ship Central Outbound > Shipping Details > Shop for Rates.
    
2.  On the Shop for Rates page, specify the details in the following fields:
    
    1.  **Location** - Select the location associated with the order.
        
    2.  **Transaction Type** - Select either **Sales Order** (default) or **Transfer Order**.
        
    3.  **Order #** - Enter the order number.
        
3.  If the order has the **Enable Item Line Shipping** box checked, you can rerate an order line, by doing the following:
    
    1.  Check the **Item Line Shipping Enabled** box.
        
    2.  Optionally, to specify lines that you want to rerate, select values in any of the following fields: **Ship To Per Line** or **Ship Via Per Line**.
        
4.  Click **Shop for Rates**.
    
    The Shipping Options list appears with details of the available shipping methods and carriers.
    
5.  Click **Submit**.
    
    You can view any updates on the **Shipping** subtab of the order transaction.
    

#### To rerate directly on the order transaction: {#procedure_20082623078}

1.  Open a sales or transfer order in edit mode.
    
2.  On a sales or transfer order, verify that the selected shipping method is associated with a shipping item created for Ship Central. You can also review the address in the **Ship To** field. Based on your order set up, do either of the following:
    
    -   If the order has a single shipping method, click the **Shipping** subtab to view the **Shipping Method** and **Ship To** fields.
        
    -   If you set the **Enable Line Item Shipping** box on the **Items** subtab, view the **Ship Via** and **Ship To** columns for each item line.
        
3.  On the **Shipping** subtab, do one of the following to view availablle shipping rates and select one:
    
    Tip:
    
    Before you rerate an order or order line, you can validate the shipping address first if you need to. For more information, see [Validating Shipping Addresses on Orders](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0423105825.html).
    
    -   For the order shipping, click **Get Carrier Rates** and wait for the request to be completely processed. Then, in the **Select Carrier Rate** field, select a new rate.
        
    -   For item line shipping, in the **Carrier Rates** column, click the calculate icon and wait for the request to be completely processed. Then, in the **Select Carrier Rate** field, select a new rate. You can repeat this step for another order line.
        
4.  For item line shipping only, after you select rates for all the order lines you want to rerate, apply the new rates by clicking **Calculate Shipping**.
    
    You can view related updates to shipping fields on the Shipment table and on the **Items** subtab.
    

After you apply new rates, note that other services from your carrier that you add to the order or through the app may further adjust the shipping cost. After you ship the order, you can view the actual shipping cost on item fulfillments.
