Ship Central can generate unique numbers or IDs for cartons, pallets, shipments, and bill of lading documents. It can also generate SSCC-18 codes in GS1 linear bar code format. Following GS1 specifications, it generates the appropriate SSCC-18 code for a carton or pallet. See [SSCC-18 Barcodes](https://www.gs1-128.info/sscc-18/).

Ship Central provides the following default formats for a label or document: BOL prefix, Carton prefix, Pallet prefix, Shipment prefix, and UCC DUNS. You can edit them if you want to define your own format. When you define a format for carton IDs, you can assign order transaction numbers as the prefix. For SSCC-18 codes, you can provide your company prefix or DUNS number.

Before you can generate IDs for cartons or pallets, you must activate the **Autogenerate carton and pallet IDs** rule. See [Configuring Ship Central Rules](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111041523.html).

If you enable Mobile Printing, you can print labels or documents with these IDs or codes, as you pack an order using your kiosk device. For more information about mobile printing, see [Shipping Labels and Documents for Mobile Printing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0131112602.html#subsect_53113621200).

#### To define autogenerated ID formats: {#procedure_1111041857}

1.  Edit the default format for the ID or code by doing the following:
    
    1.  Using the Packing Administrator role, go to Packing > Autogenerated ID Formats > Autogenerated ID Formats.
        
    2.  On the PackShip - Autogenerated ID Format List page, click **Edit** next to the format.
        
2.  On the Autogenerated ID Format page, set the following fields:
    
    -   **Name** - Enter a unique identifier for the ID format.
        
    -   **Label Type** - Select the type of label to which you want to assign the ID's prefix.
        
    
    For the UCC format type, proceed to step 4 to set additional fields for the SSCC-18.
    
3.  To define a format for cartons, pallets, BOL numbers, or shipments, set the following fields:
    
    -   **Prefix** - Enter a combination of letters, numbers, and symbols for the prefix of your ID.
        
        Tip:
        
        If you want to use an order number as the prefix for carton IDs, leave this field blank, and then check the **Use Order # as Prefix** box.
        
    -   **Initial Number** - Enter the initial number at which you want to begin the numbering sequence for the ID.
        
        This number appears after the prefix. It increments by one for each subsequent autogenerated ID. The number used in the latest autogenerated ID appears in the Last Number Used field.
        
    -   **Use Order # as Prefix** - For the Carton label type, check this box if you want to set the order number as the prefix for autogenerated carton IDs.
        
        If you check this box, NetSuite uses an order number as the prefix and overrides any value in the Prefix field. When you pack items from multiple orders at the same time, it uses only one order number for the prefix.
        
4.  To define a format for the SSCC-18 code, set the following fields:
    
    1.  **DUNS Number - Company Prefix** - Enter your DUNS number, with 9 digits, or your company prefix, with 7-10 digits.
        
    2.  **Initial Number** - Enter your first number in the sequence for your serial reference number, which identifies the shipping container.
        
        NetSuite increments this number by 1 for each subsequent serial reference number. If you do not specify your initial number, NetSuite uses **1** for your first serial reference number. The length of your serial reference number, from 6 to 9 digits, varies depending on the length of your company prefix or DUNS number.
        
        For example, if you enter an 8-digit company prefix, your serial reference number must not exceed 8 digits. You can enter an initial number that has 8 digits or less, such as **00001000** or **100**. If you enter a number less than 8 digits, NetSuite automatically prepends the appropriate number of 0's to the serial reference number.
        
        The Last Number Used field displays the number used for the serial reference number of the latest autogenerated SSCC-18 code.
        
5.  Click **Save**.
    

When you pack or ship through the app, you can manually enter an ID or name if you want to replace the autogenerated one or if you do not define a format.

#### To define autogenerated ID format for a subsidiary:

1.  Using the Packing Administrator role, go to Setup > Autogenerated ID Formats > Autogenerated ID Formats.
    
2.  Click **New PackShip - Autogenerated ID Format** on the PackShip - Autogenerated ID Format List page.
    
3.  On the Autogenerated ID Format page, set the following fields:
    
    -   **Name** - Enter a unique identifier for the ID format.
        
    -   **Label Type** - Select the UCC label type. The subsidiary values can only be added when the label type is UCC.
        
    -   **Subsidiary** - Select the subsidiary.
        
    
    -   **DUNS Number - Company Prefix** - Enter your DUNS number, with 9 digits, or your company prefix, with 7-10 digits.
        
    -   Click **Save**.
        

For the UCC DUNS format type, you must specify the subsidiary that owns the UCC. You can't assign a subsidiary to multiple formats of this type.
