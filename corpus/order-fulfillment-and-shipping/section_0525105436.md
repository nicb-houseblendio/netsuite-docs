Inventory reallocation enables you to redistribute inventory to fulfill high priority orders. You can reallocate inventory even from an order with a fulfillment in Picked or Packed status. However, you can't create a fulfillment for the other order with the reallocated inventory. If you ship the existing fulfillment, the reallocated inventory is reassigned to its originating order.

To control the inventory reallocation for orders with fulfillments in Picked or Packed status, you can use the following commitment settings:

-   **Limit to Committed** fulfillment preference - This preference setting prevents you from creating fulfillments for orders with no allocated inventory.
    
    To select this option, go to Setup > Accounting > Accounting Preferences. On the Accounting Preferences page, click the **Order Management** subtab, and then in the **Fulfill Based on Commitment** field, select **Limit to Committed**. For more information, see [Fulfillment](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1388149.html#bridgehead_N1390212).
    
-   **Commitment Confirmed** setting on order lines - Before you fulfill an order, you can check the **Commitment Confirmed** box on an order line. When you check this box, you set the allocation as firm.
    
    Note:
    
    The Supply Allocation feature provides the Reallocate Order Item exception management tool that enables you to ignore the Commitment Confirmed setting. When you use this tool, you can choose not to reallocate inventory from orders that have existing fulfillments in Picked or Packed status. For more information, see [Supply Allocation Exceptions Management](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159181096597.html).
    
    If you use the Warehouse Management feature to release orders in waves, you can set the **Automatically Set to Firm Committed Quantities in a Wave** preference. For more information, see [Setting Warehouse Management Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156406848826.html).
