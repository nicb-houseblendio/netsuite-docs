See the questions and answers below for information about NetSuite Ship Central:

### What third-party applications can I use with the Ship Central app?

Depending on the app capabilities that you want to use, you can set up the following additional requirements:

-   For shipping of packed orders on the app, NetSuite integrates with ShipStation API to connect with shipping services from your carriers.
    
-   For printing of labels, lists, and related documents, NetSuite integrates with PrintNode to connect with printers in your network. Without PrintNode integration, you can only save a soft copy of labels and documents.
    
    The same PrintNode integration is also used for weighing scale support.
    

The printers, bar code scanners, or weighing scales that you use may include their own software requirements.

For more information, see [NetSuite Ship Central Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111025719.html), [Bar Code Scanning for Ship Central](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0726023627.html), or [Mobile Printing and Weighing Scale Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0131112602.html).

### How do I know if my devices are supported by PrintNode?

PrintNode supports several ZPL printers for labels and regular printers for lists and documents in PDF format. It also supports a variety of weighing scales. To make sure that you get the latest guidelines, refer to the following PrintNode articles.

-   [Is My Printer Supported?](https://www.printnode.com/en/docs/supported-printers)
    
-   [Supported Scales](https://www.printnode.com/en/docs/supported-scales)
    

### What are the setup requirements for PrintNode integration?

Before you set up PrintNode, you can prepare your devices first, including computers, printers, and weighing scales. Verify that the drivers are up to date. For printers, you may also specify your printing preferences, such as the page size and orientation. For more information, see [Mobile Printing Requirements for PrintNode Integration](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161495837530.html#subsect_161495851722) or [Weighing Scale Support Requirements](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161523537011.html#subsect_161523545493).

To use NetSuite Ship Central with PrintNode, start your setup by creating a PrintNode account. Then, download and install the PrintNode client on all local computers associated with your printers and weighing scales. Verify that your active devices appear in your PrintNode client. For instructions, see [Installing the PrintNode Client](https://www.printnode.com/en/docs/installation/windows).

After setting up your PrintNode client and devices, enable Mobile Printing and Weighing Scale Support in your NetSuite account. To integrate the client with your NetSuite account, provide your active PrintNode API key. To connect your computers, safelist the IP addresses in your NetSuite account. Then, add and set up your printers in NetSuite. For instructions, see [Mobile Printing Setup Procedures](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161495837530.html#subsect_161495863496).

If you encounter setup errors, see [Troubleshooting Mobile Printing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162499375334.html).

### I use NetSuite WMS with Mobile Printing, are there additional PrintNode requirements for NetSuite Ship Central?

If you enable Mobile Printing for NetSuite WMS, you do not have to enable it separately for NetSuite Ship Central. If you want to enable Weighing Scale Support, you can set up your weighing scales through the same PrintNode client. For more information, see [Weighing Scale Support](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161523537011.html).

For Mobile Printing, if you want to use different printers, printing settings, or custom templates, you can complete the required setup tasks in NetSuite. For more information, see [SCM Mobile Printing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161495837530.html) or [Shipping Labels and Documents for Mobile Printing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0131112602.html#subsect_53113621200).

### How do I know if ShipStation API supports my carriers and carrier services?

NetSuite Ship Central supports shipping services for local and international shipments. Currently, Ship Central does not support carrier services for LTL shipping. For an overview of available shipping services, see [NetSuite Ship Central](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_90092747693.html).

ShipStation API enables you to connect with multiple carriers and their shipping services, which may change at any time. To make sure that you get the latest guidelines from ShipStation API, see [Connect ShipEngine and Get All These Integrations](https://www.shipengine.com/integrations).

### What are the setup requirements for ShipStation API integration?

To use NetSuite Ship Central with ShipStation API, note the following requirements and tasks:

1.  Create a ShipStation API account within NetSuite.
    
2.  Within your NetSuite ShipStation API account, provide your billing details and connect to your carrier accounts.
    
3.  Sync your NetSuite account.
    
4.  Enable the NetSuite Ship Central plug-in.
    
5.  If you want to enable additional shipping capabilities, do the following:
    
    a. Enable the capability or preference you want to use: International shipping, Third-party billing, or default company logo for printing.
    
    b. Re-sync your NetSuite account.
    
6.  Create shipping items for your shipping services.
    

To begin your ShipStation API integration, see [Registering and Integrating Your Carrier Accounts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111034346.html) and [NetSuite ShipStation API Account Help Resources](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_31113623121.html).

For more information about additional shipping capabilities, see [Ship Central Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0808031849.html).

### I created a ShipStation API account through NetSuite Ship Central. Can I use my existing API key for a different integration instead of Ship Central?

No, the API key cannot be accessed and used outside of Ship Central. API keys generated through Ship Central are assigned to NetSuite ShipStation API accounts to integrate exclusively with Ship Central.

If your API key gets corrupted, especially due to using it outside of your NetSuite ShipStation API account. see [Account Re-registration](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111034346.html#subsect_0916083749) or [Managing Your Shipping Integration](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111034346.html#subsect_20092856968).

### Can I use the app to pack items only, then ship items outside of the app or through a different shipping provider?

Yes, but you should check with your NetSuite account manager. You can use Ship Central Packing only and use another provider to ship items outside of the app. Setting up the ShipStation API integration capability for shipping is not required to pack items through the app.

For example, if you use NetSuite WMS, you can use the WMS Shipping Integration or Quick Ship instead, for shipping. For more information, see [Shipping Orders](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1541442959.html).

### Can I process international shipments without tax?

Yes, you can choose the **No Tax** option for the **Charge Tax To** setting for international shipments. With this option, you can skip entry of tax identifier details. You can configure this setting for locations on a preference record or for specific shipments on the app. For instructions, see [Setting Ship Central Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0219032354.html).

You can check with your carriers if they can process international shipments without tax. This setting is not available for direct shipments through the NetSuite UI.

### Can I specify the importer's address for international shipments?

Yes, you can specify the importer's address for international shipments if you set the **Charge Tax To** preference to **Importer of Record**. On customer records of your recipients, you can enter multiple addresses on the **Address** subtab and select a default shipping address.

When you ship through the app, you can tap the **Add Customs Details** to select any of these addresses for the importer. By default, this **Address of Importer** field shows the ship to address on the order. The address you select in this field doesn't go through address validation during shipment processing. It appears on commercial invoices and doesn't replace the order or ship to address.

For instructions, see the following topics:

-   [Tax Setup for International Shipments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0808031849.html#subsect_0408022317)
    
-   [Creating a Customer Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161860867711.html)
    
-   [Shipping Orders Through the App](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111051146.html)
    

### Through the app, can I ship to a P.O. box address?

Yes, using USPS shipping services, you can ship items to a P.O. box address through the mobile app. You can also ship through FedEx if you use their Ground Economy (formerly called FedEx SmartPost) service or UPS if you use their SurePost service. Contact your carrier for information, such as package limits, delivery times, and rates, about these services.

For existing NetSuite ShipStation API accounts, if you have newly added SmartPost or SurePost to your carrier account, you can sync your carriers and create shipping items within NetSuite. For instructions, see [Managing Your Shipping Integration](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111034346.html#subsect_20092856968).

You can also ship military and diplomatic mail to Army Post Office (APO), Fleet Post Office (FPO), or Diplomatic Post Office (DPO) addresses.

### How is the paid address validation service different from the standard one available within Ship Central?

The paid address validation available from ShipStation API provides the following capabilities that aren't included in the standard validation:

-   Ability to validate order or order line shipping addresses before you process orders for shipping
    
-   Detailed status and failure messages
    
    To view the list of messages, see [Address Validation Messages](https://www.shipengine.com/docs/addresses/validation/messages/).
    
-   Validation levels per country
    
    To view the list of supported countries and validation levels, see [Address Validation by Country](https://www.shipengine.com/docs/addresses/validation/countries/)
    

Unlike in the standard address validation, it does not suggest addresses that match the shipping address you provide. For more information about the paid service, see [Validating Shipping Addresses on Orders](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0423105825.html). For information about the standard service, see [Shipping Address Validation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111051105.html#subsect_98094927605).

### How does Bulk Shipping differ from the regular shipping flow?

On the app, Bulk Shipping for sales orders lets you generate shipping labels and related documents for multiple shipments at the same time. A batch of shipments for bulk shipping may include local and international shipments from different carriers. In your file cabinet, you can find the soft copes with filenames that have the **\- Batch** suffix.

Bulk Shipping doesn't support other system rules and preferences that you can enable for the regular shipping flow. These include insurance, package codes, shipment references, additional shipping options, and best rates, among others. You cannot rerate, unless you use the rate shopping facility within the NetSuite UI.

For international shipments, you can't change details required by customs, billing information, and tax charging. The app follows your settings from applicable preference records.

The app applies the Started shipping status to orders that you partially process through one shipping option. You can't access these orders and try to process them through the other shipping option.

As with the regular shipping flow, bulk shipping updates item fulfillments to Shipped status, along with the tracking number and actual shipping cost.

For more information, see [Generating Labels Through Bulk Shipping](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0717014902.html).

### How do I scan the GTIN content (application identifier 02) in a GS1 bar code?

By default, the app considers the 01 application identifier when you scan a GS1 item bar code, even if the 02 application identifier is present. If you want the app to consider the AI 02 of a scanned GS1 item bar code, complete the following procedures:

1.  On item records associated with application identifier 02 of bar codes that you want to scan on the app, set up the appropriate GTIN.
    
2.  On a Ship Central Preferences record, check the **Use AI 02 as Preferred for GS1** box. You can set it up on the standard preferences record for all locations or on custom preferences records of specific locations.
    

For more information see, [Bar Code Scanning for Ship Central](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0726023627.html).

The app uses only one application identifier at any time. If you set the preference and your GS1 item bar code has no AI 02 value, the app uses AI 01 instead. You may encounter an issue if you set the preference and scan a GS1 item bar code that has neither of these application identifiers.

For more information, see [What is the difference between AI (01) and AI (02)? - GS1 Ireland](https://www.gs1ie.org/tools-services/barcode-services/logistics-label-tool/faqs/what-is-the-difference-between-ai-01-and-ai-02.html).

### How do I set up and generate QR codes for shipping labels?

If you use the Shipping Label Integration feature, you can generate label QR codes, available through Stamps.com for USPS only.

To set up label QR codes, complete the following required or optional procedures:

1.  1\. Verify that Stamps.com is listed in your Carriers list and make sure that your USPS shipping account is set up with Stamps.com.
    
    See [Managing Your Shipping Integration](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111034346.html#subsect_20092856968).
    
2.  Create a dedicated shipping item for the Stamps.com carrier in which you set up your USPS account.
    
    Make sure that you can distinguish this shipping item from others that you may have set up for your USPS account outside of Stamps.com. On order transactions, you should be able to select shipping methods associated with this shipping item.
    
    To create shipping items, see [Creating Shipping Items for your Shipping Services](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111040332.html).
    
3.  (Optional) To set a default preference, on a Ship Central preferences record of your choice, in the **Print Format for USPS** field, select **QR Code**.
    
    See [Setting Ship Central Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0219032354.html).
    

To generate or print label QR codes through the app:

1.  When you create an order, select a shipping method associated with a shipping item for the label QR code.
    
2.  On the app, select one or more orders that use the same shipping method for label QR codes. Before you ship or print, you can tap **Edit** to make sure that the **Print Format for USPS** field is set to **QR Code**.
    
3.  When you ship or separately print labels, you can generate the QR code to print a hard copy or save on your device, depending on your Mobile Printing setup.
    
    For instructions on mobile app shipping, see [Shipping Orders Through the App](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111051146.html) or [Generating Labels Through Bulk Shipping](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0717014902.html). For instructions on the Print popup window, see [Label Printing and Reprinting](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_163113050855.html).
