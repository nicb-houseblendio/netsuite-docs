On item fulfillments, you can directly record packing or shipping details, as well as print labels. Options for fulfilling orders directly through the NetSuite UI depend on the following features and settings:

| Pick, Pack, and Ship feature = Enabled | Shipping Integration Label feature = Enabled \* | Shipping Mode Preference |
| --- | --- | --- |
| Pack and ship within NetSuite UI | Print or save labels using shipping items for Ship Central (FedEx, UPS, or USPS only) | **Integrated Shipping Only** or **Integrated Shipping Per Order** (FedEx, UPS, or USPS only) |
| Pack through app and ship within NetSuite UI |
| Pack and ship through the app | Print or save labels using shipping items for Ship Central | **Ship Central Only** |
| Pack within NetSuite UI and ship through app |
| **\*** If disabled, you can pack or ship through the NetSuite UI using any carrier without generating labels. |  |
| **Pick, Pack, and Ship feature = Disabled** |  |
| Ship through the app | Print or save labels using shipping items for Ship Central | **Ship Central Only** |
| Ship within NetSuite UI | Print or save labels using shipping items for Ship Central (FedEx, UPS, or USPS only) | **Integrated Shipping Only** or **Integrated Shipping Per Order** (FedEx, UPS, or USPS only) |
| **\*** If disabled, you can ship through the NetSuite UI using any carrier without generating labels. |  |

-   **Pick, Pack, and Ship** - If disabled, you can track orders for shipping only.
    
    Regardless of your setting for this feature, the bulk fulfillment option does not apply to direct fulfillments with Ship Central.
    
-   **Shipping Label Integration** - If disabled, you cannot print or save shipping labels regardless of the shipping item you use.
    
    If enabled, you can generate shipping and return labels on item fulfillments for orders that use shipping items that you create for Ship Central. In case you do not use these shipping items, you can ship the orders, but without generating labels through Ship Central. These capabilities apply to FedEx, UPS, or USPS only. For more information about shipping items, see [Creating Shipping Items for your Shipping Services](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111040332.html). To choose between PDF and ZPL label format for printing, see [Setting Ship Central Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0219032354.html).
    
    Note:
    
    For other carriers, you can ship and generate labels through the app using shipping items created for Ship Central only.
    
    This feature enables other shipping options, including international shipping and third-party billing, among others. For more information, see [Enabling Features for NetSuite Ship Central](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111032244.html).
    
-   **PrintNode integration** - Without PrintNode integration, you can view a soft copy of generated shipping labels and save it to your file cabinet. Whether you ship through the NetSuite UI or app, you must use shipping items for Ship Central. For more information about printing or saving labels, see [SCM Mobile Printing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161495837530.html).
    
-   **Shipping Mode** - To set this preference, see [Setting Up Direct Packing and Shipping on Fulfillments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0219030324.html) or [Setting Ship Central Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0219032354.html).
    

#### To pack or ship directly through the NetSuite UI:

1.  Before you pack or ship, you can review the order to verify that it has the following settings on the **Shipping** subtab:
    
    -   The shipping address must be correct, including the attention, phone number, and addressee details.
        
    -   The shipping method and cost from FedEx, UPS, or USPS must be set. The method must be associated with a shipping item created for Ship Central if you want to print or save labels.
        
    -   The **Integrated Shipping Mode** box must be checked.
        
2.  To pack orders, do one of the following:
    
    Tip:
    
    To ship directly through the NetSuite UI, begin from step 5 instead. You may do so if you do not have the packing option or if you want to ship orders packed through the app.
    
    -   To open an existing fulfillment, go to Transactions > Order Management > Fulfill Orders > List (Administrator). On the Item Fulfillments page, click **Edit** next to the fulfillment.
        
    -   To create a fulfillment from a single order, access the sales or transfer order, and then click **Fulfill**.
        
3.  On a fulfillment record in edit mode, in the **Set Shipment Status To** or **Status** field, select **Packed**.
    
4.  On the **Items** subtab, you can check the **Fulfill** box for each item and enter the inventory details.
    
5.  On the **Packages** subtab, do the following:
    
    1.  In the **LBS** or **KG** column, enter the weight in pounds or kilograms, respectively.
        
    2.  To add package details, click the package details icon.
        
        Then, on the popup window, in the appropriate fields, you may enter the following details: insurance amount, shipment references, delivery confirmation, and dry ice weight, among others.
        
    3.  Click **OK**.
        
6.  Click **Submit** or **Save**.
    
7.  To print, click the printer icon at the header. Then from the list, select **Print** for packing lists or **Print item labels**.
    
8.  When you are ready to ship the orders, do one of the following:
    
    -   To ship packed orders, open the existing fulfillment in edit mode. Then, in the **Status** field, select **Shipped**.
        
    -   To ship only, open the sales or transfer order in edit mode, and then click **Fulfill**.
        
9.  For orders that you ship only, see step 4 to view or add packages to the generated item fulfillment.
    
10.  Optionally, you can click the Shipment Details icons to view or add shipping options that may be available from your carrier. On the Integrated Shipping section of the popup window, note that some options depend on rules or preferences that you set up. If you enable the preference for billing other parties, you can change the billing account details obtained from the sales order or preference record.
     
     For more information about rules or preferences, see [Configuring Ship Central Rules](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111041523.html) or [Ship Central Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0808031849.html).
     
11.  Click **Save**.
     
12.  To print shipping labels, click the printer icon. Then, from the list, select **Print Label**.
