On sales or transfer orders, you can validate shipping addresses using the paid service available for NetSuite ShipStation API accounts. When you calculate the shipping cost on the order or through the app, you might encounter an issue due to the address. It may also cause issues when generating shipping labels. To avoid these issues, you can validate the address before you process orders for shipping. If you use the Multiple Shipping Routes feature, you can validate distinct addresses from the order lines. A charge applies for each address submission.

Important:

This paid validation service does not determine whether you have validated the same address on a different order

The same paid service enables you to validate location addresses that you add for your company or organization. For more information and instructions, see [Adding Location Addresses With Address Validation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0219015224.html).

For information about standard address validation on the NetSuite UI or app, see [Shipping Address Validation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111051105.html#subsect_98094927605).

#### To validate shipping addresses on orders:

1.  Open a sales or transfer order in edit mode.
    
2.  Verify that the order has a shipping method associated with a shipping item created for Ship Central by doing either of the following:
    
    -   If the order has a single shipping method, click the **Shipping** subtab to view the **Shipping Method** field.
        
    -   If you set the **Enable Line Item Shipping** box, click the **Items** subtab to view the **Ship Via** column.
        
    
    On the same subtabs, you can also review or edit the shipping addresses.
    
3.  On the **Shipping** subtab, do one of the following:
    
    Tip:
    
    A disabled button or check box indicates that the address has been validated successfully for this order. You can view the validation status for the order or order line.
    
    -   For order validation, click **Validate Address**.
        
    -   For order line validation, check the box next to each shipping address, and then click **Validate Address**.
        
4.  From the message at the header, you can review the results, and then do either of the following:
    
    Tip:
    
    Before you save the order, you can also view other available shipping rates and rerate the order. For information and guidelines, see [Rerating Orders](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0304032152.html).
    
    -   If you see a confirmation message, you can save the order.
        
    -   If you see a failure message, review or edit the address before you save the order.
        
    
    Failure statuses remain on the order, unless you revalidate the address. If you change a successfully validated address, you can perform another validation. For more information about these messages, see [NetSuite Ship Central FAQs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0831022109.html).
    
5.  If you edit or update the address for an order, be sure to apply the same changes to any associated fulfillment records.
