Shipping settings include additional capabilities that you can enable, separately, through the following procedures:

-   [To update your Shipping setup:](#procedure_0808031701)
    
    If you use the Shipping Label Integration feature, you can enable the following capabilities on the Set Up Shipping page: International Shipping, HazMat/Dangerous Goods (for USPS only); and Packages. Package setup includes package types that you can assign as a default for all items or to specific items.
    
    If you have a Commerce website, you can enable the setting to include shipping items created for Ship Central.
    
    For more information about the Shipping Label Integration feature, see [Enabling Features for NetSuite Ship Central](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111032244.html).
    
-   [To display customer names for shipments:](#procedure_47144417792)
    
    Mobile pages for packing and shipping contain tables that include the Customer column. To display customer names in this column, complete the following procedure. If you have already done this procedure for other features, you can double check your settings.
    

#### To update your Shipping setup: {#procedure_0808031701}

1.  Using the Administrator role, go to Setup > Accounting > Setup Tasks > Shipping.
    
    The Set Up Shipping page appears.
    
2.  To use the app to ship orders packed through the NetSuite UI, in **Shipping Label Creation Stage** field, select **Shipped**.
    
3.  To include shipping items in your Commerce website, check the **Charge for Shipping** box.
    
    If you enable this setting, you must also enable the **Display in Website** setting for each shipping item that you want to use on your website. See [Creating Shipping Items for your Shipping Services](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111040332.html).
    
4.  On the Preferences subtab, check the following boxes for the shipping options that you want to set up:
    
    -   **International Shipping**
        
    -   **HazMat/Dangerous Goods**
        
5.  On the **Packages** subtab, you can add package types that you want to set up on items that you ship:
    
    For instructions, see [Packages Subtab](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1257579.html#bridgehead_N1258591).
    
    To assign a default package to an item, see [Creating Items for Ship Central](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111040001.html).
    
6.  Click **Submit**.
    

To continue setting up international shipping or shipping of hazmat items, see [Ship Central Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0808031849.html).

#### To display customer names for shipments: {#procedure_47144417792}

1.  Go to Setup > Company > Auto-Generated Numbers (Administrator).
    
2.  In the Enable column, check the box for Customer.
    
3.  If you already have existing customer records, check the **Allow Override** and **Update** boxes for Customer.
    
    Skip this step if you have not added customer records yet.
    
4.  Click **Save**.
