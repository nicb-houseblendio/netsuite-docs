On Ship Central Preferences records, you can set up additional capabilities or default settings for the shipping services available from your carriers. These include shipment references, logos, Saturday delivery, shipping item rates, and default package codes.

If you can scan GS1 item bar codes, you can set the preference to consider application identifier 02 as preferred instead of application identifier 01. For more information, see [NetSuite Ship Central FAQs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0831022109.html). To set up bar codes for scanning, see [Bar Code Scanning for Ship Central](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0726023627.html).

If you use the Shipping Label Integration feature, you can enable settings on preference records to add the following shipping options:

-   Shipping labels, return labels, international shipping, and hazmat/dangerous goods shipping
    
-   Additional preferences for shipping labels include displaying your default logo and multiple shipment references supported by certain carriers
    
-   For FedEx, UPS, or USPS, you can choose a shipping mode for direct packing and shipping on item fulfillments.
    
    You can choose whether to print labels in ZPL or PDF format.
    
    You can also assign rates to shipping items that you create for these carriers.
    
    With the preference enabled, you can provide third party billing details when you pack or ship directly on item fulfillments.
    
-   Label QR codes generated by Stamps.com for USPS only.
    
    For more information, see [NetSuite Ship Central FAQs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0831022109.html).
    
-   Negotiated rates for some carriers

## International Shipping Setup for Ship Central {#subsect_67151942691}

You can set up international shipping for the Ship Central app by completing the following procedures:

1.  Enable international shipping in NetSuite - You can skip this step if you already use international shipping in NetSuite.
    
    -   Enable the required features for International Shipping. See [Enabling Features for NetSuite Ship Central](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111032244.html).
        
    -   Enable the International Shipping setting. See [Updating Shipping Settings](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0808031602.html).
        
2.  Set up international shipping for the Ship Central app.
    
    -   Set the **International Shipping** preference and settings for content type, and non-delivery instructions. See [Setting Ship Central Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0219032354.html).
        
    -   Configure tax settings, including tax registration numbers. See [Tax Setup for International Shipments](#subsect_0408022317).
        
    -   Sync your carriers to connect services for international shipping. See [Managing Your Shipping Integration](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111034346.html#subsect_20092856968).
        
    -   Create shipping items for international shipping services. See [Creating Shipping Items for your Shipping Services](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111040332.html).
        
    -   Update the items that you want to ship internationally with the manufacturer details and the description of goods. See [Creating Items for Ship Central](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111040001.html).
        
3.  Review any carrier-specific requirements, such as letterheads and signatures for FedEx international shipping. See [NetSuite ShipStation API Account Help Resources](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_31113623121.html).
    
4.  You can enable or update Mobile Printing to print or save international shipping labels and documents manually or automatically. For instructions, see [Mobile Printing and Weighing Scale Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0131112602.html).
    
    Note that shipping services from your carrier may include submission of shipping documents electronically, without making them available for printing or saving. For more information, see [Details on Shipping Labels and Documents](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111051105.html#subsect_85095144742).
    

## Tax Setup for International Shipments {#subsect_0408022317}

You can configure tax settings on a preference record enabled with international shipping. Tax settings apply to a subsidiary or location if you specify either or both on a preference record.

If you set the **International Shipping** preference, be sure to complete the following tax setup procedures:

1.  **Charge Tax To** - On a standard or custom preference record, be sure to set this preference. Choose the entity responsible for taxes, tariffs, and duties, or you can choose the **No Tax** option. On the app, your preference appears as the default setting, which you can change.
    
    Tip:
    
    On the app, you can apply a different setting for a shipment or override a tax setting using the **No Tax** option. Also, if you choose the **Importer of Record** option, you can specify whether to use the ship to address or any of the addresses from the associated customer record.
    
2.  **Tax Identifier** - Unless your **Charge Tax To** setting is set to **No Tax**, on a preference record, select the issuing country for the tax registration number.
    
    Note:
    
    Even if you choose the **No Tax** preference option, note that you may change it on the app for each shipment. In this case, you may still set tax identifiers on preference records. Depending on your business processes, you can also provide tax registration numbers on customer records, Company Information, or subsidiary records.
    
3.  **Tax Registration Number** - Depending on your **Charge Tax To** setting, set up tax registration numbers in the appropriate record, as follows:
    
    -   If you charge tax to recipients or importer of record, verify that you have correct tax registration numbers in customer records. See [Entering Financial Information for the Customer](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1078064.html)
        
    -   If you charge tax to the shipper, make sure that you have a tax registration number for the country that you want to ship from.
        
        Ship Central obtains the number from the subsidiary when you ship from the subsidiary's country. To view the subsidiary country and tax registration number, see [Creating Subsidiary Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N272471.html).
        
        If the subsidiary record has no tax registration number or when you ship from a different country, it checks the country on your Company Information record. It obtains the tax registration number from this record, instead, when you ship from the company's country. To view the company's country and tax registration number, see [Enter Basic Company Information](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_156710108009.html).
        
        For some countries, you may have an Employer Identification Number (EIN) and another tax registration number on the subsidiary or Company Information record. If you provide both numbers on a record, Ship Central uses the EIN.
        
        Ship Central also considers any tax details that you add on the **Tax Identifiers** subtab of your Ship Central Preferences record. It obtains the tax type for the country that matches the one from which you want to ship packages. Then, it determines whether to obtain the corresponding number for the tax type from the subsidiary record or Company Information record.
        
4.  **Enable USPS Canada Delivered Duty Paid** - (Optional) You can set this preference for the supported carrier and country only.
    
5.  **Calculate International Shipping Tax** - (Optional) You can set this preference to view estimated tariff charges before you ship a package.
    

## Third-party or Recipient Billing Setup {#subsect_19152430936}

You can set a preference record to bill recipients or third parties through the app and add billing account details per carrier and per customer. Depending on shipping services from your carrier, billing accounts apply to all local and international shipments for their associated customers.

Note:

Ship Central provides a separate **Enable 3rd Party Billing for FedEx Ground Collect** setting for this specific FedEx shipping service. If this service is available to your customers, their billing accounts are used, which they set up directly through FedEx. If you add third party or recipient billing accounts for the same customers on the preference page, Ship Central does not apply them to this shipping service.

Complete the following procedures to enable billing of other parties for the app:

1.  Set the **Bill Other Parties** preference in a Ship Central Preferences record. See [Setting Ship Central Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0219032354.html).
    
2.  If you have multiple billing accounts, you can associate them with preference records enabled with the Bill Other Parties preference. To add single or multiple billing accounts, you can do any of the following procedures:
    
    Tip:
    
    On customer records, make sure that the customer names match the names on the billing accounts that you associate with a preference record.
    
    -   After you set the preference, if you have multiple billing accounts to set up, you can add them to the same Ship Central Preferences record. For customers with multiple billing accounts, you can assign a default one for a carrier. Third party or recipient billing accounts apply to all locations unless you specify a location on the preference record. From the billing accounts that you add, you can choose on the app the one you want to use for a specific shipment.
        
    -   Through the CSV Import Assistant, using the Administrator role, you can use the **Other Billing Accounts** record type to add these accounts in bulk. On Step 1 of the Import Assistant, this option becomes available when you select the **Custom Records** import type. In your CSV file, include the account details. You can associate billing accounts with preference records during the import by including the following details:
        
        -   Internal ID of the Ship Central preferences record
            
        -   Billing Type setting
            
        -   Set as Default setting
            
        
        For instructions, see [Importing CSV Files with the Import Assistant](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N343158.html).
        
        Otherwise, you can assign each billing account to a preference record after your import.
        
    -   If you use the Shipping Label Integration feature, you can set up third party or recipient billing accounts for FedEx or UPS carriers on customer records. Instead of adding billing accounts to a preference record, you can set up one on each customer record. The app automatically uses the billing account for the customer. See [Entering Financial Information for the Customer](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1078064.html).
        
3.  Sync your carriers to connect services for third-party or recipient billing. See [Managing Your Shipping Integration](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111034346.html#subsect_20092856968).
    

After you enable other party billing, you can choose the third party or recipient billing details directly on sales orders. The **Other Party Type**, **Account Number**, **Country**, and **ZIP Code** fields appear at the order or line level, depending on your order setup. These fields default from the customer, carrier, and ship-to address you that you set in a preference record. On the app, Ship Central displays the billing account from orders when you select them for packing or shipping. The actual billing account used on a shipment, if updated on the app or changed through a rerate, display on item fulfilments after shipping.

## Return Label Setup for Local Shipping {#subsect_0408023536}

If you use the Shipping Label Integration feature, you can add the capability to print or save return labels. If you set up direct shipping on fulfillments for FedEx, UPS, or USPS, you can print or save return labels on item fulfillment records only. If you generate returns from a sales order or an invoice created from a sales order or item fulfillment, you can generate return labels from the RMA record.

Complete the following procedures to print or save return labels for local shipments:

1.  **Address** or **Return Address** - In your Company Information record, enter your main address, which the app also uses as your return address. You can also enter a different return address, instead, in its respective field.
    
2.  **Print Return Labels** - On a standard or custom preference record, be sure to set this preference. Your setting applies to a subsidiary or location that you may specify on a custom preference record.
    
    Note that you can only save labels if you do not use the PrintNode integration. For more information, see [SCM Mobile Printing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161495837530.html) or [Mobile Printing and Weighing Scale Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0131112602.html).
    
3.  **Return Service** - (Optional) If you set up direct shipping on fulfillments for FedEx, UPS, or USPS, you can configure this setting on a shipping item. For instructions, see [Creating Shipping Items for your Shipping Services](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111040332.html).
    
    For shipping through the app, the same shipping service applies to both shipping labels and return labels.
    

## HazMat or Dangerous Goods Setup {#subsect_0809110808}

For USPS local shipping only, you can complete the following procedures to enable shipping of hazardous materials or dangerous goods through the app.

1.  Enable hazmat shipping in NetSuite by doing the following:
    
    -   Enable the required feature for hazmat shipping. See [Enabling Features for NetSuite Ship Central](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111032244.html).
        
    -   Enable the **Hazmat/Dangerous Goods Shipping** setting. See [Updating Shipping Settings](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0808031602.html).
        
2.  Enable the **Hazmat/Dangerous Goods** setting on each inventory or assembly item record for your hazardous materials or dangerous goods. For instructions, see [Creating Items for Ship Central](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111040001.html).
    
3.  On the Ship Central Preferences record, provide the name and phone number of the person responsible for the shipment of dangerous goods.
    

## Rate Shopping Setup for the App {#subsect_0219032022}

You can provide the following options for operators to shop for rates on the app

-   **Rate Shopping** - To enable this option, activate the **Enable rate shopping** rule.
    
-   **Get Best Rate** - To enable this option, activate the **Enable rate shopping** rule and set the **Get Best Shipping Rate** preference. On the app, it automatically searches for and applies the lowest shipping rate for your shipment. For more information, see [Shipping Orders Through the App](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111051146.html).
    
    If you enable this option, you can also set the **Default Shipping Carriers for Best Rate** preference to specify the carriers for your source of best rates.
    

For more information, see [Configuring Ship Central Rules](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111041523.html).

These settings and preferences do not apply to the Shop for Rates options available on the NetSuite UI. For more information about these options, see [Rerating Orders](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0304032152.html).
