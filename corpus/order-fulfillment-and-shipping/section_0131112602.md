Before you enable Mobile Printing or Weighing Scale Support, you can read more information about PrintNode integration. See [NetSuite Ship Central FAQs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0831022109.html).

Templates and labels for Mobile Printing do not apply to the Print option available on the item fulfillment record. For this Print option, you can choose either the PDF or ZPL printing format for shipping labels. For information about requirements and setup procedures, see [Setting Up Direct Packing and Shipping on Fulfillments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0219030324.html).

To review Mobile Printing requirements, enable printing or weighing scale capabilities, or set up your devices and other preferences, see the following topics:

-   [SCM Mobile Printing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161495837530.html)
    
    You can enable Mobile Printing to print or save labels and documents during packing or shipping.
    
    After you set up Mobile Printing, printers, or printing settings, you can enable settings that add details to shipping labels or documents. See [Setting Ship Central Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0219032354.html) and [Configuring Ship Central Rules](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111041523.html).
    
-   [Weighing Scale Support](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161523537011.html)
    

## Saving Labels and Documents Without PrintNode Integration {#subsect_0304014939}

Without PrintNode integration, you can save soft copies of labels or documents for shipping or packing. On the app, you can choose the **Print to File** option in the **Printer** field. For more information, see [Setting Up Print to File](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0303093427.html).

## Shipping Labels and Documents for Mobile Printing {#subsect_53113621200}

If you enable Mobile Printing, you can print or save packing and shipping labels in these formats:

-   PDF format for regular printers
    
    For shipping labels only, you can print on a predefined letter size of 8.5 in. x 11 in. in PDF or PNG format. On a single page, you can print up to two labels of 4 in. x 6 in. size each.
    
-   ZPL format for label printers
    
-   Stamps.com paperless labels or label QR codes (for USPS only)
    
    For shipping labels only, QR codes can be generated for printing or saving on your device. To set up, see [Setting Ship Central Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0219032354.html).
    

### Standard Templates for Packing or Shipping Labels or Documents {#subsect_0304014546}

By default, you can print or save packing and shipping labels in ZPL format. You can change the default format through print templates configured on standard print reports.

For example, on the standard print report, you can assign the template for the letter-sized shipping label as your default.

On print reports, you can also change the default printer, number of copies for printing, and other printing settings. For more information about print reports, see [Setting Up Printing Settings on Print Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161496026645.html).

Mobile Printing provides one print template for each format of a label or document except for documents available in PDF format only. Print templates are preconfigured with XML templates files for PDF formats and TXT template files for ZPL formats. These template files contain the details included in a label or document for printing.

### Accessing and Customizing Print Template Files and Printed Files {#subsect_0726024427}

You can create your own XML and TXT files for the packing labels or documents to update the details or layout. You can copy a standard print template file, customize your copy, and assign it to a print template. For more information about print files and template customization, see [Creating Custom Print Templates and Files](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0206031419.html).

Without customizing templates, you can add a logo, shipment references, and other details to shipping documents. For more information, see [Details on Shipping Labels and Documents](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111051105.html#subsect_85095144742).

In the File Cabinet, you can access print files and soft copies of printed labels or documents. Using the Administrator role, go to Documents > Files > File Cabinet. Then, access the appropriate folder through either of the following navigation paths:

-   For print files, access the Templates folder of the Ship Central Bundle folder through this path: SuiteBundles > Bundle <Ship Central Bundle ID> > src > Templates.
    
-   For soft copies of printed labels, documents, or QR codes, access the PrintDocuments folder through this path: SuiteBundles > Bundle < Ship Central Bundle ID> > com.netsuite.packstation > src > PrintDocuments.
    

For information about bundle IDs, see [Installing the SuiteApps for NetSuite Ship Central](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111031232.html).
