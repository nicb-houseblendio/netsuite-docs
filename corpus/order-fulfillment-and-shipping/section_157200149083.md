Create truck records to assign the trucks to different routes.

#### To create a truck record:

1.  Go to Lists > Route Management > Trucks > New.
    
2.  In the **Truck Name** field, enter a name for the truck.
    
    Note:
    
    The truck name must be unique across all the subsidiaries.
    
3.  From the **Subsidiary** list, select the subsidiary to which you want to assign this truck.
    
4.  (Optional) To enter additional details of the truck, update any of the following fields:
    
    -   **Truck License Plate #** - Enter the truck's license plate number.
        
    -   **Truck Driver Name** - Enter the name of the truck driver.
        
    -   **Maximum Payload Weight** - Enter the maximum weight that the truck can carry.
        
    -   **Ambient Payload Capacity** - Enter the ambient payload capacity of the truck.
        
    -   **Refrigerated Payload Capacity** - Enter the refrigerated payload capacity of the truck.
        
    -   **Frozen Payload Capacity** - Enter the frozen payload capacity of the truck.
        
5.  Click **Save**.
    

You can also import truck information using the Import CSV Records feature. For more information, read [Importing CSV Files with the Import Assistant](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N343158.html).

Note:

You can delete a truck record only if it is not used in any routes.
