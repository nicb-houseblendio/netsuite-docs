NetSuite integrates with ShipStation API, a third-party provider of shipping solutions that include the ability to connect to services from multiple carriers. Within your NetSuite ShipStation API account, you can connect the carrier accounts that you want to use to process shipments through the app. For more information about the NetSuite ShipStation API account, see [NetSuite Ship Central FAQs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0831022109.html) or [NetSuite ShipStation API Account Help Resources](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_31113623121.html).

If you want to use the Ship Central app capabilities for shipping, you must create a NetSuite ShipStation API account within NetSuite. You cannot integrate a ShipStation API account created outside of NetSuite.

Ship Central uses the following details from your Company Information record to create and integrate a NetSuite ShipStation API account:

-   **Company Name** - Make sure that your company name does not exceed 50 characters, ShipStation API's limit for company names.
    
-   **Return Email Address** - Use an email address that is not associated with any existing ShipStation API or NetSuite ShipStation API account, whether a production or sandbox account.
    
-   **Account ID** - Make sure that the production or sandbox account ID is not already associated with a NetSuite ShipStation API account. To change the account ID and re-register, see [Account Re-registration](#subsect_0916083749).
    

To view or edit your company details, see [Entering Company Information for Shipping](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0524032659.html).

## ShipStation API Integration for NetSuite Sandbox Accounts {#subsect_0916083644}

To set up ShipCentral shipping in a NetSuite sandbox account, you must create a separate NetSuite ShipStation API account for it. If you use a free version of Stamps.com in your sandbox account, you can view estimated shipping costs on the app. However, you cannot print labels and complete the shipping process.

You cannot use the same NetSuite ShipStation API account for your NetSuite production and sandbox accounts. Be sure to use a different email address and account ID each for a NetSuite sandbox account and a NetSuite production account. To view or edit your company details for each account, see [Entering Company Information for Shipping](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0524032659.html).

In case of a sandbox refresh or registration issues, you can re-register your account. See [Account Re-registration](#subsect_0916083749).

## Account Re-registration {#subsect_0916083749}

During your initial registration, if you encounter an issue or a message about an existing ShipStation API account, you can retry the registration. Similarly, after a sandbox account refresh, re-register it to create a new NetSuite ShipStation API account. If your API key gets corrupted which usually occurs when you use it outside of your NetSuite ShipStation API account, that may also require you to re-register.

Note the following guidelines before doing an account re-registration for a NetSuite production or sandbox account:

-   Search for and delete all entries for the following custom records:
    
    -   PackShip - Encryption Key
        
    -   PackShip - Shipping API Key
        
-   Verify that no NetSuite ShipStation API account is associated with your sandbox or production account. For instructions, see Step 6 in the procedure, [To register and integrate your shipping services:](#procedure_1111034436)
    
-   To use a new email address and account ID, you can search for the PackShip - Company Details record in which you can enter them. After a sandbox refresh, these details may have been copied from your production account. Make sure that you re-register a production or sandbox account using an email address and account ID that is not associated with any ShipStation API account.
    
-   Repeat the same registration steps to create a new ShipStation API account within NetSuite.
    

#### To register and integrate your shipping services: {#procedure_1111034436}

1.  Using the Ship Central Manager role, go to Ship Central Setup > ShipStation API Integration > Manage Integration & Carriers.
    
2.  On the Encryption Key Entry page, do the following:
    
    Tip:
    
    This page does not appear if you have already entered an encryption key. You can skip this step.
    
    1.  In the **Encryption Key** field, enter a key that you want to use to encrypt your API key and account ID for ShipStation API.
        
        Important:
        
        Do not use your API key for another carrier integration or use it outside of your NetSuite ShipStation API account. If you do so, it might get corrupted and require you to re-register your account when you cannot use Ship Central services.
        
        An encryption key must have 16 characters. You can include a combination of letters, numbers, and symbols.
        
    2.  Click **Save**.
        
3.  On the Manage ShipStation API Integration page, click **Create ShipStation API Account.**
    
    A message appears at the top of the page to confirm your newly created ShipStation API account.
    
    ShipStation API generates your shipping API key, which is automatically encrypted and saved in your NetSuite account. If you need to make changes to the encryption key or shipping API key, see [Managing Your Shipping Integration](#subsect_20092856968).
    
4.  To add your carrier accounts to ShipStation API, do the following:
    
    1.  On the Manage ShipStation API Integration page, click **Add Carriers**.
        
        You are redirected to the ShipStation API site to get started and connect your carrier accounts.
        
    2.  Add each carrier account that you want to use for NetSuite Ship Central. For instructions, see [NetSuite ShipStation API Account Help Resources](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_31113623121.html).
        
    3.  On the Manage ShipStation API Integration page, click **Sync & Update Carriers**.
        
    
    Each carrier that you add appears in the Carriers list along with the shipping services associated with it.
    
5.  After you add and connect your carriers, follow these steps to enable the NetSuite Ship Central plug-in:
    
    1.  Go to Ship Central Setup > Ship Central Plug-in > Manage Plug-in.
        
    2.  On the Manage Plug-in Implementations page, check the **PackShip - Shipping Plugin** box.
        
    3.  Click **Save**.
        
6.  (Optional) To view your NetSuite ShipStation API account ID, do the following:
    
    1.  Using the Administrator role, go to Setup > Custom > Carrier Integration Details.
        
    2.  On the Carrier Integration Details page, click **Get ShipStation API Account ID**.
        
    
    Your account ID appears in the ShipStation API Account ID field. Ship Central uses this data during shipment processing only.
    

After you integrate your carrier accounts and enable the plug-in, you can create your shipping items. For instructions, see [Creating Shipping Items for your Shipping Services](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111040332.html).

## Managing Your Shipping Integration {#subsect_20092856968}

You can perform tasks to manage your existing ShipStation API integration. You can change the API key or re-encrypt the existing one. You can also sync or resync the default logo that you upload in your ShipStation API account. For the following purposes, be sure to resync your carriers before you use their shipping services:

-   To update or remove shipping services from existing carriers
    
-   To set up and use the shipping services of a new carrier
    
-   To update shipping services after you set the International Shipping or Other Party Billing preferences
    
    For more information, see [Setting Ship Central Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0219032354.html).
    

#### To manage your existing shipping integration: {#procedure_1111035236}

1.  Using the Ship Central Manager role, go to Ship Central Setup > ShipStation API Integration > Manage Integration & Carriers.
    
    On the Manage ShipStation API Integration page, from the Carriers list, you can view your integrated carriers and available shipping services.
    
2.  On the Manage ShipStation API Integration page, click the button that corresponds to the task you want to perform:
    
    -   **Add Carriers** - Enables you to connect additional carrier accounts to your NetSuite ShipStation API account.
        
    -   **Sync & Update Carriers** - Syncs your integrated carrier accounts from ShipStation API with NetSuite.
        
        Updates to carriers apply to new and existing shipments that you are processing on your device.
        
        If shipping services are updated or removed, make sure that you perform the necessary changes to the associated shipping services. For more information, see [Creating Shipping Items for your Shipping Services](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111040332.html).
        
    -   **Sync Default Logo** - Obtains the path for your default company logo used in label printing if supported by your carrier.
        
        Note:
        
        You must choose a default logo in your NetSuite ShipStation API account. To set up, you can upload a company logo in JPG or PNG format. The logo cannot exceed the maximum file size of 512 KB and maximum logo size of 500px. To view ShipStation API's guidelines on company logos, see [NetSuite ShipStation API Account Help Resources](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_31113623121.html).
        
        To enable printing of logos, see [Setting Ship Central Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0219032354.html).
        
    -   **Replace API Key** - Automatically obtains the shipping API key from ShipStation API and associates it with your NetSuite account.
        
        After the update, the new shipping API key is used to authenticate new shipping sessions on the app.
        
    -   **Re-encrypt API Key** - Opens the Encryption Key Entry page. Make sure you enter a 16-character string for the new encryption key.
        
        After you change the encryption key, NetSuite uses it to automatically re-encrypt the ShipStation API API key associated with your account.
