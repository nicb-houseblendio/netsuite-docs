If you use the Bar Coding and Item Labels feature, you can set up scanning of this additional item bar code format:

-   GS1 DataMatrix (2D)
    

If you activate the Tally Scanning rule, you can use the same items bar codes to tally scan items. See [System Rules for Ship Central](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111041523.html#subsect_5094547985).

## Bar Code Scanning Requirements {#subsect_0726023707}

Before you begin your setup, review the following scanner requirements:

-   For your browser, use Google Chrome. Other browsers may not be able to display FNC1 (Function Code One) characters from scanned bar codes.
    
-   To scan GS1 item bar codes, the scanner should be able to display FNC1 characters and bar code symbols.
    

For more information about bar code scanning through the app, see [Bar Code Scanning for SCM Mobile](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161495607456.html).
