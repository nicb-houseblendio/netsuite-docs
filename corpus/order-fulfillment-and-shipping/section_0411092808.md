You can pack all items, all quantities of an item, or all quantities of multiple items into a single carton. For items that ship individually, Ship Central adds a pack carton for each quantity and closes it automatically.

On the app, the **Enable Multiselect** toggle displays the **Pack All** and **Unpack All** options. It also disables the **Pack** and **Unpack** options for each row. When you pack all or unpack all, you do not provide any item quantities, lot numbers, and serial numbers. After you enable the toggle, it remains enabled unless you clear your browser's cache.

To review settings and system rules that may affect packing or label printing flows, see [Ship Central Packing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111042907.html).

#### To pack all items into a carton:

1.  On the Ship Central app, access packing by doing the following:
    
    1.  From the Main Menu, tap **Packing**.
        
    2.  On the Select Order page, tap one of the following order types: **Sales Order** or **Transfer Order**.
        
    
    The names and labels on succeeding pages depend on the order transaction that you select.
    
2.  If you use Warehouse Management and your location has multiple bins, on the Select Bin page, do the following:
    
    If you want to hide the bins list from this page, tap **Show Bins** to switch off the toggle. Without waiting for bins to load, you can tap **Show Orders from All Displayed Bins** to proceed.
    
    1.  If you want to change the bin filter, tap the table icon. Then, in the **Bin Type** filter, you can select **Outbound Staging Bins**, which is the default setting. Otherwise, select **All Bins** to also display other bin types, including Inbound Staging, Picking, and None.
        
    2.  From the Bins list, tap the bin that contains the picked items you want to pack. Alternatively, tap **Show Orders from All Displayed Bins** to display orders from all the bins displayed in the list.
        
    
    Even if you select a bin, you must pack all the picked items from the same order that may be contained in other bins. Regardless of your filter, the list also includes orders for non-inventory items.
    
3.  On the Order page, select the orders you want to pack by doing the following:
    
    1.  If you want to change the pick status filter, tap the table icon. Then, in the **Pick Status** field, select one of the following options: **Include Partially Picked** or **Exclude Partially Picked**, which is the default setting.
        
    2.  From the orders list, tap the box next to the order you want to select.
        
        Tip:
        
        To continue packing an order in a previous session, tap the order in Started pack status. Then, select other orders that may appear in the list. These orders have been previously selected for packing at the same time.
        
        Alternatively, in the **Scan/Enter Order** field, scan or enter an order associated with the items you want to pack. If you use waves or pick cartons for Warehouse Management, you can scan or enter the wave number or pick carton that contains the items. If you enter the data, press **Enter Order**. The order that you scan or enter is automatically selected on the table.
        
        To process other orders or orders within the same wave, for the same customer and shipping details, that remain on the table, do one of the following:
        
        Tip:
        
        To remove the wave filter, tap the x icon beside the wave number that appears above the table.
        
        With the preference enabled, you can select orders or order lines with the same third party billing account that appears in the **Other Billing Account #** column. See [Third-party or Recipient Billing Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0808031849.html#subsect_19152430936).
        
        -   You can select, scan, or enter those that you want to pack at the same time, and then press **Enter Order**.
            
        -   To select all orders in the list, tap the box on the table header, and then press **Enter Order**.
            
    3.  If you have other orders for the same customer and shipping details, you can select, scan, or enter those that you want to pack at the same time. To select all of these orders, tap the box on the table header. If you enter the data, press **Enter**.
        
    4.  After you select all the orders that you want to process at the same time, tap **Enter Order**.
        
    5.  For orders that have items in separate bins or pick cartons, the Order Details page appears. You can view the list of bins or cartons per order. Then, tap **Pack Order** to continue.
        
    
    The Pack Items into Cartons page appears.
    
4.  To add a carton, except for items that ship individually, do the following:
    
    1.  Tap **Add Carton**.
        
    2.  On the popup window, in the **Scan/Enter Carton** field, scan or enter the pack carton.
        
        Tip:
        
        If you can reuse existing cartons, tap **Reuse Carton** instead. You can search for or select any pack carton associated with a Shipped fulfillment.
        
        Alternatively, for autogenerated carton IDs, you can edit or change the ID. For more information, see [Defining Autogenerated ID Formats](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161704561857.html).
        
    3.  (Optional) To print or save a pack carton label, tap **Print Label**.
        
    4.  Tap **Add Carton**.
        
    
    In the panel beside the Items Packed table, the new carton appears.
    
    Repeat this step to add more cartons. If you want to delete a pack carton, see [Deleting a Carton](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1122013706.html#subsect_19093724355).
    
5.  Above the Items to Pack table, tap the **Enable Multiselect** toggle and then do the following:
    
    1.  Tap the box next to each item or at the header.
        
    2.  Tap **Pack All**.
        
    
    All quantities of the items move to the Items Packed table.
    
    If you want to add another carton, repeat from step 4.
    
6.  To close a carton and enter the carton weight and size, do the following:
    
    Tip:
    
    If you want to remove all the quantities of an item before you close a carton, tap the box next to the item. Then, tap **Unpack All**.
    
    For an item that ships individually, skip this step. If you want to unpack it, tap the box next to it and then tap **Delete Carton**.
    
    1.  In the panel beside the Items Packed table, tap the carton.
        
    2.  Tap **Pack Carton**.
        
    3.  (Optional) If you use package weight calculation, in the **Tare Weight** field, enter the tare weight of the carton.
        
    4.  In the **Carton Weight** field, enter the numeric value of the carton's weight. If you set up calculated default weights, you can edit it.
        
        Alternatively, if you set up your weighing scale, tap **Capture Weight**. If you change the unit after tapping this button, tap it again to display the converted weight value. If you use package weight calculation, the app displays the scale weight's variance from the calculated weight in the **Weight Variance** field.
        
        For more information, see [Package Weight Entry or Calculation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111042907.html#subsect_16085704157) or [Weighing Scale Support](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161523537011.html).
        
    5.  In the **Carton Size** field, select a predefined size or select **Custom** to enter the length, width, and depth.
        
        For more information about predefined pack carton sizes, see [Creating Packing Items for Cartons and Pallets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_72093515569.html).
        
    6.  To manually print or save a pack carton label, lists, and other documents, tap **Print Label**.
        
    7.  Tap **Pack Carton**.
        
    
    Repeat this step to close all the open cartons. If you want to edit details or unpack items, tap **Open Carton**, before you repeat this step.
    
7.  After you close all the open cartons, tap **Next**.
    
8.  On the Packing Summary page, tap **Print Carton List** or **Add to Pallet**.
    
    If you want to print or save, be sure to do so before you transfer cartons to a pallet. Alternatively, to skip pallets, you can tap any of the other options: **Mark as Shipped, Go to Shipping,** or **Complete Packing**. These options depend on rules that you active for shipping on the app. If you use Warehouse Management, you can tap **Go to Staging** before you ship or complete your packing.
