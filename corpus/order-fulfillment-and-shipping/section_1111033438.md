You can assign NetSuite Ship Central roles to employees in your organization. If they already have existing roles assigned, you can update the roles with permissions that provide access to packing or shipping.

If you use Specialized User: WMS roles and want to modify access to the Ship Central app, see [Specialized User: WMS Role](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0318011053.html).

## Assigning Ship Central Roles {#subsect_47093402623}

The following roles enable you to perform fulfillment tasks on your kiosk device and setup procedures:

-   **Packing Administrator** - This custom role provides access to Ship Central records that enable you to set up shipping integration, packing or shipping items, rules, and printing settings.
    
    Note:
    
    Use the standard Administrator role for initial setup requirements such as SuiteApp installation, enabling features, and assigning roles. Use it to update NetSuite records, such as company, item, location, and the Set Up Shipping records. Use this role too for direct packing or shipping on fulfillment records available for direct carrier integrations.
    
-   **Packing Operator** - This custom role enables you to process orders for packing on the mobile app.
    
-   **Ship Central Manager** - This custom role provides access to packing and shipping records to set up and use Ship Central.
    
-   **Ship Central Mobile Operator** - This custom role enables you to process orders for packing and shipping on the mobile app.
    
-   **Ship Central Packing Operator** - This custom role enables you to process orders for packing on the mobile app.
    
-   **Ship Central Shipping Operator** - This custom role enables you to process orders for shipping on the mobile app.
    

To assign any of the Ship Central roles, see [Assigning Roles to an Employee](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N897798.html).

When you copy a Ship Central role, you carry over their predefined permissions and access levels. On your copy of the role, you can add more permissions that suit your business requirements before you assign the role. See [Customizing and Creating Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N286284.html) or [NetSuite Permissions Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N325094.html).

## Updating Roles with Ship Central Permissions {#subsect_80093414118}

NetSuite Ship Central permissions give you access to custom records and process flows for setup tasks and fulfillment processing using a kiosk device. To use roles that are not copied from a Ship Central role, you can manually assign these permissions. See [Assigning Ship Central Roles](#subsect_47093402623).

For example, you can add permissions to provide a custom WMS Warehouse Manager or Specialized User: WMS role access to packing or shipping on the app. For more information about these roles, see [Warehouse Management Roles and Permissions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156520467974.html).

| --- | --- |
| Packing Administrator | Packing or Shipping Operator Ship Central Manager or Mobile Operator |
| --- | --- |
| PackShip - Autogenerated ID Format | Full | Full (Packing Operator only) |
| PackShip - List Print Parent Record | Full | Full |
| PackShip - Pack Carton | Full | Full |
| PackShip - Packed Item | Full | Full |
| PackShip - Packed Item Details | Full | Full |
| PackShip - Packing Item |  | Full |
| PackShip - Pallet | Full | Full |
| PackShip - Print Carrier Information | Full | Full |
| PackShip - Print Carton And Items | Full | Full |
| PackShip - Print Customer Order Info | Full | Full |
| PackShip - Print Items In Cartons | Full | Full |
| PackShip - Shipment | Full | Full |
| PackShip - Shipping Cost Distribution |  | Full (except Packing Operator) |
| PackShip Auto Printing Rule data | Full | Full |
| PackShip Lock Record | Full | Full |
| PackShip - Advanced Options | Full | Full |
| Ship Central Packing | Full | Full |
| Ship Central Shipping | Full | Full |
| **\*** Packing permissions apply to accounts that use the Pick, Pack, and Ship feature only. |  |

Aside from the Custom Record permissions listed in the table, verify that shipping roles have access to the following standard permissions:

-   **Lists** subtab: Shipping Partner Package - **Full**
    
-   **Setup** subtab: Set Up Company - **View**
