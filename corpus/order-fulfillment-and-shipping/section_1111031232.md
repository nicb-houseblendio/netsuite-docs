To begin your setup, you must first install the SCM Mobile SuiteApp, and then install the Ship Central SuiteApp. SCM Mobile provides you with Ship Central access on a kiosk or tablet device. For requirements and installation of the SCM Mobile SuiteApp, see [SCM Mobile Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161495429711.html).

#### To install SuiteApps for NetSuite Ship Central: {#procedure_1111031634}

1.  Using the Administrator role, go to _Customization > SuiteBundler > Search & Install Bundles_.
    
    The Search & Install Bundles page appears.
    
2.  In the **Keywords** field, enter the name of the bundle you want to install, following the order in this list:
    
    1.  **SCM Mobile** - 590761
        
    2.  **NetSuite Ship Central** - 591665
        
3.  Click **Search**.
    
4.  From the search results, click the name next to the corresponding bundle ID shown in step 2.
    
5.  On the Bundle Details page, click **Install**.
    
6.  If a popup message appears that asks for your permission to install future bundle updates, click **OK** to confirm.
    
7.  On the Preview Bundle Install page, click **Install Bundle**.
    
    After you install the SCM Mobile SuiteApp, you can follow the same instructions to install the Ship Central SuiteApp.
    

While you wait for a bundle installation to complete, you can continue your work in your NetSuite account. To view the status of bundle installations, go to Customization > SuiteBundler > Search & Install Bundles > List.
