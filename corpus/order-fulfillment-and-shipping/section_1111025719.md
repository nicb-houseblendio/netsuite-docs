To set up Ship Central packing, shipping, or both, follow the procedures in these topics:

Note:

If you want to review requirements for integrations with ShipStation API and PrintNode before you begin your Ship Central setup, see [NetSuite Ship Central FAQs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0831022109.html).

1.  [Installing the SuiteApps for NetSuite Ship Central](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111031232.html)
    
    Install the required SCM Mobile SuiteApp and NetSuite Ship Central SuiteApp.
    
2.  [Enabling Features for NetSuite Ship Central](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111032244.html)
    
    Enable required features to use the Ship Central app for packing, shipping, or both. Additionally, you can enable optional features for bar code scanning, international shipping, and bin management, among others.
    
    Without enabling the Pick, Pack, and Ship feature, you can ship only through the app or NetSuite UI. If you enable it, you can pack, ship, or do both through the app or NetSuite UI. For more information about processing through NetSuite UI, see [Direct Packing or Shipping on Fulfillments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0324093230.html).
    
3.  [NetSuite Ship Central Roles and Permissions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111033438.html)
    
    Assign predefined roles, specialized user roles, or permissions to existing roles to perform packing and shipping tasks.
    
4.  If you enable features for shipping and international shipping, you can continue your shipping setup by completing the following tasks:
    
    a. [Entering Company Information for Shipping](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0524032659.html) - Enter company details that you want to use to create and register your NetSuite ShipStation API account.
    
    b. [Registering and Integrating Your Carrier Accounts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111034346.html) - Create a ShipStation API account within NetSuite, sync your carriers or company logo, enable the Ship Central plug-in, and manage synced carriers.
    
    c. [Updating Shipping Settings](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0808031602.html) - Enable required settings for international shipping, hazmat shipping, showing customer names, and other optional shipping settings.
    
    d. [Ship Central Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0808031849.html) - Depending on your business needs, you can enable return labels and settings for rates, logos, or shipment references, among others, as described in these topics:
    
    -   [Setting Up Direct Packing and Shipping on Fulfillments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0219030324.html)
        
    -   [International Shipping Setup for Ship Central](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0808031849.html#subsect_67151942691)
        
    -   [Tax Setup for International Shipments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0808031849.html#subsect_0408022317)
        
    -   [Third-party or Recipient Billing Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0808031849.html#subsect_19152430936)
        
    -   [Return Label Setup for Local Shipping](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0808031849.html#subsect_0408023536)
        
    -   [HazMat or Dangerous Goods Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0808031849.html#subsect_0809110808)
        
    -   [Rate Shopping Setup for the App](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0808031849.html#subsect_0219032022)
        
    -   [Adding Package Code Settings](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0219032354.html#subsect_0219033442)
        
    -   [Adding Shipping Item Settings](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0219032354.html#subsect_0219033648)
        
    -   [Adding Shipment References](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0219032354.html#subsect_0219034016)
        
    -   [Shipping Cost with Discounts, Mark ups, Flat Rates, or Negotiated Rates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0809043322.html#subsect_1027031205)
        
5.  [Setting Up Records for NetSuite Ship Central](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3093009106.html)
    
    Depending on the features you want to use, set up locations, items, packing items, shipping items, and cost distributions.
    
    Alternatively, you can import these records through a CSV import using the Administrator role: shipping item and other billing accounts, among others. To use the Import Assistant, see [Importing CSV Files with the Import Assistant](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N343158.html). For specific guidelines, see [Third-party or Recipient Billing Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0808031849.html#subsect_19152430936) or [Importing Shipping Items for NetSuite Ship Central](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0401023430.html).
    
6.  [Defining Autogenerated ID Formats](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161704561857.html)
    
    Set up autogenerated IDs for cartons, pallets, shipments, BOL, or SSCC-18.
    

After your Ship Central setup, you can configure your kiosk or tablet devices and mobile app access.

## Mobile Device Requirements {#subsect_86105915253}

Refer to the following device hardware and software requirements or recommendations:

-   For new kiosk and tablet devices -
    
    -   Kiosks: Windows 10.0 or higher
        
    -   Tablets: Only devices that have iOS ((iPadOS 18 or higher versions for iPad) or Android (7.0 or higher versions) are supported. Support for versions may change subject to updates from their respective developers.
        
        Only the Google Chrome and Safari browsers are supported. You should use the latest version of the browser.
        
-   Recommended screen resolution - 1280 x 800 up to 1920 x 1080
    
-   Optimized for horizontal user interfaces or the landscape display mode
    

If available for your device, you can set it up to automatically enter data after you perform a scan. See [Scanning Item Bar Codes in Apps](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156382538378.html#subsect_156382537880).

For more information about mobile app requirements, see [SCM Mobile Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161495429711.html).

## Enabling Ship Central Mobile App Capabilities and Access {#subsect_36110001888}

If you already use another SCM Mobile app, you may have enabled mobile app capabilities such as bar code scanning, weighing scale support, mobile printing, and tally scanning. When you set up Ship Central, these capabilities also apply to packing and shipping. In addition, you can enable settings and rules that suit your business requirements or enhance specific Ship Central processes. For more information and instructions, see the following topics:

-   [Bar Code Scanning for Ship Central](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0726023627.html)
    
-   [Mobile Printing and Weighing Scale Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0131112602.html)
    
    \- Includes options to use or not use PrintNode integration
    
    \- Set up print templates for packing or shipping labels or documents
    
-   [Configuring Ship Central Rules](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111041523.html)
    
    \- Includes packing and shipping rules for specifying your threshold when processing large volumes of transactions in real time
    
    \- Rules also enable packing instructions, additional shipping options, and carton reuse, among other
    

To set up mobile app access, see the following SCM Mobile topics:

-   [Language Preference Setup for SCM Mobile](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161495570632.html)
    
-   [Setting Up the Online Form User Role](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0814113835.html)
    
-   [SCM Mobile App Access](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161497091941.html)
    

Optionally, if you want to provide access to specific mobile process only, see the following topics:

-   To set up access to standard mobile processes, see [Configuring Menu Icons on Independent Mobile Pages](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0804040635.html).
    
-   To set up access to custom mobile process that you create, see [Customizing Mobile Processes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163614423814.html).
    

Menu icons remain hidden from roles that don't have access to a standard or custom mobile process

You can update mobile pages, page elements, and actions to suit your app requirements, as described in the following topics:
