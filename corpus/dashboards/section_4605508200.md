Report Snapshot portlets show summaries of some reports you can access. You can pick from standard report snapshots or create your own custom snapshots.

#### To add a Report Snapshot to your dashboard:

1.  Click **Personalize** in the upper right corner of your dashboard or use **Personalize Dashboard** in the **Settings** portlet.
    
2.  On the **Standard Content** tab of the **Personalize Dashboard** palette, click the **Report Snapshots** icon or drag it onto the dashboard.
    
    ![Report Snapshot icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Dashboards/ReportSnapshot_portlet_icon.png)
3.  Click **Set Up** in the portlet menu and select the report snapshot you want to display from the **Snapshot** list.
    
4.  Click **Save** to update the portlet content.
    

You can also expand the portlet to full screen by clicking the double arrow icon ![The Double Arrow icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Dashboards/DoubleArrowIcon.png).

For a list of standard report snapshots, see [Standard Report Snapshots Table](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N626685.html).

To learn how to create custom report snapshots, see [Creating Custom Report Snapshots](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N630437.html).

For more information about report snapshots, see [Report Snapshots](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N625749.html).
