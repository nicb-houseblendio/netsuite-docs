You can delete a custom report snapshot when it is displayed in a report snapshot portlet.

#### To delete a custom report snapshot: {#procedure_N630768}

1.  Find the custom report snapshot on your dashboard.
    
2.  Click the report snapshot dropdown list and select **Edit**.
    
3.  From the **Actions** menu, select **Delete**.
