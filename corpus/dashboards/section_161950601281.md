When Dashboard Tiles is installed, the dashboard tiles custom record becomes available. The following table lists the permissions required to access the dashboard tiles custom record.

An Administrator needs to add the required permissions to roles that will use the SuiteApp. For information about customizing roles, see [Customizing or Creating NetSuite Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N285937.html).

| Custom Record | Minimum Permission Level | Maximum Permission Level |
| --- | --- | --- |
| Dashboard Tiles | View | Full |
