After the Navigation Portlet is installed, custom records become available. See the following table for the list of custom records and the permission levels required to access them.

An Administrator needs to add the required permissions to roles that will use the SuiteApp.

| Custom Record | Minimum Permission Level | Maximum Permission Level |
| --- | --- | --- |
| Navigation Categories | View | Full |
| Navigation Shortcut | View | Full |
| Navigation Shortcut Group | View | Full |
| Navigation Shortcut Tooltip | View | Full |
