You can print or export content from some dashboard portlets. These options are usually in the same menu as the Set Up option in the portlets where they are available. The following table lists the portlets that support these options.

| Portlet Type | Supported Print/Export Options | Notes |
| --- | --- | --- |
| KPI Meter | 
-   Print the chart
-   Download PNG image
-   Download JPG image
-   Download PDF document
-   Download SVG vector image

 | Available from portlet menu. |
| KPI Scorecard | 

-   Export (data to CSV file)

 | Available from portlet menu. |
| Report Snapshot | 

-   Print the chart
-   Download PNG image
-   Download JPG image
-   Download PDF document
-   Download SVG vector image

 | Available from portlet menu. |
| Trend Graph Portlet | 

-   Export (data to CSV file)
-   Print the chart
-   Download PNG image
-   Download JPG image
-   Download PDF document
-   Download SVG vector image

 | Available from portlet menu. |
| Trend Graph Pop-Up Window | 

-   Export (data to CSV file)
-   Print the chart
-   Download PNG image
-   Download JPG image
-   Download PDF document
-   Download SVG vector image

 | 

-   The Trend Graph pop-up window is available on some portlets, including KPI Scorecard and Key Performance Indicators portlets.
-   Export link is available from the Trend Graph window.

-   Print and download options are available from the Trend Graph window menu.

 |
