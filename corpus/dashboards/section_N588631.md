You can use the Quick Add portlet to quickly add new records of a selected type right from your dashboard, without switching pages. For example, a Sales Rep could create a new customer record from the Home page, or a new task from a customer page.

You can set up the Quick Add portlet for several standard record types or for a custom type that you've made available for Quick Add. You also can edit which fields are available in the portlet for data entry.

Important:

For the Quick Add portlet work, you need to have the Inline Editing feature enabled. For more information, see [Using Inline Editing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N495192.html).

#### To add a Quick Add portlet to a dashboard:

1.  Click **Personalize** in the upper right corner of your dashboard or use **Personalize Dashboard** in the **Settings** portlet.
    
2.  On the **Standard Content** tab of the **Personalize Dashboard** palette, click the **Quick Add** icon or drag it onto the dashboard.
    
    ![Quick Add portlet icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Dashboards/QuickAdd_portlet.png)
3.  To choose a different default record type, click **Set Up** in the portlet menu. Then, select the record type from the **Quick Add: Type** list and click **Save**.
    
    ![Change Type window](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Dashboards/QuickAddDropdown.png)

For more information, see [Using Quick Add for Standard Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N588741.html) and [Using Quick Add for Custom Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N589317.html).
