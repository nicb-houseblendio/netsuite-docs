The KPI Scorecards feature must be enabled before you can create a KPI scorecard or add a KPI Scorecard portlet to a dashboard.

#### To enable the KPI Scorecards feature: {#procedure_N611031}

1.  Go to _Setup > Company > Enable Features_.
    
2.  On the **Analytics** subtab, check the **KPI Scorecards** box, and click **Save**.
    

Note:

If you don't see **Enable Features** on your **Setup** tab, you don't have this permission. You need to ask a user with the Administrator role or the Enable Features permission to enable the KPI Scorecards feature.

When the KPI Scorecards feature is enabled, you can:

-   Create your own KPI scorecard (if you have the KPI Scorecards permission). See [Creating a KPI Scorecard](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N612318.html).
    
-   Add a KPI scorecard portlet to display an existing KPI scorecard. See [Adding a KPI Scorecard Portlet to a Dashboard](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N612018.html).
