## Overview {#subsect_156869693399}

Navigation Portlet lets you simplify navigation to commonly used menus in NetSuite. Using this SuiteApp, you can create groups and categories for shortcuts or links that you frequently use in NetSuite. The shortcuts and categories are displayed in the custom portlet and can be configured using a custom record.

To get started with this SuiteApp, you need to add the navigation portlet custom portlet. For more information about adding custom portlets, see [Custom Portlets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4605493647.html). You can add multiple navigation portlets to your dashboard.

Navigation Portlet is available in all languages that NetSuite supports. For more information, read [Configuring Multiple Languages](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N247147.html) and [Choosing a Language for Your NetSuite User Interface](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N479109.html).

## Availability {#subsect_156867973323}

Navigation Portlet is a managed SuiteApp that automatically updates whenever there are new features or enhancements added.

For instructions on installing this SuiteApp, see [Installing the Navigation Portlet SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1501567651.html).
