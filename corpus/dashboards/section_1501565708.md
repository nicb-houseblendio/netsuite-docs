## Overview {#bridgehead_1552978518}

Dashboard Tiles lets you build a dashboard with tiles that display business critical KPIs in a bold, visual layout with images and blinking alerts. The blinking alerts remind you when metrics don't meet certain conditions. You can configure the content of the tiles based on how you want them to be displayed or translated on your dashboard.

Using this SuiteApp, you can create and customize the following tile types:

-   Static
    
-   Reminder
    
-   Scorecard
    

For more information, see [Types of Dashboard Tiles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1548305654.html).

## Availability {#bridgehead_1501565782}

Dashboard Tiles is a managed SuiteApp that automatically updates whenever there are enhancements or new features added.

For instructions on installing this SuiteApp, see [Installing the Dashboard Tiles SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1501565893.html).

## Multi-Language Support {#bridgehead_1554706880}

Dashboard Tiles is available in all languages that NetSuite supports. For more information, read [Configuring Multiple Languages](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N247147.html) and [Choosing a Language for Your NetSuite User Interface](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N479109.html).

The only exception to multi-language support are entries for the **Name**, **Prefix**, **Display Value**, and **Suffix** fields. If you're an Administrator or a user with edit permissions to dashboard tile records, you need to enter translations for these fields in all the languages NetSuite supports. For more information about entering dashboard tile translations, see [Entering Dashboard Tile Translations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1552457863.html).
