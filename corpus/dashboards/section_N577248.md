The following table describes content available for display in dashboard portlets, and notes how you can set up content after adding portlets to your dashboard.

Note:

Not all content is available on every page. To see what's available for a specific page, click **Personalize** in the upper right corner or **Personalize Dashboard** in the Settings portlet. The Personalize Dashboard panel lists the content you can add. Some portlets have task links, like a Set Up link, under icons in their upper right corner. For details, see [Setting Up Dashboard Portlet Content](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N581550.html).

For most content, you can display one portlet per dashboard on a standard NetSuite tab. The table also notes content you can display in multiple portlets. Custom NetSuite tabs may also have multiple portlets with other content.

| Content | Description |
| --- | --- |
| Bank Reconciliation Summary | Lists your bank and credit card accounts and displays the key data for matching and reconciliation activities. For each account, you'll see the currency, GL account balance, last reconciled balance and date, bank (imported) statement balance and date, and the number of items that need matching. To view the Bank Register Report for one of the listed accounts, click the hyperlinked account name. If your user role has permission for the Reconcile Account Statement page, this portlet is on your dashboard by default. If you remove it, it's available in the Personalize Dashboard panel. For details on account reconciliation, see [Bank Data Matching and Reconciliation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4842302228.html). |
| Analytics | (Can display up to 10.) Shows one workbook chart, pivot table, or table view per portlet. In the portlet, click **Set Up** to select a workbook visualization from the list. You can also define layout options for the displayed portlets, such as the portlet title and specific options for charts, pivot tables, and table views. For more information, see [Workbooks](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1546871231.html). |
| Calendar | Lists activities for a selected period ordered by date and time, with links to drill down into individual activity records. In the portlet, you can choose a daily, weekly, monthly, or agenda view. You can show your own calendar or a public calendar for another entity in your organization. Click the **Set Up** menu in the portlet to open a popup where you can choose which activities to show in the calendar. You can also expand the portlet to full-screen by clicking the double arrow icon. ![The Double Arrow icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Dashboards/DoubleArrowIcon.png) In full-screen view, the portlet shows more columns and rows in the search results. Note: The Calendar portlet is supported by the Copy to Account feature. If the portlet is included in a published dashboard and the dashboard is copied to another account, the portlet is also copied. For more information, see [Copy to Account](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1544019532.html) and [Copying a Published Dashboard to Another Account](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1554476919.html). For more details, see [Calendar Portlets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4086195407.html). |
| Custom Portlet | (Can display up to six.) Shows results from a portlet SuiteScript, which can be lists, data entry forms, free-form HTML, or links to external data. In the portlet, click **Set Up** to select the source file for the SuiteScript results. Note: The Custom portlet is supported by the Copy to Account feature. If the portlet is included in a published dashboard and the dashboard is copied to another account, the portlet is also copied. You can also use the Copy to Account feature to copy an individual script to another of your accounts. For more information, see [Copy to Account](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1544019532.html) and [Copying a Published Dashboard to Another Account](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1554476919.html). For information about creating scripts, see [SuiteScript 2.1 Portlet Script Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4387799288.html). |
| Custom Search | (Can display up to six on the Home page.) Shows results from a saved search. In the portlet, click **Set Up** and:
-   Select the saved search.
-   Set a custom title.
-   Choose how many results to show.
-   Decide if you want to drill down in the portlet or on a new page.
-   Turn on inline editing for search results (if enabled). See [Using Inline Editing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N495192.html).

Additionally, you can expand the portlet to full-screen view by clicking the double arrow icon ![The Double Arrow icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Dashboards/DoubleArrowIcon.png). The full-screen view of the portlet displays more columns and rows in the search results. Note: When custom search portlets are in the right or left columns, they show only the first 4 results columns. In the center column, they show the first 9 results columns. Custom search portlets also include New, Edit, and View columns with links for each result record. Note: The Custom Search portlet is supported by the Copy to Account feature. If the portlet is included in a published dashboard and the dashboard is copied to another account, the portlet is also copied. You can also use the Copy to Account feature to copy an individual saved search to another of your accounts. For more information, see [Copy to Account](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1544019532.html) and [Copying a Published Dashboard to Another Account](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1554476919.html). For more details, see [Displaying Saved Search Results in Dashboard Portlets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N690632.html). |
| Goals | Shows actions to take on goals and an overview of goals that are in progress. You can see your own goals that are starting soon, due soon, or overdue. You can also check the progress and time elapsed for your top three goals in progress. If you're assigned as a supervisor to at least one employee in NetSuite, you can view goal information for your direct reports. You can see goals that need approval or reflection and those that are overdue. As a manager, you can also check the progress and time elapsed for your direct reports' goals in progress. For more information, see [Viewing Goals in the Goals Portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/rc_1495765765.html#rc_2579620289). Note: To use the Goals portlet, the Performance Management feature must be enabled in your account. For more information, see [Goal Management and Performance Reviews](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_156295348582.html). |
| KPI Meter | (Can display up to three.) Shows up to three graphical meters of key performance indicator (KPI) data. The KPI meter also displays the currency symbol of the data for values represented by currencies. In the portlet, select a KPI from the dropdown list. Click **Set Up** to choose date ranges, highlighting, and comparison options. You also can click menu options to print the KPI meter or download it to a PNG, JPG, PDF, or SVG file. You can only select KPIs that are shown in the dashboard's Key Performance Indicators portlet, plus Actual vs. Forecast, Actual vs. Quota, and Forecast vs. Quota. Note: The KPI Meter portlet is supported by the Copy to Account feature. If the portlet is included in a published dashboard and the dashboard is copied to another account, the portlet is also copied. You can also use the Copy to Account feature to copy an individual saved search to another of your accounts. For more information, see [Copy to Account](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1544019532.html) and [Copying a Published Dashboard to Another Account](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1554476919.html). For more information, see [KPI Meters](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N605338.html). |
| KPI Scorecard | Shows a performance scorecard with comparisons of selected key performance indicator (KPI) data. In the portlet, click **Set Up** to select a KPI Scorecard and layout options. For more information, see [KPI Scorecards](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N610592.html). |
| Key Performance Indicators | Shows key business metrics. These metrics are summary data from reports or saved searches for selected date ranges. They have options to show comparisons between date ranges and to highlight results not meeting defined thresholds. You can set up to eight KPIs as headlines. Each headline appears in bold and is shown in a trend graph. The lower panel lists the rest of the KPIs, and you can collapse or expand the list as needed. In the portlet, click **Refresh** to update all KPIs, or click the Refresh icon ![The Refresh icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Dashboards/RefreshIcon.png) next to a KPI to update it individually. If available, click the Trend Graph icon next to a KPI to see a popup trend graph. Click **Set Up** to select standard KPIs or custom KPIs based on saved searches. You can also set comparison and highlighting options, and choose how popup trend graphs look. The KPI Portlet can go in a wide or narrow column. If it's in a narrow column, the headlines aren't shown in a trend graph because of the compact format. You can see a popup trend graph by clicking the Trend Graph icon next to a KPI in the list, if available. This option is on by default. Note: The Key Performance Indicator (KPI) portlet is supported by the Copy to Account feature. If the portlet is included in a published dashboard and the dashboard is copied to another account, the portlet is also copied. You can also use the Copy to Account feature to copy an individual saved search to another of your accounts. For more information, see [Copy to Account](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1544019532.html) and [Copying a Published Dashboard to Another Account](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1554476919.html). For more information, see [Key Performance Indicators](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N595760.html). |
| Links | Shows links to pages that NetSuite has defined as related. This portlet is available on the Activities, Cases, Customers, Lists, Reports, and Transactions pages. Unlike other portlets, which are column-oriented and sorted top to bottom, the Links portlet is row-oriented and sorted left to right. |
| List | Shows a list of records of a selected type, with links to view and, if you have permission, edit individual records. It shows 9 columns in the center column of the dashboard and 4 columns in the right or left column. In the portlet, click **Set Up** to select a type of record and how many records to show. If the Inline Editing feature is enabled and you have permission, you can edit records directly in the portlet. See [Using Inline Editing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N495192.html). You can also expand the portlet to full-screen by clicking the double arrow icon ![The Double Arrow icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Dashboards/DoubleArrowIcon.png). In full-screen view, the portlet shows more columns and rows in the search results. Note: On some tabs, List portlets are set up to show certain types of records. For example, the Activities page offers Tasks and Phone Calls list portlets. Note: The List portlet is supported by the Copy to Account feature. If the portlet is included in a published dashboard and the dashboard is copied to another account, the portlet is also copied. You can also use the Copy to Account feature to copy an individual list view to another of your accounts. For more information, see [Copy to Account](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1544019532.html) and [Copying a Published Dashboard to Another Account](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1554476919.html). |
| My Login Audit | Shows info about your login activity. Use it to track your last successful or failed login, the IP address for your login activity, the password expire date, and other login information. Note: The date and time in this portlet are based on the Time Zone preference you set on the General subtab at _Home > Set Preferences_. For more information, see [General Personal Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N475661.html). For more information, see [My Login Audit Portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4767195874.html). |
| New Release | Shows a summary of new features from the latest release of NetSuite, with links to more detailed descriptions. |
| Phone Calls | Shows a list of upcoming phone calls, with links to view and, if you have permission, edit individual records. In the portlet, select a view and sorting method, then click **Set Up** to choose how many phone calls to show. If the Inline Editing feature is enabled and you have permission, you can edit records directly in the portlet list. You can also expand the portlet to full-screen by clicking the double arrow icon ![The Double Arrow icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Dashboards/DoubleArrowIcon.png). In full-screen view, the portlet shows more columns and rows in the search results. For more information, see [Phone Calls Portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156414901559.html). |
| Project Tasks | (Available when the Project Management feature is enabled. To learn how to enable Project Management, see [Enabling Project Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4740572949.html).) This portlet is available on the Projects tab. Shows a list of project tasks with links to view and, if you have permission, edit individual records. It shows project tasks assigned to you and other project resources. In the portlet, select a view and sorting method. Click **Set Up** to choose how many tasks to show. For more information, see [Tasks and Project Tasks Portlets on Your Dashboard](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N509646.html). |
| Quick Add | Shows a form where you can quickly add records of a selected type. In the portlet, click **Set Up** if you want to change the type of records to add. For more information, see [Quick Add Portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N588631.html). |
| Quick Search | Shows a form where you can quickly search for records of a selected type, using one filter field and keywords. In the portlet, click **Set Up** to select the type of records to search and click **Save**. Then, enter keywords in the text box and select a field name from the **Search For** dropdown list. Note: The Quick Search portlet is supported by the Copy to Account feature. If the portlet is included in a published dashboard and the dashboard is copied to another account, the portlet is also copied. For more information, see [Copy to Account](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1544019532.html) and [Copying a Published Dashboard to Another Account](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1554476919.html). For more information, see [Quick Search Portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N643459.html). |
| RSS/Atom Feed | (Can display up to two.) Shows RSS or Atom feed URL content, from an external website or HTML document. In the portlet, click **Set Up** to select display options and a URL. NetSuite provides several standard RSS feed URLs, or you can choose Custom and enter another URL. For more information, see [RSS/Atom Feed Portlets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N586341.html). |
| Recent Records | Shows a list of records you've recently created, modified, or viewed. In the portlet, click the record to view it. If you have permission, an Edit link is also available. You can click it to open the record in Edit mode. Important: Recent record links also appear in a menu under the clock icon, left of the Home tab on every NetSuite page. For more information, see [Recent Records Portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N588166.html). |
| Recent Reports | (Available on the Reports tabbed page.) Shows a list of reports you've recently created, modified, or viewed. In the portlet, click the report name to view the individual report. |
| Reminders | Shows important tasks of selected types, usually those that are past due or due soon. In the portlet, click **Set Up** to select reminder types and set how many days in advance reminders should show. Click a reminder to go to the page where you need to take action. For more information, see [Setting Up Reminders](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N581945.html). |
| Report Snapshots | (Can display up to 10.) Each portlet gives a graphical or list summary of a selected standard or custom report's data, with a link to view the full report. In the portlet, select a date range for data and click thumbnails to choose chart types. Click **Set Up** to select the display type and other layout options, including chart themes. You can also print the report snapshot chart, download it as a PNG, JPG, PDF, or SVG file, or view the full report results. You can also expand the portlet to full-screen by clicking the double arrow icon ![The Double Arrow icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Dashboards/DoubleArrowIcon.png). Report snapshot list text is cut off at 25 characters when the portlet is in the left or right column. To avoid this, place the portlet in the middle column. Report snapshot list amounts are rounded to the nearest whole number and don't show decimal places. For more information, see [Report Snapshots](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N625749.html). |
| Saved Searches | Shows the top ten saved searches in your account, including run time and how many users have accessed the search during a set period. In the portlet, you can sort the searches by most requested, most timeouts, most users, or highest run time. For more information, see [Using the Saved Searches Portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1508294837.html). |
| Scheduler | (Available on the Activities page.) Shows an interface where you can view others' schedules and add activities. Note: This portlet cannot be removed or modified. In the portlet, you can select the date and use the View Group dropdown menu to select others' schedules. Click the buttons to create new events, add invitees or resources. |
| Search Form | Shows a form to search for records of a selected type. Filter fields are based on system defaults or a custom search form you've set as preferred. In the portlet, click **Set Up** to select the search form to use. Click **Full Search** to go to the default search page for the selected record type. Click **Edit** to open the definitions page for the search form and make changes. See [Adding Personalized Search Forms to NetSuite Pages](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N666481.html). Note: The Search Form portlet is supported by the Copy to Account feature. If the portlet is included in a published dashboard and the dashboard is copied to another account, the portlet is also copied. You can also use the Copy to Account feature to copy an individual saved search to another of your accounts. For more information, see [Copy to Account](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1544019532.html) and [Copying a Published Dashboard to Another Account](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1554476919.html). |
| Settings | Shows links to user-level setup tasks. Important: The contents of this portlet are system-defined. This portlet cannot be removed or modified. For more information, see [Settings Portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4767335916.html). |
| Shortcuts | Shows links to selected pages, so you can go to frequently used pages quickly. In the portlet, click **Set Up** to reorder shortcut links or click **New Shortcut** to add one if you know the page's URL. If you don't know the URL, go to the upper right corner of that page, then from the More list, select Add to Shortcuts. For more information, see [Shortcuts Portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N587785.html). |
| SMT Links | The Site Management Tools Links portlet shows links to all available domains in your administrator role. In the portlet, use the dropdown menu to choose from your available websites. After you've chosen the website, you can choose to Preview or Edit any of the available domains. For more information, see [SMT Links Portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156201804002.html). |
| Tasks | Shows a list of upcoming CRM tasks assigned to you, with links to view and, if you have permission, edit individual records. In the portlet, select a view and a sorting method, and click **Set Up** to define the number of tasks shown. Additionally, you can expand the portlet to full-screen view by clicking the double arrow icon ![The Double Arrow icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Dashboards/DoubleArrowIcon.png). The full-screen view of the portlet displays more columns and rows in the search results. For more information, see [Tasks and Project Tasks Portlets on Your Dashboard](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N509646.html). |
| Trend Graphs | (Can display up to five.) Shows up to three Key Performance Indicators (KPIs) in a single chart with a time-based X axis. In the portlet, click thumbnails to choose among different chart types. You can enter a title for your portlet to quickly identify it. You also can change the graph's X axis scale by selecting different time intervals from the dropdown list. Click **Set Up** to select the KPIs to be graphed and layout options, including chart themes. You also can click menu options to print the trend graph chart or download it to a PNG, JPG, PDF, or SVG file. You can also expand the portlet to full-screen by clicking the double arrow icon ![The Double Arrow icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Dashboards/DoubleArrowIcon.png). Note: The Trend Graph portlet is supported by the Copy to Account feature. If the portlet is included in a published dashboard and the dashboard is copied to another account, the portlet is also copied. For more information, see [Copy to Account](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1544019532.html) and [Copying a Published Dashboard to Another Account](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1554476919.html). For more information, see [Trend Graphs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N605811.html). |

Note:

You can set chart theme preferences that define the default look and feel for dashboard charts, including report snapshots and trend graphs. The Chart Theme preference sets the shape and colors for chart data. The Chart Background preference sets the display behind the data. See [Personal Preferences for Appearance](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N479574.html).
