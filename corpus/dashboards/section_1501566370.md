When you log in to NetSuite, the portlet displays the default title and fonts sizes. You can modify the title and font sizes of the Dashboard Tiles portlet to fit your preferences.

Note:

The tile preference always takes precedence over the portlet preference. For information about setting dashboard tile preferences, see [Modifying the Appearance of a Dashboard Tile](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1501566272.html).

#### To modify the title and font sizes of the Dashboard Tiles portlet:

1.  In the Tiles portlet, click the **Menu** icon ![Menu icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Dashboards/MenuIcon.png) and select **Edit**.
    
2.  In the Custom Content dialog, fill in the following fields:
    
    Note:
    
    If you're using the Redwood theme and you go to the Portlet settings, entering 0 in the **KPI Font** or **Label Font** fields removes the corresponding text from the tiles. Entering any other number does not affect the text display on both fields.
    
    Additionally, the **Blink Delay field** isn't supported in Redwood Theme right now.
    
    -   **Title** - Enter a name for the portlet. If you leave this field blank, the default name Tiles is displayed.
        
    -   **KPI Font Size (PT)** - Enter a font size for the tile KPI from 0 to 18 points. If you leave this field blank, the default KPI font size is 13.
        
    -   **Label Font Size (PT)** - Enter a font size for the tile label from 0 to 16 points.
        
        If you leave this field blank, the default label font size is 10. If you enter 0, the tile label is removed.
        
    -   **Blink Delay (MS)** - Enter a value in milliseconds from 300 to 3000. If you don't enter any value, the default 530 milliseconds is used.
        
        This field only sets the blink delay for reminder and scorecard tiles.
