The Shortcuts portlet lets you quickly access your most-used records, transactions, lists, and reports.

![Shortcut Portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Dashboards/ShortcutPortlet.png)

For instructions on how to add the Shortcuts portlet to a page, see [Adding a Portlet to a Dashboard](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N580906.html).

Important:

If you have added the Shortcuts portlet to more than one page, the portlet always maintains the same links on every page. Any changes you make to the Shortcuts portlet displayed on one page are applied automatically to the Shortcuts portlet displayed on any other page and to the menu options listed on the shortcuts menu.

#### To add a shortcut from the Shortcuts portlet: {#procedure_N587908}

1.  On the Shortcuts portlet, click **New Shortcut** on the portlet menu.
    
2.  Enter a name for the shortcut link.
    
3.  Enter the **URL** of the page.
    
4.  If you want the linked page to open in a new window, check the **Open in New Window** box.
    
5.  Click **Save**.
    

## Shortcuts Menu {#subsect_0417035113}

These same links also appear as options on the shortcuts menu, the star icon ![Star icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Dashboards/StarIcon.png), on the navigation menu.

![Shortcuts menu](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Dashboards/ShortcutsMenu.png)

You can add, remove, and reorder shortcuts in the portlet or menu, and you can set shortcuts to open in new windows. Any changes you make show up in both the Shortcuts portlet and menu.

### Adding Shortcut Links {#bridgehead_N587858}

You can add a link by going to the page you want to bookmark and selecting **Add to Shortcuts** from the **More** list. Or, go to the Shortcuts portlet and click **New Shortcut**.

#### To add a shortcut from the page where you want the shortcut to go: {#procedure_N587870}

1.  Click the star icon ![Star icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Dashboards/StarIcon.png) on the navigation menu and select **Add to Shortcuts**.
    
    ![Add To Shortcuts option in the Shortcuts menu.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Dashboards/Add_To_Shortcuts.png)
2.  Edit the name for the shortcut link. By default it is the name of the page.
    
3.  If you want the shortcut to open in a new window, check the **Open in New Window** box.
    
4.  Click **Save**.
    

### Setting Up Shortcut Links {#bridgehead_N587953}

In the Set Up Shortcuts popup window, you can remove, reorder, rename shortcuts, and decide if they open in a new window.

![Set Up Shortcuts popup window.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Dashboards/SetUpShortcutsWindow.png)

#### To remove a shortcut: {#procedure_N587965}

1.  Click **Set Up** in the Shortcuts portlet menu or the **Set Up Shortcuts** option on the shortcuts menu to open the Set Up Shortcuts popup window.
    
2.  Clear the **Enable** box next to each shortcut that you want to remove.
    
    Note:
    
    Shortcuts that were created when a dashboard was published for you appear with asterisks. The publisher may have restricted these shortcuts so that you cannot remove them.
    
3.  Click **Save**.
    

#### To reorder shortcut links: {#procedure_N587998}

1.  Click **Set Up** in the Shortcuts portlet menu or the **Set Up Shortcuts** option on the shortcuts menu to open the Set Up Shortcuts popup window.
    
2.  Click the shortcut row to select it. The row will be highlighted and have a drag gripper.
    
    ![A drag gripper.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Dashboards/SelectShortcut.png)
3.  Drag the shortcut row where you want it or use the **Move to Top** or **Move to Bottom** buttons.
    
4.  Click **Save**.
    

#### To indicate that a shortcut's linked page should open in a new window: {#procedure_N588035}

1.  Click **Set Up** in the Shortcuts portlet menu or the **Set Up Shortcuts** option on the shortcuts menu to open the Set Up Shortcuts popup window.
    
2.  Check the **Open in New Window** box next to the shortcut name, and click **Save**.
    

#### To rename a shortcut link: {#procedure_N588058}

1.  Click **Set Up** in the Shortcuts portlet menu or the **Set Up Shortcuts** option on the shortcuts menu to open the Set Up Shortcuts popup window.
    
2.  Change the name in the **Label** field, and click **Save**.
    

Note:

The Shortcuts portlet might show duplicate links if your administrator published a dashboard with links that match yours. To fix that, remove any custom links you've added.
