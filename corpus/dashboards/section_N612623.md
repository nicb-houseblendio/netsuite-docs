To create a new KPI scorecard, go to _Customization > Centers and Tabs > KPI Scorecards > New_. For more information, see [Creating a KPI Scorecard](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N612318.html). Then you can enter basic scorecard information at the top of the page.

#### To enter basic KPI scorecard information: {#procedure_N612650}

1.  Enter a **Name** for the KPI scorecard. This name will appear as the title of portlets displaying this scorecard.
    
    By default, your name appears in the **Owner** dropdown list. If you are an administrator, you can define a different owner by selecting a different name.
    
2.  If you want the KPI data to be calculated according to accounting periods rather then date ranges, check the **Use Periods** box.
    
    When **Use Periods** is selected:
    
    -   The name of the **Date Ranges** subtab changes to **Periods**.
        
    -   Only saved searches with a **Period** filter defined under **Available Filters** are available for use as custom KPIs in this scorecard.
        
    -   You may encounter issues with KPI scorecard data if you haven't set up accounting periods, or if you haven't set the **Report by Period** preference to **All Reports** on the **Analytics** subtab of the Set Preferences page.
        
3.  (Optional) Enter a **Description** for the scorecard.
