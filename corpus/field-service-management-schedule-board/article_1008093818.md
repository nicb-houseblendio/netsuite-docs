Keyboard shortcuts let you quickly perform tasks on the Scheduler using a key or a combination of keys. The table below lists Scheduler icons and keyboard shortcuts.

| Icon | Action | Description |
| --- | --- | --- |
| ![Scheduler standard cursor](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/FieldServiceManagement/SchedulerUserGuide/scheduler_hotkey_cursor.png) | Cursor | The standard cursor for the Scheduler view. No changes will occur when this cursor is displayed. |
| ![Scheduler move task icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/FieldServiceManagement/SchedulerUserGuide/scheduler_hotkey_move.png) | Move Task | Reassign or reschedule a task by placing the cursor over it and dragging it to the desired employee or day. The start and end times of the task will not change. |
| ![Scheduler change start and end times keyboard shortcut icons](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/FieldServiceManagement/SchedulerUserGuide/scheduler_hotkey_change.png) | Change Start and End Time | Press Alt (Windows) or Option (Mac) and use the cursor to change start and end times on tasks. Place the cursor on the start or end time of the task to change the time. Alternatively, place the cursor in the middle of the task to move the whole appointment to a different time. |
| ![Scheduler zoom and move map icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/FieldServiceManagement/SchedulerUserGuide/scheduler_hotkey_zoom.png) | Zoom and Move the Map | Press and hold Spacebar and use your mouse scroll to zoom in and out of the map. |
| ![Scheduler assign team member icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/FieldServiceManagement/SchedulerUserGuide/scheduler_hotkey_assign.png) | Assign and Remove Team Members | Press Ctrl (Windows) or Command (Mac) and use the cursor to assign the main task to different employees and include them as team members. To remove a team member, drag their task back onto the main task. |
| ![Scheduler save icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/FieldServiceManagement/SchedulerUserGuide/scheduler_hotkey_save.png) | Apply or Cancel Scheduler Changes | The Scheduler lets users to move tasks and visualize alternate scenarios for resource scheduling without saving changes. You can go back to the original view or save your changes. The Save icon shows how many records have changes. Click the icon to save changes. Note: After your changes are saved, you can no longer revert them. |
| ![Scheduler cancel icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/FieldServiceManagement/SchedulerUserGuide/scheduler_hotkey_cancel.png) | The Cancel icon shows on hover. It lets you cancel all changes. The view also refreshes when you cancel. |
