Tasks are NetSuite tasks, project tasks, non-working days, leave requests, or any other record that takes time and can be assigned to a resource. Tasks appear as rectangular elements with a label and status icon. Tasks may be single day or multi-day, have a primary assignee and secondary assignees.

## Color Coding {#bridgehead_42153413180}

Tasks are color-coded to make them easier to browse. By default, they're color-coded based on their priority. Completed tasks are gray but still show their priority in the border.

![color coding in tasks showing priority and status](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/FieldServiceManagement/SchedulerUserGuide/tasks_color_coding_icon.png)

## Icons {#bridgehead_28153439931}

Tasks will show a status icon in the top right corner if they are on today or have activity on them.

## Clock {#bridgehead_4153454152}

![clock icon in tasks](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/FieldServiceManagement/SchedulerUserGuide/tasks_icons_clock_icon.png)

Status is **Not Started**.

## Vehicle {#bridgehead_21153514682}

![vechicle icon in tasks](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/FieldServiceManagement/SchedulerUserGuide/tasks_icons_vehicle_icon.png)

Status is **In Progress** but the primary assignee hasn't been detected on site.

## Person {#bridgehead_72153537163}

![person icon in tasks](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/FieldServiceManagement/SchedulerUserGuide/tasks_icons_person_icon.png)

The task status is **In Progress** and the primary assignee has been detached on site.

## Check {#bridgehead_48153604341}

![check icon in tasks](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/FieldServiceManagement/SchedulerUserGuide/tasks_icons_check_icon.png)

Status is **Completed**.

## Alert {#bridgehead_61153624525}

![alert icon in tasks](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/FieldServiceManagement/SchedulerUserGuide/tasks_icons_alert_icon.png)

Status is **Not Started**, and the start time has passed.

## Error {#bridgehead_24153644857}

![error icon in tasks](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/FieldServiceManagement/SchedulerUserGuide/tasks_icons_error_icon.png)

Changes to this task didn't save successfully to NetSuite.

## Context Menu {#bridgehead_37153720253}

**Right clicking** or **Ctrl + Left clicking** a task opens a context menu. Click the customer, project, case, task, or asset name to go to the record in NetSuite.

## Marker {#bridgehead_28153739881}

![marker icon in task context menu](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/FieldServiceManagement/SchedulerUserGuide/tasks_context_menu_marker_icon.png)

Centers the map on the task.

## Download {#bridgehead_60153800036}

![download icon in task context menu](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/FieldServiceManagement/SchedulerUserGuide/tasks_context_menu_download_icon.png)

Downloads the latest service report for that task.

## Copy {#bridgehead_81153821883}

![copy icon in task context menu](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/FieldServiceManagement/SchedulerUserGuide/tasks_context_menu_copy_icon.png)

Opens a new record form in NetSuite that's a copy of this task.

## Cancel {#bridgehead_19153843795}

![cancel icon in task context menu](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/FieldServiceManagement/SchedulerUserGuide/tasks_context_menu_cancel_icon.png)

Resets changes to this task.

## Save {#bridgehead_5153903332}

![save icon in task context menu](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/FieldServiceManagement/SchedulerUserGuide/tasks_context_menu_save_icon.png)

Saves changes to this task.

## Time Zone {#bridgehead_71154017116}

Tasks display a time zone with their date and time if they're not in the same time zone as your current view. The context menu always displays the task's time zone.
