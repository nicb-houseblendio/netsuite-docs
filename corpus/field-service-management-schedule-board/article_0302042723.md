The Field Service Management (FSM) Schedule Board combines resources and tasks with navigation and filtering tools so you can find the right work items and focus the board on what you need to schedule.

## Resources and Tasks {#subsect_0302043458}

In the Schedule Board, resources are the people (or entities) you assign tasks to. You can select a resource to open a context menu with actions such as:

-   **Marker** - Center map on the resource.
    
-   **Mobile** - Open a mobile emulator, if applicable and permitted.
    
-   **Letter** - Draft an email.
    
-   **Phone** - Start a call with the default VoIP application.
    

Tasks are NetSuite CRM and Project tasks. In FSM Schedule Board, tasks are:

-   Color-coded (by default, based on task priority) to make them easier to scan.
    
-   Displayed with status icons to represent statuses such as not started, in progress, completed, overdue, or error saving.
    

The board can also display non-working days and other assignable time blocks.

## Navigation and Filtering {#subsect_0302043655}

As you browse, FSM Schedule Board loads tasks for any new resources and dates you bring into view. It refreshes the visible data every 60 seconds to keep information up to date.

Extension panels let you filter resources and tasks shown on the board and map by selecting property values. Filter capabilities include:

-   Adding filters using dropdowns.
    
-   Removing individual values or clearing all filters.
    
-   Choosing all selected values or any selected value.
    

The panel header shows a filter icon when filters are available, and the unassigned tasks panel shows a count for the current date range. You can use separate panels to filter assigned tasks, resources, and unassigned tasks, and use fuzzy search to narrow the lists.
