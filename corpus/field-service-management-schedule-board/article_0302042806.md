Settings, scheduling, saving, and shortcuts in the Field Service Management (FSM) Schedule Board help you:

-   Personalize your view
    
-   Assign and update tasks
    
-   Use quick actions to manage changes in NetSuite
    

## Schedule Board Settings {#subsect_0302044003}

You can open Schedule Board settings from the settings icon in the board's header. Your preferences are saved for next time. Common settings include:

-   **Hours Shown** - Default is 9:00 am-5:00 pm. You can adjust the From/To sliders or select **Show 24 hrs**.
    
-   **Time Zone** - Select the time zone in which you want to view the board. On first launch, the default is your NetSuite time zone preference. Later launches will use your preferred setting.
    
    Note:
    
    When editing a task, NetSuite uses the time zone of your current view. To edit a task in a different time zone, change the Schedule Board time zone first to save the task in the correct time zone.
    
-   **View options**\- Show and hide scheduler elements using checkboxes.
    
-   **Resizing panels** - Resize the map, control panel, and resource column by dragging their borders.
    

## Scheduling and Saving Changes in the Schedule Board {#subsect_0302044218}

You can schedule or assign resources by dragging and dropping tasks on the board and extension panels, then saving your changes to NetSuite. You can also assign or unassign tasks by dragging them between the board, the assigned tasks panel, and the unassigned tasks panel.

Important:

You can't edit tasks after they've started.

You can select one or more tasks by clicking them or dragging a selection box. Hold the Shift key (PC and Mac) to toggle selection. You can also select linked tasks automatically (by default, tasks on the same case). Schedule tasks independently by holding Shift and selecting each task.

Tasks with unsaved changes show a red border, and the Sync menu shows how many unsaved tasks you have. You can use the following commands:

-   **Save** - Save all unsaved changes to NetSuite.
    
-   **Cancel** - Clear all unsaved changes.
    

You can also save or cancel from a single task's context menu.

If saving fails, the task shows an Error status icon and a red border. You can try saving again or if the problem persists, contact NetSuite Support.

## Schedule Board Task Context Menu Shortcuts {#subsect_0302044418}

Right-click (or Ctrl + left-click) a task to open its context menu. From there, you can:

-   Go to related records in NetSuite, for example, the customer, project, case, task, and asset records.
    
-   Use the marker to center the map on the task or resource.
    
-   Download the latest service report.
    
-   Create a copy of the task in NetSuite.
    
-   Save or cancel changes.
    

Tasks also display time zones when they're different from your current view. The task context menu always displays the task time zone.
