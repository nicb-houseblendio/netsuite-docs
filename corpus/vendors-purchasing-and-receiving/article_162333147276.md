When you enable the Vendor Prepayments feature, the system creates two new permissions:

-   **Vendor Prepayment** - Grants the user or role permissions to work with vendor prepayment transactions.
    
-   **Vendor Prepayment Application** - Grants the user or role permissions to work with the vendor prepayments applications.
    

The following table lists the required permission levels for working with vendor prepayment transactions:

| Permission Level | Permissions |
| --- | --- |
| VIEW | View only |
| CREATE | 
-   View
-   Enter new transactions

 |
| EDIT | 

-   View
-   Enter new transactions
-   Edit existing transactions

 |
| FULL | 

-   View
-   Enter new transactions
-   Edit existing transactions
-   Delete transactions

 |

To access and work with vendor prepayments, the administrator must assign these permissions to roles. By default, the A/P Clerk role has the edit permission level for vendor prepayment transactions.

Note:

If you only apply vendor prepayments to your bills using Auto-Apply, you do not need permissions to work with vendor prepayments. With Auto-Apply, NetSuite works in the background using the system account credentials for the vendor prepayment application. For more information about Auto-Apply, see [Applying Vendor Prepayments With Auto-Apply](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157372109804.html).

In addition to permissions, NetSuite restrictions can limit your access to certain records. These restrictions may include subsidiary, department, class, or location restrictions. Consider the following example. Lisa, who works in Purchasing, belongs to a role with no restrictions. She creates different vendor prepayment transactions in different locations. Later, the administrator updates Lisa's role to include the location restriction own and subordinates only. After this change, Lisa can access prepayment transactions on her location and subordinates locations only. Lisa can"t access prepayment transactions created for other locations, even when these transactions were created by herself. For more information about restrictions in NetSuite, see [Permissions and Restrictions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3781107123.html).

#### To configure permissions for vendor prepayments: {#procedure_156396805388}

1.  Go to _Setup > User / Roles > User Management > Manage Roles_.
    
2.  Locate the role you want to modify, and click **Edit** or **Customize**.
    
3.  On the **Permissions** subtab, click **Transactions**.
    
4.  In the **Permission** list, select the corresponding permission:
    
    -   **Vendor Prepayment** - To authorize the user or role to work with vendor prepayment transactions.
        
    -   Select **Vendor Prepayment Application** - To authorize the user or role to work with vendor prepayment applications.
        
5.  In the **Level** list, select the required access level.
    
6.  Click **Add** to add the new permission, or click **OK** to modify the existing permission.
    
7.  Click **Save**.
