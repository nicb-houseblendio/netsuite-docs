After you enable Centralized Purchasing and Billingfeature, line items on the Items subtab of the purchase order contain Target Subsidiary and Target Location columns. The target subsidiary and target location values can be different from the Subsidiary and Location fields. Each item in a single purchase order can go to a different subsidiary and location. When you set the Target Subsidiary and Target Location fields on a line item, you override the Subsidiary and Location fields for that line item. You can configure available subsidiaries and locations on individual item records. For more information, see [Creating Item Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2166469.html).
