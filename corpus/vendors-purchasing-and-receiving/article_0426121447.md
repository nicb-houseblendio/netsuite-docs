The SuiteProcurement Preferences page enables you to set company-level preferences for working with the SuiteApp. These preferences include:

-   **Company Preferences**\- This preference enables you to automatically generate a purchase request or a requisition after purchasing items from a trading partner's store. To set these preferences, go to Setup > SuiteProcurement > Preferences.
    
    If you want to change the setting for a particular trading partner, you can change the preference on the **Accounting** subtab. The settings at the trading partner level take precedence over company-level settings.
    
    To set the preference at the trading partner level, see [Mapping Trading Partners with NetSuite Vendors](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0928011028.html).
    
-   **Sync Trading Partners**\- This preference enables you to sync the trading partners registered on OBN for a selected subsidiary. For more information, see [Syncing Trading Partners for a Subsidiary](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0928011003.html).
    
-   **Account Mapping**\- This preference lets you map trading partners with NetSuite vendors. For more information, see [Mapping Trading Partners with NetSuite Vendors](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0928011028.html).
    
-   **Item Category Mapping**\- This preference lets you map NetSuite vendor item categories with trading partner item categories. For more information, see [Mapping Item Categories](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1002124423.html).
    

Set the preferences in the order specified using the Administrator role only.

1.  [Syncing Trading Partners for a Subsidiary](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0928011003.html)
    
2.  [Mapping Trading Partners with NetSuite Vendors](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0928011028.html)
    
3.  [Mapping Item Categories](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1002124423.html)
    

You can also set SuiteProcurement preferences at the vendor level. For more information, see [Setting Up SuiteProcurement Preferences at Vendor Level](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0928011918.html).
