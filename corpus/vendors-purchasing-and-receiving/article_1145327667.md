Any user with edit permission can cancel an open payment run. Canceling the payment run keeps the payment run record and releases the selected payables.

#### To cancel a payment run:

1.  Open the payment run you want to cancel at Transactions > Payables > Enter Payment Run > List.
    
2.  Click the **Cancel Run** button.
    

An open payment run can also be deleted unless generated vendor payments still exist. To delete those payment runs, first delete the associated vendor payments, if possible.

#### To delete a payment run:

1.  Ensure all associated vendor payments, if any, have been deleted.
    
2.  Open the payment run you want to delete at Transactions > Payables > Enter Payment Run > List.
    
3.  Click the **Edit** button.
    
4.  Click **Actions**, then **Delete**.
