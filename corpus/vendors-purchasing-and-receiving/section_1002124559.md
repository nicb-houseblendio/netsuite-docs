The trading partner item categories are linked to non-inventory item categories in NetSuite. This setup enables you to associate specific expense accounts (GL accounts) with each item. On an item record, you can select the expense account on the **Accounting** subtab, which facilitates automated GL coding for each item purchased.

Note:

You must set the purchase price to **zero** for non-inventory items used for SuiteProcurement purchases. This is required to display the rate and amount correctly on an order requisition.

The following image illustrates how to assign an expense account to a non-inventory item for purchase.

![A screenshot of a non-inventory item for purchase](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/VendorsPurchasingReceiving/PurchasingReceiving/Non-inventoryItemforPurchase.png)

You can create as many non-inventory items as required to accommodate the level of detail needed when assigning categories to GL expenses accounts. Examples include the following:

-   Office Supplies
    
-   IT Supplies
    
-   Janitorial Supplies
    
-   MRO Supplies
    

To include any non-inventory item for SuiteProcurement purchases, check the following boxes on the item record.

-   **Include in NetSuite Category for SuiteProcurement Purchases**
    
-   **Can be Fulfilled/Received**
    
-   **Generate Accruals**
    

When you check these boxes for an item, the **NetSuite Category** field lists the non-inventory item in the list.

#### To perform item category mapping:

1.  Go to Setup > SuiteProcurement > Preferences.
    
2.  In the Manage Trading Partners section, click the **Item Category** subtab.
    
3.  In the **Trading Partner Category** field, select a category.
    
4.  In the **NetSuite Category** field, select a category. If you leave this field blank, **Default SuiteProcurement Category** is selected by default.
    
5.  Repeat Step 3 and Step 4 for each trading partner category and NetSuite category combination for each of the trading partners.
    
6.  To save the mapping, click **Save**.
    

When you update more than 100 category mappings, it isn't saved immediately. A Map/Reduce script runs to process the category mappings update.

By default, the **Trading Partner Category** field lists the L1 categories, which are high level categories associated with a trading partner. UNSPSC L1 categories have been chosen because they provide the best balance between mapping maintenance and expense level detail. However, if you want to add an additional trading partner category for a more granular level of mapping (expense) detail, use the Category CSV file upload functionality. For more information, see [Importing Item Categories through CSV](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0928011924.html).
