Before you install the Transaction Email Capture SuiteApp, make sure that AP Automation is provisioned in your NetSuite account. For more information, see [Prerequisites for Bill Capture](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1021104845.html).

You also need to enable additional features in your NetSuite account before you can use the SuiteApp.

| Feature | Enable Features Subtab |
| --- | --- |
| A/P (Accounts Payable) | Accounting |
| Bill Capture | Accounting |
| Online Forms | CRM |
| Custom Records | SuiteCloud |
| Client SuiteScript | SuiteCloud |
| Server SuiteScript | SuiteCloud |

To enable features, go to _Setup > Company > Enable Features_. For more information, see [Enabling Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N232138.html).

Note:

To avoid installation issues, make sure the employee record with internal ID -5 is active before you install the SuiteApp. For more information about internal ID, see [Finding the Internal ID of Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162634223275.html).
