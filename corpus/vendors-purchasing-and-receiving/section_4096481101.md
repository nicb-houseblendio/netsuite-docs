You can update the details of a state, its actions, and assign specific settings. Within each state, you can change the order by which the validations or exception criteria are executed.

For specific instructions on using the tolerance limits and disabling exception criteria, see [Setting Tolerance and Difference Limits](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4168980481.html) and [Disabling Exception Criteria](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4096490752.html).

To view and edit a state, select the state from the workspace. On the **State** subtab, click the pencil icon. You can also double-click the state on the workflow diagram to open the Workflow State page.

## Editing a State {#bridgehead_4096483152}

On the Workflow State page, you can change the state name and description. For more information about workflow states, see [Workflow States](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4071953710.html).

On the **Actions** subtab, click the Edit link for the action or group to update its details, add a condition, and set the schedule. You can also create a new custom action or group by clicking **New Action** or **New Group**. For more information about actions, see [Workflow Actions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4071954161.html).

For more information about action groups, see [Using Action Groups](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4103059250.html).

On the **Transitions** subtab, click the Edit link for the transition to update its details and add a condition. By changing the transition settings, you can reorder the flow of processing. You can also add a new transition to the state. For more information about transitions, see [Workflow Transitions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4071954244.html).

## Changing the Exception Message {#bridgehead_4096487984}

Exception or validation messages displayed on the vendor bill record are set in the workflow state where its action is executed.

#### To change the exception message:

1.  On the Workflow State page, click the **Edit** link for the NAW Create Exception Record WS action.
    
    The Parameters section shows the message for \[SS\] VB-PO: Vendor Qty Difference: Discrepancy between Quantity on Bill and PO exceeds the Vendor Quantity difference limit.
    
2.  On the Workflow Action page, in the Parameters section, enter the new message in the **Value** column for the **exception** field.
    
3.  Click **Save**.
    

## Reordering Actions or Groups {#bridgehead_4096488665}

On the Workflow State page, on the **Actions** subtab, click the row of the action to be moved. Drag and drop it before or after another action. You can also click the Edit link for the action, and use the **Insert Before** field on the Workflow Action page. For more information, see [Reordering Actions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4103058104.html).

To reorder action groups within a state, click the group to be moved. Drag and drop it to the beginning or end of another group. You can also use the **Insert Before** field on the Workflow Action Group page. When you save the changes, the group numbering is automatically updated.
