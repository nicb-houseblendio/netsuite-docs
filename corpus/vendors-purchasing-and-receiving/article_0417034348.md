This topic provides several considerations for the Bill Capture feature.

-   Bill Capture leverages Oracle Cloud Infrastructure (OCI) Document Understanding Custom Generative Model to intelligently extract key values from your vendor bills.
    
-   Bill Capture is available only in the United States.
    
-   The following file types and sizes are supported:
    
    -   PDF, JPEG, PNG
        
    -   PDF file format - 30 page limit
        
    -   JPEG, PNG file formats - 1 page limit
        
    -   One bill per JPEG, PNG, PDF file (multiple bills are not supported)
        
    -   Uploaded files can't exceed 8 MB
        
    -   Upload a maximum of 50 files at a time for best performance
        
    -   For email - 20 attached files maximum, each file can't exceed 8 MB, and overall email size can't exceed 10 MB
        
    -   Email notification replies are not sent if the vendor bill contains a virus or if there is no bill file attached to the email
        
-   Serial/Lot numbered items, Bins, and Inventory Status are not supported on standalone bills (those without an associated purchase order)
    
-   Mandatory line level custom fields are not supported on standalone bills (those without an associated purchase order)
    
-   Matrix subitems are available for selection on the Review Scanned Bill page. Parent matrix items are not available. After creating a bill with Bill Capture, the generated vendor bill will show the parent matrix item and subitems, if the custom fields are set up correctly. For more information about matrix items, see [Matrix Items](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2227654.html).
    
-   Customization is not supported on the Review Scanned Bill page
    

The following date formats are supported in uploaded files:

-   DD/MM/YYYY
    
-   MM/DD/YYYY
    
-   YYYY/MM/DD
    
-   DD/MONTH/YYYY
    
-   DD/MONTH (assuming current year)
    
-   MONTH/DD/YYYY
    
-   MONTH/YYYY (assuming today's day)
    

The following are additional details regarding date formats:

-   The date format used in the date fields of the review page are based on your account's date preferences (Setup > Company > General Preferences > Date Format)
    
-   Dividers can be any symbol that is not a number or a letter (for example, / or - or space)
    
-   Month can be MONTH or MON (for example, September or Sep, but not Sept)
    
-   Month can be MM or M (for example, 06 or 6)
    
-   Day can be DD or D (for example, 04 or 4)
    
-   Year can be YYYY or YY (for example, 2023 or 23)
