After you enable the Centralized Purchasing and Billing feature, you can create a vendor return authorization centrally. Then, you can ship the return from specific subsidiaries and locations, and then credit the return to the originating subsidiary.

To return purchase orders centrally, you first have to enable the Vendor Return Authorizations feature. For more information, see [Vendor Return Authorization Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2386202.html).

The Centralized Purchasing and Billing feature enables the automation of intercompany cross charges between the credit subsidiary and the target subsidiary. You can set up the automation to be performed upon accounting period closure. For more information, see [Intercompany Cross Charges](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1519995046.html).
