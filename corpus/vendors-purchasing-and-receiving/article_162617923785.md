Install the Purchase Order Approval Workflow SuiteApp with the following details:

-   Bundle Name: **Purchase Order Approval Workflow**
    
-   Bundle ID: **239645**
    
-   Location: Production
    
-   Availability: Public
    

The PO Approval Workflow SuiteApp is a managed bundle and is automatically updated whenever there are updates. These issue fixes and enhancements are available after the SuiteApp is updated in your account.

For more information about installing SuiteApps, see [Installing a Bundle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3395142.html).
