The Transaction Email Capture SuiteApp only works with the Bill Capture feature to enable employees and vendors to send vendor bills directly through email.

Using the Bill Capture feature, the system captures the charges and line items from the vendor bill file to create a vendor bill in NetSuite. After you create a bill with Bill Capture, you can view the uploaded file side by side with the created bill.

For more information about how the Bill Capture feature works, see [Bill Capture](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_164726334180.html).
