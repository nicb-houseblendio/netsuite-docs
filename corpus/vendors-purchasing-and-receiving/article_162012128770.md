To request quotes, enable both the Purchase Contracts feature and the Request for Quotes feature.

#### To enable the Request for Quote feature: {#procedure_4285410924}

1.  Go to _Setup > Company > Setup Tasks > Enable Features_.
    
2.  On the **Transactions** subtab, check the **Request for Quote** box.
    
3.  Verify that the **Purchase Contracts** box is checked.
    
4.  Click **Save**.
    

After the feature is enabled, you can request quotes from vendors. For more information, see [Entering a Request For Quote](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4212822856.html).
