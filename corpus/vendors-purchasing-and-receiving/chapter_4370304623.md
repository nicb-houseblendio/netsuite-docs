The Procurement Dashboard displays consolidated procurement-related information from transactions and records on one page. Key information is available in the form of reports, reminders, tables, and other monitoring and management tools. From the dashboard, you can keep track of outstanding transactions, vendor performance, and expenditure across segments within the organization. Based on your specific business requirements, you can customize the dashboard content.

## Availability {#bridgehead_4370307950}

The Procurement Dashboard is available in the Advanced Procurement SuiteApp that is included in the Advanced Procurement Module. To purchase, contact your NetSuite sales representative.

## Procurement Dashboard Limitations {#bridgehead_4370308524}

Be aware of the following limitations of the Procurement Dashboard:

-   The Procurement Dashboard is only set up in the Classic, Accounting, and Shipping centers. It has to be set up manually for other centers. For more information, see [Roles and Permissions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4370304909.html#bridgehead_4370321672). For instructions on setting up and publishing the dashboard, see [Publishing the Procurement Dashboard](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4380612316.html#bridgehead_4370338243).
    
-   For portlets that use currency data, the saved search follows the currency of the transaction.
    
-   The original layout of the Procurement Dashboard is not automatically set up when you uninstall and reinstall the Advanced Procurement SuiteApp. In case you need to reinstall the SuiteApp, you have to set up the dashboard components manually. For more information, see [Setting Up the Procurement Dashboard](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4380612316.html).
    
-   For the spend reports, only values for the class, department, location, and vendor on the main line are used to generate the report. Values in these fields on the line items are not considered.
    

For more information, see [Adding portlet content](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4373525526.html#bridgehead_4373528873).
