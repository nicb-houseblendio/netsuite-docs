If you've received all items in a purchase request, you can generate an item receipt.

The SuiteProcurement SuiteApp includes the **Generate Item Receipt** button on a SuiteProcurement purchase request. Users with the employee center or administrator role can use this button to generate an item receipt for the partial or complete request.

When you click **Generate Item Receipt**, you can update the **Received Quantity** column of the items by entering the corresponding received quantity. If you are not receiving the all the pending items, enter only the quantity currently received for the expected items. When you create the partial item receipt, only the received quantity is logged in that receipt. You can create partial receipts for the received items until the total ordered quantity is received.

When all items in a purchase request are received, the bill status is set to **Approved**.
