You need to map items and expenses to the appropriate categories to ensure accurate tracking of expenses. See [Tracking Expenses with SuiteProcurement SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0928012501.html) for more information.

The default item and expense categories are used for items and expenses with no specific mapping defined.

#### To set up default item and expense categories:

1.  Go to Setup > SuiteProcurement > Preferences.
    
2.  In the Set Up Trading Partners section, select a subsidiary. The field lists all subsidiaries registered on OBN.
    
3.  Select the category you want to use as default in **NetSuite Category** list.
    
4.  Select the category you want to use as default in **Expense Category** list.
    
5.  Click **Save**.
