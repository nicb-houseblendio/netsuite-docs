See the following sections for information about how to set up vendor payment installments in your account:

-   [Enabling Vendor Payment Installments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161978767792.html)
    
-   [Setting Preferences for Vendor Payment Installments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161978780357.html)
    
-   [Creating Terms for Vendor Payment Installments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161978785528.html)
    

You first must enable the Installments feature. Note that the Installments feature can also be used with customer payments. For more information, see [Creating Installments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1540928779.html).

You can optionally also enable the Allow Bill Consolidation of POs with Different Terms preference. When this preference is enabled, the first installment term is applied to any additional bills created for that purchase.

For more information about setting accounting preferences, see [Accounting Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1384948.html).
