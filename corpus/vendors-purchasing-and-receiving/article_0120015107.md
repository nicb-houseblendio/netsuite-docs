NetSuite provides several Bill Capture preferences that determine how scanned vendor bill information is sourced, categorized, and displayed.

To access the Bill Capture Preferences page, go to _Setup > Accounting > Bill Capture Preferences_.

Preferences are organized in the following subtabs:

## Scanned Vendor Bills Row Display {#subsect_40112212948}

-   **Row Display** - Rows of scanned bills can be hidden from the Scanned Vendor Bills page. Rows can be hidden immediately or 30/60/90 days after bill creation. The default is 60 days. Hiding rows reduces the number of rows on the page, improving user experience and performance of the page, for example, when filtering. Only rows of scanned bills that have been reviewed and generated can be hidden. Hiding a row doesn't delete the file from the File Cabinet. Hidden bills are available in the Bills list (Transactions > Payables > Enter Bills > List).
    

## Review Page Line Display {#subsect_38112243121}

-   **Line Categorization** - Scanned lines can be recorded as items only, expenses only, or both, based on existing records and transactions.
    
    If lines are to be recorded as expenses (either all or some), they can be summarized into a single line (aggregate total). See the Expense Line Total option.
    
    If lines are categorized based on existing records and transaction (default), the following logic is applied:
    
    -   If there is a PO match, the system attempts to categorize the lines in the scanned file with items and expenses in the matched PO.
        
    -   If there is no PO match, the system determines whether the scanned line should be recorded as an item or expense from historical transactions of the matched vendor.
        
-   **Expense Line Total** - If scanned lines are recorded as expenses, they can be recorded as multiple expense lines with net amount, multiple expense lines with gross amount, or summarized into a single expense line. Use a net amount option when tax is recorded separately. Use a gross amount option when tax is included in the scanned line amounts. Select the option that matches your most common use case.
    
-   **Item Line Total** - If scanned lines are recorded as items, they can be recorded as multiple item lines with net amount, multiple item lines with gross amount, or summarized into a single item line. Use a net amount option when tax is recorded separately. Use a gross amount option when tax is included in the scanned line amounts. Select the option that matches your most common use case.
    
-   **Total Tax** - Total tax can be recorded separately as an account, expense category, or item. To prevent Bill Capture from saving scanned tax as a separate line, select No tax. If NetSuite SuiteTax Engine is enabled, select No tax.
    
-   **Shipping Cost** - Shipping cost can be recorded separately as an account, expense category, or item. To prevent Bill Capture from saving scanned shipping cost as a separate line, select No shipping cost.
    

## Review Page Field Sourcing {#subsect_89112314986}

-   **Purchase Order** - Scanned bill information is overwritten with content from the PO that is linked in the Primary Information section. Select whether items and expenses scanned data should be overwritten with content from the PO that is linked in the Primary Information section, and whether review is required or if the bill can be created automatically.
    
-   **Currency** - Currency can be sourced from the scanned file (default) or the vendor record.
    
-   **Payment Terms** - Payment terms can be sourced from the scanned file (default) or the vendor record. You can also choose to source payment terms from the vendor record only when they can't be extracted from the scanned file.
    
-   **Due Date** - Due date can be sourced from the scanned file (default) or calculated from the payment terms and bill date values.
    
-   **Expense Account** - If expense accounts are sourced from the vendor record, the system automatically populates the default expense account of the matched vendor (default). Otherwise, the system associates each memo with the expense account or category you entered.
