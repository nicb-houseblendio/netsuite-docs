Take note of the following considerations when using Transaction Email Capture:

-   The SuiteApp can't tell vendor bill file attachments apart from email signature images. If an email has signature images, the SuiteApp will process them with the vendor bill file attachments.
    
-   If you create a new vendor record using Make Copy or Save As, data from the **Transaction Email Capture** subtab doesn't carry over to the new record.
    
-   The SuiteApp can only process a vendor bill email with up to 20 attachments. If there are more, the system processes the first 20 and notifies the sender about any files it didn't process.
    
-   If the email address is in both employee and vendor records, the SuiteApp prioritizes the employee as the email sender. The employee then gets the notifications.
    
-   If several vendors use the same email address, you can assign it to one vendor record only. For more information, see [Managing Vendor Email Addresses Using Transaction Email Capture](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1114024729.html).
    
-   NetSuite sends missing vendor bill file attachment notifications only if the **Send Emails for Missing File Attachments** preference is enabled. For more information, see [Setting Up Transaction Email Capture Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1114023845.html).
    
-   Email client setup isn't supported. This includes but not limited to:
    
    -   Email client configurations
        
    -   Automation workflows, for example, email forwarding or alias setup
        
    
    Although some email clients let you set up email aliases or configure forwarding rules, the setup process varies by provider and is managed independently by you. Should you choose to use email forwarding, any resulting issues are outside the scope of the Transaction Email Capture SuiteApp.
    
-   The SuiteApp doesn't support email messages in Rich Text Format (RTF).
    
-   When you load a vendor bill in Safari, you may see a gray area while the system checks if it needs a preview window. The gray area disappears when the check is done.
