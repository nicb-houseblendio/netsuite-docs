The NetSuite as OIDC Provider feature provides an alternative to NetSuite's Outbound Single Sign-on (SuiteSignOn) feature. This feature is based on OpenID Connect (OIDC) Single Sign-on, with NetSuite acting as the OIDC provider (OP). The NetSuite as OIDC Provider feature uses OAuth 2.0 as an authorization framework. OAuth 2.0 is a token-based authentication method. For more information, see [OAuth 2.0](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_157769826287.html).

Note:

You should use the NetSuite as OIDC Provider feature as an outbound single sign-on method for use with integrations.
