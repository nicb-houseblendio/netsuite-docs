To set up the NetSuite as OIDC Provider feature in your NetSuite account, you must complete the following tasks.

Click the links in the following steps for detailed instructions for each task.

#### To set up the NetSuite as OIDC Provider feature in your NetSuite account:

1.  [Enable the NetSuite as OIDC Provider Feature](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160077233201.html)
    
2.  [Add OIDC Provider Setup Permission to Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160855187652.html)
    
    See also [OIDC Provider Setup Permission](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160855187652.html#subsect_160855237215).
    
3.  [Assign Users to Roles with the OIDC Provider Setup Permission](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160855273282.html)
    
4.  [Create Integration Records for Applications that Use NetSuite as OIDC Provider for Outbound Single Sign-on](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160855288663.html)
    
5.  [Configure NetSuite as OIDC Provider](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160855299656.html)
    
6.  [Managing OAuth 2.0 Authorized Applications](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160855309644.html)
