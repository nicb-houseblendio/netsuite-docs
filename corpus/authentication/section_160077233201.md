Before you can begin using the NetSuite as OIDC Provider feature in your account, you must enable the feature.

#### To enable the NetSuite as OIDC Provider feature:

1.  Go to _Setup > Company > Setup Tasks > Enable Features_.
    
2.  Click the **SuiteCloud** subtab.
    
3.  In the **Manage Authentication** section, check the **OAuth 2.0** box. Click **I Agree** on the SuiteCloud Terms of Service page.
    
    Note:
    
    You must enable the OAuth 2.0 feature to use the NetSuite as OIDC Provider feature in your account.
    
4.  In the **Manage Authentication** section, check the **NetSuite as OIDC Provider** box. Click **I Agree** on the SuiteCloud Terms of Service page.
    
5.  Click **Save**.
    

After you've enabled the NetSuite as OIDC Provider feature:

-   You must set up NetSuite as OIDC Provider roles. See [Add OIDC Provider Setup Permission to Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160855187652.html). See also [OIDC Provider Setup Permission](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160855187652.html#subsect_160855237215).
    
-   Administrators and users with the Integration Application permission can configure applications to use the NetSuite as OIDC Provider feature. See [Create Integration Records for Applications that Use NetSuite as OIDC Provider for Outbound Single Sign-on](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160855288663.html). For more information about integration records, see [Creating an Integration Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4393879073.html).
