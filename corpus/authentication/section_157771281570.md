To set up OAuth 2.0 in your NetSuite account, you must complete the following tasks.

Click the links in the following steps for detailed instructions for each task.

#### To set up OAuth 2.0 in your NetSuite account:

1.  [Enable the OAuth 2.0 Feature](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157771482304.html)
    
2.  [Set Up OAuth 2.0 Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157771510070.html)
    
    See also [OAuth 2.0 Permissions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157771510070.html#subsect_157771562575)
    
3.  [Assign Users to OAuth 2.0 Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157771650112.html)
    
4.  [Create Integration Records for Applications to Use OAuth 2.0](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157771733782.html)
    

See also [Managing OAuth 2.0 Authorized Applications](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157771979135.html), and [OAuth 2.0 Client Credentials Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162686838198.html)
