If you use OAuth headers when calling RESTlets, you can track and block RESTlet calls. Use integration records to manage RESTlet activity. Each record shows the RESTlet calls that authenticated by using that record's consumer key.

Integration records are located at _Setup > Integration > Manage Integrations_. For more information about using integration records with RESTlets, see the following topics:

-   [Create Integration Records for Applications to Use TBA](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4249032125.html)
    
-   [Blocking an Application](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4639959077.html)
    
-   [Regenerating a Consumer Key and Secret](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4395597766.html)
    
-   [Using the RESTlets Execution Log](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4639542510.html)
    
-   [Ownership of Integration Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4389727047.html#bridgehead_4430967734)
    
-   [Tracking Changes to Integration Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4543308762.html)
    

Note:

For more information about managing integration records, see [Integration Management](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4399047360.html), which is part of the SOAP Web Services Platform Guide. However, be aware that some of the detail in that guide pertain only or primarily to SOAP web services.
