The API Secrets page provides an overview of the secrets stored in NetSuite at _Setup > Company > Preferences > API Secrets_. You can enter keywords in the **Search** field to search for a secret by name, description, ID, application ID or owner.

You can also use filters to narrow down your choices when searching for a secret:

-   **Exposure**
    
    -   **All** - Displays all secrets.
        
    -   **Local** - Displays secrets that are intended for local use only.
        
    -   **Shared** - Displays secrets that are exposed to a SuiteApp.
        
-   **Origin**
    
    -   **All** - Displays all secrets.
        
    -   **My**\- Displays secrets that you own.
        
    -   **This Account** - Displays secrets that are owned by any user in the account.
        
    -   **External** - Displays secrets that were installed together with a SuiteApp.
