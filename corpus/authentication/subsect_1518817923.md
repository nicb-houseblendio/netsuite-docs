See the following table for a mapping of SAML attributes to NetSuite parameters, and whether they are required or optional.

| SAML Attribute | NetSuite Parameter | Required or Optional |
| --- | --- | --- |
| account | accountID | Optional, unless:
-   you are sending the role attribute.
-   you are sending the site attribute.
-   access to both non-customer center and customer center SAML roles is needed.

Sending the account attribute locks user access to a single account. See [Account Attribute](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1518813066.html#subsect_1518211003) for more information. |
| role | role | Optional. See [Role Attribute](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1518813066.html#subsect_1518813345) for more information. |
| site | site ID | Required for web store access. See [Site Attribute](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1518813066.html#bridgehead_N3827061) for more information. |
| NameID or email | user email address | Required, must use the NameID attribute or the email attribute. See [NameID and Email Attributes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1518813066.html#subsect_1518211048) for more information. |
