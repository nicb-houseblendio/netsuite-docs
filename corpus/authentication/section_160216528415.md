You can reference secrets by using any of the following modules:

| **Module** | **Method or Property** |
| --- | --- |
| N/sftp | [sftp.createConnection(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4617005472.html) |
| N/https | [https.createSecretKey(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4418247967.html) [https.createSecureString(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4418247678.html) |
| N/crypto | [crypto.createSecretKey(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4358653390.html) [SecretKey.secret](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161299949029.html) |
| N/keyControl | [keyControl.createKey(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557417459.html) [Key.password](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557418554.html) |
| N/certificateControl | [certificateControl.createCertificate(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156156407497.html) [Certificate.password](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156263312543.html) |
