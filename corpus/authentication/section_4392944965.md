Administrators can create device records manually, but there is potential for data entry errors. Before creating the record, ensure you have access to the correct device ID and device name.

#### To create a device record: {#procedure_4393016666}

1.  Go to _Setup > Integration > Device ID_.
    
2.  Click **New Device ID**. The **Device** subtab appears by default.
    
3.  Enter the **Device Name**. If you don't enter a device name, a name will be generated automatically.
    
4.  Enter the **Device ID**. The device ID should be a unique identifier for a specific device.
    
5.  Manually created records default to the **Device Status** of **Trusted**, meaning the device can log in to NetSuite.
    
    Change the status, if preferred. Devices in any status other than **Trusted** can't log in to NetSuite.
    
    -   **Pending** - Awaiting review and approval from an administrator. For device records created manually, the administrator should change the status to **Pending** before saving the record. This provides additional time to verify the information (especially the Device ID) has been entered correctly.
        
    -   **On Hold** - Has been reviewed by the administrator, but is not approved, yet. Administrators can use this status for devices for a store that is not yet open, for example.
        
    -   **Denied** - Reviewed by the administrator and denied access to NetSuite.
        
6.  Click **Submit**.
    

## Viewing System Notes {#bridgehead_4398463857}

Administrators can view the change history of a device record on the System Notes subtab.

#### To view the system notes for a device:

1.  Go to _Setup > Integration > Device ID_.
    
2.  On the List of devices page, click **Edit** or **View** for a particular device.
    
3.  On the Device page, click the **System Notes** subtab.
    

For more information about system notes, see [System Notes Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_158644279544.html).

## Deleting a Device Record {#bridgehead_4400247475}

Administrators can delete a device record. For example, you may want to delete a manually created device record if information such as the device ID isn't correct.

#### To delete a device record:

1.  Go to _Setup > Integration > Device ID_.
    
2.  On the List of devices page, click **Edit** or **View** for a particular device.
    
3.  Select **Delete** from the **Actions** list.
    
4.  If you're sure you want to delete this device, click **OK**.
    
    A confirmation notice appears on the List of devices page.
    

Note:

You can search for a device's login history using the Login Audit Trail search, even after the device record was deleted. See [Login Audit Trail Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N324233.html). Only a device that has been used for login leaves a login audit trail. Searching for a device that was never used for login will have no results.
