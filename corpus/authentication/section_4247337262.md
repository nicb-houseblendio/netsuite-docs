To set up token-based authentication (TBA) in your NetSuite account, you must complete the following tasks.

Click the links in the following steps for detailed instructions for each task.

#### To set up TBA in your NetSuite account:

1.  [Enable the Token-based Authentication Feature](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4253254429.html).
    
2.  [Set Up Token-based Authentication Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4248124361.html).
    
    See also [Token-based Authentication (TBA) Permissions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4248124361.html#bridgehead_4249074259).
    
3.  [Assign Users to Token-based Authentication Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4249025340.html).
    
4.  [Create Integration Records for Applications to Use TBA](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4249032125.html).
    
5.  [Manage TBA Tokens in the NetSuite UI](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4254975694.html).
