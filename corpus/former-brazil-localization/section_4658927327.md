In NetSuite, you assign MCN codes to CFOP codes. Then, you assign MCN codes to item records. When you add an item to a transaction, you select the appropriate CFOP code for the item.

Note:

Locking of MCN records applies only to records associated with CFOP records. MCN records that are selected on an item record, but have no associated CFOP records, are still editable.

-   [Deleting an MCN Code Record](#subsect_159662991436)
    

## Creating an MCN Code Record {#subsect_159662986311}

By default, the Administrator can create MCN code records. However, administrators can grant custom roles access to the MCN record. See [Granting Custom Roles Access to MCN and CFOP Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4658913680.html#bridgehead_4677049472).

#### To create an MCN code record:

1.  Go to Setup > Brazil Localization > MCN Codes.
    
2.  Click **New**.
    
3.  Enter values in the following fields:
    
    -   **Mercosur Common Nomenclature** - Enter an 8-digit number in one of the following formats: XXXX.XX.XX or or XXXXXXXX
        
        Note:
        
        If you entered a number without the dots, the system automatically formats it with dots when the record is saved.
        
    -   **Description** - Enter text to provide information about the MCN code.
        
4.  Click **Save**.
    

## Editing or Inactivating an MCN Code Record {#subsect_159662989047}

An MCN code record can be inactivated if it's not yet assigned to a CFOP code.

If the MCN code isn't assigned to any CFOP code, you can edit all the fields on the MCN code record. After an MCN code is assigned to a CFOP code, only the **Description** field of the MCN code record can be edited. To edit or inactivate the MCN record, you must first remove the MCN code from the CFOP record.

#### To edit or inactivate an MCN code record:

1.  Go to Setup > Brazil Localization > MCN Codes.
    
2.  To edit:
    
    1.  Click the Edit link of the MCN code that you want to modify.
        
    2.  Edit the fields.
        
3.  To inactivate the record, check the **Inactive** box.
    
4.  Click **Save**.
    

## Deleting an MCN Code Record {#subsect_159662991436}

You can delete an MCN record if it's not assigned to any CFOP code or item.

#### To delete an MCN code record:

1.  Go to Setup > Brazil Localization > MCN Codes.
    
2.  Click the Edit link of the MCN code that you want to delete.
    
3.  On the MCN Code page, under **Actions**, click **Delete**.
    
4.  At the prompt, to confirm the action, click **OK**.
