Features in the following table can be fully tested in sandbox accounts.

| Feature | Testing Notes |
| --- | --- |
| Bulk Merge |  |
| CTI Integration | Partners are Contivio and Five9 |
| CSV Import |  |
| Custom Records | Security-sensitive fields on custom records will display the same values displayed in the production account. |
| Email Campaigns | Email campaigns must have fewer than 25 recipients. Note: The From header on email you send from your sandbox account will be rewritten to use the SMTP-related email address (netsuite.com). For more information, see [FROM Headers in Email Can Be Rewritten](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1536091586.html). |
| Email Case Capture |  |
| Email Notifications and Outgoing Email | Saved searches are automatically set to inactive in sandbox accounts. For email routing options, see [Setting Preferences for Sandbox Email](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N334772.html). |
| Intellesync |  |
| NetSuite Analytics Warehouse (NSAW) | NSAW is disabled by default. You must purchase an NSAW license for sandbox before you can enable it. To do this, contact your account manager. For more information about enabling NSAW after you have purchased the license, see the Enabling NetSuite Analytics Warehouse section of the [NetSuite Analytics Warehouse Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_159309442275.html). |
| OpenID Connect (OIDC) | For instructions, see [OpenID Connect (OIDC) Single Sign-on](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_156399873235.html). |
| Reports Scheduled Reports | Reports and Scheduled Reports do not send email alerts in sandbox. **Alert Me When Ready** reports do send emails (assuming a user initiates this action). Note: The company preference for sandbox email is evaluated after the **Alert Me When Ready** report is executed and prepares to send email. Depending on the preference specified, the email is sent to a specific user or not sent at all. See [Setting Preferences for Sandbox Email](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N334772.html) for more information. If creating a report using a large Item Pricing dataset, it is possible that the oldest items were truncated due to size when copied from production to sandbox and this could impact your reports. |
| Saved Searches Scheduled Saved Searches | Saved Searches and Scheduled Saved Searches do not send email alerts in sandbox. Note: The company preference for sandbox email is evaluated after the **Alert Me When Ready** report is executed and prepares to send email. Depending on the preference specified, the email is sent to a specific user or not sent at all. See [Setting Preferences for Sandbox Email](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N334772.html) for more information. |
| Secure Domains | It is possible to test and verify a custom secure domain from the user's perspective in a sandbox account. Note: Don't try to reuse domains that are already live in your production account. You must set up a unique domain for each of your accounts: production, sandbox, and Release Preview. See [Secure Domain Licenses](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_1498574038.html), [Manual Certificates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2485854.html) and [Set Up Domains for Web Stores](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2484898.html) for more information. |
| Server SuiteScript |  |
| Client SuiteScript |  |
| SuiteAnalytics Connect (formerly ODBC) |  |
| SuiteFlow (Workflows) | SuiteFlow can be fully tested. Note: Scheduled SuiteFlow (workflows) are not run automatically in sandbox accounts, but can be tested manually. |
| Telephony Integration (Basic) |  |
| Two-Factor Authentication | 2FA Settings are shared between a production account and the sandbox accounts that are associated with that production account. Users do not need to recreate their 2FA Settings for sandbox accounts. |
| SOAP Web Services | The SOAP requests and responses for each job can be viewed in the SOAP Web Services Usage Log. In sandbox accounts, requests and responses are accessible for one day. For more information, see [Using the SOAP Web Services Usage Log](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3444819.html). |
