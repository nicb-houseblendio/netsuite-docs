Account administrators can select 10 users who can access each development account. Users must be created separately in each development account.

#### To grant development account access to a user:

1.  Log in to a development account. See [Logging in to Development Accounts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4422387327.html).
    
2.  Go to _Lists > Employees > Employees > New_ and create an employee record for the user.
    
    If this user is an employee in your production account, you can enter the username, email address, assign a role, and check the **Give Access** box on the **Access** subtab. For more information about creating an employee record, see [Adding an Employee](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N894212.html).
    
3.  Click **Save**.
    
    If prompted whether the user should inherit the password from the production account, click OK. The employee to whom you have granted access can now log in to this development account.
