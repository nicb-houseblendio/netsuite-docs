NetSuite CPQ AI Assistant improves your product setup by using AI-generated content. To get the most out of the assistant, it's important to know how product information is structured and managed. Users with an Administrator role or a CPQ Product Builder role can manage the content used by the assistant. For more information about NetSuite CPQ custom roles, see [Assigning NetSuite CPQ Custom Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1145912241.html#subsect_0527012755).

Users with the correct role (Administrator role or CPQ Product Builder role), can access the CPQ AI Assistant subtab on product, question, and answer records. Use the subtab to check readiness, create or improve AI descriptions, and confirm all options are complete. Text Enhance lets you quickly create or improve AI descriptions, and NetSuite CPQ AI Assistant automatically checks them against quality standards. For more information, see [Text Enhance](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_2171112518.html). You also control where and when the assistant appears for users, helping you deliver more consistent, well-prepared configurations.

There are three main custom record types where you enter and refine this information:

-   **Product Record** - Add essential details such as the configurable item name, category, and a natural language description. The product record also has a field for configuration questions, which are used if users need to provide more information during setup. This record is the key place to evaluate and prepare your product's AI readiness for NetSuite CPQ AI Assistant.
    
    For more information about the product record, see [NetSuite CPQ Configurator Products](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_6124716984.html).
    
-   **Question Record** - Define and manage the CPQ configuration questions that users must answer when setting up a product. Each question record includes fields for the name, label, type, sequence number, and a description of the question's purpose and specific characteristics. This description field is important because it helps the assistant understand the context of each part of the product setup.
    
    For more information about the question record, see [Working with Questions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0212121552.html).
    
-   **Answer Record** - Define the options available for each CPQ configuration question. Each answer record represents a possible selection for an item feature and includes its own characteristics and descriptive details. This information guides users during configuration and also helps the assistant build accurate configurations. For each answer, you add the name, label, sequence number, and optional settings like tool tips, appearance, and rules.
    
    For more information about the answer record, see [Working with Answers](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0212124147.html).
    

Note:

If a question or answer uses data or custom input, or shouldn't be shown in NetSuite CPQ AI Assistant, check the **Exclude from CPQ AI** box on the relevant record.

For a unified view and easier management, go to the **CPQ AI Assistant** subtab on the product record. This subtab is your main place for reviewing and updating AI-generated product information and readiness.

Users with an Administrator role or a CPQ Product Builder role can enhance existing products by adding the required information to meet description and readiness criteria. For new implementations, these users can also create new products along with their related questions and answers. Both approaches ensure the products are compatible with the assistant. For details, see [Setting Up CPQC Products for NetSuite CPQ AI Assistant](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0902032705.html).
