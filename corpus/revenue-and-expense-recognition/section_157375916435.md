The revenue arrangement record includes the following subtabs:

-   **Revenue Elements** - This subtab contains detailed information about the revenue elements included in the revenue arrangement. For details, see [Revenue Elements Subtab on Revenue Arrangements](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157375961377.html).
    
-   **Communication** - This subtab includes subtabs where you can track information specific to the revenue arrangement while in view mode: Activities, User Notes, and Files.
    
    Activities you can track include events, phone calls and tasks. For information about these activities, see [Working with Events](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N501214.html), [Working with Phone Calls](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N509876.html), and [Working with CRM Tasks](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N506499.html).
    
    Access to the User Notes subtab is controlled by the Notes Tab permission. You need at least Create level access to see the New Note button and add a note. To add a user note to the revenue arrangement, click the User Notes subtab. Then click New Note.
    
    Use the Files subtab to attach supporting documents to the revenue arrangement. For instructions, see [Attaching Files to Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N490137.html).
    
-   **Related Records** - This subtab lists related transactions and journal entries for deferred cost, revenue recognition, and reclassification with links to view the records. The source record or transaction isn't included on this subtab, but you can find it on the Revenue Elements subtab.
    
-   **System Information** - This subtab includes a System Notes subtab that enables you to view details about changes to the review arrangement. For more information, see [Viewing Transaction System Notes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N555355.html).
