If you have dependent custom segments, you need to create the revenue field map for the parent custom segment before the child custom segment. If you create the child custom segment map before the parent, you'll get an error message when you update the revenue arrangement.

The following example shows how to create custom dependent custom segments and corresponding revenue field map records:

#### To field map dependent custom segments: {#procedure_0116114331}

1.  Create a custom segment by going to _Customization > Lists, Records, &amp;amp;amp; Fields > Custom Segments > New_. Make sure you do the following:
    
    1.  Enter a label, such as Country Segment.
        
    2.  Set Type to **List/Record**.
        
    3.  Check the **Show In List** box.
        
    4.  Under the **Values** subtab, add a line for India and a line for USA.
        
    5.  Under the **Application & Sourcing** subtab, click **Transactions**, and then check **Sales Transactions** and **Revenue Arrangement**.
        
    6.  Under the **Application & Sourcing** subtab, click Transaction Columns, and then check **Sale Item** and **Revenue Arrangement**.
        
    7.  Complete other fields as needed.
        
    8.  Click **Save**.
        
2.  Create another custom segment:
    
    1.  Enter a label, such as City Segment.
        
    2.  Set Type to **List/Record**.
        
    3.  Check the **Show In List** box.
        
    4.  Under **Filtered By**, select the custom segment you created in step 1.
        
    5.  Under the **Values** subtab, add a line for Chicago.
        
    6.  Click **Set Filters** and filter Chicago by USA. In this example, **Country Segment: USA** appears under the **Filtering** column.
        
    7.  Repeat steps 2e-2f for any additional values you want to add.
        
    8.  Under the **Application & Sourcing** subtab, click **Transactions**, and then check **Sales Transactions** and **Revenue Arrangement**.
        
    9.  Under the **Application & Sourcing** subtab, click **Transaction Columns**, and then check **Sale Item** and **Revenue Arrangement**.
        
    10.  Complete other fields as needed.
         
    11.  Click **Save**.
         
3.  Create a revenue recognition field map record by going to Setup > Accounting > Revenue Field Mapping > New:
    
    1.  Set the Source Record Type to **Transaction Line**.
        
    2.  Set the Transaction Type to **Sales Order**.
        
    3.  Set the Source Field to the custom segment you created in step 1.
        
    4.  Set the Target Field to the custom segment you created in step 1.
        
    5.  Complete other fields as needed.
        
    6.  Click **Save**.
        
    
    Note:
    
    The first revenue recognition field map you create should contain the parent custom segment.
    
4.  Create another revenue recognition field map record:
    
    1.  Set the Source Record Type to **Transaction Line**.
        
    2.  Set the Transaction Type to **Sales Order**.
        
    3.  Set the Source Field to the custom segment you created in step 2.
        
    4.  Set the Target Field to the custom segment you created in step 2.
        
    5.  Complete other fields as needed.
        
    6.  Click **Save**.
        

The source field's custom segment value appears in the target field upon creating a sales order and updating the revenue arrangement.

For more information about custom segments, see [Custom Segments Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4732448748.html).
