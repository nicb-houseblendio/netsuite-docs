To exclude elements in a revenue arrangement from the carve in/carve adjustment during reclassification, set their Allocation Type to Exclude. You can set the default Allocation Type on the item record. For information, see [Item Configuration for Advanced Revenue Management (Essentials) and (Revenue Allocation)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4340443927.html).

Changes on the item record don't affect revenue elements that have already been created. However, you can change the Allocation Type for a revenue element after it's been created by editing the revenue element in the revenue arrangement. For information, see [Editing Revenue Arrangements](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4663787622.html).

Negative elements from returns without a linked positive element automatically have the Allocation Type set to Exclude. For more information, see [Revenue Allocation for Returns](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4381033932.html).

When elements are excluded, they're ignored during carve in/carve out and receive special handling in the other steps of the process. When you run the deferred revenue reclassification, the reclassification adjustments are affected in the following ways:

-   **Carve in/carve out adjustment** - Excluded elements don't participate. Their carve out ratio is 0. Consequently, any billing or credit for these items stays in their own deferred revenue account and doesn't affect other elements.
    
-   **Foreign currency adjustment** - Foreign exchange variance for each excluded element is calculated.
    
-   **Unbilled receivable adjustment** - Excluded elements participate in this process.
