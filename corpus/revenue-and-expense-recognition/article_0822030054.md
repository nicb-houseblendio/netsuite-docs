In a dataset, you combine the fields of a root record type and any joined related record types to create a query. The record types and fields you can access depend on the features enabled in your account and the permissions for your NetSuite role.

You can create an Amortization Schedule dataset to query amortization schedules and gain insights into your expense workflow. Consider the following information when working with the Amortization Schedule dataset:

-   If you want to see the amortization journal entry, drag and drop the **Custom Recurrence Pattern: Journal** field to the Data Grid. The **Custom Recurrence Pattern: Journal** displays the journal entry number if the line is recognized on the amortization schedule. This field displays as **\-NONE-** if the line isn't recognized on the amortization schedule. For more information about defining and filtering datasets, see [Defining a Dataset](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544122173.html) and [Dataset Criteria Filters](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544211200.html).
    

You can link the Amortization Schedule dataset to another dataset, such as the Revenue Recognition Schedule dataset. For more information about dataset linking, see [Dataset Linking in SuiteAnalytics Workbook](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_162627392718.html).
