When you enable Advanced Revenue Management (Essentials), NetSuite automatically adds the following system accounts:

-   Deferred Revenue - for contract liabilities
    
-   Deferred Revenue Clearing
    
-   Unbilled Receivable - for contract assets (This account already exists if you've previously enabled the Revenue Commitments feature.)
    
-   Revenue Arrangement (a non-posting account)
    

The Advanced Revenue Management (ARM) in Configuration Mode feature is automatically enabled when you enable ARM (Essentials). You can't use ARM features to recognize revenue when ARM in Configuration Mode is enabled. ARM in Configuration Mode lets you continue using your previous revenue recognition processes while configuring ARM. For more information about ARM in Configuration Mode, see [Advanced Revenue Management in Configuration Mode](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0726035100.html).

Note:

ARM in Configuration Mode is automatically disabled for users of ARM (Essentials) before the 2024.2 NetSuite release and can't be enabled.

If you disable ARM (Essentials) while ARM in Configuration Mode is enabled, then ARM in Configuration Mode is automatically disabled. Disabling ARM (Essentials) while ARM in Configuration Mode is enabled deletes all your configurations for ARM (Essentials), including its default system accounts. You can't disable ARM (Essentials) if there is a balance on any of its default system accounts.

Important:

After enabling ARM (Essentials) and disabling ARM in Configuration Mode, you can't disable ARM (Essentials).

If you use the Automated Intercompany Management feature, NetSuite automatically checks the Eliminate Intercompany Transactions box on the system deferred revenue and unbilled receivable accounts. This enables the automatic generation of elimination journal entries for intercompany sales. For more information, see [Automated Intercompany Management Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1486393.html).

When the ARM (Essentials) feature is enabled and the ARM in Configuration Mode feature is disabled, revenue for all items is deferred until revenue recognition journal entries are created. Item records use the system-generated deferred revenue account and the Default Standard revenue recognition rule by default. You must select a value for the Create Revenue Plans On field on the item record to finish item configuration. For more information, see the following topics:

-   [Revenue Recognition Rules](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4333740009.html)
    
-   [Item Configuration for Advanced Revenue Management (Essentials) and (Revenue Allocation)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4340443927.html)
    
-   [Disabling the Advanced Revenue Management in Configuration Mode Feature](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0726041738.html)
    
-   [Generating Advanced Revenue Recognition Journal Entries](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4358638894.html)
    

The NetSuite order-to-revenue workflow begins with the sales order or invoice, and specifically includes these transactions:

-   Sales order
    
-   Invoice
    
-   Cash sale
    
-   Return authorization
    
-   Credit memo
    
-   Cash refund
    

If you've been using classic revenue recognition, order-to-revenue workflows that started before you enabled the ARM (Essentials) feature continue to use classic revenue recognition. Any new order-to-revenue workflows will use Advanced Revenue Management (Essentials) after disabling ARM in Configuration Mode. For details, see [Revenue Recognition and Advanced Revenue Management (Essentials)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510249882.html).

To use ARM (Essentials), you need to enable the Accounting Periods feature because accounting periods are used for revenue recognition plans.

Important:

When you enable the ARM (Essentials) feature, it can't be disabled.

Watch the following video to learn how to enable the ARM (Essentials) feature.

Note:

This video also shows you how to enable ARM (Revenue Allocation). For more information about that feature, see [Enabling the Advanced Revenue Management (Revenue Allocation) Feature](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_165101927337.html).

#### To enable Advanced Revenue Management (Essentials):

1.  Go to _Setup > Company > Setup Tasks > Enable Features_.
    
2.  Click the **Accounting** subtab and check **Advanced Revenue Management (Essentials)**.
    
3.  Make sure that **Accounting Periods** is also checked.
    
4.  Click **Save**.
    

After you've enabled ARM (Essentials), you can enable the related feature, Rule-Based Recognition Treatment. For information about this feature, see [Rule-Based Recognition Treatment](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1552502028.html).
