With revenue recognition field mappings, you can map different data types to one another.

The following table shows compatible source and target field data types:

| Source Field Data Type | Target Field Data Type |
| --- | --- |
| Check Box | Free-Form Text Text Area |
| Currency | Decimal Number Free-Form Text Text Area Percent |
| Date | Free-Form Text Text Area |
| Date/Time | Free-Form Text Text Area |
| Decimal Number | Free-Form Text Percent Text Area |
| Integer Number | Currency Decimal Number Free-Form Text Percent Text Area |
| List/Record | Free-Form Text Text Area |
| Long Text | Free-Form Text |
| Percent | Decimal Number Free-Form Text Text Area |
| Rich Text | Free-Form Text Text Area |
| Text Area | Free-Form Text |
| Text | Text Area |

Note:

Mapping a Date/Time Type source field to a Reference ID target field causes an causes an error when updating the corresponding revenue arrangement.

For information about cross-data type field transformations, see [Field Mapping Transformations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_25101936887.html).
