Fair value dimensions are fields that you add to the fair value price record. For example, if you add a fair value dimension for subsidiary, a subsidiary field appears on the fair value price record. The dimensions you add appear in the Fair Value Dimension group on the fair value price record. The dimensions don't automatically appear in the fair value price list, but you can create a custom list view to add them. For information, see [Customizing List Views](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N496170.html).

The fair value dimensions may be custom segments. The custom fields may be automatically populated in the revenue arrangement columns using revenue recognition field mapping. For more information, see [Mapping Revenue Recognition Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4527123579.html).

The Fair Value Dimension permission controls access to the Fair Value Dimension page. This permission belongs to the Lists permission type.

#### To add fair value dimensions:

1.  Administrators: Go to Setup > Accounting > Fair Value Dimensions in the Revenue group.
    
    Revenue Managers: Go to Revenue > Setup > Fair Value Dimensions.
    
2.  Select a dimension from the **Field** list, and type a **Description**.
    
3.  Select additional fields and type descriptions as desired.
    
    You may use each field only one time. The maximum number of dimensions is 10.
    
4.  Click **Save**.
    

You can't delete a fair value dimension that is used in a fair value price record. If the fair value price record hasn't been used, you can delete the fair value price record and then delete the dimension.

#### To delete a fair value dimension:

1.  Administrators: Go to Setup > Accounting > Fair Value Dimensions in the Revenue group.
    
    Revenue Managers: Go to Revenue > Setup > Fair Value Dimensions.
    
2.  Select the blank option at the top of the **Field** dropdown list, and clear any text in the **Description** field.
    
3.  Click **Save**.
