The Application Performance Management (APM) SuiteApp lets you see and manage the performance of your NetSuite customizations and key business operations.

This SuiteApp is designed to help you:

-   Access a main dashboard to spot potential issues and dig into them using different tools.
    
-   Identify performance opportunities or slowdowns, and prioritize issues based on usage and traffic.
    
-   See performance metrics for your key record pages, and check on system health and trends.
    
-   Drill down for more detail on specific record types, operations, and instances.
    
-   View response times by client, server, and network.
    
-   Monitor performance of user event scripts, workflows, RESTlets, scheduled scripts, and Suitelets.
    
-   Check the overall health of jobs handled by SuiteCloud Processors, scheduling queues, or both.
    
-   Export performance data captured on different pages.

## Performance Management Tools in APM {#subsect_0606094309}

The Performance Health Dashboard consolidates near-real-time metrics and highlights anomalies across record pages, scripts, saved searches, integrations, and processors. When a metric exceeds its threshold, the corresponding dashboard tile exposes a direct link to the relevant analysis tool.

Tools that can be accessed directly from the dashboard (when an alert is present) include:

-   Page Time Summary
    
-   SuiteScript Analysis
    
-   SuiteCloud Processors Monitor
    
-   SOAP Web Services Analysis
    
-   REST Web Services Analysis
    
-   Search Performance Details
    
-   Concurrency Monitor
    

The following tools are available only from Customization > Performance:

-   Record Pages Monitor
    
-   Page Time Details
    
-   Search Performance Analysis
    

Use the dashboard as your initial investigative point, then drill into the linked tool for root-cause analysis. For additional guidance, see [Monitoring Account Performance](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160272438485.html) and [Using the Application Performance Management Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4304060408.html).

## Script and Plug-in Types Supported in APM {#section_160316349429}

The APM SuiteApp lets you keep an eye on how your scripts and plug-ins are performing with the Page Time Details and SuiteScript Analysis tools.

In SuiteScript Analysis, you'll only see logs for client scripts that ran long enough to help diagnose issues. It's not meant to trace every script and plug-in your account processed.

For more details, see:

-   [Using Page Time Details](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4304056471.html)
    
-   [Analyzing Scripts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4299098804.html)
    

The APM SuiteApp gives you data for these script and plug-in types:

| Script Types | Plug-in Types |
| --- | --- |
| Bundle Installation Client Map/Reduce Mass Update Portlet RESTlet Scheduled SDF Installation Suitelet User Event Workflow Action | Custom GL Lines Payment Gateway Revenue Management Tax Calculation |

## Language Support in APM {#bridgehead_1549426874}

If you have the Multi-Language feature enabled, you can see these APM SuiteApp pages in your preferred language:

-   Performance Health Dashboard
    
-   Page Time Summary
    
-   Page Time Details
    
-   SuiteScript Analysis
    
-   REST Web Services Analysis
    
-   SOAP Web Services Analysis
    
-   Concurrency Monitor
    
-   Search Performance Analysis
    
-   Search Performance Details
    

For more information about setting your language preferences with the Multi-Language feature, see [Choosing a Language for Your NetSuite User Interface](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N479109.html).
