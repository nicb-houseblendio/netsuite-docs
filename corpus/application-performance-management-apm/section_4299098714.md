The Page Time Summary is a troubleshooting tool that shows performance logs by record type. This page shows summary performance log info and a list of instances. It shows a script and workflow time breakdown chart for the selected instance.

Use the Page Time Summary page to measure script and workflow performance. Identify customizations that take too long to run.

For each record instance, you can see the total time all scripts and workflows took to run.

To change Summary aggregations, click the menu at the top right and select **Set Up**. Clear the box to hide that column in the Summary section.

## Accessing the Page Time Summary {#bridgehead_4304198633}

To open the Page Time Summary page, do one of the following:

-   Go to Customization > Performance > Page Time Summary.
    
-   In Record Pages Monitor, click a data point on any graph. For more details, see [Record Pages Monitor Charts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4303425856.html).
    

## Guidelines for Using the Page Time Summary {#subsect_165283934602}

Refer to the following guidelines to optimize use of the Page Time Summary:

-   Your performance logs don't move with your NetSuite account to the new OCI data center. For the first 29 days after the move, values use only data collected since the move, and not the full 30 days.
    
-   Page Time Summary shows up to 30 days of data. Filter logs by picking any start and end date within that range.
    
-   Performance is measured for each record and each script. You can't check performance for individual API calls.
    
-   Only UI changes are logged on the Page Time Summary page.
