Note:

This topic applies to Application Performance Management (APM) version 2.0.0 and later versions available in the SuiteApp Marketplace.

As of March 7, 2023, you can't use APM SuiteApp versions installed from the Search & Install Bundles page anymore. If you're still using one of those, install the latest version from the SuiteApp Marketplace. Then, uninstall the old version from the Search & Install Bundles page (Bundle ID: 67350).

To set up the Application Performance Management (APM) SuiteApp, follow the steps in the table below.

| Step | Related Help Topic |
| --- | --- |
| 1\. Log in to NetSuite using an Administrator role. | [Roles and Accounts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N295370.html) |
| 2\. Complete the prerequisites. | [Prerequisites for the APM SuiteApp](#bridgehead_1488345748) |

## Prerequisites for the APM SuiteApp {#bridgehead_1488345748}

Before you install the APM SuiteApp, make sure you complete these prerequisites:

-   If you are not using the Administrator role, check that you have View or higher access to the **Documents and Files** and **Perform Search** permissions. Administrators can give these permissions on the Role page, under the **Permissions** subtab, then the **Lists** subtab. See [Setting Permissions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N288727.html)
    
-   Make sure you have permission to access APM. Administrators can access APM and give access to other roles and employees. See [Setting Up Access to the Application Performance Management SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4553051128.html).
    
-   If you want to use the SuiteScript Analysis tool, make sure Server SuiteScript is enabled.
    
    Go to _Setup > Company > Enable Features_, click the **SuiteCloud** tab, and check that the **Server SuiteScript** box is selected.
    

## Installing the APM SuiteApp from the SuiteApp Marketplace {#section_4283524938}

With the standard Administrator role, follow these steps to install the APM SuiteApp from the SuiteApp Marketplace.

#### To install the APM SuiteApp from the SuiteApp Marketplace:

1.  Go to SuiteApps.
    
2.  In the **Search** field, enter **Application Performance Management**.
    
3.  Click the Application Performance Management (APM) SuiteApp tile.
    
4.  On the SuiteApp details page, click **Install**, then click **OK**.
    
    The installation will start.
    

For more information about installing SuiteApps from the SuiteApp Marketplace, see [Installing from the SuiteApp Marketplace](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1539799323.html).

After installation, access the APM tools by going to Customization > Performance. Administrators can access APM by default and set up APM access for other roles and employees. For more information, see [Setting Up Access to the Application Performance Management SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4553051128.html).

Important:

If you previously installed the APM SuiteApp from the Search & Install Bundles page, install the APM SuiteApp from the SuiteApp Marketplace. Then, uninstall the old version. The roles and employees you set up on the APM Setup page will be automatically migrated to the Marketplace version. For more information, see [Uninstalling a Bundle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3400972.html).
