After you install the Application Performance Management (APM) SuiteApp, you can access the APM tools by going to Customization > Performance.

By default, anyone with the Administrator role can access APM. If you're an Administrator, you can also set up APM access for other roles and employees.

#### To set up APM access for other roles and employees: {#procedure_1488778183}

1.  Go to Customization > Performance > APM Setup.
    
    -   To provide access to specific roles (like CEO), select the **Roles** tab.
        
    -   To provide access to an individual, select the **Employees** tab.
        
2.  Select the role or employee name from the dropdown list.
    
    1.  To let them see the Top 10 Most Utilized portlet on the Record Pages Monitor, check the box in the **Top 10 Most Utilized** column.
        
    2.  Click **Add**.
        
3.  Repeat Step 2 for each role and employee you want to give APM access to.
    
4.  Click **Save**.
    

For more information about NetSuite roles, see [NetSuite Users & Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N284861.html).

For information about how to access and use the APM tools, see [Using the Application Performance Management Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4304060408.html).
