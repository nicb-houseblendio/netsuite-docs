The SOAP Web Services API Version Usage portlet shows the total SOAP web service requests for each API version. Each version is color-coded based on its level of support. This portlet helps you keep track of API changes and predict their impact on your web services.

API versions are color-coded by these support levels:

-   **Retired** - This API version isn't in the system anymore and isn't supported.
    
-   **Not Supported** - This API version is still in the system, but it's not supported.
    
-   **Supported** - This API version exists, can be used, and is supported.
    
-   **Not Released** - This API version exists but hasn't been released yet.
    

![SOAP Web Services API Version Usage portlet.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/AccountAdministration/Performance/APM_SOAP_WSA_APIVersionUsage.jpg)

Note:

To filter data for all portlets by date range, see [Filtering Data in SOAP Web Services Analysis](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1503364123.html). You can pick a preset date range or choose Custom to set one within the last 30 days.
