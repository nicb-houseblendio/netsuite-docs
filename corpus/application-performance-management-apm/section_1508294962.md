The Saved Searches by Context portlet lets you track how execution time changes across different contexts over time. It helps you spot trends in saved search performance based on the context and timing.

![Saved Search by Context portlet.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/AccountAdministration/Performance/APM_SPA_SavedSearchbyContextPortlet.jpg)

You can also click any item in the legend to hide or show that data segment.
