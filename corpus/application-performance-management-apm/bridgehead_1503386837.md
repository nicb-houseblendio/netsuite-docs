SOAP Web Services Operation Details shows these portlets:

-   **SOAP Web Services Operation Details** - A summary of data for the web service operation, including total records, request counts, error rate, and execution time.
    
    ![SOAP Web Services Operation Details.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/AccountAdministration/Performance/APM_SOAP_WSA_WebServicesOperationDetails_Summary.jpg)
-   **Performance Details** - These four charts show execution time, error rate, requests, and records for the operation at different times. Click any data point to open the Web Services Operation Logs window. For more, see Web Services Operation Logs.
    
    ![Performance Details portlet.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/AccountAdministration/Performance/APM_SOAP_WSA_WebServicesOperationDetails_Performance.jpg)
-   **Top Records Performance** - This line graph compares execution times for each record type at different times. You can see up to five record types at the same time. Click a data point to open the Web Services Record Processing Logs window. For more, see [Web Services Record Processing Logs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161849643104.html#subsect_161849658087).
    
    ![Top Records Performance portlet.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/AccountAdministration/Performance/APM_SOAP_WSOD_TopRecordsPerformance.jpg)
