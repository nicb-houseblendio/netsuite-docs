#### To search for a specific script to analyze on the SuiteScript Analysis page:

1.  On the SuiteScript Analysis page, click the plus icon in Filters to expand them.
    
2.  Enter values for the filters. You can use the following filter options:
    
    | Filter | Description |
    | --- | --- |
    | Start Date and Time | In the date field, choose when the script started. In the next field, choose the time. |
    | End Date and Time | In the date field, choose when the script ended. In the next field, choose the time. |
    | Type | Choose the script or plug-in type from the list. After you set the type, the **Name** field fills in with matching records. |
    | Name | Choose the record name from the list. |
    | Client Event Type | This field appears when you select **Client** from the **Type** field. Choose the client event type from the list. |
    | Map/Reduce Stage | This field appears when you select **Map/Reduce** from the **Type** field. Choose the map/reduce stage you want to investigate from the list. |
    | Context | This field appears when you select any **User Event** types from the **Type** field. Choose the context that triggered the script from the list. |
    
3.  Click **Refresh**.
