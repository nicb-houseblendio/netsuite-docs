You can use Profiler Details to see the timing breakdown and context of an operation then locate and correct performance bottlenecks.

Profiler Details helps you dig deeper into performance issues. Profiler Details are available from Page Time Summary, Page Time Details, SuiteScript Analysis, SOAP Web Services Analysis, and Search Performance Details. You'll find this page only through links in tables or logs on those pages. To investigate a performance issue, select the operation you're interested in, then go to its Profiler Details page. For more information, see [Accessing Profiler Details](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1547529711.html).

Note:

Your performance logs don't move with your NetSuite account to the new OCI data center. For the first 29 days, you'll only see data collected after the move, not the previous 30 days.
