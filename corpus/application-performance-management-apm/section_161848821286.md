SOAP Web Services Analysis lets you track how your top SOAP web services operations and record processing are performing. It shows the status breakdown for SOAP web services, info about the API versions used in requests, and more details for each operation.

Watch this video for a quick introduction to SOAP Web Services Analysis:

## Accessing SOAP Web Services Analysis {#bridgehead_1504676426}

To get started with the Web Services Analysis dashboard, go to Customization > Performance > SOAP Web Services Analysis.
