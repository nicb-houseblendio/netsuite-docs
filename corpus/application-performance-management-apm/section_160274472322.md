The Performance Health Dashboard lets you track performance issues in your account, especially urgent ones found in the last seven days.

The dashboard shows issues related to these processes in NetSuite:

-   Record Pages
    
-   Scripts
    
-   Saved Searches
    
-   Integrations
    
-   Processors
    

## Accessing the Performance Health Dashboard {#subsect_160274566549}

To use the dashboard, go to Customization > Performance > Performance Health Dashboard.

To learn about the information about dashboard tiles, see [Monitoring Issues with Performance Health Dashboard Tiles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160274479766.html).

To learn about the information about dashboard tables, see [Investigating Issues with Performance Health Dashboard Tables](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160274514817.html).

To learn how to snooze issues for 30 days or show snoozed issues, see [Snoozing Issues in the Performance Health Dashboard](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160274559006.html).
