Saved searches show up as tiles.The portlet shows the top ten saved searches based on your filters. Each tile shows:

-   **Execution Time** - The median number of seconds it took for the saved search to run during the selected time. This time counts the search itself only, not filters, fields, or the UI.
    
-   **Timeout Rate** - The percentage of saved search executions that timed out during the period.
    
-   **Number of Users** ![User icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/AccountAdministration/Performance/APM_SPA_UserIcon.png) - The total number of users who accessed the saved search during the period.
    
-   **Number of Requests** ![Requests icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/AccountAdministration/Performance/APM_SPA_RequestsIcon.png) - The total number of requests for the saved search during the period.
    
-   **Execution Time Line Graph** - A line graph that shows median execution time for the selected period.
    

![Saved Searches portlet.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/AccountAdministration/Performance/APM_SPA_SavedSearchesPortlet.jpg)

You can change the time range for the data using the dropdown at the top left of the page. You can pick from the following options:

![Duration dropdown list.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/AccountAdministration/Performance/APM_SPA_Period.png)

If you want info for a custom time frame, click the saved search tile. You'll go to the Search Performance Details Dashboard, where you can filter data by start and end date/time. To learn more, read [Filtering Data on the Search Performance Details Dashboard](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1508294883.html#bridgehead_1508295961).

You can also sort the data by most requested, most timeouts, most users, or highest execution time. To sort, pick an option from the dropdown at the top right of the page.
