The Application Performance Management (APM) SuiteApp lets you export performance data from different tools. You can export CSV files from the APM SuiteApp.

Note:

Your performance logs don't move with your NetSuite account to the new OCI data center. For the first 29 days, values use only data collected since the move-not the last 30 days.

Dates and times in exported files use the time zone you've set in your preferences.

Use the table below to see how you can export data from each tool.

| APM Tool | Page or Window Name | To Export Data |
| --- | --- | --- |
| Record Pages Monitor | Record Pages Monitor | 
1.  Go to Customization > Performance > Record Pages Monitor.
2.  On the Record Pages portlet, point to the upper right corner to show the menu icon ![Menu icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/AccountAdministration/Performance/APM_191_MenuIconInLine.png).
3.  Click the menu icon ![Menu icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/AccountAdministration/Performance/APM_191_MenuIconInLine.png), and then select **Export**.

 |
| Page Time Summary | Performance Logs portlet | 

1.  Go to Customization > Performance > Page Time Summary.
2.  On the Performance Logs section, click the CSV export icon ![CSV Export icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/AccountAdministration/Performance/APM_191_CSVExportIcon.png).

 |
| Script and Workflow Time Breakdown portlet | 

1.  Go to Customization > Performance > Page Time Summary.
2.  On the Details section, click the CSV export icon ![CSV Export icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/AccountAdministration/Performance/APM_191_CSVExportIcon.png).

 |
| Page Time Details | SuiteScript and Workflow Details section | 

1.  Go to the page. See [Accessing Page Time Details](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4304056471.html#subsect_160316179437).
2.  On the SuiteScript and Workflow Details section, click the CSV export icon.

 |
| SuiteScript Analysis | SuiteScript Details popup window | 

1.  Go to Customization > Performance > SuiteScript Analysis.
2.  On the SuiteScript Details portlet, click **View Logs.**
3.  On the SuiteScript Details page, click the CSV export icon ![CSV Export icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/AccountAdministration/Performance/APM_191_CSVExportIcon.png).

 |
| SuiteCloud Processors Monitor | SuiteCloud Processors Monitor page | 

1.  Go to Customization > Performance > SuiteCloud Processors Monitor.
2.  On the Overview portlet, click the CSV export icon ![CSV Export icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/AccountAdministration/Performance/APM_191_CSVExportIcon.png).

 |
| SuiteCloud Processors Job Details | SuiteCloud Processors Job Details page | 

1.  Go to Customization > Performance > SuiteCloud Processors Job Details.
2.  On the Job Details portlet, click the CSV export icon ![CSV Export icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/AccountAdministration/Performance/APM_191_CSVExportIcon.png).

 |
| Search Performance Details | Saved Search Logs popup window | 

1.  Go to Customization > Performance > Search Performance Details.
2.  On the Saved Search Details portlet, click any data point.
3.  On the Saved Search Logs popup window, click the CSV export icon ![CSV Export icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/AccountAdministration/Performance/APM_191_CSVExportIcon.png).

 |
| Concurrency Details | Instance Details popup window | 

1.  Go to Customization > Performance > Concurrency Monitor.
2.  Filter the data by date range. To learn more, see [Filtering Data on the Concurrency Monitor Dashboard](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1526957048.html#subsect_1527036130).
3.  On the General Concurrency portlet, choose the cell of the hour you want to explore.
4.  Click the cell to access the Concurrency Details dashboard.
5.  On the Detailed Concurrency portlet, click the **View Requests** link on the tooltip to go to open the Instance Details popup window.
6.  Click the CSV export icon ![CSV Export icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/AccountAdministration/Performance/APM_191_CSVExportIcon.png).

 |
| REST Web Services Analysis | REST Web Services Logs | 

1.  Go to Customization > Performance > REST Web Services Analysis.
2.  On the Top REST Web Services Operations portlet, choose and click an operation tile.
3.  On the chart, click a data point you want to export. The corresponding REST Web Services Logs table appears.

 |
| SOAP Web Services Analysis | Web Services Operation Logs popup window | 

1.  Go to Customization > Performance > SOAP Web Services Analysis.
2.  Click a data point to open the SOAP Web Services Operation Details page.
3.  On the Performance Details portlet, click any data point.
4.  On the Web Services Operation Logs popup window, click the CSV export icon ![CSV Export icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/AccountAdministration/Performance/APM_191_CSVExportIcon.png).

 |
| Web Services Record Processing Logs popup window | 

1.  Go to Customization > Performance > SOAP Web Services Analysis.
2.  Click a data point to open SOAP Web Services Operation Details page.
3.  On the Top Records Performance portlet, click any data point.
4.  On the Web Services Record Processing Logs popup window, click the CSV export icon ![CSV Export icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/AccountAdministration/Performance/APM_191_CSVExportIcon.png).

 |
| Profiler Details | Timing Details section | 

1.  Go to the page. See [Accessing Profiler Details](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1547529711.html).
2.  On the Timing Details section, click the CSV export icon.

 |
