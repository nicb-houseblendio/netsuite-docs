To open Profiler Details, click a link or icon on certain Application Performance Management (APM) pages. Profiler Details uses data from the APM page to give you context about the operation you want to check out.

The Profiler Details page consists of the following areas:

-   **Header** - Here you'll see simple details about the operation, like its ID, start time, and date. To learn more, see [Viewing the Details of an Operation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1547529735.html).
    
-   **Timeline** - This section shows when each child record ran and for how long. For details, read [Viewing Data on the Timeline Section of Profiler Details](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1547529788.html#subsect_1556064804).
    
-   **Timing Details** - This section gives you more details about each child record's context and type. For more, see [Viewing Data on the Timing Details Section of Profiler Details](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1547529788.html#subsect_1556065058).
