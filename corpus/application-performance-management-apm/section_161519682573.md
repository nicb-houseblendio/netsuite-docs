An operation logs table pops up when you click a data point in a chart from the Top REST Web Services Operations portlet.

The operation logs table only shows instances that ran long enough to help you troubleshoot issues.This tool doesn't track every operation or record your account processed.

![Operation logs table.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/AccountAdministration/Performance/APM_REST_WSA_Logs_LimitedStatus.jpg)

This table includes the following information:

-   **Date and Time** - The date and time for each instance.
    
-   **Execution Time** - How long it took to run the instance.
    
-   **Status** - The instance's status after it ran.
    
-   **Email Address** - The user's email who ran the instance.
    
-   **HTTP Method** - The method used in the HTTP call.
    
-   **HTTP Status Code** - The numbered code for the HTTP status.
    
-   **URL** - The internal URL used to access and test the integration.
