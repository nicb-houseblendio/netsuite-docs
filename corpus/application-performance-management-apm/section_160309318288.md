Concurrency Monitor lets you track how your web services and RESTlet integrations are performing. It has two dashboards that give you different levels of detail to help you investigate. You'll see different displays depending on what governance type your account uses.

For more information, see the following:

-   [Governance Types on Concurrency Monitor](#subsect_160308689615)
    
-   [Concurrency Monitor Dashboards](#subsect_160308684906)
    
-   [Accessing Concurrency Monitor Dashboards](#subsect_1527036119)
    

## Governance Types on Concurrency Monitor {#subsect_160308689615}

The data you see in Concurrency Monitor changes based on your account's governance type. The tool gives you concurrency data for these account types:

-   **Accounts without integration-specific limits** - These accounts don't have governed concurrency requests or limits set for integrations.
    
-   **Accounts with integration-specific limits** - These accounts have governed concurrency requests, with part of the limit set aside for specific integrations.
    
    For these accounts, Concurrency Monitor shows separate data for:
    
    -   **Allocated Limit** - Shows concurrency data for an integration with a set concurrency limit.
        
    -   **Unallocated Limit** - Shows concurrency data for requests or integrations with no set concurrency limit.
        
    
    Allocated and unallocated limits add up to your account's total concurrency limit. You can see these in the Overview sections of the **Unallocated Limit** and **Allocated Limit** subtabs in Concurrency Monitor.
    

## Concurrency Monitor Dashboards {#subsect_160308684906}

Concurrency Monitor has these dashboards:

-   **Concurrency Monitor** - Gives you an overview of your account's concurrency and available integrations. The dashboard has an estimated concurrency rates chart showing errors and peak levels for each hour. Click any point to open the Concurrency Details dashboard.
    
-   **Concurrency Details** - Shows concurrency data for the hour you picked in the main dashboard, with minute-by-minute counts. You can also view logs for specific times.
    

## Accessing Concurrency Monitor Dashboards {#subsect_1527036119}

The table below shows how you can access each Concurrency Monitor dashboard:

| Dashboard | Navigation |
| --- | --- |
| Concurrency Monitor | Go to Customization > Performance > Concurrency Monitor. |
| Concurrency Details | To open the page: 1. Go to Concurrency Monitor. 2. On the Estimated Concurrency Rates chart, click a data point. |

Important:

If you're an Administrator already using the APM SuiteApp, you'll need to save access again for other roles and employees. For more information about giving others access to the Concurrency Monitor, see [Setting Up Access to the Application Performance Management SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4553051128.html).
