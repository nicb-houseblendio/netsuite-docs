The Top SOAP Web Services Record Processing portlet groups data points by record type. You can use this portlet to spot and fix issues in record processing.

To change which data you see, click the dropdown arrow at the top left and pick either **Execution Time** or **Instance Count**. Each chart can display up to 10 record types.

![Top SOAP Web Services Record Processing dropdown list.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/AccountAdministration/Performance/APM_SOAP_WSA_WebServicesRecordProcessing_Dropdown.jpg)

## Execution Time View {#subsect_161849688739}

When you pick this view, it shows how long it took for operations in each record type to run their requests.

![Top SOAP Web Services Record Processing Execution Time.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/AccountAdministration/Performance/APM_SOAP_WSA_WebServicesRecordProcessing_ExecutionTime.jpg)

Click any operation in the legend to hide it from the chart.

![Top SOAP Web Services Record Processing Execution Time chart without Add operation.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/AccountAdministration/Performance/APM_WSA_WebServicesRecordProcessing_Exclusion.png)

## Instance Count View {#subsect_161849698111}

If you choose this view, you'll see how many requests ran for each record type.

![Top SOAP Web Services Record Processing Instance Count.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/AccountAdministration/Performance/APM_SOAP_WSA_WebServicesRecordProcessing_InstanceCount.jpg)

## Web Services Record Processing {#subsect_161849712772}

To learn more about a record type, click its name or bars in the chart. You'll see a pop-up chart with data about a web service operation for that record type at different times.

To see data for a specific operation, pick it from the dropdown arrow at the top left of the window.

![Web Services Record Processing chart.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/AccountAdministration/Performance/APM_SOAP_WSA_WebServicesRecordProcessing_Popup.jpg)
