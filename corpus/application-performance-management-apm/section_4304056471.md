Page Time Details gives you an overview of a specific operation for a chosen date and time. It includes a timeline of scripts, workflows, and plug-ins that ran during the period. It also shows a detailed table with info for each instance. The timeline tracks client header, render, and init timings too. For more information, see [Viewing the Page Time Details Timeline](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160316221937.html).

To learn more about supported script and plug-in types, see [Script and Plug-in Types Supported in APM](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4283522055.html#section_160316349429).

Note:

Your performance logs don't move with your NetSuite account to the new OCI data center. For the first 29 days, values use only data collected since the move-not the last 30 days.

## Accessing Page Time Details {#subsect_160316179437}

To access Page Time Details, choose from the following:

-   If you have the operation ID from another APM tool, like Profiler Details, go to Customization > Performance > Page Time Details. Enter the ID, then click Search.
    
    Like other tools, Page Time Details has a link to **Profiler Details**. Make sure the **Operation ID** field has a value before clicking Profiler Details, or you'll get an error.
    
-   Go to Customization > Performance > Page Time Summary.
    
    In the Performance Logs section, hover over the **Page Time Details** column and click the view icon. This opens Page Time Details in a new page. For more information, see [Monitoring Performance with the Page Time Summary](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4299098714.html).
