Profiler Details lets you collect performance data on the timing and context of an operation, action, or request, so you can spot what's causing slowdowns.

Profiler Details only logs scripts that run long enough to help you troubleshoot issues. It doesn't track every script and plug-in your account runs.

Profiler Details show contextual data from the following Application Performance Management (APM) tools:

-   Page Time Summary
    
-   Page Time Details
    
-   SuiteScript Analysis
    
-   SOAP Web Services Analysis
    
-   Search Performance Details
    

## Profiler Details Limitations {#subsect_1556061504}

The Profiler Details page has a few limits:

-   Profiler Details logs only the operations that have customizations.
    
-   Profiler Details cannot display information about client scripts.
