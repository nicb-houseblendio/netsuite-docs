Here's how you can get to Profiler Details from different Application Performance Management (APM) tools.

## Accessing Profiler Details from Page Time Summary {#subsect_1556061986}

#### To go to Profiler Details from Page Time Summary:

1.  On the Page Time Summary page, go to the Performance Logs section.
    
2.  In the Profiler Details column, click the view icon that corresponds to the operation you want to investigate.
    

## Accessing Profiler Details from Page Time Details {#subsect_1556062092}

Note:

To get to Page Time Details, check out [Using Page Time Details](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4304056471.html).

#### To go to Profiler Details from the Timeline of Page Time Details:

1.  On the Page Time Details page, go to the timeline section.
    
2.  Point to the data segment you want to check, then click **View Profiler Details** in the tooltip.
    
    Note:
    
    You won't see the **View Profiler Details** link when you point to client scripts or network data segments.
    

#### To go to Profiler Details from SuiteScript and Workflow Details in Page Time Details:

1.  On the Page Time Details page, go to the SuiteScript and Workflow Details section.
    
2.  In the **Profiler Details** column, click the view icon that corresponds to the operation that you want to investigate.
    

## Accessing Profiler Details from SuiteScript Analysis {#subsect_1556062535}

#### To go to Profiler Details from SuiteScript Analysis:

1.  On the SuiteScript Analysis page, go to the SuiteScript Details section.
    
2.  Click **View Logs** to open the SuiteScript Details log page.
    
3.  On the SuiteScript Details logs page, find the **Profiler Details** column.
    
4.  Click the view icon that corresponds to the operation that you want to investigate.
    

## Accessing Profiler Details from SOAP Web Services Analysis {#subsect_1556062564}

#### To go to Profiler Details from SOAP Web Services Analysis

1.  On the SOAP Web Services Analysis page, find the Top SOAP Web Services Operations portlet.
    
2.  On the chart, click any data segment you want to review.
    
3.  On the SOAP Web Services Operation Details page, pick which portlet you want to use to see more data.
    
    -   Using the Performance Details portlet
        
        -   Click a data point on the chart.
            
        -   On the Web Services Operation Logs page, find the **Profiler Details** column.
            
        -   Click the view icon that corresponds to the operation that you want to investigate.
            
    -   Using the Top Records Performance portlet
        
        -   Click a data point on the chart.
            
        -   On the Web Services Record Processing Logs page, find the **Profiler Details** column.
            
        -   Click the view icon that corresponds to the operation that you want to investigate.
            

## Accessing Profiler Details from Search Performance Details {#subsect_1556062599}

#### To go to Profiler Details from Search Performance Details

1.  On the Saved Search Logs page, find the **Profiler Details** column.
    
2.  Click the view icon next to the operation you want to check out.
