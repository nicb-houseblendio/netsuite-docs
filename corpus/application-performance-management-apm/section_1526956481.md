The SuiteCloud Processors Monitor dashboard lets you check how your script jobs are running. You can use it to track both scheduled and map/reduce script jobs.

To choose a date range, see [Setting the Date Range in SuiteCloud Processors Monitor](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1526956645.html).

## Accessing the SuiteCloud Processors Monitor Dashboard {#subsect_1526972085}

To start using the SuiteCloud Processors Monitor dashboard, go to Customization > Performance > SuiteCloud Processors Monitor.

Important:

If you're an Administrator and already use the Application Performance Management (APM) SuiteApp, you'll need to save access again for other roles and employees. For more information about giving others access to the SuiteCloud Processors Monitor Dashboard, see [Setting Up Access to the Application Performance Management SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4553051128.html).
