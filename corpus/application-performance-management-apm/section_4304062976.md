This pie chart shows scripts from the Performance Log instance that took a long time. They help diagnose issues. The chart doesn't track every script and plug-in your account processes. The chart also shows what percentage of time the system used. All time values are in seconds.

The Script and Workflow Time Breakdown chart includes an entry for NetSuite System time. NetSuite System time is calculated using the following formula:

NetSuite System Time = Server Time - SuiteScript Time - Workflow Time

Find Total, SuiteScript, and Workflow time in the Details section of Performance Logs. For more, see About Performance Logs. For more information, read [About Performance Logs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4304063537.html).

You can perform any of the following tasks on the Script and Workflow Time Breakdown chart:

-   To view the execution time, place your cursor over a section of the pie chart.
    
-   To show or hide items on the chart, click their labels in the legend.
    
-   To hide or display specific items from the chart, click their corresponding labels on the chart legend.
    
-   To see details for scripts, workflows, or NetSuite system times, go to the Details table. It shows response times and related SuiteApps for server, user event, and client scripts, as well as workflows.
    
-   To export a CSV file of the Details table, click the CSV export icon.
