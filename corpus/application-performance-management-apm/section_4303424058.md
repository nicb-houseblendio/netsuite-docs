You can modify, filter, and sort record pages and performance data on Record Pages Monitor.

For more information, see the following table:

| Configuration | Description | Related Link |
| --- | --- | --- |
| Chart preferences | Change the data and interval for the Execution Time Distribution chart. | [Changing Chart Preferences on Record Pages Monitor](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4381245537.html) |
| Watch lists | Add or remove record page operations you want to monitor. | [Changing Watch Lists on Record Pages Monitor](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4304025095.html) |
| Custom date and time range | Add a custom date and time range. | [Adding a Custom Date and Time Range on Record Pages Monitor](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4304025842.html) |
