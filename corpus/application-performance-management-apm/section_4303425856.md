You can interact with performance data visualizations by showing or hiding data, and using quick links to drill down for more details.

To see the charts that appear when you click a record tile, see:

-   [Response Time Chart](#section_4303995647)
    
-   [Throughput Chart](#section_4303995594)
    
-   [User Event and Workflow Chart](#section_4303995549)
    
-   [Execution Time Distribution Chart](#section_4303992077)
    

## Response Time Chart {#section_4303995647}

The Response Time chart shows median response time of record pages over time. Use it to see changes in request speed and its impact on users.

Each color shows time used by client, network, or server. The graph helps you see which component used most of the response time.

![Response time chart in Record Pages Monitor](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/AccountAdministration/Performance/APM_RecordPagesMonitor_ResponseTimeChart.jpg)

## Throughput Chart {#section_4303995594}

The Throughput chart shows the number of record instances and users over time. Use it to spot heavy usage and consider offloading traffic during peaks.

![Throughput chart in Record Pages Monitor.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/AccountAdministration/Performance/APM_RecordPagesMonitor_ThroughputChart.jpg)

## User Event and Workflow Chart {#section_4303995549}

The User Event and Workflow chart shows how long user event scripts and workflows took to run. Use it to spot customization impact and bottlenecks.

![User Event and Workflow chart in Record Pages Monitor.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/AccountAdministration/Performance/APM_RecordPagesMonitor_UserEventWorkflowChart.jpg)

## Execution Time Distribution Chart {#section_4303992077}

TThe Execution Time Distribution chart is a histogram that groups record instances by response time. Use it to see if high response times were anomalies.

![Execution Time Distribution chart in Record Pages Monitor.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/AccountAdministration/Performance/APM_RecordPagesMonitor_ExecutionTimeDistChart.jpg)
