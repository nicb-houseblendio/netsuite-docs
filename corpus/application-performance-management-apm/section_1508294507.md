Saved searches give you the latest and most accurate business insights for smarter decisions. You can spot performance issues with saved searches by monitoring them in real time. In the Application Performance Management (APM) SuiteApp, NetSuite gives you tools to track and analyze your saved searches' performance.

## Guidelines for Analyzing Search Performance {#subsect_165284317812}

Use these guidelines to get the most out of search performance tools:

-   If you're an Administrator already using the APM SuiteApp, you'll need to save access again for other roles and employees. For more information about giving others access to the search performance tools, see [Setting Up Access to the Application Performance Management SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4553051128.html).
    
    For more information, see [Setting Up Access to the Application Performance Management SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4553051128.html).
    
-   Your performance logs won't move with your NetSuite account to the new OCI data center. For the first 29 days, you'll only see data collected since the move-not the last 30 days.
    

To learn more about each tool, read the topics:

-   [Using the Search Performance Analysis Dashboard](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1508294719.html)
    
-   [Using the Search Performance Details Dashboard](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1508294883.html)
