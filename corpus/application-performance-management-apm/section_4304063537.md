A performance log includes instances of the selected record type and operation. The summary and table highlight instances that took a long time to run. They help you diagnose related issues. The portlet doesn't track every script or plug-in your account processes.

Each entry lists the following information. Note that all time entries are shown in seconds.

| Column | Description |
| --- | --- |
| Date and Time | Date and time of the instance. |
| Email | The email address of the user who is logged in when the operation was performed. |
| Client | The time it took for the client to format and send the data to the NetSuite server and display the data when the server responded. |
| Network | The time it took for the data to move back and forth between the client and the NetSuite server. |
| SuiteScript | The total time it took for all triggered scripts to run. |
| Workflow | The total time it took for all triggered workflows to run. |
| Server | The total page load time spent on retrieving information from the NetSuite server. |
| Total | The total request speed between all triggered scripts, triggered workflows, the client, and the network. |
| Page Time Details | Click the icon in this column to open Page Time Details for the instance. For more information, see [Using Page Time Details](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4304056471.html). |
| Profiler Details | Click the icon in this column to open the Profiler Details page. For more, see [Profiling Operations Performance](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1547529505.html). |

Note:

Performance Logs show Total, SuiteScript, and Workflow time. These calculate NetSuite System time on the Script and Workflow Time Breakdown chart. For more information, read [Script and Workflow Time Breakdown Chart](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4304062976.html).
