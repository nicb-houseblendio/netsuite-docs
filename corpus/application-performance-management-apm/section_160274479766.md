The Performance Health Dashboard displays a separate tile for each process it monitors.

![Performance Health Dashboard tiles.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/AccountAdministration/Performance/APM_PerformanceHealthDashboard_Tiles.jpg)

Each tile may show one or more of these issue types:

-   **Error** - Shows how many issues are related to high error rates.
    
-   **Performance Issue** - Shows how many issues are related to slow or unusual processing times.
    
-   **Standards Update** - Shows how many issues are related to NetSuite standards you need to address to keep your account running smoothly.
    

Each tile shows this information:

-   Types of issues found
    
-   Number of issues for each type
    
-   Number of snoozed issues
    

Click a tile to see tables for each issue type found in your account. For more about the tables, see [Investigating Issues with Performance Health Dashboard Tables](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160274514817.html).
