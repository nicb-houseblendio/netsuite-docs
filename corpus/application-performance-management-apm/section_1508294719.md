The Search Performance Analysis dashboard lets you keep an eye on multiple saved searches all on one page. It shows saved searches as tiles with helpful metrics that update in real time. You can use this tool to quickly spot saved search performance issues and anomalies. The dashboard also lets you quickly compare stats between saved searches.

To get started, read [Using the Saved Searches Portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1508294837.html).

## Accessing the Search Performance Analysis Dashboard {#bridgehead_1508294756}

To start using the dashboard, go to Customization > Performance > Search Performance Analysis.
