#### To generate the Contra Account Sheet report:

1.  Go to Reports > Financial > Contra Account Sheet.
    
2.  In the **Subsidiary** field, select the subsidiary.
    
3.  In the **Accounts** field, select the accounts from the list.
    
    Note:
    
    **Subsidiary** and **Accounts** lists contain both active and inactive entries.
    
4.  If you are using the Multi-Book Accounting feature, in the **Accounting Book** field, select the accounting book.
    
    Note:
    
    The **Accounting Book** list contains active, inactive, and pending entries. Primary accounting book is selected by default.
    
5.  In the **Date from** and **Date to** fields, select the accounting period. To select a date range instead, click **Select range by date**.
    
6.  The report is dynamically generated upon every change. You can click the report lines to inspect the contents.
    
7.  Click **Export to ...** to export your report as a PDF or CSV file. (The PDF file is useful if you need to show it to tax authorities.) When the report's generated, you can download it. NetSuite also saves the exported report n the File Cabinet. To find it, go to Documents > Files > File Cabinet.
    
    Important:
    
    You can instantly export up to 8 accounts, or up to 100 accounts if you schedule the export. If your report has more than 30000 lines, it might not generate successfully.
