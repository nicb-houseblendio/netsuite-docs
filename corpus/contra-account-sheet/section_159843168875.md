Only the following standard NetSuite roles can access the Contra Account Sheet SuiteApp:

-   Accountant
    
-   Accountant (Reviewer)
    
-   Administrator
    
-   CEO
    
-   CEO (Hands Off)
    
-   CFO
    

The access level for all these roles is set to **Full**.

Additionally, you can create a custom role with access to Contra Account Sheet. For more information, see [NetSuite Roles Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N285436.html).

For more information about NetSuite user roles and access levels, see [NetSuite Roles Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N285436.html) and [Access Levels for Permissions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N326341.html).
