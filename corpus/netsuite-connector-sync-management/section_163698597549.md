The delete and cancel features do different things in NetSuite Connector. Here's what makes them different:

## Deleting an Order {#bridgehead_163703895162}

When you delete an order in NetSuite Connector, it's only removed from NetSuite Connector. The order is not deleted from the storefront or NetSuite. Deleting the order doesn't stop NetSuite Connector from syncing it again if the order still has a status that NetSuite Connector syncs or falls within the current sync time period.

#### To delete an order from NetSuite Connector:

1.  Log in to [app.farapp.com](https://app.farapp.com).
    
2.  Select the required connector and then select the relevant account.
    
3.  Go to Data Flows > Orders.
    
4.  In the row for the order you want to delete, hover over the **Action** menu (pencil icon) and click **Delete from FarApp**.
    
5.  In the confirmation alert, click **OK**.
    

The next time the order sync runs, depending on the connector, the order might get pulled into NetSuite Connector again.

To pull the deleted order back into NetSuite Connector, you can manually retrieve it. Ensure that you delete the originally synced order from NetSuite first.

For more information, read [Importing Orders from the Storefront in NetSuite Connector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162987170038.html).

## Canceling an Order {#bridgehead_163704561630}

When you cancel an order, NetSuite Connector stops processing and syncing updates for that order. It keeps the order data but marks it as closed and doesn't do anything else with it. Cancel an order if you've made changes outside NetSuite Connector and don't want it to sync anymore.

#### To cancel an order:

1.  Log in to [app.farapp.com](https://app.farapp.com).
    
2.  Select the required connector and then select the relevant account.
    
3.  Go to Data Flows > Orders.
    
4.  In the order row that you want to cancel, hover over the **Action** menu (pencil icon) and click **Cancel**.
    
    The order is canceled and its status shows as **Cancelled**.
    

## Reverting Canceled Orders {#bridgehead_163705279805}

If you canceled an order by mistake, you can revert it.

#### To revert a canceled order:

1.  Log in to [app.farapp.com](https://app.farapp.com).
    
2.  Select the required connector and then select the relevant account.
    
3.  Go to Data Flows > Orders.
    
4.  In the row for the order you want to revert, hover over the **Action** menu (pencil icon) and click **Uncancel**.
    

## Deleting and Canceling Orders in Bulk {#bridgehead_163705293801}

You can delete or cancel multiple orders in bulk using the **Delete Selected** and **Cancel Selected** options respectively from the **Bulk Actions** dropdown list.

#### To delete or cancel orders in bulk:

1.  Log in to [app.farapp.com](https://app.farapp.com).
    
2.  Select the required connector and then select the relevant account.
    
3.  Go to Data Flows > Orders.
    
4.  From the orders list, check the boxes for the orders you want to delete or cancel.
    
5.  Perform one of the following actions in the **Bulk Actions** dropdown list:
    
    -   To delete the selected orders, select **Delete Selected**.
        
    -   To cancel the selected orders, select **Cancel Selected**.
