For items posted on a storefront with NetSuite Connector, don't update the item SKU directly on the item record. This can cause problems with order and product sync in NetSuite Connector. If you need to update the item SKU, follow these steps to avoid issues.

#### To update SKU of items posted with NetSuite Connector:

1.  Set the item you want to update to inactive.
    
    For more information, see [Working with Inventory Items](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530631819.html), Making an Item Inactive.
    
2.  On the inactive item, change the SKU to show it's removed or obsolete. For example, add 'removed' or 'obsolete' to the SKU, like ItemCode-obsolete.
    
3.  Create a new item record with the new or updated SKU.
    
    For more information, see [Creating Item Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2166469.html).
