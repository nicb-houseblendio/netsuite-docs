Following are the possible reasons for NetSuite Connector not syncing correct values in fields for items in the storefront:

-   The mapping is not using the intended source field in NetSuite.
    
-   The value in the source field in NetSuite is not what you are expecting.
    

To resolve the issue, check if the mappings of affected fields are set up correctly set up. For more information, see the topics about mapping under [NetSuite Connector Product Sync Management](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163161457080.html).
