When you install the NetSuite Connector SuiteApp, the SuiteApp creates the following custom fields on sales orders and cash sales posted or synced by NetSuite Connector:

-   NetSuite Connector Storefront (field ID: custbody\_fa\_channel)
    
-   NetSuite Connector Storefront Order Number (field ID: custbody\_fa\_channel\_order)
    

The **NetSuite Connector Storefront** field indicates the storefront from which the order was imported. The **NetSuite Connector Storefront Order Number** field indicates the storefront order number.

Don't change these fields or hide the subtabs they're on. If you do, NetSuite Connector will not be able to post the storefront and order number details, and you'll see an error when syncing orders. Make sure the subtab isn't hidden. These fields are for internal use only and their content can change at any time, so don't use them for automation or reporting. Instead, create your own custom fields for automation or reporting and sync the same data there.

For more information about unhiding the custom fields, read [Troubleshooting Fields Not Being Visible or Editable Errors](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164069464310.html).
