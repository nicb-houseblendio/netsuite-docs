To remove an item you no longer need to show on the marketplace or cart, you need to set the item's storefront flag field to **Remove Item**.

Note:

The **Remove Item** setting only removes the item when using full product sync. If you are using price and quantity sync, **Remove Item** only stops syncing the item.

For more information, see [NetSuite Connector Storefront Flag Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163015507111.html).
