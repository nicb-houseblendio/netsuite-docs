Before you start, see [NetSuite Connector Storefront Flag Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163015507111.html) for more information about storefront flag fields in NetSuite Connector.

## Creating a Custom List {#bridgehead_162980845563}

If you have an existing working flag field, you can reuse the list used by that field, except for eBay connector.

Skip this section if you're using an existing list.

#### To create a custom list:

1.  Go to Customization > Lists, Records, & Fields > New.
    
    The Custom List page opens.
    
2.  In the **Name** field, enter a name for your custom list.
    
3.  In the **ID** field, enter an ID for your custom list.
    
4.  From the **Show Options In** field, choose **Order Entered**.
    
5.  Make sure **Matrix Option List** and **Inactive** check boxes are cleared.
    
6.  In the **Values** sublist, add the following values in the given order:
    
    1.  Add/Update Item
        
    2.  Remove Item
        
    3.  Ignore Item
        
    4.  Post Children as Stand-Alone
        
    
    Important:
    
    You need to set up the values in this order because it determines each internal ID. See [NetSuite Connector Storefront Flag Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163015507111.html) for more information.
    
7.  Click **Save**.
    

## Creating a Custom Field {#bridgehead_162980955368}

After you create the custom list, make a custom field.

#### To create a custom field:

1.  Go to Customization > Lists, Records, & Fields > Item Fields > New.
    
    The Custom Item Field page opens.
    
2.  In the **Label** field, enter a display name for the field on the item record.
    
3.  In the **ID** field, enter the field's ID
    
    You'll use this ID for the flag field in product mappings.
    
4.  From the **Type** list, choose **List/Record**.
    
5.  From the **List/Record** list, pick your custom list.
    
6.  In the **Applies To** subtab, check the boxes for the item types where you want the field to appear.
    
7.  (Optional) To determine where the field appears on the item record, click the **Display Type** subtab, from the **Subtab** field, select the subtab.
    
    If you don't choose a subtab, the field will appear in the **Custom** subtab.
    
8.  Click **Save**.
