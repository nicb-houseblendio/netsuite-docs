If NetSuite Connector shows correct discount amounts but you find that the Order Summary in NetSuite displays an incorrect tax amount you will need to:

-   Verify NetSuite discount Item configuration
    
-   Verify Country Tax setup
    

## Verify NetSuite Discount Item Configuration {#bridgehead_164387961604}

Make sure your discount item is set to apply tax correctly in NetSuite. For general discounts, it should apply before sales tax. For gift certificates, it should not apply before sales tax. For more information about setting up tax configuration in NetSuite, read the following topics:

-   For standard discounts, read [Configuring the Discount Item in NetSuite Connector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164967821723.html#bridgehead_162730373572).
    
-   For gift certificate discounts, read [Configuring Gift Cards for NetSuite Connector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164967821723.html).
    

## Verify Country Tax Setup {#bridgehead_164388043719}

Some countries in NetSuite (including the United States) have a setting that controls whether the discount item's tax setting is followed when applying the discount. Here's how to check if this setting is on:

#### To verify country tax setup:

1.  Go to Set Up > Accounting > Set Up Taxes.
    
2.  Select the subtab with the country's name.
    
3.  Check the **Respect Discount Item Tax Preference** box.
    
4.  Click **Save**.
