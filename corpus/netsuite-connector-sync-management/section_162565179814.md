Sometimes, you might want to delay importing orders to NetSuite Connector by a few minutes. You might need this delay to run a process, like a fraud detector, in your storefront. You can do this by using an order filter to hold back orders that aren't older than your chosen number of minutes.

Here's how to filter out orders less than 10 minutes old for the Shopify connector. You can adjust the timing as needed.

#### To introduce delay in order imports:

1.  Log in to [app.farapp.com](https://app.farapp.com).
    
2.  Select the appropriate connector and account.
    
3.  Go to Settings > Orders.
    
    The **General** tab of Order Settings page opens.
    
4.  Click **Advanced Options**.
    
5.  Click **Edit Order Filters**.
    
    The Edit Order Filters popup window opens.
    
6.  Update the fields in the popup window as follows:
    
    1.  **Check if**: **Order Header Value** - **Current time** - **Is Greater Than** - **Computed Value**
        
    2.  **If True, Set Value To**: **Set Order Filter** - **Import Order**
        
    3.  **Otherwise, Set Value To**: **Set Order Filter** - **Don't Import Order**
        
7.  Click the **Click to View/Edit Value** link that displays in the first row.
    
8.  Update the fields in the popup window as follows:
    
    1.  **Value Type**: **Calculate Value**
        
    2.  **Set Value To**: **Order Header Value** - **Order Date** - **Add Time To Date (Seconds)** - **Fixed Value** - **600**.
        
        Note:
        
        600 indicates 600 seconds, that is 10 minutes.
        
9.  Click **Save Changes**.
    
10.  Click **Close**.
     
11.  In the Order Settings page, click **Save**.
