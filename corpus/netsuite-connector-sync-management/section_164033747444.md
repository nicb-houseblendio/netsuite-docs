You should always have unique SKUs in NetSuite across all item types. For example, with NetSuite Connector, you shouldn't use the same SKU for both an inventory item and a kit item.

## Fixing Duplicate SKUs Error {#subsect_24150007078}

If you've inadvertently used the same SKU twice, follow these steps to fix the problem.

#### To fix the duplicate SKUs error: {#procedure_0707045906}

1.  Decide which of the duplicate SKUs you're going to use from now on.
    
2.  For the SKU you don't want to use:
    
    1.  Fulfill all the orders containing that SKU.
        
    2.  Change the **SKU** field to some unique value. For example, if the SKU value was **MYSKU**, change it to **MYSKU-OLD**.
        
3.  Wait until the order sync runs again. This time, NetSuite Connector should only find one matching SKU and sync the order.
    

Important:

Don't set the SKU you don't want to inactive. NetSuite Connector will still look for it and may show a different error about it being inactive.

You shouldn't delete the SKU you don't want to use. If there are open fulfillments for the old SKU, you could run into issues after deleting it.

If you change the SKU value, you can always temporarily change it back to the original if needed.
