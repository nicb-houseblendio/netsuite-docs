If you leave a field blank in NetSuite, NetSuite Connector won't automatically leave the matching field blank in the storefront.

If no data is provided for a mapped NetSuite field and a default value is set, NetSuite Connector uses the default value. If you leave a field blank in NetSuite, no data gets sent for that field, so NetSuite Connector falls back to the default value if there is one. You can set NetSuite Connector to send a single character (or 0 for numeric fields) as the default in your product sync mappings. Following are some key points to consider when sending default values:

-   Sending a space or 0 for some fields can cause problems. Make sure you know the consequences before sending blank data for those fields.
    
-   You can't send a space or 0 for required fields. Sometimes you can set them in NetSuite Connector, but the storefront will usually reject the product posting.
    

#### To set a space or 0 value as the default value for a field in NetSuite Connector:

1.  Log in to [app.farapp.com](https://app.farapp.com).
    
2.  Select the connector and then select the relevant account.
    
3.  Go to Mappings > Products.
    
4.  Find the field mapping you want to set a default for, and in the **Default Value** field, press Spacebar (or enter 0 for numeric fields).
    
    Note:
    
    Not all fields permit a default value to be set. The availability depends on the field and mapping type.
    
5.  Click **Save**.
