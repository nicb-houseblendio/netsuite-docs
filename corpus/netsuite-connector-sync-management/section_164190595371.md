NetSuite Connector uses the **Category** field to determine which set of mappings to use for a product. Most storefronts use only one mapping category. In these cases, a special mapping rule uses the flag field to check if it's not empty. If the flag field isn't empty, NetSuite Connector knows which mapping category to use.

NetSuite Connector checks if an item should sync to a storefront. If so, it uses the mapping category you selected since there's only one in use. When you use this logic, NetSuite Connector shows the flag field's ID in the **NetSuite Field ID** field, and the **Value** field stays blank.

A blank **Value** field in your Category mapping isn't a problem if the **NetSuite Field ID** is filled in.
