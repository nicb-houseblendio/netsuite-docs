By default, in NetSuite Connector, you need to map payment methods from your marketplace or cart to matching methods in NetSuite. This mapping lets you track payment methods on each order in NetSuite.

## Mapping Options {#bridgehead_162730733718}

NetSuite Connector shows payment methods it finds in NetSuite, like Cash, Visa, Check, and so on. These payment methods show up in a dropdown when you're mapping payment methods from your marketplace or cart. Besides the detected methods, you also have these options:

-   **Do Not Post** - Default setting for your account. When a new payment method comes in from your marketplace or cart, NetSuite Connector shows an error and asks you to map it. After you map the payment method, NetSuite Connector keeps using that mapping for future orders from that marketplace or cart.
    
-   **Not Mapped** - NetSuite Connector leaves the payment method off the order in NetSuite and doesn't map it.
    

## Mapping Process {#bridgehead_162730794029}

There are two ways you can map payment methods.

-   [Mapping from the Payment Mappings Page](#bridgehead_162736890657)
    
-   [Mapping Payment Methods Directly from an Order](#bridgehead_162737302970)
    

## Mapping from the Payment Mappings Page {#bridgehead_162736890657}

You can view and edit all payment methods on the Payment Mappings page. This is easier if you have several payment methods to map or need to update existing mappings.

The Payment Mappings page displays the following columns:

-   The left column displays marketplace or cart payment methods. If an order with a payment method isn't imported, the column will be blank.
    
-   The right column displays the NetSuite payment method each marketplace or cart method is mapped to. If an order with a payment method isn't imported, the column will be blank.
    

#### To map payments from the Payments Mapping page:

1.  Log in to [app.farapp.com](https://app.farapp.com).
    
2.  Select the appropriate connector and account.
    
3.  Go to Mappings > Orders.
    
    The Payment Methods page opens.
    
4.  Add the new payment method in the left column.
    
5.  Click the dropdown in the right column to select the NetSuite payment method to which you want to map the new payment method.
    
    Note:
    
    If you do not see the required payment method, refresh the NetSuite payment method.
    
    For more information, read [Refreshing NetSuite Payment Methods for NetSuite Connector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162968601943.html).
    
6.  Click **Save**.
    
    The current order and all future orders with the same payment method will use the mapping you set up this way.
    

## Mapping Payment Methods Directly from an Order {#bridgehead_162737302970}

If you have an order with a payment method that's not mapped, you can map it directly from the order.

Note:

This method does not work for Amazon orders.

#### To map payment methods directly from an order:

1.  Log in to [app.farapp.com](https://app.farapp.com).
    
2.  Select the appropriate connector and account.
    
3.  Go to Data Flow > Orders.
    
    The Payment Methods page opens.
    
4.  On the right of the order, click the **Action Menu** (pencil icon).
    
5.  Click **Edit**.
    
    The Order Details window appears.
    
6.  Click the **Mapping** tab.
    
7.  From the **NetSuite Payment Method** list, select the NetSuite payment method that you want to map.
    
    Note:
    
    If you do not see the required payment method, refresh the NetSuite payment method. For more information, read [Refreshing NetSuite Payment Methods for NetSuite Connector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162968601943.html)..
    
    Click **Save**.
    
    The current order and all future orders with the same payment method will use the mapping you set up this way.
