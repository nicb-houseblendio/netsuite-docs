By default, NetSuite Connector uses the built-in tracking number and carrier from the fulfillment record when sending data to the storefront. You can use this feature to set up alternative custom fields that NetSuite Connector will use for carrier info and tracking number on fulfillments.

If you use custom fields for tracking number and carrier on the fulfillment, you'll need to define those fields in NetSuite Connector. If you don't define them properly in NetSuite Connector, fulfillments might fail to sync or get merged, so they won't match one-to-one between NetSuite and the storefront.

#### To configure custom fields for fulfillment:

1.  In NetSuite Connector, select the connector and relevant account.
    
2.  Go to Settings > Fulfillments.
    
3.  Click Add Mapping.
    
4.  Select **Tracking Company** field from the list, then click **Add Mapping**.
    
5.  Edit the mapping with the following values:
    
    1.  In Mapping Type, set Fulfillment Header.
        
    2.  In NetSuite Field, set Custom Field and enter the Custom Field ID.
        
6.  Click **Save**.
