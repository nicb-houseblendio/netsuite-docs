If you enable TaxJar in NetSuite, change the script execution order on the form (sales order or cash sale) that NetSuite Connector posts orders to. The **FA | UE Order Total Validation** script should run after the **TaxJar** script.

The following procedure uses sales order as an example, but you can change the form type as needed.

#### To change the script execution order: {#procedure_0720124228}

1.  Go to Customization > Scripting > Scripted Records.
    
2.  On the Sales Order row, click **Edit**.
    
3.  In the **User Event Script** subtab:
    
    1.  Click the row that contains the **FA | UE Order Total Validation** script.
        
        The cursor changes to a four-way arrow.
        
    2.  Drag the script to the end of the list.
        
4.  Click **Save**.
