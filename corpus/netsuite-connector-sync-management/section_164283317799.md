This topic covers troubleshooting for the following order import issues:

-   [Order Not in NetSuite Connector](#bridgehead_164283340266)
    
-   [Order Not Imported into NetSuite](#bridgehead_164290722123)
    
-   [Order Not Imported into NetSuite but Its Status is: Order Posted, Waiting for Shipment](#bridgehead_164290776603)
    

## Order Not in NetSuite Connector {#bridgehead_164283340266}

If your order is not in NetSuite Connector, check the following:

-   **Order sync is enabled** - Check if order sync is enabled. Orders will not import if order sync is disabled.
    
-   **Marketplace or cart is connected to NetSuite Connector** - Test your credentials to make sure your account's connected. For steps on specific connectors, read [Integrating NetSuite Connector with Supported Storefronts or 3PLs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_165036447599.html).
    
-   **Order status for NetSuite Connector is set to import** - Check the order status. If the missing order's status is not highlighted in the **Automatically import orders in the following statuses** field, the order will not be imported. For more information, read [Setting Order Statuses for Automatic Import in NetSuite Connector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163456256303.html).
    
-   **Order date is older than the order cutoff date** - If the order date is before the order cutoff date set in the **Import Orders Created After** field, the order will not import. For more information, read [Setting Order Cutoff Dates in NetSuite Connector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162608935809.html).
    
-   **Order sync has run** - Order sync runs every 20 minutes. So, NetSuite Connector can take up to 20 minutes from when the order status updates to import the order.
    
    Note:
    
    For Amazon FBA, the default order sync interval is 5 hours.
    
-   **Manually import the order** - Check if you can manually import the order from your marketplace or cart. For instructions, read [Importing Orders from the Storefront in NetSuite Connector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162987170038.html).
    

## Order Not Imported into NetSuite {#bridgehead_164290722123}

If your order didn't import into NetSuite, search for the order by ID in NetSuite Connector. If you don't find the order, read [Searching for Orders Posted By NetSuite Connector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163757226356.html).

Sometimes, the order is in NetSuite Connector, but shows an error that needs to be fixed before it can be imported into NetSuite. If the order has an error for several days and you don't resolve it, NetSuite Connector might automatically cancel the order. Make sure you address order import errors so the orders import correctly. You should get order import error notifications by email.

If your order status is **Cancelled**, you can revert the canceled order. For more information, read [Reverting Canceled Orders](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163698597549.html#bridgehead_163705279805).

## Order Not Imported into NetSuite but Its Status is: Order Posted, Waiting for Shipment {#bridgehead_164290776603}

Search for the order in NetSuite. For more information, read [Searching for Orders Posted By NetSuite Connector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163757226356.html).
