You can edit order information directly in NetSuite Connector by following these steps.

#### To edit an order in NetSuite Connector:

1.  Log in to [app.farapp.com](https://app.farapp.com/).
    
2.  Select your connector and account.
    
3.  Go to **Data Flows > Orders**.
    
4.  Search for the order you want to edit by scrolling the page or entering the order ID in the search bar.
    
5.  On the row of the order you want to edit, click the pencil icon on the **Action** column, then select **Edit**.
    
    A popup screen is displayed with the order information you can edit.
    
6.  Make your changes and click **Save Changes**.
