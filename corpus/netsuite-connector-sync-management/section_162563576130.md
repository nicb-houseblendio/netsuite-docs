You must ensure that every order and total in NetSuite is imported correctly by NetSuite Connector to match what is posted on the storefront. To do this, follow these best practices:

-   **The item prices on the order need to match the prices set up in NetSuite.**
    
    By default, NetSuite Connector overrides the prices in NetSuite and uses the item prices from the order. This ensures the item totals match. If you've set up your Order Item mappings to use a price level other than -1 or Custom, NetSuite prices will be used instead, which can cause mismatched order totals. If you see that item prices in NetSuite don't match the storefront order, go to Mappings > Orders and open the Order Item Mappings page. Make sure your Price Level mapping is set to Custom (IID: -1) for this storefront or account. If you don't have a Price Level mapping yet, you can add one by clicking Add Mapping Row. Then, ensure that your mapping for **Price Level** is set to **Custom (IID: -1)** for this storefront or account. If you do not have a Price Level mapping yet, you can add one by clicking **Add Mapping Row**.
    
-   **Set up discounts in the NetSuite Connector discount settings before applying them to orders.**
    
    If there's a discount on an order, check if it's already in NetSuite. If not, set up the discount in NetSuite Connector so it imports properly. For more information, refer to [Managing Order Discounts in NetSuite Connector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162821876930.html).
    
-   **The tax totals on the NetSuite order need to match the channel order.**
    
    To import taxes correctly into NetSuite, make sure they're set up in NetSuite Connector. If the tax total is off, check the Configure Taxes section in [Setting Up NetSuite Connector Order Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162755906735.html).
    
-   **Set up discount items in NetSuite.**
    
    If an order has a discount, check the **Apply Before Taxes** box on the discount item in NetSuite. For more information, see [Applying Sales Tax or VAT to Discount Items](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1817936.html) and [Applying VAT Before or After Discounts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N1822423.html).
    
    To review your configuration, refer to [Configuring Discount Settings in NetSuite Connector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162821876930.html#bridgehead_162824350074).
