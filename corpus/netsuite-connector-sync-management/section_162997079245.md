If you try to sync an order with an invalid payment method, NetSuite Connector shows the error, `ERROR: INVALID_KEY_OR_REF - Invalid paymentmethod <reference_key>`. The reference key in the error message is the internal ID of the invalid payment method in NetSuite.

To fix this error, you'll need to search for the payment method in NetSuite and find out what's causing the problem.

The following procedure applies only for the **Payment Method** field. These steps might not apply to the **Payment Option** field, which replaces **Payment Method** when you turn on the Payment Instruments feature in NetSuite.

#### To troubleshoot the invalid payment method error:

NetSuite Connector can't always tell why NetSuite rejects some payment methods. You may need to investigate and make changes in NetSuite. If you can enter the order manually with that payment method, NetSuite Connector should also be able to send orders using that payment method.

1.  Go to Setup > Accounting > Accounting Lists. You can also use the NetSuite global search and enter **Page: Payment Methods** to get to the same page.
    
2.  Find the invalid payment method based on the reference key in the error message. This number should match the NetSuite internal ID.
    
    If you don't see the internal ID column, you might need to turn on the **Show Internal IDs** preference first. To learn more, read [Viewing Internal IDs in NetSuite](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162920785007.html).
    
3.  Edit and save the record without any changes. If NetSuite asks for any extra details, add them before saving. Then try to sync the order again.
    
4.  If the sync still fails, try creating the order manually in NetSuite. Make sure you have the same info in these fields:
    
    -   Customer
        
    -   Subsidiary
        
    -   Shipping Address
        
    -   Items
        
    -   Payment Method
        
    
    When you recreate the order, check if the payment method is missing from the dropdown. If it shows up, NetSuite will give an error if you try to save the order with the invalid payment method.
