If you want to add Promo Codes to your marketplace or cart, NetSuite Connector can map them to the matching coupon code in NetSuite. This makes sure transactions between your marketplace or cart and NetSuite match. For more information about promo code discrepancies, read [Promo Code Amount Discrepancies](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163455137160.html).

Note:

The leading practice is to set up discount, promotion, or coupon amounts to a generic discount item.

#### To set up matching Promo Codes from the marketplace or cart to NetSuite:

1.  In NetSuite, do the following:
    
    1.  List Coupon Codes at the Promotion Level from List > Marketing > Promotions > New.
        
        This is important because NetSuite Connector can only detect coupon codes listed at the Promotion Level. If your Coupon Code isn't set to the Promotion Level, NetSuite Connector won't be able to match it and this feature won't work.
        
    2.  Select the type of promotion you want to create and configure the promotions as needed.
        
        Important:
        
        Coupon Codes are case sensitive.
        
    3.  Click **Save**.
        
        If you see your Promotion has the Coupon Code listed when you view your promotions, that means it's set at the Promotion Level. Promotions without a Coupon Code are not recognized by NetSuite Connector.
        
2.  In NetSuite Connector, do the following:
    
    1.  After you set up the Coupon Codes in NetSuite, log in to [app.farapp.com](https://app.farapp.com/) and go to the connector you want to set up Promo Codes for.
        
    2.  From Settings > Orders > Discount > Advanced Options, check the box **POST COUPON CODE TO MATCHING PROMO CODE IN NETSUITE (APPLIES TO ALL SHOPIFY ACCOUNTS)**. This tells NetSuite Connector to look for a matching Coupon Code in NetSuite if a Promo Code is used in the marketplace or cart.
        
    3.  Enter the internal ID of the default discount item that you configured, as detailed in topic [Managing Order Discounts in NetSuite Connector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162821876930.html).
        
        If no Promo Code is found on the order, NetSuite Connector will use your default discount item instead.
