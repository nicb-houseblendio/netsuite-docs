When you first activate order sync, NetSuite Connector pulls all live orders from the starting date up to and including today. The starting date comes from the order cutoff setting. If you haven't set a cutoff, NetSuite Connector uses its own default for your marketplace or cart.

## Setting the Order Cutoff Date {#bridgehead_162695449755}

Use the following procedure to set the order cutoff date.

#### To set the order cutoff date:

1.  Log in to [app.farapp.com](https://app.farapp.com).
    
2.  Select the appropriate connector and account.
    
3.  Go to Settings > Orders.
    
4.  Click **Advanced Options**.
    
5.  Click the **Import Orders Created After** field and select the date you want to start pulling orders from.
    
    Note:
    
    The dates that exceed the maximum limit of cutoff date cannot be selected.
    
6.  In the time selection window that opens, select the time on your chosen date you want to start pulling orders from.
    
    You can choose the time in five-minute increments.
    
    After you select the time, the selected date and time display in the **Import Orders Created After** field.
    
7.  Click **Save**.
    
    After you activate order sync, NetSuite Connector imports all eligible orders up to the cutoff date and time you set in the **Import Orders Created After** field.
