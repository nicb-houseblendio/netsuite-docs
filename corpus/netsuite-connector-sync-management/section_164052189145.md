When orders and products encounter syncing issues, NetSuite Connector notifies you through email. Make sure you've added your email address to the notification section for NetSuite and your connectors in NetSuite Connector. For more information, read [Notification and Email Settings for NetSuite Connector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163481319710.html).

You can also check error messages in NetSuite Connector. Hover over the order on the Orders page to view the error message. For example, in the following screenshot, you'll see the error message that the order isn't posted to NetSuite because the last name and subsidiary are missing.

![An example of order error message.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteConnector/NC_OrderErrorMessage.png)

Error messages include the reason and a solution. You might need to change a NetSuite setting to fix the error.

For more information about some common errors, read [Troubleshooting Common Order Sync Errors in NetSuite Connector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164017180964.html).

Error messages on products appear similarly on the Products page in NetSuite Connector.
