An order gets the status **Order Posted, Waiting for Shipment** when it's imported into NetSuite. To find the order ID that's imported into NetSuite, click **Show NetSuite Transaction ID** in the right-most dropdown in NetSuite Connector and then click **OK**. You can also find this information within NetSuite without logging into app.farapp.com.

#### To find an order in NetSuite using Search Order ID field:

1.  Go to Transactions >Sales > Enter Sales Orders > Search.
    
2.  In the **View** dropdown, select the custom field you created for storefront order.
    
3.  Select the order from the list.
    

Alternatively, you can search for a record's internal ID. See [Finding the Internal ID of Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162634223275.html) for more information.

If you can't find your order in NetSuite but NetSuite Connector shows an internal ID, the order needs to be deleted from NetSuite. To reimport the order, you'll need to post it again from NetSuite Connector.
