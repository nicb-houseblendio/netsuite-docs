Variation items are items with different options, set up using a parent-child relationship. The parent item holds the common info, whereas child items have the unique variations. To post item families correctly, you'll need to set the flag fields for them properly.

If you're seeing posting errors for child items, check these things:

-   In NetSuite, make sure both the parent and child item flag fields are set to **Add/Update** or **Y**. Or, if you want to post the child items as standalone products, set the parent to **Post Children as Standalone** or **C**.
    
-   When using full product sync, the child SKUs and variation field values for each SKU must match what's already set on the items in your storefront. The whole family also needs to be set to sync. If anything doesn't match, the error message will tell you what needs to be fixed.
    
-   If you see errors about specific product fields, make sure you map those fields for that category. Product fields can vary by both category and storefront.
