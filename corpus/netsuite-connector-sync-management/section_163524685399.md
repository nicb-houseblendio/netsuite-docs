Some items in NetSuite need extra data called **inventory detail**. For these items, NetSuite Connector has to provide this data on the sales order or cash sale during order sync for NetSuite to accept the order posting. To handle these items, set up NetSuite to automatically provide the inventory detail. Otherwise, NetSuite Connector sends NetSuite to the first available lot number. If NetSuite gives you the data you need, you can use that value for the inventory detail. Also, make sure you have a line item level location field mapping so NetSuite Connector knows where the first available lot number is.

Setting up NetSuite this way helps you get the detail you expect. If not, you can troubleshoot to see what occurred in NetSuite. But you can't do this with NetSuite Connector.

#### To enable NetSuite Connector to select the first available lot number on items that require inventory detail during order sync:

1.  Log in to [app.farapp.com](https://app.farapp.com/).
    
2.  Select the relevant connector and account.
    
3.  Go to **Settings > Orders**.
    
4.  On the General Order Settings page, click **Advanced Options**.
    
5.  Go to Inventory Detail (Lot Number) Settings.
    
6.  Check the box of the transaction record type that you want to enable the functionality for.
    
7.  Click **Save**.
    
    You'll see a message confirming the functionality is enabled.
