You can choose which order statuses NetSuite Connector automatically imports from your marketplace or cart. Most connectors let you do this on their Order Settings page. If a sync runs and an order isn't imported, the order status might not be one that NetSuite Connector brings in automatically.

#### To set order status fields to automatically import:

1.  Log in to [app.farapp.com](https://app.farapp.com)
    
2.  Select the connector and relevant account.
    
3.  Go to Settings > Orders.
    
4.  The order status fields show up in the **Automatically import orders in the following statuses** pane. The highlighted fields on the list get imported automatically. Hold Ctrl to pick multiple order status fields.
    
    Note:
    
    If the pane is missing, the connector does not support setting order status fields for automatic import. Contact NetSuite Support for assistance.
    
5.  Click **Save**.
