If you get an error with order or fulfillment sync in NetSuite Connector, hover over the order row to see the error details.

If you're not sure how to fix the error, search SuiteAnswers or the help center with relevant keywords to find a solution. The table below lists some common error messages users get, along with help topics for finding a fix. If you need more help, contact NetSuite Connector Support.

| Error Message | Related Topic |
| --- | --- |
| Shipment method hasn't been mapped. Please map this order's shipment method or view/edit all of your shipment methods. | [Mapping Order Shipment Methods in NetSuite Connector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162995452868.html) |
| Payment method hasn't been mapped. Please map this order's payment method or view/edit all of your payment methods. | [Mapping Order Payment Methods in NetSuite Connector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162730720397.html) |
| NetSuite is reporting that shipment method with internal ID # isn't valid. Please double-check that this shipment method is valid and that it's allowed for this customer. | [Troubleshooting NetSuite Connector Shipping Method Errors](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162980038804.html) |
| ERROR: INVALID\_KEY\_OR\_REF - Invalid paymentmethod reference key. | [Troubleshooting NetSuite Connector Invalid Payment Method Errors](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162997079245.html) |
