This error means NetSuite Connector tried to sync an order or other transaction into NetSuite with data from a closed accounting period. However, NetSuite doesn't accept a date in a closed accounting period, so you get this error. You can try these options to fix the issue:

-   **Reopen the accounting period** - If you reopen the accounting period, NetSuite will let the sync run. For more information, read [Creating or Reopening an Accounting Period in NetSuite](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163782042989.html).
    
-   **Force the transaction in NetSuite with the current date** - Turn on the NetSuite Connector setting to force the transaction to use the current date. For example, even if the order's two months old, in NetSuite, the transaction date will be the sync date.
    
    Note:
    
    This setting doesn't work for order-related records like customer deposits or payments. In those cases, either reopen the accounting period or use the current date, then edit the record in NetSuite to adjust the date if needed.
    

## Enabling Automatic Use of Current Date for Closed Accounting Period Errors {#bridgehead_164085645670}

Before turning on this setting, note the following:

-   This setting doesn't disable or remove any transaction date mappings. If you have a mapping that overrides NetSuite Connector's default date handling, you'll need to change it for this setting to work.
    
-   If you keep this setting on, NetSuite Connector will automatically sync failed orders with the current date. You can also turn it on temporarily to sync old orders, then turn it off.
    
    For information about manually running a scheduled sync, read [Manually Triggering a Scheduled Sync in NetSuite Connector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163962503281.html#subsect_72145937329).
    
-   This setting applies to all connectors. To temporarily enable it for one connector, disable syncs on the accounts you don't want the setting to run on.
    

#### To enable automatic use of current date for closed accounting period errors:

1.  Log in to [app.farapp.com](https://app.farapp.com).
    
2.  Select NetSuite > Settings > General.
    
3.  Click **Advanced Options**.
    
4.  Check the **Post Current Date for Accounting Period Order Errors** box.
    
5.  Click **Save**.
    
    A banner message confirming the update appears.
