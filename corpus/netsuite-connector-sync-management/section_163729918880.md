NetSuite Connector uses order forms to filter which items are displayed. You will be unable to create new orders if you try to create an order with an item that's not included in your filter's criteria. If you can't create a new order, check whether your order form's using a filter.

#### To check if an order form is using a filter:

1.  Go to Customization > Forms > Transaction Forms.
    
2.  Find the form you're syncing. This is usually a **Cash Sale** or a **Sales Order** form, unless specified in NetSuite Connector. These are the common forms for FBA and Shopify POS.
    
3.  Click **Edit**.
    
4.  Go to the **Sublist Fields** subtab.
    
5.  Click the **Item Filter** list.
    
    If the **Item Filter** list is empty, no filter is applied. If anything's in the list, a filter's applied to your orders. You can clear the item filter list to test your form, or update your filters to make sure items from your marketplace or cart can be added to the order form.
    
6.  Click **Save**.
