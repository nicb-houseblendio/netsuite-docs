The Shipment Methods page lists two different sets of shipping methods:

-   The left column lists the shipments methods used in the storefronts that appeared on the synced orders.
    
-   The right column has a dropdown list of shipping methods in NetSuite.
    

If you don't see your storefront shipment methods in the left column, it means no order has been imported with that shipment method yet. After an order with that shipping method imports, it'll get added to the left column so you can map it.

If you don't see your NetSuite shipping method in the dropdown list in the right column, check these things:

1.  Refresh your shipment methods. For more information, read [Refreshing Shipping Methods for NetSuite Connector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162968673287.html). After refreshing, check the **Shipment Method** dropdown list to see if the missing method shows up.
    
2.  If you do not see the shipment method after refreshing, check if your shipment method is set up correctly in NetSuite. For more information, read [Configuring Shipping for NetSuite Connector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162944951251.html).
    
3.  If you have multiple subsidiaries, make sure the subsidiaries used by NetSuite Connector are set in the **NetSuite Subsidiaries Used For FarApp Connectors** field. For more information, read [Setting Up NetSuite Connector for Syncs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162945105482.html). If the missing shipment method is in a subsidiary that's not added, enter its internal ID and save the NetSuite Settings page.
    
4.  After performing steps **2** and **3**, repeat step **1**.
    

For information about setting up shipping in NetSuite, read [Shipping](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N1257369.html).
