This error appears when the TranID isn't editable in NetSuite. NetSuite Connector is trying to write to the TranID field but can't because Allow Override in Auto-Generated Numbers Setup isn't checked.

To set up your Auto-Generated Numbers and allow override for your TranID, see [Setting Up Auto-Generated Numbering](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0404030807.html).

For more information about auto-generated numbers and the allow override option, see [Auto-Generated Document Numbers](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4340435273.html).
