Viewing inventory history in NetSuite is useful for tracking things like oversells and inventory inconsistencies. Following are the places where you can check the inventory history easily:

-   Item related records - For more information, read [Related Information for Items](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2179943.html).
    
-   Inventory activity detail report - For more information, read [Inventory Activity Detail Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2355966.html)
