The NetSuite Connector integration record is used along with the token you create in NetSuite to allow NetSuite Connector to connect. If you don't see the integration record, check the following:

-   The NetSuite Connector SuiteApp creates the NetSuite Connector integration record. Make sure you have installed the NetSuite Connector SuiteApp.
    
    You can view the SuiteApps installed in NetSuite from the Installed Bundles list page.
    
-   If the SuiteApp is installed and you still don't see the NetSuite Connector integration record, the record may be set to blocked. Blocked integrations are not shown by default.
    

## Enabling a Blocked NetSuite Connector Integration Record {#bridgehead_163031404548}

Use the following procedure to check and enable the blocked NetSuite Connector integration record.

#### To check and enable a blocked NetSuite Connector integration record:

1.  Go to Setup > Integration > Manage Integrations.
    
2.  If you don't see the NetSuite Connector record, check the **Show Inactives** box.
    
3.  Click **Refresh**.
    
4.  If you still don't see the NetSuite Connector record, try to uninstall and resinstall the SuiteApp.
    
5.  When the NetSuite Connector record displays in the Integrations page, click **NetSuite Connector**.
    
    The NetSuite Connector record opens.
    
6.  Click **Edit**.
    
7.  From the **State** list, select **Enabled**.
    
8.  Click **Save**.
