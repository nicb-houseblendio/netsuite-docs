For each order, NetSuite calculates the tax code and applies the tax rate based on the shipping address. NetSuite Connector, on the other hand, overwrites the NetSuite tax rate with the rate used in the marketplace or cart. This process ensures that the tax total in NetSuite matches the tax total in the marketplace or cart. NetSuite Connector uses this method because NetSuite does not allow any manual changes to the **Tax** field.

## Incorrect Tax Rates {#subsect_163283347701}

Incorrect tax rates on the order cause tax totals to differ between NetSuite and your marketplace or cart.By default, NetSuite Connector only sends the tax rate from the marketplace or cart when it creates the order. If the rates don't match, check the following areas in NetSuite.

-   Verify if your customers are set to taxable by default (applicable only for US customers). If NetSuite assigns a non-taxable customer to an order, the order becomes non-taxable because there's no tax rate for NetSuite Connector to overwrite.
    
-   Verify if your items are set to a taxable tax schedule. If NetSuite includes a non-taxable item in an order, there's no tax rate for NetSuite Connector to overwrite. For more information, see [Taxable Items](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164744121972.html#subsect_164878454367).
    
-   Verify if you have a tax plug-in installed in NetSuite. Some tax plug-ins require additional mappings or settings in NetSuite Connector to work properly. For example, Avalara plug-in requires NetSuite Connector to check a box to specify that this plug-in should not overwrite the tax rate that NetSuite Connector sends. Refer to the plug-in documentation for any NetSuite fields or settings that you need to set to prevent overwriting tax rates.
    
-   Verify if you have an automation in NetSuite that adjusts tax rates, addresses, customers, or any other value on the order that may trigger a tax recalculation.
    
-   Verify if you use line item taxes in NetSuite. Ensure that you have NetSuite Connector set to use line item taxes. In NetSuite Connector, go to Settings > General. On the NetSuite Settings page, check the **Line-Item Taxes Are Enabled In Your NetSuite** box.
    
-   Check if there are conflicts between your NetSuite tax settings and storefront tax settings.
    
-   If you're getting incorrect tax rates on return transactions, it may be caused by sales orders not having the correct tax rates. You can enable the **Allow Sales Order Tax Rate Correction** in NetSuite in Connector > Configuration > Setup to fix the tax rates of sales orders.
    

## Tax Code Mapping {#subsect_163283368521}

NetSuite Connector does not map Tax Codes on orders. While it is possible to map a tax item on newly created customers, the leading practice is to not do so. Instead, NetSuite Connector must be configured to automatically provide a tax code based on the shipping address.

## Incorrect Tax Code or Tax Item {#subsect_163283371896}

If you see an incorrect tax code or tax item in NetSuite, check the tax nexus setup. As a best practice, manage tax codes and items in NetSuite, not in NetSuite Connector. You can test any adjustments to the nexus by manually creating an order in NetSuite and verifying if the system assigns the correct tax code.

For information about how to set up tax nexuses, codes or schedules, refer to the NetSuite Help Center or contact NetSuite Support.
