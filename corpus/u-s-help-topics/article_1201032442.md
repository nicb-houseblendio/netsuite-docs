The Sales Tax on Sales Detail report shows sales tax liabilities that have accrued on sales transactions for the date range you select. The liabilities on this report are grouped by transaction type, and the tax code applied to each transaction is shown. The report includes all nexuses in the selected subsidiary. You can customize the report to filter the nexuses. For example, to see sales tax for U.S. nexuses only, customize the report to filter out the non-U.S. nexuses.

The following columns are included in this report:

-   **Transaction Type** - This column shows the type of transaction in this group of line items.
    
-   **Transaction Date** - This column reports the date of each transaction.
    
-   **Transaction Number** - This column shows the transaction numbers for each sales transaction.
    
-   **Net Amount** - This column shows the net amount (without tax) for each transaction.
    
-   **Tax Code** - This column shows the tax code applied to each transaction.
    
-   **Tax Amount** - This column shows the tax amount from each transaction.
    

To see the Sales Tax on Sales Detail report, go to _Reports > Sales Tax US > Sales Tax on Sales > Detail_.

A message on the screen indicates that your report is loading. The status bar in the footer of the report indicates the progress as your report loads. You can click **Cancel Report** next to the status bar to stop the report from loading.
