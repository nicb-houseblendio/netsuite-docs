## Adding a U.S. State Nexus {#bridgehead_4283727458}

The steps for adding a U.S. state nexus differ depending on whether the Advanced Taxes feature is enabled or not.

#### To add a U.S. state nexus in accounts without Advanced Taxes: {#procedure_N2039412}

1.  On the Set Up Taxes page, click **Add New State**.
    
2.  On the State page:
    
    1.  Select a state from the dropdown list. The **Description** field is populated with he abbreviation for the state after you select a state.
        
    2.  Click **Save**.
        
3.  On the Set Up Taxes page:
    
    1.  Refresh the page to see the newly added U.S. state nexus.
        
    2.  Select the preferred tax agency and home tax code for the new state.
        
    3.  Click **Save**.
        

#### To add a state nexus in OneWorld accounts or accounts with Advanced Taxes:

1.  Go to _Setup > Accounting > Nexuses > New_.
    
2.  On the Nexus page:
    
    1.  In the **Country** field, select **United States**.
        
    2.  In the **State/Province/County** field, select the state that you want to add.
        
    3.  The **Description** field is populated with the abbreviation for the state after you select a value in the **State/Province/County** field.
        
    4.  Click **Save**. This new state nexus will now be available on the Set Up Taxes page for the United States.
        
3.  Click **Edit** on the Nexus page, select the preferred tax agency and home tax code, and click **Save**.
    
    Another way to assign the tax agency and home tax code is to go to _Setup > Accounting > Set Up Taxes_, and on the Set Up Taxes page:
    
    1.  Click the **United States** subtab.
        
    2.  Select the preferred tax agency and home tax code for the state.
        
    3.  Click **Save**.
        

## Deleting a U.S. State Nexus {#bridgehead_4283728489}

You can delete a U.S. state nexus if your account has the Advanced Taxes feature enabled.

Important:

Be sure that there are no transactions associated with a nexus that you want to delete. If any transactions are associated with a nexus, then you must first delete those transactions or modify them.

#### To delete a U.S. state nexus:

1.  Go to _Setup > Accounting > Nexuses_.
    
2.  Click the name of the state in the **Description** column.
    
3.  Click **Edit**.
    
4.  Point to Actions, and select **Delete**.
    
5.  Click **Save**.
