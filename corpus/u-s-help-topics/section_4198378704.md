## Overview {#bridgehead_4198379759}

The following help topics provide information about NetSuite features that are specific for companies doing business in U.S. The NetSuite International Edition can be configured with capabilities and reports specific to U.S. business setting and requirements.

To know more about localized editions of NetSuite, as well as setting up NetSuite accounts and subsidiaries, refer to the following help topics:

-   [NetSuite Editions Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N270055.html)
    
-   [Set up NetSuite OneWorld](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N268052.html)
    
-   [Creating Subsidiary Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N272471.html)
    
-   [Introduction to NetSuite OneWorld](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N266468.html) - for companies using NetSuite across multiple subsidiaries and countries
    

Please note that general NetSuite features are covered in other chapters and topics.

## General Setup {#bridgehead_156932216677}

[United States Account Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160283717546.html): Provides an overview of NetSuite features to be enabled by the user in U.S. and SuiteApps available for installation.

[Setting Up United States-Specific Preferences Page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160283719635.html): Set up your NetSuite company and user preferences for U.S., including date, currency, language, time zone, and support for U.S. number, phone, and address format.

## Functional Areas {#bridgehead_160283772127}

Users in United States can activate and get access to different features from the following functional areas:

-   [Taxation Features For Accounts with SuiteTax](#bridgehead_160309930702)
    
-   [Taxation Features For Accounts without SuiteTax](#bridgehead_4452529870)
    
-   [Payments](#bridgehead_160283788400)
    
-   [Order Management](#bridgehead_4198416197)
    

To learn more about SuiteApps installation, see [Installing a Bundle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3395142.html).

To learn more about enabling NetSuite features, see [Enabling Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N232138.html).

Important:

If you don't have sufficient permissions to install SuiteApps or enable features, please contact your account administrator.

## Taxation Features For Accounts with SuiteTax {#bridgehead_160309930702}

The following table describes taxation features in USA. These features are for accounts with SuiteTax. For more information, see [SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/preface_1496364245.html).

| Feature | Description | Prerequisites |
| --- | --- | --- |
| [Setting Up Nexuses in SuiteTax Engine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557741442.html) | Guides you through the process of setting up nexuses. | Your NetSuite account administrator must submit a SuiteTax enablement request and enable the SuiteTax feature in your NetSuite account. See [Enabling the SuiteTax Feature](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1513063459.html). Install the following SuiteApps:
-   SuiteTax Engine (see [Installing the SuiteTax Engine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557397007.html) and [Enabling the SuiteTax Plug-In](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557399475.html))
-   U.S. Sales Tax Reports (see [U.S. Sales Tax Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0831101353.html))

 |
| [Automatic Tax Records Provisioning for the United States](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557741485.html) | Creates tax records when you select SuiteTax as your tax engine. SuiteTax enables you to use different tax engines per nexus. To begin provisioning your tax records, assign a tax registration to the subsidiary or company in SuiteTax. |
| [Setting Up Tax Groups in SuiteTax Engine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1565954398.html) | Guides you through the process of setting up tax groups. |
| [Setting Up Tax Rate Types for the United States](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557741648.html) | Tax rate types are automatically provisioned by the SuiteTax Engine. For tax codes created outside of automatic provisioning, the tax rate type must be set during tax code creation. |
| [Setting Up Nexus Preferences for United States](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557741742.html) | In the SuiteTax Engine, you are able to set nexus preferences that determine the SuiteTax Engine's behavior when calculating taxes. |
| [Setting Up Entity Default Tax Codes and Tax Groups](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557742165.html) | Entity tax codes or tax groups are optional, and only required if you want to use a specific tax code or tax group for a customer or vendor. |
| [Roles and Permissions for the SuiteTax Engine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557399606.html) | The SuiteTax Engine supports assigning access, permissions, and permission levels to roles in NetSuite. |
| [Creating Exemption Certificates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0823123959.html) | The SuiteTax Engine provides support for tracking the tax exemptions allowed by respective US states. |
| [Creating Non-taxability Rules for Items](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557742237.html) | The SuiteTax Engine gives you the option to create a list of items that are generally non-taxable in a specific nexus. Item non-taxability rules are considered for tax determination. |
| [Tax Code Lookup Logic for United States](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557742280.html) | For each sales transaction, the SuiteTax Engine determines what tax code and rate to use for each item and calculates the tax amounts. |
| [U.S. Sales Tax Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0831101353.html) | The US Sales Tax Reports SuiteApp includes reports that enable users to view the taxes they must pay on all of their sales transactions. |
