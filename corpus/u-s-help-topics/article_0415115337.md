To use the File Ready Report - California, you must configure the report. The consolidated tax-relevant transaction information is generated in the report summary.

#### To configure and generate the File Ready Report - California:

1.  Go to Reports > Tax > US Sales Tax Reports.
    
2.  On the US Sales Tax Reports page, from the **Reports** list, select **File Ready Report - California**.
    
    Note:
    
    The fields in the report are not editable.
    
3.  Click **Next**.
    
4.  On the Country Tax Reports page, do the following:
    
    1.  From the **Subsidiary** list, select the required subsidiary.
        
    2.  From the **Nexus** list, select the required nexus.
        
    3.  From the **Report Name** list, select **File Ready Report - California**.
        
        Note:
        
        If you don't see File Ready Report - California in the **Report Names** list, check the country for the selected subsidiary or nexus. This report is only available when the subsidiary or nexus's country is set to United States. For more information, see [Prerequisites](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0323011445.html#bridgehead_0406023637).
        
    4.  From the **Start Period** list, select the start period for the report.
        
    5.  From the **End Period** list, select the end period for the report.
        
5.  Click **Generate**.
    
6.  On the Country Tax Report page, click **View** to open the generated report.
    
    The generated report summary opens. You can download the report in PDF file format from. Click an amount to view the drill down of the calculations.
