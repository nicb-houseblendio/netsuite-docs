For more information, see [Setting Up the SuiteTax Engine for the United States](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557741103.html).

To take advantage of all the features in the SuiteTax Engine, please configure the following:

-   Create a nexus, see [Setting Up Nexuses in SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160639612283.html)
    
-   Provision tax records, see [Automatic Tax Records Provisioning for the United States](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160639624915.html)
    
-   Set Up Tax Groups, see [Setting Up Tax Groups in SuiteTax Engine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1565954398.html)
    
-   Set up tax rate types, see [Setting Up Tax Rate Types for the United States](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160639631316.html)
    
-   Set nexus preferences, see [Setting Up Nexus Preferences for United States](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160639666119.html)
    
-   Set up entity default tax codes, see [Setting Up Entity Default Tax Codes and Tax Groups](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160639670636.html)
    
-   Set exemption certificates, see [Creating Exemption Certificates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160639676040.html)
    
-   Set the item non-taxability rules, see [Creating Non-taxability Rules for Items](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160639680662.html)
    
-   To find more about how the SuiteTax Engine determines which tax code to use, see [Tax Code Lookup Logic for United States](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160639686083.html)
