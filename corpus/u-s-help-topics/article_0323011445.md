The File Ready Report - California helps you prepare California sales tax returns using NetSuite transaction data. The report consolidates tax-relevant transaction totals into a file-ready format, reducing manual effort, minimizing confusion, and speeding up the tax filing process.

## Prerequisites {#bridgehead_0406023637}

Before you use and generate the File Ready Report - California, complete these tasks:

-   Install the Tax Reporting Framework SuiteApp. For more information, see [Installing Tax Reporting Framework](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1528245293.html).
    
-   On the subsidiary and nexus records, set the country to United States. If you do not set this value, the Country Tax Reports page does not show File Ready Report - California in the **Report Names** list.
    
    #### To set the country for a subsidiary:
    
    1.  Go to Setup > Company > Subsidiaries > New.
        
    2.  Fill in the required details.
        
        For more information about creating a subsidiary record, see [Creating Subsidiary Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N272471.html)
        
    3.  On the subsidiary record, from the **Country** list, select **United States**.
        
    4.  Click **Save**.
        
    
    #### To set the country for a nexus:
    
    1.  Go to Setup > Tax > Nexuses > New.
        
    2.  Fill in the required details.
        
        For more information about creating a nexus record, see [Creating a Nexus Record in SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4296038572.html#bridgehead_4296047186)
        
    3.  On the nexus record, from the **Country** list, select **United States**.
        
    4.  Click **Save**.
        
    
-   Verify that the city name in the billing address matches the value in the **City List** field on the city county mapping record. If these values don't match, NetSuite can't apply the correct city county mapping to the generated report
