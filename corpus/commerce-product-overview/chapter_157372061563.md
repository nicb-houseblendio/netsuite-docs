A Commerce website includes any of the following Commerce products.

-   SuiteCommerce MyAccount
    
-   SuiteCommerce
    
-   SuiteCommerce Advanced
    
-   Site Builder
    

You can create, preview, filter and edit sites based on the site type. Site type streamlines web site setup activities. It can even be used by developers to filter site records in various APIs such as SuiteScript or Commerce APIs. There are as many different site types as there are Commerce website products. These share some commerce-related functions, but also have some distinct features. The following table gives you a visual comparison of these products.
