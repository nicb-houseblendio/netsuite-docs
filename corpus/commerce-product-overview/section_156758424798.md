## Existing Site Filtering {#subsect_156758432246}

You can filter existing sites based on site type.

#### To filter for existing sites

1.  Go to _Commerce > Websites > Website List_.
    
2.  Click **Filters**.
    
3.  From the **Edition** dropdown list, select the edition you want.
    
    This dropdown list shows three options, these are: **All**, **Site Builder** and **Advanced**. The following table lists all products in each edition:
    
    | Edition | Products Included |
    | --- | --- |
    | Site Builder | Site Builder |
    | Advanced | SuiteCommerce SuiteCommerce MyAccount SuiteCommerce Advanced SuiteCommerce InStore |
    | All | SuiteCommerce SuiteCommerce MyAccount SuiteCommerce Advanced SuiteCommerce InStore Site Builder |
    

## Previewing Existing Sites {#subsect_157225517913}

The websites list page lets you quickly preview a site.

#### To preview a site

1.  Go to _Commerce > Websites > Website List_.
    
2.  On the Websites page, you can view all the sites available for your account.
    
3.  To preview a site, click the preview icon (the eye symbol) under the **Preview** column.
    

## Editing Existing Sites {#subsect_157225680462}

The Web Sites pages lets you select a site to edit.

#### To edit an existing site

1.  Go to _Commerce > Websites > Website List_.
    
2.  Click **Edit** next to the site name.
    
3.  Change or edit any of the available fields and information as required.
    
    Note:
    
    You can't change the website type. If you need a different type of website, you must create a new site.
    

If you need to inactivate or delete a website, see [Website Deletion and Inactivation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1559227298.html).
