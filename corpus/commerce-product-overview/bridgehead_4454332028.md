SuiteCommerce InStore (SCIS) is a web-based point-of-sale application. It provides a touch-based user interface for tablet devices such as iPads. Dedicated point-of-sale hardware is not required. SCIS supports common point-of-sale peripherals including credit card readers, printers, bar code scanners, and cash drawers.

For more information, see [SuiteCommerce InStore (SCIS)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/preface_156865988957.html).
