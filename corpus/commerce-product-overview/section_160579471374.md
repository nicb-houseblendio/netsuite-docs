From the 2021.1 release onwards, all Commerce-related features are accessible on the Commerce tab in the navigation menu.

![Commerce menu opened from main navigation bar.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/CommerceMenu.png)

The menus you see in the Commerce tab depend on the Commerce products enabled in your account. For example, if Site Builder isn't enabled, the Site Builder menu won't appear. To see a list of all tasks available under the Commerce tab, click Commerce in the navigation menu bar and then click Expand All.

To identify the new navigation path for the task you need, use the following reference. It is organized by the menu path location prior to 2021.1:

-   [Setup > SuiteCommerce Advanced](#subsect_160621760844)
    
-   [Setup > Site Builder](#subsect_160621767640)
    
-   [Lists > Web Site](#subsect_160621799911)
    
-   [Others](#subsect_160622793418)
    
    Navigation paths for Commerce-related tasks from the following locations. These paths continue to exist in the original locations but also appear under the Commerce tab for easy access:
    
    -   Setup > Marketing
        
    -   Lists > Marketing
        
    -   Lists > Accounting
        
    -   Lists > Relationships
        

Note:

Navigation paths for Commerce-related bundles are being moved to the Commerce tab. Until this is complete, some paths may still be available in the pre-2021.1 location.
