Mexico Complementary Features is a public and managed SuiteApp that's automatically updated whenever enhancements or new features are added. To install this SuiteApp, you must have permission and access to the SuiteApp Marketplace. For more information about viewing SuiteApps listed in the Marketplace, see [Viewing SuiteApps in the SuiteApp Marketplace](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1539797977.html).

#### To install the Mexico Complementary Features SuiteApp: {#procedure_0316095130}

1.  In NetSuite, go to SuiteApps.
    
2.  In the **Search Apps** input field, enter **Mexico Complementary Features**.
    
3.  Click **Mexico Complementary Features**.
    
4.  In the top right of the SuiteApp details page, click **Install**.
    
5.  Wait for the installation to complete.
    
    To understand the installation status, read the help topic [Installing from the SuiteApp Marketplace](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1539799323.html).
    
6.  Update to the latest version of the invoice and cash sale templates by going to Setup > Mexico Localization > Mexico Localization Components. You should update the template only for your active PACs.
    

Note:

The Administrator, Accountant, and CFO standard roles must be set to active so the installation can run correctly.

## Granting Access to Scripts and Plug-ins for the Mexico Complementary Features SuiteApp {#subsect_37111819736}

If you have the Administrator role, you can grant access to script deployments for Mexico Complementary Features.

#### To grant access to script deployments for the Mexico Complementary Features SuiteApp: {#procedure_0327045554}

1.  Go to Customization > Scripting > Script Deployments.
    
    Note:
    
    The standard roles such as Administrator, Accountant, CFO roles, and roles derived from them have granted access to script deployment for Mexico Complementary Features by default.
    
2.  To provide roles with access to the Mexico Complementary Features Setup feature, do the following:
    
    1.  Click the **Edit** link next to the script deployments that start with customscript\_mcf.
        
    2.  On the **Audience** subtab, click the roles to which you want to give access.
        
    3.  Click **Save**.
