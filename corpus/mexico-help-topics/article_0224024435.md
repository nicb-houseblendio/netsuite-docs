To use the Mexico Certification Tax Authorities SuiteApp, ensure your account meets all the prerequisites listed on this page: [Installation Prerequisites for Mexico Localization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160510306962.html).

In addition to meeting the Mexico Localization SuiteApp prerequisites, do the following:

-   Install the LATAM E-Document Certification SuiteApp. Please see [LATAM E-Document Certification SuiteApp Installation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160320094693.html).
    
-   Install the Mexico Complementary Features SuiteApp. Please see [Mexico Complementary Features Installation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0109105205.html).
    

Important:

You can install and use the Mexico Certification Tax Authorities SuiteApp only in OneWorld accounts with SuiteTax enabled.
