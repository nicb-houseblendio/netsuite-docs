Before using the Mexico Certification Tax Authorities SuiteApp, be aware of the current limitations and best practices.

## Known Limitations {#bridgehead_0224033056}

-   Only invoice cancellation is supported. If an invoice includes inventoried items, those items must already have been delivered (fulfilled) to proceed with the cancellation.
    
-   The reason for cancellation 04 is not supported.
    
-   Bulk cancellation of transactions is not supported.
    
-   Deferred taxes do not currently support canceled transactions, so they need to be manually reclassified.
    

## Best Practices {#bridgehead_0806102243}

-   When using the **Autotamic Certify E-Document MR** script to check and update the status of canceled transactions, please note that the script checks for all transactions, not only the ones pending to be canceled, so it should only be used in cases of high volume of canceled transactions.
