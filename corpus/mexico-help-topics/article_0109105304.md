To use the Mexico Complementary Features SuiteApp, ensure your account meets all the prerequisites listed on this page: [Installation Prerequisites for Mexico Localization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160510306962.html).

Important:

You can install and use the Mexico Complementary Features SuiteApp in these different configurations:

-   OneWorld accounts with SuiteTax enabled.
    
-   OneWorld accounts without SuiteTax enabled.
    
-   Accounts that are not OneWorld and without SuiteTax enabled.
    

In addition to meeting the Mexico Localization SuiteApp prerequisites, do the following:

-   Install the Localization Assistant SuiteApp. For more information, see [Localization Assistant SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_163092114640.html).
    
-   Enable the **Custom GL Lines** feature. For more information, see [Enabling SuiteGL Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1114080428.html).
