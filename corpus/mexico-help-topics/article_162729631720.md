To use the Mexico Bill of Lading (Complemento Carta Porte) SuiteApp, ensure your account meets all the prerequisites listed on this page: [Installation Prerequisites for Mexico Localization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160510306962.html).

Important:

You can install and use the Mexico Bill of Lading (Complemento Carta Porte) SuiteApp in these different configurations:

-   OneWorld accounts with SuiteTax enabled.
    
-   OneWorld accounts without SuiteTax enabled.
    
-   Accounts that are not OneWorld and without SuiteTax enabled.
    

In addition to meeting the Mexico Localization prerequisites, do the following:

-   Install the Localization Assistant SuiteApp. For more information, see [Localization Assistant SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_163092114640.html).
    
-   Configure the addresses you will be including on the bill of lading document (complemento carta porte). These are the origin and destination addresses of the goods. For more information, see [Entering or Editing an Address for Mexico Bill of Lading](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_162852625617.html).
    
-   Configure the SAT operators. For more information, see [Managing Operators Information](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163094114256.html).
    
-   Configure the fleet you will be using for moving goods. For more information, see [Managing Mexico Fleet Codes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_162730577285.html).
