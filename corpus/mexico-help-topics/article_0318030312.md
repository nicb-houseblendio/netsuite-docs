Note:

All amounts entered in foreign currencies are reported in Mexican pesos (MXN) based on the applicable exchange rate.

If you want journal entries to appear in the **Mexico DIOT 2025** report, you first need to create a custom form.

#### Creating a custom journal entry form:

1.  Go to Transactions > Financial > Make Journal Entries.
    
2.  On the Journal page, hover over **Customize**, and then click **Customize Form**.
    
3.  On the Custom Transaction Form page, in the **Name** field, enter **Mexico Standard Journal Entry (Custom Form)**.
    
4.  On the Screen Fields subtab, click the **Lines** subtab.
    
    Ensure that the following required fields are checked on the custom form:
    
5.  Under the **Show** column, ensure that boxes of the following required fields are checked on the custom form:
    
    -   Vendor
        
    -   Operation Type
        
    -   SAT Item Type
        
    -   SAT Item Code
        
    -   Tax Code
        
    -   Tax Rate
        
    -   Tax Account
        
    -   Included in DIOT 2025 Report
        
6.  Click **Save**.
    

For more information about creating custom transaction forms, see [Creating Custom Entry and Transaction Forms](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2853340.html).

When creating journal entries for inclusion in the **DIOT 2025** report, ensure the following:

-   If you increase an amount in the **Debit** column, ensure you also increase the **Tax Base** and **Tax Amount** values.
    
-   If you increase an amount in the **Credit** column, ensure you decrease the **Tax Base** and **Tax Amount** values.
    

Important:

For each journal entry you want to include, check the **Included in DIOT 2025 Report** box on the Journal Entry page. Only journal entries with this box checked are included in the report.
