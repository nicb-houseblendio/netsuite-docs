## Enabling the Mexico Complementary Features GL Lines Plug-in {#subsect_73112954492}

When you cancel electronic invoices, Mexico Foreign Trade uses a Custom GL Lines Plug-in to post additional lines to the general ledger. This custom plug-in is provided by the Mexico Complementary Features SuiteApp.

To deploy the Custom GL Lines Plug-in, you must first enable the plug-in on your account.

#### To enable the GL lines plug-in:

1.  Go to _Customization > Plug-ins > Manage Plug-ins_.
    
2.  Under Custom GL Lines Plug-in, check the **MCF GL Lines Plugin Implementation** box.
    
3.  Click **Save**.
    

## Setting Up the Mexico Complementary Features GL Lines Plug-in {#subsect_87112950091}

After enabling the plug-in, you must set up its deployment record.

#### To set up the custom GL lines plug-in:

1.  Go to _Customization > Plug-ins > Plug-in Implementations_.
    
2.  Click **View** next to the **MCF GL Lines Plugin Implementation** (ID: `customscript_mcf_pl_customgl`) plug-in implementation record.
    
3.  Click **Configure**.
    
    The custom GL lines: configuration record opens.
    
4.  Click the **Execution Rules** subtab.
    
5.  In the **Transaction Type** field, check the **CFDI Invoice Cancellation** box.
    
6.  In the **Subsidiaries** field, select the applicable Mexican subsidiaries.
    
7.  Click **Save**.
    

## Configuring the Monitoring Plug-in {#bridgehead_0813104620}

Before creating sending methods, you need to configure the monitoring plug-in.

#### To configure the monitoring plug-in:

1.  Go to Customization > Plug-ins > Plug-in Implementations > New.
    
2.  Select the script file **mcf\_pl\_cert\_monitor.js**.
    
3.  In the **Type** field, select **Certification Monitoring Plug-in Type**.
    
4.  In the **Name** field, enter **Mexico Monitoring Plugin**.
    
5.  In the **Status** field, select **Released**.
    
6.  Click **Save**.
    

## Creating Cancellation E-Document Sending Methods for Mexico {#bridgehead_0311043549}

To certify the cancellation of electronic invoices with the Mexican tax authorities, create an e-document sending method record for Mexico.

#### To create a cancellation e-document sending method:

1.  Go to Setup > E-Documents > E-Document Sending Methods > New.
    
2.  In the **Name** field, enter the corresponding PAC as the name for the e-document sending method.
    
    1.  **Solución Factible Cancellation Sending Method**
        
    2.  **MySuite Cancellation Sending Method**
        
3.  In the **E-Document Package** field, select the corresponding package for each PAC.
    
    1.  **Solución Factible E-document Package**
        
    2.  **MySuite E-document Package**
        
4.  In the **E-Document Sending Method Plug-in Implementation** field, select **MX PI PAC Certify**.
    
5.  In the **Subsidiary** field, select the corresponding subsidiary.
    
6.  In the **Sending Channel** field, enter **SOAP**.
    
7.  In the **Transaction Type** field, select the following transaction types:
    
    -   CFDI Invoice Cancellation
        
8.  Check the **Sending Method for Certification** box.
    
9.  Click **Save**.
    

For more information about sending methods, see [Creating E-Document Sending Methods](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4536875049.html).

## Configuring accounts in the PAC Configuration {#bridgehead_0422025122}

To follow with the configuration needed for the certification of invoice cancellation for Mexico, the default accounts that apply for cancellation must be setup.

#### To set up cancellation accounts:

1.  Go to Setup > Accounting > Accounting Preferences.
    
2.  In the **Items/Transactions** tab, select the corresponding accounts for the following fields:
    
    1.  In the **Default Income Account** field, select Sales.
        
    2.  In the **Default Asset Account** field, select Inventory.
        
3.  Click **Save**.
    

#### To configure accounts in the PAC Configuration:

1.  Go to Setup > Mexico Localization > PAC Configuration
    
2.  Select the corresponding e-document package and click **Edit**.
    
3.  In the **Invoice** tab, go to the Cancellation Accounts Setup subtab.
    
4.  Select the Returned Sales and Returned Inventory accounts.
    
5.  Click **Save**.
    

## Adding the Monitoring Plug-in Implementation {#bridgehead_0522122723}

To set up your tax authority, you must first ensure the monitoring plug-in implementation is set up in the Tax Authority Certification Service record.

#### To add the plug-in implementation:

1.  Go to Setup > E-Document Certification > Tax Authority Certification Service > Search.
    
2.  Click **List** in the upper right corner.
    
3.  Click **Edit** next to the tax authority you want to update.
    
4.  In the **Certification Monitoring Plug-in Implementation** field, select **Mexico Monitoring Plugin**.
    
5.  Click **Save**.
    

Complete this task for both MySuite Tax Authority and Solución Factible Tax Authority.

## Creating an API Secret for E-document Certification {#bridgehead_0522112916}

To improve the security of the credentials you store in NetSuite, you should encrypt the Username and Access Pass custom fields.

To enable the encryption, create an API secret and enter its ID on the e-document certification settings record associated with the SAT certification service. Ensure that the API secret password has 16, 24, or 32 bytes. If the API secret ID is missing or invalid, certification requests may fail due to encryption or authentication errors.

For more information, see [Creating Secrets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160216498405.html) and [Defining E-Document Certification Settings](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160527596799.html).

## Adding Mexico Certification Custom Fields {#bridgehead_0422030444}

The Mexico Tax Authority (SAT) provides you with authentication credentials when you register your company to certify e-documents with the city. The tax authority uses this information to authenticate your request for certification.

To include the credentials on the certification requests you send to Mexico, create certification custom fields on the city's e-document certification settings record.

You should do this for all subsidiaries that send e-documents for certification to Mexico, both in test and production environments.

Important:

Use the exact custom field keys **Username** and **Access Pass** for the certification custom fields.

Do not use legacy values such as PAC\_USER or PAC\_PASS. These values are no longer supported for Mexico certification and may result in authentication failures.

If you have legacy values for your custom field keys, it is recommended you delete those credentials and recreate the custom fields with the correct custom field keys.

#### To add Mexico certification custom fields:

1.  Go to Setup > E-Document Certification > Tax Authority Certification Service > Search.
    
2.  Click **List** in the upper right corner.
    
3.  Find the corresponding tax authority certification service record and click **View**.
    
4.  Click the **Certification Settings** subtab.
    
5.  Find the e-document certification settings you want, and then click **Edit**.
    
6.  Add your username and password information.
    
    1.  For Solución Factible Tax Authority:
        
        1.  Click the **Custom Fields** subtab.
            
        2.  Click **New Certification Custom Fields**.
            
            A certification custom fields record opens.
            
        3.  In the **Custom Field Key** field, enter **Username**.
            
        4.  In the **Custom Field Value** field, enter the company's username.
            
        5.  Check the **Encrypt Custom Field Value** box.
            
        6.  Click **Save**.
            
        7.  Click the **Custom Fields** subtab.
            
        8.  Click **New Certification Custom Fields**.
            
            A certification custom fields record opens.
            
        9.  In the **Custom Field Key** field, enter **Access Pass**.
            
        10.  In the **Custom Field Value** field, enter the company's access pass.
             
        11.  Check the **Encrypt Custom Field Value** box.
             
        12.  Click **Save**.
             
    2.  For MySuite Tax Authority:
        
        1.  Click the **Custom Fields** subtab.
            
        2.  Click **New Certification Custom Fields**.
            
            A certification custom fields record opens.
            
        3.  In the **Custom Field Key** field, enter **Username**.
            
        4.  In the **Custom Field Value** field, enter a dummy name.
            
        5.  Check the **Encrypt Custom Field Value** box.
            
        6.  Click **Save**.
            
        7.  Click the **Custom Fields** subtab.
            
        8.  Click **New Certification Custom Fields**.
            
            A certification custom fields record opens.
            
        9.  In the **Custom Field Key** field, enter **Access Pass**.
            
        10.  In the **Custom Field Value** field, enter the company's user name.
             
        11.  Check the **Encrypt Custom Field Value** box.
             
        12.  Click **Save**.
             

Values for custom fields can be obtained from your PAC Configuration settings.
