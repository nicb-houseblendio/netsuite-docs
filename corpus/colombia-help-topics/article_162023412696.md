To create the predefined tax determination rules from the SuiteTax Latam Engine - Colombia Records SuiteApp, you must import the CSV files to your account.

For each set of rules, you must upload two CSV files:

-   First, upload the CSV file that creates the tax determination rules records.
    
-   Then, upload the CSV file that creates tax determination settings related to the rules.
    

Importing the CSV files out of the prescribed order may cause import issues.

To import the CSV files, your role needs both the permissions to perform imports, as well as permissions to access the record types you're creating with the import. For more information, see the following help topics:

-   [Importing CSV Files with the Import Assistant](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N343158.html)
    
-   [Roles and Permissions for the SuiteTax Latam Engine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_162040661540.html)
    

For more information about how to import the files, see the following topics.

-   [Importing Predefined Tax Determination Rules for Colombia](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_162135025016.html)
    
-   [Importing Predefined Tax Determination Settings for Colombia](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_162135026697.html)
