The SuiteTax Latam Engine - Colombia Records SuiteApp is a managed SuiteApp. Whenever there are enhancements or new features added, NetSuite automatically updates your account.

You need permission and access to the SuiteApp Marketplace to install this SuiteApp. For more information, see [Viewing SuiteApps in the SuiteApp Marketplace](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1539797977.html).

Before you install SuiteTax Latam Engine - Colombia Records, ensure you meet the prerequisites for installation. For more information, see [Prerequisites for Installing the SuiteTax Latam Engine - Colombia Records SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_161970457034.html).

#### To install the SuiteTax Latam Engine - Colombia Records SuiteApp:

1.  In NetSuite, go to SuiteApps.
    
2.  In the **Search SuiteApps** field, enter **SuiteTax Latam Engine - Colombia Records**.
    
3.  Click **SuiteTax Latam Engine - Colombia Records**.
    
4.  At the top-right area of the SuiteApp details page, click **Install**.
    
5.  Wait for the installation to complete.
    
    Tip:
    
    After the installation is complete, verify the status of the import that creates the predefined records. For more information, see [Verifying the Import Status of the Colombia Predefined Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_162023200235.html).
    

For more information about the SuiteApp installation process, see [Installing from the SuiteApp Marketplace](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1539799323.html).
