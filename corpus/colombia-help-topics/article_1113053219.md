The SuiteTax Latam Engine - Colombia Records SuiteApp provides predefined plug-ins and records required to calculate taxes for companies operating in Colombia. To leverage the SuiteTax Latam Engine - Colombia Records capabilities, you need specific permissions.

For more information about the roles and permissions for the SuiteApp, see the following help topics:

-   [Default Permission for SuiteTax Latam Engine - Colombia Records](#subsect_1113053432)
    
-   [Required Permission for SuiteTax Latam Engine - Colombia Records](#subsect_1113053445)
    

In addition to the specific SuiteTax Latam Engine - Colombia Records permissions, you also need SuiteTax Latam Engine permissions. For more information, see [Roles and Permissions for the SuiteTax Latam Engine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_162040661540.html).

## Default Permission for SuiteTax Latam Engine - Colombia Records {#subsect_1113053432}

SuiteTax Latam Engine - Colombia Records doesn't include custom roles. By default, the SuiteApp grants the following permission to the standard Administrator role:

-   **Subtab** - Custom Record
    
-   **Permission** - UVT Value
    
-   **Access level** - Full
    

## Required Permission for SuiteTax Latam Engine - Colombia Records {#subsect_1113053445}

If you're not an administrator, you need the following permission to create transactions with SuiteTax Latam Engine - Colombia Records tax calculation:

-   **Subtab** - Custom Record
    
-   **Permission** - UVT Value
    
-   **Minimum access level** - View
