If you set the UVT parameter type in Colombian tax codes, you must define the current Unidad de Valor Tributario (UVT) value in NetSuite.

The UVT value is established each year by the Dirección de Impuestos y Aduanas Nacionales (DIAN).

Each time the value changes, you need to create a new UVT value record in NetSuite.

#### To define the UVT value:

1.  Go to Lists > Colombia Tax Information > UVT Value > New.
    
2.  In the **Name** field, enter a name for the record.
    
    For example, you can mention the year to which the value applies.
    
3.  In the **Value** field, enter the amount in Colombian pesos that one UVT represents in the selected effective period.
    
4.  In the **Effective From** field, select the date when the defined value for the UVT starts being effective.
    
5.  In the **Effective Until** field, select the date when the defined value for the UVT stops being effective.
    
    After this date, the value for the UVT no longer applies to your NetSuite transactions.
    
6.  Click **Save**.
