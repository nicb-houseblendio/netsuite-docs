The Colombia Localization SuiteApp provides custom fields, validations, and other customizations to help Colombian businesses meet tax and other government requirements in Colombia.

The Colombia Localization SuiteApp includes the following:

-   Colombia Localization custom fields
    
-   Colombia Localization custom forms
    
-   Creating customers and vendors
    
-   Creating employees
    
-   Creating items
    

For updated exchange rates, check with the Superintendencia Financiera (Financial Superintendence)

## Colombia Localization Custom Fields {#bridgehead_164252057142}

The Colombia Localization custom fields are available when the Colombia context applies.

For more information about Colombia context, see [Colombia Context](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_164251996938.html).

## Colombia Localization Custom Forms {#bridgehead_164252068909}

The Colombia Localization SuiteApp provides the following custom forms:

-   Colombia Standard Invoice
    
-   Colombia Standard Sales Order
    
-   Colombia Standard Contact Form
    
-   Colombia Standard Customer Form
    
-   Colombia Standard Employee Form
    
-   Colombia Standard Vendor Form
    

You can set these custom forms as the default for specific user roles. For more information, see [Defining Preferred Forms](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2873968.html)

For detailed information about how to customize a transaction form, see [Creating Custom Entry and Transaction Forms](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2853340.html)

The SuiteApp comes with an advanced PDF template. To customize it, go to Customizations > Forms > Advanced PDF/HTML Templates and search for **Colombia (transaction) PDF Template**. For more information about the Advanced PDF/HTML Templates feature, see [Advanced PDF/HTML Templates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4453550706.html).

Important:

When customizing a Colombia transaction form, select the **Standard (transaction) PDF/HTML Template** from the dropdown list. Don't select the **Colombia (transaction) PDF Template** on this record. The **Colombia (transaction) PDF Template** is used for Certification processes and therefore must be specified on the Electronic Invoicing Setup record only. For the **Print Template,** select **Proveedor Tecnológico PDF Template.**

You can send the generated e-documents (XML and PDF) to your customers. For more information, see [Sending and Resending E-Documents](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4576956606.html).

To learn more about the outbound electronic invoicing process, see [Outbound Electronic Invoicing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4536869579.html#bridgehead_1494832893).

## Creating customers and vendors {#bridgehead_164252090254}

By default, NetSuite creates customers and vendors as companies (is person = F). When you create a customer (for interested customers, the values to fill in are optional), vendors partner, or other entity, make sure you fill in the following information.

#### To create customers and vendors: {#procedure_0102044808}

1.  In the Primary Information field group, leave the **Auto** box checked so that the name can be linked to the TIN or entity ID number.
    
2.  Select the **Subsidiary**.
    
3.  Fill in the **First Name**, **Second Name**, **Last Name**, and **Second Last Name**.
    
    1.  In the Primary Information field group, enter the **Company Name**.
        
    2.  Legal entity (Jurídica) - In the primary information field group, enter the **Company Name**.
        
4.  Select the **Colombia Document Type** and the system will identify the DIAN code for each type of document.
    
5.  **Colombia Identification Number**: This field populates after saving the record and after the information in the Financial subtab > Tax Registrations is fulfilled.
    
6.  **Colombia Verification Digit**: It's calculated by NetSuite after saving the entity, only when the document type corresponds to the DIAN codes 13 and 31.
    
7.  Enter the **Invoicing Email** address where the invoicing files should be sent to.
    
8.  Select the **Tax Regime**. It should indicate if the entity is liable for VAT or not.
    
9.  Select the **Tax Scheme** corresponding to the company.
    
10.  Select the **DIAN Taxpayer's Obligations** assigned by the DIAN in the RUT.
     
11.  : Check the **Is Consortium?** box to identify if the entity is a Consortium; if so, on the tab Relationships > Consortium assign the participant and the corresponding participation percentage.
     
12.  On the Financial subtab > Tax Registrations subtab, select the following fields:
     
     1.  **Country** - the country that the Entity belongs to.
         
     2.  **State** - if applies for that country.
         
     3.  **Nexus** - it's auto filled according to the selected country.
         
     4.  **Tax Reg. Number** - the TIN or entity identification number.
         
13.  On the Address subtab, assign the information about the entity's location and the Department and Municipality (city) fields. The DIAN uses numeric codes to identify its states and municipalities (cities), but you'll see their names on the User interface.
     

## Creating Employees {#bridgehead_164252120545}

Follow the steps to create an employee.

#### To create an employee: {#procedure_0102054707}

1.  In the Primary Information field group, leave the **Auto** box checked.
    
2.  Select the **Subsidiary**.
    
3.  In the Colombia field group, enter the **First Name**, **Second Name**, **Last Name**, and **Second Last Name**.
    
4.  Select the **Colombia Document Type** and the system will identify the DIAN code for each type of document.
    
5.  **Colombia Identification Number**: This field is equivalent to the Tax ID generated by the system by default.
    
6.  **Colombia Verification Digit**: It's calculated by NetSuite only after saving the entity.
    
7.  On the Address subtab, enter the Department and Municipality (city). The DIAN uses numeric codes to identify its states and municipalities (cities), but you'll see their names on the User interface.
    

## Creating Items {#bridgehead_164252135011}

To create an export item, fill in the following fields:

-   **Brand - Colombia**
    
-   **DIAN Electronic Inv. Code**
    
-   **Tariff Heading**
    

After assigning these fields on the items, the information will be reflected on the transaction line.

## Currency Exchange Rate Update {#bridgehead_164252140386}

The Colombia Localization SuiteApp automatically updates exchange rates from dollars to Colombian pesos in NetSuite's Currency Exchange Rates register. The script runs every day at 1 am, based on your NetSuite time zone settings.

If you want to change when it runs, go to Customization > Scripting > Script Deployments > CO | Actualizar TRM, customdeploy\_co\_update\_trm\_sc\_dp
