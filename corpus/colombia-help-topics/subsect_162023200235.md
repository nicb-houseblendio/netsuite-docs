After the SuiteTax Latam Engine - Colombia Records SuiteApp installation is complete, the import of the predefined records provided by the SuiteApp starts automatically.

Two script deployment records run in your account to import the predefined records.

The **FTECO SDF Installer** script (Script ID `customscript_fteco_sdf_installer`) directly creates the following record types:

-   Nexus
    
-   Tax code
    
-   Tax type
    

The **FTECO SC SDF Installer** script (Script ID `customscript_fteco_sc_sdf_installer`) triggers the CSV import that creates the predefined records for the following record types:

-   Item code
    
-   Line of business
    
-   Parameter type
    
-   Tax regime
    

The predefined nexus provided is for the country of Colombia. The predefined tax type and tax code records include the taxes mentioned in the [SuiteTax Latam Engine - Colombia Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161970452622.html). The predefined item code, line of business, and tax regime records include the main economical activities and items from Colombia.

Before you start using the SuiteTax Latam Engine - Colombia Records SuiteApp, you must verify the status of the import. The SuiteApp is ready to use after NetSuite completes the import.

#### To verify the import status of the predefined records:

1.  Go to _Setup > Import/Export > View CSV Import Status_.
    
2.  In the Job Status list, verify the status information for the following jobs:
    
    -   CUSTOMRECORD\_FTE\_ITEMCODE
        
    -   CUSTOMRECORD\_FTE\_LOB
        
    -   CUSTOMRECORD\_FTE\_PARAMTYPE
        
    -   CUSTOMRECORD\_FTE\_TAXREGIME
        
3.  Wait until you can see the following information for the jobs:
    
    -   The **Status** column is set as **Complete**
        
    -   The **Percent Complete** column is set as **100%**
        
    -   The **Message** column states that all records were imported successfully
        

Tip:

If predefined records are missing from your account, review the execution log of their respective script. In the execution log, you can verify if errors occurred. For more information, see [Using the Script Execution Log Subtab](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4375896105.html).
