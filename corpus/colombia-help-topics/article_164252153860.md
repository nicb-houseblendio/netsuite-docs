This document is used to accredit the purchase of a good or service. The buyer must generate it when doing transactions with a vendor who isn't obligated to issue a sales invoice or an equivalent document.

## Technical-administrative Prerequisites {#bridgehead_164259871320}

For this module's proper functioning, the Colombia Localization package must be installed. This module uses libraries in the package. The initial configuration is also needed.

## Prerequisites Setup {#bridgehead_164259873845}

#### To set up the prerequisites for the Support Document {#procedure_1212011057}

1.  Go to Setup > Colombia Localization > Support Document Setup > New. Complete the subsidiary the setup applies to, the language, and the advanced template used to render the PDF.
    
2.  Set up the [Electronic Invoicing Numbering Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_164252150679.html#bridgehead_164259707261) record to configure the DIAN's authorization. This setup should be done on the Vendor Bill.
    
3.  Set up the resolution title and description if applies. Go to Customization > Translations > Manage Translations. Click the **Strings** tab and select **CO Support Document** from the **Collection** list. Now select the authorization and title labels to set them up according to each customer needs.
    

## Development Feature Description {#bridgehead_164259890902}

To generate a support document, create a vendor invoice transaction. Then you must select the resolution that was previously set up, on the **CUFE Information** tab, and check the **Support Document** box. With this, a resolution number will be assigned to the document. After clicking **Save** , the button for generating the support document appears.

## Requirements for the Support Document {#bridgehead_45110228517}

**What is the Support Document?**

It's the document used to prove the purchase of a good or service. The buyer must generate it when making transactions with a service provider that isn't required to issue a sales invoice or an equivalent document.

**When should you generate one?**

The buyer must issue a support document to register the transaction that generates deductible taxes or operating costs. The document contains a number authorized by the DIAN when the vendor or service provider isn't obliged to issue an invoice.

Colombia has the following technological service providers (authorized by the DIAN) to certify this document:

-   Gosocket
    
-   Facture
    
-   Dispapeles
    

For more information, go to Setup > Colombia Localization > Electronic Invoicing Setup.

You can only use one DIAN-authorized technological service provider at a time. Make sure to inactivate any others you're not using.

As mentioned before, the vendor needs to have information in the **E-document package** field, based on the technological service provider selected before.

When you've filled all the information for the setup, vendor, and bill, you can create the transaction and certification. After that, you'll see the PDF and XML files on the **E-Document** subtab.
