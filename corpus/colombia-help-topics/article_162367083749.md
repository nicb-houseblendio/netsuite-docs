## Overview {#bridgehead_162367102914}

The following help topics give you information about NetSuite features made for companies doing business in Colombia. You can set up the NetSuite International Edition with features and reports tailored for Colombian business needs.

To know more about localized editions of NetSuite, or how to set up NetSuite accounts and subsidiaries, refer to the following help topics:

-   [NetSuite Editions Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N270055.html)
    
-   [Set up NetSuite OneWorld](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N268052.html)
    
-   [Creating Subsidiary Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N272471.html)
    
-   [Introduction to NetSuite OneWorld](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N266468.html) - for companies using NetSuite across multiple subsidiaries and countries
    

Please note that general NetSuite features are covered in other chapters and topics.

## Required Licenses {#bridgehead_164845688707}

To install the Colombia Localization SuiteApp, make sure you have the NetSuite SuiteApps License Client and a OneWorld account set up.

#### To access the features of the Colombia Localization SuiteApp:

1.  Install the NetSuite SuiteApp License Client (Bundle ID 116144)
    
2.  Obtain a license for the Colombia Localization SuiteApp - contact your account manager and they'll set it up for you.
    
3.  Verify that the NetSuite SuiteApp License Client has the NetSuite Colombia Localization license.
    

If the license client isn't installed or your license expires, you won't be able to use the SuiteApp features. For more information see [NetSuite SuiteApps License Client Guide for Administrators](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4635371677.html)

Contact your account representative to reinstate any state licenses.

## Purchasing {#bridgehead_162367138321}

| Subarea | Feature | Description | Prerequisites |
| --- | --- | --- | --- |
| Vendor Bill | Support document setup for people not liable for VAT | This document confirms the purchase of a product or service, and the buyer must generate it when doing transactions with a vendor who isn't required to issue a sales invoice or a similar document. | Install the Colombia Localization SuiteApp. For more information, see [Installing the Colombia Localization SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_162367074300.html#bridgehead_164251859010) |
| Vendor Bill Expense Report | Manual third-party assignment | It informs you about the account payments or deposits made through a third party. For petty cash, contract of mandate invoices, expense reports, travel expenses, where the account payable must be registered under a third party and the line-item expenses under other related third parties, check the **Manual Third-party Assignment** box. This feature allows third parties assigned in the **Third Party Entity**' field to be reported in the Magnetic Media information. Important: Make sure the **Third-Party Entity** field is enabled for all the transaction forms both at the line and header level. If you're doing an expense report with a CSV import, check the **Manual Third-party Assignment** box, so that you can assign the third party during the transaction in the **Third Party** field. | Install the following SuiteApps:
-   Colombia Localization SuiteApp. For more information, see [Installing the Colombia Localization SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_162367074300.html#bridgehead_164251859010)

After you intall the SuiteApp, set up the custom GL Plug-In **CO/Reclassification Taxes** by clicking the Configure button. Select all transactions and subsidiaries, save the setup under the **Manage Plug-In Implementations** screen, select the plug-in, and save again to make sure everything works right. |

Note:

The CO/Reclassification Taxes GL Plug-in is deployed over the Vendor Bill and Expense report transactions to reclassify the GL Impact movements to a third-party entity. They're later reported on the Magnetic Media Reports to meet the DIAN requirements.
