The SuiteTax Latam Engine - Colombia Records SuiteApp offers a set of predefined SuiteTax Latam Engine plug-ins. These plug-ins enable you to calculate several taxes on goods and services in Colombia with the SuiteTax Latam Engine tax engine.

For the plug-ins to run on transactions, the applicable tax determination rules and settings must meet requirements such as:

-   Tax code's internal name
    
    For more information about internal names, see [Associating a SuiteTax Latam Engine Plug-in Implementation With a Tax Code](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_162645934764.html).
    
-   Parameter types
    
    For more information, see [Parameter Types for Colombia](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1226030407.html).
    
-   Subsidiary tax information
    
    For more information, see _Associating Tax Regime and Line of Business with Subsidiaries_.
    

Consider the requirements and parameters of each tax plug-in when you create and set up your tax determination rules and settings.

For more information about the predefined plug-ins, see the following help topics:

-   [IVA Colombia Plug-in](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1226033047.html)
    
-   [RETEFUENTE Colombia Plug-in](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1226033130.html)
    
-   [RETEICA Colombia Plug-in](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1226033153.html)
    
-   [RETEIVA Colombia Plug-in](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1226033144.html)
