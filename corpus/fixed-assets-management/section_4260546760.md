The Asset Proposal record contains values for the primary book. Values on the **FAM Proposal Alt Depreciation** subtab are sourced from the Asset Type's secondary book.

![Other methods subtab in the Asset Proposal record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Accounting/FixedAssetsManagement/MB_ProposalOtherMethods.png)

You can edit the Asset Proposal record to change the default general ledger accounts or proposal values per book. For more information, see [Asset Proposal and Generation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2155572.html).

For more information about asset proposal, see [Asset Proposal and Generation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2155572.html).
