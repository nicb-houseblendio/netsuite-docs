Before importing asset data, run a test import first to ensure that your CSV import works without errors. Create a test CSV file with a few assets and check the formatting to ensure that the data is imported with correct values.

To import fixed asset records, read the following topics:

-   For information about the fields to include in your CSV file, see [CSV Fields for Importing Fixed Asset Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1120064917.html)
    
-   For detailed instructions on how to import fixed asset records, see [Uploading Fixed Asset Records through CSV Import](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1120065424.html)
