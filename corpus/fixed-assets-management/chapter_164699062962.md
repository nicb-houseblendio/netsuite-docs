The Fixed Assets Management SuiteApp lets you create asset records in several ways. You can create asset records manually or from transactions entered in the system. If you have an existing system and want to migrate your assets to NetSuite, you can create asset records with the CSV Import Assistant. Read the following help topics to learn more:

-   [Creating Asset Records from Transactions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164689333704.html)
    
-   [Creating Asset Records through CSV Import](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164689335971.html)
    
-   [Creating Asset Records Manually](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164689339824.html)
