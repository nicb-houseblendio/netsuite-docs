When many assets must be divided at one time, bulk splitting applies the same validation rules used for a single split. The system processes each asset in sequence, and refreshes all related depreciation forecasts.

To split assets in bulk, read the following topics:

-   [Guidelines and Limitations for Splitting Assets in Bulk using CSV Import](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_0717030348.html)
    
-   [Splitting Multiple Assets through CSV Import](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1202025103.html)
