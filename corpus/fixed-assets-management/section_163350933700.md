When mapping the NetSuite fields for depreciation, you must set default values for Transaction Type, Reference Type, and Depreciation Method.

The following screenshot shows the default value for the Transaction Type being set to **Depreciation**.

![Setting the default value of the Transaction Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Accounting/FixedAssetsManagement/FAMImportDepreciationHistory3TransactionType.png)

The following screenshot shows the Reference Type for Asset being set to **Internal ID**.

![Setting the Reference Type for the asset](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Accounting/FixedAssetsManagement/FAMImportDepreciationHistory3InternalID.png)

The following screenshot shows the Depreciation Method default value being set to **Accounting Method**.

![Setting the default value of the depreciation method](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Accounting/FixedAssetsManagement/FAMImportDepreciationHistory3DepreciationMethod.png)
