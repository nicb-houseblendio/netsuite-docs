After installing the Fixed Assets Management SuiteApp, complete the following setup tasks:

-   Set up the [General Ledger Accounts for Fixed Assets Management](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164861717992.html).
    
-   Set up [Fixed Assets General Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164861799775.html), [Fixed Assets Report Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164861832847.html), [Fixed Assets Country Specific Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164861834272.html).
    
-   Set up the [Asset Transfer Accounts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164862663749.html).
    
-   Set up the [FAM Diagnostics Portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157970301580.html) to monitor the health of your FAM bundle, from your dashboard.
    
-   Assign [Depreciation Methods](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164862696596.html) to an asset.
    
-   Set up [Alternate Methods (Tax Depreciation Methods)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164862707730.html).
    
-   Define [FAM Asset Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164862669287.html).
    
-   Migrate fixed asset data from your previous system. See [Creating Asset Records through CSV Import](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164689335971.html).
    
-   If you want to apply custom segments to your FAM records, see [Custom Segments and Custom Fields in Fixed Assets Management Records and Transactions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1501725267.html).
