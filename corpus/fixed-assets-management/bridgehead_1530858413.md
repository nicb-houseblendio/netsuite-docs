-   The Priority on the following script deployments must be set to High:
    
    -   **FAM Trigger Process SS** (customdeploy\_fam\_triggerprocess\_ss)
        
    -   **FAM Process Manager SS** (customdeploy\_fam\_processmanager\_ss)
        
-   The scheduled script that manages the process must be prioritized as well. For more information, see [Background Processing of Fixed Assets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164861655712.html).
    

Important:

The bundle update preference for most FAM scripts are set to **Update Deployments**. When the SuiteApp is updated, the script priority that you set will be updated to the value in the source account. This issue is currently being addressed. Until the issue is resolved, you must prioritize the FAM scripts again after the SuiteApp is updated.
