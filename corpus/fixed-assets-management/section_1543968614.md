You can enter all relevant lease information in the Lease record, allowing you to effectively manage your lease asset. From the Lease record page, you can do the following tasks:

-   Propose a lease asset
    
-   Create a mid-life lease
    
-   Define the terms of the lease
    
-   Add lease payments
    
-   Create the lease amortization schedule
    

When a lease journal is generated, a link to the journal entry becomes available in the record page.

You can upload records through CSV import to create a Lease record.

To learn more about creating a lease record, read the following topics:

-   [Creating a Lease Record Manually](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1203074757.html)
    
-   [Importing Lease Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1203074838.html)
    
-   [Posting Reference Subtab (Lease Accounting)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1543971320.html)
    
-   [Accounting Books Subtab (Lease Accounting)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1543971336.html)
    
-   [Lease Amortization Schedule Subtab](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1543971350.html)
    

Note:

You currently can't create a mid-life lease through CSV import.
