For information about installing SuiteApps, see [Installing a Bundle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3395142.html).

Use the following information to install the Fixed Assets Management SuiteApp:

-   **Bundle Name:** Fixed Assets Management
    
-   **Bundle ID:** 700639
    

Note:

If the Install button isn't available, this SuiteApp may not have been shared with your account. To get access to the SuiteApp, contact NetSuite Customer Support.

The Fixed Assets Management SuiteApp supports all the languages that NetSuite offers. For more information, see [Choosing a Language for Your NetSuite User Interface](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N479109.html).
