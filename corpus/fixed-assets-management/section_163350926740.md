After updating the missing fields for the tax methods, you must import the tax method DHRs so the system reflects the correct values.

To import tax method DHRs, read the following topics:

-   For information about the fields to include in your CSV file, see [CSV Fields for Importing Tax Method DHRs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1201050345.html).
    
-   For detailed instructions on how to import fixed asset records, see [Uploading Tax Method DHRs through CSV Import](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1201050450.html).
