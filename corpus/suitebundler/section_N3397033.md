After you have installed a bundle, it is listed on the Installed Bundles page, available at Customization > SuiteBundler > Search & Install Bundles > List . The Installed Bundles page is available if the SuiteBundler feature is enabled in your account and you have the SuiteApp Marketplace permission.

This page includes the following information for each bundle created in the current account:

-   Bundle name
    
-   Bundle ID
    
-   Bundle version (If a newer version than the installed version is available, an icon displays that you can click to go to the Preview Bundle Update page and update the bundle to the latest version.)
    
-   Whether the bundle is a managed bundle
    
-   Abstract
    
-   Link to bundle documentation file for administrators (Note that bundle documentation for users may be available in the NetSuite Help Center. See [Finding SuiteApp Help Content in the NetSuite Help Center](#bridgehead_1499381681).)
    
-   Status of the install (completed or in progress)
    
-   NetSuite account ID for the account from which the bundle was installed
    
-   Type of account from which the bundle was installed (production or sandbox)
    
-   User name of the user who installed the bundle
    
-   Date and time when the bundle was originally installed in the account
    
    Note:
    
    The date and time value is hardcoded to Pacific Time Zone and does not reflect the time zone setting on Home > Set Preferences.
    
-   Date and time when the bundle was last updated
    
    Note:
    
    The date and time value is hardcoded to Pacific Time Zone and does not reflect the time zone setting on Home > Set Preferences.
    

You can use the dropdown menu in the Action column to link to pages for other bundle tasks, including:

-   Updating the installed bundle (See [Installed Bundle Updates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3397927.html).)
    
-   Uninstalling the bundle (See [Uninstalling a Bundle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3400972.html).)
    

You can click the bundle name to open the Bundle Details page:

-   This page provides information about the bundle, including a link to the bundle documentation file and SuiteApp.com details, if any. See [Bundle Details](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3393046.html).
    
-   On this page's Components subtab, you can indicate whether objects installed by the bundle should be displayed in your account's list pages. See [Choosing to Hide or Show Bundle Components](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3397428.html).
    
-   This page also includes a Messages subtab that displays all messages sent by the bundle author. On this subtab you can set up the users who should receive bundle messages as email. See [Subscribing to Bundle Email Messages](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3397668.html).
    

Note:

You can differentiate objects added to your account through bundle installation from other account objects, because they have a bundle ID listed in the From Bundle column of list pages. See [Identifying Bundle Objects in Target Accounts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3401780.html).

You can also use SuiteScript to get information about installed bundles and SuiteApps. For more information, see [N/suiteAppInfo Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160236086332.html).

## Finding SuiteApp Help Content in the NetSuite Help Center {#bridgehead_1499381681}

Bundle authors may make user help content available in the NetSuite Help Center. This content is available from a page titled Third Party SuiteApps. You can access this documentation by going directly to this page, or through a Help Center search. The Third Party SuiteApps page includes a table of third party SuiteApps. Each SuiteApp in the table links to a help page with the SuiteApp's name. That help page links to the SuiteApp's PDF documentation and the author's website.
