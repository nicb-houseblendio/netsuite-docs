For an overview of the bundle installation process, see [Installing a Bundle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3395142.html). Before you choose a bundle to install, you should review [Bundle Installation Notes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3396757.html).

#### To choose a bundle to install: {#procedure_N3395770}

1.  Log in to the account where you want to install the bundle.
    
    You can install bundles in both production and sandbox accounts.
    
2.  Go to _Customization > SuiteBundler > Search & Install Bundles (Administrator)_.
    
3.  Search for a bundle to install.
    
    See [Bundle Searches Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3394713.html).
    
4.  Optionally, click the **Name** of a bundle to display its Bundle Details page.
    
    -   Click **Documentation** to review documentation for the bundle.
        
    -   The **Overview** subtab displays the bundle abstract, and description. It also displays a link to any bundle-specific terms of service. See [Bundle Terms of Service](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3393542.html).
        
    -   The **Components** subtab lists bundle objects, including their custom script IDs, referencing objects, and lock status.
        
    -   The **SuiteApp Info** subtab displays details about the bundle from SuiteApp.com, if the bundle has been developed by a NetSuite partner and is available on that site.
        
    -   For more information, see [Bundle Details](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3393046.html).
        
5.  When you've decided to install a bundle, click the Install button.
    
    -   The **Install** button is only available for bundles that are public or have been shared with your account. If you don't see it, contact the solution provider for access.
        
    -   If the bundle is a managed bundle, you must agree to allow the bundle author to upgrade the bundle in your account when new updates are available. Managed bundles are indicated in the **Managed** column of the Installed Bundles page. For more information, see [Using Managed Bundles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3400741.html).
        
    -   If the bundle's deprecated, you'll see a message telling you which replacement bundle to install. A deprecated bundle just means it's been replaced by a newer version.
        
    -   If this bundle is already installed, or it's a copy of one that's already installed, you'll see an error message.
        
6.  After you've clicked **Install**, the Bundle Details page appears. Click **Install** again on this page.
    
    -   If the bundle has terms of service you need to accept, a dialog will pop up. Click **I Agree** to continue.
        
    -   The Preview Bundle Install page displays. See [Reviewing the Preview Bundle Install Page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3396121.html).
