You can review the files and folders included in a bundle before you install it. If you are installing a bundle from another production account, NetSuite installs the files and folders in a folder called SuiteBundles. If you are installing a bundle from a sandbox account associated with the target account, NetSuite installs the files and folders with the same path information as the source account.

The following screenshot shows the properties for the files and folders that are being installed from a sandbox source account:

![Preview Bundle Install page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/SuiteBundler/BundleDetailsComponentsSubtab.png)

For more information, see [Starting the Bundle Installation Process](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3396567.html).
