If the Allow GL Custom Segment Deletion setting is enabled, bundles containing custom segments can be uninstalled. If the Allow GL Custom Segment Deletion setting is not enabled, an error appears when you attempt to uninstall a bundle containing a custom segment.

For more information about uninstalling bundles, see [Uninstalling a Bundle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3400972.html).

For more information about custom segments, see [Custom Segments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4313464438.html).
