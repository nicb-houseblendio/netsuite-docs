For bundle updates of bundled custom records with deleted custom record entries in a source account, there are different scenarios about what happens to system notes for changes on the custom record entries in a target account.

Note:

System notes get deleted for entries that are deleted from a bundle.

The following table describes the different bundle update scenarios and their effect on system notes for changes on the custom record entries:

|  | Description of Changes | Effect on System Notes for the Preserve Data Option | Effect on System Notes for the Merge Data Option | Effect on System Notes for the Replace Data Option |
| --- | --- | --- | --- | --- |
| Scenario 1 | Delete the custom record entries from a bundled custom record in a source account. Update the bundle in a target account. | System notes for changes on the custom record entries are retained in a target account. | The custom record entries and system notes for changes on the custom record entries that got deleted from a source account, get deleted from a target account. | When custom record entries get deleted from a source account, system notes for changes on the custom record entries get deleted from a target account as well. |
| Scenario 2 | For custom records, that are included in multiple bundles: Delete a bundled custom record in a source account. Create a new custom record with the same ID as the previously deleted custom record. Edit the bundle in a source account by adding the newly created custom record. Update the bundle in a target account. | System notes for changes on the custom record entries are retained in a target account. | The custom record entries and system notes for changes on the custom record entries that got deleted from a source account, get deleted from a target account. | When custom record entries get deleted from a source account, system notes for changes on the custom record entries get deleted from a target account as well. |
| Scenario 3 | For custom records, that are included in one bundle: Delete a bundled custom record in a source account. Create a new custom record with the same ID as the previously deleted custom record. Edit the bundle in a source account by adding the newly created custom record. Update the bundle in a target account. | System notes for changes on the custom record entries get deleted from a target account. | System notes for changes on the custom record entries get deleted from a target account. | System notes for changes on the custom record entries get deleted from a target account. |
