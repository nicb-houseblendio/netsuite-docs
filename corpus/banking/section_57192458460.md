Note:

An administrator must give access to roles that will use the Cash 360 SuiteApp. When access is not given, the role has no permission to view the cash forecasts. For more information, see [Giving a Role Access to Cash 360](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_165164965370.html#subsect_165173782244).

You can display the cash forecast for a single subsidiary or for consolidated subsidiaries in the Cash Forecast table. To change reports by subsidiary or to view consolidated reports, go to the upper right corner of the page and select the subsidiary or consolidated subsidiary.

Dates in the Cash Forecast table are based on the time zone preferences of the of the logged-in user. For more information, see [Setting Your Calendar Time Zone](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N500123.html).

Note:

Inactive subsidiaries are not included in the list of subsidiary options. However, all posting transaction amounts from inactive subsidiaries are included in the cash forecast when viewing reports for a consolidated subsidiary. For more information about consolidated reports in OneWorld accounts, see [Consolidated Reporting in OneWorld](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N278654.html).

#### To view cash forecasts:

1.  Go to Financial > Cash 360 > Dashboard.
    
2.  On the left pane, click **Cash Forecast** to display the Cash Forecast table.
    
    The default display of the Cash Forecast table is always based on the currently logged-in user's subsidiary. To display the table for another subsidiary, select the subsidiary in the upper right corner of the page.
    
    The Cash Forecast table displays the following information.
    
    | Table Heading | Table Element | Description |
    | --- | --- | --- |
    | Account Category | Column header | This column displays the account categories and additional values. The account categories are sorted per type, whether they are inflow or outflow. Additional values are marked with an asterisk (\*). Accounts receivable and accounts payable are also displayed in this column. |
    | Amount (Currency) | Column header | This column is divided into subcolumns that show the cash forecast amount for the date range specified in the SuiteApp's Preferences page. The cash forecast amount is shown in the currency of the selected subsidiary or consolidated subsidiary. |
    | Date, Week, Month | Column subheader | This is the date range specified in the **Forecast Period** field on the SuiteApp's Preferences page. Each column shows the forecast amount for the date range and starts with the current date, week, or month. If you selected **3 Months** in the **Forecast Period** field, the SuiteApp computes the next full 3 months after the current date. For example, if the current date is October 20, the table displays the next full 3 months of data after October. That is, data from November to January. |
    | Opening Balance | Row header | This row displays the opening balance amount for the date range specified in the SuiteApp's Preferences page. For more information, see [Setting Cash 360 Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164974435218.html). The initial opening balance amount is the sum of all accounts in the chart of accounts with the type equal to bank (except for those excluded from Cash 360 calculations) for the selected subsidiary or consolidated subsidiary up to the current posting period. For more information about excluding bank accounts from the opening balance calculations, see [Excluding Bank Accounts from Cash 360 Calculations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0219083320.html). The succeeding opening balance amounts are taken from the closing balance amounts from the previous periods. This row is only displayed if the **Include Opening Balance** box is checked in the SuiteApp's Preferences page. Click the opening balance amount to open a window that lists all accounts included in the opening balance amount calculation. You can only click the opening balance amount if it is greater than zero. For more information, see [Viewing the Opening Balance Details](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_95175116414.html). |
    | Undeposited/Future-Period Funds | Row header | This row displays the total undeposited funds and bank transaction amounts for the date range specified that fall on the succeeding posting period. This row displays values if there are undeposited funds or if there is an overlap in the accounting periods within the same forecast period. For example, you have a forecast period that is set to 6 or 12 weeks, a report that starts on the last week of October 2026, and bank transactions for November 1, 2026. Any undeposited funds and any bank transaction amounts for November 1 is shown on this row. This row is only displayed if the **Include Opening Balance** box is checked in the SuiteApp's Preferences page. For more information, see [Setting Cash 360 Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164974435218.html). |
    | Inflow | Row separator | All entries below this row are inflow account categories, additional values, accounts receivables, sales orders, and sales orders with billing schedules. The forecast amount for the account categories are based on historical averages as set in the **Forecast Period** field on the SuiteApp's Preferences page. When there is no data available for the period specified, the forecast amount will contain zero values. If the Cash Forecast table displayed is for a consolidated subsidiary, the inflow amounts are grouped together for each subsidiary. Expand the subsidiary name to show the account categories or additional values for that subsidiary. Additional values are marked with an asterisk. For information about how to add additional values, see [Setting Cash 360 Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164974435218.html). |
    | Accounts Receivable | Row | This row displays the accounts receivable from all A/R posting transactions that fall on the date, week, or month specified. If there are receivable installment transactions, the installment amount is included on the month, week, or date when the installment amount is received. The amounts in this row include transactions with due dates in the future. Where due dates are not specified for transactions, the transaction date is used in place of the due date. This row is displayed even if there are no A/R posting transactions, account categories, or additional values entered. The first column in this row includes all the accounts receivable amount up to the current date, week, or month. Click the accounts receivable amount to open a window that lists all accounts included in the accounts receivable amount calculation. You can only click the accounts receivable amount if it is greater than zero. For more information, see [Viewing the Accounts Receivable Details](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_93182907963.html). |
    | Sales Orders | Row | The first column in this row displays the total open amount (up to the current date, week, or month) from all open and partially billed sales orders. The succeeding columns in this row display the total open amount for all open and partially billed sales orders with forecast dates that fall on the date, week, or month specified. The following sales order statuses are included in the calculation of the total open amount: partially fulfilled, pending billing, and pending fulfillment. Sales orders with billing schedules are not included in the calculation of amounts in this row. Sales orders with installments or subscription lines are treated as regular sales orders and only the total sales order amount is considered in forecast computations. Click the sales order amount (if greater than zero) to open a window listing all related sales orders and their details. For more information, see [Viewing the Sales Order Details](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0813021310.html). This row is only displayed if the **Include Sales Orders** box is checked in the SuiteApp's Preferences page. For more information, see [Setting Cash 360 Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164974435218.html). |
    | Sales Orders with Billing Schedules | Row | The first column in this row displays the total open amount (up to the current date, week, or month) from all open and partially billed sales orders with billing schedules. The succeeding columns in this row display the total open amount for all open and partially billed sales orders with billing schedules that have forecast dates that fall on the date, week, or month specified. The following sales order statuses are included in the calculation of the total open amount: partially fulfilled, pending billing, partially billed, and pending fulfillment. Sales orders without billing schedules and those with installments and subscriptions are excluded in the calculation of amounts in this row. Click the sales order amount (if greater than zero) to open a window listing all related sales orders with billing schedules and their details. For more information, see [Viewing the Details of Sales Orders with Billing Schedules](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1010040432.html). This row is only displayed if the **Include Sales Orders** box is checked in the SuiteApp's Preferences page. For more information, see [Setting Cash 360 Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164974435218.html). |
    | Outflow | Row separator | All entries below this row are outflow account categories, additional values, accounts payables, and purchase orders. The forecast amount for the account categories are based on historical averages as set in the **Forecast Period** field on the SuiteApp's Preferences page. When there is no data available for the period specified, the forecast amount will contain zero values. If the Cash Forecast table displayed is for a consolidated subsidiary, the outflow amounts are grouped together for each subsidiary. Expand the subsidiary name to show the account categories or additional values for that subsidiary. Additional values are marked with an asterisk. For information about how to add additional values, see [Setting Cash 360 Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164974435218.html). |
    | Accounts Payable | Row | This row displays the accounts payable from all A/P posting transactions that fall on the date, week, or month specified. If there are payable installment transactions, the installment amount is included on the month, week, or date when the installment amount is paid. The amounts in this row include transactions with due dates in the future. Where due dates are not specified for transactions, the transaction date is used in place of the due date. This row is displayed even if there are no A/P posting transactions, account categories, or additional values entered. Click the accounts payable amount to open a window that lists all accounts included in the accounts payable amount calculation. You can only click the accounts payable amount if the it is greater than zero. For more information, see [Viewing the Accounts Payable Details](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_82190814363.html). |
    | Purchase Orders | Row | The first column in this row displays the total open amount (up to the current date, week, or month) from all open purchase orders. The succeeding columns in this row display the total open amount for all open and partially billed purchase orders with forecast dates that fall on the date, week, or month specified. The following purchase order statuses are included in the calculation of the total open amount: partially received, pending billing, and pending receipt. Click the purchase order amount (if greater than zero) to open a window listing all related purchase orders and their details. For more information, see [Viewing the Purchase Orders Details](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0814055218.html). This row is only displayed if the **Include Purchase Orders** box is checked in the SuiteApp's Preferences page. For more information, see [Setting Cash 360 Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164974435218.html). |
    | Net Balance | Row header | This row displays the net balance amount for a given period. The net balance amount is calculated as the total forecast inflow amount minus the total forecast outflow amount for a given period. This row is only displayed if the **Include Opening Balance** box is checked in the SuiteApp's Preferences page. For more information, see [Setting Cash 360 Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164974435218.html). |
    | Closing Balance | Row header | This row shows the closing balance amount for a given period. The closing balance amount is calculated as the opening balance amount, plus the undeposited/future-period funds, plus the total forecast inflow amount, minus the total forecast outflow amount for a given period. Closing balance = Opening balance amount + Undeposited/Future-period funds + Total forecast inflow amount - Total forecast outflow amount This row is only displayed if the **Include Opening Balance** box is checked in the Preferences page of this SuiteApp. For more information, see [Setting Cash 360 Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164974435218.html). |
