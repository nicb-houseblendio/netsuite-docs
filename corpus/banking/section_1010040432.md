Click the amount for sales orders with billing schedules in the Cash Forecast table to open a window listing all open sales orders included in the amount calculation. You can only click the amount if it is greater than zero.

The row showing amounts from sales orders with billing schedules only appears if the **Include Sales Orders** box is checked on the SuiteApp's Preferences page. For more information, see [Setting Cash 360 Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164974435218.html).

#### To view the details of sales orders with billing schedules:

1.  Go to Financial > Cash 360 > Dashboard.
    
2.  On the left pane, click **Cash Forecast**.
    
    The default display of the Cash Forecast table is always based on the currently logged-in user's subsidiary. To display the table for another subsidiary, select the subsidiary in the upper right corner of the page.
    
3.  Click the amount for the sales order with billing schedules.
    
    The Sales Orders with Billing Schedules window opens and displays the following information:
    
    | Item | Description |
    | --- | --- |
    | Account Category | This field displays the account category for the amount. For example, if the amount is from open sales orders that have billing schedules, this field displays Sales Orders with Billing Schedules. |
    | Total Amount | This field displays the total amount from all open sales orders with billing schedules that fall on the date, week, or month specified. |
    | Period | This field displays the period covered for the total amount from sales orders with billing schedules. |
    | Currency | This field displays the currency of the total amount from sales orders with billing schedules. |
    | Subsidiary | This column displays the subsidiary of the sales order with billing schedules that contributed to the total amount calculation. |
    | Document Number | This column displays the ID of the sales order that has billing schedules that contributed to the total amount calculation. Click the ID to open the sales order record. |
    | Entity | This column displays the entity that contributed to the total amount calculation. Entity can be a customer name, vendor name, employee name, or other entities. |
    | Transaction Date | This column displays the transaction date of the sales order with billing schedules that contributed to the total amount calculation. |
    | Forecast Date | This column displays the forecast date for the sales order that has billing schedules. The forecast date is calculated as the billing schedule bill date of the sales order plus the payment terms. Forecast date = Sales order billing schedule bill date + Payment terms Only billing schedules of the standard type are considered in forecast calculations. Charge-based or other billing schedule types are excluded. Unbilled amounts from the billing schedule are included in the cash forecast. The payment terms on the billing schedule override those set on the sales order. For more information about how forecast dates are calculated for sales orders with billing schedules, see [Forecast Computations for Sales Orders with Billing Schedules](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1010040452.html). |
    | Payment Terms | This column displays the payment terms for the sales order that has billing schedules. If the payment term is installment, this column displays zero (0). If there is no payment term for the sales order that has billing schedules, this column is blank. Only standard payment terms are considered, and not date-driven or installment terms. |
    | Billing Schedule | This column displays the billing schedule for the sales order. A billing schedule outlines when to bill a sale over time or a contract term. Billing schedules manage billing by tracking invoice timing and billing amounts. For more information, see [Billing Schedules](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1251398.html). Billing schedules affect sales forecasts by spreading revenue across the billing schedule period. The system calculates forecast schedules for a sales order with billing schedules using the billing start date, initial billing amount, and subsequent billing amounts. |
    | Start Date | This column displays the start date of the sales order that has billing schedules. |
    | End Date | This column displays the end date of the sales order that has billing schedules. |
    | Open Amount (Currency) | This column displays the open amount for the sales order that has billing schedules. |
    | Transaction Amount (Currency) | This column displays the transaction amount of the sales order that has billing schedules. |
    | Amount Billed (Currency) | This column displays the amount billed for the sales order that has billing schedules. |
    | Status | This column displays the status of the sales order that has billing schedules. For example: Pending Fulfillment |
    | Open Amount in Foreign Currency | This column displays the open amount in foreign currency for the sales order that has billing schedules. |
    | Transaction Currency | This column displays the transaction currency of the sales order that has billing schedules. |
    | Transaction Amount in Foreign Currency | This column displays the transaction amount in foreign currency for the sales order that has billing schedules. |
    
4.  (Optional) To view more than 100 transactions, under the Details of Sales Orders with Billing Schedules section, click the **Export to** icon and select **CSV** to export the report as a CSV file.
    
    The Sales Orders with Billing Schedules window displays up to 100 recent transactions. Use Export to CSV to view all transactions.
