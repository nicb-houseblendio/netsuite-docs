Click the purchase order amount in the Cash Forecast table to open a window that lists all open purchase orders included in the amount calculation. You can only click the purchase order amount if it is greater than zero.

The row showing amounts from purchase orders only appears if the **Include Purchase Orders** box is checked on the SuiteApp's Preferences page. For more information, see [Setting Cash 360 Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164974435218.html).

#### To view the purchase order details:

1.  Go to Financial > Cash 360 > Dashboard.
    
2.  On the left pane, click **Cash Forecast** to display the Cash Forecast table.
    
    The default display of the Cash Forecast table is always based on the currently logged-in user's subsidiary. To display the table for another subsidiary, select the subsidiary in the upper right corner of the page.
    
3.  Click the purchase order amount.
    
    The Purchase Orders window opens and displays the following information:
    
    | Item | Description |
    | --- | --- |
    | Account Category | This field displays the account category for the amount. For example, if the amount is from open purchase orders, this field displays Purchase Orders. |
    | Total Amount | This field displays the total amount from all open purchase orders that fall on the date, week, or month specified. |
    | Period | This field displays the period covered for the total purchase order amount. |
    | Currency | This field displays the currency of the total purchase order amount. |
    | Subsidiary | This column displays the subsidiary of the purchase order that contributed to the total purchase order amount calculation. |
    | Document Number | This column displays the ID of the purchase order that contributed to the total purchase order amount calculation. Click the ID to open the purchase order record. |
    | Entity | This column displays the entity for the transaction that contributed to the total purchase order amount calculation. Entity can be a customer name, vendor name, employee name, or other entities. |
    | Transaction Date | This column displays the transaction date of the purchase order that contributed to the total amount calculation. |
    | Forecast Date | This column displays the forecast date for the purchase order. The forecast date is calculated as the transaction date plus the order billing lead time for the purchase order plus the payment terms if there are any. Forecast date = Transaction date + Order billing lead time + Payment terms The order billing lead time is system-calculated for all purchase orders that are fully billed and closed. You can manually enter this value for vendors without closed purchase orders. For more information, see [Viewing the System-Calculated Order Billing Lead Time](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0814063321.html) and [Setting Cash 360 Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164974435218.html). |
    | Payment Terms | This column displays the payment terms for the purchase order. If the payment term is installment, this column displays zero (0). If there is no payment term for the purchase order, this column is blank. Only standard payment terms are considered, and not date-driven or installment terms. |
    | Order Billing Lead Time | This column displays the order billing lead time for the purchase order. The purchase order billing lead time is the time it takes in days for a vendor to be billed for goods or services. It can be system-calculated for all fully billed and closed purchase orders and displayed in the vendor record or manually entered in the Cash 360 Preferences page. For more information, see [Viewing the System-Calculated Order Billing Lead Time](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0814063321.html) and [Setting Cash 360 Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164974435218.html). If the purchase order billing lead time is specified in both the vendor record and the Cash 360 Preferences page, the value in the vendor record takes precedence and is used to calculate forecast dates. |
    | Open Amount (Currency) | This column displays the open amount for the purchase order. |
    | Transaction Amount (Currency) | This column displays the transaction amount of the purchase order. |
    | Amount Billed (Currency) | This column displays the amount billed for the purchase order. |
    | Status | This column displays the status of the purchase order. For example: Pending Receipt |
    | Open Amount in Foreign Currency | This column displays the open amount for the purchase order in foreign currency. |
    | Transaction Currency | This column displays the currency of the purchase order transaction. |
    | Transaction Amount in Foreign Currency | This column displays the transaction amount for the purchase order in foreign currency. |
    
4.  (Optional) To view more than 100 transactions, under the Details of Purchase Order section, click the **Export to** icon and select **CSV** to export the report as a CSV file.
    
    The Purchase Orders window displays up to 100 recent transactions. Use Export to CSV to view all transactions.
