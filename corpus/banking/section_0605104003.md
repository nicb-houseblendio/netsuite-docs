Note:

If you uninstall the SuiteApp, all saved data will be lost.

If you're uninstalling the Payment Automation SuiteApp, take the following information into consideration:

-   Format profiles enable you to configure settings necessary for manual or automatic import of financial institution data. You can use the format profiles created from the Payment Automation SuiteApp to import data from HSBC to NetSuite. You can create a format profile record to link your HSBC and NetSuite accounts and trigger the data import for reconciliation. For more information about a format profile, see [Format Profile](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557261357.html). Format profiles created from the Payment Automation SuiteApp can access HSBC account data even after you uninstall the Payment Automation SuiteApp. After uninstalling the SuiteApp, the format profile record is stored in your NetSuite account and you cannot import transactions from HSBC to NetSuite.
    
-   Your GL Bank Accounts will still be accessible, but fields related to Payment Automation will be removed.
    
-   Audit trail records will be deleted. The audit trail record is a Payment Automation custom record that is not referenced by any other records.
    

#### To uninstall the Payment Automation SuiteApp: {#procedure_0605104053}

1.  Go to Customization > SuiteCloud Development > Installed SuiteApp List.
    
2.  On the line with the com.netsuite.paymentautomation App ID, click **Uninstall** in the **Action** column.
