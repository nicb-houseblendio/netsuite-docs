If you've excluded imported bank line items, you can restore them so they're included in matching.

#### To restore excluded bank data:

1.  Go to _Transactions > Bank > Match Bank Data_.
    
2.  From the **Account** list, select the bank or credit card account.
    
    In the Imported Bank Data and Account Transactions grids, NetSuite displays the imported bank lines and account transactions that require manual matching.
    
3.  Click the **Excluded** subtab.
    
4.  Select the transactions you want to restore and click **Restore**. You can use the box in the grid header to select all transactions visible on the current page.
    
    The transactions you selected move back to the **To Be Matched** subtab. If you selected all transactions using the box in the grid header, all transactions visible on the current page are restored.
