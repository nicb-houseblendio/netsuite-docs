When you choose a standard BAI2 transaction parser, the Parser Configuration subtab of your format profile automatically shows your active currencies.

With the SuiteApp, you can set the decimal precision for the BAI2 parser plug-in. The default precision value is **2**.

## Configuring the Decimal Precision for the BAI2 Parser {#subsect_1566293138}

You can set the decimal precision for each currency if you use the standard BAI2 parser.

#### To configure the decimal precision: {#procedure_1102030409}

1.  Go to _Setup > Accounting > Financial Institution > List_.
    
2.  Next to the financial institution record where you'd like to add or edit a format profile, click **View**. For more information, see [Format Profile Creation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159061330646.html).
    
3.  On the Financial Institution page, click the format profile you want to edit.
    
4.  On the Format Profile page, click **Edit**.
    
5.  Under the Parser Configuration subtab, in the **Precision** field, enter a value from 0-9.
    
    You should change the decimal precision only in these situations:
    
    -   The decimal precision of the currency associated to your bank account has changed.
        
    -   The bank has updated their system to generate bank statement files with a new decimal precision setting.
        
6.  Click **Save**.
