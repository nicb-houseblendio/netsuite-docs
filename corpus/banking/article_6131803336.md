To run an auto-create rule, along with any active matching rules, you need to initiate the Intelligent Transaction Matching Feature. You can do so by manually running reconciliation rules or through a bank data import, since the matching process automatically runs against an import. For detailed instructions on setting up automatic bank imports, see [Automating Imports for Bank Reconciliation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157895120878.html). For manual import options, see [Manual Bank Data Import](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157895093957.html).

#### To run an auto-create rule by manually running reconciliation rules:

1.  Go to _Transactions > Bank > Match Bank Data_.
    
2.  From the **Account** list, select the appropriate account.
    
3.  Click **Run Reconciliation Rules**.
    
4.  In the confirmation window, use the date picker to specify the date range you want the system to run rules against. This date range is based on when transactions were imported, not the transaction date. For large date ranges, processing time may increase. For best results, consider running reconciliation rules in smaller batches
    
5.  If you're sure, click **Run Reconciliation Rules** to initiate the matching process.
    
    Note:
    
    After the process starts, it cannot be canceled.
    
    All active system and user rules, including auto-create rules, run on the imports from your selected date range.
    
6.  To see the results, refresh the page and reload your account.
    

For more details, see [Manually Running Reconciliation Rules](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158991245944.html).
