**How do I see the status for the subsidiaries for the HSBC Application I applied for?**

Go to SuiteBanking > HSBC Application > Apply to check the list of applications and their statuses. The sublist displays the **Application ID**, **Subsidiary**, **Submitted By**, **Account Application Status**, **Credit Application Status**, and **Action**. To see more information about an application, click **Show Details** in the **Actions** column for the required application. The Verification page is displayed for a completed application.

Note:

You need to have access to the subsidiary for which the application is raised to view the details of the respective subsidiary.
