Payment Automation SuiteApp validates your **AP Automation** license and access to payment automation features.

To use the features of the SuiteApp, you need to purchase the AP Automation license and download the **NetSuite SuiteApps License Client**. The License Client will validate the latest AP Automation license information. If no valid license exists for your company, you will need to purchase a license to use the Payment Automation SuiteApp.

Note:

Provisioning from Bill team is not needed to install the SuiteApp.

If you have a valid license, you can do the following:

-   [Paying a Single Vendor](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1006024338.html)
    
-   [Processing Bulk Payments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1006024950.html)
    
-   [Vendor Prepayment](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0529035119.html)
    
-   [Making Money Transfers](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1123092904.html)
    

Important:

You have to install the **NetSuite SuiteApps License Client** to apply for a new HSBC account.

The Payment Automation SuiteApp allowed processing of payments without installing the **NetSuite SuiteApps License Client** until October 31, 2024. From November 01, 2024, payment processing requires installation of the **NetSuite SuiteApps License Client** and a valid AP Automation license.

#### To install the NetSuite SuiteApps License Client: {#procedure_27112726474}

1.  Go to Customization > SuiteBundler > Search & Install Bundles.
    
2.  In the **Keywords** field, enter NetSuite SuiteApps License Client.
    
3.  Click **Search**.
    
4.  Click the link of the bundle with the following details:
    
    -   Name: NetSuite SuiteApps License Client
        
    -   Bundle ID: 116144
        
5.  On the Bundle Details page, click **Install**.
    

After installation, the NetSuite SuiteApps License automatically connects with NetSuite to obtain your license information.

Only users with the Administrator role can install SuiteApps in your account. For more information, see [NetSuite SuiteApps License Client Guide for Administrators](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4635371677.html).

#### To check the status of the license: {#procedure_86113412830}

The license details in the SuiteBanking Preferences are refreshed based on the Time to Live (TTL). If your license is renewed, but you still see the license expired error when trying to process payments from the HSBC Bank Account, you can manually fetch the license from the License server. Go to Setup > License Client > Manual License Request to fetch the license. If an active license is available, the License Dashboard in Setup > License Client > License Dashboard is updated with the **Active** status.

1.  Go to SuiteBanking > Setup > Preferences.
    
2.  Click **View** for the preference record.
    
3.  In the Preferences subtab, click **License Details**.
    
4.  View the **License Status** and the **License Expiry Date**. The status could be **Active** or **Expired**.
    

Important:

Don't uninstall the License client Bundle.
