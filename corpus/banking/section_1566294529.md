## Prerequisites {#subsect_1566294849}

Before you install the Bank Statement Parsers SuiteApp, go to Setup > Company > Setup Tasks > Enable Features, then click the SuiteCloud tab. Make sure these features are enabled on your account:

-   Custom Records
    
-   Client SuiteScript
    
-   Server SuiteScript
    

## Installation {#subsect_1566294869}

To install the Bank Statement Parsers SuiteApp, go to Customization > SuiteBundler > Search & Install Bundles, then click **Advanced**.

Use the following information to search for the SuiteApp:

-   **Bundle Name:** Bank Statement Parsers
    
-   **Bundle ID:** 293699
    

For information about installing SuiteApps, see [Installing a Bundle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3395142.html).
