By default, these standard roles can use the Bank Statement Parsers to import statement files:

-   Administrator
    
-   CEO
    
-   CFO
    

To access the Upload File page (previously named Statement File Import) and import transactions with custom roles, you need to set these permissions:

Note:

You must have an Administrator role to assign permissions to custom roles. For details, see [Setting Permissions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N288727.html).

| Permission Subtab | Permission | Level |
| --- | --- | --- |
| Transactions | Import Online Banking File | Full or Edit |
| Custom Record | BSP Configuration Value | Full |
| Custom Record | BSP CSV Parser Configuration | Edit |

For a list of permissions needed to access the records and forms for Bank Statement Parsers, see [Permissions for Banking Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_156289552348.html).
