**What happens if the Advanced PDF/HTML Template feature is not enabled before the upgrade?**

The Payment Automation SuiteApp upgrade to the version 5.0 will fail and no further updates will be received by the account if the feature is not enabled. You will still be able to use the SuiteApp and process payments.

**What happens if I enable the Advanced PDF/HTML Templates feature before the upgrade?**

If you enable the feature before the upgrade, the Payment Automation SuiteApp will be upgraded to version 5.0.
