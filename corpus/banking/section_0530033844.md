Before you install the Intelligent Payment Automation SuiteApp, enable the required features for the SuiteApp. For more information, see [Prerequisites for Installing the Intelligent Payment Automation SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0504044603.html)

To install this SuiteApp, you need permission and access to the SuiteApp Marketplace. For more information about viewing SuiteApps listed in the Marketplace, see [Viewing SuiteApps in the SuiteApp Marketplace](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1539797977.html)

To install the SuiteApp, follow the steps detailed in [Installing from the SuiteApp Marketplace](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1539799323.html)

If you use either Electronic Bank Payments or Payment Automation with HSBC, existing vendor bank details are automatically imported after your installation. For more information, see [Switching and Migrating to Intelligent Payment Automation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1003021504.html).

Note:

For a better system stability and resource utilization, set the concurrency limit of the map/reduce script deployments to a maximum of 3. For more information, see [Map/Reduce Script Deployment Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1509578980.html)

To continue your setup, see [Setting Up Intelligent Payment Automation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0530033102.html).
