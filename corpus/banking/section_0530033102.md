Complete the following procedures as part of the set up process. Note that you need to be an Administrator or have a role with the appropriate permissions to install the SuiteApp:

1.  [Prerequisites for Installing the Intelligent Payment Automation SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0504044603.html)
    
2.  [Installing the Intelligent Payment Automation SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0530033844.html)
    
3.  [Setting Up Intelligent Payment Automation Roles and Permissions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0531124014.html)
    
4.  [Signing Forms for Intelligent Payment Automation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0530034952.html)
    
5.  [Signing Up with BILL within Intelligent Payment Automation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0626062459.html)
