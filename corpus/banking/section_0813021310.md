Click the sales order amount in the Cash Forecast table to open a window that lists all open sales orders included in the amount calculation. You can only click the sales order amount if it is greater than zero.

The row showing amounts from sales orders only appears if the **Include Sales Orders** box is checked on the SuiteApp's Preferences page. For more information, see [Setting Cash 360 Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164974435218.html).

#### To view the sales order details:

1.  Go to Financial > Cash 360 > Dashboard.
    
2.  On the left pane, click **Cash Forecast** to display the Cash Forecast table.
    
    The default display of the Cash Forecast table is always based on the currently logged-in user's subsidiary. To display the table for another subsidiary, select the subsidiary in the upper right corner of the page.
    
3.  Click the sales order amount.
    
    The Sales Orders window opens and displays the following information:
    
    | Item | Description |
    | --- | --- |
    | Account Category | This field displays the account category for the amount. For example, if the amount is from open sales orders, this field displays Sales Orders. |
    | Total Amount | This field displays the total amount from all open sales orders that fall on the date, week, or month specified. |
    | Period | This field displays the period covered for the total sales order amount. |
    | Currency | This field displays the currency of the total sales order amount. |
    | Subsidiary | This column displays the subsidiary of the sales order that contributed to the total sales order amount calculation. |
    | Document Number | This column displays the ID of the sales order that contributed to the total sales order amount calculation. Click the ID to open the sales order record. |
    | Entity | This column displays the entity for the transaction that contributed to the total sales order amount calculation. Entity can be a customer name, vendor name, employee name, or other entities. |
    | Transaction Date | This column displays the transaction date of the sales order that contributed to the total amount calculation. |
    | Forecast Date | This column displays the forecast date for the sales order. The forecast date is calculated as the transaction date plus the order billing lead time for the sales order plus the payment terms if there are any. Forecast date = Transaction date + Order billing lead time + Payment terms The order billing lead time is system-calculated for all sales orders that are fully billed and closed. You can manually enter this value for customers without closed sales orders. For more information, see [Viewing the System-Calculated Order Billing Lead Time](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0814063321.html) and [Setting Cash 360 Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164974435218.html). |
    | Payment Terms | This column displays the payment terms for the sales order. If the payment term is installment, this column displays zero (0). If there is no payment term for the sales order, this column is blank. Only standard payment terms are considered, and not date-driven or installment terms. |
    | Order Billing Lead Time | This column displays the order billing lead time for the sales order. The sales order billing lead time is the time it takes in days for a customer to be billed for goods or services. It can be system-calculated for all fully billed and closed sales orders and displayed in the customer record or manually entered on the Cash 360 Preferences page. For more information, see [Viewing the System-Calculated Order Billing Lead Time](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0814063321.html) and [Setting Cash 360 Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164974435218.html). If the sales order billing lead time is specified in both the customer record and the Cash 360 Preferences page, the value in the customer record takes precedence and is used to calculate forecast dates. |
    | Open Amount (Currency) | This column displays the open amount for the sales order. |
    | Transaction Amount (Currency) | This column displays the transaction amount of the sales order. |
    | Amount Billed (Currency) | This column displays the amount billed for the sales order. |
    | Status | This column displays the status of the sales order. For example: Pending Fulfillment |
    | Open Amount in Foreign Currency | This column displays the open amount for the sales order in foreign currency. |
    | Transaction Currency | This column displays the currency of the sales order transaction. |
    | Transaction Amount in Foreign Currency | This column displays the transaction amount for the sales order in foreign currency. |
    
4.  (Optional) To view more than 100 transactions, under the Details of Sales Orders section, click the **Export to** icon and select **CSV** to export the report as a CSV file.
    
    The Sales Orders window displays up to 100 recent transactions. Use Export to CSV to view all transactions.
