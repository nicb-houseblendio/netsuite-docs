When you create and manually match an account transaction to an imported bank line, you can check the **Make Auto-Create Rule From Selected Transactions** box.

Note:

An auto-create rule can only be applied to a single account.

NetSuite can generate auto-create rules from matches on the Match Bank Data page when these criteria are met:

-   You have the **Matching Rules for Online Banking** permission, with create-level access at a minimum.
    
-   You are performing a one-to-one match of a Check, Deposit, Credit Card Charge, or Credit Card Refund.
    
-   Your imported bank line contains a Payer/Payee or Memo.
    
-   The transaction amount is not zero.
    
-   The match difference is zero.
    
-   The account transaction contains only one line item.
    
    Note:
    
    Deposits must have a single Other Deposits line item. All other transactions must have a single Expenses line item.
    
-   The account transaction doesn't contain a tax code.
    
    Note:
    
    Auto-create rules are not currently compatible with tax codes.
    

If these criteria are met, the box becomes active. If you check the box, NetSuite generates an auto-create rule after you submit the match.

The Intelligent Transaction Matching feature runs this auto-create rule, along with other matching rules, on future imports. For details, see [Running an Auto-Create Rule](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_6131803336.html).

You can add more conditions to the rule and define its action. For more information, see [Editing Auto-Create Rules](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158991231343.html).

#### To generate an auto-create rule:

1.  If you haven't already, do the following:
    
    1.  Import bank or credit card data into your account in NetSuite. See [Bank Data Import](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N1550803.html).
        
    2.  Go to _Transactions > Bank > Bank Matching and Reconciliation > Match Bank Data_.
        
    3.  From the **Account** list, select the bank or credit card account.
        
        If NetSuite failed to import data for the account, a popup displays the most recent error. For more error details, go to _Transactions > Bank > Banking Import History_. See [Banking Import History](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159622181091.html).
        
2.  On the Transactions to Match subtab, create or select an account transaction to match with an imported bank line.
    
    To add an account transaction directly on the Match Bank Data page, see [Adding New Charges During Matching](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_17132712965.html), [Adding New Deposits During Matching](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_89132718059.html), or [Adding New Credit Card Refunds During Matching](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_70132725489.html).
    
    If you can't add the transaction on the Match Bank Data page because it contains additional required fields, create one using a transaction entry form. See [Making Deposits](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1542431.html), [Writing Checks](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1543875.html), or [Entering Company Credit Card Charges](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1548500.html).
    
3.  Select the newly created or existing account transaction and the corresponding imported bank line.
    
    If you created the transaction on the Match Bank Data page without first selecting an imported bank line, select an imported bank line now.
    
    Note:
    
    Dimmed transactions are still processing. You can't select them until processing is complete. To check the status, refresh the imported bank data.
    
4.  When the **Difference** field is zero, check the **Make Auto-Create Rule From Selected Transactions** box. If the box isn't active, the criteria for an auto-create rule aren't met.
    
    Note:
    
    The box is cleared by default. You must check it every time you generate an auto-create rule.
    
5.  Click **Match and Submit**.
    
    NetSuite generates an auto-create rule from the transaction match and submits the match for reconciliation. If NetSuite can't generate an auto-create rule, see [Troubleshooting Automatic Transaction Creation Rules](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_44132247326.html).
    
6.  To see the newly generated rule, go to the Reconciliation Rules page. To run the rule, see [Running an Auto-Create Rule](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_6131803336.html).
