The Auto Bank Statement Import (ABSI) SuiteApp lets you to automatically import bank statement files into NetSuite every day.

This feature uses a Financial Institution Connectivity Plug-in to securely connect to your financial institution's server through SFTP (Secure File Transfer Protocol).

The ABSI SuiteApp works together with the Bank Statement Parser Plug-ins to read the content of imported bank statement files. It uses a transaction parser to find the transactions in each file and pulls them into NetSuite for matching and reconciliation.

The SuiteApp enables you to perform the following tasks:

-   Set up your SFTP connection right on your format profile record.
    
    Connect to your bank's server by entering your banking credentials. Set a file name pattern so the system knows which files to import into NetSuite.
    
-   Automate daily imports of bank statement files into NetSuite.
    
    When you save a format profile for SFTP for the first time, NetSuite immediately imports new data from your bank into your accounts on the Match Bank Data page. Additionally, NetSuite subsequently imports new data according to an import schedule configured during setup. The default cadence is one time every day between 4:00 and 7:00 AM Pacific Time, although you can customize the schedule.
    
    For faster navigation and adjustments, you can manage an import schedule for an account by clicking Manage Import Schedules on the Match Bank Data page. This action requires the Financial Institution Records permission. Clicking this button takes you directly to the most relevant bank data import format profile, prioritizing active profiles and listing them alphabetically. If no profiles exist, you're directed to the Financial Institutions page to configure a profile.
    
    For a format profile with the Bank Reconciliation profile type, the **Import Schedule** subtab appears. Use this subtab to set up an automated bank transaction import schedule, ensuring timely bank data updates and more efficient reconciliation processes. For more information, see [Setting Up a Bank Import Schedule](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0107014921.html).
    
-   Manually trigger the bank statement files import process to get real-time bank data updates.
    

The ABSI SuiteApp supports all languages available in the Multi-Language feature of NetSuite. To set the language preference in NetSuite, see [Choosing a Language for Your NetSuite User Interface](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N479109.html).
