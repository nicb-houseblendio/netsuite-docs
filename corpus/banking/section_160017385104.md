During a daily or manual import, bank data import will fail if there are errors such as missing MFA token or connection issues.

When handling bank data import errors, take note of the following:

-   View the Banking Import History page to see the status and details of your bank data import. If the status is set to **Partially Completed**, this means NetSuite successfully imported data for some, but not all, of your bank or credit card accounts.
    
    In the expanded details, you'll see why the import failed and which accounts were affected. For more information about this page, see [Banking Import History](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159622181091.html).
    
-   On your format profile configuration, under the Account Linking subtab, bank and payment accounts that failed to connect show up with warning icons.
    
    Hover over the warning icon for more information about the error. You can choose to fix the error or continue the connectivity configuration. The bank data import process will still proceed, but the status will be Partially Completed if one or more accounts failed to connect. Until the financial institution connection error is fixed, you won't receive daily bank updates from the bank or credit card account.
    
-   For more information about financial institution connection errors and bank import errors, read the following topics:
    
    -   [Bank Import Error Codes (Reference)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0106063237.html), for standardized bank import error codes and scenarios by error type and file format.
        
    -   SuiteAnswers article [Resolving Financial Institution Connection Errors When Using the Bank Feeds SuiteApp.](https://suiteanswers.custhelp.com/app/answers/detail/a_id/96321)
