The Intelligent Payment Automation Learning Hub portlet provides access to setup tasks, payment workflows, vendor setup resources, help topics, and troubleshooting information for Intelligent Payment Automation (IPA).

The portlet displays curated content to help you set up your account and learn how to use the SuiteApp.

You can add this portlet to the Payment Automation Overview page.

The Intelligent Payment Automation Learning Hub portlet includes the following sections:

-   **Setup Guide**
    
    Provides access to the IPA dashboard, FAQs, BILL pricing, and quick links. This section displays contextual content based on your setup status.
    
    -   If you have not set up Intelligent Payment Automation, the section provides links and resources to help you get started.
        
    -   If your setup is still in progress, the header displays quick links to resume and complete the setup process.
        
    -   After setup is complete, the header provides quick access to the IPA dashboard and related pages so you can manage payment workflows more easily.
        
-   **Getting Started**
    
    Provides onboarding guidance and resources to help you set up your account.
    
-   **Get Vendors Ready**
    
    Provides resources for vendor setup, migration, vendor status tracking, and vendor bank detail management to help ensure vendors are ready for payment processing.
    
-   **Payment Basics**
    
    Provides resources and quick links for payment processing, payment status tracking, dashboard navigation, and bank account management. This section helps you manage payments, monitor activity, and understand key payment workflows.
    

To set up this portlet, go to [Setting Up and Publishing the Intelligent Payment Automation Learning Hub Portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0518093629.html).
