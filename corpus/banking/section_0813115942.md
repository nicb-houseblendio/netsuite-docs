You need to complete Multi-Factor Authentication (MFA) when you are trying to connect to BILL to perform any of the following actions:

-   Create a BILL account.
    
-   Link your bank accounts for funding payments.
    
-   Update details of bank accounts already linked to BILL.
    
-   Change default bank for processing payments.
    
-   Delete a bank account linked with BILL.
    
-   Submit payments to BILL for processing.
    
-   Verifying your identity for the linked bank accounts in the User Verification page.
    
-   When your user profile is created with BILL for the first time.
    

Important:

You only need to complete MFA when there isn't an active trusted session with BILL. An example of a trusted session is when you have logged into NetSuite, successfully completed the authentication process, and connected to BILL.

#### To generate MFA from the User Verification page:

1.  Go to Payment Automation > Payment Dashboard > View.
    
2.  If you use OneWorld:
    
    1.  The **Subsidiary Dashboard** opens. Click **Enabled**.
        
    2.  In the Actions column, click **View** to open the Payment Dashboard for the selected subsidiary.
        
    
    If you do not use OneWorld, the **Payment Dashboard** opens directly.
    
3.  In the left panel, under Settings, click **User Verification**.
    
4.  On the User Verification page, click **Generate MFA** to generate a verification code.
    
    Note:
    
    The verification code is sent to the phone number you entered when you created your user profile with BILL.
    
5.  In the **Verification Code** field, enter the verification code you received, and then click **Verify** to complete the MFA.
