The Auto Bank Statement Import (ABSI) SuiteApp lets you to automate bank statement file imports by setting up a format profile that uses a Financial Institution Connectivity Plug-in to start an SFTP connection.

The first time a format profile that uses SFTP connectivity is saved:

-   NetSuite matches the file name pattern you set on your bank's server and imports the matching bank statement file into NetSuite.
    
-   NetSuite then sets up a daily schedule to import your bank statement files. Every day, NetSuite automatically brings in any new bank statement files that match your file name pattern from your bank into your accounts on the Match Bank Data page.
