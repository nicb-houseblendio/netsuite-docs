For bank accounts, you can create a new deposit for imported bank data right from the Match Bank Data page.

Note:

Tax codes and rates aren't available in the Add Deposit popup window. If you have a default tax code, the deposit gets created with it, but the tax rate is set to zero so the amounts match.

If tax codes are required, create your deposits from the Deposit page, and then match them. See [Making Deposits](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1542431.html).

For information about tax codes, see [Tax Codes Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1805593.html).

#### To add a new deposit during the matching process:

1.  Go to _Transactions > Bank > Match Bank Data_.
    
2.  From the **Account** list, select the bank or credit card account.
    
3.  (Optional) To provide matching data for the new deposit, from the Imported Bank Data grid, check a box to select an item.
    
    Note:
    
    Dimmed items are still processing, so you can't check the box until they're done. Refresh the Imported Bank Data grid to check.
    
4.  Click **Add Deposit**.
    
    NetSuite displays the Add Deposit popup window.
    
5.  Enter the deposit details. If you selected an imported bank line, some fields are filled in for you.
    
    Note:
    
    The **Payor** list displays available entity types. Start typing a payor's name to limit scrolling and narrow the results.
    
6.  Click **Add**.
    
7.  To refresh the Account Transactions grid, click the refresh icon above the pane on the right.
    
    The Account Transactions grid displays the new deposit, and NetSuite adds it to the bottom section for matching.
    

For details on adding deposits, see [Making Deposits](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1542431.html).

For information about deposits in general, see [Deposits](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N1542225.html).
