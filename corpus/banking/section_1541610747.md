Configure a format profile to automatically or manually import bank or credit card data for bank or credit card reconciliation.

-   **Format Profile for Automatic Import** - Uses a connectivity plug-in and transaction parser to configure a direct connection to a financial institution to retrieve bank data automatically. You can use standard plug-ins available through the Bank Feeds SuiteApp (see [Bank Feeds SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_158079179132.html)). Alternatively, you can use custom plug-ins built using the Financial Institution Connectivity Plug-in and Financial Institution Parser Plug-in interfaces. For details, see [Financial Institution Connectivity Plug-in](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/part_157859146675.html) and [Financial Institution Parser Plug-in](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/part_159078999530.html).
    
    For reasons why you would configure a format profile for automatic import, see [Automatic Bank Data Import](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157895109986.html).
    
-   **Format Profile for Manual Import** - Uses a transaction parser to manually import a bank file you have downloaded from a financial institution.
    
    For reasons why you would configure a format profile for manual import, see [Manual Bank Data Import](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157895093957.html).
    

Both manual and automatic import format profiles enable you to do the following:

-   Link financial institution accounts to corresponding accounts in NetSuite
    
-   Map custom bank codes to corresponding bank data types
    
-   Configure a parser plug-in, if parser configuration fields are available
    

Important:

Unless you're using the Bank Feeds SuiteApp, to avoid performance degradation, don't exceed these limits:

-   10,000 transactions for all bank data imports
    
-   500 linked accounts for automatic imports
    
-   2,500 linked accounts for manual imports
    

If an import will exceed the suggested limit for linked accounts, configure multiple format profiles for parallel imports.

For information about how many banking transactions you can import and how many accounts you can link using the Bank Feeds SuiteApp, see [Bank Feeds SuiteApp Limitations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158436030865.html).

To do the following procedure, you need the Financial Institution Records permission.

#### To create a format profile for bank reconciliation:

1.  Go to _Setup > Accounting > Financial Institution > List_.
    
    The Financial Institutions page appears.
    
2.  Next to the financial institution record for which you want to add a format profile, click **View**.
    
    The Financial Institution page appears.
    
3.  In the **Format Profile: Configuration** subtab, click **Add**.
    
    Important:
    
    You must be in View mode to enable the Add button. The button is not available in Edit mode.
    
    The Format Profile page appears.
    
4.  In the **Profile Name** field, enter a name for your format profile. For example, Wells Fargo - BAI2.
    
5.  In the **Description** field, enter a description to help you identify this format profile.
    
6.  From the **Profile Type** dropdown list, select **Bank Reconciliation**, which is the default profile type.
    
    You can't modify the profile type after you save.
    
7.  From the **Connectivity Method** dropdown list, select a Financial Institution Connectivity Plug-in or select **Manual Import**.
    
    For a plug-in to be available, you must create and upload one to NetSuite. For details, see [Financial Institution Connectivity Plug-in Interface Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_157833075219.html).
    
    Alternatively, if you have installed the Auto Bank Statement Import (ABSI) SuiteApp, you can use the SFTP Connectivity Plug-in available in the list. For details about the SuiteApp, see [Auto Bank Statement Import SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_159296303155.html).
    
    Important:
    
    If the list contains a plug-in provisioned by the Bank Feeds SuiteApp, do not select it. If you try to select such a plug-in on a custom format profile, an error occurs when you try to save it.
    
8.  From the **Transaction Parser** list, select a parser.
    
    The Transaction Parser field is required. For a plug-in to be available, you must either create and upload one to NetSuite or use a plug-in provided by the Bank Statement Parsers SuiteApp.
    
    Important:
    
    If the list contains a plug-in provisioned by the Bank Feeds SuiteApp, do not select it. If you try to select such a plug-in on a custom format profile, an error occurs when you try to save it.
    
    For details on parser configuration, see [Transaction Parser Configuration](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156781775317.html).
    
9.  If you selected a connectivity plug-in from the **Connectivity Method** list, do one of the following in the **Connectivity Configuration** subtab:
    
    -   If you selected a Financial Institution Connectivity Plug-in, configure a direct connection to a financial institution. See [Configuring a Connection to a Financial Institution (Without a SuiteApp)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_67170247225.html).
        
    -   If you selected an SFTP Connectivity Plug-in, configure a connection using an SFTP protocol. See [Configuring SFTP Connection for Auto Bank Statement Import](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_159114709493.html).
        
    
    If you selected **Manual Import** from the **Connectivity Method** list, this step is not applicable.
    
10.  Link financial institution accounts to corresponding accounts in NetSuite. For details, see [Bank Account Linking](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1541639171.html).
     
     For a successful import, you'll need at least one active linked account.
     
11.  (Optional) From the **Import Schedule** subtab, set an automated bank transaction import schedule. An automated import schedule ensures timely bank data updates for connected accounts set up in your format profile. It also supports more efficient reconciliation processes. For more information, see [Setting Up a Bank Import Schedule](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0107014921.html).
     
12.  (Optional) Map custom bank codes to corresponding bank data types in NetSuite. For details, see [Mapping Custom Bank Codes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1541638968.html).
     
13.  (Optional) If parser configuration fields are available, configure your transaction parser. See [Transaction Parser Configuration](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156781775317.html).
     
14.  Click **Save**.
     
     If the format profile is configured to connect to a financial institution and the save is successful:
     
     -   NetSuite displays a progress message that an import process has begun. To view the processing status of your import, click **Track your status** See [Banking Import History](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159622181091.html).
         
     -   For any newly-linked accounts, NetSuite imports the last 60 calendar days of data. You can change this if you use a connectivity plug-in and have set a different date in an Earliest Transaction Date for Import field on the Account Linking subtab in your format profile. NetSuite will then import based on the Earliest Transaction Date for Import instead. For any existing accounts, NetSuite imports any new data since the last successful import.
         
         Note:
         
         The Earliest Transaction Date for Import can't be edited for existing linkings after the initial import unless you change the linked account in NetSuite.
         
         Note:
         
         The following SuiteApps do not currently support configuring the earliest transaction date for imports. Instead, the date is fixed at 60 days prior to the current date. The related field and column do not appear in format profiles that use these SuiteApps:
         
         -   Australia Bank Feeds
             
         -   Auto Bank Statement Import
             
         -   Brazil Banking Integration
             
         
         If you are saving this format profile for the first time, NetSuite creates an import schedule based on your format profile settings. Daily import is the default. You change the schedule using the **Import Schedule** subtab on your format profile. For more information, see [Automatic Bank Data Import](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157895109986.html).
         
         Note:
         
         If your format profile contains plug-in implementations that aren't enabled in your account, the import process and initiation of the daily import schedule won't run. Select another plug-in, or enable the selected one. See [Creating a New Plug-in Implementation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4232566030.html).
         
     -   If you are using a connectivity plug-in, an **Update Imported Bank Data** button will appear on your Format Profile and Match Bank Data pages. Use this button to request an immediate import of bank or expense data outside of your automated import schedule.
         
     -   If you're using the Intelligent Transaction Matching feature, NetSuite uses reconciliation rules to automatically match your imported data to account transactions. To view automatically-matched transactions, see [Reviewing Match Suggestions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_202608110102.html). To match imported bank lines that require manual matching, see [Matching Bank Data](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_32131451402.html).
         
     -   If you are using the Automated Cash Application feature, you can automatically generate customer payments from your imported data and apply them to invoices. These generated payments are automatically matched and cleared in the system. See [Generating Customer Payments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_38152706945.html).
         
     
     If you have configured the format profile for manual import, you must go to the Upload File page to import data. For details, see [Manual Bank Data Import](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157895093957.html).
     
15.  Repeat these steps to create another Bank Reconciliation format profile.
     
     Tip:
     
     You can click on the hyperlinked financial institution name to go back to the financial institution record.
     

For details on the bank reconciliation process, see [Reconciling Bank and Credit Card Statements](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_61161354663.html).

For information about the automated cash application process, see [Automated Cash Application](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_2164712765.html).

For details on banking-related permissions, see [Permissions for Banking Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_156289552348.html).
