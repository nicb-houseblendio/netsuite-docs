The SuiteApp imports bank transactions into NetSuite daily through an automated import schedule. Depending on the number of posted transactions and how fast your bank responds, not all transactions may get imported into NetSuite.

In some cases, your bank may post transactions after the SuiteApp finishes its scheduled daily import. When this happens, the system won't import them until the next scheduled daily import. If you want these transactions available immediately in NetSuite, you can rebuild your financial institution connection.

#### To retrieve and import remaining transactions from the initial daily import:

1.  On the format profile page, click **Update Imported Bank Data** to import transactions for all connected accounts under the format profile record.
    
    1.  Go to Setup > Accounting > Financial Statements > Financial Institution.
        
    2.  Click **View** next to the **Bank Feeds** financial institution record.
        
    3.  In the **Format Profile: Configuration** subtab, choose any of the preinstalled format profile. The **Update Imported Bank Data** button is at the top of the Format Profile page in view mode.
        
2.  Alternatively, to import data for a specific account, go to the Match Bank Data page and click **Update Imported Bank Data**. For more information, see [Updating Imported Bank Data](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_28131953402.html).
    

You should only update imported bank data if you want to check for remaining transactions or if there was an import error.

## Limitations of Importing Bank Feeds Data {#subsect_0306083934}

Take note of the following limitations when importing your bank transactions into NetSuite:

-   The authorized Account Information Service Provider (AISP) of NetSuite retrieves bank transactions within a maximum time frame.
    
    -   To avoid errors from consecutive requests, you can only request for a bank data refresh every 60 minutes. The 60-minute waiting interval doesn't apply if a data import fails.
        
    -   For connected accounts using the U.S. and Canada Accounts (MX) Format Profile, you can only request for a bank data refresh one time every 3 hours.
        
    -   For connected accounts using any Salt Edge connection (Europe and Other Countries Bank Feeds Integration), you can only request for a bank data refresh up to 4 times per day per account.
        
-   For connections to accounts that require multi-factor authentication (MFA), the Update Imported Bank Data button is not supported. Clicking the button may result to an import error or Partially Completed import status. To retrieve and import your transaction into NetSuite, you must rebuild your connection.
