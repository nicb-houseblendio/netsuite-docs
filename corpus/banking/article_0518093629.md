Before you set up the Payment Automation Overview portlet:

-   Verify that your role includes the required IPA permissions. By default, only the Administrator, Payment Clerk, and Payment Manager roles can add the portlet. For more information, see [Setting Up Intelligent Payment Automation Roles and Permissions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0531124014.html).
    
-   If you use OneWorld, verify that you have access to the subsidiaries that you want to manage.
    

#### To set up the Intelligent Payment Automation Learning Hub portlet:

1.  Go to Payment Automation > Payment Automation Overview.
    
2.  Click **Personalize**.
    
3.  In the Personalize Dashboard section, click **Custom Portlet**, and then close the dashboard.
    
4.  In the Custom Content panel, click **Set Up**.
    
5.  In the Source field, select **Payment Automation Overview**.
    
6.  Click **Save**.
    
7.  Set the dashboard layout to **Single Column**.
    

## Publishing the Dashboard {#subsect_0518094041}

After you set up the portlet, publish the dashboard to make it available to existing employees with the selected roles. Only the Administrator and Payment Manager roles can publish dashboards. New employees and employees assigned a new role for the applicable center automatically see the dashboard.

#### To publish a dashboard:

1.  Go to your NetSuite home page.
    
2.  In the Settings portlet, click **List** beside **Publish Dashboard**.
    
3.  Select one of the following dashboards:
    
    -   IPA Classic Center
        
    -   IPA Accounting Center
        
4.  On the Publish Dashboard page, edit the IPA dashboard that you selected.
    
5.  On the Apply To Roles subtab, select the roles that need access to the dashboard.
    
    1.  Select a role from the list.
        
    2.  Set **Override Existing User's Settings** to **Yes**.
        
    3.  Click **Add**.
        
    4.  Repeat these steps for each additional role.
        
6.  Click **Save & Update Content**.
    
7.  Repeat these steps for the other dashboard, if needed.
    

The dashboard becomes available the next time an employee with an applicable role logs in. For more information, see [Publishing a Dashboard](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N633149.html#bridgehead_4640072108).
