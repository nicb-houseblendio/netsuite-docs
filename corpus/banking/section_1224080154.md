To create and submit bill payments for locked or closed accounting periods, enable non-GL changes for the periods. Then assign the required permission to the custom roles that create and submit payments.

To set up Intelligent Payment Automation for locked or closed accounting periods:

1.  For existing locked or closed accounting periods, check the **Allow Non-G/L Changes** box on the accounting period record. To update a period, go to Setup > Accounting > Manage G/L > Manage Accounting Periods, and then click the period name.
    
    For more information, see [Editing an Accounting Period](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1446881.html) or [General Accounting Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1385293.html).
    
2.  To automatically check this box for new accounting periods that you create, set the **Allow Non-GL Changes Is Set by Default** preference. For more information, see [Editing an Accounting Period](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1446881.html) or [General Accounting Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1385293.html).
    
3.  Assign the **Full** access level to the **Allow Non G/L Changes** permission to related custom roles.
    
    For more information, see [Permissions Related to Accounting Periods](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N1445226.html#subsect_1532733689).
    

## Payment Submission Validation for Closed Accounting Periods {#subsect_0729010614}

When you submit payments to BILL, NetSuite validates the posting period for each payment.

You can submit a payment if its posting period is open. You can also submit a payment if the posting period is closed, and the Allow Non-G/L Changes box is checked.

If the posting period is closed and the Allow Non-G/L Changes box is not checked, the payment is not submitted to BILL. The payment remains on the Payments to Submit page and is marked as ineligible.

On the Payments to Submit page, go to the Posting Period column. Point to the error icon for the ineligible payment to view why it cannot be submitted.

To submit the payment, reopen the accounting period or check the Allow Non-G/L Changes box for the period, and then submit the payment again. For more information, see [Payments to Submit](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0609053659.html).
