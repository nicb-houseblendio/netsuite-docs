Before printing a check, you can view the template the system uses to print the check. Where you view the template depends on whether your check uses a basic layout or a customized layout with Advanced PDF/HTML Templates. This procedure is about viewing templates for checks that use basic layouts. For information about advanced templates and how to view them, see [Advanced PDF/HTML Templates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4453550706.html) and [Viewing an Advanced Template in the Template Editor](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_163731932934.html).

#### To view templates for checks that use a basic layout:

1.  Go to _Customization > Forms > Transaction Form PDF Layouts_.
    
2.  Click **Customize** next to the layout you want to view.
    
    Note:
    
    To find out which transaction form layout a check uses, see the **Custom Form** field on the check record.
    
    NetSuite displays the template it uses to print the check.
    
3.  To see a preview of your print output, click **Preview**.
    

For more information about basic printing templates, see [Basic Printing Layouts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4453552264.html).
