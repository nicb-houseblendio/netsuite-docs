When you use the Bank Feeds SuiteApp, keep in mind the following limitations:

-   You can only connect to financial institutions in the following countries with the Bank Feeds SuiteApp:
    
    -   Canada
        
    -   Countries in Europe (includes United Kingdom)
        
    -   New Zealand
        
    -   Philippines
        
    -   Singapore
        
    -   Thailand
        
    -   United States
        
    
    For the list of supported financial institutions, see [Supported Financial Institutions for Bank Feeds SuiteApp](https://suiteanswers.custhelp.com/app/answers/detail/a_id/90911).
    
-   The Bank Feeds SuiteApp supports NetSuite's Multi-Language feature, but there are some limitations depending on your format profile configuration.
    
    -   **Bank Feeds Configuration for U.S. and Canada (Yodlee and MX)** - The setup on the popup window of these format profiles only supports English.
        
    -   **Bank Feeds Configuration for Europe (PSD2 and Non-PSD2 Regulated) and Other Countries** - The setup under the Connectivity Configuration subtab and in the popup window of these format profiles support the Multi-Language feature. However, some legal terms and financial institution websites don't support all NetSuite user interface languages. In this case, some text will remain in English or the website's respective language.
        
-   Manual initiation of bank data import is only allowed every 60 minutes. For example, NetSuite won't import data from the same format profile twice within a 60-minute period.
    

## U.S. and Canada Bank Feeds Integration {#bridgehead_160021882899}

When you set up the U.S. and Canada bank feeds in NetSuite, the SuiteApp is mainly designed to cater to small and medium-sized companies only.

You have two format profile options for connecting to banks in the U.S. and Canada:

-   **U.S. and Canada Accounts (Yodlee) Format Profile** - This format profile lets you have up to 20 accounts (of any type), 10,000 transactions, or a combination of both per unique login credential for a financial institution.
    
    If you connect to a financial institution with more than these limits per unique login credential, you may experience slower performance or time out errors.
    
    If you have more than 20 accounts under one login and need to connect them all to NetSuite, ask your bank to split access across multiple credentials. For example, if you have 30 accounts in one bank, a good setup would be three bank login credentials with 10 accounts each.
    
    Starting with version 22.1.0, the maximum 20 accounts limitation doesn't apply if you're connecting to a financial institution that uses open banking technology. However, it's best to keep each import under 10,000 transactions to maintain performance.
    
    The Yodlee format profile is no longer available to new customers as a preinstalled option, but it remains available to customers with Bank Feeds SuiteApp versions installed before February 4, 2026. For more information, see [Preinstalled Bank Feeds Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_0330101903.html).
    
-   **U.S. and Canada Accounts (MX) Format Profile** - This format profile has higher limits, so you can pull data from up to 100 accounts with a maximum of 25 credentials. The AISP for this format profile also supports more banks and financial institutions using Open Authorization (OAuth) technology. This means you get more stable and secure connections, and you won't have to reauthorize as often.
    
    To avoid performance degradation, don't set up a bank data import with more than 10,000 transactions.
    

If the financial institution you want to connect exceeds the current limit, you should use the following SuiteApps instead:

-   [Auto Bank Statement Import SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_159296303155.html)
    
-   [Bank Statement Parsers SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1566294502.html)
    

## Europe and Other Countries Bank Feeds Integration {#bridgehead_160021899223}

The SuiteApp lets you connect up to 100 financial institutions and link 450 accounts across all your financial institution connections.

Important:

The authorized Account Information Service Provider (AISP) of NetSuite takes up to 20 minutes to retrieve bank data from a financial institution. However, the response time of a financial institution can affect the bank data retrieval process.

For example, when the financial institution takes more than 20 minutes to send bank and credit card information to the AISP. You may see import errors or miss some transactions in NetSuite because the retrieval took too long.

To avoid performance degradation, don't set up a bank data import with more than 10,000 transactions. If an import reaches the transaction limit, the rest of the transactions are imported during the next scheduled or manually started import. To start a manual bank transaction import, see [Updating Imported Bank Feeds Data](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158847536770.html).
