In OFX/QFX files, the transaction code is inside the TRNTYPE tag for every transaction. For example:

![A section of an OFX/QFX-formatted file](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Accounting/Banking/BSP_BTCOFX.png)

The following table lists the supported transaction codes for the OFX/QFX parser:

| CREDIT | DEP | CASH |
| --- | --- | --- |
| DEBIT | ATM | DIRECTDEP |
| INT | POS | DIRECTDEBIT |
| DIV | XFER | REPEATPMT |
| FEE | CHECK | OTHER |
| SRVCHG | PAYMENT |  |
