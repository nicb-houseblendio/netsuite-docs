Important:

This feature is available only to eligible NetSuite Next customers. NetSuite Next is being made available to customers in phases and may not yet be available in your account. You'll receive in-app notifications when your account is eligible for NetSuite Next.

This feature uses OpenAI. AI features can produce inaccurate or incomplete results. Always review recommended matches and consider additional business context before you submit a match.

The Transaction Matching Assistant is part of the match suggestions experience. It uses AI to help you resolve ambiguous matches during bank reconciliation and can help reduce manual review. When multiple possible matches remain for an imported bank transaction, the assistant evaluates transaction details and recommends the most likely match. Additional match options are displayed for comparison. The assistant doesn't create matches or transactions.

Note:

The assistant evaluates only the current transaction and candidate matches. It does not learn from past decisions or improve over time.

To use the assistant, you need the same permissions required to access the Match Bank Data page. For more information, see [Permissions for Banking Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_156289552348.html).

You can enable this feature on the Accounting subtab of the Enable Features page (_Setup > Company > Setup Tasks > Enable Features_).

Note:

For eligible accounts created after May 14, 2026, the feature is enabled by default. For eligible accounts created before May 14, 2026, the feature is disabled by default.

## How the Assistant Fits into the Matching Process {#subsect_4194927047}

During bank reconciliation, NetSuite applies multiple matching methods to identify matching transactions:

-   System and custom matching rules can identify matching transactions.
    
-   If enrichment-based matching is available, NetSuite can use enriched transaction details from bank transactions to help find a match. This applies only when multiple candidate matches exist and certain conditions are met. For more information, see [Enriched Bank Data for Transaction Matching](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0305111754.html).
    
-   The assistant evaluates candidate matches when ambiguity remains. It considers details such as payee or payor name, memo content, and transaction date proximity.
    
-   The assistant considers only one-to-one match candidates. It doesn't support payment application workflows.
    

## What You'll See {#subsect_33194919750}

When the Transaction Matching Assistant identifies a potential match, the recommendation appears on the Match Suggestions subtab. Rows with AI-assisted match suggestions are marked with an AI recommendation indicator.

When multiple match options are available, **Review Match Options** appears in the Suggested Action column. Click **Review** to view the AI-assisted recommendation and other match candidates.

In the expanded details for the imported transaction, you can do one of the following:

-   Click **Match and Submit** to submit the AI-assisted recommendation.
    
-   If the recommendation isn't correct, select another suggested match and click **Match and Submit**.
    
-   If none of the match options are correct, click **Reject Suggestions**.
    

AI-assisted recommendations are not submitted automatically. You must review a recommendation before submitting it.

For more information about reviewing and submitting suggestions, see [Reviewing Match Suggestions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_202608110102.html).

## When Recommendations Appear {#subsect_82194910125}

A recommendation only appears when multiple candidate matches exist for an imported transaction after system and custom matching rules run.

Transaction Matching Assistant recommendations are generated during bank transaction import and when you manually run reconciliation rules.
