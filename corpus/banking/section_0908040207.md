The Payment Processing section includes lists of transactions and records related to payment processing and vendors. You can use the available buttons and links to complete tasks for a payment or vendor. You can also sort the lists and records in ascending or descending order, based on the selected field.

Note:

Rejected applications or subsidiary accounts deactivated by BILL do not have access to the dashboard.

For roles, permissions, and subsidiary setup requirements, see [Payment Dashboard](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0626062427.html).

You can bookmark supported pages under Payment Processing and open them directly. Supported pages include Payables, Payment Runs, and Payments to Submit. If you open a bookmarked URL without an active NetSuite session, you are prompted to sign in. After you sign in, NetSuite opens the bookmarked page. If you already have an active session, the page opens immediately.

For OneWorld accounts, bookmarked URLs preserve the subsidiary context, so the page opens for the correct subsidiary. Existing NetSuite authentication, role, subsidiary access, permissions, and invalid URL handling continue to apply.

#### To use the dashboard's Payment Processing section:

1.  Go to Payment Automation > Payment Dashboard > View.
    
    Note:
    
    By default, these roles have preconfigured permissions to access Payment Processing: Administrator, Payment Manager, and Payment Clerk. For standard or custom roles and permission requirements, see [Setting Up Intelligent Payment Automation Roles and Permissions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0531124014.html).
    
2.  If you use OneWorld:
    
    1.  The **Subsidiary Dashboard** opens. Click **Enabled**.
        
    2.  In the Actions column, click **View** to open the Payment Dashboard for the selected subsidiary.
        
    
    If you do not use OneWorld, the **Payment Dashboard** opens directly.
    
3.  In the left panel, in Payment Processing section, click the page you want to view.
    
4.  (Optional) At the left panel's header, from the dropdown list, you can select another subsidiary that you have access to.
    

For the selected subsidiary, you can access the lists and complete tasks in the following pages under Payment Processing:

## Payables {#subsect_0908040554}

On the Payables page, you can view a list of bill and journal transactions associated with the subsidiary based on your selected bank and AP accounts.

For bills that you can pay for one or more vendors, you can do the following:

Tip:

If you do not find bills for a specific vendor, that vendor may not be synced with BILL. The vendor may also be excluded from Intelligent Payment Automation. To view the list of vendors, click **Vendors**. See [Vendor Syncing with BILL](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0604082046.html#subsect_0905023643) or [Excluding Vendors from Intelligent Payment Automation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0604082046.html#subsect_0730110127) for more information.

-   **Filter the list of transactions** - Beside the Search box, the following filters enable you to narrow down the list of transactions: **AP Account**, **Due Status**, **Payee**, **Payee Status**, **Due On or After**, and **Due On or Before**. Alternatively, the value for any of these filters can be entered in the Search box.
    
    Beside each filter, the **x** icon can be used to clear the selected or entered value.
    
-   **Pay multiple bills through a payment run** - A box appears next to each bill that you can include in a payment run. If you check a box, you can edit the bill's **Discount** field or reduce the value in the **Payment Amount** field. Also, the **Create Payment Run** button appears enabled at the header.
    
    For instructions, see [Creating a Payment Run](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0606092833.html).
    
-   **View bills with issues** - A disabled box appears next to each bill that cannot be processed. In any of the columns, data with issues appear with an error icon.
    
    For example, in the **Reference No.** column, when you point to the error icon for a blank cell, the following message appears: **Reference Number is empty**. To update the bill, in the **Transaction Type** column, click the **Bill** link.
    

## Payment Runs {#subsect_0908040827}

On the Payment Runs page, you can view the details of existing payment runs. The following filters enable you to narrow down the list: **Bank Account**, **Payment Creation Date**, and **Status**. Alternatively, the value for any of these filters can be entered in the Search box.

To further process payment runs that you create, see the following topics:

-   For instructions and requirements for approvers, see [Approve Payment Run Permissions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0802124513.html#subsect_0804034128).
    
-   Depending on the payment status, if you want to cancel or void payments, see [Canceling and Voiding Payments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0805062605.html).
    
-   To track payment run statuses, see [Payment Run Statuses](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0813115922.html).
    

## Payments to Submit {#subsect_0908041102}

On the Payments to Submit page, you can view the list of approved payments that you can submit to BILL for processing. The **Submit Payments** option shows if you have payments for submission. For instructions, see [Payments to Submit](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0609053659.html).

If you can't access the list, the following messages may appear at the header:

-   **User Not Onboarded to BILL**
    
-   **Bank Accounts Not Verified**
    

Within the banner, click the **User Verification** link to go to the User Verification section under Settings. For instructions, see [User Verification](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0813115919.html).
