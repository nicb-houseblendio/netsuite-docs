After you match or clear transactions, you can reconcile your account statement at _Transactions > Bank > Reconcile Account Statement_ (Administrator).

If you check or clear the box for each transaction on the Reconcile subtab, NetSuite saves your work as you go. You can leave and return later-the page will show your progress.

If you change a previously reconciled transaction's amount, it becomes unreconciled. Open the correct statement period and reconcile it again.

To troubleshoot reconciliation issues, see [Troubleshooting Reconciliation Issues](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_20260810010.html).

If you reconcile a statement and then get more transactions you want to include, delete the reconciled statement for that period and start over. See [Deleting Reconciled Statements](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_20260810012.html).

You can view account reconciliation reports for reconciled statements. See [Account Reconciliation Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1508786400.html). To print the reports, see [Printing Reconciliation Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1554190.html).

Note:

If you change the transaction's account, it doesn't become unreconciled.

#### To reconcile a statement:

1.  Go to _Transactions > Bank > Reconcile Account Statement_.
    
2.  From the **Account** list, select the bank or credit card account, if not already selected.
    
    Note:
    
    As of NetSuite 2021.1, all newly-created accounts automatically appear in the **Account** list. If your account does not appear, see [Editing Accounts to Use the Match Bank Data and Reconcile Account Statement Pages](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_20260810001.html).
    
    NetSuite displays the currency for the selected account.
    
    In the **Statement End Date** and **Ending Statement Balance** fields, NetSuite displays the end date and closing balance from the most recent account statement with a statement date.
    
    Note:
    
    If no statement has a statement date, the **Statement End Date** field gets the current date, and the **Ending Statement Balance** field gets the balance from the last reconciliation.
    
3.  If not already selected, in the **Statement End Date** field, enter or select the end date.
    
    Note:
    
    If you receive more transactions for a reconciled date range, and you want to include them, delete the reconciled statement and create a new reconciliation. To delete the reconciled statement, see [Deleting Reconciled Statements](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_20260810012.html). You should choose a Statement End Date in the past (for example, the day before the current date).
    
4.  In the **Ending Statement Balance** field, enter or edit the closing balance on the statement, if required.
    
    The field uses the ending balance from the imported statement, if there is one.
    
    The **Last Reconciled Balance** field provides the balance of this account from the last reconciled statement.
    
    NetSuite updates the **Reconciled This Statement** field as you include or exclude transactions in the **Reconcile** subtab.
    
5.  If needed, review matched or cleared transactions on the Review subtab. Use the selection options on this subtab only to undo transactions. To reconcile transactions, use the Reconcile subtab.
    
6.  Open the Reconcile subtab to view matched and cleared transactions that are ready for reconciliation. The Reconcile subtab displays transactions from the Match Bank Data page.
    
    Note:
    
    As of NetSuite 2021.2, when you edit your account to use the redesigned reconciliation feature, any previously-held transactions are automatically cleared and appear in the **Reconcile** subtab. See [Editing Accounts to Use the Match Bank Data and Reconcile Account Statement Pages](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_20260810001.html).
    
7.  To filter the list of transactions:
    
    -   To set the date range for transactions in the list, enter or select the dates in the **From** and **To** fields at the top of the pane.
        
    -   From the **Type** list, select a transaction type.
        
    -   To switch from a list of all transactions to only the included transactions, click **Show Included Only**.
        
    -   In the **Search** field, start typing the text or number value on which to search. As you type, NetSuite narrows the search results in the list.
        
        When entering a date, use a date format consistent with the displayed format in the page (as set in the User Preferences). For example, if you use a long date format (May 1, 2018), enter **May** to search for a date in May. When entering a year, use four digits (for example, 2018). If you use a short date format, always use two digits for the month or day (for example, 05/01/2018).
        
    -   To sort by column, click the column header.
        
    
    If the number of transactions in the list exceeds the page limit, click the arrows to see the next or previous page of results.
    
8.  To include or exclude all of the transactions, check or clear the box in the column header.
    
    If filters are active, checking the box selects all filtered transactions on the current page. Selections persist as you go between pages. If any selected transaction is part of a match group, all transactions in that group are included as well.
    
    For example, if you filtered the list by a date range and type, the filtered transactions and their match groups are selected on all the pages.
    
9.  To include or exclude a transaction from the statement, check or clear the box next to the transaction.
    
    On the Review subtab, use Select Matched Transactions or Select Cleared Transactions to select transactions for Undo Selected. You can also select individual transactions using the check boxes.
    
    Note:
    
    If a transaction is part of a match group that contains multiple NetSuite transactions (a one-to-many or many-to-many match), you cannot exclude it. The box is unavailable.
    
    Excluded transactions retain their matches and cleared status, but NetSuite excludes them from the reconciliation.
    
    NetSuite only reconciles transactions you've included.
    
    Tip:
    
    To switch from a list of all transactions to only the included transactions, click **Show Included Only**.
    
10.  Make sure you've selected all transactions you want, and then click **Reconcile**. You can reconcile a statement even if the amount isn't zero.
     
     If you don't select any transactions, clicking **Reconcile** includes them all.
     
     NetSuite displays the Close Statement popup window.
     
     Warning:
     
     You can't change the Statement End Date later. This date becomes the Close Date, which NetSuite uses to run the Reconciliation report and Reconciliation History reports.
     
     If you reconcile with today's date, and get more transactions that day, you can't pick them for your next reconciliation. To avoid this, use a Statement End Date in the past.
     
11.  Click **OK**.
     
     NetSuite takes you to the Reconciled Statements list page.
