Currently, only the AMEX Corporate Card Integration SuiteApp is supported to automate AMEX corporate card charge imports. See [American Express Integration for Expense Reporting](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159122395131.html).

A custom connectivity plug-in to set up a direct connection to another provider isn't supported yet. If you need to import corporate card charges from another provider, you should use manual import. See [Importing Data Using a Financial Institution Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1556568135.html).
