The OFX/QFX parser plug-in parses bank and credit card statement files that use OFX/QFX versions 102, 103, 211, and 220. The parser recognizes default and standard OFX/QFX bank transaction codes and supports using a period (.) or comma (,) as a decimal separator.

No configuration is required.

To identify the supported OFX/QFX transaction codes, see [OFX/QFX Transaction Codes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1567493883.html). For help with import errors, see [OFX/QFX File Import Error Messages](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1566298500.html).
