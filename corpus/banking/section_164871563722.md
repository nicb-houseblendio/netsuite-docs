-   To obtain accurate reports in the Cash 360 dashboard, an administrator must do the following before installing the Cash 360 SuiteApp:
    
    -   To use aging reports in this SuiteApp, set the **Aging Reports Use** preference.
        
        Go to Setup > Accounting > Accounting Preferences > General and select the **Due Date** option under the **Aging Reports Use** preference.
        
    -   To approve invoices using this SuiteApp:
        
        -   Enable the following required features. For instructions on enabling features, read [Enabling Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N232138.html).
            
            | Subtab | Feature |
            | --- | --- |
            | Employees | Approval Routing |
            | SuiteCloud | Client SuiteScript Server SuiteScript SuiteFlow |
            
        -   Set the **Invoices Approval Routing** preference.
            
            Go to Setup > Accounting > Accounting Preferences > Approval Routing and check the **Invoices** box.
            
    -   To include installment transactions in the Cash 360 calculations, enable the Installments feature from the **Accounting** subtab. For instructions on enabling features, read [Enabling Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N232138.html).
        
    -   If your company uses multiple currencies, enable the following features. For instructions on enabling features, read [Enabling Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N232138.html).
        
        | Subtab | Feature |
        | --- | --- |
        | Company | Multiple Currencies |
        | SuiteCloud | SuiteCloud Development Framework |
        
-   Ensure there are no access restrictions to the Subsidiary record. Remove any value selected in the **Subsidiary** field under Set Preferences > Restrict View > Subsidiary.
    
    If there is a value selected in the Subsidiary field, it means your access is restricted only to that selected subsidiary and consolidated subsidiary cash forecasts may not work properly.
    
-   Set the **Report by Period** user preference to accurately display values in the Cash 360 tiles. Go to Set Preferences > Analytics > Reporting and select **Financials Only** in the **Report By Period** field.
