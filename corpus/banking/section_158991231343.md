Auto-create rules contain conditions and actions that you can edit.

Conditions are the criteria the rule looks for in future imports. Auto-create rules check the Payor/Payee first, and then the Memo. You can add more conditions if needed. For details, see [Editing Rule Conditions of Auto-Create Rules](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158991234444.html).

Actions are the actions the rule takes if the conditions are met. The rule uses a memorized transaction record as a template to create future account transactions. You can override these values by changing the rule's actions.

For details, see [Editing Action Data of Auto-Create Rules](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158991235974.html).

For information about memorized transactions, see [Memorized Transactions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N564245.html).
