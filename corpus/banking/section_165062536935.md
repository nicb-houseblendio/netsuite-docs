The cash forecast computation varies for account categories and for additional values. The computation also varies for a single subsidiary and for a consolidated subsidiary.

For more information, read the following topics:

-   [Cash Forecast Computation for Account Categories in a Single Subsidiary](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_2180120302.html#bridgehead_39173645947)
    
-   [Cash Forecast Computation for Additional Values in a Single Subsidiary](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_2180120302.html#bridgehead_82142654297)
    
-   [Consolidated Cash Forecast Computation for Account Categories](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_82181156723.html#bridgehead_59191313499)
    
-   [Consolidated Cash Forecast Computation for Additional Values](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_82181156723.html#bridgehead_93165952368)
    

The following table shows the factors affecting the cash forecast computation for a single subsidiary and for a consolidated subsidiary.

| Single Subsidiary | Consolidated Subsidiary |
| --- | --- |
| Account categories Additional values Cash forecast preferences | Account categories Additional values Cash forecast preferences Consolidated exchange rate type Consolidated exchange rate |
