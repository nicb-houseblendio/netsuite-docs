**What should I do if I want to schedule a recurring Virtual Card payment that can be sent to a supplier because I send the same amount each month to this supplier?**

HSBC Virtual Card payments allow you to pay invoices using a secure payment method. Each Virtual Card contains the exact payment amount, for a given supplier in reference to a unique invoice for a specified time period, after which the Virtual Card expires. So, you can't set up recurring payments.
