You set check printing preferences on the Printing & Fax Preferences page.

Note:

Check printing preferences, including the Default Check Type, only apply to basic printing layouts. If you have the Administrator role, you can use advanced printing layouts to customize your printed forms. You can customize forms with Advanced PDF/HTML templates. For more information, see [Advanced PDF/HTML Templates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4453550706.html).

#### To set check printing preferences:

1.  Go to _Setup > Company > Preferences > Printing & Fax_.
    
2.  Click the **Printing** subtab.
    
3.  Under Check Printing, in the **Default Check Type** field, choose one of two check types:
    
    -   **Standard** - printed without a voucher, three checks per 8.5 x 11 inch sheet.
        
    -   **Voucher** - printed at the top of an 8.5 x 11 inch sheet with voucher information at the bottom, one check per sheet.
        
        If you use voucher checks, you can print up to 19 line items on each check. If you have more than 19 line items for a single check, the extra items won't appear on the voucher.
        
        Always print the check at the top. NetSuite doesn't support printing checks in the middle of the page.
        
    
    Note:
    
    When you customize a check form PDF layout, you see only the check, not vouchers, no matter your check type preference. Even if you change the page size, you can only add or edit standard check elements. For information about customizing check layouts, see [Customizing Transaction Form PDF Layouts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2869660.html).
    
4.  Select a font style in the **Check Font** field.
    
    Note:
    
    The preferences in steps 3 and 4 don't affect the layout of the check form.
    
5.  Select a font size in the **Check Font Size** field.
    
6.  Click **Save**.
    

If your organization uses basic printing, you can set a different check template for each subsidiary. For information, see [Specifying Check Layout by Subsidiary](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1513338497.html).

## Adjusting Check Printing Position {#bridgehead_N1545650}

If you need to adjust the printing position for the text on the check form, go to _Home > Set Preferences_. On the **Transactions** subtab in the Printing section, changes the values in the **Horizontal** and **Vertical Print Offset** fields. Changes the values on the Set Preferences page affects all checks you print.

Automatic scaling in the Page Handling section of the Print window can cause problems when printing checks. Ensure that **Page Scaling** is set to **None**, and the boxes below it are cleared in the Print window.
