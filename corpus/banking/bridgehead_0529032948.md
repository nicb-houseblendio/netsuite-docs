You can track the application status from the Status page. Go to SuiteBanking > HSBC Application > Apply to check the list of applications and their statuses. The sublist displays the **Application ID**, **Subsidiary**, **Submitted By**, **Account Application Status**, **Credit Application Status**, and **Action**.

The status of the application could be:

| Status | Description |
| --- | --- |
| Submitted | The application has been submitted for review. |
| Completed | The application has been approved by HSBC. |
| Pending Review | The application is pending review by HSBC. |
| Cancelled | The application has been cancelled by HSBC due to improper or incorrect data. |
| Ineligible | You have not met eligible criteria for opening a HSBC bank account. |

In Actions column, click **Resume** to continue working on the application or click **Show Details** to see more information about the application. The Verification page is displayed for a completed application.

Note:

You need to have access to the subsidiary for which the application is raised to view the details of the respective subsidiary.
