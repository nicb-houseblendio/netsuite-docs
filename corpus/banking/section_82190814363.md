Click the accounts payable amount in the Cash Forecast table to open a window that lists all accounts included in the accounts payable amount calculation. You can only click the accounts payable amount if it is greater than zero.

#### To view the accounts payable details:

1.  Go to Financial > Cash 360 > Dashboard.
    
2.  On the left pane, click **Cash Forecast** to display the Cash Forecast table.
    
    The default display of the Cash Forecast table is always based on the currently logged-in user's subsidiary. To display the table for another subsidiary, select the subsidiary in the upper right corner of the page.
    
3.  Click the accounts payable amount.
    
    The Accounts Payable window opens and displays the following information:
    
    | Item | Description |
    | --- | --- |
    | Account Category | This field displays the account category for the amount. For example, if the amount is an accounts payable amount, this field displays Accounts Payable. |
    | Total Amount | This field displays the total accounts payable amount that fall on the date, week, or month specified. |
    | Period | This field displays the period covered for the total accounts payable amount. |
    | Currency | This field displays the currency of the total accounts payable amount. |
    | Subsidiary | This column displays the subsidiary of the transaction that contributed to the total accounts payable amount calculation. |
    | Transaction Number | This column displays the ID of the transaction that contributed to the total accounts payable amount calculation. Click the transaction ID to open the transaction record. |
    | Reference Number | This column displays the reference number of the transaction. |
    | Transaction Type | This column displays the type of transaction that contributed to the total accounts payable amount calculation. For example: Bill Payment |
    | Entity | This column displays the entity for the transaction that contributed to the total accounts payable amount calculation. Entity can be a customer name, vendor name, employee name, or other entities. |
    | Transaction Date | This column displays the date of the transaction that contributed to the total accounts payable amount calculation. |
    | Due Date | This column displays the due date of the installment amount or due date of the transaction that contributed to the total accounts payable amount calculation. |
    | Terms | This column displays the installment term of the transaction that contributed to the total accounts payable amount calculation. This column is only available if there is an installment term created for the transaction. For more information about creating installments, see [Creating Installments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1540928779.html). |
    | Installment Amount (Currency) | This column displays the installment amount that is payable for a given period. This column is only available if there is an installment term created for the transaction. For more information about creating installments, see [Creating Installments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1540928779.html). |
    | Amount Due (Currency) | This column displays the amount due for a given period for the payable transaction that contributed to the total accounts payable calculation. For installment transactions, this column displays the installment amount. If there is no payable amount due for a given period, this column displays 0. |
    | Transaction Amount (Currency) | This column displays the total payable transaction amount. The amount is shown in the currency of the selected subsidiary or consolidated subsidiary. |
    | Status | This column displays the status of the transaction that contributed to the total accounts payable amount calculation. For example: Partially Paid |
    | Close Date | This column displays the close date of the payable transaction. For example, close date of the bill payment. |
    | Foreign Currency Amount | This column displays the transaction amount or installment amount for payable transactions, in the transaction currency. |
    | Transaction Currency | This column displays the currency of the transaction. |
    
4.  (Optional) To view more than 100 transactions, under the Accounts Payable Details section, click the **Export to** icon and select **CSV** to export the report as a CSV file.
    
    The Accounts Payable window displays up to 100 recent transactions. Use Export to CSV to view all transactions.
