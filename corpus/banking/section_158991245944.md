You can manually run reconciliation rules from the Match Bank Data page. For permission details, see [Permissions for Banking Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_156289552348.html).

Important:

NetSuite doesn't run the Automated Cash Application feature when you manually run reconciliation rules from the Match Bank Data page.

#### To manually run reconciliation rules:

1.  Go to _Transactions > Bank > Match Bank Data_.
    
2.  From the **Account** list, select the appropriate account.
    
    Note:
    
    If NetSuite is currently running reconciliation rules against the selected account, a warning notification appears. Do not run additional reconciliation rules against the selected account until the previous rule running request is complete. After the request is complete, refresh the page. You can track your import status on the Process Status page at Setup > Company > Bulk Processing Status List.
    
3.  Click **Run Reconciliation Rules**.
    
    A confirmation window appears.
    
    Note:
    
    If NetSuite is already running reconciliation rules against the selected account, a warning notification appears. Refresh the page when the request is complete and rerun the rules if needed.
    
4.  Specify the date range you want the system to run rules against. This date range is based on when transactions were imported, not the transaction date. By default, the date range is set to the previous 30 days. Make sure the end date isn't later than today.
    
    Tip:
    
    If you run reconciliation rules across a large date range (such as several years of unprocessed transactions), processing time may increase. For best results, consider running reconciliation rules in smaller batches.
    
5.  If you're sure, click **Run Reconciliation Rules** to initiate the reconciliation rule running process. After the process begins, you cannot cancel. If you need to stop a process in progress, contact NetSuite Support.
    
    A notification appears to indicate the process has started. The message includes a **Track your status** link, which you can click to view the processing status. All active system and user reconciliation rules run against transactions that have been imported during the date range you specified. Also, the built-in rule for matching in-transit payments is run.
    

To see your results, refresh the page and reload your account.

Note:

If a rule finds two or more possible matches, NetSuite can't choose one, so you need to pick and match the correct transaction yourself.

For example, say you import a $70 bank deposit dated 03/22/2023. NetSuite finds two possibilities: a $70 deposit from 02/14/2023 and another from 01/16/2023. Because both are the right amount and at or before the imported deposit's date, the system can't decide. You need to choose and match the right transaction yourself.

For troubleshooting information, see [Troubleshooting Manual Reconciliation Rule Running Issues](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1014015521.html).
