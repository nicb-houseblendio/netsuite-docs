If you encounter errors while setting up or after setting an import schedule, see the following table for error and troubleshooting steps:

| Error | Cause | Recommended Action |
| --- | --- | --- |
| **Record Not Saved** Make sure every field under Import Schedule has a value or leave them all blank. | All fields under the Import Schedule subtab must be filled or left blank. Partial entries are not allowed. The validation error pops up if you try to save a partially filled schedule. | Ensure to meet one of the following criteria:
-   All fields are filled, using either the default values or your preferred values.
-   All fields are left blank. The system uses the default values.

 |
| This format profile does not contain any active linked accounts. To import banking data using this format profile, you require at least one active linked account. Click OK to continue saving or click Cancel to go back and edit the record. | If a profile doesn't have at least one active account linked, there is no associated schedule. Imports don't run until you make the changes to meet the appropriate conditions. | To set a schedule in the Import Schedule subtab, link an active account in the Account Linking subtab. If no accounts are linked in the Account Linking subtab, the Import Schedule subtab appears but its fields remain unavailable. |

Note:

The import time in the imported data is based on the chosen time zone in the schedule, regardless of the system's time zone. Only the last successful import time displayed on Format Profile and Match Bank Data pages will be according to your respective time zone.
