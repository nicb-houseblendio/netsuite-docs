Click the opening balance amount in the Cash Forecast table to open a window that lists all accounts included in the opening balance amount calculation. Bank accounts excluded from the Cash 360 calculations are not included in the list. For more information, see [Excluding Bank Accounts from Cash 360 Calculations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0219083320.html). You can only click the opening balance amount if it is greater than zero.

The row that displays the opening balance amount is only displayed if the **Include Opening Balance** box is checked in the SuiteApp's Preferences page. For more information, see [Setting Cash 360 Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164974435218.html).

#### To view the opening balance details:

1.  Go to Financial > Cash 360 > Dashboard.
    
2.  On the left pane, click **Cash Forecast** to display the Cash Forecast table.
    
    The default display of the Cash Forecast table is always based on the currently logged-in user's subsidiary. To display the table for another subsidiary, select the subsidiary in the upper right corner of the page.
    
3.  Click the opening balance amount for the current day, week, or month.
    
    Note:
    
    Take note of the following:
    
    -   The Opening Balance row is only displayed if the **Include Opening Balance** box is checked in the SuiteApp's Preferences page. For more information, see [Setting Cash 360 Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164974435218.html).
        
    -   You can only click the current opening balance amount and not the opening balance for the succeeding days, weeks, or months.
        
    
    The Opening Balance window opens and displays the following information:
    
    | Item | Description |
    | --- | --- |
    | Account Category | This field displays the account category for the amount. For example, if the amount is the opening balance amount, this field displays Opening Balance. |
    | Total Amount | This field displays the total opening balance amount that fall on the date, week, or month specified. |
    | Period | This field displays the period covered for the total opening balance amount. |
    | Currency | This field displays the currency of the total opening balance amount. |
    | Subsidiary | This column displays the subsidiary of the account that contributed to the total opening balance amount calculation. |
    | Account Name | This column displays the account name that contributed to the total opening balance amount calculation. |
    | Transaction Amount (Currency) | This column displays the amount that contributed to the total opening balance amount calculation. The amount is shown in the currency of the selected subsidiary or consolidated subsidiary. |
    
4.  (Optional) Under the Opening Balance Details section, click the **Export to** icon and select **CSV** to export the report as a CSV file.
    
    The Opening Balance window displays up to 100 recent transactions. Use Export to CSV to view all transactions.
