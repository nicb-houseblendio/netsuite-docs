Click the undeposited/future-period funds amount in the Cash Forecast table to open a window that lists all accounts included in the undeposited/future-period funds amount calculation. You can only click the undeposited/future-period funds amount if it is greater than zero.

The row that displays the undeposited/future-period funds amount is only displayed if the **Include Opening Balance** box is checked in the SuiteApp's Preferences page. For more information, see [Setting Cash 360 Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164974435218.html).

#### To view the details of undeposited/future-period funds:

1.  Go to Financial > Cash 360 > Dashboard.
    
2.  On the left pane, click **Cash Forecast** to display the Cash Forecast table.
    
    The default display of the Cash Forecast table is always based on the currently logged-in user's subsidiary. To display the table for another subsidiary, select the subsidiary in the upper right corner of the page.
    
3.  Click the undeposited/future-period funds amount.
    
    Note:
    
    The Undeposited/Future-Period Funds row is only displayed if the **Include Opening Balance** box is checked in the SuiteApp's Preferences page. For more information, see [Setting Cash 360 Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164974435218.html).
    
    The Undeposited/Future-Period Funds window opens and displays the following information:
    
    | Item | Description |
    | --- | --- |
    | Account Category | This field displays the account category for the amount. For example, if the amount is an undeposited/future-period amount, this field displays Undeposited/Future-Period Funds. |
    | Total Amount | This field displays the total undeposited/future-period funds amount that fall on the date, week, or month specified. |
    | Period | This field displays the period covered for the total undeposited/future-period funds amount. |
    | Currency | This field displays the currency of the undeposited/future-period funds amount. |
    | Subsidiary | This column displays the subsidiary of the account that contributed to the total undeposited/future-period funds amount calculation. |
    | Transaction Number | This column displays the ID of the transaction that contributed to the total undeposited/future-period funds amount calculation. Click the transaction ID to open the transaction record. |
    | Transaction Type | This column displays the type of transaction that contributed to the to the total undeposited/future-period funds amount calculation. For example: Payment |
    | Entity | This column displays the entity for the transaction that contributed to the total undeposited/future-period funds amount calculation. Entity can be a customer name, vendor name, employee name, or other entities. |
    | Account Name | This column displays the account name that contributed to the total undeposited/future-period funds amount calculation. |
    | Transaction Amount (Currency) | This column displays the transaction amount that contributed to the total undeposited/future-period funds amount calculation. The amount is shown in the currency of the selected subsidiary or consolidated subsidiary. |
    
4.  (Optional) Under the Undeposited/Future-Period Funds Details section, click the **Export to** icon and select **CSV** to export the report as a CSV file.
    
    The Undeposited/Future-Period Funds window displays up to 100 recent transactions. Use Export to CSV to view all transactions.
