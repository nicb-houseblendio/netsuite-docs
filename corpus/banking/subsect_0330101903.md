The following table lists the records NetSuite automatically adds to your account after you install the Bank Feeds SuiteApp. These SuiteApp components let NetSuite connect directly to your financial institutions and retrieve bank data.

| Record Type | Record Name | Description | Account Information Service Provider (AISP) |
| --- | --- | --- | --- |
| Financial institution | Bank Feeds | A preinstalled financial institution record. | \- |
| Format Profile | U.S. and Canada Accounts (Yodlee) | A preinstalled format profile record that you can use to set up bank feeds for financial institutions in the United States and Canada. Important: The Yodlee format profile isn't preinstalled for new customers. If the available preinstalled format profiles don't support your U.S. or Canada financial institution, you can manually create the Yodlee format profile. Use the standard connectivity plug-in and transaction parser from the Bank Feeds SuiteApp. For the steps, see [Creating a Custom Format Profile to Connect to a U.S. or Canada (Yodlee) Financial Institutio](https://suiteanswers.custhelp.com/app/answers/detail/a_id/1024175) The Yodlee format profile remains available in Bank Feeds SuiteApp versions installed before February 4, 2026. | Yodlee |
| Format Profile | U.S. and Canada Accounts (MX) | A preinstalled format profile record that you can use to set up bank feeds for financial institutions in the United States and Canada. | MX Technologies, Inc. |
| Format Profile | Regulated Europe Accounts (Salt Edge) | A preinstalled format profile record that you can use to set up bank feeds for PSD2-regulated financial institutions in Europe. The revised Payment Services Directive (PSD2) regulates payment systems in Europe, and this is the preferred profile for connecting to European financial institutions. | Salt Edge |
| Format Profile | Nonregulated Europe Accounts (Salt Edge) | A preinstalled format profile record that you can use to set up bank feeds for European financial institutions that aren't regulated by PSD2. | Salt Edge |
| Format Profile | Accounts in Other Countries (Salt Edge) | A preinstalled format profile record that you can use to set up bank feeds for financial institutions in New Zealand, the Philippines, Singapore, and Thailand. | Salt Edge |

You can access the preinstalled records in the Setup Manager (_Setup > Accounting > Financial Institution > List_). For more information about Financial Institution and Format Profile Records, see [Financial Institution Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1538509582.html).
