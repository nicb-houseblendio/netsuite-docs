Intelligent Payment Automation offers the following key features:

## Global Availability {#subsect_0121033113}

Intelligent Payment Automation is available for customers with U.S. subsidiaries in most countries. You can use the SuiteApp in the following supported regions:

-   United States (U.S.),
    
-   Latin America (LATAM)
    
-   Europe, Middle East, and Africa (EMEA)
    
-   Australia and New Zealand (ANZ)
    
-   Asia-Pacific (APAC)
    

The SuiteApp is not supported in Canada, China, or Japan.

For Business Process Outsourcing (BPO) customers, the Estimate/Order form must be signed by the parent account's primary contact.

## Streamlined Three-Step Sign Up Process {#subsect_0706110643}

You can set up a BILL account in three steps:

1.  **Create a BILL account** - You can set up a BILL account in NetSuite without opening another application. See [Step 1 Create a BILL Account](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0530035100.html) for more information.
    
2.  **Link your bank accounts and map GL Bank Accounts** - To set up your bank accounts for Intelligent Payment Automation, link your bank accounts instantly or manually, and map the linked accounts as needed. For more information, see [Step 2 Link Your Bank Account for Funding Payments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0530035348.html) and [Mapping GL Bank Accounts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0530035513.html).
    
3.  **Set up a Payment Run Approval Routing** - Optionally, you can create an approval routing workflow to reduce the risk of unauthorized payment transactions, or skip it if you don't need one. See [Step 3 Set Up Payment Run Approval Routing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0530035733.html) for more information.
    

## Real-time Snapshot of Payment Activities {#subsect_0706110712}

With Intelligent Payment Automation you can view and track updates to payments in real time.

-   From the Payment Dashboard, you can:
    
    -   View outstanding balances of bills pending payment.
        
    -   See what pending actions are needed, such as making your first payment or managing your bank accounts.
        
    -   View reminders for payments, payment runs awaiting approval, and approved payments awaiting submission for further processing by BILL.
        
    -   Manage bank accounts linked to BILL from the dashboard.
        
    -   View GL Bank Account balances and see summaries of recent transactions.
        
    
    See [Payment Dashboard](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0626062427.html) for more information.
    
-   For NetSuite OneWorld accounts, with the Subsidiary Dashboard you can:
    
    -   See which subsidiaries are registered with BILL and which aren't eligible for a BILL account.
        
    -   Start or complete the three-step sign up process for each active subsidiary.
        
    
    See [Subsidiary Dashboard](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0530040413.html) for more information.
    
-   For cleared checks processed through BILL, you can view or download them directly from NetSuite. See [Viewing and Downloading Cleared Checks](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_28151605073.html) for more information.
    

## Vendor and Bank Account Management {#subsect_0706110839}

With Intelligent Payment Automation, you can manage your vendor information and bank accounts linked to BILL.

-   Vendor management - NetSuite syncs your vendor information to BILL so you can use BILL's network to keep vendor details and payments up to date. See [Vendor Setup and Management for Intelligent Payment Automation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0604082046.html) for more information.
    
    If you have a OneWorld account, you can also process payments for vendors linked to more than one subsidiary. See [Multi-Subsidiary Support](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0530040533.html) for more information.
    
-   Manage bank accounts - Manage bank accounts linked to BILL right from NetSuite, without needing other applications. See [Managing Bank Accounts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0606094105.html) for more information.
    

## Enhanced Security and Fraud Prevention {#subsect_0706110903}

With Intelligent Payment Automation, you can set up the following added security measures to prevent fraud.

-   Role-based access - You can set up roles, permissions, and approval routing to make sure only authorized employees can initiate and approve payments. See [Setting Up Intelligent Payment Automation Roles and Permissions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0531124014.html) for more information.
    
-   Trusted user sessions - User verification adds extra fraud controls when you submit payments to BILL for processing. See [Payments to Submit](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0609053659.html) for more information.
    

## Fully Integrated Payment Processing {#subsect_0706110942}

With Intelligent Payment Automation, you can:

-   Initiate single payments or payment runs - Start vendor payments in NetSuite with no need to switch between applications. See [Paying a Single Vendor Through BILL](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0606092816.html) and [Creating a Payment Run](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0606092833.html) for more information.
    
-   Approve Payments - If a payment amount goes over an approval limit set in your approval routing workflow, you need to [Approving Bill Payments and Payment Runs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0606092845.html).
    
-   Submit Payments - After initiating and approving payments, you can submit them to BILL for processing with a click. See [Payments to Submit](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0609053659.html) for more information.
    
-   Track Payment Status - Track payments from the dashboard after you submit them to BILL for processing. See [Viewing Payments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0606093101.html) for more information.
    

## Multiple Payment Options {#subsect_0728065629}

You can make vendor payments through the following options:

-   Check
    
-   Automated Clearing House (ACH)
    

For vendors connected to the BILL network, you can also use:

-   Virtual card (VCARD)
    
-   Wallet payments
    
-   Mastercard Remote Payment and Presentment Service (RPPS)
    

See [Bill Payment Options](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0606092711.html) for more information.

## CDL Support for Payables {#subsect_67112431814}

If the Class, Department, and Location (CDL) features are enabled in your account, you can apply these classifications on the Payables page. See [Creating a Payment Run](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0606092833.html) for more information.

For information about CDL, see [Departments and Classes Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N261602.html) and [Locations Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N263024.html).
