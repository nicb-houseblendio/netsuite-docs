Before managing unmatched transactions, review the suggestions on the **Match Suggestions** subtab. Submit the suggestions that you want to use or reject the others. For instructions, see [Reviewing Match Suggestions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_202608110102.html). When you reject a suggestion, NetSuite moves its imported transactions to the **Transactions to Match** subtab.

Use the **Transactions to Match** subtab on the Match Bank Data page to work with imported and account transactions that require manual action. You can manually match transactions, create a missing account transaction, mark an account transaction as cleared, or exclude an imported transaction from matching.

#### To manage unmatched transactions:

1.  Go to _Transactions > Bank > Bank Matching and Reconciliation > Match Bank Data_.
    
2.  From the **Account** list, select the bank or credit card account, and then click the **Transactions to Match** subtab.
    
3.  Optional: Use the available filters and search field to find the imported or account transactions that you want to work with.
    
4.  To manually match transactions, select one or more imported transactions and the corresponding account transactions. When the **Difference** is zero, click **Match**.
    
5.  Optional: To create an auto-create rule from a one-to-one manual match, select **Make Auto-Create Rule from Selected Transactions** before you click **Match**. The rule can create and match transactions from future imports. For more information, see [Generating Auto-Create Rules](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_84132242843.html).
    
6.  If the corresponding account transaction is missing, create it during the matching process. You can use an auto-create rule or manually create the transaction. For more information, see [Adding General Ledger Transaction During Matching](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_74132108117.html).
    
7.  If an account transaction does not have a corresponding imported transaction and you want to include it in the reconciliation, mark it as cleared. For more information, see [Marking Transactions as Cleared](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_61132825793.html).
    
8.  If an imported transaction does not need to be matched, exclude it from the matching process. For more information, see [Excluding Imported Transactions from the Matching Process](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_55132058186.html). To include an excluded transaction in matching again, see [Restoring Excluded Imported Transactions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_42132102942.html).
