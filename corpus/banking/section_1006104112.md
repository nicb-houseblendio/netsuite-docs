Before you can start initiating and processing payments, you must generate payment tokens that the payment processor will use. This is a one-time setup and can be handled by the Administrator.

Payment tokens are generated one time for all subsidiaries in a multi-subsidiary setup at the NetSuite account level.

**Prerequisites:**

-   Before you generate payment tokens, enable two-factor authentication (2FA) with one-time password (OTP). For information about setting 2FA, see [Set up Your Preferences for Two-Factor Authentication (2FA)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1531519158.html)
    
-   Users with [AP Integration Manager](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1006011432.html#subsect_65121955380) role can generate tokens.
    

Important:

The AP Integration Manager role must not be deleted or deactivated. Access to the AP Integration Manager role must not be removed for the user that generated the payment tokens.

#### To generate payment tokens: {#procedure_1006104245}

1.  Go to SuiteBanking > Setup > Payment Tokens.
    
2.  Enter your NetSuite password in the **Password** field.
    

## Regeneration of Payment Tokens {#subsect_41145325800}

Tokens don't expire. However, for security reasons, you should regenerate payment tokens every 24 months.

The payment audit trial indicates the user that has generated payment tokens.

If the user that has generated the payment tokens during the initial setup leaves the company, another user must regenerate the tokens.

Note:

The user regenerating the tokens must be assigned to the AP Integration Manager role.

#### To regenerate payment tokens: {#procedure_83171113173}

1.  Go to SuiteBanking > Setup > Tokens.
    
2.  If tokens are already generated, a banner is displayed: **The payment tokens have already been generated. To re-generate tokens please click here**. Click on **here** to regenerate tokens.
