You can sync vendor records manually, whether to submit new or updated details. Before you resubmit vendors that have failed in a previous sync request, be sure to correct or add the required details. You can't sync vendors tagged with issues or missing details.

To view the criteria for syncing, see [Vendor Qualification Criteria](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0604082046.html#subsect_0905024201). For automatic vendor syncing schedule and options, see [Vendor Syncing with BILL](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0604082046.html#subsect_0905023643).

#### To manually sync vendors with BILL accounts:

Wait for the confirmation message to appear at the header. For more information about vendor statuses, see [Tracking Vendor Syncing and Network Status](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0729011519.html).

1.  Using the Payment Manager role, go to Payment Automation > Payment Dashboard > View.
    
2.  If you use OneWorld:
    
    1.  The **Subsidiary Dashboard** opens. Click **Enabled**.
        
    2.  In the Actions column, click **View** to open the Payment Dashboard for the selected subsidiary.
        
    
    If you do not use OneWorld, the **Payment Dashboard** opens directly.
    
3.  In the left panel, under Payments and Vendors, click **Vendors**.
    
4.  From the Vendors list, check if you see any valid vendors that have a **Pending Sync** status in the **BILL Connection Status** column.
    
5.  Click **Sync Vendors with BILL**.
    
    Tip:
    
    This button remains disabled if you have vendors in Pending Sync status, but tagged with issues or missing details.
