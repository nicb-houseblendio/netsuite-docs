The Intelligent Transaction Matching feature automatically creates matches through the system or custom matching rules. For any remaining unmatched transactions, you can manually create matches.

Sometimes, there's no unique reference between the two sets of transactions. The same reference may appear in several imported transactions. For example, a financial clerk may combine several bank transfers into a single journal entry in NetSuite.

The [Match on Transaction Number and Amount](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160374863744.html#bridgehead_4744760171) rule groups imported bank lines by transaction number and matches them to a single NetSuite account transaction with the same number.

For details on how NetSuite groups transactions, see [Grouping Multiple Transactions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_202608110008.html).
