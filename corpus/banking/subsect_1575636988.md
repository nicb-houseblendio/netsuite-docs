Download the sample CAMT parser script from the File Cabinet and customize it as needed. The CAMT script file doesn't include validation by default. If you'd like to enable this feature, you'll need to provide your own XSD validation file.

#### To enable validation on the CAMT.053 script: {#procedure_1102034256}

1.  Download the **bsp\_lite\_parser\_camt053** script from the File Cabinet. For more information, see [Downloading Sample Bank Statement Parsers Scripts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1566298169.html).
    
2.  On your computer, open the CAMT.053 parser script file and find **module.parseBankStatement**.
    
    ![A section of the bsp\_lite\_parser\_camt053 script.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Accounting/Banking/BSP_CAMTSampleScript.png)
3.  In the **module.parseBankStatement** code block, do the following:
    
    -   Remove the **/ \*** and **\* /** characters to enable validations on the script.
        
    -   Replace **{placeholderText}** with the path to your uploaded XSD file validation. For more information, see [xml.validate(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345173468.html)
        
    
    Note:
    
    You can use the standard XSD validation file for the CAMT parser. Download it from the File Cabinet by going to SuiteBundles > Bundle 293699 > com.netsuite.bsp > src > validation. If you plan to upload a custom parser, rename the validation file before you upload it to avoid conflicts.
    
4.  Save your file.
    
5.  Deploy the modified script files as a plug-in implementation. For more information, see [Adding the Plug-in Implementation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1542902818.html).
