The CAMT.053 parser plug-in parses bank statement files in the CAMT.053.001.02 or CAMT.053.001.08 format. It also recognizes standard ISO bank transaction codes. The plug-in provides default mappings between XML elements and NetSuite fields, and you can create new mappings or override the defaults.

Note:

The CAMT.053 parser plug-in only supports (Unicode) UTF-8 encoding. Some editors add the BOM (Byte Order Marker) to the start of the file. You might need to use a third-party editor to convert your file to UTF-8 before importing it into NetSuite.
