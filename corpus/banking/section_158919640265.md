This section covers what you need and how to install the Auto Bank Statement Import (ABSI) SuiteApp.

## Prerequisites {#bridgehead_158919674199}

Before installing the ABSI SuiteApp, go to _Setup > Company > Setup Tasks > Enable Features_, then click the SuiteCloud tab. Make sure these features are enabled on your account:

-   Custom Records
    
-   Client SuiteScript
    
-   Server SuiteScript
    

## Installation {#bridgehead_158919683263}

Any role with access to the SuiteApp Marketplace in NetSuite can install the Auto Bank Statement Import SuiteApp. For more information about the SuiteApp Marketplace, see [SuiteApp Marketplace in NetSuite](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1539797981.html).

#### To install the Auto Bank Statement Import SuiteApp:

1.  Go to the SuiteApps tab.
    
    Note:
    
    The SuiteApps menu isn't available for the following centers:
    
    -   Advance Partner Center
        
    -   Employee Center
        
    -   Partner Center
        
    -   Vendor Center
        
    
2.  In the Search Apps field, enter **Auto Bank Statement Import SuiteApp**.
    
3.  Click the Auto Bank Statement Import SuiteApp tile.
    
    ![Auto Bank Statement Import SuiteApp Logo](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Accounting/Banking/ABSI_logo2.png)
4.  Go to the top right area of the Auto Bank Statement Import SuiteApp details page and click **Install**.
    

For more information about installing a SuiteApp from the SuiteApp Marketplace, see [Installing from the SuiteApp Marketplace](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1539799323.html).

Note:

Starting NetSuite 2021.1, you can uninstall the SuiteApp even after it's been used to import a bank statement file. After you uninstall the SuiteApp, NetSuite does the following:

-   Removes the SFTP Connectivity plug-in and parser plug-in from all format profiles that use the SuiteApp. The **Connectivity Method** field in the format profiles changes to Manual Import, and the **Transaction Parser** field is cleared.
    
-   Inactivates all format profiles that use the SuiteApp. To reactivate them, you'll need to select a new parser plug-in for each record. See [Modifying Format Profiles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156281299324.html). If you don't need a format profile anymore, you should delete it. See [Deleting a Format Profile](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156281397158.html).
    

The ABSI SuiteApp is a managed SuiteApp and gets updated automatically whenever new features or enhancements are added.
