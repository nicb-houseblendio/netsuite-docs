After you've saved a financial institution record, you can add one or more format profiles to it.

Format profiles enable you to configure settings necessary for manual or automatic import of financial institution data. There are two format profile types, and each uses a different workflow:

-   **Bank Reconciliation** - Configure a format profile to import bank and credit card data for reconciliation. Link your financial institution accounts to corresponding accounts in NetSuite, set an automated bank transaction import schedule, and map custom bank codes to bank data types. Bank Reconciliation is the default format profile type. For more information, see [Creating Format Profiles for Bank Reconciliation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1541610747.html).
    
    Note:
    
    As of NetSuite 2021.2, you can automatically generate customer payments from your imported data and apply them to invoices. These payments are automatically matched and cleared in the system. See [Automated Cash Application](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_2164712765.html).
    
-   **Corporate Card Expenses** - Configure a format profile to import credit card charges for expense reporting. Link credit card charges to employee accounts and map expense codes to user-defined expense categories. For more information, see [Creating Format Profiles for Expense Reporting](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159062414952.html).
    

You can only associate a format profile with one financial institution record. If you delete a financial institution record, NetSuite also deletes the associated format profile. You can't delete a format profile that has associated imports.
