You can find copies of the scripts used in the Bank Statement Parsers SuiteApp in the file cabinet. The scripts show how statement file data maps to NetSuite fields. Download these scripts as a reference if you want to create your own parser.

#### To download the Bank Statement Parsers scripts:

1.  Go to Documents > Files > File Cabinet.
    
2.  On the left pane of the File Cabinet, click SuiteBundles > Bundle 293699 > com.netsuite.bsp > lite.
    
3.  Click the **Download** link for the parser scripts you want to customize.
    

To create your own custom parsers, see [Bank Statement Parser Plug-in](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/part_156294612382.html).
