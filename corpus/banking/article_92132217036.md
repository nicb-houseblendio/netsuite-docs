Instead of manually creating and matching general ledger transactions, you can automate these steps using auto-create rules. Auto-create rules let you create transactions from future imported bank transactions and submit them for reconciliation. Auto-create rules can create the following:

-   Deposits and charges for bank accounts
    
-   Charges and refunds for credit card accounts
    

If you import bank transactions with a recurring Payor/Payee or Memo, auto-create rules look for transactions with the right transaction type and Payor/Payee. If there's no Payor/Payee, the rules check the Memo instead.

You don't need to manually create an auto-create rule. Instead, you can configure the system to generate one from a transaction match when certain criteria are met. For details, see [Generating Auto-Create Rules](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_84132242843.html).

NetSuite won't generate an auto-create rule unless you check the **Make Auto-Create Rule From Selected Transactions** box on the Transactions to Match subtab. The box is cleared by default, so you need to check it every time you want a new auto-create rule.

When an auto-create rule generates a suggestion for a future imported transaction, the Match Suggestions subtab shows a Create <transaction type> suggestion, such as Create Deposit.

For example, if a future imported bank transaction has the Payor/Payee Ben and no matching transaction, NetSuite can show the applicable Create <transaction type> suggestion.

In the expanded suggestion, select **Create and Submit** to create the transaction using the rule's specified values and submit it for reconciliation. NetSuite removes the suggestion from the Match Suggestions subtab and submits the created transaction for reconciliation. You can then review and reconcile it on the Reconcile Account Statement page.

To edit an auto-create rule, see [Editing Auto-Create Rules](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158991231343.html).

To run an auto-create rule, see [Running an Auto-Create Rule](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_6131803336.html).

For troubleshooting information, see [Troubleshooting Automatic Transaction Creation Rules](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_44132247326.html).
