This section includes the prerequisites and instructions for installing the Bank Feeds SuiteApp.

## Prerequisites {#subsect_157733863572}

Before you install the Bank Feeds SuiteApp, complete the following:

-   **Enable the required features** - Go to _Setup > Company > Setup Tasks > Enable Features_, and then click the SuiteCloud tab. Make sure that the following features are enabled on your account:
    
    -   Custom Records
        
    -   Client SuiteScript
        
    -   Server SuiteScript
        
-   **Confirm bank accounts are set up for online banking** - Verify that the bank accounts you want to connect are configured for online banking.
    
-   **Allow popups in your browser** - Enable popups in your browser so the configuration window can open during bank feeds setup.
    
-   **Check for existing financial institution record names** - If you have any custom financial institution records (active or inactive) with **Bank Feeds** in the name, rename them before installing. The Bank Feeds SuiteApp relies on financial institution record naming during installation or upgrade to apply required updates. If the preinstalled financial institution record used by the SuiteApp is renamed, or if a custom record includes **Bank Feeds** in its name, the update may be skipped, and installation or upgrade may fail.
    

## Installation {#subsect_157733864711}

Any role with access to the SuiteApp Marketplace in NetSuite can install the Bank Feeds SuiteApp. For more information about the SuiteApp Marketplace, see [SuiteApp Marketplace in NetSuite](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1539797981.html).

#### To install the Bank Feeds SuiteApp:

1.  Go to SuiteApps.
    
    Note:
    
    The SuiteApps menu is not available for the following centers:
    
    -   Advanced Partner Center
        
    -   Customer Center
        
    -   Employee Center
        
    -   Partner Center
        
    -   Support Center
        
    -   Vendor Center
        
    
2.  In the **Search SuiteApps** field, enter **Bank Feeds**, then press enter.
    
3.  Click the Bank Feeds SuiteApp tile.
    
4.  Go to the top right area of the Bank Feeds SuiteApp details page and click **Install**.
    

For more information about installing a SuiteApp from the SuiteApp Marketplace, see [Installing from the SuiteApp Marketplace](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1539799323.html).

Note:

Starting NetSuite 2021.1, you can uninstall the SuiteApp even if you've already set up bank feeds integration. After you uninstall the SuiteApp, NetSuite does the following:

-   Removes the connectivity and parser plug-in from the format profiles set up by the Bank Feeds SuiteApp. The **Connectivity Method** field in the format profiles changes to Manual Import, and the **Transaction Parser** field is cleared.
    
-   Inactivates the format profiles set up by the Bank Feeds SuiteApp. To reactivate the format profiles, you'll need to select a new parser plug-in for each record. See [Modifying Format Profiles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156281299324.html). If you no longer need a format profile, you should delete it. See [Deleting a Format Profile](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156281397158.html).
    

The Bank Feeds SuiteApp is a managed SuiteApp that's automatically updated whenever new features or enhancements are added.
