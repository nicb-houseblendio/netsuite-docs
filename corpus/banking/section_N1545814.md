You can use NetSuite to print two types of checks:

-   **Standard** - printed without a voucher, three checks per 8.5 x 11 inch sheet.
    
-   **Voucher** - printed at the top of an 8.5 x 11 inch sheet with voucher information printed at the bottom, one check per sheet.
    
    Always print the check at the top. NetSuite doesn't support printing checks in the middle of the page.
    

Note:

You can customize check forms, but you must print forms as Standard (three to a sheet) or Voucher (check at the top only.) When you customize a check layout, you see only the check, not vouchers, no matter your check type preference. Even if you change the page size, you can only add or edit standard check elements.

For information about customizing forms, see [Customizing Transaction Form PDF Layouts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2869660.html). For information about the Advanced PDF/HTML Templates feature, see [Advanced PDF/HTML Templates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4453550706.html).

If your organization uses basic printing, you can set a different check template for each subsidiary. For information, see [Specifying Check Layout by Subsidiary](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1513338497.html).

For more information about setting up check printing and aligning check forms, see [Setting Check Printing Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1545526.html).

NetSuite checks are available from the Forms Fulfillment Center, a NetSuite partner at [www.netsuiteforms.com](http://www.netsuiteforms.com/). The following checks are compatible with NetSuite:

-   Laser Top Multipurpose Check (DNL208)
    
-   Laser Top Multipurpose Check - Unlined (DNL200)
    
-   Laser 3-Up Multipurpose Check - Unlined (DNL201)
    
-   Laser 3-Up Multipurpose Checks w/Lines Product (DNL202)
    

## Printing a Check at the Form Bottom {#bridgehead_N1545959}

Some locales require printing a check at the bottom of the form instead of the top. For example, some U.K. accounts require stock that prints at the bottom of the form. If you have this requirement, order check stock from [www.access-plus.co.uk](http://www.access-plus.co.uk) and use reference number INF01SL.
