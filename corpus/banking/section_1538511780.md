You can create a record for a financial institution. Financial institution records are for storing format profiles, which enable you to configure settings necessary for importing financial institution data. You can use format profiles to configure imports of the following:

-   Bank or credit card data for bank reconciliation
    
-   Corporate card charges for expense reporting
    

For details, see [Format Profile Creation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159061330646.html).

If you use the Bank Feeds SuiteApp or AMEX Corporate Card Integration SuiteApp, NetSuite automatically creates a financial institution record and associated format profile or profiles. Therefore, if you're using either of these SuiteApps, you don't need to do the procedure that follows. For details, see [Bank Feeds SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_158079179132.html) and [American Express Integration for Expense Reporting](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159122395131.html).

#### To create a financial institution record:

1.  Go to _Setup > Accounting > Financial Institution_.
    
    The Financial Institution page appears.
    
2.  In the **Financial Institution** field, enter a financial institution name.
    
3.  In the **Description** field, enter a description to help you identify this financial institution.
    
    Important:
    
    To configure format profiles for this financial institution, you must save the financial institution record first.
    
4.  Check the **Inactive box** to inactivate the financial institution record. The box is clear by default.
    
5.  Click **Save**.
