When SFTP connectivity is in place, you can monitor the status of every bank statement file imported into NetSuite and resolve any failed attempts. The topics below show you how to:

-   review detailed import records, and
    
-   delete failed import entries so that NetSuite can import the same file again.
    

Read the following topics to learn more about managing your bank statement file imports in NetSuite:

-   [Viewing SFTP Connectivity Import Details](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_159099197253.html)
    
-   [Deleting Failed SFTP Connectivity Import Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_159099198798.html)
