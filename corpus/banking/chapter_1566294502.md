The Bank Statement Parsers SuiteApp delivers standard parser plug-ins that read bank and credit card statement files and import the data in NetSuite to aid with bank reconciliation. If the Financial Institution and Format Profiles are set up correctly, the SuiteApp can identify multiple bank accounts in a single file. For more information, see [Creating Financial Institution Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1538511780.html) and [Format Profile Creation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159061330646.html).

The SuiteApp also includes sample scripts you can download and use as a reference when you create custom parsers. For more information, see [Downloading Sample Bank Statement Parsers Scripts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1566298169.html).

Note:

The SuiteApp will not create NetSuite transactions from the imported bank statement files.

The Bank Statement Parsers SuiteApp includes parser plug-ins for the following file formats in (Unicode) UTF-8 and UTF-8 BOM encoding:

-   [BAI2 Parser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1211120325.html) - This plug-in recognizes standard BAI2 bank-transaction codes and lets you set the decimal precision.
    
-   [CAMT.053 Parser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1211120446.html) - This plug-in parses CAMT.053.001.02 or CAMT.053.001.08 format, provides default XML-to-field mappings, and supports only UTF-8 encoding.
    
-   [CSV Parser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1211120527.html) - This plug-in parses UTF-8 CSV statement files using the supplied template or your own mapping to NetSuite fields.
    
-   [MT940 Parser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1211120544.html) - This plug-in recognizes standard SWIFT MT940 transaction codes and converts embedded remittance information into a readable format.
    
-   [OFX/QFX Parser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1211120621.html) - This plug-in parses OFX/QFX files in versions 102, 103, 211, and 220 and supports either a period or a comma as the decimal separator.
