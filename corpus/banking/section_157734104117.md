Only roles with Administrator access or a custom role with Financial Institution Records permission can set up bank feeds integration.

To access the Bank Feeds Format Profile pages and import transactions using custom roles, you must set the following permissions:

| Subtab | Permission | Level |
| --- | --- | --- |
| Lists | Certificate Access | View |
| Lists | Custom Record Entries | Full |
| Lists | Documents and Files | View |
| Setup | Custom Lists | View |

For a list of permissions you need to access the necessary records and forms to use Bank Feeds, see [Permissions for Banking Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_156289552348.html).
