If you use any of the following SuiteApps, you can automatically migrate your vendors' bank account details with a U.S. address:

-   Electronic Bank Payments
    
-   Payment Automation with HSBC
    

For more information, see [Switching and Migrating to Intelligent Payment Automation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1003021504.html).

For new or existing U.S. vendors, you must enter a U.S. address in the vendor record. If you use the Vendor Payment Instruments feature, you can also set a default U.S. bank account for ACH payments.

If a vendor record does not have a bank account, you can only pay vendor bills by check. To view other available payment options for vendors in the BILL network or for Verified National Vendors, see [Bill Payment Options](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0606092711.html).

Note:

To enable the Vendor Payment Instruments feature, see [Installing the Intelligent Payment Automation SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0530033844.html). Also, see [Setting Up Intelligent Payment Automation Roles and Permissions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0531124014.html) to assign the **Edit** level for the following required permissions for ACH payments:

-   Vendor Automated Clearing House
    
-   View Unencrypted Vendor ACH Account Numbers
    

After you create and initially sync a vendor record, NetSuite generates the Vendor Profile Information record and adds it to the Intelligent Payment Automation subtab. On this record, you can view these BILL statuses and details:

-   Pay with Intelligent Payment Automation
    
-   Subsidiary
    
-   Verified National Vendor ID
    
-   Preferred Payment Mode
    
-   Vendor Network Status
    
-   Bank Account Status
    
-   Vendor Creation Failure Reason
    

For synced vendors with or without BILL accounts, except those connected to the BILL network, NetSuite updates automatically reflect on the BILL vendor record. For more guidelines, see [BILL Accounts and BILL Network for Vendors](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0604082046.html#subsect_0905024857).

#### To create vendors for Intelligent Payment Automation:

1.  Go to Lists > Relationships > Vendors > New.
    
2.  Enter the basic details in the following fields:
    
    -   Company Name
        
    -   Type
        
    -   Email
        
    
    In the **Company Name** field, enter the exact vendor's name. BILL uses this value to find matching vendor accounts.
    
    To enter other basic and additional vendor details, see [Creating a Vendor Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2362161.html).
    
3.  To set up subsidiaries:
    
    1.  In the **Primary Subsidiary** field, select a U.S. subsidiary.
        
        The primary subsidiary is assigned as the subsidiary in the Vendor Profile Information record.
        
    2.  (Optional) If you have multiple subsidiaries, on the **Subsidiaries** subtab, you can add secondary U.S. subsidiaries.
        
4.  On the **Address** subtab, add a U.S. address and select it as the default billing address.
    
    If you add multiple addresses, be sure to select a U.S. address as the vendor's default billing address.
    
5.  On the **Financial** subtab, do the following:
    
    1.  In the **Primary Currency** field, select **US Dollar**.
        
    2.  On the **Currencies** subtab, add the **US Dollar** currency.
        
6.  (Optional) On the **Intelligent Payment Automation** subtab, in the **Vendor Remittance Email Address** field, enter one email address.
    
    By default, BILL sends payment confirmation to the email address in the header, unless you enter one in this field.
    
7.  Click **Save**.
    

After you create a vendor record, NetSuite automatically submits it in the next scheduled syncing with BILL. If you want to manually sync it, see [Manually Syncing Vendors with BILL](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0905031506.html).

Regardless of the result of initial syncing, NetSuite creates a Vendor Profile Information record and displays it on the **Intelligent Payment Automation** subtab. If a vendor is synced successfully, it automatically checks the **Pay with Intelligent Payment Automation** setting on this record. After this setting is enabled, you can create and submit payments to BILL for this vendor. For more information, see [Payment Processing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0530033208.html).
