The Deposits page provides a list of deposits recorded in NetSuite and an overview of deposit details. From the list, access individual deposit records or print the deposit slip.

To view the deposits list, go to _Transactions > Bank > Make Deposits > List_.

By default, the Deposits page displays the following information for each deposit:

-   Date of the deposit
    
-   Document number for the deposit
    
-   Bank account for the deposit
    
-   Memo
    
-   Currency of the bank account
    
-   Amount (Foreign Currency)
    
-   Amount of deposit
    
-   Whether the deposit was posted
    

Depending on your enabled features, this page may also display feature-specific columns.

## Filtering the Deposits List {#bridgehead_N1542885}

To limit the deposits in the list, select one or more filters on the Deposits page. In addition to standard filters, add custom ones like Account by customizing. Delete existing deposits from the list as well.

#### To add custom filters to the Deposits list: {#procedure_N1542897}

1.  From the Deposits list, click **Customize View**.
    
2.  On the Saved Transaction Search page, open the **Available Filters** subtab.
    
3.  Select a filter in the dropdown list.
    
4.  The **Show in Footer** box is checked by default. Clear this box if you don't want to display a dropdown list of filter values on the Deposits list.
    
5.  Click **Add**.
    
6.  Click **Save**.
