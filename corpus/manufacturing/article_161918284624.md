The Advanced Manufacturing Documentation menu directs you to the NetSuite File Cabinet. You can safely store and organize documents and associate them with a company, customer, contact, vendor, task, event, or case record. For more information, see [File Cabinet Folders](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4811464978.html).

#### To view documents:

1.  Go to Advanced Manufacturing > Documentation > File Folders.
    
2.  To view or download a document, refer to the following:
    
    -   [Working with Email Templates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N514744.html)
        
    -   [Using Letter Templates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N525773.html)
        
    -   [Advanced PDF/HTML Templates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4453550706.html)
        
3.  Click **New Folder** to add a folder or file to the File Cabinet.
