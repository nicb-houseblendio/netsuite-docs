| --- | --- |
| Items & Inventory | Work Orders |
| Advanced Bill of Materials |
| Manufacturing Work In Progress |
| Manufacturing Routing and Work Center |
| Analytics | SuiteAnalytics WorkBook |
| SuiteCloud | Advanced PDF/HTML Templates |
| Custom Records |
| Client SuiteScript |
| Server SuiteScript |
