The traveler preferences enable you to print traveler reports in a predefined template to the desired directory.

Note:

You can only create one preferences record. It is automatically created by the SuiteApp during the installation. However, you can modify the preferences as per business needs.

#### To edit a preferences record: {#procedure_0620072315}

1.  Go to Setup > Manufacturing > Traveler Preferences.
    
2.  Click **Edit** on the preferences record.
    
    The Traveler Preferences page opens.
    
3.  From the **Template** list, select the desired traveler template for the work order instructions and traveler report.
    
    Note:
    
    When you install the SuiteApp, a default template appears in the field. You can also make your own templates. For more information, read [Creating Custom Template for Traveler Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0620072542.html).
    
4.  In the **Report Directory** field, select the directory path for the selected custom template.
    
    For the default template, the report directory populates with a default path.
    
5.  (Optional) Check the **Use Advanced Manufacturing** box to use the Advanced Manufacturing SuiteApp. Clearing the box will enable the Work Instructions and Traveler SuiteApp.
    
    This action will enable:
    
    -   The **Work Instructions** subtab in the manufacturing routing record.
        
    -   The **Additional Work Instructions** subtab in the work order record.
        
    -   The **Print Traveler** button in the work order record.
        
    
    Note:
    
    Follow the below points for **Use Advanced Manufacturing** box.
    
    -   **Use Advanced Manufacturing** box is checked by default for Advanced Manufacturing customers. So, the **Work Instructions** subtab is hidden in the routing record. However, if you clear the box, you'll see the subtab with any work instructions you've added to the routing record.
        
    -   When you enable the **Use****Advanced Manufacturing** box and save the preferences record, all the work instructions associated with the manufacturing routing will be deleted.
