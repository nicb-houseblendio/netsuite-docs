If you are an administrator, you can create new roles or customize roles for using the Manufacturing Scheduler SuiteApp. For more information, see [Assigning Roles to an Employee](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N897798.html) and [Customizing or Creating NetSuite Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N285937.html).

Refer to the following table for minimum access levels of permissions required for SuiteApp deployments. These minimum permissions must be updated for the existing role or when creating a new role.

| **Subtab** | **Permission** | **Level** |
| --- | --- | --- |
| **Find Transaction** | Work Order | View |
| **Transactions** | Work Order | Edit |
| **Lists** | CRM Group | View |
| **Lists** | Work Calendar | View |
| **Lists** | Locations | View |
| **Lists** | Documents and Files | View |
| **Lists** | Subsidiaries | View |
| **Custom Record** | MTS Task View | Full |
| **Custom Record** | MTS User Display | Full |
| **Setup** | Set Up Company | View |

By default, the following standard roles are granted full permissions to the two custom records that are listed in the table:

-   CEO
    
-   CFO
    
-   Sales Vice President
    
-   Accountant
    
-   Accountant (Reviewer)
    
-   Bookkeeper
    
-   Warehouse Manager
    

In addition to the two custom records, ensure you assign the other permissions to standard or custom roles. To edit or customize a role, go to _Setup > Users/Roles > Manage Roles_. On the Manage Roles page, click the Role name to open the record and verify that the permissions are set to the required level. For more information about editing or customizing roles, see [Customizing or Creating NetSuite Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N285937.html).

Based on your role, you can access the SuiteApp by following the appropriate path:

-   Warehouse Manager
    
    Inventory > Manufacturing > Manufacturing Scheduler
    
-   Administrator
    
    Transaction > Manufacturing > Manufacturing Scheduler
    
-   Executive or Accounting
    
    Financial > Manufacturing > Manufacturing Scheduler
