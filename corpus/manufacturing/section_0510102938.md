Select an assembly item, from and to date in the Cost Variance Analysis page, and you'll see the relevant work orders in the **Work Order Summary** section.

The following table provides details about the columns in the **Work Order Summary** section.

| Column Name | Description |
| --- | --- |
| Work Order | Work order number. Click on the work order number to generate the cost variance analysis report. |
| Status | Work order status. |
| Location | Location of the assembly item in the work order. |
| Actual Start Date | Actual production start date of the work order. |
| Actual End Date | Actual production end date of the work order. |
| Build Quantity | Quantity to be built for the work order. |
| Built Quantity | Quantity built for the work order. If the built quantity is zero, the cost variance per unit will be empty. |
| Planned Cost | Planned cost for completing the work order. If the planned cost is zero and the actual cost is non-zero, the cost variance percentage will be 100%. |
| Actual Cost | Actual cost when completing the work order. If the planned cost is zero and the actual cost is non-zero, the cost variance percentage will be 100%. |
| Cost Variance | Cost difference between the actual cost and planned cost of the work order. |
| Cost Variance (%) | Percentage of cost variance per planned cost of the work order. |
| Cost Variance per Unit | The difference between actual cost and planned cost for each unit built. |
