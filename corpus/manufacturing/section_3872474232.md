You can enter work orders that have a status of Planned. A planned work order operates as follows:

-   Includes component information
    
-   Includes resource information
    
-   doesn't commit items until the work order is released
    

Planned work orders can be either Open or Firmed.

-   **Open** - Open planned work orders are deleted before supply planning runs.
    
-   **Firmed** - Firmed planned work orders aren't deleted before supply planning runs. For more information, see [Marking Work Orders Firmed](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161538611138.html).
    

You can manually create planned work orders, or you can have the NetSuite supply planning process generated the planned work orders. For more information, see [Manually Entering Planned Work Orders](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161538623291.html) and [Automatically Generating Planned Work Orders](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161538619446.html).
