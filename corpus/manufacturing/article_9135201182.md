Work Instructions and Traveler SuiteApp helps you to generate traveler reports of required work orders. Using these reports, the shop floor personnel can perform day to day assembly operations. Each report includes details like required components, work order info, and step-by-step work instructions to complete each operation. This report travels from one work center to another for every operation in the work order until the work order is completed.

Traveler reports are printed only for work order with **Released** & **In Process** status either using the delivered predefined templates or any customized templates defined in the account.

Note:

This SuiteApp enables you to generate traveler reports which is also provided by the Advanced Manufacturing SuiteApp. The accounts with Advanced Manufacturing SuiteApp by default will continue to use the existing work instructions and traveler feature.

However, when you install the Work Instructions and Traveler SuiteApp, you can override the default setup and copy existing instructions from the Advanced Manufacturing SuiteApp using CSV Import/Export. For more information, read [CSV Imports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/book_4470700566.html).
