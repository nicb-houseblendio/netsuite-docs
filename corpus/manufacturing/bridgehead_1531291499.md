If you haven't set the **Implement Engineering Change Order Upon Final Approval** preference, an ECO administrator has to manually implement approved ECO records.

#### To implement approved engineering change orders:

1.  Go to Lists > Engineering > Implement Engineering Change Order (Administrator).
    
2.  Use filters to find approved ECO records:
    
    -   Use the calendar to search by effective date range. Today's date is the default date.
        
    -   Select a subsidiary.
        
3.  The page lists matching records, if any.
    
    -   To implement all records, click **Mark All**. To implement specific ECO records, check the **Select** box for each one.
        
    -   Use the pagination controls if you need to make more selections.
        
4.  Click **Implement**.
    
    To view the implementation status of an ECO record, see [Viewing Implementation Status](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_1531291564.html).
    

Note:

Set the **Implement Engineering Change Order Upon Final Approval** preference to have approved ECOs implemented automatically. See [Setting the Engineering Change Order Preference](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_1531289899.html).
