NetSuite enables you to show work order items as assembled without completing all the steps.

When you mark an order as built, the required items are marked built and added to inventory.

Note:

Associated variances aren't created when you mark an order built.

#### To mark a work order built: {#procedure_N2322848}

1.  Go to _Transactions > Manufacturing > Mark Work Orders Built_.
    
2.  Select a **Location** to filter the list of orders.
    
3.  Select an **Item** to filter the list of orders.
    
4.  Select a **Customer** to filter the list of orders.
    
5.  Check the **Mark Built** box next to each order.
    
6.  Click **Save**.
