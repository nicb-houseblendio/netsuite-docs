You'll see ATB details for assembly items and kits in the Item 360 SuiteApp dashboard portlets. The **Manufacturing** and **Sales** page of the Item 360 dashboard are enabled with the **Available to Build** portlet.

## Available to Build on Manufacturing Page {#bridgehead_0915094526}

On this page, the ATB value is generated for an assembly item. You must select a location on the Manufacturing page to calculate the ATB value.

Go to Reports > Item 360 > Item 360, then click on the **Manufacturing** page. From there, expand the **Available to Build** portlet.

The portlet provides the following details for the selected assembly item at a selected location:

-   Location
    
-   On-Hand
    
-   Available
    
-   Available to Build
    
-   Work Order Quantity
    
-   Unit (base unit of the item)
    

Check the **Top Level** box to see the ATB value at the top level of an assembly item. Clear this box to calculate ATB at **All levels**.

## Available to Build on Sales Page {#bridgehead_0915094706}

On this page, the ATB value is generated if the item is a kit item. Go to Reports > Item 360 > Item 360, then click on the **Sales** page. From there, expand the **Available to Build** portlet.

The portlet provides the following details for the selected kit item at a selected location:

-   Location
    
-   Available to Build
    

Check the **Top Level** box to see the ATB value at the top level of a kit item. Clear this box to calculate ATB at **All levels**.

Note:

If the Available to Build SuiteApp is not installed, you won't see the Available to Build portlet on the Manufacturing and Sales pages of the Item 360 dashboard.
