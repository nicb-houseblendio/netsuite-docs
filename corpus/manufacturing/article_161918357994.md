Follow these steps to search for a work order traveler.

#### To search for a work order traveler:

1.  Go to Advanced Manufacturing > Documentation > File Folders.
    
2.  In the field beside the **Search** button, enter a keyword.
    
    You can search using keywords in file or folder names.
    
3.  Click the **Search** button.
    
    The results are listed in the right panel.
    
4.  Beside the traveler you want to open, click **Edit**.
