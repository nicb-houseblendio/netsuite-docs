Enter work orders to track the production of assembly items needed for stock or to fill open orders. A work order is considered a non-posting transaction.

Special Order work orders track assemblies for a particular sale. Production work orders track assemblies to increase stock. Both use the same work order form, but production work orders don't link to a sale transaction.

Work orders you enter list the members, or components, of the assembly item to be built.

<a id="kaltura_player_182"></a>

For information about work order statuses, see [Work Order Statuses](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N2328390.html#article_161538429435)
