Production operators can report production and consumption as many times as they need and in any order.

Work order status updates after the build or when work is finished. Work order status doesn't update when you use the scanner to report data.

If you enable backflush for the work order, the consumption icon is hidden and not available for manual reporting.

To start reporting data for work orders, see the following topics:

-   [Reporting Consumption](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162091339776.html)
    
-   [Consumption Reporting Details](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164252589726.html)
    
-   [Reporting Production](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162091564313.html)
    
-   [Reporting Data for Standalone Assembly Build](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_158619613344.html)
    

To start reporting data without reference to a work order, see [Reporting Data for Standalone Assembly Items](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0320032739.html).
