You can also generate a work instructions and traveler report from a work order.

#### To generate a report from a work order {#procedure_0620093603}

1.  Go to Transactions > Manufacturing > Enter Work Orders > List.
    
2.  On the Work Order page, click **View** on a work order.
    
3.  Click **Print Traveler**.
    

After the report generation process is complete, the report opens in a new browser tab. For more information, read [Viewing Report of Each Work Order](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0620092553.html#bridgehead_47213331605).

Note:

The **WOIT MR Traveler Report** script generates the PDFs for work orders in release status and not for the work orders that are printed already. This MR script is unscheduled by default, and you can schedule it.
