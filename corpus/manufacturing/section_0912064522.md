The Available to Build SuiteApp supports the following browsers and operating systems:

| Browser | Operating System |
| --- | --- |
| Google Chrome | Windows 10 Mac OS 10.15 or newer |
| Microsoft Edge (Chromium-based) | Windows 10 or newer |
| Mozilla Firefox | Windows 10 Mac OS 10.15 or newer |
| Safari | Two most recent stable major versions |
