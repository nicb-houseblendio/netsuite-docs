If you're an administrator, you can create new roles or customize existing ones to use the Supply 360 SuiteApp. For more information, see [Assigning Roles to an Employee](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N897798.html) and [Customizing or Creating NetSuite Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N285937.html).

Refer to the following table for minimum access levels of permissions required for SuiteApp deployments. Ensure to update these minimum permissions for existing roles or when you create a new role.

| Subtab | Permission | Minimum Access Level | Purpose |
| --- | --- | --- | --- |
| Transactions | Work Order | View | Required for Supply 360 SuiteApp. |
| Find Transaction | View | Required for Supply 360 SuiteApp. |
| Lists | Locations | View | Required for Supply 360 SuiteApp. |
| Lists | Items | View | Required for Supply 360 SuiteApp. |
| Lists | Vendors | View | Required for Supply 360 SuiteApp. |
| Lists | Inbound Shipment | View | Required for Supply 360 SuiteApp (When Inbound Shipment feature is enabled for the account). |
| Lists | Units | View | Required for Supply 360 SuiteApp (When Multiple Units of Measure feature is enabled for the account). |
| Setup | SuiteScript | Edit | Required for Supply 360 SuiteApp. |
