The following procedure provides details for creating a manufacturing workbook.

#### To create a manufacturing workbook:

1.  Enable SuiteAnaytics Workbook.
    
    For more information, see [Enabling SuiteAnalytics Workbook in Your NetSuite Account](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1504014192.html).
    
2.  Select a workbook root record:
    
    1.  Click the **Analytics** tab.
        
    2.  Click **New Workbook**.
        
    3.  In the **Search Record Types** field, enter **Manufacturing**.
        
        ![Screenshot of the New Workbook: Select a Record Type page.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Manufacturing/MfgWorkbook.jpg)
    4.  Click the **Manufacturing Transaction \[Beta\]** record.
        
        The Data tab opens with preselected fields on the Data Grid based on the manufacturing record.
        
        ![Screenshot of the Data subtab of a workbook.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Manufacturing/DataTab.jpg)
        
        You can use only those fields that you add to the Data Grid to generate a pivot table or chart. By default, the Data Grid displays preselected fields, based on the root record selected for the workbook.
        
3.  To select source data, use one of the following options to add fields from the Manufacturing Transaction record root to the data grid:
    
    -   From the Manufacturing Transaction record, drag a field to the Data Grid
        
    -   Double-click a field
        
    -   In the **Search** field, enter the field name and then drag or double-click the field
        
    
    1.  To add fields to the data grid from the Manufacturing Transaction related record, click the **Join Record** icon (![Screenshot of the Join icon.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Manufacturing/JoinRecordIcon.jpg)).
        
        ![Screenshot of joining a record.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Manufacturing/JoinRecord.jpg)
    2.  Select a **Join record**.
        
        The **Fields** list updates to include the related record fields. Double-click or drag fields to the data grid.
        
4.  To create formula fields, click the **Formula Fields** tab.
    
    1.  Enter the **Formula Field Name**.
        
        For example, **Buildable - Enhanced**.
        
        ![Screenshot of a Buildable Enhanced formula field.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Manufacturing/BuildableEnhanced.png)
    2.  Select an **Output Type**.
        
        For example, **String**.
        
    3.  In the **Formula** field, enter the field IDs and SQL formula functions to use in the formula expression.
        
        Alternatively, in the **Functions and Fields** sections, double-click the field IDs or formula functions to add them to the expression.
        
    4.  Click **Validate**.
        
    5.  If there are no errors, click **Apply** to add the formula field to the workbook.
        
    6.  To filter the data source, click the **Criteria** tab.
        
    7.  Drag a record or formula field.
        
        ![Screenshot of the Criteria subtab.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Manufacturing/CriteriaBuilder.jpg)
    8.  In the **Filter** window, select the filter conditions to apply to the field.
        
    9.  Repeat these steps for each filter you want to define.
        
        By default, filters are added using an AND operator. To change the relationship between filters and filter groups, click the AND link and select OR from the popup window.
        
    10.  Click **OK**.
         
    11.  When you finish defining filters, click the **Data** tab.
         
         The Data Grid displays only values that match your selected filter conditions, and a Criteria Summary appears above the grid.
         
5.  To create a pivot table, click **Add Pivot**.
    
    Drag fields into the **Rows**, **Columns**, or **Values** section in the **Layout** panel.
    
    For example, the **Assembly** row, **Date (Year)** and **Date (Month)** columns, and **Quantity (Sum)** measure.
    
    ![Screenshot of sample Pivot details.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Manufacturing/Pivot.jpg)
    1.  Select the summary type and format options for any date or numerical fields.
        
        1.  Beside the next to the field you want to format, click the **Field Menu** icon (![Screenshot of the Menu icon.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Manufacturing/MenuIcon.jpg)).
            
        2.  Select **Summary Types**.
            
    2.  Add totals and grand totals to the pivot table:
        
        1.  In the menu bar, click the totaling icon (![Screenshot of the Totaling icon.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Manufacturing/Totaling.jpg)).
            
        2.  In the **Totaling** window, for each field, select where you want the totals or grand totals to appear.
            
        3.  Check the **Set Individually** box to select where the totals for each field will appear on the pivot table.
            
        4.  Click **OK**.
            
    3.  Click **Refresh** (![Screenshot of the Refresh icon.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Manufacturing/Refresh.jpg)) to generate the pivot table.
        
        ![Screenshot of the sample Pivot generate details.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Manufacturing/PivotGenerate.jpg)
6.  To create a chart, click **Add Chart**.
    
    1.  Drag fields into the **X-Axis**, **Series**, or **Measure** section in the **Layout** panel.
        
        For example, create an **Area Chart**, with **Date (Year)** and **Date (Month)** on the **X-Axis**, for the **Assembly Series**, with **Quantity (Sum) Measures**.
        
        ![Screenshot of the sample workbook Chart Layout.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Manufacturing/ChartLayout.jpg)
    2.  Select the summary type and format options for any date or numerical fields.
        
        1.  Beside the next to the field you want to format, click the **Field Menu** icon (![Screenshot of the Menu icon.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Manufacturing/MenuIcon.jpg)).
            
        2.  Select **Summary Types**.
            
    3.  In the **Layout** panel select a chart type.
        
    4.  Click **Refresh** (![Screenshot of the Refresh icon.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Manufacturing/Refresh.jpg)) to generate the chart.
        
    5.  In the Workbook Menu (![Screenshot of the Menu icon.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Manufacturing/MenuIcon.jpg)), click **Save As**.
        
    6.  In the **Save Workbook As** window, enter a name and description for the workbook.
        
    7.  Click **Apply**.
