To use the Manufacturing Scheduler SuiteApp, enable the features in the following table. For more information, see [Enabling Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N232138.html).

| Subtab | Feature Name |
| --- | --- |
| Items & Inventory | Manufacturing Work In Process |
| Manufacturing Routing and Work Center |

Note:

You cannot install the SuiteApp if any of the following roles are inactive.

-   CEO
    
-   CFO
    
-   Sales Vice President
    
-   Accountant
    
-   Accountant (Reviewer)
    
-   Bookkeeper
    
-   Warehouse Manager
