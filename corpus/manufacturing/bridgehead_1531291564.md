The Engineering Change Order Log section lets an ECO administrator see the implementation status of any approved ECO.

#### To view the implementation status of engineering change orders:

1.  Go to Lists > Engineering > ECO Implementation Status (Administrator).
    
2.  The Engineering Change Order Log section lists all active ECO records.
    
3.  Select a value in the **Implementation Status** list to filter the list:
    
    -   **Pending** - Approved ECO records that haven't been implemented yet.
        
    -   **In Process** - Implementation is in progress for approved ECO records.
        
    -   **Completed** - ECO records that have been implemented.
        
    -   **Error** - Approved ECO records with implementation errors.
        
4.  Click **Go to Main** to go back to the full list. Click **Refresh** to show the latest data.
    

#### To view the implementation status of action changes in approved engineering change orders:

1.  Go to Lists > Engineering > Engineering Change Order (Administrator).
    
2.  On the Engineering Change Order List page, find the ECO record you want to view using filters or sorting tools.
    
3.  Click the **View** link of the ECO record.
    
4.  Click the **Product Changes** subtab.
    
5.  View the implementation status of each change line-item under the **Is Implemented** column.
    
    Note:
    
    You may need to click the collapse (-) icon for a change line to see its implementation status.
