You can manage on how you want to view the Available to Build values from the Custom Preferences subtab. The **General** subtab is found under Setup > Company > General Preferences > Custom Preferences subtab.

Check the following boxes to choose how you want to see available to build details on the Sales Order Entry page.

-   **Show Available to Build Subtab in Sales Order**: Check this box to view Available to Build subtab in the Sales Order Entry page that provides history on the list of items for which ATB is calculated.
    
-   **Allow Available to Build Alerts**: Check this box to see ATB results in a pop-up notification.
    

During the installation of the SuiteApp, these boxes are checked by default.
