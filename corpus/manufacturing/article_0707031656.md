Rough-Cut Capacity Planning (RCCP) helps manufacturing planners compare the capacity available at manufacturing work centers with the capacity required by work orders and planned work orders. RCCP provides a mid- to long-term view of critical machine and labor resources before detailed production scheduling occurs. The report uses planned time from work orders and planned work orders to identify potential overloads and underloads.

## Enabling Rough-Cut Capacity Planning {#subsect_0807120801}

Before you enable Rough-Cut Capacity Planning, the following features must be enabled:

-   Manufacturing Routing and Work Center
    
-   Advanced Bill of Materials
    

The following permissions are required:

-   Manufacturing Routing: View
    
-   Work Order: View or Material Requirements Plan: View ( when MRP feature is enabled)
    

After RCCP is provisioned for your account, you can enable the feature.

#### To enable Rough-Cut Capacity Planning:

1.  Go to **Setup > Company > Enable Features**.
    
2.  Click the **Items & Inventory** subtab.
    
3.  Check the **Rough-Cut Capacity Planning** box.
    
4.  Click **Save**.
    

Important:

When you disable RCCP, Planned Time entries generated for planned work orders are deleted. The **Include in RCCP** box on Supply Plan Definition records is also cleared. If you enable RCCP again, Planned Time entries for existing planned work orders are not regenerated automatically.

## Using Rough-Cut Capacity Planning {#subsect_0807121708}

RCCP calculates available capacity from the work center calendar and the **Total Machine Capacity Resources** and **Total Labor Capacity Resources** values.

#### To review capacity requirements:

1.  Go to **Transactions > Manufacturing > Capacity Planning**.
    
2.  Select a **Subsidiary**.
    
3.  Set the applicable filters.
    
    | Filter | Description |
    | --- | --- |
    | Location | Limits results to one or more locations. |
    | Manufacturing Work Center | Limits results to one or more manufacturing work centers. |
    | Date Range | Limits result rows to the selected dates. |
    | Assembly Item | Limits results to transactions for the selected assembly items. |
    | Supply Plan Definition | Limits planned-order data to orders associated with selected Supply Plan Definitions. The filter applies only to planned work orders. Standard work orders are still included in the results. Note: Planned orders are included only when their Supply Plan Definition has **Include in RCCP** enabled and Planned Time entries have been generated. For more information, see [Creating a Supply Planning Definition and Schedule](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159180786193.html). |
    | Include Unfirmed Work Orders | Select the box to include unfirmed work orders. Applies to both standard and planned work orders. |
    | Include MRP Items | Select the box to include work orders and planned work orders for assembly items that use MRP replenishment. Displayed only with MRP feature enabled. |
    | Include Planned Orders | Select the box to include planned orders generated by Supply Planning. |
    | Reset Filters | Returns top-level filters and toolbar filters to their default state. |
    
4.  The toolbar above the results table includes the following actions:
    
    | Expand all | Expand all result rows to review the orders and operations that contribute to the capacity requirement. |
    | --- | --- |
    | Collapse all | Collapse all result rows. |
    | Export and Print Actions | Select one of the available export options. |
    | Refresh Data | Click to get the latest data. |
    | Work Center Resources | Select one of the capacity resource types available for each work center:
    -   Machine Only
    -   Labor Only
    -   Both Machine and Labor
    -   Either Machine or Labor
    
     |
    | Utilization Range | The Utilization Range filter lets you limit results by machine utilization, labor utilization, or both. You can also select:
    
    -   Under-utilized (represents values below 100%)
    -   Over-utilized (represents values above 100%)
    -   Custom Range
    
     |
    | Time Bucket Selection | Select a daily, weekly, or monthly time bucket. |
    | Customize Columns | Select at least one of the utilization types to display:
    
    -   **Machine Utilization**
    -   **Labor Utilization**
    
    Add or remove columns in the row details table. |
    | Reset | Click to reset all the filters. |
    
5.  Review the main results table. Each result row represents capacity for one work center, location, and time bucket. It contains the following columns:
    
    -   Manufacturing Work Center
        
    -   Location
        
    -   Time Bucket
        
    -   Total Machine Capacity
        
    -   Required Machine Capacity
        
    -   Machine Utilization
        
    -   Total Labor Capacity
        
    -   Required Labor Capacity
        
    -   Labor Utilization
        
    
    Note:
    
    When results are filtered by **Assembly Item** or **Supply Plan Definition**, RCCP displays the filtered value compared with the overall value for Required Machine Capacity, Machine Utilization, Required Labor Capacity, and Labor Utilization.
    
6.  Click the expand icon at the beginning of a row, or click a utilization value, to open an inline detail table. The details include only transactions and operations that contribute to the selected result row.
    
    The detail table includes the following columns by default:
    
    -   Assembly Item
        
    -   Transaction Number
        
    -   Operation
        
    -   Operation Quantity
        
    -   Start Date
        
    -   End Date
        
    -   Required Machine Capacity
        
    -   Machine Utilization
        
    -   Required Labor Capacity
        
    -   Labor Utilization
        
    
    To add other columns, click **Customize Columns** button in the toolbar above the results table.
