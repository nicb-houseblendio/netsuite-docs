As part of the Work Instructions and Traveler SuiteApp, the **Work Instructions** subtab is enabled in the manufacturing record. You can add work instructions for every operation, and include any related images or documents. You can print work instructions and associated images when you generate the traveler report. These reports help shop floor teams to perform the operation of the work order well.

#### To define work instructions: {#procedure_0620084231}

1.  Go to Lists > Supply Chain > Manufacturing Routing.
    
    The Manufacturing Routing page opens.
    
2.  Click **Edit** on a manufacturing routing record.
    
    Note:
    
    The subtab only shows up when you're editing the routing record.
    
3.  Check the manufacturing routing record to ensure all the required information in the **Routing Steps** subtab is available. For more information, read [Creating a Manufacturing Routing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2345383.html).
    
4.  In the **Work Instructions** subtab:
    
    1.  From the **Operation Name** list, select the manufacturing routing operation.
        
        This selection automatically populates the **Operation Sequence**.
        
        Note:
        
        The information in the fields is retrieved from the **Routing Steps** subtab
        
    2.  In the **Process Notes** field, provide instructions for every operation step to manufacture an assembly item based on manufacturing routing.
        
    3.  In the **Work Instructions** column, enter the instructions as per the sequence number to complete the operation.
        
    4.  In the **URL** column, provide a URL link for the operator's reference. You can enter a URL that contains audio, video, or image.
        
    5.  Check the box in the **Print Image** column to print the image (if URL provided in step 4 contains image) in the traveler report.
        
    6.  (Optional) Check the box in the **Inactive** column if you don't want to include a sequence.
        
    7.  Click **Add**.
        
    8.  Repeat steps 3 to 7 to add multiple steps.
        
    9.  Click **Save**.
        

Note:

There are certain limitations for the images to be printed in the traveler report.

-   You can upload an image URL in two ways:
    
    -   Upload the image to the file cabinet and add that file URL in the URL column.
        
    -   Copy the image address from any website (right click on image's copy image address).
        
        -   You must copy the proper address. When you click on the URL link, it should directly open the image.
            
        -   If a URL link has multiple images, the images will not display.
            
-   Image type must be .png or .jpg format.
    
-   The SuiteApp supports 24-bit color depth images in the PDF report while rendering the images from the file cabinet. NetSuite does not support images with other color depth.
    
-   When you upload images to the file cabinet, check the **Available Without Login** box to display the images in the report.
