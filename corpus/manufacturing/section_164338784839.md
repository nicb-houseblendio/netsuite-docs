The SCM Mobile and Manufacturing Mobile bundles contain the mobile device application that production operators and managers use to handle shop floor transactions. These bundles takes three to five minutes to install. You can continue to work in your NetSuite account as the bundle installs. If you have an Assembly and Work Order license, the SCM Mobile and Manufacturing Mobile bundles are shared and set up automatically.

The **Status** column on the Installed Bundles page displays the installation progress. When the installation is complete, a green check mark appears in the **Status** column.

To set up the Manufacturing Mobile SuiteApp, complete the following actions:

1.  [Requesting Sandbox Access](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164338837533.html)
    
2.  [Installing the SCM Mobile Bundle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158404168719.html)
    
3.  [Installing the Manufacturing Mobile Bundle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164338778846.html)
    
4.  [Setting Up Manufacturing Mobile](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158410865709.html)
    
5.  [Creating a WIP Bin for Manufacturing Mobile](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0622023514.html)
    
6.  [Activating the Allow Over-picking for Work Orders System Rule](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_28140403345.html)
    
7.  [Creating a Static Employee Group](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_158618203997.html)
    
8.  [Setting Up a Manufacturing Mobile Custom Role](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0728050037.html)
