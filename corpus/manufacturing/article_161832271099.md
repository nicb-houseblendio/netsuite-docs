To add an advanced manufacturing work bench test, complete the Quality / Inspection subtab.

#### To complete the quality / inspection subtab:

1.  Click the **Quality / Inspection** subtab.
    
2.  Click **New AM Mfg Work Bench Tests**.
    
3.  In the AM Mfg Work Bench Tests form, in the Operation Task Inspection section, complete the following steps:
    
    1.  Select an **Item** from the list.
        
    2.  (Optional) Select a **Test Name** from the list.
        
        NetSuite populates the **Inspection Method**, **Inspection Type**, and **Inspection Results** fields with the test's details.
        
    3.  Select an **Inspection Method** from the list.
        
        For example, Visual Count or Measurement.
        
    4.  Enter a **Description** of the test.
        
    5.  Enter the name of the **Quality Management System Reference**.
        
    6.  Enter the **Operation Inspection Sequence** number.
        
4.  In the Measurements Standards and Attributes section, complete the following steps:
    
    1.  Select an **Inspection Type** from the list.
        
        For example, Standard Result or Requires Sampling.
        
    2.  Select an **Inspection Results** measure from the list.
        
        For example, Pass/Fail or Measurement.
        
    3.  Enter a **Sample Size**.
        
    4.  Select a **Sample Frequency** from the list.
        
        For example, Each Unit, Each Batch, Each Lot, One Sample Per Run, Once Per Operation, or Every Hour.
        
    5.  Select an **Evaluation Criteria** from the list.
        
        For example, Test Passes or Fails, Percentage of Sample Passes, Average of Sample Values in Tolerance, or Measurement Only.
        
    6.  Enter a **Minimum Percent** number.
        
    7.  Enter a **Target Value**.
        
    8.  Enter an **Upper Control Limit** and a **Lower Control Limit**.
        
    9.  Select a **Unit of Measure** from the list.
        
        For example, Each or Lb.
        
    10.  Select a **Default Corrective Measure** from the list.
         
         For example, Open Repair Order, Cancel Work Order, or Work Order On Hold, or No Action Required.
         
5.  In the Parameters section, complete the following steps:
    
    1.  If this is a pass or fail test, check the **Pass Fail Test** box.
        
    2.  If you require a test pass or fail certification, check the **Certificate Required** box.
        
    3.  If you require a test pass or fail signature, check the **Signature Required** box.
        
    4.  If this test is required, check the **This Test is Mandatory** box.
        
6.  To include a note for this test, in the **Notes** subtab, complete the following steps:
    
    1.  Enter a **Title**.
        
    2.  Enter a **Memo**.
        
    3.  Select a memo **Type** from the list.
        
    4.  Select a memo **Direction** from the list.
        
    5.  To include additional notes, click **Add**, and then repeat steps from a to d.
        
7.  To attach a file to this test, click the **Files** subtab, and then do one of the following in the **Attach File** field:
    
    -   To select an existing file in NetSuite, click the double arrow, and then click **List**.
        
    -   To select a new file, click the plus icon, complete the File form, and then click **Save**.
        
    
    1.  To include additional files, click **Add**, and then repeat step 7.
        
8.  Click **Save**.
