Important:

NetSuite 2020.2 relocated and copied some of the manufacturing preferences from their original location. Some of the preferences were originally on the Accounting Preferences > **Items/Transactions** subtab, and others were on the **Order Management** subtab.

All of the manufacturing preferences are located at _Setup > Manufacturing > Manufacturing Preferences_.

Those that remain in their original location can be found at _Setup > Accounting > Accounting Preferences_, on the above-noted subtabs.

The following table lists all of the manufacturing preferences and whether the preference was relocated or copied.

| Preference Area | Preference Name | Move to Manufacturing Preferences | Copy to Manufacturing Preferences | Preference Key |
| --- | --- | --- | --- | --- |
| **Manufacturing Accounts** | Default Unbuild Variance Account |  | Yes | UNBUILDVARIANCEACCOUNT |
| Default WIP Cost Variance Account |  | Yes | WIPVARIANCEACCT |
| Default Scrap Account |  | Yes | SCRAPACCT |
| Default WIP Account |  | Yes | WIPACCT |
| **Production Costing** | Allow bulk cost updates for Production Charges |  |  | ALLOW\_PROD\_CHARGE\_BULK\_UPDATE |
| Allow WIP Costing to Run |  |  | ALLOW\_WIP\_COSTING\_TO\_RUN |
| Average Cost Consumption Unit Cost |  | Yes | AVGCOSTCOMPLETIONCOSTINGMETHOD |
| **Procurement** | Allow Purchase of Assembly Items |  | Yes | ALLOWASSEMBLYPURCHASE |
| **Product Definition** | Allow Editing of Legacy BOMs | Yes |  | ALLOWEDITINGOFMIGRATEDLEGACYBOMS |
| **Production Planning, Scheduling, and Allocation** | Default Scheduling Method | Yes |  | DEFAULTSCHEDULINGMETHOD |
| Default Commit Option on Work Orders |  | Yes | DEFAULTWORKORDERCOMMITOPTION |
| Manufacturing Issue Based on Commitment | Yes |  | BUILDCOMMITTED |
| Create Work Orders in Supply Planning | Yes |  | CREATEWORKORDERINPLANNING |
