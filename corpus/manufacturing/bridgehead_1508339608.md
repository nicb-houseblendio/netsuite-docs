The Tablet Filter icon appears in the Work Queue header and beside each column heading that has a filter applied to it. The Filter Settings window lets you define which columns you want to include in your tablet quick search.

#### To define tablet filter settings:

1.  Tap the **Filter** icon (![Screenshot of the Filter icon.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Manufacturing/AdvancedManufacturing/UserGuide/TabletFilterIcon.png)) to open the **Filter Settings** window.
    
2.  Select the **Quick Search Columns** you want to filter.
    
    Tap **Select All** to choose all columns.
    
3.  Tap a **Work Order Status**.
    
4.  Select whether to **Enable/Disable** **Auto End Date**.
    
5.  Enter the number of days to add to the current date to auto-populate end dates in forms in **Auto End**.
    
    You can also tap **Select** to open the keypad.
    
6.  Tap **OK**.
