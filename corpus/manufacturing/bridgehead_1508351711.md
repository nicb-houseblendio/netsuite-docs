The following table displays the work order management images setup as recommended by your NetSuite Professional Services Consultant.

#### To add work order management images:

1.  To access the images, go to Advanced Manufacturing > Documentation > File Folders.
    
    Alternatively, in the File Cabinet, go to Suite Bundles > Bundle (bundle number) > src > Images.
    
    | **Field** | **Name** | **Icons** | **Description** |
    | --- | --- | --- | --- |
    | **Planned Status Icon** | red\_dot.png | ![Screenshot of the Planned status icon (red dot).](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Manufacturing/AdvancedManufacturing/AdministratorGuide/red_dot.png) | Order information is incomplete and the order cannot be fulfilled. |
    | **Planned Firmed Status Icon** | red\_dot.png | ![Screenshot of the Planned Firmed status icon (red dot).](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Manufacturing/AdvancedManufacturing/AdministratorGuide/red_dot.png) | Order information is complete and accurate, but the order is not in the production schedule. |
    | **Release Status Icon** | blue\_dot.png | ![Screenshot of the Release status icon (blue dot).](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Manufacturing/AdvancedManufacturing/AdministratorGuide/bleu_dot-1.png) | Order is released to the plant for assembly and packaging. |
    | **In Process Status Icon** | yellow\_dot.png | ![Screenshot of the In Process status icon (yellow dot).](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Manufacturing/AdvancedManufacturing/AdministratorGuide/yellow_dot.png) | Order is being built or assembled. |
    | **Completed Status Icon** | green\_dot.png | ![Screenshot of the Completed status icon (green dot).](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Manufacturing/AdvancedManufacturing/AdministratorGuide/green_dot.png) | Order has finished processing and is ready for packaging and shipping. |
    | **Closed Status Icon** | green\_dot.png | ![Screenshot of the Closed status icon (green dot).](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Manufacturing/AdvancedManufacturing/AdministratorGuide/green_dot.png) | Order has shipped. |
    | **On Hold Status Icon** | red\_dot.png | ![Screenshot of the On Hold status icon (red dot).](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Manufacturing/AdvancedManufacturing/AdministratorGuide/red_dot.png) | Order has been entered but cannot be scheduled until an issue is resolved. |
    | **Yellow Warning Icon** | Info.png | ![Screenshot of the Warning icon (yellow triangle).](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Manufacturing/AdvancedManufacturing/AdministratorGuide/Info.png) | Warns that capacity is near or exceeds 85%. |
    | **In Process Icon** | jobActive.png | ![Screenshot of the In Process icon (green and gray gears).](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Manufacturing/AdvancedManufacturing/AdministratorGuide/jobActive.png) | Alerts that production results have been collected and the work order operation is in process. |
    | **Red Warning Icon** | InfoRed.png | ![Screenshot of the Warning icon (red triangle).](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Manufacturing/AdvancedManufacturing/AdministratorGuide/InfoRed.png) | Warns that the work order process is over capacity. |
    | **Calendar Icon** | dateChooser.png | ![Screenshot of the Calendar icon.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Manufacturing/AdvancedManufacturing/AdministratorGuide/dateChooser.png) | Calendar icon. |
    
2.  Click the icon you want to use. A browser window opens.
    
3.  Copy the URL from the browser window navigation bar.
    
4.  Paste the URL into the corresponding **Work Order Images Management** field.
    
    For more information, see step 6 in the [Creating Advanced Manufacturing Administration Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_1508351656.html) procedure.
    
5.  Repeat steps 2 and 3 for all the icon fields you need to define.
