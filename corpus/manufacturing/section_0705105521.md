If you're an administrator, you can create new roles or customize existing roles to use the Work Instructions and Traveler SuiteApp. For more information, see [Customizing or Creating NetSuite Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N285937.html) and [Assigning Roles to an Employee](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N897798.html).

Refer to the following table for minimum access levels for different permissions required to use the Work Instructions and Traveler SuiteApp:

| Subtab | Permission | Minimum Access Level | Purpose |
| --- | --- | --- | --- |
| Transactions | Work Orders | View | Required for:
-   **Print Traveler** button in Work Order page
-   Generate Traveler page

 |
| Find Transaction | View | Required for Generate Traveler page |
| Lists | Documents and Files | View | Required for:

-   **Print Traveler** button in Work Order page
-   Traveler Preferences

 |
| Items | View | Required for Generate Traveler page |
| Locations | View | Required for Generate Traveler page |
| Manufacturing Routing | View | Required for **Work Instructions** subtab |
| Perform Search | View | Required for **Work Order Saved Search** field in Generate Traveler page. If you don't have this permission, that field will be disabled. |
| Custom Record Entries | Edit | Required for **Work Instructions** subtab |
| Setup | SuiteScript | View | Required for all pages |
| Custom Records | Traveler Preferences | View | Required for all pages |
| Traveler Template | View | Required for:

-   Generate Traveler page
-   Traveler Template

 |
| Additional Work Instructions Subtab | Full | Required for **Additional Work Instructions** subtab in work order record |

You can create new roles or customize existing roles using the Administrator role to use the SuiteApp. For more information about minimum permissions required, see [Customizing and Creating Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N286284.html).
