The default operation view displays all work orders with either of these statuses: **In Process** or **Released**. It also shows the work centers linked to the subsidiary of the currently logged-in user. Use the default view or create a custom view to handle a specific set of operations. When creating a custom view, set your preferences for any of the following filters:

-   Production Date From and To
    
-   Subsidiary
    
-   Location
    
-   Work Center
    
-   Work Order Status
    

Note:

You can display a maximum of 2000 operations per page. Creating a custom view helps you limit the number of operations shown on the chart.

For example, if there are 20 work centers with a total of 2500 work orders, the Work Center view shows the list of 20 work centers in the left pane. Only the first 2000 work orders are shown under their corresponding work centers. If the 2000 work orders reach to work center 18, work centers 19 and 20 are listed but no work orders are shown under them.

-   On the Operation View Filter bar, the **Add View** button appears only on the **Default** view.
    
-   The **Edit View** and **Copy View** buttons appear only on a custom view.
    

## Adding Views {#bridgehead_0224045856}

You can create multiple custom views to handle manufacturing operations on the chart.

#### To add a view:

1.  On the Manufacturing Scheduler page, click **Add View**. The **Add View** button appears only when you select **Default** as **Operation View** type.
    
2.  In the **Add View** popup window, set the following fields:
    
    | Field | Description |
    | --- | --- |
    | Operation View | Add a name for the custom view. |
    | Production Date From | Select the production start date. |
    | Production Date To | Select the production end date. |
    | Subsidiary | Select the subsidiary to view related work order and work center details. |
    | Location | Select a location. |
    | Work Center | Select the work centers. |
    | Work Order Status | Select the status of work order. You can select multiple statuses to view relevant work orders. |
    
3.  Click **Save**.
    
    You can see the custom work order on the **Operation View** filter.
    
4.  To make changes to a custom view, select the name of the view and then click **Edit View**.
    
5.  In the **Edit View** popup window, you can change or update the required preferences.
    
6.  To create another view type with similar preferences or slight variations, use the **Copy View** option.
    

For custom views with a specified date range for the production start date, the start and end of the range appear with vertical bars. All production start dates or end dates that fall within the range appear inside the bars.
