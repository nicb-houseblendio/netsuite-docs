The **Cost Category** subtab displays the variances for a work order by cost category. This subtab calculates the sum of all the costs under each cost category. This subtab is available for both work in progress and non-work in progress work orders.

Note:

If no cost category is associated with any of the component items, there will be no data in this subtab.

The following table provides details about the columns in the **Cost Category** subtab.

| Field | Description |
| --- | --- |
| Cost Category | Cost category type. |
| Planned Cost | Planned cost for completing the work order. |
| Actual Cost | Actual cost for completing the work order. |
| Cost Variance | Cost difference between actual cost and planned cost of the work order. |
| Cost Variance (%) | Percentage of cost variance per planned cost of the work order. |
