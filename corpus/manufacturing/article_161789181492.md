Before you can use a tablet, you must create a tablet data collection configuration record and set up a tablet data role.

The tablet data collection configuration establishes the content, order, and sorting for each column in the tablet work queue table. This section describes the fields and default values that enable the tablet to function in its standard configuration.

For more information, see [Creating a Tablet Data Configuration Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161789193998.html) and [Assigning a Tablet Role to an Employee](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161789200196.html).

## Tablet Requirements {#bridgehead_1537879543}

-   At least 256 MB flash memory
    
-   Android 4.1 or higher
    
-   1D barcode scanner
    
-   4 inch or larger touch screen
    
-   802.11a/b/g enabled
    
-   Bluetooth enabled
    
-   HTML 5 and Javascript enabled browser (TLS 1.2 compliant)
    
-   Interactive Sensor Technology (IST)
    
-   (Optional) Ruggedized or semi-ruggedized
