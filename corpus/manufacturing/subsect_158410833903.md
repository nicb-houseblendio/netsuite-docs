The NetSuite Manufacturing Mobile SuiteApp enables you to use scanners to process consumption and production records to your NetSuite account. To ensure that your mobile device meets NetSuite's mobile device requirements, see [Mobile App Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1541432880.html).

Like NetSuite WMS, you can enable all customizations supported by the SCM Mobile framework. For more information, see [SCM Mobile App Customization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_163614460343.html).

Note:

Before you can enable no-code solution supported by the SCM Mobile framework, you must set a maximum number of line items for a no-code solution.
