Review the following points before you use the Engineering Change Order (ECO) feature:

-   You can use Engineering Change Order only with inventory and assembly items.
    
-   The feature doesn't support custom workflows for ECO approval. For more information, see [SuiteApprovals Considerations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0806110833.html).
    
-   If your NetSuite account has more than 80,000-90,000 active assembly and inventory items per subsidiary, ECO records may fail to load because of the user event script threshold.
    
-   The feature doesn't support SOAP web services and CSV import.
    
-   The feature works only with Advanced Bill of Materials (BOM) and it doesn't support Legacy Bill of Materials. For more information, see [Enabling Advanced BOM](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1497967586.html).
