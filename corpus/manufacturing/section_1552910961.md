This Manufacturing dataset combines fields from the Manufacturing Transaction record type and one custom formula. This dataset enables you to analyze the status of bills received during the last month. It forms the source data for the [Manufacturing Workbook](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1549896896.html).

## Dataset Configuration {#subsect_158254045818}

The Manufacturing dataset combines fields from one record type, one custom formula, and multiple criteria filters. To edit the dataset, see [Defining a Dataset](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544122173.html).

| Root Record Type | Joined Record Type | Custom Formula Field | Data Grid | Criteria Filers |
| --- | --- | --- | --- | --- |
| Manufacturing Transaction | (none) | The following custom formula is included in the dataset:
-   **cost/unit** - CASE WHEN {quantity} > 0 THEN TO\_NUMBER({transaction^transaction.transactionlines.foreignAmount})/{quantity} END

 | The following fields are included in the dataset. Manufacturing Transaction:

-   Assembly
-   Date
-   End Date
-   Location
-   Memo
-   Posting Period
-   Quantity
-   Start Date
-   Transaction
-   Transaction Type

 | The following criteria is used to filer the dataset:

-   **Transaction Type** any of Assembly Build, Work Order Close
-   **Transaction Line: Main Line** is true
-   **Date** on or after 2 Years ago

 |
