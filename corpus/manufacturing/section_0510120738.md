The **Conversion Costs** subtab shows costs for operations like labor cost, machine cost, and so on, for the selected work order. Total cost is the sum of labor cost and machine cost.

This subtab won't show any data if the work order isn't linked to a manufacturing routing.

The table below explains the columns in this subtab.

| Field | Description |
| --- | --- |
| Operation | Operation sequence in the manufacturing routing associated with the work order. |
| Name | Operation name of the operation sequence. |
| Planned Total Cost | Sum of planned labor cost and planned machine cost. If the planned total cost is zero and the actual total cost is non-zero, the total cost variance percentage is 100%. |
| Actual Total Cost | Sum of actual labor cost and actual machine cost. If the planned total cost is zero and the actual total cost is non-zero, the total cost variance percentage is 100%. |
| Total Cost Variance | The difference between actual total cost and planned total cost. |
| Total Cost Variance (%) | Percentage of total cost variance per planned total cost. |
| Planned Labor Cost | Sum of all the planned labor costs associated with the operation. If the planned labor cost is zero and the actual labor cost is non-zero, the labor cost variance percentage is 100%. For more information, see [Conversion Cost Formulas for Planned and Actual Costs](#bridgehead_70121350422). |
| Actual Labor Cost | Sum of all the actual labor costs associated with the operation. If the planned labor cost is zero and the actual labor cost is non-zero, the labor cost variance percentage is100%. For more information, see [Conversion Cost Formulas for Planned and Actual Costs](#bridgehead_70121350422). |
| Labor Cost Variance | The difference between planned labor cost and actual labor cost for the work order. |
| Labor Cost Variance (%) | Percentage of labor cost variance per planned labor cost of the work order. |
| Planned Machine Cost | Sum of all the planned machine costs associated with the operation. If the planned machine cost is zero and the actual machine cost is non-zero, the machine cost variance percentage is 100%. For more information, see [Conversion Cost Formulas for Planned and Actual Costs](#bridgehead_70121350422). |
| Actual Machine Cost | Sum of all the actual machine costs associated with the operation. If the planned machine cost is zero and the actual machine cost is non-zero, the machine cost variance percentage is 100%. For more information, see [Conversion Cost Formulas for Planned and Actual Costs](#bridgehead_70121350422). |
| Machine Cost Variance | The difference between planned machine cost and actual machine cost. |
| Machine Cost Variance (%) | Percentage of machine cost variance per planned machine cost. |

## Conversion Cost Formulas for Planned and Actual Costs {#bridgehead_70121350422}

The following table contains conversion cost formula for planned and actual costs.

| Cost Calculation | Planned Cost Formula | Actual Cost Formula |
| --- | --- | --- |
| Labor Run and Labor Run Overhead | Cost \* Labor Resources \* (Run Rate/60) \* Build Quantity | Cost \* Labor Resources \* (Labor Run Time/60) |
| Labor Setup and Labor Setup Overhead | Cost \* Labor Resources \* (Setup Time/60) | Cost \* Labor Resources \* (Labor Setup Time /60) |
| Machine Run and Machine Run Overhead | Cost \* Machine Resources \* (Run Rate/60) \* Build Quantity | Cost \* Machine Resources \* (Machine Run Time /60) |
| Machine Setup and Machine setup Overhead | Cost \* Machine Resources \* (Setup Time/60) | Cost \* Machine Resources \* (Machine Setup Time /60) |

Note:

The following points are applicable for conversion costs calculation:

-   The parameters related to planned cost formula are taken from the work orders and their respective manufacturing operation tasks.
    
-   The parameters related to actual cost formula are taken from the work order completions.
