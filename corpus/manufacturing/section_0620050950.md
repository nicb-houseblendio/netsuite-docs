The Work Instructions and Traveler SuiteApp requires a NetSuite OneWorld account. Only users with Administrator role can install the SuiteApp. For more information about installing a SuiteApp, see [Installing from the SuiteApp Marketplace](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1539799323.html) and [SuiteApp Marketplace in NetSuite](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1539797981.html).

Note:

After you install the SuiteApp, it creates a preferences record with a default template. You can also set up your traveler preferences for the work order instructions and traveler reports. Setting up traveler preferences helps you to generate the report in the right template format and directory location within the file cabinet. For more information, read [Updating Traveler Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0620054852.html).

If you want to reinstall Work Instructions and Traveler SuiteApp after uninstalling it, you must perform the following activities:

-   You can take a backup of **Work Instructions & Traveler** folder from the File Cabinet page. For more information about how to download a file or folder from the File Cabinet, see [Downloading Files from the File Cabinet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N544050.html).
    
-   Delete the **Work Instructions & Traveler** folder from the File Cabinet page, then reinstall the SuiteApp. For more about how to delete a file or folder from the File Cabinet, see [Deleting Folders from the File Cabinet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3947389300.html).
