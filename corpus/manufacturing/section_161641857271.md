Manufacturing Mobile presents a clean, minimalist interface layout to help you to identify what is available and select the right option.

The following table describes the user interface icons and buttons.

| Icon or Button | Description |
| --- | --- |
| Menu ![Menu](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Manufacturing/ManufacturingMobile/Menu.png) | Tap the menu icon to open the mobile menu to change assignment, change application, or log out. Tap the maximize icon ![Full Screen](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Manufacturing/ManufacturingMobile/Maximize.png) to enable full screen mode. |
| Search ![Search](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Manufacturing/ManufacturingMobile/Search.png) | Tap the search icon to open the Manufacturing Mobile search. In the **Search** field, enter a search term. The interface displays results as you type. Tap the filter icon ![Filter](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Manufacturing/ManufacturingMobile/FilterIcon.png) to refine your search details. |
| Column ![Column Icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Manufacturing/ManufacturingMobile/Column.png) | Tap the column icon to open the columns pop-up. In this window, you can select other columns such as order #, assembly, and date. Tap **Use full-width columns** to display the columns in full-width. |
| Info ![Info Icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Manufacturing/ManufacturingMobile/InfoIcon1.png) | Tap the info icon to display details about the job. When available, the info screen displays a picture of the item the job is building. |
| Back ![Back](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Manufacturing/ManufacturingMobile/Back.png) | Tap the back icon to return to the previous screen. |
| Return ![Return](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Manufacturing/ManufacturingMobile/Return.png) | Tap the return icon to return to the static screen or exit the scanner flow. For example, if you do not want to report production data, tap the return icon to return to the Report Work screen. If you report production data and complete your work, tap the return icon to exit the scanner flow. |
| Badge ![Badge Icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Manufacturing/ManufacturingMobile/Badge.png) | Tap the badge icon to badge-in to the work center. |
| Work Instructions ![Work Instructions icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Manufacturing/ManufacturingMobile/WorkInstructions.png) | Tap the work instructions icon to include work instructions. |
| Enter button | Tap **Enter** to enter information in the Manufacturing Mobile interface. |

For more information, see [Configuring Mobile Page Elements](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161549215472.html).
