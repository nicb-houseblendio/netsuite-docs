The following roles can access the custom forms and records for Engineering Change Order (ECO):

-   Accountant
    
-   CEO
    
-   CFO
    
-   Warehouse Manager
    
-   Administrator
    

Other roles for Engineering Change Order need additional permissions to use the feature. The following table shows the permissions you need to use ECO. For information about customizing roles, see [Customizing or Creating NetSuite Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N285937.html).

| Subtab | Permissions | Level | Description |
| --- | --- | --- | --- |
| Custom Record | Engineering Change Order Type | Full | Lets you create engineering change order types. |
| Engineering Change Order Type | View | Lets you create, view, or edit engineering change orders. |
| Engineering Change Order | Full |
| List | Custom Record Entries | View |
| Custom Record | ECO Implementation Log | View | Lets you access the engineering change order implementation status. |
| Setup | SuiteScript | View | Lets you implement approved engineering change orders. |
| SuiteScript Scheduling | Full |
