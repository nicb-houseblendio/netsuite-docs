#### To set up manufacturing routing:

1.  To enable the feature, see [Enabling the Manufacturing Routing Feature](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2341773.html).
    
2.  To set preferences, see [Setting Routing Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3950900044.html).
    
3.  To define cost categories, see [Defining Cost Categories for Manufacturing Routing and Work Center](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2342063.html).
    
4.  To define manufacturing charge items, see [Defining a Manufacturing Charge Item](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2343650.html).
    
5.  To group manufacturing charge items into a cost template, see [Creating Manufacturing Cost Templates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2344013.html).
    
6.  To define resources, see [Creating Manufacturing Work Centers or Groups](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2344727.html) and [Work Center Calendars](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3911875603.html).
    
7.  To create routings, see [Creating a Manufacturing Routing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2345383.html).
    
8.  To set up standard costing, (for accounts using the Standard Costing feature), see [Standard Costing for Manufacturing Routing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2345796.html).
