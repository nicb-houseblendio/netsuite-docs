The **All Components Requirements** subtab displays the list of all components used in work orders. The results are displayed based on the dates you provide in the **Date Range** field. These results can also be filtered based on the component.

The following table provides details about the columns in the **All Components Requirements** subtab.

| Column Name | Description |
| --- | --- |
| Component | Name of the component. |
| Total Required Quantity | Total ordered quantities across all the work orders. |
| Units | Base unit of the item. |
| On Hand | Displays on hand quantity from the item record. |
| Committed | Displays committed quantity from the item record. |
| Available | Displays available quantity from the item record. |
| Total Planned Supplies | Total of all planned supply quantities of a component across all the work orders. The SuiteApp shows total planned supplies based on the following date range.
-   Current system date to selected future date. Note: If the start date of the **Date Range** is from a historical period, the SuiteApp uses the current system date as the start date to load results.
-   If date range is not selected, the SuiteApp defaults to a time frame from the current system date to seven days in the future.

 |

To download data from the **All Components Requirements** subtab, click **Export** button. This will generate an XLSX file containing the relevant subtab data.
