The Cost Variance Analysis SuiteApp analyzes the variances that happen while you're running work orders. These variances are associated with quantity and cost between the planned values for the work order and the actual values recorded against the work order.

This SuiteApp also enables you to do the following:

-   Measure how your work orders perform and help prevent cost overruns.
    
-   Provide visibility to review work order cost variances at component and operation level. Review the work order including work order, cost type and cost category, with access to detailed information up to the transaction level.
    

You can access the SuiteApp from two places:

-   Go to Reports > Cost Accounting > Cost Variance Analysis.
    
-   Click on the **Cost Variance Analysis** button in a work order record.
    
    You'll see the **Cost Variance Analysis** button in a work order record if:
    
    -   The work order status is not **Planned** or **Released**.
        
    -   The work order contains actual production start date.
        
    -   The work order is in view mode.
        
    -   The work order is not outsourced.
        

Note:

Cost analysis isn't supported for work orders that use standard cost items.
