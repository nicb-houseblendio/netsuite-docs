The Costed Bill of Materials SuiteApp supports the following browsers and operating systems:

| Browser | Operating System |
| --- | --- |
| Google Chrome | Windows 10 Mac OS 10.15 or newer |
| Microsoft Edge (Chromium-based) | Windows 10 |
| Mozilla Firefox | Windows 10 Mac OS 10.15 or newer |
| Safari | Mac OS 10.15 or newer |

Note:

In the **Item** field of the Costed Bill of Materials page, type three characters and click on the field for the items to be populated in the list, based on the search. This is applicable only for Safari browser.
