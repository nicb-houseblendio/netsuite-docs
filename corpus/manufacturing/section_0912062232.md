If you are an administrator, you can create new roles or customize roles for using the Available to Build SuiteApp. For more information, see the help topics [Assigning Roles to an Employee](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N897798.html) and [Customizing or Creating NetSuite Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N285937.html).

Refer to the following table for minimum access levels of permissions required for the SuiteApp deployment. These minimum permissions must be updated to the existing role or when creating a new role.

| Subtab | Permission | Minimum Access Level | Purpose |
| --- | --- | --- | --- |
| Transactions | Sales Order | Edit | Required for Available to Build SuiteApp. |
| Transactions | Work Order | View | Required for Available to Build SuiteApp. |
| Transactions | Find Transaction | View | Required for Available to Build SuiteApp. |
| Lists | Items | View | Required for Available to Build SuiteApp. |
| Lists | Locations | View | Required for Available to Build SuiteApp. |
| Lists | Subsidiaries | View | Required for Available to Build SuiteApp. |
| Lists | Bill of Materials | View | Required for Available to Build SuiteApp. Note: This permission is required only if the **Advanced Bill of Materials** feature is enabled. |
| Lists | Units | View | Required for Available to Build SuiteApp. Note: This permission is required only if the **Multiple Units of Measure** feature is enabled. |
| Setup | Set Up Company | Full | Required for Available to Build SuiteApp. |
