If you accidentally closed a non-WIP work order, you can reopen it using one of the following methods:

-   Selecting the new **Reopen** action in the Actions menu on the **Work Order** page.
    
-   Changing the work order status in the **Status** field.
    
-   Updating the **Status** field through SuiteScript or CSV import
    

To reopen a closed non-WIP work order, the following conditions must be met:

-   The user has **Work Order Edit** permission.
    
-   The work order Built quantity is less than the value in the Quantity field on the Work Order page, or the work order Quantity is zero.
    
-   The work order is not voided.
    

Note:

After you reopen a work order (except for outsourced work orders), the status is set to **In Process** if the work order is partially built. Otherwise, the status is set based on the **Default Work Order Status** setting in Manufacturing Preferences (see [Manufacturing Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159112709448.html)).

Note:

Outsourced work orders that are linked to a Purchase Order can be reopened only by clearing the **Closed** box on the Purchase Order line in edit mode. Status is set to either **In Process** in case of partially built Work Order, or **Released** in other cases.
