The NetSuite Manufacturing Mobile SuiteApp uses your mobile device internet browser to report data wirelessly within your facility. Manufacturing Mobile enables you to report the Location, Work Center, Date, and Shift you want to report data for. For more information, see [Setting Up Manufacturing Mobile](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158410865709.html).

To begin collecting mobile data, see the following topics:
