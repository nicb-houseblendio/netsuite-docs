In certain business cases, you can provide specific work instructions related to a work order. You can add these instructions in the **Additional Work Instructions** subtab of the work order record. However, to enable this subtab, check the **WIP** box under the Primary Information section.

#### To define additional work instructions: {#procedure_0117115317}

1.  In the **Additional Work Instructions** subtab:
    
    1.  In the **Work Instructions** column, enter the instructions as per the sequence number to perform the steps to complete an operation.
        
    2.  In the **URL** column, provide a URL link for the operator's reference. You can enter a URL that contains audio, video, or image.
        
    3.  Check the box in the **Print Image** column to print the image (if URL provided in step 2 contains image) on the traveler report.
        
    4.  (Optional) Check the box in the **Inactive** column if you don't want to use a particular sequence.
        
    5.  Click **Add**.
        
    6.  Repeat steps 1 to 4 to add multiple steps.
        
    7.  Click **Save**.
        

Note:

There are certain limitations for the images to be printed in the traveler report.

-   You can upload an image URL in two ways:
    
    -   Upload the image to the file cabinet and add that file URL in the URL column.
        
    -   Copy the image address from any website (right click on image's copy image address).
        
        -   You must copy the proper address. When you click on the URL link, it should directly open the image.
            
        -   If a URL link has multiple images, the images will not display.
            
-   Image type must be .png or .jpg format.
    
-   The SuiteApp supports 24-bit color depth images in the PDF report while rendering the images from the file cabinet. NetSuite does not support images with other color depth.
    
-   While uploading images in the file cabinet, check the **Available Without Login** box to display the images in the report.
    

Note:

Following are the points applicable to the **Additional Work Instructions** subtab:

-   To access the **Additional Work Instructions** subtab, check the permissions provided for the **Additional Work Instructions Subtab** custom record. For more information, read [Creating or Customizing Roles and Permissions to Use Work Instructions and Traveler SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0705105521.html).
    
-   The extra work instructions and their images will be included when you print the Work Instructions and Traveler report.
