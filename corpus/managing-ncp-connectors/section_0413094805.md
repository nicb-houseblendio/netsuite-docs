When viewing or editing data mappings, you can use Mapping Level, View, and Mapping Origin to refine the displayed mappings.

## Mapping Level {#subsect_0413095921}

The Mapping Level can either be **Order Header** or **Order Item**. It can be used as a filter for the following syncs:

-   Salesforce Opportunity to NetSuite Sales Order Sync
    
-   NetSuite Sales Order to Salesforce Order Sync
    
-   NetSuite Fulfillment to Salesforce Fulfillment Sync
    

## View {#subsect_0413100129}

The available values for the View filter are:

-   Field ID Only
    
-   Field Label Only
    
-   Both Field Label and Field ID
    

## Mapping Origin {#subsect_0413100227}

The available values for the Mapping Origin filter are:

-   Default
    
-   User-added
    
-   All
