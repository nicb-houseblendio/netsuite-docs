You can test your mappings or post individual items using manual posting.

#### To manually post data:

1.  Go to the Data Flows page. You can do this by clicking the connector link from the Connector Overview portlet.
    
2.  In the Data Flows page, select the relevant connector.
    
3.  On the row of the sync that you want to manually post, click **Post Record** on the Mappings column.
    
4.  On the Manual Data Sync page, enter the **Record Internal ID**
    
    Note:
    
    When you go to the Manual Data Sync page, the connector and sync is automatically selected based on where you clicked **Post Record**. While on the Manual Data Sync page, if you want to select a different sync, you can use the sync drop-down list.
    
5.  Click **Post Record**.
