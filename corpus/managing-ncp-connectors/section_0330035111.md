The connection to your Salesforce account is facilitated by the dedicated Salesforce integration user and the Salesforce connected app. You'll need to enter the credentials of the API-only Salesforce user you created in [Creating the Integration User in Salesforce](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0708012729.html#subsect_1190752718).

The requirements for this step can vary depending on the Salesforce edition you use. You need to select the Salesforce Edition you are using from the dropdown list on the Salesforce Connector Setup Wizard

To create the NetSuite Connection, you can create a new user or use an existing NetSuite user account. If you are going to use an existing NetSuite user, refer to [Using an Existing NetSuite User to Create Salesforce Connector Connection](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_5132242955.html) for more information.

Note:

When you use an existing NetSuite user, you need to have the existing user's **NetSuite Token ID** and **NetSuite Token Secret**.

If you are not using Salesforce Professional edition, you will also need the consumer key, and consumer secret of your Salesforce Connected App. See [About the Salesforce Connected App](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1190752721.html) for more information.

#### To create the NetSuite Connection:

Note:

If the setup wizard fails to create the Integration User in NetSuite, you may need to perform the procedure manually. See [Create an Integration User in NetSuite](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0106064253.html) for more information.

1.  On the **2.1 Create NetSuite Connection** tab, enter the **Integration user type**. You can choose to create a new user or use an existing user.
    
    -   If you select **Create New User**, you need to enter the email domain of the integration user in **NetSuite Integration User Email Domain**.
        
    -   Note:
        
        If you are using an existing NetSuite user to create the NetSuite connection, refer to [Using an Existing NetSuite User to Create Salesforce Connector Connection](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_5132242955.html) for more information.
        
        If you select **Utilize existing user**, you need to enter the integration user's **NetSuite Token ID** and **NetSuite Token Secret**.
        
2.  Click **Create Connection**.
    

#### To create the Salesforce Connection:

When you create the connection, the screen is updated with an in progress banner message. The setup wizard doesn't automatically update and display a success message when the connection is created successfully. You need to periodically click **Refresh** until you get the success message.

When you get the success message, you can proceed to the next step of the setup wizard, [Salesforce Connector Setup Wizard: Setup Environment](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0330062041.html).

1.  On the **2.2 Create Salesforce Connection**, select your Salesforce Edition in **Salesforce Edition**.
    
2.  Choose accordingly in **Selected Connected App Choice** depending on your connected app.
    
    -   **Manage Connected App** - Select this if you do not have an existing connected app. This option will use the connected app provided by the Salesforce Connector. When you select Manage Connected App, you do not need to provide any Consumer Key or Consumer Secret.
        
    -   **Existing Connected App** - Select this only if you were able to create a new connected app or have edited an existing connected app to use with Salesforce Connector.
        
3.  Click **Create Connection**.
    
    The screen is updated with an in progress banner message. Creating the connection to Salesforce can take several minutes to complete.
    
    Note:
    
    If the setup wizard fails to create the Integration User in NetSuite, you may need to perform the procedure manually. See [Create an Integration User in NetSuite](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0106064253.html) for more information.
