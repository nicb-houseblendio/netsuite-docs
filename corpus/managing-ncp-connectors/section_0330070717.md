The Salesforce managed package includes a custom permission set. You need to add this permission set to your integration user to ensure that all the permissions required by Salesforce Connector are available.

#### To add the permission sets to the integration user:

Note:

The integration user will no longer able to log in to the Salesforce UI.

1.  Log in to your Salesforce account with your Administrator user.
    
    You need to use an account with System Administrator privileges to create and add permission sets.
    
2.  Add the permission set to your integration user.
    
    1.  Go to Setup > Users > Users and select the integration user you created.
        
    2.  Scroll down to **Permission Set Assignments** and click **Edit Assignments**.
        
    3.  Select the **NetSuite Connector Platform ApiOnlyUser Permission Set** in **Available Permissions Sets** and click **Add** to move the permission to **Enabled Permission Sets**.
        
3.  Click **Save**.
