You need to configure page layouts in Salesforce after completing setup, so that NetSuite-related fields are available on Salesforce objects. To manage your Salesforce page layouts, go to Connector Platform > Settings > Manage Layouts.

You can select one of the following options:

-   Use existing Account layouts - Add the NetSuite fields to the existing Salesforce layouts. Use this if your target user profiles are already assigned to specific layouts and you need NetSuite Connector-related fields and sections to be appended to the layouts they use.
    
-   Use a new NetSuite Connector Platform Salesforce Connector layout - Create a new layout for the object in Salesforce with standard fields and include NetSuite fields. Use this if your target users profiles will only do NetSuite Connector-related activities in Salesforce. Go to Setup > Object Manager.
    
    For the objects listed in the table, click on each object then click Page Layout Assignment > Edit Assignment. Select the list of user profiles that need to access this layout and under Page Layout to Use, select the applicable NetSuite Connector Platform _{Object Name}_ Layout
    

The following table lists the new Salesforce Connector layouts that are added when you choose to use the new layouts.

| Salesforce Object | Custom Page Layout |
| --- | --- |
| Account | NetSuite Connector Platform Account Layout |
| Contact | NetSuite Connector Platform Contact Layout |
| Opportunity | NetSuite Connector Platform Opportunity Layout |
| Order | NetSuite Connector Platform Order Layout |
| Product | NetSuite Connector Platform Product Layout |
