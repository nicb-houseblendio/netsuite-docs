When you map NetSuite items to Salesforce products, the following columns are available:

-   Mapping Type
    
-   Source
    
-   Destination
    
-   Product Types
    
-   Action
    

You can create standard-to-standard, custom-to-standard, standard-to-custom, and custom-to-custom mappings. Use the Product Types column to select which Salesforce product types receive the mapped value. If a source NetSuite field is not available or has no value for a particular item type when the sync runs, Salesforce Connector ignores that value for that item type.
