| **Issue** | **Probable Root Cause** | **Resolution** |
| --- | --- | --- |
| Deploy salesforce package failed with below error: This package can't be installed. There are problems that prevent this package from being installed. | Salesforce Account is in Enterprise Edition. | Reconfigure the Setup with Developer Edition Salesforce account. |
| Unable to complete Step 2 (Create Connection) Error: Failed to create Oracle NetSuite Connection Creating connection failed with the following error: 1021: Error : Failed to generate TBA token for the user {usename}. Adding access for this user exceeds the number of licenses you have purchased. To add another user, you must first remove access from an existing user or contact NetSuite to purchase additional licenses. | License exceeded issue is encountered. | Ensure that at least one (1) license is available for the integration user created by Salesforce Connector. |
| The API-only integration user cannot log in directly to Salesforce UI. | Expected behavior for **Minimum Access - API Only Integrations**. | Use an administrator account and the Salesforce **Login as** option to reset the integration user's security token. |
| Salesforce connection fails in the wizard. | Incorrect user name, password, token, consumer key, consumer secret, expired security token, or OAuth username-password flow not enabled. | Verify the integration user's password and security token, connected app OAuth settings, OAuth username-password flow setting, and IP relaxation. |
| Deploy Package step fails at **Salesforce- Assign API Only Permission Set to Integration User**. | The setup wizard was unable to assign the managed package API-only permission set to the Minimum Access user. | Manually assign **NetSuite Connector Platform ApiOnlyUser Permission Set** to the integration user. |
| Deploy Package step fails at **Salesforce- Update Remote Site Settings**. | The API-only user does not have enough Salesforce setup access for that metadata update. | Manually update the **Oracle\_Integration\_Host** Remote Site Setting with the correct OIC host URL. |
| Deploy Package step fails at **Salesforce: Fetch Salesforce Domain Name**. | Required package Apex classes are not enabled for the relevant permission set/user access. | Edit Apex Class Access and enable all `_Oraclenetsuite..._` classes. |
