Important:

When modifying mappings, you need to ensure that the corresponding data flow is inactive. Clicking **Map** when the data flow is active, displays an error message instructing you to set the data flow to inactive before editing mappings. You also can't activate a sync when the data flow mappings screen is still set to Edit mode. To activate the sync, you need to save the changes on page level of the mappings screen and exit Edit mode.

To go to the NetSuite Connector Platform Mappings screen, go to Connector Platform > Settings > Data Flows then in the Mappings column, click **Map**.

#### To view data mappings:

1.  On the Data Mappings section, select the sync that contains the mappings you want to view from the **Data Flow** list.
    
2.  Optional. Use the filters, Mapping Level, View, and Mapping Origin to refine the displayed mappings.
    
    Note:
    
    Applicable filters can vary depending on the sync. See [Applicable Filters for Salesforce Connector Syncs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0413094805.html) for more information.
    

#### To create a new data mapping:

1.  View the Data Flow where you want to create a new mapping.
    
2.  Click **Edit**.
    
3.  In Edit Mode, click **Add Row**.
    
4.  To save the added row, click the three-dots menu on the Action column then click **Save**.
    
    Wait for the confirmation message to display. In case you encounter an error, you need to click **Save** again to resubmit the new mapping. If you get the same error after multiple attempts, you should delete the row, then create a new one for submission.
    
    Note:
    
    Saving mappings and confirming the success status can take some time to complete.
    
5.  Repeat steps 3 and 4 as needed.
    

When you finish creating new data mappings, click **Save** on the upper left of the data mappings screen to exit edit mode. If you still need to modify other mappings, continue in edit mode and do the page-level save only when all changes to data mappings are complete.

#### To update an existing data mapping:

1.  View the Data Flow where you want to create a new mapping.
    
2.  Click **Edit**.
    
3.  On the row you want to edit, click the three-dots menu on the Action column then click **Edit**.
    
    Note:
    
    Mappings of the same field type can be updated in the same mapping row. When you update mappings of a different field type, you must first delete the existing mapping. Then you can create a new mapping to the same destination field.
    
4.  To save the edit row, click the three-dots menu on the Action column then click **Save**.
    
    Wait for the confirmation message to display. In case you encounter an error, you need to click **Save** again to resubmit the new mapping. If you get the same error after multiple attempts, you should delete the row, then create a new one for submission.
    
    Note:
    
    Saving mappings and confirming the success status can take some time to complete.
    

When you finish editing data mappings, click **Save** on the upper left of the data mappings screen to exit edit mode. If you still need to modify other mappings, continue in edit mode and do the page-level save only when all changes to data mappings are complete.

#### To delete a data mapping:

1.  View the Data Flow where you want to create a new mapping.
    
2.  Click **Edit**.
    
3.  On the row you want to delete, click the three-dots menu on the Action column then click **Remove**.
    

When you finish removing data mappings, click **Save** on the upper left of the data mappings screen to exit edit mode. If you still need to modify other mappings, continue in edit mode and do the page-level save only when all changes to data mappings are complete.
