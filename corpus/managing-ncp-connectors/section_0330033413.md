This step imports the connector integration packages. The import process can take several minutes to complete. When you start the import process, the screen is updated with an in progress banner message. The setup wizard doesn't automatically update and display a success message when the import process completes. You need to periodically click **Refresh** until you get the success message.

When you get the success message, you can proceed to the next step of the setup wizard, [Salesforce Connector Setup Wizard: Create Connection](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0330035111.html).
