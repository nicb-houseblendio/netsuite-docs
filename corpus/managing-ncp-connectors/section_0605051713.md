| **Issue** | **Probable Root Cause** | **Resolution** |
| --- | --- | --- |
| NetSuite Connector Platform displays the following error message: The system is currently unable to process your request. Please try again later. If the issue persists, please contact your account manager. | Unable to reach Oracle Integration Cloud (OIC). | Check with OIC team if there are any patch upgrade. Or check if OIC instance is deleted or deactivated. |
| Salesforce sandbox account is used. | \- | **NCP | New Master Configurations List** table should be updated SALESFORCE\_INSTANCE\_TYPE should be test and SALESFORCE\_INSTALLATION\_URL should be updated with test.salesforce.com |
| 2000: Error: The system is currently unable to process your request. | API usage limits reset every 24 hours. | If the limit has recently been exceeded, you may have to wait until it resets before making further requests. |
| Subsidiary creation failed with below error : Error: Failed to save Subsidiary in NetSuite. Details : ORCLBRTUPDATE\_NS\_SUBSIDIARY\_FAULT - You do not have permissions to set a value for element custrecord\_ncp\_sf\_url due to one of the following reasons: 1) The field is read-only; 2) An associated feature is disabled; 3) The field is available either when a record is created or updated, but not in both cases. | Latest ncp-salesforce SuiteApp not deployed in NS account. | Ensure that latest SuiteApp is installed in NetSuite. |
| CurrencyType is not supported error. | Multicurrency is not enabled in Salesforce. | Enable Multicurrency in Salesforce (Setup > Company information >Activate Multiple Currencies). |
| No valid, open, posting period. | No posting period for the date\`. | Set up accounting period on the date mentioned in the error to complete the item fulfillment sync. |
