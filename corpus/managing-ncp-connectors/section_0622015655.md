When you map Salesforce products to NetSuite items, the following columns are available:

-   Mapping Type
    
-   Source
    
-   Destination
    
-   Item Types
    
-   Action
    

Use the Item Types column to select one or more applicable item types for the selected destination field. During sync, the connector sends the source value only for the selected item types and skips item types that are not selected.

Important:

Default Product to Item mappings should map Product Name to Display Name and Product Code to Item Name/Number. Fields already mapped for all item types are hidden from later rows.
