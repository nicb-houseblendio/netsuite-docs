To test if the Salesforce Connector is working properly, you can create test product in Salesforce or in NetSuite.

After setting up Salesforce connector, you can configure mappings, define preferences, and modify mappings as needed. Use Manual Data Sync to post single records manually to verify that the records are synced properly.

The leading practice is to verify that records are syncing as expected before syncing historical data and enabling automated syncs.

1.  Create or modify a record in Salesforce or NetSuite.
    
2.  Manually post the updated record using [Manual Posting for Syncs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0604050453.html)
    
3.  Review the synced record.
    
4.  Repeat the test for each record type you want to sync.
    
5.  If you find fields that are not syncing the way you want, you may need to modify existing mappings or create a new mapping. To do so during initial implementation, contact your Professional Services representative. If you want to modify mappings after implementation, you need to contact Advanced Customer Support.
