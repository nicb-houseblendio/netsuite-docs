The available mappings of the selected sync are displayed on the Data Mappings table. Each row on the table is a data mapping. When in **Edit** mode, you can do the following:

-   Add or remove mappings - Click **Add Row** to create a new mapping. To remove mappings, go to the Action column of the row you want to delete, click the three-dots menu, then click **Remove**.
    
-   Update mappings - In the Action column, click the three-dots menu then click update to edit a mapping
    

## Mapping Levels {#subsect_0331055108}

Mappings can be header-level or line-item level. Use the **Mapping Level** filter to display only the mapping level you want to view or edit.

For the syncs where mapping level is applicable, see [Mapping Level](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0413094805.html#subsect_0413095921).

## Mapping Types {#subsect_0331055057}

Mappings can either be **Default** or **User-Added**. Default mappings can't be edited or deleted.

The following are the available mapping types:

-   Field-to-field - This is the commonly used mapping where a source field is mapped to a destination field.
    
-   Value-to-field - In this type of mapping, a fixed value from the source is assigned to the destination field.
    

Note:

Translation Mapping and Logic Mapping is currently not supported. If you need create mappings that use Translation or Logic type, contact NetSuite Customer Support.

## Source and Destination Fields {#subsect_0331070435}

For value-to-field mappings and field-to-field mappings, the source values and field types against destination field types can be any of the following:

| Destination Field Type | Supported Source Types |
| --- | --- |
| 
-   Decimal
-   String
-   Integer
-   Double
-   RecordRef

-   Double
-   String
-   Integer

-   RecordRef
-   Integer
-   String
-   Double

 | RecordRef |

The following table describes the expected value format for each field type.

| Field Type | Expected Source Value Format |
| --- | --- |
| Boolean | True/false. |
| Date | Date value. MM-DD-YYYY. |
| Date Time | Date and time value. MM-DD-YYYY HH:MM:SS. |
| Decimal | Numeric value. |
| Double | Numeric value up to 17 digits. |
| String | Text value. |
| RecordReference | Used to refer to record internal IDs. |

## Action Column {#subsect_0413043506}

You can access row-level actions for mappings on the vertical three-dots menu of the Action column.
