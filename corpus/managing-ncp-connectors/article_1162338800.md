The mappings of connector syncs in NetSuite Connector Platform can be viewed and managed on the Mappings screen.

By default, syncs added by the connector have some data mappings that are already available.

Default mappings can't be edited. If you need to modify a default mapping, you need to overwrite the default mapping. To do so, add a new mapping with the same destination field, then add the new source field.
