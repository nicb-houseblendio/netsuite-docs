This section contains common issues when managing mappings.

## Salesforce objects still not available after reloading fields {#subsect_0413031457}

This issue may be caused by permission issue for that specific field.

Refer to the following procedures to resolve this issue.

If you are using **System Administrator** role for Salesforce integration user:

1.  Ensure that the NetSuite Connector Platform ApiOnlyUser Permission set has Read and Edit access for that field in Salesforce.
    
2.  Reload the Salesforce fields. The field will be available in the fields that can be selected.
    

If you are using **Minimum Access API Only Integrations** for the Salesforce integration user:

1.  Edit the field in Salesforce object.
    
2.  Change the field level security to allow Read & Edit.
    
3.  Reload the Salesforce Fields. The field will be available in the fields that can be selected.
    

## Error when saving new or updated mapping rows {#subsect_0414024913}

There are instances where you can get a failed to save mappings error after trying to save a mapping multiple times.

When this occurs, remove the row from the page then add a new row again.
