A NetSuite item is synced to Salesforce whenever:

-   A new item is created or an existing item is updated in NetSuite.
    
-   A new Price Level is created or existing Price Level is updated in NetSuite. These changes will sync to the Salesforce Standard Price Book as a Salesforce Price Book Entry.

Important:

When syncing a NetSuite item to Salesforce, the connector checks if a product in Salesforce has a Product Code that matches with the NetSuite ItemID and expected Item Type. If found, the Salesforce product is updated. If no product is found, a new product is created in Salesforce for the NetSuite item.

By default, NetSuite items are synced immediately to Salesforce when created or updated. You can choose from the following Item to Salesforce Product sync triggers:

-   Sync immediately when the item is created (default)
    
-   Sync when the Salesforce Flag to Post field is selected on each item
    
-   Sync when a specific item field meets a defined criterion
    
    When you select this sync trigger, you can select the item type where the sync trigger applies. The defined criteria only applies to the selected item types.
    
    It is important to note that the Item Type selected only applies when the selected trigger condition is **Sync when a specific Item field meets a defined criterion**. For trigger options, **Sync immediately when the item is created** and **Sync when the Salesforce Flag to Post is selected on each Item**, the sync applies to all item types.
    
    For example, if you select Item Types, Inventory Item and Non Inventory Item, then the criteria you define will only apply to Inventory Items and Non Inventory Items.
    

For more information about configuring sync triggers, see [Salesforce Connector Sync Triggers](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1118052320.html).
