Salesforce Connector provides configurable sync triggers for syncs in Connector Platform > Settings > Preferences. You can use this to configure the sync condition based on which record or object to best fit your business need.

The sync triggers for the specific syncs are in the corresponding tabs on the Preferences screen.

| Preferences Tab | Sync Trigger Configuration |
| --- | --- |
| Entities Tab | 
-   Account sync
-   Subsidiary sync
-   Item sync
-   Product Sync

 |
| Financials Tab | 

-   Invoice Sync
-   Cash Sale Sync
-   Customer Payment Sync

 |

The following sync triggers are available for Salesforce Connector syncs.

| Sync | Available Sync Trigger Options |
| --- | --- |
| NetSuite Subsidiary to Salesforce Subsidiary Sync | 
-   Sync on record creation
-   [Sync Triggers with Defined Criteria](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0220112437.html)
-   Sync when [NetSuite: Salesforce Flag to Post Field](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0220112357.html) is set

 |
| NetSuite Item to Salesforce Product | 

-   Sync on record creation
-   [Sync Triggers with Defined Criteria](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0220112437.html)
-   Sync when [NetSuite: Salesforce Flag to Post Field](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0220112357.html) is set

Note: The Item Type selected only applies when the selected trigger condition is **Sync when a specific Item field meets a defined criterion**. For trigger options, **Sync immediately when the item is created** and **Sync when the Salesforce Flag to Post is selected on each Item**, the sync applies to all item types. |
| Salesforce Product to NetSuite Item | 

-   Sync on record creation
-   [Sync Triggers with Defined Criteria](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0220112437.html)

 |
| Salesforce Opportunity to NetSuite Sales Order | 

-   Sync on record creation
-   [Sync Triggers with Defined Criteria](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0220112437.html) Note: If you want to apply the selected sync trigger to record updates, you need to check the **Apply rules for record update scenarios** box.
-   Sync when [NetSuite: Salesforce Flag to Post Field](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0220112357.html) is set

 |
| NetSuite Sales Order to Salesforce Order | 

-   Sync on record creation
-   [Sync Triggers with Defined Criteria](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0220112437.html)

 |
| NetSuite Invoice to Salesforce Financial Record | 

-   Sync on record creation
-   [Sync Triggers with Defined Criteria](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0220112437.html)
-   Sync when [NetSuite: Salesforce Flag to Post Field](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0220112357.html) is set

 |
| NetSuite Payment to Salesforce Financial Record | 

-   Sync on record creation
-   [Sync Triggers with Defined Criteria](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0220112437.html)
-   Sync when [NetSuite: Salesforce Flag to Post Field](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0220112357.html) is set

 |
| NetSuite Cash Sale to Salesforce Financial Record | 

-   Sync on record creation
-   [Sync Triggers with Defined Criteria](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0220112437.html)
-   Sync when [NetSuite: Salesforce Flag to Post Field](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0220112357.html) is set

 |
| Salesforce Account to NetSuite Customer | 

-   Sync Account when syncing Opportunity (default)
-   Sync immediately when the Account is created or updated
-   [Sync Triggers with Defined Criteria](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0220112437.html)

 |
