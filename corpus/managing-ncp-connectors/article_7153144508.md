After installing the NetSuite Connector Platform SuiteApp and the Salesforce Connector SuiteApp, you need to set up Salesforce Connector to ensure connectivity between Salesforce and NetSuite. The Salesforce Connector Setup Wizard will guide you through the following steps.

-   Import Connector
    
-   Create Connection
    
-   Setup Environment
    
-   Deploy Package
    
-   Activate Integrations
    

You need an Administrator role to run the steps in the Salesforce Connector Setup Wizard. The leading practice is to finish the setup wizard in one go. If you leave the setup wizard midway, you can resume where you left off from the Pending Connector Setup portlet in the NetSuite Connector Platform dashboard.

To launch the Salesforce Connector Setup Wizard, go to the NetSuite Connector Platform dashboard then click the Setup link in the Connector Overview portlet. When the Setup Wizard launches, follow the onscreen instructions to complete the setup.

Follow the setup wizard steps to set up Salesforce Connector.

1.  [Salesforce Connector Setup Wizard: Import Connector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0330033413.html)
    
2.  [Salesforce Connector Setup Wizard: Create Connection](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0330035111.html)
    
3.  [Salesforce Connector Setup Wizard: Setup Environment](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0330062041.html)
    
4.  [Salesforce Connector Setup Wizard: Deploy Package](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0330062249.html)
    
5.  [Salesforce Connector Setup Wizard: Activate Integrations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0330064911.html)
    

When you complete the setup wizard, proceed with [Salesforce Connector Setup Wizard: Next Steps](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1190649543.html).
