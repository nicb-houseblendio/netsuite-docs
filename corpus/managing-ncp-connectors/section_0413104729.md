There are two save actions on the mappings screen. When you create a new row, you need to click **Save** from the Action column of the new row. When you do this row-level save, the mapping is processed and submitted immediately.

After completing all mappings for a sync, you need to do a page-level save so that you can exit Edit mode. To do so, click **Save** on the Data Mappings screen.

You can only resume the sync after doing a page-level save.

After making modifications to mappings, you should test the added mappings by posting a record. You can then go to the Data Flows page to activate real-time sync.
