Important:

Before deploying the package, you need to ensure that the multiple currencies feature is enabled in both NetSuite and Salesforce accounts as listed in _Verify Required Salesforce Feature is Enabled_

-   In NetSuite, enable **Multiple Currencies** under International in Company subtab.
    
-   In Salesforce, enable **Multi-Currency Everywhere (MCE)**.
    

This step deploys the Salesforce Connector packages.

When you click **Deploy Salesforce Package**, you are redirected to the NetSuite Connector Platform Managed Package installation page in Salesforce in a new tab. You need to log in to your Salesforce account with administrator access and then install the NetSuite Connector Platform Salesforce managed package. Choose the installation option, **for all users in the account**.

Follow the instructions in the popup window to install the Salesforce managed package.

Note:

If the installation takes more time than expected, you will be notified on the Salesforce page that you would receive an email confirmation upon completion.

After you receive the confirmation email, go back to the Setup Wizard page in NetSuite and click **Refresh** to update the package installation status.

The setup wizard doesn't automatically update and display a success message when the process completes. After the Salesforce managed package is installed, you need to go back to the Salesforce Connector Setup Wizard. On the Deploy Packages step, click **Refresh** until you get the success message.

When you get the success message, you can proceed to the next step of the setup wizard, [Salesforce Connector Setup Wizard: Activate Integrations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0330064911.html).

Setting up the integration user requires permissions installed by the managed package in this step. Common errors related to the managed package are failures in updating integration host, remote site settings, or fetching Salesforce domain name. If you are doing an upgrade or if you need to deploy the Salesforce Managed Package, go to Connector Platform > Overview > Quick Links then click **Install Salesforce Package** in NetSuite.
