The Oracle NetSuite Connector Platform SuiteApp handles the smart data sync between NetSuite and other marketplace or Customer Relationship Management (CRM) platforms.

To use the Salesforce Connector, the edition of your Salesforce account must support API access. The following editions of Salesforce support API access:

-   Enterprise Edition
    
-   Developer Edition
    
-   Professional Edition (with API license)
    
-   Professional Edition (without API license)
    

Note:

The Professional edition of Salesforce does not have API access by default. If you use Salesforce Professional Edition and have already purchased API license, select the Professional Edition with API license option in the Create Connection step of the Salesforce Connector Setup Wizard. If you use Salesforce Professional edition and do not have the API license, select the Professional without API license edition.

For more information, refer to [Salesforce editions with API access](https://help.salesforce.com/s/articleView?id=000385436&type=1) (Knowledge Article Number 000385436) in the online Salesforce documentation.

Before you can use the Salesforce Connector, you must complete the all of the setup tasks.

-   Ensure that required features are enabled and preferences defined in NetSuite and in Salesforce. See [Verify That Required Features are Enabled](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0602041157.html).
    
-   The NetSuite Connector Platform SuiteApp can be installed in your NetSuite production account or in your NetSuite sandbox account. For more information, see [Install the NetSuite Connector Platform SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_4155442648.html#subsect_0603013852).
    
-   Add an integration user in your Salesforce account. For more information, see _Create an Integration User in Salesforce_.
    
-   Create a Salesforce Connected App.
    
    Note:
    
    Users with Salesforce Professional Edition do not need to create a Salesforce Connected App. A different process is used to connect to Salesforce for users using this edition.
    
-   Begin the one-time tasks of setting up the portlets on NetSuite Connector Platform dashboard. See [Set Up Dashboard Portlets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_4155442648.html#subsect_0603013926).
    
    Note:
    
    Only a user who is logged in to NetSuite in an Administrator role can view and access the Connector Platform tab.
    
-   The UI will guide you through the steps outlined in _Set Up the Salesforce Connector_ to finish setting up the Salesforce Connector.
    
    Note:
    
    Before you can set up the connection between NetSuite and Salesforce, you should have already created an integration user in your Salesforce account. This integration user is specifically for the data exchange by the Salesforce Connector. The integration user cannot log in to the Salesforce UI, preventing potential misuse.
    
    When the setup is complete, you will be redirected to the Manage Lookups page. Configure lookups and preferences. For information about configuring lookups, see the Configure Lookups topic in the user guide.
    
-   Configure your page layouts in Salesforce.
    
-   Assign the permission sets to your integration user.
    
-   Sync existing item data from NetSuite to Salesforce. See [Load Historical Data](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0602043250.html) for more information.
    

Note:

All NetSuite accounts using Salesforce Connector must be OneWorld accounts that have at least one subsidiary. Salesforce Connector supports Legacy Tax and SuiteTax NetSuite accounts.
