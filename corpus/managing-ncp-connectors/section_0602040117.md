Sales people can continue to work in Salesforce, and this information is synced with financial and inventory data in NetSuite. The Salesforce Connector ensures that both applications have the same information.

<a id="svg_1"></a>

                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 

To use the Salesforce Connector, all installation and setup tasks must be complete. For example, the SuiteApp must be installed. An API-only user should have been created in Salesforce so that the connection between Salesforce and NetSuite could be configured. The Salesforce Connectors custom portlets must be set up. For more information about these tasks and more, see [Salesforce Connector Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_2155722791.html).

Only a user who is logged in to NetSuite in an Administrator role can view and access the Connector Platform tab.
