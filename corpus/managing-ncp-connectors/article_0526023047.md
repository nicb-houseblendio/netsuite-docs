A Salesforce order is an agreement between a company and a customer to provide services or deliver products with a known quantity, price, and date.

A NetSuite sales order (SO) is an order for goods and services issued by a business to a customer. The NetSuite SO specifies the details about products and services ordered by a specific customer. The SO includes the price, the quantity and the terms and conditions surrounding the order. Businesses send the SO to customers as a confirmation document before delivering goods or services.

An SO created in NetSuite can subsequently be fulfilled. When an SO is fulfilled, invoicing and revenue recognition can occur. The creation of a sales order in NetSuite is the initial step in the revenue recognition process. It is important that the Sales Order is created at the time that the deal is closed. If the creation of a sales order in NetSuite required an extra manual step, it could delay the deal (and the revenue recognition).

## About the Sales Order to Order Sync {#subsect_0717010116}

The NetSuite sales order to Salesforce order sync sends updates made to sales order records in NetSuite to order records in Salesforce, ensuring that the same information in NetSuite is automatically available in Salesforce.

<a id="svg_1"></a>

                                                                                                                                                                                                     

The Sales Order to Order sync is triggered when a NetSuite sales order exists, created by a Salesforce Closed Won Opportunity. The sync is triggered when the existing sales order in NetSuite is updated. The NetSuite sales order must have a valid Opportunity ID so that it syncs to Salesforce.

A sales order attachment will be attached to the order object in Salesforce.

Note:

No NetSuite or Salesforce activities are blocked by Salesforce Connector syncs.

## Sales Order to Order Field Mapping {#subsect_0717010208}

The following table shows the mapping between NetSuite sales order fields and Salesforce order fields to ensure that identical data is maintained in both applications.

| NetSuite Sales Order Fields | Salesforce Order Fields |
| --- | --- |
| BillingAddress city | BillingCity |
| BillingAddress country | BillingCountry |
| BillingAddress street | BillingStreet |
| BillingAddress zip | BillingPostalCode |
| BillingAddress state | BillingState |
| custentity\_oracle\_salesforce\_account\_id | AccountId |
| End Date | End Date |
| Order Date | Effective Date |
| Order Number | Oracle\_NetSuite\_Order\_Number\_c |
| Sales Order ID | Oracle\_NetSuite\_ID\_c |
| SalesForce Account ID | Account ID |
| ShippingAddress city | ShippingCity |
| ShippingAddress country | ShippingCountry |
| ShippingAddress state | ShippingState |
| ShippingAddress street | ShippingStreet |
| ShippingAddress zip | ShippingPostalCode |
| Status Code | Oracle\_NetSuite\_Order\_Statuc\_c |
