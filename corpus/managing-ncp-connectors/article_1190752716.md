Before you run the Salesforce Connector Setup Wizard, you need to have an integration user in Salesforce and a Connected App.

When creating the connection, you need to enter the credentials of the integration user in Salesforce. You need the user name, password, and integration token of your Salesforce user.

If you are not using Salesforce Professional edition, you will also need the consumer key, and consumer secret of your Salesforce Connected App.
