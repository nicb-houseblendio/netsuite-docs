Network performance is measured as the time it takes for data to travel from a server at NetSuite to your computer. Some pages in NetSuite may take longer to load than others.

The following issues are symptoms of network performance problems:

-   A form, such as a customer record or transaction, takes a long time to load.
    
-   A report takes a long time to display data on the page.
    

Use the Performance Details window to see if network time contributes a large amount of the total time to load a slow page. For more information, see [Gathering Performance Details](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_48151513026.html).

NetSuite uses a Content Delivery Network (CDN) in its global distribution network to improve page load times in the NetSuite UI. All application domains are powered by a CDN (`https://<accountID>.app.netsuite.com`).
