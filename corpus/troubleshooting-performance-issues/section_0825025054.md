Performance issue could be caused by the browser you're using. Use the following steps to verify whether this is the case.

#### To verify whether a performance issue is caused by the browser: {#procedure_0824032201}

1.  Check the browser version.
    
    -   Verify that the browser version is supported by NetSuite. For more information, see [Supported Browsers for NetSuite](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N340018.html).
        
    -   Ensure that you're using the latest version of the browser.
        
    -   Don't use trial, development, or early adoption browser versions.
        
2.  Check if the problem happens with other supported browsers.
