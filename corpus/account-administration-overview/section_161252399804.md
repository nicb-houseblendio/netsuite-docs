Regularly check NetSuite to keep your system healthy.

| Task | More Information |
| --- | --- |
| Make sure your account data is accurate and monitor changes made to NetSuite data by running regular data audits. | [Auditing Data Changes using Searches](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4774167775.html) |
| Resolve data integrity issues. | [Avoiding Duplicates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4470654298.html) |
| Review the Login Audit Trail regularly to see if any unauthorized people are trying to access the system. | [Login Audit Trail Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N324233.html) |
| Audit roles and permissions with saved searches. | [Use Searches to Audit Roles and Permissions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4460505281.html) |
| Track SuiteScript usage with saved searches. | [Defining a Saved Search](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N676039.html) |
| Monitor and optimize NetSuite performance. | [Optimizing NetSuite Performance](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N571805.html) |
