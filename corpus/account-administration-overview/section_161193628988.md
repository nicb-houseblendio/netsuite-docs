Prepare your organization for the two major NetSuite releases each year.

## Resources {#subsect_0811063027}

| Task | More Information |
| --- | --- |
| Review the release notes and monitor the New Release portlet on your dashboard. | [Release Notes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/book_N3865324.html) [Release Preview Guide](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/book_4019907166.html) |
| Find the latest release news and training. | [SuiteAnswers Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N337088.html) [SuiteAnswers Home](https://suiteanswers.custhelp.com/app/home) [Overview of Release Preview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4471776042.html) |
| Develop tests, functional testing, and rollout of application releases. | [Release Preview Guide](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/preface_4019941373.html) |
| Log in to your Release Preview account several weeks before your upgrade date to prepare, preview, and manage your release upgrade. Use Release Preview to test new features with your data and business processes and identify any issues before you upgrade. | [Release Preview Guide](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/book_4019907166.html) |
| Notify users of the release by sending a service release notification | [Setting Administrative Notification Options](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1126101845.html) |
| Report any issues you find during testing from your Release Preview account. | [How to Report Release Preview Issues](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4013029002.html) |
