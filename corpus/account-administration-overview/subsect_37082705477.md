Users with the Administrator role receive email reminders about maintenance. The following table describes each status.

| Status | Description |
| --- | --- |
| Scheduled | Important maintenance must be performed on your account. The maintenance is scheduled for a date and time that should cause the least disruption, but you can reschedule if necessary. |
| Rescheduled | Maintenance was rescheduled for one of the following reasons:
-   An administrator chose a different date and time for the maintenance.
-   Oracle NetSuite had to move the maintenance because it conflicted with other important work on your account.

 |
| Cancelled | Maintenance was canceled because of an internal issue. It will be rescheduled when the issue is resolved. OR Oracle NetSuite approved an exception requested by your administrator to cancel the maintenance. The maintenance will be rescheduled for a future date. |
| Rolled Back | Some tasks couldn't be completed during the maintenance, so all changes were reversed and is back to how it was before the maintenance began. No data was lost. You can continue using your account, and the maintenance will be rescheduled. |
| Extended | The maintenance is taking longer than expected to complete. You'll get a notification when it's done. |
| Completed | Maintenance finished successfully. |
