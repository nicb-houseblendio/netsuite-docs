Administrators are the main contact for users and provide ongoing technical and system support. Administrators help users with the tasks listed in the following table.

| Task | More Information |
| --- | --- |
| Main contact for end users, and give them when they have questions about NetSuite. | [Getting Help](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N336026.html) |
| Make sure users adopt the system are happy by offering training and support. | [SuiteAnswers Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N337088.html) [SuiteAnswers](https://netsuite.custhelp.com/app/home) [Getting Help](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N336026.html) |
| Help users pull data using searches and reports. Use business intelligence tools to help you and your users get the most from your data. | [Saved Searches](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N675442.html) [Reporting Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N698474.html) [Dashboards Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N576403.html) [Key Performance Indicators](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N595760.html) [SuiteAnalytics Workbook Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1503949328.html) [Connect](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/book_N748613.html) |
| Regularly check logs for undelivered email messages. | [Troubleshoot Undelivered Email](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510053052.html) |
| Reset user passwords when asked. | [User Access Reset Tool](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156442554498.html) |
| Work with NetSuite Customer Support to fix issues. When you contact support, make sure you know your account ID. | [NetSuite Support](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N337569.html) [Finding Your NetSuite Account ID](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1498754928.html) |
