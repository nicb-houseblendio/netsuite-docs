Users with the Administrator role oversee the initial implementation of the NetSuite application, working with the NetSuite team. Implementation tasks include:

-   [Account Setup](#bridgehead_4573923767)
    
-   [Security and Authentication Setup](#bridgehead_4573901775)
    
-   [Users, Roles, and Permissions Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_157590081585.html)
    
-   [System Integrations Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_157590669212.html)
    
-   [Data Migrations Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4573903549.html)
    
-   [Customizations Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4573918016.html)
    
-   [Sandbox Management](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4573924948.html)
    

## Account Setup {#bridgehead_4573923767}

Setup tasks for your NetSuite account are described in the following table.

| Task | More Information |
| --- | --- |
| Create a login page that shows your company's branding on the NetSuite account login page. | [Displaying Login Fields on Your Web Page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2577156.html) |
| Make sure that your NetSuite account and integrations don't contain data center-specific identifiers. | [Best Practices for Cloud Accounts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4607562099.html) |
| Decide what customizations your organization needs based on your business. | [SuiteCloud Platform Customization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1529088392.html) |
| Make sure your global subscription status follows the regulations in the email recipient's jurisdiction. The email opt-in status in the **Global Subscription Status** field shows if customers can get email messages from your campaigns and email merges. | [Subscription Management](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N994827.html) |

## Security and Authentication Setup {#bridgehead_4573901775}

NetSuite administrators determine how users and client applications access NetSuite.

| Task | More Information |
| --- | --- |
| Set a strong password policy for users who access your account. | [Password Settings That Can Be Modified](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1534873888.html) |
| Set the right password requirements for your organization. | [Password Requirements and Policies in NetSuite](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4713604654.html) |
| Set up two-factor authentication for users who handle confidential data. | [Two-Factor Authentication (2FA)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N327688.html) |
| Set up token-based authentication so client applications can access NetSuite through APIs. | [Token-based Authentication (TBA)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4247329078.html) |
| Select and set up the right single sign-on option for your organization. | [Authentication Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4369651411.html) |
