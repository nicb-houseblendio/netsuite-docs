Employees, vendors, partners, and customers might need access to your NetSuite account. Create custom roles for your organization and add the right permissions and restrictions.

| Task | More Information |
| --- | --- |
| Give employees only the access they need. | [NetSuite Access Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N285060.html) |
| Don't assign standard roles to users. Customize standard roles and assign them instead. Create roles for each job function. Assign more than one role if someone has multiple jobs. | [Showing Role Permission Differences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N292157.html) [Customizing or Creating NetSuite Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N285937.html) |
| Think carefully about the permissions for each role and use restrictions when you need more control. | [Permissions and Restrictions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3781107123.html) |
| Don't use the Full Access role. | [Full Access Role (Deprecated)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557254595.html) |
| Assign Core Administration Permissions to roles when needed. | [Core Administration Permissions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1540845284.html) |
| Don't use the Global Permissions Feature unless you have to. Whenever you can, use permissions and restrictions instead. Note: Global permissions apply to every role an employee has. | [Using the Global Permissions Feature](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N326630.html) |
| Set preferences to tailor NetSuite to each role if needed. | [Setting Role-Based Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N292753.html) |
| Assign the Financial History permission to any role that needs access to customer or vendor transactions. | [Granting User Access to Transaction History](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N555081.html) |
| Make sure you know how the Advanced Employee Permissions feature changes access to employee records. | [Before Enabling the Advanced Employee Permissions Feature](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1519678048.html) |
| Assign each role to yourself and test it. Make sure is has all permissions and access needed for the whole process. | [Permissions Documentation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N326485.html) |
| Assign custom roles to users before they start using the account. | [Assigning Roles to an Employee](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N897798.html) |
| Create user records. | [NetSuite Users Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N321756.html) [Working with Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N488213.html) |
| Give new users access. | [Giving an Employee Access to NetSuite](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N896195.html) [Giving Customers Access](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N322750.html) |
| Make sure users know how to get help. | [Tips for Help Center and SuiteAnswers](https://videohub.oracle.com/media/Tips+for+Help+Center+and+SuiteAnswers/1_fvclicbh) [Getting Help](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N336026.html) |
| Remove employees' NetSuite access right away when they leave. | [Employee Termination](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3753809772.html) |
