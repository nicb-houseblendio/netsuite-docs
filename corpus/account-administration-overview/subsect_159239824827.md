The following table describes the maintenances that you can reschedule. More will be available in the future.

| Maintenance | Description | Supported Account Type | More Information |
| --- | --- | --- | --- |
| Routine Maintenance | Bug fixes and minor enhancements to improve your NetSuite experience. | Production | [Customer-Scheduled Maintenance FAQ](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159188207648.html) |
| NetSuite Pre-Upgrade Maintenance | Pre-upgrade preparation work for the new features in the NetSuite Version Upgrade | Production Sandbox | [NetSuite Pre-Upgrade Maintenance](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1120120751.html) |
| NetSuite Version Upgrade Maintenance | Add new features and improvements to NetSuite. | Production Sandbox | [NetSuite Version Upgrade Maintenance](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1120120832.html) For more information, read the [Release Notes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/book_N3865324.html). |
