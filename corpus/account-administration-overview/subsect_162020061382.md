In the Auditing and Data Management Guide, you'll find information about tracking changes in NetSuite, internal controls, managing transactions, removing personal information, auditing data changes with searches, and avoiding duplicates.

| **Tracking Changes in NetSuite** | Lean about auditing primary data and configuration changes in NetSuite, auditing account preferences, documenting changes, and enabling audits. For more information, see [Tracking Changes in NetSuite](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4604099319.html). |
| --- | --- |
| **Internal Controls in NetSuite** | Lists internal controls that are readily available in NetSuite. Use this list a reference to help you build strong internal controls in your NetSuite setup. Find out more about standard internal controls and internal controls that require basic configuration, see [Internal Controls in NetSuite](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4750134868.html). |
| **Managing Transactions** | NetSuite has features that let you record reasons for deleting transactions and view transaction history. For more information, see [Managing Transactions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4470653255.html) |
| **Personal Information (PI) Removal** | Lets NetSuite users with the appropriate permissions to remove personal information from fields, records, and audit logs. To find out how to address privacy regulations related to data subject requests, see [Personal Information (PI) Removal](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_156596387080.html). |
| **Auditing Data Changes using Searches** | To track changes in NetSuite data, search system notes records. Learn how to search system notes, view audit trails for record types, search for deleted records, and understand the context for changes. See [Auditing Data Changes using Searches](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4774167775.html). |
| **Avoiding Duplicates** | Avoid unintended duplicate entries in NetSuite. You can avoid duplicate transaction numbers, handle duplicate transaction number warnings, and use auto-generated numbering for transactions. You can also prevent duplicate processing of memorized transactions during bulk updates. For more information, see [Avoiding Duplicates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4470654298.html). |
