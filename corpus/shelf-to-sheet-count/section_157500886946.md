The Shelf-to-Sheet Template enables you to create and organize virtual representations of your storage areas, shelves and items at a specific location. When you create a first template for a subsidiary and location, a Count Sheet Template Folder is automatically created in the File Cabinet. The folder stores templates and data about them, including subsidiary and location internal IDs. A particular subsidiary and location combination can only have one template.

#### To create and set up the Shelf-to-Sheet Template:

1.  Go to Setup > Restaurant > Shelf-to-Sheet Template > New.
    
    If you're using a BOH Manager or General Manager role, go to Setup > Other Setup > Shelf-to-Sheet Template > New.
    
2.  On the Shelf-to-Sheet Template page, in the **Subsidiary** field, select a subsidiary.
    
3.  In the **Location** field, select a location.
    
    Note:
    
    A subsidiary and location combination can only have one template.
    
4.  Click the **Template View** subtab and do the following:
    
    1.  Add storage areas:
        
        1.  Click **Add Storage**.
            
        2.  On the Add Storage popup box, in the **Storage Area Name** field, enter a name for the storage area.
            
        3.  (Optional) In the **Description** field, enter text describing the storage area.
            
        4.  Click **Save**. Repeat the steps to add more storage areas as necessary.
            
    2.  Add shelves:
        
        1.  Click the storage area where the shelf you must add should be located, and then click **Add Shelf**.
            
        2.  On the Add Shelf popup box, in the **Shelf Name** field, enter a name for the shelf.
            
        3.  (Optional) In the **Description** field, enter text describing the shelf.
            
        4.  Click **Save**. Repeat the steps to add more shelves as necessary.
            
    3.  Add items:
        
        Note:
        
        Before you add items, ensure that you already have records of inventory items, assembly items or kits/packages. You can create them from Lists > Accounting > Items > New.
        
        1.  Click the shelf where the item you must add should be located, and then click **Add Item**.
            
        2.  On the Add Items popup box, in the **Items** dropdown field, select an item from the list. The list displays the item records with the same location and subsidiary specified in the template.
            
            Note:
            
            You can't add similar items in the same shelf.
            
        3.  Click **Save**. Repeat the steps to add more items as necessary.
            
            Note:
            
            You can add up to 1000 items in total.
            
            Be careful when adding kits, because if a kit is disassembled, the number of unique items in the Shelf-to-Sheet Template will increase as each component item in the kit will be counted. Ensure that the total inventory items in the Shelf-to-Sheet Count doesn't exceed 3000, if kits are included in the Shelf-to-Sheet Template.
            
            Note:
            
            If you later change items that are already in the Shelf-to-Sheet template, to Bin, Lot Numbered, and Serialized items, or make them inactive, you'll get errors in the count. In this case, you should exclude Bin/Lot/Serial and inactive items by recreating the Shelf-to-Sheet Count record.
            
            Note:
            
            Changes to the stock unit of items that are already added to a Shelf-to-Sheet Template are not automatically updated on the template. If a stock unit of an item changed, you manually select that item again, with a new stock unit, on the Shelf-to-Sheet Template where it was previously added. All item entries on the Inventory Count record must use similar units defined in the Shelf-to-Sheet Count record.
            
    4.  (Optional) To move an item to another shelf, click the item and drag it under the shelf you want to move it to.
        
        Note:
        
        You can't move an item to a shelf that already contains that same item.
        
    5.  (Optional) Edit storage areas and shelves:
        
        1.  Double-click the storage area or shelf that you want to edit.
            
        2.  On the Edit popup box, make the necessary changes to the name or description.
            
        3.  Click **Save**.
            
            Note:
            
            You can't edit items on the template because they are associated with an inventory item record. You can only delete and select items again.
            
    6.  (Optional) Delete storage areas, shelves or items:
        
        1.  Click the storage area, shelf or item you want to delete, and click its corresponding **Delete** button.
            
        2.  On the confirmation message that appears, click **Delete**.
            
5.  On the Shelf-to-Sheet Template page, click **Save**.
    

When the Shelf-to-Sheet Template is used or referenced by a Shelf-to-Sheet Count record, the items set up in the template will be displayed on the Shelf-to-Sheet View subtab of the Shelf-to-Sheet Count record. It's the quantity of those items you will enter when Start Count is clicked on the Shelf-to-Sheet Count record.
