The following are the limitations of the Shelf-to-Sheet Count SuiteApp:

-   The Shelf-to-Sheet Template can support or contain up to 1000 items in total. The SuiteApp can reference up to 15000 items per account.
    
    Be careful in adding kits, because if a kit is disassembled, the number of unique items in the Shelf-to-Sheet Count will increase as each component item in the kit will be counted. Ensure that the total inventory items in the Shelf-to-Sheet Count doesn't exceed 3000, if kits are included in the Shelf-to-Sheet Template.
    
-   Bin, Lot Numbered, and Serialized inventory item types are not supported by Shelf-to-Sheet Count SuiteApp.
    
    Items already included in the Shelf-to-Sheet template or count, but later you changed to Bin items or made them inactive, will cause errors. In this case, do the following:
    
    -   For bin items, edit the record and on the Purchasing/Inventory subtab, clear the Use Bins box. For inactive items, edit the record and clear the Inactive box. Then, you can add the items back when you recreate the Shelf-to-Sheet template.
        
    -   Recreate the Shelf-to-Sheet Count record.
        
    
    Likewise, kits that contain bin items should not be included in the template and count.
    
-   Don't directly edit the Inventory Count record that is automatically generated when a Shelf-to-Sheet Count record is created. That Inventory Count record can only be updated by editing or changing the Shelf-to-Sheet Count record associated with it.
    
-   After you enter item quantities or memo details in the Shelf-to-Sheet View subtab of the Shelf-to-Sheet Count record, click outside the table before you click Save. If you click Save while the cursor is still in the table, the record is not saved completely.
    
-   Changes to the stock unit of items that are already added to a Shelf-to-Sheet Template are not automatically updated on the template. If you want the new stock unit of an item to be reflected on the template, you need to manually select that item again, with a new stock unit, on the Shelf-to-Sheet Template where it was previously added. All item entries on the Inventory Count record must use similar units defined in the Shelf-to-Sheet Count record.
    
-   When you create a Shelf-to-Sheet Count record, the corresponding Inventory Count record generated will not contain multiple entries of similar items. In addition, upon completion of Shelf-to-Sheet Count record, the final count of items must be the sum of the counts of ingredients or kit member items entered on the Shelf-to-Sheet Count record.
    
-   On the search results page of Shelf-to-Sheet Template, the Show Inactives box is always displayed and checked. Don't inactivate any Shelf-to-Sheet template because it's not supported and may cause issues.
