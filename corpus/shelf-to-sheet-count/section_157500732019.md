If you're using the Restaurants & Hospitality (R & H) edition or an R & H account, it's pre-configured with R & H Customization and include R & H roles.

You must customize the following R & H roles that are included in the R & H Customization Bundle:

-   **R & H - BOH Manager** and **FOH Manager** - can create templates and perform item count on the Shelf-to-Sheet Count record
    
-   **R & H - General Manager** can approve or reject the Shelf-to-Sheet Count record
    

You must customize both roles to grant them the following permissions for creating Shelf-to-Sheet Templates and Count records.

| Action or Workflow | Permission |
| --- | --- |
| Transactions > Find Transactions | Full |
| Transactions > Adjust Inventory | Full |
| Transactions > Count Inventory | Full |
| Transactions > Create Inventory Counts | Full |
| Transactions > Shelf To Sheet Count | Edit |
| Reports > SuiteAnalytics Workbook | Edit |
| Lists > Accounts | View |
| Lists > Departments | View |
| Lists > Documents and Files | Full |
| Lists > Items | View |
| Lists > Locations | View |
| Lists > Notes Tab | View |
| Lists > Perform Search | Full |
| Lists > Subsidiaries | View |
| Lists > Units | View |
| Setup > Deleted Records | Optional If you want the role to be able to delete the custom records, Shelf to Sheet Template and Shelf to Sheet Count, you can grant full permission. |
| Setup > SuiteScript | Optional If you want the role to be able to view script execution logs, you can grant view permission. |
| Custom Record > Shelf-to-Sheet Template | Edit |
| Custom Record > Shelf-to-Sheet Count Item | Edit |
| Custom Record > customrecord\_s2s\_elk\_config | Edit |

For more information on roles and permissions, see [Setting Permissions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N288727.html) under [Customizing or Creating NetSuite Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N285937.html).

To create a Shelf-to-Sheet Template or Count record, the BOH Manager, FOH Manager or General Manager that were granted the required permissions, need to access Setup > Other Setup > Shelf-to-Sheet Template or Shelf-to-Sheet Count > New. This task path is different from the way other authorized roles can access template and Shelf-to-Sheet Count record creation.

After granting permissions to the BOH Manager, FOH Manager and General Manager roles, they will be able to trigger generation of the Actual vs. Theoretical variance reports, which they can also view. For more information, see [Granting Roles Access to Variance Reports and Related Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159100286819.html).
