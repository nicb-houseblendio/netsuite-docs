As of **June 15, 2026**, ODBC driver versions 9.0.32.0 for Windows and 8.10.190.0 for Linux are available for download. These driver versions include important security fixes. We strongly recommend that you upgrade your ODBC drivers to these versions.

Note:

If you are using JDBC or ADO.NET drivers, no action is required.

To download the latest driver version, log in to NetSuite. In the Settings portlet on the Home page, click **Set Up SuiteAnalytics Connect**. For information about upgrading to the latest driver, see the following help articles:

-   [Downloading and Installing the ODBC Driver for Windows](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3963853203.html)
    
-   [Downloading and Installing the ODBC Driver for Linux](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4042973030.html)
    

For information about the latest driver version, see [ODBC Drivers](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1201032531.html).
