Whether you want to use an ODBC, JDBC, or ADO.NET driver to access the Connect Service, you must first enable the SuiteAnalytics Connect feature.

Important:

Ensure that you have the latest driver version installed and the required connection attributes. You must also update your NetSuite connections to use certificate-based server authentication and provide the NetSuite Account ID and Role ID on every connection. For information about the latest driver versions available, see [Required Update of SuiteAnalytics Connect Drivers](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_164500699628.html).

For more information about upgrading the SuiteAnalytics Connect driver, see [Upgrading an ODBC Driver](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3963860724.html).

For information about setting up certificate-based server authentication, see the following topics:

-   ODBC driver, see [Authentication Using Server Certificates for ODBC](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4041410260.html).
    
-   JDBC driver, see [Authentication Using Server Certificates for JDBC](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4353052057.html).
    
-   ADO.NET driver, see [Authentication Using Server Certificates for ADO.NET](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4170071356.html).
    

For information about setting up connections to provide NetSuite Account ID and Role ID, see the following topics:

-   ODBC driver, see [Connection Attributes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4406013158.html).
    
-   JDBC driver, see [JDBC Connection Properties](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4425626714.html).
    
-   ADO.NET driver, see [ADO.NET Connection Options](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4437990943.html).
    

#### To enable the Connect Service feature:

1.  Ensure that your Account Administrator has enabled your Account and Role with the Connect Service feature.
    
2.  Go to _Setup > Company > Enable Features_.
    
3.  Click the **Analytics** subtab.
    
4.  Check the **SuiteAnalytics Connect** box.
    
    Note:
    
    If you don't see this feature, it has not been provisioned for your account. Contact NetSuite Customer Support or your Account Manager for assistance.
