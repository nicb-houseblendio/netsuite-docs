In addition to standard and custom NetSuite tables, SuiteAnalytics Connect includes the following system tables:

-   **[oa\_tables](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4410183661.html)** - This table lists all available tables, including custom lists and custom records.
    
-   **[oa\_columns](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4410183892.html)** - This table lists all available columns in all available tables, including custom columns, custom lists, and custom records.
    
-   **[oa\_fkeys](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4410184091.html)** - This table shows the relations between columns in all available tables.
    
    Note:
    
    Due to the complexity of the NetSuite2.com schema, the `oa_fkeys` table may return inaccurate information about foreign keys for the NetSuite2.com data source. Some foreign keys may be missing or incorrectly identified as such. Consider the information about foreign keys for NetSuite2.com as a reference only.
    

The following tables are available in the schema but are not supported:

-   oa\_proc
    
-   oa\_info
    
-   oa\_proccolumns
    
-   oa\_statistics
    
-   oa\_types
    

system

These system tables can be used to show all columns and tables available in your account and the relations between them.

## Viewing the Record Types Available in Your Account {#bridgehead_4407759211}

To find all records that are available in your account, you can do the following:

Important:

Avoid using `SELECT*` when creating queries, as it can negatively impact performance with large tables. Instead, specify only the columns you need and apply targeted filters, such as `table_name`. For more information, see [SuiteQL Performance and Best Practices](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0824094533.html).

-   To see all available record types, run the following query:
    
                  `select * from oa_tables;` 
                
    
-   To see all available fields, run the following query:
    
                  `select * from oa_columns;` 
                
    

Note:

Due to an internal limitation, queries over SuiteAnalytics Connect schema tables that have more than 1000 columns only work if you retrieve 1000 columns or less in the query. This run failure can occur when using the 'Select \* From' construct to query tables that have many custom fields or when joining multiple tables in a single query and trying to retrieve all their fields. For more information, see [Custom Field Limitations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N751341.html#bridgehead_4781145588).

There are several ways to find the name of the record types and fields available in the NetSuite2.com data source. For more information, see [Record Types and Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_164312261929.html).
