After you installed the driver, you must specify the required connection properties and you can also configure some additional operating system settings.

-   **Connection Properties** - To learn about the required and optional connection properties, see [Specifying Connection Properties](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4425615742.html).
    
-   **Operating System Settings** - When you work with the Connect Service, you can choose to change some operating system settings. For more information, see [Operating System Settings](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0801115551.html).
