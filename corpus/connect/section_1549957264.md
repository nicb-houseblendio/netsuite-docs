Important:

The outdated NetSuite.com data source is no longer available as of NetSuite 2026.1. The NetSuite2.com data source is the only data source for SuiteAnalytics Connect, and all users should have completed the required actions to move to the NetSuite2.com data source. For more information, see [Removal of SuiteAnalytics Connect NetSuite.com Data Source](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0405125116.html).

After you've downloaded and installed your driver, you must configure your data source or connection string. Follow the required steps:

-   Take note of your configuration values - The configuration values are available under **Your Configuration** on the SuiteAnalytics Connect Driver Download page. For more information, see [Connect Driver Download Page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1202105110.html).
    
-   Add the configuration values to set up your data source - There are several ways to add the configuration values to the connection attributes of your driver. Depending on your driver and operating system, see the following topics:
    
    -   [Configuring the ODBC Data Source on Windows](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3963857327.html)
        
    -   [Configuring the ODBC Data Source on Linux](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4044005623.html)
        
    -   [JDBC Connection Properties](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4425626714.html)
        
    -   [Connecting with the ADO.NET Data Provider](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3998994424.html)
        

After you configured your driver, you can start querying your data through Connect. For more information, see [Connect Data Source](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N752122.html).
