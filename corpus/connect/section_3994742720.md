Installing a Connect JDBC driver lets you connect a Java application to the Connect Service. This driver lets you use the JDBC API to communicate with the SuiteAnalytics Connect service. The benefits of this driver type are:

-   Provides Java platform independence.
    
-   Offers a direct connection from the client application to the Connect Service.
    

The following table lists the tasks you must complete to set up your environment, download, and install the JDBC driver.

| Task | Description |
| --- | --- |
| Verify the installation prerequisites. | For more information, see [Installation Prerequisites](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4012735789.html#subsect_165156903341). |
| Download and install the driver. | For more information, see the following topics:
-   [Installing the JDBC Driver for Windows](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3996479815.html)
-   [Installing the JDBC Driver for Linux](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4044023088.html)
-   [Installing the JDBC Driver for macOS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4520819104.html)

 |
| Register the JDBC driver in your environment by adding the JAR file location to your class path. | For more information, see [Configuring the JDBC Driver](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0726102029.html). |
| Optionally, you can enable authentication with server certificates for the Connect for JDBC driver. | For more information, see [Authentication Using Server Certificates for JDBC](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4353052057.html). |
