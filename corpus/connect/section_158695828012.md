The outdated NetSuite.com data source is no longer available as of NetSuite 2026.1. Some users still have temporary access to the old data source as an exception, but all Connect users should transition to the NetSuite2.com data source as soon as possible. For information about the NetSuite.com data source, see [NetSuite.com Data Source](https://system.netsuite.com/app/help/helpcenter.nl?fid=NetSuitecomDataSource.pdf).
