Note:

You can use two authentication methods with SuiteAnalytics Connect: OAuth 2.0 and token-based authentication (TBA). However, OAuth 2.0 is the preferred authentication method. You should consider using OAuth 2.0 instead of TBA whenever possible. For more information about OAuth 2.0, see [OAuth 2.0 for Connect](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0907012138.html).

For details about using token-based authentication (TBA) with SuiteAnalytics Connect, see the following topics:

-   [Requirements for Using Token-based Authentication in Connect](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_163239880280.html)
    
-   [Using Connect with Token-Based Authentication (TBA)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_163239887396.html)
    
-   [Token Password for Connect](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_163239884825.html)
    

For more information about token-based authentication (TBA) in NetSuite, see [Token-based Authentication (TBA)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4247329078.html).
