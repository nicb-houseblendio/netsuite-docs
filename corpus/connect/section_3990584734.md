The following table lists tasks for an ODBC driver to connect to Connect Service; however, some of these tasks are optional to complete.

| Task | Description |
| --- | --- |
| Set up an environment and verify installation prerequisites. | For both Windows and Linux, verify the installation prerequisites. For more information, see [Installation Prerequisites](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4012735789.html#subsect_165156903341). |
| Download and install the driver. | For Windows, see [Downloading and Installing the ODBC Driver for Windows](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3963853203.html). For Linux, see [Downloading and Installing the ODBC Driver for Linux](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4042973030.html). |
| Set up the ODBC connection. | For both Windows and Linux, see [Configuring the ODBC Driver](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0801120603.html). |
| Optionally, upgrade from a previous version. | For both Windows and Linux, see [Upgrading an ODBC Driver](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3963860724.html) to upgrade a previous installation. |
| Optionally, enable authentication with server certificates. | For both Windows and Linux, see [Authentication Using Server Certificates for ODBC](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4041410260.html) to add increased encryption to secure the data connection. |
