You can install an ODBC driver in a Linux operating system.

-   Before you install the driver, make sure your Linux distribution is compatible with the ODBC driver for Linux. For details, see [Supported Linux Distributions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4042917875.html).
    
-   To learn how to download and install the ODBC driver for Linux, see [Installing the Latest Driver on Linux](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4049054066.html).
    
-   To learn how to install the driver in a custom location, see [Installing a Driver for Linux into an Alternate Directory](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4047452302.html).
