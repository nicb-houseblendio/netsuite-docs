To analyze your data with SuiteAnalytics Connect, you must download and install a Connect driver. SuiteAnalytics Connect supports three driver types: ODBC, JDBC, and ADO.NET.

The following table includes links to the information that you need for each driver type.

| Links | Description |
| --- | --- |
| [ODBC Drivers](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1201032531.html) | This topic includes the details of the latest ODBC driver version and the history of all ODBC driver versions that have been available for download. |
| [JDBC Drivers](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1201032640.html) | This topic includes the details of the latest JDBC driver version and the history of all JDBC driver versions that have been available for download. |
| [ADO.NET Drivers](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1201032653.html) | This topic includes the details of the latest ADO.NET driver version and the history of all ADO.NET driver versions that have been available for download. |
| [Connect Driver Download Page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1202105110.html) | This topic includes an overview to understand the SuiteAnalytics Connect Driver Download page. |
| [Downloading and Installing Connect Drivers](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1202121851.html) | This topic describes how to download and install your Connect driver. |
| [Verifying the Downloaded File](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0206024856.html) | This topic describes how to verify the downloaded file. |
