As of **June 1, 2026**, the latest JDBC driver version is available for download. This version resolves several issues, including TCP keep-alive behavior in certain configurations, JDBC driver branding in error message prefixes, and a JAR packaging issue. We recommend that you upgrade your JDBC driver to **version 8.10.190.0**.

Note:

If you are using ODBC or ADO.NET drivers, no action is required.

For information about upgrading to the latest driver, see the following help articles:

-   [Installing the JDBC Driver for Windows](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3996479815.html)
    
-   [Installing the JDBC Driver for Linux](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4044023088.html)
    
-   [Installing the JDBC Driver for macOS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4520819104.html)
    

For information about the latest driver version, see [JDBC Driver 8.10.190.0](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1201032640.html#subsect_0525112713).
