Note:

From the 2021.1 release onwards, all Site Builder-related features are accessible in the Commerce tab on the navigation menu. For more information, see [Commerce Tab](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160579471374.html).

| Task | For More Information |
| --- | --- |
| **1.** Enable Web Site features. Note: An Administrator must complete this step. | For more information, see [Enabling Web Store Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2455682.html). |
| **2.** Set up domain names. | [Domains](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N2478982.html) |
| **3.** Set preferences at _Commerce > Websites > New_ | [Site Builder Web Site Record Settings](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N2561820.html) |
| **4.** Create or import item records. | [Displaying Items and Information](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2585301.html) |
| **Option:** Use the Content Manager to add tabs, categories and items. | [Site Builder Web Site Content Manager](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2576424.html) |
| **5.** Upload and size images. Tip: Ensure image files are marked Available Without login. | [Images](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2592452.html) |
| **6.** Create Categories to organize items. | [Creating Site Categories](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2596427.html) |
| **7.** Create Tabs to organize Categories. | [Creating Website Tabs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2595492.html) |
| **8.** Create and upload HTML templates. If integrating with NetSuite checkout, use Web Site Tags. | [Hosting HTML Websites with NetSuite Site Builder](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2598355.html) [Web Site Tags](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N2615371.html) |
| **9.** Create Layouts. | [Creating and Editing Website Layouts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2602488.html) |
| **Option:** Advanced Site Customization Create or edit site themes and item/category templates. | [Site Builder Customization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N2601007.html) |
| **Option:** Create a Custom Color Theme | [Changing Website Color Themes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2603251.html) |
| **10.** Create Related Items Groups. | [Related Items](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2586873.html) |
| **11.** Set accounting and tax preferences for Web store orders at _Setup > Accounting > Accounting Preferences_ and _Setup > Accounting > Taxes > Set Up Taxes_. Note: An Administrator or someone with accounting permissions must complete this step. | The following preferences apply to web stores:
-   Accounting Preferences - Customers Can Pay Online
-   Set Up Taxes - Charge Sales Tax on Store Orders

 |
| **12.** Set up payment methods (including PayPal), and mark them as Display in Web Site. | [Payment Options for Commerce Web Stores](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N2469683.html) [PayPal Integration and Express Checkout for Commerce Web Stores](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2470255.html) |
| **13.** Set up shipping items. | [Setting Up Shipping](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1518563504.html) |
| **14.** Preview your site at _Commerce > Websites > Preview Website_, and make changes as necessary. | [Previewing Your Site Builder Website](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2576788.html) |
| **15.** Submit your site URL to search engines, and begin search engine optimization. | [Site Builder Search Engine Optimization (SEO)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N2635817.html) |
