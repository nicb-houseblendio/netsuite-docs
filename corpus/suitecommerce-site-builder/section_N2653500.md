This report shows you the keywords site visitors are using to search within your site and the search results. The detailed report itemizes shoppers that use each keyword and the queries each shopper submitted with a keyword.

You can click a shopper's name to view that person's lead, prospect or customer record. Internal search queries are saved on the Web subtab of these records.

## To see the Internal Search Detail report: {#bridgehead_N2653523}

Go to _Reports > Web Presence > Internal Search Detail._.

If the report does not display immediately, a message appears indicating that your report is loading. Click Cancel to stop the report from loading.
