The features you can turn on in your account depend on the Site Builder product you subscribe to. For information products you can purchase, contact your NetSuite account manager.

| Type of Web Store | Requires Advanced HTML Knowledge | Uses Advanced Site Customization Tools | Uses Custom HTML to Generate Web Store Pages | Features to Enable |
| --- | --- | --- | --- | --- |
| NetSuite Standard Site | No | Yes | No | Website, Site Builder (Website), Site Builder (Web Store), Advanced Site Customization |
| NetSuite-Hosted HTML Web Store | Yes | Yes | Yes | Website, Site Builder (Website), Site Builder (Web Store), Host HTML Files, Advanced Site Customization |
| External Catalog Site (WSDK) | Yes | No | Yes | Website, Site Builder (Website), Site Builder (Web Store), External Catalog Site (WSDK) |
| Combination Web Store | Yes | Yes | Yes | Website, Site Builder (Website), Site Builder (Web Store), Advanced Site Customization, Host HTML Files |

Warning:

You can enable the SuiteTax feature only if your Site Builder website is inactive or it has the Web Site Scope set to 'Information and Catalog' or 'Information Only'. Site Builder web sites with pricing are not compatible with SuiteTax.

You can create multiple sites of different types. For example, you can create one hosted site for general information about your company and one combination site available only to wholesalers who can log in and order items. For more information about setting up multiple sites, see [Creating Multiple Websites](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2580798.html).

Note:

Only administrators can enable features in your account.

#### To enable web store features: {#procedure_N2456149}

1.  Go to _Setup > Company > Setup Tasks > Enable Features_.
    
2.  Click the **Web Presence** subtab.
    
3.  Check the box next to each feature you want to use.
    
4.  Click **Save**.
