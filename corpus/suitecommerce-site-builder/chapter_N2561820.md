#### To select web site setup preferences for the first time: {#procedure_N2562641}

1.  Go to _Commerce > Websites > Website List_.
    
2.  Click **New** to set up a new site, or click **Edit** next to a web site. For more information on setting up multiple sites, see [Creating Multiple Websites](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2580798.html).
    
3.  After you have set your preferences, click **Save** to apply your changes.
