This report shows the numbers of items ordered, the number of orders places for each item and the number of unique customers who ordered each item by website category.

You can use this report to know which items sell the most in each website category.

## To see the Item Orders by Category report: {#bridgehead_N2649166}

Go to _Reports > Web Presence > Item Orders by Category._.

If the report does not display immediately, a message appears indicating that your report is loading. Click Cancel to stop the report from loading.
