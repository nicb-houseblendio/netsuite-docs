After you set preferences, you can start building your Site Builder website. The setup tasks listed below only apply to Site Builder sites:

1.  Use the Content Manager to set up tabs and categories.
    
    Read [Site Builder Web Site Content Manager](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2576424.html) to learn about adding content to your Site Builder Website.
    
2.  Set up your shopping domain.
    
    Site Builder sites that use custom domain names on shopping pages are required to set up a Primary Web Site URL. For more information, see [Domains](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N2478982.html).
    
3.  Preview your website.
    
    To learn how to view your site, read [Previewing Your Site Builder Website](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2576788.html).
    
4.  Set up the page where customers can register on your site.
    
    You can customize the login and registration paged for your Site Builder web store. For more information, see [Customizing Registration for Your Site Builder Web Store](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2576937.html).
    
5.  Set your website home page.
    
    Select the landing page (or home page) of your Site Builder website. For more information, see [Setting Up Your Site Builder Home Page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2578280.html).
    
6.  To customize the shopping cart and checkout, see [Customizing the Shopping Cart in Site Builder](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2571864.html) and [Customizing Checkout in Site Builder](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2572068.html).
    

The following are optional setup tasks for Site Builder, depending on the features and preferences you have enabled in your account:

-   Learn how to set up additional websites operated out of the same NetSuite account. For more information, see [Creating Multiple Websites](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2580798.html).
    
-   Learn about setting up your Site Builder website in NetSuite OneWorld. For more information, see [Site Builder and OneWorld](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2466850.html).
    
-   Allow online customers to submit orders in different currencies, read [Setting up Multiple Currencies in a Site Builder Web Store](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2582125.html).
    
-   To set up product back-ordered functionality for your e-commerce site, read [Setting Web Store Back Order and Out-of-Stock Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2582357.html).
    
-   To set up your site to support multiple languages, read [Setting Up a Site for Multiple Languages](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2463004.html).
    
-   Use system notes to track important changes and create saved searches of changes to website implementations. To work with system notes, follow the instructions as outlined for a Commerce site. See [Website System Notes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4762462531.html).
    
-   To use the SuiteCommerce Configuration record, you must set up a domain for your Site Builder website. See [Domains](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N2478982.html) for instructions.
    
    See [Configure Properties](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4346479003.html) for information how to configure your website using the SuiteCommerce Configuration record.
