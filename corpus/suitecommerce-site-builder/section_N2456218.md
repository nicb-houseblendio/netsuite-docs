Site Builder is the legacy e-commerce solution delivered by NetSuite. It includes access to the SSP application platform and free access to SuiteApps that you can install to add functionality to your web store. To start creating a Site Builder website, read [Setting Up Your Site Builder Site](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N2576231.html).

To set important preferences for your site, such as online order forms and web store shipping preferences, read [Site Builder Web Site Record Settings](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N2561820.html).

To learn more about Site Builder websites, such as different configurations, and required features, read the following topics:

-   [Site Builder Websites](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4411560271.html)
    
-   [Workflow for Setting Up a Site Builder Website or Store](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N2457552.html)
    
-   [Enabling Web Store Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2455682.html)
    

Important:

SuiteCommerce Advanced provides a more robust web store solution. For details on differences between Site Builder versus SuiteCommerce Advanced, see [Site Builder versus Commerce Web Store Sites](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_3770762759.html).
