Images can be attached to items, categories, and information items. Each record type has an image field and thumbnail field which automatically resize images to the correct size. This lets you upload the same image to both fields.

Note:

You can set default sizes for thumbnail, drilldown, dense list, and dense list drilldown images at _Commerce > Site Builder > Content > Image Resizing_. This automatically resizes images to the defined sizes so you can use a single image file in different places.

You must first upload images to the File Cabinet by going to _Commerce > Site Builder > Content > Images_. Images must be stored in the Images folder to be available to display on your website.

#### To attach an image to an item:

1.  Go to _Lists > Accounting > Items_.
    
2.  Click **Edit** on the item record you want to modify.
    
3.  Go to the **Web Store** subtab.
    
4.  Search for and select the desired images in the **Item Display Image** field and **Item Display Thumbnail** field.
    
5.  Click **Save** or **Update Matrix** to save the record.
    

#### To attach an image to a category:

1.  Go to _Commerce > Site Builder > Content Management > Categories_.
    
2.  Click **Edit** on the category you want to modify.
    
3.  Go to the **Media** subtab.
    
4.  Search for and select the desired images in the **Thumbnail** field and **Image** field.
    
5.  Click **Save**.
    

#### To attach an image to an information item:

1.  Go to _Commerce > Site Builder > Content > Information Items_.
    
2.  Click **Edit** on the information item you want to modify.
    
3.  Go to the **Media** subtab.
    
4.  Search for and select the desired images in the **Item Thumbnail** field and **Item Picture** field.
    
5.  Click **Save**.
    

Note:

Image files must be marked as Available Without Login on the File Cabinet record to display on your site. Files uploaded to the Images Folder and the Web Site Hosting Files folder are marked as Available Without Login by default. See [Make Images Available Without Login](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162137415332.html#subsect_162137429522) for instructions to perform a mass update of files to Available Without Login.
