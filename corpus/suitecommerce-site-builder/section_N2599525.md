You can test and get changes to your hosted website with the NetSuite staging environment.

In your Web Site Hosting Files folder, you'll see two folders: Live and Staging. Files in the Live folder make up your website and are visible to customers. When you want to make and test changes, upload your new site to the Staging folder.

You can set the audience on your Staging folder so only employees or partners can see the website while you're testing it. When you set an audience for your Staging folder, employees and partners have to log into NetSuite and use the site home page URL to view the site. For more information, see [Audience Permissions for Hosted Sites](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2598904.html).

If you don't set the audience for the Staging folder, you'll need to create a domain where you can stage your website.

#### To set up your website staging environment: {#procedure_N2599568}

1.  Register your staging domain and point the domain at NetSuite. For more information, see [Point Your Domain Name at Your Domain (DNS Settings)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2479403.html).
    
2.  Go to _Commerce > Hosting > Domains_. Add the domain for use on your staging environment.
    
3.  In the **HTML Hosting Root** column, select **Staging**.
    
4.  Click **Add**.
    

When you are confident with your new site, move your files from the Staging folder to the Live folder.
