With Commerce web store implementations you can build a web store that includes the full shopping, cart and checkout, and my account experiences for B2C and B2B businesses. Combined, Commerce web store components deliver a modern shopping experience and help in the advanced customization of your web store. Site Builder is the legacy commerce solution delivered by NetSuite. This section describes some of the key differences between Commerce web store solutions and Site Builder sites.
