The Home tab is included in the standard set of tabs NetSuite provides for your Site Builder website. However, you can choose any tab or hosted HTML file as your website home page. If you prefer to create your own tab, see [Creating Website Tabs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2595492.html).

Your website's home page can present vital information about your web store to visitors by displaying a Flash® file, a logo image, or by including a greeting or message targeted at online customers. For more information, see [Changing the Image and Text on Your Home Page Tab](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2578683.html).

You can also increase the visibility of certain items by featuring them on your home page. For more information, see [Featuring Items](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2585769.html).

Note that the Home page tab does not support pagination. If you want to display a long list of items, you can set the row limit on a layout to display the full list. For more information, see [Applying a Layout or Template on Your Site Builder Home Page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2580611.html). Alternatively, you could use a different presentation tab as the home page for your site. All other presentation tabs support pagination for item lists by default.
