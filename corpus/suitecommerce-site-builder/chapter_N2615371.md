Besides entering your own custom HTML for items, categories, tabs, and item/category and site theme templates you can also use various types of NetSuite tags to customize your website. Web site tags lets you apply an advanced level of customization to your website.

Note:

Changes to web site tags can take up to 15 minutes to display on the website.

You can use attribute tags in most description fields, but to work with other types of Web Site Tags, you must use the Advanced Site Customization feature. You must have experience working with HTML code to use Web Site Tags most effectively.

Important:

Web Site tags are not supported in SuiteCommerce Advanced websites.

Read the topics below for more information about each type of site tag:

-   Use Attribute tags to show information extracted from item, category, tab, customer, and custom records on your website. For more information, see [Creating Attribute Tags](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2615537.html).
    
-   Use the declareAttribute tag when you use an attribute tag in a field, and you use a site template to display that field on your website. For more information, see [Declare Attribute Tags for Tags Within Tags](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2628302.html).
    
-   Define your own tags for use in customizing item/category templates and site themes. For more information, see [Defining Custom Web Site Tags](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2628473.html).
    
-   Use the NetSuite server-side Include tag to reuse sections of HTML code from files you host in the NetSuite file cabinet. For more information, see [Using the Server-Side Include Tag](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2629027.html).
    
-   View a list of NetSuite tags for use in the HTML pages you host in NetSuite, and in the site themes you create. For more information, see [Tags for Use in HTML Pages and Site Templates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2630406.html).
