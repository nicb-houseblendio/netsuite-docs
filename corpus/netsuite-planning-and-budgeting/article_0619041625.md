To extract budget data from your Planning and Budgeting, you need to set up a data integration record in Data Exchange.

#### To create a data integration record: {#procedure_36162737521}

1.  In your Planning and Budgeting environment, click the Navigator icon ![This icon takes you to the main menu in your Oracle EPM Planning application.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuitePlanningandBudgeting/PlanningAndBudgetingSync/NSPBMenuIcon.png). Then, under Application, click **Data Exchange**.
    
2.  Click the **Add** icon ![Creates a new target application in NSPB.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuitePlanningandBudgeting/PlanningAndBudgetingSync/NSPBAddIcon.png).
    
3.  In the Create Integration popup window, do the following:
    
    1.  In the **Name** field, enter a unique name for this data integration record.
        
    2.  From the **Location** list, select the location in File Browser that you defined in [Creating a New Location in File Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_49172841084.html).
        
    3.  From the **Source** list, select **NetSuite**.
        
    4.  From the **Target** list, select the target application you created in [Creating a Target Application in Data Exchange](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0417092445.html).
        
    5.  From the **Category** list, select the required category.
        
4.  Click **Save And Continue**.
    
5.  In the Map Dimensions window, from the source column list for every target dimension, select the corresponding source column. The following screenshot shows an example of the mapping for the source file you uploaded in [Creating a Target Application in Data Exchange](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0417092445.html):
    
    ![This illustrates the mapping for this integration record.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuitePlanningandBudgeting/PlanningAndBudgetingSync/PBSyncMapDimensions.png)
6.  When finished, click **Save And Continue**.
    
7.  In the Map Members window, add mapping rules for each dimension:
    
    1.  From the **Dimension** list, select a dimension.
        
    2.  Click the **Add** icon ![Lets you update the selected dimension in NSPB.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuitePlanningandBudgeting/PlanningAndBudgetingSync/NSPBAddIcon.png).
        
    3.  In the **Source** field, enter an asterisk \*.
        
    4.  In the **Target** field, enter an asterisk \*.
        
    5.  In the **Processing Order** field, enter 1.
        
    6.  Click **OK**.
        
    7.  Repeat this procedure for all the other dimensions in the **Dimension** list.
        
    8.  When finished, click **Save And Continue**.
        
8.  In the Options window, click the **Options** tab, and do the following:
    
    1.  In the **Download File Name** field, enter the name of the CSV file that the integration should generate and store in the location you defined in [Creating a New Location in File Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_49172841084.html).
        
        Note:
        
        If you want to use the predefined **pi\_import\_budget\_data\_dm.js** post-processing plug-in, enter the following file name:
        
        `nspbBudgetDm.csv`
        
        The file name must match exactly, including upper and lower case.
        
    2.  Make any other necessary changes, and click **Save**.
        

For general information and additional setup, see the Oracle Help Center topic [Data Integration](https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/diepm/integrations_about_110x65a03764.html).
