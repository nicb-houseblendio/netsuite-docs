The Balance Sheet Report - Group Consolidated form shows consolidated balance sheet data (Actual or Forecast amounts) for all Subsidiaries by Year, Scenario, and Reporting Currency. You can see values for a single Period or Total Period. Use this form to analyze the consolidated balance sheet.

#### To review the consolidated balance sheet: {#procedure_0715035403}

1.  From the Home page, go to Financials > Balance Sheet.
    
2.  Click **Balance Sheet Report - Group Consolidated**.
    
3.  In the Point of View, choose a Version, Scenario, Year, Period, and Currency.
    
    Note:
    
    Since this report can show all subsidiaries, you should select a reporting currency that is applicable across all subsidiaries. Although you can select an input currency, values will only show in Subsidiary columns where that input currency is valid.
    
4.  (Optional) To refresh the form with the latest values from the Forecast forms, right-click the data grid and select **BS Forecast Data Refresh**.
    
5.  Review the consolidated balance sheet values.
    
6.  (Optional) To aggregate the application:
    
    1.  Go to the Home page and click the **Rules** card.
        
    2.  Beside the ruleset **NFS\_All Accts Forecast Data Refresh**, click the Launch arrow.
