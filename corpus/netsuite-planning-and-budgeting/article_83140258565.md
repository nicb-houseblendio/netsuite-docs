A successfully executed data load rule or business rule generates a data file in your Planning and Budgeting. You can download the data file from NetSuite or from your Planning and Budgeting.

| Downloading from Planning and Budgeting | Downloading from NetSuite |
| --- | --- |
| If the job runs successfully in your Planning and Budgeting, you can download the last generated CSV file from Inbox/Outbox Explorer or File Browser's inbox. For instructions, see [Uploading and Downloading Files Using the Inbox/Outbox Explorer](https://docs.oracle.com/en/cloud/saas/planning-budgeting-cloud/pfusa/inoutbox.html) or [Using the File Browser](https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/diepm/integrations_file_browser_104x9f4f8316.html) in the Oracle Help Center. | After successfully executing a data load rule or business rule with a plug-in in NetSuite, you can download the latest data file from NetSuite:
1.  In NetSuite, go to Planning & Budgeting > Jobs > Manage Jobs.
2.  Click the **Logs** link to access information about the executed job.
3.  Click **Download Current Planning Exported File**. This downloads the latest data file that was generated in your Planning and Budgeting and stored in Inbox/Outbox Explorer or File Browser's inbox.
