If you've created datasets as described in the help topic [Manage Datasets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0711110650.html), you can view the datasets at Planning & Budgeting > Setup > Dataset Settings. There you can also view all custom datasets that you've created in NetSuite for your Planning and Budgeting.

Note:

Every dataset the ID of which includes the **\_nspbcs\_** prefix, for example `custdataset_nspbcs_sync_item_new`, is listed in Data Exchange.

On each dataset in the list, you can take any of the following actions:

-   You can customize the hierarchy of metadata you want to export in the dataset.
    
    See [Customization of Created Datasets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0720082736.html).
    
-   You can manually export and review the hierarchy of metadata in the dataset.
    
    See [Manual Export of Dataset Metadata](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_28144002195.html).
    
-   You can click the dataset to open and customize it directly in NetSuite.
    
    If you need instructions on how you can customize the dataset, proceed from step 3 in [Customizing an NSPB Sync Dataset](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0711120952.html).
