User variables work as filters so that users focus on certain members, such as a department.

To manage the user variables, click the Navigator icon ![Navigator icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuitePlanningandBudgeting/PlanningandBudgetingFinancials/IntegrationGuide/NSPB-SP_MenuIcon.png), and select **Variables**. The **User Variables** tab opens by default.

If you have the Administrator role, you can select valid members for the user variable in the **User Variable Definition** column. The members that you specify limit what members users can select when they assign a value to the user variable in **User Preferences**.

The following table lists all user variables to set, along with sample member definitions:

| Dimension | User Variable Name | Sample User Variable Definition |
| --- | --- | --- |
| Item | Item Type | IDescendants(NSP\_Total Item) |
| Period | Reporting Period | IDescendants(TotalYear) |
| Relationship | Customer Category | IChildren(NSP\_Total Customer) |
| Scenario | Set Scenario | Budget |
| Version | Set Version | NSP\_Base |
