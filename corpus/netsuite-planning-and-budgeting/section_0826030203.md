Use Version Builder to modify an existing Forecast version.

#### To modify an existing forecast version: {#procedure_0704064347}

1.  From the Home page, click the **Versions** card.
    
2.  In the Point of View (POV), choose a Set Version, Subsidiary, Currency, and Years member.
    
3.  To apply the changes, click the Go icon ![Go icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuitePlanningandBudgeting/PlanningandBudgetingFinancials/UserGuide/NSPBGoIcon.png).
    
4.  Right-click the Version Builder data grid and select **Create Forecast Version**.
    
    The Create Forecast Version window opens.
    
5.  On the Version Options page, check **Use an existing Version**.
    
6.  Click **Next**.
    
7.  On the Existing Version page, click the Member Selector icon ![Member Selector icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuitePlanningandBudgeting/PlanningandBudgetingFinancials/UserGuide/NSPBMemberSelectorIcon.png) next to the **Select existing Version** field.
    
    Select the Forecast version that you want to adjust, and then click **OK**.
    
8.  Click **Next**.
    
9.  On the Copy Data From page, enter the following information:
    
    -   **Select Scenario** - Select a scenario to pull data from.
        
    -   **Select Version** - Select a version to pull data from.
        
    -   **Start Year** - Select a start year for the data that you want pulled.
        
    -   **Start Period** - Select the first period that you want to copy data from.
        
    -   **Number of Periods** - Enter the number of periods you want to copy.
        
10.  Click **Next**.
     
11.  On the Copy Data To page, enter the following information:
     
     -   **Start Year** - Enter the starting year where data will be copied.
         
     -   **Start Period** - Enter the starting period where data will be copied.
         
12.  Click **Next**.
     
13.  On the Financial Top Level Adjustments page, enter any adjustments that you want to make to the version:
     
     1.  In the **Adjustment %** field, enter a positive or negative number (such as 10.25 for a 10.25% increase or -5 for a 5% decrease).
         
     2.  In each Accounts field, select one or more accounts apply the adjustment to.
         
14.  Click **Next**.
     
15.  On the Version Processing Options page:
     
     1.  If you want the version that you're adjusting to be the Version set in the POV, check **Make this your Set Version**. Otherwise, leave it unchecked.
         
     2.  (Optional) Select one or more subsidiaries that you want the data copied to and top-level adjustments to apply in the new version. If you don't select any subsidiaries, the new version includes all subsidiaries.
         
16.  Click **Launch**.
     

Note:

After you finish creating a new Forecast version, you should run a database refresh. For more information, see [Refreshing Application Databases](https://docs.oracle.com/en/cloud/saas/planning-budgeting-cloud/pfusa/refreshing_application_databases.html) in the Oracle Help Center.
