Note:

Make sure the IDs of the cloned saved searches start with the following prefixes. The cloned saved searches shouldn't use any of these prefixes as their IDs.

| Saved Search Type | Supported Prefixes |
| --- | --- |
| Item | customsearch\_nspbcs\_sync\_item |
| Vendor | customsearch\_nspbcs\_sync\_vend |
| Subsidiary | customsearch\_nspbcs\_sync\_sub |
| Location | customsearch\_nspbcs\_sync\_loc |
| Income Statement Accounts | customsearch\_nspbcs\_sync\_acct\_inc\_stmt customsearch\_nspbcs\_sync\_acis |
| Balance Sheet Accounts | customsearch\_nspbcs\_sync\_acct\_bs customsearch\_nspbcs\_sync\_acbs |
| Class | customsearch\_nspbcs\_sync\_class customsearch\_nspbcs\_sync\_clss |
| Customer | customsearch\_nspbcs\_sync\_cust |
| Department | customsearch\_nspbcs\_sync\_dept |
| Project | customsearch\_nspbcs\_sync\_prj |
| Customer Project | customsearch\_nspbcs\_sync\_cprj |
| Employee | customsearch\_nspbcs\_sync\_emp |
