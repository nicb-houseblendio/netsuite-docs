To implement budget data import using a data integration record, you need to complete the following consecutive steps in Data Exchange:

1.  Create a target application in Data Exchange.
    
    See [Creating a Target Application in Data Exchange](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0417092445.html).
    
2.  Define a location in File Browser to store the exported data integration files.
    
    See [Creating a New Location in File Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_49172841084.html).
    
3.  Create a data integration record to extract budget data from your Planning and Budgeting.
    
    See [Creating a Data Integration Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0619041625.html).
    
4.  Run the created data integration record.
    
    See [Running the Created Data Integration](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_10172658482.html).
