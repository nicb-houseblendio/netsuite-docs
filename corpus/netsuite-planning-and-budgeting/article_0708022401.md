The Income Statement Subsidiary Consolidated form displays consolidated Income Statement data for all Subsidiaries by Year, Department, and Class for one or all periods. You can use this form to analyze the consolidated income statement in Reporting Currency across all Subsidiaries.

Note:

The form includes both Actual and open Forecast scenarios.

Substitution variables are used to define the **Scenario** and **Years** dimensions.

#### To review the consolidated income statement: {#procedure_0708024923}

1.  From the Home page, go to Financials > Income Statement.
    
2.  Click **Income Statement Subsidiary Consolidated**.
    
3.  In the Point of View, choose a Version, Scenario, Year, Period, Currency, Department, and Class.
    
    Note:
    
    Since this form can show all subsidiaries, you should select a reporting currency that is applicable across all subsidiaries. Although you can select an input currency, values will only show in Subsidiary columns where that input currency is valid.
    
4.  Consolidated income statement values show by Subsidiary and inclusw parent values and inter-company eliminations.
    
5.  To refresh the form with the latest values from the Revenue and OpEx Forecast forms, right-click the data grid and select **IS Forecast Data Refresh.**
    
6.  Review and analyze the consolidated Income Statement values.
    
7.  (Optional) To aggregate the application:
    
    1.  Go to the Home page and click the **Rules** card.
        
    2.  Beside the ruleset **NFS\_All Accts Forecast Data Refresh**, click the Launch arrow.
