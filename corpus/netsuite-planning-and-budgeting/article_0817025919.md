At the end of each financial period and year, you need to update certain substitution variables in NetSuite Planning and Budgeting. After you close the period in NetSuite and refresh and validate the NetSuite data and metadata, update the substitution variables to the new budget period.

To set the value of a substitution variable, click the Navigator icon ![Navigator icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuitePlanningandBudgeting/PlanningandBudgetingFinancials/AdminGuide/NSPBNavigatorIcon.png), and then select **Variables**. Click the **Substitution Variables** tab, and then enter the new value for a variable in the **Value** column.

For more information, see [Setting Up Values for Substitution and User Variables](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_8162312309.html) in the Planning and Budgeting Financials Integration Guide.

Tip:

If you prefer to set values for substitution variables in your NetSuite account, refer to the help topic [Substitution Variables](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158160755033.html).

Be sure to update each substitution variable as frequently as the list for its category indicates.

Update the following variables monthly:

-   NSP\_PER\_ActCurrMo
    
-   NSP\_PER\_RptCurrMo
    
-   NSP\_PER\_RptPriorMo
    
-   NSP\_PER\_RptPriorMo
    
-   NSP\_PER\_SyncEndYear
    
-   NSP\_PER\_SyncStartMonth
    
-   NSP\_PER\_SyncStartYr
    

Update the following substitution variables annually:

-   NSP\_PER\_ActCurrYr
    
-   NSP\_PER\_PriorYr
    
-   NSP\_PER\_PriorYr1
    
-   NSP\_PER\_RptCurrYr
    
-   NSP\_PER\_RptPriorYr
