Periodically, synchronize NetSuite data and metadata with Planning and Budgeting by running data load rules to refresh the data. You can set how often to refresh data and schedule Planning and Budgeting to run a refresh on a specific date and time if needed.

For details about running pipelines or scheduling jobs to run the data load rules, see the following help topics in the Oracle Help Center:

-   To synchronize data by running a pipeline job in Planning and Budgeting, see [Running the Pipeline](https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/diepm/integrations_pipeline_run.html).
    
-   To synchronize data by scheduling a refresh job in Planning and Budgeting, see [Scheduling Jobs](https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/diepm/integrations_scheduling.html#DIEPM-GUID-141F014A-0314-4BB5-A313-BCEAA837C87D).
    
    Or, if you prefer to schedule the refresh in NetSuite, see [Scheduling a Job in NetSuite](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_160527228086.html).
    
    Note:
    
    Before you schedule a job, check when other scheduled Jobs are set to run. Also, check when Daily Maintenance updates happen, since these could prevent your job from running successfully.
