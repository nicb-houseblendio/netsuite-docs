You can customize a created NSPB Sync dataset to better suit your needs.

#### To customize an NSPB Sync dataset: {#procedure_10144256746}

1.  In NetSuite, go to Planning & Budgeting > Setup > Manage Datasets.
    
2.  Click the link to a dataset in the **Created** status.
    
    This opens a NetSuite page with the dataset record.
    

<a id="step_79144002183"></a>

4.  Change the name and the ID of the dataset.
    
    Note:
    
    Read the following guidelines:
    
    -   Make sure the name and the ID are unique in NetSuite. If the name or the ID aren't unique, you need to change them to be able to create your custom dataset in NetSuite.
        
    -   Make sure you don't change the original dataset ID, and only append your custom suffix to the original dataset ID.
        
    
5.  Make any necessary changes to the dataset, and click **Save**.
    

The following list gives details about customization and hierarchy of the NSPB Sync datasets:

-   Next time you update your installed NSPB Sync, the latest updates won't affect the NSPB Sync datasets you already created and customized in NetSuite. If you want to use the datasets included in the latest release of NSPB Sync, you need to recreate them in NetSuite. See [Recreating an NSPB Sync Dataset](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0711120857.html).
    
-   If you want to use your customizations with the datasets included in the latest release of NSPB Sync, recreate the datasets and update them manually with your customizations. See [Recreating an NSPB Sync Dataset](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0711120857.html).
    
-   When you add columns to a metadata dataset, make sure you add the new columns after the predefined columns. If you reorder or remove the predefined columns, the dataset hierarchy may not be generated properly.
    
-   If you export a dataset into a CSV file, and the columns you've added show internal IDs instead of values, use a formula to display the values correctly.
    
    For example, if you add a Currency column, and the exported CSV file shows currency internal IDs, use formula `TO_CHAR({currency#display})` in your formula field. For information about creating formula fields in SuiteAnalytics Workbook, see [Creating Formula Fields in SuiteAnalytics Workbook](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158798424898.html).
    

For general information about how you can customize datasets, see [Editing a Dataset](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158041505315.html).
