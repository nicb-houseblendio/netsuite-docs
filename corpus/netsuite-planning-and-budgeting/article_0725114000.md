The NSPB Sync SuiteApp includes the following metadata saved searches:

-   PBCS sync (Metadata) Item
    
-   PBCS sync (Metadata) Vendor
    
-   PBCS sync (Metadata) Subsidiary
    
-   PBCS sync (Metadata) Location
    
-   PBCS sync (Metadata) Income Statement Accounts
    
-   PBCS sync (Metadata) Balance Sheet Accounts
    
-   PBCS sync (Metadata) Class
    
-   PBCS sync (Metadata) Customer
    
-   PBCS sync (Metadata) Department
    
-   PBCS sync (Metadata) Project
    
-   PBCS sync (Metadata) Customer Project
    
-   PBCS sync (Metadata) Employee
    

When you clone any of these metadata saved searches in NetSuite, follow instructions in [Customizing NSPB Sync Saved Searches](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156933489080.html). The NSPB Sync SuiteApp supports prefixes of metadata saved searches IDs listed in [Supported Prefixes of Metadata Saved Searches IDs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0725113520.html).

In addition to these metadata saved searches that are included in the SuiteApp, you can manually create Custom Segment metadata saved searches in NetSuite. See [Custom Segment Metadata](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_158428590850.html).
