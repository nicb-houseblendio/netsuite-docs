Planning and Budgeting Sync includes the following predefined post-processing plug-ins that you can use to import and process budget data from your Planning and Budgeting:

-   **pi\_import\_budget\_data\_br.js** to process budget data generated using a business rule in Planning and Budgeting.
    
-   **pi\_import\_budget\_data\_dm.js** to process budget data generated using a data integration job in Data Exchange.
    

Important:

These two plug-in scripts are provided to get you started and may not be applicable to your use case. If you want to use these plug-ins, you need to customize them. For configuration details, see [Plug-in Script Configuration Details](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0730024143.html). Also, you need to test your code to ensure the plug-ins work for the data volume you expect on your production account.

#### To use a Planning and Budgeting Sync plug-in: {#procedure_82114026718}

1.  In NetSuite, go to NetSuite EPM > Planning and Budgeting > Integration Artifacts.
    
2.  On the **Plug-in Scripts** subtab, click **Download** to save the required plug-in script to your disc.
    
    Tip:
    
    Alternatively, you can use the Plug-in Code Generator to help you create a custom plug-in script for importing budget data from Planning and Budgeting. See [Using the Plug-in Code Generator in Planning and Budgeting Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_9101733435.html).
    
3.  Go to _Customization > Plug-ins > Plug-in Implementations_.
    
4.  Click **New Plug-in Implementation**.
    
5.  Click the plus (+) sign to upload the plug-in script, and then click **Save**.
    
6.  Click **Create Plug-in Implementation.**
    
7.  From the list of plug-in types, click **NSPB | PI Job Post Process**.
    
8.  In the **Name** field, enter a name for your custom plug-in script.
    
9.  Set the Status field to **Released**.
    
10.  (Optional) Set the Log Level field to **Debug**.
     
11.  Click **Save**.
     
12.  To customize the script file, go back to _Customization > Plug-ins > Plug-in Implementations_, and then do the following:
     
     1.  In the displayed list, find the plug-in script that you want to customize.
         
         Tip:
         
         If NetSuite displays a long list of plug-in scripts, you can narrow the list by doing the following:
         
         1.  Expand the Filters area if the filters aren't displayed.
             
         2.  From the **Script File** filter, select the script file name.
             
         
     2.  In the **Script** column, click the link to the script file details, and then do one of the following:
         
         -   To save the script file to disk, click **Download**. Then, use any plain text editor, for example Notepad++, to open and customize the script file.
             
         -   To update the script file directly in NetSuite, in the Media item section, click **Edit** next to the script file name. When finished, click **Save** to submit your changes.
             
13.  Add the plug-in script to a job in NetSuite:
     
     1.  Go to NetSuite EPM > Planning and Budgeting > Manage Jobs.
         
     2.  On the Planning and Budgeting: Manage Jobs page, do one of the following:
         
         -   In the list of jobs, click **Edit** next to a job of your choice.
             
         -   If you don't see the job in the list, click the **Add Job** button, and follow steps 3 through 6 in [Adding a Job in NetSuite](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1209082459.html).
             
     3.  Click the **Options** subtab.
         
     4.  From the **Post-Processing Plug-ins** list, select the plug-in you want to use to process data.
         
     5.  Click **Save**.
         

Note:

With every new version of the Planning and Budgeting Sync SuiteApp, you may need to download, customize, and re-attach the sample plug-in script provided with the SuiteApp.
