To implement budget data import using a data load rule, you need to complete the following consecutive steps in Data Exchange:

1.  Create a target application in Data Exchange.
    
    See [Creating a Target Application in Data Exchange](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_54153212582.html).
    
2.  Define a location in File Browser to store the exported data integration files.
    
    See [Creating a New Location in File Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0418122043.html).
    
3.  Create a data integration record to extract budget data from your Planning and Budgeting.
    
    See [Creating a Data Integration Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_12153848342.html).
    
4.  Run the created data integration record.
    
    See [Running the Created Data Integration](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0418070332.html).
