You can use the saved searches included in the Planning and Budgeting Sync SuiteApp. If you need to customize a created Planning and Budgeting Sync saved search to better suit your needs, make sure you customize it properly in NetSuite.

#### To customize a Planning and Budgeting Sync saved search:

1.  In NetSuite, go to NetSuite EPM > Planning and Budgeting > Manage Saved Searches.
    
2.  In the upper-right corner of the page, click **Create Default Saved Searches**.
    
3.  From the **Saved Search Group** list, select the saved search group containing the saved search you want to customize. The following are the available saved search groups:
    
    -   **NSPB - Data Saved Searches**
        
    -   **NSPB - Metadata Saved Searches**
        
    -   **NSPB - Social Impact Saved Searches**
        
    -   **NSPB Financials - Demand Forecasting Saved Searches**
        
    -   **NSPB Financials - Data Saved Searches**
        
    -   **NSPB Financials - Metadata Saved Searches**
        
    -   **NSPB SuitePeople - Saved Searches**
        
    -   **NSPB SuiteSuccess (Premium Edition) - Data Saved Searches**
        
    -   **NSPB SuiteSuccess (Premium Edition) - Metadata Saved Searches**
        
    -   **NSPB SuiteSuccess (Standard Edition) - Data Saved Searches**
        
    -   **NSPB SuiteSuccess (Standard Edition) - Metadata Saved Searches**
        
    -   **Miscellaneous Saved Searches**
        
    
    For information about saved searches included in each group, see [Saved Searches for Planning and Budgeting Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_4153122253.html).
    
4.  Click the link to a saved search in the **Created** status.
    
5.  On the saved search record page, you can modify the following:
    
    -   Saved search title.
        
        Note:
        
        Make sure the saved search name is unique in NetSuite.
        
    -   Search ID. To modify it, click **Change ID**, and then do the following:
        
        -   In the **New ID** field, enter the new search ID.
            
        -   Click **Save**.
            
        
        Important:
        
        Saved searches the IDs of which begin with **customsearch\_nspb** are available in the RESTlet. The saved search ID cannot begin with **customsearch\_nspb\_req**.
        
        Note:
        
        Read the following details about changing the saved search ID:
        
        -   Make sure the saved search ID is unique in NetSuite.
            
        -   When you change the ID of a saved search, the existing settings of the saved search will be lost.
            
        
6.  Verify that the saved search is **Public**.
    
7.  On the **Criteria** subtab, add or remove filters.
    
8.  On the **Results** subtab, add or remove columns.
    
    Note:
    
    When you enter a value in the **Summary Type** column, and then run the saved search in NetSuite, the Total row appears at the bottom of the saved search result. This Total row is excluded from CSV files that are exported to your Planning and Budgeting with Import Data/Metadata jobs.
    
9.  Make any necessary changes, and click **Save**.
    

Important:

Read the following details about customization of the Planning and Budgeting Sync saved searches:

-   Next time you update your installed Planning and Budgeting Sync, the latest updates won't affect the Planning and Budgeting Sync saved searches you already created and customized in NetSuite. If you want to use saved searches included in the latest release of the SuiteApp, you need to recreate the saved searches in NetSuite. See [Recreating a Planning and Budgeting Sync Saved Search](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1208015722.html).
    
-   The Data Exchange configurations are compatible with the saved searches included in the latest release of the SuiteApp. If you want to use your customized saved searches, you may need to manually update the Data Exchange configurations.
    
    For information about the use of Data Exchange in Oracle Cloud EPM Planning and Budgeting, see the Oracle Help Center topic [Administering Data Integration](https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/diepm/epm_coe_guide.html).
    
-   Settings associated with a deleted saved search's ID remain in the system. If you create a new saved search with the same ID, NetSuite applies the same settings to this saved search.
