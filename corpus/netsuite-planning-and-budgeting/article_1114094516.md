You can import Planning and Budgeting Sync configuration into your NetSuite account from a previously exported file.

Note:

Prior to importing the Substitution Variables configuration, check if any categories have been customized or created in the source NetSuite account. Then, create and customize the same categories in the target NetSuite account. For instructions, see [Creating and Customizing Categories for Substitution Variables in Planning and Budgeting Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1114102459.html).

#### To import Planning and Budgeting Sync configuration: {#procedure_3094831063}

1.  In NetSuite, go to NetSuite EPM > Planning and Budgeting > Import/Export Configuration.
    
2.  Choose the **Import** radio button.
    
3.  Under **File to import**, select a JSON file you exported as described in [Exporting Planning and Budgeting Sync Configuration](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1114092108.html).
    
4.  If you want to overwrite your existing configuration with the content of the import file, check the **Overwrite Existing Values** box.
    
5.  Click **Submit**.
    
    This imports the configuration into your NetSuite account. Details and the import history appear on the **Logs** subtab.
    
    When importing, you can expect the following behavior:
    
    -   If you import Form/Dashboard configuration, check the POV values after the import to ensure they match those in the source NetSuite account.
        
    -   If you import Jobs configuration, make sure all plug-ins configured on the jobs in the source NetSuite account are implemented in the target NetSuite account.
        
    -   If an error occurs with any configuration during the import, it doesn't affect the import of the rest of the configurations in the file. You can view the related error logs on the **Logs** subtab.
        
    -   If you checked the **Overwrite Existing Values** box, you can expect the following specific behavior:
        
        -   If the import file contains no configuration, you receive an error message indicating that the import file is empty.
            
        -   If you import the Account Metadata Hierarchy configuration, only the first record in the account metadata hierarchy is updated.
