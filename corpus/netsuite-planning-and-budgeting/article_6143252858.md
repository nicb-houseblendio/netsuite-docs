After you finish using the budget version that you created in Version Builder, you can remove that version and its related data from your application. You also have the option to remove only the budget data and keep the version you created.

Note:

Best practice is to have only users with the Administrator role and budget owners clear budget versions and related data.

The procedures for removing budget versions and related data are covered in the following topics:

-   [Removing Budget Versions](#subsect_34163120480)
    
-   [Removing Data in the Budget Version](#subsect_54160222776)
    

## Removing Budget Versions {#subsect_34163120480}

You can remove the budget versions that you created and the associated budget data from your application.

#### To remove the budget version from your application: {#procedure_1222043509}

1.  Click the Navigator icon ![Screenshot of the Navigator icon in NSPB](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuitePlanningandBudgeting/PlanningandBudgetingFinancials/AdminGuide/NSPBNavigatorIcon.png), and under Create and Manage, select **Dimensions**.
    
2.  Under the **Dimensions** tab, from the **Dimension** list, select **Version**.
    
3.  Click the expand icon ![Expand icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuitePlanningandBudgeting/PlanningandBudgetingFinancials/AdminGuide/DimensionsExpandArrowIcon.png) next to **NSP\_Version Builder** to open the list of budget versions.
    
4.  Select the version you want to remove, and then click the Delete icon ![Delete icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuitePlanningandBudgeting/PlanningandBudgetingFinancials/AdminGuide/NSPBDeleteIcon.png).
    

## Removing Data in the Budget Version {#subsect_54160222776}

You can keep the budget version you created and remove only the budget data. To remove the data, run the **NFS\_ADMIN - Clear Version** business rule from Version Builder.

Note:

The NFS\_ADMIN - Clear Version business rule can only clear scenarios of versions created from Version Builder. You can't use this rule to clear the Base or Final versions.

Tip:

Alternatively, you can remove data by running the NFS\_ADMIN - Clear Version business rule in the Rules card. For more information, see [Launching Business Rules](https://docs.oracle.com/en/cloud/saas/planning-budgeting-cloud/pfusu/launching_business_rules.html) in the Oracle Help Center.

#### To remove data in the budget version from Version Builder: {#procedure_1222040600}

1.  From the Home page, click the **Versions** card.
    
2.  In the Point of View (POV), select the Set Version, Subsidiary, Currency, and Years member.
    
3.  Right-click anywhere in the data grid, and select **Clear Version Data**.
    
    The window for the NFS\_ADMIN - Clear Version business rule opens.
    
4.  Select the Scenario, Version, and Year that you want to remove. You can click the Member Selector icon ![Member Selector icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuitePlanningandBudgeting/PlanningandBudgetingFinancials/AdminGuide/NSPBMemberSelectorIcon.png) to change the members to the specific scenario-version combination that you want to clear.
    
    Note:
    
    The NFS\_ADMIN - Clear Version business rule removes data only for the Year member you select. The business rule doesn't clear data in the budget version for all years you had set when you created it.
    
5.  Click **Launch**.
