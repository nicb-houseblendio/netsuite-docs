In the General tab, set preferences like your profile photo, time zone, language, which alias table to use, and more.

From the Planning and Budgeting Home page, go to Tools > User Preferences. The **General** tab opens by default. On this tab, you can set the preferences listed in the following table. When you're done, click **Save**.

Important:

If you change your language, save your changes, then sign out and sign back in to apply the new language setting.

| Field Name | Function |
| --- | --- |
| **Profile** |
| Time Zone | Select the time zone where you work. |
| Language | Select the language for your account. |
| Profile Image | To add a profile image, click **Profile Image,** and choose an image from your files. |
| **Alias Setting** |
| Alias Table | Select the alias table to use. |
| Display Member Label as | Choose how you want the member name or alias to appear:
-   Member Name
-   Alias
-   Member Name:Alias
-   Alias:Member Name
-   Default If you select Default, the form, grid, or dimension settings determine how member names display.

 |
| Use Administrator's Settings | Check this to use the settings configured by the user with the Administrator role. |
| **Approvals** |
| Display Aliases | Check this box to show aliases. |
| Show Not Started Approval Units | Check this box if you want the approval units that have not started to show with those that have started. |
| Show Approval Units as Aliases in Approvals Notification | If you enabled **Approvals** in **Notifications**, check this box to show the approval units as aliases. |
| I am currently out of the office | Check this box if you'll be out of the office and want to set what happens on approval units when you are out. This setting keeps the budget review process moving when you're away. In **Action**, select one of the following actions to take when you're away:

-   **Promote** - Promote the approval unit.
-   **Reject** - Reject the approval unit.
-   **Submit** - Submit the approval unit.
-   **Delegate** - Select this option to assign someone else your reviewing responsibilities review while you're away. In the **Message** box, you can add a message for the reviewer.

Note: When you're back in the office, clear your "out of office" setting. For more information about approvals, see the help topic [Getting Plans Approved](https://docs.oracle.com/en/cloud/saas/planning-budgeting-cloud/pfusu/getting_plans_approved.html) in the Oracle Help Center. |
| Use Administrator's Settings | Check this box to use the settings configured by the Administrator. |
