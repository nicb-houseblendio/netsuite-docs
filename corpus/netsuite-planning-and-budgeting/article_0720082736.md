You can filter dataset data by how long ago it was created or last updated. You can also customize the hierarchy of metadata you want to export in a dataset.

#### To customize a dataset: {#procedure_88144507022}

1.  In NetSuite, go to Planning & Budgeting > Setup > Dataset Settings.
    
    NetSuite displays a list of datasets.
    
2.  Click **Customize** next to a dataset of your choice.
    
    If you've already customized the dataset, the **Edit** button is available for you to make any additional changes.
    
3.  Under the Add-On Filter section that is available for transactional datasets, select your filtering option from the **Filter** dropdown list. Some of the options may not be available for the dataset you're customizing:
    
    -   **No Filter**
        
    -   **Created or Updated Since N Days Ago**
        
    -   **Created Since N Days Ago**
        
    
    Where **N** is the number of days in the past to include in the filtering. Specify the number in the **Days** field.
    
    Note:
    
    This filtering doesn't modify the configuration of the created datasets. It only filters the results of datasets execution in your Planning and Budgeting.
    
4.  If you're customizing a metadata dataset, take any of the actions under the Hierarchy Settings section. Some of the actions may not be applicable to the metadata dataset you're customizing:
    
    1.  Enter a value in the **Top Level Parent Value** field to customize the top level parent name.
        
    2.  Check the **Exclude Upper Level Hierarchy Members** box, if you don't want to include the upper level member in the hierarchy. This option applies only to the Accounts and Item metadata datasets.
        
    3.  The **Return Hierarchy Based Only on Data in This Search** box is provided to return the hierarchy of metadata only from the customized dataset.
        
        -   For all metadata datasets, this box is checked by default and can't be cleared.
            
        -   For all transactional datasets, this box is unavailable.
            
    4.  Enter a value in the **Category Prefix** field to customize the default category prefix. Make sure the category prefix is unique for each metadata dataset.
        
5.  If you're customizing a metadata dataset, take any of the actions under the Parent Level Transaction section. Some of the actions may not be applicable to the metadata dataset you're customizing:
    
    1.  From the **Data Storage for Parent Record** dropdown list, select the default value for the Data Storage column in the exported metadata dataset.
        
        You have the following options:
        
        -   **Never Share** - This option sets the value of the Data Storage column for the parent to Never Share.
            
        -   **Dynamic Calc** - This option sets the value of the Data Storage column for the parent to Dynamic Calc.
            
        -   **Store** - This option sets the value of the Data Storage column for the parent to Store.
            
        -   **Store/Never Share** - When the parent has only one child, NSPB Sync sets the value of the Data Storage column to **Never Share**. Otherwise, the value is set to **Store**.
            
        
        Your selection impacts the way data is stored and calculated for the parent in your Planning and Budgeting.
        
        Note:
        
        The default value of the Data Storage column for all child records in all the supported metadata hierarchies is **Store**.
        
    2.  To change the default prefix or suffix for the member name, do the following:
        
        1.  Enter a value in the **Member Name Affix Value** field.
            
        2.  From the **Custom Affix for Member Name** dropdown list, select whether you want to add **Member Name Affix Value** as **Prefix** or **Suffix**.
            
            If you select the **Use Default** option, the default **P\_** prefix is used.
            
    3.  To change the default prefix or suffix for the alias column, do the following:
        
        1.  Enter a value in the **Alias Affix Value** field.
            
        2.  From the **Custom Affix for Alias** dropdown list, select whether you want to add **Alias Affix Value** as **Prefix** or **Suffix**.
            
            If you select the **Use Default** option, the default **Total\_** prefix is used.
            
6.  Under the Sorting section, from the **Sort By** dropdown list, select the required option for sorting metadata in the dataset:
    
    -   Sort metadata alphabetically by **Alias**.
        
    -   Sort metadata numerically by **Member Internal ID**.
        
    -   Sort metadata alphabetically by **Member Name**.
        
    
    If you don't select any sorting option, metadata is automatically sorted by **Member Internal ID**.
    
    Metadata is sorted on each level of the hierarchy.
    
7.  Click **Save**.
