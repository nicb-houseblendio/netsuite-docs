Important:

Before you start, if you've renamed any base dimensions, make sure you follow the steps for setting up your application to support those dimensions first. For more information, see [Setting Up Planning and Budgeting After Renaming Dimensions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_9123505838.html).

If you've enabled custom dimensions, follow these steps to make sure all your business rules, Groovy scripts, and calculations work with them.

1.  Register all saved searches with **NSPB (Data) FIN** in its name from Planning and Budgeting to NetSuite.
    
    See [Registering Saved Searches from Planning and Budgeting to NetSuite](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1114053225.html).
    
2.  Update the import format mappings for the saved searches.
    
    See [Updating Import Format Mappings for Planning and Budgeting Saved Searches](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1114063545.html).
    
3.  Set up the new data load mappings for the data load rules affected by the custom dimensions.
    
    See [Setting Up New Data Load Mappings for Rules Affected by Custom Dimensions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1114074054.html).
    
4.  Review and update the layout of forms and dashboards to include the new custom dimensions, if needed.
    
    See [Defining the Layout](https://docs.oracle.com/en/cloud/saas/planning-budgeting-cloud/pfusa/defining_the_layout.html) in the Oracle Help Center.
    
5.  Update the **NSP\_SYS\_NoIntersection** substitution variable.
    
    See [Updating the NSP\_SYS\_NoIntersection Substitution Variable](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1120074358.html).
    
6.  Add the custom dimensions to the **NFS\_Form\_DiM** business rule.
    
    See [Adding Custom Dimensions to the NFS\_Form\_DiM Business Rule](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1120094813.html).
    
7.  To load metadata and data into Planning and Budgeting Financials, manually run the Batch\_Setup job.
    
    See [Executing the Default Pipeline Jobs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_2113849230.html).
    
8.  Add the custom dimensions to the **NFS\_BS\_Trending Days in Month** member formula.
    
    See [Adding Custom Dimensions to the NFS\_BS Trending Days in Month Member Formula](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1120112626.html).
