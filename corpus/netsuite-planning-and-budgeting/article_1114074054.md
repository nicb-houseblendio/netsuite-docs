Make sure you set up new data load mappings for any data load rules affected by the custom dimensions. Data load mappings convert the chart of accounts values from the NetSuite General Ledger to Planning and Budgeting dimension members during data transfer. This lets Data Management categorize NetSuite General Ledger balances. For more information about data load mapping, see [Data Load Mapping](https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/erpia/fus_data_mapping_116x52092843.html) in the Oracle Help Center.

The following table list the data load rules affected by the custom dimension and the category for each rule. Use this table to select the Location and Category in the Point of View (POV) bar when you set up the data load mapping.

| Data Load Rule (Location) | Category |
| --- | --- |
| BalSht\_Beg\_Bals | NSP\_Actual |
| BalSht\_Beg\_Bals\_RC | NSP\_Actual |
| BalSht\_Trans | NSP\_Actual |
| Consol\_FxRate\_Actual | NSP\_Actual |
| Consol\_FxRate\_BudAct | NSP\_Actual |
| Days\_in\_Month | Current |
| IncStmt\_Trans | NSP\_Actual |
| IncStmt\_Trans\_RC | NSP\_Actual |

#### To set up new data load mappings for the rules affected by custom dimensions: {#procedure_1114074113}

1.  Click the Navigator icon ![The Menu icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuitePlanningandBudgeting/PlanningandBudgetingFinancials/IntegrationGuide/NSPB-SP_MenuIcon.png), and then under Integration, select **Data Management**.
    
    The Data Management window opens.
    
2.  Click the **Workflow** tab, and then under Data Load, click **Data Load Mapping**.
    
3.  In the POV bar, click the link next to **Location**.
    
    The Select Point of View window opens.
    
    Tip:
    
    In the Select Point of View window, you can click the search icon ![Search icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuitePlanningandBudgeting/PlanningandBudgetingFinancials/IntegrationGuide/DataManagementSearchIcon.png) next to fields to search for and select POV values.
    
    1.  In the **Location** field, enter the data load rule.
        
        For example, enter **BalSht\_Beg\_Bals**.
        
    2.  In the **Category** field, enter the category that goes with the rule you entered, as shown in the preceding table.
        
        For example, if **Location** is **BalSht\_Beg\_Bals**, enter **NSP\_Actual**.
        
    3.  Click **OK**.
        
4.  From the **Dimensions** list, choose the custom dimension that you want to map.
    
5.  Click the **Like** tab, and then click **Add**.
    
6.  In the new row, in the **Source Value** and **Target Value** fields, enter an asterisk (**\***).
    
    The asterisk maps the NetSuite General Ledger account to Planning and Budgeting as-is, without any changes.
    
7.  In **Rule Name**, enter the name of the data load rule used to transfer budget amounts to the NetSuite General Ledger.
    
8.  (Optional) In **Description**, enter a short description of the mapping.
    
    For example, enter something such as **Map to the General Ledger**.
    
9.  Click **Save**.
    
10.  If you enabled more than one custom dimensions, repeat steps 4 - 9 for each one.
     
11.  Repeat steps 3 - 9 for each data load rule listed in the preceding table.
