In Data Exchange, you need to define the location in the inbox folder in File Browser where you want to store the exported CSV files.

#### To create a new location for storing the exported CSV files: {#procedure_0418122154}

1.  In your Planning and Budgeting environment, click the Navigator icon ![This icon takes you to the main menu in your Oracle EPM Planning application.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuitePlanningandBudgeting/NSPBSync/NSPBMenuIcon.png). Then, under Application, click **Data Exchange**.
    
2.  Click **Actions**, and then select **File Browser**.
    
3.  Double-click the inbox folder, and create a subfolder where you want to store the CSV files.
    

For general information about using File Browser, see the Oracle Help Center topic [Using the File Browser](https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/diepm/integrations_file_browser_104x9f4f8316.html).
