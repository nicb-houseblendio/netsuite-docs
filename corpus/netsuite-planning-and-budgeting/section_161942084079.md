You must set up token-based authentication (TBA) in your Planning and Budgeting application to enable connection to NetSuite.

For general information, see the following help topics:

-   [Create Integration Records for Applications to Use TBA](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4249032125.html)
    
-   [Requirements for Using Token-Based Authentication](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4395625427.html)
    
-   [Manage TBA Tokens in the NetSuite UI](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4254975694.html)
    

#### To set up token-based authentication: {#procedure_1127120639}

1.  In NetSuite, go to _Setup > Integration > Manage Integrations > New_.
    
2.  In the **Name** field, enter a name for this integration record that should represent your Planning and Budgeting application.
    
3.  In the **Description** field, enter a description to help you identify this integration record in NetSuite.
    
4.  In the **State** field, leave the default **Enabled** option.
    
5.  On the **Authentication** tab, make sure the **Token-based Authentication** box is checked.
    
6.  Make any other necessary changes, and then click **Save**.
    
    NetSuite generates the consumer key and consumer secret on the integration record.
    
7.  Save the consumer key and consumer secret.
    
    Note:
    
    The consumer key and consumer secret show only one time. If you lose these credentials, you can regenerate new ones. For more information, see [Regenerating a Consumer Key and Secret](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4395597766.html).
    
8.  Go to _Setup > Users/Roles > Access Tokens > New_.
    
9.  On the Access Token page:
    
    1.  From the **Application Name** dropdown list, select the created integration record.
        
    2.  From the **User** dropdown list, select the user that should be used for the integration with your Planning and Budgeting.
        
        For information about setting up the integration user, see [Setting Up the Integration User](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_1489167953.html).
        
    3.  From the **Role** dropdown list, select **PBCS Integration**, or your custom role that gives sufficient permissions to the integration user.
        
    4.  The **Token Name** field is populated with a concatenation of Application Name, User, and Role.
        
    5.  Click **Save**.
        
        NetSuite generates the Token ID and Token Secret on the page.
        
    6.  Save the generated Token ID and Token Secret.
        
        Note:
        
        The Token ID and Token Secret show only one time. If you lose these credentials, you must create a new token.
        
10.  In your Planning and Budgeting application, click the **Navigator** icon ![The Menu icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuitePlanningandBudgeting/NSPBSync/NSPBMenuIcon.png), and then click **Data Exchange**.
     
11.  Click **Actions**, and then select **Applications**.
     
12.  On the Applications page, click the **Configure Connections** icon ![The Configure Connections icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuitePlanningandBudgeting/NSPBSync/NSPBConnectionIcon.png).
     
13.  On the Connections page, click the **Add** icon ![The Add icon on the Connections page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuitePlanningandBudgeting/NSPBSync/NSPBAddIcon.png), and then select **NetSuite**.
     
14.  In the Create connection: NetSuite popup window, do the following:
     
     1.  In the **Name** field, enter a name for the connection.
         
     2.  In the **Description** field, enter a description to help you identify this connection.
         
     
     <a id="step_7123223648"></a>
     
     4.  For the **Consumer Key Type**, choose **Custom**.
         
         Important:
         
         If you've selected **Internal NS Application NS-PBCS** as the application name when creating a token in step 9, then you need to choose **Default**. Otherwise, choose **Custom**.
         
     5.  For the **Connector Type**, choose **NSPB Sync**.
         
     6.  In the **Consumer Key** and **Consumer Secret** fields, enter the generated consumer key and consumer secret.
         
     7.  In the **Token Key** and **Token Secret** fields, enter the generated Token ID and Token Secret.
         
     8.  In the **Account** field, enter the integration user's NetSuite Account ID. The value must match exactly, including upper and lower case. You can find the account ID at Setup > Company > Company Information in the **Account ID** field.
         
         The following screenshot shows the **Custom** and **NSPB Sync** connection configurations for NSPB Sync:
         
         ![The connection configurations for the Custom consumer key types.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuitePlanningandBudgeting/NSPBSync/NSPBCustomTBA.png)
15.  Click **Test Connection**.
     
16.  If a popup window confirms that the connection to NetSuite was successful, click **OK** to complete the connection configuration.
