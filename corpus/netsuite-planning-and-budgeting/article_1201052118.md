Planning and Budgeting Sync lets you use post-processing plug-ins in NetSuite to import and process data from your Planning and Budgeting. If you run a data integration job or business rule that uses an erroneous post-processing plug-in, the job ends with the **Plugin Error** status.

Note:

You can see the job execution status at NetSuite EPM > Planning and Budgeting > Manage Jobs. If the job is executed successfully in your Planning and Budgeting and the plug-in is executed successfully in NetSuite, the **Execution Status** column displays **Success**.

For instructions on troubleshooting the plug-in script error, and additional information, see the following help topics:

-   To troubleshoot the plug-in script error, see [Troubleshooting the Plug-in Script Error](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_96222930654.html).
    
-   To fix an erroneous plug-in script, see [Fixing the Plug-in Script](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_89140234174.html).
    
-   To access detailed information about the failure of the plug-in script execution, see [Viewing the Logs for Jobs with Plug-in Script Errors](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_65140251809.html).
    
-   To download the latest budget data file from Planning and Budgeting or from NetSuite, see [Downloading the Generated Data File](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1201053441.html).
