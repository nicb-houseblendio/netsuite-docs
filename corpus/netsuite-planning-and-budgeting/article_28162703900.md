The Planning and Budgeting Sync SuiteApp includes a default set of predefined datasets that you can use to load metadata from NetSuite to your Planning and Budgeting. You can customize the created Planning and Budgeting Sync datasets, or clone and customize other datasets that you want to use with Planning and Budgeting Sync.

For information, see the following help topics:

-   For the list of the datasets that are included in the Planning and Budgeting Sync, see [Supported Planning and Budgeting Sync Datasets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_29162330248.html).
    
-   To create and customize the Planning and Budgeting Sync datasets, see the following help topics:
    
    -   [Creating a Planning and Budgeting Sync Dataset](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_15163221240.html)
        
    -   [Recreating a Planning and Budgeting Sync Dataset](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_47163226321.html)
        
    -   [Customizing a Created Planning and Budgeting Sync Dataset](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_36163231143.html)
        
-   To view all the datasets you have in NetSuite for your Planning and Budgeting, change search settings, and review search results, see [Dataset Settings in Planning and Budgeting Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_94163304747.html).
    

Note:

Read the following details about the assigned role permissions:

-   If you have the **Administrator** role, you can create, review, or customize the predefined Planning and Budgeting Sync datasets in NetSuite.
    
-   If you create datasets using the **NSEPM Implementer** role, the Planning and Budgeting Sync SuiteApp cannot be uninstalled from the NetSuite account until these datasets are removed.
