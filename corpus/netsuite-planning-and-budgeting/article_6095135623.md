To install and set up the Planning and Budgeting Sync SuiteApp, you must have the Administrator role and complete the following consecutive steps:

1.  Make sure you have the NetSuite EPM Connector SuiteApp installed and set up properly for your Planning and Budgeting.
    
    See [NetSuite EPM Connector Installation and Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0095112426.html).
    
2.  Enable the required features in your NetSuite account.
    
    See [Required Features for Installing the Planning and Budgeting Sync SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_5114430730.html).
    
3.  Install the Planning and Budgeting Sync SuiteApp.
    
    See [Installing the Planning and Budgeting Sync SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_31093007863.html).
    
4.  Assign roles to Planning and Budgeting Sync users.
    
    See [Role Permissions for Planning and Budgeting Sync Users](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_23131818598.html).
    
5.  Create an integration user with proper permissions.
    
    See [Setting Up the Integration User for Planning and Budgeting Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_7141303101.html).
    
6.  Set up token-based authentication (TBA) for Planning and Budgeting users.
    
    See [Setting Up Token-based Authentication for Planning and Budgeting Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_3142954952.html).
    
7.  Set up the connection to your Planning and Budgeting.
    
    See [Setting Up the Connection to Planning and Budgeting](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_4144843069.html).
    
8.  Schedule the required Planning and Budgeting Sync script deployments.
    
    See [Scheduling Script Deployments for Planning and Budgeting Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_150410060.html).
    
9.  Use a checklist of tasks to validate your Planning and Budgeting Sync setup.
    
    See [Planning and Budgeting Sync Configuration Checklist](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_6124225652.html).
    

After the SuiteApp is configured, you can use the following functionality provided by Planning and Budgeting Sync:

-   Create and customize the saved searches that are included in the SuiteApp, or create new saved searches to use in your Planning and Budgeting. You can also create saved searches from the available custom record types.
    
    See [Managing the Planning and Budgeting Sync Saved Searches](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_34174642403.html).
    
-   Customize metadata saved searches included in the SuiteApp, and call RESTlets from Data Exchange to automatically export metadata from NetSuite entities to Planning and Budgeting.
    
    See [Metadata Export to Planning and Budgeting](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1160657999.html).
    
-   Customize upper-level members of account metadata that you want to export from NetSuite.
    
    See [Account Metadata Hierarchy in Planning and Budgeting Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_7121032309.html).
    
-   Extract data from SuiteAnalytics datasets that you have created in NetSuite.
    
    See [Using SuiteAnalytics Datasets with Planning and Budgeting Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_6161321340.html).
    
-   Define SuiteQL queries to load data and metadata from NetSuite to your Planning and Budgeting.
    
    See [Managing SuiteQL Queries in Planning and Budgeting Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161554610.html).
    
-   Use your NetSuite account to access and manage features in your Planning and Budgeting account.
    
    See the following help topics:
    
    -   [Managing Jobs in Planning and Budgeting Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_5133320393.html)
        
    -   [Substitution Variables in Planning and Budgeting Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_7101207665.html)
        
    -   [Saved Search Settings in Planning and Budgeting Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_8111232373.html)
        
    -   [Forms and Dashboards in Planning and Budgeting Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_4194832638.html)
        
-   Export and import your Planning and Budgeting Sync configuration.
    
    See [Import/Export Configuration in Planning and Budgeting Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_5091412706.html).
    
-   Exchange data packages between NetSuite and your Planning and Budgeting application.
    
    See [Integration Artifacts in Planning and Budgeting Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_6133345084.html).
    
-   Create default configurations for Planning and Budgeting Financials in your NetSuite account.
    
    See [Setting Up Default Configurations for Planning and Budgeting Financials](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_36142750338.html).
    
-   View the NetSuite SuitePeople payroll data that is loaded into your Planning and Budgeting.
    
    See [Viewing NetSuite SuitePeople Payroll Data by Category](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_6161906576.html).
    
-   Use portlets for maintenance and access to Planning and Budgeting Sync features.
    
    See [Planning and Budgeting Sync Portlets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1143023848.html).
