To start using Planning and Budgeting Financials, enable the module's features in your NetSuite Planning and Budgeting application.

#### To enable features for Planning and Budgeting Financials:

1.  In your NetSuite Planning and Budgeting application, click the Navigator icon ![The Menu icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuitePlanningandBudgeting/PlanningandBudgetingFinancials/IntegrationGuide/NSPB-SP_MenuIcon.png). Then, under **Application**, click **Configuration**.
    
2.  On the Configure: NSPB Financials page, click **Enable Features**.
    
3.  In the popup window, select the features you want to enable. You have the following options:
    
    1.  **NSPB Financials**
        
    2.  (Optional) **Version Builder**
        
        The **Version Builder** box becomes active only after you check check the **NSPB Financials** box.
        
    3.  (Optional) **Budget Process**
        
        The **Budget Process** box becomes active only after you check the **NSPB Financials** box.
        
    
    For details about these features, see [Planning and Budgeting Financials User Guide](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_2153858950.html).
    
4.  (Optional) Under Map/Rename Dimensions, map and rename existing dimensions or enable custom dimensions:
    
    1.  If you're renaming an existing base dimension, go to step 4b.
        
        If you're enabling a new custom dimension, check the box next to the custom dimension in the **Enable** column. You can enable up to three custom dimensions.
        
    2.  Click the Rename Target Dimension icon ![Rename Target Dimension icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuitePlanningandBudgeting/PlanningandBudgetingFinancials/IntegrationGuide/NSPBRenameTargetDimensionIcon.png) next to the dimension.
        
    3.  In the **Rename** field, enter a new name, and then click **OK**.
        
    4.  Repeat steps 4a - 4c for each base dimension you're renaming or custom dimension you're enabling.
        
    
    For details about this feature, see [Mapping and Renaming Existing Dimensions and Enabling Custom Dimensions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_5211315067.html).
    
    Important:
    
    You can enable custom dimensions when you first enable Planning and Budgeting Financials, or any time later. However, you can map and rename existing dimensions only when you first enable Planning and Budgeting Financials. After that, you can't go back to the Enable Features window to change dimension mapping or names.
    
5.  To enable the selected features, click **Enable**.
    
6.  Click **Yes** to confirm your selection, or **No** to go back to the setup.
    
    Note:
    
    After you click **Yes** to enable the selected features, you can't disable them.
    
7.  If a popup window confirms the features were enabled, click **OK** to finish.
    
8.  To start using this default Planning and Budgeting Financials configuration, sign out of your Planning and Budgeting account, and then sign back in.
