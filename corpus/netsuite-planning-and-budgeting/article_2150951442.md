In the context of synchronization, Planning and Budgeting metadata means dimension members. Dimensions define how you analyze data values, and they are pre-configured. Dimension members are the components by which to measure the dimension data. Metadata synchronization ensures that new or changed dimension members in NetSuite also appear in Planning and Budgeting.

Also in the context of synchronization, data means the NetSuite balances or movements for each period. Data synchronization ensures that general ledger activities in NetSuite appear in Planning and Budgeting. NetSuite data and metadata go into Planning and Budgeting through saved searches during a data refresh. Only the data included in those saved searches synchronizes with Planning and Budgeting.

Besides data load rules and pipelines, you can create data load jobs to:

-   Run business rules.
    
-   Import data or metadata directly from CSV files.
    
-   Run multiple data load jobs sequentially.
    

Important:

Data load jobs should already be set up on your system. Only change data load jobs only after careful consideration and getting advice, since changing data load jobs, data load rules, or pipelines can cause synchronization to fail.
