Planning and Budgeting Financials supports multiple currencies, but you can set up your application to work with only a single currency.

## Single Currency Implementation Checklist {#subsect_32141958589}

To set up your application for a single currency, you must have the Administrator role and should complete the following steps in order:

1.  In Data Management, update the data load mappings for the Member Name and Base Currency dimensions.
    
    See [Updating the Data Load Mappings of the Member Name and Base Currency Dimensions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0212104933.html).
    
2.  In Data Management, update the data load mappings for the Account and Subsidiary dimensions for certain transaction-related data load rules.
    
    See [Updating the Data Load Mappings of the Account and Subsidiary Dimensions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0213124903.html).
    
3.  In Data Exchange, update certain data integrations to support the single currency setup.
    
    See [Updating Business Rules of Data Integrations in Embedded Mode](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1208082307.html).
    
4.  Update the member formulas of certain zero-level accounts in the Cash Flow dimension members.
    
    See [Updating the Member Formulas for Cash Flow Dimension Members to Single Currency](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1208084841.html).
    
5.  Update certain action menus to run business rules that support single currency.
    
    See [Updating the Business Rule Properties of Action Menus](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0213024821.html).
