If a saved search is in the **Created** status, you can no longer select it for submission. To use the latest release version of the saved search, you need to delete the saved search and recreate it in NetSuite.

#### To recreate a Planning and Budgeting Sync saved search: {#procedure_1208015749}

1.  In NetSuite, go to NetSuite EPM > Planning and Budgeting > Manage Saved Searches.
    
2.  In the upper-right corner of the page, click **Create Default Saved Searches**.
    
3.  From the **Saved Search Group** list, select the saved search group containing the saved search you want to recreate. The following are the available saved search groups:
    
    -   **NSPB - Data Saved Searches**
        
    -   **NSPB - Metadata Saved Searches**
        
    -   **NSPB - Social Impact Saved Searches**
        
    -   **NSPB Financials - Demand Forecasting Saved Searches**
        
    -   **NSPB Financials - Data Saved Searches**
        
    -   **NSPB Financials - Metadata Saved Searches**
        
    -   **NSPB SuitePeople - Saved Searches**
        
    -   **NSPB SuiteSuccess (Premium Edition) - Data Saved Searches**
        
    -   **NSPB SuiteSuccess (Premium Edition) - Metadata Saved Searches**
        
    -   **NSPB SuiteSuccess (Standard Edition) - Data Saved Searches**
        
    -   **NSPB SuiteSuccess (Standard Edition) - Metadata Saved Searches**
        
    -   **Miscellaneous Saved Searches**
        
    
    For information about saved searches included in each group, see [Saved Searches for Planning and Budgeting Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_4153122253.html).
    
4.  Click the link to a saved search in the **Created** status.
    
5.  On the saved search record page, under **Actions**, click **Delete**.
    
6.  At the prompt to confirm the action, click **OK**.
    
7.  Go back to NetSuite EPM > Planning and Budgeting > Manage Saved Searches.
    
    In the list of saved searches, the status of the saved search changes to **Not Created**.
    
8.  Depending on the selected saved search group, you can apply one or more of the following configuration options upon the saved searches creation:
    
    -   To populate data source ID mappings with legacy "NSPBCS" saved search IDs for the selected financial saved searches, check the **Add Data Source Mappings to Support Legacy Financial Saved Search IDs** box.
        
    -   To populate data source ID mappings with legacy "NSPBCS" saved search IDs for the selected SuiteSuccess saved searches, check the **Add Data Source Mappings to Support Legacy SuiteSuccess Saved Search IDs** box.
        
    -   From the **Fiscal Calendar** list, select the fiscal calendar of your choice. The list displays existing fiscal calendars in your NetSuite account. For information about fiscal calendars, see [Fiscal Calendars](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1449211.html).
        
    -   From the **Currencies Used in NSPB for Reporting** list, select one or multiple currencies of your choice. This adds the currencies to the Reporting Currency formula on the saved search record's **Results** subtab. The list displays existing currencies in your NetSuite account. For more information about currencies, see [Creating Currency Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1395911.html).
        
    -   For metadata saved searches, from the More list, select **Data Source Map**. This opens a NetSuite page where you can update data source mappings. For information, see [Change Data Source Mappings for Metadata Searches and Datasets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0712061757.html#subsect_0712062938).
        
9.  Check the **Select** box next to the saved search.
    
10.  Click **Submit**.
     
     In the list of saved searches, the status of the saved search changes to **Created**.
     

You can click the created saved search to review or customize it. To customize the saved search, see the help topic [Customizing a Planning and Budgeting Sync Saved Search](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_98174727806.html).
