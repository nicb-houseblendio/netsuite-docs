Customers in NetSuite can use NSPB Item Planning Category values to group items into different categories and create their own custom hierarchy. When you import Item metadata to your Planning and Budgeting, the NSPB Item Planning Category values are used to build the Item metadata hierarchy.

You can define the NSPB Item Planning Category on an item record under the **Custom** subtab.

The Item metadata hierarchy is built with the following logic:

-   If an item from NetSuite has a parent, the parent of the item is used in your Planning and Budgeting as the parent.
    
-   If an item from NetSuite doesn't have a parent, but has an NSPB Item Planning Category, a concatenation of the item type and the NSPB Item Planning Category is used in your Planning and Budgeting as the parent. For example, `Inventory Item: CAT_ITEM_1`, where Inventory Item is the item type and CAT\_ITEM\_1 is the NSPB Item Planning Category that was set on the item record.
    
-   If an item from NetSuite has neither a parent nor an NSPB Item Planning Category, the item type of the item is used in your Planning and Budgeting as the parent.
