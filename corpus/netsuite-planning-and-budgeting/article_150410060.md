Make sure you schedule deployment of the following scripts properly in your NetSuite account:

| Script Deployment Name | Script Deployment ID | Script File Name |
| --- | --- | --- |
| NSPB | MR Start Scheduled Jobs | customdeploy\_nspb\_mr\_start\_sched\_jobs | mr\_start\_scheduled\_jobs.js |
| NSPB | SS Check Job Progress | customdeploy\_nspb\_ss\_chk\_job\_progress | ss\_check\_job\_progress.js |
| NSPB | SS Check/Generate OAuth Token | customdeploy\_nspb\_ss\_chk\_oauth\_token | ss\_check\_oauth\_token.js |
| NSPB | SS Cleanup | customdeploy\_nspb\_ss\_cleanup | ss\_cleanup.js |

#### To schedule a script deployment properly for Planning and Budgeting Sync: {#procedure_6150330930}

1.  In NetSuite, go to _Customization > Scripting > Script Deployments_.
    
2.  Expand the Filters area if the filters aren't displayed.
    
3.  From the **Script** filter, select the script deployment you want to schedule.
    
4.  Next to the script deployment, click **Edit**.
    
5.  Set the **Status** field to **Scheduled**.
    
6.  On the **Schedule** subtab, do the following:
    
    -   Set the **Start Time** field to **12:00 am**.
        
    -   Set the **Repeat** field to **Every 2 hours** for the NSPB | SS Cleanup script and to **Every 15 minutes** for the other scripts.
        
7.  Click **Save**.
    
8.  Repeat these steps for each script deployment.
