If you want to use NetSuite to schedule and run a rule set configured in your Planning and Budgeting, you need to add the rule set in NetSuite. Then, you can set up the rule set as needed.

#### To add and set up a rule set:

1.  Log in to NetSuite, and go to Planning & Budgeting > Jobs > Manage Jobs.
    
2.  On the **Planning & Budgeting Jobs** page, do one of the following:
    
    -   In the list of jobs, click **Edit** next to a rule set of your choice.
        
    -   If you don't see the rule set in the list, and you have the Administrator role, click the **Add Job** button, and follow steps 3 through 6 in [Adding a Job in NetSuite](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_160527233569.html).
        
3.  Click the **Job Parameters** subtab.
    
    Enter the **Key** and **Value** of a rule set defined in your Planning and Budgeting. The field values must match exactly, including upper and lower case. Repeat if needed to create a list of parameters.
    
4.  If you want to schedule the rule set, click the **Schedule** subtab, and follow step 3 in [Scheduling a Job in NetSuite](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_160527228086.html).
    
5.  Click **Save**.
    

For general information about rule sets in your Planning and Budgeting, see [Designing Business Rule Sets](https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/ecalc/designing_business_rule_sets.html) in the Oracle Help Center.
