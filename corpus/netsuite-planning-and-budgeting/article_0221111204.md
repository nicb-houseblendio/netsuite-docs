If you have the Administrator role, you can assign roles with specific permissions to new or existing users in NetSuite. Depending on tasks the users should perform, you can assign the following roles:

-   **PBCS Integration**
    
    You assign the PBCS Integration role to a user that the NSPB Sync SuiteApp will use to integrate with your Planning and Budgeting.
    
    For more information, see [Setting Up the Integration User](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_1489167953.html).
    
-   **NSPB Implementer**
    
    You assign the NSPB Implementer role to a user who should set up and configure the NSPB Sync SuiteApp on a NetSuite account.
    
    For more information, see [Setting Up the NSPB Implementer Role](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0221123639.html).
