The NSPB Sync SuiteApp enables you to extract metadata from NetSuite entities and use the metadata in your Planning and Budgeting. You can export metadata from each entity to a CSV file instead of viewing it in the NetSuite UI. You can then use the exported CSV file to import the metadata to your Planning and Budgeting.

To export selected metadata from NetSuite entities, you have the following options:

-   You can export metadata manually, as described in [Saved Search Settings](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160628719006.html).
    
-   After configuring Data Exchange in your Planning and Budgeting for automated metadata synchronization, you can use saved searches included in the SuiteApp to export metadata as CSV files from NetSuite to your Planning and Budgeting. For the list of metadata saved searches, see [Supported Metadata Saved Searches](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0725114000.html).
