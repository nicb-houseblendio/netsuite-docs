This portlet lets you run a job with a single click of a button. You can use up to three buttons to run three different jobs from NetSuite.

#### To use a button to run a job: {#procedure_4160414690}

1.  Go to NetSuite EPM > Planning and Budgeting > Manage Jobs.
    
2.  Click **Edit** next to a job you want to run from the portlet.
    
3.  From the More list, select **Job Execution Portlet Setup**.
    
4.  From the **Job Description** list for any of the available line items, select the required job. Each line item corresponds to one button in the portlet.
    
    You can only select from jobs that you've added in NetSuite. See [Adding a Job in Planning and Budgeting Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1114010611.html).
    
    Tip:
    
    If you haven't yet added any Planning and Budgeting or Data Exchange jobs for the integration, click **here** in the Information bar to access a NetSuite page where you can add the jobs.
    
    ![Page with information message stating there are no jobs and link to create jobs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuitePlanningandBudgeting/PlanningAndBudgetingSync/NSPBClickHere.png)
5.  Click **Save**.
    
6.  Go to NetSuite EPM > NetSuite EPM Overview to access the Job Execution portlet.
    
    If you can't see the portlet on the NetSuite EPM page, you need to add the portlet to the page. For instructions, see [Accessing NetSuite EPM Overview Portlets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1114023631.html).
    
    The following screenshot shows an example of the portlet setup:
    
    ![Example of a Job Execution portlet setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuitePlanningandBudgeting/PlanningAndBudgetingSync/NSPBQuickLinks.png)
7.  Click the **Execute** button for the job you want to run. The button is dimmed and marked with one of the following icons:
    
    -   An information icon ![An information icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuitePlanningandBudgeting/PlanningAndBudgetingSync/NSPBInformationIcon.png) - When you hover over the icon, a message appears indicating whether the job execution was queued or is already in progress.
        
    -   A red cross icon ![A red cross icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuitePlanningandBudgeting/PlanningAndBudgetingSync/NSPBRedCross.png) - When you hover over the icon, a message appears indicating the reason for the job failure.
        
8.  You can watch the status of the job execution in the corresponding Execution Logs portlet. See [Execution Logs Portlets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1114024214.html).
