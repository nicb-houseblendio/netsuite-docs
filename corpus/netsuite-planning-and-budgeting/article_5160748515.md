You can map any account type from your NetSuite account to any account type in your Planning and Budgeting.

#### To create the mapping: {#procedure_10160753970}

1.  Go to _Customization > Lists, Records, & Fields > Record Types_.
    
2.  In the list of record types, find **NSPB | Account Type Mapping**.
    
3.  Click **New Record** for this record type.
    
4.  From the **Source Account Type** list, select the NetSuite account type you want to map to Planning and Budgeting.
    
5.  In the **Target Account Type** field, enter the name of the Planning and Budgeting account type you want to map to.
    
6.  To map to a specific parent account member in Planning and Budgeting, enter the relevant account number in the **Source Account Number** field.
    
    If you use this option, you can expect the following behavior:
    
    -   Adding a unique account number lets you map the same NetSuite account type to different Planning and Budgeting account types.
        
        Note:
        
        You can find the account number at _Lists > Accounting > Accounts_.
        
    -   When you set an account number in the account type mapping, it takes priority and is used instead of the source account type. If no account number is defined, the existing logic based on account type is used.
        
    
    Read these guidelines for using account numbers when mapping the same NetSuite account type to different Planning and Budgeting account types:
    
    -   Don't add account numbers to existing mapping records. Always create a separate record with the account number, and place it after the existing record. Make sure you use a different target account type.
        
    -   If you want to map only a specific account number, first create a record for the same NetSuite account type and leave the account number field empty. Then, create the record with the account number.
        
        Important:
        
        The record with the specific account number must be placed after the record with an empty account number.
        
        The following screenshot shows the correct mapping:
        
        ![An example of a correct account type mapping.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuitePlanningandBudgeting/PlanningAndBudgetingSync/PBSyncCorrectAccountTypeMapping.png)
    -   Use the account number only one time for each NetSuite account type. If you use it a second time, the record is considered a duplicate, and only the earlier record appears in the generated saved search result.
        
        In the following screenshot, the second record is a duplicate and won't appear in the saved search result:
        
        ![An example of a mapping including a duplicate account number.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuitePlanningandBudgeting/PlanningAndBudgetingSync/PBSyncDuplicateAccountTypeMapping.png)
7.  Click **Save**.
    
8.  Click **List** in the upper-right corner of the page to see all mappings you've created.
