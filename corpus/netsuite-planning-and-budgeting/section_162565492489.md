This portlet lets you run a job with a single click of a button. You can use up to three buttons to run three different jobs from NetSuite.

#### To use a button to run a job:

1.  Go to Planning & Budgeting > Jobs > Manage Jobs.
    
2.  Click **Edit** next to a job you want to run from the portlet.
    
3.  From the More list, select **Job Execution Portlet Setup**.
    
4.  From the **Job Description** dropdown list for any of the available line items, select the required job. Each line item corresponds to one button in the portlet.
    
    You can only select from jobs that you've added in NetSuite. See [Adding a Job in NetSuite](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_160527233569.html).
    
    Tip:
    
    If you haven't yet added any Planning and Budgeting or Data Exchange jobs for the integration, click **here** in the Information bar to access a NetSuite page where you can add the jobs.
    
    ![Page with information message stating there are no jobs and link to create jobs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuitePlanningandBudgeting/NSPBSync/NSPBClickHere.png)
5.  Click **Submit**.
    
6.  Go to Planning & Budgeting > Planning & Budgeting Overview to access the Job Execution portlet.
    
    If you can't see the portlet on the Planning & Budgeting page, you need to add the portlet to the page. For instructions, see [Accessing Planning & Budgeting Overview Portlets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1551958192.html#subsect_162704504393).
    
    The following screenshot shows an example of the portlet setup:
    
    ![Example of a Job Execution portlet setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuitePlanningandBudgeting/NSPBSync/NSPBQuickLinks.png)
7.  Click the **Execute** button for the job you want to run. The button is dimmed and marked with one of the following icons:
    
    -   An information icon ![An information icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuitePlanningandBudgeting/NSPBSync/NSPBInformationIcon.png) - When you hover over the icon, a message appears indicating whether the job execution was queued or is already in progress.
        
    -   A red cross icon ![A red cross icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuitePlanningandBudgeting/NSPBSync/NSPBRedCross.png) - When you hover over the icon, a message appears indicating the reason for the job failure.
        
8.  You can watch the status of the job execution in the corresponding Execution Logs portlet. See [Execution Logs Portlets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162824769683.html).
    

For instructions on adding the Job Execution portlet to the Planning & Budgeting page, see [Accessing Planning & Budgeting Overview Portlets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1551958192.html#subsect_162704504393).
