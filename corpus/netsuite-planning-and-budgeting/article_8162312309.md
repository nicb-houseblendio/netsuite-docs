If you have the Administrator role, you can review and edit values for substitution variables and user variables in NetSuite Planning and Budgeting.

During implementation, you need to set values for all substitution variables before loading metadata and data.This is because the business rules that run during the metadata and data load need those values.You should also set user variables during implementation so that you can use data forms and review reports and dashboards.

Additionally, you'll need to update certain substitution variables at the end of each financial period and at the end of the year

For more information about the values that you can set for substitution and user variables, read:

-   [Values for Substitution Variables](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1027032928.html)
    
-   [Member Values for User Variables](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1027033728.html)
