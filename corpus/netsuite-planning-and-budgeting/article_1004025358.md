If you have the Service Administrator role, you can assign or remove application roles for users with a predefined role. For more information about different application roles, see the help topic [Planning Application Roles](https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/pappm/planning_application_roles.html) from Oracle Help Center.

#### To add or remove application roles from a user: {#procedure_1004025655}

1.  Click the Navigator icon ![Screenshot of the Navigator icon in NSPB](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuitePlanningandBudgeting/PlanningandBudgetingFinancials/AdminGuide/NSPBNavigatorIcon.png), and then under Tools, select **Access Control**.
    
2.  Click the **Manage Application Roles** tab at the bottom of the page.
    
3.  Select the user you want to update.
    
4.  To add or remove roles:
    
    1.  Click the Actions icon ![NSPB Actions icon in Access Control.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuitePlanningandBudgeting/PlanningandBudgetingFinancials/AdminGuide/NSPBActionsSettingIcon.png) for the user, and then select **Manage Roles**.
        
    2.  In the Assign Application Roles to User window, do one of the following actions:
        
        -   To add a new role, under the Available Application Roles pane, select a role, and then click the right single arrow ![Rightwards single arrow to move selected items to other list.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuitePlanningandBudgeting/PlanningandBudgetingFinancials/AdminGuide/NSPBRightwardsSingleArrow.png). This adds the selected role to the Assigned Application Roles pane.
            
        -   To remove roles, under the Assigned Application Roles pane, select a role, then and click the left single arrow ![Lefttwards single arrow to move selected items to other list.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuitePlanningandBudgeting/PlanningandBudgetingFinancials/AdminGuide/NSPBLefttwardsSingleArrow.png). This moves the select role to the Available Application Roles pane.
            
        
        Tip:
        
        You can select multiple roles to add or remove before clicking the right or left single arrow. You can also click the right or left double arrow to move all roles from one pane list to the other.
        
    3.  Click **OK**.
        
    4.  A confirmation message appears. Click **OK**.
        
5.  (Optional) To see all roles assigned to a specific user:
    
    1.  Click the Actions icon ![NSPB Actions icon in Access Control.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuitePlanningandBudgeting/PlanningandBudgetingFinancials/AdminGuide/NSPBActionsSettingIcon.png) for that user, and then select **Role Assignment Report**.
        
        The Role Assignment Report window opens and shows all predefined and application-level roles assigned to the user in the **Roles** column.
        
    2.  After you are done reviewing the report, click **Done**.
