Important:

Many of the user interface pages listed in the table below aren't available in Data Management anymore, but you can find them in Data Integration. To access Data Integration, from the Application card on the NetSuite Cloud EPM home screen, click Data Exchange. These features are available in the current update.

Data Management isn't being retired. Only a few features with full parity are moving to Data Integration right now.

Data Management is an export, transform, and load (ETL) tool and interface. Use Data Management to drive the flow of data from NetSuite to NetSuite Planning and Budgeting.

## Data Management Feature Migration to Data Integration {#subsect_0820045403}

All Data Integration features mentioned in this topic are available now in NetSuite Cloud EPM business processes. Data Integration is the next version of the Data Management user interface. It lets you easily build and manage NetSuite Cloud EPM integrations.

As more features are added, Data Management features will be turned off, and you'll start using the new Data Integration interface. This transition is gradual. Future What's New documents will have details about upcoming and future changes, see the [NetSuite EPM What's New](https://docs.oracle.com/en/cloud/saas/readiness/netsuite.html) readiness updates page.

Data Integration is on the Data Management data model, so you don't need to migrate content from Data Management to Data Integration. Integration definitions you build with Data Management also show up in Data Integration, so you can switch to the new interface easily.

To access Data Integration, from the Home page, click the **Application** card, and then click **Data Exchange.**

For more information about the activities you can perform in Data Integration, see the [Administering Data Integration](https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/diepm/index.html) guide in the Oracle Help Center.

Note:

New integration features will only be added to Data Integration, not to Data Management.
