You can import NSPB Sync configuration into your NetSuite account from a previously exported file.

Note:

Prior to importing the Substitution Variables configuration, check if any categories have been customized or created in the source NetSuite account. Then, create and customize the same categories in the target NetSuite account. For instructions, see [Creating and Customizing Categories for Substitution Variables](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158160755033.html#article_0124101356).

#### To import NSPB Sync configuration:

1.  In NetSuite, go to Planning & Budgeting > Tools > Import/Export Configuration.
    
2.  Choose the **Import** radio button.
    
3.  Click **Choose File**, then select the file you want to import.
    
4.  If you want to overwrite your existing configuration with the import file content, check the **Overwrite Existing Values** box.
    
5.  Click the **Logs** subtab to view the following information about the imported configuration:
    
    -   Date
        
    -   Operation
        
    -   Status
        
    -   Options
        
    -   Details
        
    -   Filename
        
    
    Click the **View** link to see the details of the log you want to review.
    
6.  Click **Submit**.
    
    -   If you import Forms/Dashboards configuration, check the POV values after the import to ensure they match the values in the source NetSuite account.
        
    -   If you import Jobs configuration, make sure all plug-ins configured on the jobs in the source NetSuite account are implemented in the target NetSuite account.
        
    -   If an error occurs on any configuration while importing the file, it doesn't affect the import of the rest of configuration in the file. You can view the related error logs on the **Logs** subtab.
        
    -   When the **Overwrite Existing Values** box is checked, you can expect the following specific behavior:
        
        -   If the import file contains no configuration, you receive an error message indicating that the import file content is required.
            
        -   If you import the Account Metadata Hierarchy configuration, only the first record in the account metadata hierarchy is updated.
