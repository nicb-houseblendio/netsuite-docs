You can export all available Planning and Budgeting Sync configurations, or select specific configurations you want to export. The following configurations are available for export:

| Configuration Label | Description |
| --- | --- |
| Jobs | The jobs configured in Data Exchange or your Planning and Budgeting and added in NetSuite. See [Managing Jobs in Planning and Budgeting Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_5133320393.html). |
| Substitution Variables | The substitution variables configured in your Planning and Budgeting and categorized in NetSuite. See [Substitution Variables in Planning and Budgeting Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_7101207665.html). |
| Account Metadata Hierarchy | The customized upper-level members of account metadata. See [Account Metadata Hierarchy in Planning and Budgeting Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_7121032309.html). |
| Form/Dashboard | The forms and dashboards configured in your Planning and Budgeting and accessed from NetSuite. See [Forms and Dashboards in Planning and Budgeting Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_4194832638.html). |
| Saved Search Settings | Customizations to the Planning and Budgeting saved searches that you added in NetSuite. See [Saved Search Settings in Planning and Budgeting Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_8111232373.html). |
| Dataset Settings | Customizations to the Planning and Budgeting datasets that you added in NetSuite. See [Dataset Settings in Planning and Budgeting Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_94163304747.html). |
| Account Balance Portlet Settings | The custom record type setup for the Account Balance portlet. See [Planning and Budgeting Account Balance Portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1114024243.html). |
| Data Source Mappings | A list for mapping prefixes of source saved search and dataset IDs to prefixes of target saved search and dataset IDs. See [Change Data Source Mappings for Metadata Searches and Datasets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0712061757.html#subsect_0712062938). |
| Other Settings | Other settings related to the basic Planning and Budgeting Sync SuiteApp configuration. |

#### To export Planning and Budgeting Sync configuration: {#procedure_60094009216}

1.  In NetSuite, go to NetSuite EPM > Planning and Budgeting > Import/Export Configuration.
    
2.  Choose the **Export** radio button.
    
3.  On the **Configurations to Export** subtab, do any of the following:
    
    1.  In the **Select** column, check the box next to each configuration you want to export.
        
        Tip:
        
        To select all configurations, click the **Mark All** button. To clear all selections, click the **Unmark All** button.
        
    2.  To review configuration details, click the **View** link to access the specific configuration page.
        
4.  Click **Submit**.
    
    This exports the configuration to a JSON file and saves it to your local disk.
    
    Note:
    
    If the export contains no configuration, you receive an error message indicating that at least one configuration is required for the export.
    
5.  To view details and the history of your exported configurations, click the **Logs** subtab.
