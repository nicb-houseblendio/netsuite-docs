To view the status of job execution, you can access the job execution logs in NetSuite. In the logs, you can also find detailed information about errors in case of job failure.

#### To view the log of an executed job or troubleshoot:

1.  In NetSuite, go to NetSuite EPM > Planning and Budgeting > Manage Jobs.
    
2.  To access the execution log of a job, click **Logs** next to the job. This opens the Planning and Budgeting: Job Execution Log page where you can view:
    
    -   Details and the status of the executed job and plug-in script.
        
    -   A basic description of the job failure or plug-in error.
        
3.  Click the **View** link to open a NetSuite page with the log file content.
    
    Note:
    
    The **View** link isn't available on the following conditions:
    
    -   If the job wasn't executed successfully
        
    -   For rule sets
        
    
    On this page, you can do the following:
    
    1.  Choose between **Full** or **Summary** view of the log file content.
        
    2.  Click **Download** to save the log file to your local computer.
        
    3.  If an Import Data/Metadata job was completed with **Error**, clicking the **Download** link saves the latest error log to your computer.
        
4.  Click **Back** to return to the Planning and Budgeting: Job Execution Log page.
    
5.  To download the latest budget data file that was generated in your Planning and Budgeting after successfully running a data integration job or business rule, click **Download Current Planning Exported File**. For details, see [Downloading the Generated Data File](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1201053441.html).
    
6.  To view all plug-in execution logs for troubleshooting, do the following:
    
    1.  In the upper-right corner of the page, click the **Plugin Execution Logs** link to open the **NSPB | MR Job Plugin Executor** script deployment record.
        
    2.  To view all script logs, click the **Execution Log** subtab.
        
    3.  To view debug-level logs for troubleshooting, click the **Deployments** subtab, and complete these steps for all the listed script deployment records:
        
        1.  Click the link to a script deployment record.
            
        2.  On the script deployment record, click **Edit**.
            
        3.  Set the **Log Level** field to **Debug**.
            
        4.  Click **Save**.
            
        5.  To return to the list of script deployment records, click the **NSPB | MR Job Plugin Executor** link at the top of the page.
            
        6.  Click the **Deployments** subtab, and repeat these steps for each remaining script deployment record in the list.
            
        
        Important:
        
        When you finish troubleshooting, make sure you change the log level to **Audit**. This ensures that your data is not exposed in the logs.
        
        For detailed troubleshooting information, see [Troubleshooting Post-Processing Plug-ins](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1201052118.html).
