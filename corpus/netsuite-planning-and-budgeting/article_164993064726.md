Important:

The following guidelines are for users who use the Planning and Budgeting Sync SuiteApp to integrate NetSuite Planning and Budgeting or Planning and Budgeting Financials with NetSuite.

To integrate your Planning and Budgeting with NetSuite, you'll need the Administrator or the NSEPM Implementer role to complete these steps:

1.  Install the NetSuite EPM Connector SuiteApp and set it up for your Planning and Budgeting application. For information, see the following help topics:
    
    -   [Installing the NetSuite EPM Connector SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_4120644213.html)
        
        Note:
        
        To install the NetSuite EPM Connector SuiteApp, you'll need the Administrator role. To complete the integration steps outlined below, you can use either the Administrator or NSEPM Implementer role.
        
    -   [Setting Up a File Encryption Password for NetSuite EPM Connector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_3115159270.html)
        
    -   [Data Source Allowlist](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_9115749534.html)
        
2.  Install the Planning and Budgeting Sync SuiteApp.
    
    See [Installing the Planning and Budgeting Sync SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_31093007863.html).
    
3.  Enable and set up Planning and Budgeting Financials for your Planning and Budgeting application.
    
    See [Creating the NetSuite Planning and Budgeting Application](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_165046501863.html).
    
4.  Set up an integration user with proper permissions in NetSuite.
    
    See [Setting Up the Integration User for Planning and Budgeting Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_7141303101.html).
    
5.  Create the default saved searches to load data and metadata from NetSuite into your Planning and Budgeting application.
    
    See [Managing the Planning and Budgeting Sync Saved Searches](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_34174642403.html).
    
6.  Set up the default configurations for Planning and Budgeting Financials in your NetSuite account.
    
    See [Setting Up Default Configurations for Planning and Budgeting Financials](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_36142750338.html).
    
7.  Set up the connection from your Planning and Budgeting application to NetSuite.
    
    See [Setting Up Token-based Authentication for Planning and Budgeting Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_3142954952.html).
    
8.  Set up the connection from NetSuite to your Planning and Budgeting application.
    
    See [Setting Up the Connection to Planning and Budgeting](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_4144843069.html).
    
9.  Schedule the required Planning and Budgeting Sync script deployments.
    
    See [Scheduling Script Deployments for Planning and Budgeting Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_150410060.html).
    
10.  Use a checklist of tasks to make sure your Planning and Budgeting Sync setup works.
     
     See [Planning and Budgeting Sync Configuration Checklist](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_6124225652.html).
     
11.  Enable the Planning and Budgeting Financials features in your new NetSuite Planning and Budgeting environment.
     
     See [Enabling Planning and Budgeting Financials](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_165096987704.html).
     
12.  Download the ZIP file with the default configurations for Data Exchange and upload it to your Planning and Budgeting Financials environment.
     
     See [Downloading Planning and Budgeting Financials Integration Artifacts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_60123415099.html).
     
13.  To load data and metadata, manually run or schedule jobs in NetSuite:
     
     -   For Planning and Budgeting, see [Managing Jobs in Planning and Budgeting Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_5133320393.html).
         
     -   For Planning and Budgeting Financials, see [Executing the Default Pipeline Jobs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_2113849230.html).
         

After you've completed the required integration steps, you can move on to these extra configuration steps:

-   To load data and metadata from NetSuite to your Planning and Budgeting application, customize the metadata saved searches that are included in the SuiteApp. Optionally, you can also create and customize the default datasets.
    
    See the following help topics:
    
    -   [Metadata Export to Planning and Budgeting](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1160657999.html)
        
    -   [Using SuiteAnalytics Datasets with Planning and Budgeting Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_6161321340.html)
        
-   Customize upper-level members of account metadata that you want to export from NetSuite.
    
    See [Account Metadata Hierarchy in Planning and Budgeting Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_7121032309.html).
    
-   Set up values for substitution variables in your Planning and Budgeting.
    
    See [Setting Up Values for Substitution and User Variables](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_8162312309.html).
    
-   If you mapped and renamed existing dimensions or enabled custom ones, set up your NetSuite Planning and Budgeting application to use these renamed or custom dimensions.
    
    See [Mapping and Renaming Existing Dimensions and Enabling Custom Dimensions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_5211315067.html).
    
-   Use the Planning and Budgeting Sync portlets in NetSuite.
    
    See [Planning and Budgeting Sync Portlets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1143023848.html).
