Important:

Before you start setting up the Planning and Budgeting Financials module, ensure that you've integrated Planning and Budgeting Financials with NetSuite. For more information about these prerequisite steps, see the [Planning and Budgeting Financials Integration Guide](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1090228298.html).

After you've enable Planning and Budgeting Financials and completed the integration steps, you can start setting up the module. To set up your application, you must have the Administrator role and complete the following tasks in order.

## Initial Setup Task {#subsect_80002016179}

Check the source connection's token-based authentication credentials. See [Validating the Source Connection](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_3143547647.html).

## Data Import Tasks {#subsect_70002021629}

Follow these steps to update the metadata and data:

1.  Verify that the **Default POV Period** fields in system and application settings have valid accounting period values.
    
    See [Verifying the Default Point Of View Period in Data Management](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0817014643.html).
    
2.  Update the load periods for the **Pipeline\_Data\_Load** pipeline.
    
    See [Updating the Data Load Periods for Pipeline\_Data\_Load](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0818042247.html).
    
3.  If you added new revenue accounts in NetSuite, verify the account details and run the **Pipeline\_MetaData\_Load** job.
    
    See [Verifying Details After Adding New Revenue Accounts in NetSuite](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0817062101.html).
    

## Data Verification Tasks {#subsect_10002032835}

Follow these steps to validate the metadata and data in Planning and Budgeting Financials:

1.  Compare the ending totals in the Income Statement form in Planning and Budgeting Financials against ending totals in NetSuite for the current reporting month.
    
    See [Verifying the Income Statement Data](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0822014827.html).
    
2.  Compare the ending totals in the Balance Sheet Report form in Planning and Budgeting Financials against ending totals in NetSuite for the current reporting month.
    
    See [Verifying the Balance Sheet Data](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0822024800.html).
    
3.  Check the Retained Earnings adjustments.
    
    See [Reviewing and Entering Retained Earnings Adjustments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0822030140.html).
    
    Note:
    
    Do this task only if all values in the last row of the Balance Sheet Report form aren't zero.
