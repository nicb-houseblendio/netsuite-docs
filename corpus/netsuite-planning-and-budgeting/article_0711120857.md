If a dataset is in the **Created** status, you can no longer select it for submission. If you want to use the latest release version of the dataset, you need to delete the dataset and recreate it in NetSuite.

#### To recreate an NSPB Sync dataset: {#procedure_1143923118}

1.  In NetSuite, click the **Analytics** tab.
    
2.  On the Analytics Home page, click the **Datasets** subtab.
    
    NetSuite displays a list of datasets.
    
3.  For the NSPB Sync dataset you want to recreate, under **Actions**, click **Delete**.
    
4.  At the prompt to confirm the action, click **Delete**.
    
5.  Go to Planning & Budgeting > Setup > Manage Datasets.
    
    In the list of datasets, the status of the dataset changes to **Not Created**.
    
6.  Check the **Select** box next to the dataset.
    
7.  Click **Submit**.
    
    In the list of datasets, the status of the dataset changes to **Created**.
    

You can click the created dataset to review or customize it. If you want to customize the dataset, refer to [Customizing an NSPB Sync Dataset](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0711120952.html) for information. If you want to export, review, or customize the hierarchy of metadata in the dataset, refer to [Dataset Settings](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0711095050.html).
