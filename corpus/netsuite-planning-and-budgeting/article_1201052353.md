Planning and Budgeting Sync lets you use post-processing plug-ins to process budget data imported into NetSuite from your Planning and Budgeting. To start implementing budget data import into NetSuite, you need to properly configure a new data integration record or business rule in your Planning and Budgeting.

For detailed instructions, see the following help topics:

-   To implement budget data import using a data integration record, see [Budget Data Import Using Data Exchange](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0427105403.html).
    
-   To implement budget data import using a business rule, see [Budget Data Import Using Business Rules](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_38172513936.html).
    

For general information about using post-processing plug-ins with Planning and Budgeting Sync, see [Post-Processing Plug-ins in Planning and Budgeting Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_5132559979.html).
