If you want to use NetSuite to upload saved search results directly to your Planning and Budgeting, you need to add the corresponding import job to NetSuite. Then, you can set up the import job as needed. The import job will run the saved search, create the CSV file, and upload the CSV file to the Inbox/Outbox Explorer in your Planning and Budgeting.

Note:

The maximum size of the CSV file to upload data to your Planning and Budgeting shouldn't exceed 10 MB. This limitation doesn't apply to metadata upload.

#### To add and set up an import job:

1.  Log in to NetSuite, and go to Planning & Budgeting > Jobs > Manage Jobs.
    
2.  On the **Planning & Budgeting Jobs** page, do one of the following:
    
    -   In the list of jobs, click **Edit** next to an import job of your choice.
        
    -   If you don't see the import job in the list, and you have the Administrator role, click the **Add Job** button, and follow steps 3 through 6 in [Adding a Job in NetSuite](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_160527233569.html).
        
3.  Click the **Job Parameters** subtab.
    
    The **Import Type** field indicates whether this job uploads data or metadata from the saved search results. For metadata, NSPB Sync includes the metadata hierarchy in the uploaded CSV file.
    
4.  From the **Data Source Type** dropdown list, select **Saved Search** or **Dataset** to load data from NetSuite to your Planning and Budgeting.
    
5.  From the **Data Source Name** dropdown list, select the saved search or dataset this import job should run. This list is populated based on the selected data source type.
    
6.  In the **Filename** field, enter the name of the CSV file that will be generated by the import job and stored in the Inbox/Outbox Explorer in your Planning and Budgeting account. The value must match exactly, including upper and lower case.
    
7.  In the **Dimension** field, enter the name of a dimension in your Planning and Budgeting that this metadata will be loaded to. The value must match exactly, including upper and lower case.
    
    Important:
    
    Follow the [Naming Restrictions](https://docs.oracle.com/cd/E57185_01/EALAG/esb_restricted_names.html) to make sure you don't use any of the restricted characters at the beginning of the dimension name. If a restricted character is used, you need to change the dimension name in your Planning and Budgeting.
    
8.  Check the **Refresh Cube** box if you want to force a cube refresh in your Planning and Budgeting.
    
9.  If you want to schedule the import job, click the **Schedule** subtab, and follow step 3 in [Scheduling a Job in NetSuite](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_160527228086.html).
    
10.  For optional setup of the import job, click the **Options** subtab.
     
     If you only want to upload the CSV file to your Planning and Budgeting without running the import job, check the **Upload Only** box.
     
11.  Click **Save**.
     

If an Import Data/Metadata job fails, you can view the latest error log. Go to Planning & Budgeting > Jobs > Manage Jobs, and click **Logs** next to a job in the Error execution status. Then, you can click the **Download** link to save the latest error log to disk.
