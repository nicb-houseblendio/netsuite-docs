Besides the saved searches in NetSuite, Planning and Budgeting Sync lets you use SuiteAnalytics datasets to load data and metadata from NetSuite to your Planning and Budgeting. To use SuiteAnalytics datasets with Planning and Budgeting Sync, you need to prefix each dataset with **\_nspb\_**. Every dataset the ID of which includes this prefix is then listed in Data Exchange. You can configure and call it from Data Exchange in the same way as you configure and call saved searches.

Note:

The filters you set on your datasets in NetSuite aren't available in Data Exchange.

Important:

Make sure that field relationships in dataset criteria don't include lengthy filter names exceeding 65 characters in a single line. Exceeding this character limit may cause issues when loading the datasets into Data Exchange during the initial setup. To prevent the data load issues, consider breaking down complex criteria into multiple smaller filters within your datasets.

Planning and Budgeting Sync includes predefined datasets that you can use to load metadata from NetSuite to your Planning and Budgeting. For information, see the following help topics:

-   [Supported Planning and Budgeting Sync Datasets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_29162330248.html)
    
-   [Managing the Planning and Budgeting Sync Datasets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_28162703900.html)
    
-   [Dataset Settings in Planning and Budgeting Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_94163304747.html)
    

For general information about using SuiteAnalytics datasets, see [Custom Workbooks and Datasets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1544122127.html).
