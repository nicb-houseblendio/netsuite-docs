As part of the budget data import implementation, you need to verify that the data integration record you created in [Creating a Data Integration Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0619041625.html) runs successfully in Data Exchange.

#### To run the created data integration: {#procedure_36174605814}

1.  In your Planning and Budgeting environment, click the Navigator icon ![This icon takes you to the main menu in your Oracle EPM Planning application.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuitePlanningandBudgeting/PlanningAndBudgetingSync/NSPBMenuIcon.png). Then, under Application, click **Data Exchange**.
    
2.  Locate the data integration record you created in [Creating a Data Integration Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0619041625.html), and then click the **Run** icon ![This launches the budget data import.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuitePlanningandBudgeting/PlanningAndBudgetingSync/PBSyncRunIcon.png).
    
3.  In the Run Integration popup window, make any necessary changes, and then click **Run**.
    
4.  If the data integration completes successfully, you can do any of the following:
    
    -   Go to the location in File Browser that you defined in [Creating a New Location in File Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_49172841084.html) to access the CSV file generated by this data integration. You can download the file and verify that the data format is correct.
        
    -   Run this data integration as a job from NetSuite. If the job runs successfully in NetSuite, Planning and Budgeting Sync downloads the CSV file from inbox in File Browser, and the post-processing plug-in processes the budget data in NetSuite. For information, see [Selecting a Plug-in for Data Processing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1201052013.html).
        

For general information and additional setup, see the Oracle Help Center topic [Launching Data Integration](https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/diepm/integrations_launch_100x6b39d94c.html).
