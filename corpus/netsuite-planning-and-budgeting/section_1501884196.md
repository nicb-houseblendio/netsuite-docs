This help topic summarizes the recent changes to the NSPB Sync SuiteApp. Here you may also find instructions on how to troubleshoot your issues, or what actions to take to ensure the integration works for you.

## Version 2023.2.04 {#subsect_0612015435}

### June 16, 2026 {#subsect_0612015517}

This release implements a security fix that restricts Suitelet access to the Administrator and NSPB Implementer roles.

## Version 2023.2.03 {#subsect_0206040715}

## February 18, 2025 {#bridgehead_0206040746}

This release fixes an issue where temporary saved searches were not removed after running the Import Data/Metadata job.

## Version 2023.2.02 {#subsect_0731081309}

## August 26, 2024 {#bridgehead_0731081322}

This release includes updates that make the NSPB Sync SuiteApp fully compatible with NetSuite 2024.2.

## Version 2023.2.01 {#subsect_1203938843}

## February 12, 2024 {#bridgehead_41204003351}

This release fixes an issue with a search request returning an invalid timeout response.

## Version 2023.2 {#subsect_27171827642}

## October 9, 2023 {#bridgehead_29172154819}

This version of the NSPB Sync SuiteApp lets you advance values of substitution variables to the next period or year on a button click. For configuration instructions, see [Enabling Automatic Update of Substitution Variables Values](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158160755033.html#subsect_34162126924).

Important:

To start using this feature, you need to re-enter the password you use to log in to your Planning and Budgeting environment. For instructions, see [Connection Settings](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160855050373.html).
