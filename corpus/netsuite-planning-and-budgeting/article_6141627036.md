Planning and Budgeting Financials has several features that let you create, manage, and analyze scenario planning details.

These features help you create and manage your scenario plans:

-   **Predictive Planning** - Use this feature to review and update scenario plans.
    
    For more information, see [Forecasting with Predictive Planning](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_7031622740.html).
    
-   **Grid Spread** - Use this feature to make new total entries or adjust existing totals in a form. The new value spreads back to fill the row's open periods.
    
    For more information, see [Scenario Planning with Grid Spread](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_2013453409.html).
    
-   **Version Builder** - Use this feature to create and manage multiple versions of a Forecast.
    
    For more information, see ['What-if' Planning With Version Builder](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_5144519873.html).
    
-   **Budget process** - Use this optional feature to complete your annual budgeting process.
    
    For more information, see [Budgeting Management Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_3141633609.html).
    

These features help you investigate and analyze your scenario plans:

-   **Drill Options** - Use this feature to investigate data by drilling down into the Account Details or through to the underlying NetSuite data. Drill options include drilling to Account details and drilling through to NetSuite.
    
    For more information, see [Investigating Data with Drill Options](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_7004007906.html).
    
-   **Smart View** - Use this feature to perform data analysis.
    
    For more information, see [Analyzing Data in Smart View](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_5032640042.html).
