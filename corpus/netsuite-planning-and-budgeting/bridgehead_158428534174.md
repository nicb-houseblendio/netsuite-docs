To use the Project metadata saved searches, go to the Lists subtab of the Permissions tab, and assign the Projects permission to your custom role. Refer to [Customizing the PBCS Integration Role](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_158456459598.html).

When the Project metadata saved search is called from Data Exchange, it returns the hierarchy of the project. The NSPB Sync SuiteApp supports the following Project metadata saved searches:

-   **Basic Projects**
    
    Basic projects are part of NetSuite. For information, see [Basic Projects Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1179020.html) in the NetSuite Help Center.
    
-   **Advanced Projects**
    
    To do advanced project tracking, you must purchase the Advanced Projects add-on from NetSuite. For information, contact your NetSuite Account Manager.
