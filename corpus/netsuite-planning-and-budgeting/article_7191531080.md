The Migration tool lets you perform lifecycle Management tasks within NetSuite Planning and Budgeting. From Migration, you can complete these tasks:

-   Manage backups and exports of snapshots with artifacts and your application data.
    
-   Migrate (export or import) snapshots and archives.
    
-   Set import options to control how data imports into an environment from uploaded files and snapshots.
    
-   Generate reports with information about the artifact migrations.
    

To open the Migration tool, click the Navigator icon ![Screenshot of the Navigator icon in NSPB](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuitePlanningandBudgeting/PlanningandBudgetingFinancials/AdminGuide/NSPBNavigatorIcon.png), and under Tools, select **Migration**.

For more information about tasks you can complete in each tab in Migration, see the following help topics from the Oracle Help Center:

-   In the **Categories** tab, you can create a backup of your entire environment or an export of specific artifacts.
    
    For more information, see [Back up Artifacts and Application](https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/epmss/export_dialog.html).
    
-   In the **Snapshots** tab, you can do the following activities:
    
    -   [Upload Archives to the Service](https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/epmss/lcm_upload_file.html)
        
    -   [Download Snapshots from an Environment](https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/epmss/lcm_download_file.html)
        
    -   [Delete Snapshots and Archives](https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/epmss/lcm_delete_file.html)
        
    -   [Repeat an Export Operation](https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/epmss/lcm_repeat_export.html)
        
    -   [Rename Snapshots and Archives](https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/epmss/lcm_rename.html)
        
    -   [Set Import Options](https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/epmss/lcm_import_options.html)
        
    -   [Import Artifacts and Application from a Snapshot](https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/epmss/lcm_import_artifact.html)
        
    -   [View the Artifact Modification History Report](https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/epmss/modifiedsince.html).
        
-   In the **Reports** tab, you can generate the following reports:
    
    -   **Migration Status** **\-** Shows information about the artifact migrations that were done in the service instance.
        
        For more information, see [Generating the Migration Status Report](https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/epmss/mig_stat_report.html).
        
    -   **Artifact Updates** - Shows information about updated artifacts.
        
    -   For more information, see [Generating the Artifact Updates Report](https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/epmss/lcm_artifac_updates.html).
        

For more information about using Migration, see the [Administering Migration](https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/epmss/index.html) guide in the Oracle Help Center.
