In Data Integration, update the load periods (start and end) for the **Pipeline\_Data\_Load** pipeline. This pipeline jobs loads transaction data from NetSuite into Planing and Budgeting Financials as a part of a scheduled data load process.

Note:

You need to update the Load periods one time annually at the start of the financial year.

#### To update the load periods for Pipeline\_Data\_Load:

1.  On your Planning and Budgeting Home page, click the **Application** card, then click **Data Exchange**.
    
2.  On the Data Integration page, in the search bar, enter **Pipeline\_Data\_Load**.
    
3.  Click **Pipeline\_Data\_Load**.
    
4.  Click the Edit Pipeline icon ![Edit Pipeline icon on a pipeline details page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuitePlanningandBudgeting/PlanningandBudgetingFinancials/AdminGuide/EditIconDI.png).
    
5.  Click the **Variables** tab.
    
6.  For the **Start Period** variable, in **Default Value**, enter the previous month. The start period should match the period in the NSP\_PER\_ActCurrMo substitution variable.
    
7.  Click **Save**.
    

Important:

After you update the parameters for the load periods, make sure you update the substitution variables.

For example, update **NSP\_PER\_PriorYr** to **FY24** and **NSP\_PER\_ActCurrYr** to **FY25**.

For more information about substitution variable values, see [Setting Up Values for Substitution and User Variables](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_8162312309.html).
