If you've created or customized datasets as described in the help topic [Managing the Planning and Budgeting Sync Datasets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_28162703900.html), you can view the datasets at NetSuite EPM > Planning and Budgeting > Manage Datasets. There you can also view all custom datasets that you've created in NetSuite for your Planning and Budgeting.

Note:

Every dataset the ID of which includes the **\_nspb\_** prefix, for example `custdataset_nspb_sync_item_new`, is listed in Data Exchange.

Important:

After you install Planning and Budgeting Sync, you should update IDs of existing datasets in your NetSuite account to include the **\_nspb\_** prefix:

-   For data datasets, place the new **custdataset\_nspb\_** prefix and the existing prefixes on an allowlist in NetSuite EPM Connector. For instructions, see [Data Source Allowlist](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_9115749534.html).
    
-   If you use the \_nspbcs\_ prefixes in your Planning and Budgeting environment for metadata datasets:
    
    -   Update dataset ID prefixes to include **custdataset\_nspb\_** in place of custdataset\_nspbcs\_. See [Metadata Datasets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0712061757.html#subsect_0712062743).
        
    -   Update data source mappings for existing metadata datasets to include **\_nspb\_** in place of \_nspbcs\_. For instructions, see [Change Data Source Mappings for Metadata Searches and Datasets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0712061757.html#subsect_0712062938).
        

On each dataset in the list, you can take any of the following actions:

-   You can customize the hierarchy of metadata you want to export in the dataset.
    
    See [Customization of Planning and Budgeting Sync Datasets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_11163339421.html).
    
-   You can manually export and review the hierarchy of metadata in the dataset.
    
    See [Manual Export of Dataset Metadata in Planning and Budgeting Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_37163355131.html).
    
-   You can click the dataset to open and customize it directly in NetSuite.
    
    For instructions on how you can customize the dataset, see [Customizing a Created Planning and Budgeting Sync Dataset](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_36163231143.html).
