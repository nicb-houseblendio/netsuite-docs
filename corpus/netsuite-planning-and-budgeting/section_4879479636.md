After installing the NSPB Sync SuiteApp, a user with the Administrator role needs to perform the following tasks:

1.  Set up a password for file encryption.
    
    See [Setting Up a Password for File Encryption](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4879518470.html).
    
2.  Create an integration user with proper permissions.
    
    See [Setting Up the Integration User](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_1489167953.html).
    
3.  Set up token-based authentication.
    
    See [Setting Up Token-based Authentication](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161942084079.html).
    
4.  Set up the connection to your Planning and Budgeting.
    
    See [Setting Up the Planning and Budgeting Connection](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158073354875.html).
    
5.  Schedule the required NSPB Sync script deployments.
    
    See [Scheduling Script Deployments for NSPB Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160829049734.html).
