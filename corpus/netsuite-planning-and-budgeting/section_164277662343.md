You can export all NSPB Sync configurations or you can select specific configurations you want to export. The following configurations can be exported:

| Configuration Label | Description |
| --- | --- |
| Jobs | The jobs configured in Data Exchange and your Planning and Budgeting and added in NetSuite. See [Manage Jobs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160461398107.html). |
| Substitution Variables | The substitution variables configured in your Planning and Budgeting and categorized in NetSuite. See [Substitution Variables](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158160755033.html). |
| Account Metadata Hierarchy | The customized upper-level members of account metadata. See [Account Metadata Hierarchy](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158340798391.html). |
| Form/Dashboard | The forms and dashboards configured in your Planning and Budgeting and accessed from NetSuite. See [Forms/Dashboards](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160510908737.html). |
| Saved Search Settings | Customizations to the Planning and Budgeting saved searches that you added in NetSuite. See [Saved Search Settings](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160628719006.html). |
| Account Balance Portlet Settings | The custom record type setup for the Account Balance portlet. See [Planning & Budgeting Account Balance Portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162563948204.html). |
| Connection Settings | The connection settings to connect you to the Planning and Budgeting environment from NetSuite, except the username and the password. See [Connection Settings](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160855050373.html). |
| Other Settings | Other settings related to NSPB Sync SuiteApp. |

#### To export NSPB Sync configuration:

Note:

If the export contains no configuration, you receive an error message indicating that at least one configuration is required for the export.

1.  In NetSuite, go to Planning & Budgeting > Tools > Import/Export Configuration.
    
2.  Choose the **Export** radio button.
    
3.  Click the **Configurations to Export** subtab and do any of the following:
    
    1.  In the **Select** column, check the box next to every configuration you want to export.
        
    2.  Click the **View** link for every configuration page you want to go to in the NetSuite UI.
        
4.  Click the **Logs** subtab to view the following information about the exported configuration:
    
    -   Date
        
    -   Operation
        
    -   Status
        
    -   Options
        
    -   Details
        
    -   Filename
        
    
    Click the **View** link to see the details of the log you want to review.
    
5.  Click **Submit**.
