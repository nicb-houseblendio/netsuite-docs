After integration, make sure that the **Default Point POV Period** fields in the system and application settings have valid accounting period values. The system and application settings should already be set up in Data Management.

For more information about setting up system or application settings, see [Predefining a List of Profiles](https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/erpia/predefining_a_list_of_profiles.html).

#### To verify the default POV Period for the system and application settings: {#procedure_0817020247}

1.  Click the Navigator icon ![Screenshot of the Navigator icon in NSPB](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuitePlanningandBudgeting/PlanningandBudgetingFinancials/AdminGuide/NSPBNavigatorIcon.png), and under Integration, select **Data Management**.
    
2.  Click the **Setup** tab.
    
3.  Under Configure, click **System Settings**.
    
4.  In the **Profile Type** dropdown list, select **POV**.
    
5.  Make sure there's a valid accounting period value for **Default POV Period**.
    
    ![A portion of the System Settings page in Data Management with the Default POV Period setting outlined in red.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuitePlanningandBudgeting/PlanningandBudgetingFinancials/AdminGuide/DMSystemSettingsDefaultPOVPeriod.png)
6.  Under Configure, click **Application Settings**.
    
7.  In the **Target Application** dropdown list, select **NetSuite**.
    
8.  Make sure there's a value for **Default POV Period**, and it should be the current reporting month.
    
    ![A portion of the Application Settings page in Data Management with the Default POV Period setting outlined in red.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuitePlanningandBudgeting/PlanningandBudgetingFinancials/AdminGuide/DMApplicationSettingsDefaultPOVPeriod.png)
