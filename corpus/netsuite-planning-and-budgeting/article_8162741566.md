Use the OpEx Detail form to update departmental Forecast amounts by Account. If needed, you can add (or remove) detail lines for an Account to enter detailed operating expense Forecasts by Account and in the selected Currency.

Important:

Only accounts with Forecast or Actual data appear in the OpEx Detail form, so make sure the account has one of these before you add detail lines.

If you want to add detail lines to an account with only Forecast data (and no Actuals), first run an aggregation to the Income Statement, then add the detail lines. This ensures the detail lines appear for the account in the OpEx Detail form.

Note:

On the OpEx by Dept form, you can enter single Forecast values by Account. On the OpEx Detail form, you can enter detailed Forecast values.

Read these topics to learn more about using the OpEx Detail form:

-   [Updating Departmental Forecast Amounts](#subsect_37113423450)
    
-   [Adding or Removing Detail Lines](#subsect_33113242294)
    

## Updating Departmental Forecast Amounts {#subsect_37113423450}

Use the OpEx Detail form to update departmental Forecast amounts for each detail line.

#### To update departmental Forecast amounts: {#procedure_0817104640}

1.  From the Home page, click the **OpEx** card.
    
2.  To open OpEx Planning forms, click the **1** tab on the left.
    
3.  Click **OpEx Detail**.
    
4.  In the Point of View, choose a Version, Subsidiary, Currency, and Department.
    
5.  To update top-level members with the adjusted data in input currency, right-click the data grid and select **Aggregate to Income Statement**.
    
6.  Enter Forecast values in the open (white) cells.
    
7.  (Optional) In the third column, click an open cell to enter comments. You can add comments only at the detail level.
    
8.  Click **Save**.
    
9.  (Optional) To update the relevant financial statements in both input and reporting currencies:
    
    1.  Go to the Home page and click the **Rules** card.
        
    2.  Beside the ruleset **NFS\_All Accts Forecast Data Refresh**, click the Launch arrow.
        

## Adding or Removing Detail Lines {#subsect_33113242294}

You can add detail lines for each Account to enter detailed operating expense Forecasts by Account and in the selected Currency. You can also remove detail lines that you don't need.

#### To add OpEx Forecast detail lines: {#procedure_0721043555}

1.  In the first column, right-click the cell for the relevant Account and select **Add Detail Lines**.
    
2.  In the popup window, enter the number of detail lines you want to add.
    
3.  Click **Launch**.
    

#### To remove OpEx Forecast detail lines: {#procedure_0817104958}

1.  Click the detail line that you want to remove under the **Amount with Details** column to highlight the row.
    
    Right-click the cell under the **Amount with Details** column, and select **Remove Detail Lines**.
    
2.  In the popup window, make sure that the selected detail line is the one you want to remove.
    
3.  Click **Launch**.
