By default, when a metadata saved search is run, a full metadata hierarchy is built in the saved search result. If any parent is missing in your cloned saved search, it is added in the hierarchy based on the default metadata saved search.

You can choose to skip running the default metadata saved search and use only the data from your cloned saved search to build the hierarchy. This enables you to:

-   Decrease the volume of the data load.
    
-   Use only a subset of data in the saved search.
    

#### To skip running the default metadata saved search: {#procedure_0725105246}

1.  Go to Planning & Budgeting > Setup > Saved Search Settings.
    
2.  Click **Customize** next to the saved search of your choice.
    
3.  Under the Parent Level Transaction section, check the **Return Hierarchy Based Only on Data in This Search** box.
    
    -   The box is clear by default.
        
    -   If a parent is missing, the top-level parent is used. Therefore, make sure your saved search contains all data that you need to build the hierarchy.
        
    -   NSPB Sync doesn't support using the box and the **Filter** dropdown list at the same time. If you try to save a search with the box checked and a filter selected, you receive an error message.
        
    -   The box is not available for Accounts and Customer Project metadata saved searches.
        
4.  Click **Save**.
