The integration artifacts for your Planning and Budgeting Financials are included in **NSPB-Financials\_integration\_artifacts\_202x.x.zip**. The artifacts contain all the default configurations for Data Exchange to load the saved searches you created in NetSuite. See [Creating a Planning and Budgeting Sync Saved Search](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_42135416383.html).

Note:

In Planning and Budgeting, the integration artifacts are called Lifecycle Management (LCM) imports.

You need to download the integration artifacts from NetSuite, and import them to your Planning and Budgeting Financials. Before downloading and importing the integration artifacts, see [Guidelines for Importing Integration Artifacts to Planning and Budgeting Financials](#subsect_1105023805).

## Guidelines for Importing Integration Artifacts to Planning and Budgeting Financials {#subsect_1105023805}

Before downloading and importing the integration artifacts, review the following guidelines:

-   The default setup is compatible only with Planning and Budgeting Financials. To use the integration artifacts with other NetSuite Planning and Budgeting editions, adjust the default values to match those in your specific Planning and Budgeting edition.
    
-   The downloaded ZIP file doesn't contain configurations for Data Exchange to load demand forecasting saved searches. For a list of the saved searches, see the **NSPB Financials - Demand Forecasting Saved Searches** group in the help topic [Saved Searches for Planning and Budgeting Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_4153122253.html).
    
-   Before importing the integration artifacts to your Planning and Budgeting Financials, you need to enable Planning and Budgeting Financials. For information, see [Enabling Planning and Budgeting Financials](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_165096987704.html).
    
-   If you modify the saved searches provided for Planning and Budgeting Financials with this SuiteApp, make corresponding updates in Data Exchange.
    
-   When a new release of Planning and Budgeting Sync introduces a ZIP file with additional integration artifacts, these artifacts aren't automatically updated in your Planning and Budgeting Financials. To incorporate these new artifacts, manually download the latest ZIP file and upload it to your Planning and Budgeting Financials. Alternatively, you can configure Data Exchange manually to include the new artifacts.
    
    Warning:
    
    Uploading the ZIP file after finishing the implementation may overwrite your customizations in Data Exchange, potentially disrupting your integration. Therefore, perform this action only in a test environment or during the initial implementation phase. For information about how to leverage new features while keeping your customized artifacts, see the Oracle Help Center topic [Updating Financials](https://docs.oracle.com/en/cloud/saas/planning-budgeting-cloud/epbca/fin_updating_artifacts_102x656ceaab.html?utm_source=openai).
    

#### To download and import the integration artifacts:

1.  In NetSuite, go to NetSuite EPM > Planning and Budgeting > Integration Artifacts.
    
2.  Click the **Packages** subtab.
    
3.  Click the **Download** button to save the configuration package of your choice to disk.
    
4.  In your Planning and Budgeting Financials application, click the Navigator icon ![The Menu icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuitePlanningandBudgeting/PlanningAndBudgetingSync/NSPB-SP_MenuIcon.png), and select **Migration**.
    
5.  Click the **Snapshots** tab.
    
6.  Click **Upload** to locate the ZIP file on your disk.
    
7.  Select the ZIP file, and click **Open**. Then, click **Upload**.
    
8.  If a popup window confirms that the file has been successfully uploaded, click **OK** to complete the upload process.
    
9.  For the uploaded file, in the **Actions** column, click the ellipsis icon ![If clicked, the icon displays a list of actions to select from.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuitePlanningandBudgeting/PlanningAndBudgetingSync/FNsEllipsisIcon.png). Then, click **Import**.
    
10.  Click **OK** to proceed with the import.
     
11.  In the **Migration Status Report** window, refresh and review the migration progress until it completes. Then, close the window.
     
12.  To see the list of the artifacts you have imported, click the Navigator icon ![The Menu icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuitePlanningandBudgeting/PlanningAndBudgetingSync/NSPB-SP_MenuIcon.png), and select **Data Exchange**.
