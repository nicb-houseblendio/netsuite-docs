Besides the saved searches in NetSuite, NSPB Sync lets you use SuiteAnalytics workbooks and datasets to load data and metadata from NetSuite to your Planning and Budgeting. To use SuiteAnalytics workbooks and datasets with NSPB Sync, you need to prefix each workbook and dataset with **\_nspbcs\_**. Every workbook and dataset the ID of which includes this prefix is then listed in Data Exchange. You can configure and call it from Data Exchange in the same way as you configure and call saved searches.

If you want to create workbooks or datasets for NSPB Sync, read the following additional information:

-   NSPB Sync doesn't support multiple table views for workbooks. You can use one table view for each workbook created for NSPB Sync.
    
-   The filters you set on your datasets and workbooks in NetSuite are not available in Data Exchange.
    

NSPB Sync includes predefined datasets that you can use to load metadata from NetSuite to your Planning and Budgeting. For information, refer to the following help topics:

-   [Supported NSPB Sync Datasets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0208074641.html)
    
-   [Manage Datasets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0711110650.html)
    
-   [Dataset Settings](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0711095050.html)
    

For general information about using SuiteAnalytics workbooks and datasets, see [Custom Workbooks and Datasets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1544122127.html).
