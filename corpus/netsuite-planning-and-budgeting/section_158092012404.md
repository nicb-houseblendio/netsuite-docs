If you have the Administrator role, the integration lets you use NetSuite to access exported files stored in the File Browser's outbox in your Planning and Budgeting account. For information, refer to the Oracle Help Center topic [Using the File Browser](https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/diepm/integrations_file_browser_104x9f4f8316.html).

To browse the files, log in to NetSuite, and go to Planning & Budgeting > Tools > File Browser. NetSuite displays a list of exported data files prefixed with **nspbcs\_**.

To save a file to your computer, click **Download** next to the file. This way you can use NetSuite to download the exported Planning and Budgeting files one by one without navigating to the File Browser's outbox in your Planning and Budgeting. You can then use the downloaded files for import to NetSuite.

To delete a file from the list of exported data files, click **Delete** next to the file. This way you can use NetSuite to delete the exported Planning and Budgeting files one by one without navigating to the File Browser's outbox in your Planning and Budgeting. When you delete a file from the list in NetSuite, you delete the file from the list in the File Browser's outbox.

To reload the list of exported data files, click **Refresh File List**.
