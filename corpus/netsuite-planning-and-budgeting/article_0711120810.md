If you want to use a dataset included in NSPB Sync, you need to create it in NetSuite.

Note:

After you create a dataset, you can share it with other users or roles that need to access the dataset. For information about sharing datasets, see [Accessing and Sharing Workbooks and Datasets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1531766899.html).

#### To create an NSPB Sync dataset: {#procedure_39142501648}

1.  In NetSuite, go to Planning & Budgeting > Setup > Manage Datasets.
    
2.  Check the **Select** box next to the dataset you want to create.
    
    Note:
    
    You can only select a dataset that is in the **Not Created** status.
    
3.  Click **Submit**.
    
    In the list of datasets, the status of the dataset changes to **Created**.
    

You can click the created dataset to review or customize it. If you want to customize the dataset, refer to [Customizing an NSPB Sync Dataset](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0711120952.html) for information. If you want to export, review, or customize the hierarchy of metadata in the dataset, refer to [Dataset Settings](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0711095050.html).
