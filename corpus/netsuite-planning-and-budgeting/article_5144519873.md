You can use Version Builder to create and manage multiple versions of a Forecast. To use Version Builder, make sure the Version Builder feature is enabled. For more information, see the help topic [Enabling Planning and Budgeting Financials](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_165096987704.html) from the Planning and Budgeting Financials Integration Guide.

Note:

It is best practice to let only users with the Administrator role and budget owners use Version Builder.

Version Builder lets you:

-   Model different possibilities, such as Best Case, Worst Case, and What-if scenarios.
    
-   Manage how you share your plan data with internal and external stakeholders.
    
-   Have multiple iterations on a plan.
    

You can create a new Forecast version, make adjustments to an existing version, or assign a new alias to an existing version.

This topic covers how to use Version Builder for the following tasks:

-   [Creating a New Forecast Version](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0826030120.html)
    
-   [Modifying an Existing Forecast Version](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0826030203.html)
    
-   [Assigning a New Alias to an Existing Forecast Version](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0826030319.html)
    

Note:

In some cases, Version Builder can take a while to run.

Note:

After you create a new version, adjust an existing version, or assign a new alias to an existing version, you should run a database refresh. For more information, see [Refreshing Application Databases](https://docs.oracle.com/en/cloud/saas/planning-budgeting-cloud/pfusa/refreshing_application_databases.html) in the Oracle Help Center.
