To make sure you've configured Planning and Budgeting Sync properly, you can use a checklist of tasks to quickly set up any missing features. To access the checklist, go to NetSuite EPM > Planning and Budgeting > Configuration Checklist. You need to complete each task on the checklist. You can also use this checklist to validate your current Planning and Budgeting Sync setup.

For details on the checklist, refer to the following table:

| NetSuite Column Label | Description |
| --- | --- |
| Feature | The setup of the Planning and Budgeting Sync features includes the following configuration tasks:
-   To set up the connection from NetSuite to Planning and Budgeting, see the following help topics:
    -   [Setting Up the Connection to Planning and Budgeting](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_4144843069.html)
    -   [Using OAuth 2.0 to Connect to Planning and Budgeting](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1121101959.html)
-   To set up and schedule the required script deployments, see [Scheduling Script Deployments for Planning and Budgeting Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_150410060.html).
-   To configure the Planning and Budgeting Financials features, see [Setting Up Default Configurations for Planning and Budgeting Financials](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_36142750338.html).
-   To set up the parent hierarchy of account metadata, see [Account Metadata Hierarchy in Planning and Budgeting Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_7121032309.html).
-   To review how NetSuite SuitePeople Payroll data is grouped by workforce categories, see [Viewing NetSuite SuitePeople Payroll Data by Category](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_6161906576.html).

 |
| Status | The configuration status for each feature can be one of the following:

-   If configured correctly, the feature is denoted with a green check mark icon ![A green tick icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuitePlanningandBudgeting/PlanningAndBudgetingSync/NSPBGreenTick.png).
-   If not configured, or configured incorrectly, the feature is denoted with a red cross icon ![A red cross icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuitePlanningandBudgeting/PlanningAndBudgetingSync/NSPBRedCross.png).
-   Features where you should check the configuration are denoted with a dash ![A dash icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuitePlanningandBudgeting/PlanningAndBudgetingSync/NSPBDash.png).

 |
| Link | Clicking the **View** link for each feature takes you to the NetSuite page where you can configure the feature. |
| Instruction | This column shows relevant information about what you need to do to configure a particular Planning and Budgeting Sync feature properly. |

For your convenience, you can access the checklist also through the [Planning and Budgeting Sync Checklist Portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1114024313.html).
