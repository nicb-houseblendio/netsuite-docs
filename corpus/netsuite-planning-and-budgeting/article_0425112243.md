If you have the Administrator role, you can complete a full restructure of a database (also called block storage cube) to reduce or eliminate fragmentation. This process also removes empty blocks.

Note:

It's best practice to only let users with the Administrator role complete the restructure of a database.

You can restructure a database by using either the Calculation Manager or Jobs Scheduler.

Tip:

To keep your database from getting fragmented, use Jobs Scheduler to run restructures regularly.

Schedule these restructures when users aren't using NetSuite Planning and Budgeting because this task can take a long time and use a lot of resources.

Important:

You can't undo this action.

#### To restructure a database by using Calculation Manager: {#procedure_0706073811}

1.  From the Home page, click the Navigator icon ![Navigator Icon in NSPB](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuitePlanningandBudgeting/PlanningandBudgetingFinancials/AdminGuide/NSPBNavigatorIcon.png).
    
2.  Under Create and Manage, click **Rules**.
    
    Note:
    
    You might need to turn off any ad blockers plug-ins to see the Calculation Manager window.
    
3.  In the Calculation Manager window, under the **System View** tab, click Actions > Database Properties.
    
4.  **Database Properties** opens in a new tab. Under Enterprise View, expand **Planning**, then **NetSuite**.
    
5.  Right-click a database, and then click **Restructure Database**.
    
6.  Click **OK**.
    

#### To restructure a database by using Jobs Scheduler: {#procedure_0706073907}

1.  From the Home page, click the Navigator icon ![Navigator Icon in NSPB](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuitePlanningandBudgeting/PlanningandBudgetingFinancials/AdminGuide/NSPBNavigatorIcon.png).
    
2.  Under Application, click **Jobs**.
    
3.  Click **Schedule Jobs**.
    
4.  Scroll down the list on the left pane and select **Restructure Cube**.
    
5.  Choose either **Run Now** or **Schedule starting from**.
    
6.  If you chose **Schedule starting from**:
    
    1.  Select a starting date, time, and time zone.
        
    2.  Enter a name for this job and a set how often it should run.
        
    3.  (Optional) Check **End Date** if you want to set when to end the job, and then select an end date and time.
        
7.  Click **Next**.
    
8.  In the **Cube** field, select a database to restructure.
    
9.  Click **Next**.
    
10.  Review your choices on the Review page, then click **Finish**.
