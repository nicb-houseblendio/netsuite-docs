The Planning and Budgeting Sync SuiteApp includes predefined saved searches that you can use to load metadata from NetSuite to your Planning and Budgeting. You can access the saved searches at NetSuite EPM > Planning and Budgeting > Manage Saved Searches > Create Default Saved Searches. The metadata saved searches are listed in the following groups:

-   **NSPB - Metadata Saved Searches**
    
    The table below shows the names and IDs of the saved searches included in this group.
    
    Note:
    
    Make sure the IDs of the cloned saved searches start with the following prefixes. The cloned saved searches shouldn't use any of these prefixes as their IDs.
    
    | **Saved Search Name** | **Saved Search ID** |
    | --- | --- |
    | NSPB Sync (Metadata) Balance Sheet Accounts | customsearch\_nspb\_sync\_acbs |
    | NSPB Sync (Metadata) Class | customsearch\_nspb\_sync\_clss |
    | NSPB Sync (Metadata) Customer | customsearch\_nspb\_sync\_cust |
    | NSPB Sync (Metadata) Customer Project | customsearch\_nspb\_sync\_cprj |
    | NSPB Sync (Metadata) Department | customsearch\_nspb\_sync\_dept |
    | NSPB Sync (Metadata) Employee | customsearch\_nspb\_sync\_emp |
    | NSPB Sync (Metadata) Income Statement Accounts | customsearch\_nspb\_sync\_acis |
    | NSPB Sync (Metadata) Item | customsearch\_nspb\_sync\_item |
    | NSPB Sync (Metadata) Location | customsearch\_nspb\_sync\_loc |
    | NSPB Sync (Metadata) Project | customsearch\_nspb\_sync\_prj |
    | NSPB Sync (Metadata) Subsidiary | customsearch\_nspb\_sync\_sub |
    | NSPB Sync (Metadata) Vendor | customsearch\_nspb\_sync\_vend |
    
-   **NSPB Financials - Metadata Saved Searches**
    
    The table below shows the names and IDs of the saved searches included in this group.
    
    Note:
    
    Make sure the IDs of the cloned saved searches start with the following prefixes. The cloned saved searches shouldn't use any of these prefixes as their IDs.
    
    | **Saved Search Name** | **Saved Search ID** |
    | --- | --- |
    | NSPB (Admin) FIN Cube Refresh | customsearch\_nspb\_cube\_refresh\_fn |
    | NSPB (Metadata) FIN Balance Sheet Accounts | customsearch\_nspb\_sync\_acbs\_fn |
    | NSPB (Metadata) FIN Classes | customsearch\_nspb\_sync\_clss\_fn |
    | NSPB (Metadata) FIN Currencies | customsearch\_nspb\_sync\_currencies\_fn |
    | NSPB (Metadata) FIN Customers | customsearch\_nspb\_sync\_cust\_fn |
    | NSPB (Metadata) FIN Departments | customsearch\_nspb\_sync\_dept\_fn |
    | NSPB (Metadata) FIN Income Statement Accounts | customsearch\_nspb\_sync\_acis\_fn |
    | NSPB (Metadata) FIN Items | customsearch\_nspb\_sync\_item\_fn |
    | NSPB (Metadata) FIN Locations | customsearch\_nspb\_sync\_loc\_fn |
    | NSPB (Metadata) FIN Subsidiaries | customsearch\_nspb\_sync\_sub\_fn |
    | NSPB (Metadata) FIN Vendors | customsearch\_nspb\_sync\_vend\_fn |
    

To use the metadata saved searches for your integration with Planning and Budgeting, you need to create them in NetSuite. For information, see [Creating a Planning and Budgeting Sync Saved Search](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_42135416383.html).

When you clone any of these metadata saved searches in NetSuite, follow instructions in the help topic [Customizing a Planning and Budgeting Sync Saved Search](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_98174727806.html).

In addition to the metadata saved searches that are included in the SuiteApp, you can manually create Custom Segment metadata saved searches in NetSuite. See [Custom Segment Metadata](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1109040522.html).
