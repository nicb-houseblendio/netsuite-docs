Data is stored and updated in cubes. You should refresh the cube (also called refreshing the database) whenever you make changes so that those changes go to the relevant cubes. This applies to:

-   Changes to the metadata.
    
-   Changes to the configuration of the application.
    
    For example, changes to the order of the Dimensions or to the settings of a dimension, or adding a new custom dimension.
    
-   Updates to any substitution variables that are used in any member formulas.
    

You can refresh the cube from different areas in the system, including through Smart View. The following procedure describes one way to refresh the database in Planning and Budgeting.

Tip:

You should back up your application before you refresh a cube. A cube refresh recreates the outline for all cubes in your application based on the current metadata definition.

#### To perform a cube refresh: {#procedure_0907115037}

1.  Click the Navigator icon ![Screenshot of the Navigator icon in NSPB](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuitePlanningandBudgeting/PlanningandBudgetingFinancials/AdminGuide/NSPBNavigatorIcon.png), and then under Create and Manage, select **Dimensions**.
    
2.  Click **Actions**, and select **Refresh Database**.
    
3.  A warning message appears. Click **Refresh**.
    
4.  Wait for the refresh to finish, then click **Finish**. Or, click **Run in Background**.
