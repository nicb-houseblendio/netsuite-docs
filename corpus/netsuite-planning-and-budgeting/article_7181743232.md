The Planning and Budgeting Sync SuiteApp enables you to extract accounting reports from NetSuite searches and use them in your Planning and Budgeting application in Oracle Cloud Enterprise Performance Management (EPM).

Through the use of Data Exchange in your Planning and Budgeting, you can run searches defined in NetSuite and use the results in your Planning and Budgeting.

For information about Planning and Budgeting, and about using Data Exchange for the integration with NetSuite, see the following Oracle Help Center topics:

-   [Oracle EPM Planning](https://docs.oracle.com/en/cloud/saas/planning-budgeting-cloud/index.html)
    
-   [Oracle NetSuite Planning and Budgeting](https://docs.oracle.com/en/cloud/saas/netsuite-planning-budgeting/index.html)
    
-   [Administering Data Integration](https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/diepm/epm_coe_guide.html)
    

For information about how you can install and configure Planning and Budgeting Sync, and about the functionality of Planning and Budgeting Sync, see [Planning and Budgeting Sync Installation and Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_6095135623.html).

For information about changes to the Planning and Budgeting Sync SuiteApp with each release, see [Planning and Budgeting Sync Release Notes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_100535233.html).
