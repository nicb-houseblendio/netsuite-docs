The navigation flow determines which clusters, cards, and forms you can access. If you're assigned to more than one navigation flow, you can switch between them. To change your navigation flow, click the Navigation Flow icon ![Navigation Flows icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuitePlanningandBudgeting/PlanningandBudgetingFinancials/AdminGuide/NSPBNavigationFlowsIcon.png) next to your user name on the Home page, and select a different navigation flow. The Home page will show the clusters and cards for the navigation flow that you select.

You can choose which clusters and cards show up on the Home page by configuring your navigation flow. For more information, see [Managing Navigation Flows](https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/cgsad/3_manage_cross_app_nav_flow.html) in the Oracle Help Center.

If you have the Administrator role, then you can access extra administrative tasks and tools that aren't on the Home page by going to the Navigator Menu. For example, you can access Data Exchange and additional tools that are reserved for advanced users with the Administrator role. To open the Navigator Menu, click the Navigator icon ![Navigator icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuitePlanningandBudgeting/PlanningandBudgetingFinancials/AdminGuide/NSPBNavigatorIcon.png) in the top left of the Home page.
