User variables act as filters in your application so you focus only on certain members. The User Variables tab shows the user variables set by the Administrator and the members currently selected for each variable.

Before you can open a form that uses a user variable, you need to assign a value to that user variable. For example, if a form has a user variable for Departments on the rows, you'll have to assign a value for that user variable. Additionally, you can limit the number of rows on the form by selecting a member for the user variable. For example, for the Department user variable, select the Sales member. After, you can select another member for Department, such as Marketing, and the form will show Marketing Departments.

Note:

For the initial setup, best practice is to set the **Set Version** user variable to **NSP\_Base**.

#### To update user variables: {#procedure_0930111251}

1.  From the Planning and Budgeting Home page, go to Tools > User Preferences.
    
2.  Click the **User Variables** tab.
    
3.  Click the Member Selector icon ![Member Selector icon.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuitePlanningandBudgeting/PlanningandBudgetingFinancials/UserGuide/NSPBMemberSelectorButtonIcon.png) next to the member you want to change.
    
    You can also enter a member name directly in the **Member** column for the dimension.
    
4.  In the Select a Member window, select the member you want.
    
    You can use the search field to find the member.
    
5.  Click **OK**.
    
6.  Click **Save**.
