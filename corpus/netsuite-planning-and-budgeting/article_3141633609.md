The Budget process is an optional feature in NetSuite Planning and Budgeting Financials that lets you use Budget-specific tools, forms, and trends. These resources help you complete your annual budgeting process in the application. You can also work on the Budget without disrupting other users who are working on the Forecast.

Important:

To start using the Budget tools, complete these prerequisite steps:

-   Make sure you've enabled both the Financials module (if you haven't already done so) and the Budget process feature. For more information, see [Enabling Planning and Budgeting Financials](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_165096987704.html).
    
-   After you enable the Budget process, set the budget-specific substitution variable and user variables. For more information, see [Setting Up Values for Substitution and User Variables](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_8162312309.html).
