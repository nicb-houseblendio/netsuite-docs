If you have the Administrator role, you can install the NSPB Sync SuiteApp.

#### To install the NSPB Sync SuiteApp:

1.  Enable all required features. See [Required Features for Installing the NSPB Sync SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4882113016.html).
    
2.  Go to _Customization > SuiteBundler > Search & Install Bundles_.
    
3.  In the Keywords box, enter the bundle ID or name:
    
    -   Bundle ID: **168463**
        
    -   Bundle name: **NSPB Sync**
        
4.  Click **Search**.
    
5.  Click the link for the NSPB Sync SuiteApp.
    
6.  On the Bundle Details page, click **Install**.
    
7.  On the Preview Bundle Install page, review the list of objects that will be installed, and click the **Install Bundle** button.
    

For general information about installing, updating and uninstalling SuiteApps, see [Installing a Bundle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3395142.html).
