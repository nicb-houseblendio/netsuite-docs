The NSPB Sync SuiteApp includes the following predefined metadata datasets:

-   NSPB (Metadata) Subsidiary
    
-   NSPB (Metadata) Item
    
-   NSPB (Metadata) Vendor
    
-   NSPB (Metadata) Location
    
-   NSPB (Metadata) Class
    
-   NSPB (Metadata) Department
    
-   NSPB (Metadata) Customer
    
-   NSPB (Metadata) Project
    
-   NSPB (Metadata) Customer Project
    
-   NSPB (Metadata) Employee
    
-   NSPB (Metadata) Income Statement Accounts
    
-   NSPB (Metadata) Balance Sheet Accounts
    

If you have the Administrator role, you can create, review, or customize the datasets as described in help topics [Manage Datasets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0711110650.html) and [Dataset Settings](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0711095050.html).
