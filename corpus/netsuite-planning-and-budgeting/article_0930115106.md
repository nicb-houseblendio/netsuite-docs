In the Reports tab, set the preferences for how reports are shown.

From the Planning and Budgeting Home page, go to Tools > User Preferences, and click the **Reports** tab. On this tab, you can set the preferences described in the following table. There are two subtabs on this page:

-   Reports (for next-generation reports)
    
-   Financial Reports (for financial reporting)
    

When you're done setting your preferences, click **Save**.

| Field Name | Function |
| --- | --- |
| **Reports tab** |
| Preview POV | Check this box to enable report previews. If you enable it, click the Run Report icon ![Run Report icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuitePlanningandBudgeting/PlanningandBudgetingFinancials/UserGuide/RunReportIcon.png) to open or preview a report and refresh the data. |
| Unit of Measurement | Select **Inch** or **Centimeter** as the unit of measurement. |
| **Financial Reports tab** |
| Annotation Printing Preferences | Click this button to define how to print annotations in a report, and then click **OK**. |
| Merge Equivalent Prompts | Check this box to respond only one time or to respond consecutively to repeated prompts and variables. |
| Show Annotations | Check this box to include annotations in the report. |
| **Query-Ready Export** |
| Export Mode | Choose how reports are exported to Excel:
-   **Smart View** - Exports the report to Oracle Smart View for Office. To use this option, you need to install Smart View. See [Working with Planning Data in Excel](https://docs.oracle.com/en/cloud/saas/planning-budgeting-cloud/pfusu/working_with_application_data_in_excel.html#f_basics_data_69).
-   **Excel Grid** - Opens the exported report in Excel, but without the Smart View connection. If you choose this option, you need to choose the **Export To** option.
-   **Disabled** - Hides the query-ready link when the report appears by using the HTML preview.

 |
| Export To | Choose how reports are exported to Excel:

-   **New Worksheet** - Opens the exported report as a new sheet in an existing Excel workbook.
-   **New Workbook** - Opens the exported report as **sheet1** in a new Excel workbook.

 |
