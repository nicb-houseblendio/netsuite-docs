NSPB Sync lets you use post-processing plug-ins to process budget data imported into NetSuite from your Planning and Budgeting. To start implementing budget data import into NetSuite, you need to properly configure a new data load rule or business rule in your Planning and Budgeting.

For detailed instructions, see the following help topics:

-   To implement budget data import using a data load rule, see [Budget Data Import Using Data Exchange](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_40152802597.html).
    
-   To implement budget data import using a business rule, see [Budget Data Import Using Business Rules](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0419024849.html).
    

For general information about using post-processing plug-ins with NSPB Sync, see [Using Post-Processing Plug-ins with NSPB Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_160527537382.html).
