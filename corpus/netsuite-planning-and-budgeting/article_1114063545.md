Use Data Management to update the import format mappings for all saved searches with source values that include **NSPB (Data) FIN**. The import format lets you set up the integration mappings between NetSuite Ledger (chart of accounts) segments and Planning and Budgeting dimensions. Map the saved searches to the new dimensions you created so that the new dimensions are the new import sources.

Note:

When you select the source and target, Data Management automatically fills the source and target columns. For more information, see [Working with Import Formats](https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/erpia/fus_adding_import_formats_108x5091d58d.html) in the Oracle Help Center.

#### To update import format mappings for Planning and Budgeting saved searches: {#procedure_1114063737}

1.  Click the Navigator icon ![The Menu icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuitePlanningandBudgeting/PlanningandBudgetingFinancials/IntegrationGuide/NSPB-SP_MenuIcon.png), and then under Integration, select **Data Management**.
    
    The Data Management window opens.
    
2.  Click the **Setup** tab, and then under Integration Setup, click **Import Format**.
    
3.  In Import Format Summary:
    
    1.  Find and select a saved search where the value in the **Source** column includes **NSPB (Data) FIN**.
        
        For example, select the saved search with this source value: **NSPB (Data) FIN Balance Sheet Beg Balances**.
        
    2.  In Import Format Mappings, find the row for the new dimension. Use the **Target** column to help you find it.
        
    3.  Change the value in the **Source Column** field to the name of the new dimension.
        
        For example, if your new dimension is **TaskType**, set the **Source Column** value to **TaskType**.
        
        Tip:
        
        Make sure that the **Source Column** value matches the **Target** value for the new dimension.
        
    4.  Repeat steps 3b - 3c for each new dimension.
        
    5.  Click **Save**.
        
        Important:
        
        Save after every update that you make to the mapping for the saved search.
        
4.  Repeat step 3 for each saved search with a source value that includes **NSPB (Data) FIN**.
