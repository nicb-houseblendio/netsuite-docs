To set up your application to work with a single currency, update the data load mappings for the Member Name and Base Currency dimensions. Make these updates in the following data load rules:

-   MD\_Currency
    
-   MD\_Subsid
    

For these data load rules, update the existing **Like** mapping and create a new **Explicit** mapping for your base currency.

#### To update the data load mappings of the Member Name and Base Currency dimensions: {#procedure_0212110533}

1.  Click the Navigator icon ![Screenshot of the Navigator icon in NSPB](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuitePlanningandBudgeting/PlanningandBudgetingFinancials/AdminGuide/NSPBNavigatorIcon.png), and under Integration, click **Data Management**.
    
2.  The Data Management window opens. Click the **Workflow** tab, and then under Data Load, click **Data Load Mapping**.
    
3.  To define the data load mappings for MD\_Currency, in the POV bar, click the link next to **Location**.
    
    The Select Point of View window opens.
    
    1.  In the **Location** field, enter **MD\_Currency**, and then click **OK**.
        
    2.  From the **Dimensions** list, select **Member Name**.
        
    3.  Click the **Like** tab.
        
    4.  To update the existing mapping, in the **Target Value** field, delete the existing value and enter **Ignore**.
        
    5.  Click the **Explicit** tab.
        
    6.  Click **Add**.
        
    7.  In the new row, enter your base currency's three-letter currency code in the **Source Value** and **Target Value** fields. For example, if your base currency is USD, enter USD in both fields.
        
    8.  Click **Save**.
        
4.  To define the data load mapping for MD\_Subsid, in the POV bar, click the link next to **Location**.
    
    The Select Point of View window appears.
    
    1.  In the **Location** field, enter **MD\_Subsid**, and then click **OK**.
        
    2.  From the **Dimensions** list, change the value to **Base Currency**.
        
    3.  Repeat steps 3c - 3h.
