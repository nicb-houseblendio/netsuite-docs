To set up the NSPB Sync SuiteApp, users with the Administrator role need to perform the following tasks:

1.  Enable the required features in your NetSuite account. See [Required Features for Installing the NSPB Sync SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4882113016.html).
    
2.  Install the SuiteApp. See [Installing the NSPB Sync SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4879479154.html).
    
3.  Assign roles to NSPB Sync users. See [Role Permissions for NSPB Sync Users](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0221111204.html).
    
4.  Set the file encryption password. See [Setting Up a Password for File Encryption](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4879518470.html).
    
5.  Create an integration user with proper permissions. See [Setting Up the Integration User](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_1489167953.html).
    
6.  Set up token-based authentication (TBA) for Planning and Budgeting users. See [Setting Up Token-based Authentication](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161942084079.html).
    
7.  Set up the connection to your Planning and Budgeting. See [Setting Up the Planning and Budgeting Connection](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158073354875.html).
    
8.  Schedule the required NSPB Sync script deployments properly. See [Scheduling Script Deployments for NSPB Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160829049734.html).
    

After the SuiteApp is configured, administrators can use the following functionality provided by NSPB Sync:

-   Customize the saved searches that are included in the SuiteApp or create new saved searches to use in your Planning and Budgeting. You can also create saved searches from the available custom record types. See [NSPB Sync Saved Searches](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1512147604.html).
    
-   Customize the metadata saved searches that are included in the SuiteApp and call RESTlets from Data Exchange to automatically export the metadata from NetSuite entities to your Planning and Budgeting. See [Metadata Export to Planning and Budgeting](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156404064233.html).
    
-   Extract data from SuiteAnalytics workbooks and datasets that you've created in NetSuite. See [Using SuiteAnalytics Workbooks and Datasets with NSPB Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160673989178.html).
    
-   Administer your Planning and Budgeting directly from the NetSuite UI without needing to open the Planning and Budgeting account. See [NSPB Sync Functionality in NetSuite UI](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158402598917.html).
    
-   Use the [NSPB Sync SuiteApp Portlets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1551958192.html).
