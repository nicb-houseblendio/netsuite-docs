After you rename dimensions, go to Data Integration and update the dimension details for the affected dimensions in NetSuite (the target application). You need to define the details for the renamed dimensions and remove the original base dimensions.

#### To update the dimension details for NetSuite:

1.  Click the Navigator icon ![The Menu icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuitePlanningandBudgeting/PlanningandBudgetingFinancials/IntegrationGuide/NSPB-SP_MenuIcon.png), and then under Application, click **Data Exchange**.
    
2.  Click the **Data Integration** tab.
    
3.  Click the **Actions** dropdown menu and select **Applications**.
    
4.  In the Applications window, find **NetSuite** from the list.
    
5.  Click the Actions icon ![Actions icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuitePlanningandBudgeting/PlanningandBudgetingFinancials/IntegrationGuide/ActionsEllipsisIcon.png) (ellipsis) for **NetSuite**, and then select **Refresh Metadata**. This action synchronizes the application's metadata from NetSuite.
    
    If the action is successful, a confirmation message appears.
    
6.  Click the Actions icon ![Actions icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuitePlanningandBudgeting/PlanningandBudgetingFinancials/IntegrationGuide/ActionsEllipsisIcon.png) (ellipsis) for **NetSuite**, and then select **Application Details**.
    
7.  In the Application Details: NetSuite window, click the **Dimensions** tab.
    
8.  To map the renamed dimension:
    
    1.  Find the renamed dimension in the list.
        
        For example, if you renamed **Department** to **MyDepartment**, find **MyDepartment**.
        
    2.  In the **Data Table Column Name** column, enter the value that was used for the original base dimension.
        
        For example, if the value for **Department** in **Data Table Column Name** is **UD9**, enter **UD9** for **MyDepartment**.
        
    3.  Check **Create Drill Region** for the renamed dimension.
        
        Click **Save**.
        
9.  Select the original base dimension in the list, and then click the Delete icon ![Delete icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuitePlanningandBudgeting/PlanningandBudgetingFinancials/IntegrationGuide/DeleteIconDataIntegration.png).
    
    For example, select and delete **Department**.
    
10.  Click **Save**.
     
11.  If you renamed multiple dimensions, repeat steps 6 - 8 for each one.
