Customers in NetSuite can use NSPB Class Planning Category values to group classes into different categories and create their own custom hierarchy. When you import Class metadata to your Planning and Budgeting, the NSPB Class Planning Category values are used to build the Class metadata hierarchy.

You can define the NSPB Class Planning Category on a class record.

The Class metadata hierarchy is built with the following logic:

-   If a class from NetSuite has a parent, the parent of the class is used in your Planning and Budgeting as the parent.
    
-   If a class from NetSuite doesn't have a parent, but has an NSPB Class Planning Category, the NSPB Class Planning Category is used in your Planning and Budgeting as the parent.
    
-   If a class from NetSuite has neither a parent nor an NSPB Class Planning Category, the top-level class is used in your Planning and Budgeting as the parent.
