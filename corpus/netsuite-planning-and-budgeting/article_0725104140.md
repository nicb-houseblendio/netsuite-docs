NSPB Sync has been tested for the number of records that can be successfully imported to Planning and Budgeting in cloned metadata saved searches. The following table shows the test results per individual entity:

| Saved Search Type | Total Number of Imported Records |
| --- | --- |
| Item | 100,000 parent and child items |
| Vendor | 100,000 parent vendors |
| Subsidiary | 120 parent and child subsidiaries |
| Location | 5,000 parent and child locations |
| Income Statement Accounts | 5,000 parent and child accounts |
| Balance Sheet Accounts | 5,000 parent and child accounts |
| Class | 7,500 parent and child classes |
| Customer | 300,000 parent customers 75,000 parent and child customers |
| Department | 5,000 parent and child departments |
| Project | 10,000 parent and child projects |
| Customer Project | 10,000 parent and child customer projects |
| Employee | 50,000 parent employees |

Note:

The number of records you can successfully import to your Planning and Budgeting may differ from these test results. This depends on the total number of records you have in your account and the complexity of your metadata hierarchy.

If you attempt to process more records than listed above, the import may fail. To process more records for an entity, you can skip running the default metadata saved search for that entity. For instructions, see [Returning Metadata Hierarchy Based Only on Cloned Saved Search](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0725105119.html).
