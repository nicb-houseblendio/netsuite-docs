The NSPB Sync SuiteApp includes a default set of predefined datasets that you can use to load metadata from NetSuite to your Planning and Budgeting.

Note:

If you have the **Administrator** role, you can create, review, or customize the predefined NSPB Sync datasets in NetSuite.

To access the datasets, log in to NetSuite, and go to Planning & Budgeting > Setup > Manage Datasets. This opens a NetSuite page with the list of datasets.

The status of the datasets can be one of the following:

-   **Not Created**
    
    You can create a dataset that is in this status.
    
-   **Created**
    
    You can recreate or customize a dataset that is in this status.
    

To manage the datasets, refer to the following help topics:

-   [Creating an NSPB Sync Dataset](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0711120810.html)
    
-   [Recreating an NSPB Sync Dataset](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0711120857.html)
    
-   [Customizing an NSPB Sync Dataset](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0711120952.html)
