To start implementing the budget data import using a data load rule, you need to create a target application in Data Exchange.

#### To create a target application: {#procedure_0417092527}

1.  In your Planning and Budgeting environment, click the Navigator icon ![This icon takes you to the main menu in your Oracle EPM Planning application.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuitePlanningandBudgeting/NSPBSync/NSPBMenuIcon.png). Then, under Application, click **Data Exchange**.
    
2.  Click **Actions**, and then select **Applications**.
    
3.  Click the **Add** icon ![Creates a new target application in NSPB.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuitePlanningandBudgeting/NSPBSync/NSPBAddIcon.png).
    
4.  In the Create Application popup window, do the following:
    
    1.  For the **Category** field, select **Data Export**.
        
    2.  For the **Type** field, select **Data Export to File**.
        
    3.  Next to the **File** field, click the **File Browser** icon ![This opens File Browser.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuitePlanningandBudgeting/NSPBSync/NSPBFileBrowserIcon.PNG).
        
    4.  Click **Upload** to locate a source file on your disk. This should be a simple CSV file with column headers ordered as you want them to be generated.
        
        For example, if you want to use the predefined **NSPB - Import Budget Data Using DM** post-processing plug-in, the CSV file should look exactly as follows:
        
        ![A sample source file with column headers as they are in the predefined plug-in for data load rules.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuitePlanningandBudgeting/NSPBSync/NSPBSourceDM.png)
    5.  Select the source file on your disk, and click **Open**.
        
    6.  In **File Browser**, click the source file. Then, click **OK**.
        
    7.  In the **Prefix** field, enter a prefix to give the target application a unique name.
        
    8.  Click **OK**.
        
        This registers your target application in Data Exchange.
        
5.  Open the newly created target application, and do the following:
    
    1.  On the **Dimensions** tab, make the following changes in the **Dimension Classification** column, if applicable to your use case:
        
        1.  For the **Period** dimension, select **Period**.
            
        2.  For the **Years** dimension, select **Year**.
            
    2.  Make any other necessary changes, and click **Save**.
        

For general information and additional setup, see the Oracle Help Center topic [Registering Applications](https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/diepm/integrations_epm_applications_104xfe051403.html).
