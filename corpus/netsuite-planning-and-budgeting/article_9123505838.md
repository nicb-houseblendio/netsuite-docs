Important:

Before you start setting up Planning and Budgeting to support the renamed dimensions, make sure that you've integrated Planning and Budgeting Financials with NetSuite. For more details about the prerequisite steps you need for integration, see the help topic [Setup and Configuration](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_164993064726.html).

If you renamed any base dimensions, follow these steps to make sure that the calculations using the renamed dimensions work.

1.  Update the data load rules for the dimensions you renamed. See [Updating Data Load Rules for Metadata After Renaming Dimensions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1111123535.html).
    
2.  Copy and update the Groovy scripts for business rules and template affected by renaming dimensions. See [Copying and Updating Groovy Scripts of Business Rules and Template](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1113084500.html).
    
3.  If you only renamed dimensions and didn't enable new custom dimensions, skip step 3 and go to step 4.
    
    If you also enabled new custom dimensions when you enabled other Planning and Budgeting Financials features, complete the steps in [Setting Up Planning and Budgeting After Enabling Custom Dimensions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1172609273.html).
    
    Important:
    
    After you complete the steps in [Setting Up Planning and Budgeting After Enabling Custom Dimensions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1172609273.html), return to this list, skip step 4, and do step 5.
    
4.  Update the dimension details for the affected dimensions. See [Defining Dimension Details for Renamed Dimensions and Removing Original Dimensions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0208123732.html).
    
5.  Manually run the Batch\_Setup job to load data into Planning and Budgeting Financials. See [Executing the Default Pipeline Jobs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_2113849230.html).
    
    Note:
    
    Skip this step if you've already run the Batch\_Setup job from the steps in [Setting Up Planning and Budgeting After Enabling Custom Dimensions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1172609273.html).
