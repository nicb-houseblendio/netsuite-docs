If the job execution in NetSuite ends with **Plugin Error**, you need to check the job and plug-in script setup in your NetSuite and Planning and Budgeting environments.

#### To troubleshoot the plug-in script error: {#procedure_10174447582}

1.  In your Planning and Budgeting environment, check that the following applies:
    
    1.  The data integration job or business rule runs successfully.
        
    2.  The generated CSV file is stored in Inbox/Outbox Explorer or File Browser's inbox.
        
2.  In NetSuite, go to _Customization > Plug-ins > Plug-in Implementations_, and then do the following:
    
    1.  In the displayed list, find the plug-in script that you want to troubleshoot.
        
        Tip:
        
        If NetSuite displays a long list of plug-in scripts, you can narrow the list by doing the following:
        
        1.  Expand the Filters area if the filters aren't displayed.
            
        2.  From the **Script File** filter, select the script file name.
            
        
    2.  Click **Edit** next to the plug-in script.
        
    3.  Check that the **Status** field is set to **Released**.
        
    4.  Check that the **Log Level** field is set to **Debug**.
        
    5.  Click **Save** if you've made any changes, or click **Cancel** to return to the Plug-In Implementations page.
        
    6.  If you need to update the script file, do the following:
        
        1.  In the **Script** column, click the link to the script file details.
            
        2.  Proceed as described in [Fixing the Plug-in Script](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_89140234174.html).
            
3.  Go to NetSuite EPM > Planning and Budgeting > Manage Jobs, and then do the following:
    
    1.  Click **Edit** next to the job that runs the plug-in script.
        
    2.  Click the **Options** subtab.
        
    3.  From the **Post-Processing Plug-ins** list, select the updated plug-in script.
        
    4.  Click **Save**.
        
4.  Go back to NetSuite EPM > Planning and Budgeting > Manage Jobs, and then click **Execute** next to the job that runs the plug-in script. This opens a page where you can do the following:
    
    1.  Click the **Execute** button to manually run the job. The information banner indicates the start of the job execution.
        
    2.  To watch the progress of the job execution, click the **Execution Logs** subtab.
        
        For more details about the job execution, you need to access the job execution logs. See [Viewing the Logs for Jobs with Plug-in Script Errors](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_65140251809.html).
