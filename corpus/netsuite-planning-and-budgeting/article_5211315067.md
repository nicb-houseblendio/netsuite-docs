In Planning and Budgeting Financials, you can enable these two groups of dimension:

-   You can map and rename existing base dimensions for Item, Department, Relationship, Class, and Location.
    
-   You can enable up to three custom dimensions.
    

Important:

You can only map and rename existing dimensions when you first enable the Planning and Budgeting Financials features. After you enable these features, you can't go back to the Enable Features window to map and rename dimensions.

You can enable custom dimensions when you first enable the Planning and Budgeting features and any time after.

For more information about how to map and rename or enable dimensions, see [Enabling Planning and Budgeting Financials](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_165096987704.html).

After you enable one or both groups of dimensions, read the following topics about setting up Planning and Budgeting:

-   If you enabled the mapping and renaming of existing base dimensions, see [Setting Up Planning and Budgeting After Renaming Dimensions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_9123505838.html).
    
-   If you enabled new custom dimensions, see [Setting Up Planning and Budgeting After Enabling Custom Dimensions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1172609273.html).
    

Note:

If you enabled both groups of dimensions, complete the steps for the renamed dimensions first, and then complete the steps for the custom dimensions.
