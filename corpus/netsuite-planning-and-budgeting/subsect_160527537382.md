NSPB Sync lets you use post-processing plug-ins in NetSuite to import and process data from your Planning and Budgeting.

For example, you want to run a business rule or data load rule with a post-processing plug-in to process budget data from Planning and Budgeting. The logic then works as follows:

1.  You need to create a business rule or data load rule in your Planning and Budgeting. Then, check that the business rule or data load rule runs successfully in your Planning and Budgeting.
    
2.  You need to add the business rule or data load rule as a job in NetSuite, and then select a plug-in to process budget data.
    
3.  When you run the job in NetSuite, the business rule or data load rule generates an export file and stores it in your Planning and Budgeting. The business rule stores the file in Inbox/Outbox Explorer, and the data load rule in the File Browser's inbox folder.
    
4.  When the job execution is complete, NSPB Sync downloads the generated export file from Inbox/Outbox Explorer or File Browser's inbox to NetSuite.
    
5.  NSPB Sync passes the export file to the plug-in for processing.
