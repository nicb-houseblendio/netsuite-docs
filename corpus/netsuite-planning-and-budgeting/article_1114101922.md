For your convenience, you can split the list of substitution variables into categories.

#### To categorize the substitution variables: {#procedure_11102050638}

1.  Go to _Customization > Lists, Records, & Fields > Record Types_.
    
2.  Click **List** for the **NSPB | Substitution Variable** record type.
    
3.  Click **New NSPB | Substitution Variable**.
    
4.  In the **Name** field, paste the name of a substitution variable that you copied from the **Other** subtab at NetSuite EPM > Planning and Budgeting > Substitution Variables.
    
    The value must match exactly, including upper and lower case.
    
    Important:
    
    To display a substitution variable under the **Other** subtab, you first need to create it in your Planning and Budgeting.
    
5.  In the **Description** field, enter a description to help you identify this substitution variable in NetSuite.
    
6.  From the **Category** list, select a category for this substitution variable. If you select **New**, you can create your custom category right away:
    
    1.  In the **Name** field, enter a name for your custom category.
        
    2.  Click **Save**.
        
    3.  Select the created custom category from the **Category** list.
        
        For instructions on how you can create a list of custom categories, see [Creating and Customizing Categories for Substitution Variables in Planning and Budgeting Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1114102459.html).
        
7.  (Optional) From the **Auto-Update Action** list, select an option for automatic update of the substitution variable values. For a complete description of this feature, see [Enabling Automatic Update of Substitution Variables Values in Planning and Budgeting Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1114103159.html).
    
8.  Click **Save**.
    
    This moves the substitution variable to the appropriate subtab at NetSuite EPM > Planning and Budgeting > Substitution Variables.
