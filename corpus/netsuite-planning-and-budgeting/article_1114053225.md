Register all saved searches with **NSPB (Data) FIN** in its name from Planning and Budgeting to NetSuite.

#### To register a saved search:

1.  Click the Navigator icon ![The Menu icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuitePlanningandBudgeting/PlanningandBudgetingFinancials/IntegrationGuide/NSPB-SP_MenuIcon.png), and then under Application, click **Data Exchange**.
    
2.  Click the **Data Integration** tab.
    
3.  Click the **Actions** dropdown menu and select **Applications**.
    
    The Applications window opens.
    
4.  Click the Add icon ![Add icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuitePlanningandBudgeting/PlanningandBudgetingFinancials/IntegrationGuide/DataIntegrationAddIcon.png).
    
5.  In the Create Application window, do the following actions:
    
    1.  In the **Category** field, select **Data Source**.
        
    2.  In the **Type** field, select **NetSuite**.
        
    3.  In the **Connection** field, keep the default value **NetSuite\_ERP**.
        
    4.  In the **Application** field, enter **NSPB (Data) FIN**.
        
        Note:
        
        The search shows all the saved searches you need to register.
        
    5.  Select a saved search with **NSPB (Data) FIN** in its name.
        
        For example, select **NSPB (Data) FIN Balance Sheet Transactions**.
        
    6.  Click **OK**.
        
        If the registration works, you'll see a confirmation message.
        
6.  Repeat steps 4 - 5 for each saved search with **NSPB (Data) FIN** in its name.
    
7.  On the Applications window, locate **NetSuite**.
    
8.  Click the Actions icon ![Actions icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuitePlanningandBudgeting/PlanningandBudgetingFinancials/IntegrationGuide/ActionsEllipsisIcon.png) (ellipsis) for **NetSuite**, and then select **Refresh Metadata**.
    
    If it works, you'll see a confirmation message.
