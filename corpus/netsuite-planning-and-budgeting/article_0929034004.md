In the Strategic Modeling tab, set your calculation preferences for Strategic Modeling.

From the Planning and Budgeting Home page, go to Tools > User Preferences, and click the **Strategic Modeling** tab. On this tab, you can set the preferences listed in the following table. When you're done, click **Save**.

| Field Name | Function |
| --- | --- |
| **Calculations** |
| Suppress funds flow out of balance warning | Check this box to stop the application from generating "Funds Flow Out of Balance" errors when funds flow accounts don't balance in historical periods. |
| Warn for deprecated functions | This box is checked by default. Keep the box checked to get warnings if the application finds deprecated functions during calculations. |
| Auto calculate newly selected scenario | Check this box to enable automatic scenario calculation. |
| Suppress zeros on analyze | Check this box to exclude empty cells from calculation, analysis, and audit trail features. |
