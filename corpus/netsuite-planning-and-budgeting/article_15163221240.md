If you want to use a dataset included in Planning and Budgeting Sync, you need to create it in NetSuite.

Note:

After you create a dataset, you can share it with other users or roles that need to access the dataset. For information about sharing datasets, see [Accessing and Sharing Workbooks and Datasets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1531766899.html).

#### To create a Planning and Budgeting Sync dataset: {#procedure_0711120851}

1.  In NetSuite, go to NetSuite EPM > Planning and Budgeting > Manage Datasets.
    
2.  In the upper-right corner of the page, click **Create Default Datasets**.
    
3.  Check the **Select** box next to the dataset you want to create.
    
    Note:
    
    You can only select a dataset that's in the **Not Created** status. If you want to select a dataset that's in the **Created** status, you need to recreate it as described in the help topic [Recreating a Planning and Budgeting Sync Dataset](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_47163226321.html).
    
    Tip:
    
    To check the boxes for all datasets in the **Not Created** status, click the **Mark All** button. To clear the boxes for all datasets in the **Not Created** status, click the **Unmark All** button.
    
4.  Click **Submit**.
    
    In the list of datasets, the status of the dataset changes to **Created**.
    

You can click the created dataset to review or customize it. To customize the dataset, see [Customizing a Created Planning and Budgeting Sync Dataset](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_36163231143.html) for information. To export, review, or customize the hierarchy of metadata in the dataset, see [Dataset Settings in Planning and Budgeting Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_94163304747.html).
