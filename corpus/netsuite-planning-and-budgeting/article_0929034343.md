In the Ad Hoc Options tab, set how ad hoc grids look and behave.

From the Planning and Budgeting Home page, go to Tools > User Preferences, and click the **Ad Hoc Options** tab. On this tab, you can set the preferences described in the following table. When you're done, click **Save**.

| Field Name | Function |
| --- | --- |
| Member Inclusion | Check one or both of these options:
-   **Include selection** - Check this box to show both the selected member and any members retrieved by the operation. For example, zooming in on the selected member Qtr1 shows data for Qtr1, Jan, Feb, and Mar.
-   **Within selected group** - Check this box to run an operation (such as zoom only on the selected group of members), and leave unselected cells as they are. This setting matters only when there are two or more dimensions as rows or as columns. This option applies to **Zoom**, **Keep Only**, and **Remove Only**.

 |
| Zoom in | Choose the level at which to zoom in:

-   **Next level** - Gets data for the children of the selected member.
-   **All levels** - gets data for all descendants of the selected members.
-   **Bottom level** - Gets data for the lowest level of members in a dimension.

 |
| Ancestor Position | Choose how to show ancestors in the hierarchy:

-   **Top** - Shows member hierarchies in order from highest to lowest level.
-   **Bottom** - Shows member hierarchies in order from lowest to highest level.

 |
| Display Member Label as | Select whether member names, aliases, or both show:

-   Distinct Member Name Only
-   Member Name Or Alias

 |
| Alias Table | Select which alias tables to use:

-   Default
-   NetSuite
-   None

 |
| Indentation | Choose how member hierarchy levels are indented:

-   **None** - No indentation.
-   **Subitem** - Indents descendants. Ancestors are left-justified in the column.
-   **Totals** - Indents ancestors. Descendants are left-justified in the column.

 |
| Navigate without refreshing data | Check this box to improve performance as you move around the grid, for example, when you pivot and zoom. Click **Refresh** when you want to update the data. If you don't select this option, data refreshes as you work in ad hoc. |
| **Suppression** |
| Zeros | To hide rows or columns with zeros, check one or both of these options:

-   **Row** - Check this box to hide rows with only zeros.
-   **Column** - Check this box to hide columns with only zeros.

 |
| Suppress | Check one or both of these elements to hide them from the grid:

-   **Repeated members** - Check this box to hide rows with repeated member names, regardless of the grid orientation.
-   **Missing blocks on rows** - Check this box to hide blocks of cells in rows with no data.

 |
| Missing data | To hide rows or columns with zeros or no data, check one or both of these options:

-   Row
-   Column

 |
| No Access | To hide rows or columns that you can't access, check one or both of these options:

-   Row
-   Column

 |
| **Precision** |
| Use currency member setting | Check this box to apply the precision setting to the Currency member. If you check this option, you can't set minimum and maximum values for currencies. |
| Currency Values | Set the minimum and maximum number of decimal places to show in a cell for currency values. |
| Non-Currency Values | Set the minimum and maximum number of decimal positions to show in a cell for non-currency values. |
| Percentage Values | Set the minimum and maximum number of decimal positions to show in a cell for percentage values. |
| **Replacement** |
| No Data | Enter the text to show for cells with **#Missing** or **#NoData**. |
| No Access | Enter the text to show for cells that you don't have permission to see. |
| Submit Zeros | Check this box if you set **#NumericZero** as the text for the **No Data** or **No Access** replacement option, and you want to submit zeros. |
