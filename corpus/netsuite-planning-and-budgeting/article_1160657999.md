Important:

The integration with Planning and Budgeting recognizes saved search IDs the prefixes of which begin with **customsearch\_nspb\_**. Therefore, after you install Planning and Budgeting Sync, you should update IDs of the existing metadata saved search records in your NetSuite account to include the supported **\_nspb\_** prefix. To take appropriate action, read the guidelines for metadata saved searches in the help topic [Updating Existing Records to Include the Supported \_nspb\_ Prefix](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0712061757.html).

The Planning and Budgeting Sync SuiteApp enables you to extract metadata from NetSuite entities and use the metadata in your Planning and Budgeting. Metadata from each entity can be exported to a CSV file instead of being displayed in the NetSuite UI. You can then use the exported CSV file to import the metadata to your Planning and Budgeting.

To export selected metadata from NetSuite entities, you have the following options:

-   You can export metadata manually, as described in [Saved Search Settings in Planning and Budgeting Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_8111232373.html).
    
-   After configuring Data Exchange in your Planning and Budgeting for automated metadata synchronization, you can use saved searches included in the SuiteApp to export metadata as CSV files from NetSuite to your Planning and Budgeting. For the list of metadata saved searches, see [Supported Metadata Saved Searches in Planning and Budgeting Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_25155810721.html).
