If you have the Administrator role, you can assign the NSPB Implementer role to a new or existing user in NetSuite. This role allows the user to perform the following tasks:

-   Set the file encryption password
    
-   Set up token-based authentication for Planning and Budgeting users
    
-   Set up the connection to your Planning and Budgeting
    
-   Schedule the required NSPB Sync script deployments
    
-   Perform all tasks under the Planning & Budgeting tab in NetSuite
    
-   Create and customize the saved searches that are predefined in NSPB Sync
    
-   Create and customize the datasets that are predefined in NSPB Sync
    

For details about using the NSPB Implementer role, see the following help topics:

-   For guidelines on using the NSPB Implementer role, see [Best Practices for Using the NSPB Implementer Role](#bridgehead_55142154743).
    
-   To assign the NSPB Implementer role to an NSPB Sync user, see [Assigning the NSPB Implementer Role to Users](#bridgehead_32141111845).
    
-   To customize the NSPB Implementer role to better suit your needs, see [Customizing the NSPB Implementer Role](#bridgehead_33162836741).
    

## Best Practices for Using the NSPB Implementer Role {#bridgehead_55142154743}

Important:

You shouldn't use the NSPB Implementer role for integration with your Planning and Budgeting. To integrate with Planning and Budgeting, set up the integration user record as described in the help topic [Setting Up the Integration User](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_1489167953.html).

Tip:

The best practice is to use the NSPB Implementer role with new installations of the NSPB Sync SuiteApp.

If NSPB Sync is upgraded from a previous version, the NSPB Implementer role can't access all pages under the Planning & Budgeting tab in NetSuite. To allow users to access all the Planning & Budgeting pages, you need to add the NSPB Implementer role to the following NSPB Sync script deployment records:

-   NSPB Redirect to Account Metadata Hierar
    
-   NSPB SL Activity Logs
    
-   NSPB SL Planning & Budgeting Settings
    
-   NSPB SL Quick Job Execution Setup
    
-   NSPB | Data Source Setting
    
-   NSPB | Form/Dashboard
    
-   NSPB | Job Setup
    
-   NSPB | Manage Dataset
    
-   NSPB | Planning & Budgeting Data Files
    
-   NSPB | Planning & Budgeting Setup
    
-   NSPB | Saved Search Allowlist
    
-   NSPB | Saved Search Execution
    
-   NSPB | SL Import/Export
    
-   NSPB | SL Substitution Variables
    

#### To add the NSPB Implementer role to a script deployment: {#procedure_0307023629}

1.  Go to _Customization > Scripting > Script Deployments_.
    
    Tip:
    
    If NetSuite displays a long list of script deployments, you can narrow the list by doing the following:
    
    1.  Expand the Filters area if the filters are not displayed.
        
    2.  From the **Script** filter, select the required script deployment.
        
    
2.  For the required script deployment, do the following:
    
    1.  Click **Edit** next to the script deployment.
        
    2.  On the **Audience** subtab, from the **Roles** list, select **NSPB Implementer**.
        
    3.  Click **Save**.
        
3.  Repeat these steps for every script deployment that you need to update.
    
    The NSPB Implementer role can then access all the pages and perform all the tasks under the Planning & Budgeting tab in NetSuite.
    

## Assigning the NSPB Implementer Role to Users {#bridgehead_32141111845}

Using the Administrator role, you can assign the NSPB Implementer role to users who should set up and configure NSPB Sync on NetSuite accounts.

#### To assign the NSPB Implementer role to a user: {#procedure_25125641188}

1.  Go to _Lists > Employees > Employees_.
    
2.  Click **Edit** next to the employee to whom you want to assign the **NSPB Implementer** role.
    
3.  Click the **Access** subtab.
    
4.  In the **Role** column, select **NSPB Implementer**, and then click **Add**.
    
5.  Click **Save**.
    

## Customizing the NSPB Implementer Role {#bridgehead_33162836741}

The NSPB Implementer role is included in the installed SuiteApp, and has all the necessary permissions to get you started. If you need to create a custom role to better suit your needs, clone the NSPB Implementer role and assign your specific permissions to it.

#### To clone and customize the NSPB Implementer role: {#procedure_83180737845}

1.  In NetSuite, go to _Setup > Users/Roles > Manage Roles_.
    
2.  In the list of roles, click **Customize** next to the NSPB Implementer role.
    
3.  On the **Permissions** subtab, add the permissions you require for your custom role one by one.
    
4.  (Optional) If you need to rename records and transactions at Setup > Company > Rename Records/Transactions, do the following:
    
    1.  Click the **Setup** subtab.
        
    2.  For the **Set Up Company** permission, change the access level to **Full**.
        
5.  Click **Save**.
    

Tip:

The best practice is only to add the missing permissions and avoid removing any permissions.

Important:

With every new version of the NSPB Sync SuiteApp, new permissions may be added to the NSPB Implementer role. After you update your installed SuiteApp, you should go to _Setup > Users/Roles > Show Role Differences_, and compare the permissions you have in your custom role with the permissions in the updated NSPB Implementer role. To make sure the integration works properly for you, add the new permissions to your custom role.
