In the Form Printing tab, set your preferences for how forms and their data are printed as PDF files.

When designing a form, the Administrator sets the default printing options, for example, whether to include Supporting Detail. You can use these default settings or set your own preferences for printing PDF files.

From the Planning and Budgeting Home page, go to Tools > User Preferences, and click the **Form Printing** tab. On this tab, you can set the preferences listed in the following table. When you're done, click **Save**.

| Field Name | Function |
| --- | --- |
| **Page Settings** |
| Paper Size | Select the paper size dimension. |
| Black & White | Check this box to print documents in black and white. |
| Layout | Choose either landscape or portrait for your print layout. |
| Fit To | Choose how you want to scale the sheet size when printing:
-   None
-   Page
-   Width

 |
| Flow | Choose how you want the data to flow when printing:

-   Down Then Across
-   Across Then Down

 |
| **Options** |
| Check the print settings that you want applied to your printed files. The options are:

-   Format Data
-   Apply Precision
-   Include Supporting Detail Note: If you check **Include Supporting Detail**, choose whether to print in **Normal Order** or **Reverse Order**.
-   Show Comments
-   Show attribute members
-   Show Currency Codes This only applies if the form supports multiple currencies per entity.
-   Print Form Name
-   Repeat Column Headers
-   Repeat Row Headers
-   Print POV/Page
-   Print Grid Lines
-   Print Footer

 |
