Important:

You shouldn't use the NSEPM Implementer role for integration with your Planning and Budgeting. To integrate with Planning and Budgeting, set up the integration user record as described in the help topic [Setting Up the Integration User for Planning and Budgeting Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_7141303101.html).

Tip:

The best practice is to use the NSEPM Implementer role with new installations of the Planning and Budgeting Sync SuiteApp.

If Planning and Budgeting Sync is upgraded from a previous version, the NSEPM Implementer role cannot access all the pages at NetSuite EPM > Planning and Budgeting. To allow users to access all the Planning and Budgeting pages in NetSuite, you need to add the NSEPM Implementer role to the following Planning and Budgeting Sync script deployment records:

-   NSPB | SL Configure Oauth
    
-   NSPB | SL Configuration Checklist
    
-   NSPB | SL Acct Metadata Hrchy redirect
    
-   NSPB | SL Data Source Execution
    
-   NSPB | SL Data Source Setting
    
-   NSPB | SL Form/Dashboard
    
-   NSPB | SL Import/Export
    
-   NSPB | SL Job Setup
    
-   NSPB | SL Quick Job Execution Setup
    
-   NSPB | SL Create Default Datasets
    
-   NSPB | SL Create Default Saved Searches
    
-   NSPB | SL Quick Job Execution Setup
    
-   NSPB | SL Substitution Variables
    
-   NSPB | SL Advance Substitution Variables
    
-   NSPB | SL Integration Artifacts
    
-   NSPB | SL Download Financials Artifacts
    

#### To add the NSEPM Implementer role to a script deployment record: {#procedure_23110918195}

1.  Go to _Customization > Scripting > Script Deployments_.
    
    Tip:
    
    If NetSuite displays a long list of script deployments, you can narrow the list by doing the following:
    
    1.  Expand the Filters area if the filters are not displayed.
        
    2.  From the **Script** filter, select the required script deployment.
        
    
2.  For the required script deployment, do the following:
    
    1.  Click **Edit** next to the script deployment.
        
    2.  On the **Audience** subtab, from the **Roles** list, select **NSEPM Implementer**.
        
    3.  Click **Save**.
        
3.  Repeat these steps for every script deployment that you need to update.
    
    The NSEPM Implementer role can then access all the pages and perform all the tasks at NetSuite EPM > Planning and Budgeting in NetSuite.
