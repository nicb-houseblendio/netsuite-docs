If you want to use NetSuite to schedule and run a data integration configured in Data Exchange, you need to add the data integration record as a job in NetSuite. Then, you can set up the job as needed.

#### To add and set up a data integration job: {#procedure_91140047841}

1.  In NetSuite, go to NetSuite EPM > Planning and Budgeting > Manage Jobs.
    
2.  On the **Manage Jobs** page, do one of the following:
    
    -   In the list of jobs, click **Edit** next to a data integration job of your choice.
        
    -   If you don't see the data integration job in the list, click the **Add Job** button, and follow steps 3 through 6 in [Adding a Job in Planning and Budgeting Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1114010611.html).
        
3.  If you want to specify the accounting period during which the data integration job should be executed, click the **Job Parameters** subtab, and do the following:
    
    1.  From the **Period Type** list, select one of the following:
        
        -   **Relative** to specify an accounting period that is relative to the current date.
            
            Important:
            
            Ensure that the periods configured in Data Exchange match those defined in NetSuite at Setup > Accounting > Manage Accounting Periods. For information about managing accounting periods, see [Manage Accounting Periods Page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1445839.html).
            
        -   **Absolute** to set up a specific date range.
            
        -   **Substitution Variables** to use the substitution variables configured in your Planning and Budgeting to set up the start and end month and year of the accounting period.
            
            Note:
            
            The Substitution Variables period type is only supported for data integration jobs loading data. For data integration jobs loading metadata, the Absolute or Relative period types need to be used.
            
        
        For **Relative** and **Absolute**, you have the following options:
        
        -   **Start Period**
            
        -   **End Period**
            
        
        From the **Start Period** and **End Period** lists, select the accounting periods as follows:
        
        -   If you've selected **Absolute** as the **Period Type**, select from the list of available accounting periods. For more information about managing accounting periods, see [Manage Accounting Periods Page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1445839.html).
            
        -   If you've selected **Relative** as the **Period Type**, select one of the following accounting periods:
            
            -   **This Fiscal Year**
                
            -   **This Fiscal Quarter**
                
            -   **This Period**
                
            -   **Last Fiscal Year**
                
            -   **Last Fiscal Quarter**
                
            -   **Last Period**
                
            -   **Period Before Last**
                
            
            Note:
            
            When a fiscal year or quarter is selected for **Start Period**, the first month of the selected period is used. When a fiscal year or quarter is selected for **End Period**, the last month of the selected period is used.
            
        
        For Substitution Variables, you have the following options:
        
        -   **Start Period Month**
            
        -   **Start Period Year**
            
        -   **End Period Month**
            
        -   **End Period Year**
            
    2.  Specify the **Import Mode** and **Export Mode** of the job execution, as defined in Data Exchange.
        
4.  If you want to schedule the data integration job, click the **Schedule** subtab, and follow step 3 in [Scheduling a Job in Planning and Budgeting Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1114011407.html).
    

<a id="step_161014412816"></a>

6.  If you want to override the saved search criteria next time a saved search is executed, click the **Source Filters** subtab, and do the following:
    
    1.  In the **Name** column, add the names of source filters that are defined in your Planning and Budgeting. The field values must match exactly, including upper and lower case.
        
    2.  From the **Value** list for each of the source filters in the list, select the substitution variables by which you want to filter the saved search results.
        
    
    Read the following details about using the source filters:
    
    -   When you run the data integration job, this setting overrides the filters you've previously defined in NetSuite on the saved search record's **Criteria** subtab.
        
    -   When you want to use a different substitution variable for filtering, you can change it here instead of logging in to your Planning and Budgeting and changing it there. For information about how you can use NetSuite to manage substitution variables configured in your Planning and Budgeting, see [Substitution Variables in Planning and Budgeting Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_7101207665.html).
        
    -   When you run the data integration job, and use source filters, you can expect the following behavior:
        
        -   Planning and Budgeting Sync applies filter operators you defined in NetSuite on the saved search record's **Criteria** subtab.
            
        -   Planning and Budgeting Sync ignores the condition that's set for the source filters in Data Exchange.
            
        
        For example, if you set a date as a source filter value in Data Exchange, Planning and Budgeting Sync applies the filter operator from NetSuite to that source filter.
        
        This functionality lets you pass the start and end date for a target period from Data Exchange to NetSuite, and filter NetSuite saved searches based on that target period. To pass the start and end dates, you can use the following variables as source filter values in Data Exchange:
        
        -   `$START_PERIODKEY[yyyy-MM-dd]$`
            
        -   `$END_PERIODKEY[yyyy-MM-dd]$`
            
        
        For more information about using these variables in Data Exchange, see [Selecting Period Report Parameters from the Oracle ERP Cloud](https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/erpia/erp_cloud_period_parameters_102x8ab94db0.html) in the Oracle Help Center.
        
        Note:
        
        Make sure the date format you use when you set these variables in Data Exchange is compatible with NetSuite. For information about the NetSuite date formats, see [Formatting for Dates, Numbers, Phone Numbers, and Time](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N249143.html).
        
7.  For optional setup of the data integration job, click the **Options** subtab.
    
    From the **Post-Processing Plug-ins** list, select a plug-in of your choice. The field is set to **None** by default.
    
    For information about how you can use post-processing plug-ins for the integration purposes, see [Post-Processing Plug-ins in Planning and Budgeting Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_5132559979.html).
    
8.  Click **Save**.
