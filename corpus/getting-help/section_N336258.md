Watch the following video to learn how to use the help center.

<a id="kaltura_player_23"></a>

The help center has many features to help you find what you need to know about NetSuite. For information about how to access the help center, see [Accessing the Help Center](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0721112059.html).

![Help Center](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteBasics/GettingHelp_HelpCenterWindow.jpg)

| 1 | **Search** - To search for help topics for the pages and features of NetSuite, type a keyword or phrase in the Search field of the Help window, and press Enter. For more information, see [Searching for Help](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N336535.html). |
| --- | --- |
| 2 | **Language Preference** - If your account has the multi-language feature enabled, you can choose your preferred language displayed in the NetSuite Help Center from the dropdown list at the top right corner of the page. This language preference is independent of the language preference you specify for the NetSuite user interface. You can switch between languages in the Help Center, if needed. The next time you open the Help Center, it opens in the language you last chose. You can choose from these languages: ![Chinese Simplified icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteBasics/PersonalPrefs_HelpCenter_Language_Chinese.png)(Chinese Simplified), Deutsch (German), English, ![Japanese icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteBasics/PersonalPrefs_HelpCenter_Language_Japanese_new.png) (Japanese), Español (Spanish). Note: You can also set the language of the Help Center using the Set Preferences link. See [Setting Personal Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N475297.html), specifically, the entry for Language of the Help Center in the User Profile section. |
| 3 | **Home** - Click the home icon ![Home icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteBasics/HelpCenter_HomeIcon.png) on the toolbar to go back to the Help Center home page. A home icon also appears at the top of each help topic. |
| 4 | **SuiteAnswers** - Click SuiteAnswers to go to the SuiteAnswers site. This page opens in a new tab. SuiteAnswers is a searchable repository of support solutions, best practices, training videos, and help topics. |
| 5 | **Developers** - Click Developers to view a list of resources for SuiteCloud and Commerce developers. |
| 6 | **Videos** - Click Videos to view a list of help videos that demonstrate how to perform specific tasks in NetSuite. When you click a link, you're redirected to the Oracle Learning Library to view the video. |
| 7 | **Training** - Click Training to go to the SuiteTraining site. This page opens in a new tab. Here you'll find complete information about the courses and certification programs that NetSuite offers. |
| 8 | **SuiteApps** - Click SuiteApps to open a list of current SuiteApps. You'll also find a link to SuiteApp.com where you can find information about SuiteApps developed by SDN Partners and other third parties. |
| 9 | **User Guides** - Click User Guides to open a list of available PDF guides. These User Guides offer conceptual details and setup information for specific areas of NetSuite. Click the PDF icon beside a User Guide to open the PDF in a new window. |
| 10 | **New Release** - Click New Release to open a page with links to Sneak Peeks, Release Notes, and other important information for the newest release of NetSuite. |
| 11 | **Table of Contents** - Click the arrows ![Show and Hide icons](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteBasics/HCShowHideArrows.png) at the top of the divider to hide or show the Table of Contents. Click the Show in Table of Contents icon ![Show in Table of Content icon.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteBasics/HCShowInTOCIcon.png) in the page header to find the current topic in the Table of Contents. Seeing a topic within the organization of the Table of Contents can help you find related topics or understand where you're in a process or a feature. |
| 12 | **Print Icon** - Click Print icon ![Print icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteBasics/HCPrintIcon.png) in the page header to print the current help topic. Or, right-click and use the browser's Print function. |
