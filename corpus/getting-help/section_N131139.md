The SuiteCloud platform offers a comprehensive set of tools to help you customize and extend NetSuite to fit your business needs. Any customizations you make on the platform automatically migrate with every NetSuite upgrade. The following documentation is available for the SuiteCloud platform:

| **Introduction** | Learn how to customize NetSuite to your own needs with SuiteCloud Platform. Learn about the records reference tools available and review the SuiteCloud platform glossary for new terminology. See [SuiteCloud Platform Introduction](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_9105332207.html). |
| --- | --- |
| **Point-and-Click Customization** | Customize NetSuite fields, forms, record types, transaction types, segments, and centers using a point-and-click experience. You can control how users of your NetSuite account access and enter information. For more information, see [Customization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/book_N2823893.html). For templates customization, such as advanced PDF/HTML templates, advanced templates reference, scriptable templates, and basic printing layouts, see [Template Customization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/book_5164527716.html). Copy a custom object to another account with Copy to Account. Select a target account, choose dependencies, specify whether to include instances, if applicable, and then preview and deploy the custom object. See [Copy to Account](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1544019532.html). |
| **Workflow Engine** | SuiteFlow provides developers and customers with point-and-click tools to customize and automate business processes, such as lead nurturing, transaction approval, record management, and more. See [SuiteFlow (Workflow)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/book_N2723865.html). |
| **Custom Coding** | Built on industry-standard JavaScript, SuiteScript and SuiteScript 2.x enables full-featured application-level scripting capabilities that support sophisticated procedural logic and feature robust debugging capabilities throughout NetSuite. Many NetSuite records support SuiteScript. See [SuiteScript](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/set_1502135122.html). SuiteCloud Development Framework (SDF) is a development framework and deployment mechanism. It gives developers and partners IDE tools that customize NetSuite accounts and deploy solutions. See [SuiteCloud Development Framework](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4702622163.html). SuiteCloud Software Development Kit represents tools for customizing accounts through SuiteCloud Development Framework. Available tools are SuiteCloud IDE plug-in, SuiteCloud CLI, and other extentions. See [SuiteCloud SDK](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1558730192.html). Use the SuiteCloud Developer Assistant - an AI-powered coding assistant designed for SuiteCloud developers. Integrated with Visual Studio Code (VS Code) through the Cline extension, it uses advanced language models specialized for SuiteCloud and SuiteScript to support NetSuite customization tasks. See [SuiteCloud Developer Assistant Guide](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1171315103.html). |
| **Managing SuiteApps** | Define and manage your SuiteApp distribution process in one place. Upload SuiteApp projects to SuiteApp control center and distribute them in the SuiteApp Marketplace, from which users can install and upgrade SuiteApps. See [SuiteApp Control Center](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/book_1557425073.html) and [SuiteApp Marketplace](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/book_1540487155.html). |
| **Distribution** | Use the SuiteApp Marketplace to find and install SuiteApps. SuiteApps can include customizations and configuration settings useful to your organization. To learn about the information that is available for each SuiteApp, see [Viewing SuiteApps in the SuiteApp Marketplace](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1539797977.html). If you create SuiteApps, use the SuiteApp Control Center to define and manage your SuiteApp distribution process. You can upload SuiteApp projects to SuiteApp Control Center and distribute them as SuiteApp versions to the SuiteApp Marketplace. For more information about getting started with SuiteApp Control Center, see [Accessing SuiteApp Control Center](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1526317441.html). |
| **Integrations** | SuiteTalk SOAP web services help customers and partners integrate NetSuite with existing on-premise investments and third party cloud applications. Integrations can use Java, .NET, or any other programming language that supports SOAP-based web services. See [SuiteTalk SOAP Web Services Platform Guide](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/book_156388532579.html). The SuiteTalk SOAP web services records guide contains a description of each record, including information about supported operations, field definitions, usage notes, and code samples. The guide includes links to the SOAP Schema Browser. See [SuiteTalk SOAP Web Services Records Guide](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/book_156388697975.html). SuiteTalk REST web services offer a REST-based interface for interacting with NetSuite. See [SuiteTalk REST Web Services API Guide](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/book_1559132836.html) SuiteTalk REST web services records guide lists the records that you can access through REST web services. See [SuiteTalk REST Web Services Records Guide](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/book_157830111504.html). The Import Assistant supports bulk transfer of data from other applications into NetSuite using CSV files. The wizard lets you visually map CSV columns to NetSuite fields. See [CSV Imports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/book_4470700566.html). With the AI Connector Service, NetSuite gives you the option to use an external AI client to complete some of your tasks. NetSuite has adopted the Model Context Protocol (MCP), which boosts its integration capabilities and enables secure interactions between AI models and data systems. This feature provides you with a seamless integration that lets supported AI clients directly access and interact with NetSuite data and functionality. See [NetSuite AI Connector Service](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_7200233106.html). |
| **Plug-ins** | NetSuite develops core plug-ins and releases them to partners or customers. You can create and test new core plug-in implementations using the SuiteScript Debugger. See available core plug-ins in [Core Plug-ins](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/book_4616046155.html). You can also develop, implement, and manage your own custom plug-ins in NetSuite. See [Custom Plug-ins](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/book_4060648050.html). |
| **Supported Records and Samples** | See a comparison of record types supported for SuiteScript, Web Services integration, SuiteAnalytics Connect, and CSV import. See [SuiteCloud Supported Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/preface_3710625923.html). For information about the record types, fields, and relationships available for a specific NetSuite channel, see the Records Catalog. The Records Catalog includes the custom records, forms, and fields for your account, based on the features you're using. See [Records Catalog](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/book_159368199162.html). NetSuite offers sample customization projects created with SuiteCloud platform tools. Explore these samples to determine which SuiteCloud tools suit you best to customize NetSuite for your organization. Also, you can browse tutorials that walk you through creating sample customization projects using SuiteCloud concepts. See [SuiteCloud Customization Tutorials](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_159163143019.html). |
