## Overview of Available Help Resources {#subsect_0216113057}

NetSuite offers many resources to help you when you need it. From self-service tools like the Help Center and SuiteAnswers to NetSuite customer support and training, you can always find answers to your questions.

Watch the following video for a quick introduction to using the Help Center, Field-level help, SuiteAnswers, and NetSuite Support.

<a id="kaltura_player_21"></a>

The following resources are available:

**Documentation Resources**

-   [NetSuite Documentation Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N128815.html) - a list of NetSuite Help Center resources.
    
-   [Videos](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/preface_1511796659.html) - a library of Help Center videos that work alongside the Help Center content to make difficult tasks easier.
    
-   [User Guides](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/preface_3710621755.html) - all of the Help Center content provided in PDF format.
    
-   [Developer Documentation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/preface_1531238762.html) - a summary of the resources NetSuite provides for SuiteCloud and Commerce developers.
    
-   [SuiteAnswers Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N337088.html) - a description of the resources offered in SuiteAnswers.
    
-   [Using the Help Center Window](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N336258.html) - tips and tricks to help you use the NetSuite Help Center effectively.
    
-   [Searching for Help](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N336535.html) - a description of the search tools you can use to find the help you need.
    
-   [Getting Field-Level Help](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N336742.html) - an explanation of help provided for each field on NetSuite pages.
    
-   [Training Resources](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/preface_3710623483.html) - an extensive on-demand library in the SuiteAnswers Learning Center, training and feature videos in the Help Center, and Oracle video hub.
    

For more information about contacting NetSuite Support Services, see [Support Cases in SuiteAnswers](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0707020330.html) and [NetSuite Support](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N337569.html).

Note:

For more information and resources, see [Getting Help for Administrators](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162160010710.html). This page is only visible for administrator roles.
