The NetSuite Help Center is organized into sections corresponding to different NetSuite functions.

Some tasks in NetSuite are common to most users, no matter the functional area in which they work. These tasks are covered in NetSuite Basics. For an outline, see [NetSuite Basics Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N473387.html).

These topics cover specific NetSuite product areas, including what you can do in each area and links to corresponding documentation:

-   [ERP Documentation Summary](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N129046.html)
    
-   [CRM and SFA Documentation Summary](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N129588.html)
    
-   [Commerce Documentation Summary](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N130062.html)
    
-   [SuiteCloud Platform Documentation Summary](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N131139.html)
    

The following topics list the documentation for activities that aren't specific to one product area:

-   [SuiteAnalytics Documentation Summary](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4347514288.html)
    
-   [SuiteApps Documentation Summary](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4347515321.html)
    
-   [Account Administration Documentation Summary](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4347506380.html)
    
-   [OneWorld Documentation Summary](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4347512692.html)
    
-   [Country-Specific Documentation Summary](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156042704856.html)
    

Many help topics also are available as User Guides in PDF format that you can view and print. You can find them in the User Guides section of the Help Center. For more details about using the NetSuite Help Center, see [Using the Help Center Window](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N336258.html).

In addition to the Help Center, SuiteAnswers provides support knowledge base articles, training videos, and best practices information. For more information, see [SuiteAnswers Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N337088.html).
