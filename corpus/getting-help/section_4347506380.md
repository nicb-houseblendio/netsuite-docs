NetSuite account administrators need to do many tasks to set up and maintain the NetSuite application and related customizations. The following documentation is available for these tasks:

| **Account Administration Overview** | Guidelines for setting up NetSuite and maintaining and upgrading your NetSuite account. You can also see the Account Administration guides summaries. See [Account Administration Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161460204879.html). |
| --- | --- |
| **Account Setup** | Setup of a NetSuite account requires enabling features, setting company preferences, defining classifications for NetSuite records, managing NetSuite roles and permissions, and incorporating approval routing. See [Account Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/book_N125907.html). For information about NetSuite OneWorld, see [OneWorld Documentation Summary](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4347512692.html). |
| **Email for Administrators** | Setup of DomainKeys identified mail, information about blocklists and spamlists, setup of scriptable templates, size limits of emails and attachments, and DMARC-compliant messaging in NetSuite. See [Email for Administrators](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/book_1556559731.html). |
| **Authentication** | NetSuite supports many authentication methods, including two-factor authentication, token-based authentication, OAuth 2.0, Device ID authentication, Single Sign-on (outbound, SAML, and OpenID Connect), Digital Signing, SSH Keys, secrets management, and RESTlet authentication. For more information about password requirements and policies in NetSuite, see [Authentication](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/book_4299752196.html). |
| **CSV Imports** | The Import Assistant supports bulk transfer of data from other applications into NetSuite using CSV files. The wizard lets you visually map CSV columns to NetSuite fields. See [CSV Imports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/book_4470700566.html). |
| **Auditing and Data Management** | NetSuite helps you track changes, manage internal controls, manage transactions, remove personal information, audit data changes, and avoid duplicates. See [Auditing and Data Management](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/book_4607606682.html). |
| **System Notes** | NetSuite uses System Notes to track any changes made to a record. A system note captures the date when the change was made, who made the change, the role of the user who made the change, the type of change, and the old and new value in the record. System Notes v2 captures detailed changes such as sublist information and groups the changes under high-level actions. Learn about the differences between System Notes and System Notes v2. See [System Notes Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_158644279544.html). |
| **Cloud Infrastructure** | Best practices for accessing NetSuite through the UI, SuiteTalk web services, SuiteScript, RESTlets, Single Sign-on, SuiteAnalytics Connect, or other NetSuite services. Learn about NetSuite accounts in a cloud environment, traffic health, NetSuite URLs, DataCenterUrls REST service, the REST role service, and more. See [Best Practices for Cloud Accounts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4607562099.html). |
| **Account Customization** | Customize the NetSuite UI and business logic through scripting or through point-and-click options in the UI, create custom roles and customize access, share your customization with other accounts, and integrate information from other systems. See [SuiteCloud Platform Customization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1529088392.html). |
| **NetSuite Account Types** | NetSuite offers you test accounts for developing and testing new applications and customizations. You can use release preview, sandbox, and development accounts without impacting the production account. See [Understanding NetSuite Account Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4413974567.html). |
| **Performance** | Best practices and troubleshooting tips enable you to optimize NetSuite performance. To help troubleshoot performance issues, use the Application Performance Management (APM) SuiteApp to monitor and manage NetSuite performance for business-critical operations. See [Performance](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/book_4273976157.html). |
| **Globalization** | NetSuite supports multi-language features, managing translation collections, and localization context filtering for user event and client scripts. See [Globalization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/preface_8154319431.html). |
