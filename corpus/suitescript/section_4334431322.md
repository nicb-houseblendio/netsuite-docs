| **Method Description** | Gets the current value of a sublist field (line item) in a step. |
| --- | --- |
| **Returns** | string |
| **Supported Script Types** | Suitelets For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/ui/serverWidget Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4321345532.html) |
| **Since** | 2015.2 |

## Parameters {#bridgehead_4449822054}

Note:

The options parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description | Since |
| --- | --- | --- | --- | --- |
| `options.group` | string | required | The internal ID of the sublist. | 2015.2 |
| `options.id` | string | required | The internal ID of the sublist field. | 2015.2 |
| `options.line` | number | required | The line number for the sublist field. Note: The first line number on a sublist is 0 (not 1). | 2015.2 |
