| **Object Description** | A sublist on a [serverWidget.Form](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4325835149.html) or an [serverWidget.Assistant](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4325849970.html) object. To add a sublist, use [Assistant.addSublist(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4333407203.html) or [Form.addSublist(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4339569512.html). Note: This object is read-only except for instances created using the serverWidget module using Suitelets or beforeLoad user event scripts. |
