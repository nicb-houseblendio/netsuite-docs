| **Object Description** | A sort object which is used when you create a table column, a dimension sort, or a measure sort. Use [workbook.createSort(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159051806613.html) to create this object. A sort object is used as a parameter in the [workbook.createSortByDataDimensionItem(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162886098564.html), and [workbook.createTableColumn(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159051899414.html) methods. |

The following code sample shows the syntax for this member. It is not a functional example. Also see [Full scripts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163336512698.html) in the [Tutorial: Creating a Workbook Using the Workbook API](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_163336268431.html) topic.
