| **Property Description** | An array of values used by an operator to create the condition. This property is set by passing in values for `options.fieldId`, `options.operator` and `options.values` during the of [Query.createCondition(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510780329.html) or [Component.createCondition(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510784922.html). Note: This property is not applicable to parent conditions created with the of [Query.and(conditions)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510780422.html), [Query.or(conditions)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510780444.html), or [Query.not(condition)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510780462.html). |
