| **Property Description** | The type of entity on which you want to merge duplicate records. Use a [task.DedupeEntityType](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345807845.html) enum value to set the value. Note: If you set entityType to CUSTOMER, the system will automatically include prospects and leads in the task request. |
