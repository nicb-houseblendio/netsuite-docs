| **Object Description** | Encapsulates the record fields in the dataset. Columns are equivalent to the fields you use when you build a dataset in SuiteAnalytics. For more information about datasets in SuiteAnalytics, see [Custom Workbooks and Datasets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1544122127.html). Use [dataset.createColumn(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158990102328.html) to create this object. |

The following code sample shows the syntax for this member. It is not a functional example. Also see the [Tutorial: Creating a Dataset Using the Workbook API](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_159414513430.html) topic.
