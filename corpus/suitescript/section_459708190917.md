| **Method Description** | Appends a node after the last child node of a specific element node. Returns the new child node. |
| --- | --- |
| **Returns** | [xml.Node](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4346057759.html) |
| **Supported Script Types** | Client and server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/xml Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4344917661.html) |
| **Since** | 2015.2 |

## Parameters {#bridgehead_454127441405}

Note:

The options parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.newChild` | [xml.Node](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4346057759.html) | required | [xml.Node](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4346057759.html) object to append. |

## Errors {#bridgehead_454101501464}

| Error Code | Message | Thrown If |
| --- | --- | --- |
| `SSS_XML_DOM_EXCEPTION` | HIERARCHY\_REQUEST\_ERR: An attempt was made to insert a node where it is not permitted. | Node cannot be appended. |
