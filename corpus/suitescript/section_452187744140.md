| **Property Description** | Encoding used for an XML document at the time the document was parsed. When parsing an XML document with the following declaration, the inputEncoding property is UTF-8: `<?xml version="1.0" encoding="UTF-8" standalone="yes"?>` Important: The value of this property is browser-specific. |
| --- | --- |
| **Type** | string (read-only) |
| **Module** | [N/xml Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4344917661.html) |
