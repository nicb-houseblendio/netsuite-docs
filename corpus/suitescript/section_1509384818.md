| **Method Description** | Returns an executable record action for the specified record type. If the `recordId` parameter is specified, the action object is returned only if the specified action can be executed on the specified record instance. |
| --- | --- |
| **Returns** | [action.Action](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1509380249.html) |
| **Supported Script Types** | Client and server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/action Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510761537.html) |
| **Sibling Object Members** | [N/action Module Members](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510761537.html#bridgehead_1509379229) |
| **Since** | 2018.2 |

## Parameters {#bridgehead_1509385066}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.recordType` | string | required | The record type. For a list of record types, see [record.Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4273205732.html). |
| `options.recordId` | string | optional | The record instance ID. |
| `options.id` | string | required | The ID of the action. For a list of action IDs, see [Supported Record Actions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1516982564.html). |

## Errors {#bridgehead_1519776901}

| Error Code | Thrown If |
| --- | --- |
| `RECORD_DOES_NOT_EXIST` | The specified record instance does not exist. |
| `SSS_INVALID_ACTION_ID` | The specified action does not exist on the specified record type. - or - The action exists, but cannot be executed on the specified record instance. |
| `SSS_INVALID_RECORD_TYPE` | The specified record type is invalid. |
| `SSS_MISSING_REQD_ARGUMENT` | A required parameter is missing. |
