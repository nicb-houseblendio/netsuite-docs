## Parameters {#bridgehead_4235187972}

Note:

The options parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description | Since |
| --- | --- | --- | --- | --- |
| `options.id` | number | string | required | 
-   Internal ID of the file.
-   To find the internal ID of the file in the UI, click _Documents > Files > File Cabinet_.

 | 2015.2 |
