| **Property Description** | Indicates whether the current invocation of the [reduce(reduceContext)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4413276172.html) function is the first, second, third, or fourth for the current key and its values. For an overview of events that can cause a restart, see [System Response After a Map/Reduce Interruption](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1517279626.html). When the reduce function restarts for a key, any data it wrote last time is deleted. Some logic might have run before it was interrupted, so you might want to use reduceContext.executionNo to help avoid duplicate processing. For examples of how to write a robust map/reduce script, see [Adding Logic to Handle Map/Reduce Restarts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1490987232.html). Related properties include [reduceContext.isRestarted](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4540820922.html) and [reduceContext.errors](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1516393583.html). |
