| **Method Description** | Creates an empty directory. |
| --- | --- |
| **Returns** | void |
| **Supported Script Types** | Server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | 10 units |
| **Module** | [N/sftp Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4617004932.html) |
| **Since** | 2019.2 |

## Parameters {#bridgehead_1557234036}

Note:

The options parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description | Since |
| --- | --- | --- | --- | --- |
| `options.path` | string | required | The relative path of a directory to be created. | 2019.2 |

## Errors {#bridgehead_1557234044}

| Error Code | Thrown If |
| --- | --- |
| `FTP_PERMISSION_DENIED` | Access to the file or directory on the remote FTP server was denied. |
| `FTP_DIRECTORY_NOT_FOUND` | Creating a directory in a non-existent directory. |
