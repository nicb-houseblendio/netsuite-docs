| **Property Description** | Internal ID of the search. The internal ID is available only when the search is either loaded with [search.load(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345775360.html) or after is has been saved with [Search.save()](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_452655578613.html). Typical values are 55 or 234 or 87, not a value like `customsearch_mysearch`. Any ID prefixed with `customsearch` is a script ID, not the internal system ID for a search. |
