| **Property Description** | Indicates whether to recalculate the fair value on residual elements when revenue arrangements are prospectively merged. For more information about prospective merges, see [Prospective Merges](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1498077674.html). This property is optional. This property can be set to `true` only if the [MergeArrangementsTask.mergeResidualRevenueAmounts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1554921647.html) property is also set to `true`. If the [MergeArrangementsTask.mergeResidualRevenueAmounts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1554921647.html) property is `false`, this property is ignored. The default value of this property is `false`. |
