| **Method Description** | Returns `true` if the specified namespace uniform resource identifier (URI) is the default namespace for the current node or returns `false` if the specified namespace is not the default namespace. See also [Node.namespaceURI](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_456845336913.html). Important: This method is not supported on Internet Explorer. |
| --- | --- |
| **Returns** | boolean |
| **Supported Script Types** | Client and server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/xml Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4344917661.html) |
| **Since** | 2015.2 |

## Parameters {#bridgehead_453351379394}

Note:

The options parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.namespaceURI` | string | required | The namespace URI to compare. |
