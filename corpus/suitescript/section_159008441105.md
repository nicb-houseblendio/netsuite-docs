| **Object Description** | A pivot axis object which is used with you create a pivot definition. Use [workbook.createPivotAxis(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159051729422.html) to create this object. A pivot axis object is used as a parameter in the [workbook.createPivot(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159051610759.html) method. |
