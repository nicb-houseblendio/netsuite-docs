## Parameters {#subsect_0508040041}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.start` | string | required | Start date or date time. Use the [workbook.TemporalUnit](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163104301627.html) enum to set the value. |
| `options.end` | string | required | End date or date time. Use the [workbook.TemporalUnit](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163104301627.html) enum to set the value. |

## Errors {#subsect_0508040049}

| Error Code | Thrown If |
| --- | --- |
| INVALID\_TEMPORAL\_UNIT | If `options.start` or `options.end` values are not valid temporal unit values. |
