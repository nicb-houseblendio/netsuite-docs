| **Property Description** | Internal ID of the CSV file that SuiteQL query results are exported to. This property references the same CSV file that is specified by the [SuiteQLTask.fileId](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159223852102.html) property or [SuiteQLTask.filePath](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159223855624.html) property in the corresponding [task.SuiteQLTask](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159223833809.html) object. |
