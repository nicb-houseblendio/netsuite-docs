## Parameters {#bridgehead_4392319268}

Note:

The options parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description | Since |
| --- | --- | --- | --- | --- |
| `options.algorithm` | string | required | The hash algorithm. Use the [crypto.HashAlg](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4358655346.html) enum to set the value. | 2015.2 |
