| **Method Description** | Removes a select option from certain types of select and multiselect fields. This method is usable only in select fields that were added by a front-end Suitelet or beforeLoad user event script. The IDs for these fields always have a prefix of **custpage**. |
| --- | --- |
| **Returns** | void |
| **Supported Script Types** | Client scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/currentRecord Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4625600928.html) |
| **Since** | 2016.2 |

## Parameters {#bridgehead_4794225818}

Note:

The options parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description | Since |
| --- | --- | --- | --- | --- |
| `options.value` | string | required | A string, not shown in the UI, that identifies the option. To remove all options from the list, set this field to null, as follows: `... field.removeSelectOption({ value: null, }); ...` | 2016.2 |

## Errors {#bridgehead_4794225728}

| Error Code | Thrown If |
| --- | --- |
| `SSS_INVALID_UI_OBJECT_TYPE` | A script attempts to use this method on the wrong type of field. This method can be used only on select and multiselect fields whose IDs begin with the prefix **custpage**. |
