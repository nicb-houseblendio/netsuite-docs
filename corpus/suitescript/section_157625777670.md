Deployed-mode debugging is for testing scripts that have a defined Script Deployment record. Note that plug-in implementations are not supported.

Note:

Only SuiteScript 2.1 scripts can be debugged using the 2.1 Script Debugger. You cannot use the 2.1 Script Debugger to debug SuiteScript 1.0 or 2.0 scripts.

You can debug SuiteScript 2.1 scheduled scripts, Suitelets, and user event scripts using the 2.1 Debugger. See the following help topics for more information:

-   [Debugging Deployed SuiteScript 2.1 Scheduled Scripts and Suitelets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160833595760.html)
    
-   [Debugging Deployed SuiteScript 2.1 User Event Scripts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160833600356.html)
