| **Property Description** | The selector for the axis that is not defined in the associated sort definition. In a sort definition, the sort is applied to a row or column. This property represents the selector for the other axis. |

| **Type** | [workbook.DescendantorSelfNodesSelector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163170591936.html) | [workbook.PathSelector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008382970.html) | [workbook.DimensionSelector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008193274.html) |

## Errors {#subsect_163173441272}

| Error Code | Thrown If |
| --- | --- |
