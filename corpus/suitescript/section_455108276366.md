| **Method Description** | Renders a server response into a PDF file. For example, you can pass in a response to be rendered as a PDF in a browser, or downloaded by a user. |
| --- | --- |
| **Returns** | void |
| **Supported Script Types** | Server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/render Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4412042824.html) |
| **Since** | 2015.2 |

## Parameters {#bridgehead_458503356932}

Note:

The options parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.response` | [http.ServerResponse](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4314609319.html) | required | Response that will be written to PDF. For example, the response passed from a Suitelet. |
