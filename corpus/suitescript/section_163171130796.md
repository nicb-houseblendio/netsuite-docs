| **Object Description** | A rule for a report style. Use [workbook.createReportStyleRule(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162886077520.html) to create this object. A report style rule object is used as a parameter in the [workbook.createReportStyle(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162886027908.html) method. |
