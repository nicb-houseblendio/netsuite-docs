| **Object Description** | The response from an HTTPS server (for example, Suitelet or RESTlet) to an HTTPS request from a server, such as a user event script. Textual files are re-encoded to UTF-8 by default. If you want to return a file with an alternative character encoding, see [Return a File with Alternative Character Encoding](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0808012948.html). |
