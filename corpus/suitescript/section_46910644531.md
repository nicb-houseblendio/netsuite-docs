| **Property Description** | The parent node of a node. All node types, except [xml.Attr](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345169036.html), [xml.Document](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4392323653.html), DocumentFragment, Entity, and Notation can have a parent node. See [xml.NodeType](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345174049.html) for possible node types. |
