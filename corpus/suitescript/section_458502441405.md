## Parameters {#bridgehead_452743469238}

Note:

The options parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.outputEncoding` | string | optional | Specifies the encoding for the output. Use the [encode.Encoding](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4369865177.html) enum to set the value. The default value is `encode.Encoding.UTF-8`. |
