| **Method Description** | Removes the attribute specified as a [xml.Attr](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345169036.html) object. |
| --- | --- |
| **Returns** | [xml.Attr](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345169036.html) |
| **Supported Script Types** | Client and server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/xml Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4344917661.html) |
| **Since** | 2015.2 |

## Parameters {#bridgehead_460758300780}

Note:

The options parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.oldAttr` | [xml.Attr](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345169036.html) | required | [xml.Attr](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345169036.html) object to remove. |

## Errors {#bridgehead_1457629394}

| Error Code | Message | Thrown If |
| --- | --- | --- |
| `SSS_XML_DOM_EXCEPTION` | NOT\_FOUND\_ERR: An attempt is made to reference a node in a context where it does not exist. | Attribute node cannot be removed. |
