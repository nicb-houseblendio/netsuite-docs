| **Property Description** | Internal ID of the CSV file to export query results to. The CSV file must be located in the File Cabinet. You can provide a value for this property or the [QueryTask.filePath](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159223771684.html) property. Only one of these properties can be set at the same time. If both are set, an error occurs. |
