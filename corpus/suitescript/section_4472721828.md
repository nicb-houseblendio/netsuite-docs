| **Property Description** | This array holds all values for a unique key passed to the reduce stage. These values are listed in [lexicographical order](https://en.wikipedia.org/wiki/Lexicographical_order). When the map/reduce process includes a map stage, the key-value pairs passed to the reduce stage are derived from the values written by [mapContext.write(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4472712995.html). When the map stage is skipped, the values are determined by the getInputData stage:
-   If the input type is an array, it's the value in the element.
-   If the input type is an object, it's the value in the object.
-   If the input type is a result set, the value is a `search.Result` object converted to a JSON string with `JSON.stringify()`.

Note: Each value cannot exceed 1 megabyte. |
