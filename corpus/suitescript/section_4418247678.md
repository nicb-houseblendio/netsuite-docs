| **Method Description** | Creates and returns an [https.SecureString](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4418286676.html). The input for the secure string can be a GUID or a secret. For more information about secrets, see [Secrets Management](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160216486846.html). |
| --- | --- |
| **Returns** | [https.SecureString](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4418286676.html) |
| **Supported Script Types** | Server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/https Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4418229131.html) |
| **Since** | 2015.2 |

## Parameters {#bridgehead_4420037438}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description | Since |
| --- | --- | --- | --- | --- |
| `options.input` | string | required | The string to convert to a [https.SecureString](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4418286676.html). The following patterns are accepted:
-   \\{\[a-fA-F0-9\]{32}\\} or alternatively { + <32 hexadecimal characters forming a UUID/GUID> + }
-   \\{custsecret\[a-zA-Z0-9\_\]{1,89}\\} or alternatively { + custsecret + <1 up to 89 alfanumeric characters or underscores > + }
-   specific payment-plug-in tokens

 | Release 15 Version 2 |
| `options.inputEncoding` | [https.Encoding](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4612521061.html) | optional | Identifies the encoding that the input string uses. The default value is `UTF_8`. | Release 15 Version 2 |
