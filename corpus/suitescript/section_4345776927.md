| **Method Description** | Creates a new search column as a [search.Column](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345767216.html) object. A search column represents a field on a record. You create a column for each field that you want to include in the search results. For example, if you create a column for the Sales Rep field on a customer record and specify that column when you create a search, the value of the Sales Rep field is included in the search results. Important: As you create search columns, consider the following:
-   You cannot directly create a filter or column for a list/record type field in SuiteScript by passing in its text value. You must use the field's internal ID. If you must use the field's text value, you can create a filter or column with a formula using `name: 'formulatext'`.
-   After you create a column, you cannot change the sort order of the column. If you use the same column in another search and specify a new sort order, the previous sort order is still used (the sort order that you specified using the `options.sort` parameter).

## Parameters {#bridgehead_4345776927}

Note:

The options parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description | Since |
| --- | --- | --- | --- | --- |
| `options.name` | string | required | Name of the search column. See [Column.name](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_456729370116.html). | 2015.2 |
| `options.join` | string | optional | Join ID for the search column. See [Column.join](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_460655456542.html). | 2015.2 |
| `options.summary` | string | optional | Summary type for the column. See [search.Summary](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345777923.html) and [Column.summary](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_455339294433.html). | 2015.2 |
| `options.formula` | string | optional | Formula for the search column. See [Column.formula](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_454645935058.html). | 2015.2 |
| `options.function` | string | optional | Special function for the search column. See [Column.function](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_453268676757.html). | 2015.2 |
| `options.label` | string | optional | Label for the search column. See [Column.label](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_459848266600.html). | 2015.2 |
| `options.sort` | string | optional | The sort order of the column. Use the [search.Sort](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4486581209.html) enum for this argument. Also see [Column.sort](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_456142211913.html). | 2015.2 |
