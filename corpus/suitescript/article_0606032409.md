| **Enum Description** | The language to translate documents to or from. Use this enum to set the value of the following properties:
-   `options.targetLanguage` in [machineTranslation.translate(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0606031958.html)
-   `options.language` in [machineTranslation.createDocument(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0606031651.html)

Note: JavaScript does not include an enumeration type. The SuiteScript 2.x documentation uses the term enumeration (or enum) to describe a plain JavaScript object with a flat, map-like structure. In this object, each key points to a read-only string value. |
