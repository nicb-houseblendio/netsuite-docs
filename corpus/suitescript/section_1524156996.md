With SuiteScript 2.x, you use the [N/record Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4267255811.html) and [N/currentRecord Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4625600928.html) to script with records.

In **server scripts**, use the [N/record Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4267255811.html). See the following topics for examples of working with records in server scripts:

-   [SuiteScript 2.1 User Event Script Sample](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4387799721.html#bridgehead_4485602565)
    
-   [SuiteScript 2.1 User Event Script Tutorial](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510274245.html)
    
-   [Custom Module Tutorial](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510274256.html)
    

In **client scripts**:

-   Use [N/currentRecord Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4625600928.html) methods to interact with the current record.
    
-   Use the [N/record Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4267255811.html) to load and interact with remote records.
    

See the following topics for examples of working with records in client scripts:

-   [SuiteScript Client Script Sample](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4484779426.html)
    
-   [Using the currentRecord Module in Client Scripts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1512507152.html)
    
-   [Interfacing with Remote Objects in Client Scripts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1512507271.html)
    
-   [Disable Field on Client PageInit using SuiteScript 2.0](https://suiteanswers.custhelp.com/app/answers/detail/a_id/68790)
