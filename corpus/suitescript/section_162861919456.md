## Parameters {#subsect_162861919858}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.filter` | [workbook.TableColumnFilter](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163182554335.html) | required | A filter indicating when the conditional format rule should be applied. |
| `options.style` | [workbook.Style](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163173520481.html) | required | The style to use for the conditional format rule. |
