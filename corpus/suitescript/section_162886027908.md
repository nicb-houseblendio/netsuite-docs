## Parameters {#subsect_162886028309}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.rules` | [workbook.ReportStyleRule](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163171130796.html)\[\] | required | The report style rules to apply to the report style. |
| `options.selectors` | [workbook.MeasureValueSelector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163170568904.html)\[\] | required | Selectors indicating where to apply the report style. |

## Errors {#subsect_162886028711}

| Error Code | Thrown If |
| --- | --- |
| `NO_RULE_DEFINED` | The `options.rules` parameter is an empty array. |
| `NO_SELECTORS_DEFINED` | The `options.selectors` parameter is an empty array. |
