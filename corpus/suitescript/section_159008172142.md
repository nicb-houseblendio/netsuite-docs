| **Object Description** | A data dimension object which can be used when you create a category, a legend, a pivot axis, a dimension selector, or a section. Use [workbook.createDataDimension(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159051058770.html) to create this object. A data dimension object is used as a parameter in the [workbook.createDataDimension(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159051058770.html), [workbook.createDimensionSelector(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159051255354.html), [workbook.createPivotAxis(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159051729422.html), and [workbook.createSection(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159051755688.html) methods. |
