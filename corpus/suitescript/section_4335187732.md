| **Method Description** | Updates the break type of the field. Set this value using the FieldBreakType enum The break type is used to add a break in flow layout for the field. |
| --- | --- |
| **Returns** | [serverWidget.Field](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4325837128.html) object |
| **Supported Script Types** | Suitelets User event scripts - beforeLoad entry point For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/ui/serverWidget Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4321345532.html) |
| **Since** | 2016.1 |

## Parameters {#bridgehead_4545241425}

Note:

The options parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description | Since |
| --- | --- | --- | --- | --- |
| `options.breakType` | string | required | The break type of the field. Set this value using the [serverWidget.FieldBreakType](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4332670010.html) enum | 2015.2 |
