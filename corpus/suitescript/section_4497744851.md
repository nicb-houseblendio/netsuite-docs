| **Method Description** | Creates an Alert dialog with an OK button. |
| --- | --- |
| **Returns** | [Promise Object](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4387812940.html). To run a callback function when the OK button is clicked, pass a function to the **then** portion of the Promise object. When the OK button is clicked, **true** is passed to the callback. You do not have to use the Promise object unless there is an action you want performed after the user clicks the OK button. |
| **Supported Script Types** | Client scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/ui/dialog Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4497725142.html) |
| **Since** | 2016.1 |

## Parameters {#bridgehead_4497765942}

Note:

The options parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description | Since |
| --- | --- | --- | --- | --- |
| `options.title` | string | optional | The alert dialog title. This value defaults to an empty string. | 2016.1 |
| `options.message` | string | optional | The content of the alert dialog. This value defaults to an empty string. | 2016.1 |
