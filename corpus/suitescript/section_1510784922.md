| **Method Description** | Creates a condition (query filter) based on the [query.Component](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510779141.html) object. A condition narrows the query results. The [query.Condition](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510779210.html) object acts in the same capacity as the [search.Filter](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345767603.html) object in the [N/search Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345764122.html). The primary difference is that [query.Condition](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510779210.html) objects can contain other [query.Condition](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510779210.html) objects. To create conditions:
-   Use `Component.createCondition(options)` to create conditions on the join relationships created with [Query.autoJoin(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530819144.html) and [Component.autoJoin(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530818573.html). Use this method in one of two ways:
    -   Pass in arguments for the parameters `options.fieldId`, `options.operator`, and `options.values`. The combination of these arguments translates to <_filter column_\><_operator_\><_field value_\> (for example, 'city' equals 'Boston').
    -   Pass in an argument for the parameter `options.formula`. If you use this option, you can also use the optional parameter `options.type`.
-   If needed, use [Query.createCondition(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510780329.html) to create conditions on the initial query definition created with [query.create(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510275581.html).
-   If you have multiple conditions, use them to create a new nested condition with the methods [Query.and(conditions)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510780422.html), [Query.or(conditions)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510780444.html), and [Query.not(condition)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510780462.html).
-   Assign your simple or nested condition to [Query.condition](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510781832.html). For an example, see [Syntax](#subsect_1530619891).

## Parameters {#subsect_1510784922}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.fieldId` | string | required if `options.operator` and `options.values` are used | The field that the condition applies to. This value sets the [Condition.fieldId](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510789485.html) property. Obtain this value from the Records Catalog. The Records Catalog lists every record type and field that is available using SuiteAnalytics Workbook and the N/query module. For more information, see [Records Catalog Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_159367781370.html). |
| `options.operator` | string | required | The operator used by the condition. This value sets the [Condition.operator](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510789501.html) parameter. Use the appropriate [query.Operator](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510275752.html) enum value to pass in your argument. This enum holds all the supported values for this parameter. |
| `options.values` | string\[\] | number\[\] | \[\] | Date\[\] | [query.RelativeDate](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544109440.html)\[\] | [query.Period](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158289614570.html)\[\] | required if `options.fieldId` and `options.operator` are used, and `options.operator` does **not** have a value of `query.Operator.EMPTY` or `query.Operator.EMPTY_NOT` | An array of values to use for the condition. This value sets the [Condition.values](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510789525.html) property. |
| `options.formula` | string | required if `options.fieldId` is **not** used | The formula used to create the condition. This value sets the [Condition.formula](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510789560.html) property. For more information about formulas, see [Formulas in Searches](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_5143710889.html) and [SQL Expressions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2833020.html). |
| `options.type` | string | required if `options.formula` is used | If you use the `options.formula` parameter, use this parameter to explicitly define the formula's return type. This value sets the [Condition.type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510789582.html) property. Use the appropriate [query.ReturnType](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510878969.html) enum value to pass in your argument. This enum holds all the supported values for this parameter. |
| `options.aggregate` | string | optional | An aggregate function to run on the condition. An aggregate function performs a calculation on the condition values and returns a single value. This value sets the [Condition.aggregate](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510789603.html) property. Use the appropriate [query.Aggregate](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510878932.html) enum value to pass in your argument. This enum holds all the supported values for this parameter. |
| `options.caseSensitive` | boolean | optional | Use this parameter to specify whether filtered text is case sensitive or not. This parameter only applies to text fields. You may encounter script errors if this parameter is set with numbers or date values. You can use this parameter to improve the performance of the final query. By default, this value is set to `false`. |

The following code sample shows the syntax for this member. It is not a functional example. For a complete script example, see [N/query Module Script Samples](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0304035624.html).
