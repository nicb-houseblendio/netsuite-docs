| **Method Description** | Returns a [runtime.Script](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4296527813.html) object that represents the currently executing script. Use this method to get properties and parameters of the currently executing script and script deployment. If you want to get properties for the session or user, use [runtime.getCurrentSession()](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4296529736.html) or [runtime.getCurrentUser()](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4296529105.html) instead. |
| --- | --- |
| **Returns** | [runtime.Script](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4296527813.html) |
| **Supported Script Types** | Client and server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/runtime Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4296359529.html) |
| **Since** | 2015.2 |
