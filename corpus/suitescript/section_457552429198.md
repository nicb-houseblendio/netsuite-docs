| **Returns** | [file.File](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4247974825.html) that contains a PDF or HTML document |

## Parameters {#bridgehead_455190063476}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.entityId` | number | required | The internal ID of the transaction associated with the bom. |
| `options.printMode` | string | optional | The print output type. Use the [render.PrintMode](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4412215015.html) enum to set this value. By default, uses the company/user preference for print output. |
| `options.inCustLocale` | boolean | optional | Applies when advanced templates are used. Print the document in the customer's locale. If basic printing is used, this parameter is ignored and the transaction form is printed in the customer's locale. |
