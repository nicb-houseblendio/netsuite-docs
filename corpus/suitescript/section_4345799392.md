| **Object Description** | The status of an asynchronous workflow initiation task placed into the NetSuite task queue by [WorkflowTriggerTask.submit()](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_459607788085.html). Use [task.checkStatus(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345805891.html) with the unique ID for the asynchronous workflow initiation task to get the WorkflowTriggerTaskStatus object. |
