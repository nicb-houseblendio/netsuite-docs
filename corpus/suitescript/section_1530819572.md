| **Property Description** | Whether the sort is case sensitive. This property is set during the of [Query.createSort(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510780402.html) and [Component.createSort(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510785047.html). If a sort is case sensitive (and the sort direction is ascending), rows with column values that start with uppercase letters are listed before rows with column values that start with lowercase letters. If a sort is not case sensitive, uppercase and lowercase letters are treated the same. For example, the following list of items is sorted using a case-sensitive sort with a sort direction of ascending:
-   Banana
-   Orange
-   apple
-   grapefruit
-   kiwi

Here is the same list of items sorted using a regular (not case-sensitive) sort with a sort direction of ascending:

-   apple
-   Banana
-   grapefruit
-   kiwi
-   Orange

The default value of this property is `false`. |
