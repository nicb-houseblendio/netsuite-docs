| **Object Description** | An error returned from the translation service when calling [machineTranslation.translate(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0606031958.html). The translation service returns an error if a provided document couldn't be translated. An error might occur if the text to translate isn't formatted correctly (for example, if it contains unrecognized characters). This object includes properties for the ID of the document that the error relates to ([Error.documentId](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0604035154.html)) and the text of the error message ([Error.message](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0604035337.html)). When passing documents to [machineTranslation.translate(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0606031958.html), this object is included in the returned [machineTranslation.Response](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0606030944.html) object (in the [Response.errors](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0606031259.html) property) if an error occurred while translating the documents. If no errors occurred, the [Response.errors](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0606031259.html) property is empty. |
