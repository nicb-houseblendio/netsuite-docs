## Parameters {#bridgehead_453463684081}

Note:

The options parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.id` | string | required | The internal ID name of the button. The internal ID must be in lowercase and without spaces. |
| `options.label` | string | required | The label for the button. |
| `options.functionName` | string | optional | The function name to call when clicking this button. The function name must be the name of the method defined in a custom module client script. For examples, see [N/currentRecord Samples](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157071004224.html). Important: Custom module client scripts with the specified function must be attached to the form. To learn more, see [Form.clientScriptModulePath](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4625445350.html) and [Form.clientScriptFileId](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4340375753.html). |
