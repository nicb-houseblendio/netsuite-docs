| **Property Description** | The list of documents used to generate the streamed response. This property is an array of [llm.Document](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_73085600635.html) objects, each of which represents a document provided to [llm.generateTextStreamed(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_46075557997.html) or [llm.generateTextStreamed.promise(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_48093225962.html). This property has a value only if a provided document was used to generate the response. Note: The value of this property is not available until the entire response from the LLM has been generated. |
