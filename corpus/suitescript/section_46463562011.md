| **Method Description** | Creates a CDATA section node of type DOCUMENT\_FRAGMENT\_NODE with the specified data and returns the new [xml.Node](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4346057759.html) object. |
| --- | --- |
| **Returns** | [xml.Node](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4346057759.html) |
| **Supported Script Types** | Client and server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/xml Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4344917661.html) |
| **Since** | 2015.2 |

## Parameters {#bridgehead_456825195311}

Note:

The options parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.data` | string | required | Data for the new CDATA section node. |

## Errors {#bridgehead_454657531737}

| Error Code | Message | Thrown If |
| --- | --- | --- |
| `SSS_XML_DOM_EXCEPTION` | Invalid argument type, expected string: data | Cannot create CDATA section node with the specified data. |
