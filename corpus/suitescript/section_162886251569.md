## Parameters {#subsect_162886251917}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.backgroundColor` | [workbook.Color](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162887285281.html) | string | optional | The background color. |
| `options.backgroundImage` | string | optional | The background image. |
| `options.backgroundPosition` | [workbook.PositionPercent](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163170729070.html) | [workbook.PositionUnits](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163170762618.html) | [workbook.PositionValues](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163170827938.html) | optional | The background position. |
| `options.color` | [workbook.Color](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162887285281.html) | string | optional | The font color. |
| `options.fontSize` | [workbook.FontSize](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162887352651.html) | optional | The font size. |
| `options.fontStyle` | [workbook.FontStyle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162887378565.html) | optional | The font style. |
| `options.fontWeight` | [workbook.FontWeight](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163104222816.html) | optional | The font weight. |
| `options.textAlign` | [workbook.TextAlign](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163104334844.html) | optional | The alignment of text. |
| `options.textDecorationColor` | [workbook.Color](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162887285281.html) | string | optional | The text decoration color. |
| `options.textDecorationLine` | [workbook.TextDecorationLine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163104347221.html) | optional | The text decoration line. |
| `options.textDecorationStyle` | [workbook.TextDecorationStyle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163104360654.html) | string | optional | The text decoration style. |

## Errors {#subsect_162886252301}

| Error Code | Thrown If |
| --- | --- |
| `INVALID_COLOR` | The value of any of the `options.backgroundColor`, `options.color`, or `options.textDecorationColor` parameters is not included in the [workbook.Color](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162887285281.html) enum and is not a [workbook.Color](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162887285281.html) object. |
| `INVALID_FONT_SIZE` | The value of the `options.fontSize` parameter is not included in the [workbook.FontSize](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162887352651.html) enum. |
| `INVALID_FONT_STYLE` | The value of the `options.fontStyle` parameter is not included in the [workbook.FontStyle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162887378565.html) enum. |
| `INVALID_FONT_WEIGHT` | The value of the `options.fontWeight` parameter is not included in the [workbook.FontWeight](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163104222816.html) enum. |
| `INVALID_IMAGE` | The value of the `options.backgroundImage` parameter is not included in the [workbook.Image](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163104240054.html) enum. |
| `INVALID_TEXT_ALIGN` | The value of the `options.textAlign` parameter is not included in the [workbook.TextAlign](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163104334844.html) enum. |
| `INVALID_TEXT_DECORATION_LINE` | The value of the `options.textDecorationLine` parameter is not included in the [workbook.TextDecorationLine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163104347221.html) enum. |
| `INVALID_TEXT_DECORATION_STYLE` | The value of the `options.textDecorationStyle` parameter is not included in the [workbook.TextDecorationStyle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163104360654.html) enum. |
