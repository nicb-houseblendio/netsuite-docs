| **Method Description** | Method used to fetch the previous segment of data (bounded by [search.PageRange](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4486559010.html)). Moves the current page to previous range. |
| --- | --- |
| **Returns** | Void |
| **Supported Script Types** | Client and server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | 5 units |
| **Module** | [N/search Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345764122.html) |
| **Since** | 2016.1 |

## Errors {#bridgehead_4492595808}

| Error Code | Message | Thrown If |
| --- | --- | --- |
| `INVALID_PAGE_RANGE` | Invalid page range. | The page range is invalid, or when the page is the first page. |
