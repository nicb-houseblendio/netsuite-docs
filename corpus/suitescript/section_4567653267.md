| **Method Description** | Returns the value or values of a response header. If multiple values are assigned to the header name, the values are returned as an Array. For more information, see [HTTPS Header Information](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4418229131.html#subsect_1558529145). |
| --- | --- |
| **Returns** | string | string\[\] |
| **Supported Script Types** | Server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/https Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4418229131.html) |
| **Since** | 2015.2 |

## Parameters {#bridgehead_4567653175}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description | Since |
| --- | --- | --- | --- | --- |
| `options.name` | string | required | The name of the header. | 2015.2 |

## Errors {#bridgehead_4567653137}

| Error Code | Message | Thrown If |
| --- | --- | --- |
| `SSS_MISSING_REQD_ARGUMENT` | Missing a required argument: {param name} | The `options.name` parameter is not specified. |
