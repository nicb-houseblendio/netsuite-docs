| **Method Description** | Creates an explicit directional join relationship from a child component to its parent component (an inverse join). This method sets the [Component.source](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510785292.html) property on the returned [query.Component](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510779141.html) object. Use the method [query.create(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510275581.html) to create your initial query definition ([query.Query](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510275177.html)). The initial query definition uses one query type. For available query types, see [query.Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510878994.html). After you create the initial query definition, use this method to create your first join as an explicit directional join from another component to this component. Note: This method is a shortcut for the chained [Query.root](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510781874.html) and [Component.joinFrom(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530818705.html): `Query.root.joinFrom(options)`. The [Query.root](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510781874.html) property references the root component, which is a [query.Component](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510779141.html) object. Important: The N/query module supports the same record types that are supported by the SuiteAnalytics Workbook interface. For more information, see [Available Record Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1543418356.html). |

## Parameters {#subsect_1530819225}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.fieldId` | string | required | The column type (field type) that joins the parent component to the new component. Obtain this value from the Records Catalog. The Records Catalog lists every record type and field that is available using SuiteAnalytics Workbook and the N/query module. For more information, see [Records Catalog Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_159367781370.html). |
| `options.source` | string | required | The query type of the component joined to this component. This value sets the [Component.source](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510785292.html) property. This value can be described as the inverse relationship of this component, and it determines the source query type of the newly joined component. |

## Errors {#subsect_1531773037}

| Error Code | Thrown If |
| --- | --- |
| `RELATIONSHIP_ALREADY_USED` | The specified join relationship already exists. |
