| **Property Description** | Search settings for this search as an array of [search.Setting](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1536244919.html) objects or a string array of column names. Search settings let you specify search parameters that are typically available only in the UI. You set this value with an array of [search.Setting](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1536244919.html) objects or a single [search.Setting](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1536244919.html) object. You can create a [search.Setting](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1536244919.html) object by calling [search.createSetting(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1536171305.html). You can also set this value with an array of column names, each of which is a string. The supported values for a [search.Setting](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1536244919.html) object differ depending on the search parameter that you set. For more information, see [Setting.name](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1536177181.html) and [Setting.value](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1536177235.html). |

## Errors {#bridgehead_1536244096}

| Error Code | Thrown If |
| --- | --- |
| `SSS_INVALID_SRCH_SETTING` | An unknown search parameter name is provided. |
| `SSS_INVALID_SRCH_SETTING_VALUE` | An unsupported value is set for the provided search parameter name. |
