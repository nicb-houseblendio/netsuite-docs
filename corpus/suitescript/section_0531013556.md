The inventory count transaction type supports the following actions: startcount, completecount, reject, and approve.

For help working with this record in the UI, see [Inventory Count](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3898859490.html).

For information about SuiteScript 2.0 record actions, see the following topics:

-   [Overview of Record Action and Macro APIs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1509640242.html)
    
-   [N/action Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510761537.html)
    

## startcount {#subsect_0531013951}

| **Corresponding UI Button** | Start Count |
| --- | --- |
| **Action Description** | Changes the status of Open inventory counts to Started. |
| **Returns** | Object that contains the inventory count ID |
| **Supported Script Types** | Client and server scripts For additional information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | 20 units |
| **Since** | 2024.2 |

### Parameters {#subsect_0531014215}

See [action.execute(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1509391388.html) for details about parameters required for the execution of any action. The allocate action does not support any additional parameters.

## completecount {#subsect_0531014337}

| **Corresponding UI Button** | Complete Count |
| --- | --- |
| **Action Description** | Changes the status of counts from Started to Completed/Pending approval. |
| **Returns** | Object that contains the inventory count ID |
| **Supported Script Types** | Client and server scripts For additional information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | 5 units |
| **Since** | 2024.2 |

### Parameters {#subsect_0531014458}

See [action.execute(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1509391388.html) for details about parameters required for the execution of any action. The allocate action does not support any additional parameters.

## approve {#subsect_0531014548}

| **Corresponding UI Button** | Approve |
| --- | --- |
| **Action Description** | Changes the status of completed counts to Approved. Creates inventory adjustments if the count results do not match the current on-hand quantities. |
| **Returns** | Object that contains the inventory count ID |
| **Supported Script Types** | Client and server scripts For additional information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | 60 units |
| **Since** | 2024.2 |

### Parameters {#subsect_0531014706}

See [action.execute(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1509391388.html) for details about parameters required for the execution of any action. The allocate action does not support any additional parameters.

## reject {#subsect_0531014729}

| **Corresponding UI Button** | Reject |
| --- | --- |
| **Action Description** | Reassigns the Open status to completed counts. |
| **Returns** | Object that contains the inventory count ID |
| **Supported Script Types** | Client and server scripts For additional information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | 5 units |
| **Since** | 2024.2 |

### Parameters {#subsect_0531014744}

See [action.execute(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1509391388.html) for details about parameters required for the execution of any action. The allocate action does not support any additional parameters.

## Sample Code {#subsect_0531014921}

Refer to the following samples for using the start count action from the client side and server side:

            `require(['N/action'], function(actionMod) {      // client side example   actionMod.getActions.promise({recordType: 'inventorycount'}).then(function(actions) {     var startAction = actions.startcount;     startAction.promise({recordId: 1}).then(function(result) {       console.log("Inventory Count with id " + result.response.id + " has been started");     });   });      // server side example   var result = actionMod.executeAction({id: 'startcount', recordType: 'inventorycount', params: {recordId: 1}}); });`
