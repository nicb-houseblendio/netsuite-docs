Employee type values are used to categorize employees for descriptive or reporting purposes. These values display on the Human Resources subtab of employee records. System-defined values include the following: Contractor, Exempt (in the U.S., an employee not entitled to overtime pay), Officer, Owner, Regular Employee, and Statutory Employee.

For help working with this record in the user interface, see [Setting Up Employee Related Lists](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1394576.html).

The internal ID for this record is `employeetype`.

See the [SuiteScript Records Browser](https://system.netsuite.com/help/helpcenter/en_US/srbrowser/Browser2026_1/script/record/employeetype.html) for all internal IDs associated with this record.

Note:

For information about using the SuiteScript Records Browser, see [Working with the SuiteScript Records Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N3169369.html) in the NetSuite Help Center.

## Supported Script Types {#bridgehead_156278877808}

The employee record is scriptable in both client and server SuiteScript.

## Supported Functions {#bridgehead_156278878310}

The following SuiteScript functionality is supported:

-   Read
    
-   Create
    
-   Update
    
-   Copy
    
-   Delete
    
-   Search
    

## Script Sample {#bridgehead_156278709813}

The following sample shows how to create an employee type record.

          `require(['N/record'], function (record) {     var myRecord = record.create({         type: record.Type.EMPLOYEE_TYPE     });       myRecord.setValue({         fieldId: 'name',         value: Exempt     });       myRecord.save(); });`
