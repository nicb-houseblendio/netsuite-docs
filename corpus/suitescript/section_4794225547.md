| **Property Description** | Returns the type of a body or sublist field. For example, the value can return `text`, `date`, `currency`, `select`, `checkbox`, and other similar values. For more information about possible return values, see [format.Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4388844232.html). The maximum character limit for select field types is 801. |
