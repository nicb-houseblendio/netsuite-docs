The content in this help topic pertains to SuiteScript 2.1.

| **Object Description** | The embeddings response returned from the LLM. Use the [llm.embed(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_76083302199.html) or the [llm.embed.promise(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_52083437973.html) method to retrieve an embeddings response from the LLM. Important: Embeddings include the semantic information of the original data and should be treated with the same level of sensitivity. Embeddings created from sensitive data must be protected, stored, logged, shared, retained, and deleted according to the same rules as the original data. |
