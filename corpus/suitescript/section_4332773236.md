| **Method Description** | Adds a step to an assistant. Steps define each page of the assistant. Use [Assistant.isNotOrdered](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4333544993.html) to control if the steps must be completed sequentially or in no specific order. If you want to create help text for the step, you can use [AssistantStep.helpText](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4334438434.html) on the object returned. |
| --- | --- |
| **Returns** | [serverWidget.AssistantStep](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4325851003.html) object |
| **Supported Script Types** | Suitelets For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/ui/serverWidget Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4321345532.html) |
| **Since** | 2015.2 |

## Parameters {#bridgehead_4333407587}

Note:

The options parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description | Since |
| --- | --- | --- | --- | --- |
| `options.id` | string | required | The internal ID for this step (for example, 'entercontacts'). | 2015.2 |
| `options.label` | string | required | The label for this step (for example, 'Enter Contacts'). By default, the step appears vertically in the left panel of the assistant. | 2015.2 |
