## Parameters {#bridgehead_4426015212}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description | Since |
| --- | --- | --- | --- | --- |
| `options.type` | enum | required | The value of the caching duration. Use [http.CacheDuration](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4426027147.html) to set this value. When used with a Suitelet, if this value is set to UNIQUE, then the Suitelet will never be cached and will always be executed if there's a request to its URL. | 2015.2 |
