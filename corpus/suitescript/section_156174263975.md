| **Object Description** | Encapsulates a task to remove personal information (PI). This object includes lists of the record, field, and workflow IDs to remove personal information from, as well as history replacement information. Use [piremoval.createTask(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156174907211.html) to create a [piremoval.PiRemovalTask](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156174263975.html) object, or use [piremoval.loadTask(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156174989271.html) to load a PI removal task as a [piremoval.PiRemovalTask](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156174263975.html) object. To save the object, use [PiRemovalTask.save()](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156174691190.html). To execute the PI removal, use [PiRemovalTask.run()](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156174672468.html). |
