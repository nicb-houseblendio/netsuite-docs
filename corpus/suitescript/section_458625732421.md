| **Method Description** | Creates a PDF or HTML object of a packing slip. |
| --- | --- |
| **Returns** | [file.File](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4247974825.html) that contains a PDF or HTML document |
| **Supported Script Types** | Server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | 10 units |

## Parameters {#bridgehead_453270202636}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.entityId` | number | required | The internal ID of the transaction associated with the packing slip. |
| `options.printMode` | string | optional | The print output type. Set using the [render.PrintMode](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4412215015.html) enum. By default, uses the company/user preference for print output. |
| `options.formId` | number | optional | The packing slip form number. |
| `options.fulfillmentId` | number | optional | The fulfillment ID number. |
| `options.inCustLocale` | boolean | optional | Applies when advanced templates are used. Print the document in the customer's locale. If basic printing is used, this parameter is ignored and the transaction form is printed in the customer's locale. |
