| **Method Description** | Updates the clear data with the specified encoding. |
| --- | --- |
| **Returns** | void |
| **Supported Script Types** | Server scripts For additional information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/crypto Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4358549582.html) |
| **Since** | 2015.2 |

## Parameters {#bridgehead_458785949706}

Note:

The options parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.input` | string | required | The clear data to be updated. |
| `options.inputEncoding` | enum | optional | The input encoding. Use the [encode.Encoding](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4369865177.html) enum to set the value. The default value is `encode.Encoding.UTF-8`. |
