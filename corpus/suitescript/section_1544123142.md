| **Property Description** | The condition used to select record IDs of records for which the action is to be executed. This parameter is specified with the task.ActionCondition enum. This is used in conjunction with RecordActionTask.paramCallback. If RecordActionTask.paramCallback is not specified, this default callback is used: `function(v) { return { recordId: v }; }`. |
