Note:

The content in this help topic pertains to SuiteScript 2.1.

The following sample sends a "Hello World" prompt to the default NetSuite large language model (LLM) and receives the response. It also shows the number of AI Units remaining. For more information, see [NetSuite AI Units and NetSuite Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_2163848930.html) and [AI Units FAQ](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_8144753226.html).

For instructions about how to run a SuiteScript 2.1 code snippet in the debugger, see [On-Demand Debugging of SuiteScript 2.1 Scripts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157625776929.html). Step through the code until the line before the end of the script to see the response text returned from the LLM and the number of AI Units remaining.

Note:

This sample script uses the `require` function so that you can copy it into the SuiteScript Debugger and test it. You must use the `define` function in an entry point script (the script you attach to a script record and deploy). For more information, see [SuiteScript 2.1 Script Basics](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1504638761.html) and [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html).

          `/** *@NApiVersion 2.1 */ // This example shows how to query the default LLM require(['N/llm'],     function(llm) {                 const response = llm.generateText({             // modelFamily is optional. When omitted, the Cohere Command A model is used.             prompt: "Hello World!",             modelParameters: {                 maxTokens: 1000,                 temperature: 0.2,                 topK: 3,                 topP: 0.7,                 frequencyPenalty: 0.4,                 presencePenalty: 0             }         });         const responseText = response.text;         const remainingUsage = llm.getRemainingUsage(); // View remaining AI Units     });`
