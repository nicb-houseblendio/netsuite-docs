| **Method Description** | Parses a String into a W3C XML document object. This API is useful if you want to query a structured XML document more effectively using either the Document API or NetSuite built-in XPath functions. Note: You can also use this method to validate your XML. If you pass a malformed string in as the `options.text` argument, `Parser.fromString` returns an `SSS_XML_DOM_EXCEPTION` error. |
| --- | --- |
| **Returns** | [xml.Document](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4392323653.html) |
| **Supported Script Types** | Client and server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/xml Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4344917661.html) |
| **Since** | 2015.2 |

## Parameters {#bridgehead_4344924257}

Note:

The options parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.text` | string | required | String being converted to an [xml.Document](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4392323653.html). |

## Errors {#bridgehead_4447764686}

| Error Code | Thrown If |
| --- | --- |
| `SSS_XML_DOM_EXCEPTION` | The input XML string is malformed. |
