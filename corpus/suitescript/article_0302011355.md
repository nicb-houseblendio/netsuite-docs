The campaign family record helps you refine the campaign family for a marketing campaign.

For help working with this record in the UI, see [Campaign Families](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1006480.html).

The internal ID for this record is `campaignfamily`.

Note:

For information about using the SuiteScript Records Browser, see [Working with the SuiteScript Records Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N3169369.html) in the NetSuite Help Center.

## Supported Script Types {#subsect_69131930267}

The campaign family record is scriptable in both client and server SuiteScript.

## Supported Functions {#subsect_65131936989}

The campaign family record supports the following functions: create, read, update, and delete. The following functions aren't supported: copy, search, and transform.

## Prerequisites {#subsect_82131940652}

You must enable the Marketing Automation feature before you can use this record with SuiteScript. For more information, see [Marketing Automation Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N973384.html).

## Code Samples {#subsect_7131944184}

The following samples show common actions with campaign family scripting.

### Create script example: {#subsect_0302012017}

              `var record = nlapiCreateRecord('campaignfamily, true); record.setFieldValue('description', 'Test description'); record.setFieldValue('name', 'Test name'); record.setFieldValue('inactive', 'F'); var recordId = nlapiSubmitRecord(record);` 
            

### Update script example: {#subsect_0302012103}

              `record = nlapiLoadRecord('campaignfamily, recordId); record.setFieldValue('description', 'Test description updated'); record.setFieldValue('name', 'Test name updated'); record.setFieldValue('inactive', 'T'); recordId = nlapiSubmitRecord(record);` 
            

### Delete script example: {#subsect_0302012143}

              `nlapiDeleteRecord('campaignfamily, recordId);`
