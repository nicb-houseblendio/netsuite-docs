Note: The parameters and errors thrown for this method are the same as those for [record.load(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4267258486.html). ## Parameters {#bridgehead_4601436645}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description | Since |
| --- | --- | --- | --- | --- |
| `options.type` | string | required | The record type. Use the following guidelines:
-   When loading an instance of a standard NetSuite record type, set this value by using the [record.Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4273205732.html) enum.
-   When loading an instance of a custom record type, set this value by using the custom record type's string ID. For help finding this ID, see [Custom Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3204194.html).

 | 2015.2 |
| `options.id` | number | required | The internal ID of the existing record instance in NetSuite. The internal ID of the record is displayed on the list page for the record type. |  |
| `options.isDynamic` | boolean | optional | Determines whether the record is loaded in dynamic mode.

-   If set to `true`, the record is loaded in dynamic mode.
-   If set to `false`, the record is loaded in standard mode.

By default, this value is `false`. Note: For additional information about standard and dynamic mode, see [record.Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4205869719.html) and [SuiteScript 2.x Standard and Dynamic Modes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1524156901.html). | 2015.2 |
| `options.defaultValues` | Object | optional | Name-value pairs containing default values of fields in the new record. By default, this value is empty. |  |
