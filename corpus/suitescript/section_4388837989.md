| **Method Description** | Parses a value from the appropriate preference format to its raw value. The appropriate preference format is the one selected in the Date Format field at _Home > Set Preferences_. For a `datetime` or `datetimetz` value, use this method to convert a Date Object into a string based on the specified timezone. Note: This method is overloaded when you format a `datetime` or `datetimetz` value. |
| --- | --- |
| **Returns** | `Datetime` or `datetimetz` values are returned as a Date Object. Note: If the value given is not valid or parsable, the original value passed to `options.value` is returned. Note: For client scripts, the string returned is based on the user's system time. For server scripts, the string returned is based on the current time in the Pacific Time Zone. Daylight Savings Time does apply. For more information, see [Parse a String to a Date Object](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_2100456218.html). |
| **Supported Script Types** | Client and server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html) |
| **Governance** | None |
| **Module** | [N/format Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4388721627.html) |
| **Since** | 2015.2 |

## Parameters {#bridgehead_4388844116}

This method is overloaded when you format a `datetime` or `datetimetz` value.

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description | Since |
| --- | --- | --- | --- | --- |
| `options.value` | string | required | The input data to parse. | 2015.2 |
| `options.type` | string | required | The field type (for example, `DATE`, `CURRENCY`, `INTEGER`). Use the [format.Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4388844232.html) enum to set this value. | 2015.2 |

The table below applies to datetime and datetimeTZ values only.

| Parameter | Type | Required / Optional | Description | Since |
| --- | --- | --- | --- | --- |
| `options.value` | string | required | The string that contains the date and time information in the specified timezone. | 2015.2 |
| `options.type` | string | required | The field type (either `DATETIME` or `DATETIMETZ`). Use the [format.Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4388844232.html) enum to set this value. | 2015.2 |
| `options.timezone` | enum | optional | The time zone represented by the options.value string. Use the [format.Timezone](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4407050795.html) enum to set this value. If a time zone is not specified, the time zone is based on user preference. If the time zone is invalid, the time zone is set to GMT. | 2015.2 |
