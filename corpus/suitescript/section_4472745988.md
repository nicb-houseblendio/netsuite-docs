| **Property Description** | Holds all serialized errors thrown from the [map(mapContext)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4413275809.html) function. May also hold the `SSS_APP_SERVER_RESTART` error code, which is recorded in the event of an application server restart. |
| --- | --- |
| **Type** | iterator |
| **Since** | 2015.2 |

## Members {#subsect_1515713864}

| Member | Type | Required/Optional | Description |
| --- | --- | --- | --- |
| iterator().each([parameters](#subsect_1515717738)) | function | required | Executes one time for each error. |

## parameters {#subsect_1515717738}

| Member | Type | Required/Optional | Description |
| --- | --- | --- | --- |
| iteratorFunction(key, error, executionNo) See also [functionParameters](#subsect_1515707886). | function | required | Provides logic to be executed during each iteration. |

## functionParameters {#subsect_1515707886}

| Parameter | Type | Required/Optional | Description |
| --- | --- | --- | --- |
| key | string | optional | Represents a key that was passed to the map stage for processing. |
| error | string | optional | The error thrown during processing of the corresponding key. |
| executionNo | number | optional | Indicates whether the error occurred during the first, second, third, or fourth attempt to process the key. |
