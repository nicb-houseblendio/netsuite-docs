| **Method Description** | Returns whether NetSuite Next is active for the user running the script. Note: For scheduled and map/reduce scripts, the return value depends on the user running the script. If NetSuite runs the script as the System user, this method returns `false`. For more information about how NetSuite determines the user who runs a script, see [Scheduled Script Submission](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4658507760.html) and [Map/Reduce Script Submission](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1504747863.html). |
| --- | --- |
| **Returns** | boolean |
| **Supported Script Types** | Client and server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
