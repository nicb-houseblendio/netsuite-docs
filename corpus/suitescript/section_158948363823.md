| **Method Description** | Executes the dataset and returns the result set as paginated data (the same as in [N/query Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510275060.html)). The maximum number of results per page is 1000. The minimum number of results per page is 5, except for the last page, which may include fewer than 5 results. |

## Parameters {#subsect_158948364622}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.pageSize` | number | required | The size of each page in the dataset results. The maximum allowed value is 1000. The minimum allowed value is 5. The default page size is 50 results per page. |
