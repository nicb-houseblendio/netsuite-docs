| **Object Description** | Encapsulates a template object that produces HTML and PDF printed forms utilizing advanced PDF/HTML template capabilities. The template object includes methods that pass in a template as string to be interpreted by FreeMarker, and render interpreted content in your choice of two different formats: as HTML output to an [http.ServerResponse](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4314609319.html) object, or as XML string that can be passed to [render.xmlToPdf(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_459185424803.html) to produce a PDF. This object is available when the Advanced PDF/HTML Templates feature is enabled. |
