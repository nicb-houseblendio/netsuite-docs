## Parameters {#bridgehead_1558023369}

Note:

The `options` parameter is a JavaScript object.

Warning:

These parameters are mutually exclusive, you can always use only one of them.

| Parameter | Type | Required / Optional | Description | Since |
| --- | --- | --- | --- | --- |
| `options.currency` | string | required if `options.locale` is not specified | Code of the currency that is used by formatter. Use the [format.Currency](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1558027087.html) enum to set this value. | 2019.2 |
| `options.locale` | string | required if `options.currency` is not specified | Code of the locale that is used by formatter. | 2021.1 |
