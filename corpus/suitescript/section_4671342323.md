| **Method Description** | Adds multiple rows to the portlet. |
| --- | --- |
| **Returns** | Object |
| **Entry Point** | [render(params)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4407951965.html) |
| **Since** | 2016.2 |

## Parameters {#bridgehead_4671342323}

Note:

The options parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description | Since |
| --- | --- | --- | --- | --- |
| `options.rows` | [search.Result](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345767112.html)\[\] | object\[\] | required | An array of rows that consist of either a search. Result array, or an array of name/value pairs. Each pair should contain the value for the corresponding Column object in the list. | 2016.2 |

## Syntax {#bridgehead_4671342367}

The following code snippet shows the syntax for this member. Note that this isn't a working example. For a complete script example, see [SuiteScript 2.1 Portlet Script Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4387799288.html).

          `... params.portlet.addRows({ rows: [{ columnid1: 'value1', columnid2: 'value2' }, { columnid1: 'value2', columnid2: 'value3' }] }); ...`
