Pivots help you analyze specific parts of your dataset using features like dimensions, measures, filters, and report styles. To create a pivot, you need to use fields that are already part of the underlying dataset.

For more information about pivots in SuiteAnalytics Workbook, see [Workbook Pivot Tables](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158042187611.html).

You can create a pivot using [workbook.createPivot(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159051610759.html). This method creates a [workbook.Pivot](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008434619.html) object. To create a pivot, you'll need to provide these required parameters:

-   `columnAxis` - The column axis for the pivot. Use [workbook.createPivotAxis(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159051729422.html) to create axes. For more information, see [Pivot Axes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_163354458410.html).
    
-   `dataset` or `datasetLink` - The underlying dataset or linked dataset for the pivot. You can provide either a dataset (using the `dataset` parameter) or a linked dataset (using the `datasetLink` parameter), but you can't use both simultaneously. For more information, see [Datasets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_163353416302.html) and [Dataset Linking](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_163354438805.html).
    
-   `id` - A script ID for the pivot. You can provide this ID to [Workbook.runPivot(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159068644727.html) to obtain the results of the pivot.
    
-   `name` - A name for the pivot.
    

          `var myPivot = workbook.createPivot({     columnAxis: myColumnAxis,     dataset: myDataset,     id: 'MyPivot',     name: 'My Pivot',     rowAxis: myRowAxis });` 
        

You can also provide these optional parameters for [workbook.createPivot(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159051610759.html):

-   `aggregationFilters` - A set of conditional filters or limiting filters that are applied to the pivot. Use [workbook.createConditionalFilter(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159050988221.html) to create conditional filters, and use [workbook.createLimitingFilter(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159051462385.html) to create limiting filters. For more information about filters in SuiteAnalytics Workbook, see [Workbook Visualization Filters](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544211325.html).
    
-   `filterExpressions` - A set of simple, non-aggregated value-based filters for the pivot. You provide these filters as a set of [workbook.Expression](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008229845.html) objects. Use [workbook.createExpression(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159051315304.html) to create these expressions. For more information, see [Expressions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_163386238329.html).
    
-   `portletName` - A name for the pivot when it is displayed as a portlet in NetSuite.
    
-   `reportStyles` - A set of report styles for the pivot. Use [workbook.createReportStyle(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162886027908.html) to create report styles. For more information, see [Styles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_163354460183.html).
    

          `var myPivot = workbook.createPivot({     aggregationFilters: myAggregationFilters,     columnAxis: myColumnAxis,     dataset: myDataset,     filterExpressions: myFilterExpressions,     id: 'MyPivot',     name: 'My Pivot',     portletName: 'My Pivot as a Portlet',     reportStyles: [myFirstReportStyle, mySecondReportStyle],     rowAxis: myRowAxis });`
