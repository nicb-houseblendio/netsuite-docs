Note:

JavaScript does not include an enumeration type. The SuiteScript 2.x documentation uses the term enumeration (or enum) to describe a plain JavaScript object with a flat, map-like structure. In this object, each key points to a read-only string value.

| **Enum Description** | Holds the string values for supported date codes in relative dates. This enum is used to pass the date ID argument to [query.createRelativeDate(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544108154.html). It is also used as the value of the [RelativeDate.dateId](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544109453.html) property. When [query.createRelativeDate(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544108154.html) is called, the enum value that you specify is set as the value of the [RelativeDate.dateId](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544109453.html) property. When creating a relative date using [query.createRelativeDate(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544108154.html), use the values in this enum to specify a date relative to the current date. For example, to create a relative date that represents the date a certain number of days before the current date, use the `DateId.DAYS_AGO` enum value. To create a relative date that represents the date a certain number of months after the current date, use the `DateId.MONTHS_FROM_NOW` enum value. The values in this enum might look similar to the values in the [query.RelativeDateRange](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544111773.html) enum, but each enum is used for a different purpose:
-   Use `query.DateId` enum values to create a [query.RelativeDate](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544109440.html) object using [query.createRelativeDate(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544108154.html). After you create this object, you can use it in query conditions that you create using [Query.createCondition(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510780329.html) or [Component.createCondition(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510784922.html).
-   Use [query.RelativeDateRange](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544111773.html) enum values directly in query conditions that you create using [Query.createCondition(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510780329.html) or [Component.createCondition(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510784922.html). Each value in the [query.RelativeDateRange](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544111773.html) enum represents a date range, and you can use these values in the `values` parameter of [Query.createCondition(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510780329.html) or [Component.createCondition(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510784922.html).
