| **Method Description** | Performs a global search asynchronously against a single keyword or multiple keywords. Returns an array of [search.Result](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345767112.html) objects with four columns: **name**, **type**, **info1**, and **info2**. Note: The parameters and errors thrown for this method are the same as those for [search.global(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345775747.html). For more information about promises, see [Promise Object](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4387812940.html). |
