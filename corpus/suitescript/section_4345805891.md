| **Method Description** | Returns a task status object associated with a specific task ID. You can check the status of the following task types:
-   CSV import
-   Entity deduplication
-   Map/reduce script
-   Query
-   Record action
-   Scheduled script
-   Search
-   SuiteQL
-   Workflow trigger

 |
| --- | --- |
| **Returns** | [task.CsvImportTaskStatus](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345798793.html) | [task.EntityDeduplicationTaskStatus](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345799153.html) | [task.MapReduceScriptTaskStatus](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345798546.html) | [task.QueryTaskStatus](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159223798559.html) | [task.RecordActionTaskStatus](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544125423.html) | [task.ScheduledScriptTaskStatus](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345798266.html) | [task.SearchTaskStatus](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4799344334.html) | [task.SuiteQLTaskStatus](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159223884561.html) | [task.WorkflowTriggerTaskStatus](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345799392.html) |

## Parameters {#subsect_159406361680}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.taskId` | string | required | Unique ID of the task to check the status of. |
