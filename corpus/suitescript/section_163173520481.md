| **Object Description** | A style object which defines attributes such as background color, font size, font style, text alignment, and more. Use [workbook.createStyle(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162886251569.html) to create this object. A style object is used as a parameter in the [workbook.createConditionalFormatRule(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162861919456.html) and [workbook.createReportStyle(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162886027908.html) methods. method. |
