| **Method Description** | Creates a message that can be displayed or hidden near the top of the page. |
| --- | --- |
| **Returns** | [message.Message](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4497858078.html). |
| **Supported Script Types** | Client scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/ui/message Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4497735093.html) |
| **Since** | 2016.1 |

## Parameters {#bridgehead_4497874085}

Note:

The options parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description | Since |
| --- | --- | --- | --- | --- |
| `options.type` | [message.Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4498688050.html) | required | The type of message to create. Set this value using the [message.Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4498688050.html) enum. | 2016.1 |
| `options.title` | string | optional | The message title. This value defaults to an empty string. | 2016.1 |
| `options.message` | string | optional | The content of the message. This value defaults to an empty string. | 2016.1 |
| `options.duration` | int | string | optional | The amount of time, in milliseconds, to show the message. The default is 0, which shows the message until Message.hide() [Message.hide()](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4610801857.html) is called. If you use a string, it will be parsed to a number. If you specify a duration both when you create the message and when you show it using [Message.show(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4497866594.html), the value when you show it takes precedence. | 2018.2 |
