| **Object Description** | A chart definition object. A chart is a workbook component that enables you to visualize your dataset query results using predefined chart and graph types, such as line graphs and bar charts. A chart definition is used when you create a workbook. Use [workbook.createChart(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008909052.html) to create this object. |
