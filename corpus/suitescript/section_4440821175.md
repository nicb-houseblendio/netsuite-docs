| **Method Description** | Attaches a record asynchronously to another record. Note: The parameters and errors thrown for this method are the same as those for [record.attach(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4267284169.html). For more information about promises, see [Promise Object](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4387812940.html). |
| --- | --- |
| **Returns** | [Promise Object](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4387812940.html) |
| **Synchronous Version** | [record.attach(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4267284169.html) |
| **Supported Script Types** | Client scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | 10 units |
| **Module** | [N/record Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4267255811.html) |
| **Since** | 2015.2 |

## Parameters {#bridgehead_4601369784}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description | Since |
| --- | --- | --- | --- | --- |
| `options.record` | [record.Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4205869719.html) | required | The record to attach. | 2015.2 |
| `options.record.type` | string | required | The type of record to attach. Set the value using the [record.Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4273205732.html) enum. To attach a file from the File Cabinet to a record, set type to `file`. | 2015.2 |
| `options.record.id` | number | string | required | The internal ID of the record to attach. | 2015.2 |
| `options.to` | [record.Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4205869719.html) | required | The record that the `options.record` gets attached to. | 2015.2 |
| `options.to.type` | string | required | The record type of the record to attach to. Set the value using the [record.Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4273205732.html) enum. To attach a file from the File Cabinet to a record, set type to `file`. | 2015.2 |
| `options.to.id` | number | string | required | The internal ID of the record to attach to. | 2015.2 |
| `options.attributes` | Object | optional | The name-value pairs containing attributes for the attachment. By default, this value is null. | 2015.2 |
