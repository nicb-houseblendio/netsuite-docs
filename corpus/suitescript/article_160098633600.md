Some SuiteScript 1.0 functions and objects do not directly map to any SuiteScript 2.1 module method, property, or enum. This includes SuiteScript 1.0 APIs that either do not have direct SuiteScript 2.1 API equivalents or the mapping is not intuitive (such as a mapping from a method to a property, or to a new module altogether).

The following table provides the functions and objects that do not have direct or intuitive mapping to SuiteScript 2.1. This information is a summary of what is included in the [SuiteScript 1.0 to SuiteScript 2.1 API Map](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4752722762.html).

Refer to the [SuiteScript 1.0 Documentation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_7151939532.html) for information about SuiteScript 1.0 functions and objects.

| SuiteScript 1.0 Function or Object | What to use when writing SuiteScript 2.1 scripts |
| --- | --- |
| **Functions** |
| nlapiAddDays(d, days) | Standard JavaScript supplies date functions to add or subtract days from a Date object. SuiteScript 2.1 is also compatible with third-party JavaScript APIs that provide date functions. |
| nlapiAddMonths(d, months) | Standard JavaScript supplies date functions to add or subtract months from a Date object. SuiteScript 2.1 is also compatible with third-party JavaScript APIs that provide date functions. |
| nlapiEncrypt(s, algorithm, key) | Hashing and HMAC functionality are provided by the [N/crypto Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4358549582.html). Encoding functionality is provided by the [N/encode Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4369847722.html). |
| nlapiGetCurrentLineItemDateTimeValue(type, fieldId, timeZone) | This functionality is provided by the [N/format Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4388721627.html). Specifically, the [format.Timezone](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4407050795.html) enum used in the [format.format(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4388843892.html) and [format.parse(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4388837989.html) methods. |
| nlapiGetDateTimeValue(fieldId, timeZone) |
| nlapiGetLineItemDateTimeValue(type, fieldId, lineNum, timeZone) |
| nlapiSetCurrentLineItemDateTimeValue(type, fieldId, dateTime, timeZone) |
| nlapiSetDateTimeValue(fieldId, dateTime, timeZone) |
| nlapiSetLineItemDateTimeValue(type, fieldId, lineNum, dateTime, timeZone) |
| nlapiSetRecoveryPoint() | Scripting recovery points for scheduled scripts are no longer necessary. See [SuiteScript 2.1 Scheduled Script Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4387799491.html) and [Map/Reduce Script Type Differences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160098628783.html#section_160104924027). |
| nlapiYieldScript() |
| **Objects** |
| nlobjCredentialBuilder.replace(string1, string2) | This functionality is not provided by a SuiteScript 2.1 module or method. You need to manually perform the replacement of credential strings within your script. |
| nlobjPortlet.setRefreshInterval(n) | Although there is a Portlet object in SuiteScript 2.1, that object does not include a refresh function. It is no longer needed in SuiteScript 2.1 scripts. |
| nlobjRecord.getCurrentLineItemDateTimeValue(type,fieldId, timeZone) | This functionality is provided by the [N/format Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4388721627.html). Specifically, the [format.format(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4388843892.html) and [format.parse(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4388837989.html) methods. |
| nlobjRecord.getDateTimeValue(fieldId, timeZone) |
| nlobjRecord.getLineItemDateTimeValue(type, fieldId, lineNum, timeZone) |
| nlobjRecord.setCurrentLineItemDateTimeValue(type, fieldId, dateTime, timeZone) |
| nlobjRecord.setDateTimeValue(fieldId, dateTime, timeZone) |
| nlobjRecord.setLineItemDateTimeValue(type, fieldId, lineNum, dateTime, timeZone) |
| nlobjResponse.setContentType(type, name, disposition). | The functionality to specify content type and encoding type is specified using HTTP headers in SuiteScript 2.1. For more information, see [HTTP Header Information](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4296361104.html#subsect_1558529000) and [HTTPS Header Information](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4418229131.html#subsect_1558529145). |
| nlobjResponse.setEncoding(encodingType). |
| nlobjSublist.setLineItemValues(values) | Use the [Sublist.setSublistValue(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_456052185058.html) method of the [N/ui/serverWidget Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4321345532.html) to set each value in the sublist individually. |

Along with functions and objects that are not directly mapped from SuiteScript 1.0 to SuiteScript 2.1, there are also some functions and objects in SuiteScript 1.0 that map to SuiteScript 2.1, but those mapping may not be intuitive. For example, the functions and objects provided to perform CSV imports in SuiteScript 1.0 are now provided by the [N/task Samples](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157072886263.html) in SuiteScript 2.1. All mappings are provided in the [SuiteScript 1.0 to SuiteScript 2.1 API Map](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4752722762.html). The map includes notes to aid in understanding mappings between SuiteScript 1.0 and SuiteScript 2.1 that are not intuitive. Also refer to all help topics for the mapped SuiteScript 2.1 modules to fully understand the difference (if any) in functionality provided by SuiteScript 1.0 and by SuiteScript 2.1.

Further, some SuiteScript 1.0 functions and objects map to SuiteScript 2.1 module properties instead of module methods. The [SuiteScript 1.0 to SuiteScript 2.1 API Map](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4752722762.html) clearly indicates these type of mappings. Look in the Notes column - it will indicate the mapping is to a SuiteScript 2.1 module property.

If converting your SuiteScript 1.0 scripts to SuiteScript 2.1 is not feasible in your situation, you can use SuiteScript 2.1 RESTlet scripts to extend the capabilities of your existing SuiteScript 1.0 scripts. For more information, see [Using SuiteScript 2.x Scripts with SuiteScript 1.0 Scripts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_4155500631.html).
