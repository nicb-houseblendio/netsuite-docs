| **Property Description** | Internal ID of the CSV file that query results are exported to. This property references the same CSV file that is specified by the [QueryTask.fileId](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159223756577.html) property or [QueryTask.filePath](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159223771684.html) property in the corresponding [task.QueryTask](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159223655124.html) object. |
