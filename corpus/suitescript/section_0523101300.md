## Errors {#subsect_0523101427}

| Error Code | Thrown If |
| --- | --- |
| `WRONG_PARAMETER_TYPE` | The value specified for this property is not a [workbook.DescendantorSelfNodesSelector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163170591936.html), a [workbook.PathSelector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008382970.html), a [workbook.DimensionSelector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008193274.html), or a [workbook.ChildNodesSelector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163405579141.html). |
