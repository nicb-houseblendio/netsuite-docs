| **Property Description** | The collection of [search.PageRange](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4486559010.html) objects that divide the entire result set into smaller groups. This property includes page range information with the key and label for rendering. Page range indexes start at 0. |
| --- | --- |
| **Type** | [search.PageRange](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4486559010.html)\[\] This property is read-only. |
| **Module** | [N/search Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345764122.html) |
| **Since** | 2016.1 |
