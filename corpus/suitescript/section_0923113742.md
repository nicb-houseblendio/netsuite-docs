Note:

The content in this help topic pertains to SuiteScript 2.1.

| **Method Description** | Creates a [certificate.Signer](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1547242551.html) object for signing plain strings. If the given PGP key contains multiple valid signing sub keys, the most recently added will be used. This behavior is consistent with [MessageData.encrypt(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0923093832.html) method. |
| --- | --- |
| **Returns** | [certificate.Signer](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1547242551.html) |
| **Supported Script Types** | Server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | 10 units |
| **Module** | [N/pgp Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_5095832176.html) |
| **Sibling Module Members** | [N/pgp Module Members](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_5095832176.html#subsect_5121135606) |
| **Since** | 2022.2 |

## Parameters {#subsect_96155201800}

| Parameter | Type | Required / Optional | Description | Since |
| --- | --- | --- | --- | --- |
| `options.key` | [pgp.Key](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0921033205.html) | required | The pgp key. | 2022.2 |
| `options.algorithm` | string | required | Hash algorithm | 2022.2 |

## Errors {#subsect_8155224168}

| Error Code | Thrown If |
| --- | --- |
| `UNSUPPORTED_COMBINATION_OF_KEY_AND_HASH_ALGORITHMS` | The given key's encryption algorithm is not compatible with the given hash algorithm. |
| `PGP_NO_SIGNING_KEY_FOUND_IN_KEY_PARAM_1` | No valid signing (sub)keys are found in the given key. |
