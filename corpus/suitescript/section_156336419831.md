| **Property Description** | The application ID for this search. An application ID identifies a SuiteApp project and is a fully qualified name with the following notation: `<publisher_id>.<project_id>` For example, com.netsuite.mysuiteapp and org.mycompany.helloworld are application IDs. To use this feature, the Show App ID Field preference must be enabled in your NetSuite account. For more information, see [SuiteCloud Development Framework Account Preferences (SDF Developers Only)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4730893710.html). |
