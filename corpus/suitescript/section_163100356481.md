This transaction is available when the Expense Report feature is enabled at _Setup > Company > Enable Features_, on the Employees subtab.

For help working with this record in the UI, see [Expense Reporting](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N907845.html).

The internal ID for this record is `importedemployeeexpense`. The internal ID of the new subrecord is `importedemplexpensedetail`.

See the [SuiteScript Records Browser](https://system.netsuite.com/help/helpcenter/en_US/srbrowser/Browser2026_1/script/record/importedemployeeexpense.html) for all internal IDs associated with this record.

Note:

For information about using the SuiteScript Records Browser, see [Working with the SuiteScript Records Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N3169369.html) in the NetSuite Help Center.

## Supported Script Types {#bridgehead_163100452119}

The imported employee expense record is scriptable in both client and server SuiteScript.

## Supported Functions {#bridgehead_163545232515}

The imported employee expense record is fully scriptable. It can be created, updated, copied, deleted, and searched using SuiteScript. It can also be transformed.
