| **Method Description** | Adds a submit button to a form. Note: If the row count exceeds 25, sorting is not supported on static sublists created using this method. |
| --- | --- |
| **Returns** | [serverWidget.Button](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4325806317.html) object |
| **Supported Script Types** | Suitelets User event scripts - beforeLoad entry point For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/ui/serverWidget Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4321345532.html) |
| **Since** | 2016.1 |

## Parameters {#bridgehead_4543597666}

Note:

The options parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description | Since |
| --- | --- | --- | --- | --- |
| `options.label` | string | optional | The label for this button. If no label is provided, the label defaults to 'Save'. | 2016.1 |
