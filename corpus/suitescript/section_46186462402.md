| **Property Description** | Initialization vector for the cipher payload. You can pass this value to [crypto.createDecipher(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4358650886.html). Note: This property is encoded in `encode.Encoding.HEX` regardless of the options.inputEncoding parameter value in the `cipher.final` method. |
