| **Object Description** | Encapsulates a file within NetSuite. Note: This object only encapsulates a file's metadata. Content is only loaded into memory (and returned as a string) when you call the [File.getContents()](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4229269811.html). Content from CSV or text files can be accessed line by line using [File.appendLine(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4769938149.html) or [File.lines.iterator()](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4769955095.html). Important: Binary content must be base64 encoded. Create a new `file.File` Object (up to 10MB in size) with the [file.create(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4223861820.html) method. After you create a new `file.File`, you can:
-   upload it to the NetSuite File Cabinet with the [File.save()](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4229271179.html) method.
-   attach it to an email or fax without saving it to the File Cabinet.

Important: If you want to save the file to the NetSuite File Cabinet, you must set a NetSuite File Cabinet folder with the [File.folder](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4229265810.html) property. You must do this before you call [File.save()](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4229271179.html). Returns reader object [File.getReader()](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1543843814.html) and iterator of segments [File.getSegments(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1543844004.html). |
