Conditional formatting rules help you highlight important data in your workbook visualizations based on criteria you set. For instance, you can customize cell backgrounds, font sizes, styles, and more.

For more information about conditional formatting in SuiteAnalytics Workbook, see [Conditional Formatting](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161125973915.html).

You can create a conditional formatting rule using [workbook.createConditionalFormatRule(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162861919456.html). This method creates a [workbook.ConditionalFormatRule](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163170087636.html) object. To create a rule, you'll need to provide these parameters:

-   `filter` - A filter indicating when the conditional formatting rule should be applied. Use [workbook.createTableColumnFilter(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159051973321.html) to create this filter as a [workbook.TableColumnFilter](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163182554335.html) object. To create a filter, combine an operator with a set of values. Use operators (or their string equivalents) from the [query.Operator](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510275752.html) enum. Values are specified based on the column the filter is used for and the operator used.
    
                  `var myFilter = workbook.createTableColumnFilter({     operator: query.Operator.ANY_OF,     values: [myArrayOfValues] });` 
                
    
-   `style` - The style to apply when the filter evaluates to `true`. Create a style using [workbook.createStyle(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162886251569.html) which returns a [workbook.Style](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163173520481.html) object. When you create a style, you can use supporting methods such as [workbook.createColor(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162861840772.html) and [workbook.createFontSize(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162862018622.html) to define the different attributes of a style. For more information, see [Styles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_163354460183.html).
    
                  `var myStyle = workbook.createStyle({     backgroundColor: workbook.createColor({         red: 255,         green: 255,         blue: 0     }); });` 
                
    

Use both parameters to create a conditional formatting rule:

          `var myRule = workbook.createConditionalFormatRule({     filter: myFilter,     style: myStyle });` 
        

Once you have your rules, use [workbook.createConditionalFormat(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162861895977.html) to combine them into a single [workbook.ConditionalFormat](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163170026948.html) object:

          `var myConditionalFormat = workbook.createConditionalFormat({     rules: [myFirstRule, mySecondRule] });` 
        

To apply the rules to a column, pass a [workbook.ConditionalFormat](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163170026948.html) object to [workbook.createTableColumn(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159051899414.html). For more information, see [Table Columns](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_163354454437.html).

          `var myTableColumn = workbook.createTableColumn({     datasetColumnAlias: 'MyColumn',     conditionalFormats: [myFirstConditionalFormat, mySecondConditionalFormat] });`
