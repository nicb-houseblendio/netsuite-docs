| **Property Description** | The features to extract from the document (such as fields, tables, or text). Use values from the [documentCapture.Feature](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0704103522.html) enum to set the value of this property. If you don't specify any features, the `TEXT_EXTRACTION` and `TABLE_EXTRACTION` features are used by default. For more information, see the description of the `options.features` parameter in [documentCapture.documentToStructure(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0704102801.html). |
