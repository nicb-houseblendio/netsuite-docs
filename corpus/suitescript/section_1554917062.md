| **Property Description** | Holds an array of internal IDs of the revenue arrangement records to merge. This property is required. You must specify a value for this property before you can submit the task for processing using [MergeArrangementsTask.submit()](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1554926010.html). If you do not specify any revenue arrangement record IDs, a `NO_REVENUE_ARRANGEMENT_IDS_ARE_INCLUDED_IN_YOUR_INPUT` error is thrown when you call [MergeArrangementsTask.submit()](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1554926010.html) for the task. Invalid IDs are ignored. If no revenue elements were found for the specified revenue arrangement record IDs, a `NO_REVENUE_ELEMENTS_WERE_FOUND_FOR_THE_REVENUE_ARRANGEMENT_IDS_YOU_INPUT` error is thrown when you call [MergeArrangementsTask.submit()](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1554926010.html). |
