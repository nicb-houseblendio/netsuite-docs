## Creating the Client SuiteScript File {#subsect_1751320801}

Use one of the following options to create the client script file for this tutorial:

-   [Writing the Client SuiteScript File](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_1503351407.html).
    
-   [Copying the Full Script](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_1503351379.html).
    

Note:

All entry point scripts need to include the required components described in [SuiteScript 2.1 Anatomy of a Script](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510274310.html).

## Uploading the Script File to NetSuite {#bridgehead_1501632681}

After you create the file, complete the following steps to upload it to NetSuite:

#### To upload the script file:

1.  In the NetSuite UI, go to _Documents > File > SuiteScripts_.
    
2.  In the left pane, select the SuiteScripts folder and click **Add File**.
    
3.  Follow the prompts to find the helloWorld.js file on your computer and upload it.
    

After you upload the file, you can edit it in the File Cabinet if needed. For more information, see [Editing Files in the File Cabinet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N542738.html).
