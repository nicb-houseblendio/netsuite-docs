This topic maps SuiteScript 1.0 Functions (prefixed with 'nlapi') to their corresponding SuiteScript 2.1 APIs. All functions are listed alphabetically in one table.

Note:

NetSuite does not support calling SuiteScript 1.0 APIs from SuiteScript 2.1 scripts.

Note:

To view a mapping of SuiteScript 1.0 Objects (prefixed with 'nlobj') to their corresponding SuiteScript 2.1 APIs, see [SuiteScript 1.0 to SuiteScript 2.1 API Map - Objects (nlobj)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4752730521.html).

| nlapiAddDays(d, days) | See Notes | See Notes | This API does not have a SuiteScript 2.1 equivalent. Use the following JavaScript to add or subtract days from a Date object: dateObj.setDate(dateObj.getDate() + or - days) For example: `var tomorrow = new Date(); tomorrow.setDate(tomorrow.getDate() + 1);` Note: SuiteScript 2.1 is also compatible with third-party JavaScript APIs that provide this functionality. For information about using third-party APIs with SuiteScript 2.1, see [SuiteScript 2.1 Custom Modules](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4704097697.html). |
