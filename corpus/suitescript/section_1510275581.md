| **Method Description** | Creates a [query.Query](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510275177.html) object. Use this method to create your initial query definition. The initial query definition uses one query type. For available query types, see [query.Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510878994.html). After you create the initial query definition, use [Query.autoJoin(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530819144.html) to create your first join. Then use [Query.autoJoin(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530819144.html) or [Component.autoJoin(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530818573.html) to create all subsequent joins. For standard record types, the query type that you specify is validated immediately and must be one of the values in the [query.Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510878994.html) enum. For custom record types, the query type that you specify is not validated until the query is executed using [Query.run(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510780212.html) or [Query.runPaged(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510780277.html) (or using the promise versions of these methods). If you specify a query type for a custom record type that does not exist, this method allows you to create the query and does not throw an error. However, when you perform the query, an error is thrown. Important: The N/query module lets you create and run queries using the SuiteAnalytics Workbook query process. You can use the N/query module to load and delete existing queries, but you cannot save queries. You can save queries using the SuiteAnalytics Workbook interface. For more information, see [Navigating SuiteAnalytics Workbook](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1544220943.html). For more information about creating queries, see [Scripting with the N/query Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1532440865.html). |

## Parameters {#subsect_1510778559}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.type` | string | required | The query type that you want to use for the initial query definition. Use the [query.Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510878994.html) enum to set this value (for an example, see [Syntax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510275511.html#subsect_1547575881)). When you perform `query.create(options)`, the [Query.type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510275511.html) property is set based on this value. Important: The N/query module supports the same record types that are supported by the SuiteAnalytics Workbook interface. For more information, see [Available Record Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1543418356.html). |
| `options.columns` | Object\[\] | optional | An array of objects to be used as query columns. If you specify a value for this parameter, the [Query.createColumn(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510780373.html) method is called on each object in the. Important: You must include a [query.Column](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510779196.html) object in your query definition to avoid scripting errors. This object is an optional parameter with the [query.create(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510275581.html) method, but at least one Column must be created for every query definition. For more information, see the syntax example below. |
| `options.condition` | Object | optional | A condition for the query. If you specify a value for this parameter, the [Query.createCondition(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510780329.html) method is called on the object you specify. |
| `options.sort` | Object\[\] | optional | An array of objects representing sort options. If you specify a value for this parameter, the [Query.createColumn(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510780373.html) and [Query.createSort(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510780402.html) methods are called on each object in the . |

## Errors {#subsect_1555436467}

| Error Code | Thrown If |
| --- | --- |
| `INVALID_RCRD_TYPE` | The specified query type is invalid. Note: This error is not thrown if you specify a custom record type as the query type. Custom record types are validated when the query is executed using [Query.run(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510780212.html) or [Query.runPaged(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510780277.html) (or using the promise versions of these methods). |
