| **Property Description** | The name of the search parameter. This property is set when you call [search.createSetting(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1536171305.html). The following values are supported for this property:
-   `consolidationtype`: This value corresponds to the Consolidated Exchange Rate setting.
-   `includeperiodendtransactions`: This value corresponds to the Show Period End Transactions setting.

 |
| --- | --- |
| **Type** | string This property is read-only. |
| **Module** | [N/search Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345764122.html) |
| **Since** | 2018.2 |
