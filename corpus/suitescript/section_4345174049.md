| **Enum Description** | Holds the string values for the supported node types. Use this enum to determine the type of a node in an XML document and to set the [Node.nodeType](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_456552673339.html) property. Note: Enum values are constants and therefore read-only. |
