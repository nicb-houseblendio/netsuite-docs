| **Method Description** | Sets a field as a totalling column, which is used to calculate and display a running total for the sublist. |
| --- | --- |
| **Returns** | [serverWidget.Sublist](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4325844858.html) object |
| **Supported Script Types** | Suitelets User event scripts - beforeLoad entry point For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/ui/serverWidget Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4321345532.html) |
| **Since** | 2015.2 |

## Parameters {#bridgehead_4549603546}

Note:

The options parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.id` | string | required | The internal ID of the field used to calculate the total field. |

## Syntax {#bridgehead_458850036620}

Important:

This script sample uses the `define` function, which is required for an entry point script (a script you attach to a script record and deploy). You must use the `require` function if you want to copy the script into the SuiteScript Debugger and test it.
