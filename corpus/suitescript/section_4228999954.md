| **Enum Description** | Enumeration that holds the string values for supported file types. Use this enum to set the value of the [File.fileType](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4229267378.html) property. Note that the [File.fileType](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4229267378.html) property is read-only. It's value must be set with [file.create(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4223861820.html). See [N/file Module Script Samples](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0303032537.html) for an example. Note: JavaScript does not include an enumeration type. The SuiteScript 2.0 documentation utilizes the term enumeration (or enum) to describe the following: a plain JavaScript object with a flat, map-like structure. Within this object, each key points to a read-only string value. |
