| **Object Description** | A SuiteQL query. SuiteQL is a query language based on the SQL-92 revision of the SQL database query language. It provides advanced query capabilities you can use to access your NetSuite records and data. Use [Query.toSuiteQL()](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157960522744.html) to create this object. This method converts an existing [query.Query](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510275177.html) object to its corresponding SuiteQL representation as a `query.SuiteQL` object. You can use [SuiteQL.run()](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157960470046.html) to run the query and obtain the results as a [query.ResultSet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510779235.html) object. You can also use [SuiteQL.runPaged(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157960491275.html) to run the query as a paged query and obtain the results as a [query.PagedData](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510779273.html) object. When you convert a [query.Query](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510275177.html) object to a `query.SuiteQL` object, the resulting SuiteQL query is the same as the original query. It includes the same query result columns, sort order, and conditions that were set on the original query. When you run the resulting SuiteQL query using [SuiteQL.run()](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157960470046.html) or [SuiteQL.runPaged(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157960491275.html), you receive the same results as you would if you ran the original query using [Query.run(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510780212.html) or [Query.runPaged(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510780277.html). For more information and examples of using SuiteQL in the N/query module, see [SuiteQL in the N/query Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157960623712.html). For more information about SuiteQL in general, see [SuiteQL](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156257770590.html). |
