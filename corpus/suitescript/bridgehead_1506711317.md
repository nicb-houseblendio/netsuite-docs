Each scheduled script run can use up to 10,000 usage units. For more info, see [SuiteScript Governance and Limits](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N3350651.html).

SuiteScript 2.1 scheduled scripts don't let you set recovery points or yield. There's no direct replacement for `nlapiYieldScript()` or `nlapiSetRecoverPoint()`. If you need to process lots of records, switch to the [SuiteScript 2.1 Map/Reduce Script Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4387799161.html), which supports yielding and works much like scheduled scripts.
