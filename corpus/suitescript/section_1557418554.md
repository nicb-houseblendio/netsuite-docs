| **Property Description** | The password of the key. Either the GUID or API secret script ID for working with passwords is accepted. You can create a GUID using [Form.addCredentialField(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4337770901.html). For more information about API Secrets, see [Secrets Management](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160216486846.html) |
