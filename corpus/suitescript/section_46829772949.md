| **Property Description** | Value of an attribute. The value of the attribute is returned as a string. Character and general entity references are replaced with their values. For example, a character reference such as `&#160;` or an entity reference such as `&#nbsp;` is replaced with a non-breaking space. Note: If you set this value, it creates a text node with the unparsed contents of the string, for example, any characters that an XML processor would recognize as markup are instead treated as literal text. |
| --- | --- |
| **Type** | string |
| **Module** | [N/xml Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4344917661.html) |
