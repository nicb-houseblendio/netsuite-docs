| **Object Description** | A tool result returned from [llm.createToolResult(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_40090425838.html). This object represents the output of running a tool in response to a tool call request from the large language model (LLM). Tool results let you communicate the outcome of the tool handler logic (such as the result of a SuiteQL query or a business operation) back to the LLM. The LLM uses these results to generate a more complete and informed response. You create this object using the [llm.createToolResult(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_40090425838.html) method. This object includes properties for the originating tool call request that this result corresponds to ([ToolResult.call](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_92104450377.html)) and the output values produced by running the tool ([ToolResult.outputs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_68104522023.html)). After you create this object, you can provide it to subsequent [llm.generateText(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1014032554.html) or [llm.generateTextStreamed(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_46075557997.html) calls, which lets the LLM incorporate the results of the tool call and return a more accurate and relevant response. |
