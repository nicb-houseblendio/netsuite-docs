NetSuite loads the util Object is loaded by default for all script types. You do not need to load it manually. However, you can choose to load it using the [N/util Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4569538303.html), for testing purposes.

Note:

SuiteScript 2.1 provides global objects including [log Object](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4387812838.html) and [util Object](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4387813290.html). If you are using the words 'log' or 'util' as variable names in your SuiteScript 1.0 scripts and you have both SuiteScript 1.0 and SuiteScript 2.1 scripts running on the same record you will receive an error. Both the 'log' and 'util' words are reserved in SuiteScript 2.1. You will need to update your SuiteScript 1.0 scripts that use 'log' or 'util' as variables names.
