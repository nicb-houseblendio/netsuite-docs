The content in this help topic pertains to SuiteScript 2.1.

| **Enum Description** | Holds values for the type of a field. These enum values are returned as part of a [documentCapture.Field](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0703031446.html) object (in the [Field.type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0704094825.html) property). They describe the category or type of data extracted for a specific field, providing semantic meaning and helping with structured processing of the data. [documentCapture.Field](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0703031446.html) objects are included in extracted content from a document only when the `documentCapture.Feature.FIELD_EXTRACTION` feature is specified when you call [documentCapture.documentToStructure(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0704102801.html). |
| --- | --- |
| **Module** | [N/documentCapture Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_8134325498.html) |
| **Supported Script Types** | Server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Since** | 2025.2 |
