| **Method Description** | Gets the value at a given index in [Result.values](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510859061.html). Value types correspond to the [ResultSet.types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510857678.html) property. Values correspond to the values for [ResultSet.columns](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510857693.html). |
| --- | --- |
| **Returns** | <string | number | Date | null> (read-only) |
| **Supported Script Types** | Client and server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/query Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510275060.html) |
| **Parent Object** | [query.Result](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510779258.html) |
| **Sibling Object Members** | [Result Object Members](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510275060.html#subsect_1510858930) |
| **Since** | 2018.2 |

## Parameters {#subsect_2114815879}

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options` | number | required | The index of the element from [Result.values](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510859061.html) that you want the method to return. |
