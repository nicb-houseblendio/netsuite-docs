## Parameters {#subsect_162862131847}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.measures` | Array<[workbook.CalculatedMeasure](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163169891173.html) | [workbook.DataMeasure](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163170291911.html)\> | required | The measures for the measure selector. |

## Errors {#subsect_162862132256}

| Error Code | Thrown If |
| --- | --- |
| `NO_MEASURE_DEFINED` | The `options.measures` parameter is an empty array. |
