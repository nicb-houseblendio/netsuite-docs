The campaign offer record helps you refine the campaign offer for a marketing campaign.

For help working with this record in the UI, see [Campaign Offers](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1019075.html).

The internal ID for this record is `campaignoffer`.

Note:

For information about using the SuiteScript Records Browser, see [Working with the SuiteScript Records Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N3169369.html) in the NetSuite Help Center.

## Supported Script Types {#subsect_83134019840}

The campaign offer record is scriptable in both client and server SuiteScript.

## Supported Functions {#subsect_94134023897}

The campaign offer record supports the following functions: create, read, update, and delete. The following functions aren't supported: copy, search, and transform.

## Prerequisites {#subsect_55134027142}

You must enable the Marketing Automation feature before you can use this record with SuiteScript. For more information, see [Marketing Automation Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N973384.html).

## Code Samples {#subsect_12134031193}

The following samples show common actions with campaign offer scripting.

### Create script example: {#subsect_0302014215}

              `var record = nlapiCreateRecord('campaignoffer, true); record.setFieldValue('description', 'Test description'); record.setFieldValue('name', 'Test name'); record.setFieldValue('inactive', 'F'); var recordId = nlapiSubmitRecord(record);` 
            

### Update script example: {#subsect_0302014245}

              `record = nlapiLoadRecord('campaignoffer, recordId); record.setFieldValue('description', 'Test description updated'); record.setFieldValue('name', 'Test name updated'); record.setFieldValue('inactive', 'T'); recordId = nlapiSubmitRecord(record);` 
            

### Delete script example: {#subsect_0302014315}

              `nlapiDeleteRecord('campaignoffer', recordId);`
