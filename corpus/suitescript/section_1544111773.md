Note:

JavaScript does not include an enumeration type. The SuiteScript 2.x documentation uses the term enumeration (or enum) to describe a plain JavaScript object with a flat, map-like structure. In this object, each key points to a read-only string value.

| **Enum Description** | Holds [query.RelativeDate](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544109440.html) object values for supported date ranges in relative dates. This enum is used to pass the values argument to [Query.createCondition(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510780329.html) and [Component.createCondition(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510784922.html). It is also used as the value of the [RelativeDate.value](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544109837.html) property. Each value in this enum represents a date range. When [Query.createCondition(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510780329.html) or [Component.createCondition(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510784922.html) is called with a [query.RelativeDate](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544109440.html) object as the `values` argument, this object is set as the value of the [RelativeDate.value](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544109837.html) property. When creating a condition using [Query.createCondition(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510780329.html) or [Component.createCondition(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510784922.html), use the values in this enum (along with values in the [query.Operator](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510275752.html) enum) to specify a range of dates relative to the current date. For example, to create a condition to match dates that occur before the current date, use the `query.RelativeDateRange.TODAY` enum value and the `query.Operator.BEFORE` enum value. To create a condition to match dates that occur after last year, use the `query.RelativeDateRange.LAST_YEAR` enum value and the `query.Operator.AFTER` enum value. For more information about relative dates, see [Relative Dates in the N/query Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1549916938.html). The values in this enum might look similar to the values in the [query.DateId](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544111587.html) enum, but each enum is used for a different purpose:
-   Use [query.DateId](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544111587.html) enum values to create a [query.RelativeDate](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544109440.html) object using [query.createRelativeDate(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544108154.html). After you create this object, you can use it in query conditions that you create using [Query.createCondition(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510780329.html) or [Component.createCondition(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510784922.html).
-   Use `query.RelativeDateRange` enum values directly in query conditions that you create using [Query.createCondition(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510780329.html) or [Component.createCondition(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510784922.html). Each value in the `query.RelativeDateRange` enum represents a date range, and you can use these values in the `values` parameter of [Query.createCondition(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510780329.html) or [Component.createCondition(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510784922.html).
