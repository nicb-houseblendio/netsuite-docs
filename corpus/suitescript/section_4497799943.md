| **Method Description** | Creates a Confirm dialog with OK and Cancel buttons. |
| --- | --- |
| **Returns** | [Promise Object](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4387812940.html). To run a callback function when the OK button is pressed, pass a function to the **then** portion of the Promise object. The value of the pressed button, where OK is **true** and Cancel is **false**, is passed to the callback. |
| **Supported Script Types** | Client scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/ui/dialog Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4497725142.html) |
| **Since** | 2016.1 |

## Parameters {#bridgehead_4497802251}

Note:

The options parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description | Since |
| --- | --- | --- | --- | --- |
| `options.title` | string | optional | The confirmation dialog title. This value defaults to an empty string. | 2016.1 |
| `options.message` | string | optional | The content of the confirmation dialog. This value defaults to an empty string. | 2016.1 |

## Syntax {#bridgehead_4497803233}

Important:

The following code snippet shows the syntax for this member. It is not a functional example. For a complete script example, see [N/ui/dialog Module Script Samples](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0305025805.html).
