| **Property Description** | Object with key-value pairs that override static script parameter field values on the script deployment. Use these parameters for the [task.ScheduledScriptTask](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4392318707.html) object to programmatically pass values to the script deployment. For more information about script parameters, see [Creating Script Parameters Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N2999300.html). |
