| **Object Description** | All the properties required to asynchronously initiate a workflow. Use the `WorkflowTriggerTask` Object to create a task that initiates an instance of the specified workflow. The task is placed in the scheduling queue, and the workflow instance is initiated after the task reaches the top of the queue. `task.WorkflowTriggerTask` does not successfully place a workflow job in queue if an identical instance of that workflow (with the same `recordType`, `id`, and `workflowId`) is currently executing or already in the scheduling queue. To use the `WorkflowTriggerTask` Object:
-   Use [task.create(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4392320106.html) to create the `WorkflowTriggerTask` Object.
-   Use [WorkflowTriggerTask.recordType](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_452073913574.html) to set the record type of the workflow base record.
-   Use [WorkflowTriggerTask.recordId](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_456538635253.html) to set the internal ID of the base record for the workflow.
-   Use [WorkflowTriggerTask.workflowId](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_46870056152.html) to set the internal ID of the workflow that you want to run on the record specified by the `recordId`.
-   Optionally, use [WorkflowTriggerTask.params](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_457660766600.html) to specify default values for workflow fields.
-   Use [WorkflowTriggerTask.submit()](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_459607788085.html) to submit the asynchronous workflow initiation task to the NetSuite task queue.
-   Use the properties for the [WorkflowTriggerTaskStatus.status](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_46640258788.html) object to get the status of the workflow execution.

Use the following guidelines with the `WorkflowTriggerTask` Object:

-   [WorkflowTriggerTask.submit()](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_459607788085.html) does not successfully place a workflow task in the scheduling queue if an identical instance of that workflow, with the same `recordType`, `recordId`, and `workflowId`, is currently executing or already in the scheduling queue.

To initiate a workflow on demand, see [workflow.initiate(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4344303916.html). |
