| **Method Description** | Returns `true` if two nodes reference the same object or returns `false` if two nodes do not reference the same object. If two nodes are the same, all attributes have the same values and you can use methods on the two nodes interchangeably. Note: Two nodes that are the same are also equal. See [Node.isEqualNode(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_453230529784.html). Important: This method is not supported on Internet Explorer or Firefox. |
| --- | --- |
| **Returns** | boolean |
| **Supported Script Types** | Client and server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/xml Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4344917661.html) |
| **Since** | 2015.2 |

## Parameters {#bridgehead_457739196776}

Note:

The options parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.other` | [xml.Node](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4346057759.html) | required | The node to compare with the current node. |
