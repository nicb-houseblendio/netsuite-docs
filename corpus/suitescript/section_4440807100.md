| **Method Description** | Sends a single 'on-demand' campaign email asynchronously to a specified recipient and return a campaign response ID to track the email. This is used for lead nurturing campaigns (drip marketing email). If the email fails to send, the value returned is -1. Note: The parameters and errors thrown for this method are the same as those for [email.sendCampaignEvent(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4431144897.html). For more information about promises, see [Promise Object](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4387812940.html). |
