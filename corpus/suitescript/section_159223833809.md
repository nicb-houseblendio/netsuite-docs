| **Object Description** | An asynchronous SuiteQL task. Use the methods and properties for this object to submit a SuiteQL task to the NetSuite task queue and execute it asynchronously. You can create a `task.SuiteQLTask` object using [task.create(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4392320106.html). You can populate the properties of this object as you create it. With a `task.SuiteQLTask` object, you can do the following:
-   Specify the SuiteQL query to submit using the [SuiteQLTask.query](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159223864743.html) property. This property accepts a string that represents a SuiteQL query. For more information, see [SuiteQL](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156257770590.html).
-   Provide parameters to use in the SuiteQL query using the [SuiteQLTask.params](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159223862155.html) property.
-   Set the file ID or file path of a CSV file in the File Cabinet. SuiteQL query results are exported to this file. Use the [SuiteQLTask.fileId](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159223852102.html) property to specify a file ID, or use the [SuiteQLTask.filePath](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159223855624.html) property to specify a file path. Only one of these properties can be set at the same time. If both are set, an error occurs.
-   Add dependent tasks to the SuiteQL task using [SuiteQLTask.addInboundDependency(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159223844941.html). Dependent tasks are processed automatically when the SuiteQL task is complete.
-   Submit the SuiteQL task to the task queue using [SuiteQLTask.submit()](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159223847318.html).
-   Get the status of a SuiteQL task using the properties of an associated [task.SuiteQLTaskStatus](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159223884561.html) object. The [task.checkStatus(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345805891.html) method returns a [task.SuiteQLTaskStatus](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159223884561.html) object when you specify a task ID that represents a SuiteQL task.
