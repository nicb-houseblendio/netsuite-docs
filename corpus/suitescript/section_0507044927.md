| **Method Description** | Asynchronously executes the dataset and returns the result set (the same as in [N/query Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510275060.html)). Note: The parameters and errors thrown for this method are the same as those for [Dataset.run()](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158948330969.html). For more information about promises, see [Promise Object](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4387812940.html). |
