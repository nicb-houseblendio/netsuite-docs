| **Property Description** | The start of the relative date. For relative dates that you create using [query.createRelativeDate(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544108154.html), the value of this property is set when that method is executed. For relative date ranges that are included in the [query.RelativeDateRange](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544111773.html) enum, the value of this property is always available (for example, `query.RelativeDateRange.YESTERDAY.start`). |
