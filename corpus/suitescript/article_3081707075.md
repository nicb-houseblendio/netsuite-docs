Note:

The content in this help topic pertains to SuiteScript 2.1.

SuiteScript AI APIs provide artificial intelligence (AI) capabilities directly within the NetSuite platform, letting you automate, analyze, and enhance your business processes using AI. These APIs leverage Oracle Cloud Infrastructure (OCI) services to enable features such as large language model (LLM) interaction, language translation, and document extraction. For more information about AI in NetSuite, see [NetSuite Features That Use AI](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_5101751849.html).

The following table lists the available SuiteScript AI APIs, including the OCI service each one uses and links to full module documentation and code samples.

| Module | Description | OCI Service Used | Links |
| --- | --- | --- | --- |
| N/documentCapture | The N/documentCapture module provides access to document extraction capabilities in scripts. This module lets you extract structured content and key information from a variety of document types (such as invoices, receipts, contracts, and so on) in PDF, TIFF, PNG, or JPG format. You can use this module to help automate document processing, reduce manual data entry, and enhance business workflows. | [OCI Document Understanding](https://docs.oracle.com/en-us/iaas/Content/document-understanding/using/home.htm) | 
-   [N/documentCapture Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_8134325498.html)

-   [Getting Started with the N/documentCapture Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0828072922.html)

 |
| N/llm | The N/llm module provides access to large language model (LLM) capabilities in scripts. This module lets you generate text, summarize content, and extract information using AI-driven models directly from your SuiteScript code. You can use this module to help automate, enhance, or analyze business data using AI, while ensuring seamless integration with your NetSuite workflows and processes. | [OCI Generative AI](https://docs.oracle.com/en-us/iaas/Content/generative-ai/home.htm) |
