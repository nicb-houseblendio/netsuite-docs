| **Method Description** | Creates a tool definition that you can provide when calling [llm.generateText(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1014032554.html) or [llm.generateTextStreamed(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_46075557997.html). Tools are callable operations that the large language model (LLM) can request to augment its responses. They are custom utilities that you define, and they let the LLM retrieve external data (such as data from NetSuite using SuiteQL), perform calculations, or trigger business logic as part of an LLM interaction. By providing tools that the LLM can request, the LLM can use the tool results to generate more accurate and dynamic responses. After you create a tool definition, you can provide it to [llm.generateText(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1014032554.html) or [llm.generateTextStreamed(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_46075557997.html) using the `options.tools` parameter. Doing so makes the tool available for the LLM to request during an interaction. You can create and provide multiple tool definitions based on your use cases. |

## Parameters {#subsect_66090028948}

| Parameter | Type | Required / Optional | Description | Since |
| --- | --- | --- | --- | --- |
| `options.description` | string | required | A description of what the tool does. This parameter helps the LLM understand when to request the tool. | 2025.2 |
| `options.name` | string | required | A unique identifier for the tool. This parameter is used when the LLM refers to this tool in tool call requests (which are represented as [llm.ToolCall](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_16103740432.html) objects). | 2025.2 |
| `options.parameters` | [llm.ToolParameter](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_70104105348.html)\[\] | required | An array of tool parameters, which are created using [llm.createToolParameter(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_47090328711.html). These parameters specify the input values required to run the tool. | 2025.2 |
