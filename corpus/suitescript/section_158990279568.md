## Parameters {#subsect_158990280133}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.fieldId` | string | required | The ID of the record field for the join. When you perform a join, you must specify the field to be used to perform the join. For example, consider a transaction record. Transaction records can be joined to customer records using the entity field on the transaction record. If you joined a transaction record to a customer record in this way, the value of this property is 'entity'. |
| `options.join` | [dataset.Join](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158948390739.html) | optional | The existing join used to a create multi-level join. Use this parameter only if a child join exists with the current join as its parent. |
| `options.source` | string | optional | The internal ID for the source record type for the join used to create an inverse join. Use the [Records Catalog](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/book_159368199162.html) to find the Internal ID of scriptable records. |
| `options.target` | string | optional | The polymorphic target of the join. |

## Errors {#subsect_158990280681}

| Error Code | Thrown If |
| --- | --- |
| `MUTUALLY_EXCLUSIVE_ARGUMENTS` | Both the `options.source` and `options.target` parameters are specified. |
