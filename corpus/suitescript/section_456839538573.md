| **Method Description** | Returns the current percentage complete for the current stage of a [task.MapReduceScriptTask](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345798404.html). Use the [MapReduceScriptTaskStatus.stage](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_460753112791.html) property to get the current stage. For general information about map/reduce stages, see [Map/Reduce Key Concepts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0901045042.html) and [Map/Reduce Script Stages](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4387802529.html). Note: The input and summarize stages are either 0% or 100% complete at any time. |
| --- | --- |
| **Returns** | number |
