| **Method Description** | Method used to reset the file contents. Serves as an undo action on any unsaved content written with [File.appendLine(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4769938149.html) or [File.lines.iterator()](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4769955095.html). Use this method to reset the reading and writing streams that may have been opened by [File.appendLine(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4769938149.html) or [File.lines.iterator()](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4769955095.html). The line pointer (or read iterator) is also set to its previous state. This method can be used on text or .csv files. Important: To use this method, each line must be less than 10MB. |
