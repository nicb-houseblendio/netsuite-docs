## Example of a Valid Script that Includes All Required Elements {#bridgehead_4489046490}

The following script is valid. It includes a `define` statement, a `return` statement with an entry point, and an entry point function that corresponds with the entry point. Plus, the `@NScriptType` JSDoc tag matches the script type interface, and the `@NApiVersion` JSDoc tag is correct.

          `/**  * @NApiVersion 2.1  * @NScriptType UserEventScript  */  define(['N/record'], (record) => {     function myBeforeSubmitFunction(context) {         if (context.type !== context.UserEventType.CREATE)             return;         let customerRecord = context.newRecord;         customerRecord.setValue({             fieldId: 'comments',              value: 'Please follow up with this customer!'         });     }     return {         beforeSubmit: myBeforeSubmitFunction     }; });` 
        

## Example of an Invalid Script - Missing Return Statement {#bridgehead_4489048802}

The following script is invalid because it doesn't have a `return` statement. If you try to upload a script that doesn't include a `return` statement, the system returns the error 'SuiteScript 2.0 entry point scripts must implement one script type function.' For more information, see [SCRIPT\_OF\_API\_VERSION\_20\_MUST ...](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4503568059.html#bridgehead_4515727591).

          `/**  * @NApiVersion 2.1  * @NScriptType UserEventScript  */  define(['N/record'], (record) => {     function myBeforeSubmitFunction(context) {         if (context.type !== context.UserEventType.CREATE)             return;         let customerRecord = context.newRecord;         customerRecord.setValue({             fieldId: 'comments',             value: 'Please follow up with this customer!'         });     } });` 
        

## Example of an Invalid Script - Missing Define Statement {#bridgehead_4489060109}

The following script is invalid because it uses a `require` statement instead of a `define` statement. If you try to upload a script that includes a `require` statement, the system returns the error 'SuiteScript 2.0 entry point scripts must implement one script type function.' For more information, see [SCRIPT\_OF\_API\_VERSION\_20\_MUST ...](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4503568059.html#bridgehead_4515727591). For more information about using the `require` statement, see [require Function](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4387813188.html).

          `/**  * @NApiVersion 2.x  * @NScriptType UserEventScript  */  require(['N/record'], (record) => {     function myBeforeSubmitFunction(context) {         if (context.type !== context.UserEventType.CREATE)             return;         let customerRecord = context.newRecord;         customerRecord.setValue({             fieldId: 'comments',             value: 'Please follow up with this customer!'         });     } });` 
        

## Example of an Invalid Script - Missing @NScriptType JSDoc Tag {#bridgehead_4533720700}

The following script is invalid because it doesn't have an `@NScriptType` JSDoc tag. You can upload the script file, however, if you try to create a script record for the script, the system returns the error '@NScriptType is required for 2.0 entry point script.' For more information, see [MISSING\_SCRIPT\_TYPE](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4503568059.html#bridgehead_4515261480).

          `/**  * @NApiVersion 2.1  */  define([ 'N/record' ], (record) => {     function myBeforeSubmitFunction(context) {         if (context.type !== context.UserEventType.CREATE)             return;         let customerRecord = context.newRecord;         customerRecord.setValue({             fieldId: 'comments',             value: 'Please follow up with this customer!'         });     }     return {         beforeSubmit : myBeforeSubmitFunction     }; });` 
        

## Example of an Invalid Script - Missing @NApiVersion JSDoc Tag {#bridgehead_4527908171}

The following script is invalid because it doesn't have an `@NApiVersion` JSDoc tag. If you try to upload a script file that doesn't include the `@NApiVersion` JSDoc tag, the system returns the error 'Failed to validate script file.' For more information, see [FAILED\_TO\_VALIDATE\_SCRIPT\_FILE](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4503568059.html#bridgehead_4527776671).

          `/**  * @NScriptType UserEventScript  */  define(['N/record'], function(record) {     function myBeforeSubmitFunction(context) {         if (context.type !== context.UserEventType.CREATE)             return;         let customerRecord = context.newRecord;         customerRecord.setValue({             fieldId: 'comments',             value: 'Please follow up with this customer!'         });     }     return {         beforeSubmit : myBeforeSubmitFunction     }; });`
