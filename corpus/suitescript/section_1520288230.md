The use of products on issue records helps determine which product team is responsible for the resolution of that issue.

For help working with this record in the UI, see [Working with Products and Modules](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2443140.html).

The internal ID for this record is `issueproduct`.

See the [SuiteScript Records Browser](https://system.netsuite.com/help/helpcenter/en_US/srbrowser/Browser2026_1/script/record/issueproduct.html) for all internal IDs associated with this record.

## Supported Script Types {#bridgehead_1517234964}

The issue record is scriptable in both server and client SuiteScript.

## Supported Functions {#bridgehead_1517234970}

The record can be created, read, updated and deleted using SuiteScript. It cannot be copied, transformed or searched.

## Code Sample {#bridgehead_1517236673}

The following script example illustrates how to create an issue product record.

          `var product = record.create({     type: record.Type.ISSUE_PRODUCT }); product.setFieldValue({     fieldId: 'issueproduct',     value: 'new product' }); var productId = product.save();`
