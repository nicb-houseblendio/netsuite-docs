## Parameters {#subsect_14154631604}

| Parameter | Type | Required / Optional | Description | Since |
| --- | --- | --- | --- | --- |
| `options.encryptionKeys` | [pgp.Key](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0921033205.html) | [pgp.Key](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0921033205.html)\[\] | Required | One or more keys used to encrypt a message. If a key contains multiple valid encryption (sub)keys, the most recent key added will be used. | 2022.2 |
| `options.signingKeys` | [pgp.Key](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0921033205.html) | [pgp.Key](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0921033205.html)\[\] | optional | Zero or more keys used for signing. If a key contains multiple valid signing (sub)keys, the most recent key added will be used. Default value = `[]`. | 2022.2 |
| `options.compressionAlgorithm` | [pgp.CompressionAlgorithm](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0923112620.html) | optional | The compression algorithm to use. Default value = `CompressionAlgorithm.ZLIB.` | 2022.2 |

## Errors {#subsect_27154554141}

| Error Code | Thrown If |
| --- | --- |
| `PGP_NO_ENCRYPTION_KEY_FOUND_IN_KEY_PARAM_1` | No valid encryption (sub)key was found in one of the provided keys. |
| `PGP_NO_SIGNING_KEY_FOUND_IN_KEY_PARAM_1` | No valid signing (sub)key was found in one of the provided keys. |
