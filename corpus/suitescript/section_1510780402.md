| **Method Description** | Creates a sort based on the [query.Query](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510275177.html) object. The [query.Sort](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510779222.html) object describes a sort that is placed on a particular query result column. To create a sort:
-   Use `Query.createSort(options)` to create a sort based on the initial query definition created with [query.create(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510275581.html).
-   Use [Component.createSort(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510785047.html) to create a sort based on a join relationship created with [Query.autoJoin(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530819144.html) or [Component.autoJoin(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530818573.html).
-   Assign all created sorts as values to [Query.sort](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510781853.html). For an example, see [Syntax](#subsect_1530622187).

Note: This method is a shortcut for the chained [Query.root](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510781874.html) and [Component.createSort(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510785047.html): `Query.root.createSort(options)`. The [Query.root](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510781874.html) property references the root component, which is a [query.Component](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510779141.html) object. |

## Parameters {#subsect_1510780402}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.column` | [query.Column](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510779196.html) | required | The query result column that you want to sort by. This value sets the [Sort.column](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510790467.html) property. |
| `options.ascending` | boolean | optional | Whether the sort direction is ascending. This value sets the [Sort.ascending](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530897548.html) property. The default value of this property is `true`, meaning that the sort direction is ascending. If you want the sort direction to be descending, set this property to `false`. |
| `options.caseSensitive` | boolean | optional | Whether the sort is case sensitive. This value sets the [Sort.caseSensitive](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530819572.html) property. If a sort is case sensitive (and the sort direction is ascending), rows with column values that start with uppercase letters are listed before rows with column values that start with lowercase letters. If a sort is not case sensitive, uppercase and lowercase letters are treated the same. For example, the following list of items is sorted using a case-sensitive sort with a sort direction of ascending:
-   Banana
-   Orange
-   apple
-   grapefruit
-   kiwi

Here is the same list of items sorted using a regular (not case-sensitive) sort with a sort direction of ascending:

-   apple
-   Banana
-   grapefruit
-   kiwi
-   Orange

The default value of this property is `false`. |
| `options.locale` | string | optional | The locale to use for the sort. This value sets the [Sort.locale](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530819644.html) property. A locale represents a combination of language and region, and it can affect how certain values (such as strings) are sorted. For example, languages that share the same alphabet may sort characters differently. Use this property to ensure that query results are sorted using locale-specific rules. Use the appropriate [query.SortLocale](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530819885.html) enum value to pass in your argument. This enum holds all the supported values for this parameter. |
| `options.nullsLast` | boolean | optional | Whether query results with null values are listed at the end of the query results. This value sets the [Sort.nullsLast](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530819676.html) property. The default value of this property is the value of the `options.ascending` property. For example, if the `options.ascending` property is set to `true`, the `options.nullsLast` property is also set to `true`. |
