| **Object Description** | A scriptable, multi-step NetSuite assistant. An assistant contains a series of step that a user must complete to accomplish a larger goal. An assistant can be sequential, or non-sequential and include optional steps. Each page of the assistant is defined by a step. All data and states for an assistant are tracked automatically throughout the user's session until completion of the assistant. You can create a new assistant with the [serverWidget.createAssistant(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4325753291.html) method. After you create an `Assistant` object, you can:
-   Build and run an assistant in your NetSuite account.
-   Add a variety of scriptable elements to the assistant including fields, steps, buttons, tabs, and sublists.

Note: The assistant cannot be used on externally available Suitelets. |
