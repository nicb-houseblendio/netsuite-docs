| **Property Description** | Indicates whether the current invocation of the [map(mapContext)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4413275809.html) function is the first or a subsequent invocation for the current key-value pair. For an overview of events that can cause a restart, see [System Response After a Map/Reduce Interruption](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1517279626.html). When the map function restarts for a key-value pair, any data it wrote last time is deleted. Some logic might have run before it was interrupted, so you might want to use mapContext.executionNo to add logic that avoids duplicate processing. For examples of how to write a robust map/reduce script, see [Adding Logic to Handle Map/Reduce Restarts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1490987232.html). Related properties include [mapContext.isRestarted](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4540852756.html) and [mapContext.errors](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1516209193.html). |
