The item process group is an item category that groups similar items in your warehouse using a more refined property or attribute than the item process family. For example, if you have a clothing item process family, you can create item process groups such as pants and jeans. You can further identify and group clothing items into either of these item process groups.

The item process group record is available when the Warehouse Management feature is enabled. For help working with this record in the UI, see [Creating Item Process Groups](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1541433524.html).

The internal ID for this record is `itemprocessgroup`.

See the [SuiteScript Records Browser](https://system.netsuite.com/help/helpcenter/en_US/srbrowser/Browser2026_1/script/record/itemprocessgroup.html) for all internal IDs associated with this record.

## Supported Script Types {#subsect_158594072708}

The item process group record is scriptable in both client and server SuiteScript.

## Supported Functions {#subsect_158594076024}

The item process group record is fully scriptable - it can be created, copied, updated, deleted, and searched using SuiteScript.

## Code Samples {#subsect_158688815603}

The following code sample shows how to create and edit an item process group record using SuiteScript 2.x:

            `require(["N/record"], function (record) {     function createItemProcessGroup() {         var ipf = record.create({type: record.Type.ITEM_PROCESS_GROUP});         ipf.setValue({fieldId: "name", value: "Vegetables"});         ipf.setValue({fieldId: "description", value: "Carrots, lettuce, so on"});         ipf.save();     }      function editItemProcessGroup() {         var ipf = record.load({type: record.Type.ITEM_PROCESS_GROUP, id: 17});         ipf.setValue({fieldId: "name", value: "Fruit"});         ipf.setValue({fieldId: "description", value: "Apples, pears, so on"});         ipf.save();     } });`
