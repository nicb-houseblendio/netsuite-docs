## Parameters {#subsect_1547089285}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.certId` | string | required | The script ID of the digital certificate. |
| `options.algorithm` | string | required | The hash algorithm. Set this property using the [certificate.HashAlg](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1549631688.html) enum. |
