A Text Enhance action record represents a Text Enhance action that can be added to supported text fields.

For more information, see [Text Enhance](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_2171112518.html).

The following types of text fields support Text Enhance actions:

-   Long text
    
-   Text area
    
-   Rich text
    

A Text Enhance action record includes information about the action, such as:

-   Name and script ID
    
-   Language
    
-   Whether the action is a partial Text Enhance action
    

The internal ID for this record is `textenhanceaction`.

For help working with this record in the UI, see [Prompt Studio](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160809601.html).

## Supported Script Types {#subsect_0311033920}

The Text Enhance action record is scriptable in both client and server SuiteScript.

## Supported Functions {#subsect_0311033936}

The Text Enhance action record is partially scriptable - it can be created, updated, and deleted using SuiteScript.

Certain fields cannot be updated after a Text Enhance action record is created. You can update the values of these fields in your scripts, but you will receive an error if you try to save the record with the updated values.

## Code Sample {#subsect_0311034020}

The following code sample demonstrates how to create a Text Enhance action record, set field values, and save the Text Enhance action record.

            `require(['N/record'], function(record) {     var action = record.create({         type: "textenhanceaction"     });           action.setValue({         fieldId: "name",         value: "Summarize"     });     action.setValue({         fieldId: "language",         value: "en"     });     action.setValue({         fieldId: "scriptid",         value: "custteaction_summarize"     });           action.save(); });`
