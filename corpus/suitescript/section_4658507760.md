All scheduled script instances are executed (processed) by [SuiteCloud Processors](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1498571420.html). You can submit a scheduled script instance for processing in one of three ways:

-   By [Scheduling a One Time or Recurring Scheduled Script Submission](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1508948660.html) from the script deployment record UI
    
-   By [Submitting an On-Demand Scheduled Script Instance from the UI](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1508948664.html) with the **Save and Execute** option
    
-   By [Submitting an On-Demand Scheduled Script Instance from Another Script](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1508948669.html) with the [task.ScheduledScriptTask](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4392318707.html) API
    

For any of these options, you'll need to create a [Scheduled Script Deployment Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1508948655.html).

How your scheduled script runs depends on its deployment type. See the following table for details, and read [Scheduled Script Deployment Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1508948655.html) for more about deployment.

![scheduled script submission by deployment type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/SuiteScript/SuiteScript20/SuiteScript20/scheduledscript_submissiondeploy_diagram.png)

Important:

After you submit a scheduled script, there might be a short system delay before it runs even if no other scripts are ahead of it. If there are scripts already in the queue, your script will wait until those finish.
