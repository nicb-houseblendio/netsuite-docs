| **Method Description** | Creates a conditional filter, which includes a selector of what to filter, a row axis and other axis, a measure and a predicate. Conditional filters can be used in pivot definitions. |
| --- | --- |
| **Returns** | [workbook.ConditionalFilter](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008152586.html) |
| **Supported Script Types** | Server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/workbook Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_159006350818.html) |
| **Sibling Module Members** | [N/workbook Module Members](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_159006350818.html#subsect_159006379904) |
| **Since** | 2020.2 |

## Parameters {#subsect_159050988658}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.filteredNodesSelector` | [workbook.DimensionSelector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008193274.html) | [workbook.PathSelector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008382970.html) | required | The selector for the conditional filter. |
| `options.measure` | [workbook.CalculatedMeasure](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163169891173.html) | [workbook.DataMeasure](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163170291911.html) | required | The measure for the conditional filter. |
| `options.otherAxisSelector` | [workbook.DimensionSelector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008193274.html) | [workbook.PathSelector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008382970.html) | required | The other axis selector for the conditional filter. |
| `options.predicate` | [workbook.Expression](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008229845.html) | required | The predicate for the conditional filter. |
| `options.row` | boolean | required | Indicator for a row axis filter. If set to false, the filter is a on a column axis. |
