The campaign search engine record helps you refine the campaign search engine for a marketing campaign.

For help working with this record in the UI, see [Campaign Search Engines](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1018748.html).

The internal ID for this record is `campaignsearchengine`.

Note:

For information about using the SuiteScript Records Browser, see [Working with the SuiteScript Records Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N3169369.html) in the NetSuite Help Center.

## Supported Script Types {#subsect_39141302614}

The campaign search engine record is scriptable in both client and server SuiteScript.

## Supported Functions {#subsect_43141306146}

The campaign search engine record supports the following functions: create, read, update, and delete. The following functions aren't supported: copy, search, and transform.

## Prerequisites {#subsect_58141309156}

You must enable the Marketing Automation feature before you can use this record with SuiteScript. For more information, see [Marketing Automation Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N973384.html).

## Code Samples {#subsect_90141313230}

The following samples show common actions with campaign search engine scripting.

### Create script example: {#subsect_0302021109}

              `var record = nlapiCreateRecord('campaignsearchengine', true); record.setFieldValue('description', 'Test description'); record.setFieldValue('name', 'Test name'); record.setFieldValue('inactive', 'F'); var recordId = nlapiSubmitRecord(record);` 
            

### Update script example: {#subsect_0302021145}

              `record = nlapiLoadRecord('campaignsearchengine', recordId); record.setFieldValue('description', 'Test description updated'); record.setFieldValue('name', 'Test name updated'); record.setFieldValue('inactive', 'T'); recordId = nlapiSubmitRecord(record);` 
            

### Delete script example: {#subsect_0302021216}

              `nlapiDeleteRecord('campaignsearchengine', recordId);`
