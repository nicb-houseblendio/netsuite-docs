| **Property Description** | Whether assistant steps are displayed with numbers. By default, the value is `false`, which means that steps are numbered. If set to `true`, the assistant does not use step numbers. To change step ordering, set [Assistant.isNotOrdered](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4333544993.html). |
| --- | --- |
| **Type** | Boolean |
