| **Object Description** | The properties of a search task. Use the methods and properties for this object to submit a search task into the task queue, execute it asynchronously, and persist search results. Similar to SuiteAnalytics persisted search functionality, this capability is useful for searches across high volumes of data. You can create a `task.SearchTask` object using [task.create(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4392320106.html). Use the `task.SearchTask` object to do the following:
-   Set the search ID using the [SearchTask.savedSearchId](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4804561931.html) property.
-   Set the file ID or file path of a CSV file in the File Cabinet. Search results are exported to this file. Use the [SearchTask.fileId](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4804562077.html) property or the [SearchTask.filePath](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4804562119.html) property. Exactly one of these properties must be set. If both are set, an error occurs.
-   Add dependent scripts to the search task using [SearchTask.addInboundDependency()](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530711128.html). Dependent scripts are processed automatically when the search task is complete.
-   Submit the search task to the NetSuite task queue using [SearchTask.submit()](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4804558173.html).
-   Get the status of a search task using the properties of the [task.SearchTaskStatus](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4799344334.html) object.

Note: There is a limit to the number of asynchronous searches running at the same time. The limit is set to be the same as the limit for CSV import. The file size limit is based on File Cabinet limits. |
