| **Method Description** | Creates a chart category, which includes an axis, a data root, and a sort definition. A chart category is used in a [workbook.Chart](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159007989923.html). |
| --- | --- |
| **Returns** | [workbook.Category](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159007978137.html) |
| **Supported Script Types** | Server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/workbook Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_159006350818.html) |
| **Sibling Module Members** | [N/workbook Module Members](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_159006350818.html#subsect_159006379904) |
| **Since** | 2020.2 |

## Parameters {#subsect_159008867994}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.axis` | [workbook.ChartAxis](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008145231.html) | required | The chart category axis definition. |
| `options.root` | [workbook.DataDimension](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008172142.html) |[workbook.Section](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008446199.html) | required | The data that feeds the chart category. |
| `options.sortDefinitions` | [workbook.SortDefinition](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008585696.html)\[\] | optional | The sorting for the chart category. |
