| **Method Description** | Converts (serializes) an [xml.Document](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4392323653.html) object into a string. This API is useful, for example, if you want to serialize and store an [xml.Document](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4392323653.html) in a custom field. |
| --- | --- |
| **Returns** | string |
| **Supported Script Types** | Client and server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/xml Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4344917661.html) |
| **Since** | 2015.2 |

## Parameters {#bridgehead_4344924636}

Note:

The options parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.document` | [xml.Document](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4392323653.html) | required | XML document being serialized. |
