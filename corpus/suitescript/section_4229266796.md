| **Property Description** | The size of a file in bytes. This property is read-only. Note: You can use this value to determine if the file is within size limits for [File.getContents()](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4229269811.html). Size will reflect any lines you have streamed into a file. For example, the original file size plus lines appended. |
| --- | --- |
| **Type** | number |
| **Module** | [N/file Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4205693274.html) |
