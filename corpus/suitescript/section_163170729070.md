| **Object Description** | A position that is defined using a percentage of x and y dimensions. Use [workbook.createPositionPercent(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162862263729.html) to create this object. A position percent object is used as a parameter in the [workbook.createStyle(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162886251569.html) method. |
