The content in this help topic pertains to SuiteScript 2.1.

| **Object Description** | An extracted table from a document. This object includes properties for the following:
-   **Header rows** - [Table.headerRows](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0704102044.html)
-   **Body rows** - [Table.bodyRows](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0704101315.html)
-   **Footer rows** - [Table.footerRows](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0704102012.html)
-   **Number of rows** - [Table.rowCount](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0704102126.html)
-   **Number of columns** - [Table.columnCount](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0704101358.html)
-   **Confidence level** - [Table.confidence](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0704101426.html)

Tables are included in extracted content only when the `documentCapture.Feature.TABLE_EXTRACTION` feature is specified when you call [documentCapture.documentToStructure(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0704102801.html) (or when you submit an asynchronous extraction task then parse the result using [documentCapture.parseResult(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0704103210.html)). If you don't specify any features when you call this method, the `TABLE_EXTRACTION` feature is used by default (along with the `TEXT_EXTRACTION` feature). |
