| **Object Description** | Encapsulates a body or sublist field on a standard or custom record. Use the following methods to access the `Field` object:
-   [Record.getField(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4273153320.html)
-   [Record.getSublistField(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4273153882.html)
-   [Record.getCurrentSublistField(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4659853446.html)
-   [CurrentRecord.getField(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4637585044.html)
-   [CurrentRecord.getSublistField(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4637583684.html)

Certain properties of `Field` objects are available only when working with a record in dynamic mode.

-   [Field.id](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4435754429.html) - standard and dynamic modes
-   [Field.isDisplay](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1526056555.html) - dynamic mode only
-   [Field.isMandatory](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4435755588.html) - standard and dynamic modes
-   [Field.label](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4435738555.html) - standard and dynamic modes
-   [Field.sublistId](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4834774974.html) - dynamic mode only
-   [Field.type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4435754577.html) - standard and dynamic modes

For more information about record modes, see [SuiteScript 2.x Standard and Dynamic Modes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1524156901.html). |
