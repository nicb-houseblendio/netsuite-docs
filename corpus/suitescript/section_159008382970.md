| **Object Description** | A path selector object which can be used when you create a sort definition, a conditional filter, a limiting filter, or a measure sort. Use [workbook.createPathSelector(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159051588951.html) to create this object. A path selector object is used as a parameter in the [workbook.createConditionalFilter(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159050988221.html), [workbook.createLimitingFilter(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159051462385.html), [workbook.createSortDefinition(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159051836190.html), and [workbook.createSortByMeasure(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162886129949.html) methods. |
