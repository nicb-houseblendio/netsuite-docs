| **Property Description** | Returns the type of a body or sublist field. For example, the value can return text, date, currency, select, checkbox, etc. For more information about possible return values, see [format.Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4388844232.html). The maximum character limit for select field types is 801. |
| --- | --- |
| **Type** | string (read-only) |
| **Supported Script Types** | Suitelets User event scripts - beforeLoad entry point For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Module** | [N/ui/serverWidget Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4321345532.html) |
| **Since** | 2015.2 |
