SuiteScript UI Objects let you build custom UIs and assistants. For more information, see:

-   [Custom UI Development](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1518470161.html) - lets you build a custom user interface to optimize your NetSuite environment.
    
-   [UI Component Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1518470191.html) - a collection of objects you can use to customize NetSuite with using SuiteScript 2.1.
    
-   [SuiteScript 2.1 UI Modules](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1518470197.html) - API modules for building a custom UI with SuiteScript 2.1
    
-   [Using HTML](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1518456409.html) - lets you use HTML to add elements you can't find in the NetSuite UI components.
    
-   [Creating Custom Assistants](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1518456420.html) - lets you create custom assistants (also called wizards) with a series of steps that users follow to complete a bigger task.
