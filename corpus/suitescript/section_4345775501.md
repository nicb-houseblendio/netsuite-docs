| **Method Description** | Deletes an existing saved search. The saved search could have been created using the UI or created with [search.create(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345171487.html) and [Search.save()](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_452655578613.html). The search.delete(options) method also includes a promise version, [search.delete.promise(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4440793315.html). For more information about promises, see [Promise Object](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4387812940.html). |
| --- | --- |
| **Returns** | void |
| **Supported Script Types** | Client and server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | 5 units |
| **Module** | [N/search Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345764122.html) |
| **Since** | 2015.2 |

## Parameters {#bridgehead_4345775501}

Note:

The options parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description | Since |
| --- | --- | --- | --- | --- |
| `options.id` | string | number | required | Internal ID or script ID of a saved search. The script ID starts with `customsearch`. See [Search.id](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_455917297362.html) for script ID. See [Search.searchId](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_458892150878.html) for internal ID. | 2015.2 |
| `options.type` | string | Required if the saved search to delete uses a standalone search type, optional otherwise | The search type of the saved search to delete. Use a value from the [search.Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4483165708.html) enum for this parameter. To successfully delete a standalone search, this parameter is required to avoid an error being thrown. For more information about standalone search types, see [search.load(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345775360.html). | 2015.2 |

## Errors {#bridgehead_4449819922}

| Error Code | Message | Thrown If |
| --- | --- | --- |
| `INVALID_SEARCH` | That search or mass update does not exist. | Cannot find saved search with the saved search ID from `options.id` parameter. |
| `SSS_MISSING_REQD_ARGUMENT` | {1}: Missing a required argument: {2} | Required parameter is missing. |
