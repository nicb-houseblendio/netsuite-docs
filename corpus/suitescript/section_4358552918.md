Use the N/url module to determine URL navigation paths within NetSuite and format URL strings.

**[N/url Module Script Samples](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0305033928.html)**

## N/url Module Members {#bridgehead_4419860905}

| Member Type | Name | Return Type / Value Type | Supported Script Types | Description |
| --- | --- | --- | --- | --- |
| Method | [url.format(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4358672703.html) | string | Client and server scripts | Converts (serializes) URL query parameters into a string. |
| [url.resolveDomain(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4861456597.html) | string | Client and server scripts | Returns a domain name for a NetSuite account. |
| [url.resolveRecord(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4358667680.html) | string | Client and server scripts | Returns an internal URL to a NetSuite record. |
| [url.resolveScript(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4358672433.html) | string | Client and server scripts | Returns an external or internal URL to a script. |
| [url.resolveTaskLink(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4358672296.html) | string | Client and server scripts | Returns an internal URL for a tasklink. |
| Enum | [url.HostType](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4834765371.html) | enum | Client and server scripts | Holds the string values that describe a category of domain name. Use this enum to set the value of the `hostType` parameter of the [url.resolveDomain(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4861456597.html) method. |
