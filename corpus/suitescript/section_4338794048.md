| **Method Description** | Adds a link to a form. Note: You cannot choose where the page link appears. |
| --- | --- |
| **Returns** | void |
| **Supported Script Types** | Suitelets User event scripts - beforeLoad entry point For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/ui/serverWidget Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4321345532.html) |
| **Since** | 2015.2 |

## Parameters {#bridgehead_4338794048}

Note:

The options parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description | Since |
| --- | --- | --- | --- | --- |
| `options.title` | string | required | The text label for the link. | 2015.2 |
| `options.type` | string | required | The type of page link to add. Use the [serverWidget.FormPageLinkType](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4332671075.html) enum to set the value. | 2015.2 |
| `options.url` | string | required | The URL for the link. | 2015.2 |
