| **Method Description** | Creates a new [crypto.Decipher](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4358620478.html) object. Note: The blockCipherMode is automatically set to CBC. |
| --- | --- |
| **Returns** | A [crypto.Decipher](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4358620478.html) object. |
| **Supported Script Types** | Server scripts For additional information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/crypto Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4358549582.html) |
| **Since** | 2015.2 |

## Parameters {#bridgehead_4449124404}

Note:

The options parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description | Since |
| --- | --- | --- | --- | --- |
| `options.algorithm` | string | required | The hash algorithm. Use the [crypto.EncryptionAlg](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4358655796.html) enum to set the value. | 2015.2 |
| `options.key` | object | required | The [crypto.SecretKey](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4358620976.html) object used for encryption. Note: When using the crypto.SecretKey object for an AES algorithm, the length of the text (secret key) that is used to generate the GUID must be 16, 24, or 32 characters. | 2015.2 |
| `options.padding` | object | optional | The padding for the cipher. Use the [crypto.Padding](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4358655564.html) enum to set the value. | 2015.2 |
| `options.iv` | string | required | The initialization vector that was used for encryption. You can use a [CipherPayload.iv](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_46186462402.html) value. | 2015.2 |
