| Script Entry Point | Description |
| --- | --- |
| [fieldChanged(scriptContext)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4410692508.html) | This is the function that runs when a user or client changes a field. |
| [lineInit(scriptContext)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4410693004.html) | This function runs when a line is set up, like when you select an existing line or add a new one. |
| [localizationContextEnter(scriptContext)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157495533652.html) | This function runs when the record enters a specific localization context, as set in the script deployment record. |
| [localizationContextExit(scriptContext)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157495540056.html) | This function runs when the record exits that context. |
| [pageInit(scriptContext)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4410597671.html) | This function runs when the page finishes loading or the form is reset. |
| [postSourcing(scriptContext)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4410692646.html) | This function runs when you change a field that gets its info from another field. Executes on transaction forms only. |
| [saveRecord(scriptContext)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4410693749.html) | This function runs when you save a record, after you click submit but before the form is sent. |
| [sublistChanged(scriptContext)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4410692812.html) | This function runs after you add, remove, or edit a sublist. |
| [validateDelete(scriptContext)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4410693608.html) | This function checks if it's okay to delete a line from an edit sublist. |
| [validateField(scriptContext)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4410693152.html) | This function checks if a field change is valid when a user or client makes a change. |
| [validateInsert(scriptContext)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4410693455.html) | This function checks if it's okay to add a new line to an edit sublist. |
| [validateLine(scriptContext)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4410693302.html) | This function checks if it's okay to add a new line to an inline editor sublist before it happens. |
