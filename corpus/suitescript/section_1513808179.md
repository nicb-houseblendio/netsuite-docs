| **Property Description** | The number of processors available to the current account. [SuiteCloud Processors](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1498571420.html) is the current system used to execute (process) scheduled scripts and map/reduce scripts. This property is helpful if you are a SuiteApp developer and your script needs to know the total number of processors available to a deployment. For scheduled script deployments that continue to use queues, use [runtime.queueCount](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4296531705.html). With the introduction of SuiteCloud Processors, map/reduce script deployments and new scheduled script deployments no longer use queues, but pre-existing scheduled script deployments continue to use queues until the queues are removed (see [SuiteCloud Processors Supported Task Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1505167691.html)). Be aware that the number of processors available may not be the same as the number of queues available. For more information, see [SuiteCloud Plus Settings](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N259503.html). Note: The `runtime.processorCount` property reflects the number of processors available to an account. It is not impacted by changes to deployments. The value is the same regardless of whether deployments continue to use queues. For more information, see [SuiteCloud Processors Supported Task Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1505167691.html). For more information about scheduled scripts, see [SuiteScript 2.1 Scheduled Script Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4387799491.html). For more information about map/reduce scripts, see [SuiteScript 2.1 Map/Reduce Script Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4387799161.html). |
