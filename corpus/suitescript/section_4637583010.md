| **Method Description** | Gets the subrecord associated with the field. If the subrecord does not exist, a new subrecord is created and returned. |
| --- | --- |
| **Returns** | [currentRecord.CurrentRecord](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4642657958.html) |
| **Supported Script Types** | Client scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). Note: Setting values of [Inventory Detail](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3194671.html) subrecord is currently not supported in Client scripts since the subrecord object in this context is only available in view-mode. |
| **Governance** | None |
| **Module** | [N/currentRecord Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4625600928.html) |
| **Since** | 2016.2 |

## Parameters {#bridgehead_4637583048}

Note:

The options parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description | Since |
| --- | --- | --- | --- | --- |
| `options.fieldId` | string | required | The internal ID of a standard or custom body field. See [Finding Internal IDs of Record Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_0416043804.html). | 2016.2 |

## Errors {#bridgehead_4637582511}

| Error Code | Thrown If |
| --- | --- |
| `FIELD_1_IS_DISABLED_YOU_CANNOT_APPLY_SUBRECORD_OPERATION_ON_THIS_FIELD` | The specified field is disabled. |
| `FIELD_1_IS_NOT_A_SUBRECORD_FIELD` | The specified field is not a subrecord field. |
| `SSS_INVALID_FIELD_ON_SUBRECORD_OPERATION` | The specified fieldId does not refer to a subrecord. |
| `SSS_MISSING_REQD_ARGUMENT` | A required argument is missing or undefined. |
