| **Property Description** | The ID of the query definition. This property has a value only for existing queries that are loaded using [query.load(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510349101.html). If you create a query using [query.create(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510275581.html) but do not save it, this property is null. Important: The N/query module lets you create and run queries using the SuiteAnalytics Workbook query process. You can use the N/query module to load and delete existing queries, but you cannot save queries. You can save queries using the SuiteAnalytics Workbook interface. For more information, see [Navigating SuiteAnalytics Workbook](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1544220943.html). |
