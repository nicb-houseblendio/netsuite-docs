Note:

JavaScript does not include an enumeration type. The SuiteScript 2.x documentation uses the term enumeration (or enum) to describe a plain JavaScript object with a flat, map-like structure. In this object, each key points to a read-only string value.

| **Enum Description** | Holds string values for temporal units, such as hours or minutes. Used to set the value of the `options.start` and `options.end` parameters of the [workbook.createDuration(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0508035928.html) method. |
