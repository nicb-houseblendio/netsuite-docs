| **Method Description** | Use this method to determine if a particular feature is enabled in a NetSuite account. These are the features that appear on the Enable Features page at _Setup > Company > Enable Features_. |
| --- | --- |
| **Returns** | boolean |
| **Supported Script Types** | Client and server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/runtime Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4296359529.html) |
| **Since** | 2015.2 |

## Parameters {#bridgehead_4439982248}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description | Since |
| --- | --- | --- | --- | --- |
| `options.feature` | string | required | The internal ID of the feature to check. For a list of feature internal IDs, see [Feature Names and IDs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N3247851.html). | 2015.2 |

## Errors {#bridgehead_159458167516}

| Error Code | Thrown If |
| --- | --- |
| `SSS_MISSING_REQD_ARGUMENT` | The `options.feature` parameter is not specified. |
| `WRONG_PARAMETER_TYPE` | The value for the `options.feature` parameter is not a string. |
