The content in this help topic pertains to SuiteScript 2.1.

| **Method Description** | Creates a tool result that you can provide when calling [llm.generateText(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1014032554.html) or [llm.generateTextStreamed(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_46075557997.html). Tool results let you send the output of a tool (such as the result of a SuiteQL query or a business operation) back to the large language model (LLM). You generate tool results in your SuiteScript code after handling a tool call request, which is represented by a [llm.ToolCall](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_16103740432.html) object. These results provide additional relevant data that the LLM uses when creating its response. After you create a tool result, you can provide it to subsequent [llm.generateText(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1014032554.html) or [llm.generateTextStreamed(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_46075557997.html) calls, which lets the LLM incorporate the results of the tool call and return a more accurate and relevant response. |

## Parameters {#subsect_16090447868}

| Parameter | Type | Required / Optional | Description | Since |
| --- | --- | --- | --- | --- |
| `options.call` | [llm.ToolCall](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_16103740432.html) | required | The original tool call request from the LLM. This parameter links the result to a specific tool call request. | 2025.2 |
| `options.outputs` | Object\[\] | required | An array of output objects representing the results of running the tool. Each output object typically includes a `result` property (or another relevant property) that contains the value to send back to the LLM. | 2025.2 |
