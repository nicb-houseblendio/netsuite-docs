| **Method Description** | Creates a [query.RelativeDate](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544109440.html) object that represents a date relative to the current date. Use this method to create a [query.RelativeDate](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544109440.html) object to use as part of a query condition. After you create a [query.RelativeDate](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544109440.html) object, you can use it directly in the `values` parameter of [Query.createCondition(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510780329.html) or [Component.createCondition(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510784922.html). When you call this method, the `options.dateId` parameter determines the relative date that is created. The `options.dateId` parameter uses values from the [query.DateId](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544111587.html) enum, and these values describe potential dates relative to the current date. Use them along with the `options.value` parameter to create a relative date. For example, to create a relative date that represents the date three weeks before the current date, call `query.createRelativeDate(options)` with an `options.dateId` value of `query.DateId.WEEKS_AGO` and an `options.value` value of 3. To create a relative date that represents the date three weeks after the current date, call `query.createRelativeDate(options)` with an `options.dateId` value of `query.DateId.WEEKS_FROM_NOW` and an `options.value` value of 3. |

## Parameters {#subsect_1544108168}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.dateId` | string | required | The ID of the relative date to create. Use the [query.DateId](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544111587.html) enum to set this value. |
| `options.value` | number | required | The value to use to create the relative date. This value depends on the value that you specify for `options.dateId`. For example, to create a relative date that represents the date five days before the current date, use an `options.value` value of 5 and an `options.dateId` value of `query.DateId.DAYS_AGO`. |

## Errors {#subsect_158291851130}

| Error Code | Thrown If |
| --- | --- |
| `INVALID_DATE_ID` | The specified value for `options.dateId` is not a value from the [query.DateId](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544111587.html) enum. |
