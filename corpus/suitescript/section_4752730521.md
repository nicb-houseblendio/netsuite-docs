This topic maps SuiteScript 1.0 Objects (prefixed with 'nlobj') to their corresponding SuiteScript 2.1 APIs. Objects and their members are grouped alphabetically by object name. Each object has its own table containing all object members.

Note:

NetSuite does not support calling SuiteScript 1.0 APIs from SuiteScript 2.1 scripts.

Note:

To view a mapping of SuiteScript 1.0 Functions (prefixed with 'nlapi') to their corresponding SuiteScript 2.1 APIs, see [SuiteScript 1.0 to SuiteScript 2.1 API Map - Functions (nlapi)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4752724744.html).
