| **Method Description** | Returns the value of a script parameter for the currently executing script. For information about script parameters, see [Creating Script Parameters Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N2999300.html). |
| --- | --- |
| **Returns** | number | Date | string | boolean | null | undefined |
| **Supported Script Types** | Client and server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/runtime Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4296359529.html) |
| **Since** | 2015.2 |

## Parameters {#bridgehead_4338195836}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description | Since |
| --- | --- | --- | --- | --- |
| `options.name` | string | required | The name of the script parameter. | 2015.2 |

## Errors {#bridgehead_159458183194}

| Error Code | Thrown If |
| --- | --- |
| `SSS_MISSING_REQD_ARGUMENT` | The `options.name` parameter is not specified. |
| `WRONG_PARAMETER_TYPE` | The value for the `options.name` parameter is not a string. |
