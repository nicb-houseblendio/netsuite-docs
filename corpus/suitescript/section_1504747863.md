You can submit a map/reduce script in several ways:

-   By [Scheduling a Map/Reduce Script Submission](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1509578930.html)
    
-   By [Submitting an On-Demand Map/Reduce Script Deployment from the UI](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1509579025.html)
    
-   By [Submitting an On-Demand Map/Reduce Script Deployment from a Script](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1508887826.html)
    

You can create multiple deployments for a single script record. This is helpful if you need to run the same script multiple times simultaneously or in a short period. For details, see [Submitting Multiple Deployments of the Same Script](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510974473.html).

You'll need a map/reduce script deployment record for each process. For details about the fields available on this record, see [Map/Reduce Script Deployment Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1509578980.html).

Important:

SuiteCloud Processors run all map/reduce script instances. Before submitting a map/reduce script for processing, review [SuiteCloud Processors](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1498571420.html).
