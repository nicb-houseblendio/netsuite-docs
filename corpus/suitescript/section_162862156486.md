## Parameters {#subsect_162862156881}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.columnSelector` | [workbook.DescendantorSelfNodesSelector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163170591936.html) | [workbook.DimensionSelector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008193274.html) | [workbook.PathSelector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008382970.html) | required | The column to style. |
| `options.measureSelector` | [workbook.MeasureSelector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163170447750.html) | required | The measures to apply conditional formatting to. |
| `options.rowSelector` | [workbook.DescendantorSelfNodesSelector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163170591936.html) | [workbook.DimensionSelector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008193274.html) | [workbook.PathSelector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008382970.html) | required | The row to style. |
