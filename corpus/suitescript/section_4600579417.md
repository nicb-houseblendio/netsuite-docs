## Parameters {#bridgehead_4600579506}

Note:

The options parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description | Since |
| --- | --- | --- | --- | --- |
| `options.fieldId` | string | required | The internal ID of the column field in the sublist. See, [Finding Internal IDs of Record Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_0416043804.html). | 2015.2 |
