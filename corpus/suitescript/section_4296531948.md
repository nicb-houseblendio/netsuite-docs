| **Property Description** | The version of NetSuite that the method is called in. For example, the runtime.version property in an account running NetSuite 2023.2 is 2023.2. For example, you can use this method when installing a bundle in another NetSuite accounts to find out the version number before installing the bundle. |
| --- | --- |
| **Type** | string (read-only) |
| **Module** | [N/runtime Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4296359529.html) |
