| **Method Description** | Unlocks a certificate record that has been locked with [certificateControl.lock(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161316650912.html). |
| --- | --- |
| **Returns** | void |
| **Supported Script Types** | Server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | 10 units |
| **Module** | [N/certificateControl Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1547247950.html) |
| **Since** | 2021.1 |

## Parameters {#subsect_161316706289}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.id` | string | required | The script ID or internal ID for the certificate you want to unlock. You can view the ID of a certificate from the **Digital Certificates** list at _Setup > Company > Certificates_. |

Important:

The following code sample shows the syntax for this member. It is not a functional example. For a complete script example, see [N/certificateControl Module Script Samples](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0302040948.html).
