| **Property Description** | Columns to return for this search as an array of [search.Column](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345767216.html) objects or a string array of column names. You set this value with an array of search.Column objects or a single search.Column to overwrite any prior return columns for the search. Use `null` to set an empty array and remove any existing columns on this search. |
| --- | --- |
| **Type** | [search.Column](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345767216.html)\[\] | string\[\] |
| **Module** | [N/search Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345764122.html) |
| **Since** | 2015.2 |
