The content in this help topic pertains to SuiteScript 2.1.

| **Property Description** | The tool call requests from the LLM. Note: The value of this property is not available until the entire response from the LLM has been generated. Make sure that you don't start processing this property and calling any required tools in your scripts until the streamed response is fully read. |
