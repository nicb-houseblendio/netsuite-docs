| **Object Description** | The token usage for a request to the LLM. This object is included in the [llm.Response](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1015033509.html) object returned from [llm.generateText(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1014032554.html) (using the [Response.usage](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0804073454.html) property) and represents the number of tokens used during a request to the LLM. It includes properties for the number of tokens in the response from the LLM ([Usage.completionTokens](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0804071705.html)), the number of tokens in the request to the LLM ([Usage.promptTokens](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0804071825.html)), and the total number of tokens for the entire request ([Usage.totalTokens](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0804071933.html)). This object is available only for Cohere models. |
