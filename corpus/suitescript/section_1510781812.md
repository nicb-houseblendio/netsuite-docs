| **Property Description** | An array of result columns ([query.Column](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510779196.html) objects) returned from the query. The [query.Column](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510779196.html) object is the equivalent of the [search.Column](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345767216.html) object in the [N/search Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345764122.html). The [query.Column](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510779196.html) object describes a field type (column) that is returned from the query results. To create columns:
-   Use [Query.createColumn(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510780373.html) to create conditions on the initial query definition created with [query.create(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510275581.html).
-   Use [Component.createColumn(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510784945.html) to create conditions on the join relationships created with [Query.autoJoin(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530819144.html) and [Component.autoJoin(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530818573.html).
-   Assign all created columns as values to `Query.columns`. For an example, see [Syntax](#subsect_1510781812).
