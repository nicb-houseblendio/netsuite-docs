For more information about SuiteScript modules, see [SuiteScript 2.1 Modules](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4220488571.html). For more information about the SuiteScript module APIs, see [SuiteScript 2.x API Reference](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_4140956840.html).

For use case samples available in the SuiteScript Code Samples catalog, see [SuiteScript Use Cases Samples](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_156097263055.html).
