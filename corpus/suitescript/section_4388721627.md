Use the format module to parse formatted data into strings and to convert strings into a specified format. The format module formats data according to personal preferences set on the Set Preferences page, accessible from _Home > Set Preferences_. See [Setting Personal Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N475297.html).

## N/format Module Members {#section_4388726111}

| Member Type | Name | Return Type / Value Type | Supported Script Types | Description |
| --- | --- | --- | --- | --- |
| Method | [format.format(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4388843892.html) | string | Date | Client and server scripts | Takes a raw value and returns a formatted value. Note: This method is overloaded when you format a `datetime` or `datetimetz` value. |
| [format.parse(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4388837989.html) | Date | string | number | Client and server scripts | Takes a formatted value and returns a raw value. | Enum | [format.Timezone](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4407050795.html) | enum | Client and server scripts | Holds the string values for supported time zone formats. Use this enum to set the value of the `options.timezone` parameter. |
| [format.Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4388844232.html) | enum | Client and server scripts | Holds the string values for the supported field types. Use this enum to set the value of the `options.type` parameter when calling [format.format(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4388843892.html) or [format.parse(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4388837989.html). |
