| **Method Description** | Replaces all occurrences of a pattern string inside an [https.SecureString](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4418286676.html) with a replacement string. Tip: If you are using an [https.SecureString](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4418286676.html) as a URL in [https.put(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4567627984.html) or [https.post(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4567628658.html) calls, you can use this method to escape any special characters you are using in the URL. For instance, you can replace the '#' special character with '%23' to allow for the use of '#' in a SecureString used as a URL. |
| --- | --- |
| **Returns** | A converted [https.SecureString](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4418286676.html) (not a new SecureString). |
| **Supported Script Types** | Server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/https Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4418229131.html) |
| **Since** | 2021.2 |

## Parameters {#bridgehead_162190865576}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.pattern` | string | required | The string to be replaced. |
| `options.replacement` | string | required | The replacement string. |

The following code sample shows the syntax for this member. It is not a functional example. For a complete script example, see [N/https Module Script Samples](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0305042314.html).
