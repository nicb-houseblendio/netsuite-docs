| **Property Description** | An aggregate function that is performed on the condition. An aggregate function performs a calculation on the condition values and returns a single value. This property is set during the of [Query.createCondition(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510780329.html) or [Component.createCondition(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510784922.html). Note: This property is not applicable to parent conditions created with the of [Query.and(conditions)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510780422.html), [Query.or(conditions)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510780444.html), or [Query.not(condition)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510780462.html). |
