A RESTlet is a SuiteScript you can call from outside NetSuite or another script. It only runs when called, and sometimes returns a value.

RESTlets help you pull data into NetSuite from other systems or send data out. You can also use RESTlets with other scripts to customize how NetSuite pages work.

For more details, see the following:

-   [SuiteScript 2.1 RESTlet Reference](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4618434109.html)
    
-   [SuiteScript 2.1 RESTlet Script and Request Examples](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4618431360.html)
    
-   [SuiteScript 2.1 RESTlet Script Entry Points and API](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4557203242.html)
    

You can manage RESTlet scripts with SuiteCloud Development Framework (SDF) in file-based projects. To learn more, see [SuiteCloud Development Framework](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4702622163.html). Use Copy to Account to send a RESTlet script to another account. Click Copy to Account in the upper right on the script page. For details, see [Copy to Account](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1544019532.html).

Use SuiteScript Analysis to check when a script was installed and how it's performed. For more, see [Analyzing Scripts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4299098804.html).
