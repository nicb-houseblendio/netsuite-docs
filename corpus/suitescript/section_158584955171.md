| **Method Description** | Decompresses a file that was compressed using gzip and returns it as a temporary file object. |
| --- | --- |
| **Returns** | [file.File](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4247974825.html) |
| **Supported Script Types** | Server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/compress Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158584507367.html) |
| **Module Members** | [N/compress Module Members](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158584507367.html#subsect_158584510347) |
| **Since** | 2020.2 |

## Parameters {#subsect_158584966607}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.file` | [file.File](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4247974825.html) | required | The file to be decompressed. |

## Errors {#subsect_158584970690}

| Error Code | Thrown If |
| --- | --- |
| `COMPRESS_API_DECOMPRESS_ERROR` | The file cannot be decompressed. |
| `COMPRESS_API_UNABLE_TO_RETRIEVE_FILE_CONTENTS` | The contents of the file to be decompressed cannot be retrieved. |

            `// Add additional code ... var gunzippedFile = compress.gunzip({     file: gzippedFile });`
