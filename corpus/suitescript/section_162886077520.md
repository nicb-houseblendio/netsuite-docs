## Parameters {#subsect_162886077864}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.expression` | [workbook.Expression](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008229845.html) | required | An expression indicating when the report style rule should be applied. |
| `options.style` | [workbook.Style](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163173520481.html) | required | The style to use for the report style rule. |
