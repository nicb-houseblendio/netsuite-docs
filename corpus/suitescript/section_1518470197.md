There are three API modules you can use to build a custom user interface with SuiteScript 2.1:

-   [N/ui/serverWidget Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4321345532.html) - The serverWidget module has UI components for working with user interfaces in NetSuite. You can use it to create custom pages, forms, lists, and widgets with the NetSuite look and feel.
    
-   [N/ui/message Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4497735093.html) - The message module lets you display and manage messages at the top of your user interface.
    
-   [N/ui/dialog Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4497725142.html) - The dialog module lets you create modal dialog boxes to present options or alerts. It uses JavaScript promises to manage dialogs asynchronously.
