## Parameters {#bridgehead_1544103215}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description | Since |
| --- | --- | --- | --- | --- |
| `options.number` | number | required | The number to be spelled out in a string. | 2019.1 |
| `options.locale` | string | required | The language code that specifies the string's language. ISO 639-1 alpha-2 language codes are supported. The language specified in this parameter is not related to the language specified for a NetSuite account. You can specify any language for this parameter; you do not have to specify a NetSuite supported language. For more information, see [Codes for the Representation of Names of Languages.](http://www.loc.gov/standards/iso639-2/php/code_list.php) | 2019.1 |
