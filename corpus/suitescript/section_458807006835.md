| **Property Description** | Title for a saved search. Use this property to set the title for a search before you save it for the first time. You can also set the title for a search when you create it with [search.create(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345171487.html). The Search.title property is required to save a search with [Search.save()](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_452655578613.html). |
| --- | --- |
| **Type** | string |
| **Module** | [N/search Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345764122.html) |
| **Since** | 2015.2 |
