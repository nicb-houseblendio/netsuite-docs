| **Method Description** | Adds a link to a list. |
| --- | --- |
| **Returns** | [serverWidget.List](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4325856174.html) (it return itself) |

| **Governance** | None |
| **Module** | [N/ui/serverWidget Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4321345532.html) |
| **Since** | 2015.2 |

## Parameters {#bridgehead_4346428587}

Note:

The options parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description | Since |
| --- | --- | --- | --- | --- |
| `options.title` | string | required | The text label for the link. | 2015.2 |
| `options.type` | string | required | The type of page link to add. Set this value using the [serverWidget.FormPageLinkType](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4332671075.html) enum. | 2015.2 |
| `options.url` | string | required | The URL for the link. | 2015.2 |
