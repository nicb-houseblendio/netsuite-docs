(dynamic and standard mode - see [SuiteScript 2.x Standard and Dynamic Modes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1524156901.html)) |

## Parameters {#bridgehead_4600438392}

Note:

The options parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description | Since |
| --- | --- | --- | --- | --- |
| `options.fieldId` | string | required | The internal ID of the field that may contain a subrecord. See, [Finding Internal IDs of Record Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_0416043804.html). | 2015.2 |
