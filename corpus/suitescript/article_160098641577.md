The general steps you take to convert a SuiteScript 1.0 script to a SuiteScript 2.1 script depend on whether you are converting an entry point script or a custom module script.

-   If your script is for a specific script type, such as user event or client script, you will first need to edit the script so that the correct script type structure is in place. This includes adding JSDoc comments, the define function, and a return statement at a minimum. For more information about proper script structure, see the help topic [SuiteScript 2.1 Anatomy of a Script](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510274310.html).
    
-   After you place the script into the proper structure, you can start converting individual SuiteScript 1.0 calls into their corresponding SuiteScript 2.1 calls according to the [SuiteScript 1.0 to SuiteScript 2.1 API Map](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4752722762.html). Note that this order is not a strict order of steps to take; however, you may find it easier to place the script into the proper script structure first and then convert each call statement.
    
-   If your script is a custom module and not a specific script type, you can convert each SuiteScript 1.0 call into its corresponding SuiteScript 2.1 call according to the [SuiteScript 1.0 to SuiteScript 2.1 API Map](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4752722762.html).
    

Here are a few additional notes to consider when converting your scripts:

-   Some functions and objects in SuiteScript 1.0 are now supported in SuiteScript 2.1 by using JavaScript, such as Date functions.
    
-   Some functions and objects in SuiteScript 1.0 operate a little differently in SuiteScript 2.1, such as logging and printing. See the help topic [Differences in Similar SuiteScript 1.0 and SuiteScript 2.1 Capabilities](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160098637276.html).
    
-   Some function and objects in SuiteScript 1.0 do not completely map to any SuiteScript 2.1 module, method, property, or enum. See the help topic [SuiteScript 1.0 APIs Not Directly Mapped to a SuiteScript 2.1 Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160098633600.html).
    

The [Sample SuiteScript 1.0 to SuiteScript 2.0 and SuiteScript 2.1 Conversions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160098646281.html) help topic shows you side-by-side comparisons for SuiteScript 1.0, SuiteScript 2.0, and SuiteScript 2.1 scripts for each script type and custom modules.

If converting your SuiteScript 1.0 scripts to SuiteScript 2.1 is not feasible in your situation, you can use SuiteScript 2.1 RESTlet scripts to extend the capabilities of your existing SuiteScript 1.0 scripts. For more information, see [Using SuiteScript 2.x Scripts with SuiteScript 1.0 Scripts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_4155500631.html).
