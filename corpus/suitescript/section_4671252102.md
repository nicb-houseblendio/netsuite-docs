| **Property Description** | The script path to be used in the portlet. |
| --- | --- |
| **Type** | string |
| **Entry Point** | [render(params)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4407951965.html) |
| **Since** | 2016.2 |

## Errors {#bridgehead_4672923132}

| Error Code | Thrown If |
| --- | --- |
| PROPERTY\_VALUE\_CONFLICT | You tried to set this value, but the Portlet.clientScriptFileId is already set. For more information, see [Portlet.clientScriptFileId](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4671255061.html). |

## Syntax {#bridgehead_4671252102}

The following code snippet shows the syntax for this member. Note that this isn't a working example. For a complete script example, see [SuiteScript 2.1 Portlet Script Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4387799288.html).

          `... params.portlet.clientScriptModulePath = '/SuiteScripts/clientScript.js'; ...`
