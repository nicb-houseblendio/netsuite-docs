As charged project revenue rules recognize the revenue from project charges as they are created rather than when they are billed. It is available when the Projects Management, Charge-Based Billing and Advanced Revenue Management features are enabled.

For help working with this record in the UI, see the help topics [Creating As Charged Project Revenue Rules](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_159360988425.html) and [Charge-Based Project Billing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3752830510.html).

The internal ID for this record is `aschargedprojectrevenuerule`.

See the [SuiteScript Records Browser](https://system.netsuite.com/help/helpcenter/en_US/srbrowser/Browser2026_1/script/record/resourcegroup.html) for all internal IDs associated with this record. For information about using the SuiteScript Records Browser, see [Working with the SuiteScript Records Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N3169369.html).

## Supported Script Types {#bridgehead_95150441389}

The As Charge Project Revenue rule record is scriptable in server and client SuiteScript.

## Supported Functions {#bridgehead_40150637622}

This record is fully scriptable, which means that the record can be created, updated, copied, deleted, and searched using SuiteScript.

## Usage Notes {#bridgehead_4150732893}

The system notes sublist is search-only. The chargerule sublist contains only one editable column: chargerule. Other columns are read only: amount, type, billingitem, description.

## Code Samples {#bridgehead_59150803501}

The following sample shows how to create a new As Charged Revenue rule.

          `require(['N/record'], function(record) {     var asChargedRevRule = record.create({       type: 'aschargedprojectrevenuerule',        isDynamic: true    });     asChargedRevRule.setText({       fieldId: 'name',       text: 'As Charged Revenue Rule name'    });    asChargedRevRule.setValue({       fieldId: 'project',       value: 456    });    asChargedRevRule.selectNewLine({       sublistId: 'chargerule'    });    asChargedRevRule.setCurrentSublistValue({       sublistId: 'chargerule',        fieldId: 'chargerule',        value: '3'    });    asChargedRevRule.commitLine({       sublistId: 'chargerule'    });    var asChargedRevRuleId = asChargedRevRule.save(); });`
