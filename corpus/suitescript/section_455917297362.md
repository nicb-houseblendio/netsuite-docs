| **Property Description** | Script ID for a saved search, starting with `customsearch`. If you do not set this property and then save the search, NetSuite generates a script ID for you. Note: This is not the internal NetSuite ID for the saved search. See [Search.searchId](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_458892150878.html). |
