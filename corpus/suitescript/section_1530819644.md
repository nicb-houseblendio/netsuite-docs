| **Property Description** | The locale to use for the sort. This property uses values from the [query.SortLocale](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530819885.html) enum. This property is set during the of [Query.createSort(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510780402.html) and [Component.createSort(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510785047.html). A locale represents a combination of language and region, and it can affect how certain values (such as strings) are sorted. For example, languages that share the same alphabet may sort characters differently. Use this property to ensure that query results are sorted using locale-specific rules. |
