| **Object Description** | Encapsulates a single search column in a [search.Search](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4392315904.html). Use the methods and properties available to the Column object to get or set Column properties. You create a search column object with [search.createColumn(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345776927.html) and add it to a [search.Search](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4392315904.html) object that you create with [search.create(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345171487.html) or load with [search.load(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345775360.html). You can pass a Column object as a parameter to the [Result.getValue(column)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_46988464355.html) or [Result.getText(column)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_460663391112.html) methods. In addition, [search.ResultSet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345767679.html) contains an array of Column objects returned in the results of a search. |
