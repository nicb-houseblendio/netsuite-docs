| **Object Description** | A dimension selector object which is used when you create a path selector, a sort definition, a conditional filter, a limiting filter or a measure sort. Use [workbook.createDimensionSelector(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159051255354.html) to create this object. A dimension selector object is used as a parameter in these methods: [workbook.createConditionalFilter(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159050988221.html), [workbook.createLimitingFilter(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159051462385.html), [workbook.createMeasureValueSelector(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162862156486.html) , [workbook.createPathSelector(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159051588951.html), [workbook.createSortByMeasure(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162886129949.html), and [workbook.createSortDefinition(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159051836190.html). |
