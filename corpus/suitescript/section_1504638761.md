SuiteScript 2.1 scripts differ structurally from SuiteScript 1.0 scripts. They use a modular architecture and organize script logic around entry points, context objects, and object-based method arguments.

The following topics explain basic structural patterns in SuiteScript 2.1 scripts:

-   [Modular Architecture](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1508957818.html)
    
-   [Objects in Standard Method Calls](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1508957722.html)
    
-   [Context Objects in Entry Point and Custom Module Scripts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1508957748.html)
    

For a walkthrough that shows these concepts in context, review [SuiteScript 2.1 Hello World](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1503717063.html).
