| **Method Description** | Runs an on-demand search created with [search.create(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345171487.html) or a search loaded with [search.load(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345775360.html), returning the results as a [search.ResultSet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345767679.html). Calling this method does not save the search. Use this method with [search.create(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345171487.html) to create and run on-demand searches that are never saved to the database. After you run a search, you can use [ResultSet.each(callback)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_457160888671.html) to iterate through the result set and process each result. Important: When you call this method, consider the following:
-   Search result sets are not cached. If records applicable to your search are created, modified, or deleted at the same time you are traversing your result set, your result set may change.
-   For better performance, consider creating a saved search in the UI and loading it in your script using [search.load(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345775360.html) instead of creating the search directly in your script using [search.create(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345171487.html).
