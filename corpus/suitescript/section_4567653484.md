| **Method Description** | Adds a header to the response. If the same header has already been set, this method adds another line for that header. For example: `{Vary: ['Accept-Language', 'Accept-Encoding']}` For more information, see [HTTPS Header Information](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4418229131.html#subsect_1558529145). |
| --- | --- |
| **Returns** | void |
| **Supported Script Types** | Server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/https Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4418229131.html) |
| **Since** | 2015.2 |

## Parameters {#bridgehead_4567653383}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description | Since |
| --- | --- | --- | --- | --- |
| `options.name` | string | required | The name of the header. | 2015.2 |
| `options.value` | string | required | The value used to set the header. | 2015.2 |

## Errors {#bridgehead_4567653330}

| Error Code | Message | Thrown If |
| --- | --- | --- |
| `SSS_INVALID_HEADER` | One or more headers are not valid. | The header name or value is invalid. |
| `SSS_MISSING_REQD_ARGUMENT` | Missing a required argument: {param name} | The `options.name` or `options.value` parameter is not specified. |
