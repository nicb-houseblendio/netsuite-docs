The project charge rule record is available only when the Project Management and Charge-Based Billing features are enabled. In the UI, you access this record on the Financial subtab of charge-based billing projects.

The internal ID for this record is `chargerule`.

Project charge rules determine the billing rate, the timing of project charges, and the stage of a charge when it is generated.

For help working with this record in the UI, see [Understanding Charge Rules](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3752833778.html).

See [Project Charge Rule Record Macros](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1529345552.html) for macros associated with this record. For more information about actions and macros, see [Overview of Record Action and Macro APIs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1509640242.html).

## Supported Script Types {#bridgehead_1490781609}

The project charge rule record is supported in client and server SuiteScript.

## Supported Operations {#bridgehead_4839903362}

This record can be created, read, updated, deleted, copied, and searched using SuiteScript. It cannot be transformed.

## Usage Notes {#bridgehead_4839903596}

If charges generated from a project charge rule have been billed, the project charge rule record is read-only. The `chargeruletype` field is required.

## Code Samples {#bridgehead_4839903861}

The following samples show how to create a time-based project charge rule.

          `var chargeRule= record.create({     type: record.Type.CHARGE_RULE,     isDynamic: true,     defaultValues: {         'charegeruletype': 'TIMEBASED'     } }); chargeRule.setValue({     fieldId: 'name',     value: 'ChargeRuleName' }); chargeRule.setValue({     fieldId: 'project',     value: '96' }); var id = chargeRule.save();`
