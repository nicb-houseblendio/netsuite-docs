| **Object Description** | Represents a single node in an XML document tree. A node can be an element, attribute, or document. For a list of possible node types, see [xml.NodeType](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345174049.html). The XML Document Object Module (DOM) is a general way to access and manipulate XML documents. In an XML document, the DOM organizes nodes into a hierarchical tree structure. For general information about the XML DOM structure, see [XML DOM.](https://www.w3schools.com/xml/xml_dom.asp) NetSuite supports a subset of W3C DOM methods to manipulate parent and nested nodes. For other code samples that use this object, see the syntax sample that follows, as well as [Node.childNodes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_459823547362.html) and [N/xml Module Script Samples](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0305035854.html). |
