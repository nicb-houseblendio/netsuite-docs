## Parameters {#subsect_159051255851}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.dimension` | [workbook.DataDimension](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008172142.html) | [workbook.Section](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008446199.html) | required | The dimension of the selector (the dimension to be selected). |
