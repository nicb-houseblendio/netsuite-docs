| **Property Description** | The parameters for the query. In SuiteQL, query conditions are represented using the `WHERE` clause and a set of parameters. In a SuiteQL string, parameter values for conditions are represented using question marks (?), and the `params` property includes a list of the parameter values to use when the query runs. If the query uses more than one parameter, the order of the values in the `params` property matches the order the parameters appear in the query string. For example, consider the following [query.Condition](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510779210.html) object in a query for customer records: `myQueryObject.createCondition({ fieldId: 'creditlimit', operator: query.Operator.LESS_OR_EQUAL, values: [50000] });` If you use [Query.toSuiteQL()](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157960522744.html) to convert this query to SuiteQL, the resulting SuiteQL query string includes the following `WHERE` clause: `WHERE customer.creditlimit <= ?` In the resulting [query.SuiteQL](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157960384819.html) object, the `params` property includes the value `50000`. |
