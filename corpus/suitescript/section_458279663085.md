| **Method Description** | Returns the total number of record or row inputs to the reduce stage of a [task.MapReduceScriptTask](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345798404.html). Use the [MapReduceScriptTaskStatus.stage](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_460753112791.html) property to get the current stage. For general information about map/reduce stages, see [Map/Reduce Key Concepts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0901045042.html) and [Map/Reduce Script Stages](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4387802529.html). |
| --- | --- |
| **Returns** | number |
