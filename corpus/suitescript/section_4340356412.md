| **Method Description** | Removes a button. This method can be used on custom buttons and certain built-in NetSuite buttons. For more information about built-in NetSuite buttons, see [Button IDs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N3265696.html). |
| --- | --- |
| **Returns** | void |
| **Supported Script Types** | Suitelets User event scripts - beforeLoad entry point For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/ui/serverWidget Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4321345532.html) |
| **Since** | 2015.2 |

## Parameters {#bridgehead_4340356411}

Note:

The options parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description | Since |
| --- | --- | --- | --- | --- |
| `options.id` | string | required | The internal ID name of the button to remove. See [Button IDs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N3265696.html). The internal ID must be in lowercase and contain no spaces. | 2015.2 |
