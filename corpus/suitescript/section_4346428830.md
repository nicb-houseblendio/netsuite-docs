| **Method Description** | Adds a single row to a list. |
| --- | --- |

## Parameters {#bridgehead_4346428860}

Note:

The options parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description | Since |
| --- | --- | --- | --- | --- |
| `options.row` | Object\[\] | required | A row that consists of either a [search.Result](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345767112.html) array, or name/value pairs. Each pair should contain the value for the corresponding Column object in the list. | 2015.2 |
