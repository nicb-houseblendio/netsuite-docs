Note:

The content in this help topic pertains to SuiteScript 2.1.

| **Object Description** | A tool call request from the large language model (LLM), which is returned as part of the response from [llm.generateText(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1014032554.html) or [llm.generateTextStreamed(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_46075557997.html). This object represents a single request from the LLM to run a defined tool as part of an LLM interaction. The LLM generates a tool call request when it determines that running a particular tool may help provide a more accurate or useful response to your prompt. This object enables dynamic, context-driven integration between the LLM and your SuiteScript code, allowing for real-time data retrieval, business logic execution, or other operations to be included in LLM interactions. This object is returned in the Response.toolCalls property (when calling [llm.generateText(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1014032554.html)) or StreamedResponse.toolCalls property (when calling [llm.generateTextStreamed(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_46075557997.html)). This object includes properties for the name of the tool to call ([ToolCall.name](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_21103802286.html)) and key-value pairs for each input parameter required by the tool, as specified in the tool definition ([ToolCall.parameters](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_48103839503.html)). Your SuiteScript code is responsible for iterating over these tool calls, running the appropriate handler logic with the provided parameters, and returning the results to the LLM. |
