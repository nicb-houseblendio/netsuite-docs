| **Method Description** | Method used to send a SSL secured POST request to a remote service and return the response. Important: If negotiating a connection to the destination server exceeds 5 seconds, a connection timeout occurs. If transferring a payload to the server exceeds 45 seconds, a request timeout occurs. |
| --- | --- |
| **Returns** | An [https.ClientResponse](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4567656083.html) Object |
| **Supported Script Types** | Server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | 10 units |
| **Module** | [N/https/clientCertificate Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1543986321.html) |
| **Since** | 2019.1 |

## Parameters {#subsect_1547084646}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description | Since |
| --- | --- | --- | --- | --- |
| `options.url` | string | required | The URL address of the remote server. | 2019.1 |
| `options.certId` | string | required | The ID of the client certificate. | 2019.1 |
| `options.body` | string | required | The POST data to be sent to the remote server. | 2019.1 |
| `options.headers` | object | optional | The HTTPS headers associated with the request. For more information, see [HTTPS Header Information](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4418229131.html#subsect_1558529145). | 2019.1 |
