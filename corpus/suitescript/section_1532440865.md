The N/query module lets you create and run queries using the SuiteAnalytics Workbook query engine. Before you start creating your queries, you should be familiar with the module objects and how to use them, as well as some of the terminology used in the N/query module. You can also take a look at a script walkthrough that explains how to create queries using different approaches.

-   [N/query Module Objects](#subsect_1527642761)
    
-   [N/query Module Terminology](#subsect_1519851639)

### Query and Component Objects {#subsect_1527642796}

The [query.Query](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510275177.html) object and the [query.Component](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510779141.html) object are the primary building blocks for a query created with the N/query module. Each query creates one [query.Query](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510275177.html) object and one or more [query.Component](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510779141.html) objects. The [query.Query](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510275177.html) object encapsulates the query definition, and the [query.Component](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510779141.html) object encapsulates one component of the query definition.

To create a query with the N/query module:

1.  Use the [query.create(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510275581.html) method to create your initial query definition (the [query.Query](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510275177.html) object). The initial query definition uses one search type. For available search types, see [query.Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510878994.html).
    
2.  After you create the initial query definition, use [Query.autoJoin(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530819144.html), [Query.joinFrom(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530819218.html), or [Query.joinTo(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530819329.html) to create your first join.
    
3.  Use any of the following methods to create subsequent joins:
    
    -   [Query.autoJoin(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530819144.html)
        
    -   [Query.joinFrom(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530819218.html)
        
    -   [Query.joinTo(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530819329.html)
        
    -   [Component.autoJoin(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530818573.html)
        
    -   [Component.joinFrom(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530818705.html)
        
    -   [Component.joinTo(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530818855.html)
        

The query definition always contains at least one [query.Component](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510779141.html) object. Each new component is created as a child of the previous component, and all components exist as children of the query definition. You can think of a component as a building block; each new component builds on the previous component created. The last component created encapsulates the relationship between it and all of its parent components.

Queries with joins contain multiple components. The query definition contains a child [query.Component](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510779141.html) object for each of the following:

-   **The initial query definition:** The initial [query.Component](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510779141.html) object is called the root component. It encapsulates the initial search type passed to [query.create(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510275581.html). The root component is automatically created with the initial query definition and is a child to the [query.Query](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510275177.html) object. The [Query.root](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510781874.html) property contains a reference to the root component.
    
-   **The first join:** The second [query.Component](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510779141.html) object is created with [Query.autoJoin(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530819144.html), [Query.joinFrom(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530819218.html), or [Query.joinTo(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530819329.html). It encapsulates the relationship between the initial query definition and the second search type. This relationship is determined by the join ID passed to these methods, as well as whether [Query.joinFrom(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530819218.html) or [Query.joinTo(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530819329.html) was used to create an explicit directional join. The second [query.Component](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510779141.html) object is a child to the root component.
    
-   **Each subsequent join:** The third [query.Component](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510779141.html) object is created with [Component.autoJoin(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530818573.html), [Component.joinFrom(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530818705.html), or [Component.joinTo(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530818855.html). All subsequent joins are also created using these methods. Each of these [query.Component](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510779141.html) objects encapsulates the relationship between all previous search types and the new search type. This relationship is determined by the join ID passed to these methods, as well as whether [Component.joinFrom(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530818705.html) or [Component.joinTo(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530818855.html) was used to create an explicit directional join.
    

### Condition Object {#subsect_1527642813}

A condition narrows the query results. The [query.Condition](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510779210.html) object performs the same function as the [search.Filter](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345767603.html) object in the [N/search Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345764122.html). The primary difference is that [query.Condition](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510779210.html) objects can contain other [query.Condition](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510779210.html) objects.

To create conditions:

-   Use [Query.createCondition(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510780329.html) to create conditions for the initial query definition created with [query.create(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510275581.html).
    
-   Use [Component.createCondition(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510784922.html) to create conditions for the join relationships created with [Query.autoJoin(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530819144.html), [Query.joinFrom(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530819218.html)/[Query.joinTo(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530819329.html), [Component.autoJoin(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530818573.html), or [Component.joinFrom(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530818705.html)/[Component.joinTo(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530818855.html).
    
-   If you have multiple conditions, use [Query.and(conditions)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510780422.html), [Query.or(conditions)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510780444.html), and [Query.not(condition)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510780462.html) to create a new nested condition.
    
-   If you want to use a formula to define your conditions, assign the formula to [Condition.formula](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510789560.html).
    
-   Assign your simple or nested conditions as array values to [Query.condition](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510781832.html).
    

### RelativeDate Object {#subsect_1549905133}

The [query.RelativeDate](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544109440.html) object represents a date that is relative to the current date. You can use relative dates when you create query conditions.

To create relative dates:

-   Use [query.createRelativeDate(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544108154.html) to create a [query.RelativeDate](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544109440.html) object. When you call [query.createRelativeDate(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544108154.html), use the values in the [query.DateId](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544111587.html) enum to specify a date that is relative to the current date.
    
-   Use [Query.createCondition(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510780329.html) or [Component.createCondition(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510784922.html) to create a condition using the [query.RelativeDate](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544109440.html) object. Alternatively, you can create a condition using values in the [query.RelativeDateRange](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544111773.html) enum.
    
-   If you have multiple conditions, use [Query.and(conditions)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510780422.html), [Query.or(conditions)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510780444.html), and [Query.not(condition)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510780462.html) to create a new nested condition.
    
-   Assign your simple or nested conditions as array values to [Query.condition](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510781832.html).
    

### Column Object {#subsect_1527642835}

The [query.Column](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510779196.html) object is the equivalent of the [search.Column](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345767216.html) object in the [N/search Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345764122.html). The [query.Column](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510779196.html) object describes the field types (columns) that are displayed from the query results.

To create columns:

-   Use [Query.createColumn(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510780373.html) to create a column on the initial query definition created with [query.create(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510275581.html).
    
-   Use [Component.createColumn(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510784945.html) to create a column on a join relationship created with [Query.autoJoin(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530819144.html), [Query.joinFrom(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530819218.html)/[Query.joinTo(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530819329.html), [Component.autoJoin(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530818573.html), or [Component.joinFrom(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530818705.html)/[Component.joinTo(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530818855.html).
    
-   If you want to use a formula to define your columns, assign the formula to [Column.formula](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510789062.html).
    
-   Assign all created columns as array values to [Query.columns](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510781812.html).
    

### Sort Object {#subsect_1527642857}

The [query.Sort](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510779222.html) object describes how query results are sorted (for example, ascending or descending, case sensitive or case insensitive, and so on).

To create a sort:

-   Use [Query.createSort(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510780402.html) to create a sort on the initial query definition created with [query.create(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510275581.html).
    
-   Use [Component.createSort(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510785047.html) to create a sort based on a join relationship created with [Query.autoJoin(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530819144.html), [Query.joinFrom(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530819218.html)/[Query.joinTo(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530819329.html), [Component.autoJoin(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530818573.html), or [Component.joinFrom(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530818705.html)/[Component.joinTo(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530818855.html).
    
-   Assign all created sorts as array values to [Query.sort](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510781853.html).
    

### ResultSet and Result Objects {#subsect_1527642999}

When you are ready to execute your query, call [Query.run(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510780212.html). This method returns a [query.ResultSet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510779235.html) object, which encapsulates the metadata for the set of results returned by the query.

To access your query results, iterate through the [ResultSet.results](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510857646.html) array. Each member of the [ResultSet.results](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510857646.html) array is a [query.Result](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510779258.html) object. The [query.Result](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510779258.html) object encapsulates a single row of the result set.

### Page, PagedData, and PageRange Objects {#subsect_1527642880}

You also can execute your query by calling [Query.runPaged(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510780277.html). This method returns a [query.PagedData](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510779273.html) object, which encapsulates a set of paged query results.

To access your query results, iterate through the paged query results using [PagedData.iterator()](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510861317.html). You can access each page of the query results, which are represented by [query.Page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510779287.html) objects. The [query.PageRange](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510779296.html) object encapsulates the range of query results for a page.
