| **Method Description** | Use this method to retrieve the IDs for bundles that contain the specified script, for each script specified. |
| --- | --- |
| **Returns** | Object.<String, \[int\]>, which is a `{scriptId: arrayOfBundleIds}` mapping. See [Syntax](#subsect_160470647943) for an example. |
| **Supported Script Types** | Client and server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | 10 units |
| **Module** | [N/suiteAppInfo Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160236086332.html) |
| **Sibling Module Members** | [N/suiteAppInfo Module Members](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160236086332.html#subsect_160236033491) |
| **Since** | 2021.1 |

## Parameters {#subsect_160470649347}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.scriptsIds` | string\[\] | required | The list of script ids. |

## Syntax {#subsect_160470647943}

Important:

The following code sample shows the syntax for this member. It is not a functional example. For a complete script example, see [N/suiteAppInfo Module Script Sample](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0303051612.html).

            `// Add additional code ... var myScriptIds = {"scriptA", "scriptB", "scriptC"}; var bundlesWithScripts = suiteAppInfo.listBundlesContainingScripts({     scriptIds: myScriptIds }); // For example, bundlesWithScripts would be: // { //    "scriptA": [],        // there is no bundle that contains this script //    "scriptB": [12],      // bundle with bundle ID 12 contains this script //    "scriptC": [12, 123]  // bundles with bundle ID 12 and bundle ID 123 contain this script // } ... // Add additional code`
