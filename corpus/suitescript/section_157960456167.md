| **Property Description** | The type of the query. This property uses values from the [query.Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510878994.html) enum. When you use [Query.toSuiteQL()](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157960522744.html) to convert an existing [query.Query](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510275177.html) object to SuiteQL, this property contains the same type that was specified for the original query. |
