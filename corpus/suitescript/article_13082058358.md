| **Object Description** | The streamed response returned from the LLM. Use the following methods to retrieve a streamed response from the LLM:
-   [llm.generateTextStreamed(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_46075557997.html)
-   [llm.generateTextStreamed.promise(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_48093225962.html)
-   [llm.evaluatePromptStreamed(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_47080704730.html)
-   [llm.evaluatePromptStreamed.promise(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_43094934029.html)

When calling these methods, you can access the partial response (using the [StreamedResponse.text](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_83082638858.html) property of the returned [llm.StreamedResponse](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_13082058358.html) object) before the entire response has been generated. You can also access the value of the [StreamedResponse.model](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_37082546497.html) property in this way. Other properties (such as [StreamedResponse.documents](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_2082503946.html) and [StreamedResponse.citations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_2082423034.html)) are accessible only after the entire response has been generated. You can use an iterator to examine each token returned by the LLM. For an example, see [llm.generateTextStreamed(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_46075557997.html). |
