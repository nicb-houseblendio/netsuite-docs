| **Method Description** | Method used to return the content of the file. Important: Content held in memory is limited to 10MB. Note: You can access CSV or text files (including files over 10MB) using [File.appendLine(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4769938149.html) or [File.lines.iterator()](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4769955095.html). |
| --- | --- |
| **Returns** | The file content as a string. |
| **Supported Script Types** | Server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/file Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4205693274.html) |
| **Since** | 2015.2 |

## Errors {#bridgehead_4528912649}

| Error Code | Message | Thrown If |
| --- | --- | --- |
| `SSS_FILE_CONTENT_SIZE_EXCEEDED` | The file content you are attempting to access exceeds the maximum allowed size of 10 MB. | You attempt to return the content of a file larger than 10MB. |
