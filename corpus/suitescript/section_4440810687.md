| **Method Description** | Sends an HTTP DELETE request asynchronously. Note: The parameters and errors thrown for this method are the same as those for [http.delete(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4426024970.html). For more information about promises, see [Promise Object](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4387812940.html). |
