| **Returns** | void |
| **Since** | 2016.1 |

## afterInstall(params) Parameters {#bridgehead_4460460407}

Note:

The `params` parameter is a JavaScript object. It's automatically passed to the script entry point by NetSuite.

| Parameter | Type | Description | Since |
| --- | --- | --- | --- |
| `params.version` | string | The version of the bundle that's being installed in the target account. | 2016.1 |
