| Script Entry Point | Description |
| --- | --- |
| [RESTlet Script get Entry Point](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4407965171.html) | Lets you retrieve something (like a NetSuite record). Runs when a get request calls the RESTlet-like http.get. Returns an HTTP response body. |
| [RESTlet Script delete Entry Point](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4407965553.html) | Lets you delete something (like a NetSuite record). Runs when a delete request calls the RESTlet-like http.delete. Returns an HTTP response body. |
| [RESTlet Script put Entry Point](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4407965751.html) | Lets you insert or upsert something (like a NetSuite record). Runs when a put request calls the RESTlet-like http.put. Returns an HTTP response body. |
| [RESTlet Script post Entry Point](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4407966008.html) | Lets you create something (like a NetSuite record). Runs when a post request calls the RESTlet-like http.post. Returns an HTTP response body. |
