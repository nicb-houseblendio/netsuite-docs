| **Property Description** | Returns `true` if the field is visible on the record form, or `false` if it is not. This property is available only when working with a record in dynamic mode. For more information about record modes, see [SuiteScript 2.x Standard and Dynamic Modes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1524156901.html). This property is not available when working with record sublist fields. It is only available when working with record body fields. |
