| **Method Description** | Adds a file to be archived. In the archive, the path to the target file is `options.directory` or `options.file.nam`. If the `options.directory` parameter is not specified, the target file is located in the root directory of the archive. |
| --- | --- |
| **Returns** | void |
| **Supported Script Types** | Server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/compress Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158584507367.html) |
| **Parent Object** | [compress.Archiver](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158584592144.html) |
| **Sibling Object Members** | [Archiver Object Members](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158584507367.html#subsect_158584546368) |
| **Since** | 2020.2 |

## Parameters {#subsect_158584753167}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.file` | [file.File](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4247974825.html) | required | The file to be archived. |
| `options.directory` | string | optional | The target directory in the archive. If this parameter is not specified, the file is placed in the root directory of the archive. |

## Errors {#subsect_158584764231}

| Error Code | Thrown If |
| --- | --- |
| `COMPRESS_API_DUPLICATE_PATH` | A file has already been added using the same target path. |
| `COMPRESS_API_FILE_IS_TOO_LARGE` | The file cannot be compressed due to size; this happens for files >680MB. Binary/ASCII files have a higher limit of 2GB. |
