| **Method Description** | Returns an array of [xml.Element](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345167426.html) objects with a specific tag name, in the order in which they appear in the XML document. |
| --- | --- |
| **Returns** | [xml.Element](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345167426.html)\[\] |
| **Supported Script Types** | Client and server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/xml Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4344917661.html) |
| **Since** | 2015.2 |

## Parameters {#bridgehead_455679260253}

Note:

The options parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.tagName` | string | required | Case-sensitive tag name of the element to match on. Use the `*` wildcard to match all elements. |
