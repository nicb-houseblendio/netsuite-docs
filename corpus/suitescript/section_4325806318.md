| **Property Description** | Determines whether the button is hidden in the UI. The default value is `false`, which means the button is visible. If set to true, the button is not visible in the UI. Note: This property is supported on custom buttons and on some standard NetSuite buttons. For a list of supported standard buttons, see [Button IDs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N3265696.html). |
| --- | --- |
| **Type** | boolean |
| **Supported Script Types** | Suitelets User event scripts - `beforeLoad` entry point For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Module** | [N/ui/serverWidget Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4321345532.html) |
| **Since** | 2015.2 |
