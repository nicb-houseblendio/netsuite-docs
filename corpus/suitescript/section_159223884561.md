| **Object Description** | The status of an asynchronous SuiteQL task ([task.SuiteQLTask](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159223833809.html)) in the NetSuite task queue. You create a `task.SuiteQLTaskStatus` object using [task.checkStatus(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345805891.html). To check the status of a SuiteQL task, you must provide the task ID of the SuiteQL task. To submit a SuiteQL task and obtain the task ID, use [SuiteQLTask.submit()](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159223847318.html). |
