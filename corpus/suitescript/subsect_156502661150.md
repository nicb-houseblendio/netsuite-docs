To run an SDF installation script when deploying your SuiteApp, you need to link it to a script record and a script deployment record. For more information, see the help topic [Creating a Script Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4489062315.html).

You can create script records and script deployment records in a few ways:

1.  Within your SuiteCloud project as XML representations
    
2.  Using SuiteScript.
    
3.  From your NetSuite account.
    

For more information, see [SDF Installation Scripts as XML Definitions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1547147541.html) and [SuiteCloud Development Framework XML Reference](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/SDFxml.html).

SDF installation scripts have a limit of 10,000 units per run. For more information about governance, see the help topics [Script Type Usage Unit Limits](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3351480.html) and [SuiteScript Governance and Limits](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N3350651.html).

## Managing SDF Installation Scripts in SDF {#subsect_156502584911}

You can use SuiteCloud Development Framework to manage SDF installation scripts as part of file-based customization projects. You can also add SDF installation scripts to your SuiteApp project deployment. SuiteApp projects can include SDF installation scripts, which run automatically when the project is deployed. For more information, see the following help topics:

-   [SuiteCloud Development Framework](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4702622163.html)
    
-   [Customizing SuiteApp Project Deployment using SDF Installation Scripts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1548438348.html)
    
-   [SDF Installation Scripts as XML Definitions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1547147541.html)
    
-   [Defining a Script Record and Deployment for an SDF Installation Script](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1553883681.html)
    
-   [Customizing SuiteApp Project Deployment using SDF Installation Scripts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1548438348.html)
    

You can monitor SDF installation scripts and deployments using the deploy log in SuiteCloud IDE or the Execution Log on the Script or Script Deployment page. For more information, see [Deployment Logs for SuiteCloud Projects](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4715369474.html) and [Handling Exceptions and Monitoring SDF Installation Scripts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1548438348.html#subsect_1553712761).

## Copy to Account Support for SDF Installation Scripts {#subsect_156502645900}

Use the Copy to Account feature to copy an SDF installation script to another account. Find the Copy To Account option in the top right corner of each SDF installation script page. For information about Copy to Account, see the help topic [Copy to Account](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1544019532.html).
