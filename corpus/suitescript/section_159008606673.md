| **Object Description** | A table column object which is used when you create a table definition. Use [workbook.createTableColumn(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159051899414.html) to create this object. A table column object is used as a parameter in the [workbook.createTable(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163344854839.html) method. |
