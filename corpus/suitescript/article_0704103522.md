The content in this help topic pertains to SuiteScript 2.1.

| **Enum Description** | Holds values for the feature to extract from a document. Use this enum to specify the document features you want to extract when you call [documentCapture.documentToStructure(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0704102801.html) (using the `options.features` parameter). If you don't specify any features when you call this method, the `TEXT_EXTRACTION` and `TABLE_EXTRACTION` features are used by default. |
| --- | --- |
| **Module** | [N/documentCapture Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_8134325498.html) |
| **Supported Script Types** | Server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Since** | 2025.2 |
