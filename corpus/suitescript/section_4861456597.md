| **Method Description** | Returns a domain name for a NetSuite account. |
| --- | --- |
| **Returns** | string |
| **Supported Script Types** | Client and server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/url Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4358552918.html) |
| **Since** | 2017.1 |

## Parameters {#bridgehead_4805546283}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description | Since |
| --- | --- | --- | --- | --- |
| `options.hostType` | string | required | The type of domain name you want to retrieve. Set this value using the [url.HostType](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4834765371.html) enum. | 2017.1 |
| `options.accountId` | string | optional | The NetSuite account ID for which you want to retrieve data. If no account is specified, the system returns data on the account that is running the script. You can find the account ID at _Setup > Company > Company Information_ in the **Account ID** field. | 2017.1 |
