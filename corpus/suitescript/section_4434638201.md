| **Method Description** | Returns true if the `obj` parameter is a JavaScript Array object and false otherwise. |
| --- | --- |
| **Returns** | boolean |
| **Supported Script Types** | Client and server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/util Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4569538303.html) |
| **Global object** | [util Object](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4387813290.html) |
| **Since** | 2016.1 |

## Parameters {#bridgehead_4434630677}

| Parameter | Type | Required / Optional | Description | Since |
| --- | --- | --- | --- | --- |
| obj | Object | Primitive | required | Object for which you want to verify the type. | 2016.1 |
