Use N/crypto module to perform hashing, hash-based message authentication (hmac), and symmetrical encryption functions.

When the N/crypto module is used, SuiteScript also loads [N/encode Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4369847722.html).

**[N/crypto Module Script Samples](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0302070216.html)**
