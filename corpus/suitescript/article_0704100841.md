The content in this help topic pertains to SuiteScript 2.1.

| **Object Description** | An extracted page from a document. This object includes properties for the fields ([Page.fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0704100922.html)), lines ([Page.lines](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0704101048.html)), tables ([Page.tables](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0704101117.html)), and words ([Page.words](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0704101139.html)) of the page. These properties have values only when the associated feature is specified when you call [documentCapture.documentToStructure(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0704102801.html). For example, the [Page.fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0704100922.html) property includes extracted fields only if the `documentCapture.Feature.FIELD_EXTRACTION` feature is specified. If you don't specify any features when you call this method, the `TEXT_EXTRACTION` and `TABLE_EXTRACTION` features are used by default. |
