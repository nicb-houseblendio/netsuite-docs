| **Property Description** | Path of the CSV file to export query results to. The CSV file must be located in the File Cabinet. You can provide a value for this property or the [QueryTask.fileId](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159223756577.html) property. Only one of these properties can be set at the same time. If both are set, an error occurs. |

## Errors {#subsect_159223772077}

| Error Code | Thrown If |
