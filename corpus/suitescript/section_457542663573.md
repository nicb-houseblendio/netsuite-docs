| **Method Description** | Converts the content of a [https.SecureString](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4418286676.html) between two encodings. |
| --- | --- |
| **Returns** | The converted [https.SecureString](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4418286676.html) (not a new SecureString). |
| **Supported Script Types** | Server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/https Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4418229131.html) |
| **Since** | 2015.2 |

## Parameters {#bridgehead_458227783202}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.fromEncoding` | string | required | The encoding to be used to decode the current content of the SecureString. Use values from [https.Encoding](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4612521061.html). |
| `options.toEncoding` | string | required | The encoding to store the content as. Use values from [https.Encoding](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4612521061.html). |

## Errors {#bridgehead_162265707869}

| Error Code | Thrown If |
| --- | --- |
| `FAILED_TO_CONVERT_BINARY_DATA_TO_UTF_8` | The content of the SecureString is binary data and it does not represent a valid UTF-8-encoded string. |
| `FAILED_TO_DECODE_STRING_ENCODED_BINARY_DATA_USING_1_ENCODING` | The content of the SecureString is not a valid encoded string according to the `options.fromEncoding` parameter value. |
