The following tips may help you debug SuiteScript 1.0 and 2.0 scripts using the Script Debugger:

-   Review the Execution Log subtab on the Script Debugger page to view all script messages and alerts, including those indicating any script errors.
    
-   Execution metrics are shown on the Execution Log subtab of the Script Debugger page.
    
-   Use breakpoints to pause script execution at predetermined lines of code. Breakpoints are managed on the Break Points subtab on the Script Debugger page. See [Break Points Debugger Subtab](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N3018104.html) for more information.
    
-   Use the Watch subtab on the Script Debugger page to see values of variables within your script and to evaluate expressions instantly. See [Watches Debugger Subtab](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N3017995.html) for more information.
    
-   Use the Evaluated Expressions subtab on the Script Debugger page to manually enter and evaluate expressions. See [Evaluate Expressions Debugger Subtab](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N3018068.html) for more information.
    
-   To cancel a debugging session without finishing script execution, click the **X** button on the Script Debugger page.
