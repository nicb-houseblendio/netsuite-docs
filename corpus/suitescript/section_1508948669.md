Important:

Before you submit a scheduled script, be sure you know how [SuiteCloud Processors](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1498571420.html) works.

You can programmatically submit a scheduled script to [SuiteCloud Processors](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1498571420.html) with [task.ScheduledScriptTask](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4392318707.html). When a script submits or schedules a deployment, NetSuite runs the scheduled script with the same user and role permissions as the calling script.

You can submit an on-demand script only if there isn't another unfinished instance of it running.

#### To submit an on-demand scheduled script instance from another script: {#procedure_1509039462}

1.  First, create your scheduled script entry point, which includes your JavaScript file and script record. Need an example? Check out the [SuiteScript 2.1 Scheduled Script Type Code Sample](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4647930350.html). New to scripts? See [SuiteScript 2.1 Hello World](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1503717063.html) and [SuiteScript 2.x Entry Point Script Creation and Deployment](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4525001447.html).
    
2.  On the associated script record, select the **Deploy Script** button.
    
3.  When the script deployment record loads, click the **Deployed** box if it's not already checked. You can't submit the script unless this box is checked.
    
4.  Review the scheduled script deployment field descriptions at [Scheduled Script Deployment Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1508948655.html).
    
5.  Set the Status field to **Not Scheduled**.
    
6.  Set the remaining body fields.
    
7.  Click **Save**.
    
8.  In the server script where you want to submit the scheduled script, call [task.create(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4392320106.html) This returns a [task.ScheduledScriptTask](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4392318707.html) object:
    
                    `var scriptTask = task.create({     taskType: task.TaskType.SCHEDULED_SCRIPT });` 
                  
    
9.  Set the [ScheduledScriptTask.scriptId](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_459331604003.html) and [ScheduledScriptTask.deploymentId](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_46258483886.html) properties:
    
                    `scriptTask.scriptId = 1234; scriptTask.deploymentId = 'customdeploy1';` 
                  
    
10.  Call [ScheduledScriptTask.submit()](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_460871520995.html) to submit the scheduled script instance to [SuiteCloud Processors](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1498571420.html).
     
                     `var scheduledScriptTaskId = scriptTask.submit();`
