| **Method Description** | Creates a data dimension, which includes items, child data items, and a total line. A data dimension is used in a [workbook.PivotAxis](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008441105.html), a [workbook.DimensionSelector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008193274.html), and a [workbook.Section](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008446199.html). |
| --- | --- |
| **Returns** | [workbook.DataDimension](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008172142.html) |
| **Supported Script Types** | Server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/workbook Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_159006350818.html) |
| **Sibling Module Members** | [N/workbook Module Members](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_159006350818.html#subsect_159006379904) |
| **Since** | 2020.2 |

## Parameters {#subsect_159051059242}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.children` | Array<[workbook.DataDimension](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008172142.html) | [workbook.Section](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008446199.html) | [workbook.CalculatedMeasure](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163169891173.html) | [workbook.DataMeasure](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163170291911.html)\> | optional | The child data dimensions or sections of the data dimension. |
| `options.items` | [workbook.DataDimensionItem](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008187726.html)\[\] | required | The items of the data dimension. |
| `options.totalLine` | [workbook.TotalLine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159059291106.html) | optional | The predefined formats for the total line. |

## Errors {#subsect_159051059727}

| Error Code | Thrown If |
| --- | --- |
| `INVALID_TOTAL_LINE` | The value specified for the `options.totalLine` parameter is invalid. Set this parameter value using [workbook.TotalLine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159059291106.html). |
| `NO_DIMENSION_ITEM_DEFINED` | The `options.items` parameter is empty. |
