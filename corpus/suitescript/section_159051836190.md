## Parameters {#subsect_159051836721}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.selector` | [workbook.DimensionSelector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008193274.html) | [workbook.PathSelector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008382970.html) | required | The selector for the sort definition. |
| `options.sortBys` | Array < [workbook.SortByDataDimensionItem](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163173379734.html) | [workbook.SortByMeasure](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163173416538.html)\> | required | The sort order for the sort definition. |

## Errors {#subsect_159051837253}

| Error Code | Thrown If |
| --- | --- |
| `NO_SORT_BY_DEFINED` | The value set for the `options.sortBys` parameter is empty. |
