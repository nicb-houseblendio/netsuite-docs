| **Method Description** | Creates an attribute node of type ATTRIBUTE\_NODE with the optional specified value and returns the new [xml.Attr](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345169036.html) object. The localName, prefix, and namespaceURI properties of the new node are set to `null`. |
| --- | --- |
| **Returns** | [xml.Attr](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345169036.html) |
| **Supported Script Types** | Client and server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/xml Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4344917661.html) |
| **Since** | 2015.2 |

## Parameters {#bridgehead_457204528807}

Note:

The options parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.name` | string | required | Name of the new attribute node. |
| `options.value` | string | optional | Value for the attribute node. If unspecified, the value is an empty string. |

## Errors {#bridgehead_454612060546}

| Error Code | Message | Thrown If |
| --- | --- | --- |
| `SSS_XML_DOM_EXCEPTION` | INVALID\_CHARACTER\_ERR: An invalid or illegal XML character is specified. | Attribute with the spcified name or value cannot be created. |
