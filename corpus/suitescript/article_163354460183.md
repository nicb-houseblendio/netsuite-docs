Styles help you customize cell formats in table views and pivots based on conditions. You can create standalone styles to customize cell attributes, and then add them to formatting rules.

For more information about styles in SuiteAnalytics Workbook, see [Conditional Formatting](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161125973915.html).

You can create a standalone style using [workbook.createStyle(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162886251569.html). This method creates a [workbook.Style](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163173520481.html) object. You can also provide these optional parameters to [workbook.createStyle(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162886251569.html):

-   `backgroundColor` - The background color. Use values from the [workbook.Color](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162887285281.html) enum, or use [workbook.createColor(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162861840772.html) to create a custom color.
    
-   `backgroundImage` - The background image. Use values from the [workbook.Image](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163104240054.html) enum.
    
-   `backgroundPosition` - The background position. Use values from the [workbook.Position](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163104283914.html) enum, or use [workbook.createPositionPercent(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162862263729.html), [workbook.createPositionUnits(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162862280295.html), or [workbook.createPositionValues(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162862321945.html) to create a custom position.
    
-   `color` - The font color. Use values from the [workbook.Color](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162887285281.html) enum, or use [workbook.createColor(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162861840772.html) to create a custom color.
    
-   `fontSize` - The font size. Use values from the [workbook.FontSize](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162887352651.html) enum.
    
-   `fontStyle` - The font style. Use values from the [workbook.FontStyle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162887378565.html) enum.
    
-   `fontWeight` - The font weight. Use values from the [workbook.FontWeight](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163104222816.html) enum.
    
-   `textAlign` - The text alignment. Use values from the [workbook.TextAlign](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163104334844.html) enum.
    
-   `textDecorationColor` - The text decoration color. Use values from the [workbook.Color](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162887285281.html) enum, or use [workbook.createColor(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162861840772.html) to create a custom color.
    
-   `textDecorationLine` - The text decoration line. Use values from the [workbook.TextDecorationLine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163104347221.html) enum.
    
-   `textDecorationStyle` - The text decoration style. Use values from the [workbook.TextDecorationStyle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163104360654.html) enum.
    

          `var myFirstStyle = workbook.createStyle({     backgroundColor: workbook.createColor({         red: 255,         green: 192,         blue: 203     }) });  var mySecondStyle = workbook.createStyle({     fontSize: workbook.FontSize.LARGE,     fontStyle: workbook.FontStyle.ITALIC,     fontWeight: workbook.FontWeight.BOLD });` 
        

To create a report style, start by creating report style rules using [workbook.createReportStyleRule(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162886077520.html), similar to creating conditional formatting rules for a conditional format. This creates a [workbook.ReportStyleRule](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163171130796.html) object. You'll need to provide these parameters:

-   `expression` - An expression indicating when to apply the style. Create expressions using [workbook.createExpression(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159051315304.html). For more information, see [Expressions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_163386238329.html).
    
-   `style` - The style to apply when the expression evaluates to `true`. Create styles using [workbook.createStyle(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162886251569.html).
    

          `var myReportStyleRule = workbook.createReportStyleRule({     expression: workbook.createExpression({         functionId: workbook.ExpressionType.COMPARE,         parameters: {             comparisonType: 'GREATER_OR_EQUAL',             operand1: workbook.createExpression({                 functionId: workbook.ExpressionType.MEASURE_VALUE,                 parameters: {                     measure: myCalculatedMeasure                 }             }),             operand2: workbook.createConstant(                 workbook.createCurrency({                     amount: 1,                     id: 'USD'                 })             )         }     }),     style: workbook.createStyle({         backgroundColor: workbook.createColor({             red: 255,             green: 192,             blue: 203         })     }) });` 
        

When you have your report style rules, use [workbook.createReportStyle(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162886027908.html) combine them into a single [workbook.ReportStyle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163171063813.html) object. You'll also need to provide a selector to choose the cell in the pivot where the style will be applied. For more information, see [Selectors](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_163354461590.html).

          `var conditionalRowSelector = workbook.DescendantOrSelfNodesSelector; var conditionalColumnSelector = workbook.DescendantOrSelfNodesSelector; var conditionalMeasureSelector = workbook.createMeasureSelector({     measures: [myCalculatedMeasure] });  var measureValueSelector = workbook.createMeasureValueSelector({     rowSelector: conditionalRowSelector,     columnSelector: conditionalColumnSelector,     measureSelector: conditionalMeasureSelector });  var myReportStyle = workbook.createReportStyle({     selectors: [measureValueSelector],     rules: [myFirstReportStyleRule, mySecondReportStyleRule] });`
