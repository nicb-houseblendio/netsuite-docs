| **Method Description** | Adds a new attribute with the specified name. If an attribute with that name is already present in the element, its value is changed to the value specified in method argument. If an attribute with the specified name already exists, the value of the attribute is changed to the value of the value parameter. |
| --- | --- |
| **Returns** | void |
| **Supported Script Types** | Client and server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/xml Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4344917661.html) |
| **Since** | 2015.2 |

## Parameters {#bridgehead_457448974608}

Note:

The options parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.name` | string | required | Name of the attribute to add. |
| `options.value` | string | required | Value of the attribute to add. |

## Errors {#bridgehead_455031982421}

| Error Code | Message | Thrown If |
| --- | --- | --- |
| `SSS_XML_DOM_EXCEPTION` | INVALID\_CHARACTER\_ERR: An invalid or illegal XML character is specified. | Value for the attribute cannot be set. |
