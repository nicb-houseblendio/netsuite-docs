| **Method Description** | Creates a new workbook. Workbooks are where you analyze the results of your dataset queries using different components, such as table views and pivots. All workbooks are based on a dataset, and a single dataset can be used as the basis for multiple workbooks. A workbook can include an ID, a name, a description, pivots, and tables. |

## Parameters {#subsect_159008745109}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.charts` | [workbook.Chart](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159007989923.html)\[\] | optional | The c |
| `options.description` | string | optional | The description of the workbook. |
| `options.name` | string | optional | The name of the workbook. |
| `options.pivots` | [workbook.Pivot](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008434619.html)\[\] | optional | The pivots to include in the workbook. |
| `options.tables` | [workbook.Table](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163344915869.html)\[\] | optional | The tables to include in the workbook. |
