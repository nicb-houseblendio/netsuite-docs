| **Property Description** | The key-value pairs that override static script parameter field values on the script deployment record. Use these parameters on a [task.MapReduceScriptTask](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345798404.html) object to programmatically pass values to the script deployment. For example, if you create a script parameter called `custscript_my_script_param`, you can set the value of that parameter as follows: `// mrTask is a MapReduceScriptTask object mrTask.params = { 'custscript_my_script_param': 'value' };` For more information about script parameters, see [Creating Script Parameters Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N2999300.html). |
