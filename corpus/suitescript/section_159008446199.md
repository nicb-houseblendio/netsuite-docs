| **Object Description** | A section object which can be used when you create a data dimension, a dimension selector, a pivot axis, or a pivot. Use [workbook.createSection(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159051755688.html) to create this object. A section object is used as a parameter in the [workbook.createDataDimension(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159051058770.html), [workbook.createPivotAxis(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159051729422.html), [workbook.createSection(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159051755688.html) methods. |
