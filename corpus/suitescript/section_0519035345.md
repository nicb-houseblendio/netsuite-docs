## Parameters {#subsect_0519035442}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.filters` | [workbook.TableColumnFilter](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163182554335.html) \[\] | optional | Filters for the condition. |
| `options.operator` | string | required | Operator of the condition. |

## Errors {#subsect_0519035455}

| Error Code | Thrown If |
| --- | --- |
| INVALID\_OPERATOR | The `options.operator` parameter is invalid. |
