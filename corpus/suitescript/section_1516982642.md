Record macros automate business logic when you edit a record. For more information, see [Overview of Record Action and Macro APIs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1509640242.html).

Record macro APIs are part of the [N/record Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4267255811.html). For more information, see [Record Object Members](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4267255811.html#bridgehead_4273190849) and [Macro Object Members](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4267255811.html#bridgehead_1529088663).
