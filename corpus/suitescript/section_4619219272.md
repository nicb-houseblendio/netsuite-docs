When you call a RESTlet, you can use one of four HTTP/HTTPS methods: delete, get, post, or put. Use the N/https module to connect SuiteScript scripts, RESTlets, and SuiteTalk REST endpoints without needing to reauthenticate. Use [https.requestRestlet(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159139340774.html) or [https.requestSuiteTalkRest(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159139347369.html) to send HTTPS requests to a RESTlet or REST endpoint.

When you call a RESTlet, keep these things in mind:

-   [A Call's Method Must Match an Entry Point](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_32154153292.html) defined in the RESTlet
    
-   [HTTP/HTTPS Methods Use the RESTlet Script Entry Points](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4625646774.html)
    
-   [Input Data Is Handled Differently by Different HTTP Methods](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4625649079.html)
    
-   [HTTPS Methods for Secure Communication Between SuiteScript Scripts and REST Endpoints](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_159215430391.html)
