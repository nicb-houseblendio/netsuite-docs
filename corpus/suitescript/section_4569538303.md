Use the N/util module to manually access methods that verify object and primitive types in a SuiteScript 2.x script. These methods can also be accessed using the global util object. For more information about the global util object, see [SuiteScript 2.1 Global Objects](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387171685.html).

**[N/util Module Script Sample](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0305034417.html)**

Use the N/util module to access methods that verify object and primitive types in a SuiteScript 2.x script.

Each method (for example, [util.isArray(obj)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4434638201.html)) returns a boolean value, based on evaluation of the `obj` parameter.

If you need to identify a type specific to SuiteScript 2.x, use the [toString()](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4542785226.html) global method.
