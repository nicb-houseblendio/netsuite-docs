| **Method Description** | Loads an existing saved search and redirect to the populated search definition page. |
| --- | --- |
| **Returns** | void |
| **Supported Script Types** | User event scripts -afterSubmit entry point For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | 5 units |
| **Module** | [N/redirect Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4424286105.html) |
| **Since** | 2015.2 |

## Parameters {#bridgehead_4424988669}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.id` | number | required | Internal ID of the search. The internal ID is available only when the search is either loaded with [search.load(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345775360.html) or after is has been saved with [Search.save()](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_452655578613.html). Typical values are 55 or 234 or 87, not a value like `customsearch_mysearch`. Any ID prefixed with `customsearch` is a script ID, not the internal system ID for a search. |
