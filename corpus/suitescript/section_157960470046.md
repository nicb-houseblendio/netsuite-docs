| **Method Description** | Runs the SuiteQL query and returns the query results. You can use this method to run the SuiteQL query and obtain the results as a [query.ResultSet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510779235.html) object. If you want to run the SuiteQL query as a paged query, use [SuiteQL.runPaged(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157960491275.html). Calling this method is equivalent to calling [query.runSuiteQL(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157960542026.html) and passing the [query.SuiteQL](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157960384819.html) object as a parameter: `// These two query calls return the same result set var firstResultSet = mySuiteQLObject.run(); var secondResultSet = query.runSuiteQL(mySuiteQLObject);` Note: If the SuiteAnalytics Connect feature is enabled in your NetSuite account, there is no limit to the number of results this method can return. If the SuiteAnalytics Connect feature is not enabled, this method can return a maximum of 100,000 results. For more information about SuiteAnalytics Connect, see [SuiteAnalytics Connect](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_3963845427.html). For more information and examples of using SuiteQL in the N/query module, see [SuiteQL in the N/query Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157960623712.html). For more information about SuiteQL in general, see [SuiteQL](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156257770590.html). |

## Parameters {#subsect_164607022591}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.customScriptId` | string | optional | A unique identifier used for potential performance issues in a query. If your query produces performance issues, the custom script ID identifies where the update will need to occur. This ID can also be used as a precaution to speed up performance fixes, if necessary. Note: The Script ID must be unique or the performance enhancements will affect each query with the same customScriptID. |
