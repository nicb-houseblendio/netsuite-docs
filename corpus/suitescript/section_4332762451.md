| **Method Description** | Adds a field group to the assistant. A field group is a collection of fields that can be displayed in a one or two column format. Assign a field to a field group to label, hide or collapse a group of fields. By default, the field group is collapsible and appears expanded on the assistant page. To change this behavior, set the [FieldGroup.isCollapsed](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4335356208.html) and [FieldGroup.isCollapsible](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4335348134.html) properties. |
| --- | --- |
| **Returns** | [serverWidget.FieldGroup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4325835878.html) object |
| **Supported Script Types** | Suitelets For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/ui/serverWidget Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4321345532.html) |
| **Since** | 2015.2 |

## Parameters {#bridgehead_4332762579}

Note:

The options parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description | Since |
| --- | --- | --- | --- | --- |
| `options.id` | string | required | The internal ID for the field group. | 2015.2 |
| `options.label` | string | required | The label for the field group. | 2015.2 |
