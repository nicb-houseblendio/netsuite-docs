## Parameters {#subsect_162862280640}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.unit` | [workbook.Unit](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163104381588.html) | required | The units to use for x-y coordinates. |
| `options.x` | number | required | The x coordinate. |
| `options.y` | number | required | The y coordinate. |

## Errors {#subsect_162862280968}

| Error Code | Thrown If |
| --- | --- |
| `INVALID_POSITION` | The resulting position is not included in the [workbook.Position](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163104283914.html) enum. |
| `INVALID_UNIT` | The value of the `options.unit` parameter is not included in the [workbook.Unit](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163104381588.html) enum. |
