| **Method Description** | Returns the value of a field. Note: You should not use of this method for custom password fields as it will no longer return a hashed value, but will return an obsfucated value. Use [crypto.checkPasswordField(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160806904480.html) instead. This applies to encrypted custom password field values obtained through a variety of ways, including by saved searches, SuiteAnalytics workbooks and datasets, SuiteAnalytics Connect integrations, SOAP web services integrations, REST web services integrations, and CSV export integrations. To get the value of a custom password field, use the [crypto.checkPasswordField(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160806904480.html) method. |
| --- | --- |
| **Returns** | number | Date | string | array | boolean |
| **Supported Script Types** | Client scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |

## Parameters {#bridgehead_4637582214}

Note:

The options parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description | Since |
| --- | --- | --- | --- | --- |
| `options.fieldId` | string | required | The internal ID of a standard or custom body field. See [Finding Internal IDs of Record Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_0416043804.html). | 2016.2 |
