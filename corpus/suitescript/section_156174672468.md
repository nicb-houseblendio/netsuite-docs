| **Method Description** | Runs the PI removal task. All validation for the task (for example, ensuring that the specified record IDs are valid) occurs when the task is saved using [PiRemovalTask.save()](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156174691190.html), not when the task is run using `PiRemovalTask.run()`. Note: Remove Personal Information Run permission is required to run a PI removal task. |
