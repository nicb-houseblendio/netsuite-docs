| **Property Description** | The current record's type. Note the following:
-   On an instance of a standard record type, this property is represented by a value from the [record.Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4273205732.html) enum.
-   On an instance of a custom record type, this value is populated by the custom record type's string ID. For help finding this ID, see [Custom Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3204194.html).
