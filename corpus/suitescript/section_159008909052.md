| **Method Description** | Creates a chart , A chart is a workbook component that enables you to visualize your dataset query results using predefined chart and graph types, such as line graphs and bar charts. A chart is built from an underlying dataset and can also include a category, a legend, series, a type, expressions, filters, stacking behavior indicators, along with an ID, a name, a title, and a subtitle. For more information about charts in SuiteAnalytics, see [Workbook Charts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544211366.html). |

## Parameters {#subsect_159008909598}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.aggregationFilters` | Array<[workbook.ConditionalFilter](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008152586.html) |[workbook.LimitingFilter](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008328944.html)\> | optional | The set of conditional filters or limiting filters that are applied to the chart. When multiple filters are defined, they are aggregated together to form a single compounded filter. |
| `options.category` | [workbook.Category](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159007978137.html) | required | The category of the chart. |
| `options.dataset` | [dataset.Dataset](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158948063457.html) | required | The underlying dataset that the chart is based on. A chart can include only the data (fields) that are included in the dataset. |
| `options.datasetLink` | [datasetLink.DatasetLink](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162626627810.html) | required | The datasetLink on which the chart is based |
| `options.filterExpressions` | [workbook.Expression](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008229845.html)\[\] | optional | The simple, non-aggregated value-based filters for the chart. |
| `options.id` | string | required | The ID of the chart. |
| `options.legend` | [workbook.Legend](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008316064.html) | required | The legend for the chart. |
| `options.name` | string | required | The name of the chart. |
| `options.portletName` | string | [workbook.Expression](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008229845.html) | required | The name of the portlet for the chart. |
| `options.series` | [workbook.Series](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008573032.html)\[\] | required | The set of series for the chart. Each series includes information about how each data point is calculated. For example, a series can represent the sum of transaction amounts for a customer in a particular month. |
| `options.stacking` | [workbook.Stacking](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159059283191.html) | optional | The stacking type that describes how the chart data is stacked. |
| `options.subTitle` | string | [workbook.Expression](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008229845.html) | optional | The subtitle of the chart. |
| `options.title` | string | [workbook.Expression](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008229845.html) | optional | The title of the chart. |
| `options.type` | [workbook.ChartType](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159059165881.html) | required | The type of the chart. |

## Errors {#subsect_159008910236}

| Error Code | Thrown If |
| --- | --- |
| `INVALID_CHART_TYPE` | The value specified for the `options.type` parameter is invalid. Set this value using [workbook.ChartType](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159059165881.html) |
| `INVALID_STACKING_TYPE` | The value specified for the `options.stacking` parameter is invalid. Set this value using [workbook.Stacking](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159059283191.html). |
