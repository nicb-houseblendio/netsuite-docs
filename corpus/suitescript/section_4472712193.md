| **Object Description** | Object that contains:
-   The key-value pairs to process in the map stage.
-   Logic to save data and pass it to the reduce stage.
-   Other properties you can use in the map function.

This object includes the following properties and methods:

-   [mapContext.isRestarted](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4540852756.html)
-   [mapContext.executionNo](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1516217757.html)
-   [mapContext.errors](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1516209193.html)
-   [mapContext.key](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4483840988.html)
-   [mapContext.value](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4483841695.html)
-   [mapContext.write(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4472712995.html)
