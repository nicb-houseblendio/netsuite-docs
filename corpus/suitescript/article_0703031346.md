The content in this help topic pertains to SuiteScript 2.1.

| **Property Description** | The pages of the document. The [documentCapture.documentToStructure(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0704102801.html) method supports documents up to five pages in length, so the returned [documentCapture.Document](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0703030933.html) object can contain up to five pages (as [documentCapture.Page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0704100841.html) objects). When you submit an asynchronous extraction task using the N/task module, you can provide documents of any length, so the returned object contains as many pages as were in the provided document. |
