| **Property Description** | The result columns to be returned from the query. This property is an array of [query.Column](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510779196.html) objects. When you use [Query.toSuiteQL()](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157960522744.html) to convert an existing [query.Query](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510275177.html) object to SuiteQL, this property contains the same [query.Column](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510779196.html) objects that were specified for the original query. Important: The SuiteQL query string in a [query.SuiteQL](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157960384819.html) object (contained in the [SuiteQL.query](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157960443690.html) property) does not include any aliases you set on query result columns in the original [query.Query](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510275177.html) object. For more information about aliases, see [Column.alias](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156336566313.html). |
