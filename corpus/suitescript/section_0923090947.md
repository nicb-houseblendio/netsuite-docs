The content in this help topic pertains to SuiteScript 2.1.

| **Object Description** | Stores processed PGP data. Responsible for enabling message serialization and providing a set of single-step processors to covert to a readable message. Use the [MessageData.toMessage()](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0923093718.html) and [MessageData.encrypt(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0923093832.html) to create a Message object. |
