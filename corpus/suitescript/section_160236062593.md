| **Method Description** | Use this method to retrieve a list of successfully installed bundles, as an array of objects. |
| --- | --- |
| **Returns** | Object\[\] Each object includes the following properties:
-   `id` (integer)
-   `name` (string)
-   `version` (string)
-   `description` (string)
-   `installedFrom` (string)
-   `isManaged` (boolean)
-   `dateInstalled` (Date)
-   `dateLastUpdated` (Date)
-   `publisher` (Publisher object, which includes an integer `id` and a string `name`)
-   `installedBy` (Installer object, which includes an integer `id` and a string `name`)

 |
| **Supported Script Types** | Client and server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
