| **Object Description** | Stores message data. The responsibilities of this object includes:
-   Store message contents with meta data.
-   Enable reading message contents and metadata.
-   For further processing, determines whether data is text or binary.
-   Provides a set of single-step processors for various PGP use cases.

Use the [pgp.createMessageData(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0923113223.html) method to create a message data object. |
