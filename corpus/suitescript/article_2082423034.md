| **Property Description** | The list of citations used to generate the streamed response. This property is an array of [llm.Citation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_56082143862.html) objects, each of which represents relevant information that was taken from a document provided to [llm.generateTextStreamed(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_46075557997.html) or [llm.generateTextStreamed.promise(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_48093225962.html). This property has a value only if a provided document was used to generate the response. Note: The value of this property is not available until the entire response from the LLM has been generated. |
