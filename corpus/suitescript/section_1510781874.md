| **Property Description** | The root component of the query definition. The initial [query.Component](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510779141.html) object is called the root component. It encapsulates the initial query type passed to [query.create(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510275581.html). The root component is automatically created with the [query.Query](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510275177.html) object and is a child of the [query.Query](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510275177.html) object. |
