| **Method Description** | Writes the key-value pairs to pass to the shuffle stage, and then to the reduce stage. If your script has both a map and a reduce function, you need to use this method so the reduce function runs. |
| --- | --- |
| **Returns** | Void |
| **Since** | 2015.2 |

## Parameters {#bridgehead_4473611214}

Note:

The options parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| options.key | String or object. However, note that if you provide an object, the system calls JSON.stringify() on your input. | required | The key to write |
| options.value | required | The value to write |

## Syntax {#bridgehead_4477802975}

The following code snippet shows the syntax for this member. It's not a functional example. For a complete script example, see [SuiteScript 2.1 Map/Reduce Script Code Samples](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0901033444.html).

          `... function map(context) {     for (var i = 0; context.value && i < context.value.length; i++)         if (context.value[i] !=== ' ' && !PUNCTUATION_REGEXP.test(context.value[i]))             {                 context.write({                     key: context.value[i],                     value: 1                  });             } } ...`
