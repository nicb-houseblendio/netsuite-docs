| **Method Description** | Creates a [render.EmailMergeResult](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4417244174.html) object for a mail merge with an existing scriptable email template. Note: You must load the [N/email Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4358552361.html) to send and attach the email template to a record. |
| --- | --- |
| **Returns** | [render.EmailMergeResult](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4417244174.html) |
| **Supported Script Types** | Server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/render Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4412042824.html) |
| **Since** | 2015.2 |

## Parameters {#bridgehead_453057189941}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.templateId` | number | required | Internal ID of the template. |
| `options.entity` | RecordRef | optional | The entity. |
| `options.recipient` | RecordRef | optional, the recipient can be specified with this parameter or with the [email.send(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4358681681.html) method. | The recipient. |
| `options.customRecord` | RecordRef | optional | The custom record. |
| `options.supportCaseId` | number | optional | The support case ID. |
| `options.transactionId` | number | optional | The transaction ID. |

## RecordRef {#bridgehead_4583319419}

You can use a RecordRef to designate the record to perform the mail merge on.

Note:

The RecordRef object encapsulates the type and ID of a particular record instance.

| Property | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `RecordRef.id` | number | required | Internal ID of the record instance. |
| `RecordRef.type` | string | required | The record type ID. |

## Syntax {#bridgehead_456403747558}

          `//Add additional code ... /** * @NApiVersion 2.x */ require(['N/email', 'N/render'], function(email, render) {     function sendEmail() {         var senderId = -5;         var recipientId = 1711;         var mergeResult = render.mergeEmail({             templateId: 7,             entity: {                 type: 'employee',                 id: senderId             },             recipient: {                 type: 'customer',                 id: recipientId             }         });              email.send({             author: senderId,             recipients: recipientId,             subject: mergeResult.subject,             body: mergeResult.body         });     }     sendEmail(); }); ... //Add additional code`
