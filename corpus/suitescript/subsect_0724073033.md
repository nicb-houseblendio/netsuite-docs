When external AI clients run custom tools, some scripts and customizations in NetSuite may also be triggered. The following table shows how these components are affected during execution.

| Customization | Impact |
| --- | --- |
| User Event Scripts Workflow Action Scripts | Run as the role configured for the NetSuite AI Connector Service. |
| Workflow | If not set to run as administrator, workflows are triggered as the role configured for the NetSuite AI Connector Service. |
