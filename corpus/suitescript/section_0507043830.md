Note: The parameters and errors thrown for this method are the same as those for [dataset.describe(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162853496011.html). For more information about promises, see [Promise Object](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4387812940.html). |

## Parameters {#subsect_0507043916}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.id` | string | required | The ID of the dataset to describe. |
