| **Method Description** | Creates a new [crypto.SecretKey](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4358620976.html) object. This method can take a GUID or the script ID of a secret stored at _Setup > Company > API Secrets_. Use [Form.addCredentialField(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4337770901.html) to generate a GUID value. For more information about API Secrets, see [Secrets Management](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160216486846.html). Note: When using the crypto.SecretKey object for an AES algorithm, the length of the text (secret key) that is used to generate the GUID must be 16, 24, or 32 characters. |
| --- | --- |
| **Returns** | A [crypto.SecretKey](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4358620976.html) object |
| **Supported Script Types** | Server scripts For additional information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/crypto Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4358549582.html) |
| **Since** | 2015.2 |

## Parameters {#bridgehead_4449124602}

Note:

The options parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description | Since |
| --- | --- | --- | --- | --- |
| `options.guid` | string | required if `secret` is not specified | A GUID used to generate a secret key. The GUID can resolve to either data or metadata. You can create a GUID using [Form.addCredentialField(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4337770901.html). This is only required if a secret is not provided. You cannot use the `guid` parameter in combination with the `secret` parameter. | 2015.2 |
| `options.secret` | string | required if `options.guid` is not specified | The script ID of the secret used for authentication. You can store secrets at _Setup > Company > API Secrets_. For more information, see [Secrets Management](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160216486846.html). This is only required if GUID is not provided. You cannot use the `secret` parameter in combination with the `passwordGuid` parameter. | 2021.1 |
| `options.encoding` | enum | optional | Specifies the encoding for the SecureKey. Use the [encode.Encoding](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4369865177.html) enum to set the value. The default value is `encode.Encoding.HEX`. | 2015.2 |
