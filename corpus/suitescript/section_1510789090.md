| **Property Description** | The return type of the formula used to create the query result column. This property is set during the of [Query.createColumn(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510780373.html) or [Component.createColumn(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510784945.html). If a formula is specified when these methods are called, this property contains the return type of the formula. If a formula is not specified, this property is null. For more information about formulas, see [Formulas in Searches](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_5143710889.html) and [SQL Expressions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2833020.html). |
