## Parameters {#subsect_162861793083}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.expression` | [workbook.Expression](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008229845.html) | required | The expression for the calculated measure. |
| `options.label` | string | [workbook.Expression](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008229845.html) | optional | The label for the calculated measure. |
