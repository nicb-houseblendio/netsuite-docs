| **Method Description** | Use this method to retrieve the ID for the SDF SuiteApp that contains the specified script, for each script specified. Only one ID will be returned for each specified script. |
| --- | --- |
| **Returns** | Object.<String, null|String>, which is a `{scriptId: suiteAppId|null}` mapping. See [Syntax](#subsect_160470641799) for an example. |
| **Supported Script Types** | Client and server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | 10 units |
| **Module** | [N/suiteAppInfo Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160236086332.html) |
| **Sibling Module Members** | [N/suiteAppInfo Module Members](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160236086332.html#subsect_160236033491) |
| **Since** | 2021.1 |

## Parameters {#subsect_160236084157}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.scriptsIds` | string\[\] | required | The list of script ids. |

## Syntax {#subsect_160470641799}

Important:

The following code sample shows the syntax for this member. It is not a functional example. For a complete script example, see [N/suiteAppInfo Module Script Sample](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0303051612.html).

            `// Add additional code ... var myScripts = {"scriptA", "scriptB", "scriptC"}; var suiteAppsWithScripts = suiteAppInfo.listSuiteAppsContainingScripts({     scriptIds: myScripts }); // For example, suiteAppsWithScripts would be: // { //    "scriptA": null,            // there is no SuiteApp that contains this script //    "scriptB": "SuiteAppX",     // SuiteAppX contains this script //    "scriptC": "SuiteAppY"      // SuiteAppY contains this script // }  ... // Add additional code`
