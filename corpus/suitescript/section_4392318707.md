| **Object Description** | All the properties of scheduled script task in SuiteScript. Use this object to place a scheduled script deployment into the NetSuite scheduling queue. To use the `ScheduledScriptTask` Object:
1.  In the NetSuite UI, create the script record and script deployment record.
2.  Use [task.create(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4392320106.html) to create the `ScheduledScriptTask` object.
3.  Use the `ScheduledScriptTask` object properties to set the script and deployment properties.
4.  Use [ScheduledScriptTask.submit()](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_460871520995.html) to deploy the scheduled script to the NetSuite scheduling queue.
5.  Use the properties for the [task.ScheduledScriptTaskStatus](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345798266.html) object to get the status of the scheduled script.

For more information about scheduled scripts in NetSuite, see [SuiteScript 2.1 Scheduled Script Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4387799491.html). |
