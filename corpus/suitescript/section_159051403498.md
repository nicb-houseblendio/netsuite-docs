## Parameters {#subsect_159051403889}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.axes` | [workbook.ChartAxis](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008145231.html)\[\] | required | The axes for the legend. |
| `options.root` | [workbook.Section](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008446199.html) |[workbook.DataDimension](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008172142.html) | required | The data for the legend. |
| `options.sortDefinitions` | [workbook.SortDefinition](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008585696.html)\[\] | optional | The sort definition for the corresponding legend axes. |
