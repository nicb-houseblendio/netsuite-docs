| **Method Description** | Locks a key that has been uploaded to the Private Keys list in the UI or created using [keyControl.createKey(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557417459.html). Locked keys cannot be edited in the UI until they are unlocked with [keyControl.unlock(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161351774208.html). For more information, see [Locking and Restricting Certificates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161964252762.html). |
| --- | --- |
| **Returns** | void |
| **Supported Script Types** | Server scripts For additional information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | 10 units |
| **Module** | [N/keyControl Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557413213.html) |
| **Since** | 2021.1 |

## Parameters {#subsect_161351701471}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description | Since |
| --- | --- | --- | --- | --- |
| `options.id` | string | required | The script ID or internal ID for the key you want to lock. You can view the ID of a key from the **Private Keys** list at _Setup > Company > Keys_. | 2021.1 |

### Errors {#subsect_162014224931}

| Error | Thrown If |
| --- | --- |
| `KEY_NOT_FOUND` | The key with the ID provided does not exist in this account. |
| `ACCESS_TO_KEY_RESTRICTED` | The current employee or script does not have permission to access or edit the key. This can happen if the key is restricted to specific scripts or employees on the key record using the Restrict to Scripts or Restrict to Employees fields. |
| `KEY_ALREADY_LOCKED` | The key has already been locked. |
