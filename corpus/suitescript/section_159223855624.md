| **Property Description** | Path of the CSV file to export SuiteQL query results to. The CSV file must be located in the File Cabinet. When you create a SuiteQL task using [task.create(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4392320106.html), you can provide a value for this property or the [SuiteQLTask.fileId](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159223852102.html) property. Only one of these properties can be set at the same time. If both are set, an error occurs. |
