| **Property Description** | Part of the XML declaration, the version number of the XML document. In the following declaration, the xmlVersion property is 1.0: `<?xml version="1.0" encoding="UTF-8" standalone="yes"?>` Important: This property is not supported on Internet Explorer or Firefox. |
| --- | --- |
| **Type** | string (read-only) |
| **Module** | [N/xml Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4344917661.html) |
| **Since** | 2015.2 |
