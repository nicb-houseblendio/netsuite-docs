For a SuiteScript 2.x entry point script to work, it must contain certain required elements. The system checks each script file for these elements when you upload it to the File Cabinet and saves data about your file which is used when you create a script record for the script.

If NetSuite detects that a required element within the script file is missing or incorrectly formatted, it returns an error. Errors can be returned when you upload the file to the File Cabinet or when you create a script record for the script file. Errors can also be returned when you attach a client script to a custom form.

For more information, see the following help topics:

-   [Entry Point Script Validation Guidelines](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4527904430.html)
    
-   [Entry Point Script Validation Examples](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4527901694.html)
