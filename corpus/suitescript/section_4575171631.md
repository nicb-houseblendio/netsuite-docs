After you create an entry point script and it passes validation, as described in [SuiteScript 2.x Entry Point Script Validation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4486246568.html), you'll need to deploy the script on records in your NetSuite Account by following these steps:

1.  Upload the script file to the File Cabinet.
    
2.  Create a script record for your script file, as described in [Script Record Creation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4486246677.html). The script record identifies the script's internal ID, whether the script is active, and other details.
    
3.  Deploy the script, as described in [Script Deployment](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4486246754.html). You can use script deployments to configure details for how and when the script runs. The choices you make vary depending on the script's type.
