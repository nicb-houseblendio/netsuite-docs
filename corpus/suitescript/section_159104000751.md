The internal ID for this record is `performancemetric`. For more details about this record and how to work with it in the UI, see [Goal Tracking with Performance Metrics](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/rc_1051865006.html).

This record becomes available when the Performance Management feature is enabled.

See the [SuiteScript Records Browser](https://system.netsuite.com/help/helpcenter/en_US/srbrowser/Browser2026_1/script/record/performancemetric.html) for all internal IDs associated with this record.

For information about using the SuiteScript Records Browser, see [Working with the SuiteScript Records Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N3169369.html) in the NetSuite Help Center.

## Support Script Types {#subsect_159104267937}

This record is scriptable in both server and client SuiteScript.

## Supported Functions {#subsect_161850975962}

This record is fully scriptable, which means it can be created, edited, copied, deleted, and searched.

## Code Sample {#subsect_159104267938}

The following sample shows how to open a performance metric record, change the name of the performance metric, and then save the performance metric.

            `var metric= record.load({    type: record.Type.PERFORMANCE_METRIC,    id: 1 });  metric.setValue({    fieldId: 'name',    value: 'Average Days to Close' });  metric.save();`
