| **Property Description** | An alternate name that you can assign to a [serverWidget.Field](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4325837128.html) object. By default, the alias is equal to the field's internal ID. This property is only supported on scripted fields created using the [N/ui/serverWidget Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4321345532.html). |
| --- | --- |
| **Type** | string |
| **Supported Script Types** | Suitelets User event scripts - beforeLoad entry point For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Module** | [N/ui/serverWidget Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4321345532.html) |
| **Since** | 2015.2 |
