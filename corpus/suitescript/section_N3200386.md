## Supported Script Types {#bridgehead_1516396843}

The case record is scriptable in both server and client SuiteScript.

## Supported Functions {#bridgehead_1516396876}

The case record is fully scriptable - it can be created, updated, copied, deleted, and searched using SuiteScript.
