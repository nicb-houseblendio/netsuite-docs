| **Method Description** | Sets CDN caching for a period of time. |
| --- | --- |
| **Returns** | void |
| **Supported Script Types** | Server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/https Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4418229131.html) |
| **Since** | 2015.2 |

## Parameters {#bridgehead_4567652119}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description | Since |
| --- | --- | --- | --- | --- |
| `options.type` | [https.CacheDuration](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4567627367.html) | required | The value of the caching duration. When used with a Suitelet, if this value is set to UNIQUE, then the Suitelet will never be cached and will always be executed if there's a request to its URL. | 2015.2 |

## Errors {#bridgehead_4567652058}

| Error Code | Message | Thrown If |
| --- | --- | --- |
| `SSS_MISSING_REQD_ARGUMENT` | Missing a required argument: {param name} | The `options.type` parameter is not specified. |
