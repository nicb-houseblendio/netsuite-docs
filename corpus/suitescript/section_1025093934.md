The following steps show how to set up and configure your Visual Studio Code for unit testing. For additional help, see [SuiteCloud Unit Testing](https://github.com/oracle/netsuite-suitecloud-sdk/tree/master/packages/unit-testing).

-   Install Visual Studio Code - Follow the steps on [SuiteCloud Extension for Visual Studio Code Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_158400948906.html) for information about how to install and set up your development environment. When your SuiteCloud project is created, you'll need to install the unit testing software.
    
-   Install Unit testing for SuiteCloud - For information about how to configure your SuiteCloud project for unit testing, see [SuiteCloud Unit Testing](https://github.com/oracle/netsuite-suitecloud-sdk/tree/master/packages/unit-testing).
    

## Complete Project Structure {#subsect_20094744657}

When you've set up your SuiteCloud project in Visual Studio, you're ready to begin writing unit tests. The following list provides details on each file in your project. For more information about SuiteCloud project structure, see [SuiteCloud Project Structure and File Components](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4724963992.html).

-   A **src** (source) folder that contains account configuration, SuiteScript file cabinet, and other SuiteCloud project dependencies.
    
-   A **\_\_tests\_\_** (unit tests) folder that contains the unit test files that correspond to each SuiteScript in your project.
    
-   A **jest.config.js** configuration file that contains project information, such as custom stub naming conventions and file paths.
    
-   A **package.json** file that contains project information, such as Jest and SuiteCloud dependencies.
    

Note that the following files are automatically generated in your project folder:

-   A **package-lock.json** file
    
-   A **coverage** folder that contains code coverage details for your test file. This folder will appear if code coverage is configured in the jest.config.js file when you run the `npm test` command in the embedded terminal.
    
-   A **node\_modules** folder
