| **Property Description** | Returns the sublist type. For more information about sublist types, see [serverWidget.SublistType](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4332704307.html). Important: Sublist.type will return a lower case string representing the sublist type. For example, `inlineeditor` not `INLINEEDITOR`. |
