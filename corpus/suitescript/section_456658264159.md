| **Method Description** | Used on select, image, and document fields. Returns the text value of a specified search result column. Note: This method is overloaded. You can also use [Result.getText(column)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_460663391112.html) to get a column value. This method takes in a single [search.Column](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345767216.html). |
| --- | --- |
| **Returns** | string |
| **Supported Script Types** | Client and server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/search Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345764122.html) |
| **Since** | 2015.2 |

## Parameters {#bridgehead_452158752441}

Note:

The options parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.name` | string | required | The name of the search column. |
| `options.join` | string | optional | The join internal ID for the search column. |
| `options.summary` | string | optional | The summary type used for the search column. See [search.Summary](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345777923.html). |
