| **Method Description** | Returns a [runtime.User](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4296528504.html) object that represents the properties and preferences for the user currently executing the script. Use this method to get session objects for the current user session. If you want to get properties for the script or session, use [runtime.getCurrentScript()](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4296529387.html) or [runtime.getCurrentSession()](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4296529736.html) instead. |
| --- | --- |
| **Returns** | [runtime.User](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4296528504.html) |
| **Supported Script Types** | Client and server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/runtime Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4296359529.html) |
| **Since** | 2015.2 |
