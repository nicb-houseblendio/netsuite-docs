When you open a record from the Scripted Records page, subtabs for each customization type is shown. The subtabs quickly show which scripts or workflows are deployed. Use these subtabs to view or update deployments.

Clicking on a script or workflow from a subtab opens the corresponding script or workflow record.

![Subtabs on the Scripted Records page include User Event Scripts, Client Scripts, Custom Forms, Localized user Event Scripts, and Localized Client Scripts.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/SuiteScript/SuiteScriptDeveloper/SuiteScriptDeveloperGuide/ScriptedRecordsView.png)

To learn more about each subtab, see:

-   [User Event Scripts and Localized User Event Scripts Subtabs on the Scripted Records Page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1520896383.html)
    
-   [Client Scripts and Localized Client Scripts Subtabs on the Scripted Records Page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_156409225234.html)
    
-   [Custom Forms Subtab on the Scripted Records Page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_156409229908.html)
    
-   [Workflows Subtab on the Scripted Records Page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_156409232168.html) (if enabled)
