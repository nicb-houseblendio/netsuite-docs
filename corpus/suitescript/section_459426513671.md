| **Method Description** | Writes template content to a server response. |
| --- | --- |
| **Returns** | void |
| **Supported Script Types** | Server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/render Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4412042824.html) |
| **Since** | 2015.2 |

## Parameters {#bridgehead_458502136229}

Note:

The options parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.response` | [http.ServerResponse](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4314609319.html) | required | Response to write to. |
