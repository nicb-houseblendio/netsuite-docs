| **Property Description** | Indicates whether the field group can be collapsed. The default value is `false`, which means the field group displays as a static group that cannot be opened or closed. If set to true, the field group can be collapsed. Only supported for fields on [serverWidget.Assistant](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4325849970.html) objects |
| --- | --- |
| **Type** | Boolean |
| **Supported Script Types** | Suitelets User event scripts - beforeLoad entry point For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Module** | [N/ui/serverWidget Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4321345532.html) |
| **Since** | 2015.2 |
