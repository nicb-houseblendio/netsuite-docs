| **Property Description** | Whether the relative date represents a range of dates or a specific moment in time. For relative date ranges that you obtain from the [query.RelativeDateRange](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544111773.html) enum, the value of this property is `true` (the relative date represents a range of dates). For all other relative dates (such as those that you create using [query.createRelativeDate(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544108154.html)), the value of this property is `false` (the relative date represents a specific moment in time). |
