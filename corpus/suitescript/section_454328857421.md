| **Method Description** | Adds the specified attribute node. If an attribute with the same local name and namespace URI is already present in the element, it is replaced by the new one. If an attribute with the same namespaceURI and localName property already exist, it is replaced with the object in the newAttr parameter. If the attribute node replaces an existing attribute node, the method returns the new xml.Attr object. Important: This method is not supported on Internet Explorer. |
| --- | --- |
| **Returns** | [xml.Attr](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345169036.html) |
| **Supported Script Types** | Client and server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/xml Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4344917661.html) |
| **Since** | 2015.2 |

## Parameters {#bridgehead_453599792480}

Note:

The options parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.newAttr` | [xml.Attr](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345169036.html) | required | New [xml.Attr](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345169036.html) object to add to the [xml.Element](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345167426.html) object. |

## Errors {#bridgehead_4349491851}

| Error Code | Message | Thrown If |
| --- | --- | --- |
| `SSS_XML_DOM_EXCEPTION` | INUSE\_ATTRIBUTE\_ERR: An attempt is made to add an attribute that is already in use elsewhere. | Attribute node cannot be added. |
