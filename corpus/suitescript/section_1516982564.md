Record actions make it convenient to update records that are currently being viewed. For more information, see [Overview of Record Action and Macro APIs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1509640242.html).

Record macro APIs are part of the [N/action Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510761537.html). For more information, see [N/action Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510761537.html).

The following table lists currently supported record actions. The table is organized by record type and includes the UI button labels. For details about a specific action, click its Action ID.

Note:

For information about working with record actions in REST web services, see [Executing Record Actions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156631158782.html).
