| **Property Description** | The namespace prefix of the node, or `null` if the node does not have a namespace. If the value is `null`, setting it has no effect, including read-only node types. |
| --- | --- |
| **Type** | string |
| **Module** | [N/xml Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4344917661.html) |
| **Since** | 2015.2 |

## Errors {#bridgehead_4383116899}

| Error Code | Message | Thrown If |
| --- | --- | --- |
| `SSS_XML_DOM_EXCEPTION` | NAMESPACE\_ERR: An attempt is made to create or change an object in a way which is incorrect with regard to namespaces. | Cannot edit the node prefix. |
