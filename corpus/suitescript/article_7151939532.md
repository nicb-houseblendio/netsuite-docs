SuiteScript 1.0 is a previous version of SuiteScript, the coding functionality used to extend and customize NetSuite. Even though our support and service teams remain able to troubleshoot solutions previously written in SuiteScript 1.0, this version is no longer updated.

To assist with receiving relevant search results in the help, the SuiteScript 1.0 documentation and API reference are no longer available as individual Help topics. Instead, SuiteScript 1.0 documentation is offered in two PDF guides:

-   [SuiteScript 1.0 PDF](https://system.netsuite.com/help/helpcenter/shared_resources/PDF/SuiteScript10.pdf)
    
-   [SuiteScript 1.0 API Reference PDF](https://system.netsuite.com/help/helpcenter/shared_resources/PDF/SuiteScript10API.pdf)
    

You must log in to your NetSuite account to view these PDF files.

Choose SuiteScript 2.1 for the most up to date, fully supported functionality. For more information about transitioning from SuiteScript 1.0 to SuiteScript 2.1, see [Transitioning from SuiteScript 1.0 to SuiteScript 2.x](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160098544034.html).
