| **Object Description** | Encapsulates a custom SuiteScript error. Use this object in a try-catch statement to abort script execution. Create a new custom error with the [error.create(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4243803203.html) method, which returns an `error.SuiteScriptError`. |
