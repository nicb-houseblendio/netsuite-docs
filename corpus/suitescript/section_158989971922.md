## Parameters {#subsect_158989972628}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.columns` | [dataset.Column](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158946808345.html)\[\] | optional | The fields (columns) in the dataset. |
| `options.condition` | [dataset.Condition](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158946951148.html) | optional | The condition (criteria to be applied to the dataset. A condition can have children which are combined using the appropriate operator (AND or OR) to produce the criteria used. |
| `options.description` | string | optional | The description of the dataset. |
| `options.id` | string | optional | The script ID of the dataset. |
| `options.name` | string | optional | The name of the dataset. |
| `options.type` | string | required | The internal ID for the record type on which to build the dataset. Use the [Records Catalog](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/book_159368199162.html) to find the Internal ID of scriptable records. |

## Errors {#subsect_158989973458}

| Error Code | Thrown If |
| --- | --- |
| `INVALID_SEARCH_TYPE` | The `options.type` parameter is invalid. |
