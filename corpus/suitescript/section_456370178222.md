| **Method Description** | Calculates the digest of the data to be hashed. |
| --- | --- |
| **Returns** | A hash value as a string. |
| **Supported Script Types** | Server scripts For additional information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/crypto Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4358549582.html) |
| **Since** | 2015.2 |

## Parameters {#bridgehead_454105773925}

Note:

The options parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.outputEncoding` | string | optional | The output encoding. Use the [encode.Encoding](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4369865177.html) enum to set the value. The default value is `encode.Encoding.HEX`. |
