The supply change order record supports the approve and reject actions.

For help working with this record in the UI, see [Change Orders](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159190685327.html).

For information about SuiteScript 2.x record actions, see the following help topics:

-   [Overview of Record Action and Macro APIs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1509640242.html)
    
-   [N/action Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510761537.html)
    

## approve {#subsect_159854730513}

| **Corresponding UI Button** | Approve all pending. |
| --- | --- |
| **Action Description** | Approve the Supply Change Order with the given recordId. |
| **Governance** | This action performs a simple edit, update, and save record. An approve action updates a tranline, which is a necessary step for the feature. |
| **Exception** | Exceptions are thrown when tranline fails to update a tranline fails. |
| **Since** | 2020.2 |

## reject {#subsect_159854737448}

| **Corresponding UI Button** | Reject all pending. Reject all pending and add a note. |
| --- | --- |
| **Action Description** | Reject the Supply Change Order with the given recordId. Optionally include a note that explains the reason for the rejection. |
| **Governance** | This action performs a simple edit, update, and save record. |
| **Exception** | Exceptions are thrown when tranline fails to update a tranline fails. |
| **Since** | 2020.2 |

## Parameters {#subsect_159854731028}

The recordId is the default input parameter for this action
