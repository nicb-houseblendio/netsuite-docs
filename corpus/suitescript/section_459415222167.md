| **Property Description** | Filters for the search as an array of [search.Filter](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345767603.html) objects. Value is `null` if the search has no defined filters. You set this value with an array or single search. Filter objects to overwrite any prior filters. Use `null` to set an empty array and remove any existing filters on this search. Use [search.createFilter(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345777107.html) to create a filter. Filter expressions are an alternative way to define filters of a search. The expressions are an array of JavaScript objects that are passed through this property. For more information about filter expressions, see the [Search.filterExpression](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_458440490721.html) property. |
