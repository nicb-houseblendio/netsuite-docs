## Parameters {#bridgehead_4378416898}

Note:

The options parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description | Since |
| --- | --- | --- | --- | --- |
| `options.id` | string | required | The internal ID of the field group. | 2015.2 |
