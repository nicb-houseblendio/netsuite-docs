## Parameters {#subsect_158289669785}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.code` | string | required | The code of the period to create. Use a value from the [query.PeriodCode](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158289876878.html) enum for this parameter. |
| `options.adjustment` | string | optional | The adjustment of the period to create. Use a value from the [query.PeriodAdjustment](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158289865548.html) enum for this parameter. The default value is `query.PeriodAdjustment.NOT_LAST`. |
| `options.type` | string | optional | The type of the period to create. Use a value from the [query.PeriodType](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158289949288.html) enum for this parameter. The default value is `query.PeriodType.START`. |

## Errors {#subsect_158289669251}

| Error Code | Thrown If |
| --- | --- |
| `INVALID_PERIOD_ADJUSTMENT` | The specified period adjustment is not a value from the [query.PeriodAdjustment](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158289865548.html) enum. |
| `INVALID_PERIOD_CODE` | The specified period code is not a value from the [query.PeriodCode](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158289876878.html) enum. |
| `INVALID_PERIOD_TYPE` | The specified period type is not a value from the [query.PeriodType](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158289949288.html) enum. |
| `WRONG_PARAMETER_TYPE` | Any of the parameters is not a string. |
