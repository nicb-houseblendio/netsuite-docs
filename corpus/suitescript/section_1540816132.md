| **Method Description** | Returns the current status of [action.executeBulk(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1540815927.html) for the specified task ID. The bulk execution status is returned in a status object. |

| **Since** | 2019.1 |

## Parameters {#bridgehead_1540816160}

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.taskId` | string | required | The task ID returned by a previous [action.executeBulk(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1540815927.html) call. |
