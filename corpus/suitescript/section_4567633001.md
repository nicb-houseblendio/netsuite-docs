| **Method Description** | Writes a file to the response. Textual files are re-encoded to UTF-8 by default. If you want to preserve the file's encoding, you must specify the same charset in the response's Content-Type header using [ServerResponse.setHeader(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4567652689.html) before calling this method. To see an example, refer to [Return a File with Alternative Character Encoding](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0808012948.html). |
| --- | --- |
| **Returns** | void |
| **Supported Script Types** | Server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/https Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4418229131.html) |
| **Since** | 2015.2 |

## Parameters {#bridgehead_4567632930}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description | Since |
| --- | --- | --- | --- | --- |
| `options.file` | [file.File](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4247974825.html) | required | A [file.File](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4247974825.html) Object that encapsulates the file to be written. | 2015.2 |
| `options.isInline` | boolean | optional | Determines whether the field is inline. If true, the file is inline. | 2015.2 |

## Errors {#bridgehead_4567632842}

| Error Code | Message | Thrown If |
| --- | --- | --- |
| `SSS_MISSING_REQD_ARGUMENT` | Missing a required argument: {param name} | The `options.file` parameter is not specified. |
| `WRONG_PARAMETER_TYPE` | {param name} | The value input for `options.file` is not a [file.File](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4247974825.html) Object. |
