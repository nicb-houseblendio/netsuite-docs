| **Object Description** | A pivot object which is a workbook component that enables you to pivot your dataset query results by defining measures and dimensions, so that you can analyze different subsets of data. Use [workbook.createPivot(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159051610759.html) to create this object. A pivot object is used as a parameter in the [workbook.create(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008744522.html) method. |
