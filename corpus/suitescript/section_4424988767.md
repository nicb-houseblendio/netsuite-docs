| **Method Description** | Sets the redirect to the URL of a Suitelet that is available externally (Suitelets set to Available Without Login on the Script Deployment page). |
| --- | --- |
| **Returns** | void |
| **Supported Script Types** | Suitelets User Event scripts - beforeLoad entry point and synchronous afterSubmit user events. This module does not support beforeSubmit or asynchronous afterSubmit user events. This module is only supported when triggered from the UI. Backend contexts such as CSV Import and Scheduled Scripts are not supported. For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/redirect Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4424286105.html) |
| **Since** | 2015.2 |

## Parameters {#bridgehead_4424988767}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.url` | string | required | The URL of a Suitelet that is available externally. Note: For an external URL, Available without Login must be enabled on the Script Deployment page for the Suitelet. |
| `options.parameters` | Object | optional | Contains additional URL parameters as key-value pairs. Note: Parameters cannot be arrays. Use JSON.stringify/JSON.parse instead to handle arrays. |
