| **Description** | Executes when the `summarize` entry point is triggered. When you add custom logic to this entry point function, that logic is applied to the result set. For information about the context object provided to this entry point, see [summaryContext](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4472725629.html). |
| --- | --- |
| **Returns** | Void |
| **Since** | 2015.2 |

## Parameters {#bridgehead_4472688344}

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| [summaryContext](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4472725629.html) | Object | Required | Holds statistics regarding the execution of a map/reduce script. For a description of each property in this object, see [summaryContext Object Members](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4685231336.html#subsect_1513900334). |
