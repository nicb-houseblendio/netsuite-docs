Use the N/config module to access NetSuite configuration settings. The [config.load(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4256772439.html) method returns a [record.Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4205869719.html) object. Use the [record.Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4205869719.html) object members to access configuration settings. You do not need to load the N/record module to do this.

See [config.Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4256772632.html) for a list of supported configuration objects.
