## Parameters {#subsect_159051034179}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.constant` | string | number | boolean | Date | required | The ID of the function to use. |
| `options.type` | [workbook.ConstantType](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159059175435.html) | optional | The type of constant. |
