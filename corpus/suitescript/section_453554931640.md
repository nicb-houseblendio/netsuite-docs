| **Property Description** | Part of the XML declaration, the XML encoding of the XML document. In the following declaration, the xmlEncoding property is UTF-8: `<?xml version="1.0" encoding="UTF-8" standalone="yes"?>` Important: This property is not supported on Internet Explorer or Firefox. |
| --- | --- |
| **Type** | string (read-only) |
