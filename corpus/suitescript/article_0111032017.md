The following sample shows how to filter the Digital Certificates list by subsidiary and by file type.

Note:

This sample script uses the `require` function so that you can copy it into the SuiteScript Debugger and test it. You must use the `define` function in an entry point script (the script you attach to a script record and depoly). For more information, see [SuiteScript 2.1 Script Basics](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1504638761.html) and [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html).

          `/**  * @NApiVersion 2.1    */ require(['N/certificateControl'],       function(certificateControl){          var all = certificateControl.findCertificates();          var specificType = certificateControl.findCertificates({               type: 'PFX'          });          var specificSub = certificateControl.findCertificates({               subsidiary: 93          });          var specificTypeAndSub = certificateControl.findCertificates({                type: 'PFX',                subsidiary: 93          });       });;`
