| **Object Description** | An asynchronous document capture task. Use the methods and properties for this object to submit a document capture task to the NetSuite task queue and execute it asynchronously. You can create a `task.DocumentCaptureTask` object using [task.create(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4392320106.html). You can populate the properties of this object as you create it. With a `task.DocumentCaptureTask` object, you can do the following:
-   Specify the following information about the document capture task:
    -   The document to extract content from using the [DocumentCaptureTask.inputFile](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_75075322173.html) property. This property accepts a [file.File](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4247974825.html) object that represents a supported document in the NetSuite File Cabinet.
    -   The document type using the [DocumentCaptureTask.documentType](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_25082104010.html) property. Use a value from the [documentCapture.DocumentType](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0704103314.html) enum to set the value of this property.
    -   The feature content to extract from the document (such as fields, tables, or text) using the [DocumentCaptureTask.features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_23082157954.html) property. Use values from the [documentCapture.Feature](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0704103522.html) to set the value of this property. If you don't specify any features, the `TEXT_EXTRACTION` and `TABLE_EXTRACTION` features are used by default.
    -   The language of the document using the [DocumentCaptureTask.language](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_25082336704.html) property. Use a value from the [documentCapture.Language](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0828075605.html) enum to set the value of this property. If you don't specify a language, English is used by default.

-   Set the file path of a JSON file in the NetSuite File Cabinet using the [DocumentCaptureTask.outputFilePath](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_4082548662.html) property. Document capture results are exported to this file.
-   Add dependent tasks to the document capture task using [DocumentCaptureTask.addInboundDependency(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_3075210437.html). Dependent tasks are processed automatically when the document capture task is complete.
-   Submit the document capture task to the task queue using [DocumentCaptureTask.submit()](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_11075253797.html).
-   Get the status of a document capture task using the properties of an associated [task.DocumentCaptureTaskStatus](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_84075519375.html) object. The [task.checkStatus(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345805891.html) method returns a [task.DocumentCaptureTaskStatus](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_84075519375.html) object when you specify a task ID that represents a document capture task.

For an example of submitting an asynchronous document capture task, see [Extract Content from a Document Asynchronously](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_0721114921.html). |
