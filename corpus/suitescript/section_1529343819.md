The billing rate card record type currently supports the modifyPricebyPercent macro.

For help working with this record in the UI, see [Using Billing Rate Cards](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4689764278.html).

For information about SuiteScript 2.x record macros, see the following help topics:

-   [Overview of Record Action and Macro APIs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1509640242.html)
    
-   [N/record Module Members](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4267255811.html#bridgehead_4273190312)
    
-   [Macro Object Members](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4267255811.html#bridgehead_1529088663)
    

## modifyPriceByPercent {#subsect_1516986592}

| **Corresponding UI Button** | Recalculate |
| --- | --- |
| **Macro Description** | Modifies the price list on the record by a specified percentage. |
| **Returns** | {notifications:\[\], response:{}} |
| **Supported Script Types** | Client and server scripts For additional information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Since** | 2018.1 |

### Parameters {#subsect_1518025922}

See [Record.executeMacro(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1509992174.html) for details about parameters required for the of any macro. The modifyPriceByPercent macro also requires the following additional parameter.

| Parameter | Type | Required / Optional | Description | Since |
| --- | --- | --- | --- | --- |
| percent | number | required | The percentage amount by which the price list is modified. May be positive or negative. | 2018.1 |

## Billing Rate Card modifyPriceByPercent Macro Syntax {#subsect_1516996661}

The following code sample is from a Suitelet that increases the prices on a billing rate card with id 1 by 10%.

            `/**  * @NApiVersion 2.x  * @NScriptName Script Parameter Test  * @NScriptType suitelet  */ define(['N/record'], function(record) {     return Object.freeze({         onRequest : function(context) {             var rec = record.load({                 type: 'billingratecard',                 id: 1,                 isDynamic: true             });             rec.executeMacro({                 id: 'modifyPriceByPercent',                 params: { percent: 10 }             });             rec.save();         }     }); });`
