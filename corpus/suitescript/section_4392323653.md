| **Object Description** | Represents an entire XML document. The XML DOM presents a document as a hierarchy of node objects. Use the methods and properties available to the xml.Document object to manipulate the XML document and the nodes in the document tree. An XML document object is also a node of type DOCUMENT\_NODE. In addition to the Document object members, Document objects inherit the members of the Node object. For a complete list of these methods and properties, see [Node Object Members](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4344917661.html#bridgehead_4344920428). |
