| **Property Description** | Whether query results with null values are listed at the end of the query results. This property is set during the of [Query.createSort(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510780402.html) and [Component.createSort(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510785047.html). The default value of this property is the value of the [Sort.ascending](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530897548.html) property. For example, if the [Sort.ascending](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530897548.html) property is set to `true`, the `Sort.nullsLast` property is also set to `true`. |
