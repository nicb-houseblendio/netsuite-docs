Important:

You must include a [query.Column](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510779196.html) object in your query definition to avoid scripting errors. This object is an optional parameter with the [query.create(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510275581.html) method, but at least one Column must be created for every query definition. For more information, see the syntax example below.

| **Object Description** | A query result column. The `query.Column` object is the equivalent of the [search.Column](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345767216.html) object in the [N/search Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345764122.html). The `query.Column` object describes the field types (columns) that are displayed from the query results. To create columns:
-   Use [Query.createColumn(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510780373.html) to create a column on the initial query definition created with [query.create(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510275581.html).
-   Use [Component.createColumn(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510784945.html) to create a column on a join relationship created with [Query.autoJoin(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530819144.html) or [Component.autoJoin(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530818573.html).
-   Assign all created columns as values to [Query.columns](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510781812.html). For an example, see [Syntax](#subsect_1510779362).

## Syntax {#subsect_1510779362}

Important:

The following code sample shows the syntax for this member. It is not a functional example. For a complete script example, see [N/query Module Script Samples](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0304035624.html).

            `// Add additional code ...     var myCustomerQuery = query.create({         type: query.Type.CUSTOMER     });     var mySalesRepJoin = myCustomerQuery.autoJoin({         fieldId: 'salesrep'     });     myCustomerQuery.columns = [         myCustomerQuery.createColumn({             fieldId: 'entityid'         }),         myCustomerQuery.createColumn({             fieldId: 'id'         }),         mySalesRepJoin.createColumn({             fieldId: 'entityid'         }),         mySalesRepJoin.createColumn({             fieldId: 'email'         }),         mySalesRepJoin.createColumn({             fieldId: 'hiredate'         }),     ];     myCustomerQuery.sort = [         myCustomerQuery.createSort({             column: myCustomerQuery.columns[1]         }),         mySalesRepJoin.createSort({             column: mySalesRepJoin.columns[0], ascending: false         })     ];     var resultSet = myCustomerQuery.run(); ... // Add additional code`
