## Parameters {#subsect_159051228595}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.expression` | [workbook.Expression](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008229845.html) | required | The expression for the data dimension item. |
| `options.label` | string | optional | The label for the data dimension item. |
