Note:

The content in this help topic pertains to SuiteScript 2.1.

| **Object Description** | Stores multiple cryptographic keys and metadata. You can use this object in the [Message.decrypt(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0923092155.html) and [MessageData.encrypt(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0923093832.html) methods. Note: You cannot create a new key with the N/pgp Module. You must generate keys from an external third party source that supports key generation. For more information, see [Limitations of N/pgp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_5095832176.html#subsect_0605040117). |
