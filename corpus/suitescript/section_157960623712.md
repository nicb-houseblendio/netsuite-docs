SuiteQL is a query language based on the SQL-92 revision of the SQL database query language. It provides advanced query capabilities you can use to access your NetSuite records and data. For more information about SuiteQL, including limitations, exceptions, and more usage examples, see [SuiteQL](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156257770590.html).

In SuiteScript, you can create and run SuiteQL queries using the N/query module. Queries created using SuiteQL can be more powerful and flexible than queries created using other APIs in the N/query module. SuiteQL queries can also provide the best query performance for many use cases. You can create your own SuiteQL query strings, which lets you create and run complex SQL queries that cannot be created otherwise. For examples of SuiteQL queries you can create, see [Examples of Using SuiteQL in the N/query Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158039627694.html).

Important:

To create your own SuiteQL query strings, you must know the names of the record types and fields you want to use. For more information about finding record type and field names, see [Finding Record Type and Field Names](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156475462055.html).

Using the N/query module, you can run SuiteQL queries in the following ways:

-   Convert an existing query (as a [query.Query](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510275177.html) object) to its SuiteQL representation (as a [query.SuiteQL](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157960384819.html) object) and run the query. To learn more, see [Converting an Existing Query to SuiteQL](#subsect_158038956754).
    
-   Run an arbitrary SuiteQL query as a paged or non-paged query. To learn more, see [Running an Arbitrary SuiteQL Query](#subsect_158038957562).
    

## Converting an Existing Query to SuiteQL {#subsect_158038956754}

If you already have a [query.Query](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510275177.html) object in your script (one that you created using [query.create(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510275581.html) or loaded using [query.load(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510349101.html)), you can convert the query to its SuiteQL representation. The [Query.toSuiteQL()](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157960522744.html) method converts a [query.Query](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510275177.html) object to a [query.SuiteQL](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157960384819.html) object. The resulting [query.SuiteQL](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157960384819.html) object represents the same query as the original [query.Query](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510275177.html) object and, when run, returns the same query results.

Important:

The resulting SuiteQL query string (contained in the [SuiteQL.query](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157960443690.html) property) does not include any aliases you set on query result columns in the original [query.Query](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510275177.html) object. For more information about aliases, see [Column.alias](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156336566313.html).

A [query.SuiteQL](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157960384819.html) object includes the following properties:

-   [SuiteQL.columns](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157960405619.html) - The result columns to be returned from the query. This property is an array of [query.Column](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510779196.html) objects. The value of this property is the same as the value of the [Query.columns](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510781812.html) property in the original [query.Query](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510275177.html) object.
    
-   [SuiteQL.params](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157960427733.html) - The parameters for the query. In SuiteQL, query conditions are represented using the `WHERE` clause and a set of parameters.
    
-   [SuiteQL.query](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157960443690.html) - The string representation of the SuiteQL query. This string can contain SQL clauses, record or table names, field names, operators, and more.
    
-   [SuiteQL.type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157960456167.html) - The type of the query. This property uses values from the [query.Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510878994.html) enum. The value of this property is the same as the value of the [Query.type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510275511.html) property in the original [query.Query](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510275177.html) object.
    

To run the SuiteQL query, use one of the following methods:

-   Use [SuiteQL.run()](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157960470046.html) to run the query as a non-paged query. This method returns the results as a [query.ResultSet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510779235.html) object.
    
-   Use [SuiteQL.runPaged(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157960491275.html) to run the query as a paged query. This method returns the results as a [query.PagedData](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510779273.html) object. The default page size is 50 results per page. The minimum page size is 5 results per page, and the maximum page size is 1000 results per page.
    

The following example shows you how to create a query as a [query.Query](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510275177.html) object, convert the query to SuiteQL, and run the resulting SuiteQL query as a non-paged query:

            `var myCustomerQuery = query.create({     type: query.Type.CUSTOMER });  myCustomerQuery.columns = [     myCustomerQuery.createColumn({         fieldId: 'entityid'     }),     myCustomerQuery.createColumn({         fieldId: 'email'     }) ];  myCustomerQuery.condition = myCustomerQuery.createCondition({     fieldId: 'isperson',     operator: query.Operator.IS,     values: [true] });  var mySQLCustomerQuery = myCustomerQuery.toSuiteQL();  var results = mySQLCustomerQuery.run();` 
          

In the preceding example, the `mySQLCustomerQuery` variable contains the resulting [query.SuiteQL](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157960384819.html) object after the conversion. In this object, the [SuiteQL.query](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157960443690.html) property contains the string representation of the original query. In this example, this property contains the following string:

            `SELECT customer.entityid AS entityidRAW /*{entityid#RAW}*/, customer.email AS emailRAW /*{email#RAW}*/ FROM customer WHERE customer.isperson = ?` 
          

The [SuiteQL.params](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157960427733.html) property contains the parameter value `true`. When the SuiteQL query runs, the question mark (`?`) in the query string is replaced with the parameter value (`true`).

## Running an Arbitrary SuiteQL Query {#subsect_158038957562}

You can create your own SuiteQL queries and run them. The [query.runSuiteQL(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157960542026.html) method lets you run an arbitrary SuiteQL query, and it returns query results as a [query.ResultSet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510779235.html) object. The [query.runSuiteQLPaged(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157960586441.html) method lets you run a SuiteQL query as a paged query, and it returns query results as a [query.PagedData](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510779273.html) object.

To specify the SuiteQL query to run, you can provide one of the following to [query.runSuiteQL(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157960542026.html) or [query.runSuiteQLPaged(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157960586441.html):

-   A string representation of the SuiteQL query
    
                    `var results = query.runSuiteQL({     query: 'SELECT customer.entityid, customer.email FROM customer' });` 
                  
    
-   A [query.SuiteQL](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157960384819.html) object
    
                    `// In this example, mySuiteQLCustomerQuery is an existing SuiteQL object var results = query.runSuiteQL(mySuiteQLCustomerQuery);` 
                  
    
-   A JavaScript Object that contains a `query` property and, optionally, a `params` property:
    
                    `var results = query.runSuiteQL({     query: 'SELECT customer.entityid, customer.email FROM customer WHERE customer.isperson = ?',     params: [true] });`
