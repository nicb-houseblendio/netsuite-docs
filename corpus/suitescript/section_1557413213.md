Use the N/keyControl module to use SSH keys and access key storage. You can also access keys in the UI at _Setup > Company > Preferences > Keys_.

By using the SSH keys, you can manage files and directories by using the SSH file transfer (SFTP) protocol. For more information, see [SSH Keys for SFTP](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1558548485.html). For more information about SFTP, see [N/sftp Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4617004932.html).

**[N/keyControl Module Script Samples](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0303041314.html)**
