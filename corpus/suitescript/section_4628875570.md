RESTlets can be a bit trickier than other script types. Other script types run when needed after deployment. With RESTlets, you deploy them but have to call them for them to run. To call a RESTlet, make sure you do these three things:

-   Correctly identify the RESTlet domain for your NetSuite account
    
-   Use an HTTP method that matches an entry point in your script
    
-   Use two required headers: Content-Type and Authorization.
    
    For details on the required headers, see [Creating a Content-Type Header](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4619215993.html) and [RESTlet Authentication](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1529417663.html).
    

The following example RESTlet is a simple implementation of the standard Hello World example implemented using the RESTlet get entry point.

## RESTlet {#bridgehead_4636494192}

            `/**  * @NApiVersion 2.x  * @NScriptType Restlet */ define([], function() {  return {   get : function() {    return "Hello World!"   }  } });` 
          

## Example Get Call and Response {#bridgehead_4636494555}

You call this RESTlet with the http get method. Since it doesn't take any arguments, you don't need to add anything else to the URL.For testing, use the value in the External URL field of the deployment record. But for integrations, make sure you dynamically find the RESTlet domain. See [Dynamically Generating a Full URL](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4618456734.html#bridgehead_4625420336)).

For example, you could call this RESTlet by using a URL like the following - one that does not include embedded parameters:

            `https://<accountID>.restlets.api.netsuite.com/app/site/hosting/restlet.nl?script=482&deploy=1` 
          

After you add the two required headers, your call will look like this:

            `GET /app/site/hosting/restlet.nl?script=482&deploy=1 HTTP/1.1   HOST: <accountID>.restlets.api.netsuite.com  authorization: NLAuth nlauth_account=12345, nlauth_email=john@smith.com, nlauth_signature=Welcome123   content-type: application/json   cookie: ...` 
          

The RESTlet returns this response:

            `Hello World!` 
          

For help troubleshooting RESTlet errors, see [SuiteScript 2.1 RESTlet Error Handling](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4634920277.html) and [Entry Point Script Validation Error Reference](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4503568059.html).
