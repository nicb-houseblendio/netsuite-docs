Important:

You must specify a sorting order in the search definition when using this method to avoid duplicate or missing results. The query definition must provide a unique and unambiguous sorting order with a specified precedence.

| **Method Description** | Runs the current search asynchronously and returns a [search.PagedData](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4486558900.html) Object. Note: The parameters and errors thrown for this method are the same as those for [Search.runPaged(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4486596158.html). For more information about promises, see [Promise Object](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4387812940.html). |
