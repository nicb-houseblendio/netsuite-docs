## Parameters {#bridgehead_4407956625}

Note:

The `params` parameter is a JavaScript object. NetSuite automatically passes it to your script entry point. The values for `params` are read-only.

| Parameter | Type | Description | Since |
| --- | --- | --- | --- |
| `params.portlet` | [Portlet Object](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4671201924.html) | The Portlet object used for rendering. The availability of Portlet members depends on the type of Portlet that is passed in. For more information, see the following:
-   [Simple Form Portlet Object Members](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4671201924.html#bridgehead_4671206091)
-   [Inline HTML Portlet Object Members](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4671201924.html#bridgehead_4671212993)
-   [Links and Indents Portlet Object Members](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4671201924.html#bridgehead_4671214225)
-   [Simple List Portlet Object Members](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4671201924.html#bridgehead_4671218629)

 | Version 2015 Release 2 |
| `params.column` | string (read-only) | The column index for the portlet on the dashboard. The index is a string representation of one of the following numeric values:

1.  left column
2.  center column
3.  right column

 | Version 2015 Release 2 |
| `params.entity` | string (read-only) | The customer ID for the selected customer. | Version 2015 Release 2 |
