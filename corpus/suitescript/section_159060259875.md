## Errors {#subsect_159060260269}

| Error Code | Thrown If |
| --- | --- |
| `INVALID_TOTAL_LINE` | The value for this property is invalid. Set this parameter using values from the [workbook.TotalLine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159059291106.html) enum. |
