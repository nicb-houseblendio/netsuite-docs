| **Object Description** | An extracted field from a document. When extracted from a document, a field is represented by a key-value pair. The key is the name or label of the field (as a [documentCapture.FieldLabel](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0704095038.html) object), and the value is the field's value (as a [documentCapture.FieldValue](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0704095437.html) object). This object includes properties for the field label ([Field.label](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0703031534.html)), type ([Field.type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0704094825.html)), and value ([Field.value](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0704094949.html)). Fields are included in extracted content only when the `documentCapture.Feature.FIELD_EXTRACTION` feature is specified when you call [documentCapture.documentToStructure(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0704102801.html) (or when you submit an asynchronous extraction task then parse the result using [documentCapture.parseResult(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0704103210.html)). |
