| **Object Description** | A plain object that defines the input data. For example, a SuiteQL query. You can return such object from [getInputData(inputContext)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4412447940.html). |

## Syntax {#bridgehead_4477103059}

The following code snippet shows the syntax for this member. It's not a functional example. For a complete script example, see [SuiteScript 2.1 Map/Reduce Script Code Samples](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0901033444.html).
