This help topic gives you example conversions from SuiteScript 1.0 to SuiteScript 2.0 or 2.1 scripts. Each example shows the SuiteScript 1.0 script on the left and the SuiteScript 2.0/2.1 script on the right.

Conversions for the following scripts are included:

-   Bundle installation script one: [Confirm bundle installation, enable features, create account](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160167170508.html)
    
-   Client script one: [Set default fields values on a record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160167167363.html)
    
-   Client script two: [Disable fields on a record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160167163186.html)
    
-   Client script three: [Display user profile information](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160167158951.html)
    
-   Mass update script one: [Update fields on sales order and estimate records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160167155341.html)
    
-   Portlet script one: [Build a simple portlet that posts data to a servlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160167147939.html)
    
-   RESTlet script one: [Using RESTlet get, post, put, and delete entry points and methods](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160167140410.html)
    
-   Scheduled script one: [Fulfill and bill sales orders each day](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160167136106.html)
    
-   Suitelet script one: [Create a simple form](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160167127375.html)
    
-   User event script one: [Implement end of month sales order promotions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160167121863.html)
    
-   Workflow action script one: [Set the sales rep on the record in a workflow](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160167118290.html)
    
-   Custom module script one: [Create an item receipt from a purchase order](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160167112338.html)
    
-   Custom module script two: [Create and run a joined search](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160167106851.html)
    
-   Custom module script three: [Create CSV imports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160167101517.html)
