| **Enum Description** | Holds the string values for query types used in the query definition. This enum is used to pass the initial query type argument to [query.create(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510275581.html). Important: The N/query module supports the same record types that are supported by the SuiteAnalytics Workbook interface. For more information, see [Available Record Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1543418356.html). |

## Values {#subsect_1510878994}

Note:

Before using these values, consider the following:

-   A query type is not the same as a record type. The supported query types listed below do not necessarily correspond with the supported record types listed in the [N/record Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4267255811.html).
    
-   Depending on your account, role, and enabled features, some of these values may not be available.
    
-   Custom record types are not included in this enum.
    
-   You must configure your account settings according to the query type used in your scripts to avoid potential errors.
