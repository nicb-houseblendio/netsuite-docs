| **Method Description** | This method retrieves the data within the specified page range. This method also includes a promise version, [PagedData.fetch.promise()](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4491674556.html). For more information about promises, see [Promise Object](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4387812940.html). |
| --- | --- |
| **Returns** | [search.Page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4486547978.html) |
| **Supported Script Types** | Client and server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | 5 units |
| **Module** | [N/search Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345764122.html) |
| **Since** | 2016.1 |

## Parameters {#bridgehead_4491678090}

Note:

The options parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `pageRange.index` | number | required | The index of the page range that bounds the desired data. Page range indexes start at 0. |

## Errors {#bridgehead_4492596185}

| Error Code | Message | Thrown If |
| --- | --- | --- |
| `INVALID_PAGE_RANGE` | Invalid page range. | The page range is not valid. |
