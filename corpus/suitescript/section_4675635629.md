You might need to retrieve data from a subrecord in a body field.

To retrieve a subrecord, your script can use either the [N/record Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4267255811.html) or the [N/currentRecord Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4625600928.html). You can use either dynamic or standard mode.

To learn about SuiteScript scripting modes, see [SuiteScript 2.x Standard and Dynamic Modes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1524156901.html)

#### To use SuiteScript 2.x to retrieve a body field subrecord:

1.  Load the record.
    
2.  Get the subrecord using the getSubrecord() method. This method requires one argument: A fieldId, which identifies the field on the sublist that contains the subrecord. In the Records Browser, the field that holds the subrecord is always identified as a field of type summary.
    
    For example, you could use an expression like the following to load an address subrecord stored in the body field of a location record:
    
                    `... var subrec = call.getSubrecord({      fieldId: 'mainaddress' }); ...` 
                  
    
3.  To retrieve a value from the subrecord's body, use the getValue() method. For example, you could use an expression like the following to retrieve a detail from the body of an address subrecord:
    
                    `... var cityValue = subrec.getValue({     fieldId: 'city' }); ...` 
                  
    
4.  To retrieve a value from the subrecord's sublist, use the getSublistValue() method. For example, you could use an expression like the following to retrieve a detail from the sublist of an inventory detail subrecord:
    
                    `... var cityValue = subrec.getValue({     sublistId: 'inventoryassignment',     fieldId: 'receiptinventorynumber',     line: 4, }); ...`
