| **Method Description** | Runs the pivot and returns an array of pivot intersections. |
| --- | --- |
| **Returns** | [workbook.PivotIntersection](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163170659013.html)\[\] |
| **Supported Script Types** | Server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | 10 units for each intersection returned |
| **Module** | [N/workbook Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_159006350818.html) |
| **Parent Object** | [workbook.Workbook](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008620913.html) |
| **Sibling Object Members** | [Workbook Object Members](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_159006350818.html#subsect_159007391335) |
| **Since** | 2021.2 |

## Parameters {#subsect_159068645257}

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.id` | string | required | The ID of the pivot. |

## Errors {#subsect_159068676660}

| Error Code | Thrown If |
| --- | --- |
| `PIVOT_DOES_NOT_EXIST` | The pivot specified by the `options.id` parameter is not included in the workbook. |
