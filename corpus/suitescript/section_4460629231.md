| **Description** | Defines the function that's executed before a bundle is uninstalled from a target account. Calls to scheduled scripts aren't supported. |
| --- | --- |
| **Returns** | void |
| **Since** | 2016.1 |

## beforeUninstall(params) Parameters {#bridgehead_4460629231}

Note:

The `params` parameter is a JavaScript object. It's automatically passed to the script entry point by NetSuite.

| Parameter | Type | Description | Since |
| --- | --- | --- | --- |
| `params.version` | string | The version of the bundle that's being uninstalled from the target account. | 2016.1 |
