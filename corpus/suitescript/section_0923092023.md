Note:

The content in this help topic pertains to SuiteScript 2.1.

| **Method Description** | Converts a [pgp.Message](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0923090947.html) object to message data without any processing. This method only works if the message is not encrypted. |
| --- | --- |
| **Returns** | [pgp.MessageData](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0923092625.html) |
| **Supported Script Types** | Server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/pgp Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_5095832176.html) |
| **Parent Object** | [pgp.Message](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0923090947.html) |
| **Sibling Module Members** | [Message Object Members](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_5095832176.html#subsect_14122340914) |
| **Since** | 2022.2 |

## Errors {#subsect_41154322792}

| Error Code | Thrown If |
| --- | --- |
| `PGP_EXPECTED_UNENCRYPTED_MESSAGE` | The message is encrypted. |
