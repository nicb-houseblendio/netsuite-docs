To help you understand how SuiteScript 2.1 works, this tutorial walks you through how to set up a basic customization. After you finish the steps in this tutorial, you'll see a 'Hello, World!' message whenever you load a NetSuite task record.

For background information used in this tutorial, see [SuiteScript 2.1 Development Concepts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_1501543623.html).

To complete the tutorial, see [Completing the Hello World Tutorial](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_78144816796.html).

After completing the tutorial, see [Next Steps with SuiteScript 2.1](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_1502139850.html) for related examples and follow-up topics.
