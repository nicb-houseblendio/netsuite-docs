| **Method Description** | Returns the total number of records or rows not yet processed by the map stage of a [task.MapReduceScriptTask](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345798404.html). Use the [MapReduceScriptTaskStatus.stage](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_460753112791.html) property to get the current stage. For general information about map/reduce stages, see [Map/Reduce Key Concepts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0901045042.html) and [Map/Reduce Script Stages](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4387802529.html). |
| --- | --- |
| **Returns** | number |
| **Supported Script Types** | Server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
