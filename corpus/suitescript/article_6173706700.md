This SuiteScript Code Samples Catalog contains code samples that you can use for reference. You can copy and update them to fit your needs.

Samples can also be found on the netsuite-suitecloud-samples github repository at: [netsuite-suitecloud-samples](https://github.com/oracle-samples/netsuite-suitecloud-samples).

This catalog includes the following sample categories. Note that each sample may be included in multiple categories.

-   [SuiteScript 2.1 Samples](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_69170511559.html) - This section includes samples that use SuiteScript 2.1 code constructs.
    
-   [SuiteScript Samples by Script Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_14143320003.html) - This section includes samples specific to each SuiteScript script type.
    
-   [SuiteScript Samples by Function](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_67132715094.html) - This section includes samples that cover distinct SuiteScript functions and capabilities.
    
-   [SuiteScript Samples by Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1551381633.html) - This section includes samples for each SuiteScript API module. For more information about SuiteScript modules, see [SuiteScript 2.1 Modules](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4220488571.html)
    
-   [SuiteScript Samples That Use Promises](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_17173508509.html) - This section includes samples that use SuiteScript promise methods.
    
-   [Custom Plug-in Samples](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_159552695257.html) - This section includes custom plug-in samples. For each plug-in code sample, you can read an associated help topic that describes the full context of the sample and includes additional implementation details. For more information, see [Custom Plug-in Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_3976781171.html).
    
-   [SuiteScript Use Cases Samples](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_156097263055.html) - This section includes full use case samples. These codes samples are a small portion of the full SuiteScript tutorials that describe how to perform functions in a step-by-step approach. For more information, see [SuiteCloud Customization Tutorials](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_159163143019.html).
    

You can also find a complete alphabetized listing of all samples in the SuiteScript Samples Catalog here: [SuiteScript Samples Catalog Complete Listing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_4163241476.html).
