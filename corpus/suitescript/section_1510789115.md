| **Property Description** | An aggregate function that is performed on the query result column. An aggregate function performs a calculation on the column values and returns a single value. This property is set when [Query.createColumn(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510780373.html) or [Component.createColumn(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510784945.html) is executed. For a list of supported aggregate functions, see the [query.Aggregate](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510878932.html) enum. |
