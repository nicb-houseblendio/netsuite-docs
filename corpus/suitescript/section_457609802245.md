| **Method Description** | Imports a node from another document to this document. This method creates a new copy of the source node. If the `deep` parameter is set to `true`, it imports all children of the specified node. If set to `false`, it imports only the node itself. Method returns the imported [xml.Node](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4346057759.html) object. |
| --- | --- |
| **Returns** | [xml.Node](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4346057759.html) |
| **Supported Script Types** | Client and server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/xml Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4344917661.html) |
| **Since** | 2015.2 |

## Parameters {#bridgehead_457096496581}

Note:

The options parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.importedNode` | [xml.Node](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4346057759.html) | required | Node from another XML document to import. |
| `options.deep` | boolean | required | Use `true` to import the node, its attributes, and all descendents. Use `false` to only import the node and its attributes. Important: This parameter is not supported on Internet Explorer. |

## Errors {#bridgehead_455252014159}

| Error Code | Message | Thrown If |
| --- | --- | --- |
| `SSS_XML_DOM_EXCEPTION` | NOT\_SUPPORTED\_ERR: The implementation does not support the requested type of object or operation. | Node cannot be imported. |
