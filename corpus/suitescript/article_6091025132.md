| **Method Description** | Asynchronously extracts text content from a PDF file. This method returns the text of the specified PDF file located in the NetSuite File Cabinet. If you want to extract other content from a file, such as tables and fields (key-value pairs), or extract content from a JPG, PNG, or TIFF file, use [documentCapture.documentToStructure(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0704102801.html) instead. Encrypted files are not supported. You can use the text returned from this method in calls to N/llm methods for further querying. For example, you can provide the returned text to [llm.generateText(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1014032554.html) and ask questions about the data, as the following code sample shows: `// "14" is the unique ID of a PDF stored in the NetSuite File Cabinet const fileObj = file.load({ id: "14" }); documentCapture.documentToText.promise({ file: fileObj }).then(function(result) { const response = llm.generateText({ prompt: "What is this invoice for?", documents: [{ id: '14', data: result }] }) });` Note: The parameters and errors thrown for this method are the same as those for [documentCapture.documentToText(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0704103115.html). For more information about promises, see [Promise Object](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4387812940.html). |
