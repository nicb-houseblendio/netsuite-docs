| **Enum Description** | Enumeration that holds the string values for supported character encoding. Use this enum to set the value of the [File.encoding](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4229270853.html) property. Note: JavaScript does not include an enumeration type. The SuiteScript 2.0 documentation utilizes the term enumeration (or enum) to describe the following: a plain JavaScript object with a flat, map-like structure. Within this object, each key points to a read-only string value. |

## Values {#bridgehead_4229093362}

| Value | Character Set |
| --- | --- |
| `UTF_8` | Unicode |
| `WINDOWS_1252` | Western |
| `ISO_8859_1` | Western |
| `GB18030` | Chinese Simplified |
| `SHIFT_JIS` | Japanese |
| `MAC_ROMAN` | Western |
| `GB2312` | Chinese Simplified |
| `BIG5` | Chinese Traditional |
