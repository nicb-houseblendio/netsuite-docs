| **Property Description** | A formula used to create the query result column. This property is set during the of [Query.createColumn(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510780373.html) or [Component.createColumn(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510784945.html). This property and the [Column.fieldId](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510788976.html) property cannot be set at the same time. For more information about formulas, see [Formulas in Searches](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_5143710889.html) and [SQL Expressions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2833020.html). |
