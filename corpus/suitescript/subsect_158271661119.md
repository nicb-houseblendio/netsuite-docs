You can use destructuring to bind variables to different properties of an Object:

          `const name = 'data.csv'; const isOnline = true; const fileType = file.Type.CSV; const contents = "Alpha,Bravo,Charlie,Delta";  // Create a file using destructured properties const dataFile = file.create({name, fileType, isOnline, contents});`
