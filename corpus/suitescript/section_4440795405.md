| **Method Description** | Performs a search asynchronously for one or more body fields on a record. Returns select fields as an object with value and text properties. Returns multiselect fields as an object with value:text pairs. Note: The parameters and errors thrown for this method are the same as those for [search.lookupFields(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345776651.html). For more information about promises, see [Promise Object](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4387812940.html). |
