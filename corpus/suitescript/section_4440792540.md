| **Method Description** | Loads an existing saved search asynchronously and returns it as a [search.Search](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4392315904.html) object. The saved search could have been created using the UI or created with [search.create(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345171487.html) and [Search.save()](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_452655578613.html). Note: The parameters and errors thrown for this method are the same as those for [search.load(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345775360.html). For more information about promises, see [Promise Object](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4387812940.html). |
