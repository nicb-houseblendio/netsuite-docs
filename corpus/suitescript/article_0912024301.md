This sample creates a portlet that displays simple HTML.

          `/**  * @NApiVersion 2.1  * @NScriptType Portlet  */  define([], function() {      function render(params) {          params.portlet.title = 'My Portlet';          var content = '<td><span><b>Hello!!!</b></span></td>';          params.portlet.html = content;      }           return {          render: render      }; });`
