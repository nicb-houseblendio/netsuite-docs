| **Method Description** | Returns the user-defined session object value associated with a session object key. Both the session object value and associated key are defined using [Session.set(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4296667139.html) (supported in server scripts only). If the key does not exist, this method returns null. |
| --- | --- |
| **Returns** | string | null |
| **Supported Script Types** | Client and server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/runtime Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4296359529.html) |
| **Since** | 2015.2 |

## Parameters {#bridgehead_4439979879}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description | Since |
| --- | --- | --- | --- | --- |
| `options.name` | string | required | Key used to store the session object. | 2015.2 |

## Errors {#bridgehead_159458194375}

| Error Code | Thrown If |
| --- | --- |
| `SSS_MISSING_REQD_ARGUMENT` | The `options.name` parameter is not specified. |
