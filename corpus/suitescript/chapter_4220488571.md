SuiteScript 2.1 APIs are organized into various modules, based on behavior. The following table lists each module and provides a description, the supported script types, and permissions associated with the module. See [Setting Roles and Permissions for SuiteScript](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0403053450.html) for more information about permissions.

Note:

As a best practice, you should load only the modules that are needed by your script.
