To use a portlet script on the NetSuite dashboard, you need to create and deploy it first. For more information, see [Creating and Deploying a Portlet Script](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1515621634.html).

If you want to create a Dashboard SuiteApp Icon, see the [Guidelines for Creating a Dashboard SuiteApp Icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1515621736.html).

See [Portlet Script Samples](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0509035029.html) for a sample of each type of portlet script (simple form, HTML, links, and list).
