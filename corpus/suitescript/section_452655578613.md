| **Method Description** | Saves a search created by [search.create(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345171487.html) or loaded with [search.load(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345775360.html). Returns the internal ID of the saved search. You must set the title and id properties for a new saved search before you save it, either when you create it with [search.create(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345171487.html) or by setting the [Search.title](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_458807006835.html) and [Search.id](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_455917297362.html) properties. If you do not set the saved search ID, NetSuite generates one for you. See [Search.id](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_455917297362.html). Note: You do not need to set these properties if you load a previously saved search with [search.load(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345775360.html) and then save it. This method also includes a promise version, [Search.save.promise()](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4440796572.html). For more information about promises, see [Promise Object](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4387812940.html). |
| --- | --- |
| **Returns** | the internal search ID of the saved search as a number |
| **Supported Script Types** | Client and server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | 5 units |
| **Module** | [N/search Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345764122.html) |
| **Since** | 2015.2 |

## Errors {#bridgehead_459041381835}

| Error Code | Message | Thrown If |
| --- | --- | --- |
| `NAME_ALREADY_IN_USE` | A search has already been saved with that name. Please use a different name. | The [Search.title](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_458807006835.html) property on [search.Search](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4392315904.html) is not unique. |
| `SSS_DUPLICATE_SEARCH_SCRIPT_ID` | Saved search script IDs must be unique. Please choose another script ID. If you are trying to modify an existing saved search, use search.load(). | The [Search.id](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_455917297362.html) property on [search.Search](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4392315904.html) is not unique. |
| `SSS_MISSING_REQD_ARGUMENT` | {1}: Missing a required argument: {2} | Required [Search.title](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_458807006835.html) property not set on [search.Search](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4392315904.html). |
