Note:

The content in this help topic pertains to SuiteScript 2.1.

You can use the N/llm module in your scripts to send prompts to a large language model (LLM) and receive a response. The module supports several approaches:

-   Use [llm.generateText(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1014032554.html) or [llm.generateText.promise(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1014100301.html) to send text to the LLM and receive a response. When you call these methods, you can specify the model family and model parameters that the LLM should use to provide the response.
    
-   Use [llm.generateTextStreamed(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_46075557997.html) or [llm.generateTextStreamed.promise(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_48093225962.html) to send text to the LLM and receive a streamed response. When you call these methods, you can access the partial response from the LLM before the entire response has been generated. You can specify the model family and model parameters that the LLM should use to provide the response.
    
-   Use [llm.evaluatePrompt(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0115064704.html) or [llm.evaluatePrompt.promise(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_81065603726.html) to send a prompt that already exists in NetSuite to the LLM and receive a response. When you call these methods, you can specify the ID of an existing prompt and values for any variables it uses.
    

You can use Prompt Studio to manage prompts and Text Enhance actions in the NetSuite UI, including creating, updating, and deleting them. For more information about Prompt Studio, see [Prompt Studio](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160809601.html).

The N/llm module works alongside Prompt Studio, letting you work with prompts and Text Enhance actions in your scripts. You can do the following:

-   [Create, Update, and Delete Prompts and Text Enhance Actions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_0219092245.html)
    
-   [Generate SuiteScript Code from an Existing Prompt](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_0219104303.html)
