## Parameters {#bridgehead_4132638853}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description | Since |
| --- | --- | --- | --- | --- |
| `options.defaultCountry` | [format.Country](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158626866748.html) | optional | Parser point of reference. Specify this value if the phone number is not in international formatl. If specified, value must be a [format.Country](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158626866748.html) value. If a value is not specified, the company country is used. | 2020.2 |
