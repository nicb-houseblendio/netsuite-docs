| **Property Description** | The script logging level for the currently executing script. This method is not supported on client scripts. Returns one of the following values:
-   DEBUG
-   AUDIT
-   ERROR
-   EMERGENCY

 |
| --- | --- |
| **Type** | string (read-only) |
