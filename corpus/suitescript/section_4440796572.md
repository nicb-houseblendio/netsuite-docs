| **Method Description** | Asynchronously saves a search created by [search.create(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345171487.html) or loaded with [search.load(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345775360.html). Returns the internal ID of the saved search. Note: The parameters and errors thrown for this method are the same as those for [Search.save()](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_452655578613.html). For more information about promises, see [Promise Object](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4387812940.html). |
