| **Property Description** | Path of the CSV file to export search results into. Note: Either this property or the [SearchTask.fileId](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4804562077.html) property must be set. If both are set, an error occurs. |
| --- | --- |
| **Type** | string |
| **Module** | [N/task Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345787858.html) |
| **Since** | 2017.1 |

## Errors {#bridgehead_4805210376}

| Error Code | Thrown If |
| --- | --- |
| `UNSUPPORTED_COMBINATION_OF_PARAMETERS` | Both this property and the [SearchTask.fileId](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4804562077.html) property are set at the same time. |
