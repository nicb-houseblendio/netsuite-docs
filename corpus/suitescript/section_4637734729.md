| **Method Description** | Retrieves a promise for a currentRecord object that represents the record active on the current page. Note: The parameters and errors thrown for this method are the same as those for [currentRecord.get()](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4637729624.html). For more information about promises, see [Promise Object](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4387812940.html). |
| --- | --- |
| **Returns** | [Promise Object](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4387812940.html) |
| **Synchronous Version** | [currentRecord.get()](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4637729624.html) |
| **Supported Script Types** | Client scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/currentRecord Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4625600928.html) |
| **Since** | 2016.2 |

## Errors {#bridgehead_4637734455}

| Error Code | Thrown If |
| --- | --- |
| `CANNOT_CREATE_RECORD_INSTANCE` | The current record page is not scriptable or an error occurred when creating the record instance. |
