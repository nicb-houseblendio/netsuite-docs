| **Property Description** | Parameters for the SuiteQL query. The specified parameters are substituted into the SuiteQL query string (represented by [SuiteQLTask.query](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159223864743.html)) when you submit the SuiteQL task using [SuiteQLTask.submit()](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159223847318.html). This property references the same set of parameters that are specified by the [SuiteQLTask.params](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159223862155.html) property in the corresponding [task.SuiteQLTask](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159223833809.html) object. |
