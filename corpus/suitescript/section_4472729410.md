| **Property Description** | Iterator that provides keys and values saved as output during the reduce stage. Note that keys are listed in [lexicographical order](https://en.wikipedia.org/wiki/Lexicographical_order). |
| --- | --- |
| **Type** | iterator |
| **Since** | 2015.2 |

## Members {#subsect_1516128244}

| Member | Type | Required/Optional | Description |
| --- | --- | --- | --- |
| iterator().each([parameters](#subsect_1516128236)) | function | required | Executes one time for each key-value pair. |

## parameters {#subsect_1516128236}

| Member | Type | Required/Optional | Description |
| --- | --- | --- | --- |
| iteratorFunction(key, value). See [functionParameters](#subsect_1516128268). | function | required | Provides logic to be executed during each iteration. |

## functionParameters {#subsect_1516128268}

| Parameter | Type | Required/Optional | Description |
| --- | --- | --- | --- |
| key | string | optional | The key saved at the end of the reduce stage by using the [reduceContext.write(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4472721829.html) method. |
| value | string | optional | The value saved at the end of the reduce stage by using the [reduceContext.write(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4472721829.html) method. |

## Syntax {#bridgehead_4474522866}
