User event scripts run during beforeLoad, beforeSubmit, and afterSubmit operations. To learn how each one works, see [How User Event Scripts are Executed](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1512409310.html).

To learn how to write a basic user event script, check out the [SuiteScript 2.1 User Event Script Tutorial](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510274245.html). In it, you'll create a script that adds a new employee record, updates fields, and creates a task.

For tips, see the [User Event Script Best Practices](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N3361453.html) section in the [SuiteScript Developer Guide](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/book_14946590423.html).
