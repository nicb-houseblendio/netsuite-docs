| **Method Description** | Creates a new node of type ELEMENT\_NODE with the specified namespace URI and name and returns the new [xml.Element](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345167426.html) object. The [Node.localName](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_460875793456.html), [Node.prefix](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_460653930663.html), and [Node.namespaceURI](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_456845336913.html) properties of the new node are set to `null`. |
| --- | --- |
| **Returns** | [xml.Element](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345167426.html) |
| **Supported Script Types** | Client and server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/xml Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4344917661.html) |
| **Since** | 2015.2 |

## Parameters {#bridgehead_458381896971}

Note:

The options parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.namespaceURI` | string | required | Namespace URI of the element to create. Can be `null`. |
| `options.qualifiedName` | string | required | Qualified name of the element to create. |

## Errors {#bridgehead_46435180664}

| Error Code | Message | Thrown If |
| --- | --- | --- |
| `SSS_XML_DOM_EXCEPTION` | INVALID\_CHARACTER\_ERR: An invalid or illegal XML character is specified. | Element with the specified namespace cannot be created. |
