| **Method Description** | Submits a record action task script deployment for processing and returns its task ID. The record action task is processed by a background process which executes the specified record action for each record ID provided in the parameters. The overall task status as well as individual action results can be queried using the `task.checkStatus()` method. |
| --- | --- |
| **Returns** | string The task ID. |
| **Supported Script Types** | Server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | 50 units |
| **Module** | [N/task Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345787858.html) |
| **Sibling Object Members** | [RecordActionTask Object Members](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345787858.html#bridgehead_1544129739) |
| **Since** | 2019.1 |
