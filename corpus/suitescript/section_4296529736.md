| **Method Description** | Returns a [runtime.Session](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4296528369.html) object that represents the user session for the currently executing script. Use this method to get session objects for the current user session. Note: In a client script, session information can change in some situations, such as due to a restart, HTTPS session timeout, or restart of a server script running in the same session which may have reset the value. If you want to get properties for the script or user, use [runtime.getCurrentScript()](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4296529387.html) or [runtime.getCurrentUser()](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4296529105.html) instead. |
| --- | --- |
| **Returns** | [runtime.Session](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4296528369.html) |
| **Supported Script Types** | Client and server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
