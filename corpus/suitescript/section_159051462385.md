| **Method Description** | Creates a limiting filter, which includes a selector of what to filter, a row axis, a limit, and a sorting order. Limiting filters can be used in pivot definitions to limit the data shown on a pivot. |
| --- | --- |
| **Returns** | [workbook.LimitingFilter](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008328944.html) |
| **Supported Script Types** | Server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/workbook Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_159006350818.html) |
| **Sibling Module Members** | [N/workbook Module Members](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_159006350818.html#subsect_159006379904) |
| **Since** | 2020.2 |

## Parameters {#subsect_159051462838}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.filteredNodesSelector` | [workbook.DimensionSelector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008193274.html) | [workbook.PathSelector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008382970.html) | required | The selector for the limiting filter. |
| `options.limit` | number | required | The limit for the limiting filter. |
| `options.row` | boolean | required | Indicator for a row axis filter. If set to false, the filter is a on a column axis. |
| `options.sortBys` | Array<[workbook.SortByDataDimensionItem](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163173379734.html) | [workbook.SortByMeasure](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163173416538.html)\> | required | The sort order for the limiting filter. |
