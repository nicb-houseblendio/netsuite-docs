| **Method Description** | Creates a [translation.Handle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1541705125.html) object in the specified locale from an existing `translation.Handle` object. This method returns a translation.Handle object that contains the same translation strings as the `options.handle` object, and the strings are in the `options.locale` locale. Before you can use this method to select a locale, the locale must be loaded using the `locales` parameter of [translation.load(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1541708603.html). |
| --- | --- |
| **Returns** | [translation.Handle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1541705125.html) |
| **Supported Script Types** | Client and server scripts For additional information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |

| **Sibling Object Members** | [N/translation Module Members](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1538666156.html#bridgehead_1544212280) |

## Parameters {#subsect_1541708967}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.handle` | [translation.Handle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1541705125.html) | required | The [translation.Handle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1541705125.html) object to select a locale for. |
| `options.locale` | string | required | The locale to select. Use the values in the [translation.Locale](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1541709045.html) enum to set this value. |

## Errors {#subsect_1541708990}

| Error Code | Thrown If |
| --- | --- |
| `SSS_MISSING_REQD_ARGUMENT` | A handle or locale parameter is missing. |
| `WRONG_PARAMETER_TYPE` | The `options.handle` parameter is not a [translation.Handle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1541705125.html) object. |
| `INVALID_LOCALE` | The specified [translation.Handle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1541705125.html) object uses an unknown or unsupported locale. |
| `TRANSLATION_HANDLE_IS_IN_AN_ILLEGAL_STATE` | The specified [translation.Handle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1541705125.html) object is in an illegal state. |
