NetSuite offers built-in tools so you can debug your SuiteScript 1.0, 2.0, and 2.1 scripts.

In SuiteScript Debugger help topics, the debugger for SuiteScript 1.0 and 2.0 scripts is called the _Script Debugger_, whereas the debugger for SuiteScript 2.1 scripts is called the _2.1 Script Debugger_. To use either debugger, you must be using a role with SuiteScript permission (Full level).

Note:

If you are using SuiteScript 1.0 for your scripts, consider converting these scripts to SuiteScript 2.0 or SuiteScript 2.1 scripts. Use SuiteScript 2.0 to take advantage of new features, APIs, and functionality enhancements. SuiteScript 2.1 uses the Graal runtime engine which may improve script performance and adds new language features, such as support for the spread operator, classes, and destructuring. For more information, see [SuiteScript 2.1 Advantages](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4284471744.html) and [SuiteScript 2.1](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_156042690639.html).
