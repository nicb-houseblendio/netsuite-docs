| **Method Description** | Updates the display type for the field. |
| --- | --- |
| **Returns** | [serverWidget.Field](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4325837128.html) object |
| **Supported Script Types** | Suitelets User event scripts - beforeLoad entry point For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |

| **Since** | 2016.1 |

## Parameters {#bridgehead_4545258216}

Note:

The options parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description | Since |
| --- | --- | --- | --- | --- |
| `options.displayType` | string | required | The new display type of the field. For more information about possible values, see [serverWidget.FieldDisplayType](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4332670964.html). | 2015.2 |
