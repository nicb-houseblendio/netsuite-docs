| **Method Description** | Converts this [query.Query](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510275177.html) object to its corresponding SuiteQL representation. This method returns a [query.SuiteQL](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157960384819.html) object that represents the same query as the original [query.Query](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510275177.html) object. This object includes the [SuiteQL.columns](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157960405619.html), [SuiteQL.params](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157960427733.html), [SuiteQL.query](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157960443690.html), and [SuiteQL.type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157960456167.html) properties. You can run the query using [SuiteQL.run()](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157960470046.html), or you can run the query as a paged query using [SuiteQL.runPaged(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157960491275.html). Important: The resulting SuiteQL query string (contained in the [SuiteQL.query](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157960443690.html) property) does not include any aliases you set on query result columns in the original [query.Query](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510275177.html) object. For more information about aliases, see [Column.alias](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156336566313.html). For more information and examples of using SuiteQL in the N/query module, see [SuiteQL in the N/query Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157960623712.html). For more information about SuiteQL in general, see [SuiteQL](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156257770590.html). |
