| **Method Description** | Use this method to determine if a specified bundle is installed. |
| --- | --- |
| **Returns** | Returns true if the specified bundle is installed. Returns false if the specified bundle is not installed. |
| **Supported Script Types** | Client and server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | 5 units |

| **Sibling Module Members** | [N/suiteAppInfo Module Members](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160236086332.html#subsect_160236033491) |
| **Since** | 2021.1 |

## Parameters {#subsect_160236055600}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.bundleId` | integer | required | The id of the bundle. |
