| **Description** | This function checks if it's okay to delete a line from an edit sublist. For an example, see [SuiteScript Client Script Sample](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4484779426.html). |
| --- | --- |
| **Returns** | `true` if the sublist line is valid and the delete is successful. `false` otherwise. |
| **Since** | Version 2015 Release 2 |

## validateDelete(scriptContext) Parameters {#bridgehead_4410702781}

Note:

The `scriptContext` parameter is a JavaScript object. NetSuite automatically sends it to your script's entry point.

| Parameter | Type | Description | Since |
| --- | --- | --- | --- |
| `scriptContext.currentRecord` | [currentRecord.CurrentRecord](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4642657958.html) | The current form record. For more information about CurrentRecord object members, see [CurrentRecord Object Members](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4625600928.html#bridgehead_4642652726). | Version 2015 Release 2 |
| `scriptContext.sublistId` | string | The sublist ID name. | Version 2015 Release 2 |
| `scriptContext.lineCount` | number | The number of lines to be deleted. This property is defined only when `validateDelete` is triggered by the **Clear All Lines** button in the UI. | Version 2020 Release 2 |

For an example of the validateDelete entry point, see [SuiteScript Client Script Sample](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4484779426.html).
