The following features must be enabled in your account:

-   **Server SuiteScript** - This feature lets you attach server scripts to records.
    
-   **OAuth 2.0** - This feature lets you perform integration requests if it is a NetSuite endpoint.
    

For more information, see [Enabling Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N232138.html).

If you're making requests to a NetSuite account, the target account must have an integration record and a public key uploaded into your account.

-   To set up a new integration, go to Setup > Integration > Manage Integrations > New.
    
-   To upload a public key, go to Setup > Integration > OAuth 2.0 Client Credentials (M2M) Setup.
    

For more information, see [Create Integration Records for Applications to Use OAuth 2.0](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157771733782.html) and [OAuth 2.0 Client Credentials Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162686838198.html).
