## Parameters {#subsect_162886130313}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.measure` | [workbook.CalculatedMeasure](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163169891173.html) | [workbook.DataMeasure](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163170291911.html) | required | The measure to sort by. |
| `options.otherAxisSelector` | Array< [workbook.DescendantorSelfNodesSelector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163170591936.html) | [workbook.DimensionSelector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008193274.html) | [workbook.PathSelector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008382970.html)\> | required | The selector for the other axis. |
| `options.selector` | Array< [workbook.DescendantorSelfNodesSelector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163170591936.html) | [workbook.DimensionSelector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008193274.html) | [workbook.PathSelector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008382970.html)\> | required | The selector for the sort. |
| `options.sort` | [workbook.Sort](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008577679.html) | required | The sort used to create. |
