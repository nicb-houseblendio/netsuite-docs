| **Method Description** | Selects an array of nodes from an XML that match an XPath expression. |
| --- | --- |
| **Returns** | [xml.Node](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4346057759.html)\[\] |
| **Supported Script Types** | Client and server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/xml Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4344917661.html) |
| **Since** | 2015.2 |

## Parameters {#bridgehead_4383133799}

Note:

The options parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.node` | [xml.Node](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4346057759.html) | required | XML node being queried. |
| `options.xpath` | string | required | XPath expression used to query node. |

## Syntax {#bridgehead_4383133717}

Important:

The following code sample shows the syntax for this member. It is not a functional example. For a complete script example, see [N/xml Module Script Samples](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0305035854.html).

In the following code sample, a single node is selected based on the `xpath` and `node` parameters. The type of node being selected is an XML document. The xpath parameter matches to the `//book` expression to locate the node. For more general information about xpath, see [XPath Tutorial.](https://www.w3schools.com/xml/xpath_intro.asp)

          `//Add additional code  ... var bookNode = xml.XPath.select({     node : xmlDocument,     xpath : '//book'  }); ... //Add additional code`
