| **Object Description** | The response from the server to an HTTP request (for example, [http.get(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4426024767.html)) from a client. This is the return type for [http.delete(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4426024970.html), [http.get(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4426024767.html), [http.post(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4426024574.html), [http.put(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4426024367.html), [http.request(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4426024227.html), and corresponding promise methods) when those methods are called from a client. This object is read-only. |
