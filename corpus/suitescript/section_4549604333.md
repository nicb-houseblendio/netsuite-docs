| **Property Description** | Indicates whether the current invocation of the [getInputData(inputContext)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4412447940.html) function is the first. Usually, the getInput function runs one time only. But if it's interrupted by an application server restart, the system restarts getInputData function. If the value of this property is `true`, the [getInputData(inputContext)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4412447940.html) has been restarted. You can use this property to make your script more robust. |
| --- | --- |
| **Type** | boolean (read-only) |
| **Since** | 2016.1 |
