| **Method Description** | Changes the current user's NetSuite password. See [Creating a Strong Password](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N487704.html) for information about valid passwords. |

## Parameters {#bridgehead_4298291061}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.currentPassword` | string | required | The logged in user's current NetSuite password. |
| `options.newPassword` | string | required | The logged in user's new NetSuite password. See [Creating a Strong Password](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N487704.html) for information about valid passwords. |

## Errors {#bridgehead_4298291881}

| Error Code | Thrown If |
| --- | --- |
| `INVALID_PSWD` | The `options.password` does not conform to the password rules. See [Creating a Strong Password](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N487704.html) for information about valid passwords. |
| `INVALID_EMAIL` | The `options.newEmail` is invalid. |
| `SSS_MISSING_REQD_ARGUMENT` | The `options.currentPassword` or `options.newPassword` is not specified. |
