Use the deployment record's **Testing** status to debug and test your script. If you want to step through your script in the [SuiteScript Debugger](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N3014215.html), you'll need to use deployed debugging.

Want more details? See [Debugging Deployed SuiteScript 1.0 and SuiteScript 2.0 Server Scripts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160418170126.html) and [Debugging Deployed SuiteScript 2.1 Server Scripts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157625777670.html).
