| **Property Description** | Part of the XML declaration, returns `true` if the current XML document is standalone or returns `false` if it is not. In the following declaration, the xmlStandalone property is `true`: `<?xml version="1.0" encoding="UTF-8" standalone="yes"?>` Important: This property is not supported on Internet Explorer or Firefox. |
| --- | --- |
| **Type** | boolean |
| **Module** | [N/xml Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4344917661.html) |
| **Since** | 2015.2 |
