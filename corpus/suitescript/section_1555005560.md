## Parameters {#subsect_1555005570}

Note:

The options parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.taskId` | number | string | required | The task ID of the merge task to check. The task ID is assigned to the merge task when you call [recognition.create(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1554995115.html). |
