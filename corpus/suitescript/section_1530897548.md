| **Property Description** | Whether the sort direction is ascending. This property is set during the of [Query.createSort(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510780402.html) and [Component.createSort(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510785047.html). The default value of this property is `true`, meaning that the sort direction is ascending. If you want the sort direction to be descending, set this property to `false`. |
