| **Property Description** | The type of the period. This property uses values from the [query.PeriodType](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158289949288.html) enum. If you create a period using [query.createPeriod(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158289670344.html) and do not specify a value for the `options.type` parameter, the default value of this property is `query.PeriodType.START`. |
