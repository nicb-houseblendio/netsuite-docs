Before you call a RESTlet, you'll need to know how to identify it, which depends on whether you're calling it from inside or outside NetSuite. Usually, you'll use values from the script deployment record, and sometimes the script record ID too.

## Internal Versus External Calls {#bridgehead_4625439845}

The script and deployment records have everything you need to identify a RESTlet. The exact values to use depend on where the call comes from.

![Script and Script deployment records for a RESTlet with ID and URL fields called out.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/SuiteScript/SuiteScript20/SuiteScript20/ScriptDeploymentScriptRecord.png)

| Source of the Call | Identify the RESTlet with: |
| --- | --- |
| An external client | A full URL, similar to the one shown on the script deployment record, in the **External URL** field (callout 4). For details, see [Dynamically Generating a Full URL](#bridgehead_4625420336). |
| A client SuiteScript with an active session in the same NetSuite account where the RESTlet is deployed | Either of the following:
-   The partial URL shown on the script deployment record, in the **URL** field (callout 3). For an example, check out [Example of a Client Script that Calls a RESTlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4643595999.html).
-   A URL generated by using the N/url module. To build the URL this way, use the script ID (from the script record) and the deployment ID (from the deployment record). For an example, check out [Example of a Suitelet that Calls a RESTlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4643598737.html).

 |
| A server SuiteScript in the same NetSuite account where the RESTlet is deployed | A full URL, similar to the one shown on the script deployment record, in the **External URL** field callout (4). This URL must be dynamically generated, in one of the following ways:

-   By using the REST roles service. For details, see [The REST Roles Service](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_157011522878.html).
-   A URL generated by using the N/url module. To generate the URL this way, you need the script ID, which is viewable on the script record in the **ID** field (callout 1). Combine this with the deployment ID, which is viewable on the script deployment record, in its **ID** field (callout 2). For an example, see [Example of a Suitelet that Calls a RESTlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4643598737.html).

 |
| A server SuiteScript in a different NetSuite account from where the RESTlet is deployed | A full URL, similar to the one shown on the script deployment record, in the **External URL** field (callout 4). This URL must be dynamically generated by using the REST roles service. For details, see [Dynamically Generating a Full URL](#bridgehead_4625420336). |

Note:

If you call a RESTlet using the delete or get method, extend the URL to include any input data required by the RESTlet logic. For details, see [Selecting an HTTP/HTTPS Method for Calling a RESTlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4619219272.html).

## Dynamically Generating a Full URL {#bridgehead_4625420336}

When you save the deployment record, NetSuite gives you the full URL in the **External URL** field. However, you should not hard-code this URL. Add logic to build the RESTlet domain dynamically instead.

You can do this in a couple of ways:

-   To call a RESTlet from an external source, use NetSuite's roles service. For details on using this service, see [The REST Roles Service](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_157011522878.html).
    
-   To call a RESTlet from within NetSuite, you can use the N/url module. With this approach, you provide the ID values from the script record and script deployment record. For an example, see [Example of a Suitelet that Calls a RESTlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4643598737.html).
    

Note:

Since 2017.2, you can use account-specific domains for RESTlets at .restlets.api.netsuite.com. The old data center-specific domains still work, too. For more info, see [URLs for Account-Specific Domains](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1498251763.html).
