Note:

JavaScript does not include an enumeration type. The SuiteScript 2.x documentation uses the term enumeration (or enum) to describe a plain JavaScript object with a flat, map-like structure. In this object, each key points to a read-only string value.

| **Enum Description** | Holds the string values for search types supported in the [N/search Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345764122.html). Use this enum to set the value for the `options.type` parameter of the [search.create(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345171487.html) method. |
| --- | --- |
| **Module** | [N/search Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345764122.html) |
| **Sibling Module Members** | [N/search Module Members](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345764122.html#bridgehead_4392314640) |
| **Since** | 2015.2 |

Note:

You must adjust your account settings according to each search type being used in your scripts to avoid potential errors.
