The supply plan definition record type only supports launch actions.

For help working with this record in the UI, see [Creating a Supply Planning Definition and Schedule](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159180786193.html).

For information about SuiteScript 2.x record actions, see the following help topics:

-   [Overview of Record Action and Macro APIs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1509640242.html)
    
-   [N/action Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510761537.html)
    

## launch {#subsect_159854576699}

| **Corresponding UI Button** | Launch |
| --- | --- |
| **Action Description** | Click launch to run the supply planning process based on the criteria which will then generate planned orders based on the demand for the items within the planning horizon. |
| **Returns** | The record owner can populate zero to many notifications and zero to many response <key, value> pairs. |
| **Exception** | After the page is launched, the bulk processing page opens to display any errors. |
| **Since** | 2020.2 |

## Parameters {#subsect_159854633694}

The recordId is the default input parameter for the action.
