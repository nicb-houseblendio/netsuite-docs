## Supported Script Types {#bridgehead_1516397389}

The folder record is scriptable in server SuiteScript only.

beforeLoad event is not supported on user event scripts.

## Supported Functions {#bridgehead_1516397413}

The folder record is fully scriptable - it can be created, updated, copied, deleted, and searched using SuiteScript.
