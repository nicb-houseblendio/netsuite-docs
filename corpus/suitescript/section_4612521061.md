## Values {#bridgehead_4616789231}

| Value |
| --- |
| `UTF_8` |
| `BASE_16` |
| `BASE_32` |
| `BASE_64` |
| `BASE_64_URL_SAFE` |
| `HEX` |

Note:

BASE\_64\_URL\_SAFE uses a different character set compared to BASE64, where the following properties apply:

-   \+ is replaced with -
    
-   / is replaced with \_
    
-   Padding is still present and represented by character =
    
-   Use SecureString.replaceString to remove padding or replace it with URL-encoded form %3D.
    

See: [Base-N Encodings](https://datatracker.ietf.org/doc/html/rfc4648#section-5)
