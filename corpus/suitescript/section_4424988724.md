| **Method Description** | Redirects a user to a search results page. For example, the results from an on demand search created with the [N/search Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345764122.html), or a loaded search that you modified but did not save. |
| --- | --- |
| **Returns** | void |
| **Supported Script Types** | User event scripts - afterSubmit entry point For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/redirect Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4424286105.html) |
| **Since** | 2015.2 |

## Parameters {#bridgehead_4424988724}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.search` | [search.Search](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4392315904.html) | required | The search result to be redirected to. |

## Syntax {#bridgehead_4449818182}

Important:

The following code sample shows the syntax for this member. It is not a functional example. For a complete script example, see [N/redirect Module Script Sample](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0304044237.html).

          `//Add additional code  ...    myNewSearch = search.create({        type: search.Type.CUSTOMER    });    redirect.toSearchResult({        search:myNewSearch    }); ... //Add additional code`
