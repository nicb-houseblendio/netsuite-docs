## Parameters {#subsect_163344855380}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.columns` | [workbook.TableColumn](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008606673.html)\[\] | required | The columns to include in the table view. |
| `options.dataset` | [dataset.Dataset](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158948063457.html) | required | The dataset containing the columns to include in the table view. |
| `options.id` | string | required | The ID of the table view. |
| `options.name` | string | [workbook.Expression](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008229845.html) | required | The name of the table view. |
