| **Method Description** | Creates a new [error.SuiteScriptError](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4253432660.html) object, which can be used in a try-catch statement to abort script execution. Note this method creates a new error, but does not throw the error. Your script code will need to include logic to throw the error when appropriate. |
| --- | --- |
| **Returns** | An [error.SuiteScriptError](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4253432660.html) object. |
| **Supported Script Types** | Server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/error Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4243798608.html) |
| **Since** | 2015.2 |

## Parameters {#bridgehead_4243803279}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description | Since |
| --- | --- | --- | --- | --- |
| `options.message` | string | required | Error message text displayed in the Details column of the Execution Log. Sets the value for the [SuiteScriptError.message](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4243803629.html) property. The default value is null. | 2015.2 |
| `options.name` | string | required | User-defined error code. You can create a custom name such as "My\_Custom\_Error" or use the values in the [error.Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159469488562.html) enum. Sets the value for the [SuiteScriptError.name](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4243803552.html) property. | 2015.2 |
| `options.notifyOff` | boolean | optional | Sets whether email notification is suppressed. Sets the value for the [SuiteScriptError.notifyOff](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159475415674.html) property. If set to false, the system emails the users identified on the applicable script record's Unhandled Errors subtab when the error is thrown. The default values is false. For additional information about the Unhandled Errors subtab, see [Creating a Script Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4489062315.html). | 2015.2 |

## Errors {#bridgehead_4243803333}

| Error Code | Thrown If |
| --- | --- |
| `SSS_MISSING_REQD_ARGUMENT` | The `options.message` or `options.name` parameter is not specified. |
| `WRONG_PARAMETER_TYPE` | One of the parameters is not specified as the correct type:
-   `options.message` must be a string value
-   `options.name` must be a string value
-   `options.notifyOff` must be a boolean value

 |
