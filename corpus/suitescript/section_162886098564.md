## Parameters {#subsect_162886098963}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.item` | [workbook.DataDimensionItem](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008187726.html) | required | The data dimension items to sort by. |
| `options.sort` | [workbook.Sort](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008577679.html) | required | The sort to use, which defines sort behavior such as whether to sort ascending or descending, whether the sort is case sensitive, and so on. |
