| **Object Description** | A relative date to use in query conditions. Use [query.createRelativeDate(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544108154.html) to create this object. After you create this object, you can use it in the `values` parameter of [Query.createCondition(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510780329.html) or [Component.createCondition(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510784922.html). This object represents a specific moment in time, and you can use it to create query conditions using operators from the [query.Operator](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510275752.html) enum, such as `query.Operator.AFTER`, `query.Operator.BEFORE`, and `query.Operator.WITHIN`. For more information about relative dates, see [Relative Dates in the N/query Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1549916938.html). |
