Before you can run a Suitelet script, you need to create at least one deployment record for it.

A Suitelet deployment record is like other script types, but it has a few extra fields. This topic covers all available fields.

You can access a Suitelet script deployment record in the following ways:

-   To edit a deployment record, go to _Customization > Scripting > Script Deployments_. Locate the appropriate record, and click the corresponding **Edit** link.
    
-   To create a new deployment record, open the script record in view mode and click the **Deploy Script** button. For help creating a script record, see [Script Record Creation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4486246677.html).
