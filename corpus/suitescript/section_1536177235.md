| **Property Description** | The value of the search parameter. This property is set when you call [search.createSetting(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1536171305.html). If you specify `consolidationtype` as the search parameter name ([Setting.name](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1536177181.html)), the following values are supported for this parameter:
-   `ACCTTYPE`
-   `AVERAGE`
-   `CURRENT`
-   `HISTORICAL`
-   `NONE`

If you specify `includeperiodendtransactions` as the search parameter name ([Setting.name](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1536177181.html)), the following values are supported for this parameter:

-   `F`
-   `FALSE`
-   `T`
-   `TRUE`

These values are not case sensitive. |
| --- | --- |
| **Type** | string This property is read-only. |
| **Module** | [N/search Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345764122.html) |
| **Since** | 2018.2 |
