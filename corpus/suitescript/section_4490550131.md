You can use script parameters to configure your script either through script deployment or by the user. Script parameters should be created whenever you need to parameterize a script that is deployed multiple times. Using script parameters lets you customize the behavior of the script for each deployment. For more information about using script parameters, see [Creating Script Parameters (Custom Fields)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/part_1542289448.html).
