SuiteScript 2.1 supports the JavaScript Object Notation (JSON) standard. You can use the JSON object to parse text as a JSON object and convert strings to JSON notation. For more information, see [JSON.parse(text)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4434848518.html) and [JSON.stringify(obj)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4434858442.html).

Important:

The following sections are included as a summary and are intended for reference only. For additional information about JSON, see [http://www.ietf.org/rfc/rfc4627.txt](http://www.ietf.org/rfc/rfc4627.txt).
