| **Property Description** | Holds the keys that were passed to the map stage by the getInputData stage. Note that keys are sorted in the following way:
-   If all values are numbers, they're listed in numeric order.
-   If any values are strings, they're listed in [lexicographical order](https://en.wikipedia.org/wiki/Lexicographical_order).

 |
| --- | --- |
| **Type** | iterator |
| **Since** | 2015.2 |

## Members {#subsect_1518576897}

| Member | Type | Required/Optional | Description |
| --- | --- | --- | --- |
| iterator().each([parameters](#subsect_1518576916)) | function | required | Executes one time for each key. |

## parameters {#subsect_1518576916}

| Member | Type | Required/Optional | Description |
| --- | --- | --- | --- |
| iteratorFunction(key, executionCount, completionState) See also [functionParameters](#subsect_1515783758). | function | required | Provides logic to be executed during each iteration. |

## functionParameters {#subsect_1515783758}

| Parameter | Type | Required/Optional | Description |
| --- | --- | --- | --- |
| key | string | optional | Represents a key that was passed to the map stage. |
| executionCount | number | optional | The number of times the map function was called for the key. |
| completionState | string | optional | A setting that indicates whether the map function was executed successfully for the key. Possible values are 'COMPLETE', 'FAILED', and 'PENDING.' The system uses 'PENDING' if the script left the stage before it tried to process the key. This behavior can occur when exitOnError is set to true. |

## Syntax {#bridgehead_4478016589}

The following snippets show three ways you could use this iterator.

This code isn't a functional example. For a complete script example, see [SuiteScript 2.1 Map/Reduce Script Code Samples](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0901033444.html).
