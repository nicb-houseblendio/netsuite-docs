| **Method Description** | Sets a key and value for a user-defined session object. Use [Session.get(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4296666278.html) to retrieve the object value after you set it. |
| --- | --- |
| **Returns** | void |
| **Supported Script Types** | Server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/runtime Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4296359529.html) |
| **Since** | 2015.2 |

## Parameters {#bridgehead_4449819036}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description | Since |
| --- | --- | --- | --- | --- |
| `options.name` | string | required | Key used to store the session object. | 2015.2 |
| `options.value` | string | required | Value to associate with the key in the user session. | 2015.2 |

## Errors {#bridgehead_159458198903}

| Error Code | Thrown If |
| --- | --- |
| `SSS_MISSING_REQD_ARGUMENT` | The `options.name` or `options.value` parameter is not specified. |
