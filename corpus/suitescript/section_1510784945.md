| **Method Description** | Creates a query result column based on the [query.Component](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510779141.html) object. The [query.Column](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510779196.html) object is the equivalent of the [search.Column](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345767216.html) object in the [N/search Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345764122.html). The [query.Column](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510779196.html) object describes the field types (columns) that are displayed from the query results. To create columns:
-   Use `Component.createColumn(options)` to create columns on the join relationships created with [Query.autoJoin(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530819144.html) and [Component.autoJoin(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530818573.html). Use this method in one of two ways:
    -   Pass in an argument for the parameter `options.fieldId`.
    -   Pass in an argument for the parameter `options.formula`. If you use this option, you can also use the optional parameter `options.type`.
-   If needed, use [Query.createColumn(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510780373.html) to create columns on the initial query definition created with [query.create(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510275581.html).
-   Assign all created columns as values to [Query.columns](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510781812.html). For an example, see [Syntax](#subsect_1530619698).

When you create a column, you can specify a field context. The field context determines how field values are displayed in the column. For example, you can specify that a column should display raw data (such as internal IDs), consolidated or converted amounts (such as currency totals), or user-friendly values (such as names). You can specify a field context in two ways:

-   Use a context from the [query.FieldContext](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1552071599.html) enum directly as the value of the `options.context` parameter. For example: `myTransactionLine.createColumn({ fieldId: 'netamount', context: query.FieldContext.CURRENCY_CONSOLIDATED });` This example is the simplest way to specify a field context that does not accept additional parameters. Because the `options.context` parameter is an Object, this example is equivalent to the following: `myTransactionLine.createColumn({ fieldId: 'netamount', context: { name: query.FieldContext.CURRENCY_CONSOLIDATED } });`
-   Use a context from the [query.FieldContext](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1552071599.html) enum as the value of the `options.context.name` parameter, and specify additional parameters using the `options.context.params` parameter. For example: `myTransactionLine.createColumn({ fieldId: 'netamount', context: { name: query.FieldContext.CONVERTED, params: { currencyId: 4, date: new Date('2019/01/01') } } });` In this release, only the `query.FieldContext.CONVERTED` context uses additional parameters. The supported parameters are `currencyId` and `date`. For the `date` parameter, you can pass a JavaScript `Date` object or [query.RelativeDate](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544109440.html) object.

## Parameters {#subsect_1510784945}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.fieldId` | string | required if `options.formula` is not used | The field ID of the query result column. This value sets the [Column.fieldId](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510788976.html) property. Obtain this value from the Records Catalog. The Records Catalog lists every record type and field that is available using SuiteAnalytics Workbook and the N/query module. For more information, see [Records Catalog Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_159367781370.html). |
| `options.formula` | string | required if `options.fieldId` is not used | The formula used to create the query result column. This value sets the [Column.formula](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510789062.html) property. For more information about formulas, see [Formulas in Searches](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_5143710889.html) and [SQL Expressions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2833020.html). |
| `options.type` | string | required if `options.formula` is used | If you use the `options.formula` parameter, use this parameter to explicitly define the formula's return type. This value sets the [Column.type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510789090.html) property. Use the appropriate [query.ReturnType](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510878969.html) enum value to pass in your argument. This enum holds all the supported values for this parameter. |
| `options.aggregate` | string | optional | Use this parameter to run an aggregate function on your query result column. An aggregate function performs a calculation on the column values and returns a single value. This value sets the [Column.aggregate](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510789115.html) property. Use the appropriate [query.Aggregate](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510878932.html) enum value to pass in your argument. This enum holds all the supported values for this parameter. |
| `options.groupBy` | boolean | optional | Whether the query results are grouped by this query result column. This value sets the [Column.groupBy](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510789147.html) property. If you do not pass in an argument, the default value is set to `false`. |
| `options.label` | string | optional | The label for the column. A label is important if the query object is used as the data source for printing (for example, in the [TemplateRenderer.addQuery(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156217838581.html) method in the N/render module). |
| `options.context` | Object | optional | The field context for values in the query result column. This value sets the [Column.context](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544109085.html) property. |
| `options.context.name` | string | required if `options.context` is used | The name of the field context. Use the appropriate [query.FieldContext](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1552071599.html) enum value to pass in your argument. This enum holds all the supported values for this parameter. |
| `options.context.params` | Object | required if `options.context.name` has a value of `query.FieldContext.CONVERTED` | The additional parameters to use with the specified field context. In this release, only the `query.FieldContext.CONVERTED` context uses additional parameters. The supported parameters are `currencyId` and `date`. |
| `options.context.params.currencyId` | number | required if `options.context.name` has a value of `query.FieldContext.CONVERTED` | The internal ID of the currency to convert to. You can specify the internal ID of any currency that is configured in your NetSuite account. For more information, see [Multiple Currencies](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1395463.html). |
| `options.context.params.date` | [query.RelativeDate](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544109440.html) | [JavaScript Date](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Date) | required if `options.context.name` has a value of `query.FieldContext.CONVERTED` | The date to use for the exchange rate between the base currency and the currency to convert to. For example, if you want to use the exchange rate that was in effect on March 3, 2019, specify a [query.RelativeDate](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544109440.html) object or JavaScript `Date` object that represents this date. |
