| **Method Description** | Attempts to adopt a node from another document to this document. If successful, this method changes the Node.ownerDocument property of the source node, its children, and any attribute nodes to the current document. If the source node has a parent node, the parent node is first removed from the child list of its own parent node. Important: This method is not supported on Internet Explorer. |
| --- | --- |
| **Returns** | [xml.Node](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4346057759.html) |
| **Supported Script Types** | Client and server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/xml Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4344917661.html) |
| **Since** | 2015.2 |

## Parameters {#bridgehead_460177856444}

Note:

The options parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.source` | [xml.Node](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4346057759.html) | required | Source node to add as a child into the current node object. |

## Errors {#bridgehead_454282165527}

| Error Code | Message | Thrown If |
| --- | --- | --- |
| `SSS_XML_DOM_EXCEPTION` | NOT\_FOUND\_ERR: An attempt is made to reference a node in a context where it does not exist. | Node cannot be adopted. |
