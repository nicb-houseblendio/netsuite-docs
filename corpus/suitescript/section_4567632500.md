## Parameters {#bridgehead_4567632405}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description | Since |
| --- | --- | --- | --- | --- |
| `options.pageObject` | [serverWidget.Assistant](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4325849970.html) | [serverWidget.Form](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4325835149.html) | [serverWidget.List](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4325856174.html) | required | A standalone page Object in the form of an assistant, form or list. | 2015.2 |

## Errors {#bridgehead_4567631989}

| Error Code | Message | Thrown If |
| --- | --- | --- |
| `SSS_MISSING_REQD_ARGUMENT` | Missing a required argument: {param name} | The `options.pageObject` parameter is not specified. |
