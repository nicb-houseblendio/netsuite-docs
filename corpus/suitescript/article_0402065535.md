## Working with IDEs Other Than SuiteCloud IDEs {#subsect_90152146793}

SuiteCloud IDEs are preferred, but you can develop SuiteScript files in any editor. If you work outside the SuiteCloud IDEs, you must manually upload the script files to the NetSuite File Cabinet.

When working with unsupported IDEs, see the following topics:

-   [Adding the SuiteScript Library File to Your IDE](#subsect_0403045947)
    
-   [Uploading Scripts to the File Cabinet Without SuiteCloud IDEs](#subsect_0403050043)
    

### Adding the SuiteScript Library File to Your IDE {#subsect_0403045947}

If you're using a non-SuiteCloud IDE, add the SuiteScript library file to your local project folder to enable features like code completion. Only roles with SuiteScript access can download the file. For more details, see [Setting Roles and Permissions for SuiteScript](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0403053450.html).

#### To add the SuiteScript library file: {#procedure_N2930181}

1.  In NetSuite, go to _Documents > Files > File Cabinet_.
    
2.  Click the **SuiteScript 2.1 API** link. NetSuite downloads the file to your browser's default Downloads folder.
    
    ![The File Cabinet page with SuiteScript API link highlighted.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/SuiteScript/SuiteScriptDeveloper/SuiteScriptDeveloperGuide/SSAPIfile.png)
3.  Extract the files, then follow your IDE's defined steps to add them in your project.
    

### Uploading Scripts to the File Cabinet Without SuiteCloud IDEs {#subsect_0403050043}

When you enable SuiteScript, NetSuite creates a **SuiteScripts** folder in the File Cabinet. You can save your scripts there for easier organization, but it's optional. Scripts run from any folder in the File Cabinet.

![The File Cabinet SuiteScripts Folder](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/SuiteScript/SuiteScriptDeveloper/SuiteScriptDeveloperGuide/SuiteScriptsFolder.png)

Note:

Keep the following guidelines in mind:

-   Only scripts in the File Cabinet can run in your account.
    
-   To run a script in the Customer, Vendor, Partner, or Employee Center, choose the matching role on the Audience subtab of the deployment record.
    
-   Make sure the script file-and any files it references-has **Company-Wide Usage** or **Available Without Login** enabled on its File Cabinet record. For more details, see [Permissions and File Cabinet Files](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4799276714.html).
    

#### To upload SuiteScript scripts to the File Cabinet: {#procedure_N2931388}

1.  Go to _Documents > Files > SuiteScripts_.
    
2.  Click **Add File**.
    
    ![The File Cabinet SuiteScripts Folder Contents page with the Add File button highlighted.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/SuiteScript/SuiteScriptDeveloper/SuiteScriptDeveloperGuide/scriptsFolder2.png)
3.  In the popup window that appears, select the file you want to upload and click **Open**.
    

Note:

After you edit a SuiteScript file in the File Cabinet, repeat steps 1-3 to upload it again. Then click **OK** to overwrite the file and apply your changes.
