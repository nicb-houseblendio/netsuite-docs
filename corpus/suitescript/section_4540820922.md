| **Property Description** | Indicates whether the [reduce(reduceContext)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4413276172.html) function has run before for the current key and values. For an overview of events that can cause a restart, see [System Response After a Map/Reduce Interruption](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1517279626.html). When the reduce function restarts for a key-value pair, any data it wrote last time is deleted. Some logic might have run before it was interrupted, so if reduceContext.isRestarted is true, your script should take steps to avoid duplicate processing. For examples, see Adding Logic to Handle Map/Reduce Restarts. For examples, see [Adding Logic to Handle Map/Reduce Restarts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1490987232.html). Related properties include [reduceContext.executionNo](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1516393633.html) and [reduceContext.errors](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1516393583.html). |

| **Type** | boolean |
