| **Method Description** | Updates cipher data with the specified encoding. |
| --- | --- |
| **Returns** | void |
| **Supported Script Types** | Server scripts For additional information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/crypto Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4358549582.html) |
| **Since** | 2015.2 |

## Parameters {#bridgehead_455947204589}

Note:

The options parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.input` | string | required | The data to update. |
| `options.inputEncoding` | string | optional | Specifies the encoding of the input data. Use the [encode.Encoding](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4369865177.html) enum to set the value. The default value is `encode.Encoding.HEX`. |
