| **Method Description** | Formats a value from the raw value to its appropriate preference format. Note: This method is overloaded when you format a `datetime` or `datetimetz` value. |
| --- | --- |
| **Returns** | If a datetime or datetimetz value is specified, the string in date format is returned in the user's local app time zone. Note: If an invalid value is given, the original value passed to `options.value` is returned. Note: For client scripts, the string returned is based on the user's system time. For server scripts, the string returned is based on the current time in the Pacific Time Zone. Daylight Savings Time does apply. |
| **Supported Script Types** | Client and server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html) |
| **Governance** | None |
| **Module** | [N/format Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4388721627.html) |
| **Since** | 2015.2 |

## Parameters {#bridgehead_4388843990}

This method is overloaded when you format a `datetime` or `datetimetz` value.

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description | Since |
| --- | --- | --- | --- | --- |
| `options.value` | Date | string | number | required | The input data to format. | 2015.2 |
| `options.type` | string | required | The field type (for example, `DATE`, `CURRENCY`, `INTEGER`). Use the [format.Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4388844232.html) enum to set this value. | 2015.2 |

The table below applies to datetime and datetimetz values only.

| Parameter | Type | Required / Optional | Description | Since |
| --- | --- | --- | --- | --- |
| `options.value` | Date | required | The Date Object being converted into a string | 2015.2 |
| `options.type` | string | required | The field type (either `DATETIME` or `DATETIMETZ`). Set using the [format.Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4388844232.html) enum. | 2015.2 |
| `options.timezone` | enum | number | optional | The time zone specified for the returned string. Set using the [format.Timezone](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4407050795.html) enum or key. If a time zone is not specified, the time zone is set based on user preference. If the time zone is invalid, the time zone is set to GMT. | 2015.2 |
