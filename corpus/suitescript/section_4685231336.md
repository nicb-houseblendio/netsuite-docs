## Map/Reduce Script Entry Points {#subsect_1513962485}

The map/reduce script type has four entry points. These let you control the script's behavior and data flow within the map/reduce stages. For an overview of the stages, see [Map/Reduce Script Stages](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4387802529.html).

| Entry Point | Context Object | Required/Optional | Description |
| --- | --- | --- | --- |
| [getInputData(inputContext)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4412447940.html) | [inputContext](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4549604332.html) | Required | Marks the beginning of the map/reduce script execution and invokes the input stage. This function is invoked one time in the execution of the script. |
| [map(mapContext)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4413275809.html) | [mapContext](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4472712193.html) | Optional, but if this entry point is skipped, the [reduce(reduceContext)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4413276172.html) entry point is required. | Invokes the map stage. If you use this entry point, the map function is invoked one time for each key-value pair provided by the [getInputData(inputContext)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4412447940.html) function. |
| [reduce(reduceContext)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4413276172.html) | [reduceContext](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4483843828.html) | Optional, but if this entry point is skipped, the [map(mapContext)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4413275809.html) entry point is required. | Invokes the reduce stage. If you use this entry point, the reduce function is invoked one time for each key and list of values provided. Data comes from the map stage or, if that's not used, from the getInputData stage. |
| [summarize(summaryContext)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4413276323.html) | [summaryContext](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4472725629.html) | Optional | Invokes the summarize stage. If you use this entry point, the summarize function is invoked one time in the execution of the script. |

## Map/Reduce Script API {#subsect_1513891653}

The following tables describe properties that are available through the map/reduce entry points.

| Property | [inputContext.isRestarted](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4549604333.html) | boolean | Indicates whether the current invocation of the [getInputData(inputContext)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4412447940.html) function represents a restart. |
