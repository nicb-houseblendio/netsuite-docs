To run an entry point script in your NetSuite account, you'll need a script deployment that decides how and when it runs. Here are the ways you can create a script deployment:

-   Using the Deployments subtab on the script record (see [Work with the Deployments Subtab/Sublist](#bridgehead_4839882570)).
    
-   Using the script deployment record (see [Use the Script Deployment Record](#bridgehead_4839884653)).
    
-   Using N/record module methods (see [Use N/record Module Methods](#bridgehead_4839888500)).
    

In most cases, you can also use the above methods to edit a script deployment.

## Work with the Deployments Subtab/Sublist {#bridgehead_4839882570}

You can deploy a script when you create a script record by using the Deployments subtab on the script record page. This lets you define values for many deployment fields, although not all. For some script types, you can also use the Deployments subtab when you are editing an existing script record. However, for other script types, the Deployments subtab is read-only when you are editing the script record. For more information about using the Deployment sublist, see [Deploying a Script by using the Deployments Sublist](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4490584904.html).

## Use the Script Deployment Record {#bridgehead_4839884653}

You can deploy a script by using the script deployment record. Here's why you might want to use this approach:

-   The script deployment record lets you access a greater number of fields than the Deployments sublist.
    
-   If you've already created a script record, in some cases it isn't possible to edit the Deployments sublist.
    

For more information about using the script deployment record, see [Deploying a Script by using the Script Deployment Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0706024425.html).

## Use N/record Module Methods {#bridgehead_4839888500}

You can create a deployment programmatically by using the [record.create(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4267258059.html) method in a script. When creating a script deployment record, set the `options.type` parameter to `record.Type.SCRIPT_DEPLOYMENT`. Similarly, if you can want to modify a script deployment record programmatically, you can load it by using [record.load(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4267258486.html). You can also modify an existing deployment record by using other [N/record Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4267255811.html) methods.

For help with the field IDs available on the script deployment record, refer to the [SuiteScript Records Browser](https://system.netsuite.com/help/helpcenter/en_US/srbrowser/Browser2026_1/script/record/scriptdeployment.html).
