Use the N/plugin module to load custom plug-in implementations. For more information about custom plug-ins, see the following help topics:

-   [Custom Plug-ins](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/book_4060648050.html)
    
-   [Custom Plug-in Creation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_3976789939.html)
    
-   [Custom Plug-in Development](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3987089571.html)
    
-   [Custom Plug-in Implementation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3987095830.html)
    

**[N/plugin Module Script Sample](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0303065130.html)**

Important:

You cannot use the SuiteScript Debugger to debug a script on demand that uses the N/plugin module. You must use deployed debugging. To use deployed debugging, you must complete the steps described in [Adding a Script that Instantiates a Custom Plug-in to NetSuite](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4574689541.html). For the complete process on creating a custom plugin, see [Custom Plug-in Development](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3987089571.html). For additional information about ad-hoc and deployed debugging, see [SuiteScript Debugger](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N3014215.html).
