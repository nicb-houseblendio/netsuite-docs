All scheduled scripts run with [SuiteCloud Processors](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1498571420.html). For more information, see the following:

-   [Scheduled Script Submission](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4658507760.html)
    
-   [Scheduled Script Execution](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4664470832.html)
    

You can debug scheduled scripts with the SuiteScript Debugger. For details, see [Scheduled Script Debugging](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1508948698.html).

Check the runtime status of your scheduled script instances on the Scheduled Script Status page. For more, see [Scheduled Script Status Page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4659353312.html).

Sometimes a scheduled script might fail because the application server restarts, for example from an update, maintenance, or some unexpected error. Restarts can end your script at any moment, so make sure your scripts can handle interruptions and recover. In SuiteScript 2.1, if there's a system failure, the script restarts from the beginning. For details, see [Scheduled Script Handling of Server Restarts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1490041886.html).
