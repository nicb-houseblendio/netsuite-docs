| **Method Description** | Shows a message when users view a record or Suitelet. User event context can be used to control whether the message is shown on records in view, create, or edit mode (not applicable for Suitelets). See [context.UserEventType](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4407992596.html). This method is called during a `beforeLoad` user event or in a Suitelet, and the message is later displayed on the client, after the `pageInit` script is completed. |
| --- | --- |
| **Returns** | void |
| **Supported Script Types** | Suitelets User event scripts - beforeLoad entry point For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/ui/serverWidget Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4321345532.html) |
| **Since** | 2018.2 |

## Parameters {#bridgehead_1530198286}

The options object passed to the Form.addPageInitMessage(options) method takes a single property; either a [message.Message](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4497858078.html) object, or the same options object that can be passed to the [message.create(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4497873263.html) method. The following tables list the parameters for the previously mentioned object property possibilities.

The [message.Message](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4497858078.html) object and the [message.Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4498688050.html) enum require loading the [N/ui/message Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4497735093.html).

Note:

The options parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description | Since |
| --- | --- | --- | --- | --- |
| `options.message` | [message.Message](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4497858078.html) | required | Encapsulates the message to be shown on the form. | 2018.2 |
| `options.type` | [message.Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4498688050.html) | required | The message type. | 2016.1 |
| `options.title` | string | optional | The message title. This value defaults to an empty string. | 2016.1 |
| `options.message` | string | optional | The content of the message. This value defaults to an empty string. | 2016.1 |
| `options.duration` | int | optional | The amount of time, in milliseconds, to show the message. The default is 0, which shows the message until Message.hide() is called. If you specify a duration for message.create() and message.show(), the value from the message.show() method call takes precedence. | 2018.2 |
