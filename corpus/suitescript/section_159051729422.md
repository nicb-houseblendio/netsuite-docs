## Parameters {#subsect_159051729900}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.root` | [workbook.DataDimension](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008172142.html) | [workbook.Section](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008446199.html) | required | The data for the pivot axis. |
| `options.sortDefinitions` | [workbook.SortDefinition](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008585696.html)\[\] | optional | The sorting definition for the pivot axis. |
