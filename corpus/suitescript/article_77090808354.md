The content in this help topic pertains to SuiteScript 2.1.

| **Property Description** | The list of documents used to generate the response. This property is an array of [llm.Document](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_73085600635.html) objects, each of which represents a document provided to [llm.generateText(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1014032554.html) or [llm.generateText.promise(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1014100301.html). This property has a value only if a provided document was used to generate the response. |
