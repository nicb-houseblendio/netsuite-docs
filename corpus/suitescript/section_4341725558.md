Use the N/workflow module to initiate new workflow instances or trigger existing workflow instances.

**[N/workflow Module Script Sample](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0305035055.html)**

## In This Help Topic {#subsect_28173335236}

-   [N/workflow Module Members](#bridgehead_4344304062)
    

## N/workflow Module Members {#bridgehead_4344304062}

| Member Type | Name | Return Type / Value Type | Supported Script Types | Description |
| --- | --- | --- | --- | --- |
| Method | [workflow.initiate(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4344303916.html) | number | Server scripts | Initiates a workflow on-demand. This method is the programmatic equivalent of the [Initiate Workflow Action](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2743465.html) action in SuiteFlow. Returns the internal ID of the workflow instance used to track the workflow against the record. |
| [workflow.trigger(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4344892270.html) | number | Server scripts | Triggers a workflow on a record. The actions and transitions of the workflow are evaluated for the record in the workflow instance, based on the current state for the workflow instance. Returns the internal ID of the workflow instance used to track the workflow against the record. |
