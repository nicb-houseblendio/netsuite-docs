| **Method Description** | Executes the query asynchronously and returns the query result set. Note: The parameters and errors thrown for this method are the same as those for [Query.run(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510780212.html). For more information about promises, see [Promise Object](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4387812940.html). |
