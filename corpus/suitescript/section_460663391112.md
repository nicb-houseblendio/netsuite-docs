| **Method Description** | Used on select, image, and document fields. Returns the text value of a specified search result column. For convenience, this method takes a single [search.Column](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345767216.html) Object. Note: This method is overloaded. You can also use [Result.getText(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_456658264159.html) to get column text value based on the name, join and summary values for a column. |
| --- | --- |
| **Returns** | string |
| **Supported Script Types** | Client and server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/search Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345764122.html) |
| **Since** | 2015.2 |

## Parameters {#bridgehead_452853942870}

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| column | [search.Column](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345767216.html) | required | Name of the search result column. |
