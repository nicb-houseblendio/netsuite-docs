| **Object Description** | Status of a document capture task ([task.DocumentCaptureTask](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_78075142728.html)) in the NetSuite task queue. You create a `task.DocumentCaptureTaskStatus` object using [task.checkStatus(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345805891.html). To check the status of a document capture task, you must provide the task ID of the document capture task. To submit a document capture task and obtain the task ID, use [DocumentCaptureTask.submit()](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_11075253797.html). |
