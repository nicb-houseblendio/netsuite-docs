Note:

The content in this help topic pertains to SuiteScript 2.1.

The following code sample shows how to receive a partial response from the LLM using [llm.generateTextStreamed(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_46075557997.html).

When you send a prompt and related content to the LLM using [llm.generateText(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1014032554.html) or [llm.evaluatePrompt(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0115064704.html), you must wait until the entire response is generated before you can access the content of the response. By contrast, [llm.generateTextStreamed(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_46075557997.html) and [llm.evaluatePromptStreamed(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_47080704730.html) let you access the partial response content before the entire response has been generated. These methods are useful if you're sending a prompt that will generate a lot of content, letting you process the response more quickly and potentially improving the performance of your scripts.

This sample provides a short preamble (which is an optional parameter supported by Cohere models) and prompt to [llm.generateTextStreamed(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_46075557997.html), along with the model to use and a set of model parameters. The `temperature` model parameter controls the randomness and creativity of the response. Higher values (closer to 1) are appropriate for generating creative or diverse responses, which fits the prompt used in the sample.

The sample uses an iterator to examine each token returned by the LLM. Here, `token.value` contains the value of each token returned by the LLM, and `response.text` contains the partial response up to and including that token. For more information about iterators, see [Iterator](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0831085754.html).

For instructions about how to run a SuiteScript 2.1 code snippet in the debugger, see [On-Demand Debugging of SuiteScript 2.1 Scripts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157625776929.html).

Note:

This sample script uses the `require` function so that you can copy it into the SuiteScript Debugger and test it. You must use the `define` function in an entry point script (the script you attach to a script record and deploy). For more information, see [SuiteScript 2.1 Script Basics](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1504638761.html) and [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html).

          `/**  * @NApiVersion 2.1  */ require(['N/llm'], function(llm) {     const response = llm.generateTextStreamed({        preamble: "You are a script writer for TV shows.",         prompt: "Write a 300 word pitch for a TV show about tigers.",        modelFamily: llm.ModelFamily.COHERE_COMMAND,        modelParameters: {           maxTokens: 1000,           temperature: 0.8,          // High temperature values result in more varied and                                      // creative responses           topK: 3,           topP: 0.7,           frequencyPenalty: 0.4,           presencePenalty: 0        }     });      var iter = response.iterator();     iter.each(function(token){         log.debug("token.value: " + token.value);         log.debug("response.text: " + response.text);         return true;     }) });`
