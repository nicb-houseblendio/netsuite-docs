Use this enum to set the `inputEncoding` and `outputEncoding` parameter values in [N/crypto Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4358549582.html) or [N/encode Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4369847722.html). |

## Values {#bridgehead_4369864765}

| Value |
| --- |
| `UTF_8` |
| `BASE_16` |
| `BASE_32` |
| `BASE_64` |
| `BASE_64_URL_SAFE` |
| `HEX` |

Note:

BASE\_64\_URL\_SAFE uses a different character set compared to BASE64, where the following properties apply:

-   \+ is replaced with -
    
-   / is replaced with \_
    
-   Padding is still present and represented by character =
    
-   Use a standard javascript String replace operation to remove padding or replace it with URL-encoded form %3D.
    

See: [Base-N Encodings](https://datatracker.ietf.org/doc/html/rfc4648#section-5)
