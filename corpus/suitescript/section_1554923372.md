| **Property Description** | Holds an array of internal IDs of the revenue arrangement records to merge. This property is valid only if the merge task was created using a task type of `TaskType.MERGE_ARRANGEMENTS_TASK`. Note: This property has a potential governance value of 10 units. For more information about governance, see [SuiteScript Governance and Limits](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N3350651.html). |
