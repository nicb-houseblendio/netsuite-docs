Portlet objects are used to encapsulate scriptable dashboard portlets. NetSuite automatically passes them to the render(params) entry point. For more information, see [render(params)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4407951965.html).

## Simple Form Portlet Object Members {#bridgehead_4671206091}

These options are only for Form Portlet objects.

| Member Type | Name | Return Type / Value Type | Description |
| --- | --- | --- | --- |
| Method | [Portlet.addField(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4671374019.html) | [serverWidget.Field](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4325837128.html) | Adds a field to the form. |
| [Portlet.setSubmitButton(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4671280175.html) | [serverWidget.Button](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4325806317.html) | Adds a submit button to the form. |
| Property | [Portlet.clientScriptFileId](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4671255061.html) | number or string | The script file ID to be used in the portlet. Can be in either numerical or string format. |
| [Portlet.clientScriptModulePath](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4671252102.html) | string | The script path to be used in the portlet. |
| [Portlet.title](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4671239839.html) | string | The title of the portlet. |
