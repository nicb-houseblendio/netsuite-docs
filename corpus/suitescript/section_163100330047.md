This transaction is available when the Expense Report feature is enabled at _Setup > Company > Enable Features_, on the Employees subtab.

For help working with this record in the UI, see [Expense Reporting](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N907845.html).

The internal ID for this record is `employeeexpensesourcetype`.

See the [SuiteScript Records Browser](https://system.netsuite.com/help/helpcenter/en_US/srbrowser/Browser2026_1/script/record/employeeexpensesourcetype.html) for all internal IDs associated with this record.

## Supported Script Types {#bridgehead_163100381816}

The employee expense source type record is scriptable in both client and server SuiteScript.

## Supported Functions {#bridgehead_163100381817}

The employee expense source type record is fully scriptable. It can be created, updated, copied, deleted, and searched using SuiteScript. It can also be transformed.
