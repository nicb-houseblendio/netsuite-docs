| **Object Description** | A limiting filter object which can be used when you create a pivot. Use [workbook.createLimitingFilter(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159051462385.html) to create this object. A limiting filter object is used as a parameter in the [workbook.createPivot(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159051610759.html) method. |
