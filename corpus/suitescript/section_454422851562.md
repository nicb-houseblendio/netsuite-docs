| **Method Description** | Returns the cipher data. Sets the output encoding for the [crypto.CipherPayload](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4358619238.html) object. |
| --- | --- |
| **Returns** | A [crypto.CipherPayload](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4358619238.html) object. |
| **Supported Script Types** | Server scripts For additional information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/crypto Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4358549582.html) |
| **Since** | 2015.2 |

## Parameters {#bridgehead_460931030272}

Note:

The options parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.outputEncoding` | enum | optional | The output encoding for a [crypto.CipherPayload](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4358619238.html) object. Use the [encode.Encoding](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4369865177.html) enum to set the value. The default value is `encode.Encoding.HEX`. |
