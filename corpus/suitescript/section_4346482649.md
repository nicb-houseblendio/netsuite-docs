## Parameters {#bridgehead_4346482649}

Note:

The options parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description | Since |
| --- | --- | --- | --- | --- |
| `options.rows` | Object\[\] | required | An array of rows that consist of either a [search.Result](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345767112.html) array, or an array of name/value pairs. Each pair should contain the value for the corresponding Column object in the list. | 2015.2 |
