| **Object Description** | A sort based on the [query.Query](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510275177.html) or [query.Component](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510779141.html) object. The `query.Sort` object describes a sort that is placed on a particular query result column. To create a sort:
-   Use [Query.createSort(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510780402.html) to create a sort based on the initial query definition created with [query.create(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510275581.html).
-   Use [Component.createSort(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510785047.html) to create a sort based on a join relationship created with [Query.autoJoin(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530819144.html) or [Component.autoJoin(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530818573.html).
-   Assign all created sorts as values to [Query.sort](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510781853.html). For an example, see [Syntax](#subsect_1510779379).
