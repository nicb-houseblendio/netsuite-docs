| **Method Description** | Redirects a user to an on demand search built in SuiteScript. This method loads a search into the session, and then redirects to a URL that loads the search definition page. |
| --- | --- |
| **Returns** | void |
| **Supported Script Types** | User event scripts - afterSubmit entry point For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/redirect Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4424286105.html) |
| **Since** | 2015.2 |

## Parameters {#bridgehead_4424988719}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.search` | [search.Search](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4392315904.html) | required | The search to be redirected to. |

## Syntax {#bridgehead_4449817979}

Important:

The following code sample shows the syntax for this member. It is not a functional example. For a complete script example, see [N/redirect Module Script Sample](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0304044237.html).

          `var column = ['internalid']; var filter = [["mainline", "is", "T"]]; var ourNewSearch = search.create({     id: 'customsearch_test',     type: search.Type.SALES_ORDER,     title: 'My Generated Search',     columns: column,     filters: filter }); redirect.toSearch({     search: ourNewSearch });`
