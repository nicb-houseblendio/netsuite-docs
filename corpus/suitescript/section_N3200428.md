## Supported Script Types {#bridgehead_1516396926}

The issue record is scriptable in both server and client SuiteScript.

## Supported Functions {#bridgehead_1516396959}

The issue record is fully scriptable - it can be created, updated, copied, deleted, and searched using SuiteScript.
