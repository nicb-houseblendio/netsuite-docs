| **Method Description** | Method used to send a SSL secured request to a remote service and return the response. Important: If negotiating a connection to the destination server exceeds 5 seconds, a connection timeout occurs. If transferring a payload to the server exceeds 45 seconds, a request timeout occurs. |
| --- | --- |
| **Returns** | An [https.ClientResponse](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4567656083.html) Object |
| **Supported Script Types** | Server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | 10 units |
| **Module** | [N/https/clientCertificate Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1543986321.html) |
| **Since** | 2019.2 |

## Parameters {#subsect_156409111682}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description | Since |
| --- | --- | --- | --- | --- |
| `options.url` | string | required | The URL address of the remote server. | 2019.2 |
| `options.body` | string | optional | The body content to send in the HTTPS request. Only the PUT, POST, and PATCH [https.Method](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4567626997.html) values support this parameter; all other methods ignore it. | 2019.2 |
| `options.certId` | string | required | The ID of the client certificate. | 2019.2 |
| `options.headers` | object | required | The HTTP headers associated with the request. | 2019.2 |
| `options.method` | string | required | The HTTP method to be used. Use the [https.Method](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4567626997.html) enum to set this value. | 2019.2 |
