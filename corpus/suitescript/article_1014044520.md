Note:

The content in this help topic pertains to SuiteScript 2.1.

The N/llm module supports the following large language models (LLMs) that are provided in Oracle Cloud Infrastructure (OCI):

-   Cohere Command A (`cohere.command-a-03-2025`)
    
-   Cohere Command A Vision (`cohere.command-a-vision`)
    
-   OpenAI GPT-OSS (`openai.gpt-oss-120b`)
    

When calling certain N/llm methods, you can provide model parameter values to customize how you want the model to generate its response. For example, you can use the `temperature` model parameter to adjust the creativity of the response. Higher temperature values generally increase creativity by adding randomness and diversity to the response.

The following N/llm methods use these parameters:

-   [llm.generateText(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1014032554.html)
    
-   [llm.generateText.promise(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1014100301.html)
    
-   [llm.generateTextStreamed(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_46075557997.html)
    
-   [llm.generateTextStreamed.promise(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_48093225962.html)
    

The following table lists the accepted ranges for model parameter values, as well as the default values used when you don't specify the values explicitly. For more information about the model parameters, refer to [Offered Pretrained Foundational Models in Generative AI](https://docs.oracle.com/en-us/iaas/Content/generative-ai/pretrained-models.htm) in the _Oracle Cloud Infrastructure Documentation_.

| Parameter | Accepted Ranges and Default Values |
| --- | --- |
| Cohere Command A | Cohere Command A Vision | OpenAI GPT-OSS |
| --- | --- | --- |
| `maxTokens` | Number between 1 and 4,000 with a default of 2,000. Average tokens per word is 3 (or about 4 characters per token). | Number between 1 and 4,000 with a default of 2,000. Average tokens per word is 3 (or about 4 characters per token). | Number between 1 and 16,000 with a default of 2,000. Average tokens per word is 3 (or about 4 characters per token). |
| `frequencyPenalty` | Number between 0 and 1 with a default of 0. | Number between 0 and 1 with a default of 0. | Number between -2 and 2 with a default of 0. |
| `presencePenalty` | Number between 0 and 1 with a default of 0. | Number between 0 and 1 with a default of 0. | Number between -2 and 2 with a default of 0. |
| `prompt` | Input token limit is 256,000. | Input token limit is 256,000. | Input token limit is 128,000. |
| `temperature` | Number between 0 and 1 with a default of 0.2. | Number between 0 and 1 with a default of 0.2. | Number between 0 and 2 with a default of 0.2. |
| `topK` | Number between 0 and 500 with a default of 500. | Number between 0 and 500 with a default of 500. | Number between 1 and 100,000 with a default of 500. |
| `topP` | Number between 0 and 1 with a default of 0.7. | Number between 0 and 1 with a default of 0.7. | Number between 0 and 1 with a default of 0.7. |
