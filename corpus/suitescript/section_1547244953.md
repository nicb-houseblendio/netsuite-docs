## Parameters {#subsect_1547244964}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.signature` | string | required | The signature to be verified. |
| `options.signatureEncoding` | string | optional | The signature's encoding in Base64 format. |

### Errors {#subsect_1548968077}

| Error Code | Thrown If |
| --- | --- |
| `INVALID_SIGNATURE` | Signature is not verified. This error can occur if the certificate or hash algorithm is not correct in the Verifier object. The error can also occur if the signature is not valid for the supplied string. |
