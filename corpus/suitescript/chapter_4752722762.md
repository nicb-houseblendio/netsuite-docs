This topic maps SuiteScript 1.0 APIs to their corresponding SuiteScript 2.1 APIs. Keep the following in mind when using these mappings:

-   Some SuiteScript 1.0 APIs do not have a SuiteScript 2.1 equivalent.
    
-   There is not always a 1:1 mapping between SuiteScript 1.0 and SuiteScript 2.1. Each SuiteScript 1.0 API is listed only one time, but it may map to several SuiteScript 2.1 APIs.
    
-   These mappings **do not include** SuiteScript 1.0 deprecated APIs.
    
-   These mappings **do not include** new SuiteScript 2.1 functionality. To find new SuiteScript 2.1 functionality, go to [SuiteScript 2.1 Modules](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4220488571.html) which includes a description and link to each module.
    

Important:

If you are using SuiteScript 1.0 for your scripts, consider converting these scripts to SuiteScript 2.1. Use SuiteScript 2.1 to take advantage of new features, APIs, and functionality enhancements. For more information, see [SuiteScript 2.1 Advantages](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4284471744.html) and [Transitioning from SuiteScript 1.0 to SuiteScript 2.x](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160098544034.html).

If converting your SuiteScript 1.0 scripts to SuiteScript 2.1 is not feasible in your situation, you can use SuiteScript 2.1 RESTlet scripts to extend the capabilities of your existing SuiteScript 1.0 scripts. For more information, see [Using SuiteScript 2.x Scripts with SuiteScript 1.0 Scripts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_4155500631.html).

The following topics group SuiteScript 1.0 APIs into functions (prefixed with 'nlapi') and objects (prefixed with 'nlobj'). All functions are listed alphabetically in one table. Whereas objects and their members are grouped alphabetically by object name. Each object has its own table containing all object members.

-   [SuiteScript 1.0 to SuiteScript 2.1 API Map - Functions (nlapi)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4752724744.html)
    
-   [SuiteScript 1.0 to SuiteScript 2.1 API Map - Objects (nlobj)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4752730521.html)
