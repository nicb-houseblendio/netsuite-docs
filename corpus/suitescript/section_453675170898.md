| **Method Description** | Creates a new node of type PROCESSING\_INSTRUCTION\_NODE with the specified target and data and returns the new [xml.Node](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4346057759.html) object. The following example shows a sample processing instruction: `<?xml version="1.0"?>` Use a processing instruction node to keep processor-specific information in the text of the XML document. |
| --- | --- |
| **Returns** | [xml.Node](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4346057759.html) |
| **Supported Script Types** | Client and server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/xml Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4344917661.html) |
| **Since** | 2015.2 |

## Parameters {#bridgehead_455389648437}

Note:

The options parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.target` | string | required | Target part of the processing instruction. |
| `options.data` | string | required | Data for the processing instruction. |

## Errors {#bridgehead_454478698730}

| Error Code | Message | Thrown If |
| --- | --- | --- |
| `SSS_XML_DOM_EXCEPTION` | INVALID\_CHARACTER\_ERR: An invalid or illegal XML character is specified. | Processing instruction node cannot be created with the specified target or data. |
