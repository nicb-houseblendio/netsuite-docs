| **Object Description** | A position that is defined using position values, such as `LEFT` and `CENTER`. Use [workbook.createPositionValues(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162862321945.html) to create this object. A position values object is used as a parameter in the [workbook.createStyle(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162886251569.html) method. |
