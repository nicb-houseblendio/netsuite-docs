The following script samples demonstrate how to use the features of the N/search module:

-   [Search for Customer Records and Log First 50 Results](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_156691009252.html)
    
-   [Search for Sales Order Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_156691117264.html)
    
-   [Load a Search for Sales Order Records and Use a Callback Function to Process Results](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_156691156175.html)
    
-   [Load a Search for Sales Order Records and Return the First 100 Search Results](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_156691178780.html)
    
-   [Load and Run a Paginated Search and Process the Results](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_156691193698.html)
    
-   [Create a Search for a Custom Record Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_156691607120.html)
    
-   [Search for Items in a Custom List](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_156691710476.html)
    
-   [Delete a Saved Search](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_156691213501.html)
    
-   [Search Using a Specific Record Field](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_161114820748.html)
    

Important:

These samples are designed to run in a NetSuite OneWorld account, so the OneWorld feature must be enabled in your NetSuite account for the samples to work.
