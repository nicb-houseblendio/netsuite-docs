After you add the bundle installation script file to the file cabinet, you create the bundle installation script record.

1.  Go to _Setup > Customization > Scripts > New_, and click **Bundle Installation**.
    
2.  Complete fields in the script record and save.
    
    Although you don't need to set every field on the Script record, you must at least provide a **Name** for the Script record, load your SuiteScript file to the record, and specify at least one of the executing functions on the Scripts subtab.
    
    ![Entry points on Script page for bundle installation script.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/SuiteScript/SuiteScript20/SuiteScript20/BundInScriptRecord.png)
3.  These functions should all be in the main script file. If these functions call functions in other script files, you need to list those files as library script files.
