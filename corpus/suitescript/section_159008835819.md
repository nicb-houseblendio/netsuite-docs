## Parameters {#subsect_159008836438}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.measure` | [workbook.CalculatedMeasure](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163169891173.html) | [workbook.DataMeasure](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163170291911.html) | required | The measure of the chart series. |
| `options.type` | [workbook.AspectType](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159059139226.html) | optional | The aspect type of the chart series. |
