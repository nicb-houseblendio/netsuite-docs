SuiteScript 2.0 and all future releases of SuiteScript will maintain the following versioning system.

| Version Type | Numbering Pattern | Description |
| --- | --- | --- |
| Major | Version 2.0, 3.0, 4.0 | Major versions of SuiteScript include significant functionality changes and improvements. Major versions aren't backward compatible with previous versions. |
| Minor | Version 2.0, 2.1, 2.2 | Minor versions of SuiteScript include enhancements to existing features. Minor versions are backward compatible with all versions released since the last major version. For example, SuiteScript 2.1 is backward compatible with SuiteScript 2.0, but it is not backward compatible with SuiteScript 1.0. |
| Patch | Does not apply | Patch versions of SuiteScript are included with regular NetSuite bug fix releases. Patch versions are backward compatible with all versions released since the last major version. |

## Using SuiteScript Version 2.x in Scripts {#subsect_0120123008}

You can specify a SuiteScript version of 2.x in your scripts. The 2.x value usually represents the latest generally available SuiteScript version. By default, 2.x resolves to SuiteScript 2.0. If the **Execute SuiteScript 2.x Server Scripts As** account-level preference is set to 2.1, compatible 2.x scripts can run as SuiteScript 2.1.

For more information about specifying a version for your script, see [SuiteScript 2.1 JSDoc Validation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387175355.html) and [SuiteScript Versions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_1501543623.html#bridgehead_161849369316). For more information about the account-level preference and how to use it, see [Enabling SuiteScript 2.1 at the Account Level](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157960966997.html).
