| **Property Description** | The total number of tokens for the entire request to the LLM. This value is the sum of the [Usage.completionTokens](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0804071705.html) and [Usage.promptTokens](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0804071825.html) properties. |
| --- | --- |
| **Type** | number |
| **Supported Script Types** | Server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Module** | [N/llm Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_9123730083.html) |
