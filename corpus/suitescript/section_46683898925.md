| **Property Description** | Formula used by the search filter. Use this property to get or set the formula used by the search filter. For more information about the formula property, see [search.createFilter(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345777107.html). For more information about using formulas in searches, see [Formulas in Searches](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_5143710889.html). |
