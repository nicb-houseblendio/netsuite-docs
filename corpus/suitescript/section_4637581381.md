| **Method Description** | Returns a value indicating whether the field contains a subrecord. |
| --- | --- |
| **Returns** | boolean |
| **Supported Script Types** | Client scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/currentRecord Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4625600928.html) |
| **Since** | 2016.2 |

## Parameters {#bridgehead_4637581337}

Note:

The options parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description | Since |
| --- | --- | --- | --- | --- |
| `options.fieldId` | string | required | The internal ID of the field that may contain a subrecord. See [Finding Internal IDs of Record Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_0416043804.html). | 2016.2 |
