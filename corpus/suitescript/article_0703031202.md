Note:

The content in this help topic pertains to SuiteScript 2.1.

| **Property Description** | The MIME type of the document. This property can contain the following MIME types, depending on the extension of the file provided to [documentCapture.documentToStructure(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0704102801.html) or parsed using [documentCapture.parseResult(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0704103210.html):
-   **JPG** - `image/jpeg`
-   **PDF** - `application/pdf`
-   **PNG** - `image/png`
-   **TIFF** - `image/tiff`
