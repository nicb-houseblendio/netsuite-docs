| **Method Description** | Returns the search column for which the minimal or maximal value should be found when returning the [search.Column](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345767216.html) value. For example, can be set to find the most recent or earliest date, or the largest or smallest amount for a record, and then the [search.Column](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345767216.html) value for that record is returned. Note: You can only use this method if you use `MIN` or `MAX` as the summary type on a search column with the [Result.getValue(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_46917053222.html) method. |
| --- | --- |
| **Returns** | [search.Column](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345767216.html) |
| **Supported Script Types** | Client and server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/search Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345764122.html) |
| **Since** | 2015.2 |

## Parameters {#bridgehead_453410278320}

Note:

The options parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.name` | string | required | The name of the search column for which the minimal or maximal value should be found. |
| `options.join` | string | required | The join id for the search column. |
