| **Property Description** | The custom scriptId of the role for the current user. You can use this value instead of [User.role](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4296669948.html). When bundling a custom role, the internal ID number of the role in the target account can change after the bundle is installed. Therefore, in the target account you can use this property to access the unique/custom scriptId assigned to the role. |
| --- | --- |
| **Type** | string (read-only) |
| **Module** | [N/runtime Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4296359529.html) |
