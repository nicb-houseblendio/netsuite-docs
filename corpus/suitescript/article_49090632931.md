| **Method Description** | Asynchronously extracts content from a document. This method can return the text content, table content, and key-value pairs (fields) from the specified document located in the NetSuite File Cabinet. The content returned depends on the features you specify when you call this method (using the `options.features` parameter). Use the [documentCapture.Feature](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0704103522.html) enum to specify the features you want to extract, such as `TEXT_EXTRACTION`, `TABLE_EXTRACTION`, and `FIELD_EXTRACTION`. This method supports documents up to five pages in length. If you want to extract content from documents longer than five pages, you must submit an asynchronous extraction task using the N/task module. For an example, see [Extract Content from a Document Asynchronously](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_0721114921.html). This method supports PDF, JPG, PNG, and TIFF files. Encrypted files are not supported. Note: The parameters and errors thrown for this method are the same as those for [documentCapture.documentToStructure(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0704102801.html). For more information about promises, see [Promise Object](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4387812940.html). |
