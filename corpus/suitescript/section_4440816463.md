| **Method Description** | Sends an HTTP POST request asynchronously. Note that when a Suitelet is invoked by this method, it will wait for all the pending promises to finish. Note: The parameters and errors thrown for this method are the same as those for [http.post(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4426024574.html). For more information about promises, see [Promise Object](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4387812940.html). |
