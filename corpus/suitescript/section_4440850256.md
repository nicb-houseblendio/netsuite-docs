| **Method Description** | Voids a transaction record object asynchronously and return an ID that indicates the type of void performed:
-   If a direct void is performed, this method returns the ID of the record that was voided.
-   If a void by reversing journal is performed, this method returns the ID of the newly created voiding journal.

The type of void performed depends on the targeted account's preference settings. Important: After you void a transaction, you cannot make changes to the transaction that impact the general ledger. Note: The parameters and errors thrown for this method are the same as those for [transaction.void(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4413165692.html). For more information about promises, see [Promise Object](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4387812940.html). |
