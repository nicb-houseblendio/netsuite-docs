## SuiteScript 2.1 SDF Installation Script Entry Point Parameters {#subsect_156383127007}

Note:

The `scriptContext` parameter is a JavaScript object.

| Parameter | Type | Description | Since |
| --- | --- | --- | --- |
| `fromVersion` | string | The current SuiteApp version installed on the account. Specify Null if this is a new installation. | 2015.2 |
| `toVersion` | string | The version of the SuiteApp that will be installed on the account. | 2015.2 |

For examples of the run entry point, see [SDF Installation Script Samples](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_156502661150.html#subsect_156383114165).

You can also define custom script parameters by adding a parameter to the script record (defined as a custom script field). Then, set the parameter to a particular value on the deployment. Here's an example of how to get a script parameter from an SDF installation script:

            `/**  * @NApiVersion 2.0  * @NScriptType SDFInstallationScript  */  define(['N/runtime'], function(runtime) {     function run(params) {         var customParam = runtime.getCurrentScript().getParameter({name: 'custscript1'});     }     return {         run: run     }; });` 
          

See [Creating Script Parameters (Custom Fields)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/part_1542289448.html) for more information about script parameters. See [SDF Installation Script Example of Customizing a SuiteApp Update](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1553874490.html) for an example.
