You can link two datasets that share at least one common field, like a date. Linking datasets is useful when you're working with record types that cannot be joined.

For more information about dataset linking in SuiteAnalytics Workbook, see [Linking Datasets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162627283560.html).

To link datasets, use [datasetLink.create(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162626675925.html). This method creates a [datasetLink.DatasetLink](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162626627810.html) object. You'll need to provide two arrays: an array containing the datasets to link (as [dataset.Dataset](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158948063457.html) objects) and an array of expressions representing the columns to use to link the datasets. The columns you choose should have the same data type, like string or date. Create column expressions using [Dataset.getExpressionFromColumn(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158948233177.html). For more information, see [Expressions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_163386238329.html). You can also include an optional ID.

          `var myDatasetLink = datasetLink.create({     datasets: [myFirstDataset, mySecondDataset],     expressions: [[myFirstColumnExpression, mySecondColumnExpression]],     id: 'myDatasetLinkId' });` 
        

Important:

You can use linked datasets only in pivots, not in table views.

For more information, see [N/datasetLink Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_162609851226.html).
