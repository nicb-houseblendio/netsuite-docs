Project Templates enable you to create project records in NetSuite for projects your business performs repeatedly.

To use the project template and [Project](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3185758.html) records, you must have the Projects feature enabled at _Setup > Company > Enable Features_, on the Company subtab. If you plan to do advanced project tracking, you must also enable Project Management. If you do not see the Project Management box, your company must first purchase the Project Management add-on from NetSuite.

For help working with this record in the user interface, see [Project Templates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3897375321.html).

The internal ID for this record is `projecttemplate`.

See the [SuiteScript Records Browser](https://system.netsuite.com/help/helpcenter/en_US/srbrowser/Browser2026_1/script/record/projecttemplate.html) for all internal IDs associated with this record.

Note:

For information about using the SuiteScript Records Browser, see [Working with the SuiteScript Records Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N3169369.html) in the NetSuite Help Center.

Use a project template as a standard starting point for projects and project items. Each record instance is reusable. See [Project Templates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3897375321.html) for information about using project templates in the UI.

For information about scripting with this record in SuiteScript, see the following:

-   [SuiteScript 2.x Scripting Records and Subrecords](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4675582755.html)
    
-   [SuiteScript 2.1 Custom Forms](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1518455588.html)
    
-   [N/record Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4267255811.html)
    

## Supported Script Types {#bridgehead_4449119178}

The project template record is supported in all client and server scripts.

## Supported Functions {#bridgehead_4230863762}

The following SuiteScript functionality is supported:

-   Read
    
-   Create
    
-   Edit
    
-   Delete
    
-   Search
    

Note:

Copy is not supported.
