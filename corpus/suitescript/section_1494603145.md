Note:

JavaScript does not include an enumeration type. The SuiteScript 2.x documentation uses the term enumeration (or enum) to describe a plain JavaScript object with a flat, map-like structure. In this object, each key points to a read-only string value.

| **Enum Description** | Holds the string values for supported NetSuite resources that you can redirect to. Use this enum to set the value of the `type` parameter for [ServerResponse.sendRedirect(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4567653054.html). |
| --- | --- |
| **Module** | [N/https Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4418229131.html) |
| **Sibling Module Members** | [N/https Module Members](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4418229131.html#bridgehead_4418245329) |
| **Since** | 2020.2 |

## Values {#bridgehead_1494603317}

| Value | Description |
| --- | --- |
| `MEDIA_ITEM` | A file in the NetSuite File Cabinet |
| `RECORD` | A NetSuite record. |
| `RESTLET` | A deployed RESTlet. |
| `SUITELET` | A deployed Suitelet. |
| `TASK_LINK` | A page in NetSuite, as defined by a valid Task ID. |
