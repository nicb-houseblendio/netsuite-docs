| **Object Description** | A tool returned from [llm.createTool(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_54090013211.html). This object represents a callable operation that the large language model (LLM) can request to augment its responses. Tools are custom utilities that you define, and they let the LLM retrieve external data (such as data from NetSuite using SuiteQL), perform calculations, or trigger business logic as part of an LLM interaction. This object is used to inform the LLM about which operations are available to invoke as it generates its response. You create this object using the [llm.createTool(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_54090013211.html) method. This object includes properties for the tool name ([Tool.name](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_19103033051.html)), tool description ([Tool.description](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_71090751307.html)), and a set of input parameters ([Tool.parameters](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_60103126273.html)). When you call [llm.generateText(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1014032554.html) or [llm.generateTextStreamed(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_46075557997.html), you can use the `options.tools` parameter to provide a set of tools that the LLM can request. When the LLM determines that a tool may help answer a prompt, it requests a tool call, which you handle in your SuiteScript code. After running the tool's logic and obtaining a result, you can send the result (as a [llm.ToolResult](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_73104354447.html) object) back to the LLM, which can enable richer and more dynamic responses. |
