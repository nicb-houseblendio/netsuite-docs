| **Method Description** | Directs NetSuite to place the merge duplicate records task into the NetSuite task queue and returns a unique ID for the task. Use [EntityDeduplicationTaskStatus.status](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_452162109374.html) to view the status of a submitted task. |
| --- | --- |
| **Returns** | string The task ID |
| **Supported Script Types** | Server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | 100 units |
| **Module** | [N/task Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345787858.html) |
| **Since** | 2015.2 |
