| **Method Description** | Creates a new condition (a [query.Condition](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510779210.html) object) that corresponds to a logical conjunction (AND) of the arguments passed to the method. The arguments must be one or more [query.Condition](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510779210.html) objects. A condition narrows the query results. The [query.Condition](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510779210.html) object acts in the same capacity as the [search.Filter](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345767603.html) object in the [N/search Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345764122.html). The primary difference is that [query.Condition](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510779210.html) objects can contain other [query.Condition](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510779210.html) objects. To create conditions:
-   Use [Query.createCondition(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510780329.html) to create conditions for the initial query definition created with [query.create(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510275581.html).
-   Use [Component.createCondition(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510784922.html) to create conditions for the join relationships created with [Query.autoJoin(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530819144.html) and [Component.autoJoin(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530818573.html).
-   If you have multiple conditions, use them to create a new parent condition with the methods `Query.and()`, [Query.or(conditions)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510780444.html), and [Query.not(condition)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510780462.html).
-   Assign your parent condition to [Query.condition](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510781832.html). For an example, see [Syntax](#subsect_1530620843).

The following code sample shows the syntax for this member. It is not a functional example. For a complete script example, see [N/query Module Script Samples](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0304035624.html).

            `// Add additional code ...     var myCustomerQuery = query.create({         type: query.Type.CUSTOMER     });     var mySalesRepJoin = myCustomerQuery.autoJoin({         fieldId: 'salesrep'     });     var myLocationJoin = mySalesRepJoin.autoJoin({         fieldId: 'location'     });     var firstCondition = myCustomerQuery.createCondition({         fieldId: 'id',         operator: query.Operator.EQUAL,         values: 107     });     var secondCondition = myCustomerQuery.createCondition({         fieldId: 'id',         operator: query.Operator.EQUAL,         values: 2647     });     var thirdCondition = mySalesRepJoin.createCondition({         fieldId: 'email',         operator: query.Operator.START_WITH_NOT,         values: 'foo'     });     myCustomerQuery.condition = myCustomerQuery.and(thirdCondition, myCustomerQuery.not(myCustomerQuery.or(firstCondition, secondCondition)));     var resultSet = myCustomerQuery.run(); ... // Add additional code`
