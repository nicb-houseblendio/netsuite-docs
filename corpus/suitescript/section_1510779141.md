| **Object Description** | One component of the query definition. Each new component is created as a child to the previous component. All components exist as children to the query definition ([query.Query](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510275177.html)). You can think of a component as a building block; each new component builds on the previous component created. The last component created encapsulates the relationship between it and all of its parent components. The query definition always contains at least one component. Queries with joins contain multiple components. The query definition ([query.Query](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510275177.html)) contains a child `query.Component` object for each of the following:
-   **The initial query definition:** The initial `query.Component` object is called the root component. It encapsulates the initial query type passed to [query.create(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510275581.html). The root component is automatically created with the [query.Query](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510275177.html) object and is a child of the [query.Query](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510275177.html) object. The [Query.root](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510781874.html) property contains a reference to the root component.
-   **The first join:** The second `query.Component` object is created with [Query.autoJoin(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530819144.html). It encapsulates the relationship between the initial query definition and the second query type. This relationship is determined by the join ID passed to [Query.autoJoin(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530819144.html) . The second `query.Component` object is a child of the root component.
-   **Each subsequent join:** The third `query.Component` object is created with [Component.autoJoin(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530818573.html). All subsequent joins and their respective `query.Component` objects are also created with [Component.autoJoin(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530818573.html) . Each of these `query.Component` objects encapsulates the relationship between all previous query types and the new query type. This relationship is determined by the join ID passed to [Component.autoJoin(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530818573.html).
