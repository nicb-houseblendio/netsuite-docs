| **Method Description** | Creates a hash for a [https.SecureString](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4418286676.html). You can optionally specify the encoding used to convert the SecureString content to and the encoding used to encode the result as a string. Use [https.HashAlg](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1543504694.html) to set the hash algorithm. |
| --- | --- |
| **Returns** | [https.SecureString](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4418286676.html) |
| **Supported Script Types** | Server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/https Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4418229131.html) |
| **Since** | 2015.2 |

## Parameters {#bridgehead_460989929198}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.algorithm` | string | required | The hash algorithm. Use values from the [https.HashAlg](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1543504694.html) enum. |
| `options.contentEncoding` | string | optional | Encoding used to convert/decode the current string content into binary data for hashing. Use values from the [https.Encoding](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4612521061.html) enum. Defaults to current internal encoding of the SecureString. Although a default is provided, we highly encourage the use of this parameter for the most secure and correct encoding. |
| `options.resultEncoding` | string | optional | Encoding used encode the binary result as a string. Use values from the [https.Encoding](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4612521061.html) enum. Defaults to HEX when `options.contentEncoding` is specified, otherwise defaults to current internal encoding of the SecureString. Although a default is provided, we highly encourage the use of this parameter for the most secure and correct encoding. |

## Errors {#bridgehead_162266049498}

| Error Code | Thrown If |
| --- | --- |
| `FAILED_TO_CONVERT_BINARY_DATA_TO_UTF_8` | An invalid attempt was made to encode the binary result to UTF-8 string. |
| `FAILED_TO_DECODE_STRING_ENCODED_BINARY_DATA_USING_1_ENCODING` | The content of the SecureString is not a valid encoded string according to the `options.contentEncoding` parameter value. |
