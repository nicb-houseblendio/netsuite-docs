The lead source record helps you refine the lead source for a marketing campaign.

For help working with this record in the UI, see [Lead Sources](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N975884.html).

The internal ID for this record is `leadsource`.

Note:

For information about using the SuiteScript Records Browser, see [Working with the SuiteScript Records Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N3169369.html) in the NetSuite Help Center.

## Supported Script Types {#subsect_54152105224}

The lead source record is scriptable in both client and server SuiteScript.

## Supported Functions {#subsect_25152108416}

The lead source record supports the following functions: create, read, update, and delete. The following functions aren't supported: copy, search, and transform.

## Prerequisites {#subsect_60152112100}

You must enable the Marketing Automation feature before you can use this record with SuiteScript. For more information, see [Marketing Automation Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N973384.html).

## Code Samples {#subsect_15152123183}

The following samples show common actions with lead source scripting.

### Create script example: {#subsect_0302040131}

              `var record = nlapiCreateRecord('leadsource', true); record.setFieldValue('description', 'Test description'); record.setFieldValue('name', 'Test name'); record.setFieldValue('inactive', 'F'); var recordId = nlapiSubmitRecord(record);` 
            

### Update script example: {#subsect_0302040154}

              `record = nlapiLoadRecord('leadsource', recordId); record.setFieldValue('description', 'Test description updated'); record.setFieldValue('name', 'Test name updated'); record.setFieldValue('inactive', 'T'); recordId = nlapiSubmitRecord(record);` 
            

### Delete script example: {#subsect_0302040230}

              `nlapiDeleteRecord('leadsource', recordId);`
