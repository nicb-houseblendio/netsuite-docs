| **Object Description** | A color object which is made up of red, green, blue, and alpha components. Use [workbook.createColor(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162861840772.html) to create this object. A color object is used as a parameter in the [workbook.createStyle(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162886251569.html) method. |
