This record is used to indicate the posting periods in which revenue should be recognized and the amount to be recognized in each period. Revenue plans are derived from revenue recognition rules. Each revenue element has a forecast plan and one or more plans. The revenue plans control the posting of revenue.

This record is part of advanced revenue management. To use advanced revenue management (essentials), the Accounting Periods feature and Advanced Revenue Management (Essentials) feature must be enabled.

For help working with this record in the UI, see [Setup for Advanced Revenue Management (Essentials)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4328435754.html).

The internal ID for this record is `revrecplan`.

See the [SuiteScript Records Browser](https://system.netsuite.com/help/helpcenter/en_US/srbrowser/Browser2026_1/script/record/revenueplan.html) for all internal IDs associated with this record.

## Supported Script Types {#bridgehead_1492454976}

The revenue recognition plan record is supported in server SuiteScript only.

The user events are not supported.

## Supported Functions {#bridgehead_1492454989}

The revenue recognition plan record is partially scriptable. It can be read, updated, and searched using SuiteScript. It cannot be created, copied, deleted, or transformed.

## Planned Revenue Sublist {#bridgehead_4437997033}

The internal id for this sublist is `plannedrevenue`. The sublist type is inline editor.

The following table lists the scriptable sublist fields associated with the Planned Revenue sublist.

| **Field** | **Type** | **Internal ID** |
| --- | --- | --- |
| Amount | Decimal Number | `amount` |
| Planned Period | List/Record | `plannedperiod` |
