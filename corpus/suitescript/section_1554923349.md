| **Property Description** | Holds an error message that describes the failure of the merge task. This property is valid only if the value of the [MergeArrangementsTaskStatus.status](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1554924176.html) property is `TaskStatus.FAILED`. |
