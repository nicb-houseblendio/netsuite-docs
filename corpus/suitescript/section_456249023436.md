| **Method Description** | Binds a search result to a template variable. |
| --- | --- |
| **Returns** | void |
| **Supported Script Types** | Server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/render Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4412042824.html) |
| **Since** | 2015.2 |

## Parameters {#bridgehead_459116149901}

Note:

The options parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.templateName` | string | required | Name of the results iterator variable referred to in the template. |
| `options.searchResult` | [search.Result](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4345767112.html) object | required | The search result to add. |
