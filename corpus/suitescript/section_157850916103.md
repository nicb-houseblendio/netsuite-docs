The Records Browser includes a Deleted Record page, listed under **D**. This page lists the columns and filters available for deleted record searches in SuiteScript.

![The Deleted Record page in the Records Browser.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/SuiteScript/SuiteScriptDeveloper/SuiteScriptDeveloperGuide/RBDeletedRecSearch.png)

Check a record's page in the Records Browser to see if it can be used as a filter for deleted record searches. Records that can be used as filters have a **Supports Deleted Record Search** designation on their pages. For information about running deleted record searches in the UI, see [Searching for Deleted Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4031815869.html).

The retrieval of deleted records in SOAP web services is a bit different. You can use the [getDeleted](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3497592.html) operation instead of running a search. For a complete list of supported record types for this operation, refer to the `DeletedRecordType` enumeration in the [coreTypes](https://webservices.netsuite.com/xsd/platform/v2022_1_0/coreTypes.xsd) spreadsheet.
