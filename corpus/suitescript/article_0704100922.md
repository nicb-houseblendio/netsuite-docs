Note:

The content in this help topic pertains to SuiteScript 2.1.

| **Property Description** | The extracted fields from the page of a document. This property has a value only when the `documentCapture.Feature.FIELD_EXTRACTION` feature is specified when you call [documentCapture.documentToStructure(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0704102801.html). |
| --- | --- |
| **Type** | [documentCapture.Field](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0703031446.html)\[\] |
| **Supported Script Types** | Server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Module** | [N/documentCapture Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_8134325498.html) |
| **Parent Object** | [documentCapture.Page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0704100841.html) |
| **Sibling Object Members** | [Page Object Members](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_8134325498.html#subsect_0703021817) |
| **Since** | 2025.2 |
