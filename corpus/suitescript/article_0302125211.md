The campaign channel record helps you refine the campaign channel for a marketing campaign.

For help working with this record in the UI, see [Campaign Channels](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N987856.html).

The internal ID for this record is `campaignchannel`.

This record contains the following subrecord: eventtype

Note:

For information about using the SuiteScript Records Browser, see [Working with the SuiteScript Records Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N3169369.html) in the NetSuite Help Center.

## Supported Script Types {#subsect_40125856957}

The campaign channel record is scriptable in both client and server SuiteScript.

## Supported Functions {#subsect_82125901909}

The campaign channel record supports the following functions: create, read, update, and delete. The following functions aren't supported: copy, search, and transform.

## Prerequisites {#subsect_58125905555}

You must enable the Marketing Automation feature before you can use this record with SuiteScript. For more information, see [Marketing Automation Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N973384.html).

## Additional Details {#subsect_59125909201}

The eventType field can't be updated.

## Code Samples {#subsect_9125912588}

The following samples show common actions with campaign channel scripting.

### Create script example: {#subsect_0302010123}

              `var record = nlapiCreateRecord('campaignchannel', true); record.setFieldValue('description', 'Test description'); record.setFieldValue('name', 'Test name'); record.setFieldValue('inactive', 'F'); record.setFieldText('eventtype', 'Direct Mail'); var recordId = nlapiSubmitRecord(record);` 
            

### Update script example: {#subsect_0302010154}

              `record = nlapiLoadRecord('campaignchannel', recordId); record.setFieldValue('description', 'Test description updated'); record.setFieldValue('name', 'Test name updated'); record.setFieldValue('inactive', 'T'); recordId = nlapiSubmitRecord(record);` 
            

### Delete script example: {#subsect_0302010237}

              `nlapiDeleteRecord('campaignchannel', recordId);`
