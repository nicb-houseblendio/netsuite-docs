You must set the file type by passing in a [file.Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4228999954.html) enum value to [file.create(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4223861820.html). |
