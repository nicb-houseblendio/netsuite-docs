| **Method Description** | Creates a new record asynchronously by copying an existing record in NetSuite. Note: The parameters and errors thrown for this method are the same as those for [record.copy(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4267258260.html). For more information about promises, see [Promise Object](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4387812940.html). |

| **Synchronous Version** | [record.copy(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4267258260.html) |

## Parameters {#bridgehead_4601399636}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description | Since |
| --- | --- | --- | --- | --- |
| `options.type` | string | required | The record type. Use the following guidelines:
-   When copying an instance of a standard NetSuite record type, set this value by using the [record.Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4273205732.html) enum.
-   When copying an instance of a custom record type, set this value by using the custom record type's string ID. For help finding this ID, see [Custom Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3204194.html).

 | 2015.2 |
| `options.id` | number | required | The internal ID of the existing record instance in NetSuite. | 2015.2 |
| `options.isDynamic` | boolean | optional | Determines whether the new record is created in dynamic mode.

-   If set to `true`, the new record is created in dynamic mode.
-   If set to `false`, the new record is created in standard mode.

By default, this value is `false`. Note: For additional information about standard and dynamic mode, see [record.Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4205869719.html) and [SuiteScript 2.x Standard and Dynamic Modes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1524156901.html). | 2015.2 |
| `options.defaultValues` | Object | optional | Name-value pairs containing default values of fields in the new record. By default, this value is null. | 2015.2 |
