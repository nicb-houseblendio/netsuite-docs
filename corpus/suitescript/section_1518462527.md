Use the following UI components to build a custom assistant.

## Fields {#subsect_1522095722}

Use fields to display and collect data. Fields are added to the current step as needed. For more information, see [Assistant.addField(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4332747915.html).

## Field Groups {#subsect_1522095741}

Use field groups to organize fields in a step. For more information, see [Assistant.addFieldGroup(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4332762451.html).

Field groups can be collapsed to save space on the page. For more information, see [FieldGroup.isCollapsed](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4335356208.html) and [FieldGroup.isCollapsible](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4335348134.html).

## Sublists {#subsect_1522095764}

Use a sublist to show the results of a saved search.

Note:

INLINEEDITOR is the only sublist type supported by the assistant page type.

For more information, see [Assistant.addSublist(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4333407203.html).

## Buttons {#subsect_1522095781}

Unlike form and list page types, you don't need to add buttons to an assistant. Buttons are generated automatically.

## Steps {#subsect_1520883623}

Steps are the main UI components in an assistant because they define each page. You can set step sequence, placement, and positioning with these properties.

-   To add a step to your assistant, see [Assistant.addStep(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4332773236.html).
    
-   To indicate whether the steps must be completed in a particular order, see [Assistant.isNotOrdered](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4333544993.html).
    
    Note:
    
    Ordered steps appear vertically along the left side. Unordered steps show up horizontally at the top of the assistant.
    
-   To add help text to your steps, see [AssistantStep.helpText](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4334438434.html).
