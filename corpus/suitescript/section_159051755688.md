## Parameters {#subsect_159051756270}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.children` | Array<[workbook.DataDimension](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008172142.html) | [workbook.CalculatedMeasure](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163169891173.html) | [workbook.DataMeasure](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163170291911.html) | [workbook.Section](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008446199.html)\> | required | The child data. |
| `options.totalLine` | [workbook.TotalLine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159059291106.html) | optional | Predefined format values for the total line. |

## Errors {#subsect_159051756713}

| Error Code | Thrown If |
| --- | --- |
| `INVALID_TOTAL_LINE` | The value specified for the `options.totalLine` parameter is invalid. Set this parameter value using [workbook.TotalLine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159059291106.html). |
