| **Method Description** | Asynchronously returns the embeddings from the LLM for a given input. Important: Embeddings include the semantic information of the original data and should be treated with the same level of sensitivity. Embeddings created from sensitive data must be protected, stored, logged, shared, retained, and deleted according to the same rules as the original data. Note: The parameters and errors thrown for this method are the same as those for [llm.embed(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_76083302199.html). For more information about promises, see [Promise Object](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4387812940.html). |
