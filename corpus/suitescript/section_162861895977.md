## Parameters {#subsect_162861896500}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.rules` | [workbook.ConditionalFormatRule](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163170087636.html)\[\] | required | The style rules to use for this conditional format. |

## Errors {#subsect_162861896953}

| Error Code | Thrown If |
| --- | --- |
| `NO_RULE_DEFINED` | The `options.rules` parameter is an empty array. |
