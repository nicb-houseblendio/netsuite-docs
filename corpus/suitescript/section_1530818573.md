| **Method Description** | Creates a join relationship. Use the method [query.create(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510275581.html) to create your initial query definition ([query.Query](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510275177.html)). The initial query definition uses one query type. For available query types, see [query.Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510878994.html). After you create the initial query definition, use [Query.autoJoin(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530819144.html) to create your first join ([query.Component](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510779141.html)). Then use `Component.autoJoin(options)` to create each subsequent join ([query.Component](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510779141.html)). Important: The N/query module supports the same record types that are supported by the SuiteAnalytics Workbook interface. For more information, see [Available Record Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1543418356.html). |

## Parameters {#subsect_1530818760}

Note:

The `options` parameter is a JavaScript object.

| Parameter | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| `options.fieldId` | string | required | The ID of the field that joins the parent component to the new component. Obtain this value from the Records Catalog. The Records Catalog lists every record type and field that is available using SuiteAnalytics Workbook and the N/query module. For more information, see [Records Catalog Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_159367781370.html). |

## Errors {#subsect_1531770422}

| Error Code | Thrown If |
| --- | --- |
| `RELATIONSHIP_ALREADY_USED` | The specified join relationship already exists. |
