The content in this help topic pertains to SuiteScript 2.1.

| **Property Description** | The list of citations used to generate the response. This property is an array of [llm.Citation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_56082143862.html) objects, each of which represents relevant information that was taken from a document provided to [llm.generateText(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1014032554.html) or [llm.generateText.promise(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1014100301.html). This property has a value only if a provided document was used to generate the response. |
