Note:

The content in this help topic pertains to SuiteScript 2.1.

| **Method Description** | Creates a chat message based on a specified role and text. Chat messages can be used in the `chatHistory` parameter of the [llm.generateText(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1014032554.html) method. Supported roles are defined by the [llm.ChatRole](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1015044805.html) enum. |
| --- | --- |
| **Returns** | [llm.ChatMessage](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1015043130.html) |
| **Supported Script Types** | Server scripts For more information, see [SuiteScript 2.1 Script Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4387172495.html). |
| **Governance** | None |
| **Module** | [N/llm Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_9123730083.html) |
| **Since** | 2024.1 |

## Parameters {#subsect_5154915380}

| Parameter | Type | Required / Optional | Description | Since |
| --- | --- | --- | --- | --- |
| `options.role` | string | required | Author of the message (as a role). Use [llm.ChatRole](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1015044805.html) to set the value. | 2024.1 |
| `options.text` | string | required | Text of the chat. | 2024.1 |
