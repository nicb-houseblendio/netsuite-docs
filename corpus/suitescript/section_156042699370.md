SuiteScript 2.1 runs on the GraalVM runtime engine, so it supports the ECMAScript features that Graal does (ES2019). For example, SuiteScript 2.1 includes support for constants, block-scoped variables and functions, customizable iterator behavior, typed arrays, and more. You can take advantage of these features when you write SuiteScript 2.1 scripts. Also consider converting your existing SuiteScript 2.0 scripts to SuiteScript 2.1, since some of these new features may help you improve performance or refactor your code.

The following sections include examples of using ECMAScript features supported in SuiteScript 2.1:

-   [Spread Operator](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_156632282242.html)
    
-   [Classes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_158271579250.html)
    
-   [Destructuring](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_158271661119.html)
    
-   [Rest Operator](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_158271677319.html)
    
-   [Asynchronous Server-Side Promises](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_160883795035.html)
    
-   [Additional ECMAScript Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_75145948396.html)
    

For more information about new language features, see [JavaScript language resources](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Language_Resources).
