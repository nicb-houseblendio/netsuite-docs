You can use record localization context in user event and client scripts to filter script run by localization context. In SuiteFlow, you can use record localization context to filter which workflows run.

Developers can use this feature to customize scripts for certain countries and keep them from running on records from other countries.

A record's localization contexxt shows which country or countries are linked to that record.

For more information about Record Localization Context, see [Record Localization Context](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_157847236329.html).
