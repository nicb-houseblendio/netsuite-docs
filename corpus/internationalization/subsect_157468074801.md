In NetSuite, a big part of internationalization is about formatting. Dates, times, phone numbers, and order totals have to be formatted according to the chose locale. For example, every account gets a standard address form that's set as the default for all countries. However, if you have customers in different countries, you can send them documents with addresses formatted for their country.

-   For more information about customizing date formats, see [Formatting for Dates, Numbers, Phone Numbers, and Time](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N249143.html).
    
-   For more information about currencies, see [Currency Management](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N1395057.html).
    
-   For more information about customizing address forms, see [Customizing Address Forms](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2874310.html).
    
-   For more information about formatting support, see [International Formatting Support](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_158572286697.html).
