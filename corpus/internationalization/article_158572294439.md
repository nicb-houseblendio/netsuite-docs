Custom fields set to Phone Number use local formatting if you enable the Phone Number Formatting feature in your account. The Country field in your subsidiary defines which local formatting is used.

NetSuite supports worldwide phone number formatting for all countries in the UI and SuiteScript. This covers any phone number you enter on records, forms, and anywhere else in NetSuite.

For the full list of supported countries and their country codes, see [List of Supported Countries](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161304811431.html).

Only administrators can enable this feature.

For backward compatibility, you can hide the +1 international prefix. For more information, see [Hiding the +1 Country Calling Code for Countries Using This Prefix](#bridgehead_162687861332).

To enable worldwide phone number formatting, go to _Setup > Company > Enable Features_ and check **Worldwide Support for Phone Number Formatting** inn the **International** section.

When you enter a phone number in NetSuite, it's formatted using these rules:

-   NetSuite checks your subsidiary's country against the phone number you enter.
    
-   If you enter the number in international format and it's from your subsidiary's country, NetSuite leaves out the country code and formats it using national standards.
    
-   If you enter the number in international format and it's form another country, NetSuite keeps it in international format and uses that country's standards.
    
-   If you enter the number in national format, NetSuite formats it for your subsidiary's country.
    

Note:

This feature only formats valid phone numbers. If you enter an invalid number, like all zeroes, the number won't be formatted.

Phone number formatting only happens after you open the record and access or edit the phone number field. The field can be up to 32 characters long.

This feature doesn't change phone numbers already saved in NetSuite. They're only reformatted if you open the record and access or edit the field.

This feature supports these phone number formats:

-   Local phone numbers
    
-   Area phone numbers
    
-   National phone numbers
    
-   International phone numbers
    
-   Special phone numbers
    
-   Emergency service phone numbers
    
-   Phone numbers with letters and numbers

## Hiding the +1 Country Calling Code for Countries Using This Prefix {#bridgehead_162687861332}

You can hide the +1 country code in phone numbers if you meet both of these requirements:

-   You use the Worldwide Support for Phone Number formatting feature.
    
-   Your company is in a country that uses the +1 country code.
    

The +1 code is used in the USA, Canada, and in some Caribbean, and British Overseas Territories.

This update helps with backward compatibility for users of the Worldwide Support for Phone Number Formatting feature.

To hide the +1 code, go to _Setup > Company > General Preferences_ and check **Use phone numbers without the +1 international country calling code**.

Note:

If you don't have Worldwide Support for Phone Number Formatting enabled, you won't see the option to use phone numbers without the +1 code.
