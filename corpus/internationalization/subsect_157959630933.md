You can use the localization context feature with these types of scriptable standard records:

-   Item
    
-   Transaction
    
-   Entity
    
-   Tax Code
    
-   Tax Type
    
-   Subsidiary
    
-   Account
    

You can use tax code and tax type records with record localization context in NetSuite.

You can create or view tax types and tax codes by going to _Setup > Accounting_.

For tax types, the record localization context comes from the **Country** field you select when creating the Tax Type.

For tax codes, the record localization context comes from the **Country** field of the Tax Type linked to the Tax Code.

Account and subsidiary records can use record localization context in scripts and workflows.

You can create or view accounts and subsidiaries by going to _Setup > Company > Subsidiary Settings Manager_.

For accounts, the record localization context comes from the **Country** field of account's subsidiary.

For subsidiaries, the record localization context comes from their **Country** field.

For a full list of records that support localization context, see [Records that Support Localization Context](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157496034201.html#subsect_157607681264).
