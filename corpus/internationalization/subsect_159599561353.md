Use the Record Localization Context API in SuiteScript 2.0. The `N/recordContext` module lets you set record localization context for supported record types.

For more information, see [N/recordContext Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158627324548.html).

For a full list of supported record types, see [Records that Support Localization Context](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157496034201.html#subsect_157607681264).

For more information about Record Localization Context, see [Localization Context](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_158572284997.html).
