SuiteCloud Software Development Kit (SuiteCloud SDK) are the tools that allow you to customize accounts through SuiteCloud Development Framework (SDF).

Use the SDK tools to work with an IDE plug-in or an extension to develop SuiteCloud projects. If you're familiar with an IDE or a code editor of your choice, use SuiteCloud Command Line Interface (SuiteCloud CLI) through a terminal to develop SuiteCloud projects.

The following tools are available:

-   To use a plug-in developed for a specific IDE or to use an extension, see [SuiteCloud Plug-ins and Extensions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156026287422.html).
    
-   To use a CLI, see [SuiteCloud CLIs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156026261619.html).
    

For a list of the available features for each tool, see [Overview of Features by Tool](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0131060804.html).

Important:

Before using any of the SuiteCloud SDK tools, ensure that your role fulfills all the requirements. For more information, see [Assigning the Developer Role (Administrator Only)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4724921075.html).

## Sample projects {#subsect_0722024517}

If you're not familiar with how SuiteCloud projects work, you can download sample projects that are ready to be used. You can modify the SuiteScript files, SDF custom objects, and all the files in the projects as you see fit. For more information, see [SuiteCloud Customization Tutorials](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_159163143019.html).

Important:

To work with these SuiteCloud projects in SuiteCloud CLI for Node.js, first run `suitecloud project:create` to create a SuiteApp project. Then, download a ZIP file from the Help Center and extract its contents in the src folder of the SuiteApp you created.
