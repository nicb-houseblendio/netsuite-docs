#### To install SuiteCloud Extension for Visual Studio Code:

Note:

To set up a proxy server, create the SUITECLOUD\_PROXY environment variable. The variable value must include an http or https protocol, a hostname, and a port number, for example: http://proxyurl:proxyport. After you create the variable, restart VS Code.

1.  Open VS Code and click the **Extensions** tab (![Extensions icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/SuiteCloudSDK/SuiteCloudIDE/SuiteCloudIDEforVSCode/VSCodeExtensionsLogo.png)).
    
2.  In the search field, type **SuiteCloud Extension for Visual Studio Code**. To find it easily, check that the publisher is Oracle Corporation.
    
3.  Under the extension's description, click **Install**.
    
4.  After SuiteCloud Extension for VS Code is installed, restart VS Code to ensure the installation process is successful.
