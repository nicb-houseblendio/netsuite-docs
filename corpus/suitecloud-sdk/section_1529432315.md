Make sure you've got the following prerequisites before you install and use WebStorm with the IDE plug-in:

-   **Operating system and browser** - Make sure the operating system version that you want to use with the WebStorm plug-in is supported.
    
    For more information, see [Supported Operating Systems for SuiteCloud IDE Plug-in for WebStorm](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1529432517.html).
    
-   **Java SE Development Kit** - The IDE plug-in requires [Oracle JDK version 17](https://www.oracle.com/java/technologies/downloads/#java17) or [Oracle JDK version 21](https://www.oracle.com/java/technologies/downloads/#java21).
    
-   **64-bit requirements** - To run the 64-bit version of the WebStorm plug-in, make sure your operating system and Java versions are both 64-bit versions.
    
-   **Two-factor authentication setup** - If you want to use an administrator role and any other role that requires 2FA for SDF development, install the SuiteCloud Development Integration bundle to your account.
    
    For more information about using a role that needs 2FA for SDF development, see [SuiteCloud IDE Plug-in for WebStorm Account Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530731998.html).
    
-   **SuiteCloud Development Framework (SDF) enabled** - Make sure SDF is enabled in your NetSuite account by checking the SDF box in _Setup > Company > Enable Features_, click the **SuiteCloud** subtab, and check the **SuiteCloud Development Framework** box on the **SuiteCloud Development Framework** section.
    
-   **NetSuite account features** - An account administrator must enable the features in your account that SDF depends on.
    
    For more information, see [Enabling SuiteCloud Development Framework in the Target NetSuite Account (Administrator Only)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4724921034.html).
    
-   **Account** - Your WebStorm plug-in version should match your NetSuite account version. You might run into compatibility issues if you use an older version of the WebStorm plug-in with the latest version of NetSuite.
    
-   **OAuth 2.0 enabled** - Make sure OAuth 2.0 is enabled in your NetSuite account. To enable the OAuth 2.0 feature, go to _Setup > Company > Enable Features_, click the **SuiteCloud** subtab, and check the **OAuth 2.0** box on the **Manage Authentication** section. For more information, see [Enable the OAuth 2.0 Feature](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157771482304.html).
    
-   **WebStorm** - The IDE plug-in needs WebStorm version 2026.2.x.
    

For more information, see the following topics:
