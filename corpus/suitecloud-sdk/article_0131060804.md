Here's a list of the available features for each tool in the table below.

Note:

The information in the table below is for the latest version of each tool.

| Feature | SuiteCloud Extension for Visual Studio Code (VS Code) | SuiteCloud IDE Plug-in for WebStorm | SuiteCloud CLI for Node.js | SuiteCloud CLI for Java |
| --- | --- | --- | --- | --- |
| AI - SuiteCloud Developer Assistant | Available | Not available | Not available | Not available |
| Authenticate (browser-based and machine-to-machine account set up) | Available | Available | Available | Available |
| Manage authentication IDs | Available | Available | Available | Available |
| Create project (for ACPs and SuiteApps) | Available | Available | Available | Available |
| Unit testing with Jest | Available | Available\* | Available | Not available |
| Create object | Not available | Available | Not applicable | Not applicable |
| Import object | Available | Available | Available | Available |
| Import custom record instances | Available | Available | Available | Available |
| Update object | Available | Available | Available | Available |
| List object | Available | Available | Available | Available |
| Compare object | Available | Available | Not applicable | Not applicable |
| Create file | Available | Available | Available | Available |
| Import file | Available | Available | Available | Available |
| Upload file | Available | Available | Available | Available |
| List file | Available | Available | Available | Available |
| Compare file | Available | Available | Not applicable | Not applicable |
| Upload folder | Not available | Available | Not available | Available |
| Add dependencies | Available | Available | Available | Available |
| Code completion (for SuiteScript files) | Not available | Available | Not applicable | Not applicable |
| Dry run/Preview | Not available | Available\* | Available | Available |
| Run debug configuration | Not available | Available | Not available | Not available |
| Package project | Not available | Available | Available | Available |
| Validate locally | Not available | Not available | Not available | Available |
| Validate server-side | Available | Available | Available | Available |
| Deploy | Available | Available | Available | Available |
| Account specific values (for ACPs) | Available | Available | Available | Available |
| Create installation preferences file (for SuiteApps) | Not available | Available | Not applicable | Not applicable |
| Apply installation preferences (for SuiteApps) | Available | Available | Available | Available |
