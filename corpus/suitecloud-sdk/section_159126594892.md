SuiteCloud IDE plug-in for WebStorm lets you customize the configuration for SuiteCloud projects. The settings you pick apply to all SuiteCloud projects you work on with in the IDE.

Note:

You can have more than one SuiteCloud project open in a WebStorm window.

The following options are available:

-   **Global Settings:** **Automatic Add Dependencies**. If your project is missing any dependencies, they're automatically added when you deploy the project.
    
-   **Skip Warnings**
    
    -   **Deploy to Production**: When deploying a project, skip the confirmation message for deploying to a production account.
        
    -   **Overwrite Custom Objects in Project**: When you import SDF custom objects, skip the confirmation message to overwrite the selected SDF custom objects in your project with the matching ones from your account.
        
    -   **Overwrite Files in Project**: When importing files, skip the confirmation message to overwrite the selected files in your project with the SuiteScript files from your account.
        

#### To customize your SuiteCloud project configuration:

1.  Depending on your operation system, do one of the following in WebStorm:
    
    -   If you're on Windows OS, select **File** > **Settings** > **Tools** > **NetSuite** > **Account Management**.
        
    -   If you're on macOS, select **WebStorm** > **Preferences** > **Tools**\> **NetSuite**.
        
2.  Select the options you want to enable, then click **OK**.
