You can compare the XML definition of an SDF custom object with the XML version of an account object. You can only compare objects if they have the same script ID and are the same object type.

#### To compare an SDF custom object with an object from the account:

1.  In WebStorm, open your SuiteCloud project and expand the **Objects** folder.
    
2.  Right-click the object file and choose **NetSuite** > **Compare with Account Object**.
    
    The side-by-side comparison window appears if an object with the same script ID exists in your NetSuite account, and the differences between the two objects are highlighted.
