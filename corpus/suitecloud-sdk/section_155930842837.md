Before you start working with SuiteCloud CLI for Node.js, you need to run `suitecloud account:setup` in your project folder.

If you don't have a project yet, run `suitecloud project:create -i`, then run `suitecloud account:setup`.

Important:

Make sure your role is set up for SDF development. For more information, see [Assigning the Developer Role (Administrator Only)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4724921075.html).

To see how to install and set up SuiteCloud CLI for Node.js, watch the following video:

<a id="kaltura_player_299"></a>

#### To set up SuiteCloud CLI for Node.js

1.  Launch your preferred command-line interpreter.
    
2.  Go to the folder of an existing project on your machine.
    
3.  In your project folder, run `suitecloud account:setup` and answer the questions in SuiteCloud CLI.
    
    ![Output appearing when setting up an account.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/SuiteCloudSDK/SuiteCloudCLI/CLINodejs/CLIforNodejsSetupaccount.png)
    
    Tip:
    
    To exit the process at any time, press Ctrl + C.
