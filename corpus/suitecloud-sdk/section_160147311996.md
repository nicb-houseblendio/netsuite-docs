You can customize SDF custom objects by downloading their XML definitions from your account. The XML files are converted into SDF custom objects when you deploy them to your NetSuite account.

To see how to download XML definitions of objects, see [Downloading the XML Definition of an Object from a NetSuite Account](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4738151284.html).

The following actions are available for working with SDF custom objects:

-   [Listing SDF Custom Objects in SuiteCloud Extension for Visual Studio Code](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_160163955513.html)
    
-   [Updating SDF Custom Objects in SuiteCloud Extension for Visual Studio Code](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_160147382361.html)
    
-   [Importing SDF Custom Objects from a NetSuite Account with SuiteCloud Extension for Visual Studio Code](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162971830372.html)
