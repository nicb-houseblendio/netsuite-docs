You can upload files to your account's File Cabinet without having to deploy the whole project. The files need to be in a File Cabinet folder supported by SDF. Depending on your SuiteCloud project type, these folders are supported.

-   `SuiteScripts`
    
-   `SuiteApps/<Application ID>`
    
    Note:
    
    For more information about the Application ID, see [SuiteApp Application ID](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1509931104.html#subsect_1522775442).
    
-   Templates
    
-   Web Site Hosting Files
    

#### To upload a file from your SuiteCloud project to your account:

1.  In VS Code, open the file you want to upload to the File Cabinet.
    
2.  Open the Command Palette and type `suitecloud`.
    
    From the dropdown, pick **SuiteCloud: Upload File**.
    
3.  From the dropdown, choose whether to overwrite your File Cabinet file with the project version.
    
    Note:
    
    If you click **Cancel** when prompted, the upload process is canceled.
    
    The file open in the editor is overwritten in the File Cabinet.
    

If the folder containing the file didn't exist in the account, SDF creates it during the upload process.
