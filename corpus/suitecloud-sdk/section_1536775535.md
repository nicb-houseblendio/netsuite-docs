SDF custom objects are created when XML representations in a SuiteCloud project get deployed to your NetSuite account.

You can customize SDF custom objects by downloading XML definitions of those objects from your account, importing them, or creating new representations. The XML files get converted into SDF custom objects when you deploy them to your NetSuite account.

For more information, check out these topics to learn more about working with SDF custom objects using SDF:

-   [Downloading the XML Definition of an Object from a NetSuite Account](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4738151284.html)
    
-   [Creating an XML Definition for an SDF Custom Object in SuiteCloud IDE Plug-in for WebStorm](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1536776224.html)
    
-   [Comparing an SDF Custom Object with an Object from the Account in SuiteCloud IDE Plug-in for WebStorm](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1538083707.html)
    
-   [Comparing a SuiteCloud Project File with its Equivalent Account Version in SuiteCloud IDE Plug-in for WebStorm](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1538083718.html)
