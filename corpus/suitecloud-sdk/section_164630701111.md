You can manage the authentication IDs linked to your accounts by renaming or removing them, and you can also view the details of any specific auth ID.

#### To rename an auth ID:

1.  In VS Code, open the Command Palette and type `suitecloud`.
    
2.  From the dropdown list, pick **SuiteCloud: Manage Accounts**.
    
3.  Pick the account you want to manage.
    
4.  Choose the **Rename** option.
    
5.  Enter the new auth ID when prompted.
    
6.  Click **See Details** to check the log output.
    

#### To remove an auth ID:

1.  In VS Code, open the Command Palette and enter `suitecloud`.
    
2.  From the dropdown list, select **SuiteCloud: Manage Accounts**.
    
3.  Select the account you want to manage.
    
4.  Choose the **Remove** option.
    
5.  Click **Continue** when prompted to confirm that the auth ID will be removed from your computer but is still valid in your account.
    
6.  Select **See Details** to check the log output.
    

#### To see the details of an auth ID:

1.  In VS Code, open the Command Palette and enter `suitecloud`.
    
2.  From the dropdown list, select **SuiteCloud: Manage Accounts**.
    
3.  Choose the **Show Details** option.
    
4.  Click **See Details** to check the auth ID details.
