You can overwrite a file in your project with the matching file from your account.

#### To update a file from your account:

1.  In VS Code, open the Command Palette and type `suitecloud`.
    
2.  From the dropdown, pick **SuiteCloud: Update File from Account**.
    
3.  Choose whether to exclude all file properties within the `.attributes` folder.
    
4.  Choose whether to overwrite the selected file in your project
    
    Note:
    
    If you click **Cancel** when prompted, the update process is canceled.
    
    The selected file is updated.
