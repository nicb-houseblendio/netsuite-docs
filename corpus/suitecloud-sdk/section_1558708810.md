Verify the following prerequisites before you install SuiteCloud CLI for Node.js:

-   **Java SE Development Kit**: SuiteCloud CLI for Node.js requires [Oracle JDK version 17](https://www.oracle.com/java/technologies/downloads/#java17) or [Oracle JDK version 21](https://www.oracle.com/java/technologies/downloads/#java21).
    
-   **Node.js**: SuiteCloud CLI for Node.js requires [Node.js version 24 LTS](https://nodejs.dev/en/download/).
    
-   **Operating system**: SuiteCloud CLI for Node.js officially supports the following operating systems:
    
    -   Windows
        
    -   macOS
        
    -   Linux
        
    
    Specifically, it was tested with the following operating system and browser combinations:
    
    -   Windows 11 - Firefox and Chrome
        
    -   Linux Fedora - Firefox, Chrome
        
    -   macOS Sequoia - Firefox, Safari, and Chrome
        
-   **SuiteCloud Development Framework (SDF) enabled**: Ensure SDF is enabled in your NetSuite account. Go to _Setup > Company > Enable Features_, click the SuiteCloud subtab, and check the SuiteCloud Development Framework box.
    
-   **NetSuite account features**: An account administrator must enable the features in your account that SDF depends on.
    
    For more information, see [Enabling SuiteCloud Development Framework in the Target NetSuite Account (Administrator Only)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4724921034.html).
    
-   **NetSuite permissions**: An account administrator must create and assign the SDF Developer role to your account.
    
    For more information, see [Assigning the Developer Role (Administrator Only)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4724921075.html).
    
-   **OAuth 2.0 enabled**: Ensure OAuth 2.0 is enabled in your NetSuite account. To enable it, go to _Setup > Company > Enable Features_, click the **SuiteCloud** subtab, and check the **OAuth 2.0** box on the **Manage Authentication** section. For more information, see [Enable the OAuth 2.0 Feature](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157771482304.html).
