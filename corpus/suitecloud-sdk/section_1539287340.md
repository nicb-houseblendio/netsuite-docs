You can use keymaps to trigger these SDF functions:

| Function | Key Combination |
| --- | --- |
| Windows | Mac OS | Linux |
| --- | --- | --- |
| Add Dependency References to Manifest | Ctrl+Alt+Shift+A | Cmd+Alt+Shift+A | Ctrl+Alt+Shift+A |
| Compare with Account File | Alt+Shift+E | Alt+Shift+E | Alt+Shift+E |
| Deploy | Ctrl+Alt+D | Cmd+Ctrl+Alt+D | Alt+D |
| Deploy to Account... | Ctrl+Alt+Shift+D | Cmd+Alt+Shift+D | Shift+D |
| Import Files from Account... | Ctrl+Alt+F | Cmd+Alt+F | Ctrl+Alt+F |
| Import Objects from Account... | Ctrl+Shift+O | Cmd+Ctrl+Alt+O | Ctrl+Alt+O |
| NetSuite Settings | Ctrl+Alt+N | Cmd+Option+N | Ctrl+Alt+N |
| Upload File(s) to Account | Alt+Shift+U | Alt+Shift+U | Alt+Shift+U |
| Update with Account Object(s) | Ctrl+U | Cmd+U | Ctrl+U |
| Validate | Ctrl+Alt+V | Cmd+Alt+V | Ctrl+Alt+V |
| Validate to Account... | Ctrl+Alt+Shift+V | Cmd+Alt+Shift+V | Ctrl+Alt+Shift+V |

Note:

For more information about general keyboard shortcuts, see [Keyboard Shortcuts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N474926.html).
