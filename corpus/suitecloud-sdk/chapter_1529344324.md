SuiteCloud IDE plug-in for WebStorm is installed from within the WebStorm client. After you download and install WebStorm, you can add the IDE plug-in update site to your list of software updates.

To see how to install WebStorm and SuiteCloud IDE plug-in for WebStorm, check out the help video [SuiteCloud Development Framework: Installing SuiteCloud IDE Plug-in for WebStorm](https://videohub.oracle.com/media/SuiteCloud+Development+FrameworkA+Installing+SuiteCloud+IDE+for+WebStorm/1_6pac06xz?ed=189).
