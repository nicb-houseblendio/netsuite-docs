You can set dependencies on existing objects, files, and scripts from your NetSuite accounts in an account customization project (ACP). You can also set dependencies on objects in a SuiteApp that are outside your SuiteCloud project, if they're supported by SDF.

For more information about dependencies, see the following topics:

-   [Customizations Supported by SuiteCloud Development Framework](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4706653920.html)
    
-   [Account Component Dependencies in SuiteCloud Projects](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4720575592.html)
    
-   [SDF Custom Object Dependencies in SuiteApps](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1517248350.html)
    
-   [Specifying an SDF Custom Object Reference](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_24076946.html#subsect_1523297346)
    
-   [Manually Defining Account Component Dependencies in the Account Customization Project Manifest](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1523378695.html)
    
-   [Manually Defining Feature Dependencies in the SuiteCloud Project Manifest](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1523379149.html)
    

When you use SDF with NetSuite features like SuiteScript or custom records, you need to define the dependencies in your SuiteCloud project. For more information, see [Feature Dependencies for SDF Custom Objects in SuiteCloud Projects](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4718752626.html).

#### To add dependencies to the manifest:

1.  In VS Code, open the Command Palette and type `suitecloud`.
    
2.  From the dropdown, pick **SuiteCloud: Add Dependency References to the Manifest**.
    
    If your project is missing any dependency references, they'll be added to the `manifest.xml` file.
    
    Tip:
    
    You can also use these keyboard shortcuts to add dependencies:
    
    -   Linux: Press Ctrl+Shift+Alt+A
        
    -   Mac OS: Press Ctrl+Alt+Cmd+A
        
    -   Windows: Press Ctrl+Shift+Alt+A
        
    

Note:

To track the progress of adding dependencies to the manifest, refer to the terminal output.
