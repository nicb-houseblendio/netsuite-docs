Adds any missing dependencies to the manifest file. When you run this command, all the dependencies that were missing in the `manifest.xml` file get added.

Note:

This command doesn't support interactive mode.

## Syntax {#subsect_155981602453}

            `suitecloud project:adddependencies [-h]` 
          

## Options {#subsect_155981604035}

| Option | Required / Optional | Description |
| --- | --- | --- |
| \-h or --help | Optional | Prints the help for this command. |

## Example {#subsect_155981607188}

Here's a command that updates the `manifest.xml` file of the current project:

            `suitecloud project:adddependencies` 
          

## Output Example {#subsect_156353294091}

When you run the command, it produces an output that is similar to the following:

            `The following dependencies were added to the manifest: Feature - CRM:optional Feature - CUSTOMRECORDS:required Feature - EXTREMELIST:optional Feature - MAILMERGE:optional Feature - MATRIXITEMS:optional Feature - SERVERSIDESCRIPTING:required Feature - WEBSERVICES:optional`
