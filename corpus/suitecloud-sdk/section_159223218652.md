#### To download Visual Studio Code:

1.  Download VS Code for your operating system from [https://code.visualstudio.com](https://code.visualstudio.com/). For supported versions that work with SuiteCloud Extension for VS Code, see [Installation Prerequisites for SuiteCloud Extension for Visual Studio Code](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159223197655.html).
    
2.  Run the file you downloaded and follow the prompts to complete installation.
    

Next, install SuiteCloud Extension for VS Code. For more information, see [Installing SuiteCloud Extension for Visual Studio Code](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159223240436.html).
