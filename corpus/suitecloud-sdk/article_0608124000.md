You can compare a file on your computer with its account version. The differences show up in split editors. The files you compare need to be in the File Cabinet directory.

#### To compare a local file with its account version: {#procedure_0713042841}

1.  In VS Code, open the local file you want to compare with its account version.
    
2.  Open the Command Palette and type `suitecloud`.
    
3.  From the dropdown, pick **SuiteCloud: Compare with Account File**.
    
    Tip:
    
    You can also use the context menu by right-clicking the file name in the left-hand menu.
    
    The editor shows both versions and highlights the differences between them.
