SuiteCloud Extension for Visual Studio Code (VS Code) provides a user interface for NetSuite platform development using SuiteCloud Development Framework (SDF). SDF is a development framework and deployment mechanism.

To get started with SuiteCloud Extension for VS Code, see [Installing and Setting Up SuiteCloud Extension for Visual Studio Code](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_159223155621.html).

Here's what you can do in SuiteCloud Extension for VS Code for SuiteCloud projects:

-   To create a SuiteCloud project, see [Creating a SuiteCloud Project in SuiteCloud Extension for Visual Studio Code](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162938506015.html).
    
-   To set up a NetSuite Account, see [Setting Up NetSuite Accounts in SuiteCloud Extension for Visual Studio Code](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160147609118.html).
    
-   To manage the authentication IDs linked to your accounts, see [Managing NetSuite Accounts in SuiteCloud Extension for Visual Studio Code](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164630701111.html).
    
-   To list the SDF custom objects used in your account, see [Listing SDF Custom Objects in SuiteCloud Extension for Visual Studio Code](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_160163955513.html).
    
-   To update the SDF custom objects in your project, see [Updating SDF Custom Objects in SuiteCloud Extension for Visual Studio Code](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_160147382361.html).
    
-   To import SDF custom objects from a NetSuite account, see [Importing SDF Custom Objects from a NetSuite Account with SuiteCloud Extension for Visual Studio Code](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162971830372.html).
    
-   To create a SuiteScript file, see [Creating a SuiteScript File in SuiteCloud Extension for Visual Studio Code](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160147328227.html).
    
-   To list the files in your account, see [Listing Files in SuiteCloud Extension for Visual Studio Code](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163067396066.html).
    
-   To update a file from your account, see [Updating a File from Your Account with SuiteCloud Extension for Visual Studio Code](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163067510539.html)
    
-   To upload files to your account, see [Uploading Files to Your Account with SuiteCloud Extension for Visual Studio Code](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161643514921.html).
    
-   To import files from a NetSuite account, see [Importing Files from a NetSuite Account with SuiteCloud Extension for Visual Studio Code](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162930381001.html).
    
-   To compare a local file with its account version, see [Comparing a Local File with its Account Version with SuiteCloud Extension for Visual Studio Code](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0608124000.html)
    
-   To add dependencies to the SuiteCloud project manifest, see [Adding Dependencies to the Manifest in SuiteCloud Extension for Visual Studio Code](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160147339580.html).
    
-   To validate your SuiteCloud project against your NetSuite account, see [Validating a SuiteCloud Project Against Your NetSuite Account with SuiteCloud Extension for Visual Studio Code](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164563201243.html).
    
-   To deploy SuiteCloud projects to your account, see [Deploying a SuiteCloud Project to Your NetSuite Account with SuiteCloud Extension for Visual Studio Code](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160147342366.html).
    
-   To view SDF logs in the output console, see [User Interface of SuiteCloud Extension for Visual Studio Code](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158400984643.html).
    
-   To use SuiteCloud Developer Assistant, an AI-powered coding assistant designed for SuiteCloud developers, see [Setting Up SuiteCloud Developer Assistant Using Cline in SuiteCloud Extension for VS Code](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1121114206.html).
