The WebStorm plug-in is installed to WebStorm as a custom plug-in. You need to download the IDE plug-in package from the SuiteCloud IDE update site. Here's what to do:

1.  [Add the SuiteCloud IDE Plug-in for WebStorm Update Site](#bridgehead_1539788784).
    
2.  [Update SuiteCloud IDE Plug-in for WebStorm](#bridgehead_1539789193).
    
3.  [Verify the Installation of SuiteCloud IDE Plug-in for WebStorm](#bridgehead_1539789400).
    

## Add the SuiteCloud IDE Plug-in for WebStorm Update Site {#bridgehead_1539788784}

When you add the SuiteCloud IDE update site to WebStorm, you can download the latest version of the IDE plug-in that is compatible with your NetSuite account as a custom plug-in. When installed, you'll have access to the IDE plug-in and SDF options in WebStorm.

#### To add the update site in SuiteCloud IDE Plug-in for WebStorm:

1.  Launch WebStorm.
    
2.  Depending on your operation system, do one of the following:
    
    -   If you're on Windows, press Ctrl+Alt+S. You can also select **File** > **Settings...**.
        
    -   If you're on macOS, press Cmd+,. You can also select **WebStorm** > **Preferences**.
        
3.  Select **Plugins**, and click ![Gear wheel icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/SuiteCloudSDK/SuiteCloudIDE/SuiteCloudIDEForWebStorm/WSmanageRepositoriesIcon.png).
    
4.  Select **Manage Plugin Repositories...**.
    
5.  In the **Custom Plugin Repositories** window, click ![Add icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/SuiteCloudSDK/SuiteCloudIDE/SuiteCloudIDEForWebStorm/IDE_WebStorm_Add_icon.png) and enter one of the following links based on your preference:
    
    The latest version of SuiteCloud IDE Plug-in for WebStorm is 2026.2 and is compatible with NetSuite 2026.2. To get it, use the following link:
    
    -   `https://system.netsuite.com/download/suitecloud-sdk/ideplugin/webstorm/26.2/updatePlugins.xml`
        
    
    If you want to get the latest updates automatically, use:
    
    -   `https://system.netsuite.com/download/suitecloud-sdk/ideplugin/webstorm/latest/updatePlugins.xml`
        
    
    If you want to use the previous version of the plug-in, use this link:
    
    -   Version 2025.2:
        
        `https://system.netsuite.com/download/suitecloud-sdk/ideplugin/webstorm/25.2/updatePlugins.xml`
        
6.  Click **OK**.
    
7.  Click the **SuiteCloud IDE Plug-in** plug-in, and click **Install**.
    
8.  Restart WebStorm.
    

## Update SuiteCloud IDE Plug-in for WebStorm {#bridgehead_1539789193}

If you already have the SuiteCloud IDE Plug-in installed, you can update it to the latest version right from WebStorm.

#### To update SuiteCloud IDE Plug-in for WebStorm:

1.  Launch WebStorm.
    
2.  Depending on your operation system, do one of the following:
    
    -   If you're on Windows OS, press Ctrl+Alt+S. You can also select **File** > **Settings...**.
        
    -   If you're on macOS, press Cmd+,. You can also select **WebStorm** > **Preferences**.
        
3.  Select **Plugins**.
    
4.  Use the search bar to find the plug-in, or use the **Show** filter after clicking the three dots.
    
5.  In the list, click **SuiteCloud IDE Plug-in**.
    
    If there's an update available, you'll see the **Update** button.
    
6.  Click **Update**, then restart WebStorm.
    

## Verify the Installation of SuiteCloud IDE Plug-in for WebStorm {#bridgehead_1539789400}

When you install SuiteCloud IDE plug-in for WeStorm, information about the SuiteCloud IDE version is added. You can check this information any time.

#### To verify the installation of SuiteCloud IDE plug-in for WebStorm:

1.  Launch WebStorm.
    
2.  Depending on your operation system, do one of the following:
    
    -   If you're on Windows OS, press Ctrl+Alt+S. You can also select **File** > **Settings...**.
        
    -   If you're on macOS, press Cmd+,. You can also select **WebStorm** > **Preferences**.
        
3.  Select **Plugins**.
    
4.  In the list, click **SuiteCloud IDE for WebStorm**.
    
    You'll see the WebStorm plug-in version information.
    
    ![SuiteCloud IDE for WebStorm plug-in details](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/SuiteCloudSDK/SuiteCloudIDE/SuiteCloudIDEForWebStorm/WebStormPluginDetails.png)
