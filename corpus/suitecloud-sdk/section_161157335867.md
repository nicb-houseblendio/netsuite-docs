You can create run/debug configurations to work with multiple accounts in SuiteCloud projects. A run/debug configuration lets you link SDF actions to a project and a specific authentication ID. This way, you'll be more efficient when working with several accounts and SuiteCloud projects.

#### To use multiple accounts with run/debug configurations:

1.  In WebStorm, go to **Run** > **Edit Configurations...**, then click ![Add icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/SuiteCloudSDK/SuiteCloudIDE/SuiteCloudIDEForWebStorm/IDE_WebStorm_Add_icon.png) and select **SuiteCloud**.
    
    The following window is displayed:
    
    ![Run/Debug Configurations screen](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/SuiteCloudSDK/SuiteCloudIDE/SuiteCloudIDEForWebStorm/WebStormRunDebugMultipleAccounts.png)
2.  From the **Action** dropdown, select the SDF action you want this configuration to use.
    
3.  In the **Project** field, pick the project for this configuration. You can:
    
    -   ![Select an SDF project open in the current WebStorm window icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/SuiteCloudSDK/SuiteCloudIDE/SuiteCloudIDEForWebStorm/selectFolderIcon.png)\- to pick a SuiteCloud project that is already open.
        
    -   ![Select an SDF project from your machine icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/SuiteCloudSDK/SuiteCloudIDE/SuiteCloudIDEForWebStorm/WebStormSelectFolder.png)\- to pick a SuiteCloud project from anywhere on your machine.
        
4.  From the **Auth ID** dropdown, select an authentication ID for this configuration.
    
    Tip:
    
    Click ![Additional Configuration icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/SuiteCloudSDK/SuiteCloudIDE/SuiteCloudIDEForWebStorm/AdditionalConfig.png) to open the **Account Management** window and add an account to your machine.
    
5.  Depending on your SuiteCloud project type, set one of the following options.
    
    -   For account customization projects - From the **Account Specific Values** dropwdown, choose whether to stop the process if the project has account-specific values.
        
    -   For SuiteApp projects - Check the **Apply Installation Preferences** box to use the settings from the InstallationPreferences folder.
        
6.  In the **Before launch** section, decide if you want to run any tools or scripts prior to launching the run/debug configuration.
