## Creating an Installation Preference File with SuiteCloud IDE Plug-in for WebStorm {#bridgehead_1539789850}

#### To create an installation preference file:

1.  Open a SuiteApp project in WebStorm.
    
2.  Right-click the **InstallationPreferences** folder and choose either **New** > **Overwriting File**, **New** > **Locking File**, or **New** > **Hiding File**.
    
    The file is created inside of the `InstallationPreferences` folder.
