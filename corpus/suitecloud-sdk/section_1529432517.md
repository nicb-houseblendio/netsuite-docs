The IDE plug-in officially supports these operating systems:

-   Windows
    
-   Linux
    
-   macOS
    

Specifically, the IDE plug-in was tested with these operating system and browser combinations:

-   Windows 11 - Firefox and Chrome
    
-   Linux Fedora - Firefox, Chrome
    
-   macOS Sequoia - Firefox, Safari, and Chrome
