If you're familiar with an IDE or a code editor of your choice, you can use SuiteCloud Command Line Interface (SuiteCloud CLI) through a terminal to develop SuiteCloud projects.

The following CLIs are available:

-   [SuiteCloud CLI for Java](#subsect_156026391487)
    
-   [SuiteCloud CLI for Node.js](#subsect_156026395014)
    

## SuiteCloud CLI for Node.js {#subsect_156026395014}

This CLI is interactive and guides you through every step of connecting your local project to your account. You can also use it for integrations and automations.

To learn more about SuiteCloud CLI, see [SuiteCloud CLI for Node.js Guide](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1558708800.html).

## SuiteCloud CLI for Java {#subsect_156026391487}

This CLI is built on Java and is optimized for integrations and automations.

To learn more about SuiteCloud CLI, see [SuiteCloud CLI for Java Guide](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4779302061.html).
