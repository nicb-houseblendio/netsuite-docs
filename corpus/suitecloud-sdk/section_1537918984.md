You can upload files or folders to your account's File Cabinet without having to deploy the whole project. The files or folders need to be in a FileCabinet folder supported by SDF. Depending on your SuiteCloud project type, these folders are supported:

-   SuiteScripts
    
-   SuiteApps/<Application ID>
    
    Note:
    
    For more information about the Application ID, see [SuiteApp Application ID](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1509931104.html#subsect_1522775442).
    
-   Templates
    
-   Web Site Hosting Files
    

To upload a file or folder from your SuiteCloud project to your account with SuiteCloud IDE plug-in for WebStorm, go to your **FileCabinet** folder.

Next, do one of the following:

-   Right-click a file and select **NetSuite** > **Upload File to Account**.
    
    For multiple files, select **NetSuite** > **Upload Files to Account**.
    
-   Right-click a folder and select **NetSuite** > **Upload Folder to Account**.
    
    For multiple folders, select **NetSuite** > **Upload Folders to Account**.
    

If a file or folder with the same FileCabinet location and name already exists in your account, it gets overwritten by the SDF file upload.

If the folder containing the file didn't exist in the account, SDF creates it during the upload process.
