You can list the files in your account's File Cabinet.

#### To list files:

1.  In VS Code, open the Command Palette and type `suitecloud`.
    
2.  From the dropdown, pick **SuiteCloud: List Files**.
    
3.  In the dropdown, pick the path where you want to list the files (for example `/SuiteScripts/`) and press Enter.
    
4.  In the **Output** tab of VS Code, you can see the list of files in your account.
