SuiteCloud CLI for Node.js works with these command-line interpreters and has been tested with them:

-   **Windows:**
    
    -   Command Prompt
        
    -   Windows PowerShell
        
    -   ConEmu
        
-   **Linux:** GNOME Terminal
    
-   **MacOS:**
    
    -   Terminal
        
    -   iTerm2
