## Changing Where Projects Open in SuiteCloud IDE Plug-in for WebStorm {#bridgehead_1542050667}

By default, the WebStorm plug-in asks if you want to open the project in the same window or a new one, but you can change this setting.

#### To always open projects in a new window:

1.  In WebStorm, select **File** > **Settings...**
    
2.  Select **Appearance & Behavior** > **System Settings**.
    
3.  Under **Project**, select **Open project in new window** to always open projects in a separate window.
    

## Turning Off Code Completion in SuiteCloud IDE Plug-in for WebStorm {#bridgehead_1542050673}

Note:

If you disable code completion, you can still get suggestions when pressing **Ctrl+Spacebar**. For information about SuiteScript code completion, see [Using SuiteScript Code Completion in SuiteCloud IDE Plug-in for WebStorm](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530903260.html).

#### To turn off code completion:

1.  In WebStorm, select **File** > **Settings...**
    
2.  Select **Editor** > **General** > **Code Completion**.
    
3.  Clear all the boxes, click **Apply**, and then **OK**.
