You can compare a file in your project's FileCabinet folder with the matching version in your account. You can only compare files if they have the same script ID and file type.

#### To compare a SuiteCloud Project File with its equivalent account version: {#procedure_0306033958}

1.  In your SuiteCloud project in the WebStorm plug-in, expand the **FileCabinet** folder or one of its subfolders.
    
2.  Right-click a file and choose **NetSuite** > **Compare with Account File**.
    
    The side-by-side comparison window appears if a file with the same script ID exists in your NetSuite account, and the differences between the two files are highlighted.
