You can use SuiteCloud IDE Plug-in for WebStorm to create SuiteApp projects, which are meant for SuiteCloud Developer Network (SDN) members building SDF SuiteApps.

Note:

By default, all SuiteApp projects created in SuiteCloud IDE plug-in for WebStorm work with SuiteScript 2.x.

For more information about SuiteApp projects, see:

-   [SuiteApp Projects](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1509931104.html)
    
-   [Differences Between SuiteCloud Projects](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1505834545.html)
    

#### To create a SuiteApp project:

1.  In WebStorm, select **File** > **New** > **Project...**.
    
2.  From the New Project dialog, select the project type: **SuiteApp**.
    
3.  Choose where you want to save your project or accept the default location.
    
4.  Set the rest of the project properties. For more information, see [Properties of a SuiteApp Project](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1509931104.html#subsect_1520876235).
    
5.  Click **Create**.
    
    When the project is created, you can choose to open it in **This Window** or a **New Window**. If there's already a SuiteCloud project open, picking **This Window** closes it and opens your new one.
    
6.  Add the domains and accounts you want to customize. For more information, see [Adding an Account in SuiteCloud IDE Plug-in for WebStorm](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1530894035.html).
    

To open an existing project, go to **File** > **Open**.
