To set up SuiteCloud IDE plug-in for WebStorm so you can create SuiteCloud projects, check out these topics:

1.  **Customize the configuration for you SuiteCloud projects.** For more information, see [Customizing SuiteCloud Project Configuration in SuiteCloud IDE plug-in for WebStorm](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159126594892.html).
    
2.  **Create or open a SuiteCloud project.** For more information, see [Creating an Account Customization Project in SuiteCloud IDE Plug-in for WebStorm](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530903289.html) or [Creating a SuiteApp Project in SuiteCloud IDE Plug-in for WebStorm](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530903307.html).
    
3.  **Connect to your accounts and roles.** For more information, see [SuiteCloud IDE Plug-in for WebStorm Account Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530731998.html).
    

Note:

To set up a different SuiteScript development environment instead of the WebStorm plug-in, see [Working with IDEs Other Than SuiteCloud IDEs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0402065535.html#subsect_90152146793).
