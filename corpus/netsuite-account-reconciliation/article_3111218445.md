Ensure you schedule deployment of the following scripts properly in your NetSuite account:

| Script Deployment Name | Script Deployment ID | Script File Name |
| --- | --- | --- |
| NSAR | Start Scheduled Jobs | customscript\_nsar\_mr\_start\_sched\_jobs | mr\_start\_scheduled\_jobs.js |
| NSAR | SS Check Job Progress | customdeploy\_nsar\_ss\_chk\_job\_progress | ss\_check\_job\_progress.js |
| NSAR | SS Cleanup | customdeploy\_nsar\_ss\_cleanup | ss\_cleanup.js |
| NSAR | SS Check/Generate OAuth Token | customdeploy\_nsar\_ss\_chk\_oauth\_token | ss\_check\_oauth\_token.js |

#### To schedule a script deployment properly for Account Reconciliation Sync:

1.  In NetSuite, go to Customization > Scripting > Script Deployments.
    
2.  Expand the Filters area if the filters are not displayed.
    
3.  From the **Script** filter, select the script deployment you want to schedule.
    
4.  Next to the script deployment, click **Edit**.
    
5.  On the **Schedule** subtab, do the following:
    
    -   Set the **Start Time** field to **12:00 am**.
        
    -   Set the **Repeat** field to **Every 2 hours** for the NSAR | SS Cleanup script and to **Every 15 minutes** for the other scripts.
        
6.  Click **Save**.
    
7.  Repeat these steps for each script deployment.
