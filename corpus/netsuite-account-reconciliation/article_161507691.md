If you have the Administrator role, you can assign roles with specific permissions to new or existing users in NetSuite. Depending on tasks the users should perform, you can assign the following roles:

-   **NSEPM Implementer Role**
    
    You assign the NSEPM Implementer role to a user who should set up and configure the Account Reconciliation Sync SuiteApp in NetSuite.
    
    For more information, see [Using the NSEPM Implementer Role](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0324112610.html).
    
-   **NSAR Integration Role**
    
    You assign the NSAR Integration role to a user who should configure the integration with your Account Reconciliation application.
    
    For more information, see [Using the NSAR Integration Role](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0324112720.html).
    

You can customize these roles to better suit your needs. For more information, see [Changing Custom Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N289485.html).

You can access some of the Account Reconciliation Sync features with other than the listed roles. For more information, see [Using Account Reconciliation Sync with Other Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0414120708.html).
