To connect a user to Account Reconciliation application from NetSuite, the Account Reconciliation Sync SuiteApp supports two types of authentication:

-   Authentication by entering a username and a password.
    
    For information, see [Using Basic Authentication to Connect to Account Reconciliation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0221061851.html).
    
-   OAuth 2.0 that eliminates the need to store user credentials in NetSuite. This provides better security and prevents integration issues when a password expires or is changed.
    
    For information, see [Using OAuth 2.0 to Connect to Account Reconciliation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0221062843.html).
    

#### To choose your preferred authentication method: {#procedure_0221060306}

1.  In NetSuite, go to NetSuite EPM > Account Reconciliation > Connection Settings.
    
2.  In the **Account Reconciliation URL** field, enter the URL that points to the Account Reconciliation application you want NetSuite to connect to.
    
    Depending on the Account Reconciliation instance, the format of the URL may look similar to one of the following examples:
    
    -   https://epm-test-idDomain.epm.dataCenterRegion.oraclecloud.com/
        
    -   https://acme-epmidm.epm.us-phoenix-1.ocs.oraclecloud.com/
        
    
    To review the URL components, see the help topic [Sample URLs](https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/cgsad/1_epm_cloud_accessing_sample_urls.html) in the Oracle Help Center.
    
3.  To verify that the Account Reconciliation application identified in the **Account Reconciliation URL** field connects to this NetSuite account, check the **Use Entered URL to Verify Inbound Connections** box.
    
    Tip:
    
    To avoid connection issues or troubleshoot:
    
    -   Go to NetSuite EPM > EPM Connector > Search Activity Logs, and then compare the `sourceinstance` value in the **Execution Parameters** column with the **Account Reconciliation URL** value.
        
    -   Check the integration user's NetSuite Account ID entered in the **Account** field during token-based authentication setup in Data Exchange. See step 14.g in [Setting Up Token-Based Authentication](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_4164105234.html).
        
    
4.  Choose your preferred authentication method from the available options:
    
    1.  **Basic Auth**
        
        Important:
        
        This option displays a box that you must check to confirm your understanding that you should use basic authentication only for testing purposes or when OAuth 2.0 is unavailable. Until you check the displayed box, you can't start using basic authentication as your preferred authentication method.
        
        For configuration instructions, see [Using Basic Authentication to Connect to Account Reconciliation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0221061851.html).
        
    2.  **OAuth 2.0**
        
        For configuration instructions, see [Using OAuth 2.0 to Connect to Account Reconciliation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0221062843.html).
        
5.  Click **Save Active Connection** to save your preferred authentication method.
