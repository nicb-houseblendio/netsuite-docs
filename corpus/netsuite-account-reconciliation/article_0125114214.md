Import the profile data in your Account Reconciliation application.

#### To import the profile data in Account Reconciliation: {#procedure_0103045955}

1.  Click the **Navigator** icon ![Navigator Menu Icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuiteAccountReconciliation/AccountReconciliationSync/ARNavigatorMenuIcon.png), and then click **Profiles**.
    
2.  Click **Actions**, and then select **Import** from the list.
    
3.  In the Import Profiles popup window, do the following:
    
    1.  Click **Choose File**. In the popup window, find the CSV file you want to import, and click **Open**. Then, click **Import**.
        
    2.  For **File Type**, choose **Profiles**.
        
    3.  For **Import Type**, choose one of the following:
        
        -   **Replace**
            
        -   **Replace All**
            
    4.  For **Date Format**, select a date format from the list.
        
    5.  For **File Delimiter**, select a file delimiter from the list.
        
4.  Click **Import**. When the import is finished, click **OK**.
