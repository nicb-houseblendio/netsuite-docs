To integrate NetSuite Account Reconciliation with NetSuite, you must have the Administrator role and complete the following consecutive steps:

1.  Install the NetSuite EPM Connector SuiteApp and set it up for Account Reconciliation.
    
    See the following help topics:
    
    -   [Installing the NetSuite EPM Connector SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_4120644213.html)
        
    -   [Setting Up a File Encryption Password for NetSuite EPM Connector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_3115159270.html)
        
    -   [Data Source Allowlist](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_9115749534.html)
        
    
    Note:
    
    If you have the NSPB Sync SuiteApp installed on your NetSuite account, read the following:
    
    -   You don't need to install the NetSuite EPM Connector SuiteApp.
        
    -   Ensure you add the **customsearch\_nsar\_** prefix for Account Reconciliation Sync saved search IDs to the allowlist in NSPB Sync. For instructions, see the help topic [Saved Search Allowlist](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158350512864.html).
        
    
2.  Install the Account Reconciliation Sync SuiteApp.
    
    See the help topic [Installing the Account Reconciliation Sync SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_3183817848.html).
    
3.  Create the NetSuite Account Reconciliation application.
    
    See the help topic [Creating the NetSuite Account Reconciliation Application](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_2183706215.html).
    
4.  Set up an integration user with proper permissions in NetSuite. You can either use the NSAR Integration role, or customize and duplicate this role to better suit your needs.
    
    See the help topic [Using the NSAR Integration Role](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0324112720.html).
    
5.  Create or customize Account Reconciliation Sync saved searches in NetSuite.
    
    See the help topic [Managing the Account Reconciliation Sync Saved Searches](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_2202945276.html).
    
6.  Set up token-based authentication.
    
    See the help topic [Setting Up Token-Based Authentication](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_4164105234.html).
    
7.  Set up the connection between your NetSuite Account Reconciliation application and NetSuite.
    
    See the help topic [Setting Up the Connection to Account Reconciliation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_5100827424.html).
    
8.  Export data from NetSuite, and import it into your NetSuite Account Reconciliation application.
    
    See the help topic [Account Reconciliation Data Export and Import](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_2131942603.html).
    
9.  Add accounts into groups of accounts that are reconciled together in your NetSuite Account Reconciliation application.
    
    See the help topic [Accounts for Group Reconciliation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_4132136758.html).
    
10.  Select accounts that you identified for transaction matching tasks in your NetSuite Account Reconciliation application.
     
     See the help topic [Transaction Matching Accounts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_4134640124.html).
     
11.  To load data into your Account Reconciliation application, manually execute the data load or schedule the job in NetSuite. You can also execute the data load in your Account Reconciliation application.
     
     See the following help topics:
     
     -   [Managing the Account Reconciliation Jobs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_8161528693.html)
         
     -   [Importing Account Reconciliation Data in NetSuite Account Reconciliation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_124559097.html)
         
12.  Create reconciliations for the data load related period in your NetSuite Account Reconciliation application.
     
     See the help topic [Creating Reconciliations](https://docs.oracle.com/en/cloud/saas/account-reconcile-cloud/adarc/admin_create_reconcil_104xd8fdaddd.html#GUID-89929014-A919-4095-A9EA-0E11D8D498DF) in the Oracle Help Center.
