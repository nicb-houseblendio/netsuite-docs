To ensure you've configured Account Reconciliation Sync properly, you can use a checklist of tasks to help you quickly set up any missing features. To access the checklist, go to NetSuite EPM > Account Reconciliation > Configuration Checklist. You need to complete each task on the checklist. You can also use this checklist to validate your current Account Reconciliation Sync setup.

For details on the checklist, refer to the following table:

| NetSuite Column Label | Description |
| --- | --- |
| Feature | The list of Account Reconciliation Sync features to configure. |
| Status | The configuration status for each feature can be one of the following:
-   If configured correctly, the feature is denoted with a green check mark icon ![A green tick icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuiteAccountReconciliation/AccountReconciliationSync/NSARGreenTick.png) .
-   If not configured, or configured incorrectly, the feature is denoted with a red cross icon ![A red cross icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuiteAccountReconciliation/AccountReconciliationSync/NSARRedCross.png).
-   Features where you should check the configuration are denoted with a dash ![A dash icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuiteAccountReconciliation/AccountReconciliationSync/NSARDash.png).

 |
| Link | Clicking the **View** link for each feature takes you to the NetSuite page where you can configure the feature. |
| Instruction | This column shows relevant information about what you need to do to configure a particular Account Reconciliation feature properly. |
