You can view and customize saved searches you've executed in NetSuite for your Account Reconciliation application. You can also determine which saved searches should load data incrementally. An incremental data load includes data that's new or has changed since the last time the saved search was executed.

#### To enable a saved search to load data incrementally: {#procedure_1023110016}

1.  In NetSuite, go to NetSuite EPM > Account Reconciliation > Manage Saved Searches.
    
2.  In the list of saved searches, click **Customize** or **Edit** next to the saved search of your choice.
    
    Note:
    
    You can choose only saved searches in the **Created** status. For information about the statuses of saved searches, see the help topic [Managing the Account Reconciliation Sync Saved Searches](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_2202945276.html).
    
3.  On the Account Reconciliation: Saved Search Settings page, do the following:
    
    -   Check the **Load Data Incrementally** box.
        
    -   From the **Criteria** list, select the date that will serve as an identifier which data should be loaded:
        
        -   **Date Created**
            
        -   **Date Last Modified**
            
        -   **Date Line Last Modified**
            
    -   Click **Save**.
        
    
    Every time Data Exchange calls the saved search, NetSuite EPM Connector returns data based on your selected criteria. You can then see the data load history at NetSuite EPM > EPM Connector > Reset Search Request Load. For information, see [Resetting the Search Request Load](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_9091535677.html).
