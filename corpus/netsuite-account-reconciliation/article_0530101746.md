After uploading the plug-in script, define and run a data integration job successfully in NetSuite.

#### To define and run a data integration job:

This generates a CSV file containing Journal Entries and stores it in the File Browser in Data Exchange. Then, the Account Reconciliation Sync SuiteApp downloads this file in NetSuite and passes it to the plug-in for processing. Go to Transactions > Financial > Make Journal Entries > List to see the newly imported journal entries.

You can see job execution logs to find detailed information about the plug-in script progress or errors. See the help topic [Viewing the Job Execution Logs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_7111204564.html) for more information about job execution logs.

1.  In NetSuite, go to NetSuite EMP > Account Reconciliation > Manage Jobs and click **Add Job**.
    
2.  In the **Job Type** field, select **Data Integration**.
    
3.  Enter a name that must match exactly the integration record name defined in [Creating a Data Integration Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0509094850.html).
    
4.  Enter job description.
    
5.  Click **Next**.
    
6.  Click the **Job Parameters** subtab, and do the following:
    
    1.  Select one of the period types from the **Period Type** list.
        
    2.  Select **Replace** from the **Export Mode** field.
        
7.  Under **Options**, select the previously created plug-in script.
    
8.  (Optional) Under **Schedule**, you can also schedule the job if needed. For details, see step 3 in [Setting Up Data Integration Job Type Parameters](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0828042138.html).
    
9.  Click **Save**.
    
10.  Go back to NetSuite EPM > Account Reconciliation > Manage Jobs, find the newly created job, and then click **Execute**.
     
11.  In the newly opened window, click **Execute**.
