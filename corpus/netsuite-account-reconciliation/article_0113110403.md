If you want to use NetSuite to schedule and run a pipeline job configured in Data Exchange, you need to add the job in NetSuite. Then, you can set up the job as needed.

#### To add and set up a pipeline job:

1.  In NetSuite, go to NetSuite EPM > Account Reconciliation > Manage Jobs.
    
2.  On the **Manage Jobs** page, do one of the following:
    
    -   In the list of jobs, click **Edit** next to a pipeline job of your choice.
        
    -   If you don't see the pipeline job in the list, click the **Add Job** button, and follow steps 3 through 6 in [Adding a Job in NetSuite](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1209082459.html).
        
3.  If you want to specify the accounting period during which the pipeline job should be executed, click the **Job Parameters** subtab, and do the following:
    
    1.  From the **Period Type** list, select one of the following:
        
        -   **Relative** to specify an accounting period that is relative to the current date.
            
            Important:
            
            Ensure that the periods configured in Data Exchange match those defined in NetSuite at Setup > Accounting > Manage Accounting Periods. For information about managing accounting periods, see [Manage Accounting Periods Page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1445839.html).
            
        -   **Absolute** to set up a specific date range.
            
    2.  From the **Start Period** and **End Period** lists, select the accounting periods as follows:
        
        -   If you've selected **Absolute** as the **Period Type**, select from the list of available accounting periods. For more information about managing accounting periods, see [Manage Accounting Periods Page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1445839.html).
            
        -   If you've selected **Relative** as the **Period Type**, select one of the following accounting periods:
            
            -   **This Fiscal Year**
                
            -   **This Fiscal Quarter**
                
            -   **This Period**
                
            -   **Last Fiscal Year**
                
            -   **Last Fiscal Quarter**
                
            -   **Last Period**
                
            -   **Period Before Last**
                
            
            Note:
            
            When a fiscal year or quarter is selected for **Start Period**, the first month of the selected period is used. When a fiscal year or quarter is selected for **End Period**, the last month of the selected period is used.
            
    3.  From the **Import Mode** list, select one of the following:
        
        -   **Replace**
            
        -   **Append**
            
        -   **No Import**
            
        -   **Map and Validate**
            
    4.  From the **Export Mode** list, select one of the following:
        
        -   **Merge**
            
        -   **Accumulate**
            
        -   **Replace**
            
        -   **No Export**
            
    5.  In the **Attach Logs** field, select **Yes** if you want the execution logs to be zipped and included as an attachment in an email notification. The default value is **No**.
        
    6.  In the **Send Mail** field, specify when an email notification with job execution details should be sent to the email recipient. The available options are:
        
        -   **No**
            
        -   **Always**
            
        -   **On Failure**
            
        -   **On Success**
            
    7.  In the **Send To** field, enter the recipient's email address.
        
    
    Important:
    
    Make sure that all fields required by Data Exchange are filled out in NetSuite. Leaving any required field blank may result in job failure.
    
4.  To schedule the pipeline job, click the **Schedule** subtab, and follow step 3 in [Scheduling a Job in NetSuite](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1209073051.html).
    
5.  For optional setup of the pipeline job, click the **Options** subtab. Then, from the **Post-Processing Plug-ins** list, select a plug-in of your choice. The field is set to **None** by default.
    
    For information about how you can use post-processing plug-ins for the integration purposes, see [Loading Account Reconciliation Data into NetSuite](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1144750550.html).
    
6.  Click **Save**.
    

For general information about using pipeline jobs in Data Exchange, see the Oracle Help Center topics [Using the Pipeline](https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/diepm/integrations_pipeline.html#DIEPM-GUID-782DFB83-F69C-4654-B7CB-F0A40BFBF2F3) and [Running the Pipeline](https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/diepm/integrations_pipeline_run.html).
