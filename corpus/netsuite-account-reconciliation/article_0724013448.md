You can export all the available Account Reconciliation Sync configurations, or you can select specific configurations you want to export. The following configurations can be exported:

| Configuration Label | Description |
| --- | --- |
| Jobs | The jobs configured in Data Exchange or your Account Reconciliation and added in NetSuite. See [Managing the Account Reconciliation Jobs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_8161528693.html). |
| Data Source Settings | Customizations to the Account Reconciliation saved searches that you've added in NetSuite. See [Saved Searches for Account Reconciliation Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_4131759732.html). |
| Accounts for Group Reconciliation | Accounts configured to be used for group reconciliations in the Account Reconciliation application. See [Accounts for Group Reconciliation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_4132136758.html). |

#### To export Account Reconciliation Sync configuration:

Note:

If the export contains no configuration, you receive an error message indicating that at least one configuration is required for the export.

1.  In NetSuite, go to NetSuite EPM > Account Reconciliation > Import/Export Configuration.
    
2.  Choose the **Export** radio button.
    
3.  Click the **Configurations to Export** subtab, and do any of the following:
    
    1.  In the **Select** column, check the box next to every configuration you want to export.
        
    2.  Click the **View** link for every configuration page you want to go to in the NetSuite UI.
        
4.  Click the **Logs** subtab to view the following information about the exported configuration:
    
    -   Date
        
    -   Operation
        
    -   Status
        
    -   Options
        
    -   Error
        
    -   Filename
        
5.  Click **Submit**.
