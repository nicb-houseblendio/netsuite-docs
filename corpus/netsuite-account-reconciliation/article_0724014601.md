You can import Account Reconciliation Sync configuration into your NetSuite account from a previously exported file.

#### To import Account Reconciliation Sync configuration:

1.  In NetSuite, go to NetSuite EPM > Account Reconciliation > Import/Export Configuration.
    
2.  Choose the **Import** radio button.
    
3.  Click **Choose File**, then select the file you want to import.
    
4.  If you want to overwrite your existing configuration with the import file content, check the **Overwrite Existing Values** box.
    
5.  Click the **Logs** subtab to view the following information about the imported configuration:
    
    -   Date
        
    -   Operation
        
    -   Status
        
    -   Options
        
    -   Error
        
    -   Filename
        
6.  Click **Submit**.
    
    -   If you import Jobs configuration, ensure all plug-ins configured on the jobs in the source NetSuite account are implemented in the target NetSuite account.
        
    -   If an error occurs on any configuration while importing the file, it doesn't affect the rest of the import. You can view the related error logs on the **Logs** subtab.
        
    -   If you check the **Overwrite Existing Values** box and the import file has no configuration, you'll receive an error message. It indicates that the import file content is required.
