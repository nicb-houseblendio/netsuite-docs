To install and set up Account Reconciliation Sync, you must have the Administrator role and complete the following steps:

1.  Ensure you have the NetSuite EPM Connector SuiteApp installed and set up properly for Account Reconciliation. See [NetSuite EPM Connector Installation and Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0095112426.html).
    
    Note:
    
    If you have the NSPB Sync SuiteApp installed on your NetSuite account, read the following:
    
    -   You don't need to install the NetSuite EPM Connector SuiteApp.
        
    -   Ensure you add the **customsearch\_nsar\_** prefix for Account Reconciliation Sync saved search IDs to the allowlist in NSPB Sync. For instructions, see the help topic [Saved Search Allowlist](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158350512864.html).
        
    
2.  Enable the required features in your NetSuite account. See [Required Features for Installing the Account Reconciliation Sync SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_7101458520.html).
    
3.  Install the Account Reconciliation Sync SuiteApp. See [Installing the Account Reconciliation Sync SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_3183817848.html).
    
4.  Assign roles to Account Reconciliation Sync users. See [Role Permissions for Account Reconciliation Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161507691.html).
    
5.  Set up the connection to your Account Reconciliation application. See [Setting Up the Connection to Account Reconciliation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_5100827424.html).
    
6.  Schedule the required script deployments properly. See [Scheduling Script Deployments for Account Reconciliation Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_3111218445.html).
    
7.  Use a post-processing plug-in script in NetSuite to load Transaction Matching adjustments into NetSuite. See [Loading Account Reconciliation Data into NetSuite](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1144750550.html).
    
8.  Export account reconciliation data in NetSuite, and import it into the Account Reconciliation application. See [Account Reconciliation Data Export and Import](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_2131942603.html).
    
9.  Set up token-based authentication. See [Setting Up Token-Based Authentication](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_4164105234.html).
    
10.  Manage jobs to load data to the Account Reconciliation application. See [Managing the Account Reconciliation Jobs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_8161528693.html).
     
11.  Create or customize saved searches for data load from NetSuite to the Account Reconciliation application. See [Saved Searches for Account Reconciliation Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_4131759732.html).
     
12.  Add accounts to group reconciliations. See [Accounts for Group Reconciliation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_4132136758.html).
     
13.  Include NetSuite account records in the Account Reconciliation Transaction Matching. See [Transaction Matching Accounts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_4134640124.html).
