The Account Reconciliation Sync saved searches are listed in the following groups:

-   **Reconciliation Compliance**
    
    The following table shows the names and IDs of the saved searches included in this group:
    
    | Saved Search Name | Saved Search ID |
    | --- | --- |
    | NSAR Balance Sheet Inventory Subsystem | customsearch\_nsar\_bs\_subsys\_inv\_trans |
    | NSAR Balance Sheet AP Subsystem | customsearch\_nsar\_bs\_subsys\_ap\_trans |
    | NSAR Balance Sheet AR Subsystem | customsearch\_nsar\_bs\_subsys\_ar\_trans |
    | NSAR Balance Sheet Ending Balance | customsearch\_nsar\_bs\_ending\_bal |
    | NSAR Balance Sheet Ending Balance - Functional | customsearch\_nsar\_bs\_ending\_bal\_fnc |
    
    These saved searches are configured in Data Exchange and LCM imports to load data into the Account Reconciliation application. If you make any changes to these saved searches, you may need to update the Data Exchange configurations. For information about the use of Data Exchange, refer to [Administering Data Integration](https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/diepm/index.html#Oracle%C2%AE-Fusion-Cloud-EPM) in the Oracle Help Center.
    
-   **Transaction Matching**
    
    The following table shows the name and ID of the saved search included in this group:
    
    | Saved Search Name | Saved Search ID |
    | --- | --- |
    | NSAR GL Transaction Lines | customsearch\_nsar\_gl\_trans\_lines |
    
    This saved search isn't configured in LCM imports. You need to configure it manually in the Account Reconciliation application. For information about how this saved search is involved in Account Reconciliation Transaction Matching, see [Transaction Matching Accounts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_4134640124.html).
    
-   **Miscellaneous Saved Searches**
    
    The following table shows the name and ID of the saved search included in this group:
    
    | Saved Search Name | Saved Search ID |
    | --- | --- |
    | NSAR Profile Template | customsearch\_nsar\_profile\_template |
    | NSAR Ongoing Profile Update | customsearch\_profile\_update\_nsar |
    | NSAR Job Execution Search | customsearch\_job\_nsar\_execution |
    
    The NSAR Profile Template saved search is used for generating the Profile data type export file. You can update the saved search before you export data. For more details, see [Account Reconciliation Data Export and Import](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_2131942603.html).
    
    The NSAR Job Execution Search saved search is used to see the list of jobs that failed to execute and the error message.
    

For information about creating and customizing the saved searches, see the following help topics:

-   [Managing the Account Reconciliation Sync Saved Searches](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_2202945276.html)
    
-   [Customizing the Executed Account Reconciliation Sync Saved Searches](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_44130817717.html)
