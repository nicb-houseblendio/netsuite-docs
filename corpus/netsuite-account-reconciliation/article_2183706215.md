If you don't have Account Reconciliation, contact your NetSuite account manager on how you can request an Account Reconciliation license.

If you have already purchased Account Reconciliation, you need the Account Reconciliation environment provisioned on your Oracle Cloud Enterprise Performance Management (EPM) account. If you don't have one, you can create and configure a new NetSuite Account Reconciliation application. You can also import a backup using the Migration tool. For more information, see the [Administering Migration](https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/epmss/index.html) guide in the Oracle Help Center.

Note:

Read the following before you start creating a new NetSuite Account Reconciliation application:

-   Use the Administrator role to create and configure a new Cloud EPM environment. For instructions, see the help topic [Oracle Application Cloud Provisioning guide](https://www.oracle.com/a/ocom/docs/cloudinfra/tas/notifications/tas/img/v1/quick-reference-guide.pdf).
    
-   Ensure you assign the Preparer and Reviewer roles. For more information, see the help topic [Application Role Assignment Overview](https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/pappm/about_application_assignment.html#GUID-22E54AB2-977A-448E-9910-D0CF9DE3A0BD) in the Oracle Help Center.
    

After you successfully create your Account Reconciliation application or import a backup using the Migration tool, log out of your Account Reconciliation. Then, log in again. This logs you in to your created NetSuite Account Reconciliation application.

#### To log out of Account Reconciliation:

1.  On the Account Reconciliation landing page, click **Administrator**.
    
2.  From the **Settings and Actions** list, select **Sign Out**.
    
3.  In the Sign Out popup window, click **OK** to confirm the action.
    

#### To log in Account Reconciliation:

1.  On the Sign In to Oracle Cloud landing page, enter your username and password.
    
2.  Click **GO** to log in.
