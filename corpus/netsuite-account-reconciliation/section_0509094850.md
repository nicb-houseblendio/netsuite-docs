To be able to export Transaction Matching adjustments, you need to create a data integration record.

#### To create a data integration record:

1.  In your Account Reconciliation application, click the **Navigator** icon ![Navigator icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuiteAccountReconciliation/AccountReconciliationSync/ARNavigatorMenuIcon.png), and then, under Application, click **Data Exchange**.
    
2.  Click the **Add** icon ![Add icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuiteAccountReconciliation/AccountReconciliationSync/ARAddIcon.PNG), and do the following:
    
    1.  In the **Name** field, enter a unique name for this data integration record.
        
    2.  In the **Source** list, select the source application you created in [Creating a Source Application in Data Exchange](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0509094725.html).
        
    3.  In the **Target** list, select the target application you created in [Creating a Target Application in Data Exchange](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0509094811.html).
        
    4.  In the **Location** field, enter the location.
        
    5.  In the **Category** field, select **Current**.
        
3.  Click **Save and Continue**.
    
4.  In the Map Dimensions window, from the Source Column list for every target dimension, select the corresponding source column. The following screenshot shows an example of the mapping for the template file you uploaded in [Creating a Target Application in Data Exchange](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0509094811.html):
    
    ![AR journal export column matching](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuiteAccountReconciliation/AccountReconciliationSync/ARColumnMatching.png)
5.  Click **Save and Continue**.
    
6.  In the Map Members window, click the **Add** icon ![Add icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuiteAccountReconciliation/AccountReconciliationSync/ARAddIcon.PNG) to add mapping rules for each column:
    
    1.  In the **Source** field, enter an asterisk \*.
        
    2.  In the **Target** field, enter an asterisk \*.
        
    3.  In the **Processing Order** field, enter 1.
        
    4.  Repeat this procedure for all the other dimensions in the **Dimension** list.
        
    5.  Click **Save and Continue**.
        
7.  In the Options window, do the following:
    
    1.  On the **Filters** tab:
        
        1.  In the **Type** field, select **Adjustments**.
            
        2.  In the **Match Type** field, enter the Match Type ID that you want to use for exporting journal adjustments.
            
    2.  On the **Options** tab, in the **Download File Name** field, enter the path that you created in [Creating a New Folder](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0509094825.html), for example, `inbox/journal_entries/journal_entry.csv`.
        
8.  Click **Save**.
