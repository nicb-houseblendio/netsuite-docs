Execute the data integration in **Data Exchange**.

#### To execute the data integration:

1.  In your Account Reconciliation application, click the **Navigator** icon ![Navigator icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuiteAccountReconciliation/AccountReconciliationSync/ARNavigatorMenuIcon.png), and then, under Application, click **Data Exchange.**
    
2.  Locate the data integration record created in [Creating a Data Integration Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0509094850.html) and click the **Run** icon ![Run icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuiteAccountReconciliation/AccountReconciliationSync/ARRunIcon.png).
    
3.  In the Run Integration window, do the following:
    
    1.  In the **Import Mode** field, select **Replace**.
        
    2.  In the **Export Mode** field, select **Replace**.
        
    3.  Select values for the **Start Period** and **End Period** fields.
        
    4.  Click **Run**.
        
4.  If the data integration job has been executed successfully, you can do any of the following:
    
    -   Go to Application > Data Exchange > File Browser to access the CSV file generated by this data integration job. You'll find it in the folder created in [Creating a New Folder](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0509094825.html). You can download the file and verify that it has the correct format.
        
        Important:
        
        After the data integration execution, exported transactions will be marked as **Closed**. To add them to another export, you need to change their status to **Open**. For instructions, see the help topic [Ensure You Have Open Adjustments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0530100752.html).
        
        Note:
        
        There's only one file stored in the folder. A new job overrides the previous file.
        
    -   Execute a data integration job from NetSuite, see [Importing Transaction Matching Adjustments Using Data Integration Job](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0509105608.html). If the job is executed successfully, the Account Reconciliation application downloads the CSV file, and the post-processing plug-in processes the Journal Entries in NetSuite.
