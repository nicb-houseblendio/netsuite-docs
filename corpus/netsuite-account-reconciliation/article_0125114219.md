Import the period data in your Account Reconciliation application.

#### To import the period data in Account Reconciliation: {#procedure_0103050118}

1.  Click the **Navigator** icon ![Navigator Menu Icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuiteAccountReconciliation/AccountReconciliationSync/ARNavigatorMenuIcon.png), and then click **Configuration**.
    
2.  Click the **Periods** icon ![Periods icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuiteAccountReconciliation/AccountReconciliationSync/ARPeriodsIcon.png).
    
3.  On the Periods page, click the **Import** icon ![Account Reconciliation Import Icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuiteAccountReconciliation/AccountReconciliationSync/ARImportIcon.PNG).
    
4.  In the Import Periods popup window, do the following:
    
    1.  Click **Choose File**. In the popup window, find the CSV file you want to import, and then click **Open**.
        
    2.  For **Import Type**, choose one of the following:
        
        -   **Replace**
            
        -   **Replace All**
            
    3.  For **Date Format**, select a date format from the list.
        
    4.  For **File Delimiter**, select a file delimiter from the list.
        
    5.  Click **Import**. When the import is finished, click **OK**.
