This help topic describes the recent changes to the Account Reconciliation Sync SuiteApp.

## Version 26.1.2 {#subsect_0730072846}

### August 4, 2026 {#subsect_0730072859}

This release enhances the security of OAuth 2.0 configurations for NetSuite EPM integrations. The OAuth 2.0 connection to Account Reconciliation now includes a token scope that is specific to each Cloud EPM service that your NetSuite integration uses.

Review the following information:

-   For the updated connection setup procedure, see [Using OAuth 2.0 to Connect to Account Reconciliation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0221062843.html).
    
-   For required updates to existing OAuth 2.0 configurations, see [Required OAuth 2.0 Configuration Updates for NetSuite EPM Integrations](https://suiteanswers.custhelp.com/app/answers/detail/a_id/1047055), SuiteAnswers ID 1047055.
    

## Version 26.1.1 {#subsect_0701092347}

### July 7, 2026 {#subsect_0701092401}

This release includes a security-related improvement.

## Version 26.1 {#subsect_0113044941}

### January 20, 2026 {#subsect_0113051806}

This release of the Account Reconciliation Sync SuiteApp introduces the following new features and enhancements:

-   You can check the **Use Entered URL to Verify Inbound Connections** box to verify that the correct Account Reconciliation application connects to NetSuite. See step 3 in [Setting Up the Connection to Account Reconciliation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_5100827424.html).
    
-   Option to delete the imported CSV file from the Inbox/Outbox Explorer in your Account Reconciliation after running a Data Integration job.
    
-   You can write SuiteQL queries to load transaction data and metadata from NetSuite to your Account Reconciliation. See [Manage SuiteQL Queries in Account Reconciliation Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_9232430195.html).
    
-   The Job Calendar page has been updated. See [Job Calendar](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1209023654.html).
    
-   Data Load Rule jobs are now called Data Integration jobs.
    
-   You can schedule and run the following jobs from NetSuite:
    
    -   **Pipeline job**. See [Pipeline in Account Reconciliation Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0113110403.html).
        
    -   **Import Profiles**. See [Setting Up Import Profiles Job Type Parameters](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0113115815.html).
        
-   Options for Relative period selection in Data Integration jobs and Group jobs are renamed from 'month' to 'period'. The following has changed:
    
    -   **This Month** changes to **This Period**
        
    -   **Last Month** changes to **Last Period**
        
    -   **Period Before Last** is now available
