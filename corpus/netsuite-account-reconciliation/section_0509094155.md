To export Transaction Matching adjustments from your Account Reconciliation application, you need to complete the following consecutive steps in Data Exchange:

1.  Create a source application in Data Exchange. See [Creating a Source Application in Data Exchange](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0509094725.html).
    
2.  Create a target application in Data Exchange. See [Creating a Target Application in Data Exchange](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0509094811.html).
    
3.  Define a folder where you want to store CSV files for export. See [Creating a New Folder](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0509094825.html).
    
4.  Create a data integration record. See [Creating a Data Integration Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0509094850.html).
    
5.  Execute the data integration record. See [Executing the Data Integration](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0509094909.html).
