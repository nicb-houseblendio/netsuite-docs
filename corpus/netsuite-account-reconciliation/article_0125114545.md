Import the application period data in your Account Reconciliation application.

#### To import the application period data in Account Reconciliation: {#procedure_0103050203}

1.  Click the **Navigator** icon ![Navigator Menu Icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuiteAccountReconciliation/AccountReconciliationSync/ARNavigatorMenuIcon.png),and then click **Data Exchange**.
    
2.  Click **Actions**, and then select **Period Mapping** from the list.
    
3.  In the Period Mapping popup window, click the **Application Mapping** subtab.
    
4.  Click **Actions**, and then select **Import From Excel** from the list.
    
    Note:
    
    Ensure the following applies before you start importing:
    
    -   The exported CSV file is converted to the Excel file format.
        
    -   The text column data format is used for the **Period Name** and **Target Period - Month** columns.
        
    -   The date format for the **Period Key** and **Prior Period Key** columns is the same as the one you select in the period data import.
        
    
5.  In the Select File To Import popup window, do the following:
    
    1.  Click the **File Browser** icon ![Account Reconciliation File Browser Icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuiteAccountReconciliation/AccountReconciliationSync/ARFileBrowserIcon.PNG).
        
    2.  In the File Browser popup window, click **Upload**. Find the Excel file you want to import, and then click **Open**. This uploads the file to the File Browser popup window.
        
    3.  Click the uploaded file to select it. Then click **OK**.
        
6.  Click **OK**.
