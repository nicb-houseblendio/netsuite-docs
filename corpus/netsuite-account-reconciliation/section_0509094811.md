You need to create a target application in Data Exchange to export CSV files.

#### To create a target application:

1.  In your Account Reconciliation application, click the **Navigator** icon ![Navigator icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuiteAccountReconciliation/AccountReconciliationSync/ARNavigatorMenuIcon.png), and then, under Application, click **Data Exchange**.
    
2.  Click **Actions**, and then select **Applications**.
    
3.  Click the **Add** icon ![Add icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuiteAccountReconciliation/AccountReconciliationSync/ARAddIcon.PNG).
    
4.  In the Create Application popup window, do the following:
    
    1.  For the **Category** field, select **Data Export**.
        
    2.  For the **Type** field, select **Data Export to File**.
        
    3.  Next to the **File** field, click the **File Browser** icon ![File browser icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuiteAccountReconciliation/AccountReconciliationSync/ARFileBrowserIcon.PNG).
        
    4.  Click **Upload** to fins a source file on your disk. It should be a simple CSV file with column headers in the order you want them generated. For example, if you want to use default settings, the CSV file should look exactly as follows:
        
        ![AR Journal Entry Export CSV](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/NetSuiteAccountReconciliation/AccountReconciliationSync/ARJournalEntryExportCSV.png)
    5.  Select the source file on your disk and click **Open**.
        
    6.  In **File Browser**, click the source file. Then, click **OK**.
        
    7.  In the **Prefix** field, enter a prefix to give the target application a unique name.
        
5.  Open the newly created application. Do the following:
    
    1.  Check that **Data Table Column Name** is filled correctly. For example, if you use the default template file, the **Account** dimension has to be set to ACCOUNT.
        
    2.  Click **Save**.
        

For general information and additional setup, see the Oracle Help Center topic [Registering a Data Export File Application](https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/diepm/integrations_data_export_file_110x000b0afe.html).
