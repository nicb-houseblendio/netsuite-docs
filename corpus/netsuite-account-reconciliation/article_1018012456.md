You can create a group of Account Reconciliation jobs that you want to run from NetSuite. The group can only contain jobs that you've previously added in NetSuite. See [Adding a Job in NetSuite](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1209082459.html). The job parameters you set for the group override the parameters set for the data integration jobs executed as part of the group.

The jobs in the group are executed one by one in 15-minute intervals. The next job can't start until the previous job is completed and the nearest 15-minute interval begins.

To use NetSuite to schedule and run a group of jobs configured in your Account Reconciliation application, you need to create and configure the group in NetSuite.

#### To set up job parameters for the Group job type:

1.  Go to NetSuite EPM > Account Reconciliation > Manage Jobs.
    
2.  On the Account Reconciliation: Manage Jobs page, do one of the following:
    
    -   In the list of jobs, click **Edit** next to a job of your choice.
        
    -   If you don't see the job in the list and have the Administrator or NSEPM Implementer role, click the **Add Job** button. Then, follow steps 3 through 6 in [Adding a Job in NetSuite](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1209082459.html).
        
3.  Click the **Members** subtab, and do the following:
    
    1.  In the **Job Name** column, add the jobs that you want to include in the group. You can only add jobs that you've added and configured in NetSuite for the integration.
        
        The members of the group will be executed in the order you add them to the column.
        
    2.  Check the **Abort on Failure** box if you want to stop executing the sequence of jobs after a job in the group fails. If you clear the box, and a member of the group fails, the group job continues executing the next jobs in the sequence.
        
4.  Click the **Job Parameters** subtab, and do the following:
    
    1.  Check the **Use Values from Member** box if you want to use parameters that you've set up for the jobs in the group. If you don't, you'll override the setup for the individual jobs.
        
        Note:
        
        This option applies only to the data integration jobs within the group and doesn't impact other jobs in the group.
        
    2.  From the **Period Type** list, select one of the period types:
        
        -   **Absolute** to select a specific accounting period.
            
        -   **Relative** to specify an accounting period that is relative to the current date.
            
    3.  From the **(Start) Period** list, do one of the following to select the accounting period:
        
        -   If you've selected **Absolute** as the **Period Type**, select from the list of available accounting periods. For more information about managing accounting periods, see [Manage Accounting Periods Page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1445839.html).
            
        -   If you've selected **Relative** as the **Period Type**, select one of the following accounting periods:
            
            -   **This Period**
                
            -   **Last Period**
                
            -   **Period Before Last**
                
    4.  From the **End Period** list, do one of the following to select the accounting period:
        
        -   If you've selected **Absolute** as the **Period Type**, select from the list of available accounting periods.
            
        -   If you've selected **Relative** as the **Period Type**, select one of the following accounting periods:
            
            -   **This Period**
                
            -   **Last Period**
                
            -   **Period Before Last**
                
5.  Click **Save**.
