The Account Reconciliation Sync SuiteApp provides a default set of predefined saved searches. You can create the saved searches in NetSuite for your integration with Account Reconciliation application. For a list of the saved searches, see [Groups of Account Reconciliation Sync Saved Searches](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0223065946.html).

#### To access the Account Reconciliation Sync saved searches: {#procedure_0223061152}

1.  In NetSuite, go to NetSuite EPM > Account Reconciliation > Manage Saved Searches.
    
2.  In the upper-right corner of the page, click **Create Default Saved Searches**. For information, see [Creating an Account Reconciliation Sync Saved Search](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1215084626.html).
    
3.  From the **Saved Search Group** list, select the saved search group you want to view. The available options include the following:
    
    -   **Other Searches**
        
    -   **Reconciliation Compliance**
        
    -   **Transaction Matching**
        
    
    For general information about the groups of saved searches, see [Groups of Account Reconciliation Sync Saved Searches](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0223065946.html).
    
    The status of the saved searches can be one of the following:
    
    -   **Not Created**
        
        You can create a saved search with this status. See [Creating an Account Reconciliation Sync Saved Search](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1215084626.html).
        
    -   **Created**
        
        You can recreate or customize a saved search with this status. For information, see the following help topics:
        
        -   [Recreating an Account Reconciliation Sync Saved Search](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1215084925.html)
            
        -   [Customizing an Account Reconciliation Sync Saved Search](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1215085213.html)
