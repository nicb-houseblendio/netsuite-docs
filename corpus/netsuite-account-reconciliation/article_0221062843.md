You can use OAuth 2.0 to connect to the Account Reconciliation application from NetSuite. To authenticate through OAuth 2.0, you need to store credentials obtained from your Oracle Cloud Infrastructure (OCI) instance in NetSuite.

#### To set up OAuth 2.0 to connect to Account Reconciliation:

1.  In Oracle Cloud Infrastructure (OCI), go to **Identity & Security**, and then click **Domains**.
    
2.  In the list of domains, select the identity domain where your Cloud EPM service is deployed. In many environments, this is the **Default** domain.
    
    Tip:
    
    You can get the domain name from the Account Reconciliation login screen.
    
3.  On the **Details** tab, copy the **Domain URL** value.
    
4.  On the **Integrated applications** tab, click **Add application**.
    
5.  Select the **Mobile Application** type, and then click **Launch workflow**.
    
6.  Enter a name for the application, and then click **Submit**.
    
7.  On the **OAuth configuration** tab, click **Edit OAuth configuration**.
    
    Then, do the following:
    
    1.  Check the **Refresh token** box.
        
    2.  Check the **Device code** box.
        
    3.  Clear the **Implicit** box.
        
    4.  In the **Client IP address** section, choose **Anywhere**.
        
    5.  In the **Token issuance policy** section, enable **Add resources**.
        
    6.  Click **Add scope**, and then select a resource for the created integrated application.
        
    7.  Click **Add**.
        
    8.  After you add the Cloud EPM resource, copy the value displayed in the **Scope** column. The value has the following format:
        
        `urn:opc:serviceInstanceID=<SERVICE_INSTANCE_ID>urn:opc:resource:consumer::all`
        
    9.  Click **Submit**.
        
    10.  Copy the **Client ID** value.
         
8.  Return to the **Integrated applications** tab.
    
9.  On the created application record, click the three dots, and then select **Activate**.
    
10.  When prompted, click **Activate application**.
     
11.  Return to the identity domain on the **Domains** page.
     
12.  On the **Oracle cloud services** tab, select the applicable Cloud EPM service instance.
     
13.  On the **OAuth configuration** tab, click **Edit OAuth configuration**.
     
     Then, do the following:
     
     1.  Make sure that **Allow token refresh** is enabled.
         
     2.  Enable **Add secondary audience**.
         
     3.  Click **Add**.
         
     4.  In the **Secondary audience** field, enter the exact URL of the Cloud EPM service instance.
         
         Note:
         
         Review the following details:
         
         -   This is the URL that you entered in the **Account Reconciliation URL** field at NetSuite EPM > Account Reconciliation > Connection Settings. See [Setting Up the Connection to Account Reconciliation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_5100827424.html).
             
         -   Don't include a trailing slash (/) at the end of the URL.
             
         
     5.  Click **Add**.
         
     6.  Click **Submit**.
         
14.  In NetSuite, go to NetSuite EPM > Account Reconciliation > Connection Settings.
     
15.  For the **OAuth 2.0** type, click **Configure**.
     
16.  In step **Enter Parameters**, provide the credentials you copied in the previous steps:
     
     1.  In the **IDCS URL** field, enter the **Domain URL** value.
         
     2.  In the **Client ID** field, enter the **Client ID** value.
         
     3.  In the **Scope** field, enter the **Scope** value.
         
17.  Click **Next**.
     
18.  In step **Provide Consent**, copy the code and click the verification URL. If prompted, log in to your Cloud EPM account.
     
     To return to the previous step, click **< Back** or **Cancel**.
     
19.  In your Cloud EPM account, paste the code to confirm that you're granting access for this logged-in user to connect from NetSuite to your Account Reconciliation application. The user must have at least a Power User role with access to the target Account Reconciliation application.
     
20.  Go back to the Configure OAuth 2.0 page in NetSuite, and click **Finish**.
