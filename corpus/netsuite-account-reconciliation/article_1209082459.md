To use NetSuite to schedule and execute jobs configured in Account Reconciliation application, use the Administrator or NSEPM Implementer role to add the jobs in NetSuite.

#### To add a job in NetSuite: {#procedure_1208053749}

1.  Go to NetSuite EPM > Account Reconciliation > Manage Jobs.
    
2.  Click **Add Job**. This opens the Account Reconciliation Job page.
    
3.  From the **Job Type** list, select the type of job you want to add to NetSuite. You have the following options:
    
    -   **Account Reconciliation Report**
        
    -   **Auto Match**
        
    -   **Data Integration**
        
    -   **Fetch File via SFTP**
        
    -   **Group**
        
    -   **Import Balances**
        
    -   **Import Currency Rates**
        
    -   **Import Profiles**
        
    -   **Pipeline**
        
4.  In the **Job Name** field, enter or select the job name you want to add in NetSuite.
    
    Note:
    
    If you want to create an Account Reconciliation Report job, enter the name of a report that is defined in your Account Reconciliation application. The name must match exactly, including upper-case and lower-case letters.
    
5.  In the **Description** field, enter a description to help you identify this job in NetSuite.
    
6.  Click **Next**.
    
7.  The job parameters you need to specify on the **Job Parameters** subtab vary depending on the selected job type. See the following help topics for the job parameters setup:
    
    -   [Setting Up Account Reconciliation Report Job Type Parameters](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1022080159.html)
        
    -   [Setting Up Auto Match Job Type Parameters](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1018012412.html)
        
    -   [Setting Up Data Integration Job Type Parameters](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0828042138.html)
        
    -   [Setting Up Fetch File via SFTP Job Type Parameters](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0130100728.html)
        
    -   [Setting Up Group Job Type Parameters](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1018012456.html)
        
    -   [Setting Up Import Balances Job Type Parameters](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1215094039.html)
        
    -   [Setting Up Import Currency Rates Job Type Parameters](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1215094121.html)
        
8.  If you want to schedule the job, click the **Schedule** subtab, and follow the help topic [Scheduling a Job in NetSuite](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1209073051.html).
    
9.  Click **Save**.
