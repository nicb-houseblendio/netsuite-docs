If you've made Transaction Matching adjustments in your Account Reconciliation application, you can load them into NetSuite. To do that, you can use a post-processing plug-in script in NetSuite. The Account Reconciliation Sync SuiteApp provides a sample plug-in script that you can customize and attach to a data integration job in NetSuite.

#### To use a plug-in script to load data into NetSuite:

1.  In your Account Reconciliation application, create a data integration job. Then, check that the job runs successfully in your Account Reconciliation application.
    
2.  In NetSuite, go to NetSuite EPM > Account Reconciliation > Integration Artifacts.
    
3.  Click **Download** to save the required plug-in script to your disc.
    
4.  Go to _Customization > Plug-ins > Plug-in Implementations_.
    
5.  Click **New Plug-in Implementation**.
    
6.  Click the plus (+) sign to upload the plug-in script, and then click **Save**.
    
7.  Click **Create Plug-in Implementation.**
    
8.  From the list of plug-in types, click **NSAR | PI Job Post Process**.
    
9.  In the **Name** field, enter a name for your custom plug-in script.
    
10.  Set the Status field to **Released**.
     
11.  (Optional) Set the Log Level field to **Debug**.
     
12.  Click **Save**.
     
13.  To customize the script file, go back to _Customization > Plug-ins > Plug-in Implementations_, and then do the following:
     
     1.  In the displayed list, find the plug-in script that you want to customize.
         
         Tip:
         
         If NetSuite displays a long list of plug-in scripts, you can narrow the list by doing the following:
         
         1.  Expand the Filters area if the filters are not displayed.
             
         2.  From the **Script File** filter, select the script file name.
             
         
     2.  In the **Script** column, click the link to the script file details, and then do one of the following:
         
         -   To save the script file to disk, click **Download**. Then, use any plain text editor, for example Notepad++, to open and customize the script file.
             
         -   To update the script file directly in NetSuite, in the Media item section, click **Edit** next to the script file name. When finished, click **Save** to submit your changes.
             
14.  Add the plug-in script to a data integration job in NetSuite:
     
     1.  Go to NetSuite EPM > Account Reconciliation > Manage Jobs.
         
     2.  On the Account Reconciliation: Manage Jobs page, do one of the following:
         
         -   In the list of jobs, click **Edit** next to a job of your choice.
             
         -   If you do not see the job in the list and have the Administrator role, click the **Add Job** button. Then, follow steps 3 through 6 in [Adding a Job in NetSuite](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1209082459.html).
             
     3.  Click the **Options** subtab.
         
     4.  From the **Post-Processing Plug-in** list, select the plug-in you want to use to process data.
         
     5.  Check the **Delete file once the job is complete** box if you want to delete the file after the job is executed.
         
     6.  Click **Save**.
         

Note:

With each new version of the Account Reconciliation Sync SuiteApp, you may need to download, customize, and re-attach the sample plug-in script.
