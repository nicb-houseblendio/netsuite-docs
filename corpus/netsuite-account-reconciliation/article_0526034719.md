If you have the Administrator role, you can grant access to Account Reconciliation Sync pages to roles other than Administrator and NSEPM Implementer. The access can be granted through script deployment records for the following pages:

| Page | **Script Deployment Title** | Script Deployment ID |
| --- | --- | --- |
| Manage Saved Searches | NSAR | Saved Search List | customdeploy\_nsar\_sl\_saved\_search\_list |
| Job Execution Log | NSAR | Job Execution Logs | customdeploy\_nsar\_sl\_job\_exec\_log |
| Manage Jobs | NSAR | Job List | customdeploy\_nsar\_sl\_job\_list |
| Execute Job | NSAR | Job Execution | customdeploy\_nsar\_sl\_job\_execution |
| Accounts for Group Reconciliation | NSAR | Profile Account Data | customdeploy\_nsar\_sl\_profile\_acct\_data |

#### To grant access to Account Reconciliation Sync pages to other roles through script deployments: {#procedure_0526040139}

1.  Go to Customization > Scripting > Script Deployments.
    
2.  In the list of script deployments, click **Edit** next to the script deployment of your choice.
    
3.  On the Script Deployment page, click the **Audience** subtab, and select roles to grant access to.
    
4.  Click **Save**.
    
    This gives all selected roles access to the Account Reconciliation Sync page associated with the script deployment.
