The Account Reconciliation Sync SuiteApp delivers default configurations to integrate NetSuite and your Account Reconciliation application in Oracle Cloud Enterprise Performance Management (EPM). This lets you to load data from NetSuite searches to your Account Reconciliation application, either on a schedule or on demand. You can also automatically load exchange rates to the Account Reconciliation application from NetSuite.

The Account Reconciliation Sync SuiteApp is dependent on the NetSuite EPM Connector SuiteApp, which enables Data Exchange to connect to NetSuite. For information about the Account Reconciliation application, and about using Data Exchange with Account Reconciliation Sync, see the following help topics in the Oracle Help Center:

-   [Oracle EPM Account Reconciliation](https://docs.oracle.com/en/cloud/saas/account-reconcile-cloud/)
    
-   [Administering Data Integration](https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/diepm/index.html#Oracle%C2%AE-Fusion-Cloud-EPM)
    

For information about installing, configuring, and using the Account Reconciliation Sync SuiteApp, see [Account Reconciliation Sync SuiteApp Installation and Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_4184207834.html).

For information about the changes in each release, see [Account Reconciliation Sync Release Notes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_8132324918.html).
