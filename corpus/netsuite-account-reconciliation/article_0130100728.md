Set up parameters for the Fetch File via SFTP job type.

#### To set up job parameters for the Fetch File via SFTP job type: {#procedure_33100827842}

1.  Go to NetSuite EPM > Account Reconciliation > Manage Jobs.
    
2.  On the Account Reconciliation: Manage Jobs page, do one of the following:
    
    -   In the list of jobs, click **Edit** next to a job of your choice.
        
    -   If you don;t see the job in the list and have the Administrator or NSEPM Implementer role, click the **Add Job** button. Then, follow steps 3 through 6 in [Adding a Job in NetSuite](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1209082459.html).
        
3.  Click the **Job Parameters** subtab, and do the following:
    
    1.  From the **Connection Name** list, select the SFTP connection that this job should use to upload files. The list includes connections that you've previously created as described in [Configuring External Connections](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_2143945831.html).
        
    2.  In the **Download Files from Folder** field, enter the path to the folder on the SFTP server from where you want to download files. For example: `bank1`
        
        Note:
        
        The entered path shouldn't start with a parent directory notation (../).
        
    3.  In the **Filename to Download** field, enter a filename pattern for files that this job should download. You can use the asterisk (\*) wildcards to match any character sequence. For example: `dailytrans*.csv`
        
    4.  (Optional) In the **After Download Move Files to Folder** field, enter a path to the folder where you want to move successfully downloaded files. For example: `bank1/Archive`
        
        Note:
        
        The entered path shouldn't start with a parent directory notation (../). This should be a subfolder that is relative to the folder path specified in **Download Files from Folder**.
        
    5.  In the **Upload Files to Folder** field, enter a path to the folder in the Account Reconciliation inbox where you want to upload the downloaded files. For example: `inbox/bank1data`
        
        Note:
        
        The entered path shouldn't start with a parent directory notation (../).
        
        To access the inbox folder in your Account Reconciliation, go to **Data Exchange**, and then from the **Actions** list under **Data Integration**, select **File Browser**.
        
    6.  (Optional) In the **Filename to Upload as** field, specify a name you want to use to rename the file before uploading to your Account Reconciliation application. For example: `bank1file.csv`
        
4.  Click **Save**.
