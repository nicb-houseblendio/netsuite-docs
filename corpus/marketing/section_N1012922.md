The Campaign Response Detail report lists the recipients of each marketing campaign event in the date or period range you select. The report shows when the event was delivered and the action taken by each recipient. Campaigns are grouped by campaign category.

This report shows the following information about each marketing campaign event:

-   title of the campaign events
    
-   the campaign response for each recipient
    
-   details on each response
    
-   the date and time the event was queued to be sent
    

For more information about types of campaign responses, see [Tracking Campaign Responses](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N990539.html).

## To view the Campaign Response Detail report: {#bridgehead_N1012998}

Go to _Reports > Marketing > Campaign Response > Detail_.

You'll see a message that your report is loading. The status bar at the bottom shows the progress as your report loads. You can click Cancel Report next to the status bar if you want to stop the report from loading.

Note:

This report does not support reporting by period even when the Report by Period preference is set to All Reports. You can set the Report by Period preference at _Home > Set Preferences_ > the Analytics subtab.
