The Campaign Clickthrough Summary report shows the specific links clicked by recipients in a marketing email message. In a message with multiple links, the report shows all links recipients clicked. The report displays base URL's and subgroups for each one of them based on the GET parameters appended to them.

For information about how to tie a transaction to a campaign, see [Associating a Transaction With a Campaign](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N991927.html).

## To view the Campaign Clickthrough Summary report: {#bridgehead_4054301175}

Go to _Reports > Marketing > Campaign Clickthrough Summary_.

You'll see a message that your report is loading. The status bar at the bottom shows the progress as your report loads. You can click Cancel Report next to the status bar if you want to stop the report from loading.

Note:

This report does not support reporting by period even when the Report by Period preference is set to All Reports. You can set the Report by Period preference at _Home > Set Preferences_ > the Analytics subtab.
