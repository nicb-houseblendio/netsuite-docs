If this campaign tracks revenue and leads generated for paid search engine keywords, enter keyword information on the Keyword subtab.

Note:

NetSuite provides two other methods to enter keyword campaigns in bulk. For more information, see [Creating Keyword Campaigns in Bulk](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1005080.html).

#### To add paid search keyword information to a campaign: {#procedure_N987299}

1.  On the campaign record, click the **Keyword** subtab.
    
2.  Select the family this keyword belongs to.
    
    Keyword families represent larger groupings of paid keywords. For more information, see [Campaign Families](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1006480.html).
    
3.  Select the search engine you purchased this keyword from.
    
    For more information, see [Campaign Search Engines](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1018748.html).
    
4.  In the **Keyword** field, enter the keyword tracked by this campaign.
