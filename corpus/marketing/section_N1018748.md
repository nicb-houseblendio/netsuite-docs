You can create campaign search engine records for the search engines from which you buy keywords.

When you create a campaign record for a keyword, you can select the search engine on the Keyword subtab. You can also customize campaign reports to include information about search engines. The Search Engine Name field is a part of the Lead Source component. For more information, see [Report Customization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N736328.html).

To create a record of a search engine, go to _Setup > Marketing > Campaign Management > Search Engines > New_.
