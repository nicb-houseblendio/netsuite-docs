The Campaign Response Summary report shows when each campaign and campaign event was delivered and gives information about the responses of recipients. Campaigns are grouped by campaign category.

This report shows the following information about each marketing campaign event:

-   date scheduled
    
-   number of messages sent
    
-   number and percentage of messages opened (email only)
    
-   number and percentage of recipients who clicked any link in the message (email only)
    
-   number and percentage of messages that the recipient responded to
    
-   number and percentage of recipients that purchased because of the campaign
    
-   number and percentage of failed messages that were not delivered
    

For more information about types of campaign responses, see [Tracking Campaign Responses](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N990539.html).

Purchases are tracked as Default Events. To view additional information about purchaser count, use the [Campaign Response Detail Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1012922.html).

## To view the Campaign Response Summary report: {#bridgehead_N1012735}

Go to _Reports > Marketing > Campaign Response_.

You'll see a message that your report is loading. The status bar at the bottom shows the progress as your report loads. You can click Cancel Report next to the status bar if you want to stop the report from loading.

Note:

This report does not support reporting by period even when the Report by Period preference is set to All Reports. You can set the Report by Period preference at _Home > Set Preferences_ > the Analytics subtab.
