Note:

This topic is unrelated to marketing campaigns. For information about campaigns, see [Email Marketing Campaigns](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N992514.html).

To create a letter template, you must first download the sample data source file from NetSuite. This data file contains all of the tags you can include in your template.

Download this sample data source file one time, and then use the file for each letter template you create.

#### To download the sample source file: {#procedure_N526003}

1.  Go to _Documents > Templates > Letter Templates > New._.
    
2.  On the Letter Template page, click the sample source file link at the top of the page.
    
3.  Save this file to your hard drive.
    

After you download the sample data source file, you can use Microsoft Word to create the template.
