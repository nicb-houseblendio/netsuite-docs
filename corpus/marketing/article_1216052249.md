This dataset enables you to analyze conversions based on intelligent item recommendations (IIRs) and view estimated revenue. This dataset forms part of the source data for the [Intelligent Item Recommendations: CRM Conversion Workbook](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1216051919.html)

## Dataset Configuration {#subsect_1216052546}

The Intelligent Item Recommendations: CRM Conversion dataset contains fields from five record types and one custom formula. To edit the dataset, see [Defining a Dataset](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544122173.html).

| Root Record Type | Joined Record Type | Custom Formula Fields | Data Grid | Criteria Filters |
| --- | --- | --- | --- | --- |
| CRM Conversion | 
-   Transaction Line
-   Transaction
-   Item
-   Entity

 | Created Date

-   CAST\_TO\_DATE({tranline.transaction.createddate})

 | The following record fields are included in the dataset: **CRM Conversion**:

-   Transaction Line
-   Use Cases

**Transaction Line:**

-   Amount (Credit) (Transaction Currency)

 | (none) |
