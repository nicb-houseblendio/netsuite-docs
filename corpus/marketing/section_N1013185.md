The Lead Source Analysis Summary report shows the number of lead, prospect, and customer records entered during the time period set for each lead source. It also shows campaign events.

The leads included in this report represent:

-   Records that were originally entered as leads during the time period selected
    
-   Records that have had a lead status that is set to be included in reports
    

Records entered as prospect or customer records during this time period are not included in this report.

A lead source is also attached to a customer if:

-   a lead source is manually selected on the record
    
-   a record is created when the customer fills out an online customer form and selects a lead source
    
-   there are parameters in the online customer form link
    

If you use the Marketing Automation feature, the lead source list contains created campaigns. The Lead Source Analysis Summary report then lists the campaigns you have available, and the number of leads, prospects, or customers added for each.

If you do not use Marketing Automation, you can create a new lead source at _Setup > Sales > Setup Tasks > CRM Lists > New_.

## To view the Lead Source Analysis Summary report: {#bridgehead_N1013285}

Go to _Reports > Marketing > Lead Source Analysis_.

You'll see a message that your report is loading. The status bar at the bottom shows the progress as your report loads. You can click Cancel Report next to the status bar if you want to stop the report from loading.

Note:

This report does not support reporting by period even when the Report by Period preference is set to All Reports. You can set the Report by Period preference at _Home > Set Preferences_ > the Analytics subtab.
