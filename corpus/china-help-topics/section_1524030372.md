China Localization in NetSuite is provided through the China Localization SuiteApp. China Localization gives you features made for Chinese business needs. This includes accounting vouchers, localized financial reports, localized VAT invoices, and localized transaction and entity fields. For more information, see [Installing China Localization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164499038294.html).

Note:

China Localization supports both accounts with SuiteTax and accounts without SuiteTax. If your account uses SuiteTax, you can install China Localization SuiteApp before or after installing SuiteTax Engine. For more information, see [Installing China Localization In Accounts With Suitetax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_165164238938.html).

Installing the China Localization SuiteApp automatically adds the following to your NetSuite account:

-   A new custom role named China Accountant. This custom role gives full permissions to all China Localization features. Customize or create new roles based on the China Accountant custom role. To customize this role, See [Changing Custom Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N289485.html).
    
-   China Cash Flow Statement Report template. See [China Cash Flow Statement Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1524052340.html)
    
-   China Balance Sheet Report templates. See [China Balance Sheet Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1524051146.html)
    
-   Configurable China Income Statement Report templates. See [China Income Statement Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1524054339.html)
    

The following features are available for China Localization:

-   Generating China VAT Invoices.
    
-   VAT transaction data flatfile export and import function for use with the Golden Tax System.
    
-   Viewing and Printing China Accounting Vouchers.
    
-   China Balance Sheet Report.
    
-   Cash Flow Statement Report.
    
-   China Income Statement Report.
    
-   Golden Tax System Integration API
    

You will need to configure the following before using all of the China Localization features:

-   Set your General Company Preferences. See [Setting Up General Company Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159901413526.html).
    
-   Configure your custom transaction forms. See [Setting Up Custom Transaction Forms for China](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160751082499.html).
    
-   Define your chart of accounts. See [Setting up China Cash Flow Item for Chart of Accounts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1524033569.html).
    
-   Define the China Max VAT Invoice Amount for the company or subsidiary. See [Setting the China Max VAT Invoice Amount](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1524034456.html).
    
-   Define Item Models in your inventory. See [Setting Up China Item Models for Inventory Items](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1524035256.html).
    
-   Define China Cash Flow Item in your Item Records. See [Setting Up China Cash Flow Item for Inventory Items](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1524033699.html).
    
-   Define China Cash Flow Item in your chart of accounts. See [Setting up China Cash Flow Item for Chart of Accounts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1524033569.html).
    
-   Define the Default Cash Inflow Item and the Default Cash Outflow Item fields in your subsidiary. See [Setting Up China Cash Flow Item for Subsidiary](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1552981384.html).
    
-   Define Taxpayer Types for customers, leads, and prospects. See [Setting China VAT Taxpayer Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1524036303.html).
    
-   Define China Bank Account Name for customers. See [Setting Up China Bank Account Name](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1524036005.html).
    
-   Customize roles for accessing the China Localization features. See [Roles and Permissions in China Localization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1536221688.html).
    
-   Enable or disable China Localization features. See [Enabling or Disabling China Localization Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1535958706.html).
    
-   (Optional) Enable and set up Golden Tax System integration. See [Enabling and Configuring China Golden Tax System Integration](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1553559863.html).
    
-   Customize the China Balance Sheet Report. See [Customizing the China Balance Sheet Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1524051871.html).
    
-   Customize the China Income Statement Report. See [Customizing China Income Statement Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1524054844.html).
