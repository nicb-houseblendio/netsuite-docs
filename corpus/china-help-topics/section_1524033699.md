Note:

This feature requires the China Localization SuiteApp

NetSuite China Localization adds a China Cash Flow Item field to inventory items. NetSuite uses this field to generate the China Cash Flow Statement report. For more information about how the China Localization SuiteApp works, see [Cash Flow Item Default Logic For China Cash Flow Values In Transactions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1524053754.html).

#### To setup China Cash Flow Item in Inventory Items:

1.  Go to Lists > Accounting > Items.
    
2.  Find an item.
    
3.  Click **Edit**.
    
4.  In the **China Cash Flow Item** field, select the China cash flow classification from the drop down list. See [China Cash Flow Item Classification](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1524034299.html) for details.
    
5.  Click **Save**.
