## Overview {#bridgehead_1535939983}

NetSuite China Localization enables you to set the China Cash Flow Item field as a required field when creating transactions. You can set this according to your company's policy. This can be set company-wide or per subsidiary (OneWorld).

This setting is disabled by default. After activation, the **China Cash Flow Item** field is set as required in the following transactions:

-   Accounts Receivable - Invoice, Cash sales, Cash refund, Credit memo, Customer Deposit, Customer Refund.
    
-   Accounts Payable - Bill, Expense Report, Credit, Checks.
    
-   Journals - using bank account.
    

Note:

For every Sales Order that creates a China Invoice, you'll need to enter a value in the China Cash Flow Item. This is because the invoices will now require the China Cash Flow Item to be entered or set per line item or for the whole transaction. You'll get validation errors if you try to save invoices without a value for this field. In this case, you should set up default values for China Cash Flow Item for inventory items and for the chart of accounts. For more information, see [Setting Up China Cash Flow Item for Inventory Items](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1524033699.html) and [Setting up China Cash Flow Item for Chart of Accounts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1524033569.html).

## Toggle China Cash Flow Item Field as Mandatory {#bridgehead_1535939999}

The following describes the procedures to enable or disable this feature.

#### To Toggle China Cash Flow Item Field as Mandatory:

1.  Go to Setup > Company > Subsidiaries.
    
2.  Choose a subsidiary and click **Edit**.
    
3.  Check the **China Cash Flow Item Mandatory** box.
    
4.  Click **Save**.
