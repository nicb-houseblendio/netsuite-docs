## Overview {#bridgehead_1524029388}

The following help topics provide information about NetSuite features that are specific to companies doing business in China. You can set up the NetSuite International Edition with features and reports for Chinese business setting and requirements.

For more information about localized NetSuite editions, and how to set up accounts and subsidiaries, see these Help topics:

-   [NetSuite Editions Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N270055.html)
    
-   [Set up NetSuite OneWorld](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N268052.html)
    
-   [Set up NetSuite OneWorld](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N268052.html)
    
-   [Introduction to NetSuite OneWorld](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N266468.html)\- for companies using NetSuite across multiple subsidiaries and countries.
    

General NetSuite features are covered in other chapters and topics.

| Functional Area | Feature | Description |

| [Setting Up China Cash Flow Item for Inventory Items](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1524033699.html) | NetSuite China Localization adds the China Cash Flow Item field for inventory items. |
| [Setting Up China Cash Flow Item for Subsidiary](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1552981384.html) | NetSuite China Localization adds the China Cash Flow Item field for subsidiaries. This setting affects all of the transactions made in the subsidiary for items without a Cash Flow Item configured for inventory items. |
| [Generating China Voucher Printing Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1524044318.html) | The China Voucher Printing Report enables you to print your company's accounting vouchers. |
| [Generating the China Voucher List](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544494013.html) | The Voucher List feature enables you to generate voucher lists for printing, reviewing voucher details, and tracking back to transaction record. You can also print single and multiple vouchers. |
| Banking | [Setting Up China Bank Account Name](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1524036005.html) | In China, a bank account name is needed when issuing VAT invoices to general taxpayer customers. |
| Taxation | [Setting China VAT Taxpayer Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1524036303.html) | In China, customers are divided into two categories: General Taxpayers and Small-Scale Taxpayers. These two customer types issue different VAT invoice types. Setting this automatically determines the VAT invoice type when making a sale. |
| [Processing Red-Letter Invoices](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1524042810.html) | In China, Red-Letter Invoices are issued for returns and refunds. |
| [Generating China VAT Transactions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1524045813.html) | In China, the Golden Tax System is the only mandated system by the government to issue VAT invoices. The NetSuite China Localization enables you to generate a flatfile for exporting your transaction data. This exported data can be used in interfacing with the Golden Tax System. |
| [Merging China VAT Transactions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1527660084.html) | NetSuite China Localization enables you to merge several transactions into one China VAT invoice. |
| [Importing VAT Transactions from the China Golden Tax System](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1524050168.html) | The NetSuite China Localization enables you to import your transaction data from the Golden Tax System. Importing your data pairs them with your transactions in NetSuite. |
| [Enabling and Configuring China Golden Tax System Integration](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1553559863.html) | The NetSuite China Localization provides an Application Programming Interface (API) that you can configure and use to build integrations with the China Golden Tax System. |
| Financial Statements | [China Balance Sheet Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1524051146.html) | The China Balance Sheet Report shows a summary of assets, liabilities, and equity in a particular month, quarter, or year. The report is presented in the prescribed layout. |
| [China Cash Flow Statement Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1524052340.html) | The China Cash Flow Statement Report shows a company's cash flow for a specific period. The report is presented in the prescribed layout. |
| [China Income Statement Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1524054339.html) | The China Income Statement Report shows a company's income, expenses, and net income for a specific period. The report is presented in the prescribed layout. |
| Financial Reports | [China Account Balance Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1536115766.html) | The China Account Balance Report contains account balances filtered and grouped according to subsidiary, date range, account level, and account range in a China specific layout. |
| [China Subledger Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1536188448.html) | The China Subledger Report contains financial transactions which covers the chart of accounts, debit and credit columns, and a document printing format specific to Chinese local practices. |
| [China Cash & Bank Journal Ledger Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1536193809.html) | The China Cash & Bank Journal Report shows journal activities in relation to a company's cash and bank accounts. This can be configured according to subsidiary, date range, and account range presented in a China specific layout. |

## Available SuiteApps {#bridgehead_1524030002}

Some additional features will only be active if you install a specific SuiteApp in your NetSuite account. SuiteApps are applications that add features to NetSuite for different industries and business needs. If you would like to access specific product area, refer to [Functional Areas](#bridgehead_84192329457) to see which SuiteApps you need to install. The following SuiteApps have features for Taiwan (Province of China):

| SuiteApp | Description |
| --- | --- |
| [Installing China Localization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164499038294.html) | Provides China-specific features including accounting vouchers, localized financial reports, localized tax reports, and localized transaction and entity fields. |
