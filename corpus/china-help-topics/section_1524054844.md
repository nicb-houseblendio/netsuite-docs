Note:

This feature requires the China Localization SuiteApp.

NetSuite China Localization provides a default Chinese Income Statement Report template for companies to use immediately. To align the report with statutory requirements, the China Income Statement Report needs to be customized according to the company's chart of accounts.

#### To Customize the China Income Statement report:

1.  Go to Reports > New Financial Report.
    
2.  Select Custom Income Statement Layout (CN)
    
3.  On the Edit Layout section, enter a name for the report.
    
4.  Edit the report layout as needed. Define the rows you want to include in your report. For more information about working with report layouts, see [Financial Statement Rows](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2115374.html).
    
5.  (Optional) Click **Preview** to see your changes before saving.
    
6.  Click **Save**. This adds the report to your Saved Reports.
