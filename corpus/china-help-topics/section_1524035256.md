An **Item Model** is an optional field when generating China VAT Invoices. NetSuite China Localization lets you automatically fill in these descriptions for every transaction using the Item Model field.

## Setup China Item Model for Existing Items {#bridgehead_1524035336}

NetSuite China Localization lets you set up an Item Model for existing items in your inventory.

#### To setup models for an existing item

1.  Go to Lists > Accounting > Items.
    
2.  Scroll through the list and look for the item you want to edit.
    
3.  Click **Edit**.
    
4.  In the **China VAT** subtab, enter a mode name in the **China VAT Item Model** field.
    
5.  Click **Save**.
    

## Setup China Item Model for New Items {#bridgehead_1524035577}

NetSuite China Localization lets you set up an Item Model when you're creating new items in your inventory.

#### To setup models when creating a new item

1.  Go to Lists > Accounting > Items > New.
    
2.  Click the type of item you want to create. For more information about the types of items you can create, see [Item Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N2222944.html).
    
3.  Select a form in the **Custom Form** field. For more information about custom forms, see [Custom Forms](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N2852749.html)
    
4.  Enter additional information as necessary. You can enter general information in the item record header. You can also enter information about the available subtabs. See [Creating Item Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2166469.html)
    
5.  In the **China VAT** subtab, enter a mode name in the **China VAT Item Model** field.
    
6.  Click **Save**.
    

Note:

Make sure you define the Item Model for your items before making a transaction to avoid issues when generating your VAT Invoices.
