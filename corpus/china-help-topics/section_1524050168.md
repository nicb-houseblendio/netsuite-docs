Note:

This feature requires the China Localization SuiteApp.

NetSuite China Localization enables you to import your VAT invoice data from the China Golden Tax System. The Golden Tax System is a mandated system that processes your exported transaction data from NetSuite.

For more information about exporting VAT transactions, see [Generating China VAT Transactions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1524045813.html).

When you import transactions from the China Golden Tax System, they'll pair with your existing transactions in NetSuite.

#### To Import VAT transaction data from the Golden Tax System to NetSuite:

1.  Go to Transactions > Sales > Generate China VAT transactions.
    
2.  Click **Import**.
    
3.  Under **File Upload**, click **Choose File**.
    
4.  In the popup window, go to the folder and select the file containing the processed VAT invoices from the Golden Tax System.
    
5.  Click **Open**.
    
6.  Click **Import**. The page refreshes and a confirmation message appears.
