## Overview {#bridgehead_1524027094}

The China Localization SuiteApp provides features necessary for companies operating in China. These features improve company, subsidiary, and transaction records in NetSuite. This SuiteApp provides the following:

-   Generating China VAT Transactions
    
-   VAT transaction data flatfile export and import function for use with the Golden Tax System
    
-   Viewing and Printing China Accounting Vouchers
    
-   China Balance Sheet Report
    
-   China Cash Flow Statement Report
    
-   China Income Statement Report
    
-   China Account Balance
    
-   China Cash & Bank Journal Ledger
    
-   China Subledger

## Installing the China Localization SuiteApp {#bridgehead_1524027613}

The China Localization SuiteApp (Bundle ID: 217320 ) is a public managed SuiteApp, and is automatically updated whenever there are enhancements or new features added.

#### To install the China Localization SuiteApp:

1.  Go to Customization > SuiteBundler > Search & Install Bundles and enter **China Localization** in the search field.
    
2.  In the results, click **China Localization** with the bundle ID **217320**.
    
3.  On the bundle details page, click **Install**.
    

You need to have the Administrator role to install SuiteApps. This SuiteApp is a managed bundle and updates automatically when there are new features or fixes.

For more information about installing SuiteApps, see [Installing a Bundle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3395142.html)

If you're installing the China Localization SuiteApp in accounts with SuiteTax, see [Installing China Localization In Accounts With Suitetax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_165164238938.html).

Warning:

Uninstalling the China Localization SuiteApp will result in losing all China Cash Flow Item data in your account.
