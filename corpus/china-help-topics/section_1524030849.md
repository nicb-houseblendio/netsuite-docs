The following are known limitations of NetSuite China Localization:

-   The feature supports two languages: Chinese and English (International).
    
-   Data governance limits for the following:
    
    -   The Generate China VAT Transactions page displays a maximum of 10000 lines or 200 invoices.
        
    -   The Generate China VAT Transactions page can import only fifty (50) VAT invoices per file.
        
    -   The China Subledger Report and the China Cash & Bank Journal Report has a 5,000 transaction line limit for the report display. If the data requested goes beyond this limit, the report display will not show any data and will prompt you to download the report in Excel (.xls) or in PDF.
        
-   The Multi-book feature is not supported.
    
-   Some Field-Level Help text is available only in Chinese.
    
-   The **China Cash Flow Statement Report** needs the **Expense Reports** feature enabled to capture transactions.
    
-   The **Custom Vendor Prepayment Form** from China Localization may not always be the default for vendor prepayment transactions, even if it's preferred. You need to set this form manually when this happens. See [Manually Select Custom Vendor Prepayment Form for China Transactions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160751082499.html#bridgehead_160981306091) for more information.
    
-   Enabling or Disabling the **Use Account Numbers** feature in the company or subsidiary **General Accounting Preferences** settings will require you to log off and log in again to continue using **NetSuite China Localization** features. See [General Accounting Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1385293.html) for more information about setting accounting preferences.
