## Set Up China Voucher List Preferences {#bridgehead_1553234278}

You can set printing preferences for the China Voucher List, like picking templates, data sources, and whether to include Location/Department/Class or Vendor/Customer/Employee in your voucher list.

#### To Set Up China Voucher List Preferences: {#procedure_1544671620}

1.  Go to Setup > China Localization > Preferences > Voucher List tab.
    
2.  Here's what you can set up under the **Voucher List** tab:
    
    -   Select the maximum volume of loaded vouchers in the **Max Loaded Transactions (100-5000)** field. If you skip this, it defaults to 500.
        
    -   Select the printing template:
        
        Note:
        
        Templates with **New** at the start let you use more characters in the account description and memo columns, and they can include entity data in each line item.
        
        -   Single Currency Double Vouchers On A4
            
        -   Single Currency Single Voucher On A4
            
        -   Single Currency Single Voucher On A5
            
        -   Multi-currencies Double Vouchers On A4
            
        -   Multi-currencies Single Voucher On A4
            
        -   Multi-currencies Single Voucher On A5
            
        -   New Multi-currencies Double Vouchers On A4
            
        -   New Multi-currencies Single Voucher On A4
            
        -   New Multi-currencies Single Voucher On A5
            
        -   **Custom Template** - You can create your own template using freemarker and use it to print your voucher list. Saved search is used for your data sources.
            
            -   In the **Search** field, select the name of the custom template you have uploaded.
                
            -   In the **Select a Saved Search As Data Source** drop down, select a saved search. For more information about saved searches, see [Saved Searches](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N675442.html).
                
    -   Choose whether to print **Location/Department/Class** for single currency templates.
        
    -   Choose whether to include **Vendor/Customer/Employee** on your reports.
        

Note:

You can only select **Location/Department/Class** and **Vendor/Customer/Employee** for **Multiple Currency** templates if you're using A4 single voucher or one of the new multiple currency templates.

These preferences only apply to the **China Voucher List** and don't affect the **China Voucher Printing Report**. For details on generating accounting voucher printouts, see [Generating China Voucher Printing Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1524044318.html).

## Customizing China Voucher List Templates {#bridgehead_1553234375}

You can customize or upload your own China Voucher List Template to use when printing the China Voucher List. You can adjust these layout elements:

-   Truncation
    
-   CSS style margin and padding
    
-   Font: font family, font size
    
-   Bold, color, alignment, background color
    
-   Table border styles
    
-   Height and width of any element
    
-   Pagination
    
-   Column and row styles
    
-   Element position
    

After you've customized your template, upload it to your file cabinet in the **自定义凭证模板\_中国本地化** folder.

Note:

Make sure you define your own templates for the China Voucher List. If a template isn't set up right, you'll get an error when generating or printing your voucher list.
