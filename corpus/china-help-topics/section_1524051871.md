Note:

This feature requires the China Localization SuiteApp.

NetSuite China Localization provides a default balance sheet template for companies to use immediately. To meet statutory requirements, you'll need to customize the China Balance Sheet Report to match your company's chart of accounts.

#### To Customize the China Balance Sheet Report:

1.  Go to Reports > Saved Reports > China Balance Sheet Template\_English > Customize. For the Chinese version, Reports > Saved Reports > 中国资产负债表模板\_中文 > Customize.
    
2.  On the **Edit Layout** section, enter a name for the report.
    
3.  Edit the report layout as needed. Ensure to define the following rows for the report:
    
    | **Header Line Items** | **Summary Line Items** |
    | --- | --- |
    | 资产（Assets） | 资产总计(Total of Assets) |
    | 流动资产(Current Assets)： | 流动资产合计(Total of Current Assets) |
    | 非流动资产(Non-current Assets)： | 非流动资产合计(Total of non-current Assets) |
    | 负债和所有者权益（或股东权益） (Liabilities and Owner's Equity) | 负债和所有者权益（或股东权益）总计 （Total of Liabilities and Owner's equity） |
    | 负债(Liabilities) | 负债合计(Total of liabilities) |
    | 流动负债(Current Liabilities)： | 流动负债合计(Total of current liabilities) |
    | 非流动负债(Non-current Liabilities)： | 非流动负债合计(Total of non-current liabilities) |
    | 所有者权益（或股东权益）(Owner's equity)： | 所有者权益（或股东权益）合计(Total of owner's equity) |
    
    For more information about working with report layouts, see [Financial Statement Rows](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2115374.html).
    
4.  In the **Edit Columns** section, add two new columns: **Closing Balance** and **Opening Balance**. For more information about using this feature, see [Financial Report Builder Edit Columns Page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2106822.html).
    
5.  Set **Alternate Period Range Type** to **Relative to Report Date**.
    
6.  (Optional) Click **Preview** to see your changes before saving.
    
7.  Click **Save**. This adds the report to Reports > Saved Reports.
