This feature requires the China Localization SuiteApp.

NetSuite China Localization provides the following reports for companies operating in China:

| **Report** | **Available In** |
| --- | --- |
| [China Balance Sheet Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1524051146.html) | China Localization SuiteApp |
| [China Cash Flow Statement Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1524052340.html) | China Localization SuiteApp |
| [China Income Statement Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1524054339.html) | China Localization SuiteApp |
| [China Account Balance Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1536115766.html) | China Localization SuiteApp |
| [China Subledger Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1536188448.html) | China Localization SuiteApp |
| [China Cash & Bank Journal Ledger Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1536193809.html) | China Localization SuiteApp |
