## Overview {#bridgehead_1536188639}

The China Subledger Report contains non-cash and bank-related financial transactions covering the chart of accounts, debit and credit columns, and a document printing format specific to Chinese practices:

-   For each account, the first row starts with the **Opening Balance**. The transactional lines follow.
    
-   The monthly totals, yearly totals, and the account subtotals follow for each account.
    

If you select a Location, Class, or Department, they'll appear on the report. Leave these fields blank to exclude them from the report.

When a report is generated, click the document number to show the GL impact for review.

## Generate China Subledger Report {#bridgehead_1536189804}

Follow these steps to generate the China Account Balance Report.

#### To Generate China Subledger Report

1.  Go to Reports > Financial > China Subledger.
    
2.  In the **Subsidiary** field, select a subsidiary.
    
3.  In the **Date From** field, select the report starting date.
    
4.  In the **To** field, select the report ending date.
    
5.  (Optional) In the **Account From** field, select an account to start filtering from.
    
6.  (Optional) In the **To** field, select an account the report filter ends with.
    
7.  (Optional) In the **Accounting Context** field, select an accounting context. For more information, see [Accounting Contexts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4640155582.html).
    
8.  (Optional) In the **Location** field, select a location.
    
9.  (Optional) In the **Department** field, select a department.
    
10.  (Optional) In the **Class** field, select a class.
     
11.  Click **Refresh**.
     
12.  (Optional) Click a document number under the **Document Number** column to view its transaction details.
     
13.  (Optional) Click **Export - PDF** to save the report in PDF format.
     
14.  (Optional) Click **Export - Excel** to save the report in Excel (.xls) format.
