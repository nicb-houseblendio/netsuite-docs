Before installing the Israel Localization SuiteApp, your account administrator must enable several features and preferences in your NetSuite account.

## Required Licenses {#bridgehead_162426985963}

To install Israel Localization SuiteApp, you must obtain NetSuite SuiteApps License Client and have a OneWorld account installed.

#### To access the features of the Israel Localization SuiteApp:

1.  Install the NetSuite SuiteApps License Client (Bundle ID 116144).
    
2.  Obtain a license for the Israel Localization SuiteApp. To do this, contact your account manager who will arrange for a license to be generated.
    
3.  Verify that the NetSuite SuiteApps License Client has the license 'NetSuite Israel Localization' active.
    

If the license client is not installed or your license expires, you will not be able to use the features of the SuiteApp. For more information, see the [NetSuite SuiteApps License Client Guide for Administrators](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4635371677.html). Contact your account representative to reinstate any stale licenses.

## Required SuiteApps {#bridgehead_162426998703}

Before installing the Israel Localization SuiteApp, you must first install the **NetSuite SuiteApps License Client**.

## Required Features {#bridgehead_162427015266}

To install Israel Localization SuiteApp, you must enable required features.

#### To enable required features:

1.  Go to _Setup > Company > Enable Features_.
    
2.  On the **Company** subtab, go to the **International** subtab, and check the **Multiple Currencies** box.
    
3.  On the **Accounting** subtab, go to the **Basic Features** section and check the **Accounting** box.
    
4.  On the **Tax** subtab, check the **Advanced Taxes** box.
    
    Important:
    
    SuiteTax is not yet compatible with Israel Localization. If your account uses SuiteTax, you will not be able to install the Israel Localization SuiteApp.
    
5.  On the **SuiteCloud** subtab, enable the following features:
    
    -   In the **SuiteBuilder** section, enable the **Custom Records** and **Advanced PDF/HTML Templates** features.
        
    -   In the **SuiteScript** section, enable the **Client SuiteScript** and **Server SuiteScript** features.
        
    -   In the **SuiteTalk** section, enable the **SOAP Web Services** feature.
        
    
    For more information about SuiteCloud features, see [SuiteCloud Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N239332.html).
    
6.  On the **Analytics** subtab, go to the **Saved Search** section and check the **HTML Formulas in Search** box.
    
7.  Click **Save**.
    

For more information, see [Enabling Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N232138.html).

If you use multi-book feature, make sure that either the primary or secondary book in the Israeli Subsidiary setup has the functional currency set to ILS.

#### To set the functional currency to ILS:

1.  Go to _Setup > Company > Subsidiaries_, and click the **Edit** link next to the applicable subsidiary.
    
2.  Verify that the **Country** field displays **Israel**.
    
3.  Verify that the **Currency** field displays **ILS**. For more information, see [Creating Currency Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1395911.html).
    
    On the **Accounting Books** subtab, you can see any additional accounting books and their currencies.
