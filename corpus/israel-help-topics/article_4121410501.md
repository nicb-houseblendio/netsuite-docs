The following help topics provide information about NetSuite features that are specific for companies doing business in Israel. The NetSuite International Edition can be configured with capabilities and reports specific to an Israel business setting and requirements.

To learn more about localized editions of NetSuite, as well as setting up NetSuite accounts and subsidiaries, refer to the following help topics:

-   [NetSuite Editions Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N270055.html)
    
-   [Set up NetSuite OneWorld](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N268052.html)
    
-   [Creating Subsidiary Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N272471.html)
    
-   [Introduction to NetSuite OneWorld](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N266468.html) - for companies using NetSuite across multiple subsidiaries and countries
    

Note that general NetSuite features are covered in other chapters and topics.

## General Setup {#bridgehead_46134548337}

[Israel Account Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1018021142.html): Provides an overview of NetSuite features to be enabled by the user in Israel and SuiteApps available for installation.

[Setting Up Israel-specific Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1018024547.html): Set up your NetSuite company and user preferences for Israel, including date, currency, language, time zone, and support for Israeli number, phone, and address format.

Important:

SuiteTax is not yet compatible with Israel Localization. If your account uses SuiteTax, you will not be able to install the Israel Localization SuiteApp.

## Functional Areas {#bridgehead_57134711584}

Israeli users can activate and get access to different features from the following functional areas:

-   [Accounting](#bridgehead_59135309923)
    
-   [Banking](#bridgehead_45133622728)
    

To learn more about SuiteApps installation, see [Installing a Bundle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3395142.html).

To learn more about enabling NetSuite features, see [Enabling Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N232138.html).

Important:

If you don't have sufficient permissions to install SuiteApps or enable features, please contact your account administrator.
