IL Shaam Import & Export file is used for mass updates for vendors and withholding tax certificates.

The Withholding Tax details must be defined for each supplier on the supplier definition page on the **Israeli Tax Certificates** subtab.

## Creating SHAAM Export File {#bridgehead_162445113053}

With the Israel Localization SuiteApp, it's possible to create a SHAAM Export File.

#### To check vendor information:

Note:

In order to pull up-to-date data from a SHAAM, the VAT number & withholding tax group must be set.

1.  Go to Reports > Israeli Interface with Shaam > IL Shaam Vendor List Results.
    
2.  Use the IL Shaam Vendor List Results Report to check for missing WHT information.
    

#### To export the file to SHAAM:

1.  Go to Reports > Israeli Interface with Shaam > IL Shaam Export File.
    
2.  From the **Subsidiary** list, select the applicable subsidiary.
    
3.  Select the **File Type**.
    
4.  Click **Generate File**. The file downloads to the "Downloads" directory on your computer or exports to Excel.
    
5.  When it's completed, upload the file to IRS website site.
    

#### To generate a SHAAM File 1000 using the new format:

1.  Go to Reports > Israeli Interface With Shaam
    
2.  Select **IL Shaam Export File**.
    
3.  Choose the appropriate subsidiary.
    
4.  In the **File Type** filed, select: **קובץ 1000 - File 1000**(the first radio button).
    
5.  In the **Included in the Original Tax Report** field, select **כן - yes**(the first option).
    
6.  Click the **Generate File** button.
    
7.  Go to the Tax Authority Website.
    
8.  On the website, always select: **New Format of File with the Entity Number** (the first radio button).
    

The generated SHAAM file includes both the **Tax Registration Number** (appears twice) and the **Taxpayer ID** (appears once) as incorporated in the vendor details.

## Importing the SHAAM File to NetSuite {#bridgehead_162445148168}

With the Israel Localization SuiteApp, it's possible to import a SHAAM Export File.

#### To import the SHAAM file to NetSuite:

1.  Go to Reports > Israeli Interface with Shaam > IL Shaam Import File > New.
    
2.  From the **Subsidiary** list, select the applicable subsidiary.
    
3.  To upload the file, click the plus icon (that will appear if you hover over or next to the טעינת קובץ field). Select the file to upload from either your computer or NetSuite library.
    
4.  When the upload is finished, save (to exit), and then save again.
    
5.  Click **Update withholding tax data**.
    
6.  Click **OK** to proceed with the update. Upon completion of the update process, you will receive an e-mail with the update results.
    

## Bank Statement Import {#bridgehead_162445167326}

To use NetSuite's Bank Import functionality, a feature is provided which converts Israeli Bank statements to QFX format. To download the file converter, go to Transactions > Bank > Israeli Import Banking Data.
