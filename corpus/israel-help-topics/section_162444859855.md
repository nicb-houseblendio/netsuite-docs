Below are the guidelines on how to process Israeli EFT payment (MASAV). MASAV is the Israeli Clearing House. This does not leverage NetSuite Electronic Payments SuiteApp. To use MASAV, the company must register first to the Israeli Clearing House and get the **EFT Institute** and **EFT Subject** numbers. MASAV provide the details needed in the process below.

#### To set up the EFT (MASAV) account:

1.  Go to _Setup > Accounting > Chart of Accounts > New_.
    
2.  To define **EFT** (MASAV) account, fill out all the required fields.
    
3.  From the **Type** list, select **Credit Card**.
    
4.  From the **Subsidiaries** list, select the applicable Israeli subsidiary.
    
5.  Click **Save**
    

#### To set up EFT Institute:

1.  Go to Customization > Lists, Records & Fields > Record Types
    
2.  Locate **IL EFT Institute** record and click the **List** link to create a new record.
    
3.  Click the **New IL EFT Institute** button.
    
4.  Enter the five-digit numbers in the **Institute Number** field received from the Israeli Clearing House.
    
5.  From the **Subsidiaries** list, select the applicable Israeli subsidiary.
    
6.  Click **Save**.
    

#### To set up IL EFT Subject:

1.  Go to Customization > Lists, Records & Fields > Record Types
    
2.  Locate the **IL EFT Subject** record and click the **List** link to create a new record.
    
3.  Click the **New IL EFT Subject**
    
    button.
    
4.  Enter the eight-digit numbers in **Subject Number** field received from the Israeli Clearing House.
    
5.  From the **Subsidiaries** list, select the applicable Israeli subsidiary.
    
6.  Click **Save**.
    

#### To set up the EFT account on Vendor record:

Note:

If the payment is processed through a commercial bank (not the Israeli Clearing House), add a dummy number to the IL EFT Institute Code (5 digits) and IL EFT Subject field (8 digits). Make sure that the correct type is selected from the File Encoding list.

1.  Go to _Lists > Relationships > Vendors_.
    
2.  Click **Edit** on the applicable vendor record.
    
    Note:
    
    Ensure that **IL Vendor Form** is applied on the selected vendor.
    
3.  Click the **Financial** subtab.
    
4.  From the **Payment Method** list, select **EFT**. This needs to be set for each vendor you are planning to pay through EFT.
    
5.  On the **Israeli Bank Details** subtab, ensure that correct bank details are defined on each vendor record.
    

#### To process bills:

1.  Go to _Transactions > Payables > Enter Bills_.
    
2.  From the **Payment Method** list, select **EFT**.
    
3.  Click **Save**.
    
4.  Go to _Transaction > Payables > Israeli Pay Bills_.
    
5.  On the **Account** subtab, select the new account created in the previous procedure.
    
6.  Set a template for the **Batch Payment Name**, combining the name and date, for example, MASAV31122020.
    
7.  From the **Payment Method** filter, select **EFT**.
    
8.  After selecting the above parameters, all open invoices that match the search will be listed. Select the invoices which need to be paid in this cycle. The Withholding Tax Rates and certificates will be applied, and deductions made where necessary. The deductions are calculated from the information in the Vendor set up.
    
9.  Click **Save**.
    
10.  Generate the payment file. If this is done after saving the payment in the previous section, a screen is shown with an option to select Israeli EFT File Generator. Alternatively, go to _Transactions > Bank > Israeli EFT File Generator_.
     
11.  On the EFT File Generator page, fill out the fields as follows:
     
     -   **PAYMENT METHOD:** EFT.
         
     -   **BANK ACCOUNT:** the bank which is making the payment.
         
     -   **EFT ACCOUNT:** EFT account.
         
     -   **PAYMENT DATE:** transaction/ EFT payment day.
         
     -   **BATCH PAYMENT NAME**
         
     -   **INSTITUTE NUMBER AND SUBJECT NUMBER**
         
     -   **FILE ENCODING:** (Use the default- MASAV). The file encoding ensures that the file appears correctly on the bank's website.
         
12.  Click **Generate**. The excel file is saved in the "Downloads" directory on your computer.
     
13.  When the file is ready and approved, upload it to the MASAV website (Israeli Clearing House) at [https://www.masav.co.il/](https://www.masav.co.il/) or the bank.
     

Note:

The calculation of the payment after withholding tax, based on the percentage updated in the vendor record, is only performed when creating a payment directly from the bill in the UI (Israeli Custom Form only) or through Transactions > Payables > Israeli Pay Bills screen.

Currently, there is no support for withholding tax calculation when importing payments through CSV or through scripts.
