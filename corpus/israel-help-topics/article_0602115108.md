To import your salary file, complete the following steps.

#### To import your salary file: {#procedure_0602115127}

1.  In the top search bar, search for **IL Salary File Import**.
    
2.  On the IL Salary File Import record, click **View**.
    
3.  Click **New IL Salary File Import List**.
    
4.  Export the salary file from the software you use for processing salaries.
    
5.  In the Transaction Details section, fill out the required fields.
    
6.  From the **Salary Software** list, select the applicable salary software.
    
7.  In the **File to Import** field, click the double arrows and select the salary file from your computer.
    
    Note:
    
    If you need to encode your file to UTF8, download the **IL-HebrewToUTF8Encoder Application** from the New IL Salary File Import page and complete the file conversion. The conversion parameters should be set as follows: קידוד מקו ר - DOS-862 (862)- Ensure the **נידרש היפו ך** box is checked.
    
8.  Click the **Perform Import** button. After the import finishes, you will receive an email notification.
    

If the import fails, go to _Setup > Company > General Preferences_ and on the **Custom Preferences** subtab, clear the **IL Salary File Import: Delete File** box. Try to import the file again. If the import succeeds this time, return to _Setup > Company > General Preferences_ and check the **IL Salary File Import: Delete File** box again.
