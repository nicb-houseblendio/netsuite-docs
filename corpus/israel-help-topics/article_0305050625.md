To use the Israel Electronic Invoicing SuiteApp, ensure your account meets all the prerequisites listed on this page:

-   Install the Localization Assistant SuiteApp. For more information, see [Localization Assistant SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_163092114640.html).
    
-   Install the Electronic Invoicing SuiteApp. For more information, see [Electronic Invoicing User Guide](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4581114785.html)
    
-   Install the NetSuite Electronic Business SuiteApp. For more information, see [NetSuite Electronic Business](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_3140642944.html)
