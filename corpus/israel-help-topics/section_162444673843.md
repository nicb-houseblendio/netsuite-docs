The following VAT reports are available for the Israel Localization SuiteApp:

-   **Israeli VAT on Purchases (PCN 874)**: To use this report, define the tax periods, subsidiary, and accounting book. Reports should be generated on a monthly basis. Click refresh, and a list will be shown of all transactions which use the VAT on Purchases code.
    
-   **Israeli VAT on Sales**: Lists all transactions which use the VAT on Sales code.
    
-   **Israeli VAT Summary and Report Generator**: It's used to reconcile VAT on Sales, VAT on Purchases in the summary report and then to generate the ASCII File.
