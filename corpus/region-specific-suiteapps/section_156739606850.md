The SuiteTax Country Tax Reports APAC SuiteApp enables users in supported countries to generate VAT or GST returns and supplementary reports. It supplements Tax Reporting Framework with the country tax report templates and localization for the following countries:

-   Australia - [Business Activity Statement](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156688148769.html)
    
-   New Zealand - [GST Return 101A](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_21151540595.html)
    
-   Philippines:
    
    -   [Philippines VAT Report: Monthly Return Form 2550M](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_35151629781.html)
        
    -   [Philippines VAT Report: Quarterly Return Form 2500Q](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_17151724578.html)
        
    -   [Philippines VAT Report: Quarterly Summary Lists of Sales and Purchases](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_25151653746.html)
        

## Installing SuiteTax Country Tax Reports APAC {#subsect_74174959718}

SuiteTax Country Tax Reports APAC is a managed SuiteApp and is automatically updated whenever there are enhancements or new features added. This SuiteApp is free but must be shared with your NetSuite account before you can install it. To get access to SuiteTax Country Tax Reports APAC, contact your NetSuite account manager. When the SuiteApp is shared with your account, you can install it by performing the following steps.

Important:

This SuiteApp requires the Tax Reporting Framework SuiteApp. To install Tax Reporting Framework, see [Installing Tax Reporting Framework](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1528245293.html).

#### To install SuiteTax Country Tax Reports APAC:

1.  In NetSuite, go to _Customization > SuiteBundler > Search & Install Bundles_.
    
2.  In the **Keywords** field, enter **SuiteTax Country Tax Reports APAC**.
    
3.  Click **Search**.
    
4.  Click **SuiteTax Country Tax Reports APAC**.
    
    Bundle ID 303913.
    
5.  On the Bundle Details page, click **Install**.
    
6.  On the Preview Bundle Install page, confirm that the following actions are applied for each set of conflicting objects:
    
    -   In the Action column, **Replace Existing Object** is selected.
        
    -   In the Preference column, **Replace Data for Conflicting Custom Records and Custom Lists** is selected.
        
    
    For information about the Preview Bundle Install page, see [Reviewing the Preview Bundle Install Page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3396121.html).
    
7.  Click **Install Bundle**.
    
8.  (Optional) Check and view the installation status of the SuiteApp. For more information, see [Viewing the Country Tax Reports Installation Status](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156212484298.html).
    

For more information about installing SuiteApps, see [Installing a Bundle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3395142.html).
