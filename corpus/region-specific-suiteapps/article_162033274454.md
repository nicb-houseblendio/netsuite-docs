Some government authorities may establish codes to identify goods and services that businesses purchase and sell within their territories. Some companies may also assign codes to identify items for internal purposes.

In NetSuite, an item code record classifies one or multiple goods or services. You can associate an item code with item records. For more information, see [Associating Item Codes With Items](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_162033229352.html).

To apply certain tax rules to specific items, you should associate the item code with a tax determination rules record. For more information, see [Creating Tax Determination Rules in the SuiteTax Latam Engine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_162153526964.html).

#### To create an item code:

1.  Go to Setup > Latam Tax Determination > Item Code > New.
    
2.  In the **Name** field, enter a name to identify the item code.
    
3.  In the **Code** field, enter the code associated with the item.
    
    If you're creating this record according to an official list of item codes provided by a government authority, enter the code defined by the authority.
    
4.  In the **Country** field, select the country associated with the item code.
    
5.  (Optional) If you want to include details about the code, in the **Description** field, enter a summary of the item code.
    
6.  (Optional) If you want to associate a specific unit of measure with the item code, in the **Unit of Measure** field, enter the unit of measure.
    
    For example, you can enter UN for unities, or KG for kilos.
    
7.  Click **Save**.
