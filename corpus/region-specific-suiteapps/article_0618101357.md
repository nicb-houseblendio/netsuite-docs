| **Function Declaration** | `function customizeQuery(context)` |
| --- | --- |
| **Type** | Interface function |
| **Description** | Runs a custom logic before running the query. The query object can be modified to accommodate any necessary changes. For example, you can use this function to add filters or conditions to the query. |
| **Returns** | query.Query |
| **Input Parameters** | source: [SectionSource](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0617104601.html), request: [FileProcessingRequestParams](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0617012603.html), sourceQuery: query.Query Note: The query.Query parameter is the object type interface Query from N/query. |
