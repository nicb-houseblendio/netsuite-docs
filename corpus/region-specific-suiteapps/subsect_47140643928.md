Note:

To access the LATAM E-Document Certification SuiteApp documentation in Brazilian Portuguese (Português do Brasil), see [LATAM E-Document Certification](https://system.netsuite.com/help/helpcenter/shared_resources/PDF/LATAMEDocumentCertification_pt_BR.pdf).

If you send e-documents in no particular order, the capacity to process requests depends on the number of SuiteCloud Processors you have available. The more SuiteCloud Processors you have, the more requests a script can handle. For more information, see [SuiteCloud Processors](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1498571420.html).

You can determine the amount of SuiteCloud Processors available to process the e-document certification requests associated with the script provided by the LATAM E-Document Certification SuiteApp. You can change this amount anytime you want.

#### To set the e-document certification requests' processing capacity: {#procedure_0505020831}

1.  Go to _Customization > Scripting > Script Deployments_.
    
2.  Find the script deployment **ECS MR Message Queue Service**, and then click **Edit**.
    
    Tip:
    
    To find the **ECS MR Message Queue Service** script deployment record, under Filters, in the **Type** list, select **Map/Reduce**. The search displays only map/reduce scripts and you can find the script deployment you want among them.
    
3.  In the **Concurrency Limit** field, enter the amount of SuiteCloud Processors available to process the requests.
    
4.  Click **Save**.
    

For more information about map/reduce script deployment records, see [Map/Reduce Script Deployment Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1509578980.html).
