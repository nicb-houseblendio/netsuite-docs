| **Function Declaration** | `function shouldRetryRequest(context)` |
| --- | --- |
| **Type** | Interface function |
| **Description** | Indicates whether the system should try to send the request again when:
-   The response from the tax authority's web service was **null**.
-   The response from the tax authority's web service was different than **200**.

These responses indicate, for example, that the web service is down or having problems. You should only implement this function if you need to adapt the system's behavior according with the tax authority's response. |
| **Returns** | Boolean |
| **Input Parameters** | [shouldRetryRequestContext](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0226020710.html) |

## Example {#bridgehead_39140536641}

          `function shouldRetryRequest(context) {         return context.response == null || context.response.code != "200";     }  };`
