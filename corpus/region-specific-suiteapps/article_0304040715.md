-   See the table below for information about accessing each of the mapping types from different NetSuite account types:
    
    | Mapping Type | Accounts where the SuiteTax feature is enabled. | Accounts Without SuiteTax |
    | --- | --- | --- |
    | **GL Accounts SAF-T 2.0** | YES | YES |
    | **Methods of Payment** | YES | YES |
    | **Units of Measure** | YES | YES |
    | **Tax Codes** | YES | NO |
    
-   You can't uninstall the mapping types that are native to the Universal Mapping Assistant SuiteApp.
    
-   Third-party SuiteApps can't uninstall the mapping type or mapping type instance that they provide.
    
-   The Universal Mapping Assistant supports a distinction between non-existing mappings, empty mappings, and populated mappings. However, you can't remove an existing mapping from the UI by clearing its value. When you clear a mapped value, the mapping still exists with an empty value. It may continue to affect downstream outputs, such as XML generation, if the consumer of the mappings treats mapped-but-empty mappings as important information for a report. Consequently, fields with cleared mappings may be included as empty values instead of being omitted entirely.
