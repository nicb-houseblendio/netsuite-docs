The Country-Specific Address Forms SuiteApp provides custom address forms for various countries. For more information, see [Country-Specific Address Forms](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_158497967043.html)

#### To install the Country-Specific Address Forms SuiteApp:

1.  Go to _Customization > SuiteBundler > Search & Install Bundles_.
    
2.  Enter **Country-Specific Address Forms** or the bundle ID, **64313** in the **Keywords** field.
    
3.  Click **Search**.
    
4.  Click **Country-Specific Address Forms** in the **Name** column.
    
5.  On the Bundle Details page, click **Install**.
    

For more information about installing SuiteApps, see [Installing a Bundle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3395142.html).

The Country-Specific Address Forms SuiteApp is a managed bundle. After you install the SuiteApp, your accounts automatically upgrade when an update to the SuiteApp is available.

Note:

After the update, any changes made to the custom address forms are reset.
