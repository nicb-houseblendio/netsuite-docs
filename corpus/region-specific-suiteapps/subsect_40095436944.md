To access the LATAM File Builder SuiteApp documentation in Brazilian Portuguese (Português do Brasil), see [LATAM File Builder](https://system.netsuite.com/help/helpcenter/shared_resources/PDF/LatamFileBuilder_pt_BR.pdf).

After the LATAM File Builder SuiteApp installation is complete, the import of the predefined records provided by the SuiteApp starts automatically.

A script deployment record runs in your account to import the predefined records. The script is named **LFB SC SDF Installer** (Script ID `customscript_lfb_sc_sdf_installer`).

The import creates predefined file processing request type records.

Tip:

If you notice that predefined records are missing from your account, view the script's execution log. On the execution log, you can verify if errors occurred. For more information, see [Using the Script Execution Log Subtab](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4375896105.html).

Before you start using the LATAM File Builder SuiteApp, you must verify the status of the import. The SuiteApp's ready to use after the import finishes.

#### To verify the import status of the LATAM File Builder predefined records:

1.  Go to _Setup > Import/Export > View CSV Import Status_.
    
2.  In the Job Status list, verify the status information for the **CUSTOMRECORD\_LFB\_FILE\_PROC\_REQ\_TYPE** job.
    
3.  Wait until you can see the following information for the job:
    
    -   The **Status** column shows **Complete**
        
    -   The **Percent Complete** column shows **100%**
        
    -   The **Message** column says all records were imported successfully
