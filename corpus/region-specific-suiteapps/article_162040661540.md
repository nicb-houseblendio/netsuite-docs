Note:

To access the SuiteTax Latam Engine SuiteApp documentation in other languages, do the following:

-   To access the documentation in Brazilian Portuguese (Português do Brasil), see [SuiteTax Latam Engine](https://system.netsuite.com/app/help/helpcenter.nl?fid=SuiteTaxLatamEngine_pt_BR.pdf).
    
-   To access the documentation in Spanish, select Español (Latinoamérica) from the dropdown list at the top right corner of the NetSuite Help Center.
    

You need specific permissions to access the custom records provided by the SuiteTax Latam Engine SuiteApp.

By default, the Administrator role has full permissions to the custom records. An administrator can also grant permissions to other roles to view, access, or edit the custom records.

See the following table for more information about the default permissions granted with the SuiteTax Latam Engine SuiteApp.

| Role | Category | Permission | Access Level |
| --- | --- | --- | --- |
| Administrator | Custom Record | Additional Tax Calculation Details | Full |
| Administrator | Custom Record | Item Code | Full |
| Administrator | Custom Record | Line of Business | Full |
| Administrator | Custom Record | Parameter Type | Full |
| Administrator | Custom Record | Tax Calculation History | Full |
| Administrator | Custom Record | Tax Determination Rules | Full |
| Administrator | Custom Record | Tax Determination Settings | Full |
| Administrator | Custom Record | Tax Information Mapping | Full |
| Administrator | Custom Record | Tax Parameter | Full |
| Administrator | Custom Record | Tax Regime | Full |

Note that the tax determination process doesn't rely on record-specific permissions. A role that creates transactions with tax calculation doesn't need permissions to each SuiteTax Latam Engine custom record. However, the role needs the following lists and setup permissions:

| Category | Permission | Access Level |
| --- | --- | --- |
| Lists | Custom Record Entries | Full |
| Lists | Items | View |
| Lists | Subsidiaries | View |
| Lists | Tax Records | View |
| Lists | Units | View |
| Setup | Custom Fields | View |
| Setup | Custom Lists | View |
| Setup | Custom Record Types | View |
| Setup | Set Up Company | View |
| Setup | SuiteScript | View |

If you have the Projects feature enabled, roles that create transactions with tax calculation also need the following permission:

-   **Category** - Lists
    
-   **Permission** - Projects
    
-   **Access level** - View
    

Warning:

The tax determination process isn't available for users with the following roles:

-   Customer Center
    
-   Employee Center
    
-   Vendor Center
