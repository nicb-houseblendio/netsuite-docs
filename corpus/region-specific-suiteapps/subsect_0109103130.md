#### To create mappings using the Methods of Payment mapping type:

1.  Go to Setup > Universal Mapping Assistant > Mapping Setup.
    
2.  In the **Mapping Type** field, select **Methods of Payment**.
    
    Note:
    
    If you encounter an error in this step, it means that a required SuiteApp isn't installed in your account. For more information, see [Prerequisites for Using the Universal Mapping Assistant Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0109113947.html).
    
3.  In the **Payment Method Standard** field, select your preferred payment method standard.
    
    Displayed options depend on the SuiteApps providing this information that are installed in your account.
    
    Note:
    
    Currently, the only supported payment method standard is the PEPPOL-81.
    
    Note:
    
    If this field doesn't show any available options, it means that a required SuiteApp isn't installed in your account. For more information, see [Prerequisites for Using the Universal Mapping Assistant Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0109113947.html).
    
4.  Click **Search**.
    
5.  View the generated results displayed in a table with the following columns:
    
    -   **Method of Payment:** Shows the list of methods of payment sourced from the Advanced Localization Features SuiteApp. Values in this column are clickable. Clicking them redirects you to individual method of payment records in the Advanced Localization Features SuiteApp.
        
    -   **Payment Method Identifier:** Shows a dropdown list of payment method identifiers.
        
    -   **Payment Method Description:** Shows the payment method description. If the description is available, it only appears after you've selected a value from the Payment Method Identifier dropdown list.
        
    -   **Status:** Shows the status of your mapping for each method of payment. This column either displays the value **Mapped** for accounts whose mappings were already selected and saved, or **Empty** for those that weren't.
        
    
    Note:
    
    Above the table, you can also see filters that allow you to filter table results based on typed keywords, status, and selected rows. Click Clear All Filters when you no longer have use for them.
    
6.  To create a mapping for your preferred method of payment, select a value in the **Payment Method Identifier** dropdown list. You can either scroll the list to find your preferred option, or type a keyword to narrow the list's selection. By default, these fields are left blank.
    
    Note:
    
    Per your needs, you can pair the same **Payment Method Identifier** with more than one method of payment.
    
7.  Check the box at the beginning of one or more Method of Payment rows, for which you want to create mappings.
    
8.  Click **Save** if you want to save your mappings or **Cancel** if you want to discard your pending changes.
    
    Upon saving, the status of these mappings will change to Mapped. If you encounter any errors when saving your mappings, see [Error Scenarios in the Methods of Payment Mapping Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0305123631.html).
    
9.  If you want to edit any of the already created mappings, click on the pen icon at the end of the table row. Then repeat steps 6, 7, and 8.
