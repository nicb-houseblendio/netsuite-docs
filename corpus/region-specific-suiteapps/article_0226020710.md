The shouldRetryRequestContext object contains the following properties:

| Property | Type | Description |
| --- | --- | --- |
| buildMessageContext | [buildMessageContext](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161557950619.html) | The same context used to build the message through [buildMessage(context)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161557944685.html). |
| response | [ClientResponse](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161558370196.html) | Object that contains the result of the HTTP request. |
