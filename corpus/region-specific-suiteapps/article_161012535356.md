To access the LATAM E-Document Certification SuiteApp documentation in Brazilian Portuguese (Português do Brasil), see [LATAM E-Document Certification](https://system.netsuite.com/help/helpcenter/shared_resources/PDF/LATAMEDocumentCertification_pt_BR.pdf).

The LATAM E-Document Certification SuiteApp helps you manage e-document certification requests in your account.

NetSuite creates a certification request and queues it when you send an e-document from a record. Then, scripts process the pending requests and send them to the right tax authority.

You can set up each script deployment record's processing capacity according to your needs. For more information, see the following topics:

-   [Setting the Processing Capacity for Non-Sequential Sending](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_47140643928.html)
    
-   [Setting the Processing Capacity for Sequential Sending](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_37140848108.html)
