#### To create mappings using the GL Accounts SAF-T 2.0 mapping type:

1.  Go to Setup > Universal Mapping Assistant > Mapping Setup.
    
2.  In the **Mapping Type** field, select **GL Accounts SAF-T 2.0**.
    
3.  In the **Country or Entity** field, select country or entity that includes the chosen mapping type.
    
    Note:
    
    If this field doesn't show any available options, it means that there's no SuiteApp in your account providing an implementation for this mapping type. Please install the appropriate SuiteApp. For more information, see [Prerequisites for Using the Universal Mapping Assistant Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0109113947.html).
    
4.  In the **Subsidiary** field, select your preferred subsidiary.
    
    Note:
    
    Displayed options depend on your user permissions. For more information, see [Restricting Role Access to Subsidiaries (OneWorld Only)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N286421.html).
    
5.  Click **Search**.
    
6.  View the generated results displayed in a table with the following columns:
    
    -   **GL Account:** Shows the GL accounts that belong to your selected subsidiary. If you update any GL accounts in Lists > Accounting > Accounts, your changes will be reflected in the Universal Mapping Assistant search results.
        
        Note:
        
        The list of GL accounts shown in this column depends on the Accounting Contexts preferences set in your account. For more information, see [Accounting Contexts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4640155582.html).
        
    -   **Account Type:** Shows the account type for each of your GL accounts.
        
    -   **Subsidiary:** Shows your selected subsidiary.
        
    -   **Country Grouping Category:** Shows a dropdown list of grouping categories sourced from your selected country's tax authority.
        
    -   **Country Grouping Code:** Shows a dropdown list of grouping codes sourced from your selected country's tax authority.
        
    -   **Status:** Shows the status of your mapping for each GL account. This column either displays the value **Mapped** for accounts whose mappings were already selected and saved, or **Empty** for those that weren't.
        
    
    Note:
    
    Above the table, you can also see filters that allow you to filter table results based on typed keywords, account type, status, and selected rows. Click Clear All Filters when you no longer have use for them.
    
7.  To create a mapping for your GL account, select a value from each of the **Country Grouping Category** and **Country Grouping Code** dropdown lists. You can either scroll the list to find your preferred option, or type a keyword to narrow the list's selection. By default, these fields are left blank.
    
    Note:
    
    When you select a grouping category, the list of grouping codes is filtered out according to your selection. The same happens inversely if you select a grouping code first. This is because not all grouping categories can be paired with all grouping codes in one mapping instance.
    
    Note:
    
    The **Country Grouping Category** and **Country Grouping Code** values are interdependent. Therefore, you must either select both of them or leave both of them empty.
    
8.  Check the box at the beginning of one or more GL account rows, for which you want to create mappings.
    
9.  Click **Save** if you want to save your mappings or **Cancel** if you want to discard your pending changes.
    
    Upon saving, the status of these mappings will change to Mapped. If you encounter any errors when saving your mappings, see [Error Scenarios in the GL Accounts SAF-T 2.0 Mapping Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0305123626.html).
    
10.  If you want to edit any of the already created mappings, click on the pen icon at the end of the table row. Then repeat steps 6, 7, and 8.
