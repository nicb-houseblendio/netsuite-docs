After generating the journal entries, you can view the process status and the resulting journal entries.

The following describes the features and steps to view the reclassification journal status.

#### To view reclassification process status:

1.  Go to the Process Status page.
    
    -   In Accounting Center, go to Accounting > Lists > View Reclass. By Region Status.
        
    -   In Classic Center, go to Transactions > Financial > View Reclass. By Region Status.
        
2.  In the **Date Created From** field, select a start date.
    
3.  In the **To** field, select an end date.
    
4.  Click **Refresh**.
    
5.  Review the transactions displayed.
    
6.  Click **Complete** to see the list of journal entries created.
    

For more information on the rules for displaying transactions, see [List Guidelines for Reclassification Journal Entries](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1550121869.html#bridgehead_1551848495).
