When you send invoices and credit memos, you'll receive transaction responses for those outbound transactions. These responses are imported and linked back to the original transactions.

The **NAEI Transaction Response Import MR** is a scheduled MR script used to receive inbound transaction responses and link them to their transaction records. The MR script runs every two hours automatically. You can change the MR script schedule based on your requirement. For more information about scheduling the MR script, see [Scheduling a Map/Reduce Script Submission](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1509578930.html).

Each inbound transaction response is matched to its original transaction using the sent transaction ID found in the response payload. When a match is found, the transaction response record is added to the source transaction on the **E-Document** subtab. If there is no matching transaction due to a missing or invalid sent transaction ID, the NSEB Inbound Document status is set to **Failed**.

You can view the inbound transaction response on the invoice or credit memo record. To view the transaction response see [Viewing a Transaction Response](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1103053930.html#subsect_1106060511).
