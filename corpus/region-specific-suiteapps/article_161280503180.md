A tax authority is a government agency that regulates taxes in a specific area, such as a city, state, region, or country. In some countries, a tax authority can oversee the certification of e-documents due to fiscal requirements.

In NetSuite, the tax authority certification service record stores information about the agency to which you send e-documents for certification.

Before creating the tax authority certification service record, make sure you've created a tax authority custom plug-in implementation. For more information, see [Creating a Custom Plug-in Implementation for a Tax Authority](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161349601331.html).

If you're using a SuiteApp with LATAM E-Document Certification, you might need to add a certification monitoring plug-in for the tax authority. This plug-in type enables other SuiteApps to receive updates about the status of certification requests.

#### To create a tax authority certification service record:

1.  Go to Setup > E-Document Certification > Tax Authority Certification Service > New.
    
2.  In the **Name** field, enter a name for the tax authority certification service.
    
3.  In the **Description** field, enter a description for the tax authority certification service.
    
    You can mention the tax authority's jurisdiction or location. For example, the city or the state of the tax authority.
    
4.  (Optional) If the tax authority requires that you send e-documents in sequential order, check the **Send E-Documents in Sequential Order** box.
    
    The order is based on the transitory e-document number sequence. For more information, see [Setting Up Sequential Order Sending](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161037151577.html).
    
5.  In the **Tax Authority Plug-in Implementation** field, select the tax authority plug-in implementation for the tax authority.
    
6.  (Optional) In the **Certification Monitoring Plug-in Implementation** field, select the certification monitoring plug-in implementation you want to associate with this tax authority certification service.
    
7.  Click **Save**.
    

After you save the tax authority certification service record, set up the record with relevant information about the tax authority.
