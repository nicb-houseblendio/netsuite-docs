| **Function Declaration** | `modifyDocumentXmlBeforeSign(context)` |
| --- | --- |
| **Type** | Interface function |
| **Description** | Modifies the e-document file by inserting new tags or updating existing tags before the final digital signature. This function should only be used if the tax authority requires the digital signature. If not, the function can be empty. |
| **Returns** | String |
| **Input Parameters** | [modifyDocumentXmlBeforeSignContext](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161617301207.html) |

## Example {#bridgehead_161642436107}

          `function modifyDocumentXmlBeforeSign(context) {    return context.unsignedXml; };`
