Note:

To access the LATAM E-Document Certification SuiteApp documentation in Brazilian Portuguese (Português do Brasil), see [LATAM E-Document Certification](https://system.netsuite.com/help/helpcenter/shared_resources/PDF/LATAMEDocumentCertification_pt_BR.pdf).

The modifyReqPropertiesBeforeSendResult object contains the following properties:

| Property | Type | Description |
| --- | --- | --- |
| url | String | The tax authority URL from the Tax Government Web Service that the system will request after customization. |
| eDocContent | String | The content of the e-document to be sent to the tax authority. |
| requestParameters | Object | The parameters that can be added when requesting the Sending Method Plug-in. |
