A tax information mapping record enables you to relate transaction fields to relevant information for the tax determination process.

You can map transaction body fields and transaction line fields:

-   A transaction body field is any field that appears on the body of a transaction.
    
-   A transaction line field is a field that appears on the line items of a transaction.
    

#### To create a tax information mapping record:

1.  Go to Setup > Latam Tax Determination > Tax Information Mapping > New.
    
2.  In the **Country** field, select the country to which to apply the tax information mapping.
    
3.  In the **Information Type** field, select the type of information you want to map.
    
    -   If you're mapping a field used to identify an operation, select **Operation Code**.
        
    -   If you're mapping a field used to identify an item, select **Item Code**.
        
        Ensure that you define the expected operation code or item code in the tax determination rules so NetSuite can find and apply the rules.
        
    -   If you're mapping a field used to identify another type of code provided by local authorities, select **Supplementary Information Code**.
        
        Local authorities may provide a list of codes that represent supplementary information about an item or other aspect of a transaction. The authorities can require you to inform one of these codes, for example, for compliance reasons or to grant you a reduced tax rate.
        
        Ensure that you define the expected supplementary information code in the tax determination settings for NetSuite to be able to find the applicable settings.
        
    -   If you're mapping a field used to identify other types of information that are relevant to tax calculation, select **Additional Tax Information**.
        
        Ensure the SuiteTax Latam Engine plug-in implementation can handle the additional tax information you're mapping.
        
    
    You can only map a single operation code and item code per country. However, you can map as many additional tax information fields as you need.
    
4.  Enter the internal ID of the transaction field you want to map:
    
    -   If you're mapping a transaction body field, in the **Transaction Body Field ID** field, enter the internal ID of the transaction body field you want to associate with the tax information you're mapping.
        
        When you enter an internal ID, the **Transaction Body Field Name** field displays the name of the transaction field that matches the internal ID you entered. For more information about viewing internal IDs, see [Setting the Show Internal IDs Preference](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3420345.html).
        
    -   If you're mapping a transaction line field, in the **Transaction Line Field ID** field, enter the internal ID of the transaction line field you want to associate with the tax information you're mapping.
        
        When you enter an internal ID, the **Transaction Line Field Name** field displays the name of the transaction line that matches the internal ID you entered. For more information about viewing internal IDs, see [Setting the Show Internal IDs Preference](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3420345.html).
        
        Important:
        
        The SuiteTax Latam Engine SuiteApp doesn't support mapping fields that contain custom lists. If the transaction field you're mapping is a list/record field, use lists of records, such as a custom record type.
        
5.  Click **Save**.
