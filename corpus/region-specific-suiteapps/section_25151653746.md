Note:

This topic is for NetSuite accounts that use the Country Tax Report page to generate the Philippines Quarterly Summary Lists of Sales and Purchases (QSLSP) report. If you're using the Tax Reports (International) page, see [VAT RELIEF Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N1955531.html).

With Tax Reporting Framework, you can generate the following Philippines supplementary VAT reports:

-   [Quarterly Summary List of Sales](#subsect_156880045388)
    
-   [Quarterly Summary List of Purchases](#subsect_156880050869)
    

To generate a report, see [Generating Localized Country Tax Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1528250223.html).

The [SuiteTax Country Tax Reports APAC](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156739606850.html) SuiteApp provides the tax report template and tax report localization for Philippines. You must install this SuiteApp to have Philippines tax reports available on the Country Tax Report page. For more information about the required SuiteApps for each country tax reports, see [Tax Reporting Framework Localization Requirements](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_157303200001.html).

## Quarterly Summary List of Sales {#subsect_156880045388}

The generated Quarterly Summary List of Sales (SLS) contains the following information:

| Field | Description |
| --- | --- |
| Customer | Name of the company or individual customer |
| VAT Number | Philippines VAT registration number of the customer |
| Taxable Month | Month of transaction |
| Gross Amount | Gross amount of the exempt, zero, and standard-rated sales |
| Exempt Sales | Sales with exempt rate |
| Zero-rated Sales | Sales with zero rate |
| Standard-rated Sales | Sales with standard rate |
| Output Tax | Value-added tax on sales |
| Gross Taxable Sales | Total sum of Standard-rated Sales and Output Tax |

## Quarterly Summary List of Purchases {#subsect_156880050869}

The Quarterly Summary List of Purchases (SLP) contains the following information:

| Field | Description |
| --- | --- |
| Vendor | Name of the company or individual vendor |
| VAT Number | Philippines VAT registration number of the vendor |
| Taxable Month | Month of transaction |
| Gross Purchases | Gross amount of the exempt, zero, and standard-rated purchases |
| Exempt Purchases | Purchases with exempt rate |
| Zero-rated Purchases | Purchases with zero rate |
| Services | Standard purchases of service |
| Capital Goods | Standard purchases of capital goods |
| Goods | Standard purchases of goods |
| Input Tax | Value-added tax on purchases |
| Gross Taxable Purchases | Total sum of all standard purchases and VAT on purchases |

To export the SLS or SLP, see [Exporting a Country Tax Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_156645000208.html).

For information about the reporting features of Country Tax Reports, see [Tax Reporting Framework](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1528262949.html).
