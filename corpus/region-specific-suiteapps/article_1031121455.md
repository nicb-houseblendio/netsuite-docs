Note:

To access the LATAM E-Document Certification SuiteApp documentation in Brazilian Portuguese (Português do Brasil), see [LATAM E-Document Certification](https://system.netsuite.com/help/helpcenter/shared_resources/PDF/LATAMEDocumentCertification_pt_BR.pdf).

The generateTaxAuthPDFContext object contains the following properties:

| Property | Type | Description |
| --- | --- | --- |
| subsidiaryId | String, Number | The ID of the subsidiary that sent the e-document for certification. NetSuite uses the tax authority ID, subsidiary ID, and category ID to find the File Cabinet folder where to save the generated PDF. |
| taxAuthId | String, Number | The ID of the tax authority certification service that certified the e-document. NetSuite uses the tax authority ID, subsidiary ID, and category ID to find the File Cabinet folder where to save the generated PDF. |
| categoryId | String, Number | The ID of the e-document category of the e-document. NetSuite uses the tax authority ID, subsidiary ID, and category ID to find the File Cabinet folder where to save the generated PDF. |
| operationId | String, Number | The ID of the certification service operation used to send the e-document for certification. NetSuite uses the operation ID to identify the appropriate PDF template. |
| operationTypeExternalId | String, Number | The external ID of the operation type associated with the certification service operation. |
| eDocContent | String | The XML content of the e-document as returned by the tax authority. You can use the e-document content as a data source to fill in the fields in the PDF template. |
