Each tax code must be linked to an EI PEPPOL Tax Category.

#### To create a tax exemption handling:

1.  Create a new EI PEPPOL Tax Category.
    
2.  Enter category name and category code.
    
3.  Enter exemption reason where applicable.
    
4.  Link the category to the relevant tax code.
