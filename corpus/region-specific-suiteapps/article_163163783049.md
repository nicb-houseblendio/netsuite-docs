If a tax code should apply to transactions based on specific criteria, you can set the required tax parameter on the tax code record.

You must ensure that your SuiteTax Latam Engine plug-in is prepared to consider the parameter when determining the tax.

#### To add a tax parameter to a tax code:

1.  Go to _Setup > Tax > Tax Codes_.
    
2.  Click **Edit** next to the tax code you want.
    
3.  Click the **Tax Parameters** subtab.
    
4.  In the **Parameter Type** column, select the type of parameter that modifies how the tax applies.
    
    For more information, see [Creating Parameter Types in the SuiteTax Latam Engine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_163163688028.html).
    
5.  (Optional) In the **Parameter Value** column, enter the value for the parameter.
    
6.  Click **Add**.
    
7.  Click **Save**.
