Consider the following scope, limitations, and best practices for using the North America Electronic Invoicing SuiteApp.

## Scope {#subsect_23105101412}

The scope of the SuiteApp is:

-   You can use the North America Electronic Invoicing SuiteApp only for invoice and credit memo transactions.
    
-   You can use the SuiteApp for companies in United States only.
    
-   The tax code of discount or markup items must be the same as the tax code of the parent item
    
-   Currently, this SuiteApp provides support for SuiteTax and Legacy accounts.
    
-   The SuiteApp supports the following items in a transaction:
    
    -   Assembly
        
    -   Download
        
    -   Drop ship and special order
        
    -   Discount
        
    -   Expense
        
    -   Gift Certificates
        
    -   Inventory
        
    -   Item Group
        
    -   Kit/package
        
    -   Markup and Matrix
        
    -   Non-inventory
        
    -   Service
        
    -   Serial and lot number
        
    -   Subtotal
        

## Limitations {#subsect_62105104500}

The limitations of the SuiteApp are:

-   Payment items must not be part of any subtotal. You can not apply group, discount or charge on a payment item.
    
-   Payment item details are not sent in the XML file because the prepaid node is not available in USDBNA XML format.
    
-   Multiple discounts and charges on items are not supported.
    
-   Currently, unitCode under quantity is set as ZZ and the allowance charge reason code is set to ZZZZ.
    
-   The SuiteApp doesn't support partner tax implementation.
