To use GL Matching features, complete the following setup:

-   Create a custom role or update an existing one for GL Matching. For more information, see [Customizing and Creating Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N286284.html).
    
-   Assign standard and GL Matching custom permissions to the role. For a list of required permissions, see [Standard and Custom Permissions for GL Matching](#subsect_157175176680).
    
-   Give the custom role access to GL Matching suitelets.
    

## Adding Standard and GL Matching Custom Permissions {#subsect_157892582544}

After you identify the custom role (new or existing) for GL Matching, assign the minimum required permissions.

The GL Matching SuiteApp comes with a custom role called **GLM Role (Use as model for custom role)**. As the name suggests, don't assign this role to users.

Use this role only as a guide for the permissions your custom role needs for GL Matching features. For information about these required permissions, see [Standard and Custom Permissions for GL Matching](#subsect_157175176680).

#### To assign permissions to a custom role: {#procedure_157174428737}

1.  Go to _Setup > Users/Roles > User Management > Manage Roles_.
    
2.  Click **Customize** to create a new custom role, or **Edit** to update an existing one, next to the role you want to use with GL Matching.
    
3.  On the **Permissions** subtab, add the standard and custom permissions shown in the **GLM Role** model. For a list of these permissions, see [Standard and Custom Permissions for GL Matching](#subsect_157175176680).
    
    If you can't do this, contact your account administrator.
    
4.  Click **Add** after you select a permission and level.
    
5.  Click **Save**.
    

## Setting Access to GL Matching Pages {#subsect_157892519244}

The following scripts let a role view the GL Matching Dashboard, see the List of Accounts, and search for transaction lines. These scripts use the permissions of the user who's currently logged in.

-   GL Matching Dashboard
    
-   GL Matching - List of Accounts (Administrator)
    
-   GL Matching Checklist
    

As an Administrator, you'll need to set these scripts to run for the custom role you choose with the right GL Matching permissions.

#### To set access to GL Matching pages for the custom role: {#procedure_157174737423}

1.  Go to _Customization > Scripting > Scripts_.
    
2.  On the **Filters** subtab, select **Suitelet** from the Type field.
    
3.  Click **View** next to **GL Matching Dashboard**.
    
4.  On the **Deployments** subtab, click **GL Matching Dashboard**.
    
5.  Click **Edit**.
    
6.  On the **Audience** subtab, select the custom role that you had assigned with the required GL Matching permissions.
    
7.  Click **Save**.
    
8.  Go to _Customization > Scripting > Scripts_.
    
9.  Click **View** next to **GL Matching Checklist**.
    
10.  On the **Deployments** subtab, click **GL Matching Checklist**.
     
11.  Repeat steps 5 to 7.
     

## Standard and Custom Permissions for GL Matching {#subsect_157175176680}

The following are the minimum standard and custom permissions you need to view the GL Matching Dashboard, see the List of Accounts, and search and match transaction lines:

| Subtab | Permission | Level |
| --- | --- | --- |
| Transactions | Find Transaction | View |
| Reports | SuiteAnalytics Workbook | Edit |
| Lists | Accounts | View |
| Lists | Currency | View |
| Lists | Document and Files | View |
| Lists | Perform Search | View |
| Lists | Subsidiaries | View |
| Setup | Accounting Book | View |
| Setup | Custom Record Types | View |
| Setup | Manage Accounting Period | View |
| Setup | SuiteScript | View |
| Setup | SuiteScript Scheduling | Full |
| Custom Record | GLM - Dashboard matching permission | Full or Create |
| Custom Record | GLM - Dashboard reference permission | Full or Create |
| Custom Record | GLM - Job | Edit |
| Custom Record | GLM - Matching | Edit |
| Custom Record | GLM - Sequence | Edit |
| Custom Record | GLM - Tranline | Edit |
| Custom Record | GLM - Variable | View |

For the GL Matching custom permissions (GLM - Dashboard matching and GLM - Dashboard reference), choose the permission level based on what you want the role to do, as shown in the following table:

| Custom Permission | Level | Capability |
| --- | --- | --- |
| GLM - Dashboard matching permission | Create | Match or unmatch transaction lines in open accounting periods. |
| Full | Match or unmatch transaction lines in both open and closed accounting periods. |
| GLM - Dashboard reference permission | Create | Add, edit, or delete the Matching Reference for transaction lines in open accounting periods. |
| Full | Add, edit, or delete the Matching Reference for transaction lines in both open and closed accounting periods. |
| GLM - Job | Edit | Create, view existing, and edit GLM - Job records. You can't delete existing GLM - Job records. |
| GLM - Matching | Edit | Create, view, and edit GLM - Matching records. You can't delete existing GLM - Matching records. |
| GLM - Sequence | Edit | Create, view, and edit GLM - Sequence records. You can't delete existing GLM - Sequence records. |
| GLM - Tranline | Edit | Create, view, and edit GLM - Tranline records. You can't delete existing GLM - Tranline records. |
| GLM - Variable | View | View existing GLM - Variable records. You can't create, edit, or delete GLM - Variable records. |
