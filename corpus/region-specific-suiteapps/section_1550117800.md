You will need to set and grant permissions to roles that need access to the reclassification by region features.

The following table describes the permissions needed to access the reclassification by region features:

## For Creating Reclassification by Region Journals {#bridgehead_1550119897}

The following describes the permissions needed for roles to create reclassification journals:

| Required Permission | Level |
| --- | --- |
| Transactions -> Make Journal Entry | view |
| Transactions -> Revenue Arrangement | View |
| Lists -> Tax Items | View |
| Lists -> Accounts | View |
| Lists -> Subsidiaries | View |
| Lists -> Custom Record Entries | View |
| Lists -> Revenue Element | View |
| Lists -> Revenue Recognition Plan | View |
| Lists -> Revenue Recognition Schedules | View |
| Lists -> Amortization Schedules | View |
| Setup -> Manage Accounting Periods | View |
| Setup -> SuiteScript Scheduling | Full |
| Custom Record -> EMEA ARL Journal Detail Child | Full |
| Custom Record -> EMEA ARL Journal Detail Parent | Full |
| Custom Record -> EMEA ARL Process Status | Full |
| Custom Record -> EU Country | Full |
| Custom Record -> Expense Reclassification Account | Full |
| Custom Record -> Revenue Reclassification Account | Full |
| Custom Record -> Setup EMEA Reclassification Accounts | Full |
