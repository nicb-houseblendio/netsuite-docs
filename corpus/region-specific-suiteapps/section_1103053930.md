After inbound documents from the NSEB inbound e-document custom record are processed, the North America E-Invoicing SuiteApp creates an inbound e-document record for every XML file you receive.

A transaction response record is created in the **E-Document Transaction Response** section, located on the **E-Document** subtab of the inbound e-documents record.

## Viewing a Transaction Response {#subsect_1106060511}

You can view the details and status of a transaction response from an inbound e-documents record using these steps.

#### To view a transaction response:

1.  Go to Customization > Lists, Records & Fields > Record Types.
    
2.  Click the **List** link beside **Inbound E-Documents**.
    
3.  Click **View** next to the inbound e-document you want to send a transaction response for.
    
4.  On the **E-Document** subtab, click **E-Document Transaction Response**.
    
5.  To view the e-document transaction response record, click the **Response** link in the **Transaction Response** column.
    

The **Response Type** of the transaction response is set to **Acknowledged** and the **Status** is set to **Ready for Sending** by default.

## Sending a Transaction Response {#subsect_1103054015}

After reviewing the transaction response on the e-document transaction response record, click **Send** to send the transaction response. The status will update as follows:

-   **Processing** - After sending the transaction response.
    
-   **Request Completed** - When the transaction is successfully sent to the supplier.
    

You can view the Avalara Document ID on the **Network Reference** subtab in the e-document transaction response record. If an error occurs, details are available in the **Error Details** subtab.

## Sending Transaction Responses in Bulk {#subsect_1106061238}

The **Transaction Response Send MR** script is used to send the transaction responses in bulk. You can schedule the script based on your requirement. For more information about scheduling the MR script, see [Scheduling a Map/Reduce Script Submission](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1509578930.html). After the transaction response is sent, the **Status** is set to **Sent** on the transaction response record.
