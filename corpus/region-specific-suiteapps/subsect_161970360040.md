Note:

To access the SuiteTax Latam Engine SuiteApp documentation in other languages, do the following:

-   To access the documentation in Brazilian Portuguese (Português do Brasil), see [SuiteTax Latam Engine](https://system.netsuite.com/app/help/helpcenter.nl?fid=SuiteTaxLatamEngine_pt_BR.pdf).
    
-   To access the documentation in Spanish, select Español (Latinoamérica) from the dropdown list at the top right corner of the NetSuite Help Center.
    

The SuiteTax Latam Engine SuiteApp is a managed SuiteApp. Whenever there are enhancements or new features added, NetSuite automatically updates your account.

To install this SuiteApp, you must have permission and access to the SuiteApp Marketplace. For more information, see [Viewing SuiteApps in the SuiteApp Marketplace](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1539797977.html).

Before you install SuiteTax Latam Engine, ensure you meet the prerequisites for installation. For more information, see [Prerequisites for Installing the SuiteTax Latam Engine SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_161970358591.html).

#### To install the SuiteTax Latam Engine SuiteApp:

1.  In NetSuite, go to SuiteApps.
    
2.  In the **Search SuiteApps** field, enter **SuiteTax Latam Engine**.
    
3.  Click **SuiteTax Latam Engine**.
    
4.  At the top-right area of the SuiteApp details page, click **Install**.
    
5.  Wait for the installation to complete.
    

For more information about the SuiteApp installation process, see [Installing from the SuiteApp Marketplace](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1539799323.html).
