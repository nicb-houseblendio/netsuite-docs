The FileLayout object contains the following properties:

| Property | Type | Description |
| --- | --- | --- |
| name | String | The name of the file layout |
| pluginId | String | The ID of the file layout plug-in |
| folderId | Number | The ID of the folder in which to save the output file |
| folderName | String | The name of the folder in which to save the output file |
| lineBreak | String | The file layout line break |
