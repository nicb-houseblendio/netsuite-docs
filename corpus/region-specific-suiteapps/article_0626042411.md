The beforeSaveOutputFileWithOptReturn object contains the following properties:

| Property | Type | Description |
| --- | --- | --- |
| fileName | String | The name of the output file |
| requestFolderId | String | The ID of the request folder |
| outputFileContents | String | The resulting content in the output file |
