To use the revenue or expense reclassification by region features in NetSuite, you must install the Revenue/Expense Reclass. by Region SuiteApp. See [Installing the Revenue/Expense Reclass. by Region SuiteApp](#bridgehead_1550582243).

## Prerequisites and Set Up {#bridgehead_1548139624}

Before installing the Revenue/Expense Reclass. by Region SuiteApp, you will need to have the following enabled in your account:

-   SuiteCloud
    
-   Client SuiteScript
    
-   Server SuiteScript
    

To complete your set up of the Revenue/Expense Reclassification by Region features, you will need to complete the following:

-   [Enabling Revenue/Expense Reclassification by Region on the Subsidiary Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1548141562.html)
    
-   [Setting Up VAT Category for Tax Codes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1548213403.html)
    
-   [Setting Up Item Rev/Exp Category for Reclass. in Items for Revenue and Expense Reclassification](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1548229720.html)
    
-   [Setting up Reclassification by Region Rules](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1548314342.html)
    
-   (Optional) [Customizing the European Union Country List](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1550041264.html)
    

## Installing the Revenue/Expense Reclass. by Region SuiteApp {#bridgehead_1550582243}

The Revenue/Expense Reclassification by Region SuiteApp (Bundle ID: 267771 ) is a shared managed bundle, and is automatically updated whenever there are enhancements or new features added. You can install the Revenue/Expense Reclassification by Region SuiteApp by performing the following steps:

#### To install the Revenue/Expense Reclass. by Region SuiteApp :

1.  Go to Customization > SuiteBundler > Search & Install Bundles and enter **Revenue/Expense Reclass. by Region** in the search field.
    
2.  In the results, click **Revenue/Expense Reclass. by Region SuiteApp** with the bundle ID **267771**.
    
3.  On the bundle details page, click **Install**.
    

You need to be an Administrator to install SuiteApps. This SuiteApp is a managed bundle and is automatically updated whenever there are updates.

Note:

If the Install button is not available, this SuiteApp may not have been shared with your account. To get access to the SuiteApp, contact your account manager for assistance. This SuiteApp is free.

For more information on installing SuiteApps, see [Installing a Bundle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3395142.html)
