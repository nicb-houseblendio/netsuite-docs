To access the LATAM E-Document Certification SuiteApp documentation in Brazilian Portuguese (Português do Brasil), see [LATAM E-Document Certification](https://system.netsuite.com/help/helpcenter/shared_resources/PDF/LATAMEDocumentCertification_pt_BR.pdf).

The NextRequestResult object contains the following properties:

| Property | Type | Description |
| --- | --- | --- |
| hasNextRequest | Boolean | Indicates if another certification request is expected to be sent after the current request. |
| requestParameters | Any | The relevant information for processing the e-document certification request and exchanging information between the sending script and the plug-in implementation. This open text field is later converted to an object. |
