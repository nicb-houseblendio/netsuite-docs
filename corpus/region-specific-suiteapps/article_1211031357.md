The European Union Electronic Invoicing SuiteApp doesn't support the following:

| Country | Feature | Limitation |
| --- | --- | --- |
| Belgium | Belgium PEPPOL Inbound Transactions | If a transaction includes inventory items and the Multi-Location Inventory feature is enabled, the Location field on the transaction line is required for that item. A default location is suggested to be used directly on the item record. |
| Tax mapping isn't supported from inbound XML e-documents. |
| Denmark | Denmark PEPPOL Inbound Transactions |
| Germany | Germany XRechnung Inbound Transactions |
| Spain | Spain Veri\*Factu Electronic Invoicing Features | Invoice and credit memo cancellation is currently not supported. |
