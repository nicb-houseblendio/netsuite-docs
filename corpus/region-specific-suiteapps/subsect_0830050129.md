Note:

To access the SuiteTax Latam Engine SuiteApp documentation in other languages, do the following:

-   To access the documentation in Brazilian Portuguese (Português do Brasil), see [SuiteTax Latam Engine](https://system.netsuite.com/app/help/helpcenter.nl?fid=SuiteTaxLatamEngine_pt_BR.pdf).
    
-   To access the documentation in Spanish, select Español (Latinoamérica) from the dropdown list at the top right corner of the NetSuite Help Center.
    

The SuiteTax Latam Engine uses the following fields to gather the information needed to match a transaction with the eligible tax determination rules:

| Transaction Type | Transaction Field | Tax Determination Rules Field |
| --- | --- | --- |
| Purchase Transactions | Item | Under General Information:
-   Item Code

 |
| Subsidiary | Under General Information:

-   Subsidiary

Under Receiver Information:

-   City
-   State
-   Country
-   Line of Business
-   Tax Regime

 |
| Vendor | Under Issuer Information:

-   City
-   State
-   Country
-   Line of Business
-   Tax Regime

 |
| Operation Code | Under General Information:

-   Operation Code

 |
| Sales Transactions | Item | Under General Information:

-   Item Code

 |
| Subsidiary | Under General Information:

-   Subsidiary

Under Issuer Information:

-   City
-   State
-   Country
-   Line of Business
-   Tax Regime

 |
| Customer or Customer/Project | Under Receiver Information:

-   City
-   State
-   Country
-   Line of Business
-   Tax Regime

 |
| Operation Code | Under General Information:

-   Operation Code

 |

Note:

The SuiteTax Latam Engine uses the customer or vendor's default shipping address to determine their country, state and city. If you want to use a different address in a specific transaction, click the Shipping subtab and select another address.
