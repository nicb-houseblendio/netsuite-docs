-   To access the documentation in Brazilian Portuguese (Português do Brasil), see [SuiteTax Latam Engine](https://system.netsuite.com/app/help/helpcenter.nl?fid=SuiteTaxLatamEngine_pt_BR.pdf).
    
-   To access the documentation in Spanish, select Español (Latinoamérica) from the dropdown list at the top right corner of the NetSuite Help Center.
    

The SuiteTax Latam Engine SuiteApp provides a plug-in implementation to enable you to perform basic tax calculations. You can use the general tax plug-in to calculate taxes that only require the multiplication of the net amount by the tax rate.

To use the general tax plug-in, you need to:

-   Associate the plug-in with a tax code record.
    
    For more information, see [Associating a SuiteTax Latam Engine Plug-in Implementation With a Tax Code](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_162645934764.html).
    
-   Create tax determination rules and tax determination settings to which the plug-in and the tax code should apply.
    
    For more information, see [Creating Tax Determination Rules in the SuiteTax Latam Engine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_162153526964.html) and [Creating Tax Determination Settings in the SuiteTax Latam Engine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_162153528705.html).
    

The General Tax Plug-in is prepared to override the tax calculation basis and tax rate if you enable this option. For more information, see [Overriding Tax Bases and Tax Rates for the SuiteTax Latam Engine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0116111646.html).

You can't customize the general tax plug-in implementation, but you can use it as a reference to create your own plug-in implementation.
