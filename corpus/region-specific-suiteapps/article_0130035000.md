In the electronic data file structure, the section source is the child record of the layout section. Section sources indicate which datasets or saved searches NetSuite uses to collect information and populate layout sections.

You can associate an existing section source with another layout section. Associating existing section sources to other layout sections enables you to reuse the same section source and its source fields on similar layouts.

For example, you have section source A, which is a child of layout section A. You want to reuse the same section source for layout section B. Instead of creating a new section source under layout section B, you add the existing section source A as a related section source.

#### To add a related section source:

1.  Go to Setup > Latam File Builder > File Layout.
    
2.  Click **View** next to the layout you want.
    
3.  Click the **Sections** subtab.
    
4.  Click the name of the section you want.
    
5.  Click the **Sources** subtab.
    
6.  Click the **Related Section Source** subtab.
    
7.  Click **New Related Section Source**.
    
8.  In the **Related Section Source** field, select the section source from another layout section which you want to reuse.
    
9.  In the **Sequence Number** field, enter the number for where in the building sequence you want to place this source.
    
10.  Click **Save**.
