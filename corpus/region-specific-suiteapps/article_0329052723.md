The ANZ Localization page lets you perform setup tasks, configure reports, and set preferences from a single location. Access the page from Setup > ANZ Localization > ANZ Localization. Access this page using the Administrator role or any role with the required permissions.

On this page, when you click a page in the left pane, the right pane shows preview of the selected page.

The ANZ Localization page menu includes the following:

-   **Overview** - Provides an overview of the ANZ Localization SuiteApp. For more information, see e [ANZ Localization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_158677153915.html).
    
-   **Setup Tasks**
    
    -   **Enable ANZ Features** - Lists reports that you can enable based on your business requirements. For more information, see [Enabling ANZ Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0329054143.html).
        
    -   **Reporting Setup** - Lists available reports that you can configure using the ANZ Localization SuiteApp. For more information, see [Payment Times Report (PTR)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_165287398352.html).
        
    -   **Supplier List** - Lets you generate a list of suppliers with fully paid bills within the selected report period and export ABNs to a CSV file. For more information, see [Generating a Supplier ABN List Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161972327493.html).
        
-   **Preferences**
    
    -   **General Preferences** - Lets you set up ABN verification warning. For more information, see [Setting Up ANZ Localization Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161156090753.html).
        
    -   **ANZ Document Printing Preferences** - Lets you configure printing preferences and footer messages for supported documents per subsidiary. For more information, see [Configuring Document Printing Preferences for Australia](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0816112253.html#subsect_11195912812).
