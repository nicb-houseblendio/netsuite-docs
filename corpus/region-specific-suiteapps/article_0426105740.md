| **Function Declaration** | `getTagsToRemoveFromLog` |
| --- | --- |
| **Type** | Interface function |
| **Description** | Returns the tags that must be removed from the message queue log to protect sensitive customer data. This function should only be used if you need to remove customer information from the system log. If not, you do not need to implement this function. |
| **Returns** | String\[\] |
