Before you start using the Universal Mapping Assistant features, read the prerequisites in the table below and follow the described steps:

| Mapping Type | Required Procedure |
| --- | --- |
| GL Accounts SAF-T 2.0 | Install an appropriate country- or region-specific SuiteApp that provides implementation for this mapping type. Because no existing SuiteApp currently provides such implementation, you can create your own mapping type instance. For more information, see [Defining a New Mapping Type Instance](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0130110617.html). |
| Enable the Use Account Numbers accounting preference.
#### To enable this preference:

1.  Go to Setup > Accounting > Preferences > Accounting Preferences.
2.  On the General subtab, check the **Use Account Numbers** box. Note: Setting this preference enables seeing both account numbers and names for general ledger accounts in lists, chart of accounts, and most financial reports.
3.  Click **Save**.

 |
| Methods of Payment | Install the Advanced Localization Features SuiteApp. For more information, see [Installing the Advanced Localization Features SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160691065745.html). Note: This SuiteApp provides the source payment method records for this mapping type. |
| Install an appropriate country- or region-specific SuiteApp. Below is a list of SuiteApps that currently provide implementation for this mapping type:

-   Electronic Invoicing SuiteApp For more information, see [Installing the Electronic Invoicing SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4592549826.html#bridgehead_4580987212) and [Coordinating the Installation of the Universal Mapping Assistant SuiteApp and Electronic Invoicing SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0108124731.html#subsect_0723015344). Note: This SuiteApp provides the payment method standard PEPPOL-81 as a mapping type instance for this mapping type.

 |
| Units of Measure | Enable the Multiple Units of Measure feature.

#### To enable this feature:

1.  Go to Setup > Company > Enable Features.
2.  On the Company subtab, check the **Multiple Units of Measure** box.
3.  Click **Save**.

 |
| Activate your preferred units of measure by going to Lists > Accounting > Units of Measure. Note: The units of measure that you mark as inactive can't be mapped using the Universal Mapping Assistant SuiteApp. |
| Install an appropriate country- or region-specific SuiteApp that provides implementation for this mapping type. Because no existing SuiteApp currently provides such implementation, you can create your own mapping type instance. For more information, see [Defining a New Mapping Type Instance](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0130110617.html). |
| Tax Codes | Enable the SuiteTax feature. For more information, see [Enabling the SuiteTax Feature](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1513063459.html). |
| Install the SuiteTax Engine SuiteApp. For more information, see [Installing the SuiteTax Engine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557397007.html). |
| Install an appropriate country- or region-specific SuiteApp that provides implementation for this mapping type. Because no existing SuiteApp currently provides such implementation, you can create your own mapping type instance. For more information, see [Defining a New Mapping Type Instance](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0130110617.html). |
