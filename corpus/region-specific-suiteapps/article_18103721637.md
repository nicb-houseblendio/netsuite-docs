| **Function Declaration** | `function beforeImportFailure(context)` |
| --- | --- |
| **Type** | Interface function |
| **Description** | Runs a custom logic if a failure occurs during the validation of the import file or on the getInputData stage of the LFB MR File Importer map/reduce script. For more information about map/reduce stages, see [Map/Reduce Script Stages](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4387802529.html). For example, you can use this function to update the status of a custom record to **Failed** and register an error message. |
