When you receive an e-invoice that matches your subsidiary, an NSEB inbound document record is created automatically with its status set to **Pending**. To view this record, go to Customization > Lists, Records & Fields > Record Types > NSEB Inbound Document.

After an NSEB inbound document record is created, an **NSEB Inbound Converter MR** script provided by NSEB is scheduled to run by default. This script converts the NSEB inbound document into an inbound e-document record in NetSuite. You can manage this script from Customization > Scripting > Scripts.

The **NSEB Inbound Converter MR** script can be set to run on demand or executed manually if preferred. The script is scheduled to run by default.

Important:

Before importing inbound e-documents, you must ensure the following:

-   Set up an item record with a vendor name and code that is consistent with that of your organization.
    
    -   For a single vendor, the item name in the inbound e-document must match the value in the **Vendor Code/Name** field on the item record.
        
    -   If the Multivendor feature is enabled, the item name must match the value in the **Vendor** column on the **Vendors** subtab.
        
    
    For more information, see the Required Vendor Code for Item Records section in [Converting Inbound E-Documents into Transaction Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1495533045.html).
    
-   For inventory items, select a location from the **Location** list on the item record.
