To access the LATAM File Builder SuiteApp documentation in Brazilian Portuguese (Português do Brasil), see [LATAM File Builder](https://system.netsuite.com/help/helpcenter/shared_resources/PDF/LatamFileBuilder_pt_BR.pdf).

The LATAM File Builder SuiteApp enables you to build dynamic file layouts to generate and import electronic data files.

You can leverage the SuiteApp to comply with business and legal requirements, such as accounting reports and bank payment files.
