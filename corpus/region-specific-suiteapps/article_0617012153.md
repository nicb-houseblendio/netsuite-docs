| Property | Value | Description |

| HeaderTrailer | LFB\_SECTION\_SOURCE\_TYPE\_HEADER\_TRAILER | Header or Trailer |
| Data | LFB\_SECTION\_SOURCE\_TYPE\_DATA | Data |
| DataSummary | LFB\_SECTION\_SOURCE\_TYPE\_DATA\_SUMMARY | Data summary |
