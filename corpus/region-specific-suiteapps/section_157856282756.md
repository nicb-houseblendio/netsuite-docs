You can do the following actions with existing groups of Matched or Partially Matched lines on the GL Matching Dashboard:

-   Add non-matched transaction lines to a group
    
-   Remove transaction lines from a group
    
-   Create a new group from matched transaction lines
    
-   Undo a group of transaction lines
    

## Adding Transaction Lines to a Group {#subsect_157856301736}

You can add unmatched transaction lines to an existing group.

#### To add transaction lines to a new or existing group: {#procedure_1539085250}

1.  In the Search Results list, select a transaction line from the group you want to add new transaction lines to.
    
2.  Select the transaction lines you want to add to the group.
    
    Note:
    
    You can add only unmatched transaction lines to a group. To add transaction lines that are already matched, remove them from their group first or unmatch the group entirely.
    
3.  Click **Match**.
    
4.  In the popup window, complete one of the following actions:
    
    -   To add transaction lines to an existing group, click **Add to the Group**. The SuiteApp gives them the same matching code.
        
    -   To create a new group, click **Create a New Group**. The SuiteApp gives the group a new matching code.
        

## Removing Transaction Lines from a Group {#subsect_157856308973}

You can remove one or more transaction lines from a group. Removed transaction lines lose their matching code. Their matching status is set to None or left blank in the Search Results list. The SuiteApp recalculates the group's total balance. Depending on the new balance, the matching status and code may change.

#### To remove transaction lines from a group: {#procedure_1539085422}

1.  In the Search Results list, select the matched transaction lines you want to remove from the group.
    
2.  Click **Unmatch**.
    

## Creating a New Group from Matched Transaction Lines {#subsect_157856334535}

You can create a new group from transaction lines that belong to another group. The new group gets a new matching code. The old groups may keep or get a new matching code and status, depending on their balance.

#### To create a new group from already matched transaction lines: {#procedure_1539087284}

1.  In the Search Results list, select matched transaction lines from two or more groups.
    
    Note:
    
    If you select an entire group, that group will be removed afterward.
    
2.  Click **Match**. You'll see a message if you select transaction lines with different matching codes.
    
3.  Click **OK**.
    

## Undoing a Group of Transaction Lines {#subsect_157856392418}

You can unmatch a group of transaction lines. After the group is removed, the transaction lines lose their matching code. Their matching status is set to None or appears blank in the Search Results list.

#### To undo a matched group of transaction lines: {#procedure_1539085429}

1.  In the Search Results list, select any transaction line from a group marked by the same matching code.
    
2.  Click **Unmatch**.
    

Important:

Adding or removing transaction lines can change a group's total balance. Some groups may lose their zero balance and change from Matched to Partially Matched.
