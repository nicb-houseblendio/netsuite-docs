#### To create mappings using the Tax Codes mapping type:

1.  Go to Setup > Universal Mapping Assistant > Mapping Setup.
    
2.  In the **Mapping Type** field, select **Tax Codes**.
    
    Note:
    
    If you encounter an error in this step, it means that a required SuiteApp isn't installed or a required feature isn't enabled in your account. For more information, see [Prerequisites for Using the Universal Mapping Assistant Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0109113947.html).
    
3.  In the **Country or Entity** field, select your preferred country or entity.
    
    Displayed options depend on the SuiteApps providing this information that are installed in your account.
    
    Note:
    
    If this field doesn't show any available options, it means that a required SuiteApp isn't installed in your account. For more information, see [Prerequisites for Using the Universal Mapping Assistant Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0109113947.html).
    
4.  In the **Subsidiary** field, select your preferred subsidiary.
    
    Note:
    
    If your role is authorized to access more than one subsidiary, you're able to select multiple subsidiaries in this field.
    
5.  Click **Search**.
    
6.  View the generated results displayed in a table with the following columns:
    
    -   **Tax Code:** Shows the list of tax codes sourced from SuiteTax. With the appropriate role, you can create or edit tax codes by going to Setup > Tax > Tax Codes. Values in this column are clickable. Clicking them redirects you to individual tax code records.
        
        Note:
        
        For more information, see [Understanding Tax Types and Tax Codes in SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4283869397.html) and [Creating Tax Codes in SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4283869397.html#bridgehead_4283882825).
        
        If you inactivate or delete a tax code, it won't be available to view or edit in the Universal Mapping Assistant SuiteApp.
        
        If you need to map partially deductible and non-deductible taxes in SuiteTax, you may need to create custom tax codes. For more information, see [Partially Deductible and Non-deductible Taxes in SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0610121020.html).
        
    -   **Subsidiary:** Shows a list of subsidiaries that you're authorized to access.
        
    -   **Nexus:** Shows the nexuses associated with the tax codes.
        
    -   **Tax Transaction Type:** Shows the tax transaction types sourced from SuiteTax. For more information, see [Tax Transaction Types in the SuiteTax Engine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557735490.html).
        
    -   **Tax Rate:** Shows the tax rates sourced from the tax code record.
        
    -   **Country Tax Code Goods:** Shows a dropdown list of country tax codes for goods.
        
    -   **Country Tax Code Services:** Shows a dropdown list of country tax codes for services.
        
    -   **Status:** Shows the status of your mapping for each tax code line. This column either displays the value **Mapped** for accounts whose mappings were already selected and saved, or **Empty** for those that weren't.
        
    
    Note:
    
    **Tax Code And Nexus Sourcing Logic:**
    
    -   Tax codes are sourced based on:
        
        -   The countries assigned to the mapping type instance.
            
        -   The subsidiaries that you're authorized to access.
            
    -   When sourcing tax codes, the system:
        
        1.  Identifies the countries assigned to the mapping type instance.
            
        2.  Identifies the subsidiaries within those countries that you're authorized to access.
            
        3.  Sources only those tax codes whose nexus belongs to the same country as a subsidiary that you're authorized to access.
            
    -   Tax codes must be associated with a nexus. The tax code is sourced if the mapping type instance country, the country of the subsidiary that you're authorized to access, and the nexus country all match.
        
    -   Multiple nexus records can exist for a subsidiary, regardless of whether their Tax Registration Numbers are valid. The system doesn't validate Tax Registration Numbers, it only checks that a nexus record exists.
        
    
    Note:
    
    Above the table, there are filters that allow you to filter table results based on typed keywords, status, nexus, tax transaction type, and tax code. Click Clear All Filters when you no longer have use for them.
    
7.  To create a mapping for your preferred tax code, select a value in the **Country Tax Code Goods** and **Country Tax Code Services** dropdown lists. Per your needs, you can select one or both of these values.
    
    You can either scroll the lists to find your preferred options, or type a keyword to narrow the selection. By default, these fields are left blank.
    
8.  Check the box at the beginning of one or more Tax Code rows, for which you want to create mappings.
    
9.  Click **Save** if you want to save your mappings or **Cancel** if you want to discard your pending changes.
    
    Upon saving, the status of these mappings will change to Mapped. If you encounter any errors when saving your mappings, see [Error Scenarios in the Tax Codes Mapping Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0611050058.html).
    
10.  If you want to edit any of the already created mappings, click on the pen icon at the end of the table row. Then repeat steps 7, 8, and 9.
