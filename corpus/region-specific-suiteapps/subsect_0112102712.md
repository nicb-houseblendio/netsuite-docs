There are two distinct ways that you can use the country- or region-specific SuiteApps to access your mapping information from the Universal Mapping Assistant SuiteApp, depending on their specific requirements:

-   **Single Mapping Retrieval:**
    
    Retrieve the mapped values for a specific mapping source. For example, you can request the mapping details for a particular grouping code by providing the relevant GL account, subsidiary, and mapping type instance.
    
-   **Bulk Mapping Retrieval:**
    
    Retrieve all mapping records that match a set of criteria, such as all mappings for a specific subsidiary and mapping type instance.
    
    -   You can filter the results using the same Universal Mapping Assistant filters available in the user interface (mapping type, country, and subsidiary).
        
    -   The bulk retrieval service is optimized for performance and delivers results within approximately 1 second for up to 500-1000 mapping records per subsidiary.
