France implementation requires coordinated setup across NetSuite, OBN, and Avalara.

#### To complete implementation setup:

1.  Install NetSuite Electronic Business SuiteApp and required dependencies.
    
    For more information, see [NetSuite Electronic Business Quick Start](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0930092258.html).
    
2.  Register the parent company in Oracle Business Network (OBN) and complete Avalara provisioning for production.
    
    For more information, see [Setting Up OBN Processes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0315115701.html), [NetSuite Guide to Integrate with Avalara](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0313104928.html), and [Avalara Provisioning](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0315074555.html).
    
3.  Generate Avalara API credentials (Client ID and Client Secret) and configure them in OBN.
    
    For more information, see [Adding Avalara Client Application API Credentials to OBN Accounts](https://suiteanswers.custhelp.com/app/answers/detail/a_id/1014964).
    
4.  Complete OBN registration of the parent company in sandbox.
    
    For more information, see [NetSuite Electronic Business Sandbox Quick Start](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1210111407.html).
    
5.  Set up subsidiary linking between NetSuite, OBN, and Avalara. Repeat this setup for each relevant French subsidiary.
    
    Production:
    
    1.  Register the subsidiary in Oracle Business Network.
        
    2.  The French mandate in the Avalara ELR solution is not live in production yet, therefore do not create the Avalara company for the subsidiary or activate it in ELR.
        
    3.  When Avalara production is live, create the Avalara company and activate the French mandate using your own SIREN number.
        
    
    Sandbox:
    
    1.  Register the subsidiary in Oracle Business Network.
        
    2.  Create the Avalara company from NetSuite, one Avalara company per subsidiary.
        
        For more information, see [Avalara Company Creation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0315074717.html).
        
    3.  Activate mandates for the subsidiary using a dummy SIREN number.
        
        For more information about Avalara Mandate Activation, see [Avalara Mandate Activation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0315074756.html).
        
    4.  If you have only one subsidiary in France and want to test the whole flow in sandbox, create a new subsidiary in NetSuite and complete the NetSuite, OBN, and Avalara linking setup for that subsidiary.
        

For more information, see the following procedure.

#### To get dummy SIREN numbers in France:

1.  Go to [Chorus Pro](https://qualif.chorus-pro.gouv.fr/aife_qual).
    
2.  Create a new account.
    
3.  Use your email for registration.
    
    Note that it can take some time for the activation email to be sent.
    
4.  Sign in.
    
5.  Click the "Matelas de données" box (English: "Dataset").
    
6.  Click "Accéder" on the "Générer un Matelas de données" tile (English: "Access" on "Generate Dataset").
    
7.  On the new page, click "Soumettre" (English: "Submit") and wait a few minutes.
    
8.  In the "Matelas de données" page, click "Accéder" on the "Consultation du matelas de données" tile (English: "Access" on "View dataset").
    
9.  On the new page, click "Générer et télécharger le fichier CSV du matelas structures et utilisateurs" (English: "Generate and download the CSV file of the structures and users").
    
10.  Use the CSV file to retrieve dummy SIREN numbers.
