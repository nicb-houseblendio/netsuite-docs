In the electronic data file structure, the layout section is the child record of the file layout. Layout sections include blocks of information from a specific source. To display different types of information in your electronic data files, you can add multiple layout sections to a layout file.

If you're generating a file, you can set the order in which NetSuite processes and adds each section to the file. For example, an electronic bank payment file can contain three sections: header, details, and trailer. You can create a record for each section and set the appropriate sequence number: 1 for header, 2 for details, and 3 for trailer.

After you save the layout section, you can create section sources to obtain the information you want to add to the file.

#### To create a layout section: {#procedure_0929022804}

1.  Go to Setup > Latam File Builder > File Layout.
    
2.  Click **View** next to the layout you want.
    
3.  Click the **Sections** subtab.
    
4.  Click **New Layout Section**.
    
5.  In the **Name** field, enter a name for the section.
    
6.  In the **Sequence Number** field, enter the number for where in the building sequence you want to place this section.
    
    The sequence starts at 1.
    
7.  Click **Save**.
