| NetSuite Error | Suggested Solution |
| --- | --- |
| This mapping type depends on a country- or region-specific SuiteApp to supply required data. Please install the appropriate SuiteApp or select a different mapping type. For more information about required SuiteApps, see the help center. | Please install the appropriate SuiteApp or choose a different mapping type. For more information, see [Prerequisites for Using the Universal Mapping Assistant Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0109113947.html). |
| Your NetSuite account setup is not compatible with the SAF-T version 2.0 account mapping type. | Make sure that you've enabled the Use Account Numbers preference. For more information, see [Prerequisites for Using the Universal Mapping Assistant Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0109113947.html). |
| Some of your mappings could not be saved because of an unexpected error. | Click the View Selected filter to see the list of unsaved mappings. Try saving your mappings again. |
| Mapping could not be saved because either the grouping category or grouping code is missing. | The Country Grouping Category and Country Grouping Code fields are interdependent, so please ensure both fields are either selected or left empty before saving. |
| Your mapping information could not be saved. Please try again. | To view the unsaved mappings, click View Selected filter and try saving them again. If the problem persists, contact Support. |
