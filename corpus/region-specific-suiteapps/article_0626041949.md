The beforeSaveOutputFileWithOptContext object contains the following properties:

| Property | Type | Description |
| --- | --- | --- |
| fileName | String | The name of the output file |
| requestFolderId | String | The ID of the request folder |
| outputFileContents | String | The content in the output file |
| fileLayout | [FileLayout](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0917051352.html) | The file layout used to generate the output file |
