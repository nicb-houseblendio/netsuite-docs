Note:

To access the LATAM E-Document Certification SuiteApp documentation in Brazilian Portuguese (Português do Brasil), see [LATAM E-Document Certification](https://system.netsuite.com/help/helpcenter/shared_resources/PDF/LATAMEDocumentCertification_pt_BR.pdf).

The LATAM E-Document Certification API provides server-side methods for preparing, signing, sending, and monitoring certified e-documents in NetSuite.

Important:

You can only use the LATAM E-Document Certification API from server-side scripts. If you need to call it from client-side code, use a `RESTlet` as an intermediary.

| Methods | Description |
| --- | --- |
| [externalSignDocument](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0430033602.html) | Signs the e-document's XML content using the configuration from the applicable tax authority. |
| [externalSendDocument](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0514123316.html) | Sends the signed e-document to the tax authority for certification. |
| [checkItemStatus](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0514124342.html) | Returns the latest status of a e-certification request. |
| [checkSequentialNumberGaps](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0514124952.html) | Checks whether the next e-document number is still in the message queue. |
| [listSeriesFromTaxAuthority](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0514125018.html) | Lists the available e-document series from a tax authority. |
| [incrementSeriesDocumentNumber](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0514125039.html) | Increments the e-document number for a specific series. |
| [incrementEDocumentBulkNumber](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0514125125.html) | Increments the bulk number used in batch certification. |
| [getSendPreferencesFromTaxAuthority](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0514125149.html) | Returns the default template and sending method for a tax authority. |
