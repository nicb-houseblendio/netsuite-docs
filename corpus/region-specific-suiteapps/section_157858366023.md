You can review the last 100 actions the GL Matching SuiteApp performed. Successfully processed transaction lines show up in the History subtab. Failed actions stay in the Matching In Progress subtab.

#### To review the matching history: {#procedure_157865875878}

1.  Go to Transactions > Financial > GL Matching Dashboard (Administrator). For roles that use the Accounting Center, go to Financial > Other Transactions > GL Matching Dashboard.
    
2.  Go to the **History** subtab.
    
    In the Transactions column, you'll see groups or single transaction lines that were successfully processed.
    
    Each transaction line shows the new and previous Matching Code and Status. The Matching Date shows when the process finished.
    
3.  Click **Refresh** to reload and update the History list.
    
4.  Click **Show list of transactions** to see the full list of transaction lines in an account.
    
5.  Click each transaction line link to go to the transaction record.
    

Note:

If a group of transaction lines is deleted, the transactions list shows **Undefined**. For deleted single transaction lines, the deleted record icon ![Icon indicating deleted transactions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/CountrySpecificFeatures/DeletedTranlineIcon.png) appears in the Transactions column.
