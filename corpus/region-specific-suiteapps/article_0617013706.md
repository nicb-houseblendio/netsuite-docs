The FileProcessingRequestStatusEnum object contains the following properties:

| Property | Value | Description |
| --- | --- | --- |
| Pending | LFB\_FLEPRCREQSTATUS\_PENDING | The status for when the file processing request is still pending |
| Processing | LFB\_FLEPRCREQSTATUS\_PROCESSING | The status for when the file processing request is being processed |
| Completed | LFB\_FLEPRCREQSTATUS\_COMPLETED | The status for when the file processing request is successfully processed |
| Failed | LFB\_FLEPRCREQSTATUS\_FAILED | The status for when the file processing request failed |
