## Best Practice for the SuiteTax Latam Engine SuiteApp {#subsect_48105650258}

When using the SuiteTax Latam Engine SuiteApp, be guided by the following best practice:

If you create your own SuiteTax Latam Engine plug-ins, create a File Cabinet folder to which to save your plug-in files. Store this folder either inside the **SuiteApps** or **SuiteScript** folders. For more information, see [Creating File Cabinet Folders](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N541665.html).

Important:

Don't save the plug-in files to File Cabinet folders automatically created by SuiteApps in your account. For example, don't save the plug-ins to the **com.netsuite.fasttaxengine** folder. Your files can be overwritten if you save them to SuiteApp's folders.

## Known Limitations of the SuiteTax Latam Engine SuiteApp {#subsect_0215010503}

Before using the SuiteTax Latam Engine SuiteApp, keep in mind the following limitations:

-   The SuiteApp has the same limitations as the SuiteTax feature.
    
    For more information about the limitations, see [Known Limitations of SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_161365561211.html).
    
-   The SuiteApp doesn't support the tax information mapping of transaction fields that use custom lists.
    
    If you're mapping a list/record field to be the operation code, item code, or additional tax information, instead of a custom list, use a list of records, such as a custom record type.
    
-   You can only override the tax basis and tax rate for the SuiteTax Latam Engine directly on the transaction record.
    
    It's not possible to override the amounts with scripts or CSV imports. For more information, see [Overriding Tax Bases and Tax Rates for the SuiteTax Latam Engine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0116111646.html).
    
-   SuiteTax's tax details override option is not supported on transactions to which the SuiteTax Latam Engine applies.
    
-   The SuiteTax Latam Engine tax determination process doesn't support the following roles:
    
    -   Customer Center
        
    -   Employee Center
        
    -   Vendor Center
        
    
    To determine and calculate taxes, use a different role.
