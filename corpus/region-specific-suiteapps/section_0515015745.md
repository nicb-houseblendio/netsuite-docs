This section includes the prerequisites and instructions for installing the Australia Bank Feeds SuiteApp.

## Enabling Features for Australia Bank Feeds SuiteApp {#subsect_93140652552}

To use the Australia Bank Feeds SuiteApp, you need to enable the following features in your account.

#### To enable features in your account for Australia Bank Feeds SuiteApp: {#procedure_0515020723}

1.  Go to Setup > Company > Setup Tasks > Enable Features.
    
2.  On the **SuiteCloud** subtab, check the following boxes:
    
    -   Custom Records
        
    -   Client SuiteScript
        
    -   Server SuiteScript
        
3.  Click **Save**.
    

For more information about enabling features in your account, see [Enabling Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N232138.html).

You also need to allow pop-up windows in your browser for the bank feeds setup.

## Installation {#subsect_35141035207}

Any role with access to the SuiteApp Marketplace in NetSuite can install the Australia Bank Feeds SuiteApp.

#### To install the Australia Bank Feeds SuiteApp: {#procedure_0515021111}

1.  Go to SuiteApps.
    
2.  From the listed SuiteApps, search **Australia Bank Feeds SuiteApp** in the **Search Apps** field.
    
3.  Click the **Australia Bank Feeds** tile.
    
4.  In the top right area of the Australia Bank Feeds SuiteApp details page, click **Install**.
    

For more information about the SuiteApp Marketplace, see [SuiteApp Marketplace in NetSuite](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1539797981.html).

The Australia Bank Feeds SuiteApp is a managed SuiteApp and is automatically updated whenever there are enhancements or new features added.
