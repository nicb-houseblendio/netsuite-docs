| **Function Declaration** | `function beforeSaveOutputFileWithOpt(context)` |
| --- | --- |
| **Type** | Interface function |
| **Description** | Runs a custom logic that changes the output before saving the file. For example, you can use this function to add the section source counters and the total of rows in the output file. Tip: This function is similar to the [beforeSaveOutputFile(context)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0618100510.html), but supports additional parameters. Prefer this function whenever possible. |
