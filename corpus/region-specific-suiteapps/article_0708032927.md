Note:

To access the LATAM E-Document Certification SuiteApp documentation in Brazilian Portuguese (Português do Brasil), see [LATAM E-Document Certification](https://system.netsuite.com/help/helpcenter/shared_resources/PDF/LATAMEDocumentCertification_pt_BR.pdf).

The modifyDocumentXmlAfterSignContext object contains the following properties:

| Property | Type | Description |
| --- | --- | --- |
| signedXml | String | The e-document XML file with the signature. |
| subsidiary | String, Number | The ID of the subsidiary. |
| certificateId | String, Number | The ID of the subsidiary's certificate. |
| taxAuthority | String, Number | The ID of the tax authority certification service that certified the e-document. |
| category | String, Number | The ID of the e-document category of the e-document. |
| operationType | String, Number | The ID of the operation type associated with the certification service operation. |
| signedTag | [SignedTag](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0708033513.html) | The digital signature structure that was applied to the e-document XML file. |
