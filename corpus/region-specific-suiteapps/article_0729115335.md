France Transaction Response supports the creation and transmission of inbound and outbound transaction responses for France E-Documents. It enables users to send and receive status information for invoices, credit memos, and bills shared electronically. When a customer creates a payment for an invoice, credit memo, or bill, the payment details are added to the Transaction Response, which is automatically sent to Avalara.

## Feature Overview {#bridgehead_0729115417}

The transaction response is a business-level response that communicates the status of an electronic invoice, credit memo, or bill. Responses are associated with the relevant E-Document so that users can follow the status of electronically shared transactions.

Outbound transaction responses let users send a status for an inbound electronic invoice, credit memo, or bill. Inbound transaction responses let users receive a status for an electronically shared invoice, credit memo, or bill.

Responses help users track the processing status of electronic transactions in the [France E-Invoicing Document Life Cycle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0729055004.html).

Important:

Transaction Response for France E-Documents works only with E-Documents shared electronically through EUEI features.

## Enabling Transaction Response feature {#bridgehead_0729115637}

Before sending transaction responses, you must enable Transaction Response feature for the relevant France subsidiary.

#### To enable Transaction Response feature:

1.  Go to Setup > E-Documents > Electronic Invoicing Preferences.
    
2.  Select the France subsidiary you want to update.
    
3.  Click **Edit**.
    
4.  Check the **Transaction Response Support** box.
    
5.  Click **Save**.
    

## Generating the transaction response {#bridgehead_0729115928}

You can generate the transaction response with relevant information, for example price, taxes or status clarification.

#### To generate the transaction response:

1.  Go to the required invoice, credit memo, vendor bill, or bill credit.
    
2.  Click **View** next to the required transaction.
    
3.  Click the **Create Transaction Response** button.
    
    Note:
    
    The **Create Transaction Response** button is available when all of the following conditions are met:
    
    -   the transaction is associated with a France subsidiary
        
    -   the E-Document status is Sent
        
    -   the transaction's subsidiary has Transaction Response Support enabled
        
    
4.  On the **E-Document Transaction Response** page, select the response type.
    
5.  On the **Additional Details** subtab, enter supplementary transaction information and click **Add**.
    
6.  On the **Status Clarification** subtab, select the **Status Action Code** and in the **Status Action** provide context for the transaction status. Then click **Add**.
    
    For more information about which status requires Reason or Additional Details, see [France E-Invoicing Document Life Cycle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0729055004.html).
    
7.  Click **Save**.
    

Important:

If an invoice is generated and a user creates a payment before the E-Document is generated, a Transaction Response record is not created and no Transaction Response is sent to Avalara. The payment itself is still processed and the funds are sent.
