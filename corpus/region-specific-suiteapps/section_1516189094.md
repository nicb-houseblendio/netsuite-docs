Before you install the GL Matching SuiteApp, make sure the required features are enabled. For more information, see [Enabling Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N232138.html).

#### To enable required features for GL Matching: {#procedure_157831688557}

1.  Go to _Setup > Company > Setup Tasks > Enable Features_.
    
2.  On the **Company** subtab, check the box for the following features:
    
    -   Multi-Language
        
    -   Multiple Currencies
        
3.  On the **Accounting** subtab, check the box for the following features:
    
    -   Accounting
        
    -   A/R
        
    -   A/P
        
4.  On the **SuiteCloud** subtab, check the box for the following features:
    
    -   Custom Records
        
    -   Client SuiteScript
        
    -   Server SuiteScript
        
5.  Click **Save**.
