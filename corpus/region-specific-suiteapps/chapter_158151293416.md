SuiteApps are applications that extend NetSuite for specific industry and business needs. Some of them can be used worldwide, some are country-specific. There are also SuiteApps that can be used in a certain group of countries, usually (but not necessarily) from the same region.

Here's an overview of NetSuite region-specific SuiteApps:

| Name | Target Countries | Description |
| --- | --- | --- |
| [ANZ Localization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_158677153915.html) | Australia New Zealand | Provides the localization features, templates, and financial reporting necessary to operate businesses in Australia and New Zealand. It includes records and fields for generating reports that meet Australia and New Zealand's accounting standards. |
| [Australia Bank Feeds SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_3164944442.html) | Australia | Automates the transfer of your bank data from financial institution accounts in Australia into NetSuite. |
| [Country-Specific Address Forms](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_158497967043.html) | Australia Brazil Canada Chile Colombia Mexico New Zealand Peru United Kingdom USA | Includes an address template for both the user interface and printed forms. |
| [EMEA Localization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_157122959910.html) | Belgium France Germany Netherlands Sweden United Kingdom | Provides custom lists and fields on transaction forms and item records to collect information for delivering localized tax reports in several EMEA countries. The collected tax-related information is then used by the country localization SuiteApps to deliver local tax reports including VAT Reports, EC Sales List, and Intrastat. |
| [GL Matching](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1516099228.html) | Belgium France Luxembourg | Includes a transaction matching feature for a common accounting practice in Europe. This practice is called Lettrage in France and it's facilitated by the SuiteApp's tools. |
| [European Union Electronic Invoicing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_7122551804.html) | Belgium Denmark Germany Spain | Offers electronic invoicing features to countries in the European Union. |
| [LATAM E-Document Certification](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160320092518.html) | Brazil | Enable companies to generate, sign, and send e-documents to tax authorities for certification. |
| [LATAM File Builder](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_66113219331.html) | Brazil | Allows companies to create dynamic file layouts for generating and importing electronic data files. |
| [Revenue/Expense Reclassification by Region](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1552020655.html) | European Union | Offers features to reclassify revenue and expenses by location. This helps EU-based companies automatically reclassify transactions as needed. |
| [Southeast Asia Localization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1532415717.html) | Malaysia Philippines Singapore Thailand | Provides invoicing features and electronic payment file formats for several countries in Southeast Asia. The invoicing templates included in this SuiteApp can be used to print and issue tax invoices and credit memos or notes to customers in those countries. |
| [SuiteTax Country Tax Reports APAC](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156739606850.html) | Australia New Zealand Philippines | Provides country tax report features that let users generate VAT or GST returns and supplementary reports for several countries. It supplements Tax Reporting Framework with the country tax report templates and localization for Australia, New Zealand, and the Philippines. |
| [SuiteTax Latam Engine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161833403570.html) | Brazil Colombia | Provides a Tax Engine plug-in implementation and custom records to help companies operating in Latin America comply with local tax requirements. |
| [Transaction Locking SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_158384161821.html) | Austria Brazil Czechia Denmark Germany Sweden Switzerland | Lets you lock transactions by hiding the Edit and Delete buttons. |
| [Universal Mapping Assistant](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_85523794.html) | Norway | Creation of custom mapping configurations that are compliant with country-specific tax reporting. |

To learn more about SuiteApps, go to [SuiteApps](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_3134602194.html).
