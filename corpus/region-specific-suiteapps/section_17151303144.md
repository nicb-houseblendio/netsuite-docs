Bank data imports follow a staggered schedule between 8:00 AM and 9:00 AM (AEST) to improve reliability and reduce errors during peak times. After the first import, the system automatically imports bank data every two hours until 3:00 PM (AEST).

If any import fails during the scheduled import, the system will retry after 45 minutes. You can trigger a manual import anytime through the Australia Bank Feeds SuiteApp.

You can set the span of bank data you want to import, in number of days. You have the option to import a minimum of one day worth of bank data or set a maximum of two months worth of bank data to import. By default, the SuiteApp imports seven days worth of bank data if there is no option specified.

You can either set a default number of days for all accounts under a bank or set the number of days for each of the accounts under a bank.

Note:

Transactions are imported based on the ID number of the last imported transaction. For example, if your most recent import of transactions has the last ID number of 01002, only subsequent transactions starting at ID 01003 will be included in the next import. This prevents duplicate transactions from being imported.

Transactions that have updates or changes, regardless of the ID number, are also imported.

#### To set the span of bank data imports:

1.  Go to Transactions > Bank > Australia Bank Feeds.
    
2.  In the Bank Information section, under the **Bank Accounts** subtab, click **Update Account Profile**.
    
3.  Expand the button for the bank where you want to set the span of bank data imports.
    
4.  Define the number of days worth of bank data that you want to import. You can do one of the following steps.
    
    -   Set a default number of days worth of bank data to import for all accounts under a bank.
        
        To do this, in the first row under the selected bank, enter a number in the **Days to Retrieve** column and check the **Default** box.
        
        For example, if you want to import three days worth of bank data for all accounts under a bank, enter **3** in the **Days to Retrieve** column and check the **Default** box.
        
    -   Manually enter the number of days worth of bank data to import for each account under a bank.
        
        To do this, in the first row under the selected bank, clear the **Default** box in the **Days to Retrieve** column and enter the span in number of days to retrieve bank data for each of the accounts under the bank.
        
        For example, if you want to import three, four, and five days worth of bank data for respective accounts under a bank, first clear the **Default** box and enter **3**, **4**, and **5** for each account in the **Days to Retrieve** column.
        
    
    If you enter zero as the number in the **Days to Retrieve** column, no data import will be imported. If you leave the field blank, the SuiteApp imports seven days worth of bank data. The maximum number of days you can enter is 60.
    
5.  Click **Save Changes**.
