Note:

To access the LATAM File Builder SuiteApp documentation in Brazilian Portuguese (Português do Brasil), see [LATAM File Builder](https://system.netsuite.com/help/helpcenter/shared_resources/PDF/LatamFileBuilder_pt_BR.pdf).

You need specific permissions to access the custom records from the LATAM File Builder SuiteApp. By default, the Administrator role is granted full permissions to the custom records. If other roles need to view, access, or edit the custom records, an administrator can give them permission.

See the following table for more information about the default permissions in the LATAM File Builder SuiteApp.

| Role | Category | Permission | Access Level |
| --- | --- | --- | --- |
| Administrator | Custom Record | File Layout | Full |
| Administrator | Custom Record | File Layout Clone Request | Full |
| Administrator | Custom Record | File Layout Parameter | Full |
| Administrator | Custom Record | File Processing Request | Full |
| Administrator | Custom Record | Data Source for File Layout Parameter | Full |
| Administrator | Custom Record | Feature for File Layout Parameter | Full |
| Administrator | Custom Record | File Processing Request Type | Full |
| Administrator | Custom Record | Temporary File for Section Source | Full |
| Administrator | Custom Record | Layout Section | Full |
| Administrator | Custom Record | Layout Section Clone Request | Full |
| Administrator | Custom Record | Related Section Source | Full |
| Administrator | Custom Record | Related Source Field | Full |
| Administrator | Custom Record | Section Source | Full |
| Administrator | Custom Record | Section Source Clone Request | Full |
| Administrator | Custom Record | Section Source Processing | Full |
| Administrator | Custom Record | Source Field | Full |

See the following table for the permissions you should grant to the roles that generate or import files with the LATAM File Builder SuiteApp.

| Category | Permission | Access Level |
| --- | --- | --- |
| Custom Record | Data Source for File Layout Parameter | Full |
| Custom Record | Feature for File Layout Parameter | Full |
| Custom Record | File Layout Parameter | Full |
| Custom Record | File Processing Request | Full |
| Custom Record | Section Source Processing | Full |
| Lists | Subsidiaries | View |
| Setup | Custom Fields | View |
| Setup | SuiteScript | Full |
| Setup | SuiteScript Scheduling | Full |

If any roles need to clone file layout records, grant them the custom record entries permission:

-   **Category** - Lists
    
-   **Permission** - Custom Record Entries
    
-   **Access Level** - Full
