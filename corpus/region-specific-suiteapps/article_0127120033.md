The Universal Mapping Assistant provides integration points that allow domain-specific SuiteApps to add their own information. This section describes the interfaces available for integration.

As a general rule, reusable components are delivered as part of the Universal Mapping Assistant SuiteApp. Any elements specific to country, region, or context may be delivered as part of a different SuiteApp.

For more information about these integration points, read the following articles:
