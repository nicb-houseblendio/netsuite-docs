| **Function Declaration** | `modifyReqPropertiesBeforeSend(context)` |
| --- | --- |
| **Type** | Interface function |
| **Description** | Modifies the request properties before sending it to the tax authority. This function should only be used to customize request parameters. If no customization is needed, you do not need to implement this function or forward the original data as is. |
| **Returns** | [modifyReqPropertiesBeforeSendContext](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0215113449.html) |
| **Input Parameters** | [modifyReqPropertiesBeforeSendResult](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0215114015.html) |

## Example {#bridgehead_57104312713}

          `function modifyReqPropertiesBeforeSend(context) {         var customizedUrl = context.url;         var originalParsedXml = parseXml(context.eDocContent);         var accessKey = taxAuthLib.getFirstElementByTagName(originalParsedXml, 'ChaveAcesso');         customizedUrl.replace('{ChaveAcesso}', accessKey);                  return {             url: customizedUrl,             eDocContent: context.eDocContent,             requestParameters: context.requestParameters         };     };`
