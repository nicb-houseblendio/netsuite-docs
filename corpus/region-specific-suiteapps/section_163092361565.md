You can install the Localization Assistant SuiteApp from the SuiteApp Marketplace in NetSuite. For more information about installing the SuiteApp, see [Installing from the SuiteApp Marketplace](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1539799323.html).

The Localization Assistant SuiteApp is a managed SuiteApp. After you install the SuiteApp, your accounts automatically update whenever an update to the SuiteApp is available. For more information about Localization Assistant SuiteApp, see [Managing the Localization SuiteApps](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163092473907.html).
