## Rules for Displaying Values Sourced from Tax Authorities {#subsect_0116031808}

NetSuite doesn't internally translate values sourced from tax authorities. However, some tax authorities may provide these values in multiple languages. The language displayed for values sourced from tax authorities follows these rules:

1.  If the country- or region-specific SuiteApp provides values in multiple languages, the values are displayed based on your language preferences.
    
2.  If values aren't available in your preferred language but are available in English, the English values are displayed.
    
3.  If values are unavailable in both your preferred language and in English, the system displays the first available set of values by default.
