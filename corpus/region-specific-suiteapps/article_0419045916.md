The LATAM File Builder SuiteApp enables you to clone file layout records. You can clone file layouts if you want to create a record of the same type with similar settings.

The system's standard option to make a copy of a record only duplicates the parent record. Meanwhile, the clone option replicates the parent and its child records. When cloning file layouts, you can create copies of the following types of record:

-   Layout section
    
-   Section source
    
-   Source field
    

For section sources, you can choose to:

-   Create a copy of the original section source record
    
-   Create a related section source record that associates the original section source to the cloned file layout and layout section
    

#### To clone a file layout:

1.  Go to Setup > Latam File Builder > File Layout Cloning.
    
2.  In the **File Layout** field, select the file layout you want to clone.
    
3.  Click **Search**.
    
    NetSuite lists the layout sections associated with the selected file layout.
    
4.  Under File Layout Cloning Information, in the **Name of the File Layout Clone** field, enter a name for the clone of the file layout.
    
    Choose a name that differentiates the clone from the original file layout.
    
5.  (Optional) To display the section sources under a layout section, click the arrow icon ![Black arrow pointing right](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/CountrySpecificFeatures/arrow_expandablerowUIF_icon.png) next to the layout section.
    
6.  Check the boxes next to the layout sections or section sources you want to clone.
    
    When you check the box next to a parent record, the system automatically selects all its child records too.
    
    Tip:
    
    To select all the layout sections and section sources listed on a page, check the box at the top of the table.
    
7.  (Optional) To skip cloning a layout section or section source, clear the box next to the record.
    
    Be aware that you can't clone a record without its parents.
    
8.  For each selected layout section, in the **Layout Section Clone** column, enter a name for the clone.
    
    Choose a name that differentiates the clone from the original layout section.
    
9.  If you want to clone the selected section sources, do the following:
    
    1.  Clear the box in the **Related Section Source** column.
        
        By default, NetSuite checks this box for all section sources, which creates related section source records. If you want to use the section source exactly as it's used on the original file layout, prefer creating related section sources. For more information about related section sources, see [Adding Related Section Sources](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0130035000.html).
        
    2.  In the **Section Source Clone** column, enter a name for the clone.
        
        Choose a name that differentiates the clone from the original section source.
        
10.  If you want to move the layout section or section source to a different place in the building sequence, in the **Sequence Number** column, clear the field and enter a new number.
     
11.  Click **Create Clone**.
     
     The file layout clone request page opens. You can check the progress of the cloning process on this page.
     
12.  Refresh the page to update the **Status** field.
     
     Keep refreshing the page until the status changes to **Completed** or **Failed**.
     
13.  If the status is **Completed**, to view the cloned records, in the **File Layout Clone** field, click the name of the file layout clone.
     
14.  If the status is **Failed**, verify the execution logs of the LFB MR Copy File Layout script (Script ID: ).
     
     For more information, see [Viewing a List of Script Execution Logs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4375937190.html).
