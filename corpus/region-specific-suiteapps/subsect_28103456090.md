Note:

To access the LATAM File Builder SuiteApp documentation in Brazilian Portuguese (Português do Brasil), see [LATAM File Builder](https://system.netsuite.com/help/helpcenter/shared_resources/PDF/LatamFileBuilder_pt_BR.pdf).

Before installing the LATAM File Builder SuiteApp, you must meet the following requirements:

-   Ensure you're using a OneWorld account.
    
    For more information, see [Introduction to NetSuite OneWorld](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N266468.html).
    
-   Enable several features in NetSuite.
    

#### To enable features:

1.  Go to _Setup > Company > Enable Features_.
    
2.  On the **Company** subtab, check the **Multi-Language** box.
    
3.  On the **SuiteCloud** subtab, check the following boxes:
    
    -   Custom Records
        
    -   Client SuiteScript
        
    -   Server SuiteScript
        
4.  Click **Save**.
