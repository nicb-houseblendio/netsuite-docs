Note:

To access the LATAM E-Document Certification SuiteApp documentation in Brazilian Portuguese (Português do Brasil), see [LATAM E-Document Certification](https://system.netsuite.com/help/helpcenter/shared_resources/PDF/LATAMEDocumentCertification_pt_BR.pdf).

To install the LATAM E-Document Certification SuiteApp, you need to meet these requirements:

-   Make sure you're using an OneWorld account.
    
    For more information, see [Introduction to NetSuite OneWorld](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N266468.html).
    
-   Install the Electronic Invoicing SuiteApp in your account.
    
    For more information, see [Installing and Setting Up Electronic Invoicing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4592549826.html).
    
-   Enable the necessary features in NetSuite.
    

#### To enable features:

1.  Go to _Setup > Company > Enable Features_.
    
2.  On the **Company** subtab, check the following boxes:
    
    -   Multi-language
        
    -   File Cabinet
        
3.  On the **SuiteCloud** subtab, check the following boxes:
    
    -   Custom Records
        
    -   Advanced PDF/HTML Templates
        
    -   Client SuiteScript
        
    -   Server SuiteScript
        
    -   REST Web Services
        
4.  Click **Save**.
