The beforeImportFailureContext object contains the following properties:

| Property | Type | Description |
| --- | --- | --- |
| requestId | String | The ID of the file processing request |
| sourceRecordType | String | The type of the record |
| sourceRecordId | String | The ID of the record |
| errorMessage | String | The content of the error message |
