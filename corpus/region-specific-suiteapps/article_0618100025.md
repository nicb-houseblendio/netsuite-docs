| **Function Declaration** | `function afterProcessRow(context)` |
| --- | --- |
| **Type** | Interface function |
| **Description** | Runs a custom logic after processing a row. You can use this function to modify the string that resulted from the processing of the row. The string is then written to the output file. |
| **Returns** | String |
