The Australia Bank Feeds SuiteApp has no built-in default or custom roles. To use the SuiteApp, you can either use the Accountant (ABFS) custom role or customize existing roles in your account.

#### To customize a role for Australia Bank Feeds SuiteApp: {#procedure_0515021457}

1.  Go to Setup > User Roles > Manage Roles.
    
2.  Search for the role you want to customize. Click **Customize**.
    
3.  Click the **Permissions** subtab.
    
4.  Set the permissions and the access levels required for the custom role as shown in the following table:
    
    | Subtab | Permissions | Access Level |
    | --- | --- | --- |
    | Transactions | Import Online Banking File | View - To access the Upload File and Bank Import History page |
    | Lists | Accounts | View |
    | Custom Record Entries | Full |
    | Setup | Financial Institution Records | Full |
    | SuiteScript | View |
    | Set Up Company | View |
    
5.  Click **Save**.
