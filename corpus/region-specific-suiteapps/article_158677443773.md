This section lists some common errors you might see when installing or upgrading the ANZ Localization SuiteApp, and how to fix them. If the error persists after following the recommended actions, please contact NetSuite Customer Support for further assistance.

## Installation {#subsect_163944609163}

The table below shows errors you might run into during your first installation of the ANZ Localization SuiteApp.

| Status | Error Message | Error Code | Cause | Recommended Action |
| --- | --- | --- | --- | --- |
| Installation Failed | Install the Tax Reporting Framework SuiteApp (SuiteApp ID: 237699) before installing the ANZ Localization SuiteApp. | \- | Your account does not have the Tax Reporting Framework SuiteApp installed. | 
#### To resolve, perform the following actions:

1.  Using the Administrator role, install the Tax Reporting Framework SuiteApp first. See [Installing Tax Reporting Framework](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1528245293.html).
2.  Uninstall the ANZ Localization SuiteApp. See [Uninstalling SuiteApps Obtained from the SuiteApp Marketplace](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1539867306.html). Warning: Uninstalling the ANZ Localization SuiteApp after an upgrade may lead to loss of data. You must backup your data before you uninstall the SuiteApp.
3.  Reinstall the ANZ Loc SuiteApp through the SuiteApp marketplace. For more information, see [Installing ANZ Localization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_158677437293.html).

 |
| Installation Failed | You have provided an invalid script id or internal id: {id}. | INVALID\_ID | The ANZ Localization SuiteApp was installed first before the Tax Reporting Framework SuiteApp. | 

#### To resolve, perform the following actions:

1.  Using the Administrator role, install the Tax Reporting Framework SuiteApp first. See [Installing Tax Reporting Framework](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1528245293.html).
2.  Uninstall the ANZ Localization SuiteApp. See [Uninstalling SuiteApps Obtained from the SuiteApp Marketplace](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1539867306.html). Warning: Uninstalling the ANZ Localization SuiteApp after an upgrade may lead to loss of data. You must backup your data before you uninstall the SuiteApp.
3.  Reinstall the ANZ Loc SuiteApp through the SuiteApp marketplace. For more information, see [Installing ANZ Localization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_158677437293.html).

 |
| Permission Violation | You need the {permission name} permission to access this page. Please contact your account administrator. | \- | The role does not have permission to access the page. | Contact your account administrator for the appropriate permission. For more information, see [Setting Permissions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N288727.html). |
| Validation Failed | An error occurred during account settings validation. The {SuiteCloud id} feature must be enabled in the account. | \- | A required SuiteCloud feature is not enabled in the account. | 

#### To resolve, perform the following actions:

1.  Enable the SuiteCloud features.
    1.  Using the Administrator role, go to Setup > Company > Setup Tasks > Enable Features.
    2.  On the SuiteCloud subtab, the following features must be enabled before installing the ANZ Localization SuiteApp:
        
        -   Custom Records
        -   Client SuiteScript
        -   Server SuiteScript
        -   SuiteCloud Development Framework
        
        For more information about enabling features in NetSuite, see [Enabling Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N232138.html)
2.  After enabling the required features, go back to the SuiteApp Marketplace and try installing the SuiteApp again.

 |
| Validation Failed | An error occurred during validation of Custom Objects against the account. An object with script ID {id} already exists. | \- | Duplicate field IDs have been detected upon installation of your ANZ Localization SuiteApp. | 

#### To resolve, perform the following actions:

1.  Rename the existing field ID mentioned in the error message used for ANZ Localization SuiteApp in your account. Ensure that your field IDs do not match the following:
    
    -   custrecord\_anz\_bn\_verification\_comp
    -   custrecord\_anz\_override\_bn\_warnings
    -   custrecord\_anz\_current\_date
    -   custrecord\_anz\_date
    -   custrecord\_anz\_running\_number\_count
    
    Note: Use unique IDs when renaming your existing field IDs during your initial installation to avoid conflicts with other fields. For more information about editing fields, see [Editing a Custom Field](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4314473404.html).
2.  After renaming the field, ensure that you have enabled the required features then go back to the SuiteApp Marketplace and try installing the SuiteApp again.

## Upgrade {#subsect_163944614371}

The ANZ Localization SuiteApp automatically updates for new features and enhancements. If the feature or fix is not available in your account, the automatic update did not push through. Check and compare the installed and latest versions by viewing the SuiteApp details in the SuiteApp Marketplace. If the versions don't match, it means there was an error during the upgrade because some required features were not enabled.

| Status | Error Message | Error Code | Cause | Recommended Action |
| --- | --- | --- | --- | --- |
| Installed | An error occurred during validation of Custom Objects against the account. | FAILED\_TO\_VALIDATE | The installed version does not match the latest version. | 
#### To resolve, perform the following actions:

1.  Using the Administrator role, go to Setup > Company > Setup Tasks > Enable Features and make sure that the SuiteCloud Development Framework feature is enabled.
2.  Contact NetSuite Support to request your SuiteApp to be updated after enabling the feature.
