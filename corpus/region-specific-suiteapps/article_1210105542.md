Before you install the European Union Electronic Invoicing SuiteApp, complete the required steps listed on this page:

1.  Make sure you're using a OneWorld account.
    
2.  Enable the **Custom Transactions** feature. For more information, see [Enabling Custom Transaction feature](#bridgehead_0811104739).
    
3.  Install the following required SuiteApps:
    
    | SuiteApp | Installation Procedure |
    | --- | --- |
    | Advanced Localization Features SuiteApp | For more information, see [Installing the Advanced Localization Features SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160691065745.html). |
    | Electronic Invoicing SuiteApp | For more information, see [Installing the Electronic Invoicing SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4592549826.html#bridgehead_4580987212). |
    | EMEA Localization SuiteApp | For more information, see [Installing the EMEA Localization SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157201390489.html). |
    | Localization Assistant SuiteApp | For more information, see [Installing the Localization Assistant SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163092361565.html). |
    | NetSuite Electronic Business SuiteApp | For more information, see [Installing the NetSuite Electronic Business SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0426114231.html#subsect_0924083004). |
    

## Enabling Custom Transaction feature {#bridgehead_0811104739}

To enable the Custom Transaction feature, follow the procedure:

#### To enable Custom Transactions feature:

1.  Go to Setup > Company > Enable Features.
    
2.  On the SuiteCloud subtab, in the **SuiteGL** section, check the **Custom Transactions** box.
    
3.  Click **Save**.
    

Important:

Without completing these required steps, you can't install the European Union Electronic Invoicing SuiteApp.
