To access the LATAM E-Document Certification SuiteApp documentation in Brazilian Portuguese (Português do Brasil), see [LATAM E-Document Certification](https://system.netsuite.com/help/helpcenter/shared_resources/PDF/LATAMEDocumentCertification_pt_BR.pdf).

The DocumentResponseResult object contains the following properties:

| Property | Type | Description |
| --- | --- | --- |
| success | Boolean | The status (success or error) of the request processing. |
| message | String | The message extracted from the file that you get back from the tax authority. |
| contents | String | The XML content returned by the tax authority web service. |
| details | Any | An object containing the main information from the results of the request. |
