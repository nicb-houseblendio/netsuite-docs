The tax determination settings record enables you to define the context to which a tax determination rule applies. Create the tax determination settings to set the following conditions:

-   The tax to which a rule applies
    
-   The tax rate at which the company or individual is taxed
    
-   Additional parameters that affect the tax determination process
    

#### To create a tax determination settings record:

1.  Go to Setup > Latam Tax Determination > Tax Determination Rules.
    
2.  Click **View** next to the tax determination rules record you want.
    
3.  Click the **Settings** subtab.
    
4.  Click **New Tax Determination Settings**.
    
5.  In the **Supplementary Information Code** field, enter the code that represents the type of supplementary information that you want to associate with these tax determination settings.
    
    Tax authorities may provide a list of codes that represent supplementary information about an item or other aspect of a transaction. They can require you to inform one of these codes, for example, for compliance reasons or to grant you a reduced tax rate.
    
    Be aware that you need to map a transaction field with which the system should match the supplementary information code. For more information, see [Creating Tax Information Mapping Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_162023332652.html).
    
6.  In the **Rate** field, enter the percentage at which the tax applies.
    
7.  In the **Effective From** field, enter or select the date the tax determination settings start being effective.
    
8.  (Optional) If the settings apply to a limited period of time, in the **Effective Until** field, enter or select the date the settings stop being effective.
    
    After the end of its effective period, the tax determination settings record is no longer considered in the tax determination process.
    
9.  In the **Tax Code** field, select the tax code to which the settings apply.
    
10.  (Optional) If deductions apply to transactions subject to the settings, in the **Deduction Amount** field, enter the amount that should be deducted from the total calculated by NetSuite.
     
11.  If the tax determination settings should apply to the selected tax code according with a specific parameter, do the following:
     
     1.  In the **Parameter Type** field, select the type of parameter that modifies how the settings apply.
         
         For more information, see [Creating Parameter Types in the SuiteTax Latam Engine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_163163688028.html).
         
     2.  (Optional) In the **Parameter Value** field, enter the value for the parameter.
         
     
     Important:
     
     You must ensure that your SuiteTax Latam Engine plug-in is prepared to consider the parameter type and value when determining the tax.
     
12.  To be able to override the tax calculation basis and the tax rate used by the SuiteTax Latam Engine on transactions to which these settings apply, check the **Enable Tax Basis and Tax Rate Override** box.
     
13.  Click **Save**.
