Note:

To access the LATAM E-Document Certification SuiteApp documentation in Brazilian Portuguese (Português do Brasil), see [LATAM E-Document Certification](https://system.netsuite.com/help/helpcenter/shared_resources/PDF/LATAMEDocumentCertification_pt_BR.pdf).

Before you create a certification service for a tax authority, you must set up the creation of e-documents in NetSuite with the Electronic Invoicing SuiteApp. Ensure you meet the following requirements:

-   **E-document template** - The LATAM E-Document Certification SuiteApp doesn't provide e-document templates. If you have a SuiteApp that provides an e-document template, you can use it, but you'll need to ensure it meets the tax authority's requirements. If not, you must create an e-document template for the tax authority to which you send e-documents. For more information, see [Creating E-Document Templates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4536871429.html).
    
-   **E-document package** - The LATAM E-Document Certification SuiteApp doesn't provide e-document packages. If you have a SuiteApp installed on your account that provides an e-document package, you can use it. If not, you must create an e-document package. For more information, see [Creating E-Document Packages](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4576918342.html).
    
-   **E-document sending method** - The LATAM E-Document Certification SuiteApp provides two standard e-document sending methods: one for goods and another one for services. You can either use the standard e-document sending methods, or you can create your own. For more information, see [Creating E-Document Sending Methods](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4536875049.html).
