After you search for transaction lines, you can start matching. The SuiteApp lets you match up to 500 transaction lines in one go.

To help you reconcile, check the top of the Search Results subtab for a summary of total values. The summary of the values are displayed according to **Balance Selected/Total**, **Debit Selected/Total**, and **Credit Selected/Total**. The first figure (in bold) is the sum for the selected transaction lines. The second figure is the total for all transaction lines in the search results list.

#### To match transaction lines: {#procedure_157866496720}

1.  In the Search Results list, select the transaction lines you want to match.
    
    To select all transaction lines, click **Select All**. Click **Clear All** to clear all checked boxes .
    
    You can select up to 500 lines. In the **Results Per Page** field, set how many transaction lines you want to display per page. Use the **Page Number** to go between pages.
    
2.  Click **Match**.
    
3.  To check the matching status, click the **Matching In Progress** subtab.
    
    The transaction lines on this subtab are grouped by account. Check the following columns for more information about the process:
    
    -   **Action** - Shows the SuiteApp process: Matching, Unmatching, or Reference editing (SuiteApp is changing the Matching Reference).
        
    -   **Matching Status** - Shows the current status of the matching process:
        
        -   **Pending** - Transaction lines awaiting action.
            
        -   **Processing** - Transaction lines being processed.
            
        -   **Failed** - Action wasn't successful on the transaction lines.
            
    -   **Matching Date** - Shows the date and time the action started.
        
    -   **User** - Shows the employee who did the action.
        
    
    Selected transaction lines get a matching code, and their matching status updates. If a new group's total balance is zero, the status is Matched. For information about the matching status, see [GL Matching Terminology](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1516368492.html#subsect_157858048991).
    
4.  (Optional) On the **Matching In Progress** subtab, click **Show List of Transactions** to see transaction lines in an account.
    
    Note:
    
    Click the transaction line name or number to view the record, but you can't make changes to it.
    

## Best Practice for Matching more than 500 Lines {#subsect_159299435179}

If you need to match more than 500 transaction lines, match these transaction lines in batches by doing the following:

-   Select and match 500 transaction lines. When they get a matching code, they belong to a matched group.
    
-   Select a transaction line from the group, then select other transaction lines you want to add. When you click **Match**, you'll be asked whether to add them to the group or create a new one with a new matching code. For more information, see [Adding Transaction Lines to a Group](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157856282756.html#subsect_157856301736).
