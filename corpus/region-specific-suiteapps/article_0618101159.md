| **Function Declaration** | `function afterSaveOutputFile(context)` |
| --- | --- |
| **Type** | Interface function |
| **Description** | Runs a custom logic after the output file is saved in the File Cabinet For example, you can use this function to update a custom record with the status **Completed** and the ID of the output file. |
| **Returns** | `void` |
