The ANZ Localization SuiteApp gives you the localization features, templates, and financial reports to run businesses in Australia and New Zealand. It includes records and transaction fields to help you generate reports that meet local accounting standards in Australia and New Zealand.

Note:

For accounts with SuiteTax, the ANZ Localization SuiteApp supports the following reports and templates: Business Activity Statement (BAS), GST101A (New Zealand GST Report), Payment Times Report (PTR), Supplier ABN List, and Advanced PDF/HTML Templates.

For more information, see [Enabling the SuiteTax Feature](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1513063459.html) and [Installing the SuiteTax Engine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557397007.html).

For accounts without SuiteTax, the ANZ Localization SuiteApp supports the following reports and templates: Payment Times Report (PTR), Supplier ABN List, Taxable Payment Annual Report (TPAR), and Advanced PDF/HTML Templates.

The following sections cover the prerequisites and installation procedure of the ANZ Localization SuiteApp.

Note:

You will need the Administrator role to install this SuiteApp.

-   [Prerequisites](#subsect_158677175306)
    
-   [Installing the ANZ Localization SuiteApp](#subsect_158677177719)
    
-   [Updating the ANZ Vendor Bill Script for Payment Times Report](#subsect_74221607777)
    

## Prerequisites {#subsect_158677175306}

Before you install the ANZ Localization SuiteApp, you must do the following:

1.  **Enable SuiteCloud features** - In NetSuite, go to _Setup > Company > Setup Tasks > Enable Features_. On the SuiteCloud subtab, enable the following features:
    
    -   Advanced PDF/HTML Templates
        
    -   Custom Records
        
    -   Client SuiteScript
        
    -   Server SuiteScript
        
    -   SuiteCloud Development Framework
        
    
    For more information about enabling features in NetSuite, see [Enabling Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N232138.html).
    
2.  **Install Tax Reporting Framework SuiteApp** - For installation steps and prerequisites, see [Installing Tax Reporting Framework](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1528245293.html).
    
    Note:
    
    Some features of the Tax Reporting Framework SuiteApp are not available on accounts without SuiteTax. For more information, see [Feature Differences Between Accounts With And Without SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_158676517011.html#bridgehead_158711189528).
    

## Installing the ANZ Localization SuiteApp {#subsect_158677177719}

The ANZ Localization SuiteApp is a free, managed SuiteApp and is automatically updated for new features and enhancements. To install this SuiteApp, you will need permission and access to the SuiteApp Marketplace. For more information about viewing SuiteApps listed in the Marketplace, see [Viewing SuiteApps in the SuiteApp Marketplace](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1539797977.html).

For sandbox accounts, you must manually upgrade installed SuiteApps when a new version is available. For more information about upgrading from the SuiteApp Marketplace, see [Upgrading from the SuiteApp Marketplace](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1562350978.html)

#### To install the ANZ Localization SuiteApp:

1.  Go to SuiteApps.
    
2.  In the **Search Apps** field, enter **ANZ Localization**.
    
3.  Click the ANZ Localization SuiteApp tile.
    
4.  At the top right area of the SuiteApp details page, click **Install**. Wait for the installation to complete.
    
    To understand the installation status, read [Viewing SuiteApp Installation or Uninstallation Status](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1539867271.html).
    
    If the installation fails, read [ANZ Localization Error Messages](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_158677443773.html) and follow the recommended steps.
    

For more information about installing SuiteApps from the SuiteApp Marketplace, see [Installing from the SuiteApp Marketplace](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1539799323.html).

### Updating the ANZ Vendor Bill Script for Payment Times Report {#subsect_74221607777}

If your first installation of the ANZ Localization SuiteApp is earlier than version 2.0.0, do the following:

-   Ensure that your account has the latest version of the SuiteApp.
    
-   Update the `ANZ_VendorBill_ue.js` user event script one time to enable the Before Submit function.
    

Enabling the Before Submit function ensures that the PTR script can do the following:

-   If you enter a date in the Date Received field on the vendor bill, the script saves it and uses it to calculate the PTR payment brackets.
    
-   If the Date Received field on the vendor bill is blank, the script uses the vendor bill's transaction date (Field ID: trandate) to calculate the PTR payment brackets
    

If any of the following applies to your account, you don't need to update the script:

-   Your first installation of the SuiteApp is at version 2.0.0 and later.
    
-   You've already gone through the procedure to update the script and enable the function.
    

Important:

If your account has the latest version of the SuiteApp but your first installation was before version 2.0.0, you will still need to do this procedure one time.

#### To update the ANZ vendor bill script for Payment Times Report: {#procedure_1007121519}

1.  Log in as an Administrator.
    
2.  Open the script record.
    
    1.  Go to Customization > Scripting > Scripts.
        
    2.  On the Scripts page, expand the Filter area.
        
    3.  From the **Type** list, select **User Event**.
        
    4.  From the **Name** column, locate **ANZ Vendor Bill UE**. Click **View**.
        
3.  Reload the user event script. This enables the required Before Submit function.
    
    1.  On the ANZ Vendor Bill UE script record, go to the **Scripts** subtab.
        
    2.  Locate the **Script File** field for `preview ANZ_VendorBill_ue.js`. Click **Edit**.
        
        The script window opens.
        
    3.  Click **Save**. Click **OK**.
        
    4.  To reload the record, refresh the page.
        
    5.  On the **Scripts** subtab, make sure the **Before Submit Function** box is checked.
        

To uninstall the ANZ Localization SuiteApp, see [Uninstalling SuiteApps Obtained from the SuiteApp Marketplace](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1539867306.html).

Warning:

If you're uninstalling the ANZ Localization SuiteApp, NetSuite does the following in your account:

-   Removes the ANZ Localization SuiteApp along with its features and preferences.
    
-   Inactivates Taxable Payment Annual Reports and Payment Times Reports generated from the Country Tax Reports Page. To reactivate the reports, you will need to reinstall the ANZ Localization SuiteApp.
