To see all transaction lines matched (or partially matched) by the GL Matching SuiteApp, use a saved search for a summary.

After you install the SuiteApp, NetSuite provides the GL Matching Report saved search. The saved search contents change based on whether the Multi-Book Accounting feature is enabled in your NetSuite account.

Important:

If you turn the Multi-Book Accounting feature on or off after installing the GL Matching SuiteApp, the subtab data may become inaccurate or cause errors. To fix this issue, contact NetSuite Customer Support to update your GL Matching SuiteApp.

## Accessing GL Matching Saved Searches {#subsect_157104415997}

You can find transaction lines with GL Matching data such as matching code, status, reference, and date in the GL Matching Report saved search. The GL Matching Report saved search includes all transaction lines that have already been matched or partially matched by the SuiteApp. It also gives you a link to each matched group's details.

To access the GL Matching Report saved search, go to Reports > Saved Searches > All Saved Searches and click **View** next to the saved search you want.

On the GL Matching Report results page, you can use these filters to display results:

-   **Period** - Shows transaction lines for the selected accounting period.
    
-   **Accounting Book** - Shows transaction lines from the selected accounting book.
    
-   **Account** - Shows transaction lines from the selected account. If Account Numbering feature is enabled, results also show the account number next to the account name.
    
-   **Name** - Shows transaction lines for the selected customer or vendor.
    

You should use the GL Matching Dashboard to find matched, partially matched, and unmatched transaction lines.

If you still want to filter matching status using the GL Matching Report saved search, first add Internal ID (Summary Type: GROUP) as a column in the **Results** subtab. Then add filters for Account, Subsidiary, Book, Date, or Posting Status in the **Criteria** subtab. This way, the saved search shows transaction lines that are not matched, partially matched, or fully matched. You can then export the results to CSV or Excel, and use Excel to filter the Matching Status column for the results you want.

Note:

If Multi-Book Accounting feature is enabled, the GL Matching Report groups results by accounting book.

With a saved search, you can share GL Matching summaries and show them on your home page. You can also export the results to CSV, Excel, or PDF by clicking the icons at the top of the page. For more information, see [Saved Searches](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N675442.html).
