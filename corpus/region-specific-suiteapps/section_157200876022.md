Before you install the EMEA Localization SuiteApp, go to _Setup > Company > Setup Tasks > Enable Features_, and enable the following features:

-   On the Accounting subtab: Accounting Periods
    
-   On the SuiteCloud subtab:
    
    -   Item Options
        
    -   Custom Records
        
    -   Advanced PDF/HTML Templates
        
    -   Client SuiteScript
        
    -   Server SuiteScript
        
    -   SOAP Web Services
        
    -   SuiteCloud Development Framework
        

To use the tax-related features in the EMEA Localization SuiteApp, you must install the Tax Reporting Framework SuiteApp. For more information, see [Installing Tax Reporting Framework](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1528245293.html#bridgehead_1528246665).

To use the payment templates in the EMEA Localization SuiteApp, you must install the Electronic Bank Payments SuiteApp. For more information, see [Installing the Electronic Bank Payments SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N1586721.html).
