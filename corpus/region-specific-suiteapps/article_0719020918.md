Note:

To access the LATAM E-Document Certification SuiteApp documentation in Brazilian Portuguese (Português do Brasil), see [LATAM E-Document Certification](https://system.netsuite.com/help/helpcenter/shared_resources/PDF/LATAMEDocumentCertification_pt_BR.pdf).

The checkWsAvailabilityContext object contains the following properties:

| Property | Type | Description |
| --- | --- | --- |
| taxAuthId | Number | The ID of the tax authority certification service. |
| taxAuth | String | The name of the tax authority certification service. |
| url | String | The web service URL associated with the send e-document operation and environment set in the e-document certification settings record. If the tax authority provides a specific URL for verifying the status of the certification service, enter the URL for availability tests. |
| operationId | Number | The ID of the certification service operation. |
| subsidiary | Number | The ID of the subsidiary. |
| subsidiaryName | String | The name of the subsidiary. |
| category | Number | The ID of the e-document category. |
| certificationEnvironment | String, Number | The certification environment set in the e-document certification settings.
-   For the production environment, enter **1**.
-   For the test environment, enter **2**.
-   For contingency, enter **3**.
