| **Function Declaration** | `generateTaxAuthPDF(context)` |
| --- | --- |
| **Type** | Interface function |
| **Description** | Generates PDF files from certified e-document XML files according with the operation. This function should only be used for tax authorities that support the generation of PDF files for certification service operations. |
| **Returns** | [generateTaxAuthPDFResult](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1031121516.html) |

## Example {#bridgehead_43172518282}

          `/**  * Returns the IDs of the generated PDF files (matched with the reference keys), the messages related to the generation process (if any), and a boolean variable that indicates whether the generation was successfull or not  */ function generateTaxAuthPDF(context) {     return {         filesDetails: [],         message: "",         success: true     }; }`
