Country-Specific Address Forms SuiteApp provides address forms formatted for certain countries. When you use a country-specific address orm, the system applies the address template to both the user interface and printed forms.

Currently, custom address forms are available for the following countries:

-   Australia
    
-   Austria
    
-   Belgium
    
-   Brazil
    
-   Canada
    
-   Chile
    
-   China
    
-   Colombia
    
-   Denmark
    
-   Finland
    
-   France
    
-   Germany
    
-   India
    
-   Indonesia
    
-   Ireland
    
-   Italy
    
-   Japan
    
-   Luxembourg
    
-   Malaysia
    
-   Mexico
    
-   Netherlands
    
-   New Zealand
    
-   Norway
    
-   Peru
    
-   Philippines
    
-   Portugal
    
-   Saudi Arabia
    
-   Singapore
    
-   South Korea
    
-   Spain
    
-   Sweden
    
-   Switzerland
    
-   Thailand
    
-   United Kingdom
    
-   USA
    
-   Viet Nam
    

You see the custom address form for the selected country when viewing or editing addresses in the popup address window. The country-specific address forms apply to the following records:

-   Entity (company, subsidiary, contact, vendor, employee. etc.)
    
-   Transaction
    
-   Location
    
-   Workplace
    

To use country-specific address forms, read the following topic:

-   [Installing Country-Specific Address Forms](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4174148515.html)
