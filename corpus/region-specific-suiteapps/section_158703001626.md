You can add or change the matching reference on the transaction record to help find transaction lines on the GL Matching Dashboard.

Adding or editing the matching reference updates all transaction lines in that record that belong to a GL Matching account.

Anyone with the GLM - Dashboard reference permission can add, edit, or delete the matching reference. For information about custom permissions, see [Adding Standard and GL Matching Custom Permissions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157104001050.html#subsect_157892582544).

You can update the matching reference on the transaction record or through a CSV import.

#### To update the matching reference on a transaction: {#procedure_158702913358}

1.  Open the transaction record you want to add or edit the matching reference for.
    
2.  Go to the **GL Matching** subtab.
    
3.  On the **Matching Reference for All Lines** field, enter the new matching reference.
    
4.  Click outside the field and you'll see a message.
    
5.  Click **Yes, continue** to proceed with the change.
    
    Click **No, cancel** if you don't want to update the matching reference.
    
6.  Click **Save**.
    

The update may take a few minutes after you save the transaction.

#### To update the matching reference using a CSV import: {#procedure_158704519290}

1.  Go to _Setup > Import/Export > Import CSV Records_.
    
2.  In the **Import Type** field, select Transactions.
    
3.  In the **Record Type** field, select the transaction type you want to import.
    
4.  Choose One File to Upload or Multiple Files to Upload, depending on how many files you're importing.
    
5.  Select the file you want to import from your computer. For more information, see [Select a File for Import](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N344348.html).
    
6.  Click **Next**.
    
7.  On the Import Options page, choose Add. For more information about other import options, see [Step Two Import Options](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N344550.html).
    
8.  Click **Next**.
    
9.  (Required for multiple files import only) On the File Mapping page, select a key column from the linked files to map to the primary key column. For more information, see [Step Three File Mapping](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N347303.html).
    
10.  On the Field Mapping page, verify that the Memo on your CSV file is mapped to the CSV Reference field in the left pane.
     
11.  (Optional) On the Field Mapping page, click the edit icon next to the CSV Reference field in the left pane. Add a short text that will be used as the matching reference.
     
12.  Click **Next**.
     
13.  On the Save Mapping & Start Import page, enter an import map name and description.
     
14.  Click **Save & Run**.
     

For more information about checking the import status, see [Viewing the CSV Import Job Status Page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N350581.html#bridgehead_N350618).

Note:

The reference may take some time to update after the import process is complete.
