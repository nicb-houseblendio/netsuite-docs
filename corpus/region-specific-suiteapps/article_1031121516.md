The generateTaxAuthPDFResult object contains the following properties:

| Property | Type | Description |
| --- | --- | --- |
| success | Boolean | The status (success or error) of the PDF generation. |
| message | String | The message returned if the PDF generation fails. |
| filesDetails | [generatedPDFDetail](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1031121545.html)\[\] | An array of [generatedPDFDetail](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1031121545.html) objects. |
