You can associate an item code with an item record. The SuiteTax Latam Engine SuiteApp supports the following types of items:

-   Group
    
-   Inventory item
    
-   Kit/package
    
-   Non-inventory item
    
-   Other charge
    
-   Service
    

#### To associate item codes with items:

1.  Go to _Lists > Accounting > Items_.
    
2.  Click **Edit** next to the item you want.
    
3.  Under Classification, in the **SuiteTax Latam Engine Item Code** field, select the item code that corresponds to the item.
    
4.  Click **Save.**
    

Note:

To apply certain tax rules to specific items, after associating the item code with item records, associate the item code with tax determination records. For more information about tax determination rules and item codes, see the following help topics:

-   [Creating Tax Determination Rules in the SuiteTax Latam Engine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_162153526964.html)
