The Universal Mapping Assistant SuiteApp is available in the SuiteApp Marketplace.

#### To install the Universal Mapping Assistant SuiteApp:

1.  Go to SuiteApps.
    
2.  In the search bar, enter **Universal Mapping Assistant**.
    
3.  Click the Universal Mapping Assistant image.
    
4.  Click **Install**.
    
5.  Read the information on the alert, and click **Install** if you want to proceed, or **Cancel** if you don't want to install the SuiteApp.
    

Note:

The Administrator, Accountant and CFO standard roles must be set to active so the installation can run properly.

## Coordinating the Installation of the Universal Mapping Assistant SuiteApp and Electronic Invoicing SuiteApp {#subsect_0723015344}

If you're using the Methods of Payment mapping type, you should install the Universal Mapping Assistant SuiteApp before installing the Electronic Invoicing SuiteApp. When the Electronic Invoicing SuiteApp detects that the Universal Mapping Assistant SuiteApp is already installed, it automatically installs the Methods of Payment mapping type.

If the Electronic Invoicing SuiteApp is installed before the Universal Mapping Assistant SuiteApp, the Methods of Payment mapping type isn't installed automatically. In this case, an administrator must run the required installation script to add the Methods of Payment mapping type.

#### To add the Methods of Payment mapping type:

1.  Go to Customization > Scripting > Script Deployments.
    
2.  Click on **Filters**.
    
3.  In the **Script** dropdown menu, select **EI UMA Mapping Instance Service SU**.
    
4.  In the table below, click **View**.
    
5.  On the **Script Deployment** page, click the link in the **URL** field to deploy the script.
    
    After the process is complete, the Methods of Payment mapping type is installed. A confirmation message indicates whether the installation completed successfully or if an error occurred.
