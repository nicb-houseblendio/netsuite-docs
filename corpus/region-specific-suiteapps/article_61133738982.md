The LineBreakScriptIdEnum object contains the following properties:

| Property | Value | Description |
| --- | --- | --- |
| Windows | LFB\_FILE\_LAYOUT\_LINEBREAK\_WINDOWS | Line break character for Windows OS |
| Unix | LFB\_FILE\_LAYOUT\_LINEBREAK\_UNIX | Line break character for Unix |
| Mac | LFB\_FILE\_LAYOUT\_LINEBREAK\_MAC | Line break character for macOS |
