Use the Issue Sources list to create new choices for the Source field on issue records. Selecting the source of an issue lets assignees know who's affected and helps you search and report on how issues are reported.

#### To set up issue sources: {#procedure_N2442728}

1.  Go to _Issues > Setup > Issue Sources_.
    
2.  On the **Issue Sources** list, click the last row if it's not already selected. This row should be blank.
    
3.  In the **Name** column, enter a name for the source you want to add.
    
    This name will be available to select in the **Source** field on issue records.
    
4.  In the **Description** column, enter a brief description of what types of issues are created with this source.
    
5.  Click **Add**.
    
6.  Click **Save**.
    

To edit an existing issue source, click its name to make it editable. Change the name or description, and click **Done**. To delete a source, click its name, and click **Remove**.

You can rearrange issue sources to change how they appear in the **Source** field on issue records. Click the name of a source. Use the **Move Up**, **Move Down**, and **Move to Top** buttons to set their order.
