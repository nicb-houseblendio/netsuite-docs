Returns the full hierarchical path to a value. Values can be returned by `id` or display field.

## Parameters {#subsect_1031101732}

| Parameter | Required / Optional | Description | Acceptable Parameter Values |
| --- | --- | --- | --- |
| Hierarchical field | Required | A field you can chose to display as hierarchies or child values. For more information, see [Hierarchical Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544128671.html). | \- |
| Expansion Type Note: Hierarchy level can sometimes return varying results. For more information, see [SuiteQL Limitations and Exceptions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156257796125.html). | Required | Specify the way a hierarchical field is displayed in results. | Parameter values must include single quotation marks:
-   `'DISPLAY'`
-   `'DISPLAY_JOINED'`
-   `'DISPLAY_SEPARATED'`
-   `'IDENTIFIER'`
-   `'IDENTIFIER_SEPARATED'`
-   `'LEVEL'`
-   `'SELF_DISPLAY'`
-   `'SELF_IDENTIFIER'`

 |

## Syntax {#subsect_1031105512}

            `BUILTIN.HIERARCHY(parent, 'IDENTIFIER_SEPARATED')` 
          

            `SELECT id, parent,  BUILTIN.HIERARCHY(parent, 'IDENTIFIER_SEPARATED') FROM Item`
