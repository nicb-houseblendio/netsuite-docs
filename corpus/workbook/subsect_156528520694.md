You can combine the CONCAT function with other functions to calculate complex string values. For example, to show duration values in days and hours, first normalize the values with TO\_NUMBER and TO\_NCHAR, then use this formula. The output type is STRING:

          `CONCAT(CONCAT('Days: ',TO_NCHAR(FLOOR(TO_NUMBER(TO_NCHAR({timeelapsed}/24))))), CONCAT(' Hours: ',TO_NCHAR(MOD(TO_NUMBER(TO_NCHAR({timeelapsed})),24))))` 
        

![Example of combining CONCAT and other functions.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Workbook/CONCAT_Formula1.png) ![CONCAT formula shown in the dataset.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Workbook/CONCAT_Formula2_20_1.png)

Try using different formula functions with the CONCAT function to calculate other string values.
