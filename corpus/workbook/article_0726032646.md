With standard data refresh, pivot tables and charts show cached data from storage for quicker loading. Datasets and table views don't use cached data and show only real-time data, which may take longer to load.

Note:

You are using standard data refresh when the Cached Data in Datasets isn't enabled. For more information about this feature, see [Optimized Data Refresh](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0726032719.html).

This caching process speeds things up by returning results faster, but the data might not always be the most current. To see when your workbook data was last refreshed, check the **Last updated** field in the upper-right corner of the Viewer. To learn more about default caching and manual cache clearing, see the topics below:

-   [Clearing the Cache for Pivot Tables and Charts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_6143352958.html)
