Only a dataset owner or someone with the Analytics Administrator permission can save changes to an existing dataset. This helps avoid data discrepancies in visualizations that share the same dataset. If a dataset is shared with you, you can edit it but have to save it with a new name. Anyone with access to a dataset can edit and preview changes in a workbook to see how it affects their visualizations. This means you can have a single dataset for lots of different users and needs.

Note:

In workbooks with linked datasets, removing a field used to define a link can affect your results and may keep you from saving.

Note:

If your account uses multiple languages and you edit and save default text in a dataset, a new translation will be added to the Manage Translations page. For more information, see [Manage Translations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_158572305264.html).

#### To edit a dataset that you own:

1.  Click the dataset or workbook name on the Analytics Home page. To quickly filter the available options, select **My Workbooks** or **My Datasets** in the dropdown list of either the Workbooks or Datasets subtabs.
    
2.  Edit the dataset. For information, see [Defining a Dataset](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544122173.html).
    
3.  Click **Save**. Alternatively, if you accessed the dataset through a connected workbook, click **Save & Close** to save your changes and open the workbook.
    
4.  (Optional) Click **Create New Workbook** or **Apply to workbook** to preview your changes in a workbook visualization before saving the dataset .
    
    The workbook will appear with a warning icon ![Warning icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Workbook/Warning-icon.png) next to the dataset name, denoting an unsaved dataset.
    
5.  If you are satisfied with your changes, click the arrow next to the dataset name and select **Save Changes**.
    
    If you're not happy with your changes, click the arrow and select **Open Dataset** to continue editing, or **Discard Changes**.
    
    Important:
    
    When you save changes to your datasets, they're automatically updated in any related workbook visualizations, even if someone else made them. This can seriously change other workbooks, so if you're not sure how your changes will affect things, try saving the dataset with a new name instead.
    

#### To edit a dataset that has been shared with you:

1.  Click the dataset or workbook name on the Analytics Home page. To quickly filter the available options, select **Shared with me** in the dropdown list of either the Workbooks or Datasets subtabs.
    
2.  Edit the dataset. For more information, see [Defining a Dataset](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544122173.html).
    
3.  Click **Save As**.
    
    The Save Dataset As window appears.
    
4.  Enter a name and description for the dataset in the fields provided, then click **Save**.
    
5.  (Optional) Click **Create New Workbook** or **Apply to workbook** to preview your changes in a workbook.
    
    The workbook will appear with a warning icon ![Warning icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Workbook/Warning-icon.png) next to the dataset name, denoting an unsaved dataset.
    
6.  If you are satisfied with your changes, click the arrow next to the dataset name and select **Open Dataset** to save it using a new name.
