By default, the data is refreshed after 60 minutes of inactivity. To better understand when the data is refreshed, see the following scenarios:

## Creating and modifying pivot tables and charts in an existing workbook {#subsect_11143631443}

After you set the layout of a new pivot table or chart, click the **Refresh** icon ![Refresh report icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Workbook/ReportRefreshIcon.png) to apply the changes and update the results. If you make changes to a pivot table directly from the Pivot Table Viewer, the results are automatically displayed.

When you create or modify your pivot tables and charts, SuiteAnalytics Workbook creates a backend query. This query pulls in results for your pivot tables and charts, letting you see the data in the Viewer. If some pivot tables and charts share the same backend query, the data used during refresh can vary:

-   If the backend query was refreshed less than 60 minutes ago from either the pivot or chart tab, the data from the cache is used for the refresh.
    
-   If the backend query was refreshed more than 60 minutes ago from either the pivot or chart tab, the most current data is used for the refresh.
    

Note that some changes in pivot tables and charts require loading real-time data. For example, adding a field to **Rows**, **Columns**, or **Measures**.

You can verify the time of the last refresh in the upper-right corner of the pivot table or chart viewer.

## Saving and re-opening a workbook before 60 minutes have elapsed {#subsect_1145530825}

When you re-open a saved workbook before 60 minutes have elapsed and open a pivot table or chart, the Viewer shows cached data by default. The last refresh time is in the upper-right corner. To retrieve the most current data, click the **Refresh** icon.

## Saving and re-opening a workbook after 60 minutes have elapsed {#subsect_48145536720}

When you re-open a saved workbook after 60 minutes have elapsed, the cache has expired. When you open a pivot table or chart, the Viewer automatically shows the latest results.

## Working with the Analytics Portlet {#subsect_34145541415}

Pivot tables and charts in the Analytics portlet show the same data as their workbooks. To get the latest results, click the **Refresh** icon ![Refresh report icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Workbook/ReportRefreshIcon.png).

For more information about how to clear the cache manually, see [Clearing the Cache for Pivot Tables and Charts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_6143352958.html).
