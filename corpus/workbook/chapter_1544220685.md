Use this tutorial to walk through the authoring process for SuiteAnalytics Workbook.

this tutorial, you'll create a sample workbook with visualizations based on two different datasets. One uses the sales (ordered) record type, and the other uses the item record type. By combining these datasets in a workbook, you'll quickly see if you have enough inventory to fulfill all the orders in your account.

The table below lists the steps to create the datasets and workbook visualizations. Each step builds on the last, so you must complete them in order:

| Step | Description |
| --- | --- |
| Step One: [Select a Root Record Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544220722.html) | Create your first dataset by choosing a root record type. |
| Step Two: [Add Fields and Join Record Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544220741.html) | Choose the fields and record types that you want to include in your dataset. |
| Step Three: [Filter Your Dataset](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544220778.html) | Apply criteria filters to refine your dataset query results. |
| Step Four: [Create a Workbook Based on Your Dataset](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158171457414.html) | Continue your analysis by creating a workbook based on your dataset. |
| Step Five: [Pivot Your Dataset Query Results](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544220809.html) | Create a pivot table using your dataset query results. |
| Step Six: [Connect a Second Dataset to Your Workbook](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159259230666.html) | Create and join an additional dataset to your workbook. |
| Step Seven: [Set up a Table View](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544220850.html) | Create a table view using the query results from your second dataset. |

Note:

This tutorial assumes you've got the right permissions and features turned on to view sales order and item data. If you're not sure which permissions you need to view sales order records or fields, download the worksheet: [NetSuitePermissionsUsage.xls](https://system.netsuite.com/core/media/media.nl?id=341574735&c=NLCORP&h=BmVV5dg6iq3SkAR6-7whWl0kksl0cQkz7wGKgkoMYABHPp51&_xt=.xls). If you don't have a needed permission, contact your NetSuite administrator.
