The following examples show how you can use calculated measures in your pivot tables and charts.

## Year over Year Growth {#subsect_161416717934}

You can create a calculated measure to compare year-over-year differences in your sales reps' performance. Here's how you can create a pivot table with a calculated measure that shows this difference.

| Step | Description |
| --- | --- |
| Step 1: Create two formula fields using the Sales (Ordered) dataset | To calculate year-over-year variance, you'll need to split the sales amount into two fields in the dataset. You can create these two formula fields:
-   **Amount LYTD** - The Amount Last Year to Date field shows sales amounts from all of last year up to today.
-   **Amount TYTD** - The Amount This Year to Date field shows sales amounts for transactions from the start of this year to today.

To copy and paste the formulas, see [Calculating Amounts for Relative Date Ranges](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_161418884855.html). |
| Step 2: Create your pivot table | Set the following fields in the Layout panel:

-   Rows: Sales Rep
-   Columns: None
-   Measures: Amount TYTD (Sum) and Amount LYTD (Sum)

For information about how to create pivot tables, see [Workbook Pivot Tables](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158042187611.html). |
| Step 3: Create your calculated measure | Use the following definition: `(Amount TYTD (Sum) - Amount LYTD (Sum)) / Amount LYTD (Sum)` For information about how to create calculated measures, see [Working with Calculated Measures](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160794532119.html). |
| Step 4: Format the results | You can also customize your pivot table results, add totals and grand totals, or set the decimal values to percentage values. For more information, see [Pivot Table Customization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544211304.html). |

After you create the calculated measure, the pivot table displays the difference over time.
