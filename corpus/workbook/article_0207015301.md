You can add workbook visualizations in a saved workbook using the Add icon ![Add icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Workbook/AddIcon.png).

#### To create a new workbook visualization within an existing workbook:

1.  On the Analytics Home page under the Workbooks subtab, click the name of the workbook you want to add your visualization to.
    
2.  Click the Add icon ![Add icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Workbook/AddIcon.png).
    
3.  Select the visualization type you want to add.
    
    By default, it's based on the dataset currently selected in the Dataset Panel. If you want to use a different dataset, click **Connect Dataset**.
    
4.  Edit the layout and format for the visualization.
    
    For more information, see [Workbook Table Views](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158083630457.html), [Workbook Pivot Tables](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158042187611.html), or [Workbook Charts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544211366.html).
    
5.  (Optional) To change the order of your workbook visualizations, drag the workbook tab to a new spot.
