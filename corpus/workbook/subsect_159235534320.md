To use currency consolidation in a dataset, you'll need to create a custom formula field using the context value #currency\_consolidated. For example, to consolidate the amount net field from the transaction accounting line record type, use this formula:

          `TO_NUMBER({transactionlines.accountingimpact.netamount#currency_consolidated})`
