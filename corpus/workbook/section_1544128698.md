You can sort the values in the Data Grid using the Advanced Sorting window. Sorting options you set in the Data Grid won't affect any workbook visualizations, and should only be used to help make the grid easier to read. To filter data in your dataset, use the Criteria Builder above the Data Grid to make criteria filters. For more information, see [Dataset Criteria Filters](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544211200.html).

To open the Advanced Sorting window, click the Field Menu icon ![Field menu icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Workbook/FieldMenuIcon18_1.png) next to a column in the Data Grid and select **Add Sort...** from the menu.

In the Advanced Sorting window, you can add sorting conditions for any Data Grid field. After adding each condition, choose the order in which the conditions should be applied.

The following image shows the parts of the Advanced Sorting window:

![Advanced Sorting window](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Workbook/AdvancedSortingWindow19_1.png)

| 1 | **Up/ Down Arrows** - Click the arrows to change the order of the sorting conditions, or drag the entire row to the location you want to move it to. |
| --- | --- |
| 2 | **Field list** - Select the field you want to create a sorting condition for. |
| 3 | **Sort** - Sort the result set in ascending ![Sort ascending icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Workbook/AscendingIcon19_1.png) or descending ![Sort descending icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Workbook/DescendingIcon19_1.png) order, based on the selected field's values. |
| 4 | **Options** - Click this icon to view the following options specific to the selected sorting condition:
-   **NULL First** - If checked, blank values for the selected field are listed first in the corresponding column in the Data Grid.
-   **Case Sensitive** - If checked, values beginning with capital letters are listed first in the corresponding column in the Data Grid.
-   **Language** - Sort the result set based on the alphabetical order for the selected language.

 |
| 5 | **Delete** - Remove the selected sorting condition. |
| 6 | **Add Sorting** - Add another sorting condition for a different field. |
| 7 | **OK** - Apply the selected sorting conditions to the Data Grid. **Cancel** - Close the Advanced Sorting window without making any changes to the existing sorting conditions. **Remove All** - Remove all sorting conditions from the Advanced Sorting window. |
