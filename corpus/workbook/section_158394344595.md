Important:

You must specify a sorting order in the query definition when using the [SuiteQL.runPaged(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157960491275.html) method to avoid duplicate or missing results. The query definition must provide a unique and unambiguous sorting order with a specified precedence.

To run SuiteQL queries through REST web services, send a POST request to the `suiteql` resource, and specify the query in the request body after the query parameter `q`. The following example shows a SuiteQL query executed through REST web services.

          `> POST https://demo123.suitetalk.api.netsuite.com/services/rest/query/v1/suiteql > Prefer: transient . { . "q": "SELECT email, COUNT(*) as count FROM transaction GROUP BY email" . }` 
        

For more information about executing SuiteQL queries through REST web services, see [Executing SuiteQL Queries Through REST Web Services](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157909186990.html).
