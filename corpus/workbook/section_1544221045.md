The Pivot tab lets you pivot your dataset query results. All fields in the dataset appear in the Dataset Panel on the left. To build your pivot table, drag fields from the Dataset Panel to the Layout panel, then click the Refresh icon ![Refresh report icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Workbook/ReportRefreshIcon_25_2.png). The pivot table is shown in the Pivot Table Viewer on the right.

You can create multiple pivot tables using the same dataset query results.

For information about how to use the Pivot tab to pivot your dataset query results, see [Creating a Workbook](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544211284.html).

The image below shows the parts of the Pivot tab:

![Pivot tab](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Workbook/PivotTabNavigation20_2.png)

1.  **Workbook Information** - Click to view or edit the workbook name, description, internal ID, or add a translatable portlet name to your Analytics portlet. This information is available from anywhere in the workbook.
    
    For more information about translatable Analytics portlet names, see [Adding Translatable Analytics Portlet Names](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_162566567856.html).
    
2.  **Undo, Redo, and Refresh** - Undo or redo your last changes, and refresh the data in the current workbook visualization. The undo and redo options work for any action in the workbook,not only the current tab. For more information about data refreshing, see [Data Refresh in SuiteAnalytics Workbook](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0726032356.html).
    
3.  **Add** - Click the add icon to add a new workbook visualization.
    
4.  **Dataset Panel** - The Dataset Panel is on the far left area and has all the fields from the selected dataset. To build a visualization, drag fields from the Dataset Panel to the Layout Panel or the Table Viewer. You can also edit the dataset or switch to a different one using the Dataset Selector at the top.
    
    -   To view or edit a dataset, click its name in the Dataset Selector.
        
    -   To see more information about a field, point to it and click the ![Information icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Workbook/ICardIcon.png) icon.
        
    -   To collapse the Dataset Panel and expand the Viewer, click the double arrows ![Collapse arrows icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Workbook/CollapseArrows.png).
        
5.  **Dataset Selector** - This list lets you access and edit the datasets connected to the visualization, select a different one, or connect a dataset that's not already used in another visualization. In visualizations with linked datasets, you can also edit the dataset link.
    
    -   To view or edit a dataset, click its name in the Dataset Selector. Alternatively, click the menu icon and select **Open Dataset**.
        
    -   To connect or create a new dataset, click the arrow and select **Connect Dataset**.
        
    -   To edit the dataset link, click the dataset menu icon and select **Edit Dataset Link**.
        
    -   To save or discard changes to the selected dataset, click the menu icon and select **Save Changes** or **Discard Changes**. You need to save or discard changes to all connected datasets before you can save the workbook.
        
6.  **Layout panel** - The Layout panel shows your pivot table layout. For date and numeric fields, the summary type is shown next to the field. Every time you make changes to your layout, click the Refresh icon ![Refresh report icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Workbook/ReportRefreshIcon_25_2.png) to see the updates.
    
    -   To add fields to the layout, drag them from the Dataset Panel to the section you want. You can add multiple fields to the same table component. For more information, see [Grouping Pivot Table Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1546889165.html).
        
    -   To add a calculated measure, click **Create Calculated Measure** and set up your calculations. Calculated measures have a calculator ![Calculated measures icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Workbook/Calculated-Measure_icon.png) icon. For more information, see [Calculated Measures](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160794526958.html).
        
    -   If you're in a NetSuite account with multiple currencies or subsidiaries and your workbook has fields with values in different currencies, click the Field Menu icon ![Field menu icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Workbook/FieldMenuIcon_25_2.png) next to the field and select **Currency...** to convert or consolidate. You need to do this to run calculations on those fields. For more information, see [Currency in Datasets and Workbooks](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544129169.html).
        
    -   To create a value-based filter, click the Field Menu icon ![Field menu icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Workbook/FieldMenuIcon_25_2.png) and select **Filter \[Field name\]...**. You also create measure-based filters by selecting the **Top 10 \[Field name\]**, **Bottom 10 \[Field name\]**, or **Filter \[Field name\] by** options. For more information, see [Workbook Visualization Filters](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544211325.html).
        
    -   To rename a field, click the Field Menu icon ![Field menu icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Workbook/FieldMenuIcon_25_2.png) and select **Rename...**.
        
    -   To format numbers in the table, click the Field Menu icon ![Field menu icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Workbook/FieldMenuIcon_25_2.png) and select **Format...**. For more information, see [Customizing Numeric Values](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1546889213.html).
        
    -   To change the summary type for dates or numbers, click the Field Menu icon ![Field menu icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Workbook/FieldMenuIcon_25_2.png) next to the field and select the summary type you want.
        
    -   To apply conditional formatting to your pivot table measures, click the Field Menu icon ![Field menu icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Workbook/FieldMenuIcon_25_2.png) next to the field you want to highlight, then point to **Conditional Formatting** and select **Manage Conditional Formatting**. For more information, see [Conditional Formatting](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161125973915.html)
        
    -   To collapse the Layout panel and expand the Pivot Table Viewer, click the double arrows ![Collapse arrows icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Workbook/CollapseArrows.png).
        
    -   To add a grand total for a field, click the Field Menu icon ![Field menu icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Workbook/FieldMenuIcon_25_2.png) and select **Show Grand Total**.
        
7.  **Pivot Table menu** - This menu has additional formatting options for the pivot table. You can do the following:
    
    -   Export icon ![Export icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Workbook/ExportIcon.png) - Export the current pivot table as an XLSX or CSV file.
        
        Important:
        
        To help prevent CSV injection, exported tables may have additional formatting applied. For more information, see [Known Limitations in SuiteAnalytics Workbook](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1551206597.html).
        
        Note:
        
        When you export a pivot table to XLSX, formatting and conditional formatting customizations aren't kept. If your pivot table is in compact mode, you can export it to XLSX only.
        
    -   Totaling icon ![Totaling icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Workbook/TotalingIcon.png) - Add totals and grand totals to your pivot table. You can add column totals to the right or left, and row totals to the top or bottom.
        
    -   Highlight Rows icon ![Highlight row icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Workbook/RowHighlightingIcon18_1.png) - When enabled, rows are highlighted when you point to them.
        
    -   Highlight Columns icon ![Highlight column icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Workbook/ColumnHighlightingIcon18_1.png) - When enabled, columns are highlighted when you point to them.
        
    -   Row Lock icon ![Freeze column icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Workbook/RowFreezeIcon18_1.png) - When enabled, the top row stays visible while you scroll.
        
    -   Column Lock icon ![Freeze row icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Workbook/ColumnFreezeIcon18_1.png) - When enabled, the first column stays visible while you scroll.
        
    -   Compact Mode icon ![Compact mode icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Workbook/CompactModeIcon_18_2.png) - If you define multiple fields as rows or add a multi-column hierarchy, turn on compact mode to combine them into one column.
        
8.  **Pivot Table filter summary** - Shows a summary of the filter conditions applied to the pivot table. Filter conditions created on the Pivot tab only affect the pivot table, not the dataset.
    
9.  **Pivot Table Viewer** - Shows your pivot table after you update the layout and click Refresh ![Refresh report icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Workbook/ReportRefreshIcon_25_2.png). You can also add fields directly to the Pivot Table Viewer instead of dragging them to the Layout panel.
    
    In the Pivot Table Viewer, you can do the following:
    
    -   To resize a column or row, drag its edge until it's the size you want.
        
    -   To change the width of a column based on its values, double-click the column header.
        
    -   To add a total for a column or row, click the Field Menu icon ![Field menu icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Workbook/FieldMenuIcon_25_2.png) and select **Show Grand Total**.
        
    -   To create a measure-based filter, click the Field Menu icon ![Field menu icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Workbook/FieldMenuIcon_25_2.png) and select **Top 10 \[Field name\]**, **Bottom 10 \[Field name\]**, or **Filter \[Field name\]**.
        
    -   To create a value-based filter for the table, click the Field Menu icon ![Field menu icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Workbook/FieldMenuIcon_25_2.png) and select **Filter \[Field Name\]...**.
        
        For more information, see [Workbook Visualization Filters](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544211325.html).
        
    -   To rename a field, click the Field Menu icon ![Field menu icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Workbook/FieldMenuIcon_25_2.png) and select **Rename...**.
        
    -   To sort the table, click the Field Menu icon ![Field menu icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Workbook/FieldMenuIcon_25_2.png) and select **Sort A to Z**, **Sort Z to A**, or **Sort \[Field name...\]**.
        
        Note:
        
        If you sort your results based on a field that contains CLOB values, Workbook currently only evaluates the first 250 characters for each result. Results with more than 250 characters may not be sorted properly.
        
    -   To create a calculated measure, click the Field Menu icon ![Field menu icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Workbook/FieldMenuIcon_25_2.png) next to a measure and select **Create Calculated Measure**.
        
10.  The data refresh details you see depend on whether the Cached Data in Datasets feature is enabled or not:
     
     -   **Cached Response / Real-time Response Data from \[time\]** - Displayed when the Cached Data in Datasets feature is enabled. It tells you if the visualization is showing real-time or cached data, and when it was last updated.
         
     -   **Last Updated** - Displayed when the Cached Data in Datasets feature is disabled. It shows when the data in the current visualization was last updated. To get the latest results, click the **Refresh** icon.
         
     
     For more information, see [Data Refresh in SuiteAnalytics Workbook](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0726032356.html).
     
11.  **Workbook Menu** - You can open this menu from any workbook visualization.
     
     -   Click **Share** to share the workbook and any connected datasets with other users in your account.
         
         For more information, see [Accessing and Sharing Workbooks and Datasets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1531766899.html)
         
     -   Click **Save** to save your workbook, including all your selections in each visualization. You can only save your workbook if the connected datasets have been saved too. If you don't own the connected datasets, save copies with different names.
         
12.  **Learn about Analytics** - Click **Learn about Analytics** to open a panel with all SuiteAnaltyics Workbook videos and their descriptions. To watch a video, click the thumbnail and it opens in a new window.
     
13.  **Tab Menu** - Hover over the Tab menu icon ![Field menu icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Workbook/FieldMenuIcon_25_2.png) and select **Rename Tab** or **Delete Tab**. You can also rename your table view by double-clicking the tab name.
