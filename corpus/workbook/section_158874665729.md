To help familiarize yourself with SuiteAnalytics Workbook, see the following video and help topics:

<a id="kaltura_player_36"></a>

-   To learn how to set up Workbook:
    
    -   Workbook is enabled by default. However, if you do not see the Analytics tab in the NetSuite navigation menu, see [Enabling SuiteAnalytics Workbook in Your NetSuite Account](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1504014192.html).
        
    -   There should be at least one user with the Analytics Administrator in your account. To learn what this user is enabled to do in Workbook, see [The Analytics Administrator Permission](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1536693720.html).
        
    -   If you experience long load times for your datasets or workbooks using your datasets, you can enable Cached Data in Datasets. For more information, see [Optimized Data Refresh](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0726032719.html).
        

-   To learn about custom workbooks, datasets, and preset templates:
    
    -   [Custom Workbooks and Datasets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1544122127.html) covers how to create your own workbooks and datasets. You'll find steps for defining, filtering, and pivoting your data, plus how to link datasets and create custom formula fields.
        
    -   Workbook supports multiple predefined workbook and dataset templates. For more information, see [Workbook and Dataset Templates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1544220378.html).
        

-   To learn about the analytics data source:
    
    -   Workbook uses the new analytics data source, so you might need different fields, record types, joins, or formulas to match your existing saved searches. Review the [Analytics Data Source Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1543418336.html) for more information, including how to join record types and steps to create sample workbooks.
        
    -   Some record types have been created specifically for Workbook and exist only in the analytics data source. For more information, see [Analytical Record Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160614258917.html).
        

-   To learn about the Workbook user interface:
    
    -   Workbook is built using a new user interface. To learn about the elements within the interface, see [Navigating SuiteAnalytics Workbook](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1544220943.html).
        
    -   There is new terminology associated with Workbook. For more information, see the [SuiteAnalytics Workbook Glossary](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_158498698111.html).
        

-   To learn how to create and run SuiteAnalytics Workbook queries using SuiteScript:
    
    -   [Scripting with the N/query Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1532440865.html) explains the different module objects and how to use them when defining your queries.
        
    -   To learn about linking datasets as part of your query definitions, see [Linking Datasets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162627283560.html).
        

-   Additional resources:
    
    -   Complete the [SuiteAnalytics Workbook Tutorial](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1544220685.html) to learn how to create a sample sales order workbook.
        
    -   For information about how to add workbook-based portlets to your NetSuite dashboards, see [Workbook-based Portlets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1544220560.html).
        
    -   There are some known limitations with the current iteration of Workbook. For more information, see [Known Limitations in SuiteAnalytics Workbook](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1551206597.html).
        
    -   You can also visit the [SuiteAnalytics Workbook Community](https://community.oracle.com/community/netsuite/users/reporting/suiteanalytics-workbook) to find answers and other information about Workbook.
        

-   Workbook videos:
    
    -   [Data Model Basics](https://videohub.oracle.com/media/SuiteAnalytics+WorkbookA+Data+Model+Basics/1_3ewbbge9?ed=273): Describes the different record types available in the analytics data source that is used by Workbook.
        
    -   [Joining Record Types in Workbook](https://videohub.oracle.com/media/SuiteAnalytics+WorkbookA+Joining+Record+Types+in+Workbook/1_j2k54m6k?ed=262): Explains the implications of joining record types in Workbook. It also provides some information about the SQL that is used to accomplish these joins in the background, and some suggestions to improve performance.
        
    -   [Separation of Dataset and Workbook in 2020.1](https://videohub.oracle.com/media/SuiteAnalyticsA+Separation+of+Dataset+and+Workbook+in+2020.1/1_97jke7oa): Describes the change in NetSuite 2020.1 that separates datasets from workbooks.
        
    -   [Using Filters in SuiteAnalytics Workbook](https://videohub.oracle.com/media/SuiteAnalyticsA+Using+Filters+in+SuiteAnalytics+Workbook/1_35b1qp3w?ed=214): Describes the different filtering options available in Workbook, including: data grid filters, value-based and measure-based filters for pivot tables, chart filtering options, and workbook criteria filters.
        
    -   [Transaction Data Model in 2020.1](https://videohub.oracle.com/media/SuiteAnalytics+WorkbookA+Transaction+Data+Model+in+2020.1/1_h6m75vwf?ed=429): Describes what happens when you join the transaction, transaction line, and transaction accounting line record types in NetSuite 2020.1. The video also explains the main differences between a transaction saved search and a transaction workbook. You'll also get tips for using the transaction record type as the root record for a dataset.
