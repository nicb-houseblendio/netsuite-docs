This functions filters a record to specify a target value on a multiselect field.

## Parameters {#subsect_98113121251}

| Parameter | Required / Optional | Description | Acceptable Parameter Values |
| --- | --- | --- | --- |
| Relationship field | required | Represents the selected value on a multiselect field. | \- |
| Operator | required | Holds the values supported when filtering relationship fields. | 
-   `'MN_INCLUDE'`
-   `'MN_INCLUDE_ALL'`
-   `'MN_INCLUDE_EXACTLY'`
-   `'MN_EXCLUDE'`
-   `'MN_EXCLUDE_ALL'`
-   `'MN_EXCLUDE_EXACTLY'`

 |
| Display field or empty string | required | A display field should be used if you are filtering a display field value of a relationship field. The empty string value should be used if filtering over foreign key values. | 

-   `'DF'`
-   `''`

 |
| boolean value | required | A boolean value helps specify if the filter should be case sensitive. | 

-   `true`
-   `false`

 |
| value | required | The list of values to be included in the filter. | \- |

## Syntax {#subsect_1031112406}

            `SELECT BUILTIN_RESULT.TYPE_INTEGER("ROLE"."ID") AS "ID" /*{id#RAW}*/,FROM"ROLE"WHERE BUILTIN.MNFILTER("ROLE".accessprofiles, 'MN_INCLUDE', '', 'TRUE', '-2') = 'T'`
