Returns the display value of a field from a target record type without having to join the target record type explicitly.

## Parameters {#subsect_1031101506}

| Parameter | Required / Optional | Description | Acceptable Parameter Values |
| --- | --- | --- | --- |
| Field name | Required | This field represents the relationship between the field and the source record type(for example, `sales.item`). | \- |

## Syntax {#subsect_1031101636}

            `BUILTIN.DF(sales.item)`
