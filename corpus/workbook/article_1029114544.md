This function returns a currency code.

## Parameters {#subsect_1030030942}

| Parameter | Required / Optional | Description | Acceptable Parameter Values |
| --- | --- | --- | --- |
| Amount | Required | The field name to apply criteria context to. | 
-   `amount`
-   `SUM(amount)`
-   `BUILTIN.CONSOLIDATE`
-   `SUM(BUILTIN.CONSOLIDATE)`
-   `BUILTIN.CURRENCY_CONVERT`
-   `SUM(BUILTIN.CURRENCY_CONVERT)`

 |

## Syntax {#subsect_1031085329}

            `BUILTIN.CURRENCY(sales.amount)` 
          

            `BUILTIN.CURRENCY(BUILTIN.CONSOLIDATE(sales.amount, 'INCOME', 'DEFAULT', 'DEFAULT', 1, 304, 'DEFAULT')`
