The SuiteAnalytics Workbook Formula Builder lets you to create custom formula fields using any functions in the [SuiteAnalyticsWorkbookFormulaFunctions.xls](https://system.netsuite.com/core/media/media.nl?id=126024094&c=NLCORP&h=6716f64221527582cb1f&_xt=.xls) spreadsheet. You can add sample formulas for any of these functions directly from the Functions subtab in the Formula Builder using the **Add the example to the formula** link. See the sections below for more sample formulas you can create using the available functions:

-   [Calculating Duration Values with TO\_NUMBER and TO\_NCHAR](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_156460411506.html)
    
-   [Combining CONCAT and other Functions to Calculate String Values](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_156528520694.html)
    
-   [Casting Field Values using TO\_NUMBER and TO\_NCHAR](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_156528465319.html)
    
-   [Currency Consolidation and Conversion Using Custom Formula Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_160406520801.html)
    
-   [Conditional Evaluations Using CASE WHEN](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_159302146246.html)
    
-   [Calculating Amounts for Relative Date Ranges](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_161418884855.html)
    
-   [Calculating Specific Dates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_161608343585.html)
    

For more sample formulas, see [Search Formula Examples and Tips](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N662868.html).

For information about using custom formula fields for currency conversion or consolidation, see [Currency Conversion Using Custom Formula Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1548714767.html).
