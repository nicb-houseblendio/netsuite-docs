SuiteQL queries include references to record types and fields. For example, the following SuiteQL string queries for `entityid` field values that are included in employee records:

          `SELECT employee.entityid AS entityidRAW FROM employee` 
        

To create a query using SuiteQL, you must know the names of the record types and fields that you want to use in your query. You can find these names in several ways:

-   [Using the NetSuite UI](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_0621034919.html)
    
-   [Using the SuiteAnalytics Workbook UI](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_156475679282.html)
    
-   [Using the Export Option from SuiteAnalytics Workbook](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_0325042706.html)
    
-   [Using the Records Catalog](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_160397886310.html)
