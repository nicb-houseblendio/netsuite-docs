Duration values are incompatible with the TO\_NUMBER function unless they are first converted to a variable format using the TO\_NCHAR function. So if you want to make a custom formula field that shows duration values as a number, use this formula:

          `TO_NUMBER(TO_NCHAR({field_ID}))` 
        

For example, let's say you want to see the time elapsed for each case in your account, in hours.

![Example of calculating duration values in the Time Elapsed column.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Workbook/TO_NUMBER_TO_NCHAR_Formula1_20_2.png)

In this case, use this formula with an output type of Float:

          `TO_NUMBER(TO_NCHAR({timeelapsed}))` 
        

![Time Elapsed (Hours) selected in the Formula Field Name fields.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Workbook/TO_NUMBER_TO_NCHAR_Formula2.png) ![Time elapsed shown in the dataset.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Workbook/TO_NUMBER_TO_NCHAR_Formula3_20_1.png)
