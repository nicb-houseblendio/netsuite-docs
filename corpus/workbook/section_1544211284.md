A workbook lets you analyze dataset results by making visualizations like tables, pivot tables, and charts.

Every workbook visualization is based on a dataset, but one dataset can be used in different workbooks and visualizations. You can also use a different dataset for each visualization in a workbook. You can open the dataset right from a workbook visualization, but the dataset is still its own object with its own creator and access controls. Any changes to a dataset are automatically applied to all connected visualizations. This keeps your data accurate, but your workbooks might change unexpectedly if you don't own the underlying dataset.

You can only make visualizations with fields already added to the dataset. If you don't see a field you want, you'll need to add it to the dataset or ask the dataset owner to do it for you. For more information about defining a dataset, see [Defining a Dataset](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544122173.html).

In workbooks with linked datasets, link definitions are part of the workbook. You can use these linked datasets for lots of visualizations, but only in that workbook. You can't share the link definition by itself.

The main workbook visualizations you can create are table views, pivot tables, and charts:

-   Table Views let you see and analyze your dataset results in a simple table. You can't use linked datasets to make a table view. For more information, see [Workbook Table Views](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158083630457.html).
    
    Note:
    
    By default, every workbook template has a Table View based on the dataset. For more information about workbook and dataset templates, see [Workbook and Dataset Templates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1544220378.html).
    
-   Pivot tables let you break down your dataset results to analyze different subsets of data-like the number of unfulfilled orders per customer. With linked datasets, you can use pivot tables to look at metrics from two different levels. For more information, see [Workbook Pivot Tables](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158042187611.html).
    
-   Charts let you create visualizations of your dataset results, so you can analyze them quickly. You can also build charts with linked datasets. For more information, see [Workbook Charts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544211366.html).
    

After you create your workbook visualizations, you can rearrange, rename, or delete workbook tabs as needed.

Note:

If you have multiple languages in your account and you edit and save default text in a workbook or visualization, a new translation collection gets added to the Manage Translations page. For more information, see [Manage Translations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_158572305264.html).
