If you haven't already, complete Step Five: [Pivot Your Dataset Query Results](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544220809.html).

The following steps show you how to create and add an additional dataset from your workbook.

#### To connect a second dataset to your workbook:

1.  Click the add ![Add icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Workbook/AddIcon.png) icon to open a new workbook visualization tab.
    
2.  Click **Connect Dataset**.
    
3.  On the Select a dataset page, click **New Dataset**.
    
4.  Select a record type for the dataset.
    
    For the purposes of this tutorial, select the item record type.
    
5.  In the Dataset Builder, add the quantity on hand and quantity back ordered fields from the item record type to the Data Grid.
    
6.  Click **Save**.
    
7.  In the Save Dataset As window, enter a name and description for the dataset, then click **Save**.
    
8.  Click **Apply to workbook**.
    

Continue to Step Seven: [Set up a Table View](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544220850.html).
