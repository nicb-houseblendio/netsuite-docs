With SuiteAnalytics Workbook, you can join multiple record types in the same dataset, even ones that are more than one join away from your root record type, so you can pull data from a wider range of sources.

By default, the Dataset Builder shows you all the record types you can join. To complete a join, add fields from a record type to the Data Grid or make a criteria filter with the Criteria Builder. If you're not sure which record type to join, search for the field you want to add using the Records and Fields list search function. For more information, see [Locating Fields in Workbook](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159303686294.html) and [Dataset Builder](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544220977.html).

If joining record types is new to you, there are a few things you should keep in mind, like how one-to-many relationships work and the order and direction of your joins. This is especially important if you're working with a transaction dataset and want to join transaction line and transaction accounting line record types.

For more information, see [Guidelines for Joining Record Types in SuiteAnalytics Workbook](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1543418452.html).
