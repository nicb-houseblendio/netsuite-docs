See the questions and answers below for information about SuiteAnalytics Workbook.

### How can I use condition-based filters in currency fields?

Condition-based filters are available for percentage, integer and float fields that do not return currency values. If you want to use this option with currency fields, customize your field using the TO\_NUMBER formula and change the output type.

For more information about how to customize a currency field, see [Advanced Sample Formula Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1554307527.html).

### How can I use relative dates in Workbook formulas?

The SuiteAnalytics Workbook Formula Builder lets you create custom formula fields using relative dates.

For more on Workbook formulas and examples using relative dates, see [Calculating Amounts for Relative Date Ranges](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_161418884855.html) and [Advanced Sample Formula Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1554307527.html).

### How do I remove a dataset from a workbook after it's been connected?

You can't manually disconnect a dataset after you connect it to a workbook. When you save and close a workbook, any datasets you didn't use in a visualization are removed automatically.
