You can use SuiteQL to query your NetSuite data using the N/query module in SuiteScript. The following object and methods are available in the N/query module to work with SuiteQL:

-   The [query.SuiteQL](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157960384819.html) object represents a SuiteQL query. It includes properties that represent the query type, the SuiteQL string representation of the query, result columns to return from the query, and any additional parameters the query requires. You can use [SuiteQL.run()](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157960470046.html) to run the query as a non-paged query or [SuiteQL.runPaged(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157960491275.html) to run the query as a paged query.
    
-   The [Query.toSuiteQL()](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157960522744.html) method converts an existing query (as a [query.Query](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510275177.html) object) to its SuiteQL representation (as a [query.SuiteQL](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157960384819.html) object).
    
-   The [query.runSuiteQL(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157960542026.html) and [query.runSuiteQLPaged(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157960586441.html) methods let you run an arbitrary SuiteQL query. You can specify this query as a SuiteQL string, [query.SuiteQL](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157960384819.html) object, or generic JavaScript Object containing a required `query` property and an optional `params` property.
    

Note:

If the SuiteAnalytics Connect feature is enabled in your NetSuite account, there's no limit to the number of results these methods can return. If the SuiteAnalytics Connect feature isn't enabled, these methods can return a maximum of 100,000 results across all pages in the result set. For more information about SuiteAnalytics Connect, see [SuiteAnalytics Connect](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_3963845427.html).

Here's an example of how to load an existing query, convert it to SuiteQL, and run it:

          `var myLoadedQuery = query.load({ id: 'custworkbook237' }); var mySuiteQLQuery = myLoadedQuery.toSuiteQL(); var myResultSet = mySuiteQLQuery.run();` 
        

For more information, see [SuiteQL in the N/query Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157960623712.html).

For a list of supported functions, see [SuiteQL Supported and Unsupported Functions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158513731864.html) and [SuiteQL Supported Built-in Functions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161950565221.html).
