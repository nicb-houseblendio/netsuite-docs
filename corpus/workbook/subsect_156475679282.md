You can use the SuiteAnalytics Workbook UI to find record type and field names. SuiteAnalytics Workbook uses the same data source that SuiteQL does (the analytics data source), so you can use the SuiteAnalytics Workbook UI to explore the available record types and fields before you create your query.

#### To find record type and field names using the SuiteAnalytics Workbook UI:

1.  In your NetSuite account, click the **Analytics** tab in the NetSuite navigation menu.
    
2.  On the **Workbooks** page, click **New Workbook**.
    
3.  Search for the record type that you want to use as the root record of your query.
    
    The name of each supported record type is listed in the Record ID column. You can use this page to find all supported record type names, but you can't use this page to find field names. If you need to find field names, continue to step 4.
    
    ![Record ID column](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Workbook/SuiteQLFindRecordTypeNames.png)
4.  Click a record type. A workbook is created with the selected record type as the root record.
    
    The left column lists the record types that you can join with the root record. The middle column lists the fields that are available on the selected record.
    
    ![Employee and Entity ID columns.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Workbook/SuiteQLFindFieldNames.png)
5.  In the middle column, find the field that you want to use in your query. Hover over the field, and click the information button.
    
    ![Field information button](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Workbook/SuiteQLFieldInfo.png)
    
    Information about the field is displayed. The field name is listed under Field ID. You can also see the type of data that the field contains (text, date, boolean, and so on).
    
    ![Field information popup window.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Workbook/SuiteQLFieldID.png)

If you want to find field names for fields that are on a different root record, repeat this procedure from step 2 and choose a new root record. To learn more about creating workbooks, see [SuiteAnalytics Workbook Tutorial](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1544220685.html).
