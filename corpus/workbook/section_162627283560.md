You can link two datasets if each one has at least one field with shared data, like a date. Then you can use the linked datasets to build one workbook visualization and compare data from both.

Link definitions are part of the workbook they're created in and can't be shared on their own, but you can still share each linked dataset by itself. If someone shares a workbook with you that uses linked datasets, you can use them to make new visualizations in that workbook. For more information, see [Dataset Linking in SuiteAnalytics Workbook](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_162627392718.html).
