SuiteAnalytics Workbook currently offers over 20 predefined workbook and dataset templates.

A dataset template comes with all the required fields, record types, and filters you need, so you can create a workbook without setting up a complex dataset first. Workbook templates also include predefined workbook visualizations like table views, pivot tables, and charts, so you can easily analyze and visualize data from the related dataset templates. In a workbook template, you can add more visualizations based on the connected dataset template or any other datasets you have access to.

By default, only users with the Analytics Administrator permission can access workbook and dataset templates. If you don't have the Analytics Administrator permission, you can only use these templates if a someone with that permission shares them with you. You also need access to the underlying dataset template to open a workbook template. Additionally, some templates are feature dependent. If you don't see a listed templates in your account, reach out to your account administrator.

If you have the Analytics Administrator permission, you can get to the templates from the Analytics Home page under either the Workbooks or Datasets subtabs.

For more information about the Analytics Administrator permission, see [The Analytics Administrator Permission](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1536693720.html).

To see the dataset templates currently available in SuiteAnalytics Workbook, see [Dataset Templates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158085103375.html).

To see the workbook templates currently available in SuiteAnalytics Workbook, see [Workbook Templates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158085159253.html).

The sales (ordered), sales (invoiced), and manufacturing workbook and dataset templates are based on custom analytical record types made for SuiteAnalytics Workbook. These record types combine data from transaction, transaction line, and transaction accounting line record types.

To see the analytical record types currently available in SuiteAnalytics Workbook, see [Analytical Record Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160614258917.html)
