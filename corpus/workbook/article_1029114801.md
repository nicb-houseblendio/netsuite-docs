This function returns filter options for department, class, location, subsidiary, and entity record types.

## Parameters {#subsect_1031112601}

| Parameter | Required / Optional | Description | Accepted Parameter Values |
| --- | --- | --- | --- |
| Record type | required | The record to return filter options for. | 
-   Department records
-   Class records
-   Location records
-   Subsidiary records
-   Entity records

 |
| Workgroup | required | Represents a way to filter a record with "me" or "mine". | 

-   `'me'` - Supported for Entity, Customer, Vendor, and Partner record types.
-   `'mine'` - Supported for Classification, Department, Location, and Subsidiary record types.

 |

## Syntax {#subsect_1031114512}

            `BUILTIN.NAMED_GROUP('employee', 'me')` 
          

            `BUILTIN.NAMED_GROUP('subsidiary', 'mine')` 
          

            `select * from Subsidiary where id in BUILTIN.NAMED_GROUP('subsidiary', 'mine')`
