If you are not sure which record type you want to join to a dataset, you can browse or search the Records and Fields list in the Dataset Builder. To get an overview of the Dataset Builder, see [Dataset Builder](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544220977.html).

The record types and fields you can see are based on your permissions and the role you use to log in. If you don't see a record type or field you think you should have access to, contact your administrator.

By default, record types and fields are listed alphabetically, except in a transaction dataset. In a transaction dataset, the transaction line and transaction accounting line types are listed at the top, since they're the most commonly joined record types.

You can search for fields by their label or internal ID. Searches work across record types up to three joins away from your dataset's root. If you'd like to search more, click **Show more results**.

If you're working in an existing dataset and aren't sure which record type a field belongs to, point to the field in the Data Grid or criteria filter, click the field menu icon, and select **Show Location in Field List**. The record type will be highlighted in the Records List.
