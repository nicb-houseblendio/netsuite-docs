Frequently asked questions related to general usability of the app.

### What's the maximum PDF file size I can attach to an expense?

The maximum file size for PDF attachments is 2 MB.

Note:

Attaching PDF files to expenses is only supported on NetSuite for Android. PDF attachments are not supported by any other record.

### How much data does the app use?

All communication is compressed and encrypted. On average, the app consumes less than 10 MB of data per month.

### How do I shrink large images when uploading through the Android app?

The resolution of receipt images can be managed from the settings menu. There are three options:

-   960 x 960
    
-   1280 x 1280
    
-   2048 x 2048
    
    Note:
    
    Uploading multiple images at this resolution may cause issues on older devices and slow connections.
    

The maximum file size for each image upload is 5 MB.

### Is the app available offline?

Yes. You can capture expenses and use the timer offline. Enable offline features from the login screen, and accept the terms and conditions.

### Why is my dashboard empty?

No supported portlets have been configured on your web application dashboard. For more information, see [NetSuite for Mobile Dashboards](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1553858494.html).

### How can I change the first (default) screen?

The My Dashboard screen has many configuration options. You can make the following configurations:

-   Reorder portlets.
    
-   Define which portlets are displayed.
    

For more information, see [NetSuite for Mobile Dashboards](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1553858494.html).

You can also reorganize which shortcuts are displayed on the Tab Bar at the bottom of the screen with NetSuite for iOS. For more information, see [Configuring the Tab Bar in NetSuite for iOS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156207479366.html).

### How do I enable file uploads?

For the majority of users, file uploads will work without any configuration. You should make sure **File Cabinet** is enabled at _Setup > Company > Enable Features, Data Management column_, and a folder location is already defined in NetSuite for expense reports. The app uses this folder as its default image upload folder. If an expense reports folder has not been set up, the app uses the Images folder.
