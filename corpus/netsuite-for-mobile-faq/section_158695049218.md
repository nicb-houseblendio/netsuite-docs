Frequently asked questions related to record management.

### What records are supported?

See [Mobile Supported Record Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1553696109.html).

### Does the app support custom records?

Yes. Users have complete access to custom records including support for view, edit, create, and delete (for any custom records already accessible through the NetSuite web application). You can access Saved Searches based on custom records. You can also use the Global Search feature (including view, edit, create, and delete) to search for any custom records already accessible through the NetSuite desktop application.

### I would like to modify the entry form used for customer records. How do I change the entry form for a specific record type?

The app uses the preferred form defined for your role. To change the entry form for a specific record type, open a browser session and define your preferred form. See [Defining Preferred Forms](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2873968.html).

### How do I change which fields are displayed on the Summary screen of a record?

Modify the QuickView fields for your preferred view. See [Configuring QuickViews](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2859666.html).

### I cannot access some of my custom records. How do I make all custom records visible on my app?

To be accessible from a mobile device, custom record types must have both the Allow UI Access and the Allow Mobile Access boxes checked. See [Creating Custom Record Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2876492.html) and [Prevent Access to a Custom Record Type through the User Interface](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N2879618.html).

### My Saved Search is not showing up as a view?

Make sure that you have checked Available as List view when configuring the Saved Search. See [Using a Saved Search as a View](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N679407.html).

### How do I add more filters for a specific list?

Only filters which have been exposed as Available Filters on the Saved Search/View are available on NetSuite for iOS. Check that the Saved Search/View is configured with the required filters. See [Customizing List Views](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N496170.html).
