Access levels determine which information about the Project 360 Dashboard are shown depending on your role. The system filters the list of projects to show based on the access level given to you.

The **Project 360 Access Level** field is located on the **Human Resources** subtab of the Employee record.

Important:

To use the access levels properly and with projects associated to proper financial segments, you must install the Project Classification SuiteApp. See [Installing the Project Classification SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_8110329949.html).

The SuiteApp provides the following access levels:

| Name | Description |
| --- | --- |
| Blank | This access level is automatically assigned to you if you install and use the Project 360 Dashboard SuiteApp for the first time. To access projects, an Administrator must change your access from **Blank** to other appropriate access level from the dropdown list. No projects are shown on the dashboard if your access level is set to blank. |
| Assigned to me | This access level is the default value of the **Project 360 Access Level** field on the employee record. You can select this access level to view only the projects that are assigned to you. It provides access to your projects if you have the following settings:
-   You are assigned as the project manager in the **Project Manager** field of your Employee record.
-   You have a project manager role shown on the **Resource Details** subtab of a project record.

Note: After you update or install version 1.1.0 of the SuiteApp, and the **Project Manager** box is checked on your employee record, your access level will be set to **Assigned to me**. |
| My Department | This access level lets you view all the projects in your department if the department name matches on both the Employee record and the Project record. |
| My Department Hierarchy | This access level lets you view all the projects in your Department and its subdepartments. |
| My Subordinates | This access level lets you view the projects of employees reporting to you. You must have a Supervisor role to view all the projects for your subordinates. To view the list of your subordinates, open your Employee record, go to **Human Resources** subtab then scroll down to the **Subordinates** subtab. An employee's supervisor is indicated on the **Supervisor** field of an Employee record. |
| All Projects | This access is intended for employees with non-project manager role who requires access to all projects of all the project managers in an organization. The employee with this access level can access all the projects with a status of **In Progress**, **Awarded**, and **Pending**. |
