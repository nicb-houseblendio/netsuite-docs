The Project 360 Dashboard portlets display data from various features of NetSuite. Some portlets on the SuiteApp need to be configured before they'll display any content.

You can also set preferences like color theme, fonts, chart theme, centers and dashboards, and other. The Project 360 Dashboard supports the Redwood Experience Theme. For more information, see [Personal Preferences for Appearance](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N479574.html).

Ensure the required features are enabled before setting up the dashboard portlets, see [Prerequisites for Project 360 Dashboard SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164121414085.html).
