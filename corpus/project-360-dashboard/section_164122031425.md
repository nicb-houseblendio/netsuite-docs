The Project 360 Dashboard SuiteApp lets project managers manage multiple projects in one place with readily accessible metrics, reports, and statuses. These project data related to tasks, resources, budget, and finance are organized on various focus pages.

A focus page provides a centered presentation of interrelated data contained in two or more portlets.

To access the dashboard, refer to the table listed on [Accessing Project 360 Dashboard](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0517061639.html).

Project managers can select a project from the [Project Portfolio](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164122038093.html) page, then drill down to the following focus pages:

-   [Project Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164122041362.html)
    
-   [Resource Planning](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164122042826.html)
    
-   [Budget and EAC](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164122044326.html)
    
-   [Billing and Revenue](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164122046180.html)
    
-   [Financial](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164122047407.html)
    

In the Project 360 Dashboard, portlets are organized on individual focus pages according to the type of datasets they contain. Focus pages contain common portlets that provide quick access to various records and pages. See [Common Portlets in Project 360 Dashboard](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_164135677431.html).

A portlet is a container that can be added to a user's dashboard, which requires a setup to display contents from one or more features of NetSuite.

Make sure you complete the required setup to view the data on the portlets for every focus pages. See [Setting Up Project 360 Dashboard Portlets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164397387391.html).
