The Project 360 Dashboard Preference page provides flexibility for Administrators to manage the type and amount of information to show on your account.

To set the preference, go to List> Relationship> Project 360 Dashboard Preference, then check or clear the boxes to select which focus pages appear on your dashboard.

Important:

The system requires only one Project 360 Dashboard Preference record for each account, and the record must not be duplicated, deleted, or set to inactive.

The Project 360 Dashboard Preference page contains the following check boxes:

-   Project Overview
    
-   Resource Planning
    
-   Budget and EAC
    
-   Billing and Revenue
    
-   Financial
