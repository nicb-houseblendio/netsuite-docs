Any standard or custom NetSuite role can use the Project 360 Dashboard SuiteApp if the Employee record has a Project 360 access level. See [Access Levels for Project 360 Dashboard](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0427123552.html).

However, roles without sufficient permissions cannot view accurate saved search results or access some data on records.

To set up permissions for custom roles, go to _Setup > Users/Roles > Manage Roles_ and click **Edit** beside the custom role.

Make sure you add these permissions and access levels to the user's role:

| Subtab | Permission | Access Level |
| --- | --- | --- |
| Transactions | Invoice | View |
| Bills | View |
| Purchase Order | View |
| Enter Vendor Credits | View |
| Reports | Project Profitability | View |
| List | Project | Edit |
| Project Tasks | View |
| Contacts | View |
| Employee Record | View |
| Departments | View |
| Setup | Bulk Time Entry Modification | Edit |
| Custom List | View |
| Other List | View |
| Project Profitability Setup | View |
| Custom Record | Project 360 Dashboard Preference | View |

For more information, see the help topics [Assigning Roles to an Employee](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N897798.html) and [Customizing or Creating NetSuite Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N285937.html).
