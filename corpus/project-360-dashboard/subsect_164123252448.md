The Project Information portlet shows the general information about the project, and sources the data from the project record and the customer record.

The following details are shown on the Project Information portlet:

-   **Project ID** - By default, this field shows the value entered in the **Job ID** field of the project record. Clicking the Project ID link takes you to the project record. If the **Auto-Generated** feature is enabled, this field shows the auto-generated ID of the project. For more information, see [Setting Up Auto-Generated Numbering](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0404030807.html).
    

-   **Project Name** - This field shows the project name entered in the **Project Name** field. If the **Auto-Generated** feature is disabled, the project name also appears in the **Project ID** field.
    
-   **Project Manager** - This field shows the project manager assigned to the project. You can click the value in this field to see the corresponding employee record.
    
-   **Client Name** - This field shows the name of the client for the project, which comes from the **Customer** field of the project record.
    
-   **Client Primary Contact** - This field shows the name of the contact person for the client of the project. You can click the value in this field to see the corresponding contact record.
    
-   **Due Date** - This field shows the scheduled end date of the project, which comes from the **Calculated End Date** field on the project record.
    

Any changes you make on the primary details of the project records reflect on this portlet.
