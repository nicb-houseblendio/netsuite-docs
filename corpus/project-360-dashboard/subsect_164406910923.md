The following table describes the tasks to set up the Project Overview portlets:

| Portlet | Task |
| --- | --- |
| [Key Performance Indicators Portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164181902071.html) | 
-   **Create a Project Budget** - Set up a project budget to plan your spending for completing the project. The Budget vs. EAC gauge chart sources data from your project budget. To set up a project budget, see [Creating a Budget from a Work Breakdown Structure](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_157830326096.html).
-   For the Profitability gauge chart setup, see the requirement listed on [Financial Portlets Set Up](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_164406923100.html). The gauge chart displays the values and chart colors (green, amber, or red) when there are transactions associated to the project.

 |
| [Primary Information Portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164172496159.html) | No prior setup is required. When you create a project record, the system automatically populates the project's primary information. |
| [Team Details Portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164172498959.html) | 

-   **Identify Project Team Resources** - Identify an employee, a generic resource, or a vendor to include in your project so you can start delegating tasks. See [Identifying an Employee as a Project Resource](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1188347.html) and [Identifying a Vendor as a Project Resource](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1188644.html). If you need to create a specific project resource role or a generic resource, see [Working with Resources in Project Management](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1187445.html).
-   **Assign Resources to a Project** - With the **Resource Allocations** feature enabled, you can allocate resources to individual projects or to directly assign resources to project tasks. See [Assigning Resources with Allocations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_3746701142.html#bridgehead_4362895283). For more information about enabling a feature, see [Enabling Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N232138.html).

 |
| [Project Documents Portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164172499937.html) | No prior setup is required. When you create a project record, the system automatically displays the project documents attached to the project record. |
| [Client Contact Portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164172501620.html) | 

-   **Create a Contact Record** - To create a new contact for individuals you do business with, read [Creating a Contact](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_161792162006.html). The portlet shows only a contact with a **Primary Contact** role.
-   **Associate a Contact to the Customer Record** - To associate a contact with the customer record, see [Associating a Contact with a Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1075740.html). Ensure to select the customer to which you associate the contact in the **Customer** field of the project record.

 |
