Monitor a project's health by reviewing snippets of key performance indicators in the My Project Portfolio portlet. KPIs for budget, resourcing, and financials help project managers track and measure progress of each project toward the goal.

The My Project Portfolio portlet lists all the projects with a status of **In Progress**, **Awarded**, and **Pending**. The projects you see depend on your access level.

By default, projects are sorted by overall status. High risks projects are shown at the top of the list followed by **Medium**, **Low**, and then **None**. You can change the default view into a descending or ascending order by clicking the appropriate column header.

Additionally, you can use these filters to narrow down your search results:

-   Project
    
-   Client
    
-   Project Manager
    
-   Project End Date
    

After you select a value for the first filter, the remaining dynamic filters only show options relevant to your first selected choice. These filters include **Project**, **Client**, and **Project Manager**.

The **Project End Date** lets you select a date range to show only the project within your chosen date range.

Click the **Clear All Filters** to remove any filters you applied on the projects list. Similarly, the filters are cleared if you load a new page within the dashboard.

The My Project Portfolio portlet shows 20 projects by default, and up to 50 at a time. If you have more than 50, you can move between pages by clicking the **Next** and **Previous** icons.

Click the name of the project from the table to go to the project's corresponding Overview page.

The following columns are shown on the My Project Portfolio portlet:

| Column Header | Subcolumn Description |
| --- | --- |
| Project Information | 
-   **Overall Status** - This column shows the status of the project based on the risk meter determined by the system. For more information, see [Criteria for the Overall Status of a Project](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_165052296973.html).
-   **Project ID**\- This column shows the auto-generated ID for the project. By default, auto-generated numbers are enabled for transactions record types and document types. You can modify the value by entering a different ID for the project. For more information, see [Setting Up Auto-Generated Numbering](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0404030807.html). Clicking the **Project ID** takes you to the Project Overview page of a specific project.
-   **Project Name** - This column shows the project name entered in the **Project Name** field of the project record.
-   **Client** - This column show the name of the project's customer sourced from the customer record.

 |
| Budget | 

-   **Budget vs. EAC** - This column shows the calculated variance percentage between the baseline budget and the EAC budget. If there is no data to retrieve or the baseline budget is zero, the system displays an em dash ( - ).
-   **Percentage Complete** - This column shows the percent of the total planned project time that has been completed. This value is sourced from the **Percent Work Complete** field of the project record.

 |
| Resourcing | 

-   **Tasks Not Resourced** - This column shows the number of tasks that are not yet assigned to a resource out of the total number of tasks for the project.
-   **Tasks Overdue** - This column shows the total number of tasks that are overdue for one or more projects. The tasks overdue count does not include milestone tasks.
-   **Timesheets Not Approved** - This column shows the number of timesheets that are not yet approved out of the total number of created timesheets.

 |
| Financials | 

-   **Profit Percentage** - This column shows the percentage value of the calculated difference between the revenue and the costs for the project.
-   **Unpaid Invoices** - This column shows the aggregated amount of unpaid invoices for the project.
-   **Unbilled Charges** - This column shows the aggregated amount of unbilled charges for the project.
-   **Charges Not Invoiced** - This column shows the number of charges that do not have an invoice.

Note: The system can load up to 6,000 projects that include charge and invoice values. If the project's billing type isn't charged-based, an em dash is shown under **Unbilled Charges** and **Charges Not Invoiced** columns. |
