The following table describes the tasks to set up the Billing and Revenue portlets:

| Portlet | Task |
| --- | --- |
| [Client Invoice Details Portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164172049039.html) | No prior setup is required. Invoices and unbilled charges associated to the project appear on the portlet after creating the transaction. |
| [Client Contact Portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164172060238.html) | This portlet is similar with the Client Contact portlet on the Project Overview page, which displays the information from the contact record you associate to the project.
-   **Create a Contact Record** - To create a new contact, read [Creating a Contact](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_161792162006.html).
-   **Associate a Contact to the Project Record** - To associate a contact with the project record, read [Associating a Contact with a Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1075740.html).
