The following table describes the tasks to set up the Resource Planning portlets:

| Portlet | Task |
| --- | --- |
| [Gantt Chart Portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164171520654.html) | 
-   **Create a Project Schedule** - Create a project plan to lay out the timeline for delivering the project. To create a project schedule, see [Working with the Project Schedule](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1202036.html).
-   **Create a Project Task or Milestone Task** - A Gantt chart requires at least one milestone task or project task to display the data on the portlet. To create a project task, see [Creating a Project Task Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1194983.html). To create a milestone task, see [Creating Milestone Tasks](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3740066806.html).

 |
| [Resource Allocation Chart/Grid Portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164171527631.html) | 

-   **Enable the Resource Allocations Feature** - You must enable the **Resource Allocations** feature to install the Resource Allocation Chart/Grid SuiteApp. See [Enabling Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N232138.html).
-   **Install the RACG SuiteApp** - Install the Resource Allocation Chart/Grid SuiteApp 2.0 to access the features and display the data specific to RACG. See [Installing the Resource Allocation Chart/Grid SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3746921235.html#bridgehead_1503020222).
-   **Grant New Custom Roles with Access to RACG.** - After customizing a role to access the Resource Allocation Chart/Grid, an Administrator must add every permitted internal role, including Administrator, to the Internal Roles list on each RACG script deployment. For more information, see [Adding Role Access to the Resource Allocation Chart/Grid SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3746921235.html#subsect_0703125735).
-   **Run the Required Script** - After granting access, you can proceed with running the **PSA RACG SU Main** script. See [Running Scripts for Resource Allocation Chart/Grid](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3746921235.html#bridgehead_1520491343).

 |
| [Milestones Portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164171538694.html) | **Create a Milestone Task** - Create milestones to mark a significant progress toward the goal of the project. To create a milestone task, see [Creating Milestone Tasks](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3740066806.html). |
| [Timesheet Tracking Portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164171563334.html) | **Enable the Required Feature** - You must enable the **Weekly Timesheets** feature to view the data on the portlet. For more information, See [Enabling Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N232138.html). |
| [Actual Hours vs. Planned Hours by Resources Portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164172026923.html) | 

-   **Set Project Preferences** - Check the **Allow Time Entry** and **Create Planned Time Entries** boxes on the Preferences subtab of the project record.
-   **Assign a Resource to a Project Task** - Assign a resource to a project task to generate the planned time. For more information, see [Assigning Project Resources](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1189140.html).

The Actual Hours data on the graph are shown after the project managers approve the timesheets submitted for the project. |
