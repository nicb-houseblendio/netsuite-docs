The following table describes the tasks required to set up the Financial portlets:

| Portlet | Task |
| --- | --- |
| [Client Invoices Portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164247223913.html) | No prior setup is required. The portlet displays the graph when there are invoices for the project to show. |
| [Project Profitability Portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164172062051.html) | **Enable the Required Feature** - You must enable the **Advanced Project Profitability** feature to view the data on the portlet. For more information, see See [Prerequisites for Project 360 Dashboard SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164121414085.html). |
| [Profitability Report Portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164172068374.html) |
