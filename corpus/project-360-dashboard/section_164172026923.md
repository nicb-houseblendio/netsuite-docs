The Actual Hours vs. Planned Hours by Resources portlet is a graph representation of the hours assigned to and logged by each project resource. It tracks their progress in finishing tasks within the planned hours.

Here's a screenshot of the Actual Hours vs. Planned Hours by Resources portlet and the details it can show:

![Project360ActualvsPlannedHours](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Projects/Project360DashboardActualvs.PlannedHours.png)

Project resource names are on the y-axis, and the range of hours is on the x-axis.

Note:

The bar graph displays on the portlet only if the project resource has an assigned task and has logged time entries.

The following information describes the legends of the graph, which you can also see in the tooltip when you hover over each bar:

-   **Planned** - This bar indicates the number of planned work hours by a project resource, which the portlet sources from the **Assignees** subtab of the Project Task record. Assigning a resource to a project task generates a planned time. For more information, see [Assigning Project Resources](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1189140.html).
    
-   **Actual** - This bar indicates the number of hours logged by the project resource in their submitted time entries. The actual hours logged can be at the project level, a task level, or a combination of both.
    
-   **Unassigned** - This bar is shown for generic resources. Generic resources are used when a specific resource has not been identified yet. They are resources not added to the resource allocation but are included as resources in the project record under the **Resource Details** subtab of **Resources** subtab.
    
-   **Remaining** - This information displays on the tooltip when you hover over the bars on the graph. The value shown for this category indicates the difference in hours after deducting the Actual hours from the Planned hours of the resource.
