The Project Overview page on the Project 360 Dashboard outlines the primary details and key performance indicators of the project.

Within the Project Overview page, you can check project details and key metrics using these portlets:

-   [Key Performance Indicators Portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164181902071.html)
    
-   [Primary Information Portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164172496159.html)
    
-   [Team Details Portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164172498959.html)
    
-   [Project Documents Portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164172499937.html)
    
-   [Client Contact Portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164172501620.html)
    

To view other projects assigned to you, click the dropdown button beside the project name on the page header. From the dropdown list, select any project you want to view. Every project displays on the list regardless of the status.

Each portlet and focus pages load information specific to the project you select.
