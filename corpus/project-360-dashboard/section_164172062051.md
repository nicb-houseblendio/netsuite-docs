The Project Profitability portlet provides a visual representation of the project's financial profit and lets you measure the level of operational efficiencies so you can take corrective actions.

This portlet sources the data from the Profitability Report page. The Project Profitability gauge chart is also shown on the Key Performance Indicators portlet of the Project Overview page.

To view the descriptions for the gauge chart including how to calculate the margin, see [Key Performance Indicators Portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164181902071.html).
