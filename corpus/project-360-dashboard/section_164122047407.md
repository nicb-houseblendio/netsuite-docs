The Financial page lets project managers view the financial information for the projects to which they are assigned to.

To set up the Financial portlets, see [Financial Portlets Set Up](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_164406923100.html).

By accessing the Financial page, you can keep track of the information from the following portlets:

-   [Client Invoices Portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164247223913.html)
    
-   [Project Profitability Portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164172062051.html)
    
-   [Profitability Report Portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164172068374.html)
