The Resource Allocation Chart/Grid (RACG) portlet in Project 360 Dashboard offers a visual tool for viewing, creating, and editing resource allocations. You can choose to view your allocations in either a chart or a grid. See [Resource Allocation Chart/Grid](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_3746701142.html#bridgehead_3746900104).

Resource Allocations help resource managers to allocate and to assign the right resources to projects based on availability, skill sets, and other criteria. After allocating or reserving a resource to a project, a project manager may then decide to assign that resource to a specific task.

You can also allocate resources directly to project tasks eliminating the requirement for resources to be assigned separately. This can be useful when the same person both allocates resources and assigns project tasks. For more information, see [Resource Allocations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_3746701142.html).
