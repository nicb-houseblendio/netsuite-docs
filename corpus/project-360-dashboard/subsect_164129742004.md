The Take Action portlet provides project managers with a quick access to records and pages associated to the project, so they can make the necessary adjustments.

The following table describes the links available on the portlet depending on the focus page you view.

| Focus Page | Link |
| --- | --- |
| Project Overview | 
-   **Update Project Record** - This link takes you to the project record where you can update the details of the project.
-   **View Client Record** - This link takes you to the customer record where you can update the details on the customer record. The link does not display when there is no customer record associated to the project.

 |
| Resource Planning | 

-   **Update Project Schedule** - This link takes you to the project record where you can edit the date for the tasks or milestones under the **Schedule** subtab. For more information, see [Working with the Project Schedule](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1202036.html).
-   **Edit Resource Allocation** - This link takes you to the Resource Allocations page where you can edit or create new resource allocations. For more information, see [Using the Resource Allocation Chart/Grid](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1503039257.html).
-   **View Gantt Chart** - This link takes you to a full screen view of the Gantt chart where you can view all the related tasks for the project. For more information, see [Gantt Chart](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1202036.html#bridgehead_N1202133).

 |
| Budget and EAC | 

-   **Manage Project Budget** - This link takes you to the project record where you can manage the existing budget on the **Budget** and **Work Breakdown Structure** subtabs. For more information, see [Advanced Project Budgeting](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156266908909.html).
-   **Transfer Incorrect Time** - This link takes you to the Update Time Entries page where you can update time entries or change how time is billed to the customers. For more information, see [Updating Time Entries](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156408321759.html) and [Transferring Time Between Projects](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156408321759.html#subsect_156417648472).

 |
| Billing and Revenue | 

-   **Manage Project Billing** - This link takes you to the project record where you can view or update the charges on the **Charges** subtab under the **Financial** subtab. For more information about project billing, see [Project Billing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1204906.html). Note: The **Charges** subtab is shown when the project billing type is charged-based. To show the **Charges** subtab, you must have the **Charge Rule** permission. To view the entries under the **Charges** subtab, you must have the **Charge** permission.

-   **Manage Revenue Recognition** - This link takes you to the project record where you can update the value in the **Rev Rec Forecast Rule** field. The value in this field is used for creating a forecast revenue recognition plan for the project. See [Revenue Recognition Rules](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4333740009.html).

Important: You must enable the **Advanced Revenue Management (Essentials)** feature to view the data. |
| Financial | **Manage Revenue Recognition** - This link is similar with the Manage Revenue Recognition link available on the Billing and Revenue page. |
