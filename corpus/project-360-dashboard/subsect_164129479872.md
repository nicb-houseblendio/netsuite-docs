Employees with full permissions on the project record can assign a project manager to view and edit data in the Project 360 Dashboard.

Note:

An employee needs to be listed as a project resource and designated as Project Manager in their Employee record to display in the Project Manager dropdown list. See [Identifying an Employee as a Project Resource](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1188347.html).

If you need to create a new employee record, see [Adding an Employee](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N894212.html)

#### To assign a project manager to a project:

1.  Go to _Lists > Employees > Employees_.
    
    1.  On the Employees list page, click **Edit** beside the corresponding employee record that you want to edit.
        
    2.  On the **Human Resources** subtab, on the Job Information section, check the boxes for **Project Resource** and **Project Manager**.
        
    3.  Click **Save**.
        
2.  Go to Lists > Relationships > Projects.
    
    1.  On the Projects list page, click **Edit** next to the project name that you want to edit.
        
    2.  On the Primary Information section, in the **Project Manager** dropdown list, assign the project manager by selecting the name of the employee.
        
    3.  Click **Save**.
