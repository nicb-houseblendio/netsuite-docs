There are three different ways to access the Project 360 Dashboard. NetSuite displays a variable set of tabbed pages, called a center, based on the user's assigned role. Each NetSuite center provides, for users with related roles, the pages and links they need to do their jobs. See [NetSuite Standard Centers](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N132466.html).

Any standard and custom NetSuite roles with sufficient permissions can access the Project 360 Dashboard using the following navigation path:

| Center | Navigation |
| --- | --- |
| Classic Center | Lists > Relationships > Project 360 Dashboard |
| Project Center | Projects > Project 360 Dashboard |
| Executive Center | Sales/Marketing > Lists > Project 360 Dashboard |

The Project 360 Dashboard supports only the NetSuite standard centers listed on the table.

To view the necessary permissions for using the Project 360 Dashboard, see [Roles and Permissions for Project 360 Dashboard](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164121661883.html).
