The following table describes the tasks to set up the Project Portfolio portlets:

| Portlet | Task |
| --- | --- |
| [My Project Portfolio Portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164247872902.html) | 
-   **Create a Project Record** - Create a project record so you can track key deliverables for completion. Project records store information like customer, start date, and status. For more information, see [Creating a Project Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1183012.html). Ensure that project status is set. Only projects marked **In progress**, **Awarded**, or **Pending** display in the portlet.
-   **Assign a Project Manager** - Employees with full permissions to the project record need to assign a project manager so they can access the records and pages for the projects. For more information, see [Assigning a Project Manager to a Project](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_164129479872.html).
