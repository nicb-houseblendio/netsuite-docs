The Project Portfolio is the main landing page of the Project 360 Dashboard. It contains the My Project Portfolio portlet, where project managers can view their assigned projects, the project's primary information, and its key metrics.

The Reminders portlet is also displayed on the Project Portfolio page. The common portlets like Project Information, Reminders, and Take Action can be seen on all focus pages on the Project 360 Dashboard.
