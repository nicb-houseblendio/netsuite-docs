The Budget vs. EAC by WBS in Project 360 Dashboard shows a comparison of the estimated cost of the project to the forecasted overall cost of the project at completion.

The data comparison helps you determine if the project can generate the anticipated profit after the project ends.

The following screenshot shows the Budget vs. EAC by WBS portlet with the budget lines and the corresponding budget, EAC, and variance values:

![Project360BudgetvsEAC](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Projects/Project360DashboardBudgetvsEAC.png)

The following information describes the columns shown in the portlet:

-   **Budget Line** - This column shows the name of the main budget lines you create using the work breakdown structure. Sublines are not shown on the portlet.
    
-   **Baseline Budget** - This column shows the budget amount for the corresponding budget line.
    
-   **EAC** - This column shows the estimated cost at completion for the corresponding budget line.
    
-   **Variance** - This column shows the difference between the budgeted cost and the EAC cost for the corresponding budget line.
    
    Negative variance values are shown in red text color and follows the negative format display settings in your Set Preferences page.
