The Budget and Estimate at Completion (EAC) page helps project managers monitor the estimated cost for completing each project task, and ensures that the spending does not exceed the budget.

To set up the Budget and EAC portlets, see [Budget and EAC Portlets Set Up](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_164406915678.html).

The system sources the data from the **Budget** subtab of the project record and various transactions for the project to populate the content of the following portlets:

-   [Budget Portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164172047267.html)
    
-   [Budget vs. Actuals by WBS Portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164172041094.html)
    
-   [Budget vs. EAC by WBS Portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164510066800.html)
    

The Budget and Budget vs. Actuals by WBS portlets also use the project profitability standard configuration. If you modify the standard configuration, the values in the Profitability Report may vary from the values shown in the Budget and Budget vs. Actuals by WBS portlets. [Project Profitability Standard Configuration](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164172068374.html#subsect_165214913667).

Note:

When the Default Project Cost Variance Account is not set, unposted time will not be retrieved as Actuals.

For more information about project budgeting, see [Advanced Project Budgeting](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156266908909.html).
