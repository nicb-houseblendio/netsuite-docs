The error messages in the SuiteApp are caused by missing permissions for the role, or features that you must enable to view or access the data.

-   To enable features, see [Enabling Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N232138.html).
    
-   To assign permissions, see [Assigning Roles to an Employee](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N897798.html) and [Customizing or Creating NetSuite Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N285937.html).
    

| Location | Error Message | Cause | Resolution |
| --- | --- | --- | --- |
| Project 360 Dashboard Preference page | A Project 360 Dashboard Preference record is required in this account. | This is a message shown in the SuiteApp when the user tries to delete a Project 360 Dashboard Preference record. | You must keep one Project 360 Dashboard Preference record in your account. |
| There must be only one Project 360 Dashboard Preference record in this account. | This is a message shown in the SuiteApp when the user attempts to create a new Project 360 Dashboard Preference record instance. | You should not create a new Project 360 Dashboard Preference record. Each account requires only one copy of that record for the SuiteApp to work. |
| The Project 360 Dashboard Preference record cannot be set to inactive. | This is a message shown in the SuiteApp when the user attempts to set the Project 360 Dashboard Preference record instance to inactive. | You should always keep the Project 360 Dashboard Preference record active. The system will not let you set the record to inactive as the SuiteApp requires one active Project 360 Dashboard Preference record for an account. |
| My Project Portfolio | A required permission to view this page is missing. Contact your Administrator or refer to the help topic Error Messages in Project 360 Dashboard SuiteApp. | This error message can mean one of the following:
-   Both **Project Resource** and **Project Manager** boxes in your employee record are cleared.
-   The Project Classification SuiteApp is not installed. The **Departments** feature is not enabled.

 | Ensure that the following requirements are met:

-   Check the **Project Resource** and **Project Manager** boxes. Install the Project Classification SuiteApp
-   Enable the **Departments** feature.

 |
| The Project Manager box in your employee record must be checked. | This is a message shown in the SuiteApp when the user tries to access a project. The **Project Manager** box in the user's employee record is cleared. | Update the employee record and check the **Project Manager** box. See [Assigning a Project Manager to a Project](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_164129479872.html). |
| A Project 360 access level must be assigned on your employee record to access this page. | This is a message shown in the SuiteApp when you try to access Project 360 Portfolio Dashboard but the Project 360 access level in your employee record is blank. | An Administrator must assign a different access level to your employee record. See [Access Levels for Project 360 Dashboard](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0427123552.html). |
| Take Action | You need the Project Budget permission to access the **Budget** subtab. Please contact your account administrator. | This is a banner message shown on the page when the user does not have enough **Budget** permission and clicks the Manage Budget link in the Take Action portlet. | Add the **Budget** permission to the role. |
| Project Record | You need the **Charge Rule** permission to access the **Charges** subtab. Please contact your account administrator. | This is a banner message shown when the user does not have enough permission and clicks the Manage Project Billing link in the Take Action portlet. | Add the **Charge Rule** permission to the role. |
| Gantt Chart | A Gantt chart requires one or more tasks. | This is a message displayed in the Gantt Chart portlet when the project has no task to associate to a Gantt chart. | Create a milestone task or a project task. See the help topics [Creating a Project Task Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1194983.html) and [Creating Milestone Tasks](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3740066806.html). |
| Timesheet Tracking | You must enable the Weekly Timesheet feature to view the data. | This is a message displayed in the Timesheet Tracking portlet when the user tries to view the data on the portlet but the **Weekly Timesheet** feature is not enabled. | Enable the **Weekly Timesheet** feature. See [Enabling Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N232138.html). |
| Resource Allocation Chart/Grid | You must install the Resource Allocation Chart/Grid SuiteApp in your account to display the data on the portlet. | This is a message displayed in the Resource Allocation Chart/Grid (RACG) portlet when the Resource Allocation Chart/Grid SuiteApp 2.0 is not installed. | Install the Resource Allocation Chart/Grid SuiteApp. See [Installing the Resource Allocation Chart/Grid SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3746921235.html#bridgehead_1503020222). |
| You must enable the Resource Allocations feature and install the Resource Allocation Chart/Grid SuiteApp to access the data. | This is a message displayed in the RACG portlet when the **Resource Allocations** feature is not enabled. | Enable the **Resource Allocations** feature. See [Enabling Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N232138.html). |
| You do not have privileges to view this page. | This is a message displayed in the RACG portlet when your user role does not have enough privileges to view the Resource Allocation Chart/Grid. | Only administrators and resource managers can access the Resource Allocation Chart/Grid by default. For other roles, you must grant additional permissions. For more information, see [Roles and Permissions for Resource Allocation Chart/Grid](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3746921235.html#bridgehead_1503020461). |
| Budget vs. Actuals by WBS | A project budget does not exist. Please use the work breakdown structure to create a budget. | This is a message shown in the Budget vs. Actuals by WBS portlet when the there are no data to display for the project. No data can mean a project budget is not created, or there are no Actuals transactions associated to the project. | Create a project budget using the work breakdown structure. See [Creating a Budget from a Work Breakdown Structure](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_157830326096.html). |
| Budget and Budget vs. EAC by WBS | A project budget does not exist. Please use the work breakdown structure to create a budget. | This is a message shown in the Budget portlet when there are no data to display for the project. No data can mean there's no project budget associated to the project, or there are no Actuals transactions associated to the project. | Create a project budget using the work breakdown structure. See [Creating a Budget from a Work Breakdown Structure](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_157830326096.html). |
| Profitability Report | You do not have enough permissions to view this portlet. Please contact your account administrator. | This is a message shown when the user does not have permission to view the project record due to subsidiary restrictions or other access restrictions. | Contact your account administrator to check if you have sufficient permissions for your role. |
| You do not have the Projects permission to view this portlet. Please contact your account administrator. | This is an error message displayed in the Profitability Report portlet when the user does not have the Projects permission. | Contact your account administrator to check if you have sufficient permissions for your role. |
| You do not have the Project Profitability permission to view this portlet. Please contact your account administrator. | This is an error message displayed in the Profitability Report portlet when the user does not have the Project Profitability permission. | Contact your account administrator to check if you have sufficient permissions for your role. |
| Web page | Invalid URL. Enter the correct URL and try again. | This is a message shown on the web page when the URL has one of the following issues:

-   The project internal ID is not provided
-   The project internal ID is not in the proper format
-   The project internal ID is zero Note: Project internal ID is different from the Project ID shown in the Project Information portlet.

 | Go to the Projects list page and click the project record you want to open. When you copy paste then modify the project record URL to a different address bar, make sure the project internal ID follows the correct format. |
| Project 360 Dashboard portlets | Internal error occurred. If the problem persists, contact NetSuite Technical Support. | This is a message shown on a portlet when there is an internal error in the system. | Contact the NetSuite Technical Support for assistance. |
