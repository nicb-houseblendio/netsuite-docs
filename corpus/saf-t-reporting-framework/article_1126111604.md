SAF-T Reporting Framework provides a base for generating SAF-T reports in version 2.0. It works together with country-specific localization SuiteApps that build onto the framework to generate reports that are compliant in their respective countries.

The key benefits of the SAF-T Reporting Framework SuiteApp include:

-   Provision of the default structure and data for common sections of SAF-T version 2.0 reports, thus enabling the report generation process.
    
-   Provision of extensibility and modification of the generated default data
    
-   Configuration of the generated SAF-T report
    
-   Compliance with the current requirements for computer-generated SAF-T files in version 2.0 as defined by the OECD
    

Note:

The features of the SAF-T Reporting Framework SuiteApp work only with NetSuite OneWorld accounts without SuiteTax. That means that the SuiteTax feature is disabled in your NetSuite account.
