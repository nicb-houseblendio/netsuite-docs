Before you install the SAF-T Reporting Framework SuiteApp, you must do the following:

1.  Enable Server SuiteScript on the **SuiteCloud** subtab at _Setup > Company > Setup Tasks > Enable Features_.
    
2.  Install the following required SuiteApps:
    
    Important:
    
    If you don't install the SuiteApps listed, the SAF-T Reporting Framework SuiteApp can't be installed or won't work.
    
    | SuiteApp | ID | Installation Procedure |
    | --- | --- | --- |
    | Tax Reporting Framework SuiteApp | Bundle ID: 237699 | See [Installing Tax Reporting Framework](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1528245293.html). |
    | EMEA Localization SuiteApp | Bundle ID: 303903 | See [Installing the EMEA Localization SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157201390489.html). |
    

## Optional Prerequisites for Using the SAF-T Reporting Framework SuiteApp {#subsect_1127094056}

The following prerequisite is optional. This means that you can install and use the SAF-T Reporting Framework SuiteApp without any problems even without this prerequisite in your account:

| SuiteApp | ID | Enablement Procedure |
| --- | --- | --- |
| Advanced Localization Features SuiteApp | Bundle ID: 359132 | See [Installing the Advanced Localization Features SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160691065745.html). |
