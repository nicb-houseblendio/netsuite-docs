The SAF-T Reporting Framework SuiteApp is available through the SuiteApp Marketplace.

#### To install the SAF-T Reporting Framework SuiteApp:

1.  Go to SuiteApps.
    
2.  In the search bar, enter **SAF-T Reporting Framework**.
    
3.  Click the SAF-T Reporting Framework image.
    
4.  Click **Install**.
    
5.  Read the information about the alert, and click **Install** if you want to proceed, or **Cancel** if you don't want to install the SuiteApp.
