The SAF-T Reporting Framework SuiteApp doesn't support the following:

-   NetSuite accounts where the SuiteTax feature is enabled
    
-   Non-OneWorld NetSuite accounts
    
-   NetSuite accounts where the Withholding Tax SuiteApp is installed. Its method of applying discount items on transaction lines isn't compatible with the report generation process provided by the SAF-T Reporting SuiteApp.
    
-   NetSuite accounts where the Multiple Calendars feature is enabled
    
-   NetSuite accounts where the Period End Journal Entries feature is enabled
    
-   NetSuite accounts where the Projects feature is enabled
    
-   Usage of Currency Revaluation
    
-   Usage of Cost of Goods Sold (COGS)
    
-   Line breaks in memo and transaction fields
    
-   New line characters and multiple lines in any of the source fields used to generate the report. This includes, in particular, the Description and Memo fields of transactions and transaction lines, as well as system-generated journal entries with multiple lines. Multiple lines must be removed from all fields before report generation; otherwise, the process will fail.
    

Important:

If you have the SAF-T Reporting Framework SuiteApp installed with these conditions, the provided features won't work.
