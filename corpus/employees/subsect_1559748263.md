Based on the employee permissions assigned to the role, users see different results when viewing the same employee saved search. Some columns in the search results are hidden, depending on what the role has access to. When the filter criteria of a saved search uses a field unavailable to the employee permissions assigned to the role, the filter is not applied.

The following examples outline what information is exposed to a role when a saved search is run using the same filter criteria. The examples use different Advanced Employee Permissions.

## Example 1 - Saved Search Results with Employee Public Permission {#subsect_156961834691}

| Advanced Employee Permissions | Filter Criteria | Reference |
| --- | --- | --- |
| Employee Public | Location - Toronto Base Wage - Greater than $100,000 | [Employee Public Permission Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1494596636.html) |

When a role using this permission runs the saved search, the results filter by Location because this permission doesn't have access to Base Wage.

![Screenshot of a saved search filtered by location.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/EmployeeManagement/Employees/SearchResultsEmployeePublic.png)

### Example 2 - Saved Search Results with Employee Administration Permission {#subsect_156961832345}

| Advanced Employee Permissions | Filter Criteria | Reference |
| --- | --- | --- |
| Employee Administration | Location - Toronto Base Wage - Greater than $100,000 | [Employee Administration Permission Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1494597540.html) |

When a role using this permission runs the same saved search different results are shown. Only the employees located in Toronto and who have a base wage greater than $100,000.00 are shown in the saved search results. In the image below, you can see that four employees meet this search criteria.

![Screenshot of a saved search filtered by location and base wage.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/EmployeeManagement/Employees/SearchResultsAdmin.png)
