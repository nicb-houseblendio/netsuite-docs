Important:

Linking work agreements is an add-on feature to Workforce Management (WFM). If you want to implement the feature in your setup, contact NetSuite Customer Support.

Cross-agreement linking allows employees to be paid against separate wage agreements at different WFM locations.

Refer to the following example:

-   **Location 1** - All employees are paid under the Retail Industry Award for all hours worked.
    
-   **Location 2** - Some employees are paid under the Warehouse Award for all hours worked.
    

Cross-agreement linking allows you to set up the Warehouse Award to be paid for the hours worked of selected employees at Location 2.

Before you can link work agreements across different locations for each employee, you should first finish setting up the wage agreements and creating groups.

For more information, see [Creating a Wage Agreement](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0909023117.html).

#### To link work agreements:

1.  Open the wage agreement. See [Accessing Wage Agreements](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0807100528.html#subsect_0903110736).
    
2.  Click the **Locations** subtab.
    
    A list of locations that use the wage agreement to calculate shifts appears.
    
3.  Click **\+ Add locations…**.
    
4.  On the Add locations window, complete the required information.
    
    -   **Groups** - If you have set up category groups, from the Available Choices panel, select the groups that should use the agreement to calculate wages.
        
    -   **Locations** - From the Available Choices panel, select the groups that should use the agreement to calculate wages.
        
5.  Click **\+ Add locations**.
    

## Assigning Employee Classification for Cross-Agreement Linking {#section_0909032322}

After linking work agreements, you can assign employees to the relevant level they will be paid at locations set for cross-agreement linking.

#### To assign employee classification for cross-agreement linking:

1.  Go to Workforce Management.
    
2.  Go to Setup > Employees > List.
    
3.  Click the name of the employee.
    
4.  On the employee profile, on the left-hand panel, click **Wages**.
    
5.  On the Wages page, click **Edit wage**.
    
6.  On the Edit wage window, expand the Advanced section.
    
    If you do not complete the fields in this section, the employee will be paid their default cost calculation type.
    
7.  Select any wage agreements and classifications that apply to the employee when they work on a location with cross-agreement linking.
    
8.  Click **Save**.
