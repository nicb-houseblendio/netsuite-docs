Important:

The ADP (Canada) integration is available only to accounts where it is already provisioned. It is not included with the current SuitePeople WFM solution.

With Workforce Management (WFM), you can export employee start and stop time to a file compatible with ADP (Canada). This file lets you export the approved actual hours that employees worked by day and let ADP (Canada) calculate pay for specific state and local holidays that may apply.

Note:

Leaves must be added in both ADP (Canada) and WFM). This data is not currently exported to ADP (Canada) using the start and stop export format.

## Creating an ADP (Canada) Configuration {#subsect_0801051422}

Follow the steps in the procedure.

#### To create a new ADP (Canada) configuration:

1.  Go to Workforce Management > Setup > Integrations.
    
2.  From the **Payroll systems** list, select **ADP (Canada)**.
    
3.  On the ADP (Canada) configurations page, click **\+ Create new**.
    
4.  On the Create new ADP (Canada) Payroll configuration page, complete the fields.
    
    -   **Company code** - Enter the two or three alphanumeric characters representing your company. ADP provides this code. You may also enter a dash (-) or ampersand (&).
        
    -   **Report format** - Select the format for the ADP report.
        
        -   **Export by Earnings Code** - This option will send over total hours worked for the pay period.
            
        -   **Export by Start/Stop Times** - This export will include the start and stops times by date, with total worked hours by date to ADP. This will allow for the payroll system, ADP, to account for any state and local holidays to be accounted for when processing payroll.
            
    -   **Start/Stop times export options** - Set optional fields for exporting start and stop times.
        
        -   **Department map** - Select how you want to allocate approved hours in WFM to ADP departments. You can choose between **Location** and **Job**.
            
            If you do not select an option, work hours will be allocated to the home department in ADP.
            
            If you link WFM locations to ADP departments, you can ensure that employees who may work at various locations are allocated to the correct departments for payment.
            
        -   **Job map** - Select how you want to map WFM jobs to ADP jobs. You can choose between **Location** and **Job**. This map benefits is useful when you need to track pay to jobs.
            
5.  Click **+Create**.
    

After you have created your configuration, you can link the following data from WFM to ADP (Canada):

-   employees
    
-   locations, available if you chose to link WFM locations to ADP departments
    
-   jobs, available if you chose to link WFM jobs to ADP jobs
