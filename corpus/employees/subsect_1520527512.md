You can edit a time-off type at any time. If you're making changes that affect accruals for many employees, do it at the end of the business day so NetSuite has time to process them. Try not to make changes that affect accruals on the same accrual day.

#### To edit a time-off type:

1.  Go to _Setup > HR Information System > Time-Off Type_.
    
2.  Click **Edit** next to the time-off type you want to change.
    
3.  When you're done editing, click **Save**.
