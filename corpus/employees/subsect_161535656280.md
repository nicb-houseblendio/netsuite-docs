You can set a time-off type to be automatically approved when requested, with to an approval threshold.

You can make certain employees self-approvers so their time-off requests are automatically approved. This is helpful for executives, like the Chief Product Officer, whose time off you still want to track.

#### To set up a time-off type for auto-approval with threshold:

1.  Go to _Setup > HR Information System > Time-Off Type_.
    
2.  Click **Edit** next to the time-off type you want to change.
    
3.  Check the **Auto-Approve with Threshold** box.
    
4.  In the **Auto-Approval Threshold** field, enter the maximum period of time that can be automatically approved. Requests over this limit will require supervisor approval. The value uses the unit from the **Increment Unit** field. The minimum value is **1**, and there is no maximum. You can enter a value such as 200 to allow for almost unlimited time-off auto-approvals.
    
    For example, if you set the threshold to 5 days, requests of up to 5 consecutive days will be automatically approved. Requests over 5 days will require supervisor approval. For more information, see _Guidelines for Time-Off Auto-Approvals_.
    
5.  Click **Save**.
    

The following guidelines describe how time-off type auto-approvals work with other time-off types in the same request:

-   If a request includes both auto-approved and non-auto-approved types, it needs supervisor approval.
    
-   If a request has multiple auto-approved types, it might still need supervisor approval depending on each threshold. The total time is checked against the highest threshold in the request.
    
    The following table summarizes different scenarios when submitting multiple auto-approved time-off types in the same request.
    
    | Time-Off Type Submitted | Total Duration of Time-Off Request | Requires Supervisor Approval? |
    | --- | --- | --- |
    | A | B |
    | --- | --- |
    | Within threshold | Within threshold | Within highest threshold value | No |
    | Within threshold | Within threshold | Exceeds highest threshold value | Yes |
    | Within threshold | Exceeds threshold | Within highest threshold value | Yes |
    | Within threshold | Exceeds threshold | Exceeds highest threshold value | Yes |
    | Exceeds threshold | Exceeds threshold | Exceeds highest threshold value | Yes |
    
-   To avoid issues, let users know they should submit auto-approved time-off requests separately from others.
    

#### To assign an employee as a time-off self-approver:

1.  Go to _List > Employees > Employees_.
    
2.  On the Employees list, click **Edit** next to the employee you want to set up as a time-off self-approver.
    
3.  Click the **Time-Off** subtab.
    
4.  Check the **Time-Off Self-Approver** box.
    
5.  Click **Save**.
    

If your account has Advanced Employee Permissions enabled, make sure you add **Time-Off Self Approver** as a custom field in your custom employee permissions. For more information, see [Adding Custom Fields to Advanced Employee Permission](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_156166658151.html).
