Quickly create new schedules by copy & pasting previous shifts and schedules.

Copying shifts and schedules will copy:

-   Shifts
    
-   Shift Breaks
    
-   Employees associated with the shifts
    
-   Jobs on each shift
    

After being copied, you can still add & remove shifts, change shift length, and reassign employees to different shifts.

This is intended as a quick way to create a schedule by copying an optimized schedule and optimizing it further for the week it's copied to.

There is a copy dialogue available on both **Daily** and **Weekly** views.

Hovering over the **Copy** button provides the following quick actions:

-   Copy to next week
    
-   Copy to 2 weeks away
    
-   Advanced week copy
    
-   Advanced day copy
    

The first choice will be to copy specific days from one week to another week.

Select the days in your base week that you want to copy, and then select the week that you want to paste them onto.

For multiple weeks select the "Paste Repeating" option, and then how many times you want for the week to repeat itself.

OR you can copy a single day to another day, select the day you want to copy, and then the day(s) that you want to paste the day onto.

Tip:

When pasting day shifts, all the shown days are from the following week, always double check the date when copying and pasting shifts.

When you're happy with what you've created, select the "Copy" button to save all changes.

If you've overlapped shifts, you'll be given a warning for every shift that is in danger, to confirm the changes select "Remove all of these changes" and then "Copy" again.
