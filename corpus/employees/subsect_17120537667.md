To keep things running smoothly with WFM, update to the latest SuitePeople Time Clock version as soon as you can. Updates are designed to address security and compliance considerations and improve overall performance.

Important:

After you update SuitePeople Time Clock for Windows, you can no longer revert it to the previous version.

#### To update SuitePeople Time Clock for Windows:

1.  Install the update.
    
    -   If you've set up the app to automatically check for updates, you'll see a notification that a new version is available. On the notification window, click **Install update**.
        
    -   If you haven't set up automatic checks for updates or if you haven't seen the notification, manually check for updates in SuitePeople Time Clock. You will need an account with higher permissions than an employee. See [Manually Updating SuitePeople Time Clock for Windows](#subsect_84121008485).
        
2.  Restart the app.
    

After you've updated and restarted SuitePeople Time Clock, you'll see the new version number at the bottom of the keypad screen.

For more information about troubleshooting issues, see [Troubleshooting SuitePeople Time Clock for Windows](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_0920125540.html).

## Manually Updating SuitePeople Time Clock for Windows {#subsect_84121008485}

If you have access to an account with higher permissions than an employee, you can check for updates in SuitePeople Time Clock for Windows. For more information about the different access groups available in WFM, see [Employee Access in WFM](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1102035209.html).

#### To manually update SuitePeople Time Clock for Windows:

1.  Open SuitePeople Time Clock on your device.
    
2.  Enter your PIN code.
    
3.  On the lower left corner of the screen, click the settings icon.
    
4.  From the list, select **Check for update**.
    
    -   If an update is available, click **Install update**. After the update, restart the app.
        
    -   If SuitePeople Time Clock is up to date, a window appears confirming that you're using the newest available version.
