Note:

Currently, the Time-Off Tracking SuiteApp supports only US and UK English languages.

## Install the Time-Off Tracking SuiteApp {#subsect_1519931424}

Important:

To install the Time-Off Tracking SuiteApp, you need to have Time-Off Management enabled. Go to Setup > Company > Enable Features. On the Employees subtab, under HR Information System, check the Time-Off Management box. If you don't see this feature on the Enable Features page, you need SuitePeople HR on your account. For more information, see [SuitePeople Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1495573671.html).

With the Time-Off Tracking SuiteApp, employees can request time off using their Employee Center role. Requests go to their supervisor for approval, and the SuiteApp includes saved searches you can use as reports. For more information, see [Time-Off Tracking Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1494947371.html).

For more information about installing SuiteApps, see [Installing a Bundle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3395142.html). You can search for the Time-Off Tracking Suite App using the following information:

-   Bundle Name: **Time-Off Tracking**
    
-   Bundle ID: 112449
    

The Time-Off Tracking SuiteApp is a managed bundle that updates automatically whenever fixes and enhancements are available.

Note:

The Time-Off Tracking SuiteApp uses the time-off request record. Custom fields on the time-off request record don't appear when employees create time-off requests. If you add custom fields to the time-off request record, make sure they aren't required, or set default values if they are.

## Assign Work Calendars to Employees {#section_1494523928}

When you use the Time-Off Management feature, you'll need to assign a work calendar to each employee. This way, NetSuite knows which days are working days and can calculate how many hours to deduct for each time-off request. For more information, see [Setting Up a Work Calendar](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1190013.html) and [Assigning a Time-Off Plan to an Employee](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1494510785.html).

## Time-Off Management Roles and Permissions Requirements {#subsect_1519931445}

You'll need the Time-Off Administration and Time-Off permissions to set up Time-Off Management. Standard roles with these permissions are HR Generalist, Administrator, and Chief People Officer (CPO). For details, see [Time-Off Management Permission Requirements](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1548186571.html).

You can also create custom roles with these permissions. For more information, see [Customizing or Creating NetSuite Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N285937.html).

If your role has the right permissions, you can review, approve, or reject time-off requests before employees take time off.

Employees assigned a time-off plan need access to the Employee Center role and Time-Off permission so they can submit time-off requests and view their time-off balances.

Managers can review requests from an email or from the Employee Center.
