Before you can set up the Time-Off Management feature with SuitePeople U.S. Payroll, the following must be completed:

-   SuitePeople U.S. Payroll needs to be set up in your NetSuite account. If it isn't contact NetSuite Customer Support. For more information, see [Payroll Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N917379.html).
    
-   You need to turn on the Time Tracking feature in your account. For more information, see [Managing Time Tracking](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N901953.html).
    
-   You need to turn on the Time-Off Management feature.
    
    Important:
    
    Be prepared to set up the Time-Off Management feature as soon as you enable it so that accruals in Payroll can be calculated correctly.
    
-   Work calendars need to be assigned to your employees. For more information see [Assign Work Calendars to Employees](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4816450696.html#section_1494523928).
