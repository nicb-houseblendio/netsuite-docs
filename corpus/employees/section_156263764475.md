## Adding the Workforce Demographics Portlet {#subsect_156264710515}

The Workforce Demographics portlet is a custom portlet that you can add to your dashboard.

#### To add the Workforce Demographics Portlet:

1.  Log in as an Administrator.
    
2.  Go to Home
    
3.  Choose from the following:
    
    -   On the upper right corner, click **Personalize**.
        
    -   On the Settings portlet, click **Personalize Dashboard**.
        
4.  Click **Standard Content**.
    
5.  Click or drag the **Custom Portlet**.
    
6.  On the Custom Content portlet menu, click **Set Up**.
    
7.  In the **Source** field, select **Workforce Demographics**.
    
8.  Click **Save**.
    

To start using the portlet, see [Viewing the Workforce Demographics Portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156263779386.html).

## Setting Up Human Resources KPIs on a Scorecard {#subsect_156264712916}

The Human Resources KPI configuration is a set of metrics that you can set to display on a KPI Scorecard portlet.

#### To set up human resources KPIs on a scorecard:

1.  Log in as an Administrator.
    
2.  Go to Home.
    
3.  Choose from the following:
    
    -   On the upper right corner, click **Personalize**.
        
    -   On the Settings portlet, click **Personalize Dashboard**.
        
4.  Click **Standard Content**.
    
5.  Click or drag the **KPI Scorecard**.
    
6.  On the KPI Scorecard portlet menu, click **Set Up**.
    
7.  In the **KPI Scorecard** field, select **Human Resources KPI**.
    
8.  Click **Save**.
    

To start using the portlet, see [Viewing Human Resources KPIs on a Scorecard](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156263780277.html).

## Adding Data from HR Saved Searches to Portlets {#subsect_156264713892}

You can set up the saved searches included with HR Dashboard Components to show data on specific portlets.

#### To add data from HR Saved Searches to portlets:

1.  Log in as an Administrator.
    
2.  Go to Home.
    
3.  Choose the portlet you want to set up, based on the saved search data you want to show.
    
    | Saved Search | Portlet |
    | --- | --- |
    | Expiring Work Visas | Reminders |
    | Expiring Passports | Reminders |
    | Expiring Driver's License | Reminders |
    | Diversity Report | Custom Search Important: The SuitePeople | Remediate Customize Rel SuiteApp (Bundle ID: 219023) includes a remediate dashboard. If you use this dashboard and Dashboard Tiles to display the Diversity Report metric, note the following. You must set up the tile with the Diversity Report saved search from HR Dashboard Components. For more information, see [Viewing HR Dashboard Components Saved Searches](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156263781270.html). |
    
4.  If the portlets are not available on the dashboard yet, choose from the following:
    
    -   On the upper right corner, click **Personalize**.
        
    -   On the Settings portlet, click **Personalize Dashboard**.
        
5.  Click **Standard Content**.
    
6.  Click or drag **Reminders** or **Custom Search**.
    
7.  On the portlet menu, click **Set Up**.
    
8.  On the portlet window, select or click the saved search.
    
    | Portlet | Action |
    | --- | --- |
    | Reminders | Click or drag the saved search |
    | Custom Search | Select the saved search in the **Search** field |
    
9.  Click **Save**.
    

For more information about displaying searches, see [Displaying Saved Search Results in Dashboard Portlets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N690632.html).

For more information about setting up reminders, see [Setting Up Reminders](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N581945.html).

To view the saved searches installed with the SuiteApp, see [Viewing HR Dashboard Components Saved Searches](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156263781270.html).
