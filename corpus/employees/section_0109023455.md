## Dynamic Extra Hours {#subsect_85123813593}

You can set up dynamic extra hours at a brand level and change them for a specific location if needed.

Name the extra hours, assign them to a team, and pick which days they apply to.

You can apply the extra hours to a fixed or relative period.

If there's a day part set up at the brand level, select it. Otherwise, you can only select **Full day**.

The next two options let you set how many extra hours you want to add, based on the selected period:

Underneath the **relative to** list, there are two rows with three options:

-   How many hours (time wise)
    
-   Select either "at", "before", or "after"
    
-   "Start of period" or "Finish of period
    

This field lets you pick how many extra hours you need before or after the start or end of the period.

For example, if I need employees to open the store each day, I can set the options like this:

-   **Relative to** - Full day period (open -> close)
    
-   **Between** - 2 hours before the start of the full day period (open time)
    
-   And at 0 hours at the start of full day period (open time)
    

So this means it'll suggest two extra hours before my open time, right up until opening..

**Employee count**

This setting applies X number of employees for the whole period.

It'll be added to the +1/-1 15-minute data.

**Fixed hours**

Fixed hours add X hours to the period you set earlier.

Prefer hours means suggested shifts will use these hours first.

For example, if you need 3 hours of setup in the two hours before open, you can set the times as above. Then, enter **3** as fixed hours and set prefer hours to finish the period.

**Demand-based hours**

Demand-based hours are calculated from stats and assigned like fixed hours.

In the daily view, the first line shows sales-driven deployment with employee count.

The second line shows dynamic extra hours. You can use 2.5 hours before open, 7 hours during open hours, and 2 hours after close.

It's up to the scheduler how to use the extra hours. They must stay within the period.

## Opening hours {#subsect_9123935140}

Under Setup > Brands, select a brand. Click **Details**.

To set opening hours for all locations, select **Hours**.

To override the shared opening hours from the brand, go to Setup > Locations. Select a location and click Scheduling > Opening hours.

Opening hours are only used for deployment in these cases:

-   Extra hours
    
-   Sales based deployment will be restricted to opening hours
