As a people manager, you can use Workforce Management (WFM) to manage staff schedules, keep labor on target, and handle staff communications.

When you first log in, you'll see a list of employees.

To help you create and manage employee schedules, see the following topics:

## Reviewing Employee Jobs and Availability {#subsect_97100439449}

The employee list shows everyone available to work at your locations.

Click an employee to see their profile.

In the employee profile, check out the **Jobs** and **Availability** tabs.

-   **Jobs**\- See which jobs the employee can work. If there aren't any listed, you can add a new job. When you create shifts, you might want to add certain roles, like a Supervisor shift. Any jobs available at the employee's locations will show up here.
    
    For more information, see [Jobs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1103102845.html)
    
-   **Availability** - When you make new schedules, employees will show up as available or not. To learn more, see [WFM Employee Availability](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0110105441.html).
    
    If you let employees log in, they can set their availability and you'll get notified about any requests. To receive availability requests or to make changes to employee availability, read [Approvals](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0819100006.html#subsect_65131501428).
    

If you're missing employees from the list, you can add them. For more information, see [Adding New WFM Employees](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0110104041.html).

## Managing Shifts {#subsect_97101210274}

In WFM, go to the **Shifts** menu to manage shifts.

See the following options:

-   **Daily** - Lets you schedule and publish shifts. For more information, see [Scheduling in Workforce Management - Daily](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0922045240.html).
    
-   **Weekly** - Lets you review and approve shifts, including exceptions. For more information, see [Weekly](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0926120210.html).
    
-   **Multi-Location** - Like the weekly options but lets you view shifts across all the locations you manage. For more information, see [Multi-location](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0927104836.html).
    
-   **Forecasting** - Lets you add and adjust sales projections to help plan future schedules. For more information, see [Forecasting](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0927105512.html).

## Duplicating and Optimizing Schedules {#subsect_38102904762}

## Reviewing Time and Attendance and Approving Exceptions {#subsect_39103033587}

Every day, you'll want to check Shifts > Weekly to review the day's shifts.

If you've set up time and attendance, times will show up under each employee's scheduled shifts. If not, you can still approve and make changes to shifts.

You can add extra shifts or approve time and attendance with notes.

For more information, see [Weekly](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0926120210.html), [Updating hours worked](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0926120210.html#subsect_65100043651) and [Approving Shifts with Automatch](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0927101719.html).

Here is video showing how to approve time:

[Approval of hours worked](https://videohub.oracle.com/media/Approving%20Time/1_4zw7jxx8)

## Short Videos: Phone App, Fill-ins, Swapping, Dropping and Approving Shifts {#subsect_68163339501}

The following videos demonstrate some other tasks you can do in Workforce Management.

### Phone App Navigation {#subsect_21163653264}

Get to know the WFM Phone App, where you can view your shifts, trades, and notifications.

For more information, see [SuitePeople Workforce Management Phone App](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_4125948041.html).

### Swapping Shifts {#subsect_68163700245}

Employees can swap shifts if the manager approves.

If enabled in your account, learn how employees can swap shifts with one another. See the workflow from employee to manager, ending in the manager reviewing the potential cost differences and approving the swap.

[Swap Shift](https://videohub.oracle.com/media/Swap%20Shift/1_fupz1c0v)

A manager can deny the swap request. The employee gets notified and can try to pick up a different shift, which sends a new approval request to the manager.

[Deny Swap](https://videohub.oracle.com/media/t/1_tgltrh6l)

### Fill Shift {#subsect_25163705433}

If an employee can't make their shift or doesn't show up, use WFM or the Phone App to quickly find a fill-in. The manager can start a fill shift and consider cost differences to make the best decision.

[Find a shift Fill-in](https://videohub.oracle.com/media/t/1_kyewfqij)

For more information, see [Filling Shifts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1019103205.html).

### Drop Shift {#subsect_63163710660}

An employee can start a drop request, and another employee can pick up the shift if the manager approves.

If it's enabled, employees can start a drop request from the Phone App if they can't make their shift.

Note:

This video shows Drop Pre-Approval turned on. If you turn it off, employees can drop shifts without manager approval, and the request goes to all available employees. When someone offers to pick up the shift, the manager gets notified to approve or deny. You can change this in Setup > WFM Phone App.

[Drop Shift Approved](https://videohub.oracle.com/media/t/1_fdk4evv9)

The manager can also deny the request.

[Deny Drop](https://player.vimeo.com/video/432999420)

### Approved Shifts {#subsect_96163715716}

If it's enabled, employees can see their approved shifts in the Phone App.

[Approved Shift](https://videohub.oracle.com/media/t/1_h0r9sen2)

You can also let employees confirm or dispute their time. To learn more, read [Attestation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1019104631.html).
