This dataset combines fields from the Time-Off Change and Employee record types so you can assess time-off information for your organization. It forms the source data for the [Time-Off Analysis Workbook](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158228762090.html).

## Dataset Configuration {#subsect_158228776387}

The Time-Off Analysis dataset combines fields from two record types and multiple criteria filters. To edit the dataset, see [Defining a Dataset](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544122173.html).

| Root Record Type | Joined Record Type | Custom Formula Fields | Data Grid | Criteria Filters |
| --- | --- | --- | --- | --- |
| Time-Off Change | Employee | (none) | The following fields are included in the dataset. Time-Off Change:
-   Accrual Rate
-   Amount
-   Date Applied
-   Description
-   Employee
-   Time-Off Change Type
-   Time-Off Type

Employee:

-   Category
-   Include in KPI
-   Name

 | (none) |
