## Managing Settings in SuitePeople Time Clock for Windows {#subsect_31103520781}

In SuitePeople Time Clock for Windows, you can edit various settings to manage how the app functions.

To view the available settings, open SuitePeople Time Clock on your Windows device, then log in to the app. Click the cog or settings icon on the bottom left corner of the screen.

The following table shows the available settings.

| Setting | Description |
| --- | --- |
| Refresh | This option synchronizes data in the Windows device to WFM. |
| Check for updates | This option lets you check for the most recent Time Clock version. |
| Enroll Employee | If you have a fingerprint scanner installed and have the authentication method set to an option that is not PIN only, this option lets you register fingerprints for an employee. |

## Setting the SuitePeople Time Clock for Windows Authentication Method {#subsect_1126024651}

The following table shows the available authentication methods you can update on the Workforce Management SuiteApp or the standalone WFM website.

Important:

To follow the Biometric Information Privacy Act (BIPA), you can't use fingerprint scanning on Windows devices in Illinois. If you're setting up a Windows device there, employees can only punch in with pin codes.

| Setting | Description |
| --- | --- |
| PIN only | This option enables the PIN authentication option. SuitePeople Time Clock needs to restart for this change to take effect. |
| Finger scan only | This option enables the fingerprint authentication options. SuitePeople Time Clock needs to restart for this change to take effect. |
| Pin or finger scan | This option enables either the PIN or finger scan options. |
| Two-factor authentication (PIN then finger scan) | This option enables two factor authentication. This allows users to sign in with both a PIN then finger scanning. |

#### To set the authentication method for SuitePeople Time Clock for Windows:

1.  Log in to Workforce Management.
    
2.  Go to Setup > Time Clock.
    
3.  Click the **Activated Devices** subtab.
    
4.  Click the device name. Click **Edit**.
    
    The wizard appears.
    
5.  On the Options page, from the **Authenticated By** field, select the authentication method. Click **Next**.
    
6.  On the Confirmation page, review the changes. Click **Update**.
    

## Enabling Two-Factor Authentication in SuitePeople Time Clock for Windows {#subsect_31105520299}

SuitePeople Time Clock for Windows offers two-factor authentication for when employees clock in and out. Two-factor authentication includes a fingerprint option and a PIN option for the user to verify their identity.

Important:

To follow the Biometric Information Privacy Act (BIPA), you can't use fingerprint scanning on Windows devices in Illinois. If you're setting up a Windows device there, employees can only punch in with pin codes.

To view device settings, log in to Workforce Management. Go to Setup > Time Clock. From the **Activated Devices** subtab, click the device name. On the Options page of the wizard, from the **Authenticate by** field, select **PIN only** as the authentication method.

Before you enable this setting, ensure employees have enrolled their fingerprints and set up their PIN codes. For more information, see the following help topics:

-   [Registering Fingerprints for SuitePeople Time Clock](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_32100439583.html)
    
-   [Setting up Employee PIN Codes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1013044154.html#subsect_96164608856)
    

#### To manage Time Clock settings on WFM SuiteApp or stand-alone website:

1.  Log in to Workforce Management.
    
2.  Go to Setup > Time Clock.
    
3.  Click the **Activated Devices** subtab.
    
4.  Click the device name. Click **Edit**.
    
    The wizard appears.
    
5.  On the Options page, from the **Authenticated By** field, select **Two-factor authentication (PIN then finger scan)**. Click **Next**.
    
6.  On the Confirmation page, review the changes. Click **Update**.
