The Time-Off Changes page displays a list view of all the time-off change records for the employees at your company. Time-off change records are created when time-off requests are approved, when you make manual adjustments, when carryover is applied, when time off expires, and when automatic accruals are calculated. Each change is recorded separately so you can tell them apart.

#### To view time-off changes:

1.  Go to _Setup > HR Information System > Time-Off Change_.
    
    The Time-Off Change page displays a list of all time-off changes, sorted by most recent changes.
    
2.  To filter the list of time-off changes, expand the **Filters** section and try these options:
    
    -   To find time-off changes for a specific employee, select the employee from the **Employee** list.
        
    -   To view time-off changes by time-off types, select a time-off type in the **Time-Off Type** list. To make multiple selections, hold down the Ctrl key.
        
    -   To view time-off changes by time-off change type, select a time-off change type from the **Time-Off Change Type** list.
        

Note:

When a time-off request for a future date that was previously approved is rejected, the associated time-off change record is deleted.
