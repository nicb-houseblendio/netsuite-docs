A time-off plan includes the types and rules that dictate how each time-off type is applied. The rules set how eligibility, accruals, entitlements, and carryover work for employees, and how these change over time.

Before you create a time-off plan, make sure you've set up and defined time-off types. For more information, see [Creating a Time-Off Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1544819200.html).
