If you're responsible for HR or finance tasks, here are a few steps and best practices to help you set up employees and ensure they get paid properly.

These are:

-   [Creating Employee Records in WFM](#subsect_94094426236)
    
-   [Assigning Employees to Locations](#subsect_22094837868)
    
-   [Setting Correct Wages](#subsect_2095142742)
    
-   [Setting Job Roles](#subsect_62095312172)
    
-   [Setting Availability](#subsect_12095454716)
    
-   [Setting Access Group](#subsect_42095718370)
    

## Creating Employee Records in WFM {#subsect_94094426236}

You can create new employee records in WFM under Setup > Employees > List > New.

When setting up an employee, the required fields are:

-   First name
    
-   Last name
    
-   Primary Location
    

You'll also want to add an email address so they can get their login details and published shifts.

For more information, see [Adding New WFM Employees](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0110104041.html)

## Assigning Employees to Locations {#subsect_22094837868}

To assign a location to an employee, go to Setup > Employees > List. Click the ID next to the employee you want to assign a location to. On the employee profile, click the **Locations** tab.

Ensure the **Primary Location** is correct. Then, check the **Can work at** field if the employee can work at more than one location.

For more information, see [Employment](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0919022953.html).

## Setting Correct Wages {#subsect_2095142742}

To assign a wage to an employee, go to Setup > Employees > List. Click the ID next to the employee you want to set a wage. On the employee profile, click the **Wages** tab.

You'll see one line of wage history showing a $0 hourly rate. This is the default wage set for all employees and needs to be updated.

You can edit this wage to set their correct salary, hourly rate, or wage agreement in WFM.

For more information, see [Managing Wages for WFM Employees](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1102035923.html).

## Setting Job Roles {#subsect_62095312172}

On the employee profile page, click the **Jobs** tab. Click **New job** and select any jobs the employee is eligible. For example, you may have a "Training" job that all new hires are required to be assigned to. Click **Save**.

For more information, see [Jobs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1103102845.html).

## Setting Availability {#subsect_12095454716}

Employees can log in and set their availability.

Or, you can set their availability so they show up as available in the schedules they can work.

For more information, see [WFM Employee Availability](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0110105441.html).

## Setting Access Group {#subsect_42095718370}

You can set the access group during the new employee setup. If it wasn't set, or if the employee was imported or promoted, you can change the access group later.

For more information, see [Employee Access in WFM](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1102035209.html).
