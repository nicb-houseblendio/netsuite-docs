1.  If you already have an approved shift you'd like to change the job, find the shift and then select the blue pencil icon.
    
2.  A message will appear. There will be a drop-down box next to **Job**
    
3.  Within this drop-down box you'll see a list of jobs which this employee is eligible to work, and which are available at the location this shift is scheduled at.
    

Note:

If you make a change to the job you might be required to add an approval note.

Note:

If no jobs appear, or the correct jobs don't appear, either the employee isn't eligible to work that job, or the job isn't available at that location.
