You'll need to update the Employee Directory and Org Browser scripts so they work with the custom roles using the SuiteApp.

| Script ID | Script |
| --- | --- |
| customdeploy\_ed\_emp\_dir\_su | Employee Directory |
| customdeploy\_ed\_emp\_dir\_portlet | Employee Directory Portlet |
| customdeploy\_ed\_emp\_search\_backend\_su | ED Employee Search Backend Su |
| customdeploy\_ob\_org\_browser\_su | Org Browser UI Su |
| customdeploy\_ob\_org\_browser\_backend\_su | Org Browser Backend Su |

#### To update the required scripts for the Employee Directory and Org Browser:

1.  Go to Customization > Scripting > Script Deployments.
    
2.  Locate a required script based on the table on this page and click **Edit**.
    
3.  On the **Audience** subtab, go to the **Roles** field.
    
4.  Pick the internal or external roles that will use the SuiteApp.
    
5.  Click **Save**.
    
6.  Repeat steps 2 to 5 for each script you need to update.
    

## Employee Directory Search Script and Role {#subsect_0708030521}

Employee Directory uses the **Employee Directory Search Service** role when conducting searches about employees and relevant details. This role is automatically selected in the **Execute as Role** field of the **ED Employee Search Backend Su** script, which runs the SuiteApp's search feature.

This role is intended only for this use and can't be used to log in to an account.
