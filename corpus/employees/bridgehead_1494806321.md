Install the Health and Safety SuiteApp:

-   Bundle Name: **Health and Safety**
    
-   Bundle ID: 109485
    

This is a managed bundle, so it's updated automatically. You'll get the latest fixes and improvements as soon as the SuiteApp is updated in your account.

For more information about installing SuiteApps, see [Installing a Bundle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3395142.html).
