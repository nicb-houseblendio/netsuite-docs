After you've installed the SuiteApp, ensure that the **SuitePeople WFM Integration** role is available to the user setting up the integration.

#### To assign the SuitePeople WFM Integration role: {#procedure_0411110915}

1.  As an Administrator, go to List > Employees > Employees.
    
2.  Click **Edit** next to the name of the employee for whom you want to set up access.
    
3.  Click the **Access** tab.
    
4.  On the **Roles** subtab, assign the **SuitePeople WFM Integration** role.
    
    Note:
    
    If you're using Infinet Cloud Payroll, add the **Payroll Administrator-Unlocked** role for ICS. Ensure all subsidiaries are selected.
    
5.  Click **Add**. Click **Save**.
    

## Assigning WFM Permissions to Roles {#subsect_1120034937}

If you need to give WFM SuiteApp access to existing roles, add the required permissions to any roles that aren't the Employee Center Role.

If needed, assign WFM permissions to the following roles:

-   HR - HR Manager
    
-   PRL - Payroll Manager
    

#### To assign WFM permissions to roles:

1.  Go to Setup > Users/Roles > Manage Roles.
    
2.  Next to the role that needs permissions, click **Edit**.
    
3.  On the **Permissions** subtab, click the **Setup** subtab.
    
4.  From the Permissions list, add the following permissions with their corresponding levels.
    
    | Permission | Level |
    | --- | --- |
    | REST Web Services | Full |
    | Log in using OAuth 2.0 Access Tokens | Full |
    
5.  Click **Save**.
    

To continue setting up WFM, see [Deploying User Event Scripts in NetSuite](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1214216333.html).
