For employees, refer to the guidelines in this section to securely use WFM applications.

## Securing WFM Accounts {#subsect_0312122015}

The following are some guidelines to secure WFM accounts:

-   Never share your pin code and password with other employees.
    
-   Punch in to WFM applications using only your own account.
    
-   Always sign out of your WFM account after punching in or out.
    

## Using Time Clock for Windows Securely {#subsect_0312122045}

The following are some considerations for using Time Clock for Windows securely:

-   Keep your pin code or password secure, and don't write them down so others can't get them.
    
    When entering your pin code or password on company premises, make sure no one sees your screen.
    

## Using WFM Mobile Apps Securely {#subsect_0312122139}

The following are some guidelines for using WFM mobile apps securely:

-   If you need visual verification, make sure your face is facing the camera for a clear image.
    
    To avoid other employees hijacking your account, lock your personal device when not in use.
