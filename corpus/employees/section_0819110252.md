When you're setting up or editing shift templates, you can add notes to each shift or select specific employees to show up as available choices.

-   **Comments column** - Adds a comment to the corresponding template shift
    
-   **Staff column** - Shows a selection box of available employees. You can select certain employees to appear for selection for that shift.
    

## Shift Notes {#subsect_66110532742}

Shift notes will show up each week when you add an employee from the template. You can change this each week if needed.

## Employee Selection {#subsect_11110553718}

Situations you may want to do this are if you have certain employees, such as full-time employees, which usually work certain shifts however any of them could work these certain shifts, these shifts are set however the employee can change each week and you must schedule a full-time employee on this shift.

You might have an employee with a regular shift every week. You can assign only that person to the shift, so they're the only one who shows up for it.

To select them, click **All employees** on the template shift.

After you've selected your employees, close out. The setup page shows how many employees are available per template shift.
