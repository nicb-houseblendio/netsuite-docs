With Workforce Management (WFM), you can generate reports about various employee metrics.

The available shifts reports are:

-   [All](#subsect_0723104415)
    
-   [Terminated](#subsect_0723104426)
    
-   [Wage Changes](#subsect_0723104440)
    
-   [Birthdays](#subsect_0723104454)
    
-   [Missing Details](#section_1013040234)
    
-   [Average Ages](#subsect_0723104517)
    
-   [Monthly Turnover](#subsect_0723104532)
    
-   [Leave/Time-Off](#section_1013035319)
    
-   [Work Permits](#subsect_0723104618)
    

For a list of all available metrics in each report, see [Extracting Data Through WFM Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0625082603.html).

## All {#subsect_0723104415}

To access the **All** report, from the Workforce Management tab, go to Reports > Employee > All.

This report lets you generate information about all available details about your employees.

You can download a CSV file of the data included in the report.

For a list of all available metrics in each employee report, see [Employee Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0625082603.html#subsect_0724122945).

## Terminated {#subsect_0723104426}

To access the **Terminated** report, from the Workforce Management tab, go to Reports > Employee > Terminated.

This report lets you generate a list of terminated employees during a specified period. It includes information relevant to their termination.

You can download a CSV file of the data included in the report.

For a list of all available metrics in each employee report, see [Employee Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0625082603.html#subsect_0724122945).

## Wage Changes {#subsect_0723104440}

To access the **Wage Changes** report, from the Workforce Management tab, go to Reports > Employee > Wage Changes.

This report lets you make a list of wage rate changes for all employees hire during a set period. It covers rate changes from birthdays that move employees to a new rate bracket, as well as updates from new agreement revisions. Employees with the wrong birth date might show the wrong rates.

This report will not include employees who did not have a change in wage during the selected period.

You can download a CSV file of the data included in the report.

For a list of all available metrics in each employee report, see [Employee Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0625082603.html#subsect_0724122945).

## Birthdays {#subsect_0723104454}

To access the **Birthdays** report, from the Workforce Management tab, go to Reports > Employee > Birthdays.

This report lets you generate a list of employee birthdays, ages, and primary locations during a specified period.

You can download a CSV file of the data included in the report.

For a list of all available metrics in each employee report, see [Employee Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0625082603.html#subsect_0724122945).

## Missing Details {#section_1013040234}

To access the **Missing Details** report, from the Workforce Management tab, go to Reports > Employee > Missing Details.

The Missing Staff details report identifies if any staff are missing required information such as personal details, bank account information, or emergency contacts.

You can notify the staff members that are listed in the Missing Staff details report by email or SMS.

You can run this report after onboarding new staff members to ensure all their details are entered in SuitePeople Workforce Management.

You can download a CSV file of the data included in the report.

For a list of all available metrics in each employee report, see [Employee Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0625082603.html#subsect_0724122945).

## Average Ages {#subsect_0723104517}

To access the **Average Ages** report, from the Workforce Management tab, go to Reports > Employee > Average Ages.

This report calculates average ages using the current age (in years) of each employee who has a date of birth on record. It can be used to view the average employee age and employee count by job, location, state, or by all these criteria.

To view a list of employees with their age and other information, select **Show staff ages and dates of birth**.

Including data about Job(s) will result in staff who are available to work multiple jobs to be counted for each job.

You may only view an aggregate report when reporting on a master brand.

You can download a CSV file of the data included in the report.

For a list of all available metrics in each employee report, see [Employee Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0625082603.html#subsect_0724122945).

## Monthly Turnover {#subsect_0723104532}

To access the **Monthly Turnover** report, from the Workforce Management tab, go to Reports > Employee > Monthly Turnover.

This report provides a breakdown of employee turnover for all active locations associated with the given brand.

Three rows are provided for each location, showing the monthly, annualized (year-to-date) and rolling 12-month turnover.

You can download a CSV file of the data included in the report.

For a list of all available metrics in each employee report, see [Employee Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0625082603.html#subsect_0724122945).

## Leave/Time-Off {#section_1013035319}

To access the **Leave/Time-Off** report, from the Workforce Management tab, go to Reports > Employee > Leave/Time-Off.

This report lets you see employees' leave periods by choosing a pay period when the leave happened. Pick the start and end dates for the pay period, then click **Fetch**.

You can download a CSV file of the data included in the report.

For a list of all available metrics in each employee report, see [Employee Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0625082603.html#subsect_0724122945).

## Work Permits {#subsect_0723104618}

To access the **Work Permits** report, from the Workforce Management tab, go to Reports > Employee > Work Permits.

This report lets you generate Permitted Worker Permits for employees working in Victoria. You're responsible for making sure you have the right address and shift information for all locations you generate reports for.

This report is generated using the template provided by the Victorian State Government.

You can download a ZIP file of the work permits that the report generates.

For a list of all available metrics in each employee report, see [Employee Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0625082603.html#subsect_0724122945).
