The Multi-location view is a variation of the Weekly view that can be used to approve and manage shifts for multiple locations a time.

This screen is a great tool for anyone managing the approval of shifts across more than one site.

## Selecting locations {#subsect_39104906183}

When you first visit this page, you'll be prompted to select which locations and week you want to look at. Move any locations you'd like to view over to the **Chosen Items** column on the right-hand side and select which week you'd like to view using the calendar selector.
