Read this section for best practices and things to watch out for when you use Onboarding/Offboarding Plans.

## Limitations {#subsect_157241865691}

-   Currently, the Onboarding/Offboarding Plans SuiteApp supports only US and UK English.
    
-   You can't import CSV files into Onboarding/Offboarding Plans. If you try to import lists from the SuiteApp, you may run into formatting issues.
    

## Best Practices {#subsect_157241870116}

Follow these guidelines to maximize your use of the SuiteApp:

-   Set your preferred form when you set up the SuiteApp to make sure plans and templates work. For more information, see [Setting Form Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157240322990.html).
    
-   Create an employee record before you create a plan. Some features need an employee record to work. For example, receiving email notifications, and automatically including employees and supervisors as assignees. For more information, see [Adding an Employee](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N894212.html).
    
-   If you created the employee's plan before their employee record, see [Guidelines for Associating Plans With Employee Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157240670706.html#subsect_157240723943).
    
-   Enter a termination date on the employee record before you create an offboarding plan.
    
-   Note:
    
    If you use Effective Dating, you must set the employee record's effective date to the current date or a past date. If you set it to a future date, the SuiteApp can't source the termination date from the record.
    
-   When you create plans, make sure you select the right plan type before editing any fields. If you change the plan type later, you'll lose any data you've entered.
    
-   When creating a plan, remember that the template field can't be changed after you click **Save**. Ensure that you select the correct template before saving.
    
-   If you need to work on existing templates, see [Guidelines for Managing Templates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157241442807.html#subsect_157241444921).
    
-   For tips on getting email notifications, see [Receiving Email Notifications](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157240337779.html#subsect_157240505682).
