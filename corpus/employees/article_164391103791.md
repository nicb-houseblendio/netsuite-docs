This dataset template can be used for scheduling performance reviews by dates that are relevant and meaningful to you.

## Dataset Configuration {#subsect_164391173251}

The Reviews Scheduler by Relative Date dataset includes fields from the employee record type that provide relevant information about your employees for creating their performance reviews. The dataset contains the following record fields, multiple custom formulas, and criteria:

| Root Record Type | Data Grid | Custom Formula Fields | Criteria Filters |
| --- | --- | --- | --- |
| Employee | The following fields are included in the dataset:
-   Entity ID
-   Hire Date
-   Email
-   Supervisor
-   Job Title
-   Department
-   Location
-   Subsidiary

 | The following custom formula fields are included in the dataset:

-   Supervisor is Active & Non-Terminated
-   Employee is not Terminated
-   Today is 30 Days After Hire Date
-   Work Anniversary + 30 Days is Today
-   Work Anniversary is Today

 | The following criteria is used to filter the dataset:

-   Is Inactive is false
-   Employee is not Terminated is true
-   Work Anniversary is Today is True

 |

To edit a dataset, see [Editing a Dataset](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158041505315.html).
