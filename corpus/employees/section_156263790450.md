By default, Workforce Demographics is available only to the roles with access to HR Dashboard Components. If you want custom roles to access the portlet, you must perform the following procedure.

#### To grant Workforce Demographics access for custom roles:

1.  Log in as an Administrator.
    
2.  Go to Customization > Scripting > Script Deployments.
    
3.  In the Script filter, select **Workforce Demographics**.
    
4.  In the ID column, locate **customdeploy\_hrdc\_ps\_workforcedemographic**. Click **Edit**.
    
5.  On the **Audience** subtab, locate the **Roles** field.
    
6.  Select the custom roles that will use the portlet.
    
7.  Click **Save**.
