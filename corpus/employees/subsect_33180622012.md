## NetSuite Payroll Item (SuitePeople/Premier Payroll) not appearing in the export preview {#bridgehead_86180741698}

If the Payroll Item column isn't showing in the preview, you can display it with a quick configuration.

| Date | Departments | Locations | Payrol Item | Workplace | Hours | Rate | Total |
| --- | --- | --- | --- | --- | --- | --- | --- |
| Thursday, March 24, 2022 | Security | USVI Security | Normal Time | USVI Hotel | 8.0000 | 10.50000 | 84.0000 |
| Thursday, March 24, 2022 | Security | USVI Security | OT 1.5 | USVI Hotel | 0.1667 | 15.75000 | 2.6250 |
| Friday, March 25, 2022 | Security | USVI Security | Normal Time | USVI Hotel | 8.0000 | 10.50000 | 84.0000 |
| Friday, March 25, 2022 | Security | USVI Security | OT 1.5 | USVI Hotel | 0.11667 | 15.75000 | 1.8375 |
| Saturday, March 26, 2022 | Security | USVI Security | Normal Time | USVI Hotel | 7.9167 | 10.50000 | 83.1250 |
| Saturday, March 26, 2022 | Security | USVI Security | Normal Time | USVI Hotel | 7.9000 | 10.50000 | 82.9500 |

To show the payroll item in the preview, go to WFM > Setup > NetSuite Integration > Settings > Records. Do the following:

-   Show the payroll item in the column.
    
    -   Click Edit Fields next to the timebill record, then click the button at the bottom labeled Create New Custom Field. This adds a new set of fields to the table-enter payrollitem as the record type and field name, then click Submit to save.
        
    -   If you want WFM to block exports to NetSuite when there's no mapped payroll item, check the box for Required For Export before submitting.
        
-   Give WFM the info to show in the preview. At the bottom of the records list, click Create New Custom Record. Fill in the details as follows:
    
    -   Record Type = payrollitem
        
    -   Display Name = Payroll Item
        
    -   Display Name Plural = Payroll Items
        
    -   Name Field = name
        
    -   Grouping Field = itemtypenohierarchy
        
    -   Columns = subsidiary
        

Click **Submit**.

The next time you load an export preview, the payroll item will show up.

## Setting Up a Saved Search to Review Time Exported to NetSuite {#bridgehead_71181051419}

To review time exported from WFM to NetSuite, you should set up a saved search with formatting to highlight any issues before you run payroll.

To set up a saved search, go to Reports > Saved Searches > All Saved Searches > New. On the next screen, pick the type of search. Select **Time** from the list.

Enter a name, like **Workforce Management Time Export**. Then, choose to make it public, available as a list, and available in sublist view.

Under **Criteria** set up a filter. Choose the option for **Created by SuitePeople WFM (Custom Column)** and set it to **True**.

Click the **Results** subtab and set the info to display. Customize as needed. From the following items, ensure you add the ones set in bold:

-   **Date**
    
-   **Employee**
    
-   **Payroll Item**
    
-   Blended Overtime (Custom Column)
    
-   Payroll Rate (Custom Column)
    
-   **Duration**
    
-   Time-Off Type
    
-   Payroll Workplace
    
-   Location
    
-   Department
    
-   Customer:Project
    
-   Case/Task/Event
    
-   Item
    

Choose a sort order. You may opt to sort by employee, then by date.

It's helpful to highlight anything of concern, like overtime rows, with a red background. To set this up, go to the **Highlighting** subtab. Add a condition. In Payroll Item, choose any of your overtime payroll items. Select a background color.

To make the report easier to use, set up some quick filter options in the **Available Filters** subtab. Select filters to help you query the data. The most common are Employee, Location, and Date. This action lets you filter by date range, staff member, or location.

Click on **Save**. You can now run this report by typing the report name in the search box. If you have selected the list and sublist view options, use this report to filter and display the data under the **Time Tracking** subtab when viewing an employee.
