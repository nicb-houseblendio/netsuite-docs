After assigning locations to region-based overrides, you can start to create conditions for your override.

#### To create a condition for region-based overrides:

1.  Open the region-based override. See [Accessing Region-Based Wages or Overrides](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0909023340.html#subsect_0807020309)
    
2.  On the Region-based override page, click the **Conditions** subtab.
    
    The New Condition form appears.
    
3.  Click **\+ Create new Condition…**.
    
4.  In the **Name** field, enter the name of the condition.
    
5.  From the **Type** list, select the type of condition or rate. For more information, see Types of Conditions.
    
6.  On the appropriate rule tab, complete the required information for the rule parameters you need. For more information, see [Rule Parameters in WFM](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0909024748.html#subsect_0903113039).
    
7.  If you need to create more rules, click **+New rule…**, then complete the required parameters.
    
8.  After you're done adding rules, click **Save**.
    

To create specific conditions, see the following help topics:

-   [Setting up a Spread of Hours Condition for Region-Based Overrides](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0903102725.html)
    
-   [Setting up Break Conditions for Region-Based Overrides](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0903102805.html)
