The first time you run SuitePeople Time Clock, it'll ask for an activation code to link the installation with a roster unit.

For more information about activating a Windows device, see the following topics:

-   [Generating an Activation Code](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1013044154.html#section_1017085615)
    
-   [Activating a New Device](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1013044154.html#subsect_24164628247)
    

If you can't see the option for SuitePeople Time Clock in your configuration menu, you'll need to speak to someone who has higher access to the system.

Save the activation code-you'll need it when you install SuitePeople Time Clock for Windows.

## Activating Additional Units {#subsect_85120350993}

To activate additional units, select **Actions** from the main menu bar and select **Activate Unit** from the dropdown menu.

SuitePeople Time Clock will require an activation code to authenticate use on the additional unit.

When the new unit has been successfully activated, their name will appear under the green header.
