HR Dashboard Components offers a workforce demographics portlet for setup.

## HR Dashboard Components Workforce Demographics Metrics {#subsect_156264938504}

The following table illustrates the metrics available on the Workforce Demographics portlet.

| Metrics | Description |
| --- | --- |
| Headcount by Department | 
-   A column chart that compares the number of employees in each department.
-   Requires that the Departments feature is enabled. If the feature is disabled, the chart displays an error message.
-   Employees that are not associated with any department are categorized under the **Blank** column.
-   Departments with an employee headcount of 0 are not displayed.

 |
| Headcount by Location | 

-   A column chart that compares the number of employees in each location.
-   Requires that the Locations feature is enabled. If the feature is disabled, the chart displays an error message.
-   Employees that are not associated with any location are categorized under the **Blank** column.
-   Locations with an employee headcount of 0 are not displayed.

 |
| Headcount by Tenure | 

-   A column chart that breaks down employee headcount by their years of service or tenure.
-   Each column represents a range of years.
-   Click counts or labels that are linked to further break down and see more information.

 |
| Headcount by Gender | 

-   A column chart that compares the number of employees in each gender.
-   Employees with no gender on record are categorized under the **Blank** column.

 |
| Headcount by Employee Type | 

-   A column chart that compares the number of employees in each employee type.
-   Employees with no employee type on record are categorized under the **Blank** column.

 |

Note:

To get an accurate representation of your workforce on this portlet, ensure that the **Department**, **Location**, **Gender**, and **Employee** **Type** fields are specified in your employees' records.
