If you use the Kudos feature, the Kudos permission needs to be assigned to roles. Additionally, if users need to create or edit organization values, the Organization Values permission should be assigned at access level Create or Edit.

You can find the Kudos and Organization Values permissions on the Lists tab of the Role page. For a list of the standard roles assigned to this permission, see [Standard Roles Permissions Table](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N295396.html).

The following table lists the permission level a user must have to perform certain tasks related to these features.

| Permission | Subtab | Permission Access Level | Supported Functionality |
| --- | --- | --- | --- |
| Kudos | Permissions > Lists | View | Allows you to receive and view Kudos. You can't create new, edit, or delete Kudos. |
| Create | Allows you to give Kudos. You can't edit or delete Kudos. |
| Edit | Allows you to edit the Inactive field. You can't delete Kudos. |
| Full | Allows you to edit the Inactive field and delete Kudos. |
| Organization Value | Permissions > Lists | View | Allows you to view company organizational values. You can't create, edit, or delete organizational values. |
| Create | Allows you to create and view organizational values. You can't edit or delete organizational values. |
| Edit | Allows you to create, view, and edit organizational values. You can't delete organizational values. |
| Full | Allows you to create, view, edit, and delete organizational values. |
