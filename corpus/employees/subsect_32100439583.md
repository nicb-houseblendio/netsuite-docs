SuitePeople Time Clock for Windows is required if you are using a fingerprint scanner.

Important:

To follow the Biometric Information Privacy Act (BIPA), you can't use fingerprint scanning on Windows devices in Illinois. If you're setting up a Windows device there, employees can only punch in with pin codes.

To enroll a new employee with the scanner, SuitePeople Time Clock requires the following:

-   An active Internet connection
    
-   The Futronic fingerprint scanner driver
    

To install the fingerprint scanner driver, see [Installing SuitePeople Time Clock Components for Windows](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_95102310959.html).

New employees can be set up to use either their PIN code, fingerprint, or both.

#### To register an employee to use the fingerprint scanner: {#procedure_1014100902}

1.  Authenticate as a manager (requires manager access or higher).
    
2.  Click the Settings icon in the bottom-left corner of SuitePeople Time Clock.
    
3.  Click **Enroll Employee**.
    
4.  Select the employee you want to set up from the employee list.
    
5.  Select the finger you want to enroll for the employee. You can register all 10 fingers for the employee.
    
6.  SuitePeople Time Clock will prompt the employee to place their finger on the scanner. This process will occur eight times per finger.
    
7.  Click **OK** to continue.
    
8.  Follow this process for each finger you're registering.
    
9.  After you've registered all the employee's fingers, click **Save** to finish setting up the new employee.
    

If you are encountering issues, see [Troubleshooting SuitePeople Time Clock for Windows](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_0920125540.html).
