You can edit an employee change request type if you have the Employee Change Request Types permission access level at Edit, or Full. For more information, see [Employee Change Requests Permission Requirements](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156164430223.html).

#### To edit or inactivate an employee change request type:

1.  Go to _Setup > HR Information System > Employee Change Request Types_.
    
2.  Click **Edit** beside the employee change request type you want to edit.
    
3.  In the **Related Fields** subtab, add, delete, or move fields that you want to appear on the employee change request form.
    
    The fields you choose here are changed on the employee record after all the approvers approve the request.
    
4.  From the **Change Reason** list, select a change reason.
    
    This is the change reason that will apply to the requested changes as an effective-dated change on the employee's record. For more information about employee change reasons, see [Managing Employee Change Reasons](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4863937145.html).
    
5.  To make it unavailable for selection when creating employee change requests, inactivate an employee change request type by checking the **Inactive** box.
    
6.  When you're finished, click **Save**.
