If a bonus is **not** paid using using SuitePeople U.S. Payroll, you can edit the bonus percentage, amount, award date, payment status, or comments. You can't edit the employee or the bonus type.

If a bonus is paid using SuitePeople U.S. Payroll, you can't edit the bonus. If you included a bonus in a payroll batch by mistake, then you might need to revert the payroll batch and then cancel the bonus. For more information, see [Creating a Payroll Reversal](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N951968.html) and [Canceling a Bonus that is in a Reversed Payroll Batch](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157489118295.html).

#### To edit a bonus:

1.  Go to _Lists > Employees > Employees_.
    
2.  Beside an employee, click **Edit**.
    
3.  Click the **Compensation Tracking** subtab.
    
4.  In the Bonuses section, click the number beside a bonus.
    
5.  Make any changes.
    
6.  Click **Save**.
