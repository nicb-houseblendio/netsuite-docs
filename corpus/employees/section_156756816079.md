HR Dashboard Components includes the scripts in the following table.

| Script Name | Script ID | Description |
| --- | --- | --- |
| HRDC Create Total Active Emp Tracker | customscript\_hrdc\_active\_emp\_tracker\_ss | This script is scheduled to count all active employees for the day and groups them according to subsidiary. The count is used for several KPIs in HR Dashboard Components. By default, it runs every day at 11:30 p.m. Pacific Time (UTC - 8). If your NetSuite account uses a different time zone, you'll need to adjust the script's start time. The same goes if you want to change the time the script runs. For more information, see [Adjusting the Start Time of Daily Metric Computations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156263785906.html). |
| Initialize Active Employee History SS | customscript\_hrdc\_ss\_active\_emp\_history | Warning: Do not run this script manually. It should run automatically after installation. If you rerun this script, it will duplicate the number of active employee records in your account. This script runs after you install HR Dashboard Components. It processes data from up to two years before the day of installation. If the data processing is successful, the script sends an email notification that confirms that the data is ready. If it fails, it sends a copy of the error message and logs for review. |
| Workforce Demographics | customscript\_hrdc\_ps\_workforcedemographic | This script loads the content of the Workforce Demographics portlet for roles with access to the SuiteApp. To view the available metrics, see [Viewing the Workforce Demographics Portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156263779386.html). To grant access to custom roles, see [Customizing Workforce Demographics for Custom Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156263790450.html). |
