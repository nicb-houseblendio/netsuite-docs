Follow the steps in the procedure below.

#### To create a new ADP (US) payroll configuration in WFM:

1.  Go to Workforce Management > Setup > Integrations.
    
2.  From the **Payroll systems** list, select **ADP (US)**.
    
3.  On the ADP (US) configurations page, click **\+ Create new**.
    
4.  On the Create new ADP (US) Payroll configuration page, complete the fields.
    
    -   **Company code** - Enter the two or three alphanumeric characters representing your company. ADP provides this code. You may also enter a dash (-) or ampersand (&).
        
    -   **Use expanded fields** - If this setting is enabled in your ADP company, check this box.
        
    -   **Send rates** - If you want WFM to include wage rates with each row in the exported ADP files, check the box. If this box is cleared, exported filed will include only the number of hours worked.
        
    -   **Department length** - Choose the length of the department name which matches the setting in ADP. You can choose from:
        
        -   Never send department
            
        -   3 characters
            
        -   6 characters
            
    -   **Cost code** - If you want to override the default cost code on the exported hours and link location and job combinations, check the box.
        
    -   **Export hours to calendar day** - If you want to export all hours to the calendar day where they belong instead of the work day, check the box. When checked, shifts may be split when they go over midnight.
        
    -   **Auto link to new revisions** - If you want to automatically link allowances, penalties, rates, and multipliers from newly created revisions, check the box.
        
        WFM notifies you when any linked agreements, regions, or location overrides are revised.
        
5.  Click **\+ Create**.
    

After creating your ADP (US) configuration, you must link the following to an ADP code:

-   Employees
    
-   Locations
    
-   Leave types
    
-   Agreements
