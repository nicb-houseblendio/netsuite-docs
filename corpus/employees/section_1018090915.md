Important:

The World Manager integration is available only to accounts where it's already provisioned. It is not included with the current SuitePeople WFM solution.

The World Manager integration gives your managers access to a fifth suite in the platform. This is a scheduling suite that includes shift drops and swaps.

When World Manager is integrated with WFM through Single Sign On, employees and managers experience a seamless onboarding process. Employees hired through World Manager are automatically created in WFM, where they can perform the following:

-   Enter all personal and financial details
    
-   See schedules
    
-   Swap shifts
    
-   Drop shifts
    

When new employees arrive for their first shift, everyone is aware that the person is on-site. The employee receives a PIN to clock on to time and attendance.

If you operate in a Franchise environment where your franchisor provides you with World Manager access, you must review the Importing Staff options.

## Setting up World Manager for WFM {#subsect_80211055202}

Before you can configure and manage World Manager for WFM, contact NetSuite Customer Support and request to enable the integration in your account.

After the integration is activated, you can continue to set up World Manager for WFM.

#### To set up World Manager for WFM:

1.  Go to Workforce Management.
    
2.  Go to Setup > Integrations > World Manager.
    
3.  On the World Manager configuration page, complete the required details.
    
    1.  Enter the required data on the following fields:
        
        -   **Name** - Enter the name of your World Manager platform.
            
        -   **Base URL** - Enter the URL of the platform.
            
        -   **Username** - Enter the username of a World Manager level user in World Manager.
            
        -   **Password** - Enter the password of the username you entered.
            
        -   **Create missing staff** - If you want WFM to automatically create staff from World Manager, check the box.
            
        -   **Generate missing timesheet pin** - If you want employees to get a random four-digit pin for WFM, check the box.
            
        -   **Send new staff emails** - If you want new staff to receive a welcome email to WFM, check the box.
            
    2.  Enter information from World Manager and enter them on the following fields:
        
        -   API key
            
        -   Oauth client id
            
        -   Oauth client secret
            
        
        For more information, go to [Get WFM Requirements from World Manager](#subsect_0923083855).
        

### Get WFM Requirements from World Manager {#subsect_0923083855}

Follow the procedure to get the API Key, OAuth client ID and OAuth secret from World Manager.

#### To get WFM requirements from World Manager:

1.  Go to World Manager.
    
2.  Create a new integration client and call it WFM Scheduling.
    
3.  On the Update Integration Client page, complete the fields.
    
    1.  In the **Name** field, enter **WFM Scheduling**.
        
    2.  In the **Scopes** section, check all the boxes.
        
    3.  In the **Authorisation Message** box, enter the message that employees will see when they log into WFM from World Manager.
        
        A sample message is: When you sign in to Workforce Managment using your World Manager login details, you can sign in without using your WFM username and password.
        
    4.  In the **Redirect URL** field, enter **https://go.adiinsights.com/complete/world\_manager/**.
        
4.  Copy the following fields to WFM:
    
    -   **Client ID** - Use this as the **OAuth Client ID** in WFM.
        
    -   **Client Secret** - Use this as the **API key** and **OAuth Client secret** in WFM.
        

## Linking Locations to World Manager {#subsect_96214836122}

To import staff from World Manager, you'll need to link a WFM Location with a World Manager Location.

If you're in a franchisee environment, your franchisor will manage this for you.

On the Link Locations to World Manager page, select a location from the drop down list to link the locations between the two systems.

## Importing Employees from World Manager {#subsect_48215749978}

Employees are automatically imported from World Manager to WFM.

If you need to import employees, follow the procedure.

#### To import employees from World Manager:

1.  Go to Workforce Management.
    
2.  Go to Setup > Integrations > World Manager.
    
    A list of employees that have not imported is available.
    
3.  For each employee that you must import, click **Import** next to their name.
    
    The screen shows any issues that prevent the import of the employees.
    
4.  In World Manager, fix the issues preventing the import.
    

After the issues are fixed, the employees are automatically imported to WFM. If the employees remain unavailable, complete the procedure to import them again.

## Linking Employees to World Manager {#subsect_64220339914}

When WFM imports employees from World Manager, it verifies that the employee to be imported doesn't currently exist in WFM.

If a similar name exists in your WFM account, the employee won't automatically import. To resolve the issue, link the existing WFM profile to the employee's World Manager profile rather than create duplicate profiles in WFM.

#### To link employees to World Manager:

1.  Go to Workforce Management.
    
2.  Go to Setup > Integrations > World Manager.
    
3.  Click **Staff**.
    
4.  Beside the name of the employee with an existing WFM profile, click **Select Person**.
    
    The **Select Person** list shows WFM profiles that are not currently linked to a World Manager profile.
    
5.  From the list, select the corresponding WFM profile.
    
6.  Click **Link**.
    

## Syncing and Importing World Manager Fields {#subsect_83221322664}

When employee profiles are imported from World Manager, WFM imports a select set of fields and synchronizes a subset of these fields.

WFM imports the following World Manager fields:

-   Name (Required to Import)
    
-   Preferred Name (Custom Field in World Manager)
    
-   Email address
    
-   Phone
    
-   Mobile
    
-   Date Of Birth (Custom Field in World Manager)
    
-   Gender (Custom Field in World Manager)
    
-   Jobs (Based on Group Name)
    

After an employee profile is imported, WFM synchronizes the following fields between both platforms:

-   Preferred Name (Custom Field)
    
-   Email
    
-   Phone
    
-   Mobile
    
-   DOB (Custom Field)
    
-   Gender
