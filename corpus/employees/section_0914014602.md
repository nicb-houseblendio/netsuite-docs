If you try and generate any shift reports where reporting by location is an option, you'll see these groups that you have created.

These groups will filter the list of available locations to choose from.

On the Can be rostered at page for each employee, you can select a particular group. Employees with an associated group will be available to be scheduled at all locations belonging to this group.
