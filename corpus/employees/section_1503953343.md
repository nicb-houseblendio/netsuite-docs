The Employee Reports SuiteApp needs SuitePeople HR and gives you access to employee reports as NetSuite saved searches. For more information, see [SuitePeople Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1495573671.html)

Note:

Right now, the Employee Reports SuiteApp only supports US and UK English.

## Prerequisites {#bridgehead_1491184908}

Ensure the required features are enabled to install the Employee Reports SuiteApp (bundle ID 167330). Go to _Setup > Company > Setup Tasks > Enable Features_.

-   On the **Employees** subtab, under HR Information System, check the boxes for **Compensation Tracking**, **Job Management**, and **Termination Reason Tracking**.
    
-   On the **SuiteCloud** subtab, under SuiteScript, check the **Server SuiteScript** box.
    

## Installation {#bridgehead_1491185360}

To install Employee Reports, go to Customization > SuiteBundler > Search & Install Bundles.

Use the following information to search for the SuiteApp:

-   Bundle Name - **Employee Reports**
    
-   Bundle ID - **167330**
    

Employee Reports is a managed bundle and is automatically updated. See [Installing a Bundle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3395142.html) for more information.

## Accessing Employee Saved Search Reports {#bridgehead_1491186062}

Important:

The saved searches installed with the SuiteApp are private. An Administrator must customize the saved searches to define the roles that can access saved searches and their location in the Reports menu. For more information, see [Customizing Employee Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1496322885.html).

Access the following saved searches through their own menu options at Reports > Employees/HR:

You can print or export saved search results. Exporting works for Excel, CSV, and PDF. Use the print and export buttons at the top of the results list. For more information, see [Exporting Search Results](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N663983.html).

You can also email saved search results to other users. See [Saved Search Email](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N680983.html) and [Saved Searches](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N675442.html).

Note:

When any of the Employee Reports saved search returns a single result, NetSuite opens the record if the user has permission to view it. To return search results as a list with only one record in the results, go to _Set Preferences > Analytics > Search_. Check the **Show List When Only One Result** box, and then save.

## Average Salary by Ethnicity Saved Search {#bridgehead_1507727199}

This search lists the average annual base wages of active employees by ethnic group. Results are sorted by ethnic group, average base wage, and employee count. In the results list, click any ethnicity name to see more details.

## Average Salary by Gender Saved Search {#bridgehead_1507727624}

This search lists the average annual base wages of active employees by gender group. Results are sorted by gender group, average base wage, and employee count. In the results list, click any gender name to see more details.

## Average Salary by Job Saved Search {#bridgehead_1507727844}

This search lists the average annual base wages of active employees by job group. Results are sorted by job group, average base wage, and employee count. In the results list, click any job name to view more details.

## Employee Birthday Report Saved Search {#bridgehead_1491188457}

This search lists all active employees with their birth date, age, and other employee details. Results are sorted by birth date and by employee name.

## Employee Birthdays by Month Saved Search {#bridgehead_1491188802}

This search lists the number of active employees born in each calendar month. In the results list, click the name of each month to see more details.

## Employee Roster Saved Search {#bridgehead_1491188341}

This search lists all active employees in ascending alphabetical order by last name. Results includes job, supervisor, class, department, location, subsidiary, and country details for each employee. The employee name is linked to the employee record.

## Employees by Age Range Saved Search {#bridgehead_1491188912}

This search lists the number of active employees by age range. In the results list, click the name of each age range group to view more details.

## Employees by Base Wage Type Saved Search {#bridgehead_1492756233}

This search lists the number of active employees by base wage type. In the results list, click the name of each base wage type to see more details.

## Employees by Ethnicity Saved Search {#bridgehead_1491190108}

This search lists the number of active employees by ethnic group. In the results list, click any ethnic group to view more details.

## Employees by Gender Saved Search {#bridgehead_1491190405}

This search lists all active employees sorted by gender and hire date.

## Employees by Hire Date Saved Search {#bridgehead_1491189567}

This search lists all active employees by hire date, from most recent to least recent.

## Employees by Job Saved Search {#bridgehead_1491189674}

This search lists the number of active employees by job. In the results list, click any job to see more details.

## Employees With Incomplete Compensation Data Saved Search {#bridgehead_1492757528}

This search lists active employees who are missing at least one of the following information in their employee record:

-   base wage
    
-   base wage type
    
-   compensation currency
    

In the results list, the employee name is linked to the employee record.

## Employees Without Supervisors Saved Search {#bridgehead_1492756944}

This search lists active employees without a supervisor on record. In the results list, the employee name is linked to the employee record.

## New Hires (Last 90 Days) Saved Search {#bridgehead_1491189772}

This search lists active employees hired within the last 90 days. Results are sorted by hire date, from most recent to least recent. Results are sorted by hire date, from most recent to least recent.

## New Hires by Ethnicity (last 12 months) Saved Search {#bridgehead_1491190283}

This search lists the number of active employees from each ethnic group who have been hired within the last 12 months. In the results list, click any ethnic group to view more details. In the detailed report, results are sorted by hire date, from most recent to least recent.

## New Hires by Gender (last 12 months) Saved Search {#bridgehead_1491190528}

This search lists the number of active employees from each gender group who have been hired within the last 12 months. In the results list, click any gender group to see more details. In the detailed report, results are sorted by hire date, from most recent to least recent.

## Termination Reasons (Trends) Saved Search {#bridgehead_1491190616}

This search lists reasons cited by inactive employees for terminating their employment, and the number of times each reason is cited. In the results list, click any termination reason to view more details.

## Upcoming New Hires Saved Search {#bridgehead_1492758106}

This search lists employees with hire dates that after the current date. Results are sorted by hire date, job, and location.

## Upcoming Terminations Saved Search {#bridgehead_1492758531}

This search lists active employees with termination or release dates that are after the current date. Results are sorted by termination date, job, and location.
