Important:

The Paypac integration is available only to accounts where it's already provisioned. It's not included with the current SuitePeople WFM solution.

You can set up Workforce Management to integrate with Attaché.

After the setup, you can generate a Paypac-compatible file of approved hours worked to import for payroll.

## Configuring Paypac with Workforce Management {#subsect_0624111750}

The Paypac file format is available in the Generic Payroll exporter.

#### To configure Paypac with WFM

1.  Go to Setup > Integrations > Payroll Integrations > Paypac.
    
2.  Create a new payroll configuration.
    
    1.  Click **Create new**.
        
    2.  On the Create new payroll configuration page, complete the required fields.
        
        -   **Name** - Enter a name to identify this specific Paypac configuration. You can create multiple Paypac configurations, such as when you have multiple databases or files and need to generate separate ones.
            
        -   **Icon** - Select an icon to identify this configuration.
            
        -   **Report type** - From the list, select **Paypac**.
            
        -   **Date format** - From the list, select **World Long**.
            
        -   (Optional) **Hourly payroll id** - If you have employees on flat rates, enter their ID here. Staff on flat rates are those whose wage on their staff members profile is set to **Hourly**.
            
    3.  Click **Create**.
        
        The Detail page appears.
        
3.  (Optional) On the Detail page, verify your configured settings and change as needed.
    

Important:

If the Detail page doesn't appear, you must link the data you want to export.

## Linking Data from Paypac to WFM {#subsect_0624015430}

After you've configured Paypac for WFM, you should see the Detail page with your chosen settings. If this isn't the case, link the data you intend to export.

#### To link data from Paypac to WFM

1.  Go to Setup > Integrations > Payroll Integrations > Paypac.
    
2.  Click **Detail**.
    
3.  Link employees.
    
    1.  From the Detail page, click **Employees**.
        
    2.  (Optional) On the top of the page, use the filters to update the names that appear on the table.
        
    3.  From the employee list, find the employee whose data you need to export.
        
    4.  (Optional) On the top of the page, search for the name of a specific employee.
        
    5.  In the corresponding **Payroll ID** column, enter the unique Paypac payroll ID of the employee.
        
        Note:
        
        You can also link Attaché IDs to employees on the Employee List page. To do so, go to Setup > Employees > List. For each employee you need to link to WFM, enter their Attaché IDs in the corresponding **Payroll ID** column.
        
    6.  Click **Link**.
        
        A page to link the employee to payroll will then appear.
        
    7.  From the **Config** list, select the name of the corresponding payroll configuration.
        
    8.  In the **Payroll id** field, enter the employee's Paypac ID.
        
    9.  Click **Link**.
        
    10.  Complete Steps E to I for all employees you need to export.
         
4.  Link locations.
    
    1.  From the Detail page, click **Locations**.
        
    2.  (Optional) On the top of the page, use the filters to update the locations that appear on the table.
        
    3.  From the locations list, find the location you need to export.
        
    4.  (Optional) On the top of the page, search for the name of a specific location.
        
    5.  In the corresponding **Payroll ID** column, enter the unique location or department ID.
        
    6.  Click **Link**.
        
    7.  Complete Steps E to F for all locations you need to export.
        
5.  Link leaves.
    
    1.  From the Detail page, click **Leave**.
        
    2.  (Optional) On the top of the page, use the filters to update the leave types that appear on the table.
        
    3.  From the leave types list, find the type you need to export.
        
    4.  (Optional) On the top of the page, search for the name of a specific leave type.
        
    5.  In the corresponding **Payroll ID** column, enter the unique leave type ID.
        
    6.  Click **Link**.
        
    7.  Complete Steps E to F for all leave types you need to export.
        
6.  Link agreements.
    
    1.  From the Detail page, click **Agreements**.
        
    2.  Select from the following options:
        
        -   **Conditions** - You should link conditions for instances when a single set of payroll ID apply to all the employees associated with the agreement, regardless of wage level and employment status.
            
        -   Allowances
            
        -   Penalties
            
        -   **Classifications** - You should link classifications if your payment setup require multiple payroll IDs to be associated with employees depending on their employment conditions.
            
    3.  (Optional) Select **Conditions**.
        
    4.  On the Enterprise Agreement page, enter the payroll ID for each unlinked agreement.
        
    5.  (Optional) Select **Classifications**.
        
    6.  On the Classifications page, filter the results by wage agreement and revision.
        
        Conditions are shown on the page based on the different classifications set up in WFM.
        
    7.  Find the condition that you need to identify.
        
    8.  Enter the payroll ID. Press **Enter**.
        
    9.  Repeat steps G to H for all the conditions you need to identify across the different classifications.
