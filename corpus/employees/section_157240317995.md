To use Onboarding/Offboarding Plans, enable the features in the following table.

| Subtab | Feature | Description |
| --- | --- | --- |
| SuiteCloud | Custom Records | Lets you access custom records provided by the SuiteApp. |
| Client SuiteScript | Lets you use custom functions provided by the SuiteApp. |
| Server SuiteScript | Lets you run scripts provided by the SuiteApp. |

For more information, see [Enabling Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N232138.html).

To continue setting up the SuiteApp, see [Installing the SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157240319613.html).
