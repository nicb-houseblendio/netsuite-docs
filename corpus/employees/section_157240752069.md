As the Coordinator of a plan, you can do the following:

-   [Viewing or Editing Plans](#subsect_157240763847)
    
-   [Tracking the Status of Plans](#subsect_157240768764)
    
-   [Deleting Plans](#subsect_157240770466)
    

If you use any standard role with complete permissions to access a plan that is created for you, you're automatically set as an Assignee. This also applies to custom roles. You can only view the complete list of tasks of other employee plans. For more information, see [Managing Plans as an Assignee](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157240753404.html).

## Viewing or Editing Plans {#subsect_157240763847}

Use the following procedure to view or edit plans.

#### To view or edit a plan:

1.  Go to the Onboarding/Offboarding Plan List page. For instructions, see [Accessing the SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157240329823.html).
    
2.  On the page, locate the employee's name, then click **View** or **Edit**.
    
3.  After you click **Edit**, you can make changes to the plan.
    
    Note:
    
    If the plan is already associated with a template, you can't change it anymore. You can only select a template when you first create the plan.
    
4.  Click **Save**.
    

## Tracking the Status of Plans {#subsect_157240768764}

As a Coordinator, use the **Plan Status** field to view and edit the status of the plan.

| Plan Status | Description | Notes |
| --- | --- | --- |
| Not Started | This status is for plans where all tasks are set to **Not Started**. New plans have this status by default. | \- |
| In Progress | This means at least one task is **In Progress** or **Completed**, but not all are done. | The plan goes back to In Progress if any task is set to **Not Started** or **In Progress**. |
| Completed | This means all tasks are completed. The coordinator can also set the plan to **Completed** even if some tasks aren't marked complete. | The plan is set to **Completed** if all tasks are marked completed, or any **Not Started** or **In Progress** tasks are deleted. |

## Deleting Plans {#subsect_157240770466}

#### To delete a plan:

1.  Go to the Onboarding/Offboarding Plan List page. For instructions, see [Accessing the SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157240329823.html).
    
2.  On the page, locate the employee's name and click **Edit**.
    
3.  From the **Actions** list, click **Delete**.
