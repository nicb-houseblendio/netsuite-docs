You must set permissions for custom roles so their assigned users can use the dashboard components.

| Subtab | Permission | Access Level |
| --- | --- | --- |
| Permissions > Setup | KPI Scorecards | Full |
| Permissions > Custom Record | Active Employee per Subsidiary | Full |
| Permissions > Custom Record | Total Active Employee Tracker | Full |

For more information about setting permissions for a role, see [Setting Permissions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N288727.html).
