With your activation code ready, prepare to install the SuitePeople Time Clock components on your Windows device.

Confirm that your Windows device meet the minimum screen requirements for Time Clock. For more information, see [Minimum Screen Requirements for SuitePeople Time Clock for Windows](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1014100159.html#subsect_0226084142)

#### To install SuitePeople Time Clock components for Windows: {#procedure_42194438850}

1.  Go to Workforce Management.
    
2.  Go to Setup > Time Clock.
    
3.  On the upper right corner of the Time Clock page, click **Download Apps**.
    
4.  On the **Download Time Clock Apps** window, click **Download** beside the Windows platform.
    
    The file downloads in the background.
    
5.  To verify the integrity of the installed file, note the installer hash in the window. Then follow the procedure to verify the installer. For more information, see [Verifying the SuitePeople Time Clock for Windows Installer](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0609074252.html).
    
6.  Run the SuitePeople Time Clock installer.
    
7.  On the Choose Components page, select components to install.
    
    -   If you don't have the Futronic fingerprint scanner, check only **SuitePeople Time Clock**.
        
    -   If you have the Futronic fingerprint scanner and don't have Time Clock installed, check both the **SuitePeople Time Clock** and **Futronic Fingerscanner Drivers** components.
        
    -   If you already have Time Clock installed and is installing the Futronic fingerprint scanner, check only **Futronic Fingerscanner Drivers**.
        
8.  Click **Next**.
    
9.  Choose the install location. Click **Install**.
    
    The wizard automatically installs the components.
    
10.  If you checked the **Futronic Fingerscanner Drivers** box, the Futronic Fingerprint Scanner Setup page appears. Click **Next**.
     
     The installer adds the driver.
     
11.  Click **Finish**. Click **Close**.
     
12.  If your installation includes SuitePeople Time Clock, open the app on your Windows device.
     
13.  Enter the activation code. Click **Activate**.
     
     SuitePeople Time Clock opens to a number pad screen that employees can use to clock in.
     
     For more information about clocking in and out, see [Using SuitePeople Time Clock for Windows](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_2105712589.html).
