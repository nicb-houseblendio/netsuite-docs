Here you are able to set up a **default superannuation fund** for employees. This default superannuation fund will appear within each employee's **Financial** section as a button which says **Default fund**.

When this button is hovered over, the default fund you have set up will appear for them.

Clicking this button pre-fills the details, and employees only need to fill in their superannuation account number.

## Setup {#subsect_4132509633}

Back to the **Setup > Financial** menu option, you'll see the **Superannuation defaults** fields.

Fill in the Fund name, and USI (or legacy SPIN if required) and save. This will then appear for the employee.

**Note: This is set up at a company level, appearing for all employees within your WFM company.**
