On the ADP configuration page, you'll see the following options:

-   **Detail** - Adjust the initial settings you made when you created the configuration.
    
-   **Employees** - Link your employees to an ADP code.
    
-   **Locations** - Link WFM locations to an ADP department.
    
-   **Location + Job** - Link WFM location and job combinations to the ADP cost codes.
    
-   **Leave** - Link leave types to an ADP code.
    
-   **Agreements** - Link WFM agreement to an ADP company.
    
-   **Wages** - (Pending)
    
-   **Report** - Export files about employee leave and work hours.
    
-   **Deactivate** - Deactivate an ADP configuration that is no longer needed.
