Before you enable the feature, note the following prerequisites.

| Prerequisite | Action |
| --- | --- |
| The New Weekly Timesheets Interface feature must be enabled in your account. | In NetSuite, enable the feature. See [Weekly Timesheet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1518113345.html). |
| SuitePeople Workforce Management and SuitePeople U.S. Payroll must be part of your implementation. Important: The Enhanced Timesheets Using Workforce Management Wage Rules feature is not available for integration with third-party payroll systems. | To learn more, contact your NetSuite account manager. See the following topics:
-   [SuitePeople Workforce Management](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1221923239.html)
-   [SuitePeople U.S. Payroll](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/preface_1538679887.html)

 |
| The SuitePeople Workforce Management (WFM) SuiteApp must be installed in the account. | Install the SuiteApp. See [Installing Workforce Management](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_31223632501.html). |
| WFM is properly integrated in your NetSuite account. This includes ensuring the proper linking of records, fields, and employees. | In WFM, do the following:

-   Import and sync employees. See:
    -   [Importing Employees to WFM](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0110111058.html)
    -   [Employee Sync Settings](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_27144903953.html#subsect_30213453569)
-   Verify payroll settings. See:
    -   [Linking Payroll Items in WFM](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1003104314.html)
    -   [Managing Wages for WFM Employees](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1102035923.html)
    -   [Managing Conditions and Rules](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0909023124.html)
-   Verify any other applicable NetSuite integration settings. See [Integrating Workforce Management with NetSuite](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_36112903912.html).
-   Map time bill records. See [Mapping Time Bill Fields for Enhanced Timesheets Using WFM](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0827011145.html).

 |

To read about the complete setup instructions for the feature, see [Setting Up Enhanced Timesheets Using WFM](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0812065915.html).
