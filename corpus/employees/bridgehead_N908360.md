When an expense report gets supervisory approval, its status changes to Pending Accounting Approval. It needs this final approval for its amounts to be posted. For more information, see [Giving Accounting Approval for Expense Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N913502.html).

The posting period for an expense report is set after accounting approves it. If that period is already closed, the report gets posted to the next open period.
