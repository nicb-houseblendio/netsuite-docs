When you set up performance reviews, consider the data that employees and managers should look at to evaluate performance for a review period.

To set up performance reviews, complete the following tasks:

-   [Performance Review Questions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157538096861.html) - Create a library of performance review questions that you can add to performance review templates.
    
-   [Performance Review Rating Scales](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157538100220.html) - Create rating scales that you can apply to performance review templates. Rating scales are used for questions that require a rating and for the overall rating.
    
-   [Performance Review Templates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157538104209.html) - Create templates for different performance review scenarios. Templates are made up of performance review questions and a rating scale.
    

After you complete the setup tasks, you can launch performance reviews for individual or groups of employees:

-   [Scheduling Performance Reviews](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157538107652.html) - Launch a performance review for a group of employees by using the Basic performance review schedule or the Advanced performance review schedule.
    
-   [Individual Performance Reviews](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157538110724.html) - Launch a performance review for an individual employee.
