You'll need to install the designated bundle to use HR Dashboard Components.

#### To install HR Dashboard Components

1.  Go to Customization > SuiteBundler > Search & Install Bundles.
    
2.  In the **Keywords** field, enter the bundle ID or name of the HR Dashboard.
    
    -   Bundle name: HR Dashboard Components
        
    -   Bundle ID: 288380
        
3.  From the search results, click the bundle name.
    
4.  On the Bundle Details page, click **Install**.
    

For more information, see [Installing a Bundle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3395142.html).

The SuiteApp takes time to process the data for the account. It can process data from up to two years before the day of installation.

If the data processing is successful, you receive an email notification that confirms that the data is ready. If it fails, you receive a copy of the error message and logs for review.
