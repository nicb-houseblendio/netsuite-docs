After you set up **State 2: Next Approver**, set up **State 3: Final Approver**. If the employee you assigned in State 2 approves the employee change request, the employee change request is sent to the final approver.

Important:

The final approver must have permission to make changes to the employee's record for the fields specified in the employee change request. For more information, see [Advanced Employee Permissions for Employee Change Requests](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156095870335.html).

Note:

You should set the final approver in your workflow to be an HR personnel so they can check the employee change request for accuracy.

## State 3: Final Approver {#subsect_156985495469}

#### To set up State 3: Final Approver:

1.  If you haven't set up State 2, go to [Setting Up State 2: Next Approver](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156096749961.html).
    
2.  In the diagrammer, click **State 3: Final Approver**.
    
3.  To set the next approver:
    
    1.  In the context panel on the **State** subtab, click **New Action**.
        
    2.  In the **New Action** window, click **Set Field Value**.
        
    3.  In the **Field** list, select **Next Approver**.
        
    4.  In the **Value** field group, choose **Static Value**.
        
    5.  In the **Selection** list, select the name of the employee you want to be the final approver.
        
4.  To set the final approver to true:
    
    1.  In the context panel on the **State** tab, click **New Action**.
        
    2.  In the **New Action** window, click **Set Field Value**.
        
    3.  In the **Field** list, select **Final Approver**.
        
    4.  In the **Value** field group, choose **Static Value**.
        
    5.  Check the **Checked** box.
        
    6.  Click **Save** to save the action.
        

## Transition to State 4: Complete {#subsect_156985499125}

#### To set up the transition to State 4: Complete:

1.  In the diagrammer, hover over the bottom of **State 3: Final Approver**. The icon becomes a filled half-circle.
    
2.  Drag the icon to **State 4: Complete**.
    
3.  In the workflow diagrammer, double-click the transition arrow from **State 3: Final Approver** to **State 4: Complete**.
    
4.  In the **To** list, select **State 4: Complete**.
    
5.  In the **Transition On** list, select **After Record Submit**.
    
6.  In the **Event Types** list, click **Approve**.
    
7.  In the **Condition** field group, select **Visual Builder**.
    
8.  Next to the **Condition** field, click the **Open** icon to open the Condition Builder.
    
9.  Enter the following:
    
    1.  In the **Field** list, select **Next Approver**.
        
    2.  In the **Compare Type** list, select **Any Of**.
        
    3.  In the **Selection** list, select **Current User**.
        
10.  Click **Add** to add the condition, and then click **Save** to save the condition.
     
11.  Click **Save** to save your changes to the transition.
     
12.  To continue with the Employee Change Request Workflow, go to [Setting Up State 4: Complete](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156096962712.html).
