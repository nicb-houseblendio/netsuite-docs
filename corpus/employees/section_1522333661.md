Access to the employee record through SOAP web services respects the permissions that are assigned to a role. However, be aware of the following:

-   A value for a field is set on the employee record in a SOAP web services program. The current role doesn't have access to that field. The program completes without errors, but the field isn't set or updated.
    
-   Fields and sublists to which the current role doesn't have access aren't returned through search or filtering.
