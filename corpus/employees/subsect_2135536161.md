Timebill field linking options from WFM to NetSuite include but aren't limited to:

-   WFM location to a NetSuite location
    
-   WFM location to a NetSuite project
    
-   WFM location to a NetSuite department
    
-   WFM job to a NetSuite department
    
-   WFM job to a NetSuite project task or service item
    

## Guidelines for Linking WFM Fields {#subsect_67135713827}

Keep these guidelines in mind.

-   The default setup is different from what's described below, so make sure your settings match exactly.
    
-   If you use Infinet Cloud Payroll, the payroll subsidiary and timebill wage options aren't available.
    
-   When mapping WFM locations and jobs, ensure that employees get the right wage rate for the locations they work at and the jobs they do.
    
-   Record and report time against projects, tasks, or other NetSuite fields.
    
-   Adapt time-based billing.
    

### Configuring WFM Fields to Link with NetSuite {#bridgehead_25140536070}

Follow the procedure to configure WFM fields.

#### To configure WFM fields to link with NetSuite:

1.  Go to Workforce Management.
    
2.  Go to Setup > NetSuite Integration > Settings.
    
3.  Click the **Configuration** subtab.
    
4.  Refer to the actions in the **Settings for Linking WFM and NetSuite Fields** table.
    
5.  After setting configurations, click **Save**.

## Configuring WFM Time Fields for NetSuite {#subsect_0731013000}

In WFM, you can set up added time fields to track more time segments in timebill records.

You can set up the:

-   Fields to be used to send additional data to NetSuite
    
-   Additional fields that employees will see when they punch in
    
-   The order that WFM shows the fields
    

Managers can select the right values during approval. Any later record types that reference a previous one will have their available list filtered based on the earlier selection.

Important:

Shifts with additional fields can't be approved using the automatch feature. If your shifts have added time fields, you must manually approve them. For more information, see [Automatch and Rounding Settings in WFM](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0314095739.html).

#### To configure WFM fields to link with NetSuite:

1.  Go to Workforce Management
    
2.  Go to Setup > NetSuite Integration > Settings.
    
3.  Click the **Time Fields** subtab.
    
4.  Click **Configure fields..**.
    
5.  On the Fields for Timebill window, complete the required details for each field.
    
    -   **Field label** - Enter the field's label. If you leave it blank, it'll default to the record name, purpose, or field name.
        
    -   **Record type** - Enter the record name linked to the field label in NetSuite without any spaces.
        
    -   **Field name** - Enter the field name from the timebill.
        
    -   **Value** - Enter **True** or **False**.
        
    -   **Purpose** - Select why you're using this field.
        
    -   **Required for export** - If there are added custom fields that the employee or manager needs to complete when approving time, check this box.
        
        For the record to export, the custom field must contain data. For example, if an employee fills out extra time fields, project, project task, or service task, they also need to complete the custom field so the data can be exported.
        
6.  (Optional) If you want to add a field, click **Create new field**.
    
7.  Click **Submit**.
    
8.  From the **Available** panel, drag the fields that you want to show into the **Time Field Order** panel.
    
    Important:
    
    Fields linked to the record type are automatically selected and placed in the Available panel.
    
    Fields that aren't mirrored can't be selected and won't show up on the panel.
    
9.  (Optional) Reorder the fields that you moved to the **Time Field Order** panel.
    
10.  Set the visibility for the added fields.
     
     1.  Click the pencil icon next to the field name.
         
         A window appears.
         
     2.  Choose how you want the field to show up for customers.
         
         -   **Do not show in Time & Attendance**\- If you want to hide the field, choose this button.
             
         -   **Show in Time & Attendance**\- If you want to show the field and make it optional, choose this button. Managers can also select the added time data field before submitting time to NetSuite.
             
         -   **Require selection in Time & Attendance**\- If you want to show this field as required, choose this button.
             

## Setting up Employees for WFM {#subsect_32135750935}

After you've finished your NetSuite setup, set up the following employee configuration:

-   Set additional locations, other than their Primary Location, where they can work.
    
-   Set up the WFM jobs that they can do.
    
-   Assign the right access levels.
    
-   Send a welcome message to employees.
    

## Can Work at Locations {#bridgehead_8175722907}

Assign added locations where employees can work.

For more information, see [Employment](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0919022953.html).

## Jobs {#bridgehead_53175749538}

Assign any added jobs that employees can work.

For more information, see [Jobs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0819111329.html).

## WFM Access Levels {#bridgehead_63175843313}

Assign employees to WFM access groups or levels. All employees start at the lowest level, **Staff**.

For more information, see [Employee Access in WFM](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1102035209.html).

After you've set up your employees and they're ready to start using the platform, send a welcome email so they can create their usernames and passwords.
