To interact with this integration in Workforce Management (WFM) head to Config > Integrations and select Oracle Hospitality from the list. If you haven't set up an Oracle Hospitality Integration before, you'll be prompted to create a new one.

## Setting up a new integration {#bridgehead_1212043339}

To set up a new integration, go to the Oracle Hospitality integration area (if you don't have one set up already) or just click New from the menu on the left.

Enter a name for the integration-this helps you tell different Oracle Hospitality setups apart.

Enter the base URL (the one you see when you're logged into Oracle Hospitality Report and Analytics) e.g. [https://mta4-ohra.oracleindustry.com/](https://mta4-ohra.oracleindustry.com/)

Enter the auth URL (the one you see for the login page for Reporting and Analytics. e.g. [https://mta4-ohra-idm.oracleindustry.com/](https://mta4-ohra-idm.oracleindustry.com/)

Enter the username and password to generate the authentication token-they're only used for this step and aren't stored. You will need to generate an API account - see [https://docs.oracle.com/en/industries/food-beverage/back-office/20.1/biapi/obtain\_acct\_info.html](https://docs.oracle.com/en/industries/food-beverage/back-office/20.1/biapi/obtain_acct_info.html) for more information.

Once you click Authenticate, a configuration is created. See below for more information about editing a configuration and what settings need to be applied.

## Editing a configuration {#bridgehead_1212043409}

To edit a configuration, select Config from the menu on the left. Here, you can change the config name, update brands, set up sales and units fields, and view the URLs.

When you pick brands from the list, you'll see all active locations from those brands that you can link. In a franchise setup, this includes locations from a franchisee account.

You can choose what data the sales and units fields pull from-just pick the right options from the dropdown.

## Linking Locations {#bridgehead_1212043542}

To link locations in WFM to locations from Oracle Hospitality, select locations from the menu on the left. You'll see a list of locations from WFM on the left and a search box to find a location from Oracle Hospitality. If the location from Oracle Hospitality isn't in the search list, click 'Reload Locations' to update the list of linkable locations.

If a location is linked incorrectly, it can be unlinked by clicking Unlink next to the link option.

## Importing Guest Checks {#bridgehead_1212043600}

If you linked a locaion and need to import its historical data from Oracle Hospitality, you can refetch data tha automatic import missed.

To re-import guest checks, select 'Import Guest Checks' from the menu on the left. Choose the start and end dates, choose the locations, and WFM will queue up the task and update sales and units once it's done.

Note:

In a franchisee environment, a franchisee can only access the "Import Guest Checks" option for available locations in the WFM account.
