You can configure an email to be imported automatically into WFM. You can schedule the import from your POS or system automatically. Otherwise, you can manually email this data each day, week, or at any point.

Note:

Make sure each time row is correct based on the resolution that you set. Each row should be in a multiple of the start of the hour.

For example, refer to the following intervals:

-   **15-minute interval** - 11:00:00, 11:15:00, 11:30:00, 11:45:00, 12:00:00
    
-   **30-minute interval** - 11:00:00, 11:30:00, 12:00:00
    
-   **60-minute interval** - 11:00:00, 12:00:00
    

Each interval contains sales and units from that time period. In the sample intervals, the row of 10:45:00 contains sales only from 10:31:00 to 10:45:00. WFM automatically aggregates sales throughout the day.

To automatically import an email into WFM, follow the procedures:

-   [Creating an Email Configuration](#subsect_1114042434)
    
-   [Formatting the CSV File for Email Sales Importer](#bridgehead_19171741310)
    
-   [Setting up Email Sales Importer](#subsect_1114042719)
    

## Creating an Email Configuration {#subsect_1114042434}

Before you set up Email Sales Importer, create the required email configuration.

#### To create an email configuration: {#procedure_1018050818}

1.  Go to Workforce Management.
    
2.  Go to Setup > Integrations.
    
3.  On the Integrations with external systems page, click **Email**.
    
4.  On the Active configurations page, click **Add**.
    
5.  Complete the fields.
    
    -   **Name** - Enter a name for the email configuration that you will use to identify it.
        
    -   **Stats period** - Enter the resolution of your data. Choose from 15 minutes, 30 minutes, or 60 minutes.
        
    -   **Import as** - Select the type of data you want to import, either **Actual** or **Forecast**.
        
    -   **Location matching** - Select the location naming convention that will be applied on the CSV file.
        
        The CSV file can contain one or more locations. WFM determines the locations based on what you select from the **Location** field.
        
        Following are the Location matching options:
        
        -   **WFM Location ID** - Needs to match the WFM location ID. This ID will appear beside the location names in the location selection.
            
        -   **WFM Location name** - Needs to match exactly with the location name in WFM.
            
        -   **Custom ID** - Needs to match the WFM location **Custom ID**. You can change or set the custom ID for each location at Setup > Locations > Select a location > Custom ID. This ID will appear next to the location names in the location selection.
            
    -   **Locations** - Select the locations that will be added in the CSV file.
        
    -   **Contact** - Enter the email address to contact if there are any import failures.
        
6.  Click **Save**.
    
    The configuration window closes.
    
7.  Click **Show keys**.
    
8.  To verify your identity, enter your password.
    
9.  Note the secret key.
    
    Warning:
    
    Do not share this key with unauthorized people.
    

## Formatting the CSV File for Email Sales Importer {#bridgehead_19171741310}

You can format your statistical data on a CSV file to set it up for the email sales importer.

On the CSV file, enter the information using the headers or columns on the table.

Important:

Enter the header names as they are shown on the table. The headers are case-sensitive and must be exact.

| Header | Description |
| --- | --- |
| location | This value tells WFM which location the row belongs to, based on your location matching setting. |
| date | This header shows the relevant date of the data according to the ISO-8601 format **YYYY-MM-DD**. For example, enter **October 31st, 2023** as **2023-10-31**. |
| time | This header shows the time the data begins in the ISO-8601 string format **hh:mm:ss**. For example, enter **11:30 pm** as **23:00:00**. |
| sales | Enter the total sales amount. It can contain **0** or any positive or negative number. Leave the cell blank if there's no data. |
| units | Enter the total unit count. It can contain **0** or any positive or negative number. Leave the cell blank if there's no data. |

The following table is an example of a CSV file you can use to import data with location matching.

| location | date | time | sales | units |
| --- | --- | --- | --- | --- |
| 1 | 2017-08-18 | 10:00:00 | \- | \- |
| 1 | 2017-08-18 | 10:15:00 | 0 | 0 |
| 1 | 2017-08-18 | 10:30:00 | 25.22 | 5 |
| 1 | 2017-08-18 | 10:45:00 | 33.54 | 5 |

## Setting up Email Sales Importer {#subsect_1114042719}

After you've set up your email, generated the secret key, and formatted your data on a CSV file, you can set up the email sales importer.

#### To set up email sales importer: {#procedure_1018051541}

1.  Schedule an email to **stats@adiinsights.com** and attach a CSV file with your statistical data.
    
2.  In the subject line, use the format **WFM-IMPORTER:<secret key>** . Make sure to use the secret key you generated earlier.
    
    For example, a complete subject heading is **WFM-IMPORTER:12345678-1234-1234-1234-123456789012**.
