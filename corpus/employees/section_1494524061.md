Time-off types let you define the different categories of leave your employees can take.

For example, you can create a time-off type for vacation and another time-off type for sick leave. These time-off types should be consistent with your company's policies.

You can create as many time-off types as you need to match your company's policies. You can also add multiple rules to each type for different stages of an employee's tenure. For more information, see [Time-Off Rules](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1494524322.html).
