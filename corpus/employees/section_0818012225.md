After you have created a brand there is always the option to go over what you have created and make any changes to your brand.

First of all you will need to go to Setup > Brands and select the brand you want to edit.

From here it will take you to the same page as New Brand.

## Editing {#subsect_24132545311}

Now you are dealing with all of the details that you originally had set for the brand. You can select which section you would like to edit by selecting the relevant tab name.

For more information, see [Creating a New Brand](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0818125948.html).
