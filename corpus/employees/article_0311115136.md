With Workforce Management (WFM), you can streamline shift scheduling, track time and attendance across your workforce, and calculate wages. You may use WFM to access, enter, and share employee and shift data across different platforms.

## Applications {#subsect_0311115910}

You can access WFM features and data using the following applications:

-   Workforce Management SuiteApp
    
-   [Stand-alone WFM website](https://see.adiinsights.com/)
    
-   SuitePeople Time Clock for Windows
    
-   WFM apps
    
    -   NetSuite Workforce Management for Android and iOS
        
    -   NetSuite Time Clock for Android and iPadOS
        

## Operating Systems and Minimum Requirements {#subsect_0312120121}

Refer to the following help topics:

-   [Minimum Requirements for SuitePeople Time Clock Mobile Apps](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_0917112543.html)
    
-   [Minimum Requirements for WFM Mobile Apps](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0204054156.html)
    

## Roles and Permissions {#subsect_0312120224}

After the Workforce Management SuiteApp is installed to a NetSuite account, users may access WFM features using the Accounting Center or Employee Center roles. WFM also provides the SuitePeople WFM Integration role for users setting up an integration.

If employees need access to other roles, WFM permissions must be added on those roles. For more information, see [Assigning WFM Permissions to Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_25214132264.html#subsect_1120034937).

## Personal Information {#subsect_0312120312}

The following table shows personal identifiable information captured and processed in WFM solutions.

| Personal Information | Specific Data |
| --- | --- |
| Personal details | Name, date of birth, gender, marital status, number of children, names of children |
| Personal contact details | Home address, home telephone or mobile number, e-mail address, password, pin code |
| Photos or images | Profile images and punch-in images |
| Employee ID | Employee or staff ID |
| Wages | Salary and rates |
| Web attributes | IP addresses and visited pages |
| Electronic identifiers | Platform name, version, model, device fingerprint, and host operating system |
| Geolocation | GPS coordinates |

## Biometric Data {#subsect_0312120602}

You can set up Time Clock for Windows to capture and record biometric data, like fingerprints, for employee punch-in.

## Security Settings {#subsect_0312120642}

You can enable two-factor authentication (2FA) to add a layer of security to your account.

-   To enable 2FA for the WFM SuiteApp and stand-alone website, refer to Security Settings in WFM.
    
-   To enable 2FA for Time Clock for Windows, refer to Enabling Two-Factor Authentication in SuitePeople Time Clock for Windows.
    

## Punch-in Authentication Methods {#subsect_0312120724}

WFM provides multiple methods to authenticate users. Employees can punch in using a pin code, a finger scan, either one, or both methods.

Authentication options may vary across different applications and locations. In some locations, employees may be limited to certain authentication methods to meet regulatory requirements.

In Time Clock for Windows, managers can set up authentication methods for employees. For more information, see [Managing Settings in SuitePeople Time Clock for Windows](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0918111029.html#subsect_31103520781).

## Time Clock Device Activation {#subsect_0312120813}

Installing SuitePeople Time Clock require managers to generate an activation code for each device you add. Activation codes are generated on the WFM SuiteApp or stand-alone website. You can also deactivate devices on the SuiteApp or site.
