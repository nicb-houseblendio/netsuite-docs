Employees should be imported from NetSuite. There may be a requirement to import employees that aren't available in NetSuite, such as contractors. You can conduct a bulk import of your employees into WFM using the Employee Importer. You can create or update multiple employees at a time.

This feature is available for Finance and General Manager user groups.

To import employees, go to Setup > Employees > List and then click **Import**.

Before importing, prepare a CSV file with the list of employees. Drag that file into the box or click the box and select the file.

Note:

WFM will automatically detect if there are headings in the file and check the **First row is headers** box for you.

Here is an example file that you can set up columns for:

![Importing staff - columns](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/EmployeeManagement/Employees/Staff/Staff_Import_Columns.png)

Note:

Mobile and date of birth fields are optional. If you're adding employee addresses, ensure that the country code and state are included as separate columns.

The sample image above is a common example of data you can import when setting up employees for the first time. Please make sure that the locations, classifications, and jobs match exactly as they are set up in WFM. This includes capitalizations and making sure there are no extra spaces.

If you want to import employee wages, you'll need to make sure you have wages set up in your WFM account first.

After you've uploaded your CSV file, review the field mapping to WFM fields.

WFM matches fields based on your column headers. However, some might not be automatically selected. If this is the case, **Do not use** appears in the dropdown. Click that and then select the correct WFM field.

If a field isn't available, it's already selected for another column. Please ensure that you've selected the correct fields.

Underneath the header mapping, the first few rows are displayed as an example. Below that, a bigger example of one employee appears with a summary so that you can ensure that the mapping is correct.

Note:

Ensure that 'Date format for CSV' matches the date format in your CSV, otherwise dates of birth and start dates will import incorrectly.

After you've confirmed that the import mapping is correct, click **Begin** and your employees' details will either update automatically or be entered into WFM.

## Other notes {#bridgehead_8161026340}

Round decimal places is a helpful checkbox if you're importing/updating leave balances. This means we'll round any extra trailing decimals.
