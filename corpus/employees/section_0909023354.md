After setting up your wage agreement, classifications, and conditions, you can configure the minimum hours that employees need to work based on their employment status and type of day worked.

#### To set up minimum hours:

1.  Open the wage agreement. See [Accessing Wage Agreements](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0807100528.html#subsect_0903110736).
    
2.  Click the **Minimum Hours** subtab.
    
3.  Click **\+ Add Minimum Hours**.
    
4.  On the Create new Minimum Hours Name window, complete the fields.
    
    -   **Employment status** - Select the status that requires minimum hours set up.
        
    -   **On days that are** - Select the type of day that the minimum hours apply, either regular or public holiday.
        
    -   **Minimum shift length** - Enter the number of hours.
        
    -   **Effective from** - Select the start date when the minimum hours apply.
        
5.  Click **Save**.
