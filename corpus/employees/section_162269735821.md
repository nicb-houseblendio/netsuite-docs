You can create an employee change request for transfers from the employee record.

#### To create an employee change request for transfers:

1.  Go to _Lists > Employees > Employees_.
    
2.  Next to the employee you want to create a transfer change request for, click **View**.
    
3.  From the **Actions** list, select **Create Employee Change Request**.
    
4.  From the **Change Request Type** list, select a transfer change request type.
    
5.  On the request form, complete the following fields:
    
    -   From the **New Location** list, select the location of the employee's new job.
        
    -   From the **New Department** list, select the department of the employee's new job.
        
    -   From the **New Supervisor** list, select the employee's new supervisor.
        
    -   From the **New Job** list, select the employee's new job.
        
    -   In the **Proposed Date** field, enter or select a date in the future.
        
        This date is used to apply the change as an effective-dated change. If your role has the permissions, you can edit this date up until the change status of Completed, Declined, or Expired.
        
    -   In the **Justification** field, enter your reason for requesting this change.
        
6.  Click **Submit**.
