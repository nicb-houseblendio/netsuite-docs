-   Get to know the phone app. Learn how to view your shifts, trades, and notifications.

## Swap Shift: Staff agree on a Swap with Manager Approval {#subsect_89114420093}

-   If enabled in your account, learn how Staff can Swap Shifts with one another. See the workflow from Staff to Manager, ending in the Manager reviewing the potential cost differences and approving the Swap.
    
    If it's enabled in your account, see how employees can swap shifts with each other. The workflow goes from employee to manager, with the manager reviewing any cost differences and approving the swap.
    
-   [In this video](https://videohub.oracle.com/media/t/1_tgltrh6l), see how the Manager can deny a swap request.
    
    The employee gets notified and can pick up a different shift instead, which sends a new swap request to the manager to approve or deny.
    

[Swap Shift](https://videohub.oracle.com/media/Swap%20Shift/1_fupz1c0v)

## Fill Shift {#subsect_23114610019}

-   If an employee can't make their shift or doesn't show up, use WFM or the phone app to quickly find a fill-in. See how the manager can start a fill shift and consider cost differences to make the best decision.
    

[Find a shift Fill-in](https://videohub.oracle.com/media/t/1_kyewfqij)

## Drop Shift: Staff initiates a Drop and Staff picks it up with Manager approval {#subsect_81114738662}

-   If it's enabled in your account, see employees can start a drop request from the phone app if they can't make their shift. The workflow goes from the employee starting the drop request to the manager reviewing it and finding a fill-in.
    
-   [In this video](https://player.vimeo.com/video/432999420), see how a manager can deny a drop request.
    
    Note:
    
    This video shows Drop Pre-approval turned on. If you turn it off, the initial manager approval is skipped. When a staff member drops their shift, it automatically sends a request to all available employees. If someone offers to pick it up, the manager gets notified to approve or deny. You can change this setting in Setup > WFM Phone App.
    

[Drop Shift Approved](https://videohub.oracle.com/media/t/1_fdk4evv9)

## Approved Shifts {#subsect_70114957439}

-   If the feature is enabled in your account, employees can see their approved shifts in the phone app.
    
-   You can also let staff confirm or dispute their time with attestation. To learn more, see [Attestation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1019104631.html).
