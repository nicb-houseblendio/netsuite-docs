The following section outlines how customizations change when Advanced Employee Permissions is enabled.

## Custom Roles {#subsect_1523644717}

Custom roles created in your NetSuite account aren't automatically updated with the employee permissions introduced by Advanced Employee Permissions. You need to manually update custom roles to include any of the required employee permissions. For more information, see [Setting Employee Access for Advanced Employee Permissions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1494598267.html).

## Roles Using the SuiteScript Permission {#subsect_1522343346}

Roles that have the Setup > SuiteScript permission can configure scripts to run as administrator, which bypasses the Advanced Employee Permissions feature. Before creating custom roles with this permission, make sure that the role has access to the information that is being exposed.

## Customization {#subsect_1522343380}

By default, any customization created with NetSuite Customization that are included with the standard Lists > Employees permission are preserved. If you customize the permission, the customizations created with Customization aren't preserved. If required, you need to manually add customizations to the custom Lists > Employees permission. For more information, see [Custom Advanced Employee Permissions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1494598577.html).
