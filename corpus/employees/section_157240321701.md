Standard Chief People Officer (CPO) and HR Generalist (HRG) roles get all permissions by default. You can then create custom versions of these roles and assign them to employees for SuiteApp access.

## Onboarding/Offboarding Plans Permissions {#subsect_157241710234}

To give access to custom roles that aren't created based on standard CPO or HRG roles, add these permissions manually:

| Custom Record | Level | Restrict |
| --- | --- | --- |
| Onboarding/Offboarding Plan | Full | \- |
| Onboarding/Offboarding Plan Task | Full | \- |
| Onboarding/Offboarding Template | Full | \- |
| Onboarding/Offboarding Template Task | Full | \- |
| Onboarding/Offboarding Task | Edit | Viewing and Editing |

#### To give a role permissions:

1.  Log in as an Administrator.
    
2.  Go to Setup > Users/Roles > User Management > Manage Roles.
    
3.  On the Manage Roles page, select a role.
    
    -   Click **Edit** to add permissions to a custom role.
        
    -   Click **Customize** to create a custom role from a standard role.
        
4.  On the Role page, look for the **Permissions** subtab, then click the **Custom Record** subtab.
    
5.  Select a permission from the list.
    
6.  Select the level of access and restrictions for the permission.
    
7.  Click **Add**
    
8.  Repeat steps 5 to 7 for each permission you want to add.
    
9.  Click **Save**.
    

## Guidelines for Granting Permissions for Custom Roles {#subsect_157241731030}

-   When the SuiteApp is upgraded or fixed, only standard roles get the updates. You'll need to manually push updates to custom roles.
    
-   If you made custom CPO and HRG roles before you installed the SuiteApp, you must manually add permissions to these custom roles.
    

For more information about setting permissions for a role, see [Setting Permissions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N288727.html).

## Change in Custom Scripts Using the Full Access Role {#subsect_161236078018}

Note:

The Full Access role has been deprecated. For more information, see [Full Access Role (Deprecated)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557254595.html).

Starting with Onboarding/Offboarding Plans version 1.02.1, custom scripts included in the SuiteApp run using the Administrator role. If you're upgrading to this version, update your script deployments to run as Administrator.

#### To update your script deployments:

1.  Go to _Customization > Scripting > Script Deployments_.
    
2.  Find the following OOP scripts and click **Edit**.
    
    -   OC Assignee Task UE
        
    -   OC Employee UE
        
    -   OC Checklist Access Su
        
    -   OC Checklist Su
        
    -   OC Onboarding Checklist UE
        
    -   OC Onboarding Template Checklist UE
        
3.  On the **Execute as Role** list, select **Administrator**.
    
4.  Click **Save**.
    

To continue setting up the SuiteApp, see [Setting Form Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157240322990.html).
