Important:

The ADP (US) integration is only available to accounts where it's already provisioned. It's not included with the current SuitePeople WFM solution.

With Workforce Management (WFM), you can export both leave and hours worked to a CSV file compatible with ADP (US).

For more information about setting up ADP (US) integrations in WFM, see the following help topics:
