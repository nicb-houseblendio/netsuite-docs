In Workforce Management, ensure that you map the NetSuite time bill records with the corresponding locations and jobs in WFM.

#### To map the time bill fields for the feature:

1.  Go to Workforce Management.
    
2.  Go to Setup > NetSuite Integration > Settings.
    
3.  Click the **Records** subtab.
    
4.  Beside the **Timebill** record, click **Fields**.
    
5.  Create a field to map the WFM location to the time bill record.
    
    1.  Beside the **Location** record, click **Edit**. Note the existing record type and field name.
        
    2.  Click **Create new field**.
        
        -   In the **Record type** field, enter the current type of the Location record.
            
        -   In the **Field name** field, enter the current type of the Location record.
            
        -   From the **Purpose** list, under Enhanced Timesheets Using Workforce Management Wage Rules, select **Mapping to Location**.
            
    3.  Click **Submit**.
        
6.  Create a field to map the WFM job to the time bill record.
    
    1.  Beside the **Job** record, click **Edit**. Note the existing record type and field name.
        
    2.  Click **Create new field**.
        
        -   In the **Record type** field, enter the current type of the Job record.
            
        -   In the **Field name** field, enter the current type of the Job record.
            
        -   From the **Purpose** list, under Enhanced Timesheets Using Workforce Management Wage Rules, select **Mapping to Job**.
            
    3.  Click **Submit**.
        

To read about the complete setup instructions for the feature, see [Setting Up Enhanced Timesheets Using WFM](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0812065915.html).
