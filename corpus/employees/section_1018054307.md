Important:

The Redcat POS integration is available only to accounts where it's already provisioned. It's not included with the current SuitePeople WFM solution.

To set up the Redcat integration, you will need a Redcat login with access to API reporting. If you're unsure if you have access, contact your Redcat representative.

## Creating a Redcat POS Integration {#subsect_0923114656}

Follow the procedure.

#### To create a Redcat POS integration:

1.  Go to Workforce Management.
    
2.  Go to Setup > Integrations > Redcat.
    
3.  On the Create page, complete the required fields.
    
    -   **Base url** - Enter tour Redcat cloud URL. Ensure that the format matches the following: **https://MYURL.redcatcloud.com.au**.
        
    -   **Credentials** - Enter the username and password from your Redcat representative.
        
4.  Click **Save**.
    

The following fields are available after you create the integration:

-   Sales field
    
-   Units field
    

The fields refer to sales and units in WFM. From each list, select the corresponding fields that you want to fetch from Redcat.

Note:

You can change this later, but you'll need to re-fetch any data you imported before.

## Setting up Additional Redcat Sale Types {#bridgehead_14181329317}

If you have additional sale types in Redcat and would like to use these in conjunction with your labor deployment model, contact NetSuite Customer Support.

After the sale types are set up, you'll see the **Sales subcategories** menu on the page. Subcategories are only for labor deployment.

For more information, see [Labor Deployment](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0818013733.html).

#### To set up additional Redcat sale types:

1.  Go to Workforce Management.
    
2.  Go to Setup > Integrations > Redcat.
    
3.  Select **edit** next to the sales or unit field where you want to add additional subcategories.
    
4.  (Optional) If you don't see what you're looking for, the field may already be mapped. To view linked fields, check the **Include items that are already linked** box at the top of the page.
    
5.  Map WFM locations to Redcat locations.
    
    1.  On the left-hand panel, click **Locations**.
        
        A list of locations appears.
        
    2.  From each location field, search the corresponding Redcat location.
        
    3.  Click **Save**.
        
        Redcat sales will start fetching to the linked units.
        

### Guidelines when Integrating Redcat with WFM {#subsect_0924121521}

Note the following guidelines.

-   Sales will update in WFM once per hour.
    
-   WFM fetches data at a 15-minute resolution.
    
-   Every time WFM fetches data, it pulls all of today's data. If sales change later (like when discounts are added), those updates will appear next time WFM fetches data.

## Fetching Historical Data from Redcat {#bridgehead_81181637373}

After you set up the Redcat integration you can fetch historical data to WFM. This data doesn't transfer automatically.

#### To fetch historical data from Redcat:

1.  Go to Workforce Management.
    
2.  Go to Setup > Integrations > Redcat.
    
3.  From the left-hand panel, click **Fetch stats**.
    
4.  Select the start and end date of the period you want to fetch. No date limit is applied.
    
5.  Select the locations with historical data that you want to fetch.
    

If you're fetching data for a short period, such as one location for one week, the page updates to let you know when the process is complete.

If you're fetching data for longer periods (such as for multiple locations for more than two weeks), a message appears to inform you the process is working in the background. WFM notifies you when the process is complete.
