You must enable the features in the table before you install the HR Dashboard Components.

## HR Dashboard Required Features {#subsect_156264034928}

| Subtab | Feature | Description |
| --- | --- | --- |
| Company | Departments | Shows the Headcount by Department chart in the Workforce Demographics portlet included in the SuiteApp. |
| Locations | Shows the Headcount by Location chart in the Workforce Demographics portlet included in the SuiteApp. |
| Employees | Termination Reason Tracking | Tracks termination reasons, termination details, and termination categories on the employee record. |
| Advanced Government-Issued ID Tracking | Tracks information about several default government-issued IDs. |
| Analytics | KPI Scorecards | Helps create KPI scorecards for your dashboard. |
| SuiteCloud | Custom Records | Helps access custom records provided by the SuiteApp. |
| Server SuiteScript | Helps run the scripts provided by the SuiteApp. |

For more information, see [Enabling Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N232138.html).
