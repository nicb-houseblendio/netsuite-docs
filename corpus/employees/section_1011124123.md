Link at least one leave type from WFM to MYOB.

WFM uses the linked leave types for the following:

-   To link leave types between WFM and MYOB when exporting payroll reports
    
-   To show the available leave balances in each employee's leave page in WFM
    

When employees request for a leave, they can immediately see their available leave balance on their employee leave page.

#### To link leave types to MYOB

1.  Go to Workforce Management > Setup > Integrations > MYOB.
    
2.  Click **Leaves**.
    
3.  Locate the leave type you need to link to MYOB.
    
4.  On the corresponding WFM leave type field, select the leave type in MYOB.
    
5.  Click **Link**.
    
6.  (Optional) If you want to unlink a leave type, click **Unlink** next to the corresponding type.
