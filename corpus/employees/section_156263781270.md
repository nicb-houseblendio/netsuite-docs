HR Dashboard Components provides saved searches of relevant HR metrics that you can set up to display in dashboard portlets.

## Default HR Dashboard Components Saved Searches {#subsect_156265014792}

By default, these saved searches are available to the default roles with access to HR Dashboard Components. If you want to allow custom roles to access these saved searches, see [Customizing HR Saved Searches for Custom Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156263784281.html).

| Saved Search Title | Saved Search ID | Description |
| --- | --- | --- |
| Diversity Report | customsearch\_hrdc\_diversity\_report | Shows active employees in each gender and ethnicity. |
| Expiring Driver's License | customsearch\_hrdc\_expiring\_dvr\_license | Shows employees whose driver's licenses are expiring for the month. |
| Expiring Passports | customsearch\_hrdc\_expiring\_passport | Shows employees whose passports are expiring for the month. |
| Expiring Work Visas | customsearch\_hrdc\_expiring\_passport | Shows employees whose work visas are expiring for the month. |

To set up the default saved searches to appropriate portlets, see [Adding Data from HR Saved Searches to Portlets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156263764475.html#subsect_156264713892).

## HR Dashboard Components Saved Searches for Custom Scorecard KPIs {#subsect_156265038088}

The following table illustrates the saved searches included in the scorecard configuration.

| Saved Search Title | Saved Search ID | Description |
| --- | --- | --- |
| First Year Voluntary Terminations | customsearch\_hrdc\_vol\_termination\_year | Shows list of employees who voluntarily left and worked for fewer than 365 days. |
| 90-Day Terminations | customsearch\_hrdc\_90day\_term | Shows list of employees who voluntarily left and worked for fewer than 90 days. |
| New Hires | customsearch\_hrdc\_new\_hires\_kpi | Shows a list of newly hired employees. |
| Terminated Female Employees | customsearch\_hrdc\_terminations\_female | Shows a list of terminated employees who are female. |
| Terminated Male Employees | customsearch\_hrdc\_terminations\_male | Shows a list of terminated employees who are male. |
| Terminations | customsearch\_hrdc\_terminations | Shows a list of terminated employees. |
| Total Active Female Employees | customsearch\_hrdc\_total\_active\_female\_em | Shows a list of active female employees. |
| Total Active Male Employees | customsearch\_hrdc\_total\_active\_male\_emp | Shows a list of active male employees. |
| Total Active Employees | customsearch\_hrdc\_total\_active\_emp | Shows list of active employees according to subsidiary. Active employees are employees whose records show the following:
-   The hire date is on or before the present date.
-   The termination date is empty, or it is after the present date.

Employees whose records show a hire date that is later than the termination date are rehired employees. They are also considered active. |
