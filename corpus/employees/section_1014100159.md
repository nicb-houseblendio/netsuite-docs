## SuitePeople Time Clock for Windows Limitations {#subsect_0528123817}

Following are some known limitations when using SuitePeople Time Clock for Windows:

-   The Windows app is designed for use with the Futronics FS88H device. Right now, it doesn't work with other fingerprint scanners.
    
-   Fingerprint quality is different for everyone, and sometimes the Windows app can't capture prints because of physical issues or other reasons. If that happens, employees can use the PIN only option. For more information, see [Setting up SuitePeople Time Clock for Windows](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0918111029.html).
