Refer to the following navigation table to access Onboarding/Offboarding Plans.

| Task | Page Name | Accounting Center (CPO and HRG) | Classic Center (Administrators) |
| --- | --- | --- | --- |
| Create a new plan | Onboarding/Offboarding Plan | Payroll and HR > Lists > Onboarding/Offboarding Plan > New | Lists > Employees > Onboarding/Offboarding Plan > New |
| View the list of plans | Onboarding/Offboarding Plan List | Payroll and HR > Lists > Onboarding/Offboarding Plan | Lists > Employees > Onboarding/Offboarding Plan |
| Create a new template | Onboarding/Offboarding Template | Setup > Onboarding/Offboarding > Template > New | Setup > Onboarding/Offboarding > Template > New |
| View the list of templates | Onboarding/Offboarding Template List | Setup > Onboarding/Offboarding > Template | Setup > Onboarding/Offboarding > Template |

For more information about using plans and templates, see [Working With Onboarding and Offboarding Plans](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157240334231.html).
