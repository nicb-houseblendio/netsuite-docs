When you enable the Termination Reason Tracking feature, NetSuite provides several default termination reasons, but you can change them or create your own. For more information, see [Default Termination Reasons](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4531519241.html).

The Termination Reasons page shows all of the termination reasons in your account. If you don't want to use a reason, but it has been used in the past, then you can make it inactive. Select the **Show Inactives** box to show all reasons.

## Adding Termination Reasons {#subsect_156986656404}

Use the following procedure to add a termination reason.

#### To add a termination reason:

1.  Go to _Setup > HR Information System > Termination Reasons > New_, or click **New Termination Reason** on the Termination Reasons page.
    
2.  Enter a **Name** for the reason. Select a **Termination Reason Category** (Voluntary, Involuntary) from the list.
    
3.  To make the reason inactive, check the **Termination Reason is Inactive** box.
    
4.  To save and return to the Termination Reasons page, click **Save**. To save and create another new termination reason, click the down arrow, and click **Save & New**.
    

## Editing Termination Reasons {#subsect_156986658595}

Use the following procedure to edit a termination reason.

#### To edit a termination reason:

1.  Go to _Setup > HR Information System > Termination Reasons_.
    
2.  Click **Edit** beside the termination reason you want to edit.
    
3.  Enter a **Name** for the reason. Select a **Termination Reason Category** (Voluntary, Involuntary) from the list.
    
4.  To make the reason inactive, check the **Termination Reason is Inactive** box.
    
5.  Click **Save**.
