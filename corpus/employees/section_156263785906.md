At the end of each day, the SuiteApp runs a script that helps compute its daily metrics. This event begins at 11:30 p.m. Pacific Time (UTC - 8).

If your NetSuite account is set to use a different time zone, you must adjust the start time of the scheduled script. This is also true if you want to change the time the script runs.

#### To customize HR saved searches for custom roles:

1.  Log in as an Administrator.
    
2.  Go to Customization > Scripting > Script Deployments.
    
3.  In the Script filter, select **HRDC Create Total Active Emp Tracker**.
    
4.  In the ID column, locate **customdeploy\_hrdc\_active\_emp\_tracker\_ss**. Click **Edit**.
    
5.  On the **Schedule** subtab, locate the **Start Time** field
    
6.  Select the start time you prefer.
    
7.  Click **Save**.
