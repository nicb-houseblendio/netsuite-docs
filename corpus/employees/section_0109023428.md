Currently, sales subcategories are only imported from Redcat.

Within a brand, select **Stats Types**.

Here you can add subcategories to an existing stats type (Sales/Units), and these can be different between sales or units.

To add a new one click **Add new**.

To change the name, click it and type in what you want.

To deactivate click **Deactivate**.

If you've got deactivated ones, you can reactivate them.

You can set these up to drill down to whatever level of detail you need.

## Deployment by Sales Subcategories {#subsect_0506122313}

Here are the actions for deployment by sales subcategories.

-   Click a button to create a new team rule.
    
-   Choose the team and the subcategory, knowing that Sales or Units is also classed as a subcategory.
    
-   If you select a subcategory with children, deployment adds up that subcategory and all its children.
    

If you create more than one model for a team, each is calculated separately and then added together for staffing needs.

For example: In a restaurant you may build a model for the FOH team based on dine-in units and a second model based on takeaway units.

When you need an employee in either model, they'll be added to the team's staffing needs.
