To install Workforce Management, follow the steps in the table.

| Step | Related Help Topic |
| --- | --- |
| 1\. Log in as a NetSuite administrator. | [Roles and Accounts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N295370.html) |
| 2\. Complete the prerequisites. | [Prerequisites](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3223731685.html) |
| 3\. Install the Workforce Management SuiteApp. | [Installing the SuitePeople Workforce Management SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_24214051946.html) |
| 4\. Assign the SuitePeople WFM Integration role. | [Assigning the SuitePeople WFM Integration Role](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_25214132264.html) |
| 5\. Deploy User Event Scripts in NetSuite. | [Deploying User Event Scripts in NetSuite](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1214216333.html) |
| 6\. Configure additional permissions in NetSuite. | [Configuring Additional Permissions in NetSuite](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0412121639.html) |
| 7\. Integrate WFM with NetSuite | [Integrating Workforce Management with NetSuite](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_36112903912.html) |
