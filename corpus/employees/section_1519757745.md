Warning:

This feature exposes personal information about employees and should only be enabled for users who are authorized to access all employee data.

Workforce Analytics gives HR the tools to measure and analyze your company's headcount, hiring, and turnover trends. It compiles your data and converts it into detailed HR metrics that you can see on the Headcount Analysis and Turnover Analysis pages.

Workforce Analytics is available to roles that have the Workforce Analytics permission. By default, NetSuite automatically adds this permission to the standard Chief People Officer (CPO) and HR Generalist roles, with View access.

You can also create custom roles that include this permission. For more information, see [Customizing or Creating NetSuite Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N285937.html) and [Workforce Analytics Permission Requirements](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1548186638.html).

Watch the following help video for information about using the Workforce Analytics feature:

<a id="kaltura_player_93"></a>

Workforce Analytics enables you to:

-   View headcount, hire, and turnover trends in your company. For more information, see [Headcount Analysis Trends](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1514926188.html).
    
-   Get a quick overview of which employees are leaving and why. For more information, see [Turnover Analysis Trends](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1514926529.html).
    
-   Filter and segment data by gender, employee type, department, location, or subsidiary (with NetSuite OneWorld). You can also filter by subdepartment and sublocation.
    
-   View custom snapshots of headcount and turnover trends for a specific quarter. For more information, see [Headcount Analysis Snapshots](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1514926273.html) and [Turnover Analysis Snapshots](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1514926552.html).
    

Note:

Workforce Analytics supports standard fields such as hire date and termination/release date, but doesn't use custom fields.
