Important:

The AdiOrg feature is available only to accounts where it is already provisioned. It's not not included with the current SuitePeople WFM solution.

In Workforce Management (WFM), the AdiOrg feature helps large organizations manage several brands and enables organizations to generate specific reports.

## AdiOrg Reports {#subsect_0909065354}

Refer to the table for the reports available with AdiOrg.

| Report | Description |
| --- | --- |
| Variance | Lets you sort locations by region and sub-region. It also lets you see your scheduled shifts, actual shifts, the variance of your wage cost, hours worked, sales, units, labor cost percentage, and other KPIs. For more information, see [Variance](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0723104651.html#subsect_0724121428). |
| Shift | Lets you view rostered or actual shifts from any of your roster units. |
| Labor | Lets you see a location's worked hours, leave, and total wages broken down by hours, amounts, and rate. |
| Hourly Breakdown | Lets you view the number of hours worked at a selected location between two chosen dates. |

## Granting Access to AdiOrg {#section_0922125651}

Access to AdiOrg is managed separately from Workforce Management.

You can grant access to AdiOrg by doing one of the following:

-   Grant access to an existing WFM user
    
-   Create a new user
    

#### To grant access to an existing WFM user:

1.  Go to Workforce Management.
    
2.  Go to AdiOrg > Manage.
    
3.  Select **Create from Adi User**.
    
4.  Select the user you want to give access to and select **Permit access to AdiOrg**.
    
5.  Select the location you want to give them access to.
    
6.  (Optional) Customize the tags assigned to a location.
    
7.  Click **Save**.
    

The next time the WFM user logs in, they can see a menu item for AdiOrg.
