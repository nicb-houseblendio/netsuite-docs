This section includes recommendations about the installation and management of the WFM solution and its applications. Only users with administrator access should handle installation.

## Installer Considerations {#subsect_0312120913}

To securely install WFM applications, refer to the following guidelines:

-   **SuitePeople Workforce Management SuiteApp** - Install the latest version available on the SuiteApp Marketplace. For more information, see [Installing the SuitePeople Workforce Management SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_24214051946.html).
    
    Stop using older Adi Insights SuiteApps, Adi Insights (Bundle ID: 317115) and Adi Insights - Embedded (Bundle ID: 401708), in your account. Be aware that, when your NetSuite account is upgraded to 2025.1, you won't be able to log in and use the older Adi Insights SuiteApps to access WFM features.
    
-   **SuitePeople Time Clock for Windows** - Install Time Clock for Windows only from the Workforce Management SuiteApp or stand-alone website. For more information, see [Installing SuitePeople Time Clock Components for Windows](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_95102310959.html).
    
-   **WFM apps** - Install the WFM apps only from the official Apple and Google Play stores. See [Operating Systems and Minimum Requirements](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0311115136.html#subsect_0312120121).
    

## Account Password Considerations {#subsect_0312121134}

When providing access to WFM for employees, administrators or managers can send an email with their username and a link to reset their password.

When resetting a password, note the following criteria:

-   It can't be similar to other personal information, such as names, addresses, or birthdays.
    
-   It can't be a commonly used password.
    
-   It needs at least 10 characters.
    
-   It should include letters, numbers, and special characters.
    
    -   It can't be all numbers.
        
    -   It needs at least one lowercase letter, one uppercase letter, one number, and one special character.
        

Password reset options are also available on the WFM SuiteApp or stand-alone website login pages.

## Pin Code Considerations {#subsect_0312121216}

WFM assigns randomly generated pin codes to employees, and managers can help employees change their codes. Pin codes can be 4, 5, or 6 digits long. When changing a code, managers should opt to set up a 6-digit code to enhance security.

## Time Clock for Windows Installation Security {#subsect_0312121232}

Note the following information when installing Time Clock for Windows:

-   Use Time Clock with devices that meet minimum hardware and software requirements.
    
-   When installing Time Clock for Windows, ensure that you have system administrator rights.
    
-   Install Time Clock updates only from the application.
    
-   Be aware that the Time Clock installer includes the Microsoft Visual C++ Redistributable component during installation. This component installs the essential libraries needed for the application to work smoothly on the computer or device.
    
-   If you use the Futronic fingerprint scanner, use the installer to install the required components.
    
-   After Time Clock is installed, data is synced with the WFM servers. When offline, WFM data is stored in an encrypted local database until the application goes online and uploads it to the central server.
    

## WFM Mobile Apps Installation Security {#subsect_0312121432}

Note the following guidance when installing WFM mobile apps:

-   To maximize app security, avoid installing and using WFM mobile apps on rooted devices. These devices may be more exposed to malware attacks and other security threats.
    
-   Use WFM mobile apps with the devices that meet minimum hardware and software requirements.
    
-   After installing the mobile apps, always keep the operating systems up to date.
    
-   If possible, enable the auto-update feature on mobile devices to receive new versions on time.
