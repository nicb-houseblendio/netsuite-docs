Onboarding/Offboarding Plans lets you edit, inactivate, or delete an existing template.

## Guidelines for Managing Templates {#subsect_157241444921}

-   If you change a template after it was associated with a plan, your changes apply only to future plans that are created with that template.
    
-   You can't delete a template if a plan uses it. Delete the plan first, then delete the template.
    
-   If you don't want to use a template, but can't delete all plans associated with it, you can mark it as inactive. Inactive templates can't be used for new plans.
    

#### To manage a template:

1.  Go to the Onboarding/Offboarding Template List page. For instructions, see [Accessing the SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157240329823.html).
    
2.  Locate the template name. Click **Edit**.
    
3.  Choose the task you want from the following table.
    
    | Task | Instructions |
    | --- | --- |
    | Edit the template | Edit the fields and columns. |
    | Inactivate the template | Check the **Inactive** box. |
    | Delete the template | Point to the Actions list. Click **Delete**. |
    
4.  Click **Save**.
