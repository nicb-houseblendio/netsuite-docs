You can update a time-off plan at any time. After you save it, the system updates any future changes to match the new settings.

#### To edit a time-off plan:

1.  Go to _Setup > HR Information System > Time-Off Plan_.
    
2.  Click **Edit** next to the time-off plan you want to change.
    
3.  When you're finished editing, click **Save**.
    

Note:

If you're removing rules from a plan, you can't delete the last rule if the time-off plan is assigned to employees. You need to either add another rule or unassign the plan from all employees before you can delete it.
