To set up the HR Dashboard Components, follow the steps in the table.

| Step | Related Help Topic |
| --- | --- |
| 1\. Log in as a NetSuite administrator | [Roles and Accounts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N295370.html) |
| 2\. Complete the prerequisites | [HR Dashboard Components Prerequisites](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156263761719.html) |
| 3\. Install the HR Dashboard Components SuiteApp. | [Installing HR Dashboard Components](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156263762598.html) |
| 4\. Grant permissions to custom roles that will use the dashboard. | [Granting HR Dashboard Components Permissions to Custom Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156263763599.html) |
| 5\. Set up content on your dashboard. | [Setting up HR Dashboard Components on Your Dashboard](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156263764475.html) |

To view a list of scripts used in the SuiteApp, see [HR Dashboard Components Scripts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156756816079.html).

Note:

Currently, the HR Dashboard Components SuiteApp supports only US and UK English languages.
