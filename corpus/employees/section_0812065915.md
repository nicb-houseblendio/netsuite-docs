This topic explains how employees with the Administrator role can set up the feature.

Follow the steps in the table.

| Step | Related Help Topic |
| --- | --- |
| 1\. Log in as an Administrator. | [Roles and Accounts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N295370.html) |
| 2\. Complete the prerequisites. | [Prerequisites of Enhanced Timesheets Using WFM](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0812082945.html) |
| 3\. Map time bill fields. | [Mapping Time Bill Fields for Enhanced Timesheets Using WFM](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0827011145.html) |
| 4\. Enable the feature. | [Enabling Enhanced Timesheets Using WFM](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0812083008.html) |
| 5\. Assign custom role permissions. | [Granting Permissions for Enhanced Timesheets Using WFM](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0812083030.html) |
| 6\. Configure options for employees. | [Configuring Enhanced Timesheets Using WFM](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0812083043.html) |
| 7\. (Optional) Disable the feature. | [Disabling Enhanced Timesheets Using WFM](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0812083020.html) |
