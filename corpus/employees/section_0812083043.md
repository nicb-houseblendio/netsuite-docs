After Enhanced Timesheets Using Workforce Management Wage Rules is enabled, the following general configuration options are available.

| General Use Case | Configuration | Changes on Timesheets |
| --- | --- | --- |
| Most employees have different work schedules | Require employees to enter work and break times | On the time entry window for each day, employees must enter shift and break times |
| Most employees have the same work schedule | Set default shift and break times | On the time entry window for each day:
-   For shifts that follow the default times, employees only need to enter the number of hours worked
-   For shifts that differ from the default times, employees can enter their actual shift and break times

 |

The person in your company who manages Workforce Management (WFM) and NetSuite, such as a manager or bookkeeper, can adjust these configurations.

#### To configure enhanced timesheets using WFM:

1.  Go to Setup > Accounting > Accounting Preferences.
    
2.  On the **Time & Expenses** subtab, go to **Time Tracking**.
    
3.  Choose the use case that applies to your organization.
    
    1.  If most employees have different schedules, you may require employees to enter shift and break times. If you choose this option, you cannot enter default shift and break times. See **Step 4**.
        
    2.  If most employees have the same schedule, you may set default shift and break times. See **Step 5**.
        
4.  If you want to require employees to enter shift and break times, check the **Require Employees to Enter Shift Start and End Times on Timesheets** box.
    
    When you check the box, the entries for default shift and break times are disabled.
    
    Important:
    
    This requirement will only be enforced for time entries that may require overtime calculation. Time entries that logically don't qualify for overtime, such as time-offs, are not included.
    
5.  If you want to set default shift and break times:
    
    1.  Clear the **Require Employees to Enter Shift Start and End Times on Timesheets** box.
        
    2.  In the **Default Shift Start Time** field, enter the default time when the employee shift starts. This time is used to calculate the cost of the shift when employees are not required to enter their shift start time.
        
    3.  (Optional) If you do not need to set default break preferences, check the **Disable Break** box.
        
        When this field is checked, the **Default Hours Worked Before Break and Default Break Duration in Hours** fields are both set to 0.
        
        If needed, employees can still enter their actual break times to override this default.
        
    4.  In the **Default Hours Worked Before Break** field, enter the default number of hours that an employee has to work before they are required to take a break during their shift. Enter a value greater than 0 but less than 24 in decimal (4.5) or hour and minute (4:30) format.
        
    5.  In the **Default Break Duration in Hours** field, enter the default length of the breaks that an employee should take after they have worked the prescribed number of hours during their shift. Enter a value greater than 0 but less than 24 in decimal (1.5) or hour and minute (1:30) format.
        
6.  Click **Save**.
    

To read about the complete setup instructions for the feature, see [Setting Up Enhanced Timesheets Using WFM](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0812065915.html).
