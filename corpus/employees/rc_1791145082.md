You can edit a performance metric anytime. Any changes you make will directly affect any goals linked to it.

When you inactivate a performance metric, employees can't pick it for new goals, but anyone already using it for existing goals can keep using.

You can delete a performance metric only if the metric isn't associated with a goal.

#### To edit, inactivate, or delete a performance metric:

1.  Go to _Setup > Performance Management > Performance Metrics_.
    
2.  Beside a metric, click **Edit**.
    
3.  Do one of the following:
    
    -   To edit the metric, make your changes and click **Save**.
        
    -   To inactivate the metric, check the **Inactive** box and click **Save**.
        
        To view inactive performance metrics, check the **Show Inactives** box on the Performance Metrics list page.
        
    -   To delete the metric, from the **Actions** list, select **Delete**. When asked to confirm, click **OK**.
