You can delete existing employee change requests if you have the Employee Change Request permission access level at Full. For more information, see [Employee Change Requests Permission Requirements](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156164430223.html).

Note:

When you delete an employee record, employee change requests for that employee are also deleted. For more information, see [Deleting Employee Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1494515524.html).

If you want to make an employee change request unavailable, you can make it inactive. For more information, see [Editing or Inactivating an Employee Change Request](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156330887492.html)

#### To delete an employee change request:

1.  Go to _Setup > HR Information System > Employee Change Requests_.
    
2.  Click **Edit** next to the employee change request you want to delete.
    
3.  On the request form, point to **Actions**, and click **Delete**.
