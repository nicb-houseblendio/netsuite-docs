Important:

The Employee Self-Service (ESS) Extended feature for Australia is available only to accounts where it's already provisioned. It's not included with the current SuitePeople WFM solution.

Employee Self-Service (ESS) Extended lets employees sign in to their WFM profiles and fill in their own financial information, eliminating the need for paper forms.

With ESS Extended, employees will have access to:

-   New tabs on their profile
    
    -   **Financial** - Employees can update and view their bank details, tax file number declaration, and superannuation fund details. This information will also carry over to payroll systems integrated with WFM.
        
        Only Finance/payroll and franchisee users will be able to see this tab on staff members profiles.
        
        Bank details and superannuation details will be filled in by employees upon onboarding, replacing current paper methods. This reduces paperwork and manual data entry. This data sync is ongoing.
        
        To know more about financial information available with ESS Extended, read [Financial Details for ESS Extended](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0919021123.html).
        
    -   **Visa details** - You can add visa details for selected employees. You'll get reminders when a visa is close to expiring.
        
    -   **Term breaks** - Employees on a Student Visa might be able to work extra hours over holiday periods, if they can show the correct required information. Managers can view & approve these Term break requests, so these employees can be scheduled on for extra hours over this period automatically. Please visit this page for more information regarding Term Breaks.
        
-   Updates to existing tabs
    
    -   **Personal** - Fields are added.
        
        -   **Education/Qualifications** - Employees, payroll employees, and managers can add this information. Any courses completed by employees, which you want to track, can be uploaded here.
            
        -   **Emergency Contacts** - Employees can enter emergency contacts upon employment. This provides quick access for managers to view this information if they need to during a shift.
            
    -   **Employment** - Employees can store employment documents like contracts, tax forms, visas, and job descriptions. Employees can remove and override or update documents with revised versions. An expiry date can be set to notify users when a document is about to expire.
