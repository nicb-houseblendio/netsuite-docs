From the Workforce Management page, click Setup, and then click Employees > List. You can sort the list by clicking on the table heading. Click it again to reverse the order. This list will sort based on:

-   WFM ID
    
-   First name
    
-   Last name
    
-   Preferred
    
-   Email
    
-   Mobile
    
-   Primary Location
    
-   Calculation type
    
-   Employment status
    
-   State
    
-   Country
    
-   Employed?
    
-   Payroll ID
    
-   Timesheet PIN
    
-   Group
    

To search for an employee, type their name in the search field.

By default, only current employees appear in this list. To filter the employee list by other parameters, select one from the dropdown list:

-   Only employed staff
    
-   All staff
    
-   Only terminated staff
    

To open the employee profile, click the employee's name. For more information, see [Viewing and Editing Employee Details](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0919020300.html).

## Viewing WFM Employee Headcount {#subsect_0204091643}

To keep track of the current number of WFM employees and count it against the provisioned number of employees, go to the Billing Information page.

Go to Setup > Company > View Billing Information.

On the **Billable Components** subtab, find **Workforce Management Employee**. You can compare the corresponding figures under the **Current Provisioned Qty** and **Current Used Qty** columns.
