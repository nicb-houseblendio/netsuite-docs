Linking agreements to ADP (US) can be done in the same way as linking payroll items in WFM.

To know more about these options, see [Linking Payroll Items in WFM](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1003104314.html).

The ADP Configuration Agreements page contain subtabs available for configuring conditions, allowances, penalties, and classifications.

#### To link agreements to ADP (US):

1.  Go to Workforce Management > Setup > Integrations > ADP (US).
    
2.  Click **Agreements**.
    
3.  Select the subtab that matches the agreement you want to link to ADP (US).
    
4.  After selecting the subtab, complete the required fields to configure items.
    
    The ADP Configuration Agreements page has fewer conditions than the Link objects to Payrollitems page. On the ADP agreements page, you can link items for the following conditions:
    
    -   Regular Hours
        
    -   Public Holiday
        
        -   Regular Hours
            
        -   Overtime Hours
            
        -   Hours 3 Code
            
        -   Hours 4 Code
            
    -   Weekend
        
    
    For more information about completing the fields, see [Linking Payroll Items in WFM](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1003104314.html).
