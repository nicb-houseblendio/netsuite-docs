As an Assignee to a task, you can do the following:

-   [Viewing Assigned Tasks](#subsect_157240804035)
    
-   [Updating the Status of Tasks](#subsect_157240805787)
    
-   [Adding Notes on Assigned Tasks](#subsect_157240806962)
    

If you use any standard role, and access a plan that is created for you, you're automatically set as an Assignee. You can only view, update, or add notes to tasks that are assigned to you. You can only view the complete list of tasks of other employee plans.

## Viewing Assigned Tasks {#subsect_157240804035}

As an Assignee, you can view tasks through the Onboarding portlet, the Reminders portlet or email notifications.

To view tasks using the Onboarding portlet, see [Using the Onboarding Portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161661453482.html).

The Reminders portlet shows notifications and how many tasks you have that are **Not Started** or **In Progress**.

#### To view assigned tasks on the Reminders portlet:

1.  Go to Home.
    
2.  On the Reminders portlet, click one of the following:
    
    -   Onboarding Tasks
        
    -   Offboarding Tasks
        
    
    Note:
    
    You'll need to add both reminders on the portlet to receive notifications. For more information, see [Updates Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157240324871.html).
    
3.  On the results page, find your task and click **Edit** or **View** to open it.
    

Employees and assignees get email notifications with links to plans. To better understand the notifications, see [Receiving Email Notifications](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157240337779.html#subsect_157240505682).

## Updating the Status of Tasks {#subsect_157240805787}

You can update your task status in the Onboarding portlet, the plan page, or the Reminders portlet results page.

To update tasks using the Onboarding portlet, see [Using the Onboarding Portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161661453482.html).

Note:

All tasks, including required and optional tasks, must be marked complete for the plan status to automatically set itself as **Completed**. Otherwise, the Coordinator has to update it manually. For more information, see [Managing Plans as a Coordinator](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157240752069.html).

#### To update the task status on the plan page:

1.  On the Onboarding/Offboarding Plan page, locate the task.
    
2.  In the **Task Status** column, select a status from the list.
    
    | Task Status | Description | Notes |
    | --- | --- | --- |
    | Not Started | All tasks start with this status by default. | \- |
    | In Progress | Select this status for tasks you've started to work on. | The assignee status changes from **Not Started** to **In Progress** if one or more task statuses are set to **In Progress** or **Completed**. |
    | Completed | Select this status for tasks you've finished. | The assignee status changes to **Completed** when all your tasks are set to **Completed**. |
    
3.  Click **Save**.
    

#### To update the task status from the Reminders portlet:

1.  On the Reminders portlet, click one of the following:
    
    -   Onboarding Tasks
        
    -   Offboarding Tasks
        
2.  To use inline editing, turn on the **Edit** switch.
    
3.  Locate the task on the list and click the status of the task to select a new status.
    

## Adding Notes on Assigned Tasks {#subsect_157240806962}

As an assignee, you can add comments or notes to each task. Other assignees assigned to these tasks can view and edit them too.

if the plan is for you, you can see notes added by assignees.

#### To add notes on assigned tasks:

1.  On the Onboarding/Offboarding Plan page, locate the task.
    
2.  In the **Notes** column, enter your comments about the task. You can enter a maximum of 300 characters in this field.
    
3.  Click **OK**.
    
4.  Repeat Steps 2 to 3 to add notes to other tasks on the plan.
    
5.  Click **Save**.
