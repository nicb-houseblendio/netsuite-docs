## Integrating Payroll with WFM {#subsect_41172748588}

Link WFM with NetSuite so they communicate and sync with one another.

#### To integrate payroll with WFM: {#procedure_0412053352}

1.  Go to the stand-alone WFM website at see.adiinsights.com.
    
2.  Go to Setup > Integrations.
    
3.  If you are using Infinet Cloud Payroll, select **SuitePeople** or **InfinetCloud Payroll**.
    
4.  Enter your NetSuite credentials used to access NetSuite when installing the WFM SuiteApp.
    
    1.  Enter your NetSuite username and password.
        
    2.  From the list, select **Production**.
        
    
    A list of NetSuite accounts the user has access to appears.
    
5.  Select the account that you used to install the WFM SuiteApp.
    
    Note:
    
    This list only shows accounts with the right roles assigned.
    

You've now successfully linked NetSuite and WFM.

Next, you'll see how to map your WFM user to your NetSuite user.

## Mapping a WFM User to Enable SuiteSignOn {#subsect_7174710859}

After you've linked WFM and NetSuite, map your own user credentials.

#### To map WFM users: {#procedure_0412055107}

You've now mapped your WFM user to your NetSuite employee record for SuiteSignOn.

1.  From the last step, go to the **Staff** tab on the left side of the screen.
    
2.  Find your WFM user. Click the search field next to the user and type the name of the NetSuite user that you set up.
    
3.  Select your name from the list.
    
4.  Click **Link**.
    

If you're using the HR or Payroll Manager NetSuite role and got an authorization error when you go to the **Process Time** subtab, log in with your NetSuite credentials.

After you map your NetSuite employee record with your WFM user credentials, you can go back to NetSuite and configure the account.

## Adding the WFM Portlet in NetSuite {#subsect_92175620842}

After you've mapped your WFM user credentials to your NetSuite employee record and returned to NetSuite, finish the setup.

To complete the setup, add the WFM portlet. The portlet lets you access and manage WFM without leaving NetSuite.

You can only add the portlet if the **Workforce Management** tab is available for your center and role. This tab is available for NetSuite roles using the Accounting or Employee Center. If you don't see the tab, see [Troubleshooting Missing WFM Tabs](#subsect_8181204808).

To continue adding the portlet, see the help topics:

-   [Setting Up the Workforce Management Portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_24214051946.html#subsect_0626110126)
    
-   [Dashboard Portlets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N576951.html)
    
-   [SuiteApp Portlets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4629724453.html)
    

After the portlet is configured you will see the following subtabs:

-   Dashboard
    
-   Availability
    
-   Shifts
    
-   Reports
    
-   Process Time
    
-   Setup
    

## Troubleshooting Missing WFM Tabs {#subsect_8181204808}

If your role uses the Accounting or Employee Center, the **Workforce Management** tab should show up by default.

If the tab is not available, perform the following actions:

-   If you have lots of tabs, check the right-hand extension menu.
    
-   Ensure that the SuitePeople Workforce Management SuiteApp is installed. For more information, see [Installing the SuitePeople Workforce Management SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_24214051946.html).
    
-   If you've already installed the SuiteApp and the tab still doesn't show up, check if it appears in the Center Tabs list for role's Center Type.
    

#### To check the Center Tabs list:

1.  Go to Customization > Centers and Tabs > Center Tabs.
    
    **Workforce Management** should show up in the list.
    
2.  If your role doesn't use the Accounting or Employee Center type, add a new center tab.
    

To create a new center tab, see [Creating Center Tabs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2890512.html).

To fill in the New Center Tab page, refer to the following information:

-   **Label** - Enter **Workforce Management**.
    
-   **ID** - Use the format custcentertab\_wfm\_center. For example, custcentertab\_wfm\_customer.
    
-   **Center** - Select the center for which you want to add the tab.
    
-   **Content subtab** - On the **Portlets** subtab, complete the following columns:
    
    -   **Type** - Select **Custom Portlet**.
        
    -   **Portlet** - Select **Center**.
        
    -   **Show** - Select **Yes**.
        

After you save the new tab page, the Workforce Management tab should be visible. If you've got a lot of center tabs, you might see it in the dropdown at the right of the menu.
