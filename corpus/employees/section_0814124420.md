To apply a region-based override, you will need to create a category group with locations to apply to your region-based override.

With categories, you can create groups of locations that you can use for management oversite, reporting, and accurate location-based wage costing.

You can also use category groups to assign locations to region-based overrides.

#### To create categories for region-based overrides:

1.  Go to Workforce Management.
    
2.  Go to Setup > Categories.
    
3.  Create and prepare a category. For the related procedures, see [Categories](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_90134936241.html).
    
    1.  Create a category.
        
    2.  Create one or more groups then assign them to the category.
        
    3.  Assign WFM locations to the groups you created.
        
4.  For each category you created, click **+Use for Region-based wage overrides**.
    

After you prepared the category group requirements for region-based overrides, you can associate the groups with the correct overrides.
