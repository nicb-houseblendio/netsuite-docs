When you terminate an employee, you must specify a termination or release date. If you use the Termination Reason Tracking feature, you must select a termination category and a termination reason from a list of options. You must also specify termination details, and whether the termination is regretted. For more information, see [Managing Termination Reasons](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4664578925.html).

If you view the employee record of an employee who was terminated before this feature was enabled, these fields are populated by the string 'Unspecified'.

NetSuite has several default termination reasons, but you can change them or create your own. For more information, see [Default Termination Reasons](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4531519241.html).

The Termination Reasons page shows all of the termination reasons in your account. If you don't want to use a reason, but it has been used in the past, you can make it inactive. To view inactivated termination reasons, select the **Show Inactives** box.

If you use the Workforce Analytics feature, you can view a high-level snapshot and synopsis of the employees who are leaving your company. You can view the reasons why employees are leaving on the Turnover Analysis page. Go to _Reports > Employees/HR > Turnover Analysis_. For more information, see [Workforce Analytics](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4823553933.html).

Note:

When this feature is enabled, mass update isn't available. Instead use the NetSuite Import Assistant to update data through import of a CSV file. For information, see [Importing CSV Files with the Import Assistant](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N343158.html). Also, when this feature is enabled inline editing is disabled.

## Termination Reason Tracking Roles and Permissions Requirements {#subsect_1520459307}

For information about the permission requirements for termination reason tracking, see [Termination Reason Tracking Permission Requirements](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1548186514.html).

Note:

If you want more control over what employee information is accessible by different NetSuite users, you can use the Advanced Employee Permissions feature. When this feature is enabled, you can use its employee permissions. This gives you more control over what employee information certain roles can access. You can also customize employee permission that include all or set of standard fields and sublists from the employee record. For more information, see [Advanced Employee Permissions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1494536002.html).
