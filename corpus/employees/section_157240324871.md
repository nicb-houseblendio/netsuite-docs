Roles that use the SuiteApp can receive updates about their plans through the Onboarding portlet, Reminders portlet, or email notifications.

To set up the Onboarding portlet, see [Setting Up the Onboarding Portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161660477431.html).

To set up reminders, see [Setting Up Reminders](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N581945.html).

Click or drag to add the following reminders on your dashboard:

-   Onboarding Tasks
    
-   Offboarding Tasks
    

For email notifications to work, refer to the following:

-   Verify that any Coordinator you assign to a plan has an email address on their employee record. The SuiteApp uses this address to send notifications to employees.
    
-   If you want an employee to get notifications, they must have an existing employee record. Otherwise, they can't receive updates about their assigned tasks or plans. If you create a plan before their record, update the plan to link it after the record has been created.
    

## Email Summary {#subsect_161662407608}

The SuiteApp has a script that sends an email summary of current tasks, assignees and coordinators. You can change the script's schedule to fit your company's email policies.

#### To change the email summary script:

1.  Go to _Customization > Scripting > Script Deployments_.
    
2.  Under the Script column, find OC Send Daily Summary SS and click **Edit**.
    
3.  In the **Status** field, select **Scheduled**.
    
4.  Make the appropriate changes under the **Schedule** subtab. For more information, see [Scheduled Script Deployment Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1508948655.html).
    
5.  Click **Save**.
    

To learn how to use the SuiteApp for your business, see [Getting Started With Onboarding and Offboarding Plans](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157240328026.html).
