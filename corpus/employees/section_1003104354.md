Important:

The MYOB AccountRight Live integration is available only to accounts where it's already provisioned. It's not included with the current SuitePeople WFM solution.

With Workforce Management (WFM), you can export employee hours to a file compatible with MYOB AccountRight Live.

To integrate WFM with MYOB AccountRight Live, follow the steps in the table.

| Step | Related Topic |
| --- | --- |
| 1\. Create an MYOB username and password. | text |
| 2\. Authenticate WFM. | [Authenticating WFM for MYOB AccountRight Live](#subsect_0808032155) |
| 3\. Set up company files. | [Setting up MYOB Company Files](#subsect_0811123059) |
| 4\. Link employees. | [Linking Employees to MYOB](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1011124143.html) |
| 5\. Link wage agreements. | [Linking Wage Agreements to MYOB](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1011124148.html) |
| 6\. Link leave types. | [Linking Leave Types to MYOB](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1011124123.html) |
| 7.(Optional) Link locations to jobs. | [Linking Locations to MYOB Jobs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1011124112.html) |

## Creating an MYOB Username and Password {#subsect_0810105110}

Before you can authenticate WFM, you need to set up an offline username and password in MYOB.

Note:

Check if you have MYOB cloud or online enabled.

#### To create an MYOB username and password:

1.  In MYOB, go to Setup > User Access.
    
2.  Follow the instructions to set up an offline password.
    

## Authenticating WFM for MYOB AccountRight Live {#subsect_0808032155}

To authenticate WFM for use with MYOB AccountRight Live, follow the procedure below.

#### To authenticate WFM for MYOB AccountRight Live:

1.  Go to (navigation path).
    
2.  On the (page), select **Get Company Files**.
    
3.  Log in to the my.MYOB site.
    
    WFM opens, and a list of your MYOB files appears.
    
4.  For each company file that you want to integrate to WFM, click **Authorise**.
    
    All authorized files appear on the left of the page. Each company file includes a menu that you can use to link employees, agreements, leaves, and locations to the file.
    

## Setting up MYOB Company Files {#subsect_0811123059}

After you've authenticated WFM for MYOB AccountRight Live, the authorized files appear on the left.

You must confirm settings for MYOB company files to properly sync with WFM.

#### To set up MYOB company files:

1.  Go to Workforce Management > Setup > Integrations.
    
2.  From the **Payroll systems** list, select **MYOB**.
    
3.  On the MYOB page, click a company file.
    
4.  On the company file page, confirm the settings.
    
    1.  In the **Authorisation Details** section, note the level of authorization and available fields.
        
    2.  (Optional) If you change the credentials used to access your company files, you should update them using the username and password fields.
        
    3.  (Optional) If you want to synchronize employee details between WFM and MYOB, check the **Sync employee details** box.
        
5.  On the **Default Hourly Wage** section, choose the action that applies to you.
    
    -   If you pay employees on the hourly wage classification, select an option from **The hourly wage category** field.
        
    -   If you don't pay employees on the hourly wage classification, leave this field blank.
