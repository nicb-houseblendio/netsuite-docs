Onboarding/Offboarding Plans helps you give new employees a smooth transition. You can run onboarding activities with custom plans and templates you can reuse.

To get started with employee onboarding, refer to the following table for a list of common tasks.

| Task | Related Help Topic | Notes |
| --- | --- | --- |
| 1\. Create an onboarding template or make a copy of the premade template. | [Working With Templates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157240335409.html) | Template: Onboarding Plan Template |
| 2\. Create an onboarding plan. | [Creating Plans](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157240670706.html) | Plan Type: Onboarding |
| 3\. Manage the onboarding plan. | [Managing Plans](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157240674013.html) | \- |
| 4\. Track updates. | [Updates Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157240324871.html) [Working With Updates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157240337779.html) | Reminders portlet: Onboarding Tasks |
