With Workforce Management (WFM), you can generate reports about various location metrics affecting your operations.

The available location reports are:

-   [Variance](#subsect_0724121428)
    
-   [Forecasting Analysis](#subsect_0724121515)
    
-   [Percent Hours Per Location](#subsect_0724121525)
    

For a list of all available metrics in each report, see [Extracting Data Through WFM Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0625082603.html).

## Variance {#subsect_0724121428}

To access the **Variance** report, from the Workforce Management tab, go to Reports > Location > Variance.

This report lets you view the variance between the scheduled and actual figures for specific metrics, including wages, hours worked, average hourly cost, and others.

You can download a CSV file of the data included in the report.

For more information about running, see [Variance Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1013034749.html).

For a list of all available metrics in each location report, see [Location Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0625082603.html#subsect_0724123015).

## Forecasting Analysis {#subsect_0724121515}

To access the **Forecasting Analysis** report, from the Workforce Management tab, go to Reports > Location > Forecasting Analysis.

This report is used to evaluate the accuracy in forecasting for the selected period and locations.

You can download a CSV file of the data included in the report.

For a list of all available metrics in each location report, see [Location Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0625082603.html#subsect_0724123015).

## Percent Hours Per Location {#subsect_0724121525}

To access the **Percent Hours Per Location** report, from the Workforce Management tab, go to Reports > Location > Percent Hours Per Location.

This report lets you view the percentage of hours that each staff member worked at each location. You can compare between two periods.

Note:

This report shows only approved and unscheduled shifts.

You can download a CSV file of the data included in the report.

For a list of all available metrics in each location report, see [Location Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0625082603.html#subsect_0724123015).
