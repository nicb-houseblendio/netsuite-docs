This dataset template includes all active employees and non-terminated employees. This enables you to create performance reviews for your active employees all at once.

## Dataset Configuration {#subsect_164391128933}

The Performance Management - Reviews Scheduler dataset includes fields from the employee record type that provide relevant information about your employees for creating their performance reviews. This dataset contains the following record fields, formulas, and criteria:

| Root Record Type | Data Grid | Custom Formula Fields | Criteria Filters |
| --- | --- | --- | --- |
| Employee | The following fields are included in the dataset:
-   Entity ID
-   Email
-   Supervisor
-   Job Title
-   Department
-   Location
-   Subsidiary

 | The following custom formula fields are included in the dataset:

-   Supervisor is Active & Non-Terminated
-   Employee is not Terminated

 | The following criteria is used to filter the dataset:

-   Is Inactive is false
-   Employee is not Terminated is true

 |

To edit a dataset, see [Editing a Dataset](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158041505315.html).
