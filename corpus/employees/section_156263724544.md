HR Dashboard Components offers the following content:

-   **Workforce demographics portlet** - This custom portlet shows the breakdown of employee headcount across different demographic dimensions.
    
-   **KPI scorecard portlet configuration** - This configuration sets up a performance scorecard that compares different human resource metrics.
    
-   **Saved searches** - These saved searches display reports on diversity and expiring government IDs.
    

**Roles with Access to HR Dashboard Components**

By default, the following roles have permissions to use the SuiteApp:

-   Administrator
    
-   Chief People Officer
    
-   Human Resources Generalist
    

To grant permissions for custom roles to use the SuiteApp, see [Setting Up HR Dashboard Components](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156263725532.html).

To start using dashboard content installed with the SuiteApp, see [Viewing HR Dashboard Components](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156263728327.html).

To modify the SuiteApp according to your needs, see [Modifying HR Dashboard Components for Custom Uses](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156263729818.html).

To view a list of scripts used in the SuiteApp, see [HR Dashboard Components Scripts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156756816079.html).
