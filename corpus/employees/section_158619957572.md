A performance review template includes questions and a rating scale. For more information, see [Performance Review Questions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157538096861.html) and [Performance Review Rating Scales](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157538100220.html).

#### To create a performance review template:

1.  Go to _Setup > Performance Management > Templates > New_.
    
2.  In the **Name** field, enter a unique name for the performance review template.
    
3.  To add instructions to the performance review, in the **Instructions** field, enter instructions.
    
4.  From the **Performance Review Rating Scale** list, select the rating scale to use for performance review questions and for the overall rating.
    
5.  If you want to customize instructions for the performance review, in the **Customize Instructions** field, enter instructions for the performance review.
    
    Note:
    
    If you don't customize the instructions, a default set will appear.
    
6.  If you want to customize the acknowledgment message, type it in the **Customize Acknowledgment** field. Make sure to include any information your company requires. Employees have to read this message before finishing their reviews.
    
    Note:
    
    If you don't customize the acknowledgment message, a default one will appear.
    
7.  From the **Performance Review Question** subtab, click a line in the list and do one of the following:
    
    -   To add an existing question, select a question from the list.
        
    -   To create a question, from the list, select **New**. For more information, see [Creating a Performance Review Question](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158620451749.html).
        
8.  Click **Add**.
    
9.  Repeat steps 5 to 6 for each question that you want to add to the performance review template.
    
10.  To finish, click **Save**.
