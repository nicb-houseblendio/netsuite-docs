Configure Workforce Management (WFM) according to your needs.

Refer to the table for available configuration options and references.

| Configuration | Description | Related Help Topic |
| --- | --- | --- |
| Account Settings | Choose the amount and length of breaks employees can record. | [Account Settings](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_26135046889.html) |
| Availability | Choose employee options for changing their availability. | [Availability](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0818124117.html) |
| Configuring Brands | Create brands and apply default settings units under the brand. | [Configuring Brands](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0818125723.html) |
| Locations | Add locations and configure schedules, locations, and other settings. | [Locations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0818035208.html) |
| Jobs | Create jobs and configure related locations, jobs, and other advanced settings. | [Jobs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0819111329.html) |
| Leave/Time Off | Set leave types, time in lieu, applications, approvals, holidays, overtimes, costings, and other related details. | [Leave/Time Off](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0819010252.html) |
| Validation Rules | Establish rules and criteria around the number and ages of employees working at a certain time. | [Validation Rules](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0829031754.html) |
| Shift Metrics | Set up items to track on individual shifts to be used for allowances, payroll, and reporting. | [Shift Metrics](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_11135129019.html) |
| Financial Configuration | Set up details about employee superannuation funds. | [Financial Configuration](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0829031816.html) |
| Wage Setup | Create wage agreements and configure allowance, rate, penalty, and overtime rate conditions. | [Wage Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_9135444970.html) |
| Notifications | Set up reminders for important events, such as birthdays, document expiration, and others. | [Notifications](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0829031829.html) |
| Shift Reports | Create reports to track important weekly and daily statistics. | [Shift Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0909120836.html) |
| Categories | Create location categories and groups for use in exporting shift reports. | [Categories](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_90134936241.html) |
| Audit logs | View user actions related to publishing schedules, approving leaves, adding shifts, and others. | [Audit Logs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_54135311043.html) |
| Greyscale mode | Change UI colors to high-contrast black, gray, and white for ease of viewing. | [Grayscale Mode](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_25134812258.html) |
| Security Settings | Set up two-factor authentication (2FA) to secure your account. | [Security Settings in WFM](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_40134711868.html) |
| Dashboard | Configure the widgets, KPIs, and groups that appear on your WFM dashboard. | [Dashboard](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0510125622.html) |
