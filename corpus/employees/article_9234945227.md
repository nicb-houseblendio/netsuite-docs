The Workforce Management (WFM) Security Guide provides detailed guidelines that let you securely use and manage the WFM solution.

## Audience {#subsect_0311115404}

This guide is for WFM users who access, use, or manage the WFM solution, like administrators, managers, employees, and other company tasks.

## Security as a Shared Responsibility {#subsect_0311115418}

As a global provider of enterprise cloud computing, Oracle builds secure software through a rigorous set of formal, always evolving security standards and practices known as Oracle Software Security Assurance (OSSA). For more information, refer to [Oracle Corporate Security Practices](https://www.oracle.com/corporate/security-practices/).

If you use WFM for your tasks, you need to take an active role in keeping data secure shared across different cloud and on-premises endpoints. Review the topics in the WFM Security Guide to familiarize yourself with ways to secure your employee and shift data.

WFM provides features to help you enhance security, but they don't guarantee regulatory compliance. You should verify if the security settings cover the right rules for the business or industry and locations where you operate.
