Onboarding/Offboarding Plans helps you make templates that fit your business needs.

#### To create a template:

1.  Go to the Onboarding/Offboarding Template page. For instructions, see [Accessing the SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157240329823.html).
    
2.  Enter a name in the required **Template Name** field. Use clear keywords. You can enter up to 300 characters.
    
3.  In the **Plan Type** field, select the appropriate type. This field is set to **Onboarding** by default.
    
4.  The **Due Date Basis** field populates with the date that matches the plan type. For onboarding, it displays **Hire Date**. For offboarding, it displays **Termination Date**. This field works in conjunction with the **Days from Due Date Basis** column to determine the due date of each task.
    
5.  In the **Custom Welcome Message and Email Content** text box, keep or edit the message. The text you enter appears in the Onboarding portlet, welcome page of the Onboarding plan, and is sent as an email notification to the employee.
    
    Tip:
    
    The \[firstname\] placeholder fills in the employee's first name sourced from the employee record.
    
6.  On the **Tasks** subtab, enter the details of your task.
    
    | Column | Notes |
    | --- | --- |
    | Task Name | Enter a task name with a maximum of 300 characters. |
    | Task Description | Enter a task description with a maximum of 100 characters. |
    | Required | Check the box if assignees must finish the task. |
    | Days from Due Date Basis | This column works with the **Due Date Basis** field on the header section. Enter the date when the task should be finished.
    -   **Before the due date basis** - Enter a minus sign (-) and the number of days.
    -   On the same day as due date basis - Enter zero (0).
    -   **After the due date basis** - Enter the number of days.
    -   No defined due date - Leave blank.
    
    The following lists some examples of tasks and the appropriate entries:
    
    -   Order a computer 14 days before the hire date - Enter **\-14**.
    -   Introduce the new hire on their hire date - Enter **0**.
    -   Complete profile five days after the hire date - Enter **5**.
    -   Submit an optional document - Leave blank.
    
     |
    | Assigned To | To assign a task to a specific employee for all plans created using this template, select the employee. Otherwise, leave it blank. You can fill out the column later when you create a plan for an employee. To select assignees, click the double arrows. On the popup window, select assignees from employee lists or search for their names. |
    | Include Supervisor as Assignee? | Check the box to include the supervisor as an assignee. When you use the template to create an employee's plan, the **Assigned To** column will automatically include their supervisor. |
    | Include Employee as Assignee? | Check the box to include the employee as an assignee. When you use the template to create an employee's plan, the **Assigned To** column will automatically include their name. |
    | Task URL | If a task requires the employee to access a website, add the URL. You can add a maximum of 999 characters on this field. The task name will show as a link in the assignee's plan. This is especially helpful if the task involves other pages in NetSuite. |
    
7.  After you complete the task details, click **Add**.
    
8.  Repeat step 6 for each task you need to add.
    
9.  Click **Save**.
    

After you save the template, you'll find it in the list of all templates. For more information, see [Accessing the SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157240329823.html).

To make a plan from the template you created, see [Creating Plans](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157240670706.html).
