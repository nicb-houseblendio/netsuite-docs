To set up Onboarding/Offboarding Plans, follow these steps.

#### To set up Onboarding and Offboarding Plans:

1.  Log in as a NetSuite administrator. For more information, see [Roles and Accounts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N295370.html).
    
2.  Complete the prerequisites. For more information, see
    
    [Prerequisites](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157240317995.html).
    
3.  Install Onboarding/Offboarding Plans. For more information, see [Installing the SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157240319613.html).
    
4.  Give custom role permission to use Onboarding/Offboarding Plans. For more information, see [Granting Onboarding/Offboarding Permissions for Custom Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157240321701.html).
    
5.  Set the preferred form for custom roles. For more information, see
    
    [Setting Form Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157240322990.html).
    
6.  Set up the Onboarding portlet. For more information, see
    
    [Setting Up the Onboarding Portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161660477431.html).
