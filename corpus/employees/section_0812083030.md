Review the procedures in this topic to provide the appropriate permissions to custom roles.

## Granting Permissions for Viewing Enhanced Timesheets {#subsect_0813123845}

If you want to ensure that custom permissions can access the enhanced weekly timesheets with overtime calculations, follow the procedure.

#### To grant permissions for viewing enhanced timesheets:

1.  Go to Setup > Users/Roles > User Management > Manage Roles (Administrator).
    
2.  On the Manage Roles list page, beside the role that needs the permissions, click **Customize**.
    
3.  On the **Permissions** subtab, click the **Transactions** subtab.
    
4.  From the **Permissions** list, select **Track Time**.
    
5.  In the corresponding **Level** column, select **View** or any higher level of permission.
    
6.  Click **Add**. Click **Save**.
    

## Granting Permissions for Setting Feature Preferences {#subsect_0813124031}

You can assign feature permissions to custom roles to allow employees in non-administrative roles to set feature preferences.

Feature permissions are only available for roles that are assigned the Accounting or Classic center types.

Important:

Important: The following procedure assigns full level Accounting Preferences permission to custom roles. It allows the role access to multiple other features, such as intercompany preferences. Assign this role only to the right employees.

#### To grant permissions for setting feature preferences:

1.  Go to Setup > Users/Roles > User Management > Manage Roles (Administrator).
    
2.  On the Manage Roles list page, beside the role that needs the permissions, click **Customize**.
    
3.  On the **Permissions** subtab, click the Setup subtab.
    
4.  From the **Permissions** list, select **Accounting Preferences**.
    
5.  In the corresponding **Level** column, select **Full**.
    
6.  Click **Add**. Click **Save**.
    

To read about the complete setup instructions for the feature, see [Setting Up Enhanced Timesheets Using WFM](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0812065915.html).
