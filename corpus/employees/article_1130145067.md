SuitePeople Workforce Management (WFM) can integrate with many platforms for many purposes.

From the Workforce Management tab, go to Setup > Integrations for a full list of available platforms.

The following integrations are available:

-   [Email Sales Importer](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1018051844.html)
    
-   [Oracle Hospitality](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1212043252.html)
    
-   [OrderMate](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1018101725.html)
    
-   [World Manager](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1018090915.html)
    
-   [Redcat POS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1018054307.html)
    

Contact NetSuite Customer Support if you don't see an integration listed.

To know more about integrating NetSuite with WFM, see [Integrating Workforce Management with NetSuite](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_36112903912.html).

## Payroll {#subsect_11143718859}

Direct integrations between Workforce Management and third-party payroll providers aren't supported in the U.S.

Payroll data can be shared by doing one of the following:

-   You can export approved hours from Workforce Management to NetSuite. For more information, contact NetSuite Customer Support.
    
-   If you are a cloud services customer, you can access the Workforce Management API. API keys are provided only to you, not to third-party partners. For more information, see [http://docs.adiinsights.info](http://docs.adiinsights.info/) and contact NetSuite Customer Support.
    
-   Workforce Management has a range of generic CSV reports that aren't specific to any third-party partner's file specifications. For more information, see [Workforce Management Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_5125609784.html).
    

## Point of Sales (POS) {#subsect_29143623246}

WFM supports POS integrations with Oracle Hospitality.

Send sales data to Workforce Management by doing one of the following:

-   [Email Sales Importer](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1018051844.html)
    
-   If you are a cloud services customer, you can access the Workforce Management API. API keys are provided only to you, not to third-party partners. For more information, see [http://docs.adiinsights.info](http://docs.adiinsights.info/) and contact NetSuite Customer Support.
