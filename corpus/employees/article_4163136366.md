When used with Workforce Management (WFM), the weekly timesheets interface is updated with added features. These updates ensure that you can accurately track employee hours and minimize errors.

If you are using weekly timesheets with the Enhanced Timesheets Using WFM Wage Rules feature, see [Enhanced Timesheets Using WFM Wage Rules](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0604033425.html).

If you are tracking hours on weekly timesheets and use both WFM and Field Service Management (FSM) SuiteApps, see [Tracking Weekly Timesheets with WFM and FSM Hours](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0204014833.html).

To ensure that total payroll hours for WFM records show up in weekly timesheets, see [Setting Custom Forms to Show WFM Payroll Hours](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0204015659.html).
