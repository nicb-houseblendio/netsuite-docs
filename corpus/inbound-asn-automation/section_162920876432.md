-   [Prerequisites](#bridgehead_162929072422)
    
-   [Installing the Inbound ASN Automation SuiteApp](#bridgehead_163029940034)

-   [Providing Access to Deployment Records](#bridgehead_162978293390)
    
-   _Setting Up General Preferences_
    

## Prerequisites {#bridgehead_162929072422}

You must enable the following features.

#### To enable features:

1.  Go to Setup > Company > Setup Tasks > Enable Features.
    
2.  On the **Transactions** subtab, under the Shipping & Receiving section, check the **Inbound Shipment Management** box.
    
3.  On the **SuiteCloud** subtab, check the following boxes:
    
    -   **Client SuiteScript**
        
    -   **Server SuiteScript**
        
4.  (Optional) Make sure you enable the following features only if your vendors want to upload ASN data through Web Services:
    
    -   On the **SuiteCloud** subtab, check the **REST Web Services** and **Token Based Authentication** boxes.
        
    -   On the **Web Presence** subtab, check the **Access** box.
        
5.  Click **Save**.
    

## Installing the Inbound ASN Automation SuiteApp {#bridgehead_163029940034}

Inbound ASN Automation SuiteApp is a managed SuiteApp that automatically updates whenever enhancements or new features are added.

You can install the Inbound ASN Automation SuiteApp from the SuiteApp Marketplace. For more information, see [Installing from the SuiteApp Marketplace](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1539799323.html).

## Permissions for Inbound ASN Automation {#bridgehead_162929075675}

Important:

If you upgrade the Inbound ASN Automation SuiteApp from version 1.0.0 to version 1.1.0, the existing Inbound ASN Automation permissions get deleted. Reassign the Inbound ASN Automation permissions to your custom and standard roles to be able to use the SuiteApp.

The Inbound ASN Warehouse Manager role has been created with the required permissions for the SuiteApp.

You can either use the Inbound ASN Warehouse Manager role or assign the required permissions to any existing roles in your organization. ## Providing Access to Deployment Records {#bridgehead_162978293390}

The Administrator and Inbound ASN Warehouse Manager roles have access to the following deployment records by default:

-   IS SU ASNLog Record Creation
    
-   IS SU ASN Approve
    
-   IS SU ASN Reject
    
-   IS SU ExceptionList
    
-   IS SL Setup Preferences. Only the Administrator role has access to this deployment record.
    

#### To provide access to the deployment records to a custom role:

1.  Go to Customization > Scripting > Script Deployments.
    
2.  Locate the deployment record and click **Edit**.
    
3.  Click the **Audience** subtab.
    
4.  From **Roles**, select the custom role you want to give access to the deployment record.
    
5.  Click **Save**.
    

When you're done with all the required setup, proceed with [Working with Inbound ASN Automation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162920910667.html).
