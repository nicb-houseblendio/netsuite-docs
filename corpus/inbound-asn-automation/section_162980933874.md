The following scripts are included with the Inbound ASN Automation SuiteApp:

-   **IS MR ASNCreationRunner** - When ASNs are uploaded through CSV or Web Services, this MR script gets triggered to create and validate the ASN records in real time. The script is also scheduled to run every 15 minutes to include any missed ASNs.
    
-   **IS MR ProcessASN** - This script gets triggered after the ASNs are created or the status of an ASN has changed from **Error** to **Success**. The script creates inbound shipment records automatically for ASNs with **Success** status. The script is scheduled to run every 15 minutes to include any missed ASNs.
    
-   **IS MR Item Exception Thresholds** - This script copies values from Vendor Bill Matching section for setting tolerances in item records.
    
-   **IS MR Vendor Exception Thresholds** - This script copies values from Vendor Bill Matching section for setting tolerances in vendor records.
