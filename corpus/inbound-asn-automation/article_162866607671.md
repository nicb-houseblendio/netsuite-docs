## Inbound ASN Automation Overview {#bridgehead_162978486264}

The Inbound Advance Ship Notice (ASN) Automation SuiteApp automatically creates an inbound shipment record from an ASN. In addition, you can create and manage ASNs with the SuiteApp.

The SuiteApp enables you to:

-   Import ASNs through CSV or Web Services. For more information, see [Uploading an Advance Ship Notice (ASN)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162920922241.html).
    
-   Define tolerance limits for receiving item overage at the company, vendor, and item levels. For more information, see [Setting Inbound ASN Automation Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162920914811.html).
    
-   Set preferences to handle ASNs with items overage. For more information, see [Setting Inbound ASN Automation Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162920914811.html).
    
-   Review ASNs to approve or reject. For more information, see [Approving or Rejecting an Advance Ship Notice (ASN)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162920927769.html).

## Supported Item Records {#bridgehead_162929277484}

The Inbound ASN Automation SuiteApp supports the following item records:

-   Assembly
    
-   Inventory Item
    
-   Non-inventory Item
    
    -   For Purchase
        
    -   For Resale
        
-   Other charge
    
    -   For Purchase
        
    -   For Resale
        
-   Service
    
    -   For Purchase
        
    -   For Resale
        
    -   Matrix items (for the above item types)
