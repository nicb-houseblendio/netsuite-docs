To use the Compliance 360 SuiteApp, an administrator must assign a SuiteApp-provided role to a user, and set permissions for that role. Users can be assigned multiple roles.

The following are the SuiteApp-provided roles.

| Role | Description |
| --- | --- |
| Compliance Officer | Users with this role have access to all of the SuiteApp controls and pages, including audits, audit templates, dashboard, activity logs, and settings. |
| Compliance Audit Supporter | Users with this role are assigned specific audit controls and contribute to an audit completion by marking assigned audit controls as pass or fail. Compliance audit supporters have access to audits and audit templates only. Users with this role can't access the dashboard and activity logs. Audit supporters can create audit controls and delete them even if not assigned to them. They can't edit the primary information of an audit, can't import audit templates into an audit, and can't change the value in the **Assigned To** column in the Audit Control section. They can only save the audit after the work is done. |

#### To set permissions for a Compliance 360 user role:

1.  Go to Setup > Users/Roles > Manage Roles.
    
2.  Click **Customize** next to a SuiteApp-provided role.
    
3.  In the **Name** field, enter **Compliance Officer** or **Compliance Audit Supporter**.
    
4.  On the **Permissions** subtab, set the following required permissions for the role:
    
    | Role | Subtab | Permission | Minimum Access Level |
    | --- | --- | --- | --- |
    | Compliance Officer | Setup | Allow JS/HTML Uploads | Full |
    | Custom Lists | Full |
    | Custom Record Types | View |
    | Import CSV File | Full |
    | Publish Dashboards | Full |
    | Set Up Company | View |
    | View Login Audit Trail | Full |
    | Custom Record | Comp 360 Audit Assignment Notifications | Full |
    | Comp 360 Audit Attachments Info | Full |
    | Comp 360 Audit Controls | Full |
    | Comp 360 Audit Data | Full |
    | Comp 360 Audit Template | Full |
    | Comp 360 Email Notifications | Full |
    | Comp 360 KPI Settings Data | Full |
    | Comp 360 Settings Data | Full |
    | Comp 360 User Email Preferences | Full |
    | Compliance Audit Supporter | Setup | Allow JS/HTML Uploads | Full |
    | Custom Lists | Full |
    | Custom Record Types | View |
    | Import CSV File | Full |
    | Publish Dashboards | Full |
    | Set Up Company | View |
    | View Login Audit Trail | Full |
    | Custom Record | Comp 360 Audit Attachments Info | Full |
    | Comp 360 Audit Controls | Full |
    | Comp 360 Audit Data | Full |
    | Comp 360 Audit Template | Full |
    | Comp 360 Settings Data | Full |
    | Comp 360 User Email Preferences | Full |
    

For more information, see [Customizing and Creating Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N286284.html) and [Setting Permissions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N288727.html).
