## KPI Settings {#subsect_1104091818}

The KPI Settings control the graphs and meters shown in the Key Performance Indicators portlet.

Modify the KPI Settings to set daily thresholds and variation ranges for the dashboard's KPI meter tiles.

The following screenshot shows how the KPI Settings screen look like:

![A screenshot that shows a portion of the KPI Settings screen.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteApps/Redwood_SettingsScreen.png)

#### To modify the KPI Settings:

1.  Go to Compliance 360 > Settings > View.
    
2.  Click the **KPI Settings** subtab.
    
3.  In the **Daily Threshold Limit** fields, enter your preferred threshold limits for each KPI meter tiles.
    
    For guidelines in setting threshold limits, see [Daily Threshold Limits](#subsect_0925024419).
    
4.  In the **Variation Range** fields, set your preferred variation ranges for the following statuses of each KPI meter:
    
    -   Good
        
    -   Concerning
        
    -   Attention required
        
    
    For guidelines and validations on setting variation range for KPI meters, see [Variation Range](#subsect_0925030129).
    

### Daily Threshold Limits {#subsect_0925024419}

Daily thresholds control the colors and stats displayed in the KPI meter's gauges.

Threshold limits also affect the percentage change from the threshold value in KPI meter tiles.

The following screenshot highlights the percentage vs threshold value in the KPI meter tile, boxed in red:

![A portion of the KPI meter tile with the percent vs threshold number boxed in red.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteApps/C360_KPIEdited_July.png)

When setting a daily threshold limit for KPI meter tile, consider the following:

-   You must only enter numbers, as non-numeric characters are not allowed.
    
-   Zero (0) is considered as a valid value.
    
-   If the **Daily Threshold Limit** field of a KPI meter is left blank, its KPI meter tile will be dimmed in the dashboard.
    
-   You must first set a threshold limit for a KPI meter tile before you can set its variation ranges. If the KPI meter's **Daily Threshold Limit** field is left blank, you cannot set a variation range for it.
    
-   The daily threshold limit in the KPI meter tile updates based on the time period filter applied in the Key Performance Indicators portlet.
    
    For example, a daily threshold limit of 5 becomes 35 when applying the **Week** filter to the Key Performance Indicators portlet.
    

### Variation Range {#subsect_0925030129}

Variation ranges control the gauge meter colors and percentage displays in KPI meter tiles.

The **Variation Range (%)** column displays two sets of fields. The left set of fields are for the minimum range value and the right set of fields are for the maximum range value.

Set variation ranges for each status of a KPI meter tile. The following table outlines the color and range validations for each status:

| Status | Color | Range Validations |
| --- | --- | --- |
| Good | Green | 
-   By default, its minimum value is dimmed and set to zero (0).
-   You can enter any number from 0-100 for its maximum value.
-   The number entered as its maximum value populates as the minimum value of the **Concerning** status.
-   If the maximum value entered for **Good** status is 100, the remaining fields are dimmed.

 |
| Concerning | Orange | 

-   By default, its minimum value is dimmed and populates the maximum value of **Good** status.
-   You can enter any number from 0-100 for its maximum value.
-   If you enter a number as its maximum value, this value populates as the minimum value of the **Attention Required** status.
-   If the maximum value entered for **Concerning** status is 100, the remaining field is dimmed.

 |
| Attention Required | Red | 

-   If a number is entered as the maximum value of **Concerning** status, this value populates as the minimum value of the **Attention Required** status.
-   By default, its maximum value is dimmed and set to one hundred (100.00).

 |

When setting variation ranges for KPI meter tiles, consider the following factors:

-   The total value of each range must be 100.
    
-   You can enter numbers with up to two decimals. (Example: 50.25 and 75.90)
    
-   You must enter a number not bigger than 100.
    
-   If the KPI meter count is below threshold limit, the gauge meter will be shown as green.
    
-   If the KPI meter count exceeds the 100% threshold limit, the gauge meter will be shown as red.
    
-   You cannot set a variation range for KPI meter statuses if the daily threshold limit for that particular KPI meter is left blank.
    

## Date Filter Settings {#subsect_1104093503}

The date filter settings control the data frequency shown in dashboard portlets.

The following screenshot displays the Date Filter Settings screen.

![A screenshot that shows a portion of the Date Filter Settings screen.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteApps/Redwood_DateFilterScreen.png)

#### To modify the date filter settings:

1.  Go to Compliance 360 > Settings > View.
    
2.  Click the **Date Filter Settings** subtab.
    
3.  From the **Default Dashboard Filter** list, select one from the following:
    
    -   **Day** - the tiles will show comparative numbers against the previous day
        
    -   **Week** - the tiles will show comparative numbers against the previous week
        
    -   **Month** - the tiles will show comparative numbers against the previous month
        
4.  Click **Save**.
    

To see if the new settings have been applied to the dashboard, you must go to the [Compliance 360 Dashboard](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0422103553.html) and refresh the page. You can also click the **Refresh** button in each portlet to see individual changes.
