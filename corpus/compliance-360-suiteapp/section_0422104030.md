The Compliance 360 activity log shows you who accessed customer personal information and what actions they took.

Note:

Activity for each NetSuite account type is tracked independently. For example, the data from the Activity Log in your production account is not synchronized with data from the Activity Log in your sandbox account.

For more information about limitations of Compliance 360 SuiteApp, see [Limitations of Compliance 360 SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_7153807491.html#subsect_0422101242).

The Activity Log tracks record types with potentially sensitive customer information. Accessing customer info through the following channels creates a log entry:

-   Record creation, view, and edit in entry forms
    
-   Saved searches
    
-   Analytics workbooks and datasets
    
-   The following reports:
    
    -   Open Invoices
        
    -   Open Sales Orders
        
    -   Sales by Customer
        
    -   Cases by Customer
        
    -   AR Aging Detail
        
    -   Unbilled Cost by Customer
        
    -   Customer Profitability
        
    -   Transaction Detail
        
-   Basic and Advanced Printing
    
-   Exports from Record Lists
    
-   Full CSV Exports
    

Warning:

You cannot delete customer records, or any records that depend on customer records, when the Activity Log feature is enabled. If you attempt to delete a customer record, NetSuite shows a dependency error.

To view the activity log, go to Compliance 360 > Activity Log > View. The log defaults to showing the last month's information.

The activity log shows 10,000 results. Use the Access Date Range filter to find the results you need and improve performance.

The following table outlines the information you can view and filter in the Compliance 360 activity log:

| Column | Column Content |
| --- | --- |
| Log Date | Date and time when the data was accessed, displayed in the time zone of the user who accessed the log. |
| User | Name of the user who accessed the data. |
| User Role | Role of the user who accessed the data. |
| Customer | Customer whose data was accessed by the user. |
| Source | Where the customer data was accessed from. In most cases, this column shows the name of the associated record that contains customer information. |
| Source Details | The name of the associated record that contains customer information. |
| Interface Type | Shows whether the action was performed through User Interface (UI) or API (Application Programming Interface). When an action is performed through API, the column shows which API was used.
-   Automation Note: The Automation label indicates that the action was performed automatically by the system. For example, when an email alert or a scheduled email campaign is sent to customers.
-   SuiteScript
-   UI
-   Unknown Note: The Unknown label appears when NetSuite cannot specify whether UI or API was used to access the data.

 |
| Action | Type of action performed. Possible values include:

-   Create
-   View
-   Export
-   Email
-   Basic Print
-   Advanced Print
-   Saved Search
-   CSV Export
-   PDF Export
-   Full CSV Export
-   Analytics Workbook
-   Analytics Query
-   Report
-   Script Execution Note: The Script Execution action implies that customer information was accessed by a server script. For client scripts, this column shows the exact action performed by the script.
-   Workflow Execution Note: For more information how to view the logs for actions performed using SuiteFlow, see [Viewing Logs for Actions Performed Using SuiteFlow](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0603010101.html).

## Filters in Compliance 360 Activity Log {#subsect_0422104355}

The Compliance 360 activity log can be filtered and exported, allowing you to customize the records shown by applying filters.

#### To apply a filter to the Compliance 360 Activity Log:

1.  Go to Compliance 360 > Activity Log > View.
    
2.  Click the Access Date Range filter to select a date range of displayed records in the activity log.
    
3.  Click one from the following filters:
    
    | Filter | Function |
    | --- | --- |
    | Access Data Range | Filters the log by your selected date range. By default, no records will be displayed in the activity log. For records to be displayed, you must first select an access date range. |
    | User | Filters the log based on the names of the users who accessed customer information. |
    | User Role | Filters the log based on the roles of the users who accessed customer information. |
    | Customer | Filters the log based on the names of the customers. |
    | Action | Filters the log based on the actions performed on customer information. |
    | Source | Filters the log based on the source record of the activity. |
    | Interface Type | Filters the log based on the interface type where the activity occurred. |
    
4.  Select one or more values from the values list of your selected filter.
    
5.  If you want to select another filter, repeat steps **3** to **4**.
    
6.  Click **Apply Filters**.
    

You can customize the number of data displayed in the activity log. From the **Show** dropdown list, select your preferred number of data to show in the activity log.

Click **Print** to print the log. Alternatively, you can download and export the log in CSV format.

The Personal Information Access Logs dataset is related to the Activity Log feature. This dataset lets you make use of all SuiteAnalytics capabilities in NetSuite, in addition to the visualizations provided by the Compliance 360 SuiteApp. For more information, see [Personal Information Access Logs Dataset and Workbook](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0522124117.html).

### Purging of Activity Logs in Compliance 360 {#subsect_0715035430}

The Compliance 360 Activity Log retains data for up to twelve months only. To store your activity logs beyond twelve months, you must download and store them offline.

Purging of data beyond twelve months happens on the 1st day of the month. For example, all activity logs from July 2024 will be purged on August 1, 2025.

Users with the role of Administrator or Compliance Officer will receive three email notifications prior to the scheduled purge date, specifically on the 1st, 15th, and 25th of the month before the purging date.
