You can attach supporting files to individual audit control line items. Adding attachments at the audit control line level helps you keep control-specific evidence with the control that it supports.

You can add, edit, or view attachments for an audit control line from the **Attachments** column in the Audit Controls section. The actions available to you depend on your Compliance 360 role and audit access. Users with edit permissions can create and delete audit control attachments. Users with view permissions can only view these attachments.

You can attach more than one file to a control line item. The combined size of all attachments for one control line item must not exceed 10 MB. Supported file types are PDF, DOC, DOCX, XLS, XLSX, JPG, PNG, TXT, and ZIP.

Audit control attachments are stored under Documents > Files > File Cabinet > SuiteApps > com.netsuite.compliance360 > Audit Attachments.

Each audit record has its own folder, named after the audit ID. Within that audit folder, each control line item also has its own folder, named after the corresponding control line item ID.
