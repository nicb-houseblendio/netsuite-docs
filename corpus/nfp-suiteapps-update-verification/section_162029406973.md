The following is the list of unlocked components in each NFP SuiteApp:

| Custom Segments, Custom Records | 
-   Program
-   Revenue Subtype

-   Functional Expense
-   Revenue Type
-   Grant

 | NFP Financials (These components are also referred and unlocked in all SuiteApps dependent on NFP Financials) | A SuiteApp update does not preserve changes to the following custom segments fields, and you must redo the changes after the update:

-   Filter By
-   Show in List
-   Display Type
-   Help
-   Description

Ensure the following:

-   No changes are made to the following subtabs
    -   Fields
    -   Icons
-   No entries are added to the following subtabs:
    -   Subtabs
    -   Sublists
-   No changes are made to the lists or records attached to a field

Do not rename the following classifications with the same name as the custom segments in the NFP Financials SuiteApp:

-   Department
-   Class
-   Locations
-   Subsidiary
-   Account
