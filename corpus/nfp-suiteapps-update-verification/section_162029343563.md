You can install the NFP SuiteApps Update Verification SuiteApp from the SuiteApp Marketplace. For more information, read [Installing from the SuiteApp Marketplace](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1539799323.html).

SuiteApps Update Verification is a managed SuiteApp that automatically updates whenever enhancements or new features are added.

## Prerequisites for NFP SuiteApps Update Verification {#bridgehead_162029437340}

The NFP SuiteApps Update Verification SuiteApp is developed and tested for use primarily with NetSuite OneWorld. For more information about NetSuite OneWorld, read Introduction to NetSuite OneWorld.
