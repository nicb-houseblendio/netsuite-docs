In the following cases, an NFP SuiteApp update is blocked and the application sends an email to the account administrator:

-   If you do not have the NFP SuiteApps Update Verification SuiteApp installed.
    
-   If you do not verify and check all the fields in SuiteApps Update Verification page.
    
-   If an error occurs when updating the SuiteApp.
