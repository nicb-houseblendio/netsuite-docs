The SuiteApps Update Verification page provides the following fields:

| Section | Field | Description |
| --- | --- | --- |
| Custom Segments Verification | Verified Custom Segments Changes | Check this box after understanding that a SuiteApp update does not preserve changes to the following custom segments fields, and you must redo the changes after the update:
-   Filter By
-   Show in List
-   Display Type
-   Help
-   Description

 |
| Custom Records Verification | Verified Custom Records Changes | Check this box after verifying the following custom records related to custom segments:

-   No changes are made to the following subtabs
    -   Fields
    -   Icons
-   No entries are added to the following subtabs:
    -   Subtabs
    -   Sublists
-   No changes are made to the lists or records attached to a field

Warning: If you change the list or record attached to a field, there is a data loss on SuiteApp update. Do not change the SuiteApp fields even if the fields are unlocked. You can add new fields and use them for your requirements. |
| Rename Classifications Verification | Verified Classifications | Check this box after verifying that you did not rename the following classifications with the same name as the custom segments in the NFP Financials SuiteApp:

-   Department
-   Class
-   Locations
-   Subsidiary
-   Account

 |
| Reports Customization Verification | Verified Report Changes | Check this box after understanding that you should not directly customize the reports delivered with the SuiteApps because the SuiteApp updates will overwrite the customizations. If you have customized the reports, verify that you have documented the changes and redo the changes after the SuiteApp updates. |
| Custom Transaction Verification | Verified Custom Transaction Changes | Check the box after understanding that the SuiteApp updates will reset any changes made to the custom transaction unlocked components. Verify that you have documented the changes and redo the changes after the SuiteApp updates. |
| Navigation Links Verification | Verified Navigation Links | Check the box after understanding that SuiteApp updates will reset navigation links changes, such as changes to the financial reports navigation links. Verify that you have documented the changes and redo the changes after the SuiteApp updates. |
| Sandbox/Release Preview Account Verification | Verified SuiteApp Updates in Sandbox/Release Preview | If you have a sandbox account or a release preview account, verify the SuiteApp updates in that account and note the changes. After verification, select **Yes** from this list. If you do not have access to a sandbox or release preview account, select **Not Applicable**. |
| SuiteApps Update Verification | Verified All Changes and Ready to Update SuiteApps | Understand and verify all the SuiteApp update related changes and confirm to get the SuiteApp updates. |
