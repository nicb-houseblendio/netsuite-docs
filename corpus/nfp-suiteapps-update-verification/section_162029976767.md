For updating NFP SuiteApps, you must check all the fields in the SuiteApps Update Verification page.

#### To enable SuiteApp updates:

1.  In the global search, enter **SuiteApps Update Verification**.
    
2.  From the search results, click **SuiteApps Update Verification**.
    
    The SuiteApps Update Verification page opens.
    
3.  Verify and check the following boxes:
    
    1.  Verified Custom Segments Changes
        
    2.  Verified Custom Records Changes
        
    3.  Verified Classifications
        
    4.  Verified Report Changes
        
    5.  Verified Navigation Links
        
    6.  Verified All Changes and Ready to Update SuiteApps
        
4.  If you have a sandbox or release preview account, from the **Verified SuiteApp Updates in Sandbox/Release Preview** list, select **Yes**.
    
    Note:
    
    **Note:** If you do not have a sandbox or release preview account, select **Not Applicable**.
    
5.  Click **Save**.
