Note:

This topic describes functionality available in NetSuite Next. NetSuite Next is being made available to customers in phases, so these features may not yet be available in your account. You'll receive in-app notifications when your account is eligible for NetSuite Next.

AI tools depend on clean, consistent data. Start with the record types that support your daily work and reporting, such as customers, vendors, and items. Look for:

-   Duplicate records
    
-   Inconsistent naming
    
-   Missing attributes
    
-   Outdated or inactive information
    

Note:

Make sure to complete the AI description fields for your custom records and fields. AI description fields help Ask Oracle understand what you're asking for when you describe record actions. The ability to set an AI description is available when editing a custom record or field. To learn more, see [AI Description for Custom Object Definitions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0109014837.html).

See the following help topics for more information:

-   [Duplicate Record Detection](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N490932.html)
    
-   [Inactivating Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N490731.html)
    

You can also use saved searches to identify active records that may need review. For example, records with missing key fields, no recent transactions or activity, inactive owners, outdated statuses, or values that no longer match your current business process. For more information, see [Defining a Saved Search](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N676039.html).
