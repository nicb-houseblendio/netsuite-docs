The SuiteCommerce Analytics Data geography record lists where a shopper was located when they browsed a web store.

| Analytics Workbooks | Saved Search | Content |
| --- | --- | --- |
| Label | Type | Label | Type | Provides |
| --- | --- | --- | --- | --- |
| **City** | Text Select | **Geography: City** | Text | City location when browsing web store |
| **Country** | Select | **Geography: Country** | Select | Country location when browsing web store |
| **State** | Select | **Geography: State** | Select | State location when browsing web store |
