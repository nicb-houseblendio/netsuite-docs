This step links the SSP application for your implementation to a previously set up domain.

#### To link your application to your domain:

1.  In NetSuite, go to _Commerce > Hosting > SSP Applications_.
    
2.  Click **View** next to the correct application:
    
    | Implementation | Application Name |
    | --- | --- |
    | SuiteCommerce | SuiteCommerce |
    | SuiteCommerce MyAccount | SuiteCommerce |
    | SuiteCommerce Advanced | SuiteCommerce Advanced - Dev xxxx (where xxxx equals the SCA version being installed) |
    
3.  Click **Link to Domain** to link touch points to your domain.
    
    Important:
    
    Touch points configured for a domain override the touch points configured for the related web site. To take advantage of themes and extensions, you must link the SSP to a domain. However, you must also define touch points on the web site record. Domain-only touch point configuration is not supported. See [Link a Website or Domain to an SSP Application](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2495714.html) and [Select Supported Touch Points](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2494795.html) for details.
    

If you're implementing SuiteCommerce Advanced 2019.1 or later, the next step is to deploys the SS2 SSP application for your implementation. See [Deploy SSP Application to Your Domain](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1231024650.html).
