If you haven't published your image with text overlay yet and want to get rid of it, you can discard it. If it's already published, you can remove it directly from the page. To learn the difference between discarding and removing content, see [Discard or Expire Content in Site Management Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1513888480.html).

#### To discard an image with text overlay (unpublished content):

1.  Log into Site Management Tools. For details, see [Logging into Site Management Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4163262385.html).
    
2.  Click the Review & Publish Changes icon ![Review and Publish Changes Icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/StoreFront/WebsiteContent/ReviewAndPublishChangesIcon.png) from the site management toolbar.
    
3.  Select the image with text overlay from the Unpublished Changes list.
    
4.  Click **Discard**.
    
5.  In the pop up window that appears, click **Yes**.
    

#### To remove an image with text overlay (published content): {#procedure_1537878280}

1.  Log into Site Management Tools. For details, see [Logging into Site Management Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4163262385.html).
    
2.  Go to the page that contains the image with text overlay.
    
3.  Click the Edit Mode icon ![Edit Mode Icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/StoreFront/WebsiteContent/EditModeIcon.png) from the site management toolbar.
    
4.  Hover over the image text overlay content to display the content controls.
    
5.  Click **X** to remove the text overlay from the page.
    
6.  In the pop up window that appears, click **Yes**.
