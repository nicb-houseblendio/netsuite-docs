The Transaction Lists feature lets you set up how you show past transaction information in the My Account area of your Commerce website.

You can set up the following transaction lists to include specific fields as columns. You can also add custom fields and choose the display order for each column.

-   Returns
    
-   Quotes
    
-   Order History
    
-   Open Invoices
    
-   Paid Invoices
    

Note:

Invoices pending approval don't show up in the My Account area when the Approval Routing feature is turned on.
