When a shopper initiates a search in your web store, the system uses the order and matching type of the fields you configure on the Search Fields subtab. This order controls how items are matched and returned in search results.

Before you [Configure Search Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1201013254.html), refer to the following sections:

-   [Understanding Match Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_1499938097.html)
    
-   [Sample Search Field Configuration](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_1510159801.html)
