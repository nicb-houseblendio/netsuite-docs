You can delete any enhancements added to the page.

#### To delete page enhancements:

1.  Log in to Site Management Tools. For details, see [Logging into Site Management Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4163262385.html).
    
2.  Go to the enhanced page from which you want to delete enhancements.
    
    For example, the URL for a facet listing of **sports helmets** is, **http://mysite.com/accessories/sportshelmets**. By going to that page and accessing the page settings menu, you can set the enhanced properties for the page.
    
3.  Click the Edit Mode icon ![Edit Mode Icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/StoreFront/WebsiteContent/EditModeIcon.png) from the site management toolbar.
    
4.  Select the ellipsis from the top-right corner of the site management toolbar and select **Edit Page Settings**.
    
5.  Select and delete any enhancements.
    
6.  Click **Save**.
    
7.  Publish the changes. For details, see [Review and Publish Content in Site Management Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4419210472.html).
