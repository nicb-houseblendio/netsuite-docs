You can edit HTML content when you need to make changes.

#### To edit HTML content:

1.  Log in to Site Management Tools. For details, see [Logging into Site Management Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4163262385.html).
    
2.  Go to the page that contains the HTML content you want to edit.
    
3.  Click the Edit Mode icon ![Edit Mode Icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/StoreFront/WebsiteContent/EditModeIcon.png) from the site management toolbar.
    
4.  Hover over the HTML content to display the content controls.
    
5.  Click **Edit** to open the HTML Settings in the side panel.
    
6.  Make any required changes and click **Save**.
    
7.  Publish your changes. For details, see [Review and Publish Content in Site Management Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4419210472.html).
