To use intelligent item recommendations on your website, you must install and then activate the SC Intelligent Item Recommendations extension.

#### To install the Intelligent Item Recommendations extension:

1.  Go to _Customization > SuiteBundler > Search & Install Bundles_.
    
2.  In the **Keywords** field, enter 'intelligent item recommendations' and click **Search**.
    
3.  Verify that the SC Intelligent Item Recommendations extension is returned in the search and select it.
    
4.  Review the extension details and then click **Install**. For more information about installing extensions, see [Installing Theme and Extension SuiteApps](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510953648.html).
    
5.  In the confirmation popup window, click **OK**.
    
6.  On the Preview Bundle Install page, review the extension details and then click **Install**.
    
7.  In the confirmation popup windo, click **OK****.**
    

#### To activate the Intelligent Item Recommendations extension:

1.  Go to Commerce > Extensions > Extension Manager (Administrator).
    
2.  Next to the website where you want to use intelligent item recommendations, click **Edit**.
    
3.  Go to the **Extensions** tab.
    
4.  Next to Intelligent Items Recommendations, check the box in the **Active** column.
    
5.  Click **Activate**.
    
6.  After you activate the Items Recommendations extension, it displays in the **Active Extensions** column for your website on the Extension Manager Page.
