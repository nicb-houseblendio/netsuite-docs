Use Site Management Tools (SMT) to add content to your blog post, including the header and thumbnail images, category, and author. Publish your changes in SMT to have your blog post appear.

#### To add a blog post:

1.  Log in to SMT. For details, see [Logging into Site Management Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4163262385.html).
    
2.  Select the Overview Mode icon ![Overview Mode Icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/StoreFront/WebsiteContent/OverviewModeIcon.png) from the site management toolbar.
    
3.  Select the **Blog** subtab.
    
4.  Click **New Blog Post**.
    
5.  In the **Blog Post** subtab, set the following fields:
    
    | Field | Description |
    | --- | --- |
    | Category | Determines the category of the blog post. A list of categories displays on the blog home page. You can select an existing category, add a new category, or edit an existing category by clicking **Edit**. You cannot delete a category that has a blog post assigned to it. |
    | Author | Determines the author of the blog post. You can select an existing author, add a new author, or edit an existing author by clicking **Edit**. You cannot delete an author that has a blog post assigned to it. |
    | Subtitle | Sets the subtitle of the blog post. |
    | Content | Determines the content of the blog post. This field supports basic HTML format tags. You can also include SMT content in your blog post content by adding a Content Management System (CMS) area using the following key: `[[content:examplecontent]]`. The ID (examplecontent) must be unique for each piece of content you add. The ID can include letters and numbers and must not exceed 20 characters. |
    | Header Image | Determines the header image that appears at the top of the blog post. For information about image size and format, see [Image Size and Format](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4123521956.html#bridgehead_4210904243). |
    | Header Image Alt | Determines the description of the header image to be used to improve accessibility and SEO. |
    | Excerpt | Determines the excerpt for the blog post preview to display in the blog post list. If left blank, the blog post preview uses the first paragraph of the post as the excerpt. |
    | Thumbnail Image | Determines the thumbnail image that is used for the blog post preview. For more information, see [Image Size and Format](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4123521956.html#bridgehead_4210904243). |
    | Thumbnail Image Alt | Determines the description of the thumbnail image to be used to improve accessibility and SEO. |
    | Post Tags | Sets the tags for the blog post. Users can use tags to filter posts. You can add multiple tags in a list separated by commas. |
    | Pin Post To | Determines the areas in which you want the blog post to be featured. Choose one of the following:
    -   Featured Articles - The post is featured in the Featured Articles section.
    -   Featured Articles in Category - The post is featured on the category home page.
    -   No Search Results - The post appears when a search returns no results.
    
    You can edit these section titles by clicking **Edit**. Do not delete the Featured Articles or Featured in Category section. |
    | Publication Date | Sets the publication date of the blog post. |
    
    The Blog Post page type also includes tabs for standard **General**, **Metadata**, **Layout**, and **Advanced** properties. For more information about these fields, see [Landing Pages](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4344038011.html).
    
6.  Click **Save**.
    
7.  Publish your changes. For details, see [Review and Publish Content in Site Management Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4419210472.html).
