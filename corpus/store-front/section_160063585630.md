In Site Management Tools (SMT), Multi-Language pages let you create website content and add your own translations in any of your configured languages. The type of content you add determines what translation options are available. If website content doesn't have translations, the base language shows by default. For SEO metadata, this behavior isn't applied so there's no negative impact on SEO. You'll need to provide any SEO translation data for the commerce category.

Note:

The visibility dates you select apply to both the default language and all translations. You can't pick visibility dates for individual translations.
