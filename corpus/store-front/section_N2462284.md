The preferred shipping method for an order is based on:

-   [Default Shipping Carrier](#bridgehead_N2462358)
    
-   [Default Website Shipping Method](#bridgehead_N2462429)
    
-   [Customer Information](#bridgehead_N2462510)
    

Shoppers can always choose a different shipping method or carrier if one's available. You can show the [Shipping Estimator](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1489430469.html) on your site to help customers pick a carrier.

## Default Shipping Carrier {#bridgehead_N2462358}

If you use UPS, FedEx, USPS, or other carriers, you can pick a default carrier for your NetSuite account. NetSuite shows the default carrier to Commerce web store shoppers if other preferences or customer address information cannot be used to determine an appropriate shipping method. Set this preference if you'd like to preselect a carrier for shoppers when nothing else applies.

To learn more about setting a default carrier in NetSuite, see [Selecting a Default Shipping Carrier](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1265937.html#bridgehead_N1265950).

## Default Website Shipping Method {#bridgehead_N2462429}

The Default Website Shipping Method is the preferred shipping carrier displayed in Checkout. Set this preference if you want customers to see this option first at checkout. You can select a default shipping method for your website whether you use multiple carriers or not.

#### To select a default shipping method for a website: {#procedure_N2462442}

1.  Go to _Commerce > Websites > Web Site List_.
    
2.  Click **Edit** next to the website you'd like to change.
    
3.  On the **Shopping** subtab, in the Shipping Page section, select a shipping method in the **Default Website Shipping Method** field.
    
4.  Click **Save**.
    

Note:

To set up shipping methods that can be used outside Commerce websites, see the Order Management topic, [Setting Up Shipping](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1257579.html).

## Customer Information {#bridgehead_N2462510}

If a shopper placed a previous order through your website, the customer record stores the shipping method selected for the last order. This information updates each time the customer picks a shipping method on the order form. The shopper's previous shipping method choice is preselected in Checkout.
