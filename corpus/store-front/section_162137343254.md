The following procedures define prerequisite settings for using item images. Complete each step before you upload the item image files.

Tip:

You'll only need to set these up one time. Follow the steps to verify they are completed.

## Set the Image Domain and Image Folder {#subsect_162137364841}

Item image files are stored in the File Cabinet at Web Site Hosting Files > Live Hosting Files > images. Images in this folder are mapped to a corresponding item record. Only store item images in this folder. Avoid creating subfolders, as images in them won't map to item records.

Note:

Other images, such as banners and logos, are stored elsewhere. See [Site Management Tools Image Content Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4123521956.html) for more details.

#### To set the image domain and image folder:

1.  Go to _Commerce > Websites > Website List_.
    
2.  Click **Edit** next to your website name.
    
3.  Click the **Images** subtab.
    
4.  In the **Image Domain** field, select the domain you're going to use.
    
5.  In the **Image Folder** field, select the path to the images folder (Web Site Hosting Files : Live Hosting Files : images).
    
6.  Click **Save**.
    

## Define the File Name Format {#subsect_162137351115}

The file name format determines the structure of image file names. The file name is made up of components used to associate the file with its corresponding item record.

For more information about the parameters for renaming image files, see [Rename Image Files with the Item Identifier](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162137381373.html).

Definitions:

-   Item Identifier - The file name component that matches an item record field. It can be the Display Name/Code, UPC Code, URL Component, Item Name/Number, or a custom field. Images associated with a given record must begin with the item identifier.
    
    You can select the item identifier from the dropdown menu or create a custom field to use as the item identifier. Custom fields must be **stored** to be used as an item identifier.
    
-   Item ID Delimiter - The component used to parse the item identifier from the other file name components.
    
    -   Can be any combination of up to 5 supported characters. Supported characters: $ - \_ . + ! \* ' ( ) ,
        
    -   The default value is an \_ (underscore).
        
-   Structure Delimiter - the component used to parse subsequent elements of the file name structure.
    
    -   It can be any combination of up to 5 supported characters. Supported characters: $ - \_ . + ! \* ' ( ) ,
        
    -   It can be the same value as the Item ID Delimiter.
        
    -   The default value is a - (hyphen).
        

#### To define the file name format:

1.  Go to _Commerce > Websites > Website List_.
    
2.  Click **Edit** next to your website name.
    
3.  Click the **Images** subtab.
    
4.  Select an option from the **Item Identifier** dropdown list.
    
5.  Enter a character in the **Item ID Delimiter** field.
    
6.  Enter a character in the **Structure Delimiter** field.
    
7.  Click **Save**.
    

## Add Item Image Field to Field Sets {#subsect_162137370529}

You need to add the item image field to the **details** and **search** field sets to display images on your website. If you skip this step, images associated with item records won't appear in search results or on product details pages. For more information, see [Define Field Sets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2659559.html).

#### To add an item image field to field sets:

1.  Go to _Commerce > Websites > Website List_.
    
2.  Click **Edit** next to your website name.
    
3.  Go to the **Field Sets** subtab.
    
4.  Click on the **details** field set and edit the **Fields Included in Field Set** column.
    
5.  In the Field Set popup window, add a new row, and select **Item Images (Detail)** from the dropdown list.
    
6.  Click **Add**.
    
7.  Click **Submit**.
    
8.  Click **OK**.
    
9.  Repeat Steps 4 through 8 for the **search** field set.
    
10.  Click **Save**.
     

## (Optional) Configure Multi-Image Options {#subsect_162137376332}

With multi-image options, you can link an image to a specific item matrix option and display it when users choose that option. For example, if an item comes in different colors, you can use the color choice to switch to the corresponding image. When a user chooses blue, they'll see the blue image.

See the next step, [Rename Image Files with the Item Identifier](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162137381373.html), for an explanation of how to rename your files to use this capability.

The multi-image options feature only works with matrix items. See [Matrix Items](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2227654.html) for instructions on how to set up matrix items. You can set up multi-image for each transaction item option you created during [Setting Up Custom Transaction Item Options](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2228669.html#subsect_164383640667).

#### To configure multi-image options:

1.  Go to **Commerce > Websites > Configuration**.
    
2.  Select the website and domain you want to configure.
    
3.  Click the **Shopping Catalog** subtab and **Multi-Image Option** sublist.
    
4.  In the **Multi-Image Option** field, enter the ID of the custom transaction item option to trigger the multi-image option. You can add one or more options to make them available on your website.
    
    Note:
    
    You can find the ID on the record for the custom transaction item option. See step 2 of [Setting Up Custom Transaction Item Options](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2228669.html#subsect_164383640667) for more details.
    
5.  Click **Add** after entering each ID.
    
6.  Click **Save**.
    

After you configure multi-image options, they are ready for use. To use multi-image, connect images to their corresponding options by adding the option value to the file name. See [Rename Image Files with the Item Identifier](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162137381373.html) for more details.
