Upload your image files to the File Cabinet in the image folder as set during the step [Set the Image Domain and Image Folder](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162137343254.html#subsect_162137364841).

After images are uploaded they're automatically linked to their corresponding item records based on the item identifier. You can add or remove files from this folder whenever you need to. Images stored in a subfolder won't be recognized and won't link to item records.

To confirm your images uploaded correctly, check the Associated Images sublist on the item record's **Web Store** subtab.

#### To upload multiple images to the File Cabinet:

1.  Create a ZIP file on your computer with the images you want to upload.
    
    Tip:
    
    To unzip directly into the images folder, don't place images in a subfolder within the ZIP file.
    
2.  Go to _Documents > Files > File Cabinet_.
    
3.  Go to and open the images folder (Web Site Hosting Files : Live Hosting Files : images).
    
4.  Click **Advanced Add**.
    
5.  From the **Zip Archive to Add** field, select the ZIP file you created on your computer and click **Open**.
    
6.  Check the **Unzip Files** box to extract your files directly into the images folder.
    
7.  Check the **Make All Files Available Without Login** box to let all visitors view your images.
    
8.  Click **Add**.
    

#### To upload a single image to the File Cabinet:

1.  Go to _Documents > Files > File Cabinet_.
    
2.  Go to and open the images folder (Web Site Hosting Files : Live Hosting Files : images).
    
3.  Click **Add File**.
    
4.  Find the image on your computer and click **Open**.
