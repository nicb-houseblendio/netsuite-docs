This dataset combines fields from the Item, Item Segments, Personalization Rules, Customer Segments, and Customers record types so that you can select specific items and see which customers can see the items, see their prices, and buy them. This dataset forms the source data for the [Customers by Item Workbook](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158264433760.html).

## Dataset Configuration {#subsect_158264426811}

The source data used in the Customers by Item dataset combines fields from five record types. To edit the dataset, see [Defining a Dataset](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544122173.html).

| Root Record Type | Joined Record Type | Custom Formula Fields | Data Grid | Criteria Filters |
| --- | --- | --- | --- | --- |
| Item | Item Segments Personalization Rules Customer Segments Customers | (none) | The following records fields are included in the dataset. **Item:**
-   Item Name/Number

**Item Segments:**

-   Name

**Personalization Rules:**

-   Website Visibility Level

**Customer Segments:**

-   Name

**Customers:**

-   Entity ID

 | The dataset is filtered using the following criteria:

-   Website Visibility Level is either Display Fully, Disable Purchase and Hide Price, or Disable Purchase

 |
