When you click **Save**, **Save & Preview**, or **Save & View** on the Customer Segments Manager page, the website's search index gets reindexed. When reindexing is done, the personalized catalog views go live and your customers see the catalog that's meant for them. Making an item segment visible to a customer segment from a customer group record or an item collection record works the same way.

You can use SuiteAnalytics Workbooks and Site Management Tools Advanced Preview to check that Personalized Catalog Views is set up correctly, but only after you've saved the personalized catalog views. So, it's best to test personalized catalog views in a way that doesn't affect your live site.

There are two ways to test:

-   **Use test customer segments** - To make certain items visible or purchasable only to specific customers, add test customers to your customer groups and set up Personalized Catalog Views like you would for real customers. Make sure the Unmapped Items segment is set to Display Fully. That way, all real customers can see everything except the items you've mapped to test customers. After you've logged in as a test customer and checked that the correct items show up, you can add real customers to the customer group.
    
-   **Publish to a test website** - If your PCV setup is more complex, it's better to test everything in a sandbox account and publish to a test site to make sure the correct customers have access to the correct items.
