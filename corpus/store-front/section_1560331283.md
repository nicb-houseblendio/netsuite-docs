To set up Personalized Catalog Views (PCV), users need a valid NetSuite account and a role with the necessary permissions. The following roles have the required permissions by default:

-   Administrator (includes access to Site Management Tools)
    
-   Store Manager (includes access to Site Management Tools)
    
-   Marketing Manager
    
-   Sales Manager
    
-   Marketing Administrator
    
-   Sales Administrator
    
-   System Administrator
    

For more information, see [NetSuite Users & Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N284861.html).

## Customer Segments Manager Permission for an Existing Role {#subsect_1561380447}

Add permissions to a custom role to enable users to set up Personalized Catalog Views (PCV). Required permissions include:

-   **Customer Segments Manager** - Required for setting up PCV. Without this permission, users can't access the Customer Segments Manager or set up PCV. However, they can view which item segments are mapped to different customer segments on Customer Groups and Item Collections records.
    
-   **Commerce Categories** - Required only if commerce categories are used with PCV.
    
-   **Site Management Tools (SMT) permissions** - Required if users want to preview PCV in the website. Required SMT permissions include:
    
    -   Documents and Files
        
    -   Website (External) Publisher
        
    -   Website Management
        
-   **SuiteAnalytics Workbook and Analytics Administrator** - Required to view the standard SuiteAnalytics Workbooks that display which items are visible to which customer and which customer can see which item. The access level for these permissions is Edit.
    

You can't edit standard NetSuite roles, but you can use them as a basis for custom roles. For detailed instructions and best practices for customizing a NetSuite role, see [NetSuite Roles Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N285436.html).
