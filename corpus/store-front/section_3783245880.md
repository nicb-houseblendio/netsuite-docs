Important:

Google Analytics 4 (GA4) has replaced Google Universal Analytics (GAU) as Google's cross-platform Analytics solution. All standard GUA properties stopped processing new hits on July 1, 2023. 360 Universal Analytics properties will stop processing new hits on July 1, 2024. See [Google Analytics 4](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0104849037.html) for information about GA4, including information about migrating from GUA to GA4.

Google Universal Analytics is a third party analytics solution that can help you evaluate traffic on your website using data based on visitor tracking information.

Note:

The URL for parent and child matrix items is the same and will be tracked as the same by Google Universal Analytics.

To track visitor activity on your site, Google Universal Analytic can be implemented in the following areas:

-   **Commerce Web Stores**\-Shopping, Checkout, and My Account. See [GUA in Commerce Web Stores](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_3819645338.html).
    
-   **Site Builder**\-Site Builder and Reference Checkout. See [GUA for Site Builder with Site Builder Extensions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4550379461.html).
    
-   **External Catalog (WSDK)**\-In conjunction with your Site Builder site and Reference Checkout, you can also implement GUA on the External site for seamless GUA tracking. See [Step 5: GUA with Site Builder with Site Builder Extensions and an External Site (WSDK)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4550379461.html#bridgehead_4568622261)
    

After Google Analytics is enabled and configured, each page hit in the shopping area of your site is tracked. For the checkout area of the site, each item in the cart is tracked. When the order is completed, details of the order such as store name, shipping, state, country, and so forth are also tracked.

Note:

Do not implement the Google Universal Analytics module if you use Google Universal Analytics in Google Tag Manager because this causes duplicate tracking results. See [Google Tag Manager](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4546835898.html) for more information about Google Tag Manager.
