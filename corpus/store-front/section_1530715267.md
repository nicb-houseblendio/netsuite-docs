System email templates are used for all types of system-automated email in NetSuite, including website email. These templates can be customized and give you good control over the appearance and content of email sent from your web store. FFor example, you can change how ordered items show up and add product pictures.

If you have the Multi-Language feature enabled, you can set up multiple language versions of the same email template without needing to create individual templates for each language. Web store users receive the email message in their preferred language.

Website email templates have a preview feature that lets you see what the email will look like when it's sent to the customer. In the preview page, you can choose the website from which the email is sent, the language in which it's sent, and other key details, resulting in a preview that is an accurate representation of the email the web store customer will receive. For more information, see [Preview Website Email Templates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1541438310.html).

The following default email templates are available for website email messages at _Setup > Company > Email > System Email Templates_. They are mobile-friendly and are available in all languages supported by NetSuite:

-   **Template Category: Web Site Order Notifications**
    
    -   Standard Web Site Order Received
        
    -   Standard Web Site Order Canceled
        
    -   Standard Web Site Order Approved
        
    -   Standard Web Site Order Fulfilled
        
-   **Template Category: Web Site Digital Delivery Notifications**
    
    -   Standard Web Site Gift Certificate
        
    -   Standard Web Site Gift Certificate Confirmation
        
    -   Standard Web Site Download Available
        
    -   Standard Web Site License Code
        
-   **Template Category: Web Site Other Notifications**
    
    -   Standard Web Site Checkout Errors
        
    -   Standard Web Site Password Recovery
        
    -   Standard Web Site Registration Confirmation
        

For information about each type of email and details on how to select the email templates you want to use in the web store, see [Select Email Templates for your Web Site](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N2573247.html).

Note:

If you want to use standard email templates for your website email messages, you should create copies of them and customize them as needed. Don't use the original default templates as these may be updated in future releases.
