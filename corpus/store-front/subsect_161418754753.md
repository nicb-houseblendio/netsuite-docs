This dataset enables you to analyze how shoppers interact with the intelligent item recommendations displayed in your website. This dataset forms part of the source data for the [Intelligent Item Recommendations Workbook](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_161418756993.html).

## Dataset Configuration {#subsect_158264347049}

The Intelligent Item Recommendations dataset contains fields from three record types and one custom formula. To edit the dataset, see [Defining a Dataset](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544122173.html).

| Root Record Type | Joined Record Type | Custom Formula Fields | Data Grid | Criteria Filters |
| --- | --- | --- | --- | --- |
| Intelligent Item Recommendations | 
-   Conversions
-   Recommendation Scenario

 | The following custom formula is included in the dataset:

-   Click Through Rate - ABS({clickevents} / {showevents})

 | The following record fields are included in the dataset: **Recommendation Scenario**

-   Website

**Intelligent Item Recommendations**

-   Recommendation Scenario
-   Date
-   Show Events
-   Click Events
-   Carousel Events

 | (none) |
