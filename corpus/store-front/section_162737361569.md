Complete these tasks to set up ACH Payments for your Commerce website:

1.  [Install a Third-party SuiteApp that Supports ACH Payments](#subsect_1017014011)
    
2.  [Create a Payment Method](#subsect_162737510578)
    
3.  [Create a Payment Processing Profile](#subsect_162737474842)
    

## Install a Third-party SuiteApp that Supports ACH Payments {#subsect_1017014011}

To enable ACH, your NetSuite account administrator should install a third-party SuiteApp that supports ACH payments. See [SuiteApps Documentation Summary](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4347515321.html) for more information.

## Create a Payment Method {#subsect_162737510578}

Create a payment method by following the steps in the Order Management help topic, [Creating a Payment Method](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1292421.html). However, to make ACH payments work on your Commerce website, you need to perform these extra steps:

1.  Select **ACH** from the **Type** list.
    
2.  Check the **Display in Web Site** box.
    
3.  Save your ACH payment method, then create an ACH payment processing profile. See [Create a Payment Processing Profile](#subsect_162737474842).
    
4.  After you've created your ACH payment processing profile, edit your ACH payment method.
    
5.  Under **Associated Payment Processing Profiles**, select your ACH payment processing profile.
    

## Create a Payment Processing Profile {#subsect_162737474842}

Create an ACH payment processing profile so your website can support ACH payments.

#### To create an ACH payment processing profile:

1.  Ensure you've installed a third-party SuiteApp that supports ACH payments. See [Install a Third-party SuiteApp that Supports ACH Payments](#subsect_1017014011).
    
2.  Follow the steps in the Order Management help topic, [Setting Up an Alternative Payment Method Processing Profile](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4213266422.html#bridgehead_4214053110) to create a payment processing profile. However, to make ACH payments work on your Commerce website, you need to perform these extra steps:
    
    -   In the **Payment Information** area, under **Supported Payment Methods**, select your ACH payment method.
        
    -   In the **Payment Information** area, under **Gateway Request Types**, select **Authorization** and **Capture Authorization**.
