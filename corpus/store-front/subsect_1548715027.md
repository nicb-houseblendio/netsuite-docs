Configure properties to customize your map and contact information. You can adjust the layout, add email and call buttons, and include store information.

#### To configure map and contact information:

1.  Log into Site Management Tools. For details, see [Logging into Site Management Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4163262385.html).
    
2.  Go to the page that contains the Map & Contact content.
    
3.  Click the Edit Mode icon ![Edit Mode Icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/StoreFront/WebsiteContent/EditModeIcon.png) from the site management toolbar.
    
4.  Hover over the Map & Contact content to display the content controls.
    
5.  Click **Edit** to open the Map & Contact Settings in the side panel.
    
6.  Select the **General** subtab and set the following fields:
    
    | Field | Description |
    | --- | --- |
    | Name | This sets a description of your new content. |
    | Visibility | This sets the visibility option that determines when you would like to make the form visible. For more information , see [View Site as of a Specific Date in Site Management Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1513783026.html). |
    | Map Position | This sets the layout of the map and the contact information. In mobile screens, the Map & Contact information sections stack in order depending on whether you choose the left or right position. |
    | Tags | This sets keywords to help filter your content in the Review Changes list. For more information about content tags, see [Content Tags and Filter Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1524601707.html). |
    
7.  Select the **Map & Contact** subtab and set the following fields:
    
    | Field | Description |
    | --- | --- |
    | Header | This sets the title to display at the top of the Map & Contact box. |
    | Map HTML Snippet | This is where you paste the HTML code of your map location. To use third-party map services, such as Google or OpenStreetMap, paste the HTML code obtained by the map provider here. To optimize display size, nest the embedded map HTML code within an iframe element. |
    | Business Address & Information | This specifies information about your business, such as your postal address, opening hours, or special instructions. This field supports basic HTML formatting tags. |
    | Primary Phone Number | This sets the phone number to display for your business. Mobile users can tap a **Call us** button to call the primary phone number automatically. |
    | Primary Email Address | This sets the email address to display for your business. Mobile users can tap a **Contact us** button to send an email to the primary email address automatically. |
    | Hide Background Color | This determines if the background color is hidden. |
    | Hide Icons | This determines if the **Call us** and **Contact us** icons are hidden. |
    
8.  Click **Save.**
    
9.  Publish your changes. For details, see [Review and Publish Content in Site Management Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4419210472.html).
