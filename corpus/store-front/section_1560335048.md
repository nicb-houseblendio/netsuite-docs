If a customer can't see an item on your website that they should, check the settings in the flowcharts below to troubleshoot the issue.

-   [Item Settings](#subsect_156700408420)
    
-   [Commerce and Site Category Settings](#subsect_156700417414)
    
-   [Out of Stock Behavior Settings](#subsect_156700421603)
    
-   [Multi-Subsidiary Settings](#subsect_156700425235)
    
-   [Personalized Catalog View Settings](#subsect_156700428205)
    

Note:

Some of these settings are role-specific. If you can't access any of them, contact your administrator.

| **Flowchart Definitions** |
| --- |
| CUSTOMER | The customer to whom the item is not available |
| ITEM | The item that is not visible on the website |
| WEBSITE | The website on which the customer cannot see the item |
| DATE | The date on which the customer cannot see the item on the website |

**List B: Category Visibility**

If you answer YES to all these questions, the Commerce or Site Category will show up on the website.

For Commerce Categories only:

-   Is the website selected for the Commerce Catalog?
    
-   Is the **Inactive** box cleared for the Commerce Catalog?
    
-   Is the Commerce Category included in the Commerce Catalog?
    
-   Is the **Inactive** box cleared for the Commerce Category?
    
-   Is **Display in Web Site** checked for the Commerce Category?
    
-   Is Date within the period defined by the start and end date of the Commerce Category?
    

For Site Categories only:

-   Is the website selected for a Presentation tab?
    
-   Is the Site Category included on the Presentation tab?
    
-   Is the **Inactive** box cleared for the Presentation tab and the Site Category?
    
-   Is **Display in Web Site** checked for both the Presentation tab and the Site Category?
    
-   Is the Customer included on the Audience subtab of the Presentation tab and the Site Category?
