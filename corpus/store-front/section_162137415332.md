## Add Alternate Text {#subsect_162137417679}

Alternative text is crucial for your website. Alt text appears when an image can't be loaded. Alt text also helps with page readers and SEO. The alt text you enter is used in the HTML image element. For example `<img src='OM5447.media.blue.01.jpg' alt='blue waterproof Apparition jacket (front view)'>`.

You must add alt text to each image on the item record. Write a brief description of what's in the image. On the item record, alt text is limited to 35 characters. Alternatively, you can add alt text to the file record, which has a 199-character limit.

Here's an example of good alt text that was added on the file record:

![Associated images and alt text on the item record.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/StoreFront/Products/ItemImages_AltText_5.png)

Note:

You can only update alt text one image at a time, unless you use customization. To learn more about customization, see [Develop SCA Customizations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1519429410.html).

#### To add alt text to an image on the item record:

1.  Go to _Lists > Accounting > Items_.
    
2.  Click **Edit** next to the item record you want to update.
    
3.  Go to the **Web Store** subtab and find the **Associated Images** sublist.
    
4.  In the **Alt Image Tag** field, provide alt text for each image (up to 35 characters).
    
5.  Click **Update Matrix** (or **Save**).
    
6.  Click **Submit**.
    

#### To add alt text to an image using the file record:

1.  Go to _Documents > Files > File Cabinet_.
    
2.  Go to Web Site Hosting Files > Live Hosting Files > images.
    
3.  Click **Edit** on the image file you want to update.
    
4.  In the **Alt Image Tag** field, enter you alto text (up to 199 characters).
    
5.  Click **Save**.
    

## Make Images Available Without Login {#subsect_162137429522}

The ability to view images is controlled in the folder settings. This procedure shows you how to perform a mass update to ensure images are viewable to all website visitors.

If you've already done this during upload, you can skip this. This procedure ensures everything in the images folder is available without a login, regardless of how the files were uploaded.

Note:

By default, SuiteScript-uploaded files require a login, regardless of which folders the files are saved in. To make SuiteScript-uploaded files accessible without a login, set the parameter on the upload script or check the **Available Without Login** box. As of 2020.2, files uploaded using Web Services use the same Available Without Login rules as files uploaded using SuiteScript.

#### To perform a mass update of files to be available without login:

1.  Go to _Lists > Mass Update > Mass Updates_.
    
2.  Click **Files** to expand the options for files.
    
3.  Click **Make Files Available Online**.
    
4.  On the **Criteria** subtab, define which files to include in the update.
    
    1.  In the **Filter** column, select **Folder** from the dropdown menu.
        
    2.  In the popup window, select **any of** from the dropdown menu.
        
    3.  In the text box, search for the image folder by entering its location (Web Site Hosting Files : Live Hosting Files : images).
        
    4.  Click **Set**.
        
5.  Click **Add**.
    
6.  Click **Save**.
