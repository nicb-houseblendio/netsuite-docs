Warning:

Be aware of the following:

-   This information applies to SuiteCommerce or SuiteCommerce Advanced 2019.2 and later. Don't enable Personalized Catalog Views (PCV) if your site is using a SuiteCommerce Advanced release prior to 2019.2.
    
-   PCV isn't compatible with SuiteCommerce InStore (SCIS), so don't enable PCV if you use SCIS.
    
-   PCV isn't compatible with Intelligent Recommendations; if you use both, intelligent recommendations may display items that shouldn't be visible based on PCV settings.
    

The Personalized Catalog Views (PCV) feature enables you to provide different customers with access to different items. You can divide your customers into groups and provide each group with access to a tailored selection of catalog items​. You can control what each customer group can do: view items, view prices, make purchases, or all three, which is especially useful for B2B sites.

For example:

-   Businesses can grant VIP customers exclusive access to buy specific catalog items.
    
-   Businesses can show products to non-members, but require signing up before displaying prices, and paid membership before permitting purchase.
    
-   Retailers that are licensed to sell certain products in limited geographies can prevent customers in other geographic locations from seeing or buying those items.
    
-   Manufacturers that require customers to be certified to buy certain items can ensure that all customers can see the items but only certified customers can buy them.
    

PCV uses NetSuite records like Customer Groups, Commerce Categories, and Item Collections, along with the Customer Segments Manager tool, to personalize catalogs.

For more information about PCV, see the following topics:

-   [Setting Up Personalized Catalog Views](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1560331188.html) - Provides guidance on how to set up PCV including how to create customer and item segments, how to make item segments visible to customer segments, and how to check that the correct items are visible to the correct customers. The [Personalized Catalog Views Setup Checklist](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1560331188.html#subsect_1560347635) lists the main steps you need to take to set up PCV.
    
-   [Personalized Catalog View Examples](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1560356094.html) - Demonstrates how PCV is set up for the three use cases listed previously, namely, VIP customers, different catalogs based on customer location, and items restricted to certified customers.
    
-   [Troubleshooting Item Availability](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1560335048.html) - Lists the settings that can prevent items from being displayed to the correct customers in the web store.
