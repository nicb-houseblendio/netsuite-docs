The **Extensions** tab shows extensions that are available for activation. Use this tab to select any extensions to activate.

Important:

If you're activating any of the following themes, you must also activate the companion theme extension that comes with the SuiteApp.

-   Bridge Theme
    
-   Horizon Theme
    
-   Manor Theme
    
-   Posh Theme
    
-   Summit Theme
    
-   Threads Theme
    

For details, see [Available Commerce Themes and Supported Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158695491035.html).

#### To activate extensions:

1.  On the Activate Themes and Extensions page, select the **Extensions** tab.
    
2.  Check the **Active** box next to any extensions you want to activate.
    
    You can activate as many extensions as you want for a domain or none at all.
    
    ![Activate Themes and Extensions Page Extensions Subtab](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/StoreFront/ThemesExtensions/ActivationManagerExtensionActivation.png)
3.  To deactivate an extension, clear the associated **Active** box.
    
4.  Do one of the following:
    
    -   If you want to select a theme to activate, select the **Themes** tab and see [Activating a Theme](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1549039282.html).
        
        You must choose a theme to proceed with the activation.
        
    -   If you're ready to process your activations, click **Activate**.
        
    -   To cancel the activation, click **Cancel**.
        
5.  If this is the first activation for a domain, clear the domain's cache by triggering a cache invalidation request. See [Cache Invalidation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4169406426.html) for details.
