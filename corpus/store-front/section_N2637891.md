You can create URL redirects in NetSuite to make your web pages available under different URLs. This comes in handy if you move your site to a new domain or need to redirect a commonly misspelled domain.

URL redirection helps search engines that have already ranked your pages find your new site and update their links. Search engines treat URL redirects made in NetSuite as **301 moved permanently** redirects.

NetSuite provides the following ways for you to set up URL redirects:

-   You can add or update URL redirects one at a time on the Redirect record page. See [Setting Up a URL Redirect](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2638072.html).
    
-   You can swap redirect domains to move several URL redirects from one domain to another. See [Updating Redirect Domains](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2638305.html).
    
-   You can bulk add or update URL redirects by importing a CSV file. NetSuite has an import assistant and template for this. See [Importing Website Redirects](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2638492.html).
    
-   You can delete URL redirects in bulk with a mass update action. See [Delete Web Site Redirects Mass Update](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2638981.html).
