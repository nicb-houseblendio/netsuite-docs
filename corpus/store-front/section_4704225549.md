To prepare your site to use SuitePromotions:

1.  Enable SuitePromotions features.
    
2.  Set up SuitePromotions records.
    
3.  Configure SuiteCommerce Advanced to use SuitePromotions.
    

#### Step 1: Enable SuitePromotions Features

1.  In NetSuite, go to _Setup > Company > Enable Features_.
    
2.  On the Transaction tab, check the following boxes in the **Sales** section:
    
    -   Promotion Codes
        
    -   SuitePromotions
        
    -   Auto-apply Promotions
        
3.  Save the record.
    

#### Step 2: Set Up SuitePromotions Records

1.  Create SuitePromotions. See [Creating Promotions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4692029228.html).
    
2.  Apply promotions and view the status of applied promotions. See [Applying Promotions and Discounts to a Transaction](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4692024512.html).
    
3.  Get the most out of SuitePromotions. See [SuitePromotions Best Practices](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4692032817.html).
    

#### Step 3: Configure SuiteCommerce Advanced to use SuitePromotions

1.  In NetSuite, go to Commerce > Websites > Configuration.
    
2.  Select the website and domain to configure, then click **Continue**.
    
3.  On the **Shopping Catalog** tab, check **Allow Adding More Than One Promocode** to enable stackable promotions.
    
4.  Click **Save**.
    
5.  Go to _Commerce > Websites > Web Site List_.
    
6.  Click the **Edit** link for your website.
    
7.  On the **Shopping** tab, under Promotions, check **Auto-Apply Promotions**.
    
8.  Click **Save**.
    

Note:

If you intend to use the SuitePromotions feature, enable all prerequisites. You must enable both **Auto-Apply Promotions** and **Allow Adding More Than One Promocode** to use SuitePromotions in your web store. Remove all configuration prerequisites if you don't intend to use SuitePromotions.
