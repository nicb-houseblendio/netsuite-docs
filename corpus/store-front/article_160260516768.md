A workbook is where you analyze the results of a query against one or more datasets. You can build workbook visualizations such as tables, pivot tables, and charts to help with your analysis.

Use this procedure as a starting point to build an Analytics Workbook for SuiteCommerce Analytics Data. The procedure uses fields found in the [Record Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160261792908.html) topic.

For a discussion on using Analytics Workbooks, see [SuiteAnalytics Workbook Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1503949328.html). For additional details on setting up a workbook, see [Creating a Workbook](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544211284.html).

Note that data available for your Analytics Workbook is historical but refreshed daily. The analytics data feature isn't designed for real-time views.

## Overview Steps {#subsect_163163727318}

These brief steps are an overview of setting up a workbook for SuiteCommerce Analytics Data.

1.  Create a **New Dataset** using the **Session** or **Customer** record type.
    
2.  Build the data set by finding and dropping the desired **Session** fields to the table.
    
3.  Add filters by finding and dropping **Session** fields to the **Criteria** bar.
    
4.  Review the results.
    
5.  **Save** your workbook.
    

![Overview of workbook creation steps](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/SuiteCommerceAnalyticsData/Overview_Workbook.png)

## Detailed Steps {#subsect_163163728406}

These steps include detailed steps for workbook creation. Follow the links for additional information.

#### To create an Analytics Workbook:

1.  Go to Analytics > Workbooks tab.
    
2.  Click **New Workbook** in the upper right.
    
    ![New Workbook button](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/SuiteCommerceAnalyticsData/New_Workbook.png)
3.  Click **New Dataset** in the upper right.
    
    Tip:
    
    If you already have a dataset, you can click the **Dataset Name** instead of creating a new dataset.
    
    ![New Dataset button](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/SuiteCommerceAnalyticsData/New_Dataset.png)
4.  Select a record type to analyze. Use the search bar to locate a record type. Enter any word or character from the record type name. No wild cards are needed.
    
    See [Record Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160261792908.html) for a list of records used in SuiteCommerce Analytics Data.
    
5.  Select the desired fields and criteria filters.
    
    See [Defining a Dataset](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544122173.html) and [Dataset Criteria Filters](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544211200.html).
    
    Tip:
    
    Use the session record as the basis for all filters.
    
6.  Click **Apply to workbook**.
    
7.  To add another dataset, click **Connect Dataset**.
    
    1.  Select a record type to analyze.
        
    2.  Select the desired fields and criteria filters.
        
    3.  Click **Apply to workbook**.
        
8.  Choose a **visualization type**.
    
9.  Edit the layout and formatting as desired.
    
    See [Workbook Table Views](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158083630457.html), [Workbook Pivot Tables](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158042187611.html), or [Workbook Charts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544211366.html).
    
10.  Click **Save**.
     
11.  Enter a name and description for the workbook and click **Save**.
     
12.  (Optional) Click **Share** to share the workbook with other users in your NetSuite account.
     

#### To open an existing workbook:

1.  Go to Analytics > Workbooks tab.
    
2.  Click a workbook tile or enter a workbook name in the search bar.
    
    To search, enter any word or character from the workbook name. No wild cards are needed.
    
    Tip:
    
    Workbook tiles labeled **Template** include the dataset only. You must select the fields and criteria.
    
    ![Existing Workbook search field](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/SuiteCommerceAnalyticsData/Existing_Workbook.png)
3.  To retrieve the most current data, click the More icon ![More menu icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/SuiteCommerceAnalyticsData/More_menu_icon.png) and click **Clear cache**.
    
4.  Click **Save** or **Save As** if you make changes.
