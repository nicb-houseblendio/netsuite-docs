Use this topic to enable the analytics data feature and install/configure the cookie consent extension.

## Prerequisites {#subsect_162696485572}

The SuiteCommerce Analytics Data feature requires these or later application versions:

-   NetSuite 2021.2
    
-   SuiteCommerce 2021.2 or
    
    SuiteCommerce Advanced 2021.2
    

The SuiteCommerce Cookie Consent extension prerequisites are the same as for the feature:

-   NetSuite 2021.2
    
-   SuiteCommerce 2021.2 or
    
    SuiteCommerce Advanced 2021.2
    

Tip:

SuiteCommerce is a NetSuite-managed product. New releases are applied to accounts automatically. SuiteCommerce Advanced requires manual upgrades.

Important:

Install the SuiteCommerce Cookie Consent extension only if you will use the SuiteCommerce Analytics Data feature.

if you aren't using this feature, use the standard cookie-consent setup.

## Installation Tasks {#subsect_162696557602}

Use each set of steps to add SuiteCommerce Analytics Data to your web store environment.

1.  [Enable the SuiteCommerce Analytics Data Feature](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_162690227190.html)
    
2.  [Install the SC Cookie Consent Extension](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_162690245617.html)
    
3.  [Activate the Extension for Your Web Store Domain](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_162690256151.html)
    
4.  [Configure the SC Cookie Consent Extension](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_162429920925.html)
    
5.  [Add Required Footer Links to Cookie Policy and Settings](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_162748768444.html)
    
6.  [Using Extensibility For a Custom Cookie Consent Process](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_163104289171.html) (Optional.)
    

Tip:

NetSuite extensions are also called 'SuiteApps.'
