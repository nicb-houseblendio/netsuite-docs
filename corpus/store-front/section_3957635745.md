Product Lists custom records store and manage product lists each customer's product lists. You can access these custom records from the **SuiteCommerce Extensions** tab of the customer record.

To use Product Lists, first install the Reference Product Lists Records SuiteApp. See [Install Your Commerce Website Applications](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2675216.html) for detailed information about how to install this SuiteApp.

Note:

You need the Reference Product Lists Records SuiteApp for the Elbrus release of SuiteCommerce Advanced, even if you don't use Product Lists records.

The following records are added when the SuiteApp is installed:

-   **Lists**:
    
    -   **Product Lists Type** lets you define lists as default, predefined, later, or quote. Any list a user adds is automatically set to default. Your users automatically have access to predefined lists. Lists set to later let users save items to buy later. Lists set to quote let users ask for a quote on a list of items.
        
    -   **Product Lists Scope** lets you set lists as private, public, or shared. Currently, only private lists are supported, and each list is set as private by default. Only the logged-in users can view and manage private lists.
        
        Note:
        
        You can set up predefined lists in the website configuration file or the customer record. If you define a predefined list in a customer record, only that customer can use it. It's best to set up predefined lists in the website configuration file so all customers can use them. A predefined list only displays in the customer record when the customer adds items to it. For information about configuration procedures, see [Configuring Product Lists](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3952550980.html).
        
-   **Records**:
    
    -   **Product Lists Items** lets you manage item data linked to a product list.
        
    -   **Product Lists** lets you manage product list data.
        
    -   **Product Lists Items Priority** is used to prioritize items within a product list. This functionality is currently not supported.
        
-   **Subtabs**: The **Product Lists** subtab is displayed under the **SuiteCommerce Extensions** tab in the customer record. See [SuiteCommerce Extensions Tab](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_3962681391.html). The **Product Lists Items** subtab is displayed under the **SuiteCommerce Product Reviews** tab in the item record.
    

You can customize these records if required.

Note:

If the Reference Product Lists Records SuiteApp is not installed:

-   Product lists don't display on the Wishlist page in My Account.
    
-   Users will see an error if they try to add an item to a product list in ShopFlow.
