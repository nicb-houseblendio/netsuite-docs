There are several ways to group items in Commerce web stores-some methods have specific purposes, whereas others are more general. The table below explains all the available item grouping methods and shows how they're different.

| \- | **Grouping Methods** |
| --- | --- |
| **Item Collections** | **Commerce Categories** | **Merchandise Hierarchy Nodes** |
| **Main Purpose** | General purpose | Web store navigation | Reporting |
| **Description** | Item collections are a general way to group items. Used by Personalized Catalog Views. For more information, see [Personalized Catalog Views](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557154874.html). | Commerce Categories let you create a hierarchy of product categories, subcategories, and products for your web store's navigation. | Merchandise Hierarchy Nodes help you organize your merchandise so you can run reports to spot market trends and analyze shopper behavior. |
| **Web Store Availability?** | Available for use with:
-   NetSuite
-   NetSuite web stores

 | Available only for NetSuite web stores. | Available for use with:

-   NetSuite
-   NetSuite web stores

 |
| **Cardinality** | Many to many | Many to many | One to many A Merchandise Hierarchy node can have multiple items, but each item can only be in one node. |
| **Member Definition** | 

-   Static (manual selection)
-   Dynamic (based on saved searches)

 | Static (manual selection) | Static (manual selection) |
| **Date Effectivity** | Does not support date effectivity. | Supports date effectivity, that is, Start Date and End Date. | Supports date effectivity, that is, Start Date and End Date. |
| **More Information** | [Item Collections](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1561369306.html) | [Commerce Categories](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4673202005.html) | [Merchandise Hierarchy](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1499435959.html) |

Note:

There are other ways to group items in NetSuite, like item groups, kits and assemblies, and Site Builder-specific methods like Site Categories. For more information, see [Groups, Assemblies, and Kit/Packages](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2318089.html) and [Site Builder Tabs & Categories](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N2595349.html).
