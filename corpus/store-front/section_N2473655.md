You can refund PayPal Express Checkout orders in NetSuite without logging in to PayPal. After PayPal Express Checkout is enabled and set up, you can refund orders made with either the Express Checkout button or PayPal payment option

You can issue full, partial, or multiple refunds on PayPal orders if the total refund doesn't exceed the original amount. You can't refund transactions if the funds haven't been captured yet.

See the Order Management topic, [Refunding an Open Balance](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1313840.html), for information about the process to refund a customer in NetSuite.

Note:

If PayPal Express Checkout isn't enabled, then transactions processed using the PayPal payment option can't be refunded in NetSuite. You need to issue the refund using the same payment method the customer used for the original transaction.
