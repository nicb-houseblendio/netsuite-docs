On the Web Site Setup page, you can set preferences for sending email messages for Commerce web stores.

-   See [Set Website Email Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2572962.html) for information about how to set the default **from** email address and the header and footer of website email.
    
-   See [Select Email Templates for your Web Site](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N2573247.html) for information about how to set email preferences, such as when the email is sent, to whom the email is sent, and the content of the email, for different types of email messages sent from the web store.
    

If you have multiple websites, you can set preferences and select different email message templates for each site.
