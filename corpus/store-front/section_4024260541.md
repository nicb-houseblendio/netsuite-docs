Using the Save for Later feature, users can move items from the Cart to a list for later reference and then add items from the Save for Later list directly to the Cart.

Note:

The Save for Later feature is built on the same architecture as Product Lists.

Save for Later provides the following functionality:

-   Items in the Save for Later list are restored with each login session.
    
-   By default, users can change the quantities in the Save for Later list.
    
-   When an item in a Save for Later list goes out of stock, shoppers can't add it to their cart and they'll see an out of stock message.
    
-   If a shopper isn't logged in, they'll be sent to the Login page when they click **Save for Later** on an item in their cart
