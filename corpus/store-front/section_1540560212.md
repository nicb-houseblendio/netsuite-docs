This information refers to SuiteCommerce or the 2019.1 release of SuiteCommerce Advanced or later.

Content Management System (CMS) Page Types let you create page types in Site Management Tools that define a set of attributes that you can apply to the page. For example, you can create a page type for a specific extension, and then group and manage specific types of content. The available NetSuite extensions offer a variety of features that increase functionality. For more information, see [Commerce Extensions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1530632028.html).

CMS Page Type records are defined in NetSuite and cannot be defined in Site Management Tools. For details on how to create a CMS Page Type, see [CMS Page Type Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1546462905.html). After you create a CMS Page Type, you must register the page for it to appear in the Pages menu and render correctly. For details, see [Register a Page Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1547242730.html).
