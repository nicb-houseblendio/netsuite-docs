You can target merchandising zones with different content using merchandising rules. Selection criteria are based on the available facets and sort options you set during SuiteCommerce Advanced website setup.

Note:

Merchandising rules are only available for SuiteCommerce Advanced websites.

#### To create a merchandising rule: {#procedure_0606053724}

1.  Go to _Setup > SuiteCommerce Advanced > Merchandising Rules > New_.
    
2.  In the **Merchandising ID** field, enter a name for the merchandising rule.
    
3.  In the **Merchandising Title** field, enter a title for the merchandising rule.
    
4.  In the **Description** field, enter a short description for the merchandising rule.
    
5.  From the **Site** field, select the website where you want this rule to appear.
    
6.  In the **Field Set** field, select a field set for the merchandising rule. Field sets filter item records to determine which results this rule returns.
    
    Note:
    
    Field sets are defined during the initial website setup. Only the field sets associated with the selected website are available. If your merchandising zone doesn't display properly after you add it, the field set may not be set up correctly. For more information about field sets, see [Define Field Sets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2659559.html).
    
7.  Enter the maximum **Number of Results** the rule should return (between 0 and 100). Pick a number that fits your website's page layout for these items.
    
8.  In the **Filter** subtab, enter your filter criteria. You can filter items based on the search index facet fields defined for your website.
    
    Note:
    
    Facet fields are defined during the initial website setup and are used to determine item filter criteria available on the website. For more information about facet fields, see [Select and Configure Facet Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2657346.html).
    
9.  If desired, check the **Apply on Current Selections** box. When this is enabled, the current search criteria is included in the item search API query.
    
10.  In the **Filter** column, select a field from the list. After you select a filter, a popup opens for you to set up values. The options change based on the field you pick. Enter the filter criteria for your rule.
     
     Note:
     
     Depending on the filter, you can check the **Current Selection** box if you only want items shown when they match the current session's search criteria. When you use Commerce Categories in the **Filter** column, enter the commerce category name in the **Value** column. To learn more, see [Commerce Categories](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4673202005.html).
     
     Important:
     
     When working with matrix items, you might see inconsistent results if custom field values differ between the parent and child items. Set the custom field on the parent item first, then use **More Actions > Update Matrix** to update the child items.
     
11.  Click **Set** to close the popup.
     
12.  Click **Add** to save the line.
     
13.  From the **Sort** subtab, enter your sort criteria. You can sort items by the sort fields set up for your website. Sort fields are defined during the initial website setup and are used to determine the sort order of search results on the website. For more information about defining sort fields, see [Select and Configure Sort Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2659294.html).
     
14.  In the **Sort** column, select the field you want results sorted by. The available fields depend on your selected website.
     
15.  Select **Ascending** or **Descending** in the **Sort Option** column.
     
16.  Click **Add**. Sorting is applied in the order each field is entered.
     
17.  In the **Advanced** subtab, you can specify items to exclude and choose a custom template. If left blank the default template is used. For more information, see [Merchandising Zone Template](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4158274442.html).
     
18.  Click **Save**.
