Add size charts to your web store with the Size Chart extension, letting shoppers view sizing options without leaving the Product Details page (PDP). In addition to a pop-up feature on the PDP, Size Chart also creates a specific landing page where shoppers can view several size charts.

Using this extension, you can provide size information in shoppers' preferred units and offer measurement and fit tips.

Important:

Commerce extensions are available if you provision, install, and activate them for a selected domain in your account. For more information, see [Commerce Extensions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1530632028.html).

Note:

You need SuiteCommerce or the Aconcagua release of SCA or later to use extensions.

This topic explains how to:

-   [Update the Field Sets](#subsect_156089359144)
    
-   [Assign a Size Chart to an Item](#subsect_156089360347)
    
-   [Customize the Size Charts](#subsect_156089361418)
    

## Size Chart Page {#bridgehead_156381854880}

The Size Chart extension creates a size chart landing page with all the size charts for your website at example.com/size-charts.

You access individual size charts by using the size chart record's internal ID and name in the URL. Any spaces in the size chart name are replaced by underscores. For example, to display a size chart named Women's Tops, the URL is example.com/size-charts/1-Womens\_Tops.

## Update the Field Sets {#subsect_156089359144}

The field sets for a website determine the data that is exposed to site templates. to use the Size Chart feature, add the Size Chart (Custom) and Size Chart ID (Custom) fields to your site's field sets. For more information, see [Define Field Sets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2659559.html).

#### To add Size Chart fields to the Web Site Setup Record:

1.  Go to _Commerce > Websites > Website List_.
    
2.  Click **Edit** next to the website to which you are adding Size Charts.
    
3.  Go to the **Field Sets** subtab.
    
4.  Add the **Size Chart (Custom)** and **Size Chart ID (Custom)** fields to the **details** and **matrixchilditems** field sets. To add each field to each field set, perform the following steps:
    
    1.  Locate the **Fields Included in Field Set** column and click the **Set** button.
        
    2.  Select the fields from the **Field Name** list and click **Add.**
        
    3.  In the Field Set window, click **Submit.**
        
    4.  In the Field Set row, click **OK.**
        
5.  After adding all the fields to the field sets, click **Save.**
    

## Assign a Size Chart to an Item {#subsect_156089360347}

You determine the size chart to display when shoppers click the size chart link on the Product Detail page (PDP). The size chart link only appears if you've selected a size chart on the Item record.

You can update item records individually or use mass update to add Size Charts to entire commerce categories. For more information about using the mass update functionality, see [Mass Updates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1103335211.html).

#### To assign a size chart to an item:

1.  Go to Lists > Accounting > Items.
    
2.  Click **Edit** next to the item to which you want to add a size chart.
    
3.  Go to the **SuiteCommerce Extensions** subtab, then the **Size Charts** subtab.
    
4.  In the **Size Chart** field, select the size chart you want to assign to the item.
    
    Note:
    
    You can only assign one size chart to an item.
    
5.  Click **Save.**
    
    -   If it's a Matrix Item, click **Update Matrix**.
        
    -   If not, click **Save.**
        

## Customize the Size Charts {#subsect_156089361418}

The Size Chart extension comes with 19 default size charts for your web store. These size charts include standard measurements in imperial and metric units for women's, men's, kid's, and baby's apparel. You can use the existing size charts or create new ones.

#### To add a new size chart:

1.  Go to Lists > Web Site > Size Charts > New.
    
    Note:
    
    Making changes to the default size charts overwrites the existing values. To create a new chart using another size chart as a template, view the chart and click **Make Copy**.
    
2.  Set the following fields:
    
    | Field | Description |
    | --- | --- |
    | Inactive | If checked, makes the size chart inactive. |
    | Name | Sets the name for the size chart. This name appears in the **Size Chart** field of the Item record. |
    | Title | Sets the title to display at the top of the size chart on your site. |
    | Description | Determines additional details to display with the size chart on your site, such as fit of the clothing and tips on taking measurements. |
    | Chart | Determines the size chart to display. You can use the basic formatting tools in Formatted Text editing mode or enter HTML tags using the Source editing mode. |
    
3.  Click **Save**.
