The Product Lists (Wishlists) feature lets users create and manage lists of items they want to buy from your Commerce website. With Product Lists, users can do the following:

-   Add items to a product list while browsing your website.
    
-   Create new lists when adding items.
    
-   Edit item order details on product list pages.
    
-   Move items between lists.
    
-   Add a list to the shopping cart with one click.
    
-   Reorder lists of items.
    

Note:

Product lists only work on SuiteCommerce websites.

With Product Lists, users can add items to a predefined or custom list:

-   **Predefined lists** are automatically available to your users. By default, one predefined list, My List, is available. You can set up your website to have multiple predefined lists. Alternatively, you can set up your website with no predefined lists, so users must always create custom lists.
    
-   **Custom lists** are created by the user. Users can add these lists on the product list page or create them when they add an item to a list. You can set up your website so users can't create custom lists.
    

For example, you can give your users two predefined lists, like Gifts and Favorites. Users can add items to either of these predefined lists, or create a new list, like Christmas, and add items there.

Note:

Logged-in customers and their contacts can see both predefined and custom lists.

For more information about configuring a website for predefined and custom lists, see [Configuring Product Lists](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3952550980.html).
