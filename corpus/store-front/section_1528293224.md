The Slideshow extension lets you add a carousel of images to your website using Site Management Tools (SMT). You can upload multiple images, set the image focus, and pick a dark or light overlay. Images slide automatically, and you control how long each slide appears. Add links or call-to-action buttons to each image, set the text color to match your theme, and choose where the content goes. For example, use Slideshow to showcase featured products or highlight new collections.

Important:

Commerce extensions are only available if provisioned, installed, and activated for a selected domain in your account. For more information, see [Commerce Extensions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1530632028.html).

Note:

Extensions require SuiteCommerce or the Aconcagua release of SCA or later.

You can add a slideshow to multiple areas on your website using SMT. For more information about Site Management Tools, see [Site Management Tools Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4165123763.html).
