The SuiteCommerce Analytics Data session record tracks a shopper's visit to a web store. A session can be active for up to 24 hours.

| Analytics Workbooks | Saved Search | Content |
| --- | --- | --- |
| Label | Type | Label | Type | Provides |
| --- | --- | --- | --- | --- |
| **Device** | Select | **Device: Device Category** | Select | Category of device used to visit web store |
| **Geography** | Select | **Geography: City** **Geography: Country** **Geography: State** | Text Select | Shopper's geographical location during the session. |
| **Start Time** | DateTime | **Start Time** | DateTime | Session start date and time |
| **End Time** | DateTime | **End Time** | DateTime | Session end date and time |
| **Site** | Select | **Site** | Select | Web store URL visited by the shopper |
| **Customer** | Select | **Customer** | Select | Information about the shopper |
| **Referral Source** | Text Select | **Referral Source** | Text | Source from which the shopper accessed the web store, such as a search or campaign |
| **Campaign Analytics** | Select | **Campaign Analytics: Campaign** **Campaign Analytics: Campaign Term** | Text Select | Campaign details when a campaign was the referral source |
| **Landing Page Title** | Text Select | **Landing Page Title** | Text Select | Title of page where the shopper entered the web store |
| **New User** | Boolean | **New User** | Box | Identifies if session is shopper's first visit to web store as a registered user |
| **Journey** | Select | Not available | Not available | Lists any transactions made when browsing web store |
| **User Interaction** | Select | **User Interaction** | Select | Shopper's interactions with web store pages, searches, and items |
| **Search** | Select | **Search** | Text Select | Search terms entered when visiting web store |
