The Product Reviews record shows all reviews for an item. You can find it in the Item record under SuiteCommerce Product Reviews > Product Reviews. Moderators can review and manage which reviews appear on your site.

Note:

Indexing for Commerce websites is performed when item elements, such as product review attributes or review statuses, are changed. Therefore, changes to item records may take a few minutes to appear on your site. Check the indexing status by clicking the icon under the Search Index Status column of the website at _Commerce > Websites > Website List_.

In the top panel of the SuiteCommerce Product Reviews tab, you can view product review analysis and configure product review attributes. The following fields are available:

-   **Product Reviews Attribute Rating** - Lists the average ratings for each attribute in a JSON object.
    
    The JSON object consists of a name value pair with the Attribute ID and the calculated average rating. You can check attribute IDs on the Product Reviews Attributes (ID customlist\_ns\_pr\_attribute) custom record by going to _Customization > Lists, Records, & Fields > Lists_.
    
    For example, {"3":"3.0","2":"2.7","1":"3.0"} indicates average ratings of each of the three default attributes where Quality is ID 1, Price is ID 2, and Durability is ID 3.
    
-   **Product Reviews Count** - Displays the total number of reviews for the item.
    
-   **Product Reviews Rating** - Displays the overall rating for the item.
    
-   **Product Reviews Attributes** - Displays the attributes set for the item. For more information, see [Product Review Attributes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3855217334.html).
    
-   **Product Reviews Rating by Rate** - Lists the total count for each overall rating score in a JSON object.
    
    The JSON object consists of a name value pair with the overall rating value and the number of reviews set to that rating.
    
    For example, {"1":"1","4":"2"} indicates one instance of an overall rating of 1 and two instances of an overall rating of 4.
    

Note:

Product review statistics are only calculated for reviews that have been approved.

Here are some key details about line items on the Product Reviews record:

-   If a shopper submits a review after buying the product, the **Verified Purchase** field is set to **Yes**.
    
-   By default, only approved reviews appear on the site and are included in the product review rating analysis.
    
-   The **Writer** field corresponds to the Customer ID of the shopper who submitted the review. It is only populated for logged-in users.
