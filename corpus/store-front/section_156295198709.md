The Gift Certificate Management extension lets you include a gift certificate section on shoppers' My Account pages. Users can use this section to check the remaining balance of their gift certificates and store gift certificates in one place.

When a user orders a gift certificate, the extension checks if the recipient's email address is associated with an account of your web store. If the recipient has an account, the extension automatically stores the gift certificate in the gift certificate section of the recipient's account.

After storing a gift certificate, users can see the following gift certificate details:

-   Code number
    
-   Remaining balance
    
-   Expiration date
    
-   Sender
    
-   Date sent
    
-   Original amount
    

Note:

If you use a theme based on SuiteCommerce Base Theme 19.1 or earlier, the gift certificate section of My Account does not appear on mobile devices. Mobile users can still use the gift certificate value check feature on a landing page.

## Configure Gift Certificates in My Account {#subsect_156295531015}

Use the SC Configuration record to enable gift certificate value check and storage on the My Account page. You can determine the feedback messages and appearance of the Gift Certificate Table in My Account.

#### To configure Gift Certificates in My Account:

1.  In NetSuite, go to Commerce > Websites > Configuration.
    
2.  Select the website and domain where the Gift Certificate Management extension is activated and click **Configure**.
    
3.  Go to the **Extensions** tab, **Gift Certificate Advanced** subtab.
    
4.  In the **Gift Certificate My Account** section, check the **Enable Gift Certificates in My Account** box to show Gift Certificates in the My Account application.
    
5.  Fill out the listed fields for each category, using the tables below as references.
    
6.  Click **Save**.
    
    **My Account Fields:**
    
    | Field | Description |
    | --- | --- |
    | Page Title - My Account | Sets the title for the My Account page. |
    | Available Balance Label - My Account | Sets the label to display the available balance of a gift certificate. |
    
    **Table Fields:**
    
    | Field | Description |
    | --- | --- |
    | Title - Gift Certificate Table | Sets the title for the gift certificate table. |
    | Description - Gift Certificate Table | Determines the description for the gift certificate table. |
    | Code - Gift Certificate Table | Sets the label for the gift certificate code column of the gift certificate table. |
    | Remaining Balance - Gift Certificate Table | Sets the label for the remaining balance column of the gift certificate table. |
    | Expiry Date - Gift Certificate Table | Sets the label for the expiration date column of the gift certificate table. |
    | Sender - Gift Certificate Table | Sets the label for the sender column of the gift certificate table. |
    | Date Format | Determines the format in which the date appears. |
    | Date Sent - Gift Certificate Table | Sets the label for the date sent column of the gift certificate table. |
    | Original Amount - Gift Certificate Table | Sets the label for the original amount column of the gift certificate table. |
    | Expired Label - Gift Certificate Table | Determines the message to display in the remaining balance column of the gift certificate table when the gift certificate has expired. |
    | Remove - Gift Certificate Table | Sets the label for the remove gift certificate link in the gift certificate table. |
    | Copy Icon Help - Gift Certificate Table | Determines the help message for the copy icon. |
    | Copy Confirmation - Gift Certificate Table | Determines the confirmation message that appears when the gift certificate code is copied to the clipboard. |
    | More Details - Gift Certificate Table | Sets the label to show more details of the gift certificate table in mobile versions. |
    | Less Details - Gift Certificate Table | Sets the label to show fewer details of the gift certificate table in mobile versions. |
    
    **Messaging Fields:**
    
    | Field | Description |
    | --- | --- |
    | Code Saved to My Account | Determines the message to display after a gift certificate code has been successfully saved. Message stays visible for five seconds. |
    | Code Removed from My Account | Determines the message to display after a gift certificate code has been successfully removed. Message stays visible for five seconds. |
    | Undo Remove Code from My Account | Sets the label for the button to undo the remove gift certificate code action. |
    | Duplicate Code in My Account | Determines the message to display if a duplicate gift certificate code is entered. |
    | Expired Code Warning Message | Determines the message to display if an expired gift certificate code is entered. |
    | General Warning | Determines the message to display when there is an error with saving, loading, or deleting. |
