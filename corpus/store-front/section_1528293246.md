The Photo Gallery extension lets you add an image gallery to your web page using Site Management Tools (SMT).

Important:

Commerce extensions are only available if provisioned, installed, and activated for a selected domain in your account. For more information, see [Commerce Extensions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1530632028.html).

With the Photo Gallery extension, you can:

-   Select the size and style of the gallery.
    
-   Customize the display with animation effects.
    
-   Add a heading and description to each image.
    
-   Choose text colors to match your look.
    
-   Add light or dark photo overlays.
    

You can link any image to a page inside your site or to an external site. For example, feature new arrivals and link to the Product Details pages. Use SMT to add, configure, or delete a photo gallery in multiple areas of your website.

Note:

Extensions require SuiteCommerce or the Aconcagua release of SCA or later.
