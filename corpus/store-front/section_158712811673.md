Commerce themes, versions 3.0.0 and later will be managed bundles only. Unmanaged bundles will no longer be supported. To receive new features, you need to update your account to use the managed theme bundle.

Important:

When you update any of the Commerce themes, you must also update the companion theme extension that comes with the SuiteApp. For details, see [Available Commerce Themes and Supported Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158695491035.html).

Important:

If you're updating an unmanaged theme with customizations, please contact your account manager before applying the update.

Important:

You can't reactivate an unmanaged theme after a managed theme is activated.

Note:

Fonts you used before might not work after switching to a managed theme. To resolve this, see [Configuring Web Fonts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158819886880.html).

#### To update unmanaged themes:

1.  Install the managed theme SuiteApp. For details, see [Installing Theme and Extension SuiteApps](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510953648.html).
    
2.  After the bundle is installed, review the Preview Bundle Install page for conflicting objects. For each conflicting object, you need to select **Replace Existing Object** from the dropdown list in the **Actions** menu. For more information, see [Choose Actions for Conflicting Objects](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3396121.html#bridgehead_N3396230).
    
3.  After you resolve any conflicts and the SuiteApp has successfully installed, go to Commerce > Extensions > Extension Manager to update and activate the theme and theme extension. For details, see [Activating a Theme](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1549039282.html).
    
4.  Select the **Theme** subtab and check the **Update** box beside the theme you are updating.
    
5.  Select the **Extensions** subtab and check the **Update** box beside the companion theme extension. For example, if you're updating the SC Bridge Theme, you also need to update the Bridge Theme Extension.
    
6.  Click **Activate**.
    
7.  To check the configuration of the theme, go to Commerce > Websites > Configuration.
    
8.  Select the website and domain where you want to set up the theme.
    
9.  Click **Configure**.
    
10.  To review the properties you can configure, go to the Theme subtab. For details, see [Configuring Themes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158680127593.html).
     
11.  Make any changes you need, and click **Save.**
     
12.  Clear the domain's cache by triggering a cache invalidation request. See [Cache Invalidation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4169406426.html) for details.
     

Now that your account is using a managed theme bundle, any future updates will be automatically pushed to your account. For more information, see [Using Managed Bundles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3400741.html).
