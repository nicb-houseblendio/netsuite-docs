Use the SuiteCommerce Configuration record to choose how the Blog extension appears on your site. You can set home page labels, search behavior, how the Latest Articles section looks, and more.

#### To configure the Blog extension:

1.  In NetSuite, go to Commerce > Websites > Configuration.
    
2.  Select the website and domain where the Blog extension is activated and click **Configure**.
    
3.  Go to the **Extensions** subtab.
    
4.  In the **Blog** subtab, set the following fields:
    
    | Field | Description |
    | --- | --- |
    | Blog Name | Sets the blog name that appears on the blog home page. |
    | Read Blog Post Label | Sets the label for the link that appears after the blog post preview that leads to the full blog post. |
    | All Blog Posts Label | Sets the label for the blog post list. |
    | Show Featured Blog Posts In Pagination | If checked, includes the featured blog posts section on every page. If cleared, the featured blog posts section only appears on the blog home page. |
    | Blog Post List Label | Sets the title for the blog post list that appears on the blog home page. |
    | Search Label | Sets the label for the search feature. |
    | Search Placeholder | Sets the placeholder for the search feature. |
    | Search Results Label | Sets the label for the search results. |
    | No Search Results Message | Enter a message to display when the search returns no results. The \[\[term\]\] placeholder gets replaced by the search term automatically. |
    | No Results Blog Post Suggestion Message | Sets the message to display when the search returns no results. In this case, the extension automatically suggests recent blog posts. |
    | Mobile Search Close Label | Sets the label for the button that closes the search feature on mobile devices. |
    | Categories Label | Sets the label for the Blog Post Categories section. |
    | Pagination Label | Sets the label for the button that displays more blog posts. |
    | Mobile Back To Top Label | Sets the label for the button that leads back to the top of the page on mobile devices. |
    | Large Images Resize ID | Determines the image resizing option for large images added in the **Content** field using SMT. To use this option, you must enter an enabled **Image Size ID** found in the **Image Resizing** section of the Web Site Setup record (Commerce > Websites > Website List > Images subtab). |
    | Thumbnail Images Resize ID | Determines the image resizing option you want to use for a **Thumbnail Image** added using Site Management Tools. To use this option, you must enter an enabled **Image Size ID** found in the **Image Resizing** section of the Web Site Setup record (Commerce > Websites > Website List > Images subtab). |
    | Blog Posts Per Page | Determines the number of blog posts you want to display per page. Selecting a higher number of blog posts could reduce loading performance. |
    | Empty State Label | Sets the label to display when there are no blog posts. |
    | Empty State Message | Determines the message to display when there are no blog posts. You can suggest visiting the Product Listing page of your web store. |
    | Empty State Button Label | Sets the label for the button that leads to the Product Listing page of your web store when there are no blog posts. |
    | Show Latest Posts Section | If checked, includes the Latest Articles carousel on the blog home page. This section displays your three most recent posts, based on publication date, in a carousel. |
    | Latest Posts Label | Sets the label for the Latest Articles carousel. |
    | Latest Posts Carousel - Interval | Determines the time interval for the Latest Articles carousel. |
    | Show RSS Feed Link | If checked, the RSS feed link will appear on your blog home page as the standard RSS icon. For more information, see [Setting Up a Blog RSS Feed](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161524173337.html). |
    
5.  Click **Save**.
