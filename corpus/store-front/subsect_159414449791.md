You can define the customer segments to which a Commerce Category is visible from the Commerce Category record.

Note:

By default the Website Visibility Level of the Commerce Category is set to Display Fully. To change the Website Visibility Level of a Commerce Category, use the Customer Segments Manager (CSM).

#### To define which customer groups can view items in a Commerce Category:

1.  Go to _Commerce > Content Management > Catalog & Categories > Commerce Categories_.
    
2.  Click **Edit** next to the Commerce Category.
    
3.  On the **Customer Segments** tab, select a customer segment from the list in the **Customer Segments** column.
    
    Add another customer segment by clicking **Add** and selecting one.
    
4.  Click **Save** when you're finished. Clicking **Save** triggers a search index rebuild, when it's complete, personalized catalog views become active for customers visiting the website. For information about how to check the status of the search index rebuild, see [Check the Search Index Job Status](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_1500035318.html).
