The catalog is the top-level group for Commerce Categories. Before you can create Commerce Categories, you'll need a catalog to assign them to. Each website can have only one catalog.

#### To create a Commerce Catalog:

1.  Go to _Commerce > Content Management > Catalog & Categories > Commerce Catalogs > New_.
    
2.  From the **Site** dropdown list, select the website for this catalog. Remember, each website can have only one catalog.
    
3.  In the **Name** field, enter a name for the catalog. This name won't show up on your website-it's used for identifying the catalog in NetSuite.
    
4.  In the Description field, add more details about the catalog. This information isn't shown on your site-it's used only to provide extra details in NetSuite, like the catalog's purpose.
    
5.  Click **Save**.
