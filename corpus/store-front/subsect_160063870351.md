Before you can create a new translation using Site Management Tools (SMT), you'll need to create a new commerce category. For details, see [Set Up Commerce Categories](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4655026143.html).

#### To create category translations using SMT:

1.  Log in to SMT. For details, see [Logging into Site Management Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4163262385.html).
    
2.  Select the Overview Mode icon ![Overview Mode Icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/StoreFront/WebsiteContent/OverviewModeIcon.png) from the site management toolbar.
    
3.  Select the **Categories** subtab.
    
4.  Click **New Category**.
    
5.  From the Category Settings panel, enter the category name in the **Name** field.
    
    Note:
    
    You won't be able to enter translations until you've entered a name for the content in your default language.
    
6.  Select the language you want to create a translation for from the language dropdown list.
    
7.  Enter your translations.
    
8.  Click **Save**.
