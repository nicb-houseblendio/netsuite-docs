This dataset combines fields from the Customer, Customer Segments, Personalization Rules, Item Segments, and Items Item record types so that you can select specific customers and see which items are visible to them. This dataset forms the source data for the [Items by Customer Workbook](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158264340182.html).

## Dataset Configuration {#subsect_163580207656}

The Items by Customer Dataset combines data from five record types. To edit the dataset, see [Defining a Dataset](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544122173.html).

| Root Record Type | Joined Record Type | Custom Formula Fields | Data Grid | Criteria Filters |
| --- | --- | --- | --- | --- |
| Customer | Customer Segments Personalization Rules Item Segments Items Item | (none) | The following records fields are included in the dataset. **Customer:**
-   Entity ID

**Customer Segments:**

-   Name

**Personalization Rules:**

-   Website Visibility Level

**Item Segments:**

-   Name

**Items Item:**

-   Item Name/Number

 | The dataset is filtered using the following criteria:

-   Website Visibility Level is either Display Fully, Disable Purchase, or Disable Purchase and Hide Price

 |
