To use Strike-Through Pricing, set up at least two prices for each item. For more information, see [Using Multiple Pricing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2181607.html).

## Price Level Requirements {#bridgehead_159889751343}

When setting up item pricing:

-   One of the prices you set up for each item must correspond to the default price level you set in the **Default Price Level** field on the SuiteCommerce Configuration record. See [Default Price Level](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4667037093.html#subsect_159845169195).
    
-   Enable the Multiple Pricing feature and create price level records if you haven't already. See [Using Multiple Pricing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2181607.html).
