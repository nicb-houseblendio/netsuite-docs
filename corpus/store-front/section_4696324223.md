Field sets control what data your site templates can use. If you're adding Commerce Categories to an existing SuiteCommerce Advanced site, you'll need to add them to the site's field sets. For more information about field sets, see [Define Field Sets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2659559.html).

#### To add Commerce Categories to website field sets:

1.  Go to _Commerce > Websites > Website List_.
    
2.  Click **Edit** next to the website where you're adding the Commerce Categories field.
    
3.  Click the **Field Sets** subtab.
    
4.  Locate the **Details** field set and click the **Fields Included in Field Set** column. This is the last column in the row.
    
5.  Click the **Set** button to the right of the field.
    
    ![Set button](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/StoreFront/Products/FieldSetsField.png)
    
    This opens the Field Set window, where you can see the assigned fields and add more if you need to.
    
6.  Click the **Field Name** dropdown list at the bottom of the field list and choose **Commerce Categories**.
    
7.  Click **Add**.
    
8.  Click **Submit** to close the Field Set window.
    
9.  Click **OK** on the search field set row.
    
10.  Click **Save**.
