When you install SuiteCommerce Gift Wrap & Message, gift wrap options are displayed in the product detail page and in the cart summary. By default, the gift message section is hidden.

Gift options in the product detail page use the selector template set up in your site configuration for matrix items. If you associate images with the gift wrap item record, SuiteCommerce Gift Wrap & Message uses these images to show the gift wrap options.

Default label text is provided for all gift wrap fields.

## Configure Gift Wrap Display Options {#subsect_1537539548}

You can determine how the gift option is displayed in the web store. You set up the color options for gift wrap as transaction item options. See [Creating Custom Transaction Item Options](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2828730.html).

If you want gift wrap item options to use a different selector template, you need to create separate item options for gift wrap.

You can set up images for each gift wrap item that lets the user view different patterns or colors. For more information, see [Item Images](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_162137155579.html).

Note:

When setting up images for each gift wrap item, it's necessary to use the correct file name format for the images. For the **Item Identifier** dropdown list, choose **Display Name/Code**. Depending on how you configured your transaction item options, the images could then be named with the format `giftColors.red.jpg`, for example. For more information, see [Define the File Name Format](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162137343254.html#subsect_162137351115).

#### To determine the display option for gift wrap items:

1.  Go to Commerce > Websites > Configuration.
    
2.  Go to the **Advanced** tab, **Item Options** subtab.
    
3.  In the **Item Options and Custom Transaction Column Fields** section, enter the ID of the item option you have set up for gift wrap colors in the **Cart Option ID** field.
    
4.  In the **Selector Template**, select the template that you want to use to select gift wrap option such as colors or patterns.
    
    Use `product_views_option_tiles.tpl` to display gift wrap options as text, and `product_views_option_color.tpl` to display gift wrap options as colors or images. If you don't specify this value, the default used is `product_views_option_tiles.tpl`.
    
5.  Click **OK**.
    
6.  Save the Configuration record.
    

#### To display gift wrap images:

1.  Go to Commerce > Websites > Configuration.
    
2.  Go to the **Shopping Catalog** tab, **Multi-Image Option** subtab.
    
3.  In the **Multi-Image Option** column, enter the ID of the transaction item option field that you used for the gift wrap item.
    
4.  Click **OK**.
    
5.  Save the Configuration record.
    

## Customize Gift Wrap Text {#subsect_1537534617}

You customize the text used for Gift Wrap & Message field labels in the SuiteCommerce Configuration record. The text fields that can be customized are listed in the following table.

| **Field** | **Description** |
| --- | --- |
| Title - Gift Options | Title displayed above the gift options on the product page. Default value: **Buying a gift?** |
| Product Page - Loading | Message displayed when loading the gift options for the item. Default value: **Loading...** |
| Product Page - Loading Error Text | Message displayed when an error occurred while loading the gift options for the item. Default value: **Gift Wrap options failed to load. Please retry.** |
| Add Gift Wrap Button Label | Text displayed on the button to view gift wrap options. This field is required. Default value: **Add Gift Wrap** |
| Description - Gift Options | Text displayed to describe the gift wrap options. Default value: **We'll add a gift message to the packing slip and hide the prices.** |
| Price Label - Gift Options | Label to indicate the price of the gift wrap option. Use the {{price}} placeholder to replace the value. Default value: **Price: {{price}}** |
| Default Wrap Item - Gift Options | Select the default gift wrap item to be used for items where no gift wrap has been specified. If you don't specify a default gift wrap, the first gift wrap option for the item is taken. |
| Show Message Section | Check this box if you want to allow users to add personalized messages to their gift order. |
| Section Label - Message | Text to describe the personalized message area. Default value: **Add a personalized gift message to your order!** |
| Sender Label - Message | Text used to indicate the field where the user enters the sender's name. Default value: **From:** |
| Recipient Label - Message | Text used to indicate the field where the user enters the recipient's name. Default value: **To:** |
| Message Area Label - Message | Text used to described the personalized message field. Default value: **Add Gift Message:** |
| Remove Gift Button Label | Text displayed on the button to remove the gift wrap options on the product page. This field is required. Default value: **Remove Gift Wrap** |
| Gift Wrap Info - Cart Summary & Checkout | Text indicating that gift wrap items are counted in the cart's item total. Default value: **Gift wrap included in the item count.** |
| Gift Wrap Info - Cart Lines | Text used in the cart to indicate the gift wrap options selected. Default value: **Gift Wrap:** |
| Gift Wrap Value - Cart Lines | Text used in the cart to indicate the total for the gift wrap options selected. Use the {{name}} and {{price}} placeholders for the gift option name and price, respectively. Default value: **{{name}} {{price}}** |

#### To change the gift wrap default text:

1.  Go to Commerce > Websites > Configuration.
    
2.  In the SuiteCommerce Configuration record, go to the **Extensions** tab.
    
3.  On the **Gift Wrap & Message** subtab, customize the text as required.
    
4.  Click **Save**.
    

#### To enable the gift message section:

1.  Go to Commerce > Websites > Configuration.
    
2.  In the SuiteCommerce Configuration record, go to the **Extensions** tab.
    
3.  On the **Gift Wrap & Message** subtab, check the **Show Message Section** box.
    
4.  Click **Save**.
