Migrate your website to SuiteCommerce or the latest version of SuiteCommerce Advanced (SCA) and use a gateway that provides native 3D Secure 2 support. However, if you can't migrate your website to SuiteCommerce or the latest SCA version, take these actions:

| Product | Version | Native Support for 3D Secure 2 | External Checkout Supported | External Support for 3D Secure 2 | Action You Should Take |
| --- | --- | --- | --- | --- | --- |
| Site Builder | All | No | No | No | Install SiteBuilder Extensions Kilimanjaro (bundle 194218) or SiteBuilder Extensions Premium Kilimanjaro (bundle 194219) and use the external checkout feature. See [Installing a Bundle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3395142.html). The following patches are required for external checkout to work with SiteBuilder Extensions Kilimanjaro and SiteBuilder Extensions Premium Kilimanjaro:
-   [Customer not Directed to the Payment Review Page after Checkout using the Checkout Flow](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_4133959411.html)
-   [Customer not Directed to the Payment Review Page after Checkout after using the Make A Payment Flow](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_6112836498.html)
-   [Customer Redirected to My Account Overview Instead of Successful Payment Page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_4121525793.html)

Change your Proceed to Checkout touchpoint on your website setup record to point to the SiteBuilder Extensions SSP. See [Select Supported Touch Points](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2494795.html). Since this SSP replaces your website's existing checkout, you'll need to set up your new checkout to fit your business needs, and you might need a developer to transfer any code-level customizations from your old checkout. |
| Site Builder with Reference Checkout | All | No | No | No | Install SiteBuilder Extensions Kilimanjaro (bundle 194218) or SiteBuilder Extensions Premium Kilimanjaro (bundle 194219) and use the external checkout feature. See [Installing a Bundle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3395142.html). The following patches are required for external checkout to work with SiteBuilder Extensions Kilimanjaro and SiteBuilder Extensions Premium Kilimanjaro:

-   [Customer not Directed to the Payment Review Page after Checkout using the Checkout Flow](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_4133959411.html)
-   [Customer not Directed to the Payment Review Page after Checkout after using the Make A Payment Flow](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_6112836498.html)
-   [Customer Redirected to My Account Overview Instead of Successful Payment Page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_4121525793.html)

Change the Proceed to Checkout touchpoint on your website setup record to point to the SiteBuilder Extensions SSP. See [Select Supported Touch Points](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2494795.html). Because this SSP replaces your website's existing checkout, you need to follow procedures to set up your new checkout to meet your business's requirements. You may also need a developer to transfer any code-level customizations that are being used in your old checkout. |
| Site Builder with SiteBuilder Extensions | All | No | Partial | No | Use the external checkout feature. 3D Secure 2 support depends on your checkout version. Install SiteBuilder Extensions Kilimanjaro (bundle 194218) or SiteBuilder Extensions Premium Kilimanjaro (bundle 194219). The following patches are required for external checkout to work with SiteBuilder Extensions Kilimanjaro and SiteBuilder Extensions Premium Kilimanjaro:

-   [Customer not Directed to the Payment Review Page after Checkout using the Checkout Flow](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_4133959411.html)
-   [Customer not Directed to the Payment Review Page after Checkout after using the Make A Payment Flow](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_6112836498.html)
-   [Customer Redirected to My Account Overview Instead of Successful Payment Page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_4121525793.html)

If you haven't already, change your Proceed to Checkout touchpoint on your website setup record to point to the SiteBuilder Extensions SSP. See [Select Supported Touch Points](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2494795.html). Since this SSP replaces your website's existing checkout, you'll need to set up your new checkout to fit your business needs, and you might need a developer to transfer any code-level customizations from your old checkout. |
| SuiteCommerce | \- | Yes | Yes | Yes | Use native 3D Secure or external checkout. |
| SuiteCommerce MyAccount | \- | Yes | Yes, except for Windcave | Yes | Use native 3D Secure or external checkout. |
| SCA- Includes My Account checkout | Denali Mont Blanc | No | Partial | Partial | Use external checkout. Support for external checkout was introduced in the Mont Blanc release of SCA and a patch was developed to backport it to the Denali release. See [Mont Blanc Release of SuiteCommerce Advanced](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4472605271.html). |
| Vinson Elbrus | No | Yes | Yes | Use external checkout. The following patches are required for external checkout to work:

-   [Domain Bridging Update](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_8095832048.html) (Elbrus and Vinson)
-   [Order Confirmation Page Not Displayed When Using Single Page Checkout and External Payment](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1556563519.html) (Elbrus and Vinson)
-   [Users Not Redirected to External Payment System](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1550857801.html) (Vinson)
-   [Incorrect Redirect URL for External Payments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1550799539.html) (Vinson)

 |
| Kilimanjaro Aconcagua 2018.2 | No | Yes | Yes | Use external checkout. You'll need the [Domain Bridging Update](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_8095832048.html) patch for external checkout to work on Kilimanjaro implementations. The following patches are required for external checkout to work with SCA Kilimanjaro and SCA 2018.2:

-   [Customer not Directed to the Payment Review Page after Checkout using the Checkout Flow](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_4133959411.html)
-   [Customer not Directed to the Payment Review Page after Checkout after using the Make A Payment Flow](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_6112836498.html)
-   [Customer Redirected to My Account Overview Instead of Successful Payment Page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_4121525793.html)

 |
| 2019.1 2019.2 | No | Yes | Yes | Use external checkout. |
| 2020.1 and later | Yes | Yes | Yes | Use native 3D Secure or external checkout. You might need patches to use native 3D Secure 2 with pre-2021.2 SCA releases. SCA 2020.1.8 and 2020.1.12 included minor fixes for 3D Secure 2. The following patches are required for external checkout to work with SCA 2020.1, SCA 2020.1.12, 2021.2, and SCA 2021.2.3:

-   [Customer not Directed to the Payment Review Page after Checkout using the Checkout Flow](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_4133959411.html)
-   [Customer not Directed to the Payment Review Page after Checkout after using the Make A Payment Flow](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_6112836498.html)
-   [Customer Redirected to My Account Overview Instead of Successful Payment Page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_4121525793.html)
