The Shipping Bar extension lets you add a shipping bar and banners to your site to show shoppers how much they need to spend to get free or special rate shipping.

Important:

SuiteCommerce extensions are only available if provisioned, installed, and activated for a selected domain in your account. For more information, see [Commerce Extensions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1530632028.html).

Note:

If you are a SuiteCommerce Advanced customer, you must be implementing the Aconcagua release or later to take advantage of extensions.

## Overview {#bridgehead_156021871286}

The shipping bar and optional banners display various messages to customers based upon how much progress they have made toward free or special rate shipping. When the cart value meets the minimum for free or special shipping, a congratulations message appears. The Shipping Bar extension comes with default progress and congratulations messages, but you can customize them if you want. The Shipping Bar also supports multiple currencies for customers in different countries. To use multiple currencies with this extension, you'll need to enable the Multiple Currency feature and add additional currencies on your Website Setup record. For more information, see [Enabling the Multiple Currencies Feature](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1395677.html) and [Multi-Currency](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1537351790.html).

## Integrate Shipping Bar with Shipping Promotions {#bridgehead_156022040338}

To use the SuiteCommerce Shipping Bar extension with auto-applied free or discounted shipping, you'll need to complete these steps first:

1.  Create a new shipping item to automatically apply free or special rate shipping. You'll use this shipping item as your default shipping method. For details, see [Creating Shipping Items](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1259213.html).
    
2.  Select the new shipping method as your preferred shipping method in the website setup. See [Setting a Preferred Shipping Method for Your Site](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2462284.html).
    

Important:

The SuiteCommerce Shipping Bar extension considers cart values when making calculations. The extension does not take into account any shipping promotions that you may have set up in your account using SuitePromotions or advanced promotions that are not reflected in the cart through auto-apply.

## Shipping Bar Display Options {#bridgehead_1558558072}

You can display the shipping bar in a few different ways:

-   **Header bar** - This bar displays in the header of your website. The bar displays an initial, progress, or congratulations message based on the cart's total. You can choose the position of the header bar and link to a specific page. For example, you can customize an alternate message to link to your shipping terms and conditions page. This image is an example of how the shipping bar looks in the header.
    
    ![Shipping Bar Header](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/StoreFront/Transactions/shippingbar_header.png)
-   **Product banner** - This banner appears on product detail pages (PDP). It shows users if they meet the minimum value to qualify for shipping if they add the item to their cart. If the cart total with that item doesn't meet the minimum, shoppers see how much more they need to spend to qualify. This image is an example of how the shipping bar looks on the PDP:
    
    ![Shipping Bar PDP](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/StoreFront/Transactions/shippingbar_product.png)
-   **Cart banner** - This banner displays on the cart page. The banner displays an initial, progress, or congratulations message based on the cart's total. This image is an example of how the shipping bar looks on the cart page.
    
    ![Shipping Bar Cart](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/StoreFront/Transactions/shippingbar_cart.png)

You can use the Shipping Bar fields in the Site Management Tools (SMT) Theme Customizer to change the style and display of the header bar, product banner, and cart banner. Pick the font, background and text colors, border size, and more to make each display fit your needs. For more information about using the Theme Customizer in SMT, see [Theme Skin Manager](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1512491665.html).

## Configure Shipping Bar {#subsect_156209098087}

Use the SuiteCommerce Configuration record to enable the header bar, product banner, and cart banner. You can also set the shipping bar's URLs and messages, and use multi-currency to set up the shipping bar for several countries.

#### To configure Shipping Bar:

1.  Go to Commerce > Websites > Configuration.
    
2.  Select the website and domain where the Shipping Bar extension is activated and click **Configure**.
    
3.  Go to the **Extensions** subtab.
    
4.  In the **Shipping Bar** subtab, fill out the listed fields for each category, using the tables below as references.
    
5.  Click **Save**.
    

**Shipping Bar Configuration Fields:**

| Field | Description |
| --- | --- |
| Shipping Goal Value | Sets the minimum order value a shopper needs for free or special rate shipping. |
| Currency Symbol | Determines the symbol or abbreviation for the currency. |
| Header Bar Position | Sets the position of the header bar. You can choose from the following options:
-   **Above Header** - Header bar displays above the website header
-   **Fixed to Top** - Header bar remains visible at the top of the page when scrolling
-   **Below Header** - Header bar displays below the website header

 |
| Initial Message URL | Sets the full URL for the header bar Initial Message link. |
| Alternate Message 1 URL | Sets the full URL for the header bar Alternate Message 1 link. For example, use this field to link to your Terms & Conditions or a sale landing page. |
| Alternate Message 2 URL | Sets the full URL for the header bar Alternate Message 2 link. For example, you can use this field to link to a Terms & Conditions page or a landing page promoting a sale. |

**Messaging Fields:**

In the Messaging fields, you can use the following placeholders, which are replaced by their associated values automatically:

-   \[\[value\]\] - shipping goal value
    
-   \[\[to-value\]\] - remaining amount required to qualify for free or special rate shipping
    

| Field | Description |
| --- | --- |
| Show Header Bar | If checked, displays the header bar at the top of all pages of your site. |
| Initial Message - Header Bar | Sets the message shown in the header bar. |
| Alternate Message 1 - Header Bar | Sets the alternate message for the header bar. The header bar displays a new message every five seconds or when a user clicks on the side arrows. |
| Alternate Message 2 - Header Bar | Sets the alternate message for the header bar. The header bar displays a new message every five seconds or when a user clicks on the side arrows. |
| Progress Message - Header Bar | Sets the message to display when the user adds an item to the cart but has not reached the shipping goal value required to qualify for free or special rate shipping. |
| Congratulations Message - Header Bar | Sets the message to display when the user meets the shipping goal and qualifies for free or special rate shipping. |
| Show Product Banner | If checked, displays the product banner on product detail pages (PDPs). |
| Progress Message - Product Banner | Sets the message to display on the PDP when a customer hasn't reached the shipping goal value required to qualify for free or special rate shipping. This message appears below the item selection options. |
| Item Qualifies Message - Product Banner | Sets the message to display on the PDP if the shopper qualifies for free or special rate shipping if they add the item to the cart. This message appears below the item selection options. |
| Show Cart Banner | If checked, displays the shipping banner on the cart page. |
| Initial Message - Cart Banner | Sets the message to display on the cart page. |
| Progress Message - Cart Banner | Sets the message to display on the cart page when the user hasn't reached the shipping goal value required to qualify for free or special rate shipping. |
| Congratulations Message - Cart Banner | Sets the message to display on the cart page when the user meets the shipping goal value to qualify for free or special rate shipping. |

**Multi-Currency Support Fields:**

| Field | Description |
| --- | --- |
| Currency | Determines an additional currency available for the shipping bar. |
| Shipping Goal Value | Sets the shipping goal value required to qualify for free or special rate shipping for this currency. |
| Currency Symbol | Sets the symbol or abbreviation for the currency. |
