To set up your website for customers, you need to determine the registration workflow for your web store. There are four possible site registration scenarios:

-   Existing Customer, New Customer or Guest Shopper
    
-   Existing Customer only
    
-   Existing Customer or New Customer
    
-   Guest Shopper only
    

Depending on the requirements of your business, you may choose one of the various options. For a more detailed description on the various registration flows and their operation, see [Customer Registration Flow](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1517327084.html).

#### To configure site registration:

1.  Go to _Commerce > Websites > Web Site List_.
    
2.  On your Web Site Setup record, click **Edit**.
    
3.  On the **Shopping** subtab, **Registration Page** section, select the desired option in the **Customer Registration Is** field. The options are: disabled, optional, existing customer only, and required.
    
    -   To enable all possible registration flows, select **optional**.
        
    -   To only enable [Existing Customer](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1517327084.html#subsect_1517566103) or [New Customer](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1517327084.html#subsect_1517566072) registration flows, select **required**.
        
    -   To enable [Guest Shopper](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1517327084.html#subsect_1517566156) registration flow only, select **disabled**.
        
    -   To enable [Existing Customer](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1517327084.html#subsect_1517566103) registration flow only, select **existing customer only**.
        
    
    For more information about the different flows, see [Customer Registration Flow](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1517327084.html).
    
4.  Click **Save**.
    

Note:

If you have multiple websites, you may want to ensure that a customer only has access to a specific site. Customers are assigned to all sites by default. To change this behavior, see [Assign Customers to Websites](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510949098.html).
