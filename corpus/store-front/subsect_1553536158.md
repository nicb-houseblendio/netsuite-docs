Set up matrix items to display options as a grid after enabling Grid Order for your domain. Grid Order works with matrix items that have one or two matrix item options. For example, a shirt with size and color options is a good example of an item that can use Grid Order.

#### To set up a matrix item to display item options as a grid:

1.  Access the matrix item in NetSuite where you want to apply Grid Order.
    
    Search NetSuite for the matrix item or go to **Lists > Accounting > Items**.
    
    Important:
    
    Set Grid Order for the Matrix Item record (parent), not the Matrix Subitem.
    
2.  Click **Edit** next to the matrix item you want to change.
    
3.  Go to the **SuiteCommerce Extensions** subtab.
    
4.  In the **Grid Order** area:
    
    1.  Set the **Grid Order Behavior** field to control how the item displays information in the Product Detail page.
        
        Choose from these options::
        
        -   **Default Site Behavior**: Choose this option to turn Grid Order on or off for as many matrix items as you want at one time, using the **Activate for All Matrix Items** field on the SC Configuration record. If **Activate for All Matrix Items** is checked, an order grid displays for items with **Default Site Behavior** selected.
            
            For more information, see [Configure Grid Order](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1553536143.html).
            
        -   **Always Activate for This Item:** Choose this option to display the matrix dimensions of this item as a grid, ignoring the default website configuration.
            
        -   **Deactivate for This Item** - Choose this option to deactivate the purchasing grid for this item, ignoring the default website configuration.
            
    2.  Check the **Show Stock Quantities** option to display the in-stock quantity in the grid. Clear this option to hide quantities in stock.
        
        For out-of-stock items, this option follows the Out of Stock Behavior on the Item record. For more information, see [Setting Web Store Back Order and Out-of-Stock Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2582357.html).
        
    3.  Check the **Activate Stock Notifications** option to display a **Notify Me** link for out-of-stock items not available on backorder.
        
        Note:
        
        The SC Stock Notifications extension must be installed and activated on the same domain to be used in conjunction with this extension.
        
5.  Click **Save**.
    

## Integration with Other SuiteCommerce Features {#subsect_1553525499}

This extension integrates with the following SuiteCommerce features:

-   **Quantity Pricing** - If enabled, options with quantity pricing options display an expandable price chart. For details, see [Quantity Pricing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4618800801.html).
    
-   **Stock Notifications** - If your domain uses the Stock Notifications extension, each item includes an option to sign up for stock notification emails. For details, see [Stock Notifications](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1550851854.html).
    
-   **Require Login for Pricing** - If enabled and the user isn't logged in when viewing the Product Details page, the Grid Order extension won't appear. A message will ask users to log in to see the price. Clear the **Require Login for Pricing** box on the Web Site Configuration record to let users use Grid Order without logging in. For more information, see [Shopping Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2567548.html).
