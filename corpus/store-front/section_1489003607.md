This section explains how to make existing items available for viewing and purchase on your website. If your item hasn't been created yet, see [Creating Item Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2166469.html). To ensure your item appears on your website, you'll need to complete the following tasks on the Item record-depending on your Commerce implementation:

-   [Item Setup for SuiteCommerce MyAccount](#subsect_160141805187)
    
-   [Item Setup for SuiteCommerce and SuiteCommerce Advanced](#subsect_160141799823)
    

## Item Setup for SuiteCommerce MyAccount {#subsect_160141805187}

SuiteCommerce MyAccount (SCMA) displays item images in the following ways:

-   Purchase History
    
-   Returns
    
-   Invoices
    
-   Quotes
    

Note:

If you don't enable an item to display on your SCMA site, it will show the message 'This item is no longer available' in the Returns area of the Sales Order record.

To ensure the item image appears, you'll need to edit the item records for all items on your SCMA site. You can do this manually using the following procedure, or use the CSV Import feature to update multiple records.

#### To display an item on your SuiteCommerce MyAccount site:

1.  Go to Lists > Accounting > Items.
    
2.  Select **Edit** beside the item you want to add to your MyAccount site.
    
3.  Select the **Web Store** subtab.
    
4.  Check the **Display in Website** box.
    
5.  In the **Web Store Display Name** field, enter the name you want to display for this item.
    
6.  Select the **Web Site Categories** subtab.
    
7.  In the **Site** field, select your SuiteCommerce MyAccount site.
    
8.  In the **Site Category** field, select **Home**.
    
9.  Click **Add**, then **Save**.
    
10.  Attach and display images with the items in the web store. For details, see [Item Images](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_162137155579.html).
     
11.  Click **Save**.
     

Tip:

Alternatively, use the CSV export and import features to make these changes.

1.  Search for your existing items using a custom search. For details, see [Search Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N635877.html).
    
2.  Include the **Web Site** and **Category** filters in your search results.
    
    These filters map to the **Site** and **Site Category** fields.
    
3.  Export your results to a CSV file. For details, see [Exporting Selected Lists and Reports as CSV Files (CSV Export)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N464443.html).
    
4.  Update the items in your CSV spreadsheet as needed.
    
    Set **Site** to your SuiteCommerce MyAccount site and **Site Category** to **Home**.
    
5.  Import your updated CSV file to NetSuite. For details, see [Importing CSV Files with the Import Assistant](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N343158.html).
    

## Item Setup for SuiteCommerce and SuiteCommerce Advanced {#subsect_160141799823}

Perform the following steps to make an item available on your SuiteCommerce or SuiteCommerce Advanced (SCA) site.

#### To display an item on your Commerce website:

1.  Go to Lists > Accounting > Items.
    
2.  Select **Edit** beside the item you want to add to your Commerce site.
    
3.  Set a price for the item in the **Sales/Pricing** subtab.
    
4.  Select the **Web Store** subtab and check the **Display in Website** box.
    
5.  Enter a title for the item page in the **Page Title** field. This title appears in the browser tab and can improve search engine ranking if it's descriptive.
    
6.  Enter the item's display name in the **Web Store Display Name** field.
    
7.  Enter a brief item description in the **Web Store Description** field.
    
8.  Enter detailed item information in the **Detailed Description** field.
    
    You can use letters, numbers, basic punctuation, and basic HTML code. The **Store Description** field allows 999 characters, while the **Detailed Description** field allows 1,300 characters.
    
9.  If this item will be featured on your home page, enter a description in the **Featured Description** field.
    
    This description appears below the item's name on the home page. You can enter up to 999 characters, including basic HTML code. Enter and format text using the formatting options, or click the **HTML Source Code** link.
    
10.  Attach and display images with the items in the web store. For details, see [Item Images](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_162137155579.html).
     
11.  Enable Commerce Categories as required. For details, see [Commerce Categories](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4673202005.html).
     
12.  Click **Save**.
