If you've got multiple websites, you can assign a different credit card payment processing profile to each one. Before you set up a credit card processing profile in NetSuite, make sure you've set up a merchant account for each payment card gateway you want to use. For more information, see the Order Management help topic, [Setting Up Payment Processing Profiles in NetSuite](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1572588.html).

#### To assign a credit card payment processing profile to your Commerce web store:

1.  Go to Setup > Accounting > Financial Statement > Payment Processing Profiles.
    
2.  Click **Edit** next to the payment processing profile you'd like to use.
    
3.  In the **Web Site** field, select one or more websites.
    
4.  Click **Save**.
    

Note:

If you assign a credit card processing profile that supports the sales request, but not authorization, you'll need to use standard sales orders as the sales order type.

Go to **Commerce > Websites > Website Lists** and click **Edit** next to your website. Go to the **Shopping** subtab, then the **Checkout** subtab, and make sure you've selected Standard Sales Order in the **Sales Order Type** field. For more information, see [Checkout Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2567548.html#bridgehead_N2568554).
