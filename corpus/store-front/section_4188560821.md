The Multiple Ship To (MST) feature lets shoppers send items from the same order to different shipping addresses. This feature works with all three checkout flows (Standard, One Page, or Billing First). For more information about configuring checkout, see [Checkout](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3753900404.html).

With MST enabled, shoppers can:

-   Specify items for checkout and ship them to different addresses as needed.
    
-   Define a different shipping method for each shipping address. (Note that users can only define one shipping method per address within the same order.)

When MST is enabled, shoppers typically proceed through the following steps:

1.  A shopper adds items with specified quantities to the shopping cart and proceeds to checkout.
    
2.  When setting the shipping address, the shopper selects **I want to ship to multiple addresses**. The shopper then selects a shipping address and the items to ship to that address, then clicks **Create Shipment**.
    
    Note:
    
    If there are no shipping addresses, the site prompts the shopper to enter one. Shoppers also have the option to create additional shipping addresses by selecting **Add/Edit Addresses**.
    
3.  The user creates additional shipments until all items have been allotted to a shipping address. If only a single address is selected, shoppers can continue, but the site returns to the configured checkout flow.
    
4.  The shopper picks a delivery method for each shipment.
    
5.  The shopper chooses a payment method and finishes the order.
    

See [Setup Tasks](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4212611303.html) for learn how to enable Multiple Ship To in your web store.
