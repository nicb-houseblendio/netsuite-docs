The SuiteCommerce Analytics Data user interaction record lists details about a shopper's visit, including the date and time, domain, actions, items and item quantities, and search terms entered.

| Analytics Workbooks | Saved Search | Content |
| --- | --- | --- |
| Label | Type | Label | Type | Provides |
| --- | --- | --- | --- | --- |
| **Time** | DateTime | **User Interaction: Time** | DateTime | Date and time a shopper action occurred |
| **Domain** | Select | **User Interaction: Domain** | Select | Domain visited by shopper |
| **Page URL** | Text Select | **User Interaction: Page URL** | Text | URL of page visit |
| **Action** | Select | **User Interaction: Action Type** | Select | Shopper's actions when visiting web store |
| **Item** | Text Select | **User Interaction: Item** | Text Select | Item added to or removed from cart by shopper |
| **Item Quantity** | Integer | **User Interaction: Item Quantity** | Integer | Number of items added to or removed from cart |
| **Commerce Category URL** | Text Select | **User Interaction: Commerce Category URL** | Text Select | Category of item added to or removed from cart |
