You can determine the feedback messages shown to users by editing the feedback message fields in Site Management Tools (SMT).

#### To configure contact form feedback messages:

1.  Log into Site Management Tools. For details, see [Logging into Site Management Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4163262385.html).
    
2.  Go to the page that contains the contact form.
    
3.  Click the Edit Mode icon ![Edit Mode Icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/StoreFront/WebsiteContent/EditModeIcon.png) from the site management toolbar.
    
4.  Hover over the content form box to display the content controls and click Edit.
    
    This displays the Contact Form Settings in the side panel.
    
5.  In the **Feedback Messages** subtab, set the following fields:
    
    | Field | Description |
    | --- | --- |
    | Success Message | This sets the message to display upon successful form submission. |
    | Required Field Message | This sets the message to display when a required field has been left blank. The required field's label replaces the placeholder `[[field]]` automatically. |
    | Invalid Email Field Message | This sets the message to display when an invalid email address has been entered. |
    | Submit Error Message | This sets the message to display when there is an error during form submission. |
    
6.  Click **Save.**
