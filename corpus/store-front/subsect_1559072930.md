To add a photo gallery to your web store, add the Photo Galley content type to a page of your site using Site Management Tools (SMT). You can add up to eight images.

#### To add a photo gallery:

1.  Log into Site Management Tools. For details, see [Logging into Site Management Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4163262385.html).
    
2.  Go to the page where you want to add a photo gallery.
    
3.  Click the Edit Mode icon ![Edit Mode Icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/StoreFront/WebsiteContent/EditModeIcon.png) from the site management toolbar.
    
4.  Click the Add icon ![Add Icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/StoreFront/WebsiteContent/SiteMangementToolsAddIcon.png) from the site management toolbar.
    
5.  Drag the **Photo Gallery** content type onto the page. You can add the content type to multiple areas of the page:
    
    -   If you drag onto an area marked **all pages**, your content shows on any page that contains that area.
        
    -   If you drag onto an area marked **page type**, your content shows on any page of that type.
        
    -   If you drag onto an area marked **this page**, your content shows only on that page.
        
    
    Note:
    
    If you don't see this content type, first check that the extension has been installed and is active. Then, click the gear icon on the site management toolbar and select **Custom Content Types**. Drag the content type from the Inactive Content Types list to the Active Content Type list.
    
6.  Configure the settings to best fit your needs. For details, see [Configuring a Photo Gallery](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1559073786.html).
