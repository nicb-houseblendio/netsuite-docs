You can use the SMT Page Layout Selector for landing pages and enhanced pages, provided additional layouts are available for those pages. For core page types, only default layouts are available. Core page types include the Home, Item Detail, and Facet Search pages.

Note:

If you are a developer, to learn how to add page types and define alternative layouts, see [Create Page Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1549653144.html).

#### To change the page layout of a specific page:

1.  Log in to Site Management Tools. For details, see [Logging into Site Management Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4163262385.html).
    
2.  Go to the page for which you want to change the layout.
    
3.  To change the layout of a landing page:
    
    1.  Click the Overview Mode icon ![Overview Mode Icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/StoreFront/WebsiteContent/OverviewModeIcon.png) from the site management toolbar. Click **Overview Mode** from the Site Management toolbar.
        
    2.  Click the **Pages** subtab.
        
    3.  Click the ellipsis beside the landing page you want to change the layout for.
        
    4.  Select **Edit** from the dropdown. This displays the page settings and page preview.
        
4.  To change the layout of an enhanced page:
    
    1.  Click the Edit Mode icon ![Edit Mode Icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/StoreFront/WebsiteContent/EditModeIcon.png) from the site management toolbar.
        
    2.  Select the ellipsis from the top-right corner of the site management toolbar and select **Edit Page Settings**.
        
5.  Select the **Layout** subtab.
    
6.  Click the thumbnail for the layout you want to apply. The page preview updates and shows how the page looks with the new layout.
    
7.  Click **Set Layout** to apply the layout.
    
    Note:
    
    The new layout may have fewer areas or areas that do not directly correspond to the areas available in the original layout. SMT places this residual content into the new layout's default area. You can then move content from the default area and place it in a different area in the new layout.
    
8.  To move content, toggle **Arrange Layout**.
    
9.  Click **Save**.
