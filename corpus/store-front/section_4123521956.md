The SMT (Site Management Tools) Image Content Type lets you add engaging visual elements to your site. These images might include:

-   Banners to advertise current and upcoming sales or events
    
-   Images that link to groups of items or categories
    
-   Free shipping or other eye-catching notifications
    

Typically, a graphics designer creates these images with their intended placement in mind, so each fits perfectly in the layout area where it will appear.

Note:

You cannot select images from the File Cabinet. If you have an image in the File Cabinet that you want to use, download it to your computer first. Then, add it to you site using SMT.

## Image Size and Format {#bridgehead_4210904243}

SMT doesn't let you set an image's dimensions, so size your image to fit the area where you'll place it. You can also make the image slightly larger than the area.

If the image is larger than the area, SMT scales it down to fit. If it's smaller, SMT displays it at its original size without stretching it.

Supported file types include **JPG, GIF, PNG, PJGP, SVG, and TIFF**.

Note:

Large image files can impact page load times. You should use the smallest image possible without losing quality.

## Image Template File {#bridgehead_4254096463}

The image template file determines how an image you add to an area is displayed. This includes image alternate text and hyperlinks. For more information, see [Image Template](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4181533616.html).

Note:

Any changes to images, including addition, edits, or deletions must be published before the changes are available on the site.
