To show strike-through pricing, the [Default Price Level](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4667037093.html#subsect_159845169195) in the Shopping Catalog subtab of the SuiteCommerce Configuration record must be added to the Details, Search, and Matrix Child Items field sets, as well as any other field sets that display items with prices. For example, if you set the default price level to pricelevel1, add the Base Price field and its formatted version to the relevant field sets as described in the following steps.

## Price Fields and Corresponding Levels {#bridgehead_159890062813}

When adding the field for the default price level:

-   The **Base Price** field is equivalent to `pricelevel1`, which you can see in the field ID when you add the field to the field set.
    
-   If you set a different price as the default price level, add the corresponding field to the **Details**, **Search**, and all other field sets that display the item with its price. For example, if you set up item prices as described in [Set Up Item Pricing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_159197517928.html), the following fields and levels are available:
    
    -   **Alternate Price 1** - `pricelevel2`
        
    -   **Alternate Price 2** - `pricelevel3`
        
    -   **Alternate Price 3** - `pricelevel4`
        
    -   **Online Price** - `pricelevel5`
        
-   You'll also need to add the (Formatted) field for the default price level. For example, if you add the **Base Price** field, also add the **Base Price (Formatted)** field. The value stored in the **Base Price** field is used to calculate the price difference. The string stored in the **Base Price (Formatted)** field is the number and currency symbol displayed on your site.
    

#### To add the field for the default price level:

1.  Go to _Commerce > Websites > Web Site List_.
    
2.  Click **Edit** next to the website for which you want to display strike-through pricing.
    
3.  Click the **Field Sets** subtab.
    
4.  Add the **Base Price** and the **Base Price (Formatted)** field to the Details field set:
    
    1.  Locate the **Fields Included in Field Set** column of the Details field set and click the **Set** icon to open the Field Set window.
        
    2.  Select the **Base Price** field from the **Field Name** list and click **Add**.
        
        There may be more than one **Base Price** field available. Select the one with a field ID of **pricelevel1**.
        
    3.  In the Field Set window, click **Submit**.
        
    4.  In the Field Set row, click **OK**.
        
    5.  Repeat Steps a through d to add the **Base Price (Formatted)** field to the Details field set.
        
        There may be more than one **Base Price (Formatted)** field available. Select the one with a field ID of **pricelevel1\_formatted**.
        
    6.  Repeat Steps a through e to add **Alternate Price 1** ( `pricelevel2`), **Alternate Price 2** ( `pricelevel3`), **Alternate Price 3** ( `pricelevel4`), and **Online Price** ( `pricelevel5`) fields as required.
        
5.  Repeat Step 4 for the following:
    
    -   Search field set.
        
    -   Matrix Child Items field set.
        
    -   All other field sets that display an item with its price if you want to display strike-through pricing for that item.
        
6.  Click **Save**.
