Build this search to see which items your shoppers viewed most within a chosen time frame. Results show how many times each item was viewed.

## Saved Search {#subsect_161359695493}

**Search type:** Customer

**Select filter:** Session Record

| **Criteria Tab** | **Results Tab** |
| --- | --- |
| **Subtab:** Standard
-   **Filter:** Session Record **Description:** is after 10 days ago
-   **Filter:** Session Record: User Interaction: Action Type **Description:** is Item view

 | **Sort By:** Session Record: User Interaction: Time (descending) **Subtab:** Columns

-   **Field:** Session Record: User Interaction: Item **Summary Type:** Group
-   **Field:** Session Record: User Interaction: Time **Summary Type:** Group

 |
