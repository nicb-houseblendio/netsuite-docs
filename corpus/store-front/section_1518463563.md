On the Web Site Setup page, you can set preferences for sending email messages from Site Builder web sites. You can set preferences and select different email message templates for each website.

For more information about setting email preferences for your website, read [Set Website Email Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2572962.html).
