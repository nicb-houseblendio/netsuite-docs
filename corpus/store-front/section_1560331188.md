The first step in setting up Personalized Catalog Views is to determine how to divide your customers and items and which items you want to make accessible to which customers.

Consider the following questions:

-   What customer groups do you need? How do you decide to which group a customer belongs?
    
-   Do you want anonymous visitors to see items and prices? Do you want them to buy items? If so, which ones?
    
-   Do all your customers fit into one or more groups, or are there some leftover customers? What items, if any, should leftover customers see or buy? Do they need to be logged in or recognized to see or buy them?
    
-   Can customers belong to more than one group?
    
-   What item segments are needed, and how will items be assigned to them? Do the item segments correspond to the sections in my website navigation or are they different?
    
-   Do you want all groups to be able to buy all items, or should some groups only see certain items without being able to buy them? Should customers who can see items also see prices?
    
-   Who should see items not mapped to a customer segment? Should they also see prices or be able to buy them?
    

Setting up PCV is much easier after you've answered these questions.

## Personalized Catalog Views Setup Checklist {#subsect_1560347635}

To set up Personalized Catalog Views, follow these steps:

1.  Identify the customer and item segments you need for your web store.
    
2.  Create customer segments. For details, see [Defining Customer Segments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1560331337.html).
    
3.  Create item segments. For details, see [Defining Item Segments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1560331373.html).
    
4.  Enable the Personalized Catalog Views feature. For details, see [Enabling Personalized Catalog Views](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1560331236.html)
    
5.  Ensure PCV users have the correct permissions. For details, see [Personalized Catalog Views Roles and Permissions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1560331283.html)
    
6.  Define which item segments are visible and purchasable. For details, see [Managing which Customer Segments can Access Item Segments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1560331424.html).
    
    -   Define which item segments are visible to which customer segments
        
    -   Define which customer segments can purchase which item segments.
        
    -   Decide if all users can view or buy items not included in any item segments that are mapped to customer segments
        
7.  Verify that the correct items are displayed to the correct customers. For details, see [Verifying Personalized Catalog Views](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1560334647.html)
