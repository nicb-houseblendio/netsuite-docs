Item collections let you group catalog items together. The items you add to a collection might not be related, or you can group them by things like vendor or location. What you add to each item collection depends on your business needs.

You can:

-   Add an item to multiple item collections
    
-   Add a group of items to a collection by picking them one by one
    
-   Automatically add items to a collection using a saved search
    

To see existing item collections, go to _Commerce > Marketing > Item Collections_.

Item collections can contain all item types supported by NetSuite. For matrix items, you can only add the parent item to the collection, but it represents all the child items. For more information about item types, see [Item Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N2222944.html).

One key use for item collections is in personalized catalog views. You can create an item collection and show it to one or more specific customer groups. For more information, see [Personalized Catalog Views](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557154874.html).

You can also get data about item collections through SuiteAnalytics Connect. The records exposed in SuiteAnalytics Connect are available in the Connect Browser. You can get data for item collections using the Item Collection Map and Item Collections tables listed in [Connect Schema](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158695828012.html). For more information, see _Working with the Connect Browser_ and [SuiteAnalytics Connect](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_3963845427.html).

Note:

To access the Connect schema, you need to have SuiteAnalytics Connect purchased and enabled in your NetSuite account.
