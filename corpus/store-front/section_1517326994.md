This section provides information about how to set up your web store for customers. It involves several steps:

| Set up the customer registration flow | [Configure Site Registration](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1517823266.html) |
| --- | --- |
| Determine specific permissions for customers | [Create the Website Customer Center Role](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1517823205.html) |
| Prevent customers from signing up several times using the same email address | [Detect Duplicate Customer Email](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1496870850.html) |
| Manage customer registration on multiple sites | [Assign Customers to Websites](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510949098.html) |
