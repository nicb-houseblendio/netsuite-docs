The next step is to deploy the SuiteCommerce SuiteScript 2.0 (SS2) application to a domain and a site in NetSuite.

Note:

If you're implementing SuiteCommerce Advanced 2018.2 or earlier, you can disregard this procedure.

#### To deploy the SuiteScript 2.0 (SS2) application:

1.  In NetSuite, go to _Commerce > Hosting > SSP Applications_.
    
2.  Click **View** next to the correct **SS2** application:
    
    Note:
    
    The SS2 SSP application is included with SuiteCommerce, SuiteCommerce MyAccount, and SuiteCommerce Advanced applications (2019.1 and later). This SSP application is required to manage scripting written in SuiteScript 2.0. For an advanced description of SSP applications written for SuiteScript 2.0, see [SuiteScript 2.0 SSP Applications](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1529598062.html).
    
    | Implementation | Application Name |
    | --- | --- |
    | SuiteCommerce | SuiteCommerce SS2 |
    | SuiteCommerce MyAccount | SuiteCommerce SS2 |
    | SuiteCommerce Advanced 2019.1, 2019.2, and 2020.1 | SuiteCommerce Advanced - Dev xxxx SS2 (xxxx equals the SCA version being installed; for example SuiteCommerce Advanced - Dev 2019.2 SS2) |
    | SuiteCommerce Advanced 2020.2 and later | SuiteCommerce Advanced - Dev xxxx v2 (xxxx equals the SCA version being installed; for example SuiteCommerce Advanced - Dev 2020.2.0 v2) |
    
3.  If your Commerce website uses a single, secure domain for shopping and checkout:
    
    Note:
    
    This step includes SuiteCommerce MyAccount implementations, which should be set up to use a single, secure domain.
    
    1.  In the SSP Application record, click **Deploy to Domain**.
        
    2.  In the **Domain** field, select the domain for your site.
        
    3.  Click **Save**.
        
4.  If your Commerce web store uses two separate domains for shopping and checkout:
    
    1.  In the SSP Application record, click **Deploy to Site**.
        
    2.  In the **Deploy to All Shopping Domains on Site** field, select the site associated with your shopping domain.
        
    3.  In the **Deploy to Checkout Domain on Site** field, select the site associated with your checkout domain.
        

Now that your applications are installed and properly linked to a domain, you're ready to configure the Web Site Setup record. See [Prepare the Web Site Setup Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2675493.html) for details.
