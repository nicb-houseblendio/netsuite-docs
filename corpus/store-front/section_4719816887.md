To configure Commerce Categories, use the SuiteCommerce Configuration record. For details, see [Categories Subtab](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4701522812.html).

#### To configure properties for Commerce Categories:

1.  Select the domain to configure at Commerce > Websites > Configuration.
    
2.  In the SuiteCommerce Configuration record, go to the **Integrations** tab, then the **Categories** subtab.
    
3.  Set feature properties as required.
    
4.  Save the Configuration record.
