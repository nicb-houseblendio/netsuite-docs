The Gift Certificate Management extension lets you add a value check feature to your website so users can check the balance on their gift certificates. You can add a predefined page where gift certificate recipients can check the balance without having to log in and visit their My Account page.

Shoppers can check the status of gift certificates by entering the gift certificate code in the field. They can view the gift certificate's balance and the expiration date. If the gift certificate has expired, a message is displayed to the user indicating the expiration date.

This topic explains how to:

-   [Configure Gift Certificate Value Check](#subsect_156295531709)
    
-   [Link to the Gift Certificate Value Check Page](#subsect_1528469958)
    

This extension also lets you include the value check feature on the My Account page. To enable features on the My Account page, see [Display Gift Certificates in My Account](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156295198709.html).

## Configure Gift Certificate Value Check {#subsect_156295531709}

Use the SuiteCommerce Configuration record to enable the gift certificate value check application, set a URL path for the landing page, and customize labels and messages to fit your needs.

#### To configure Gift Certificate Value Check:

1.  In NetSuite, go to Commerce > Websites > Configuration.
    
2.  Select the website and domain where the Gift Certificate Management extension is activated and click **Configure**.
    
3.  Go to the **Extensions** tab, **Gift Certificate Value Check** subtab.
    
4.  Check the **Enable Gift Certificate Value Check** box to show the Gift Certificate Value Check application on a landing page of your website.
    
5.  Fill out the listed fields for each category, using the tables below as references.
    
6.  Click **Save**.
    
    **Landing Page Fields:**
    
    | Field | Description |
    | --- | --- |
    | URL Path | Determines the URL path for the Gift Certificate Vale Check page. |
    | Page Title - Landing Page | Sets the title for the Gift Certificate Value Check page. |
    | Input Label - Landing Page | Sets the label for the input field where users supply a gift certificate code. |
    | Input Placeholder | Determines the placeholder for the input field to give users an example of a gift certificate code. |
    | Check Button Label | Sets the label for the check balance submit button. |
    | Field Help | Determines the field level help for the Gift Certificate input field. |
    | Paste Icon Help | Determines the help message for the paste icon. |
    | Field Min. Length | Sets the minimum length for the gift certificate code. |
    | Field Max. Length | Sets the maximum length for the gift certificate code. |
    | Save to My Account Button Label | Sets the label for the button that saves the certificate to My Account after login. The user is first directed to a login page if not logged in. |
    
    **Messaging Fields:**
    
    | Field | Description |
    | --- | --- |
    | Invalid Code Warning | Determines the message to display when a user enters an invalid code. |
    | Expired Code Warning | Determines the message to display when a user enters an expired code. |
    | Inactive Code Warning | Determines the message to display when a user enters an inactive code. |
    | Remaining Value Label | Sets the label to display the remaining value of the gift certificate. |
    | Gift Certificate Code Label | Sets the label to display the code of the gift certificate. |
    | Past Expiration Date | Sets the label to display when a gift certificate expired. |
    | Future Expiration Date | Sets the label to display when a gift certificate will expire. |
    

## Link to the Gift Certificate Value Check Page {#subsect_1528469958}

You access the Gift Certificate Value Check page by adding the path entered in the **URL Path** field on the SC Configuration record to your website domain (the default path is `gift-certificate-balance`).

You can add the Gift Certificate Value Check page URL as a link on your website footer using Site Management Tools (SMT). For more information about how to add a hyperlink to your website footer using SMT, see [Adding Text and Image Content](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4138279026.html).
