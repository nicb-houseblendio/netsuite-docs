In Site Management Tools (SMT), you can add merchandising zone content to a page by dragging it from the side panel to a pre-defined area.

Note:

You can choose either the legacy merchandising zone (CMS MerchZone) or the enhanced merchandising zone (CMS MerchZone2). Both are similar, but the enhanced merchandising zone offers a configurable display, supports multiple languages, and works with SuiteCommerce themes.

If you use Commerce themes, the enhanced merchandising zone inherits all styles from the theme, but you can make changes with the Theme Skin Manager. For more information, see [Theme Skin Manager](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1512491665.html).

#### To add a merchandising zone:

1.  Log into Site Management Tools. For details, see [Logging into Site Management Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4163262385.html).
    
2.  Go to the page where you want to add the merchandising zone.
    
3.  Click the Edit Mode icon ![Edit Mode Icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/StoreFront/WebsiteContent/EditModeIcon.png) from the site management toolbar.
    
4.  Click the Add icon ![Add Icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/StoreFront/WebsiteContent/SiteMangementToolsAddIcon.png) from the site management toolbar.
    
5.  Select and drag the **CMS MerchZone** or **CMS MerchZone2** content type to the page. You can drag the content type to multiple areas of the page:
    
    -   If you drag onto an area marked **all pages**, your content shows on any page that contains that area.
        
    -   If you drag onto an area marked **page type**, your content shows on any page of that type.
        
    -   If you drag onto an area marked **this page**, your content shows only on that page.
        
6.  From the settings panel that appears in the side panel, set the following fields:
    
    | Field | Description | Applies To |
    | --- | --- | --- |
    | Name | Enter a name for the merchandising zone. It's used as an internal identifier and isn't shown on the website. | 
    -   CMS MerchZone
    -   CMS MerchZone2
    
     |
    | Visibility | Select **Always Visible** to make the merchandising zone always visible, or **Visible on Specific Dates** to choose specific dates. Leave the end date blank to keep it visible indefinitely. For more information, see [View Site as of a Specific Date in Site Management Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1513783026.html). | 
    
    -   CMS MerchZone
    -   CMS MerchZone2
    
     |
    | Section Heading | Enter the text to display in the top-left corner of the merchandising zone. | 
    
    -   CMS MerchZone2
    
     |
    | Merchandising Rule | Select the merchandising rule from the list. The list shows all merchandising rules in your NetSuite account. The content for merchandising zones is generated from interactive elements that display dynamic groups of items based on search rules. For more information, see [Creating a Merchandising Rule](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0606053629.html). | 
    
    -   CMS MerchZone
    -   CMS MerchZone2
    
     |
    | Advanced Options | The **Exclude item's in shopper's cart** and **Exclude item shopper is viewing** boxes only report the settings from the merchandising rule in NetSuite. You can't change these setting here. | 
    
    -   CMS MerchZone
    -   CMS MerchZone2
    
     |
    | Display Mode | Select how to display items in the enhanced merchandising zone. Choose from **Grid**, **Horizontal Slider**, and **Vertical Slider**. | 
    
    -   CMS MerchZone2
    
     |
    | Number of Items Per Row | Enter how many items to show per row in grid mode, or how many at a time in slider mode. Images scale based on your selection | 
    
    -   CMS MerchZone2
    
     |
    |  |  |  |
    |  |  |  |
    |  |  |  |
    | Tags | Give the merchandising zone one or more tags, separated by commas. For more information, see [Content Tags and Filter Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1524601707.html). | 
    
    -   CMS MerchZone
    -   CMS MerchZone2
    
     |
    
7.  Click **Save**.
    
8.  When you're ready, publish your changes. For details, see [Review and Publish Content in Site Management Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4419210472.html).
