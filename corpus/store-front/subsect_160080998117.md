Use SMT to delete a translation when you no longer need it.

Important:

You can't recover deleted translations.

#### To delete category translations using SMT:

1.  Log in to SMT. For details, see [Logging into Site Management Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4163262385.html).
    
2.  Select the Overview Mode icon ![Overview Mode Icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/StoreFront/WebsiteContent/OverviewModeIcon.png) from the site management toolbar.
    
3.  Select the **Categories** subtab.
    
4.  Click the ellipsis beside the category you want to delete a translation from.
    
5.  Click **Edit Settings**.
    
6.  From the **Category Settings** panel, select the language from the language dropdown list.
    
7.  Clear the **Enable this Translation instead of values in English (U.S.)** box.
    
8.  Click **Save**.
