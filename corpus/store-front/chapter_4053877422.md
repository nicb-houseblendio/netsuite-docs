NetSuite gives you lots of tools to help make sure your site's pages are optimized for search engines. Using these tools and following SEO best practices can help improve your ranking on search results pages.

You can use the tools and techniques in the table to optimize your Commerce website for search engines-and they're available to all Commerce sites.

| SEO Tools | Description | For More Information |
| --- | --- | --- |
| Images
-   Image File names

-   Image Alt Text

 | Access image files from item records in your account to update the Image Alt Text. | [Add Alternate Text](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162137415332.html#subsect_162137417679) [SEO and Images](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4284172461.html) |
| Content Delivery | Use the Content Delivery SuiteApp to access the following page elements:

-   Page Title
-   Meta Description
-   Page Header
-   Addition to <head>

 | [Using Content Delivery](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2689412.html) |
| Descriptive URLs for Item Detail Pages | You can customize any product URL on your site. | [Customizing Item URLs for SEO](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2695545.html) |
| SEO page generator | Commerce web stores automatically build full HTML pages, so search bots can easily index your website. | [SEO Page Generator](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4053806622.html) |
| Third-Party Scripts in SSP Files | You can connect third-party services like analytics, affiliate programs, or tracking code to your Commerce web store. Use the `ns-server-execute` flag in your SSP file to reference a script attached to the SSP application. Important: If you're customizing a Commerce web store, you can't reference the script as above because of the single-page architecture. | For more information about adding a third-party script to a Commerce web store, see [Adding a Third-Party Script for Analytics Tracking](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4060551230.html). |
| Sitemap Generator | Sitemap Generator builds an XML sitemap for your website for SEO. | [Sitemap Generator](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3746951084.html) |
| Structured Data Markup | SuiteCommerce and SuiteCommerce Advanced 2020.1 and later support JSON-LD structured data markup. Major search engines use structured data markup to find more details about a page and improve search results. | [Structured Data Markup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158032882820.html) |
| Robots.txt File | Create a robots.txt file to control which pages on your site get indexed. | [SEO and Robots.txt](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4286780920.html) |
| Google Analytics | Learn how you can integrate Google Analytics 4 into your Commerce web store. | [Google Analytics 4](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0104849037.html) |
