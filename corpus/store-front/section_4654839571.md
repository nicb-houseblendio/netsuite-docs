Configure properties to customize your newsletter sign up form. You can decide how leads are created in NetSuite, adjust the display options, and choose the field and feedback message texts.

The procedures in this topic explain how to:

-   [Configure Properties in NetSuite](#subsect_156831487555)
    
-   [Configure General Settings](#subsect_156831492227)
    
-   [Configure Message Settings](#subsect_156831494894)
    
-   [Configure Layout and Style Settings](#subsect_156831499879)
    

## Configure Properties in NetSuite {#subsect_156831487555}

To set up the Newsletter Sign Up extension, you must set your preferences in NetSuite.

When a user signs up for the newsletter, SuiteCommerce checks for matching customer or lead records. If no matching record is found, a new lead record is created using the Standard Customer Form as a default.

SuiteCommerce then sets this new record's **Global Subscription Status** field to Soft Opt-In. If the user does not provide a first name, last name, or company, then the record populates with the **Default First Name,** **Default Last Name**, or **Default Company**, which you can set when configuring properties in NetSuite.

For more information about the newsletter subscription process, see [Email Subscription Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4640365472.html#section_4655046988).

#### To configure properties in NetSuite:

1.  After activating the Newsletter Sign Up extension for a domain, go to Commerce > Websites > Configuration.
    
    For more information about activating an extension, see [Manage Themes and Extensions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510954484.html).
    
2.  Select the website and domain where you want to set up the extension and click **Configure**.
    
3.  Go to the **Extensions** tab.
    
    Important:
    
    If you previously implemented the Newsletter feature as part of a SuiteCommerce theme built prior to the 2018.2 release of SuiteCommerce or the Aconcagua release of SuiteCommerce Advanced, the properties for this feature are located in the **Legacy** tab, **Newsletter** subtab.
    
    You can only configure the Generic First Name, Generic Last Name, and Company Name properties. See [Newsletter Subtab](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1532356695.html) for details.
    
4.  In the **Newsletter Sign Up** subtab, set the listed fields, using the table below as a reference.
    
    You can use the placeholder `[[email]]` to automatically populate the default fields with the user's email address. This enables you to identify a user who chooses to leave the name or company fields blank. For example, you can send a personalized marketing email generated from the lead record saying "Welcome user@example.com!" if a name is not known. This placeholder can be used with the following fields:
    
    -   Default First Name
        
    -   Default Last Name
        
    -   Default Company
        
    
    | Field | Description |
    | --- | --- |
    | Marketing Campaign for Lead | Sets the marketing campaign you want to use to track leads when a user subscribes to the newsletter. For more information, see [Campaign Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N984967.html). |
    | Default First Name | Sets the default text to display in the **First Name** field of the lead record if a first name is not supplied by the user. |
    | Default Last Name | Sets the default text to display in the **Last Name** field of the lead record if a first name is not supplied by the user. |
    | Create Lead as Company | If checked, creates newsletter sign up leads as companies, rather than individuals. This setting applies to newsletter sign up only. For more information, see [Lead Management](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1086131.html). |
    | Associate Lead To | Determines the subsidiary with which you want the lead to be associated. |
    | Default Company | Sets the default text to display in the **Company** field of the lead record if a first name is not supplied by the user. |
    
5.  Click **Save.**
    

## Configure General Settings {#subsect_156831492227}

Set the general fields in SMT to set up your newsletter sign up form. You can determine the name and display options for fields, as well as button and privacy policy text.

#### To configure general settings:

1.  While logged in to SMT, go to the page that contains the newsletter sign up form.
    
2.  In the **Newsletter Sign Up** box, click **Edit**.
    
    This displays the Newsletter Sign Up Settings in the side panel.
    
3.  In the **General** tab, set the following fields:
    
    | Field | Description |
    | --- | --- |
    | Visibility | Determines the visibility option that determines when you would like to make the form visible. For more information about visibility options, see [View Site as of a Specific Date in Site Management Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1513783026.html). |
    | Header | Sets the title you want to display at the top of the newsletter sign up form. |
    | Subtitle | Sets the descriptive text you want to display below the header text. |
    | Email Field Label | Sets the label for the **Email** field. |
    | Email Field Hint | Sets the text you want to use as a placeholder for the **Email** field. |
    | Show First Name Field | If checked, displays the **First Name** field to the user. |
    | Optional First Name | If checked, makes the **First Name** field optional. If the **First Name** field is left blank, the **Default First Name** field (SC Configuration record > Extensions > Newsletter Sign Up) is used for the **First Name** field of the lead record. |
    | First Name Field Label | Sets the label for the **First Name** field. |
    | First Name Field Hint | Sets the text you want to use as a placeholder for the **First Name** field. |
    | Show Last Name Field | If checked, displays the **Last Name** field to the user. |
    | Optional Last Name | If checked, makes the **Last Name** field optional. If the **Last Name** field is left blank, the **Default Last Name** field (SC Configuration record > Extensions > Newsletter Sign Up) is used for the **Last Name** field of the lead record. |
    | Last Name Field Label | Sets the label for the **Last Name** field. |
    | Last Name Field Hint | Sets the text you want to use as a placeholder for the **Last Name** field. |
    | Show Company Field | If checked, displays the **Company** field to the user. |
    | Optional Company | If checked, makes the **Company** field optional. If the **Company** field is left blank, the **Default Company Name** field (SC Configuration record > Extensions > Newsletter Sign Up) is used for the **Company** field of the lead record. |
    | Company Field Label | Sets the label for the **Company** field. |
    | Company Field Hint | Sets the text you want to use as a placeholder for the **Company** field. |
    | Button Text | Determines the text you want to display on the submit button. |
    | Privacy Policy Label | Determines the text you want to display as a link to a privacy policy page. |
    | Privacy Policy Link | Determines the URL to which you want the privacy policy button to link. If you leave this field blank, a link does not display. |
    | Tags | Sets keywords to help filter your content in the Review Changes list. For more information about content tags, see [Content Tags and Filter Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1524601707.html). |
    
4.  Click **Save.**
    

## Configure Message Settings {#subsect_156831494894}

You can determine the feedback messages shown to users by editing the message fields in SMT.

#### To configure message settings:

1.  While logged in to SMT, go to the page that contains the newsletter sign up form.
    
2.  In the **Newsletter Sign Up** box, click **Edit**.
    
    This displays the Newsletter Sign Up Settings in the side panel.
    
3.  In the **Messages** tab, set the following fields:
    
    | Field | Description |
    | --- | --- |
    | Empty First Name Field | Determines the message to display when a required **First Name** field is left blank. |
    | Empty Last Name Field | Determines the message to display when a required **Last Name** field is left blank. |
    | Empty Email Address Field | Determines the message to display when a required **Email Address** field is left blank. |
    | Empty Company Field | Determines the message to display when a required **Company** field is left blank. |
    | Invalid Email Address | Determines the message to display when an invalid email address is entered. |
    | Opt-In Subscription Confirmation | Determines the message to display when the user successfully subscribes to the newsletter. |
    | Already Opt-In | Determines the message to display when the user is already signed up for the newsletter. |
    | Confirmed Opt-Out | Determines the message to display when the user has opted out of the newsletter. |
    | Unexpected Error | Determines the message to display when there is an unexpected error during sign up. |
    
4.  Click **Save.**
    

## Configure Layout and Style Settings {#subsect_156831499879}

You can customize the look of the newsletter sign up form by setting the layout and style fields in SMT.

#### To configure layout and style settings:

1.  While logged in to SMT, go to the page that contains the newsletter sign up form.
    
2.  In the **Newsletter Sign Up** box, click **Edit**.
    
    This displays the Newsletter Sign Up Settings in the side panel.
    
3.  In the **Layout & Style** tab, set the following fields:
    
    | Field | Description |
    | --- | --- |
    | Newsletter Layout | Determines the layout for the newsletter sign up form.
    -   **Vertical** - fields stacked in the middle of the container
    -   **Horizontal** - fields listed horizontally across the container
    -   **Align** **Left** - fields stacked in the left side of the container
    -   **Align Right** - fields stacked in the right side of the container
    
    On mobile devices, the layout automatically appears as **Vertical**. |
    | Background Image | Determines the image to use as the newsletter sign up form background. Images are aligned to center-middle of the container and cover the full background. |
    | Image Resize ID | Sets the image resizing option you want the **Background Image** to use. To use this option, you must enter an enabled **Image Size ID** found in the **Image Resizing** section of the Web Site Setup record (Commerce > Websites > Website List > Images). |
    
4.  Click **Save.**
