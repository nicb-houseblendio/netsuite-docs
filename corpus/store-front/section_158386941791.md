Note:

The Bridge Theme requires SuiteCommerce or the Aconcagua release of SuiteCommerce Advanced or later.

The Bridge Theme is a custom theme that lets you create a tech-orientated web store. It's only available if it's provisioned, installed, and activated for a selected domain in your account. For more information, see [Installing Theme and Extension SuiteApps](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510953648.html).

You can configure the Bridge Theme properties on your domain using the SuiteCommerce Configuration record. For more information, see [Configuring Themes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158680127593.html).

Important:

When activating the Bridge Theme, you must also activate the Bridge Theme extension that comes with the SuiteApp. For details, see [Activating Themes and Extensions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1549034518.html).

The following image shows what the Bridge Theme looks like before customization. For details on how to customize a theme, see [Theme Skin Manager](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1512491665.html) and [Site Management Tools Page Layout Selector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1549386933.html).
