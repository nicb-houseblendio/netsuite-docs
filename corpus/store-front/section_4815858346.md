## Complete Order Management Tasks for Store Pickup {#subsect_162971420170}

SuiteCommerce and SuiteCommerce Advanced websites integrate with NetSuite's Order Management feature to provide the complete Store Pickup feature.

To complete the Order Management tasks required to set up Store Pickup, follow the steps outlined in the help topic [Setting Up Store Pickup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4817104683.html).

## Set Up Automation in Advanced Order Management {#subsect_162971474531}

Important:

Set up Advanced Order Management in your NetSuite account before setting up Store Pickup on your Commerce website.

Advanced Order Management lets you set up automation to meet your company's needs. Enabling Run Automation is optional, but it's considered a best practice.

Enabling Run Automation automates a business event workflow in NetSuite. When business events occur on a sales order, NetSuite runs automation processes based on your Advanced Order Management settings. For more information, see [Order Fulfillment Automation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4440622374.html).

Note:

You'll incur usage fees for order fulfillment automation if you create over 5,000 automated sales orders in a year. For more information, see [Automation Capacity and Usage Fees](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156390342045.html).

#### To set up automation in Advanced Order Management:

1.  Go to Setup > Order Management > Setup Tasks > Advanced Order Management.
    
2.  Select the **Automation** tab and then the **Pickup Orders** subtab.
    
3.  Check the **Run Automation** box.
    
4.  In the **Fulfillment Request Creation** area, select one or both of the following options to specify when to create fulfillment requests:
    
    -   **Sales Order Approved** - Automatically creates a fulfillment request when a store pickup sales order is approved and there's no payment hold.
        
    -   **Payment Hold Released** - Automatically creates a fulfillment request for store pickup sales orders when a payment hold is released on an approved store pickup sales order.
        
5.  Click **Save**.
    

## Set Up Store Locator {#subsect_162971523629}

The Store Locator feature helps customers find your physical stores by searching location records in your NetSuite account and showing results near their location or a specified address.

To set up this feature, follow the steps outlined in [Store Locator](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4594388350.html).
