In Site Management Tools (SMT), you can hide translated content you're not ready to show on your website.

#### To hide website content translations:

1.  Log in to SMT. For details, see [Logging into Site Management Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4163262385.html).
    
2.  Select the Overview Mode icon ![Overview Mode Icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/StoreFront/WebsiteContent/OverviewModeIcon.png) from the site management toolbar.
    
3.  Select the **Pages** subtab.
    
4.  Click the ellipsis next to the page you want to hide translations for.
    
5.  Click **Preview**.
    
6.  Select **Edit Mode**.
    
7.  Hover over the content you want to hide translations from and click the Edit icon ![Edit icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/StoreFront/WebsiteContent/EditModeIcon.png).
    
8.  From the settings panel, select the language from the language dropdown list.
    
9.  Clear the **Enable this Translation** box.
    
10.  Click **Save**.
     

You can view hidden translations in **Overview Mode** from the **Translations** tab. Use the **Translation Status** filter and select **Hidden** to display all hidden content.
