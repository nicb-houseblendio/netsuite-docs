In complex scenarios, particularly when there are multiple customer segments and items are included in more than one item segment, it's hard to know which items are visible and purchasable by which customers. To help you verify that the correct items are visible and purchasable by the correct customers, you have the following options:

-   **Reports** - Personalized Catalog Views (PCV) includes two standard workbooks that show which customers can see, see prices for, or buy a particular item and which items, with or without prices, are visible to and purchasable by a particular customer. For more information, see [Using Workbooks to Verify Personalized Catalog Views](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1560334678.html).
    
-   **Website preview** - Use Site Management Tools to see what items are visible to different customer segments and whether a customer segment is able to see item prices or buy the items. For more information, see [Using SMT Advanced Preview to Verify Personalized Catalog Views](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1560334720.html).
    
    Note:
    
    If you have a SuiteCommerce Advanced website, you can use website preview to see if different customer segments can view prices or buy items only if you are using the 20.2 or later release of SuiteCommerce Advanced.
