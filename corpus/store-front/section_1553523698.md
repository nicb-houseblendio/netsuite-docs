The Grid Order extension lets you set up matrix items to display purchasing options in a table on the Product Details page (PDP). These items display purchasing options in a table, replacing the standard experience. This view is ideal for customers who need to buy multiple variations of an item.

For example, a user can add the following items to their cart at one time:

-   10 small red gloves
    
-   10 medium black gloves
    
-   15 large white gloves
    

![Grid Order](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/StoreFront/Products/GridOrderScreenshot.png)

You can set up Grid Order for any matrix items with one or two item options. When enabled and set up, users can quickly add quantities for multiple buying options in a table.

This topic explains how to do the following:

-   [Add Field Sets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1554911198.html)
    
-   [Configure Grid Order](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1553536143.html)
    
-   [Set Up Matrix Items for Grid Order](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1553536158.html)
    

Important:

Commerce extensions are only available if provisioned, installed, and activated for a selected domain in your account. For more information, see [Commerce Extensions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1530632028.html).

Note:

You need SuiteCommerce or the Aconcagua release of SCA or later to use extensions.

## Limitations {#subsect_1553536605}

Note the following limitations when using the Grid Order extension:

-   The grid won't appear on your site if a matrix item has three or more item options. With Grid Order, limit matrix item options to one or two.
    
-   Grid Order won't display items with a parent matrix item that includes a required item option.
    

See [Matrix Items](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2227654.html) for details on how to create item records using an item matrix.
