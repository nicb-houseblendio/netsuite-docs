This dataset lets you view the number and value of transactions that can be traced back to shoppers clicking on the intelligent item recommendations displayed in your website. This dataset forms part of the source data for the [Intelligent Item Recommendations Workbook](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_161418756993.html).

## Dataset Configuration {#subsect_164337499705}

The Estimated Revenue dataset contains fields from three record types. To edit the dataset, see [Defining a Dataset](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544122173.html).

| Root Record Type | Joined Record Type | Custom Formula Fields | Data Grid | Criteria Filters |
| --- | --- | --- | --- | --- |
| Intelligent Item Recommendations | 
-   Conversions
-   Recommendation Scenario

 | (none) | The following record fields are included in the dataset: **Conversions**

-   Amount (Credit)(Transaction Currency)
-   Transaction
-   Item > Item Name/ Number
-   Entity > Name

**Recommendation Scenario**

-   Website

**Intelligent Item Recommendations**

-   Recommendation Scenario
-   Date

 | (none) |
