Landing pages are new custom pages with unique URLs. You create a landing page when you need to add content that is not specific to an existing page, such as the Home page or Item Detail page. As with content, when you create a landing page, you set the visibility options for that page. Like content, the landing pages are published using the same workflow. It's displayed according to the visibility options you specify. For details, see [View Site as of a Specific Date in Site Management Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1513783026.html).

Typical landing pages might include:

-   About Us
    
-   Contact Us
    
-   Return Policy
    
-   Locations
    
-   Special Event
    
-   Seasonal Sale
