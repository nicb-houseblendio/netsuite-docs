SuiteCommerce Advanced lets you set image resizing options for your site's images. When you're setting up Commerce Categories, you'll want to set the image resizing option for the commerce category banner images. For more information, see [Image Resizing and Compression](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162137401329.html).

#### To set up image resizing options for Commerce Categories:

1.  Go to _Commerce > Websites > Website List_.
    
2.  Click **Edit** next to the website where you want to set up image resizing.
    
3.  Click the **Images** subtab.
    
4.  Locate the **Image Resizing** group and make the following entries.
    
    ![Image resizing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/StoreFront/Products/CategoryBannersImageResizing.png)
    1.  **Image Size ID** - Enter **categorybanner**.
        
    2.  **Description** - The description is optional.
        
    3.  **Enabled** - Check the box.
        
    4.  **Maximum Width** and **Maximum Height** - Enter the maximum width and height for the category banner image. If you enter only the width or height, the other value is filled in automatically.
        
5.  Click **OK**.
    
6.  Click **Save**.
