Note:

The Posh Theme requires SuiteCommerce or the Aconcagua release of SuiteCommerce Advanced or later.

The Posh Theme is a custom theme that lets you showcase your health and beauty web store's assorted products. It's only available if provisioned, installed, and activated for a selected domain in your account. For more information, see [Installing Theme and Extension SuiteApps](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510953648.html).

You can configure the Posh Theme properties on your domain using the SuiteCommerce Configuration record. For more information, see [Configuring Themes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158680127593.html).

Important:

When activating the Posh Theme, you must also activate the Posh Theme extension that comes with the SuiteApp. For details, see [Activating Themes and Extensions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1549034518.html).

## Posh V4 Theme {#subsect_75155048105}

Posh V4 is an upgraded version of the Posh custom theme that still gives you a framework for your interior design-focused web store, and also taking advantage of the latest SC Base Theme releases. This means that Posh V4 can get future updates, fixes, enhancements, and new features from the SC Base Theme by reactivating Posh V4 in the Extension Manager.

To activate Posh V4:

1.  Go to Commerce > Extensions > Extension Manager and click **Edit** next to the website you want to update.
    
2.  In the **Themes** tab, check the box for **Posh V4**.
    
3.  Click **Activate**.
    

### Considerations When Activating Posh V4 {#subsect_80155659372}

When switching from the Posh theme to Posh V4, consider the following:

-   Activating Posh V4 doesn't replace or remove the standard Posh theme from your list of themes in the Extension manager.
    
-   If you've made customizations to the Posh theme and then switch to Posh V4, those changes won't carry over.
    
-   The Posh Theme Extension (found in the Extensions tab of the Extension Manager) can stay active without any changes.
    

## Customizing the Posh Theme {#subsect_0407035058}

You can use additional template areas with the Posh Theme using SMT or when modifying a page with an extension. For more information, see [SuiteCommerce Base Theme Templates and Areas](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_051602162197.html).
