After defining item and customer segments, determine which item segments can be seen and purchased by which customer segments. This requires two settings:

-   **Mapping** - Defines a relationship between an item segment and one or more customer segments
    
-   **Website Visibility Level** - Defines the nature of the relationship between the item segment and the mapped customer segments. Options include:
    
    -   **Display Fully** - Allows customers in the mapped customer segments to view and purchase all items in the item segment.
        
    -   **Disable Purchase** - Hides the **Add to Cart** button for all items in the item segment. This prevents customers in the mapped customer segments from buying the items.
        
    -   **Disable Purchase and Hide Price** - Hides the item price and **Add to Cart** button for all items in the item segment. This prevents customers in the mapped customer segments from viewing the item price and buying the items.
        
    -   **Hide Fully** - Hides unmapped items from all users. Unmapped items are items not mapped to any customer segments. For more information, see [Defining Visibility of Unmapped Items](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1560331608.html).
        
        This visibility level is available only for the Unmapped Items item segment.
        

Note:

For SuiteCommerce Advanced websites, these visibility options require the 2020.2 release or later:

-   Disable Purchase
    
-   Disable Purchase and Hide Price
    

Avoid using these options with SuiteCommerce Advanced releases prior to 2020.2.

You might not want to limit some item segments to specific customer segments. In such cases, you can allow all users to view and buy them.

You may also have items on your web store that aren't mapped to a customer segment. These items are grouped into the Unmapped Items segment. Determine which customer segments, if any, need to see and buy items in Unmapped Items segment.

Define which customers can see and buy which item segments in these NetSuite areas:

-   **Customer Segments Manager (CSM)** - Define mappings and visibility levels between item segments and customer segments. The CSM provides an overview of all the mappings that have been defined and is the only place to define access to unmapped items for all users. For more information, see [Defining which Customer Segments can Access Items (CSM)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1560331471.html) and [Defining Visibility of Unmapped Items](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1560331608.html).
    
-   **Customer Group record** - Define which item segments a customer group can view, view prices, or purchase on the Customer Group record. For more information, see [Defining which Customer Segments can Access Items (Customer Group)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1560331508.html).
    
-   **Item Collection record** - Define which customer segments can view, view prices, or purchase items in an item collection on the Item Collections record. For more information, see [Defining which Customer Segments can Access Items (Item Collection)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1560331493.html).
    
-   **Commerce Categories record** - Define which customer segments can view items in a commerce category on the Commerce Category record. Note that you can't set **Disable Purchase** or **Disable Purchase and Hide Price** visibility options. For more information, see [Defining which Customer Segments can View Items (Commerce Categories)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_159414449791.html).
    

Note:

Please be aware of the following:

-   All item collection to customer segment mappings are visible and editable in the CSM, regardless of where the mapping was created.
    
-   If a customer belongs to multiple customer segments with different visibility levels for the same item segment, they'll have the highest visibility level of the customer segments they belong to. For an example of this, see the Head Office Buyers group in [Different Product Lines Available to Different Customers](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161133053638.html).
    
-   If an item is in multiple item segments with different visibility levels, and a customer has access to more than one of these segments, the highest visibility level will apply to the relationship between the customer and the item. For example, if tomatoes are in both the Fruits and the Vegetables item segment, a customer has the website visibility level of Display Fully for Fruits and Disable Purchase for Vegetables, the customer can buy tomatoes.
    
-   If a customer in a customer group has contacts linked to it, the contacts are able to see the associated item segments only if the **Give Access** checkbox is checked for the customer and the **Access** checkbox is checked for the contact on the Customer record.
    
-   When making a dynamic item collection visible to a customer segment, PCV uses a snapshot of the dynamic item collection members. This snapshot updates hourly. Similarly, if you use a dynamic customer group as a customer segment, PCV uses a snapshot of the customers in the customer group and updates the snapshot hourly.
