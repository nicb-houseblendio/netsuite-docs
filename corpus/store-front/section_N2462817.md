You can restrict customers from checking out of your web store until they've reached a minimum total sales amount. If you have multiple subsidiaries and use different currencies, you can set a minimum order amount for each currency that's available online.

#### To set a minimum order amount for web store sales: {#procedure_1510775674}

1.  Go to _Commerce > Websites > Web Site List_.
    
2.  Click **Edit** next to the website you want to update.
    
3.  On the **Shopping** subtab, enter the minimum amount a customer must spend in the **Minimum Order Amount** field. If someone tries to check out with less than this, they'll get a warning and can't finish the order until they add more items.
    
    Note:
    
    If you use the Multiple Currencies feature, set the minimum order amount for each currency in the **Currency** list at the bottom of the **Shopping** subtab.
    
4.  Click **Save**.
    

To set a minimum or maximum quantity limit for an item, see [Order Quantity](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510780638.html).
