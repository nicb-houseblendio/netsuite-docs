## Tracked Events in Web Store Implementations with GTM {#subsect_25122253493}

Note:

For implementations of SuiteCommerce Advanced (SCA) 2018.2 - 2022.2 using Google Analytics 4 with the Google Tag Manager Commerce Extension, review the data-layer structure of SCA version 2023.1 or later and compare it with your current version. With the release of SCA 2023.1, modifications were made in the data-layer code to comply with Google and correctly track information with Google Analytics events. For information about the suggested data-layer structure you should use, see [Google Tag Manager Events Not Displaying in Data Layer Upon Checkout](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1151545068.html).
