Tracking visitor traffic is a key part of managing your site, and Commerce web store works with the most popular analytics tools. The following topics show you how to set up analytics tools on your Commerce web store.

| Description | For More Information |
| --- | --- |
| Learn how to link your Google Universal Analytics and Google Ads accounts. | [Google Ads](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4429358327.html) |
| You can manage multiple analytics tools in one place with Google Tag Manager. | [Google Tag Manager](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4546835898.html) |
| Learn how to set up Google Analytics 4, one of the most popular analytics tools. It replaces Google Universal Analytics as Google's cross-platform analytics solution. | [Google Analytics 4](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0104849037.html) |
| Learn how to set up Google Universal Analytics, one of the most widely used analytics tools. Important: Google Analytics 4 (GA4) has replaced Google Universal Analytics (GAU) as Google's cross-platform analytics solution. Standard GUA properties stopped processing new data on July 1, 2023, and 360 Universal Analytics properties will stop on July 1, 2024. See [Google Analytics 4](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0104849037.html) for information about GA4 and how to migrate from GUA. | [Google Universal Analytics](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3783245880.html) |
