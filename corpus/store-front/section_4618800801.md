This information refers to SuiteCommerce and the Elbrus release of SuiteCommerce Advanced or later.

Note:

Quantity Pricing relies on the Search API and is not available with Site Builder Extensions.

SuiteCommerce Advanced provides a Quantity Pricing feature for customers who offer quantity-based price breaks. This feature uses the Search API to return an item's quantity pricing details from NetSuite (in JSON format) and display results in a chart describing the pricing discounts available by quantity ordered. This information is collapsed by default and is available when the shopper clicks or taps a link.

![Quantity Pricing Chart](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/StoreFront/Orders/QuantityPricing-Chart.png)

Quantity pricing information is available to shoppers in the following areas of your website:

-   Product Details page
    
-   Quick View modal window
    
-   Quick Order page ([Quick Order](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4618800500.html) must be enabled)
    
-   Request for Quote page ([Quotes for Commerce Websites](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4464799196.html) must be enabled)
    
-   Product List Details page in My Account
    
-   Re-Order List Page in My Account
    

To enable this feature, perform the tasks detailed in [Set Up Quantity Pricing in NetSuite](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4622074558.html).

To disable this feature, edit the distro.json file as described in [Disable Quantity Pricing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4622078441.html).
