Important:

The features available for these themes depend on which version of SuiteCommerce or SuiteCommerce Advanced your account is using. For details, see [SuiteCommerce, SuiteCommerce MyAccount, and SuiteCommerce Advanced Release Notes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4410490401.html).

Note:

Commerce themes require SuiteCommerce or the Aconcagua release of SuiteCommerce Advanced or later.

Themes are only available if provisioned, installed, and activated for a selected domain in your account. When you activate any of these themes, you must also activate the companion theme extension that comes with the SuiteApp. For more information, see [Activating Themes and Extensions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1549034518.html). Make sure you have the latest version of the theme and theme extension in the Extension Manager. For more information, see [Manage Themes and Extensions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510954484.html).
