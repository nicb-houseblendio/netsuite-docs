If you're using URL Components on your item records, URL Component Aliases let you set up aliases for items or facets where you've changed the URL Component. For example, maybe you first set up a prelude tank top with the URL Component **tank-top-prelude**, but later decide that **Prelude-Tank-Top** works better.

Remember, if you change a URL parameter, the page might already be indexed with the old one, and visitors may have bookmarked or shared the previous URL. If you change the URL parameter, any search engine that tries to visit the page will get a 404 Page Not Found error.

By using the URL Component Aliases feature, you can change the URL Component for the item to **Prelude-Tank-Top**, and define a URL Component Alias for **tank-top-prelude**. When a visitor visits `http://mywebstore.com/tank-top-prelude`, they are automatically redirected to `http://mywebstore.com/Prelude-Tank-Top`. You can define the following URL Component Aliases for the same item:

-   tank-top-prelude
    
-   Tank-Top-Prelude
    
-   prelude-tank-top
    

Note:

URL Component Aliases are available only for Shopflow 1.06 or later.

To use URL Component Aliases, you must first enable the URL Components Alias feature in NetSuite. For more information, see [Enable URL Components Alias](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4047713124.html). Then you can enter URL Components on item records, and use the URL Component Alias subtab to maintain a list of aliases for that item. For more information, see [URL Components on Items](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4129902430.html). To manage URL components for facets, you can use the URL Components for Facets page. For more information, see [URL Components for Facets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4129902565.html).
