You can create two types of item collections:

-   **Static item collections** - Lets you add and remove items manually. They're great when your items can't be grouped by specific properties.
    
-   **Dynamic item collections** - Lets you add and remove items automatically based on a saved search. Whenever an item matches the saved search, it's added to the collection.
    

#### To create a dynamic item collection:

1.  Go to _Commerce > Marketing > Personalization > Item Collections > New_.
    
2.  In the **Name** field, enter a name for the item collection (up to 200 characters).
    
3.  Enter a description for the item collection.
    
    If you want, you can get writing help for the **Description** field from our generative AI service, NetSuite Text Enhance. Click the **Enhance Text** button to see your options. For more details, see [Text Enhance](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_2171112518.html).
    
4.  Select the **Dynamic** option on the toggle.
    
    ![Item collection type toggle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/StoreFront/Products/ItemCollectionTypeDynamic.png)
    
    Note:
    
    You can't switch an item collection from Dynamic to Static or the other way around after you've saved it.
    
5.  Select the existing item saved search you want to use from the **Saved Search** list.
    
    For information about how to create a saved search, see [Defining a Saved Search](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N676039.html).
    
6.  Click **Save**.
    

#### To create a static item collection:

1.  Go to _Commerce > Marketing > Personalization > Item Collections > New_.
    
2.  In the **Name** field, enter a name for the item collection (up to 200 characters).
    
3.  Enter a description for the item collection.
    
    If you want, you can get writing help for the **Description** field from our generative AI service, NetSuite Text Enhance. Click the **Enhance Text** button to see your options. For more details, see [Text Enhance](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_2171112518.html).
    
4.  Select the **Static** option on the toggle.
    
    ![Item collection type toggle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/StoreFront/Products/ItemCollectionTypeStatic.png)
    
    Note:
    
    You can't switch an item collection from Dynamic to Static or the other way around after you've saved it.
    
5.  On the **Items** subtab of the item collection, do one of the following:
    
    -   To add multiple items together:
        
    
    1.  Click **Add Multiple**.
        
    2.  Check the boxes for the items you want to include and click **\>** to move them to the Current Selections pane. You can use Shift and Ctrl on your keyboard to select or clear multiple values.
        
    3.  To find specific items, use the search box at the top of the Add Items window. You can also filter the list using the filter above the items.
        
    
    -   To add items one by one, pick them from the list in the Name field. You can search for specific items by typing in at least three characters from the item name.
        
6.  Click **Save**.
    

You can also use CSV Import to create static item collections. The Item Collection and Item Collection Item Map records need to be imported separately. For more information, see [Item Collection Import](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157565660234.html) and [Item Collection Item Map Import](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157599533377.html).
