Website users can:

-   View the status and details of their current subscriptions, including:
    
    -   Subscription plan name
        
    -   Activation date
        
    -   Last billing date
        
    -   Next billing date
        
    -   Renewal date
        
    -   Subscription status
        
-   View optional add-ons available for their subscriptions.
    
    Add-on lines are options added to the plan but not included when the subscription started.
    
-   See which add-ons are currently active in their subscriptions.
    
-   View add-on details like service description, quantity, cost summary, and pricing information.
    
-   Cancel or pause subscription line items and add-ons.
    
    You can set up these options in your subscription configuration record. See [Configure Subscriptions for Commerce Websites](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161460400005.html).
    
-   Change the quantity of optional add-on items.
    
    You can set up these options in your subscription configuration record. See [Configure Subscriptions for Commerce Websites](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161460400005.html).
    
-   Pause and restart a subscription.
    
    You can set up these options in your subscription configuration record. See [Configure Subscriptions for Commerce Websites](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161460400005.html).
    
-   Cancel or pause a subscription.
    
    You can set up these options in your subscription configuration record. See [Configure Subscriptions for Commerce Websites](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161460400005.html).
    

Users can also filter their subscription list by billing account. See the following sample My Subscriptions page:

**My Subscriptions Page**

![Example of the My Subscriptions page.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/StoreFront/MyAccount/MySubscriptionsPage.png)

After selecting a subscription on the My Subscriptions page, users can view more details about it, including:

-   Activation date
    
-   Last billing date
    
-   Next billing date
    
-   Renewal date
    
-   Subscription status
    
-   Subscription price
    
-   Subscription type
    
-   Subscription quantity
    

This page also shows any add-ons linked to the subscription and lets users view all available add-ons or cancel the subscription. See the following sample Subscription Detail page:

**Subscription Detail Page**

![Example of the Subscriptions Detail page.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/StoreFront/MyAccount/SubscriptionDetailPage.png)
