Follow these steps if you need to change the button link or text after the slideshow is configured.

#### To change the button link or alternative text: {#procedure_1537878336}

1.  Log into Site Management Tools. For details, see [Logging into Site Management Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4163262385.html).
    
2.  Go to the page that contains the slideshow.
    
3.  Click the Edit mode icon ![Edit Mode Icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/StoreFront/WebsiteContent/EditModeIcon.png) from the site management toolbar.
    
4.  Hover over the **Slideshow** box to display the content controls.
    
5.  Click the **Settings** button. This displays the Slideshow Settings in the side panel.
    
6.  Enter the URL for the link in the **Button Link** field or enter the alternative text in the **Alt Text** field.
    
7.  Click **Save**.
