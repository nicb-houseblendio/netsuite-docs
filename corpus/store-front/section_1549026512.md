If you're activating themes and extensions on a domain for the first time, you must create a new activation. If you or anyone else has already activated a theme or extension for a domain, that activation should be listed in the Extension Manager.

Note:

If you go through the New Activation procedure for an existing domain, the Extension Manager simply launches the active themes and extensions for that domain.

#### To create a new activation:

1.  In NetSuite, go to Commerce > Extensions > Extension Manager.
    
2.  Click **New Activation**.
    
3.  Select a site from the **Select a Web Site** list. This field is required.
    
4.  Select the domain you want from the **Select a Domain** list. This field is required.
    
5.  If you're activating themes and extensions on an SCIS domain:
    
    1.  Select the subsidiary from the **Select Subsidiary** list.
        
    2.  Select the location from the **Select Location** list.
        
        Note:
        
        If you leave either of these fields blank, NetSuite sets the subsidiaries and locations to **All** by default.
        
6.  Click **Next** to select themes and extensions for the domain, or click **Cancel** to abort the activation.
    
    Note:
    
    If you select a domain that's already activated, the Extension Manager launches the activation as if you clicked **Edit** on the preceding page.
    
7.  Follow the instructions in [Activating Themes and Extensions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1549034518.html).
