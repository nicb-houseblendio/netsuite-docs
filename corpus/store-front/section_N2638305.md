Use the Redirects list page to update multiple URL redirects from one domain to another.

Remember, any domain you want to use has to be on your shopping domains list. Redirects won't be converted if you use the Domains page to overwrite or delete the original domain.

For information about how redirect URLs work, see [Setting Up a URL Redirect](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2638072.html).

#### To change the domain on multiple redirects: {#procedure_N2638348}

1.  Go to _Commerce > Hosting > Redirects_.
    
2.  In the Filters section of the **Redirects** list page, select a domain in the **Change domain from field**, and then select another domain in the **to** field.
    
3.  Click **Update Redirects**.
    

Immediately after updating the list of redirects, a popup window is displayed, confirming the number of changed records.
