You can review translated content on your website before you publish it. You should review translations to make sure nothing's missing and special characters are displayed properly. This is also a good time to upload any language-specific images you want to appear on your site.

#### To edit and review translations:

1.  Log in to Site Management Tools (SMT). For details, see [Logging into Site Management Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4163262385.html).
    
2.  Select the Overview Mode icon ![Overview Mode Icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/StoreFront/WebsiteContent/OverviewModeIcon.png) from the site management toolbar.
    
3.  Select the **Translations** subtab.
    
4.  Select the ellipsis next to the content you want to check translations for and select **Preview**.
    
5.  Select **Edit Mode**.
    
6.  To check the translation status, hover over the Translation Status icon ![''](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/StoreFront/WebsiteContent/TranslationStatusIcon.png).
    
7.  To edit content, click the Edit icon ![Edit Icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/StoreFront/WebsiteContent/EditModeIcon.png).
    
8.  From the settings panel, select the language you want to review.
    
9.  Make any changes you need and click **Save**.
    
    Note:
    
    If you clear the **Enable this Translation** box, it hides the translated content. For more information, see [Hiding Landing Page Translations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_162317714817.html) and [Hiding Website Content Translations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_162306579560.html).
    
10.  To review your changes, select the language specific domain from the domain switcher.
     
11.  Click **Overview Mode**.
     
12.  Select the **Translations** tab.
     
13.  Select the ellipsis next to the content you want to review and click **Preview**.
     
14.  When you're ready, publish the changes. For details, see [Review and Publish Content in Site Management Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4419210472.html).
     

You can also edit translations from the Translations tab by clicking the ellipsis next to the content you want to edit, and then selecting Edit. From the settings panel, select the preferred language and make any required changes.
