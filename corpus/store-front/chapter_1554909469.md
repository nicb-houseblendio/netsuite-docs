The Infinite Scroll extension loads content continuously as users scroll down the page, eliminating the need for pagination. This extension lets users easily browse items on the Product Listings page (PLP), which can help boost sales.

With the optional auto scroll feature, you can decide if users need to click a button to see more content or keep scrolling as new products load automatically.

Important:

Commerce extensions are available only if provisioned, installed, and activated for a selected domain in your account. For more information, see [Commerce Extensions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1530632028.html).

Note:

Extensions require SuiteCommerce or the Aconcagua release of SuiteCommerce Advanced or later.

## Configure Infinite Scroll {#subsect_1554910102}

Use the SuiteCommerce Configuration record to set the loading button labels and decide if you want to turn on the auto scroll feature.

#### To configure Infinite Scroll:

1.  Go to Commerce > Websites > Configuration.
    
2.  Select the website and domain where the Infinite Scroll extension is activated and click **Configure**.
    
3.  Go to the **Extensions** tab.
    
4.  In the **Infinite Scroll** subtab, set the following fields:
    
    | Field | Description |
    | --- | --- |
    | Load More Content Label | Sets the label for the **Load More Content** button. |
    | Load Previous Content Label | Sets the label for the **Load Previous Content** button. |
    | Enable Auto Scroll | If you check this, pages automatically load when users reach the bottom, instead of showing a **Load More Content** button. This feature keeps users from reaching the site footer until they've scrolled through every page. |
    
5.  Click **Save**.
    

After configuring this extension, users can browse your PLP with Infinite Scroll.
