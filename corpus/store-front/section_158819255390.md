Note:

Themes require SuiteCommerce or the Aconcagua release of SuiteCommerce Advanced or later.

Important:

Commerce themes are only available if provisioned, installed, and activated for a selected domain in your account. For details, see [Installing Theme and Extension SuiteApps](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510953648.html).

Important:

To configure a theme, you must also have the companion theme extension activated. For details, see [Available Commerce Themes and Supported Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158695491035.html) and [Activating Themes and Extensions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1549034518.html).

This section gives an overview of the Commerce theme settings you can configure for when someone enters an incorrect URL. The 404 page settings are the same across all themes.

#### To configure the 404 page:

1.  Go to Commerce > Websites > Configuration.
    
2.  Select the website and domain where the theme is activated and click **Configure**.
    
3.  Go to the theme name subtab.
    
4.  Go to the **404 Page** subtab.
    
5.  Use the following table to fill out the fields.
    
    | Field | Description |
    | --- | --- |
    | Background Image | Enter the background image. Images should be 1170 pixels wide. All images should be uploaded to the NetSuite File Cabinet, and stored in an image folder you create under Website Hosting Files > Live Hosting Files. For details, see [File Cabinet Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N541319.html). If you use Cascading Style Sheets (CSS) to insert images, they are overridden by the images stored in the File Cabinet. |
    | Background Color | Set the background color. The background color only appears if there is no background image. You can use HEX and HTML color values. |
    | Title | Enter the title for the 404 page. For example, 404 Page Not Found. |
    | Text | Enter the text for the 404 page. For example, The page you are looking for does not exist. |
    | Button Text | Enter the text to show on the button. If this field is left blank, the button doesn't appear. |
    | HREF | Enter the URL of the internal page that you want users to go to when they click the button. |
    
6.  When you're finished making changes, click **Save**.
