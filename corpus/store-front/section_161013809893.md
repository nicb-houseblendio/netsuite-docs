In Site Management Tools (SMT), you can find and export content that needs translating from the Translations tab in Overview Mode. For details, see [Translations Tab User Interface](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159854780475.html). You can export all CMS Pages and CMS Content Types supported by SMT. The Translations tab lets you manage original translations, content updates, and see any content with pending translations. Each file is saved as an individual XLIFF file, compressed into a ZIP, and saved to the File Cabinet. For details, see [File Cabinet Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N541319.html). You can also choose to save the file locally.

Watch the following video for information about how to export translation content in bulk using SMT.

#### To export bulk content for translation from SMT:

1.  Log in to SMT. For details, see [Logging into Site Management Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4163262385.html).
    
2.  Select the Overview Mode icon ![Overview Mode Icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/StoreFront/WebsiteContent/OverviewModeIcon.png) from the site management toolbar.
    
3.  Select the **Translations** subtab.
    
4.  After you've reviewed the content, click **Export All**.
    
5.  When prompted, select the language you want to translate the default language into.
    
    Note:
    
    If there's a translation for any content, it's included in the export.
    
6.  If needed, check the **Include Unpublished** box to include unpublished content in the export.
    
7.  Click **Next** to export the content.
    
8.  Click **Close**.
    
9.  After the export finishes, a banner appears at the top of the page. From the banner you can:
    
    1.  Download the ZIP file from the File Cabinet (**Documents > Files > File Cabinet**), under **SuiteBundle > Bundle ID > ExportforTranslation**.
        
        Or
        
    2.  Save a local file by clicking the **Click here to save a local file** link.
        
    
    Note:
    
    The content in the Export for Translation folder is automatically replaced when you start a new export.
    
10.  After the ZIP file is downloaded, you can send it to a third party translator. When you've received the translated content, you can import it back into SMT. For details, see [Importing Bulk Translation Content into Site Management Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161013818898.html).
