After you've installed your Commerce application in your NetSuite account, you'll need to link it to a domain before you can see your site. First, link it to a development domain for testing. When you're happy with your web store, you can use the same steps to link it to a production domain.

Important:

These steps assume you've already set up one or more domains for your website. If you haven't yet acquired a domain and set it up for NetSuite, see [Domains](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N2478982.html). After your domain is ready, return to this topic to set up your web store.

To complete your application installation, you need to perform the following procedures:

-   [Link SSP Application to Your Domain](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1231025705.html) - Link the SSP application for your implementation to a previously set up domain.
    
-   [Deploy SSP Application to Your Domain](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1231024650.html) - Deploys the SuiteCommerce SuiteScript 2.0 (SS2) application for your implementation to your domain or site.
    

Note:

A development domain is the domain used by developers before your site goes live. In the early stages of site set up, the best practice is to link your application to this development domain to ensure everything is set up correctly. When you are ready to go live with your web store, follow this same procedure to link the application to your production domain.
