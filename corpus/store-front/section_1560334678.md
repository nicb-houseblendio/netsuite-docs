SuiteAnalytics Workbook is a powerful tool for creating and customizing workbooks with NetSuite data. For Personalized Catalog Views, the following standard workbooks are available:

-   **Items by Customer** - You can select specific customers and see which items they can see, and whether they can see prices or buy the items. This workbook displays which customer segments the selected customers are in, which item segments are mapped to those customer segments, which items are included in the item segments, and the website visibility level of the item segment to the customer segment. For more information about the components of this workbook, see [Items by Customer Workbook](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1561652138.html).
    
-   **Customers by Item** - You can select specific items and see which customers can see them and whether they can see prices or buy the items. This workbook shows you which item segments the selected items are in, which customer segments are mapped to those item segments, which customers are included in the customer segments, and the website visibility level of those items for those customers. For more information about the components of this workbook, see [Customers by Item Workbook](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1561652168.html).
    

Both workbooks update with the latest Personalized Catalog Views changes when you click any of the **Save** buttons on the Customer Segments Manager page. Note that you might need to clear the workbook cache to see the latest updates.

You can add other fields and filters to the standard workbooks or create your own. For more information, see [SuiteAnalytics Workbook Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1503949328.html).
