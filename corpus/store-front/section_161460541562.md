Subscription status labels provide a high-level overview of the status of subscriptions and related line items. Examples of values include Active, Suspending, Suspended, Canceling, Canceled, Closing, Closed, and others, as needed, to indicate the overall status of a subscription.

When a subscription add-on's status changes, its label changes too, but the main subscription's label doesn't change.

The Commerce web store displays status labels that might be different from the ones in the NetSuite SuiteBilling interface.

The following table shows the differences between the status labels in NetSuite and the ones your customers see in your Commerce web store.

**Subscriptions**

| **NetSuite Status** | **Commerce Web Store Status** | **Subscription Condition** | **Status Display Duration** |
| --- | --- | --- | --- |
| Active | Active | The subscription is active. | This status displays until a user action triggers a change in the subscription state. |
| Active | Suspending | The subscription is active but is pending suspension. | This status displays until the end of the current day. |
| Active | Canceling | The subscription is active but the subscription or add-on was canceled and the user can not reactivate. | This status displays until the end of the current day. |
| Suspended | Suspended | The subscription is canceled and the user can reactivate. | This status displays until a user action triggers a change in the subscription state. |
| Suspended | Canceled | The subscription or add-on was canceled and the user can not reactivate. | This status displays indefinitely. |
| Suspended | Closing subscription | A change order to close the subscription is in process. | This status displays until the end of the current day. |
| Suspended | Reactivating | An activate change order is in process. | This status displays until the end of the current day. |
| Terminated | Closed | The subscription is closed. | This status displays indefinitely. |
| Closed | Closed | The subscription is closed (used primarily for one-time add-ons). | This status displays indefinitely. |

The following table shows the differences between the Subscription Lines status labels in NetSuite and the ones your customers see in your Commerce web store.

**Subscription Lines**

| **NetSuite Status** | **Commerce Web Store Status** | **Subscription Line Condition** | **Status Display Duration** |
| --- | --- | --- | --- |
| Active | Pending activation | The add-on is purchased but has not been activated. | This status displays until the end of the current day. |
| Active | Active | The subscription line or add-on is active. | This status displays until a user action triggers a change in the subscription state. |
| Active | Suspending | The add-on is active with a pending suspend status. | This status displays until the end of the current day. |
| Active | Canceling | The subscription line or add-on is active with a pending suspend status and the user can not reactivate. | This status displays until the end of the current day. |
| Active | Changing quantity | The subscription line or add-on is active and the user is changing quantity. | This status displays until the end of the current day. |
| Suspended | Suspended | The subscription line or add-on is suspended. | This status displays until a user action triggers a change in the subscription state. |
| Suspended | Canceled | The subscription line or add-on was canceled and the user can not reactivate. | This status displays indefinitely. |
| Suspended | Closing | The subscription line or add-on is suspended with a pending closure status. | This status displays until the end of the current day. |
| Activate | Reactivating | The subscription line or add-on is suspended with a pending activate status. | This status displays until the end of the current day. |
| Terminated | Closed | The subscription line or add-on is closed. | This status displays indefinitely. |
| Closed | Closed | The subscription line or add-on is closed. This is normally used for one-time add-ons. | This status displays indefinitely. |
