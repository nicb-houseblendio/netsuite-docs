The SuiteCommerce Analytics Data page URL record lists each page visited by a shopper plus, if used, the search term the shopper entered to arrive at the page.

| Analytics Workbooks | Saved Search | Content |
| --- | --- | --- |
| Label | Type | Label | Type | Provides |
| --- | --- | --- | --- | --- |
| **Page** | Text Select | **Page URL: Page** | Text | Web store page visited by a shopper |
| **Search Term** | Text Select | **Page URL: Search Term** | Text Select | Web store page with the search term used by the shopper to go to the page |
