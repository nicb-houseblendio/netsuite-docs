When SuiteCommerce Gift Wrap & Message is activated, customers can add gift wrap to individual items on the product detail page. This is an example of the initial Gift Wrap & Message link:

![Initial Gift Wrap Link](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/StoreFront/Marketing/giftwrap_init.png)

When the customer clicks on the Add Gift Wrap link, the item section expands to include a Gift Wrap box and form fields to add a personal message to the recipient. This is an example of the Gift Wrap & Message item options section:

![Expanded Gift Wrap & Message Section](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/StoreFront/Marketing/giftwrap_message.png)

Note:

All item options and message texts for Gift Wrap & Message can be customized. For more information, see [Customize Gift Wrap](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1543917931.html).

This image is an example of customized Gift Wrap & Message item options:

![Customized Gift Wrap Item Options](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/StoreFront/Marketing/giftwrapitem_custom.png)
