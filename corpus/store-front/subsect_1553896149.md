Use the SuiteCommerce Configuration record to determine the Look Book section titles and display style.

#### To configure the Look Book:

1.  In NetSuite, go to Commerce > Websites > Configuration.
    
2.  Select the website and domain where the Look Book extension is activated and click **Configure**.
    
3.  Go to the **Extensions** tab.
    
4.  On the **Look Book** subtab, set the following fields:
    
    | Field | Description |
    | --- | --- |
    | PDP Section Title | Sets the title for the Look Book section appearing on the PDP. |
    | Look Subtitle | Determines the subtitle for the Look page. |
    | Look Details Title | Sets the title for the Details section of the Look page. |
    | Display Look Book Slide | If checked, your domain displays the Look Book title and description on the first slide of the Look Book slider. If cleared, your domain displays the Look Book title and description in the header above the slider. |
    
5.  Click **Save**.
    

After configuring the extension, you can create a Look Book. See [Create a Look Book](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1553896199.html).
