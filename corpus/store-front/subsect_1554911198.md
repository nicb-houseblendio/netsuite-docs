Field sets control the data that's visible to site templates. To use the Grid Order feature, you must add several fields to the site's **details** field sets. For more information about field sets, see [Define Field Sets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2659559.html).

#### To add Grid Order fields to the Web Site Setup Record:

1.  Go to _Commerce > Websites > Website List_.
    
2.  Click **Edit** next to the website to which you are adding Grid Order.
    
3.  Go to the **Field Sets** subtab.
    
4.  Add the **Grid Order Behavior**, **Show Stock Quantities**, and **Activate Stock Notifications** fields to the **details** field set. For each field, follow these steps:
    
    1.  Find the **Fields Included in Field Set** column of the **details** field set and click the **Set** button.
        
    2.  Select the fields from the **Field Name** list and click **Add.**
        
    3.  Click **Submit** in the Field Set window
        
    4.  Click **OK** in the Field Set row.
        
5.  After adding all of the fields to the field set, click **Save.**
