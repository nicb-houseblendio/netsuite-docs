To add text to an area on a page, you drag the text content from the side panel and drop it in the area where you want to place it. If there's already content in the area, you'll see a drop indicator that shows exactly where your new content will go. When you drop the content, the page automatically opens the text editor so you can add your text. The text editor is a WYSIWYG editor that lets you add formatted text and images to your site.

The following image shows the available formatting controls in the text editor.

#### To add text and image content:

1.  Log in to Site Management Tools. For details, see [Logging into Site Management Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4163262385.html).
    
2.  Go to the page where you want to add the content.
    
3.  Click the Edit Mode icon ![Edit Mode Icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/StoreFront/WebsiteContent/EditModeIcon.png) from the site management toolbar.
    
4.  Click the Add icon ![Add Icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/StoreFront/WebsiteContent/SiteMangementToolsAddIcon.png) from the site management toolbar.
    
5.  Drag the text content from the side panel to the area where you want to place it. You can drag the content to multiple areas of the page:
    
    -   If you drag onto an area marked **all pages**, your content shows on any page that contains that area.
        
    -   If you drag onto an area marked **page type**, your content shows on any page of that type.
        
    -   If you drag onto an area marked **this page**, your content shows only on that page.
        
6.  Position the content over the area and drop it. If the area already contains content, a horizontal line shows you where the new content will go.
    
7.  In the **Name** field, enter a name for the text content.
    
8.  Set the content visibility options. Choose from **Always Visible** or **Visible on Specific Dates**. For more information, see [View Site as of a Specific Date in Site Management Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1513783026.html).
    
9.  Enter your text in the text field and use the text editor toolbar to format it.
    
10.  To add an image, position your cursor in the text editor where you want the image to appear.
     
11.  Click the Image icon ![Image Icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/StoreFront/WebsiteContent/ImageManagerIcon.png) from the text editor toolbar to open the Image Manager.
     
12.  Select an existing image or upload a new image.
     
13.  Click **Insert**.
     
14.  Hover over the image in the text editor and click the gear icon.
     
15.  In the **Alt Text** field, enter the alternate text to display when the image doesn't load. Alternate text is also used by screen readers and helps to promote Search Process Optimization (SEO).
     
16.  Set the spacing for top, right, bottom, and center to control the space between the image and text.
     
17.  Set the image dimensions. If you enter either width or height, the aspect ratio stays the same automatically.
     
18.  Click **Save**.
     
19.  In the **Tags** field, enter one or more descriptive tags. For details, see [Content Tags and Filter Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1524601707.html).
     
20.  Click **Save**.
     
21.  Publish your changes. For details, see [Review and Publish Content in Site Management Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4419210472.html).
