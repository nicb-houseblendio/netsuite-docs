When a customer searches for an item on your website, how the item appears in the search results depends on the website visibility level of the item segment containing that item. The following principles apply:

-   If the item is set to be hidden from the customer, it won't appear in search results at all.
    
-   If the item price is set to be hidden from the customer and:
    
    -   no price filters are applied, the item appears in the search results but the price is not displayed.
        
    -   price filters are applied (for example, Price < $100), the item doesn't appear in the search results.
        
    -   price sorting is applied, the item appears at the bottom of the search results, regardless of whether the sort order is low to high or high to low. This makes it impossible to guess the price from it's position in the search results.
        
    
    Note:
    
    This behavior only applies to standard price fields. If pricing information for your website is stored in custom fields, prices are not hidden by the Disable Purchase and Hide Price website visibility level.
    

Important:

You need to run a full search index rebuild before the website visibility levels of item segments affect search results. For more information, see [Rebuild the Search Index Manually](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_1500035326.html).
