To start using Personalized Catalog Views (PCV), enable the feature first. PCV is an account-specific feature, which means that the personalized catalog settings are used for all Commerce web stores associated with the account. When PCV is enabled, SuiteCommerce InStore (SCIS) websites only display items visible to all users.

#### To enable personalized catalog views:

1.  Go to _Setup > Company > Enable Features_.
    
2.  Click the **Items & Inventory** subtab.
    
3.  Check the **Personalized Catalog Views** box.
    
4.  On the **Web Presence** subtab, check:
    
    -   **Commerce Categories** (only if using as item segments)
        
    -   **Site Management Tools** (for verifying PCV with Site Management Tools)
        
5.  On the **Analytics** subtab, check the **SuiteAnalytics Workbook** box (for verifying PCV with SuiteAnalytics Workbooks).
    
6.  Click **Save**.
    

The Customer Segments Manager is now available to users who have the appropriate permission.

Note:

By default, enabling PCV allows all users to see and buy all items. This means that there is no change to the website when you enable the feature. Website changes occur when you make specific item segments visible to customer segments. For more information, see [Managing which Customer Segments can Access Item Segments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1560331424.html).
