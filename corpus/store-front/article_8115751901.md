Employees use SuiteCommerce and NetSuite differently depending on their roles.

The following standard roles are available in your NetSuite account after you install a Commerce website application:

-   **Administrator** - The Administrator has **all** permissions available in your NetSuite account at **all** levels. For more information about the Administrator role, see [NetSuite Account Administration](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4570420905.html).
    
-   **Store Manager** - The Store Manager role manages non-administrative website content. See [Standard Roles Permissions Table](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N295396.html) for a list of the permissions and permission levels for the Store Manager role.
    

The following roles interact with your Commerce web store:

-   **Lead** - Leads are users who have created an account for your web store. After a lead makes a purchase, they are converted into a customer. For more information about the Lead role, see [Lead](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3186192.html).
    
-   **Customer** - Customers buy things in your web store. For more information about the Customer role, see [Customer](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3184698.html).
    

Note:

The Prospect role isn't meant for use in a Commerce web store. If someone with the Prospect role tries to create an account, they'll get an error.

See the following help topics for useful information about roles and permissions:

-   [NetSuite Users & Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N284861.html) - Describes how to manage NetSuite roles and permissions to provide your account users with the access they need.
    
-   [NetSuite Roles Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N285436.html) - Includes information about standard and custom roles, managing roles, permission differences, and the role search feature.
    
-   [Users and Roles in Site Management Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4144397279.html) - Details the roles that manage website content with Site Management Tools.
    

## Differences Between the Administrator and Store Manager Roles {#subsect_053112345056}

The Store Manager role is intended to manage your website's content but not the website itself.

The Store Manager can't create a new site and perform tasks such as technical and workflow settings changes. These tasks are performed by the Administrator. See [NetSuite Account Administration](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4570420905.html) for more information about key administrator tasks.
