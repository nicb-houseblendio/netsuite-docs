Enhance a page when you want to change specific attributes, such as the title or meta description for an existing page.

#### To enhance a page:

1.  Log in to Site Management Tools. For details, see [Logging into Site Management Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4163262385.html).
    
2.  Go to the page you want to enhance.
    
    For example, the URL for a facet listing of **sports helmets** is, **http://mysite.com/accessories/sportshelmets**. By going to that page and accessing the page settings menu, you can set the enhanced properties for the page.
    
3.  Click the Edit Mode icon ![Edit Mode Icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/StoreFront/WebsiteContent/EditModeIcon.png) from the site management toolbar.
    
4.  Select the ellipsis from the top-right corner of the site management toolbar and select **Edit Page Settings**.
    
5.  Select the **General** subtab.
    
6.  Fill out the fields using the following table for reference.
    
    | Field | Description |
    | --- | --- |
    | Heading | Enter a heading to display on the page. The heading displays only if the page template is configured to display it. |
    | Tags | Add additional information to help identify the page when using the sort and filter tools. For details, see [Content Tags and Filter Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1524601707.html). |
    
7.  Select the **Metadata** subtab.
    
8.  Fill out the fields using the following table for reference.
    
    | Field | Description |
    | --- | --- |
    | Title | Enter the title that you want to use to populate the HTML `title` element on the page. Providing a descriptive title that includes the target keywords and accurately describes the page can improve the page's ranking on search result pages. Additionally, search engines often display this title on search result pages and link it to the page. Follow SEO best practices when creating page titles. For details, see [SEO and Page Titles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4280885364.html). |
    | Meta Description | Enter the text to populate the `content` attribute of the `meta description` HTML element. The description entered here is an important SEO tool and is often displayed on search result pages as a description of the page. Setting a meaningful and accurate description that contains the target keywords can improve the ranking in search result pages. Use SEO best practices when writing descriptions. For details, see [SEO and Meta Descriptions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4285087960.html). |
    | Meta Keywords | Enter the text to populate the `content` attribute of the `meta keywords` HTML element. It is important to follow SEO best practices when defining meta keywords. Using them incorrectly can have a negative impact on the page's ranking on search result pages. |
    
9.  Select the **Layout** subtab.
    
10.  Choose the page layout that you want to apply. For details, see [Site Management Tools Page Layout Selector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1549386933.html).
     
11.  Select the **Advanced** subtab.
     
12.  If you have additional metadata to add to the `<head>` section of the page, enter the HTML code in the **Add to <head>** field.
     
13.  Click **Save**.
     
14.  Publish the changes. For details, see [Review and Publish Content in Site Management Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4419210472.html).
