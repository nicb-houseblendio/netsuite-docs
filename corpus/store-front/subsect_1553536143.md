Enable the Grid Order extension for a domain using the SuiteCommerce Configuration record. This makes Grid Order available for all matrix items. However, you must set up each item individually to use Grid Order.

#### To configure Grid Order:

1.  Go to Commerce > Websites > Configuration.
    
2.  Select the website and domain with the activated Grid Order extension, then click **Configure**.
    
3.  Go to the **Extensions** subtab.
    
4.  In the **Grid Order** subtab, fill out the fields for each category, referencing the tables below.
    
5.  Click **Save**.
    

**Grid Order Configuration Fields:**

| Field | Description |
| --- | --- |
| Activate for All Matrix Items | Enables Grid Order for all matrix items that have the **Grid Order Behavior** field on the Item Configuration record set to **Default Site Behavior.** For more information, see [Set Up Matrix Items for Grid Order](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1553536158.html). |
| Activate for Mobile | Enables Grid Order for mobile sites. |

**Grid Order Options Fields:**

| Field | Description |
| --- | --- |
| Order Grid Title | Sets the order grid title. |
| Quantity Pricing Label - Order Grid | Sets the label for the Quantity Pricing link. For more information about using Grid Order in conjunction with Quantity Pricing, see [Integration with Other SuiteCommerce Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1553536158.html#subsect_1553525499). |
| Quantity Summary Level - Order Grid | Sets the label for the Quantity Summary row, which gives the total number of items selected. |
| Subtotal Price Label - Order Grid | Sets the label for the Subtotal Price row, which gives the subtotal amount owed. |
| Combination Not Available - Order Grid | Sets the text to display when an item's unavailable. |
| Inventory Label - Order Grid | Sets the label for current inventory quantity. The `[[units]]` placeholder is automatically replaced with the available quantity. |
| Stock Notifications Label - Order Grid | Sets the label for the Stock Notifications link in the order grid. For more information about using Grid Order in conjunction with Stock Notifications, see [Integration with Other SuiteCommerce Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1553536158.html#subsect_1553525499). |
| Add to Cart Button Label - Order Grid | Sets the label for the **Add to Cart** button. The `[[items]]` placeholder is automatically replaced with the number of items to be added to the cart. |
| Quantity Warning Message - Order Grid | Sets the message to display for quantity errors. |
| Minimum Quantity Hint - Order Grid | Sets the message to display for a highlighted field when the required minimum quantity is not met. The `[[min]]` placeholder is automatically replaced with the minimum quantity for the item. |
| Maximum Quantity Hint - Order Grid | Sets the message to display for a highlighted field when the maximum quantity is exceeded. The `[[max]]` placeholder is automatically replaced with the maximum quantity for the item. |
| Confirmation Text | Sets the confirmation message after adding items to the cart. The `[[items]]` placeholder is automatically replaced with the number of items added. |
| View Cart Button Label | Sets the label for the **View Cart & Checkout** button that appears with the confirmation text. |
| Continue Shopping Button Label | Sets the label for the **Continue Shopping** button that appears with the confirmation text. |
| Grid Order Table Combinations | Determines how matrix item options appear in the order grid. Display two matrix item options by listing one as the **Order Grid Row** and the other as the **Order Grid Column**. If you list a matrix item options pair twice using both row/column alignments, the combination listed first takes precedence. Display items with one matrix item option by listing it in either the **Order Grid Row** or the **Order Grid Column**. |
| Item Color Palette Mapping | Determines the color palette for custom fields with color swatches. In the **Item Field ID** column, enter the custom field ID for the the item color field. In the **Palette ID** column, enter the ID for the color palette you want to use. If you haven't set up additional palettes, use **default** as the **Palette ID**. To view or create additional color palettes, see [Color Palettes Subtab](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4667037557.html). |
