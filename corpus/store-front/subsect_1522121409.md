After setting up your field sets, SuiteCommerce and SuiteCommerce Advanced customers should create a search index. This section explains how to set up a basic search index to get you started. For more detailed instructions, see [Search](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/preface_1518478010.html).

Your web store needs the search index to access data from your defined field sets.

#### To set up the search index:

1.  In NetSuite, go to _Commerce > Websites > Web Site List_.
    
2.  Click **Edit** next to the site you want to set up.
    
3.  On the **Search Index** tab, **Facet Fields** subtab, select at least one facet in the **Facet Field Name** field to enable in the frontend (for example, Online Price).
    
4.  Save the Web Site record.
    

When you've completed this rudimentary search index, see [Next Steps](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1520191430.html) for further instructions on setting up your web store.
