In Site Management Tools (SMT), you can edit a translation when you need to update website content.

#### To edit website content translations:

1.  Log in to SMT. For details, see [Logging into Site Management Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4163262385.html).
    
2.  Select the Overview Mode icon ![Overview Mode Icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/StoreFront/WebsiteContent/OverviewModeIcon.png) from the site management toolbar.
    
3.  Select the **Pages** subtab.
    
4.  Click the ellipsis next to the page you want to edit.
    
5.  Click **Preview**.
    
6.  Click **Edit Mode**.
    
7.  Hover over the content you want to edit and click the Edit icon ![Edit Icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/StoreFront/WebsiteContent/EditModeIcon.png).
    
8.  From the settings panel, select the language from the language dropdown list.
    
9.  Make any required changes.
    
10.  Click **Save**.
