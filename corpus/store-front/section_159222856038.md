A skin is a group of elements designed to compliment each other. Commerce themes include the following default skins:

-   Amazon-Esque
    
-   Aqua
    
-   Light Fresh
    
-   Dark Fresh
    
-   Dark Mode: Green
    
-   Deep Sea
    
-   Earth
    
-   Firehouse
    
-   Pastel
    
-   Young
    

You can preview and manage each skin associated with the active theme on your domain using the Theme Skin Manager. For more information, see [Theme Skin Manager](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1512491665.html).
