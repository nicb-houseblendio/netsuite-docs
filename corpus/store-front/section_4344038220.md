Enhancing pages lets you customize certain attributes of a page without needing to develop code or modify existing files. You can enhance an existing page, such as the Home page, Search page, or Item Detail page to customize the attributes of that page.

For example, you can enhance a Facet Search page listing of **sports helmets** to set the page title and meta description to better describe the page. These settings promotes SEO best practice and can improve the page ranking on search result pages. For details, see [SEO and Page Titles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4280885364.html) and [SEO and Meta Descriptions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4285087960.html).

Note:

[View Site as of a Specific Date in Site Management Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1513783026.html) aren't available for enhanced pages. Page enhancements take effect immediately when you save them.
