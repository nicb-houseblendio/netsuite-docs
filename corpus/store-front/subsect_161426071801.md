You can turn on the Reorder Items feature in the SuiteCommerce Configuration record.

#### To enable the Reorder Items feature:

1.  In NetSuite, go to Commerce > Websites > Configuration.
    
2.  Go to the **My Account** tab and the **Preferences** subtab.
    
3.  Check the **Allow User to Reorder Items** box.
    
4.  Click **Save**.
    

For more information about configurable properties, see [Allow User to Reorder Items](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161278879329.html#subsect_161279009186).
