NetSuite provides default search field settings to get you started. However, you should reconfigure the Search Fields based on the data in your item records.

You can use the following search fields setup as a starting point for your website:

| **Search Field** | **Item Record Field Name** | **Field ID** | **Search Type** |
| --- | --- | --- | --- |
| Name | ITEM NAME/NUMBER | itemid | Starts With Exact |
| Online Name | WEB STORE DISPLAY NAME | storedisplayname | Exact |
| Online Name | WEB STORE DISPLAY NAME | storedisplayname | Starts With |
| Online Name | WEB STORE DISPLAY NAME | storedisplayname | Keyword |
| Search Keywords | SEARCH KEYWORDS | searchkeywords | Keyword |
| Detailed Description | DETAILED DESCRIPTION | storedetaileddescription | Keyword |
