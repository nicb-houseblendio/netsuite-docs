Item images can improve your website's quality and encourage customers to make a purchase. Item images appear on the Product Details page, as thumbnails, and in search results.

Note:

This section covers item images, which follow a different procedure than other website images. For information about other image types, such as banners and logos, see [Site Management Tools Image Content Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4123521956.html).

Uploading item images involves renaming image files according to the file name format, then uploading them to the File Cabinet. From there, the images are associated with the item record that corresponds with the item identifier in the image file name.

Set up item images on your website by following these procedures:

1.  [Website Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162137343254.html)
    
    1.  [Set the Image Domain and Image Folder](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162137343254.html#subsect_162137364841)
        
    2.  [Define the File Name Format](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162137343254.html#subsect_162137351115)
        
    3.  [Add Item Image Field to Field Sets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162137343254.html#subsect_162137370529)
        
    4.  [(Optional) Configure Multi-Image Options](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162137343254.html#subsect_162137376332)
        
2.  [Rename Image Files with the Item Identifier](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162137381373.html)
