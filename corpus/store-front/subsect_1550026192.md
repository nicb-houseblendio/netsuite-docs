SMT lets you configure multiple properties for each Contact Form field to determine how the form looks to users on your site. For each messaging field appearing on the Contact Form of your site, you choose the label, placeholder, help text, whether the field is required, and whether the field is visible.

#### To configure contact form messaging fields:

1.  Log into Site Management Tools. For details, see [Logging into Site Management Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4163262385.html).
    
2.  Go to the page that contains the contact form.
    
3.  Click the Edit Mode icon ![Edit Mode Icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/StoreFront/WebsiteContent/EditModeIcon.png) from the site management toolbar.
    
4.  Hover over the content form box to display the content controls and click Edit.
    
    This displays the Contact Form Settings in the side panel.
    
5.  In the **Messaging Fields** subtab, set your preferences for each of the following **Contact Form** fields, using the table below as a reference:
    
    -   Subject
        
    -   Message
        
    
    | Field Type | Description |
    | --- | --- |
    | Label | This sets the label for the Contact Form field. |
    | Placeholder | This sets the placeholder text to display in the Contact Form field. |
    | Help Text | This sets the help text for the Contact Form field. |
    | Mandatory | This determines if the Contact Form field is required. |
    | Hide | This determines if the Contact Form field is hidden. |
    
6.  Click **Save.**
