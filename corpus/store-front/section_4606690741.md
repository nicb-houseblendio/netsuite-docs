Important:

To use Store Locator, set up location records in your NetSuite account. For details, see [Locations Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N263024.html). To set up location records for your stores, including address and business hours, see [Creating Locations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N263263.html).

The following topics provide helpful information about enabling and disabling the Store Locator feature:

-   [Verify that Store Locator is Enabled](#subsect_84120622748)
    
-   [Set Elevated Permissions for the Service File Record](#subsect_37121358670)
    
-   [Disable Store Locator](#subsect_18123102575)
    

## Verify that Store Locator is Enabled {#subsect_84120622748}

Store Locator is enabled by default in SuiteCommerce and SuiteCommerce Advanced. However, you can verify that the feature is enabled with the following processes.

#### To verify that Store Locator is enabled: {#procedure_1027120733}

1.  Go to Commerce > Websites > Configuration.
    
2.  Select your website and domain, then click **Configure**.
    
3.  Click the **Store Locator** tab and the **Store Locator** subtab.
    
4.  Verify that the **Is Enabled** box is checked. If it's not checked, select the box.
    
5.  Click **Save**.
    

#### To verify that Store Locator is enabled (SuiteCommerce Advanced pre-Vinson): {#procedure_1027121043}

1.  Open the distro.json file in the SCA source code's root directory using a code editor.
    
2.  Search for lines of code that include `StoreLocator`.
    
    For example:
    
                      `"suitecommerce/StoreLocatorReferenceMapImplementation": "X.X.X", "suitecommerce/Location.SCA": "X.X.X", "suitecommerce/StoreLocatorAccessPoints": "X.X.X", "suitecommerce/StoreLocator": "X.X.X", "suitecommerce/StoreLocatorGoogleMapsImplementation": "X.X.X",  "StoreLocatorAccessPoints", "StoreLocator"     "StoreLocator.Model"  "StoreLocator.ServiceController"` 
                    
    
3.  Verify that the lines of code are not disabled within comment tags.
    
4.  Search for the following line and confirm that it is not disabled within comment tags:
    
                      `Location.sca` 
                    
    
5.  Close the file.
    

## Set Elevated Permissions for the Service File Record {#subsect_37121358670}

To use Store Locator, set elevated permissions for the service file record in NetSuite. NetSuite creates a custom Advanced Customer Center role after you install SuiteCommerce or SuiteCommerce Advanced (SCA). Use this role for Store Locator setup.

#### To set elevated permissions for the service file record: {#procedure_1027121459}

1.  Go to Documents > Files > File Cabinet.
    
2.  Go to Web Site Hosting Files > Live Hosting Files > SSP Applications > \[Applicable Bundle Folder\] > Development > services.
    
3.  Select **Edit** next to the `StoreLocator.Service.ss` file.
    
4.  In the File record, check the **Available Without Login** box.
    
5.  Click the **Permission** subtab.
    
6.  Check the **Enabled** box.
    
7.  In the **Execute as Role** list, select the custom Advanced Customer Center role.
    
8.  Check the **Run Script Without Login** box.
    
9.  Click **Save**.
    

## Disable Store Locator {#subsect_18123102575}

You can disable the Store Locator feature in the SuiteCommerce Configuration record. When Store Locator is disabled, customers can't:

-   See store locations in a list or on an interactive map.
    
-   Find stores near their current location.
    
-   Search for stores by address, city, or postal code.
    
-   View location details, including address and hours, from the search results.
    
-   See a list of all stores.
    
-   Get directions to a store.
    

#### To disable Store Locator: {#procedure_1027123301}

1.  Go to Commerce > Websites > Configuration.
    
2.  Select your website and domain and click **Configure**.
    
3.  Click the **Store Locator** tab and the **Store Locator** subtab.
    
4.  Clear the **Is Enabled** box to disable Store Locator.
    
5.  Click **Save**.
    

#### To disable Store Locator (SuiteCommerce Advanced pre-Vinson): {#procedure_1027123635}

1.  Open the distro.json file in the SCA source code's root directory using a code editor.
    
    For more information about the distribution file and its location, see [The distro.json and ns.package.json Files](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4189587959.html).
    
    Note:
    
    In pre-Vinson SCA versions, Store Locator is enabled by default. To disable it, edit the `distro.json` file. You'll need developer experience to complete this task.
    
2.  Delete (or disable within comment tags) any lines of code that include `StoreLocator`.
    
    For example:
    
                      `"suitecommerce/StoreLocatorReferenceMapImplementation": "X.X.X", "suitecommerce/Location.SCA": "X.X.X", "suitecommerce/StoreLocatorAccessPoints": "X.X.X", "suitecommerce/StoreLocator": "X.X.X", "suitecommerce/StoreLocatorGoogleMapsImplementation": "X.X.X",  "StoreLocatorAccessPoints", "StoreLocator"     "StoreLocator.Model"  "StoreLocator.ServiceController"` 
                    
    
3.  Delete (or disable within comment tags) the following line:
    
                      `Location.sca` 
                    
    
4.  Save and redeploy the `distro.json` file. For more information, see [Deploy SCA Customizations to NetSuite](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4188899067.html).
