Although you can set up many features and fields using the Web Site Setup record, a few minimum settings are required before you can view your site on a domain. This topic explains the minimum settings you'll need to get your site up and running.

Later, you can view the [Comprehensive Web Site Setup Reference](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159499875581.html) topic for more detailed configuration options.

The minimum setup requirements depend on the type of site you're implementing:

-   [Minimum Website Setup for SuiteCommerce MyAccount](#section_159492696733)
    
-   [Minimum Website Setup for SuiteCommerce and SuiteCommerce Advanced](#section_159492694811)

## Minimum Website Setup for SuiteCommerce MyAccount {#section_159492696733}

This topic explains the minimum setup requirements to get your SuiteCommerce MyAccount site running. For more information about other settings and options available on the Web Site Setup record, see [Comprehensive Web Site Setup Reference](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159499875581.html).

#### To set minimum Web Site record fields for SCMA:

1.  In NetSuite, go to _Commerce > Websites > New_ to launch the **New Web Site** page.
    
    This page describes each type of website available for you to set up. Your implementation only lets you select from options provisioned for your account. For more detailed information about each product, see [SuiteCommerce Website Comparisons](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_157372061563.html#section_157372066938).
    
    You must have a license available to select a product. Contact your NetSuite administrator if you do not have a provisioned license for SuiteCommerce MyAccount.
    
2.  Click **Select** under **SuiteCommerce MyAccount**.
    
3.  In the **Display Name** field add a name that you want to display in the heading of your site.
    
    This name is exposed to your customers. Do not use the special character `'` as part of the display name.
    
4.  In the **Internal Name** field, add a name for your site as you want it to appear in your NetSuite account.
    
    This name isn't exposed to customers. Fill in this filed, even if the name is identical to your Display Name.
    
5.  On the **Setup** tab:
    
    1.  From the **Default Hosting Root** dropdown list (under Home Page), select the folder where you store HTML files for your web site. This should be **Website Hosting Files : Live Hosting Files**.
        

## Minimum Website Setup for SuiteCommerce and SuiteCommerce Advanced {#section_159492694811}

This topic explains the minimum setup requirements to get your SuiteCommerce or SuiteCommerce Advanced site running. For more information about other settings and options available on the Web Site Setup record, see [Comprehensive Web Site Setup Reference](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159499875581.html).

#### To set minimum Web Site record fields for SC and SCA:

1.  In NetSuite, go to _Commerce > Websites > New_ to launch the **New Web Site** page.
    
    This page describes each type of website available for you to set up. Your implementation only lets you select from options provisioned for your account. For more detailed information about each product, see [SuiteCommerce Website Comparisons](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_157372061563.html#section_157372066938).
    
    You must have a license available to select a product. Contact your NetSuite administrator if you do not have a provisioned license for SuiteCommerce or SuiteCommerce Advanced.
    
2.  Click **Select** associated with your site:
    
    -   SuiteCommerce
        
    -   SuiteCommerce Advanced
        
3.  In the **Display Name** field add a name that you want to display in the heading of your site.
    
    This name is exposed to your customers. Do not use the special character `'` as part of the display name.
    
4.  In the **Internal Name** field, add a name for your site as you want it to appear in your NetSuite account.
    
    This name isn't exposed to customers. Fill in this field, even if the name is identical to your Display Name.
    
5.  On the **Setup** tab:
    
    1.  From the **Default Hosting Root** dropdown list (in the Home Page section), select the folder where you store HTML files for your web site. This should be **Website Hosting Files : Live Hosting Files**.
        
6.  On the **Shopping** tab, **Currency** and **Languages** areas, enable at least one currency and one language to be online as the default.
    
7.  To use the shipping feature on your website, check **Shipping Information is Required**. See [Shipping Page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2567548.html#bridgehead_N2569158).
    
    This applies to SuiteCommerce and SuiteCommerce Advanced releases 2020.1.2 and later.
    
8.  Save the Web Site Setup record.
