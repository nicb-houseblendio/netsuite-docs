For further customization, you can use Site Management Tools (SMT) to:

-   Add content to the signup form - You can add an image, text, merchandising zone, and HTML content by using the corresponding content type in SMT. In addition, you can add a Custom Content Type (CCT) related to another extension. When logged into SMT, the Advanced Sign Up form allows you to select the content type you want to add and drag it onto the form.
    
    For more information about types of content, see [Site Management Tools Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4165123763.html).
    
-   Set color and font settings with the Theme Customizer - You can select font size, color, and family for the Header, Title, and Subtitle of the Advanced Sign Up form and the background color of the form using the Theme Customizer in SMT.
    
    For more information, see [Theme Skin Manager](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1512491665.html).
