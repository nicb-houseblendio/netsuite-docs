Multi-Language pages let you create landing pages and add your own translations in any language you've set up. The page name and all other attributes are stored in your company's default language. For landing pages, you can add translations for the following fields:

-   **Heading**
    
-   **Title**
    
-   **Meta Description**
    
-   **Meta Keywords**
    
-   **Add to <head>**
    

If a landing page doesn't have translations, the base language shows by default. For SEO metadata, this behavior isn't applied so there's no negative impact on SEO. You'll need to provide any SEO translation data for the landing page.

Note:

The visibility dates you select apply to the default language and any translations. There is no option to select individual visibility dates for a specific translation.
