You can manage product lists from the **Product Lists** subtab under the **SuiteCommerce Extension** tab in the customer record.

Important:

If required, you can edit list and item attributes. However, the product list records are intended for storing and showing data from the website, so you shouldn't edit them.

![Example of the SuiteCommerce Extensions > Product Lists Subtab on the Customer Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/StoreFront/MyAccount/SuiteCommerceExtensionsTabRedwood.png)

Note the following:

-   If you edit a predefined list in a customer record, it overrides the same list in the configuration file. How you edit predefined lists in the configuration file depends on which SuiteCommerce Advanced version you're using.
    
-   The scope attribute for a product list isn't supported in ShopFlow and My Account.
    
-   The Item Options field on the Product Lists Items displays the options the user selected. For, example, for gift certificates, the recipient's email address is stored in this field. You shouldn't edit the Item Options field.
