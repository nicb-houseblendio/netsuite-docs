Note:

The Summit Theme requires SuiteCommerce or the Aconcagua release of SuiteCommerce Advanced or later.

The Summit Theme is a custom theme that lets you showcase products for your industry supply web store. It's only available if provisioned, installed, and activated for a selected domain in your account. For more information, see [Installing Theme and Extension SuiteApps](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510953648.html).

You can configure the Summit Theme properties on your domain using the SuiteCommerce Configuration record. For more information, see [Configuring Themes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158680127593.html).

Important:

When activating the Summit Theme, you must also activate the Summit Theme extension that comes with the SuiteApp. For details, see [Activating Themes and Extensions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1549034518.html).

## Summit V4 Theme {#subsect_94144127408}

Summit V4 is an upgraded version of the Summit custom theme that still gives you a framework for your industry supply web store, and also taking advantage of the latest SC Base Theme releases. This means that Summit V4 can get future updates, fixes, enhancements, and new features from the SC Base Theme by reactivating Summit V4 in the Extension Manager.

To activate Summit V4:

1.  Go to Commerce > Extensions > Extension Manager and click **Edit** next to the website you want to update.
    
2.  In the **Themes** tab, check the box for **Summit V4**.
    
3.  Click **Activate**.
    

### Considerations When Activating Summit V4 {#subsect_84144117908}

When switching from the Summit theme to Summit V4, consider the following:

-   Activating Summit V4 doesn't replace or remove the standard Summit theme from your list of themes in the Extension manager.
    
-   If you've made customizations to the Summit theme and then switch to Summit V4, those changes won't carry over.
    
-   The Summit Theme Extension (found in the Extensions tab of the Extension Manager) can stay active without any changes.
    

## Customizing the Summit Theme {#subsect_0121024031}

You can use additional template areas with the Summit Theme using SMT or when modifying a page with an extension. For more information, see [SuiteCommerce Base Theme Templates and Areas](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_051602162197.html).
