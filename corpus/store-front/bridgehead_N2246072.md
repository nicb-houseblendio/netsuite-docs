You can sell gift certificates on your website that allow customers to purchase store credit they can send to someone as a gift.

Gift Certificates are set up as items in NetSuite. For more information about setting up Gift Certificates, see [Gift Certificates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2244991.html).

After setting up Gift Certificates, see the following topics for more information about working with Gift Certificates:

-   [Buy Gift Certificates in the Web Store](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1528121250.html)
    
-   [Apply Gift Certificates in the Web Store](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N2247867.html)
    
-   [Gift Certificate Management](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1527753117.html)
