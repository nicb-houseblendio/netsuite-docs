If you're a SuiteCommerce Advanced customer, you need to be on the 2019.1 release or later to use this feature.

Note:

You need to deploy SuiteScript 2.0 (SSP2) on the same site and domain as SuiteScript 1.0 (SSP1). Deploy the SSPv2 application to your Shopping and Checkout domain. In SuiteCommerce Advanced 2019.1, only one SSPv2 application is included. In SuiteCommerce Advanced 2019.2, there are two-use the DEV SSPv2 application for deployment. For details, see [Deploy and Undeploy SSP Applications](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1529598384.html).

SuiteCommerce supports the NetSuite SuiteTax feature for customers in the US and Canada. SuiteTax helps you meet local tax rules by letting you pick internal or third-party tax engines to calculate taxes. You can choose a different tax engine for each tax registration (nexus) on subsidiary records to stay compliant with each tax area. For more information, see [SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/preface_1496364245.html).

You can't use SuiteTax with the Multiple Ship To feature. See [Known Limitations of SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_161365561211.html) for more limitations and considerations.

After you've set up SuiteTax on your Commerce web store, users see the total tax for their order as soon as they add shipping details at checkout. The total tax updates when the user:

-   Adds or removes items
    
-   Changes the item quantity
    
-   Changes the shipping address
    
-   Changes the shipping method
    
-   Applies a promotion
    

| **SuiteCommerce Capabilities with SuiteTax Enabled** | **Business-to-Consumer (B2C)** | **Business-to-Business (B2B)** |
| --- | --- | --- |
| View a summary of the taxes grouped by tax type at checkout. | X | X |
| See every tax applied in the returned order summary (in My Account Returns). | X | X |
| See every tax applied in the order, summarized by type (in My Account History). | X | X |
| View the total taxes for previous orders (user must be logged in to their registered account). | X | X |
| See the total tax amount when creating a sales quote. | \- | X |
| View the total tax amount when paying an invoice. | \- | X |

#### Setting up SuiteTax for your Commerce Web Store {#procedure_1551814952}

1.  Add payment visuals for all payment methods your web store uses. See [Creating a Payment Method](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1292421.html).
    
    Important:
    
    To use SuiteTax, you need to add payment visuals for all payment methods.
    
2.  Enable the SuiteTax feature. See [Enabling the SuiteTax Feature](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1513063459.html).
    
    Important:
    
    After enabling SuiteTax, you can't switch back to the legacy tax engine.
    
3.  Go to Customization > Plug-ins > Manage Plug-ins and enable the SuiteTax Engine plug-in.
    
4.  Install these SuiteTax SuiteApps:
    
    -   SuiteTax Engine. See [Installing the SuiteTax Engine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557397007.html).
        
    -   Tax Reporting Framework. See [Installing Tax Reporting Framework](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1528245293.html).
        
5.  Set up the tax engine for your subsidiary tax registrations. See [Selecting a Tax Engine for Tax Registrations on Subsidiary Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1513835017.html).
    
6.  Set up accounting preferences for your Commerce web store. See [Set up Accounting Preferences for Web Stores](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4653397591.html).
    
7.  Make sure your SuiteTax setup is complete and check the migration status. See [Viewing the SuiteTax Data Migration Status](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1513582777.html).
