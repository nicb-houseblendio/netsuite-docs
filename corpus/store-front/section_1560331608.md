If an item is included in one or more item segments and at least one of the item segments is mapped to a customer segment, the item is visible to the customer segment. Such an item is called a mapped item.

An unmapped item, however, is one that is:

-   Not included in any item segment
    
-   Included in one or more item segments but none of the item segments are mapped to a customer segment
    

The Unmapped Items item segment is mapped by default to the All Users customer segment with Website Visibility Level set to Display Fully. Before you set up any mappings, all items are in the Unmapped Items segment, making them visible and purchasable by all users.

However, as you set up mappings between item segments and customer segments, consider whether the items left in Unmapped Items need to be visible, purchasable, or hidden from all users.

For instance, to show a subset of your inventory to VIP customers only, create an item collection called "VIP Items" and make it visible to the "VIP customers" customer segment.

What about the rest of your items that aren't mapped - what happens to them?

Let's say you've added many new items to your inventory but haven't assigned them to item segments yet. By default, these unmapped items are visible to all users, which may not be ideal.

In both these scenarios you'll need to set the Website Visibility Level of the Unmapped Items segment in the Customer Segments Manager.

#### To allow all users to buy unmapped items:

1.  Go to _Commerce > Marketing > Personalization > Customer Segments Manager_.
    
2.  Select **Display Fully** from the **Website Visibility Level** list next to the Unmapped Items item segment.
    

#### To prevent all users from buying unmapped items:

Note:

To allow all users to view but not buy unmapped items, ensure your website uses SuiteCommerce or SuiteCommerce Advanced 2020.2 or later. Don't use the following options if your site is using a SuiteCommerce Advanced release prior to 2020.2.

-   Disable Purchase
    
-   Disable Purchase and Hide Price
    

1.  Go to _Commerce > Marketing > Personalization > Customer Segments Manager_.
    
2.  Select one of the following from the **Website Visibility Level** list next to the Unmapped Items item segment:
    
    -   To allow users to see item prices but prevent them from buying the items, select Disable Purchase.
        
    -   To prevent users from seeing item prices and buying the items, select Disable Purchase and Hide Price.
        

#### To hide unmapped items from all users:

1.  Go to _Commerce > Marketing > Personalization > Customer Segments Manager_.
    
2.  Select **Hide Fully** from the **Website Visibility Level** list next to the Unmapped Items item segment.
    

Note:

An item can be included in multiple item segments. If any of these segments is mapped to a customer segment, the item is not included in the Unmapped Items segment.
