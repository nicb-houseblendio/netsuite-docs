Commerce web stores and SuiteCommerce InStore provide a comprehensive set of tools you can use to manage items on your site. Clear item descriptions, high-quality item images, and Commerce Categories (for sites with a large number of items) all contribute to the success of your website.

With Commerce web stores and SuiteCommerce InStore, you can:

-   Configure items
    
-   Group items in different ways
    
-   Add product images
    
-   Set up Commerce Categories
    
-   Create item collections
    
-   Set up personalized catalog views for different customer segments
    
-   Add features to product pages
    
-   Display item badges
    
-   Set up side-by-side product comparison
    
-   Enable the Infinite Scroll feature
    

Note:

The following item types are supported, but not visible in Commerce web stores:

-   [Discount Items](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2248474.html)
    
-   [Subtotal Items](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2248793.html)
    
-   [Markup Items](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2248975.html)
    
-   [Payment Items](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2249363.html)
    
-   [Other Charge Items](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2249208.html)
    

See the Supply Chain Management topic, [Item Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N2222944.html), for more information about tracking and managing item types.

The use of other item types in your Commerce web store will require customization. Be aware that these customizations can impact various areas of your web store and should only be made by someone with developer experience.

See the following topics for more information about web store items:

-   [Item Availability](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2656387.html) - Set up item records and inventory for your website and prepare items for search engine optimization (SEO). Set up personalized catalog views that provide different customers with access to different items.
    
-   [Item Grouping Methods](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1561721814.html) - Group items using the method that best suits your purpose. For example, sales, web store navigation, etc. Group items into general purpose collections that can be used to create personalized catalog views for different customer segments. Create a hierarchy with product categories, subcategories, and products to help users to find what they're looking for.
    
-   [Item Images](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_162137155579.html) - Add product images to your website to make your Product Details Pages and other site pages more effective.
    
-   [Item Page Options](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1551305045.html) - Enhance your web store's Product Details pages and Product Listings Pages. Do this by adding elements like Inventory Display, Product Lead Time, Stock Notifications, Item Badges, and more.
