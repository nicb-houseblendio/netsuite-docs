You can customize the look of the contact form by setting the layout and style fields in Site Management Tools (SMT).

#### To configure contact form layout and style:

1.  Log into Site Management Tools. For details, see [Logging into Site Management Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4163262385.html).
    
2.  Go to the page that contains the contact form.
    
3.  Click the Edit Mode icon ![Edit Mode Icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/StoreFront/WebsiteContent/EditModeIcon.png) from the site management toolbar.
    
4.  Hover over the content form box to display the content controls and click Edit.
    
    This displays the Contact Form Settings in the side panel.
    
5.  In the **Layout & Style** subtab, set the following fields:
    
    | Field | Description |
    | --- | --- |
    | Button Text | This sets the text to display on the submit button. If you leave this field blank, the button will not appear. |
    | Button Help Text | This sets the help text for the submit button. |
    | Button Style | This sets the button style. |
    | Hide Background Color | This determines if the background color is hidden. Background color and padding can be customized using the Theme Customizer in SMT. |
    | Position | This determines the field for this position. If the same field is selected for multiple positions, the ranking is ignored and default settings are applied. |
    
6.  Click **Save.**
