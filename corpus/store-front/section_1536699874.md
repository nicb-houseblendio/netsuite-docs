This table summarizes the different types of content types available and provides links to more detailed information.

| **Content Type** | **Description** |
| --- | --- |
| [Site Management Tools Text Content](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4123521463.html) | Use this content type to add formatted text. This content type works well for adding simple text such as headings or larger blocks of text with WYSIWYG formatting and embedded images. |
| [Columns](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1528293178.html) | Use the Columns content type to add columns of text with images. |
| [Blog](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1535962991.html) | Use the Blog Post and Blog List content types to add a post or a blog summary. |
| [Site Management Tools Image Content Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4123521956.html) | Use this content type to add a single image, such as a banner image. In addition to specifying the image, you can also specify a link for the image. |
| [Image Manager](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530202893.html) | Learn how to use the image manager to add images to text and image content. |
| [Photo Gallery](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1528293246.html) | Use the Photo Gallery content type to add an album of up to eight images. |
| [Slideshow](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1528293224.html) | Use this content type to add a carousel of images. |
| [Image Text Overlay](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1528293080.html) | Use this content type to add images with overlying text and action buttons. |
| [Merchandising Zone Content](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_159561426850.html) | Use this content type to add a merchandising zone linked to a merchandising rule. Choose between the legacy and enhanced merchandising zones. The functionality of the enhanced merchandising zone is similar to that of the legacy merchandising zone; however, it includes a configurable display, support for multiple languages, and compatibility with SuiteCommerce Themes. |
| [Site Management Tools HTML Content Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1537278615.html) | Use this content type to add HTML or JavaScript code to a page. This content type supports only code that should be placed within the `<body>` tags of the page. |
| [Map and Contact](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1533898131.html) | Use this content type to add a third-party map and contact information such as a business address and opening hours. |
| Cookie Modal Link. See [Add Required Footer Links to Cookie Policy and Settings](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_162748768444.html). | Use this content type to let customers open a cookie preferences dialog where customers can view or change their consent settings. This content type is installed with the SuiteCommerce Cookie Consent extension. |
| [Commerce Custom Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4837340253.html) | Learn how to add custom fields to your site by using the SuiteCommerce Custom Fields extension or by customizing a theme. |
