You can add a slideshow to your web store by dragging the Slideshow content type onto a page in Site Management Tools (SMT). You can add up to eight images.

#### To add a slideshow: {#procedure_1531320680}

1.  Log into Site Management Tools. For details, see [Logging into Site Management Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4163262385.html).
    
2.  Go to the page where you want to add a slideshow.
    
3.  Click the Edit mode icon ![Edit Mode Icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/StoreFront/WebsiteContent/EditModeIcon.png) from the site management toolbar.
    
4.  Click the Add icon ![Add Icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/StoreFront/WebsiteContent/SiteMangementToolsAddIcon.png) from the site management toolbar.
    
5.  Drag the **Slideshow** content type onto the page. You can add the content type to multiple areas of the page:
    
    -   If you drag onto an area marked **all pages**, your content shows on any page that contains that area.
        
    -   If you drag onto an area marked **page type**, your content shows on any page of that type.
        
    -   If you drag onto an area marked **this page**, your content shows only on that page.
        
    
    Note:
    
    If you don't see this content type, first check that the extension has been installed and is active. Then click the gear icon on the site management toolbar, select **Custom Content Types**, and drag the content type to the Active Content Type list.
    
6.  In the **General** tab, set the following fields:
    
    1.  In the **Name** field, enter a description of your new content.
        
    2.  Set when you want to display the content. Choose from **Always Visible** or **Visible on Specific Dates**. For details, see [View Site as of a Specific Date in Site Management Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1513783026.html).
        
    3.  If you don't want images to change automatically, clear the **Automatic Slideshow** box.
        
    4.  In **Transition Duration**, select how long each image displays before changing (in seconds).
        
    5.  In **Section Height**, determine the size of your slideshow.
        
        Note:
        
        On desktops, images resize to fit. On mobile, images are cropped to fit a small section height.
        
    6.  Add keywords in the **Tags** field to help filter your content. For more information, see [Content Tags and Filter Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1524601707.html).
        
7.  In the **Image** tab:
    
    1.  Select the image you want to display using the Image Manager. A preview displays on the page. For details, see [Image Manager](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530202893.html).
        
        Note:
        
        If you upload several images, use images with the same resolution for the best-looking slideshow.
        
    2.  In the **Image Alignment** field, select the position of the image in the content box. Choose from top, center, or bottom.
        
    3.  In the **Image Overlay** field, select the image opacity. Choose from dark, light, or no overlay.
        
    4.  In the **Alt Text** field, enter a description for accessibility and SEO.
        
    5.  In the **Text** field, enter the text you want to display in the slideshow. You can use simple HTML tags such as <strong> for bold text, <em> for italic, and <li> for bulleted lists. When entering your message, enclose any body text with <p> tags and use <h> tags to create headers.
        
    6.  In **Text Alignment**, select the position of the text and the button. Choose from left, right, or center aligned.
        
    7.  In the **Text Color** field, choose your text color. By default, this field uses the color scheme of your theme.
        
    8.  In the **Button Text** field, enter the text you want to display on the button. Leave this field blank if you don't want to display a button.
        
    9.  In the **Button Style** field, choose your button style. Button styles are taken from the theme.
        
    10.  In the **Button Link** field, enter the URL you want the button to open.
         
    11.  Select **Open in New Window** if you want the button's link to open in a new tab or window.
         
8.  Repeat Step 7 to include additional images. You can add up to eight images.
    
9.  Click **Save**.
