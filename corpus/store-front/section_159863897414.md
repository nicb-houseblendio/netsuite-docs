## Configuring the Top Promo {#subsect_159914406964}

**Applies only to the Bridge Theme.**

You can configure the top promo to highlight a promotion for your web store.

#### To configure the top promo:

1.  Go to Commerce > Websites > Configuration.
    
2.  Select the website and domain where the theme is activated and click **Configure**.
    
3.  Go to the **Bridge Theme** subtab.
    
4.  Go to the **Home** subtab.
    
5.  In the **Top Promo** field group, click a line in the list.
    
6.  Using the table below for reference, fill out the fields.
    
    | Field | Description | Applies To |
    | --- | --- | --- |
    | Text | Enter the text you want to show in the promo area. | Bridge Theme |
    | Background Image URL | Set the background image you want to use. All images should be uploaded to the NetSuite File Cabinet, and stored in an image folder you create under Website Hosting Files > Live Hosting Files. For details, see [File Cabinet Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N541319.html). If you use Cascading Style Sheets (CSS) to add images, they're overridden by the images in the File Cabinet. | Bridge Theme |
    | Background Color | Set the background color. The background color only appears if there is no background image. You can use HEX and HTML color values. | Bridge Theme |
    | Link Location | Enter the link to the internal page you want users to go to when they click the top promo. | Bridge Theme |
    
7.  Click **Add**.
    
8.  When you are finished making changes, click **Save**.
    

## Configuring Free-Text Images {#subsect_159914409462}

**Applies only to the Bridge Theme and Summit Theme.**

Free-text images are a collection of images that accompany the text entered in the **Free Text** field. For details, see [Configuring General Settings](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158871543692.html#subsect_158876748857).

#### To configure free-text images:

1.  Go to Commerce > Websites > Configuration.
    
2.  Select the website and domain where the theme is activated and click **Configure.**
    
3.  Go to the theme subtab.
    
4.  Go to the **Home** subtab.
    
5.  In the **Free Text Images** field group, click a line in the list.
    
6.  Using the table below for reference, fill out the fields.
    
    | Field | Description | Applies To |
    | --- | --- | --- |
    | Image | Enter the image to display. All images should be uploaded to the NetSuite File Cabinet, and stored in an image folder you create under Website Hosting Files > Live Hosting Files. For details, see [File Cabinet Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N541319.html). If you use Cascading Style Sheets (CSS) to add images, they're overridden by the images in the File Cabinet. | Bridge Theme |
    | URL | Enter the URL of the internal page you want users to go to when they click the image. This field is required if you select an image. | Bridge Theme |
    | Image URL | Set the image you want to use. All images should be uploaded to the NetSuite File Cabinet, and stored in an image folder you create, under Website Hosting Files > Live Hosting Files. For details, see [File Cabinet Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N541319.html). If you use Cascading Style Sheets (CSS) to add images, they're overridden by the images in the File Cabinet. | Summit Theme |
    | Link Location | Enter the URL of the internal page you want users to go to when they click the image. This field is required if you select an image. | Summit Theme |
    
7.  Click **Add**.
    
8.  For each free-text image you want to add, repeat steps 5 to 7.
    
9.  When you are finished making changes, click **Save**.
    

## Configuring the Hero Banner {#subsect_159914509175}

**Applies only to the Horizon Theme and Manor Theme.**

You can highlight unique information with the Hero Banner. You can choose the images, customize the text, and add multiple banners.

#### To configure the hero banner:

1.  Go to Commerce > Websites > Configuration.
    
2.  Select the website and domain where the theme is activated and click **Configure**.
    
3.  Go to the theme subtab.
    
4.  Go to the **Home** subtab.
    
5.  In the **Hero Banner** field group, select a line in the list.
    
6.  Using the table below for reference, fill out the fields.
    
    | Field | Description | Applies To |
    | --- | --- | --- |
    | Title | Enter the title to overlay on the image. | Horizon Theme |
    | Text | Enter the text to overlay on the image. | Horizon Theme |
    | Image URL | Enter the image to display in the hero banner. Images should be 1600 pixels wide to accommodate the largest screen width. All images should be uploaded to the NetSuite File Cabinet, and stored in an image folder you create under Website Hosting Files > Live Hosting Files. For details, see [File Cabinet Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N541319.html). If you use Cascading Style Sheets (CSS) to add images, they're overridden by the images in the File Cabinet. | Horizon Theme |
    | Link Text | Enter the text to display for the link. | Horizon Theme |
    | Link Location | Enter the URL of the internal page that you want users to go to when they click the link. | Horizon Theme |
    | HTML Content | Enter HTML code to display in the hero banner. | Manor Theme |
    | Background Image URL | Set the image to display. All images should be uploaded to the NetSuite File Cabinet, and stored in an image folder you create under Website Hosting Files > Live Hosting Files. For details, see [File Cabinet Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N541319.html). If you use Cascading Style Sheets (CSS) to add images, they're overridden by the images in the File Cabinet. | Manor Theme |
    | Button Text | Enter the text to display on the button. If this field is left blank, the button doesn't display. | Manor Theme |
    | Button URL | Enter the URL that you want users to go to when they click the button. | Manor Theme |
    
7.  Click **Add**.
    
8.  For each hero banner you want to add, repeat steps 5 to 7.
    
9.  When you are finished making changes, click **Save**.
    

## Configuring Facets {#subsect_159914514945}

**Applies only to the Horizon Theme.**

#### To configure facets:

1.  Go to Commerce > Websites > Configuration.
    
2.  Select the website and domain where the theme is activated and click **Configure**.
    
3.  Go to the **Horizon Theme** subtab.
    
4.  Go to the **Facets** subtab.
    
5.  From the **Display Facets Format** list, choose **Horizontally** or **Vertically**.
    
6.  Go to the **Shopping Catalog** subtab.
    
7.  Select **Facets**.
    
8.  Edit any row in the list that uses the facets\_faceted\_navigation\_item\_range.tpl template and clear the **Show Heading** box.
    
9.  Click **OK**.
    
    This ensures the desktop view is aligned and that there is no overlap when showing a header.
    
10.  Click **Save**.
     

For more information about facets, see [Select and Configure Facet Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2657346.html).

## Configuring Commerce Categories {#subsect_159914521400}

**Applies only to the Manor Theme and Horizon Theme.**

#### To configure commerce categories:

1.  Go to _Commerce > Content Management > Catalog & Categories > Commerce Categories_.
    
2.  Click **Edit** beside the commerce category you want to configure.
    
3.  From the **Thumbnail Image** drop down, select the image you want to use for the category.
    
4.  Click **Save**.
    
5.  For each category image you want to add, repeat Steps 2 to 4.
    
6.  Go to Commerce > Websites > Configuration.
    
7.  Select the website and domain where the theme is activated and click **Configure**.
    
8.  Go to the **Integrations** subtab.
    
9.  Select the **Categories** subtab.
    
10.  From the **Menu Fields** list, select **thumbnailurl**.
     
11.  Click **Save**.
     

For more information, see [Commerce Categories](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4673202005.html).

## Configuring the Promo Area {#subsect_159914529602}

**Applies only to the Posh Theme.**

You can configure the promo area to highlight a promotion for your web store.

#### To configure the promo area:

1.  Go to Commerce > Websites > Configuration.
    
2.  Select the website and domain where the theme is activated and click **Configure**.
    
3.  Go to the **Posh Theme** subtab.
    
4.  Go to the **Home** subtab.
    
5.  In the **Promo Area** field group, click a line in the list.
    
6.  Using the table below for reference, fill out the fields.
    
    | Field | Description | Applies To |
    | --- | --- | --- |
    | Title | Enter the title to show in the promo area. | Posh Theme |
    | Subtitle | Enter the subtitle to show in the promo area. | Posh Theme |
    | HTML Content | Enter HTML code in the promo area. | Posh Theme |
    | Image URL | Set the image to show in the promo area. All images should be uploaded to the NetSuite File Cabinet, and stored in an image folder you create under Website Hosting Files > Live Hosting Files. For details, see [File Cabinet Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N541319.html). If you use Cascading Style Sheets (CSS) to add images, they're overridden by the images in the File Cabinet. | Posh Theme |
    | Button Text | Enter the button text. If this field is left blank, the button doesn't display. | Posh Theme |
    | Button URL | Enter the URL that you want users to go to when they click the button. | Posh Theme |
    
7.  Click **Add**.
    
8.  When you are finished making changes, click **Save**.
