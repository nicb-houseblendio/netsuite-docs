SuiteCommerce lets you use the Payment Instruments feature for tokenized payment methods and additional payment gateways. For details, see [Tokenized Payment Instruments for Web Stores](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1549636748.html).

Requirements:

-   SuiteCommerce or SuiteCommerce Advanced version 2019.1 or later
    
-   A domain with an active theme built using the SuiteCommerce Base Theme 2019.1 or later. See [SuiteCommerce Base Theme](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1521905122.html#subsect_1520349643).
    
    Note:
    
    The 2019.1 and later versions of the SuiteCommerce Base Theme include the templates required to use tokenized payment instruments.
    
    Note:
    
    Tokenized payment instruments are not supported on SiteBuilder Extensions.
    

After the Payment Instruments feature is enabled:

-   Registered website users can manage their debit and credit card payment instruments. See [Payment Card Management for Commerce Web Stores](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1550867967.html).
    
-   Site administrators can add tokenized payment instruments as payment methods. See [Tokenized Payment Instruments for Web Stores](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1549636748.html).
