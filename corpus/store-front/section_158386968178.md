Note:

The Manor Theme requires SuiteCommerce or the Aconcagua release of SuiteCommerce Advanced or later.

The Manor Theme lets you create a product-focused furniture web store. It's only available if provisioned, installed, and activated for a selected domain in your account. For more information, see [Installing Theme and Extension SuiteApps](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510953648.html).

You can configure the Manor Theme properties on your domain using the SuiteCommerce Configuration record. For more information, see [Configuring Themes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158680127593.html).

Important:

When activating the Manor Theme, you must also activate the Manor Theme extension that comes with the SuiteApp. For details, see [Activating Themes and Extensions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1549034518.html).

## Manor V4 Theme {#subsect_44145217050}

Manor V4 is an upgraded version of the Manor custom theme that still gives you a framework for your interior design-focused web store, and also taking advantage of the latest SC Base Theme releases. This means that Manor V4 can get future updates, fixes, enhancements, and new features from the SC Base Theme by reactivating Manor V4 in the Extension Manager.

To activate Manor V4:

1.  Go to Commerce > Extensions > Extension Manager and click **Edit** next to the website you want to update.
    
2.  In the **Themes** tab, check the box for **Manor V4**.
    
3.  Click **Activate**.
    

### Considerations When Activating Manor V4 {#subsect_70145208851}

When switching from the Manor theme to Manor V4, consider the following:

-   Activating Manor V4 doesn't replace or remove the standard Manor theme from your list of themes in the Extension manager.
    
-   If you've made customizations to the Manor theme and then switch to Manor V4, those changes won't carry over.
    
-   The Manor Theme Extension (found in the Extensions tab of the Extension Manager) can stay active without any changes.
    

## Customizing the Manor Theme {#subsect_0121025141}

You can use additional template areas with the Manor Theme using SMT or when modifying a page with an extension. For more information, see [SuiteCommerce Base Theme Templates and Areas](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_051602162197.html).
