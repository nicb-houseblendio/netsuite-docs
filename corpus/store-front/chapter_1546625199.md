The Order Status extension lets you display billing and shipping information of a purchase order to customers on your website.

After you provide an order number and email address or Zip Code, both guests and registered customers can view the following:

-   Order fulfillment progress
    
-   Payment summary
    
-   Shipping details, including tracking numbers
    
-   Pickup in store details, including store location
    

Registered customers can log in and visit the My Account area to see their full purchase history without needing the Order Status extension

Important:

You can only use commerce extensions if you provision, install, and activate them for a selected domain in your account. For more information, see [Commerce Extensions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1530632028.html).

Note:

Extensions require SuiteCommerce or the Aconcagua release of SCA or later.

#### To configure properties for the Order Status feature:

1.  After you activate the Order Status extension in your NetSuite account, go to Commerce > Websites > Configuration.
    
    For more information about activating an extension, see [Manage Themes and Extensions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510954484.html).
    
2.  Select the website and domain where you're setting up the Order Status extension, then click **Configure**.
    
3.  Click the **Extensions** tab.
    
4.  In the **Order Status** subtab, fill out the fields for each category, using the tables below as a reference.
    
5.  Click **Save.**
    

Note:

The Order Status page must be accessed through the URL path, so you can choose how to link to it from your site. For example, you can use SMT Text Content to add a link to your home page. For more information, see [Site Management Tools Text Content](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4123521463.html).

**General Fields:**

| Field | Description |
| --- | --- |
| URL Path | This sets the URL path for your Order Status page. |
| Page Title | This sets the title text for the Order Status and Order Details pages on your website |

**Landing Page Fields:**

| Field | Description |
| --- | --- |
| Page Description - Landing Page | This sets the general information to display on the Order Status page. |
| Order Help Link - Landing Page | This sets the text to display for the **Order Help** link. This link opens a popup with information about finding an order number, but it only appears if you fill out this field. |
| Order Help Text - Landing | This sets the message to display when customers click the **Order Help** link. Explain how customers can find their order number in this message. |
| Order Number Label - Landing Page | This sets the label for the **Order Number** field. |
| Order Number Help - Landing Page | This sets the help text for the **Order Number** field. |
| Identification Info Label - Landing Page | This sets the label for the **Identification Info** field. Customers must enter the email address or ZIP code associated with their order. |
| Identification Info Help - Landing Page | This sets the help text for the **Identification Info** field. |
| Submit Button Label - Landing Page | This sets the **Submit** button text. |
| Submit Button Help - Landing Page | This sets the help text for the **Submit** button. |
| Login Section Text - Landing Page | This specifies the text to display in the Login section. Use this text to prompt customers to log in for their full order history. |
| Login Section Link - Landing Page | This sets the text to display for the **Login Section** link. This link takes customers to the **Order History** tab in My Account if they're logged in, or to the Login page if they're not. |
| Required Field Message - Landing Page | This specifies the message to be shown when a required field is missing. The placeholder `{{field}}` is automatically replaced with the field name. |
| No Order Found Message - Landing Page | This sets the message to display when an order isn't found |

**Order Status Fields:**

| Field | Description |
| --- | --- |
| Order Title - Order Status Page | This sets the title for your Order Status page. The placeholder `{{ordernumber}}` is automatically replaced with the order number. |
| Pending Approval - Order Status | This sets the status to display when the NetSuite order status is **Pending Approval**. For more information, see [Pending Approval State](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_163906094256.html). |
| Pending Fulfillment - Order Status | This sets the status to display when the NetSuite order status is **Pending Fulfillment**. With Advanced Shipping feature is enabled, this status means the order is approved and waiting for shipment. If the Advanced Shipping feature is disabled, this status means that the order is waiting for an invoice or cash sale to be created, including partially billed shipping orders. Fore more information, see [Advanced Billing and Advanced Shipping](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1256787.html). |
| Partially Fulfilled - Order Status | This sets the status to display when the NetSuite order status is **Partially Fulfilled**. If the Advanced Shipping feature is enable, this status means that the order is partially shipped, regardless its billing status. If the Advanced Shipping feature is disabled, this status means that the order is partially shipped. |
| Pending Billing - Order Status | This sets the status to display when the NetSuite order status is **Pending Billing**. The **Pending Billing** status applies when the Advanced Shipping feature is enabled. This status means the order is waiting for an invoice or cash sale to be created, including partially billed sales orders. |
| Fulfilled - Order Status | This sets the status to display when the NetSuite order status is **Fulfilled**. When the Advanced Shipping feature is disabled, the **Fulfilled** status applies. This status means the order is fully shipped and billed. |
| Billed - Order Status | This sets the status to display when the NetSuite order status is **Billed**. When the Advanced Shipping feature is enabled, the **Fulfilled** status applies. This status means the order is fully shipped and an invoice has been created. |
| Canceled - Order Status | This sets the status to display when the NetSuite order status is **Canceled**. Canceled is a permanent status and can't be undone. If you need the sales order again, you'll need to copy or recreate it. |
| Closed - Order Status | This sets the status to display when the NetSuite order status is **Closed**. This status means the order is closed and won't be fulfilled or billed. |
| Date Ordered Label - Order Status | This sets the text to display the order date. The placeholder `{{orderdate}}` is automatically replaced by the order date. |

**Shipping Status Fields:**

| Field | Description |
| --- | --- |
| Without Fulfillment - Shipping Status Label | This sets the status to display when the NetSuite shipping status is **Without Fulfillment**. |
| Picked - Shipping Status Label | This sets the status to display when the NetSuite shipping status is **Picked**. |
| Packed - Shipping Status Label | This sets the status to display when the NetSuite shipping status is **Packed**. |
| Shipped - Shipping Status Label | This sets the status to display when the NetSuite shipping status is **Shipped**. |
| Ships To Different Address - Shipping Status Label | This sets the item shipping status label to display when multiple items on the same order are shipped to different addresses. |
| Track Package - Shipping Status Label | This sets the label for the tracking number link. |

**Pickup Status Fields:**

| Field | Description |
| --- | --- |
| Without Fulfillment - Pickup Status Label | This sets the status to display when the NetSuite pickup in store status is **Without Fulfillment**. |
| Picked - Pickup Status Label | This sets the status to display when the NetSuite pickup in store status is **Picked**. |
| Picked Up - Pickup Status Label | This sets the status to display when the NetSuite pickup in store status is **Picked Up**. |

**Additional Fields:**

| Field | Description |
| --- | --- |
| View Details Label | This sets the label for the link to the popup window outlining Shipping or Pickup in Store details. |
| New Search Button | This sets the label for the New Search button. This button resets the customer's current search to allow for a new one. |

After you've configured the Order Status extension, guests and registered customers can view their order status on your website.
