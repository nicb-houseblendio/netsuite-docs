To set up SuiteCommerce Gift Wrap & Message in your web store, you need to perform the following steps:

1.  [Add Gift Wrap Fields to the Website Setup](#subsect_1537882551)
    
2.  [Create Gift Wrap Items](#subsect_1537534443)
    
3.  [Assign Gift Wrap Options to Web Store Items](#subsect_1537534464)
    

## Add Gift Wrap Fields to the Website Setup {#subsect_1537882551}

To check whether an item can be gift wrapped and the gift wrap options applicable, you need to add the gift wrap fields to the `detail` field set for your website. You also need to add the gift wrap item to the facet fields to hide the gift wrap items from your web store search.

When you add the gift wrap fields to your Website Setup record, they are displayed on all domains. For information about how to hide gift wrap fields in other domains associated with your website, see [Disable Gift Wrap](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1543918039.html).

#### To add the gift wrap fields to the setup: {#procedure_1537882968}

1.  Go to _Commerce > Websites > Website List_.
    
2.  Click **Edit** beside the website to which you want to add gift wrap fields.
    
3.  Go to the **Field Sets** tab.
    
4.  In the **Fields Included in the Field Set** field for the `details` Field Set ID, add the following fields:
    
    -   Gift Wrap Options - `custitem_ns_sc_ext_gw_options`
        
    -   Can Be Gift Wrapped - `custitem_ns_sc_ext_gw_iswrappable`
        
5.  Click **Add**.
    
6.  Go to the **Search Index** tab, to **Facet Fields** subtab.
    
7.  Select Gift Wrap Item in the **Facet Field Name** dropdown field and click **Add**.
    
8.  Save the Website Setup record.
    

## Create Gift Wrap Items {#subsect_1537534443}

Gift wrap items represent the different gift wrap options you make available to users in your web store. You can create gift wrap items as inventory or non-inventory items.

If you want to offer different options (like colors, sizes, or patterns) for a gift wrap category, you create a matrix item. For example, if you want to offer gift wrap boxes in various colors, you create the box as the parent matrix item and create the various colors as child matrix items. You should create a new matrix item per wrap variation. For example, one matrix item for standard wrapping & colors and a second matrix item for premium wrapping. For more information, see [Matrix Items](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2227654.html).

#### To create a gift wrap item:

1.  Go to _Lists > Accounting > Items > New_.
    
2.  Click the **Item Type**. For the gift wrap item, use either **Inventory** or **Non-Inventory Item** types.
    
3.  In the **Web Store** tab, select the **Display in Web Store** box.
    
4.  Set up the gift wrap as an item for the web store.
    
    Enter information in the following fields:
    
    -   **Item Name**
        
    -   **Item Price**
        
    -   **Web Store Display Name**
        
        If you don't enter a value in this field, the item's display name is taken.
        
    -   **Display Name**
        
    
    Add up to 30 characters as a description for the gift wrap in the **Web Store Description** field. This is displayed beside the gift wrap option in the web store.
    
    For information about setting up items for your web store, see [Item Record Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1489003607.html).
    
5.  Attach images to display in the web store for the gift wrap item.
    
    For example, if you offer different gift wrap patterns, you can display a sample of the wrap. See [Item Images](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_162137155579.html).
    
6.  Go to the **SuiteCommerce Extensions** tab, to the **Gift Wrap** subtab.
    
7.  Check the **Gift Wrap Item** box.
    
8.  Click **Save**. If you create a Matrix Item, click **Create Matrix**.
    

## Assign Gift Wrap Options to Web Store Items {#subsect_1537534464}

Gift wrap options are determined at item level. You assign all gift wrap options that can be used for the item in the Item record.

You can edit each item individually or update the gift wrap options using a mass update script. For information about how to update options using mass update, see [SuiteScript 2.1 Mass Update Script Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4460452911.html).

#### To select the gift wrap options for an item:

1.  Go to _Lists > Accounting > Items_.
    
2.  Click **Edit** next to the item for which you want to add gift wrap options.
    
3.  Go to the **SuiteCommerce Extensions** tab, to the **Gift Wrap** subtab.
    
4.  Check the **Can be gift wrapped** box.
    
5.  In the **Gift Wrap Options** box, select all gift wrap options that can be used for the item.
    
6.  Click **Save**. If the item is a matrix item, click **Update Matrix**.
