Any user who creates item collections needs a valid NetSuite user account and a role with the right permissions. These roles give you those permissions by default:

-   Administrator
    
-   Store Manager
    
-   Marketing Manager
    
-   Sales Manager
    
-   Marketing Administrator
    

You can also add the Item Collection permission to a custom NetSuite role so users can manage item collections. For more information about NetSuite users and roles, see [NetSuite Users & Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N284861.html). You can't edit a standard NetSuite role, but you can use it as a starting point for a new custom role. For detailed instructions and best practice for customizing a NetSuite role, see [NetSuite Roles Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N285436.html).
