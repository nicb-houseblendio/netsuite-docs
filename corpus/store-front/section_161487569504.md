To use the Multi-Language feature, you'll need to set a few preferences and enable the feature in NetSuite. After it's set up, you can manage translations in Site Management Tools for your commerce categories, pages, and content. To learn more about enabling and setting up the Multi-Language feature, check out these topics:

-   [Multi-Language Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159846959365.html)
