The Intelligent Item Recommendations workbook enables you to view and analyze data collected by the Intelligent Item Recommendations extension, for example:

-   the number of times shoppers viewed or interacted with a recommendation
    
-   how many transactions can be traced back to these interactions
    
-   the value of transactions that can be traced back to recommendations
    

## Intelligent Item Recommendations Workbook {#subsect_161418188679}

SuiteAnalytics Workbook is a powerful analytical tool that enables you to create and view highly customizable workbooks using NetSuite data. It offers many workbook and dataset templates, each with predefined source data, criteria, pivot tables, and charts. For more information about SuiteAnalytics Workbook, see [SuiteAnalytics Workbook Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1503949328.html).
