Themes and extensions are self-contained packages of files that extend your site in some way. You can install themes and extensions as bundled SuiteApps or as custom-built code deployed to your account by in-house site designers and developers. After installation, you use the Extension Manager in NetSuite to activate them for a domain associated with you NetSuite account.

-   **Themes** - A Theme is a special type of extension that only affects a domain's layout. Each theme presents a different style (colors, fonts, spacing, etc.) and layout for any domain linked to your Commerce website. When you activate a theme, you're changing what visitors see when they visit your site.
    
-   **Extensions** - An extension introduces added functionality to your website. Extensions let you add all kinds of features or functions to domains associated with your website. This could be a blog, a shipping bar, or a set of social media icons, to name a few examples. When you activate an extension, NetSuite adds the new features to your website, so you don't need any programming or site development experience.
    

Read the following topics to set up themes and extensions:

-   [Installing Theme and Extension SuiteApps](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510953648.html) - Before you can activate a published theme or extension, you must install the theme or extension into your NetSuite account as a bundled SuiteApp. This section shows you how.
    
-   [Manage Themes and Extensions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510954484.html) - This topic explains how to select themes and extensions and activate them on your Commerce website.
    
-   [Commerce Extensions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1530632028.html)\- This topic provides information about how to activate extensions on your site.
    
    Note:
    
    You must implement SuiteCommerce, SuiteCommerce MyAccount, or the Aconcagua release of SuiteCommerce Advanced and later to use Commerce Extensions.
