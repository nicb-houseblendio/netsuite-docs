Note:

The Threads Theme requires SuiteCommerce or the Aconcagua release of SuiteCommerce Advanced or later.

The Threads Theme is a custom theme that lets you create an apparel web store. It's only available if provisioned, installed, and activated for a selected domain in your account. For more information, see [Installing Theme and Extension SuiteApps](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510953648.html).

You can configure the Threads Theme properties on your domain using the SuiteCommerce Configuration record. For more information, see [Configuring Themes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158680127593.html).

Important:

When activating the Threads Theme, you must also activate the Threads Theme extension that comes with the SuiteApp. For details, see [Activating Themes and Extensions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1549034518.html).

## Threads V4 Theme {#subsect_39155211283}

Threads V4 is an upgraded version of the Threads custom theme that still gives you a framework for your interior design-focused web store, and also taking advantage of the latest SC Base Theme releases. This means that Threads V4 can receive future updates, fixes, enhancements, and new features from the SC Base Theme by reactivating Threads V4 in the Extension Manager.

To activate Threads V4:

1.  Go to Commerce > Extensions > Extension Manager and click **Edit** next to the website you want to update.
    
2.  In the **Themes** tab, check the box for **Threads V4**.
    
3.  Click **Activate**.
    

### Considerations When Activating Threads V4 {#subsect_83155711911}

When switching from the Threads theme to Threads V4, consider the following:

-   Activating Threads V4 doesn't replace or remove the standard Threads theme from your list of themes in the Extension manager.
    
-   If you've made customizations to the Threads theme and then switch to Threads V4, those changes won't carry over.
    
-   The Threads Theme Extension (found in the Extensions tab of the Extension Manager) can stay active without any changes.
    

## Customizing the Threads Theme {#subsect_0407035220}

You can use additional template areas with the Threads Theme using SMT or when modifying a page with an extension. For more information, see [SuiteCommerce Base Theme Templates and Areas](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_051602162197.html).
