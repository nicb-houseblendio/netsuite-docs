The **Extension Manager** lets you manage themes and extensions for each domain linked to your Commerce website. The Extension Manager lets you:

-   Activate or deactivate available themes and extensions for a domain
    
-   Implement available updates to active themes and extensions
    
-   View the currently active themes and extensions by domain
    
-   View the status of any activations currently being processed
    

Important:

If your site is using SuiteCommerce, SuiteCommerce MyAccount, or SuiteCommerce Advanced (Aconcagua release or later), you must activate a theme using the Extension Manager.

Note:

Themes and extensions must either be installed as published SuiteApps or deployed to your NetSuite account by a site developer to be available for activation. Themes and extensions are also created with versioning in mind. So, the Extension Manager only lists themes and extensions that work with your Commerce implementation and release.

## Before You Begin {#subsect_1548959861}

Be aware of the following information before using the Extension Manager:

-   To use the Extension Manager, you need SuiteCommerce, SuiteCommerce MyAccount, or SuiteCommerce Advanced (Aconcagua release or later).
    
-   The Extension Manager lets you set up multiple activations simultaneously. NetSuite processes them one at a time, but the Extension Manager creates a Pending queue and provides the status of each activation.
    
-   SuiteCommerce MyAccount only supports the SC Base Theme and certain SC Extensions. You can activate the SC Base Theme for a domain. You can also activate custom and third-party themes that are compatible with SCMA.
    
-   If you're using the 2019.1 release of the SuiteCommerce Extension Management bundle or later, you must be logged into NetSuite as an Administrator role. Otherwise, admins can set up Script Deployments to permit other roles to activate themes and extensions. See [Setting Up Script Deployments for Themes and Extensions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1561500233.html) for details.
    
-   Sass development files are not included with SuiteCommerce Advanced source code in any releases later than Aconcagua.
    
-   Themes and extensions must either be installed from published SuiteApps or deployed to your NetSuite account by a site developer to be available for activation.
    
-   You can activate any number of extensions or none at all.
    
-   You must activate a theme for each domain. You can only activate one theme per domain at a time, but you can activate the same theme on multiple domains.
    
-   If you're activating any of the following themes on your SuiteCommerce or SuiteCommerce Advanced site, you must also activate the companion theme extension that comes with the SuiteApp.
    
    Note:
    
    These themes are not compatible with SuiteCommerce MyAccount.
    
    -   Bridge Theme
        
    -   Horizon Theme
        
    -   Manor Theme
        
    -   Posh Theme
        
    -   Summit Theme
        
    -   Threads Theme
        
    
    For details, see [Available Commerce Themes and Supported Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158695491035.html).
    

Important:

Don't edit NetSuite records associated with the Extension Manager or activations directly. This includes editing the priority value of records to define the processing order. This capability will be replaced in a future release. Until then, don't manually edit these records. Doing so can compromise the processing integrity of the Extension Manager.

#### To use the Extension Manager:

1.  Confirm that your script deployments are set up properly. See [Setting Up Script Deployments for Themes and Extensions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1561500233.html) for details.
    
2.  In NetSuite, go to Commerce > Extensions > Extension Manager.
    
    If you do not see this option, make sure you have installed the SuiteCommerce Extensions Management bundle. See [Install Your Commerce Website Applications](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2675216.html) for information and the Bundle ID.
    
3.  Perform one of the following:
    
    1.  Click **Create Activation** to start a new activation.
        
    2.  Click **Edit** next to any preexisting activation to add, remove, or update themes and extensions for the associated domain.
        
4.  Choose from the following topics, as applicable:

If you are using the 2019.1 release of the SuiteCommerce Extension Management bundle or later, you must read this section. |
    | [Extension Manager Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1548960962.html) | This topic describes the Extension Manager interface. |
    | [Creating a New Activation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1549026512.html) | This topic explains how to create a new activation for a specific site and domain. Do this if you have never activated a theme or extension for the intended domain. |

## Optimizing Extension Code with SCEM Enable Code Optimization {#subsect_0616114035}

With version 2026.1.0 of the SuiteCommerce Extension Management bundle and later, the **SCEM Enable Code Optimization** field lets you optimize your extension's JavaScript code for improved performance and code protection.

To enable or disable code optimization, go to **Setup > Company > General Preferences > Custom Preferences**. **SCEM Enable Code Optimization** is enabled by default. Clear the checkbox to disable code optimization.

When this feature is enabled, JavaScript code is automatically optimized each time you activate an extension. This process includes extension JavaScript files and shared files such as **ssp\_libraries\_ext.js**, which is used across all domains within an SSP application.

Code optimization includes minification and obfuscation. Minification reduces file size by removing unnecessary characters, helping browsers download and process JavaScript more efficiently. Obfuscation makes code more difficult to read and reuse, providing an additional layer of protection for your extension code.
