When you're setting up your Commerce website, you can choose how shipping works and which shipping methods shoppers can use.

On the **Shopping** subtab of the Website Setup page, you can:

-   Require shoppers to enter shipping information before checking out.
    
-   Require shoppers to enter shipping address before billing address.
    
-   Select a default shipping method for a website.
    
-   Enable shipping to all countries or limit to specific countries.
    
-   Choose a default country to show in the **Country** field during checkout.
    

For more information, read the following topics:

-   [Setting a Preferred Shipping Method for Your Site](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2462284.html)
    
-   [Shipping Estimator](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1489430469.html)
    
-   [Restricting Ship To Countries in Your Commerce Web Store](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2462655.html)
    

For the complete listing of website shipping preferences, read [Shipping Page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2567548.html#bridgehead_N2569158).

Before you can select a default shipping method for your site, you'll need to register your shipping accounts, set your preferences, and create shipping items in NetSuite. For more information, read the following topics:

-   [Registering a FedEx Account](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1267302.html#bridgehead_N1267326), [Registering a UPS Account](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1274266.html#bridgehead_N1274274), [Registering a UPS Account (UK)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1274638.html), [Register a USPS Account with NetSuite](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1283332.html)
    
-   [Getting Started with Australia Post Integration](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4274392219.html)
    
-   [Setting Shipping Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1257579.html#bridgehead_N1257598)
    
-   [Creating Shipping Items](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1259213.html)
    

The default shipping method you pick, along with the customer's previous choices, decides which carrier and shipping options shoppers see at checkout. In Checkout, the Shipping Method page displays a list of shipping items that are appropriate for the shipping address. If you select a Default Website Shipping Method, then a shipping method is preselected in Checkout based on the customer and your settings.

Important:

If you use multiple locations, to calculate shipping correctly, the **Location** field must be displayed on the sales order form you use for your website. For more information about displaying fields on transaction forms, see [Configuring Fields or Screens](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2856992.html).

With the SuiteCommerce Shipping Bar extension, you can tell shoppers about free or special shipping rates with messages that update to show how much more they need to spend to qualify. To learn more about setting up the shipping bar on your site, see [Shipping Bar](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1533646274.html).

Note:

To set up shipping methods for use outside Commerce websites, see the Order Management topic, [Setting Up Shipping](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1257579.html).
