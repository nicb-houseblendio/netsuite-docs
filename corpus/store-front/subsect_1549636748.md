Tokenized payment instruments increase payment security by substituting sensitive payment card data with a payment card token that doesn't include sensitive data.

After you set up tokenized payment instruments for your website, NetSuite creates a token the first time a customer uses their payment card to complete a transaction. SuiteCommerce uses the token for all future transactions using that payment card.

Important:

Enabling the NetSuite Payment Instruments feature changes your payment record structure and can't be undone. Tokens created before enabling the feature are inaccessible and can't be used. Contact your NetSuite account manager to determine if you are eligible for this feature.

After the Payment Instruments feature is enabled in your NetSuite account, you can set up tokenized payment instruments.

See [Tokenization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1534257114.html) for additional information about tokenization.

#### Setting up tokenized payment instruments for SuiteCommerce {#procedure_1549634385}

1.  Set up accounting preferences to allow credit card payments on your website. See [Set up Accounting Preferences for Web Stores](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4653397591.html).
    
2.  Enable the Payment Instruments record. See [Payment Instruments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1538492538.html).
    
    Note:
    
    The Payment Instrument feature checkbox is available on the Enable Features page when your NetSuite account manager adds this feature to your NetSuite account.
    
3.  Create one or more payment methods for tokenized payment cards. See [Creating a Payment Method](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1292421.html).
    
    -   From the **Type** list, select **Payment Card Token**.
        
    -   Check the **Display in Website** box.
        
    -   Go to the **Payment Visuals** subtab to choose which images are used on your website's checkout page for this payment method.
        
4.  Set up an alternative payment method processing profile for tokenized payments. See [Setting Up an Alternative Payment Method Processing Profile](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4213266422.html#bridgehead_4214053110).
    
5.  Assign the new payment processing profile to your website. See [Assign Payment Processing Profiles to Your Website](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4653405996.html).
    
6.  Go to _Commerce > Websites > Website List_.
    
7.  Click **Edit** next to the website for which you want to set up tokenized payment instruments.
    
8.  Go to the **Shopping** subtab and the **Shopping Basics** tabs area.
    
9.  Check the **Require Authorization for Credit Card Transactions** box.
    
10.  Click **Save**.
     

Your customers now get extra security from tokenized card transactions when they use debit or credit cards in checkout.
