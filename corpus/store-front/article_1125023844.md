This article explains how to manage image compression at the website level. These settings only apply to images loaded from your website. You can also set up compression at the folder level. For details, see [Setting Up Folder Image Compression](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1125023921.html).

#### To set up website image compression:

1.  From NetSuite, go to _Commerce > Websites > Website List_.
    
2.  Click **Edit** next to the website you want to modify.
    
3.  Select the **Images** subtab.
    
4.  Check the **Compress All Website Images** box to turn on compression for all images on the website that meet the compression criteria.
    
5.  Select the compression level from the **Compressed Image Quality** field.
    
6.  (Optional) Check the **Strip Metadata** box to remove metadata, such as camera details or the date and time a photo was taken.
    
7.  (Optional) Check the **Chroma Subsampling** box to reduce color information in favor of luminance data, which is easier for the human eye to detect. This yields a smaller file size, but a similar visual appearance.
    
8.  Click **Save**.
