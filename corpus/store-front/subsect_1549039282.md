The **Themes** tab shows all themes currently available for activation. Use this tab to select a theme to activate.

Important:

SuiteCommerce MyAccount only supports the SC Base Theme. You can also activate custom and third-party themes that are compatible with SCMA.

#### To activate a theme:

1.  On the Activate Themes and Extensions page, select the **Themes** tab.
    
2.  Check the **Active** box next to the theme you want to activate.
    
    You can only activate one theme per domain at a time. You can deactivate any theme by clearing the **Active** box. However, you must activate at least one theme to proceed with the activation.
    
    ![Activate Themes and Extensions Page Themes Subtab](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/StoreFront/ThemesExtensions/ActivationManagerThemeActivation.png)
3.  Do one of the following:
    
    -   If you want to select one or more extensions to activate with your theme, click the **Extensions** tab. See [Activating Extensions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1549039302.html) to proceed.
        
        Important:
        
        If you're activating any of the following themes, you must also activate the companion theme extension that comes with the SuiteApp.
        
        -   [Bridge Theme](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158386941791.html)
            
        -   [Horizon Theme](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158386965797.html)
            
        -   [Manor Theme](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158386968178.html)
            
        -   [Posh Theme](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158386970218.html)
            
        -   [Summit Theme](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158386972535.html)
            
        -   [Threads Theme](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158386974998.html)
            
        
        For details, see [Available Commerce Themes and Supported Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158695491035.html).
        
    -   If you're ready to process your activations, click **Activate**.
        
    -   To cancel the activation, click **Cancel**.
        
4.  If this is the first activation for a domain, clear the domain's cache by triggering a cache invalidation request. See [Cache Invalidation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4169406426.html) for details.
