Important:

To use Store Pickup on your Commerce website, provision the Advanced Order Management module on your NetSuite account and enable specific features. See [Prerequisites for Store Pickup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4815858346.html) for more information.

To use Store Pickup on your Commerce website, complete the following:

-   [Define Store Pickup Field Sets](#subsect_162971602539)
    
-   [Enable Store Pickup for Commerce Websites](#subsect_162971630040)
    

## Define Store Pickup Field Sets {#subsect_162971602539}

You need to expose specific field sets to your Commerce website for the Store Pickup feature to function properly. For details, see [Set Up Initial Field Sets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3716578295.html).

Important:

Store pickup fields are specific to the Store Pickup feature and are added to field sets that are already established. Don't replace established field sets with the store pickup fields. For more information, see [Define Field Sets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2659559.html).

#### To confirm store pickup fields are exposed:

1.  Go to _Commerce > Websites > Website List_.
    
2.  Select **Edit** next to your website.
    
3.  Click the **Field Sets** subtab.
    
4.  Confirm store pickup fields are in place as defined in the following table.
    
5.  Add any missing store pickup fields to each field set as defined in the following table.
    
6.  Click **Save**.
    

| Field | Field Set ID | Fields to be Added to Field Set |
| --- | --- | --- |
| Details | details | 
-   isfulfillable: Can be Fulfilled/Received
-   isstorepickupallowed: Store Pickup Allowed
-   quantityavailableforstorepickup\_detail: Available For Store Pickup (Detail)

 |
| Matrix Child Items | matrixchilditems | 

-   isfulfillable: Can be Fulfilled/Received
-   isstorepickupallowed: Store Pickup Allowed
-   quantityavailableforstorepickup\_detail: Available For Store Pickup (Detail)

 |
| Matrix Child Items Search | matrixchilditems\_search | 

-   isfulfillable: Can be Fulfilled/Received
-   isstorepickupallowed: Store Pickup Allowed
-   quantityavailableforstorepickup\_detail: Available For Store Pickup (Detail)

 |
| Order | order | 

-   isfulfillable: Can be Fulfilled/Received
-   isstorepickupallowed: Store Pickup Allowed
-   quantityavailableforstorepickup\_detail: Available For Store Pickup (Detail)

 |
| Search | search | 

-   isfulfillable: Can be Fulfilled/Received
-   isstorepickupallowed: Store Pickup Allowed

 |

## Enable Store Pickup for Commerce Websites {#subsect_162971630040}

After you complete the steps to set up Store Pickup as part of Order Management documented in [Complete Order Management Tasks for Store Pickup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4815858346.html#subsect_162971420170), you must enable Store Pickup for your Commerce website.

#### To enable Store Pickup:

1.  Go to Commerce > Websites > Configuration.
    
2.  Select your website and domain and click **Configure**.
    
3.  Click the **Checkout** tab.
    
4.  Check **Enable Pickup In Store**.
    
5.  Enter the internal ID in the **Pickup In Store Sales Order Custom Form ID** field.
    
    See [Customizing the Sales Order Form for Store Pickup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4817105427.html) for detailed instructions on creating a sales order form for Store Pickup and obtaining the internal ID.
    
6.  Click **Save**.
    

## Disable Store Pickup for Commerce Websites {#subsect_162971651436}

To disable Store Pickup on your Commerce website, complete the following:

-   [Remove Store Pickup Field Sets](#subsect_162971657605)

### Remove Store Pickup Field Sets {#subsect_162971657605}

Important:

Store pickup fields are specific to the Store Pickup feature and are removed from field sets that are already established. Do not remove established fields when you remove the store pickup fields. See [Define Field Sets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2659559.html) for detailed information.

#### To remove store pickup fields:

1.  Go to _Commerce > Websites > Website List_.
    
2.  Select **Edit** next to the website you want to modify.
    
3.  Click the **Field Sets** subtab.
    
4.  Remove fields from each field set as defined in the following table.
    
5.  Click **Save**.

### Disable Store Pickup in SuiteCommerce or SuiteCommerce Advanced {#subsect_162971665601}

You can configure SuiteCommerce or SuiteCommerce Advanced to disable the Store Pickup feature.

#### To disable the Store Pickup feature:

1.  Go to Commerce > Websites > Configuration.
    
2.  Select your website and domain and click **Configure**.
    
3.  Click the **Checkout** subtab.
    
4.  Clear the **Enable Pickup In Store** box.
    
5.  Click **Save**.
