When you add HTML content to an area, the HTML settings are displayed in the side panel. The HTML settings give you two different views for adding and editing your HTML content. These are the basic view and the editor view. You can toggle between the two views by clicking the expand/collapse icon, denoted by two opposing arrows, in the upper right corner of the editor. The basic view gives you a simple text area for entering your HTML code. The editor view gives you an expanded side panel and an HTML editor with syntax highlighting.

#### To add HTML content:

1.  Log in to Site Management Tools. For details, see [Logging into Site Management Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4163262385.html).
    
2.  Go to the page where you want to add HTML content.
    
3.  Click the Edit Mode icon ![Edit Mode Icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/StoreFront/WebsiteContent/EditModeIcon.png) from the site management toolbar.
    
4.  Click the Add icon ![Add Icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/StoreFront/WebsiteContent/SiteMangementToolsAddIcon.png) on the site management toolbar.
    
5.  Drag the HTML content from the side panel to the area where you want to place it. You can drag the content to multiple areas of the page:
    
    -   If you drag onto an area marked **all pages**, your content shows on any page that contains that area.
        
    -   If you drag onto an area marked **page type**, your content shows on any page of that type.
        
    -   If you drag onto an area marked **this page**, your content shows only on that page.
        
6.  Position the content over the area and drop it. The HTML Settings open in the side panel.
    
7.  In the **Name** field, enter a name for the HTML content.
    
8.  Set the content visibility options. See [View Site as of a Specific Date in Site Management Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1513783026.html).
    
9.  Enter your HTML code or JavaScript in the HTML code field in the side panel or click the expand icon to expand the editor and enter your code. The HTML content on the page updates in real time as you enter code.
    
10.  In the **Tags** field, enter one or more descriptive tags. For details, see [Content Tags and Filter Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1524601707.html).
     
11.  Click **Save**.
     
12.  Publish your changes. For details, see [Review and Publish Content in Site Management Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4419210472.html).
