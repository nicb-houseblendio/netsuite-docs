Note:

Themes require SuiteCommerce or the Aconcagua release of SuiteCommerce Advanced or later.

Important:

Commerce themes are only available if provisioned, installed, and activated for a selected domain in your account. For details, see [Installing Theme and Extension SuiteApps](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510953648.html).

Important:

To configure a theme, you must also have the companion theme extension activated. For details, see [Available Commerce Themes and Supported Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158695491035.html) and [Activating Themes and Extensions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1549034518.html).

This section gives an overview of the properties you can configure for a Commerce theme's footer. For more information about how to configure the footer, explore these topics:

-   [Configuring General Footer Settings](#subsect_158869482172)
    
-   [Configuring Multi-Column Links](#subsect_158869489892)

## Configuring General Footer Settings {#subsect_158869482172}

This section explains how to configure the general settings that appear in a Commerce theme's footer. Most of these settings apply to all six themes, unless otherwise noted.

#### To configure general footer settings:

1.  Go to Commerce > Websites > Configuration.
    
2.  Select the website and domain where the theme is activated and click **Configure**.
    
3.  Go to the theme name subtab.
    
4.  Go to the **Footer** subtab.
    
5.  Use the following table to fill out the fields.
    
    | Field | Description | Applies To |
    | --- | --- | --- |
    | Show Legacy Newsletter | Clear this box to hide the legacy newsletter sign up in the footer. If you don't check this box, you can use the Newsletter Sign Up Extension in the footer or somewhere else on your website. For more information, see [Newsletter Sign Up](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1535640492.html). | All themes |
    | Hide | Check this box if you want to hide the copyright message in the footer. | All themes |
    | Company Name | Enter the company name to display in the footer. | All themes |
    | Initial Year | Enter the copyright dates to display in the footer. If left blank, the current year and company name are displayed. | All themes |
    | Newsletter Text | Enter the text that you want to display to encourage users to sign up to your newsletter. This text appears below the social media links. | Manor Theme |
    | Copyright Text | Enter the copyright text to display in the footer. | 
    -   Manor Theme
    -   Posh Theme
    
     |
    | Upper Section Title | Enter the title to display in the upper section of the footer. | 
    
    -   Bridge Theme
    -   Threads Theme
    
     |
    | Upper Section Icon | Enter the icon name. This icon displays in the upper section along with the title and text. Only the icons available through Font Awesome version 4.7.0 are supported. | Bridge Theme |
    | Upper Section Background URL | Set the background image. The image width should match the page's max width, and the height should match the footer's height. All images should be uploaded to the NetSuite File Cabinet, and stored in an image folder you create under Website Hosting Files > Live Hosting Files. For details, see [File Cabinet Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N541319.html). If you use Cascading Style Sheets (CSS) to add images, they're overridden by the images in the File Cabinet. | 
    
    -   Bridge Theme
    -   Horizon Theme
    
     |
    | Upper Section Text Area 1 | Enter the text to display in area 1 of the upper section. | Bridge Theme |
    | Upper Section Text Area 2 | Enter the text to display in area 2 of the upper section. | Bridge Theme |
    | Lower Section Text Area | Enter the text to display in the lower-right side of the footer. | Horizon Theme |
    | Social Media Links Title | Enter a title to introduce your social media links. For example, Follow Us On. | 
    
    -   Bridge Theme
    -   Summit Theme
    -   Threads Theme
    
     |
    | Social Media Title | Enter the title to display above the social media icons. | 
    
    -   Horizon Theme
    -   Manor Theme
    
     |
    
6.  When you're finished making changes, click **Save**.
    

## Configuring Multi-Column Links {#subsect_158869489892}

You can configure multi-columns to organize your content into four columns in the Commerce theme's footer. The settings that you can configure are the same across all themes. The default columns are Here to Help, Shopping with Us, About Us, and Legal, but you can change these.

#### To configure multi-column links:

1.  Go to Commerce > Websites > Configuration.
    
2.  Select the website and domain where the theme is activated and click **Configure**.
    
3.  Go to the theme name subtab.
    
4.  Go to the **Footer** subtab.
    
5.  In the **Multi-Column Links** field group, fill out the fields using the following table.
    
    | Field | Description |
    | --- | --- |
    | Text | Enter the text that you want to display for the link. |
    | URL | Enter the URL that you want users to go to when they click the link. |
    | Data-Touchpoint | Select a data-touchpoint. For example, shopping, my account or checkout. For more information about touch points, see [Link a Website or Domain to an SSP Application](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2495714.html). |
    | Data-Hashtag | Select a data-hashtag. This value must match what is entered in the **URL** field and start with a hashtag. |
    | Data-Target | Select a data-target. |
    | Column | Select the column where you want the link to appear: Column 1, Column 2, Column 3, or Column 4. |
    
6.  When you're finished making changes, click **Save**.
    

## Configuring Social Media Links {#subsect_158869496073}

Social media links let you choose which social media icons you want to include in the Commerce theme's footer. The social media links settings are the same across all themes.

Note:

By default, each Commerce theme includes the following social media icons: Facebook, Twitter, Instagram, and Pinterest.

#### To configure social media links:

1.  Go to Commerce > Websites > Configuration.
    
2.  Select the website and domain where the theme is activated and click **Configure**.
    
3.  Go to the theme name subtab.
    
4.  Go to the **Footer** subtab.
    
5.  In the **Social Media Links** field group, fill out the fields using the following table.
    
    | Field | Description |
    | --- | --- |
    | Icon Name | Enter the name of the icon. |
    | Text | Enter the text to display with the social media links. |
    | URL | Enter the URL address you want to open when a user clicks the icon. |
    | Data-Touchpoint | Select a data-touchpoint. For more information about touch points, see [Link a Website or Domain to an SSP Application](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2495714.html). |
    | Data-Hashtag | Select a data-hashtag. This value must match what is entered in the **URL** field and include a hashtag at the beginning. |
    | Data-Target | Select a data-target. |
    
6.  When you are finished making changes, click **Save**.
