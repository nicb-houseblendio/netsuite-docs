After you create your Look Book, you can add Looks to the Look Book record.

Looks allow you to present a variety of subcategories within a unified Look Book. Each Look appears as a slide of the Look Book slider. When someone clicks a Look slide, it opens your Look page with the relevant Look Items.. After creating a Look record in NetSuite, you can add the associated Look Items.

#### To add Looks to a Look Book:

1.  In NetSuite, go to Lists > Web Site > Look Book.
    
2.  Click **Edit** next to the Look Book to which you want to add Looks.
    
3.  In the **Custom** tab, click **New Look**, or click **Edit** to modify an existing Look.
    
4.  In the Look record, set the following fields:
    
    | Field | Description |
    | --- | --- |
    | Name | Sets the name for the Look. |
    | Inactive | If checked, the Look is inactive and does not appear on your site. |
    | Sequence Number | Determines the position of the Look in the Look Book slider. Looks appear in ascending order. |
    | URL | Determines the URL path for the Look page. This URL is appended to the Look Book URL (determined by the **URL** field of the Look Book record). The final URL for the Look page should end in `/lookbook/my_lookbook/[URL]`, where `[URL]` equals the value of this field. |
    | Look Book | Associates the Look with a Look Book. |
    | Short Description | Sets the short description for the Look. This displays above the **Long Description**. |
    | Long Description | Sets the long description for the Look. This displays below the **Short Description**. |
    | Text Color | Determines the color of the text on the Look page. This field supports text, HEX, or RGB. |
    | Right Align Text | This property is reserved for use in a future release. |
    | Link Text | Sets the label for the link that appears on the Look slide of the Look Book. The link points to the Look page. |
    | Carousel Image | Sets the image for the Look slide. |
    | Main Look Image | Sets the main image for the Look page. |
    | Alternative Look Image | Sets an additional image to appear on the Look page. If a **Main Look Image** and **Alternative Look Image** are both added, then a slider with both pictures appears on the Look page. |
    | Title Tag | Determines the title tag used for third-party indexing. |
    | Meta Description | Determines the meta description used for third-party indexing. |
    | Meta Keywords | Determines the meta keywords used for third-party indexing. |
    
5.  Click **Save**.
    
    After saving, a **Custom** tab is created on the Look record, where you can add Look Items.
    

For more information about adding Look Items to a Look, see [Add Look Items to a Look](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1553896243.html).
