The Customers by Item workbook enables you to select specific items and see which customers can see them, see their prices, and buy them. The workbook shows you:

-   which item segments the selected items are in
    
-   which customer segments are mapped to those item segments
    
-   which customers are included in the customer segments
    
-   the website visibility level of those items for those customers
    

#### To view which customers can see and buy specific items:

1.  Go to _Commerce > Marketing > Personalization > Customer Segments Manager_.
    
2.  Click **Save & View Report** and select the Customers by Item workbook.
    
    You can also access the workbook directly, by going to the Workbook Listing page and clicking the **Customers by Item** link in the Standard Workbooks list. For more information, see [Accessing and Sharing Workbooks and Datasets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1531766899.html).
    
    Note:
    
    If you can't see the **Save & View Report** button, you don't have the correct permissions to access workbooks. For more information, see [Personalized Catalog Views Roles and Permissions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1560331283.html).
    
3.  In the Customers by Item pivot table, click the Field Menu icon ![field menu icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/StoreFront/Products/FieldMenuIcon18_1.png) next to Item and click on Filter Item.
    
4.  In the left pane of the filter window, select the items you're interested in and click **\>** to move them to the right pane.
    
5.  Click **Apply**.
    
6.  Click the Field Menu icon ![field menu icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/StoreFront/Products/FieldMenuIcon18_1.png) next to Website Visibility Level and click **Filter Website Visibility Level**.
    
    To see the customers who:
    
    -   can buy the selected item, select **Display Fully** in the left pane of the filter window
        
    -   can view but not buy the selected item, select **Disable Purchase** in the left pane of the filter window
        
    -   can view the selected item, but not see the item price or buy the item, select **Disable Purchase and Hide Price** in the left pane of the filter window
        
    -   cannot view the selected item on the web store, select **Hide Fully** in the left pane of the filter window
        
7.  Click **\>** to move the selected Website Visibility Level to the right pane.
    
8.  Click **Apply**.
    
    The pivot table refreshes to show which customers can see and buy each selected item.
