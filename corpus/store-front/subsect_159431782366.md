To add a column to your web store, add the Column content type to a page with Site Management Tools (SMT). You can add up to three columns.

#### To add a column:

1.  Log into Site Management Tools. For details, see [Logging into Site Management Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4163262385.html).
    
2.  Go to the page where you want to add the column.
    
3.  Click the Edit Mode icon ![Edit Mode Icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/StoreFront/WebsiteContent/EditModeIcon.png) from the site management toolbar.
    
4.  Click the Add icon ![Add Icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/StoreFront/WebsiteContent/SiteMangementToolsAddIcon.png) from the site management toolbar.
    
5.  Drag the column content type from the side panel to the area where you want to place it. You can drag the column content type to multiple areas of the page:
    
    -   If you drag onto an area marked **all pages**, your content shows on any page that contains that area.
        
    -   If you drag onto an area marked **page type**, your content shows on any page of that type.
        
    -   If you drag onto an area marked **this page**, your content shows only on that page.
        
    
    Note:
    
    If you don't see this content type, first check that the extension has been installed and is active. Then, click the gear icon on the site management toolbar and select **Custom Content Types**. Drag the content type from the Inactive Content Types list to the Active Content Type list.
    
6.  From the Column Settings in the side panel, select the **General** subtab and set the following fields:
    
    | Field | Description |
    | --- | --- |
    | Name | Sets the name for the column to appear in the Review Changes list in SMT. |
    | Visibility | Sets the visibility option that determines when you want to make the column visible. For more information, see [View Site as of a Specific Date in Site Management Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1513783026.html). |
    | Header | Sets the title for the column. |
    | Text Color | Determines the color for the text fields. By default, the **Header**, **Caption**, and **Text** fields use different colors that are inherited from your theme. If you select **Dark**, all text fields use the dark text color defined in your theme. If you select **Light**, all text fields use the light text color defined in your theme. |
    | Column Alignment | Determines the positioning of the text content and button. |
    | Open in New Window | If checked, opens a link from the column in a new tab or window. |
    | Image Size ID | Links to the image resizing option you want the image to use. To use this option, you must enter an enabled **Image Size ID** found under the **Images** tab in the **Image Resizing** section of the Website Setup record. To access the Website Setup record, go to Commerce > Websites > Website Lists, and click **Edit** next to your site name. For more information, see [Image Resizing and Compression](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162137401329.html). |
    | Tags | Sets keywords to help filter your content in the Review Changes list. For more information, see [Content Tags and Filter Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1524601707.html). |
    
7.  Select the **Column** subtab and set the following fields:
    
    | Field | Description |
    | --- | --- |
    | Image | Sets the image to display using the Image Manager. For more information, see [Image Manager](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530202893.html). If you don't select an image, only the text column is displayed. For best results, optimize images before uploading. |
    | Alt Text | Sets a description of the image to be used to improve accessibility and SEO. |
    | Caption | Sets the column subtitle. |
    | Text | Determines the text to display in the column. Basic HTML formatting tags are supported. |
    | Button Text | Sets the button text. If you leave this field blank, the button doesn't appear. |
    | Button Link | Sets the URL for the button link. |
    
    Note:
    
    Each column has its own Column tab with its own settings. If you fill out only one Column tab, only one column appears.
    
8.  Click **Save.**
