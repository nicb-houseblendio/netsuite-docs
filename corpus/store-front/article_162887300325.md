The SuiteCommerce Analytics Data campaign analytic record lists the campaign, if used, that prompted the shopper to visit the web store.

| Analytics Workbooks | Saved Search | Content |
| --- | --- | --- |
| Label | Type | Label | Type | Provides |
| --- | --- | --- | --- | --- |
| **Campaign** | Text Select | **Campaign Analytics: Campaign** | Text Select | Campaign that brought shopper to web store |
| **Campaign Term** | Text Select | **Campaign Analytics: Campaign Term** | Text | Term included in campaign that brought shopper to web store |
