This section provides details on all preferences related to the Web Site Setup Record for SuiteCommerce and SuiteCommerce Advanced sites. The information herein is more detailed than the average site manager requires for initial site setup. The tables in these sections explain which of the following products apply to each preference:

-   SuiteCommerce
    
-   SuiteCommerce MyAccount
    
-   SuiteCommerce Advanced
    
-   Site Builder
    

If you're setting up your site for the first time, see [Set Minimum Site Record Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1520292597.html).

Note:

Some of these topics are distributed throughout the Help Center.
