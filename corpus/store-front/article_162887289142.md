SuiteCommerce Analytics Data action record provides the actions a shopper took during a web store visit. For example, it lists items added to the cart, page views, and changes to profile information such as a new registration or an address update.

| Analytics Workbooks | Saved Search | Content |
| --- | --- | --- |
| Label | Type | Label | Type | Provides |
| --- | --- | --- | --- | --- |
| **Action Type** | Select | **User Interaction: Action Type** | Select | The type of action a shopper performed when visiting a web store Values can be:
-   Add to Cart
-   Customer Registration
-   Item View
-   Page View
-   Place Order
-   Remove from Cart
-   Save Address
-   Save Credit Card
