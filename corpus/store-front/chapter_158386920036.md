These themes are not compatible with SuiteCommerce MyAccount and SuiteBilling Subscriptions.

Commerce themes enable you to change the layout and style of your web store. You can use any of the following Commerce themes to leverage your web store for a specific product vertical:

-   [Bridge Theme](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158386941791.html) - Balances clean empty space with edgy graphics to create a tech-oriented web store. You can use high-quality, dark images overlaid with clean, white text to highlight the different areas of your site.
    
-   [Horizon Theme](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158386965797.html) - Designed for the outdoor industry. With this theme you can showcase outdoor products on a black background with prominent images.
    
-   [Manor Theme](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158386968178.html) - Lets you create a product-focused furniture web store, utilizing blocks of images on a clean, white background. You can showcase suggested looks for rooms and highlight different furniture types.
    
-   [Posh Theme](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158386970218.html) - Uses an elegant layout of images and text to showcase your health and beauty web store's assorted products. You can use the refined, understated color palette alongside bold images to create a high-end landing page that entices shoppers.
    
-   [Summit Theme](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158386972535.html) - Enables your industry supply web store to showcase products on a sleek, simple background. You can create a seamless user experience and display clear headings, professional images, and explanatory texts.
    
-   [Threads Theme](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158386974998.html) - Enables your apparel web store to showcase products with a fresh and structured layout.
    

Note:

You must implement SuiteCommerce or the Aconcagua release of SuiteCommerce Advanced and later to use Commerce themes.

NetSuite also offers the SuiteCommerce Base Theme, which developers can use as a starting point for theme development and activation on a domain. For details, see [Anatomy of the Base Theme](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1556139021.html).

## Working with SuiteCommerce Themes {#subsect_161497689995}

After your theme is installed and activated, you can configure it using the SuiteCommerce Configuration record. You can also change specific elements of the theme's skin with Site Management Tools. If you're looking to further enhance your theme and you're a developer, you can use placeholders in the theme template files to install a custom extension or add a custom content type.

Explore the following help topics to find out more about the different ways you can work with your theme:

-   [Configuring Themes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158680127593.html) - This help topic outlines how to configure your theme properties, all within the SuiteCommerce Configuration record. This includes configuring the home page, footer, and web fonts.
    
-   [Theme Skin Manager](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1512491665.html) - This help topic covers how to use each of the skins that are included with your theme. You can quickly change how your site looks by applying a different skin. You can also edit a skin to change certain elements using the Theme Settings panel.
    
-   [Templates and Theme Areas for SuiteCommerce Themes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_161521710124.html) - This help topic explains the template files included with SuiteCommerce themes and each of the data-view and CMS placeholders. If you're a developer, you can use these pre-defined areas to install a custom extension or add a custom content type.
