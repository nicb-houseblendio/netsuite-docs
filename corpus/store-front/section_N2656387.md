There are many settings in your Commerce account that determine what items are available on your site. These options control factors like what items are displayed, out-of-stock handling, which items to display in a multi-website setup, and more.

The steps below outline how to set up item records, manage inventory, configure search and SEO options, and organize products using categories. Following these steps will help you control which items appear on your site, how inventory is handled, and how customers interact with your product listings.

| Step | Task | Description |
| --- | --- | --- |
| Step 1 | Set up Item records | [Item Record Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1489003607.html) provides instructions for displaying an item on your website. |
| Step 2 | Set up Item records for the search index | [Search Index Settings](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N2656462.html) details how to set up the search index for item records on your website. |
| Step 3 | Set up item inventory | [Item Inventory](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4456262230.html) details how to set up the item inventory for your web store. |
| Step 4 (If necessary) | Define minimum/maximum order quantities | [Order Quantity](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510780638.html) details how to set up order quantities for your web store. |
| Step 5 (If necessary) | Improve Search Engine Optimization (SEO) ranking | [Search Engine Optimization (SEO)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4053877422.html) provides tips on optimizing search engine results for your web store. |
| Step 6 (If necessary) | Create commerce categories | [Commerce Categories](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4673202005.html) details how to use commerce categories. |
