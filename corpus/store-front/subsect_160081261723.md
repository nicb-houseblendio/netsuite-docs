In Site Management Tools (SMT), you can edit a translation when you need to update a landing page.

#### To edit landing page translations:

1.  Log in to SMT. For details, see [Logging into Site Management Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4163262385.html).
    
2.  Select the Overview Mode icon ![Overview Mode Icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/StoreFront/WebsiteContent/OverviewModeIcon.png) from the site management toolbar.
    
3.  Select the **Pages** subtab.
    
4.  Click the ellipsis next to the landing page you want to edit.
    
5.  Click **Edit**.
    
6.  From the Landing Page Settings panel, select the language from the language dropdown list.
    
7.  Make any required changes.
    
8.  Click **Save**.
