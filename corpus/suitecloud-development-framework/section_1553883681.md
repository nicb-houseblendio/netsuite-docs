In SuiteCloud Development Framework (SDF), you can create new scripts and script records in your SuiteApp project or import existing scripts and records from a NetSuite account. To perform these tasks, see the following topics:

-   From your SuiteApp project, to create a new SDF installation script, see [SuiteScript 2.1 SDF Installation Script Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544719586.html).
    
-   From a NetSuite account, to add a new SDF installation script, see [Creating a Script Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4489062315.html).
    
-   From your SDF SuiteApp project, to add a new or existing SDF installation script, see:
    
    -   [Creating a SuiteScript File in SuiteCloud Extension for Visual Studio Code](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160147328227.html).
        
    -   [Creating an XML Definition for an SDF Custom Object in SuiteCloud IDE Plug-in for WebStorm](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1536776224.html).
        
    -   [Account Component Imports to SuiteCloud Projects](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4702656511.html).

Note:

The `status` field is set to Testing, meaning that the script deploys for the deployment record owner only. Set the status to Released when you want others to be able to run the script.
