The following steps show you how to enable the SuiteCloud Development Framework (SDF) feature in a target NetSuite account.

Tip:

Development accounts can be used with SDF. For information about who can benefit from using development accounts and how to get one, see [Uses for Development Accounts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_17103247407.html).

#### To set up a NetSuite account:

1.  Enable SuiteCloud Development Framework and feature dependencies in the target NetSuite account.
    
    For more information, see [Enabling SuiteCloud Development Framework in the Target NetSuite Account (Administrator Only)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4724921034.html).
    
2.  Assign a customized Developer role to employees that should use SDF. All remaining steps in this tutorial should be performed using the Developer role instead of the Administrator role.
    
    For more information, see [Assigning the Developer Role (Administrator Only)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4724921075.html) and [Assigning Roles to an Employee](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N897798.html).
    

Continue to Step Two: [Set Up Your IDE Environment](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4698042749.html).
