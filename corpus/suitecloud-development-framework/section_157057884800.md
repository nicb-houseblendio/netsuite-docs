Important:

Do not modify the contents of the definition structure or its character data. Modifications may damage the workbook data when you deploy the modified object to a target NetSuite account.

You should use NetSuite to modify custom workbooks rather than using SDF to modify workbook objects. After you save your changes in NetSuite and re-import the workbook into your SuiteCloud project, the workbook object gets updated safely and automatically.

Custom workbooks can be created or modified only by using NetSuite. After the workbooks are created, they can be either imported into a SuiteCloud project or deployed to a target NetSuite account. For more information about creating or modifying a custom workbook, see:

-   [Custom Workbooks and Datasets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1544122127.html)
    
-   [SuiteAnalytics Workbook Tutorial](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1544220685.html)
    

To import a custom workbook into a SuiteCloud project for SuiteCloud Development Framework (SDF), you must import two SDF custom object types that share a common script ID suffix - a `workbook` and a `dataset`. Both objects are required to represent a single custom workbook. For more information, see:

-   [Custom Workbook Objects](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156407234807.html)
    
-   [Custom Dataset Objects](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156408178977.html)
    

## Usage Requirements and Prerequisites {#subsect_156531956798}

You must use the Administrator role to import or deploy custom workbooks with SDF. For more information, see:

-   [Adding an Account in SuiteCloud Extension for Visual Studio Code](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_160147727190.html)
    
-   [SuiteCloud IDE Plug-in for WebStorm Account Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530731998.html)
    
-   [account:setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_89132630266.html)
    

In addition to using the Administrator role for development, enable the SuiteAnalytics Workbook feature in the target NetSuite account to be able to import and deploy workbooks with SDF. For more information, see [Enabling SuiteAnalytics Workbook in Your NetSuite Account](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1504014192.html).
