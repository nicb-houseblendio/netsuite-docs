## Possible Values {#SDFxml_2885682349}

You may need to update the SuiteCloud project manifest depending on the value you specify for a list field. When specifying a mandatory list field with a feature-dependent value, that feature must be added to the SuiteCloud project manifest as a required feature.

-   CALENDAREVENT
    
-   CAMPAIGN (This value has a dependency on the MARKETING feature.)
    
-   ISSUE (This value has a dependency on the ISSUEDB feature.)
    
-   PHONECALL
    
-   PROJECTTASK (This value has a dependency on the ADVANCEDJOBS feature.)
    
-   SOLUTION (This value has a dependency on the KNOWLEDGEBASE feature.)
    
-   SUPPORTCASE (This value has a dependency on the SUPPORT feature.)
    
-   TASK
