This topic provides the list of possible values for the releasestatus field on the [workflow](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/SDFxml_2086367724.html) SDF custom object.

## Possible Values {#SDFxml_1461510387}

**Note:** The NOTINITIATING status has replaced the NOTRUNNING status. Although NOTINITIATING is used for new objects created in NetSuite, the NOTRUNNING status is still supported in SDF for backward compatibility.

-   NOTINITIATING
    
-   NOTRUNNING
    
-   RELEASED
    
-   SUSPENDED
    
-   TESTING
