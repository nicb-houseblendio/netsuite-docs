The `<field_name>` configuration field from the `<feature_name>` feature is missing.

## Cause: A feature entry in the account configuration is missing a required field (that is the status field) {#bridgehead_1500946187}

-   **Solution**
    
    Add the missing field to the feature definition in the `AccountConfiguration/features.xml` file in the project.
