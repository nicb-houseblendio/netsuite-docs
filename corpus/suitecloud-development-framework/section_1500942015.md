Disable the `<feature_name>` feature before disabling the `<other_feature_name>` feature.

## Cause: The feature is dependent on the state of another feature that is either enabled in the target account, or set to enabled in the account configuration {#bridgehead_1500944751}

-   **Solution #1**
    
    Disable the feature in the target account.
    
-   **Solution #2**
    
    Set the feature to disabled in the `AccountConfiguration/features.xml` file in the project.
