You can create Project Profitability portlets in SuiteCloud Development Framework (SDF) using the `publisheddashboard` SDF custom object. For information about the appropriate context, see [Published Dashboards as XML Definitions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1515963216.html).

Project Profitability portlets (or P&L portlets) display a calculation of your project's profit and other information such as cost, revenue, or margin.

Project Profitability portlets in SDF are represented with the `pdpl` element. You can specify this element in a dashboard of a published dashboard object.

The following example shows a project profitability portlet definition:

          `<pdpl>     <isminimized>F</isminimized> </pdpl>` 
        

Important:

To add Project Profitability portlets to your dashboard, ensure that you enable **Advanced Project Profitability** feature on your account first. For more information, see [Advanced Project Profitability](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1484339384.html).

For more information about Project Profitability portlets, see the following help topics:
