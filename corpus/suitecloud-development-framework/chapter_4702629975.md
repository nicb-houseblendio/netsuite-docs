You can get started with SuiteCloud Development Framework (SDF) by learning from the following topics:

-   [SuiteCloud Development Framework Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4724784139.html)
    
    -   [Enabling SuiteCloud Development Framework in the Target NetSuite Account (Administrator Only)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4724921034.html)
        
    -   [Assigning the Developer Role (Administrator Only)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4724921075.html)
        
    -   [SuiteCloud Development Framework Account Preferences (SDF Developers Only)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4730893710.html)
        
-   [SuiteCloud Project Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4706651345.html)
    
    -   [Account Customization Projects](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1510680449.html)
        
    -   [SuiteApp Projects](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1509931104.html)
        
    -   [Differences Between SuiteCloud Projects](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1505834545.html)
        
    -   [SuiteCloud Project Structure and File Components](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4724963992.html)
        

To get started using SDF by working on a customization in a SuiteCloud project, begin the [SuiteCloud Development Framework Tutorial](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4702655701.html).

Tip:

Development accounts can be used with SDF. For information about who can benefit from using development accounts and how to get one, see [Uses for Development Accounts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_17103247407.html).

To use SDF with an extension or plug-in, see:

-   [Installing and Setting Up SuiteCloud Extension for Visual Studio Code](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_159223155621.html)
    
-   [Installing and Setting Up SuiteCloud IDE Plug-in for WebStorm](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1529344324.html)
    

For a demonstration of setting up SDF and creating a project, watch the following videos:

-   [SuiteCloud Development Framework: Setting up NetSuite to Use SDF](https://videohub.oracle.com/media/SuiteCloud+Development+FrameworkA+Setting+up+NetSuite+to+Use+SDF/1_67268uoj?ed=212)
    
-   [Creating a SuiteApp Project in SuiteCloud CLI for Node.js](https://videohub.oracle.com/media/Creating+a+SuiteApp+Project+in+SuiteCloud+CLI+for+Node.js/1_p37nf7d1)
