In SuiteCloud Development Framework (SDF), you can define import options in `savedcsvimport` SDF custom objects.

The following table contains information you can use to match options in the NetSuite user interface Import Assistant with SuiteCloud Development Framework (SDF) XML elements:

Note:

The table does not contain information about required elements, data types, and default values. For that information, see [savedcsvimport](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/SDFxml_2642962146.html).

| Import Assistant Option | XML Element | Notes |
| --- | --- | --- |
| Character Encoding | `charencoding` | For the list of possible values, see [csvimport\_recordtypes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/SDFxml_2327269710.html). For more information, see [Choose Import Character Encoding](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N344158.html). |
| CSV Column Delimiter | `columndelimiter` | For the list of possible values, see [csvimport\_columndelimiter](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/SDFxml_1764394564.html). For more information, see [Choose CSV Column Delimiter](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4341195935.html). |
| CSV Decimal Delimiter | `decimaldelimiter` | For more information, see [CSV Decimal Delimiter](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4341202053.html). |
| CSV File(s) | None | The `savedcsvimport` SDF custom object does not contain CSV data, and CSV file contents cannot be deployed to an account as record instance data. The CSV file is provided by your users when they make use of the CSV saved import. To prepare files for CSV import, see [Guidelines for CSV Import Files](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N356211.html). |
| Custom Form | `entryform` `transactionform` | For custom forms, use either the `entryform` or `transactionform` elements. For more information, see [Custom Form](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3751044597.html). |
| Custom Multi-Select Value Delimiter | `multiselectdelimiter` | For more information, see [Custom Multi-Select Value Delimiter](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3751045259.html). |
| Data Handling | `datahandling` | For more information, see [Choose Data Handling for Import](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N345294.html). |
| Description | `description` | Provides a description in the NetSuite user interface for the CSV import. |
| Ignore Read-Only Fields | `ignorereadonly` | For more information, see [Ignore Read Only Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3751046796.html). |
| Import Map Name | `importname` | Enter a name that can be used as a reference in the NetSuite user interface when tracking the import's progress. The name can also be used to identify the CSV import when it is rerun or edited. |
| Import Type | None | There is no XML element for this option. It is sufficient to specify the `recordtype` element. |
| Log System Notes for Custom Fields | `logsystemnotescustfields` | For more information, see [Log System Notes For Custom Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3751051117.html). |
| Overwrite Missing Fields | `overwritemissingfields` | For more information, see [Overwrite Missing Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3751050565.html). |
| Overwrite Sublists | `overwritesublists` | For more information, see [Overwrite Sublists](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3751046270.html). |
| Prevent Duplicate Records | `preventduplicates` | This element requires the DUPLICATES feature to be declared as a dependency in the manifest. For more information, see [Prevent Duplicate Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3751045493.html). |
| Queue Number | None | This option is not currently supported in SDF. The option is available in the Import Assistant for accounts that have a SuiteCloud Plus license. For more information, see [Queue Number](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3751039561.html). |
| Record Type | `recordtype` | For the list of possible values, see [csvimport\_recordtypes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/SDFxml_2327269710.html). For information about record types supported by NetSuite, see [Supported Record Types for CSV Import](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N356360.html). |
| Run Server SuiteScript and Trigger Workflows | `runserversuitescript` | For more information, see [Server Scripting and Workflow Execution](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4676525683.html). |
| Script ID | `scriptid` attribute for `savedcsvimport` | The prefix of the `scriptid` attribute value is `custimport`. The value must match the file name of the SDF custom object. |
| Use Multi-Threading | `usemultithread` | The option is available for accounts that have a SuiteCloud Plus license. For more information, see [Use Multi-Threading](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3751043993.html). |
| Validate Mandatory Custom Fields | `validatemandatorycustfields` | For more information, see [Validate Mandatory Custom Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3751048115.html). |
