This topic provides information about the available fields for restlet script SDF custom objects. For information about defining RESTlet script objects, see [RESTlet Scripts as XML Definitions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160514060027.html).

## Feature Dependencies {#SDFxml_4114865218}

-   SERVERSIDESCRIPTING
    

## Attributes {#SDFxml_83822235}

| Name | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| scriptid | string | Required | This attribute value can be up to 40 characters long. The default value is 'customscript'. |

| scriptfile | filereference | Required | This field must reference a .js file. |
| description | single-select list | Optional | This field value can be up to 999 characters long. This field accepts references to the [string](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/SDFxml_2285369723.html) custom type. |
