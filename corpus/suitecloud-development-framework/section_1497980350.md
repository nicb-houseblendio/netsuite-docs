The `<property>` value of the `<id> <object name>` object cannot be modified.

## Cause: The property value is disabled or set to read-only in the target account {#bridgehead_1500939974}

-   **Solution**
    
    Set the property to the default value that is used in the account that you are deploying to.
    
    Note:
    
    A read-only property may have a default value that is different across multiple account types.
