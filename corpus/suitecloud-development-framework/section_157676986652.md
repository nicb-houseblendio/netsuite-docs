The following table shows the types of entry forms that SuiteCloud Development Framework (SDF) supports and the feature ID required by the form, if applicable.

You must reference a supported form ID when you specify the standard form value. A feature dependency must be declared in the manifest and enabled in the target account. For an example, see [Example of a Custom Entry Form Object](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157661489922.html).
