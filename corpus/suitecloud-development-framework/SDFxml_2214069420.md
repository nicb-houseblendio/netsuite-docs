This topic provides information about the available field and attributes for the XML definition of advancedpdftemplate SDF custom objects. For information about developing advancedpdftemplate SDF custom objects, see [Advanced HTML/PDF Templates as XML Definitions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1513191111.html).

## Feature Dependencies {#SDFxml_3576084350}

-   ADVANCEDPRINTING
    

## Attributes {#SDFxml_3968119890}

| Name | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| scriptid | string | Required | This attribute value can be up to 98 characters long. The default value is 'custtmpl'. |
| standard | single-select list | Optional | This attribute value can be up to 99 characters long. For information about possible values, see [advancedpdftemplate\_standard](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/SDFxml_2666299542.html). |

## Additional Files {#SDFxml_1694906767}

To use this SDF custom object, you may need to add the following files to the SuiteCloud project:

-   **Object-Script-ID.template.xml** This file is required and must contain the template for the SDF custom object.
