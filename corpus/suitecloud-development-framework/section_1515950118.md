When you modify installation preferences for the SuiteApp project type of SuiteCloud project for SuiteCloud Development Framework (SDF), ensure you validate your project against the target account for each modification. For more information, see [SuiteCloud Project Validation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4719750997.html).

The following example shows some possible validation issues that may occur after modifying installation preferences:

| Installation Preference | Supported Value | Notes |
| --- | --- | --- |
| Preference Type | 
-   HIDING
-   LOCKING
-   OVERWRITING

 | Preference and action values must be compatible. |
| Action | defaultAction | 

-   HIDE
-   UNHIDE
-   LOCK
-   UNLOCK
-   OVERWRITE
-   PRESERVE

 | Hiding is supported for files only. Locking is supported for certain objects types. For a list, see a [Lockable SDF Custom Objects](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1515949845.html#subsect_1516124339). |
