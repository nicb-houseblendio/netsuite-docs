This topic is part of the addressForm SDF custom object documentation.

For information about developing addressForm SDF custom objects, see [Custom Address Forms as XML Definitions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1556843483.html).

The fieldGroup field group is a COLLECTION.

COLLECTION field groups may contain other field groups that can be repeated multiple times.
