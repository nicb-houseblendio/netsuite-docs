The field with the `<field>` ID contains an invalid value. The `sameRowAsPrevious` field must be set to false because it is the first entry.

## Cause: SameRowAsPrevious was enabled for TOP and BOTTOM fields or for the first field with a field group {#bridgehead_1500941479}

-   **Solution**
    
    For the top and bottom position fields, set `<SameRowAsPrevious>F</SameRowAsPrevious>`.
    
    For the first field within a field group, set `<SameRowAsPrevious>F</SameRowAsPrevious>`.
