You cannot use SuiteCloud Development Framework (SDF) to enable the `<feature_name>` feature because it requires a Terms of Service user agreement.

## Cause: There was an attempt to change the state of a feature that requires a Terms of Service user agreement {#bridgehead_1500947377}

-   **Solution**
    
    Remove the reference to the feature definition in the `AccountConfiguration/features.xml` file in the project.
