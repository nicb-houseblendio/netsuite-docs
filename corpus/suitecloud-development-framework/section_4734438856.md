Working with SuiteScript files in a SuiteCloud project for SuiteCloud Development Framework (SDF) is similar to working with those in a SuiteScript project.

For information about:

-   Creating SuiteScript files in SuiteCloud projects, see one of the following topics:
    
    -   [Creating a SuiteScript File in SuiteCloud Extension for Visual Studio Code](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160147328227.html)
        
    -   [Creating a SuiteScript File in SuiteCloud IDE Plug-in for WebStorm](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_155991453859.html)
        
    -   [file:create](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162810635242.html)
        
    -   [createfile](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162067438540.html)
        
-   Importing SuiteScript files into a SuiteCloud project, see [Account Component Imports to SuiteCloud Projects](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4702656511.html).
    
-   Deploying SuiteScript files to a target NetSuite account based on the structure of the deploy file, see [SuiteCloud Project Deployment Preparation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4737888643.html).
