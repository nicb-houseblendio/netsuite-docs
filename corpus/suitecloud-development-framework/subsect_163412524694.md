You can create Project Info portlets in SuiteCloud Development Framework (SDF) using the `publisheddashboard` SDF custom object. For information about the appropriate context, see [Published Dashboards as XML Definitions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1515963216.html).

Project Info portlets shows information about your project such as project name, project manager, customer, or status, based on the project record. You can also use this portlet to edit the project information.

Project Info portlets in SDF are represented with the `pdinfo` element. You can specify this element in a dashboard of a published dashboard object.

The following example shows a project info portlet definition:

          `<pdinfo>     <isminimized>F</isminimized> </pdinfo>`
