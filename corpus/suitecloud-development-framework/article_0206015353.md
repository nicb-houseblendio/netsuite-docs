SuiteCloud Development Framework (SDF) supports life-cycle hooks that allow developers to define custom actions at specific points in the SuiteApp life-cycle. Hooks are defined in the [application.xml](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0206015547.html) configuration file and reference SuiteScript files of type `sdf-installation-script`.

Note:

Hooks are available only in **SuiteApp** projects. Hooks are not supported in **Account Customization** projects.

Currently, SDF supports the following hooks:

| Hook | Trigger Point | Description |
| --- | --- | --- |
| [BeforeUndeploy Hook](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0206015827.html) | Before uninstallation | Executes custom logic before the SuiteApp is uninstalled. |

Note:

The hooks framework is designed for expansion. Additional hooks may be introduced in future releases.

You can use SDF installation scripts to define custom actions during various points of a SuiteApp's lifecycle that are not yet covered by hooks. For more information, see [Customizing SuiteApp Project Deployment using SDF Installation Scripts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1548438348.html).
