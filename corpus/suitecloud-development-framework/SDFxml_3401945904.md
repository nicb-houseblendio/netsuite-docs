This topic is part of the transactionForm SDF custom object documentation.

For information about developing transactionForm SDF custom objects, see [Transaction Forms as XML Definitions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1500300986.html).

The fields field group is a COLLECTION.

COLLECTION field groups may contain other field groups that can be repeated multiple times.

## Attributes {#SDFxml_3963930871}

| Name | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| position | single-select list | Required | For information about possible values, see [form\_fieldposition](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/SDFxml_1070767766.html). The default value is 'MIDDLE'. |

## Structured Fields {#SDFxml_3077706050}

Structured fields are elements that usually contain subfields or groups of fields. They are similar to regular fields but have their own embedded structure. The following structured fields are supported:
