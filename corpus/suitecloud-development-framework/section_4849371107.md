You can view and uninstall a SuiteCloud Development Framework (SDF) SuiteApp that was previously installed in a NetSuite account by going to _Customization > SuiteCloud Development > Installed SuiteApp List_.

Note:

If you do not see the SuiteCloud Development menu option, you may need to enable the SuiteCloud Development Framework feature. For more information, see [Enabling SuiteCloud Development Framework in the Target NetSuite Account (Administrator Only)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4724921034.html).

To uninstall an SDF SuiteApp from the list of installed SuiteApps, click Uninstall under the Action column.

Important:

Account customization projects cannot be uninstalled from a target NetSuite account after they have been deployed. Unwanted account components need to be manually deleted.

For information about how objects are deleted when an SDF SuiteApp is updated or uninstalled, see [Deleting Components in a SuiteCloud Project that were Deployed to a Target Account](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1522153967.html).
