A specific transaction form can be used in SuiteCloud Development Framework (SDF) when one transaction is transformed into another transaction. For the list of valid transformations, see [Supported Transformation Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4267258715.html#bridgehead_4327469981).

You can control which custom transaction form is used by defining the `linkedForms` element on a `transactionForm` SDF custom object. The `linkedForms` element corresponds to the Linked Forms subtab in the NetSuite UI.

Linking transaction forms as chains is a way to mirror your business workflow. For information about linking transaction forms in NetSuite, see [Linking Transaction Forms](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2861289.html).

To link custom transaction forms in SDF, specify the following fields for each `linkedForm` field group:

-   **form** - specifies the form, which can be one of the following:
    
    -   A standard transaction form. For example:
        
                          `<form>STANDARDPURCHASEORDER</form>` 
                        
        
        For a list of possible values, see [transactionform\_standard](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/SDFxml_1255232241.html).
        
    -   A reference to the script ID for a custom transaction form. For example:
        
                          `<form>[scriptid=custform_purchaseorder1]</form>` 
                        
        
-   **type** - specifies the transaction type for the form, which can be one of the following:
    
    -   The transaction type for the custom transaction form. For example:
        
                          `<type>PURCHASE_ORDER_VENDOR_RETURN_AUTHORIZATION_TRANSACTION</type>` 
                        
        
        For a list of possible values, see [transactionform\_trantype](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/SDFxml_618240401.html).
        
    -   A reference to the script ID for a custom transaction type. For example:
        
                          `<type>[scriptid=custtransaction_purchase1]</type>` 
                        
        
        For information about the available fields a custom transaction type, see [customtransactiontype](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/SDFxml_1766516211.html).
        

The following code sample defines linked transaction forms in a custom purchase order:

          `<transactionForm scriptid="custform_10336" standard="STANDARDPURCHASEORDER">    <name>Custom Purchase Order</name>    <recordType>PURCHASEORDER</recordType>  ...  <linkedForms>      <linkedForm>          <type>PURCHASE_ORDER_VENDOR_RETURN_AUTHORIZATION_TRANSACTION</type>          <form>STANDARDPURCHASEORDER</form>      </linkedForm>      <linkedForm>          <type>PURCHASE_ORDER_ITEM_RECEIPT_TRANSACTION</type>          <form>[scriptid=custform_purchaseorder1]</form>      </linkedForm>  </linkedForms>    </transactionForm>` 
        

The preceding code sample defines a `linkedForms` field group that specifies NetSuite to:

-   Use the `STANDARDPURCHASEORDER` standard transaction form when converting a `PURCHASEORDER` transaction to a `PURCHASE_ORDER_VENDOR_RETURN_AUTHORIZATION_TRANSACTION` transaction.
    
-   Use the `custform_purchaseorder1` custom transaction form when converting a `PURCHASEORDER` transaction to a `PURCHASE_ORDER_ITEM_RECEIPT_TRANSACTION` transaction.
