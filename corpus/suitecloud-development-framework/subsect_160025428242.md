You can create Recent Reports portlets in SuiteCloud Development Framework (SDF) using the `publisheddashboard` SDF custom object. For information about the appropriate context, see [Published Dashboards as XML Definitions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1515963216.html).

Recent Reports portlets in SDF are represented with the `recentreports` element. You can specify this element in a dashboard of a published dashboard object.

The following example shows a recent reports portlet definition:

          `<recentreports>     <isminimized>F</isminimized> </recentreports>` 
        

For more information about Recent Reports portlets, see the following help topics:

-   [The Reports Page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N700985.html)
    
-   [recentreports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/SDFxml_3776898258.html)
