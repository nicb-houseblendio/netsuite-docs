This topic is step two of the [SuiteCloud Development Framework Tutorial](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4702655701.html). If you have not already done so, complete step one: [Set Up a NetSuite Account (Administrator Only)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4698037981.html).

Depending on your IDE, refer to one of the following procedures:

-   [To set up your Visual Studio Code environment](#procedure_163103979976)
    
-   [To set up your WebStorm environment](#procedure_1550833640)
    

#### To set up your Visual Studio Code environment {#procedure_163103979976}

1.  Verify that all software prerequisites are met.
    
    For more information, see [Installation Prerequisites for SuiteCloud Extension for Visual Studio Code](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159223197655.html).
    
2.  Download and install Visual Studio Code.
    
    For more information, see [Downloading Visual Studio Code](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159223218652.html).
    
3.  Download and install SuiteCloud Extension for Visual Studio Code.
    
    For more information, see [Installing SuiteCloud Extension for Visual Studio Code](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159223240436.html).
    
4.  To use the OAuth 2.0 protocol with SuiteCloud Extension for Visual Studio Code, enable the OAuth 2.0 feature in the account. For more information, see [OAuth 2.0 Authentication for SuiteCloud SDK](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0422011927.html).
    

#### To set up your WebStorm environment {#procedure_1550833640}

1.  Verify that all software prerequisites are met.
    
    For more information, see [Installation Requirements for SuiteCloud IDE Plug-in for WebStorm](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1529432315.html) and [Supported Operating Systems for SuiteCloud IDE Plug-in for WebStorm](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1529432517.html).
    
2.  Download and install WebStorm.
    
    For more information, see [Downloading WebStorm](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1529432575.html).
    
3.  Download and install SuiteCloud IDE plug-in.
    
    For more information, see [Adding SuiteCloud IDE Plug-in to WebStorm](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1529431804.html).
    
4.  Set up the IDE plug-in. For more information, see [Set Up for SuiteCloud IDE Plug-in for WebStorm](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_1530302119.html).
    
5.  To use the OAuth 2.0 protocol with SuiteCloud IDE, enable the OAuth 2.0 feature in the account. For more information, see [OAuth 2.0 Authentication for SuiteCloud SDK](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0422011927.html).
    

Continue to Step Three: [Create an Account Customization Project](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4698043495.html).
