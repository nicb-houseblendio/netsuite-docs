You can create Project Links portlets in SuiteCloud Development Framework (SDF) using the `publisheddashboard` SDF custom object. For information about the appropriate context, see [Published Dashboards as XML Definitions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1515963216.html).

Project Links portlets display icon links to other features on a project, such as Gantt Chart, Project Task or Expenses.

Project Links portlets in SDF are represented with the `pdquicklinks` element. You can specify this element in a dashboard of a published dashboard object.

The following example shows a project links portlet definition:

          `<pdquicklinks>     <isminimized>F</isminimized> </pdquicklinks>` 
        

For more information about Project Links portlets, see the following help topics:

-   [Project Management](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/part_3746040281.html)
    
-   [pdquicklinks](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/SDFxml_368720903.html)
