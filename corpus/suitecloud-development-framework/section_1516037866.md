You can create and manage custom centers in a NetSuite account by creating a `center` object in a SuiteCloud project and deploying the project to a target account. Additionally, you can import centers from a NetSuite account into a SuiteCloud project.

The following example shows a custom `center` object with a defined label:

          `<center scriptid="custcenter_custom">     <label>My Custom Center</label> </center>` 
        

In addition to centers, you can create and manage the following objects in SDF:

-   **Center categories** - You can add custom categories to standard, built-in NetSuite tabs or custom tabs. For more information, see [Center Categories as XML Definitions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159542604516.html).
    
-   **Center tabs** - You can designate which portlets are available to the center, and which roles have access to the center. For more information, see [Center Tabs as XML Definitions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1516037901.html).
