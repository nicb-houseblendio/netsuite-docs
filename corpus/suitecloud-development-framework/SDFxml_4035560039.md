This topic provides the list of possible values for the loglevel field in the pluginimplementation, plugintype, and sspapplication SDF custom objects.

## Possible Values {#SDFxml_2929826545}

-   AUDIT
    
-   DEBUG
    
-   EMERGENCY
    
-   ERROR
