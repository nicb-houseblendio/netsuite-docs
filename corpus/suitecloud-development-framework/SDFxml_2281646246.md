This topic provides the list of possible values for the charencoding field in the [savedcsvimport](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/SDFxml_2642962146.html) SDF custom object.

## Possible Values {#SDFxml_1902031070}

-   Big5
    
-   EUC\_KR
    
-   GB18030
    
-   GBK
    
-   ISO\_2022\_KR
    
-   ISO\_8859\_1
    
-   MacRoman
    
-   SHIFT\_JIS
    
-   UTF\_8
    
-   windows-1252
