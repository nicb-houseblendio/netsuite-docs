`<state_value>` is an invalid feature state. Set the state to ENABLED or DISABLED.

## Cause: There was a typo or misspelling in the AccountConfiguration/features.xml file {#bridgehead_1500947219}

-   **Solution**
    
    Change the referenced feature state to ENABLED or DISABLED.
