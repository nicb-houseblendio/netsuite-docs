Feature definition must start with the `<tag_name>` tag but found the `<tag_name>` tag.

Features definition must start with the `<tag_name>` tag but found the `<tag_name>` tag.

## Cause: There was a typo or misspelling in the AccountConfiguration/features.xml file {#bridgehead_1500946764}

-   **Solution**
    
    Change the referenced tag to `<feature>` or `<features>`, depending on where the error occurred.
