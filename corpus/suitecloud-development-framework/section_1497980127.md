The following errors may occur when working with account configuration errors:

-   [Resolve the following conflicts to disable the feature](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1500941993.html)
    
-   [Disable the dependent feature before disabling the feature](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1500942015.html)
    
-   [The feature must be enabled to deploy this project](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1500942041.html)
    
-   [The feature is duplicated](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1500942060.html)
    
-   [Enable the dependent feature before enabling the feature](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1500942095.html)
    
-   [The feature is missing its field](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1500942128.html)
    
-   [The feature's field requires a value](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1500942147.html)
    
-   [The feature is not available on this account](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1500942165.html)
    
-   [The configuration field from the feature is missing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1500942191.html)
    
-   [Feature is not modifiable](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1500942233.html)
    
-   [Feature(s) definition must start with tag but found tag](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1500942281.html)
    
-   [An invalid feature ID](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1500942312.html)
    
-   [Is an invalid feature state](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1500942346.html)
    
-   [You cannot use SuiteCloud Development Framework to enable the feature because it requires a Terms of Service user agreement](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1500942398.html)
