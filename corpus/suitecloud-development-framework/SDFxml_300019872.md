This topic provides information about the available fields and attributes for the XML definition of centertab SDF custom objects. For information about developing centertab SDF custom objects, see [Center Tabs as XML Definitions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1516037901.html).

## Attributes {#SDFxml_2553879581}

| Name | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| scriptid | string | Required | This attribute value can be up to 99 characters long. The default value is 'custcentertab'. |
