This topic provides information about the available fields and attributes for the XML definition of addressForm SDF custom objects. For information about developing addressForm SDF custom objects, see [Custom Address Forms as XML Definitions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1556843483.html).

## Feature Dependencies {#SDFxml_1972929352}

-   ADDRESSCUSTOMIZATION
    

## Attributes {#SDFxml_739305091}

| Name | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| scriptid | string | Required | This attribute value can be up to 99 characters long. The default value is 'custform'. |
| standard | single-select list | Optional | This attribute value can be up to 99 characters long. |

## Fields {#SDFxml_2516599167}

| Name | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| name | single-select list | Required | This field accepts references to the [string](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/SDFxml_2285369723.html) custom type. |
| addressTemplate | string | Required | This field value can be up to 3990 characters long. |
| countries | multi-select list | Optional | You can specify multiple values by separating each value with a pipe (|) symbol. For information about possible values, see [countries](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/SDFxml_3500774617.html). |
