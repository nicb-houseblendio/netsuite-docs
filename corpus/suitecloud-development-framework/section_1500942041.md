The `<feature_name>` feature must be enabled to deploy this project.

## Cause: The feature is set to 'required' in the manifest but also set to disabled in the account configuration {#bridgehead_1500944926}

-   **Solution #1**
    
    Change the required state of the feature in the manifest file in the project.
    
-   **Solution #2**
    
    Set the feature to enabled in the `AccountConfiguration/features.xml` file in the project.
