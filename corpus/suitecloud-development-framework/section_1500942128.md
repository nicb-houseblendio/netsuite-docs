The feature is missing its `<field_name>` field.

## Cause: A feature entry in the account configuration is missing its ID field {#bridgehead_1500945557}

-   **Solution**
    
    Add the missing field ID to the feature definition in the `AccountConfiguration/features.xml` file in the project.
