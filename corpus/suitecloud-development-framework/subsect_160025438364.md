You can create settings portlets in SuiteCloud Development Framework (SDF) using the `publisheddashboard` SDF custom object. For information about the appropriate context, see [Published Dashboards as XML Definitions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1515963216.html).

Settings portlets in SDF are represented with the `settings` element. You can specify this element in a dashboard of a published dashboard object.

The following example shows a settings portlet definition:

          `<settings>     <isminimized>F</isminimized> </settings>` 
        

For more information about Settings portlets, see the following help topics:

-   [Settings Portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4767335916.html)
    
-   [settings](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/SDFxml_2316346497.html)
