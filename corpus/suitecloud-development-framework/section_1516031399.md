In SuiteCloud Development Framework (SDF), a saved CSV import map is a way for your users to transfer data sets from external applications into NetSuite using comma separated value (CSV) files. You can include saved CSV import maps in your SuiteCloud projects as `savedcsvimport` SDF custom objects. CSV import maps can be created using the NetSuite user interface, SuiteCloud IDE plug-in, and SuiteCloud CLI.

The `savedcsvimport` SDF custom object contains import options and CSV data mappings to record fields in NetSuite.

The `savedcsvimport` SDF custom object does not contain CSV data, and the CSV file can only be included in the SuiteCloud project as a File Cabinet file. The CSV data cannot be deployed to an account as record instance data. The CSV data is provided by your users when they make use of the CSV saved import. To prepare files for CSV import, see [Guidelines for CSV Import Files](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N356211.html).

For information about saved CSV import maps in NetSuite, see the following topics:

-   [CSV Imports Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N342646.html)
    
-   [Working with Saved CSV Imports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N353796.html)
    
-   [Setting CSV Import Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N355760.html)
    

You should create a saved CSV import from the NetSuite user interface Import Assistant, and import the object into your SuiteCloud project. Using the Import Assistant ensures that you are mapping to valid fields. For more information, see the following:

-   [Importing CSV Files with the Import Assistant](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N343158.html)
    
-   [Account Component Imports to SuiteCloud Projects](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4702656511.html)
    
-   [Downloading the XML Definition of an Object from a NetSuite Account](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4738151284.html)
    

Saved CSV import maps are composed of the following:

-   Import options, see [Defining Import Options for Saved CSV Import Maps in XML Definitions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1519144045.html)
    
-   File mappings, see [Defining File Mappings for Saved CSV Import Maps in XML Definitions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1519143985.html)
    
-   Record and field mappings, see [Defining Record and Field Mappings for Saved CSV Import Maps in XML Definitions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1519143863.html)
    

For more information about saved CSV import maps, see the following:

-   For permissions required by your role, see [Required Permissions for CSV Imports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N345544.html).
    
-   For a savedcsvimport SDF custom object example, see [Saved CSV Import Maps XML Definition Example](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1519143837.html).
