This topic provides information about the available fields and attributes for the XML definition of clientscript SDF custom objects. For information about developing clientscript SDF custom objects, see [Client Scripts as XML Definitions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158638104651.html).

## Feature Dependencies {#SDFxml_1245707576}
