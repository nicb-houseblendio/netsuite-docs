A prompt represents a generative artificial intelligence (AI) prompt. Generative AI prompts are the instructions given to a large language model (LLM). The Text Enhance feature uses prompts to provide instructions to the LLM to generate or modify text.

For more information, see [Text Enhance](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_2171112518.html).

You can also manage prompt records using Prompt Studio and SuiteScript. For more information, see [Prompt Studio](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160809601.html) and [N/llm Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_9123730083.html).

In SDF, the `prompt` object represents a prompt. To download an XML file that represents a prompt, in Prompt Studio, view a custom prompt, and click **Download XML**.

![A prompt in Prompt Studio with the Download XML button highlighted.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/SuiteCloudDevelopmentFramework/prompt_studio_download_xml_prompt.png)

You can download XML only for custom prompts, not system prompts.

Warning:

Do not manually edit the XML in SDF. Modifications to the system-generated XML may result in validation and deployment failures. You should customize prompts using Prompt Studio instead of SDF. For more information, see [Prompt Studio](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160809601.html).

## Prompt XML Example {#subsect_0325113531}

The following code sample shows an example of a prompt XML definition.

            `<prompt scriptid="custprompttranslate">     <action>[scriptid=custteactiontranslate]</action>     <description/>     <fieldid>all</fieldid>     <frequencypenalty>0</frequencypenalty>     <language>en</language>     <languagevariant/>     <maxtokens>0</maxtokens>     <modelfamily>COHERE_COMMAND_R</modelfamily>     <name>Test Translate</name>     <preamble/>     <presencepenalty>0</presencepenalty>     <prompttype>TEXTENHANCE</prompttype>     <recordtype>all</recordtype>     <temperature>0.2</temperature>     <template>Test</template>     <topk>500</topk>     <topp>0.7</topp> </prompt>`
