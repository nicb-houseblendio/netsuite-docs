Scheduled scripts are represented in SuiteCloud Development Framework (SDF) by `scheduledscript` objects. For information about available fields, see the reference documentation for the `scheduledscript` element in [SuiteCloud Development Framework XML Reference](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/SDFxml.html).

To create a `scheduledscript` object, perform one the following procedures:

| Procedure | Details |
| --- | --- |
| In SuiteCloud IDE, create a scheduled script in a NetSuite account. | For information about scheduled scripts, see [SuiteScript 2.1 Scheduled Script Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4387799491.html). |
| In the NetSuite user interface, create a scheduled script in a NetSuite account. | See the following topics:
-   [Creating a Script Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4489062315.html)
-   [Scheduled Script Deployment Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1508948655.html)

Import the `scheduledscript` object into your SuiteCloud project. See [Account Component Imports to SuiteCloud Projects](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4702656511.html). |
| In SuiteCloud plug-ins and extensions, create a scheduled script using a template. | See the following topics:

-   [Creating a SuiteScript File in SuiteCloud Extension for Visual Studio Code](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160147328227.html)
-   [Creating an XML Definition for an SDF Custom Object in SuiteCloud IDE Plug-in for WebStorm](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1536776224.html)

 |

For information about working with scheduled scripts in SDF, see the following topics:

-   [Defining a Recurring Scheduled Script Deployment](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1504707195.html)
    
-   [Scheduled Script Example](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1504707213.html)
