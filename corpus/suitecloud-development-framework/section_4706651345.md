You can use SuiteCloud Development Framework (SDF) to create **SuiteCloud project** components, sometimes referred to as customizations, for internal use within your organization or for commercial distribution. These file-based projects use XML definitions of NetSuite objects and record types, such as custom records, custom forms, and workflows. SuiteCloud projects also support SuiteScript files. You can use SDF to deploy SuiteCloud projects to a NetSuite account.

Note:

SuiteCloud projects were formerly referred to as SDF projects.

You can create the following SuiteCloud project types:

-   [Account Customization Projects](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1510680449.html)
    
-   [SuiteApp Projects](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1509931104.html)
    

Account customization projects are intended for customizations on accounts you own, such as your production, development, and sandbox account types.

SuiteApp Projects are for SuiteCloud Developer Network (SDN) members to develop and deploy SDF SuiteApps to their NetSuite accounts.

For information about the directory structure and files in SuiteCloud projects, see [SuiteCloud Project Structure and File Components](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4724963992.html).

For information that compares the SuiteCloud project types, see [Differences Between SuiteCloud Projects](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1505834545.html).
