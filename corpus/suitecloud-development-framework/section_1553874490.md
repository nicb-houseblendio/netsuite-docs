The following example shows all the coding components that are required in a SuiteApp to run a SuiteCloud Development Framework (SDF) installation script. During deployment, the SDF installation script migrates an older version of the SuiteApp in the target account to the newer version, for upgrading a SuiteApp from 4.0 to 4.1.

The following components are needed to run the SDF installation script:

-   [SDF Installation SuiteScript File Example](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1554821424.html)
    
-   [SDF Custom Objects in SuiteApps Example](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1554821430.html)
    
-   [Deploy File that Executes the SDF Installation Script Example](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1554821440.html)
    

For another SDF Installation script example, see [SDF Installation Script Example of Validating an Account Preference Before Installation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1553701566.html).
