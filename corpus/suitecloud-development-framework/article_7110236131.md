This topic is part of the [eventsubscriber](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_7110236124.html) SDF custom object documentation.

Each `criterion` structured field defines an event subscription and the parameters used to filter it.

## Fields {#subsect_7110236132}

| Name | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| domain | string | Required | Domain of the subscribed event. The supported value is 'RECORD'. |
| type | string | Required | Type of event that triggers the Event Subscriber script. Possible values are 'CREATED', 'UPDATED', and 'DELETED'. |
