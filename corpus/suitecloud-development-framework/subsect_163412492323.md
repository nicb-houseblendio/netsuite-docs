You can create Gantt Chart portlets in SuiteCloud Development Framework (SDF) using the `publisheddashboard` SDF custom object. For information about the appropriate context, see [Published Dashboards as XML Definitions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1515963216.html).

Gantt Chart portlets displays graphical representation of tasks for your project.

Gantt Chart portlets in SDF are represented with the `pdganttchart` element. You can specify this element in a dashboard of a published dashboard object.

The following example shows a Gantt Chart portlet definition:

          `<pdganttchart>     <isminimized>F</isminimized> </pdganttchart>` 
        

For more information about Gantt Chart portlets, see the following help topics:

-   [Gantt Chart](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1202036.html#bridgehead_N1202133)
    
-   [pdganttchart](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/SDFxml_2693680880.html)
