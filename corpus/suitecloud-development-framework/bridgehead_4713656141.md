Note:

You cannot create new address forms, entry forms and transaction forms using SDF. To work with those forms in SDF, you must first import them from a NetSuite account into a SuiteCloud project. See [Account Component Imports to SuiteCloud Projects](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4702656511.html).

-   Address form, see [Custom Address Forms as XML Definitions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1556843483.html) and [addressForm](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/SDFxml_3569816061.html)
    
-   Entry form, see [Custom Entry Forms as XML Definitions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1556843605.html) and [entryForm](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/SDFxml_287092742.html)
    
-   Transaction form, see [Transaction Forms as XML Definitions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1500300986.html) and [transactionForm](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/SDFxml_4143403259.html)
    
-   Sublist, see [Sublists as XML Definitions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1502731359.html) and [sublist](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/SDFxml_1872888069.html)
    
-   Subtab, see [Subtabs as XML Definitions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156416063849.html) and [subtab](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/SDFxml_2906705078.html)
