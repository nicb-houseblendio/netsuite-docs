You can use SuiteCloud Development Framework (SDF) to create custom plug-ins that customize functionality in NetSuite. For information about how custom plug-ins are used, see [Custom Plug-in Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_3976781171.html).

For information about working with custom plug-ins in SDF, see the following topics.

-   [Creating a Custom Plug-in in an XML Definition](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1506612247.html)
    
-   [Instantiating a Custom Plug-in Script in an XML Definition](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1507311527.html)
    
-   [Validating a Custom Plug-in in an XML Definition](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1506970937.html)
    
-   [Custom Plug-in Object Examples](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1506625859.html)
