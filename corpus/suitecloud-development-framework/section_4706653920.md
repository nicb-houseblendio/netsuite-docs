SuiteCloud Development Framework (SDF) provides you with a way to customize NetSuite using SuiteCloud project components instead of using the NetSuite interface. These components can consist of files, scripts, and SDF custom objects such as custom records, custom forms, and workflows. Such components are sometimes referred to as customizations, SDF custom objects, and XML definitions. For more information, see [SuiteCloud Development Framework](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4702622163.html).

Tip:

You can see the root XML tag and script ID prefix for each SDF custom object in [SDF Custom Object File Structure](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1537555588.html).
