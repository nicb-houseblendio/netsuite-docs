The following errors may occur when working with transaction forms or entry forms:

-   [The object value is either invalid or does not exist in the account](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1497980203.html)
    
-   [The field under the group is invalid](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1497980303.html)
    
-   [The property value of the object cannot be modified](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1497980350.html)
    
-   [The sameRowAsPrevious field must be set to false because it is the first entry](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1500939395.html)
    
-   [The object field must not be NOT\_YET\_SUPPORTED](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1500939397.html)
    

For more information, see [entryForm](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/SDFxml_287092742.html) and [transactionForm](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/SDFxml_4143403259.html).
