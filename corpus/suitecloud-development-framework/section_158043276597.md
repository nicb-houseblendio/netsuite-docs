As part of supporting map/reduce scripts in SuiteCloud Development Framework (SDF), to specify the custom plug-in type in a `mapreducescript` SDF custom object, use the `customplugintypes` and `plugintype` elements to reference your custom plug-in. For example:

          `<mapreducescript scriptid="customscript_mr">     ...     <customplugintypes>         <plugintype>             <plugintype>[scriptid=customscript_doc_signing]</plugintype>         </plugintype>     </customplugintypes>     ... </mapreducescript>` 
        

For information about custom plug-ins:

-   [Custom Plug-ins as XML Definitions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1506612236.html)
    
-   [plugintype](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/SDFxml_2530420543.html)
