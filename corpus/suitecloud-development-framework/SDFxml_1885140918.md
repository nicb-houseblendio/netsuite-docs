This topic is part of the publisheddashboard SDF custom object documentation.

For information about developing publisheddashboard SDF custom objects, see [Published Dashboards as XML Definitions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1515963216.html).

The dashboard field group is a DEFAULT.

## Fields {#SDFxml_1892503502}

| Name | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| centertab | single-select list | Required | This field accepts references to the [centertab](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/SDFxml_300019872.html) custom type. For information about other possible values, see [generic\_centertab](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/SDFxml_2711749150.html). |
| mode | single-select list | Required | For information about possible values, see [dashboard\_mode](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/SDFxml_2875910423.html). The default value is 'UNLOCKED'. |
| layout | single-select list | Required | For information about possible values, see [dashboard\_layout](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/SDFxml_1126447129.html). The default value is 'TWO\_COLUMN'. |
