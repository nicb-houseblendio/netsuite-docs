This topic provides information about the available fields and attributes for the XML definition of `eventsubscriber` SDF custom objects. An `eventsubscriber` object defines an Event Subscriber script and the events that trigger it.

For information about developing Event Subscriber scripts, see [SuiteScript 2.1 Event Subscriber Script Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_8125656702.html).

## Feature Dependencies {#subsect_7110236125}

-   SERVERSIDESCRIPTING
    

## Attributes {#subsect_7110236126}

| Name | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| scriptid | string | Required | The script ID for the Event Subscriber script. This attribute value can be up to 27 characters long. The default value is 'custevsub'. |

## Fields {#subsect_7110236127}

| Name | Type | Required / Optional | Description |
| --- | --- | --- | --- |
| scriptfilepath | filereference | Required | Location of the Event Subscriber script file. This field must reference a `.js` file. |
