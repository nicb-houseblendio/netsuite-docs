You can create KPI meter portlets in SuiteCloud Development Framework (SDF) using the `publisheddashboard` SDF custom object. For information about the appropriate context, see [Published Dashboards as XML Definitions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1515963216.html).

KPI meter portlets display data for one of the KPIs included in a KPI portlet on the same dashboard or a different KPI.

KPI meter portlets in SDF are represented with the `kpimeter` element. You can specify this element in a dashboard of a published dashboard object.

The following example shows a KPI meter portlet definition that illustrates the Bank Balance KPI data in a meter:

          `<kpimeter>     <kpi>BANKBAL</kpi> </kpimeter>` 
        

For more information about KPI meter portlets, see:

-   [KPI Meter Portlets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4605495776.html)
    
-   [kpimeter](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/SDFxml_3695579850.html)
