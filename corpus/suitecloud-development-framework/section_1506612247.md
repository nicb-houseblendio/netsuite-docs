The following process describes creating a custom plug-in for use in SuiteCloud Development Framework (SDF):

1.  Create a custom plug-in type. In SDF, that is represented by a `plugintype` object.
    
    See [Creating a Custom Plug-in Type in an XML Definition](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1506970768.html).
    
2.  Create alternate custom plug-in implementations for that type. In SDF, those are represented by `pluginimplementation` objects.
    
    See [Creating a Custom Plug-in Implementation in an XML Definition](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1506970727.html).
    
3.  Instantiate the custom plug-in in a SuiteScript script.
    
    See [Instantiating a Custom Plug-in Script in SuiteScript 2.x](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4574576982.html).
    
4.  Validate the SDF custom objects and then deploy them to a NetSuite account.
    
    See [Validating a Custom Plug-in in an XML Definition](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1506970937.html) and [Deployment Logs for SuiteCloud Projects](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4715369474.html).
    
5.  Set the active implementation in a NetSuite account.
    
    See [Managing Custom Plug-in Implementations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3976831129.html).
    

Tip:

To bundle the custom plug-in, see [Bundling a Custom Plug-in](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3976830493.html).
