You can create Recent Records portlets in SuiteCloud Development Framework (SDF) using the `publisheddashboard` SDF custom object. For information about the appropriate context, see [Published Dashboards as XML Definitions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1515963216.html).

Recent Records portlets in SDF are represented with the `recentrecords` element. You can specify this element in a dashboard of a published dashboard object.

The following example shows a recent records portlet definition:

          `<recentrecords>     <isminimized>F</isminimized> </recentrecords>` 
        

For more information about Recent Records portlets, see the following help topics:

-   [Recent Records Portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N588166.html)
    
-   [Using the Recent Records Menu](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N495728.html)
