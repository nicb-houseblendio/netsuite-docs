This topic is part of the [eventsubscriber](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_7110236124.html) SDF custom object documentation.

The `criteria` structured field is required and contains one or more criteria that determine which events trigger the Event Subscriber script.

## Structured Fields {#subsect_7110236130}

Structured fields are elements that usually contain subfields or groups of fields. They are similar to regular fields but have their own embedded structure. The following structured fields are supported:

-   [criterion](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_7110236131.html)
