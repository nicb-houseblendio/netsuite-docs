The following process describes how to work with custom transaction forms in SuiteCloud Development Framework (SDF) and add custom transaction forms to your SuiteCloud project:

1.  Create custom transaction forms in a NetSuite account one of the following ways:
    
    -   Customize a transaction form in a NetSuite account. See [Creating Custom Entry and Transaction Forms](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2853340.html) and [Supported Custom Transaction Form Objects](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1502220166.html).
        
    -   Customize a transaction form in a NetSuite account using SuiteCloud IDE plug-in.
        
2.  Import the custom transaction forms from a NetSuite account into a SuiteCloud project.
    
    See [Account Component Imports to SuiteCloud Projects](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4702656511.html).
    
    For CLI for Java, see [importobjects](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4788674268.html).
    
    For CLI for Node,js, see [object:import](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156042181820.html).
    
    You can also import custom transaction forms as part of bundles. See [Conversion of a Bundle to an Account Customization Project for SDF](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4849384524.html).
    
3.  Customize the custom transaction form objects in SuiteCloud IDE plug-in, or a third-party IDE and SuiteCloud CLI. For the list of available fields, see [transactionForm](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/SDFxml_4143403259.html).
    
4.  Validate the objects and then address errors and warnings that are returned in the validation log.
    
    See [SuiteCloud Project Validation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4719750997.html) and [Custom Transaction Form Validation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1502220335.html).
    
5.  Deploy the SuiteCloud project to a target NetSuite account.
    
    See [Deployment Logs for SuiteCloud Projects](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4715369474.html) and [Publishing an SDF SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4849369849.html).
