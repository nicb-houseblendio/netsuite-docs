`<feature_name>` is not modifiable.

## Cause: There was an attempt to modify a feature (DOCUMENTS or SUITEAPPDEVELOPMENTFRAMEWORK) that SDF requires to function {#bridgehead_1500946595}

-   **Solution**
    
    Remove the reference to the feature definition in the `AccountConfiguration/features.xml` file in the project.
