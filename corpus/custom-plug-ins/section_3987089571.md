Important:

To create your own custom plug-ins and implementation scripts, you need some JavaScript experience and an understanding of SuiteScript. You should write new custom plug-in scripts in SuiteScript 2.1. To get started with SuiteScript, see [SuiteScript 2.1](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_156042690639.html).

Important:

You cannot use the SuiteScript Debugger to ad hoc debug a script that uses the [N/plugin Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4558176297.html). You must use deployed debugging instead. To use deployed debugging, you must complete the steps described in [Adding a Script that Instantiates a Custom Plug-in to NetSuite](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4574689541.html). For additional information about ad hoc and deployed debugging, see [SuiteScript Debugger](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N3014215.html).
