To use this feature, follow these steps:

1.  Map the Philippines invoicing templates to your transaction forms. Go to **Customization > Forms > Transaction Forms**. For more information, see [Mapping Philippines Invoicing Templates to Transaction Forms](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1219014820.html).
    
    The preceding table in the [Document Types and Templates Preformatted for Philippines](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_78080634004.html) section lists the supported templates you can map in the Template Filename column.
    
2.  Map the Philippines Document Type to your standard transactions or custom forms. Go to **Setup > Southeast Asia Localization > Philippines Transaction Form Mapping**. For more information, see [Mapping Philippines Document Types to Custom Forms](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1219014923.html).
