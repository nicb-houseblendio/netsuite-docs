The Philippines Localization Setup page is a Single Page Application (SPA) for Philippines Localization. You must add permissions to your standard or custom roles to access this SPA.

#### To add SPA permissions to your role:

1.  Go to Customization > Scripting > Single Page Applications and click Philippines Localization Setup.
    
2.  Click **Configuration**.
    
3.  Under the Release Audience section, click **Setup Audience**.
    
    Select the standard or custom role that you want to add to the permission and click the right arrow to add to your selection.
    
4.  Click **Save**.
    

For more information, see the help topic [Managing Single Page Applications Included in SuiteApps](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161244384924.html).
