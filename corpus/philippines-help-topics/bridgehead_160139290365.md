The following table lists the standard roles and their capability to create Philippines transactions with Document Numbering, for OneWorld.

| Standard Role | Create Sales Invoice and Billing Statement | Create Official Receipt and Collection Receipt | Create Credit Memo |
| --- | --- | --- | --- |
| A/R Clerk | Yes | Yes | No |
| Accountant | Yes | Yes | Yes |
| Bookkeeper | Yes | Yes | Yes |
| CEO | Yes | Yes | Yes |
| CFO | Yes | Yes | Yes |
| Retail Clerk | Yes | Yes | Yes |
