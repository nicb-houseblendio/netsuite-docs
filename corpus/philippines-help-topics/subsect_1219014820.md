#### To map Philippines invoicing templates to transaction forms: {#procedure_1107105709}

1.  Go to Customization > Forms > Transaction Forms.
    
2.  Click the **Edit** link for the transaction form you want to map.
    
3.  In the **Printing Type** option, choose **Advanced**.
    
4.  In the **Print Template** field, select the CAS-generated or pre-printed template you want to use.
    
    If you don't use a Computerized Accounting System (CAS), select a document type template marked as 'Pre-printed'.
    
5.  (Optional) In the **Email Template** field, select the Philippines document type template you want to use.
    
6.  Click **Save**.
