The following limitations of Philippines Localization applies to the Locations feature:

-   You don't need to enable the Locations feature to install the Philippines Localization SuiteApp. When the SuiteApp is installed, Locations is disabled by default.
    
-   When you disable the Locations feature, the system hides the Branch Code and Branch Serial Number fields.
    

Note:

It's possible that the Locations feature is already enabled even before installing the SuiteApp.

To enable the Locations feature after installing the Philippines Localization SuiteApp, request NetSuite Support to file an issue for reinstallation of the SuiteApp on your account.
