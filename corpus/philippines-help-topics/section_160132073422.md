Note:

This SuiteApp requires SuiteTax installed to run properly. Enable SuiteTax before installing the Philippines Localization SuiteApp to avoid installation errors. For more information, see [Prerequisites for the Philippines Localization SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160132029316.html) and [Limitations of the Philippines Localization SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160132152779.html).

To install this SuiteApp, you need permission and access to the SuiteApp Marketplace. For more information about viewing SuiteApps listed in the Marketplace, see [Viewing SuiteApps in the SuiteApp Marketplace](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1539797977.html).

#### To install the Philippines Localization SuiteApp:

1.  Go to the NetSuite Home page and **SuiteApps** tab.
    
2.  In the **Search SuiteApps** field, enter 'Philippines Localization'.
    
3.  Click the **Philippines Localization** tile.
    
4.  Click **Install**.
    

For more information, see [SuiteApp Marketplace in NetSuite](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1539797981.html) and [Installing from the SuiteApp Marketplace](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1539799323.html).
