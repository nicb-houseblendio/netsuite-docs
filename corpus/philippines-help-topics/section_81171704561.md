Customize the footer messages of your Philippines documents using the Philippines Invoicing feature of the Southeast Asia Localization SuiteApp.

Note:

Before you can use the Philippines Document Printing Preferences feature, the role you use must be assigned the permission to print Philippines transactions. For more information, see the help topic [Permissions Required to Update Philippines Document Printing Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_16144039037.html).

#### To customize footer messages for Philippines documents: {#procedure_0417053655}

1.  Go to Setup > Southeast Asia Localization > Philippines Document Printing Preferences.
    
2.  Refer to the table below and fill out the fields.
    
    | Field | Description | Related Help Topic |
    | --- | --- | --- |
    | Preview | This field displays a preview of the footer messages in Philippines documents in HTML format. | \- |
    | Document Type | Select the document you want to add footer messages to. You can select from the following:
    -   Billing Statement
    -   Collection Receipt
    -   Credit Memo
    -   Official Receipt
    -   Sales Invoice
    
     | [Philippines Transaction Form Mapping and Invoicing Templates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157890872746.html) |
    | Upper Section Footer Message | Enter the message you want to display in the upper section of the footer of your documents. The footer message field has a header with a link you can click to enter an HTML source code. The header also includes font, paragraph, and other formatting options you can use to format the text you enter in the field. The message you enter appears above the PTU (Permit to Use) or ACCN (Acknowledgment Certificate Control Number) details. | [Viewing and Editing Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N489685.html) |
    | Middle Section Footer Message | Enter the message you want to display in the middle section of the footer of your documents. The footer message field has a header with a link you can click to enter an HTML source code. The header also includes font, paragraph, and other formatting options you can use to format the text you enter in the field. The message you enter appears across the PTU (Permit to Use) or ACCN (Acknowledgment Certificate Control Number) details. | [Viewing and Editing Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N489685.html) |
    | Lower Section Footer Message | Enter the message you want to display in the lower section of the footer of your documents. The footer message field has a header with a link you can click to enter an HTML source code. The header also includes font, paragraph, and other formatting options you can use to format the text you enter in the field. The message you enter appears below the document time stamp. | [Viewing and Editing Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N489685.html) |
    
3.  Click **Save**
    
    To verify that your changes render correctly, use an unapproved transaction to print a test page.
    

Important:

You can't change the seller, buyer, and footer details of approved and printed transactions.

Changes made in the footer details of a document will be reflected on your next printed transaction.
