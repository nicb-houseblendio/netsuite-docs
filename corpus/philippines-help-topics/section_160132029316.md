Enable SuiteTax in your NetSuite Philippines account to install the Philippines Localization SuiteApp. You must set up the SuiteTax Engine and other SuiteTax settings before using Philippines Localization features. For more information, see [Enabling the SuiteTax Feature](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1513063459.html) and [Installing the SuiteTax Engine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557397007.html).

If you have the Southeast Asia Localization bundle installed, you can't install the Philippines Localization SuiteApp. You must uninstall the Southeast Asia Localization bundle.

Before installing the SuiteApp, enable required features in NetSuite.

#### To enable required features in NetSuite:

1.  Go to Setup > Company > Setup Tasks > Enable Features.
    
2.  Click the **SuiteCloud** subtab and check the following features:
    
    -   Custom Records
        
    -   Advanced PDF/HTML Templates
        
    -   Client SuiteScript
        
    -   Server SuiteScript
        
    -   SOAP Web Services
        
    -   SuiteCloud Development Framework
        
    
    Note:
    
    You can enable Locations if needed, but it's not required for installation.
    
3.  Click **Save**.
    

For more information, see [Enabling Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N232138.html).
