#### To add access to a script for a custom role: {#procedure_12173422698}

1.  As an **Administrator**, go to Customization > Scripting > Script Deployments.
    
2.  Click **Edit** next to the **customdeploy\_psg\_sal\_print\_pref\_su** script.
    
    You can select multiple roles by holding down the Ctrl key while selecting each role.
    
3.  Click **Save**.
    

For more information, see [Customizing Philippines Document Printing Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_81171704561.html).
