#### To map Philippines Document Types to custom forms: {#procedure_1107105840}

1.  Go to Setup > Southeast Asia Localization > Philippines Transaction Form Mapping.
    
2.  Click the **Edit** link for the Philippines Document Type template you want to map.
    
3.  In the **Transaction Forms** field, select an applicable transaction form. You can associate multiple transaction forms with this Philippines Document Type template.
    
4.  Click **Save**.
    

The Philippines invoicing template is applied to the transaction form you specified. When you print a transaction record of that type, the PDF or HTML output will be formatted according to the associated template.

Note:

Ensure that the Official Receipt template and the Billing Statement template are both mapped correctly before creating a customer payment. You can't create a customer payment, if the applied or attached invoice's transaction form isn't mapped to the Billing Statement template. Map the transaction form of invoices to the Billing Statement template first, then create an Official Receipt customer payment with those invoices. A payment mapped to the Collection Receipt template only accepts invoices mapped to the Sales Invoice template.
