The Philippines Localization SuiteApp does not support the Email Merge feature. When you use **Merge & Send** to send transactions by email, the system displays an error message.

To send a saved transaction by email, go to view mode and select **Email** from the **Actions** list. Refer to [Emailing Transactions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N513303.html) for more information.
