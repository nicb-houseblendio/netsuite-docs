If you're going to send Philippines documents with applied templates through email, ensure that the documents are displayed correctly. To do this, select the right template for the format you want to send.

#### To set your preferred format for printing or sending Philippines documents through email:

1.  Go to Home > Set Preferences.
    
2.  Click the **Transactions** subtab, and under Printing, check the **Print Using HTML** box if you prefer HTML for printing Philippines documents.
    
    If you prefer PDF for printing, clear the box.
    
3.  For Transaction Email Attachment Format, select one of the following options:
    
    -   HTML - If you want to email documents as inline text.
        
    -   PDF - If you want to email documents as PDF attachments.
        
4.  Click **Save**.
    

Note:

PDF and HTML printouts of unapproved billing statements and sales invoices have their status, 'PENDING APPROVAL', indicated below the document type name in the header. In addition, printouts will have watermarks indicating 'DRAFT'. On PDF, the watermark will appear across every page. On HTML, watermarks will appear in the middle of the document, above the header and transaction body.
