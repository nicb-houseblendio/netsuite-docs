Refer to the following table for the additional minimum permissions you must add to your custom roles.

| Account Type | Subtab | Permission | Minimum Access Level |
| --- | --- | --- | --- |
| All account types | Custom Record | PHL CAS Application Type | View |
| Lists | Custom Record Entries | View |
| Lists | Documents and Files | Edit |
| Lists | Subsidiaries | Edit |
| Setup | SuiteScript | View |
| Accounts with OneWorld only | Lists | Subsidiaries | Edit |
| Accounts without OneWorld only | Setup | Company Information | Full |
| Setup | Set Up Company | Full |

For more information, see the help topics [Setting Permissions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N288727.html) and [Customizing and Creating Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N286284.html).
