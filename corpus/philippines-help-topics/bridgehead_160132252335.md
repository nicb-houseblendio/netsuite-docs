The Philippines Localization SuiteApp enables you to use the following Philippines invoicing features:

-   Use Standard Philippines Forms that are included in the SuiteApp.
    
-   Use forms with Philippines PDF/HTML templates applied and are mapped to Philippines Document Types.
    
-   Set up Document Numbering on transactions.
    
-   Add Inclusive Serial Number to transactions.
    
-   Include Permit To Use (PTU) Number on transactions, with information about date issued and validity period.
    
-   BIR-required details such as document validity period and invalid input tax claim for non-VAT are added in the footer of printed transactions.
    
-   In the second and succeeding printing of approved documents, 'REPRINT' is indicated below the document type.
