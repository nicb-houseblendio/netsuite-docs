Before you can print invoices using Philippines templates, you need to:

-   Set up your account for [Philippines Invoicing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157890644903.html).
    
-   Configure your transaction forms for Philippines Invoicing. For more information, see [Philippines Transaction Form Mapping and Invoicing Templates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157890872746.html).
    
-   Customize your roles to print Philippines invoicing templates. For more information, see [Permissions Required to Print Philippines Invoicing Transactions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_26115236936.html).
    

For information about how to print invoices, see [Printing an Invoice](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1242104.html).

For more information about printing Philippines invoicing transactions, read the following topics:

-   [Changing the Printing Preference](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_162401091084.html)
    
-   [Displaying BIR-Required Details](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_163463327702.html)
    
-   [Labels and Watermarks in Philippines Invoicing Documents](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_15131955781.html)
