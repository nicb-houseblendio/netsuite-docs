The Philippines Localization Setup page enables you to configure invoicing features that are compliant with tax regulations in the Philippines.

#### To configure the Document Setup tab:

1.  Go to Setup > Philippines Localization > Localization Setup.
    
2.  Click the **Document Setup** tab.
    
3.  Refer to the following table when entering field values:
    
    | Field | Description | Related Help Topic |
    | --- | --- | --- |
    | Active Field | With OneWorld, this field displays the edit log icon if there are unsaved changes in the record. The icon is not displayed when the record has been saved. | [Philippines Localization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160131997443.html) |
    | Internal ID | With OneWorld, this field displays the Internal ID of your Subsidiary. | [Subsidiaries in OneWorld](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N268563.html), [Setting the Internal ID Preference](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3423996.html) |
    | Subsidiary | With OneWorld, this displays the Philippines Subsidiaries associated with your account. | [Configuring Company Information](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N240902.html), [Creating Subsidiary Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N272471.html) |
    | Enable Document Numbering | Select to enable Philippines Invoicing in your account. Check this box to generate and enable document numbering for documents associated with your Company or Subsidiary. | [Document Numbering in Philippines Localization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160132340169.html), |
    | BIR Document Issued | This field enables you to select the Computerized Accounting System (CAS) document issued by the BIR. The CAS document you select will appear at the footer of your document. If you're not using CAS, select **None** and no footer will be printed:
    -   **PTU** - for Permit To Use.
    -   **AC** - for Acknowledgement Certificate.
    -   **None** - if you're not using CAS and want to use this SuiteApp for Philippines Document Numbering.
    
     | [Simplified System Registration for Computerized Accounting System (CAS) Users](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162390883580.html) |
    | AC Control or PTU Number | For **PTU**, enter the PTU Number issued to your company. For **AC**,enter the AC Control No. (ACCN) issued to your company in the format, AC\_RDO\_MMYYYY\_XXXXXX, where: AC - means Acknowledgement Certificate RDO - 3-character alphanumeric RDO Code, for example, 038, 044, 132, 17A, 21C MM - month that the Acknowledgement Certificate was prepared or issued YYYY - year that the Acknowledgement Certificate was prepared or issued, must be February 1, 2020 onwards XXXXXX - 6-digit number series | [Simplified System Registration for Computerized Accounting System (CAS) Users](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162390883580.html) |
    | Date Issued | In this field, enter the date when the AC Control or PTU Number was issued to your company. | [Simplified System Registration for Computerized Accounting System (CAS) Users](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162390883580.html) |
    | Valid Until | In this field, enter the date when the validity of your PTU will expire. | [Simplified System Registration for Computerized Accounting System (CAS) Users](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162390883580.html) |
    | Include VAT | Choose to include or exclude VAT details in printing Philippines documents. Check this box to display the amount with the tax added. A separate column for tax amount and tax total will be added to the transaction summary on printed forms. | [Printing Philippines Localization Transactions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162391189397.html) |
    
4.  Click **Save**.
    

The footer details selected will be indicated in the HTML or PDF document generated when you create transactions that use Philippines invoicing templates.
