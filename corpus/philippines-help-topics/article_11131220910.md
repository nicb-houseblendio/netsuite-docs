The Philippines Sales Journal includes information such as customer TIN (Tax Identification Number) and address details, amounts, and related invoice numbers. The following section are included in the audit files:

-   [Audit Files Headers](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1967465.html#bridgehead_29161803781)
    
-   [Sales Journal File Attribute Key](#bridgehead_69131325931)
    

## Sales Journal File Attribute Key {#bridgehead_69131325931}

The File Attribute Key is a section of the Philippines audit files that lists the available columns and their descriptions. The following table lists the values that show in the File Attribute key section of the sales journal.

| Field Name | Description |
| --- | --- |
| Date | Displays the date of the transaction. |
| Customer TIN | Displays the tax registration number of the customer. |
| Customer Name | Displays the name of the customer. |
| Address | Displays the address of the customer. |
| Description | The value in this field is sourced from the **Memo** field. If the Memo field is blank, this is sourced from the **Ref. No.** field. |
| Transaction Type | Displays the transaction type. |
| Reference / Doc No. / Invoice No. | Displays the reference number of the document associated with the transaction. |
| Amount | Displays the gross amount. |
| Discount | Displays the total applied discount on the transaction. |
| Net Sales | Displays the net amount. |
| VAT Amount | Displays the tax amount. |
| Gross Sales | Displays the gross amount without the applied discount. |
