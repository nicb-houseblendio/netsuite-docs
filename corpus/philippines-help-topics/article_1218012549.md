The SuiteApp also includes features to generate and add the following information about Philippines document types:

-   Document Serial Number. For more information, see [Philippines Inclusive Serial Number](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161531259282.html).
    
-   Unique document numbering. For more information, see [Philippines Document Numbering Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157891055492.html).
    
-   PTU (Permit To Use) Number details. For more information, see [Permit To Use (PTU) for Computerized Accounting System (CAS)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157891320550.html).
    
-   ACCN (Acknowledgment Certificate Control Number) details. For more information, see [Support for Simplified System Registration for CAS Users](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161531133306.html).
    
-   Reprint label and watermark for documents with pending approval status. For more information, see [Printing Philippines Invoicing Transactions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161530891415.html).
    
-   Print remittance slip for invoices and statements. For more information, see [Printing Remittance Forms](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1234980.html).
