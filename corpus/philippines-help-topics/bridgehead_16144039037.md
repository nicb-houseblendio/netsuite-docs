To use the Philippines Document Printing Preferences feature, configure the following settings as an Administrator:

-   Customize the role that you want to use to update Philippines invoicing printing preferences and add the following permissions:
    
    -   Document And Files - Set the access level to **View**.
        
    -   Customer Record Entries - Set the access level to **Edit**.
        
        For more information about permissions, see [Setting Permissions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N288727.html).
        
-   Add access to the **customdeploy\_psg\_sal\_print\_pref\_su** script deployment for the custom role with the permission to update printing preferences. For more information, see [Adding Access to a Script for a Custom Role](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1219013611.html).
