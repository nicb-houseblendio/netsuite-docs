NetSuite provides value added tax (VAT) and withholding tax tracking and reporting for businesses in the Philippines. To use the related reporting features, install the following SuiteApps:

-   **International Tax Reports** - Use this SuiteApp to track and report VAT in the Philippines. For more information, read the following topics:
    
    -   [International Tax Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2051341.html)
        
    -   [Installing and Setting Up International Tax Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2051712.html)
        
    -   [Creating or Customizing Roles to Use the International Tax Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2054151.html)
        
        -   [International Tax Reports Permissions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2054820.html)
            
        -   [Granting Access to VAT/GST Reporting](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2060150.html)
            
        -   [Granting Access to Sales and Purchase Reports Grouped by Tax Code](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2060594.html)
            
    -   [Setting Tax Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1813668.html)
        
    -   [Setting Tax Rounding Levels, Methods, and Precision Settings](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1814149.html)
        
    -   [Managing Tax Codes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N1805198.html)
        
    -   [Philippines Tax Codes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1952432.html)

        -   [What goes into each box - Philippines Monthly VAT Form 2550M](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1956367.html)
            
        -   [VAT RELIEF Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N1955531.html) - quarterly Summary List of Sales (SLS) and quarterly Summary List of Purchases (SLP)
            
-   **Withholding Tax** - Use this SuiteApp to track and report withholding tax in the Philippines. For more information, read the following topics:
    
    -   [Withholding Tax Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2079416.html)
        
    -   [Setting Up Withholding Tax - Philippines](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1960928.html)
        
    -   [Setting Default Withholding Tax Codes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2085546.html)
        
    -   [Applying Withholding Taxes on Transactions as a Buyer](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2085924.html)
        
    -   [Recording Withholding Taxes on Transactions as a Seller](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2087219.html)
        
    -   [Withholding Tax Reporting](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2088848.html)

    -   [Creditable Withholding Tax Codes - Philippines](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1961761.html)
        
    -   [Withholding Tax Reports - Philippines](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1966882.html)
        
    -   [Specifying Withholding Tax Settings for Journal Entries](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0610114601.html)
        
-   **Tax Audit Files** - Use this SuiteApp to export general ledger data from NetSuite and generate the Philippines RR09-2009 audit files. For more information, read the following topics:
    
    -   [Philippines Tax Audit Files](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1967465.html)
        
    -   [Using Tax Audit Files](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2077183.html)

-   **Philippines Tax Reports** - Use this SuiteApp to generate Philippines RR 09-2009 audit files from NetSuite for accounts with SuiteTax. For more information, read the following topics:
    
    -   [Prerequisites for Philippines Tax Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0804082317.html)
        
    -   [Installing the Philippines Tax Reports SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0804082633.html)
        
    -   [Tax Audit Files in Philippines Tax Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0804082346.html)
        

For more information about tax features in NetSuite, refer to the list of related topics.

For more information about taxation in the Philippines, go to the [Bureau of Internal Revenue](http://www.bir.gov.ph/) web site.
