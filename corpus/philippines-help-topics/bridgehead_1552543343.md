In NetSuite, users can define their personal preferences, which you can learn more about in [Setting Personal Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N475297.html). To set personal preferences suited for using NetSuite in the Philippines, go to the Home page, point to the Home icon and click **Set Preferences**. On the **General** subtab, go to the Localization section where you can set the following locale-specific preferences:

-   In the **Time Zone** field, select (GMT+08:00) Manila.
    
-   Go to the Formatting section and in the **Date Format** field, select DD/MM/YYYY. In the **Long Date Format** field, select D Month YYYY.
    

For more information, see [General Personal Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N475661.html).
