You can use the following fields when customizing forms and templates:

-   **ACCN / PTU No.** - The Acknowledgment Certificate Control Number or Permit to Use number issued by the BIR.
    
-   **ACCN / PTU Issue Date** - The date the ACCN or PTU was issued.
    
-   **Document Serial Number** - A range of serial numbers registered with the BIR. This information is available on the **Philippines Invoicing > Document Serial Number** subtab of applicable Subsidiary and Location records for supported documents (sales invoices, billing statements, collection receipts, official receipts, and credit memos).
    
-   **Business Style** - The business name registered with the BIR.
    
-   **TIN + 5-digit branch code** - The 9-digit Taxpayer Identification Number (TIN) and 5-digit branch code.
    
    You have two branch code options:
    
    -   Subsidiary TIN - The field ID `federalidnumber`. If the value exceeds 9 digits, the next 5 digits (10th-14th) are considered the branch code.
        
    -   Location / Branch - The Taxpayer Branch Code found under the **Philippine Invoicing** subtab.
