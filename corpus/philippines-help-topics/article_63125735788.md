The Philippines General Ledger includes all your posting transactions. The following sections are included in the audit file.

-   [Audit Files Headers](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1967465.html#bridgehead_29161803781)
    
-   [General Ledger File Attribute Key](#bridgehead_38125928216)
    

Note:

The Philippines General Ledger includes Advanced Intercompany Journal Entry transactions.

## General Ledger File Attribute Key {#bridgehead_38125928216}

The File Attribute Key is a section of the Philippines audit files that lists the available columns and their descriptions. The following table lists the values that show in the File Attribute key section of the general ledger.

| Field Name | Description |
| --- | --- |
| Account | Displays the account name. |
| Date | Displays the date of the transaction. |
| Transaction Type | Displays the transaction type. |
| Reference | Displays the reference number of the document associated with the transaction. |
| Description/Memo | The value in this field is sourced from the **Memo** field. If the Memo field is blank, this is sourced from the **Ref. No.** field. |
| Transaction Number | Displays the internal transaction ID generated by the system. |
| Name | Displays the name of the customer or supplier. |
| Debit | Displays the Debit amount. |
| Credit | Displays the Credit amount. |
| Balance | Displays the Balance amount. |
