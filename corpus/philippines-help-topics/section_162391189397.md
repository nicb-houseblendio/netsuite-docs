To print invoices using Philippines templates, you need to configure your transaction forms for Philippines Invoicing. For more information, read the following topics:

-   [Philippines Localization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160131997443.html)
    
-   [Changing the Printing Preference](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_162391650018.html)
    
-   [Displaying BIR-Required Details](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_162391693050.html)
    
-   [Sample Sales Invoice and Transaction Status](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1219033739.html)
    

For information about how to print invoices, see [Printing an Invoice](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1242104.html).
