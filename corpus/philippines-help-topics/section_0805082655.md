In mixed non-VAT sales invoices, use of percentage tax codes supports accurate sales breakdowns and reporting.

The new percentage tax code appears in the Tax Code column on sales transactions. For a sample invoice and related details, see [About Mixed Non-VAT Sales Invoices](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_0805081640.html)

To create a percentage tax code, read the following topics:

-   [Creating a Percentage Tax Code for Accounts without SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0811023555.html)
    
-   [Creating a Percentage Tax Code for Accounts with SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0811023600.html)
