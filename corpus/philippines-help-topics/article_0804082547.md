#### To generate a tax audit file in Philippines Tax Reports

1.  Go to Reports > Tax > Country Tax Reports.
    
2.  On the Country Tax Report page, provide values for the following fields:
    
    -   **Subsidiary** - Select which subsidiary data you want to include in the country tax report.
        
    -   **Nexus** - Set this filter to display the available reports for the selected nexus.
        
        This field displays a list of nexuses associated to the subsidiary.
        
    -   **Report Name** - Select the report you want to generate.
        
        This field displays the list of supported country reports for the selected nexus.
        
    -   **Start Period** - Select the period range for the transactions you want to show on the report.
        
    -   **End Period** - Select the period range for the transactions you want to show on the report.
        
3.  Click **Generate**.
    
    When the tax audit file is being generated, you can see its progress in the Report Execution Log subtab of the Country Tax Report page. When it's finished, you'll see a download link.
    
4.  Click **Download** to save the file to your device.
