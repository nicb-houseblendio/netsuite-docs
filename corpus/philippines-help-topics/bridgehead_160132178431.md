When you print official receipts and collection receipts for customer payment transactions, the system copies the VAT Reg Number in the header from the VAT Reg Number of the first invoice being paid. When paying for multiple invoices, select only those with similar VAT Reg Numbers. The Philippines Localization SuiteApp does not validate this.
