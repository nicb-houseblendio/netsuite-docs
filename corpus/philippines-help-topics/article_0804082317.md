Before you install the Philippines Tax Reports SuiteApp, make sure the following SuiteApps and features are installed or enabled in your NetSuite account:

## Required SuiteApps {#subsect_0805030955}

-   Southeast Asia Localization SuiteApp
    
    For more information, see [Installing the Southeast Asia Localization SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_1532417449.html).
    
-   Tax Reporting Framework SuiteApp
    
    For more information, see [Installing Tax Reporting Framework](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1528245293.html).
    
-   Localization Assistant SuiteApp (only if you require localization assistant registration)
    
    For more information, see [Installing the Localization Assistant SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163092361565.html).
    

## Required Features {#subsect_0805031059}

#### To enable required features for Philippines Tax Reports:

For more information about enabling features, see [Enabling Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N232138.html).

1.  Go to Setup > Company > Enable Features.
    
2.  On the SuiteCloud subtab, check the **Custom Records** and **Server SuiteScript** box.
    
3.  On the Tax subtab, check the **SuiteTax** box.
    
    Note:
    
    You must also set up the SuiteTax Engine and other SuiteTax settings before using the Philippines Tax Reports features. For more information, see [Enabling the SuiteTax Feature](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1513063459.html) and [Installing the SuiteTax Engine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557397007.html).
    
4.  Click **Save**.
