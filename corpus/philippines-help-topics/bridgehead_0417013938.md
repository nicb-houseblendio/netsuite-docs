If you don't have a OneWorld account, add access to the PHL Company Information RESTLet script deployment to your roles.

#### To add a script deployment to your roles:

1.  As an **Administrator**, go to Customization > Scripting > Script Deployments.
    
2.  Click **Edit** next to the `customdeploy_psg_phl_rest_compinfo` script ID.
    
3.  Under the **Audience** subtab, select the role that you want to have access to the Philippines Localization Setup page.
    
    To select multiple roles, hold down Ctrl while clicking each role.
    
4.  Click **Save**.
    

For more information, see Updating a [Updating a Script Deployment](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4515651225.html).
