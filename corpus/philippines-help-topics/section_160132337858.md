You can use Standard Philippines Forms that already use Philippines PDF/HTML templates. These standard forms are included in the Philippines Localization SuiteApp. Or, you can use your own custom forms, which must be associated with or use the Philippines PDF/HTML invoicing templates. Then, Standard Philippines Forms or your custom forms must be mapped to corresponding Philippines Document Types.

Note:

You can't map the same form to multiple Philippines document types. To change the document type of a form, open the Philippines document type and change the form you want to map to another Philippines document type.

For more information, see the following topics:

-   [Using Philippines PDF/HTML Templates on Customized Forms](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1219035224.html)
    
-   [Mapping Customized Transaction Forms to Philippines Document Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1219035251.html)
