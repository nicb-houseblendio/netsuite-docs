1.  In SuiteCloud, make sure that the following SuiteCloud features are enabled:
    
    -   SuiteBuilder
        
    -   SuiteScript
        
    -   Custom Plug-ins
        
2.  For companies using NetSuite across multiple subsidiaries and countries, see [OneWorld Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N266701.html).
    
3.  Install or confirm the installation of the following SuiteApps (if applicable):
    
    -   Payment Gateway - Provides integration with AsiaPay and AsiaPay External Checkout credit card payment gateways for the Philippines.
        
    -   International Tax Reports - Provides the pre-configured VAT tax codes and rates as well as VAT reports.
        
    -   Withholding Tax - Provides pre-configured withholding tax codes and rates as well as withholding tax reports.
        
    -   Tax Audit Files - Provides Philippines RR 9-2009 books of accounts in CSV format.
        
    -   Supplementary Tax Calculation - Enables application of nondeductible input tax on transactions.
        
    
    See [SuiteApps](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_3134602194.html) to learn more about NetSuite SuiteApps and installation.
