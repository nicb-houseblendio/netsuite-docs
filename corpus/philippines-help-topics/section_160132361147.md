You can exclude items from the Philippines Tax Summary based on the Tax Code setup. To do this, edit the Tax Code record that you want to exclude from the Tax Summary. Check the **Exclude from Tax Summary** box and save the record. When the tax code is applied to items, those items will be excluded from the Philippines Tax Summary.
