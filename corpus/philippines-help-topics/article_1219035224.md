#### To use Philippines PDF/HTML templates on customized forms:

1.  Go to Customization > Forms > Transaction Forms.
    
2.  Click the Customize or Edit link of the transaction form that you want to use or associate with a template.
    
3.  In the **Printing Type** option, choose **Advanced**.
    
4.  In the **Print Template** field, select the appropriate PDF/HTML template that you want to use for this transaction form.
    
    Note:
    
    For non-CAS users or those who use loose-leaf forms, select a document type template with 'Pre-printed' indicated.
    
5.  (Optional) In the **Email Template** field, select the appropriate PDF/HTML template. Generally, this is for businesses that have switched to paperless transactions.
    
6.  Click **Save**.
