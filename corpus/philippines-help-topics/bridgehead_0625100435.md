The table below outlines Philippines taxation features. These features apply to accounts with SuiteTax. For more information, see [SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/preface_1496364245.html).

| Feature | Description | Prerequisites |
| --- | --- | --- |
| [Setting Up Nexuses in SuiteTax Engine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557741442.html) | Guides you through the process of setting up nexuses. | Your NetSuite account administrator must submit a SuiteTax enablement request and enable the SuiteTax feature in your NetSuite account. See [Enabling the SuiteTax Feature](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1513063459.html). Install the following:
-   SuiteTax Engine (see [Installing the SuiteTax Engine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557397007.html) and [Enabling the SuiteTax Plug-In](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557399475.html))

 |
| [Prerequisites for the Philippines Localization SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160132029316.html) | Guides you through the process of setting up the Philippines Localization SuiteApp for accounts with SuiteTax enabled. |
| Philippines invoicing with SuiteTax in [Philippines Invoicing with SuiteTax in Southeast Asia Localization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0811032321.html) [Philippines Invoicing with SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160132213655.html) | Provides information to set up and use Philippines invoicing features with SuiteTax. |
