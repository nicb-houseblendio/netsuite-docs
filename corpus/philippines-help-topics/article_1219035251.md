#### To map customized transaction forms to Philippines document types:

1.  Go to Setup > Philippines Localization > Transaction Form Mapping.
    
2.  From the Transaction Form Mapping List, click the **Edit** link of the Philippines Document Type that you want to map to or associate with transaction forms.
    
3.  On the Transaction Form Mapping page, in the **Transaction Forms** field, select the customized transaction form that use Philippines PDF/HTML templates. You can select multiple transaction forms to associate with this Philippines document type template.
    
4.  Click **Save**.
