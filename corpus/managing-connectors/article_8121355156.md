You can install the NetSuite Connector for Outlook add-in from your Outlook application. The add-in supports Microsoft Outlook 2016 onwards. For more information, see the [Microsoft Outlook help article about add-ins](https://support.microsoft.com/en-us/office/use-add-ins-in-outlook-1ee261f9-49bf-4ba6-b3e2-2ba7bcab64c8).

After installing NetSuite Connector for Outlook, you need to enter your NetSuite credentials and create a token for access. NetSuite Connector for Outlook supports Microsoft 365 cloud accounts and on-premises exchange servers. For on-premise instances, see the [mail server requirements](https://learn.microsoft.com/en-us/office/dev/add-ins/outlook/add-in-requirements#mail-server-requirements) in the Microsoft Outlook help center for more information. Free Outlook.com accounts are not supported.
