The following are the Loop Returns settings:

<a id="table_0209111027"></a>

| Setting Name | Value | Description |
| --- | --- | --- |
| Loop API Token | generated API Token | Used for authentication between NetSuite Connector and Loop Returns. |
| Shopify Store Name linked to the Loop | store name | Field used to identify the Shopify store linked to the Loop account. |

<a id="table_0209112425"></a>

| Setting Name | Description |
| --- | --- |
| Cancel returns in Loop when Return Authorizations are cancelled in NetSuite | Check this box to cancel returns in Loop when Return Authorizations are cancelled in NetSuite |
| Cancel Return Authorizations in NetSuite when returns are cancelled in Loop | Check this box to cancel Return Authorizations in NetSuite when returns are cancelled in Loop |
| Create Return Authorization and Item Receipts as part of the Shopify refund process when a refund is initiated in Loop | Check this box to create Return Authorization and Item Receipts as part of the Shopify refund process when a return is processed in Loop directly. Note: Ensure you haven't selected any conflicting settings. Enabling these settings at the same time may cause the sync to behave incorrectly. Settings-
-   When a refund is detected in the storefront, only sync a cash refund against a matching record in NetSuite. Applies to all channels/accounts.
-   When a refund is detected in the storefront, only sync a return authorization against a matching record in NetSuite. Applies to all channels/accounts.

 |
| Return Authorization Flag Field | NetSuite field ID to flag the return in Loop. |
| NetSuite SKU Field ID | This field matches items on Return Authorization to items on NetSuite. |
