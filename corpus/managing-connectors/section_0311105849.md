You can use the Shopify rich text field mapping, rich\_text\_field, for HTML or plain text values. The rich text metafield is used to display text formatting and styling on storefront content. When using rich text field mapping, be aware of the following:

-   Shopify only supports the following tags:
    
    -   Container tags - paragraph (<p>), heading (<h1>:<h6>), and lists (<ul>, <ol>, <li>)
        
    -   Anchor tag - link (<a>)
        
    -   Styling tags - bold (<b>), italic (<i>), and strong (<strong>)
        
-   Shopify supports the following structure rules:
    
    -   The HTML document root can only contain container tags.
        
    -   Links and text can only be placed inside container tags.
        
    -   Container tags cannot be placed inside other container tags.
        
    -   Only paragraphs support styling tags. Styling tags inside all other tags are ignored.
        

For more information about the Shopify rich text field, see the [Shopify documentation](https://shopify.dev/docs/apps/custom-data/metafields/types#rich-text-formatting).
