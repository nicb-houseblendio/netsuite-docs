NetSuite Connector for Outlook is a Microsoft Outlook add-in that integrates your Outlook with NetSuite. Emails and events can be synced into corresponding records in NetSuite.

## Email Sync {#subsect_0305010525}

You can use the Email Sync to add a received email and its attachments to a NetSuite Customer, Lead, Prospect, Contact, or Opportunity record.

The email synced to NetSuite includes the following details:

-   Subject
    
-   Message
    
-   Message attachments selected during sync
    

## Event Sync {#subsect_0305010637}

You can use the Event Sync to add a received event invitation to a NetSuite Customer, Lead, Prospect, Contact, or Opportunity record.

Important:

The event sync does not support attachments.

The event synced to NetSuite includes the following details:

-   Time and date of event
    
-   Status - always set to Confirmed.
    
-   Reserve Time box - always set to checked.
    
-   All Day box
    
-   Recurring Event
    
-   Attendee responses at the time of sync - Only responses entered by clicking the event in the calendar are recorded. Responses that were made as a reply to the sent email invitation are not recorded.
    

Note:

NetSuite only supports events that start and end on the same calendar day. If an event spans multiple days or if the event ends after 12:00 midnight, it will not sync to NetSuite.
