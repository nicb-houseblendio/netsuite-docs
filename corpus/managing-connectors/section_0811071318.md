This section describes the current limitations of NetSuite Connector for Outlook

## Custom Event Forms {#subsect_0811071423}

When a custom event form is set as the preferred form in NetSuite, events will fail to sync if the custom form contains required fields. Mapping or populating custom required fields during sync is not supported by the add-in.

If you want to use custom event forms, you need to assign a custom event form that does not include required fields to the relevant role. This allows users to access and use the event form, even if the customer's preferred custom form contains required fields.

Note:

Note: Assigning a form without required fields ensures smooth form access and data entry for users in that role.
