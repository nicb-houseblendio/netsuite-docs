The first email address in the To field is designated as the primary recipient. When populating the Recipient field, NetSuite Connector for Outlook checks if the record you selected the email to sync to was taken from the following fields:

-   If the selected record was in the **To** field - This record is used as the Recipient field. The selected record is set as the primary recipient regardless of its position in the To field.
    
-   If the selected record was in the **From** field - NetSuite Connector for Outlook checks if the primary recipient is an associated record of the selected record. If the primary recipient is an associated record, it is used as the Recipient field. If the primary recipient has no associated record, then the selected record is used as the Recipient field. The record of this email address is designated as the primary recipient.
    
-   If the selected record was in the **CC** field - NetSuite Connector for Outlook checks if the primary recipient is an associated record of the selected record. If the primary recipient is an associated record, the record of the primary recipient is used as the Recipient field. If the recipient has no associated record, then the selected record is used as the Recipient field.
