The Amazon Multi-Chanel Fulfillment (MCF) connector enables you to set up Amazon MCF as a 3PL so that you can send orders from the storefronts to Amazon for fulfillment. To set up the Amazon MCF as a 3PL, contact NetSuite Customer Support. In preparation for the setup, be ready with the answers to the following questions:

-   Do you want all orders to post to the Amazon MCF 3PL?
    
-   If all orders should not be posted as Amazon MCF 3PL:
    
    -   What criteria should be used to determine the orders that will go to Amazon FBA?
        
    -   Will only orders at a specific location go to Amazon MCF?
        
    -   Will there be a custom field set up on the order that can be used to determine the orders that will go to Amazon MCF?
