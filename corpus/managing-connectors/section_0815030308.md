The Amazon Vendor Central Fulfillment Sync exchanges routing requests with Amazon Vendor Central for fulfillment. When the orders are fulfilled in NetSuite, the fulfillment information is sent to Amazon Vendor Central.

All orders from Direct Fulfillment Order Sync and Retail Procurement Order Sync are processed by the Fulfillment Sync.

## Amazon Fulfillment Sync Process Flow {#subsect_21195524853}

1.  When the order is fulfilled in NetSuite, NetSuite Connector posts the shipment confirmation to Amazon.
    
2.  Note:
    
    Partial fulfillment is currently not supported when fulfilling orders in the direct fulfillment program. NetSuite Connector only posts to Amazon when the fulfillment is completed.
    
    For partial fulfillments, NetSuite Connector only posts the fulfilled items. The status of the order remains in waiting for shipment.
    
3.  When the order is completely fulfilled, the status of the order in NetSuite is updated to pending billing.
    

## ShipFromParty Party ID {#subsect_60134251830}

The Ship From Party field is a required parameter for Amazon Vendor Central. It contains the warehouse ID of the vendor. You need to create the mapping for Ship From Party in NetSuite Connector in Mappings > Fulfillments. When creating the mapping, you can map to a NetSuite Custom field that will be used as the warehouse ID. Additionally, you can set the default values to be used as the warehouse ID.

## Carton Details in Retail Procurement {#subsect_10153544141}

When fulfilling orders in NetSuite for retail procurement, fulfillment requests are posted as cartons. NetSuite transforms the package into a carton detail. Line items in the package are added as packedItems at the carton-level.

For example, if fulfilling an order with 10 items and the vendor fulfills 5 items, this fulfillment request will have a single tracking number and is posted as one carton from NetSuite. When the remaining items in the order are fulfilled, it is fulfilled with a different carton ID but with the same order ID.
