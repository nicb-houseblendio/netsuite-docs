## Return Authorization Sync {#subsect_0209102633}

The Return Authorization sync automatically retrieves return requests created in Loop Returns. For each return created in Loop, it generates a corresponding Return Authorization record in NetSuite. This ensures that every return you handle through Loop is reflected in NetSuite.

Important:

Note the following about returns in Loop:

-   The connector currently doesn't support multiple returns and exchanges on the same order when the return or exchange is initiated in Loop.
    
-   When you flag a return in NetSuite, the Loop Returns Connector flags the matching return in Loop for manual review. After you complete the manual review in Loop, it moves the return to open. To prevent the connector from flagging the return for future syncs, you must update the reviewed status or clear the flag in NetSuite. If you don't, the connector will continue to flag the return on subsequent syncs.
    

## Item Receipt Sync- NetSuite to Loop {#subsect_0209102824}

When you receive and process returned items in NetSuite, create an Item Receipt against the associated Return Authorization. The Loop Connector syncs this Item Receipt status to Loop Returns, updating the return's progress within Loop and marking the Loop records as Processed. The sync also sends the Return Authorization updates to Loop, like flagging the returns.

## Item Receipt Sync- Loop to NetSuite {#subsect_0209102836}

When you mark a refund or exchange as Processed in Loop Returns, the Loop Connector detects the update and creates an Item Receipt in NetSuite against the relevant Return Authorization. The sync confirms that you have received and processed the returned items.

## Refund Sync {#subsect_0209102917}

When you create a refund in Loop Returns, the Loop Connector creates the corresponding transaction in NetSuite. Based on the original payment method and your business rules, it creates either a cash refund or a credit memo. This refund links to the original Shopify order in NetSuite, for traceability and reconciliation.

## Return Cancellation Sync {#subsect_0209102929}

When you cancel an exchange in Loop, the Return Cancellation sync in the Loop Connect closes the corresponding Return Authorization in NetSuite.

## Returns Authorization Cancellation Sync {#subsect_0209102947}

When you close or cancel a Return Authorization in NetSuite, the Return Authorization Cancellation Sync in the Loop Connector cancels the corresponding exchange in Loop.
