Inbound Shipping refers to the process of sending inventory from your business (or supplier) to the Amazon fulfillment centers, typically for FBA (fulfilled by Amazon) operations. The NetSuite Connector helps automate and manage this process between NetSuite and Amazon Seller Central.

Inbound Shipping functionality supports two syncs- Shipment sync and Receipt only sync.

## Setting up the Inbound Shipping Addon {#subsect_0708030746}

When setting up the inbound shipment addon, you need to decide if you want to receive inbound shipping receipts or if you want to also run the shipment sync.

### Inbound Shipping Settings {#subsect_0708031601}

The Inbound Shipping Addon can be configured in the Settings > Addon Settings > Inbound Shipping screen of your Amazon Connector.

| Settings | Description |
| --- | --- |
| Inbound Shipping Sync Mode | Select among the radio buttons whether you want to only receive inbound shipping receipts or run inbound shipping sync with receipts. |
| Inbound Shipping Posting Errors Recipient | Displays the email address that receives inbound shipment posting error reports. To configure this email address, in NetSuite Connector, go to Amazon > Settings > Notifications and then modify the entry in **Send Amazon inbound shipment sync error notifications to**. |
| Inbound Shipping Cutoff Date | Set the cutoff date for the first run of the Inbound Shipments sync. When the sync is already set up and running, the sync uses the previous run as the cutoff date. |
| NetSuite SKU Field ID | Provide the NetSuite SKU field. If you check the **Same as general settings** box, the NetSuite SKU Field ID will be auto populated from Amazon > Settings > Orders > NetSuite SKU Field ID. |
| Shipment ID Field ID | Provide the NetSuite field ID that contains Amazon Shipment ID value. This field starts with custbody. |
| From Location | Select the NetSuite location from which the inbound shipments will be transferred. Note: Applicable only for Shipment Sync. |
| To Location | Select the FBA location to which the inbound shipments will be transferred.**Note**: Applicable only for Shipment Sync. |

| Advanced Options- Shipment Sync | Description |
| --- | --- |
| Create Transfer Order in NetSuite With Status | Select whether the transfer order's status is set to Pending Approval or Pending Fulfilment upon posting in NetSuite. If you check **Create Item Fulfillment in Picked Status** box, the item will be set to picked status. |
| Shipment Overages and Decrements Notification Email ID | Enter the recipient email ID of the inbound shipment overages and decrements provided in the Notification settings screen. |
| Post Overages and Decrements to NetSuite | When checked, the Overages and Decrements will be posted to NetSuite. |
| Frequency | This is by default set as Interval by the system for the scheduler. |
| Enter Minutes | This is by default set to 20 minutes by the system for the scheduler. |
| Test Inbound Shipments | You can click on this button to test the shipment functionality |

| Advanced Options - Receipt Only Sync | Description |
| --- | --- |
| Process Item Receipts For | Select whether to process item receipts for **Transfer Orders** or **Purchase Orders.** |
| Shipment Overages and Decrements Notification Email ID | Enter the recipient email ID of the inbound shipment overages and decrements provided in the Notification settings screen. |
| Post Overages and Decrements to NetSuite | When checked, the Overages and Decrements will be posted to NetSuite. |
| Frequency | This is by default set as Interval by the system for the scheduler. |
| Enter Minutes | This is by default set to 20 minutes by the system for the scheduler. |
| Test Inbound Shipments | You can click on this button to test the shipment functionality |

### Testing Inbound Shipping {#subsect_0708042617}

After setting up inbound shipping settings, you need to ensure that the Inbound Shipping Addon is properly configured before setting up the scheduler. You can use the Test Inbound Shipping feature to check if the data can be properly retrieved and posted as needed.

Important:

To test the Inbound shipping sync, make sure the Inbound Shipping Sync Mode is selected as Shipment Sync.

#### To test the inbound shipping sync:

1.  Log in to [app.farapp.com](http://app.farapp.com)
    
2.  Select the Amazon connector and the relevant account.
    
3.  Go to Settings > Addons > Inbound Shipping.
    
4.  Scroll down to the bottom of the screen, then click **Test Inbound Shipping**.
    
5.  In the Test Inbound Shipping window, enter a Shipment ID to test, then click **View Status**.
    
6.  Verify the payload displayed in **Output** field.
    
7.  Click **Create Transfer Order**. When done, verify the Transfer Order created in the NetSuite.
    
    Note:
    
    The **Create Transfer Order** button will only be shown when the transfer order does not exist in NetSuite. Otherwise, only **View Status** will be shown.
    
8.  After the Transfer Order is created and Item fulfillment is shipped, click on the **View Status** again. It will show **Post Item Receipt** button to post the Item receipts to NetSuite.
    
9.  Click on **Post Item Receipt**. When done, verify the Item receipt created in NetSuite.
    

A success message is displayed. The transaction is posted to NetSuite and a report is sent to the configured email address. If you instead encounter an error message, rectify the error mentioned in the message and then test again.

Important:

To test the Inbound shipping sync, make sure the Inbound Shipping Sync Mode is selected as Receipt-Only Sync.

#### To test inbound shipping receipts:

1.  Log in to [app.farapp.com](http://app.farapp.com)
    
2.  Select the Amazon connector and the relevant account.
    
3.  Go to Settings > Addon Settings > Inbound Shipping.
    
4.  Scroll down to the bottom of the screen, then click **Test Inbound Shipping**.
    
5.  In the Inbound Shipping window, enter a Item ID to test, then click **View Status**.
    
6.  Verify the payload displayed in **Output** field.
    
7.  Click on **Post Item Receipt**. When done, verify the Item receipt created in NetSuite.
    
    Note:
    
    The **Post Item Receipt** button will only be shown when the Transfer order/Purchase order does not exist in NetSuite. Otherwise, only **View Status** will be shown.
    

A success message is displayed. The receipt is sent to the email address configured. If you encounter an error message, correct the error mentioned in the message then test again.

### Setting up the Inbound Shipping Addon Scheduler {#subsect_0708050314}

Before setting up the Inbound Shipping scheduler, you need to:

-   Ensure that the settings are properly configured.
    
-   Test if the inbound shipping sync and inbound shipping receipts work with the configured settings.
    

Note:

The scheduler frequency is set up by default, so no additional setup is needed apart from the settings. If the user wants to use a different frequency, then only proceed updating the schedule.

You can set inbound shipping to run weekly or daily frequency.

#### To set up inbound shipping schedule:

Important:

The scheduler settings apply to all your accounts that use the Amazon Inbound Shipping addon.

1.  Log in to [app.farapp.com](http://app.farapp.com)
    
2.  Select the Amazon connector and the relevant account.
    
3.  Go to Settings > Addon Settings > Inbound Shipping.
    
4.  Under Advanced Options, use the following fields to set up your inbound shipping schedule:
    
    -   Frequency- select **Daily** or **Weekly**.
        
    -   Run at Time- Set the time when the scheduled task runs.
        
    -   Run on Day- This field is only available when **Weekly** frequency is selected. Set the day of the week when the scheduled task runs.
