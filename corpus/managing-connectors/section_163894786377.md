If customers can place orders for products even if the inventory of a product is 0, check the following:

-   Make sure the **inventory\_tracking** field is not set to **None** for the product.
    
-   If you are syncing the **inventory\_tracking** field from NetSuite, make sure the mapped field in NetSuite is not set to **None**. If you are not syncing the **inventory\_tracking** field, then check and change the field directly in the BigCommerce connector.
