You can use NetSuite Connector for Outlook to sync an event invitation to a particular Customer, Contact, or Opportunity record in NetSuite.

#### To sync an event to NetSuite:

1.  In Outlook, open the event you want to sync.
    
2.  Launch NetSuite Connector for Outlook.
    
3.  On the **Matching Records** of the **Manual** tab, check the record that you want to sync this event. You can select multiple records.
    
    Note:
    
    The add-in determines the matching records based on the email addresses found in the event invitation. See [Matching Records in NetSuite Connector for Outlook](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_2183327472.html) for more information.
    
    If you want to sync the event to a record that is not available in the Matching Records, you can search for the record and manually add it to Matching Records. For more information, see [Adding a Record to Matching Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0305063524.html).
    
4.  Click **Sync Event**.
