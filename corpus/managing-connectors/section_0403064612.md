You can use NetSuite Connector for Outlook to quickly create NetSuite records from the email address of an email message or event.

During sync, the add-in checks all the email addresses found in the email or event. Email addresses with matching records in NetSuite are displayed and can be selected for sync. Email addresses that have no corresponding record in NetSuite are also displayed under New Records. You can click the plus (+) button to create a NetSuite record using the email address. You can create any of the following records:

-   Customer
    
-   Lead
    
-   Prospect
    
-   Contact
    
-   Opportunity
    

#### To create a new NetSuite record from an email address:

1.  In **Sync** tab, email addresses that do not have corresponding NetSuite records will appear under **New Records**. Click + then select the record type you want to create.
    
2.  In the Create Record screen, enter the fields for the new record.
    
    Note:
    
    You can customize the available fields in the create new record screen. Use these fields to create more detailed NetSuite records from NetSuite Connector for Outlook. See [Customizing Record Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0403070649.html) for more information.
    
3.  Click **Save**.
    
4.  You can view the details of the created record on the Summary page. Click **Continue** to go back to the **Sync** screen.
    
5.  Optional. If you want to edit the created record, click Edit.
