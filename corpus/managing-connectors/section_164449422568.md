NetSuite Connector supports creating the Amazon Settlement charge SKUs under the following conditions:

-   You have a single subsidiary or no subsidiaries.
    
-   You are using the **itemId** field as your SKU field.
    

NetSuite Connector provides an automated process for creating the SKUs.

For information about using the automated process, see [Importing Amazon Settlement Reports in NetSuite Connector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162884600373.html).

If you need to create the SKUs manually, see [Manually Creating Amazon Settlement SKUs in NetSuite Connector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162986228640.html).
