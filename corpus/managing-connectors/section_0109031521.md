When you add an Amazon connector, you need to create and configure categories for your products. Amazon requires sellers to create separate templates to categorize their products.

You can use the AmazonListings category to retrieve all available fields of your supported product types to create your product mappings. The standard mapping category for Price and Quantity sync is AmazonListingsPriceQty.

For information about setting up product sync when using the latest Amazon Listings API, see [Amazon Listings API Categories in NetSuite Connector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1106052345.html).
