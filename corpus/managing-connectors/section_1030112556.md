When syncing events or emails to NetSuite using Outlook Connector, you can select which attachments to sync with the email. Inline images can also be included as attachments. Attachments are not supported to sync for events.

For more information about email and attachment limits, see [Size Limits for Emails and Attachments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_7130136991.html).

For more information about the folder structure of the Attachments folder in NetSuite, see [Storing Attachments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3655720.html#bridgehead_N3656145).

## Limitation on Syncing Email with Attachments on Compose Mode {#subsect_1111050910}

If you are composing an Outlook email with attachments, the files cannot be attached for sync before the email has been sent. This limitation occurs because the Microsoft API can only access attachments that are already on the Exchange Server. Emails in compose mode only have the files on your local system. You need to send the email, then open it in your Sent Items folder to sync attachment files to NetSuite.
