When using Outlook Connector, the following features need to be enabled in NetSuite for Outlook Connector to function properly.

-   SOAP Web Services
    
-   REST Web Services
    
-   Token-Based Authentication
    
-   Log in using OAuth 2.0 Access Tokens
    

#### To verify that required NetSuite features are enabled:

1.  Go to _Setup > Company > Setup Tasks > Enable Features_ to verify that all required features are enabled in your NetSuite account.
    
    Note:
    
    If any of these features are not enabled, check the box to enable the feature.
    
2.  Click the SuiteCloud subtab.
    
    1.  Under SuiteTalk (Web Services), verify that the **SOAP Web Services** and the **REST Web Services** boxes are checked.
        
    2.  Under Manage Authentication, verify that the following boxes are checked:
        
        -   **Token-based Authentication**
            
        -   **OAuth 2.0**
            
    
    Note:
    
    When you newly enable a SuiteCloud feature, you are prompted to accept the SuiteCloud Terms of Service. Accept the terms of service to continue.
    
3.  Click **Save**.
