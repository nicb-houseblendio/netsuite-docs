The inventory sync is only available for direct fulfillment. For retail procurement, Amazon can order any quantity if the item is active.

When setting up the inventory sync, you need to map the following items:

-   Flag Field - Defines the NetSuite field to be used as flag field.
    
-   Category - Maps the category to the flag field.
    
-   Price - Defines the mapping for the price level.
    
-   Quantity - Defines the locations where the quantity is synced.
    
-   Selling Party - Defines the vendor name or code.
    
-   Warehouse ID - Maps the location IDs in NetSuite with the Amazon Vendor Central location values.
