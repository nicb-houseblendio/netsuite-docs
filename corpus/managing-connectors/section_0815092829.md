This section lists the available actions that can be manually triggered when managing the data synced by Amazon Vendor Central connector.

## Order Sync {#subsect_15213037615}

| Action | Condition |
| --- | --- |
| **Upload acknowledgement from NetSuite** | Auto acknowledgement is disabled. The order has been approved in NetSuite and is in waiting for approval status in NetSuite Connector. |
| **Get acknowledgement status from AmazonVendorCentral** | Auto acknowledgement is disabled. The order has been approved in NetSuite and is waiting for response from Amazon. |

## Fulfillment Sync {#subsect_31214537349}

| Action | Condition |
| --- | --- |
| **Upload shipment from NetSuite** | The order has already been posted and fulfilled in NetSuite. |

## Inventory Sync {#subsect_38214934506}

| Action | Condition |
| --- | --- |
| **Reload from NetSuite** | The item has been updated in NetSuite. |
| **Check pending posting result** | The update has been posted to Amazon but has not received confirmation yet. |
| **Update inventory on AmazonVendorCentral** | The update is scheduled to post to Amazon. |

## Invoice Sync {#subsect_48215602808}

| Action | Condition |
| --- | --- |
| **Post to AmazonVendorCentral** | The invoice is retrieved in NetSuite Connector. |
