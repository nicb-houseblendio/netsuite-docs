Before using NetSuite Connector for Outlook, contact your NetSuite Administrator and ensure that your NetSuite account has a role with the appropriate permissions. The following table lists the required permissions for the add-in to work properly.

| **Category** | **Permission** | **Access Level for Administrator User** | **Access Level for Standard User** |
| --- | --- | --- | --- |
| Transactions | Find Transaction | View | View |
| Transactions | Opportunity | Edit | Edit |
| Reports | SuiteAnalytics Workbook | Edit | Edit |
| Lists | Calendar | Edit | Edit |
| Lists | Contact-Subsidiary relationship | View | View |
| Lists | Contacts | Edit | Edit |
| Lists | Customers | Edit | Edit |
| Lists | Documents and Files | Full | Full |
| Lists | Events | Create | Create |
| Lists | Track Messages | Create | Create |
| Lists | Employee Record -or- Employee Public Note: The required Employee permission depends on whether you have the Advanced Employee feature enabled in your NetSuite.
-   If the Advanced Employee feature is enabled, you need to have View permission to Lists > Employee Public.
-   If you do not use the Advanced Employee feature, you need to have View permission to Lists > Employee Record.

 | View | View |
| Lists | Employees | View | View |
| Lists | Subsidiaries | View - This permission is only needed for OneWorld accounts. | View - This permission is only needed for OneWorld accounts. |
| Setup | Custom Event Fields | Edit | Edit |
| Setup | Custom Fields | Edit | Edit |
| Setup | Custom Lists | Edit | Edit |
| Setup | Custom Sublists | Edit | Edit |
| Setup | Custom Subtabs | Edit | Edit |
| Setup | Log in using Access Tokens | Full | Full |
| Setup | REST Web Services | Full | Full |
| Setup | SOAP Web Services | Full | Full |
| Setup | User Access Tokens | Full | Full |
| Setup | Accounting Lists | View | View |
| Setup | CRM Lists | View | View |
| Setup | Log in using OAuth 2.0 Access Tokens | Full | Full |
| Setup | Manage own OAuth 2.0 Client Credentials certificates | Full | Not Required |
| Setup | OAuth 2.0 Authorized Applications Management | Full | Not Required |

Your NetSuite role must have access to the NetSuite for Outlook integration features. Contact your NetSuite administrator for this access.

Important:

The Employee Record and Employees permissions are needed for Outlook data to sync to the proper NetSuite records. There may be sensitive information in Employee records that are commonly restricted to HR personnel. When creating a role with these permissions, your NetSuite Administrator needs to ensure that sensitive data is properly handled.
