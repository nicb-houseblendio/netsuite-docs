When using Amazon Inventory Adjustments, there are several settings that need to be considered. You need to decide if you want to only receive inventory adjustment reports or if you want to also run inventory adjustment sync.

The leading practice when setting up Amazon Inventory Adjustments is as follows:

1.  [Inventory Adjustment Settings](#subsect_0705061703)
    
2.  [Configuring Inventory Adjustment Mappings](#subsect_0705061741)
    
3.  [Testing Inventory Adjustment](#subsect_0705061826)
    
4.  [Setting up the Inventory Adjustment Scheduler](#subsect_0705061719)
    

## Inventory Adjustment Settings {#subsect_0705061703}

The Amazon Inventory Adjustment settings can be configured in the Settings > Addon Settings > Inventory Adjustments screen of your Amazon Connector.

| Setting | Description |
| --- | --- |
| **Inventory Adjustment Mode** | Select whether you want to only receive discrepancy reports or run inventory adjustments sync with discrepancy reports. |
| **Inventory Discrepancy Reports Recipient** | Displays the email address that receives inventory adjustment reports. To configure this email address, in NetSuite Connector, go to NetSuite > Settings > Notifications and then modify the entry in **Send NetSuite inventory adjustment error notifications to**. |
| **When an inventory discrepancy is detected, include** | Select whether the report includes only new discrepancies or also include discrepancies detected in previous reports. |
| **FBA SKU Field ID** | The custom field ID for Amazon FBA item SKU. When not entered, the Inventory Adjustment sync takes the SKU field provided in Order Settings. |
| **Location ID** | The inventory location in NetSuite where the inventory adjustment is posted. |

## Configuring Inventory Adjustment Mappings {#subsect_0705061741}

When you have Amazon Inventory Adjustments enabled, you can use the **Inventory Adjustment** transaction type to create inventory adjustment mappings in Amazon connector's Mappings > Other Transactions.

You can map the following fields:

-   Adjustment Account (required)
    
-   Subsidiary
    
-   Class
    
-   Department
    
-   Adjustment Location
    

#### To configure inventory adjustment account:

1.  Log in to [app.farapp.com](https://app.farapp.com).
    
2.  Select the Amazon connector and the relevant account.
    
3.  Go to Mappings > Other Transactions.
    
4.  Click **Add Mapping**.
    
5.  In the Add NetSuite Mapping screen, select the **Transaction Type**, **Adjustment Account**.
    
6.  In **NetSuite Field**, select the internal ID of the NetSuite field that you want to set as the adjustment account.
    
7.  Click **Add Mapping**.
    
8.  Click **Save**.
    

## Testing Inventory Adjustment {#subsect_0705061826}

After setting up inventory adjustment settings and mappings, you need to ensure that the Inventory Adjustment Addon is properly configured before setting up the scheduler. You can do so by testing by using the Test Inventory Adjustments feature to check if the data can be properly retrieved and posted as needed.

#### To test inventory adjustment sync:

A success message is displayed. The transaction is posted to NetSuite and a report is sent to the configured email address. If you instead encounter an error message, rectify the error mentioned in the message then test again.

1.  Log in to [app.farapp.com](https://app.farapp.com).
    
2.  Select the Amazon connector and the relevant account.
    
3.  Go to Settings > Addon Settings > Inventory Adjustments.
    
4.  Scroll down to the bottom of the screen, then click **Test Inventory Adjustments**.
    
5.  In the Test Inventory Adjustments window, enter an Item ID to test, then click **Show Data**.
    
6.  Verify the payload displayed in **Output**.
    
7.  Click **Post Adjustments**.
    

#### To test inventory adjustment report:

A success message is displayed. The report is sent to the email address configured. If you encounter an error message, correct the error mentioned in the message then test again.

1.  Log in to [app.farapp.com](https://app.farapp.com).
    
2.  Select the Amazon connector and the relevant account.
    
3.  Go to Settings > Addon Settings > Inventory Adjustments.
    
4.  Scroll down to the bottom of the screen, then click **Test Inventory Adjustments**.
    
5.  In the Test Inventory Adjustments window, enter an Item ID to test, then click **Show Data**.
    
6.  Verify the payload displayed in **Output**.
    
7.  Click **Send Report**.
    

## Setting up the Inventory Adjustment Scheduler {#subsect_0705061719}

Before setting up the Inventory Adjustment Scheduler you need to:

-   Ensure that the settings and mappings are properly configured
    
-   Test if the inventory adjustment sync and discrepancy works with the configured settings
    

You can set inventory adjustments to run weekly or daily frequency.

#### To set up inventory adjustment schedule:

Note:

The scheduler settings apply to all your accounts that use Amazon Inventory Adjustments.

1.  Log in to [app.farapp.com](https://app.farapp.com).
    
2.  Select the Amazon connector and the relevant account.
    
3.  Go to Settings > Addon Settings > Inventory Adjustments.
    
4.  Under Advanced Options, use the following fields to set up your inventory adjustment schedule.
    
    -   **Frequency** - Select **Daily** or **Weekly**.
        
    -   **Run at Time** - Set the time when the scheduled task runs.
        
    -   **Run on Day** - This field is only available when **Weekly** frequency is selected. Set the day of the week when the scheduled task runs.
