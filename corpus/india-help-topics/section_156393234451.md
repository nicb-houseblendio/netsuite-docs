To view and export TDS tax reports, perform the following steps.

#### To view and export a TDS tax report:

1.  Go to Reports > Tax > Country Reports.
    
2.  On the **Report Execution Log** subtab, locate the report you want to view.
    
3.  Click **View**.
    
4.  To export the report in any of the following file formats, click the respective icon.
    
    -   CSV (.csv)
        
    -   DAT (.dat)
        
    -   Excel (.xls)
        
    -   JSON (.json)
        
    -   Text (.txt)
        
    
    Note:
    
    If export is unavailable, your report doesn't contain data for the selected period range. Click **Back** to return to the Country Tax Reports page and check your filters.
