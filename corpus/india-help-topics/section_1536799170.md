India Tax Deduction at Source (TDS) system requires organizations (deductors) to file quarterly TDS returns with the Income Tax Department of India. These returns must include details such as the Tax Deduction Account Number (TAN), TDS payments, payment types, Permanent Account Number (PAN), and more.

The India Localization SuiteTax Reports SuiteApp in NetSuite streamlines this process by enabling users to generate, view, and export the required TDS reports for compliance.

The SuiteApp provides the following TDS reports:

-   **Income Tax Form 26Q** - This report shows the resident vendor transactions per subsidiary. You should generate this report quarterly.
    
-   **Income Tax Form 27Q** - This report shows the non-resident vendor transactions per subsidiary. You should generate this report quarterly.
    

You can export the TDS reports in the following formats:

-   CSV (.csv)
    
-   DAT (.dat)
    
-   Excel (.xls)
    
-   JSON (.json)
    
-   Text (.txt)
    

To generate TDS reports, see [Generating TDS Tax Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156393229436.html).

To view and export TDS reports, see [Viewing and Exporting TDS Tax Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156393234451.html).

To file TDS returns, see [Filing TDS Returns](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156393238552.html).
