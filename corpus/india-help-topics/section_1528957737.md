The section code determines which TDS tax rate rule applies to a vendor bill. The India Localization Tax Process SuiteApp provides standard section codes for TDS, but you can also manage your own.

You can perform the following actions if you have the Administrator or India Tax Manager role.

-   [Creating Section Codes](#subsect_2125026186)
    
-   [Editing Section Codes](#subsect_9125735910)
    
-   [Inactivating Section Codes](#subsect_37130243133)
    
-   [Deleting Section Codes](#subsect_64130537358)
    

## Creating Section Codes {#subsect_2125026186}

You can create new section codes to meet your business needs.

#### To create a section code: {#procedure_0220125040}

1.  Go to _Customization > Lists, Records, & Fields > Record Types_.
    
2.  Click the New Record link for **India Tax Section Code for TDS**.
    
3.  Enter a unique name for the record.
    
4.  In the **Challan Code** field, enter the code for challan payment.
    
5.  Click **Save**.
    

## Editing Section Codes {#subsect_9125735910}

You can update the name or code of an existing section code. To edit a section code, update the name or code manually.

#### To edit an existing section code: {#procedure_0220125951}

1.  Go to _Customization > Lists, Records, & Fields > Record Types_.
    
2.  Click the List link for **India Tax Section Code for TDS**.
    
3.  Click **Edit** beside the section code you want to edit.
    
4.  Make any changes you need.
    
5.  Click **Save**.
    

## Inactivating Section Codes {#subsect_37130243133}

Inactivate a section code if you no longer want it to appear in transactions, reports, or records, but want to retain its history.I

#### To inactivate a section code: {#procedure_0220010354}

1.  Go to _Customization > Lists, Records, & Fields > Record Types_.
    
2.  Click the List link for **India Tax Section Code for TDS**.
    
3.  On the India Tax Section Code for TDS List page, check the **Show Inactives** box.
    
4.  Check the box next to the section code you want to inactivate.
    
5.  Click **Submit**.
    

## Deleting Section Codes {#subsect_64130537358}

Delete a section code if you want to remove it completely from NetSuite.

#### To delete a section code: {#procedure_0220010616}

1.  Go to _Customization > Lists, Records, & Fields > Record Types_.
    
2.  Click the List link for **India Tax Section Code for TDS**.
    
3.  Click **Edit** beside the section code you want to delete.
    
4.  From the Actions menu, select **Delete**.
    
5.  Click **OK** to confirm you want to delete the section code.
    

After you set up section codes for TDS, create TDS tax rate rules. For more information, see [Creating Rules for TDS Tax Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1528944307.html).
