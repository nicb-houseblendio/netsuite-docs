The E-Way Bill feature supports the following transactions:

-   Bill
    
-   Invoice
    
-   Credit Memo
    
-   Cash Sale
    
-   Cash Refund
    
-   Bill Credit
    

## Best Practices of Entering E-Way Bill Details on Transactions {#subsect_0626111133}

1.  To generate an E-Way Bill, at least one item in the transaction has to be **Goods**.
    
2.  For transactions created before you enabled the E-Way Bill feature, the E-Way Bill status on the **Billing** subtab will be blank. You must edit and save those transactions for the threshold rules to apply.
    
3.  Whenever you update the threshold setup, it only applies to transactions processed after the update. To apply it to older transactions, edit and save those records.
    
4.  To avoid incorrect GST Cess details in your E-Way Bill report, don't edit the **Details** column of the **Tax Details** subtab in a transaction.
    
5.  If the entity's registration type is **Overseas** the shipping address must be in India to generate an E-Way Bill using the Invoice Reference Number (IRN).
    

#### To enter E-Way Bill details on a transaction record:

1.  Create or edit a transaction record.
    
2.  Select the customer or vendor for the transaction.
    
3.  Click the **Billing** subtab.
    
4.  In the India E-Way Bill Details section, review the fields. For details. see [India E-Way Bill Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111053842.html).
    
5.  Check the **Override E-Way Bill Defaults** box to override the default value for the following fields under the India E-Way Bill Details section:
    
    -   Supply Type
        
    -   Sub Type
        
    -   Doc Type
        
    -   E-Way Bill Transaction Type
        
6.  Enter any other necessary information.
    
7.  Click **Save**.
