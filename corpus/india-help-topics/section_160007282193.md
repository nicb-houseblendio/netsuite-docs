The India Localization SuiteApp enables organizations to generate and process outbound electronic invoices (e-invoices) in compliance with Indian government regulations. This SuiteApp streamlines e-invoicing by integrating with GST Suvidha Providers (GSPs) and the Invoice Registration Portal (IRP), helping you meet statutory requirements efficiently.

The SuiteApp lets you:

-   Generate e-invoices for the following transactions:
    
    -   Bill Credit or Vendor Credit
        
    -   Cash Sale
        
    -   Credit Memo
        
    -   Invoice
        
-   Connect NetSuite with GST Suvidha Providers (GSPs), with ClearTax preconfigured as a GSP.
    
-   Generate outbound e-invoices using government-compliant JSON templates.
    
-   Submit e-invoices for certification (registration) on the Invoice Registration Portal (IRP).
    
-   Send certified e-invoices to customers.
    
-   Generate an E-Way Bill using the Invoice Reference Number.
    
-   Create and manage e-document packages, including templates and certification-sending methods for GSP integration. For more information, see [Creating E-Document Packages](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4576918342.html).
    

Before using the India electronic invoicing features, ensure you:

-   Complete the [Prerequisites of India Electronic Invoicing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1112032439.html) and user permissions. For more information, see [Configuring Roles for India Localization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1027053649.html#subsect_1027052144).
    
-   Understand the key terms:
    
    -   GST Suvidha Provider (GSP) - A government-authorized intermediary for GST compliance.
        
    -   Invoice Registration Portal (IRP) - The government portal for registering and certifying e-invoices.
        
    -   E-Way Bill - A document required for the movement of goods, generated using the Invoice Reference Number.
        
-   Review the limitations and best practices of using the India Localization SuiteTax Engine SuiteApp. For more information, see [India Localization SuiteTax Engine Limitations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0220055541.html) and [India Localization SuiteTax Engine Best Practices](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0406045813.html).
    
-   Complete the setup before proceeding to use the India electronic invoicing features. For more information, see [Setting Up India Electronic Invoicing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160083885810.html).
