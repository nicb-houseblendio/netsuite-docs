The India Localization SuiteTax Engine SuiteApp provides default e-document JSON templates for common transaction types, including credit memos, invoices, cash sales, and vendor credits. These templates define the structure and data fields used when generating e-documents.

To view or manage these templates, go to Setup > E-Documents > E-Document Templates in your NetSuite account.

If you need to modify a default template to meet your business requirements:

-   **Make a copy** - Select the template you want to customize and create a copy.
    
-   **Edit the copy** - Make your changes to the copied template, not the original.
    

To create a new e-document template for outbound processing, see [Creating E-Document Templates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4536871429.html).

For more details on the templates, see the following:

-   [Credit Memo](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160196451208.html)
    
-   [Vendor Credit or Bill Credit](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160196452588.html)
    
-   [Invoice and Cash Sale](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160196454533.html)
