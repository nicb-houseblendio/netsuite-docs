With the E-Way Bill feature, you can generate an E-Way Bill file with all the details you need for the GST EWB-01 form online. Use this file to import E-Way Bill details for transactions into the E-Way Bill portal and get your E-Way Bill Number (EBN).

To complete the E-Way Bill process, you must perform the following steps in order:

1.  [Generating the E-Way Bill File](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1111054857.html).
    
2.  [Submitting the E-Way Bill File to the E-Way Bill Portal](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1111054901.html).
    
3.  [Updating EBN and E-Way Bill Date Value on Transactions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1111054908.html).
    
4.  [Updating E-Way Bill Details on Transactions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1111054904.html).
