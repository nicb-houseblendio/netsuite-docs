The India Localization SuiteTax Engine SuiteApp lets you create a challan voucher to submit TDS to the tax authority. A challan voucher includes tax information and payment details required for compliance.

You can create multiple challan vouchers in a tax period if each voucher is for a different section code. However, you can't create more than one challan voucher with the same section code and the same period (**Tax Transaction From** and **Tax Transaction To** dates).

This rule applies even if you use different accounts in the voucher lines. The restriction is strictly by section code and date range.

If you attempt to create such a duplicate, you'll see an error message that says "A challan with the same effective date range already exists in this record."

If you require multiple challan vouchers, you should either use different section codes or adjust the date range.

To create a TDS challan voucher, you must have access to the India Localization SuiteApp and the necessary permissions in NetSuite. If you don't see the required menu options, contact your account administrator to verify your role and permissions.

Before creating a challan voucher, ensure that TDS has been applied to the relevant vendor bills for the selected period.

#### To create a TDS challan voucher:

1.  If you're using the Accounting Center, go to Financial > Other > India TDS Challan Voucher.
    
    If you're using the Classic Center, go to Transactions > Finance > India TDS Challan Voucher.
    
2.  Click **New India TDS Challan Voucher**.
    
3.  In the Classification section, select a subsidiary.
    
4.  In the India Tax Information section, fill out the following fields:
    
    1.  In the **Tax Transaction To** and **Tax Transaction From** fields, enter the transaction period.
        
    2.  Enter bank details for the challan.
        
    3.  In the **Section Code** field, select one or more section codes to create a challan voucher.
        
    4.  (Optional) Check the **Select All Section Codes** box to create a challan voucher for all section codes. By default, the box is checked for new and existing transactions.
        
5.  To select account at the line level, do the following:
    
    1.  In the **Debit Account** field, select the account from which the TDS amount is paid (typically the tax authority account). You can set this up on the Tax Type Mapping Configuration page, using the nexus and section code, or by configuring the Tax Type record for TDS.
        
    2.  In the **Credit Account** field, select the account to which the TDS is credited.
        
    3.  Ensure that the correct debit and credit accounts are selected at the line level to accurately reflect the tax payment.
        
6.  Enter other details as needed.
    
7.  Click **Save**.
    

A challan voucher contains the following fields.

| Field | Description |
| --- | --- |
| Challan for NRI | Check this box to file Form 27Q. |
| Return Form Period | Select the return form period for the challan. |
| Tax Transaction From | Enter the start date of the bills linked to this challan. |
| Tax Transaction To | Enter the end date of the bills linked to this challan. |
| Bank Challan Number | Enter the challan number from the bank. |
| Bank Branch Code | Enter the challan BSR code for the receiving branch. |
| Date of Bank Challan | Enter the tax payment date. |
| Minor Head of Challan | Select from the following options:
-   TDS Payable by Taxpayer
-   TDS Regular Assessment

 |
| Nil Challan Indicator | Check this box if the voucher qualifies for Nil TDS Return. |
| Details of Payment | Select the type of payment made. |
| Section Code | Select the section codes you want to generate challan vouchers for in a transaction period. |
| Select All Section Codes | Check this box to select all section codes and generate challan vouchers for a transaction period. |
