To calculate TDS on vendor bills, you must first set up tax information in your vendor records. Use the Administrator role for to complete the procedure.

#### To set up tax information in a vendor record: {#procedure_0217022247}

1.  Go to _Lists > Relationships > Vendor_.
    
2.  Click **Edit** beside the vendor record you want to edit.
    
3.  Click the **Financials** subtab.
    
4.  Under the Tax Information section, in the **PAN Availability** field, select the vendor's Permanent Account Number (PAN) status from the following options:
    
    -   **Applied** - Select this option if the vendor has applied for a PAN but doesn't have the number yet.
        
    -   **Invalid** - Select this option if the vendor's PAN isn't in the correct format.
        
    -   **Not Available** - Select this option if the vendor doesn't have a PAN.
        
    -   **Available** - Select this option if the vendor has a PAN.
        
5.  In the **Permanent Account Number (PAN)** field, enter the vendor's PAN if it's available.
    
6.  In the **Reference Number** field, enter a reference number if the PAN status is **Applied**, **Invalid**, or **Not Available**.
    
7.  In the **Tax Identification Number (TIN)** field, enter the TIN.
    
8.  Check the **Non-Resident Indian** box if the vendor isn't an Indian resident.
    
9.  Click **Save**.
    

After you set up tax information in vendor records, map TDS tax types. For more information, see [Mapping TDS Tax Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1528941496.html).
