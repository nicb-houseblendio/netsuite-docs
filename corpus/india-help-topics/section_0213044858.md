This topic provides a high-level overview of the steps required to set up the India Localization SuiteTax Engine SuiteApp. Before you begin, note the following:To set up the India Localization SuiteTax Engine, you must do the following tasks in order:

-   Ensure you have the Administrator role.
    
-   Gather all required tax information for your subsidiaries.
    
-   Prepare your CSV files for tax rule import.
    

Use this page as a guide to understand the process and go to detailed instructions for each step.

Important:

The **State**, **Province**, and **County** in the address help determine the correct place of supply and tax classification for India GST.

Ensure to disable the Allow Free-Form States in Addresses preference before setting up India GST to avoid errors during tax calculation.

1.  **Select the India SuiteTax Engine plug-in** - Activate the required tax engine plug-in in your NetSuite account. Go to Customization > Plug-ins > Manage Plug-ins and enable the **NetSuite India SuiteTax Engine SS2** tax engine plug-in for tax calculation. For more information, see [Selecting the India Tax Engine Plug-in](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1027053537.html).
    
2.  **Assign roles and permissions** - Assign the India Tax Manager role or set up custom roles with the necessary permissions. Go to Setup > Users/Roles > Manage Roles and assign the required permissions to your custom roles. For more information, see [Assigning Roles and Permissions to Use India Tax Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1027053649.html).
    
3.  **Configure subsidiary tax information** - Enter GST and TDS details for each subsidiary. Go to Setup > Company > Classifications > Subsidiary and set up tax information for your subsidiaries for GST and TDS calculation. For more information, see [Configuring Subsidiary Tax Information](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1027053753.html).
    
4.  **Set up India tax registration** - Register each subsidiary for GST and TDS, and enter GSTIN and nexus details. Go to Setup > Company > Classifications > Subsidiary and set up tax information for your subsidiaries for GST and TDS calculation. For more information, see [Setting Up India Tax Registration](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1027054053.html).
    
5.  **Import India tax rules using CSV** - Import GST, TDS, and TCS tax rules using a CSV file. Go to Setup > Import/Export > Import Tasks > Import CSV Records and import India tax rules using a CSV file. For more information, see [Importing India Tax Rules with a CSV File](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1027054308.html).
