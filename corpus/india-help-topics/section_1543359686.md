## Overview {#subsect_42120001197}

Note:

The following topics are for NetSuite accounts with SuiteTax. For accounts without SuiteTax, see e [Legacy Tax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/preface_3710626699.html).

The India Localization SuiteTax Engine SuiteApp provides localization features for businesses in India. The SuiteApp lets you manage and calculate transactions so you're compliant with accounting and tax requirements. It was developed using the India SuiteTax Engine plug-in.

The SuiteApp provides the following features for India businesses:

-   [Goods and Services Tax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1533876022.html) - Use this feature to calculate GST on purchase and sales transactions. Generate automatic journals for export transactions.
    
-   [Tax Deduction at Source](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1528857544.html) - Use this feature to calculate TDS on vendor bills and create TDS challan vouchers. Verify calculated TDS amounts against accurate deductions to ensure accuracy and compliance.
    
-   [Tax Collection at Source](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1226092929.html) - Use this feature to calculate TCS on items specified in Section 206C of the Income Tax Act.
    
-   [Electronic Invoicing for India](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160007282193.html) - Use this feature to generate, certify, and send electronic invoices.
    
-   [E-Way Bill for India](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1548723858.html) - Use this feature to generate and manage GST compliant E-Way bills for goods.
    
-   [Creating Statutory Adjustment Journals](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1550110256.html) - Use this feature to create adjustment journals for statutory compliance.
    
-   [Sending Customized Notifications](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1219033453.html) - Use this feature to set up automated, customized email notifications for GST tax rate rules and LUT bond details. Use predefined criteria and configurable scenarios to trigger notifications.
    
-   [Localization Assistant SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_163092114640.html) - Use this feature to manage localization components through the Localization Assistant SuiteApp.
    
-   [Generating Invoices with QR Codes for India](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0925010949.html) - Use this feature to generate invoices with QR codes for B2C customers.
    

Before you start using the India Localization SuiteApp, note its limitations and best practices.

-   [India Localization SuiteTax Engine Limitations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0220055541.html)
    
-   [India Localization SuiteTax Engine Best Practices](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0406045813.html)
    

### Prerequisites and Setup {#subsect_1023022550}

To use the India Localization SuiteTax Engine SuiteApp, you must perform the following:

-   Enable the SuiteTax feature in your NetSuite account.
    
-   Contact your NetSuite account manager to set up India Localization SuiteTax Engine.
    
-   Complete the following tasks in order:
    
    1.  [India Localization SuiteTax Engine Prerequisites](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0213044746.html)
        
    2.  [Installing the India Localization SuiteTax Engine SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0213044826.html)
        
    3.  [Setting Up the India Localization SuiteTax Engine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0213044858.html)
        

For further assistance or detailed setup instructions, see the relevant help topics or contact your NetSuite account manager.
