To set up Tax Deduction at Source (TDS), use the Administrator or India Tax Manager role to complete these steps in order:

1.  **Set up tax information in your vendor records** - This ensures each vendor has the correct tax details. For more information, see [Setting Up Tax Information in Vendor Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1528944722.html).
    
2.  **Map TDS tax types to the correct GL account** - This step ensures TDS amounts are posted to the right account. For more information, see [Mapping TDS Tax Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1528941496.html).
    
3.  **Set up section codes for TDS** - Section codes help categorize TDS transactions. For more information, see [Managing Section Codes for TDS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1528957737.html).
    
4.  **Create TDS tax rules** - These rules define how TDS is calculated for each transaction. For more information, see [Creating Rules for TDS Tax Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1528944307.html).
