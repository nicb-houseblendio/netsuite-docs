Under CGST rules, any taxable transaction needs a Unique Quantity Code (UQC) or a quantity unit description. A UQC is an abbreviation for a unit of measurement, such as kgs for kilograms or mtr for meter. When you set up a UQC record in NetSuite, use the first three letters of the measurement as the code.

Note:

To set a UQC, you must enable the Multiple Units of Measure feature. For more information about the feature, see [Multiple Units of Measure](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N2211898.html).

#### To create a UQC unit type:

1.  Go to _Lists > Accounting > Units of Measure > New_.
    
2.  On the Units Type page, in the **Type Name** field, enter the type of unit you're creating.
    
3.  In the **Name** column, enter a name for the unit you want to create, such as Box.
    
4.  In the **Plural Name** column, enter the plural name for the unit.
    
5.  In the **Abbreviation** column, enter the abbreviation for the singular unit.
    
6.  In the **Plural Abbreviation** column, enter the abbreviation for the singular unit.
    
7.  In the **Conversion Rate** column, enter the quantity that matches one of the base units.
    
8.  In the **Base Unit** column, check the box this unit will be used to define other units in this group. When entering multiple units, you must select at least one as the base unit.
    
9.  In the **India UQC** column, select the unique quantity code for the unit.
    
10.  Click **Save**.
