The India Localization SuiteTax Engine SuiteApp lets you view tax details for each tax type using saved searches. This helps you review tax details for your transactions before paying taxes or filing returns.

To view tax details for your transactions, use the following default saved searches or create your own. Only administrators can view TDS tax details.

You can copy the default saved searches or make new ones. Ensure to add the required filters to get the correct data.

-   **India TDS Tax Details**\- This saved search lists tax details for each vendor bill.
    
-   **India TDS Tax Adjustments**\- This saved search displays tax adjustments for each journal entry.
    
-   **India Vendor Wise Transaction**\- This saved search lists transactions by vendor.
    

Tip:

If you don't see the default saved searches, make sure all filters are set to **All**, especially the Use filter.

To view default TDS Tax Details saved searches, go to Reports > Saved Searches > All Saved Searches and click **View**.

Note:

When you install the India Localization SuiteTax Engine SuiteApp, all TDS Tax Details saved searches are available.

#### To copy a default TDS saved search:

1.  Go to Lists > Search > Saved Searches.
    
2.  In the Saved Searches list, click **Edit** next to the saved search you want to copy.
    
    To create a new saved search, click **New Saved Search** and select a search type.
    
    Note:
    
    If you don't see this saved search, make sure your filters are set to **All**, especially the Use filter. Click the plus icon next to the Filters header to see the filters.
    
3.  In the **Search Title** field, enter a name for the saved search.
    
4.  Click the **Criteria** subtab.
    
5.  Check the **Use Expressions** box for the India TDS Tax Details saved search. For the India TDS Tax Adjustments saved search, clear the **Use Expressions** box.
    
6.  Add the required filters. For more information, see [TDS Saved Search Filters](#subsect_50172752747).
    
7.  Click **Save As** to save your copy of a saved search, or click **Save** if you're creating a new one.
    

To see the transaction results, click **Preview**. In OneWorld accounts, you'll only see transactions for subsidiaries you have permission to access.

## TDS Saved Search Filters {#subsect_50172752747}

The following table displays the filters you need to include your transactions in saved search results and to view their tax details.

| Saved Search Title | Filter | Values (Description and Expressions) |
| --- | --- | --- |
| India TDS Tax Details | Type | 
-   **Value**: is, Bill
-   **: And**

 |
| INDIA TAX SECTION CODE (Custom Column) Fields | 

-   **Filter**: Name
-   **Value**: is not empty
-   **: And**

 |
| Subsidiary Fields | 

-   **Filter**: India
-   **: And**

 |
| Formula (Text) | 

-   **Parens**: (
-   **Values**:is, Tax Deduction at Source
-   **Formula**: {taxdetail.taxtype}
-   **: Or**

 |
| Formula (Text) | 

-   **Value**:is, TDS Education Cess
-   **Formula**: {taxdetail.taxtype}
-   **: Or**

 |
| Formula (Text) | 

-   **Value**:is, TDS Education SH Cess
-   **Formula**: {taxdetail.taxtype}
-   **: Or**

 |
| Formula (Text) | 

-   **Values**:is, Surcharge
-   **Formula**: {taxdetail.taxtype}
-   **Parens**: )

 |
| India TDS Tax Adjustments | Type | 

-   **Value**: is, Journal

 |
| Journal Is TI (Custom Body) | 

-   **Value**: is, TI

 |
| Vendor (Line) Fields | 

-   **Value**: is, Empty

 |
| India Vendor Wise Transaction | Type | 

-   **Value**: any of, Bill, Bill Credit, Journal, Return Authorization, System Journal, Vendor Return Authorization

 |

After you review the tax details for your bills, you can create TDS challan vouchers to submit taxes to the tax authority. For more information, see [Creating TDS Challan Vouchers](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1536798316.html).
