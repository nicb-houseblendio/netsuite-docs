You must complete the following prerequisites before installing the India Localization SuiteTax Engine SuiteApp.

1.  **Enable the SuiteTax feature** - In NetSuite, go to Setup > Company > Enable Features. On the **Tax** subtab, check the **SuiteTax** box.
    
2.  **Confirm that SuiteTax setup is complete** - In NetSuite, go to Setup > Tax > SuiteTax Migration. Click **Confirm SuiteTax Setup** to confirm that the SuiteTax setup is complete.
    
3.  **Enable the SuiteCloud features** - In NetSuite, go to Setup > Company > Enable Features. On the **SuiteCloud** subtab, check the following boxes:
    
    -   **Custom Records**
        
    -   **Custom Transactions**
        
4.  **Set up accounting periods** - In NetSuite, go to Setup > Accounting > Manage G/L > Manage Accounting Periods to set up accounting periods. You'll need this for GST and TDS features.
    
5.  **Create sales and purchase accounts** - You'll need these accounts to use GST and TDS features.
    
6.  **Set up a tax agency for each nexus** - Ensure to set up the correct tax agencies for all your nexuses before creating any transactions. For more information, see [Setting Up Nexuses in SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4296038572.html).
    

After you've finished the prerequisites, install the India Localization SuiteTax Engine SuiteApp. For more information, see [Installing the India Localization SuiteTax Engine SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0213044826.html).
