The India Localization SuiteTax Engine SuiteApp provides you a default template to generate E-Way Bills using IRN. To customize the template, create a new template. Don't edit the default template. Deactivate the default template before you mark the new template as active.

Note:

You can only have one active template at a time.

#### To customize and activate E-Way Bill by IRN template:

1.  Go to Customization > Lists, Records, & Fields > Record Types.
    
2.  Find **E-Way Bill by IRN Template** and click **List**.
    
3.  To customize a default template, create a new template and mark it as active.
    
4.  Click **Save**.
