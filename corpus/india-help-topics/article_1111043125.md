India GST lets you override tax information on the **Tax Details** subtab if you have the Tax Details Tab permission set to at least **Edit**. For more information about SuiteTax permissions, see [Roles and Permissions in SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4822121243.html).

#### To override the tax information:

1.  Click the **Tax Details** subtab.
    
2.  Check the **Tax Details Override** box.
    
3.  In the Taxes section, select the Tax Details Reference ID you want to change.
    
4.  Modify the values in the **Tax Type**, **Tax Code**, **Tax Basis**, **Tax Rate**, and **Tax Amount** columns for existing tax lines. All tax information fields are required.
    
5.  Click **OK**.
    

You can't preview tax if the **Tax Details Override** box is checked. If you clear the box, the calculated tax will be deleted.

For more information about using the Tax Details Override feature, see [Tax Details on Transactions in SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4283867856.html).
