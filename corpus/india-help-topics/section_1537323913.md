Assigning default India HSN (Harmonized System of Nomenclature) and SAC (Services Accounting Code) codes to items, accounts, and shipping items is essential for GST compliance.

The India Localization SuiteTax Engine SuiteApp uses these default codes and other transaction details to determine the correct GST tax rate rule for each transaction.

Setting default HSN or SAC codes ensures the appropriate tax codes are automatically populated on transactions. This streamlines GST reporting, reduces manual errors, and still allows for overrides when necessary.

To assign default HSN and SAC Code, read the following topics:

-   [Assigning Default India HSN and SAC Codes to Account Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_21162615419.html).
    
-   [Assigning Default India HSN and SAC Codes to Item Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1111041500.html).
    
-   [Assigning Default India HSN and SAC Codes to Shipping Item Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1111041154.html).
    

To create, edit, delete, or inactivate these code, see [Managing HSN or SAC Codes for India GST](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1533876290.html)
