To set up India Goods and Services Tax (GST), follow these steps in order:

1.  Set up India GST tax registrations for your vendors and customers. For more information, see [Setting Up India GST Tax Registrations for Entities](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1534401707.html).
    
2.  Assign a default India tax nature to your items. For more information, see [Assigning India Tax Nature to Items](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1549243345.html).
    
3.  Assign tax accounts to each GST type. For more information, see [Assigning Tax Accounts to India GST Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1534231174.html).
    
4.  Set up HSN and SAC codes for GST. For more information, see [Managing HSN or SAC Codes for India GST](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1533876290.html).
    
5.  Create GST tax rate rules. For more information, see [Creating India GST Tax Rate Rules](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1534232862.html).
    
6.  Set up Unique Quantity Code (UQC) for GST. For more information, see [Setting Up Default Unique Quantity Code (UQC) for Items](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1534403824.html).
