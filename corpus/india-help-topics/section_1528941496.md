The India Localization SuiteTax Engine SuiteApp uses TDS tax type mapping to deposit TDS into the correct GL account. Only users with the Administrator role can create or edit tax type mappings.

The SuiteApp supports the following TDS tax types for mapping:

-   Tax Deduction at Source
    
-   TDS Education Cess
    
-   TDS Secondary Education Cess
    
-   TDS Surcharge
    

You can map TDS tax types using either the Tax Type page or the Configuration page. The Tax Type page enables mapping all supported TDS tax types. The Configuration page is used specifically for mapping the Tax Deduction at Source tax type and lets you include a section code.

For more information, see [Tax Type Mapping on the Configuration Page](#subsect_52105214247).

Note:

The India Localization SuiteTax Engine only supports default tax types. Custom tax types aren't supported.

## Tax Type Mapping on the Tax Type Page {#subsect_73145819459}

On the Tax Type page, you can map all TDS tax types using the following fields.

-   Nexus - tax jurisdiction
    
-   Tax type - all TDS tax types supported
    
-   Tax on purchase - account for TDS deposits
    

#### To map a TDS tax type: {#procedure_0329114253}

1.  Go to _Setup > Tax > Tax Type_.
    
2.  Click **Edit** beside the tax type you want to edit.
    
3.  In the **Name** field, edit the name if needed.
    
4.  Click the **Accounts** subtab and select:
    
    -   **Nexus** - Select a nexus.
        
    -   **Tax On Purchase** - Select the account you want to use for TDS deposits.
        
5.  Click **Save**.
    

## Tax Type Mapping on the Configuration Page {#subsect_52105214247}

On the Configuration page, you can only map the **Tax Deduction at Source** tax type. This mapping overrides any details set on the Tax Type page.

The fields used for mapping includes the following:

-   Nexus - tax jurisdiction
    
-   Tax type - only Tax Deduction at Source is supported
    
-   Section code - the relevant section code for TDS
    
-   Tax on purchase - account for TDS deposits
    

### Prerequisites for Setting Up the Custom GL Plug-in {#subsect_1028032539}

Before tax type mapping, you must set up the I **India Custom GL** plug-in to ensure TDS is deposited to the correct account.

1.  **Enable the Custom GL Lines feature** - In NetSuite, go to Setup > Company > Enable Features.
    
    #### To enable the Custom GL Lines feature:
    
    1.  Go to Setup > Company > Enable Features.
        
    2.  Click the **SuiteCloud** subtab, under the SuiteGL section, check the **Custom GL Lines** box.
        
    3.  Click **Save**.
        
    
2.  **Configure the India Custom GL Plug-in** - In NetSuite, go to Customization > Plug-ins > Plug-in Implementations and complete the procedure:
    
    #### To configure the India Custom GL Plug-in: {#procedure_0424105705}
    
    1.  Go to Customization > Plug-ins > Plug-in Implementations.
        
    2.  Click **Configure**.
        
    3.  Check the **Asynchronous** box.
        
    4.  On the **Rules** subtab, from the **Transaction Type** list, select **Bill**.
        
    5.  Under the **Subsidiaries** field, check the **All** box.
        
    6.  Click **Save**.
        
    
3.  **Enable the India custom GL plug-in** - In NetSuite, go to Customization > Plug-ins > Manage Plug-ins.
    
    #### To enable the India Custom GL plug-in:
    
    1.  Go to Customization > Plug-ins > Manage Plug-ins.
        
    2.  Check the **India Custom GL Plugin** box.
        
    3.  Click **Save**.
        
    

#### TDS Entries for Multiple Books {#subsect_0526110809}

If the Multiple Books feature is enabled, the **India Custom GL Plug-in** creates a single TDS custom GL entry in the primary accounting book. The entry remains non-book-specific, so NetSuite doesn't add duplicate entries to secondary books.

NetSuite applies the same entry to each secondary book using that book's currency and accounting context. However, the following conditions apply.

-   The **India Custom GL Plug-in** is active.
    
-   The Multiple Books feature is enabled.
    
-   TDS and exchange rate data apply to the transaction.
    

### Mapping the Tax Deduction at Source Tax Type {#subsect_1028033756}

After you set up the India custom GL plug-in, follow these steps to map the TDS tax type.

#### To map Tax Deduction at Source tax type: {#procedure_36105904294}

1.  Go to Setup > India Localization > Configuration.
    
2.  Click the **Tax Deduction at Source** subtab.
    
3.  In the **Nexus** column, select a nexus.
    
4.  In the **Tax Type** column, select **Tax Deduction at Source**.
    
5.  In the **Section Code** column, select a section code.
    
6.  In the **Tax On Purchase** account, select the account you want to use for TDS deposits.
    
7.  Click **Add**.
    
8.  Click **Save**.
    

After you mapping TDS tax types, set up section codes for TDS. For more information, see [Managing Section Codes for TDS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1528957737.html).
