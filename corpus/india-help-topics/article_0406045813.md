The following list contains best practices for using the India Localization SuiteTax Engine SuiteApp:

-   If you let transactions happen outside of posting periods, enable the **Allow Transaction Date Outside of Posting Period** preference. To enable the preference, go to Setup > Accounting > Accounting Preferences > General, then check the **Allow Transaction Date Outside of Posting Period** box.
    
-   To ensure tax is calculated correctly for shipping or handling, enable the Charge for Shipping or Charge Handling Separate From Shipping preference.
    
-   If you have vendor bills with multiple tax rate rules and different tax rates in a financial year, delete them.
    
-   If vendor bills are already created for a vendor, don't edit the **PAN Availability** and **Vendor Type** field values.
    
-   To ensure invoices and vendor bills save successfully, set the **Maximum Entries in Dropdown** field value to **50** or more. You can manage this at the company level by going to Setup > Company > Preferences > General Preferences,or at the user level by going to Home > Set Preferences.
    
-   If you're using electronic invoicing, keep these best practices in mind:
    
    -   Install the Electronic Invoicing and NetSuite SuiteApps License Client SuiteApps.
        
    -   Contact ClearTax for the webservice URL, connection token, and owner ID details.
        
    -   Set up the webservice URL and connection token in the India GSP Configuration record. You should add the owner ID details in the subsidiary record.
        
    -   Check if the e-document templates are already in your account. If not, go to Setup > India Localization > India Localization Components and install them manually.
        
        To customize the e-document templates, create a new template and customize it. Don't edit the default templates.
        
    -   To customize the e-Way Bill by IRN template, create a new template and customize it. Don't edit the default e-Way Bill by IRN template.
        
    -   Assign subsidiaries to e-document templates and sending methods by going to Setup > E-Documents.
        
    -   In customer records, assign an e-document package and update the e-document email recipients.
        
    -   In transaction records, select an e-document template and choose **email** as the sending method.
        
    -   After you generate an e-document, certify it and send it to your customers.
        
        Note:
        
        If you've created a custom form, ensure it includes the fields required for generating, certifying, and sending e-documents.
        
-   To generate an e-document, ensure the item name and description aren't split into multiple lines and don't have any special characters.
    
-   If you want to apply a vendor exemption rule to transactions that meet the criteria, create the rule before you create transactions in an accounting period. By doing so, the rule applies to all relevant transactions.
    
-   Don't edit an invoice if it's already approved and tax has been calculated.
    
-   Use the Localization Assistant SuiteApp to install the required SuiteApps and manage their localization components.
    
-   The TDS calculation method for tax rules with a document threshold was updated in India Localization SuiteTax Engine SuiteApp version 5.00.0. To use the new method for existing bills (where only the document threshold has reached), create new bills or update the existing ones.
