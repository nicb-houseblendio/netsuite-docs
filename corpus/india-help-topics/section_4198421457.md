## Overview {#subsect_0619115147}

The following help topics provide information about NetSuite features that are specific to companies doing business in India. You can set up the NetSuite International edition with features and reports tailored for Indian businesses.

If you want to learn more about localized NetSuite editions or setting up accounts and subsidiaries, read the following help topics:

-   [NetSuite Editions Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N270055.html)
    
-   [Set up NetSuite OneWorld](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N268052.html)
    
-   [Creating Subsidiary Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N272471.html) - for NetSuite OneWorld accounts.
    
-   [Introduction to NetSuite OneWorld](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N266468.html) - for companies using NetSuite across multiple subsidiaries and countries.
    

General NetSuite features are covered in other chapters and topics.

## General Setup {#subsect_0619115429}

If you want information about NetSuite features, SuiteApps, and preferences for users in India, read the following topics:

-   [India Account Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156505353585.html) - Provides an overview of NetSuite features you can enable and SuiteApps you can install for your business in India.
    
-   [Setting Up India-specific Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156507253436.html) - Set up your NetSuite company and user preferences for India such as date, currency, language, time zone, and support for India phone numbers and addresses.
    

## Functional Areas {#subsect_0619115506}

You can enable and get access to different features in the following functional areas:

-   [Taxation](#subsect_0619115906)
    
-   [Order Management](#subsect_0619115930)
    

For information about installing a SuiteApp, see [Installing a Bundle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3395142.html).

For information about enabling NetSuite features, see [Enabling Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N232138.html).

Important:

If you don't have enough permissions to install SuiteApps or enable features, contact your account administrator.
