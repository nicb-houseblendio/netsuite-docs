To use India electronic invoicing features, review the following prerequisites:

1.  Install the Electronic Invoicing SuiteApp from the SuiteBundler -
    
    -   Search for and install the latest version of the Electronic Invoicing SuiteApp.
        
    -   Ensure all prerequisites for electronic invoicing are met before installation. For more information, see [Installing the Electronic Invoicing SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4592549826.html#bridgehead_4580987212)
        
2.  Verify the Localization components -
    
    1.  Go to Setup > India Localization > Localization Components.
        
    2.  Confirm that all required localization components (such as e-document packages and templates) are installed and up to date.
        
    3.  Review the status of each component:
        
        -   **Installed** - Component is ready to use.
            
        -   **Installation Failed** - Review the installation log and retry as needed.
            
        -   **SuiteApp Unavailable** - Ensure the SuiteApp is installed and updated.
            
        
        For more information, see [Viewing India Electronic Invoicing Components](#subsect_0627125454)
        
3.  Use the Localization Assistant SuiteApp if you need to install or manage additional components.
    
4.  If an invoice contains lot numbered or serialized inventory items, you must enable the following features for e-document generation and certification.
    
    -   Serialized Inventory
        
    -   Lot Tracking
        
        To enable them, go to Set Up > Company > Enable Features. On the **Items & Inventory** subtab, check the **Serialized Inventory** and **Lot Tracking** boxes.
        

## Viewing India Electronic Invoicing Components {#subsect_0627125454}

To view the e-document packages (India electronic invoicing components), go to Setup > India Localization > Localization Components.

The Localization Components page shows the installation status for each electronic invoicing component.

You can manually install or reinstall templates as required. However, ensure that you have the latest version of the Electronic Invoicing SuiteApp before installing. To customize the e-document templates, create a new one and customize it. Don't customize the default templates.

You can also install e-document packages and manage the components of localization or partner SuiteApps using the Localization Assistant SuiteApp.

The India Localization Components page displays the following information:

| Field | Description |
| --- | --- |
| Component Name | This column displays the name of the localization component. |
| Status | This column displays the current status of the component. Following are the statuses available:
-   **Installed** - This status appears if the component was installed successfully.
-   **Installation Failed** - This status appears if the component hasn't been installed. Click the Installation Failed link or check the installation log for more details.
-   **SuiteApp Unavailable** - This status appears if the target SuiteApp isn't installed yet or hasn't been updated to the latest version.

 |
| Last Updated Date | This column displays when the component was last updated. |
| Last Updated By | This column displays who last updated the component. |
| Action | This column displays what action you can take on the component. |
