The India Localization SuiteTax Engine uses TDS tax rate rules to calculate TDS on vendor bills. You can create TDS tax rules only if you have the Administrator or India Tax Manager role.

The SuiteApp selects the appropriate TDS tax rule for each item in a vendor bill based on:

-   Vendor type
    
-   Section code assigned to the item
    
-   Transaction date
