Assigning tax accounts to a GST type means selecting the accounts where GST will be deposited. The SuiteApp uses GST tax types to track GST in your chart of accounts.

#### To assign tax accounts for a GST type:

1.  Go to _Setup > Tax > Tax Types_.
    
2.  Click **Edit** next to the tax type you want to add tax accounts to.
    
3.  Click the **Accounts** subtab.
    
4.  Select a nexus. The list only shows nexuses for India.
    
5.  Select the **Tax on Sales** account.
    
6.  Select the **Tax on Purchase** account.
    
7.  Click **Save**.
    

The following table shows the different GST tax types, their descriptions, and setup instructions.

| India GST Tax Type | Description |
| --- | --- |
| CGST | Use this type for regular Central Goods & Services Tax (CGST), which covers both sales and purchases. You must set up tax accounts for both. |
| IGST | Use this type for regular Integrated Goods & Services Tax (IGST), which applies to both sales and purchases. You must set up tax accounts for both. |
| SGST | Use this type for regular State Goods & Services Tax (SGST), which applies to both sales and purchases. You must set up tax accounts for both. |
| UTGST | Use this type for regular Union Territory Goods and Services Tax (UTGST), which covers both sales and purchases. You must set up tax accounts for both. |
| GST Cess | Use this type for regular GST Cess, which applies to both sales and purchases. |
| NonRecovery\_CGST | Use this type for purchase transactions with nonrecoverable CGST. The tax amount gets added to the item's or expense's cost. |
| NonRecovery\_IGST | Use this type for purchase transactions with nonrecoverable IGST. The tax amount gets added to the item's or expense's cost. |
| NonRecovery\_SGST | Use this type for purchase transactions with nonrecoverable SGST. The tax amount gets added to the item's or expense's cost. |
| NonRecovery\_UTGST | Use this type for purchase transactions with nonrecoverable UTGST. The tax amount gets added to the item's or expense's cost. |
| NonRecovery\_GSTCess | Use this type for purchase transactions with nonrecoverable GST Cess. The tax amount gets added to the item's or expense's cost. |
| Reverse Charge\_CGST | Use this type for CGST under reverse charge. It's a default recoverable tax for purchases only. You must set up tax accounts for both purchases and sales. |
| Reverse Charge\_IGST | Use this type for IGST under reverse charge. It's a default recoverable tax for purchases only. You must set up tax accounts for both purchases and sales. |
| Reverse Charge\_SGST | Use this type for SGST under reverse charge. It's a default recoverable tax for purchases only. You must set up tax accounts for both purchases and sales. |
| Reverse Charge\_UTGST | Use this type for UTGST under reverse charge. It's a default recoverable tax for purchases only. You must set up tax accounts for both purchases and sales. |
| Reverse Charge\_GSTCess | Use this type for GST Cess under reverse charge. It's a default recoverable tax for purchases only. You must set up tax accounts for both purchases and sales. |
| Offset\_CGST | Use this type to offset the Tax on Purchase account for your reverse charge CGST that's nonrecoverable. It's always used with ReverseCharge\_CGST and Nonrecovery\_CGST. You must set up the tax account for purchases. |
| Offset\_IGST Note: When you pick a Tax on Purchase account for any offset tax type, make sure it's the same as the one you set up for your reverse charge tax types. | Use this type to offset the Tax on Purchase account for your reverse charge IGST that's nonrecoverable. It's always used with ReverseCharge\_IGST and Nonrecovery\_IGST. You'll need to set up the tax account for purchases. |
| Offset\_SGST | Use this type to offset the Tax on Purchase account for your reverse charge SGST that's nonrecoverable. It's always used with ReverseCharge\_SGST and Nonrecovery\_SGST. You must set up the tax account for purchases. |
| Offset\_UTGST | Use this type to offset the Tax on Purchase account for your reverse charge UTGST that's nonrecoverable. It's always used with ReverseCharge\_UTGST and Nonrecovery\_UTGST. You must set up the tax account for purchases. |
| Offset\_GSTCess | Use this type to offset the Tax on Purchase account for your reverse charge GST Cess that's nonrecoverable. It's always used with ReverseCharge\_GSTCess and NonRecovery\_GSTCess. You must set up the tax account for purchases. |
