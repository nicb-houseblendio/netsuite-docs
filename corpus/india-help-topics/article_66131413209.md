The India Localization SuiteTax Reports SuiteApp includes the following saved searches. To access these saved searches, go to Lists > Search > Saved Searches. You can use these searches to view transactions in the selected search category.

If you want to customize these default searches, copy a template, and create a new saved search as required.

-   India GSTR9 Table 4 Credit Notes
    
-   India GSTR9 Table 4 Inward Reverse Charge
    
-   India GSTR9 Table 4 Outward B2B
    
-   India GSTR9 Table 4 Outward Export
    
-   India GSTR9 Table 4 Outward SEZ
    
-   India GSTR9 Table 4 Outward B2C
    
-   India GSTR9 Exempted
    
-   India GSTR9 Nil Rated
    
-   India GSTR9 Non-GST Supply
    

For more information about the contents of the GSTR-9 report, see [GSTR-9](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0105105130.html).
