To set up your NetSuite account according to India-specific preferences, you must adjust your NetSuite Company settings.

Note:

Make sure that your NetSuite role has the appropriate permissions to set up company preferences for India.

#### To adjust NetSuite Company settings:

1.  Go to Setup > Company > Company Information and do the following:
    
    1.  In the **Currency** field, set **India Rupee** as your company's base currency.
        
    2.  In the **Time Zone** field, set **(GMT+05:30) Chennai, Kolkata, Mumbai, New Delhi** as your company's time zone. To set your personal time zones at Home > Set Preferences.
        
2.  Go to _Setup > Company > General Preferences_ and do the following:
    
    1.  Set the **Date Format** field to **DD/MM/YYYY**.
        
    2.  Set the **Long Date Format** to **D Month YYYY**.
        

For more information about localizing general account preferences in NetSuite, see [Set Company Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N242860.html).

## Adjusting NetSuite User Preferences {#bridgehead_160804744744}

You should set preferences at the company level. User preferences usually override those set for a role, subsidiary, or company. If a user is linked to a subsidiary, that user will inherit the settings from that subsidiary record. For more information, see [General Personal Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N475661.html).

#### To set user preferences for India account:

1.  Go to Home > Set Preferences.
    
2.  Go to the **General** subtab and set the following locale-specific preferences:
    
    1.  On the **Localization** subtab, set **Language** to **English (International)**.
        
    2.  On the **Localization** subtab, set **Time Zone** to **(GMT+05:30) Chennai, Kolkata, Mumbai, New Delhi**.
        
    3.  On the **Formatting** subtab, set **Date Format** to **DD/MM/YYYY**.
        
        On the **Formatting** subtab, set **Long Date Format** to **D Month YYYY**.
        
3.  Click **Save**.
