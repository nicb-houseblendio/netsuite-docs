After you install the India Localization SuiteTax Report SuiteApp, the India Tax Manager role is added to your account.

Users with the Administrator role can assign this custom role to users who need access to TDS and GST reports, or use it as a template to create custom roles. If you already use custom roles and want to add permissions for TDS and GST reports, use the permissions provided by the Tax Reporting Framework SuiteApp for guidance. For more information, see [Tax Reporting Framework](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158279516034.html#subsect_159004676168).
