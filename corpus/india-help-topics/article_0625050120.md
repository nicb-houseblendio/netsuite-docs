To set up E-Way Bill, you must set up thresholds and configure customer and vendor records.

## Setting Up E-Way Bill Thresholds {#subsect_0625050327}

Set up a threshold rule to help you identify the transactions valid for E-Way Bill generation.

#### To set up E-Way Bill thresholds:

1.  Go to Setup > India Localization > Configuration.
    
2.  Click the **E-Way Bill** subtab.
    
3.  In the E-Way Bill Threshold section, select your preferred threshold basis:
    
    -   **Invoice Total Value** - Select this if you want to use the sum of GST tax basis and GST tax amount as the E-Way Bill threshold, regardless of it's normal or exempted.
        
    -   **Taxable Value** - Select this if you want to use the GST normal rate tax basis as the E-Way Bill threshold.
        
    -   **Taxable and Exempted Value** - Select this if you want to use the GST tax basis as the E-Way Bill threshold, regardless of it's normal or exempted.
        
4.  In the **Threshold Amount** field, enter the threshold amount. The amount must be in your account's base currency.
    
5.  In the **Classification of Supply** field, select how the threshold is classified.
    
6.  Enter the effective period for this E-Way Bill threshold in the **Effective From** and **Valid Until** fields.
    
7.  Click **Save**.
    

## Setting Up Customer and Vendor Records for E-Way Bill {#subsect_0625053011}

Set up the customer or vendor record under India subsidiary for E-Way Bill generation. The default address needs a valid state and PIN for E-Way Bill details to be validated.

#### To set up a customer or vendor record for E-Way Bill:

1.  Go to Lists > Relationships > Customer or Vendor.
    
2.  Click the Edit link beside the customer or vendor record.
    
3.  Click the **Financials** subtab.
    
4.  Edit your default shipping or billing address.
    
5.  In the **State** field, select a valid state. If the entity's registration type is **Overseas**, select **Other Countries**.
    
6.  In the **PIN** field, enter the 6-digit numeric PIN code for your default address. If the entity's registration type is **Overseas**, use **999999** as the PIN.
    
7.  Click **Save**.
