After exporting your India GST report from NetSuite, you must submit the data to the Indian tax authority through the GST portal ([www.gst.gov.in](https://www.gst.gov.in/)). The portal supports both online and offline filing, depending on the return type. This guide explains how to use India GST reports in NetSuite for filing GSTR-1, GSTR-3B, and GSTR-9 returns.

Note:

Always verify the data in the reports before submitting to your tax authority.

## Filing GSTR-1 Tax Returns {#subsect_156386184361}

GSTR-1 returns require uploading data in JSON format. The India GST portal ([www.gst.gov.in](https://www.gst.gov.in/)) provides an offline utility to convert CSV files to the required format.

#### To file GSTR-1:

1.  Download the GST Offline Tool.
    
    Obtain the latest version (such as V2.2.9) from the India GST portal.
    
2.  Export the report from NetSuite.
    
    Export your India GST report in CSV format. For exporting the report, see [Viewing and Exporting India GST Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156384355710.html).
    
3.  Convert CSV to JSON:
    
    1.  Open the GST Offline Tool.
        
    2.  Upload your CSV file.
        
    3.  Go to View Summary > Generate File > Save to create a JSON file.
        
4.  Upload the report to the India GST Portal.
    
    Log in to the GST portal and upload the generated JSON file for validation and submission.
    

## Filing GSTR-3B Tax Returns {#subsect_156386211842}

GSTR-3B returns require manual data entry on the GST portal. The exported report from NetSuite will help you fill in the required fields.

#### To file GSTR3B:

1.  Export the GSTR3B tax report.
    
    For more information, see [Viewing and Exporting India GST Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156384355710.html).
    
2.  Log in to the India GST portal.
    
    Access the portal and go to Services > Returns > Returns Dashboard.
    
3.  Select the return filing period.
    
4.  Enter data manually.
    
    Select GSTR-3B and manually input the data from your NetSuite report.
    
5.  Review and submit.
    
    Verify all entries before submitting your return.
    

## Filing GSTR-9 Tax Returns {#subsect_26201344791}

GSTR-9 is the annual return and must be submitted in JSON format using the GSTR-9 Offline Tool.

#### To file GSTR-9: {#procedure_0107081447}

1.  Export and convert the report.
    
    Ensure your GSTR-9 report is in JSON format. If exported as a DAT file, convert it to JSON.
    
2.  Download the GSTR-9 Offline Tool from [Goods and Services Tax](https://www.gst.gov.in/download/gstr9) portal.
    
    Obtain version V1.8 from the GST portal.
    
3.  Import and validate:
    
    1.  Open the GST Offline Tool [Goods and Services Tax](https://www.gst.gov.in/download/gstr9).
        
    2.  Go to the **Home** tab and select **Open Downloaded GSTR-9 JSON File**.
        
    3.  Import your report and click **OK**.
        
    4.  Use **Validate Sheet** to check for errors.
        
    5.  Submit the return.
        
        After validation, upload the JSON file to the GST portal ([Goods and Services Tax](https://www.gst.gov.in/download/gstr9)) for submission.
