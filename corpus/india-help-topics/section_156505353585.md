Setting up an account for a business in India usually requires you to enable several features and install some additional SuiteApps.

## Enabling Features for India Account {#bridgehead_160804487971}

Some features in your NetSuite account can be helpful for businesses in India. Enable Company, Tax, and SuiteCloud features to make your NetSuite account more suited to business requirements in India. For information about features and prerequisites for specific product areas, see [Functional Areas](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4198421457.html#subsect_0619115506).

Note:

If you don't have sufficient permissions to enable features, contact your account administrator.

#### To enable features:

1.  Go to _Setup > Company > Enable Features_.
    
2.  On the **Company** subtab, go to the International section and check the **Multi-language** and **Multiple Currencies** boxes.
    
3.  On the **Accounting** subtab, do the following:
    
    1.  Go to the Basic Features section and check the **GL Audit Numbering** box.
        
    2.  (Optional) Go to the Advanced Features section and check the **Period End Journal Entries** and **Foreign Currency Variance Mapping** boxes.
        
4.  On the **SuiteCloud** subtab, enable the desired features on the following subtabs:
    
    -   Suite Builder
        
    -   Suite Script
        
    
    For more information about SuiteCloud features, see [SuiteCloud Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N239332.html).
    
5.  Click **Save**.
    

## Available SuiteApps {#bridgehead_160804630297}

Some additional features require you to install a specific SuiteApp. SuiteApps are apps that add features to NetSuite for certain industries or business needs. For information about the required SuiteApps for specific product areas, see [Functional Areas](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4198421457.html#subsect_0619115506).

The following SuiteApps include features specific to India:

| SuiteApp | Area | Description |
| --- | --- | --- |
| [India Localization SuiteTax Engine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1543359686.html) | Taxation | Provides India-specific tax features such as creating Challan vouchers and calculating taxes for your transactions.
-   TDS - Calculates TDS for your vendor bill transactions.
-   GST - Calculates GST for your sales and purchase transactions.

This SuiteApp also gives you pre-configured tax codes and types you can use for every new nexus you create. |
| [India Localization SuiteTax Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1543360158.html) | Taxation | Provides India-specific tax reports, including TDS and GST reports, to make submissions easier and more accurate. |
| [Electronic Invoicing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4536869488.html) | Order Management | Lets you connect with GST Suvidha Providers for electronic invoicing as required by GST. |
| [Payment Gateway](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3803057063.html) | Order Management | Lets you connect with AsiaPay and AsiaPay External Checkout credit card gateways for India. |
| [Tax Reporting Framework](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1528262949.html) | Taxation (SuiteTax) | Lets finance users and accountants generate localized tax reports. You'll need this SuiteApp to install the India Localization SuiteTax Reports SuiteApp. |
| [NetSuite SuiteApps License Client](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4635371374.html) | SuiteApps | Manages your account's access to electronic invoicing features. When you install it, the NetSuite SuiteApps License Client connects to the NetSuite SuiteApps License Server to get your active license information. |

#### To install a SuiteApp:

1.  Go to _Customization > SuiteBundler > Search & Install Bundles_.
    
2.  Search for the following bundles by name or bundle ID and install them:
    
    -   **Payment Gateway SuiteApp** - Lets you connect with AsiaPay and AsiaPay External Checkout credit card gateways for India.
        
    -   **India Localization SuiteTax** - The following SuiteApps provide India-specific tax features and must be installed in this order:
        
        | Priority | SuiteApp | Bundle ID |
        | --- | --- | --- |
        | 1 | India Localization SuiteTax Engine | 400562 |
        | 2 | Tax Reporting Framework | 237699 |
        | 3 | India Localization SuiteTax Reports | 400554 |
        
3.  On the Bundle Details page, click **Install**.
    

For more information about SuiteApps, see [SuiteApps](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_3134602194.html).

For more information about SuiteApps installation, see [Installing a Bundle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3395142.html).
