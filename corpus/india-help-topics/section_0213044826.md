The India Localization SuiteTax Engine is a free, managed SuiteApp. It is automatically updated when new features or enhancements are released.

Before you install the SuiteApp, complete the following:

-   Contact your NetSuite account manager to provision the India Localization SuiteTax Engine SuiteApp in your account.
    
-   Ensure you have the Administrator role to install the SuiteApp.
    

## Installation Methods {#subsect_1023025013}

You can install the India Localization SuiteTax Engine SuiteApp using one of the following methods:

-   **Using the Localization Assistant SuiteApp** - To install the SuiteApp, follow these steps:
    
    1.  Install the Localization Assistant SuiteApp from the SuiteApp Marketplace. For more information, see [Installing from the SuiteApp Marketplace](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1539799323.html).
        
    2.  So to Setup > Localization Assistant > Manage Localizations.
        
    3.  Follow the steps in the [Managing the Localization SuiteApps](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163092473907.html) topic.
        
-   **Using Search & Install Bundles** - To install the SuiteApp from this page, go to Customization > SuiteBundler > Search & Install Bundles and perform the following steps.
    
    #### To install the India Localization SuiteTax Engine SuiteApp: {#procedure_0213052037}
    
    1.  Go to Customization > SuiteBundler > Search & Install Bundles.
        
    2.  In the **Keywords** field, enter **India Localization SuiteTax Engine**.
        
    3.  Click **Search**.
        
    4.  Click the **India Localization SuiteTax Engine SuiteApp** link with bundle ID 400562.
        
    5.  On the Bundle Details page, click **Install**.
        
    

After you've installed the India Localization SuiteTax Engine SuiteApp, set up the India Localization SuiteTax Engine. For more information, see [Setting Up the India Localization SuiteTax Engine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0213044858.html).

If you need to uninstall the India Localization SuiteTax Engine SuiteApp, see [Uninstalling the India Localization SuiteTax Engine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0220055125.html).
