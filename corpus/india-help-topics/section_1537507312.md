The India Localization SuiteTax Engine lets you view tax details for each tax type. You can review them before paying taxes or filing returns.

You can access India GST tax details using an Administrator or India Tax Manager role.

#### To view the India GST Tax Details saved search:

1.  Go to _Reports > Saved Searches > All Saved Searches_.
    
2.  Look for **India GST Tax Details** and click the **View** link.
    
    This saved search provides tax details for both purchase and sales transactions supported by the SuiteApp.
    

Note:

The India GST Tax Details saved search is available upon installing the India Localization SuiteTax Engine SuiteApp.

## Creating a Custom Saved Search for Viewing India GST Details {#subsect_1111043904}

You can create your own GST Tax Details saved search or copy the default **India GST Tax Details** for India GST. On the saved search, set up the filters you need to pull in the correct transactions. For a list of saved search filters, see [India GST Tax Details Saved Search Filters](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1111044448.html).

The India Localization SuiteTax Engine provides the default **India GST Tax Details** saved search to view tax details.

#### To create a custom transaction saved search for India GST tax details:

1.  Go to _Lists > Search > Saved Searches_.
    
2.  In the Saved Searches list, click the Edit link for India GST Tax Details.
    
    Note:
    
    If you don't see this saved search in the list, make sure your filters are set to **All**, especially the Use filter. To see the filters, click the **Plus** icon next to the Filters header.
    
    If you want to create your own saved search, click **New Saved Search** and select the transaction type.
    
3.  On the Saved Transaction Search page, enter a name for your saved search copy.
    
4.  On the **Criteria** subtab, check the **Use Expressions** box, then add your filtering criteria.
    
    For the list of default filters, see [India GST Tax Details Saved Search Filters](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1111044448.html).
    
5.  Click **Save As** to save your copy, or click **Save** if you're making a new saved search.
    
    If you want to view the results, click **Preview**. The search results include purchase and sales transactions for subsidiaries your role can access.
