The India Localization SuiteTax Engine SuiteApp provides a print voucher template called **Standard India TDS Challan Voucher PDF/HTML**. You can use the standard print voucher template provided, or customize it to fit your requirements.

#### To customize the standard template:

1.  Go to Customization > Forms > Advanced PDF/HTML Templates.
    
2.  Select **Standard India TDS Challan Voucher PDF/HTML Template**.
    
3.  Edit the template as required.
    
4.  Click **Save**.
    

Make sure you use the same customized template in the Challan Voucher form.
