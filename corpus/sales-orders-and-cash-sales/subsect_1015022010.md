You can only delete a grid item template that isn't being used in any order transaction.

If you're using a Sales Person role, you can't delete grid item templates. For more information, see [Roles and Permissions for Grid Order Management](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1505110051.html).

Use the following procedure to delete a grid item template.

#### To delete a grid item template: {#procedure_158029249809}

1.  Go to the Grid Templates page.
    
    -   If you are using an Administrator role, go to Lists > Grid Order Entry > Grid Templates.
        
    -   If you are using other roles, read [Roles and Permissions for Grid Order Management](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1505110051.html).
        
2.  On the Grid Templates list, click **Edit** or **View** beside the grid item template you want to delete.
    
3.  Click **Delete**.
