Items must meet certain criteria to be added to order guides. This section lists the criteria for adding items to order guides.

In the Order Guide Template page, items must meet these criteria:

-   Items must be a supported type
    
-   Items must be applicable to the selected subsidiary
    
-   Items must have the **Display in Web Store** box checked
    
-   Items must be active
    

When creating an order guide for a customer from the Create Order Guide page, items must meet these criteria:

-   Items are of a type supported by order guides
    
-   Items applicable to the selected subsidiary of the customer
    
-   Items that have the **Display in Web Store** box checked
    
-   Items must have a base price or absolute price defined in the customer's default currency
    
-   Items that are not inactive
    

When creating an order guide from the Order Guide Template page, items must meet these criteria:

-   Items are of a type supported by order guides
    
-   Items applicable to the selected subsidiary of the customer
    
-   Items that have the **Display in Web Store** box checked
    
-   Items that have a base price or absolute price defined in the default currency of the customer
    
-   Items that are not inactive
    

In the Order Guide Entry popup, items must meet these criteria:

-   Items must be applicable to the customer's subsidiary
    
-   Items must have a quantity greater than zero
    
-   Items that are not inactive
    

Note:

Don't remove an item's base price after adding it to an order guide. Otherwise, you won't be able to add the item to the sales order.

The current price won't be shown in these cases:

-   If the item price isn't defined in customer's price level currency
    
-   If you change the default currency in the **Currency** field of the sales order's **Accounting** subtab
