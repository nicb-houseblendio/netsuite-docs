The Contract Renewals SuiteApp works with the SaaS Metric feature. If you enable the SaaS Metrics feature, SaaS Metric Commitment Start Date and SaaS Metric Commitment End Date fields are added to the transaction header or line items on Contract Renewals custom transaction forms. These date fields enable collecting and tracking of Contract Renewals transaction and subscription data for SaaS metrics reporting. For more information, see [SaaS Metric](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_35114359424.html) feature.

When the SaaS Metric feature is enabled, the following date fields will be available.

| Date field | Action | Transactions displaying the date field in the header | Transactions displaying the date field in line items | Validations | If date field is blank |
| --- | --- | --- | --- | --- | --- |
| **SaaS Metric Commitment Start Date** | Enter the date when the customer commits to ordering items or using services. | 
-   Return Authorization
-   Credit Memo
-   Cash Refund

 | 

-   Return Authorization
-   Credit Memo
-   Cash Refund
-   Sales Order
-   Invoice
-   Cash Sale

 | 

-   SaaS Metric Commitment Start Date must be before the SaaS Metric Commitment End Date, in both transaction header and line items.
-   SaaS Metric Commitment Start Date must be on or before the transaction Start Date.
-   In line items, SaaS Metric Commitment Start Date must be on or before contract item Start Date.

 | If SaaS Metric Commitment Start Date is blank in the header or line item when you save, the system fills it with the earliest date from either the form creation date, transaction date, or Start Date. |
| **SaaS Metric Commitment End Date** | Enter the date when the customer stops ordering items or using services. | 

-   Return Authorization
-   Credit Memo
-   Cash Refund

 | 

-   Return Authorization
-   Credit Memo
-   Cash Refund
-   Sales Order
-   Invoice
-   Cash Sale

 | 

-   SaaS Metric Commitment End Date must be on or before the transaction End Date.
-   In line items, SaaS Metric Commitment End Date must be on or before contract item End Date.

 | If the SaaS Metric Commitment End Date is blank in the header or line item when you save, the system fills it with the date of the End Date. If no End Date is specified, SaaS Metric Commitment End Date is left blank. |
