You can only use one order guide when adding items to a sales order. But you can switch to a different order guide when editing the sales order. You can set the quantity and price of items before adding them to the transaction.

#### To use order guides on transactions:

1.  Create or edit a sales order by doing one of the following:
    
    -   To create a sales order, go to _Transactions > Sales > Enter Sales Orders_.
        
    -   To edit a sales order, go to _Transactions > Sales > Enter Sales Orders > List_, and then click **Edit** next to the transaction you want to update.
        
2.  On the sales order page, from the **Customer** list, select the customer.
    
3.  From the **Subsidiary** field, select the subsidiary.
    
4.  Click **Order Guide**.
    
5.  In the Order Guide Entry popup, select the order guide you want to use.
    
    Note:
    
    If the customer has a preferred order guide for the subsidiary, NetSuite automatically adds those items. For more information about preferred order guides, see [Creating Order Guides](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1553539698.html).
    
    You'll see a list of unique items from the order guide.
    
6.  In the **Quantity** column, enter the quantity.
    
    Tip:
    
    You can use keyboard shortcuts to move between and edit the order guide fields. See [Keyboard Shortcuts for Order Guides](#bridgehead_1553543248).
    
7.  Press **Enter** to move to the next row and then enter a new quantity.
    
    Repeat this process for each item you want to add.
    
8.  (Optional) You can also add more details for each item:
    
    -   In the **Current Price** column, enter the item price.
        
        The transaction calculates item amounts based on price and quantity.
        
    -   In the **UOM** column, select the unit of measure.
        
9.  After updating the items, click **Save**.
    
    Tip:
    
    You can click **Save** right after entering a quantity. The quantity is saved automatically, no need to press any other keys.
    
    The sales order is now saved.
    
    For detailed instructions on creating sales order transactions, see [Creating Sales Orders](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1216500.html).
    

## Keyboard Shortcuts for Order Guides {#bridgehead_1553543248}

Here are the keyboard shortcuts for editing order guide items:

| Keyboard Shortcut | What it does |
| --- | --- |
| Tab | Moves to the next field or button. |
| Shift + Enter | Saves the quantity and selects the previous row. |
| Enter | Saves the quantity and selects the next row. |
