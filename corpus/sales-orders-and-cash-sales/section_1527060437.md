## Prerequisite {#bridgehead_1527060998}

Before you set up Item Substitution, make sure you enable the **Multi-Location Inventory** feature in your account. For more information, see [Multi-Location Inventory Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2303574.html#bridgehead_162032472912).

For more information, read [Enabling Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N232138.html).

For more information about installing the SuiteApp, see [Installing the Supply Chain Management SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4258666051.html).

## Enabling Item Substitution on Sales Orders {#bridgehead_1527062466}

After you install the Supply Chain Management SuiteApp, you must enable the Item Substitution feature in your account.

Important:

Access to the Supply Chain Preferences page is supported only for users with Administrator roles.

#### To enable Item Substitution:

1.  Go to Transactions > Management > Supply Chain Management.
    
2.  On the Supply Chain Management page, click the Preferences link.
    
3.  On the Supply Chain Preferences page, click **Edit**.
    
4.  On the **Features** subtab, check the **Item Substitution** box.
    
5.  Click **Save**.
    

When you have enabled the feature in your account, set up role records for anyone who'll use Item Substitution. For more information, see [Roles and Permissions for Item Substitution](#bridgehead_1527063110).

## Roles and Permissions for Item Substitution {#bridgehead_1527063110}

You must enable Item Substitution for all standard and custom roles who'll use the feature. Go to _Setup > Users/Roles > User Management > Manage Roles_. Edit or customize the role to set up the following:

-   On the role record, under the Authentication section, check the **Enable Item Substitution** box.
    
    Note:
    
    Administrators can access Item Substitution records.
    
-   For standard and custom roles that need to be able to set up item substitution on item records, set up the following permission on the role record:
    
    On the **Permissions** subtab:
    
    | Subtab | Record | Level |
    | --- | --- | --- |
    | Custom Record | Item Substitute | Full |
    
-   For standard and custom roles that should be able to use item substitution on item records, set up the following permission on the role record:
    
    On the **Permissions** subtab:
    
    | Subtab | Record | Level |
    | --- | --- | --- |
    | Custom Record | Item Substitute | View |
    

When you have finished setting up the permissions, proceed to [Script Deployment](#bridgehead_1530104727).

## Script Deployment {#bridgehead_1530104727}

After you customize a role to access Item Substitute records, an administrator also needs to add the role to the Item Substitute Transactions CS script deployment.

#### To add access to item substitution records for a role:

1.  Go to _Customization > Scripting > Script Deployments_.
    
2.  Locate the **Item Substitute Transactions CS** script.
    
3.  Click the **Edit** link for the script.
    
4.  On the **Audience** subtab, in the **Roles** field, select the roles you want to have access to item substitution records.
    
    You can select multiple roles by holding down the Ctrl button while selecting each role.
    
5.  When you're done, click **Save**.
    

## Adding Substitute Items to Item Records {#bridgehead_1527065092}

On assembly and inventory item records, you can set up substitutes right on the item record.

#### To add substitute items to an item record:

1.  Go to _Lists > Accounting > Items_.
    
2.  Search for the item you want to add substitutes to.
    
3.  Click the **Edit** link for the item.
    
4.  Click the **Item Substitution** subtab.
    
5.  In the **Substitute Item** dropdown list, select an item and then click **Add**.
    
    Repeat to add more substitute items.
    
6.  When you're done, click **Save**.
    

There's currently no limit to how many substitute items you can add for an item. You can go back to the item record anytime to edit the substitute items.

Note:

If you add Item B as a substitute for Item A, that doesn't mean Item A is also a substitute for Item B. You'll need to go to Item B's record to add Item A as a substitute.

## Customizing the Sales Order Form for Item Substitution {#bridgehead_1527066753}

To work with item substitution on a sales order, you'll need to create a custom sales order form.

#### To customize the sales order form for item substitution:

1.  Go to _Transactions > Sales > Enter Sales Orders_.
    
2.  Click **Customize** at the top of the form and then select **Customize Form**.
    
3.  In the **Name** field, enter a name to identify the form.
    
4.  Click the **Sublist Fields** subtab.
    
5.  Under the Label column, locate **Item Substitution** and **Original Item**. Select the **Show** box for each.
    
6.  Click **Save**.
