Auto Close Back Orders is a managed SuiteApp. It's automatically updated whenever enhancements or new features are added.

## Installing Auto Close Back Orders {#bridgehead_160847043245}

You need to have the Administrator role or SuiteBundler permission to install the SuiteApp. Here are the bundle details:

-   Bundle Name: Auto Close Back Orders
    
-   Bundle ID: 300047
    

For more information about installing a bundle, see [Installing a Bundle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3395142.html).

## Prerequisites {#bridgehead_157665210248}

The Auto Close Back Orders SuiteApp is developed and tested for use primarily with NetSuite OneWorld.

The following features are required to use this SuiteApp:

-   Custom Records
    
-   Client SuiteScript
    
-   Server SuiteScript
    

#### To enable the features:

1.  Go to Setup > Company > Setup Tasks > Enable Features.
    
2.  Check the boxes next to all the features listed in the following table:
    
    | Subtab | Feature Name |
    | --- | --- |
    | **SuiteCloud** | 
    -   Custom Records
    -   Client SuiteScript
    -   Server SuiteScript
    
     |
    
3.  Click **Save**.

## Creating or Customizing Roles to Use Auto Close Back Orders {#bridgehead_157960208653}

As an administrator, you can create or customize roles to add Auto Close Back Orders permissions. For more information, see [Assigning Roles to an Employee](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N897798.html) and [Customizing or Creating NetSuite Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N285937.html).

Check the following table for minimum access levels needed for Auto Close Back Orders:

| Record | Minimum Access Level |
| --- | --- |
| Transaction > Find Transaction | View |
| Lists > Custom Record Entries | View |
| Lists > Customers | View |
| Lists > Documents and Files | View |
| Lists > Subsidiaries | View |
| Custom Record > Auto Close Items | View |
| Custom Record > Item Exceptions | View |
