The preferred grid template preference lets you set the value of the **Set As Preferred Grid Template** box. This box appears when you create or edit a grid matrix template. Follow the instructions below to set the preferred Grid Template Preference.

#### To set the preferred Grid Template Preference: {#procedure_158029235618}

1.  Go to Lists > Grid Order Entry > Set Grid Preferences.
    
2.  On the **Preferred Grid Template** subtab, leave the **Check By Default The Set As Preferred Grid Template Box On The Grid Matrix Template And Bulk Create Grid Matrix Template Pages** box checked.
    
    If you enable this preference, the **Set As Preferred Grid Template** boxes on both the Grid Matrix Template and Bulk Create Grid Matrix Templates pages will also be checked. Then, you can leave the boxes checked so that the matrix template you create automatically becomes the preferred grid template. You can override this preference when creating or editing a matrix template. For more information, see [Creating a Single Grid Matrix Template](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157662832405.html) and [Creating Grid Matrix Templates in Bulk](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157663057189.html).
    
3.  Click **Save**.
