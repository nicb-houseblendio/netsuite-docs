You can create copies of a grid matrix template for the same item. All template and item information are copied, except for the template name. You can edit the copy's details before saving the template.

#### To create a copy of a grid matrix template: {#procedure_158029237551}

1.  Go to the Grid Templates page.
    
    -   If you are using an Administrator role, go to Lists > Grid Order Entry > Grid Templates.
        
    -   If you are using other roles, read [Roles and Permissions for Grid Order Management](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1505110051.html).
        
2.  In the Grid Templates list, click **View** beside the grid template that you want to copy.
    
3.  On the Grid Matrix Template page, click **Make Copy**.
    
    This button's only available in View mode.
    
4.  On the template copy, enter a name for the grid matrix template.
    
    You can update the **Name**, **Description**, **Available In**, and **Percent** fields.
    
    You can also check or clear the **Set As Preferred Grid Template** box. By default, this box is checked and follows your preferred grid template settings. For more information, see [Setting the Preferred Grid Template Preference](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_157587771606.html).
    
5.  Click **Save**.
    

For more information, see [Creating a Single Grid Matrix Template](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157662832405.html).
