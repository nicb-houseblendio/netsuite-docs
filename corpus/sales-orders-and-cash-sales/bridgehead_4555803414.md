This pricing model calculates the contract value based on the price level and list rate specified on the contract's source transaction.

For information about the contract value fields on a contract record, see [Contract Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4460975456.html).

| Field | Formula |
| --- | --- |
| Contract Value (Customer Primary Curr) | `origLR * (1-origDC) * qty * ciTerm` |
| Contract Value (Base Curr) | `origLR * (1-origDC) * qty * ciTerm` |
| Annual Contract Value (Gross) | `origLR * qty * annualTerm` |
| Annual Contract Value (Net) | `origLR * (1-origDC) * qty * annualTerm` |
| Annual Renewal Value (Gross) | `origLR * qty * 12` |
| Annual Renewal Value (Net) | `origLR * (1-origDC) * qty * 12` |
| Renewal Term Renew Value (Gross) | `origLR * qty * contractRenewalTerms` |
| Renewal Term Renew Value (Net) | `origLR * (1-origDC) * qty * contractRenewalTerms` |

Note:

Even if a renewal item is different from the original item, this pricing model will still use the list rate of the original item in the source transaction.
