#### To install the Customer Lifetime Value SuiteApp: {#procedure_1543197820}

1.  Go to Customization > SuiteBundler > Search & Install Bundles.
    
2.  On the Search & Install Bundles page, use the following information to search for the SuiteApp:
    
    -   **Bundle Name**: Customer Lifetime Value
        
    -   **Bundle ID**: 254383
        
3.  Click **Customer Lifetime Value** to display its Bundle Details page.
    
    For more information, see [Bundle Details](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3393046.html).
    
4.  Click **Install**.
    
    If you're prompted, let NetSuite automatically upgrade the SuiteApp when updates become available. During installation, click **Refresh** to get the latest status.
    

After you install the SuiteApp, you'll see the **Customer Lifetime Value** field in the customer record. This field is initially blank until you schedule or manually run the **Customer Lifetime Value Setter** script. For more information, see [Customer Lifetime Value Setter Script](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1542934601.html).

The following table lists the minimum permission level required to view the Customer Lifetime Value field.

| Permission | Minimum Permission Level |
| --- | --- |
| Customers | View |
