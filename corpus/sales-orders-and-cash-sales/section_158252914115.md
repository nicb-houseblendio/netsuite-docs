When you edit a grid matrix template, existing orders that use it don't update automatically. For more information, see [Editing Grid Orders](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3978408.html). Additionally, you can't inactivate a parent matrix item or delete a matrix item that's assigned to a grid matrix template.

Use the following procedure to edit a grid matrix template.

#### To edit a grid matrix template: {#procedure_158253197264}

1.  Go to the Grid Templates page.
    
    -   If you are using an Administrator role, go to Lists > Grid Order Entry > Grid Templates.
        
    -   If you are using other roles, read [Roles and Permissions for Grid Order Management](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1505110051.html).
        
2.  On the Grid Templates page, click **Edit** beside the grid matrix template you want to update.
    
3.  Edit the grid matrix template as needed. You can update the **Name**, **Description**, **Available In**, and **Percent** fields.
    
    You can also check or clear the **Set As Preferred Grid Template** box. By default, this box is checked and follows the setting on the preferred grid template preference. For more information, see [Setting the Preferred Grid Template Preference](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_157587771606.html).
    
    To rearrange the grid, click and drag the column header and drop it on its new position.
    
4.  Click **Save**.
