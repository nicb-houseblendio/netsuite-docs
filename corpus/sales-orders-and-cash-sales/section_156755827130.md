You can schedule the **Customer Lifetime Value Setter** script to run daily, weekly, monthly, yearly, or as a single event. You can also set the start date and time, and set an end date if desired.

#### To schedule the Customer Lifetime Value Setter script: {#procedure_1543197859}

1.  Go to Customization > Scripting > Scripts.
    
2.  Look for **Customer Lifetime Value Setter** and click **View**.
    
3.  On the **Deployments** subtab, click **Customer Lifetime Value Setter**.
    
4.  On the Script Deployment page, click **Edit**, go to the **Schedule** subtab, and set your preferred schedule.
    
    Note:
    
    Only set the script schedule to run during off-peak hours. See [Scheduling a Map/Reduce Script Submission](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1509578930.html).
    
5.  Go to the **Parameters** subtab and select the appropriate Customer Lifetime Value (CLV) map/reduce saved search from the **Map Reduce Saved Search** list:
    
    -   **CLV MR Saved Search Exclude Inactive Customers** - This saved search updates the Customer Lifetime Value field for all customers, except those that are Inactive. This is selected by default.
        
    -   **CLV MR Saved Search Include Inactive Customers** - This updates the Customer Lifetime Value field for all customers.
        
6.  Check the **Write Results** box to display the number of customers already processed by the script. Clear the **Write Results** box to include only the script log.
    
7.  Click **Save**.
    

To view the list of processed customers in the custom record, go to Customization > Lists, Records, & Fields > Record Types. On the Record Types page, locate **CLV MR Customer Lifetime Value Results**, and click **List**.

For more information about the map/reduce saved searches for CLV, see [Map/Reduce Saved Searches for Customer Lifetime Value](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156755957940.html).
