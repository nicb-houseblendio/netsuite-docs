Newly created and existing sales orders can be renewed if they meet these prerequisites:

-   Start Date and End Date must have values
    
-   Start Date can't be later than End Date
    
-   Uplift Percent is a valid number or blank
    
-   Sales Order status must not be Canceled
    
-   Renewal Price must have value
    

Follow these steps to automatically renew a sales order.

#### To enable automatic renewal of a sales order:

1.  Create a new sales order from Transactions > Sales > Enter Sales Order or edit an existing one.
    
2.  (Optional) In the **Custom Form** field, select **Sales Order Renewals**. However, you can select other custom forms as necessary, as the renewal process also works with them.
    
3.  Enter or change values in required fields of the sales order.
    
4.  Add items and ensure that they are eligible for sales order renewal. For more information, see [Items that can be Included in Sales Order Renewal](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0216102655.html).
    
5.  Under the Renewal section, do the following:
    
    1.  Check the **Renew SO Automatically** box.
        
    2.  Enter or ensure date values are specified in **Start Date** and **End Date** fields.
        
    3.  In the **Renewal Price** field, select either:
        
        -   **Same as original sales order** - the price of items in the original sales order will be used in renewal.
            
        -   **Current price at the time of renewal** - The item price to be used will be based on the rates in the Item record at the time of renewal.
            
    4.  (Optional) In **Renewal in Days Before Expiry**, enter the number of days before the End Date or expiry, when automatic sales order renewal should start. If you leave this field blank, the Renewal Date will be the same as the SO End Date. This field does not accept negative numbers.
        
    5.  (Optional) In **Uplift Percentage**, enter a percentage value that you want to increase the rate of every line item included in renewal.
        
6.  Click **Save**.
    
    If Days Before Renewal has no value, then the sales order will automatically renew on the same day as the end date.
