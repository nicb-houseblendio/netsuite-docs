You need the Administrator role or SuiteBundler permission to install the SuiteApp. The following are the bundle details:

-   Bundle name: Order Guides
    
-   Bundle ID: 275880
    

For more information about installing a bundle, see [Installing a Bundle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3395142.html).

The Order Guides SuiteApp automatically updates with new features and enhancements.

## Prerequisites {#bridgehead_156326045809}

The Order Guides SuiteApp is developed and tested mainly for use with NetSuite OneWorld.

You need to enable certain features to use the Order Guides SuiteApp.

#### To enable features:

1.  Go to _Setup > Company > Enable Features_.
    
2.  Check the boxes next to all the features listed in the following table.
    
    | Subtab on Enable Features Page | Feature Name |
    | --- | --- |
    | Analytics | SuiteAnalytics Workbook |
    | Web Presence (To give access to Customer Center role) | 
    -   Customer Access
    -   Online Ordering
    
     |
    | SuiteCloud | 
    
    -   Custom Records
    -   Client SuiteScript
    -   Server SuiteSctipt
    
     |
    
3.  Click **Save**.
