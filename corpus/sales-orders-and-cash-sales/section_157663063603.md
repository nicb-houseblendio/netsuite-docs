Setting a preferred grid template makes it easier to assign a grid template for each matrix item. This feature is available for matrix items, including assembly, lot numbered assembly, serialized assembly, inventory, lot numbered inventory, and serialized inventory items.

You can use the following methods to assign a preferred grid template:

-   **Through the item record** - See [Assigning a Preferred Grid Template Using the Item Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157663260452.html).
    
-   **Through CSV Import** - See [Assigning a Preferred Grid Template Using CSV Import](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157663349314.html).
    
-   **Through creating or editing a grid matrix template** - See [Creating a Single Grid Matrix Template](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157662832405.html) and [Creating Grid Matrix Templates in Bulk](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157663057189.html).
