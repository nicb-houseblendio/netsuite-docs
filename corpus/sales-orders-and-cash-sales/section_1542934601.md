The **Customer Lifetime Value** field is initially blank until you schedule or manually run the **Customer Lifetime Value Setter** script. The script calculates the Customer Lifetime Value amount and populates the **Customer Lifetime Value** field in the customer record. For more information about running the script, read the following topics:

-   [Scheduling the Customer Lifetime Value Setter Script](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156755827130.html)
    
-   [Manually Running the Customer Lifetime Value Setter Script](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156755842405.html)
