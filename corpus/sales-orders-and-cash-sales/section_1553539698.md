Create an order guide from a customer record or make a template for multiple customers. Order guides made from a customer record are only for that customer. You can create an order guide template for each subsidiary. Use the template to create separate order guides for multiple customers in a subsidiary.

## Best Practices for Creating Order Guides {#bridgehead_1556008279}

Follow these best practices for order guides:

-   Assign up to 50 customers at one time when creating order guide templates.
    
-   Add up to 200 items to an order guide.
    

## Creating an Order Guide from a Customer Record {#bridgehead_158564792667}

You can create an order guide from a customer record.

#### To create an order guide from a customer record:

1.  Go to _Lists > Relationships > Customers_.
    
2.  From the list of customers, click **View** for the customer you want to assign to the order guide.
    
3.  On the Customer page, click **Create Order Guide**.
    
4.  On the Order Guide page, in the **Order Guide Name** field, enter a unique name for the order guide.
    
5.  From the **Subsidiary** list, select the subsidiary that you want to associate with this order guide.
    
6.  (Optional) To mark this as a preferred order guide, check the **Preferred** box.
    
    Note:
    
    On a transaction, items of a preferred order guide are preloaded when you open the Order Guide Entry popup window. For more information, see [Using Order Guides on Transactions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1553542393.html).
    
7.  (Optional), To mark this as a historical order guide for the customer, check the **Historical** box.
    
8.  Add items to the order guide by doing either or both of the following:
    
    -   From the **Add Items from Saved Search** list, select an item saved search to retrieve multiple items.
        
        If you select another item saved search, the retrieved items are added to the list.
        
        The order guide is saved and opened in edit mode and the items display in the sublist.
        
        If any items do not match the items filtering criteria, those items are not included. You can view the list of excluded items by clicking the link in the banner message.
        
        Note:
        
        If using expressions in the saved search, enclose the entire expression in parentheses to prevent incorrect saved search results.
        
    -   On the **Items** subtab, in the **Item Code** field, select the item from the list, and then click **Add**.
        
        Note:
        
        You can add duplicate items to the order guide. However, in the Order Guide Entry popup window of the sales order, the list is filtered to show only unique items.
        
9.  (Optional) To set a default item quantity for the customer, enter a value in the **Quantity** field.
    
10.  Click **Save**.
     
     On a customer record, you can view the list of order guides on the **Order Guides** subtab.
     

## Creating an Order Guide Template {#bridgehead_158565248093}

Create an order guide template for multiple customers.

#### To create an order guide template:

1.  Go to Order Guide > Order Guide Templates > Order Guide Templates > New.
    
2.  On the Order Guide Template page, in the **Order Guide Template Name** field, enter a unique name for the order guide template.
    
3.  From the **Subsidiary** list, select the subsidiary to associate with this order guide template.
    
4.  To add items to the order guide, do either or both of the following:
    
    -   From the **Add Items from Saved Search** list, select an item saved search to retrieve multiple items.
        
        If you select another item saved search, the retrieved items are added to the list.
        
        The order guide is saved and opened for editing, and the items appear in the sublist.
        
        Items that don't match the filter criteria are excluded from the order guide. Click the link in the banner to see the excluded items.
        
        Note:
        
        When using expressions in saved searches, enclose them in parentheses. Otherwise, you may get incorrect saved search results.
        
    -   On the **Items** subtab, in the **Item Code** field, select the item from the list, and then click **Add**.
        
    
    To review the conditions for items that you can add to order guides, see [Order Guides](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1553536374.html).
    
    Note:
    
    You can add duplicate items to the order guide template. In the Order Guide Entry popup window of the sales order, the list only shows unique items.
    
5.  (Optional) To set a default item quantity for the customer, enter a value in the **Quantity** field.
    
6.  Click **Save**.
    

## Creating Order Guides from an Order Guide Template {#bridgehead_158565255034}

After creating an order guide template, create order guides from the template and assign them to multiple customers in a subsidiary.

Each customer gets their own order guide when you assign a template to multiple customers. The order guide's internal ID is added to the name of each customer's order guide. Find the generated order guide on the customer's record, under the **Order Guide** subtab.

These order guides are linked to the order guide template by default. Changes to the template can be applied to the linked order guides. For information about updating order guides, see [Updating Order Guides](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1553542108.html).

#### To create order guides from an order guide template:

1.  Go to Order Guide > Order Guide Templates > Order Guide Templates.
    
2.  Next to the template you want to use, click **View**.
    
3.  Click **Create Order Guides**.
    
4.  In the Create Order Guides from Template window, select the saved search from the **List Customers from Saved Search** list.
    
    If you select another customer saved search, the new customers are added to the list.
    
    Tip:
    
    To change the customer selection, press **Shift** or **Ctrl** and update the list.
    
5.  Click **OK** to continue.
    
    A banner in the Order Guides Template page displays the status of the order guide creation. Click the **Refresh** button in the banner to update the completion status. When the order guides creation is done, you see a confirmation message in the banner. If some items don't match the items filtering criteria, those items are excluded from the order guides. You can view the list of excluded items by clicking the link in the banner message.
    
    Note:
    
    If you try creating another order guide for a customer from the same order guide template, the SuiteApp creates a duplicate order guide. However, if you want to update an existing order guide created from an order guide template, you must update the linked order guides. For more information, read [Updating Linked Order Guides](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1553542108.html#bridgehead_158617029905).
    

## Creating Order Guides and Order Guide Templates Using CSV Import {#bridgehead_162648937427}

Use the standard CSV Import feature to create order guides and templates. Keep the following in mind when using CSV import:

-   Be sure to check the **Run Server SuiteScript and Trigger Workflows** box.
    
-   When creating order guides:
    
    -   Leave the **Order Guide Template** field blank.
        
    -   The **Item Saved Search** field isn't available.
        
-   The **Item Saved Search** field also isn't available for creating order guide templates.
