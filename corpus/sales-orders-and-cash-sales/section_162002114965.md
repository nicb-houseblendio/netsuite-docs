The contract item creation script (R03) uses a default search to identify the list of transactions that will be processed for contract item creation. If you want to use a custom transaction search for contract item creation, you should set these preferences:

-   **Use CI Pending Creation Search** - Check this box if you want to use a custom saved search to define the list of transactions for contract item creation.
    
-   **Search: CI Pending Creation** - Specify the custom saved search that you want to use for contract item creation. For more information, see [Guidelines for Creating a Custom Search for Contract Item Creation](#subsect_162002177501).
    

These preferences are available on the [Contract Items Creation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/procedure_N1321905.html) subtab of the Contract Renewals Preferences page. For more information, see [Setting Up Contract Renewals Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1321619.html).

## Guidelines for Creating a Custom Search for Contract Item Creation {#subsect_162002177501}

If the **Use CI Pending Creation Search** box is checked, you can't use the default saved search **Contract Item Pending Creation** (or any custom search based on this saved search) in the **Search: CI Pending Creation** field. Instead, you must follow these guidelines to create a new saved search:

-   Search type must be Transaction.
    
-   Search must be set to Public.
    
-   To avoid any errors, the search shouldn't include these filters:
    
    -   Main Line
        
    -   Check Log Status (Custom Body)
        
    -   Contract: Status
        
    -   Created From
        
    -   Contract (Custom Body)
        
    -   Status
        
    -   End User: Inactive
        
    -   Distributor: Inactive
        
    -   Reseller: Inactive
        
    -   Type
        
    -   Quantity Type (hidden) (Custom Column)
        
    -   Item Category (hidden) (Custom Column)
        

For information about creating saved searches, see [Defining a Saved Search](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N676039.html).
