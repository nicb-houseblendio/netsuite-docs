After you apply attributes to items, you can use those items in a grid item template. To place items in the grid, search for them by category and assign grid attributes to the rows and columns. You can enter percentages for each item to be used in calculating the distribution of quantities across all items in the grid item template.

You can assign matrix item options to a grid item template if the items are mapped to grid attributes. For more information, see [Applying Grid Attributes to Items](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3748267099.html). For guidelines and limitations when creating grid templates, see [Setting Up Grid Templates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4273599062.html).

To see how to create, edit and delete a Grid Item Template, read the following topics:

-   [Editing a Grid Item Template](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157017513970.html)
