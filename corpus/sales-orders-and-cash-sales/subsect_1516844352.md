Default discounts for customer groups are automatically applied to all customers that belong to the customer group.

#### To set a default discount for a customer group:

1.  Go to _Lists > Relationships > Groups > New_.
    
2.  Create a customer group. For instructions, see the help topic [Working with Groups](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N492945.html).
    
3.  In the **Default Discount** field, select the applicable discount for the customer group.
    
    To create a new discount, see the help topic [Configuring Discounts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4231800589.html).
    
4.  Click **Save**.
