During the term of a contract, you can make changes by entering sales orders for additional items (upsell) or by issuing returns (downsell).

When you want to add items to an existing contract, you create another sales order for the customer and attach it to the existing contract. You can also create a new order from the contract by selecting the contract items for upsell and clicking the Create Upsell Order button.

Items added to a contract must have start and end dates within the contract term. To add items that extend beyond the existing contract's start and end dates, you need to create a separate contract. For more information, see [Contract Upsell](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1326206.html).

If the customer reduces their service during the contract term, you create a return authorization tied to the contract. These items are then offset from the contract and aren't renewed. For more information, see [Contracts and Returns](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1326489.html).
