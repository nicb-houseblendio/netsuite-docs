Update order guides made from customer records. You can also update templates and apply those changes to linked order guides.

## Updating Order Guides Created from a Customer Record {#bridgehead_158652196845}

You can update an order guide created from a customer record. On the Order Guide subtab of a customer record, click **Edit** next to the order guide. You can do the following:

-   Rename the order guide
    
-   Add or remove items from the order guide
    
-   Update the status (Inactive, Preferred, or Historical)
    

Edit or delete items as needed. Changes won't affect past transactions that used this order guide.

For linked order guides, you can only update the **Preferred** status.

## Updating Order Guide Templates {#bridgehead_157233745859}

On the Order Guide Templates List page, click **Edit** next to the template you want to update. You can do the following:

-   Rename the template
    
-   Add or remove items from the template
    
-   Update item quantities
    

## Updating Linked Order Guides {#bridgehead_158617029905}

Apply template changes to linked order guides.

#### To update linked order guides:

1.  Go to Order Guide > Order Guide Templates > Order Guide Templates.
    
2.  Next to the order guide template, click **View**.
    
3.  Click **Update Order Guides**.
    
    You'll see the **Update Order Guides** button if you have linked order guides.
    
4.  Click **OK** to continue.
    

A banner shows the update status. Click **Refresh** to update the status. You'll see a confirmation message when the update is done. Items that don't match the filter criteria are excluded from the order guides. Click the link to see the excluded items.

## Unlinking Order Guides {#bridgehead_158617136353}

Unlink an order guide if you don't want it to be updated with changes in the order guide template. There are two ways that you can unlink an order guide:

-   On the Order Guide page, click **Unlink From Template**.
    
-   On the Order Guide Template page, on the **Linked Order Guides** subtab, click **Unlink** next to the order guide name.
    

Note:

When unlinked, the order guide can't be linked again and works like a order guide works likes an order guide created from a customer record. Alternatively, create a new order guide from the same template and assign it to the same customer.

## Updating Order Guide Templates and Order Guides Using CSV Import {#bridgehead_162649194081}

When updating order guides with CSV import, on the Scan & Upload CSV page, select the following:

-   From the **Import Type** list, select **Custom Records**
    
-   From the **Record Type** list, select **Order Guide**.
    

When updating order guide templates using CSV import, on the Scan & Upload CSV page, select the following:

-   From the **Import Type** list, select **Custom Records**
    
-   For template settings, from the **Record Type** list, select **Order Guide Template**.
    
-   For template items, from the **Record Type** list, select **Order Guide Item**.
    

When adding items to an existing template, on the Import Options page, select **Add**.

Note:

Order guides can have the same name for different customers or subsidiaries. When updating order guides with CSV import, be sure to include the correct order guide name, customer, and subsidiary in the CSV file. When creating a template,include the correct template name and subsidiary.

## Deleting Order Guides {#bridgehead_157233748845}

To delete an order guide, click **Delete** while in edit mode. After an order guide is deleted, it's gone for good. If you delete a template, its linked order guides are unlinked and work like regular order guides created from customer records.
