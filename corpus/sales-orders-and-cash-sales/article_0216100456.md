After selecting the transaction forms where sales order renewal fields will be displayed, refer to the following table to learn how to set them up.

| Field name | Description | Required? Y / N | More Details |
| --- | --- | --- | --- |
| Renew SO Automatically | Check this box to automatically renew sales orders. | N Checking the box is optional because you can still renew sales orders manually | If you want to manually renew a sales order later using the Sales Order Renewal custom form, save the sales order without checking this box. |
| Start Date | A date field on the sale order record indicating when the first invoice was generated. | Y , if Renew SO Automatically is checked | The Start Date can't be later than or after the End Date. |
| End Date | A date field on the sale order record indicating when the sale order expires. | Y , if Renew SO Automatically is checked | The End Date can't be earlier than or before the Start Date. |
| Renewal Date | A date field indicating when you want the sales order to be renewed automatically. This field is only available if Renew SO Automatically is checked. | N , if you leave this field blank and the record is saved, it is automatically populated with End Date + 1 day | 
-   Renewal Date = Days Before Renewal - End Date
-   If the Days Before Renewal has no value, Renewal Date will take the sales order End Date.
-   Renewal Date will change if End Date or Days Before Renewal is changed.
-   Manually changing Renewal Date will clear the value of Days Before Renewal.

 |
| Renewal Price | A dropdown field with two options to define the renewal price:

-   **Same as original sales order** - If selected, the price of items in the original sales order will be used in renewal.
-   **Current price at the time of renewal** - If selected, the item price will be based on the rates in the Item record at the time of renewal.

 | Y , if Renew SO Automatically is checked |  |
| Renewal in Days Before Expiry | This field accepts the number of days before the End Date or expiry, when you want automatic sales order renewal to start. | N | 

-   Renewing the sales order days ahead of its expiry will give you time to review or approve it.
-   If you leave this field blank, the Renewal Date will be the End Date of the sales order.
-   This field does not accept negative numbers.

 |
| Uplift Percentage | This field accepts a percentage value that you want to increase the rate of every line item included in renewal. | N | For example, entering 10.0 will increase the rate of all line items by 10% upon renewal. |
| Renewal Of | This field only displays a value after the original sales order is renewed, indicating the previous or original sales order. You can't edit this field. | N |  |
| Renewed Order | This field only displays a value after the current sales order is renewed, indicating the Renewal Sales Order. You can't edit this field. | N |  |
| Create Renewal | A button that is displayed only if the Renew SO Automatically box is cleared when the sales order is saved. Later, you can click this button to manually renew a sales order. | N |  |
