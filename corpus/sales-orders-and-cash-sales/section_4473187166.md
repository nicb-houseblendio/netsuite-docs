Contract values are calculated based on the Renewals License Pricing Model that you selected on the Contract Renewals Preferences page. For more information, see [Setting Up Contract Renewals Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1321619.html).

These topics discuss how contract values are calculated for each pricing model:

-   [Historical License List Rate - From Tran Line](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4555803414.html)
    
-   [Current License List Rate - Price Level on Customer Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4555859740.html)
    
-   [Current License List Rate - Price Level on Contract](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4562783078.html)
    
-   [Current License List Rate - Price Level on Contract with Custom Price Handling](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4562788958.html)
    

These variables are used to calculate the contract value:

| Variable | Description |
| --- | --- |
| annualTerm | Refers to the contract term. A value of 12 is used when the term type is annual, otherwise a value of 1 is used. |
| ciTerm | Refers to the contract item term. A value of 1 is used when there is no term defined, otherwise the value of the original contract item term is used. |
| contractRenewalTerms | Refers to the new term of the contract (in months) when it is renewed. |
| contractLR | Refers to the current item list rate based on the contract price level. |
| currentLR | Refers to the current item list rate based on the base price on the item record. |
| customerLR | Refers to the current item list rate based on the customer price level. |
| origLR | Refers to the original item list rate from the transaction. |
| origDC | Refers to the original discount. |
| qty | Refers to the quantity of the contract items. |
