The following table lists the minimum permission levels required to use Enhanced Validations and Defaulting:

| Permissions | Minimum Permission Level |
| --- | --- |
| CRM Groups | View |
| Custom Record Entries | View |
| Customers | View |
| Items | View |
| Locations | View |

For more information about setting permissions, see [Customizing or Creating NetSuite Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N285937.html).
