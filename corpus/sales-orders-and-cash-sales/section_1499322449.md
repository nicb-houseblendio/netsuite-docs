## CSV Imports for Grid Purchase Order and Sales Order Transactions {#section_1499145566}

You can use the CSV Import method to import multiple grid purchase order and sales order transactions. When you import these, you can view and print the transaction using the grid template assigned to each item record. Read the following topics to learn more:

-   [Grid Item ID Assignment](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_157045009348.html)
    
-   [Grid Template Assignment](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_157045003099.html)
    
-   [Viewing the Grid for the Item Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_157045003099.html#bridgehead_1499305512)
    
-   [Printing Transaction Records Using the Grid Template](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_1499306991.html)
    

### Guidelines for Importing Grid Purchase Order and Sales Order Transactions {#subsect_157053685028}

Read the following guidelines for importing grid purchase order and sales order transactions:

-   You can only import up to 100 distinct grid templates for each transaction.
    
-   The system automatically assigns the value of the **Grid Item ID** and **Grid Template** fields for assembly and inventory matrix items in the transaction. So, these fields are no longer required in the CSV Import file.
    
-   If the value of the **Grid Item ID** field is specified in the CSV Import file, it's ignored.
    
-   The value of the **Grid Template** field is based on the current preferred grid template assignment in the item record. If you want to assign the grid template manually, make sure your CSV Import file has the valid internal ID for the grid template.
