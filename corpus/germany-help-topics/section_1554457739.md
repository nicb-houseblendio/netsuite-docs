After installing the SuiteApp, three new roles will be added to your NetSuite account. Only a user with one of these following roles is allowed to use the Germany Central Bank Reports SuiteApp.

The following table displays different permissions for each of these roles:

| Action / User Role | Z4 Report Viewer | Z4 Report Creator | Z4 Report Administrator | Administrator |
| --- | --- | --- | --- | --- |
| **Access the Central Bank Reports Dashboard (Reports > Financial > Germany Central Bank Reports) / Display report previews** | Yes | Yes | Yes | Yes |
| **Export reports** | No | Yes | Yes | Yes |
| **Access Germany Central Bank Reports settings (Setup > Customization > Central Bank Reports)** | No | No | Yes | Yes |

Important:

To use the Germany Central Bank Reports SuiteApp, you can't be logged in using one of the Z4 roles directly. You must be logged in using a different role, but one of the roles mentioned above must be also assigned to you. For example, if a user is a Z4 Report Administrator, they must use this SuiteApp using some other of his or her roles. For more information about users and roles in NetSuite, see [NetSuite Access Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N285060.html).
