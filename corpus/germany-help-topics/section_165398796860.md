This topic describes the Germany-specific field of the Intrastat Supplementary Declaration. To learn more about Intrastat and other fields used in this declaration, see [Intrastat Supplementary Declaration](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_156889008497.html).

To use the Intrastat Reporting feature, the Tax Reporting Framework SuiteApp must be installed in your NetSuite account. For more information, see [Tax Reporting Framework](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1528262949.html).

The Germany Intrastat report supports Multi-Book Accounting. For more information, see [Multi-Book Accounting Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_3831567542.html).

To generate the Germany Intrastat reports, see [Generating Localized Country Tax Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1528250223.html). You can also export these reports to PDF and XLS formats. For more information, see [Exporting a Country Tax Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_156645000208.html).
