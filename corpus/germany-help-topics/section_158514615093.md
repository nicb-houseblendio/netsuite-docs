The Deferred VAT Recognition SuiteApp (Bundle ID: 250593 ) is a shared and managed bundle, and is automatically updated whenever there are enhancements or new features added. This SuiteApp is free but must be shared with your NetSuite account before you can install it.

You need to be an Administrator to install this SuiteApp. When the SuiteApp is shared with your account, you can install it by performing the following procedure:

#### To install the Deferred VAT Recognition SuiteApp:

1.  Go to Customization > SuiteBundler > Search & Install Bundles and enter **Deferred VAT Recognition** in the search field.
    
2.  In the results, click **Deferred VAT Recognition** with the bundle ID **250593**.
    
3.  On the bundle details page, click **Install**.
    

For more information on installing SuiteApps, see [Installing a Bundle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3395142.html)
