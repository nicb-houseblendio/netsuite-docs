To access the Central Bank Reports Dashboard, go to Reports > Financial > Germany Central Bank Reports. The purpose of this dashboard is to use several filters to search for transactions that should be added to the Z4 report and to create the report itself from the search results.

The following filters are available:

-   **Subsidiary**: Use to search for transactions assigned to this specific subsidiary.
    
-   **Accounting Book**: Use to search for transactions assigned to this accounting book.
    
    Note:
    
    Only if Multi-Book feature is enabled. For more information, see [Multi-Book Accounting Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_3831567542.html)
    
-   **Year**: Use to filter out the transactions submitted during a certain year.
    
-   **Month**: Use to filter out the transactions submitted during a certain month.
    
    Note:
    
    If there are any overdue statements required to be reported to the German Central Bank in selected month, you'll see a notification in the upper part of the screen (containing further info). This notification disappears if you've already exported all the statements for selected month.
    
-   **Report:** Use this menu to select the report type to be generated from the search results (currently, only Z4 report is available).
    

When you set up your filters, click the **Show Report** button.
