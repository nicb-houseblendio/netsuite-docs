The International Tax Reports SuiteApp provides a localized Intrastat Dispatches and Arrivals reports for NetSuite accounts with a Germany nexus. For more information about generating the Intrastat report for businesses based in Germany, see [Generating the Germany Intrastat Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164380299176.html).

The information displayed on the Intrastat Dispatches and Arrivals reports are based on your transaction and item records in NetSuite. To know more about the Intrastat Report fields, see [Germany Intrastat Report Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164380122380.html).

The following table lists the information that appear on the generated Intrastat Dispatches and Arrivals report for Germany.

| Intrastat Dispatches (Sales) Report | Intrastat Arrivals (Purchases) Report |
| --- | --- |
| Line Number | Line Number |
| Description of Goods | Description |
| Item | Country of Origin |
| Country of Destination | Region of Origin |
| Region of Origin | Nature of Transaction |
| Country of Origin | Commodity Code |
| Nature of Transaction | Net Mass (kg) |
| Commodity Code | Supplementary Unit |
| Net Mass (kg) | Value |
| Supplementary Unit | Statistical Value |
| Value | Delivery Terms |
| Statistical Value | Mode of Transport |
| VAT ID No. of the Partner Operator |  |
| Delivery Terms |  |
| Mode of Transport |  |

For more details about the Intrastat Report field descriptions, see [Intrastat Reporting Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4150707116.html).

You can also customize an Intrastat report. You can access these custom reports from Reports > Saved Reports.

-   Intrastat Purchases Report \[Custom\]
    
-   Intrastat Sales Report \[Custom\]
    

For information about customizing a report, see [Report Customization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N736328.html).
