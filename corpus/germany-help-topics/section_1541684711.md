Some pages of the Germany Localization SuiteApp can only be accessed by users with a certain role. The following table contains an overview of these roles and whether they can access the specific page or not:

| User Role / Action | Accountant | Accountant (Reviewer) | Administrator | CEO | CEO (Hand Off) | CFO | System Administrator |
| --- | --- | --- | --- | --- | --- | --- | --- |
| Financial statements (Reports > Financial > Country-Specific Reports) | Yes | Yes | Yes | Yes | Yes | Yes | No |
| Germany Localization Overview page (Setup > Customization > Germany Localization) | No | No | Yes | Yes | Yes | Yes | No |

#### How to grant access to financial statements to a NetSuite custom role:

1.  Go to Customization > Scripting > Script Deployments (filter out the Suitelet script type and make sure the Show Undeployed box is selected).
    
2.  In the list, locate the **customdeploy\_csr\_sl\_dashboard** script, and click the corresponding **Edit** link.
    
3.  In the Audience subtab, select the custom role that you would like to give access to the financial statements (click the name of the custom role while pressing the Ctrl key).
    
4.  Click **Save**.
    

To learn more about deploying scripts in NetSuite, see [Script Deployment](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4486246754.html).

For custom roles, your account administrator can grant them permission to work with the German Chart of Accounts and financial statements through the Script Deployment Page.

For more information about setting permissions, see [Customizing or Creating NetSuite Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N285937.html) and [Setting Permissions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N288727.html).
