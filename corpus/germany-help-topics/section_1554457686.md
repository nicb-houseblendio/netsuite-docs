## Germany Localization SuiteApp {#bridgehead_157008867161}

The Germany Localization SuiteApp provides features that address or comply with accounting and financial reporting requirements or standards specific to Germany. It's the basic SuiteApp covering the requirements of German customers, to which additional SuiteApps can be added (if necessary). To install the Germany Central Bank Reports SuiteApp, you must have the Germany Localization SuiteApp installed in your account.

## Required Features {#bridgehead_157008870538}

Before installing the Germany Central Bank Reports SuiteApp, your account administrator must enable several features in your NetSuite account.

Go to _Setup > Company > Setup Tasks > Enable Features_.

-   In the **Company** subtab, check the following boxes: Multi-Language, Multiple Currencies, Currency Exchange Rate Integration, File Cabinet.
    
-   In the **Accounting** subtab, check the following boxes: Accounting, A/R, A/P, Accounting Periods.
    
-   In the **SuiteCloud** subtab, check the following boxes: Custom Records, Advanced PDF/HTML Templates, Client SuiteScript, Server SuiteScript, Create Bundles with SuiteBundler, SOAP/REST Web Services, SuiteCloud Development Framework.
    

For more information, see [Enabling Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N232138.html).
