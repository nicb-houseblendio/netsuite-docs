After installing the Germany Localization SuiteApp and installing one of the Charts of Accounts, you should install German financial statements as well. If you're using the SKR 03 Chart of Accounts template, install SKR 03 reports. If you're using the SKR 04 Chart of Accounts template, use SKR 04 reports.

#### To install Germany financial statements:

1.  Go to Setup > Customization > Germany Localization.
    
2.  Click the Install action link for the set of reports that you would like to use (either SKR 03 or SKR 04).
    
3.  The installation process usually takes up to 20 minutes to accomplish. To monitor the progress, go to Setup > Import/Export > View CSV Import Status.
    
4.  Go to Reports > Financial > Country-Specific Reports and check whether the new reports have been installed and can be properly displayed.
    

Important:

When the Germany Localization SuiteApp is updated to a newer version, go to the Germany Localization overview page (Setup > Customization > Germany Localization) to ensure your financial statements are installed and up to date. For more information, see [Germany Localization Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1541684686.html#bridgehead_1556020877).
