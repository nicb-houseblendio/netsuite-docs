You can use the ElsterTransit application to submit your Germany monthly, quarterly, and annual tax returns to Elster. The application requires the XML file of the tax return that you are going to submit. To generate an XML file, see [Generating an XML File of your Germany VAT Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N1917880.html).

To learn about submitting a monthly or quarterly VAT return using ElsterTransit, read [Using ElsterTransit to Submit Monthly/Quarterly German Tax Returns](https://suiteanswers.custhelp.com/app/answers/detail/a_id/100631).

To learn about submitting an annual VAT return using ElsterTransit, read [E-filing of Germany Annual VAT Return Using ElsterTransit](https://suiteanswers.custhelp.com/app/answers/detail/a_id/99400).

Important:

Before using ElsterTransit, make sure that on your Windows setup, your Regional Options is set to Germany. Your computer must be set to use German decimal notation so that the values of your VAT report are correctly displayed on the application.
