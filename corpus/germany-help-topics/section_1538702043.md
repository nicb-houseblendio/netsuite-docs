A custom role named **German Deferred VAT Accountant** is created so you can use this feature immediately. If a customized role or an existing role needs access to the deferred VAT feature, you will need to customize a role. For more information, see [Customizing or Creating NetSuite Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N285937.html).

The following table describes the permissions needed for users to access the Deferred German VAT Recognition features:

| Permission | Access |
| --- | --- |
| Lists > Subsidiaries | View |
| Setup > Manage Accounting Periods | View |
| Custom Record > EMEA DVR Process Status | Full |
| Custom Record > EMEA Journal Summary Detail | Full |
| Custom Record > EMEA Journal Summary Detail parent | Full |
| Transactions > Make Journal Entry | Full |
| Lists > Tax Items | Full |
| Setup > SuiteScript Scheduling | Full |
| Lists > Custom Record Entries | View |
| Lists > Accounts | Full |
| Transactions > Revenue Arrangement | Full |
| Lists > Revenue Element | Full |
| Lists > Revenue Recognition Plan | Full |
| Lists > Revenue Recognition Schedules | Full |

For more information on customizing roles, see [Customizing or Creating NetSuite Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N285937.html).
