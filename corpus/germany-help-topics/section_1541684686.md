The Germany Localization SuiteApp is currently available as a public SuiteApp. For information about installing SuiteApps, see [Installing a Bundle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3395142.html).

The Germany Localization SuiteApp is a managed bundle, and is automatically updated whenever improvements or new features are added.

#### To install the Germany Localization SuiteApp:

1.  Go to Customization > SuiteBundler > Search & Install Bundles.
    
2.  Using the **Keywords** field, search for the Bundle ID **255470**.
    
3.  Click the **Germany Localization** link in the **Name** column.
    
4.  On the Bundle Details page, click **Install**.
    

After the installation, go to Setup > Customization > Germany Localization to check if the following features are installed:

-   **German Financial Reports** - If you have Country Specific Reports installed on your account, this feature will install automatically. To learn more, go to [Germany Financial Statements](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1541685047.html).
    
-   **German Tax Reports** - To learn more, go to [Germany Tax Reports (SuiteTax)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157252936767.html).
    
-   **German Electronic Bank Payments (EBP) templates**\- If you have Electronic Bank Payments SuiteApp installed on your account, this feature will install automatically. To learn more, go to [Germany Electronic Bank Payments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1554985535.html).
    

## Germany Localization Overview {#bridgehead_1556020877}

You can inspect the state of your Germany Localization SuiteApp and its components in a dedicated page.

To visit this page, go to Setup > Customization > Germany Localization.

The page contains the following information:

| Field | Description |
| --- | --- |
| SuiteApp or Component Name | Name of SuiteApp or localization component as provided by the Germany Localization SuiteApp. This column is split into several sections:
-   Required SuiteApps
    -   EMEA Localization
    -   Germany Localization
-   Recommended SuiteApps
    -   Contra Account Sheets
    -   Country-Specific Reports
    -   Electronic Bank Payments
    -   Germany Central Bank Reports
    -   Tax Reporting Framework
-   Components
    -   Electronic Bank Payments Templates
    -   Financial Reports SKR03
    -   Financial Reports SKR04
    -   Tax Audit Files: GoBD Data Extract
    -   Tax Reports

 |
| Status | Current stage of the SuiteApp or component in the installation process. |
| Last Updated Date | Timestamp information about the last update performed on the SuiteApp or component. |
| Last Updated By | Name of user who last updated the SuiteApp or component. |
| Action | Manually install, update, or uninstall the component, or view more information about the required and recommended SuiteApps. |

The following statuses can appear in the **Status** column of the Germany Localization Overview page:

| Status | Description |
| --- | --- |
| Installed | The component is successfully installed. Click the **Uninstall** link in the Action column to uninstall it. |
| Not Installed | The component has not been installed yet. Click the **Install** link in the Action column to install it. |
| Installing | The installation process of this component is currently in progress. Click the **Refresh** button to keep it up to date. |
| Uninstalling | The uninstallation process of this component is currently in progress. Click the **Refresh** button to keep it up to date. |
| Need Update | Your component isn't up to date. Click the **Update** link in the Action column to update it to the latest version. |
| Error | This status appears if the component has not been installed properly. If you click this status, an error message with more detailed information appears. Components in error status can be either uninstalled or updated. Click the **Uninstall** or **Update** link in the Action column. |
| Missing SuiteApp | Components only. Appears if the SuiteApp providing the component isn't installed. Click the link to open the **Details** dialog. Click the SuiteApp link in the **Details** dialog to open a browser window with the option to install the missing SuiteApp. |
