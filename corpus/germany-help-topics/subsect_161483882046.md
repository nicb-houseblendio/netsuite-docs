Use ElsterTransit to submit your Germany VAT reports. ElsterTransit is a desktop application developed by Küppers Software GmbH and made available for free to NetSuite customers.

ElsterTransit enables you to:

-   Import the XML file of your periodic or annual tax return from NetSuite, and view and edit the online submission form before submitting the file to Elster
    
-   View successful submission or error messages from Elster
    
-   Print and save the submitted online form
    

Click the [ElsterTransit](https://urldefense.com/v3/__https://www.kuepperssoft.de/NetSuite_8.0.3.Editable.zip__;!!ACWV5N9M2RV99hQ!MDRQFoTtNNjseXHr-EaNdCurlasGv5WLz8xnbgzwteMa0dsaqdtZu8YJfsG1ImBtlZVXQ2TvPB73eObWOIAF$) link to download and install it on your desktop or local network.

Note:

While there are no limitations on the number of installations that you can have in your business, you should install ElsterTransit only on the computer of the person responsible for filing your tax returns. The Microsoft Visual C++ Redistributable Package for Visual Studio 2013 is needed in the 32-bit version of Windows. ElsterTransit isn't compatible with Mac OS.
