The Germany Central Bank Reports SuiteApp allows you to export files to two different formats: XML and PDF. The XML file is to be uploaded to the Central Bank web portal. The PDF file is mostly informative, useful to be presented to the tax authorities (if necessary).

To view your future report in PDF format, click **Preview in PDF**. The report preview will be displayed in your browser. The language of the preview as well as the PDF is determined by your settings. For more information, see [Choosing a Language for Your NetSuite User Interface](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N479109.html).

To export your new report, click the **Export** button. The following actions will take place:

-   You'll be prompted to save the report to your hard drive (the XML file only). Subsequently, don't forget to upload this file to the Central Bank web portal.
    
-   Both XML and PDF version of the report will be stored in NetSuite File Cabinet. To access them, go to Documents > Files > File Cabinet and open the zreports folders. There, the reports are stored within the Subsidiary/Year/Month/Report hierarchy. For example, if you want to access the Z4 reports for Germany subsidiary for February 2019, go to Germany > 2019 > 02 > z4. If you export the report for one month multiple times, the stored files will be numbered (for example, 02\_2019\_v1\_xml, 02\_2019\_v2\_xml...).
    
-   Both versions of the report (XML and PDF) will be sent to the archivation email. To set the archivation emails for individual subsidiaries, go to the Subsidiary-specific Settings in the Central Bank Reports settings (Setup > Customization > Central Bank Reports).
    

To access the reports that you've already exported, use the **Report history** section of the Central Bank Reports Dashboard. Click the links to download the different versions of XML or PDF files.

Important:

If the number of items in the search results it too high, no results will be displayed (but you'll see a notification about that in the upper part of the screen). In such case, if you click the **Export** button, the exporting process will run in the background. As soon as this process is finished, both versions of the report (XML and PDF) will be sent to the archivation email and will also be stored in NetSuite File Cabinet (however, you won't be offered to save the report file locally).
