To be able to properly generate reports provided by the Germany Localization SuiteApp, the Region field of your German subsidiary must be set.

Note:

This setting applies to the One World account types. If you use a Single Instance account type, see [Setting the Region of Your German Company](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_0318082729.html).

#### To set your subsidiary's region:

1.  Go to Setup > Company > Subsidiaries.
    
2.  Click **Edit** next to the subsidiary, for which you want to set the region. If you're creating a new subsidiary, click the **New Subsidiary** button instead.
    
3.  In the **Region** field on the Subsidiary page, select an appropriate region from the list.
    
4.  Click **Save**.
