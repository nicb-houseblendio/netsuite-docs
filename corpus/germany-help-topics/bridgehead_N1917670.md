To view and e-file your tax return, there are two prerequisites:

-   Installation of the [International Tax Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2051341.html) SuiteApp (bundle ID 43003)
    
-   Installation onto your desktop of the NetSuite ElsterTransit software
    

The SuiteApp and software are free to NetSuite customers. The ElsterTransit software is provided by the German software provider, Küppers Software GmbH. For information about installing the software, see [Installing ElsterTransit](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_161483882046.html).

#### To prepare and submit your German VAT return: {#procedure_N1917714}

1.  Set up tax filing information. See [Setting Up Tax Filing for Germany](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1917361.html). If no tax filing information has been set up for this nexus, then NetSuite will use your subsidiary VAT number for the Germany VAT form and Recapitulative Statement (EU Sales List) form.
    
2.  Go to Reports > VAT/GST > Tax Reports (International) to access the Umsatzsteuer-Voranmeldung in English or German.
    
    For more information, see [Generating VAT/GST Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2064551.html).
    
3.  Select the tax period for the report.
    
4.  Carefully review the values displayed to verify that they are accurate. Some boxes may require you to enter data manually.
    
    Click the value generated in each box to view the Detailed Report page in another window. This page shows the drill down report of the box value. For more information about the Detailed Report, see [Viewing VAT Report Transaction Details](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2065235.html).
    
5.  Click **Print** to save a PDF file of the VAT return.
    
6.  Choose any of these submission options:
    
    -   To submit your VAT return using ElsterFormular or another software, use the saved PDF file.
        
    -   To submit your VAT return using NetSuite ElsterTransit, click **Export to XML** and save the XML file in the File Cabinet or your computer. For complete instructions, read [Generating an XML File of your Germany VAT Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N1917880.html). Before you can file online to the Elster online tax returns system, you must have access to the ElsterTransit software on your desktop or network. To install ElsterTransit, see [Installing ElsterTransit](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_161483882046.html). To continue with your submission, see [Submitting the German Tax Return to Elster](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N1918013.html).
        
    
    Important:
    
    You should review all the values in the report prior to submission.
