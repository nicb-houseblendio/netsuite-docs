German users can activate and get access to different features from the following functional areas:

-   [Accounting](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_1554723518.html)
    
-   [Taxation (Non-SuiteTax)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_160162478333.html)
    
-   [Taxation (SuiteTax)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_160162598725.html)
    
-   [Payments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_160162965367.html)
    
-   [Bank Reconciliation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_160163124401.html)
    
-   [SuiteCommerce](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_1554726124.html)
    

To learn more about SuiteApps installation, see [Installing a Bundle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3395142.html).

To learn more about enabling NetSuite features, see [Enabling Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N232138.html).

Important:

If you don't have sufficient permissions to install SuiteApps or enable features, please contact your account administrator.
