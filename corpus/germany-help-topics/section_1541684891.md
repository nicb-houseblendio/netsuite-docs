With the Germany Localization SuiteApp, you'll notice some changes when creating or editing transaction records.

First, the **Memo** field is required for every German subsidiary to comply with German generally accepted accounting principles. This applies to the following transaction types:

-   Journal Entry
    
-   Book Specific Journal Entry
    
-   Advanced Intercompany Journal Entry
    
-   Statistical Journal Entry
    

If you try to save any transaction with this field left blank, an error will be displayed, and you won't be allowed to proceed.

Note:

If you've entered all transaction line memos, you can leave the main Memo field blank. This field becomes required only if at least one of the transaction line memos is missing.

## Central Bank Reports Transaction Codes {#bridgehead_157017400246}

With the Germany Localization SuiteApp installed, the new **CBR Transaction ID** field is added to the following item records:

-   Inventory Item
    
-   Item Group
    
-   Kit/Package
    
-   Non-inventory Item (all categories)
    
-   Other Charge (all categories)
    
-   Service (all categories)
    
-   Assembly Item
    

For more information about enabling Assembly Items, see [Enabling Assembly Items](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2319428.html).

Use this field to categorize your transactions (by selecting specific unique codes set by German law). These categories can be used by the **Germany Central Bank Reports SuiteApp** that generates reports containing information about international payments (for example, the Z4 report).

To view and edit items already present in your account, go to _Lists > Accounting > Items_. To create a new item, go to _Lists > Accounting > Items > New_ and select one of the item types from the list. For more information about item records in NetSuite, see [Using Item Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N2164525.html).
