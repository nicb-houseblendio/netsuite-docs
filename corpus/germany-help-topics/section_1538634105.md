Note:

This feature requires the Deferred VAT SuiteApp

NetSuite provides you the ability to view the status of your deferred VAT journal creation requests. This is useful to keep track of your submissions creating deferred VAT recognition journal entries.

#### To view deferred VAT process status:

1.  Go to the Process Status page:
    
    -   In Accounting Center, go to Financial > Lists > View Defer VAT Process Status.
        
    -   In Classic Center, go to Transactions > Financial > View Defer VAT Process Status.
        
2.  Select a start date in the **Date Created From** field.
    
3.  Select an end date in the **To** field.
    
4.  Click **Refresh**.
    
5.  (Optional) Click **Complete** under **Submission Status** column to view the journal entries created by this submission. For details, see [Viewing Journal Entries Created For Deferred VAT Recognition](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1539167097.html).
