The Germany Intrastat report can be generated for monthly tax periods only. If you have multiple months to generate, you must generate the report one month at a time.

#### To generate the Germany Intrastat report:

1.  Go to Reports > VAT/GST > EU Intrastat Report.
    
2.  Select your Germany subsidiary.
    
3.  In the **Report Type** dropdown, you can select between **Sale** (for Dispatches) or **Purchase** (for Arrivals).
    
4.  In the **Country Form** dropdown, you can select between **Germany (Deutsch)** for the German version or **Germany (English)** for the English version of the form.
    
5.  Choose the reporting period that you want to generate. Select the month from the **Tax Period** (from) and **To** fields.
    
6.  In the **Accounting Book** field, select which accounting book will be used to generate the report. This field is available if the Multi-Book Accounting feature is enabled. The dropdown list shows all active books associated with the selected subsidiary. For more information, see [Multi-Book Accounting for International Tax Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4108426899.html).
    
7.  To display the report, click **Refresh**. Each time you change the reporting criteria, click **Refresh**.
    
    Important:
    
    For the saved reports in the International Tax Reporting SuiteApp, results are limited to 25,000 rows. A truncated report will display this note at the bottom of the page:
    
    'The results of this report are too large. Please narrow your results.' If you want to request for an increase in the limit, you must file a Support case.
    
8.  Review the report. Take note of the following when reviewing reports:
    
    -   Review all pages of the report.
        
    -   To specify the number of rows displayed on each page, go to the **General** subtab in _Home > Set Preferences_.
        
    -   All transactions that have the same values in the following fields are consolidated to one line:
        
        -   Commodity Code
            
        -   Country of Destination
            
        -   Region of Origin
            
        -   NoTC
            
        -   Mode of Transport
            
        -   Country of Origin
            
        -   VAT ID No. of the Partner Operator
            
        -   Delivery Terms
            
        
        The Net Mass, Value, Statistical Value, and Supplementary Unit of the consolidated transactions are added to get the total sum.
        
9.  Check the **Exclude** box for each transaction that you want to omit from your report. You can also click **Mark All** or **Unmark All**.
    
10.  To save the report, click any of the following options:
     
     -   **Print** - to generate a PDF version of the report that you can print or save for your own records. When you print a Germany Intrastat Report, NetSuite saves it as a PDF in the File Cabinet. You may specify the Output Folder for Intrastat Reports on the Tax Filing Setup page. The default name for this folder is Germany Intrastat and is stored in the root folder of the file cabinet. Go to Documents > Files > File Cabinet and click the Intrastat folder to download and view the report.
         
         For information about the Tax Filing Setup page, see [Setting Up Tax Filing for Germany](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1917361.html).
         
     -   **Export to Excel** - to save the Intrastat report as a Microsoft Excel (.xls) file.
         
     -   **Export to CSV** - to save the Intrastat report as a CSV file. To export the Germany Intrastat report in a format acceptable for upload to the tax agency website, see [Exporting the Germany Intrastat Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164380364524.html).
