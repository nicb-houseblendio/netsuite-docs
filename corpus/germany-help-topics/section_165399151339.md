If you have a German nexus, you can generate a localized Recapitulative Statement (EU Sales List) report for Germany.

To use the Recapitulative Statement (EU Sales List) feature, the Tax Reporting Framework SuiteApp must be installed in your NetSuite account. For more information, see [Tax Reporting Framework](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1528262949.html).

The Germany Recapitulative Statement (EU Sales List) report supports Multi-Book Accounting. For more information, see [Multi-Book Accounting Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_3831567542.html).

To generate the Germany Recapitulative Statement (EU Sales List) report, see [Generating Localized Country Tax Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1528250223.html). You can also export the report to PDF, XLS and CSV (ELSTER) formats. For more information, see [Exporting a Country Tax Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_156645000208.html).

The form displays the following information:

| Column Name | Description |
| --- | --- |
| Country code | Country code prefix of the customer's VAT registration number |
| Customer VAT number | Customer's VAT number without the country prefix |
| Customer | Name of the customer as stated in the Customer Record |
| Value of supplies | Total value of supplies of goods or services made in the reporting period |
| Indicator | Specifies the type of transaction, whether it's triangular trade, goods, or service |

Report date is aggregated according to the following:

-   Search Type
    
-   Transaction Type
    
-   Tax Code
    
-   Tax Transaction Type
    
-   Tax Item Type
    
-   Tax Reporting Category
