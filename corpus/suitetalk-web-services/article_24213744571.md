An other charge for sale item record exposes an other charge for sale item to REST web services. This record is not a subrecord.

The REST API Browser includes information about the field names and field types of the other charge for sale record, and about the HTTP methods, request parameters, and operations available to this record. For details, see the REST API Browser's [other charge sale item](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2026.1/index.html#tag-otherChargeSaleItem) reference page.

For information about using the REST API Browser, see [The REST API Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157373386674.html).

## Record IDs {#subsect_40213756366}

The record ID for an other charge for sale item REST record is **otherChargeSaleItem**.

## Code Samples {#subsect_65213811325}

The following samples show common use cases for other charge for sale items. The example ID is 4.

### Creating an Other Charge for Sale Item Using a POST Request {#subsect_9213819702}

              `POST https://demo123.suitetalk.api.snap.netsuite.com/services/rest/record/v1/otherChargeSaleItem { "itemId": " Other Charge for Sale", "displayName": "displayName", "upcCode": "code" }` 
            

### Retrieving an Other Charge for Sale Item Using a GET Request {#subsect_92213826649}

              `GET https://demo123.suitetalk.api.snap.netsuite.com/services/rest/record/v1/otherChargeSaleItem/4` 
            

### Updating an Other Charge for Sale Item Using a PATCH Request {#subsect_47213833263}

              `PATCH https://demo123.suitetalk.api.snap.netsuite.com/services/rest/record/v1/otherChargeSaleItem/4 { "itemId": " Other Charge for Sale A", "displayName": "displayName A", "upcCode": "code A" }`
