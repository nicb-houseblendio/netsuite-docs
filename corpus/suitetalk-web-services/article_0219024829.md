A serialized assembly item is an assembly item made up of several components but identified as a single item. Each quantity of the assembly item is assigned a unique serial number. Assemblies are manufactured by combining raw materials that you stock.

For more information about serialized assembly items, see [Building a Serialized Assembly](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2234538.html). For information about assemblies, see [Assembly Items](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2318089.html#bridgehead_N2318216).

This record is not a subrecord.

The REST API Browser includes information about the field names and field types of the serialized assembly item record, and about the HTTP methods, request parameters, and operations available to this record. For details, see the REST API Browser's [serialized assembly item](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2026.1/index.html#tag-serializedAssemblyItem) reference page.

For information about using the REST API Browser, see [The REST API Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157373386674.html).

## Record ID {#subsect_44144917285}

The record ID for the serialized assembly item REST record is **serializedAssemblyItem**.

## Prerequisites {#subsect_24144912387}

You must enable the Assembly Items and Serialized Inventory features before you can use this record through REST web services.

## Limitations {#subsect_50144904624}

A serialized assembly item REST record does not show Quantity Pricing Discount/Levels (quantitypricingdiscount, quantitypricinglevel) or the Item Translations subtab (translations).

Note:

REST web services do not support legacy tax features. To work with taxation through REST web services, you must have the SuiteTax feature enabled. For more information about using SuiteTax, see [SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/preface_1496364245.html).
