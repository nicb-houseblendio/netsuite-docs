A partner record exposes a partner to REST web services.

For more information about partners and how they function in the user interface, see [Partners](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/book_N1166406.html).

To access this record in NetSuite, go to _Lists > Relationships > Partners_.

This record:

-   is not a subrecord
    
-   has no subrecords
    

The following sublists are not accessible through REST web services:

-   bulkmerge
    
-   subscriptionmessagehistory
    
-   subscriptions
    
-   taxregistration
    

The REST API Browser includes information about the field names and field types of the partner record, and about the HTTP methods, request parameters, and operations available to this record. For details, see the REST API Browser's [partner](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2026.1/index.html#tag-partner) reference page.

For information about using the REST API Browser, see [The REST API Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157373386674.html)

Note:

REST web services do not support legacy tax features. To work with taxation through REST web services, you must have the SuiteTax feature enabled. For more information about using SuiteTax, see [SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/preface_1496364245.html).

## Record ID {#subsect_15151625611}

The record ID for the partner REST record is **partner**.

## Prerequisites {#subsect_70151734940}

You must enable the CRM feature before you can use this record through REST web services.

## Code Sample {#subsect_40152133044}

The following samples show common use cases for a partner record. The example ID is 5.

### Retrieving Partner Metadata {#subsect_9161855226}

              `GET https://demo123.suitetalk.api.snap.netsuite.com/services/rest/record/v1/metadata-catalog/partner` 
            

### Retrieving a Partner Using a GET Request {#subsect_13164610280}

              `GET https://demo123.suitetalk.api.snap.netsuite.com/services/rest/record/v1/partner/5` 
            

### Creating a Partner Using a POST Request {#subsect_25163427266}

              `POST https://demo123.suitetalk.api.snap.netsuite.com/services/rest/record/v1/partner { "partnerCode": "EXAMPLE COMPANY", "companyName": "Example Company", "subsidiary": "3" }` 
            

### Updating a Partner Using a PATCH Request {#subsect_21170105010}

              `PATCH https://demo123.suitetalk.api.snap.netsuite.com/services/rest/record/v1/partner/5 { "companyName": "Updated Company Name" }` 
            

### Deleting a Partner Using a DELETE Request {#subsect_38164248920}

              `DELETE https://demo123.suitetalk.api.netsuite.com/services/rest/record/v1/partner/5`
