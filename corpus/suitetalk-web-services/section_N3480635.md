Important:

In many cases, you can achieve the equivalent of SOAP operations using REST web services. For a comparison of available operations in SOAP and REST web services, see [SOAP Web Services vs. REST Web Services Operation Mapping](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164155878349.html).

The following asynchronous equivalents are available for these list operations:

-   [addList](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3481360.html): asyncAddList
    
-   [updateList](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3527652.html): asyncUpdateList
    
-   [upsertList](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3533243.html): asyncUpsertList
    
-   [deleteList](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3486552.html): asyncDeleteList
    
-   [getList](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3499748.html): asyncGetList
    
-   [search](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3514306.html): asyncSearch
    
-   [initialize / initializeList](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3508536.html): asyncInitializeList
    

You can use the [checkAsyncStatus](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3485891.html) and [getAsyncResult](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3489563.html) operations to track asynchronous requests. For information about asynchronous request processing, see [Asynchronous Request Processing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3770809638.html) and [Synchronous Versus Asynchronous Request Processing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3444207.html).
