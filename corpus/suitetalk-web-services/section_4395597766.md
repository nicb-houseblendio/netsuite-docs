Regenerate the consumer key and secret if you've lost them for an integration record created in your account. Note that resetting the credentials invalidates the old ones.

You can still use existing tokens and token secrets after resetting the consumer key and secret. However, you must use them with the new consumer key and secret.

You can't reset credentials for records installed by bundling. Only an authorized user in the original NetSuite account can reset the credentials.

Note:

Only administrators can complete this procedure.

#### To regenerate a consumer key and secret: {#procedure_4395600198}

1.  Go to _Setup > Integration > Manage Integrations_.
    
2.  Select the record for which you want to generate a new consumer key and secret.
    
    The record opens in view mode.
    
3.  Click the **Edit** button.
    
4.  Click the **Reset Credentials** button.
    
    Note:
    
    The **Reset Credentials** button is only displayed if the integration is using TBA.
    
    ![Reset Credentials button on an integration record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/SuiteTalkWebServices/ResetTBACredentials.png)
    
    The system displays a popup message asking if you are sure you want to reset the credentials.
    
5.  Click **OK**.
    
    The system resets the credentials. The record is again shown in view mode, with the new consumer key and secret displayed.
    

Warning:

Consumer key and secret values are only shown on the confirmation page for security reasons. When you leave the page, you can't retrieve these values from the system. If you lose or forget your credentials, reset them to get new ones. Handle these credentials like you would a password. Keep these credentials secure: don't share them with others or send by email.
