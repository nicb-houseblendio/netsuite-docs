To get permissions assigned to a role, send a SuiteQL query with the role id. Add the limit and offset criteria to your request to get the results in multiple pages. For more information about pagination, read [Collection Paging](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156414087576.html).

Note that `Prefer: transient` is a required header parameter.

          `POST {{REST_SERVICES}}/query/v1/suiteql?limit=5&offset=10 {     "q": "SELECT * FROM rolepermissions WHERE role = 1028" }`
