The ProjectTaskAssignmentSearchBasic record is not a stand-alone search record. It must be used in conjunction with a search join from the projectTaskSearch record.

The ProjectTaskAssignmentSearchBasic is defined in the [platformCommon](https://webservices.netsuite.com/xsd/platform/v2025_2_0/common.xsd) XSD.

## Field Definitions {#bridgehead_N3654444}

See [SOAP Schema Browser](https://system.netsuite.com/help/helpcenter/en_US/srbrowser/Browser2026_1/schema/search/projecttaskassignmentsearchbasic.html?mode=package) for a list of all project task assignment search filter fields.

For information about working with search filter fields and search joins, see the [search](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3514306.html) () operation in the NetSuite Help Center.
