To create a vendor bill, include values for fields such as vendor and item details in the request body.

          `POST {{REST_SERVICES}}/record/v1/vendorbill {     "entity": {         "id": "1722"     },     "item": {         "items": [             {                 "item": {                     "id": 84                 },                 "quantity": 25,                 "rate": 100             }         ]     } }`
