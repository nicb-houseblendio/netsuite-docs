Check out the following sections to learn how to use this material and find information about supported records, fields, and sublists in SOAP web services:

-   [How to Use the SOAP Web Services Records Help](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3635039.html) - describes how to use both the PDF and online versions of this guide with the SOAP Schema Browser.
    
-   [SOAP Web Services Supported Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3635369.html) - provides links to all records supported in SOAP web services.
    
-   [SOAP Schema Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3639052.html) - describes the SOAP Schema Browser and how to use it with the NetSuite Help Center material.
    

To learn more about SOAP platform features, operations, types, warnings, errors, and faults, see [SuiteTalk SOAP Web Services Platform Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N3412777.html).

Important:

The Records Guide currently covers the 2025.2 endpoint.

Important:

Some endpoints that pre-date 2025.2 are still supported. For documentation about these endpoints, see [SOAP Web Services Archives](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3892701016.html).
