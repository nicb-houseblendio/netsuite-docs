Important:

Most types of records are also supported in REST web services. For a list of all records supported in REST, see [REST Web Services Supported Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1558962745.html).

Note:

Processed lines for this record type do not contribute to the Monthly Transaction Lines metric that counts toward maximum limits for your NetSuite service tier. For more information, see Transaction Types Included in [Transaction Types Included in Monthly Transaction Lines Metric](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160311737279.html).

For information about transactions that do contribute to the Monthly Transaction Lines metric, see [Transactions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N3657735.html).
