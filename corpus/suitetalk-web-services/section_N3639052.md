## Viewing the SOAP Schema Browser {#bridgehead_4803473821}

**[Go to the SOAP Schema Browser](https://system.netsuite.com/help/helpcenter/en_US/srbrowser/Browser2026_1/schema/index.html)**.

The [SOAP Schema Browser](https://system.netsuite.com/help/helpcenter/en_US/srbrowser/Browser2026_1/schema/index.html) gives you an overview of all available records, sublists, and objects in SOAP web services. You'll find object information in series of tables, with more details than the WSDL.

For more details about the SOAP Schema Browser, see the following:

-   [Finding a Record or Subrecord](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3975716851.html)
    
-   [Finding Other Objects](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3975714806.html)
    
-   [Default View](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3975713667.html)
    
-   [Namespace View](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3975743909.html)
    

You can use the SOAP Schema Browser online, or you can download it. For help downloading the browser, see [Downloading the SOAP Schema Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3635039.html#bridgehead_N3635209).

Note:

Only the 2025.2 SOAP Schema Browser is currently supported. Older versions may still be accessible, but they aren't supported.
