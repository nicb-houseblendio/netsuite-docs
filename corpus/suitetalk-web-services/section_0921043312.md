Knowledge base solutions are organized by a hierarchy of topics and subtopics. When you publish a topic, you also publish its subtopics and the solutions attached to these subtopics.

Use the topic record to create new topics and expose them to REST web services.

To learn more, see [Support Case](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_91142453659.html).

This record:

-   is not a subrecord
    
-   has no subrecords
    

The REST API Browser includes information about the field names and field types of the topic record, and about the HTTP methods, request parameters, and operations available to this record. For details, see the REST API Browser's [topic](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2026.1/index.html#tag-topic) reference page.

For information about using the REST API Browser, see [The REST API Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157373386674.html).

## Record ID {#subsect_92163526332}

The record ID for a topic REST record is **topic**.

## Prerequisites {#subsect_75163537155}

You must enable Enable Features > CRM > Support > Knowledge Base feature and Permissions > Lists > Knowledge Base before you can use this record through REST web services.

## Elements Not Accessible Through REST Web Services {#subsect_52163549291}

The following elements are not accessible through REST web services:

-   subtopics
    
-   solutions
    
-   notes
    
-   publish
    

## Usage Notes {#subsect_88163601358}

Review the following notes on working with the topic REST record:

-   `title` is required, all other fields are optional
    

## Code Sample {#subsect_92163616167}

The following samples show common use cases for topic.

### Creating a Topic {#subsect_13163631562}

              `POST https://demo123.suitetalk.api.snap.netsuite.com/services/rest/record/v1/topic Body: { "title": "REST title", "description": "<p>A Description</p>", "isInactive": false, "longDescription": "<p>Long Description</p>", "parentTopic": 2 }` 
            

### Retrieving a Topic {#subsect_90163644570}

              `GET https://demo123.suitetalk.api.snap.netsuite.com/services/rest/record/v1/topic/4` 
            

### Updating a Topic {#subsect_2163654235}

              `PATCH https://demo123.suitetalk.api.snap.netsuite.com/services/rest/record/v1/topic/4 Body:{ "title": "Updated REST title", "description": "<p>Updated Description</p>", "isInactive": true, "longDescription": "<p>Updated Description</p>", "parentTopic": 3 }` 
            

### Deleting a Topic {#subsect_53163705937}

              `DELETE https://demo123.suitetalk.api.snap.netsuite.com/services/rest/record/v1/paymentItem/4`
