A transfer order transaction records the change in location of inventory items within the same subsidiary. It also records the quantity and shipping details.

This transaction is available when the Locations feature and the Multi-Location Inventory (MLI) feature are enabled. A transfer order can initialize item fulfillment and item receipt transactions. It has one subrecord: inventory detail. See [Item Fulfillment](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3680777.html) and [Item Receipt](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3681685.html). For more information about transfer orders, see [Inventory Transfer Orders](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2308766.html).

The REST API Browser includes information about the field names and field types of the transfer order record, and about the HTTP methods, request parameters, and operations available to this record. For details, see the REST API Browser's [transfer order](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2026.1/index.html#tag-transferOrder) reference page.

For information about using the REST API Browser, see [The REST API Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157373386674.html).

## Record IDs {#subsect_77141203988}

The record ID for a transfer order REST record is **transferorder**.

The record ID for an inventory detail REST subrecord is **inventorydetail**.

## Prerequisites {#subsect_7141236907}

There are no prerequisites for using the record in REST.
