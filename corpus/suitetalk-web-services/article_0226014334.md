The campaign channel record exposes a campaign channel to REST web services.

This record:

-   is not a subrecord
    
-   contains one subrecord: eventType
    

For more information about working with campaign channels in the UI, see [Campaign Channels](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N987856.html).

The REST API Browser includes information about the field names and field types of the campaign channel record and about the HTTP methods, request parameters, and operations available to this record. For details, see the REST API Browser's [campaign channel](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2026.1/index.html#tag-campaignChannel) reference page.

For information about using the REST API Browser, see [The REST API Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157373386674.html).

## Record ID {#subsect_28134421482}

The record ID for a campaign channel record is **campaignchannel**.

## Prerequisites {#subsect_50134426319}

You must enable the Marketing Automation feature before you can use this record through REST web services. For more information, see [Marketing Automation Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N973384.html).

## Additional Details {#subsect_0226015013}

When working with the campaign channel record, the eventType field can't be updated.
