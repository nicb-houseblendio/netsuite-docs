To create an invoice with an item, include the values of required fields such as posting period, location, item ID, and amount in the request body.

          `POST {{REST_SERVICES}}/record/v1/invoice/ {     "entity": {         "id": "614"     },     "postingperiod": "21",     "location": 1,     "item": {         "items": [             {                 "amount": 1000.0,                 "item": {                     "id": "86"                 }             }         ]     },     "subsidiary": {         "id": "1"     },     "terms": {         "id": "1"     } }` 
        

For more options to create an invoice using REST API, see [Invoice](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161488248489.html).
