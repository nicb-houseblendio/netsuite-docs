To create an event, include values for fields such as title, status, and start date in the request body.

          `POST {{REST_SERVICES}}/record/v1/calendarevent/ {     "title": "Meeting with Tom",     "status": "CONFIRMED",     "message": "Let's discuss work",     "location": "Caffe West",     "startdate": "2023-11-04" }`
