All elements on this record are accessible through REST web services.

The REST API Browser includes information about the field names and field types of the win/loss reason record and about the HTTP methods, request parameters, and operations available to this record. For details, see the REST API Browser's [win/loss reason](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2026.1/index.html#tag-winLossReason) reference page.

## Record IDs {#subsect_0227112716}

The record ID for a win/loss REST record is **winLossReason**.
