The HCM Job record exposes a job to REST web services.

This record:

-   Is not a subrecord
    

The REST API Browser includes information about the field names and field types of the HCM job record and about the HTTP methods, request parameters, and operations available to this record. For details, see the REST API Browser's [HCM job](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2026.1/index.html#tag-hcmJob) reference page.

For information about using the REST API Browser, see [The REST API Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157373386674.html).

## Record IDs {#subsect_0718103032}

The record ID for an HCM Job REST record is **hcmjob**.

## Prerequisites {#subsect_0718103144}

Before you can use this record with REST web services, you must enable the Job Management feature.

## Exposed Elements {#subsect_0718103222}

The following record fields are exposed to REST web services:

-   Description
    
-   Employmentcategory
    
-   Externalid
    
-   Id
    
-   Internalid
    
-   Isinactive
    
-   Jobid
    
-   Jobidlabel
    
-   Title
    

## Supported Operations {#subsect_0718103513}

The following actions are available on this record:

-   Submit
    
-   Submit New
    
-   Delete
    

## Code Samples {#subsect_0718103656}

The following code shows how to get a job:

            `GET  https://demo123.suitetalk.api.netsuite.com/services/rest/record/v1/hcmjob/326` 
          

The following code shows how to update a job description:

            `PATCH https://demo123.suitetalk.api.netsuite.com/services/rest/record/v1/hcmjob/326  {   "description": "Updated description" }'` 
          

The following code shows how to create a job:

            `POST https://demo123.suitetalk.api.netsuite.com/services/rest/record/v1/hcmjob {   "description": "New Description",   "employmentCategory": {     "id": "-10"   },   "title": "New job rest" }`
