The accounting book record lets you create secondary accounting books when Multi-Book Accounting feature is enabled in your NetSuite account.

In the NetSuite UI, you can access the accounting book record at _Setup > Accounting > Multi-Book Accounting > Accounting Books_.

Important:

You need to have the **Multi-Book Accounting** feature enabled and you must have the **Accounting Book Administrator** permission to work with this record.

The accounting book record is exposed in REST web services as `accountingBook`, and the _HTTP_ methods for working with this record are described on the [The REST API Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157373386674.html) page.

For more information about adding accounting books in NetSuite UI, see [Adding Accounting Books](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4842479230.html).

The REST API Browser includes information about the field names and field types of the accounting book record and about the HTTP methods, request parameters, and operations available to this record. For details, see the REST API Browser's [accounting book](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2026.1/index.html#tag-accountingBook) reference page.

For information about using the REST API Browser, see [The REST API Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157373386674.html).

## Record ID {#subsect_0313103742}

In REST web services, the record ID for accounting book is `accountingBook`.

This record has subrecord **Subsidiaries**, with the record ID: `accountingBookSubsidiaries`.

## Inaccessible Elements {#subsect_0313104121}

All elements of this record are accessible in REST web services. However, the `AccountingBookSubsidiaries` subrecord has a fixed number of lines (corresponding to the number of subsidiary options), new lines can't be added and existing lines can't be removed.

## Code Sample {#subsect_0313104230}

The code sample below shows how to create an accounting book:

            `POST /services/rest/record/v1/accountingBook/ {"name": "Secondary Book - IFRS", "isPrimary": false, "includeChildren": true}` 
          

The code sample below shows how to retrieve an accounting book:

            `GET /services/rest/record/v1/accountingBook/1`
