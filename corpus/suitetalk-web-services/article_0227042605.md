The lead source record exposes a lead source to REST web services.

This record:

-   is not a subrecord
    
-   contains no subrecords
    

For more information about working with lead sources in the UI, see [Lead Sources](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N975884.html).

The REST API Browser includes information about the field names and field types of the lead source record and about the HTTP methods, request parameters, and operations available to this record. For details, see the REST API Browser's [lead source](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2026.1/index.html#tag-leadSource) reference page.

For information about using the REST API Browser, see [The REST API Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157373386674.html).

## Record ID {#subsect_40162954810}

The record ID for a lead source REST record is **leadsource**.

## Prerequisites {#subsect_16162958629}

You must enable the CRM feature before you can use this record through REST web services.
