When writing SOAP web services you will want to capture and analyze SOAP request and response messages associated with an operation call. You can use such products as Actional Diagnostics or SOAPScope. NetSuite also provides access to SOAP requests and responses for review. You can download these files from the Execution Log of each integration record, or you can use the SOAP Web Services Usage Log, which shows the logs from all integration records. For details on working with integration records, see [Integration Management](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4399047360.html). For details on using the usage log, see [Using the SOAP Web Services Usage Log](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3444819.html).
