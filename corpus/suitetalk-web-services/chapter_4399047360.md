As of 2015.2, all external applications that send SOAP web services requests to your NetSuite account are represented by one or more integration records. You can use integration records to manage applications, view activity logs, and more.

An integration record represents any app that sends web services requests or calls RESTlets. However, some integration record capabilities are limited for RESTlet activity. This section focuses on using integration records with SOAP web services activity.
