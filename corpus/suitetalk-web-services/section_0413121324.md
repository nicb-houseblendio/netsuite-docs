To give a role access to a vendor, enable the **Give Access** box and add the role details in the request body.

          `PATCH {{REST_SERVICES}}/record/v1/vendor/<id>/ {     "giveaccess": true,     "roles": {         "items": [             {                 "selectedRole": {                     "id": "6"                 }             }         ]     } }`
