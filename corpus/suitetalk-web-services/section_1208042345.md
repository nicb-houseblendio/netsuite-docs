To add employee address, send a PATCH request with the address details in the request body.

          `PATCH {{REST_SERVICES}}/record/v1/employee/<id>/ {     "addressbook": {         "items": [             {                 "label": "New York HQ",                 "addressbookaddress": {                     "country": "US",                     "state": "NY",                     "zip": "10001",                     "addressee": "New company"                 }             }         ]     } }`
