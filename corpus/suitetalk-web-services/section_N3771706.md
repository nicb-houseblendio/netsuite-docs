Custom record custom fields can only be set on a custom record after the custom record has been created.

The custom record custom field record is defined in the [setupCustom (customization)](https://webservices.netsuite.com/xsd/setup/v2025_2_0/customization.xsd) XSD.

## Supported Operations {#bridgehead_N3771727}

The following operations can be used with custom record custom fields.

[add](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3480855.html) | [addList](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3481360.html) | [delete](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3486046.html) | [deleteList](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3486552.html) | [get](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3488543.html) | [getList](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3499748.html) | [getSelectValue](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3504236.html) | [update](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3527090.html) | [updateList](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3527652.html) | [upsert](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3532463.html) | [upsertList](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3533243.html)

Note:

You can also use the asynchronous equivalents of SOAP web services list operations. For information about asynchronous operations, see [SOAP Web Services Asynchronous Operations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3480635.html). For more information about request processing, see [Synchronous Versus Asynchronous Request Processing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3444207.html).

## Usage Notes {#bridgehead_N3771931}

The following figure shows the UI equivalent of creating a custom record custom field. First you must create a new custom record type. After the new type is created, click the New Field button on the Fields subtab. This is the only way you can create a custom record custom field, which is directly associated with the custom record type. Therefore, you cannot directly search for custom record custom fields using either the search() or getCustomization() operations. You must perform a record type search and locate your custom record custom field within that search.

![A new custom record type in the UI.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/SuiteTalkWebServices/customRecordCustomField.png)

As of 2018.2, you can use a unified script ID to identify a custom segment. If you use the unified script ID, the script ID does not uniquely identify the record instance. The unified script ID generated by one custom segment on several custom record custom fields can be the same. For more information, see [Identifying the Correct Script ID for a Custom Segment](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4514248688.html).

For custom fields not related to custom segments, the definition and data can be identified using the same script ID.

This is different for custom fields generated from custom segments that use the unified script ID. The identification uses the legacy script ID, but the data instance uses the unified script ID.
