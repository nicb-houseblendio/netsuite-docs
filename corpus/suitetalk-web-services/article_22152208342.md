Support case type categorizes the kind of issue or request associated with each support case, for example, Request, Question, or Problem.

This record is not a subrecord and does not have subrecords.

The REST API Browser includes information about the field names and field types of the support case type record, and about the HTTP methods, request parameters, and operations available to this record. For details, see the REST API Browser's [support case type](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2026.1/index.html#tag-supportCaseType) reference page.

For information about using the REST API Browser, see [The REST API Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157373386674.html).

## Record ID {#subsect_60152738249}

The record ID for a support case status REST record is **supportcasetype**.

## Prerequisites {#subsect_64152744468}

You must enable the following before you can use this record through REST web services:

-   Feature: CRM > Customer Support and Service
    
-   Permission: Setup > Support Case Type
    

## Code Sample {#subsect_58152751937}

The following samples show common use cases for support case type.

### Creating a Support Case Type {#subsect_97152758165}

              `POST https://demo123.suitetalk.api.netsuite.com/services/rest/record/v1/supportcasetype Body: { "name": "Request" }` 
            

### Reading a Support Case Type {#subsect_97152802756}

              `GET https://demo123.suitetalk.api.netsuite.com/services/rest/record/v1/supportcasetype/{id}` 
            

### Updating a Support Case Type {#subsect_90152808406}

              `PATCH https://demo123.suitetalk.api.netsuite.com/services/rest/record/v1/supportcasetype/{id} Body: { "description": "Customer asks for a new service or action" }` 
            

### Deleting a Support Case Type {#subsect_17152813251}

              `DELETE https://demo123.suitetalk.api.netsuite.com/services/rest/record/v1/supportcasetype/{id}`
