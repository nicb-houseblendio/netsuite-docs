The campaign family record exposes a campaign family to REST web services.

This record:

-   is not a subrecord
    
-   contains no subrecords
    

For more information about working with campaign families in the UI, see [Campaign Families](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1006480.html).

The REST API Browser includes information about the field names and field types of the campaign family record and about the HTTP methods, request parameters, and operations available to this record. For details, see the REST API Browser's [campaign family](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2026.1/index.html#tag-campaignFamily) reference page.

For information about using the REST API Browser, see [The REST API Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157373386674.html).

## Record ID {#subsect_90142030382}

The record ID for a campaign family REST record is **campaignfamily**.

## Prerequisites {#subsect_61142035607}

You must enable the Marketing Automation feature before you can use this record through REST web services. For more information, see [Marketing Automation Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N973384.html).
