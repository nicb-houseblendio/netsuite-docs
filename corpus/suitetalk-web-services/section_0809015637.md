A pricing group record exposes a pricing group to REST web services.

To access this record in NetSuite, go to Setup > Accounting > Accounting Lists > New > Pricing Group.

The REST API Browser includes information about the field names and field types of the pricing group record. It also includes information about the HTTP methods, request parameters, and operations available to this record. For details, see the REST API Browser's [pricing group](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2026.1/index.html#tag-pricingGroup) reference page.

For information about using the REST API Browser, see [The REST API Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157373386674.html).

## Record ID {#subsect_36153546503}

The record ID for a pricing group REST record is **pricinggroup**.

## Prerequisites {#subsect_64142316014}

You must enable Multiple Prices before you can use this record through REST web services. To do so, go to Setup > Company > Enable Features. On the **Transactions** subtab under Sales, check the **Multiple Prices** box, and then click **Save**.

## Actions {#subsect_9144339600}

The pricing group record has the following actions through REST web services:

-   Create
    
-   Read
    
-   Update
    
-   Delete
    

## Code Samples {#subsect_16153707627}

The following samples show common use cases for pricing groups. The example ID is 6.

### Creating a Pricing Group Using a POST Request {#subsect_54212923825}

              `POST {{REST_SERVICES}}/services/rest/record/v1/pricinggroup { "name": "Test Pricing Group", "externalid": "pricinggroup1", "isInactive": false }` 
            

### Retrieving a Pricing Group Using a GET Request {#subsect_64151235034}

              `GET {{REST_SERVICES}}/services/rest/record/v1/pricinggroup/6` 
            

### Updating a Pricing Group Using a PATCH Request {#subsect_25212911838}

              `PATCH {{REST_SERVICES}}/services/rest/record/v1/pricinggroup/6 { "name": "Updated Pricing Group", "externalid": "pricinggroup2", "isInactive": true }` 
            

### Deleting a Pricing Group Using a DELETE Request {#subsect_31212859219}

              `DELETE {{REST_SERVICES}}/services/rest/record/v1/pricinggroup/6`
