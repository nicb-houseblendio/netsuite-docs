Merchandise Hierarchy is a feature that enables you to plan, price, report on, and analyze your product inventory by categorizing inventory items in your enterprise. For more information, see [Merchandise Hierarchy Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1499436261.html).

A merchandise hierarchy node provides groupings for items that share similar characteristics. They can either be a point in the hierarchy from which other nodes can be created, or the point in the hierarchy where products are assigned to.

A Merchandise Hierarchy Node record contains details of the position of the node in the hierarchy, and the hierarchy version or versions in which it is included.

To work with Merchandize Hierarchy Node records in SOAP Web Services, the hierarchy versions and hierarchy levels need to have been defined in the UI. For more information about defining the hierarchy versions and levels, see [Creating a Hierarchy Version](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1529072633.html) and [Creating a Hierarchy Level](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1529072726.html).

The Merchandise Hierarchy Node record is available only when the following features are enabled:

-   Merchandise Hierarchy in _Setup > Company > Setup Tasks > Enable Features_, Items & Inventory subtab.
    
-   Custom Segments in _Setup > Company > Setup Tasks > Enable Features_, SuiteCloud subtab.
    

For more information, see [Creating a Hierarchy Node](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1516013743.html).

## Usage Notes {#bridgehead_1556535571}

Consider the following information when you work with Merchandise Hierarchy Nodes.

-   You can set the value of the IsIncluded field to false, when creating it, but then the node will not be visible in the merchandise hierarchy. You will not be able to assign any items to the node, until it is included to a hierarchy version.
    
-   You can update the value of the IsIncluded field to false, if the node does not have items assigned to it, or is not a parent node in that version.
    
-   The HierarchyVersionsList sublist has the hierarchyVersion field as key.
    
-   ReplaceAll is ignored in the sublist. Regardless if set to true or false, SOAP Web Services updates only the specified lines, while leaving the rest of the lines unchanged. So, it behaves more like replaceAll is set to false. No error message is displayed. It is not possible to remove applied lines using replaceAll=true like on other sublists. To remove an applied line, specify its hierarchy version and set the isIncluded field to false.
    
-   When using the operation [get](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3488543.html), SOAP Web Services return all the lines, regardless if they are applied or not.
    

For more information about creating, editing and deleting a hierarchy node, see [Creating a Hierarchy Node](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1516013743.html).

## Code Sample {#bridgehead_1556537581}

In the following example, a new Merchandize Hierarchy Node is created. The hierarchy versions and levels were already defined in the UI environment.

## Java {#bridgehead_1556537710}

          `public void addNewMHN() throws Exception {      MerchandiseHierarchyNodeHierarchyVersions version = new MerchandiseHierarchyNodeHierarchyVersions();     version.setIsIncluded(true);      version.setHierarchyVersion(createRecordRef("1"));     version.setHierarchyLevel(createRecordRef("3"));     version.setParentNode(createRecordRef("2"));      MerchandiseHierarchyNodeHierarchyVersionsList list = new MerchandiseHierarchyNodeHierarchyVersionsList();      list.setMerchandiseHierarchyNodeHierarchyVersions(new MerchandiseHierarchyNodeHierarchyVersions[]{version});      MerchandiseHierarchyNode record = new MerchandiseHierarchyNode();     record.setName("Sci-Fi");     record.setDescription("Sci-Fi books in store");      record.setHierarchyVersionsList(list);      c.addRecord(record); }`
