Default Web Services Integrations Records were only allowed for requests using the 2015.1 or earlier endpoint. Since these endpoints are no longer available, Default Web Services Integrations aren't permitted.

If you were using a Default Web Services Integrations Record, create a new Integration Record as described in [Creating an Integration Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4393879073.html).

Note:

For information about integration records in general, see [Integration Record Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4389727047.html).
