The code USER\_ERROR is returned in the code field of the statusDetail type where the type attribute has a value of warning. A warning message is also returned which varies depending on the exact cause of the warning and is usually self-descriptive. For a complete description of warnings and how they differ from errors and faults, refer to [SOAP Web Services Warnings, Errors, and Faults](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3536574.html).
