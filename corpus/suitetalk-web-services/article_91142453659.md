Support cases are support issues logged for specific companies and used for case management.

Use the support case record to create new support cases and expose them to REST web services.

To learn more, see [Support Management](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/book_N2420978.html).

This record:

-   is not a subrecord
    
-   has one subrecord: supportcaseescalatehist
    

The REST API Browser includes information about the field names and field types of the support case record, and about the HTTP methods, request parameters, and operations available to this record. For details, see the REST API Browser's [support case](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2026.1/index.html#tag-supportCase) reference page.

For information about using the REST API Browser, see [The REST API Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157373386674.html).

## Record ID {#subsect_34142530227}

The record ID for a support case REST record is **supportcase**.

## Prerequisites {#subsect_40142558832}

You must enable the Lists -> Cases permission before you can use this record through REST web services.

## Elements Not Accessible Through REST Web Services {#subsect_40142612374}

## Additional Details {#subsect_3111111505}

The support case record is complex because it is integrated with many features.

Some elements of the support case form behave differently when accessed through REST web services.

## Code Sample {#subsect_54142633905}

The following samples show common use cases for support cases.

### Creating a Support Case {#subsect_8142650447}

              `POST https://demo123.suitetalk.api.netsuite.com/services/rest/record/v1/supportCase With body: { "title": "some subject", "company": { "id": 931 } }` 
            

Note:

To create a support case, you need to have the permission of lists > customers with at least a value of view.

### Reading a Support Case {#subsect_82142701284}

              `GET https://demo123.suitetalk.api.netsuite.com/services/rest/record/v1/supportCase/{{id}}` 
            

### Updating a Support Case {#subsect_53142709426}

              `PATCH https://demo123.suitetalk.api.netsuite.com/services/rest/record/v1/supportCase/{{id}} Body: { "title": "different subject" }` 
            

### Deleting a Support Case {#subsect_30142718902}

              `DELETE https://demo123.suitetalk.api.netsuite.com/services/rest/record/v1/supportCase/{{id}}`
