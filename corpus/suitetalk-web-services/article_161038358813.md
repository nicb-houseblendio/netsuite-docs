A message record exposes a message to REST web services.

This record has the following subrecords:

-   MessageFile
    
-   CcBccRecipient
    

The REST API Browser includes information about the field names and field types of the message record, and about the HTTP methods, request parameters, and operations available to this record. For details, see the REST API Browser's [message](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2026.1/index.html#tag-message) reference page.

For information about using the REST API Browser, see [The REST API Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157373386674.html).

## Record ID {#subsect_161130853160}

The record ID for the message REST record is **Message**.

## Exposed Elements {#subsect_161130857074}

The following message record elements are exposed to REST web services:

-   activity
    
-   author
    
-   authoremail
    
-   bcc
    
-   cc
    
-   emailed
    
-   entity
    
-   externalid
    
-   hasattachment
    
-   htmlmessage
    
-   id
    
-   incoming
    
-   lastmodifieddate
    
-   message
    
-   messagedate
    
-   recipient
    
-   recipientemail
    
-   record
    
-   recordtype
    
-   subject
    
-   template
    
-   time
    
-   transaction
    

## Usage Notes {#subsect_161130867645}

All fields are read-only.

## Code Sample {#subsect_161130877729}

In the following example, `<accountID>` represents your account ID.

HTTP request: `https://<accountID>/services/rest/record/v1/message`

### Request Body {#subsect_161130883712}

              `{ "subject": "Meeting agenda", "message": "Please send the agenda for tomorrow's meeting.", "author": "-5", "authorEmail": "sender@your.example.com", "recipientEmail": "recipient@your.example.com", "cc": "cc_recipient@your.example.com", "bcc": "bcc_recipient@your.example.com" }`
