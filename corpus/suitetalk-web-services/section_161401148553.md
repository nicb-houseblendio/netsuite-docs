A subscription term is a stand-alone record that exposes a SuiteBilling subscription term to REST web services.

The REST API Browser includes information about the field names and field types of the subscription term record, and about the HTTP methods, request parameters, and operations available to this record. For details, see the REST API Browser's [subscription term](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2026.1/index.html#tag-subscriptionTerm) reference page.

For information about using the REST API Browser, see [The REST API Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157373386674.html).

## Record ID {#subsect_161401248653}

The record ID for a subscription term REST record is **subscriptionterm**.

## Prerequisites {#subsect_161401250010}

You must [Enabling SuiteBilling Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1546981120.html) before you can use this record through REST web services.

## Code Sample {#subsect_161401251861}

This sample shows a common use case for creating a subscription plan.

### Create a Six-Month Subscription Term {#subsect_161401302517}

              `POST services/rest/record/v1/subscriptionterm { "name": "Six Months", "subscriptionTermDuration": 6, "subscriptionTermUnit": { "id": "MONTHS" } }`
