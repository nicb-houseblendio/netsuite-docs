NetSuite exposes the payment card token record to REST web services.

Payment card tokens represent payment cards without the need to save the payment card number (PAN). Typically, tokens are created automatically by gateway integrations. Payment gateways can update a token after the token is used. For more information, see [Tokenization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1534257114.html).

The payment card token record isn't a subrecord and doesn't have any subrecords of its own.

The REST API Browser includes information about the field names and field types of the payment card token record and about the HTTP methods, request parameters, and operations available to this record. For details, see the REST API Browser's [payment card token](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2026.1/index.html#tag-paymentCardToken) reference page.

For information about using the REST API Browser, see [The REST API Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157373386674.html).

## Record ID {#subsect_0303081643}

The record ID for payment card token is **paymentcardtoken**.

## Prerequisites {#subsect_0303081835}

-   enable the Payment Instruments feature. For instructions, see [Payment Instruments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1538492538.html).
    
-   enable the Credit Card Payments feature. For instructions, see [Setting Up Customer Credit Card Processing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1572221.html).
    

## Code Samples {#subsect_0303081907}

The code samples in this section show common use cases for payment card token.

### Creating a Payment Card Token {#subsect_0303081939}

              `POST https://123456.suitetalk.api.netsuite.com/services/rest//record/v1/paymentCardToken {     "cardBrand": {         "id": "1"     },      "paymentMethod": {         "id": "19"     },     "cardExpirationDate": "2029-12",     "cardIssuerIdNumber": "123456789",     "cardLastFourDigits": "4111",     "cardNameOnCard": "John Smith",     "cardType": {         "id": "CREDIT"     },     "entity": {         "id": "28"     },     "isDefault": false,     "preserveOnFile": true,     "token": "tkntkntkntkn",     "tokenExpirationDate": "2029-12",     "tokenFamily": {         "id": "1"     },     "tokenNamespace": "NMSPC" }` 
            

### Updating a Payment Card Token {#subsect_0303082111}

              `PATCH https://123456.suitetalk.api.netsuite.com/services/rest//record/v1/paymentCardToken/<id> {    "memo": "Updated MEMO" }`
