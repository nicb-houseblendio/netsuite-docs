A ship item record exposes a ship item to REST web services. This record is not a subrecord.

The REST API Browser includes information about the field names and field types of the ship item record, and about the HTTP methods, request parameters, and operations available to this record. For details, see the REST API Browser's [ship item](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2026.1/index.html#tag-shipItem) reference page.

For information about using the REST API Browser, see [The REST API Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157373386674.html).

## Record IDs {#subsect_19232405733}

The record ID for a ship item REST record is **shipitem**.

## Taxation {#subsect_95235009813}

Note:

REST web services do not support legacy tax features. To work with taxation through REST web services, you must have the SuiteTax feature enabled. For more information about using SuiteTax, see [SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/preface_1496364245.html).

The ship item record includes the following fields related to taxation features:

-   Charge Tax on This Shipping Portion of Item
    
-   Charge Tax on This Handling Portion of Item
    

## Code Samples {#subsect_75232417276}

The following samples show common use cases for ship items. The example ID is 4.

### Creating a Ship Item Using a POST Request {#subsect_65232433258}

This sample shows how to create a $10.00 flat-rate ship item.

              `POST https://demo123.suitetalk.api.snap.netsuite.com/services/rest/record/v1/shipitem { "itemid": "Flat Rate Priority Shipping", "displayname": "Flat Rate Priority Shipping", "description": "Only to be used for priority orders - flat rate 10.00", "subsidiary": "1", "isonline": false, "account": "54", "costbasis": "fr", "shippingflatrateamount": 10.00, "accounthandling": "238", "taxschedule": "1", "taxschedulehandling": "1" }` 
            

### Retrieving a Ship Item Using a GET Request {#subsect_87232455506}

              `GET https://demo123.suitetalk.api.snap.netsuite.com/services/rest/record/v1/shipitem/4` 
            

### Updating a Ship Item Using a PATCH Request {#subsect_98232501066}

This sample shows how to update fields on a ship item.

              `PATCH https://demo123.suitetalk.api.snap.netsuite.com/services/rest/record/v1/shipitem/4 { "itemid": "Flat Rate Priority Shipping - $15", "displayname": "Flat Rate Priority Shipping - $15", "description": "Only to be used for priority orders - flat rate 15.00", "shippingflatrateamount": 15.00 }` 
            

### Deleting a Ship Item Using a DELETE Request {#subsect_4232508986}

              `DELETE https://demo123.suitetalk.api.snap.netsuite.com/services/rest/record/v1/shipitem/4`
