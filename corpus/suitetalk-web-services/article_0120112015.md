An item group is sold as a single unit but made up of several individual items. An item group is a group of items on a sales or purchase order that need to be sold or purchased together. The item group is not fulfilled, received, or stocked. However, the item group is available in the item list on a sales or purchase order and can be added to those transactions.

For more information, see [Item Groups](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2224824.html).

The item group record has one subrecord: **member**.

The REST API Browser includes information about the field names and field types of the item group record, and about the HTTP methods, request parameters, and operations available to this record. For details, see the REST API Browser's [item group](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2026.1/index.html#tag-itemGroup) reference page.

For information about using the REST API Browser, see [The REST API Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157373386674.html).

## Record ID {#subsect_0120112229}

The record ID for the item group REST record is **itemgroup**.

## Inaccessible Elements {#subsect_0120112419}

The **translations** sublist is not exposed to REST web services.

## Code Sample {#subsect_0120112450}

### Creating an Item Group {#subsect_0120112514}

              `POST {{COMPANY_URL}}/services/rest/record/v1/itemGroup { "itemId": "ItemGroup REST TEST", "member": { "items": [ { "item": { "id":"233" }, "quantity":1 } ] } }` 
            

### Getting an Existing Item Group by ID {#subsect_0120112754}

              `GET {{COMPANY_URL}}/services/rest/record/v1/itemGroup/{{itemGroupId}}` 
            

### Updating an Existing Item Group by ID {#subsect_0120112947}

              `PATCH {{COMPANY_URL}}/services/rest/record/v1/itemGroup/{{itemGroupId}} { "itemId": "ItemGroup REST TEST updated", "member": { "items": [ { "lineNumber": 1, "quantity":2 } ] } }`
