The campaign offer record exposes a campaign offer to REST web services.

This record:

-   is not a subrecord
    
-   contains no subrecords
    

For more information about working with campaign offers in the UI, see [Campaign Offers](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1019075.html).

The REST API Browser includes information about the field names and field types of the campaign offer record and about the HTTP methods, request parameters, and operations available to this record. For details, see the REST API Browser's [campaign offer](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2026.1/index.html#tag-campaignOffer) reference page.

For information about using the REST API Browser, see [The REST API Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157373386674.html).

## Record ID {#subsect_71142619299}

The record ID for a campaign offer REST record is **campaignoffer**.

## Prerequisites {#subsect_70142623133}

You must enable the Marketing Automation feature before you can use this record through REST web services. For more information, see [Marketing Automation Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N973384.html).
