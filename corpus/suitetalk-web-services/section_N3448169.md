SOAP web services in NetSuite are protected by TLS encryption. Only requests sent using TLS encryption are granted access. For more information, see [Supported TLS Protocol and Cipher Suites](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1554220186.html).
