You can install an integration record by installing a bundle that includes it. This method is useful for adding partner records or moving sandbox records to production.

Note that the State field is set to Enabled when you install a record through a bundle. This allows SOAP web services requests from the application. (In contrast, auto-installation sets the State field based on your **Require Approval during Auto-Installation of Integration** preference.)

After installation, you can edit the record and update the State field as needed. For more details, see [Blocking SOAP Web Services Requests](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4431175537.html).

For general help installing a bundle, see [SuiteApp Installation and Update](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N3394134.html).

Note:

When a record is installed through auto-installation (or through bundling), the values of many fields on the record are determined by the NetSuite account that owns the record. These fields are read-only in the account where the record is installed. For details, see [Ownership of Integration Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4389727047.html#bridgehead_4430967734).
