Use the [SOAP Schema Browser](https://system.netsuite.com/help/helpcenter/en_US/srbrowser/Browser2026_1/schema/index.html) to find records and subrecords by name or namespace.

## Using the A-Z Index {#bridgehead_3978158926}

Use the A-Z index at the top of the browser to find a record by name.

#### Finding a record or subrecord using the A-Z index:

1.  Click the letter that matches the record name.
    
    The left pane shows a list of matching records, and the center pane shows the first record's details.
    
    ![Alphabetical index of records in the Schema Browser.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/SuiteTalkWebServices/SchemaBrowser20.png)
2.  In the left-hand pane, find the name of the record or subrecord you are interested in, and click it.
    
    The center pane now shows details of the record. For help understanding the details displayed, see [Summary of the Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3975713667.html#bridgehead_3975775688).
    

## Using the Namespace Dropdown List {#bridgehead_3978160900}

Not sure of the record name? Try browsing by namespace using the dropdown list, which is located below the A-Z index.

#### Finding a record using the namespace dropdown list:

1.  Choose a namespace from the dropdown list.
    
    ![The namespace dropdown list in the Schema Browser.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/SuiteTalkWebServices/SchemaBrowser21.png)
    
    The left pane shows a list of objects in the namespace, and the center pane shows the first record's details.
    
2.  In the left-hand pane, find the name of the record or subrecord you are interested in, and click it.
    
    The center pane now shows details of this record. For help understanding the details displayed, see [Summary of the Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3975713667.html#bridgehead_3975775688).
