You can create competitor records to track how other businesses in your industry impact your sales. In the UI, this is a user defined list at Lists > Relationships > Competitors > New.

Use the competitor record to create new competitors and expose them to REST web services.

To learn more, see [Competitors](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1096618.html).

This record:

-   is not a subrecord
    
-   has no subrecords
    

The REST API Browser includes information about the field names and field types of the competitor record, and about the HTTP methods, request parameters, and operations available to this record. For details, see the REST API Browser's [competitor](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2026.1/index.html#tag-competitor) reference page.

For information about using the REST API Browser, see [The REST API Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157373386674.html).

## Record ID {#subsect_21132416006}

The record ID for a competitor REST record is **competitor**.

## Prerequisites {#subsect_14101209231}

You must enable Permissions > Lists > Competitors before you can use this record through REST web services.

## Elements Not Accessible Through REST Web Services {#subsect_37103054175}

The following elements are not accessible through REST web services:

-   opportunities
    

## Usage Notes {#subsect_88103300623}

Review the following notes on working with the competitor REST record:

-   `name` is required, all other fields are optional
    

## Code Sample {#subsect_68132436616}

The following samples show common use cases for competitor.

### Creating a Competitor {#subsect_43132500803}

              `POST https://demo123.suitetalk.api.snap.netsuite.com/services/rest/record/v1/competitor Body: { "name": "A Competitor", "description": "Description of competitor", "strengths": "Competitor's strengths", "weaknesses": "Competitor's weaknesses", "strategy": "Strategy for winning against competitor", "productService": "Competitor's products and services", "isInactive": false }` 
            

### Retrieving a Competitor {#subsect_64132521430}

              `GET https://demo123.suitetalk.api.snap.netsuite.com/services/rest/record/v1/competitor/2` 
            

### Updating a Competitor {#subsect_31132547562}

              `PATCH https://demo123.suitetalk.api.snap.netsuite.com/services/rest/record/v1/competitor/2 Body: { "name": "Updated Competitor", "description": "Updated description of competitor", "strengths": "Updated Competitor's strengths", "weaknesses": "Updated competitor's weaknesses", "strategy": "Updated strategy for winning against competitor", "productService": "Updated competitor's products and services", "isInactive": true }` 
            

### Deleting a Competitor {#subsect_32132609689}

              `DELETE https://demo123.suitetalk.api.snap.netsuite.com/services/rest/record/v1/ competitor/2`
