You can set preferences at the request level. Request-level settings override account-wide preferences.

Some preferences can only be set company-wide and cannot be overridden. Other preferences exist only at the request level and can be set only during a specific request or search. These preferences do not have a company-wide equivalent.

The available request-level preferences are described in the [Request-Level Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4170181850.html) topic.

For details on company-wide preferences, see [Company-Wide Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3422217.html).
