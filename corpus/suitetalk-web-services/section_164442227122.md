A sales price rule entry record exposes the sales price rule entry to REST web services. This record is not a subrecord. This record has one subrecord: quantitybreak.

The REST API browser includes information about the field names and field types of the sales price rule entry record, and about the HTTP methods, request parameters, and operations available to this record. For details, see the REST API Browser's [sales price rule entry](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2026.1/index.html#tag-salesPriceRuleEntry) reference page.

For information about using the REST API Browser, see [The REST API Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157373386674.html).

## Record ID {#subsect_164442737586}

The record ID for a sales price rule entry REST record is **salespriceruleentry**.

The record ID for a sales price rule entry REST subrecord is **quantityBreaks**.

## Prerequisites {#subsect_164442739502}

You must enable Advanced Pricing before you can use this record through REST web services.

You must use camel case for field names (likeThisExample).

## Limitations {#subsect_164442740959}

You cannot create or edit a sales price rule entry record that references a currently inactive price rule.

## Code Sample {#subsect_164442742192}

The following code sample shows a common use case for updating a sales price rule entry record.

            `POST /services/rest/record/v1/salespriceruleentry User-Agent: NetSuite-REST-Client Content-Type: application/json; charset=UTF-8 { "item": { "id": "380" }, "priceRule": { "id": "6" }, "quantityBreaks": { "items": [ { "lowerBound": 0, "rate": 0 } ] } }`
