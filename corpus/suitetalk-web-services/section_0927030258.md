A sales role record exposes a sales role to REST web services.

For more information about sales roles and how they function in the user interface, see [NetSuite Roles Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N285436.html).

To access this record in NetSuite, go to _Setup > Users/Roles > Manage Roles_.

This record:

-   is not a subrecord
    
-   has no subrecords
    

The REST API Browser includes information about the field names and field types of the sales role record, and about the HTTP methods, request parameters, and operations available to this record. For details, see the REST API Browser's [sales role](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2026.1/index.html#tag-salesRole) reference page.

For information about using the REST API Browser, see [The REST API Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157373386674.html).

## Record ID {#subsect_39151832729}

The record ID for the sales role REST record is **salesrole**.

## Prerequisites {#subsect_59105857136}

You must enable the Team Selling feature before you can use this record through REST web services. For more information, see [Team Selling](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1037318.html).

## Code Sample {#subsect_37151839579}

The following samples show common use cases for a sales role record. The example ID is 6.

              `GET https://demo123.suitetalk.api.snap.netsuite.com/services/rest/record/v1/metadata-catalog/salesrole`
