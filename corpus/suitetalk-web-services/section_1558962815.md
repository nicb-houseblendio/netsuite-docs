A billing account record exposes a SuiteBilling account to REST web services. You can enable Billing Accounts without enabling SuiteBilling.

This record:

-   is not a subrecord
    
-   has no subrecords
    

All elements on this record are accessible through REST web services.

The REST API Browser includes information about the field names and field types of the billing account record, and about the HTTP methods, request parameters, and operations available to this record. For details, see the REST API Browser's [billing account](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2026.1/index.html#tag-billingAccount) reference page.

For information about using the REST API Browser, see [The REST API Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157373386674.html).

## Record ID {#subsect_156027402466}

The record ID for the billing account REST record is **billingaccount**.

## Prerequisites {#subsect_156027395416}

You must [Enabling SuiteBilling Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1546981120.html) before you can use this record through REST web services.

## Limitations {#subsect_156096571525}

A billing account REST record does not show related records.

## Code Sample {#subsect_156027374788}

            `{ "startDate": "2019-2-20", "customer": {"id" : 1}, "billingSchedule": {"id": 1} "currency": {"id" : 1} }`
