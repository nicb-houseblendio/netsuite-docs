This list defines the website category for the item.

| Field Name | 
Type /

Field Length



 | Req. | Mapping | Notes |
| --- | --- | --- | --- | --- |
| category | RecordRef | Y | Site Category | References a value in a user-defined list at _Commerce > Site Builder > Content Management > Categories_ (Site Builder website) or _Setup > Intranet > Categories_ (Intranet). |
| categoryDescription | string / 50 | Y | Description | A read-only field that returns the description defined in the category record. |
| website | RecordRef | \- | \- | \- |
