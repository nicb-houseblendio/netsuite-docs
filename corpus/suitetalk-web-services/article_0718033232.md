A price level record exposes a price level to REST web services.

To access this record in NetSuite, go to Setup > Accounting > Accounting Lists > New > Price Level.

The REST API Browser includes information about the field names and field types of the price level record. It also includes information about the HTTP methods, request parameters, and operations available to this record. For details, see the REST API Browser's [price level](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2026.1/index.html#tag-priceLevel) reference page.

For information about using the REST API Browser, see [The REST API Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157373386674.html).

## Record ID {#subsect_87212750171}

The record ID for a price level REST record is **pricelevel**.

## Code Samples {#subsect_31212842843}

The following samples show common use cases for price levels. The example ID is 6.

### Creating a Price Level Using a POST Request {#subsect_65154135691}

              `POST: {{REST_SERVICES}}/record/v1/pricelevel  {    "name": "Test Price Level",    "discountPct": -15.0,    "isInactive": false,    "isOnline": false,    "updateExistingPrices": false }` 
            

### Retrieving a Price Level Using a GET Request {#subsect_55154410715}

              `GET: {{REST_SERVICES}}/record/v1/pricelevel/6` 
            

### Updating a Price Level Using a PATCH Request {#subsect_84154846941}

              `PATCH: {{REST_SERVICES}}/record/v1/pricelevel/6  {    "discountPct": -20.0,    "isInactive": false,    "isOnline": true,    "name": "Toolbox Price Level", }` 
            

### Deleting a Price Level Using a DELETE Request {#subsect_39155018741}

              `DELETE: {{REST_SERVICES}}/record/v1/pricelevel/6`
