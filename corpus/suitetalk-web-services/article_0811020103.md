NetSuite uses the term nexus to describe a tax jurisdiction or geographic area where you do business and which has its own tax regulations. For example, a nexus can be a country, municipality, city, state, province, county, or economic zone.

For more information, see [Understanding Nexuses in SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4283851663.html).

This record is not a subrecord.

Note:

REST web services do not support legacy tax features. To work with taxation through REST web services, you must have the SuiteTax feature enabled. For more information about using SuiteTax, see [SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/preface_1496364245.html).

The REST API Browser includes information about the field names and field types of the nexus record, and about the HTTP methods, request parameters, and operations available to this record. For details, see the REST API Browser's [nexus](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2026.1/index.html#tag-nexus) reference page.

For information about using the REST API Browser, see [The REST API Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157373386674.html).

## Record ID {#subsect_0811025957}

The record ID for the nexus REST record is **nexus**.

## Prerequisites {#subsect_0811030517}

The SuiteTax feature must be enabled.

## Actions {#subsect_0811034423}

The nexus record has the following actions through REST web services:

-   Submit new
    
-   Submit
    
-   Reset
    
-   Delete
