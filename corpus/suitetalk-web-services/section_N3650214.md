The EntitySearchBasic record is not a stand-alone search record. It must be used in conjunction with a search join from another record. The EntitySearchBasic interface is used when you are unsure of the entity type you are searching against.

EntitySearchBasic is defined in the [platformCommon](https://webservices.netsuite.com/xsd/platform/v2025_2_0/common.xsd) XSD.

## Field Definitions {#bridgehead_N3650236}

For details, see the SOAP Schema Browser's [EntitySearchBasic](https://system.netsuite.com/help/helpcenter/en_US/srbrowser/Browser2026_1/schema/search/entitysearchbasic.html?mode=package) reference page.

For information about working with search filter fields and search joins, see the [search](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3514306.html) operation in the NetSuite Help Center.
