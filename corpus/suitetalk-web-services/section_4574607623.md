This example shows how to update an existing custom segment value to include a new name.

The way you update a custom segment value can vary depending on the endpoint and operation you are using. This example uses the 2015.2 endpoint. It demonstrates how to identify the segment by using the internal ID of the appropriate custom record type. This method of identifying the segment is available with all endpoints.

This example also shows how to identify a segment value by its internal ID.

For details on identifying custom segments and their values, see [Identifying Custom Segments and Values](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4574498478.html).

## C# {#bridgehead_4574607753}

          `private void updateSegmentValue() { RecordRef myRef = new RecordRef(); myRef.type = RecordType.customRecordType; myRef.internalId = "39"; myRef.typeSpecified = true; CustomRecord myUpdatedSegmentValue = new CustomRecord(); myUpdatedSegmentValue.recType = myRef; myUpdatedSegmentValue.name = "Furniture"; myUpdatedSegmentValue.internalId = "108"; _service.update(myNewSegmentValue); }` 
        

## SOAP Request {#bridgehead_4574607830}

          `<soap:Body>    <update xmlns="urn:messages_2017_1.platform.webservices.netsuite.com">       <record internalId="108" xsi:type="q1:CustomRecord" xmlns:q1="urn:customization_2017_1.setup.webservices.netsuite.com">          <q1:name>Furniture</q1:name>          <q1:recType type="customRecordType" internalId="39"/>       </record>    </update> </soap:Body>` 
        

## SOAP Response {#bridgehead_4574607903}

          `<soapenv:Body>    <updateResponse xmlns="urn:messages_2017_1.platform.webservices.netsuite.com">       <writeResponse>          <platformCore:status isSuccess="true" xmlns:platformCore="urn:core_2017_1.platform.webservices.netsuite.com"/>          <baseRef xsi:type="platformCore:CustomRecordRef" typeId="39" internalId="108" xmlns:platformCore="urn:core_2017_1.platform.webservices.netsuite.com"/>       </writeResponse>    </updateResponse> </soapenv:Body>`
