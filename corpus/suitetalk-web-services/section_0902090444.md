Departments can be used to identify and categorize records in your NetSuite account. You can also define departments for your organization's needs by creating custom segments. Departments enable you to better organize data and preserve accuracy.

For information about working with departments in the UI, see [Classifications in NetSuite](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N261411.html).

The REST API Browser includes information about the field names and field types of the department record. It also includes the HTTP methods, request parameters, and operations available to this record. For details, see the REST API Browser's [department](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2026.1/index.html#tag-department) reference page.

For information about using the REST API Browser, see [The REST API Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157373386674.html).

## Record ID {#subsect_17090519086}

The record ID for the department REST record is **department**.

The department record has the following subrecord:

-   classTranslation
    

## Limitations {#subsect_2090523558}

Read-only sublists, including system notes, are not supported in REST.
