SOAP web services supports all the fields that are available in the user interface for the global account mapping record. It also supports external ID, any custom fields that you add, and the selection of a custom entry form (through the customForm field).

Note that the Custom Dimension field is available only if you have configured it at _Setup > Accounting > Accounting Preferences_, on the Accounting Books subtab. For details on this process, see [Custom Mapping Dimensions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3855057144.html#bridgehead_3861937453).

For details about working with this record in the user interface, see [Global Account Mapping](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3855055309.html).

Refer also to the [SOAP Schema Browser](https://system.netsuite.com/help/helpcenter/en_US/srbrowser/Browser2026_1/schema/record/globalaccountmapping.html), which includes definitions for all body fields, sublist fields, search filters, and search joins available to this record.

Note:

For information about using the SOAP Schema Browser, see [SOAP Schema Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3639052.html).
