The campaign vertical record exposes a campaign vertical to REST web services.

This record:

-   is not a subrecord
    
-   contains no subrecords
    

For more information about working with campaign verticals in the UI, see [Campaign Verticals](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1018615.html).

The REST API Browser includes information about the field names and field types of the campaign vertical record and about the HTTP methods, request parameters, and operations available to this record. For details, see the REST API Browser's [campaign vertical](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2026.1/index.html#tag-campaignVertical) reference page.

For information about using the REST API Browser, see [The REST API Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157373386674.html).

## Record ID {#subsect_15121708083}

The record ID for a campaign vertical REST record is **campaignvertical**.

## Prerequisites {#subsect_75121712331}

You must enable the Marketing Automation feature before you can use this record through REST web services. For more information, see [Marketing Automation Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N973384.html).
