Certain internal applications are excluded from the scope of concurrency governance. Requests from the specified internal applications do not count toward your concurrency limit.

Additionally, requests from these applications are not included in the usage data on the APM web services performance dashboard, APM Concurrency Monitor tool, or Integration Governance page. For information about these tools, see [Account Concurrency Monitoring Resources](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_1525252220.html).

Requests from these applications are not included in the usage data displayed on the Integration Governance page. For information about ways to monitor your concurrency usage, see [Account Concurrency Monitoring Resources](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_1525252220.html).

The following internal applications and SuiteApps are exempt from concurrency governance:

-   SuiteProjects Pro
    
-   NSPOS - See [NetSuite Point of Sale (NSPOS)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/preface_4631540035.html).
    
-   NetSuite for Outlook - See [NetSuite for Outlook](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/preface_1552649469.html).
    
-   NetSuite Connector
    

Important:

The list of excluded internal applications is subject to change.
