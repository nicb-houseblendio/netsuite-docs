The campaign template record exposes a campaign template to REST web services.

This record:

-   is not a subrecord
    
-   contains the following subrecords:
    
    -   fromEmail
        
    -   replyToEmail
        
    -   restrictToGroup
        
    -   subscription
        
    -   typeName
        
    -   usesMedia
        

For more information about working with campaign templates in the UI, see [Email Marketing Campaigns](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N992514.html).

The REST API Browser includes information about the field names and field types of the campaign template record and about the HTTP methods, request parameters, and operations available to this record. For details, see the REST API Browser's [campaign template](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2026.1/index.html#tag-campaignTemplate) reference page.

For information about using the REST API Browser, see [The REST API Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157373386674.html).

## Record ID {#subsect_51161436314}

The record ID for a campaign template REST record is **campaigntemplate**.

## Prerequisites {#subsect_87161441861}

You must enable the following features before you can use this record through REST web services:

-   Marketing Automation
    
-   Customer Relationship Management
    
-   CRM Template Categories
    

For more information, see [Marketing Automation Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N973384.html).
