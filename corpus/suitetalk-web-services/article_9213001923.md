An item revision record exposes an item revision item to REST web services.

This record:

-   is not a subrecord
    
-   has the following subrecords:
    
    -   component
        
    -   operation
        

The REST API Browser includes information about the field names and field types of the item revision record, and about the HTTP methods, request parameters, and operations available to this record. For details, see the REST API Browser's [item revision](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2026.1/index.html#tag-itemRevision) reference page.

For information about using the REST API Browser, see [The REST API Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157373386674.html).

## Record IDs {#subsect_46213013963}

The record ID for an item revision REST record is **ItemRevision**.

## Code Samples {#subsect_47213034017}

The following samples show common use cases for item revisions. The example ID is 4.

### Creating an Item Revision Using a POST Request {#subsect_71213108291}

              `POST https://demo123.suitetalk.api.snap.netsuite.com/services/rest/record/v1/itemRevision { "item": {"id":410}, "name": "REV_2022", "effectiveDate": "2022-01-01", "memo": "memo" }` 
            

### Retrieving an Item Revision Using a GET Request {#subsect_83213116353}

              `GET https://demo123.suitetalk.api.snap.netsuite.com/services/rest/record/v1/itemRevision/4` 
            

### Updating an Item Revision Using a PATCH Request {#subsect_43213119727}

              `PATCH https://demo123.suitetalk.api.snap.netsuite.com/services/rest/record/v1/itemRevision/4 { "memo": "new memo" }`
