A work order close record exposes a work order close to REST web services.

This record:

-   is not a subrecord
    
-   has the following subrecords:
    
    -   component
        
    -   routingItem
        

The REST API Browser includes information about the field names and field types of the work order close record, and about the HTTP methods, request parameters, and operations available to this record. For details, see the REST API Browser's [workOrderClose](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2026.1/index.html#tag-workOrderClose) reference page.

For information about using the REST API Browser, see [The REST API Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157373386674.html).

## Record IDs {#subsect_91213543329}

The record ID for a work order close REST record is **workOrderClose**.

## Prerequisites {#subsect_45213546287}

You must enable the Manufacturing Work In Process feature before you can use this record through REST web services.
