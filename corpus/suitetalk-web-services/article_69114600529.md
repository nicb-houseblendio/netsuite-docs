Support case priority defines the severity or urgency assigned to a support case, for example, Critical, High, Medium, or Low.

This record is not a subrecord and does not have a subrecord.

The REST API Browser includes information about the field names and field types of the support case priority record, and about the HTTP methods, request parameters, and operations available to this record. For details, see the REST API Browser's [support case priority](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2026.1/index.html#tag-supportCasePriority) reference page.

For information about using the REST API Browser, see [The REST API Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157373386674.html).

## Record ID {#subsect_65115856693}

The record ID for a support case priority REST record is **supportcasepriority**.

## Prerequisites {#subsect_34115901145}

You must enable the following before you can use this record through REST web services:

-   Feature: CRM > Customer Support and Service
    
-   Permission: Setup > Support Case Priority
    

## Code Sample {#subsect_86115906527}

The following samples show common use cases for support case priority.

### Creating a Support Case Priority {#subsect_16115916209}

              `POST https://demo123.suitetalk.api.netsuite.com/services/rest/record/v1/supportcasepriority Body: { "name": "Critical" }` 
            

### Reading a Support Case Priority {#subsect_25115920427}

              `GET https://demo123.suitetalk.api.netsuite.com/services/rest/record/v1/supportcasepriority/{id}` 
            

### Updating a Support Case Priority {#subsect_3115925262}

              `PATCH https://demo123.suitetalk.api.netsuite.com/services/rest/record/v1/supportcasepriority/{id} Body: { "description": "Severe business impact" }` 
            

### Deleting a Support Case Priority {#subsect_98115932076}

              `DELETE https://demo123.suitetalk.api.netsuite.com/services/rest/record/v1/supportcasepriority/{id}`
