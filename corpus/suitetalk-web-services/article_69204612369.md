A kit item record exposes a kit item to REST web services. This record is not a subrecord.

The REST API Browser includes information about the field names and field types of the kit item record, and about the HTTP methods, request parameters, and operations available to this record. For details, see the REST API Browser's [kit item](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2026.1/index.html#tag-kitItem) reference page.

For information about using the REST API Browser, see [The REST API Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157373386674.html).

Note:

REST web services do not support legacy tax features. To work with taxation through REST web services, you must have the SuiteTax feature enabled. For more information about using SuiteTax, see [SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/preface_1496364245.html).

## Record IDs {#subsect_12204704949}

The record ID for a kit item REST record is **kitItem**.

## Elements with Different Functionality {#subsect_11112308801}

The record has a matrix pricing machine. Otherwise, it behaves in the same way as the inventory item.

## Code Samples {#subsect_3204732694}

The following samples show common use cases for kit items. The example ID is 4.

### Creating a Kit Item Using a POST Request {#subsect_26204741872}

              `POST https://demo123.suitetalk.api.snap.netsuite.com/services/rest/record/v1/kitItem { "itemId": "Kit A", "member": { "items": [ { "item": { "id": "71", "refName": "Invt_Item_1" }, "quantity": 1.0 } ] } }` 
            

### Retrieving a Kit Item Using a GET Request {#subsect_84204748974}

              `GET https://demo123.suitetalk.api.snap.netsuite.com/services/rest/record/v1/kitItem/4` 
            

### Updating a Kit Item Using a PATCH Request {#subsect_36204753878}

              `PATCH https://demo123.suitetalk.api.snap.netsuite.com/services/rest/record/v1/kitItem/4 { "itemId": "Kit B", " description": "Kit Item description", }` 
            

              `PATCH https://demo123.suitetalk.api.snap.netsuite.com/services/rest/record/v1/kitItem/4 { "item": { "id": "71" }, "quantity": 5.0 }` 
            

### Deleting a Kit Item Using a DELETE Request {#subsect_91204800527}

              `DELETE https://demo123.suitetalk.api.snap.netsuite.com/services/rest/record/v1/kitItem/4`
