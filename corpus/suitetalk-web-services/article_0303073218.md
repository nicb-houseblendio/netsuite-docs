NetSuite exposes the payment card record to REST web services.

Payment card is a card-based funding source such that is used to authorize and settle electronic payments through a card network.

In NetSuite, a payment card is a tokenized payment instrument saved to a customer through a payment gateway. Payment cards can be used to authorize, capture, charge, and refund transactions such as sales orders, cash sales, invoices, and customer deposits after configuring a merchant account and a payment processing profile. Supported card brands depend on the selected gateway. For more information, see [Payment Instruments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1538492538.html).

The payment card record isn't a subrecord and doesn't have any subrecords of its own.

The REST API Browser includes information about the field names and field types of the payment card record and about the HTTP methods, request parameters, and operations available to this record. For details, see the REST API Browser's [payment card](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2026.1/index.html#tag-paymentCard) reference page.

For information about using the REST API Browser, see [The REST API Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157373386674.html).

## Record ID {#subsect_0303075022}

The record ID for payment card is **paymentcard**.

## Prerequisites {#subsect_0303075413}

-   enable the Payment Instruments feature. For instructions, see [Payment Instruments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1538492538.html).
    
-   enable the Credit Card Payments feature. For instructions, see [Setting Up Customer Credit Card Processing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1572221.html).
    

## Code Samples {#subsect_0303075744}

The code samples in this section show common use cases for payment card.

### Creating a Payment Card {#subsect_0303075858}

              `POST https://123456.suitetalk.api.netsuite.com/services/rest//record/v1/paymentCard {     "cardNumber": "4111111111111111",     "entity": {         "id": "28"     },     "expirationDate": "2029-10",     "isDefault": false,     "nameOnCard": "John Smith",     "preserveOnFile": true }` 
            

### Updating a Payment Card {#subsect_0303080152}

              `PATCH https://123456.suitetalk.api.netsuite.com/services/rest//record/v1/paymentCard/<id> {    "memo": "Updated MEMO" }`
