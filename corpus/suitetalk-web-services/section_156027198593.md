A subscription record exposes a SuiteBilling subscription to REST web services. This record:

-   is not a subrecord
    
-   has no subrecords
    

The REST API Browser includes information about the field names and field types of the subscription record, and about the HTTP methods, request parameters, and operations available to this record. For details, see the REST API Browser's [subscription](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2026.1/index.html#tag-subscription) reference page.

For information about using the REST API Browser, see [The REST API Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157373386674.html).

## Record ID {#subsect_156079954767}

The record ID for a subscription REST record is **subscription**.

## Prerequisites {#subsect_156079955874}

You must [Enabling SuiteBilling Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1546981120.html) before you can use this record through REST web services.

## Limitations {#subsect_156080040037}

A subscription REST record does not show change orders, related records, or system information.

## Code Samples {#subsect_156027507095}

These samples show common use cases for creating subscriptions.
