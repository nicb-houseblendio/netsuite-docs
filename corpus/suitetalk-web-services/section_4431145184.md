To track an app with an integration record, each request must include identifying data. After creating or installing an integration record, you might need to update your client code.

You can identify the app using either the application ID or token-based authentication (TBA). You can't send both types of data at the same time. For details, see the following topics:

-   [Sending an Application ID with User Credentials](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4398166065.html)
    
-   [Token-Based Authentication Details](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4395622897.html)
