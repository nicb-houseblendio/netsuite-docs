A paycheck journal record exposes a paycheck journal to REST web services.

This record:

-   is not a subrecord
    
-   has the following subrecords:
    
    -   PaycheckJournalCompanyContribution
        
    -   PaycheckJournalCompanyTax
        
    -   PaycheckJournalDeduction
        
    -   PaycheckJournalEarning
        
    -   PaycheckJournalEmployeeTax
        

The REST API Browser includes information about the field names and field types of the paycheck journal record and about the HTTP methods, request parameters, and operations available to this record. For details, see the REST API Browser's [paycheck journal](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2026.1/index.html#tag-paycheckJournal) reference page.

For information about using the REST API Browser, see [The REST API Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157373386674.html).

## Record ID {#subsect_0723074739}

The record ID for a paycheck journal REST record is **paycheckjournal**.

## Prerequisites {#subsect_0723074856}

Before you can use this record with REST web services, you must enable the payroll and payroll journal features.

## Actions {#subsect_0723074948}

The following actions are available for the paycheck journal record:

-   Customize Form
    
-   Delete
    
-   New Body Field
    
-   New Column Field
    
-   Reset
    
-   Save
    
-   Save and New
    

## Elements Related to Taxation Features {#subsect_0723075219}

The paycheck journal record has the following tax-related fields that are not exposed to REST:

-   companytax
    
-   employeetax
    

Note:

REST web services do not support legacy tax features. To work with taxation through REST web services, you must have the SuiteTax feature enabled. For more information about using SuiteTax, see [SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/preface_1496364245.html).

## Code Samples {#subsect_0723075359}

The following code sample shows how to create a paycheck journal:

            `curl --request POST \   --url {{COMPANY_URL}}/services/rest/record/v1/paycheckJournal \   --header 'content-type: application/json' \   --data '{   "employee": {     "id": 3   },   "account": {     "id": 21   },   "earning": {     "items": [       {         "amount": 10000,         "payrollItem": {           "id": "4"         }       }     ]   } }` 
          

The following code sample shows how to delete a paycheck journal earning:

            `curl --request PATCH \   --url {{COMPANY_URL}}services/rest/record/v1/paycheckJournal/4 \   --header 'content-type: application/json' \   --data '{   "earning": {     "items": []   } }` 
          

The following code sample shows how to get a paycheck journal:

            `curl --request GET \   --url {{COMPANY_URL}}/services/rest/record/v1/paycheckJournal/5`
