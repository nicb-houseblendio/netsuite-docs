A serialized inventory item is an inventory item that you maintain and track as individual units, each assigned a unique serial number. Serialized inventory item records track the quantity of items and each serial number that is purchased and sold.

For information about using serialized inventory items in the UI, see [Serial Numbered Items](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2230290.html). For information about using inventory items in the UI, see [Inventory Items](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2247990.html).

This record is not a subrecord.

The REST API Browser includes information about the field names and field types of the serialized inventory item record, and about the HTTP methods, request parameters, and operations available to this record. For details, see the REST API Browser's [serialized inventory item](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2026.1/index.html#tag-serializedInventoryItem) reference page.

For information about using the REST API Browser, see [The REST API Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157373386674.html).

## Record ID {#subsect_91144243199}

The record ID for the serialized inventory item REST record is **serializedInventoryItem**.

## Prerequisites {#subsect_63144237851}

You must enable the Serialized Inventory feature before you can use this record through REST web services.

## Limitations {#subsect_66144231908}

A serialized inventory item REST record does not show Quantity Pricing Discount/Levels (quantitypricingdiscount, quantitypricinglevel) or the Item Translations subtab (translations).

Note:

REST web services do not support legacy tax features. To work with taxation through REST web services, you must have the SuiteTax feature enabled. For more information about using SuiteTax, see [SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/preface_1496364245.html).
