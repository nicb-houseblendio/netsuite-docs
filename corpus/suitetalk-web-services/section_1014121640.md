Use the PUT command to create a customer using an external ID.

          `PUT {{REST_SERVICES}}/record/v1/customer/eid:{{customerExternalId}} {    "companyName": "New Company External Id {{$timestamp}}",    "email": "customer@example.com",    "location" : "1" }` 
        

For more information about using external IDs [Using External IDs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156334828635.html).
