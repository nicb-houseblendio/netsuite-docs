A bin records enable you to organize and track items and their on-hand quantities within a location. This record is available when the Bin Management feature is enabled. For more information about bins, see [Bin Management](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2270284.html)

The REST API Browser includes information about the field names and field types of the bin record, and about the HTTP methods, request parameters, and operations available to this record. For details, see the REST API Browser's [bin](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2026.1/index.html#tag-bin) reference page.

For information about using the REST API Browser, see [The REST API Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157373386674.html).

## Record ID {#subsect_38105642832}

The record ID for a bin REST record is **bin**.
