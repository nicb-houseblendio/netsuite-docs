In the default view of the [SOAP Schema Browser](https://system.netsuite.com/help/helpcenter/en_US/srbrowser/Browser2026_1/schema/index.html), the left pane lists records matching the letter selected in the A-Z index at the top of the page. The center pane shows details of one record. You may also switch to a namespace view. This view includes:

-   The left pane shows a tabbed list of namespace objects.
    
-   The center pane shows a summary of details about one object, which can be a record or something else.
    

This topic describes this view in more detail.

## Summary of the Object {#bridgehead_3975765968}

The central pane of the SOAP Schema Browser shows a summary of the selected object.

Sometimes, the object is a record. For help understanding the summary of a record, see [Summary of the Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3975713667.html#bridgehead_3975775688).

Non-record objects display varying details. For example, the description of an enumeration shows all of its possible values. By contrast, an object such as ExpenseReportExpense, which details a single line in a sublist, is described in a table similar to that of a record.

## Navigating to a Different Object {#bridgehead_3978181142}

To switch to a different object in the namespace view, use the left pane's tabbed list. The following table describes each subtab.

| Tab | Shows |
| --- | --- |
| Record | All records and subrecords defined in the namespace |
| Search | All search objects in the namespace |
| Other | The namespace's sublists, their child elements, and sometimes other objects |
| Enum | All enumerations in the namespace |

Clicking a subtab updates the list of buttons on the left to match the chosen category. Select any button to see the summary of that object.

## Navigating to the Namespace View {#bridgehead_3975767561}

If you have navigated away from the namespace view and you want to get it back to it, try one of these options:

-   Select a namespace using the dropdown list directly below the A-Z index.
    
-   In the center pane, click the namespace link displayed below the name of the record.
    
-   In the **Type** column, click the name of any data type that is underlined.
    
-   At the bottom of the record reference page, click the name of any search object listed.
