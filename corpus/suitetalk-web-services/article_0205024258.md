A partner category record exposes a partner category to REST web services.

For more information about partner categories and how they function in the user interface, see [Creating a Partner Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1166599.html).

To access this record in NetSuite, go to _Setup > Sales > Setup Tasks > CRM Lists (Administrator)_.

This record:

-   is not a subrecord
    
-   has no subrecords
    

## Actions {#subsect_94151256723}

The partner category record includes the following actions from the Actions Framework:

-   Save
    
-   Save & New
    
-   Delete
    

The REST API Browser includes information about the field names and field types of the partner category record, and about the HTTP methods, request parameters, and operations available to this record. For details, see the REST API Browser's [partner category](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2026.1/index.html#tag-partnerCategory) reference page.

For information about using the REST API Browser, see [The REST API Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157373386674.html).

Note:

REST web services do not support legacy tax features. To work with taxation through REST web services, you must have the SuiteTax feature enabled. For more information about using SuiteTax, see [SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/preface_1496364245.html).

## Record ID {#subsect_48144958273}

The record ID for the partner category REST record is **partnerCategory**.

## Prerequisites {#subsect_94145003330}

You must enable the CRM feature before you can use this record through REST web services.

## Code Sample {#subsect_26145008583}

The following samples show common use cases for a partner category record. The example ID is 5.

### Retrieving Partner Category Metadata {#subsect_84165314669}

              `GET https://demo123.suitetalk.api.netsuite.com/services/rest/record/v1/metadata-catalog/partnercategory` 
            

### Updating a Partner Category Using a PATCH Request {#subsect_88145028938}

              `PATCH https://demo123.suitetalk.api.netsuite.com/services/rest/record/v1/partnercategory/5 { "name": "Name updated" }` 
            

### Deleting a Partner Category Using a DELETE Request {#subsect_27165318723}

              `DELETE https://demo123.suitetalk.api.netsuite.com/services/rest/record/v1/partnercategory/5`
