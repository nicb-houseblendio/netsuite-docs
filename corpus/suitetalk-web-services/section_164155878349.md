The following table maps SOAP operations to their REST equivalents.

| SOAP Operation | REST Operation | Notes |
| --- | --- | --- |
| [add](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0624101814.html) | POST |  |
| [addList](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0129091558.html) | [Batch Operations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0127092747.html) |  |
| [attach / detach](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0115032226.html) | [Attach and Detach Operations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0113084334.html) |  |
| changeEmail | \- | Login through user credentials is not supported in REST web services. |
| changePassword | \- | Login through user credentials is not supported in REST web services. |
| [checkAsyncStatus](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0624010801.html) | GET | You can use the async service to retrieve the status of a single async operation. |
| [delete](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0624125335.html) | DELETE |  |
| [deleteList](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0130093306.html) | [Batch Operations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0127092747.html) |  |
| [get](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0721010159.html) | GET |  |
| [getAccountGovernanceInfo](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0729100620.html) | [GovernanceLimits Operation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0625010817.html) |  |
| [getAll](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0804011937.html) | GET |  |
| [getAsyncResult](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0721110548.html) | \- | You can use the async service to retrieve the result of a single async operation. |
| [getBudgetExchangeRate](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0717093507.html) | [Budget Exchange Rate](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0305060708.html) |  |
| [getCurrencyRate](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0723093056.html) | GET | You can achieve the equivalent in REST by sending a GET request for a specific currency rate record. |
| getCustomizationId |  | In REST web services, you can return data about your customization objects by sending a request to the metadata catalog. For information, see [Getting Metadata](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1540810174.html). |
| getDataCenterUrls | \- | REST web services only use account-specific domains. |
| getDeleted | \- | This functionality is not available in REST web services. You can retrieve information about deleted records by using the Deleted Record search type or a SuiteQL query. For information, see [Searching for Deleted Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4031815869.html). |
| [getIntegrationGovernanceInfo](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0815123622.html) | [GovernanceLimits Operation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0625010817.html) |  |
| [getItemAvailability](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0815092044.html) |  | You can achieve the equivalent in REST by sending a GET request for a specific record. |
| [getList](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0728100352.html) | GET | You can retrieve a list of records of the same record type in REST. |
| getPostingTransactionSummary | \- | You can search for financial reports and summaries in the UI. For information, see [Financial Statements Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N2092547.html). |
| getSavedSearch | \- | Saved Search isn't supported in REST web services. REST web services supports SuiteAnalytics Datasets. For more information, see [Working with SuiteAnalytics Datasets in REST Web Services](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156577938018.html). |
| [getSelectValue](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0216100311.html) | [selectOptions Operation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0115100241.html) |  |
| [getServerTime](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0728090637.html) | [serverTime Operation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0528010158.html) |  |
| [initialize / initializeList](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0717100858.html) | [Create-form Operation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1217103046.html) |  |
| [search](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0728114850.html) | GET |  |
| [searchMoreWithId](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0807095731.html) |  | In REST web services, you can use collection paging to move between pages of search results. |
| [update](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0731124139.html) | PATCH |  |
| [updateList](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0130125737.html) | [Batch Operations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0127092747.html) |  |
| [updateInviteeStatus](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0728122402.html) | PATCH | You can achieve the equivalent in REST by sending a PATCH request for a specific record. |
| updateInviteeStatusList | \- | You can update calendar events one by one. For information, see [updateInviteeStatus](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0728122402.html). |
| [upsert](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0807093604.html) | PUT |  |
| [upsertList](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0203101639.html) | [Batch Operations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0127092747.html) |  |
