The item supply plan record exposes an item supply plan to REST web services.

To access this record in NetSuite, go to Transactions > Demand Planning > Generate Item Supply Plan (Administrator). For more information about working with this record, see [Creating Item Supply Plans](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2293372.html).

The item supply plan record is not a subrecord, but has one subrecord, **itemsupplyplanorder**.

The REST API Browser includes information about the field names and field types of the item supply plan record, and about the HTTP methods, request parameters, and operations available to this record. For details, see the REST API Browser's [item supply plan](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2026.1/index.html#tag-itemSupplyPlan) reference page.

For information about using the REST API Browser, see [The REST API Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157373386674.html).

## Record ID {#subsect_0220040637}

The record ID for an item supply plan record is **itemsupplyplan**.

## Prerequisites {#subsect_0220040701}

You must enable the Demand Planning feature before you can use this record through REST web services.

## Code Sample {#subsect_0220040814}

The following samples show common use cases for the item supply plan:

### Get {#subsect_0220041637}

              `GET URL: {{COMPANY_URL}}/services/rest/record/v1/itemsupplyplan/{itemsupplyplanId}` 
            

### Patch: Update {#subsect_0220041650}

              `PATCH URL: {{COMPANY_URL}}/services/rest/record/v1/itemsupplyplan/{itemsupplyplanId} Body: {   "memo": "Added new plan order line",   "order": {     "items": [       {         "links": [],         "ordercreated": false,         "orderdate": "2025-05-14",         "orderlineid": 0,         "ordertype": {           "id": "PurchOrd",           "refName": "Purchase Order"         },         "quantity": 10.0,         "receiptdate": "2025-05-23"       },       {         "orderdate": "2025-05-14",         "ordertype": "PurchOrd",         "quantity": 20.0,         "receiptdate": "2025-05-24"       }     ]   } }` 
            

### Get Post: Create {#subsect_0220041721}

              `POST URL: {{COMPANY_URL}}/services/rest/record/v1/itemsupplyplan Body: {   "item": {     "id": "3869"   },   "location": {     "id": "4009"   },   "memo": "Memo",   "order": {     "items": [       {         "orderdate": "2025-05-14",         "ordertype": "PurchOrd",         "quantity": 10.0,         "receiptdate": "2025-05-23"       }     ]   },   "subsidiary": {     "id": "1"   } }` 
            

### Put: Create with external ID {#subsect_0220041736}

              `PUT URL: {{COMPANY_URL}}/services/rest/record/v1/itemSupplyPlan/eid:{{planExternalId}} Body: {   "item": {     "id": "199"   },   "location": {     "id": "6"   },   "memo": "Memo",   "order": {     "items": [       {         "orderdate": "2025-05-14",         "ordertype": "PurchOrd",         "quantity": 10.0,         "receiptdate": "2025-05-23"       }     ]   },   "subsidiary": {     "id": "1"   } }  Pre-request Script: pm.collectionVariables.set("planExternalId", "MYISP" + new Date().getTime());` 
            

### Get: with external ID {#subsect_0220041753}

              `GET URL: {{COMPANY_URL}}/services/rest/record/v1/itemsupplyplan/eid:{{planExternalId}} NOTE: get after you create itemsupplyplan with eid` 
            

### Delete {#subsect_0220041828}

              `DELETE URL: {{COMPANY_URL}}/services/rest/record/v1/itemsupplyplan/{itemsupplyplanId}`
