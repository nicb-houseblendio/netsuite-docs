Important:

Most types of records are also supported in REST web services. For a list of all records supported in REST, see [REST Web Services Supported Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1558962745.html).

The following activity records are supported in SOAP web services:

-   [Events (CalendarEvent)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3650565.html)
    
-   [Phone Call](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3651734.html)
    
-   [Project Task](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3652149.html)
    
-   [Project Task Assignment Joined Search](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3654425.html)
    
-   [Resource Allocation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3724237064.html)
    
-   [Tasks](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3654609.html)
