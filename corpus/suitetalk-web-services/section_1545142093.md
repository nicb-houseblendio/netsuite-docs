REST web services models multiselects as a collection of references containing the internal ID and HATEOAS links navigating to the referenced record. The following example shows the subsidiary multiselect field that is located on the account record.

          `"subsidiary": {     "links": [         {             "rel": "self",             "href": "https://demo123.suitetalk.api.netsuite.com/services/rest/record/v1/account/106/subsidiary"         }     ],     "items": [         {             "links": [                 {                     "rel": "self",                     "href": "https://demo123.suitetalk.api.netsuite.com/services/rest/record/v1/subsidiary/1"                 }             ],             "id": "1"         },          {             "links": [                 {                     "rel": "self",                     "href": "https://demo123.suitetalk.api.netsuite.com/services/rest/record/v1/subsidiary/2"                 }             ],             "id": "2"         }     ],     "totalResults": 2 }`
