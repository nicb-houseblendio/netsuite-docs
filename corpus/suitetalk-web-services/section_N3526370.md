Warning:

As of the NetSuite 2021.1 release, the ssoLogin operation is no longer available. This affects all endpoints, and even though the SOAP schema remains for older endpoints, the method is not working. For SOAP web services you must use token-based Aauthentication instead. For more information, see [Token-based Authentication (TBA)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4247329078.html).
