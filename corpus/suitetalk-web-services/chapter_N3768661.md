-   [Custom Record Custom Field](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3771706.html)

-   [Custom Segment](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1552570607.html)
    
-   [Custom Transaction](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4177777043.html)
    
-   [CRM Custom Field](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3772486.html)

-   [Transaction Line Custom Field](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3775025.html)
    

Note:

If you are unfamiliar with NetSuite custom fields, you should see [Custom Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N2826978.html) in the NetSuite Help Center. This section describes the purpose and general characteristics of each custom field type, which will help you when working with the SOAP web services customization API. For general information about working with both standard and custom fields in SOAP web services, see [Fields in SOAP Web Services](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3436475.html).
