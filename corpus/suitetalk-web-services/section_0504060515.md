To add line items to a vendor bill, use the PATCH command and include the item details in the request body.

          `PATCH {{REST_SERVICES}}/record/v1/vendorbill/<id> {     "item": {         "items": [             {                 "item": {                     "id": 84                 },                 "quantity": 30,                 "rate": 50             }         ]     } }`
