Use the PATCH command to update a cash sale.

          `PATCH {{REST_SERVICES}}/record/v1/cashsale/<id> {     "item": {         "items": [             {                 "item": {                     "id": "14"                 },                 "quantity": 50,                 "amount": 300             }         ]     } }`
