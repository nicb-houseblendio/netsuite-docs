A discount item record exposes a discount item to REST web services. This record is not a subrecord.

The REST API Browser includes information about the field names and field types of the discount item record, and about the HTTP methods, request parameters, and operations available to this record. For details, see the REST API Browser's [discountItem](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2026.1/index.html#tag-discountItem) reference page.

For information about using the REST API Browser, see [The REST API Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157373386674.html).

## Record IDs {#subsect_72144713042}

The record ID for a discount item REST record is **discountItem**.

## Taxation {#subsect_68144736554}

Note:

REST web services do not support legacy tax features. To work with taxation through REST web services, you must have the SuiteTax feature enabled. For more information about using SuiteTax, see [SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/preface_1496364245.html).

The discount item includes the Apply Before Tax field related to taxation features.

## Code Samples {#subsect_21144745721}

The following samples show common use cases for discount items. The example ID is 4.

### Creating a Discount Item Using a POST Request {#subsect_96144755528}

              `POST https://demo123.suitetalk.api.snap.netsuite.com/services/rest/record/v1/discountItem { "isInactive": false, "itemId": "031036c6-1815-4b95-87d6-d5f9367a1cf5", "rate": 8.0, "displayName": "Test nonposting", "account": { "id": "105", "refName": "Discount 500$ After Tax Non Post", "externalId": "2" }, "nonPosting": false }` 
            

### Retrieving a Discount Item Using a GET Request {#subsect_21144805972}

              `GET https://demo123.suitetalk.api.snap.netsuite.com/services/rest/record/v1/discountItem/4` 
            

### Updating a Discount Item Using a PATCH Request {#subsect_26144810838}

              `PATCH https://demo123.suitetalk.api.snap.netsuite.com/services/rest/record/v1/discountItem/4 { "isInactive": false, "description": "Discount 10$ After Tax Non Post", "itemId": "03", "rate": "", "displayName": "Test", "account": { "id": "105", "refName": "Discount 5$ After Tax Non Post", "externalId": "2" } }` 
            

### Deleting a Discount Item Using a DELETE Request {#subsect_89144820119}

              `DELETE https://demo123.suitetalk.api.snap.netsuite.com/services/rest/record/v1/discountItem/4`
