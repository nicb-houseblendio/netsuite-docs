The CustomTransaction complex type lets you interact with instances of existing custom transaction types. For example, if your account included a custom transaction type called Non-Operational Income Entry, you could use SOAP web services to create and modify non-operational income entries. This record is defined in the [customization XSD](https://webservices.netsuite.com/xsd/setup/v2025_2_0/customization.xsd).

For details about working with custom transactions in the user interface, see [Custom Transactions Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4172599049.html).
