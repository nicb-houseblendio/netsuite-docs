The Period End Journal Entries feature processes and posts subsidiary consolidation and income statement closing using a transaction type called Period End Journal. Period end journals are generated automatically when you complete the Create Period End Journals task on the Period Close Checklist.

For more information about period end journal entries in NetSuite, see [Period End Journal Entries](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1531269686.html). For help creating this record in the user interface, see [Period End Journal Creation Process](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1513210898.html).

This record isn't a subrecord and doesn't have any subrecords.

The REST API Browser includes information about the field names and field types of the period end journal entry record, and about the HTTP methods, request parameters, and operations available to this record. For details, see the REST API Browser's [period end journal](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2026.1/index.html#tag-periodEndJournal) reference page.

For information about using the REST API Browser, see [The REST API Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157373386674.html).

## Record ID {#subsect_0522043336}

The record ID for a period end journal entry REST record is **periodendjournal**.

## Prerequisites {#subsect_0522043848}

The Period End Journal Entry feature is available only on NetSuite OneWorld accounts. You must enable the Accounting Periods feature to enable this feature.

To use the Period End Journal Entries feature, you must enable the feature for your account and then for specific subsidiaries. For more information, see [Enabling the Period End Journal Entries Feature](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1513209294.html).

## Supported Operations {#subsect_0522043953}

The following operations are supported when working with this record through REST web services:

-   GET (Read, Search for a list of period end journal entries)
    
-   PATCH (update a specific record)
    

Only the **Memo** and **External ID** fields can be updated.

## Inaccessible Elements {#subsect_0522044117}

The following sublists aren't accessible through REST web services:

-   Communication
    
-   System Information
    
-   GL Impact
    

## Code Samples {#subsect_0522044212}

The following sample shows how to retrieve a period end journal entry record with an internal ID of 1:

            `GET:     {{COMPANY_URL}}/services/rest/record/v1/periodendjournal/1` 
          

The following sample shows how to update the **Memo** field on a period end journal entry record with an internal ID of 1:

            `PATCH:     {{COMPANY_URL}}/services/rest/record/v1/periodendjournal/1 { "externalId": "PERJNL1", "memo": "Updated memo using REST"}`
