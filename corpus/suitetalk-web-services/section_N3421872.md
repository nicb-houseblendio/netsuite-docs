To reference an image, the image must first be uploaded to the NetSuite File Cabinet, and then referenced using the image name specified in the File Cabinet. For more information about working with images (and other file types) in the File Cabinet, see [File](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3784054.html).
