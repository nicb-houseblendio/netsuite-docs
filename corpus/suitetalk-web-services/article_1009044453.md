Note type defines a list of values that are used by the note record to set the type of note. In the UI, this is a user defined list at Setup > Sales > Setup Tasks > CRM Lists.

Use the note type record to create new note types and expose them to REST web services.

To learn more, see [Note Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3762642.html).

This record:

-   is not a subrecord
    
-   has no subrecords
    

There are no prerequisites for using this record through REST web services.

The REST API Browser includes information about the field names and field types of the note type record, and about the HTTP methods, request parameters, and operations available to this record. For details, see the REST API Browser's [note type](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2026.1/index.html#tag-noteType) reference page.

For information about using the REST API Browser, see [The REST API Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157373386674.html).

## Record ID {#subsect_91164627376}

The record ID for a note type REST record is **notetype**.

## Code Sample {#subsect_4164636654}

The following samples show common use cases for notetype.

### Creating a Note Type {#subsect_87164656732}

              `POST https://{{REST_SERVICE}}/services/rest/record/v1/notetype Body: { "description": "NoteType description 1696527953", "isInactive": false, "name": "NoteType 1696527953", "externalId": "ext_1696527953", }'` 
            

### Retrieving a Note Type {#subsect_40164709420}

              `GET https://{{REST_SERVICE}}/services/rest/record/v1/notetype/209?expandSubResources=true` 
            

### Updating a Note Type {#subsect_37164724492}

              `PATCH https://REST_SERVICE/services/rest/record/v1/notetype/209 Body: { "description": "Updated NoteType description 1696528478", "isInactive": true, "name": "Update NoteType 1696528478" }'` 
            

### Deleting a Note Type {#subsect_70164838452}

              `DELETE https://REST_SERVICE/services/rest/record/v1/notetype/209`
