The campaign audience record exposes a campaign audience to REST web services.

This record:

-   is not a subrecord
    
-   contains no subrecords
    

For more information about working with campaign audiences in the UI, see [Campaign Audiences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1018420.html).

The REST API Browser includes information about the field names and field types of the campaign audience and about the HTTP methods, request parameters, and operations available to this record. For details, see the REST API Browser's [campaign audience](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2026.1/index.html#tag-campaignAudience) reference page.

For information about using the REST API Browser, see [The REST API Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157373386674.html).

## Record ID {#subsect_19220415625}

The record ID for a campaign response REST record is **campaignaudience**.

## Prerequisites {#subsect_41220422415}

You must enable the Marketing Automation feature before you can use this record through REST web services. For more information, see [Marketing Automation Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N973384.html).
