Take a closer look at when concurrency peaks happen and consider rescheduling requests to avoid peak times.

Make sure your client applications are designed to handle error codes properly. The following example shows how to handle error codes programmatically:

          `int i = 0;             int maxAttempts = 5; // try it 5 times, then fail for good              while (i < maxAttempts)             {                 response = doWSCall();                 isSuccess = response.getIsSuccess();                 errorMsg = response.getErrorMsg();                  if (isSuccess == false && (errorMsg == WS_CONCUR_SESSION_DISALLWD || errorMsg == WS_REQUEST_BLOCKED))                 {                     wait();                     i++; // try again                 }                 else                  {                     break; // end the cycle                 }             }` 
        

Upgrade your client applications to serialize requests and prevent overlap between non-concurrent users.

Updating your SOAP web services integrations to use Token-Based Authentication (TBA) allows for more flexible concurrency.
