A unit of measure record exposes a unit of measure to REST web services. The unit of measure is also known as a unit type. This record is not a subrecord.

The REST API Browser includes information about the field names and field types of the unit type record, and about the HTTP methods, request parameters, and operations available to this record. For details, see the REST API Browser's [units type](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2026.1/index.html#tag-unitsType) reference page.

For information about using the REST API Browser, see [The REST API Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157373386674.html).

## Record IDs {#subsect_6210234923}

The record ID for a unit of measure REST record is **unitsType**.

## Code Samples {#subsect_31210242105}

The following samples show common use cases for unit of measure. The example ID is 4.

### Creating a Unit of Measure Using a POST Request {#subsect_90210250656}

              `POST https://demo123.suitetalk.api.snap.netsuite.com/services/rest/record/v1/unitsType { "name": "unit A", "uom": { "items": [ { "abbreviation": "UA", "baseUnit": true, "conversionRate": 1.0, "inUse": false, "pluralAbbreviation": "UsA", "pluralName": "units A", "unitName": "unit A" } ] } }` 
            

### Retrieving a Unit of Measure Using a GET Request {#subsect_87210257428}

This sample shows how to retrieve an existing units type.

              `GET https://demo123.suitetalk.api.snap.netsuite.com/services/rest/record/v1/unitsType/4` 
            

This sample shows how to retrieve an existing units type unit of measure with the internal id of 567.

              `GET https://demo123.suitetalk.api.snap.netsuite.com/services/rest/record/v1/unitsType/4/uom/567` 
            

### Updating a Unit of Measure Using a PATCH Request {#subsect_35210302869}

This sample shows how to update an existing units type.

              `PATCH https://demo123.suitetalk.api.snap.netsuite.com/services/rest/record/v1/unitsType/4 { "name": "unit B", " description": "Unit description", }` 
            

This sample shows how to update an existing unit of measure.

              `PATCH https://demo123.suitetalk.api.snap.netsuite.com/services/rest/record/v1/unitsType/4 { "abbreviation": "UBx", "baseUnit": true, "conversionRate": 1.0, "pluralAbbreviation": "UsBx", "pluralName": "units Bx", "unitName": "unit Bx" }` 
            

### Deleting a Unit of Measure Using a DELETE Request {#subsect_87210309332}

              `DELETE https://demo123.suitetalk.api.snap.netsuite.com/services/rest/record/v1/unitsType/4`
