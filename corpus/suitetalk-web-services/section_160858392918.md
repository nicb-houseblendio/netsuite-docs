A change order record exposes a SuiteBilling change order to REST web services. This record has the following subrecords:

-   subLine
    
-   newSubLine
    
-   renewalSteps
    

The REST API Browser includes information about the field names and field types of the change order record, and about the HTTP methods, request parameters, and operations available to this record. For details, see the REST API Browser's [change order](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2026.1/index.html#tag-subscriptionChangeOrder) reference page.

For information about using the REST API Browser, see [The REST API Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157373386674.html).

## Record ID {#subsect_160858446306}

The record ID for the change order REST record is `subscriptionChangeOrder`.

## Prerequisites {#subsect_160858448176}

You must [Enabling SuiteBilling Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1546981120.html) before you can use this record through REST web services.

## Code Sample {#subsect_160858454587}

            `POST 'https://demo123.suitetalk.api.netsuite.com/services/rest/record/v1/subscriptionchangeorder' \ "action": "MODIFY_PRICING", "subscription": 208, "customer": 5, "billingAccount": 2, "subline": { "items": [ { "apply": true, "sequence": 1, "priceplannew": 541 } ] } }'`
