A Bill of Materials, or BOM, record exposes a Bill of Materials, or BOM, to REST web services.

This record:

-   is not a subrecord
    
-   has one subrecord: assembly
    

The REST API Browser includes information about the field names and field types of the BOM record, and about the HTTP methods, request parameters, and operations available to this record. For details, see the REST API Browser's [bom](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2026.1/index.html#tag-bom) reference page.

For information about using the REST API Browser, see [The REST API Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157373386674.html).

## Record IDs {#subsect_37203622213}

The record ID for a BOM REST record is **bom**.

## Prerequisites {#subsect_98203627219}

You must enable the Advanced Bill of Materials feature before you can use this record through REST web services.

## Code Samples {#subsect_7203640351}

The following samples show common use cases for BOMs. The example ID is 4.

### Creating a BOM Using a POST Request {#subsect_31203653441}

              `POST   https://demo123.suitetalk.api.snap.netsuite.com/services/rest/record/v1/bom {    "name": "bom rest 1",    "availableForAllAssemblies": true,    "availableForAllLocations": true,    "subsidiary": {        "items": [            {                "id": "5"            }        ]    } }` 
            

### Retrieving a BOM Using a GET Request {#subsect_51203701362}

              `GET https://demo123.suitetalk.api.snap.netsuite.com/services/rest/record/v1/bom/4` 
            

### Updating a BOM Using a PATCH Request {#subsect_59203705685}

              `PATCH https://demo123.suitetalk.api.snap.netsuite.com/services/rest/record/v1/bom/4 {    "assembly": {        "items": [            {               "assembly": {"id": 115},               "masterDefault": true            },            {                 "assembly": {"id": 67},                 "defaultforlocation":  {                     "items": [                         {                             "id": "5"                         },                         {                             "id": 8                         }                     ]                 }            }        ]    } }`
