These sections provide the basic information you need to get started with SOAP web services.

-   [SOAP Web Services Quick Start](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3419782.html) - provides step-by-step instructions on how to set up your SOAP web services environment and start building applications to interface with SOAP web services. Also provides a path for [Downloading Sample Applications](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3421207.html) provided by NetSuite.
    
-   [SOAP Web Services Development Considerations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3421363.html) - describes development considerations such as account configurations and the enabling of NetSuite features to ensure your SOAP web services calls execute successfully.
    
-   [SOAP Web Services PHP Toolkit](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N3533866.html) - provides setup information for those wanting to use the NetSuite PHP toolkit to develop SOAP web services applications.
    

To build a web services application, you need to enable the NetSuite web services feature in your account first. See [Enabling the SOAP Web Services Feature](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3419926.html).

After enabling SOAP web services, set your preferences to get started. See [SOAP Web Services Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N3422061.html).
