Use the PATCH command to add line items to a credit memo.

          `PATCH {{REST_SERVICES}}/record/v1/creditmemo/<id>/  {     "item": {         "items": [             {                 "item": {                     "id": 10                 },                 "amount": 100,                 "quantity": 25             }         ]     } }`
