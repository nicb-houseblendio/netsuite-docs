An inventory transfer transaction records the change in quantity when items are transferred between locations. It also decreases the on-hand quantity in the source location and increases it in the new location.

This transaction is available when the Locations feature and the Multi-Location Inventory (MLI) feature are enabled. For more details about this type of transaction, see [Transferring Inventory](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2308202.html).

The REST API Browser includes information about the field names and field types of the inventory transfer record, and about the HTTP methods, request parameters, and operations available to this record. For details, see the REST API Browser's [inventory transfer](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2026.1/index.html#tag-inventoryTransfer) reference page.

For information about using the REST API Browser, see [The REST API Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157373386674.html).

## Record IDs {#subsect_70112923016}

The record ID for an inventory transfer REST record is **inventorytransfer**.

The record ID for an inventory detail REST subrecord is **inventorydetail**.

## Prerequisites {#subsect_22113200224}

There are no prerequisites for using the record in REST.

## Sample Codes {#subsect_91113218491}

The sample codes show common use cases for inventory transfers.

### Creating an Inventory Transfer {#subsect_6113322186}

The following example shows how to create an inventory transfer:

              `POST {{REST_SERVICES}}/record/v1/inventorytransfer { "subsidiary": {"id": 1}, "location": {"id": 1}, "transferLocation": {"id": 2}, "inventory": { "items": [{ "item": { "id": 20 }, "adjustQtyBy": 10 }] } }` 
            

### Updating an inventory transfer {#subsect_54122555144}

The following example shows how to update an inventory transfer:

              `PATCH {{REST_SERVICES}}/record/v1/inventorytransfer/2072 { "total": 10.0, "inventory": { "items": [{ "line": 1, "adjustQtyBy": 2, "inventoryDetail": { "inventoryAssignment": { "items": [ { "internalId": 7207, "inventoryDetail": 1476, "inventoryStatus": {"id": 1}, "toInventoryStatus": {"id": 1}, "quantity": 2.0 } ] } } }] } }`
