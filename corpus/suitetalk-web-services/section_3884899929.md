For accounts using Multi-Book Accounting, the global account mapping record enables you to configure secondary accounting books to post to accounts different from the primary book. These mappings are used by transactions where the user can manually select the account to which the transaction posts.

This record is defined in the listAcct (Accounting) XSD, where it is called GlobalAccountMapping.

Using this record requires that, as part of your Multi-Book configuration, you select the Chart of Accounts Mapping option at _Setup > Company > Enable Features_, on the Accounting subtab.

In the user interface, you access this record at _Setup > Accounting > Global Account Mappings > New_.

For information about working with this record in the UI, see [Global Account Mapping](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3855055309.html).
