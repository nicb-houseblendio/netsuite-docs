Support case origin defines how a support case was initially reported for example, by phone, email, or web chat.

This record is not a subrecord and does not have any subrecords.

The REST API Browser includes information about the field names and field types of the support case origin record, and about the HTTP methods, request parameters, and operations available to this record. For details, see the REST API Browser's [support case origin](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2026.1/index.html#tag-supportCaseOrigin) reference page.

For information about using the REST API Browser, see [The REST API Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157373386674.html).

## Record ID {#subsect_86172711945}

The record ID for a support case origin REST record is **supportcaseorigin**.

## Prerequisites {#subsect_95172719573}

You must enable the following before you can use this record through REST web services:

-   Feature: CRM > Customer Support and Service
    
-   Permission: Setup > Support Case Origin
    

## Code Sample {#subsect_56172744974}

The following samples show common use cases for support case origin.

### Creating a Support Case Origin {#subsect_32172753905}

              `POST https://demo123.suitetalk.api.netsuite.com/services/rest/record/v1/supportcaseorigin Body: { "name": "Chat" }` 
            

### Reading a Support Case Origin {#subsect_27173122153}

              `GET https://demo123.suitetalk.api.netsuite.com/services/rest/record/v1/supportcaseorigin/{id}` 
            

### Updating a Support Case Origin {#subsect_16173307671}

              `PATCH https://demo123.suitetalk.api.netsuite.com/services/rest/record/v1/supportcaseorigin/{id} Body: { "description": "Real-time assistance via web chat" }` 
            

### Deleting a Support Case Origin {#subsect_80173314844}

              `DELETE https://demo123.suitetalk.api.netsuite.com/services/rest/record/v1/supportcaseorigin/{id}`
