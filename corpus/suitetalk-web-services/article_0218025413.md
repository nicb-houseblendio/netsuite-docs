A merchandise hierarchy version record exposes a merchandise hierarchy version to REST web services. This record is not a subrecord. This record contains one subrecord with the ID **hierarchylevels**.

The REST API Browser includes information about the field names and field types of the merchandise hierarchy version record and about the HTTP methods, request parameters, and operations available to this record.

For details, see the REST API Browser's [merchandise hierarchy version](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2026.1/index.html#tag-merchandiseHierarchyVersion) reference page.

For information on using the REST API Browser, see [The REST API Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157373386674.html).

## Record ID {#subsect_0218030351}

The record ID for the merchandise hierarchy node REST record is **merchandisehierarchyversion**.

## Prerequisites {#subsect_0218030334}

You must enable the Merchandise Hierarchy feature before you can use this record through REST web services. This feature depends on the Custom Segments feature.

## Code Sample {#subsect_0218030448}

### Creating a Merchandise Hierarchy Version {#subsect_0218033048}

              `POST {{REST_SERVICES}}/record/v1/merchandisehierarchyversion {     "name": "Version 1",     "description": "V1",     "startdate": "2024-09-01" }` 
            

### Updating a Merchandise Hierarchy Version {#subsect_0218033116}

              `PATCH {{REST_SERVICES}}/record/v1/merchandisehierarchyversion/{{id}} {     "name": "Version 1 updated",     "description": "V1 updated",     "startdate": "2024-09-02" }`
