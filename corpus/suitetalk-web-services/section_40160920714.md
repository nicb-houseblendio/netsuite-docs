The cash refund record exposes a cash refund to REST web services.

To access this record in NetSuite, go to _Transactions > Customers > Refund Cash Sales_.

A cash refund transaction records the return of money to a customer who immediately paid for goods or services using cash, a check or a credit card. For details about this type of transaction, see [Refunding a Cash Sale](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1247359.html).

This record has the following subrecords:

-   Accounting Books (accountingbookdetail)
    
-   Applied Rules (appliedrules)
    
-   Cash Refund Items (items)
    
-   Partners (partners)
    
-   Promotions (promotions)
    
-   Sales Team (salesteam)
    
-   Taxes (taxdetails)
    

The REST API Browser includes information about the field names and field types of the cash refund record and about the HTTP methods, request parameters, and operations available to this record.

For details, see the REST API Browser's [cash refund](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2026.1/index.html#tag-cashRefund) reference page.

For information about using the REST API Browser, see [The REST API Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157373386674.html).

Note:

REST web services do not support legacy tax features. To work with taxation through REST web services, you must have the SuiteTax feature enabled. For more information about using SuiteTax, see [SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/preface_1496364245.html).

## Record ID {#subsect_78160947893}

The record ID for a cash refund REST record is **cashrefund**.

## Prerequisites {#subsect_0310051755}

Before you can use this record through REST web services, you must first enable the Accounts Receivable feature. Go to Setup > Company > Setup Tasks > Enable Features. On the Accounting subtab, check the **A/R** box, and then click **Save**.

## Usage Notes {#subsect_0520035421}

Using this record requires you to specify an item line number that is 1-indexed.

To use the **Choose Team** and **Update Customer** fields in the Sales Team subtab, an administrator must first enable the Team Selling feature. Go to Setup > Company > Enable Features. Select the CRM subtab. Under Sales, check the **Team Selling** box, and then click **Save**.

To use the **Update Customer** field in the Relationships subtab, an administrator must first enable the Multi-Partner Management feature. Go to Setup > Company > Setup Tasks > Enable Features. Select the CRM subtab. Under Partners, check the **Multi-Partner Management** box, and then click **Save**.

## Code Samples {#subsect_73160952426}

These samples show common use cases for cash refunds.

### Create a Cash Refund {#subsect_0310051857}

              `POST: https://demo123.suitetalk.api.netsuite.com/services/rest/record/v1/cashrefund { "account": { "id": "155", "refName": "660 US Bank USD" }, "currency": { "id": "1", "refName": "USA" }, "entity": { "id": "110", "refName": "Anonymous Customer" }, "item": { "items": [ { "item": { "id": "98" }, "quantity": 1 } ] }, "location": { "id": "6", "refName": "US ONLY LOCATION" } }` 
            

### Read a Cash Refund {#subsect_0310051932}

              `GET: https://demo123.suitetalk.api.netsuite.com/services/rest/record/v1/cashrefund/318` 
            

### Update a Cash Refund {#subsect_0310052003}

              `PATCH: https://demo123.suitetalk.api.netsuite.com/services/rest/record/v1/cashrefund/318 { "account": { "id": "155", "refName": "660 US Bank USD" }, "currency": { "id": "1", "refName": "USA" }, "entity": { "id": "110", "refName": "Anonymous Customer" }, "item": { "items": [ { "line": 1, "refName": "Custom", "rate": 49.95, "item": { "id": "98" }, "quantity": 2 } ] }, "location": { "id": "6", "refName": "US ONLY LOCATION" } }` 
            

### Update a Cash Refund with a Line Item {#subsect_0310052354}

              `PATCH {{REST_SERVICES}}/record/v1/cashrefund/{id} {     "tranDate": "2026-01-20",     "tranId": "Updated Cash Refund ID",     "item": {         "items": [             {                 "item": {                     "id": "7"                 },                 "line": 1, // including line field will update the existing line at this index, excluding will add a new line                 "quantity": 1.0             }         ]     } }` 
            

### Delete a Cash Refund {#subsect_0310052035}

              `DELETE: https://demo123.suitetalk.api.netsuite.com/services/rest/record/v1/cashrefund/318` 
            

### Set the Sales Order's Sales Team Members to Match Sales Group 164 {#subsect_0522013924}

              `"salesGroup": {     "id": 164 }` 
            

### Update the Customer's Partner Team to Match the Transaction Partners {#subsect_0522014343}

              `"syncPartnerTeams": true` 
            

### Update the Customer's Sales Team to Match the Transaction Sales Team {#subsect_0522014656}

              `"syncSalesTeams": true`
