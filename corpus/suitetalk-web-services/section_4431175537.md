Use an integration record to block SOAP requests from a specific application. This method only blocks requests that identify the integration record. For instance, blocking Integration Record A only blocks requests with its application ID or token-based authentication details.

Apps using 2015.1 or earlier endpoints don't need to send this data in requests. Requests without this data are handled by the Default Web Services Integrations record, which can also be blocked.

#### To block web services requests: {#procedure_4431208100}

1.  Do one or both of the following:
    
    -   To block requests from a specific integration record, edit the record. Set the **State** field to **Blocked**, and click **Save**. After this, your account won't accept requests with the record's application ID or token-based authentication details. Additionally, RESTlet calls using the associated consumer key and secret will be blocked.
        
    -   To block requests from external apps without an application ID or token-based auth, edit the Default Web Services Integrations record. Set the **State** field to **Blocked**, and click **Save**.
