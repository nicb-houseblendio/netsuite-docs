In addition to using the responses NetSuite sends for each request, you can monitor synchronous SOAP web services processing in the NetSuite user interface. You have the following options:

-   Referring to the execution log of the appropriate integration record. For details on working with integration records, see [Integration Management](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4399047360.html).
    
-   [Using the SOAP Web Services Usage Log](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3444819.html)
    
-   [Creating Integration Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3445008.html)
    

See also [Handling of Lengthy Requests](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4078474279.html), which describes limitations that exist for sending responses.

For information about monitoring asynchronous requests, see [Monitoring Asynchronous Jobs from the UI](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3445354.html).
