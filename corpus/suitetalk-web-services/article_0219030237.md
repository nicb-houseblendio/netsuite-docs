An inventory status is an attribute that you can assign to items that you store and track in your inventory.

For more information, see [Inventory Status](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1515696627.html).

This record is not a subrecord.

The REST API Browser includes information about the field names and field types of the inventory status record, and about the HTTP methods, request parameters, and operations available to this record. For details, see the REST API Browser's [inventory status](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2026.1/index.html#tag-inventoryStatus) reference page.

For information about using the REST API Browser, see [The REST API Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157373386674.html).

## Record ID {#subsect_0219030514}

The record ID for the inventory status REST record is **inventoryStatus**.

## Prerequisites {#subsect_0219030529}

You must enable the Inventory Status feature before you can use this record through REST web services.
