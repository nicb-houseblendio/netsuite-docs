Use the Records Guide alongside the [SOAP Schema Browser](https://system.netsuite.com/help/helpcenter/en_US/srbrowser/Browser2026_1/schema/index.html). You'll find a link to the SOAP Schema Browser for each record in this guide. The SOAP Schema Browser shows all fields, sublists, and search filters for a record. Plus, get field-level help for each field in the record.

Each record description typically covers the following topics:

-   **Supported operations** - a list of all operations you can do with the record.
    
-   **Field definitions** - links to the SOAP Schema Browser, plus extra tips for some fields.
    
-   **Usage notes** - additional details or context about working with the record.
    
-   **Code samples** - examples in Java or C# to help you get started.
    

Important:

For a list of all NetSuite records that are supported in SOAP web services, see [SOAP Web Services Supported Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3635369.html).

## Working Online {#bridgehead_3823641839}

When working online, using either the PDF or online help version of this guide, click the links in each record description to access the SOAP Schema Browser. The SOAP Schema Browser will open in your default browser.

## Downloading the SOAP Schema Browser {#bridgehead_N3635209}

To download a .zip file of the SOAP Schema Browser, click the Download v2025.2 SOAP Schema Browser Zipped link. After you download the .zip and extract all files, go to the schema directory. To view the SOAP Schema Browser content, open index.html file in the browser of your choice.

[Download v2025.2 SOAP Schema Browser Zipped](https://content.netsuite.com/download/2025_2_Schema_and_Records_Browser.zip)

Note:

For information about using the SOAP Schema Browser, see [SOAP Schema Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3639052.html).
