Previously, concurrency for web services and RESTlets was managed separately for each user and authentication method. Starting with the 2017.2 release, web services and RESTlet concurrency are also governed at the account level. The account governance limit covers the total number of web services and RESTlet requests combined.

For a visual overview of the governance model, see the [Concurrency Governance Cheat Sheet PDF file](https://system.netsuite.com/core/media/media.nl?id=205292050&c=NLCORP&h=31f547d819de9e4473b2&_xt=.pdf).

For a visual overview of the governance model introduced in June 2020, see the [New Concurrency Governance Cheat Sheet PDF file](https://system.netsuite.com/core/media/media.nl?id=205292151&c=NLCORP&h=1a5af77f3fdd806dea9e&_xt=.pdf).
