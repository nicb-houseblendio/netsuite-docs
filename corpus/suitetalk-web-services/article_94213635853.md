A work order completion record exposes a work order completion to REST web services.

This record:

-   is not a subrecord
    
-   has the following subrecords:
    
    -   component
        
    -   operation
        

The REST API Browser includes information about the field names and field types of the work order completion record, and about the HTTP methods, request parameters, and operations available to this record. For details, see the REST API Browser's [work order completion](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2026.1/index.html#tag-workOrderCompletion) reference page.

For information about using the REST API Browser, see [The REST API Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157373386674.html).

## Record IDs {#subsect_52213646262}

The record ID for a work order completion REST record is **workOrderCompletion**.

## Prerequisites {#subsect_17203033132}

You must enable the Manufacturing Work In Process feature before you can use this record through REST web services.

## Code Samples {#subsect_5213702571}

The following samples show common use cases for work order completion. The example ID is 4.

### Retrieving a Work Order Completion Using a GET Request {#subsect_50203115537}

A work order completion is created by doing a transformation on a work order.

              `GET https://demo123.suitetalk.api.snap.netsuite.com/services/rest/record/v1/workOrderCompletion/4` 
            

### Updating a Work Order Completion Using a PATCH Request {#subsect_88213719978}

The following code sample shows how to edit the setup time in the operation sequence. The ID for the operation is 7.

              `PATCH https://demo123.suitetalk.api.snap.netsuite.com/services/rest/record/v1/workOrderCompletion/4/operation/7 { "laborSetupTime": 20.0 }` 
            

The following code sample shows how to edit the component with backflush. The component ID is 7.

              `PATCH https://demo123.suitetalk.api.snap.netsuite.com/services/rest/record/v1/workOrderCompletion/4/component/lineNumber=7 { "quantity": 3 }`
