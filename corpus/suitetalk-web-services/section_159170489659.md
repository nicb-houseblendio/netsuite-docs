A contact role record exposes a contact role to REST web services.

This record:

-   is not a subrecord
    
-   has no subrecords
    

All elements on this record are accessible through REST web services.

The REST API Browser includes information about the field names and field types of the contact role record, and about the HTTP methods, request parameters, and operations available to this record. For details, see the REST API Browser's [contactRole](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2026.1/index.html#tag-contactRole) reference page.

For information about using the REST API Browser, see [The REST API Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157373386674.html).

## Record ID {#subsect_159170500491}

The record ID for a contact role REST record is **contactrole**.

## Code Sample {#subsect_159170503969}

In the following example, _<accountID>_ represents your account ID.

HTTP request: `https://``_<accountID>_``/services/rest/record/v1/contactrole/1`

            `{ "name": "ContactRoleOne", "description": "Key Contact", "isinactive": true }`
