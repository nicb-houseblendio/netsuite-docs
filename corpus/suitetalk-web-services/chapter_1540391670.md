NetSuite REST web services provide an integration channel that extends the capabilities of SuiteTalk. REST web services provide a REST-based interface for interacting with NetSuite.

With REST web services, you can:

-   Use CRUD (create, read, update, delete) operations to manage NetSuite records and move between records. For details, see [Working with Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1540811107.html).
    
-   Get and process the API definition and record metadata. For details, see [Working with Resource Metadata](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1540810168.html).
    
-   Run NetSuite queries on records. For details, see [Record Filtering and Query](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1540810947.html).
    

## REST Web Services Features {#subsect_13133350732}

The following table provides an overview of features in REST web services, and how they work with records.

For information about the different REST web services features, see [Prerequisites and Setup for REST Web Services](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_5085602973.html).

| SuiteTalk REST Web Services | Generally Available Records |
| --- | --- |
| REST Record Service | Fully supported. |
| REST Query Service | Fully supported. To see which records you can use in queries, see the Records Catalog. For information, see [Records Catalog Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_159367781370.html). |

## REST Web Services Key Features {#subsect_77134318664}

Here's an overview of the main REST web services features:

-   Metadata - for more information, see [Working with Resource Metadata](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1540810168.html).
    
-   CRUD operations - for more information, see [Working with Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1540811107.html).
    
-   Record Collection Filtering - for more information, see [Record Collection Filtering](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1545222128.html).
    
-   Record Actions - for more information, see [Executing Record Actions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156631158782.html).
    
-   Record Transformation - for more information, see [Transforming Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157901123882.html).
    
-   Asynchronous request processing - for more information, see [REST Web Services Request Processing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_161251386312.html).
    
-   Workbook Dataset execution - for more information, see [Working with SuiteAnalytics Datasets in REST Web Services](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156577938018.html).
    
-   Workbook Dataset List - for more information, see [Getting a List of Datasets Through REST Web Services](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156577938018.html#subsect_159656293432).
    
-   SuiteQL Query execution - for more information, see [Executing SuiteQL Queries Through REST Web Services](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157909186990.html).
    

## Benefits of REST Web Services {#subsect_1544786431}

The benefits of REST web services include:

-   Simple access to records metadata. This includes user and company-specific metadata. For more information about working with records metadata, see [Working with Resource Metadata](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1540810168.html).
    
-   Easier handling of custom records and custom fields.
    
-   Easy to navigate API.
    
-   Unlike RESTlets, you don't need to write, deploy, and run custom scripts.
