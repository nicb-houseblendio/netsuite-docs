The SOAP web services platform refers to the software infrastructure used to expose NetSuite application functionality through SOAP web services. This section describes some of the core features of the SOAP web services and includes the following sections:

-   [Enabling Web Services Concurrent Users with SuiteCloud Plus](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3448861.html): provides an overview of the Web Services Plus license type.
    
-   [Operations and Their Internal ID Requirements](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3449174.html): describes IDs and how they are used.
    
-   [Using SOAP web services to Send Data from a CSV File](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4488980213.html): describes how to use the NetSuite Data Loader tool.
    
-   [Searching for SOAP Web Services Log Information](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4738049812.html): describes how to search for SOAP web services operation and record information.
    
-   [SOAP Web Services Operations Search Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4738050787.html): describes the SOAP web services operation fields available for search.
    
-   [SOAP Web Services Record Processing Search Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4738051114.html): describes the SOAP web services record fields available for search
    

Important:

NetSuite hosts customer accounts in multiple data centers. For that reason, the correct URL for SOAP web services access varies depending on the data center hosting the account.

For more details, see [Dynamic Discovery of URLs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_7094653807.html).
