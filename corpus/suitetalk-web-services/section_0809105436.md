Requisition records are used to initiate the purchase process for goods and services needed within your company. For help working with this record in the UI, see [Entering a Requisition](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3873972591.html).

NetSuite exposes the purchase requisition record to REST web services. This record is not a subrecord and does not contain a subrecord.

The following elements are not accessible through REST web services:

-   Item
    
-   Expense sublist
    
-   Accounting book sublist
    

The REST API Browser includes information about the field names and field types of the requisition record. It also includes information about the HTTP methods, request parameters, and operations available to this record. For details, see the REST API Browser's [requisition](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2026.1/index.html#tag-purchaseRequisition) reference page.

For information about using the REST API Browser, see [The REST API Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157373386674.html).

## Record ID {#subsect_69132159761}

The record ID for a purchase requisition REST record is **purchaserequisition**.

## Prerequisites {#subsect_80132722066}

To use the purchase requisition REST record, you must have the Requisition feature enabled.

## Code Samples {#subsect_55134415833}

The following code sample shows how to create a purchase requisition:

            `POST {{REST_SERVICES}}/record/v1/purchaseRequisition Body: { "entity": { "id": {{entityId}} }, "item": { "items": [{ "item": { "id": {{item}} }, "rate": 10 }] } }`
