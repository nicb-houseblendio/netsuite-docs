This section provides details on using Java to build an application that uses NetSuite SOAP web services. This section provides steps for the following tasks:

-   [Enabling the SOAP Web Services Feature](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3419926.html)
    
-   [Setting the Show Internal IDs Preference](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3420345.html)
    
-   [Building an Application with Java using Apache Axis](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3420833.html)
    
-   [Downloading Sample Applications](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3421207.html)
    
-   [Capturing SOAP](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3421282.html)
    

Pay attention to the following:

-   Before developing your own SOAP web services applications, you should see the topic [SOAP Web Services Development Considerations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3421363.html).
    
-   For information about working with SOAP web services and PHP, see [SOAP Web Services PHP Toolkit](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N3533866.html).
    
-   Although some customers have built SOAP web services applications using Perl, Perl is not officially supported by NetSuite.
