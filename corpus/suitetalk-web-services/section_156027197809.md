A price plan record exposes a SuiteBilling price plan to REST web services.

This record:

-   is not a subrecord
    
-   has no subrecords
    

The REST API Browser includes information about the field names and field types of the price plan record. It also includes information about the HTTP methods, request parameters, and operations available to this record. For details, see the REST API Browser's [price plan](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2026.1/index.html#tag-pricePlan) reference page.

For information about using the REST API Browser, see [The REST API Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157373386674.html).

## Record ID {#subsect_158809008525}

The record ID for a price plan REST record is **priceplan**.

## Prerequisites {#subsect_158798947373}

You must [Enabling SuiteBilling Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1546981120.html) before you can use this record through REST web services.

## Code Sample {#subsect_156027504623}

            `{ "currency": {"id": "1"}, "priceplantype": "2", "pricetiers": { "items": [ { "fromval": 0, "pricingoption": {"id": "-102"}, "value": 50.00 } ] } }`
