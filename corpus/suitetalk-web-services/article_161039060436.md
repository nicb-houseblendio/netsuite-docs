A task record exposes a task to REST web services.

This record:

-   is not a subrecord
    
-   has the following subrecords
    
    -   EventFile
        
    -   TaskCompanyMap
        
    -   TaskContactMap
        

The REST API Browser includes information about the field names and field types of the task record, and about the HTTP methods, request parameters, and operations available to this record. For details, see the REST API Browser's [task](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2026.1/index.html#tag-task) reference page.

For more information about using the REST API Browser, see [The REST API Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157373386674.html).

## Record ID {#subsect_161131787475}

The record ID for the task REST record is **task**.

## Exposed Elements {#subsect_161131789280}

The following task record elements are exposed to REST web services:

-   accesslevel
    
-   assigned
    
-   bom (Requires Advanced Bill of Materials feature)
    
-   bomrevision ( Requires Advanced Bill of Materials feature)
    
-   company
    
-   contact
    
-   createdate (Read only)
    
-   customform
    
-   duedate
    
-   endtime
    
-   externalid
    
-   id
    
-   nessage
    
-   order
    
-   owner
    
-   percentcomplete
    
-   priority
    
-   relateditem
    
-   reminderminutes
    
-   sendemail
    
-   startdate
    
-   starttime
    
-   status
    
-   supportcase
    
-   timedevent
    
-   title
    
-   transaction
    
-   usernotes
    

## Code Sample {#subsect_161131794107}

In the following example, `<accountID>` represents your account ID.

HTTP request: `https://<accountID>/services/rest/record/v1/task`

              `{ "title": "Prepare sales slides", "message": "Charts are required", "priority": "HIGH", "duedate": "2022-11-03", "timedevent": true }`
