To download the 2025.2 PHP Toolkit, click the link for the [PHPToolkit\_2025\_2.zip](http://content.netsuite.com/download/PHPToolkit_2025_2.zip) file.

Note:

If your browser does not download the PHP Toolkit zip file, copy the link and paste it in the address bar of a new tab or window of your browser. If needed, you can also try a different browser.

The toolkit is provided as an archive file and contains:

-   A folder called PHPToolkit that contains:
    
    -   NetSuiteService.php - Class library
        
    -   NSconfig.php - Passport configuration file
        
    -   NSPHPClient.php - Helper functions
        
-   A folder called Samples that contains PHP code examples that are usable in your own projects.
    

Next see, [Configuring an Environment for the PHP Toolkit](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3534858.html).
