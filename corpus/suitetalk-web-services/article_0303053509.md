NetSuite exposes the automated clearing house record to REST web services.

Automated Clearing House (ACH) is a secure electronic network used in the United States to transfer funds between bank accounts. Use the automated clearing house record when working with the ACH payment instrument type. For details, see [Payment Instruments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1538492538.html).

The automated clearing house record isn't a subrecord and doesn't have any subrecords of its own.

The REST API Browser includes information about the field names and field types of the automated clearing house record and about the HTTP methods, request parameters, and operations available to this record. For details, see the REST API Browser's [automated clearing house](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2026.1/index.html#tag-automatedClearingHouse) reference page.

For information about using the REST API Browser, see [The REST API Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157373386674.html).

## Record ID {#subsect_0303055834}

The record ID for automated clearing house is **automatedclearinghouse**.

## Prerequisites {#subsect_0303053952}

-   enable the Payment Instruments feature. For instructions, see [Payment Instruments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1538492538.html).
    
-   enable the Credit Card Payments feature. For instructions, see [Setting Up Customer Credit Card Processing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1572221.html).
