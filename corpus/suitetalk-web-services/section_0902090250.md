Classes (or classifications) can be used to identify and categorize records in your NetSuite account. You can also define classifications for your organization's needs by creating custom segments. Classifications enable you to better organize data and preserve accuracy.

For information about working with classes in the UI, see [Classifications in NetSuite](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N261411.html).

The REST API Browser includes information about the field names and field types of the class record, and about the HTTP methods, request parameters, and operations available to this record. For details, see the REST API Browser's [classification](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2026.1/index.html#tag-classification) reference page.

For information about using the REST API Browser, see [The REST API Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157373386674.html).

## Record ID {#subsect_83090321021}

The record ID for the classification REST record is **classification**.

The classification record has the following subrecord:

-   classTranslation
    

## Limitations {#subsect_78090326198}

Read-only sublists, including system notes, are not supported in REST.
