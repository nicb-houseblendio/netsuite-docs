An application can authenticate using an integration record in two ways: with an application ID and user credentials, or with token-based authentication. For help with token-based authentication, see [Token-Based Authentication Details](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4395622897.html). For details about sending an application ID, see the following topics:

-   [Requirements for Using an Application ID and User Credentials](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4399767175.html)
    
-   [Application ID Code Samples (Request-Level Credentials)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4399767063.html)
    
-   [Using Application ID with the Login and ssoLogin Operations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4502721888.html)
