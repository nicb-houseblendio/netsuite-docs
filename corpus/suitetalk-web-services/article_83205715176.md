A subtotal item record exposes a subtotal item to REST web services. This record is not a subrecord.

The REST API Browser includes information about the field names and field types of the subtotal item record, and about the HTTP methods, request parameters, and operations available to this record. For details, see the REST API Browser's [subtotal item](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2026.1/index.html#tag-subtotalItem) reference page.

For information about using the REST API Browser, see [The REST API Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157373386674.html).

## Record IDs {#subsect_20205734182}

The record ID for a subtotal item REST record is **subtotalItem**.

## Code Samples {#subsect_17205738870}

The following samples show common use cases for subtotal items. The example ID is 4.

### Creating a Subtotal Item Using a POST Request {#subsect_96205746733}

              `POST https://demo123.suitetalk.api.snap.netsuite.com/services/rest/record/v1/subtotalItem { "itemId": " Subtotal Item A", "displayName": "Subtotal Item A DisplayName" }` 
            

### Retrieving a Subtotal Item Using a GET Request {#subsect_11205753709}

              `GET https://demo123.suitetalk.api.snap.netsuite.com/services/rest/record/v1/subtotalItem/4` 
            

### Updating a Subtotal Item Using a PATCH Request {#subsect_2205758162}

              `PATCH https://demo123.suitetalk.api.snap.netsuite.com/services/rest/record/v1/subtotalItem/4 { "itemId": "Payment Item B", "displayName": "Payment Item B DisplayName", "description": "description" }` 
            

### Deleting a Subtotal Item Using a DELETE Request {#subsect_11205804221}

              `DELETE https://demo123.suitetalk.api.snap.netsuite.com/services/rest/record/v1/subtotalItem/4`
