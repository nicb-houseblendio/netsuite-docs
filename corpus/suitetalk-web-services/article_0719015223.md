A markup item record exposes a markup item to REST web services. To access this record in NetSuite, go to Lists > Accounting > Items > New > Markup.

The REST API Browser includes information about the field names and field types of the markup item record. It also includes information about the HTTP methods, request parameters, and operations available to this record. For details, see the REST API Browser's [markup item](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2026.1/index.html#tag-markupItem) reference page.

For information about using the REST API Browser, see [The REST API Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157373386674.html).

## Record ID {#subsect_38140813687}

The record ID for the markup item REST record is **markupitem**.

## Code Samples {#subsect_23143147175}

These samples show common use cases for markup items. The example ID is 6.

### Creating a Markup Item Using a POST Request {#subsect_39143448535}

              `{    "itemId": "New Markup",    "itemType": {       "id": "Markup",       "refName": "Markup"    },    "nonPosting": true,    "rate": 60 }` 
            

### Retrieving a Markup Item Using a GET Request {#subsect_6143602962}

              `GET: {{REST_SERVICES}}/record/v1/markupitem/6` 
            

### Updating a Markup Item Using a PATCH Request {#subsect_89143912687}

              `PATCH: {{REST_SERVICES}}/record/v1/markupitem/6  {    "itemId": "Newer Markup Item",    "rate": 80 }` 
            

### Deleting a Markup Item Using a DELETE Request {#subsect_51144158884}

              `DELETE: {{REST_SERVICES}}/record/v1/markupitem/6`
