A merchandise hierarchy node record exposes a merchandise hierarchy node to REST web services. This record is not a subrecord. This record contains one subrecord with the ID **hierarchyversions**.

The REST API Browser includes information about the field names and field types of the merchandise hierarchy node record and about the HTTP methods, request parameters, and operations available to this record.

For details, see the REST API Browser's [merchandise hierarchy node](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2026.1/index.html#tag-merchandiseHierarchyNode) reference page.

For information on using the REST API Browser, see [The REST API Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157373386674.html).

## Record ID {#subsect_0218024805}

The record ID for the merchandise hierarchy node REST record is **merchandisehierarchynode**.

## Prerequisites {#subsect_0218024927}

You must enable the Merchandise Hierarchy feature before you can use this record through REST web services. This feature depends on the Custom Segments feature.

## Code Sample {#subsect_0218025018}

### Creating a Merchandise Hierarchy Node {#subsect_0218032857}

              `POST {{REST_SERVICES}}/record/v1/merchandisehierarchynode {     "name": "Node 2",     "description": "N2" }` 
            

### Updating a Merchandise Hierarchy Node {#subsect_0218032934}

              `PATCH {{REST_SERVICES}}/record/v1/merchandisehierarchynode/{{id}} {     "name": "Node 2 updated",     "description": "N2 updated",     "hierarchyversions":{         "items":         [             {                 "hierarchylevel":{                     "id": 3                 },                 "hierarchyversion":{                     "id": 2                 },                 "parentnode": 1,                 "isincluded": true             }         ]     } }`
