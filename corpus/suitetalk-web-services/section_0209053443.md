Use the PATCH command to add a line item to an invoice:

          `PATCH {{REST_SERVICES}}/record/v1/invoice/<id>/ {     "item": {         "items": [             {                 "item": {                     "id": "13"                 },                 "quantity": 50,                 "amount": 100             }         ]     } }` 
        

To update a line item in an invoice, add the line item ID in the request.

          `PATCH {{REST_SERVICES}}/record/v1/invoice/<id>/ {     "item": {         "items": [             {                 "line": 5,                 "item": {                     "id": "10"                 },                 "quantity": 75,                 "amount": 90             }         ]     } }`
