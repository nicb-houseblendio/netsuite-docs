For help working with this record in the UI, see [Sales Taxes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4407866123.html).

This record is not a subrecord.

Note:

REST web services do not support legacy tax features. To work with taxation through REST web services, you must have the SuiteTax feature enabled. For more information about using SuiteTax, see [SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/preface_1496364245.html).

The REST API Browser includes information about the field names and field types of the sales tax item record, and about the HTTP methods, request parameters, and operations available to this record. For details, see the REST API Browser's [salesTaxItem](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2026.1/index.html#tag-salesTaxItem) reference page.

For information about using the REST API Browser, see [The REST API Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157373386674.html).

## Record ID {#subsect_0814122643}

The record ID for the sales tax item REST record is **salesTaxItem**.

## Prerequisites {#subsect_0814122759}

The SuiteTax feature must be enabled.

## Actions {#subsect_0814122832}

The sales tax item record has the following actions through REST web services:

-   Submit new
    
-   Submit
    

## Code Samples {#subsect_0814123051}

This code sample shows how to post the sales tax item record:

            `POST /services/rest/record/v1/salesTaxItem { "name": "Test Tax Code", "description": "Test Tax Code", "taxType": "13" }`
