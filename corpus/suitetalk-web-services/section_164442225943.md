A sales price rule record exposes a sales price rule to REST web services. This record is not a subrecord. This record has one subrecord: customerdimension.

The REST API browser includes information about the field names and field types of the sales price rule record, and about the HTTP methods, request parameters, and operations available to this record. For details, see the REST API Browser's [sales price rule](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2026.1/index.html#tag-salesPriceRule) reference page.

For information about using the REST API browser, see [The REST API Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157373386674.html).

## Record ID {#subsect_164442287122}

The record ID for a sales price rule REST record is **salespricerule**.

The record ID for a sales price rule subrecord is **customerdimension**.

## Prerequisites {#subsect_164442288478}

You must enable Advanced Pricing before you can use this record through REST web services.

You must use camel case for field names (likeThisExample).

## Limitations {#subsect_164442289744}

When you create a sales price rule, the inactive property must remain false by default. Also, base price rules must always be true.

## Code Sample {#subsect_164442290848}

The following code sample shows a common use case for updating a sales price rule record.

            `POST /services/rest/record/v1/salespricerule User-Agent: NetSuite-REST-Client Content-Type: application/json; charset=UTF-8 { "currency": { "id": "1" }, "endDate": "2001-01-31", "name": "Test Price Rule", "priceLevel": { "id": "106" }, "priority": 1, "startDate": "2001-01-01" }`
