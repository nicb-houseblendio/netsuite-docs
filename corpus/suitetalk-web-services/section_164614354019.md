An assembly item is an inventory item made up of several components but identified as a single item. Assemblies are manufactured by combining raw materials that you stock.

For more information, see [Assembly Items](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N2319010.html).

This record is not a subrecord.

The REST API Browser includes information about the field names and field types of the assembly item record, and about the HTTP methods, request parameters, and operations available to this record.

For details, see the REST API Browser's [assembly item](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2026.1/index.html#tag-assemblyItem) reference page.

For information about using the REST API Browser, see [The REST API Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157373386674.html).

## Record ID {#subsect_164622419578}

The record ID for the assembly item REST record is **assemblyItem**.

## Prerequisites {#subsect_164622421171}

You must enable the Assemblies feature before you can use this record through REST web services.

## Inaccessible Elements {#subsect_164622422927}

The following sublists are not accessible through REST web services:

-   Quantity Pricing Discount/Levels (quantitypricingdiscount, quantitypricinglevel)
    
-   Item Translations subtab (translations)
    

## Elements with Different Functionality {#subsect_164622425233}

The following sublists have different functionality through REST web services:

Manufacturing > Bills of Materials > Master Default field is not controllable through REST.

## Code Samples {#subsect_164622427578}

### Get Record Metadata {#subsect_164622429015}

              `GET https://<HOST>/services/rest/record/v1/metadata-catalog/assemblyItemHeader: Accept: application/swagger+json` 
            

### Get Record {#subsect_164622431743}

              `GET https://<HOST>/services/rest/record/v1/assemblyItem/<ID>?expandSubResources=true` 
            

### Update Record {#subsect_164622433573}

              `PATCH  https://<HOST>/services/rest/record/v1/assemblyItem/<ID> Header: Content-Type: application/json Body:  {        'itemId': 'Updated item name',        'upcCode: '123456' }` 
            

### Update Item Price when all Related Features are Enabled {#subsect_164622436766}

              `PATCH https://<HOST>/services/rest/record/v1/assemblyItem/<ID>/price/currencypage=1,pricelevel=1,quantity=10 Header: Content-Type: application/json Body: {     'price': 10 }` 
            

### Update Bill of Materials/Default for Location {#subsect_164622439043}

              `PATCH https://<HOST>/services/rest/record/v1/assemblyItem/<ID> Header: Content-Type: application/json Body: { "billOfMaterials": { "items": [ { "billOfMaterials": { "id": 14 } "defaultForLocation": { "items": [ { 'id": 5 }, { 'id": 6 } ] ] ] ] ] ]`
