A time transaction, also known as TimeBill, records the hours worked by an employee. You can use this transaction to record billable hours and invoice customers. This transaction is available when the Time Tracking feature is enabled.

Important:

The TimeBill record is labelled as the Track Time record in the UI.

The REST API Browser includes information about the field names and field types of the time bill record, and about the HTTP methods, request parameters, and operations available to this record. For details, see the REST API Browser's [time bill](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2026.1/index.html#tag-timeBill) reference page.

For information about using the REST API Browser, see [The REST API Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157373386674.html).

## Record ID {#subsect_164439865840}

The record ID for a time bill REST record is **timebill**.

## Prerequisites {#subsect_164439865841}

You must enable the Time Tracking feature before you can use this record through REST web services.
