Experience the new standard in NSPOS search today. The feature brings clarity and consistency by unifying how NSPOS handles searches for inactivated items. No matter where you're searching. This enhancement ensures a more intuitive experience, making it easier for users to find exactly what they need, faster and more reliably.

All item searches at NSPOS search items by their name/ID, their UPC code, or their RA-Barcode. There are several places where different types of searches are used, including in the journal, in validated returns searches and in non-validated returns searches.

This release unifies the behavior of the searches across all places in NSPOS

When searching for an inactivated item, all searches in NSPOS will not show a result for the item (although there can be an active RA-Barcode assigned to it). You may need to wait for a few minutes after the item inactivation before the change is reflect on all registers.

There may be different results when searching for an active item, depending on the item's RA-Barcode and UPC status. The following results are possible:

| Search type | Item is active & RA-Barcode is expired | Item is active and UPC is expired |
| --- | --- | --- |
| Find by item name/ID | Item is displayed | Item is displayed |
| Find by UPC code | Item is displayed | No result |
| Find by RA-Barcode | No result | Item is displayed |

If you need to see an inactivated item, the **Find inactivated items** search function lets you find inactivated items or items with inactivated or expired attributes. The results will show any items matching the criteria.

Important:

As a part of this feature release, the following flags have been removed:

-   Find Item: Disallow Expired Items
    
-   Find Item: Hide Expired Items
