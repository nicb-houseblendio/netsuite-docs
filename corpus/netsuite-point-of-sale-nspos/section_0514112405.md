The self-checkout kiosk feature lets your shoppers make purchases without the need for a cashier to handle each step in the process. With NSPOS 2025.1.0, authenticating at self-checkout kiosks is faster than ever. Assistants can now log in using a secure QR code scan followed by a quick PIN entry. There is no need for a username or password input. PIN entry is more efficient and tailored to the kiosk's design for a seamless experience.

#### How to configure QR code scan for self-checkout kiosk assistants

1.  Log in to NetSuite POS as Administrator
    
2.  Go to the Edit Employee form for the employees you want to enable QR code authentication for and select the **Kiosk Assistant** tab
    
    ![Edit employee window to select new Kiosk Assistant tab](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/NSPOS/NetSuitePointSaleReleaseNotes/2025_1/NSPOS_Edit_Employee_Kiosk_Assistant.png)
3.  Enter the alphanumeric representation of the QR code in the **QR Code** field
    

You can find the generated QR code in NetSuite ERP on the Employee record. Or you can use any QR code generator and generate a QR code for the QR code value you configured for the employee.

Note:

Administrators cannot enter PIN value for employees. Employees must enter PIN value in their own self-checkout kiosk.

#### How to configure PIN for self-checkout kiosk assistants at kiosk

1.  Log in to self-checkout kiosk as an **Assistant** using your username and password
    
2.  Go to **System Tools** and click **Set/Change your PIN**
    
    ![Set/Change Your Pin Button](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/NSPOS/NetSuitePointSaleReleaseNotes/2025_1/NSPOS_Set_Change_Your_Pin.png)
3.  Configure a PIN and enter your existing password. Your PIN can be between four and six numbers.
    
    ![Enter your new PIN and your existing password](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/NSPOS/NetSuitePointSaleReleaseNotes/2025_1/NSPOS_Enter_New_Pin_Password.png)

#### How to authenticate the self-checkout kiosk using QR code and PIN

1.  If you are authenticating the self-checkout kiosk as an assistant, the system will prompt you to "Scan your personal code or enter you admin credentials." Scan your QR code.
    
2.  ![Scan personal code or enter your admin credentials in the Assistance Login](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/NSPOS/NetSuitePointSaleReleaseNotes/2025_1/NSPOS_Assistance_Login.png)
3.  Enter your PIN
    
    ![Enter your PIN in the Assistance Login](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/NSPOS/NetSuitePointSaleReleaseNotes/2025_1/NSPOS_Assistance_Login_Pin.png)
4.  Click **Authenticate** to authenticate the self-checkout kiosk
