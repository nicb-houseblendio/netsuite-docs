This document lists the updates provided in NetSuite Point of Sale (NSPOS) version 2024.1.20. The enhancements/fixes listed here are not available to NSPOS customers until they have upgraded to this version. NetSuite will modify these notes when needed to provide our customers with additional information.

## Minor Release Components {#subsect_9131203492}

The NSPOS 2024.1.20 minor release is deployed to customers upon request if their server is running NSPOS 2024.1.10. This minor release is optional, and applies updates to these areas:

| Release Type | NSPOS Component | Updated? |
| --- | --- | --- |
| Minor Release | Bundle | **No** |
| Replication Server | **Yes** |
| NSPOS Application | **Yes** |

## Notes and Suggested Actions {#subsect_9131203493}

Updating your NSPOS components to 2024.1.20 is optional, but should be done to ensure your environment is using the most recent version of NSPOS. Use the descriptions in this topic to decide what actions to take after the minor release is deployed to your server.

You can verify server deployment by viewing any active RA-Workstation record in NetSuite ERP. See [Appendix: NSPOS Release Types and Verification](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_86104348453.html).

### Replication Server Update {#subsect_9131203496}

No user actions are available for the replication server portion of the update.

### NSPOS Application Update {#subsect_9131203497}

This application update requires restaging your registers/workstations. The sooner you perform restaging, the sooner your registers can benefit from the minor release.

Note that NSPOS registers can run in backward compatibility mode (one release prior to the server version) until time for restaging is available. You do not need to restage all registers immediately after the minor release is deployed.

## To Upgrade Your Registers {#subsect_9131203498}

Restage your registers to NSPOS 2024.1.20.

## Product Enhancements NSPOS 2024.1.20 {#subsect_9131203499}

To keep pace with recent versions of internal components, we have migrated NSPOS to .NET8. To read about the improvements included in .NET 8, see the Microsoft article [What's new in .NET 8](https://learn.microsoft.com/en-us/dotnet/core/whats-new/dotnet-8/overview).

## Fixes NSPOS 2024.1.20 {#subsect_9131203522}

The update includes these fixes.

### SuiteTax Upsync Not Working Properly for Voided Items {#subsect_0226032155}

When a NSPOS transaction contains a voided item, the upsync of the transaction to NetSuite ERP failed. Now the transaction completes as intended.

### Sales Order Deposit/Invoice Might Post to NetSuite ERP a Day Late {#subsect_0226032241}

In some cases, the deposit/invoice for a sales order was posted to NetSuite ERP a day later than the sales order transaction.

### Transaction Detail Report Not Showing Totals Correctly for Prices with Tax {#subsect_0226032327}

Transaction Detail Report was displaying incorrect totals for prices that included tax. Now when the report has prices that include tax, the total is accurate.

## Verifying an Minor Release Was Deployed {#subsect_9131203535}

You can verify that the minor release was deployed to your server by viewing any active RA-Workstation record in NetSuite ERP. See [Appendix: NSPOS Release Types and Verification](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_86104348453.html).
