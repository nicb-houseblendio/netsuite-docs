These topics describe how to configure SuiteTax for use with NetSuite Point of Sale (NSPOS), using the NSPOS menu, NSPOS SuiteTax custom records, and standard SuiteTax records.

The NSPOS menu is available as a tab in NetSuite ERP. The SuiteTax section doesn't appear until you have enabled SuiteTax.

**NSPOS SuiteTax Custom Records**

These settings records are configured for use with NSPOS.

-   [Global Settings](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_85151101714.html)
    
-   [Tax Schedules Settings](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_58151144703.html)
    
-   [Subsidiaries Settings](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_94151158177.html)
    
-   [Locations Settings](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_55151207358.html)
    

**Standard SuiteTax Records**

These tax-rate based records are part of the standard setup for NetSuite SuiteTax.

-   [Tax Schedules](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_94151215613.html)
    
-   [Tax Codes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_43151223274.html)
    
-   [Tax Groups](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_23151230749.html)
    

Note:

Processing for the records you configure occurs in the background. However, processing can take several hours. You should consider this processing time when preparing to use SuiteTax in your production environment.
