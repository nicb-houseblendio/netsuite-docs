This document lists the updates provided in NetSuite Point of Sale (NSPOS) version 2020.1.11. The enhancements/fixes listed here are not available to NSPOS customers until they have upgraded to this version. NetSuite will modify these notes when needed to provide our customers with additional information.

## Server Update - No Manual Steps Needed {#subsect_8153420418}

This minor release is an integration update to your server. It is deployed automatically to customers who are currently on NSPOS version 2020.1.10. The minor release does not contain a new version of the NSPOS application or bundle.

You can verify if this release has been deployed to your server by viewing the **Replication Server Version** on an RA-Workstation record. With the update, it will show **2020.1.11**.

![Replication Version number](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/NSPOS/NetSuitePointSaleReleaseNotes/2020_1/NS_ERP_view_versioning_2020_1_11.png)

## Note on Server/Workstation Versions after Minor Release Deployment {#subsect_49153500670}

Because the fix affects the server only, after the upgrade you might notice different version numbers between a workstation (register) and its NetSuite ERP > RA-Workstation record. This is a result of the server update and does not affect register operations or status.

-   When you log into NetSuite ERP and view the RA-Workstation record, the version shows 2020.1.11 for the server and workstation.
    
    ![Workstation record showing version 2020.1.11](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/NSPOS/NetSuitePointSaleReleaseNotes/2020_1/NS_ERP_RA_WORKSTATION_versioning_2020_1_11.png)
-   When you log into an NSPOS workstation (register), the version number in the top-left will show 2020.1.10 in all modes.
    
    ![Version number in NSPOS closed mode](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/NSPOS/NetSuitePointSaleReleaseNotes/2020_1/NS_NSPOS_versioning_2020_1_10_closed.png) ![Version number in NSPOS sales mode](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/NSPOS/NetSuitePointSaleReleaseNotes/2020_1/NS_NSPOS_versioning_2020_1_10.png)
    
    Note:
    
    You might see other areas on the workstation where the version is earlier than shown in NetSuite ERP.
    

## Also fixed {#subsect_16162527997}

This minor release also corrects these issues:

-   **Password change not recognized after staging** - after upgrading a register to NSPOS 2020.1.10, an employee was assigned an NSPOS Operator ID but could not log in after changing their password. (Issue 692723)
    
-   **Sales Audit report showed incorrect KPIs, Counts, and reported zero for Gross Sales** - the key performance indicators (KPIs) and counts listed on the report were not correct. Although the report included transactions, the transaction amounts were not included in the gross sales total. (Issues 694124 and 694678)
