## Database Application Replacement {#subsect_41140001359}

NSPOS 2020.1.X brings a change to the database architecture installed on your registers. We have replaced Microsoft SQL Server 2016 Service Pack 2 (or 3) Express with MySQL. The MySQL application does not have the storage limits found in Microsoft SQL Server and does not require installing the database in a separate task. Instead, MySQL is set up automatically when you use [Staging 2.0](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_162930310025.html) to create or upgrade a register.
