This document lists the updates provided in NetSuite Point of Sale (NSPOS) version 2020.1.22. The fixes listed here are not available to NSPOS customers until they have upgraded to this version. NetSuite will modify these notes when needed to provide our customers with additional information.

## Replication Server Update - No Manual Steps Needed {#subsect_13144802302}

This hot push is an update to your NSPOS server. The update is deployed automatically to customers currently on NSPOS version 2020.1.20 or later, and affects the following areas:

| Release Type | NSPOS Component | Updated? |
| --- | --- | --- |
| Hot Push | Bundle | No |
| **Replication Server** | **Yes** |
| NSPOS Application | No |

Important:

You do not need to restage registers for this hot push.

## Included Fixes {#subsect_3144808284}

The NSPOS 2020.1.22 hot push applies corrections to these issues:

-   **Incorrect monitoring status results** - In some instances, the RA-Workstation record > Workstation Monitoring tab displayed active workstations as being in an "offline" or "terminated" status due to no activity. (Issue 717639, 718934)
    
-   **Transactions integration problems** - In some cases, transactions created at workstations were not synced correctly to NetSuite ERP. The issue should be fixed now. (Issue 717639)
    

## Verifying That Server Hot Push Was Applied {#subsect_28144713344}

You can verify that the hot push was applied to your account by viewing any active RA-Workstation record in NetSuite ERP. For more information, see [Appendix: NSPOS Release Types and Verification](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_86104348453.html).

Note:

Do to an issue with version reporting, the NSPOS 2020.1.22 update does not change the **Replication Server Version**. After receiving the update, the server version will display the previous version you were using.
