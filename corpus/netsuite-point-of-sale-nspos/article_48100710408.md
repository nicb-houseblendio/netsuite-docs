This document lists the updates provided in NetSuite Point of Sale (NSPOS) version 2020.1.21. The enhancements/fixes listed here are not available to NSPOS customers until they have upgraded to this version. NetSuite will modify these notes when needed to provide our customers with additional information.

## Bundle Update - Optional Only For NSPOS 2020.1.20 {#subsect_55100719608}

The NSPOS 2020.1.21 minor release is a supplement to NSPOS 2020.1.20.

-   If you are already using **NSPOS 2020.1.20**, the 2020.1.21 minor release is optional.
    
    To install the minor release, follow the steps in these release notes for updating Bundle ID 294243. See [If you are using NSPOS 2020.1.1 (Bundle 294243)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159301995180.html#subsect_79093010971).
    
-   If you are using **NSPOS 2020.1.13 or earlier**, including 2018.2.X or 2019.1.X, do not update your bundle. Our Support team will contact you to schedule your required upgrade to 2020.1.21 or later.
    

NSPOS 2020.1.21 includes these fixes:

## Staged From Version Now Searchable {#subsect_77100838140}

The RA-Workstation record includes a **Staged From Version** field. This field shows which NSPOS release was installed on the server when the register was upgraded or, if it is a new register, when it was deployed.

With the NSPOS 2020.1.21 minor release, the **Staged From Version** can be included in **Saved Searches** that you create. This information is important for planning phased upgrades, especially when you have some registers running in backward compatibility mode.

## Sales Order Processing Adjustment {#subsect_62100859476}

The NSPOS 2020.1.20 release included a fix to correct sales order synchronization issues with default payment methods assigned to customers in NetSuite ERP.

For 2020.1.21, we refined and limited that fix to ensure it does not affect processing handled by other integrations that use SuiteTalk.

## RA-Workstation Record Load and Save Issue {#subsect_65100916064}

In some circumstances, the RA-Workstation record in NetSuite ERP was failing to load or save. This issue has been resolved.
