This document lists the updates provided in NetSuite Point of Sale (NSPOS) version 2020.1.13. The enhancements/fixes listed here are not available to NSPOS customers until they have upgraded to this version. NetSuite will modify these notes when needed to provide our customers with additional information.

## Server Update - No Manual Steps Needed {#subsect_86142802831}

This minor release is an integration update to your server. It is deployed automatically to customers who are currently on NSPOS version 2020.1.X. The minor release does not contain a new version of the NSPOS application or bundle.

You can verify if this release has been deployed to your server by viewing the **Replication Server Version** on an RA-Workstation record. With the update, it will show **2020.1.13**.

![Replication Server Version number](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/NSPOS/NetSuitePointSaleReleaseNotes/2020_1/NS_ERP_view_versioning_2020_1_13.png)

## Note on Server/Workstation Versions after Minor Release Deployment {#subsect_15142814344}

Because the fix affects the server only, after the upgrade you might notice different version numbers between a workstation (register) and its NetSuite ERP > RA-Workstation record. This is a result of the server update and does not affect register operations or status.

## Also fixed {#subsect_18142823262}

The NSPOS 2020.1.13 minor release includes a correction for this issue:

**Integration performance** - In some instances, integration with NetSuite ERP was impacted due to a resource-allocation issue on the server. (Issue 698105)
