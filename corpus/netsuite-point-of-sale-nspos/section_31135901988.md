To use the functionality provided in the 2025.1.X release, you must log into NetSuite and update your NetSuite Point of Sale (NSPOS) environment using bundle **294243**.

Working with bundles requires an Administrator Role. If you need assistance performing this update and verifying settings, please contact NetSuite Customer Support.

#### Update bundle 294243 to NSPOS 2025.1.X: {#T_procedure_51104806474_2}

1.  Log in to NetSuite as an administrator.
    
2.  Go to _Customization > SuiteBundler > Search & Install Bundles > List_.
    
3.  Locate Bundle ID **294243** in the list.
    
    If not found, tap **New** and search for `294243` using the **Keywords** field.
    
4.  A blue icon under the version number indicates that a new version is available. Using your mouse, point to the blue icon to display more information.
    
    If you do not see the blue icon, your installed bundle is already up to date and no further action is required.
    
5.  Using your mouse, point to the green icon and click **Update**. Allow time for the page to load
    
    ![Green bundle status](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/NSPOS/NetSuitePointSaleReleaseNotes/2025_1/NSPOS_Bundle_update_green_icon_text.png)
6.  Review the updates to be installed.
    
7.  NetSuite alerts you in red font if conflicts exist between your previous installation and the current installation.
    
    If any of these conflicts appear, select **Replace existing object**. If you are unsure, contact NetSuite Customer Support.
    
    ![Bundle upgrade conflicts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/NSPOS/NetSuitePointSaleReleaseNotes/2025_1/NS_ERP_Bundle_upgrade_conflicts.png) ![Bundle upgrade confilsts close up](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/NSPOS/NetSuitePointSaleReleaseNotes/2025_1/NS_ERP_Bundle_upgrade_conflicts_SUBSET.png)
8.  Click **Update Bundle**.
    
9.  Click **OK** at the prompt.
    
    The **Status** column will display a green check mark when the installation is complete.
