These topics describe how to configure SuiteTax for use with NetSuite Point of Sale (NSPOS). The setup is performed using the NSPOS menu, NSPOS SuiteTax custom records, and standard SuiteTax records.

The NSPOS menu is available as a tab in NetSuite ERP. The SuiteTax section does not appear until you have enabled SuiteTax.

![NSPOS SuiteTax menu](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/NSPOS/NetSuitePointSaleReleaseNotes/2024_1/NS_ERP_SuiteTax_NSPOS_menu.png)

**NSPOS SuiteTax Custom Records**

These settings records are configured for use with NSPOS.

-   [Global Settings](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0312104957.html)
    
-   [Tax Schedules Settings](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0313034409.html)
    
-   [Subsidiaries Settings](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0510024358.html)
    
-   [Locations Settings](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0510024408.html)
    

**Standard SuiteTax Records**

These tax-rate based records are part of the standard setup for NetSuite SuiteTax.

-   [Tax Schedules](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0313125458.html)
    
-   [Tax Codes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0320043034.html)
    
-   [Tax Groups](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0320033753.html)
    

Note:

Processing for the records you configure occurs in the background. However, processing can take several hours. You should consider this processing time when preparing to use SuiteTax in your production environment.
