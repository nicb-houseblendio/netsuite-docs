In addition to behind-the-scenes fixes, NetSuite Point of Sale (NSPOS) 2020.1.0 includes the following updates.

## Default Account 9999 No Longer Used {#subsect_163336473994}

This default account setup and corresponding password have been removed from our servers and from the staging setup. The change means that you no longer need to manually remove the account or change the password.

## Find Item/Customer on NSPOS {#subsect_163336494740}

Retailers who have a very large number of items or customers have found that NSPOS can take a long time to return search results. To speed the process, we have limited search results to 1000 records. In addition, the results are now provided in alphabetical order.

Use well-defined criteria when entering a search to ensure the results include the desired item or customer

## Changes to Report Format Options {#subsect_163336498189}

The database application change from Microsoft SQL Server to MySQL in NSPOS 2020.1.X limits the formats available for report output. This table shows the difference in formats between NSPOS releases.

| NSPOS 2020.1.X report formats | NSPOS 2019.1.X and earlier |
| --- | --- |
| Word Excel PowerPoint PDF Data Feed | Word Excel PowerPoint PDF TIFF file MHTML (web archive) CSV (comma delimited) XML file with report data Data Feed |

## Workstation Provisioning for Mass Staging Removed {#subsect_163336504016}

Because Staging 2.0 generates fresh staging packages for all workstations every 24 hours, the options previously provided by the mass provisioning feature are no longer needed. You will no longer see the **NSPOS Workstations Provisioning** record in NetSuite under Customization > Lists, Records, & Fields > Record Types.
