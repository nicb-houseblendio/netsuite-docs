You can configure the logo that appears in the NetSuite Point of Sale (NSPOS) journal window using the NetSuite ERP File Cabinet.

Warning:

**File Cabinet changes can affect performance.** Moving or modifying files in the File Cabinet can seriously affect NSPOS performance or cause it to cease functioning completely. If you're not sure about making a change, please contact NSPOS Customer Support first.

**Ensure limited access to the File Cabinet.** You should strictly limit File Cabinet access to only your administrator and others that have a need for such access. Not restricting access could enable others to inadvertently or maliciously interrupt NSPOS operations, including causing a complete denial of service at the point of sale.

## Specifications {#subsect_0102101833}

-   **Image size** - No limitation in terms of pixels for image size
    
-   **File name** - The default file name is **Journal Logo.jpg** but you can use any file name. File names for logos aren't case sensitive.
    
-   **File extensions** - Logo files can be in JPG, JPEG, PNG, or GIF format
    
-   **File size** - Maximum size is 10 MB
    

#### To configure your Journal Logo

1.  Log in to NetSuite as an administrator.
    
2.  Go to Documents > Files > File Cabinet.
    
3.  Expand the folder NSPOS > RAFS Content > RAPOS > Logo
    
4.  .Click **Edit** for the current logo file.
    
5.  If desired, click **Download** to save a local copy of the current file.
    
6.  Under **Select File**, click **Choose File**.
    
7.  Select the new logo file and click **Open**.
    
8.  Click **Save**.
    

Tip:

To use a different logo image at certain locations (stores) or workstations, set up a folder structure for those areas and add your versions of **Journal Logo.png** to those folders.

-   **Stores:** NSPOS > File System > RAPOS > Logo > Store # > Journal Logo.jpg
    
-   **Workstations:** NSPOS > File System > RAPOS > Logo > Workstation # > Journal Logo.jpg
