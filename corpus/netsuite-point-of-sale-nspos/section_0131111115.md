Instead of provisioning a workstation for restaging using the RA-Workstation record in NetSuite ERP, you can download and run the staging client directly from the register.

When you use this process:

-   The same staging package downloads that you receive from using the Provisioning > Installation URL link in NetSuite ERP
    
-   The NSPOS application closes so that restaging can start
    
-   The staging client opens and starts automatically
    
-   The same staging options that are available when downloading from NetSuite ERP are available when restaging from the register
    
-   When you start NSPOS after restaging, the register will use the version you installed
    

#### To restage NSPOS from the register: {#procedure_0131124505}

1.  Sign on to NSPOS as a manager or administrator (Resource ID 9070 or greater).
    
2.  Press **Ctrl+F12** to open the Function List.
    
3.  Search for and tap **Restage.RunStagingClient**.
    
    ![Function List search for restage from register](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/NSPOS/NetSuitePointofSaleAdminGuide/NSPOS_Stage_from_workstation_Function.png)
    
    The staging client downloads and the verification step begins automatically. For information about the staging process and options, see [Stage a Register in NSPOS 2020.1.X or 2024.1.X](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164936755439.html).
    
4.  Manually start NSPOS when the staging process is complete.
    

If desired, you can assign the restaging function to a button that is available only to managers and administrators. Running restaging from a button eliminates a few steps from the process.

![Example button setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/NSPOS/NetSuitePointofSaleAdminGuide/NSPOS_Stage_from_workstation_Function_Button.png)

#### To assign Restage.RunStagingClient to a button: {#procedure_0131015641}

1.  Press **Ctrl+F12** to open the Function List.
    
2.  Search for and tap **Button Edit**.
    
3.  Tap **Main** (bottom) or **Side** and then tap **Pages**.
    
4.  Under **Button Page**, tap **Other Functions** or a different page on which to place the button.
    
5.  Tap **Activate** so that you can see the changes immediately.
    
6.  Tap **Buttons**.
    
7.  Tap **New** to create a new button or tap an existing button to remap it.
    
8.  Search for and tap **Restage.RunStagingClient**.
    
9.  Tap **Done**.
    
10.  Enter a **Caption** for the button, such as **Restage**.
     
11.  Choose a button **Style**, **Width**, **Height**, and other options as desired. See [Configure Button Bars](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4537576167.html) for more information.
     
12.  Close the button window when your setup is complete.
