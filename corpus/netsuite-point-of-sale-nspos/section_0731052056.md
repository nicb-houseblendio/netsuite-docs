Follow these procedures to stage an NSPOS kiosk, set up a kiosk welcome page image, and work item images. For topics that describe using the kiosk, see [Self-checkout Kiosk](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_66171906511.html).

## Provisioning a Kiosk {#subsect_82155946115}

Staging a kiosk works the same way as staging an NSPOS workstation. The only difference is the **Provisioning Type** you select on the RA-Workstation record.

1.  Locate the RA-Workstation record set up for the kiosk
    
2.  Click **Edit**
    
3.  Select **Kiosk** as the Provisioning Type and click **Save**
    
4.  Wait a few minutes.
    
5.  Click **View** and then click the **Installation URL**
    
6.  The staging package download begins
    

![Kiosk Provisioning type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/NSPOS/NetSuitePointofSaleAdminGuide/NS_ERP_Kiosk_WS_Provision.png)

See [Add an RA-Workstation Record in NetSuite](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4768027020.html) or see [Set up a Register](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4737180054.html) for a complete guide to staging.

Important:

You should use and configure FreedomPay in NetSuite ERP before staging your first kiosk.

Because FreedomPay is the only payment gateway NSPOS kiosk supports, staging a kiosk without first configuring FreedomPay will result in a non-functioning kiosk.

![kiosk staging](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/NSPOS/NetSuitePointofSaleAdminGuide/NS_ERP_Kiosk_WS_Staging.png)

## Working with Images for the Kiosk {#subsect_62160007359}

You can customize an image to use as your NSPOS kiosk "welcome" page while the kiosk is in idle mode. You can also add item images that display with line items as the shopper adds their purchases to the kiosk journal. Both procedures include adding images to the File Cabinet.

Warning:

Changes made to certain areas of the File Cabinet can affect performance. You should limit who has access to the File Cabinet and contact Customer Support if you're unsure about making a change.

### Kiosk Image Specifications {#subsect_94160035968}

Images to be used for your welcome page or items should meet these specifications:

-   **Formats Supported:**
    
    -   PNG
        
    -   JPG/JPEG
        
    -   PJPEG
        
    -   BMP
        
    -   TIFF
        
-   **Maximum File Size:** 10 MB
    

Important:

**File sizes over 10 MB** - File Cabinet will accept these images for upload, but NSPOS will **not** use those images at the kiosk. If an image is missing from the kiosk, verify the file size used.

### Setting Up Your Kiosk Welcome Page Image {#subsect_40160045170}

Use these steps to set up your kiosk idle-mode welcome page image, which greets the shopper as they begin the self-checkout process.

The welcome page is the left-hand pane as shown in this example.

![Kiosk welcome page image](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/NSPOS/NetSuitePointofSaleAdminGuide/NSPOS_Kiosk_Shopper_Welcome_Image.png)

### Image Size {#bridgehead_95102549719}

Welcome page images should have a resolution of **480 x 560** pixels, height x width.

-   If you use a smaller image, NSPOS centers it on the page and leaves the remaining area empty.
    
-   If you use a larger image, portions of the image may be hidden.
    

### File Name {#bridgehead_54102702586}

The default welcome image is **IdleLogo.png**.

-   Your replacement for the default image must be named **IdleLogo.\*** where \* is any one of the supported formats.
    
    For example, **IdleLogo.png** or **IdleLogo.jpg**.
    
-   The **IdleLogo** file name must use an upper-case **I** for "Idle" and **L** for "Logo."
    

#### To set up your kiosk welcome page image:

1.  Create an image file named **IdleLogo.\***, such as **IdleLogo.png**.
    
2.  Log into NetSuite ERP as an administrator.
    
3.  Go to _Documents > Files > File Cabinet_.
    
4.  Go to the folder NSPOS > File System > RAPOS > Kiosk.
    
5.  Click **Add File**.
    
6.  Select your **IdleLogo.\*** file.
    
7.  Click **Open**.
    
8.  Click **OK** if you are prompted about replacing the existing image file.
    
    Important:
    
    If your IdleLogo.\* file isn't in PNG format, you should delete the default PNG file. For example:
    
    1.  Upload **IdleLogo.jpg**
        
    2.  Delete **IdleLogo.png** (default)
        
    

Tip:

To use a different version of the image at certain locations or workstations, set up a folder structure for those areas and add your versions of **IdleLogo.png** to those folders.

For example: NSPOS > File System > RAPOS > Kiosk > Store ##

### Adding Kiosk Item Images {#subsect_94160058047}

Use this topic to add item images and associate images with individual item records. Item images appear as the shopper adds items to the kiosk journal.

![Image with item on journal](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/NSPOS/NetSuitePointofSaleAdminGuide/NSPOS_Kiosk_Shopper_Journal_Item_image.png)

### Image Size {#bridgehead_39102753600}

Item images should have a resolution of **256 x 256** pixels, height x width.

-   If an image has a resolution greater than 256 x 256, NSPOS downsyncs the image to the kiosk, converts the image to be 256 x 256 and saves the converted image to the kiosk database. This process can delay the time needed for an image to become available.
    
    Tip:
    
    To ensure performance for NSPOS synchronization updates with your kiosks, always use a resolution of 256 x 256 for item images.
    

#### Upload and Use Kiosk Item Images {#subsect_44160149507}

Follow this procedure to add multiple images to the File Cabinet. To add a single image or to learn more about uploading images, see [Upload Images to the File Cabinet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162137397938.html).

Uploading a large quantity of images or using large file sizes can increase the time it takes to downsync images to each kiosk.

#### To upload multiple images to the File Cabinet:

1.  On your computer, create a ZIP file of the images to upload.
    
    Don't include folders in your zip file. Folders can complicate unzipping your images in the File Cabinet.
    
2.  Log into NetSuite ERP as an administrator.
    
3.  Go to _Documents > Files > File Cabinet_.
    
4.  Open the **Images** folder. (Your setup may use a different folder name.)
    
5.  Click **Advanced Add**.
    
6.  From the **Zip Archive to Add** field, select the ZIP file you created on your computer and click **Open**.
    
7.  Check the **Unzip Files** box. Checking this box unzips your files directly into the images folder.
    
8.  Click **Add**.
    
    Note:
    
    New and changed images are synchronized to the kiosk with the next downsync, usually within one hour. However, due to caching requirements, an image update may take up to two hours. Uploading multiple images can increase the time needed to downsync and update.
    

#### To associate an item with its image:

1.  Log into NetSuite ERP as an administrator.
    
2.  Go to _Lists > Accounting > Items_.
    
3.  Locate the item and click **Edit**.
    
4.  Open the **Custom** subtab.
    
5.  Locate the **NSPOS Item Image** field.
    
6.  Click the list icon and select the item's image.
    
    ![Kiosk item image field](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/NSPOS/NetSuitePointofSaleAdminGuide/NS_ERP_Kiosk_Item_Image_field.png)
7.  Click **Save**.
    

#### Use Your Web Store Item Images at the Kiosk {#subsect_55131752153}

You can use item images set up for your web store for journal line items on the kiosk. The **Use Web Store Image for NSPOS** option overrides any NSPOS item image already set up on the item record.

#### To set an item to use a web store image at the kiosk:

1.  Log into NetSuite ERP as an administrator.
    
2.  Go to _Lists > Accounting > Items_.
    
3.  Locate the item and click **Edit**.
    
4.  Open the **Custom** subtab.
    
    ![Use web store image](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/NSPOS/NetSuitePointofSaleAdminGuide/NS_ERP_Kiosk_Use_Web_Store_image.png)
5.  Check the **Use Web Store Image For NSPOS** option.
    
6.  Open the **Web Store** subtab.
    
7.  Verify the image to use in the **Item Display Image** field.
    
    ![Web store item display image](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/NSPOS/NetSuitePointofSaleAdminGuide/NS_ERP_Kiosk_Web_Store_item_display_image.png)
8.  Click **Save**.
    

The web store item image will be used for the item at the kiosk. If a web store **Item Display Image** is not selected, no item image will be used at the kiosk.

Note:

New and changed images are synchronized to the kiosk with the next downsync, usually within one hour. However, due to caching requirements, an image update may take up to two hours.
