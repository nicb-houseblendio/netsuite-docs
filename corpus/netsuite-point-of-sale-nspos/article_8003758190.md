This document lists the updates provided in NetSuite Point of Sale (NSPOS) version 2025.1.4. The fixes listed here are not available to NSPOS customers until this hot push has been deployed to their environment. NetSuite will modify these notes when needed to provide customers with additional information.

## Hot Push Components {#subsect_0812123906}

This hot push is applied automatically to NSPOS customer environments and affects the following areas:

| Release Type | NSPOS Component | Updated? |
| --- | --- | --- |
| Hot Push | Bundle | No |
| Replication Server | Yes |
| NSPOS Application | Yes |

## Notes and Suggested Actions {#subsect_0812124010}

No action is required for the server-side portion of this hot push.

For more information about verifying deployment, see [Appendix: NSPOS Release Types and Verification](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_7316222129.html).

### Bundle Update {#subsect_0812124200}

No bundle update is required for this hot push.

### Replication Server Update {#subsect_0812124240}

No user actions are available for the replication server portion of the update.

### NSPOS Application Update {#subsect_0812124254}

Restaging registers is not required immediately after this hot push is deployed. If you provision or restage a register after the update, the register will use the 2025.1.4 staging package.

Important: Restaging or provisioning to 2025.1.4 includes an update to MySQL 8.4.9. This portion of the staging process may take additional time to complete on each register.

## Included Fixes and Updates {#subsect_0812124327}

The NSPOS 2025.1.4 hot push includes the following fixes and updates:

-   Security and infrastructure updates: Security-related updates were applied to NSPOS server and monitoring components.
    
-   Synchronization reliability: Updates were applied to improve handling of intermittent communication failures during replication processing.
    
-   Replication Agent compression handling: An issue that could prevent the Replication Agent from processing compressed payload data was corrected.
    
-   MySQL database engine update: The MySQL database engine used by NSPOS staging was updated to MySQL 8.4.9.
    
-   Version information NSPOS version information shown throughout the NSPOS ecosystem is updated to 2025.1.4, including the version shown in NetSuite ERP on the RA-Workstation record. Some components may show this version even when they have no functional changes.
    

### Verify a Hot Push Was Deployed {#subsect_0812124404}

See [Appendix: NSPOS Release Types and Verification](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_7316222129.html) for the steps to determine if an update has been deployed to your server.
