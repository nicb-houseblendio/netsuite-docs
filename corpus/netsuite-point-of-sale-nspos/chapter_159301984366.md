## Prerequisites {#subsect_159301988833}

-   Your server and all registers must be on NSPOS 2018.2.0 or later prior to moving to 2020.1.X.
    
    Important:
    
    Backward compatibility in this release is available for environments running 2018.2.X and 2019.1.X only.
    
-   You must have the appropriate third-party applications installed. See [Prerequisites for NSPOS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1495565126.html) under 'Set up a Register' in the NetSuite Point of Sale Administrator Guide.
    
    Important:
    
    The **Microsoft SQL Server** (MSSQL) prerequisite listed in the Administrator Guide does not apply to NSPOS 2020.1.X. This Microsoft database server was replaced by **MySQL**, which is installed automatically with the NSPOS 2020.1.X bundle.
    

## Required User Actions {#subsect_159301986739}

To use the functionality included in this release, your business must perform the following steps:

1.  [Perform the Update to NSPOS 2020.1.X](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159301995180.html)
    
2.  Set up the **Security GUID** with random characters. This procedure enhances the token used for secure communications. See [Configuring the Security GUID](#subsect_94140001250).
    
    Important:
    
    You must configure the **Security GUID** after installing the NSPOS 2020.1.X bundle. Otherwise you might experience loss of function for staging new registers and for handling tasks such as real-time sales orders on existing registers.
    
3.  Configure options as needed for features you want to use. For example, configuring [Digital Receipts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_162930296833.html) or setting up [Location and Working Hours Restrictions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_164822375473.html).
    
4.  Perform [User Acceptance Testing (UAT)](#subsect_159301988179) as desired
    

Your assistance will be required to perform the upgrade. A NetSuite representative will contact you in advance to agree on the details.

## Configuring the Security GUID {#subsect_94140001250}

This setup configures the encrypted security token used to authenticate NSPOS communication over secure connections. The random characters you enter supplement the encrypted token characters automatically assigned by NetSuite. Do this task after installing the NSPOS 2020.1.X bundle and before staging any registers.

Important:

This setup must be performed before staging any register to NSPOS 2020.1.X.

#### To configure the Security GUID after installing the bundle:

1.  Log in to NetSuite as an administrator.
    
2.  Go to Setup > Integration > (Partner Integrations) Setup Security GUID.
    
3.  Enter 32 random characters. You can enter letters, numbers, or a mix of both.
    
    ![Security GUID setup form](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/NSPOS/NetSuitePointSaleReleaseNotes/2020_1/NS_ERP_Security_GUID_Token_Random.png)
    
    Tip:
    
    No need to count the characters. Entries will stop when you have reached the 32-character limit.
    
4.  Click **Save**.
    

## User Acceptance Testing (UAT) {#subsect_159301988179}

When your NSPOS upgrade is complete, you should test at least one register in every location. You can find a verification checklist in the NetSuite Help Center > User Guides > NetSuite Point of Sale (NSPOS) section. See [NSPOS Register Verification Checklist](https://system.netsuite.com/help/helpcenter/shared_resources/PDF/NSPOS_Register_Verif_Checklist.pdf).
