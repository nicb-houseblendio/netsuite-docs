To use the functionality provided in the 2020.1.X release, you must log into NetSuite and update your NetSuite Point of Sale (NSPOS) environment to bundle 294243.

The update procedure you will use depends on your current NSPOS release:

-   [If you are using NSPOS 2018.2.X (Bundle 27525 or 399097)](#subsect_36102219142)
    
-   [If you are using NSPOS 2019.1.X (Bundle 294243)](#subsect_85102236705)
    
-   [If you are using NSPOS 2020.1.1 (Bundle 294243)](#subsect_79093010971)
    

Working with bundles requires an Administrator Role. If you need assistance performing this update and verifying settings, please contact NetSuite Customer Support.

Important:

**Register backward compatibility** - When upgrading to 2020.1.X from 2018.2 or 2019.1, only registers that have connected to the replication server within 10 days prior to the upgrade can be used in backward compatibility mode.

If a 2018.2 or 20191.1 register was not online within the 10 days, it will be unable to connect and must be restaged to 2020.1.X.

## If you are using NSPOS 2018.2.X (Bundle 27525 or 399097) {#subsect_36102219142}

Follow these steps to install the new 2020.1.X bundle 294243 and then uninstall the previous bundle for NSPOS 2018.2.X.

Important:

**Reprinting Receipts** - Any receipts generated using 2018.1.2.X will not be available for reprinting after your upgrade to NSPOS 2020.1.X.

The 2018.2.X reprint function was replaced in NSPOS 2019.1.X, and is considered to be obsolete.

Warning:

Do not uninstall your previous bundle until you have installed the new bundle. Otherwise, you could lose data and the integration with NetSuite ERP will stop working.

#### Install bundle 294243 for NSPOS 2020.1.X: {#procedure_0621031105}

1.  Log in to NetSuite as an administrator.
    
2.  Go to _Customization > SuiteBundler > Search & Install Bundles > List_.
    
3.  Locate Bundle ID **294243** in the list.
    
    If not found, tap **New** and search for `294243` using the **Keywords** field.
    
4.  Click the **Name** by the **Bundle ID**.
    
5.  Click **Install**.
    
6.  NetSuite alerts you in red font if conflicts exist between your previous installation and the current installation.
    
    If any of these conflicts appear, select **Replace existing object**. If you are unsure, contact NetSuite Customer Support.
    
    ![Upgrade conflicts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/NSPOS/NetSuitePointSaleReleaseNotes/2020_1/NSPOS_18_2_19_1_upgrade_conflicts.png) ![Upgrade conflicts subset view](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/NSPOS/NetSuitePointSaleReleaseNotes/2020_1/NSPOS_18_2_19_1_upgrade_conflicts_SUBSET.png)
7.  Review the **Custom Lists/Records** section to ensure the **Preference** column matches these images.
    
    If not, select **Replace Data** or **Preserve Data** as shown.
    
    ![Bundle lists to verify](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/NSPOS/NetSuitePointSaleReleaseNotes/2020_1/NS_ERP_Bundle_custom_lists_verify_18_2.png) ![Bundle records to verify](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/NSPOS/NetSuitePointSaleReleaseNotes/2020_1/NS_ERP_Bundle_custom_records_verify_18_2.png)
8.  After you have verified the **Preference** column, click **Update Bundle** to begin the installation.
    
9.  Click **OK** at the prompt.
    
    The **Status** column will display a green check mark when the installation is complete.
    

Warning:

Do not uninstall a bundle until after the replacement is installed. Otherwise, you will lose data and the integration with NetSuite ERP will stop working.

#### Uninstall the NSPOS 2018.2.X bundle: {#procedure_0621031137}

1.  Log in to NetSuite as an administrator.
    
2.  Go to Customization > SuiteBundler > Search & Install Bundles > List.
    
3.  Locate **Bundle ID** 27525 or 399097 in the list.
    
4.  Click the **Name** by the **Bundle ID**.
    
5.  Click **Uninstall**.
    
6.  Click **OK**.
    

## If you are using NSPOS 2019.1.X (Bundle 294243) {#subsect_85102236705}

Follow these steps to update your bundle 294243 from NSPOS 2019.1.X to 2020.1.X.

#### Update bundle 294243 to NSPOS 2020.1.X: {#procedure_60140001377}

1.  Log in to NetSuite as an administrator.
    
2.  Go to _Customization > SuiteBundler > Search & Install Bundles > List_.
    
3.  Locate Bundle ID **294243** in the list.
    
    If not found, tap **New** and search for `294243` using the **Keywords** field.
    
4.  A blue icon under the version number indicates that a new version is available. Using your mouse, point to the blue icon to display more information.
    
    If you do not see the blue icon, your installed bundle is already up to date and no further action is required.
    
5.  Using your mouse, point to the green icon and click **Update**. Allow time for the page to load
    
    ![Green bundle status](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/NSPOS/NetSuitePointSaleReleaseNotes/2020_1/NSPOS_Bundle_update_green_icon_text.png)
6.  Review the updates to be installed.
    
7.  NetSuite alerts you in red font if conflicts exist between your previous installation and the current installation.
    
    If any of these conflicts appear, select **Replace existing object**. If you are unsure, contact NetSuite Customer Support.
    
    ![Upgrade conflicts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/NSPOS/NetSuitePointSaleReleaseNotes/2020_1/NSPOS_18_2_19_1_upgrade_conflicts.png) ![Upgrade conflicts subset view](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/NSPOS/NetSuitePointSaleReleaseNotes/2020_1/NSPOS_18_2_19_1_upgrade_conflicts_SUBSET.png)
8.  Review the **Custom Lists/Records** section to ensure the **Preference** column matches these images.
    
    If not, select **Replace Data** or **Preserve Data** as shown.
    
    ![Bundle lists to verify](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/NSPOS/NetSuitePointSaleReleaseNotes/2020_1/NS_ERP_Bundle_custom_lists_verify_19_1.png) ![Bundle records to verify](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/NSPOS/NetSuitePointSaleReleaseNotes/2020_1/NS_ERP_Bundle_custom_records_verify_19_1.png)
9.  Click **Update Bundle**.
    
10.  Click **OK** at the prompt.
     
     The **Status** column will display a green check mark when the installation is complete.
