To simplify the NSPOS Kiosk installation, we have introduced a new **Configure Windows to run in Kiosk Mode** option during the staging process. When enabled, this feature will automatically set up the NSPOS Kiosk to run in Windows Kiosk Mode if the device's Windows version supports it.

This option is disabled by default, giving users full control over their setup preferences.

If you restage the Kiosk, your previously chosen option is automatically enabled.
