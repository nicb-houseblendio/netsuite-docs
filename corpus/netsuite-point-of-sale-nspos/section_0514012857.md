Configuration of NSPOS promotions is now accessible through the Promotions sub-menu in the NSPOS menu. It is available as a tab in NetSuite ERP.

The sub-menu allows the configuration of:

-   **Promotions** - Configure promotion parameters.
    
-   **Promotion Items** - Add, remove, or update the items used within promotions.
    
-   **Coupons** - Configure coupons for promotions.
    
-   **Promotion Customers** - Add, remove, or update customers eligible for promotion
    
-   **Stacking Rules** - Group promotions and set rules and limits for their parallel usage. For more information, see [Use Stacking Rules for Promotion Interactions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1497967237.html).
    

For more information about promotions, see [Promotions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1497908536.html).
