NetSuite Point of Sale (NSPOS) includes a variety of reports. Each report appears in a separate window where you can preview results and refine your criteria before saving or printing.

In the report viewer tool bar, tap **Export** to save report results in a Microsoft Word, Excel, or PowerPoint format. PDF and Data Feed formats are also available. Tap **Print** to send the report to your printer.

The following are core reports supported in NSPOS as standard functionality. Most reports have alternates you can run online in NetSuite.

## Select Reports from a List {#bridgehead_1533048628}

If you don't have an NSPOS report assigned to a button, you can select from the list of all NSPOS reports.

#### To run a report from the report list:

1.  Sign in to any NSPOS register.
    
2.  From the main button bar, tap **Reports**.
    
    If you don't see the **Reports** button, press **Ctrl+F12** and enter `Reports`.
    
    Tip:
    
    If you don't see the report you want, tap **Reports** on the side button bar (sub-menu) for a list of other reports.
    
3.  Find and tap desired report.
    

## Custom Reports {#bridgehead_1533048613}

You can set up saved searches in NetSuite ERP to create custom reports. See [Custom Reports using Saved Searches](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1533048850.html).
