## Operating Systems and Components {#bridgehead_1496859822}

For a list of supported operating systems and industry-compliance information about the NetSuite Point of Sale (NSPOS) application, see [Appendix: PCI SSF Information for NSPOS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_4142502876.html).

### Regional Settings for Windows {#subsect_66152752719}

The NSPOS application uses the Window's Regional format settings found on each register to format decimal numbers. To ensure NSPOS compatibility, Windows must use a period to separate decimal places.

The **Region** setting **\[English (United States)\]** uses a period for decimals.

## Hardware - Standalone and POS Client Workstations {#subsect_1530126130}

The following specifications apply to **Standalone** or **POSClient** registers in your stores. These workstations provide normal register functions for sales and other transactions.

-   Processor speed: 2.2 GHz (2.8 GHz recommended)
    
-   Processor type: Intel Dual-Core / Core i3 (or AMD equivalent) or above
    
-   Operating system: Windows 10 64 bit, required to address RAM above 4 GB
    
-   RAM: At least 4 GB (6-8 GB recommended)
    
-   Hard disk drive (HDD) or solid state drive (SSD): 30 GB free space or above
    

Note:

Configurations that only meet the minimum requirements might experience slower processing times during periods of high-volume traffic.

## Hardware - Server with POS Workstations {#subsect_1530126636}

These specifications apply to **Server with POS** workstations.

In addition to providing functions for sales and other register transactions, these workstations act as the database server for POSClient registers. See [Store Server Architecture](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1494359246.html) for more information.

The following are for a Server with POS register connected with **five** POSClient registers. Setups not meeting the minimum requirements might experience performance issues.

### Minimum Specifications {#bridgehead_1530130266}

-   Processor speed: 3.2 GHz (2 cores 4 threads)
    
-   Processor type: Intel Dual-Core / Core i3 (or AMD equivalent) or above
    
-   Operating system: Windows 10 64 bit
    
-   RAM: At least 6 GB (8 GB recommended)
    
-   Solid state drive (SSD): 30 GB free space or above
    

### Optimal Specifications {#bridgehead_1530130621}

-   Processor speed: 3.2 GHz (4 cores 4 threads)
    
-   Processor type: Intel Dual-Core / Core i5 (or AMD equivalent) or above
    
-   Operating system: Windows 10 64 bit
    
-   RAM: At least 8 GB (16 GB recommended)
    
-   Solid state drive (SSD): 30 GB free space or above
    

## Transport Layer Security (TLS) {#subsect_162732112528}

Most payment gateways set up for NSPOS PIN pad payments use TLS to communicate between the pad and gateway. NetSuite supports TLS 1.2 or later for communication protocols. Ensure that your payment provider doesn't use TLS 1.1 or earlier in your setup.

You can update a workstation's registry to stop obsoleve versions of TLS from running. See [Transport Layer Security (TLS) Versions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1535385076.html#subsect_1535637026) in the NSPOS Security Guide.

## Supported OPOS Peripheral Types {#subsect_1530134413}

NSPOS supports the following OLE for Retail Point of Sale (OPOS) compatible devices. You should confirm support for specific device models with your hardware provider.

-   POS Printers
    
-   Bar Code Scanners
    
-   PIN Pads
    
-   Signature Capture Devices
    
-   Magnetic Stripe Readers (MSRs)
    
-   Line Displays
    
-   Cash Drawers
