In conjunction with the [Location and Working Hours Restrictions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_164822375473.html) added in NSPOS 2020.1.X, we made behind-the-scenes changes to how passwords are managed. Changes include:

-   Employee passwords for NSPOS are valid only on registers within their assigned locations
    
-   If an employee record is inactivated, that employee's NSPOS password will no longer function at the locations to which the employee was assigned
    

See [Employees and NSPOS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4539107183.html) to work with passwords, working hours, and more.

Note:

By default, employees set up prior to upgrading to NSPOS 2020.1.X can log on at location.

Tip:

If an employee is inactivated in NS ERP by mistake or if an employee returns to active work after their record was inactivated, the best practice is to set them up as a new employee. See [Setting up a New Employee](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158802309801.html).
