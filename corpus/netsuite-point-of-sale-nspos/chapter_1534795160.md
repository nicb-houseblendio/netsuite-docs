## Operating Systems {#subsect_1534859964}

NetSuite Point of Sale (NSPOS) supports running our application on several Windows-based operating systems. See [Appendix: PCI SSF Information for NSPOS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_4142502876.html) for more information.

## Required Third-party Applications {#subsect_1534797274}

NSPOS uses applications that must be installed on each workstation prior to staging. If you have questions about a third-party installation, contact the support department associated with that company and application. NetSuite Customer Support is also available to provide guidance.

See [Prerequisites for NSPOS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1495565126.html) for the list of applications required for NSPOS.

## Optional Third-party Payment Gateway Applications {#subsect_1534860372}

Payment gateways are third-party applications selected by retail businesses to handle credit or debit card authorizations. Some payment gateway providers require that the retailer install a third-party application on each NSPOS register that uses their service.

Information about security protocols utilized by these providers and their applications can be found on each gateway provider's website. For a list of providers supported by NSPOS, see [Payment Gateways](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1508162264.html) in the NetSuite Point of Sale Administrator Guide.

## Register Types {#subsect_1534797284}

We use the following terms to describe the NSPOS register types available to retailers:

-   Standalone
    
-   Server with POS
    
-   POSClient
    
-   Kiosk
    

For more information about register types, review the section in this document on [Store Server Architecture](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1535385076.html#subsect_1535384382) or see [Set up a Register](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4737180054.html) in the NetSuite Point of Sale Administrator Guide.
