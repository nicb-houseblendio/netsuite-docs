Applies to NSPOS 2024.1 and later.

NetSuite Point of Sale (NSPOS) is fully compatible with the NetSuite ERP Payment Instruments feature.

Payment Instruments makes setting up payment methods more straightforward than configuring each method separately. Payment Instruments also provides benefits that can make accepting physical payment cards more secure than default methods. For more information about the feature, see [Payment Instruments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1538492538.html).

Enabling (or not enabling) Payment Instruments doesn't impact your NSPOS payment processes.

## No Action Required for Most Accounts {#bridgehead_67144454047}

Most accounts don't need to enable and disable Payment Instruments. By default, newer accounts are set up with Payment Instruments enabled.

However, if you want to use certain FreedomPay options and also have Payment Instruments enabled, you should complete the following steps.

-   [Payment Instruments and FreedomPay Swipe-less Returns](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0404105606.html#subsect_0408035229)
    
-   [Payment Instruments and FreedomPay Tokens](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0404105606.html#subsect_0410040135)
    

See [FreedomPay](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1492114692.html) to return to the FreedomPay configuration topics.

Note:

NetSuite ERP automatically enables Payment Instruments in new accounts.

## Payment Instruments and FreedomPay Swipe-less Returns {#subsect_88144511167}

If you want to use FreedomPay swipe-less returns **and** the Payment Instruments feature, you should review and update your NSPOS payments settings. Swipe-less returns are where money is refunded to the original payment card without the need to swipe or insert the card using a PIN pad.

The swipe-less refund workflow is available if you are using the FreedomPay payment gateway for both NetSuite ERP and NSPOS transactions. For example, you can set up swipe-less refunds when your FreedomPay setup allows for:

-   Transactions paid in NetSuite ERP to be refunded at an NSPOS workstation
    
-   Transactions paid at an NSPOS workstation to be refunded in NetSuite ERP
    

Important:

If you are using FreedomPay swipe-less returns now and have **not** enabled Payment Instruments, you should not make any changes. It is not necessary that you enable the feature.

In these steps you will:

1.  Enable **Payment Instruments**.
    
2.  Verify that your FreedomPay setup allows "returns of NetSuite ERP transactions using Transaction ID (swipe-less) returns".
    
3.  Change the NSPOS integration payment method **Type** to **Pay By Reference**.
    
    For information about this payment method type, see [Creating a Payment Method](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1292421.html).
    
    Note:
    
    **Upsync limitation for Type:** Pay By Reference
    
    This payment method type limits the corrective actions available from NSPOS during the upsync process . For example, when NSPOS detects during upsync that an invoice or payment for a split-payment transaction is missing, NSPOS will attempt to re-upsync and, if needed, overwrite all records previously loaded for the transaction.
    
    If a payment with type "Pay By Reference" was upsynced previously, NSPOS cannot overwrite that payment record through another upsync. Automatic correction will not occur, the transaction will appear in the , and manual intervention will be needed.
    

#### To configure NSPOS for Payment Instruments with FreedomPay Swipe-less Returns:

1.  Go to Setup > Company > (Setup Tasks) Enable Features.
    
2.  Open the **Transactions** subtab.
    
3.  Scroll to the **Payment Processing** section.
    
4.  If not already selected, check the **Payment Instruments** box to enable the feature.
    
    ![Enable box for payment instruments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/NSPOS/NetSuitePointofSaleAdminGuide/NS_ERP_PInstruments_enable.png)
5.  Click **Save**.
    
6.  Go to NSPOS > Payments > FreedomPay.
    
7.  If not already done, check the box to **Allow returns of NetSuite ERP transactions using Transaction ID (swipe-less) returns**.
    
8.  Click **Save** if you made a change.
    
9.  Go to Setup > Accounting > (Setup Tasks) Accounting Lists.
    
10.  For each payment method used for NSPOS integration and FreedomPay card payments:
     
     1.  Click **Edit**.
         
     2.  Change the **Type** to **Pay By Reference**.
         
     3.  Click **Save**.
         
     
     Note:
     
     Don't update any payment method not used for NSPOS integration or FreedomPay card payments. For example, do not update payment methods for cash or gift cards.
     

### Payment Instruments with Multiple Subsidiaries {#subsect_0806033847}

If you use more than one subsidiary, you should create a **Payment Processing** profile for each subsidiary and associate the profiles with your NSPOS payment method.

Otherwise, if a payment happens at a subsidiary location that has no payment processing profile associated with the payment method used for upsync, the PNREF number won't populate correctly in NetSuite ERP.

## Payment Instruments and FreedomPay Tokens {#subsect_31144518763}

The NSPOS integration with Payments Instruments provides compatibility for its use with FreedomPay Tokens. After you have it configured, you can issue a token through NSPOS and it'll automatically upsync to ERP. Tokens are saved on the customer record Financial tab in the Payment Instruments section.

After a token from NSPOS is upsynced to NetSuite ERP, it can be used as payment for ERP purchases.

Tip:

If you want to use FreedomPay Tokens without Payment Instruments, you don't need to change anything. See [FreedomPay](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1492114692.html) in the NSPOS administrator guide for the standard setup steps.

In these steps you will:

1.  Enable Payment Instruments
    
2.  Verify that your FreedomPay setup **Token Family** is **FreedomPay**
    
3.  Ensure the FreedomPay Token payment method **Type** and **Associated Payment Processing Profile** are configured correctly
    

#### To configure NSPOS for Payment Instruments with FreedomPay Tokens:

1.  Go to Setup > Company > (Setup Tasks) Enable Features.
    
2.  Open the **Transactions** subtab.
    
3.  Scroll to the **Payment Processing** section.
    
4.  If not already selected, check the **Payment Instruments** box to enable the feature.
    
    ![Enable box for payment instruments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/NSPOS/NetSuitePointofSaleAdminGuide/NS_ERP_PInstruments_enable.png)
5.  Click **Save**.
    
6.  Go to NSPOS > Payments > FreedomPay.
    
7.  Verify that **FreedomPay** is selected for **Token Family**.
    
8.  Click **Save** if you had to adjust the Token Family. Otherwise, click **Cancel**.
    
9.  Go to Setup > Accounting > (Setup Tasks) Accounting Lists.
    
10.  Click **Edit** for **FreedomPay Token.**
     
11.  Ensure the **Type** is **Payment Card Token**.
     
12.  Ensure the **Associated Payment Processing Profile** is **FreedomPayPPP**.
     
13.  Click **Save** if you had to adjust the Type or Profile. Otherwise, click **Cancel**.
