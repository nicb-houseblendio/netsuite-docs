Starting with NSPOS 2025.1.0, we will stop support for the Worldpay (Vantiv) \[Mercury Payment Systems (MPS)\] payment gateway.

## Recommended Actions {#subsect_0528030337}

Review the **Payment Provider** choice on each register's RA-Workstation record. NetSuite shows the Worldpay (Vantiv/MPS) payment integration as **Mercury Payment Systems**.

If the register is set to use Mercury Payment Systems, you must reconfigure the register to use a different gateway before NSPOS 2025.1 is deployed to your NetSuite account.

#### To view a register's payment gateway setup

1.  Log in to NetSuite as an administrator.
    
2.  Go to Customization > Lists, Records, & Fields > Record Types.
    
3.  Find the **RA-Workstation** row and click **List**.
    
4.  Clcik **View** for the first register to review.
    
5.  Review the register's **Payment Provider** choice. This list is near the top of the record form.
    
    -   If the register is set for **Mercury Payment Systems (OBSOLETE)**, reconfigure the register to use a different provider. See [Payment Gateways](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1508162264.html) for more information. Otherwise, no changes to the register's payment gateway are needed.
        
6.  Continue with the next register's RA-Workstation record.
    

Important:

If you keep the **obsolete** Mercury Payment Systems configuration on your RA-Workstation record and upgrade to the 2025.1.0 NSPOS release, this payment provider will be removed automatically and you will have to configure a new payment provider before the next restage.

If you have any concerns or need more information, please contact NetSuite Customer Support or Worldpay.
