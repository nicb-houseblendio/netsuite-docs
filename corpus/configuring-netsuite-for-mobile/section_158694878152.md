You can add the Mobile Device Access permission to individual users.

Note:

For security, you shouldn't give the Mobile Device Access permission directly to a user. Instead, add it to their role See [Using the Global Permissions Feature](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N326630.html).

#### To add Mobile Device Access permission to a user: {#procedure_1553609051}

1.  Go to _Setup > User / Roles > Manage Users_.
    
2.  Click the relevant username.
    
3.  Click **Edit**.
    
4.  On the **Access** tab, click the **Global Permissions** subtab.
    
5.  In a new row, from the Permissions list, select **Mobile Device Access**.
    
6.  Click **Add**, and then **Save**.
    

Note:

Only Administrators can add the Mobile Access Device permission to a user.
