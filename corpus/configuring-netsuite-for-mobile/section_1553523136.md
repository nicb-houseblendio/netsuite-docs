The following section covers topics related to mobile data security, the use of security questions, and IP address rules for the app.

## Mobile Data Security {#subsect_1553611681}

NetSuite for Mobile stores a limited amount of data on your device, like Time and Expense logs. The app always encrypts your data with industry-standard encryption.

You can use the Remember Me option to save your username and password. If you want to log in with TouchID or Fingerprint, you need to enable the Remember Me option. When you do, the app stores and encrypts your username and password on your device. See [Saving your Login Details in NetSuite for Mobile](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1554101927.html).

## Mobile Security Questions {#subsect_1553613628}

The first time you use the app, you need to answer one of the three security questions you set up on your desktop and enter your password. You also need to do this if you use a different device or reset or reinstall the app.

## IP Address Rules for the App {#subsect_1553695187}

Any IP address filtering you set up in your browser also applies to the app. Don't enable this for roles that need unrestricted mobile access, like sales roles. See [Enabling and Creating IP Address Rules](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4726612641.html).
