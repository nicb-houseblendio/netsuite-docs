The number of entries in a list of options determines which type of selector NetSuite displays: popup selector or roll selector. You can configure this from a browser by setting the Maximum Entries in Dropdowns preference.

#### To set the Maximum Entries in Dropdown preference: {#procedure_1553849630}

1.  Log in to NetSuite from a browser session, and then go to _Home > Set Preferences_.
    
2.  In the **General** subtab, under Optimizing NetSuite, enter a value in the **Maximum Entries in Dropdowns** field.
    
    If the list has more items than this value, you'll see a popup list. Otherwise, you'll get a roll selector.
