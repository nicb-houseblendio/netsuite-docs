Administrators can manage who gets mobile access to NetSuite by enabling the Mobile Device Access permission for each role. This lets your administrators control mobile access for each role separately.

By default, NetSuite enables Mobile Device Access permission for all standard roles including Employee and Advanced Partner Center roles with the following exceptions.

Roles requiring you to enable Mobile Device Access permission in a browser session before using the app:

-   **Custom**
    
-   **System Administrator**
    

Roles that do not support Mobile Device Access permission:

-   **Administrator**
    
-   **Customer Center**
    
-   **Partner Center**
    
-   **Vendor Center**
    

Note:

If you're an Administrator and need mobile access for the Administrator role, you can do one of the following:

-   Assign yourself to a custom role that has Mobile Device Access enabled.
    
-   Add the Mobile Device Access permission to your employee record. See [Adding Mobile Device Access Permission to Users](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158694878152.html).
    

See the next sections to learn how to add mobile device access permission to roles and individual users.

-   [Adding Mobile Device Access Permission to Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158694870043.html)
    
-   [Adding Mobile Device Access Permission to Users](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158694878152.html)
