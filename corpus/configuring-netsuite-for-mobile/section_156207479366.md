Note:

The Tab bar is a feature specific to the iPhone version of the NetSuite app.

You can set up the Tab Bar to show four options from Home, Calendar, Saved Searches, or any supported record type.

For information about how to configure your dashboard, see [Dashboards in NetSuite for iOS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158686457118.html).

#### To configure the Navigation Tab Bar: {#procedure_3775071458}

1.  In the Tab bar, tap **More**.
    
2.  Tap **Reorder**.
    
3.  To move a record type up or down in the list, touch and hold the grab icon ![Screenshot of the NetSuite for iOS Grab icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteMobile/iOS_grab_icon.png).
    
    The first four items, under the Tab Bar section, display in the Tab bar.
    
4.  To confirm the order of your items, tap **Done**.
    

Note:

When selecting record types for the Tab Bar, think about your user roles and what each role can access. If you select a record type that isn't available for a role, it won't show up when that role is active. Instead, the next available item in the list will appear in the Tab bar.
