Note:

This topic is for NetSuite accounts that use the Country Tax Report page to generate the Netherlands EC Sales List. If you're using the EU Sales List Report page, see [EU Sales List for Netherlands](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1947306.html).

The EC Sales List (ESL) is a report of your company's supplied goods and services to another EU Member State. Generating this report requires the SuiteTax feature, the Netherlands Localization SuiteApp, and the Tax Reporting Framework SuiteApp. For more information, see [Generating Netherlands Tax Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1021101424.html).

The generated report can only be in the Nederlands or English language, depending on the language set in your user preferences. If your user preferences isn't set in either English or Nederlands, then the report will be generated in Nederlands. The report is in XBRL format and can be exported to PDF and XLS.

If you're using the Full Multi-Book Accounting feature, you can generate the ESL for each accounting book. Reporting custom transactions and transactions for triangular trade isn't supported.

The Netherlands EC Sales List contains the following information:

-   **Company Name** - The company name indicated on the Company Information page.
    
-   **VAT Registration Number** - The Tax Registration Number associated with the Netherlands Nexus indicated on the Company Information page for non-OneWorld accounts, or Subsidiary page for OneWorld accounts.
    
-   **Reporting Period**
