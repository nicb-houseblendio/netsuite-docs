The Netherlands Intrastat report can be generated for monthly tax periods only. If you have multiple months to generate, you must generate the report one month at a time.

#### To generate the Netherlands Intrastat report:

1.  Go to Reports > VAT/GST > EU Intrastat Report.
    
2.  Select your Netherlands subsidiary.
    
3.  In the **Report Type** dropdown list, you can select between **Sale** (for Dispatches) or **Purchase** (for Arrivals).
    
4.  In the **Country Form** dropdown list, you can select between **Netherlands (Dutch)** for the Dutch version or **Netherlands (English)** for the English version of the form.
    
5.  Select the month from the **Tax Period** (from) and **To** fields.
    
6.  In the **Accounting Book** field, select which accounting book will be used to generate the report. This field is available if the Multi-Book Accounting feature is enabled. The dropdown list shows all active books associated with the selected subsidiary. For more information, see [Multi-Book Accounting for International Tax Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4108426899.html).
    
7.  To display the report, click **Refresh**. Each time you change the reporting criteria, click **Refresh**.
    
    Important:
    
    For the saved reports in the International Tax Reporting SuiteApp, results are limited to 25,000 rows. A truncated report will display this note at the bottom of the page: 'The results of this report are too large. Please narrow your results.' If you want to request for an increase in the limit, you must file a Support case.
    
8.  Review the report displayed. Be sure to review all pages of the report. To specify the number of rows displayed on each page, go to Home > Set Preferences > **General** subtab.
    
    Note:
    
    Lines with the **Exclude** box checked aren't included in the report. Clear the **Exclude** box if you want to include the transaction in your report.
    
9.  To save an English or Dutch version of the report, click any of the following options:
    
    -   **Print** - to generate a PDF version of the report that you can print or save for your own records.
        
    -   **Export to Excel** - to save the Intrastat report as a Microsoft Excel (.xls) file.
        
    
    When you save a Netherlands Intrastat Report, NetSuite saves it as a PDF in the File Cabinet. You can specify the Output Folder for Intrastat Reports on the Tax Filing Setup page. The default name for this folder is Netherlands Intrastat and is stored in the root folder of the File Cabinet. Go to Documents > Files > File Cabinet and click the Intrastat folder to download and view the report.
    
    To export the Netherlands Intrastat report in a format acceptable for upload to the tax agency website, see [Exporting the Netherlands Intrastat Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_165283919785.html).
