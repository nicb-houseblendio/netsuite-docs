The <periods> element contains information about the accounting periods associated with the subsidiary for which you generated the XAF file.

| Tag Name | Source Information |
| --- | --- |
| periodNumber | Includes all the accounting periods within the Start Date and End Date that you selected on the Country Tax Report page. Adjustment period is also included. The monthly accounting periods are numbered starting from 01. For example, a 12-month period is represented by numbers 01 to 12, and the adjustment period is 13. |
| startDatePeriod | Entry in the **Start Date** (startdate) field on the base period record. |
| endDatePeriod | Entry in the **End Date** (enddate) field on the base period record. |
