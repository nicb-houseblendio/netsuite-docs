Important:

The SuiteApp's features for WKR reporting are only compatible with NetSuite OneWorld accounts.

The Work-Related Costs (WKR) Report, provided by the Netherlands Localization SuiteApp, contains a monthly overview of your total fiscal salary in a given Fiscal Year.

In each month, you can see your WKR budget, how much you've spent from that budget, and how much you've exceeded the baseline. The report also shows the exemptions to the taxable fiscal salary under Nontaxable Categories.

Note:

The WKR report can only be displayed with EUR as the base currency. The report can source its values from transactions in other currencies, but you can only view the report while your subsidiary's currency is EUR.

WKR reporting for an accounting book that uses a currency other than EUR isn't supported. You can only report the work-related costs in an accounting book that uses EUR as currency.

#### To view the WKR report:

1.  Go to Reports > Netherlands Reports > Work-Related Costs Report.
    
2.  Verify if the Netherlands subsidiary name under which you want to generate the report is the name that appears in the Subsidiary field. Select a subsidiary as necessary.
    
3.  If you have the Full Multi-Book Accounting feature enabled in your NetSuite account, in the Accounting Book field, select the book whose WKR transactions you want to report.
    
4.  In the Fiscal Year field, select the year you want to view the reported items and expenses under WKR.
    
5.  To drill down on a category to a transaction detail:
    
    1.  Click a specific amount.
        
        The **WKR Report: Details** page opens where you can see an overview of the transactions, which had been assigned the category.
        
    2.  Click the Document ID of a transaction to view its details.
        

Note:

The number of lines in the drill down list is determined by the preferences you had set in the **Number of Rows in List Segments** field on the **Set Preferences** page. For more information, see [WKR Report Formatting and Optimization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164458112171.html).

The WKR report is displayed according to the fiscal calendar of the subsidiary you selected on the Subsidiary field. You can switch to a different calendar. For more information, see [Displaying the WKR Report in a Specific Fiscal Calendar](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0619015859.html).

## Exporting the Work-Related Costs Report {#subsect_164458223247}

You can export the Work-Related Costs (WKR) report to PDF and CSV. On the **Work-Related Costs Report** page, click **Export to…**, and select your desired format.
