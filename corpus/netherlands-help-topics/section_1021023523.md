The <vatCodes> element contains information about the tax codes associated with the subsidiary for which you generated the XAF file.

| Tag Name | Source Information |
| --- | --- |
| vatID | If you're using SuiteTax, the data is sourced from the **Name** (name) field on the tax code record. You can view a tax code record at Setup > Tax > Tax Codes. If you aren't using SuiteTax, the data is sourced from the **Tax Name** (itemid) field on the tax record. You can view a tax code record at Setup > Accounting > Taxes > Tax Codes. |
| vatDesc | Entry in the **Description** (description) field on the tax code record. |
