You may be unable to access the **Work-Related Costs Report** and the **Work-Related Costs Configuration** pages despite having the sufficient permissions level (as set up on the Permissions subtab of the Work-Related Costs Configuration page). This may be caused by classification restrictions that are set up on the File Cabinet.

## Editing Access Restrictions from the File Cabinet {#subsect_81134826074}

Contact your account administrator or, if you have access to the File Cabinet, check the set restrictions on the Netherlands Localization SuiteApp folder on the File Cabinet, and edit as necessary.

#### To edit the restrictions on the WKR pages from the File Cabinet: {#procedure_0907012904}

1.  Go to Documents > Files > File Cabinet.
    
2.  Click the **SuiteApps** folder.
    
3.  Click **Edit** next to the **com.netsuite.nedlocalization** folder.
    
4.  See the restrictions set in the **Restrict By Class**, **Restrict By Subsidiary**, and **Restrict By Group** folders. Edit as necessary.
    
5.  Click **Save**.
