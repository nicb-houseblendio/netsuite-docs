The Intrastat Report gets the following information from the **Tax Reporting** subtab and **Items** sublist of transaction forms and item records:

-   Partner ID
    
-   Country of Origin
    
-   Nature of Transaction Code
    
-   Mode of Transport
    
-   Delivery Terms
    
-   Commodity Code
    
-   Supplementary Unit
    

You must fill in these fields to generate a fulfilled Intrastat Dispatches and Arrivals reports.

## Netherlands Intrastat Report Fields on Transaction Forms {#subsect_165283585983}

The **Tax Reporting** subtab on transaction forms only appears if you're transacting with an EU vendor or EU customer.

This subtab contains the following fields which are used for Intrastat reporting:

-   **Partner ID** - This refers to the VAT number of the party receiving the goods in the EU member state of destination. For more information, see [Partner ID](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164377982356.html).
    
-   **Country of Origin** - This refers to the country where the goods were harvested, manufactured, or substantially changed. For more information, see [Country of Origin](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164377962805.html).
    
-   **Nature of Transaction Code** - This refers to the type of transaction in the Intrastat declaration. For more information, see [Nature of Transaction Code](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2070738.html).
    
-   **Mode of Transport** - This refers to the active vehicle that moves goods for every arrival or dispatch transaction. For more information, see [Mode of Transport](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1505110665.html).
    
-   **Delivery Terms** - This refers to the international commercial terms (Incoterms) defined by the International Chamber of Commerce (ICC). For more information, see [Delivery Terms](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2071234.html).
    

For more information about EU Intrastat Report Fields on transaction forms, see [Intrastat Reporting Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4150707116.html).

## Netherlands Intrastat Report Fields on Item Records {#subsect_165283592541}

The **Tax Reporting** subtab on item records contains the following fields:

-   **Commodity Code** - This refers to the 8-10 digit number that identifies the type of goods or commodity on the item record. For more information, see [Commodity Code](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2070438.html).
    
-   **Supplementary Unit** - This refers to the unit used in measuring the quantity of goods or commodity on the item record. For more information, see [Supplementary Unit](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4605983594.html).
    

For more information about EU Intrastat Report Fields on item records, see [Intrastat Reporting Fields on Item Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4150707116.html#bridgehead_4150717128).
