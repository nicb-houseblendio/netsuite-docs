To install the Netherlands Localization SuiteApp, you must first install the EMEA Localization SuiteApp. For more information, see [Installing the EMEA Localization SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157201390489.html).

To use the electronic bank payment templates in Netherlands Localization, you must install the Electronic Bank Payments SuiteApp. For more information, see [Installing the Electronic Bank Payments SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N1586721.html).

To use the tax-related features of the Netherlands Localization SuiteApp, you must have the SuiteTax feature enabled in your NetSuite account. Then, install the following:

| SuiteApp | Installation |
| --- | --- |
| SuiteTax Engine | See [Installing the SuiteTax Engine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557397007.html). |
| Tax Reporting Framework | See [Installing Tax Reporting Framework](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1528245293.html#bridgehead_1528246665). |

Note:

The Electronic Bank Payments SuiteApp and the SuiteTax-related SuiteApps aren't required in the installation of the Netherlands Localization SuiteApp. You can install Netherlands Localization without these SuiteApps. However, without the Electronic Bank Payments SuiteApp, you can't use the provided electronic bank payment templates. Similarly, you can't use the provided tax report templates without the Tax Reporting Framework SuiteApp.
