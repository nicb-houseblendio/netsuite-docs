The Netherlands Localization SuiteApp provides SuiteTax-based report templates required in the Netherlands. Before generating the reports, you must first set up your account for tax reporting. For more information, see [SuiteTax-Based Reports Setup for Netherlands Localization](#subsect_159912157281).

Using the Country Tax Reports page provided by the Tax Reporting Framework SuiteApp, you can generate the following Netherlands SuiteTax-based reports:

-   [Netherlands Periodic VAT Return OB69](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156775966230.html)
    
-   [Netherlands Intrastat](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159913315292.html)
    
-   [Netherlands EC Sales List](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159913612875.html)
    

To generate a tax report, see [Generating Netherlands Tax Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1021101424.html).

For other tasks that you can do with the Netherlands tax reports on the Country Tax Reports page, see the following topics:

-   [Viewing a Generated Country Tax Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_1528251207.html)
    
-   [Making Adjustments on a Country Tax Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_156647155234.html)
    
-   [Exporting a Country Tax Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_156645000208.html)
    

## SuiteTax-Based Reports Setup for Netherlands Localization {#subsect_159912157281}

To use the tax-related features of the Netherlands Localization SuiteApp, you should also do the following:

-   Set up an accounting period. For more information, see [Setting Up Accounting Periods for a Year](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1446183.html).
    
-   Enable the SuiteTax Plug-In. For more information, see [Enabling the SuiteTax Plug-In](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557399475.html).
    
-   Assign a tax registration to a Netherlands subsidiary. For more information, see [Assigning Tax Registrations to a Subsidiary in SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4296038273.html).
    
-   Set up Netherlands tax reporting preferences. For more information, see [Setting Up Country Tax Reporting Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_1557127083.html).
    
-   Set up the filters for the Periodic VAT Return OB69. The VAT return provided by this SuiteApp has default filters, but you can customize these filters. For more information, see [Customizing Localized Tax Returns](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1528248236.html).
    

Important:

Enhancements or issue fixes on the Periodic VAT Return OB69 are provided through a SuiteApp version upgrade. Any enhancement or fix on the VAT report template will only apply if the **Use Custom Template** option (which appears when you customize any filters) on the **Setup Tax Return** page is disabled. If enabled, the customizations done on the report before the upgrade will remain, and the fix and new filters can't be used. You must disable the custom template option. After the upgrade, you can customize the VAT Report, and use the new provided filters.
