The Netherlands Localization SuiteApp provides the XML Auditfile Financieel (XAF), the tax audit file required in the Netherlands.

The XAF report can be generated with or without the SuiteTax feature. The Tax Reporting Framework SuiteApp must be installed in your NetSuite account to generate the XAF report. For more information, see [Installing Tax Reporting Framework](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1528245293.html).

For information about XAF reporting, see:

-   [Generating Netherlands Tax Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1021101424.html)
    
-   [Netherlands XAF Data Source](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1021101109.html)
    

## Supported Features {#subsect_30100711767}

XAF reporting in the Netherlands Localization SuiteApp supports the Full Multi-Book Accounting feature. You can generate the XAF report for a specific accounting book of a given subsidiary.

Important:

If you're using the Full Multi-Book Accounting feature, be sure to enable the Foreign Currency Management feature as well, to prevent any potential issues.

Period end journals aren't supported. You can't include period end journal entries in the XAF report.
