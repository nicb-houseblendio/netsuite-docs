The Calculation Terms subtab on the WKR Configuration page records the percentages used to derive the WKR budget and the tax rate that's levied on the excess of the budget.

Important:

These percentages aren't arbitrary. You must verify the values with the WKR legislation in the Netherlands. You can refer to [Allowances, benefits in kind and provisions](https://www.belastingdienst.nl/wps/wcm/connect/bldcontenten/belastingdienst/business/payroll_taxes/you_are_not_established_in_the_netherlands_are_you_required_to_withhold_payroll_taxes/when_you_are_going_to_withhold_payroll_taxes/calculating_payroll_taxes/reimbursements_and_provisions).

## Notes for Adding Calculation Terms {#subsect_164456713124}

When you add calculation terms, note the following:

-   If the **Applicable To** column is empty, the set of terms will be applied until a new set of terms has been added.
    
-   You can't add calculation terms that are effective retrospectively.
    
-   The effective period of any row of calculation terms shouldn't be in conflict with another set of terms. You aren't allowed to save the new set of terms if the period you set overlaps another.
    
-   Newly added set of terms aren't effective immediately. They're applied the next day.
