The European Union Electronic Invoicing SuiteApp allows the E-filling feature for Netherlands. E-filling feature enables the user to do the electronic invoicing in Netherlands.

## Validation of the Certificate {#bridgehead_0325125651}

Before you start the whole process, you must check the valid certificate exists.

#### To validate the certificate

1.  Go to Setup > Company > Certificates.
    
2.  Locate the NL Digipoort certificate.
    
3.  Optional: If you cannot locate the certificate, create a new one. See [To create a new certificate](#procedure_ps5_ndg_s3c).
    
4.  Click on the certificate.
    
5.  Go to the **Audience** subtab and select the respective Subsidiary from the checklist.
    
6.  Click **Update**.
    

#### To create a new certificate {#procedure_ps5_ndg_s3c}

1.  Go to Setup > Company > Certificates.
    
2.  Click **Create New**.
    
3.  Enter the name of your certificate.
    
4.  Click **Save**.
    

## Configuring the e-filling report {#bridgehead_0325010003}

To configure the e-filling report, you need to obtain the Digipoort URL first.

#### To obtain the Digipoort URL {#procedure_gz5_zng_s3c}

1.  Go to https://aansluiten.procesinfrastructuur.nl/site/gegevensstandaarden.
    
2.  At the bottom of the page, click the Berichtsoortentabel link to download an xml file.
    
3.  Open the xml file.
    
4.  Go to the Berichtsoorten verlopen sheet and copy the respective URL from the Entrypoint column.
    
5.  Go back to NetSuite page.
    

#### To configure E-filling

Note:

If the Save button is disabled before you click on it, make sure required information is complete and the configuration has been changed and is valid.

1.  Go to Reports > Tax > Country Tax Reports.
    
2.  Select the Netherlands subsidiary, make sure the Nexus is Netherlands, the report name says: Report Name Periodic VAT return - \`\`OB 69.
    
3.  Select the Start Date and End Date.
    
4.  Click E-filling Configuration.
    
5.  On the E-filling Configuration page, select the respective certificate.
    
6.  Enter the URL Digipoort (for more information, see [To obtain the Digipoort URL](#procedure_gz5_zng_s3c))
    
7.  Click **Save**. The Save button is now disabled and you can close the E-Filling Configuration window.
    

## Submitting the report {#bridgehead_0325011045}

When the e-filling is configured, the report can be generated and submitted.

#### To submit the report

1.  Go to Reports > Tax > Country Tax Reports.
    
2.  Click **Generate**. Wait for the process to finish.
    
3.  Click **View** next to the generated report.
    
4.  Check the report is successfully generated.
    
5.  Click **Submit to Belastingdienst**.
