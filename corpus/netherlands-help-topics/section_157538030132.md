The Netherlands Localization SuiteApp is available in the SuiteApps Marketplace.

#### To install the Netherlands Localization SuiteApp

1.  Go to SuiteApps.
    
2.  In the Search field, enter **Netherlands Localization**.
    
3.  Click the Netherlands Localization image.
    
4.  Click **Install**.
    

Note:

The Netherlands Localization SuiteApp is automatically updated whenever enhancements or new features are added. Previous versions (1.03.0 and earlier) are no longer supported and aren't automatically upgraded. To install the latest version from the SuiteApps Marketplace, uninstall version 1.03.0 or earlier (Bundle ID: 307509) from SuiteBundler. For more information, see [Uninstalling a Bundle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3400972.html). You won't lose your custom SuiteTax-based reports setup when you uninstall the Netherlands Localization SuiteApp from SuiteBundler.
