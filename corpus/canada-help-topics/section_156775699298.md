This topic is for NetSuite accounts that use the Country Tax Report page to generate the GST34 Worksheet. If you are using the Tax Reports (International) page, see [GST34 Worksheet - Canada](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1862347.html).

It also shows the Search Type, Transaction Types, Tax Codes, Tax Transaction Types, Tax Item Types, and Tax Reporting Category filters. The Canada Sales Tax Reports SuiteApp uses the filters to get the values for each of the boxes on the report. These filters are automatically set up but can be modified.

To enter amounts on boxes 104, 107, and 111, see [Making Adjustments on a Country Tax Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_156647155234.html).

The value reported on box 110 is from the data of the selected account upon Canada tax return setup. To select an account, see [Customizing Localized Tax Returns](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1528248236.html).

To view the General Ledger, click the **View General Ledger** button.

To view the Canada GST report in detail, see [Viewing a Generated Country Tax Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_1528251207.html).

To learn more about the Canada Sales Tax Reports SuiteApp providing the Canada GST34 Worksheet report, see [Canada Sales Tax Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1011110652.html).
