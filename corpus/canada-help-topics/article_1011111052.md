Before installing Canada Sales Tax Reports, you must enable some additional features and install relevant SuiteApps.

## Required Features {#subsect_68111245664}

Go to _Setup > Company > Setup Tasks > Enable Features_.

-   On the Tax subtab, under Tax & Compliance, enable SuiteTax.
    
-   On the SuiteCloud subtab, enable the following features:
    
    -   Item Options
        
    -   Custom Records
        
    -   Advanced PDF/HTML Templates
        
    -   Server SuiteScript
        

## Required SuiteApps {#subsect_20111301432}

After you enable the required features, install the following SuiteApps:

-   SuiteTax Engine
    
-   Localization Assistant
    
-   Tax Reporting Framework
    

For more information about these SuiteApps, see [Localization Assistant SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_163092114640.html), [SuiteTax Engine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1557396965.html), and [Tax Reporting Framework](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1528262949.html).

After you have completed the prerequisites, you can install the Canada Sales Tax Reports SuiteApp. For information about how to install the Canada Sales Tax Reports SuiteApp, see [Installing the Canada Sales Tax Reports SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1011111614.html).
