For more information, see [Setting Up the SuiteTax Engine for Canada](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159499696946.html).

To take advantage of all the features in the SuiteTax Engine, please configure the following:

-   To create nexuses and subnexuses, see [Canada Parent Nexus and Subnexuses](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160630107433.html).
    
-   To find out more about periodic tax return, see [Canada Periodic GST/HST Return (GST 34)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160630131884.html).
    
-   To learn about data provisioning enhancements, see [Canada Data Provisioning Enhancements](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160630138231.html).
    
-   To find out more about Canada Sales Tax Reports, see [Canada Sales Tax Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1011110652.html).
