Setting up an account for an organization doing business in Canada usually requires enabling several features and installing some additional SuiteApps.

## Enabling Features {#bridgehead_160257508094}

Some features available in your NetSuite account can be very important or even essential for users in Canada. If they are inactive, you should consider enabling them. Follow the instructions below to enable most common features beneficial for users in Canada. However, if you want to get access to some specific product area, go to the [Functional Areas](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4198261632.html#bridgehead_160257527028) help topic and check the exact requirements.

If you don't have sufficient permissions to enable features, please contact your account administrator.

#### To enable most common features:

1.  Go to _Setup > Company > Setup Tasks > Enable Features (Administrator)_.
    
2.  On the **Company** subtab, go to the **International** subtab, and check the **Multi-language** and **Multiple Currencies** boxes.
    
3.  (Optional) On the **Accounting** subtab, go to the Basic features section and check the **GL Audit Numbering** box.
    
4.  (Optional) On the **Accounting** subtab, go to the Advanced features section and check the **Period End Journal Entries** and **Foreign Currency Variance Mapping** boxes.
    
5.  On the **SuiteCloud** subtab, enable the features under the following sections:
    
    -   SuiteBuilder
        
    -   SuiteScript
        
    -   SuiteGL
        
    -   SuiteFlow
        
    
    For more information about SuiteCloud features, see [SuiteCloud Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N239332.html).
    
6.  If your company is registered for the EU OSS VAT scheme, on the **Tax** subtab check the **EU One Stop Shop** box.
    
7.  Click **Save**.
    

## Available SuiteApps {#bridgehead_160257584281}

Some additional features will only become active if you install a specific SuiteApp to your NetSuite account. SuiteApps are applications that extend NetSuite for specific industry and business needs. If you would like to get access to some specific product area, go to the [Functional Areas](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4198261632.html#bridgehead_160257527028) help topic and check which SuiteApps are required to be installed. Canada-specific features are currently available in the following SuiteApps:

| Feature | Area | Description |
| --- | --- | --- |
| [Canada Sales Tax Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1011110652.html) | Accounting | Provides support for the GST34 Worksheet report. |
| [Country-Specific Address Forms](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_158497967043.html) | Provides address forms formatted for Canada and other countries. |
| [Electronic Bank Payments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N1585433.html) | Payments | Provides Canadian payment formats to enable businesses to pay vendor bills and employee expenses, and receive payments from customers within Canada. |

To learn more about SuiteApps installation, see [Installing a Bundle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3395142.html).

For more information about SuiteApps, see [SuiteApps](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_3134602194.html).
