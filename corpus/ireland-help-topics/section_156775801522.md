Note:

This topic is for NetSuite accounts that use the Country Tax Report page to generate the Ireland VAT report. If you're using the Tax Reports (International) page, see [What goes into each box - Ireland VAT 3 report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1929852.html).

With Tax Reporting Framework, you can generate the Ireland VAT3 report. To generate a report, see [Generating Localized Country Tax Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1528250223.html).

Ireland VAT3 report supports Multi-book Accounting. For more information, see [Multi-Book Accounting](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/book_3831565332.html).

Ireland VAT3 report supports OSS (One Stop Shop) transactions. For more information, see [One Stop Shop](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_162918935998.html).

The following tables describe the reported values on the Ireland VAT report. It also shows the Search Type, Transaction Types, Tax Codes, Tax Transaction Types, and Tax Item Types filters that Tax Reporting Framework uses to get the values for each of the boxes on the report. These filters are automatically set up but can be modified. If you want to customize the report and configure the filters, see [Customizing Localized Tax Returns](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1528248236.html).

To view the Ireland VAT report in detail, see [Viewing a Generated Country Tax Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_1528251207.html).

To export the report in XML, XLS, or PDF formats, see [Exporting a Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N736119.html).

The XML file is suitable for manual online submission to Ireland's tax authority.

Note:

You can test if the XML file is in correct format for submission [here](https://softwaretestnextversion.ros.ie/VAT3Upload/testfile?l=1).

For more information about the reporting features of Tax Reporting Framework, see [Tax Reporting Framework](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1528262949.html).
