If you're using Tax Reporting Framework, you can generate the following Ireland-specific tax reports.

-   [Ireland VAT Report: Periodic VAT Return - VAT3](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156775801522.html)
    
-   [Ireland VAT Report: Return of Trading Details](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156775806262.html)
    
-   [Ireland Intrastat](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159056915948.html)
    
    For more information about the codes required in the Intrastat declaration, see [Intrastat Supplementary Declaration](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_156889008497.html).
    
-   [EC Sales List](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_156888850442.html) - it can be exported in PDF or XLS formats.
