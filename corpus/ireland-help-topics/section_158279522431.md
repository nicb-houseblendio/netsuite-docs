Before you install the Ireland Localization SuiteApp, your account administrator must enable several features and preferences in your NetSuite account.

## SuiteApps {#bridgehead_158857755432}

To use additional Ireland Localization features, you must install the following SuiteApps:

-   **EMEA Localization SuiteApp** - This is a required SuiteApp. You must install the EMEA Localization SuiteApp before you install the Ireland Localization SuiteApp. This SuiteApp provides the framework for local VAT reports in SuiteTax and other EMEA-specific features. For more information, see [Installing the EMEA Localization SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157201390489.html).
    
-   **SuiteTax Engine** - This is an optional SuiteApp. However, you must install it if you want to use the Tax Reporting Framework. It helps your business meet the tax determination and reporting requirements. For more information, see [Installing the SuiteTax Engine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557397007.html).
    
-   **Tax Reporting Framework** - This is an optional SuiteApp. However, you must install it if you want to use the Tax Reporting Framework. It provides the permissions, setup options, and tax reporting features to country tax reports. For more information, see [Installing Tax Reporting Framework](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1528245293.html).
    
-   **Electronic Bank Payments** - This is an optional SuiteApp. However, you must install it if you want to generate payment files for your bank. Charges may apply if you need to produce files for multiple countries. This SuiteApp lets you process bank payments of your vendor bills, employee expenses, partner and employee commissions, and customer refunds. It also lets you produce direct debit files. For more information, see [Electronic Bank Payments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N1585433.html).
    

For more information about installing SuiteApps, see [Installing a Bundle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3395142.html).

## Enabling Features for Ireland Localization {#bridgehead_158858360699}

Before you install the Ireland Localization SuiteApp, you must enable the required features.

Note:

Some of the required features have already been enabled if you've installed the EMEA Localization SuiteApp.

#### To enable required features:

1.  Go to _Setup > Company > Setup Tasks > Enable Features_.
    
2.  On the **Tax** subtab, check the **SuiteTax** box.
    
3.  On the **SuiteCloud** subtab, check the following boxes:
    
    -   Custom Records
        
    -   Advanced PDF/HTML Templates
        
    -   Client SuiteScript
        
    -   Server SuiteScript
        
4.  Click **Save**.
    

## Setting Up Accounts for Ireland Localization {#bridgehead_158858385934}

If you want to use the Tax Reporting Framework from the Ireland Localization SuiteApp, make sure your NetSuite account is set up correctly. Take a look at the following:

-   You must set accounting periods for an Irish subsidiary. For more information, see [Setting Up Accounting Periods for a Year](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1446183.html).
    
-   You must enable the SuiteTax Plug-In. Enabling the SuiteTax Plug-In lets you select SuiteTax as your tax engine. For more information, see [Enabling the SuiteTax Plug-In](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557399475.html).
    
-   You must assign a tax registration to a subsidiary. To add a tax registration for a subsidiary, see [Assigning Tax Registrations to a Subsidiary in SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4296038273.html).
