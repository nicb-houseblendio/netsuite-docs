If you have an Ireland nexus, and you have the International Tax Reports SuiteApp installed in your NetSuite account, you can generate a localized EU Sales List (ESL) report for Ireland. To generate an ESL report, go to Reports > VAT/GST > EU Sales List Report.

The form displays the following information:

-   **Country Indicator** - Country code prefix of the customer's VAT registration number
    
-   **Customer VAT Registration No.** - Customer's VAT number without the country prefix
    
-   **Customer** - Click the customer name to view the customer record
    
-   **Total Value of Supplies of Goods/Services (Exports) Rounded to the Nearest Euro** - Displayed in the appropriate format for Ireland
    
-   **Flag** - Editable field that specifies if the transaction is for goods, services, or triangulation. The Flag column is the indicator. For goods, this column is empty. For triangulation, use T, and for services, use S.
    
-   **Exclude** - Check this box for lines that you want to exclude from your report
    

Verify and correct the data as necessary. Any inconsistencies that NetSuite finds in your data, based on your selected reporting criteria, are indicated by color codes on the ESL report. By default, the system checks the Exclude box for those transactions with data inconsistencies, except for VAT number errors.

You can save the file in PDF, Microsoft Excel (.xls), or XML format. Lines with the Exclude box checked aren't included in the exported file. NetSuite saves a copy of the file in the File Cabinet, and sends you an email containing a URL of the file location.

For more information about using the EU Sales List reporting feature, read the following topics:

-   [EU Sales List Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2068226.html)
    
-   [Generating an EU Sales List Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2068441.html)
    

**EU Sales List Online Filing**

You can export the Ireland EU Sales List report from NetSuite to an XML file that you can submit for online filing. The XML file generated by NetSuite complies with the specifications of the tax authority in Ireland.

To generate the EU Sales List report, see [Generating an EU Sales List Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2068441.html). When the EU Sales List report for Ireland is displayed, click Export to XML.

Before generating a report to be used for online filing, be sure to complete the EU Sales Filing setup page. For more information, see [Setting Up Tax Filing for Ireland](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1929131.html).

You should review all the values in the report prior to submission.
