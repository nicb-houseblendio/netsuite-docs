Ireland users can activate and get access to different features from the following functional areas:

-   [Accounting](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_157961123615.html)
    
-   [Taxation Features for Accounts Without SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_160372663874.html)
    
-   [Taxation Features for Accounts with SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_160372794542.html)
    
-   [Payments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_160372865356.html)
    
-   [Bank Reconciliation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_160372869361.html)
    

To learn more about SuiteApps installation, see [Installing a Bundle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3395142.html).

To learn more about enabling NetSuite features, see [Enabling Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N232138.html).

Important:

If you don't have sufficient permissions to install SuiteApps or enable features, please contact your account administrator.
