Ireland Localization SuiteApp version 2.0.0 and above is available on the SuiteApp Marketplace. If you have Ireland Localization SuiteApp 1.02 or earlier installed, you'll need to uninstall it before you can use version 2.0 and higher. For more information about uninstalling SuiteApps, see [Uninstalling a Bundle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3400972.html).

#### To install the Ireland Localization SuiteApp: {#procedure_158280823194}

1.  Go to Customization > SuiteCloud Development > SuiteApp Marketplace.
    
2.  In the Search field, enter **Ireland Localization**.
    
3.  Click the Ireland Localization image.
    
4.  Click **Install**.
    

Ireland Localization SuiteApp version 2.0.0 and above gets updated automatically whenever there are enhancements or new features. Older versions (1.02 and earlier) aren't supported anymore and don't get automatic updates.
