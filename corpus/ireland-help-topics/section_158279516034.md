Ireland Localization SuiteApp works with SuiteTax to generate tax reports required in Ireland. To use these tax reports, you must install the SuiteTax SuiteApps.

Ireland Localization SuiteApp also delivers several Ireland-specific payment templates that were originally part of the Electronic Bank Payments SuiteApp. To use these templates, you must install the Electronic Bank Payments SuiteApp.

## Tax Reporting Framework {#subsect_159004676168}

This SuiteApp works with the Tax Reporting Framework SuiteApp to provide Ireland tax report templates which you can choose from the country-specific templates at Reports > Tax > Country Tax Reports. To use the Ireland Localization features, you need to install EMEA Localization. For more information, see [EMEA Localization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_157122959910.html).

The following tax reports are supported by the Ireland Localization SuiteApp:

-   [Ireland VAT Report: Return of Trading Details](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156775806262.html)
    
-   [Ireland VAT Report: Periodic VAT Return - VAT3](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156775801522.html)
    
-   [Intrastat Supplementary Declaration](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_156889008497.html) (Arrivals/Dispatches) - You can export this report either as a PDF or XLS file. For information about the codes required for the Intrastat declaration, see [Ireland Nature of Transaction Code](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_157164704998.html)
    
-   [EC Sales List](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_156888850442.html) - You can export this report either as a PDF or XLS file.
    

To generate tax reports, read these topics:

-   [Setting Up Country Tax Reporting Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_1557127083.html)
    
-   [Generating Localized Country Tax Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1528250223.html)
    

For more information, see [Ireland Tax Reporting Framework](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158279537998.html).

For more information about other tasks available in the Ireland tax templates on the Country Tax Reports page, see these topics:

-   [Viewing a Generated Country Tax Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_1528251207.html)
    
-   [Making Adjustments on a Country Tax Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_156647155234.html)
    
-   [Exporting a Country Tax Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_156645000208.html)
    

## Electronic Bank Payments Formats {#subsect_159004712240}

The Ireland Localization SuiteApp delivers several payment formats used by the Electronic Bank Payment SuiteApp. This SuiteApp provides payment file formats. Before you can use a file format, you need to set it up with the relevant bank details and other information that the system requires.

If you've previously installed the Electronic Bank Payments SuiteApp, which provided Irish payment templates, installing the Ireland Localization SuiteApp updates those templates, so that they're compliant with Irish standards.

For more information about the payment file formats provided by the Electronic Bank Payments SuiteApp, see [Payment File Formats](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1675118.html).
