Task Service Report Component Adds a button to view mode of Completed Tasks to preview the Service Report pdf and email to the customer.

## Members {#subsect_7151610577}

## delay {#bridgehead_75151630703}

| Type | Description |
| --- | --- |
| Number | Delay in milliseconds before confirming with the user to send the email. |

Default

            `{   "delay": 1000 }` 
          

## hidden {#bridgehead_36151647798}

| Type | Description |
| --- | --- |
| Boolean | This view is to be shown or hidden |

Default

            `{   "hidden": false }` 
          

## label {#bridgehead_35151659982}

| Type | Description |
| --- | --- |
| String | Button label |

Default

            `{   "label": "Service Report" }` 
          

## name {#bridgehead_7151712064}

| Type | Description |
| --- | --- |
| String | Button name |

Default

            `{   "name": "custpage_nx_servicereport" }` 
          

## send {#bridgehead_70151723827}

| Type | Description |
| --- | --- |
| String | Confirm text before sending the email. Clear this value to only preview the pdf. |

Default

            `{   "send": "Are you sure you want to send this Service Report?" }` 
          

## success {#bridgehead_35151750523}

| Type | Description |
| --- | --- |
| String | Alert text when the email is successfully sent. |

Default

            `{   "success": "Service Report successfully queued to be sent." }`
