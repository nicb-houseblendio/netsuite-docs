Utility to convert hash of objects to sorted array of objects with id

## Parameters {#subsect_47152743078}

| Parameter | Type | Attributes | Description |
| --- | --- | --- | --- |
| data | Object | Required | Hash of objects to convert. |
| data.\*.index | Number | Optional | Zero based index for the item in the collection. |

## returns {#bridgehead_65152927249}

| Type | Description |
| --- | --- |
| Array.<Object> | Ordered collection of objects |
