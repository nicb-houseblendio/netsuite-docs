Project Profitability Report Component Adds a button to view mode of Customer to view the Profitability Report.

## Members {#subsect_6145621920}

## hidden {#bridgehead_56145650442}

| Type | Description |
| --- | --- |
| Boolean | This view is to be shown or hidden |

Default

            `{   "hidden": false }` 
          

## label {#bridgehead_48145658789}

| Type | Description |
| --- | --- |
| String | Button label |

Default

            `{   "label": "Profitability Report" }` 
          

## name {#bridgehead_20145730761}

| Type | Description |
| --- | --- |
| String | Button name |

Default

            `{   "name": "custpage_nx_profitability" }` 
          

## report {#bridgehead_21145803993}

| Type | Description |
| --- | --- |
| Number | Asset Profitability report internal id |

Default

            `{   "report": 306 }`
