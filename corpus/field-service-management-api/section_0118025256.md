Project Journal Component Adds a button to view mode of Projects with unrecoverd Time to create a Labour Recovery Journal.

## Members {#subsect_65145309315}

## hidden {#bridgehead_61145344249}

| Type | Description |
| --- | --- |
| Boolean | This view is to be shown or hidden |

Default

            `{   "hidden": false }` 
          

## label {#bridgehead_44145356157}

| Type | Description |
| --- | --- |
| String | Button label |

Default

            `{   "label": "Create Time Journal" }` 
          

## name {#bridgehead_76145416182}

| Type | Description |
| --- | --- |
| String | Button name |

Default

            `{   "name": "custpage_nx_journal" }`

| Type | Description |
| --- | --- |

Default

            `{   "success": "Journal successfully created." }`
