Utility to finds the matching rules in a rule set

## Parameters {#subsect_16182124362}

| Parameter | Type | Attributes | Description |
| --- | --- | --- | --- |
| rules | Array.<Object> | Required | Rules to test against |
| ignore | Array | Required | Rule attributes to ignore |
| attributes | Object | Required | Attributes to match on |

## Returns {#bridgehead_3182258028}

| Type | Description |
| --- | --- |
| Object | The matching rule |
| Null | If no matching rule found |
