Employee Mobile Login Button Component Adds a button to view mode of Mobile Employees to email them a link to the Mobile app.

## Members {#subsect_48142802920}

## confirm {#bridgehead_83142810053}

| Type | Description |
| --- | --- |
| String | Confirm text before creating the invoice. |

Default

            `{   "confirm": "Are you sure you want to send this email?" }` 
          

## hidden {#bridgehead_92142852277}

| Type | Description |
| --- | --- |
| Boolean | This view is to be shown or hidden |

Default

            `{   "hidden": false }` 
          

## label {#bridgehead_23142933398}

| Type | Description |
| --- | --- |
| String | Button label |

Default

            `{   "label": "Email Mobile Login" }` 
          

## name {#bridgehead_59143024400}

| Type | Description |
| --- | --- |
| String | Button name |

Default

            `{   "name": "custpage_nx_mobilelogin" }` 
          

## success {#bridgehead_10143104289}

| Type | Description |
| --- | --- |
| String | Alert text when the email is successfully sent. |

Default

            `{   "success": "Email successfully queued to be sent." }`
