Case Invoice Component Adds a button to view mode of Cases with unbilled time, expenses, or sales to create an Invoice.

## Members {#subsect_63135506967}

## confirm {#bridgehead_50135516607}

| Type | Description |
| --- | --- |
| String | Confirm text before creating the invoice. |

Default

            `{   "confirm": "Are you sure you want to generate the Invoice?" }` 
          

## hidden {#bridgehead_14135613115}

| Type | Description |
| --- | --- |
| Boolean | This view is to be shown or hidden |

Default

            `{   "hidden": false }` 
          

## label {#bridgehead_37135654249}

| Type | Description |
| --- | --- |
| String | Button label |

Default

            `{   "label": "Generate Invoice" }` 
          

## name {#bridgehead_87135741611}

| Type | Description |
| --- | --- |
| String | Button name |

Default

            `{   "name": "custpage_nx_invoice" }` 
          

## success {#bridgehead_29135821857}

| Type | Description |
| --- | --- |
| String | Alert text when the invoice is successfully created. |

Default

            `{   "success": "Invoice successfully created." }`
