Case Service Report Component Adds a button to view mode of Closed Cases to preview the Service Report pdf and email to the customer.

## Members {#subsect_93140741685}

## delay {#bridgehead_66140750473}

| Type | Description |
| --- | --- |
| Number | Delay in milliseconds before confirming with the user to send the email. |

Default

            `{   "delay": 1000 }` 
          

## hidden {#bridgehead_6140847562}

| Type | Description |
| --- | --- |
| Boolean | This view is to be shown or hidden |

Default

            `{   "hidden": false }` 
          

## label {#bridgehead_29140934604}

| Type | Description |
| --- | --- |
| String | Button label |

Default

            `{   "name": "custpage_nx_servicereport" }` 
          

## send {#bridgehead_71141110316}

| Type | Description |
| --- | --- |
| String | Confirm text before sending the email. Clear this value to only preview the pdf. |

Default

            `{   "send": "Are you sure you want to send this Service Report?" }` 
          

## success {#bridgehead_24141154866}

| Type | Description |
| --- | --- |
| String | Alert text when the email is successfully sent. |

Default

            `{   "success": "Service Report successfully queued to be sent." }`
