Reports created using the Country-Specific Reports SuiteApp are based on HTML/XML report templates. These tables contain cells that you need to fill with NetSuite data. There are two different data types that you can add to your reports:

-   **Variables** - A variable is the basic element of every report created by the Country-Specific Reports SuiteApp. For each of them, you must define a cell of your template in which they will be displayed. You can use your variables as text only, inserting them into your report as labels or captions. However, your variables can be much more advanced: you can use them in formulas. Values from various accounts are either added or subtracted and the final count of every such formula is then displayed in a certain cell of a report. More complex actions are also permitted. For example, you can set variables to include only specific accounts or define conditions (if you want your variables to be used under specific circumstances).
    
    To learn more about variables in the Country-Specific Reports SuiteApp, see [Variables in Country-Specific Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1540549203.html).
    
-   **Filters** - Filters let you arrange the data in your reports in different ways. Certain filters are automatically added to every report created by the Country-Specific Reports SuiteApp. Some are optional and must be added manually. The following filters are currently available: Accounting Book, Subsidiary Context, Period From / To, Period To, and List of Accounts.
    
    To learn more about filters in the Country-Specific Reports SuiteApp, see [Filters in Country-Specific Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1540549220.html).
    

#### To add variables or filters to a country-specific report: {#procedure_1111025424}

1.  Go to Reports > Financial > Country-Specific Reports.
    
2.  From the Report list, select a report.
    
3.  Click the Open icon.
    
4.  On the report record, click **Edit**.
    
5.  Add a variable to the report:
    
    1.  Go to the Variables subtab.
        
    2.  Click **New CSR - Variable**.
        
    3.  Fill-in the fields for the new variable record.
        
        For more information, see [Variables in Country-Specific Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1540549203.html).
        
6.  Add a filter to the report:
    
    1.  Go to the Filters subtab.
        
    2.  From the CSR - Filter Block Type list, select any of the following optional filters:
        
        -   List of Accounts
            
        -   Period From / To
            
        -   Period To
            
        
        For information about these optional filters, see [Filters in Country-Specific Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1540549220.html).
        
    3.  Click **Add** for each filter you have selected.
        
    4.  Click **Save**.
        

Note:

Other types of variables (system and filter) are added directly to your HTML/XML report template. It means that you don't have to create separate records for them. To learn more about the system variables, see [System variables](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1541420619.html#subsect_1542187887). To learn more about the filter variables, see [Filter variables](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1541420619.html#subsect_157052256640).

Important:

Reports delivered by NetSuite Localization SuiteApps are **locked**. You cannot edit the reports, add any variables and filters to them, or to delete them. This is because these reports are tailored to suit the reporting requirements of a specific country. You can create copies of these locked reports and edit them as necessary. For more information about making a copy of the report, see [Copying reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1556614212.html).

The only element of locked reports that you are allowed to edit is the Accounting Context (because its content depends on the accounting contexts currently available in your NetSuite account). To learn more about accounting contexts in NetSuite, see [Accounting Contexts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4640155582.html).
