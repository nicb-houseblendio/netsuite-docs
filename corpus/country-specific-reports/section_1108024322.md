Important:

The Counry-Specific Reports SuiteApp will no longer receive feature enhancements. Support will still be provided to issues but no new features will be added.

To create your custom report with the Country-Specific Reports SuiteApp, you need to do the following actions:

-   Build an HTML/XML template for your report. For more information, see [Creating a Template for the Country-Specific Reports SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1556609508.html).
    
-   Create a record of your report.
    

#### To create a record of your report: {#procedure_1108025210}

1.  Go to Reports > Financial > Country-Specific Reports.
    
2.  Click the New icon next to the Report field.
    
3.  On the CSR - Report page, enter a name for your report in the Name field.
    
    The name you enter here is the name that will be displayed in the Report list on the Country-Specific Reports page.
    
4.  In the Template File field, click the double arrow and click **List**.
    
5.  Select the HTML/XML template that you built for this report.
    
6.  _(Optional)_ Fill-in the following fields:
    
    -   **2nd Column Definition** - If you want your report to display transactional data from the previous year in a second column, select **Minus One Year**.
        
    -   **Net Amount Calculation Method** - Select the method for calculating the net amount type of variables.
        
        **Debit minus Credit** and **Credit minus Debit** use simple substraction. **System calculation** means the report will use the values returned by the NetSuite system search.
        
        Note:
        
        If you leave this field blank, the default net calculation method will be used. The default method is System calculation. If you want to change the default method, go to _Setup > Company > Preferences > General Preferences_. On the **Custom Preferences** subtab, go to the Country-Specific Reports subtab. Edit the entry in the **Net Amount** field as necessary.
        
    -   **Report Type**\- Edit the default entry if you are creating a balance sheet or income statement. Balance sheet and income statement have drill-down features specific to the type of the report.
        
        Note:
        
        The Contra Account Sheets SuiteApp and other Localization SuiteApps provide features that process certain country-specific report types.
        
        Custom reports that were created before the drill-down feature was implemented are automatically marked as Other Report.
        
    -   **Accounting Context**\- Select an entry if you want a specific accounting context to be applied to your report. For more information, see [Accounting Contexts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4640155582.html).
        
7.  Click **Save**.
    

When you are done with this procedure, you can start adding variables and filters to your report. For more information, see [Adding and Editing Report Elements](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1540549110.html).

## Country-Specific Reports Link {#subsect_37102942857}

A unique link is assigned to every report you create. You can find this link on your report record at _Customization > List, Records, & Fields > Record Types_. To view a report record, click **List** in the CSR - Report record type, then click **View** next to the report you want to see.

You cannot edit the provided report link. NetSuite users with the Creating Center Links permission can use this report link to create a center link. For more information, see [Creating Center Links](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2891250.html).

If you want to share this link, click **Copy this link to clipboard**. When you share the link, add the following text in the beginning of the copied report link: `https://system.netsuite.com`.
