For special cases (like the balance sheet report), there is a possibility to split the report into two columns. The rows containing totals for both columns are automatically aligned.

To use the two-columns layout, assign the **.csr-columns-2** class to the div.csr-content. This section must contain two columns: <div> elements using the **.csr-column** class.

          `<table>     <!-- ... --> </table>   <div>     <!-- Column 1 -->     <div>           <table>             <!-- ... -->          </table>       </div>     <!-- END Column 1 -->       <!-- Column 2 -->     <div>           <table>             <!-- ... -->         </table>       </div>     <!-- END Column 2 --> </div>` 
        

![An example of how a table created using the Country-Specific Reports SuiteApp looks like with a two-columns layout. This means that the whole report is split into two separate columns.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteApps/csr-sample-5.png)
