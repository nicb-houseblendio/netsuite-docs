You can provide access to the records delivered by the Country-Specific Reports SuiteApp to both new roles and to customized standard NetSuite roles.

To create a new role, go to Setup > Users/Roles > User Management > Manage Roles > New Role.

To customize an already existing role, go to Setup > Users/Roles > User Management > Manage Roles to open the Manage Roles page. Then click the corresponding **Customize** link to create a custom version of a certain standard role.

For more information, see [Customizing or Creating NetSuite Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N285937.html).

Afterwards, proceed with the following:

1.  On the **Permissions** subtab, gradually go to the **Lists**, **Setup**, and **Custom Record** subtabs.
    
2.  To add a permission, click the blank line at the bottom of a list, select a permission (like CSR - Report or CSR - Variable), and click **Add**.
    
3.  To set the level of access for a permission, click a line in a list and select one of the options from the Level column (None, View, Create, Edit, or Full). To learn more about the permission levels in NetSuite, see [Access Levels for Permissions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N326341.html).
    
4.  Click **Save**.
    

In the following table, you can see the permission categories, types, and levels required by the primary users of the Country-Specific Reports SuiteApp. The primary users are people who can create and edit financial records, like NetSuite developers or professional services consultants. If necessary, you can assign higher permission levels than those listed in the Minimum Permission Level column.

| Category | Name | Minimum Permission Level |
| --- | --- | --- |
| Lists | Documents and Files | Full |
| Setup | SuiteScript | View |
| Setup | Custom Lists | View |
| Setup | Custom Record Types | View |
| Custom Record | CSR - Country | View |
| Custom Record | CSR - Export | Edit |
| Custom Record | CSR - Filter Block | Full |
| Custom Record | CSR - Report | Full |
| Custom Record | CSR - Report Copy Task | Create |
| Custom Record | CSR - Report Data Log | View |
| Custom Record | CSR - Settings | View |
| Custom Record | CSR - Variable | Full |
| Custom Record | CSR - Variable Filter | Full |
| Custom Record | CSR - Variable Value | Edit |

Note:

Secondary users (like accountants) are only expected to view financial reports. There is usually no need for them to see the custom records delivered by the Country-Specific Reports SuiteApp. Therefore, giving them access to the Country-Specific Reports dashboard (as described above) should be sufficient.

Important:

When using the drill-down feature, you are accessing the dashboard that already belongs to a different SuiteApp: the Contra Account Sheets. This SuiteApp uses a different set of permissions; see [Access to Contra Account Sheet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159843168875.html) to learn more. For more information about the drill-down feature itself, see [Viewing Country-Specific Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1540548990.html).
