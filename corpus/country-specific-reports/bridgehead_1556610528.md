The content of the report should be added to the **.csr-content** section. Usually, this section should contain one table with the **.csr-data** class.

Each cell in the data table should be assigned the right class depending on its type:

-   **.csr-label** - the text describing the value (for example, "A. Fixed Assets")
    
-   **.csr-value** - the computed value
    

          `<div>     <table>         <thead>             <tr>                 <td width="80%">${VAR.header_label.name}</td>                 <td width="20%">${VAR.header_value.name}</td>             </tr>         </thead>         <tbody>             <tr>                 <td>${VAR.some_var_1.name}</td>                 <td>${VAR.some_var_1.value}</td>             </tr>             <tr>                 <td>${VAR.some_var_2.name}</td>                 <td>${VAR.some_var_2.value}</td>             </tr>         </tbody>     </table> </div>`
