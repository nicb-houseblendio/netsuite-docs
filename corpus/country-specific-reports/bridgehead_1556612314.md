Cells with the **.csr-value** class are automatically aligned to the right. Everything else is aligned to the left. To manually override the default alignment, assign the **.csr-align-right** (or left/center) class to the <td> element.

To override the vertical alignment of the cell, use the **.csr-valign-bottom** (or top/middle) class.

          `<table>     <!-- ... --> </table>   <div>     <table>         <thead>             <tr>                 <td width="70%" rowspan="2">${VAR.header_label.name}</td>                 <td width="30%" colspan="2">${VAR.header_value.name}</td>             </tr>             <tr>                 <td width="15%">${VAR.header_value_now.name}</td>                 <td width="15%">${VAR.header_value_previous.name}</td>             </tr>         </thead>         <tbody>             <tr>                 <td>${VAR.some_var_1.name}</td>                 <td>${VAR.some_var_1.value}</td>                 <td>${VAR.some_var_1.value2}</td>             </tr>             <tr>                 <td>${VAR.some_var_2.name}</td>                 <td>${VAR.some_var_2.value}</td>                 <td>${VAR.some_var_2.value2}</td>             </tr>         </tbody>     </table> </div>`
