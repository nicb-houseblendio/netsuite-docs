You can find a list of the variables included in a country-specific report on the report's record. If the report isn't locked, you can add or remove variables from the list. In most cases, the reports that are provided by Localization SuiteApps are locked. You cannot add or remove variables in locked reports.

#### To view a list of variables assigned to a report: {#procedure_161434324248}

1.  Select a report that you would like to view from the **Reports** dropdown list.
    
2.  Click the **Open** button next to the dropdown list.
    
3.  A new CSR-Report page opens.
    
4.  On this page, click the Variables subtab.
    
5.  The CSR-Variable subtab contains a list of variables assigned to this report. If the report isn't locked (which is the case with original NetSuite reports delivered by the Localization SuiteApps), you can also use this list to add or remove variables to this report (or to edit the existing ones).
