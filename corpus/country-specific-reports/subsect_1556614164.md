The easiest way to add new, previously created reports to the Country-Specific Reports SuiteApp, is to use the CSV import. It is necessary to have three separate CSV files prepared for each new report (with variables, filters, and the report itself). To learn more about CSV imports in NetSuite system, see [CSV Imports Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N342646.html).

Note:

The import of a report CSV file must be always performed first. This will let other imports (variables and filters) refer to this newly created report.
