Before installing the Country-Specific Reports SuiteApp, go to Setup > Company > Setup Tasks > Enable features, and make sure that you have the following features enabled in your NetSuite account:

-   In the **Company** tab: Multi-Language
    
-   In the **Accounting** tab: Accounting
    
-   In the **SuiteCloud** tab: Custom Records, Advanced PDF/HTML Templates, Server SuiteScript, Client SuiteScript, SuiteFlow
    

For more information, see the help topic [Enabling Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N232138.html).

Also, go to Setup > Accounting > Preferences > Accounting Preferences. On the **General** subtab, check the **Use Account Numbers** box. For more information, see [Chart of Account Numbering](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1440268.html).

Finally, to open the Country-Specific Reports SuiteApp, the **hidden feature for aggregating financial data** must be active for your account. If this feature is disabled, you'll not be able to access the Country-Specific Reports dashboard (Reports > Financial > Country-Specific Reports). This feature will be activated automatically; its activation usually takes up to 10 minutes to complete. In case of any issues, contact NetSuite Technical Support.

## Contra Account Sheets SuiteApp {#bridgehead_164216185555}

If you want to use the drill-down feature of the Country-Specific Reports SuiteApp, you must install the Contra Account Sheets SuiteApp. With this additional SuiteApp installed, you can click account values in your reports to open the Contra Account Sheets dashboard containing detailed transaction level information for the selected account and period. The drill-down feature helps you to better understand the report data related to a single account.

Note that only drill-down into a single account balance is supported. Also, this feature is only available for reports using the [List of Accounts in Country-Specific Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_159775319391.html) macro.

To learn more about the Contra Account Sheets installation, see [Installing Contra Account Sheet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157830256115.html).

For more information about how to use the drill-down feature, see [Viewing Country-Specific Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1540548990.html).
