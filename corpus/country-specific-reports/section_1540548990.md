Important:

The Counry-Specific Reports SuiteApp will no longer receive feature enhancements. Support will still be provided to issues but no new features will be added.

You can view all reports that are built using the Country-Specific Reports SuiteApp on the Country-Specific Reports page. These reports include the reports that are provided by Localization SuiteApps such as Contra Account Sheet SuiteApp and France Localization SuiteApp.

On the Country-Specific Reports page, you can do the following actions:

-   Display a report.
    
-   View the structure (filters and variables) of the report. You can click on any variable in the report to go to the variable record. There you can edit or delete the variable as necessary.
    
-   Show a list of accounts in a variable.
    
-   Drill-down on an account balance.
    
    Note:
    
    This feature only applies to NetSuite accounts that have the Contra Account Sheet SuiteApp installed. For more information, see [Contra Account Sheet Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_159421062967.html).
    

#### To view a country-specific report: {#procedure_161434325892}

1.  Go to Reports > Financial > Country-Specific Reports.
    
2.  Select a report from the **Reports** list.
    
3.  Click **Show Report**.
    
4.  To see an overview of the variables in a report, and the accounts included in a variable, click **View Structure**.
    
    If you see variables that are highlighted in red, this means that these variables are undefined. You can click on any variable so that you can edit the variable record. For more information about the actions you can do when viewing the report structure, see [Viewing the report structure](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161425435770.html).
    
5.  To view the list of accounts that make up a balance, check the **Show Individual Accounts**.
    
6.  To drill-down on an account balance, click a value from the list of accounts.
    
    Note:
    
    The drill-down feature is only available if you are using the Contra Account Sheet SuiteApp.
    
    When you click on an account balance, the Contra Account Sheets page opens. This page contains detailed transaction-level information for the selected account and period. For more information, see [Contra Account Sheet Dashboard Management](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157830272851.html).
