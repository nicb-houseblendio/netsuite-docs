Important:

The Counry-Specific Reports SuiteApp will no longer receive feature enhancements. Support will still be provided to issues but no new features will be added.

You can export to PDF any report that you created using the Country-Specific Reports SuiteApp. The PDF file will contain the same report structure as it is viewed on the Country-Specific Reports page.

For information about exporting a report to other formats, see [Exporting Country-Specific Reports to Non-PDF Formats](#subsect_91111826872).

#### To export a country-specific report to PDF: {#procedure_0829111048}

1.  Go to Reports > Financial > Country-Specific Reports.
    
2.  From the Report list, select the report that you want to export.
    
3.  Click **Show Report**.
    
4.  Edit the filters as necessary.
    
5.  Click **Show Report** again to refresh the report and display the new values based on the adjusted filters.
    
6.  Click **Export to PDF**.

## Exporting Country-Specific Reports to Non-PDF Formats {#subsect_91111826872}

You can export a report, which you created using the Country-Specific Reports SuiteApp, to a format other than PDF such as CSV or XML. When exporting to non-PDF formats, you need to create your own custom export template.

For more information, see the following topics:

-   [Creating a Custom Template for Exporting Country-Specific Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0829125743.html)
