To include subtotals inside the table, mark the <tr> element with class **.csr-total**.

To include the total for the whole table, use <tfoot> element with class **.csr-totalall**.

Note:

Don't forget to repeat the width of each cell in the <tfoot> element.

          `<table>     <!-- ... --> </table>   <div>     <table>         <thead>             <tr>                 <td width="80%">${VAR.header_label.name}</td>                 <td width="20%">${VAR.header_value.name}</td>             </tr>         </thead>         <tbody>             <tr>                 <td>${VAR.some_var_1.name}</td>                 <td>${VAR.some_var_1.value}</td>             </tr>             <tr>                 <td>${VAR.some_var_2.name}</td>                 <td>${VAR.some_var_2.value}</td>             </tr>             <!-- Subtotal -->             <tr>                 <td>${VAR.subtotal.name}</td>                 <td>${VAR.subtotal.value}</td>             </tr>             <!-- END Subtotal -->             <tr>                 <td>${VAR.some_var_3.name}</td>                 <td>${VAR.some_var_3.value}</td>             </tr>         </tbody>         <!-- Total all -->         <tfoot>             <tr>                 <td width="80%">${VAR.total_all.name}</td>                 <td width="20%">${VAR.total_all.value}</td>             </tr>         </tfoot>          <!-- END Total all -->        </table> </div>`
