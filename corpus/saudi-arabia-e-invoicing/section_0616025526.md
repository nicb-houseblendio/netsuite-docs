The administrator can deploy a script to generate multiple e-documents at a specific time, instead of users generating e-documents for each transaction manually. For more information, see [Deploying the Bulk Generation Script for E-Documents](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4536902188.html).

Important:

Automatic bulk e-document generation using the **Generate E-Document Content MR** script (script ID: customscript\_mr\_einv\_generate\_content) is not fully supported for Saudi Arabia e-invoicing. The script can submit the same invoice to ZATCA multiple times. To reduce this risk, consider generating and certifying Saudi Arabia e-documents manually, one transaction at a time.

Likewise, a script can be used for automatic scheduled sending of outbound e-documents. The script sends only outbound e-documents whose status is "Ready for Sending." For more information, see [Deploying the Script for Bulk Scheduled Sending of E-Documents](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1495611216.html).
