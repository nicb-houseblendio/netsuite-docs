The following are some frequently asked questions about Saudi Arabia E-Invoicing.

### When setting up the Saudi Arabia E-Invoicing Configuration record, the page takes long to move to the next step. Should I wait?

It may take several minutes to go to the next step. If a popup window appears, click **Wait** and wait for the page to load. Do not click **Exit** or reload the page.

### What should I do when the host is not responding or host connection-related errors?

This is most likely related to ZATCA APIs not responding. Please try again later.

### How do I view e-invoicing fields on a customer record, invoice, and credit memo?

Electronic invoicing fields need to be enabled on your custom forms.

For the customer record, the following fields need to be visible:

1.  E-Document Package
    
2.  Template and Sending Method Auto-selection
    

For invoices and credit memos, the following fields need to be visible:

1.  E-Document Template
    
2.  E-Document Sending Method
    
3.  E-Document Status
    
4.  Generated E-Document
    
5.  Certified E-Document
    
6.  QR String (ID: custbody\_psg\_ei\_qr\_string) (Optional for QR code information)
    

### Do I have to only use the VAT number in my authentication certificate?

Use the same VAT registration number in the CSR configuration file and the subsidiary record.

### What can I do if ZATCA is unable to process requests?

Check your CSR configuration file and verify that it matches the required format. Also, check that the CSR and private key were copied properly into the Saudi Arabia E-Invoicing Configuration record. For more information, see [Obtaining a Certificate Signing Request, Private Key, and Compliance Binary Security Token](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0517025020.html).

### Where can I find more information about OTP generation?

For information about OTP generation, see [Fatoora Portal User Manual](https://zatca.gov.sa/en/E-Invoicing/Introduction/Guidelines/Documents/Fatoora_Portal_User_Manual_English.pdf).
