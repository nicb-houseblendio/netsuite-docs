Before installing the Saudi Arabia e-Invoicing SuiteApp, you must complete the following:

-   Register with the [Saudi Arabian Taxation Portal (ERAD)](https://fatoora.zatca.gov.sa/)**.** You must be registered as a taxpayer in Saudi Arabia and must have a valid value-added tax (VAT) registration number.
    
-   Install the Electronic Invoicing SuiteApp. For more information, see [Installing and Setting Up Electronic Invoicing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4592549826.html).
    
    The Electronic Invoicing SuiteApp will be the main component for processing outbound e-documents.
    
-   Install the Localization Assistant SuiteApp. For more information, see [Installing the Localization Assistant SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163092361565.html).
    
-   Install the NetSuite Country-Specific Address Forms SuiteApp. For more information, see [Country-Specific Address Forms](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_158497967043.html).
    
-   Install the NetSuite SuiteApps License Client. For more information, see [NetSuite SuiteApps License Client](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4635371374.html).
    
-   Enable the Accounting and Custom GL Lines feature in your accounts before installing the SuiteApp.
    
    Note:
    
    This SuiteApp is available for accounts with and without SuiteTax enabled.
    
    #### To enable the Accounting feature:
    
    1.  Go to Setup > Company > Enable Features.
        
    2.  On the **Accounting** subtab, check the **Accounting** box.
        
    3.  Click **Save**.
        
    
    #### To enable the Custom GL Lines feature:
    
    1.  Go to Setup > Company > Enable Features.
        
    2.  On the **SuiteCloud** subtab, check the **Custom GL Lines** box.
        
    3.  Click **Save**.
