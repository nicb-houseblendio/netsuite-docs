Before using the Saudi Arabia e-Invoicing SuiteApp, you must complete the following:

-   If your NetSuite account has an active electronic invoicing license, you can use Electronic Invoicing features for multiple countries. If your account does not have an active license, you can still use the Electronic Invoicing SuiteApp for free, but your account can generate and send e-documents to only one country. For more information, see [Defining the E-Document Country for Free Use](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4613215788.html).
    
-   Obtain a Certificate Signing Request (CSR) and private key, which is passed as an input for obtaining a Compliance Binary Security Token, also referred to as Cryptographic Stamp Identifier (CSID). For more information, see [Obtaining a Certificate Signing Request, Private Key, and Compliance Binary Security Token](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0517025020.html).
    
-   Perform a Compliance Check. For more information, see [Performing a Compliance Check](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0517040522.html).
    
-   Obtain a Production Binary Security Token, which ZATCA assigns to compliant EGSs. For more information, see [Obtaining Production Credentials](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0517050303.html).
