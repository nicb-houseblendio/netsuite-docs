You must setup a location record when a seller has same subsidiary across multiple locations.

When a location is selected in a transaction record, the **Saudi Arabia Seller ID**, **Saudi Arabia Seller Scheme ID**, and **Address** field values are retrieved from the location record.

If the Location feature is not enabled, the **Location** field will not be available on transaction record. In this case, the **Saudi Arabia Seller ID**, **Saudi Arabia Seller Scheme ID**, and **Address** field values are retrieved from the subsidiary record.

If the Location feature is enabled, but the selected location record does not contain the **Saudi Arabia Seller ID**, **Seller Scheme ID**, and **Address** field values, the values are retrieved from the subsidiary record.

#### To enable the location feature:

1.  Go to Setup > Company > Enable Features.
    
2.  In the Company subtab, check the **Locations** box.
    
3.  Click **Save**.
    

#### Creating a location record:

1.  Go to Setup > Company > Locations > New.
    
2.  Click **New Locations**.
    
3.  Fill in the following fields with the required information:
    
    -   **Subsidiary** - Select the required subsidiary
        
    -   **Saudi Arabia Seller ID** - Enter the Saudi Arabia seller ID
        
    -   **Saudi Arabia Seller Scheme ID** - Enter the Saudi Arabia seller scheme ID
        
4.  Click **Save**.
