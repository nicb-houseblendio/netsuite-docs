This report provides details on all return authorizations. By default, for each return authorization, the report shows the transaction date, transaction number, customer or project name, order status, and the order total (aggregate amount).

With Narrative Insights, you can use generative AI to summarize the report, helping you identify top customers by return activity and monitor refund and fulfillment trends.

The generated insights may include:

-   Customers with the highest total amount of return authorizations, regardless of status
    
-   The total refunded amount for all return authorizations
    
-   The largest amounts still pending fulfillment
    

To generate an insight on the Return Authorizations Register, the **Enable Narrative Insights** preference must be enabled on the **Narrative Insights** tab of the AI Preferences page. This preference is enabled by default. For more information, see [Managing Narrative Insights Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_6150024470.html).

For more information about Narrative Insights, see [Narrative Insights Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_135342304.html).

## To see the Return Authorizations Register: {#bridgehead_N1316152}

Go to _Reports > Order Management > Return Authorizations Register_.

A message appears indicating that your report is loading. The status bar in the footer of the report indicates the progress as your report loads. You can click **Cancel Report** next to the status bar to stop the report from loading.

You can customize this report by clicking the Customize link to open it in the Report Builder.

Note:

This report does not support reporting by period even when the Report by Period preference is set to All Reports. The Report by Period preference can be configured at _Home > Set Preferences_, on the Analytics subtab.

## To generate an insight on the Return Authorizations Register report: {#bridgehead_1125113915}

1.  Filter the report to include only the information you want the insight to reflect.
    
2.  Click the **Generate Insight** button.
    
    The Narrative Insights dialog is displayed. You can generate the insight again at any time by clicking the **Generate Insight** button.
    

Important:

Insights may differ each time they're generated, even when you're viewing the same data.

For more information about reporting, see [Reporting Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N698474.html).
