Only users with an Administrator role or with SuiteBundler permission can install the SuiteApp. The following are the bundle details:

-   Bundle name: Lot and Serial Number Trace
    
-   Bundle ID: 322956
    

For more information, read [Installing a Bundle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3395142.html).

Lot and Serial Number Trace is a managed SuiteApp that automatically updates whenever enhancements or new features are added.

Note:

After the SuiteApp version 2.0.0 update, you may encounter an error on the Lot Trace page or the Serial Number Trace page asking you to save the Trace Preferences page. To resolve the error, open the Trace Preferences page in **Edit** mode, and save the page.

## Prerequisites for Lot and Serial Number Trace {#subsect_159412077860}

The Lot and Serial Number Trace SuiteApp is developed and tested for use primarily with the following products:

-   NetSuite
    
-   NetSuite OneWorld
    

To use the Lot and Serial Number SuiteApp, enable features listed in the following procedure:

#### To enable features:

1.  Go to Setup > Company > Setup Tasks > Enable Features.
    
2.  Check the boxes next to all the features listed in the following table:
    
    | Subtab | Feature Name |
    | --- | --- |
    | Company | 
    -   Locations
    -   Multiple Units of Measure
    
     |
    | Items & Inventory | 
    
    -   Inventory
    -   Serialized Inventory (required for serial number trace)
    -   Lot Tracking (required for lot trace)
    -   Bin Management
    -   Advanced Bin/Numbered Inventory Management
    
     |
    | CRM | Customer Relationship Management |
    | Analytics | SuiteAnalytics Workbook |
    | SuiteCloud | 
    
    -   Custom Records
    -   Client SuiteScript
    -   Server SuiteScript
    -   SuiteFlow
    
     |
