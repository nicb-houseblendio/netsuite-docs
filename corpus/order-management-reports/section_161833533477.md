You can edit any of the imported custom Same-Store Sales calendars.

#### To edit a Same-Store Sales calendar:

1.  Go to Setup > Same-Store Sales > Calendar.
    
2.  On the Calendar List page, click the **Edit** link of the calendar that you want to edit.
    
3.  On the Calendar page, you can change the values in the following fields:
    
    -   **Calendar Name** - enter a different name for the calendar.
        
    -   **Set as Primary Calendar for the Year** - if it's already checked and you want to clear it, you must first set another calendar as the Primary Calendar; otherwise, you can't clear the box. Clearing this box revokes the calendar as the Primary Calendar, so it won't be used by the Same-Store Sales Report.
        
4.  Click **Save**.
