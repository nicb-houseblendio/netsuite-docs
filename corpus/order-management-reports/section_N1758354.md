When you enable the Gross Profit feature, one or more cost estimate types become available for each item type. NetSuite automatically assigns one of the cost estimate types as the default on item records.

All cost estimate types are not available for all types of items. The following table lists item types, with their available and default cost estimate types.

Note:

Items for purchase that are part of kits or assemblies must use the **Purchase Price** cost estimate type.

| Item Type | Available Cost Estimate Types |
| --- | --- |
| Non-Inventory Item (for sale) | Item Defined Cost (default) |
| Non-Inventory Item (for resale) | Last Purchase Price (default) |
| Purchase Price |
| Preferred Vendor Rate |
| Purchase Order Rate |
| Item Defined Cost |
| Download Item | Item Defined Cost (default) |
| Gift Certificate Item | Item Defined Cost (default) |
| Service Item (for sale) | Item Defined Cost (default) |
| Service Item (for resale) | Last Purchase Price (default) |
| Purchase Price |
| Preferred Vendor Rate |
| Purchase Order Rate |
| Item Defined Cost |
| Other Charge (for sale) | Item Defined Cost (default) |
| Other Charge (for resale) | Last Purchase Price (default) |
| Purchase Price |
| Preferred Vendor Rate |
| Purchase Order Rate |
| Item Defined Cost |
| Assembly Item | Average Cost (default) |
| Last Purchase Price |
| Purchase Price |
| Preferred Vendor Rate |
| Purchase Order Rate |
| Item Defined Cost |
| Kit | Derived From Member Items (default) |
| Item Defined Cost |
| Inventory Item | Average Cost (default) |
| Item Defined Cost |
| Last Purchase Price |
| Preferred Vendor Rate |
| Purchase Order Rate |
| Purchase Price |

For descriptions of cost estimate types, see [Cost Estimate Type Descriptions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1757784.html).

For information about Items and their attributes, see [Creating Item Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2166469.html).
