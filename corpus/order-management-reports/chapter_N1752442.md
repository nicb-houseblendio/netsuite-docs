Many businesses focus on the estimated profitability of prospective sales transactions. Businesses in price- and cost-sensitive environments often use estimated gross profit to price proposals, negotiate with suppliers, and compensate sales teams. Participants in the product distribution channel need information to balance prices, costs, and estimated gross profit before making a sale. With the right information, these distributors, wholesalers, and other resellers can make informed selling and buying decisions.

The Gross Profit feature lets you accurately estimate gross profit for certain transactions using estimated item costs and proposed discounts. This feature provides vital data to companies whose overall margins and ultimate success depend on accurately estimating and improving gross profit. For more information, see [What is Gross Profit?](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1752846.html)

Different types of users may use this feature, including sales representatives and sales managers, sales operations employees, executives, and administrators. For usage descriptions and examples, see [Who Uses Gross Profit and Why?](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1753013.html)

To make gross profit estimates available, the Gross Profit feature, and any related features that you need for the desired data, must be enabled. See [Setting Up Gross Profit](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1756747.html).

When these features are enabled, gross profit fields are available on standard transaction forms and can be added to custom transaction forms. These fields also are available to custom reports, advanced and saved searches and custom KPIs, and are supported for CSV Import, SOAP web services, and SuiteScript. See [Using Gross Profit Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1762134.html).

The Cost Estimate Type field is an important gross profit field. This field is the method used to estimate costs for an item. A default value for this field can be set on item records; some users can edit this value on transaction item lines. See [Working with Cost Estimate Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1757575.html).

For more information about the Gross Profit feature, see [Frequently Asked Questions about Gross Profit](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1764883.html).

Note:

Because the Gross Profit feature uses estimated cost to calculate gross profit, it does not result in postings to general ledger accounts. Keep this in mind if you use the estimates provided by this feature to post to general ledger accounts.
