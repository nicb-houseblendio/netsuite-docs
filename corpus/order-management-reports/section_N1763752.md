Even after the Gross Profit feature has been enabled, values for gross profit fields are not included in any standard reports, simple searches, or standard KPIs. However, these fields are available for addition to your custom reports, advanced searches, saved searches, and custom KPIs.

For descriptions of these fields, see [Using Gross Profit Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1762134.html).

For details about using these fields in SuiteAnalytics, see:

-   [Gross Profit Fields in Custom Reports](#bridgehead_N1763840)
    
-   [Gross Profit Fields in Searches](#bridgehead_N1764031)
    
-   [Gross Profit Fields in Custom KPIs](#bridgehead_N1764190)
    

## Gross Profit Fields in Custom Reports {#bridgehead_N1763840}

Customized versions of the following types of reports support the addition of gross profit fields:

-   Customer Profitability Report
    
-   Forecast reports
    
-   Pipeline Analysis reports, including Estimate reports and Opportunity reports
    
-   Sales reports
    
-   Sales Orders reports
    

If you have the Report Customization permission, you can add fields from the Edit Columns page of the Report Builder. The name of the folder containing these fields varies by report type. The following fields may be available:

-   Cost Estimate Type
    
-   Est. Extended Cost (Line)
    
-   Est. Extended Cost (Transaction)
    
-   Est. Extended Cost (Transaction) (Foreign Currency)
    
-   Est. Gross Profit (Line)
    
-   Est. Gross Profit (Line) (Foreign Currency)
    
-   Est. Gross Profit (Transaction)
    
-   Est. Gross Profit (Transaction) (Foreign Currency)
    
-   Est. Gross Profit Percent (Line)
    
-   Est. Gross Profit Percent (Transaction)
    
-   Est. Unit Cost
    
-   Est. Unit Cost (Foreign Currency)
    

Note:

When the Multiple Currencies feature is enabled, you can add both base and foreign currency values for some fields. Foreign Currency fields are only available when this feature is enabled.

For information about customizing reports, see:

-   [Report Customization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N736328.html)
    
-   [Adding, Removing, or Reordering Report Columns](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N738669.html).
    

## Gross Profit Fields in Searches {#bridgehead_N1764031}

You can use the following fields as criteria and results in advanced searches and saved searches of transactions. These fields also can be used as available filters for saved searches.

-   Cost Estimate Type
    
-   Est. Extended Cost (Line)
    
-   Est. Extended Cost (Transaction)
    
-   Est. Gross Profit (Line)
    
-   Est. Gross Profit (Transaction)
    
-   Est. Gross Profit Percent (Line)
    
-   Est. Gross Profit Percent (Transaction)
    
-   Est. Unit Cost
    

For information about setting up searches, see:

-   [Defining an Advanced Search](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N646177.html)
    
-   [Defining a Saved Search](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N676039.html)
    
-   [Advanced Search Criteria Filters](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N646477.html)
    
-   [Search Results Display Options](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N648053.html)
    
-   [Selecting Available Filters for Saved Searches](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N678025.html)
    

## Gross Profit Fields in Custom KPIs {#bridgehead_N1764190}

Custom KPIs are based on custom saved searches. To include gross profit fields in a custom KPI, you need to define a saved search with these fields as results, then create a custom KPI based on that saved search. See [Custom KPIs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N609047.html).
