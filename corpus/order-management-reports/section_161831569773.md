You can create and import custom retail calendars for the Same-Store Sales Report SuiteApp to compare store sales by year, quarter, month, week, or day.

To create a custom retail calendar, you must first enter calendar data in a CSV file that will be imported to NetSuite. The Same-Store Sales SuiteApp provides the CSV file for creating and entering calendar data for the years you want to compare store sales.

## Validations in Creating and Importing Calendars {#bridgehead_161831578846}

In creating and importing calendars, the following validations and requirements must be met:

-   Multiple calendars can't be created at the same time. Ongoing calendar creation must be finished before another can be created.
    
-   The calendar must be in CSV file format. Ensure that you select a CSV file in calendar import.
    
-   The calendar name must be unique.
    
-   The CSV file must contain columns for the Date, Year, Quarter, Period, Week, and Day.
    
-   Only one Primary calendar must be specified for a year.
    
-   A calendar can't be deleted there is an ongoing calendar creation or deletion.
    
-   All calendar dates must be complete and have valid values and formats:
    
    -   Each date must be unique (no duplicates) and use the MM/DD/YYYY format.
        
        Note:
        
        If other date formats are used, calendar import will fail. However, if you used the correct date format, but the calendar import still failed, then you should check the date format in your account. Go to Setup > Company > Preferences > General Preferences and Home > Set Preferences, then ensure that the Date Format field has MM/DD/YYYY defined for both.
        
    -   Year must be valid.
        
    -   The year in the calendar record must match the year in the CSV file.
        
    -   Quarter can have a value from 1 to 4.
        
    -   Period can have a value from 1 to 12.
        
    -   Week can have a value from 1 to 5.
        
    -   Day can have a value from 1 to 7.
        

#### To create and enter calendar data:

1.  Go to Documents > File > File Cabinet.
    
2.  Click **SuiteApps**.
    
3.  Click **Bundle 338212** and **com.netsuite.samestoresales**.
    
4.  Open the following files:
    
    -   Template Files > **Custom Calendar Template.xlsx** - Use this file as reference only to understand how calendar data must to be entered. This file has descriptions of the fields in the Custom Calendar CSV file, where you should enter dates to create the calendar.
        
    -   CSV Files > **Custom Calendar - CSV File - Sample Data.csv** - Contains sample data for a year to guide you in creating the calendar CSV file.
        
    -   **CSV Files > Custom Calendar - CSV File.csv** - This is the file you must download and use to enter data for the new calendar.
        
5.  In the downloaded **Custom Calendar - CSV File.csv**, enter the dates and other details for the calendar you want to create. For example, the first date of the calendar is entered Day: 1, Week: 1, Period: 1, Quarter: 1, and the corresponding Year. The next date is Day: 2, Week: 1, Period: 1, and so on.
    
6.  After entering the calendar dates and details, save the CSV file in your local computer.
    

#### To import the calendar CSV file to your NetSuite account:

1.  Go to Setup > Same-Store Sales > Calendar > New.
    
2.  On the Calendar page, specify values in the following fields:
    
    -   **Calendar Name** - Enter the name of the calendar. Calendar names must be unique to avoid duplicates.
        
    -   **Calendar Year** - Specify the year for the calendar. The year must match the calendar year specified in the Year column of the CSV file that calendar data was entered.
        
    -   **Set as Primary Calendar for the Year** - Check this box if you want to set the calendar as the Primary Calendar for the specified year. The Primary Calendar is used for the Same-Store Sales Report.
        
        Note:
        
        If you create multiple custom calendars for the same year, only one calendar can be set as Primary Calendar for that year. If there is an existing Primary Calendar for a certain year, setting the new calendar as Primary removes the setting for the existing Primary Calendar.
        
    -   **Calendar Dates Import File** - Select the CSV file of the calendar you want to import and create.
        
3.  Click **Save** to create the calendar record.
    

Repeat the steps to create and import calendars for all the years that you want to compare store sales.

After a new calendar record is created, its import status is set to Complete. On the Calendar record page are following fields:

| Field | Description |
| --- | --- |
| Period | Displays the total number of periods or months in the calendar. |
| Weeks | Displays the total number of weeks in the calendar. |
| Week Start | Displays the day of the week the calendar starts, based on the first date in the calendar. |
| Start Date | Displays the start date of the calendar, based on the first date in the calendar. |
| End Date | Displays the end date of the calendar, based on the last date in the calendar. |
