If you are an administrator, you can create new roles or customize roles for using the Lot and Serial Number Trace SuiteApp. For more information, read [Assigning Roles to an Employee](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N897798.html) and [Customizing or Creating NetSuite Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N285937.html). Refer to the following table for minimum access levels for different permissions required to use the Lot and Serial Number Trace SuiteApp:

| Permissions | Minimum Access Level |
| --- | --- |
| Lists > Subsidiaries | View |
| Lists > Items | View |
| Lists > Custom Record Entries | View |
| Custom Record > Trace Preferences | View |
| Custom Record > Trace-Grid | Edit |

The following scripts must have the new or custom role included as audience:

-   LOT SN SL Serialized Tracing Filter
    
-   LT SN SL TracingFilter
    
-   LT SL Data Service
    
-   Tracing Field Change Suitelet
    
-   LOT SN SL EXPORT CONTENT
    
-   LT SN SL Item Number Fields Popup
    

For more information, read [Defining Script Audience](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N2999041.html).

## Enabling Quality Data {#subsect_94142352324}

If you have the Quality Management SuiteApp installed, you can view the quality data for the traced item. Follow this procedure to enable viewing the quality data.

Note:

Make sure you have the Quality Management SuiteApp installed.

#### To enable quality data: {#procedure_0824022515}

1.  Go to Setup > User/Roles > Manage Roles.
    
2.  On the **LOT\_SN\_CustomRole** role row, click **Customize**.
    
    The Role page opens.
    
3.  Create a custom role:
    
    1.  (Optional) To rename the custom role, enter the role name in the **Name** field.
        
    2.  Click the **Custom Record** subtab.
        
    3.  From the **Record** list, select **Quality Data**.
        
    4.  From the level list, select **View**.
        
    5.  Click **Add**.
        
    6.  Click **Save**.
        
4.  Add the custom role to the scripts:
    
    1.  Go to Customization > Scripting > Scripts.
        
    2.  On the **LOT SN SL Serialized Tracing Filter** script row, click **Deployments**.
        
    3.  On the Script Deployments page, click **Edit**.
        
    4.  From the **Execute As Role** list, select the custom role that you created in step 3.
        
    5.  Click **Save**.
        
    6.  Repeat steps 4a to 4e for the following scripts:
        
        -   LT SN SL TracingFilter
            
        -   LOT SN SL EXPORT CONTENT
            

## Adding Center Category and Center Types {#bridgehead_159412271806}

For custom role, add the **Lot / Serial Trace** center category to the **Reports** menu. Use the following information when creating the center category:

-   Center category label - Lot / Serial Trace
    
-   Add the following links:
    
    -   Trace Preferences
        
    -   Lot Trace
        
    -   Serial Number Trace
        

For more information, read [Creating Center Categories](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2890916.html) and [Creating Center Links](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2891250.html).
