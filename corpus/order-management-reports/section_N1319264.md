A Transaction Detail report lists all transactions entered during a specific time period in chronological order.

Each line shows:

-   **Type** - the type of transaction
    
-   **Date** - the transaction date
    
-   **Document Number** - a reference number (such as an invoice number)
    
-   **Name** - the name of the vendor, customer or employee
    
-   **Memo** - a brief description
    
-   **Account** - the general ledger account affected, or planned to be affected if the transaction is non-posting
    
-   **CLR** - If the transaction cleared your bank account, the value is T. Otherwise, it's F.
    
-   **Split** - the other account involved in the double-entry bookkeeping notation. (If more than one account was used to offset this distribution, you'll see **\-Split-**.)
    
-   **QTY** - the quantity
    
-   **Amount** - amount if the transaction
    

#### To view the Transaction Detail report:

1.  Go to _Reports > Financial > Transaction Detail_.
    
    NetSuite shows a message indicating that your report is loading. The status bar indicates the progress as your report loads.
    
2.  To stop the report from loading, you can click **Cancel Report**.
    

If employee information is masked and you require this information, contact your account administrator.

Note:

NetSuite doesn't provide a standard transaction summary report. The Transactions ad hoc report can provide a summary-level report of transaction data. To create this type of report, go to Reports > New Report and choose the Transactions metric. For more information about creating ad hoc reports, see [Creating a New Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N711076.html).

For more information about reporting, see [Reporting Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N698474.html).
