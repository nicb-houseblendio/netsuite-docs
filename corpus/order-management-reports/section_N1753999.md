NetSuite administrators are responsible for setting up and maintaining NetSuite features. Administrators need to work closely with Sales Operations to set up the Gross Profit feature, to assign permissions to team members, to modify custom forms to include gross profit fields, and to define custom reports, searches, and KPIs that include gross profit fields.

Mike, a NetSuite administrator, helped set up the Gross Profit feature with guidance from Sales Operations. Using the feature's online documentation, setting up and starting the estimated Gross Profit feature proved quite easy. The setup process consisted of:

1.  [Enabling the Gross Profit Feature](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1756926.html)
    
2.  [Setting the Recalculate Estimated Cost on Creation of Linked Transactions Preference](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1757197.html)
    
3.  [Granting the Override Estimated Costs on Transactions Permission](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1757391.html)
    
4.  [Working with Cost Estimate Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1757575.html)
    
5.  Editing custom transaction forms to include gross profit fields (See [Using Gross Profit Fields on Transaction Forms](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1762276.html).)
    
6.  Customizing reports to include gross profit fields (See [Gross Profit Fields in Custom Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1763752.html#bridgehead_N1763840).)
    
7.  Creating searches and custom KPIs that include gross profit data (See [Gross Profit Fields in Searches](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1763752.html#bridgehead_N1764031) and [Gross Profit Fields in Custom KPIs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1763752.html#bridgehead_N1764190).)
    
8.  Importing gross profit data from an external system into NetSuite (See [Gross Profit Fields in CSV Import](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1764294.html#bridgehead_N1764363).)
    
9.  Creating integrations with gross profit data (See [Gross Profit Fields in SOAP Web Services](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1764294.html#bridgehead_N1764500) and [Gross Profit Fields in SuiteScript](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1764294.html#bridgehead_N1764562).)
    

Typical administrator questions may include:

-   Can I prevent some users from editing the gross profit fields? See [Granting the Override Estimated Costs on Transactions Permission](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1757391.html).
    
-   How do I get gross profit information, if there is no new gross profit report?
    
-   How does the Gross Profit feature interact with my existing gross profit functionality, such as the Item Profitability report? See [Using Gross Profit Fields on Transaction Forms](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1762276.html).
    
-   Which transactions display the estimated gross profit fields? See [Using Gross Profit Fields on Transaction Forms](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1762276.html).
    
-   What preferences control the Gross Profit feature? See [Setting the Recalculate Estimated Cost on Creation of Linked Transactions Preference](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1757197.html) and [Granting the Override Estimated Costs on Transactions Permission](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1757391.html).
    
-   How does the Gross Profit feature interact with other features? See [Enabling the Gross Profit Feature](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1756926.html).
    
-   What happens when I turn off, or disable, the Gross Profit feature? See [Enabling the Gross Profit Feature](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1756926.html).
    
-   Are the cost fields, used to calculate estimated Gross Profit, available to CSV Import, SOAP web services, or scripting? See [Using Gross Profit Values in CSV Import, SOAP Web Services, and SuiteScript](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1764294.html).
