Here you'll find a variety of tutorials that walk you through creating sample customization projects using SuiteCloud concepts, such as custom forms and fields, saved searches, and script parameters. All tutorials use SuiteScript 2.1 sample code. The projects are available on the [SuiteCloud Project Repository on Oracle Samples GitHub](https://github.com/oracle-samples/netsuite-suitecloud-samples). Each one includes a complete project customization setup with custom objects, unit tests, package file configuration, and more. Each folder is its own project and has a README.md file with detailed descriptions of the use case and customization.

The following tutorials are available:

-   [Hide Body Fields and Sublist Columns on Transaction Forms](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1112112278.html)
    
-   [Hide a Column in a Sublist](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157305280561.html)
    
-   [Validate Order on Entry](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157297763683.html)
    
-   [Set Default Values in a Sublist](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157375587585.html)
    
-   [Set the Item Amount to Zero for Marketing Orders](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157243821278.html)
    
-   [Add Custom Button to Run a Suitelet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157169557654.html)
    
-   [Calculate Commission on Sales Orders](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157227646073.html)
    
-   [Copy a Value to the Item Column](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157365998080.html)
