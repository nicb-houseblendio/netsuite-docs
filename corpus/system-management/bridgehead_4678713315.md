These settings let you set the initial default case status values you need.

## Status Start ID {#bridgehead_4700785145}

This string lets you define the NetSuite status Commerce web stores use to indicate that a case has been started. Options include:

-   1 - Not Started
    
-   2 - In Progress
    
-   3 - Escalated
    
-   4 - Re-opened
    
-   5 - Closed
    

| **ID** | cases.defaultValues.statusStart.id |
| --- | --- |
| **UI location** | My Account > Cases |
| **JSON file** | Case.json |
| **Configuration file (pre-Vinson)** | Configuration.js |

## Status Close ID {#bridgehead_4700785514}

This string lets you define the NetSuite status your Commerce web store uses when a case is closed. Options include:

-   1 - Not Started
    
-   2 - In Progress
    
-   3 - Escalated
    
-   4 - Re-opened
    
-   5 - Closed
    

| **ID** | cases.defaultValues.statusClose.id |
| --- | --- |
| **UI location** | My Account > Cases |
| **JSON file** | Case.json |
| **Configuration file (pre-Vinson)** | Configuration.js |

## Origin ID {#bridgehead_4700785766}

This string lets you define the internal identifier for the case origin.

| **ID** | cases.defaultValues.origin.id |
| --- | --- |
| **UI location** | My Account > Cases |
| **JSON file** | Case.json |
| **Configuration file (pre-Vinson)** | Configuration.js |
