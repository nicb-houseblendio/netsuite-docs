These settings let you manage Google Analytics 4 (GA4) for your site. GA4 is a third-party analytics tool that helps you track and understand your website traffic.

See [Google Analytics 4](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0104849037.html) for more information about GA4.

## Google Analytics 4 ID {#subsect_49110108955}

This string lets you enter your Google Analytics 4 Tracking ID.

The application adds this ID to every page. To find your Tracking ID, see the Google support topic [What happened to my Tracking ID?](https://support.google.com/analytics/answer/9539598?hl=en&ref_topic=9303319)

| **ID** | tracking.googleAnalyticsFour.propertyID |
| --- | --- |
| **UI location** | Integrations > Google Analytics 4 |
| **JSON file** | GoogleAnalytics4.json |

## Google Analytics 4 Domain {#subsect_34110521260}

This string lets you enter the unencrypted domain hostname for GA4.

If you use different domains for shopping and checkout, enter the hostname of your secure shopping domain in this field.

Example: `shopping.example.com`

If you use one secure domain for shopping and checkout, leave this field blank. See [Set Up Domains for Web Stores](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2484898.html) for more information.

| **ID** | tracking.googleAnalyticsFour.domainName |
| --- | --- |
| **UI location** | Integrations > Google Analytics 4 |
| **JSON file** | GoogleAnalytics4.json |

## Google Analytics 4 Secure Domain {#subsect_52110841815}

This string lets you enter the secure domain hostname for GA4.

If you use one secure domain for shopping and checkout, leave this field empty.

If you use a custom checkout domain, enter its hostname in this field.

Example: `checkout.example.com`

If you use NetSuite for your checkout domain, enter `netsuite.com` in this field.

See [Set Up Domains for Web Stores](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2484898.html) for more information.

Note:

If you're implementing SuiteCommerce MyAccount, use one secure domain and enter that URL in this field.

| **ID** | tracking.googleAnalyticsFour.domainNameSecure |
| --- | --- |
| **UI location** | Integrations > Google Analytics 4 |
| **JSON file** | GoogleAnalytics4.json |
