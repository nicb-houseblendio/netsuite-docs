The `global_views_breadcrumb.tpl` template file in the GlobalViews@x.x.x module creates the breadcrumb navigation on your site's pages. There are two default areas. One area is located directly above the breadcrumb navigation and the other area is located directly below:

![Shows the default areas above and below the breadcrumb navigation.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/SystemManagement/SiteConfiguration/breadcrumbdefaultareas.png)

The `global_views_breadcrumb.tpl` template file contains the two following **All Pages** areas.

-   `breadcrumb_top`
    
-   `breadcrumb_top`
