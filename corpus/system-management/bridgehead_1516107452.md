| Message | Message Type | Cause | Action |
| --- | --- | --- | --- |
| Your DNS record is configured correctly. | Informational | \- | No action required. |
| Your DNS record is configured incorrectly. | Error | Your DNS entry for this domain does not point to the CNAME required by NetSuite. | Ensure that you are using the correct CNAME for the domain in the DNS record. See [Point Your Domain Name at Your Domain (DNS Settings)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2479403.html) for more information. |
| Your DNS record is configured with a CNAME on a second-level domain. This can result in errors such as email server failures. Please check your DNS configuration with your DNS provider. | Error | This error is shown when a second-level domain is used. You should not use second-level domains in NetSuite because they typically do not permit use of a CNAME DNS entry. | Contact your domain provider to check your DNS configuration. |
| Unable to verify DNS status because this is a root domain. Root domains in NetSuite must use CNAME flattening. | Error | This error is shown when a root domain is used. You should not use root domains in NetSuite because they typically do not permit use of a CNAME DNS entry. | You must use a CNAME flattening service for this domain, as described in [Website Domains and Email Hosting](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4322255829.html). If you already use a CNAME flattening service for this domain, you can ignore this message. |
