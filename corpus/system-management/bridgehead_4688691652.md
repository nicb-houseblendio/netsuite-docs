These settings let you set up multiple domains so your website can support different languages or regions.

Note:

The following fields can't be translated when pages are run through the SEO page generator:

-   Meta Title
    
-   Meta Tag HTML
    
-   Schema Markup
    
-   Open Graph Tags and all other social media meta tags
    

Your website's default language and currency will display instead of any other languages or locales you've set up.

## List of Translations {#bridgehead_4695856491}

This array lets you add new string translations or update existing ones. Use this method for small changes to your site's translated content. If you're making significant changes to your site's translated content, see [The Translation Process](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3825633359.html) for details.

Each translation array contains the following properties:

-   **Key** (string) - the string you want to translate.
    
-   **Language** (string) - the localized version for each locale.
    

More Information: [Localization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3825631277.html)
