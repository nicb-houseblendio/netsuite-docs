Deleting a website removes it permanently and irrecoverably. Users are no longer able to access it and no history or audit trail is retained.

While you can usually delete simple websites, it's often not possible or desirable to delete a website entirely. For example, it is not possible to delete a website record if other NetSuite records are dependent on it or if there are database references to it that cannot be deleted.

When trying to delete a website, you can encounter two types of dependent record scenarios:

-   Non-blocking records - These include Promotion and Item records. They don't block the website record deletion.
    
-   Blocking records - These include Commerce Catalog and Shipping Item records, or instances when a Customer is assigned to the site. When you're trying to delete a website with blocking dependent records, website deletion gets blocked. Instead, you get a list of the dependent records for review.
    

If you can't delete your website record, you can inactivate it instead. For more information, see [Making a Website Inactive](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1559227395.html).

#### To delete a website:

1.  Go to _Commerce > Websites > Website List_.
    
2.  Click **Edit** next to the website you want to delete.
    
3.  Select **Delete** from the Actions menu.
    
4.  Click **OK** to confirm that you want to delete the website.
    
    If the website has no dependent records, it gets deleted.
    
    If the website does have dependent records, it doesn't get deleted. Instead, a list of the dependant records is displayed.
    
    In some cases, you may be able to delete a website with dependent records. To do this, access each of the dependent records and, if possible and desirable, delete them or remove their connection to the website. Then, attempt to delete the website again. Remember that not all websites can be deleted.
    

Note:

You cannot delete the primary website.
