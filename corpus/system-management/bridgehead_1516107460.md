| Message | Message Type | Cause | Action |
| --- | --- | --- | --- |
| Your certificate is valid. | Informational | \- | \- |
| Your SSL certificate will expire soon. | Warning | The SSL certificate will expire in fewer than 30 days. | Renew your SSL certificate before it expires. Warning: If you don't renew the certificate, the website will become inaccessible seven days after the certificate expires. This happens even if the user previously accepted a security exception in the browser. For more information, see [Maintenance of Manual Certificates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2489874.html). |
| Your SSL certificate has expired. | Error | \- | Renew your SSL certificate. Warning: If you don't renew the certificate, the website will become inaccessible seven days after the certificate expires. This happens even if the user previously accepted a security exception in the browser. For more information, see [Maintenance of Manual Certificates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2489874.html). |
| Awaiting upload of SSL certificate. | Warning | The domain record has been created but the certificate has not been uploaded. | Upload your SSL certificate. For more information, see [Manual Certificates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2485854.html). |
