Internationalization lets the website administrator set the language for the Site Management Tools user interface. SMT uses the language preference that you selected in your NetSuite account. To select your language preference, see [Choosing a Language for Your NetSuite User Interface](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N479109.html). This means that administrators can set their own language preferences when using SMT. For example, one administrator can use SMT in English and another in Spanish. SMT uses the language preference selected in each administrator's NetSuite account.

Internationalization doesn't change the language for your site's visitors. Visitor language is controlled by language preference in SuiteCommerce Advanced. See [Web Site Language Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N2567348.html).

Currently, internationalization is only supported in SMT V3. To check your version of SMT, see [Determine Your Version of SMT](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4806124052.html#bridgehead_4806935576).

You can select any foreign language that's available in NetSuite for internationalization.

Note:

Custom Content Types aren't currently supported for internationalization.
