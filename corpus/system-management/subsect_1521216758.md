The first step in setting up an online store is deciding the type of shopping and checkout domains to use. You need to decide if you want to use one domain for both shopping and checkout, or if you'd rather keep them separate.

Depending on what you decide, the following combinations are available:

-   **Single secure domain for both shopping and checkout** - You can run both shopping and checkout on one HTTPS domain. A single domain gives your customers a seamless buying experience. In NetSuite, this type of domain is called **Single Domain for Web Store and Checkout**.
    
    Note:
    
    If you're using SuiteCommerce MyAccount, set the **Domain Type** to **Single Domain for Webstore and Checkout**.
    
-   **Secure shopping domain combined with separate secure checkout domain** - In NetSuite, a standalone shopping domain is called **Web Store Only**. You can use an SSL certificate to secure your store's shopping area. You can choose from:
    
    -   a single, secure shopping domain paired with a single, secure checkout domain
        
    -   multiple secure shopping domains paired with a single, secure checkout domain
        

If you decide to keep shopping and checkout domains separate, the following types of checkout domain are available:

-   Custom checkout domain secured using an SSL certificate. In NetSuite, this type of domain is called **Checkout Only**.
    
-   Preset checkout domain.
    

For details on how to set up the different types of domain, see [Set Up Domains for Web Stores](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2484898.html).
