Inbound single sign-on (SSO) lets your web store users log in to an external application and then go to your NetSuite web store without logging in again. Outbound SSO lets users access an external app from your web store.

You can use either of these methods to set up inbound SSO for your NetSuite web store:

-   **SAML SSO** - This method uses authentication from a third-party identity provider. For more information, see [SAML Single Sign-on Access to Web Store](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3940510119.html).
    
-   **OpenID Connect (OIDC)** - This is another option instead of SAML SSO. It uses authentication from a third-party OIDC Connect Provider (OP). For more information, see [OpenID Connect (OIDC) Access to Web Store](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157909327293.html).
    

Starting with the 2025.1 release, NetSuite doesn't support Outbound Single Sign-on (SuiteSignOn) anymore. If you need outbound SSO, use the NetSuite as OIDC Provider feature. See [NetSuite as OIDC Provider](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_160077062690.html).
