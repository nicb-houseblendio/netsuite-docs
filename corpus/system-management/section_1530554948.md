These settings let you set up Quick Orders.

More Information: [Quick Order](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4618800500.html)

This feature and its settings require:

-   SuiteCommerce Advanced - 18.2 or later
    
-   SuiteCommerce
    

## Show Quick Order Hyperlink {#bridgehead_1532614856}

This boolean controls whether the Quick Order link displays. Enable it to display the Quick Order link. By default, it's enabled.

| **ID** | quickOrder.showHyperlink |
| --- | --- |
| **UI location** | Shopping > Quick Order |
| **JSON file** | QuickOrder.json |

## Hyperlink Text {#bridgehead_1532614885}

This string lets you choose the text for the Quick Order link. By default, the text is "Quick Order."

| **ID** | quickOrder.textHyperlink |
| --- | --- |
| **UI location** | Shopping > Quick Order |
| **JSON file** | QuickOrder.json |
