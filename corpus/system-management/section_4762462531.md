Note:

This topic applies to System Notes only. For information about System Notes v2, see [System Notes v2 Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158108495822.html).

You can use system notes to track important changes to website implementations. System notes are visible to account administrators and users with access to the Web Site Setup page. For more information, see [System Notes Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_158644279544.html).

#### To view system notes:

1.  Go to _Commerce > Websites > Website List_.
    
2.  Click **Edit** next to the website.
    
3.  Click the **System Notes** subtab.
    

System notes are also available in Saved Search. To create a saved search, click **System Note** in the New Saved Search list, and then filter the search for the website record type.

#### To create a saved search of Web Site record changes:

1.  Go to _Lists > Saved Search > New_.
    
2.  Click **System Notes**.
    
3.  On the **Criteria** subtab in the list of **Filters**, select **Record Type**, and then select **Website**.
    
4.  Click **Save & Run**.
    

Search results show changes made to your websites, including the date and who made them.

Note:

Not all changes made to the Web Site Setup page are logged in system notes.
