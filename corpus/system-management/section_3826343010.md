#### To enable your website for localized content: {#procedure_3830672797}

1.  If setting up your site for multiple languages, verify that the Multi-Language feature is enabled:
    
    1.  In NetSuite, go to Setup > Company > Setup Tasks > Enable Features.
        
    2.  On the **Company** subtab, check the **Multi-Language** box.
        
    3.  Click **Save**.
        
2.  Verify that all languages available on your site are defined in your Company General Preferences:
    
    1.  Go to Setup > Company > Preferences > General Preferences.
        
    2.  On the **Languages** subtab, select and add each language you want available in your NetSuite account and on your website.
        
    3.  Click **Save**.
        
    
    Only languages enabled in your Company General Preferences are available. See [Configuring Multiple Languages](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N247147.html) for more information.
    
3.  Verify that all desired languages are enabled in the Web Site Setup page.
    
    1.  In NetSuite, go to _Commerce > Websites > Website List_.
        
    2.  Click Edit for the desired website.
        
    3.  Navigate to the **Shopping** tab and **Languages** subtab.
        
    4.  Check the box in the **Online** column for each language you want available on the site.
        
        ![Shows several languages enabled in the Languages subtab and U.S. English set as the default language.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/SystemManagement/Microsites/ref_Languages.PNG)
    5.  Verify that item names and descriptions have associated translation fields for each language.
        
        When you fill in translation fields on the item record, the translated fields show up in the web store.
        
        Note:
        
        Translation of custom fields on item records isn't supported, so data from custom fields in a web store won't have translated strings.
        
        For detailed instructions, see [Working With Multi-Language Names and Descriptions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2178279.html).
        
    6.  Click **Save**.
        
4.  Verify that all desired currencies are enabled in the Web Site Setup page.
    
    1.  In NetSuite, go to _Commerce > Websites > Website List_.
        
        Note:
        
        Currencies must be set up in NetSuite to appear in this list. See [Currency Management](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N1395057.html) for information on adding currencies to NetSuite.
        
    2.  Click **Edit** for the desired website.
        
    3.  Navigate to the **Shopping** tab and **Currency** subtab.
        
    4.  Check the box in the **Online** column for each currency you want available on the site.
        
        ![Shows enabled currencies in the Currency subtab and a default currency of USD.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/SystemManagement/Microsites/Localization-CurrencySetup.png)
    5.  Click **Save**.
        
5.  If you're setting up your site for multiple languages and currencies, make sure you set up the `hosts` array
    
    See [Configure Hosts for Sites with Multiple Languages](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3830019370.html).
    
    After your website is set up and customized to support multiple languages, the location drop-down appears by default in the upper left corner.
    
    ![Shows how the location selector looks in your website.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/SystemManagement/Microsites/ref_WebSiteLanguages.PNG)
