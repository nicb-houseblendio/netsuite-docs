If you set up a standalone secure Web Store Only domain, link it to a secure checkout domain. Customers can't buy products from your store until you do this.

There are two checkout domain options for Web Store Only domains:

-   Secure shopping domain combined with a separate secure custom checkout domain.
    
-   Secure shopping domain combined with a separate secure preset checkout domain
    

No matter which checkout domain you choose, users on your website enter their information using an SSL connection. An SSL connection is protected by encryption. Users can tell they're on an SSL connection because the browser displays a padlock and the address bar starts with https instead of http. SSL provides the confidence that private data sent to the website is kept confidential. See [Overview of SSL Encryption](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_1521565671.html) for more information.

#### To link a Web Store Only domain with a Checkout Only domain:

1.  Go to _Commerce > Websites > Website List_.
    
2.  Click **Edit** next to the website whose Web Store Only domains you want to link to the checkout domain.
    
3.  On the **Domains** tab, select the Checkout domain from the **Checkout URL HTTPS://** list.
    
    This list contains the preset checkout domain and any custom checkout domains you have already set up. It also contains unbranded checkout subdomains if you have enabled them.
    
    Note:
    
    Your Checkout Only domain must be a custom secure domain. To use a custom checkout domain, follow the steps in [Set Up a Domain](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1526632554.html) for the domain type Checkout Only, and then follow the steps in [Secure Your Domain](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0603043411.html). If you can't see your configured checkout domain in the **Checkout URL HTTPS://** list, contact your account manager.
    
4.  Click **Save**.
    
    All the Web Store Only domains for the website are now linked to the selected checkout domain.
    
    Note:
    
    These steps don't apply to the Single Domain for Web Store and Checkout domain type. This is because a single domain is used for both the web store and checkout.
    

#### To set up a secure subdomain for checkout: {#procedure_N2485452}

1.  Go to _Commerce > Websites > Website List_.
    
    1.  Click the **Web Presence** subtab.
        
    2.  Check the box next to **Customizable Checkout Subdomains**.
        
    3.  Click **Save**.
        
2.  Go to _Commerce > Websites > Website List_.
    
3.  Click **Edit** for the desired website.
    
4.  On the **Domains** subtab, enter your checkout **Domain Prefix**. Enter the prefix as one word, all lower case and without punctuation (for example, `mysite`).
    
    A domain prefix can help a user to identify areas on your site.
    
    ![Example of a checkout domain prefix set in the Domains subtab](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/SystemManagement/Domains/domainSCSCAScreenshotRedwood.png)
5.  Select your preferred checkout subdomain in **Checkout URL**.
    
    The subdomain is appended to the domain prefix to construct your checkout URL. For example, if your domain prefix is `mysite` and your selected subdomain is `example.com`, the checkout URL is `https://mysite.example.com`.
    
6.  Click **Save**.
    

After you set up a checkout subdomain, changing to a different one might take up to 30 minutes to redirect. This delay happens because the previous subdomain needs to be cleared from the web store caches.
