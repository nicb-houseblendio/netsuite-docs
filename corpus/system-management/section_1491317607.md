Important:

The Content Delivery Service is supported up to the Denali R2 (revision 2) release of SuiteCommerce Advanced only. After that, you should use Site Management Tools for SuiteCommerce and for the Mont Blanc release and later.

Content Delivery lets you manage key SEO parts of your site, like page titles and meta descriptions. See the following help topics to set these up with Content Delivery.

-   [Setting Page Titles with Content Delivery](#bridgehead_1490883711)
    
-   [Setting Meta Descriptions with Content Delivery](#bridgehead_1490883727)
    

Note:

If you use Site Management Tools, you can't use Content Delivery to set page titles or meta tags. You can set those on Site Management Tools landing and enhanced pages instead. See [Pages](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4314594735.html).

## Setting Page Titles with Content Delivery {#bridgehead_1490883711}

Page titles are a key part of your site's SEO. The title shows up in the browser's title bar or tab, and it's also what people see in search engine results. See [SEO and Page Titles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4280885364.html)

If you use Content Delivery, follow these steps to set page titles for your site.

-   [Home Page Title](#bridgehead_1491233498)
    
-   [Item Detail Page Title](#bridgehead_1491233520)
    
-   [Facet Search Page Title](#bridgehead_1491233577)
    
-   [Landing Page Title](#bridgehead_1491233601)
    

## Home Page Title {#bridgehead_1491233498}

You can set your home page title with a SuiteCommerce Advanced custom module. See [Home Page Title](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4280885364.html#section_4280885576).

## Item Detail Page Title {#bridgehead_1491233520}

You set the item detail page title on the Item Record in NetSuite. See [Item Detail Page Titles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4280885364.html#section_4280879700).

## Facet Search Page Title {#bridgehead_1491233577}

You can use Content Delivery enhanced pages to set SEO-friendly titles for your search pages.

#### To set facet search page titles with content delivery enhanced pages:

1.  Go to Setup > SuiteCommerce Advanced > Content Delivery.
    
2.  Click **New Enhanced Page**.
    
3.  In the **Name** field, enter a name for this enhanced page.
    
4.  In the **Site** list select the website for which you're creating the enhanced page.
    
5.  On the Target URL subtab, in the **Target URL** field, enter the URL for which you want to set a page title.
    
6.  Click **Add**.
    
7.  Select the Content Rule subtab.
    
8.  In the **Target** field, enter **#empty**.
    
9.  In the **Content** dropdown list select **New**. Create a new blank HTML page.
    
10.  On the Advanced subtab, enter the title for the page in the **Page Title** field.
     
     Note:
     
     You can also set other important SEO elements here, such as the `meta description`.
     

## Landing Page Title {#bridgehead_1491233601}

You can use Content Delivery to set SEO-friendly titles for your landing pages. For more information about Content Delivery landing pages, see [Using Content Delivery](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2689412.html).

#### To set landing page titles:

1.  Go to Setup > SuiteCommerce Advanced > Content Delivery.
    
2.  Click **Edit** for the landing page.
    
3.  On the Advanced subtab, enter the title in the **Page Title** field.
    
4.  Click **Save**.
    

## Setting Meta Descriptions with Content Delivery {#bridgehead_1490883727}

The `meta description` for your pages is important for SEO because it tells search engines what the page is about. It's also usually the summary that shows up in search results. See [SEO and Meta Descriptions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4285087960.html). You can use Content Delivery to set the `meta description` for your home page, facet pages, and Content Delivery landing and enhanced pages.

## Meta Description for the Home Page {#bridgehead_1490884795}

You can use a Content Delivery enhanced page to add a `meta description` to your home page. Keep it short and informative to encourage people to visit your site.

#### To set the meta description for the home page:

1.  Go to Setup > SuiteCommerce Advanced > Content Delivery.
    
2.  Click **New Enhanced Page**.
    
3.  In the **Name** field, enter a name for this enhanced page, for example **home page**.
    
4.  In the **Site** list, select the site for this enhanced page.
    
5.  In the **Target URL** field on the Target URL subtab, enter **/**. That means the home page of your site.
    
6.  On the Content Rule subtab, enter **#empty** in the **Target** field.
    
7.  Select **New** from the **Content** dropdown list. This opens the new content window. Create a blank HTML page.
    
    Note:
    
    If you already have a blank HTML page, you can use that instead of creating a new one.
    
8.  On the Advanced subtab, enter your meta description in the **Meta Description** field.
    
    Note:
    
    You can also set other attributes, like the page title and page header.
    

## Meta Description for Facet Pages {#bridgehead_1490884844}

You can use Content Delivery to set the `meta description` for a facet search page. For example, for a men's shoes filter, your description could be: Shop the best deals on men's dress shoes, loafers, sneakers, boots, and more at YourSite.com.

#### To set the meta description for a facet page:

1.  Go to Setup > SuiteCommerce Advanced > Content Delivery.
    
2.  Click **New Enhanced Page**.
    
3.  In the **Name** field, enter a name for this enhanced page, for example **mensshoes**.
    
4.  In the **Site** list, select the site for this enhanced page.
    
5.  In the **Target URL** field on the Target URL subtab, enter the URL for the facet listing. For example, if the URL for Men's Shoes is /mens/shoes, then enter **/mens/shoes**.
    
6.  On the Content Rule subtab, enter **#empty** in the **Target** field.
    
7.  Select New from the **Content** dropdown list. This opens the new content window. Create a blank HTML page.
    
    Note:
    
    If you already have a blank HTML page, you can use that instead of creating a new one.
    
8.  On the Advanced Subtab, enter your meta description in the **Meta Description** field.
    
    Note:
    
    You can also set other attributes, like the page title and page header.
    

## Meta Descriptions for Content Delivery Landing Pages {#bridgehead_1490890920}

You set the `meta description` for a Content Delivery landing page on the Content Delivery landing page record. Enter the `meta description` in the **Meta Description** field on the **Advanced** subtab. For more information about creating landing pages, see [Using Content Delivery](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2689412.html).
