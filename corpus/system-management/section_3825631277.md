Commerce web stores support multiple languages and currencies by default, and you can customize them to add translated components. Setting up multiple languages needs some frontend configuration.

Note:

Translation for the following fields is not supported when web pages are run through the SEO page generator:

-   Meta Title
    
-   Meta Tag HTML
    
-   Schema Markup
    
-   Open Graph Tags and all other social media meta tags
    

Your website shows the default language and currency instead of any others you've set up.
