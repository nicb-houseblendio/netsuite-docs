Note:

This information refers to SuiteCommerce and the Mont Blanc release of SuiteCommerce Advanced (SCA) or later. Site Builder supports this functionality, but only if your implementation doesn't deploy SSP Applications to SCA reference implementations.

Commerce websites let you restrict access to your website in two ways:

-   [Restrict Access to Your Entire Site](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4527004110.html)
    
-   [Restrict Access to Pricing Information](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4527004533.html)
    

Both options are disabled by default and require some minor configuration to work.

Warning:

The CXM API is public and contains all the information exposed by the field set being used. Password protection restricts user access to some or all of your site when enabled. However, users who knows a URL that calls the different APIs can still access some information.
