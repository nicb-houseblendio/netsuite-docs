These settings let you control how the Quotes feature works in your Commerce web store.

More Information: [Quotes for Commerce Websites](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4464799196.html)

## Show Request A Quote Hyperlink {#bridgehead_1532276090}

This property works with:

-   SuiteCommerce Advanced - 2018.2 and later
    
-   SuiteCommerce
    

This boolean lets you choose if the Request a Quote link displays. By default, this is set to enabled.

| **ID** | quote.showHyperlink |
| --- | --- |
| **UI location** | My Account > Quotes |
| **JSON file** | RequestQuoteAccessPoint.json |

This property works with:

This string lets you set the text for the Request a Quote link. By default, it's set to "Request a Quote."

| **ID** | quote.textHyperlink |
| --- | --- |
| **UI location** | My Account > Quotes |

## Purchase Ready Status ID {#bridgehead_4700619224}

This string lets you set the Customer Status that lets customers buy from a quote. This field must match the Internal ID of the Customer Status required for a customer to buy from the quote.

In NetSuite, the Estimate record's Status field lists all available Customer Statuses for the quote. When you the merchant changes this field to the Customer Status with an Internal ID that matches the **Purchase Ready Status ID**, all website links to Review or Purchasing pages are enabled. The customer can then make a purchase.

More Information: [Set the Customer Status Internal ID](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4527214444.html)

| **ID** | quote.purchaseReadyStatusId |
| --- | --- |
| **UI location** | My Account > Quotes |
| **ID (pre-Vinson)** | purchase\_ready\_status\_id |
| **JSON file** | Quote.json |
| **Configuration file (pre-Vinson)** | Configuration.js |

## Days Before Expiration Notification {#subsect_156259970986}

This value lets you set how many days before a quote expires the expiration notification displays on your web site. By default, it's set to 7. All quotes use the same expiration notification configuration.

More Information: [Set Quote Expiration](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4706652617.html)

| **ID** | quote.daysToExpirationNotification |
| --- | --- |
| **UI location** | My Account > Quotes |
| **JSON file** | Quote.json |

## Days to Expiration {#bridgehead_4700625455}

This value lets you set how many days all quotes stay valid after they're first submitted. If you set this value to 0, the expiration is set by the **Default Quote Expiration (In Days)** field in the Sales Preferences record. See [Sales Force Automation Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1035924.html). All quotes use the same expiration setting. After this time expires, the quote can't be turned into a purchase.

More Information: [Set Quote Expiration](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4706652617.html)

| **ID** | quote.daysToExpire |
| --- | --- |
| **UI location** | My Account > Quotes |
| **ID (pre-Vinson)** | days\_to\_expire |
| **JSON file** | Quote.json |
| **Configuration file (pre-Vinson)** | Configuration.js |
