Template files control the web page structure of your SuiteCommerce themes. They contain HTML markup and placeholders for your custom extensions and custom content types.

The following SuiteCommerce theme areas include template files with pre-defined areas where you can install custom extensions or add custom content types:

-   [My Account Theme Area](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161486861351.html)
    
-   [Checkout Theme Area](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161486862723.html)
    
-   [Shopping Theme Area](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161486864048.html)
    

For more information about themes, see [Commerce Themes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_158386920036.html).
