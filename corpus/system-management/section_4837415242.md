The information in this topic refers to SuiteCommerce and the Elbrus, Kilimanjaro, and Aconcagua releases of SuiteCommerce Advanced only.

You can only upgrade secure Web Store Only domains to Single Domains for Web Store and Checkout. To secure a Web Store Only domain with an automatic certificate, follow the steps in [Secure Your Domain](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0603043411.html). You can also use a manual certificate, as described in [Manual Certificates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2485854.html).

After the Web Store Only domain is secure, you can upgrade it to a Single Domain for Web Store and Checkout by editing the domain record and selecting **Single Domain for Web Store and Checkout** from the **Domain Type** list.
