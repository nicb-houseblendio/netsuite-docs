After you've set up a domain, you can view its status in NetSuite on the Domains list page, where all your domain names are listed. The Domain Status feature helps you troubleshoot by running health tests and flagging any issues with Deployment, DNS, or Certificates.

For information about the importance of proper DNS setup and the risks of improper DNS setup, see [Importance of Proper DNS Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1115112645.html).

You can view a summary of your domain's health on the Domains list page by status icons displayed in the Deployment, DNS, and Certificate columns. If you notice any issues in these columns, click **View** next to your domain name to troubleshoot.

Note:

The DNS column on the Domains list page includes the status for both DNS and DNS Verification. If there's an issue with either status, you'll see an error icon in the DNS column.

Important:

The Encryption column on the Domains list page displays an error status icon if you're using a non-secure (HTTP) domain. That's because NetSuite no longer supports non-secure domains. You'll need to secure all your domains. See [Secure Your Domain](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0603043411.html).

On the Domain page, the Status section tells you the cause of the problem.

Note:

To actively monitor your domain health, add the Domain Configuration Alert reminder to your reminder portlet. For more information, see [Setting Up Reminders](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N581945.html).

The Status section can contain the following message types:

-   **Informational** - These messages provide information about an ongoing or completed task.
    
-   **Warning** - These messages point out issues that could cause problems later if you don't fix them.
    
-   **Error** - These messages mean the task didn't finish because of a user or system error and needs your attention.
    

There is also information about the actions that can trigger these messages. The issues fall into one of four categories:

-   [Deployment Status](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_1516107391.html)
    
-   [DNS Status](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_1516107452.html)
    
-   [DNS Verification Status](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0423035423.html)
    
-   [Certificate Status](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_1516107460.html)
    

The "This domain already exists" error does not fall into any of these categories. This message is displayed if you try to create a domain record that already exists or was recently deleted. It can take up to two hours for a deleted domain's DNS record to be fully removed from all DNS servers. You'll need to wait until the record is fully removed before you can create it again.
