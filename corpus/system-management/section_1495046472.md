These settings let you control how addresses work on My Account pages.

See [Working with Addresses on Transactions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N553515.html) for more information about managing addresses.

## Require a Phone Number With Addresses {#bridgehead_1495048014}

This boolean lets you decide if customers must include a phone number when saving an address to their account. If you check this property, customers must add a phone number when entering an address. If you leave it unchecked, customers don't need to add a phone number. By default, this property is unchecked.

| **ID** | addresses.isPhoneMandatory |
| --- | --- |
| **UI location** | My Account > Addresses |
| **JSON file** | Address.json |
