Commerce websites let you configure common properties and modify application behavior for a specific domain using the NetSuite UI, instead of having to customize the source code. The SuiteCommerce Configuration record feature provides this capability and is installed with the SuiteCommerce Configuration bundle.

You can:

-   Configure properties for a domain
    
-   Read configuration file types information
    
-   Browse the site configuration properties reference section
    
-   Configure and maintain Site Management Tools
    

To access a SuiteCommerce Configuration record, go to _Commerce > Websites > Configuration_.

See the following topics for more information:

-   [Configure Properties](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4346479003.html) - This section explains how to configure properties for a domain and how to copy a SuiteCommerce configuration record.
    
-   [Configuration Properties Reference](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4666182345.html) - This section lists all the configuration properties SuiteCommerce supports. They're grouped by how they appear in the Configuration record.
    
-   [Configuration File Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4672165457.html) - This section explains the different configuration files you may encounter when setting up SuiteCommerce. The types of files and their purpose can change depending on your SuiteCommerce version.
    
-   [Site Management Tools Configuration](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4534752587.html) - This section explains how to set up and manage Site Management Tools..
    
-   [Templates and Theme Areas for SuiteCommerce Themes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_161521710124.html) - This section outlines the template files and pre-defined areas you can use to install a custom extension or to add a custom content type to your SuiteCommerce theme.
