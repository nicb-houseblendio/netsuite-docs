After you enable email verification for your Commerce web store, here's how it works:

1.  A customer enters their email address in a form as part of one of the following flows on your web store:
    
    -   Registration
        
    -   Guest checkout
        
    -   Skip checkout login
        
2.  A random, one-time code is generated and sent to the customer's email.
    
3.  A popup on your website asks the customer to enter the verification code.
    
4.  The customer enters the code into the popup's **Verification Code**.
    
    Each verification code is unique and expires after a set time. You can set how long they're valid for in NetSuite.
    
5.  If the code is valid and hasn't expired, the customer proceeds to registration or checkout. Otherwise, the customer can request a new code after the waiting period you set in NetSuite.
    
6.  If there's a form error, the customer's email remains validated and they don't need to re-verify.
    

For more information, see [SuiteCommerce Email Verification User Experience](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0826025727.html).

## Configuration Options {#subsect_0826025232}

You can set up SuiteCommerce Email Verification in NetSuite using the SuiteCommerce Configuration record. Options include:

-   Enabling or disabling email verification
    
-   Selecting the sender and customizing the email template
    
-   Setting verification code expiration and resend intervals
    

For more information, see [How to Enable and Configure SuiteCommerce Email Verification](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0826025342.html).
