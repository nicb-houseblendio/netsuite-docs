These settings let you control the behavior for the Store Pickup feature. For more information, [Store Pickup for SuiteCommerce Websites](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4793321418.html).

## Enable Pickup in Store {#subsect_0319040545}

The **Enable Pickup In Store** setting works with SuiteCommerce MyAccount, SuiteCommerce, and the Elbrus release of SuiteCommerce Advanced and later.

This boolean lets you enable the Store Pickup for Commerce Websites feature.

| **ID** | isPickupInStoreEnabled |
| --- | --- |
| **UI location** | Checkout > Pick Up in Store |
| **JSON file** | PickupInStore.json |

## Pickup In Store Sales Order Custom Form ID {#subsect_0319041105}

The **Pickup In Store Sales Order Customer Form ID** setting works with to SuiteCommerce MyAccount, SuiteCommerce, and the Elbrus release of SuiteCommerce Advanced and later.

This string lets you set the ID for the sales order form customized for the Store Pickup for Commerce Websites feature.

| **ID** | pickupInStoreSalesOrderCustomFormId |
| --- | --- |
| **UI location** | Checkout > Pick Up in Store |
| **JSON file** | PickupInStore.json |
