The `home.tpl` template file in the Home@x.x.x module controls your site's home page's layout. In the following screenshot, you can see the This Page areas available on the `home.tpl` template file. You can also see the All Pages header and footer module areas at the top and bottom of the page.

![Shows the defined areas on the site's home page as displayed in the Site Management Tools interface. The areas on the page are numbered 1 through 6.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/SystemManagement/SiteConfiguration/homePageDefaultAreas.png)

| Item | Description |
| --- | --- |
| 1 | `home_main` |
| 2 | `home_banner_1` |
| 3 | `home_banner_2` |
| 4 | `home_banner_3` |
| 5 | `item_list_banner_bottom` |
| 6 | `home_bottom` |
