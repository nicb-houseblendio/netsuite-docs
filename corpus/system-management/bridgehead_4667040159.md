These settings let you specify the options in the Results Per Page dropdown menu. This array contains the following properties:

-   **Items** (number) - the number of search results this option displays.
    
-   **Name** (string) - the label for this option.
    
-   **Is Default** (boolean) - specifies whether this option is the default.
