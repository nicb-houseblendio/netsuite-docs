The **Allow User to Reorder Items** setting lets shoppers reorder items.

For more information see [Reorder Items](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_161286223878.html).

## Allow User to Reorder Items {#subsect_161279009186}

This setting works with SuiteCommerce MyAccount.

This boolean lets you choose if shoppers can reorder items.

| **ID** | myAccountPreferences.reorderEnabled |
| --- | --- |
| **UI location** | My Account > Preferences > Allow users to reorder items |
| **JSON file** | ReorderItems.json |
