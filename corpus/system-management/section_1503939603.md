## Favicon of the Website {#bridgehead_1503939673}

This string sets the path to your website's favicon. By default, this property is blank. You should use a relative URL path.

| **ID** | faviconPath |
| --- | --- |
| **UI location** | Advanced > Favicon Path |
| **JSON file** | Favicon.json |
