As of the 2025.1 release of NetSuite, the SuiteSignOn feature is no longer supported. If you need an integration using outbound single sign-on, use the NetSuite as OIDC Provider feature instead. See [NetSuite as OIDC Provider](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_160077062690.html).
