After you enable Email Verification for your Commerce web store, customers are asked to verify their email address when registering a new account or checking out as a guest. This feature helps ensure that only valid, reachable email addresses are used for account creation and order placement.

## SuiteCommerce Email Verification Flow {#subsect_0826031129}

When a customer enters their email address during registration or guest checkout, here's what happens:

1.  **Email Entry:** A customer enters their email address in the registration or guest checkout form. If it's invalid, an on-screen message tells them to enter a valid email address.
    
2.  **Verification Email Sent:** After the customer submits the form,NetSuite sends an automated email with a unique, time-limited verification code.
    
    Sample email content:
    
    `Subject: Verify Your Email Address`
    
    `To help keep your transactions secure, please use the code below to verify your email address.`
    
    `123456`
    
    `This code is valid for 300 seconds. If you didn't request this code or need assistance, contact our support team.`
    
3.  **Email Verification Popup:** Your web store displays a popup asking the customer to enter the verification code sent by email.
    
    Sample on-screen message:
    
    `A verification code has been sent to test@example.com.`
    
    Sample popup fields and actions:
    
    **Verification Code:** \[Input field\]
    
    **Resend Code (XXs)** (disabled until the resend interval expires)
    
    **Verify** | **Cancel** (buttons)
    
    Note:
    
    Customers can ask for a new code to be sent after a set time. The resend option is time-limited to prevent abuse and a countdown timer displays next to the **Resend Code** button.
    
4.  **Code Validation:**
    
    If the customer enters the correct code before it expires, registration or checkout continues.
    
    If the code is incorrect or expired, an error message tells the customer that the code is invalid and their email isn't verified.
    
5.  **Account Activation or Order Placement:**
    
    For new accounts, the account is created after successful verification.
    
    For guest checkout, the order process continues after verification.
