This array lets you set color labels in the palette that are close in hue to the background color. The color picker displays an outer border for each of these colors.

| **ID** | layout.lightColors |
| --- | --- |
| **ID (Pre-Elbrus)** Note: In the Vinson release of SCA, this property is located on the **Shopping Catalog** tab and **Light Colors** subtab. | lightColors |
| **UI location** | Layout > Light Colors |
| **JSON file** | ApplicationSkeleton.Layout.Colors.json |
| **Configuration file (pre-Vinson)** | SC.Shopping.Configuration.js |
