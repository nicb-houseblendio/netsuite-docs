Template files control the structure of your website pages. These files contain HTML markup and placeholders for data and scripts. Site Management Tools (SMT) uses areas defined within the template files to determine the locations on a page where you can add and manage website content. For more information about using SMT, see [Site Management Tools Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4165123763.html).

SMT areas are `<div>` tags that are defined in a template file. The `<div>` defines the location on the page where you can add content. Commerce web stores include page template files that have pre-configured areas. You can use these areas as they are defined, edit the areas, or add new areas to the templates.
