These settings let you specify the sorting options in the Sort By dropdown, grouped by browser type (desktop, phone, or tablet). First, you must define sort fields in the Web Site Setup record. See [Select and Configure Sort Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2659294.html).

Each sort property contains the following (note the different property IDs for each browser type):

-   **ID** (string) - the ID of the search option.
    
-   **Name** (string) - the label for the sort option.
    
-   **Is Default** (boolean) - the default active search option.

This array lets you specify the sorting options in the Sort By dropdown for desktop browsers.
