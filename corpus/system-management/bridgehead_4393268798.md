The settings on the Checkout tab let you set up properties related to the Checkout application on your Commerce website. This tab includes general checkout settings and the following subtabs:

-   [Pick Up In Store Subtab](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0319040256.html)
    
-   [Checkout Experience Subtab](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0319041636.html)
    
-   [Forms Subtab](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4700765645.html)
    
-   [Quantity Stock Message Subtab](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0314024910.html)
    

## Enable Multiple Shipping {#bridgehead_4700783184}

The **Enable Multiple Shipping** setting works with to SuiteCommerce MyAccount, SuiteCommerce, and SuiteCommerce Advanced.

This boolean lets you control if shoppers can send items from the same order to multiple shipping addresses. For more information, see [Multiple Ship To](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4188560821.html).

| **ID** | isMultiShippingEnabled |
| --- | --- |
| **UI location** | Checkout |
| **JSON file** | CheckoutApplication.json |
| **Configuration file (pre-Vinson)** | Configuration.js |

## Checkout Steps {#bridgehead_4700783650}

The **Checkout Steps** setting works with SuiteCommerce MyAccount, SuiteCommerce, and SuiteCommerce Advanced.

This string lets you select one of three checkout flow configurations from the dropdown list. Each checkout flow guides the shopper through the same steps but in a different order.

For more information, see [Checkout Flows](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4465847415.html).

| **ID** | checkoutApp.checkoutSteps |
| --- | --- |
| **UI location** | Checkout |
| **JSON file** | CheckoutApplication.json |
| **Configuration file (pre-Vinson)** | SC.Checkout.Configuration.js |
