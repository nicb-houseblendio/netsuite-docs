These settings let you set up the search feature in the application header.

More Information: [Select and Configure Sort Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2659294.html)

## Search Results Title {#bridgehead_4695853664}

This string lets you specify the title for the facet browse view in the application header.

| **ID** | defaultSearchTitle |
| --- | --- |
| **UI location** | Search > Search Results |
| **JSON file** | SearchResults.json |
| **Configuration file (pre-Vinson)** | SC.Shopping.Configuration.js |

## Search Keyword Maximum Length {#bridgehead_4695853890}

This number lets you specify the maximum number of characters users can enter in the search field.

| **ID** | searchPrefs.maxLength |
| --- | --- |
| **UI location** | Search > Search Results |
| **JSON file** | SearchResults.json |
| **Configuration file (pre-Vinson)** | SC.Configuration.js |
