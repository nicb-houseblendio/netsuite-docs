These topics explain how to configure your Commerce website using the SuiteCommerce Configuration record. For this record to appear in your account, you must install the SuiteCommerce Configuration bundle, which is available for SuiteCommerce, SuiteCommerce MyAccount, and the Vinson release of SCA and later. See [Install Your Commerce Website Applications](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2675216.html) for more information.

Note:

This configuration method is available for SuiteCommerce, SuiteCommerce MyAccount, and the Vinson release of SuiteCommerce Advanced and later. When configuring the Mont Blanc or Denali release of SCA, you must customize JavaScript configuration files. See [Develop Your SCA Customization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3705381013.html) for more details.

This topic explains how to:

-   [Configure Properties for a Domain](#subsect_1519942737)
    
-   [Copy a SuiteCommerce Configuration Record](#section_1516630924)
    

Important:

If you're using SuiteCommerce Advanced (SCA) and moving to a later release from Denali or Mont Blanc, you can copy your previous configuration files and include them directly in the Vinson JavaScript files. If you do this, you don't need to install the SuiteCommerce Configuration bundle. These existing configuration files take priority over the SuiteCommerce Configuration record. However, if you're installing Vinson or a later release as your first SCA installation, you need to install the SuiteCommerce Configuration bundle to set up your site.

Note:

Before configuring a Commerce web store, ensure that you've created a website and domain for your NetSuite account. See [Getting Started](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2655840.html) and [Set Up Domains for Web Stores](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2484898.html) for more information.

## Configure Properties for a Domain {#subsect_1519942737}

Use the SuiteCommerce Configuration record when you want to update properties for your domain.

#### To configure properties for a domain: {#procedure_4725042028}

1.  Go to _Commerce > Websites > Configuration_.
    
2.  Choose the site that you want to configure from the **Select Website** list.
    
3.  Select the domain that you want to configure from the **Select Domain** list.
    
4.  Click **Configure**.
    
5.  Configure properties for the domain by clicking the tab and subtab for the feature you want to update. See [Configuration Properties Reference](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4666182345.html) for details.
    
6.  Save the record.
    

Important:

Saving changes to the SuiteCommerce Configuration record creates a custom record for the selected domain. To configure multiple domains, you need to save a SuiteCommerce Configuration record for each one separately.

You can also copy one domain's configuration to another using the **Copy Configuration** feature. See [Copy a SuiteCommerce Configuration Record](#section_1516630924).

Important:

The SuiteCommerce Configuration record works with valid JSON data, like strings, numbers, booleans, objects, arrays, or null. The [Configuration Properties Reference](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4666182345.html) explains the type of data expected for each property.

Note:

If your domain is mapped to a CDN, any changes you make to the Shopping Application with the SuiteCommerce Configuration record take about five minutes to take effect. This happens because the configuration information is published to the sc.shopping.environment.ssp file, which has a five-minute CDN cache by default. See [CDN Caching Times](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4411360163.html#bridgehead_4374568099) for more details.

## Copy a SuiteCommerce Configuration Record {#section_1516630924}

Use the Copy Configuration function to copy a SuiteCommerce Configuration record from one domain to another.

Common scenarios where this function is useful include:

-   When you move a site from staging to production
    
-   When you upgrade from one SCA release to another
    
    Note:
    
    The two domains do not have to be on the same release of SCA. For example, you can copy a Kilimanjaro Configuration record from one domain to another Kilimanjaro domain or to an Aconcagua domain. Because newer SCA versions often have fields that older releases don't, the tool copies all the fields they share and uses default values for any new fields.
    

To use the Copy Configuration feature, select the origin domain and the destination domain, then click Copy Configuration.

In the procedure below:

-   **Origin Website/Domain** refers to the source configuration record. The tool copies the configuration record values from this website/domain, but doesn't change anything there.
    
-   **Destination Website/Domain** is the configuration record you're overwriting. The tool populates the field values from the origin record into this one.
    

Important:

This procedure overwrites the destination domain's configuration with the origin domain's setting. Copy to a test domain first (especially if you're copying from a Sandbox domain) before to copying to a production domain. Make sure that the configuration values you're copying match what you want for the destination domain.

#### To copy a SuiteCommerce Configuration record: {#procedure_1516389621}

1.  Go to _Commerce > Websites > Configuration_.
    
2.  Click **Copy Configuration**.
    
3.  Select the origin website from the **Origin Website** list.
    
4.  Select the origin domain from the **Origin Domain** list.
    
5.  Select the destination site from the **Destination Website** list.
    
6.  Select the destination domain from the **Destination Domain** list
    
7.  Click **Copy Configuration**.
    
8.  Optional: If you want to change any values in the destination SuiteCommerce Configuration record, see: [Configure Properties for a Domain](#subsect_1519942737).
    

Note:

The Copy Configuration function is a part of the SuiteCommerce Configuration bundle.
