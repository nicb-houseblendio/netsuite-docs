| Message | Message Type | Cause | Action |
| --- | --- | --- | --- |
| Live | Informational | Deployment successful, all processes complete. | None Note: You can't make changes to domain settings until the Deployment Status is **Live**. |
| Deployment in progress | Informational | DNS propagation underway. | None Note: NetSuite Hosting deployments take about 10 minutes. CDN deployments go live in up to 45 minutes. If this status has not changed after six hours, edit and save the NetSuite Domain record to redeploy it. |
| Pending | Informational | The domain record has been created but the certificate has not been uploaded. | Upload your SSL certificate. For more information, see [Manual Certificates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2485854.html). |
| Waiting for DNS configuration | Informational | DNS isn't configured with your domain provider. | Log in to your domain provider's website to update your DNS settings. Note: DNS configuration is a task that you complete outside of NetSuite. After you've configured your DNS, return to the Domain record page in NetSuite and click **Save** to redeploy it. |
| Removing | Informational | DNS switched to new provider, old provider being removed or the domain is in the process of being deleted. | None |
| Failed | Error | Deployment failed. This issue seldom occurs. Some internal error might have caused this issue. | Contact NetSuite Customer Support to resolve this issue. |
