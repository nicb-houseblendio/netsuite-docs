Depending on your license agreement, you can run multiple websites on the same NetSuite account. Each website can have its own branding, look, and feel, and you can use them for different purposes, like separate sites for different brands, countries, or languages.

If you have NetSuite OneWorld, your organization can use a single NetSuite account to manage records and transactions for multiple legal entities, or subsidiaries, conducting business across multiple tax jurisdictions, or nexuses, involving multiple currencies. You can associate multiple subsidiaries with a single Commerce website, or have multiple websites for each subsidiary.

Multiple languages and currencies are supported by default, and you can customize websites to add translated components.

See the following topics for more information about multi-sites:

-   [Multi-Site Development](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4364449525.html) - Learn how to set up multiple sites on one NetSuite account.
    
-   [SuiteCommerce and OneWorld](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1501264344.html) - See how to use NetSuite OneWorld with Commerce web stores.
    
-   [Localization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3825631277.html) - Find out how to set up and manage translated components in Commerce web stores.
