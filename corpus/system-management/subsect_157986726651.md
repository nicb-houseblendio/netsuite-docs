NetSuite has ended support for non-secure (HTTP) domains, so you need to secure all your domains. See [Secure Your Domain](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0603043411.html) for information about securing your domain.

All of the following domain types, that are available in NetSuite need to be secured with an SSL certificate.

-   **Single Domain for Web Store and Checkout** - lets you run your shopping and checkout on one secure HTTPS domain.
    
-   **Web Store Only** - also called shopping domains.
    
-   **Checkout Only** - these domains handle customer payment details. For more details, see [Link a Checkout Domain with Your Web Store](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157953243614.html).
    
-   **Hosted Web Page domains** - these domains point to a page hosted in your NetSuite File Cabinet.
    
-   **Redirect URL domains** - these domains redirect to a different website or page.
    
-   **Email Campaign domains** - these domains replace references to netsuite.com in your email and marketing templates.
    
-   **Promotional URL domains** - the domain a promotional URL redirects to.
    

How you secure these domain types depends on whether you use automatic or manual certificates. For information, see [Automatic and Manual Certificates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157538985860.html).
