**Action History** appears when you click the link in the popup window on the timeline. You can use these filters to limit the performance data shown:

-   Total Duration
    
-   User Event Time
    
-   Workflow Time
    

![Shows an example of performance data included in an Action History table as described in the corresponding table.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/SystemManagement/ScAPM/APM_ActionHistory.jpg)

Depending on the feature that you are using, the following columns appear in the **Action History** table:

| APM for Commerce Feature | Column | Description |
| --- | --- | --- |
| All | Open Icon | Opens the details page for that action's history. For more information, see [APM Action History Detail](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1559344080.html). |
| Date and Time | Shows when the action occurred. |
| Customization Performance | Shows the total duration of user event scripts and workflows as a graphic. Note: User event scripts and workflows are customizations. APM for Commerce features display the date and time when customization data was most recently available. |
| Total Duration | Shows how long the action took, including customizations like user event scripts and workflows. For more information about what the total duration covers, see [SuiteCommerce APM Action Sensors](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159845041822.html#bridgehead_160188591610). |
| User Event Scripts | Shows how long user event scripts took to run. Your developers can use this to spot and optimize any long-running scripts. |
| Workflow | Shows how long workflows took to run, so you can spot and adjust long-running ones. |
| Device | For SuiteCommerce APM, this shows the device type; for SuiteCommerce InStore APM, it shows the device ID. |
| SuiteCommerce InStore APM | Location | Shows the location where the action occurred. |
| Subsidiary | Shows the subsidiary where the action occurred. |
