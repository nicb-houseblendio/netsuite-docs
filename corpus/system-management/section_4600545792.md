The `cms_landing_page.tpl` file in the CMSadapter@x.x.x module controls the layout of your landing page. In the following screenshot, you can see the defined areas. The `cms_landing_page.tpl` file has one Page Type area and one This Page area. You can also see the header, footer, and breadcrumb areas that are defined in those modules.

![Shows the default areas on site landing pages as displayed in the Site Management Tools interface. The default areas are numbered 1 and 2.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/SystemManagement/SiteConfiguration/SMTLandingPageDefaultAreas.png)

| Item | Description |
| --- | --- |
| 1 | Page Type - `cms-landing-page-placeholder-page-type` |
| 2 | This Page - `cms-landing-page-placeholder-path` |
