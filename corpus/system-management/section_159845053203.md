Note:

This topic applies to SuiteCommerce and the 2020.1.1 release of SuiteCommerce Advanced and later.

The following scenarios are a guide to using Application Performance Management (APM) results to improve SuiteCommerce (SC) or SuiteCommerce Advance (SCA) performance:

-   [Scenario A - Placing an Order is Slow](#subsect_160070376172)
    
-   [Scenario B - Home Page is Slow](#subsect_160070383891)
    

## Scenario A - Placing an Order is Slow {#subsect_160070376172}

Follow these steps to fix slow order placement:

#### To resolve the scenario in SC APM

1.  Go to Customization > SuiteCommerce Performance > SuiteCommerce Action Diagnostics.
    
2.  Click the **Place Order** action tile.
    
3.  On the chart, look for times when scripts or workflows ran with the action.
    
4.  Click any point in time you're interested in to open the action history table.
    
5.  Review the logs on the table.
    
6.  For each log you want to check, click its open icon.
    
    This opens the SuiteCommerce Action History Details page for that log.
    
7.  Review the page to find out which SuiteApp, user event script, client script, or workflow is affecting performance.
    

## Scenario B - Home Page is Slow {#subsect_160070383891}

Follow these steps to fix a slow-loading home page:

#### To resolve the scenario in SC APM

1.  Go to Customization > SuiteCommerce Performance > SuiteCommerce Page Type Diagnostics.
    
2.  In the **Filters** panel, enter the information you want and click **Refresh**.
    
3.  On the **Content Display Times and Views Over Time** chart, click the time when the home page was slow to load.
    
    The Page Type Views table appears.
    
4.  Review the logs on the table.
    
5.  For each log you want to review, click its open icon.
    
    The Page View Details page opens for that log.
    
6.  On the Page View Details page, hover over resources that are taking the most time.
    
7.  Use the initiator type timings in the tooltip to see which load phases are slowing down the page.
