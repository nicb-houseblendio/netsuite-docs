This tab lets you access properties that may move to Site Management Tools or Extensions. The Legacy Tab is only available in SuiteCommerce implementations.

SuiteCommerce and SCA 2018.1 include the templates you need to access properties on the Legacy tab and subtabs. If you have an implementation of SCA 2018.2 release or later, you don't have the templates necessary to access these properties and you shouldn't use this tab.

This tab includes the following subtabs:

-   [Newsletter Subtab](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1532356695.html)
    
-   [Footer Subtab](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1532357301.html)
