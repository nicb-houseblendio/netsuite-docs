After you've created a Cache Invalidation Request, you can check its progress on the Cache Invalidation Status page. The Cache Invalidation Status page shows the status of all cache invalidation requests. If there are too many cache invalidation entries on the page, you can find the cache invalidation request you're looking for by filtering on the following fields: Submitted Date and Time, Request Type, Domain Name, User Name, and Status.

#### To view the status of a cache invalidation request:

1.  Go to _Commerce > Content Management > Cache Invalidation Requests_.
    
    You'll see the Cache Invalidation Status page with a list of cache invalidation requests.
    
    Note:
    
    You can also check the status of a Cache Invalidation Request by clicking **Cache Invalidation Status** on the Cache Invalidation Request page.
    
2.  (Optional) To filter the list of cache validation requests:
    
    1.  Expand **Filters** on the Cache Invalidation Status page.
        
    2.  Use these fields to filter the list of cache invalidation requests:
        
        -   **Date Submitted** - Filter the list to show only requests in the specified date and time range.
            
        -   **Request Type** - Filter the list to show only Automatic requests, Manual requests, or both.
            
        -   **Domain** - Filter the list to show only the selected domains.
            
        -   **User** - Filter the list to show only the selected user.
            
        -   **Status** - Filter the list to show only requests that are Processed, In Progress, Failed, or any combination of these statuses.
            
    3.  (Optional) Click **Reset** to return all filter fields to their default values.
        
    4.  Click **Filter Requests**.
