The following table shows the template files, data-view, and CMS placeholders for the checkout area of your SuiteCommerce theme.

| Area | Template | Data-View | CMS | Placeholder | Location |
| --- | --- | --- | --- | --- | --- |
| ACH Payment Wizard | payment\_wizard\_paymentmethod\_ach\_module.tpl |  |  |  |  |
| Log in | Register | login\_register\_login.tpl | x | \- | Login.CustomFields | After the password input |
| \- | x | Register.CustomFields | After the login form |
| New Customer | login\_register\_register.tpl | x | \- | Scope:Path | After the re-entering password input |
| \- | x | Scope:Path | After the register form |
| Order Wizard Cart Module | order\_wizard\_cart\_summary.tpl | x | \- | OrderWizardSummary.AfterTitle | After .order-wizard-cart-summary-title |
| x | \- | OrderWizardSummary.AfterSubtotal | After .order-wizard-cart-summary-subtotal |
| x | \- | OrderWizardSummary.AfterTotal | After .order-wizard-cart-summary-total |
| Order Wizard Confirmation Page | order\_wizard\_confirmation\_module.tpl | x | \- | OrderWizard.AfterConfirmation | .orderwizard.module.confirmation |
| Order Wizard Payment Method Module | order\_wizard\_paymentmethod\_selector\_module.tpl | x | \- | OrderWizard.AfterPaymentMethods | .order-wizard-paymentmethod-selector-module |
| Order Wizard Shipping Address Module | order\_wizard\_address\_module.tpl | x | \- | OrderWizard.AfterShippingAddresses | .order-wizard-address-module-placeholder |
| Order Wizard Shipping Method Module | order\_wizard\_shipmethod\_module.tpl | x | \- | OrderWizard.AfterShippingMethods | order-wizard-shipmethod-module |
