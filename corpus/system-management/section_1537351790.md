If your business uses more than one currency, you must configure multiple currencies as part of your initial accounting setup. This lets you create transactions for foreign customers and vendors you work with. The currency used to manage your company's financials is called the base currency, and other currencies used by customers and vendors are called foreign currencies. With NetSuite OneWorld, each subsidiary can have a separate base currency, which is used to manage the subsidiary's financials.

#### To set up Multi-Currency for your Commerce site:

1.  Enable the Multiple Currencies feature. See [Enabling the Multiple Currencies Feature](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1395677.html).
    
2.  (Optional) Define additional currencies in NetSuite. By default, CAD, EUR, GBP, and USD currencies are available in NetSuite. To define additional currencies, see [Creating Currency Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1395911.html).
    
    Note:
    
    Ensure that you select the correct default locale on the currency record to avoid errors related to currency mismatch. For example, select New Zealand (English) as the default locale for New Zealand Dollar.
    
3.  Set the base currency for your subsidiary as described in [Setting a Base Currency](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1397082.html).
    
4.  Configure the exchange rates so that the prices are dynamically updated based on the shopper's default currency. See [Adding Rates to the Currency Exchange Rates List](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1401868.html).
    
5.  Associate your Commerce site with a subsidiary. You can associate multiple subsidiaries with a Commerce site. However, only the subsidiary selected as the default shows up on the website. See [SuiteCommerce and OneWorld](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1501264344.html).
    
6.  Set the chosen subsidiary's base currency as the default currency. Prices are displayed in the default currency for new shoppers visiting your website.
    
    To set the currencies for your website, do the following:
    
    1.  In NetSuite, go to _Commerce > Websites > Website List_.
        
    2.  At the bottom of the **Shopping** tab, click the **Currency** subtab.
        
    3.  In the Default column, select the radio button for the default currency. Also, ensure that the box is checked in the Online column.
        
    4.  In the Online column, select the box for each currency in which you want to display item prices on your website.
        
        The selected currencies appear in the Currency Selector list, which allows a shopper to switch from the default currency to other available currencies.
        
    5.  Click **Save**.
        

## Shopper Currency Selection {#subsect_161840850867}

Guest shoppers and registered shoppers who haven't yet placed their first order can choose their preferred currency from the Currency Selector list. The website shows prices in the currency they select.

After registered shoppers place their first order, the currency of the order becomes their default currency. Prices on the website are shown in their default currency and they can no longer choose a different currency from the Currency Selector list.
