This property on this subtab lets you set which item option fields control the final image for the selected product on the Product Description Page (PDP). In SuiteCommerce and the Elbrus release of SCA and later, you can set up two or more item option IDs for image changes.

More Information: [(Optional) Configure Multi-Image Options](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162137343254.html#subsect_162137376332)

| **ID** | productline.multiImageOption |
| --- | --- |
| **UI location** | Shopping Catalog > Multi-Image Option |
| **UI location (pre-Elbrus)** | Layout > Images |
| **JSON file** | ProductLine.MultiImages.json |
| **Configuration file (pre-Vinson)** | SC.Shopping.Configuration.js |
