A Commerce website license includes a fixed number of secure domain licenses. You need to secure all the domains you use for your Commerce website.

Each license covers one secure domain. For example, if to set up three domains to support three different languages and currencies on your website, you can set them up as follows:

-   Language A - Combined Web Store and Default Checkout domain (uses one secure domain license)
    
-   Language B - Combined Web Store and Default Checkout domain (uses another secure domain license)
    
-   Language C - Secure Web Store domain with Custom Checkout domain (uses two secure domain licenses)
    

If you need more secure domain licenses, contact your account manager.

## Free Up a Secure Domain License {#subsect_1534512108}

You can free up a license already in use by replacing the Custom Checkout domain with a default checkout subdomain. To do this, follow the steps in the [To set up a secure subdomain for checkout:](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157953243614.html#procedure_N2485452) procedure to replace the custom checkout domain with a default checkout subdomain.

Warning:

If any of your custom scripts or features have the checkout domain name hard coded, make sure you update them first. Otherwise, they might stop working when you switch to the default checkout subdomain.

When you have a free secure domain slot available, you can use it to set up a secure Web Store domain or combined Web Store and Checkout domain.
