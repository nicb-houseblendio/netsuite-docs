Note:

NetSuite has ended support for non-secure (HTTP) domains. See [Secure Your Domain](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0603043411.html).

Setting up any domain type in NetSuite works the same way. However, the information you enter in the Domain record depends on the domain type you select.

#### To set up a domain: {#procedure_1524487340}

1.  Go to _Commerce > Hosting > Domains > New_.
    
2.  Select the type of domain you want to create from the **Domain Type** list. The options are:
    
    -   Single Domain for Web Store and Checkout
        
    -   Web Store Only
        
    -   Checkout Only
        
    -   Hosted Web Page
        
    -   Redirect URL
        
    -   Promotional URL
        
    -   E-mail Campaign
        
    
    See [Set Up Domains for Web Stores](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2484898.html) for information about each of these domain types.
    
    Tip:
    
    You can also add or manage domains from the Website Setup record.
    
    -   Go to Commerce > Websites > Website list and click **Edit** next to the website for which you want to add or manage domains.
        
    -   Go to the **Domains** tab.
        
    -   Click **Add New Domain** or **Manage Domains**.
        
    
3.  In the **Domain Name** field, enter the domain URL without https://. For example: www.example.com. The domain name can contain up to 64 characters.
    
    In the DNS area, the **CNAME** records populate automatically for the hosting and DNS verification records using the value you enter in the **Domain Name** field.
    
    Use these CNAME records to configure DNS settings with your domain name provider. You should configure DNS settings before you finish setting up the domain record in NetSuite. For more information, see [Point Your Domain Name at Your Domain (DNS Settings)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2479403.html).
    
    Important:
    
    Always point your domain names to a CNAME record. Make sure CNAME records are set up correctly to avoid problems with SSL certificates and domain security.
    
4.  The domain type you selected in Step 2 determines which of the following fields are displayed on the domain setup form. Fill in all visible fields as follows:
    
    -   **Web Site** - Select from the list the website that uses the domain name.
        
        This list shows all websites in your NetSuite account that work with the domain type you selected.
        
    -   **Hosting Root** - Select **Live Hosting Files** for a live site or **Staging Hosting Files** for a test site. For information about setting up a domain name for a test site, see the following help topics:
        
        -   SuiteCommerce, SuiteCommerce MyAccount, and SuiteCommerce Advanced (SCA) Aconcagua and later - [Test a Theme on a Local Server](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1497015355.html) and [Test an Extension on a Local Server](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510870075.html).
            
        -   SCA (pre-Aconcagua) - [Test SCA Customizations on a Local Server](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4305360627.html).
            
        -   Site Builder - [Website Staging Environment](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2599525.html).
            
    -   **Use CDN Cache** - Check this box to cache your Commerce web store data on the content delivery network (CDN). This helps your website load faster.
        
        Important:
        
        Before you choose CDN caching for your checkout domain, review the information about prerequisites, caching, and IP address ranges in [CDN Caching for Secure Domains](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4749904289.html). For more information, see [CDN Caching](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4411360163.html) and [Configure CDN Caching](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3937695730.html).
        
        You need to set up CDN caching in NetSuite. Third-party CDN setups aren't supported.
        
    -   **Maintenance Content Folder** (optional) - Select the custom site maintenance folder you want to use if your site is down for repairs or routine updates.
        
        For more information about setting up a custom site maintenance page, see [Custom Maintenance Folder and Content](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_7112636199.html).
        
    -   **Not-Found Page** (optional) - Select the hosted page where customers are directed if they go to an inactive page. By default, they're redirected to your home page.
        
        Start by entering the page name, then press **Tab** or click the down arrow for a list of pages.
        
    -   **Home Page** - If you're setting up a Hosted Web Page domain, select the file from your File Cabinet that the domain name should point to.
        
    -   **Redirect URL** - If you're setting up a redirect URL domain:
        
        -   In the **Redirect URL** field, enter the URL of the web page or site where you want to redirect visitors.
            
        -   Check the **Include File Path and Parameters in the Redirect** box if you want to preserve the original path when redirecting visitors to the Redirect URL domain.
            
            If you check this box, `https://www.example1.com/product-a?param=1` redirects to `https://www.example2.com/product-a?param=1`.
            
            If you don't check this box, `https://www.example1.com/product-a?param=1` redirects to `https://www.example2.com`.
            
5.  To secure your domain with an SSL certificate, complete the steps provided in the help topic, [Secure Your Domain](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0603043411.html). All domain types used in NetSuite need to be secured.
    
    You need to enter the domain name in the **Domain Name** field before you download the CSR.
    
    Important:
    
    Make sure CNAME records are always set up correctly to avoid problems with SSL certificates and domain security.
    

As required, follow the steps outlined in these topics to complete the domain setup process:

-   [Secure Your Domain](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0603043411.html)
    
-   [Deploy Your Domain](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0603043220.html)
    
-   [Set Up DNS Verification](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0603035652.html)
    
    Note:
    
    Setting up DNS verification is only required for secure domains.
