The `item_details.tpl` template file in the ItemDetails@x.x.x module controls the layout of your item detail pages. The `item_details.tpl` file has three Page Type areas and one This Page area.

![Shows the default areas on the item details page as displayed in the Site Management Tools interface. The areas are numbered 1 through 4.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/SystemManagement/SiteConfiguration/itemDetailPageDefaultAreas.png)

| Item | Description |
| --- | --- |
| 1 | Page Type - `item_details_banner` |
| 2 | This Page - `item_info` |
| 3 | Page Type - `item_info_bottom` |
| 4 | Page Type - `item_details_banner_bottom` |
