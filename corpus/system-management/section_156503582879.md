The following settings configure the SuiteBilling Subscriptions for Commerce feature:

-   Subscription Line Status Change
    
-   Allow the User to Cancel/Suspend Required Lines
    
-   Subscription General Status Change
    
-   Disallow the User to Upgrade Quantity
    
-   Disallow the User to Downgrade Quantity
    

More information: [Subscriptions for Commerce Websites](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_156079542004.html)

## Subscription Line Status Change {#subsect_158808925310}

This setting works with:

-   SuiteCommerce Advanced - 2019.2 and later
    
-   SuiteCommerce
    
-   SuiteCommerce MyAccount
    

This string lets you choose if shoppers can:

-   Suspend and resume a subscription line item
    
-   Cancel a subscription line item
    
-   Change the status of a subscription line item
    

| **ID** | subscriptions.lineStatusChange |
| --- | --- |
| **UI location** | My Account > Subscriptions |
| **JSON file** | subscriptions.json |
