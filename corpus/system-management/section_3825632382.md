SuiteCommerce Advanced supports the `locale` tag, so you can deliver localized content generated from the Content Delivery bundle.

#### To localize content generated from the Content Delivery bundle:

1.  Create a new Content Record for each localized version you want to display.
    
    For details on how to create a Content Delivery record see [Creating a Content Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2689968.html).
    
2.  Tag each record with the corresponding locale attribute.
    
    For example, to specify a record as the American English version, use the locale tag **locale:EN\_us**. The locale attribute must match the language/locale parameters set by the system when languages are enabled.
    
    ![Shows how to set the locale in the content tag of a record.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/SystemManagement/Microsites/ref_LocaleTag.PNG)
    
    See [Using Content Delivery](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2689412.html) for more information about setting up your site for content delivery.
