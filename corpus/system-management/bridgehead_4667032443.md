Important:

Google Analytics 4 (GA4) has replaced Google Universal Analytics (GAU) as Google's cross-platform Analytics solution. All standard GUA properties stopped processing new hits on July 1, 2023. 360 Universal Analytics properties will stop processing new hits on July 1, 2024. See [Google Analytics 4 Subtab](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0930101732.html) for information about configuring GA4.

These settings configure properties for Google Universal Analytics. Google Universal Analytics is a third party analytics solution that can help you evaluate traffic on your website using data based on visitor tracking information.

More Information: [Configuring GUA](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3819647146.html)

## Google Universal Analytics ID {#bridgehead_4700682695}

This string lets you define the Google Universal Analytics Tracking ID.

The application inserts this property into each page of the application. To find your tracking ID, login to your Google Analytics account and go to Admin > Property > Property Settings.

More Information: [Set Up GUA Account and Website Property](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3819647146.html#bridgehead_4538182356)

| **ID** | tracking.googleUniversalAnalytics.propertyID |
| --- | --- |
| **UI location** | Integrations > Google Universal Analytics |
| **JSON file** | GoogleUniversalAnalytics.json |
| **Configuration file (pre-Vinson)** | SC.Checkout.Configuration.js |

## Google Universal Analytics Domain {#bridgehead_4700686846}

This string lets you define the unencrypted (not secure) domain hostname used for Google Universal Analytics.

If you use different domains for shopping and checkout, enter the hostname of the shopping domain in this field.

Example: `shopping.example.com`

If you use one secure domain for shopping and checkout, leave this field blank. See [Set Up Domains for Web Stores](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2484898.html) for additional information.

More Information: [Configuring GUA](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3819647146.html)

Note:

If you're using SuiteCommerce Advanced Mont Blanc or later, use Google Tag Manager to set up your tracking codes. See [Google Tag Manager](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4546835898.html).

| **ID** | tracking.googleUniversalAnalytics.domainName |
| --- | --- |
| **UI location** | Integrations > Google Universal Analytics |
| **JSON file** | GoogleUniversalAnalytics.json |
| **Configuration file (pre-Vinson)** | SC.Checkout.Configuration.js |

## Google Universal Analytics Secure Domain {#bridgehead_4700687276}

This string lets you define the encrypted (secure) domain hostname used for Google Universal Analytics.

If you use one secure domain for both shopping and checkout, leave this field empty.

If you have a custom checkout domain, enter its hostname in this field.

Example: `checkout.example.com`

If you use NetSuite for your checkout domain, enter `netsuite.com` in this field.

See [Set Up Domains for Web Stores](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2484898.html) for additional information.

Note:

If you're setting up SuiteCommerce MyAccount, use one secure domain and enter its URL in this field.
