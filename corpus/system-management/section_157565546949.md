The following table lists all NetSuite records that support Execute as Role permissions. This table has:

-   record names
    
-   supported operations (whether the record can be created, loaded, edited, and deleted searched)
    
-   links to information on using the record in the UI
    

Note:

Records not included in this table may also support Execute as Role permissions, particularly for Read operations. However, such records have not been tested nor confirmed to work with Execute as Role permissions.
