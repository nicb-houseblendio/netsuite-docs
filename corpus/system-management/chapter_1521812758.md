The simplest way to set up an online store in NetSuite is to create a Single Domain for Web Store and Checkout domain and secure it using an automatic certificate. This keeps both shopping and checkout activities on the same domain, so it's faster and more efficient. It's also easier to maintain because automatic certification means Oracle NetSuite takes care of renewing your certificate for you.

However, in some cases, you might want to keep your web store and checkout on different domains. For details on how this setup works, see [Web Store Sessions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4258773946.html).

You may also prefer to obtain a certificate from your preferred certificate authority. For details on how to do this, see [Manual Certificates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2485854.html).
