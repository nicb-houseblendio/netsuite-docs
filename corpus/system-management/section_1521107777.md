You need domains for different purposes in NetSuite. All domain types available in NetSuite can and must be secured. See [Secure Your Domain](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0603043411.html).

When you're setting up an online store where your customers can browse and buy products, the following domain types are available in NetSuite:

-   **Web Store Only** - also called the shopping domain, this is your main website where users can browse products. On its own, a web store domain acts as a product catalog. Customers can browse, but they can't buy anything. If you want customers to buy products, you need to link the web store domain with a Checkout domain.
    
-   **Checkout Only** - this is where users buy products, and where you collect payment details.
    
-   **Single Domain for Web Store and Checkout** - this combines both web store and checkout functions into one secure domain, so customers can browse, add items to their basket, and check out securely.
    
    Note:
    
    If you're using SuiteCommerce MyAccount, set the **Domain Type** to **Single Domain for Webstore and Checkout**.
    

Depending on what you need, you can set up one or more of these domain types for your web store. For more information, see [Domain Options for Web Stores](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1521216758.html).

You can also set up the following domains to add extra features to your website:

-   **Email Campaign** - the domain you use to replace references to netsuite.com in your email and marketing templates. You'll need this if you send more than 10,000 emails a month. For more information, see [Website Domains and Email Hosting](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4322255829.html) for more information.
    
-   **Hosted Web Page** - the domain that points to a page in your NetSuite File Cabinet.
    
-   **Promotional URL** - the domain that a promotional URL redirects to. It can be the same as your shopping domain or a separate one. For more details, see [Promotional URLs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N1016228.html).
    
-   **Redirect URL** - the domain where URLs are redirected to, either to a different domain or another page. For more information, see [SEO and Redirects](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2637891.html).
