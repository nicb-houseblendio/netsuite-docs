SuiteCommerce Page View Details shows info about web resources and their timings for the exact time a user viewed the page.

![Shows the visual elements included in a Page View Details dashboard as described in the corresponding table.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/SystemManagement/ScAPM/SCAPM_PageViewDetails.jpg)

The following elements are available on the dashboard:

| Item | Information | Description |
| --- | --- | --- |
| 1 | Header | Shows the following information about the page:
-   **Domain**\- Shows the website's domain.
-   **URL Fragment**\- Shows the URL fragment that locates the page.
-   **Web or Modal Address**\- Shows the full URL of the page the user viewed.
-   **Content Display Time**\- Shows how long it took to update page content for the user's action.
-   **Navigation Type and Device**\- Shows how the user viewed the page and what device they used.
-   **Current SuiteApp**\- Shows the current SuiteCommerce SuiteApp name and version.

 |
| 2 | Resource Timing Chart | Shows website resources and when they loaded. Hover over a bar in the chart to see what triggered the resource. The tooltip shows the timing of the following load phases:

-   **DNS**\- Refers to Domain Name System and shows the time it took to access the web address.
-   **TCP**\- Refers to Transmission Control Protocol and shows the time it took to properly establish a connection.
-   **TTFB**\- Refers to Time to First Byte and shows the time it took for the browser to get the first byte from the server.

 |
