These settings let you control how lists of data and collections are displayed. The ListHeader module uses these settings.

## Filter Range Quantity Days {#bridgehead_4700662603}

This integer lets you set how many days are included in the date range when displaying data.

| **ID** | listHeader.filterRangeQuantityDays |
| --- | --- |
| **UI location** | My Account > List Header |
| **JSON file** | ListHeader.json |
| **Configuration file (pre-Vinson)** | SC.MyAccount.Configuration.js |
