This section explains how to create a custom configuration file. This is useful when creating custom configuration properties for your extension. When you deploy your extension to NetSuite and activate it for a domain, the SuiteCommerce Configuration record user interface shows any new additions.

Note:

If you're using the Kilimanjaro release of SCA or earlier, these changes happen after you deploy your custom modules. If you're using the Mont Blanc release of SCA or earlier, you need to customize the configuration JavaScript files to make any changes. See [Develop Your SCA Customization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3705381013.html) for details.
