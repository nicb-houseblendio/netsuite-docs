Note:

This topic applies to SuiteCommerce and the 2020.1.1 release of SuiteCommerce Advanced and later.

Application Performance Management (APM) for Commerce SuiteApps, SuiteCommerce APM and SuiteCommerce InStore APM, are managed SuiteApps. They are installed separately from the APM SuiteApp and other Commerce SuiteApps.

You can install these SuiteApps in both OneWorld and non-OneWorld accounts.

After installing either APM for Commerce SuiteApp, updates and enhancements are pushed to your account automatically, and you don't need to update them manually.

Use one of these options to install the SuiteApp you need:

-   [Installing the SuiteCommerce APM SuiteApp](#subsect_159899891336)
    
-   [Installing the SuiteCommerce InStore APM SuiteApp](#subsect_159899879249)
    

## Installing the SuiteCommerce APM SuiteApp {#subsect_159899891336}

Follow these steps to install the SC APM SuiteApp:

#### To install SC APM from the SuiteApp Marketplace:

1.  Go to SuiteApps.
    
2.  In the Search field, enter **APM for SuiteCommerce**.
    
3.  Click the SuiteApp tile.
    
    This opens the SuiteApp details page.
    
4.  Click **View SuiteApp**.
    
    This opens the Bundle Details page.
    
5.  Click **Install**. Click **OK**.
    
6.  Click **Install Bundle**. Click **OK**.
    
7.  The Installed Bundles page has a **Status** column to show the installation progress.
    
    Click **Refresh** to update the status. The column shows a green check mark when the installation's done.
    

## Installing the SuiteCommerce InStore APM SuiteApp {#subsect_159899879249}

Follow these steps to install the SCIS APM SuiteApp:

#### To install SCIS APM:

1.  Go to Customization > SuiteBundler > Search & Install Bundles.
    
2.  In the **Keywords** field, enter the Bundle ID: **267306**.
    
3.  Verify that the search result lists **SuiteCommerce InStore APM.**
    
4.  Click the bundle name.
    
    This opens the Bundle Details page.
    
5.  Click **Install**. Click **OK**.
    
6.  Click **Install Bundle**. Click **OK**.
    
7.  The Installed Bundles page has a **Status** column to show installation progress.
    
    Click **Refresh** to update the status. The column shows a green check mark when the installation is done.
    
    Note:
    
    You might need to scroll to the bottom to find the SuiteCommerce InStore APM bundle and check its status. The installation could take some time.
    

After installing the APM for Commerce SuiteApp you need, grant roles and employees permission to use it. For more information, see [Granting Access to APM for Commerce Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1560549187.html).
