These settings configure properties related to the Google Tag Manager.

More: [Google Tag Manager](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4546835898.html)

## Google Tag Manager ID {#bridgehead_4700688369}

This string lets you define the Google Tag Manager ID. Setting this property enables this feature on your Commerce site.

More Information: [Sign Up for Google Tag Manager](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1525975256.html#subsect_1549550438)

| **ID** | tracking.googleTagManager.id |
| --- | --- |
| **UI location** | Integrations > Google Tag Manager |
| **JSON file** | GoogleTagManager.json |
| **Configuration file (pre-Vinson)** | SC.Configuration.js |

## Google Tag Manager Data Name {#bridgehead_4700688692}

This string sets the data layer object that contains all of the information that you want to send to Google Tag Manager.

| **ID** | tracking.googleTagManager.dataLayerName |
| --- | --- |
| **UI location** | Integrations > Google Tag Manager |
| **JSON file** | GoogleTagManager.json |
| **Configuration file (pre-Vinson)** | SC.Configuration.js |

## Is A Multi-Domain Site? {#subsect_1543500959}

This property works with:

-   SuiteCommerce Advanced - 2018.2 and later
    
-   SuiteCommerce
    

This boolean lets you specify if you're using different domains for shopping and checkout. Enable this option to preserve data between sessions when you use separate domains for shopping and checkout.

| **ID** | tracking.googleTagManager.isMultiDomain |
| --- | --- |
| **UI location** | Integrations > Google Tag Manager |
| **JSON file** | GoogleTagManager.json |
