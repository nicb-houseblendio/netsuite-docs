These settings configure Google AdWords.

More Information: [Google Ads](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4429358327.html)

## Google AdWords ID {#bridgehead_4700724745}

This string is your Google AdWords ID, which matches the conversion tag you set up in your AdWords account.

| **ID** | 2019.2 and later: tracking.googleAdWordsConversion.id 2019.1 and earlier: googleAdWordsConversion.id |
| --- | --- |
| **UI location** | 2019.2 and later: Integrations > Adwords 2019.1 and earlier: Integrations > Google Adwords |
| **JSON file** | GoogleAdWords.json |
| **Configuration file (pre-Vinson)** | 
SC.Shopping.Configuration.js

SC.MyAccount.Configuration.js

SC.Checkout.Configuration.js



 |
