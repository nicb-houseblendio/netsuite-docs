In SuiteCommerce Advanced (SCA) Aconcagua and earlier, this subtab is located under the **Shopping** tab. In SCA 2018.2 and later, it's not available.

This feature and its settings work with:

-   SuiteCommerce Advanced - Vinson, Elbrus, Kilimanjaro, or Aconcagua
    
-   SuiteCommerce 2018.1
    

The following settings control the Newsletter opt-in feature.

If a user signs up for the newsletter and there's no matching Customer or Lead records in NetSuite, the application creates a new Lead record. SCA then sets this new record's **Global Subscription Status** to Soft Opt-In. However, NetSuite requires a **Name** or **Company Name** for the new lead, and you set these values. By default, each field is set to **unknown**.

If a user signs up for the newsletter and there's no matching Customer or Lead records in NetSuite, the application creates a new Lead record. SCA then sets this new record's **Global Subscription Status** to **Full Subscription (Not opted in; send all messages)**. However, NetSuite requires a **Name** or **Company Name** for the new lead, and you set these values. By default, each field is set to **unknown**.

More Information: [Newsletter](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4640365472.html)
