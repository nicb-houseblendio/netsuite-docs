The Escape to Login feature is available in SuiteCommerce Advanced Elbrus and later.

This feature lets you specify if you want to access Site Management Tools by pressing the escape key or by going to the admin URL. For more information, see [Configuring Access to Site Management Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4787945118.html).

#### To enable or disable escape to login:

1.  Go to Commerce > Websites > Configuration.
    
2.  Select your website and domain, then click **Configure**.
    
3.  In the SuiteCommerce Configuration record, go to the **Integrations** tab and then the **Site Management Tools** subtab.
    
4.  Check the **Disable Esc Key to Login** box to disable the Escape key for logging in. You can clear the box to enable the Escape key for logging in.
