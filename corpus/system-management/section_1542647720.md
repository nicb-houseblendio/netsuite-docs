Important:

The Content Delivery Service is only supported up to the Denali R2 (revision 2) release of SuiteCommerce Advanced. After that, you should use Site Management Tools for SuiteCommerce and for the Mont Blanc release and later.

In some cases, you might not be able to access the Content Delivery page and instead receive the following error:

`Permission Violation: You need the 'Lists -> Documents and Files' permission to access this page. Please contact your account administrator.` This only applies to the Denali or Denali R2 implementations of SuiteCommerce Advanced.

If you see this error, you must edit the Script Deployment record for **NS CD - SL - Content Management Menu**.

#### To update the script deployment record:

1.  In NetSuite, go to Customization > Scripting > Script Deployments.
    
2.  Set the **Type** filter to **Suitelet**.
    
3.  Click **Edit** next to the **NS CD - SL - Content Management Menu** script (ID: customdeploy\_cds\_sl\_main\_menu).
    
4.  Change the **Execute as Role** field to **Administrator**.
    
5.  Save the record.
