SuiteScript 2.0 SSP applications must be explicitly deployed to websites and domains; unlike SuiteScript 1.0 SSP applications, they are not available by default. You can deploy to a single domain, or you can deploy to all the domains on a website.

It is important to remember that only one SSP application can be deployed to one URL root per domain. If you want to deploy an SSP application to a URL root at which an SSP application is already deployed, you must first undeploy the existing application before you can deploy the new one.

#### To deploy an SSP application to a single domain:

1.  Go to _Commerce > Hosting > SSP Applications_.
    
2.  Click **View** next to the SSP application.
    
3.  Click **Deploy to Domain.**
    
4.  Select the domain to which you want to deploy from the **Domain** list.
    
5.  Click **Save**.
    

#### To deploy an SSP application to all custom domains associated with a website:

1.  Go to _Commerce > Hosting > SSP Applications_.
    
2.  Click **View** next to the SSP application.
    
3.  Click **Deploy to Site.**
    
4.  From the:
    
    -   **Deploy to Checkout Domain on Site** list - select the site to whose checkout domain you want to deploy the SSP application.
        
    -   **Deploy to all Shopping Domains on Site** list - select the site to whose shopping domains you want to deploy the SSP application.
        
    
    If you want to deploy the SSP application to the checkout domain of one site and the shopping domains of the other, you can select different site names from the lists. Alternatively, if you want to deploy to just the checkout domain or just shopping domains, select **\- Do Not Deploy -** for the domain type to which you do not want to deploy.
    
5.  Click **Save**.
    

#### To undeploy an SSP application:

1.  Go to _Commerce > Hosting > SSP Applications_.
    
2.  Click **View** next to the SSP application.
    
3.  On the Deployments tab, click on one of the following subtabs
    
    -   Site Shopping - if the SSP application is deployed to all shopping domains of the site.
        
    -   Site Checkout - if the SSP application is deployed to the site checkout domain.
        
    -   Domain - if the SSP application is deployed only to specific domains.
        
4.  Click **Undeploy** next to the SSP application you want to undeploy.
