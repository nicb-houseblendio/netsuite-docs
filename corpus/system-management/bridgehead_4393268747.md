These settings control the application header's properties.

## Hide Currency Selector {#bridgehead_4700680204}

This boolean lets you hide or display the currency selector in the application. Enable this property to hide the selector.

| **ID** | header.notShowCurrencySelector |
| --- | --- |
| **UI location** | Layout > Header |
| **JSON file** | Header.json |
| **Configuration file (pre-Vinson)** | SC.Checkout.Configuration.js |

## Logo URL {#bridgehead_4700680571}

This string lets you specify the location of the logo image file that's displayed at the top of the application.

| **ID** | header.logoUrl |
| --- | --- |
| **UI location** | Layout > Header |
| **JSON file** | Header.json |
| **Configuration file (pre-Vinson)** | SC.Checkout.Configuration.js |

## Show Recognized Shopper {#subsect_156693606282}

This boolean lets you enable or disable the show recognized shopper feature when a session times out.

| **ID** | header.showRecognizedShopper |
| --- | --- |
| **UI location** | Layout > Header |
| **JSON file** | Header.json |
