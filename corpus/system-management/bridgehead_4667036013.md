These settings control Twitter popup settings.

More Information: [Twitter Cards](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3971318111.html)

## Enable {#bridgehead_4695830601}

This boolean lets you control if the Twitter addThis property is enabled.

| **ID** | twitter.enable |
| --- | --- |
| **UI location** | Integrations > Twitter |
| **JSON file** | twitter.json |
| **Configuration file (pre-Vinson)** | SC.Shopping.Configuration.js |
