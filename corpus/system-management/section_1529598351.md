SuiteScript 2.0 SSP applications must be explicitly made available on websites and domains; unlike SuiteScript 1.0 SSP applications, they are not available by default.

#### To make an SSP Application available on your system domain:

1.  Go to _Commerce > Hosting > SSP Applications_.
    
2.  Click **Edit** next to an SSP application.
    
3.  Check **Available on System Domain**. System domains are those that have the format `system.netsuite.com`.
    
4.  Save the SSP application record.
    

To learn how to deploy an SSP application record to one or more custom domains, see [Deploy and Undeploy SSP Applications](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1529598384.html).
