SuiteCommerce Advanced (SCA) supports using multiple website records, each with its own domain, or multiple domain configurations pointing to the same website record. When using multiple website records, you must configure item records to appear on each website. See [Item Availability](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2656387.html) for more information. When you use multiple domains, each domain uses the same website record. All items configured for that website are available to both domains.
