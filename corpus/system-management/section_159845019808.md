Note:

This topic applies to SuiteCommerce and the 2020.1.1 release of SuiteCommerce Advanced and later.

See performance data at a glance on the various dashboards available with Application Performance Management (APM). The following table lists the dashboards you can use.

Note:

APM tools display data from up to 30 days ago-the 30-day limit is also the max in the time interval dropdown. You can try to get data from farther back by customizing the date range, but the page only shows it if still available.

| APM for Commerce Feature | Dashboards | Description | Navigation |
| --- | --- | --- | --- |
| SuiteCommerce APM (SC APM) | SuiteCommerce Performance Dashboard | See high-level info about the SuiteCommerce SuiteApp you're using, plus view counts and statistics for each page type and action on your site. For more information, see [SuiteCommerce Performance Dashboard](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159845028175.html). | Go to Customization > SuiteCommerce Performance > SuiteCommerce Performance Dashboard. |
| SuiteCommerce Page Type Diagnostics | See detailed timing and view counts for specific web and modal addresses on the page type you want to investigate. For more information, see [SuiteCommerce Page Type Diagnostics](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159921851331.html). | Choose from the following:
-   On the SuiteCommerce Performance Dashboard page, click a row on the Page Type portlet.
-   Go to Customization > SuiteCommerce Performance > SuiteCommerce Page Type Diagnostics.

 |
| SuiteCommerce Page View Details | See information about web resources and their timings for a specific time a user viewed the page. For more information, see [SuiteCommerce Page View Details](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160022165365.html). | To open the page: 1. Go to SuiteCommerce Page Type Diagnostics. 2. On the Content Display Times and Views Over Time chart, click a point. 3. In the Page Type Views table, click the corresponding open icon. |
| SuiteCommerce Action Diagnostics | See information about actions users took on the website and domain you want to check. For more information, see [SuiteCommerce Action Diagnostics](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159921855052.html). | Choose from the following:

-   On the SuiteCommerce Performance Dashboard page, click an action tile on the Actions portlet.
-   Go to Customization > SuiteCommerce Performance > SuiteCommerce Action Diagnostics.

 |
| SuiteCommerce InStore APM (SCIS APM) | SuiteCommerce InStore Performance Diagnostics | See high-level information about actions sales associates performed using SCIS as a point-of-sale solution. For more information, see [SuiteCommerce InStore Performance Diagnostics](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1559343806.html). | Go to Customization > SCIS Performance > SCIS Performance Diagnostics. |
