SuiteCommerce rehydration provides the following performance and user-experience benefits:

-   **Faster first render** - Pages can show meaningful content faster by displaying prerendered HTML right away. This can improve user-perceived load speed and web page performance metrics, such as First Contentful Paint (FCP) performance.
    
    Note:
    
    FCP is how long it takes for a page to display any content.
    
-   **Reduced flickering during first load** - The main page view reuses the existing prerendered page structure rather than discarding or recreating it.
    
-   **More stable page areas during hydration** - Sections inside the page (for example, data-driven content views) can be kept in place so they don't flash or redraw as the page becomes interactive.
    
-   **Better control of out-of-date content** - Areas that might be stale (for example, prices or stock status) can be hidden or masked until fresh data is loaded, reducing the chance of displaying incorrect information. See [How SuiteCommerce Rehydration Addresses Stale Content](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0407014755.html).
