These settings let you set up Pinterest integration with your Commerce web store.

More Information: [Pinterest](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3971317981.html)

## Enable Hover {#bridgehead_4700642559}

This boolean enables or disables the Pinterest Pin It to hover over the image.

| **ID** | pinterest.enableHover |
| --- | --- |
| **UI location** | Integrations > Pinterest |
| **JSON file** | pinterest.json |
| **Configuration file (pre-Vinson)** | SC.Shopping.Configuration.js |
