Note:

This topic applies to SuiteCommerce and the 2020.1.1 release of SuiteCommerce Advanced and later.

Here are some key terms used in Application Performance Management (APM) for Commerce features:

-   **Action** - A step or activity that a user performs on the website. For more information, see [APM for Commerce Action Performance](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159845041822.html).
    
-   **Content Display Time (CDT)** - The time it takes to update content on a Commerce web page relative to the action the user performs.
    
    Commerce websites use the Single-Page Application (SPA) model to dynamically update a page when a user interacts with the site. With CDT, you can monitor the time that these interactions take. Use it to identify web addresses or actions that can affect user experience.
    
    Note:
    
    CDT is not a measure of the full page load time or the time it takes to load the page from when it is first viewed to when it has finished loading all elements.
    
-   **Navigation Types** - The ways a user loads web pages.
    
    -   **Hard Navigation** - The user's initial launch of the web page.
        
    -   **Soft Navigation** - Any subsequent action the user performed after the initial web page launch.
        
-   **Statistical Values** - The different computations of metrics available on the charts and tables.
    
    -   **Average** - Shows the average value of the metric.
        
    -   **Median** - Shows the median (middle) value of the metric.
        
    -   **95th Percentile** - Shows the value that is recorded for the metric 95% of the time. 95% of recorded values are lower and 5% are higher.
        
-   **Views** - The number of times users viewed a web page.
