| **Function Declaration** | `getRefreshRequestStatus(context)` |
| --- | --- |
| **Type** | Interface function |
| **Description** | Retrieves the status of a data refresh request from the Account Information Service Provider (AISP). |
| **Returns** | void |
| **Input Parameters** | `context` (JavaScript object) with the following properties:
-   [pluginConfiguration](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157861200583.html)
-   [refreshRequestId](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_71184757410.html)
-   [status](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_98185413723.html)
-   [returnRefreshRequestStatus(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_19185150999.html)

 |

## Example {#bridgehead_45184601325}

          `function getRefreshRequestStatus(context) {   var configurationId = context.pluginConfiguration.getConfigurationFieldValue({fieldName: "configuration_id"});   var configuration = loadConfiguration(configurationId);   const requestId = context.refreshRequestId;   context.returnRefreshRequestStatus({     refreshRequestId: requestId,     status: context.status.IN_PROGRESS // context.status has four enum members NOT_FOUND, IN_PROGRESS, FAILED, COMPLETED   }); }` 
        

Note:

This function is only applicable to connectivity plug-ins used in Corporate Card Expenses type format profiles. For more information, see [Creating Format Profiles for Expense Reporting](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159062414952.html).
