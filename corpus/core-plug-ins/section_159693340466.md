In addition to using the Financial Institution Connectivity Plug-in API specifications to create a plug-in, you can use the following default implementations of the plug-in:

-   **Bank Feeds Connectivity** - This plug-in is provisioned by the Bank Feeds SuiteApp. Use this plug-in with the Bank Feeds Parser bundled with the SuiteApp, to connect to financial institutions in the United States or Canada, or in Europe. The Bank Feeds SuiteApp enables you to automatically import data daily. For details, see [Bank Feeds SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_158079179132.html).
    
-   **SFTP Connectivity** - This plug-in is provisioned by the Auto Bank Statement Import (ABSI) SuiteApp. Use this plug-in with a Bank Statement Parser Plug-in to connect to a financial institution to retrieve bank statement files, daily. The ABSI SuiteApp uses a Financial Institution Connectivity Plug-in implementation to securely connect to your financial institution's server through Secure File Transfer Protocol connectivity. For details, see [Auto Bank Statement Import SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_159296303155.html).
