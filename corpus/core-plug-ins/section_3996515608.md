After a developer creates and bundles a Custom GL Lines plug-in implementation, you can install the bundle and set up the plug-in implementation.

To install and set up a Custom GL Lines plug-in implementation, complete the following steps:

-   [Enabling Features for a Custom GL Lines Plug-in Implementation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4224216932.html)
    
-   [Installing a Custom GL Lines Plug-in Bundle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3910326198.html)
    
-   [Configuring the Custom GL Lines Plug-in Implementation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3996554772.html)
    
-   [Enabling the Custom GL Lines Plug-in Implementation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3910326606.html)
    

You can monitor implementations using system notes. For information, see [Custom GL Lines Plug-in Implementation System Notes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1515607550.html).

Important:

The system always uses the current version of the Custom GL Lines Plug-in. An older version of the plug-in may have been used to create a transaction, which may give you a different result than the current version. If you try to update a transaction in a closed period and the current plug-in generates a different result, you can't save the updates.

You can either open the period or branch your plug-in implementation by the date of the plug-in version.
