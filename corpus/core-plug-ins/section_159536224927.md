| **Function Declaration** | `function getExpenseCodes(context)` |
| --- | --- |
| **Type** | Interface function |
| **Description** | Retrieve expense codes as defined by the file format being used. When a format profile record is configured to import corporate card expenses, the Expense Code Mapping subtab appears, which contains a grid populated with values returned by getExpenseCodes(). This subtab enables you to map expense codes to expense categories to automatically populate expense categories in expense reports. Note: You cannot add custom expense codes. For more information, see [Mapping Custom Expense Codes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159062414968.html). |
| **Returns** | void |
| **Input Parameters** | context - a JavaScript object with the property [createNewExpenseCode()](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159536224935.html). |

## Example {#bridgehead_159536506354}

          `function getExpenseCodes(context) {     context.createNewExpenseCode({       code: '4',       description: 'RESTAURANT'   }); }`
