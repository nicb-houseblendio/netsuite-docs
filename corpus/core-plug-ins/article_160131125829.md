| **Type** | Object property |
| --- | --- |
| **Description** | A context property for the created workbook. In your plug-in implementation, use the N/workbook module to create a workbook as a [workbook.Workbook](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008620913.html) object. After you create this object, assign it to this property. For more information, see [N/workbook Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_159006350818.html). This property is required. If you do not assign a workbook to this property, a `NO_WORKBOOK_CREATED` error is thrown. This property is write-only and accepts only a [workbook.Workbook](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008620913.html) object. If you try to assign an object other than a [workbook.Workbook](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159008620913.html) object to this property, a `WRONG_PARAMETER_TYPE` error is thrown. You can reference only datasets that have been saved using the SuiteAnalytics Workbook UI or a Dataset Builder Plug-in. If you try to reference a dataset that has not been saved, a `CAN_REFERENCE_ONLY_PERSISTED_DATASET` error is thrown. |
