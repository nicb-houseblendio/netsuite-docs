| **Function** | `function addError(options)` |
| --- | --- |
| **Type** | Interface function |
| **Description** | Adds a parser error |
| **Returns** | void |
| **Input Parameters** | options (JavaScript object) with the following properties:
-   [errorCode](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_17161553103.html)
-   [lineNumber](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_21161849778.html)
-   [characterOffset](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0106040927.html)

 |

## Example {#bridgehead_0106040340}

            `function addParserErrors(context) {      context.addError({        errorCode: '1000000000',        lineNumber: '1',        characterOffset: '1'    }); }`
