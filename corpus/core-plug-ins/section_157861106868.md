| **Type** | string |
| --- | --- |
| **Description** | The URL to a user interface for configuring a connection to your financial institution. This URL appears on the Connectivity Configuration subtab on the Format Profile page. |

## Example {#bridgehead_159694737342}

          `var configurationId = context.pluginConfiguration.getConfigurationFieldValue({fieldName: "configuration_id"}); context.configurationIFrameUrl = "/app/site/hosting/scriptlet.nl?script=1&deploy=1&configurationId=" + configurationId;`
