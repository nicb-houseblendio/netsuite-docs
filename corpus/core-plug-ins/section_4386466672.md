You can access the Custom GL Lines Audit Log using the following methods:

-   GL Impact page. On a transaction in View mode, click Actions > GL Impact. For any custom lines on the transaction, click the name of the plug-in implementation in the **Custom Script** column:
    
    ![Plug-in implementation shown on GL Impact page.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/CorePlugIns/CustomGLLinesPlugin/CustomGLLinesAccessAuditLog.png)
-   Use a search. Create a search with the **Custom GL Lines Plug-in Audit Log** search type:
    
    ![New Saved Search page with Custom GL Lines Plug-in Audit Log highlighted.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/CorePlugIns/CustomGLLinesPlugin/CustomGLLinesAuditLogSavedSearch.png)
    
    For more information about using search in NetSuite, see [Simple and Advanced Searches](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N643948.html).
    

Important:

You must have the Administrator role or the Custom GL Lines Plug-in Audit Log permission to view or search the Custom GL Lines audit log.

You can also view system notes for plug-in implementations. For more information, see [Viewing Plug-in Implementation System Notes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4702431116.html).
