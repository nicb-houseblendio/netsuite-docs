All of the following error messages are preceded by: **Custom GL Lines Plugin error due to a failed validation of script output:**

| Error Message | Cause | Preferred Action |
| --- | --- | --- |
| Statistical account {id} was used in financial journal entry. Statistical accounts are not allowed in financial journal entries | The transaction is a Journal and you created a new [CustomLine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4072818715.html) object with [addNewLine()](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4072804185.html#bridgehead_4072815957). However, you used a statistical account ID for [setAccountId(accountId)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4072818715.html#bridgehead_4072826446). | Make sure the ID for the account isn't for a statistical account. Statistical accounts appear on the Chart of Accounts page at _Setup > Accounting > Chart of Accounts_ with a type of **Statistical**. |
| Transaction was not in balance. Total = {amount} | A Custom GL Lines plug-in implementation creates custom lines for a transaction, but the total debits and credits for the custom lines in the transaction don't balance. | Make sure that the plug-in implementation logic creates custom lines with equal credits and debits. |
| Transaction and foreign currency account use different currencies. Account internal ID: {id} | You used [setCreditAmount(credit)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4072818715.html#bridgehead_4072826841) or [setDebitAmount(debit)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4072818715.html#bridgehead_4211975932) to add an amount to a custom line. However, the currency for the account doesn't match either the base currency for the subsidiary entity or the currency for the transaction. | Choose an account with a currency that matches the base currency for the subsidiary entity or the currency for the transaction. |
| {classification types} are required on all lines of the journal entry | You didn't include a required classification type on every line of the journal entry. | On the Accounting Preferences General page, determine whether the Make Departments Mandatory, Make Classes Mandatory, and Make Locations Mandatory boxes are checked. If the boxes are checked, you must provide the classification types on every line of the journal entry. |
| The role set up to run the plugin does not have permissions to set values on the custom segment {script ID of custom segment} | The role of the user who is running the plug-in doesn't have permission to set values on the custom segment. | Provide the user the permissions needed to set values on the custom segment. For more information, see [Granting a Role Permission to Manage Custom Segment Values](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4365642580.html). |
| Setting entity of type {entity type} on the same GL line with account of type {account type} is not allowed | You specified an account type and entity type combination that isn't allowed. For example, you specified a vendor with an accounts payable account, or a customer with an accounts receivable account. | Ensure that the account type specified in [setAccountId(accountId)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4072818715.html#bridgehead_4072826446) is appropriate for the entity type |
| Setting entity on GL line with account of type {account type} is not allowed for book-specific transactions | You specified an entity with an accounts receivable or accounts payable account type that's not allowed with a book-specific line. | Ensure that the account type specified in [setAccountId(accountId)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4072818715.html#bridgehead_4072826446) allows book-specific transactions. |
| You have entered entity IDs belonging to these entity types: {entity type}. These entity types are not supported on custom GL lines. | You specified an entity ID whose entity types aren't supported on custom GL lines. | Enter an entity ID in [setEntityId(entityId)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4072818715.html#bridgehead_4525232716) that belongs to supported entity types. |
| Entity {entity id} and transaction use different currencies | The transaction and entity use different currencies. | Specify an entity in [setEntityId(entityId)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4072818715.html#bridgehead_4525232716) that uses the same currency as the transaction. For more information, see [Multiple Currencies Examples](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4223244273.html). |
| Setting inactive entity {entity id} on custom GL lines is not allowed | You specified an inactive entity ID on the custom GL line. | Specify a valid entity in [setEntityId(entityId)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4072818715.html#bridgehead_4525232716). |
