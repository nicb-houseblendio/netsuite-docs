The Custom GL Lines Audit Log Segments page shows the segments that were set by a specific transaction. Click the link in the **Total Segments Set** column of the Custom GL Lines Audit Log Transaction Details page to access the Custom GL Lines Audit Log Segments page. Administrator or Custom GL Lines Plug-in Audit Log (Segments) permissions are required to view the Custom GL Lines Audit Log Segments page.

The following table describes the columns available on the default view of the Custom GL Lines Audit Log Segments page:

| Column | Description |
| --- | --- |
| Log Entry No. | Internal ID of the custom line in the audit log. This is the same ID as the **Log Entry No.** column on the [Custom GL Lines Audit Log Page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4386466945.html). Click the link to go to the audit log page for the custom line. |
| Line | Line number of the custom GL line. |
| Segment ID | ID for the custom segment definition. |
| Segment | Description of the custom segment definition. |
| Segment Value ID | ID of the segment value for the custom line set with the `setSegmentValueId(segmentId, segmentValueId)` method by the plug-in implementation. For more information, see [setSegmentValueId(segmentId, segmentValueId)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4072818715.html#bridgehead_4525237186). |
| Segment Value | Custom segment value. |
