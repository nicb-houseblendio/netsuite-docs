| **Type** | Object property |
| --- | --- |
| **Description** | A context property for the created dataset. In your plug-in implementation, use the N/dataset module to create a dataset as a [dataset.Dataset](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158948063457.html) object. After you create this object, assign it to this property. For more information, see [N/dataset Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_158946741680.html). This property is required. If you do not assign a dataset to this property, a `NO_DATASET_CREATED` error is thrown. This property is write-only and accepts only a [dataset.Dataset](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158948063457.html) object. If you try to assign an object other than a [dataset.Dataset](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158948063457.html) object to this property, a `WRONG_PARAMETER_TYPE` error is thrown. |
