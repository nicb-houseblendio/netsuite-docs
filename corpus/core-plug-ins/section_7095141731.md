| **Description** | Contains the business logic to modify the general impact for a transaction with the Custom GL Lines Plug-in. Use the objects passed to this function by NetSuite to implement the following business logic in a Custom GL Lines plug-in implementation.
-   Get information about general ledger impact. Use the [StandardLines](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_48095106414.html) object to get information about each line of general ledger impact for a transaction.
-   Create custom lines. Use the [CustomLines](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_7095141731.html) object to create lines with general ledger impact in primary and secondary accounts for a transaction.
-   Modify how GL impact in the primary book affects the secondary books. You can create different business logic for primary and secondary accounting books. See [AccountingBook](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_74095018462.html).

Contains an array of all custom lines with GL impact in a transaction as [CustomLine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_97094831021.html) objects. Use this object to add and modify custom lines with GL impact on a transaction. Create a new CustomLine object with [addNewLine()](#bridgehead_62095244735). For more information, see [Custom GL Lines Plug-in Process Flow](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4211909641.html). |

## count {#bridgehead_41095302485}

| **Property Description** | Returns the number of custom lines with GL impact for a specific accounting book in a transaction. These lines are added with [addNewLine()](#bridgehead_62095244735). Use this property in conjunction with [getLine(options)](#bridgehead_52095308608) to get individual custom lines after you add them in the plug-in implementation. |
| --- | --- |
| **Type** | number (read-only) |
| **Parent object** | [CustomLines](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_7095141731.html) |

## addNewLine() {#bridgehead_62095244735}

| **Method Description** | Adds a [CustomLine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_97094831021.html) object to the parent [CustomLines](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_7095141731.html) object in a Custom GL Lines plug-in implementation and returns the new object. Use this method to add a custom line with GL impact to a transaction. After you create the custom line, use the methods available to the [CustomLine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_97094831021.html) object to set the properties of the custom line, including the general ledger account ID and the amount of the custom line. Note: If you use the Multi-Book Accounting feature and want this line to be copied to the secondary accounting books, use the [isBookSpecific](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_97094831021.html#bridgehead_65094908412) property. |
| --- | --- |
| **Returns** | [CustomLine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_97094831021.html) |
| **Parent object** | [CustomLines](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_7095141731.html) |

## getLine(options) {#bridgehead_52095308608}

| **Method Description** | Returns a [CustomLine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_97094831021.html) object that represents a custom line with GL impact. CustomLine objects are stored in the [CustomLines](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_7095141731.html) object starting at index `0`. |
| --- | --- |
| **Returns** | CustomLine |
| **Parent object** | [CustomLines](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_7095141731.html) |
