To make sure the automatic import of transaction data works, you can test your Financial Institution Parser Plug-in implementation.

#### To test a Financial Institution Parser Plug-in:

1.  Run a Financial Institution Parser Plug-in to import financial institution data. For details, see [Conditions for Running a Financial Institution Parser Plug-in](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159078229220.html).
    
2.  View your imported transaction data. For details, see [Viewing Imported Banking Data](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1494957464.html).
    
    A successful import indicates that your plug-in implementation is correctly configured.
    
    If you receive an import error, look at the plug-in's execution log for details. Go to _Customization > Plug-ins > Plug-in Implementations_. Click the **View** link of the Financial Institution Parser Plug-in, and then on the Plug-in Implementation page, click the **Execution Log** subtab.
