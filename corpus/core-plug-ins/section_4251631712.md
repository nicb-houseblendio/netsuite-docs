To test an Email Capture Plug-in implementation, perform the following tasks:

-   Enable the implementation. Go to the Manage Plug-ins page in your development account to enable the plug-in implementation for testing. The Manage Plug-ins page includes the email address associated with the plug-in implementation. See [Enable the Email Capture Plug-in Implementation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4251628729.html).
    
-   Create a custom role for the plug-in implementation. The **Execute As Role** field specifies the role the plug-in implementation script runs as, and it needs the SuiteScript permission.
    
    For more information about the **Execute As Role** field, see [Add the Plug-in Implementation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4251631349.html). For more information about custom roles in NetSuite, see [Customizing or Creating NetSuite Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N285937.html).
    
-   Send messages to the email address for the plug-in implementation to test the functionality.
    

Important:

You should test your plug-in implementation on every NetSuite version yours customers use.
