The following table lists the journal-specific accounting preferences and classification handling on custom lines.

| Preference | Classification Handling |
| --- | --- |
| Always Allow Per-line Classifications on Journals | Set line-item classes, departments, and locations on custom lines for journal entries. Overrides any other setting for standard transaction classifications. See [Classification Handling on Standard Transactions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4222511570.html) and [General Accounting Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1385293.html). |
| Allow Non-balancing Classifications on Journal Entries | Set non-balancing classifications on custom lines for a journal. See [General Accounting Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1385293.html). For example, if you set a debit amount for a custom line with a specific classification, the transaction does not require a balancing credit for the same classification. |
| Allow Empty Classifications on Journals | Journal line-items do not contain classes, departments, and locations. Overrides any other setting for standard transaction classifications. See [Classification Handling on Standard Transactions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4222511570.html) and [General Accounting Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1385293.html). |
