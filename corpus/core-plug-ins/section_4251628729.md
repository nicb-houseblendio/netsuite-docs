A user with the Administrator role enables the Email Capture Plug-in implementation to activate it in your account.

#### To enable the Email Capture Plug-in implementation:

1.  Go to: _Customization > Plug-ins > Manage Plug-ins_.
    
2.  Under Email Capture Plugin, check the **Log Email Details** box next to the name of the plug-in implementation.
    
    ![Log Email Details box](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/CorePlugIns/EmailCapturePlugin/ManagePluginsPage.png)
3.  Click **Save**.
    
    Note:
    
    NetSuite automatically generates a unique capture email address for each plug-in implementation. You'll see the email address next to the plug-in implementation name on the Manage Plug-in Implementations page. The plug-in implementation executes when users send an email message to the address associated with the plug-in implementation.
    
4.  To continue with installing a Email Capture bundle, go to [Create an Email Alias and Set Up Forwarding](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4256217344.html).
