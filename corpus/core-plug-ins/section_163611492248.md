All of the following error messages are preceded by: **Custom GL Lines Plugin error due to an invalid script operation**.

| Error Message | Cause | Preferred Action |
| --- | --- | --- |
| Cannot Parse Value: {amount} | You used [setDebitAmount(debit)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4072818715.html#bridgehead_4211975932) or [setCreditAmount(credit)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4072818715.html#bridgehead_4072826841) to add an amount to a custom line but the amount is either NULL or not a number. | Verify that the parameter value for the method is a non-null number in the plug-in implementation script file or utility file. |
| Cannot use {amount} as input to setDebitAmount(debit). Amount to debit must be positive | You used [setDebitAmount(debit)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4072818715.html#bridgehead_4211975932) to add a debit amount to a custom line but the amount is negative. | Use a positive value for [setDebitAmount(debit)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4072818715.html#bridgehead_4211975932). |
| Line with index {index} does not exist. Total line count is: {lineCount} | You used [getLine(index)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4072804185.html#bridgehead_4072816543) to get a standard or custom line. However, the index value is equal to or greater than the total number of lines in the [StandardLine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4072807749.html) or [CustomLine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4072818715.html) object. | Make sure the index parameter for [getLine(index)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4072803330.html#bridgehead_4072806950) references a valid element. You can use [getCount()](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4072803330.html#bridgehead_4072806151) to get the total number of lines. |
| Cannot use {amount} as input to setCreditAmount(credit). Amount to credit must be positive | You used [setCreditAmount(credit)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4072818715.html#bridgehead_4072826841) to add a credit amount to a custom line, but the amount is negative. | Use a positive value for [setCreditAmount(credit)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4072818715.html#bridgehead_4072826841). |
