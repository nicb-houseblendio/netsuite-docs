NetSuite develops core plug-ins and releases them to partners or customers usually as part of a major release. A core plug-in's interface defines functions that run in the core NetSuite code. See the following topics:

-   [Available Core Plug-ins](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_3994865673.html)
    
-   [Creating a New Plug-in Implementation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4232566030.html)
    
-   [Debugging a Core Plug-in Implementation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4232567086.html)
    

A plug-in is functionality defined through an interface. After the plug-in is installed, a third party can replace the plug-in's default logic with logic that suits their needs. For more information about managing plug-ins, see [Managing Plug-ins](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4659859610.html)

Oracle NetSuite develops and releases core plug-ins. The logic in a core plug-in runs in the core NetSuite code. See [Core Plug-in Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4567788235.html) for additional information.

Each core plug-in has is own documentation. Refer to the core plug-in's help for details on installing, using, and customizing it The [Available Core Plug-ins](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_3994865673.html) table links to the help for each generally available core plug-in.
