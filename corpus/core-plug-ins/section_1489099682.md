After the administrator installs and implements the plug-in, you can define specific configuration requirements. The options available depend on the set-up configuration in the JavaScript file.

You may require a secret username or password to connect to the bank.

#### To define configuration requirements:

1.  Go to _Customization > Plug-ins > Plug-in Implementations_.
    
    NetSuite displays the list page.
    
2.  For your plug-in implementation, click **Edit**.
    
    NetSuite displays the implementation page for your plug-in.
    
3.  Click **Configure**.
    
    NetSuite dynamically generates the form from the plug-in implementation.
    
4.  If defined by the plug-in, you may need to set:
    
    -   URL for the connecting bank
        
    -   user name and password
        
    -   host key and key type
        
    -   port
        
    -   file download information
        
5.  Click **Save**.
    
    NetSuite saves your configuration for the plug-in.
