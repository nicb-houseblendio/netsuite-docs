## getName() {#bridgehead_4251715921}

| **Function Declaration** | `string getName()` |
| --- | --- |
| **Type** | Object method |
| **Description** | Returns a string that represents the name associated with an email address in the `from`, `to`, `cc`, or `reply-to` headers of an email message. Returns null if the address does not contain a name associated with the email address. |
| **Returns** | string |
| **Since** | 2015.1 |
| **Input Parameters** | None. |
| **Parent object** | 
-   [Address](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4251642963.html)

 |

## Example {#bridgehead_4251771538}

          `function process(email) {       ...       var to = email.getTo();       for (var indexTo in to)       {          logAddress('to', to[indexTo]);       }       ...       function logAddress(label, address)       {           if (address)           {             nlapiLogExecution('DEBUG', 'Email - ' + label + ': ' + address.getName() + ', ' + address.getEmail());           }       }       ...    }` 
        

## getEmail() {#bridgehead_4251715995}

| **Function Declaration** | `string getEmail()` |
| --- | --- |
| **Type** | Object method |
| **Description** | Returns a string that represents the email address in the `from`, `to`, `cc`, or `reply-to` headers of an email message. The headers must contain an email address. |
| **Returns** | string |
| **Since** | 2015.1 |
| **Input Parameters** | None. |
| **Parent object** | 
-   [Address](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4251642963.html)
