To run a Financial Institution Parser Plug-in implementation, you must configure and save a format profile that uses the plug-in. You can run the plug-in using both Bank Reconciliation and Corporate Card Expenses format profiles. For details, see [Format Profile Creation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159061330646.html).

Note:

To perform a successful import in a Bank Reconciliation format profile, you need at least one active linked account.

When you save a format profile configured for automatic import for the first time, NetSuite creates a daily import schedule. Automatic import needs a Financial Institution Parser Plug-in and the Financial Institution Connectivity Plug-in. Together, they let you securely connect to your data source and get data. For more information, see [Automatic Bank Data Import](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157895109986.html).

If the profile type is Bank Reconciliation and it's your first save, NetSuite automatically downloads the last 60 days of data from your linked accounts.

After the format profile is saved for the first time, subsequent imports can occur in the following ways:

-   During a scheduled import of transaction data.
    
-   If you are importing data for bank or credit card reconciliation:
    
    -   When you edit and save an existing format profile configured for connectivity to a financial institution (see [Format Profile Creation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159061330646.html)). The plug-in runs, enabling NetSuite to parse and retrieve new data from existing accounts since the last successful import. For new accounts, NetSuite imports the last 60 calendar days of data.
        
    -   When you manually update imported data for an account on the Match Bank Data page, the plug-in runs so NetSuite can import new data since the last successful import. The new data shows up in the Imported Bank Data grid. For details, see [Updating Imported Bank Data](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_28131953402.html).
        
        Note:
        
        You should only use this method in the following scenarios:
        
        -   You have a need to test the plug-in for a single financial institution account.
            
        -   The selected account does not contain the latest data.
            
        -   There was an import error.
            
        

If you're setting up a format profile for manual import of bank or credit card data, you'll need to import data on the Upload File page after setup. The plug-in runs when you click Import. For details, see [Manual Bank Data Import](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157895093957.html).

To verify that the plug-in is working, see [Testing a Financial Institution Parser Plug-in](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159078146146.html).
