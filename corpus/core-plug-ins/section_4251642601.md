| **Type** | Interface input object |
| --- | --- |
| **Description** | Object that represents an email message sent to the Email Capture plug-in implementation. Use the methods available to the Email object to retrieve the following properties:
-   Sender and recipient headers. The **From**, **To**, **Cc**, and **ReplyTo** properties of the email message as an [Address](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4251642963.html) object. See [getFrom()](#bridgehead_4251713816), [getTo()](#bridgehead_4251714011), [getCc()](#bridgehead_4251714158), and [getReplyTo()](#bridgehead_4251714241).
-   Date. Date the email message was sent. See [getSentDate()](#bridgehead_4251714531).
-   Subject field and email body. The value of the subject field and the value of the email body as a text string or HTML string. See [getSubject()](#bridgehead_4251714683), [getTextBody()](#bridgehead_4251714818), and [getHtmlBody()](#bridgehead_4251714814).
-   Attachment. An array of all attachments as [Attachment](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4251643145.html) objects. See [getAttachments()](#bridgehead_4251714829).

## getTextBody() {#bridgehead_4251714818}

| **Function Declaration** | `string getTextBody()` |
| --- | --- |
| **Type** | Object method |
| **Description** | Returns a string that represents the plaintext part of the body of an email message sent to an Email Capture plug-in implementation. Returns null if there is no text in the body of the email message. If there is text in the body field, this method returns a string regardless of the format of the email message. For example, if an email message was sent in HTML format, the string contains the text of the body field without any HTML formatting. |
| **Returns** | string |
| **Since** | 2015.1 |
| **Input Parameters** | None. |
| **Parent object** | 
-   [Email](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4251642601.html)

 |

## Example {#bridgehead_4251726554}

          `function process(email) {       ...       log('text body', email.getTextBody());       ...    }` 
        

## getHtmlBody() {#bridgehead_4251714814}

| **Function Declaration** | `string getHtmlBody()` |
| --- | --- |
| **Type** | Object method |
| **Description** | Returns a string that represents the HTML content included in the body field of an email message sent to an Email Capture plug-in implementation. Returns null if there is no HTML content in the body of the email message. For example, this method returns null if the body of an email message contains plain text with no formatting. |

## getAttachments() {#bridgehead_4251714829}

| **Function Declaration** | `Attachment[] getAttachments()` |
| --- | --- |
| **Type** | Object method |
| **Description** | Returns an array of [Attachment](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4251643145.html) objects that represent the attachments included in an email message. Returns an empty array of the email message if does not include an attachment. Use the methods available to the [Attachment](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4251643145.html) object to get the name, type, and value of each attachment. |
| **Returns** | [Attachment](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4251643145.html)\[\] |
| **Since** | 2015.1 |
| **Input Parameters** | None. |
| **Parent object** | 
-   [Email](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4251642601.html)

 |

## Example {#bridgehead_4251726591}

          `function process(email) {       ...       var attachments = email.getAttachments();       for (var indexAtt in attachments)       {          logAttachment('att', attachments[indexAtt]);       }       ...    }`
