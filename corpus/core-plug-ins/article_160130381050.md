| **Type** | Object property |
| --- | --- |
| **Description** | The role of the plug-in implementation. The role is the role of the user who added the plug-in implementation to NetSuite. For more information, see [Adding the Plug-in Implementation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160130156224.html). This property is a number, which represents the internal ID of the role of the user who added the plug-in implementation. This property is read-only. If you try to assign a value to this property, a `READ_ONLY` error is thrown. |
