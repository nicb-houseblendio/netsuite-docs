## Interface Function {#bridgehead_4072799671}

The Custom GL Lines plug-in interface includes the following functions for SuiteScript 1.0:

| Function | Description |
| --- | --- |
| [customizeGlImpact(transactionRecord, standardLines, customLines, book)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4072803104.html) | Contains the business logic to modify the general ledger impact for a transaction with the Custom GL Lines plug-in. For more information about how NetSuite uses this function, see [Custom GL Lines Plug-in Process Flow](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4211909641.html). |

Important:

You cannot change this function signature in a Custom GL Lines plug-in implementation.

The Custom GL Lines plug-in interface includes the following function for SuiteScript 2.x:

| Function | Description |
| --- | --- |
| [customizeGlImpact(context)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_8102434206.html) | Contains the business logic to modify the general ledger impact for a transaction with the Custom GL Lines plug-in. For more information about how NetSuite uses this function, see [Custom GL Lines Plug-in Process Flow](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4211909641.html). |
