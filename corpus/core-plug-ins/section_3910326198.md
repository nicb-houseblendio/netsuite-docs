A developer can create a Custom GL Lines plug-in implementation and bundle it to distribute to other NetSuite accounts. Then, an administrator can install the bundle in the target NetSuite account.

#### To install a Custom GL Lines plug-in implementation bundle:

1.  Go to _Customization > SuiteBundler > Search & Install Bundles_.
    
2.  On the Install Bundle page, choose Production Account from the **Location** list.
    
3.  Search for the plug-in bundle.
    
4.  Click **Install** for the bundle.
    
    Important:
    
    To avoid duplicate objects during installation, select **Replace Existing Object** if you're prompted.
    
    After you start installing a bundle, you can continue working in NetSuite as the bundle installs.
    
    To check the installation progress, go to the list of installed bundles at _Customization > SuiteBundler > Search & Install Bundles > List_. If installation isn't done yet, the Status column displays the percentage complete. Click Refresh to update the status. When installation is complete, you'll see a green check mark in the Status column.
    
    Note:
    
    If you don't see an Install button, the bundle may not have been shared with your account. To get access, contact the developer or NetSuite Customer Support.
    
5.  To continue with installing a Custom GL Lines bundle, go to [Configuring the Custom GL Lines Plug-in Implementation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3996554772.html).
    

Important:

If you uninstall the bundle with the plug-in implementation, any custom lines it created remain in your account after the plug-in implementation is uninstalled. For more information, see [Deleting a Custom GL Lines Plug-in Implementation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4386467970.html).
