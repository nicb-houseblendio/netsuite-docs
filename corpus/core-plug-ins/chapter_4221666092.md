Use the information in this section as reference when you develop, run, and test a Custom GL Lines plug-in implementation.

| Topic | Description |
| --- | --- |
| View example code | View example code for using utility files in a plug-in implementation. Use the utility files to create helper functions, reference internal NetSuite IDs, search records, and store internal NetSuite record IDs using a custom record. See [Custom GL Lines Plug-in Example Code](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4223245421.html). |
| Classification handling | You can set classifications, including department, class, and location, on custom lines for standard transactions, journals, and custom transactions. Depending on the accounting preferences, NetSuite may set the classifications. See [Classifications](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4222072444.html). |
| Guidelines and best practices | Get more information about creating the plug-in implementation script file and plug-in implementation behavior. See [Custom GL Lines Plug-in Guidelines and Best Practices](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4229148151.html). |
| Get help on error messages | Get more information about error messages that can occur when NetSuite validates the plug-in implementation logic or when the plug-in implementation script runs. See [Error Messages for Custom GL Lines Plug-in](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4226525629.html). |
| Searching and reporting on custom lines | Use the **Custom GL** flag on reports and searches. See [Custom Lines on Reports and in Searches](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4298138426.html). |
| Use the audit log | Use the Custom GL Lines audit log to learnt more about custom lines created by a plug-in implementation. See [Custom GL Lines Audit Log](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4344257444.html). |
| Use the plug-in system notes | Use the plug-in system notes to learn more about changes made on a plug-in implementation record. See [Viewing Plug-in Implementation System Notes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4702431116.html). |
| Delete a plug-in implementation | Delete a Custom GL Lines plug-in from a NetSuite account, or uninstall a bundle that contains a plug-in implementation. See [Deleting a Custom GL Lines Plug-in Implementation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4386467970.html). |
