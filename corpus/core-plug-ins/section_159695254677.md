| **Function Declaration** | `function retry(options)` |
| --- | --- |
| **Type** | Object function |
| **Description** | This method is invoked by the plug-in to schedule a bank import retry deltaMinutesLater minutes in the future. The current import job will fail and a failure reason will appear. If your role has the Import Online Banking File permission with create-level access at a minimum, the failure reason will include an error from the plug-in. Otherwise, the failure reason will be more generic. The method may throw an exception with one of the following error codes:
-   SSS\_RETRY\_NOT\_ALLOWED: retry is called when retry is not allowed
-   SSS\_INVALID\_RETRY\_DELAY: deltaMinutesLater is outside of valid range
-   SSS\_RETRY\_FAILURE\_REASON\_SIZE\_LIMIT\_EXCEEDED: currentFailureReason is too long

 |
| **Returns** | void |

| Parameter | Type | Required | Description | Since |
| --- | --- | --- | --- | --- |
| deltaMinutesLater | Number | Yes | How many minutes into the future to schedule the import retry. Must be greater than or equal to 30, and less than or equal to 240. | 2020.2 |
| currentFailureReason | String | No | The reason an import retry is needed. | 2020.2 |

## Example {#bridgehead_159695602836}

          `if (context.isRetryAllowed()) {     context.retry({deltaMinutesLater: 30, currentFailureReason: "Timed out"}); }`
