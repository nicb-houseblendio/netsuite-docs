Note:

This topic applies to System Notes only. For information about System Notes v2, see [System Notes v2 Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158108495822.html).

System notes are logged on custom GL lines plug-in implementations.

A System Notes subtab is available on the plug-in implementation configuration page for Custom GL Lines Plug-ins. The system notes show any changes made to the plug-in implementation configuration settings.

![Custom GL Lines: Configuration page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/CorePlugIns/CustomGLLinesPlugin/CustomGLLinesConfigSysNotes.png)

For more information about system notes, see [System Notes Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_158644279544.html).
