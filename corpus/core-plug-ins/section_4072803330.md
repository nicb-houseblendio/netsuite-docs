| **Description** | Contains an array of all standard lines with GL impact in a transaction as StandardLine objects. Standard lines are the general ledger impacts that appear on the GL Impact report for a transaction. Use this object to access individual standard lines for an accounting book in a transaction. ## getCount() {#bridgehead_4072806151}

| **Function Declaration** | `int getCount()` |
| --- | --- |
| **Type** | Object method |
| **Description** | Returns the number of standard lines with GL impact for a specific accounting book in a transaction. Use this method in conjunction with [getLine(index)](#bridgehead_4072806950) to read individual standard lines. `getCount()` counts both visible and hidden lines on the GL Impact page. For an example of how to return only the number of visible lines, see [Custom GL Lines Plug-in Guidelines and Best Practices](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4229148151.html). |
| **Returns** | int |
| **Input Parameters** | None. |
| **Parent object** | [StandardLines](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4072803330.html) |

**Example**

          `function customizeGlImpact(transactionRecord, standardLines, customLines, book)    {       ...       for (var i = 0; i < standardLines.getCount(); i++)        {          var currLine = standardLines.getLine(i);          ...       }    }` 
        

## getLine(index) {#bridgehead_4072806950}

| **Function Declaration** | `StandardLine getLine(int index)` |
| --- | --- |
| **Type** | Object method |
| **Description** | Returns a [StandardLine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4072807749.html) object that represents a standard line with GL impact. StandardLine objects are stored in the [StandardLines](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4072803330.html) object starting at index `0`. |
| **Returns** | [StandardLine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4072807749.html) |
| **Input Parameters** | index {int} - Integer value for the StandardLine object at the specified position in the StandardLines object. |
| **Parent object** | [StandardLines](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4072803330.html) |

**Example**

          `function customizeGlImpact(transactionRecord, standardLines, customLines, book)    {       ...       for (var i = 0; i < standardLines.getCount(); i++)        {          var currLine = standardLines.getLine(i);          ...       }    }`
