| **Type** | Object property |
| --- | --- |
| **Description** | The description of the plug-in implementation. This description is the same as the one you specify when you add your plug-in implementation to NetSuite. For more information, see [Adding the Plug-in Implementation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160130995889.html). This property is a string. This property is read-only. If you try to assign a value to this property, a `READ_ONLY` error is thrown. |
