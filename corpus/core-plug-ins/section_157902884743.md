| **Type** | string |
| --- | --- |
| **Description** | A list of financial institution accounts required for the plug-in to query bank data, as well as the required data date ranges. The information retrieved is provided as a JSON format string: Note: The accountRequestsJSON property is only applicable to Bank Reconciliation format profile setups. `[{\"dataStartTime\":\"2019-08-20T02:30:11\", \"dataEndTime\":\"2019-09-20T02:30:11\", \"accountMappingKey\":\"acct-123\"}, * {\"dataStartTime\":\"2019-08-20T02:30:11\", \"dataEndTime\":\"2019-09-20T02:30:11\", \"accountMappingKey\":\"acct-456\"}]` The properties embedded in the JSON string include the following:
-   dataStartTime - The requested start time of the data to be retrieved. If the Bank Reconciliation format profile is saved for the first time, NetSuite downloads data up to 60 calendar days old. After the first import, dataStartTime can also be dependent on the last successful import.
-   dataEndTime - The requested end time of the data to be retrieved. dataEndTime is the time when a bank data import is initiated.
-   accountMappingKey - The financial institution account's unique identifier.

 |

For an example of where the property accountRequestsJSON is used, see [getTransactionData()](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160339622086.html).
