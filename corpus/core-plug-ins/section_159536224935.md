| **Function Declaration** | `function createNewExpenseCode(options)` |
| --- | --- |
| **Type** | Object function |
| **Description** | Create a new ExpenseCode object for the plug-in to set property values. |
| **Returns** | void |

options is a JavaScript object with the following input parameters:

| Parameter | Type | Required | Description | Since |
| --- | --- | --- | --- | --- |
| code | String | Yes | A raw expense code supported by the data file. | 2020.2 |
| description | String | No | A description of the kind of expense that the expense code represents. | 2020.2 |

## Example {#bridgehead_159536507306}

          `var expenseCode = context.createNewExpenseCode({     code: '4',     description: 'RESTAURANT' });`
