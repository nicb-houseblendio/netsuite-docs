A developer can create and bundle an implementation of the Email Capture Plug-in for distribution to other NetSuite accounts. An administrator can then install the bundle in the target account.

Important:

Before you try to install the bundle, check with your NetSuite Administrator to make sure that the bundle has been shared on your account. See [Sharing a Bundle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3385867.html).

#### To install an Email Capture Plug-in bundle:

1.  Go to _Customization > SuiteBundler > Search & Install Bundles_.
    
2.  On the Install Bundle page, select **Advanced** and choose **Production Account** in the **Location** dropdown.
    
3.  In the **Keywords** , enter Email Capture Bundle and click **Enter**.
    
4.  Select the bundle from the list.
    
5.  Click **Install** for the bundle.
    
    Important:
    
    To avoid duplicate objects, select **Replace Existing Object** if you're prompted during install.
    
    After you start installing a bundle, you can continue working in NetSuite as the bundle installs.
    
    To check on the progress of the installation, go to _Customization > SuiteBundler > Search & Install Bundles > List_. If installation is not complete, the Status column shows the progress as a percentage. Click **Refresh** to update the status. When the installation is complete, you'll see a green check mark.
    
    Note:
    
    If you don't see an **Install** button, the bundle may not be shared with your account. To get access to the bundle, contact the developer or NetSuite Technical Support.
    
6.  To continue with installing a Email Capture bundle, go to [Enable the Email Capture Plug-in Implementation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4251628729.html).
