To test a Financial Institution Connectivity Plug-in, run the plug-in to import bank data, then check your import.

To run the plug-in, see [Conditions for Running a Financial Institution Connectivity Plug-in](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157851439658.html).

If you get an import error, check the plug-in's execution log for details. Go to _Customization > Plug-ins > Plug-in Implementations_. Click the View link of the Financial Institution Connectivity Plug-in, and then on the Plug-in Implementation page, click the Execution Log subtab.

To view your imported data, see [Viewing Imported Banking Data](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1494957464.html).
