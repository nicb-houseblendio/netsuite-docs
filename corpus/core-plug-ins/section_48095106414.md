| **Description** | Contains an array of all standard lines with GL impact in a transaction as StandardLine objects. Standard lines are the general ledger impacts that appear on the GL Impact report for a transaction. Use this object to access individual standard lines for an accounting book in a transaction. For more information, see [Custom GL Lines Plug-in Process Flow](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4211909641.html). |
| **Properties** | [count](#bridgehead_51095122385) |
| **Child Object(s)** | [StandardLine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_95095135857.html) |

## count {#bridgehead_51095122385}

| **Property Description** | Returns the number of standard lines with GL impact for a specific accounting book in a transaction. Use this method in conjunction with to read individual standard lines. This property counts both visible and hidden lines on the GL Impact page. For an example of how to return only the number of visible lines, see [Custom GL Lines Plug-in Guidelines and Best Practices](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4229148151.html). |
| --- | --- |
| **Type** | number (read-only) |
| **Parent object** | [StandardLines](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_48095106414.html) |

## getLine(options) {#bridgehead_60095129955}

| Method Description | Returns a [StandardLine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_95095135857.html) object that represents a standard line with GL impact. StandardLine objects are stored in the [StandardLines](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_48095106414.html) object starting at index `0`. |
| --- | --- |
| **Returns** | [StandardLine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_95095135857.html) |
| **Parent object** | [StandardLines](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_48095106414.html) |

**Parameters**

| **Parameter** | **Type** | **Required/Optional** | **Description** |
| --- | --- | --- | --- |
| options.index | number | Required | Index of the line to be returned by the method, starting at 0. |
