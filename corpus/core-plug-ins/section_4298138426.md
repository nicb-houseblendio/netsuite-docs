You can use the **Custom GL** flag in the Report Builder and in searches to view custom lines created by a Custom GL Lines plug-in implementation. See one of the following topics:

-   [Custom GL Lines on NetSuite Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4387500938.html)
    
-   [Searches for Custom GL Lines](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4387502858.html)
    

Note:

You can still view custom lines on reports and search for custom lines even if you delete the plug-in implementation that created the lines. See [Deleting a Custom GL Lines Plug-in Implementation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4386467970.html).
