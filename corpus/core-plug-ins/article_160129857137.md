To develop a Dataset Builder Plug-in, complete the following steps:

1.  Enable the required features for a Dataset Builder Plug-in. See [Enabling Features for a Dataset Builder Plug-in](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160129950663.html).
    
2.  Create a Dataset Builder Plug-in script file. See [Creating a Dataset Builder Plug-in Script File](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160129974584.html).
