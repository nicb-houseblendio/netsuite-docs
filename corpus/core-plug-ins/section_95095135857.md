## accountId {#subsect_0813015204}

| **Property Description** | Returns the internal NetSuite ID of the entity for a [StandardLine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_95095135857.html) object. This account ID represents the NetSuite general ledger account to which a credit or debit is applied on the GL impact for a transaction. Use this ID to define plug-in implementation functionality based on the credited or debited account. See also [accountId](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_97094831021.html#bridgehead_34094920764). You can view the internal NetSuite ID for all accounts on the Chart of Accounts page at _Setup > Accounting > Chart of Accounts_. You can use helper functions in a utility file to customize the internal NetSuite account IDs in the plug-in implementation logic. |
| --- | --- |
| **Type** | number (read-only) |
| **Parent object** | [StandardLine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_95095135857.html) |

Use this property to define plug-in implementation functionality based on the amount for a GL impact line. If the line is a credit, than it will have a negative sign. |

## entityId {#subsect_15092347292}

| **Property Description** | Returns the internal NetSuite ID for the entity on a [StandardLine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_95095135857.html) object. The entity can be any customer, employee, partner, or vendor, depending on the type of transaction. You can use this ID, for example, to define plug-in implementation functionality based on the entity ID, to load the record for the entity with `[record.load(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4267258486.html)`, or to search for the record using the [N/query Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510275060.html) to look up the type of the entity. Important: Limit the use of these APIs, where possible, to improve performance of the plug-in implementation. Also, searching for a record results in better performance than loading the record. To implement functionality based on the entity ID, you can use helper functions to avoid adding the internal NetSuite ID into the plug-in implementation logic. |

## id {#subsect_62092756333}

| **Property Description** | Returns the internal NetSuite database ID for a standard GL impact line. The summary line for the GL impact on a transaction occurs for most transaction types with an ID of 0. Some transactions, like journal entries, do not have a summary line. You can use the summary information to define plug-in implementation functionality based on the values in the summary line. Note: The summary line for the GL impact on a transaction does not include tax information. |
| --- | --- |
| **Type** | number (read-only) |
| **Parent object** | [StandardLine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_95095135857.html) |

## isPosting {#subsect_79092946348}

| **Property Description** | Returns `true` if the transaction is a posting transaction and the associated standard GL impact line posts to the general ledger. Returns `false` if the transaction is a non-posting transaction. NetSuite transactions can be posting, non-posting, or posting with approval. For example, journal entries do not post without approval. For more information, see [General Ledger Impact of Transactions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N1459499.html). |
| --- | --- |
| **Type** | boolean (read-only) |
| **Parent object** | [StandardLine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_95095135857.html) |

## isTaxable {#subsect_52093113854}

| **Property Description** | Returns `true` if a standard GL impact line is a credit to a tax account. For example, if a standard line on a taxable transaction contains a credit value of 10.00 for an account of type Other Current Liability, this property returns `true`. |

## taxAmount {#subsect_82093920419}

| **Property Description** | Returns a string that represents the amount of tax charged on a standard GL line. This property only returns a value other than 0 if the standard line is a credit to a tax account. For example, if a standard line on a taxable transaction contains a credit value of 10.00 for an account of type Other Current Liability, this property returns -10. Use this property with [taxItemId](#subsect_34094324857), [taxableAmount](#subsect_36093847799), and [taxType](#subsect_57094343677) to get the tax information for a standard GL impact line. |
| --- | --- |
| **Type** | string (read-only) |
| **Parent object** | [StandardLine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_95095135857.html) |

## taxableAmount {#subsect_36093847799}

| **Property Description** | Returns a string that represents the amount of a standard GL line that was subject to tax. Returns 0 if the line was not subject to tax. Use this property with [taxItemId](#subsect_34094324857), [taxAmount](#subsect_82093920419), and [taxType](#subsect_57094343677) to get the tax information for a standard GL impact line. You can use helper functions in a utility file to avoid adding the internal NetSuite IDs into the plug-in implementation logic. |

## taxItemId {#subsect_34094324857}

| **Property Description** | Returns the internal NetSuite ID of the tax code for a standard GL line. Returns `null` if the line was not subject to tax or if the line does not credit a tax account with a tax liability. You can use this ID to define plug-in implementation functionality based on the tax code. For example, a tax code of -7 indicates the line was not subject to tax. You can view all tax codes in NetSuite at _Setup > Accounting > Tax Codes_. You can use helper functions in a utility file to avoid adding the internal NetSuite IDs into the plug-in implementation logic. Use this property with [taxableAmount](#subsect_36093847799), [taxAmount](#subsect_82093920419), and [taxType](#subsect_57094343677) to get the tax information for a standard GL impact line. |
| --- | --- |
| **Type** | number (read-only) |
| **Parent object** | [StandardLine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_95095135857.html) |

## taxType {#subsect_57094343677}

| **Property Description** | Returns the tax type for a standard GL line that was subject to tax. Returns null if the standard line was not subject to tax. You can use this ID to define plug-in implementation functionality based on the tax type. You can view all tax types in NetSuite at _Setup > Accounting > Tax Types_. Use this property with [taxableAmount](#subsect_36093847799), [taxAmount](#subsect_82093920419), and [taxItemId](#subsect_34094324857) to get the tax information for a standard GL impact line. |
