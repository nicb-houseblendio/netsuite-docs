## accountId {#bridgehead_34094920764}

| **Property Description** | Sets the account ID property for a [CustomLine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_97094831021.html) object in a primary or secondary book. This value is the internal NetSuite ID for a general ledger account. You must use this property to set the account to be debited or credited for a custom line. You can view the internal NetSuite ID for all accounts on the Chart of Accounts page at _Setup > Accounting > Chart of Accounts_. You can use helper functions in a utility file to customize the internal NetSuite account IDs in the plug-in implementation logic. |

## creditAmount {#bridgehead_80094931459}

| **Property Description** | Sets the credit amount of a [CustomLine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_97094831021.html) object in a primary or secondary book. ## entityId {#bridgehead_9094946771}

| **Property Description** | Sets the entity ID property for a [CustomLine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_97094831021.html) object in a primary or secondary book. Supported entity types include:
-   Customers
-   Jobs
-   Leads
-   Prospects
-   Vendors
-   Employees
-   Other Names

The following restrictions apply to setting of entities on custom GL lines:

-   Setting a vendor is not supported on lines with an Accounts Payable account type.
-   Setting a customer is not supported on lines with an Accounts Receivable account type.
-   Creating book-specific custom GL lines with an AP or AR account and entity combination. Only generic custom GL lines can be created with this combination.
-   Only entities that have the same subsidiary as the transaction can be set on lines for that transaction.
-   Only entities that have the same currency as the transaction can be set on lines for that transaction.
-   Entities must be active.

Note: This property does not set the sales representative for the line, and it does not change the date of the first sale for the customer. |
| --- | --- |
| **Type** | number - An internal NetSuite ID for an entity. |
| **Parent object** | [CustomLine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_97094831021.html) |

## isBookSpecific {#bridgehead_65094908412}

| **Property Description** | Sets a custom GL impact line to affect only the primary book in a Custom GL plug-in implementation. If you use this property and set the value to `false`, the plug-in implementation copies the custom line to secondary books and the custom line is also subject to the mapping set up for the Multi-Book Accounting feature. If you do not use this property or set the value to `true`, the custom GL impact line only applies to the primary accounting book and is not copied to secondary books. Note: This property only applies if you use the Multi-Book Accounting feature and the property is being called for the primary accounting book. It has no impact on book-specific journal entries. For more information about how the plug-in implementation processes book-specific lines, see [Custom GL Lines Plug-in Process Flow](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4211909641.html). |
| --- | --- |
| **Type** | boolean - Use `true` to make the custom line specific to the primary accounting book. Use `false` to direct NetSuite to copy the custom line to secondary accounting books. |
| **Parent object** | [CustomLine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_97094831021.html) |

## setSegmentValueId(options) {#bridgehead_10095005117}

| **Method Description** | Sets custom segment values on a [CustomLine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_97094831021.html) object NetSuite assigns custom segment values as follows:
-   If the custom segment has a body and lines, the value is copied from the body to all custom lines. The plug-in can be used to change the value of the lines.
-   If the custom segment has only a body value, the value is copied from the body to all custom lines. The plug-in can be used to change the value.
-   If the custom segment has only line values, no values are copied to custom lines.

 |
| --- | --- |
| **Returns** | Void |
| **Parent object** | [CustomLine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_97094831021.html) |

**Parameters**

| **Parameter** | **Type** | **Required/Optional** | **Description** |
| --- | --- | --- | --- |
| options.segmentId | string | Required | String value of the custom segment ID. |
| options.segmentValueId | number | Optional | Internal ID of the custom segment value that the custom line should be set to. Omitting this parameter unsets the custom segment value. |
