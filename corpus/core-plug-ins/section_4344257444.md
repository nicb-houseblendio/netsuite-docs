The Custom GL Lines Audit Log shows custom lines created by Custom GL Lines plug-in implementations in a NetSuite account. Use the audit log to view any custom lines created for a specific transaction, all transactions, or for a specific plug-in implementation. To view the Custom GL Lines audit log page, you must have either the Administrator role or the Custom GL Lines Plug-in Audit Log permission. To view the Custom GL Lines segments audit log page, you must have either administrator or Custom GL Lines Plug-in Audit Log (Segments) permissions.

See the following topics for more information:

-   [Accessing the Custom GL Lines Audit Log](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4386466672.html)
    
-   [Custom GL Lines Audit Log Page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4386466945.html)
    

Note:

Custom lines remain in the audit log even if you delete the plug-in implementation that created the lines. See [Deleting a Custom GL Lines Plug-in Implementation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4386467970.html).
