The application stores exception logs in a default folder. Other logs are stored in the same folders that you have set up in the [ODBC Connection](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158619821210.html#subsect_158619885698) section of the Configuration Settings.

To view logs, from the application's menu, go to Settings > View Logs. On the View folder and logs window, click one of the buttons to open the folder location where you can find the log files.
