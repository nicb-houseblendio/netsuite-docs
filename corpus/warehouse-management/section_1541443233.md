If you activate the following Zone Picking rules for locations with bins, you can pick items from zones for orders released in waves:

-   **Enable Zone Picking for single orders** - Different pickers can process one or more pick tasks associated with the same order in a wave. See [Zone Picking for Single Orders](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164461153402.html).
    
-   **Enable Zone Picking for multiple orders** - Multiple pickers can process orders from the same wave. See [Zone Picking for Multiple Orders](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164461269708.html).
    

You can stage the items picked from different zones in the same bin location. For more information, see [System Rules for NetSuite WMS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156406918320.html).

On the mobile app, the Select Zone page appears to display the zones from the same warehouse. You can select one or more zones that contain the items you want to pick. The app displays the list of pick task or lines with recommended bins associated with the zone. If you select the **All Unassigned Zones** option, you can process non-inventory items along with pick task lines with recommended bins not associated with zones. For more information about zones, see [Creating Zones](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161314312081.html#section_1541433488).

On a pick task subrecord, you can view the **Recommended Bin** field in the header and its associated zone on the **Recommended Bins** subtab. On this subtab, you can also view the applicable pick strategy that you may have set up for the zone. For more information, see [Pick Task Sorting and Recommended Bins](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1549310986.html) or [Defining Pick Strategies](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1551132634.html).
