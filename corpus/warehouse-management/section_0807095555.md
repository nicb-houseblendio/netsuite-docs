You can generate inventory counts from cycle count plans through the mobile app. If you activate the **Start and Complete Counts on App** rule, you can start cycle counts through the mobile app immediately after you generate them. You can also process and complete the started counts.

#### To generate counts on the app:

1.  Access the Cycle Count process by doing the following:
    
    1.  On the mobile app, tap the menu icon at the top-left corner of the screen, and then tap **Main Menu**.
        
    2.  On the Main Menu page, tap **Inventory**.
        
    3.  On the Inventory page, tap **Cycle Count**.
        
2.  On the Cycle Count page, tap **Generate from Plan**.
    
3.  On the Generate Cycle Count from Plan page, enter or select a plan by doing one of the following:
    
    -   To enter a cycle count plan, in the **Enter Plan #** field, enter the name or number of the plan. Optionally, you can enter dates in the **Count Start Date** or **Count End Date** fields. The app searches for plans schedule after or before the date you enter, respectively. You can enter both dates to specify a range for filtering cycle count plans. Then, tap **Enter** to proceed.
        
    -   To select a cycle count plan, tap the **Cycle Count Plans** toggle and then select a plan from the list.
        
4.  On the next page, do the following:
    
    1.  Tap the box for up to 10 items that you want to count from the plan.
        
    2.  Tap **Generate and Release**.
        
5.  On the Cycle Count Created page, you can view the list of generated cycle count tasks.
    
6.  If you can start counts on the app, you can do the following:
    
    Tip:
    
    If you do not have this option or if you want to start counts later through the NetSuite UI, see [Starting Inventory Counts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_155993306635.html).
    
    1.  Tap the more icon, and then tap **Start Cycle Count**.
        
    2.  On the Select Task page, to start all the counts generated from the plan, tap **Start Count**.
        
    
    In the NetSuite UI, the associated inventory count changes to Started status.
    
    You can proceed to the next steps to perform and complete the count. You can also process them at a later time. For instructions, see [Performing Inventory Counts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_155993309359.html).
    
7.  For warehouses with bins, on the Enter Bin page, do one of the following:
    
    -   In the **Scan/Enter Bin** field, scan or enter the bin name or number. If you enter the data, tap **Enter Bin** to proceed.
        
    -   In the **Expected Bin** field, tap the bin.
        
8.  On the Enter Item page, do one of the following:
    
    Tip:
    
    If you want to view the completed count tasks from the plan, tap the **Show Completed** toggle.
    
    -   In the **Scan/Enter Item** field, scan or enter the item name or number. If you enter the data, tap **Enter Item** to proceed.
        
    -   From the Items to Count list, tap the item name or number.
        
9.  On the Enter Quantity page, do the following:
    
    1.  In the **Enter Quantity** field, enter the number of items you have counted.
        
    2.  If the item has multiple units, you can select a unit.
        
    3.  Tap **Enter Quantity**.
        
10.  On the Select Task page, do one of the following:
     
     -   To process another task from the same plan, from the Cycle Count Tasks list, tap the bin or item name. Return to step 7.
         
     -   To start other cycle count tasks, tap **Start Count**. Return to step 6.
         
     -   To complete all the counts that you have processed, tap **Complete Count**. On the popup message, tap **OK** to confirm that you want to complete and submit the counts for approval.
         
         Tip:
         
         If you do not have this option or if you want to complete counts later through the NetSuite UI, see [Completing Inventory Counts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_155993309646.html).
         
     
     In the NetSuite UI, the associated inventory count changes to Completed/Pending Approval status. You cannot edit counts in this status.
