On the app, you can set pick task lines to **Done** status for each partially picked order, including lines with zero picked quantities. When all lines have this status, the entire pick task may be set to **Done** automatically. Item fulfillment generation for each pick task line follows your preference. For more information, see [Viewing the Status of Fulfillment Generation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1541442979.html).

During a partial picking flow, the app applies the system rules that you activate for picking such as use of pick cartons and printing of carton labels. If you activate the **Automatically mark partial picks as Done** rule, partial picks can no longer be set to **Done** manually. If you don't manually stage any partially picked items, the app automatically selects the first staging bin associated with each pick task line.

If you want to mark partial picks **Done** through the NetSuite UI, see [Posting Item Fulfillments for Partially Picked Orders](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1541443017.html).

#### To mark partial and zero picks Done through the app:

1.  Access the sales or transfer order picking process on the app.
    
    For detailed instructions, see the following articles:
    
    -   [Picking Items for Single Orders](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161618347171.html)
        
    -   [Picking Items for Multiple Orders](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161618492327.html)
        
    -   [Performing Bulk Picking](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161643765683.html)
        
    -   [Picking Orders from a Zone](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1541443233.html)
        
2.  After you select an order or wave, on the Select Pick Task page, do one of the following:
    
    -   To do a full or partial pick, scan or enter a pick task in the **Scan/Enter Pick Task #** field. Alternatively, tap the pick task you want to select from the Pick Tasks list. If you enter the data, tap **Enter Pick Task** to proceed.
        
    -   If you have not fully or partially processed any pick task from the order, you can tap **Mark All Picks Done**, which applies to all zero quantity picks. Skip steps 3 and 4.
        
3.  For fully or partially picked quantities, depending on capabilities that you use, you can continue to stage them in bins, assign pick cartons, or print carton labels.
    
4.  After you partially pick an item for the order, when you return to the Select Pick Task page, you can tap one of the following options:
    
    -   **Mark All Picks Done** - Applies to pick task lines with partially picked and zero picked quantities.
        
    -   **Mark Partial Picks Done** - Applies to pick task lines with partially picked quantities
        
5.  On the popup window, tap **Submit** to continue to set the affected pick task lines to **Done** status.
    
6.  To continue, you can process another pick task or for multi-order picking, another order within the same wave. Return to step 2.
    
    If you have no remaining pick tasks or orders to process, you can review the picking details on the summary page.
    

Within the NetSuite UI, you can access the pick tasks and view their associated pick task lines that you have set to **Done** status. You can also view any generated fulfillments or changes to the wave status. For more information, see [Monitoring the Status of Released Orders](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1548081071.html).
