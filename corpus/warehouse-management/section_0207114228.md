If you activate the **Entry of additional details** rule, create one or more adjustment reasons for the Create Inventory process. On the app, you can select the reason for adjusting inventory quantities. NetSuite WMS includes the reason when it generates the inventory adjustment.

For more information about the rule, see [System Rules for NetSuite WMS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156406918320.html).

#### To create adjustment reasons:

1.  Using the WMS Warehouse Manager role, go to WMS Configuration > Configure Warehouse > WMS Reason for Adjustment > New.
    
2.  On the WMS Reason for Adjustment page, set values in the following fields:
    
    -   **Reason Code** - Enter a unique code that identifies this record.
        
    -   **Reason Description** - Enter a short text that describes the adjustment reason.
        
        The description of each record appears in the app for selection within the Create Inventory process. On the generated inventory adjustment, your selected reason description appears in the **Reason for Adjustment** field on the **NS WMS** subtab. For more information, see [Entering an Inventory Adjustment](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161981111273.html).
        
3.  Click **Save**.
