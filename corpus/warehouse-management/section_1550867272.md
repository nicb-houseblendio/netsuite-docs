You can configure standard mobile processes to make minor changes to labels, layout, and other basic settings. You can also add specific page elements to mobile pages. For more information about Mobile Configuration, refer to the following topics:

-   [Configuring Mobile Page Elements](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161549215472.html) - Page elements include fields and columns that you can configure in standard mobile processes. It also includes icons on menu pages and icons for capturing or uploading images and files.
    
-   [Configuring Pages and Actions for Custom Mobile Processes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161556508008.html) - You can change some of the mobile actions within standard mobile processes.
    

To perform additional changes, you can clone a standard process to create a copy of its pages, page elements, and other components. You can customize these components and add more to suit your app requirements. You can also set up your own RESTlets, client scripts, or saved searches for mobile actions of buttons, icons, and other page elements. For more information about Mobile Customization, see [SCM Mobile App Customization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_163614460343.html).

Mobile customizations include updating print templates, labels, printing settings, and the Print button. For more information, see the following topics:

-   [Mobile Printing Customization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162506469317.html)
    
-   [Creating Custom Print Templates and Files](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0206031419.html)
    
-   [Setting Up Printing Settings on Print Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161496026645.html)
    
-   [Setting Up Automatic or Required Printing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161496236607.html)
