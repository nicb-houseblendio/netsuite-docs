The following tables contain the list of standard NetSuite and WMS permissions for inbound, inventory, and outbound processing:

-   [Inbound Processing Permissions](#subsect_156520614424)
    
-   [Inventory Processing Permissions](#subsect_156520688431)
    
-   [Outbound Processing Permissions](#subsect_156520752283)
    

Use these tables as a guide when you want to manually add WMS permissions to your custom roles. The permissions allow roles to perform WMS tasks on both the NetSuite user interface and on a mobile device.

Add permissions based on your business requirements. For example, if you don't process work orders in your warehouse, you don't need to assign the Work Order permission. If you want your custom role to perform inbound and outbound processing tasks, you can combine the permissions from their corresponding tables.

To assign permissions, you can edit your custom role by going to _Setup > Users/Roles > User Management > Manage Roles_. On the Role page, you can set each permission and access level on the **Permissions** subtab. All minimum access levels for WMS permissions are set to **Full**, unless otherwise indicated in the table. For detailed instructions, see [Setting Permissions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N288727.html).

For information about NetSuite permissions, view the following topics:

-   For more information about permission levels, see [Access Levels for Permissions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N326341.html).
    
-   For the complete list of NetSuite permissions, see [Permissions Documentation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N326485.html).
    

## Inbound Processing Permissions {#subsect_156520614424}

Inbound processing permissions enable the following tasks:

-   Receiving purchase orders, transfer orders, and customer returns
    
-   Posting of item receipts
    
-   Bin putaway and cart moves
    
-   Reversal of item receipts
    

The following roles are preset with these permissions: WMS Inbound Manager, WMS Inbound Operator, and WMS Warehouse Manager.

## Inventory Processing Permissions {#subsect_156520688431}

-   Inventory search, creation, transfer
    
-   Inventory cycle counts and replenishment

-   Mobile picking of sales and transfer orders
