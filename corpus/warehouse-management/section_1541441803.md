On the app, you can pick components of assembly items to stock or fill orders. You can pick component items for one work order at a time.

If you use bins, you can choose the bin from which to pick them and stage picked components in bins. If you activate the **Bin blocking** system rule, you can use the **Bin Empty** option to remove bins from your list of choices to pick from. To set up, see [Setting Up Bin Blocking for Order Picking](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0214032203.html).

To complete a work order, you can process it for an assembly build. After you process each task on the app, NetSuite WMS updates the work order with the status and quantities.

For more information about work orders, see [Assembly Work Orders](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N2328390.html).

To assemble inventory through NetSuite WMS, complete the following tasks on the app:

-   [Picking Component Items for Work Orders](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_155993390806.html)
    
    If you want to reverse a work order pick task, see [Reversing Work Order Picking](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0804111823.html).
    
-   [Building Assembly Items for a Work Order](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_155993396614.html)
