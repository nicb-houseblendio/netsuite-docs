When you create locations that use bins, you can assign them to zones and bin records. You can also create strategies to specify zone priority and bin sorting during item putaway and order picking. To select bins across the inbound mobile processes on the app, you must create at least one putaway strategy.

To create zones and bins, see the following topics:

-   [Creating Zones](#section_1541433488)
    
-   [Creating Bin Locations or Carts](#section_1541433492)
    
-   [Moving Existing Items To Bin Locations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1541433541.html)
    

To configure strategies, see [Warehouse Management Strategies](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156406882224.html).

## Creating Zones {#section_1541433488}

Zones are areas in your warehouse that contain items with similar qualities or requirements. Some examples of warehouse zones might include an electronics zone, a special handling zone, or a refrigerated items zone.

In addition to helping you organize your warehouse, you can use zones in the definition of pick and putaway strategies.

When you create bin locations, you can assign them to zones. You may notice a performance impact if a zone has more than 4000 associated bins. You should create at least one zone record for each batch of 4000 bins in your warehouse. For information about bins, see [Creating Bin Locations or Carts](#section_1541433492).

#### To create a zone: {#procedure_1541433704}

1.  Go to _Lists > Supply Chain > Zone > New_.
    
2.  In the **Name** field, enter a name for your warehouse zone.
    
3.  In the **Location** field, select the warehouse location to which the zone belongs to.
    
    Note:
    
    This field displays only locations that use Warehouse Management. For more information, see [Creating Warehouse Locations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1541433484.html).
    
4.  Click **Save**.
    

## Creating Bin Locations or Carts {#section_1541433492}

Bin records define physical bin locations within your warehouse. To track on-hand inventory quantity in each bin, you can associate bin records with items. When you process orders for these items, NetSuite WMS displays the bin quantities on the receiving and fulfillment transactions.

For each warehouse and zone, you can create of the following bin types:

-   **None** - Default bin type
    
-   **Inbound Staging** - To stage received items, you can transfer them into this bin before you put them away
    
    You can set an Inbound Staging bin record as a cart and use it for processing cart moves through a mobile device.
    
-   **Storage** - Stores items after they are put away, but before they are picked, transferred, or moved
    
-   **WIP** - Stores assembly item components for work orders temporarily after they are picked, but before they are assembled
    
    If you use Manufacturing Mobile with Warehouse Management, you can enable **Use Bin in Manufacturing Mobile** for WIP bin types. This setting enables Manufacturing Mobile to access the WIP bin and specific capabilities on the NetSuite WMS app. For more information, see [Creating a WIP Bin for Manufacturing Mobile](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0622023514.html).
    
-   **Vendor Returns** - Contains items that you want to return to vendors for picking
    
-   **Picking** - Stores items that can be processed for fulfillment and shipping
    
-   **Outbound Staging** - To stage picked items for sales or transfer orders, you must transfer picked items into this bin before you ship them out. binUsing this bin, you can also stage items picked for vendor returns.
    

Note:

You can create multiple bin records at one time by adding all of the bin information to a CSV (comma-separated value) file and using the Import Assistant to upload the data to NetSuite. Using the Administrator role, the Import Assistant is available at Setup > Import/Export > Import Tasks > Import CSV Records. For more information, see [Importing CSV Files with the Import Assistant](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N343158.html).

On your mobile device, the use of bin types depends on the process, as described in the following:

-   You can store, transfer, create inventory, and pick items in these bin types: Storage, Picking, or None.
    
    Note:
    
    For inventory transfers and inbound processes, you must create at least one putaway strategy for your warehouse location. The app uses putaway strategies to determine which bins in a location to display when you select a destination bin. See [Defining Putaway Strategies](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4436271568.html).
    
-   You can remove Picking, None, Storage, and Inbound Staging bin types from the outbound order picking process through the **Block Bins From Wave Order Picking** setting. It includes removing a bin from bin lists and bin recommendations. The bin remains active and available for other mobile processes, such as inventory counting and bin transfers.
    
-   For the outbound order picking process, you can pick from Inbound Staging bins by enabling a setting on pick strategies. This setting does not apply to work order and vendor return picking. It excludes Inbound Staging bins that you block from the outbound order picking process. See [Bin Sorting with Pick Strategies](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1549310986.html#bridgehead_1550264236).
    
-   You can count items in all bin types, except those in WIP bins. See [Inventory Counts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1541441798.html).
    

For more information about bins, see [Accessing Bins on the App](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1122014929.html).

#### To create a bin location or cart: {#procedure_1541433711}

1.  Go to _Lists > Supply Chain > Bin > New_.
    
2.  On the Bin page, enter or select values in the following fields:
    
    -   **Bin Number** - Enter a number or code to identify the bin or designate a bin location in your warehouse.
        
        For example, you want to create a bin numbering nomenclature that uses aisle, pallet position, and level in the format aisle-pallet position-level. You can assign the name A1-01-01 to the bin in the first aisle in the first pallet position of the first level.
        
    -   **Bin Type** - Select the bin type.
        
        When you release orders to the warehouse, NetSuite WMS sorts bins by type to determine the recommended bin for picking. For more information, see [Pick Task Sorting and Recommended Bins](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1549310986.html).
        
    -   (Optional) **Sequence Number** - Enter the bin's sequence number in relation to other bins in your warehouse.
        
        Bin sequence numbers are used to determine which bins in a warehouse zone take priority when you pick items. When NetSuite WMS suggests bins for outbound order and vendor return picking, the bins appear in ascending order by bin sequence number. See [Pick Task Sorting and Recommended Bins](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1549310986.html).
        
    -   **Location** - Select the warehouse location of this bin.
        
        The location can't be changed after you save the bin record.
        
    -   **Zone** - Select the warehouse zone in which this bin is located.
        
        Note:
        
        You may notice a performance impact if a zone has more than 4000 associated bins. You shouldn't assign more than 4000 bins to the same zone. See [Creating Zones](#section_1541433488).
        
        If you assign a zone to a bin, you can also set it up on strategies for outbound and vendor return picking. See [Defining Pick Strategies](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1551132634.html).
        
3.  If you want to set an inbound staging bin as a cart, check the **Set as a Cart** box
    
4.  Depending on the bin type, you can check the **Block Bin From Wave Order Picking** box to remove this bin from the outbound order picking process.
    
5.  If you assign this bin as a preferred bin for an item and you want to replenish it using a plan, enter values in the following fields:
    
    -   **WMS Replen Max Qty** - Enter the maximum number of an item the bin can contain after a replenishment.
        
    -   **WMS Replen Min Qty** - Enter the minimum number of an item the bin should contain before a replenishment.
        
    -   **WMS Replen Qty** - Enter the default quantity of an item to be used for replenishment tasks.
        
    -   **WMS Replen Round Qty** - Enter the multiple to which the required replenishment quantity must be rounded down to determine the required number of replenishment tasks.
        
    
    For more information about inventory replenishment, see [Replenishment for Warehouse Management](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1541441806.html).
    
6.  (Optional) Set the following fields that you can use in your putaway strategies:
    
    -   **WMS Zone** - Select the warehouse zone you want to associate with this bin and to set up in a putaway strategy.
        
    -   **WMS Put Seq No** - Enter the bin's sequence number with regard to other bins in your warehouse.
        
    
    For more information about putaway strategies, see [Putaway Strategies](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1541436052.html) or [Defining Putaway Strategies](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4436271568.html).
    
7.  (Optional) To specify more details about a bin's location or position, you can set these fields: **WMS Pallet Position**, **WMS Aisle**, or **WMS Level**.
    
8.  For a WIP bin type, you can check the **Use Bin in Manufacturing Mobile** box if you want to use the bin for the Manufacturing Mobile processes.
    
9.  Click **Save**.
    

After you create bin records, you can set up item records for use with bin locations. See [Creating Items for NetSuite WMS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1541433512.html) or [Moving Existing Items To Bin Locations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1541433541.html).
