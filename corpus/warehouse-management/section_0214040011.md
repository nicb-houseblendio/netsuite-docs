To set up scanning of HIBC bar codes, add the unique labeler ID code (LIC) of each of your vendors. You can't assign multiple labeler ID codes to a vendor.

When you scan an HIBC bar code, the mobile app validates the LIC and vendor details based on the LIC records that you create.

#### To add HIBC labeler ID codes: {#procedure_0214040051}

1.  Go to Setup > Custom > LIC Mapping > New.
    
2.  On the Mobile - Labeler ID page, set the following fields:
    
    -   **Name** - Enter a unique name for this mapping of a labeler ID code and vendor.
        
    -   **Labeler Identification Code (LIC)** - Enter the four characters of the labeler ID code.
        
    -   **Vendor** - Select the vendor assigned to the labeler ID code.
        
3.  Click **Save**.
