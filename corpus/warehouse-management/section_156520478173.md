To access records and perform warehouse processing or setup tasks, use the following standard or custom roles:

-   **Administrator** - Use this standard role to enable features, install the SuiteApps, and create or manage records for NetSuite WMS.
    
-   **Mobile - Administrator** - Without having all the standard administrator permissions, use this custom role to customize and configure mobile processes and mobile printing.
    
-   **WMS Web Services Admin** - This custom role enables you to access and use the NSWMS Printer Driver Application. See [NetSuite WMS Shipping Integration Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158619718289.html).
    
-   **WMS Warehouse Manager** - Use this custom role to perform certain setup procedures for mobile processes, such as activating system rules and creating item aliases or cycle count plans. You can also use this role to create records for WMS.
    
    The WMS Warehouse Manager role has access to the inbound, inventory, and outbound processing tasks on mobile devices. Specific permissions within the role also enable you to perform related tasks on the NetSuite user interface, such as pick task reversals and completing inventory counts.
    
    Warehouse Management provides the following specialized roles for warehouse managers:
    
    -   **WMS Inbound Manager** - for inbound processing records and tasks only
        
    -   **WMS Outbound Manager** - for outbound processing records and tasks only
        
    
    If you use Ship Central, this role automatically gains access to the Ship Central records and mobile app for kiosk devices. See [NetSuite Ship Central Roles and Permissions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111033438.html).
    
-   **WMS Mobile Operator** - Use this custom role to perform all the warehouse processing tasks available in mobile devices.
    
    Warehouse Management provides the following specialized roles for operators:
    
    -   **WMS Inbound Operator** - for inbound processing tasks and outbound picking through mobile
        
    -   **WMS Outbound Operator** - for outbound processing tasks only
        
-   **Specialized User: WMS** - This standard role is not available by default. If you have this role, you can use it to access tasks on the mobile app. For more information, see [Specialized User: WMS Role](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0318011053.html).
    

If you want to customize or configure roles for Warehouse Management, see [Setting Up Roles for Warehouse Management](#subsect_156520498887).

## Setting Up Roles for Warehouse Management {#subsect_156520498887}

Depending on your business requirements, you can update existing roles or create new custom roles for Warehouse Management.

#### To set up roles for Warehouse Management:

1.  To set up a role, do one of the following:
    
    -   Create your copy of a role for warehouse managers or operators.
        
        Your copy of a custom role inherits the complete set of permissions, so you do not need to manually add each permission. To view the list of these roles, see [Warehouse Management Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156520478173.html).
        
        If you copy a role not based on any of the WMS roles, you can add the WMS permissions that suit your business requirements.
        
        For instructions on creating roles, see [Customizing or Creating NetSuite Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N285937.html).
        
    -   Update your existing custom role with the permissions that provide access to warehouse processing tasks through mobile devices.
        
        For instructions, see [Changing Custom Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N289485.html).
        
    
    To view the list of inbound, inventory, and outbound processing permissions, see [Warehouse Management Permissions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156520480478.html).
    
2.  To assign a role to a warehouse manager or operator, see [Assigning Roles to an Employee](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N897798.html).
    
3.  (Optional) On the employee record of operators or pickers, verify that they have the correct warehouse location.
    
    Pickers with no location setting can be assigned to pick tasks from any warehouse location. If you specify a location on an employee's record, you can assign only pick tasks that belong to wave transactions from the same warehouse location. For more information about picker assignment, see [Pick Task Assignment](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1548079991.html).
    
    For instructions on updating employee records, see [Adding an Employee](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N894212.html). For more information about locations, see [Creating Warehouse Locations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1541433484.html).
