## Configuring NetSuite WMS for Locations With No Bins {#subsect_161244368394}

NetSuite WMS uses the Bin Management feature settings on location and item records to determine when to use the standard bin processing flows. When you configure locations with no bins, you process associated items and orders without bins.

For example, wave transactions for these locations do not display recommended bins. On your mobile device, the order picking process does not include bin selection and staging.

You cannot perform bin-related tasks, such as bin transfers, putaway, and replenishment for locations with no bins. For more information about Bin Management, see [Enabling Features for NetSuite WMS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156399385061.html).

<a id="kaltura_player_198"></a>

The following table shows the location and item settings that control NetSuite WMS flows:

| NetSuite WMS Flow | Location | Item |
| --- | --- | --- |
| Nonbin flow | Use Bins = cleared | Use Bins = checked or cleared |
| Bin flow | Use Bins = checked | Use Bins = checked |

The Use Bins setting on item records doesn't affect how NetSuite WMS processes orders for items in locations with no bins. NetSuite WMS doesn't apply the standard bin flows even if you check the Use Bins box on the item record.

NetSuite WMS applies the standard bin flows only for locations and items that use bins. If you have items that don't use bins in these locations, receive, process, or fulfill them directly from their order transactions or through the NetSuite user interface. On a mobile device, you might encounter an error when you try to process items that don't use bins.

To configure NetSuite WMS for warehouse locations with no bins, create or update the following records in these topics:

1.  [Creating Warehouse Locations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1541433484.html) - To set up locations with no bins, clear the **Use Bins** box on the location record.
    
2.  [Creating Items for NetSuite WMS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1541433512.html) - (Optional) On item records, you can assign a pick sequence number that NetSuite WMS uses to sort and display pick tasks on a mobile device.
    
    Make sure that the **Use Bins** box is configured correctly, especially if you have items associated with multiple locations, some of which may use bins.
    
3.  [Creating Item Stock Locations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159708123882.html) - (Optional) You can create item stock locations and assign them to items in warehouses with no bins.
    

## NetSuite WMS Setup with Ship Central {#subsect_162127565264}

With the Pick, Pack, and Ship feature, you can use Warehouse Management with [NetSuite Ship Central](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_90092747693.html) (formerly, Pack Station). Complete your Warehouse Management setup first, before you begin your Ship Central setup. After you complete your Warehouse Management setup, the same features required for Ship Central should already be enabled on your account.

Some Warehouse Management capabilities apply to Ship Central too. Use of waves that you set up within Warehouse Management enables you to search for orders in waves when you pack through Ship Central.

Note:

You shouldn't use the packing capabilities available in NetSuite WMS and Ship Central at the same time. They process fulfillment and other record updates differently.

You can enable more features if you want to use Ship Central shipping instead of the Quick Ship capability within NetSuite WMS. For more information about required features and installation, see [NetSuite Ship Central Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111025719.html).

You can use the same PrintNode integration that you use for NetSuite WMS to set up Mobile Printing and Weighing Scale Support. You can add more printer devices that you want to use for Ship Central. Without this integration, you can enable Mobile Printing for both apps to save labels or documents. For more information, see [Mobile Printing and Weighing Scale Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0131112602.html)

If you activate the pick cartons rule for NetSuite WMS, you can search for orders to pack through Ship Central using pick cartons. You can activate separate Ship Central system rules for tally scanning and staging. To view the rules available for Ship Central packing and shipping, see [Configuring Ship Central Rules](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111041523.html).

Use the same login URL from SCM Mobile to access the NetSuite WMS and Ship Central apps on the appropriate devices. For more information, see [Hardware and Software Requirements](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161495429711.html#subsect_161495524434) and [SCM Mobile App Access](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161497091941.html).
