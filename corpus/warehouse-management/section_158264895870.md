You can set up item bar codes for scanning and mobile printing. You can scan the bar codes of items that you receive, store, or ship out of your warehouse.

If available for your device, you can set it up to automatically enter data after you perform a scan. See [Scanning Item Bar Codes in Apps](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156382538378.html#subsect_156382537880).

## Supported Bar Code Formats for NetSuite WMS {#subsect_158377213603}

Aside from the regular bar code formats supported by the Bar Coding and Item Labels feature, NetSuite WMS also supports the following advanced types and formats for scanning items:

-   **Composite** - Linear (1D) and data matrix (2D)
    
    You can scan composite bar codes of items that you receive in your warehouse through the app. After an item bar code has been initially scanned during the PO receiving mobile process, you can reuse it in other warehouse processes including TO receiving.
    
-   **GS1** - GS1-128 (1D) and GS1 DataMatrix (2D), with support for GTIN-14 (01)
    
-   **Health Industry Bar Code (HIBC)** - Code 128 and Data Matrix
    

For information about regular bar codes, see [Bar Codes and Item Labels](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N2215205.html).

The following table shows the mobile processes and advanced bar code types supported by specific bar code scanning capabilities:

| Capability | Bar Code Types | Mobile Process |
| --- | --- | --- |
| Advanced bar code scanning | GS1 and composite | All WMS processes, except inbound shipment receiving |
| HIBC | Purchase order, transfer order, returns receiving Inbound shipment receiving All inventory processes, except vendor returns picking Single and multiple order picking Search inventory |
| Tally scanning | GS1, composite | All except Inbound shipment receiving, Replenishments, and Create inventory |
| HIBC | Purchase order, transfer order, returns receiving Inbound shipment receiving Single and multiple order picking |
| Tally scanning across item types | GS1 and composite | Purchase order receiving Transfer order receiving |
| Bar code generation for label printing | GS1 DataMatrix only | Purchase order receiving Inbound shipment receiving Assembly build |
| Continuous scanning of lot or serialized items | GS1 and composite | Purchase order receiving (serial numbers only) Single and multiple order picking |

For mobile printing, the generated bar codes contain only the following supported attributes or GS1 application identifiers: item, GTIN, quantity, unit of measure, lot number, expiry date, and serial number. Custom mobile processes and custom application identifiers are not supported. For more information, see [Mobile Printing for NetSuite WMS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158411462538.html) or [WMS Standard Labels and Templates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158411462538.html#subsect_158411469285).

## Bar Code Scanning for Lot and Serialized Items {#subsect_3111809721}

When you scan a GS1 or composite item bar code that includes a lot number, serial number, or quantity, the appropriate fields are automatically populated with these details. If the pick task has remaining quantity to be picked, you can scan the next lot or serial number. This behavior applies to all supported mobile processes when you scan item bar codes on the Enter Item page. See [Supported Bar Code Formats for NetSuite WMS](#subsect_158377213603).

If you use the Tally Scanning rule and scan an item bar code that has a quantity, you can verify that the value in the Quantity field is equal to one. For lot items, if the value is greater than one, you can edit this field before you scan the next item or lot number. If the item bar codes have no quantity, the default quantity of one applies to each tally scan.

## Bar Code Setup Requirements {#subsect_158377223281}

Note the following browser and scanner requirements:

-   For your browser, you should use Google Chrome. Other browsers may not be able to display FNC1 (Function Code One) characters from scanned bar codes. For mobile device requirements, see [Mobile App Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1541432880.html).
    
-   To scan GS1 bar codes, the scanner should be able to display FNC1 characters and the bar code symbol.
    

## Bar Code Setup Procedures {#subsect_158948070458}

To begin your bar code setup, you must activate the **Enable Advanced Barcode Scanning?** system rule. For each warehouse location, you can enable GS1, HIBC, or Composite bar code, but not all formats. For instructions on activating system rules, see [System Rules for NetSuite WMS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156406918320.html).

After you activate the Advanced Barcode system rule, you can complete the following procedures depending on the bar code type you want to set up:

-   Composite bar code scanning setup - See [Creating Composite Bar Code Templates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1541433231.html).
    
-   GS1 bar code scanning setup - See [Creating Item Aliases](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1541433516.html).
    
    If you want to set up your own GS1 application identifiers for bar code scanning, see [Setting Up Custom Application Identifiers for GS1 Bar Code Scanning](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158264983840.html)
    
    For the list of supported standard or custom application identifiers, see [Standard GS1 Application Identifiers](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158264983840.html#subsect_158265001707).
    
-   HIBC bar code scanning setup - To set up the labeler ID codes for your vendors, see [Adding HIBC Labeler ID Codes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0214040011.html).
    

If you use NetSuite WMS with Ship Central, see [Bar Code Scanning for Ship Central](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0726023627.html).
