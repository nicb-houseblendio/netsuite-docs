Item aliases provide alternate names for items used in your warehouse. When prompted to enter an item on your mobile device, you can enter an item alias instead of the item name.

For example, you can create an item alias to track an item's vendor code. For an item named **red t-shirt** in your warehouse, but has a vendor code of **12345678**, enter **12345678** in the item alias' Name field and select **red t-shirt** in the Item field.

If you activate the **Enable Advanced Barcode Scanning?** system rule for GS1 bar codes, note the following guidelines for setting up item alias records:

-   You must create item alias records to map the GTIN-14 of a GS1 bar code to an item.
    
-   You can set up the GTIN (01 identifier) or the GTIN of Contained Trade Items (02 identifier).
    
    If you set up both GTINs in your item bar code, NetSuite maps only the GTIN (01 identifier) to the item alias. For more information about identifiers, see [Standard GS1 Application Identifiers](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158264983840.html#subsect_158265001707).
    
-   An item can have more than one associated item alias. However, the same item alias can't be associated with more than one item. For GS1 bar codes, you can't set up multiple item alias records that have the same GTIN-14 and item, but with different units.
    

For more information, see [System Rules for NetSuite WMS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156406918320.html) or [Bar Code Setup for NetSuite WMS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158264895870.html).

#### To create an item alias: {#procedure_1541433805}

1.  Using the WMS Warehouse Manager role, go to WMS Configuration > Configure Items > Item Aliases > New.
    
2.  On the WMS Item Alias page, in the **Custom Form** field, select **Custom WMS Item Alias Form**:
    
    This form provides a single Units field for default unit selection. If you're editing an existing record that uses the Standard WMS Item Alias Form, you don't need to change the form.
    
3.  Set the following fields:
    
    1.  **Name** - Enter a unique name for the item alias or enter the GTIN-14 for a GS1 bar code.
        
        Note:
        
        For GS1 bar codes, you must enter all digits of the GTIN-14, including the 14th digit reserved for the check digit.
        
    2.  **Item** - Select the item to which you want to assign this alias.
        
    3.  **Units** - (Optional) Select a default unit for the item alias.
        
        You can ignore this field If you use the Standard WMS Item Alias Form. Select a default unit in the **Alias Unit** field instead.
        
        Note:
        
        For GS1 bar codes, if you do not specify a default unit of measure in the item alias record, NetSuite WMS retrieves the transaction unit when you scan a GS1 bar code using your mobile device. Setting of default units apply to bar code scanning of GS1 formats only, and not to scanning of item aliases in other formats.
        
4.  Click **Save**
    

For GS1 bar code scanning only, you can set up custom application identifiers to add more data to your bar code. See [Setting Up Custom Application Identifiers for GS1 Bar Code Scanning](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158264983840.html).
