On the mobile app, you can update the count quantity when you perform a recount of an item. You can recount completed count tasks if you identify an error prior to approval submission. For rejected cycle counts, you can do a recount of all tasks or some tasks that may contain errors. The associated cycle count remains in Started status before and after you recount a task.

The following instructions apply to completed and rejected cycle counts:

#### To recount cycle counts:

1.  Access the Cycle Count process by doing the following:
    
    1.  On the mobile app, tap the menu icon at the top-left corner of the screen, and then tap **Main Menu**.
        
    2.  On the Main Menu page, tap **Inventory**.
        
    3.  On the Inventory page, tap **Cycle Count**.
        
2.  On the Cycle Count page, tap **Process Count**.
    
3.  On the Select Plan page, tap the **Show Completed** toggle.
    
4.  From the list, tap the number of the cycle count task you want to recount.
    
    This redirects you to the Enter Bin page for locations with bins or the Enter Item page. For instructions on entering the quantity counted, start from step 6 of the instructions on [Performing Inventory Counts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_155993309359.html).
    
    Repeat the steps for each cycle count task that you want to recount.
    

You must complete the associated cycle count to submit or resubmit it for approval. For instructions, see [Completing Inventory Counts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_155993309646.html)

After you complete a count, it changes from Started to Completed/Pending Approval status, during which you cannot perform a recount.
