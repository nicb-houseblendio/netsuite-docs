You can start inventory counts that have the Open status. NetSuite WMS takes a snapshot of the on-hand count of the items for counting by bin and serial number. It records the data on the inventory count.

You can start all inventory count types through the NetSuite UI. If you activate the **Start and Complete Counts on App** rule, you can start cycle counts through the mobile app. For more information, see [System Rules for NetSuite WMS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156406918320.html).

Complete either of the following procedures to start a cycle count:

-   [To start counts through the NetSuite UI:](#procedure_1541442125)
    
-   [To start cycle counts through the app:](#procedure_9104037540)
    

Using the NetSuite WMS user interface, you can process started manual or calculated inventory counts. Using a mobile device, you can perform started inventory counts generated from cycle count plans. When you count an item, you can edit the quantity but you can't add or delete items from count tasks.

#### To start counts through the NetSuite UI: {#procedure_1541442125}

1.  Using the WMS Warehouse Manager role, go to WMS Inventory > Cycle Count > Enter Cycle Count > List.
    
2.  From the Inventory Counts list, click **View** next to the count you want to start.
    
3.  On the Inventory Count page, click **Start Count**.
    
    To process manual and calculated inventory counts that you have started, see [Working with an Inventory Count](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2299731.html). To process started counts generated from cycle count plans, see [Performing Inventory Counts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_155993309359.html).
    

#### To start cycle counts through the app: {#procedure_9104037540}

1.  Access the Cycle Count process by doing the following:
    
    1.  On the mobile app, tap the menu icon at the top-left corner of the screen, and then tap **Main Menu**.
        
    2.  On the Main Menu page, tap **Inventory**.
        
    3.  On the Inventory page, tap **Cycle Count**.
        
2.  On the Cycle Count page, tap **Process Count**.
    
3.  On the Select Plan page, enter or select a plan by doing one of the following:
    
    -   To enter a cycle count plan, in the **Scan/Enter Plan #** field, scan or enter the name or number of the plan. If you enter the data, tap **Enter Plan #** to proceed.
        
    -   To select a cycle count plan, from the Cycle Count Plans list, tap the plan number.
        
4.  On the Select Task page, tap **Start Count**.
    
    To continue processing started cycle counts, you can proceed to step 7 of [Generating and Processing Counts on the App](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0807095555.html). To process started cycle counts at a later time, see [Performing Inventory Counts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_155993309359.html).
