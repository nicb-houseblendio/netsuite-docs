Bin or inventory transfers enable you to transfer inventory between storage bins or warehouse locations, respectively. For both types of transfers, NetSuite WMS can apply putaway strategies that you define to recommend destination bins for warehouse locations that use bins. When you transfer inventory, it decreases the stock level for the source bin location and increases the stock level for the destination bin location.

If you set up carts, you can transfer items from bins or carts onto carts before you store items in their new bin locations.

If you use Manufacturing Mobile with Warehouse Management, you can transfer items to WIP bins that you set up for Manufacturing Mobile. For more information, see [Creating a WIP Bin for Manufacturing Mobile](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0622023514.html).

To set up carts or WIP bins, see [Creating Bin Locations or Carts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161314312081.html#section_1541433492).

To process transfers through the app, see the following topics:

-   [Transferring Items Between Bin Locations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1541441872.html)
    
-   [Bin Transfer via Cart](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0220102704.html)
