NetSuite WMS provides system rules that add capabilities or enable alternate behavior for warehouse processing tasks on the app. You can activate a system rule that applies to all or specific warehouse locations. For some rules, you can also specify the mobile process for which you want to activate it.

For example, if you have a business exception that applies to one warehouse location, you can make a copy of the default system rule and assign the warehouse location to your copy.

See the following topics in this section:

-   [System Rule Values and Actions](#bridgehead_1541433088)
    
-   [Activating System Rules](#subsect_158827283631)
    

Depending on the capabilities you use, you can also set up these additional system rules:

-   [Activating the Allow Over-picking for Work Orders System Rule](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_28140403345.html)
    
-   [Activating System Rules for WMS Shipping Integration](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158619718289.html#subsect_0827101020)
    
-   [Activating the EDI System Rule](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156840265669.html#subsect_51084801915)
    

If you update your language preference for the NetSuite UI, be sure to apply it to the app and system rules. For instructions, see [Adding Language Options for Mobile App Translation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161522893749.html).

## Activating System Rules {#subsect_158827283631}

On a system rule record, configure the required or optional settings that apply to a rule. You can create multiple copies of rules that you can assign to specific locations, mobile processes, or transactions. On other records, you must also configure additional settings used by the rule.

If you update your language preference for the NetSuite UI, be sure to apply it to the app and system rules. For instructions, see [Adding Language Options for Mobile App Translation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161522893749.html).

#### To activate a system rule: {#procedure_1541433107}

1.  Using the WMS Warehouse Manager role, go to WMS Configuration > Configure Warehouse > System Rules.
    
    The System Rules List appears on the page.
    
2.  Next to the rule you want to activate, do one of the following:
    
    -   To activate an existing rule, click **Edit**. Proceed to step 4.
        
    -   If you want to create a copy of a rule, click **View**.
        
    
    The WMS System Rules page appears in edit or view mode.
    
3.  To create a copy of a rule, from the **Actions** list, select **Make Copy**.
    
    A new WMS System Rules page appears in edit mode.
    
4.  Enter or select values in the following fields:
    
    -   In the **Name** field, enter the default rule name.
        
    -   If you want to create a location-specific rule, in the **Location** field, select a warehouse location.
        
        Note:
        
        For the **Enable Warehouse Management** rule, do not specify a location. On location records, you can configure locations to use Warehouse Management. See [Creating Warehouse Locations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1541433484.html).
        
    -   In the **Rule Value** field, enter **Y**.
        
5.  Enter or select values in the fields for the following additional settings that are required or optional for some rules:

8.  After you activate a certain rule, you can activate other rules that depend on it. Also, make sure you update other records with settings required for some of the rules.
    
    See [System Rule Values and Actions](#bridgehead_1541433088).
