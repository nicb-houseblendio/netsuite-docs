NetSuite WMS leverages the mobility and convenience of handheld bar code scanners to process inbound, outbound, and inventory transactions and to post real-time updates to your NetSuite account.

## Handheld Bar Code Scanner Requirements {#subsect_158620357411}

For use with NetSuite WMS, refer to the following hardware and software requirements:

-   At least 256 MB flash memory
    
-   Only devices that have iOS (iPadOS 18 or higher versions for iPad; latest version for iPhone 13 or newer models) or Android (7.0 and higher versions) are supported. Support for versions may change subject to updates from their respective developers.
    
-   1D bar code scanner
    
    For bar code requirements, see [Bar Code Setup Requirements](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158264895870.html#subsect_158377223281).
    
-   4 inch or larger touch screen
    
-   802.11a/b/g enabled
    
-   Bluetooth enabled
    
-   HTML 5 & JavaScript enabled browser (TLS 1.2 compliant)
    
    Only devices that have iOS (iPadOS 18 or higher versions for iPad; latest version for iPhone 13 or newer models) or Android (7.0 and higher versions) are supported. Support for versions may change subject to updates from their respective developers.
    
-   Interactive Sensor Technology (IST)
    
-   Ruggedized or semi-ruggedized (optional)
    

## Setup Procedures for NetSuite WMS Mobile Capabilities {#subsect_158620365717}

You can set up additional capabilities depending on your mobile app requirements. Some capabilities apply to all apps supported by SCM Mobile, whereas others apply to NetSuite WMS only.

To set up additional capabilities for the mobile app, you can complete the following procedures:

-   [Language Preference Setup for SCM Mobile](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161495570632.html)
    
    Make sure that you use the same language for the NetSuite UI and the mobile app.
    
-   [Bar Code Setup for NetSuite WMS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158264895870.html)
    
    If available for your device, you can set it up to automatically enter and submit data after you perform a scan. See [Scanning Item Bar Codes in Apps](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156382538378.html#subsect_156382537880).
    
-   [Configuring Mobile App Settings](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158411380821.html)
    
    Mobile app settings include Mobile Printing and Weighing Scale Support, which require PrintNode integration. Without PrintNode integration, you can enable Mobile Printing to save soft copies of labels or documents. Before you enable these capabilities, see [NetSuite Ship Central FAQs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0831022109.html) to find more information about PrintNode integration.
    
    -   [Mobile Printing for NetSuite WMS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158411462538.html)
        
    -   [Weighing Scale Support](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161523537011.html)
        
-   [Mobile Configuration and Customization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1550867272.html)
    

### NetSuite WMS Mobile App Access Setup {#subsect_1022102513}

After you set up your language preference and other capabilities for the app, you can set up access to the mobile app and its mobile processes.

If you set up custom roles, be sure to provide them the appropriate permissions and access levels for transactions and records used in mobile processes. See [Warehouse Management Roles and Permissions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156520467974.html).

The following procedures enable you to set up mobile app access for your roles:

-   [Setting Up the Online Form User Role](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0814113835.html)
    
-   [SCM Mobile App Access](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161497091941.html)
    

Optionally, if you want to provide access to specific mobile process only, see the following topics:

-   To set up access to standard mobile processes, see [Configuring Menu Icons on Independent Mobile Pages](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0804040635.html).
    
-   To set up access to custom mobile process that you create, see [Customizing Mobile Processes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163614423814.html).
    

Menu icons remain hidden from roles that do not have access to a mobile process. To review basic mobile app pages and page elements, such as fields, buttons, and tables, see [SCM Mobile App Basics](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161556703949.html) or [Mobile Device Basics for NetSuite WMS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_156382508723.html).
