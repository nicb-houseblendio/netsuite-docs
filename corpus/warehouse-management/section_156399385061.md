-   [Inventory Count](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2296970.html)
    
-   [Advanced Item Location Configuration](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1503666392.html)
    
    Before you enable this feature, note the following item record changes:
    
    -   You can enable this feature to access the Item Location Configuration record from the item record. On the Item Location Configuration record, you can set up the pick sequence number of an item for each warehouse location that does not use bins. For more information about pick sequence numbers, see [Item Sorting](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1549310986.html#subsect_159837919248).
        
    -   For your existing item records, you can access the calculated inventory count fields on the Item Location Configuration record, instead of directly on the Locations subtab. See [Creating Items for NetSuite WMS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1541433512.html), [Creating Calculated Inventory Counts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1541442051.html), or [Locations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1504284372.html).

Before you can enable this feature, you must contact NetSuite Customer Support to provision this feature for your NetSuite WMS account. See [Inventory Details on an Inbound Shipment](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158136489199.html).

Then, you can activate the **Enable Restock option for returns?** rule for the app. For information about rules, see [System Rules for NetSuite WMS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156406918320.html).

## Warehouse Management Feature and System Rule {#subsect_156631324778}

Aside from installing the NetSuite WMS SuiteApps and enabling the prerequisite features, you must also complete the following setup tasks in the specified order:

1.  Enable the Warehouse Management feature. For instructions, see [To enable features for NetSuite WMS:](#rc_358530107).
    
    The Warehouse Management feature provides the capability to create wave transactions that you can use to release orders to the warehouse.
    
2.  Activate the **Enable Warehouse Management** system rule. For instructions, see [System Rules for NetSuite WMS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156406918320.html).
    
    The Enable Warehouse Management rule exposes the menu items you use to start working with the warehouse management capabilities.
    
    In case the Oracle NetSuite WMS SuiteApp is no longer active or installed on your account, make sure you inactivate this rule. Otherwise, you might encounter issues when you try to process orders through your mobile device.
    
3.  Make sure that you set up your new or updated login page URL on your mobile device. If you do not set up the latest URL, you might see a blank page on your mobile device screen. See [SCM Mobile App Access](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161497091941.html).
    

#### To enable features for NetSuite WMS: {#rc_358530107}

1.  Go to _Setup > Company > Enable Features_.
    
2.  Click the **Items & Inventory** subtab.
    
3.  Under the Inventory heading, check the box next to **Warehouse Management**.
    
    Note:
    
    If you do not find the Warehouse Management feature, contact NetSuite Customer Support to provision the feature for your account.
    
4.  (Optional) Enable other features that suit your business requirements. See [Additional Features for NetSuite WMS](#subsect_159725191767) or [Enabling Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N232138.html).
    
5.  Click **Save**.
