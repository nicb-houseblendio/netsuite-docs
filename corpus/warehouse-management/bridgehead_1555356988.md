You can delete waves that you don't want to release to the warehouse or process for picking. You might not be able to delete those with discrepancies. NetSuite WMS provides an option to update the wave status instead.

## Deleting Waves {#subsect_159233207716}

To access an existing wave, you can go to _Transactions > Inventory > Create a Wave > List_, and then click **Edit** for the wave you want to delete. In edit mode, you can click the Actions list and select **Delete**.

See the following guidelines for deleting waves:

-   You can delete unreleased waves.
    
-   You can delete a released wave if none of its pick tasks have been started or if you remove its associated pick tasks.
    
    If you want to reverse completed pick tasks and release the orders in a new wave, see [Pick Task Reversal](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1541443266.html).
    
    If you want to delete a pick task from a released wave, see [Viewing, Updating, or Deleting Pick Tasks](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1548082148.html).
    

Orders or line items that you disassociate from a deleted wave can be included and released in a new wave.

## Handling Wave Issues {#subsect_159233211570}

NetSuite WMS automatically displays a warning message on wave transactions that have discrepancy issues. These waves contain pick tasks that do not reflect the current status or state of the sales or transfer order. They can also be associated with orders released in other waves that have pick tasks in the same state. As a result, the pick tasks remain in In Progress status and you have no option to delete or complete the waves. To resolve these issues for all affected waves at the same time, you can click the link on the warning message to automatically set the pick tasks to Done status and the waves to Completed status.

For more information about wave and pick task statuses, see [Monitoring the Status of Released Orders](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1548081071.html).

To handle fulfillment generation issues on pick tasks, see [Viewing and Handling Fulfillment Generation Failures](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0305030933.html). For pick task failures, see [Viewing Pick Task Generation Failures](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0331104429.html) or [Viewing, Updating, or Deleting Pick Tasks](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1548082148.html).
