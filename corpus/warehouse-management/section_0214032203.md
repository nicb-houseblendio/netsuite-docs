For locations that use bins, you can block bins per item as you pick orders using your mobile device. To setup, complete the following procedures:

1.  Activate the **Enable bin reporting and blocking** system rule. See [System Rules for NetSuite WMS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156406918320.html).
    
2.  Add predefined reasons that operators can select when they block bins. If you use the Smart Count app, you can also indicate whether you want bins blocked for a particular reason to be included in spot counts. See [Defining Reasons for Bin Blocking](#subsect_80152723957).
    
3.  Add email addresses of recipients of bin blocking notifications. See [Setting Up Bin Blocking Notification](#subsect_50153021073).
    

For more information about bin blocking, see [Managing Bins Blocked from Order Picking](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0214043924.html).

If you want to block bins of a specific type from wave order picking, see [Creating Bin Locations or Carts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161314312081.html#section_1541433492).

## Defining Reasons for Bin Blocking {#subsect_80152723957}

You can add reasons for blocking a bin such as due to insufficient quantity or if the bin is used for damaged items. During order picking on the app, you can choose and report the reason for blocking a bin for an item.

For users of the Smart Count app, you can choose whether to enable spot counting for the reason you are creating or editing. On the NetSuite user interface, you can view the list of blocked bins for an item along with the reason. For more information, see [Managing Bins Blocked from Order Picking](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0214043924.html).

#### To define reasons for bin blocking: {#procedure_0214032755}

1.  Using the WMS Warehouse Manager role, go to WMS Configuration > Configure Warehouse > Reasons for Blocking > New.
    
    The WMS Reason for Blocking Bins page appears.
    
2.  Enter values in the following fields:
    
    -   **Reason Code** - Enter a unique code, which may include only the following special characters: hyphen (-), underscore (\_), and colon (:)
        
    -   **Reason Description** - Enter a short description for the reason.
        
        The description you provide appears in the list on the app from which you select a reason for blocking a bin.
        
    -   **Include Bin in Counts** - If you use the Smart Count app, check this box to indicate that you want bins blocked for this reason to be included in spot counts.
        
        When you approve a spot count, you automatically unblock the bin for the item.
        
3.  Click **Save**.
    

## Setting Up Bin Blocking Notification {#subsect_50153021073}

Warehouse Management sends out a confirmation email after you block a bin for an item. You can assign two default recipients in your General Preferences.

You can also assign different recipients per warehouse location that use bins.

#### To set up bin blocking notification on General Preferences: {#procedure_0214033045}

1.  Using the Administrator role, go to Setup > Company > General Preferences.
    
2.  On the General Preferences page, click the **Custom Preferences** subtab.
    
3.  In the Oracle NetSuite WMS section, do the following:
    
    1.  In the **Primary Recipient** field, select the name of the person you want to assign.
        
    2.  (Optional) If you want to assign another person, in the **Additional Recipient**, you can select the name.
        
4.  Click **Save**.
    

#### To set up bin blocking notification per location:

1.  Using the Administrator role, go to Setup > Company > Locations.
    
2.  On the Locations list, next to the location, click **Edit**.
    
3.  On the Locations page, make sure that the **Use Warehouse Management** box is checked.
    
4.  To assign recipients, do the following:
    
    1.  In the **Blocked Bin Primary Contact**, select the name of the recipient.
        
    2.  (Optional) If you want to assign another recipient, in the **Blocked Bin Additional Contact**, select the name.
        
    3.  If you update your language preference for the NetSuite UI, be sure to apply it to the app and system rules.
        
        For instructions, see [Adding Language Options for Mobile App Translation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161522893749.html).
        
5.  Click **Save**.
