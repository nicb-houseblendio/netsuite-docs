You can reverse pick task lines through the NetSuite UI or the NetSuite WMS app. Through the NetSuite UI, you can perform full pick task reversals only. To undo order picking, it sets the picked quantity back to zero and moves the pick task line to Done status. It also deletes fulfillments or specific fulfillment lines associated with the reversal. You can release reversed lines from the order in a new wave.

Through the NetSuite WMS app, you can undo order picking for the quantity you specify. For a partial reversal, a new fulfillment is created for the picked quantities, including other picked orders, that you do not reverse. For information fulfillment creation preferences, see [Setting Warehouse Management Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156406848826.html).

You can reverse failed pick task lines if you want to release the associated order line in another wave, for instance. Note that you can't reverse lines that have the **Override Fulfillment Creation** setting enabled. For more information, see [Viewing, Updating, or Deleting Pick Tasks](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1548082148.html).

Using the NetSuite user interface or app, you can reverse pick tasks with fulfillments that have not yet been marked Shipped. You can't directly reverse pick tasks for pending billing or billed orders. Before you can reverse them, you must delete the fulfillment records first. For more information, see [Voiding, Deleting, or Closing Transactions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N563543.html).

If you use the Ship Central app to pack orders, you can also reverse pick tasks for those orders. When NetSuite deletes or updates the associated fulfillments, it also deletes the pack cartons and pallets, including printed labels and related documents. For more information, see [Ship Central Packing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111042907.html).

## Reversing Pick Tasks Using the NetSuite UI {#subsect_161721858581}

To perform full reversals through the NetSuite UI, you can search for the wave or order associated with the pick tasks.

#### To reverse pick tasks using the NetSuite UI: {#procedure_1541443277}

1.  Using the Warehouse role, go to Shipping > Picking > Reverse Picks.
    
    Important:
    
    Don't use the Pick Reversal menu option available from the previous version of NetSuite WMS.
    
2.  On the Reverse Picks page, in the **Location** field, select the warehouse location where the pick tasks have been released.
    
3.  Search for the pick tasks you want to reverse by doing one of the following:
    
    -   To search by wave transaction, in the **Wave #** field, enter the number of the wave transaction.
        
    -   To search by order transaction, in the **Transaction Type** field, select one of the following transaction types: **Sales Order** or **Transfer Order**. Then, in the **Transaction #** field, enter the number of the order transaction.
        
4.  Click **Display**.
    
5.  On the **Line Items** subtab, in the **Reverse Pick** column, check the box next to each pick task line you want to reverse.
    
6.  Click **Submit**.
    

## Reversing Pick Tasks on the App {#subsect_161721860917}

To perform reversals through the app, you can select the pick task line and specify the full or partial quantity. For partial reversals, you can further enter the quantity for a specific inventory status, lot number, or serial number.

Partial reversals do not apply to non-inventory items and kit/package items, which requires reversal of components all at the same time.

For locations with bins, you return picked quantities back to the bin from which they were picked. If you want to select the destination bin, you can activate the **Choose bins for reversed pick task items?** rule. To activate rules, see [System Rules for NetSuite WMS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156406918320.html).

#### To reverse pick tasks through a mobile device:

If you transfer the items to a temporary bin, you can perform a bin transfer to move them to their storage bins. You can view updates to the wave and order transactions associated with the reversed pick tasks.

1.  Access work order reversal by doing the following:
    
    1.  On the WMS app, tap the menu icon at the top-left corner of the screen, and then tap **Main Menu.**
        
    2.  On the Main Menu, tap **Picking.**
        
    3.  On the Picking menu, tap **Reverse Picks**.
        
2.  On the Select Order Type page, tap one of the following order types: **Sales Order** or **Transfer Order**.
    
3.  On the Enter Wave or Order page, in the **Scan/Enter Wave or Order #** field, scan or enter the wave or order number. If you enter the data, tap **Enter Wave/Order #** to proceed.
    
4.  On the Select Pick Task Line page, from the Line Items list, tap the order associated with the pick task you want to process.
    
5.  On the Pick Task Line Details page, you can review the item and picking details for the task.
    
    For kit items, a message appears to inform you that all pick tasks for other kit components are also reversed.
    
6.  If you can choose the destination bin, in the **Scan/Enter Bin** field, scan or enter the bin to which you want to transfer the reversed items. Alternatively, in the **Original Bin** field, you can tap the bin to transfer them to the bin from which they had been picked.
    
7.  Tap **Reverse**.
