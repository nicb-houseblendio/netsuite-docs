You can generate an inventory report to view item details that appear in its columns, as follows:

-   Item
    
-   Item Description
    
-   Location
    
-   Bin Location - Only for locations that use bins
    
-   Units
    
-   Quantity On Hand
    
-   Available Quantity
    
-   Inventory Status - Only if you use the Inventory Status feature
    

For more information about inventory quantities, see [Assessing Stock Levels](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2262573.html).

You can export generated inventory reports into an Excel file. To export all results, multiple files of up to 10 MB each may be generated. On the NetSuite UI, you can view up to 4000 results only.

#### To generate an inventory report:

1.  Using the WMS Warehouse Manager role, go to WMS Reporting > Inventory Reporting > Generate Inventory Report.
    
2.  On the Generate Inventory Report page, in the **Location** field, select the location that contains the inventory.
    
3.  (Optional) In any of the following fields, select filters for the data you want to include in the report:
    
    -   **Item** - Select an item name or number.
        
    -   **Bin Location** - If your warehouse location uses bins, select a bin number.
        
    -   **Inventory Status** - If you use the Inventory Status feature, select a status.
        
4.  Click **Display**.
    
    The Inventory Report table appears with list and details of items based on the location and your filters.
    
5.  (Optional) To export the inventory report, click **Export to Excel File**. Then, open or save the file in your local computer.
