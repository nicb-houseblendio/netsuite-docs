You can complete all types of inventory counts through the NetSuite UI. If you activate the **Start and Complete Counts on App** rule, you can complete cycle counts through the mobile app. Either way, you can complete inventory counts that include tasks that have not been counted or processed. For more information, see [System Rules for NetSuite WMS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156406918320.html).

Follow one of these procedures to complete a count:

-   [To complete an inventory count through the NetSuite UI:](#procedure_1541442140)
    
-   [To complete counts on the app:](#procedure_72104259214)
    

Depending on a count's results, NetSuite may create either or both of the following inventory adjustment transactions after approval:

-   One positive inventory adjustment to increase on-hand quantity
    
-   One negative adjustment to decrease on-hand quantity
    

When you return to the item record of an item for which there is a completed count, the Inventory subtab shows the following:

-   **Last Count Date** - Date when the last count occurred
    
-   **Next Count Date** - System-calculated next date to enter an item count
    
-   **Count Interval** - Preset count interval
    

#### To complete an inventory count through the NetSuite UI: {#procedure_1541442140}

1.  Log in to your NetSuite WMS account using the Warehouse role.
    
2.  Go to Inventory > Cycle Counting > Enter Cycle Count > List.
    
3.  Click **View** next to the count you want to complete.
    
4.  Click **Complete Count**.
    
    Note:
    
    Until you complete an inventory count, you cannot release or start a new inventory count for that item.
    

#### To complete counts on the app: {#procedure_72104259214}

1.  Access the Cycle Count process by doing the following:
    
    1.  On the mobile app, tap the menu icon at the top-left corner of the screen, and then tap **Main Menu**.
        
    2.  On the Main Menu page, tap **Inventory**.
        
    3.  On the Inventory page, tap **Cycle Count**.
        
2.  On the Cycle Count page, tap **Process Count**.
    
3.  On the Select Plan page, do either of the following:
    
    -   In the **Scan/Enter Plan #** field, scan or enter the cycle count plan number. If you enter the data, tap **Enter Plan #** to proceed.
        
    -   From the Cycle Count Plans list, tap the number.
        
4.  On the Select Task page, tap the **Show Completed** toggle to review the processed cycle count tasks. On the Cycle Count Tasks table, review any tasks that have not been counted.
    
    Note:
    
    If you have remaining uncounted tasks, you can process them before completing this inventory count. Otherwise, the task will be submitted for approval without a counted quantity.
    
5.  Tap **Complete Cycle Count**.
    
6.  On the message, to confirm that you want to complete the entire inventory count, tap **OK**.
    

Completed inventory count records change from Started to Completed/Pending Approval status. To approve completed counts, see [Approving or Rejecting Inventory Counts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_155993310131.html).
