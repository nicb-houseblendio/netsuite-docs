Releasing orders to the warehouse initiates the outbound processing of orders for fulfillment using wave transactions. It enables you to select and prioritize the orders or order lines you want to include in a wave. When you release a wave, the orders become available for picking or staging through the mobile app.

NetSuite WMS provides the following options for releasing orders:

-   [Creating Wave Transactions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1548078883.html)
    
-   [Creating a Wave Release Schedule](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161721775390.html)
    
-   Picking of unreleased single orders - When you pick an unreleased order through the app, NetSuite WMS automatically generates the wave and its pick tasks. See [Picking Items for Single Orders](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161618347171.html).
    
-   [Re-releasing Lines with Backorders](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0803020225.html)
    

You can apply pick decomposition when you create or generate waves for release. For more information, see [Pick Task Decomposition](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0207120728.html).

NetSuite WMS provides the following records for order release:

-   **Wave** - Wave transactions contain the list of orders you want to release and their associated pick tasks. For more information, see [Creating Wave Transactions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1548078883.html).
    
-   **Pick Task** - Pick task subrecords display picking details, including quantity, status, and pick assignment. It records picking details gathered through a mobile device.
    
    You can generate pick task subrecords only from wave transactions. For more information, see [Pick Task Assignment](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1548079991.html).
    

You can set preferences to apply default settings on waves that you create and their generated pick tasks. See [Setting Warehouse Management Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156406848826.html).

![Release Orders to Warehouse Workflow diagram](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/WarehouseManagement/Workflow-ReleasingOrdersToWarehouse.png)

In a sample scenario, you create a wave with orders to be delivered by a shipping provider along a specific route. Narrow down the list of orders based on priority or ship date. From a wave, NetSuite WMS generates the pick tasks, which you can assign to warehouse operators or pickers. You can manage both the list of orders for release and pick tasks on a wave transaction.

Pickers that you assign to one or more tasks can update the picked quantity on the mobile app. Any picker can access and process unassigned pick tasks. Based on pick task updates, NetSuite WMS updates the status of the associated wave. It also generates items fulfillments for completed pick tasks. On both wave transactions and pick task subrecords, you can track the progress as soon as you release the orders to the warehouse.

## Supported Transactions and Item Types for NetSuite WMS {#subsect_156511029393}

To include orders in wave transactions, make sure they meet the following conditions for transactions and item types:

-   Sales or transfer order transactions must be unfulfilled.
    
-   Orders must have fully or partially committed line items not included in any active waves.
    
    This condition doesn't apply to non-inventory items, which can't be committed.
    
-   Items must belong to the following supported item types:
    
    -   Inventory and assembly items, including, matrix, lot numbered, and serialized items
        
    -   Kit/package items, including kits with kit components
        
        Service and non-inventory items (for sale and for resale only)
        
        Note:
        
        To release and fulfill orders for these item types, you must enable the **Can be Fulfilled/Received** setting on the item record. For more information about creating fulfillable items, see [Entering Preferences on Item Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2173412.html) or [Fulfilling Inventory](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2281951.html).
        
    -   Item groups
        
-   Orders or line items must be associated with a warehouse location.
    
    By default, NetSuite WMS filters transactions to include in a wave using the location in the header for sales orders and the from location for transfer orders. For information about creating warehouse locations, see [Creating Warehouse Locations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1541433484.html).
    

See [Creating Wave Transactions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1548078883.html) to learn how specific preferences affect the orders that you can release to the warehouse. For more information about items, see [Item Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N2222944.html).

## NetSuite WMS Limitations {#bridgehead_1551729982}

Note the following limitations for waves and releasing orders to the warehouse:

-   You can create waves only for sales and transfer order transactions.
    
-   The following preferences or settings do not apply when fulfilling released orders:
    
    -   **Fulfill Based on Commitment** - Non-committed item quantities can't be included in waves. Using NetSuite WMS, you can release and fulfill only fully or partially committed items. See [Fulfillment](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1388149.html#bridgehead_N1390212).
        
    -   **Allow Overage on Item Fulfillments** - For released orders, you can't pick more than the quantity on the pick task. See [Picking Orders](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1541442950.html).
        
    -   **Use Item Cost as Transfer Cost** - Even with this preference enabled for transfer orders, you can still release and fulfill partially committed items. For more information, see [Setting Transfer Order Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2310077.html).
        
-   Sorting of picks through FIFO (first in, first out) and LIFO (last in, first out) are both not supported. For more information, see [Pick Task Sorting and Recommended Bins](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1549310986.html).
    
-   Refer to other limitations and conditions in the following topics: [Creating Wave Transactions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1548078883.html) and [Creating Custom Wave Criteria Templates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1550845655.html).
