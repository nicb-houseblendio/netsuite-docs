You can search for inventory within your warehouse by item name, number, or UPC. From the search results, you can view the quantity on hand. For kit/package items, you can view the details for each component.

If your warehouse location uses bins, you can also search by bin number to display the list of items within bins that match the keyword.

If you enable Mobile Printing, you can search for items to print item and pallet labels, including those for component items. For numbered items, you can print labels with a lot or serial number. Only the default manual printing option is available for inventory searches. If you activate the Advanced Barcode rule, you can print labels with the item bar code in GS1 format. If you don't use PrintNode integration with printing, you can save generated item labels into your file cabinet.

If you want to print item labels during receiving on the app, see [Inbound Processing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1541435915.html). For more information about Mobile Printing, see [Label Printing and Reprinting](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_163113050855.html). To activate system rules, see [System Rules for NetSuite WMS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156406918320.html).

#### To search for inventory:

1.  On your mobile device, tap the menu icon at the top-left corner of the screen, and then tap **Search Inventory**.
    
2.  On the Search Inventory page, in the search field, enter the item name, number, or UPC.
    
    Alternatively, if your warehouse location uses bins, you can enter the bin number.
    
    Tip:
    
    Results appear after you type three characters.
    
3.  If you can print or save item labels, you can do the following:
    
    1.  From the results, tap the item. Additionally, to print labels for a kit component item of from the Kit Components table, tap the component item.
        
    2.  On the Item Information page, tap the more icon.
        
    3.  From the submenu, tap **Print, Print GS1 Barcode,** or **Print Lot/Serial #**.
        
    4.  For lot or serial items, on the Select Lot/Serial # to Print page, tap the box next to the numbers you want to print. Then, tap **Print**.
        
        One lot or serial number appears for each item label.
        
    5.  On the Print popup window, you can modify the printing options, and then tap **Print**.
