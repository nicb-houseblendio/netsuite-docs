In this section, find the answers to frequently asked questions about setting up or using NetSuite WMS.

### When should I use Pick Reversal vs Override Fulfillment Creation?

If you want to undo item picking done through the mobile app, you can perform a pick task reversal. It removes picked quantities from pick tasks and associated orders. It also deletes the generated fulfillments. However, if a fulfillment contains non-reversed item lines, it removes only the item lines that you have reversed.

You can reverse failed pick task lines, except those that have the Override Fulfillment Creation setting enabled. This setting appears only for failed pick task lines.

You can check the **Override Fulfillment Creation** box if you do not want to keep trying to generate the fulfillment record from the pick task. It does not reverse picked items, so they remain in the staging bin.

After you check this box, you can generate the fulfillment directly from the order transaction. When you provide the inventory details on your fulfillment record, be sure to select the staging bin that contains the picked items.

For more information, see the following topics:

-   [Pick Task Reversal](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1541443266.html)
    
-   [Viewing, Updating, or Deleting Pick Tasks](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1548082148.html)
    
-   [Viewing and Handling Fulfillment Generation Failures](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0305030933.html)
    

### In addition to the required NetSuite WMS SuiteApps, what other SuiteApps provide additional capabilities for NetSuite WMS?

To suit your business requirements, you can install the following SuiteApps that provide preconfigured capabilities within NetSuite WMS:

-   **NetSuite Ship Central** - Enables packing or shipping of orders that you pick through the NetSuite WMS app. You can also reverse picking of orders that you pack through the Ship Central app. For more information, see [NetSuite WMS Setup with Ship Central](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_156382465711.html#subsect_162127565264).
    
-   **Manufacturing Mobile** - Provides capabilities associated with the following settings available to users of the Warehouse Management feature:
    
    -   **Item Process Family** and **Group** item record setting - Available to users of the Warehouse Management feature. See [Label Printing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0717015324.html).
        
    -   **Use Bin in Manufacturing Mobile** bin record setting - Available to users of the Warehouse Management feature and NetSuite WMS SuiteApp. See [Creating a WIP Bin for Manufacturing Mobile](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0622023514.html).
        
    -   **Allow over-picking for work orders** system rule - Available to users of the Warehouse Management feature and NetSuite WMS SuiteApp. See [Activating the Allow Over-picking for Work Orders System Rule](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_28140403345.html).
        
-   **Smart Count** - Enables you to spot count items in blocked bins and unblock them automatically through the Smart Count app. For more information, see [System Rules for NetSuite WMS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156406918320.html).
    
-   **Lot Autonumbering** - Enables you to activate the following system rules to generate lot or serial numbers on the app: **Autogenerate Lot Numbers?** or **Autogenerate Serial Numbers?** For more information, see [System Rules for NetSuite WMS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156406918320.html).
    

NetSuite Ship Central, Manufacturing Mobile, and Smart Count use the same required SCM Mobile SuiteApp for NetSuite WMS. For more information, see [SCM Mobile Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161495429711.html).
