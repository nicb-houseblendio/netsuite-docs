If you activate the **Set Landed Cost During Receiving** rule, you can update landed cost settings on the app only for transactions enabled with landed cost allocation per line. If you track landed cost for an item, you can enter or update the landed cost category and actual amount. If you set up estimated landed cost, you can choose a landed cost template associated with the item. Your landed cost settings on the app reflect on item receipts and don't update the associated order.

If you activate the **Manually post item receipts?** rule **,** you can view landed cost settings on the WMS Open Task record prior to posting a receipt. Landed cost settings eventually appear on generated or manually created item receipts. To activate landed cost for the app, see [System Rules for NetSuite WMS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156406918320.html).

To enter landed cost on orders, see [Entering Landed Cost on a Transaction](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2418831.html) or [Guidelines for Estimated Landed Cost on Transactions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4576833448.html).

#### To receive with actual or estimated landed cost:

1.  Access the receiving process for the purchase order, transfer order, or inbound shipment.
    
    For instructions, see one of the following topics:
    
    -   [Receiving Orders](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1541435923.html)
        
    -   [Receiving Inbound Shipment Orders](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158212308061.html)
        
2.  After you select an order and item, on the Enter Quantity page, enter the quantity you want to receive. Then, do one of the following:
    
    -   To enter actual landed cost, in the **Landed Cost Category** field, select a category associated with the item. In the **Landed Cost Amount** field, enter the actual landed cost amount for the quantity of items.
        
        Note:
        
        A landed cost category can't be applied to the same item multiple times within an order. Be sure to enter the quantity to which you want to apply the same landed cost category for the item.
        
    -   To enter estimated landed cost, in the **Landed Cost Template** field, select a template associated with the item.
        
3.  Tap **Enter Quantity**.
    
4.  For numbered items, you can do the following:
    
    -   For lot items, you can select another lot number and enter the quantity you want to receive. Repeat from step 2.
        
    -   For serialized items, you can enter another serial number.
        

To post item receipts through the app, see [Manually Posting Item Receipts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_155993562169.html). On item receipts, you can view landed cost calculations and allocation on the **Landed Cost** subtab.

Within the NetSuite UI, you can access transactions to view generated item receipts or WMS Open Task records with your landed cost settings. For more information about landed cost, see [Landed Cost Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2417056.html) or [Estimated Landed Cost](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4576786578.html).
