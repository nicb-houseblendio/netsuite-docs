To receive items from purchase orders, customer returns, or transfer orders, you can scan the item bar code using the app. If you activate the **Enable Advanced Barcode Scanning?** rule, you can scan specific item bar code types. For more information about rules that affect the receiving process flow, see [Receiving Orders](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1541435923.html). To activate rules, see [System Rules for NetSuite WMS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156406918320.html). Note which rules apply to PO Receiving only.

Before you start using the app, check your device if it has a setting that enables automatic data entry after a scan. Without this setting, you can tap the button at the footer to proceed to the next page. For more information about scanning options, see [Scanning Item Bar Codes in Apps](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156382538378.html#subsect_156382537880).

The following procedure does not include steps and process flows for Tally Scanning.

#### To receive orders through scanning on the app:

On the confirmation page, you can review the receiving details. If you automatically post receipts, it includes details of the item receipt. You can access the receipt and updated order through the NetSuite UI.

If you receive a partial quantity, you can repeat from step 4 to process additional quantities of the item until you complete the order. If you want to manually post a receipt for a partially or fully received item, see [Manually Posting Item Receipts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_155993562169.html).

1.  On the app, access order receiving by doing the following:
    
    -   Tap the menu icon at the top-left corner of the screen, and then tap **Main Menu**.
        
    -   From the Main Menu, tap **Receiving**.
        
    -   On the Receiving menu, depending on the type of transaction you want to process, tap **Purchase Order**, **Transfer Order**, or **Returns**.
        
    
    The Receiving page for the specific transaction type appears. The field names and options on this page vary depending on the transaction type.
    
2.  On the Receiving page, do one of the following:
    
    -   In the **Scan/Enter PO # or Item** field, scan the item bar code.
        
    -   To scan a manufacturing part number, tap **Find PO By MPN**. Then, in the **Scan/Enter MPN** field, scan the bar code for the part number.
        
    -   To select from lists or if the item or part number could not be found, try the other options: **Select PO From List**, **Find PO By Vendor**, or **Find PO By Item**.
        
3.  On the Select PO # page, from the Open Orders list, tap the order number you want to receive.
    
4.  On the Enter Item page, in the **Scan/Enter Item** field, scan the item bar code.
    
    Note:
    
    Don't tap the item name from the list or table to avoid replacing the scanned bar code data. If your device doesn't enter scanned data automatically, tap the **Enter Item** button.
    
    If your item bar code includes the lot number, expiry date, and quantity, you can skip entry of these details in succeeding fields.
    
5.  If the item has multiple aliases, in the Select Item Alias page, do one of the following:
    
    -   If the item bar code includes the item alias, in the **Scan/Enter Item Alias** field, scan the item.
        
    -   From the list of item aliases, tap the item alias.
        
6.  For lot-numbered items, if you can autogenerate the numbers, on the Autogenerate Lot Number page, do the following:
    
    1.  In each field, enter the lot item detail.
        
    2.  Tap **Autogenerate Lot Number**.
        
7.  For lot item bar codes, in the Enter Lot Number page, set the following fields for details not included in the bar code:
    
    1.  In the **Expiry Date** field, enter or select the expiration date for the lot number.
        
    2.  In the **Scan/Enter Lot Number** field, scan or enter the lot number. Optionally, you can select a lot number from the Expected Lots list.
        
        Note:
        
        If you scan a bar code in this field, don't select a lot number from the list to avoid losing the scanned data.
        
    3.  Tap **Enter Lot Number**.
        
8.  On the Enter Quantity page, do the following:
    
    1.  If you use the Inventory Status feature, in the **Inventory Status** field, select the status of the item.
        
    2.  In the **Enter Quantity** field, enter the number of items you want to receive.
        
    3.  If your item has multiple units, you can change the unit.
        
        Tip:
        
        To view unit conversion rates, tap the unit icon beside the **Quantity Remaining** field. Each time you edit the quantity, make sure that you assign the correct unit.
        
    4.  For customer returns, if you automatically post receipts and you can edit the **Restock?** field, you can select **YES** or **NO**.
        
        Your selection appears in the **Restock?** column on item receipts. If you manually post item receipts, the app follows your Restock Returned Items preference to set this column..
        
    5.  (Optional) If your warehouse location does not use bins and you want to view the list of stock locations associated with the item, tap the **Show Stock Locations** toggle.
        
    6.  (Optional) For PO receiving, if you can capture weights from your scale, in the **Weight Units** field, select the unit of measure for the weight of each quantity. Then, tap **Capture Weight**.
        
        If you change the weight unit along with the weight, make sure that you tap **Capture Weight** again.
        
        The **Weight Per Quantity** field displays the weight of each item quantity. You can tap the info icon to view the calculated total weight of the received quantity.
        
    7.  (Optional) If you can print or save item or pallet labels for regular or lot items for PO receiving, tap **Print**.
        
    8.  Tap **Enter Quantity**.
        
9.  In the Enter Serial Number page, do the following:
    
    1.  In the **Scan/Enter Serial Number** field, scan the item bar code that contains the serial number. If you can scan item bar codes that contain multiple serial numbers, you can scan them instead.
        
        Alternatively, from the list of serial numbers, you can copy a serial number and paste it into the field. If you enter the data, tap **Enter Serial Number** to proceed.
        
    2.  (Optional) If you can print or save item or pallet labels for PO receiving, tap **Print**.
        
10.  For locations that use bins, in the Enter Bin page, do either of the following:
     
     Note:
     
     You can't choose a bin that does not contain any quantity of the item.
     
     -   In the **Scan/Enter Bin** field, scan or enter the number of a storage bin. If you enter the data, tap **Enter Bin** to proceed.
         
     -   From the list of bins, tap the bin name or number.
