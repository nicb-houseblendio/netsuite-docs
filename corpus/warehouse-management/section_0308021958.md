On the mobile app, you can record the details of items in your location that you want to pick and return to vendors. You can fully or partially pick items from Vendor Returns type of bins and for standalone vendor returns only. After you pick and stage the items, the app automatically generates the item fulfillment.

To create Vendor Returns bins, see [Creating Bin Locations or Carts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161314312081.html#section_1541433492).

Note the following settings that may affect vendor returns processing on the app:

-   When you create Vendor Returns bin types, the location, zone, and sequence number settings affect which and how NetSuite WMS recommends bins for picking.
    
-   Pick strategies for a location can be set to filter out Vendor Returns bin types that you can pick from. They may also affect the bin that appears in the Recommended Bin field. For more information, see [Defining Pick Strategies](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1551132634.html).
    
-   On vendor return authorizations, you can view the quantity of items available in Vendor Returns bins. If you have items for return contained in other bins, you can transfer them into Vendor Returns type of bins.
    
-   Item fulfillment creation for vendor returns follows your preference, as described in this topic, [Setting Warehouse Management Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156406848826.html).
    

#### To pick items for vendor returns:

1.  Access vendor returns by doing the following:
    
    1.  On the mobile app, tap the menu icon at the top-left corner of the screen, and then tap **Main Menu**.
        
    2.  On the Main Menu page, tap **Vendor Returns**.
        
2.  On the Enter Vendor Return # page, do one of the following:
    
    -   In the **Scan/Enter Vendor Return # or Item** field, scan or enter the vendor return authorization number or item. If you enter the data, tap **Enter Vendor Return or Item**.
        
        Item details that you can scan or enter include the name, item number, item alias, or UPC.
        
    -   To select from the list of transactions, tap **Select Vendor Return # From List**, and then tap the transaction you want to process.
        
        Tip:
        
        If you do not find the vendor return from the list, you can search by vendor name by tapping the search icon.
        
    -   To search for a transaction, tap one of the following: **Find Vendor Return # By Vendor**, **Find PO by Item**, or **Find Vendor Return # by Item**.
        
3.  On the Select Pick Task page, do one of the following:
    
    Tip:
    
    The pick task table includes the Picked column that you can display to view the number of picked items from partially processed tasks. You can also tap the **Show Completed** toggle to view pick task lines with fully picked items.
    
    -   Select the item associated with the pick task line from the vendor return.
        
    -   If you are redirected to this page and you want to stage partially picked items, tap **Go To Staging**. Proceed to step 7.
        
4.  On the Enter Bin page, do one of the following to select a Vendor Returns bin that contains the item to pick:
    
    -   In the **Scan/Enter Bin** field, scan or enter the bin name. If you enter the data, tap **Enter Bin** to proceed.
        
    -   In the **Recommended Bin** field, tap the bin.
        
    -   Tap the **Show all bins** toggle, and then select one from the list.
        
5.  For regular and serialized items, on the Enter Item page, do one of the following:
    
    -   In the **Scan/Enter Item** field, scan or enter the item name, number, or UPC. If you enter the data, tap Enter Item to proceed.
        
    -   In the **Item to Pick field**, tap the item.
        
6.  On the Enter Quantity page, do the following:
    
    1.  In the **Enter Quantity** field, enter the number of items you want to pick.
        
        Alternatively, if you activate the Tally Scanning rule, you can scan each item until you reach the quantity you want to pick. For lot items, you can scan the lot number or select it from the Available Lots list
        
    2.  Optionally, you can change the values in the following fields depending on the features you use: unit and **Inventory Status**.
        
    3.  To proceed, tap one of the following buttons:
        
        -   If the Vendor Returns bin does not have available items for picking, you can tap **Bin Empty**. This option redirects you to the Select Pick Task page on which you can stage the partially picked items. Return to step 3.
            
        -   To save the quantity, tap **Enter Quantity**.
            
7.  For serialized items, on the Enter Serial Number page, in the **Scan/Enter Serial Number** field, scan or enter the serial number. If you enter the data, tap **Enter Serial Number** to proceed.
    
8.  On the Pick Task Complete page, you can view the details of the picked item. Then, tap one of the following buttons:
    
    -   **Go to Staging** - Tap this button to stage all the picked items in the same bin
        
    -   **Next Pick Task** - Tap this button to process other pick tasks before you stage them altogether in the same bin.
        
9.  On the Enter Staging Bin page, to choose a staging bin, do one of the following:
    
    -   In the **Scan/Enter Staging Bin** field, scan or enter the outbound staging bin. If you enter the data, tap **Enter Staging Bin** to proceed.
        
    -   From the list of staging bins, tap a bin.
        

On the Staging Complete page, you can view the details of the picked and staged items. To continue processing vendor returns, tap any of the following buttons:

-   **Next Pick Task**\- Tap this button to process other pick tasks from the same vendor return. You can stage the other picked items in a different bin.
    
-   **Next Vendor Return** - Tap this button to process another vendor return.
    

After you stage one or more pick tasks at the same time, the app generates an item fulfillment. It creates additional item fulfillments for each pick task that you stage separately.
