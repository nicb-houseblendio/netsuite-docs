You can create a schedule for automatically generating bin replenishment tasks. You can specify when and how often you want to run the schedule. NetSuite WMS notifies you about the results through email addresses that you provide.

You can limit the items you want to include by setting filters on a schedule. You can also provide a saved search that returns the list of items you want to replenish based on predefined filtering criteria.

If you want to run your custom schedule and deploy your script, see [Methods of Deploying a Script](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4519293976.html).

#### To schedule bin replenishments: {#procedure_74143329205}

1.  Using the WMS Warehouse Manager role, go to WMS Inventory > Bin Replenishment > Schedule Bin Replenishment > New.
    
2.  On the WMS Bin Replenishment Schedule page, enter basic details in the following fields:
    
    -   **Name** - Enter a unique name for the replenishment schedule.
        
    -   **Location** - Select a warehouse location of the bins you want to replenish.
        
3.  In the Items section, you can specify the items in bins you want to replenish by doing one of the following:
    
    -   **Item** - Select one or more items you want to include in the schedule.
        
    -   **Saved Search** and **Saved Search Column** - Instead of specifying items, you can select a saved search that provides the list of items. You must also select the specific column that provides the item names or numbers from the saved search.
        
4.  Optionally, if you do not provide a saved search, you can add the following filters to further narrow down the items:
    
    -   **Item Classification** - Select one of the following inventory classification or velocity codes assigned to the items: **A, B**, or **C**.
        
    -   **Item Family** - Select the name of the item family to which the items belong.
        
    -   **Item Group** - Select the name of the item group to which the items belong.
        
5.  In the Replenishment Schedule section, specify when and how often you want to run the schedule:
    
    -   **Frequency** - Select the option that corresponds to how often you want to run the schedule within the day.
        
    -   **Day of Week** - Select the day or select **Every Day** to specify when you want to run the schedule within each week.
        
    -   **Run Time Start** - Enter the time within the day you want to start the schedule.
        
    -   **Run Time End** - Enter the time within the day you want to end the schedule.
        
    -   **Assigned To** - Select the name of the warehouse operator you want to assign to the replenishment tasks generated from the schedule.
        
6.  In the Email Notification section, you can enter email addresses for the following notifications:
    
    -   **Email Address for Failed Status** - Enter the email address to which you want to send notifications for failed runs. You can use a colon **:** to separate multiple addresses.
        
        Note that failures include cases where you have no preferred bins that need to be replenished
        
    -   **Email Address for Success Status** - Enter the email address to which you want to send notifications for successful runs. You can use a colon **:** to separate multiple addresses.
        
7.  Click **Save**.
    

On the **WMS Open Task** subtab, you can view the details of a scheduled run and the replenishment tasks. You can process each task on the mobile app. For instructions, see [Replenishing Primary Bin Locations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1541442264.html).
