NetSuite WMS generates item fulfillments for orders that you release in wave transactions. To track released orders picked through the app, it uses pick task subrecords generated for each wave. On the app, warehouse operators can access these pick tasks to determine the items and quantities they need to pick. After they complete one or more pick tasks, NetSuite WMS generates the fulfillment records. On fulfillment records, it adds details of the picked items, which include quantities, lot or serial numbers, inventory statuses, and bins. It also updates associated sales or transfer orders with the picked quantity.

For more information about picking and staging of released orders, see [Releasing Orders to the Warehouse](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1548078373.html) or [Picking Orders](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1541442950.html).

Pick task reversal for orders or quantities that have not been shipped may also generate fulfillments automatically. For more information, see [Pick Task Reversal](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1541443266.html).

Note the following settings, rules, and preferences that affect fulfillment generation:

-   To determine whether to create fulfillments for orders, order lines, or released orders, NetSuite WMS follows your setting for the **Create Item Fulfillment at Locations Using Warehouse Management** preference.
    
-   By default, newly generated fulfillments are assigned the **Picked** status. If you inactivate the **Manually pack orders?** system rule, it assigns the **Packed** status instead.
    
-   For warehouse locations that use bins, pick tasks are completed after the staging of picked items in outbound staging bins. On fulfillment records, the inventory detail shows each staging bin and the quantity transferred to it from the picking bin.
    
-   Fulfillment generation times may vary depending on the number of orders, order lines, or pick task line. For warehouse locations that use bins, it may also depend on your setting if you activate the **Enable bulk staging of large pick tasks** system rule.
    

See how the following features affect fulfillment generation for released orders:

-   **Fulfillment creation with Multiple Shipping Routes**
    
    If you use the Multiple Shipping Routes feature and generate fulfillments per order, you can create a fulfillment record for each shipping route. Warehouse operators can pick, pack, and ship orders for items in the same shipping route. For more information, see [Multiple Shipping Routes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1263041.html).
    
-   **Fulfillment creation with Intercompany Cross-Subsidiary Fulfillments**
    
    When you process cross-subsidiary fulfillments for released orders, you create separate waves for an order according to the inventory location on the line items. In the same way, you generate separate item fulfillments for these orders, depending on your fulfillment creation preference. The Per Order preference consolidates the line items for each order in a released wave. For more information, see [Intercompany Cross-Subsidiary Fulfillment](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1515621767.html).
    

Users with the Administrator role can view the status of item fulfillment generation.

#### To view the status of fulfillment generation:

1.  Go to Setup > Company > Company Management > Bulk Processing Status List.
    
2.  On the Process Status page, you can expand Filters and in the **Process Type** field, select **Order Release Fulfillment**.
    
    This filter displays the fulfillment creation jobs in your queue.
    
3.  Click **Refresh** to get the latest status of the jobs in the list.
    
    For more information, see [Searching Bulk Processing Jobs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1495464846.html).
    
4.  On the Process Status list, you can do the following:
    
    -   To view the results for each pick task line, you can click the status link in the **Submission Status** column.
        
        The list displays the status for each line, including any processing errors or the fulfillment record link for the successfully completed lines.
        
    -   To view the errors for a job, you can click the error link in the **Message** column.
        
5.  To view the results of fulfillment generation, you can click the status link for a job.
    
    The list shows you the status and result for each pick task line included in the job. It also displays any processing errors or the fulfillment record link for successfully completed pick task lines.
    

Alternatively, on a pick task subrecord, you can also access the link to a generated fulfillment record for each pick task line. To open a pick task, you can go to _Transactions > Inventory > View Pick Tasks_. You can also view any failures encountered and retry or override fulfillment generation. Pick task lines with failures display the Failed status.

If you want to view a list of pick task lines along with failures, see [Viewing, Updating, or Deleting Pick Tasks](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1548082148.html).

For more information about fulfillment generation failures, see [Viewing and Handling Fulfillment Generation Failures](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0305030933.html).
