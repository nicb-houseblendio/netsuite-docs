Picking an order involves pulling items from your warehouse's inventory to fill an open order. You can pick a single order or multiple orders at a time. When you pick items using a mobile device, NetSuite WMS can guide you through the warehouse by suggesting the bin locations from which to pick items. It also decreases the available stock level of picked items. On your mobile device, you automatically skip the steps for bin entry and staging when you pick non-inventory items or items from warehouse locations that don't use bins.

For single order picking, you can select an unreleased order to pick and automatically generate the wave transaction. Like orders released in waves, sales or transfer orders must be in Pending Fulfillment status and must have committed lines.

For more information about order processing in NetSuite WMS, see [Releasing Orders to the Warehouse](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1548078373.html) or [NetSuite WMS Limitations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1548078373.html#bridgehead_1551729982).

You can set the following system rules or preferences to modify order picking through NetSuite WMS:

-   NetSuite WMS submits jobs to process the picking of orders that exceed 50 pick task lines and the staging of orders that exceed 25 pick task lines. If you activate the system rules for bulk picking or bulk staging, you can change these default limits for the number of pick tasks.
    
-   If you activate the **Enable Tally Scan** rule, each time you scan a picked item, you increment the picked quantity by 1. This rule displays the Tally Scan field on the Enter Quantity page.
    
-   If you activate the **Use carton** rules, you can use cartons for single and multiple order picking. It adds the Enter Carton page to the appropriate order picking flow.
    
    You can reuse a pick carton after you pack all of its items. The fulfillments associated with the items must be in Packed status.
    
    Aside from multi-order picking, the **Use cartons for multi-order picking?** rule also applies to bulk order picking of serialized items only. Serialized items included in waves for bulk order picking follow the multi-order picking flow. You can pick serialized items per order and place them in pick cartons.
    
    If you activate one of these rules and use the Mobile Printing capability, you can enable pick carton label printing or saving. You can activate the **Print pick carton labels?** rule for each process in which you use pick cartons. It adds the Mobile Printing capability to the Enter Carton page.
    
-   For picked or staged items, you can set your fulfillment preference to automatically generate fulfillment records per order or per order line. When you process partially picked items, you must close the pick tasks first, before you can generate the fulfillments.
    
    For more information about fulfillment preferences, see [Setting Warehouse Management Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156406848826.html).
    
-   To enable picking items from zones, see [Picking Orders from a Zone](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1541443233.html).
    

## Picking Orders Partially {#subsect_8165619340}

On the mobile app, you can use the Bin Empty option to indicate that a bin has insufficient quantity. For non-inventory items or locations with no bins, you can use the No Stock option. Both options redirect you to the page for selecting other pick tasks to process. To generate item fulfillments for partially picked items, you must close the pick task by marking it Done. For more information, see [Posting Item Fulfillments for Partially Picked Orders](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1541443017.html).

The **Enable bin blocking** rule provides the option to block bins and modifies the default partial picking flow for inventory items. It provides options to stage partially picked items right away or along with other items within the order. For more information, see [Managing Bins Blocked from Order Picking](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0214043924.html).

If you activate the **Automatically mark partial picks as Done** rule, you don't need to manually set the pick task status to Done. After you submit a partially picked item, the fulfillments are automatically generated based on your fulfillment preference. For locations that use bins, fulfillment creation occurs after you stage the partially picked items.

For more information about these rules, see [System Rules for NetSuite WMS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156406918320.html).

## Serialized Items in Waves {#subsect_53151717812}

You can pick serialized items through the single order or multiple order picking flows. You can include serialized items in waves set to bulk picking and process them through the multiple order picking flow on the app. If you activate rules for multi-order picking with cartons and tally scanning, they also apply to serialized items within bulk picking waves.

For warehouses that use bins, the **Pick All** button appears on the Enter Serial Number page that enables you to empty out a bin. You can pick all the serial numbers from a bin that contains the same or less than the quantity you want to pick. The button doesn't appear when you select a bin that contains more than the quantity you want to pick. In this case, you can scan or enter the serial numbers to pick from the bin. The same conditions apply to partially picked orders or order lines.

For example, you want to process a pick task that requires 11 quantities of serialized Item D. You have two picking bins that contain quantities of Item D as follows: Bin B = 5 and Bin C = 15. You can pick all from Bin B if you enter 5 as your quantity to pick. If you enter a number less than 5, the Pick All button will not appear. After you empty out Bin B, you can scan or enter the serial numbers to pick the remaining quantity from Bin C.
