On the app, you can primarily access a bin based on its associated warehouse location, which you can specify on the bin record. You can view or select items in bins to process for each location. Depending on the features you use, you can specify item details, which include lot numbers, serial numbers, and inventory statuses. You can access bins that contain items with these details.

Across the mobile processes, you can use bins based on their bin type. For example, you can place received items in storage bins and pick items for sales orders from picking bins among other types. For more information about bin types, see [Creating Bin Locations or Carts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161314312081.html#section_1541433492).

For some bin types, you can enable additional bin settings, including the following:

-   **Include Inbound Staging Bins** - On pick strategies, you can enable the setting to pick items from Inbound Staging type of bins. They become available for the order picking processes, including single, bulk, and multiple order picking.
    
-   **Set as Cart** - When you create an Inbound Staging bin type, you can enable this setting and use the cart during item putaway. Otherwise, you can use this type of bin to stage received items only.
    
-   **Use Bin in Manufacturing Mobile** - If you use Manufacturing Mobile and create a WIP bin type, you can enable this setting. See [Creating a WIP Bin for Manufacturing Mobile](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0622023514.html).
    
-   **Block Bin From Wave Order Picking** - When you create certain bin types, you can enable this setting to remove the bin types from bin lists and recommendations.
    
-   **Use Pick to Clean Process at Locations Using Warehouse Management** - For bin types that support order picking, you can set this preference used to sort and recommend bins. For more information, see [Setting Warehouse Management Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156406848826.html).
    

NetSuite WMS also considers additional bin-related settings on item records, which include the following:

-   **Use Bins** - When you enable this setting, you may use bins for an item in one warehouse location and not use bins for the same item in another location. NetSuite WMS applies the bin flow across mobile processes only for items that use bins within locations that use bins.
    
    For more information about this bin setting, see [Configuring NetSuite WMS for Locations With No Bins](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_156382465711.html#subsect_161244368394).
    
-   **WMS Mix Items in Bins** - When you store or put away the received item, bins that contain other items become available. You can mix regular items with lot items and serialized items in the same bin.
    
-   **WMS Mix Lots in Bins** - When you store or put away a specific lot number for the received lot item, bins that contain other lot numbers become available.
    
-   **Preferred Bin** or **WMS Preferred**\- If you assign a preferred bin to an item, NetSuite WMS recommends the bin with this setting for picking before it recommends non-preferred ones. It also recommends preferred bins based on pick strategies that you create.
    
    You can also generate plans to replenish preferred bins based on replenishment settings on bin or item records.
    

To view all item settings related to bins, see [Creating Items for NetSuite WMS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1541433512.html).

For some mobile processes, access to bins on the app may also depend on system rules provided within NetSuite WMS. To use Inbound Staging bin types, you can activate the rule to stage received items. You can also activate the rule to include bin selection during pick reversal. If you activate the rule for bin blocking, you may not access specific bins when you pick orders through the app. See [System Rules for NetSuite WMS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156406918320.html).
