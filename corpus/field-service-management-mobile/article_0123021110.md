Field Service Mobile includes the following screen types:

-   [Login Screen](#bridgehead_4141951459)
    
-   [Task List Screen](#bridgehead_81142040970)
    
-   [Add Task Screen](#bridgehead_27142133557)
    
-   [Selected Task Details Screen](#bridgehead_84142215880)
    

## Login Screen {#bridgehead_4141951459}

The **Login** screen lets you enter your email address and password to log into the system.

![FSM Mobile login screen](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/FieldServiceManagement/mobile_login_screen_v2.png)

## Task List Screen {#bridgehead_81142040970}

The **Task List** screen displays assigned tasks ordered from oldest to newest date.

Depending on the resolution of your mobile device, a map showing the location of all tasks in the list is displayed.

![FSM Mobile task list screen](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/FieldServiceManagement/mobile_screen_layout_task_list_screen_v2.png)

## Add Task Screen {#bridgehead_27142133557}

The **Add Task** screen lets you add a new task that isn't necessarily related to your currently-assigned tasks.

![FSM Mobile add task screen](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/FieldServiceManagement/mobile_screen_layout_add_task_screen_v2.png)

## Selected Task Details Screen {#bridgehead_84142215880}

The **Selected Task Details** screen displays more details for a selected task including a map displaying the route to the task location.

In addition to the additional task detail, this screen displays a list of tab headings. It also lets you start and complete the selected task

![FSM Mobile selected task details screen](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/FieldServiceManagement/mobile_screen_sections_selected_task_details_map_view_screen_icon_v4.png)

## Selected Task Tab Screen {#bridgehead_33142259324}

The **Selected Task Tab** screen displays a particular tab's content so that you can read or record information for the selected task.

Each tab may have multiple screens.

![FSM Mobile selected task tab screen](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/FieldServiceManagement/mobile_screen_layout_selected_task_tab_screen_v2.png)
