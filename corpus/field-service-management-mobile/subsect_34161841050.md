This screen lets you collect all the data you need to create a quote for a customer.

![NextService Mobile quote screen.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/FieldServiceManagement/MobileUserGuide/mobile_quote_tab_screen_detail_icon.png)

| Section | Task | Effect | Availability | Errors/Alerts Shown | Highlighted in Screenshot |
| --- | --- | --- | --- | --- | --- |
| Back button | Lets you go to the **Quote List screen**. | If there's one or more saved quotes for this task, then **Field Service Mobile** displays the **Quote List screen**. If there are no saved notes for this task, then this button has no effect. | Always | None | 1 |
| Toggle Selected Task Details Screen Visibility button | Lets you access functions on the **Selected Task Details screen**. This button, positioned in the **Control Bar**, spans the entire width of the screen except where other buttons are placed. Quote number is displayed inside this button when you've saved the quote. | Shows the **Selected Task Details screen**. | Always | None | 2 |
| Delete Note button | Lets you delete a quote saved to the cloud and with an **Open** status. | Deletes the current quote from the cloud. If there's one or more quotes saved for the task after you delete, then Field Service Mobile displays the **Quote list**. If there are no quotes saved for the selected task after you delete, then Field Service Mobile displays the **Quote Details screen** with all data entry fields set to default values. | When viewing a quote that has been saved and the status for that quote is **Open**. | None | 3 |
| Saving To Cloud indicator | Informs you that the quote is being saved to the cloud. | None | After you tap the **Save** button until the data has been saved to the cloud. | None | 4 |
| Discard Changes button | Lets you clear any changes made in the **Quote Details screen**. | Shows the alert below. If you tap **OK** on the alert, then **Field Service Mobile** reverts the contents of all data entry fields to the previous values. If no data has been saved to the cloud for the current quote, then all data entry items will be set to default values. If data has been saved previously for the current quote, then all values revert to their previous values when the note data was last saved. If you tap **Cancel** on alert, then the alert is hidden, and no changes are made. | As soon as changes are made to any of the data entry items in the screen. | Shows the alert 'Are you sure you want to discard your changes? OK. Cancel'. | 5 |
| Save button | Lets you save any changes made in the Quote Details screen. | Saves all the data you entered in the Quote Details screen. | As soon as the Quote Item list contains one or more Quote Item List entry instances. | None | 6 |
| Add New Quote Item button | Lets you go to the **Add/Edit/Delete/View Quote Item screen** to add a new quote item. | Shows the **Add/Edit/Delete/View Quote Item screen** with the data entry items set to default values. | When the current quote status is set to **Open**. | None | 7 |
| Quote Item list | Displays all of the quote items for the current quote. | None | Always | None | 8 |
| Quote Item List entry | Displays the **Item**, **Description**, **Quantity** and **Amount** values for a particular quote item. | Displays the **Add/Edit/Delete Quote Item screen** with the data entry items set to the values of the current quote item. | When one or more quote items have been added for the current quote. | None | 9 |
| Total text display field | Displays the total amount for each quote item saved to the cloud, plus any applicable tax. If you haven't saved a quote item to the cloud yet, then its value is unknown and will not be included in the total amount displayed. If you edit a quote item by changing either the **Item dropdown list** contents or the **Quantity text field** contents in the **Add/Edit/Delete Quote Item screen**, then the previous value of the **Amount text display field** in the **Quote Item List entry** will be used in the total. If you delete a quote item by using the **Add/Edit/Delete Quote Item screen**, then the previous value for the **Amount text display field** will be used in the total. At the same time, any change made as detailed as above, you should save the data to the cloud using the **Save button**. Wait for the completion of this saving action for the **Total text display field** to be updated with the correct value. | None | Always | None | 10 |
| Purchase Order Number text field | Lets you enter a purchase order number for the current quote. | None | When the value of the **Status text display field** of the current quote is **Open**. If the **Status text display field** of the current quote is set to any value except **Open**, then the **Purchase Order Number text field** is replaced with a non-editable **Purchase Order Number text display field** filled with the value of the **Purchase Order Number text field** when you save the data to the cloud. | None | 11 |
| Status text display field | Displays the status of the quote. | None | Always | None | 12 |
| Send Mail checkbox | Lets you decide whether an email is sent to the address entered in the **Email text field** when you save the current quote to the cloud. If the box is checked, an email is sent. If the box is cleared, no email is sent. | None | When the value of the **Status text display field** of the current quote is **Open**. If the **Status** text display field of the current quote is set to any value except **Open**, then the **Send Mail checkbox** is replaced with a non-editable **Send Email text display field**. If the **Send Mail checkbox** was checked when the quote was saved to the cloud, then the **Send Mail** text display field is set to **Yes**. If the **Send Mail checkbox** was unchecked when you save the quote to the cloud, then the **Send Mail text display field** is set to **No**. | None | 13 |
| Email text field | Displays the default email address for the current case contact person. However, you can edit the contents of the Email text field as needed. | None | When the value of the **Status text display field** of the current quote is **Open**. If the **Status text display field** of the current quote is set to any value except **Open**, then the **Email text field** is replaced with a non-editable **Email text display field** filled with the value of the **Email text field** when you save data to the cloud. | None Note: This field lets you type in any character. However, if the data you entered does not form a valid email address, the data will be deemed invalid and the **Save button** will not be available. | 14 |
| Apply To Current Job checkbox | Lets you decide whether the quote you're creating will be applied to the project and case of the selected task. | None | When the value of the **Status text display field** of the current quote is Open. If the **Status text display field** of the current quote is set to any value except **Open**, then the **Apply To Current Job checkbox** is replaced with a non editable **Apply To Current Job text display field**. If the **Apply To Current Job checkbox** was checked when you save the quote to the cloud then the **Apply To Current Job text display field** is set to **Yes**. If the **Apply To Current Job checkbox** was unchecked when you saved the quote to the cloud, then the **Apply To Current Job text display field** is set to **No**. | None | 15 |
| Clear Signature Drawing Box button | Lets you clear the contents of the **Signature drawing box**. | Clears the contents of the **Signature drawing box**. | When the **Signature drawing box** contains data. | None | 16 |
| Signature drawing box | Lets you capture the customer's signature to show that the customer has approved creating a sales order from the quote. | None | When the value of the **Status text display field** of the current quote is **Open**. If the **Status text display field** of the current quote is set to any value except **Open**, then the **Signature drawing box** is replaced with a non editable **Signature drawing display box** filled with the data from the **Signature drawing box field** when you save data to the cloud. | None | 17 |
