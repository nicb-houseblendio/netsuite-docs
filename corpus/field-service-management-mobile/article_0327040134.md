Field Service Management (FSM) Mobile is organized by screens and tabs.

## Screens {#subsect_0327041118}

FSM Mobile is organized into these standard screen types:

-   **Login screen** - Technicians sign in with an email address and password.
    
-   **Task List screen** - Home screen that displays assigned tasks and, depending on device resolution, a map panel.
    
-   **Task Details screen** - Displays details for the selected task, lets technicians start and complete the task, and gives them access to task tabs.
    
-   **Task tab screens** - Each tab opens a screen for viewing or capturing specific information related to the task.
    

Note:

Navigation can vary by device resolution. For example, switching between tabs and the task details panel may behave differently on phones and tablets.

## Tabs {#subsect_0327041128}

FSM Mobile setup may vary, but standard mobile tabs include:

| Mobile Tab Name | Related Help Topic | Description |
| --- | --- | --- |
| Asset (Asset Details or Site Details) | [Asset Tab in FSM Mobile](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0130095730.html) | View information about the asset linked to the task, such as model and photo. |
| Contact | [Contact Tab in FSM Mobile](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0130101048.html) | View task contacts and launch the device phone or email apps using contact details. |
| Details (Sign-off Details) | [Details Tab in FSM Mobile](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0130103506.html) | Capture final job notes and signatures used to record completion, including technician signature and optional customer name, email, and signature. |
| Time | [Time Tab in FSM Mobile](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0201045059.html) | Record time items, such as service actions and hours, for the selected task. |
| Expenses | [Expenses Tab in FSM Mobile](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0130013633.html) | Create expense report lines for the task and upload receipt images. |
| Files | [Files Tab in FSM Mobile](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0130020256.html) | Attach files from your device to the selected task. File types depend on device and configuration. |
| Notes | [Notes Tab in FSM Mobile](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0130040140.html) | Record text notes relating to the selected task. |
| History | [History Tab in FSM Mobile](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0130023036.html) | View completed tasks carried out on the current asset, including task details and related historical information. |
| Consumables (Inventory) | [Consumables Tab in FSM Mobile](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0902094550.html) | Record inventory usage. Technicians record usage, and NetSuite creates the sales order after the task is finished. |
| Sales Order | [Sales Order Tab in FSM Mobile](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0902112932.html) | Create a sales order in real time. Unlike consumables, after you save the sales order, NetSuite creates the sales order and displays it in the mobile app. |
| Quote | [Quote Tab in FSM Mobile](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0130041350.html) | Create a quote. Customers can sign on the device and FSM Mobile can create a sales order from the accepted quote. |
| Receive | [Receive Tab in FSM Mobile](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0131035224.html) | Receive items into the technician's location, based on transfer orders pending receipt. |
| Return | [Return Tab in FSM Mobile](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0131041508.html) | Create a list of items in the technician's location to send back to the default warehouse. |
| Transfer Order (Order Parts) | [Transfer Order Tab in FSM Mobile](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0201050811.html) | Request parts from another warehouse to be transferred to the technician's location. |
| Task (Actions) | [Task Tab in FSM Mobile](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0201043416.html) | Create a new task for the existing case to schedule a follow-up visit when more work is needed. |
