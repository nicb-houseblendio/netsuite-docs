This screen lets you view all of the received items added for this task.

![NextService Mobile received item list screen.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/FieldServiceManagement/MobileUserGuide/mobile_receive_tab_item_list_screen_detail_icon.png)

| Section | Task | Effect | Availability | Errors/Alerts Shown | Highlighted in Screenshot |
| --- | --- | --- | --- | --- | --- |
| Toggle Selected Task Details Screen Visibility button | Lets you access functions on the **Selected Task Details screen**. | Shows the **Selected Task Details screen**. | Always | None | 1 |
| Add Received Item button | Lets you add a new receive item. | Shows the **Add/Edit/Delete/View Receive Item screen** with all data entry item values set to default. | Always | None | 2 |
| Received Item list | Lets you see all current received items that have been added. | None | Always | None | 3 |
| Received Item List entry | Shows the basic information for each received item that has been added. This also functions as a button that displays **Add/Edit/Delete Receive Item screen** when you tap it to edit or delete the information about the received item. | Shows the **Add/Edit/Delete Receive Item screen** and fills the data fields with the data from the selected received item. | When there's one or more received items added for the selected task. | None | 4 |
