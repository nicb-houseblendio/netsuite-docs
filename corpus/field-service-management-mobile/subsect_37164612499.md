This screen lets you view all new tasks that have been added.

![NextService Mobile task list screen.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/FieldServiceManagement/MobileUserGuide/mobile_task_list_tab_icon.png)

| Section | Task | Effect | Availability | Errors/Alerts Shown | Highlighted in Screenshot |
| --- | --- | --- | --- | --- | --- |
| Toggle Selected Task Details Screen Visibility button | Lets you access functions on the **Selected Task Details screen**. | Shows the **Selected Task Details screen**. | Always | None | 1 |
| Add New Task button | Lets you add another new task for the current case. | Shows the **Add/Edit/Delete Task For Current Case screen**. | Always | None | 2 |
| New Task list | Lets you see all new tasks that have been added. | None | Always | None | 3 |
| New Task List item | Displays the basic information for each new task that has been added. This also functions as a button that displays **Add/Edit/Delete Task For Current Case screen** when you tap it to edit or delete the current information for the selected task. | Displays the **Add/Edit/Delete Task For Current Case screen**. | When there's one or more new tasks added for the case in the selected task. | None | 4 |
