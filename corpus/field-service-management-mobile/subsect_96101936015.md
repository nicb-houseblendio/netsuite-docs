The **Contact List** screen displays basic contact information for all contacts for the selected task.

| Section | Task | Effect | Availability | Errors/Alerts Shown | Highlighted in Screenshot |
| --- | --- | --- | --- | --- | --- |
| Back button | Lets you go back from the **Contact List screen** to the **Selected Task Details screen**. | Shows the **Selected Task Details screen**. | Always | None | 1 |
| Toggle Selected Task Details Screen Visibility button | Lets you access functions on the **Selected Task Details screen**. | Shows the **Selected Task Details screen**. | Always | None | 2 |
| Contact list | Displays contact information for the selected task and lets you go to the **Contact Details screen** to see all available information for a particular contact. | When you select any row in the **Contacts list**, the **Contact Details screen** is displayed. | Always | None | 3 |
