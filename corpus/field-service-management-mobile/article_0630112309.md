You can grant access to the FSM Mobile application to employees and other workers. The process is a little different depending on whether the user also has access to NetSuite.

After you've given users access, they can install FSM Mobile on their device. To install FSM Mobile on a tablet or phone, see [Mobile Installation Guide](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1008043939.html).

## Prerequisite {#subsect_0630112424}

To give someone access to FSM Mobile, they must have an existing employee record with an email address. The email address is the user ID in both NetSuite and FSM Mobile.

To add an employee record, see [Adding an Employee](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N894212.html).

Important:

Don't give access to unknown email addresses or employees. It's also unsafe to use generic emails like test@test.com or emails that several people can access.

## Grant Access to a NetSuite User {#subsect_0630112552}

You can give a NetSuite user access to FSM Mobile. They'll use the same user ID and password they use in NetSuite to log in to Mobile.

#### To give an existing NetSuite user access to FSM Mobile:

1.  Go to _Lists > Employees > Employees_.
    
2.  Next to the person's name you want to set up, click **Edit**.
    
3.  Click the **Field Service** subtab.
    
4.  Check the **Field Service Mobile User** box. The numbers next to the box show how many FSM licenses you've used out of your total.
    
    Note:
    
    To free up licenses, you'll need to clear this box on the employee record of anyone who doesn't need FSM Mobile access anymore.
    
5.  Click **Save**, then refresh the page.
    
6.  Click **Email Mobile Login** at the top of the page. This sends an email with a link to FSM Mobile to the person's email address on their employee record. They'll use their NetSuite login to sign in to FSM Mobile.
    

## Grant Access to a Non-NetSuite User and Assign a Password {#subsect_0630113328}

Follow these steps to give access to someone who doesn't use NetSuite and to set their FSM Mobile password.

#### To give a user access to FSM Mobile and set a password:

1.  Go to _Lists > Employees > Employees_.
    
2.  Next to the person's name you want to set up, click **Edit**.
    
3.  Click the **Field Service** subtab.
    
4.  Check the **Field Service Mobile User** box. The numbers next to the box show how many FSM licenses you've used out of your total.
    
    Note:
    
    To free up licenses, you'll need to clear this box on the employee record of anyone who doesn't need FSM Mobile access anymore.
    
5.  Click the **Access** subtab.
    
6.  Check the **Manually Assign or Change Password** box.
    
7.  Enter a password. As you type, the characters are checked against NetSuite password rules.
    
    Important:
    
    FSM Mobile doesn't have the same password requirements as NetSuite.
    
    -   Although you can set a password that doesn't follow NetSuite complexity rules, you shouldn't use common, plain or obvious passwords for security reasons.
        
    -   The **Give Access** box gives you NetSuite access, so make sure it remains cleared.
        
    
8.  In the **Confirm Password** field, type the password again.
    
9.  Click **Save**, then refresh the page.
    
10.  Click **Email Mobile Login** at the top of the page. This sends an email with a link to FSM Mobile to the person's email address on their employee record.
     
11.  Let your user know their email address is their FSM Mobile user ID and give them the password you set. For security, don't send the password by email.
