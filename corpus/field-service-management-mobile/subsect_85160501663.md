This screen lets you add, edit or delete notes.

![NextService Mobile note screen.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/FieldServiceManagement/MobileUserGuide/mobile_note_screen_detail_icon.png)

| Section | Task | Effect | Availability | Errors/Alerts Shown | Highlighted in Screenshot |
| --- | --- | --- | --- | --- | --- |
| Back button | Lets you go to the **Notes List screen**. | If there's one or more saved notes for this task, then the **Notes List screen** is displayed. If there are no saved notes for this task, then this button has no effect. | Always | None | 1 |
| Toggle Selected Task Details Screen Visibility button | Lets you access functions on the **Selected Task Details screen**. This button, positioned in the **Control Bar**, spans the entire width of the screen except where other buttons are placed. The creation date of the note is displayed inside the button. | Shows the **Selected Task Details screen**. | Always | None | 2 |
| Delete Note button | Lets you delete a note that has already been saved to the cloud. | Deletes the current note from the cloud and then shows the **Add/Edit/Delete Note screen** with all data entry fields set to default values. | When viewing a note that has been saved. | None | 3 |
| Saving To Cloud indicator | Informs you that the note is being saved to the cloud. | None | After you tap on the **Save button** until the data has been saved to the cloud. | None | 4 |
| Discard Changes button | Lets you clear any changes made in the **Add/Edit/Delete Note screen**. | Shows the alert below. If you tap **OK** on the alert, then **Field Service Mobile** reverts the contents of all data entry fields to the previous values. If no data has been saved to the cloud for the current note, then all data entry items will be set to default values. If data has been saved previously for the current note, then all values revert to their previous values when the note data was last saved. If you tap **Cancel** on alert, then the alert is hidden, and no changes are made. | As soon as changes are made to any of the data entry fields in the screen. | Shows the alert 'Are you sure you want to discard your changes? OK. Cancel'. | 5 |
| Save button | Lets you save any changes made in the **Add/Edit/Delete Note screen**. | Saves all the data you enter in the **Add/Edit/Delete Note screen** for the selected task. | When both the **Note Title text field** and the **Note Message text box** contain valid values. | None | 6 |
| Title text field | Lets you enter a title for the current note. | None | Always | None | 7 |
| Message text box | Lets you enter a message for the current note. | None | Always | None | 8 |
