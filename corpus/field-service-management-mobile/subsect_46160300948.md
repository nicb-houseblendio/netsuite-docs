This screen lets you add, edit or delete a received item.

![NextService Mobile receive item screen.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/FieldServiceManagement/MobileUserGuide/mobile_receive_tab_item_screen_detail_icon.png)

| Section | Task | Effect | Availability | Errors/Alerts Shown | Highlighted in Screenshot |
| --- | --- | --- | --- | --- | --- |
| Back button | Lets you go to the **Receive Item List screen**. | Displays the **Receive Item List screen**. | If there's one or more **Receive Item List entry** instances in the **Receive Item list**. | None | 1 |
| Toggle Selected Task Details Screen Visibility button | Lets you access functions on the **Selected Task Details screen**. This button, positioned in the **Control Bar**, spans the entire width of the screen except where other buttons are placed. The receive order number is displayed inside this button. | Shows the **Selected Task Details screen**. | Always | None | 2 |
| Delete Received Item button | Lets you delete a previously saved received item. | Shows the alert below. If you tap **OK**, then the current new task for the current case is deleted and all values on the **Add/Edit/Delete Receive Item screen** are reverted to the default values. If you tap **Cancel**, then the alert is hidden, and no changes are made. | If you have recently saved the data or opened **Add/Edit/Delete Receive Item screen** from a **Receive Item List entry** and haven't changed any data entry fields on the **Add/Edit/Delete Receive Item screen**. | Shows the alert 'Are you sure you want to Delete? OK. Cancel'. | 3 |
| Saving To Cloud indicator | Lets you know that the new received item details are being saved to the cloud. | None | After you tap the **Save** button until the data has been saved to the cloud. | None | 4 |
| Discard Changes button | Lets you clear any changes made in the **Add/Edit/Delete Receive Item screen**. | Shows the alert below. If you tap **OK** on the alert, then **Field Service Mobile** reverts the contents of all data entry fields to the previous values. If no new received item data has been saved previously for the selected received item, then all data entry items will be set to default values. If new received item data has been saved previously for the selected received item, then all values revert to their previous values when the new received item data was last saved. If you tap **Cancel** on alert, then the alert is hidden, and no changes are made. | As soon as changes are made to any of the data entry items in the **Add/Edit/Delete Receive Item screen**. | Shows the alert 'Are you sure you want to discard your changes? OK. Cancel'. | 5 |
| Save button | Lets you save any changes made in the **Add/Edit/Delete Receive Item screen**. | Saves all the data entered in the **Add/Edit/Delete Receive Item screen**. | When the **Item dropdown list** and the **Quantity text field** both contain valid data. | None | 6 |
| Item dropdown list | Lets you select an item to receive. | None | Always | None | 7 |
| Quantity text field | Lets you enter a quantity value. | None | Always | None Note: This field accepts only numerals, decimal points, or the letter 'e'. For a valid value, don't enter a value with more than one decimal point preceding another character or the letter 'e'. | 8 |
