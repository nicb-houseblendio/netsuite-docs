The **Files tab** lets you attach files from your mobile device to the selected task.

This tab has three screens: **Add File Item screen**, the **Edit/Delete File Item screen** and the **File Item List screen**.

![NextService Mobile files tab.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/FieldServiceManagement/MobileUserGuide/mobile_files_tab_icon.png)

For more information, see the following:

## Add File Item Screen in Detail {#subsect_2141240374}

This screen lets you add and attach file items to the selected task.

| Section | Task | Effect | Availability | Errors/Alerts Shown | Highlighted in Screenshot |
| --- | --- | --- | --- | --- | --- |
| Back button | Lets you go to the **File Item List screen**. | If there's one or more saved files for this task, then the **File Item List screen** is displayed. If there are no saved notes for this task, then this button has no effect. | When there's one or more saved file items for the selected task. | None | 1 |
| Toggle Selected Task Details Screen Visibility button | Lets you access functions on the **Selected Task Details screen**. | Shows the **Selected Task Details screen**. | Always | None | 2 |
| Saving To Cloud indicator | Informs you that the file item is being saved to the cloud. | None | After you tap the **Save button** until data has been saved to the cloud. | None | 3 |
| Discard Changes button | Lets you clear any changes made in the **Add/Edit File screen**. | Shows the alert below. If you tap on **OK** on the alert, then **Field Service Mobile** reverts the contents of all data entry fields to the default values. If you tap on **Cancel** on alert, then the alert is hidden, and no changes are made. | As soon as changes are made to any of the data entry items in the screen. | Shows the alert 'Are you sure you want to discard your changes? OK. Cancel'. | 4 |
| Save button | Lets you save any changes made in the **Add File Item screen**. | Saves all data entered in the **Add File Item screen** then displays the **Edit/View File Item screen** with all the fields and data for the newly added file item. | When both the **File autoload text field** and the **Description text box** contain valid values. | None | 5 |
| Upload Autoload text field | Lets you select a file to upload and attach to the selected task. This also functions as a button when you tap anywhere in the field, **Field Service Mobile** opens your device's default file selection tool. When you select a field, the field displays the filename of the selected file. | Displays your mobile device's default file selection tool so you may select one file to upload to the cloud. | Always | None | 6 |
| Clear Upload Autoload text field button | Lets you clear contents of the **Upload autoload text field**. | Clears contents of the **Upload autoload text field**. | When the **Upload autoload text field** contains data. | None | 7 |
| File Description text box | Lets you enter a description for the current file. | None | Always | None | 8 |
