The **Task tab** lets you create a new task.

If the selected task has a case, then the new task will have the same case.

This tab has two screens: the **Add/Edit/Delete New Task For Current Case screen** and the **New Task List For Current Case screen**.

The first time you enter the **Task tab** for a selected task, you will see the **Add/Edit/Delete New Task For Current Case screen**.

After you fill out all the required fields and save, you can go to the **List New Tasks For Current Case screen** to see the new task in the list. From there, you can go to the **Add/Edit/Delete New Task For Current Case screen** to add, edit or delete the currently selected task.

Even after saving to the cloud, you can still edit the task and save updates over the existing data.
