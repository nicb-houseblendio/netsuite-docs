This screen lets you view all the quotes added for the selected task.

![NextService Mobile quote item list screen.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/FieldServiceManagement/MobileUserGuide/mobile_quote_tab_item_list_screen_detail_icon.png)

| Section | Task | Effect | Availability | Errors/Alerts Shown | Highlighted in Screenshot |
| --- | --- | --- | --- | --- | --- |
| Toggle Selected Task Details Screen Visibility button | Lets you access functions on the **Selected Task Details screen**. | Shows the **Selected Task Details screen**. | Always | None | 1 |
| Add New Quote button | Lets you display the **Add/Edit/Delete/View Quote Item screen** to add a new file record. | Shows the **Add/Edit/Delete/View Quote Item screen** with default values for all data entry fields. | Always | None | 2 |
| Quote list | Displays all the quotes for the selected task. | None | Always | None | 3 |
| Quote List entry | Lets you view **Transaction**, **Status**, **Apply To Current Job**, **Total** and **Quote Status** of a particular quote in the **Quote list**. This also functions as a button that displays **Quote Details screen** when you tap it. | Shows the **Quote Details screen** with the data entry fields pre-filled with the values for the current quote. | Always | None | 4 |
