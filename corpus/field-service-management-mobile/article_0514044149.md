Before you update the FSM configuration, decide whether to use a system prompt or create a custom prompt.

Note:

The FSM SuiteApp does not support prompts for partial text enhancement. If you use a generic partial prompt, the text area does not update and the mobile app shows an error message.

For more information about working with prompts, see [Manage Prompts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_231233812.html).

#### To create a prompt for Enhanced Technician Notes:

1.  Go to _Setup > Company > AI > Prompt Studio_.
    
2.  Click **Create Prompt**.
    
3.  In the **Script ID** field, enter `_fsm_textenhance`.
    
    If you are creating a custom prompt for a language other than English, add the locale suffix used by the system prompts. For example, use `_fsm_textenhance_es` for Spanish.
    
    The `_fsm_textenhance` script ID and the value in the prompt record's **Language** field help the system find the prompt that matches the technician's language. If needed, the system also compares the **Language Variant** field in the prompt record.
    
4.  Complete the other required fields.
    
5.  Click **Save**.
