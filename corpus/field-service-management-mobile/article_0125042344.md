The Task List screen is the home screen of **Field Service Mobile**.

From this screen, you can:

-   see assigned tasks
    
-   view a map showing the location of all assigned tasks
    
-   select one task to show more detail
    
-   refresh the task data from the cloud
    
-   add new tasks
    
-   logout of the system.
    

The Task List screen displays all of the tasks assigned to you for a set date range.

By default, the date range is from 5 days before to 5 days after the current date.

Depending on your device's resolution, the Field Service Mobile app might show a map to the right of your task list.

Note:

You can have more than one task set to in progress. In this document where a reference is made to the 'selected task' this refers to the task that was selected for viewing in the **Task list** on the **Task List screen**.

## Task List Entry Display Styles Explained {#subsect_66170841088}

The **Task entry** occurrences in the **Task list** have 5 visual styles that inform you of the task status. These are explained below.

The **Data Loading Status** describes whether the app has finished loading the data for this particular task from the cloud. The possible values are **Loading** and **Loaded**.

The **Task Status** reflects the progress of a task from start to end. The possible values are **Not Started**, **In Progress** and **Completed**.

| Data Loading Status | Task Status |
| --- | --- |
| Loading | Not Started or Completed |
| Loading | In Progress |
| Loaded | Not Started |
| Loaded | In Progress |
| Loaded | Completed |

## Task List Map View Explained {#subsect_88171114767}

This map panel shows you symbols signifying your location as well as the location of each of the assigned tasks.

Like most GPS apps, you can zoom in, zoom out and pan around the map to see the location and level of details you need.

![FSM Mobile task list map view](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/FieldServiceManagement/mobile_screen_layout_task_list_screen_v6.png)

## Technician Symbol {#bridgehead_28171517409}

![FSM Mobile map view technician symbol](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/FieldServiceManagement/mobile_task_list_map_view_technician_symbol_icon_v2.png)

The location of the technician is signified by an instance of the Technician Symbol.

If Field Service has a photo of the technician, it'll show up as part of the symbol.

## Task Location Symbol {#bridgehead_7171619773}

![FSM Mobile map view task location symbol](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/FieldServiceManagement/mobile_task_list_map_view_task_location_symbol_v2.png)

Each task location is signified by an instance of the Task Location icon.

Tapping on any one of these icons will display the **Selected Task Detail** screen in **Map View** lets you see more details for the selected task.

## Zoom In {#bridgehead_51171752216}

![NextService Mobile map view zoom in symbol.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/FieldServiceManagement/MobileUserGuide/mobile_task_list_map_view_zoom_in_icon.png)

To zoom in on the map, spread two fingers apart on your device's screen where you want to zoom. Double-tapping quickly in one location on the map will also zoom in.

## Zoom Out {#bridgehead_90171836497}

![NextService Mobile map view zoom out symbol.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/FieldServiceManagement/MobileUserGuide/mobile_task_list_map_view_zoom_out_icon.png)

To zoom out, pinch two fingers together anywhere on the map on your device's screen.

## Pan North/South/East/West {#bridgehead_57171912233}

![NextService Mobile map view pan symbol.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/FieldServiceManagement/MobileUserGuide/mobile_task_list_map_view_pan_icon.png)

To pan around the map, place two fingers anywhere on the map on your device's screen and slide up, down, left or right.
