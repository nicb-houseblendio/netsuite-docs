This screen lets you add, edit or delete a returned item.

![NextService Mobile return item screen.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/FieldServiceManagement/MobileUserGuide/mobile_return_tab_item_screen_detail_icon.png)

| Section | Task | Effect | Availability | Errors/Alerts Shown | Highlighted in Screenshot |
| --- | --- | --- | --- | --- | --- |
| Back button | Lets you go to the **Return Item List screen**. | Displays the **Return Item List screen**. | Always | None | 1 |
| Toggle Selected Task Details Screen Visibility button | Lets you access functions on the **Selected Task Details screen**. | Shows the **Selected Task Details screen**. | Always | None | 2 |
| Delete Return Item button | Lets you delete a previously saved returned item. | Shows the alert below. If you tap **OK**, then the current new task for the current case is deleted and all values on the **Add/Edit/Delete Return Item screen** are reverted to the default values. If you tap **Cancel**, then the alert is hidden, and no changes are made. | If you recently saved the data for a received item or opened the **Add/Edit/Delete Return Item screen** from **Return Item List entry** in the **Return Item list** and haven't changed the data entry fields on the **Add/Edit/Delete Return Item screen**. | Shows the alert 'Are you sure you want to Delete? OK. Cancel'. | 3 |
| Saving To Cloud indicator | Lets you know that the new returned item details are being saved to the cloud. | None | After you tap the **Save** button until the data has been saved to the cloud. | None | 4 |
| Discard Changes button | Lets you clear any changes made in the **Add/Edit/Delete Return Item screen**. | Shows the alert below. If you tap **OK** on the alert, then **Field Service Mobile** reverts the contents of all data entry fields to the previous values. If no new return item data has been saved previously for the selected received item, then all data entry items will be set to default values. If new return item data has been saved previously for the selected return item, then all values revert to their previous values when the new return item data was last saved. If you tap **Cancel** on alert, then the alert is hidden, and no changes are made. | As soon as changes are made to any of the data entry items in the **Add/Edit/Delete Return Item screen**. | Shows the alert 'Are you sure you want to discard your changes? OK. Cancel'. | 5 |
| Save button | Lets you save any changes made in the **Add/Edit/Delete Return Item screen**. | Saves all the data entered in the **Add/Edit/Delete Return Item screen**. | When the **Item dropdown list** and the **Quantity text field** both contain valid data. | None | 6 |
| Item dropdown list | Lets you select an item to return. | None | Always | None | 7 |
| Quantity text field | Lets you enter a quantity value. | None | Always | None Note: This field only lets you type numerals, decimal points or the letter 'e'. To be considered valid, you should not enter a value with more than one decimal point preceding another character or the letter 'e'. | 8 |
