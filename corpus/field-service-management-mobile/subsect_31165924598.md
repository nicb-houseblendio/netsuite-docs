This screen lets you add, edit or delete time items.

![NextService Mobile time item detail screen.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/FieldServiceManagement/MobileUserGuide/mobile_time_tab_screen_detail_icon.png)

| Section | Task | Effect | Availability | Errors/Alerts Shown | Highlighted in Screenshot |
| --- | --- | --- | --- | --- | --- |
| Back button | Lets you go to the **Time Item List screen**. | Displays the **Time Item List screen**. | If there are existing time items for the selected task. | None | 1 |
| Toggle Selected Task Details Screen Visibility button | Lets you access functions on the **Selected Task Details screen**. | Shows the **Selected Task Details screen**. | Always | None | 2 |
| Delete Time Item button | Lets you delete the current time item. | Shows the alert below. If you tap **OK** on the alert, then Field Service Mobile deletes the saved time item. If the selected task has existing time items and you delete this item, then the **Time Tab List screen** is displayed. Otherwise, the **Task Detail screen** is displayed instead. If you tap **Cancel**, then the alert is hidden, and no changes are made. | As soon as a time item has been saved using the **Save Time Item button**. | Shows the alert 'Are you sure you want to Delete? OK. Cancel'. | 3 |
| Saving To Cloud indicator | Lets you know that the time item is being saved to the cloud. | None | After you tap the **Save button** until the data has been saved to the cloud. | None | 4 |
| Discard Changes button | Lets you undo any changes made without saving any data. | Shows the alert below. If you tap **OK** on the alert and does not save entered values. If the selected task has existing time records then the **Time Tab List screen** is displayed. Otherwise, the **Task Detail screen** is displayed instead. If it's your first time to add a time item for this task, then the **Selected Task Details screen** will be displayed. Otherwise, the **Time Item List screen** is displayed instead. If you tap **Cancel** on the alert, then the alert is hidden, and no changes are made. | When **Item dropdown box** and **Hours text field** fields are filled with value(s). | Shows the alert 'Are you sure you want to discard your changes? OK. Cancel'. | 5 |
| Save button | Lets you save the entered values in the **Item dropdown list** and **Hours text field**. | Saves the values as a new time item and displays the **Saving To Cloud indicator** while this happens. As soon as the data has been saved, the **Saving To Cloud indicator** is hidden and the **Delete Time Item button** is displayed. | When both **Item dropdown box** and **Hours text field** are filled with valid values. | None | 6 |
| Item Search button | Shows the normally hidden **Item Search text box** to let you type in a search query. | If you tap the **Item Search button**, then the **Item Search text box** field slides out from the right-hand side of the **Item Search button** letting you type in a search query. | If the **Status** of the selected task is not set to **Complete**. If the **Status** of the current task is set to **Complete**, then the **Item Search button** will be displayed but inactive. | None | 7 |
| Item Search text box | Lets you enter a search query to show matching items in the **Item dropdown list** making it easier to find the item you need. | As you type the search query text in the **Item Search text box** the **Item dropdown list** changes to display how many items match the search query. As soon as you type the query, you should tap the **Item dropdown list** to show the matching items. | If the **Item Search button** is visible and active after you tap the **Item Search button** but you haven't tapped anywhere on the screen except for the **Item Search button** or **Item Search text box**. | None | 8 |
| Item dropdown list | Lets you select from a list of items. The list will be either the full list of all items in the system if you haven't entered a search query using the **Item Search text box**, or a subset of all items in the system matching the search query you entered. | None | If the **Status** of the current has not been set to Complete. If the **Status** of the selected task has been set to Complete, then the **Item dropdown list** will be visible but not editable. | None | 9 |
| Hours text field | Lets you type a whole or decimal number to represent the number of hours. | None | Always | None Note: This field only lets you type numerals, decimal points or the letter 'e'. If you enter a value containing two or more decimal points followed by numerals, the value will be deemed invalid and the **Save button** will be hidden. Also, if you enter a value containing one or more instances of the letter 'e', the value will be deemed invalid and the **Save button** will be hidden. | 10 |
