When Enhanced Technician Notes is available for a supported text area, the **Clean Up** button appears.

#### To enhance technician notes:

1.  On the mobile app tab where Enhanced Technician Notes is configured, enter text in the text area.
    
    Note:
    
    The feature does not support partial enhancement. Even if you select only part of the text, it enhances the full text area content.
    
2.  Click **Clean Up** to refine the text.
    
    This action corrects spelling and grammar. It may also improve style and tone.
    
3.  Review the enhanced text.
    
4.  Edit the text manually if needed.
    
5.  (Optional) Click **Undo** to return to the original text.
    
6.  Click the check icon to keep the refined text.
    
    Click the clear icon to discard the refined text and restore the original text.
