The **Time tab** lets you record a list of actions (items) and time spent on each action for the selected task.

This tab has two screens: the **Time Item List screen** and the **Add/Edit/Delete Time Item screen**.

If there are existing time items for the selected task, you'll see the **Time Item List screen**; if not, then the **Add/Edit/Delete Time Item screen** opens so you can add your first time record.

Even after saving to the cloud, you can still edit and save updates over the existing data until the selected task's **Status** is set to **Complete**.
