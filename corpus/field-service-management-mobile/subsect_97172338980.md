This screen lets you add, edit, delete or view a transfer order item.

| Section | Task | Effect | Availability | Errors/Alerts Shown | Highlighted in Screenshot |
| --- | --- | --- | --- | --- | --- |
| Back button | Lets you go to the **Transfer Order Details screen**. | Displays the **Transfer Order Details screen**. | Always | None | 1 |
| View Previous Transfer Order Item button | Lets you view the previous transfer order item. | Populates the **Item dropdown list** and **Quantity text field** with the values from the previous transfer order item. | When there are two or more transfer order items entered and **Field Service Mobile** is not showing the first transfer order item. | None | 2 |
| View Next Transfer Order Item button | Lets you view the next transfer order item. | Populates the **Item dropdown list** and **Quantity text field** with the values from the next transfer order item. | When there are two or more transfer order items entered and **Field Service Mobile** is not showing the last transfer order item. | None | 3 |
| Toggle Selected Task Details Screen Visibility button | Lets you access functions on the **Selected Task Details screen**. | Displays the **Selected Task Details screen**. | Always | None | 4 |
| Add Transfer Order Item button | Adds a new transfer order item for the current transfer order. | Adds a new transfer order item for the selected task and populates the **Item dropdown list** and **Quantity text field** with the default values. | Always | None | 5 |
| Delete Current Transfer Order Item button | Deletes the currently displayed transfer order item for the current transfer order. | Deletes the current transfer order item and shows the **Transfer Order Details screen**. | Always | None | 6 |
| Item Search button | Displays the normally hidden **Item Search text box** to let you type in a search query. | If you tap the **Item Search button**, then the **Item Search text box** slides out from the right-hand side of the **Item Search button** letting you type in a search query. | If the **Status text field** of the current transfer order has a value of **Open**. If the **Status text field** of the current transfer order has a value other than **Open**, then the **Item Search button** will be hidden. | None | 7 |
| Item Search text field | Lets you enter a search query to display only matching items in the **Item dropdown list** making it easier and quicker to find your desired item. | As you type the search query text in the **Item Search text box** the **Item dropdown list** changes to display how many items match your search query. As soon you type the query, you should tap the **Item dropdown list** to display the matching items. | If the **Item Search button** is visible and after you tap the **Item Search button** but you haven't tapped anywhere on the screen except for the **Item Search button** or **Item Search text box**. | None | 8 |
| Item dropdown list | Lets you select from a list of items that may be added to a transfer order. The list will be either the full list of all items in the system if you haven't entered a search query using the **Item Search text box** or a subset of all items in the system matching the search query you entered. | None | If the **Status text** field of the current transfer order has a value of **Open**. If the **Status text field** of the current transfer order has a value other than **Open**, then the **Item dropdown list** will be replaced with an **Item text display field**. | None | 9 |
| Quantity text field | Lets you add a quantity for the current transfer order item in the current transfer order for the selected task. | None | If the **Status text field** of the current transfer order has a value of **Open**. If the **Status text field** of the current transfer order has a value other than **Open**, then the **Quantity text field** will be replaced with a **Quantity text display field**. | None Note: This field only lets you type numerals, decimal points or the letter 'e'. To be considered valid, you should not enter a value with more than one decimal point preceding another character or the letter 'e'. | 10 |
