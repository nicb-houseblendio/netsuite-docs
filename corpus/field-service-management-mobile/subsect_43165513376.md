This screen lets you see all time items that have been added for the selected task.

![NextService Mobile time tab list.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/FieldServiceManagement/MobileUserGuide/mobile_time_tab_list_screen_detail_icon.png)

| Section | Task | Effect | Availability | Errors/Alerts Shown | Highlighted in Screenshot |
| --- | --- | --- | --- | --- | --- |
| Toggle Selected Task Details Screen Visibility button | Lets you access functions on the **Selected Task Details screen**. | Displays the **Selected Task Details screen**. | Always | None | 1 |
| Add Time Item button | Lets you go to the **Add/Edit/Delete Time Item screen** to add a new time record. | Displays the **Add/Edit/Delete Time Item screen** with all data entry fields set to default values. | If the **Status** of the selected task has not been set to **Complete**. | None | 2 |
| Time Item list | Displays all time items for the selected task. | None | Always | None | 3 |
| Time Item List entry | Displays the details of an existing time item like item name, item hours and item record creation date. This also functions as a button that displays **Add/Edit/Delete Time Item screen** when you tap it to edit or delete the selected time item. Lets you edit an existing time item. | Displays the **Add/Edit/Delete Time Item screen** with all data entry fields pre-filled with data from the selected time item. | If there is one or more time items for the selected task. | None | 4 |
