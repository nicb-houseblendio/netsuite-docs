-   To get the best results from Enhanced Technician Notes, use a valid and available prompt ID. For more information, see [Manage Prompts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_231233812.html).
    
-   For non-English custom prompts, use the locale suffix pattern used by the system prompts for consistency.
    
-   If you create custom prompts for multiple languages, use the same base script ID for related prompts and make sure the value in the prompt record's **Language** field matches the technician's **Field Service Language** value in the employee record.
    
-   If you support language variants, create a separate prompt for each variant and use locale suffixes to distinguish related prompts.
