The **History tab** lets you view completed tasks that have been carried out on the current asset.

This tab has four screens: **History Task List screen**, **History Task Details screen**, **History Inventory Display screen** and **History File Display screen**.

![NextService Mobile history tab.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/FieldServiceManagement/MobileUserGuide/mobile_history_tab_icon.png)

For more information, see:
