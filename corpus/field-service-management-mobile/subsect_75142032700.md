This screen lets you edit or delete files attached to the selected task.

| Section | Task | Effect | Availability | Errors/Alerts Shown | Highlighted in Screenshot |
| --- | --- | --- | --- | --- | --- |
| Back button | Lets you go to the File Item List screen. | If there's one or more saved files for this task, then Field Service Mobile shows File Item List screen. If there are no saved notes for this task, then this button has no effect. | Always | None | 1 |
| Toggle Selected Task Details Screen Visibility button | Lets you access functions on the **Selected Task Details screen**. | Shows the **Selected Task Details screen**. | Always | None | 2 |
| Delete File Item button | Lets you delete a file item. This includes the attached file itself and associated data like description, that has been saved to the cloud. | Deletes the current file and associated data from the cloud. If the file you deleted is the only file saved for the selected task, then the **Add File Item screen** is displayed. Otherwise, the **File Item List screen** is displayed. | When viewing a file record that has been saved. | None | 3 |
| Saving To Cloud indicator | Lets you know the file item is being saved to the cloud. | None | After you tap on the **Save button** until the data has been saved to the cloud. | None | 4 |
| Discard Changes button | Lets you clear any changes made in the **Edit/Delete File Item screen**. | Shows the alert below. If you tap **OK** on the alert, then **Field Service Mobile** reverts the contents of all data entry fields to the default values. If no data has been saved to the cloud for the current file item, then all data entry items are set to default values. If data has been saved previously for the current file item, then all values revert to their previous values when the file item was last saved. If you tap **Cancel** on alert, then the alert is hidden, and no changes are made. | As soon as changes are made to the **File Description text box**. | Shows the alert 'Are you sure you want to discard your changes? OK. Cancel'. | 5 |
| Save button | Lets you save any changes made in the **Edit/Delete File Item screen**. | Saves all the data entered in the **Edit/Delete File Item screen** for the selected task. | As soon as changes are made to the **File Description text box**. | None | 6 |
| Download button | Lets you download and view a file that has been previously saved to the cloud. | The file opens in a new browser tab. Depending on the operating system of your mobile device, the file, and the file type, this file will either display in the new tab or be saved in your device so that another app may be able to display the file. | Always | None | 7 |
| File Size text display field | Shows you the file size, in kilobytes, of the stored file. | None | Always | None | 8 |
| File Description text box | Shows you the previously saved description for the current file record. However, if you edit the contents of this text box, you can save the new contents to the cloud by tapping the **Save button**. | None | Always | None | 9 |
