Enhanced Technician Notes is a Field Service Management (FSM) feature that uses Prompt Studio and Text Enhance to improve technician notes in the mobile app. Supported NetSuite text area and long text fields that use a `textarea` element type show a **Clean Up** button.

You can use Enhanced Technician Notes to:

-   Clean up spelling, grammar, and punctuation.
    
-   Rephrase text for clarity.
    
-   Improve the structure and readability of job documentation.
    
-   Preserve the original meaning and improving tone and cohesion.
    

Enhanced Technician Notes is disabled by default. Before you can enable it, you must have an Oracle OCI account. For more information, see [Enabling Enhanced Technician Notes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0514051513.html).

When enabled, the feature uses the generic clean up prompt from Prompt Studio (internal ID -27), which supports 27 languages without additional configuration.

To learn how to use the feature, see [Enhancing Technician Notes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0514051451.html).

To change the prompt behavior or feature availability, see [Configure Enhanced Technician Notes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0514044217.html).

To learn how language settings affect the output, see [How Technician Language Affects Enhanced Technician Notes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0514044028.html).
