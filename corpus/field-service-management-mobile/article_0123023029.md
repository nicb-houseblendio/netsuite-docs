## Login Screen {#subsect_24143048847}

The **Login** screen controls access to the sensitive business data within the FSM Mobile app. You must provide a valid login and password to login and access the app.

| Section | Description | Highlighted in Screenshot |
| --- | --- | --- |
| Login Controls | The three controls on this screen form a standard email field, password field, and sign in button. | 1 |

![FSM Mobile login controls](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/FieldServiceManagement/mobile_login_screen_v3.png)

## Task List Screen {#subsect_91145454628}

The **Task List** screen is the FSM Mobile app's home screen. From this screen, you can view a map showing your current location and the location of all your displayed tasks, select a particular task from the list to see more detail, refresh task data from the cloud, and add a new task, or log out.

| Section | Description | Highlighted in Screenshot |
| --- | --- | --- |
| Control Bar | Contained within the Control Bar are several buttons. These cover functions such as task management, add new task, search, and use camera. | 1 |
| Task List | Contains an entry for each assigned task that falls within the configured date range. From each of these entries you can either go to the **Selected Task Details** screen for more details or launch your mobile device's default GPS mapping app to view the route to the task. | 2 |

![FSM Mobile task list section](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/FieldServiceManagement/mobile_screen_layout_task_list_screen_v3.png)

## Task List screen - Map view {#subsect_13150252067}

The map view on the **Task List** screen shows your current location and the locations of tasks in the Task List.

Note:

From NetSuite version 2024.08, maps are rendered using Oracle Maps.

| Section | Description | Highlighted in Screenshot |
| --- | --- | --- |
| Control Bar | Within the **Control Bar** is a button that lets you show the **Selected Task Details screen**. | 1 |
| Map | The map lets you zoom in and out, pan north, south, east, or west and view details for a selected task. | 2 |

![FSM Mobile task list screen map view](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/FieldServiceManagement/mobile_screen_sections_task_list_screen_map_view_v3.png)

## Selected Task Details Screen {#subsect_61165127871}

On the **Selected Task Details** screen, you can view task details, open the map, start or complete the task, and open task tabs.

| Section | Description | Highlighted in Screenshot |
| --- | --- | --- |
| Control Bar | Contained within the **Control Bar** are buttons that let you go to the **Task List screen** or to the **Selected Task Details screen - Map View**. | 1 |
| Task General Details | This section shows details about the selected task, such as asset name and scheduled start and end times (in the user's time zone) and more. | 2 |
| Task Status Controls | These controls let you start or complete the selected task. | 3 |
| Task Tab List | This list shows all available tabs. It lets you go to the tab screen for any particular tab by tapping its entry in the tab list. | 4 |

![FSM Mobile selected task details screen](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/FieldServiceManagement/mobile_screen_layout_selected_task_details_screen_v3.png)

## Selected Task Details screen - Map view {#subsect_32170632002}

This screen lets you view a map showing your location, the task location, the fastest route and the travel time (without traffic delays).

| Section | Description | Highlighted in Screenshot |
| --- | --- | --- |
| Control Bar | The Control Bar includes controls for returning to the standard Selected Task Details screen and opening the route in your device's default GPS mapping app. The GPS app can show additional route details, such as live traffic data. | 1 |
| Map for Selected Task | This map displays your current location and the location of the selected task. This map also shows the quickest route to the task location without traffic being taken into account. | 2 |
| Task General Details | This section informs you of details about the selected task like asset name, scheduled start and end times (in your time zone) and more. | 3 |
| Task Status Controls | These controls let you start or complete the selected task. | 4 |

![FSM Mobile task selected details map view](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/FieldServiceManagement/mobile_screen_sections_selected_task_details_map_view_screen_icon_v3a.png)

## Task Tab Detail Screen {#subsect_38170843416}

Task tabs let you view or record data for the selected task. Each tab has one or more screens that together make up its functionality.

| Section | Description | Highlighted in Screenshot |
| --- | --- | --- |
| Control Bar | Contained within the **Control Bar** are buttons which let you go to other screens within the current tab or to toggle the visibility of the **Selected Task Details screen**. | 1 |
| Task Tab Details Area | Made up of many different combinations of data display and data entry fields, this area lets you view or record data relevant to the selected task. | 2 |

![alt text: FSM Mobile task tab detail screen](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/FieldServiceManagement/mobile_screen_layout_selected_task_tab_screen_v3.png)
