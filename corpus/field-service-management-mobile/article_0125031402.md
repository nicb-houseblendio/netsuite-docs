The **Login screen** lets you enter an email address as a login and an associated password to gain access to the **Field Service Mobile** system.

| Section | Task | Effect | Availability | Errors/Alerts Shown | Highlighted in Screenshot |
| --- | --- | --- | --- | --- | --- |
| Login text field | Lets you enter your email address as a unique login identifier. | None | Always | None | 1 |
| Password text field | Lets you enter a password. | None | Always | None | 2 |
| Sign In button | Lets you submit the values entered in the **Login text field** and **Password text field**. | If the **Login text field** and **Password text field** contain the correct values for a valid login then the **Task List screen** is loaded. | Always except when replaced to show **'Unable to authenticate'** error message. | If the **Login text field** and **Password text field** are blank, then a 'Fill in this field' error message is displayed. If this **Login text field** contains data but that data does not contain a '@' character, then a **'Enter an email address'** error is shown. If the **Login text field** and **Password text field** both contain values but do not form a valid password/login combination, then the **Sign In** button is replaced with an **'Unable to authenticate'** error message. This message is hidden and the **Sign In button** becomes available again as soon as you change the values in the **Login text field** or **Password text field**. | 3 |
