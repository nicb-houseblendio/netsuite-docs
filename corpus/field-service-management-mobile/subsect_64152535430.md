This screen lets you view all of the inventory items that are saved for the selected historical task.

| Section | Task | Effect | Availability | Errors/Alerts Shown | Highlighted in Screenshot |
| --- | --- | --- | --- | --- | --- |
| Back button | Lets you go to the **History Task Display screen**. | Displays the **History Task Display screen**. | Always | None | 1 |
| View Previous Historical Inventory Item button | Lets you view the details for the previous historical inventory item. | Replaces the value of the **Item display text field** and the **Quantity display text field** with the stored values for the previous historical inventory item. | If the currently displayed historical inventory item is not the first in the list. | None | 2 |
| View Next Historical Inventory Item button | Lets you view the details for the next historical inventory item. | Replaces the value of the **Item display text field** and the **Quantity display text field** with the stored values for the next historical inventory item. | If the currently displayed historical inventory item is not the last in the list. | None | 3 |
| Toggle Selected Task Details Screen Visibility button | Lets you access functions on the **Selected Task Details screen**. This button, positioned in the **Control Bar**, spans the entire width of the screen except where other buttons are placed. When the transfer order has been saved, the transfer order number shows up inside the button. | Shows the **Selected Task Details screen**. | Always | None | 4 |
| Item display text field | Displays the item name for the selected historical inventory item. | None | Always | None | 5 |
| Quantity display text field | Displays the quantity for the selected historical inventory item. | None | Always | None | 6 |
