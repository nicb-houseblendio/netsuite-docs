Each promotion type has a unique form, but they all have the same basic elements. Before you create a promotion, you should understand each of the following promotion elements:

-   **Basic properties** - identify the promotion. See [Basic Properties of a Promotion](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1519294750.html).
    
-   **Scheduling** - limit promotion usage to a specific date range. See [Scheduling Promotions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1519290809.html).
    
-   **Buy conditions** - define what the customer needs to buy to be eligible for the discount. See [Promotion Buy Conditions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1519292682.html).
    
-   **Get conditions** - define what the customer will get from the promotion. See [Promotion Get Conditions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1519292729.html).
    
-   **Coupon codes** - let you apply promotions to a transaction. See [Coupon Codes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1519291829.html).
    
-   **Targeting customers** - limit promotion usage to specific customers or groups of customers. See [Targeting Promotions at Specific Customers](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1519291783.html).
    
-   **Sales channels** - limit promotion usage to specific sales channels. See [Setting Where Promotions Can Be Used](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1519290718.html).
    
-   **Usage limits** - limit how many times a promotion can be used by each customer. See [Promotion Usage Limits](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1519290847.html).
