The number of active promotions that can have the This promotion can be automatically applied box checked is limited to 30 for a specific date range per location. This limitation is enforced when you create or edit a promotion record. You can't save a promotion if it exceeds this limit.

To save new promotions without exceeding the limit, you must do one of the following:

-   Clear the **This promotion can be automatically applied** box for the new promotion.
    
-   Check the **Inactive** box.
    
-   Change the date range. Any promotions that don't specify a date range are considered as 'any date' and are counted as one of the 30 available active promotions for all date ranges.
    
-   Change the location. Any promotions that don't specify a location are considered as 'any location' and are counted as one of the 30 available active promotions for all locations. For more information about setting locations, see [Setting Where Promotions Can Be Used](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1519290718.html).
    
-   Clear the **This promotion can be automatically applied** box on another promotion with the same date range or location, or on a promotion with an unspecified date or location.
    

For more information about promotions that don't specify date ranges or locations, see [Promotions With Unspecified Schedules or Locations](#subsect_1519726904). See also, [Planning Automatically Applied Promotions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1519726407.html).

Note:

You can create an unlimited number of active promotions that don't have the This promotion can be automatically applied box checked, and you can apply these promotions manually.

## Promotions With Unspecified Schedules or Locations {#subsect_1519726904}

Promotions with blank date ranges and blank locations are considered as 'any date and any location'. These promotions are counted as one of the 30 active promotions available for automatic application. You can't create more than 30 active 'any date and any location' promotions.

## Coupon Codes and Auto-Apply {#subsect_1519726868}

Promotions that have the **This promotion can be automatically applied** box checked are limited to Multiple Use coupon codes. Single-use coupon codes can't be automatically applied.
