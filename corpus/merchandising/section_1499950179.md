In this section you will learn how to create a merchandise hierarchy manually. For information regarding how to create a hierarchy using data from a CSV import, see [Creating a Merchandise Hierarchy by CSV](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1507650631.html).

To create a merchandise hierarchy manually you must create the following elements in NetSuite:

-   **A hierarchy version** - contains the complete hierarchy definition for a specific time period. You may only need one version, which therefore wouldn't have an end date. If you have defined several versions, only one version can be active at any time. See [Creating a Hierarchy Version](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1529072633.html).
    
-   **Hierarchy levels** - provide a useful way to categorize hierarchy nodes and determine the relationships between items. See [Creating a Hierarchy Level](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1529072726.html).
    
-   **Hierarchy nodes** - groupings for merchandise that share similar characteristics. They also provide a point in the hierarchy from where other nodes can be created or products can be assigned. See [Creating a Hierarchy Node](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1516013743.html).

After you create a hierarchy version, you create the levels and nodes for that version in the [The Hierarchy Manager](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1527505426.html).

When all the required elements have been created for your complete hierarchy, you can assign items to the right hierarchy nodes. For more information, see [Assigning Items to a Hierarchy Node](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1516013894.html).
