Searchandising adds extra features to your search tools, making product searches better and more profitable. With Searchandising features, you can entice shoppers to buy certain products and help move your inventory.

The Search Synonyms feature lets you set up synonyms in NetSuite, so when a shopper searches for a word, they'll also see results for its synonyms. For example, if you set trousers and pants as synonyms, anyone searching for pants will see results for both pants and trousers. This feature is available for all Commerce web stores and SuiteCommerce InStore customers. For more information, see [Search Synonyms](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1532949178.html).

With the Commerce Search Analytics feature, you can check out standard reports that show the top search queries your shoppers use to find products. Since these reports show the exact search terms people use, they help you understand your website visitors. For more information, see [Search Analytics](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1558523538.html).
