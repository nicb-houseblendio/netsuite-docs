The following list contains best practices for defining search synonyms:

-   If Google Analytics is enabled in your account, you can check out what search terms your shoppers use. This helps you spot which common terms aren't returning results, so you can add synonyms for those and make sure shoppers find the right products.
    
-   Try out a few synonyms in a sandbox or test site to see how adding them changes your search results.
    
-   Synonyms apply to your whole product catalog, so it's better to set up a few that give relevant results instead of making a huge list of every possible synonym.
    
-   If you use multiple websites or languages, make different sets of synonyms for each group of customers. For example, since Americans and British use different words for the same item, you can set up those terms as synonyms for your US and UK websites.
