Note:

This topic applies to System Notes v2 only. For information about System Notes, see [System Notes Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_158644279544.html).

NetSuite logs system notes for changes to the promotion code (record ID **promotioncode**) and coupon code (record ID **couponcode**) REST records. You need to use the System Notes v2 Workbook to view changes to the promotion code and coupon code records. For more information, see [System Notes v2 Workbook](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156623525551.html).

The System Notes tab isn't available on the promotion code and coupon code page. Therefore, you can only access system notes through the System Notes v2 Workbook.
