This template combines fields from the Transaction and Transaction Line record types to list all transactions entered during a specific time period. It forms the source data for the Merchandise Hierarchy Workbook Template.

## Dataset Configuration {#bridgehead_158505833462}

The Merchandise Hierarchy dataset combines fields from one record type, multiple custom formulas and criteria filters. To edit the dataset, see [Defining a Dataset](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544122173.html).

| Root Record Type | Joined Record Type | Custom Formula Field | Data Grid | Criteria Filters |
| --- | --- | --- | --- | --- |
| Sales (Invoiced) | Transaction Line Item | (none) | The following fields are included in the dataset.
-   Custom hierarchy fields
-   Date
-   Item
-   Net Sales Amount
-   Net Sales Quantity
-   On Hand Quantity

 | The following criteria is used to filter the dataset:

-   **Date** between the start date and end date of the active hierarchy version

 |
