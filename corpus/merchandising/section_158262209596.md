This workbook shows you the most common shopper searches that return zero results. It also helps you figure out what your shoppers are struggling to find and lets you see exactly what words and phrases they're using to describe those products.

After you identify the search queries that didn't return any results, merchandisers can do a few things:

-   Set up [Search Synonyms](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1532949178.html) so shoppers don't experience unsuccessful searches.
    
-   Tweak your item search settings as described in [Search Settings Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2656810.html).
    
-   Update product descriptions for related items to include the right keywords.
    
-   Add new products to your catalog.
    

In the workbook, you can check out pivot tables that sort Search Queries with No Results by number of searches (from most to least). By default, there's a pivot table for each site in your account. To open the workbook, click the **SuiteCommerce Top Searches with No Results** link from the Standard Workbooks list on the Workbook Listing Page. Click any site name tab and then click the refresh icon to load the data for that website.

## Pivot Tables {#subsect_158262576544}

There's a pivot table for each site you've set up in NetSuite, so the number of pivot tables in the Top Searches with No Results Workbook matches the number of sites in your account.

Note:

The name of the pivot table is same as the name of the site configured in your account.
