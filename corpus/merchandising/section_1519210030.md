The Sales Channels subtab is where you select if eligibility for the promotion is limited to a specific location, or a specific website.

![Sales Channel Eligibility](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/Merchandising/SA_Promo_SalesChannel.png)

The Sales Channel subtab doesn't appear if the Locations feature and Commerce Web Stores aren't enabled.

Select the **All Locations and Websites** option to set no restrictions regarding location and website eligibility for the promotion.

Note:

You can't delete customer categories, customers, customer groups, locations, nor websites when you create a promotion that has eligibility criteria based on them.

See also [Enabling Other Features that Impact SuitePromotions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4690874193.html#subsect_1519661526).

## Limiting Eligibility to Locations {#subsect_1519050717}

Before you can set location-based promotion eligibility, you must first enable the Locations feature. For more information regarding creating locations and assigning them to transactions, see [Working with Locations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4846759449.html).

Note:

There are limits to the number of promotions that can be automatically applied based on schedule and location. For more information, see [Auto-Apply Promotions Limits](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1519726718.html).

#### To limit eligibility for a promotion to a specific location: {#procedure_4704054058}

1.  On the **Sales Channels** subtab, select the **Specific Locations** option.
    
2.  Enter each location that is eligible for the promotion in the **Location** field that appears.
    

## Limiting Eligibility to Websites {#subsect_1519050743}

Before you can set website-based promotion eligibility, you must first set up Commerce Web Stores. Only Commerce web stores are eligible for website-based promotion eligibility. For more information regarding creating a Commerce web store, see [Commerce Product Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4258759122.html).

#### To limit eligibility for a promotion to a specific website: {#procedure_4704054234}

1.  On the **Sales Channels** subtab, select the **Specific Websites** option.
    
2.  Enter each website that is eligible for the promotion in the **Website** field that appears.
