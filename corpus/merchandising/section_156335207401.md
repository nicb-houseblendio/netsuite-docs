SuiteAnalytics Workbook lets you create custom workbooks that combine queries, pivot tables, and charts. Workbooks are suited to help you analyze items organized in merchandise hierarchies, enabling you to slice sales performance data by product categories (hierarchy nodes).

The following options are available to analyze your merchandise hierarchy with SuiteAnalytics:

-   **Merchandise Hierarchy Workbook** - default Merchandise Hierarchy Workbook with a pivot table that includes custom Merchandise Hierarchy fields. See [Merchandise Hierarchy Workbook](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164312115246.html).
    
-   **SuiteAnalytics Sales workbook templates** - these templates include custom Merchandise Hierarchy fields by default in the dataset, but you still need to edit a pivot or chart to include the fields. See [Analyzing Merchandise Hierarchy with Sales Workbook Templates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_156335256082.html).
    
-   **Custom SuiteAnalytics workbooks** - you can also create custom workbooks as needed. See [Creating Custom Merchandise Hierarchy Workbooks](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1547568123.html).
    

For more information, see [Workbook](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/book_1527274324.html).
