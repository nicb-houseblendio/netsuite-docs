With Search Analytics, every search your shoppers make in the web store gets logged in the backend. When you enable the Search Analytics feature, a scheduled task pulls all that logged data into a NetSuite record called Commerce Search Activity Data. That data then gets organized into two workbooks. SuiteAnalytics Workbook is an analytical tool that lets you explore this data in NetSuite. For more information about SuiteAnalytics Workbook, see [SuiteAnalytics Workbook Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1503949328.html).

Note:

There's a 48-hour delay between when search data is logged and when it shows up in the workbooks. So, the newest data you'll see is always from two days ago.

Commerce Search Analytics uses the SuiteAnalytics Workbook feature to generate two standard workbooks:

-   [SuiteCommerce Top Searches Workbook](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1562062068.html)
    
-   [SuiteCommerce Top Searches with No Results Workbook](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1562062076.html)
    

The main goal of these workbooks is to help merchandisers get to the important search analytics data in a few clicks. Think of this data as a starting point for building more advanced visualizations. For information about creating visualizations from your search analytics data, see [Workbook Charts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544211366.html) and [Creating a Workbook](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544211284.html).

Important:

By default, only users with the Analytics Administrator permission can access the Commerce Search Activity: Top Searches and Commerce Search Activity: Top Searches with No Results workbooks. If you don't have this permission, you'll need someone who does to share the workbooks with you. For more information, see [Saving and Sharing Workbooks and Datasets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1547241303.html). To access the workbooks, click the **SuiteCommerce Top Searches** or **SuiteCommerce Top Searches with No Results** link in the Standard Workbooks list on the Workbook Listing Page. For more information about the Analytics Administrator permission, see [The Analytics Administrator Permission](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1536693720.html).
