Customers are eligible for free shipping when they buy a minimum number of a specific item.

Tagline: Buy a T-shirt and get free shipping on your order!

![Promotion Banner](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/Merchandising/SuitePromotionsExample31.png)

## What the customer needs to buy {#subsect_1517934010}

The following table shows how to set up the Buy conditions for this type of promotion.

| Field | Value |
| --- | --- |
| Buy Anything | Clear |
| Spend a minimum order amount or buy specific items | Select |
| Minimum Order Amount | Clear |
| Specific Items | Select |
| Item | T-shirt |
| Item Quantity | 1 |
| Repeat Discount Incrementally | Clear |

## What the customer will get {#subsect_1518531178}

The following table shows how to set up the Get conditions for this type of promotion.

| Field | Value |
| --- | --- |
| Shipping Method | Select any available shipping method from the list (the selected shipping method will be free for any eligible order). |
