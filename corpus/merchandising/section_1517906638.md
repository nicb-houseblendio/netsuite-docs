Customers are eligible for a percentage off each specified item when they spend a minimum amount.

Tagline: Spend $20 or more and buy 1 T-shirt to get 50% off an additional T-shirt!

![Promotion Banner](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/Merchandising/SuitePromotionsExample17.png)

Small print: Discount applied to the cheapest T-shirt or T-shirts.

## What the customer needs to buy {#subsect_1516889769}

The following table shows how to set up the Buy conditions for this type of promotion.

| Field | Value |
| --- | --- |
| Buy Anything | Clear |
| Spend a minimum order amount or buy specific items | Select |
| Minimum Order Amount | 20.00 |
| Specific Items | Select |
| Item | T-shirt |
| Item Quantity | 1 |
| Repeat Discount Incrementally | Select |

## What the customer will get {#subsect_1518530895}

The following table shows how to set up the Get conditions for this type of promotion.

| Field | Value |
| --- | --- |
| Discount Type | % |
| Discount Rate | 50.00 |
| Items to be discounted | T-shirt |
| Apply discount to | Cheapest |

## Examples of the discount provided {#subsect_1518530900}

The following table shows examples of the discount that this type of promotion provides when various quantities of items are added to a transaction.

| What the customer buys | Price before discount | Discount | Price after discount |
| --- | --- | --- | --- |
| 1 T-shirt | $10 | \- | $10 |
| 1 T-shirt, 1 dress | $30 | \- | $30 |
| 2 T-shirts , 1 dress | $40 | $5 ($5 off the cheapest T-shirt) | $35 |
| 4 T-shirts, 1 dress | $60 | $10 ($5 off the two cheapest T-shirts ) | $50 |
