Customers are eligible for a free item when they buy a specific different item.

Tagline: Buy a dress and get a free T-shirt!

![Promotion Banner](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/Merchandising/SuitePromotionsExample19.png)

Small print: Discount applied to the cheapest T-shirt or T-shirts .

Note:

To create a promotion that automatically adds a free gift to a customer's order, see [Free Gift Promotions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1516725509.html).

## What the customer needs to buy {#subsect_1516890288}

The following table shows how to set up the Buy conditions for this type of promotion.

| Field | Value |
| --- | --- |
| Buy Anything | Clear |
| Spend a minimum order amount or buy specific items | Select |
| Minimum Order Amount | \- |
| Specific Items | Select |
| Item | Dress |
| Item Quantity | 1 |
| Repeat Discount Incrementally | Select |

## What the customer will get {#subsect_1518530919}

The following table shows how to set up the Get conditions for this type of promotion.

| Field | Value |
| --- | --- |
| Discount Type | % |
| Discount Rate | 100.00 |
| Items to be discounted | T-shirt |
| Apply discount to | Cheapest |

## Examples of the discount provided {#subsect_1518530924}

The following table shows examples of the discount that this type of promotion provides when various quantities of items are added to a transaction.

| What the customer buys | Price before discount | Discount | Price after discount |
| --- | --- | --- | --- |
| 1 dress | $20 | \- | $20 |
| 1 T-shirt, 1 dress | $30 | $10 ($10 off the T-shirt) | $20 |
| 2 T-shirts , 1 dress | $40 | $10 ($10 off the cheapest T-shirt) | $30 |
| 2 T-shirts, 2 dresses | $60 | $20 ($10 off the two cheapest T-shirts) | $40 |
