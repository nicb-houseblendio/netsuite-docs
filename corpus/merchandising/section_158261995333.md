This workbook shows the top search queries your shoppers used to find products on your website. You'll see not only which products are popular, but also the words and phrases shoppers use to describe what they're looking for.

After you identify the popular search queries, merchandisers can do a few things to encourage shoppers to buy:

-   Run promotions on the most searched products.
    
-   Feature popular related products on the home page.
    
-   Boost popular products higher in the search results.
    

In the workbook, you can check out pivot tables that sort search queries by number of searches (from most to least). By default, there's a pivot table for each site in your account. To open the workbook, click the **SuiteCommerce Top Searches** link in the Standard Workbooks list on the Workbook Listing Page. Click any site name tab and then click the refresh icon to load the data for that website.

## Pivot Tables {#subsect_158262126562}

There's a pivot table for each site you've set up in NetSuite, so the number of pivot tables in the Top Searches Workbook matches the number of sites in your account.

Note:

The name of the pivot table is same as the name of the site configured in your account.
