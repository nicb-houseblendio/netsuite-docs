You can create free gift promotions that give customers an item with 100% discount. The free gift is automatically added to the customer's order if the transaction is eligible.

Note:

You can only use inventory items with Free Gift Promotions for orders placed through the SuiteCommerce web store. If you try to use other item types, the free gift won't be added, and you'll get an error that says, 'Sorry, something went wrong. We couldn't add your gift to the order.'

However, you can use any item type with Free Gift Promotions for orders placed through the NetSuite user interface.

Watch this video to learn how to create a free gift promotion.

Note:

Free gift promotions can't be exclusive and can't be excluded by other exclusive promotions.

#### To create a free gift promotion:

1.  Go to _Commerce > Marketing > Upsell > Promotions > New_.
    
2.  Select **Free Gift Promotion** from the SuitePromotions category.
    
3.  Enter a name and description for this promotion.
    
4.  Check the **Inactive** box if you want to make the promotion inactive but not deleted. If this box is checked the promotion won't be available for selection on a transaction.
    
5.  Enter a start date and an end date for this promotion.
    
    After the end date, the promotion will no longer trigger discounts, and will no longer appear in the list of available promotions.
    
6.  Check the **This promotion can be automatically applied** box if you want this promotion to be automatically applied to transactions.
    
7.  Enter the **Buy** conditions for this promotion. For more information, see [What the Customer Needs to Buy](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1519210305.html).
    
8.  Enter the **Get** conditions for this promotion. For more information, see [Free Gift Get Conditions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1519210224.html#subsect_1519050186).
    
9.  Enter coupon code details for this promotion. For more information, see [Associating Coupon Codes With a SuitePromotion](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1519210145.html).
    
10.  Enter usage limits for this promotion. For more information, see [Setting Usage Limits on SuitePromotions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1519209942.html).
     
11.  Click **Save**. You can also do one of the following:
     
     -   Click **Save & New** to save the form and create a new promotion.
         
     -   Click **Save & Copy** to save the form and create a new promotion with the same data.
         

Note:

When you use Custom Item Filters with Free Gift Promotions, make sure the items added by the promotion are included in your Custom Item Filter. If the item added by the Free Gift promotion isn't part of the custom item filter, the system might not process the added item correctly resulting in an inconsistent transaction state.

For more information about the Custom Item Filters feature, see [Filtering the Items Dropdown List on Transactions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N551064.html).

## Free Gift Promotion Example {#bridgehead_1519209547}

**Free Gift With Any Order**

-   **Description** - Customers are eligible for a free gift with any order.
    
-   **Tagline** - Get a free T-shirt with any order!
    

**What the customer needs to buy**

The following table shows how to set up the Buy conditions for this type of promotion.

| Field | Value |
| --- | --- |
| Buy Anything | Select |
| Spend a minimum order amount or buy specific items | Clear |

**What the customer will get**

The following table shows how to set up the Get conditions for this type of promotion.

| Field | Value |
| --- | --- |
| Free Gift | T-shirt Note, you can't add parent matrix items as a free gift. |

**Examples of the discount provided**

The following table shows examples of the discount that this type of promotion provides when various quantities of items are added to a transaction.

| What the customer buys | Price before discount | Free gifts | Price after discount |
| --- | --- | --- | --- |
| 1 T-shirt | $10 | 1 T-shirt | $10 (the T-shirt in the order isn't discounted, an extra T-shirt is added to the order) |
| 1 dress | $20 | 1 T-shirt | $20 |
| 1 T-shirt, 1 dress | $30 | 1 T-shirt | $30 (the T-shirt in the order isn't discounted, an extra T-shirt is added to the order) |
| 2 T-shirts, 1 dress | $40 | 1 T-shirt | $40 (the T-shirts in the order aren't discounted, an extra T-shirt is added to the order) |

For many more SuitePromotions examples, see [SuitePromotions Examples](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0424124317.html).
