Customers are eligible for a percentage off a specific item when they buy at least two of a specific different item.

Tagline: For every 2 T-shirts you buy, get 10% off a dress!

![Promotion Banner](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/Merchandising/SuitePromotionsExample20.png)

Small print: Discount applied to the cheapest dress or dresses.

## What the customer needs to buy {#subsect_1516891446}

The following table shows how to set up the Buy conditions for this type of promotion.

| Field | Value |
| --- | --- |
| Buy Anything | Clear |
| Spend a minimum order amount or buy specific items | Select |
| Minimum Order Amount | \- |
| Specific Items | Select |
| Item | T-shirt |
| Item Quantity | 2 |
| Repeat Discount Incrementally | Select |

## What the customer will get {#subsect_1518530933}

The following table shows how to set up the Get conditions for this type of promotion.

| Field | Value |
| --- | --- |
| Discount Type | % |
| Discount Rate | 10.00 |
| Items to be discounted | Dress |
| Apply discount to | Cheapest |

## Examples of the discount provided {#subsect_1518530938}

The following table shows examples of the discount that this type of promotion provides when various quantities of items are added to a transaction.

| What the customer buys | Price before discount | Discount | Price after discount |
| --- | --- | --- | --- |
| 1 T-shirt, 1 dress | $30 | \- | $30 |
| 2 T-shirts, 1 dress | $40 | $2 ($2 off the dress) | $38 |
| 2 T-shirts , 2 dresses | $60 | $2($2 off the cheapest dress) | $58 |
| 4 T-shirts, 2 dresses | $80 | $4 ($2 off the two cheapest dresses) | $76 |
