To identify a promotion, you must give each promotion a useful name. You can also provide a description for each promotion.

Name and description information is defined in the [SuitePromotions Basic Properties](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1519210477.html) section on the promotion record.
