Customers are eligible for a percentage off a specified item when they spend a minimum amount and buy at least one of a specific different item.

Tagline: Spend $35 or more and buy 1 T-shirt to get 50% off dresses!

![Promotion Banner](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/Merchandising/SuitePromotionsExample21.png)

Small print: Discount applied to the cheapest dress or dresses.

## What the customer needs to buy {#subsect_1516894915}

The following table shows how to set up the Buy conditions for this type of promotion.

| Field | Value |
| --- | --- |
| Buy Anything | Clear |
| Spend a minimum order amount or buy specific items | Select |
| Minimum Order Amount | 35.00 |
| Specific Items | Select |
| Item | T-shirt |
| Item Quantity | 1 |
| Repeat Discount Incrementally | Select |

## What the customer will get {#subsect_1518530945}

The following table shows how to set up the Get conditions for this type of promotion.

| Field | Value |
| --- | --- |
| Discount Type | % |
| Discount Rate | 50.00 |
| Items to be discounted | Dress |
| Apply discount to | Cheapest |

## Examples of the discount provided {#subsect_1518530950}

The following table shows examples of the discount that this type of promotion provides when various quantities of items are added to a transaction.

| What the customer buys | Price before discount | Discount | Price after discount |
| --- | --- | --- | --- |
| 1 T-shirt, 1 dress | $30 | \- | $30 |
| 2 T-shirts, 1 dress | $40 | $10 ($10 off the dress) | $30 |
| 2 T-shirts , 2 dresses | $60 | $20 ($10 off each of the dresses) | $40 |
| 3 T-shirts, 2 dresses | $70 | $20 ($10 off each of the dresses) | $50 |
