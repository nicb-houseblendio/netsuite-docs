Customers are eligible for an item at a discounted fixed price when they buy a specific different item.

Tagline: Buy 1 T-shirt and get a dress for $15!

![Promotion Banner](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/Merchandising/SuitePromotionsExample24.png)

## What the customer needs to buy {#subsect_1518022747}

The following table shows how to set up the Buy conditions for this type of promotion.

| Field | Value |
| --- | --- |
| Buy Anything | Clear |
| Spend a minimum order amount or buy specific items | Select |
| Minimum Order Amount | Clear |
| Specific Items | Select |
| Item | T-shirt |
| Item Quantity | 1 |
| Repeat Discount Incrementally | Select |

## What the customer will get {#subsect_1518531010}

The following table shows how to set up the Get conditions for this type of promotion.

| Field | Value |
| --- | --- |
| Fixed Price | 15.00 |
| Items to be discounted | Dress |
| Apply discount to | Cheapest |

## Examples of the discount provided {#subsect_1518531015}

The following table shows examples of the discount that this type of promotion provides when various quantities of items are added to a transaction.

| What the customer buys | Price before discount | Discount | Price after discount |
| --- | --- | --- | --- |
| 1 T-shirt | $10 | \- | $10 |
| 1 T-shirt, 1 dress | $30 | $5 ($5 off the dress) | $25 |
| 2 T-shirts, 1 dress | $40 | $5 ($5 off the dress) | $35 |
| 2 T-shirts, 2 dresses | $60 | $10 ($5 off each dress) | $50 |
