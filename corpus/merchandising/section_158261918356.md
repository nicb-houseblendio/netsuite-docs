This dataset combines fields from the Commerce Search Activity Data and Web Site record types so that you can view the top search queries your shoppers used to find products on your website. It forms the source data for the [SuiteCommerce Top Searches Workbook](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158261995333.html).

## Dataset Configuration {#subsect_158262032110}

The source data used in the SuiteCommerce Top Searches workbook combines fields from two record types and multiple criteria filters. To edit the dataset, see [Defining a Dataset](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544122173.html).

| Root Record Type | Joined Record Type | Custom Formula Fields | Data Grid | Criteria Filters |
| --- | --- | --- | --- | --- |
| Commerce Search Activity Data | Web Site | (none) | The following record fields are included in the dataset. Commerce Search Activity Data
-   Aggregation Value
-   Duration
-   Position
-   Start Time
-   Value
-   Web Site

Web Site

-   Depends on the number of sites configured in your account

 | The following criteria is used to filter the dataset:

-   **Metric** is Search Query
-   **Start Time** is 2 days ago

 |
