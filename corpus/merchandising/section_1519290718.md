You can restrict promotions so that they can only be used at specific locations, or on specific websites.

To set location-based promotion eligibility, you must first enable the Locations feature. See [Enabling Other Features that Impact SuitePromotions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4690874193.html#subsect_1519661526).

Location and website restrictions are defined on the **Sales Channel** subtab on the promotion record. For more information, see [Setting Sales Channel Eligibility on SuitePromotions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1519210030.html).

Note:

There are limits to the number of promotions that can be automatically applied based on schedule and location. For more information, see [Auto-Apply Promotions Limits](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1519726718.html).
