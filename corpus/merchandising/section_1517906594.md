Customers are eligible for a percentage off each specified item when they buy a different item.

Tagline: Buy a T-shirt and get 10% off dresses!

![Promotion Banner](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/Merchandising/SuitePromotionsExample11.png)

Small print: Discount applied to each dress

## What the customer needs to buy {#subsect_1516875524}

The following table shows how to set up the Buy conditions for this type of promotion.

| Field | Value |
| --- | --- |
| Buy Anything | Clear |
| Spend a minimum order amount or buy specific items | Select |
| Minimum Order Amount | \- |
| Specific Items | Select |
| Item | T-shirt |
| Item Quantity | \- |
| Repeat Discount Incrementally | Clear |

## What the customer will get {#subsect_1518530732}

The following table shows how to set up the Get conditions for this type of promotion.

| Field | Value |
| --- | --- |
| Discount Type | % |
| Discount Rate | 10.00 |
| Items to be discounted | Dress |
| Apply discount to | Each Discountable Item |

## Examples of the discount provided {#subsect_1518530737}

When there is a percentage promotion that applies to each item, the discount is returned as a percentage. The following table shows examples of the discount that this type of promotion provides when various quantities of items are added to a transaction.

| What the customer buys | Price before discount | Discount | Price after discount |
| --- | --- | --- | --- |
| 1 T-shirt, 1 dress | $30 | 10% ($2 off the dress) | $28 |
| 1 T-shirt, 2 dresses | $50 | 10% ($2 off each dress = $4) | $46 |
| 1 T-shirt, 3 dresses | $70 | 10% ($2 off each dress = $6) | $64 |
| 2 T-shirts, 3 dresses | $80 | 10% ($2 off each dress = $6) | $74 |
