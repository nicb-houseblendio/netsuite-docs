Customers are eligible for free shipping when they spend a minimum amount on a specific item or items.

Tagline: Spend $50 or more on T-shirts or dresses and get free shipping on the order!

![Promotion Banner](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/Merchandising/SuitePromotionsExample32.png)

## What the customer needs to buy {#subsect_1518531188}

The following table shows how to set up the Buy conditions for this type of promotion.

| Field | Value |
| --- | --- |
| Buy Anything | Clear |
| Spend a minimum order amount or buy specific items | Select |
| Minimum Order Amount | 50.00 |
| Specific Items | Select |
| Item | T-shirt or Dress |
| Item Quantity | 1 |
| Repeat Discount Incrementally | Clear |

## What the customer will get {#subsect_1518531193}

The following table shows how to set up the Get conditions for this type of promotion.

| Field | Value |
| --- | --- |
| Shipping Method | Select any available shipping method from the list (the selected shipping method will be free for any eligible order). |
