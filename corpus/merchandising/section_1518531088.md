Customers are eligible for a percentage off any order over a certain value.

Tagline: 10% off all orders over $50!

![Promotion Banner](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/Merchandising/SuitePromotionsExample29.png)

## What the customer needs to buy {#subsect_1518531093}

The following table shows how to set up the Buy conditions for this type of promotion.

| Field | Value |
| --- | --- |
| Buy Anything | Clear |
| Spend a minimum order amount or buy specific items | Select |
| Minimum Order Amount | 50.00 |
| Specific Items | Clear |
| Item | \- |

## What the customer will get {#subsect_1518531098}

The following table shows how to set up the Get conditions for this type of promotion.

| Field | Value |
| --- | --- |
| Discount Type | % |
| Discount Rate | 10.00 |

## Examples of the discount provided {#subsect_1518531102}

The following table shows examples of the discount that this type of promotion provides when various quantities of items are added to a transaction.

| What the customer buys | Price before discount | Discount | Price after discount |
| --- | --- | --- | --- |
| 1 T-shirt, 1 dress | $30 | \- | $30 |
| 2 T-shirts, 1 dress | $40 | \- | $40 |
| 3 T-shirts, 1 dress | $50 | $5 | $45 |
| 6 T-shirts, 2 dresses | $100 | $10 | $90 |
