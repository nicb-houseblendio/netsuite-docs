Customers are eligible for a flat rate discount on any order.

Tagline: 10% off everything!

![Promotion Banner](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/Merchandising/SuitePromotionsExample28.png)

## What the customer needs to buy {#subsect_1517932316}

The following table shows how to set up the Buy conditions for this type of promotion.

| Field | Value |
| --- | --- |
| Buy Anything | Select |
| Spend a minimum order amount or buy specific items | Clear |
| Minimum Order Amount | Clear |
| Specific Items | Clear |
| Item | \- |

## What the customer will get {#subsect_1518531079}

The following table shows how to set up the Get conditions for this type of promotion.

| Field | Value |
| --- | --- |
| Discount Type | % |
| Discount Rate | 10.00 |

## Examples of the discount provided {#subsect_1518531084}

The following table shows examples of the discount that this type of promotion provides when various quantities of items are added to a transaction.

| What the customer buys | Price before discount | Discount | Price after discount |
| --- | --- | --- | --- |
| 1 T-shirt, 1 dress | $30 | $3 | $27 |
| 2 T-shirts, 1 dress | $40 | $4 | $36 |
| 3 T-shirts, 2 dresses | $60 | $6 | $54 |
| 4 T-shirts, 2 dresses | $80 | $8 | $72 |
