Customers are eligible for a percentage off any order when they buy a specific item.

Tagline: Buy a T-shirt and get 10% off your order!

![Promotion Banner](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/Merchandising/SuitePromotionsExample30.png)

## What the customer needs to buy {#subsect_1518531110}

The following table shows how to set up the Buy conditions for this type of promotion.

| Field | Value |
| --- | --- |
| Buy Anything | Clear |
| Spend a minimum order amount or buy specific items | Select |
| Minimum Order Amount | Clear |
| Specific Items | Select |
| Item | T-shirt |
| Item Quantity | 1 |
| Repeat Discount Incrementally | Clear |

## What the customer will get {#subsect_1518531115}

The following table shows how to set up the Get conditions for this type of promotion.

| Field | Value |
| --- | --- |
| Discount Type | % |
| Discount Rate | 10.00 |

## Examples of the discount provided {#subsect_1518531120}

The following table shows examples of the discount that this type of promotion provides when various quantities of items are added to a transaction.

| What the customer buys | Price before discount | Discount | Price after discount |
| --- | --- | --- | --- |
| 1 dress | $20 | \- | $20 |
| 1 T-shirt, 1 dress | $30 | $3 | $27 |
| 2 T-shirts, 2 dresses | $60 | $6 | $54 |
| 3 T-shirts, 2 dresses | $70 | $7 | $63 |
