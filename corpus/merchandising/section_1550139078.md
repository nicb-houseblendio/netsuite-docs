SuitePromotions provide the following added flexibility when applying promotions to a transaction:

-   SuitePromotions can be stacked, so you can have more than one eligible promotion per transaction. For more information, see [Applying Combinable Promotions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1519663151.html).
    
-   SuitePromotions can be manually or automatically applied. For more information, see [Automatically Applying Promotions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1519662625.html).
    
-   Free gift SuitePromotions automatically add the free item to a transaction. Promotions that offer an item or items for free - but aren't created using the free gift SuitePromotion type - don't automatically add the item to a transaction. For more information, see [Applying Automatically Added Free Gift Items](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1519662570.html).
