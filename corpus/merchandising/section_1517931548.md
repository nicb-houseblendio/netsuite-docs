Customers are eligible for a flat rate discount on any order when they buy a specific item.

Tagline: Buy a T-shirt and get $5 off your order!

![Promotion Banner](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/Merchandising/SuitePromotionsExample27.png)

## What the customer needs to buy {#subsect_1517931548}

The following table shows how to set up the Buy conditions for this type of promotion.

| Field | Value |
| --- | --- |
| Buy Anything | Clear |
| Spend a minimum order amount or buy specific items | Select |
| Minimum Order Amount | Clear |
| Specific Items | Select |
| Item | T-shirt |
| Item Quantity | 1 |
| Repeat Discount Incrementally | Clear |

## What the customer will get {#subsect_1518531062}

The following table shows how to set up the Get conditions for this type of promotion.

| Field | Value |
| --- | --- |
| Discount Type | Flat |
| Discount Rate | 5.00 |

## Examples of the discount provided {#subsect_1518531067}

The following table shows examples of the discount that this type of promotion provides when various quantities of items are added to a transaction.

| What the customer buys | Price before discount | Discount | Price after discount |
| --- | --- | --- | --- |
| 1 dress | $20 | \- | $20 |
| 1 T-shirt, 1 dress | $30 | $5 | $25 |
| 2 T-shirts, 2 dresses | $60 | $5 | $55 |
| 3 T-shirts, 2 dresses | $70 | $5 | $65 |
