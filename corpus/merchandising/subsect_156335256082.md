You can also analyze sales performance sliced by Merchandise Hierarchy elements using the SuiteAnalytics Sales workbook templates. Custom Merchandise Hierarchy fields are included by default, in the datasets used by the following templates:

-   Sales (Invoiced) Workbook
    
-   Sales (Ordered) Workbook
    

If you have the Analytics Administrator permission, you can access these workbooks from the Workbooks tab on the Analytics home page.

![Sales Workbook Templates from the Workbooks tab on the Analytics home page.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/Merchandising/SA_MH_StandardSalesWorkbooks.png)

Tip:

If you create a new workbook and use Sales (Invoiced) or Sales (Ordered) as the root record type, note that the workbook won't include custom Merchandise Hierarchy fields by default.

You can drag custom Merchandise Hierarchy fields included in the dataset for these templates to columns or rows in a pivot table or chart. The following image is an example of Merchandise Hierarchy fields used in a Sales by Item pivot table.

![Merchandise Hierarchy fields used in a Sales by Item pivot table.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/Merchandising/SA_MH_WorkbookExample-Simple.png)

For more information, see [Workbook and Dataset Templates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1544220378.html).

Note:

Sales workbook templates don't include merchandise hierarchy attribute fields by default. To include attributes in your workbooks you must create a custom workbook. For more information, see [Creating Custom Merchandise Hierarchy Workbooks](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1547568123.html).
