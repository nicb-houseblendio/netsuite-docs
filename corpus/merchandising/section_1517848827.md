Customers are eligible for a flat rate discount on each specified item when they buy a specific item.

Tagline: Buy a T-shirt and get $5 off dresses!

![Promotion Banner](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/Merchandising/SuitePromotionsExample2.png)

## What the customer needs to buy {#subsect_1518529479}

The following table shows how to set up the Buy conditions for this type of promotion.

| Field | Value |
| --- | --- |
| Buy Anything | Clear |
| Spend a minimum order amount or buy specific items | Select |
| Minimum Order Amount | Clear |
| Specific Items | Select |
| Item | T-shirt |
| Item Quantity | \- |
| Repeat Discount Incrementally | Clear |

## What the customer will get {#subsect_1518529484}

The following table shows how to set up the Get conditions for this type of promotion.

| Field | Value |
| --- | --- |
| Discount Type | Flat |
| Discount Rate | 5.00 |
| Items to be discounted | Dress |
| Apply discount to | Each Discountable Item |

## Examples of the discount provided {#subsect_1518529490}

The following table shows examples of the discount that this type of promotion provides when various quantities of items are added to a transaction.

| What the customer buys | Price before discount | Discount | Price after discount |
| --- | --- | --- | --- |
| 1 T-shirt, 1 dress | $30 | $5 ($5 off the dress) | $25 |
| 1 T-shirt, 2 dresses | $50 | $10 ($5 off each dress) | $40 |
| 1 T-shirt, 3 dresses | $70 | $15 ($5 off each dress) | $55 |
| 2 T-shirts, 3 dresses | $90 | $15 ($5 off each dress) | $65 |
