Customers are eligible for a flat rate discount on an additional same item when they buy three of that item.

Tagline: Buy 2 dresses and get $10 off an additional dress!

![Promotion Banner](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/Merchandising/SuitePromotionsExample5.png)

Small print: Discount applied to the cheapest dress or dresses

## What the customer needs to buy {#subsect_1516788341}

The following table shows how to set up the Buy conditions for this type of promotion.

| Field | Value |
| --- | --- |
| Buy Anything | Clear |
| Spend a minimum order amount or buy specific items | Select |
| Minimum Order Amount | \- |
| Specific Items | Select |
| Item | Dress |
| Item Quantity | 2 |
| Repeat Discount Incrementally | Select |

## What the customer will get {#subsect_1518530653}

The following table shows how to set up the Get conditions for this type of promotion.

| Field | Value |
| --- | --- |
| Discount Type | Flat |
| Discount Rate | 10.00 |
| Items to be discounted | Dress |
| Apply discount to | Cheapest |

## Examples of the discount provided {#subsect_1518530658}

The following table shows examples of the discount that this type of promotion provides when various quantities of items are added to a transaction.

| What the customer buys | Price before discount | Discount | Price after discount |
| --- | --- | --- | --- |
| 1 dress | $20 | \- | $20 |
| 2 dresses | $40 | \- | $40 |
| 3 dresses | $60 | $10 ($10 off the cheapest dress) | $50 |
| 6 dresses | $120 | $20 ($10 off each of the two cheapest dresses) | $100 |
