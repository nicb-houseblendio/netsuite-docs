You can use SuiteTax with Localization SuiteApps to meet the tax-related requirements specific to each country.

Localization features that are compatible with SuiteTax are available in the following countries:

| Country | SuiteTax Features |
| --- | --- |
| Australia | Includes the Business Activity Statement. For more SuiteTax-compatible features and information about the relevant SuiteApps for Australia, see [Taxation Features For Accounts With SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4198253102.html#subsect_161167880004). |
| Belgium | Includes tax reports and the Fiche 281.50 tax audit file. For more SuiteTax-compatible features and information about the relevant SuiteApps for Belgium, see [Taxation Features For Accounts With SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_156024393244.html#bridgehead_160189408129). |
| Brazil | Includes the capability to enter tax-related information for your subsidiaries in Brazil and set up rules for calculating taxes. For more SuiteTax-compatible features and information about the relevant SuiteApps for Brazil, see [Taxation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4198261118.html#bridgehead_162698529266). |
| Canada | Includes tax reports, such as the sales tax reports, required in Canada. For more SuiteTax-compatible features and information about the relevant SuiteApps for Canada, see [Taxation Features for Accounts with SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4198261632.html#bridgehead_160309740140). |
| China | Includes generating VAT transactions required in China. For more SuiteTax-compatible features and information about the relevant SuiteApps for China, see [Taxation Features for Accounts With SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4198421197.html#bridgehead_18132447244). |
| Colombia | Includes the capability to set up tax-related information and codes and generate the Magnetic Media Information. For more SuiteTax-compatible features and information about the relevant SuiteApps for Colombia, see [Taxation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_162367083749.html#bridgehead_162367142592). |
| Finland | Includes the VAT return required in Finland. For more SuiteTax-compatible features and information about the relevant SuiteApps for Finland, see [Taxation (Accounts With SuiteTax)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_157849439820.html#bridgehead_160215818289). |
| France | Includes tax reports and the FEC files required in France. For more SuiteTax-compatible features and information about the relevant SuiteApps for France, see [Taxation Features For Accounts With SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4169635010.html#bridgehead_159835171846). |
| Germany | Includes tax reports and the GoBD tax audit file required in Germany. For more SuiteTax-compatible features and information about the relevant SuiteApps for Germany, see [Taxation (SuiteTax)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_160162598725.html). |
| India | Includes support for tax deduction and tax collection at source and calculating taxes for the sale of goods and services. For more SuiteTax-compatible features and information about the relevant SuiteApps for India, see [Taxation (SuiteTax)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_160162598725.html). |
| Ireland | Includes the VAT and EU cross-border reports required in Ireland. For more SuiteTax-compatible features and information about the relevant SuiteApps for Ireland, see [Taxation Features for Accounts with SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_160372794542.html). |
| Mexico | Includes customizations and validations that enables Mexican businesses to comply with the statutory tax requirements. For more SuiteTax-compatible features and information about the relevant SuiteApps for Mexico, see [Taxation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4452522556.html#bridgehead_160509349318). |
| Netherlands | Includes tax reports and the XAF file required in the Netherlands. For more SuiteTax-compatible features and information about the relevant SuiteApps for the Netherlands, see [Taxation Features for Accounts with SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4452525786.html#bridgehead_160216102740). |
| New Zealand | Includes the GST Return 101A. For more SuiteTax-compatible features and information about the relevant SuiteApps for New Zealand, see [Taxation Features For Accounts With SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4198378244.html#subsect_161216118476). |
| Norway | Includes e-VAT reporting. For more SuiteTax-compatible features and information about the relevant SuiteApps for Norway, see [Taxation (Accounts With SuiteTax)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_157907863207.html#bridgehead_160682457374). |
| Philippines | Includes standard Philippine forms and document types that businesses in the Philippines can use to generate VAT invoices and receipts. For more SuiteTax-compatible features and information about the relevant SuiteApps for the Philippines, see [Taxation Features for Accounts With SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_0625100435.html). |
| Singapore | Includes the GST F5 Return and the IRAS tax audit file. For more SuiteTax-compatible features and information about the relevant SuiteApps for Singapore, see [Taxation Features for Accounts With SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4256391369.html#bridgehead_0625010908). |
| Spain | Includes tax reports as well as the platform that facilitates online submissions to the AEAT portal. For more SuiteTax-compatible features and information about the relevant SuiteApps for Spain, see [Taxation Features For Accounts With SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_49092358354.html). |
| Sweden | Includes VAT and cross-border tax reports required in Sweden. For more SuiteTax-compatible features and information about the relevant SuiteApps for Sweden, see [Taxation (Accounts With SuiteTax)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_157425969916.html#bridgehead_160199074806). |
| United Kingdom | Includes VAT, EU cross-border reports, and support for Making Tax Digital. For more SuiteTax-compatible features and information about the relevant SuiteApps for the U.K., see [Taxation (Accounts With SuiteTax)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_160327610240.html). |
| United States | Includes the capability to set up standard U.S. tax codes and groups, and set up and generate workbooks for sales tax transaction data. For more SuiteTax-compatible features and information about the relevant SuiteApps for the U.S., see [Taxation Features For Accounts with SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4198378704.html#bridgehead_160309930702). |
