When you enable the SuiteTax feature, the Tax Engine role is added to your account. This role is set up with all the required permissions to use SuiteTax, and can be used as template for creating customized roles.

You should set up your tax engine plug-in implementations to run under the standard Tax Engine role. When using a customized version of this role, you should consult your tax engine plug-in provider regarding your customizations.

To view the default permissions assigned to the Tax Engine role, go to _Setup > Users/Roles > Manage Roles_ and click the link for the **Tax Engine** role. For information about assigning roles to users, see [Assigning Roles to an Employee](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N897798.html).

SuiteTax also adds the following tax-related permissions to NetSuite standard roles, including the Tax Engine role.

| Permission Subtab | SuiteTax Permission | Usage | Default Permission Level on Tax Engine Role | Minimum Permission Level | Help Topic |
| --- | --- | --- | --- | --- | --- |
| Lists | Tax Details Tab | View and edit tax information about the **Tax Details** subtab on transactions. | Full | Edit - To be able to override the nexus, tax registration number, and tax details on transactions. | [Tax Details on Transactions in SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4283867856.html) |
| Subsidiary - Tax Engine Selection | View and edit the tax registration details on the **Tax Registrations** subtab on subsidiary records. | Full | Edit - To be able to assign tax registrations and tax engines when editing subsidiary records. Note: You must also have at least the Edit level of the Subsidiaries permission to edit a subsidiary record and select a tax engine. | [Assigning Tax Registrations to a Subsidiary in SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4296038273.html) |
| Reports | Tax Reports | View tax reports. | View | View | [Generating a Standard Tax Report in SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1497941633.html) |
| Transactions | Tax Liability Payment | Create, view, and edit the **Tax Liability Payment** transaction. | Edit (Accountant, Bookkeeper) View (Accountant (Reviewer)) Create (AP Clerk) Full (Administrator, CFO) | \- | [Tax Liability Payment Transaction in SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_8154422897.html) |

If you are an administrator, you can create new roles or customize standard roles to add tax permissions or modify the access level for tax permissions. For information about NetSuite roles and permissions, see [NetSuite Roles Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N285436.html) and [NetSuite Permissions Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N325094.html).
