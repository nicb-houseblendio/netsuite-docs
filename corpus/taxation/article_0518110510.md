The report template is an HTML, XML, or FTL file that determines and configures how your reports are exported. These can be exported as a view or as a file.

To change the report template, copy and follow the format in the CTR project folder.

The report template follows the FreeMarker format. For more information, see [https://freemarker.apache.org/](https://freemarker.apache.org/).
