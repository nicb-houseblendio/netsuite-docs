The Advanced Taxes feature enables you to manage and calculate taxes for multiple nexuses within the same NetSuite account. This is done through the use of tax schedules which enable items to be taxed differently in each nexus to meet local business requirements.

The Advanced Taxes feature also links tax control accounts to a nexus to more effectively manage tax postings in your ledger.

This feature is already enabled in OneWorld accounts.

To begin using Advanced Taxes, read the following topics:

-   [Enabling Advanced Taxes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1803739.html) describes how to enable this feature in your account.
    
    Warning:
    
    If you enable Advanced Taxes, you can't disable it in the future.
    
-   [Creating Tax Nexuses](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1804264.html) describes how to set up the tax nexuses, or jurisdictions, in which you must pay taxes.
    
-   [Adding or Removing Nexuses from a Subsidiary](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N273510.html) describes how to associate a nexus with a subsidiary, and how to remove a nexus from a subsidiary.
    
-   [Deleting Tax Nexuses](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1804522.html) describes how to delete a nexus from the system.
    
-   [Creating Tax Schedules](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1804737.html) describes how to apply taxes in each nexus.
    

For general information about nexuses and subsidiaries, read the following topics:

-   [Nexuses and Taxes in OneWorld](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N269581.html)
    
-   [Nexuses and Subsidiaries](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1804037.html)
    

For information about setting default tax items on records, read the following topics:

-   [Setting Tax Codes or Tax Schedules on Item Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1797005.html) - For example, setting a default tax code or tax schedule to be applied to a particular item, or (for U.S. editions without Advanced Taxes) setting an item to be either taxable or not taxable.
    
-   [Setting Default Tax Items on Vendor Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1796855.html) - For example, defining a default tax code that applies to vendor bills and purchase orders for a particular vendor.
    
-   [Setting Default Tax Items on Customer Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1796705.html) - For example, defining a customer as tax-exempt.
    
    Note:
    
    On customer records in U.S. edition accounts **without** the Advanced Taxes feature, the tax lookup determines that a customer isn't taxable only if the **Taxable** box isn't checked and the **Tax Item** field is empty.
