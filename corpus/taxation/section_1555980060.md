The following table lists error codes and messages that you may encounter in generating country tax reports using the Tax Reporting Framework SuiteApp. Read the scenarios below and follow the recommended actions to resolve the errors. If your country tax report generation continues to fail after following these instructions, please contact NetSuite Customer Support for further assistance.

For information about errors specific to submitting the U.K. tax report to the Making Tax Digital system, see [Making Tax Digital: Submission Errors in Tax Reporting Framework](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1552967912.html).

Note:

Some errors listed on this page still refer to the old name **SuiteTax Reports (STR)**. These are retained to reflect the actual error messages you may receive when using Tax Reporting Framework. References to SuiteTax Reports (STR) will be changed once the messages in Tax Reporting Framework SuiteApp are also changed from SuiteTax Reports to Tax Reporting Framework.

| Error Code | Error Message | Description/Recommended Action |
| --- | --- | --- |
| STR\_GLAUDITNUMBERING\_REQUIRED | GL Audit Numbering Feature is required. | The GL Audit Numbering feature is disabled. You must enable this feature. For more information, see [GL Audit Numbering](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3735573963.html). |
| STR\_GLAUDITNUMBERING\_INCOMPLETE | (See email notification: **\[SuiteTax Reports\] <report name> : <reporting period> Failed**. Error details are included in the email.) | There may be GL lines in your report with missing GL numbers. Run the GL Audit Numbering Sequences to address the numbering gaps. See [Running GL Audit Numbering Sequences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4805209975.html). |
| STR\_ROLES\_PERMISSIONS\_DUPLICATE | Permissions for role already set. Edit or remove existing role permission record before creating another. | The standard or custom role has existing Tax Reporting Framework (TRF) permissions. You must modify the role to remove the TRF permissions duplicate. For more information, see [Roles and Permissions in Tax Reporting Framework](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1528249899.html). |
| STR\_INTRASTAT\_MASS\_NOT\_SET | (See email notification: **Tax Reporting Framework: Intrastat Report Generation Failed**. Error details are included in the email.) | There are items in your report that have empty weight fields. Review the **STR Inventory Items with Missing Values** saved search and ensure that there are weights specified in your item records. |
| STR\_MISSING\_REQUIRED\_SUITEAPP | (See email notification: **Tax Reporting Framework: Report Generation Failed**. Error details are included in the email.) | Your report generation failed due to a missing SuiteApp in your account. If you are an administrator, you must install the required SuiteApp stated in the email. For more information about installing SuiteApps, see [Installing SDF SuiteApps](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1525982323.html). If you do not have sufficient permissions to perform this action, please contact your account administrator. |
| STR\_TAX\_FILING\_EXCEPTION | Tax filing is disabled on a non-production environment. | The electronic tax filing feature is not supported in the test environment. You cannot test submit a VAT/GST Return. |
| \- | **End Period Override** Overriding the auto-calculated End Date/Period may result to a mismatch on your reporting period and frequency. | Tax Reporting Framework auto-calculates the End Date/Period field. Selecting a different end date/period may cause a mismatch with the reporting frequency. You should consider the reporting frequency of the report when overriding the auto-calculated End Date/Period to avoid issues in generating your report. |
| \- | The End Period cannot be determined. Select a period in the **End Period** field. | Choose a start period that matches the reporting frequency of the report. If the End Period auto-calculation continues to fail, use the list to select an end period. |
| STAF\_MISSING\_REQUIRED\_SUITEAPP | **Required SuiteApp Not Found.** You must install Tax Reporting Framework first before SuiteTax EMEA Audit Files. | Tax Reporting Framework is a prerequisite SuiteApp of SuiteTax EMEA Audit Files. You must install Tax Reporting Framework first before the SuiteTax EMEA Audit Files SuiteApp. To install Tax Reporting Framework, see [Installing Tax Reporting Framework](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1528245293.html). |
| CTR\_APAC\_MISSING\_REQUIRED\_SUITEAPP | **Required SuiteApp Not Found.** You must install Tax Reporting Framework first before SuiteTax Country Tax Reports APAC. | Tax Reporting Framework is a prerequisite SuiteApp of SuiteTax Country Tax Reports APAC. You must install Tax Reporting Framework first before the SuiteTax Country Tax Reports APAC SuiteApp. To install Tax Reporting Framework, see [Installing Tax Reporting Framework](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1528245293.html). |
