If you have a Czechia nexus, and you have the International Tax Reports SuiteApp installed in your NetSuite account, you can generate a localized EU Sales List (ESL) report for Czechia. To generate an ESL report, go to Reports > VAT/GST > EU Sales List Report. The form can be displayed in English or Czech.

The form displays the following information:

-   **Country Code** - Country code prefix of the customer's VAT registration number
    
-   **Customer's VAT number** - Customer's VAT number without the country prefix
    
-   **Customer** - Click the customer name to view the customer record
    
-   **Supplies Code** - Specifies the type of transaction. For each line in the report, you must select the appropriate supplies code:
    
    -   **0** - Delivery of goods
        
    -   **1** - Movement of business property
        
    -   **2** - Delivery of goods in the form of triangular trade
        
    -   **3** - Delivery of services
        
-   **Number of Supplies** - Number of transactions
    
-   **Total Value of Supplies in CZK** - Displayed in the appropriate format for Czechia
    
-   **Exclude** - Check this box for lines that you want to exclude from your report
    
-   **Cancel** - Check this box to cancel lines
    
    Note:
    
    The Cancel option becomes available only when you have selected the Corrective Recapitulative Statement in the Form SH field on the EU Sales Filing Setup page. See [Setting Up Tax Filing for Czechia](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1877657.html).
    

Make sure you verify and correct data as necessary. If NetSuite finds any inconsistencies based on your reporting criteria, you'll see them marked with color codes on the ESL report. By default, the **Exclude** box is checked for transactions with data inconsistencies, except for VAT number errors.

You can save the report in PDF, Microsoft Excel (.xls), or XML format. Lines with the Exclude box checked aren't included in the exported file. NetSuite saves a copy of the file in the File Cabinet and sends you an email with a URL to its location.

For more information about using the EU Sales List reporting feature, read the following topics:

-   [EU Sales List Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2068226.html)
    
-   [Generating an EU Sales List Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2068441.html)
    

**EU Sales List Online Filing**

You can export the Czechia EU Sales List report to an XML file for online filing. The XML file NetSuite generates meets Czechia tax authority requirements.

To generate the EU Sales List report, see [Generating an EU Sales List Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2068441.html). When the Czechia EU Sales List report is displayed, click Export to XML.

Before you generate a report for online filing, make sure you complete the EU Sales Filing setup page. For information, see [Setting Up Tax Filing for Czechia](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1877657.html).

You should review all the values in the report before you submit it.
