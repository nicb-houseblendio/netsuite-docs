To create a tax code in SuiteTax, please see [Creating Tax Codes in SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4283869397.html#bridgehead_4283882825).

To create a withholding tax code, in the **Tax Type** field, you must select the withholding tax type you created earlier.

In the **Tax Rate Type** field, select **Standard**.
