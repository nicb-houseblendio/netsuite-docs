There are two ways for you to download the country tax reports project files for Tax Reporting Framework:

-   Create a new project through the Tax Reporting Framework CLI. This is installed through Node JS Package Manager (NPM) or Node Package Execute (NPX).
    
-   Manually download and extract the ZIP archive for your application.
    
    Important:
    
    To download the country tax reports project files by this method, you need to have access to the Tax Reporting Framework Project Zip File.
    

Installing through the NodeJS package manager provides you with a Command-line Interface (CLI) that enables you to create new projects using Tax Reporting Framework quickly as the tool recreates the templates and project folder to fit your requirements. Downloading and extracting a ZIP file gives you the option to try to create a new tax report without downloading and installing its dependencies.

To install Tax Reporting Framework through TRF CLI, see [Installing Tax Reporting Framework through TRF CLI](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0517042952.html).
