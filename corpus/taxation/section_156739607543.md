Important:

SuiteTax EMEA Audit Files SuiteApp is no longer supported. To generate audit files for Germany, install the Germany Localization SuiteApp. To generate audit files for France, install the France Localization SuiteApp. For more information, see [Germany Audit Files: GoBD Data Extract](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1539585682.html) and [Fichier d'Ecritures Comptables (FEC) in France Localization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1539840650.html).

The SuiteTax EMEA Audit Files SuiteApp enables users to generate SAF-T type accounting data and master file extracts that can be submitted to a national tax authority or external auditors.

Using this SuiteApp, you can generate the following tax audit file:

-   [Germany Audit Files: GoBD Data Extract](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1539585682.html)
    

For more information about tax audit files in Tax Reporting Framework, see [Tax Audit Files in Tax Reporting Framework](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1558938109.html).

## Installing SuiteTax EMEA Audit Files {#subsect_156706354809}

Note:

SuiteTax EMEA Audit Files is a private SuiteApp. Localization SuiteApps for your region will replace this SuiteApp, which will support Germany Grundsätze zur ordnungsmäßigen Führung und Aufbewahrung von Büchern, Aufzeichnungen und Unterlagen in elektronischer Form sowie zum Datenzugriff (GoBD).

This SuiteApp can only be installed when it is shared with your account. The following describes the steps for you to install the SuiteTax EMEA Audit files if it is shared with your account:

Important:

This SuiteApp requires the Tax Reporting Framework SuiteApp. To install Tax Reporting Framework and check prerequisite features and SuiteApps for your tax audit file, see [Installing Tax Reporting Framework](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1528245293.html).

#### To install SuiteTax EMEA Audit Files:

1.  In NetSuite, go to _Customization > SuiteBundler > Search & Install Bundles_.
    
2.  In the **Keywords** field, enter **SuiteTax EMEA Audit Files**.
    
3.  Click **Search**.
    
4.  Click **SuiteTax EMEA Audit Files**.
    
    Bundle ID 303920.
    
5.  On the Bundle Details page, click **Install**.
    
6.  On the Preview Bundle Install page, confirm that the following actions are applied for each set of conflicting objects:
    
    -   In the Action column, **Replace Existing Object** is selected.
        
    -   In the Preference column, **Replace Data for Conflicting Custom Records and Custom Lists** is selected.
        
    
    For more information about the Preview Bundle Install page, see [Reviewing the Preview Bundle Install Page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3396121.html).
    
7.  Click **Install Bundle**.
    
8.  (Optional) Check and view the installation status of the SuiteApp. For more information, see [Viewing the Country Tax Reports Installation Status](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156212484298.html).
    

For more information about installing SuiteApps, see [Installing a Bundle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3395142.html).

To uninstall SuiteTax EMEA Audit Files SuiteApp, see [Uninstalling a Bundle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3400972.html).
