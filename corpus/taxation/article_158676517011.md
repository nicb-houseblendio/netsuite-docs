Tax Reporting Framework provides the ability to generate Country Tax Reports in accounts without SuiteTax. With Tax Reporting Framework, you can use the same user interface and report generation capabilities for accounts that have SuiteTax.

## Prerequisites {#bridgehead_158676599776}

The following are the setup requirements to generate country tax reports:

-   The country is in the list of supported countries.
    
-   A localization SuiteApp exists for your country.
    

## Supported Countries {#bridgehead_158711117515}

The following is a list of supported countries in Tax Reporting Framework for accounts without SuiteTax:

-   Australia (Taxable Payments Annual Report)
    
-   Belgium (Fiche 281.50 Form)
    
-   France (France Fichier d'Ecritures Comptables)
    
-   Germany (GoBD)
    
-   Norway (SAF-T, VAT Return)
    
-   Portugal (SAF-T)
    

## Feature Differences Between Accounts With And Without SuiteTax {#bridgehead_158711189528}

When using Tax Reporting Framework in accounts without SuiteTax, generating a tax report is the same as generating tax reports in accounts with SuiteTax. For more information on generating tax reports in Tax Reporting Framework, see [Generating Localized Country Tax Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1528250223.html).

The following table lists the differences between the features of Tax Reporting Framework in accounts with and without SuiteTax:

| Feature | Accounts With SuiteTax | Accounts Without SuiteTax |
| --- | --- | --- |
| Multi-Book Accounting | Yes | Yes |
| Accounting Period | Yes | Yes |
| Tax Period | No | Yes (for VAT reports) |
| Notional Tax Amount Reporting | N/A (Known as Tax Amount for accounts with SuiteTax) | Yes |
| Generating Country Tax Reports | Yes | Yes |
| VAT Group Reporting | No | Yes |
| Adjust Tax Return | Yes | Yes |
| VAT Return Form Versioning | No | Yes |
| Non-deductible Tax Amount Reporting | No | Yes |
| Period End Journal Entries Reporting (for Tax Audit Files) | Yes | Yes |
| PDF/XML Export | Yes | Yes |
| Country Tax Reports Preferences | Yes | Yes |
| Setup Tax Return | Yes | No |
| Reporting Frequency | Yes | Yes |
| Tax Reporting Framework Roles | Yes | Limited\* |

Note:

\*Assigning the Tax Return Setup to a role does not have an effect in accounts without SuiteTax.
