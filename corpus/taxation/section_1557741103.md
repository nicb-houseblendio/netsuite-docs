To take advantage of all the SuiteTax Engine features, complete the following:

-   Create a nexus, see [Setting Up Nexuses in SuiteTax Engine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557741442.html)
    
-   Provision tax records, see [Automatic Tax Records Provisioning for the United States](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557741485.html)
    
-   Set Up Tax Groups, see [Setting Up Tax Groups in SuiteTax Engine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1565954398.html)
    
-   Set up tax rate types, see [Setting Up Tax Rate Types for the United States](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557741648.html)
    
-   To learn more about the U.S. Consumer's Use Tax, see [U.S. Consumer's Use Tax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160086073386.html)
    
-   Set nexus preferences, see [Setting Up Nexus Preferences for United States](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557741742.html)
    
-   Set up entity default tax codes, see [Setting Up Entity Default Tax Codes and Tax Groups](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557742165.html)
    
-   Set up default tax codes and tax groups on entity tax registration as CSV, see [Setting Default Tax Code or Tax Group on Entity Tax Registration as CSV](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0910045552.html)
    
-   Review and customize roles and permissions, see [Roles and Permissions for the SuiteTax Engine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557399606.html)
    
-   Set exemption certificates, see [Creating Exemption Certificates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0823123959.html)
    
-   Set the item non-taxability rules, see [Creating Non-taxability Rules for Items](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557742237.html)
    
-   Create an exception from the general taxation for relevant items, see [Setting up US Item Tax Exceptions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0711032317.html)
    
-   To find more about how the SuiteTax Engine determines which tax code to use, see [Tax Code Lookup Logic for United States](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557742280.html)
