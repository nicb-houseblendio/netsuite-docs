In SuiteTax, you can create a hierarchy of nexuses by specifying a parent on the nexus record.

Note:

For Canada, SuiteTax creates a country-level Canada nexus and sets it as the parent nexus for the provincial-level Canada nexuses during migration.

| Legacy Tax | SuiteTax | Migration to SuiteTax |
| --- | --- | --- |
| Field Name | Field ID | Field Name | Field ID |
| --- | --- | --- | --- |
| Country | country | Country | country | Retained. |
| State/Province/County | state | State/Province/County | state | Retained. |
| Description | description | Description | description | Retained. |
| Preferred Tax Agency Preferred GST/HST Agency | taxagency | Tax Agency | taxagency | Retained. For Canada:
-   SuiteTax creates a country-level parent nexus, and sets the value of this field to the default value, which is the preferred GST/HST set for the first Canadian nexus (from the Set Up Taxes legacy page). Note: If there are different values set for each Canadian nexus on the Set Up Taxes page, when you enable SuiteTax, you will be prompted to set the same value for all nexuses or the default value will be set for the parent Canada nexus during migration.
-   For provincial-level Canada nexuses, SuiteTax sets the value of this field to the preferred PST agency for the province nexus.

 |
| Preferred PST Agency | taxagencypst | \- | \- | Removed from form. |
| Home Tax Code | taxcode | \- | \- | Removed from form. |
| \- | \- | Parent Nexus | parentnexus | Added to the form and set to blank. For Canada, SuiteTax sets the value of this field to the newly created parent Canada nexus for all provincial-level Canada nexuses. |
| Inactive (available only in search) | inactive | Inactive | isinactive | Added to the form and set to false. For Canada, if at least one province nexus is active, SuiteTax sets the parent Canada nexus to active. |
