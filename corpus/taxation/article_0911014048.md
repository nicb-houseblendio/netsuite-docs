You can import default tax codes or default tax groups for each registration using the STE Entity Lookup Settings record.

Note:

You'll first need to create an entity tax registration before setting up the default tax codes or tax groups through CSV.

#### To set default tax group or tax code as CSV:

1.  Go to Customization > Lists, Records, & Fields > Record Types > STE Entity Lookup Settings > List.
    
2.  Export a list of **STE Entity Lookup Settings**, making sure you include **Internal ID** s.
    
3.  Prepare your CSV file. For each row, include:
    
    1.  **Internal ID** (of the STE Entity Lookup Setting record)
        
    2.  **Default Tax Code** (Internal ID of the tax code), or **Default Tax Group** (Name, Internal ID, or External ID of the tax group).
        
    
    Note:
    
    Other fields can remain in the import file for reference if they aren't mapped.
    
    Note:
    
    Don't update the **Entity**, **Nexus Country**, **Nexus**, or **Tax Registration Number** fields in this import. If these need changes, update them on the entity record itself. If you make changes in these fields within the STE Entity Lookup Settings record, they won't be applied to the entity tax registration.
    
    Note:
    
    Only one (Default Tax Code or Default Tax Group) may be set per line.
    
    Note:
    
    For US nexuses, don't set the **Entity Exempt Status** field. This is managed automatically by the related exemption certificate record if there's one. For nexuses outside US, if **Entity Exempt Status** is set to "**True**", any transaction created for the entity + nexus + entity tax registration combination will be applied with a **Not Liable** tax code.
    
4.  Go to Setup > Import/Export > Import CSV Records.
    
    1.  In the **Import Type** field, select **Custom Records**.
        
    2.  In the **Record Type** field, select **STE Entity Lookup Settings**.
        
    3.  Set **Data Handling** to **Update** and enable **Run Server SuiteScript and trigger WorkFlows** under **Advanced Options**.
        
    4.  Map **Internal ID** and the correct field (**Default Tax Code** or **Default Tax Group**).
        
    
    Note:
    
    Be sure to set the appropriate **Reference Type** used on the **Default Tax Group** (**Names**, **Internal ID**, or **External ID**).
    
5.  Complete the import process.
    

Note:

You may update both customer and vendor tax registrations in a single import.
