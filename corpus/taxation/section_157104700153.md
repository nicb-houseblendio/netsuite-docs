Note:

This topic is for NetSuite accounts that use the Country Tax Report page to generate the Intrastat Supplementary Declaration for Dispatches and Arrivals reports. If you are using the EU Intrastat Report page, see [Mode of Transport](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1505110665.html).

Mode of Transport is defined according to the active vehicle that moves goods for every arrival or dispatch transaction.

When you choose an EU vendor or customer on a transaction form, the Tax Reporting subtab displays the **Mode of Transport** field. You must fill in this field for it to be included on the Intrastat report.

The Intrastat Arrivals and Dispatches reports declare the mode of transport through the following one-digit codes:

| Code | Description |
| --- | --- |
| 1 | Sea transport/Transport by sea |
| 2 | Rail transport/Transport by rail |
| 3 | Road transport/Transport by road |
| 4 | Air transport/Transport by air |
| 5 | Postal consignments/Consignments by post |
| 7 | Fixed transport installations |
| 8 | Inland waterway transport/Transport by inland waterway |
| 9 | Own propulsion |
