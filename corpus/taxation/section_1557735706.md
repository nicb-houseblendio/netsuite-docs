You must configure the following to take advantage of all the features in the SuiteTax Engine:

-   Create a nexus, see [Setting Up Nexuses in SuiteTax Engine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557741442.html)
    
-   Provision tax records, see [Automatic Tax Record Provisioning for VAT Countries](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557735917.html)
    
-   Set up partially deductible and non-deductible taxes, see [Partially Deductible and Non-deductible Taxes in SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0610121020.html)
    
-   Set Up Tax Groups, see [Setting Up Tax Groups in SuiteTax Engine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1565954398.html)
    
-   Set nexus preferences, see [Setting Up Nexus Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557736138.html)
    
-   To learn more about the Transaction Level Rounding method, see [Transaction Level Rounding](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0603044036.html)
    
-   Edit nexus default tax codes, see [Editing Default Tax Codes for Nexuses](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557736208.html)
    
-   Set tax schedules as needed, see [Setting Up Tax Schedules](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557736252.html)
    
-   Set default tax codes and tax groups for entities, see [Setting Up Entity Default Tax Codes and Tax Groups](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557736345.html)
    
-   Set default tax codes and tax groups for entity tax registrations as CSV, see [Setting Default Tax Code or Tax Group on Entity Tax Registration as CSV](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0910045552.html)
    
-   Set compliance text for reverse charge sales invoices as needed, see [Setting Up Compliance Text on Reverse Charge Sales Invoices](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557736683.html)
    
-   Review and customize roles and permissions, see [Roles and Permissions for the SuiteTax Engine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557399606.html)
    
-   To find more about how the SuiteTax Engine determines which tax code to use, see [Tax Code Lookup Logic for VAT Countries](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557736389.html)
    
-   To learn more about automatic tax calculation for shipping, see [Automatic Tax Calculation for Shipping in VAT Countries](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159482019960.html)
    

The SuiteTax Engine uses these settings to calculate your taxes. For more information, see [Tax Code Lookup Logic for VAT Countries](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557736389.html).
