## Tax Setup Permissions {#bridgehead_4657982050}

Administrators can access the tax setup tasks in the Accounting section of the **Setup** tab.

If you are an administrator, you can create new roles or customize roles to add tax permissions or modify access levels for tax permissions. For information about assigning permissions to roles, see [Customizing or Creating NetSuite Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N285937.html).

Refer to the following table for permissions required for the tax setup tasks.

For details about permissions, see [Permissions Documentation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N326485.html).
