In the SuiteTax Engine, you are able to set nexus preferences that determine the SuiteTax Engine's behavior when calculating taxes. To configure nexus preference in the SuiteTax Engine, please see [Setting Up Nexus Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557736138.html).

To learn more about the Transaction Level Rounding method, see [Transaction Level Rounding](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0603044036.html).
