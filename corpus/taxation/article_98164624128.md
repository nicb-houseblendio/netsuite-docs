Important:

Tax Audit Files SuiteApp isn't compatible with the SuiteTax feature. If the SuiteTax feature is enabled in your NetSuite account, don't install this SuiteApp.

Before you can Tax Audit Files, your account administrator needs to enable additional features and preferences in your NetSuite account.

## Required Features {#bridgehead_58164823052}

Enable the required features for Tax Audit files.

#### To enable features {#procedure_35105419287}

1.  Go to Setup > Company > Setup Tasks > Enable Features.
    
2.  Click the **SuiteCloud** subtab and check the box for each of the following features:
    
    1.  Item Option
        
    2.  Custom Records
        
    3.  Client SuiteScript
        
    4.  Server SuiteScript
        
    5.  SuitFlow
        
3.  Click **Save**.
    

For more information, see [Enabling Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N232138.html).

Important:

Make sure you review and give your consent to the SuiteCloud Terms of Service when you're prompted during activation.

## Additional Requirements {#bridgehead_1165203404}

After you enable the required features, make sure you set up the following:

-   Install the [International Tax Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2051341.html) SuiteApp (Bundle ID 43003).
    
-   Set up tax reporting and accounting periods. For more information, see [Working with Tax Periods](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1797157.html), [Setting Up Tax Periods](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1797599.html) and [Accounting Period Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1445585.html).
    
-   To use Tax Audit Files for Singapore, you'll need to set up your Singapore subsidiary and nexus, and create Singapore tax codes. For more information, see [Singapore Tax Topics for Accounts Without SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N1981261.html).
    
-   To use Tax Audit Files for Mexico, you'll need to install the Mexico Compliance SuiteApp. For more information, see [Mexico Tax Topics (Mexico Compliance SuiteApp)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N1940317.html).
