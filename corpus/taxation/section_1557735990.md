The SuiteTax Engine automatically provisions tax rate types. For tax codes you create outside of automatic provisioning, the tax rate type must be set during tax code creation.

For more information about SuiteTax Engine tax records automated provisioning, see [Automatic Tax Record Provisioning for VAT Countries](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557735917.html).

For more information about tax rate types, see [Tax Rate Types in the SuiteTax Engine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557735634.html).

#### To set tax the rate type when creating a tax code:

1.  Go to _Setup > Tax > Tax Codes > New_.
    
2.  In the **Name** field, enter a name.
    
3.  In the **Description** field, enter a description.
    
4.  In the **Tax Type** field, select a tax type from the list. You can create a new tax type at _Setup > Tax > Tax Types > New_. For more information, see [Tax Rate Types in the SuiteTax Engine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557735634.html).
    
5.  In the **Payables Account** and **Receivables Account** fields, the values are populated based on the defined accounts for the selected tax type.
    
6.  In the **Available On** field, select a type of transaction from the list. See [Tax Transaction Types in the SuiteTax Engine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557735490.html) for details.
    
7.  In the **Tax Rate Type** field, select a tax rate type from the list.
    
8.  Click **Save**.
