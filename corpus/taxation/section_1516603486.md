Important:

The Tax Audit Files Report Threshold Configuration is currently available only for the Mexico Journal (XML) report.

When you generate a report using Tax Audit Files, the system runs a scheduled script and queues it for processing. How soon your script runs depends on how many unfinished jobs are in the system, their priority, and execution time.Reports with a large amount of data take a longer to generate. If the instruction limit is reached, the script fails and the report won't be generated. To avoid reaching the instruction limit, you can set a report threshold for your Tax Audit Files.

#### To set threshold configuration:

1.  Go to Customization > Lists, Records, & Fields > Record Types.
    
2.  On the Record Types page, click **New Record** next to the **TAF Report Threshold Configuration** record.
    
3.  On the TAF Report Threshold Configuration page, enter values for the following fields:
    
    -   **Name** - Enter the ID of the Tax Audit File report.
        
        Note:
        
        For Mexico Journal (XML) report, the report ID is **JOURNAL\_MX\_XML.**
        
    -   **Runtime Limit** - Enter a runtime limit in milliseconds. This limit determines when the system reschedules the script for your TAF report.
        
        Important:
        
        The preferred runtime limit value is from 600,000 through 900,000 milliseconds. If you leave the Runtime Limit blank, the system sets the reschedule time for the Tax Audit Files scheduled script to 30 minutes (1,800,000 milliseconds).
        
4.  Click **Save**.
