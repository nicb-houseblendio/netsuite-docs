To take advantage of all the features in the SuiteTax Engine, please configure the following:

-   To create nexuses and subnexuses, see [Canada Parent Nexus and Subnexuses](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159524875531.html).
    
-   To find out more about periodic tax return, see [Canada Periodic GST/HST Return (GST 34)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159524879202.html).
    
-   To learn about data provisioning enhancements, see [Canada Data Provisioning Enhancements](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159499705842.html).
