Tax codes determine how much tax is applied to each line item on your transaction records.

To view existing tax codes in your NetSuite account, go to _Setup > Accounting > Taxes > Tax Codes_. Make sure all the properties on each tax code are set correctly. Changes made to tax codes are captured in system notes. For more information, see [Searching System Notes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N673560.html).

For information, see [Tax Code Properties](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1805973.html).

To create tax codes, read the following topics:

-   [Creating Tax Codes - U.S. Nexus](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2039577.html)
    
-   [Creating Tax Codes - United Kingdom](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2026362.html)
    
-   [Creating Tax Codes - Canada](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1856762.html)
    
-   [Creating Tax Codes - Australia](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1834295.html)
    
-   [Creating Tax Codes - Other Nexuses](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1816436.html)
    
-   [Tax Code Properties](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1805973.html)
    
-   [Setting Up Nondeductible Input Tax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1822730.html)
    

Note:

For information about withholding tax codes, read the [Withholding Tax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N2078886.html) topic.

Important:

To use the automatic tax code provisioning feature, install the [International Tax Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2051341.html) before you create subsidiaries. In OneWorld accounts that have the SuiteApp, when you add a new subsidiary country, the system creates the nexus and VAT/GST tax codes for that country. In other words, you need to have the SuiteApp installed before adding a subsidiary.

Without the SuiteApp, when you create a subsidiary country, NetSuite adds the nexus, but only gives you a few default tax codes. For more information, see [Automatic Tax Code Provisioning](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2053451.html).
