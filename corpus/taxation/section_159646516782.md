To create a tax type in SuiteTax, please see [Creating Tax Types in SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4283869397.html#bridgehead_4283871397).

To create a withholding tax type, you must check the **Does Not Add To Transaction Total** box on the tax type form.
