You can import new entity tax registrations into NetSuite using a CSV file.

#### To add a new entity tax registration as CSV:

1.  Prepare your import file. You can use either the single or multiple file upload option.
    
    1.  Create a CSV file with columns for:
        
        1.  **Country**
            
        2.  **State**
            
        3.  **Nexus**
            
        4.  **Address** (from the entity's address list)
            
        5.  **Tax Registration Number**
            
    
    Note:
    
    Each row should represent a new tax registration for an existing customer or vendor.
    
    Note:
    
    Only standard tax registration fields are included in this step. Fields specific to SuiteTax Engine (like Default Tax Code/Group) aren't set here and must be imported separately through the STE Entity Lookup Settings record. For more information, see [Setting Default Tax Code or Tax Group on Entity Tax Registration as CSV](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0910045552.html).
    
2.  Go to Setup > Import/Export > Import CSV Records.
    
3.  Scan and upload your CSV file.
    
    1.  In the **Import Type** field, select **Relationships**.
        
    2.  In the **Record Type** field, select **Customer** or **Vendor**.
        
4.  Set the import options.
    
    1.  For **Data Handling**, select **Update**. This adds new tax registrations to existing entity records.
        
    2.  Under **Advanced Options**, check **Run Server SuiteScript and trigger WorkFlows**. This makes sure the related **STE Entity Lookup Setting** record is created or updated automatically.
        
5.  Map your fields.
    
    1.  Map the following fields from your file:
        
        1.  **Country** (Name or Internal ID)
            
        2.  **State** (Name or Internal ID)
            
        3.  **Nexus** (Name or Internal ID)
            
        4.  **Address** (from the entity's address list)
            
        5.  **Tax Registration Number**
            
    2.  Save your import for the future use.
        
6.  Import the file.
    
    1.  Proceed through the Import Assistant and complete the import.
        
    2.  Confirm the newly added tax registrations appear for the appropriate customers or vendors.
        
    
    Note:
    
    Perform separate imports for customer and vendor tax registration records.
