If you have a tax code you don't use and don't want it to appear in your lists, you can inactivate or delete it.

Important:

Don't delete the UNDEF tax code provisioned by NetSuite. It's used when NetSuite can't figure out the correct tax code for transactions imported into the system using CSV or Web Services.

#### To inactivate a tax code: {#procedure_N1808252}

1.  Go to _Setup > Accounting > Taxes > Tax Codes_.
    
2.  Check the **Show Inactives** box.
    
3.  Check the box in the **Inactive** column next to the tax code record.
    
4.  Click **Submit**.
    

The tax code won't show up in the Tax Codes list unless you check the **Show Inactives** box, and won't be available for selection on transactions, reports, and records.

#### To delete a tax code: {#procedure_N1808317}

1.  Go to _Setup > Accounting > Taxes > Tax Codes_.
    
2.  Click **Edit** next to the tax code.
    
3.  Click **Delete**. A confirmation message is shown.
    
4.  Click **OK** to confirm the deletion.
