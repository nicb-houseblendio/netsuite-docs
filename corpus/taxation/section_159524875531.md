Note:

To ensure that the provisioning for the Canada province nexus works properly, please set the Canada nexus as parent when creating a Canada province nexus.

You must create a Canada parent nexus before you can select it as parent in your Canadian province subnexuses. Please complete the following steps:

1.  Go to _Setup > Tax > Nexuses > New_.
    
2.  In the **Country** field, select Canada.
    
3.  Leave the **State/Province/County** field blank.
    
4.  In the **Description** field, describe this nexus.
    
5.  Leave the **Parent Nexus** field blank.
    
6.  Click **Save**.
    

When you have created a Canada parent nexus, you can create province subnexuses. Please complete the following steps:

1.  Go to _Setup > Tax > Nexuses > New_.
    
2.  In the **Country** field, select Canada.
    
3.  In the **State/Province/County** field, select the state, province, or county of your nexus.
    
4.  In the **Description** field, describe the nexus.
    
5.  In the **Parent Nexus** field, select the 'Canada' nexus.
    
6.  Click **Save**.
