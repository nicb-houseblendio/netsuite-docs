Note:

This topic is for NetSuite accounts that use the Country Tax Report page to generate the Intrastat Supplementary Declaration for Dispatches and Arrivals reports. If you are using the EU Intrastat Report page, see [Supplementary Unit](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4605983594.html).

Supplementary Unit is the unit specified in the Combined Nomenclature for certain commodity codes. It is the secondary unit of quantity for declaring goods in the Intrastat report other than net mass in kilograms. If the Combined Nomenclature published a supplementary unit for a commodity code, you must also select this unit in the **Supplementary Unit** field located at the Tax Reporting subtab of an Item record. You may leave this field blank if the commodity code does not require a supplementary unit.

The Intrastat Supplementary Declaration for Dispatches and Arrivals reports display the supplementary unit according to its abbreviation:

| Abbreviation | Supplementary Unit |
| --- | --- |
| c/k | Carats (1 metric carat = 2 × 10-4 kg) |
| ce/el | Number of cells |
| ct/l | Carrying capacity in tonnes<1> |
| g | Gram |
| gi F/S | Gram of fissile isotopes |
| GT | Gross tonnage |
| kg C5H14ClNO | Kilogram of choline chloride |
| kg H2O2 | Kilogram of hydrogen peroxide |
| kg K2O | Kilogram of potassium oxide |
| kg KOH | Kilogram of potassium hydroxide (caustic potash) |
| kg met.am. | Kilogram of methylamines |
| kg N | Kilogram of nitrogen |
| kg NaOH | Kilogram of sodium hydroxide (caustic soda) |
| kg/net eda | Kilogram drained net weight |
| kg P2O5 | Kilogram of diphosphorus pentaoxide |
| kg U | Kilogram of uranium |
| kg 90 % sdt | Kilogram of substance 90 % dry |
| 1,000 kWh | Thousand kilowatt hours |
| l | Litre |
| l alc. 100% | Litre pure (100 %) alcohol |
| 1,000 l | Thousand litres |
| m | Metre |
| m2 | Square metre |
| m3 | Cubic metre |

| pa | Number of pairs |

| 100 p/st | Hundred items |
