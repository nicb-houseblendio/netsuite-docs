The International Tax Reports SuiteApp includes nature of transaction codes for some countries. If the code you need isn't in NetSuite, you can create a new nature of transaction code and NetSuite will pick it up in the Intrastat report. For more information, see [Creating a Nature of Transaction Code](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164379251413.html).

Set up nature of transaction codes separately for each nexus. After that, you can set a default code for each transaction type per nexus. For more information, see [Setting Up Default Nature of Transaction Codes on Transaction Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N2070986.html).

#### To set up a nature of transaction code for a nexus: {#procedure_N2070775}

1.  Go to Setup > Accounting > Manage Tax Reporting.
    
2.  Click the **Intrastat Reporting** subtab.
    
3.  Select a nexus.
    
4.  Select the nature of transaction codes that you need for the nexus. You can press and hold the CTRL key to select multiple codes in the list.
    
5.  Click **Save**.
    

After you've set up nature of transaction codes for your nexus, they'll be available for selection in the **Nature of Transaction Code** dropdown field on transaction records. For information about selecting nature of transaction codes on transaction records, see [Setting Up Default Nature of Transaction Codes on Transaction Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N2070986.html).

Note:

The nature of transaction codes that you set up on the **Intrastat Reporting** subtab are also available on the **Intrastat Defaults** subtab.
