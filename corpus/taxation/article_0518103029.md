Tax Reporting Framework supports reports that contain data using SuiteQL. To build a report using SuiteQL, you need to download and extract the tafsuiteql.zip file. For more information, see [Downloading and Extracting the Country Tax Reports Project Files](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0517042820.html).

The following are the files you can customize for your tax report using SuiteQL:

-   **TAF\_SUITEQL.json** - Contains the objects and code to run the SuiteQL query and the report processor. Found in FileCabinet\\SuiteApps\\com.netsuite.tafsuiteql\\src\\schemas folder.
    
-   **SuiteQLBuilder.js** - Contains the code that returns a SuiteQL query. Found in \\FileCabinet\\SuiteApps\\com.netsuite.tafsuiteql\\src\\builders folder.
    

The sample code and query provided in the **SuiteQLBuilder.js** can be run and customized according to your reports needs. For more information about SuiteQL, see [SuiteQL](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156257770590.html).
