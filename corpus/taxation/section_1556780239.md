If you have installed the Tax Reporting Framework SuiteApp before Mexico Localization and GL Audit Numbering features, you need to rerun the Search Installer Scheduled script. This workaround is for ensuring that Mexico Electronic Accounting fields are included in your saved searches.

Note:

Only an administrator can rerun scheduled scripts. If you do not have sufficient permissions to perform this action, please contact your account administrator for assistance.

#### To rerun the Search Installer Scheduled Script:

1.  In NetSuite, go to _Customization > Scripting > Script Deployments_.
    
2.  Select **Search Installer** from the **Script** list.
    
3.  Click **Edit** beside the Search Installer ID: customdeploy\_str\_search\_installer\_ss.
    
4.  Click the dropdown arrow beside Save and select **Save and Execute**.
    

For more information about submitting scheduled scripts on demand, see [Submitting an On-Demand Scheduled Script Instance from the UI](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1508948664.html).
