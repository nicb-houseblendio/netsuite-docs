With Tax Reporting Framework, you can generate tax audit files that comply with government statutory requirements. The generated tax audit files are extracts of the general ledger and can be downloaded in a format prescribed by the tax authorities. The exported data provides a way for you to back up or archive critical transaction data that has impact on the general ledger.

To start generating tax audit files, read the following topics:

-   [Additional Prerequisites for Tax Audit Files](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1528245293.html#bridgehead_1556592564)
    
-   [SuiteTax EMEA Audit Files](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156739607543.html)
    
-   [Generating Localized Country Tax Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1528250223.html)
    

If you are using a OneWorld account, Tax Audit Files automatically generates the tax audit files in your preferred accounting context. To set up an accounting context, see [Accounting Contexts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4640155582.html).

Tax Reporting Framework supports the following tax audit files:

-   [Fichier d'Ecritures Comptables (FEC) in France Localization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1539840650.html)
    
-   [Mexico Audit Files: Electronic Accounting Files](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1554879047.html)
    
-   [Singapore IRAS Audit File](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0104020156.html)
    

Note:

Tax Reporting Framework must be supplemented with a regional or country-specific localization SuiteApp to generate tax audit files. Check the table on [Tax Reporting Framework Localization Requirements](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_157303200001.html) for a list of required SuiteApps that you need to install.

For information about the reporting features of Country Tax Reports, see [Tax Reporting Framework](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1528262949.html).

To install Tax Reporting Framework, see [Installing Tax Reporting Framework](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1528245293.html).
