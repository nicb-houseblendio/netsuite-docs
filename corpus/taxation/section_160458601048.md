Important:

The topics here cover withholding tax for NetSuite accounts without the SuiteTax feature enabled. If you're using an account with SuiteTax enabled, go to [Withholding Taxes in SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159646451288.html).

Withholding tax isn't getting new features and reports in accounts without SuiteTax. Updates to the Withholding Tax SuiteApp now include only fixes for reported issues.

The Withholding Tax SuiteApp has the following limitations:

-   It isn't compatible with the SuiteTax feature. For information about withholding tax in SuiteTax, see [Withholding Taxes in SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159646451288.html).
    
-   The SuiteApp only supports up to 400 withholding tax codes per nexus. For more information, see [Setting Up Withholding Tax Codes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2084484.html).
    
-   It doesn't apply withholding tax to the following line items:
    
    -   Description item type
        
    -   Subtotal item type
        
    -   Group item type
        
    -   End of Group line (the amount of the group item)
        
-   It doesn't support the Installments feature. Withholding tax can't be applied to invoices with installment terms.
    
-   It doesn't support bulk invoice processing. You need to edit and save each invoice to trigger withholding tax calculation. For more information, see [Recording Withholding Taxes on Transactions as a Seller](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2087219.html).
    
-   It process up to 1000 bills or invoice records and 1000 open bills or invoices at a time, with a maximum of 1000 open bills or invoices.
    
-   It doesn't support the Void Transactions Using Reversing Journals feature, so you can't void a bill payment with withholding tax using reversing journals.
    
-   Header discounts aren't supported if withholding tax is set to record on accrual in sales transactions. For more information, see [Setting Up Withholding Tax Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2083657.html).
    
-   The Pay Tax Liability feature in NetSuite can't pick up withholding tax amounts posted to an account that isn't a tax control account. For more information, see [Setting Up Withholding Tax Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2084141.html).
    
-   Cash discounts aren't included in the withholding tax amount calculation. For information about applying discounts on a bill payment, see Step 7 of [Withholding Taxes on Bill Payments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2086435.html). For information about applying discounts on a payment for an invoice, see Step 6 of [Withholding Taxes on Payment Acceptance](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2087711.html).
    
-   When importing transactions using CSV and SOAP web services, you can't apply withholding tax to a check transaction for a customer. For information about withholding tax errors that you may encounter when using CSV import and SOAP web services, see [Withholding Tax Error Codes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4605306566.html).
    
-   Localized withholding tax reports are only available in accounts with a Philippines nexus. For more information about the withholding tax reports provided by the Withholding Tax SuiteApp, see [Withholding Tax Reporting](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2088848.html).
    
-   Automatic provisioning of withholding tax codes is available to Philippine nexus only.
    
-   Withholding tax recalculates on nexus change triggered by changes related to entity, address, or subsidiary. If the nexus change is related to adding or editing a One Stop Shop (OSS) item, withholding tax won't be recalculated.
    
-   Withholding tax values don't show for Payment type line items in View mode. You can only see them when creating or editing a payment.
    
-   When you save a bill payment record, a bill credit is created with withholding tax regardless of the approval status.
    
-   The computation of withholding tax only works when transactions are processed with the following method:
    
    -   NetSuite User Interface
        
    -   Scheduled Script
        
    -   CSV Import
        
    -   Web Services
