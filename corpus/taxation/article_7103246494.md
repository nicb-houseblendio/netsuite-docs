If you encounter issues about tax codes on transactions, check the table below for scenarios and troubleshooting steps:

| Scenario | Guidelines | Recommended Action |
| --- | --- | --- |
| The tax codes on a transaction aren't from the country you expect. For example, you see UK tax codes instead of the German ones. | 
-   On a transaction, you can only assign nexuses linked to the subsidiary. Usually, nexus is based on the transaction shipping address.
-   The tax code list is based on the transaction nexus.
-   The tax code list on a transaction shows tax codes from the same country as the transaction nexus ("nexus\_country").

 | 

-   To check the nexus on your transaction, do one of the following:
    -   Right-click anywhere on your page and then select "View page source" or "View source". Search "nexus\_country" and the country code will show in the value field
    -   You can also use Chrome Developer Console. Type "nlapiGetFieldText('nexus')" and press "Enter". Note: This works only if the transaction is in the edit mode.
    -   Usually, nexus is based on the transaction shipping (ship to) address.
-   You can also check these help topics on legacy tax determination logic:
    -   [Set Up Taxes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1796252.html)
    -   [Setting Default Tax Items on Vendor Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1796855.html)
    -   [Setting Default Tax Items on Customer Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1796705.html)
    -   [Setting Tax Codes or Tax Schedules on Item Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1797005.html)
    -   [Billing Costs to Customers](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1248576.html)
    -   [Differences between SuiteTax and Legacy Tax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0315035511.html) Note: In the "Generic Features" table, see the "Nexus Determination" entry.

 |
| No default tax code is set on a new item line, even though there's a default tax code on the customer record. | 

-   On a transaction, you can only assign nexuses linked to the subsidiary. Usually, nexus is based on the transaction shipping address.
-   The tax code list is based on the transaction nexus.
-   The tax code set on the customer record defaults to the transaction if its country matches the transaction nexus ("nexus\_country"). If not, it isn't defaulted. For more information, see [Setting Default Tax Items on Customer Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1796705.html).

 | To check the nexus on the transaction, try one of these methods:

-   Using **Chrome Developer Console**: type "_nlapiGetFieldText('nexus')_" and press "Enter".
-   Right-click anywhere on your page and then select "View page source" or "View source". Search "nexus\_country" and the country code will show in the value field.

 |
| The tax codes are from the expected country, but a tax code or group is missing from the list. | 

-   Only "**Active**" tax codes or tax groups appear in the list.
-   The tax accounts connected to the tax code type must be "**Active**" too.

 | 

-   Check if the tax code or group is active. If it's "**Inactive**", it won't appear in the tax code list for transactions and entity records.
-   If you're using OneWorld, ensure that the tax code or group is linked to the transaction subsidiary.
-   Check if the tax control account linked to the tax code is active. Check the tax type linked to the tax code or group. The tax control accounts are on the tax type record. Look for them in the Chart of Accounts and check if "**Inactive**" is set. If so, that's why it doesn't appear in your tax code list.
-   If your tax group and control accounts are active but the tax group is missing, check if the "**Tax Code Lists Include**" setting is set to "**Tax Codes**" only. For missing tax codes, check if it's set to "**Tax Groups**" only.
    -   To check this, go to Setup > Accounting > Set Up Taxes and select your nexus tab.
    -   Set the **Tax Code Lists Include** setting as needed.
    -   The **Tax Code Lists Include** only applies to US nexuses.
-   For more information, see the related help topics:
    -   [Set Up Taxes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1796252.html)
    -   [Tax Groups Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1809948.html)
-   If none of those solve the issue, check the **Maximum Entries in Dropdowns** setting under Home > Set Preferences.

 |
| Only the "**Not Taxable**" tax code appears in the transaction tax code list. | \- | Check if "**Taxable**" box is unchecked on the customer record, transaction level, or item line. For US nexuses, also check on tax schedules. |
| Other settings to check if the tax code is missing or the tax code list is not related to the country the you expect. | \- | 

-   Make sure these records are active:
    -   nexus
    -   tax code or tax group
    -   tax control account
    -   tax type
-   Check the **Maximum Entries in Dropdowns** setting under Home Icon > Set Preferences > General > Optimizing NetSuite. Change the setting so that dropdown lists become a popup lists. For example, set it from "50" to "0", then see if that fixes your issue. If that fixes your issue, submit a support case for further investigation.

 |
