The NetSuite Tax Reporting Framework SuiteApp is the tax reporting framework accounts with SuiteTax, accounts without SuiteTax, and accounts with localization SuiteApps installed. It provides the tax report setup options, permissions, and generation preferences. The following describes the setup requirements for you to make use of all the features and capabilities in Tax Reporting Framework:

-   [Prerequisites for Accounts With SuiteTax](#bridgehead_1528246412)
    
-   [Prerequisites for Accounts Without SuiteTax](#subsect_158977703422)
    
-   [Additional Prerequisites for Tax Audit Files](#bridgehead_1556592564)
    
-   [Installing Tax Reporting Framework](#bridgehead_1528246665)
    

## Prerequisites for Accounts With SuiteTax {#bridgehead_1528246412}

The following are the setup requirements for installing Tax Reporting Framework in accounts with SuiteTax:

-   **Enable SuiteTax** - To enable the SuiteTax feature, see [Enabling the SuiteTax Feature](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1513063459.html).
    
-   **Install SuiteTax Engine** - To install the SuiteTax Engine, see [Installing the SuiteTax Engine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557397007.html).
    
    Note:
    
    Do not install the SuiteTax Engine if your account only needs India or Brazil taxation. For information about NetSuite's India Localization, see [India Help Topics](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4198421457.html) . For information about Brazil Reports SuiteApp, see [Brazil Reports SuiteApp Installation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_164624303035.html).
    
-   **Enable the following features** - In NetSuite, go to _Setup > Company > Setup Tasks > Enable Features_ and enable the following features:
    
    | Enable Feature subtab | Feature to enable |
    | --- | --- |
    | Company | 
    -   File Cabinet
    
     |
    | Accounting | 
    
    -   Accounting Periods
    
     |
    | SuiteCloud | 
    
    -   Item Options
    -   Custom Records
    -   Advanced PDF/HTML Templates
    -   Client SuiteScript
    -   Server SuiteScript
    -   SuiteFlow
    
     |
    
    For information about enabling features in NetSuite, see [Enabling Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N232138.html).

## Installing Tax Reporting Framework {#bridgehead_1528246665}

Tax Reporting Framework SuiteApp is automatically updated whenever there are enhancements or new features added. This SuiteApp is free.

Note:

You must be an administrator to install the Tax Reporting Framework SuiteApp.

#### To install Tax Reporting Framework:

1.  In NetSuite, go to _Customization > SuiteBundler > Search & Install Bundles_.
    
2.  In the **Keywords** field, enter **Tax Reporting Framework**.
    
3.  Click **Search**.
    
4.  Click **Tax Reporting Framework**.
    
    Bundle ID: 237699.
    
5.  On the Bundle Details page, click **Install**.
    
6.  On the Preview Bundle Install page, click **Install Bundle**.
    
    For more information about installing SuiteApps, see [Installing a Bundle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3395142.html).
    
7.  After the installation completes, you must install the regional or country-specific localization SuiteApp for your nexus. See [Tax Reporting Framework Localization Requirements](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_157303200001.html).
    

To learn about the limitations of Tax Reporting Framework, see [Known Limitations of Tax Reporting Framework](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156706175950.html).

To uninstall Tax Reporting Framework, see [Uninstalling a Bundle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3400972.html) . After you uninstall the SuiteApp, go to the File Cabinet and delete the bundle folder. In NetSuite, go to _Documents > Files > File Cabinet_ > SuiteBundles. Click **Delete Files** and check the box for Bundle 237699. Click **Delete**.
