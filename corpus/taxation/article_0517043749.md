You need to first generate a Universally Unique Identifier (UUID) for your tax report. This serves as an identifier for your country tax report.

To do this, you can use online services such as the [Online UUID Generator](https://www.uuidgenerator.net/).

After generating the UUID, replace all instances of **NEW\_UUID** in the project files with your generated **UUID**:

-   str\_localized\_reports\_list.json
    
-   SDFInstaller.js
    
-   str\_localized\_bundle.json
    
-   constants.js
    

In case you are integrating this report with an existing SuiteApp, you can use the same UUID as your existing project UUID file if the CTR project files are located in the same folder.

If your project file is located in another sub folder in your project, generate a new UUID. Tax Reporting Framework requires a unique UUID in the base CTR folder.
