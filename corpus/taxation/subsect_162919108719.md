This topic describes the OSS Feature setup for accounts without the SuiteTax feature enabled. For accounts with SuiteTax, see [One Stop Shop Setup for Accounts with SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0622104643.html).

Before generating an OSS VAT report for accounts without SuiteTax, see the following help topics:

-   [Best Practices for OSS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4161911339.html)
    
-   [Enabling the OSS Feature](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4161988579.html)
    
-   [Setting Up OSS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4162081368.html)
    
-   [Assigning an OSS Nexus to a Company or Subsidiary](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4162117213.html)
    

Before you can generate OSS reports, you must install all required SuiteApps.

## Required SuiteApps {#bridgehead_52160309745}

| SuiteApp | Installation Steps |
| --- | --- |
| Tax Reporting Framework | [Installing Tax Reporting Framework](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1528245293.html) |
| International Tax Reports | [Installing and Setting Up International Tax Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2051712.html) |

After the SuiteApps have been installed, you can install the One Stop Shop SuiteApp.

#### To install One Stop Shop SuiteApp:

1.  Go to **SuiteApps**.
    
2.  In the search bar, enter **One Stop Shop**.
    
3.  Click the One Stop Shop image.
    
4.  Click **Install**.
    
5.  In the dialog window, click **Install**. The process may take a few minutes to finish.
    

Tax Reporting Framework includes an OSS Item Type field on Item records. This field supplies information for OSS reporting by classifying items as either Goods or Services. NetSuite automatically considers goods as OSS items.

-   To apply OSS reporting to a service item, check the **MOSS Applies** box on the Accounting subtab on an Item record.
    
-   If you check the **MOSS Applies** box on an item marked as Goods, NetSuite will treat the item as a Service for OSS reporting purposes.
    

For more information, see [Marking OSS Items](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4162935442.html).

Furthermore, review Tax Reporting Framework permissions. By default, the Tax Reporting Framework SuiteApp provides permission levels to standard roles such as Administrator, Accountant, and CFO. You can also assign a Tax Reporting Framework permission to a standard or a custom role. For more information, see [Roles and Permissions in Tax Reporting Framework](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1528249899.html).
