For developers, Tax Reporting Framework provides you with the necessary APIs and scripts for you to be able to build a tax report quickly within the **Suite Developer Framework**.

-   Support for Saved Searches, SuiteQL, so you can quickly generate reports.
    
-   Support for freemarker in customizing reporting templates.
    
-   Support for accounts with and without SuiteTax enabled.
    

Note:

Currently, Tax Reporting Framework only supports generation of Tax Audit Files within the Suite Developer Framework.

## Prerequisites {#subsect_80153424893}

To be able to build tax reports using Tax Reporting Framework, you need the following:

-   Access to the Tax Reporting Framework Project Zip File. See [Downloading and Extracting the Country Tax Reports Project Files](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0517042820.html) for more information.
    
-   Install the SuiteCloud Command-Line Interface (CLI). For more information, see [SuiteCloud Platform](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157660595670.html).
    
-   Generate an UUID for your SuiteApp. See [Setting a UUID for your Tax Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0517043749.html).
