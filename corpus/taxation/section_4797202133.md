When you enable the SuiteTax feature, the following tax records and pages are no longer available in your NetSuite account.

-   Process GST/HST Refund
    
-   Sales Tax Payment
    
-   Set Up Taxes
    
-   State Tax Import
    
-   Tax Control Account
    
-   Tax Group
    
-   Tax Liability
    
-   Tax Period
    
-   Tax Reports
    
-   Tax Schedule
    

SuiteTax retains the nexus, tax code, and tax type records, but reconfigures some of the fields available on these records. For information about the changes to these tax records when SuiteTax is enabled, read the following topics:

-   [Nexus Records in SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4797203207.html)
    
-   [Tax Code Records in SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4797203596.html)
    
-   [Tax Type Records in SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4797203280.html)
    

Note:

Some tax codes and tax groups can have subsidiary restrictions on sales tax payable accounts. Certain subsidiary restrictions on a record can be incompatible with some tax types. For example, the tax code CA\_CA has a tax type that contains a sales tax payable account. This tax code is also part of the CA tax group, which is inaccessible because SuiteTax is enabled. You must make sure you set the same subsidiaries on your related tax codes and tax groups in your account.
