The following table shows the One Stop Shop (OSS) setup permission levels for various NetSuite roles.

Note:

The following permissions are by default, and it'sn't possible to change it. it'sn't possible to assign the permissions to different roles either.

| Role | OSS Setup permission |
| --- | --- |
| Administrator | Full |
| Tax Engine Role | Full |
| Full Access (deprecated) | View |
| A/P Clerk | View |
| A/R Clerk | View |
| Accountant | View |
| CFO | View |
| Accountant (Reviewer) | View |
| Bookkeeper | View |

Note:

OSS Tax Schedules follows the Tax Schedule permission. It can be changed and assigned to different roles. For more information, see [SuiteTax Engine Permissions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557734578.html).
