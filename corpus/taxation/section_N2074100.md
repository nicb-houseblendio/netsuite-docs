Note:

For this SuiteApp to work, you need to have the [International Tax Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2051341.html) SuiteApp installed in your account. To avoid errors, make sure this SuiteApp is installed and you've enabled the required features before you install Tax Audit Files. For more information, see the help topic [Prerequisites for Installing the Tax Audit Files SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_98164624128.html).

## Installation {#subsect_40170036478}

To install this SuiteApp, you'll need to have an Administrator role.

#### To install the Tax Audit Files SuiteApp: {#procedure_34170023937}

1.  Go to Setup > Company > Enable Features.
    
2.  Click the **Tax** subtab.
    
3.  Click **Tax Audit Files**.
    
4.  On the SuiteApp Details page for Tax Audit Files (Bundle ID 47492), click **Install**.
