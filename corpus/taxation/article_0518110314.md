Tax Reporting Framework uses Report Processors to parse and transform your account's financial information to be used in generating your country tax reports. These report processors are used in reports that use either saved searches or SuiteQL.

The Report processors can be found in:

-   **SearchPreProcessor.js** - report processor for reports based on saved searches. Found in \\FileCabinet\\SuiteApps\\com.netsuite.tafsearch\\src\\processors\\pre.
    
-   **SuiteQLPreProcessor.js** - processor for reports based on SuiteQL. Found in \\FileCabinet\\SuiteApps\\com.netsuite.tafsuiteql\\src\\processors\\pre.
    

The saved search or SuiteQL result is a data object the processor will then parse and transform into usable data. This transformed data is then used by the data object in the report summary to generate your tax reports.

For more information about customizing your reports for saved searches, see [Customizing Your Tax Report Using Saved Searches](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0517044036.html).

For more information about customizing your reports for SuiteQL, see [Customizing Your Tax Report Using SuiteQL](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0518103029.html).
