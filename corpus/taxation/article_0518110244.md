After completing the **str\_localized\_reports.json** file, you can update your registry records in the **str\_localized\_bundle.json** file.

The following table describes the fields you need to complete in the file.

| Attribute | Type | Description |
| --- | --- | --- |
| name | string | Name of the report. |
| guid | string | The same values as your UUID. |
| countries | string | Alist of 2-letter ISO codes of countries. If your SuiteApp supports Tax Reports for a given country, please add it to this list. |
| requiredFeatures | string\[\] | A list of features required by your reports. |
| legacyCountries | string | A list of 2-letter ISO codes of countries. If your SuiteApp supports Legacy Tax Reports for a given country, please add it to this list. |
| legacyRequiredFeatures | string\[\] | A list of features required by your Legacy reports. |
