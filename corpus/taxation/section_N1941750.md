## Mexico Tax Preferences {#bridgehead_N1941758}

To set tax preferences, go to Setup > Accounting > Set Up Taxes. Use the following tax preferences for Mexico:

-   **Tax Code for International Sale** : S-MX
    
-   **Default Tax Code** : S-MX
    
-   **Tax Rounding Method** : Round Off
    
-   **Tax Reporting Cash Basis** : Check this box
    

To set up tax codes, see [Mexico Tax Codes (Mexico Compliance SuiteApp)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1940638.html).
