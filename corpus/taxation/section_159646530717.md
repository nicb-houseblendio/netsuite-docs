You can set a default tax group on the entity record, nexus, and tax schedule record.

To assign a default tax group to an entity record, please see [Setting Up Entity Default Tax Codes and Tax Groups](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557736345.html). To assign a default withholding tax group, select the tax group with both sales/VAT tax codes and withholding tax codes created earlier.

If you want to assign a default tax group on the nexus record, see [Editing Default Tax Codes for Nexuses](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557736208.html). Select the tax group containing withholding tax codes to assign a withholding tax group.

To assign a default tax group on the tax schedule record, see [Setting Up Tax Schedules](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557736252.html). To assign a default withholding tax group, under the **Nexus** subtab, select the tax group containing withholding tax codes.
