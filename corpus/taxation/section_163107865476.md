Note:

You must have the SuiteTax feature enabled to use OSS in SuiteTax. For more information on how to enable SuiteTax, see [NetSuite SuiteTax Engine Setup Guide](https://system.netsuite.com/app/help/helpcenter.nl?fid=NetSuiteSuiteTaxEngineSetupGuide.pdf).

If you have a OneWorld account, you must indicate which of your subsidiaries will use One Stop Shop. To use OSS, a subsidiary must have a tax registration in an EU country and use the SuiteTax Engine as its tax engine.

Note:

If you have existing OSS transactions for the subsidiary or the existing schemes in the One Stop Shop Setup page, you can't save changes to the affected lines.

#### To set up OSS in SuiteTax for a particular subsidiary for OneWorld accounts:

1.  Go to Setup > SuiteTax Engine > One Stop Shop Setup. On the One Stop Shop page, you can see the list of subsidiaries for which the OSS setup was already created.
    
2.  To set up OSS for a subsidiary, click **New Subsidiary**.
    
    1.  If the subsidiary is already set up for OSS, click **Edit** next to the subsidiary.
        
3.  In the **Subsidiary** list, select the subsidiary for which you want to set up OSS. Only subsidiaries with EU tax registrations and which use the SuiteTax Engine appear in the list.
    
4.  Select a **Scheme**. You can register for one or multiple OSS schemes. You can use three schemes with OSS:
    
    -   **Union** - You can use this scheme to comply with VAT obligations on all cross-border EU sales of goods to non-business customers.
        
    -   **Non-Union** - Exclusively sellers not established in the EU can use this scheme. The sellers use it for all B2C supplies of services taking place in the EU.
        
    -   **Import** - Suppliers selling goods dispatched or transported from a non-EU country to EU non-business customers can use this scheme.
        
5.  Select a **Member State of Identification** for the subsidiary and for each scheme. Member State of Identification is a Member State in which the taxable person is registered to use OSS. The member state also uses Member State of Identification to declare and pay the VAT due in the Member States of consumption.
    
    Only the following member states appear in the **Member State of Identification** list:
    
    -   that your subsidiaries have a tax nexus in
        
    -   that use the SuiteTax Engine
        
    
    Note:
    
    The United Kingdom can be selected as a Member State of Identification to accommodate business in Northern Ireland. For more information, see the United Kingdom's EU VAT e-commerce package policy paper at [GOV.UK](https://www.gov.uk/government/publications/eu-e-commerce-package/eu-vat-e-commerce-package).
    
6.  Enter the subsidiary's **Tax Identification Number** assigned to the particular scheme. Each scheme has a different Tax Identification Number.
    
7.  Enter the **Valid From** date for the OSS scheme. The date should be between the subsidiary's VAT registration Effective From and Valid Until dates on the Subsidiary record.
    
    Note:
    
    You can't have two OSS schemes of the same type that have the same or overlapping Valid From and Valid Until dates. For each validity period, you can only have one Member State of Identification per scheme. For example, you can report all of your OSS Import scheme VAT obligations to Austria between 1/1/2021 and 12/31/2021, and to Hungary between 1/1/2022 and 12/31/2022. However, you can't report to both countries during the same time.
    
8.  (Optional) If the OSS scheme has an end date, enter the date in the **Valid Until** field. Ensure the date meets the following criteria:
    
    -   The Valid Until date is after the Valid From date for the OSS scheme.
        
    -   The Valid Until date should occur on or before the Valid Until date on the Subsidiary record.
        
    
    If you want to add additional schemes of the same type, you should set Valid Until dates for all of your existing schemes of that type. For example, if you have an existing import scheme with only a Valid From date, you should set a Valid Until date for it. Then you can add the new import scheme.
    
9.  Click **Add** and enter additional schemes, as needed.
    
10.  Click **Save** when done.
