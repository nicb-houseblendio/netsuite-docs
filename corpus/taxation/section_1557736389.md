For each sale or purchase transaction, the SuiteTax Engine determines which tax code to use, and uses the appropriate tax rate to calculate tax amounts.

-   [Tax Code Lookup for Sales](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_165087396818.html)
    
-   [Tax Code Lookup for Purchases](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_165087397958.html)
    

The SuiteTax Engine makes use of SuiteTax nexus lookup logic by automatically determining nexuses for every transaction. For more information, see [Nexus Determination Lookup Logic in SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4283866360.html).
