To test the Mexico UUID plug-in implementation, perform the following tasks:

-   Set up a custom record or custom field that will contain the UUID for each transaction.
    
    For more information about custom records, see [Custom Records Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N2875173.html).
    
    For more information about custom fields, see [Custom Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N2826978.html).
    
-   Enable the plug-in implementation. See [Enable the Mexico UUID Plug-in Implementation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4265084026.html).
    
-   Generate the Mexico Journal tax audit file. See [Generating Mexico Electronic Accounting File (Mexico Compliance SuiteApp)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4252635849.html).
    
-   Examine the generated report. Make sure that the plug-in implementation performs as expected.
