With Tax Reporting Framework, you can generate the following VAT/GST reports:

-   [Business Activity Statement](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156688148769.html)
    
-   [Periodic VAT Return 625](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156775521116.html)
    
-   [Periodic VAT Return CA3](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156775787841.html)
    
-   [Germany Periodic VAT Return - USt 1A](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156775791511.html)
    
-   [Ireland VAT Report: Periodic VAT Return - VAT3](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156775801522.html)
    
-   [Netherlands Periodic VAT Return OB69](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156775966230.html)
    
-   [GST Return 101A](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_21151540595.html)
    
-   [Philippines VAT Report: Monthly Return Form 2550M](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_35151629781.html)
    
-   [Philippines VAT Report: Quarterly Return Form 2500Q](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_17151724578.html)
    
-   [Singapore GST F5 Return](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1220053809.html)
    
-   [Sweden VAT Report: Return Form SKV4700](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156775976474.html)
    
-   [Periodic VAT Return - VAT100](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156775976739.html)
    

Note:

Tax Reporting Framework must be supplemented with a regional or country-specific localization SuiteApp to generate localized VAT/GST reports. Check the table on [Tax Reporting Framework Localization Requirements](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_157303200001.html) for a list of required SuiteApps that you need to install.

To generate a report, see [Generating Localized Country Tax Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1528250223.html).

For information about the reporting features of Country Tax Reports, see [Tax Reporting Framework](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1528262949.html).

To install Tax Reporting Framework, see [Installing Tax Reporting Framework](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1528245293.html).
