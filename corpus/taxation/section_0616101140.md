The following limitations apply to tax codes when scripting with SuiteScript 2.x:

-   When using Legacy Tax, the Tax Code on a requisition won't automatically be carried over when transforming the requisition to a purchase order. You must either apply the tax code to the purchase order in your script, or enter a new tax code in the user interface after the purchase order has been created.
