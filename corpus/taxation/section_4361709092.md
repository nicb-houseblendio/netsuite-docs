Important:

Tax Audit Files SuiteApp isn't compatible with the SuiteTax feature. If the SuiteTax feature is enabled in your NetSuite account, please don't install this SuiteApp.

You can use multiple queues or processors for script processing to split up tax audit file generation and run it in parallel for better performance.

As of 2017.2, the SuiteCloud Processors feature supports a new system based on script processors instead of queues. You can switch script deployments to use processors instead of queues. With this feature, even queue-based processing runs on processors in the server. For more information about this feature, see [SuiteCloud Processors](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1498571420.html). You can increase the number of queues or processors available to your account by purchasing SuiteCloud Plus licenses. For information, see [SuiteCloud Plus Settings](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N259503.html).
