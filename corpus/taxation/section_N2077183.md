Important:

Tax Audit Files SuiteApp isn't compatible with the SuiteTax feature. If the SuiteTax feature is enabled in your NetSuite account, please don't install this SuiteApp.

You can generate tax audit files in NetSuite if your account has the Tax Audit Files SuiteApp.

You can generate, download, or delete any tax audit file from the Audit Files page at Reports > Tax > Audit Files.

The System Notes subtab keeps a history of everything you do with the Tax Audit Files SuiteApp. It records events such as:

-   Create
    
-   Delete
    
-   Cancel
    
-   Generate
    
-   Download
    
-   User names
    
-   Dates
    

It also records specific file details such as period, subsidiary, and report type.

Important:

By using the Tax Audit Files SuiteApp, you assume all responsibility for making sure the data you generate and download is accurate and meets your needs. You're also responsible for keeping any data you download from NetSuite secure if you store it outside the system.
