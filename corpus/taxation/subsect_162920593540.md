The following table describes the reported values on the Import One Stop Shop VAT return in accounts without SuiteTax.

| Box | Report Label | Details |
| --- | --- | --- |
| **EU One Stop Shop VAT Return - Import Scheme** | Title of the report. |
| **Subsidiary** | Name of the selected subsidiary. |
| **Member State of Identification** | Nexus of the selected subsidiary. |
| **Part 1: General Information** |
| 1 | VAT Identification No. | The VAT Identification No. supplied in the EU One Stop Shop preferences tab. |
| 2 | Tax Period | The format of the Tax Period is Mmm.YYYY. |
| 2a | Start date and end date of period | Includes the start date and end date of the tax period in the following format: dd.mm.yyyy - dd.mm.yyyy. |
| 3 | Currency | The 3 digit ISO country code of subsidiary or company's base currency. |
| **Part 2: For each Member State of consumption in which VAT is due** |
| 4.1 | Member State of Consumption | Country code of the Member State of Consumption. |
| 5.1 | Standard VAT rate | Percentage of standard VAT rate in the Member State of Consumption. |
| 6.1 | Reduced VAT rate | Percentage of reduced VAT rate in the Member State of Consumption. |
| 7.1 | Taxable amount at standard rate | Taxable amount at standard rate. |
| 8.1 | VAT amount at standard rate | VAT amount at standard rate. |
| 9.1 | Taxable amount at reduced rate | Taxable amount at reduced rate. |
| 10.1 | VAT amount at reduced rate | VAT amount at reduced rate. |
| **11.1** | **Total VAT amount payable** | Total VAT amount payable. |
| 4.2 | Member State of Consumption | Country code of the Member State of Consumption. |
| 5.2 | Standard VAT rate | Percentage of standard VAT rate in the Member State of Consumption. |
| 6.2 | Reduced VAT rate | Percentage of reduced VAT rate in the Member State of Consumption. |
| 6.2.1 | Special reduced VAT rate | Percentage of special reduced VAT rate. |
| 7.2 | Taxable amount at standard rate | Taxable amount at standard rate. |
| 8.2 | VAT amount at standard rate | VAT amount at standard rate. |
| 9.2 | Taxable amount at reduced rate | Taxable amount at reduced rate. |
| 9.2.1 | Taxable amount at special reduced rate | Taxable amount at special reduced rate. |
| 10.2 | VAT amount at reduced rate | VAT amount at reduced rate. |
| 10.2.1 | VAT amount at special reduced rate | VAT amount at special reduced rate. |
| **11.2** | **Total VAT amount payable** | Total VAT amount payable. |
| **Part 5: Total amount of VAT due for all Member States of consumption** |
| 26 | Total VAT amount due for all Member States | Total VAT amount due for all Member States. |
