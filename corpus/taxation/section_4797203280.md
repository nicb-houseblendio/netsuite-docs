In SuiteTax, tax types are used to link tax codes to nexuses and to the proper general ledger accounts, and to group tax amounts on the transaction summary box. Special tax types, such as withholding tax, are also supported in SuiteTax.

During migration, new tax type records will be created if the tax accounts set on the legacy tax code and tax type records don't match.

| Legacy Tax | SuiteTax | Migration to SuiteTax |
| --- | --- | --- |
| Field Name | Field ID | Field Name | Field ID |
| --- | --- | --- | --- |
| Country (tax type name) | country | Country (dropdown field) | country | Retained (changed to regular field). |
| Name | name | Name | name | Retained. |
| Description | description | Description | description | Retained. |
| \- | \- | Does Not Add To Transaction Total | doesnotaddtototal | Added to the form and set to false. |
| \- | \- | Post To Item Cost | posttoitemcost | Added to the form and set to false. |
| \- | \- | Tax Included In Net Amount | taxinnetamount | Added to the form and set to false. |
| \- | \- | Reverse Charge | reversecharge | Added to the form and set to false. |
| \- | \- | Inactive | isinactive | Added to the form and set to false. |
| \- | nexusestax | \- | nexusaccounts | Changed machine ID. |
| \- | nexusid | \- | \- | Removed from form. |
| Nexus | nexus | Nexus | nexus | Retained. |
| Liability/Sales Tax Account | saletaxacct | Payables Account | payablesaccount | Changed field names and IDs. Field values depend on whether the sales and purchase tax accounts set on the legacy tax code and tax type records are the same or not:
-   If the tax accounts are the same on both records, the legacy values for tax accounts are retained on the tax type record during migration to SuiteTax. When the tax code is used on transactions in SuiteTax, the GL account is sourced from the tax type.
-   If the tax accounts are different, SuiteTax will create a new tax type with tax accounts that match the ones set on the legacy tax code record. The newly created tax type will be assigned to the migrated tax code record and to other migrated tax codes with the same tax accounts. Doing so ensures that the GL impact of transactions remains unchanged after migration to SuiteTax. Note: A new tax type will be created regardless of whether there is an existing legacy tax type with the same tax accounts.
