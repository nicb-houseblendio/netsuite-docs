Note:

This section applies only to VAT countries.

The SuiteTax Engine uses transaction types to calculate tax for your transactions. The SuiteTax Engine bases these calculations on the transaction details at the time of the transaction. These are possible tax transaction types:

-   For sales and purchases in the same country:
    
    -   Domestic Sales
        
    -   Domestic Purchases
        
-   For sales and purchases outside the country:
    
    -   Imports
        
    -   Exports
        
-   For sales and purchases within the same economic union:
    
    -   Intra-Community Sales
        
    -   Intra-Community Purchases
        

Note:

Intra-community sale and purchase transaction types are only available for nexuses in economic union member states.

After the SuiteTax Engine has determined tax transaction type, the SuiteTax Engine selects a tax code based on the following in priority order:

-   Tax codes set on entity records, see [Setting Up Entity Default Tax Codes and Tax Groups](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557736345.html).
    
-   Tax codes set in tax schedules, see [Setting Up Tax Schedules](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557736252.html).
    
-   Default tax codes in nexus preferences, see [Editing Default Tax Codes for Nexuses](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557736208.html).
