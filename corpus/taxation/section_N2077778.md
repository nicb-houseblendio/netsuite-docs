NetSuite sends you an email to let you know if your file was generated successfully or not.

#### If your tax audit file generation fails: {#procedure_N2077790}

1.  Go to Reports > Tax > Audit Files and find your data export.
    
2.  Review the parameters of your data export. For example, check if the date range is correct.
    
3.  Set the correct parameters and generate the file again.
    

If you're still getting an error, contact Support through your usual support channels for help.

You can delete the failed data export file to remove it from the list.
