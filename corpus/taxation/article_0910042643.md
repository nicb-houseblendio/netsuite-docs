You can update existing entity tax registrations, such as changing a tax registration number, using CSV import.

#### To edit an existing entity tax registration as CSV:

1.  Use a saved search or SuiteAnalytics to identify the **ID** of the registration line you want to update.
    
2.  Prepare your CSV file. Include these fields:
    
    1.  **Internal ID** of the tax registration line
        
    2.  **ID** of the tax registration line
        
    3.  The fields you want to update (for example, **Tax Registration Number**)
        
3.  Go to Setup > Import/Export > Import CSV Records.
    
4.  In the **Import Type** field, select **Relationships**.
    
5.  In the **Record Type** field, select **Customer** or **Vendor**.
    
6.  Set **Data Handling** to **Update** and enable **Run Server SuiteScript and trigger WorkFlows** under **Advanced Options**.
    
7.  Map **Internal ID**, **ID**, and the fields you want to update.
    
8.  Complete the import process.
    

Note:

In SuiteTax, if you edit a tax registration that has already been used in a transaction, NetSuite will create a new registration record and set the old one to inactive. This preserves transaction history and applies changes prospectively.
