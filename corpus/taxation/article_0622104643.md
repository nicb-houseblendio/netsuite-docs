Important:

One Stop Shop is available only in SuiteTax accounts with OneWorld feature enabled.

This topic describes the OSS setup for accounts with the SuiteTax feature enabled. For accounts without SuiteTax, see [OSS Feature Setup For Accounts Without SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_162919108719.html).

Before setting up OSS in SuiteTax, review OSS setup permissions. For more information, see [One Stop Shop (OSS) Permission](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163490166033.html).

To set up OSS in the SuiteTax Engine, see the following help topics:

-   [Prerequisites for One Stop Shop (OSS) in SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163107839465.html)
    
-   [Setting Up One Stop Shop (OSS) in the SuiteTax Engine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163107865476.html)
    
-   [Tax Code Provisioning in One Stop Shop (OSS)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163107998132.html)
    

Before you can generate OSS reports, you must install all required SuiteApps.

## Required SuiteApps {#bridgehead_052910555010}

| SuiteApp | Installation Steps |
| --- | --- |
| Tax Reporting Framework | [Installing Tax Reporting Framework](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1528245293.html) |
| SuiteTax Engine | [Installing the SuiteTax Engine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557397007.html) |

After the SuiteApps have been installed, you can install the One Stop Shop SuiteApp.

#### To install One Stop Shop SuiteApp:

1.  Go to **SuiteApps**.
    
2.  In the search bar, enter **One Stop Shop**.
    
3.  Click the One Stop Shop image.
    
4.  Click **Install**.
    
5.  In the dialog window, click **Install**. The process may take a few minutes to finish.
    

To learn more about how SuiteTax identifies and evaluates OSS transactions, see the following help topics:

-   [Tax Details for OSS on Transactions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163107799087.html)
    
-   [One Stop Shop (OSS) for SuiteTax Lookup Logic](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163455899497.html)
