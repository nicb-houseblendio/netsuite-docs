One Stop Shop SuiteApp has the following known limitations:

-   Generating OSS VAT returns using the One Stop Shop SuiteApp only applies to OSS transactions processed from July 1, 2021 onwards. This is because the implementation of EU One Stop Shop starts on July 1, 2021.
    
-   Import OSS Scheme only applies to goods valued at less than EUR 150. However, One Stop Shop in accounts without SuiteTax does not validate if the goods are valued at less than EUR 150. If you have Import Scheme enabled, any goods coming from a non-EU country with an applied OSS tax code are reported in the Import OSS VAT return.
    
-   In the current version, OSS feature for accounts without SuiteTax does not support Northern Ireland as a Country of Consumption. Therefore, Import OSS report does not include goods from a non-EU country to Northern Ireland.
    
-   The following are the known limitations of the OSS Item Type Reporting Fields in accounts without SuiteTax:
    
    -   Ship Item type is always defined as Goods if the **MOSS Applies** box is checked.
        
    -   Subscription Plan, Download Item and Expense item types do not support this feature. These item types are also considered as non-OSS item types.
        

-   In the current version, Tax Reporting Framework does not support **Part 3: For each Member State of consumption for which a VAT correction is made** and **Part 4: Balance of VAT due for each Member State of consumption** sections of the Import OSS and Non-Union OSS reports. Net and tax amounts related to Credit Memo and Cash Refund transaction types are deducted based on the applicable tax codes.
    

-   One Stop Shop does not currently support MBA reporting of OSS reports.
    
-   In the current version, amounts appear in the subsidiary's or company's base currency.
    
-   One Stop Shop is supported in OneWorld accounts only.
    
-   The following are the supported transaction types:
    
    -   Cash Sale
        
    -   Invoice
        
    -   Credit Memo
        
    -   Cash Refund
        
    -   Return Authorization
