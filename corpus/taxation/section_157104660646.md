Note:

This topic is for NetSuite accounts that use the Country Tax Report page to generate the Intrastat Supplementary Declaration for Dispatches and Arrival reports. If you are using the EU Intrastat Report page, see [Nature of Transaction Code](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2070738.html).

The Nature of Transaction Code (NOTC) indicates the type of transaction being declared in the Intrastat report.

When you choose an EU vendor or customer on a transaction form, the Tax Reporting subtab displays the **NOTC** field. You must fill in this field for it to be included on the Intrastat report.

The Intrastat Arrivals and Dispatches reports display the NOTC according to the country where you must file an Intrastat report.

-   [Belgium Transaction Code](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157538424588.html#subsect_157164633946)
