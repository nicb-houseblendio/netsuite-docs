Some items in the US are taxed differently from the general product. One of the typical exceptions is the reduced tax for certain items.

## Creating a New Item Tax Exception Setup Rule for the United States {#subsect_0711033515}

To set up the US item tax exception rules, see the following steps.

Note:

Created nontaxability rules and relevant exemption certificates or entity default tax codes have priority over item tax exception setup rules. For more information, see [United States Tax Code Lookup for Sales](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0801101253.html) and [United States Tax Code Lookup for Purchases](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0801101608.html).

#### To create a new US item taxability setup:

1.  Go to Setup > SuiteTax Engine > US Item Taxability Setup.
    
2.  Fill in the name of your item tax exception rule.
    
3.  Then, select a nexus from the **Nexus** list to be able to be able to add items to the rule.
    
4.  In the **Type of Exception** field, you can only see the "**State-Wide Exception**" value.
    
    Note:
    
    The **Type of Exception** field is prefilled and disabled because we're currently supporting only state-wide exceptions.
    
5.  With the state-wide exception type preselected, you can select tax code(s) applicable to this rule. These tax codes are automatically applied to all the items for the selected nexus.
    
6.  In the Items section, you can add individual items by:
    
    -   using an item saved search
        
    -   copying items from a different setup rule
        
    -   choosing specific items manually from the list.
        
    
    Note:
    
    To save the record, there must be at least one item on the list. Duplicates are not allowed. If the item you are adding is already included in a different rule for the same nexus, with the same or overlapping validity period, we consider it a duplicate.
    
    Note:
    
    Don't exceed the limit of 85000 items when adding items in bulk (by the saved search or by copying them from another setup rule).
    
7.  To specify the validity of your US Item Taxability Setup rule, you can do one of the following:
    
    -   fill in the validity dates manually, when adding individual items or editing already added items
        
    -   fill in the validity dates manually, when adding individual items or editing already added items
        
    -   check the **Validity Dates** box and fill in the validity dates for all the items you enter manually, add by a saved search, or copy from another setup rule.
        
    
    Note:
    
    The validity dates must be in the chronological order. The **Valid From** date should be before the **Valid Until** date if both dates are filled in.
    

The permission for the US Item Taxability Setup is based on the permission for the non-taxability setup. For more information about setting up SuiteTax Engine permissions, see [SuiteTax Engine Permissions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557734578.html).
