The SuiteTax Engine supports the validation of tax registration numbers for customer and vendor entities in the European Union. For EU entities, the validation is processed using the European Union's VAT Information Exchange System (VIES). The validation requests are handled by the VIESAPI, which is a private provider. For more information, see [Setting Up Entity Default Tax Codes and Tax Groups](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557736345.html)).

Note:

The validation results depend entirely on the VIES.

If a tax registration number is valid and in the correct format (see [Defining a Tax Registration Number Format](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557742714.html#subsect_157183377854) and [Countries With a Pre-Defined Tax Registration Number Validation Format](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557742766.html)), the following will occur:

-   The **Validation Result** field displays a 'Tax reg. number is valid' message.
    
-   The **Name** and **Address from Validation** fields display data from VIES.
    
-   The **Consultation Number** field displays a unique query identifier generated by the VIES system.
    
-   The **Date Stamp** field displays the date and time you last queried VIES for this entity.
    

If the Tax Registration Number is invalid, NetSuite displays a 'Tax reg. number isn't valid' message in the **Validation Result** field, and the time and date of the query in the **Date Stamp** field.

The query validates the tax registration number of an entity.
