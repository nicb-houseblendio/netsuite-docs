The following table describes the reported values on the Union One Stop Shop VAT Return in accounts without SuiteTax.

| Report Label | Details |
| --- | --- |
| **EU One Stop Shop VAT Return - Union Scheme** | Title of the report. |
| **Subsidiary** | Name of the selected subsidiary. |
| **Member State of Identification** | Nexus of the selected subsidiary. |
| **General Information** |  |
| VAT Registration number | The VAT Identification number supplied in the EU One Stop Shop preferences tab |
| Tax period | The format of the Tax Period is Mmm.YYYY. |
| Start date and end date of period | Includes the start date and end date of the tax period in the following format: dd.mm.yyyy - dd.mm.yyyy. |
| Currency | The 3 digit ISO country code of subsidiary or company's base currency. |
| **Report Label** |  | **Member State of Consumption** | **VAT** | **VAT rate type** | **From** | **Taxable amount** | **VAT amount** |
| **Details** | If the **Split by goods and services** toggle switch is on, Goods or Services displays in this box, depending on the type of item. | Name of the Member State of Consumption. | Percentage of the VAT rate. | Type of VAT rate. This can either be standard, reduced, or special reduced VAT rate type. | Two digit country code of the state the item is shipped from. | Taxable amount. | VAT amount. |
| **Total** | Total taxable amount for the country the item is shipped from. | Total VAT amount for the country the item is shipped from. |
| **Total supplies from outside Member State of Identification** | Total taxable amount for supplies from outside Member State of Identification displays here. This row appears only if the **Split by goods and services** toggle switch is on. | Total VAT amount for supplies from outside Member State of Identification displays here. This row appears only if the **Split by goods and services** toggle switch is on. |
| **Total (Member State of Consumption)** | Total taxable amount for Member State of Consumption displays here. | Total VAT amount for Member State of Consumption displays here. |
| **Total VAT amount due for all Member states** | Taxable amount of total VAT amount due for all Member states displays here. | VAT amount of total VAT amount due for all Member states displays here. |
