When you enable the SuiteTax feature, the subsidiary and entity tax registration numbers are assigned to the legacy transaction and tax details are generated. The GL impact is preserved. For more information, see [Transactions in SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4797202760.html).

SuiteTax adds the time item line and detail item line to the **Tax Details Reference**. This happens when you edit migrated transactions with combined time items or detail items or both. This lets you save any edits made on your migrated transaction. When editing a migrated transaction, follow these steps to successfully save your edits:

| Details | Preference | Action Required |
| --- | --- | --- |
| Invoice with Billable Time | Combine Time Items on Invoices is "True". | To retain the existing taxes on the transaction, use **Tax Details Override**.
-   Go to the **Tax Details** subtab.
-   Check the **Tax Details Override** box.
-   Assign the **Tax Details Reference** to each tax line.
-   Select "**Save**".

**Preview Tax** may be used to retrigger the tax calculation. Note that using this option may result in a different tax calculation result. |
| Expense Report with Line Items from the Same Expense Category | Combine Detail Items on Expense Reports is "True". | 

-   Go to the **Tax Details** subtab.
-   Check the **Tax Details Override** box.
-   Assign the **Tax Details Reference** to each tax line.
-   Select "**Save**".

 |
| Invoice with Expense Items | Combine Expense Items on Invoices is "True". | To retain the existing taxes on the transaction, use **Tax Details Override**.

-   Go to the **Tax Details** subtab.
-   Check the **Tax Details Override** box.
-   Assign the **Tax Details Reference** to each tax line.
-   Select "**Save**".

**Preview Tax** may be used to retrigger the tax calculation. Note that using this option may result in a different tax calculation result. |
| Invoice with Billable Items | Combine Billable Items on Invoices is "True". | To retain the existing taxes on the transaction, use **Tax Details Override**.
