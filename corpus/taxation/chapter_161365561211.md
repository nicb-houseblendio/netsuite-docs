SuiteTax is a non-reversible feature and when enabled, it can't be disabled. Be sure to review any incompatible features before implementing SuiteTax in your account.

The tables below list incompatible bundles/SuiteApps and the equivalent SuiteApps available for use with SuiteTax.

Also check the table 'Tax Functionalities/Use Cases' for what the NetSuite SuiteTax Engine doesn't support yet.

| **PRODUCT NAME** | **ADDITIONAL INFORMATION** |
| --- | --- |
| NetSuite CRM | No plans to support this |
| NetSuite CRM+ | No plans to support this |
| NetSuite JCurve | No plans to support this |
| NetSuite Small Business | No plans to support this |

| --- | --- |
| Advanced Promotions | This feature is being deprecated, and customers will need to migrate to SuitePromotions. |
|  |  |

| Web Site | You can only enable SuiteTax if Site Builder websites are inactive, or their Web Site Scope is set to 'Information and Catalog' or 'Information Only.' For all other Web Site Scopes, SiteBuilder isn't supported with SuiteTax. For more information about the Web Site Scope setting on the Website Setup record, see [Multi-Site Settings](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2562624.html#bridgehead_N2563304). |

The following tax functionalities and use cases aren't yet supported by the NetSuite SuiteTax Engine yet, but SuiteTax partners may offer solutions.

| **TAX FUNCTIONALITIES/USE CASES** | **ADDITIONAL INFORMATION** |
| --- | --- |
| Cash Basis Tax Reporting | No workaround available |
| Partially deductible VAT and reverse charge on partially deductible purchases | See the [NetSuite SuiteTax Engine Setup Guide](https://system.netsuite.com/app/help/helpcenter.nl?fid=NetSuiteSuiteTaxEngineSetupGuide.pdf) and [Partially Deductible and Non-deductible Taxes in SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0610121020.html) for more information. |
| Tax Periods | SuiteTax doesn't support Tax Periods, but we've added the Tax Point Date field instead, which you can enable Tax Point Date at the Nexus level. Tax reports use this date field. |
|  |  |
|  |  |
| Withholding Tax on Payments | The SuiteTax Engine doesn't support Withholding Tax on Payments. |
