The System Notes tab of the VAT form stores a copy of each exported file and a PDF of the submitted or final VAT return. You can download the exported file and print a copy of the submitted or final VAT form.

The submission history shows the following:

-   Date - Date of VAT return generation
    
-   User - Name of the user who generated the VAT return
    
-   Date From - Submitted period start date
    
-   Date To - Submitted period end date
    
-   Status link (available for the U.K. only) - Indicates the status of the submission (success or failure), and opens the VAT Online Submitted Periods record.
    
-   Type (available for the Czechia and Ireland only) - Indicates whether the file is an original (the first submission for the period), an amendment (correction), or an additional (supplementary) return.
    
-   File Name link (not available for U.K.) - Downloads the CSV, XML, or DAT file of the submitted VAT return for the period. The file name differentiates reports for flagged and unflagged tax periods. Reports with flagged tax periods have 'Final' in the file name. Reports where you chose to not flag the tax period have 'Draft' in the file name.
    
-   View & Print link (available for submitted/final reports only) - Opens a copy of the VAT form containing the submitted or final values for the period.
    
-   Accounting Book (available if Multi-Book Accounting feature is enabled) - Shows the accounting book used to generate the report.
    

#### To download a copy of the exported file:

1.  Click the file name of the report.
    
2.  On the download window, choose **Save** to download the file to your computer.
    

Note:

The file name tells you if a report is for a flagged or unflagged tax period. Flagged periods have **Final** in the file name, when unflagged reports have **Draft** in the file name. For more information about flagging tax periods, see [Flagging Tax Periods in a VAT Return](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3721526384.html).

#### To print a PDF and view details of the VAT report:

1.  Click the **View & Print** link of the report.
    
2.  To view details of the VAT return, click the amounts in the fields or boxes. The system opens the Detailed Report that contains a list of transactions.
    
    Note:
    
    The International Tax Reports SuiteApp can only support one million characters of long text or about 5000 transaction lines for sales or purchases. If that limit is reached, you won't be able to view the transaction details of the report.
    
3.  To print a copy of the VAT return, click **Print**.
    

Note:

The header of the printed form has a **Submitted** stamp for UK or **Final** stamp for other countries. The footer shows who generated the final report, and the time and date it was created.
