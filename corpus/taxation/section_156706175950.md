Tax Reporting Framework has the following limitations:

-   Period End Journal Support for Tax Audit Files: The Income Summary Journal closing entry of the 3030 Retained Earning account is not yet included as a report filter.
    
-   The **Report Execution Log** subtab in the Country Tax Report page has a limit of 4000 entries.
    
    Note:
    
    If this limit is reached, contact NetSuite Customer Support for assistance.
    
-   In accounts with SuiteTax:
    
    -   Tax Reporting Framework has similar limitations with SuiteTax and the assigned tax engine. For more information, see [Known Limitations of SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_161365561211.html).
        
    -   Tax Reporting Framework does not support reporting of tax groups.
        
    
    -   Generating VAT reports using adjustment-only accounting books in Tax Reporting Framework is not supported.
        
    -   Generating tax reports in accounts with SuiteTax that include data from accounts without SuiteTax or old tax codes is not supported.
        
-   In accounts without SuiteTax:
    
    -   There is no access to the Tax Return Setup page.
        
    -   Adjust Tax Return and VAT Group Reporting features are only applicable for the primary accounting book.
        
    -   Tax Reporting Framework roles can be assigned in the **Tax Reporting Framework Roles** page. Assigning the Tax Return Setup permission to a role does not have an effect in accounts without SuiteTax.
