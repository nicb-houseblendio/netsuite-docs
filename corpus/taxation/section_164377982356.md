The Partner ID is the client's VAT number. It should be the VAT number of the party receiving the goods in the European Union (EU) country of destination.

The Partner ID field appears on the **Tax Reporting** and **Items** subtabs on sales transactions between EU countries. When you generate the Intrastat report, the system looks for this value in the item line. You can assign a different Partner ID for every item line.

If nothing's entered on the **Items** subtab, the system looks at the **Partner ID** field on the **Tax Reporting** subtab. If you enter the Partner ID value on the **Tax Reporting** subtab, it gets assigned to all items on the **Items** subtab.

If the **Partner ID** field is blank on both subtabs, the Intrastat Dispatch report uses the **Tax Registration Number** from the customer record if it's valid.

Note:

A valid Partner ID is alphanumeric, with 4 to 14 characters, and starts with the 2-letter alpha code for the member state. See [Alpha Codes of EU Member States](#subsect_164378002580) for more information. For example, a valid Partner ID is **LT123456789123**.
