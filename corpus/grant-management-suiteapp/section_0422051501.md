This section includes the prerequisites and instructions for installing the Grant Management SuiteApp.

## Prerequisites {#subsect_0422051543}

The Grant Management SuiteApp is developed and tested for use primarily with NetSuite OneWorld. For more information about NetSuite OneWorld, see [Introduction to NetSuite OneWorld](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N266468.html).

Using an Administrator role, enable the following features by going to Setup > Company > Enable Features.

| Subtab | Section | Feature |
| --- | --- | --- |
| Accounting | Basic Features | Accounting |
| Employees | Time & Expenses | Expense Reports |
| Time Tracking |
| CRM | Sales | Opportunities |
| SuiteCloud | SuiteBuilder | Custom Records |
| SuiteScript | Client SuiteScript |
| Server SuiteScript |
| SuiteGL | Custom Segments |
| Custom Transactions |

## Installation {#subsect_0422051750}

Any role with access to the SuiteApp Marketplace in NetSuite can install the Grant Management SuiteApp. For more information about the SuiteApp Marketplace, see [SuiteApp Marketplace in NetSuite](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1539797981.html).

#### To install the Grant Management SuiteApp:

1.  Go to the **SuiteApps** tab.
    
2.  In the **Search Apps** field, enter **Grant Management SuiteApp**.
    
3.  Click the **Grant Management** tile.
    
4.  On the top right area of the Grant Management SuiteApp details page, click **Install**.
    

For more information about installing a SuiteApp from the SuiteApp Marketplace, see [Installing from the SuiteApp Marketplace](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1539799323.html).

The Grant Management SuiteApp is a managed SuiteApp and is automatically updated whenever there are enhancements or new features added.
