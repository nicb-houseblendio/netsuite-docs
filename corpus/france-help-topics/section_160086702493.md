The reports in Country-Specific Reports framework are locked. To change a specification of the report, for example, to accommodate your specific company requirements, you must create a copy of the report.

#### To modify a france report:

1.  Go to Reports > France Reports > Country-Specific Reports.
    
2.  In the Report field, select the France report that you want modify.
    
3.  Click **Show Report**.
    
4.  On the CSR - Report page, click **Copy Full Report**.
    
5.  Make the necessary adjustments. Make sure the Report name isn't the same as the default locked report's name.
    
6.  Click **Save**.
    

If, however, you're customizing a variable of the Country-Specific Reports SuiteApp (CSR), you don't have to make a copy of the report. You can edit the CSR variable directly.

#### To edit a CSR variable:

1.  Go to _Customization > Lists, Records, & Fields > Record Types_.
    
2.  Find the row of **CSR-Variable**, and click **List**.
    
3.  Find the variable you want to edit.
    
    You can sort by Cell ID or Name of the variable.
    
4.  Click **Edit**.
    
5.  On the Sum of Values subtab, you can add or remove a value computation line.
    
    For example, in the FrenchBS\_DI variable, you can add a line with a math method of **Add** and value type of **Variable**. In the Value Perimeter column, you can enter an account prefix, for example **12\***. Then, in the Credit/Debit/Net column, you can select **Net Amount**.
    
6.  Click **Save**.
