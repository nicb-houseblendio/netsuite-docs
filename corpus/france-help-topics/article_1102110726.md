The following table defines the terms used in NetSuite to support businesses in France.

| Term | Definition |
| --- | --- |
| Applying transactions (Lettrage) | If you're using the France Localization SuiteApp, applying transactions, for example applying a customer payment to an invoice, is a method to reconcile transactions (also known as match transactions). For information about applying transactions for reconciliation, see [Best Practice for Applying Transactions for Lettrage](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160085908153.html). |
| FEC | This acronym stands for Fichier d'Ecritures Comptables, the tax audit file required in France. |
| France CSR Reports | These are financial reports required in France that are built using the Country-Specific Reports SuiteApp. For information about the France CSR reports provided by the France Localization SuiteApp, see [France Reports in Country-Specific Reports Framework](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156388724912.html#subsect_160034331797). The France Localization SuiteApp provides CSR reports because it enables more granularity in financial reporting. |
| PCG | This acronym stands for Plan Comptable Général, the generally accepted accounting principles in France. To make your NetSuite account compliant with the PCG, see [Configuring NetSuite Accounts for Plan Comptable Général Compliance](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159843313396.html). |
| Matching code | This is a numeric code the France Localization SuiteApp assigns to a group of debiting and crediting transactions that have been fully reconciled (that means, the matching status is Fully Matched). This means the total balance of this group equals to zero. |
| Matching status | This refers to the status of the reconciliation process. Fully matched means the total balance of a group of debiting and crediting transactions equals to zero. |
| Unmatched transactions | Unmatched transactions are debiting and crediting transactions that haven't yet been reconciled. |
