You can manage the installation or update of France Localization components using the France Localization Overview page.

The page shows which prerequisite SuiteApps you need to install, reinstall, or update for France Localization to work. It also reminds you to manage the layouts of your financial reports so that they comply with the French accounting laws.

To view the France Localization Overview, go to Setup > France Localization > France Localization Overview.

Check the Status column to know the current state of the component, and the Action column where you can address any problem indicated by the status. The following statuses require your action:

-   **Not Installed** - The component hasn't been installed yet. If the component is needed in your account, click **Install** in the Action column. With some components, such as the France FEC Files, a prerequisite SuiteApp must be installed. Click **Install** for details about the prerequisites.
    
-   **Update Required** - An update is required to register and import the components from other SuiteApps to the France Localization SuiteApp. This status appears if you installed Tax Reporting Framework SuiteApp, Electronic Bank Payments SuiteApp, and Country-Specific Reports SuiteApp. By clicking **Update,** the France Localization SuiteApp will be updated with the newly imported components from other prerequisite SuiteApps.
    
-   **Error** - The status appears if the component hasn't been installed properly. Click the Error link for more detailed information about the error. Based on the recommendation in the information, click **Uninstall** or **Update** in the Action column.
    
-   **Layout Required** - Some financial reports need to be assigned a row layout that conform to accounting guidelines in France. To set the correct layout, click **Get Layout**. You'll be redirected to the Row Layouts Assignment page where you manually change the layouts. For more information, see [Getting a France Financial Report Layout](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160034165510.html).
