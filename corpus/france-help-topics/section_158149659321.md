Important:

This topic pertains to the France FEC files generation feature, which is no longer supported as of Tax Audit File SuiteApp version 1.85.0. You can only use this SuiteApp to generate France FEC files from 2022 and earlier. To generate this report, see [Fichier d'Ecritures Comptables (FEC) in France Localization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1539840650.html).

## Tax Audit Files Configuration for the FEC Report {#bridgehead_4817007863}

The Tax Audit Files Configuration record provides you additional options to customize the generated FEC report. To access the Tax Audit Files Configuration, go to Customization > Lists, Records, & Fields > Record Types. Look for **Tax Audit Files Configuration** and click its corresponding **List** link.

-   To use customer or vendor ID for the CompAuxNum and CompAuxLib columns of the France FEC report, edit the custom record for **FR\_SAFT\_TXT** with the key, **UseSubAccount**. Specify values for the following fields:
    
    -   **Subsidiary** - Select a subsidiary.
        
    -   **Value** - Set the value to **T** (true).
        
-   To exclude opening balances, edit the custom record **FR\_SAFT\_TXT** with the key, **IncludeOpeningBalance**. Specify values for the following fields:
    
    -   **Subsidiary** - Select a subsidiary.
        
    -   **Value** - Set the value to **F** (false).
        
-   To exclude closing balances, edit the custom record **FR\_SAFT\_TXT** with the key, **IncludeClosingBalance**. Specify values for the following fields:
    
    -   **Subsidiary** - Select a subsidiary.
        
    -   **Value** - Set the value to **F** (false).
        

You can generate audit files using the Tax Audit Files SuiteApp. For steps to generate tax audit files, see [Generating a Tax Audit File](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2077452.html).

Note:

France FEC report is available to NetSuite accounts with the France nexus.
