The French translations that you enter on the France Localization Configuration page are used for the JournalLib and for generating the EcritureLib on the custom transactions. For the translations to be applied in generating the EcritureLib, you need to deploy a script.

#### To deploy the script: {#procedure_1005123049}

1.  On the Custom Transaction Translations subtab, click the link to the script. Alternatively, go to Customization > Scripting > Scripts, and click **View** next to **FL UE FEC EcritureLib** (ID: customscript\_fl\_ue\_fec\_ecriturelib).
    
2.  Click **Deploy Script**.
    
3.  From the **Applies to** list, select the custom transaction or transactions where you want the French translations to take effect.
    
4.  Update the following fields:
    
    1.  In **Status**, select **Released**.
        
    2.  In **Log****Level**, select **Error**.
        
    3.  In **Execute as Role**, select **Administrator**.
        
5.  Go to the Audience subtab, and next to **Roles**, check the **Select All** box.
    
6.  Click **Save**.
    

Note:

Whenever you add a new custom transaction type and its French translation to the list, you need to deploy the script for this new custom transaction.
