This section contains details of the following reports, which are built using the Country-Specific Reports SuiteApp:

-   [France Balance Sheet](#subsect_160103458034)
    
-   [France Income Statement](#subsect_160103487416)
    
-   [France SIG](#subsect_160136787300) (Soldes intermédiaries de gestion)
    

Specifically, it shows from which account (indicated by account number prefix and account description) each item in the report is sourced.

Note:

For previous versions of the CSR reports, that were used before 2025, see [France Reports (CSR) (Pre 2025) Details](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_83170535237.html)

## France Balance Sheet {#subsect_160103458034}

This report refers to the Balance Sheet (Bilan) report created in the Country-Specific Reports framework. To access this report, go to Reports > France Reports > Country-Specific Reports. For more information, see [France Reports in Country-Specific Reports Framework](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156388724912.html#subsect_160034331797).

Note:

If you're using manual journal entries to close your Profit or Loss accounts at the end of the Fiscal Year, you have to move your accounts with prefix 12 from the **Retained Earnings Previous FY** variable (Cell ID: FrenchBS\_PLNA) to the **Financial period earnings (profit or loss)** variable (Cell ID: FrenchBS\_DI).
