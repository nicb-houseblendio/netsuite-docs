To use the Intrastat Reporting feature, the International Tax Reports SuiteApp must be installed in your NetSuite account. For more information, see [International Tax Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2051341.html).

#### To Generate the France Intrastat Report: {#procedure_157018548159}

1.  Go to Reports > VAT/GST > EU Intrastat Report.
    
2.  Select the France subsidiary.
    
3.  Select **Sale** (for Dispatches) or **Purchase** (for Arrivals) in the **Report Type** dropdown.
    
4.  Select a country form in the **Country Form** dropdown. For the France Intrastat Report you can choose among two languages: English and French.
    
5.  Select a reporting period by entering a **Tax Period** (from date) and a **To** (date). Intrastat reports are submitted monthly.
    
6.  In the **Accounting Book** field, select which accounting book will be used to generate the report. This field is available if the Multi-Book Accounting feature is enabled. The dropdown list shows all active books associated with the selected subsidiary. For more information, see [Multi-Book Accounting for International Tax Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4108426899.html).
    
7.  To display the report, click **Refresh**. Each time you change the reporting criteria, click **Refresh**.
    
    Transaction lines with the same values of Commodity Code, Member State, NOTC, Region of Origin, Mode of Transport, Incoterm, Country of Origin, and Counterparty VAT number are consolidated and declared as one transaction. For consolidated transactions, Net Mass, Value in Euro, and Supplementary Unit columns are added.
    
    Important:
    
    For the saved reports in the International Tax Reporting SuiteApp, results are limited to 25,000 rows. A truncated report will display this note at the bottom of the page: 'The results of this report are too large. Please narrow your results.' If you want to request for an increase in the limit, you must file a Support case.
    
8.  Review the report displayed. Be sure to review all pages of the report. To specify the number of rows displayed on each page, go to the **General** subtab in _Home > Set Preferences_. Columns displayed vary depending on the country form selected. For some country forms, you can click the customer names to view the customer records, or click the **Reference No**. to view transaction records.
    
9.  Check the **Exclude** box for each transaction that you want to omit from your report. You can also click **Mark All** or **Unmark All**.
    
    Important:
    
    You should review all the values in the report prior to submission.
    
10.  To save the report, click any of the following options:
     
     -   **Print** - to generate a PDF version of the report that you can print or save for your own records. Lines with the Exclude box checked aren't included in the PDF.
         
     -   **Export to Excel** - to save the Intrastat report as a Microsoft Excel (.xls) file. Lines with the Exclude box checked aren't included in the .xls file.
