Note:

This topic is for NetSuite accounts that use the Country Tax Report page to generate the France VAT report. If you're using the Tax Reports (International) page, see [What goes into each box - France VAT report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1892495.html).

Note:

From 2024 onwards, use the report [Periodic VAT Return CA3 - 2024](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_101109421610.html). The Periodic VAT Return CA3 report should be used only for years prior to 2024.

With the Tax Reporting Framework SuiteApp installed with France Localization SuiteApp, you can generate the France Periodic VAT Return CA3. To generate the VAT report, see [Generating the France FEC and SuiteTax-Based Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163058970280.html). This report can be exported to PDF. To export a report, see [Exporting a Country Tax Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_156645000208.html).

The following tables describe the reported values on the France VAT report. It also shows the Search Type, Transaction Types, Tax Codes, Tax Transaction Types, and Tax Item Types filters that Tax Reporting Framework uses to get the values for each of the boxes on the report. These filters are automatically set up but can be modified. If you want to customize the report and configure the filters, see [Customizing Localized Tax Returns](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1528248236.html).
