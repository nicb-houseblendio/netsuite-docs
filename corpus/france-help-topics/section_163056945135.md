To download the Chart of Accounts template, go to Setup > France Localization > France Chart of Accounts. Follow the steps indicated on the installation page.

You can modify or keep the default list of accounts in the template. You can add subaccounts needed by your company or remove accounts that aren't applicable to your business.

You can edit the list of accounts, external IDs, and other relevant information directly into the provided template.

When editing the template, adhere to the following guidelines:

-   For Bank account types, you must assign the currency and the subsidiary of the bank account. Only one currency and one subsidiary should be selected per account. You need to create one account for each of your bank accounts.
    
-   You must enter complete names for the subsidiaries. If you want to refer to a child subsidiary, the complete hierarchy must be provided in the following format: Parent Subsidiary Name: Child Subsidiary Name. Alternatively, you can use the External ID.
    
-   If you edit the external ID, also edit the external ID of the parent account in the **Subaccount of (External ID)** column. This only applies if you're using the parent-child hierarchy of the accounts.
    
-   If the Chart of Accounts is shared by all subsidiaries, you must define the parent subsidiary in the Subsidiary field. Enter **Yes** in the Include Children column.
    
-   Delete the notes on top of the column headings before saving the file.
    

To import, click **Saved CSV Imports - Chart of Accounts under Step 3 of the installation page**. Click the **France Chart of Accounts**. Follow the steps of the CSV Import Assistant. For more information, see [CSV Imports Guide](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_162020066497.html).

The France Localization SuiteApp provides the **France Chart of Accounts** Saved CSV Import. You don't have to do the mapping in the CSV Import Assistant.

In importing the file, make sure that it's importing using the external IDs and not the names. For example, if you're trying to map Subaccount of (External ID), be sure to keep the external ID. Edit as necessary.

After the CSV file has been imported, go to Setup > Accounting > Manage G/L > Chart of Accounts to see your imported France accounts.
