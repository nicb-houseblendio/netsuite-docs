The France Fichier d'Ecritures Comptables (FEC) is an audit file system mandated by the France tax authorities. In France, tax paying companies are required to submit an audit report in the prescribed electronic format in case of a tax audit.

The France Localization SuiteApp provides the following FEC files:

-   [France FEC Data Extract](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163058205041.html)
    
-   [France FEC Lettrage Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163058213722.html)
    

You can generate these reports on the Country Tax Report page with or without the SuiteTax feature. You'll receive an email every time you try to generate the FEC reports.

For information about setting up the FEC file, see [Prerequisites for Generating the France FEC Files](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163057160474.html).

Note:

Please note of the following important aspects of the FEC reports:

-   Starting from December 7, 2021, the following file name formats are applied to the FEC reports:
    
    -   FEC Data Extract - Your company's SIREN, **FEC**, and the last day of the Fiscal Year in YYYYMMDD format.
        
    -   FEC Lettrage Report - Your company's SIREN, **FEC**, the last day of the Fiscal Year in YYYYMMDD format, and **\_lettrage**.
        
-   Owing to the changes in file name formats from December 7, 2021, FEC files generated before this date will no longer be accessible. You'll have to generate those files again.
