Usually, the EcritureLib field is set by a script described in the [Deploying a Script to Apply French Translations of Custom Transactions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1005122740.html). However, if the script was not deployed or the France Localization SuiteApp was not installed at all, some transactions may be missing the EcritureLib. The mass update enables you to correct this by updating multiple transactions at the same time.

Tip:

You can use this mass update script if you'd like to realign the EcritureLib field values from previous transactions to the latest version.

#### To deploy the scripts: {#procedure_40203408503}

1.  Go to Lists > Mass Update > Mass Updates > Custom Updates > Invoice, and click **EcritureLib value Recalculation**.
    
2.  Filter transactions without the EcritureLib.
    
3.  Click **Preview**.
    
4.  Click **Perform Update**.
    
5.  Click **Refresh** when available.
    

Note:

If there are a large number of transactions, apply filters (such as Limit Subsidiary or Date Range) to reduce the number of transactions included in the Mass Update.
