Set up the bank account records of each partner to whom you'll send electronic bank payments. You can set up multiple bank accounts for each partner.

#### To set up partner bank details in France: {#procedure_3851204788}

1.  Go to _Lists > Relationships > Partners_.
    
    For information about adding a partner, see [Creating a Partner Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1166599.html).
    
2.  Click **Edit** next to the name of the partner.
    
3.  On the **Bank Payment Details** subtab, check the **EFT Bill Payment** box.
    
4.  Click **Save**.
    
5.  Click **New Bank Details**.
    
6.  In the Payment File Format field, select your preferred France format.
    
7.  Fill-in the required fields depending on the EFT format you selected.
    
    For more information, see [France Entity Bank Details](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160042663023.html).
    
8.  Click **Save**.
    

You can also set up bank records of partners by importing bank details in CSV format into NetSuite using the Import Assistant. For more information, see [Importing Electronic Bank Payments Data](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3739634016.html). For information about the required fields for import, see [France Entity Bank Details](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160042663023.html).
