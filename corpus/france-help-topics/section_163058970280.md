You can generate the France Fichier d'Écritures Comptables (FEC) and the SuiteTax-based tax reports that are provided by the France Localization SuiteApp on the Country Tax Report page. The Tax Reporting Framework SuiteApp is required to have access to the Country Tax Report page.

Note:

The FEC files can be generated on the Country Tax Report page with or without the SuiteTax feature enabled in your NetSuite account.

#### To generate the France FEC and SuiteTax-based reports: {#procedure_158642443997}

1.  Go to Reports > Tax > Country Tax Reports.
    
2.  Select a France subsidiary from the Subsidiary dropdown list. This automatically fills the Nexus field with a France nexus.
    
3.  If a Confirm Preferences window appears, verify the tax reporting preferences. If the preferences are correct, click **Confirm**.
    
    For more information, see [Setting Up Country Tax Reporting Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_1557127083.html) and [Including Period End Journals in France FEC](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163057260404.html).
    
4.  In the Report Name field, select the France tax report that you want to generate. The Report Name field only shows tax report templates that are associated with the indicated nexus.
    
5.  If you have the Full Multi-Book Accounting feature enabled in your NetSuite account, select the accounting book whose transactions will be included in the FEC reports.
    
    For example, **Adjustment Primary** means Primary Accounting Book, and Adjustment-Only Book.
    
6.  _(Optional for generating FEC files)_ From the Accounting Context list, select the accounting context that you want to use in the FEC report.
    
    The selected accounting context is applied to the CompteNum and CompteLib fields of the FEC Data Extract and the FEC Lettrage Report. For more information, see [France FEC Data Extract](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163058205041.html).
    
    To see the accounting contexts that have been set up in your NetSuite account, go to Setup > Company > Preferences > General Preferences, then, go to the Accounting Contexts subtab.
    
7.  Enter a date in the Start Date and End Date fields.
    
8.  Click **Generate**.
    

For more information, see [Generating Localized Country Tax Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1528250223.html).
