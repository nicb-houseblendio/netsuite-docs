Perform the following actions before generating the Fichier d'Écritures Comptables (FEC) files:

1.  Install the Tax Reporting Framework SuiteApp. For more information, see [Installing Tax Reporting Framework](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1528245293.html).
    
2.  Go to Setup > France Localization > France Localization Overview to check if you need to update specific France Localization components. Check the status next to the France Localization SuiteApp. If the status says **Update Required**, then click **Update** under the Action column.
    
3.  Go to Setup > France Localization > Preferences. On the General Configuration subtab, check or clear the appropriate boxes depending on your preferred settings. On the FEC Configuration subtab, read the guidelines. The guidelines ensure that your FEC file is compliant with the tax laws in France.
    
    For more information about the settings on the Preferences page, see [Configuring France Localization SuiteApp Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163058267184.html).
    
    The FEC Configuration subtab also includes links to saved searches where you can check for inconsistencies in your transactional data. One of these saved searches, for example, is the **FEC Ecritures non validées** (FEC Nonvalidated Transactions). For more information, see [Saved Searches for FEC Compliance](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160041767095.html).
