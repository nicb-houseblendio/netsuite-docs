The France Localization SuiteApp provides the following tax reports specific to France:

-   **France SuiteTax-based reports** - For setup, see [SuiteTax-Based Reports Setup for France Localization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157562414065.html).
    
    -   [Periodic VAT Return CA3](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156775787841.html)
        
    -   [Periodic VAT Return CA3 - 2024](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_101109421610.html)
        
    -   [Declaration of Exchange of Goods (DEB)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159005773113.html)
        
    -   [European Services Declaration (DES)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159006531001.html)
        
-   **France VAT reports for cash basis and accruals** - These reports need configuration. For more information, see [Configuring France VAT Reports for Cash and Accruals Basis](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160041507132.html).
    
    -   **FR Achats par Code TVA - sur encaissement** (Purchase by Tax Code (Detail) - Cash Basis)
        
    -   **FR Achats par Code TVA - sur les débits** (Purchase by Tax Code (Detail) - Accruals)
        
    -   **FR Ventes par Code TVA - sur encaissement** (Sales by Tax Code (Detail) - Cash Basis)
        
    -   **FR Ventes par Code TVA - sur les débits** (Sales by Tax Code (Detail) -Accruals)
        
-   **France Fichier d'Ecritures Comptables (FEC)** - For setup, see [Prerequisites for Generating the France FEC Files](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163057160474.html).
    
    -   [France FEC Data Extract](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163058205041.html) - The audit report required by the tax authorities in France. This file can be generated with or without the SuiteTax feature enabled in your NetSuite account.
        
    -   [Draft FEC Data Extract](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_78151326078.html) - Internal-only version of the France FEC Data Extract report. This file can be generated with or without the SuiteTax feature enabled in your NetSuite account.
        
    -   [France FEC Lettrage Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163058213722.html) - This is a supplemental FEC report that shows matched transactions. This file can be generated with SuiteTax or without the SuiteTax feature enabled in your NetSuite account.
