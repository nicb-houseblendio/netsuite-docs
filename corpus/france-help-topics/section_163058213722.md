The FEC Lettrage Report provided by the France Localization SuiteApp is a supplemental FEC report that shows linked transactions (that means a transaction is applied to another transaction).

You can generate this report with or without the SuiteTax feature enabled in your NetSuite account. To generate this report, go to the Country Tax Reports page in Reports > Tax > Country Tax Reports.

Important:

Starting from December 7, 2021, the file name of the generated FEC Data Extract includes your company's SIREN and the last day of the Fiscal Year in YYYYMMDD format. Owing to this change, FEC files generated prior to this date will no longer be accessible. You'll have to generate those files again.

The FEC Lettrage Report is structured similarly to the FEC Data Extract except for the following information that's present only in the FEC Lettrage Report:

| Column Name | Description |
| --- | --- |
| **EcritureLet** | The code that indicates being linked |
| **TransactionLetType** | Transaction type (such as Invoice, Bill) |
| **TransactionLetNumber** | The document number, or, if not available, transaction number |
| **DebitLet or CreditLet** | For unapplied transactions, DebitLet or CreditLet column shows the unapplied amount of the transaction |
| **SearchField** | Contains the transaction names of the linked transactions. If a transaction hasn't been linked to another, then this field contains only one transaction name. |
| **DateLet** | The date when the transactions are linked. |

The transactions displayed in the report are filtered by the period range you defined in the **Start Date** and **End Date** fields on the Country Tax Report page. Transactions from before the Start Date are also included in the report if these are unapplied or applied to a transaction from a period before the End Date.

For an overview of the applied or unapplied transactions under your France subsidiary, you can view the Lettrage saved-search reports provided by the SuiteApp. For more information, see [France Lettrage Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156388724912.html#subsect_160034607941).

## Support for Currency Revaluation {#bridgehead_163610234059}

Currency revaluation is a system-generated transaction that records the impact to base currency valuation due to exchange rate fluctuations. For more information, see [Currency Revaluation Transactions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1550016096.html).

The France FEC Lettrage Report includes a currency revaluation transaction, which contains the difference in currency exchange rates among transactions. For example, a bill is issued on Day 1 with an X exchange rate. On Day 2, the bill is paid. Owing to exchange rate fluctuations, the bill payment takes a Y exchange rate. The Y and X difference in exchange rates automatically creates a currency revaluation transaction. This transaction is included in the FEC Lettrage Report.
