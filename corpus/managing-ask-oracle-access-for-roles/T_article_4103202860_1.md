Note:

This topic describes functionality available to users eligible for **NetSuite Next**. NetSuite Next is being made available to customers in phases, so these features may not yet be available in your account. You'll receive in-app notifications when your account is eligible for NetSuite Next.

Use the Ask Oracle Access page to control which roles can access Ask Oracle. Access is role-based. By default, roles do not have access.

Note:

Only users with the Administrator role can access the Ask Oracle Access page.

The Ask Oracle Access page lists eligible roles and shows whether each role has access to Ask Oracle. For each role, the page also shows the number of assigned users, the associated bundle ID, whether the role is custom or standard, and the center type. You can use the search field to filter the list by role name.

For information about how to set Ask Oracle access, see [Setting Ask Oracle Access](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/T_article_0804111020_1.html).
