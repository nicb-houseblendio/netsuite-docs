On the Online Donation HTML page, a donor can check the **Anonymous** box to submit online donation anonymously. After an anonymous donation is submitted, an invoice transaction is generated in NetSuite.

When setting up your anonymous online donations, keep in the mind the following tasks:

-   You must assign a default customer record to use on transactions created from anonymous online donations. For more information, see [Enabling Online Donations Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164794402409.html#subsect_164796158479).
    
    For more information on how to create a customer record in NetSuite, see [Creating a Customer Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161860867711.html).
    
-   All anonymous online donation transactions are created under one customer record.
    
-   To display the Anonymous checkbox on your Online Donation HTML page, you can do either of the following actions:
    
    -   Enable the Multi Subsidiary Customer feature. By enabling this feature, the Anonymous checkbox automatically becomes available on your Online Donation HTML file. For more information, see [Enable the Multi-Subsidiary Customer Feature](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1509460991.html).
        
    -   Modify the HTML code in your Online Donation HTML file to display the Anonymous checkbox. To learn how to work on your files in the File Cabinet, see [Editing Files in the File Cabinet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N542738.html).
        

## Submitting an Anonymous Donation {#subsect_164981640232}

The following procedure is for donors to submit anonymous donation on your website.

#### To submit an anonymous donation:

1.  On the Online Donation HTML page, the donor checks the **Anonymous** box.
    
2.  The donor provides the following details:
    
    1.  **(Optional) Name, Email, and Phone Number** - For anonymous donations, donors are not required to enter their Name, Email, and Phone Number details. This is because no new customer record is created in NetSuite when an anonymous donation is submitted. All anonymous donation transactions are automatically associated with the default customer record set on the General Preferences page.
        
        To assign a customer record for anonymous donations, see [Enabling Online Donations Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164794402409.html#subsect_164796158479).
        
    2.  **Donation** - Donor's preferred donation program.
        
    3.  **Amount** - The field dynamically displays the amount depending on the donation program or option you select. The donor can also enter a custom amount.
        
3.  The donor clicks **Donate Now**.
    
    The page redirects to the Payment Link payment page where the donor enters their payment details.
    
    The Payment Link page also displays a summary of the invoice created for the online donation.
    
4.  The donor clicks **Pay**.
