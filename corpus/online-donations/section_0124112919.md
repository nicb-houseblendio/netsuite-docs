You can set up saved searches to see transactions in the Online Donations SuiteApp.

Set up separate saved searches to view transactions created with the SuiteApp and those created without it.

## Viewing Transactions Created Using the Online Donations SuiteApp {#subsect_79233042674}

Here's how to create a saved search to view transactions made with the Online Donations SuiteApp.

#### To view transactions created using the Online Donations SuiteApp: {#procedure_0124113139}

1.  Go to Lists > Search > Saved Searches > New.
    
2.  On the New Saved Search page, click **Transaction**.
    
3.  In the **Search Title** field, enter the saved search name.
    
4.  Under the **Criteria** subtab, from the **Filter** list, select **Donation Setup ID (Custom Body)**.
    
    The Saved Transaction Search popup window opens.
    
    1.  From the Donation Setup ID dropdown, select **none of**.
        
    2.  From the list box, click **None**.
        
    3.  Click **Set**.
        
5.  From the **Filter** list, select **Main Line**.
    
    The Saved Transaction Search popup window opens.
    
    1.  From the **Main Line** selection, choose **Yes**.
        
    2.  Click **Set**.
        
6.  Click **Save**.
    

## Viewing Transactions Not Created Using the Online Donations SuiteApp {#subsect_9233633946}

The following procedure explains how to create a saved search to view transactions that were not made using the Online Donations SuiteApp.

#### To view transactions that were not created using the Online Donations SuiteApp: {#procedure_0124113735}

1.  Go to Lists > Search > Saved Searches > New.
    
2.  On the New Saved Search page, click **Transaction**.
    
3.  In the **Search Title** field, enter the saved search name.
    
4.  Under the **Criteria** subtab, from the **Filter** list, select **Donation Setup ID (Custom Body)**.
    
    The Saved Transaction Search popup window opens.
    
    1.  From the Donation Setup ID dropdown, select **any of**.
        
    2.  From the list box, click **None**.
        
    3.  Click **Set**.
        
5.  From the **Filter** list, select **Main Line**.
    
    The Saved Transaction Search popup window opens.
    
    1.  From the Main Line selection, choose **Yes**.
        
    2.  Click **Set**.
        
6.  Click **Save**.
    

For more information about adding a search filter, see [Advanced Search Criteria Filters](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N646477.html).
