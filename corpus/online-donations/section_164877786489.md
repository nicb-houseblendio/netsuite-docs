This workbook is based on the Online Donations Reporting dataset and displays information from the online donations generated in NetSuite.

## Online Donations Report Dataset {#subsect_164877873410}

The Online Donations Report workbook includes the following predefined criteria and fields. The dataset combines fields from several record types so you can retrieve and analyze data related to transactions generated through online donations.

| Root Record Type | Joined Record Type | Data Grid | Criteria Filters |
| --- | --- | --- | --- |
| Transaction | 
-   Address Book
-   Entity (Customer)
-   Donation Setup ID
-   Transaction Line

 | The following fields are included in the dataset: Transaction:

-   Currency
-   Date
-   Entity
-   Item

Transaction Line:

-   Amount (Transaction Currency)
-   Class
-   Department
-   Expense Account
-   Location
-   Subsidiary

Entity (Customer):

-   Email
-   Address
-   Phone

Donation Setup ID:

-   Donation Setup ID

 | The following criteria is used to filter the dataset:

-   **Donation Setup ID** is not blank
-   **Transaction Line: Amount (Transaction Currency) (not consolidated)** is greater than 0.00
-   **Type** is Invoice

 |
