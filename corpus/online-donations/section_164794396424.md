This section includes the prerequisites and instructions for installing the Online Donations SuiteApp.

## Prerequisites {#subsect_164794410120}

Before installing the Online Donations SuiteApp, you must ensure that the following prerequisites are met:

-   Enable the Payment Link feature.
    
    #### To enable the Payment Link feature:
    
    1.  Go to Setup > Company > Enable Features > Transactions > Payment Processing.
        
    2.  Check the **Payment Link** box.
        
    3.  Click **Save**.
        
    
    For more information on how to setup and use the Payment Link feature, see [Payment Link](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_162516600357.html).
    
-   To use the recurring donations feature, you must enable the Advanced Billing feature. For more information, see [Advanced Billing Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1250795.html).
    
-   If you are using a custom transaction form, make sure you assign a Payment Link Invoice PDF/HTML template. This ensures the email sent to the customers include the payment link. To set up Payment Link templates and customize your transaction form, see [Set Up Payment Link Invoice Templates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_162516600357.html#subsect_163128351464).
    

## Installation {#subsect_164794415425}

Any role with access to the SuiteApp Marketplace in NetSuite can install the Online Donations SuiteApp. For more information about the SuiteApp Marketplace, see [SuiteApp Marketplace in NetSuite](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1539797981.html).

#### To install the Online Donations SuiteApp:

1.  Go to the **SuiteApps** tab.
    
2.  In the Search Apps field, enter **Online Donations SuiteApp**.
    
3.  Click the Online Donations SuiteApp tile.
    
    ![Online Donations SuiteApp Tile](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SocialImpact/OnlineDonations_Help.png)
4.  Go to the top right area of the Online Donations SuiteApp details page and click **Install**.
    

For more information about installing a SuiteApp from the SuiteApp Marketplace, see [Installing from the SuiteApp Marketplace](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1539799323.html).

The Online Donations SuiteApp is a managed SuiteApp and is automatically updated whenever there are enhancements or new features added.
