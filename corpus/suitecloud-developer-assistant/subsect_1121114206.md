Before you install and use SuiteCloud Developer Assistant using Cline in SuiteCloud Extension for Visual Studio Code (VS Code), verify the following prerequisites:

-   Install or update SuiteCloud Extension for VS Code that includes SuiteCloud Developer Assistant. For more information, see [Installing and Setting Up SuiteCloud Extension for Visual Studio Code](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_159223155621.html).
    
-   Install the Cline extension from the Visual Studio Marketplace. For more information, see [Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=saoudrizwan.claude-dev).
    
-   Create a SuiteCloud project. For more information, see [Creating a SuiteCloud Project in SuiteCloud Extension for Visual Studio Code](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162938506015.html).
    
-   Set up an authentication ID (auth ID). For more information, see [Setting Up NetSuite Accounts in SuiteCloud Extension for Visual Studio Code](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160147609118.html).
    

To unlock the full capabilities of SuiteCloud Developer Assistant, install SuiteCloud CLI for Node.js. The CLI provides a secure authentication proxy for a seamless SuiteCloud Developer Assistant experience. For more information, see [SuiteCloud CLI for Node.js Guide](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1558708800.html).

#### To set up SuiteCloud Developer Assistant:

1.  Open Visual Studio Code with the SuiteCloud Extension installed and click the SuiteCloud Developer Assistant welcome message to go to the extension settings.
    
    ![Welcome message showing the Open Settings button](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/SuiteCloudDeveloperAssistant/Dev_Assist_Welcome_Message.png)
    
    Tip:
    
    Return to the extension settings anytime by using Ctrl+, for Windows and Linux, or Cmd+, for macOS.
    
2.  In Workspace > Extensions > SuiteCloud, configure the fields as follows:
    
    1.  **Developer Assistant: Auth ID:** Enter the auth ID you want to use for the SuiteCloud Developer Assistant service. For more information, see [Setting Up NetSuite Accounts in SuiteCloud Extension for Visual Studio Code](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160147609118.html).
        
    2.  **Developer Assistant: Local Port:** Autopopulated by default. Change it if you prefer a different port or if the default port is already in use.
        
    3.  **Developer Assistant: Enable:** Check the **Enable** box.
        
        The SuiteCloud Developer Assistant service isn't enabled automatically, so you need to check the box to start using the feature.
        
        Note:
        
        By enabling the SuiteCloud Developer Assistant service, you acknowledge that you have read and understood the disclaimer provided on the extension Settings page.
        
        During the initial setup, when you enable the SuiteCloud Developer Assistant service, a popup window appears displaying an API key. Copy it and follow the instructions provided.
        
    
    Note:
    
    Refer to the success popup message or the SuiteCloud output to see the Base URL. You'll need it later.
    
3.  In the activity bar, go to the Cline extension and click the provider and model configuration. Next, click **Edit in settings**.
    
    ![Provider and model selector highlighted and Edit in settings option highlighted](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/SuiteCloudDeveloperAssistant/Dev_Assist_Select_Provider_Settings.png)
    
    Configure the provider and model configuration fields as follows:
    
    1.  **API Provider:** Select **OpenAI Compatible**.
        
    2.  **OpenAI Compatible API Key:** Paste the generated API key.
        
    3.  **Base URL:** Enter the URL provided by SuiteCloud Extension for VS Code during SuiteCloud Developer Assistant configuration. To see it again, refer to the SuiteCloud output panel.
        
    4.  **Model ID:** If this isn't autopopulated, enter **NetSuite**.
        
    5.  In **Model Configuration**:
        
        -   Clear the **Supports Images** box.
            
        -   Set the **Context Window Size** to **1,000,000**.
            

Refer to the provider status bar to see the status of SuiteCloud Developer Assistant. Clicking it opens the SuiteCloud Extension for VS Code settings.

![Status bar showing the status of the Developer Assistant](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/SuiteCloudDeveloperAssistant/Dev_Assist_Status_Bar_API_Key.png)
