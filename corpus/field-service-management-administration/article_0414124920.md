The issues mentioned in the following table cover common points of confusion when setting up or using Programs. They also explain what's happening so you can troubleshoot.

| Issue | Likely Cause / Explanation |
| --- | --- |
| Nothing is being created. | Program requires the right Project fields (Project Type, Start Date, and End Date or Create Until) and the related Program configuration. |
| Closing a Case didn't generate the next one. | Closing a Case manually (outside the Case Status flow) doesn't move the Program forward. To resolve the issue, go to the Project and check the **Update Program** box. |
| The Program subtab is confusing. For example, Cases don't line up with the Program Date. | The Program subtab matches existing Cases to the pattern based on date order and type-matching rules. Manually added Cases of the same type that are in the Project's Program can change which schedule rows other Cases match to. Another possibility is that changes were made to the Program mid-project. It's best practice not to change data on the Project. If a contract changes, close the existing project and create a new one with the new terms, structure, and dates. |
