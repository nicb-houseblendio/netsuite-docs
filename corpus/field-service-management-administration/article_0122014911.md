NetSuite Field Service Management (FSM) Programs are used to generate planned, recurring service work. They're often used for maintenance work that needs to repeat on a set schedule.

You define a Program in the "program" section of the FSM configuration, and it runs from a Project. A Program generates a schedule that appears in NetSuite on the Project record's Program subtab. The schedule creates recurring Cases and Tasks so work can be scheduled and completed. In the FSM configuration, you can set when Cases and Tasks are created, and what data is copied between them.

## Purpose of the Program Feature {#subsect_0414124134}

The FSM Program feature automates recurring service work by generating Cases and Tasks under a Project on a defined schedule. This automation reduces manual job creation for recurring or maintenance contracts. The FSM Program feature also supports niche scenarios where a Case is needed, but the business workflow must start from a Project.
