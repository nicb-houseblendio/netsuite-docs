A mobile element is a field that you can configure for a tab in the FSM Mobile app. Each NetSuite field type has a corresponding mobile element type. Mobile element properties determine how the element appears and behaves. For select and multi-select mobile elements, configure the `options` property to define available options.

Use the following topics to configure Field Service Mobile elements:

-   [Field Service Mobile Element Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0222033113.html) - Describes available element types and how element types correspond to NetSuite field types.
    
-   [Field Service Mobile Element Properties](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0222033149.html) - Provides the mobile element property reference, including accepted values and supported element types.
    
-   [Field Service Mobile Element Select Options](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0222033126.html) - Explains option IDs and labels, default select options, and additional option properties.
