## What is Contact Management? {#bridgehead_50134215088}

Contact Management is a feature set that assists you in maintaining and populating Contacts on Project, Case, and Task records. You can select a Primary Contact for new Projects, sync Contacts from Customers to Projects, and source Contact information when creating Cases.

## Project Primary Contact {#subsect_49140042912}

This feature adds a field to the new Project form to select a Primary Contact. This saves users the extra steps of reloading the Project form and manually attaching the Contact after the Project has been created.

## Primary Contact {#bridgehead_39134301609}

This scripted select field contains options for all of the selected Customer's Contacts. The first Primary Contact in the options will be selected by default. After the form is submitted and the Project record successfully created, the Contact is attached with the Primary Contact role.

## Project Sync from Customer {#subsect_28140109058}

This feature bulk-attaches Customer contacts to Project records, so Transactions, Cases, and Tasks under the Project have access to all relevant Contacts on the Customer. You can use a Search Filter to specify which Contacts should be attached.

## Update Contacts {#bridgehead_1134355363}

This Update Contacts box requests to attach any Contacts on the Customer that are not yet attached to the current Project. It is automatically checked on newly created Project records.

A Project submitted with this field checked will schedule the _NextService Scheduled : Contact_ Scheduled Script with script deployment id `customdeploy_nx_contact`. After the scheduled script has finished processing and attaching all Contacts successfully, the Update Contacts box will be unchecked.
