When a Project is configured for a Program, Field Service Management (FSM) can:

-   Create recurring Cases under a Project according to configured Program rules.
    
-   Create one or more Tasks under those Cases so the work can be scheduled and actioned.
    
-   Set field values from one record to another, including Project to Case, Project to Task, and Case to Task.
    
-   Display a Program subtab on the Project with the calculated program dates and the Cases the Program creates and matches.
    

Note:

Tasks (not Cases) display on the FSM Schedule Board and in FSM Mobile. You configure the Program feature to create those Tasks.
