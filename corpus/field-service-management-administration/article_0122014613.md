## What are Notifications? {#bridgehead_78134628273}

Notifications are automated emails sent when Support Cases, Tasks, and Project Tasks change state. This keeps all stakeholders have prompt and consistent communication about activities and transactions.

## Event Pending Notifications Field {#subsect_66135731416}

This field contains the notifications associated with the record that are queued to be sent. When you submit a record with this field, FSM runs the _NextService Scheduled : Notification_ Scheduled Script with script deployment id `customdeploy_nx_notification`.

This Scheduled Script processes records with this field populated one at a time by:

1.  Sending all pending notifications for the record.
    
2.  Clearing the _Pending Notifications_ field value.
    

This Scheduled Script handles all notifications by record type in order of Support Case, Task, then Project Task.
