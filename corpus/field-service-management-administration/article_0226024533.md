This section outlines the steps to update the Configuration file.

Important:

Test configuration changes in sandbox before making the change in your production account.

Always run an end-to-end test of your field service processes after making a change.

#### To update the configuration file:

1.  Go to Field Service > Administration > Configuration.
    
2.  The Field Service Configuration page opens the current active configuration file.
    
    In the **Name** field, enter a unique file name that you can identify later, for example, "2024-01-31 EL."
    
    Tip:
    
    Take note of the active configuration file's original name because you'll need to find and inactivate it later.
    
    You may also need to return to previous configurations, so it's best to familiarize yourself with each file name.
    
3.  Check the **Inactive** box so the new configuration file stays inactive for now.
    
4.  Make the changes you want in the configuration record.
    
5.  From the **Save** dropdown list, click **Save As**.
    
6.  Click **List** in the upper right corner to open the Field Service Configuration list.
    
7.  On the Field Service Configuration List page, ensure the **Show Inactives** box is checked.
    
8.  Find the file you created in steps 2 to 5 and clear its **Inactive** box.
    
9.  Find the previous configuration file in the list and ensure that its **Inactive** box is checked.
    
10.  Click **Submit** and complete your end-to-end testing.
