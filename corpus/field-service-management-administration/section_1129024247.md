This section describes the various compatibility and support levels of Field Service Management (FSM) in relation to its functionality with NetSuite features.

For more information about NetSuite features, see [Enabling Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N232138.html).

## Compatibility {#subsect_1129025222}

A NetSuite Feature is considered compatible with Field Service Management (FSM) if it can be enabled without causing errors in NetSuite or Field Service Management.

| Compatibility | Description |
| --- | --- |
| Required | The NetSuite feature is required for Field Service Management to function. |
| Optional | The NetSuite feature is not required for Field Service Management to function. This means FSM will work properly, with or without this featured enabled. |
| Incompatible | The NetSuite feature is not compatible with Field Service Management. If enabled, this feature will cause errors in FSM or, installing FSM on an account with this feature enabled will cause the feature to not work as expected. |
| Not tested | The NetSuite feature has not been tested alongside Field Service Management. The feature may or may not work properly with FSM. |

## Support Levels {#subsect_1129030912}

Field Service Management (FSM) support levels describe how NetSuite feature behavior is applied to FSM features.

| Support Level | Description |
| --- | --- |
| Full | The NetSuite feature behavior is applied to all FSM features. |
| Partial | The NetSuite feature has some behaviors applied to FSM features. |
| None | The NetSuite feature has not been integrated into FSM features. |
| Not applicable | The NetSuite feature has no interaction with FSM features. |

The following tables list the compatibility and support levels of Field Service Management (FSM) with NetSuite features and project management preferences.
