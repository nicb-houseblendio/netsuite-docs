The Program feature uses the following records:

| Record | Role in Program Feature |
| --- | --- |
| Task | Optional child records created under each Case to track and complete the work. Tasks are used for scheduling and viewing in the mobile app. |
| Asset | Program scenarios often link Projects, Cases, and Tasks to Assets such as service equipment. |
| Case | Recurring service work generated by the Program. |
| Field Service Configuration (customrecord\_nx\_configuration) | Stores the JSON configuration that defines Program rules. |
| Project | Stores the primary schedule and key Program fields like Start Date, End Date, and Program Type. See [Program Setup on the Project Record](#subsect_0414032619). |

## Program Setup on the Project Record {#subsect_0414032619}

Program setup in NetSuite depends on the Project record fields and status values that determine whether a Project is eligible to run a Program and how NetSuite creates, updates, or deletes Program-generated Cases and Tasks.

### Project Record Fields (UI) {#subsect_0414032707}

Program behavior depends on the following Project record fields:

-   NetSuite fields:
    
    -   Start Date
        
    -   End Date
        
-   FSM fields:
    
    -   Field Service Customer
        
    -   Field Service Asset
        
    -   Field Service Project Type
        
    -   Field Service Start Date
        
    -   Field Service Program Create Until
        
    -   Field Service Time Zone
        
    -   Field Service Update Program
