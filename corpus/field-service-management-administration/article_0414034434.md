To view a Program in NetSuite, go to Field Service > Projects. Click **View** next to the Project that contains the Program you want to view.

On the Project record page, go to the Field Service tab and the Program subtab. This area updates dynamically after Program-driving fields on the Project are changed.

Each row under the Program subtab represents a Case that's created for the Program based on the Project's current values.

The Program subtab columns are described in the following table:

| Subtab Column Title | Description |
| --- | --- |
| **Type** | The Case Type that will be created for that Program row. |
| **Program Date** | The scheduled date that the Program calculates for the Case. This isn't the same as the Case's **Start Date**, which appears in the **Start Date** column. For how **Start Date**, **Field Service Start Date**, and **Field Service Program Create Until** affect this value, see [What the Program Feature Automatically Sets or Controls](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0414124851.html). |
| **Case** | The Case for that row. If the Case hasn't been created, this field is blank. |
| **Start Date** | The Case's start date. If the Case hasn't been created, this field is blank. |
| **End Date** | The Case's end date. If the Case hasn't been created or doesn't have an end date yet, this field is blank. |
| **Status** | The Case's current status. If the Case hasn't been created, this field is blank. |
| **Assigned To** | The Case's assignee. If the Case hasn't been created, this field is blank. |
