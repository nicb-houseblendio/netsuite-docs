The Program feature affects other areas of Field Service Management (FSM) by generating work that flows into scheduling and mobile processes. Its behavior is shaped by how it operates alongside related features such as Recurrence and the FSM configuration framework.

## How the Program Feature Affects Other FSM Areas {#subsect_0414040646}

Programs have the following downstream impacts:

-   **Scheduling** - A Program can generate Tasks that schedulers can assign on the FSM Schedule Board.
    
-   **Mobile app** - Technicians work on Tasks in FSM Mobile. Programs are often used to generate a recurring workload through Cases and Tasks.
    

## Program Feature Interaction with Other Features {#subsect_0414040651}

The Program feature integrates with key FSM features and processes, influencing how recurring work is generated, scheduled, and completed across the system.

-   **Recurrence vs Program** - Program requires a Project and is separate from the Recurrence feature. Recurrence can generate repeating records (like Cases, Tasks, and Project Tasks), but Program depends on a Project record.
    
-   **Configuration framework** - Program behavior depends entirely on the FSM configuration architecture.
