The following example shows how the Program feature works in practice, from configuration and project setup through to automated record creation, scheduling, and task completion.

1.  A Field Service Management (FSM) administrator creates or updates the Program configuration in the program section of the FSM configuration JSON.
    
2.  An operations manager creates a Project linked to an asset or service contract and completes the required Program setup on the Project record. See [Program Setup on the Project Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0414124820.html#subsect_0414032619).
    
3.  The operations manager saves the Project with **Field Service Update Program** checked. This queues the Project for processing by the Program scheduled script.
    
4.  FSM creates the scheduled Cases and, if configured, the Tasks under them.
    
5.  Schedulers assign tasks on the Schedule Board.
    
6.  Technicians complete the Tasks in FSM Mobile.
