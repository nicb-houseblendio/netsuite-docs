The Program subtab on the Project record generates the planned schedule rows for the Program. At a minimum, each row includes a **Type** and a **Program Date**.

After those rows are generated, NetSuite searches for existing Cases under the Project with a start date after the Project **Start Date** or **Field Service Start Date**.

NetSuite then:

-   Orders those Cases chronologically from oldest to newest
    
-   Matches them one by one against the next available Program row that matches by **Type**
    
-   Refrains from matching the **Program Date** to the Case's **Start Date**
    

Because of this matching logic, manually created Cases or changes made partway through a Program can affect which Program row an existing Case is matched to.
