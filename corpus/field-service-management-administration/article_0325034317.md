## Supported Browsers and Devices {#subsect_0325050452}

The Field Service Management mobile application and the Field Service Scheduler board are supported on the following web browsers:

| Browser | Latest Version Tested |
| --- | --- |
| Google Chrome | 140.0.7339.123 |
| Microsoft Edge | 139.0.3405.125 |
| Apple Safari | 18.6.2 |

The Mozilla Firefox and Opera browsers are not supported. You should use one of the supported browsers to ensure the most stable experience.

The Field Service Management mobile application is a progressive web application designed for use on touch-enabled mobile devices such as phones and tablets running one of the supported browsers.

The following mobile devices have been tested to work with the mobile application.

| Device | Latest OS Version Tested |
| --- | --- |
| Umidigi Bison | Android 11 |
| Samsung S21 Ultra | Android 15 |
| iPhone 11, iPhone 13 Pro | iOS 18.6.2 |
| iPad Pro | iPadOS 17.7.2 |

The Field Service Scheduler board is designed for use only in browsers on non-touch enabled devices with a screen resolution of at least 1024 x 768 pixels. It will not function as expected on touch-enabled devices such as tablets or phones.
