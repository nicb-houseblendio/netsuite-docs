You can track field service time on tasks that have been linked to activities for time tracking.

#### To track field service time:

1.  On the Mobile task list screen, select the appropriate task.
    
2.  Click **Start**. This opens a popup window.
    
3.  On the **Start the Task** window, the **Start Time** field defaults to the current time. You can edit the start time by clicking on the clock icon.
    
4.  Click **Start** to begin tracking service time and create the activity record. If you click **Cancel,** the task doesn't start and no time record is captured.
    
5.  When the task is in progress, fill in any required information related to the task in the appropriate fields.
    
    You can still edit the task start time by clicking the dimmed Start button which is now labeled **Started at x:xx AM or PM**. The **Update the Task** popup window opens and you can edit the time by clicking on the clock icon. Click **Update** to set the new start time.
    
    Note:
    
    You can only track time for a single task. A banner indicating the current task appears at the bottom of the Mobile dashboard. The banner remains on screen when you check other pending tasks. Click **Continue** to return to your active task. You have to complete your current task before you can track time for another.
    
6.  When the task is done, click **Complete** to open the **Complete the Task** popup window.
    
7.  On the popup window, the **Complete Time** field defaults to the current time. You can edit the time by clicking on the clock icon.
    
8.  Click **Complete** to end the task and record the completion time.
