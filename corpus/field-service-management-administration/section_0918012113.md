You can view time-tracking activities logged for completed field tasks on the Task record.

#### To view created activities on a task:

1.  Go to Field Service > Tasks > Tasks.
    
2.  On the **Tasks** list page, select the appropriate task.
    
3.  Under the **Field Service** subtab, go to the **Field Service Activity** subtab.
    
4.  The **Field Service Activity** subtab shows all related activities created against the task.
    
    The **Start Task** and **Complete Task** entries under the **Type** column shows the user-confirmed start and completion times respectively.
    
5.  (Optional) Click **Edit** beside an activity to open the **Field Service Activity** page showing more details.
    

The following table describes the relationship between the timestamps of different actions in Mobile and the corresponding values saved in the Task record. This is important to know because the mobile user can change the start or completion times of a task.

| Timestamp | Where is this saved on the Task record? |
| --- | --- |
| User clicks Start | Field Service Start |
| User-confirmed start time on Start or Update the Task popup window | Start Task time under the Field Service Activity subtab |
| User-confirmed completion time on Complete the Task popup window | Complete Task time under Field Service Activity subtab |
| User clicks Complete | Field Service End |
