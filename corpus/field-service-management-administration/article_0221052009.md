This documentation is for administrators with access to Field Service Management Configuration that have an in depth knowledge of how to configure Programs.

#### Setting Up Recurring Cases with a Task That Sits Underneath (Using Programs)

1.  Setup a Case Type and a Task Type in NetSuite.
    
2.  Configure the case type and task type in the `program` as below. `"project"` is set to `[true, false]` so it covers both with and without project type. `5` is an example of an `internalid` of the `case type`, and `7` is an example of an `internalid` of the `task type`.
    
                    `{    "program": {       "caserules": [{             "project": [true, false],             "case": 5,             "task": {                "type": 7             }          }]    } }` 
                  
    
3.  Create a Case selecting the case type above. Setup the recurrence.
    

## Example {#bridgehead_0221052805}

1.  Set up a Case Type in NetSuite.
    
    ![NetSuite case type screen.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/FieldServiceManagement/AdminUserGuide/recurring_case_program_task_01.png)
2.  Set up a Task Type in NetSuite.
    
    ![NetSuite task type screen.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/FieldServiceManagement/AdminUserGuide/recurring_case_program_task_02.png)
3.  Configure the case type and task type in the `program`.
    
                  `{    "program": {       "caserules": [{             "project": [true, false],             "//": "Safety Inspection",             "case": 5,             "task": {                "//": "Smoke Alarm Inspection",                "type": 7             }          }]    } }` 
                
    
4.  Create a Case selecting the case type.
    
    ![Case screen selecting the created case type.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/FieldServiceManagement/AdminUserGuide/recurring_case_program_task_04.png)
5.  Set up the Recurrence. Save.
    
    ![Recurrence subtab of Case.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/FieldServiceManagement/AdminUserGuide/recurring_case_program_task_05.png)
6.  Refresh the page periodically until the Pending banner is gone.
    
7.  Check the **Recurrence Instances** sublist to see the generated instances.
    
    ![Recurrence Instances subtab.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/FieldServiceManagement/AdminUserGuide/recurring_case_program_task_07.png)
8.  Open each case and see the task created with it.
    
    ![Tasks subtab created with each case.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/FieldServiceManagement/AdminUserGuide/recurring_case_program_task_08.png)
9.  Each task must have the type configured in the `program`.
    
    ![Task configured must be the same as in program.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/FieldServiceManagement/AdminUserGuide/recurring_case_program_task_09.png)
