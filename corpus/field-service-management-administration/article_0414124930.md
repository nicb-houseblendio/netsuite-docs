Use these checks to confirm the project is eligible for program processing. They also help you verify that the configuration and triggers are in place for Field Service Management (FSM) to create or update the expected cases and tasks.

1.  Confirm the project meets the setup requirements described in [Program Feature Minimum Requirements](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0414124831.html).
    
2.  Check the Project record to confirm that the **Field Service Update Program** box is checked and saved so processing gets queued.
    
3.  Confirm the program configuration exists in the FSM configuration JSON (the program section with projectrules and caserules).
    
4.  If you're using 'next case only' patterns, confirm the behavior matches your create and shift rules and trigger setup.
