Field Service Management (FSM) configuration includes core product configuration and custom configuration. Custom configuration lets you adapt FSM to account-specific requirements.

Use the configuration file to:

-   Customize Field Service Management features and behaviors in the NetSuite user interface.
    
-   Customize the FSM Schedule Board.
    
-   Customize the FSM Mobile app.
    

Use the following topics to work with FSM configuration:

-   [Field Service Management Configuration Architecture](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0727073041.html) - Explains the core product and custom configuration layers.
    
-   [Configuration File Structure](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0729060557.html) - Describes the main configuration sections and the FSM features that each section controls.
    
-   [Updating the Configuration File](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0226024533.html) - Explains how to update and activate a custom configuration file.
    
-   [Field Service Configuration Reference](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0727085102.html) - Provides detailed reference information for FSM configuration.
    
-   [Configuration Preview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0729063846.html) - Explains how to view the merged runtime configuration.
    
-   [Running Searches in Config](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0729061604.html) - Explains search syntax and patterns for configuration.
