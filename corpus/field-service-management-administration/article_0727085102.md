This topic summarizes configuration for the FSM Mobile app, Schedule Board, notifications, and shared FSM components.

## FSM Mobile App Configuration {#subsect_0727085226}

The following table summarizes FSM Mobile app configuration topics and links to detailed guidance.

| Configuration Area | Scope | Description | Related Topic |
| --- | --- | --- | --- |
| Mobile elements | FSM Mobile tabs | Provides an overview of mobile element types, mobile element properties, and options for select and multi-select elements. | [Field Service Mobile Element Configuration](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0803014220.html) |
| Automatic field mapping | FSM Mobile tabs | Explains how the `automap` property maps FSM Mobile elements to NetSuite fields when element IDs match field IDs and how explicit mappings take precedence. | [Automatic Mapping of NetSuite Fields for an FSM Mobile Tab](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0810081531.html) |
| Mobile form expressions | FSM Mobile forms | Explains how mobile form expressions change form properties in response to form data, including conditional questions, calculations, select options, styles, and reusable data from other mobile resources. | [Mobile Form Expressions for Field Service Management](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0728090801.html) |
| HTML content and customization | FSM Mobile forms and screens | Explains how to configure HTML content in the FSM Mobile app and when to use imported JavaScript functions instead of an HTML field. | [HTML Content and JavaScript Customization in FSM Mobile](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0729021515.html) |
| Task and project task data | FSM Mobile configuration | Explains how FSM Mobile app loads task and project Task data, how to reference that data in configuration, and how to use it with date, time of day, and datetime fields. | [Task and Project Task Data in FSM Mobile](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0730090514.html) |
