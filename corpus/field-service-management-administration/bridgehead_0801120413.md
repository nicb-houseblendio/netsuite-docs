This feature is not enabled by default. To enable the feature, you must add the `timetracking` property and set it to true in your FSM Configuration.

Important:

If you intend to enable the Track Service Time feature for the first time, test the feature in a sandbox before enabling it in a production account.

#### To enable the Track Service Time feature:

1.  Go to Field Service > Administration > Configuration.
    
2.  In the **Editor** text area, add the `timetracking` property:
    
                    `},   "time": {     "timetracking": true   },` 
                  
    
3.  Click **Save**.
    

For more information about updating the FSM Configuration, see [Updating the Configuration File](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0226024533.html).

## Setting Up the Technician's Tasks {#bridgehead_0801120610}

After you enable the feature, ensure all tasks on the mobile app are set to **Not Started** for each technician. Only one task can be active at a time in the mobile app. Complete any other In Progress tasks in NetSuite.

If more than one task is active in the mobile app, the technician may need a service manager to update the tasks in NetSuite.
