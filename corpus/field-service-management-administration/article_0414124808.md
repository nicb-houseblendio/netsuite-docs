Program configuration includes both the Project record fields and the Field Service Management (FSM) configuration JSON that together define how the Program feature runs. It covers the configuration elements that control:

-   Which Projects generate Cases and Tasks
    
-   How data is mapped between records
    
-   How schedule behavior is governed through the program's maps, rules, and related properties
