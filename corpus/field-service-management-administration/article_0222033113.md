Administrators can define elements that represent NetSuite fields when configuring custom mobile tabs or modifying core mobile tabs. Each NetSuite field type has a corresponding mobile element type.

The following topics describe the available Field Service Mobile element types and how element types correspond to NetSuite fields:

-   [Field Service Mobile Element Type Reference](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_0222041011.html) - Review available element types, corresponding NetSuite field types, configuration examples, and default properties.
    
-   [Mapping Field Service Mobile Elements to NetSuite Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_0222041940.html) - Learn how to map Field Service Mobile elements to NetSuite fields, including mapping structures for specialized element types.
    
-   [Determining Field Service Mobile Element Types from Custom Forms](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_0222042004.html) - Learn how custom forms determine mobile element types and how field ID suffixes specify document, image, and signature elements.
    
-   [Field Service Mobile Element Type Aliases](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_0222042022.html) - Review shorthand element types, corresponding base element types, and preset properties.
