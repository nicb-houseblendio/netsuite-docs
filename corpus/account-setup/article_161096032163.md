When you import transactions from another application, Advanced Numbering determines which numbers to used based on the following rules:

-   If external document numbers are included, Advanced Numbering uses them.
    
-   If external document numbers are missing, Advanced Numbering generates them using your rules.
    
-   Advanced Numbering always generates new transaction numbers. You can't import transaction numbers from external applications or overwrite the NetSuite transaction numbers with external ones.
    

These rules apply to transactions you import using the following methods:

-   SuiteScript
    
-   CSV import
    
-   REST
    
-   JSON
