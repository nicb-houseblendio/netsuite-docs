A plug-in is customized functionality that is defined by an interface. After a plug-in is implemented, users with the Administrator role can override the plug-in's default logic to better fit their organization's needs.

-   NetSuite provides core plug-ins, which are usually part of a major release. A core plug-in's interface defines functions that are run within the core NetSuite code. For more information about core plug-ins, see [Core Plug-in Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4567788235.html).
    
    Third-party providers develop custom plug-ins as alternate implementations of an interface, and bundle them in a SuiteApp. For more information about custom plug-ins, see [Custom Plug-in Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_3976781171.html).
    

When a plug-in's implementations are ready, a user with the Administrator role activates the implementations available for each NetSuite account.

To view the plug-in implementations available in an account:

1.  Go to _Customization > Plug-ins > Manage Plug-ins_.
    
2.  The Manage Plug-in Implementations page lists the core and custom plug-in implementations that are available in the current account. To activate an implementation, check the box. To inactivate an implementation, clear the box.
    
3.  Make changes as required. Then, click **Save**.
    

For information about viewing system notes for a plug-in implementation, see [Viewing Plug-in Implementation System Notes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4702431116.html).
