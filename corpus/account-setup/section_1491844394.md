The following link provides you with Microsoft Excel worksheet listing the permissions associated with NetSuite features. You can use this list to see which roles have the permissions needed to access specific features. The spreadsheet format lets you search and sort fields however works best for you.

To access the worksheet, click this link: [FeaturesStandardRoles.xlsx](https://system.netsuite.com/core/media/media.nl?id=414072541&c=NLCORP&h=0zb8bktc2gXg9TyXy-mTnNS_jbblTZ_IF65k-Zpsg0viOzXu&_xt=.xls).

The following topics contain information about permissions you need to access specific NetSuite features. The listings isn't a complete set of permissions help topics. You can find more permissions documentation in the Help Center, including details about the permissions needed to access different records or features. For general permissions documentation, see [NetSuite Permissions Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N325094.html).
