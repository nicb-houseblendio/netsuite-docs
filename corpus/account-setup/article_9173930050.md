You can use Prompt Studio to customize system Text Enhance actions for your company's account. When you customize a system Text Enhance prompt, your version overrides the system prompt for the Text Enhance action. After you save customized Text Enhance prompts, the new behavior will apply to system actions in the applicable Text Enhance menus.

Note:

You can access Prompt Studio if you're a NetSuite user with an Administrator role or with a customized role that has the Setup Prompts (ADMI\_PROMPTS) permission.
