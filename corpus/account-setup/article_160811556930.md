Advanced numbering sequences combine a rule set and its rules. You can add as many rules as you need for any standard or custom transaction type. You create an advanced numbering rule in three steps:

1.  Enter the number format, including prefix and suffix, for your numbering sequence. For more information, see [Entering the Number Format](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161096135812.html).
    
2.  Use the **Sequences by Segment** subtab to select a segment (fiscal year, subsidiary, or location) for the sequence. Advanced Numbering creates a unique sequence for each combination you select. For more information, see [Selecting the Sequences by Segment](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161096176287.html).
    
3.  Use the **Criteria** subtab to set when to apply the sequence. You must have at least one criterion. You should use Date to limit Advanced Numbering to the following:
    
    -   Transactions that happen after you enabled the feature
        
    -   Transactions that happen after the date you want to start using Advanced Numbering.
        
    
    For more information, see [Selecting the Advanced Numbering Criteria](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161096198249.html).
    

For detailed instructions to create an advanced numbering rule, see [Creating an Advanced Numbering Rule](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161096212635.html).
