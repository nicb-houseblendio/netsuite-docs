Selecting the criteria for your advanced numbering rule is the last step when you set up the rule, as described in [Creating an Advanced Numbering Rule](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161096212635.html). In the **Criteria** subtab, select the fields NetSuite will use to determine when to number transactions. For example, you can apply a numbering rule to transactions in a certain date range, whether they're posting or not, or if they're in a specified posting period.

## Tips for Selecting Criteria {#subsect_69192235444}

You must have at least one criterion. You should use Date to limit Advanced Numbering to:

-   Transactions that happen after you turned on the feature
    
-   Transactions that happen after the date you want to start using Advanced Numbering
    

Important:

If you use a custom field in a numbering rule, you can't change the field settings because any change will break the rule.

You also can't change the field ID.

## Available Criteria {#subsect_94192224345}

You can select any combination of the following fields to use as criteria for your advanced numbering rule:

-   Subsidiary
    
-   Posting Period
    
-   Posting (Y/N)
    
-   Memo
    
-   Location
    
-   Date
    
-   Currency
    
-   (Subsidiary) Country
    
-   The following types of custom fields:
    
    -   Checkbox
        
    -   Currency
        
    -   Date
        
    -   Decimal Number
        
    -   Email Address
        
    -   Free-Form Text
        
    -   Integer
        
    -   List/Record
        
    -   Rich Text
        
    -   Text Area
