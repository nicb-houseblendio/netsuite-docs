Specialized User: Manufacturing Operator is a standard role that enables manufacturing operators to complete required shop floor and manufacturing tasks. This role provides restricted access to Manufacturing Mobile and Advanced Manufacturing Tablet flows.

By default, the role includes permissions for tasks such as assembly builds, work orders, work order completions, work order issues, and bill materials inquiries.

Before you assign the Specialized User: Manufacturing Operator role, you can customize it to suit your manufacturing requirements. You can restrict permissions, but you can't add permissions or assign access levels higher than those available in the standard role. For more information, see [Customizing the Specialized User: Manufacturing Operator Role](#subsect_0617113951).

You can assign either the standard role or a customized Specialized User: Manufacturing Operator role to provide access to supported manufacturing mobile flows. For instructions, see the following topics:

-   [Assigning Roles to an Employee](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N897798.html)
    
-   [Managing Specialized User: Manufacturing Operator Users](#subsect_0617114028)
    

To view the list of default permissions and access levels for this role, see [Standard Roles Permissions Table](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N295396.html).

Note:

Assign a Specialized User: Manufacturing Operator role instead of a manufacturing role that is included with NetSuite Manufacturing. Other manufacturing roles don't count toward Specialized User access.

## Specialized User: Manufacturing Operator Role Availability {#subsect_0617113907}

To use the Specialized User: Manufacturing Operator role, you must have the following:

-   NetSuite Specialized Manufacturing Cloud Service User license
    
-   Active NetSuite Advanced Manufacturing account
    
-   Manufacturing Mobile SuiteApp
    

The Specialized User: Manufacturing Operator role is not available by default in NetSuite Manufacturing. For more information, contact your NetSuite account manager.

## Customizing the Specialized User: Manufacturing Operator Role {#subsect_0617113951}

You can create a custom role based on the standard Specialized User: Manufacturing Operator role. Use a custom role when you need to restrict access for manufacturing operators. You can't add permissions that are not included in the standard role. You also can't assign higher access levels than the standard role allows.

Important:

If you don't use SAML SSO to access NetSuite or the app, customize or create a custom role to remove the SAML Single Sign-on permission. Otherwise, you may receive an error message indicating that login access is disabled for the role. To add or remove this permission, see Add SAML Single Sign-on Permissions to Roles.

When you create a custom role, include Specialized User: Manufacturing Operator in the role name. This naming pattern helps you distinguish the role from other manufacturing roles. For instructions, see the following topics:

-   [Customizing and Creating Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N286284.html)
    
-   [Setting Permissions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N288727.html)
    

After you create a custom Specialized User: Manufacturing Operator role, assign it on the employee record. See [Specialized User: Manufacturing Operator Role](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0617113517.html).

## Managing Specialized User: Manufacturing Operator Users {#subsect_0617114028}

An employee counts toward Specialized User: Manufacturing Operator usage only when assigned the standard or a custom Specialized User: Manufacturing Operator role based on it. You can assign multiple Specialized User: Manufacturing Operator roles to the same employee.

If you assign a Specialized User: Manufacturing Operator role together with one or more Full access roles, the employee counts toward Full access usage.

If you switch an employee to a Specialized User: Manufacturing Operator role, remove other roles not based on it. Otherwise, the employee may not count toward Specialized User: Manufacturing Operator usage.

To view the number of available licenses, go to Setup > Company > Billing Information using the Administrator role. On the **Billable Components** subtab, locate **Specialized User: Manufacturing Operator in** the **Component** column. The **Current Provisioned Qty** column shows the number of users that you can assign to this role.
