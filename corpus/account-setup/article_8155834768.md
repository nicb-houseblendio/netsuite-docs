If you're a user with the Administrator role, you can manage company-level generative AI settings. Company-level generative AI settings affect everyone using the company's NetSuite account.

-   Use the AI Preferences page and its subtabs to manage settings for features that use AI. You can also use this page to manage common generative AI settings you have set. For more information, see [Managing AI Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_155945673.html).
    
-   Use Prompt Studio to manage Text Enhance actions, set up prompts for those actions, and manage prompts used by SuiteScript code with the N/llm module. For more information, see [Prompt Studio](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160809601.html).
