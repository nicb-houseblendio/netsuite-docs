Important:

This feature is required. Users with the Administrator role can't request to turn it off, and no setup is needed.

All files you store in the File Cabinet are screened for malicious content when you upload them through the UI, SuiteScript, or Web Services. If files are found to be malicious, they're rejected. In these cases, you'll see the following error message in the UI or the console: **'The file '{1:filename} was not saved to the File Cabinet. An Unexpected error has occurred.'**

If you think a rejected file is safe, please contact NetSuite Customer Support for help with the issue.

Email attachments sent to NetSuite are also scanned for viruses. This includes attachments in support cases or those received through the email capture plug-in. If a file attachment is found to be malicious, it's automatically blocked and no error message is sent.
