Important:

To use some of the employee and payroll features, you need SuitePeople HR or SuitePeople U.S. Payroll set up on your account. For more information, see [SuitePeople Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1495573671.html).

If you're an Administrator, you can enable the following features on the **Employees** subtab of the Enable Features page at _Setup > Company > Enable Features_.

| Feature | Description |
| --- | --- |
| Expense Reports | Track employee expenses and turn them into bills. Note: Enabling this feature creates system-generated Unapproved Expense Reports, Advances Paid, and Accounts Payable accounts. |
| Approval Routing | Set up an approval hierarchy required to process expense reports and purchase requests. If you don't enable this feature, each expense report or purchase request automatically goes to the employee's supervisor and then to accounting. When you enable this feature, extra steps after an employee enters an expense report or purchase request depend on their expense or purchase limit. Some other criteria include who their supervisor or approver is, and the approval limit of that supervisor or approver. |
| Per-Employee Billing Rates | Check this box to set up billing classes that set billable time rates when employees charge different rates for the same service. If you link a billing class to an employee, the correct rate defaults when billing customers for time tracking. |
| Billing Rate Cards | Set different rates for groups of billing classes. |
| Purchase Requests | Let employees enter purchase requests online. |
| Time Tracking | Let employees record their work hours. If you're using products other than NetSuite CRM+, you can:
-   Record billable hours and invoice customers for these hours.
-   Record time for payroll items.

Warning: NetSuite CRM+ users can't record billable time, invoice customers for it, or record time for payroll items. |
| Weekly Timesheets | Track employee time with weekly timesheets. Important: You need Time Tracking to use Weekly Timesheets. |
| New Weekly Timesheets Interface | Enable a new interface for your weekly timesheets with column headings, fixed time entry columns, and a memo popup for each entry. Important: You need both Time Tracking and Weekly Timesheets to use the new interface. |
| Time Tracking for CRM | Track time for cases, tasks, and events. When you enable this, a Time subtab appears on case, task, and event records. |
