NetSuite offers the following types of user licenses:

-   Full Licensed User - For users who require full permissions to NetSuite features, including standard and custom roles that provide comprehensive permissions.
    
-   Employee Center - For users whose activities are limited to self-service tasks, such as entering timesheets, expenses, or viewing pay slips.
    
-   Retail User - For users with specific roles such as Retail Clerk or Retail Clerk (Web Services Only), intended for use in retail environments.
    
-   Specialized User - For users assigned specialized roles that provide limited access: CRM, Project Manager, Site Operator, View and Approve, or WMS.
    
-   SuiteCloud Plus License - For users with the 'Concurrent Web Services User' feature enabled, required for supporting certain integrations and API scenarios.
