If you're an Administrator, you can enable the following features on the **Analytics** subtab of the Enable Features page at _Setup > Company > Enable Features_.

| Feature | Description |
| --- | --- |
| HTML Formulas in Search | Add HTML to search formulas using Formula (HTML) fields. |
