If you use the Restrict by Device ID feature, check the **Restrict by Device ID** box at _Setup > Users/Roles > Manage Roles_ to allow access to this role only from the listed devices.

For more information, see [Device ID Authentication](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4369653050.html).
