The SuiteSuccess Transaction Types Analysis Workbook is available on the SuiteApp marketplace to help you see your company's transaction line usage for the current month in NetSuite. If you install the SuiteApp, you can see how many transaction lines you generate this month and analyze them by transaction type. For details on installing SuiteApps, see [SuiteApp Installation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1540236668.html).

Note:

The transaction line numbers you see in the SuiteSuccess Transaction Types Analysis Workbook are accurate. However, you might notice a small difference between the total shown in the workbook and the numbers on the Billing Information page. That's because a small number of transaction types, such as memorized transaction templates and statistical journals, don't appear in the Transaction Dataset in SuiteAnalytics. This discrepancy is less than 1%.
