If you're an Administrator, you can enable the following features on the **SuiteCloud** subtab of the Enable Features page at _Setup > Company > Enable Features_.

| Feature | Description |
| --- | --- |
| Client SuiteScript | Add advanced functionality to your account with industry-standard JavaScript. |
| Server SuiteScript | Use server-side scripting to customize your business workflows and processes. |
| SuiteScript Server Pages | Support the creation of SSP applications to use website and other customizations. You can use both SuiteScript 1.0 and SuiteScript 2.0 in web applications. |
