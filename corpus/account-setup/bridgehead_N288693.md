If you use the IP Address Rules feature, check the **Restrict this role by IP Address** box at _Setup > Users/Roles > Manage Roles_ to allow access to this role only from the IP addresses listed at .

For more information, see [Enabling and Creating IP Address Rules](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4726612641.html).

Note:

Oracle NetSuite does not support traffic that is routed through a split-tunnel Virtual Private Network (VPN) to control user access to NetSuite. For more information, see [VPN Configuration for User Access to NetSuite](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161609571818.html).
