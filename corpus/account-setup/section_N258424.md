A system alert lets users with the Administrator role know when NetSuite has a problem processing a transaction and offers advice on how to fix it. Only users with the Administrator role can access system alerts.

System alerts appear in the Reminders portlet on the Home tab after you've activated the reminder. For more information, see [Viewing the System Alert Page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_162091251359.html).

#### To activate system alert reminders: {#procedure_N258445}

1.  Click **Personalize Dashboard** in the Settings portlet or **Personalize** in the top right corner of the Home page.
    
2.  In the **Add Content** panel, click or move the **Reminders** item.
    
3.  In the **Reminders** portlet, click **Set Up**.
    
4.  Check the **NetSuite System Alerts to Acknowledge** box.
    
5.  Click **Save**.
    

To view a system alert, click the reminder in the Reminders portlet on the Home page. See system alerts at _Setup > Company > System Alerts_.

To view a list of system alerts, see [Viewing the System Alert Page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_162091251359.html).

Automatic Memorized Transaction (AMT) alerts appear as a system alert in the Reminders portlet on the Home page. The AMT system alert tells you that an automatic memorized transaction didn't post because it's missing a location reference.
