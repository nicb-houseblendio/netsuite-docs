Important:

Only users with the NetSuite 360 - Plus Financials role can access the Financial Dashboard in NetSuite 360.

The Financial Dashboard enables you to view and pay NetSuite invoices and add and edit payment cards. You can access the Financial Dashboard from the left panel in NetSuite 360.

You can use the **NetSuite Invoices** portlet to review the amounts of Open Invoices and Past Due Invoices. For information about how to pay NetSuite invoices, see [Paying NetSuite Invoices Using the Financial Dashboard](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_39140258205.html). For information about how to add payment cards, see [Adding Payment Cards Using the Financial Dashboard](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_89140305257.html). For information about how to set up ACH payment methods, see [Adding ACH Payment Methods](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_42140315761.html).

The **Quick Access** portlet provides you with the following links:

-   **Contact the NetSuite Collections Team** - The NetSuite Collections Team can help if you're having trouble paying invoices. Click this link to contact the NetSuite Collections Team. In the popup window that opens, from the **Choose a Region** list, select your region, fill out the **Subject** and **Message** fields, and then click **Send Email**.
    
-   **Download Financial Documents** - Click this link if you want to download your financial documents. From the popup window, select which file you want to download, and the download should start automatically.
    
-   **Submit Primary Contact Change Request** - Click this link if you'd like to request a change of your primary contact. For more information, see [Submitting a Primary Contact Change Request](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_69140320346.html).
    
-   **Submit Billing/Shipping Address Change Request** - Click this link if you'd like to request a change of your address. For more information, see [Submitting a Billing/Shipping Address Change Request](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_26140325761.html).
