If a role is designed to be used by programs that integrate with NetSuite through web services, check the **Web Services Only Role** box to allow NetSuite account access but disallow UI access and privileges.

This setting prohibits a user from accessing the user interface with permissions and privileges that are created specifically for web services development, adding to the security of your integration. For more details, see [Setting a Web Services Only Role for a User](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3424894.html).
