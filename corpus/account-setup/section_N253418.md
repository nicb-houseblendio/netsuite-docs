The Transaction Numbering Audit Log lists every internal transaction number, even for standard and custom transactions that were deleted or didn't get created. Transactions that didn't get created include cash sales that fail due to problems with credit card processing. For more information about internal transaction numbers, see [Auto-Generated Transaction Numbers](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4340444343.html).

Users with the Administrator role or the **Access to transaction numbering audit log** permission can view this audit log at _Transactions > Management > Transaction Numbering Audit Log_.

This audit log shows the transaction type, number, date and time the number was assigned, and who created the transaction. Subsidiary and location also display if your auto-generated numbering is based on those.

If a transaction is deleted, you'll see the date and time it was deleted and the person who deleted it. If a transaction didn't get created, the reason displays in the Message column.

If the Use Deletion Reason feature is enabled in your account, the log also provides the reason why a user deleted a transaction and any related memo. For more information, see [Recording a Reason for Deleting a Transaction](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4338624600.html).
