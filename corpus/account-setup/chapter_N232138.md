Users with the Administrator role can enable NetSuite features on the Enable Features page.

Note:

Changes to feature settings are recorded in system notes. For more information, see [Searching System Notes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N673560.html).

#### To enable features: {#procedure_N232150}

1.  Go to _Setup > Company > Setup Tasks > Enable Features_.
    
2.  Check the boxes next to features you want to use.
    
3.  Assign any permissions related to the newly enabled features to custom roles as necessary.
    
    When you enable a new feature in your account, you must consider the associated permissions. You may need to update customized roles that you have already assigned to users to reflect the new feature's permissions. See [Customizing or Creating NetSuite Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N285937.html).
    

Note:
