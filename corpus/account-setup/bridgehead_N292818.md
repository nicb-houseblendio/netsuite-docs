The same preferences that can be set for roles also can be set by individual users for themselves only at _Home > Set Preferences_. Role-based preferences are not intended to override any preferences explicitly set by an individual user. If a user has set a preference to a value other than the system default, company default, or subsidiary default, the corresponding role-based preference is not applied when that user logs in with that role.

Some role-based preferences are also available at the company level, and in NetSuite OneWorld accounts, at the subsidiary level. A role-based preference overrides the system default setting, the corresponding company-level preference, if any, and the corresponding subsidiary-level preference, if any. Note that if a company preference has been set not to allow override, it is not available to be set as a preference on role records.

For more information, see [NetSuite Preference Levels Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N243257.html).
