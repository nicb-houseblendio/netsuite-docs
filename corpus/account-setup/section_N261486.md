Departments, Classes, and Locations are classifications that users with the Administrator role can use to identify and categorize records in their NetSuite accounts. You can also define classifications for your organization's needs by creating custom segments. Classifications help you organize data and keep it accurate.

To use each classification, you must enable the feature and then set up records. After you've set up classification records, you can use them to identify other records in your NetSuite account. For example, you can enable the Departments feature and then create a record for each department. You can select a department on each employee record or select a location on each sales order. You can identify employees by department and then run financial reports by location.

To add more custom classification fields similar to class, department, and location, use the Custom Segments feature. You can create an unlimited number of custom segments and add them to specific record types. For more information, see [Custom Segments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4313464438.html).

If you use NetSuite OneWorld, subsidiaries are the primary classification used to organize your records. You can use departments, classes, locations, and custom segments along with subsidiaries. If you use these classifications, you must associate them with a subsidiary. This association lets you select the department, class, location, or custom segment on the record or transaction related to that subsidiary. For more information about using subsidiaries, see [Subsidiaries in OneWorld](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N268563.html) and [Subsidiary Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N272210.html).

Also, if you plan to enable the Intercompany Time and Expense feature for NetSuite OneWorld, you'll need to determine a strategy for handling classifications on intercompany time and expenses. You can either make classifications optional for journal entries or set up global classifications that are available to all subsidiaries. If you don't have a defined strategy, errors may occur for automated intercompany adjustments. For information about using this feature, see [Enabling Intercompany Time and Expenses](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1476983.html).
