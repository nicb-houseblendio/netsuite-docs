If you use the Issue Management feature and want employees with this role to work with issues, select the issue role in the **Issue Role** field.

Administrators and Issue Administrators can access issue role types at _Setup > Issues > Issue Management > Issue Roles_. The type of issue role you select affects what employees with this role can select in the **Status** and **Assigned To** fields on issue records, depending on how you have set up issue workflow at _Setup > Issues > Issue Management > Manage Status Transitions_.
