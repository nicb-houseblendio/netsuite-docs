Enable the following feature on the **Company** subtab of the Enable Features page at _Setup > Company > Enable Features_.

| Feature | Description |
| --- | --- |
| IP Address Rules | Create access rules for employees based on the IP address of the computer used to log in. For more information, see [Enabling and Creating IP Address Rules](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4726612641.html). |
| Login Notification | Set up a notification for your users to acknowledge when the log in your account. For more information, see [Login Notification](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_56135727646.html). |
| Multiple Sessions for 2FA-Protected Users | Allow users with 2FA-protected roles to log in to your account from three different devices at the same time. For more information, see [Setting Up Simultaneous Access to Multiple NetSuite Sessions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_67135625265.html). |
| Disable Passkey as 2FA | Disallow users to use their FIDO2 passkeys instead of an authenticator app for two-factor authentication. For more information, see _Passkeys as 2FA_. |
