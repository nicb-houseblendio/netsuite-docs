If you're an Administrator, you can enable the following features on the **SuiteCloud** subtab of the Enable Features page at _Setup > Company > Enable Features_.

Note:

SuiteBundler is still supported, but it is not being updated with new features. Use SuiteCloud Development Framework to create SuiteApps from an integrated development environment (IDE) on your local computer. For more information, see [SuiteCloud Development Framework](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4702622163.html).

| Feature | Description |
| --- | --- |
| Create Bundles with SuiteBundler | Check this box to enable the packaging together of groups of customization objects so they can be shared between NetSuite accounts |
