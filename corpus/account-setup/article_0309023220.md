If you're an Administrator, you can enable the following features on the **Analytics** subtab of the Enable Features page at _Setup > Company > Enable Features_.

| Feature | Description |
| --- | --- |
| SaaS Metric Reporting | Track recurring revenue for transactions and subscriptions. You can use SaaS metrics in saved search, analytics, and the Subscription Metrics SuiteApp. For more information, see [SaaS Metric Reporting Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_6160057721.html). |
