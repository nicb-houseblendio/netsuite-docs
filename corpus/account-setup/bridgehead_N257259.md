Administrators can set the following transaction email preferences on the **Templates** subtab of the Email Preferences page at _Setup > Company > Email > Email Preferences_.

| Field | Description |
| --- | --- |
| Template Folder | In this field, select the File Cabinet folder where you want to store your email templates by default. |
| User Access Email Template | In this field, select the template to use when notifying an employee that they've been given access to your account. To add more templates to this dropdown list, go to _Setup > Company > Email > Email System Templates_, then click **New Template**. |
| Customer Center Email Template | In this field, select the template to use when notifying customers that they've been given access to the Customer Center. To add more templates to this dropdown list, go to _Setup > Company > Email > System Email Templates_ and click **New Template**. |
| Partner Center Email Template | In this field, select the template to use when notifying partners that they've been given access to the Partner Center or Advanced Partner Center. To add more templates to this dropdown list, go to _Setup > Company > Email > System Email Templates_, then click **New Template**. |
| Webstore Template Folder | Select the File Cabinet folder where you want to store templates used by the Web store for outbound email messages. |
