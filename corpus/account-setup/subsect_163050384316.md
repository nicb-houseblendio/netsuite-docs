Besides transaction types that count toward the Monthly Transaction Lines metric, NetSuite provides other transaction-related records. You can see an example of these transaction types in [SuiteCloud Supported Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/preface_3710625923.html) under **Transactions**.

Note:

For information about specific transaction types and transaction-related records, go to Transactions > Transactions Overview and click on a transaction type in the Transactions Links portlet. Then, click the **Help** button at the top of the page. An appropriate Help topic will open.
