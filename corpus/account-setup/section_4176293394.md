You can edit an existing class at any time. Any change you make will overwrite historical transactions. For example, if you change the class name from NorthEast to North East, all historical transactions for that class appear as North East.

You can delete a class only **if** there aren't any dependent transactions. If there are any historical transactions, you can't delete the class.

#### To modify a class record: {#procedure_4176294116}

1.  Go to _Setup > Company > Classes_.
    
2.  Click **Edit** next to the class you want to change.
    
3.  On the Class page, make any changes as needed.
    
4.  Click **Save**.
    

#### To delete a class record: {#procedure_4176369119}

1.  Go to _Setup > Company > Classes_.
    
2.  Click **Edit** next to the class you want to remove.
    
3.  On the Class page, in the **Actions** menu, click **Delete**.
    
4.  Click **OK** to confirm you want to delete the class.
