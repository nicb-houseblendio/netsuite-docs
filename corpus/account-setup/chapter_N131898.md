The flexible NetSuite user interface adjusts automatically to different users' business needs. For each user, NetSuite displays a variable set of tabbed pages, called a **center**, based on the user's assigned role. Each NetSuite center provides, for users with related roles, the pages and links they need to do their jobs.

Each tabbed page of each center displays a collection of real-time data called a **dashboard**. Dashboard data is displayed in a variety of dynamic data display windows called **portlets**. NetSuite lets users personalize their own dashboards, and lets administrators to publish personalized dashboards to others.

When a user logs in to NetSuite, the system determines the last used role and account, or the user's default role if indicated, and displays the associated center. If a user has more than one role assigned, their roles are displayed under the Change Roles list in the upper right corner of the page. For more information, see [Roles and Accounts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N295370.html). When a user changes roles, the interface refreshes to show a different center if needed.

NetSuite includes several standard centers. Each standard center is designed to make the most-used links available for the roles that use that center. For example, the Accounting Center's tabbed pages have data and links that are relevant for Accountants, Bookkeepers, Payroll Managers, and Clerks.

-   To review a list of standard centers and their related roles, see [NetSuite Standard Centers](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N132466.html).
    
-   To review a list of specialized centers and their related roles, see [NetSuite Specialized Centers](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0531125149.html).
    
-   To understand NetSuite 360 and the special roles that can access it, see [NetSuite 360](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4350949235.html).

If the standard centers don't meet all of your business needs, you can customize the user interface in the following ways:

-   Create custom centers with custom tabs and links. See [Creating and Editing Custom Centers](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2890334.html).
    
-   Add custom tabs to standard or custom centers. See [Creating Center Tabs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2890512.html).
    
-   Add custom links to standard or custom centers. See [Creating Center Links](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2891250.html).
    
-   Create custom roles that use custom centers. See [Customizing or Creating NetSuite Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N285937.html).
