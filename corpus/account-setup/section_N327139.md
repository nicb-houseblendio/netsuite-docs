You can assign one permission, Financial Statements, to grant the ability to run all financial statement reports. The Financial Statements permission is a Reports type permission with only a View level possible.

Users also must have the Report Customization permission to be able to customize financial statements in the Financial Report Builder and to rename, delete, or reassign financial statement layouts. The View level of this permission is sufficient.

For information about assigning permissions, see [NetSuite Permissions Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N325094.html).

For information about financial statement reports, see [Financial Statements Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N2092547.html).
