The Privacy and Compliance Dashboard in NetSuite 360 provides you with key compliance documentation. You can access Privacy and Compliance from the left panel in NetSuite 360. For information about accessing NetSuite 360, see [Accessing NetSuite 360](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N337869.html).

You can view the Oracle NetSuite Subprocessor List and the Oracle Cloud Services Strategic Subcontractor List through a Privacy Compliance Request. You can also subscribe to receive notifications whenever updates are made to these lists. To learn more about how to access Oracle NetSuite Subprocessor List and the Oracle Cloud Services Strategic Subcontractor List. To learn about how to create compliance requests, see Creating Compliance Requests.

You can request available audit reports across multiple accounting periods and coverage scopes. For detailed instructions, see Requesting an Audit Report.
