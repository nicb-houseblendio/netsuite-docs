If you're a user with the Administrator role, you can manage Text Enhance Translations preferences from the **Text Enhance Translations** subtab in AI Preferences.

With Text Enhance Translations, you can use the **Translate to** action of Text Enhance to translate content into any supported language. Text Enhance Translations uses generative AI through NetSuite, which provides context awareness when translating content. Users with a NetSuite Administrator role use Prompt Studio to customize translation prompts and Text Enhance actions.

For more information about using Text Enhance Translations, see [Text Enhance](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_2171112518.html).

Note:

Text Enhance Translations is part of Text Enhance, so the following apply:

-   To use the **Translate to** action, you also need Text Enhance enabled.
    
-   The **Translate to** action counts toward your AI usage. To view NetSuite AI Units capacity and usage for your account, see [Viewing AI Usage](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_3234529606.html).

## Enable or Disable Text Enhance Translations {#subsect_0616014810}

Note:

The Text Enhance Translations setting is enabled by default. To use Text Enhance Translations, Text Enhance must also be enabled for your account. For more information, see [Enable or Disable Text Enhance](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_3190337552.html#subsect_0204070856).

#### To disable or enable Text Enhance Translations for an account:

1.  Go to _Setup > Company > AI > AI Preferences_.
    
2.  From the AI Preferences page, click the **Text Enhance Translations** subtab.
    
3.  On the **Text Enhance Translations** subtab:
    
    -   Clear the **Enable Translations** box to disable Text Enhance Translations.
        
    -   Check the **Enable Translations** box to enable Text Enhance Translations.
        
4.  Click **Save**.
    

## Enable or Disable Text Enhance Translations for External Roles {#subsect_0616015829}

The **Enable Translations for External Roles** setting lets you control whether users with external roles can use Text Enhance to translate content. To enhance security, this setting is disabled by default. Only users with internal roles have access to Text Enhance unless you enable this setting.

The following is a list of standard external roles that can use Text Enhance Translations when this setting is enabled:

-   Customer Center
    
-   Employee Center
    
-   NetSuite Support Center
    
-   NetSuite Support Center (Basic)
    
-   Online Form User
    
-   Partner Center
    
-   Shopper
    
-   Vendor Center
    

#### To enable or disable Text Enhance Translations for external roles:

1.  Go to _Setup > Company > AI > AI Preferences_.
    
2.  From the AI Preferences page, click the **Text Enhance Translations** subtab.
    
3.  On the **Text Enhance Translations** subtab:
    
    -   Check the **Enable Translations for External Roles** box to enable Text Enhance Translations for users with external roles.
        
    -   Clear the **Enable Translations for External Roles** box to disable Text Enhance Translations for users with external roles.
        
4.  Click **Save**.
    

## Enable or Disable Translation Languages {#subsect_0616034835}

Use the **Translation Languages** list to set which languages Text Enhance users can access.

Note:

Translation languages are the _target_ languages. You don't have to set up source languages, because Text Enhance Translations figures it out from the text you enter or select.

#### To enable or disable translation languages:

1.  Go to _Setup > Company > AI > AI Preferences_.
    
2.  From the AI Preferences page, click the **Text Enhance Translations** subtab.
    
3.  On the **Text Enhance Translations** subtab, find the **Translation Languages** list. (See [Supported Languages for Text Enhance Translation](#subsect_0616044446) for details.)
    
    -   To enable a language, select it in the list.
        
    -   To disable a language, clear its selection in the list.
        
4.  Click **Save**.
    

### Supported Languages for Text Enhance Translation {#subsect_0616044446}

The **Translation Languages** list depends on your company settings:

-   If your company doesn't have the Multi-Language feature enabled, the default list shows these languages:
    
    -   English
        
    -   French
        
    -   German
        
    -   Italian
        
    -   Japanese
        
    -   Portuguese (Brazilian)
        
    -   Spanish
        
-   If your company has the Multi-Language feature enabled, the default list of available languages is based on your company's enabled languages. Text Enhance Translations supports these languages:
    
    -   Chinese (Simplified)

    -   Dutch

    -   Finnish

    -   French (Canada)

    -   Indonesian

    -   Japanese
        
    -   Korean

    -   Portuguese (Brazilian)
        
    -   Russian
        
    -   Spanish
        
    -   Swedish
        
    -   Thai
