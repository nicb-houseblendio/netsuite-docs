The number of SuiteCloud Plus licenses your account needs depends on several factors. Consider your integration concurrency needs during peak transaction periods, how many applications need to integrate, and your overall integration model when managing governance limits. When you use scheduled processors or map/reduce jobs, the number of transactions and processing time will help you decide how many queues or processors you need. If you're using CSV import, the number of files you need to import in parallel and how long they take will help you decide how many queues or threads to use.

Increasing the integration concurrency limit lets you run more parallel integration operations at one time, which increases integration transaction throughput.

Map/reduce and scheduled script processors help you batch process lots of transactions or run scheduled business processes. More processors let you process in parallel, which increases throughput and reduces processing time.

CSV import queues help you load large volumes of transactions into NetSuite using the Import Assistant. These imports can be multi-threaded to reduce the import time, and increasing CSV queues and threads lets you import more files in a shorter period of time.

Note:

Only Premium, Enterprise, and Ultimate tier accounts can buy more than one SuiteCloud Plus license. Contact your sales representative or account manager to discuss SuiteCloud Plus licenses.

Please note the following:

-   SuiteCloud Plus licensing may be offered in conjunction with service tiers. For more information about service tier offerings, see [NetSuite Service Tiers](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1539959231.html). To see how many SuiteCloud Plus licenses you have, see [Service Tier Dashboard](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0514020332.html).
    
-   The account governance limit for concurrent requests depends on your service tier and how many SuiteCloud Plus licenses you've purchased. Different service tiers have different base limits.
    
-   The SuiteCloud Processors feature is used to process map/reduce scripts and scheduled scripts. A scheduler automatically determines the job order based on priority levels, submission times, and user-defined preferences. This increases throughput, reduced wait times, and eliminates most bottlenecks. For more information about this feature, see [SuiteCloud Processors](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1498571420.html).
    
-   The REST Async Processors feature handles asynchronous requests in REST web services. For more information, see [REST Web Services Request Processing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_161251386312.html).
