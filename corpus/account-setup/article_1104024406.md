After you enter general information settings, set the currency preferences for your company.

#### To set company currency settings:

1.  Enter general information settings. For more information, see [Company General Information Settings](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1104025021.html).
    
2.  The **Currency** field is available when Multiple Currencies **is** enabled. Choose a base currency for your company. After transactions have been entered with this currency, you can't edit this field.
    
    For information about working with multiple currencies, see [Currency Management](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N1395057.html). You can format the currency on the currency record.
    
3.  The **Currency fields** field is available when Multiple Currencies **is not** enabled. Use these fields to select a currency and format how amounts appear on reports and printed transactions.
    
    1.  **Currency Locale** - Select a country to set the currency for your account. The currency locale specifies the symbol, placement, and thousands separator for currency values.
        
    2.  **Name** - Enter a unique name for the currency.
        
    3.  **ISO Code** - Enter the three-letter International Standards Organization (ISO) code for the currency.
        
    4.  **Default Exchange Rate** - Enter the exchange rate for this currency against your company's base currency. If you use OneWorld, enter the exchange rate for this currency against the base currency of the root parent subsidiary.
        
    5.  **Automatic Update** - Check the box to update currency exchange rates daily.
        
    6.  **Currency Precision** - Shows how many digits are used after the decimal point used in currency transaction. Precision can be zero or two.
        
    7.  **Inactive** - Check the box to make the currency inactive.
        
    8.  **Format Sample** - This field displays the default currency format, including the symbol, thousands separator, and decimal precision for amounts on transactions.
        
    9.  **Override Currency Format** - Check this box to override the default format for this currency. If you check this box, the Currency Locale field disappears, and you can set the Currency Symbol and Symbol Placement. For more information about currency formats, see [Customizing Currency Formats](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N1396253.html).
        
        Customized currency formats appear on the screen when viewing, editing, and creating new forms, list pages, search results, and printed documents. Customized currency formats are **not** shown in reports, or in CSV imports and exports.
        
        ![Override Currency Format box checked and currency symbol fields.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/AccountAdministration/AccountSetup/overridecurrencyformat.png)
    10.  **Symbol** - Enter the currency symbol and text to use for the currency. Include spaces if you want to separate the symbol from the value, for example, $ USD or $USD.
         
    11.  **Symbol Placement** - Choose whether the currency symbol goes before or after the number.
         
         The **Format Sample** field shows how amounts will display with your custom format.
         

Enter electronic invoicing settings for your company. For more information, see _Company Electronic Invoicing Settings_.
