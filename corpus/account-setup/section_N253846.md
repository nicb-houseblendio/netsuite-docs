On the Countries page at _Setup > Company > Countries_, you can:

-   See the list of countries you can use in NetSuite records
    
-   Click Print to print the list of supported countries
    
-   Click a **country name** to see its address template and the script that runs when users click Map links next to addresses in NetSuite.
    
-   Click **Edit** next to a country to change its address template or mapping program script (if you have permission).
    

If you're using countries in your customizations and integrations on the SuiteCloud Platform, be aware of the following:

-   SOAP web services integrations use their own country enumerations. For a list of these enumerations, see [Country Enumerations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3785183.html).
    
-   CSV imports use country names or labels, as listed in [Country Names for CSV Import](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N454670.html).
    
-   SuiteScript scripts generally use ISO country codes, which Oracle doesn't maintain. Some SuiteScript APIs may also use country names.
    
-   SuiteAnalytics Connect integrations use ISO country codes.
