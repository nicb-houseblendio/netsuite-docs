The assigned roles determine which type of license is required:

| Assigned Roles | License Type |
| --- | --- |
| Any full-licensed role (standard or custom), with or without other roles | Full Licensed User |
| Only Employee Center roles | Employee Center |
| Only Retail Clerk roles | Retail User |
| Only a single specialized role | Corresponding Specialized User |
| Specialized role + Employee Center role | Corresponding Specialized User |
| More than one specialized role or a specialized role plus any other non-employee role | Full Licensed User |

## Special Considerations for SuiteCloud Plus License {#subsect_0304103429}

If the Concurrent Web Services User feature is enabled on the user's Employee record, that user requires a SuiteCloud Plus license. For multiple entities with the same login email but differing CWSU settings, NetSuite counts the CWSU-enabled and non-enabled accounts separately for licensing purposes. For more information, see [SuiteCloud Plus Settings](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N259503.html) and [Enabling Web Services Concurrent Users with SuiteCloud Plus](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3448861.html).

## Reducing License Usage {#subsect_0304103906}

To avoid unnecessary license consumption, review user role assignments regularly and ensure that each user has only the permissions needed for their responsibilities. Remove unneeded roles or deactivate unused accounts as part of your access management process.
