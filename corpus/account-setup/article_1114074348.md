If you're an Administrator, you can enable the following features on the **Analytics** subtab of the Enable Features page at _Setup > Company > Enable Features_.

| Feature | Description |
| --- | --- |
| Tableau® Workbook Export | Enable users to export saved search and report results as Tableau® workbooks. For more information, see [Exporting Reports, Searches, and Lists](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N575321.html). |
