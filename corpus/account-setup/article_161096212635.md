See the following detailed instructions to create an advanced numbering rule.

#### To create an advanced numbering rule:

1.  Go to _Setup > Company > Auto-Generated Numbers (Administrator)_ and click the Document Numbers or Transaction Numbers subtab.
    
2.  Click the **Setup** link next to the transaction type you want to create the rule for.
    
3.  In the Advanced Numbering Rule Set, click **New Rule**.
    
4.  Type a name for the rule, using up to 32 characters.
    
5.  (Optional) Check the **Inactive** box if you want to create the rule as inactive.
    
6.  Enter the following in the Numbering section:
    
    -   Prefix
        
    -   Suffix
        
    -   Minimum Digits
        
    -   Initial Number
        
    
    The **Number Preview** field displays what the next number will look like whenever you finish editing a Numbering Format field.
    
    For more information, see [Entering the Number Format](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161096135812.html).
    
7.  In the **Sequences by Segment** subtab, select the segment to create unique sequences for. You can create unique sequences for each fiscal year, location, subsidiary, or any combination of the three. NetSuite will create a unique numbering sequence for every combination.
    
    For more information, see [Selecting the Sequences by Segment](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161096176287.html).
    
8.  On the **Criteria** subtab, select the fields NetSuite will use to determine when to number transactions. For example, you can apply a numbering rule to transactions in a certain date range, whether they're posting or not, or if they're in a specified posting period. For more information, see [Selecting the Advanced Numbering Criteria](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161096198249.html).
    
9.  Click **Save**.
    
10.  The Advanced Numbering Rules page displays a list of all rules in the rule set. Click **Edit**.
     
11.  Set the order of your rules in the rule set. Rules run in ascending numeric order. To change the order, click a rule and click Move Up, Move Down, Move To Top, or Move to Bottom. For each transaction, NetSuite uses the first rule in the rule set that matches all criteria.
     
12.  Click **Save**.
