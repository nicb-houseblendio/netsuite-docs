Administrators can set other duplicate detection preferences on the **Other Preferences** subtab of the Set Up Duplicate Detection page at _Setup > Company > Duplicate Detection_.

1.  Check the **Show Duplicate Warning Popup on Records** box if you want to show a popup warning when a user clicks **Save** and the cursor is in a duplicate criteria field.
    
    Normally, users get a warning of possible duplicates when they move from a duplicate criteria field to another field. However, if the cursor is still in a duplicate criteria field when they click **Save**, the usual warning isn't shown. Enable this preference to ensure users are still notified.
    
2.  Choose how you want to resolve duplicate records with conflicting login access. If two duplicate records both have login access but different email addresses, they're considered to have conflicting login access. The following options are available:
    
    -   **Manually**: Duplicate records with conflicting login access aren't merged. You must manually remove login access from one record before you can merge them.
        
    -   **By deleting the duplicates' access**: When you merge records, the login access of duplicate record is deleted when it's merged into the primary record.
