For some entity and CRM record types, you can let users enter numbers manually instead of using the auto-generated numbers. To let users enter numbers manually, check the Allow Override box. Be aware that letting users overwrite these numbers can create duplicates or gaps in the numbering. Use this feature with caution.

After someone manually changes a number, the next auto-generated number follows the higher number in the series.

-   For example, the latest record has auto-generated number 53 and someone manually assign 05 to a new record. The number of the next record created is 54.
    
-   For example, if you change customer record number 101 to 1001, auto-generated numbers begin at 1002.
    

Also, if you manually set a record number to a higher value, auto-generated numbers begin at the next number. Use this feature with caution.
