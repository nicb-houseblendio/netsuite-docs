Auto-generated transaction numbers are internal, gapless, and can't be changed. They're generated for each standard and custom transaction type when you save the record.

The Transaction Numbers subtab (previously called Transactions subtab), at _Setup > Company > Auto-Generated Numbers_ isn't visible by default. If you need to set up transaction type options, go to _Setup > Company > General Preferences_ and check the Show Transaction Numbering Setup box.

Important:

If you started using NetSuite in 2016.1 or later, each transaction type is automatically assigned a default prefix, the internal system name. For example, Bill uses VENDBILL. You can change or delete the default prefix if you want.

Some settings from the old Transactions subtab now appear on the new Transaction Numbers subtab. This occurs for account-based and externally generated transactions because these settings affect both document and transaction numbers. Account-based and externally generated transactions include the following:

-   Bill (Vendor Bill), Externally generated
    
-   Bill Credit (Vendor Credit), Externally generated
    
-   Bill Payment (Vendor Payment), Account-based
    
-   Check, Account-based
    
-   Credit Card Charge (Customer Credit Card), Externally generated
    
-   Credit Card Refund (CCard Refund), Externally generated
    
-   Customer Refund, Account-based
    
-   Paycheck, Account-based
    
-   Paycheck Journal, Regular
    
-   Payroll Liability Check, Account-based
    
-   Sales Tax Payment (Tax Payment), Account-based
    
-   Tax Liability Cheque (Tax Liability), Account-based
    

Settings for transaction types other than account-based or externally generated numbers were moved to the Document Numbers subtab. You can change those options on the Document Numbers subtab as needed.

If you don't have auto-generated numbering set up, document type numbers start at 1.

By default, internal transaction numbers don't appear on transaction type records or standard reports. However, you can customize any transaction type record to make internal transaction numbers visible. To display internal transaction numbers on transaction records, go to _Customization > Forms > Transaction Forms_. Find the transaction type, click Customize, and click the Screen Fields subtab. In the Label column, find Transaction Number, check the Show box, and then save. For information about customizing transaction forms, see [Custom Forms](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N2852749.html).

You can search for internal transaction numbers when the number is hidden or visible in the UI.

Successful CSV transaction imports are numbered based on the internal sequence at the time of the import.

When you copy transactions, they're numbered based on the internal sequence at that time.

Important:

In the old Transactions subtab, you could overwrite the internal number of transactions if the Allow Override box was checked for the transaction type. That could cause duplicate internal numbering in these historical transactions. In the new Transaction Numbers subtab, you can't overwrite transaction numbers, only document numbers. NetSuite doesn't renumber historical internal transaction numbers.
