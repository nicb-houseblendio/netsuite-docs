Each service tier supports a maximum number of users, file storage, and monthly transaction lines created.

Note:

If you exceed one or more service tier limits, administrators will see a banner message and receive an email notification with further instructions.

If the limit you have exceeded is File Cabinet Storage, you will be granted a 90 day grace period for this limit only. You can use this time to either optimize your current storage, or discuss service tier upgrade options with your Account Manager.

The Monthly Transaction Lines metric counts the number of transaction lines created for the previous month. A transaction records a business event. For example, a transaction could record a financial agreement between your business and a customer or vendor. It could also be an inventory adjustment or an assembly build transaction. It's likely that one transaction has multiple transaction lines that count toward your Monthly Transaction Lines metric.

Depending on the type of transaction you create, the number of transaction line items created for each transaction can differ. Transaction line item records track lots of information in your account, including services and physical inventory. The item type also affects the number of transaction line items. The line items you enter determine what changes appear in NetSuite when you process the transaction. For example, when you add line items to an invoice and save it, your inventory decreases and accounts receivable increases to reflect the account changes for that transaction.

For more information about transactions, see [Working with Transactions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N545359.html). For more information about transaction lines breakdown and analysis, see the SuiteSuccess Transaction Type Analysis Workbook SuiteApp. For details on installing SuiteApps, see [SuiteApp Installation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1540236668.html).
