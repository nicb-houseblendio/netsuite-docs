You can use the Locations feature to track inventory, employees, and transactions for different company locations. If you used classes for this before, you can convert all your class information to location information.

When you use this feature, all class are converted to locations, including historical transactions. On financial reports that show classes or locations, values that used to appear on class now appear on location.

You can't convert classes to locations if you already have locations in the system. You need to remove existing locations first. Each class can have only one subsidiary before being converted to locations.

Warning:

The conversion process overrides existing locations, deletes all class information, and is **irreversible**.

#### To convert classes to locations: {#procedure_N262907}

1.  Go to _Setup > Company > Convert Classes_.
    
2.  To convert your classes to locations, click **Save**.
    
3.  To view your new locations, go to _Setup > Company > Locations_.
