Users with the Administrator role can change record and transaction names from the NetSuite defaults to terms that fit your company. On the Rename Records/Transactions page, you can also change account type names. For examples of the different areas of this page, see [Sections of the Rename Records/Transactions Page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4622199203.html).

By changing records and transaction names, your employees don't have to adjust to NetSuite terms. Instead, NetSuite adapts to the terms they're used to using.

When you rename records or transactions, those names update in most places in NetSuite. You can go back to the Rename Records/Transactions page to switch them back or enter a new term.

-   [Renaming Records and Transactions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1124115113.html)
    
-   [Sections of the Rename Records/Transactions Page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4622199203.html)
    

## Notes and Tips for Renaming Records and Transactions {#bridgehead_4266932746}

Keep the following details in mind when renaming records or transactions.

-   You may see internal tags in translated record and transaction names in the user interface. For example, instead of Record you may see {#Record#}. If you find these, please contact NetSuite Customer Support so that we can make a correction in a future release.
    
-   In the Help Center, if you search for a renamed record or transaction, the search results offer to search for the default name too. For example, you rename 'estimate' to 'quote' and search for 'quote.' If there are fewer than 10 search results, you're prompted to search for 'estimate.' Click the link to search for 'estimate' instead.
    
-   Don't rename records to standard NetSuite record type names or reuse the same name for more than one type. For example, don't rename Customer to Partner or use Client for two different record types.
    
-   Name changes on the Rename Records/Transactions page apply to the Language preference you currently have set at _Home > Set Preferences_ only, not to every language. You need to switch your Language preference to each language your account uses and repeat the renaming. If you miss a language, users see the original names when they select that language.
    
-   Field labels on existing custom forms don't update when you rename records or transactions. You need to edit the labels manually on the custom forms.
    
-   Name changes apply to standard NetSuite elements (standard records, transactions, and page names), but not to elements you've customized. For example, if you rename 'Customer' to 'Client', a custom center tab called 'Customer' doesn't change.
