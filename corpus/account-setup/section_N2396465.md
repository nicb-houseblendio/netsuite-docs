Use NetSuite SuiteFlow to create custom approvals workflows. You can create more flexible transaction approval processes, such as non-sequential approvals or conditional routing. For example, you can set up a workflow that requires action from specific employees, shows buttons on forms at certain stages, or automatically send email based on specific actions.

To use a custom SuiteFlow workflow, check the box for the transaction type on the Approval Routing subtab of Accounting Preferences and then set up the approval workflow.

You don't need to enable Approval Routing to use this workflow. To learn more, see [Enabling SuiteFlow](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1489429767.html).
