Prompt Studio lets you manage generative artificial intelligence (AI) prompts and Text Enhance actions in NetSuite. Generative AI prompts are the instructions given to a large language model (LLM). For Text Enhance, prompts give the LLM detailed instructions for completing a Text Enhance action. In SuiteScript code, the SuiteScript Generative AI APIs (N/llm module) methods send prompts to the LLM and get its responses.

Watch the following help video for a general overview of Prompt Studio.

<a id="kaltura_player_0"></a>

With Prompt Studio, you can:

-   Create custom Text Enhance actions and their prompts for your company's account. See [Create Custom Text Enhance Actions and Prompts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_7173149473.html) for more details.
    
-   Override standard Text Enhance actions for your company's account. See [Customize System Text Enhance Actions and Prompts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_9173930050.html) for more details.
    
-   Create and manage generic prompts for your SuiteScript code. Instead of hard coding prompts in your SuiteScript code, you can reference a prompt by its internal ID or script ID. For more information about the N/llm module methods that use Prompt Studio prompts, see [llm.evaluatePrompt(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0115064704.html) and [llm.evaluatePrompt.promise(options)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_81065603726.html).
    
-   Create and manage AI-related SuiteCloud Development Framework (SDF) custom objects. Prompt Studio supports two SDF custom objects: `prompt` (an object that represents a prompt) and `textenhanceaction` (an object that represents a Text Enhance action). You can download these SDF custom objects as XML definitions and use them in your SDF projects. For more information, see [Prompts as XML Definitions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0325112241.html) and [Text Enhance Actions as XML Definitions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0325112302.html).
    

For more information about using Prompt Studio, see [Manage Prompts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_231233812.html) and [Manage Text Enhance Actions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_3231255264.html).

You can use Prompt Studio only if your NetSuite account supports generative AI.

For more details, see [Generative AI Feature Availability in NetSuite](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_3132707887.html).

Note:

To learn more about the generative AI models, see the SuiteAnswers article [LLM Mapping for Generative AI Features](https://suiteanswers.custhelp.com/app/answers/detail/a_id/1023335). Be aware that you must be logged in to NetSuite to access articles in SuiteAnswers.
