In the Sequences by Segment subtab, select any combination of the following segments to use in your advanced numbering rules:

-   Fiscal Year
    
-   Subsidiary
    
-   Location
    

Advanced Numbering creates a unique sequence for each combination you select. For example:

-   If you select fiscal year, NetSuite will generate a unique numbering sequence for every fiscal year (1 sequence for each fiscal year).
    
-   If you select fiscal year and subsidiary, NetSuite will automatically generate a unique sequence for each subsidiary every fiscal year.
    

The following expressions in the number format generate additional numbering sequences by segment value:

-   ${YYYY\_START} or ${YY\_START}
    
-   ${YYYY\_END} or ${YY\_END}
    
-   ${location}
    
-   ${subsidiary}
    

Expressions tied to calendar year, including ${YYYY} or ${MM}, aren't connected to the fiscal year segment.

For more information about using expressions with Sequences by Segment, see [Entering the Number Format](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161096135812.html) and [Using Fiscal Year Expressions with Advanced Numbering Rules](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161096237628.html).

For the next step in the Advanced Numbering workflow, see [Selecting the Advanced Numbering Criteria](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161096198249.html).
