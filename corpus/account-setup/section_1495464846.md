If you have the Administrator role, you can view the status and history of all the bulk processing jobs in your account.

Go to _Setup > Company > Company Management > Bulk Processing Status List_ to view a list of bulk processing jobs. The columns that appear on this list include submission ID, submission status, percent complete, result, message, date created, and created by. Many of these columns also act as filters, so you can narrow the list to the processing jobs you want to see.

Available filters include the bulk processing type, submission status, result, and who created the bulk processing job. You can use selectors to filter the bulk processing jobs by creation date and choose how you want the list displayed.
