Use the Auto-Generated Numbers permission to control who can use this feature. This permission lets you decide who can access the Set Up Auto-Generated Numbers page and other Advanced Numbering forms. This permission has three levels:

-   **View** - Users can see all pages where advanced numbering is defined. Examples include the Auto-Generated Numbers page, the Advanced Numbering Rule Set page, and the Advanced Numbering Rule page.
    
-   **Edit** - Users can add and edit advanced numbering rules.
    
-   **Full** - Users can add and edit advanced numbering rules and enable or disable the Advanced Numbering feature.
    

When you use Advanced Numbering, every transaction has an Applied Rules subtab that displays the following information:

-   The date NetSuite applied the rule
    
-   A Rule Type field that shows which feature applied the rule
    
-   An action log link to additional feature-specific information
