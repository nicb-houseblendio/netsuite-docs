The Store Manager and Intranet Manager roles are part of the E-Commerce Management Center. Users assigned these roles can set up your website, configure your domain, and preview the site on the Setup tab.

For more information about the different options available for setting up and building a website, see [Commerce](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/set_N2453322.html).

The Web Site page also appears in this center. It has portlets you can set up to display various statistics to help you see how well your website is doing. The E-Commerce Management Center - Links portlet provides another way to access the same items listed in the menu on the Web Site page.
