The Custom Preferences subtab on the General Preferences page, available at _Setup > Company > Preferences > General Preferences_, includes preferences you can use as parameters for SuiteScript. If you're not using these features, you may not see this subtab.

For information about setting up and using these preferences, see [Creating Script Parameters](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N2999459.html).
