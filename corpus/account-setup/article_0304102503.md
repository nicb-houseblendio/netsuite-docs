User licenses control access to NetSuite features for individuals in your organization. Each user who needs to interact with NetSuite in any capacity must be assigned an appropriate license. NetSuite provides several license types to match different roles and usage patterns. Understanding how user licenses are counted and assigned helps you manage compliance and optimize costs.

For more information, see the following topics:

-   [Overview of User License Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0304103113.html)
    
-   [How NetSuite Counts User Licenses](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0304103142.html)
    
-   [Role Assignment and License Consumption](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0304103817.html)
