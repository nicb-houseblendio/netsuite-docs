If you're a user with the Administrator role, you can use the **Text Enhance** subtab of the AI Preferences page to manage Text Enhance preferences.

Text Enhance is a NetSuite feature that uses generative AI to help you write business content.

For more information about using this feature, see [Text Enhance](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_2171112518.html).

See the following sections for more information about managing Text Enhance preferences:

-   [Enable or Disable Text Enhance](#subsect_0204070856)
    
-   [Enable or Disable Text Enhance for External Roles](#subsect_0424065140)
    

Text Enhance uses NetSuite AI Units. To view NetSuite AI Units capacity and usage for your account, see [Viewing AI Usage](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_3234529606.html).

## Enable or Disable Text Enhance {#subsect_0204070856}

Note:

Text Enhance is enabled by default.

#### To disable or enable Text Enhance for an account:

1.  Go to _Setup > Company > AI > AI Preferences_.
    
2.  From the AI Preferences page, click the **Text Enhance** subtab.
    
3.  On the **Text Enhance** subtab:
    
    -   Clear the **Enable Text Enhance** box to disable Text Enhance.
        
    -   Check the **Enable Text Enhance** box to enable Text Enhance.
        
4.  Click **Save**.
    

## Enable or Disable Text Enhance for External Roles {#subsect_0424065140}

The **Enable Text Enhance for External Roles** setting lets you control whether users with external roles can use Text Enhance. To enhance security, this setting is disabled by default. Only users with internal roles have access to Text Enhance unless you enable this setting.

When this setting is enabled, the following standard external roles can use Text Enhance:

-   Customer Center
    
-   Employee Center
    
-   NetSuite Support Center
    
-   NetSuite Support Center (Basic)
    
-   Online Form User
    
-   Partner Center
    
-   Shopper
    
-   Vendor Center
    

#### To enable or disable Text Enhance for external roles:

1.  Go to _Setup > Company > AI > AI Preferences_.
    
2.  From the AI Preferences page, click the **Text Enhance** subtab.
    
3.  On the **Text Enhance** subtab:
    
    -   Check the **Enable Text Enhance for External Roles** box to enable Text Enhance for users with external roles.
        
    -   Clear the **Enable Text Enhance for External Roles** box to disable Text Enhance for users with external roles.
        
4.  Click **Save**.
