Administrators can enable the following features on the **Items & Inventory** subtab of the Enable Features page at _Setup > Company > Enable Features_.

| Feature | Description |
| --- | --- |
| Drop Shipments & Special Orders | Ship items directly from your vendor to your customer. |
| Matrix Items | Track inventory and pricing separately based on item options, like tracking shirts by color and size. |
| Multiple Vendors | Manage procurement from multiple vendors and track vendor details like vendor name, item code, and purchase price. |
| Gift Certificates | Sell gift certificates to customers in set or variable amounts. When they buy a gift certificate, they'll enter recipient information, and the message, amount, and code are emailed to the recipient. Gift certificates apply to the total order amount and you can reuse them if there's a remaining balance. |
| Sell Downloadable Files | Enable download item records and online forms with downloads. Attach files to item records for customers to buy and download from your web store. Online forms with downloads let you offer free downloads to leads when they give you their contact information. You can also use this feature to share files with customers for free. For example, you can attach terms of service to their record for access from the Customer Center. |
| Bar Coding and Item Labels | Create bar codes to track transactions and items, then print labels with the item's bar code. |
| Advanced Item Location Configuration | Check this box to manage item attributes by location and view only the data you need for each one. |
| Merchandise Hierarchy | Create custom merchandise hierarchies to help you analyze sales, purchases, and inventory data. |
| Personalized Catalog Views | Group web store customers and give each group a customized catalog selection. |
