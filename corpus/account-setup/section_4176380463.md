You can edit an existing location at any time. Any changes you make overwrite historical transactions. For example, if you change the location name from NorthEast to North East, all historical transactions for that location appear as North East.

You can delete a location only **if** there aren't any dependent transactions. If there are any historical transactions, you can't delete the location.

#### To modify a location record: {#procedure_4430962270}

1.  Go to _Setup > Company > Locations_.
    
2.  Click **Edit** next to the location you want to change.
    
3.  On the Location page, make any changes as needed.
    
4.  Click **Save**.
    

#### To delete a location record: {#procedure_4176380463}

1.  Go to _Setup > Company > Locations_.
    
2.  Click **Edit** next to the location you want to delete.
    
3.  On the Location page, in the **Actions** menu, click **Delete**.
    
4.  Click **OK** to confirm you want to delete the location.
