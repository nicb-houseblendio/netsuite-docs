You can set up a login notification for your users to acknowledge when they log in to your NetSuite account. This feature can be used, for example, to comply with the NIST standards.

When a login notification is set in the account, the system displays a compliance message to all users when they log in. Users must acknowledge the message before accessing the account.

Users with the Administrator role can track acknowledgments, including the date and time when users acknowledged the compliance message, using the Login Audit Trail.
