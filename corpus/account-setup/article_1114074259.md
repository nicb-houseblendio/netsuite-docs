If you're an Administrator, you can enable the following features on the **Analytics** subtab of the Enable Features page at _Setup > Company > Enable Features_.

| Feature | Description |
| --- | --- |
| SuiteAnalytics Connect | Enable the SuiteAnalytics Connect feature to access and query your NetSuite data using SQL through database standards such as ODBC, JDBC, and ADO.NET. For more information, see [SuiteAnalytics Connect](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_3963845427.html). |
| NetSuite Analytics Warehouse | Configure and transfer data to the NetSuite Analytics Warehouse. You can use any data transferred with Oracle Analytics for applications. |
