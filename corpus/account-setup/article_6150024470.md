If you're a user with the Administrator role, you can manage your account's Narrative Insights preferences from the **Narrative Insights** subtab in AI Preferences.

Narrative Insights uses generative artificial intelligence (AI) to generate a concise overview of data in supported NetSuite reports and records. The feature helps you quickly understand key information without reviewing an entire report or record. For more information, see [Narrative Insights Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_135342304.html).

See the following sections for more information about managing Narrative Insights preferences:

-   [Disabling or Enabling Narrative Insights](#subsect_0105040039)
    
-   [Enabling or Disabling Narrative Insights for External Roles](#subsect_0105040554)
    

Narrative Insights uses NetSuite AI Units. To view NetSuite AI Units capacity and usage for your account, see [Viewing AI Usage](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_3234529606.html).

## Disabling or Enabling Narrative Insights {#subsect_0105040039}

Narrative Insights is enabled by default. The feature is available for accounts in supported locations and for users whose language preference is set to a supported language. For more information, see [Generative AI Feature Availability in NetSuite](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_3132707887.html).

#### To disable or enable Narrative Insights for an account:

1.  Go to _Setup > Company > AI > AI Preferences_.
    
2.  On the AI Preferences page, click the **Narrative Insights** subtab.
    
3.  On the **Narrative Insights** subtab:
    
    -   Clear the **Enable Narrative Insights** box to disable Narrative Insights.
        
    -   Check the **Enable Narrative Insights** box to enable Narrative Insights.
        
4.  Click **Save**.
    

## Enabling or Disabling Narrative Insights for External Roles {#subsect_0105040554}

The **Enable Narrative Insights for External Roles** setting lets you control whether users with external roles can use Narrative Insights. To enhance security, this setting is disabled by default. Only users with internal roles have access to Narrative Insights unless you enable this setting.

The following standard external roles can use Narrative Insights when this setting is enabled:

-   Customer Center
    
-   Employee Center
    
-   NetSuite Support Center
    
-   NetSuite Support Center (Basic)
    
-   Online Form User
    
-   Partner Center
    
-   Shopper
    
-   Vendor Center
    

#### To enable or disable Narrative Insights for external roles:

1.  Go to _Setup > Company > AI > AI Preferences_.
    
2.  On the AI Preferences page, click the **Narrative Insights** subtab.
    
3.  On the **Narrative Insights** subtab:
    
    -   Check the **Enable Narrative Insights for External Roles** box to enable Narrative Insights for users with external roles.
        
    -   Clear the **Enable Narrative Insights for External Roles** box to disable Narrative Insights for users with external roles.
        
4.  Click **Save**.
