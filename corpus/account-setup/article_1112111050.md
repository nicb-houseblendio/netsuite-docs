Important:

To use some of the employee and payroll features, you need SuitePeople HR or SuitePeople U.S. Payroll set up on your account. For more information, see [SuitePeople Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1495573671.html).

If you're an Administrator, you can enable the following features on the **Employees** subtab of the Enable Features page at _Setup > Company > Enable Features_.

| Feature | Description |
| --- | --- |
| Global Permissions | Enable direct permission assignments to employees and roles. When this box is checked, you'll see a Global Permissions subtab on the Access subtab of each employee record. |
| Advanced Employee Permissions | Check this box to use extra employee permissions. These let administrators control which fields and sublists are available to each role, and these changes apply to most parts of NetSuite. Before enabling this feature, review [Before Enabling the Advanced Employee Permissions Feature](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1519678048.html). |
