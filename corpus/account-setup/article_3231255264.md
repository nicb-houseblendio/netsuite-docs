## Accessing Text Enhance Actions in Prompt Studio {#subsect_0205012516}

You can access Prompt Studio if you're a NetSuite user with an Administrator role or another role with the Setup Prompts (ADMI\_PROMPTS) permission.

#### To access Text Enhance Actions in Prompt Studio:

1.  Go to _Setup > Company > AI > Prompt Studio_.
    
2.  Click the **Text Enhance Actions** subtab.
    
    The list of Text Enhance actions is displayed.
    

## Viewing Text Enhance Actions {#subsect_0205012650}

You can view Text Enhance actions and filter the list by different properties.

#### To view Text Enhance actions:

1.  Go to the **Text Enhance Actions** tab of the Prompt Studio page. Before you filter the list, it shows all system Text Enhance action records.
    
2.  Find the Text Enhance action you want to view. You can search by name or use filters.
    
    -   **To search for a Text Enhance action by name:** Type part of or all of the Text Enhance action name in the search box.
        
    -   **To filter the Text Enhance actions list:** Click **Filters** and select one or more options to narrow it down:
        
        -   **Type**: System or Custom
            
            System Text Enhance actions, which have a negative ID number, are provided by NetSuite. You can't change or delete them.
            
            Custom Text Enhance actions, which have a positive ID number, are Text Enhance actions created by account users or installed with SuiteApps.
            
        -   **Language**: Search by the Text Enhance action's language.
            
        
        Note:
        
        Your filter selections are saved. You can reset the filters by clicking **Clear All Filters**.
        
3.  Click the Text Enhance action name to view its record.
    

## Creating New Text Enhance Actions {#subsect_0205013515}

There are two ways to create a new Text Enhance action.

#### To create a new Text Enhance action from outside Prompt Studio:

1.  Go to _Setup > Company > AI > Prompt Studio_ and click the **Text Enhance Actions** tab.
    
2.  Click **Create Text Enhance Action**.
    
3.  On the Text Enhance Action page, fill in the details. For more information, see [Editing Text Enhance Actions](#subsect_0205013557).
    
4.  Click **Save**.
    

#### To create a new Text Enhance action within Prompt Studio:

1.  Click the **Text Enhance Actions** tab.
    
2.  Click **Create Text Enhance Action**.
    
3.  On the Text Enhance Action page, fill in the details. For more details, see [Editing Text Enhance Actions](#subsect_0205013557).
    
4.  Click **Save**.
    

## Editing Text Enhance Actions {#subsect_0205013557}

You can only edit custom Text Enhance actions.

#### To edit a Text Enhance action:

1.  Go to _Setup > Company > AI > Prompt Studio_ and click the **Text Enhance Actions** tab.
    
2.  Find the Text Enhance action you want to edit. For more information, see [Viewing Text Enhance Actions](#subsect_0205012650).
    
3.  Click the Text Enhance action's **Edit** link. The Text Enhance Action page displays the action's details.
    
4.  Complete the Text Enhance action's details:
    
    1.  Fill in the **Basic Fields**:
        
        -   **Name:** Give the Text Enhance action a descriptive name. The name is what NetSuite users will see in Text Enhance menus. If you're making Text Enhance actions for full and partial Text Enhance that will do the same thing, you can use the same name for both.
            
        -   **Script ID:** Enter a unique ID to reference the Text Enhance action in scripts. When you save, the prefix **custteaction** is added to the script ID.
            
    2.  Fill in the **Target Fields**:
        
        -   **Language:** Select the language for the Text Enhance action. This setting determines which Text Enhance actions are available to select for the prompt. For example, if the prompt language is Japanese, only Text Enhance actions with Language set to Japanese are displayed in the prompt's Action menu.
            
        -   **Is Partial:** Optionally, select this option to create a partial Text Enhance action. Partial Text Enhance actions display in a popup menu when you select text in a field with Text Enhance.
            
5.  Click **Save**.
    

## Testing a Text Enhance Action {#subsect_0205013629}

For best results, test the Text Enhance action and its prompt before you activate it in your account.

#### To test a Text Enhance action:

1.  In Prompt Studio, test the prompt that uses the action. For more information, see [Testing a Prompt](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_231233812.html#subsect_0205011213).
    
2.  Go to the record and field where the Text Enhance action is set up, then test the action there. To test Text Enhance actions in other languages, you'll first need to change your language in user preferences to match the action's language. For more information, see [Choosing a Language for Your NetSuite User Interface](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N479109.html).
    

## Deleting Custom Text Enhance Actions {#subsect_0317052637}

You can delete custom Text Enhance actions that your account users create. You can't delete system Text Enhance actions or custom Text Enhance actions installed with SuiteApps. When you delete a custom Text Enhance action, all prompts that use the Text Enhance action are also deleted.

#### To delete a custom Text Enhance action:

1.  Find the Text Enhance Action in the list and select it, or open the Text Enhance Action record.
    
2.  On the Text Enhance Action page, click **Delete**.
    

## Viewing System Notes for a Custom Text Enhance Action {#subsect_0318051623}

You can view system notes for custom Text Enhance Action records. Text Enhance Action records are supported by System Notes v2. For more information, see [System Notes v2 Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158108495822.html).

System notes update in the background, so there may be a short delay between an action occurring and its details being shown in the system notes.

#### To view system notes for a custom Text Enhance action:

1.  Open the Text Enhance action.
    
2.  Click **System Notes**.
    
    The System Notes page is displayed for the Text Enhance Action record.
