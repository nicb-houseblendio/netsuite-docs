Set up the Support Center by specifying how you want to use the Customer Service feature and creating case issues, types, origins, rules, and territories.

For more information, see [Setting Up Case Management](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N2421072.html). In particular, see [Setting Up Support Checklist](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2421296.html).
