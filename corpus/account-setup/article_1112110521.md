Important:

To use some of the employee and payroll features, you need SuitePeople HR or SuitePeople U.S. Payroll set up on your account. For more information, see [SuitePeople Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1495573671.html).

If you're an Administrator, you can enable the following features on the **Employees** subtab of the Enable Features page at _Setup > Company > Enable Features_.

| Feature | Description |
| --- | --- |
| Payroll | Pay your employees through SuitePeople U.S. Payroll, calculate wages, deductions, and liabilities, and always have the latest tax data. This feature only supports U.S. payroll. Note: Enabling this feature creates a system-generated Payroll Adjustments account. |
| Service Printed Check and Stubs | Use your payroll service provider to print check stubs. |
| Paycheck Journal | Let SOAP web services integrate with external payroll systems or build custom payroll solutions with SuiteScript. This works for payroll in any country and for non-U.S. subsidiaries in OneWorld accounts. |
