Important:

Multi-Book Accounting is only available in NetSuite OneWorld. Contact your sales or account representative to learn more about Multi-Book Accounting. You need help from NetSuite Professional Services to set up this feature.

Administrators can enable the following features on the **Accounting** subtab of the Enable Features page at _Setup > Company > Enable Features_.

If the feature creates system-generated accounts when enabled, the accounts created are included in the descriptions. For a complete list of system-generated accounts, see [Feature-Specific, System-Generated Accounts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4078513386.html).

| Feature | Description |
| --- | --- |
| Adjustment Only Books | Check this box to enable adjustment-only accounting books. Adjustment-only books let you post book-specific adjustments to a secondary, adjustment-only book at closing. They're a simplified version of multi-book accounting, and you don't need the full Multi-Book Accounting feature to use them. |
| Full Multi-Book Accounting | Check this box to use multiple accounting books to manage your business. For more information, see [Multi-Book Accounting Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_3831567542.html). |
| Chart of Accounts Mapping | Check this box to allow different account values to be used across accounting books. You must also check Multi-Book Accounting. For more information, see [Chart of Accounts Mapping](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3851620232.html). |
| Foreign Currency Management | Check this box to manage foreign currency transactions automatically across accounting books. You must also check Multi-Book Accounting. Enable this feature on the Company subtab. For more information, see [Foreign Currency Management](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3851620590.html). |
| Revenue and Expense Management | Check this box to recognize revenue and amortize expenses per accounting book. You must also check Multi-Book Accounting. For more information, see [Revenue and Expense Management](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3851620883.html). |
| Extended Accounting Period Close Process | Check this box to use independent closure of accounting periods by accounting book. You must also check Multi-Book Accounting. For more information, see [Accounting Book Period Close Management](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4308385929.html). |
