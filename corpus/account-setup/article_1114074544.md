If you're an Administrator, you can enable the following features on the **Analytics** subtab of the Enable Features page at _Setup > Company > Enable Features_.

| Feature | Description |
| --- | --- |
| Supply Chain Predicted Risks | Receive warnings about potential purchase order risks using the predicted risks portlet with the supply chain control tower. |
