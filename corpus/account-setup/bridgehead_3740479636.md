Administrators can enable these tax features and install related SuiteApps on the **Tax** subtab of the Enable Features page at _Setup > Company > Enable Features_.

| Feature | Description |
| --- | --- |
| Advanced Taxes | Use the Advanced Taxes feature. This feature enables you to use tax schedules to track taxes for each nexus in which your company is required to pay taxes. Warning: If you enable Advanced Taxes, then you can't disable later. For more information, see [Advanced Taxes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N1803438.html). |
| EU One Stop Shop | Check this box if you're registered for the EU One Stop Shop (OSS) VAT scheme. The OSS feature lets you charge the right tax on B2C digital services sales based on the customer's EU country VAT rate. For more information, see [EU One Stop Shop (OSS)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4163851800.html). |
| SuiteTax | Check this box to define different tax engines for different tax jurisdictions and see tax details on each transaction. For more information, see [General SuiteTax Topics](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4283850851.html). |
| Related SuiteApps
-   International Tax Reports
-   Tax Audit Files
-   Withholding Tax
-   Supplementary Tax Calculation
-   SuiteTax Engine

 | For more information about installing the tax SuiteApps, see [Taxation Features Provided by SuiteApps from NetSuite](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3740493324.html). |
