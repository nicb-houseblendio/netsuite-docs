You can find a list of public and private events on the Events page at Activities > Scheduling > Events. Note that the list only displays events where you're listed as an attendee, no matter who owns the event and regardless of the event's access settings. If you want to see a list that includes events where you're not an attendee, you can run a defined search.

#### To search event records: {#procedure_1559216848}

1.  Go to Activities > Scheduling > Events > Search.
    
2.  Define at least two search filters. You can choose more than one option from each filter. To choose multiple options, click the names while holding the Ctrl key.
    
    Important:
    
    If you only set the Date filter, you'll see only the events which you're invited to. Add more filters to expand the search.
    
3.  Click Submit.
    

For more information about running simple searches in NetSuite, see [Defining a Simple Search](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N645582.html).
