If an event occurs on a regular basis, such as weekly, monthly, or on a specific day of the month, you can set a recurrence pattern for the event. The event appears on the calendar on the dates when it occurs.

#### To make an event occur more than one time: {#procedure_N503096}

1.  On the event record, click the **Recurrence** subtab.
    
2.  Select how often this event should occur:
    
    -   **Daily** - Enter the interval between days if this event is every day or every few days, or select every weekday if this event is every day except Saturdays and Sundays.
        
        Enter 1 as the interval if this event is every day, for example, or enter 2 if the event repeats every other day.
        
    -   **Weekly** - Enter the number of weeks between events, and pick the day of the week the event repeats.
        
    -   **Monthly** - If the event falls on the same date every month or every few months, enter the date it repeats and the number of months between events.
        
    -   **Yearly** - If this event takes place one time a year, select the month and day of the event, or select the week, day and month.
        
3.  In the **End By** field, set the date when this event stops recurring.
    
4.  If the event continues indefinitely, check the **No End Date** box.
    
5.  If you need resource materials for this event, click the **Resources** subtab. For more information, see [Using Resource Records on Events](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N503366.html).
    
6.  Click **Save** to save the event.
    

To edit a recurring event, go to the calendar in NetSuite and click the event link. Select the occurrence or series.

Invitees can decline either the entire series of events or specific dates in the series.

Note:

If you change your time zone preference at Home > Set Preferences > Activities and then edit an event created in your original time zone, you may need to review the recurrence settings for that event to ensure they're set properly before saving your changes.
