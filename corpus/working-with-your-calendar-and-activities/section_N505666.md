Only an event's organizer can cancel or delete an event.

When canceling an event, you can use the event record to alert attendees and to update the event's status. If your event is recurring, you can choose to cancel one instance or cancel the entire series of events.

Canceled and deleted events are removed from the calendar unless you enable the Show Canceled Events option in your portlet setup. For more information, see [Calendar Portlets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4086195407.html).

Note:

To edit events from the calendar, make sure you've checked the Edit Activities from Calendar box on the Activities subtab at Home > Set Preferences.

For more information, see the following:

-   [Canceling Events](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N505886.html)
    
-   [Deleting an Event](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N506152.html)
    

Note:

Administrators can delete events in bulk for employees who are no longer with your company. See [Mass Deleting an Employee's Events](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N506354.html)
