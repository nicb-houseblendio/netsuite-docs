You can schedule an event through an event record or by using the Scheduler portlet. The Scheduler is convenient when organizing an event for a group. You can click an event link on your calendar to make changes if you need to.

For more information about scheduling events, see the following:

-   To understand how to enter information about an event record, read [Creating a New Event Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N501988.html).
    
-   To learn how to invite a group of people to an event, read [Using the Event Scheduler Portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N502460.html).
    
-   To find out about keyboard shortcuts, managing conflicting events, and marking events as private, see [Event Scheduling Notes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N502623.html).
    
-   To add a resource to an event, read [Using Resource Records on Events](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N503366.html).
    
-   To learn how to cancel an event, or how to remove it from your calendar, read [Canceling or Deleting Events](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N505666.html).
