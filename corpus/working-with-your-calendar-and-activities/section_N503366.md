Resources can be anything from conference rooms to speaker phones that you use within your company for meetings, and conferences. In NetSuite, you create resource records to reserve these items.

You must use the Resources subtab on the event record to reserve a resource for an event. If someone else creates an event for the same time, and tries to reserve the same resource, the resource shows as busy.

For information about using resource records, see the following:

-   [Creating a Resource](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N503484.html)
    
-   [Reserving Resources for Events](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N503835.html)
