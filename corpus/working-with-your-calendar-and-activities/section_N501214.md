In NetSuite, you use event records to reserve time on your calendar for appointments and meetings. When you create an event, you're the owner. If you're invited to an event and you accept, you're an attendee. You can click on an event displayed on your calendar to see more information about it, such as the location and a list of the people invited.

![Event page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteBasics/Calendars_EventPage.png)

Read the topics below to learn more about working with events:

-   [Scheduling Events](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N501467.html) describes how to create new event records and how to use the Scheduler portlet to schedule events.
    
-   [Sending Event Invitations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N502840.html) describes how to send an email invitation with details about the event, including the date, time, and location.
    
-   [Setting Up Recurring Events](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N503084.html) describes how to create a record for an event that occurs on a regular basis, such as a weekly or monthly meeting.
    
-   [Using Resource Records on Events](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N503366.html) describes how to use event records to reserve certain resources, such as a conference room or a speaker phone.
    
-   [Tracking Time for Events](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N503967.html) describes how to keep track of time spent on events for purposes of reporting and billing. Note that you can only track time on events if you use the Tracking Time for CRM feature.
    
-   [Responding to Event Invitations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N504722.html) describes how to accept, decline, or mark an event invitation as tentative.
    
-   [Setting Up Event Reminders](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N505146.html) describes the different types of event reminders and how to set them up when you edit an event record or respond to an event invitation by email.
    
-   [Canceling or Deleting Events](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N505666.html) describes the difference between canceling and deleting events, as well as how to cancel one-time and recurring events.
    
-   [Searching Event Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1559218597.html) describes how to set filters and find events that aren't listed on your Events page.
    
-   [Sharing Your Calendar with iCal-Compatible Devices and Applications](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3930228959.html) explains how to share your NetSuite calendar with Outlook, and iOS and Android devices.
