Time Tracking for CRM lets you track time spent on events and bill that time to customers, if needed. Before you can use this feature, an administrator must enable the Time Tracking for CRM feature. See [Enabling Time Tracking for CRM](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N902265.html#bridgehead_4351562768).

#### To track time on event records: {#procedure_N503995}

1.  Go to _Activities > Scheduling > Events_.
    
2.  On the **Events** list, click the event for which you want to track time.
    
3.  On the Event record, click the **Time Tracking** subtab.
    
    Note:
    
    If any case, task, or event record has more than 9500 time entries to display on the Time Tracking subtab, all events display a static list of time entries. You can't edit entries directly from the list.
    
4.  Click **New Time**.
    
    A new time transaction window opens.
    
5.  Your name is selected in the **Employee** field by default. You can select other employees or vendors here.
    
    Note:
    
    For private events, only employees and vendors listed as attendees on the event record can track time for the event.
    
6.  Enter information for this time transaction.
    
    For more information about entering time for Time Tracking, see [Entering a Time Transaction](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N904108.html).
    
    For more information about entering time for Timesheets, see [Timesheets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3891941390.html).
    
7.  When you've finished, click **Save**.
    

If the **Billable** box is checked, you can bill the customer for this time on the **Billable Time** subtab when you create an invoice. You can view reports for time spent on cases, tasks and events on the Reports tab, under the Project/Time Tracking heading.

All employee names display on the **Time** subtab by default.

Note:

For instructions on how to limit employees' ability to enter time records, see [Restricting Employee Time Tracking Entries](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N898879.html).
