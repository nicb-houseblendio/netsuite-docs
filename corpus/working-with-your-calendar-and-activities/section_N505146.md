Event reminders are sent either as email messages, or as popup messages in NetSuite. Reminders show the day, date, time, title and location of the upcoming event.

Event reminders are helpful when an event is scheduled far in advance.

When you get a popup reminder, you can do the following:

-   Click **Dismiss** to close the window
    
-   Click **Go to Event** to open the event record in a new window.
    
-   Click **Snooze** to select the amount of time before you want to be reminded again.
    

By default, reminders have audio. You can change this preference, and set other preferences for event reminders on the Activities subtab at _Home > Set Preferences_.

When you're logged in to NetSuite with your default role, the preference you set for Default Reminder Type determines the type of reminder you get for events. If you're not logged in with your default role, then the type of reminder you get is set by a company-wide preference your account administrator chooses. For more information, see [Personal Preferences for Activities](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N482375.html).

You set event reminders when you create or edit an event, or when you accept or tentatively accept an event invitation. For instructions, see the following help topics:

-   [Setting Up Event Reminders when Creating or Editing Events](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N505393.html)
    
-   [Setting Up Event Reminders when Responding to Event Invitations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N505528.html)
