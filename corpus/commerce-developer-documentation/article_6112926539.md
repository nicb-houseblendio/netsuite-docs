Google will end data collection for the Google Universal Analytics (GUA) service on July 1, 2023, and the feature will be replaced with Google Analytics 4 (GA4). GA4 support comes standard with SuiteCommerce, SuiteCommerce MyAccount, and SuiteCommerce Advanced (SCA) versions 2022.2 and later.

For earlier versions of SCA, you can implement GA4 support by following the instructions provided in the following guides. Be sure to follow the instructions for the version of SCA you have implemented.

| SCA Implementation | Instructions |
| --- | --- |
| 2022.1 2021.2 2021.1 2020.2 2020.1 2019.2 | [Enable Google Analytics 4 (SCA 2019.2 - 2022.1)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1129114324.html) |
| 2019.1 2018.2 Aconcagua Kilimanjaro Elbrus Vinson | [Enable Google Analytics 4 (SCA Vinson - 2019.1)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1129122348.html) |
| Mont Blanc Denali | [Enable Google Analytics 4 (Denali - Mont Blanc)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1129124501.html) |

Note:

Do not implement GA4 if you use GA4 with Google Tag Manager (GTM) because this causes duplicate tracking results. See [Google Tag Manager](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4546835898.html) for information about GTM.
