Views are JavaScript files that provide instructions about how to build an HTML page, including instructions for which template to use. Views also handle data transfer to and from templates. For more information about views and templates, see [Anatomy of an Extension](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161858972640.html).

When developing an extension, you can create views or add child views to a parent view to add additional functionality. When creating a view, you should use one of the existing base classes in the extensibility API. This section describes how to use the Extensibility API to complete the following tasks for views in an extension:

-   [Create a View](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1521747570.html) - explains how to implement a new view for your extension.
    
-   [Add a Child View](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1519605655.html) - explains how to add a custom child view to a parent view in the Product Details Page, Product List Page, Cart, Layout, or Checkout components using the Extensibility API .
    
-   [Replace a Child View](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1519606173.html) - explains how to replace an existing view with a custom view in an extension.
    

For more information on view architecture, see [Views](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4307439828.html).
