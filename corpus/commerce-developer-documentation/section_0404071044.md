This object contains ACH payment information.

| Field Name | Field Type | Description | In Get Functions? | In Set Functions? |
| --- | --- | --- | --- | --- |
| internalid | string | Internal ID of the ACH bank account | yes | yes |
| mask | string | Masked account number | yes | no |
| bankname | string | Bank name | yes | no |
| routingnumber | string | Routing number | yes | no |
| ownername | string | Name of the owner of the bank account | yes | no |
| accounttype | string | Type of bank account Value should be **Checking** or **Saving** | yes | no |
| limit | string | Maximum order limit in US dollars | yes | no |
