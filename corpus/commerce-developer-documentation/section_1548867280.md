Before can use an SSL certificate to secure the shopping portion of your web store under an HTTPS domain, you must set up a secure shopping domain in NetSuite. See [Set Up a Domain](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1526632554.html) for more information.

When setting up a secure domain, be aware that sites implementing Site Builder can only secure the shopping portion of the web store under a separate HTTPS domain. Site Builder sites cannot implement a single secure domain for both Shopping and Checkout applications.

When you have configured your domain, continue with the next step: [Apply Patch to Source Files](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544034478.html).
