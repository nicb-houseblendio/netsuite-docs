In some implementations of SuiteCommerce Advanced (SCA), permissions need to be changed to provide a higher level of security for the custom records created for Reference Product Reviews and Reference Product List.

These patch instructions describe how to update Product Reviews and Product List permissions so that your web store continues working properly.

## Reference Product Reviews {#subsect_0108120330}

The following patch instructions describe the steps to update the permissions for Product Reviews. Be sure to follow the instructions for your implemented version of SCA.

| Implementation | Patch Instructions |
| --- | --- |
| SuiteCommerce SCA 2024.2.10 and later | [Reference Product Reviews Patch for SuiteCommerce, SCA 2024.2.10, and Later](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0219114445.html) |
| SCA 2024.2 | [Reference Product Reviews Patch for SCA 2024.2](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0108120956.html) |
