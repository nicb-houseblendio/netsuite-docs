Before you can set up and use the SCA developer tools, you need to complete these tasks:

| Task | Description |
| --- | --- |
| Make sure the SCA SuiteApp is installed in your account. | SuiteApp installation is generally performed by your system or NetSuite administrator. This process installs all of the required application files in NetSuite. It also installs a downloadable zip file containing the source code for SCA. |
| Make sure your role enables you to deploy source files to NetSuite. | To use Gulp.js to deploy source files to NetSuite, you must use either the System Administrator role, the Store Manager role, or a custom role with the following permissions set to Full:
-   Documents and Files
-   Website (External) publisher
-   Web Services

 |
| Set up your developer environment. | To use the SCA developer tools, you first need to install the Node.js and Gulp.js utilities. For detailed instructions, see [Set Up the Commerce Developer Environment](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4183925632.html). |

After completing these tasks, you can continue setting up as described in [Download SCA Source Files](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4183926134.html).
