With the release of NetSuite 2021.1, all versions of the developer tools, including the extension, theme, and SuiteCommerce Advanced command-line developer tools, require token-based authentication. Developer tools can no longer accept NetSuite user credentials for authentication. This update to token-based authentication is required for compliance with the required Two-Factor Authentication (2FA) policy for NetSuite administrators and other highly privileged roles.

SuiteCommerce Advanced (SCA) 2020.2.4 and later releases support token-based authentication. If you cannot migrate to the latest release of SCA, you can prepare your current installation of SCA for token-based authentication as described in the following patch instructions. Be sure to follow the patch instructions appropriate for the version of SuiteCommerce Advanced you have implemented.

| Implementation | Patch Instructions |
| --- | --- |
| SCA Aconcagua, 2018.2, 2019.1, 2019.2, 2020.1, and 2020.2 | [Enable Token-Based Authentication (Aconcagua and Later Versions)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161109639471.html) |
| SCA Montblanc, Vinson, Elbrus, and Kilimanjaro Site Builder Extensions and Extensions Premium Montblanc, Vinson, Elbrus, and Kilimanjaro | [Enable Token-Based Authentication (Montblanc, Vinson, Elbrus, and Kilimanjaro)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161109634325.html) |
| SCA Denali Site Builder Extensions and Extensions Premium Denali | [Enable Token-Based Authentication (Denali)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161109447739.html) |

Note:

For all SCA versions:

-   You must enable the Token Based Authentication feature in your NetSuite account to update to token-based authentication. For more information, see [Enable the Token-based Authentication Feature](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4253254429.html).
    
-   After you complete the steps in these patch instructions, you must continue with additional updates for token-based authentication. For detailed instructions, see [Token-Based Authentication Updates for Developer Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_9132912150.html).
