With Gulp.js installed in your developer environment, you can use the commands it provides to create and manage the resources needed for your customizations. The following topics describe the Gulp.js commands available when using the Commerce developer tools:

-   [Gulp Command Reference for Theme and Extension Developer Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510956587.html)
    
-   [Gulp Command Reference for SCA Developer Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4305338128.html)
    

For more information about how the commands described in these command references play a part in development, see [What is the Development Life Cycle?](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160979747993.html)
