Important:

Each section below describes the required changes needed. Since many files are affected, and for simplicity, we have not described the detailed implementation steps here. However, you should implement these changes using the best practices of using extensions and overrides while ensuring that you do not impact previous customizations to your implementation. For more information, see [Best Practices for Customizing SCA](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4501068327.html).

In addition to making the changes described, you must create ns.package.json files and update your distro.json file for any custom modules you include the code updates in.

Note:

After creating modifications to existing modules, you also need to create a new PromocodeNotifications custom module, Updates to the distro.json file must include this module as well. See [Custom PromocodeNotifications Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1500378362.html).
