After successfully installing the theme developer tools, you can start customize existing themes and developing new themes.

There are two ways to create a custom theme:

-   By using the `create` command: This method uses the fallback theme approach that allows one-click updates.
    
-   By fetching active theme files: This method uses the currently active theme as a baseline for the new custom theme.
    

Read the following topics to learn more about customizing and developing themes:

-   [Create a Custom Theme](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_3162629949.html)
    
-   [Fetch Active Theme Files](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_5110052337.html)
    
-   [Edit the Theme Manifest](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_112420166.html)
