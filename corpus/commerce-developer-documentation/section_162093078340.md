To start developing extensions with the extension developer tools, complete the following tasks:

| Step/Task | For detailed instructions, see |
| --- | --- |
| Download and install extension developer tools | [Set Up Extension Developer Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1518824336.html) |
| Create or download files to use as the basis for your extension | 
-   [Create a Baseline Extension](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1516375394.html) (recommended if you're new to Commerce website development and want to learn best practices)
-   [Fetch Active Theme and Extension Files](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510944391.html) (if you want to customize currently active extensions)

 |
| Add modules to your extension | [Create Additional Modules for an Extension](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1516375472.html) (recommended if you're new to Commerce website development and learning best practices) |
| Develop your extension using available APIs | 

-   [Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/preface_1520641595.html)
-   [SuiteScript API](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4260857223.html)
-   [Commerce API](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2496227.html)
-   [Item Search API](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N2665337.html)

 |
| Edit the extension manifest (only necessary if you need to add new Sass or other assets) | [Edit the Extension Manifest](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1511302363.html) |
| If you haven't already done so, fetch the active theme (theme files are required to test locally and to deploy) | [Fetch Active Theme and Extension Files](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510944391.html) |
| Test your extension locally | [Test an Extension on a Local Server](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510870075.html) |
| Deploy your extension to NetSuite | [Deploy an Extension to NetSuite](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510870586.html) |
| Activate your extension | [Manage Themes and Extensions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510954484.html) |
| If you want to do more with extensions | 

-   [Create a Custom Content Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_163284068965.html) (to integrate with Site Management Tools)
-   [Create Page Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1549653144.html) (to integrate with Site Management Tools)
-   [Bundle Process for SuiteCommerce](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1527275163.html)

 |
