Important:

You should use the SCA developer tools only if you are customizing the Kilimanjaro release of SuiteCommerce Advanced (SCA) or earlier. If you are implementing the Aconcagua Release of SCA or later, the best practice is to use themes and extensions to customize your site unless your customization requires access to objects not available using the Extensibility API.

These examples show basic methods for extending SuiteCommerce Advanced (SCA) and creating your own custom modules.

Note the following information about the provided examples:

-   The module source files for SCA 2019.1 and earlier are JavaScript files with .js filename extensions. The module source files for SCA 2019.2 and later are TypeScript files with .ts filename extensions. For more information about TypeScript, see [TypeScript](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156460113000.html).
    
-   Sample scripts included in the customization examples use SuiteScript 1.0 functions and objects only. These examples do not include SuiteScript 2.0 capabilities.
