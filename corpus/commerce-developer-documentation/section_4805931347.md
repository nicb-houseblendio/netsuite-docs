This object contains information about the overall discount impact for a given item.

| Field Name | Field Type | Description | In Get Functions? | In Set Functions? |
| --- | --- | --- | --- | --- |
| discounts | Array of JSON object of type [discounts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4823324745.html) | Discounts applied to the order. | yes | no |
| total\_amount | number | Total currency amount of the discount applied to the order. | yes | no |
| total\_amount\_formatted | string | Discount amount formatted with currency symbol. | yes | no |
