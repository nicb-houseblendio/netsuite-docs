To start developing with the SuiteCommerce Advanced (SCA) developer tools, complete the following tasks.

Note:

Use the SCA developer tools only if you are customizing a site that implements the Kilimanjaro release of SCA or earlier or if you need to access objects not available using the Extensibility API.

| Step/Task | For detailed instructions, see |
| --- | --- |
| Download and install SCA developer tools | 
-   [Download SCA Source Files](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4183926134.html)
-   [Install Additional Files in the Source Directory](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4189324618.html)

 |
| Understand best practices for customizing SCA | [Best Practices for Customizing SCA](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4501068327.html) |
| Customize by extending or overriding SCA source files | [Example SCA Customizations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4515052007.html) |
| Understand how SCA source files are organized and compiled | [SCA Build Process](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4183935476.html) |
| Test your SCA customization locally | [Test SCA Customizations on a Local Server](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4305360627.html) |
| Deploy local source files to an SSP application in NetSuite and then deploy the SSP application to your site | [Deploy SCA Customizations to NetSuite](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4188899067.html) |
