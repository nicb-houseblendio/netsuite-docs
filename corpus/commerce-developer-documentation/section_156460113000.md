SuiteCommerce Advanced (SCA) source code is being migrated to TypeScript in phases. TypeScript is an open source superset of JavaScript designed to optimize development efficiency. To learn more about TypeScript, see [Typescriptlang.org](https://www.typescriptlang.org/).

Important:

Do not edit SCA source code directly. Use the SCA developer tools to override or extend existing SCA source code to create the custom functionality you want. For more information, see [Best Practices for Customizing SCA](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4501068327.html).

The code migration to TypeScript is ongoing and includes changes such as:

-   Changing filename extension from .js to .ts
    
-   Transforming module system from Asynchronous Module Definition (AMD) to a TypeScript compatible (common JavaScript) system
    
-   Implementing base class for Models
    
-   Implementing base class for Collection
    
-   Migrating Utils.ts
    
-   Migrating Case.Model
    
-   Migrating Case.Collection
    

TypeScript code compiles to common JavaScript. The `gulp local` and `gulp deploy` commands automatically compile all SCA TypeScript files to JavaScript.
