Important:

Before applying this patch, apply the patch for [Configuration Changes for Custom Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_3113611969.html).

To implement this patch, set the permissions for the `product-list.ss` and `product-list-item.ss` files and modify the `commons.js` file.

## Step 1: Set Permissions for product-list.ss File {#subsect_71131457138}

1.  In NetSuite, go to Documents > Files > File Cabinet.
    
2.  In the File Cabinet, go to Web Site Hosting Files > Live Hosting Files > SSP Applications > NetSuite Inc. - My Account X.Y.Z > Custom My Account > services.
    
    Important:
    
    Replace the string, X.Y.Z, with the version of My Account you are using.
    
3.  Next to product-list.js, click **Edit**.
    
4.  Go to the **Permission** tab and check the **Enabled** box.
    
5.  From the **Execute as Role** list, select **SC Product List**.
    
6.  Check the **Run Script Without Login** box.
    
7.  Click **Save**.
    

## Step 2: Set Permissions for product-list-item.ss File {#subsect_80131621854}

1.  In NetSuite, go to Documents > Files > File Cabinet.
    
2.  In the File Cabinet, go to Web Site Hosting Files > Live Hosting Files > SSP Applications > NetSuite Inc. - My Account X.Y.Z > Custom My Account > services.
    
    Important:
    
    Replace the string, X.Y.Z, with the version of My Account you are using.
    
3.  Next to product-list-item.js, click **Edit**.
    
4.  Go to the **Permission** tab and check the **Enabled** box.
    
5.  From the **Execute as Role** list, select **SC Product List**.
    
6.  Check the **Run Script Without Login** box.
    
7.  Click **Save**.
    

## Step 3: Modify the commons.js File {#subsect_91131705264}

You can edit the file, `commons.js`, in the NetSuite File Cabinet. See [Editing Files in the File Cabinet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N542738.html).

1.  Go to Documents > Files > File Cabinet.
    
2.  In the File Cabinet, go to Web Site Hosting Files > Live Hosting Files > SSP Applications > NetSuite Inc. - My Account X.Y.Z > Custom My Account > ssp\_libraries.
    
    Important:
    
    Replace the string, X.Y.Z, with the version of My Account you are using.
    
3.  Create a backup of the file, `commons.js`.
    
    Note:
    
    If `commons.js` does not exist in the ssp\_libraries directory, make a copy from Web Site Hosting Files > Live Hosting Files > SSP Applications > Netsuite Inc. - ShopFlow X.Y.Z > Reference My Account > ssp\_libraries > commons.js.
    
4.  In the `commons.js` file, find and replace the following line of code with the provided code sample.
    
    Find the following code:
    
                    `return session.isLoggedIn();` 
                  
    
    Replace it with the following code:
    
                    `return session.isLoggedIn3();` 
                  
    
5.  Save and deploy the file.
    

## Step 4: Confirm Custom Record ID and Access Type {#subsect_38140914660}

1.  In NetSuite, go to Customization > List, Records & Fields > Record Types.
    
2.  Click the link for the custom record type, Product Lists.
    
3.  On the Custom Record Type page for Product Lists, confirm that **ID** has the value, `customrecord_ns_pl_productlist`.
    
4.  Confirm that **Access Type** has Use Permission List selected.
    
    If the access type is not correct, select Use Permission List from **Access Type**.
    
5.  Click **Save** to save any changes you made.
    
6.  Repeat steps 1 to 5 for the following custom record type:
    
    Product Lists Items - the ID should be `customrecord_ns_pl_productlistitem` and the access type should be Use Permission List.
    

## Step 5: Add Item List Permission to View {#subsect_16141734160}

1.  In NetSuite, go to Setup > Users/Roles > Manage Roles.
    
2.  Next to the SC Product Lists role with the ID, `customrole_sc_product_lists`, click **Edit**.
    
3.  Go to the **Permissions** tab and the **Lists** subtab.
    
4.  For the permission, Items, confirm the level is set to View.
    
    If the Items permission level is not View, update the level to View, then click **Save**.
