A custom content type (CCT) lets you create custom functionality as content that you can dynamically manage using the Site Management Tools (SMT). Implementing CCTs for SCA requires two separate, but related, activities.

If you are implementing the Kilimanjaro release of SCA, you must first create a custom SCA module to contain the JavaScript, HTML, Sass, and resources required for your CCT. This topic explains how to accomplish this. The second activity involves setting up custom records in NetSuite for your custom content type using SMT.

See [Site Management Tools Custom Content Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4809772539.html) for details on setting up your CCT using Site Management Tools.

Important:

If you are customizing the Aconcagua release of SCA or later, you must create CCTs using extensions. See [Create a Custom Content Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_163284068965.html).

Note:

You must have SMT enabled in your NetSuite account to implement CCTs on your SCA website. See [Site Management Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4431874390.html#bridgehead_4431875294) for information on how to set up SMT.

This procedure explains how to:

1.  [Create a Custom Module for Your CCT](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1502915823.html).
    
2.  [Create an Entry Point File](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1502915836.html).
    
3.  [Create a View File](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1502915843.html).
    
4.  [Create a Template File](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1502915852.html).
    
5.  [Set Up Your ns.package.json and distro.json Files](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1502915859.html)
    
6.  Deploy your code to your NetSuite account.
