This object contains general settings for the order.

| Field Name | Field Type | Description | In Get Functions? | In Set Functions? |
| --- | --- | --- | --- | --- |
| itemdisplayorder | string | Ordering of items in an order | yes | no |
| outofstockbehavior | string | Behavior for out of stock items | yes | no |
| upselldisplay | string | 
-   Related Items Only
-   Upsell Items
-   Related Items and then Upsell Items
-   Upsell Items and then Related Items

 | yes | no |
