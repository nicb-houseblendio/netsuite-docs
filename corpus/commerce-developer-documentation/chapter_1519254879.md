A theme is a special type of extension that affects a domain's design and appearance (layouts and styles). Themes contain HTML templates, Sass files, and other assets that can be made available as published themes (bundled into a single SuiteApp) or deployed to a NetSuite account by on-site theme developers.

To learn more about customization options and whether developing a custom theme using the theme developer tools is the right option for your needs, see [Commerce Developer Essentials](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160978698230.html).

Note:

The only theme available to SuiteCommerce MyAccount sites is the SuiteCommerce Base Theme published by Oracle NetSuite. You can use the Base Theme as a baseline for your own theme to be compatible with SuiteCommerce MyAccount.
