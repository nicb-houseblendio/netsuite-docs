Before you get started, familiarize yourself with [Best Practices for Customizing SCA](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4501068327.html).

## Step 1: Set Permissions for checkout.environment.shortcache.ssp {#subsect_1008025913}

1.  In NetSuite, go to Documents > Files > File Cabinet.
    
2.  Go to the following location: Web Site Hosting Files > Live Hosting Files > SSP Applications > NetSuite Inc. - X.Y.Z > Development
    
    Important:
    
    You must replace the string, X.Y.Z, with the version of SCA you are using.
    
3.  Click **Edit** next to the file, checkout.environment.shortcache.ssp.
    
4.  Go to the **Permission** tab and check the **Enabled** box.
    
5.  From the **Execute as Role** list, select **Store Manager**.
    
6.  Check the **Run Script Without Login** box.
    
7.  Click **Save**.
