This object contains information used for campaign subscriptions.

| Field Name | Field Type | Description | In Get Functions? | In Set Functions? |
| --- | --- | --- | --- | --- |
| internalid | string | The internalid of the campaign subscription. | yes | no |
| name | string | Name of the customer. | yes | no |
| subscribed | boolean | Indicates whether the customer is currently subscribed to this email campaign category. | yes | yes |
| description | string | Description of the campaign. | yes | no |
