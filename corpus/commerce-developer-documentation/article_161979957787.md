When developing extensions for a SuiteCommerce website, you are likely to use one or more APIs to complete your customization. NetSuite and the SuiteCommerce framework provide the following APIs:

-   **SuiteCommerce Extensibility API** - Use the extensibility API to interact with the application layer of a SuiteCommerce website. The extensibility API consists of several components that provide access to different parts of the SuiteCommerce application. For more information, see [SuiteCommerce Extensibility API](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162990829621.html).
    
-   **SuiteScript API** - You can use the SuiteScript API to access custom records and NetSuite records, get and set record data, and perform record actions. SuiteScript 2.x is a JavaScript API that enables you to customize, extend, and process data in NetSuite. For more information, see [Use SuiteScript With Your Extension](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163338080586.html).
    
-   **Item Search API** - The item search API is a REST style API that lets you to retrieve information from item records. It returns the information in JSON format. For more information, see [Item Search API](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N2665337.html).
    
-   **Commerce API** - The Commerce API exposes a set of shopping objects and functions that you can use to develop web store customizations. For more information, see [Commerce API](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2496227.html).
