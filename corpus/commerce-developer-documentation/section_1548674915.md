This object contains a breakdown of the different types of taxes applicable to a web store shopping order. For example, in Canada, it would contain the total amount of PST and GST. The `summarytax` object is used only with tax calculations using SuiteTax. Tax calculation using SuiteTax is available only for US and Canada.

| Field Name | Field Type | Description | In Get Functions? | In Set Functions? |
| --- | --- | --- | --- | --- |
| taxTypeId | string | The ID of the type of tax. | yes | no |
| taxTypeName | string | The name of the tax type. For example, PST or GST. | yes | no |
| taxTotal | number | The total tax amount for the tax type used on the sales order. | yes | no |
