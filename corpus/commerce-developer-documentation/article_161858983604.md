After activating your extension for a domain in NetSuite, you can test your extension code on a local server for debugging purposes. When you are satisfied with your extension code, you can then deploy it to your website using the extension developer tools.

-   Test an extension - Test your extension locally with the gulp command `gulp extension:local`. This command automatically recompiles the extension files with a watch task when you change files in your extension development directory.
    
-   Deploy an extension - Upload your extension's source files to your NetSuite account with the gulp command `gulp extension:deploy`. See [Deploy an Extension to NetSuite](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510870586.html) for more information
    

For a list of all gulp commands available with the extension developer tools, see [Gulp Command Reference for Theme and Extension Developer Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510956587.html).
