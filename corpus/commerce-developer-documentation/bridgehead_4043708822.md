SuiteCommerce, SuiteCommerce MyAccount, and SuiteCommerce Advanced (SCA) releases follow the same general release schedule. How these updates apply to your implementation depends on the Commerce application you are implementing:

## SuiteCommerce and SuiteCommerce MyAccount {#bridgehead_163060842358}

SuiteCommerce and SuiteCommerce MyAccount are delivered as part of the same **managed bundle**. Therefore, all major and minor release updates apply to your account automatically. Unless otherwise noted in the release notes, these updates require no further action.

## SuiteCommerce Advanced {#bridgehead_163060844392}

SCA implementations are delivered as **unmanaged bundles**. Therefore, you must manually migrate your account to the latest major or minor release to take advantage of any related features and updates.

-   To migrate your SCA implementation to the latest release, see [Migrate SuiteCommerce Advanced](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1559073362.html) for details.
    
-   If you are interested in migrating to SCA from a SuiteCommerce implementation, see [Upgrade SuiteCommerce to SuiteCommerce Advanced](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1522935586.html).
    

All major and minor releases include specific release notes, indicating the new features or updates that apply. Releases prior to 2019.2 include release notes for major releases only. See [SuiteCommerce, SuiteCommerce MyAccount, and SuiteCommerce Advanced Release Notes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4410490401.html) for details.

Familiarize yourself with the following topics:

-   [Types of Releases](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4043708822.html#subsect_163060881736)
    
-   [What are SCA Patches?](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4043708822.html#subsect_157185258472)
    

## Types of Releases {#subsect_163060881736}

### What is a Major Release? {#subsect_157185254711}

Each release includes a version number using a nomenclature that is based on the semantic versioning schema, or SEMVER. An example of release version nomenclature is **2019.2.1**, as depicted in the following image.

Major releases include significant product enhancements and new features or updates to both SuiteCommerce and SuiteCommerce Advanced applications. These releases occur approximately twice annually and are designated by the year of release. For example, 2019.1 and 2019.2.

#### Earlier Releases {#subsect_159957222554}

Prior to the 2018.2 release, major releases of SuiteCommerce and SuiteCommerce Advanced were released using names of well-known mountains, not numbers. These were released as the following (listed in reverse-chronological order):

-   Aconcagua
    
-   Kilimanjaro (SCA Only)
    
-   Elbrus (SCA Only)
    
-   Vinson (SCA Only)
    
-   Mont Blanc (SCA Only)
    
-   Denali (SCA Only)
    

### What is a Minor Release? {#subsect_157185257527}

Minor releases include periodic updates to core source code for SuiteCommerce, SuiteCommerce MyAccount, and SuiteCommerce Advanced. These releases occur periodically within a major release cycle. Release notes explain any updates that have occurred. For example, 2019.2.1.

## What are SCA Patches? {#subsect_157185258472}

Patches apply to the Kilimanjaro release of SuiteCommerce Advanced and earlier only.

Patches are documented instructions detailing how to implement a code update by manually customizing core SuiteCommerce Advanced source code. Patches are only available for SuiteCommerce Advanced implementations of Kilimanjaro and earlier.

If you are implementing the Kilimanjaro release of SCA or earlier and you do not want to migrate to the latest release of SCA, we provide patching instructions for some issues you may encounter with your implementation.

For detailed instructions on patching SCA implementations (Kilimanjaro and earlier) see [SCA Patches](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4709493958.html).

Note:

The Aconcagua release of SCA and later does not require patching. SuiteCommerce and SuiteCommerce MyAccount implementations receive updates automatically and, therefore, also do not require patching. The best practice to update SCA (Aconcagua and later) is to migrate to the latest major or minor release.
