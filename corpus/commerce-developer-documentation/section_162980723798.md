Read the following topics to learn how to enable site administrators to customize a SuiteCommerce website using Site Management Tools (SMT). As an extension developer, you can develop extensions:

-   To expose new page types to site administrators or let them customize existing page types by introducing new layouts they can choose from. For more information, see [Create Page Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1549653144.html).
    
-   To register new page types so site administrators can define each new page as a specific type. For more information, see [Register Page Types and Templates for SMT](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1547495743.html).
