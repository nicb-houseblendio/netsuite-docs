This object contains shipping method information for the order.

| Field Name | Field Type | Description | In Get Functions? | In Set Functions? |
| --- | --- | --- | --- | --- |
| name | string | Name of the shipping method | yes | no |
| rate | string | Rate of the shipping method | yes | no |
| shipcarrier | string | Shipping carrier ID Note: Valid values that can be set for shipcarrier are `ups` or `noups`. | yes | yes |
| shipmethod | string | Shipping method ID | yes | yes |
