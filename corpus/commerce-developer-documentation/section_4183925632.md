Before you start to customize your SuiteCommerce, SuiteCommerce Advanced (SCA), or SuiteCommerce MyAccount (SCMA) implementation using the theme and extension developer tools, you need to set up your developer environment. The same is true if you plan to develop extensions for SuiteCommerce InStore (SCIS) using the extension developer tools or if you need to customize a Kilimanjaro or earlier release of SCA using the SCA developer tools.

To set up your developer environment, you need to install the following JavaScript utilities:

-   [Install Node.js](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4183926623.html)
    
-   [Install Gulp.js](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4183927828.html)
    

After installing the required JavaScript utilities, make sure you understand the roles and permissions required to use the developer tools as well as the gulp commands that are available for use with each tool. For more information, see:

-   [Developer Tool Roles and Permissions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161004948870.html)
    
-   [Gulp Commands](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161851935635.html)
    

After installing the required JavaScript utilities and learning more about roles, permissions, and gulp commands, continue to set up your tools and develop your customizations as described in [Next Steps for Each Tool](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161851938939.html).
