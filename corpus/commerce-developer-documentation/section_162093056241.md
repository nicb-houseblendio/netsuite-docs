To start developing themes, complete the following tasks:

| Step/Task | For detailed instructions, see |
| --- | --- |
| Download and install theme developer tools | [Set Up Theme Developer Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1509997459.html) |
| Download files to use as the basis for your own custom theme | 
-   [Anatomy of the Base Theme](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1556139021.html) (recommended if you're new to website development and learning best practices)
-   [Fetch Active Theme Files](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_5110052337.html) (if you want to customize the currently active theme)

 |
| Understand best practices for theme development | [Best Practices for Creating Themes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510849826.html) |
| Develop your theme | 

-   [Customize Pre-Existing Theme Files](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1497015350.html)
-   [Add a New File to a Theme](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510179465.html)
-   [Theme Tutorials](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161851995461.html)

 |
| Edit the theme manifest (only necessary if you need to introduce new HTML, Sass, or other assets) | _Theme Manifest_ |
| Test your theme locally | [Test a Theme on a Local Server](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1497015355.html) |
| Deploy your theme to NetSuite | [Deploy a Theme to NetSuite](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1498073418.html) |
| Activate your theme | [Manage Themes and Extensions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510954484.html) |
| If you want to do more with themes | 

-   [Override Active Extension Files](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1498666438.html)
-   [Enable Customization from Site Management Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510848163.html) (to integrate with Site Management Tools)
-   [Customize Site Search Elements](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1535469140.html)
-   [Bundle Process for SuiteCommerce](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1527275163.html)

 |
