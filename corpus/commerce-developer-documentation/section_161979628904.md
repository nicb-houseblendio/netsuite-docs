Before you start the following tutorials, complete the following tasks:

-   Install and configure SuiteCommerce or SuiteCommerce Advanced (Aconcagua and later versions) as described in [Install Your Commerce Website Applications](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2675216.html).
    
-   [Install Node.js](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4183926623.html)
    
-   [Install Gulp.js](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4183927828.html)
    
-   [Set Up Theme Developer Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1509997459.html)
    
-   Understand the [Anatomy of the Base Theme](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1556139021.html)
    
-   Install and activate the SuiteCommerce Base Theme as described in [Use the SuiteCommerce Base Theme](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1556139021.html#subsect_1556136959)
    
-   Ensure Site Management Tools (SMT) are enabled as described in the SMT [Site Management Tools Installation and Implementation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4098551783.html) topic
    
-   Familiarize yourself with the [Best Practices for Creating Themes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510849826.html)
