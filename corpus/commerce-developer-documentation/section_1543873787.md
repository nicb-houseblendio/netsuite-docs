Before you can use an SSL certificate to secure the shopping portion of your web store under an HTTPS domain, you must set up a secure shopping domain in NetSuite. See [Set Up a Domain](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1526632554.html) for more information.

When setting up a secure domain for a site implementing Site Builder, be aware that sites implementing Site Builder can only implement SSL for the Shopping area of their site using a separate, secure shopping domain. Site Builder sites cannot implement a single secure domain for both Shopping and Checkout applications.

When you have configured your domain, continue with the next step: [Apply the Patch to Source Files](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1543873798.html).
