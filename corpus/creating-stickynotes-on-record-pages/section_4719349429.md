#### To set StickyNotes preferences:

1.  Go to Setup > Customization > StickyNotes Setup.
    
2.  Under User Preferences, set the values for the following:
    
    -   **Enable StickyNotes on Record Pages** - Check this box to enable the StickyNotes toolbar on record pages.
        
    -   **Preview Images on Record Notes** - Check this box to preview an image attached to a note when it's expanded on the record page. If this setting's off, you'll see the image icon and filename on the note. This setting won't work if the administrator turned off image preview on the account.
        
    -   **Preview Images on StickyNotes Board** - Check this box to preview an image attached to a note when it's expanded on the StickyNotes Board. If this setting's off, you'll see the image icon and filename on the note. This setting won't work if the administrator turned off image preview on the account.
        
        Note:
        
        Only JPG and PNG images can be previewed in the note. Other file types show up as an icon with a link to the attached file.
        
    -   **Hide Notes on Record Pages** - Check this box to hide all notes across record pages. When this setting's on, you'll get a pop-up alert about hidden notes when you open a record. You can click Show Notes from the StickyNotes menu on the record page to see the notes.
        
    -   **Suppress Tutorial on Record Pages** - Check this box to turn off the tutorial on record pages.
        
    -   **Suppress Tutorial on StickyNotes Board** - Check this box to turn off the tutorial on the StickyNotes Board.
        
        Note:
        
        You'll see a tutorial when you open the StickyNotes Board or a record page where it's enabled. You can hide the tutorial by clicking **Don't show this message again**. If you want to view the tutorial again, you can enable it on this page.
        
    -   **Shortcut Key for Posting Notes** - Select a keyboard shortcut that you want to use to post notes on record pages.
        
    -   **Font Size** - Select your preferred font size.
        
    -   **Note Size** - Select your preferred note size.
        
    
    ![Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteApps/StickyNotes_Preferences.png)
3.  Click **Save**.
