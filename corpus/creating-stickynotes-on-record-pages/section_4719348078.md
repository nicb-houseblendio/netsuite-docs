## Enabling Email Capture for StickyNotes {#bridgehead_4719369607}

Users get an email when you add them to a note or when someone replies to their note. When email capture's on for StickyNotes, users can reply to notes right from their email.

#### To enable email capture for StickyNotes:

1.  Go to _Customization > Plug-ins > Manage Plug-ins_.
    
2.  Check the **StickyNotes Email Capture** box.
    
    Important:
    
    Make sure you note the email address shown below this setting. You'll use it to set up the email capture address in [Setting General StickyNotes Settings](#bridgehead_4740047857).
    
3.  Click **Save**.
    

## Setting General StickyNotes Settings {#bridgehead_4740047857}

Manage general StickyNotes settings for your account.

#### To configure general settings for all users:

1.  Go to Setup > Customization > StickyNotes Setup.
    
2.  Under Admin Setup, set values for the following:
    
    -   **Enable Tutorials** - Check this box to enable the StickyNotes tutorial on record pages and on the StickyNotes Board, for all users on this account.
        
    -   **Send Email Notifications** - Check this box to notify users through email when:
        
        -   They are added as a recipient in a note
            
        -   Someone replied to a note that they created, or they are a recipient of
            
        -   Someone replied to a note that they have previously replied to
            
    -   **Allow File Attachments** - Check this box to enable users to attach files to StickyNotes.
        
    -   **View Historical Notes on Transformed Records** - Check this box if you want notes to carry over to transformed records. For example, if you generate an estimate from an opportunity, those notes carry over to the estimate. Notes attached to specific fields on the opportunity aren't included. Notes added to the estimate won't be available on the opportunity record.
        
    -   **Preview Images on Record Notes (All Users)** - Check this box to preview an image attached to a note when it's expanded on the record page. If this setting's off, you'll see the image icon and file name on the note. This setting won't work if users have turned off image preview in their account.
        
    -   **Preview Images on StickyNotes Board (All Users)** - Check this box to preview an image attached to a note when it's expanded on the StickyNotes Board. If this setting's off, you'll see the image icon and filename on the note. This setting won't work if users have turned off image preview in their account.
        
        Note:
        
        Only JPG and PNG images can be previewed on the note. Other file types are displayed as an icon with a link to the attached file.
        
    -   **Email Capture Address** - Enter the email capture address for StickyNotes. Replies to notes made by email go to this address.
        
3.  Click **Save**.
    

## Enabling StickyNotes on Record Types {#bridgehead_4743389168}

Account administrators can enable StickyNotes on specific record pages or all record pages. When enabled, the StickyNotes toolbar shows up at the top of the record page so you can add notes.

#### To enable StickyNotes on all or selected record types:

1.  Go to Setup > Customization > StickyNotes Setup.
    
2.  On the Record Types subtab, do one of the following:
    
    -   To enable StickyNotes on all record types, check the **Enable on All Record Types** box.
        
    -   To enable StickyNotes on selected record types, clear the **Enable on All Record Types** box, and add a record type to the Enabled Record Type sublist. When the Enable on All Record Types setting is enabled, the system will ignore entries in the Enabled Record Types sublist.
        
3.  Click **Save**.
    

## Configuring StickyNotes Access {#bridgehead_3971730196}

By default, the StickyNotes Toolbar and Board are available to all roles after installation. Account administrators can limit access to StickyNotes, so only certain roles can view the Board and toolbar on record pages. Administrators can also let certain users search for all public notes from the StickyNotes Board.

#### To configure access to StickyNotes

1.  Go to Setup > Customization > StickyNotes Setup.
    
2.  On the Access subtab, set values for the following:
    
    -   **Enable All Roles** - Check this box to enable StickyNotes for all roles on the account. If you leave this box unchecked, only selected StickyNotes roles can see the toolbar and Board.
        
    -   **StickyNotes Roles** - Select which roles can access StickyNotes on the account. If you've checked Enable All Roles, the system ignores the selected roles.
        
    -   **Global Search Users** - Select users who can view all public notes on the account. By default, users can only see notes they've created or where they're a recipient.
        
3.  Click **Save**.
