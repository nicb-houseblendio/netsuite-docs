## Prerequisite {#bridgehead_3940869119}

Before you install the StickyNotes SuiteApp, go to _Setup > Company > Enable Features_. For more information, [Enabling Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N232138.html).

Make sure that the following features are enabled on your account:

| Subtab | Section | Feature |
| --- | --- | --- |
| SuiteCloud | SuiteScript | Client SuiteScript |
| Server SuiteScript |
| SuiteBuilder | Custom Records |

## Installation {#bridgehead_3971736755}

Note:

Only users with the Administrator role can install and set up the StickyNotes SuiteApp.

To install the StickyNotes SuiteApp, go to _Customization > SuiteBundler > Search & Install Bundles_, and then click **Advanced**.

Use the following information to search for the SuiteApp:

-   **Bundle Name:** StickyNotes
    
-   **Bundle ID:** 49018
    
-   **Location:** Production (Account ID 3849685)
    

StickyNotes is a managed SuiteApp, and we automatically update it whenever there are changes. You'll get these fixes and enhancements as soon as the SuiteApp updates in your account.

For information about installing SuiteApps, see [Installing a Bundle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3395142.html).
