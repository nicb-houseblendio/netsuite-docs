## StickyNotes Actions {#bridgehead_4749538277}

When you're viewing notes on a record page or the StickyNotes Board, hover over a note to see the Actions menu in the upper-right corner. From the **Actions** menu, you can do any of the following:

Note:

Some actions aren't available when you view a note from the StickyNotes Board.

-   **Mark as Done** - Crosses out the note to show the action items are done. Anyone with access to the note can mark it as done.
    
-   **Reply** - Opens a new reply note. Type your message in the space provided. Anyone with access to the note can reply.
    
-   **Expand Replies** - Expands a note to see all replies.
    
-   **Compile Replies** - Collapses note replies.
    
-   **Delete Note** - Deletes the current note. You can only delete notes you created.
    
-   **Archive Note** - Archives the current note. Archived notes won't show up on the record page, but you can still see them on the StickyNotes Board. You can only archive notes you've created.
    

## StickyNotes Icons {#bridgehead_4749454441}

You'll see icons at the bottom of the original note showing if it's public or private, or if it has replies and attachments.

| Icon | Description |
| --- | --- |
| ![Replies to note](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteApps/StickyNotes_IconReply.png) | This icon means there are replies to the note. |
| ![Private note](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteApps/StickyNotes_IconPrivate.png) | This icon means the note is private. Only the note owner and recipients can see private notes. |
| ![Public note](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteApps/StickyNotes_IconPublic.png) | This icon means the note is public. Everyone with access to the record page can see public notes. |
| ![Attachment to note](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteApps/StickyNotes_IconAttachment.png) | This icon means there's a file attached to the note or its replies. |
