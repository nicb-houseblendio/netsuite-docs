Before creating documents, define settings on the options record at CPQ > Proposal Generator > Settings.

Users must be able to view the **Proposal** button on transactions to create documents. To enable the **Proposal** button, check the **Proposal Generator Button** box. For more information about eligible transactions, see [Selecting Eligible Transactions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_9124208079.html#subsect_0515013646).

If you use custom partner roles that aren't assigned to the Partner Center, check the **Custom Role Centers** box. This option lets users with those roles create documents from transactions. To verify the center assigned to a role, go to Setup > Users/Roles > Manage Roles. On the role record, view the information in the **Center Type** field. For more information about roles, see [NetSuite Roles Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N285436.html).

When you're finished with the setup, save the options record.

After the installation, NetSuite CPQ Proposal Generator automatically creates and enables two custom transaction body fields to work with eligible transactions. When customizing these transactions, always maintain these fields enabled to let users create documents.

The following table lists the custom transaction body fields.

| Body Field Name | Body Field ID |
| --- | --- |
| **NS CPQ Auto-generated Proposals** | custbody\_cpqp\_auto\_gen\_proposals |
| **NS CPQ Proposals JSON** | custbody\_cpqp\_proposals\_json |

For more information about custom fields in NetSuite, see [Custom Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N2826978.html).

Users with an administrator or a CPQ PropGen Builder role can create and maintain templates. For more information about NetSuite CPQ custom roles, see [Assigning NetSuite CPQ Custom Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1145912241.html#subsect_0527012755).
