Note:

NetSuite CPQ Proposal Generator requires NetSuite CPQ Configurator to create documents from transactions. For more information, see [Installing NetSuite CPQ SuiteApps](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1145912241.html).

NetSuite CPQ Proposal Generator helps sales teams quickly create customized business documents-such as quotes and proposals-for configured items and transactions. By quickly creating documents, sales teams can close deals for configured items faster.

With NetSuite CPQ Proposal Generator, you can:

-   Create PDF files and Microsoft® Word documents (DOCX files).
    
-   Base your documents on information from configured items, transactions, item records, and your account.
    
-   Create document templates and automatically generate documents from those templates.
    
-   Include or exclude information using question and answer combinations from NetSuite CPQ Configurator.
    
-   Organize and structure the document layout.
    
-   Customize and format documents with HTML and CSS code.
    
-   Append existing PDF files to documents.
    

Note:

You can also create documents for transactions that don't contain configured items.

Before creating documents, set up basic and additional options. For more information, see [NetSuite CPQ Proposal Generator Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1133208531.html).

After completing the setup, you can create templates. A template defines the layout and structure for the document to be created. For more information, see [Creating Document Templates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1134727908.html).

Templates are divided into groups and sections to help you organize information. Groups contain sections. Sections store the document content, such as text, tables, and images. You can nest groups within the template and sections within groups. For more information, see [Dividing Documents into Groups](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_6135420618.html) and [Adding Content to Sections](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_9135538673.html).

Sections can include dynamic information from configured items, transactions, and your account. For more information, see [Including Dynamic Information in Text Sections](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_8163432400.html).

To include or exclude groups and sections in a document, use rules based on question and answer combinations from configurable items. For more information about rules, see [Activating or Hiding Building Blocks with Rules](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_4124359628.html).

If you have information stored in PDF files, you can append those files to the final document. For more information, see [Including PDF Files in Documents](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_6135623631.html).

When templates are ready, users can create documents from transactions. For more information, see [Creating Documents from Transactions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_93712689.html).
