Users can create documents from saved transactions. For more information about eligible transactions, see [Selecting Eligible Transactions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_9124208079.html#subsect_0515013646).

#### To create a document:

1.  On a saved transaction, click the **Proposal** button on the **Items** subtab.
    
2.  In the template list, select the template to generate the document in the browser.
    
    Note:
    
    The document header and footer aren't included in the browser preview.
    
3.  On the document page, click one of the following buttons:
    
    -   **Print** - Prints the document.
        
    -   **PDF** - Downloads the document as a PDF file.
        
    -   **DOC** - Downloads the document as a Microsoft® Word file (DOCX file).
