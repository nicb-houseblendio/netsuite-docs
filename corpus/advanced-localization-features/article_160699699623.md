The main feature delivered by the Advanced Localization Features SuiteApp consists of the advanced PDF/HTML templates for the following transactions. The templates comply with tax regulations and meet common business needs of NetSuite users. To learn more about these templates, see [Setting Up the Advanced Localization Features Templates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160691067358.html).

-   Invoices
    
-   Credit Memos
    
-   Sales Orders
    
-   Purchase Orders
    
-   Transfer Orders
    
-   Item Receipts
    

This main feature is enhanced by several additional features. They work in conjunction with the PDF/HTML templates, making them available for customizations. Note that the additional features only work with the templates provided by this SuiteApp and don't automatically interact with any other existing invoice, credit memo, sales order, or purchase order layout.

Configure and adjust additional features of the Advanced Localization Features SuiteApp using the Customize Document Template page (Setup > Accounting > Customize Document Template).

Installing the Advanced Localization Features SuiteApp also enhances the process of printing your transactions. It enables you to print transaction drafts and to view the printing history of every transaction having the original copy of the printed transaction and all subsequent copies. For more information, see [Printing Transactions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_160154427786.html).
