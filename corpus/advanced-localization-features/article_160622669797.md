The purpose of this SuiteApp is to create the following localized printable transactions that comply with tax regulations and meet common business needs of NetSuite users. To achieve this, the SuiteApp delivers advanced PDF/HTML templates. To learn more about these templates, see [Setting Up the Advanced Localization Features Templates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160691067358.html).

-   Invoices
    
-   Credit Memos
    
-   Sales Orders
    
-   Purchase Orders
    
-   Transfer Orders
    
-   Item Receipts
    

![Advanced Localization Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteApps/ALF-Overview.png)

Additional features of the Advanced Localization Features SuiteApp work in conjunction with these PDF/HTML templates, making them available for customization.

Note:

The additional features only work with the templates provided by this SuiteApp and don't automatically interact with any other existing invoice, credit memo, sales order, or purchase order layout.

With the following additional features you can:

-   Fill in additional fields added to subsidiary, customer, or vendor records. The content of these fields will then be used on printed transaction forms. To learn more, see [New Fields on Subsidiary, Customer, and Vendor Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160103607732.html).
    
-   Create Transaction Bank Details records with the content for printed invoices, credit memos, sales orders, or purchase orders. These records can be assigned to subsidiaries, customers, vendors, or individual transactions. To learn more, see [Transaction Bank Details](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160103823775.html).
    
-   Create Method of Payment records to specify the texts to be printed (at customer, vendor, or transaction level). To learn more, see [Method of Payment](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160104065991.html).
    
-   Create Tax Compliance Text records with tax-related texts. To learn more, see [Tax Compliance Text](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160138370371.html).
    
-   Customize your template's color scheme and layout. To learn more, see [Color Scheme and Layout](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160139141365.html).
    
-   Replace the default texts with your customized texts (for every supported language). To learn more, see [Labels and Notes Customization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160146278813.html).
    
-   Set the invoice locking level for each subsidiary to prevent editing of approved or sent invoices. To learn more, see [Invoice Locking](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160146897977.html).
    
-   Print transaction drafts and view the printing history of every transaction (containing the original of the printed transaction and all subsequent copies). To learn more, see [Printing Transactions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_160154427786.html).
    

## Known Limitations of the Advanced Localization Features SuiteApp {#bridgehead_161477673116}

The currently known limitations of the Advanced Localization Features SuiteApp are as follows:

-   If you print an invoice, credit memo, sales order, or purchase order created before the Advanced Localization Features SuiteApp installation, the Issuer (the subsidiary) entry on it'll remain empty. The Advanced Localization Features SuiteApp can't identify the issuers retrospectively.
    
-   The Item Groups feature is currently not supported. Any item group printed on an invoice, credit memo, sales order, or purchase order will contain incomplete information. To learn more about this feature, see [Item Groups](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2224824.html).
    
-   In the **Labels and Notes** subtab of the Customize Document Template page, the **Custom Text** field under **Labels & Text** sublist has a character limit. The allowable character limit is 200 characters including spaces and special characters. However, you can enter up to 4000 characters for subsidiary translatable fields in the **Custom Notes** field under the **Notes** sublist.
    
    Note:
    
    For duplicate custom text, the character limit of the **Custom Text** field under **Labels & Text** subtab is 175 characters including spaces and special characters.
    
-   The Service Period feature is available for item groups that have service items with the **Reference Start/End Lines On Picking Ticket** box cleared on an item record. If the **Reference Start/End Lines On Picking Ticket** box is checked then the service period dates are not available for the service items. For more information about service period dates, see [Service Period](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0821084529.html).
    

The following limitations apply only to transactions with accounting periods closed before Advanced Localization SuiteApp version 1.04.0 update:

-   Invoices, credit memos, sales orders, and purchase orders from closed periods with the **Allow Non-GL Changes** box not checked can only be printed with the following limitations:
    
    Note:
    
    You should enable **Allow Non-GL Changes** permission to avoid the limitations. For more information, see [Accounting Period Management](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N1445226.html). Role with Allow Non G/L Changes permissions is required.
    
    -   If the original document has not been printed before closing the period, all its printouts are marked as originals, not as duplicates.
        
    -   The **Preview PDF** and **Print a PDF Copy** buttons are disabled, preventing draft and copy printing.
        
    -   The printing history doesn't get updated and may therefore display incorrect data.
        
    -   Your account's Suitelet governance usage determines how many custom text entries you can add. The number is based on your subsidiaries and configuration.
