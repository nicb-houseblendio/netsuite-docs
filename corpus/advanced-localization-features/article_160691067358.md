With the Advanced Localization Features SuiteApp, advanced PDF/HTML templates for invoices, credit memos, and sales orders are installed to your NetSuite account. To use them, you should assign them to your transaction forms first.

#### To assign the ALF template to an invoice transaction form:

1.  Go to Customization > Forms > Transaction Forms.
    
2.  On the Custom Transaction Forms page, locate an invoice type transaction form (for example, Standard Product Invoice). Click **Edit** for a custom form, or click **Customize** for a standard form.
    
3.  Ensure the **Printing Type** is set to **Advanced** for this transaction form.
    
4.  From the **Print Template**, **Email Template** or both dropdown lists, select **ALF Invoice PDF/HTML Template**.
    
5.  (Optional) Check the **Form Is Preferred** box to make the form template the default for this transaction type.
    
6.  (Optional) Use the **Name** field to name this custom transaction form (for example, ALF Product Invoice).
    
7.  Click **Save**.
    

#### To assign the ALF template to a credit memo transaction form:

1.  Go to Customization > Forms > Transaction Forms.
    
2.  On the Custom Transaction Forms page, locate a credit memo type transaction form (for example, Standard Credit Memo). Click **Edit** for a custom form, or click **Customize** for a standard form.
    
3.  Make sure that for this transaction form, the **Printing Type** is set to **Advanced**.
    
4.  From the **Print Template**, **Email Template** or both dropdown lists, select **ALF Credit Memo PDF/HTML Template**.
    
5.  (Optional) Check the **Form Is Preferred** box to make the form template the default for this transaction type.
    
6.  (Optional) Use the **Name** field to name this custom transaction form (for example, ALF Credit Memo).
    
7.  Click **Save**.
    

#### To assign the ALF template to a sales order transaction form: {#procedure_0613091754}

1.  Go to Customization > Forms > Transaction Forms.
    
2.  On the Custom Transaction Forms page, locate a sales order type transaction form (for example, Standard Sales Order). Click **Edit** for a custom form, or click **Customize** for a standard form.
    
3.  Make sure that for this transaction form, the **Printing Type** is set to **Advanced**.
    
4.  From the **Print Template**, **Email Template** or both dropdown lists, select **ALF Sales Order PDF/HTML Template**.
    
5.  (Optional) Check the **Form Is Preferred** box to make the form template the default for this transaction type.
    
6.  (Optional) Use the **Name** field to name this custom transaction form (for example, ALF Sales Order).
    
7.  Click **Save**.
    

#### To assign the ALF Proforma Invoice template to a sales order transaction form: {#procedure_0613091839}

1.  Go to Customization > Forms > Transaction Forms.
    
2.  On the Custom Transaction Forms page, locate a proforma invoice type transaction form (for example, Standard Proforma Invoice). Click **Edit** for a custom form, or click **Customize** for a standard form.
    
3.  Make sure that for this transaction form, the **Printing Type** is set to **Advanced**.
    
4.  From the **Print Template**, **Email Template** or both dropdown lists, select **ALF Proforma Invoice PDF/HTML Template**.
    
5.  (Optional) Check the **Form Is Preferred** box to make the form template the default for this transaction type.
    
6.  (Optional) Use the **Name** field to name this custom transaction form (for example, ALF Proforma Invoice).
    
7.  Click **Save**.
    

#### To assign the ALF Purchase Order template to a sales order transaction form:

1.  Go to Customization > Forms > Transaction Forms.
    
2.  On the Custom Transaction Forms page, locate a purchase order type transaction form (for example, Standard Purchase Order) and click **Edit** for a custom form, or click **Customize** for a standard form.
    
3.  Ensure the **Printing Type** is set to **Advanced** for this form.
    
4.  Select the **ALF Credit Memo PDF/HTML Templat****e** from the **Print Template**, **Email Template**, or both dropdowns.
    
5.  (Optional) To make the form template as default for this transaction type, check the **Form Is Preferred** box.
    
6.  (Optional) To name this custom transaction form (for example, ALF Purchase Order), use the **Name** field.
    
7.  Click **Save**.
    

If you want to make sure that every new invoice, credit memo, sales order, or purchase order custom form uses the templates provided by the Advanced Localization Features SuiteApp, set these templates as preferred. When you choose the Advanced printing type for a custom form (see step 3 of the procedures above), the preferred advanced template is selected by default as the template for that form.

1.  Go to Customization > Forms > Advanced HTML/PDF Templates.
    
2.  Locate the following templates:
    
    -   **ALF Invoice PDF/HTML Template**
        
    -   **ALF Credit Memo PDF/HTML Template**
        
    -   **ALF Sales Order PDF/HTML Template**
        
    -   **ALF Proforma Invoice PDF/HTML Template**
        
    -   **ALF Purchase Order PDF/HTML Template**
        
    -   **ALF Transfer Order PDF/HTML Template**
        
    -   **ALF Item Receipt PDF/HTML Template**
        
    -   **ALF Commercial Invoice PDF/HTML Template**
        
3.  Make sure that for the located templates, the box in the **Preferred** column is checked.
    

For more information, see [Setting Custom Forms to Use Advanced Templates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2863334.html) or [Reviewing Available Advanced Templates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2863143.html).

## Editing Templates in the Template Editor {#bridgehead_160699454351}

The HTML/PDF templates provided by the Advanced Localization Features SuiteApps are fully tailored to meet common business requirements of NetSuite users. However, you can still adjust them to make them even more suitable for your needs.

Important:

Before editing the templates, you should read the help topic [Advanced Templates Customization in the Template Editor](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2863632.html) (as well as other related help topics) carefully. Also, you should save templates using the **Save as** button to keep the original templates unchanged and avoid overwriting the user-modified templates during automatic bundle updates.

#### To edit a template in the Template Editor:

1.  Go to Customization > Forms > Advanced HTML/PDF Templates.
    
2.  Locate the following templates:
    
    -   **ALF Invoice PDF/HTML Template**
        
    -   **ALF Credit Memo PDF/HTML Template**
        
    -   **ALF Sales Order PDF/HTML Template**
        
    -   **ALF Proforma Invoice PDF/HTML Template**
        
    -   **ALF Purchase Order PDF/HTML Template**
        
3.  Click the **Edit** link next to one of these templates.
    
4.  After you're done editing, save the template by clicking **Save as** from the **Save** dropdown menu.
    

Note:

If you save the changes by clicking **Save**, the changes will be overwritten by the next SuiteApp update.
