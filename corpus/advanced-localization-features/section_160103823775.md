Every Transaction Bank Details record contains several fields. The content of some of these fields is printed on invoices, credit memos, sales orders, or purchase orders if you're using the PDF/HTML templates provided by the Advanced Localization Features SuiteApp. The purpose of other fields is to provide additional configuration such as assigning the Transaction Bank Details record to a certain subsidiary only.

Transaction Bank Details records can be assigned at subsidiary, customer, or vendor level. You can also assign it to individual transactions.. For more information, see [New Fields on Subsidiary, Customer, and Vendor Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160103607732.html).

#### To assign Transaction Bank Detail records to individual transactions: {#procedure_0614022045}

1.  Go to an Invoice, Credit Memo, Sales Order, or Purchase Order page.
    
2.  Select the **Invoice Configuration** subtab.
    
3.  Select a record from the **Transaction Bank Details**.
    
4.  Click **Save**.
    

For more information, see the following help topics:

-   [Creating an Invoice](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1238506.html)
    
-   [Customer Credit Memos](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1311306.html)
    
-   [Creating a Sales Order](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1216500.html#bridgehead_4593540360)
    
-   [Entering a Purchase Order](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2400504.html)
    

The default Transaction Bank Details record is always inherited from a higher instance. This means that if you assign a certain Transaction Bank Details record to a subsidiary, it'll be automatically used for all newly-created customers or vendors of this subsidiary and their transactions. If you want some customer, vendor or transaction to use different bank details, you must go to that customer, vendor or transaction record and change them manually.

Similarly, if you assign a Transaction Bank Details record to a customer or vendor, the record can be automatically used on all newly-entered invoices, credit memos, sales orders, and purchase orders for this customer or vendor. If no Transaction Bank Details record is assigned to the customer or vendor, then the value will be retrieved in the following order:

1.  The value is retrieved from the matching transaction bank details record with same subsidiary and currency as mentioned in the transaction.
    
2.  If more than one bank details or duplicate records are found, then the value is retrieved from subsidiary record.
    
3.  If no value is found, then the value is retrieved from subsidiary record.
    
    However, for conditions 2 and 3 you can override the derivation at the transaction level.
    

To create a new Transaction Bank Details record, go to Setup > Accounting > Customize Document Template, select the Bank Details subtab, and click the **New Bank Details** button. The Bank Details subtab also displays all already existing Transaction Bank Details records. You can view or edit them. Use the respective links.

Alternatively, you can access these records without using the Customize Document Template page. In that case, go to Lists > Accounting > Transaction Bank Details.

The Transaction Bank Details record contains the following fields:

| Field | Description |
| --- | --- |
| Name | Enter a name for this Transaction Bank Details record to easily identify the bank details to be selected for subsidiaries, customers, vendors, or transactions. Examples: UK Subsidiary GBP account UK Subsidiary EUR account |
| Subsidiary | Use this field to select the subsidiary that these bank details will be available for. |
| Transaction Currency | Use this field to select the transaction currency that these bank details will be available for. |
| Bank Details to Print | Enter the text that will be printed on transactions assigned to this Transaction Bank Details record. Note that it'll not be translated. **Example:** Please remit payment to: IBAN ING12NL12345678 BIC INGBOXX Note that in the Method of Payment dropdown list on the transaction record (in the Invoice Configuration subtab), the following option for Print on invoice, credit memo, sales order, or purchase order must be selected: Bank Details. Otherwise, this text will not be printed. For more information, see [Method of Payment](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160104065991.html). |
| Direct Debit Details to Print | Enter the text that will be printed on transactions assigned to this Transaction Bank Details record. Note that it'll not be translated. **Example:** Payment will be taken automatically from your account 14 days after this invoice. Note that in the Method of Payment dropdown list on the transaction record (in the Invoice Configuration subtab), the following option for Print on invoice, credit memo, sales order, or purchase order must be selected: Direct Debit. Otherwise, this text will not be printed. For more information, see [Method of Payment](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160104065991.html). |
| IBAN | Enter the International Bank Account Number for this Transaction Bank Details record. The content of this field can be used if more detailed and structured information is required (like in electronic invoicing). Text is not printed in an invoice, credit memo, sales order, or purchase order. |
| BIC | Enter the Bank Identifier Code for this Transaction Bank Details record. The content of this field can be used if more detailed and structured information is required (like in electronic invoicing). Text is not printed in an invoice, credit memo, sales order, or purchase order. |
| Local Bank Account | Enter the local bank account for this Transaction Bank Details record. The content of this field can be used if more detailed and structured information is required (like in electronic invoicing). Text is not printed in an invoice, credit memo, sales order, or purchase order. |
| Local Branch Code | Enter the local branch code for this Transaction Bank Details record. The content of this field can be used if more detailed and structured information is required (like in electronic invoicing). Text is not printed in an invoice, credit memo, sales order, or purchase order. |
