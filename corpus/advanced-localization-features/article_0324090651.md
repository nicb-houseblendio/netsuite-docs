Some e-document formats require a transaction to reference a previously generated e-document.

For example:

-   A corrective invoice that references the original invoice.
    
-   A final invoice that references a prepayment invoice.
    

You can create one or more document references from a parent transaction to a reference transaction. You can add references only between invoices or credit memos that share the same subsidiary and customer.

#### To create a document reference from a transaction:

1.  Open an invoice or credit memo.
    
2.  On the **Invoice Configuration** subtab, click **New Document Reference**.
    
3.  From the **Reference Transaction** list, select the transaction to add as a reference.
    
    Note:
    
    Only invoices and credit memos with the same subsidiary and customer as the parent transaction are available in the **Reference Transaction** list.
    
4.  From the **Link Transaction Relationship Type** list, select the relationship type between the linked transactions.
    
5.  Click **Save**.
