The templates provided by the Advanced Localization Features SuiteApp contain FreeMarker placeholder tags for sourcing and displaying required information as well as setting the layout of the transaction document when printed. The following information is available when printed to PDF or HTML.

Note:

The Advanced Localization Features SuiteApp enables you to customize the invoice, credit memo, and sales order default labels. To learn more about this feature, see [Labels and Notes Customization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160146278813.html).

## Quick Response Code {#bridgehead_0818113005}

The Quick Response (QR) code on the ALF invoice PDF/HTML file enables the customers to scan and access additional details related to the invoice. You can also add payment resources using a QR code.

To include QR code on an invoice template, the hidden transaction body field **custbody\_alf\_qr\_code** must be populated to have QR code on the generated Invoice PDF file. Users can populate the field using scripts or workflows

Here is the code sample with the QR code string:

![ALFInvoicescriptwithQRCodeString](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteApps/ALF-QRCodeStringBodyField.png)

For assistance on QR code string details, contact NetSuite Technical Support.

Note:

The QR Code feature is available only for ALF Invoice template.
