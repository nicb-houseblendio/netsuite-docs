`_The Advanced Localization Features SuiteApp enables you to create the following localized printable transactions that comply with tax regulations and meet common business needs of NetSuite users._`

-   `_Invoices_`
    
-   `_Credit memos_`
    
-   `_Sales orders_`
    
-   `_Purchase orders_`
    

#### To install the Advanced Localization Features SuiteApp: {#procedure_161364078778}

1.  Go to Customization > SuiteBundler > Search & Install Bundles (Administrator).
    
    Note:
    
    Read the Installation Terms of Service on the use of the NetSuite SuiteBundler. Click **I Agree** if you agree, and **I Disagree** if you don't agree with the terms.
    
2.  In the Keywords field, enter **Advanced Localization Features**, or the Bundle ID **359132**.
    
3.  Click **Search**.
    
4.  In the **Name** column, click **Advanced Localization Features**.
    
5.  On the Bundle Details page, click **Install**.
    

For more information about installing SuiteApps, see [Installing a Bundle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3395142.html).

The Advanced Localization Features SuiteApp is a managed bundle, and is automatically updated whenever improvements or new features are added.

Important:

The update applies to the following PDF/HTML templates only:

-   ALF Credit Memo PDF/HTML Template
    
-   ALF Invoice PDF/HTML Template
    
-   ALF Proforma Invoice PDF/HTML Template
    
-   ALF Sales Order PDF/HTML Template
    
-   ALF Purchase Order PDF/HTML Template
    

Any update will overwrite any user-made changes to these templates. To avoid overwriting changes during updates, save them using the **Save as** button when modifying templates..
