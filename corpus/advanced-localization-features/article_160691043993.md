Before installing the Advanced Localization Features SuiteApp, go to _Setup > Company > Setup Tasks > Enable Features_, and make sure that the following features are enabled:

Note:

All the required fields in the Company Information page and the primary subsidiary record must be filled before you install the Advanced Localization Features SuiteApp. For more information, see [Installing the Advanced Localization Features SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160691065745.html).

-   On the **Company** subtab:
    
    -   Multi-Language
        
    -   Multiple Currencies
        
-   On the **SuiteCloud** subtab:
    
    -   Custom Records
        
    -   Advanced PDF/HTML Templates
        
    -   Client SuiteScript
        
    -   Server SuiteScript
        
    -   SOAP Web Services
        
    -   SuiteCloud Development Framework
