If you're using either [Legacy Tax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/preface_3710626699.html) or [SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/preface_1496364245.html) in your NetSuite account, you can apply the Tax Compliance Text records to add various tax-related texts to be printed on your invoices, credit memos, sales orders, or purchase orders.

Every Tax Compliance Text record consists of the text itself and several conditions (filters) for this text to be printed. This text will be printed on every invoice, credit memo, sales order, or purchase order but only if all specified conditions are met.

To create a new Tax Compliance Text record, go to Setup > Accounting > Customize Document Template, select the Tax Compliance Text subtab, and click the **New Tax Compliance Text** button. The Tax Compliance Text subtab also displays all already existing Tax Compliance Text records. You can view or edit them. Use the respective links.

Alternatively, you can access these records without using the Customize Document Template page. In that case, go to Lists > Accounting > Tax Compliance Text.

The Tax Compliance Text record contains the following required field:

| Field | Description |
| --- | --- |
| Text to Print | Enter the tax-related text. It'll be printed on your invoice, credit memo, sales order, or purchase order if all defined conditions are met. |

The optional fields (filters) are as follows:

| Field (Filter) | Description |
| --- | --- |
| Language | Use this filter to specify the language in which the text is defined. Note the text in the Text to Print field must also be in this language. The setting must match customer or vendor, transaction, or subsidiary language setting. |
| Nexus | Use this filter to specify the nexus that the tax compliance text should apply to. |
| Tax Code | Use this filter to specify the tax code that the tax compliance text should apply to. |
| Tax Transaction Type | This option is only applicable if you're using SuiteTax (otherwise, this field is not visible). Use this filter to specify the tax transaction type that the tax compliance text should apply to. |
| Tax Item Type | This option is only applicable if you're using SuiteTax (otherwise, this field is not visible). Use this filter to specify the tax item type that the tax compliance text should apply to. |
