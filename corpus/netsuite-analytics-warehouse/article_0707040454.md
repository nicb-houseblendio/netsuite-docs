## Transfer Saved Searches to NetSuite Analytics Warehouse {#subsect_0707040516}

You can transfer saved searches to NetSuite Analytics Warehouse from the Data Transfer Setup page.

This feature lets you analyze business-specific search data together with standard Analytics Warehouse data and helps you reuse existing saved search logic instead of recreating the same data definitions in another tool.

Before transferring saved searches, you need to complete a one-time Oracle NetSuite Analytics connector setup in Oracle Analytics Cloud first. For more information, see [Transferring Saved Searches to NetSuite Analytics Warehouse](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0526094511.html).

## Transfer Data from Salesforce Data Source {#subsect_0707040601}

If you are a Premium or Enterprise NetSuite Analytics Warehouse user, you can manage data transfer from Salesforce as a data source from the NetSuite Analytics Warehouse Data Transfer Setup page. Salesforce data is grouped into functional areas similar to how NetSuite data is organized.

For more information, see [Transferring Salesforce Data to NetSuite Analytics Warehouse](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0703033717.html).
