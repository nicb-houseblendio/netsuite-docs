NetSuite Analytics Warehouse lets you extend analytics by importing data from NetSuite Saved Searches. This lets you include business-specific datasets already defined in NetSuite and analyze them together with standard NetSuite Analytics Warehouse data without rebuilding business logic.

To start transferring saved searches, you need to configure the NetSuite Analytics Connector for Oracle Analytics Cloud (OAC) first. This is a one-time setup.

Important:

To complete these steps, you must be an NSAW Administrator. Use a NetSuite role that's not a Web Services only role or the Data Warehouse Integrator role, and ensure it has the following permissions assigned:

-   Log in using OAuth 2.0 Access Tokens (**Setup** permission type)
    
-   SuiteAnalytics Workbook (**Reports** permission type)
    
-   Custom Record Entries (**Lists** permission type)
    
-   Perform Search (**Lists** permission type)
    

For more information about the NSAW Administrator role, see [Adding Users to NetSuite Analytics Warehouse](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_159497489716.html). For more information about assigning permissions to roles, see [Managing Roles and Permissions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N284861.html#subsect_0318031643).

#### To configure the NetSuite Analytics connector in OAC:

1.  Go to your Analytics Warehouse instance. For more information, see [Setting Up NetSuite Analytics Warehouse](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_159472942033.html).
    
2.  On the Analytics Warehouse home page, click **Create** at the top-right corner. Then, click **Connection**.
    
3.  Select **Oracle NetSuite Analytics**.
    
4.  Provide the following connection details:
    
    -   **Connection name** - Enter a name for the connection, for example, NetSuiteAnalyticsConnection.
        
    -   **Account ID** - Enter the NetSuite account ID connected to your Analytics Warehouse instance. For more information, see [Finding Your NetSuite Account ID](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1498754928.html).
        
5.  Click **Generate and Download Public Key**. This prompts the download of the certificate file.
    
    Note:
    
    Don't close this tab after downloading the certificate file.
    
6.  Open NetSuite in a new tab and go to Setup > Integration > OAuth 2.0 Client Credentials (M2M) Setup.
    
7.  Click **Create New**. Provide the following details:
    
    -   **Entity** - Enter the name of the person creating the connection.
        
    -   **Role** - Enter the role you're using to create this connection. Be sure it's a role that fulfills the requirements stated in the Important note above.
        
    -   **Application** - Choose **NSAW Analytics Connector**.
        
    -   **Certificate** - Upload the certificate file you downloaded in step 5.
        
8.  Click **Save**.
    
9.  Copy the text in **Certificate ID** and go back to the Oracle NetSuite Analytics connector tab.
    
10.  Paste the certificate ID in the **Certificate ID** field. Then, click **Save**.
     

Before you start transferring saved searches, make sure the search is created and validated in NetSuite, and marked as public and active. For more information, see [Defining a Saved Search](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N676039.html).

#### To transfer saved searches to NetSuite Analytics Warehouse:

1.  Go to the Data Transfer Setup page. For more information, see [Setting Up the Data Transfer](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_159497492876.html).
    
2.  On the Data Transfer Setup page, go to the **Saved Searches** tab.
    
3.  Click **Transfer new Saved Search**.
    
4.  Select the saved searches you want to transfer.
    
5.  Click **Start transfer**.
    

The saved searches that you've transferred are available to create datasets in OAC.

#### To create an OAC dataset from a saved search:

1.  Open the NetSuite Analytics connection.
    
2.  Open the public folder and browse the available saved searches.
    
3.  Double-click the saved search or drag and drop it into the main window.
    
4.  Create an OAC dataset. For more information, see [Create a Dataset from a Connection](https://docs.oracle.com/en/cloud/paas/analytics-cloud/acubi/create-dataset-from-connection.html#ACUBI-GUID-CF5AE48C-C2CB-45EC-A25A-F48843D1D24A).
    
5.  Save the dataset to use it in data visualization, analyses, and other OAC content.
    

Important:

You can create saved-search based datasets in OAC only from saved searches that are active and public.
