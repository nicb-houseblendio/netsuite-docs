NetSuite offers a hub that lets you access and set up your Analytics Warehouse instance. From here, you can also find resources that help you understand and work with the Analytics Warehouse more efficiently. This hub is called the Configuration page.

Users with the NSAW Administrator role can manage users, set up the data transfer, reset transfer credentials, and update the notification email from the NetSuite Analytics Warehouse Configuration page.

## Accessing the NetSuite Analytics Warehouse Configuration Page {#subsect_0129115424}

To open the Configuration page, go to _Setup > Integration > Configuration_, or Analytics > NSAW.

![Configuration page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/NetSuiteAnalyticsWarehouse/configuration_page.png)

1.  **Open NetSuite Analytics Warehouse** - Click this button to access your Analytics Warehouse instance.
    
    Note:
    
    If you have the NSAW Administrator role assigned, the Administration console for NetSuite Analytics Warehouse opens. You can then click **Go to Home Page** to access your Analytics Warehouse instance.
    
2.  **Overview** - This section shows tiles with key details about your instance, including pipeline status, last incremental data transfer, service tier, current active users, and storage usage.
    
3.  **Admin Actions** - Users with the NSAW Administrator role can do the following:
    
    -   **Manage users** - Add, edit, remove, and assign roles to users. For more information, see [Adding Users to NetSuite Analytics Warehouse](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_159497489716.html).
        
    -   **Set up data transfer** - Configure and manage the data transfers. For more information, see [Setting Up the Data Transfer](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_159497492876.html).
        
    -   **Reset transfer credentials** - Update or reset the credentials for data transfers. For more information, see [Resetting NetSuite Analytics Warehouse Transfer Credentials](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_160190666625.html).
        
    -   **Update notification email** - Change the email address for system alerts and transfer notifications. For more information, see [Updating the Notification Recipient Email](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_164640711089.html).
        
        Note:
        
        Only users with the NSAW Administrator role can see this section.
        
4.  **Resources** - All users can access these tiles for more information:
    
    -   **NSAW release notes** - Learn about the latest and key features.
        
    -   **NSAW training courses** - Access training and courses related to NetSuite Analytics Warehouse.
        
    -   **Product documentation** - Find help articles and guides for using NetSuite Analytics Warehouse.
        
    -   **Community page** - Access the [community](https://community.oracle.com/netsuite/english/categories/netsuite-analytics-warehouse-nsaw), where you can interact with other users, ask questions and share insights.
