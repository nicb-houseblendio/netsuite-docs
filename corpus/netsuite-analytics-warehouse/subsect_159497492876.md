To start transferring data to the Analytics Warehouse, you need to go to the Data Transfer Setup page and select the functional areas to include. Your NetSuite data is grouped into predefined functional areas. To learn about the record types and fields available in the NetSuite2.com data source, see [Record Types and Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_164312261929.html).

For more information about the functional areas, see [Supported Functional Areas](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_159591991992.html).

#### To set up the data transfer:

1.  Go to the Configuration page. For more information, see [Accessing the NetSuite Analytics Warehouse Configuration Page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_159472942033.html#subsect_0129115424).
    
    Note:
    
    The configuration page might take some time to load. If you get an error message, ensure the **NetSuite Data Warehouse** integration record is enabled. For more information, see [Enabling NetSuite Analytics Warehouse](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_159350029602.html).
    
2.  Click the **Set Up Data Transfer** tile. The NetSuite Analytics Warehouse Data Transfer Setup page opens.
    
3.  In the **Initial Extract Date** field, select the date from when you want your data transferred.
    
4.  In the **Subsidiary** field, select the subsidiary for which you want to transfer the data.
    
5.  Select the functional areas to include in the transfer.
    

Data from the selected functional areas is refreshed automatically every 24 hours. The **Last Transfer** column shows the date and time of the first automatic data transfer, or the last manual data transfer. You can see the time remaining before the next automatic data transfer above the functional area list.

The first data transfer may take some time. The subsequent data transfers happen incrementally every day.

You don't have to wait until the scheduled data transfer. If you want the latest data, click **Transfer Data** in the **Transfer Data** column to manually start a transfer for a specific functional area. You can see the last transfer date for each functional area in the **Status** column.

## Viewing the Data Transfer Audit Log {#subsect_0429042836}

You can use the NetSuite Analytics Warehouse Customization History page as a data transfer audit log to check and track all the data transfer operations and their statuses. It shows the operation name, status, and a time stamp for when each operation occurred.

Note:

You must be assigned the NSAW Administrator role to view the Data Transfer Audit Log page.

#### To view the data transfer audit log:

1.  Go to the Configuration page. For more information, see [Accessing the NetSuite Analytics Warehouse Configuration Page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_159472942033.html#subsect_0129115424).
    
    Note:
    
    The configuration page might take some time to load. If you get an error message, ensure the **NetSuite Data Warehouse** integration record is enabled. For more information, see [Enabling NetSuite Analytics Warehouse](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_159350029602.html).
    
2.  Click the **Set Up Data Transfer** tile. The NetSuite Analytics Warehouse Data Transfer Setup page opens.
    
3.  Click the **Audit Log** button.
