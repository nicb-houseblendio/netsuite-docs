Before you begin transferring your data to the Analytics Warehouse, you need to enable the feature first.

#### To enable NetSuite Analytics Warehouse in your account:

1.  Go to _Setup > Company > Enable Features_.
    
2.  Click the **Analytics** subtab.
    
3.  Check the **NetSuite Analytics Warehouse** box.
    

After completing these steps, you receive a NetSuite Analytics Warehouse welcome email. Follow the instructions in the email to activate your account.

NetSuite Analytics Warehouse requires these features to establish and maintain the pipeline between NetSuite and the Analytics Warehouse:

-   SuiteAnalytics Connect - In the **Analytics** subtab.
    
-   OAuth 2.0 / Token-based authentication (TBA) - In the **SuiteCloud** subtab.
    

When you enable **NetSuite Analytics Warehouse**, NetSuite automatically enables these two required features.

Warning:

If you clear the **SuiteAnalytics Connect** or **OAuth 2.0 / Token-based authentication** boxes, NetSuite automatically disables the **NetSuite Analytics Warehouse** feature. This deletes the Analytics Warehouse instance and all its data.

Note:

Since the 26.1 March minor release, all new NetSuite Analytics Warehouse accounts use **OAuth 2.0** instead of TBA. Existing accounts must use either **Token-based authentication** (checked by default when you enable NetSuite Analytics Warehouse) or **OAuth 2.0**.

After you complete these steps, your Analytics Warehouse account starts configuring. This process may take some time. When the configuration is complete, the **NetSuite Data Warehouse** integration record is created automatically.

Note:

The **NetSuite Data Warehouse** integration record state is set to **Enabled** by default. If its state is set to **Blocked**, you are not able to access the NetSuite Analytics Warehouse Configuration page. Complete the following steps only if you can't access the NetSuite Analytics Warehouse Configuration page after enabling the feature.

#### To enable the NetSuite Data Warehouse integration record:

1.  Go to _Setup > Integration > Manage Integrations_.
    
2.  Click the **NetSuite Data Warehouse** integration record.
    
3.  Click **Edit**. In the **State** field, choose **Enabled**.
    
4.  Click **Save**.
    

After enabling your account, you need to set it up by:

-   [Adding Users to NetSuite Analytics Warehouse](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_159497489716.html)
    
-   [Setting Up the Data Transfer](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_159497492876.html)
