## NetSuite Analytics Warehouse Data Lineage Mapping Guide {#subsect_1222020655}

A mapping guide is available in NetSuite Analytics Warehouse that helps you track the origins and transformations of your data. You can download a mapping guide file to trace your data from the NetSuite application to the Analytics Warehouse platform. This mapping guide helps you identify the fields in the Analytics Warehouse and relate them to the equivalent NetSuite fields. Seeing the relationship between the fields provides a better understanding of the Analytics Warehouse semantic layer and ensures better usage of the analytic tools. For more information, see [Understanding Data Lineage](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0317020250.html).

## Create User Groups for NetSuite Analytics Warehouse {#subsect_1222020754}

You can create user groups for NetSuite Analytics Warehouse for better efficiency and organization when adding application roles and security assignments. On the User Management page, you can create and edit groups, and add users to them. To add application roles and security assignments, go to the NetSuite Analytics Warehouse Console page. For more information, see [Creating User Groups for NetSuite Analytics Warehouse](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_159497489716.html#subsect_0822014332).
