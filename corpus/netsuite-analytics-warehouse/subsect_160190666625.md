To keep your data safe, you can reset your data transfer credentials anytime. When you reset your transfer credentials, new tokens are created and sent to NetSuite Analytics Warehouse automatically. Allow a few minutes for your transfer settings to finish configuring. You can't access the Configuration page during the time that your new transfer credentials are being set up,

To reset your transfer credentials, go to the Configuration page and click the **Reset Transfer Credentials** tile. By default, transfer credentials are assigned to the user who enabled NetSuite Analytics Warehouse. If you want to give the transfer credentials to a different user, choose that user from the dropdown list and click **Reset Transfer Credentials**.

Note:

You can give data transfer credentials only to a user with the Data Warehouse Integrator role. For more information, see [Data Warehouse Integrator Role](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_159350036029.html).

## Resolving the Invalid Credentials Error {#subsect_10122419620}

You always need a user with the Data Warehouse Integrator role and transfer credentials. If you receive an invalid credentials error email, you need to reset the transfer credentials. The data transfer to the Analytics Warehouse will pause until you add a valid user.

Note:

You must be assigned the NSAW Administrator role to complete these steps.

#### To resolve the error:

1.  Check the **User account for data transfer credentials** list, and ensure the list is not empty.
    
2.  Select the user from the list and click **Reset Transfer Credentials**.
    
3.  Go to the Analytics Warehouse Administration Console page. For more information, see [NetSuite Analytics Warehouse Basics](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160250775480.html).
    
4.  Click the **Data Configuration** tile, and then, the **Pipeline Settings** tile.
    
5.  Change the **Data Pipeline Status** switch to **Enabled**.
