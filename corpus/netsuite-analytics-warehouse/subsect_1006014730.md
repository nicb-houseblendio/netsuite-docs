You can add Analytics Warehouse workbooks to your dashboard using SuiteApp portlets instead. To do so, you need to:

1.  Enable the feature in the NetSuite Analytics Warehouse console.
    
    Note:
    
    You need to have the NSAW Administrator role assigned to complete this step.
    
2.  Set up a SuiteApp portlet by downloading and deploying the script file.
    
3.  Add the portlet to your dashboard. You can add up to six SuiteApp portlets.
    

Note:

You need to set up SAML SSO for NetSuite Analytics Warehouse before adding the workbooks to your dashboard. For more information, see [Setting up SAML SSO for NetSuite Analytics Warehouse](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1211045628.html).

#### To enable the feature in the NetSuite Analytics Warehouse console:

1.  Log in to your Analytics Warehouse instance.
    
2.  Click the Navigator menu icon ![Navigator icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/NetSuiteAnalyticsWarehouse/AnalyticsWarehouseNavigator_icon.png). Then, select **Console**.
    
3.  Click **Safe Domains**_._
    
4.  Click **Add domain** and paste your NetSuite account URL (https://_<accountID>_.app.netsuite.com/), where _<accountID>_ is your NetSuite account ID.
    
5.  Check all the boxes for the URL you added.
    

#### To download and deploy the script file:

1.  Download the script file by clicking this link: [nsawportlet.js](https://system.netsuite.com/core/media/media.nl?id=400036673&c=NLCORP&h=lORkci_RYT3N1Ysk1DqN0oWyxTQx4N1RZwnyrSpktWYhYWXH&_xt=.zip)
    
2.  Go to _Customization > Scripting > Scripts_\> New.
    
3.  Click the + icon next to **Script File**.
    
4.  In the **Select File** field, upload the script file you have downloaded in step 1. Click **Save**.
    
5.  Click **Create Script Record**. Fill out the following fields:
    
    -   In the **Name** field, type a name for your portlet based on the workbook you want to add (for example, NSAW Sales).
        
    -   In the **Portlet Type** field, select **Inline HTML** from the list.
        
    -   Click the **Parameters** subtab.
        
        -   Type _nsawurl_ in the **Label** and **ID** fields.
            
        -   Select **Hyperlink** in the **Type** field.
            
        -   Click **Add**, and then **Save**.
            
6.  Click **Deploy Script**. Fill out the following fields:
    
    -   Check the **Dashboard SuiteApp** box.
        
    -   In the **Status** field, select one of these options:
        
        -   **Testing** - The portlet is visible to you only.
            
        -   **Released** - The portlet is visible to the audience you specify.
            
    -   Click the **Audience** subtab and select the audience to which you want to make the portlet visible.
        
        Note:
        
        This is applicable only if you have selected **Released** in the **Status** field.
        
    -   Click the **Parameters** subtab. In the **NSAWURL** field, paste the URL of the workbook you want to add.
        
7.  Click **Save**.
    

#### To add the workbook to your dashboard:

1.  Go to your dashboard and click **Personalize**.
    
2.  On the **SuiteApps** tab of the **Personalize Dashboard** palette, click the workbook you have set up or drag it onto the dashboard.
    

Note:

The data in the portlet is generated based on the last incremental data transfer.
