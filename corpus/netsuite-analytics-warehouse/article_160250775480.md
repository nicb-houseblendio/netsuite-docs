To work with data transferred to the Analytics Warehouse, go to the Configuration page and click **Open NetSuite Analytics Warehouse**. For more information, see [Accessing the NetSuite Analytics Warehouse Configuration Page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_159472942033.html#subsect_0129115424). Your "Welcome to Oracle NetSuite Analytics Warehouse" email also contains a direct link to the service.

If you have the NSAW Administrator role, the Analytics Warehouse Administration Console page opens. Here you can perform service and application administrator tasks. It also contains a link to the Analytics Warehouse home page.

If you don't have the NSAW Administrator role, the Analytics Warehouse home page opens directly.

For more detailed information about working with data in the NetSuite Analytics Warehouse, see the following links:

-   [Get Started with Oracle NetSuite Analytics Warehouse](https://docs.oracle.com/en/cloud/saas/netsuite-analytics-warehouse/index.html)
    
-   [Access Oracle NetSuite Analytics Warehouse Content](https://docs.oracle.com/en/cloud/saas/netsuite-analytics-warehouse/nawug/access-faw-oac.html)
    
-   [Overview to Using Datasets](https://docs.oracle.com/en/cloud/paas/analytics-cloud/acubi/overview-using-datasets.html)
    

For more information about managing NetSuite Analytics Warehouse advanced settings, see [Configure Oracle NetSuite Analytics Warehouse Data](https://docs.oracle.com/en/cloud/saas/netsuite-analytics-warehouse/nsawa/configure-oracle-netsuite-analytics-warehouse-data.html#GUID-2B7824FC-ABBB-4E9C-ACFD-ADEF48B8CE2B).
