NetSuite Analytics Warehouse service tiers are designed to align with your needs and provide an optimal experience at various levels of scale. Each tier includes different services such as instances, warehouse storage, or number of users.

The table below summarizes the characteristics of the NetSuite Analytics Warehouse service tiers.

|  | NetSuite Analytics Warehouse Standard | NetSuite Analytics Warehouse Premium | NetSuite Analytics Warehouse Enterprise |
| --- | --- | --- | --- |
| **Instances** | 1 production instance | 1 production instance 1 sandbox instance | 1 production instance 1 sandbox instance |
| **Warehouse Storage** | 1TB | 3TB | 5TB |
| **Users Included** | 10 | 50 | 100 |
| **Additional User Packs (5 users each)** | Maximum of 7 user packs | Maximum of 9 user packs | ∞ |
| **Pre-built NetSuite Connector** | ✓ | ✓ | ✓ |
| **Additional NetSuite Connectors (MIC)** | ✗ | ✓ Maximum of 2 instances | ✓ Maximum of 10 instances |
| **DA Connector** | ✓ | ✓ | ✓ |
| **OAC Connector** | ✓ | ✓ | ✓ |
| **Data Transforms** (For more information, see [Using Oracle Data Transforms](https://docs.oracle.com/en/database/data-integration/data-transforms/using/supported-connection-types.html).) | ✓ No incremental synchronization Only the first six months after purchase | ✓ | ✓ |
| **Pre-built NetSuite Data Model** | ✓ | ✓ | ✓ |
| **Frequent Data Refresh** | ✗ | ✓ | ✓ |
| **AI Assistant** | ✓ | ✓ | ✓ |
| **Auto Insights** | ✓ | ✓ | ✓ |
| **Pre-built AI Predictive Models** | ✓ | ✓ | ✓ |
| **Oracle Machine Learning** | ✗ | ✗ | ✓ |
| **Adding Workbooks to your NetSuite Dashboard** (For more information, see [Adding NetSuite Analytics Warehouse Workbooks to a Dashboard](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_4185035324.html).) | ✓ | ✓ | ✓ |
| **Pre-built Analytics Warehouse Dashboards and Reports** | ✓ | ✓ | ✓ |
| **Oracle REST Data Service** | ✗ | ✓ | ✓ |
| **APEX** | ✗ | ✗ | ✓ |
| **Supported Languages** | English Arabic Chinese Simplified Chinese Traditional French Dutch |
