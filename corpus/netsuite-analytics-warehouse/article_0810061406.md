Saved searches in NetSuite Analytics Warehouse have the following known limitations:

-   **Complex saved searches may take a long time to run**. The connector has a 55-minute request timeout. If a saved search doesn't finish within 55 minutes, the Oracle Analytics Cloud (OAC) request times out. To improve reliability:
    
    -   Split or simplify a large search into smaller searches.
        
    -   Reduce the number of columns returned.
        
    -   Test the saved search directly in NetSuite before using it in OAC.
        
-   The following saved searches are not supported to create datasets in OAC:
    
    -   Inactive saved searches.
        
    -   Private saved searches.
        
    -   Titles containing two or more consecutive asterisks (\*\*).
        
    -   Titles containing a double quotation mark (").
        
    -   Titles containing a backslash (\\).
        
    -   Titles containing two consecutive colons (::).
        
    
    Note:
    
    For better results, use a simple saved search title containing letters, numbers, spaces, or underscores.
    
    If a saved search with special characters doesn't appear, can't be selected, or fails during dataset creation:
    
    1.  Check if the search runs successfully in NetSuite.
        
    2.  Ensure that it's shared with the authorized NetSuite account and it's public, not private.
        
    3.  Create a copy of the search with a simpler title and use this one for OAC dataset creation.
