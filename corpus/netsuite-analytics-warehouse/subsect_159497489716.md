Adding users to your account enables them to work with data transferred to NetSuite Analytics Warehouse. You can add NetSuite users and non-NetSuite users.

#### To add NetSuite users to your NetSuite Analytics Warehouse account:

1.  Go to the Configuration page. For more information, see [Accessing the NetSuite Analytics Warehouse Configuration Page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_159472942033.html#subsect_0129115424).
    
    Note:
    
    The configuration page might take some time to load. If you get an error message, ensure the **NetSuite Data Warehouse** integration record is enabled. For more information, see [Enabling NetSuite Analytics Warehouse](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_159350029602.html).
    
2.  Click the **Manage Users** tile. The NetSuite Analytics Warehouse User Management page opens.
    
3.  At the bottom of the page, click **Add NetSuite Users**.
    
4.  Select the users you want to add and click **Apply**.
    

#### To add an external user to your NetSuite Analytics Warehouse account:

1.  Go to the Configuration page. For more information, see [Accessing the NetSuite Analytics Warehouse Configuration Page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_159472942033.html#subsect_0129115424).
    
    Note:
    
    The configuration page might take some time to load. If you get an error message, ensure the **NetSuite Data Warehouse** integration record is enabled. For more information, see [Enabling NetSuite Analytics Warehouse](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_159350029602.html).
    
2.  Click the **Manage Users** tile. The NetSuite Analytics Warehouse User Management page opens.
    
3.  At the bottom of the page, click **Add External User**.
    
4.  Enter the first name, last name, and email address of the user. Then click **OK**.
    

You need to specify a role for every user you add to the NetSuite Analytics Warehouse account. To do so, select a role from the **NSAW Role** list. The following roles are available:

-   **NSAW Administrator** - Lets you perform all administrator related activities, manage data components, and create data visualizations in the Analytics Warehouse.
    
-   **NSAW Author** - Lets you manage data components and create data visualizations in the Analytics Warehouse.
    
-   **NSAW Viewer** - Lets you view data components and visualizations in the Analytics Warehouse.
    

Note:

There must be a minimum of two NetSuite users with the NSAW Administrator role.

All new users, whether they're NetSuite or external, get an email notification asking them to complete their account activation and set a password. Use these credentials to log in to the Analytics Warehouse.

## Creating User Groups for NetSuite Analytics Warehouse {#subsect_0822014332}

In NetSuite, you can create user groups for NetSuite Analytics Warehouse and manage the users in each group. You can then use these groups to add application roles and security assignments.

Note:

You need to have the Administrator role assigned to create and manage groups. Application roles and security assignments are managed on the NetSuite Analytics Warehouse Console page. For more information, see [Manage Users, Groups, and Application Roles](http://docs.oracle.com/en/cloud/saas/netsuite-analytics-warehouse/nsawa/manage-users-groups-application-roles.html).

#### To create and manage user groups:

1.  Go to the Configuration page. For more information, see [Accessing the NetSuite Analytics Warehouse Configuration Page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_159472942033.html#subsect_0129115424).
    
    Note:
    
    The configuration page might take some time to load. If you get an error message, ensure the **NetSuite Data Warehouse** integration record is enabled. For more information, see [Enabling NetSuite Analytics Warehouse](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_159350029602.html).
    
2.  Click the **Manage Users** tile. The NetSuite Analytics Warehouse User Management page opens.
    
3.  Click the button **Create Group** to create a new group. Add a name and a description for the group.
    
4.  Click the **Edit Group Users** icon ![images/edit.png](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/NetSuiteAnalyticsWarehouse/edit.png). The **Edit Group Users** window appears.
    
5.  Select the users you want to add to the group on the left pane. Then, move them to the right pane and click **Apply**.
    
6.  To view the users that are part of the group, click the **View Group Users** icon ![view group users](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/NetSuiteAnalyticsWarehouse/view_goup_users.png).
    
7.  To delete a group, click the delete icon ![delete](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/NetSuiteAnalyticsWarehouse/delete.png) in the **Actions** column.
