Information about a Municipal can be specified on the DATR Municipal Information page that has fields to enter the Japan subsidiary, Municipal and other details.

## Requirements and Validations for Specifying Municipal Information {#bridgehead_162624125217}

Before specifying a Municipal Information, you must have performed these steps:

-   created a Municipal record, which will be associated with the Municipal Information; and
    
-   set up the Reporting Information of the subsidiary that will be assigned to the Municipal Information.
    

Before specifying Municipal Information, you should consider these validations:

-   Municipal Information should be unique for each Municipal . If a Municipal already has a corresponding Municipal Information record, duplicate records can't be created.
    
-   A Municipal record shouldn't necessarily have a corresponding Municipal Information record.
    

#### To specify Municipal Information:

1.  Go to Depreciable Assets > Setup > Municipal Information > New.
    
2.  On the DATR Municipal Information page, enter values for these fields:
    
    -   **Reporting Information** - Select the corresponding Japan subsidiary under the Municipal.
        
    -   **Municipal** - Select the Municipal whose information you will specify.
        
3.  You can specify information in these optional fields by checking the corresponding boxes of the features, records, and settings that are enabled or existing in your account.
    
    | English Label | Japanese Label |
    | --- | --- |
    | Approved Useful Period of Asset | 短縮耐用年数の承認 |
    | Notify for Increase in Depreciation | 増加償却の届出 |
    | Non-taxable Assets | 非課税該当資産 |
    | Standard Tax Exemption | 課税標準の特例 |
    | Leased Assets | 借用資産 |
    | Blue-form Return | 青色申告 |
    
4.  Click **Save**.
