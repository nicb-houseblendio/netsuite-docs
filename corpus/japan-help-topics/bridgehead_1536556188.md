Perform these steps to install the Japan Financial Statements SuiteApp.

#### To install the Japan Financial Statements SuiteApp:

1.  Go to _Customization > SuiteBundler > Search & Install Bundles_.
    
2.  In the **Keywords** field, enter 'Japan Financial Statements', or 519372, the Bundle ID.
    
3.  Click **Search**. Japan Financial Statements, Bundle ID 519372, should appear in the search result.
    
4.  Click the Japan Financial Statements link.
    
5.  On the Bundle Details page, click **Install**.
    
    For more information about installing SuiteApps, see [Installing a Bundle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3395142.html).
    
6.  If you've other saved reports in your account, ensure that they are compatible with the saved reports included with the SuiteApp. On the Preview Bundle Install page, ensure that no saved report is indicated under the **Existing Object in Conflict** column. If there is a report under that column, go to the **Action** column and select **Replace Existing Object**.
    

The Japan Financial Statements SuiteApp is a managed bundle and is automatically updated whenever there are enhancements or new features released.
