Important:

To use Japanese invoicing features, you should install the Japan Localization SuiteApp. This SuiteApp isn't compatible with the SuiteTax feature. If the SuiteTax feature is enabled in your NetSuite account, don't install the Japan Localization SuiteApp.

The Japan Localization SuiteApp provides these features that support Japanese invoicing:

-   Multiple payment terms to manage a Japanese customer's billing cycle - See [Japanese Billing Cycle and Payment Terms](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1536510.html).
    
-   Japanese holiday checking for payment due date - See [Setting Up Japanese Holidays to Validate Payment Due Dates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4355767272.html)
    
-   Japanese Invoice Summary - See [Japanese Invoice Summary](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1536907.html).
    
-   [Support for Japan Qualified Invoicing System](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0306032503.html) - this includes adjusted computation of consumption tax in the invoice summary, and reconciliation in the difference of tax amount between the transaction level and invoice summary.
    
-   XML template for generating a Japanese Invoice Summary - See [Customizing the Japanese Invoice Summary XML Template](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N1539711.html).
    
-   Invoice Summary Collection Calendar Report - See [Invoice Summary Collection Calendar Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4327112408.html)
    

For information about roles and permissions, see [Roles and Permissions for Using Japanese Invoicing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4357171134.html).

To include Japan Localization custom fields on custom forms, see [Including Japan Localization Custom Fields in Custom Forms](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4359065189.html).
