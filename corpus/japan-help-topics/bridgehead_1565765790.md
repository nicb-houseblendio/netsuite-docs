Only the Administrator role has default permission to use the Japan Consumption Tax and set it up. However, the administrator can grant other roles the permission to use Japan Consumption Tax, with these steps.

#### To grant roles the permission to use the Japan Consumption Tax:

1.  Add the roles you want to grant permission as Audience for relevant script deployments:
    
    1.  Go to Customization > Scripting > Script Deployment.
        
    2.  Edit these script deployments:
        
        -   customdeploy\_su\_jp\_sales\_purchase\_report
            
        -   customdeploy\_rs\_jp\_sales\_purchase\_report
            
        -   customdeploy\_jp\_deduc\_print\_rs
            
    3.  On the **Audience** subtab, add the custom role to the Roles field.
        
    4.  Save the script deployments.
        
2.  Edit the roles to add permissions to accounting preferences and accounting period:
    
    1.  Go to Setup > Users/Roles > Manage Roles.
        
    2.  In the Mange Roles list, click the Edit or Customize link of the roles you added as Audience for script deployments.
        
    3.  On the Role page, go to the **Permissions** subtab, click **Setup** and do these steps:
        
        -   Add **Accounting Preferences** and set its permission Level to **Full**.
            
        -   Add **Manage Accounting Periods** and set its permission Level to **View**.
            
    4.  Save the changes.
        
3.  Grant the roles access permission to relevant saved reports.
    
    1.  Edit these saved reports:
        
        -   Sales by Tax Classification Report
            
        -   Purchase by Main Tax Category Report
            
    2.  Click **More Customization**, and then click **More Options**.
        
    3.  Go to the **Access** subtab, and under the **Roles** list, select the roles you specified in previous steps.
        
    4.  Click **Save**.
