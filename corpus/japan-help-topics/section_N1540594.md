The NetSuite Japan edition provides multiple language capability for NetSuite custom elements. Depending on your user language preferences, you can see labels or values in your own language in the user interface.

Custom elements supported are:

-   Custom Lists
    
-   Custom Fields
    
-   Custom Subtabs
    
-   Custom Item Options
    
-   Custom Records
    

Important:

To use this feature, you must enable the Multi-Language feature in _Setup > Company > Enable Features_.

For more information about how to enter translations for custom elements, refer to [Working With Multi-Language Names and Descriptions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2178279.html).

Note:

Some Japanese characters aren't displayed correctly with only NetSuite's default font packages, because Japanese characters are part of the Adobe original font set. To display Japanese characters correctly and consistently, you can set custom templates to use the Adobe font set, which requires a license from Adobe.
