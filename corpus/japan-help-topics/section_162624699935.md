To generate depreciable assets reports and corresponding tax reports, the Japan Fixed Assets Report SuiteApp references depreciable asset records that you must create from Asset records of the Fixed Assets Management (FAM) SuiteApp. Therefore, FAM is a requirement and must be installed and set up before using the Japan Fixed Assets Report SuiteApp. Then, FAM Asset records must be created. To create Asset records in FAM, see, [Creating Asset Records Manually](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164689339824.html).
