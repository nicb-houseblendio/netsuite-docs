In Japan edition NetSuite accounts, the **Tax Category** field is shown on purchase orders, vendor bills, vendor return authorizations, vendor credits, expense reports, and journal entries.

To apply the individual calculation method when calculating the deductible purchase tax amount, you must select a tax category on your purchase transactions or journal entries.

In the **Tax Category** field, you can select these predefined tax categories:

-   Taxable - Refund
    
-   Taxable - Import
    
-   Taxable - Import Tax
    
-   Non-taxable - Refund
    
-   Non-taxable - Import
    
-   Non-taxable - Import Tax
    
-   Common - Refund
    
-   Common - Import
    
-   Common - Import Tax
    
-   Local Tax for Import
    
-   Not Applicable
