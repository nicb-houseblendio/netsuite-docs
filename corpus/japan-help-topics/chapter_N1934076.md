NetSuite and the Japan Localization SuiteApp provide tax features and tax records specific to Japan. The SuiteApp also enables you to calculate Japan consumption taxes, accomplish the Japan Consumption Tax Form, and use tax reports.

To use the Japan Consumption Tax Form and other Japan tax features, you must install the Japan Localization SuiteApp, with Bundle ID: 473889 or later versions.

Note:

The Japan Localization SuiteApp isn't compatible with the SuiteTax feature. If the SuiteTax feature is enabled in your NetSuite account, don't install the Japan Localization SuiteApp.

A new installation of the Japan Localization SuiteApp will automatically provide these tax records:

-   Tax codes (to be used starting October 1, 2019)
    
-   Tax types
    
-   Tax control accounts
    
-   Tax agency
    

Note:

If your account already has the Japan Localization SuiteApp installed, you must manually create the new tax codes that become effective on October 1, 2019. The new tax codes should be set up using the correct tax classification. Tax category mapped to main tax category must be set on purchase transactions.

To begin using Japan tax features, do these steps:

-   Install the Japan Localization SuiteApp. See [Installing the Japan Localization SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1516002472.html).
    
-   Set your tax preferences. See [Setting Up Consumption Tax - Japan](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1934652.html).
    
-   Set up the rounding method and precision. See [Setting Tax Rounding Methods - Japan](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1935242.html) and [Selecting Precision Settings - Japan](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1937177.html).
    
-   Set tax rounding preferences for customers and vendors. See [Setting Tax Rounding Preferences for a Customer or Vendor - Japan](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1937473.html).
    

Note:

Currently. Reverse Charge reporting on imports isn't supported in Japan.
