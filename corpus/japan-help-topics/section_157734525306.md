Important:

Support for this financial statement will end starting 2025. You must transition to using the new Japan Trial Balance from Reports > Financial > Japan Trial Balance New. For more information, see [Japan Trial Balance New](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0306042140.html).

The Japanese Trial Balance is a report that shows active account balances in credit and debit columns, for a specific period, usually at the end of the month. You can run this report before preparing financial statements to ensure that debits and credits balance out.

These steps generate the trial balance report.

#### To define and generate the Japanese Trial Balance:

1.  Go to Reports > Financial > Japanese Trial Balance.
    
2.  (For OneWorld accounts) In the **Subsidiary** field, select the subsidiary or company that you want to generate a trial balance for. Only Japanese subsidiaries are available in the dropdown list.
    
3.  In the **From** field, specify a start date. In the **To** field, specify an end date. These dates define the period that the trial balance will cover.
    
4.  (Optional) You can select values in the Department, Class or Location fields. If you select a Department, Class or Location, the financial statement will include the items, accounts or transactions that have the selected classifications specified in their records.
    
    Note:
    
    Debits and credits may not balance out if you use classification filters.
    
5.  Click **Refresh**.
    
    The trial balance is generated and displayed based on the values you specified in the fields.
    
    Every time you change any field values, like specifying a different period or subsidiary, be sure to click Refresh to apply the new values in the trial balance.
    
    Note:
    
    To prevent the build-up of old data and ensure optimal system performance, a scheduled script regularly deletes data of Japan financial reports from the previous day. If you're viewing a financial report and its report data is deleted at the same time, an error message will be displayed indicating: 'The report generation session timed out. You should regenerate the report'. If you encounter this, you should regenerate the financial report you're viewing.
    
6.  To generate a PDF file or Excel file of the balance sheet, click **Export to PDF** or **Export to Excel**. The generated PDF or Excel file of the trial balance isn't automatically saved in the File Cabinet.
    

View [Sample Trial Balance](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1229053737.html).
