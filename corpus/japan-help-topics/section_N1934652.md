A new installation of the Japan Localization SuiteApp will automatically provide these tax records:

-   Tax codes (to be used starting October 1, 2019)
    
-   Tax types
    
-   Tax control accounts
    
-   Tax agency
    

Note:

If your account already has the Japan Localization SuiteApp installed, you must manually create the new tax codes that become effective on October 1, 2019. The new tax codes should be set up using the correct tax classification. Tax category mapped to main tax category must be set on purchase transactions.

Read the following topics to understand how to set up Japan Consumption Tax:

-   [Roles for Setting Up Japan Consumption Tax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_1565765790.html)
    
-   [Setting Up Provisioned Tax Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_1565856602.html)
    
-   [Tax Preferences for Japan](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N1934692.html)
    
-   [Tax Control Accounts for Japan](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N1935017.html)
    
-   [Tax Codes for Japan](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N1935056.html)
    
-   [Specifying Deductible Rate on Tax Code Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_0626103110.html)
    
-   [Tax Classifications for Japan](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_1565774729.html)

In addition, you can select company-wide rounding settings, rounding methods, and precision settings for consumption tax. For more information, see [Selecting Precision Settings - Japan](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1937177.html) and [Setting Tax Rounding Methods - Japan](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1935242.html).
