The tax classifications must be manually set for the provisioned tax codes so that transaction amounts will be set in the correct boxes on the Japan Consumption Tax Form.

Tax classifications are available on the tax code and displayed from Setup > Accounting > Tax Code > Tax Classification.

Japan tax classifications:

| English | Japanese |
| --- | --- |
| Consumption Tax 10% (Standard) | 消費税 10%(標準) |
| Consumption Tax 8% (Reduced) | 消費税 8%(軽減) |
| Consumption Tax 3% (Legacy) | 消費税 3%(旧) |
| Consumption Tax 5% (Legacy) | 消費税 5%(旧) |
| Consumption Tax 8% (Legacy) | 消費税 8%(旧) |
| Consumption Tax 10%(Standard) for Non Qualified Invoice Issuer | 非適格請求書発行事業者の消費税10% (標準) |
| Consumption Tax 8%(Reduced) for Non Qualified Invoice Issuer | 非適格請求書発行事業者の消費税 8%(軽減) |
| Consumption Tax 3%(Legacy) for Non Qualified Invoice Issuer | 非適格請求書発行事業者の消費税 3%(旧) |
| Consumption Tax 5%(Legacy) for Non Qualified Invoice Issuer | 非適格請求書発行事業者の消費税 5%(旧) |
| Consumption Tax 8%(Legacy) for Non Qualified Invoice Issuer | 非適格請求書発行事業者の消費税 8%(旧) |
| Special Non-taxable Sales | 非課税資産の輸出等 |
| Others, Taxable Freight Consumption Tax 10% | 課税貨物に係る、消費税 10%(標準) |
| Others, Taxable Freight Consumption Tax 8% (Reduced) | 課税貨物に係る、消費税 8%(軽減) |
| Others, Taxable Freight Consumption Tax 8% (Legacy) | 課税貨物に係る、消費税 8%(旧) |
| Others, Specified Taxable Purchase, Consumption Tax 10% | 特定課税仕入に係る、消費税 10%(標準) |
| Others, Specified Taxable Purchase, Consumption Tax 8% (Legacy) | 特定課税仕入に係る、消費税 8%(旧) |
| Taxable | 課税 |
| Non-taxable | 非課税 |
| Tax-exempt | 免税 |
