Adding translations for Holiday Types is optional. Do these steps if you want users to see translated names of Holiday Types depending on the language they specified on their Set Preferences page.

#### To include translations for a Holiday Type:

1.  Enable the Multi-Language feature by doing these steps:
    
    1.  Go to _Setup > Company > Enable Features_.
        
    2.  On the **Company** subtab, check the **Multi-Language** box.
        
    3.  Click **Save**.
        
2.  Add languages by doing these steps:
    
    1.  Go to _Setup > Company > General Preferences_.
        
    2.  On the **Languages** subtab, add languages.
        
    3.  Click **Save**.
        
        On the Holiday Type record, the **Language** column will display fields for the languages you selected. You can enter the translation of the Holiday Type in the **Name** field of the corresponding language.
