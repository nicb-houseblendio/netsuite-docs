The Japan Localization SuiteApp includes a saved search, Invoice Summary Transaction Search, which you can use as a template to create or customize the custom statement search. Or, you can create a new statement saved search. For more information about creating a saved search, see Defining a Saved Search.

#### To define filters to optimize custom statement search: {#procedure_0809093909}

1.  Edit the Invoice Summary Transaction Saved Search.
    
2.  On the **Standard** subtab, under the **Filter** column, find **Invoice Summary Transaction: Internal ID**.
    
3.  In its corresponding **Description** column, specify, **is (internal ID of the previously generated invoice summary)**.
    
4.  Ensure that the filter before this has the AND operator.
    
5.  Click **Preview** to check the resulting transactions of the search.
    
    Only the transactions that are included in the Invoice Summary set by the filter, should be displayed.
    
    This will optimize the saved search when it runs through the generation process, ensuring that only the transactions included with the invoice summary will be the result of the saved search.
    
    Note:
    
    Don't enclose in parenthesis the entire saved search filter. This will result in a malformed search filter error during generation.
    
6.  Save the saved search.
    
7.  To check if the saved search is working, remove the Invoice Summary Transaction filter when the saved search is ready for use in production.
