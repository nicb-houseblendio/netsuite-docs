Before installing the Japan Fixed Assets Reports SuiteApp, you must complete these requirements.

## Requirements of the Japan Fixed Assets Reports {#bridgehead_162622985795}

Before installing the Japan Fixed Assets Reports SuiteApp, these are required:

-   For OneWorld, you must have Japanese subsidiaries. The SuiteApp only works with Japanese subsidiaries.
    
    Without OneWorld, you must be using the NetSuite Japan edition.
    
-   The Fixed Assets Management (FAM) SuiteApp must be installed and set up, because depreciable asset records are created from FAM asset records.
    
    Important:
    
    The version of FAM must be from the same release period as the Japan Fixed Assets Reports version. For example, FAM must first be upgraded to its 2023.1 version, and then Japan Fixed Assets Reports can be upgraded to the compatible version 2.0, from the same release period. Every time a new version of FAM is released, a compatible version of Japan Fixed Assets Reports SuiteApp will also be released.
    

In addition, before installing the Japan Fixed Assets Reports, these features must be enabled:

1.  Go to Setup > Company > Enable Features.
    
2.  Enable Accounting features:
    
    1.  Click the **Accounting** subtab.
        
    2.  Under Basic Features, check **Accounting**.
        
3.  Enable Custom Records and Server SuiteScript features:
    
    Click the **SuiteCloud** subtab and do these steps:
    
    -   Under SuiteBuilder, check **Custom Records** and **Advanced PDF/HTML Templates**.
        
    -   Under SuiteScript, check **Server SuiteScript**.
        
    -   Under SuiteCloud Development Framework, check **SuiteCloud Development Framework**.
        
4.  Click **Save**.
    

## Installing the SuiteApp {#bridgehead_162623945947}

After completing the requirements, you can install the Japan Fixed Assets Report SuiteApp, which is available from the SuiteApp Marketplace. Any role with access to the SuiteApp Marketplace in NetSuite can install the SuiteApp.

Note:

Consider the following:

-   You can install Japan Fixed Assets Reports SuiteApp to accounts with or without the SuiteTax feature enabled.
    
-   The versions of the Japan Fixed Assets Reports and the required Fixed Assets Management must be from the same release period. For example, both versions of the SuiteApps must be from the 2023.1 NetSuite release.
    

#### To install the Japan Fixed Assets Report SuiteApp:

1.  From the NetSuite Home page, click the **SuiteApps** tab.
    
2.  In the **Search SuiteApps** field, type '**Japan Fixed Assets Report**'.
    
3.  Click the **Japan Fixed Assets Report** tile.
    
4.  Click **Install**.
    

For more information, see [Installing from the SuiteApp Marketplace](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1539799323.html) and [SuiteApp Marketplace in NetSuite](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1539797981.html).

The Japan Fixed Assets Reports SuiteApp is a managed bundle and is automatically updated whenever there are improvements or new features added.

Note:

After installing the Japan fixed Assets Report SuiteApp, you should create a Report Folder in Documents > Files > SuiteScripts > DATR. Generated fixed asset reports will be stored in this folder. Then, indicate the folder path in the Report Folder field, on the Reporting Preferences page. For more information, see Specifying Reporting Preferences for Depreciable Asset Tax Report.
