You can specify which tax rates to include when printing the Japan Consumption Tax Form.

#### To set the Consumption Tax Form Print Option:

1.  Open the **Japan Localization Setup** subtab:
    
    -   (With OneWorld) Go to Setup > Company > Subsidiaries. Edit a Japan subsidiary, and then click the subtab.
        
    -   (Without OneWorld) Go to Setup > Company > Company Information, and then click the subtab.
        
2.  On the subtab, in the **Consumption Tax Form Print Option** field, choose any one of these options:
    
    -   **Print Including Previous Rate** - If selected, this option will print Tables 1, 2, 1-1, 1-2, 2-1 and 2-2.
        
    -   **Print Current Standard Rate and Reduced Rate Only** - The default option. If selected, this option will print Tables 1, and 2, as well as the new Tables 1-3 and 2-3.
        
    
    If you don't specify a print option, the default is **Print Current Standard Rate and Reduced Rate Only**.
    
3.  Click **Save**.
