There are two sets of balance sheet templates that are included with the SuiteApp: one for the Comparative Balance Sheet and the other for the non-comparative balance sheet.

In customizing either balance sheet template using the Financial Report Builder, you must define the main header rows as 'Assets', 'Liabilities', and 'Equities'. Otherwise, an error is displayed when you refresh the Japanese Balance Sheet page. For more information, see [Editing Financial Statement Header and Summary Rows](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2115720.html).

If you customize the Comparative Balance Sheet template and edit the columns, ensure that in the **Alternate Period Range** field, you select **Same Period Last FY**.
