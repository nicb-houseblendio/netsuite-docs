From a custom record in the source account, click **Copy to Account**.

Note:

The **Copy to Account** link appears only on custom record types that are associated with objects supported by SDF. Single Page Application (SPA) objects cannot be copied using Copy to Account. For a list of supported types, see [Customizations Supported by SuiteCloud Development Framework](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4706653920.html).
