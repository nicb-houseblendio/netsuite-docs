To copy an object into another account, the Copy to Account tool goes through the following steps:

1.  [Starting Copy to Account on a Custom Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1548372335.html)
    
2.  [Selecting a Target Account](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1548372307.html)
    
3.  [Selecting Dependencies to Copy](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1548372263.html)
    
    Tip:
    
    When selecting dependencies to copy, you may see an error that indicates a dependency is not available for copy. For more information, see [Handling Dependency Errors](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1543940935.html).
    
4.  [Previewing the Copy](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1548372214.html)
    
5.  [Deploying a Custom Object](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1548372172.html)
    

After a deployment, you can go to the target account to download the log. For more information, see [Viewing the Copy to Account Log](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1548372088.html).
