You can update the ID of any custom objects after creation, except for custom segments. Use this feature with caution, as changing an ID used in a script can break the script without warning.

For information about best practices and naming conventions, see [Conventions for Naming Custom Objects](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_162428958352.html).

#### To change the ID or Script ID of a custom object:

1.  Go to the custom object page and click **Change ID**.
    
2.  In the **New ID** field, enter the new ID.
    
3.  Click **Save**.
