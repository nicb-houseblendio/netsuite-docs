This topic provides an example scenario and AI description for a custom record type. For general information about the AI Description field, see [AI Description for Custom Object Definitions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0109014837.html).

## Scenario {#subsect_0109022144}

You manage a retail business and need to track seasonal promotions across all your stores. You decide to create a custom record in NetSuite called Seasonal Promotion to store details about each promotion, including start/end dates, discount rates, and participating store locations.

## AI Description {#subsect_0109022215}

You could enter a description similar to the following into the AI Description field:

Tracks retail promotions offered during specific seasons, including promotion name, dates, discount rate, and the stores involved. Used to plan, manage, and report on sales campaigns across multiple locations.
