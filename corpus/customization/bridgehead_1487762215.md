Use the Store Value box to control whether NetSuite saves a custom field's default value or reevaluates the default dynamically.

| Store Value Setting | When to use it | Result |
| --- | --- | --- |
| Checked | Check this box when the field should retain its initially evaluated default value. | NetSuite saves the value. It does not update dynamically when related field values change. |
| Cleared | Clear this box when the field must reflect changes to a dynamic default or its related values. | NetSuite reevaluates the dynamic default when the page loads and saves. NetSuite tags are substituted each time. |

**Example: Sourcing a value from another record**

Suppose you create a transaction body field that sources a customer's phone number. Select the Store Value box if each transaction must retain the phone number that was sourced when the transaction was created. Clear the Store Value box if you want NetSuite to update the sourced value when the customer's phone number changes.

**Example: Recalculating a formula**

Suppose you create a custom formula field named Remaining Credit. The formula uses the customer's credit limit and balance. Clear the Store Value box so NetSuite recalculates the value each time the field is viewed. If you change a field used in the formula when the record is open, reload the record to recalculate the formula.
