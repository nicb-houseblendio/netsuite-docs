This example describes the steps for creating dependent dropdown lists for the shirt style scenario described in [Dependent Dropdown Lists Example](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162153822814.html), which you should read before continuing. For this example, the available shirt style selections depend on what is entered for the shirt size and shirt color.

Complete the following steps:

1.  [Steps for Creating the Custom Lists and Custom Record Type for Dependent Dropdown Lists](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_162153908411.html)
    
2.  [Steps for Creating Custom Transaction Line Fields and Setting up Filtering for Dependent Dropdown Lists](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_162154004530.html)
