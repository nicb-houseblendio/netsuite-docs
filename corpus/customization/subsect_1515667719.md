When you print a form, a preview page shows you what the printed transaction will look like. When you click Print on the preview page, the browser opens a print options page. The print preview looks different in each browser, which isn't related to NetSuite. You may need to change the browser print settings or the printer settings so that the printout looks the same as it did in the NetSuite preview.
