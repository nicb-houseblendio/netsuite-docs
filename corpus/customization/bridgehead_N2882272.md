This topic describes how to translate custom record subtab titles. For an overview of translation options, see [Adding Translations for Custom Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2882154.html).

You can define translations for a custom record type's subtab titles, on the Subtabs subtab of the custom record page:

![Sample Subtabs subtag with Translation edit button highlighted.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/SuiteBuilderCustomization/CustRecTransSubtab.png)

For details about custom record subtabs, see [Adding Subtabs to a Custom Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2877748.html).
