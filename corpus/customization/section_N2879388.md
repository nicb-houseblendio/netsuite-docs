The topics in this section provide an overview of managing access to custom record type data in NetSuite. To meet different business and security needs, you can define permission models, understand recent changes to access options, and restrict user interface access to custom records.

To manage access to custom record type data, you can:

-   [Define the Permission Model for a Custom Record Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N2879432.html) to use permissions on role records, use permissions defined on the custom record itself, or provide public access to the custom record type.
    
-   [Prevent Access to a Custom Record Type through the User Interface](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N2879618.html) so that users can't access custom record type data through the NetSuite user interface.
    

For information about recent changes to access types, see [Changes to 'No Permission Required' Access on Custom Record Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_0816050536.html)
