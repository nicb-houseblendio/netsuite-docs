This topic summarizes the impact of setting currency context for custom fields. For overview information about the Currency Context subtab, see [Setting Currency Context for a Currency Custom Field](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0511114806.html).

When a currency symbol field is defined:

-   Values display with the appropriate currency based on the selected Currency Symbol Field
    
-   Reports and analytics can correctly interpret currency values based on the selected currency field
    
-   Totals and calculations follow currency-aware rules
    

When no currency context is defined:

-   Values display as plain numbers
    
-   Currency-specific processing is not applied
    

For information about setting the currency symbol field, see [Setting the Currency Symbol Field on the Currency Context Subtab](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0511120459.html).
