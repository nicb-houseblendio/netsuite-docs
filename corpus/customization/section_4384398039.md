If needed, you can create default values for custom segments. For any segment, you can use one or both of the following options:

-   You can choose any of the segment's available values and make it the static default. That value is automatically selected on all new records that use the segment, unless other logic creates an alternate default. For details, see [Configuring Static Defaults for Custom Segments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4384398405.html).
    
-   You can configure logic that dynamically generates default values. You can specify varying logic for various groups of record types. With this approach, the default for a record is derived from the segment value that was saved on a related record. If a dynamic default value is loaded on a record, it overrides a static default. For more details, see [Dynamic Default Value Sourcing for Custom Segments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4384326119.html).
