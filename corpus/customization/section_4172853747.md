For help getting started with the Custom Transactions feature, see the following topics:

-   [Enabling the Custom Transactions Feature](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4230577490.html) (required)
    
-   [Granting a Role Permission to Manage Custom Transaction Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4229706425.html) (optional)
    

After you've enabled the feature, authorized users can create custom transaction types, as described in [Creating and Editing Custom Transaction Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4172784423.html). After custom transaction types have been created, authorized users can enter transaction instances by going to _Customization > Lists, Records, & Fields > Transaction Types_, and clicking the New Transaction link for the required transaction type.

If appropriate, you can also configure other menu paths for entering custom transactions. This process is described in [Creating Links for a Custom Transaction Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4177822787.html).
