If you have the appropriate privileges, you can change a custom segment's values by editing the segment's Values sublist. This approach lets you view all list values as you change the list.

For details about the permissions required to complete this procedure, see [Required Permissions for Editing Custom Segment Values](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4381110812.html). For an alternative method of editing values, see [Editing Values of a Custom Segment by Clicking Manage Values](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4381112394.html).

#### To edit a custom segment's values by updating the segment definition: {#procedure_4381112908}

1.  Edit the custom segment.
    
2.  Find the value you want to change in the Values subtab. Make any of the following changes as needed:
    
    -   In the **Value** column, you can change the value's name. The value's name is displayed in the segment's list when the segment appears on a record.
        
    -   If your account uses the Multi-Language feature, and you want to change translations for the value's name, click in the **Translation** column. The system displays a popup window. Make any necessary translation changes. When you're finished, click **Done**.
        
        ![Sample translations popup window.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/SuiteBuilderCustomization/segmentTranslation.png)
    -   If you want to create a parent or change the value's parent, click in the **Parent** column. The system displays a list. Make any changes to the list as needed. For details about parent-child relationships, see [Creating Hierarchies Among the Values of a Custom Segment](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4376484409.html).
        
    -   If you want to change whether this value is visible to users, click in the **Inactive** column to display a check box. Check or clear the box as needed. Note that making the value inactive prevents the value from appearing as a stand-alone choice. However, if the value is a parent to another value, the value still appears as a parent.
        
    -   If this segment uses filtering, you may want to create, change, or clear criteria for determining when this value is available. In this case, click the name of the value to display a series of buttons. Click **Set Filters** to display a popup window. The popup window shows the other classification fields you can use to set conditions for this value's availability. Make the appropriate changes. Then click **Set** to close the window. Click **OK** to close the series of buttons and save the filtering choices. For more information about filtering, see [Filtering for a Custom Segment](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4376692773.html).
        
3.  If you have more values to change, repeat Step 2.
    
4.  On the segment definition, click **Save**.
