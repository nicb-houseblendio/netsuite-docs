This topic describes how to delete custom segment values by editing the Values sublist within the segment definition, a method available if you have permission to edit the segment. For more information and other deletion options, see [Deleting the Values of a Custom Segment](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4316016599.html).

In some cases, you may have a set of permissions that includes the ability to edit the segment definition. In these cases, you can delete values by editing the segment's Values sublist. This approach lets you view all values as you change the list.

#### To delete a custom's segment value from within the segment definition: {#procedure_4383419730}

1.  Edit the custom segment.
    
2.  Find the value you want to delete. Click anywhere in that row to enable a series of buttons.
    
3.  Click **Remove**.
    
4.  Click **Save**.
