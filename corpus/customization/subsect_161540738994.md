This topic provides an example of overriding the value of a segment or field on a line with an assembly component. For general information about the Apply to Kit or Assembly Components setting, see [Apply to Kit or Assembly Components Setting for Custom Segments and Transaction Line Custom Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161540199813.html).

In the following example, for the Inventory and Child terms, you can override the original values in the Kitlinefield and the Kitsegment columns.
