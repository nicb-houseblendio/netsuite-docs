You can use the Fields subtab to add fields to your record. Add as many fields as needed to your custom record. If any custom segments have been applied to this custom record type, they're listed on the Fields subtab. Custom segments have an ID that begins with **cseg**.

Important:

This subtab is available only after the record type has been saved.

To show inactive fields in the list, check Show Inactives.

#### To add fields to your custom record: {#procedure_N2878359}

1.  To create a new field for this record type, click **New Field** on the **Fields** subtab.
    
    For step-by-step instructions for creating a new field, refer to [Creating a Custom Field](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2829580.html).
    
2.  Rearrange the fields as needed.
    
    Select a line and drag it to the required position, or click **Move To Top** or **Move To Bottom**. If you've placed the fields on subtabs, moving a field here will affect its position within that subtab only.
    
3.  To edit a field, click the name of the field in the **Description** column.
    
4.  Make changes as needed, and then click **Save**.
    
    Before saving, NetSuite validates any parent-child combinations to ensure that the values are unique. If the same parent-child combination already exists, an error message appears showing the existing entry, and you can't save the duplicate.
    

Note:

If you want this field to be available for data entry in the Quick Add portlet, check the **Allow Quick Add** box. By default, this option isn't enabled. For more information, see [Quick Add Portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N588631.html).
