Enabling GL Impact for a custom segment enables the values for the segment values to appear on the GL Impact page for related transactions, ensuring accurate financial tracking and reporting. You can set the GL Impact option when first creating a custom segment, but note that this setting can't be modified after the segment is saved. For more overview information, see [Configuring GL Impact for a Custom Segment Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4385199949.html).

#### To configure GL impact for a custom segment:

1.  Go to _Customization > Lists, Records, & Fields > Custom Segments_ > New.
    
2.  Check or clear the **GL Impact** box as needed.
    
3.  Click **Save**.
