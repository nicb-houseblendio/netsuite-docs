Note:

The content in this topic applies only if the AI Description field is available in the custom record definition page.

For custom records, you can provide detailed information about the record in the AI Description field. AI features can use this description to deliver relevant, meaningful answers to user questions about the record.

![Custom Record Type page highlighting the AI Description field](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/SuiteBuilderCustomization/AIDescriptionField_Classic.jpg)

To add an AI description, briefly explain what your custom record is for, how it's used, and any other relevant information an AI feature should know. .

For more details and guidelines about what information to provide, see [AI Description for Custom Object Definitions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0109014837.html).
