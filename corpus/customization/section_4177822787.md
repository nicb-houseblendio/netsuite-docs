For each of your custom transaction types, you can create links, or menu paths, in the NetSuite UI. People in your organization can use these menu paths to access the transaction type's list view and entry form. For more details, see the following:

-   [Planning for Custom Transaction Type Links](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4235016819.html)
    
-   [Creating Links for a Custom Transaction Type by Editing the Transaction Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4235017244.html)
    
-   [Creating Links for a Custom Transaction Type by Using the Customization Menu](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4235018237.html)
