If the Multi-Language feature is enabled in your account, you can translate the name of a custom list, and its available values, so that they match the language of the NetSuite user interface. For details, see the following:

-   [Translating a Custom List Name](#bridgehead_N2852587)
    
-   [Translating Custom List Values](#bridgehead_N2852626)
    

Important:

Before you can add these translations, you need to select translation languages at _Setup > Company > General Preferences_, on the Languages subtab. The Languages subtab lists both system-supported languages that can be used for the NetSuite user interface (and are available at _Home > Set Preferences_), and additional languages that can used for website translations only (and aren't available at _Home > Set Preferences_). You should enter translations only for system-supported languages, because these are the only languages that can be displayed in the user interface. For details, see [Configuring Multiple Languages](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N247147.html).

## Translating a Custom List Name {#bridgehead_N2852587}

You can define translations for a custom list name on the Translation subtab of the Custom List page.

![Custom List page with Transaction sublist options highlighted.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/SuiteBuilderCustomization/CustomListNameTranslate.png)

Note:

The maximum length for a custom list name's translation is 30 characters.

## Translating Custom List Values {#bridgehead_N2852626}

You can define translations for a custom list's values, on the Values subtab of the Custom List page:

![Custom List page with translation values shown on the Values subtab.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/SuiteBuilderCustomization/CustomListValueTranslate.png)

Note:

Custom list value translations have a 60-character limit.
