You can create custom centers for custom roles to tailor the experience. After creating a custom center, you can add tabs and links, define the order of tabs, and translate labels.

You need to enable Custom Records to customize centers.

See the following topics:

-   [Creating a Custom Center](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_161659739764.html)
    
-   [Entering Translation Labels for a Custom Center](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_161660013773.html)
    
-   [Changing the Order of Tabs in a Custom Center](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_161660005458.html)
    
-   [Managing Centers with SuiteCloud Development Framework (SDF)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_161660059367.html)
