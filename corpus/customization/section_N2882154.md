If the Multiple Languages feature is enabled in your account, you can translate the name of a custom record, its custom subtab titles, and its custom sublist labels. These translations can match the language of the NetSuite user interface. You can also translate the names of instances of a custom record. For more details, see the following:

-   [Multiple Languages Translation Management](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_163475565174.html)
    
-   [Translating a Custom Record Name](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N2882240.html)
    
-   [Translating Custom Record Subtab Titles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N2882272.html)
    
-   [Translating Custom Record Sublist Labels](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N2882316.html)
    
-   [Translating Custom Record Instance Names](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_3746164319.html)
    

Note:

If you use the multi-language feature, you should manage your translations using translation collections maintained in Manage Translations. It's more efficient to use a translation collection for managing translations for multiple languages than it is to define translations on the Translation subtab. For more information, see [Multiple Languages Translation Management](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_163475565174.html).

Before you can add translations, you must select translation languages in general company preferences on the Languages subtab. For more information, see [Setting General Account Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N243797.html). The Languages subtab lists:

-   System-supported languages that can be used for the NetSuite user interface (available at Home > Set Preferences)
    
-   Additional languages that can be used for website translations only (not available at Home > Set Preferences)
    

You should enter translations for system-supported languages only, because these are the only languages that can be displayed in the user interface. For custom records, NetSuite uses the user's language preference for translations. For standard records, NetSuite returns and updates translations in the company's primary language. For more information, see [Configuring Multiple Languages](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N247147.html).
