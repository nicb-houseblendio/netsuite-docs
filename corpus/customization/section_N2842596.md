You can create custom fields that display information but don't store that information with any record or transaction. You can create a read-only field of any type with any display, default, validation, or sourcing options.

A read-only field is especially useful when used with information sourcing. Sourced fields show information stored elsewhere in NetSuite. That information is retrieved from the source every time the page is loaded. Because any changes you make to the field aren't saved, making the field read-only prevents editing attempts.

#### To create a read-only custom field: {#procedure_N2842610}

1.  Edit an existing custom field or create a new one.
    
    If you want to create a new field, see [Custom Field Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2827140.html) to determine the type of field you want to create. You'll find step-by-step instructions for each custom field type.
    
2.  Clear the **Store Value** box.
    
3.  Click the **Display** subtab.
    
4.  Set the **Display Type** field to **Disabled**.
    
5.  Click **Save**.
    

For more information about using display types, see [Setting Display Options for Custom Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2830238.html).
