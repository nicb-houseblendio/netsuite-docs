This topic describes when user events are triggered for parent-child records. For details about how to create parent-child relationships, see [Creating a Parent-Child Relationship](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158229389859.html).

User events are triggered when a custom child record is associated with or separated from its parent record, unless the custom field referencing the parent record is of type Multiple Select. A beforeLoad, beforeSubmit, or afterSubmit event occurs if a record is associated or separated.

The user events support scripting and workflows based on association and separation of custom child records. The event is audited on the custom child record as an edit execution event type and is supported in SuiteScript 2.0. For more information about user events, see [SuiteScript 2.1 User Event Script Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4387799721.html).
