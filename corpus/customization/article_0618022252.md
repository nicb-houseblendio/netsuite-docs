This topic describes how to revert the effective AI description to the original default AI description in Advanced Record Customization (ARC). For overview information about ARC, see [Advanced Record Customization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_2144345458.html).

If you no longer need an override, revert to the default AI description. For example, you may revert when:

-   The original owner-defined description is now acceptable or preferred.
    
-   The override was temporary and is no longer needed.
    
-   You want all descriptions to use owner-defined terminology.
    

#### To revert an ARC AI Description override:

1.  Open the **Advanced Record Customization** (Customization > Advanced Record Customization).
    
2.  Find the record type with an active override you want to revert.
    
3.  In the **Effective AI description** area for the record type, open the edit action by clicking the edit (pencil) icon.
    
4.  In the **Edit effective AI description** popup window, review the descriptions for the (default) AI description and the (effective) AI Description Override.
    
5.  If you want to revert the effective AI description to the default AI description, clear the **Override this AI description** box.
    
6.  Click **Save**.
    

## Result {#subsect_0618023208}

When you revert an AI description override, the following changes occur:

-   If a default AI description exists, the effective AI description reverts to the default AI description.
    
-   If the record type has no default AI description, clearing the **Override this AI description** box removes the effective AI description. When you save the change, the system deletes the previous value from the AI Description Overview field.
    
-   The ARC badge is removed for the record type.
