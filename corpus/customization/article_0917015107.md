This example describes the steps for creating a hierarchical custom record for the train carriage scenario described in [Hierarchy of Parent-Child Instances of the Same Record Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_158230568711.html), which you should read before continuing. For this example, all record instances are created using a single custom record.

Watch the following help video for details about how to create the example described in this topic.

1.  [Creating the Custom Record Type for Steps in Creating Hierarchical Custom Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_0917015524.html)
    
2.  [Creating the Record Instances for Steps in Creating Hierarchical Custom Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_0917020033.html)
    
3.  [Creating the Custom Field for Steps in Creating Hierarchical Custom Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_0917021613.html)
