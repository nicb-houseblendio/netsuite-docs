**Can all Users access ARC?**

ARC is intended for administrator-level access.

**What is an effective AI description?**

The effective AI description is the description that AI features use for the record type. If no ARC override exists, the effective AI description matches the default AI description. If an ARC override exists, AI features use the override instead of the default description.

When an ARC override is active, changes made to the default AI description outside of ARC don't affect the effective AI description. This rule applies to changes from NetSuite or installed partner solutions.

**Why does the ARC list show the effective AI description instead of the default AI description?**

ARC displays the description currently applied in the account.

**What's the difference between AI Description and AI Description Override?**

-   AI Description is the baseline description defined by NetSuite, a custom account configuration, or an installed partner solution.
    
-   AI Description Override is the description used as the effective AI description after applying the description override.
    

**Can I revert to the default description after overriding it?**

Yes. In edit mode, clear **Override this AI description**, and then save.

**What happens if no default AI Description exists?**

-   If no default description exists and you save an AI description override in ARC, ARC uses that description as the effective AI description for the record type.
    
-   If you later clear the override for that record type, the effective AI description is removed.
    

**What happens if I change the default AI description on the record definition when an AI description override is active in ARC?**

Changes to the default AI description don't affect the effective AI description when an ARC AI description override is active. ARC continues to use the override as the effective AI description until you clear the override. If you later clear the override, ARC uses the current default AI description defined in the record definition.
