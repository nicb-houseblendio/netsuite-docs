This topic provides an example scenario and AI description for a custom transaction type. For general information about the AI Description field, see [AI Description for Custom Object Definitions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0109014837.html).

## Scenario {#subsect_0109022350}

Your retail company wants to track inventory transfers between different store locations, beyond standard purchase or sales transactions. You create a custom transaction type called Store Transfer to record when stock moves from one store to another, including store names, transfer dates, and item details.

## AI Description {#subsect_0109022432}

You could enter a description similar to the following into the AI Description field:

Tracks inventory transfers between store locations with details like transfer date, sending and receiving store, and items moved. Supports inventory management and stock level tracking across the business.
