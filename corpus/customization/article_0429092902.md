System Notes usually track changes to records, fields, and custom fields.

Text type fields let users enter letters and numbers. These field types are included:

-   Text Area
    
-   Long Text
    
-   Rich Text
    
-   Free-Form Text
    

System Notes record exact changes in values for Text Area and Free-Form Text type fields only. The recorded values are taken from the transaction where the field was used. This only applies if the Store Value setting is checked. If Store Value isn't checked, no changes are recorded. For Long Text and Rich Text fields, System Notes only record changes in the number of characters entered.

On the System Notes subtab of a transaction, the line related to the custom field shows the old and new values after editing the transaction. The following table provides examples of what this could look like:

On the System Notes subtab of a transaction, the line related to the custom field shows the old and new values after the user edits the transaction. The following table shows examples:

| Field Type | Old Value | New Value |
| --- | --- | --- |
| Text Area | This is a test note. | This is a new test note. |
| Free-Form Text | This is a test note. | This is a new test note. |
| Long Text | Old: 20 Chars | New: 24 Chars |
| Rich Text | Old: 519 Chars | New: 523 Chars |

Use Text Area and Free-Form Text fields to track changes to custom field values. System notes for these field types show the previous and new values entered in the field.

For more information, see [System Notes Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_158644279544.html).
