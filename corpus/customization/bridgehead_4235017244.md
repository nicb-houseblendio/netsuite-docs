If appropriate, you can create links for a custom transaction type by directly editing the custom transaction type.

Note:

In these cases, you can't directly edit the transaction type as described in this topic. But you can still add links for the type. For details, see [Creating Links for a Custom Transaction Type by Using the Customization Menu](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4235018237.html).

#### To create links for a custom transaction type: {#procedure_4228801410}

1.  Go to _Customiztion > Lists, Records, & Fields > Transaction Types_, and click the name of the appropriate transaction type.
    
2.  Click the **Links** subtab.
    
3.  Create a link by adding a line to the sublist, as follows:
    
    1.  Use the **Center** list to select a center.
        
    2.  Use the **Section** list to select the appropriate section, or tab. The available tabs vary depending on the center you selected. If you did not select a center, no tabs are listed.
        
    3.  Use the **Category** list to select the appropriate menu category.
        
    4.  (Optional) In the **Label** column, enter the label text you want to use. If you don't enter label text, the system uses the name of the transaction type.
        
    5.  (Optional) Enter translations for the link. Click in the **Translation** column to display a popup window. In this window, you can enter a translation for each language your account uses. (The available languages are set at _Setup > Company > Preferences > General Preferences_, on the Languages subtab.) When you're finished entering translations, click **Done**.
        
    6.  (Optional) Specify where the label will appear in relation to other labels in the category. Click in the **Insert Before** column to display a list, and select the appropriate label.
        
    7.  Click **Save**.
        
4.  Create additional links as needed.
    
5.  Click **Save**.
    

For full details on creating and editing custom transaction types, see [Creating a Custom Transaction Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4172789910.html) and [Editing a Custom Transaction Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4172785713.html).
