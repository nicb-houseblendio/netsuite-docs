After you create statuses, a common next step is to create a workflow. As described in [Custom Transaction Type Statuses Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4225285410.html), a workflow offers a useful way to set statuses for transactions instances.

For more details about working with workflows, see [Custom Transaction Types in Workflows](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4172859930.html).

You can also manipulate statuses using SuiteScript. For details on scripting with custom transaction types, see [Custom Transaction](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4174405432.html) in the SuiteScript Reference section.
