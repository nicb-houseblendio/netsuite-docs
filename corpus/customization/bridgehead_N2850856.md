You can source from Sales Rep or Supervisor fields.

## Source From Sales Rep or Supervisor {#bridgehead_N2850864}

When you select Sales Rep, information is sourced from the record selected in the **Sales Rep** field of **customer** records.

When you select Supervisor, information is sourced from the records selected in the **Supervisor** field of **employee** records.

Note:

To source correctly, select the Employee list in the List/Record field.

| **Field** | **Type** |
| --- | --- |
| Name | Free-Form Text |
| Bill To | Text Area |
| Phone | Phone Number |
| Email | Email Address |
| City | Free-Form Text |
| State | Free-Form Text |
| Zip | Free-Form Text |
| Country | Free-Form Text |
| Supervisor | List/Record |
| Soc. Sec. # | Free-Form Text |
