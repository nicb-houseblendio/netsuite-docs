Advanced Record Customization (ARC) provides a central location where administrators can review and refine standard and custom data model configurations. Administrators can also override existing settings.

ARC supports standard record types, custom record types, and custom transaction types. Each standard record type has a default AI description.

ARC applies a layer over values from NetSuite, account customizations, or installed partner solutions. ARC also preserves administrator overrides as effective account-level values.

With ARC, you can:

-   View and filter the list of supported record types. The list shows details such as the record type name, ID, family, source, and effective AI description.
    
-   Identify effective AI descriptions that have ARC overrides. The ARC badge appears in the Effective AI Description field for each override.
    
-   Click the edit (pencil) icon in the Effective AI Description field to open the edit window. In the window, you can:
    
    -   Compare the original and effective AI descriptions when both descriptions are available.
        
    -   Create or update an AI description override.
        
    -   Revert an override to the default AI description.
        
    -   Select **Optimize for AI** to enhance the description for use with AI features.
