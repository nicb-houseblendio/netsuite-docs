Custom segment values can be set or created using Custom GL Lines Plug-in, SuiteScript, SOAP web services, or CSV import.

The Custom GL Lines Plug-in can set and read custom segment values from custom and standard lines and from transaction records, if the custom segment has GL impact. The default values for column segments are sourced from the body. The Custom GL Lines Plug-in can change this value, even for segments that are applied only to the body. For details, see [Custom GL Lines Plug-In Interface Definition](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4072802996.html).

On record types that are exposed to SuiteScript, you can use SuiteScript to set values for custom segments that exist as fields. You can also use SuiteScript to create values for existing custom segments. For details see [SuiteScript 2.x API Reference](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_4140956840.html).

In many cases, you can use SOAP web services to set values for custom segments that exist as fields. You can set values on instances of record types that are exposed to SOAP web services and have a CustomFieldList defined as part of the exposure. You can also use SOAP web services to create values for existing custom segments. For details, see [CustomFieldLists for Setting Custom Segment Values](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4514127747.html).

You can create and update custom segment values using the CSV Import Assistant. For details, see [Custom Segment Value Import](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4358372117.html).

Also, see [Benefits of Custom Segments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4313464596.html).
