This topic provides an example of one parent record type to one child record type. For a general overview of the one parent record type to one child record type relationship, see [One Parent Record Type to One Child Record Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_158230205382.html).

An example of a one-to-one record type relationship is a customer parent record type with an address child record type. Typically, in a one record type to another record type scenario, the child record has multiple instances, but the parent record has only one instance. For example, a customer record instance can have three unique addresses. The addresses are the child record instances.
