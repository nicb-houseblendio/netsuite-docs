A custom list is a list of values you can use in custom fields on your forms and records. Custom lists enable you to set up predefined choices for your employees and customers to select when entering transactions and records.

Important:

Custom lists are intended for use with small, fixed, related sets of data. Each custom list should include no more than 1000 values. You can't import CSV files for custom lists with over 25,000 values.

To see a list page for custom lists, go to _Customization > Lists, Records, & Fields > Lists_.

To save time, you should create any custom lists or subtabs that may be needed when implementing the more advanced customizations for your account.

For help on defining a custom list, see [Creating a Custom List](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2852278.html), [Adding Translations for Custom Lists](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2852517.html), and [Managing Large Custom Lists](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4823380225.html).

For information about running saved searches on custom lists, see [Saved Searches for Custom Sublists](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4453543527.html).

## More Information about List Pages in NetSuite {#subsect_0127022745}

For more information about what you can do on the Lists page, see [Working with Lists](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N494311.html).

Additionally, you can click **List** to edit the list values. A list page appears where you can view, edit, add, or delete any values as required.

To edit the settings of an existing custom list, click the list name. For lists with fewer than 1000 values, edit the list as needed. For lists of more than 1000 values, click **Manage Values** on the **Values** subtab to edit the list values.
