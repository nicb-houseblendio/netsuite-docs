After completing the steps to create the record instances described in [Creating the Record Instances for Steps in Creating Hierarchical Custom Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_0917020033.html), you can create the custom field that will be used on forms. For this example, the following steps create a custom entity field.

#### To create the custom field:

1.  Go to Customization > Lists, Records, & Fields > Entity Fields > New.
    
2.  In the **Label** field, enter **Train Carriage**.
    
3.  In the **Type** field, select **List/Record**.
    
4.  In the **List/Record** field, select **Train Carriage**.
    
5.  On the **Applies To** subtab, select where the field should apply. For this example, check **Customer** and **Project**.
    
6.  Click the **Display** subtab.
    
7.  In the **Subtab** field, select where you want the field to appear. For this example, select **Main**.
    
8.  Click **Save**.
    

You can now add this field to your forms as needed. For more information, see [Configuring Fields or Screens](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2856992.html).
