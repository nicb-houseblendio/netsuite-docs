This topic explains how to manage effective AI descriptions in Advanced Record Customization (ARC). For an overview of ARC, see [Advanced Record Customization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_2144345458.html).

With ARC, you can create an override with account-specific wording or revert an override to the default AI description.

#### To manage an effective AI Description in ARC:

ARC stores an override as the effective AI description. AI features use the effective AI description to answer questions about the record type. An ARC badge in the Effective AI Description field indicates that an override is active.

1.  Go to _Customization > Advanced Record Customization_
    
2.  Find the record type you want to update.
    
3.  In the **Effective AI Description** area, open the edit action, by clicking the edit (pencil) icon.
    
4.  In the **Edit AI description** popup window, review the current AI description.
    
5.  If the record type has a description defined by NetSuite, a custom account configuration, or an installed partner solution that you want to override, check **Override this AI description**.
    
6.  In the **AI Description Override** field, enter the new description. Use clear, specific language that matches the record type business meaning in your account.
    
    Note:
    
    Change original wording only when your company uses the record type differently from the original meaning. For more information, see [AI Description for Custom Object Definitions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0109014837.html).
    
7.  (Optional) To optimize the description AI uses to deliver relevant, meaningful answers to user questions about the field, click **Optimize for AI**. Then, review the description for accuracy. You can make further edits if needed. For more information, see [Adding an AI Description for a Custom Object](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0109015544.html).
    
8.  Click **Save**.
