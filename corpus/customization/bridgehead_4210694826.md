Users entering instances of a Basic style transaction type can enter either a series of credits or a series of debits. Users specify the accounts to be credited (or debited) in each transaction's Lines sublist. The corresponding account to be adjusted for balancing purposes is defined on the transaction type's definition. This account is sometimes called the offset account.

With this approach, the custom transaction is similar to the expense report transaction, which always debits the same predefined account. However, one unique feature of the Basic style is that you can choose whether the offset account named on the transaction type is to be credited or debited. You make this choice using the transaction type's Credit box. If the Credit box is checked, the offset account is credited, and the accounts that the user identifies in the Lines sublist are debited. If the Credit box is cleared, the behavior is reversed.

After a transaction type has been created, you can't change the value of the Credit box.
