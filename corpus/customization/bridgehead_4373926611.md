This topic describes the primary limitations and restrictions when using the Multiple Select type for custom segments in NetSuite. For an overview of custom segment types and additional considerations, see [Custom Segment Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4368830364.html).

If you select a type of Multiple Select for a segment, be aware of the following limitations:

-   The segment can't have GL Impact.
    
-   You can't apply the segment to transaction columns.
    
-   The segments don't support dynamic defaulting. (Dynamic defaulting is configured by using the Source List field on the Application & Sourcing subtab of the segment definition, as described in [Creating a Custom Segment](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4313465979.html).)
    
-   Multiple selects on multiple custom segments aren't supported.
