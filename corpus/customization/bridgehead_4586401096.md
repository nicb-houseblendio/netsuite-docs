To be able to create values, a user must have the necessary privileges. There are several permission configurations that can result in users having this access.

The following table describes examples of users with different permissions and how each group can create values.

| Description | When Can the User Add Values? | Permitted Methods for Creating Values |
| --- | --- | --- |
| Users assigned to the Administrator role | At any time | [Creating Values Within the Segment Definition](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4380806824.html) [Creating Values by Clicking Manage Values](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4380806541.html) [Creating Values Using the New Button](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4380881353.html) |
| Users with the Create level of the Custom Segments permission | Only during the time that the user is creating the segment (unless the user has additional privileges). | [Creating Values Within the Segment Definition](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4380806824.html) |
| Users with the following:
-   The Create, Edit, or Full level of the Value Management Access permission

 | At any time | [Creating Values Within the Segment Definition](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4380806824.html) [Creating Values by Clicking Manage Values](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4380806541.html) |
| Users with both of the following:

-   The Create, Edit, or Full level of the Value Management Access permission
-   Permission to work with the segment when it's displayed on another record

 | At any time | [Creating Values by Clicking Manage Values](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4380806541.html) [Creating Values Using the New Button](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4380881353.html) |

Note:

Be aware that even if users have only the Edit or Full value of the Custom Segments permission, they can assign themselves the Value Management Access permission for any custom segment.
