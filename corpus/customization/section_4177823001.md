If your account uses the Multi-Language feature, you can add translations for your transaction type's name.

Note:

For help entering translations for link labels, see [Creating Links for a Custom Transaction Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4177822787.html).

#### To add translations for a custom transaction type: {#procedure_4230569416}

1.  Go to _Customization > Lists, Records, & Fields > Transaction Types_, and click the name of the appropriate transaction type.
    
2.  Click the **Translations** subtab.
    
    The system displays a list of the languages configured for your account. These languages are configured at _Setup > Company > Preferences > General Preferences_, on the Languages subtab.
    
3.  In the **Name** column, enter the appropriate translation for each language, as needed.
    
4.  Click **Save**.
    

For full details on editing and creating custom transaction types, see [Creating a Custom Transaction Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4172789910.html) and [Editing a Custom Transaction Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4172785713.html).
