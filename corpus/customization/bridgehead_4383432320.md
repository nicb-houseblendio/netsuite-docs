This topic describes how to make a custom segment value inactive using the Manage Values page, which is useful if you do not have permission to edit the segment definition. For a general overview and other options to inactivate segment values, see [Making Values of a Custom Segment Inactive](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4383432320.html).

In some cases, you may not have permission to edit segments, but you do have permission to edit values for a segment. In these cases, to make a value inactive, you must open a page designed specifically for managing the value. You get to this page by viewing the segment definition and clicking the button labeled Manage Values.

#### To make a value inactive by clicking Manage Values:

1.  Go to _Customization > Lists, Records, & Fields > Custom Segments_.
    
2.  In the list, select the name of the segment for which you want to edit values.
    
    The segment definition opens in view mode.
    
3.  Click **Manage Values**. A list of the existing segment values appears.
    
4.  Fine the value you want to change and click the corresponding **Edit** button.
    
5.  Check the **Inactive** box.
    
6.  Click **Save**.
