When you add values to a custom segment, those values are displayed in a list on a record.

![Sample custom segment list.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/SuiteBuilderCustomization/segmentOrdering.png)

You can configure the sequence of values in two ways. You can sort them alphabetically or use the list sequence from the segment definition. The default is to use the sequence from the segment definition.

To change the way values are ordered, you must have permission to edit the segment definition.

#### To reorder segment values:

1.  Edit the custom segment.
    
2.  On the Values subtab, find the **Display Order** label.
    
3.  Do one of the following:
    
    -   To make the values appear in the order shown on the segment's Values sublist, select **Sublist**.
        
    -   To make the values appear in alphabetical order, select **Alphabetical**.
        
    
    ![Sample Values subtab showing display order options.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/SuiteBuilderCustomization/segmentReordering.png)
4.  Click **Save**.
