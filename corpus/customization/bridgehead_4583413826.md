Users who have the Custom Address Form permission, but who don't have the SuiteScript permission, can no longer access the Custom Code subtab of custom forms. Previously, these users could edit the Custom Code subtab of an address form record to attach a script to the form.

Now users must have at least the Edit level of the SuiteScript permission to attach a script to a custom form by editing the Custom Code subtab of the form record. For users with the Edit or Full level of the SuiteScript permission, the Custom Code subtab is displayed and is fully editable. Users with the View or Create level of the SuiteScript permission can see but not edit the Custom Code subtab. For users who don't have SuiteScript permission, the Custom Code subtab isn't visible.
