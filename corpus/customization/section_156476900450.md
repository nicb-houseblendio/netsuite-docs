Note:

This topic applies to System Notes v2 only. For information about System Notes, see [System Notes Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_158644279544.html).

NetSuite logs system notes for changes to custom transaction type configuration. Use the System Notes v2 Workbook to view changes to the configuration of custom transaction types. For more information, see [System Notes v2 Workbook](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156623525551.html).

You can also access system notes for custom transactions types using the System Notes link on the Custom Transaction Types page.
