When a custom segment is displayed on a record, the segment's values are displayed as choices in a list. Depending on the configuration of the segment's Type field, the user can save one or more selections.

![Sample segment values list.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/SuiteBuilderCustomization/segmentValuesSimple.png)

For details about designing and working with a segment's list of values, see the following:

-   [Value Creation for Custom Segments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4313451357.html)
    
-   [Creating Hierarchies Among the Values of a Custom Segment](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4376484409.html)
    
-   [Edit the Values of a Custom Segment](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4381094119.html)
    
-   [Changing the Order of Values for a Custom Segment](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4313482444.html)
    
-   [Making Values of a Custom Segment Inactive](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4383432320.html)
