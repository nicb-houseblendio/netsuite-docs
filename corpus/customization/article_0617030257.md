This topic describes the AI description versions available in Advanced Record Customization (ARC). For an overview of ARC, see [Advanced Record Customization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_2144345458.html).

Administrators can use ARC to:

-   Review AI Descriptions across record types in one place.
    
-   Override a default AI description when an account requires different wording.
    
-   Revert an override to the default AI description from the record definition.
    

ARC uses a layered model that supports two AI description versions:

-   **AI description -** The default description for the record type. The description comes from NetSuite, an account customization, or an installed partner solution. This default description is used by AI features when no ARC override is applied.
    
-   **AI override description -** A description that a customer or administrator defines to replace the default AI description. AI features use this version when an override exists.
    

## Effective AI Description {#subsect_0617030648}

The effective AI description is the version that AI features use for a record type. If no ARC override exists, the effective AI description matches the default AI description. If an override exists, AI features use the override instead of the default description.

Important:

When an ARC override is active, updates to the default AI description from NetSuite or installed partner solutions don't affect the effective AI description.

For details about editing and reverting AI descriptions, see:

-   [Managing Effective AI Descriptions in Advanced Record Customization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0617031336.html)
    
-   [Reverting Advanced Record Customization AI Description Overrides](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0618022252.html)
    

## How AI Descriptions Appear in ARC {#subsect_0617031107}

On ARC list pages, the Effective AI Description column contains the effective AI description. An ARC badge appears when the description comes from an ARC override.

In the edit window, administrators can compare the descriptions before they save changes or revert the override.
