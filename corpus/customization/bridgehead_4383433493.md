This topic describes how to make a custom segment value inactive directly from the segment definition if you have the necessary permissions. For a general overview and other options to inactivate segment values, see [Making Values of a Custom Segment Inactive](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4383432320.html).

In some cases, you may have a set of permissions that includes the ability to edit the segment definition. In these cases, you can make a value inactive by directly editing the segment's Values sublist. This approach lets you view all values as you change the list.

#### To make a value inactive by editing the segment definition: {#procedure_4383433453}

1.  Edit the custom segment.
    
2.  Find the value you want to hide. Click in the **Inactive** column to display a check box.
    
3.  Check the **Inactive** box.
    
4.  Click **Save**.
