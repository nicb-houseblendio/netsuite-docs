The purpose of the GL Impact option is to add the segment to the GL Impact page for transactions where it's used. For this reason, you may receive a warning if you check the GL Impact box without applying the segment to a transaction. The GL Impact option has no function if the segment isn't applied to a transaction type. However, you're not required to apply these segments to transaction types.

You set the GL Impact when creating a custom segment. After that, GL Impact can't be changed.

For more information about GL Impact, see [Configure a Segment to Appear on the GL Impact Page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4471745392.html).
