If needed, you can set up a segment to let a user save multiple selections. This option differs from the Class, Department, and Location fields, where users can select only one option.

![Segments multi-select example.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/SuiteBuilderCustomization/SegmentsMultiSelectExample.png)

Some limitations exist for this capability. For example, if a segment is configured to display on the GL Impact page, it can't be a multi-select field. For more details, see [Custom Segment Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4368830364.html).

Also, see [Benefits of Custom Segments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4313464596.html).
