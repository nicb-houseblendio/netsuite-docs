**Issue:**

When setting up filtering, the Filter Using dropdown list is empty or missing your intended controlling field.

**What to Check:**

-   Did you create and save the controlling field (for example, Vehicle Make) as a field on the same record type as the dependent field?
    
-   Did you save the record type after adding the controlling field?
    
-   If using multiple custom forms or record subtypes, is the controlling field present and visible on the specific form/subtype?
    

**How to Fix:**

-   Ensure you create and save the controlling field on the correct record type before creating or editing the dependent field.
    
-   Always save the record type after adding a new field, then return to the dependent field and configure filtering.
    
-   For setups with multiple forms or subtypes, add the controlling field to every required form type.
    

For more troubleshooting tips, see [Troubleshooting Dependent Dropdown List Issues](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1016111656.html).
