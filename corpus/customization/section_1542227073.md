You can create a custom transaction to record unique business events in your general ledger. The custom transactions feature lets you to create custom transaction types that meet your specific needs and business logic. For instance, create a custom transaction to record adjustments for nonoperational income, like investment income or currency exchanges.

Custom transaction types share the same features as standard NetSuite transaction types, including purchases, payables, sales, billing, customers, and more. Custom transaction types share the same features as standard NetSuite transaction types, including purchases, payables, sales, and more. These features enable each transaction type to have unique behavior and processing. For example, restrict access to certain users, add custom transactions in bundles, and reference them in workflows.

For more information about custom transactions, see [Custom Transactions Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4172599049.html).

For more information about standard transaction types, see [Transaction Types Included in Monthly Transaction Lines Metric](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160311737279.html).
