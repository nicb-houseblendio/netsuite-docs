This topic provides sample autogenerated transaction numbers that demonstrate the different prefix combinations that can be used. For an overview and related examples, see [Autogenerated Transaction Number with Transaction Type and Location Prefixes Examples](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_14110249068.html).

The following examples show the results of autogenerated transaction numbers based on prefixes used.

## No Prefixes Used {#subsect_16110339438}

If no transaction or location (or subsidiary) prefix is used, the transaction number is based on the initial number in the transaction type record. No prefixes are added to the transaction number.

The following screenshot shows a transaction number that does not use prefixes.

![Sample purchase type transaction showing a transaction number that does not have any prefixes.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/SuiteBuilderCustomization/TransNumberNoPrefixExample.png)

## Location Prefix Used {#subsect_94110321603}

If a location prefix is used (either alone or with a transaction type prefix) the transaction number is based on the initial number on the location record.

The following screenshot shows a transaction number that uses a location prefix only.

![Sample purchase type transaction showing a transaction number that uses a location prefix.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/SuiteBuilderCustomization/LocPrefixOnlyExample.png)

The following screenshot shows a transaction number that both a transaction prefix and a location prefix.

![Sample purchase type transaction showing a transaction number that uses both transaction type prefix and a location prefix.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/SuiteBuilderCustomization/CustLocTransPrefix.png)

## Transaction Type Prefix Used {#subsect_64110219765}

If a transaction type prefix is used without a location (or subsidiary) prefix, the transaction number is based on the transaction number on the transaction type record.

![Sample purchase transaction type showing a transaction number that uses a transaction prefix.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/SuiteBuilderCustomization/TransPrefixOnlyExample.png)
