You can create custom icons to represent custom records in the NetSuite user interface.

#### To use a custom record icon: {#procedure_N2881475}

1.  Create an image file for your icon.
    
2.  Open the custom record you want to add the icon to.
    
3.  On the **Icon** subtab, select the **Use Custom Icon** option.
    
4.  Click the **New** button next to the **File** field.
    
    ![Sample Icon subtab showing New option.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/SuiteBuilderCustomization/iconcustomnew.png)
5.  In the File popup window, select an icon image.
    
6.  Click **Save**. Then save the custom record.
    
    Important:
    
    Make sure your custom icons meet the requirements outlined in the following sections. Take the time to thoroughly read and understand the requirements, and test your icon. You should read these requirements thoroughly and give yourself enough time to test your icon. You'll need basic image-editing skills and software like Adobe Photoshop to create and edit your icons, and save as transparent PNG files.
