The restrictions to custom record type access set up on the Permissions subtab don't apply to custom record data access by searches. If you want to prevent searches from returning custom record type data, you can:

-   restrict search access to specific custom record type fields on a field-by-field basis
    
-   restrict the audience for custom record type saved searches on a search-by search-basis
    

For more information, see the following topics:

-   [Limiting Search and Reporting Access to a Custom Field](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_161955053124.html)
    
-   [Limiting Access for a Custom Record Saved Search](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_161955058767.html)
