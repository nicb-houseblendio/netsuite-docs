This topic describes how you can create center links to web pages. For general information about creating center links, see [Creating Center Links](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2891250.html).

#### To create links to web pages: {#procedure_N2891435}

Note:

On the **Translation** subtab, enter translations for the custom center link. The Translation subtab is available only if the Multi-Languages feature is enabled in your account. For more information, see [Configuring Multiple Languages](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N247147.html).

1.  Go to the website or NetSuite page for which you want to create a link. Right-click the address bar and select **Copy**.
    
2.  Go to _Customization > Centers and Tabs > Center Links_ > New.
    
    ![Custom Center Links page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/SuiteBuilderCustomization/CustCenterLink.png)
3.  In the **Label** column, name your custom link.
    
4.  In the **URL** column, enter the URL for the link.
    
5.  In the **Script ID** field, enter a unique ID for the custom center link.
    
6.  Click **Add**.
    
    Note:
    
    The link will open in the existing window. You cannot set up a link to open in a new window.
    
7.  Click **Save**.
    
8.  To add the link to a custom category, go to _Customization > Center and Tabs > Center Categories_
    
9.  Click **Edit** next to the category where you want to add the link.
    
    ![Customer Center Category Values subtab](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/SuiteBuilderCustomization/CustCenterAddLink.png)
10.  From the **Link** list, select the custom link label.
     
11.  Click **Add**.
     
12.  Click **Save**.
