The note form displays as a popup window when a user adds a note to a record. You can vary note form fields by hiding standard fields, adding custom fields, and changing field order. You can configure note form actions by setting actions to display as buttons or menus, changing labels, hiding standard actions, and adding custom actions. You also can attach a form-level script to custom note forms.

For more information, see the following topics:

-   [Creating a Custom Note Form](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_163655385484.html)
    
-   [Creating a Custom Field for use in Custom Note Forms](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_163655437424.html)
    
-   [Using Custom Note Forms](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_3914783458.html)
    

Note:

The Note form includes a **Type** field for selecting the type of note (for example, email, phone call, meeting, and so on). To add a new note type, you must create it in CRM Lists. For more information, see [CRM Lists](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1044602.html).
