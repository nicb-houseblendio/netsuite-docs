After you create statuses for your custom transaction type, you may want to make changes. Your ability to make changes varies, as follows:

-   Before users have created transaction instances, you can change any field's value except ID. You can also delete statuses. Note that when you a delete a status, its ID value is never reused.
    
-   After an instance of a transaction type has been created, your options are limited to changing the name of the status and changing the translations of the name. You can't make other changes or delete statuses after transactions are created.
    

Note:

You can add new statuses at any time, as described in [Creating Statuses for Custom Transaction Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4222863092.html).

#### To modify or delete a status: {#procedure_4236006628}

1.  Go to _Customization > Lists, Records, & Fields > Transaction Types_, and click the name of the appropriate transaction type.
    
2.  Click the **Statuses** subtab.
    
3.  If you want to edit an existing status, do any of the following:
    
    -   To change the status name, edit the value in the **Description** column.
        
    -   To change whether the status is posting, click in the **Posting** column and check or clear the box. If you can't display the box, it's because an instance of the transaction type already exists, and you can't change the field.
        
    -   To change or add translations of the status name, click in the **Translation** column. The system displays a popup window that lists all the existing translations. Make changes as needed. When you're finished, click **Done**.
        
4.  If you want to delete a status, complete the following steps:
    
    1.  Click in the row that represents the status you want to delete. The system displays several buttons.
        
    2.  Click **Remove**. If you don't see a Remove button, it's because an instance of the transaction type already exists, and you can't delete the status.
        
5.  Click **Save**.
