The setup described in the following table provides a summary of the requirements to create the vehicle specification example in the preceding [Dependent Dropdown Lists Vehicle Specification Example](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0923085842.html) topic. The setup is specific to this example and doesn't describe all possible setup options.

| Step | What to Create | Where to Create | Type | Source and Examples | Required Step |
| --- | --- | --- | --- | --- | --- |
| 1 | Vehicle Make list | Customization > Lists, Records, & Fields > Lists > New | Custom List | Ford, Toyota, Honda | Name: Vehicle Make (List) Name: Vehicle Make (List) Values: Vehicle makes to include in the list (Ford, Honda, Toyota) Save. |
| 2 | Vehicle Model record type | Customization > Lists, Records & Fields > Record Types > New | Custom record type | Vehicle Model | Label: Vehicle Model (Record) Save and reopen. New field:
-   Label: Vehicle Make
-   Type: List/Record
-   List/Record: Vehicle Make (list)

 |
| 3 | Vehicle Model record instances | Customization > Lists, Records, & Fields > Record Types > Vehicle Model (Record) - New Record | Custom record type - record instances | Model Name: Mustang Vehicle Make: Ford | On the Record Types list, click New Record for Vehicle Model (Record). For each model, create a record, such as:

-   Name: Mustang
-   Vehicle Make: Ford

 |
| Model Name: F-150 Vehicle Make: Ford |
| Model Name: Corolla Vehicle Make: Toyota |
| Model Name: Camry Vehicle Make: Toyota |
| Model Name: Civic Vehicle Make: Honda |
| Model Name: Accord Vehicle Make: Honda |
| 4 | Vehicle Specification record type | Customization > Lists, Records, & Fields > Record Types > New | Custom record type | Vehicle Specification | Name: Vehicle Specification (Record) Save and reopen. New field 1:

-   Label: Vehicle Make
-   Type: List/Record
-   List/Record: Vehicle Make (List)

Save. New field 2:

-   Label: Vehicle Model
-   Type: List/Record
-   List/Record: Vehicle Model (Record)

Save. |
| 5 | Vehicle Specification record instances | Customization > Lists, Records, & Fields > Record Types > Vehicle Specification (Record) - New Record | Custom record type - record instances | 2025 Ford F-150 XL - 2.7 L EcoBoost V6 (325 hp / 400 lb-ft) - Agate Black Metallic | On the Record Types list, click New Record for Vehicle Specification (Record).For each valid combination, create a record instance, such as:

-   Name: 2025 Ford F-150 XL, 2.7L EcoBoost V6, Black
-   Vehicle Make: Ford
-   Vehicle Model: Mustang

Save. Repeat for all make and model combinations you want to include. |
| 2025 Ford F-150 XLT - 3.5 L PowerBoost Hybrid V6 (430 hp / 570 lb-ft) - Space White Metallic |
| 2025 Ford F-150 XLT - 3.5 L PowerBoost Hybrid V6 (430 hp / 570 lb-ft) - Space White Metallic |
| 2024 Toyota Corolla LE - 2.0 L engine - Ruby Flare (deep red) |
| 2024 Toyota Corolla XSE - 2.0 L engine - Blueprint (deep blue) |
| 2025 Honda Civic LX Sedan - 2.0 L 4-Cyl - Crystal Black Pearl |
| 2025 Honda Civic Sport Sedan - 2.0 L 4-Cyl - Rallye Red |
| 6 | Vehicle Make field | Customization > Lists, Records, & Fields > Transaction Body Field > New | Transaction body field | List/Record: Vehicle Make (custom list) | Label: Vehicle Model Applies To (subtab): Sale Display (subtab) > Subtab: Main Sourcing & Filtering (subtab):

-   Filter Using: Vehicle Make
-   Compare Type: equal
-   Compare To: Vehicle Make (on Vehicle Model record).

Save & New. |
| 7 | Vehicle Model field | Customization > Lists, Records, & Fields > Transaction Body Field > New | Transaction body field | List/Record: Vehicle Model (custom record type) | Label: Vehicle Model Applies To (subtab): Sale Sourcing & Filtering (subtab):

-   Filter Using: Vehicle Make
-   Compare Type: equal
-   Compare To: Vehicle Make (on Vehicle Model record).

Save & New. |
| 8 | Vehicle Specification field | Customization > Lists, Records, & Fields > Transaction Body Field > New | Transaction body field | List/Record Vehicle Specification (custom record) | Label: Vehicle Specification Applies To (subtab): Sale Display (subtab) > Subtab: Main Sourcing & Filtering subtab:

-   Filter 1
    -   Filter Using: Vehicle Make
    -   Compare Type: equal
    -   Compare To: Vehicle Make (on Vehicle Specification record)
-   Filter 2
    -   Filter Using: Vehicle Make
    -   Compare Type: equal
    -   Compare To: Vehicle Model (on Vehicle Specification record)

Save. |
| 9 | Custom sales form | Customization > Forms > Transaction Forms | Form | \- | Customize the Standard Sales Order form to create a new form called Vehicle Sales Order. For more information, see [Custom Forms](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N2852749.html). |
| 10 | Add fields to forms | Customization > Forms > Transaction Forms > Edit Vehicle Sales Order | Form | \- | Screen Fields (subtab) > Main (subtab) Show (column): Check for each field (Vehicle Make, Vehicle Model, Vehicle Specification) Arrange order: Vehicle Make, Vehicle Model, Vehicle Specification. Save. Note: When creating fields, if you don't select a subtab for the fields to display on, they default to the Custom subtab. You can use the Save & Move Elements button to move them to another area of the form, such as the Main section |
| 11 | Test filtering | Transactions > Sales > Enter Sales Orders > New | Sales order transaction | \- | Custom Form: Vehicle Sales Order Test fields by making selections. Vehicle Make: Select a vehicle make, such as Ford. The list should include all vehicle makes set up in the list. Vehicle Model: Select a vehicle model, such as Mustang. The list should include only Ford models when the Ford make is selected. Vehicle Specification: Select a vehicle specification. The list should include only the Ford Mustang specification options when the Mustang model is selected. |
