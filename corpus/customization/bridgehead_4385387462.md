This topic describes how to set filter conditions for each segment value by editing the Values sublist within the segment definition. For general information about value filtering, see [Setting Filters for Each of the Segment's Values](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4382569992.html).

If you have permission to edit the segment definition, you can set filters for each value by editing the Values sublist.

#### To edit values within the segment definition: {#procedure_4382647254}

1.  Edit the custom segment for which you want to add filtering.
    
2.  In the Values sublist, edit each value as follows:
    
    1.  For the value that you want to configure, click anywhere in that row to enable a series of buttons.
        
    2.  Click **Set Filters** to open a popup window. The popup window includes a **Filter** list. Its value is the field selected in the segment's **Filtered by** field. Directly below the list is a list of that field's values.
        
    3.  In the popup window, select the values of the **Filter** field that permit this value to be displayed as an option. For example, suppose you're editing the Book value of the Profit Center segment. If you want this value to be available only when the West Coast: California location is selected, select West Coast: California. To select more than one value, hold down the Ctrl key.
        
        ![Sample Set Custom Segment filtering setup.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/SuiteBuilderCustomization/segmentFilteringSetup.png)
    4.  If the segment's **Filtered by** field includes more than one selection, use the **Filter** list to select another classification and set its values.
        
    5.  When you've selected values for all fields in the **Filter** list, click **Set**.
        
        Important:
        
        You **must** set values for all of the fields available in the **Filter** list, or the value is never available to users.
        
    6.  Click **OK**.
        
3.  If there are other values that should be available, and don't have filters set, repeat the preceding editing steps for that value.
    
4.  Click **Save** on the segment definition.
