You can inactivate a custom segment by checking the **Inactive** box on the custom segment definition page. When you make a custom segment inactive, the segment no longer appears on any forms, reports, searches, or GL Impact pages, and isn't available for SuiteBundler, SuiteFlow, SOAP web services, SuiteAnalytics Connect, Mass Update, or the Custom GL Lines Plug-in. However, you can reactivate an inactive segment when needed.

If you inactivate a parent segment but keep its child segment active, the child segment is no longer filtered by the parent.

You can't inactivate a custom segment that's used as a search filter or in a workflow. If you try, you'll receive an error message indicating why the custom segment can't be inactivated.

You can't inactivate the custom field if it's used for criteria in duplicate detection. If you try, you'll get an error message. For more information about duplicate detection, see [Setting Up Duplicate Detection](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N258211.html).

Inactive segments and their values aren't visible on historical transactions, nor are they available when entering new transactions.

To view inactive segments, check **Show Inactives** on the Custom Segments list page. Inactive segments appear at the bottom of the list because they have no display order specified.
