This topic provides an example scenario and AI description for a custom field. For general information about the AI Description field, see [AI Description for Custom Object Definitions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0109014837.html).

## Scenario {#subsect_0109022606}

Your retail business wants to track whether each product in your inventory is eco-friendly, which is not a standard field in NetSuite. You decide to add a custom field called Eco-Friendly Product to your item records. This field is a checkbox that indicates if a product meets your company's sustainability criteria.

## AI Description {#subsect_0109022631}

You could enter a description similar to the following into the AI Description field:

Checkbox field that shows if a product meets eco-friendly or sustainable criteria, used to filter and report on sustainable inventory.
