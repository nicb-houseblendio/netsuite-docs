After the segment's **Filtered by** field has been configured, you must edit each of the segment's values. (In the example from the [Setting the Segment's Filtered by Field](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4382560236.html) topic, you edit the Profit Center segment's values.) If you don't edit a value, that value won't be available for users to select. You can edit values in two ways:

-   [Editing Values Within the Segment Definition](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4385387462.html)
    
-   [Editing Each Segment Value Directly](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4385387733.html)
    

Important:

Make sure you edit every value, if you want every value to be available under some circumstance. If you don't set the filtering conditions for a value, that value is never displayed in the segment's list.

Note:

Custom segments don't support filtering for revenue arrangements and revenue recognition journal entries. For more information, see [Filtering for a Custom Segment](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4376692773.html).
