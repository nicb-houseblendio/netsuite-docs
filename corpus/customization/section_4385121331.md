In some cases, you may want to edit an existing custom segment. For example, you may want to change the segment's label, the record types where the segment is applied, or the segment's default value. Most fields on a custom segment can be changed after creation, but there are some exceptions:

-   The **ID** field can't be changed.
    
-   The **GL Impact** option can't be changed.
    
-   Your ability to change the **Type** field depends on your permissions. For details, see [Required Permissions for Editing Custom Segments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4385121418.html).
    

For more information about editing custom segments, see [Inactivating a Custom Segment](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4520740541.html) and [Deleting a Custom Segment Definition](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4392098880.html).

When you create a custom segment, an associated custom record type is also created. The custom record type has the same name as the custom segment. You can edit the custom record at any time to add custom segment values. For more information about creating custom record types, see [Creating Custom Record Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2876492.html).

Custom segment definitions can be updated at any time, even if the segment is used in a transaction that's in a closed period.

Note also that changing the **Type** field from Multiple Select to List/Record can cause data loss. For more details, see [Custom Segment Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4368830364.html).

#### To edit a custom segment: {#section_4313466089}

1.  Go to _Customization > Lists, Records, & Fields > Custom Segments_.
    
2.  In the list, find the segment and click **Edit**.
    
3.  Make any necessary changes. If you need to add or update values, and the Values sublist is dimmed, click **Manage Values**. This opens a separate page for working with values. For details, see [Creating Values by Clicking Manage Values](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4380806541.html).
    
    If you need help understanding other fields on the segment definition, see the following topics:
    
    -   [Filtering for a Custom Segment](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4376692773.html)
        
    -   [Applying a Custom Segment to Record Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4384305776.html)
        
    -   [Dynamic Default Value Sourcing for Custom Segments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4384326119.html)
        
    -   [Validation and Static Default Values for Custom Segments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4384398039.html)
        
    -   [User Permissions for a Custom Segment](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4385127974.html)
        
    -   [Dependent Segments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4585727637.html)
        
    -   [Setting Display Order of All Custom Segments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4527888154.html)
        
4.  After making all necessary changes on the segment definition, click **Save**.
