Depending on the Allow GL Custom Segment Deletion setting in [General Accounting Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1385293.html), you may be able to delete custom segments. If you can't delete custom segments, you can inactivate them instead.

Warning:

If you delete a custom segment definition, both the custom segment definition and all custom segment values and instances on records are removed anywhere they're used. Consequently, custom segment values are removed from transactions, even in closed periods. You can't undo deleting a custom segment.

To delete a custom segment, you must have the necessary permissions. Authorized users include the following:

-   **Administrative users** - Users assigned to the Administrator role.
    
-   **Other users** - Users assigned to a role that has the Full level of the Custom Segments permission.
    

You can't delete a custom segment with dependent segments. For example, if another segment references this segment in the Filtered by field, the first segment can't be deleted.

You can't delete the custom segment if it's used for criteria in duplicate detection. If you try, you'll receive an error message. For more information about duplicate detection, see [Setting Up Duplicate Detection](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N258211.html).

#### To delete a custom segment definition: {#procedure_4392099365}

1.  Go to _Customization > Lists, Records, & Fields > Custom Segments_.
    
2.  Find the segment you want to delete and click **Edit**.
    
3.  In the **Action** menu, click **Delete**.
    
    The system displays a warning asking if you're sure you want to delete the custom segment.
    
4.  Click **OK**.
