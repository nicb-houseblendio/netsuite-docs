This topic explains how to display or hide the Status field on a standard entry form of a custom transaction type. For an overview of displaying or hiding the Status field, see [Displaying or Hiding the Status Field for a Custom Transaction Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4222860341.html).

To show the Status field, you need to configure it for the transaction type. This configuration makes the field viewable on the standard entry form for the type.

#### To configure the transaction type to include the Status field in the UI:

1.  Go to _Customization > Lists, Records, & Fields > Transaction Types_, and click the name of the appropriate transaction type.
    
2.  Click the **Statuses** subtab.
    
3.  If you want the **Status** field to be displayed on the transaction, check the **Show Status Field** box. If you want to hide the **Status** field, clear the box.
    
4.  Click **Save**.
