Custom Segments offers various permissions options. One option is that you can choose to make a segment visible only to users with specific roles. For example, you can create a segment called Rating that's applied to the Employee record type. This segment may contain sensitive information that should be available only to supervisors. In this case, you can configure the segment to be available to users in a Supervisor role but hidden for all other users. Additionally, you can make the segment read-only for certain roles.

You also have several options for controlling how users manage custom segments. For example, many roles in your account likely won't have permission to create or edit segments. However, if needed, you can give these roles permission to create and edit values for a specific segment. Note also that you can create and update values using the CSV Import Assistant. For details, see [Custom Segment Value Import](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4358372117.html).

For more details about managing permissions for segments, see [Permissions for Managing Custom Segments and Values](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4365567665.html).

Also, see [Benefits of Custom Segments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4313464596.html).
