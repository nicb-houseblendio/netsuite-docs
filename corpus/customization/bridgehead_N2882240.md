This topic describes how to translate a custom record name. For an overview of translation options, see [Adding Translations for Custom Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2882154.html).

You can define translations for a custom record type name (at _Customization > Lists, Records & Fields > Record Types_) on the Translation subtab of the custom record page:

![Sample Custom Record Type highlighting Translation subtab.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/SuiteBuilderCustomization/CustRecTransName.png)

The **Name** field has a 300-character limit.

Note:

Translated names that are available on a menu are truncated to 128 characters.
