This topic describes Step 2 of the example for creating dynamic default values in custom segments. For a complete list of steps for this example, see [Dynamic Default Values in Custom Segments Example](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161946314530.html).

Create the custom segment whose value dynamically displays in the field based on the value entered in the custom segment field created in the preceding procedure. In this example, the custom segment is for the name of the state, and it'll automatically appear based on the city name entered.

#### To create the segment:

1.  Go to _Customization > Lists, Records, & Fields > Custom Segments_ > New.
    
2.  In the **Label** field, enter the name of the segment, for example, **State**.
    
3.  Complete the fields, as required.
    
4.  Select the **Application & Sourcing** subtab. Then select the **Transactions** subtab
    
5.  In the Application field group, check the box beside the transactions you want to apply this segment to. For this example, check the **Sales Transactions** box.
    
6.  In the **Source List** field, select the label of the first custom segment created. For this example, select **City**.
    
7.  A message appears informing you that setting the source list (custom segment) requires the system to apply the segment to the record type. To proceed, click **OK**.
    
8.  Click **Save**.
