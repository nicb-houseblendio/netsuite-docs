If needed, you can reference custom segments when working with workflows. You can do either of the following:

-   Refer to custom segments when they appear as fields on other record types. For example, you can configure a segment field to default to a particular value. For more details, see [Custom Segments as Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4410260924.html).
    
-   Use workflows to manage the records that represent custom segment values. For more details, see [Records that Represent Custom Segment Values](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4410257732.html).
