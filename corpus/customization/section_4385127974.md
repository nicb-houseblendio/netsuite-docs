Every segment that has been applied to a record becomes a field on that record. Therefore, you can use the Permissions subtab to manage permissions for each segment in its capacity as a field on another record. At a high level, you can give a role permission to:

-   **View and use a segment when it appears on a record** - For each segment, you can explicitly permit or deny a role from being able to set a value for the segment. You can also make the segment hidden or read-only for a particular role. You manage these types of privileges by using the segment's Record Access permission. For more details, see [Granting Roles Permission to Set Segment Values on Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4317002357.html).
    
-   **View and refer to the segment when using searches and reports** - For each segment, you can explicitly permit or deny a role from being able to use the segment as a search field or column. You can also permit or deny a role from being able to use segments when customizing reports. You manage these types of privileges by using the segment's Search/Reporting Access permission. For more details, see [Granting Roles Permission to Use Segments in Searches and Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4317000329.html).
