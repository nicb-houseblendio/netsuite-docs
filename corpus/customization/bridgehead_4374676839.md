Refer to the following table for details about the privileges associated with the Value Management Access permission.

| Value Management Access Level | Users can: | Users can't: |
| --- | --- | --- |
| View | 
-   View values for the segment. (In addition, by having the View level of the Custom Segments permission, the user can view values for all segments.)

 | 

-   Create, edit, or delete the segment's values.

 |
| Create | 

-   Create values for the segment for which they have the Value Management Access permission.

 | 

-   Edit or delete the segment's values.

 |
| Edit | 

-   Create and edit the values for the segment.

 | 

-   Delete the segment's values.

 |
| Full | 

-   Create, edit, and delete the values for the segment.

 | \- |
