If field sourcing doesn't work as intended, review the following common issues. Verifying your field configuration, source data, and related customizations can help you identify and resolve the most common causes of sourcing problems.

| Sourcing Issue | Troubleshooting Recommendation |
| --- | --- |
| Sourcing not configured correctly | Verify that the custom field is configured for sourcing on the Sourcing & Filtering subtab and that the appropriate source record and source field are selected. |
| Incorrect Source List or Source From field selection | Verify that you selected the correct source record type and source field in the Source List and Source From fields. |
| Field type mismatch | Verify that the source and destination fields use compatible field types (for example, both are Percentage fields). |
| Missing data in the source field | Verify that the source record contains a value in the field being sourced. |
| Incorrect source record selected | Verify that the transaction or record is associated with the correct source record (for example, the correct Item Class custom segment value). |
| Store Value setting selected | If Store Value is selected, the sourced value may not update when the source value changes. Clear Store Value if you want the field to continue reflecting changes to the source. |
| SuiteScript, workflows, or other customizations override sourced values | Check whether SuiteScript, workflows, or other customizations update the field after sourcing occurs. |
| Insufficient record or field access | Verify that users have permission to access the source and destination records and fields. |
