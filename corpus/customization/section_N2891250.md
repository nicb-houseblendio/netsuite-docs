Administrators and users with the Creating Center Links permission can create center links.

You can create links for your custom categories as well as for standard NetSuite categories. Center links can go to other pages within NetSuite (including public saved searches for which a role has access), custom records, Suitelets, or external websites. You need to enable the Custom Records feature to customize center links.

You can create links to NetSuite pages and web pages. For more information, see [Creating Center Links to NetSuite Pages](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_161650692409.html) and [Creating Center Links to Web Pages](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_161650705377.html).
