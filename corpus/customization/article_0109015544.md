This topic describes how to add an AI description for a custom object, such as a record type, transaction type, or field. For general information about the AI Description field, see [AI Description for Custom Object Definitions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0109014837.html).

#### To add an AI description:

1.  In the **AI Description** field, briefly explain the purpose of the custom object, what it's used for, and how it fits into your business process. Include any important context that helps AI features understand its meaning.. For detailed guidelines, see [Guidelines for Writing an AI Description](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0109020149.html).
    
2.  After entering a description, click **Optimize for AI**. The system reviews your entry, improves readability, and enhances it for AI features. This ensures the content is clear, complete, and effective for AI-powered search and responses.
    
3.  Review the optimized description. You can make further edits if needed.
    

For more details about the type of information to include in the AI Description field, see [NetSuite Features That Use AI](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_5101751849.html).
