This topic explains the different access levels available for the Search/Reporting Access permission on custom segments. It details what each level enables and restricts for user.

For general information, see [Granting Roles Permission to Use Segments in Searches and Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4317000329.html).

The following table describes the access associated with the various levels of the Search/Reporting Access permission.

| Level | Users can: | Users can't: |
| --- | --- | --- |
| None | \- | 
-   Use the segment as a search filter.
-   Use the segment as a column in search results.
-   View columns that reference custom segments in saved searches. The user can view the saved search, but columns referencing custom segments are omitted from the view.
-   View reports that use the segment as a filter or include it as a column.
-   Customize reports to use custom segments as filters or columns.

 |
| View | 

-   View saved searches that include custom segments in their results.
-   View reports that use the segment as a filter or include it as a column.

 | 

-   Use the segment as a search filter
-   Use the segment as a column in search results.
-   Customize reports to use custom segments as filters or columns.

 |
| Edit | 

-   View saved searches that include custom segments in their results.
-   View reports that use the segment as a filter or include it as a column.
-   Use the segment as a search filter.
-   Use the segment as a column in search results.
-   Customize reports to use custom segments as filters or columns.

 | \- |

For information about assigning the Search/Reporting Access permission, see [Assigning the Search/Reporting Access Permission to Roles for Custom Segments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4374809622.html).
