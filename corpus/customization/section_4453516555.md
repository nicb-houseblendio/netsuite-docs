NetSuite provides a variety of options for customizing how transaction forms are printed. Preferences can be set at the company and user level, and there are separate settings for browser and layout behavior. For detailed information about each area, see the following topics:

-   [Transaction Forms and Company Printing Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4453520361.html)
    
-   [Setting Transaction Forms to Print in Landscape](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4453535297.html)
    
-   [Transaction Forms and User Printing Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4453528352.html)
    
-   [Browser Print Settings for Transaction Forms](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1515667719.html)
