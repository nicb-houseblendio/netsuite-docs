If a custom segment's Type field is set to Multiple Select, that segment can't be applied to a transaction sublist.

For more information about custom segment types, see [Custom Segment Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4368830364.html).
