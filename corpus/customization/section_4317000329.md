For every segment, you can control which roles can view and interact with the segment when working with searches and reports. You control this access by defining the Search/Reporting Access level for each role. You can also set a default access level, which applies to all roles that don't have an access level explicitly defined.

For details, see the following topics:

-   [Scope of the Search/Reporting Access Permission on Custom Segments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4374808861.html)
