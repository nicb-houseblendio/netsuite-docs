Unlike other sublists, there are no standard IDs that can be documented for custom child record sublists. The internal ID for the sublist itself, and all of its associated fields, is unique to each custom child record sublist.

See these topics for guidelines about determining which IDs to reference in [N/record Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4267255811.html) or [N/currentRecord Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4625600928.html):

-   [Determining the Sublist ID for a Child Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N3211618.html)
    
-   [Determining Field IDs on a Child Record Sublist](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N3211830.html)
