In some cases, you may be working with a custom transaction type that has been locked to editing. For example, transaction types that were imported by a bundle are sometimes locked. If a transaction type is locked, you can't directly edit its definition. But you can still refine some of the transaction type's behavior using other NetSuite UI options. For more details, see the following:

-   [Account Field Setup for Custom Transaction Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4187566241.html)
