You can source from Company, Contact, Item, or Assigned field.s

## Source From Company or Contact {#bridgehead_N2849659}

When you select Company, information is sourced from the record selected in the **Company** field of **case** records.

When you select Contact, information is sourced from the record selected in the **Contact** field of **case** records.

Note:

To source correctly, select the Employee list in the List/Record field.

| **Field** | **Type** |
| --- | --- |
| Name | Free-Form Text |
| Bill To | Text Area |
| Ship To | Text Area |
| Phone | Phone Number |
| Fax | Phone Number |
| Email | Email Address |
| City | Free-Form Text |
| State | Free-Form Text |
| Country | Free-Form Text |
| Sales Rep | List/Record |
| Expected Close Date | Date |
| Renewal Date | Date |
| Contact | Free-Form Text |
| Alt. Contact | Free-Form Text |
| Alt. Phone | Phone Number |
| Balance | Currency |
| Credit Limit | Currency |
| Account | Free-Form Text |

## Source From Item {#bridgehead_N2850233}

When you select Item, information is sourced from the record selected in the **Item** field of **case** records.

Note:

To source correctly, select the Vendor list in the List/Record field.

| **Field** | **Type** |
| --- | --- |
| Name | Free-Form Text |
| Display Name | Free-Form Text |
| Vendor Name | Free-Form Text |
| Online Name | Free-Form Text |
| Available Online | Check Box |
| Base Price | Currency |
| Cost | Currency |
| Preferred Vendor | List/Record |
| On Hand | Decimal Number |

## Source From Assigned {#bridgehead_N2850556}

When you select Assigned, information is sourced from the record selected in the **Assigned To** field of **case** records.

Note:

To source correctly, select the Employee list in the List/Record field.

| **Field** | **Type** |
| --- | --- |
| Name | Free-Form Text |
| Bill To | Text Area |
| Phone | Phone Number |
| Email | Email Address |
| City | Free-Form Text |
| Country | Free-Form Text |
| Supervisor | List/Record |
| Soc. Sec. # | Free-Form Text |
