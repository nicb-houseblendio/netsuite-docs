On the Record Types list page, the custom segment name in the Segment column means that the custom record type is associated with a custom segment.

![Sample Record Types list page.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/SuiteBuilderCustomization/CustomRecordTypeList.png)

The custom record has the same name as the custom segment.

![Sample Custom Record Type page in edit mode.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/SuiteBuilderCustomization/CustomRecordEdit.png)

When editing a custom record that's associated with a custom segment, keep the following in mind:

-   Some of the fields on the Custom Record Types page are read-only to avoid conflict with the custom segment settings.
    
-   Some of the subtabs on the Custom Record Types page aren't available because the record is associated with the custom segment.
    
-   You can't edit the permissions of the custom record. The custom record permissions are set on the custom segment definition page.
    
-   You can't inactivate the custom record type because it's associated with a custom segment.
    

When you add a new field to the record, it appears as a column on the Values subtab of the custom segment definition page.

![Sample custom record Display subtab.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/SuiteBuilderCustomization/CustSegRecordAddField.png) ![Sample Custom Segment defiintion page showing a new column on the Values subtab.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/SuiteBuilderCustomization/CustSegRecordWithFieldColumn.png)
