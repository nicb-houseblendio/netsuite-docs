The following record types support Class, Department, Location, and Subsidiary filtering:

-   Transaction types
    
-   Transaction line types
    
-   Entities
    
-   Items
    
-   Some other record types, specifically:
    
    -   Allocation Schedule Destination Line
        
    -   Allocation Schedule Source Line
        
    -   Budget Import
        

For general information about filtering segments by Class, Department, Location, or Subsidiary, see [Filtering Segments by Class, Department, Location, or Subsidiary](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_43104707091.html).
