In some cases, you may need to hide one or more of a custom segment's values. To hide a value, make it inactive. You can reactivate it later, if needed.

Inactivating a segment's values has these effects:

-   The value no longer appears as a choice in the segments list on new forms or on existing forms where it wasn't already selected. However, if the value is a parent to another value, it still appears as a parent.
    
-   If an inactive value was previously selected on an existing form, the value continues to appear on that form. A search on that value will also turn up in search results.
    
-   When filtering, if one segment is dependent on another segment, values filtered by an inactive value won't be available. This is true even if the inactive value on which other values depend is already selected.
    

You can make the values of a segment inactive in two ways:

-   [Making a Value Inactive by Editing the Segment Definition](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4383433493.html)
    
-   [Making a Value Inactive by Clicking Manage Values](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4383432320.html)
    

If needed, you can also delete a segment's values. For details, see [Deleting the Values of a Custom Segment](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4316016599.html).
