Here are the types of custom record and transaction fields you can create:

| Type | Description | Instructions for Creating Field Type |
| --- | --- | --- |
| Custom CRM Fields | Used to add fields to CRM records. These records include Activity, Marketing and Support records - such as tasks, events, campaigns, or cases. | [Creating Custom CRM Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2827328.html) |
| Custom Entity Fields | Used to add fields to entity records. These records include Relationship and Employee records - such as customers, vendors, employees, contacts, partners, or groups. | [Creating Custom Entity Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2827562.html). |
| Custom Item Fields | Used to add fields to item records. These records include Accounting and website item records - such as inventory, noninventory, service, other charge, group, kit/package, and assembly/bill of materials item records. | [Creating Custom Item Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2827818.html) |
| Custom Transaction Body Fields | Used to add fields to the body of transaction records. These records include, for example, purchase, sale, journal entry and expense report records - such as sales orders, invoices, purchase orders, opportunities, Web store transactions, or item receipts. | [Creating Custom Transaction Body Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2828059.html). |
| Custom Transaction Line Fields | Used to add fields to the lines of transaction records. These fields display in the line-item columns of transaction records and include fields such as expense items, purchase items, sales items, store items, or opportunity items. | [Creating Custom Transaction Line Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2828307.html) |
| Custom Transaction Item Fields | Used to add fields to the line items of your transaction records such as purchase items, sales items, and Web store items. When adding a custom field to the line items of a transaction, apply it to the specific line item type. | [Creating Custom Transaction Item Options](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2828730.html) |
| Custom Item Number Fields | Used to add fields to serial and lot numbered inventory records to track information specific to each item or workflow unique to your business. For example, track quality control procedures or recall information. | [Creating Custom Item Number Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2829121.html) |
| Other Custom Fields | Used to add fields to custom records not defined by the preceding categories, including campaign events, classes, competitors, departments, and locations. | [Creating Other Record Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2829304.html) |
| Other Sublist Fields | Used to add fields to the columns of a custom sublist. These fields appear in sublist line-item columns. | [Creating Other Sublist Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1515582937.html) |

You can tell custom and standard fields apart on NetSuite pages. To do this, enable the Show Internal IDs preference at _Home > Set Preferences_ under the Defaults section of the General subtab. With this preference enabled, clicking a field shows its ID in the bottom right corner of the field-level help popup. If it's a custom field, the ID from the custom field record is shown.
