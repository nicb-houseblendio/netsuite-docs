You can filter segments using standard fields that are available on a record, including the Class, Department, Location, and Subsidiary fields. However, you can't always filter a segment using these fields. Custom records don't have these standard fields. Therefore, if you apply a custom segment to any custom record type or custom segment, you can't filter the custom segment values using these fields. For more information, see [Applying a Custom Segment to Record Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4384305776.html).

However, custom segments can be applied to custom records and standard records, such as transactions and items, when filtering by classifications (class, department, location, and subsidiary) is selected. For more information, see [Viewing a Custom Segment's Filtering Relationships](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4385390178.html)

For more information about filtering custom segments, see [Filtering for a Custom Segment](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4376692773.html) and [Setting the Segment's Filtered by Field](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4382560236.html).

For information about record types that do and don't support filtering by Class, Department, Location, and Subsidiary, see the following topics:

-   [Record Types that Support Filtering by Class, Department, Location, and Subsidiary](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_40105008662.html)
    
-   [Record Types that Do Not Support Filtering by Class, Department, Location, and Subsidiary](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_29105256537.html)
