In some cases, you may need to delete one or more of a custom segment's values. You can delete the values of a segment in two ways:

-   [Deleting Values Within the Custom Segment Definition](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4383420757.html)
    
-   [Deleting Values by Clicking Manage Values](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4383423975.html)
    

You can't delete a value if that value has been saved on an instance of a record. If you try to delete this type of value, the system displays the following error: `The segment value cannot be deleted because a child record exists`.

Instead of deleting a value, consider it inactive.

If a period is closed, you can't change custom segment values that impact GL on any transactions in the period.
