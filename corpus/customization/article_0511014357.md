This topic describes the behavior of the Currency Symbol Field on new and existing custom fields. For more information about how to set this field, see Setting the Currency Symbol Field. For overview information about setting currency context, see [Setting Currency Context for a Currency Custom Field](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0511114806.html).

## Creating a New Custom Field {#subsect_0521122822}

**When creating a new custom field:**

-   You can optionally select a value in the Currency Symbol Field.
    
-   No warning message appears when setting the value during creation.
    
-   If left blank, the field behaves as a numeric field. A message appears warning that totals may be calculated incorrectly if multiple currencies are used.
    

## Setting a Value for the First Time on an Existing Custom Field {#subsect_0521122920}

**When setting a value for the first time on an existing custom field:**

-   A message appears indicating that the change affects how values are displayed and processed.
    
-   The currency from the selected Currency Symbol Field applies to both existing (historical) and future values.
    

## Changing the Currency Symbol Field on an Existing Custom Field {#subsect_0521123024}

**When changing the Currency Symbol Field on an existing custom field:**

-   A message appears warning that changing the field will remove the field as the currency source for any dependent currency fields.
    
-   Changing the currency source affects how historical and future values are displayed and processed.
    

## Clearing the Currency Symbol Field {#subsect_0521123131}

You can remove the selected value to clear the currency context. After you save the custom field:

-   The field no longer has a currency context.
    
-   Values are treated as numeric only.
    
-   Currency-specific display and aggregation behavior is removed.
