**Issue:**

Dropdown lists with multiple controlling and dependent fields don't filter as expected across the chain.

**What to Check:**

-   Does each field in the dependency chain correctly reference the previous controlling or dependent field?
    
-   Is each filtering step set up and tested individually?
    

**How to Fix:**

-   Validate and test each dependency layer independently, before testing the combined setup.
    
-   Confirm each custom record type and field setup supports the necessary dependencies.
    

For more troubleshooting tips, see [Troubleshooting Dependent Dropdown List Issues](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1016111656.html).
