This topic describes Step 2 of [Equipment Service Example using Custom Record Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_162092311855.html).

To create the parent-child relationship, you add a custom field to the Equipment Service record in which you can select the associated Equipment record. You select a field type of List/Record and select Equipment in the List/Record field. To create the parent-child relationship, check the Record is Parent box.

![Sample Equipment Service Field record with Record is Parent box checked.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/SuiteBuilderCustomization/Overview_parentChildAssocation.png)

Continue to Step 3: [Creating a New Service Record Instance for the Equipment Service Example](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_162092352234.html).
