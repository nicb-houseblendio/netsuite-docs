When your organization sell kits or assemblies, it's important that custom field and segment values associated with each item are accurately carried over from the sales order to the fulfillment record. The Apply to Kit or Assembly Components settings for custom segments and transaction line custom fields automate this process. This reduces manual data entry and helps maintain data integrity through order fulfillment and inventory management. Use these features to streamline workflows, support compliance, and ensure accurate tracking of custom data across transactional records.

You can configure kit or assembly custom segments or transaction line custom fields to copy values from sales order items to fulfillment items. For more information, see the following topics:

-   [Configuring Custom Segments for Kit and Assembly Component Value Carryover](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_161540707958.html)
    
-   [Configuring Transaction Line Custom Fields for Kit Assembly Value Transfer](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_161540711702.html)
    
-   [Kit and Assembly Components Behavior](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_161540730328.html)
    
-   [Example of Overriding the Value of a Segment or Field on a Line with an Assembly Component](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_161540738994.html)
