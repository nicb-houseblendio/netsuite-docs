The procedures in this section provide high-level steps for creating dependent dropdown lists. To understand the process, you should be familiar with creating custom lists, custom record types, and custom transaction types.

For a detailed example, see [Dependent Dropdown Lists Example](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162153822814.html).

To create a field that's filtered by multiple other List/Record fields, follow these steps:

1.  [Creating the Custom Lists and Custom Record Type for Dependent Dropdown Lists](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_162153739862.html)
    
2.  [Creating Custom Fields and Setting up Filtering for Dependent Dropdown Lists](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_162153750701.html)
    

There may be situations where creating a hierarchical custom record is a better approach than creating a dependent dropdown list. For a comparison of the two approaches, see the following video.
