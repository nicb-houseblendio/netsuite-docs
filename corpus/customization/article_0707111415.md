You can apply custom segments to custom record types, custom segments, and standard records, even when filtering by classification is selected.

Note the following:

-   When filtering by classification is selected in the main section Filter by field on the custom segment configuration page, the filtering options apply only for segments on standard records.
    
-   Simultaneously, the segment can be applied on custom records and other custom segments, but classification filter by options are ignored. Only other custom segment filter by options are used.
    

When applying a custom segment to a custom record type, you can select the custom record type on the Application & Sourcing subtab. This lets you apply the custom segment to both custom record types and standard record types, such as transactions and items, all within the same subtab. If you select a custom record type and a standard record type, and you want to filter by standard classification, the classification filtering options will be applied only to the standard records.

A read-only Filter by column on the Custom Segment configuration page displays the custom segment filter that's applied to the custom record instance. The Filter by column displays only non-standard segment classification options. If the custom segment isn't applied to the custom record type, or if there's no filtering, the field is blank. Inactive custom segments are displayed followed by (inactive) in brackets. This column is visible only in view mode and links to specific segments.

This Filter by display happens automatically, so you don't have to configure anything. The filtering settings are determined by the Filtered by field in the Main section of the Custom Segments configuration page.

## Filtering Behavior {#subsect_0707112503}

Here's an outline of the filtering behavior for custom segments applied to custom records.

| Selected Filter by Options (C/D/L/S) | Selected Filter by Options to Custom Segments | Behavior on Custom Record Instances |
| --- | --- | --- |
| No | No | All segment values are available. (No filtering applied.) |
| No | Yes | Filtering works. The segment displays only values permitted by the custom segment. |
| Yes | No | All segment values are available. (No filtering applied.) |
| Yes | Yes | Filtering works, but only by another custom segment. Filtering by class, department, location, and subsidiary are ignored. |

For a detailed example and more information, see [Filtering Custom Segment Values on Custom Records Example](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0707113855.html).
