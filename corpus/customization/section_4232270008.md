Every custom transaction field you create is available to be added to all transaction types, both custom and standard types. This procedure explains how to add one of these fields to your custom transaction type.

Note that adding a custom field adds it to **all** forms for the transaction type, including standard and custom forms. However, you can customize the field on your custom forms if needed. For example, you can change the field's label, make it read-only, or hide it. For help working with custom forms, see [Configuring Custom Forms for a Custom Transaction Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4230558097.html).

For help creating a custom field, see [Creating a Custom Field](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2829580.html).

#### To add an existing custom field to a custom transaction type: {#procedure_4232270085}

1.  Do one of the following:
    
    -   To add an existing body field, go to _Customization > Lists, Records, & Fields > Transaction Body Fields_.
        
    -   To add an existing column field, go to _Customization > Lists, Records, & Fields > Transaction Column Fields_.
        
2.  Click the name of the required field.
    
3.  On the **Applies to** subtab, locate the **Custom Transactions** box, which lists all of the existing custom transaction types. Select the name of the appropriate type.
    
4.  Click **Save**.
