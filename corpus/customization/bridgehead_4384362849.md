This topic describes how to use the Source List field to set up dynamic defaulting relationships for custom segments and clarifies what each option in the Source List represents. For general information about dynamic defaulting for custom segments, see [Dynamic Defaulting for Custom Segments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4384362043.html).

You use the Source List field to set up dynamic defaulting.

Each choice in the Source List shows two terms. The first term represents the label of a field. The second term represents a record type.

![Segment source list example.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/SuiteBuilderCustomization/segmentSourceListExample2.png)

| Callout | Description |
| --- | --- |
| ![Segment callout number 1.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/SuiteBuilderCustomization/segmentCallout1.png) | This term represents the name of a field on the target record types. The selection that you make in this field always represents another record. For example, some transaction types have a field called Sales Rep. When a value for that field is saved on a transaction, that value identifies a specific employee record. |
| ![Segment callout number 2.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/SuiteBuilderCustomization/segmentCallout3.png) | This term represents the record type of the source record instance. To follow the example from the preceding row, a field labeled Sales Rep identifies a record of type Employee. |
