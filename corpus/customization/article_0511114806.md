Use the Currency Context subtab to define the currency associated with values entered in a currency custom field. Setting a currency context ensures that reports and analytics tools can display values with the correct currency and apply currency-aware processing. This helps you avoid confusion when working with data that may include multiple currencies. Other areas, such as transaction forms and saved searches, are not affected.

Setting a currency context is optional. Existing custom fields continue to behave as numeric fields unless you configure a currency context. The Currency Context subtab appears only when all the following conditions are met:

-   The custom field Type is set to Currency
    
-   The field is not a workflow, workflow state, or script field
    

The subtab doesn't appear for non-currency fields or workflow-related fields.
