You can make a segment required on records where it's used. To make a segment required, check the Mandatory box on the segment definition. This setting applies to all record types that use the segment.

However, be aware that even with this configuration, the segment isn't necessarily required in all situations. For example:

-   A custom form for the record type can be designed to prevent the custom segment from being visible. When a user creates or updates a record using this type of form, the segment isn't required.
    
-   Some users may have permission to create and edit a specific record type, but they may not have permission to set a value for the segment. When these users work with the record, the segment isn't required.
    

You can configure a segment to be required when you're creating the segment. You can also edit the segment later to change this setting.

#### To make a segment mandatory:

1.  Edit the custom segment.
    
2.  Click the **Validation & Defaulting** subtab.
    
3.  Check the **Mandatory** box.
    
4.  Click **Save**.
