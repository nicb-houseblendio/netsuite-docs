This topic describes how to select which record types and fields will receive dynamically defaulted values when configuring custom segments. For general information about dynamic defaulting for custom segments, see [Dynamic Defaulting for Custom Segments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4384362043.html).

The Application & Sourcing subtab has several child subtabs. Each subtab represents a category of record type.

When you display some of these subtabs, you'll see only one Source List field. The choice you make in this field affects all of the record types selected on that subtab. When you go to certain other subtabs, you can select a alternate Source List option for those record types.

On two of the subtabs, you can specify a Source List choice for each record type listed. This option is possible for the types listed on two subtabs: Other Record Types and Custom Record Types.
