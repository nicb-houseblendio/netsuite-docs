The following tags can be used in formulas:

-   Date - Current date and time:
    
    -   {TODAY}
        
    -   {NOW}
        
-   User ID:
    
    -   {ME}
        
    -   {USER}
        
    -   {USER.ID}
        
-   User role:
    
    -   {USERROLE}
        
    -   {USERROLE.ID}
        
-   User department:
    
    -   {USER.DEPARTMENT}
        
    -   {USERDEPARTMENT.ID}
        
-   User location:
    
    -   {USER.LOCATION}
        
    -   {USERLOCATION.ID}
        
-   User subsidiary:
    
    -   {USER.SUBSIDIARY}
        
    -   {USERSUBSIDIARY.ID}
        
-   User class:
    
    -   {USER.CLASS}
        
    -   {USERCLASS.ID}
