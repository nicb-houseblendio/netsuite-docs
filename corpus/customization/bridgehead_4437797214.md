This topic describes transaction numbers for a custom transaction type. For general information, see [Numbering for a Custom Transaction Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4177822615.html).

Autogenerated numbers are internal, gapless numbers that can't be overwritten. They're generated when a transaction record is saved. These internal numbers are generated for each transaction type.

If autogenerated numbering isn't set up in your account, transaction numbers begin at 1. For more information about the records and transactions available for autonumbering, see [Records and Transactions Available for Auto-Numbering](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N252520.html).

Important:

Historical transaction records can have duplicate internal numbering. NetSuite prohibits overwriting transaction type numbering sequences but permits the overwriting of document numbers. NetSuite does not renumber historical internal transaction numbers.

For more information about setting up autogenerated document numbers and transaction numbers, see [Set Auto-Generated Numbers](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N252198.html).

For each of your custom transaction types, you can customize the way these entry numbers are created. These options are described in [Components of a Custom Transaction Type's Entry Number](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4230484446.html). You may want to review these options before configuring numbering.

The process of configuring numbering includes the following tasks:

-   [Defining Numbering for a Custom Transaction Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4230484089.html) - Set the main values that define your numbering scheme.
    
-   [Defining Numbering Preferences for Subsidiaries and Locations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4230481550.html) - (Optional) Tie some aspect of numbering to subsidiary or location.
