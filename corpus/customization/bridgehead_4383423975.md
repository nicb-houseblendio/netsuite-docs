his topic describes how to delete custom segment values using the Manage Values page, which is helpful if you don't have access to edit the segment definition directly. For more information and other deletion options, see [Deleting the Values of a Custom Segment](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4316016599.html).

In some cases, you may not have permission to edit segments, but you do have permission to delete values for a segment. In these cases, to delete a value, you must open a page designed specifically for managing the value. You get to this page by viewing the segment definition and clicking the button labeled Manage Values.

#### To delete values by clicking Manage Values:

1.  Go to _Customization > Lists, Records, & Fields > Custom Segments_.
    
2.  In the list, select the segment you want to edit values for.
    
    The system opens the segment definition in view mode.
    
3.  Click **Manage Values**. A list of the existing segment values appears.
    
4.  Find the value you want to change and click the corresponding **Edit** button.
    
5.  Point to the **Actions** label to display a popup menu.
    
6.  Click **Delete**.
    
    The system displays a message asking if you're sure you want to delete the record.
    
7.  Click **OK**.
