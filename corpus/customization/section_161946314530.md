You can use sourcing to create a dynamic default on a filtered segment. The steps in this example outline how you can set up a state to filter by city on a sales order. Then when you enter the city name on a sales order, the state fills in automatically.

To complete the steps in this example, you'll need to create custom segments. For more information, see [Creating a Custom Segment](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4313465979.html).

Complete the following steps

1.  [Creating a Custom Segment Type that Determines the Dynamic Default Value](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_161946331340.html).
    
2.  [Creating a Custom Segment Type that Displays the Dynamic Default Value](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_161946393319.html).
    
3.  [Setting Dynamic Default Values](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_161946426768.html).
    
4.  [Using the Segments on a Transaction Form](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_161946462505.html).
