On the **Sublist Fields** subtab, you can change the label of custom sublist fields and rearrange the columns, if required.

You can use the **Item Filter** on this subtab to select the saved search to determine which items are shown in the Items list on the transaction form. For more information, see [Filtering the Items Dropdown List on Transactions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N551064.html).

Note:

If you use the Item Filter on this page, only saved searches marked as Public appear in the list. For more information about creating a saved search, see [Defining a Saved Search](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N676039.html).

#### To configure sublist fields:

1.  In the **Show** column, check the boxes for the sublist fields to display on the form.
    
2.  In the **Label** column, enter labels as needed.
    
    Note:
    
    If you change the label of a field on the **Sublist Fields** subtab, the new label is also applied to the field on the **Printing Fields** subtab.
    
3.  Rearrange the fields as needed. To rearrange the fields, select and drag each line item to the preferred position, or click **Move to Top** or **Move to Bottom**.
    
4.  Click **Save**.
    

Note:

You can delete custom fields from sublists only by going to Customization > Lists, Records, & Fields and finding the field under the correct field type or under Custom Record Types. Standard fields can't be deleted, but you can hide them from forms by clearing their Show box. If you can't locate a field, try checking Custom Record Types or confirm whether the displayed label has been customized on the form.

Tip: You may find it easier to identify custom fields using a Custom Field Definition dataset in Analytics. For more information about creating datasets, see [Defining a Dataset](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544122173.html).
