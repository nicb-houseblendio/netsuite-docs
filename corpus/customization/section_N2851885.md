Changing a custom field's name doesn't automatically update it on custom forms that use the field.

#### To apply the new name to custom forms: {#procedure_N2851904}

1.  After changing your custom field, click **Apply to Forms**.
    
2.  On the Apply Custom Field to Forms page, in the **Label** field, change the field label for each form where you want to reflect the change.
    
    If no forms are listed, the Display Type field may be set to Hidden. Hidden fields aren't shown on any form.
    
    Note:
    
    Custom transaction body and custom transaction line fields are included on all forms, even if they aren't displayed. If the Display Type field is set to Hidden, the field is still included on all forms for those two field types. The system ignores any changes you make to show or hide the field on all forms that apply to that custom transaction body or custom transaction line field.
    
3.  Click **Save**.
