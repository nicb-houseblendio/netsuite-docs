This topic describes the specific behaviors and outcomes of enabling or disabling the View from Order Only setting, including example scenarios. For a general explanation of this setting, see [Behavior of View from Order Only Settings on Transaction Line and Transaction Body Custom Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0528113109.html).

When you click Receive on a purchase order, an Item Receipt page appears. The custom Item Receipt field gets its value from the original (parent) purchase order.

When you click Fulfill on a sales order, an Item Fulfillment page appears. The custom Item Fulfillment field gets its value from the original (parent) sales order.

If the View from Order Only box is checked on the field definitions page, the values in the related custom Item Receipt or custom Item Fulfillment fields are read-only. Even after saving and editing, the fields stay read-only. If you update the custom field value on the parent record, the value also updates on the related Item Receipt page or Item Fulfillment page. To edit the values, you first need to clear the View from Order Only box.

The following table describes how purchase order transactions and item receipts work with different settings. The same behavior applies to sales order transactions using the Sale box, Item Fulfillment box, and Fulfill button.

| Boxes | Actions |
| --- | --- |
| **Purchase or Purchase Item** | **Item Receipt** | **View from Order Only** | **Create New Item Receipt from Purchase Order by Clicking the Receive Button** | **Clear the View from Order Only box after Item Receipt is Created** | **Update Field Value on Purchase Order** | **Check or Clear the View from Order Only Box** |
| Cleared | Checked | Cleared | Item Receipt page has no value in the related custom field. You can enter and save a value. | N/A | Can't update field on purchase order because the Purchase field isn't applied. | N/A |
| Checked | Checked | Cleared | Item Receipt page has a value in the related custom field that's copied from the parent purchase order. You can edit and save this value. | N/A | Value on related Item Receipt page custom field does not update. | N/A |
| Checked | Checked | Checked | Item Receipt page has a value in the related custom field that's copied from the parent purchase order. The value is read-only and can't be changed. | Value isn't taken from the parent purchase order. Instead, the value loads from a database, and contains the value that was sourced during the creation of the item receipt. | Value on related Item Receipt page custom field does update. | **Clear:** Field displays the value that was in the field when the item receipt was created from the purchase order. If you change the value on the purchase order, the value on the item receipt remains the same. **Check:** Field displays the updated value taken from the purchase order. |
