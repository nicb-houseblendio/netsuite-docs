## Source From Item {#bridgehead_N2849341}

Note:

To source correctly, select the Vendor list in the List/Record field.

| **Field** | **Type** |
| --- | --- |
| Name | Free-Form Text |
| Display Name | Free-Form Text |
| Vendor Name | Free-Form Text |
| Online Name | Free-Form Text |
| Available Online | Check Box |
| Base Price | Currency |
| Cost | Currency |
| Preferred Vendor | List/Record |
| On Hand | Decimal Number |
