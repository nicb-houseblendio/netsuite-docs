The Links subtab lets you create links throughout your account to access your custom records. When determining where to place links for the records, it's important to consider all roles that will be using the record type and how they'll be using it to determine the most logical place for the links.

When you add links, choose only the link types that users need. For example, use:

-   **Custom Record** when users should be able to list, create, and search records from the menu .
    
-   **New Custom Record** when users mainly need to create new records .
    
-   **Search Custom Record** when users mainly need to find existing records.
    

Important:

After you create a link to a custom record type, this link displays only for users with permission to access the custom record type

#### To add a link to a custom record: {#procedure_N2880954}

1.  In the **Center** column of the **Links** subtab, select the center you want the link to be visible in.
    
    If needed, you can add links to this custom record in each center.
    
2.  In the **Section** column, select the tab you want the link to display on.
    
    The available tabs depend on the selected center. If a center **hasn't** been selected, no tabs are listed.
    
3.  In the **Category** column, select a category for your link, either a built-in one or a custom one you've created. For more information about creating custom categories, see [Creating Center Categories](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2890916.html).
    
4.  In the **Links** column, select the type of link you want to add to the menu:
    
    -   To have the custom record list option display in the menu and open to the Custom Record List page, select **Custom Record**, where Custom Record is the name of the custom record. This option also adds New and Search to the menu.
        
    -   To have the new custom record option display in the menu and open to the New Custom Record page, select **New Custom Record**, where Custom Record is the name of the custom record.
        
    -   To have the search custom record option display on the menu and open to the Custom Record Search page, select **Search Custom Record**, where Custom Record is the name of the custom record.
        
5.  In the **Label** column, enter a name for this link.
    
    If you don't enter a label, the name defaults to the custom record type name.
    
6.  (Optional) In the **Translation** column, enter any translated names required for the link. Then click **Done**.
    
7.  (Optional) In the **Insert Before** column, choose where you want to place the link. If you don't provide a value in the **Insert Before** column, the link will appear below the last link in your chosen category.
    
8.  Click **Add**.
    
9.  Repeat these steps for each link you want to add.
    
    If you want to edit a link, click the line for that link and make changes as needed.
    
10.  Click **Save**.
