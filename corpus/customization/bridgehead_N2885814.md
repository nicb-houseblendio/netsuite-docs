You can establish parent-child relationships in NetSuite between standard or custom records using custom fields. The process varies slightly depending on whether you're working from the Custom Field configuration page or the Custom Record Type page. You can also specify where child records display on the parent record. For detailed steps, see the following topics:

-   [Defining a Parent-Child Relationship Using the Custom Field Configuration Page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_158229274539.html)
    
-   [Defining a Parent-Child Relationship from a Custom Record Type Page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_158229291316.html)
    
-   [Setting the Display Subtab for Child Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_158229331667.html)
    

To establish a parent-child relationship between records, you must create a custom field and define both the parent and the child. This applies to both custom and standard records.

You can define the parent and child on the:

-   Custom Field configuration page, when creating a new custom field
    
-   New Field configuration page from a Custom Record Type page
