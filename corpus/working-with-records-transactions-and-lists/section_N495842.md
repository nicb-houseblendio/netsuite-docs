NetSuite provides you with several different options for viewing lists of records in your account, including the following:

-   [List View](#bridgehead_N495933)
    
-   [Sublist View](#bridgehead_N495978)
    
-   [Dashboard View](#bridgehead_N496018)
    

## List View {#bridgehead_N495933}

The list view is displayed when you go to the NetSuite tab that lists the record you want, and click the task link for that type of record. You can customize this view by changing the fields that display on the list page. A customized view is based on a custom search that you create for that record type.

To customize a list view, click Customize View or Edit View. Note that the Edit View button only appears when you've already customized the list view. For more information, see [Customizing List Views](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N496170.html).

![List view page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteBasics/WorkingWithLists_ListsOfEmployees.png)

## Sublist View {#bridgehead_N495978}

Most records include subtabs that display additional fields or lists of other records. You can create a separate customized sublist view that displays different data than a list view. For more information, see [Customizing Sublist Views](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N496633.html).

![Custom subtab](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteBasics/WorkingWithRecords_CustomSubtab.png)

## Dashboard View {#bridgehead_N496018}

You may choose to display a list of records in a portlet on your dashboard. NetSuite enables you to create a separate customized view for list portlets on your dashboard. For more information, see [Customizing Dashboard Views](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N496945.html).

![Customize View option](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteBasics/WorkingWithRecords_CustomizeDashboardList.png)

Your existing list, sublist, and dashboard views may be based on preferred view settings specified by your administrator or by another user with Publish Search permission, rather than on system-defined defaults. For information about how preferred view settings are defined, see [Using a Saved Search as a View](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N679407.html).
