When creating a transaction, the total number of lines per transaction shouldn't exceed the following limits:

Warning:

Transactions with more than 1,000 lines may negatively affect performance or cause timeouts.

| Type of Transaction | Line Limit | Details |
| --- | --- | --- |
| Expense Allocation Schedules | 10,000 | [Creating Expense Allocation Schedules](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1483674.html) |
| Journal Entries | 200 | [Journal Entries](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N1468455.html) |
| Revenue Recognition Journal Entry | 1,000 | [Generating Revenue Recognition Journal Entries](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1692238.html) |
| Merge Revenue Arrangements | 10,000 | [Combination and Modification of Performance Obligations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4370936582.html) |
| Generating Revaluations | 2,000 | [Generating Revaluations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1430227.html) |
| Reclassification Journal Entries | 1,000 | [Creating Reclassification Journal Entries](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4365500917.html) |
| Journal Entry Allocation | 200 | [Allocating Paycheck Expenses to Projects](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N955773.html) |
| Invoices | 200 | [Invoices](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1235134.html) |
| Sales Orders | 500 | [Sales Orders](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N1215966.html) |
| Software Vertical Contract Renewals | 10,000 | [Contract Renewals Best Practices](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157058181085.html) |
| SuiteTalk SOAP Web Services Transactions | 200 | [Usage Notes for Transaction Record Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3658677.html) |
| Custom Actions using the Workflow Action script | 100,000,000 | [Custom Action](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2752089.html) |
