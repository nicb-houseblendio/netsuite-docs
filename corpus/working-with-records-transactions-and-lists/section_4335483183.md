NetSuite includes several search tools to help you find and view your records. Here is a summary of the available tools with links to more information:

-   **Global search** - A search field appears in the center of the NetSuite header so that it's accessible everywhere in NetSuite. You can enter keywords here to search your entire NetSuite account. See [Global Search](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4307693953.html).
    
-   **Search crosslink** - This link in the upper right of most record and lists pages opens a search page for the current record type. From this page you can search using the following methods:
    
    -   **Simple search** - Use the filters on the page to search. See [Defining a Simple Search](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N645582.html).
        
    -   **Advanced search** - Check the **Use Advanced Search** box to switch to advanced search mode. See [Defining an Advanced Search](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N646177.html))
        
        **Saved search** - Click **Create Saved Search** to open a page where you can define a search that you and others can run repeatedly for dynamically updated results. See [Defining a Saved Search](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N676039.html).
        
-   **Quick find** - Many NetSuite pages include an icon ![Quick find icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteBasics/QuickFindIcon.png) (Quick Find) at the top of the page that you can click to search for other records of the same type. See [Quick Find](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N643277.html).
    
-   **Dashboard search portlets** - Several portlets are designed to help you search for records. These are:
    
    -   **Custom Search** - Displays the results from a saved search in a list. See [Displaying Saved Search Results in Dashboard Portlets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N690632.html).
        
    -   **Quick Search** - Contains a form where you can search for records of a selected type using a filter and keywords. See [Quick Search Portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N643459.html).
        
    -   **Search Form** - Similar to Quick Search, but the form is more complex and can be personalized. See [Adding Personalized Search Forms to NetSuite Pages](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N666481.html).
