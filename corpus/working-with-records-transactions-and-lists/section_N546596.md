When you're entering transactions, you can create new records as you complete the transaction fields. You don't need to leave the transaction record to create new records.

For the following transactions in NetSuite, you must select an entity prior to adding a record from the transaction:

-   **Write Checks** - You must select a payee before you can create a new account.
    
-   **Enter Sales Orders** - You must select a customer before you can create a new job.
    
-   **Accept Customer Payments** - You must select a customer before you can create a new bank account.
    

For example, you're entering checks and want to enter a new bank account. Select a payee and then click ![Create New icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteBasics/NavigatingNetSuite_AddNewIcon.png) next to the **Accounts** field. In the popup window, enter the new bank account name, account number, and whether the account is a subaccount of another. When you click **Save**, the Check page appears displaying the new account in the **Accounts** field.
