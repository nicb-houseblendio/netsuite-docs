NetSuite includes record types for all areas of your business. Click the links below to learn more about each record type and how to create new records:

-   **Accounting** - See [NetSuite Accounting Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N1379709.html).
    
-   **Items** - See [Creating Item Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2166469.html).
    
-   **Shipping Items** - See [Creating Shipping Items](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1259213.html).
    
    If you use the Shipping Label Integration feature, see [Shipping Integration with FedEx, UPS, and USPS/Endicia](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1263996.html).
    
-   **Gift Certificates** - See [Setting Preferences for Gift Certificate Authentication Codes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2245256.html)
    
-   **Employees** - See [Adding an Employee](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N894212.html).
    
-   **Relationships** - You can create records for different types of business relationships:
    
    -   **Leads** - See [Lead Management](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1086131.html).
        
    -   **Prospects** - See [Prospect Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1096136.html).
        
    -   **Customers** - See [Customers](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1076428.html).
        
    -   **Projects** - See one of the following topics:
        
        -   [Creating a Basic Project Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1179164.html)
            
        -   [Creating a Project Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1183012.html)
            
    -   **Contacts** - See [Contacts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1075037.html).
        
    -   **Groups** - See [Working with Groups](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N492945.html).
        
        Groups are a collection of contact, customer, employee, job, partner, or vendor records that you select. Using groups in NetSuite enables you to communicate efficiently with individuals and companies you do business with.
        
    -   **Vendor** - See [Creating a Vendor Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2362161.html).
        
    -   **Competitors** - See [Competitors](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1096618.html).
        
    -   **Other Names** - See [Other Name Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1096940.html).
        
-   **Commissions** - See [Commissions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N1122333.html).
    
-   **Marketing** - See [Marketing Automation Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N973384.html).
    
-   **Support Management** - See the following topics:
    
    -   [Setting Up Case Management](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N2421072.html)
        
    -   [Issue Management](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N2438260.html)
        
    -   [Knowledge Base](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N2445950.html)
        
-   **Web Site** - See the following topics:
    
    -   [Site Builder Items, Forms, & Images](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N2582621.html)
        
    -   [Site Builder Tabs & Categories](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N2595349.html)
        
    -   [Setting Up Items for the Web Site](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2585301.html#section_N2177433)
        
-   **Search** - See [Defining a Saved Search](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N676039.html).
    
-   **Mass Updates** - See [Mass Updates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1103335211.html).
    
-   **Custom** - See [Creating Custom Record Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2876492.html).
    
-   **Activities** - NetSuite enables you to create records to keep track of your business activities. See the following topics:
    
    -   [Scheduling Events](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N501467.html)
        
    -   [Creating CRM Task Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N508608.html)
        
    -   [Scheduling or Logging Phone Calls](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N510059.html)
