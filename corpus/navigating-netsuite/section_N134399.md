The Setup page is where NetSuite account administrators (and other users with a role granting permission) manage the details of your NetSuite account. The menu items available on the Setup page depends on your assigned role and permissions. If you aren't an account administrator, many setup tasks are unavailable to you. Some menu items available on the Setup page are only available for specific roles. See the following topics for information about Setup page menu items.

-   **Company**: see [Set Company Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N242860.html).
    
-   **Accounting**: see [General Accounting](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/preface_3710627041.html).
    
-   **Sales**: see [Setting Up SFA](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N1035717.html).
    
-   **Marketing**: see [Setting Up Marketing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N1017289.html).
    
-   **Support**: see [Support Management](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/book_N2420978.html).
    
-   **Issues**: see [Issue Management](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N2438260.html). In particular, see [Setting Issue Management Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2441221.html).
    
-   **Import/Export**: see [CSV Imports Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N342646.html) and [Additional Import and Export Options](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N463253.html).
    
-   **Users/Roles**: See [NetSuite Users & Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N284861.html).
    
-   **Integration**: see the following topics:
    
    -   [Company-Wide Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3422217.html)
        
    -   [Using the SOAP Web Services Usage Log](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3444819.html)
        
    -   [SOAP Web Services Security](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N3445516.html)
        

You may also see the following menu items on the Setup page, depending on what features are enabled in your account.

-   **Payroll**: depending on which payroll feature your company is using, see either [SuitePeople U.S. Payroll](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/preface_1538679887.html) or [Payroll Solutions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/part_N969390.html).
    
-   **Customization**: see [Customization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N3768661.html).
    
-   **Site Builder**: see [SuiteCommerce Site Builder](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/book_N2561640.html). See also [Site Builder Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2456218.html).
