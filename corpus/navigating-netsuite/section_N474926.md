The following are useful keyboard shortcuts you can use in NetSuite.

Note:

Some keyboard shortcuts work differently depending on the browser you use. For more information, see [Supported Browsers for NetSuite](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N340018.html).

## Searching Data in Your Account {#bridgehead_N474945}

You can press Alt+G to move the cursor directly to the Global Search field.

To search only the current page, press Alt+Shift+G. If you want to see results from both the global search and the current page search, press Esc. For more information, see [Global Search Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161899349589.html).

## Entering Data and Completing Forms {#bridgehead_N474963}

Use these shortcuts to complete and edit data on forms and records:

-   Press and hold Alt and Shift and type a letter to move to a subtab. See [Navigating Subtabs](#bridgehead_N475188).
    
-   On a transaction line, press Enter to save the line and go to the next line.
    
-   Press Tab to move the cursor between fields and buttons.
    
-   Use the Spacebar to check or clear a box.
    
-   In Amount fields, enter numbers to calculate by addition, subtraction, multiplication, and division.
    
    For example, enter 10 + 15 to calculate a total amount.
    
-   Press and hold Ctrl and click with your mouse to select multiple choices in a list.
    

## Date Fields {#bridgehead_N475057}

In date fields, press the following keyboard shortcuts to change dates:

| Alt+T | Enter today's date |
| --- | --- |
| Alt+Shift+T | Enter tomorrow's date |
| Alt+Y | Enter yesterday's date |
| Alt+Left | Enter previous day |
| Alt+Shift+Left | Enter previous month |
| Alt+Right | Enter next day |
| Alt+Shift+Right | Enter next month |
| Alt+Home | Enter the first day of the selected month |
| Alt+End | Enter the last day of the selected month |
| Alt+Page Up | Enter next month |
| Alt+Page Down | Enter previous month |
| Alt+M | Enter the last day of the current month |
| Alt+L | Enter the last day of the previous month |

Note:

These keyboard shortcuts are supported only in full date fields that include the month, day, and year.

## Multi-Choice buttons {#bridgehead_N475157}

On transactions and records that have buttons with popup lists, you can select the non-default button option. Use the Tab key to go to the list button. Then, use the down arrow key to expand the dropdown list. Click Enter to select the desired action. To collapse the list, use the up arrow key to return to the top.

## Navigating Subtabs {#bridgehead_N475188}

When using tabbed pages, you can quickly switch between subtabs by using keyboard shortcuts. Each subtab has a single letter underlined in the title. Press and hold Alt and Shift (for MacOS, press and hold Option and Control) and then press the corresponding letter to switch to that subtab. The cursor appears in the first field on the subtab.

## Viewing Reports {#bridgehead_N475205}

When viewing reports, you can do the following:

-   Press **Page Up** to go to the previous page of a report.
    
-   Press **Page Down** to go to the next page of a report.
    
-   Press **Home** to go to the first page of a report.
    
-   Press **End** to go to the last page of a report.
    

## Filtering Search Results {#bridgehead_4637307921}

When working with search results filters, you can use the following keyboard shortcuts:

-   Use the Tab key to switch between filters.
    
-   Use the Down Arrow key or the Up Arrow key to select an option from a filter dropdown list.
    
-   When typing a value into a filter field, use the Tab key to apply the value.
    
    Please note that pressing Enter doesn't apply the filter value.
