A new settings record is required for each subsidiary in every country.

#### To create a new settings record:

1.  Go to Setup > Customization > Localization Settings > New.
    
2.  From the **Subsidiary** list, select your subsidiary.
    
3.  To enable automatic EC tax code assignment, check the **EC Tax Code Change Enabled** box.
    
4.  From the **EC Dummy Tax Code** list, select **EC-DUMMY-DK** created in the previous procedure. To open the popup list and make the required changes, click the double arrow.
    
5.  From the following lists, select the respective tax codes. To open the popup lists and make the required changes, click the double arrows.
    
    -   From the **EC Goods Tax Code** list, select **ES-DK** if the standard ES-DK is not split, or **ESS-DK** if the standard ES-DK is split into two - for goods and services respectively.
        
    -   From the **EC Services Tax Code** list, select **ESSS-DK**.
        
    -   Click **Save**.
