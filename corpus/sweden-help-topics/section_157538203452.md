Sweden Tax Reports is a SuiteApp that delivers templates so that Sweden tax reports, including Periodic VAT Return Form 4700 report and EU Sales List & Intrastat, can be generated.

This SuiteApp works with the Tax Reporting Framework SuiteApp by providing Sweden tax report templates which you can choose from, among the country-specific templates, at Reports > Tax > Country Tax Reports. To use the features of Sweden Tax Reports, you need to install EMEA Localization. For more information, see [EMEA Localization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_157122959910.html).

The following tax reports are supported by the Sweden Tax Reports SuiteApp:

-   EU Sales List
    
-   Intrastat
    
-   Periodic VAT return Form 4700
    

To generate and file tax reports, read the following topics:

-   [Setting Up Country Tax Reporting Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_1557127083.html)
    
-   [Generating Localized Country Tax Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1528250223.html)
    
-   [Electronic Tax Filing in Tax Reporting Framework](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1555083924.html)
    

For information about the contents of each tax report, read the following topics:

-   [Sweden VAT Report: Return Form SKV4700](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156775976474.html)
    
-   [Sweden Intrastat](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164482996923.html)
    
    [Net Mass Requirement in Sweden Intrastat](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164482996923.html#subsect_23110408679)
    
-   [EC Sales List](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_156888850442.html)
    

To view any report in detail, see [Viewing a Generated Country Tax Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_1528251207.html).
