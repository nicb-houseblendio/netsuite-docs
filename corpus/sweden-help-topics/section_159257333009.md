Following Country-specific and Bank-specific payment file templates are stored in a Payment Template custom record:

-   Sweden BankGiro
    
-   Sweden IBAN
    
-   Sweden BankGiro SEB
    
-   Sweden IBAN SEB
    
-   Sweden BankGiro Swedbank
    
-   Sweden BBAN SEPA Swedbank
    
-   Sweden BBAN Xborder Swedbank
    
-   Sweden Fedwire XBorder Swedbank
    

The custom Payment Templates are stored under Setup > Customization > Payment Template. Click **Edit** on the template you want to use. The fields are the same as on NetSuite Payment Template record.

Copy the respective values and paste them onto the standard NetSuite Payment File Format record:

Select newly created Payment Template as the EFT template when creating Company Bank Details record according to NetSuite Electronic Payments documentation.

Create or edit Entity Bank Details records to use newly created Payment Template for your entities according to NetSuite Electronic Payments documentation.
