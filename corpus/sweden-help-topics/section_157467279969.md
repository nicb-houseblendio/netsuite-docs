Setting up an account for an organization doing business in Sweden usually requires enabling several features and installing some additional SuiteApps.

## Enabling Features {#bridgehead_157467407890}

Some features available in your NetSuite account can be very important or even essential for users in Sweden. If they are inactive, you should consider enabling them. Follow the instructions below to enable the most common features beneficial for users in Sweden. However, if you want to get access to some specific product area, go to the [Functional Areas](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_157425969916.html#bridgehead_160197814908) help topic and check the exact requirements.

If you don't have sufficient permissions to enable features, please contact your account administrator.

#### To enable most common features:

1.  Go to _Setup > Company > Setup Tasks > Enable Features (Administrator)_.
    
2.  On the **Company** subtab, go to the **International** subtab, and check the **Multi-language** and **Multiple Currencies** boxes.
    
3.  (Optional) On the **Accounting** subtab, go to the **Basic features** subtab, and check the **GL Audit Numbering** box.
    
4.  (Optional) On the **Accounting** subtab, go to the **Advanced features** subtab, and check the **Period End Journal Entries** and **Foreign Currency Variance Mapping** boxes.
    
5.  On the **SuiteCloud** subtab, enable the features under the following sections:
    
    -   SuiteBuilder
        
    -   SuiteScript
        
    -   SuiteGL
        
    -   SuiteFlow
        
    
    For more information about SuiteCloud features, see [SuiteCloud Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N239332.html).
    
6.  If your company is registered for EU One Stop Shop, on the **Tax** subtab check the **EU One Stop Shop** box.
    
7.  Click **Save**.
    

## Available SuiteApps {#bridgehead_160206247926}

Some additional features will only become active if you install a specific SuiteApp to your NetSuite account. SuiteApps are applications that extend NetSuite for specific industry and business needs. If you would like to get access to some specific product area, go to the [Functional Areas](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_157425969916.html#bridgehead_160197814908) help topic and check which SuiteApps are required to be installed. Sweden-specific features are currently available in the following SuiteApps:

| SuiteApp | Area | Description |
| --- | --- | --- |
| [Electronic Bank Payments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N1585433.html) | Payments | Enables bank payments of vendor bills, employee expenses, partner and employee commissions, customer refunds, and customer payments within Sweden. |
| [International Tax Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2051341.html) | Taxation (Accounts without SuiteTax) | Generates the Sweden VAT reports in English, or Swedish and generic sales and purchase reports by tax code, the generic EU sales list report, and the Intrastat report. |
| Supplementary Tax Calculation | Taxation (Accounts without SuiteTax) | Manages EU reverse charges through automatic posting of notional VAT to the General Ledger (GL), and provides support for the calculation of non-deductible input tax. This SuiteApp works in conjunction with the International Tax Reports SuiteApp and isn't compatible with SuiteTax. For more information, see [Setting Up Tax Codes to Post Notional Tax Amounts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4702880164.html) and [Recording Nondeductible Input Tax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1822590.html). This SuiteApp also supports VAT on prompt payment discounts. For more information, see [Recording Tax on Prompt Payment Discount](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4702990460.html). If the SuiteTax feature is enabled in your NetSuite account, don't install the Supplementary Tax Calculation SuiteApp. |
| [Tax Audit Files](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N2073244.html) | Taxation (Accounts without SuiteTax) | This SuiteApp enables tax payers to provide their electronic records to tax auditors in support of their tax returns, and for auditors to review accounting records. Note that FAIA isn't currently supported. Please use one of the following formats instead:
-   OECD Standard Audit File for Tax (SAF-T) XML file
-   GL Data Extract

 |
| [SuiteTax Engine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1557396965.html) | Taxation (Accounts with SuiteTax) | For NetSuite accounts with the SuiteTax feature enabled, the SuiteTax Engine sets default tax codes based on local tax requirements. You must install these SuiteApps in the following order:

1.  SuiteTax Engine
2.  Tax Reporting Framework

 |
| [Tax Reporting Framework](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1528262949.html) | Taxation (Accounts with SuiteTax) | This SuiteApps enables to generate VAT reports, tax audit files, EU Cross-Border reports (Intrastat and EC Sales List). For Sweden, the generic summary and detailed tax reports are available to support you in producing the VAT return. You must install these SuiteApps in the following order:

1.  SuiteTax Engine
2.  Tax Reporting Framework

 |

-   Accounting

 | Supports localization features for Sweden. Important: This SuiteApp isn't compatible with SuiteTax. |

Following SuiteApps are required:

-   SuiteTax Engine Tax Reporting Framework EMEA Localization

 |

OSS is categorized into three specific schemes: Non-Union OSS Scheme, Union OSS Scheme, and Import OSS Scheme. These schemes allow taxable persons to declare and pay VAT due in Member States where the taxable persons are not established. |
