The Sweden Tax Reports SuiteApp delivers templates for tax reports that are required in Sweden.

#### To install the Sweden Tax Reports SuiteApp: {#procedure_157538241568}

1.  Go to Customization > SuiteBundler > Search & Install Bundles.
    
2.  Using the **Keywords** field, search for the bundle ID **307400**.
    
3.  Click the Sweden Tax Reports link in the Name column.
    
4.  On the Bundle Details page, click Install.
    

For more information about installing SuiteApps, see [Installing a Bundle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3395142.html).

The Sweden Tax Reports SuiteApp is a managed bundle and is automatically updated whenever enhancements or new features are added.
