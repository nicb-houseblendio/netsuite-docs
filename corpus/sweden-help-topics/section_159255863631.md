With the Sweden Localization SuiteApp, it's possible to create a dummy tax code.

#### To create a dummy tax code:

1.  Go to Setup > Accounting > Tax codes > New.
    
2.  Select a country.
    
3.  In the **Tax Code** field, enter **EC-DUMMY-SE** for Sweden.
    
4.  In the **Description** field, you can write, for example, that this tax code placeholder is used with Automatic EU Tax Code Selection for EC Sales feature.
    
5.  In the **Rate** field, enter **0.00**.
    
6.  In the **Subsidiaries** field, select all subsidiaries in Sweden (pressing Ctrl).
    
7.  From the **Tax Agency** list, select the **Tax Agency SE**.
    
8.  From the **Tax Type** list, select **VAT**.
    
9.  From the **Available On** list, select **Sales Transactions**.
    

If it's required to use Notional VAT or to set up reverse charges, the default ES-SE tax code for EU standard sales/purchases for goods must be split into two. One tax code must be set for sales and one for purchases, as the setup would only apply on the purchase side. The tax codes must be set up as follows (example is given for Denmark):

![Split ES-DK tax code settings, ESS-DK for sales, ESP-DK for purchases.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/CountrySpecificFeatures/Nordic_TaxCodes.png)

The **Available On** field must be set to **Sales Transactions** and **Purchase Transactions** accordingly.
