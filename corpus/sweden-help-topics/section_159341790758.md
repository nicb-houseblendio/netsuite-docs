## Invoice Print Layout {#subsect_2173955711}

To print invoices in Swedish layout, the Invoice Template has to be linked with the Invoice Transaction Form.

#### To customize invoices for printing:

1.  Go to Customization > Forms > Transaction Forms.
    
2.  Click **Edit** on the Nordics Invoice Form. If you don't have one, click **Customize** on the **Standard Invoice Form** and save it as a custom invoice form. However, **if your NetSuite account is using SuiteTax**, you may want to customize the transaction forms included in the SuiteApps which are **Sweden Invoice (EN) - SuiteTax** or **Sweden Invoice (SE) - SuiteTax.**
    
3.  From the **Print Template** list, if your NetSuite account is using Legacy tax, select **Nordic Countries Invoice PDF/HTML Template**. If your NetSuite account is using SuiteTax, select **Sweden Invoice PDF/HTML Template (SuiteTax)**.
    
4.  Click **Save**.
    

There is a single (consolidated) PDF/HTML template that reads the language of the Customer and prints the invoice accordingly.

Also, the customer's language must be set to Swedish. Open the customer's record and go to the **Preferences** subtab:

Note:

The languages can only be added if they are first set under Setup > Company > General Preferences on the **Languages** subtab.

## Printing Invoice in Customer's Language {#bridgehead_159661616278}

If the customer's language is set to Swedish language, the invoice is printed accordingly.

Click on the Print icon and select **Print**.

## Subsidiary Specific Fields {#subsect_159341793795}

Company information (name, phone, IBAN and so on) is displayed in the footer of the Invoice Layout. To set which information should be displayed, go to Setup > Company > Subsidiaries and click **Edit** on the respective subsidiary. Enter the values you want to get printed.

You can find the following fields on an invoice:

-   Subsidiary Logo (Forms): This value is required for the template to print correctly as otherwise an error is thrown.
    
-   Company VAT: This is created as a separate field in case the standard field is no longer available, for example if changes are required.
    
-   Company Business ID
    
-   Bank Account No: Local bank account number for local currency.
    
-   Company IBAN
    
-   Company IBAN 2: For payments in other currency, if required.
    
-   Company IBAN 3: For payments in additional currency, if required.
    
-   Company BIC
    
-   Company BIC 2: Linked to IBAN 2.
    
-   Place of Domicile: Sweden only.
    
-   Phone Number for Invoice
    
-   Company Email for Invoice
    
-   Overdue Interest
