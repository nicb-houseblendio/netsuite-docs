## Defining SRU Codes for Every Account {#bridgehead_159281196991}

Standardiserad Räkenskaps Utdrag (SRU) is the Swedish tax authority's code for standardized accounts extraction. It focuses on a specific general ledger account where you enter the account's balance on the form for standardized accounts extracts. You may be required to enter account balances under several form headings or on income tax return forms.

To set an SRU code for an account, update a CSV, or set it manually.

#### To set an SRU code manually:

1.  Go to Lists > Accounting > Accounts.
    
2.  Click **Edit** on the account record you want to set the SRU code for.
    
3.  Enter the value in the **SRU Code** field.
    
4.  Click **Save**.
    

## Creating a Folder in the File Cabinet for Storing SIE Files {#bridgehead_159281214183}

You can create multiple folders but only one per subsidiary.

#### To create multiple folders:

1.  Go to Documents > Files > File Cabinet > New.
    
2.  Enter the name of the folder (for example SIE File Export).
    
3.  Select a parent folder if required.
    
4.  You can restrict your results by class using the **Restrict by Class** field. You can restrict your results by department, location or group in the same way.
    
5.  Click **Save**.
    
6.  The internal ID of the folder is required in the next procedure (to enable Internal IDs, go to Home > Set Preferences > General > Default sections > Show Internal IDs'.).
    

## Defining Localization Settings for SIE Export {#bridgehead_159281531696}

The internal ID of the SIE folder is required in the following procedure.

Note:

The Sweden Localization SuiteApp supports the following SIE dimensions:

-   Department
    
-   Class
    
-   Location
    
-   Custom Segments
    

#### To define localization settings for SIE Export:

1.  Go to Setup > Customization > Localization Settings.
    
2.  Open the record for your subsidiary, or create a new one.
    
3.  Enter the internal ID of the folder in the **SIE Folder ID** field.
    
4.  Select the standard Retained Earnings account.
    
5.  Define the SIE Dimensions that need to be considered for the SIE extract in the following format:
    
    Record/Table ID for the dimension in NS:ID of the field in transaction;Name for dimension in SIE Export
    
    For example: department:department;Kostnadställe
    
6.  Click **Save**.
    
7.  Repeat this procedure for other subsidiaries.
    

## Role Setup {#bridgehead_159283145284}

Roles of users who perform SIE extract must be given certain permissions.

#### To give permissions to roles:

1.  Go to Setup > Users/Roles > Manage Roles.
    
2.  Click **Edit** on the role record that is used for SIE extract.
    
3.  On the **Permissions** subtab, go to **Custom Record** subtab.
    
4.  From the popup list, select **Localization Settings** and from the **Level** list, select **View**.
    
5.  Click **Save**.
