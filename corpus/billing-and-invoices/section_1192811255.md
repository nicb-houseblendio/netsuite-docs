Creating additional item information fields for sales transactions such as sales orders, item receipt, item fulfillment records, and invoices involves the creation of transaction line fields. Creating additional item information fields for subscriptions involves the creation of other record fields.

The additional item information fields that you create will appear in the sales order, item fulfillment, item receipt, subscription, and invoice records as columns in the item line.

#### To create additional item information fields in sales and subscription records:

1.  To create additional item information fields for sales transactions, such as in a sales order, item fulfillment, item receipt, and invoice records, do the following steps:
    
    1.  Go to Customization > Lists, Records, & Fields > Transaction Line Fields > New.
        
    2.  In the **Label** field, enter a label for the additional item information field.
        
        For example, if you want an additional item information field for a product key to appear in an item fulfillment record item line, enter **Product Key** here.
        
    3.  In the **ID** field, enter the script ID for the field.
        
        Note:
        
        Take note of the script ID for the field. You will use the script ID when setting item field mappings.
        
    4.  In the **Type** field, select the type of field that you want to create.
        
        Tip:
        
        The free-form text field type has a limit of 300 characters. Any commas used to separate entries are included in the character limit count. If you plan to use more than 300 characters in an additional item information field, use the text area field type.
        
    5.  Check the **Store Value** box.
        
        Checking this box allows you to store information in the additional item information field.
        
    6.  In the **Applies To** subtab, check the following boxes to display the additional item information field in sales transaction records.
        
        -   **Sale** - Check this box to create the additional item information field in sales transaction records such as in sales orders and invoices.
            
        -   **Item Receipt** - Check this box to create the additional item information field in item receipt records.
            
        -   **Item Fulfillment** - Check this box to create the additional item information field in item fulfillment records.
            
    7.  Complete the fields in the Transaction Line Fields page, as necessary.
        
        For more information, see [Creating Custom Transaction Line Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2828307.html).
        
    8.  Click **Save**.
        
2.  To create additional item information fields for subscription records, do the following steps:
    
    1.  Go to Customization > Lists, Records, & Fields > Other Record Fields > New.
        
    2.  In the **Record Type** field, select **Subscription Line**.
        
    3.  In the **Label** field, enter a label for the additional item information field.
        
        For example, if you want to have an additional item information field for a product key to appear in the related subscription record item line, enter **Product Key** here.
        
    4.  In the **ID** field, enter the script ID for the field.
        
        Note:
        
        Take note of the script ID for the field. You will use the script ID when setting item field mappings.
        
    5.  In the **Type** field, select the type of field that you want to create.
        
        Tip:
        
        The free-form text field type has a limit of 300 characters. Any commas used to separate entries are included in the character limit count. If you plan to use more than 300 characters in an additional item information field, use the text area field type.
        
    6.  Check the **Store Value** box.
        
        When you check this box, information entered can be stored in the additional item information field.
        
    7.  Click **Save**.
