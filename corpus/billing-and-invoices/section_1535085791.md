The usage data RESTlet supports these methods:

-   [sbCreateUsage](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1535005401.html) - Creates usage records for subscription items in NetSuite.
    
-   [sbGetUsageCreationStatus](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1535005426.html) - Returns the status of the request ID for usage data creation.
