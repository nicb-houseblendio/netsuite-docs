When creating or editing an item record for a fulfillable item, you can link the fulfillable item to its corresponding subscription item. When this linking happens, the subscription item automatically displays as a counterpart of the fulfillable item when you create a sales order.

#### To link a fulfillable item to a subscription item:

1.  Go Lists > Accounting > Items > New.
    
2.  Select the fulfillable item type that you want to create a record for.
    
    For more information about the supported fulfillable item types, see [Supported Item Types for Fulfillable Items with SuiteBilling](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_25151523576.html).
    
3.  Enter information for the fulfillable item, as necessary.
    
    For more details, see [Creating Item Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2166469.html).
    
4.  In the **Subscription Item** field, under the Classification section, select the subscription item that you want to link to the fulfillable item.
    
    For more information about the supported subscription item types, see [Supported Item Types for Fulfillable Items with SuiteBilling](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_25151523576.html).
    
5.  Click **Save**.
