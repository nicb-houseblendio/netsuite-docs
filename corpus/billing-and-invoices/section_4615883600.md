The following standard roles can send and re-send e-documents in bulk:

-   A/P Clerk
    
-   A/R Clerk
    
-   Accountant
    
-   Administrator
    
-   Bookkeeper
    
-   CEO
    
-   CFO
    
-   Custom Accountant
    
-   Retail Clerk
    

An administrator can give custom roles access to the bulk sending feature. The following conditions must be met to enable a custom role to send e-documents in bulk:

-   The custom role has been added to the script audience for the **Outbound E-Invoicing Form SU** script.
    
-   The custom role has Edit permissions for the transaction types for which your company generates and sends e-documents.
    
-   The custom role has Edit permission for the Add E-Document Sending Batch custom record.
    

#### To grant custom roles access and permissions to send e-documents:

1.  Add the custom roles to the script audience by performing the following steps:.
    
    1.  Go to _Customization > Scripting > Script Deployments_.
        
    2.  Click the Edit link of the script named **Outbound E-Invoicing Form SU**.
        
    3.  On the **Audience** subtab, in the **Roles** field, select the custom roles that you want to give access to.
        
    4.  Click **Save**.
        
2.  Add the required permissions to custom roles by performing the following steps:
    
    1.  Go to _Setup > Users/Roles > Manage Roles_.
        
    2.  Click the Edit link of the custom role that you want to modify.
        
    3.  Add permission to edit transaction types:
        
        1.  On the **Permissions** subtab, go to the **Transactions** subtab.
            
        2.  In the **Permission** column, on a blank row, select a transaction type.
            
        3.  In the **Level** column, select **Edit**.
            
        4.  Click **Add** to add the row.
            
        5.  Add other transaction types that the custom role must have access to.
            
    4.  Add permission to edit the custom record used for bulk sending:
        
        1.  On the **Permissions** subtab, go to the **Custom Record** subtab.
            
        2.  In the **Record** column, on a blank row, select **Add E-Document Sending Batch**.
            
        3.  In the **Level** column, select **Edit**.
            
        4.  In the **Restrict** column, select **Editing Only**.
            
        5.  Click **Add** to add the row.
            
    5.  Click **Save** to save the changes to the custom role.
