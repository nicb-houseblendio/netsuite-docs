After Avalara provisioning, the final step in the parent company setup, set up each subsidiary. Register it with OBN and create its Avalara company.

#### To set up subsidiaries:

1.  Click **Subsidiary Setup List**.
    
2.  From the **Subsidiary Setup** list, select a subsidiary.
    
3.  Click **Start Setup**.
    
4.  If setup is already in progress, click **Continue**.
    
    The OBN Registration page opens.
    
5.  For each subsidiary, complete the following tasks:
    
    #### Register the subsidiary as an OBN trading partner:
    
    1.  Review the Company Information, Address, and Contact Information sections.
        
    2.  In the Company Contact Information section, select the **OBN Manager**.
        
    3.  Do one of the following:
        
        -   If the subsidiary legal name is not already registered, click **Register**. After registration, click **Next**.
            
        -   If another subsidiary with the same legal name is already registered, click **Sync** to reuse the existing OBN registration information.
            
        
        The Avalara Company Creation page opens.
        
    
    #### Create the company in Avalara:
    
    1.  Review the subsidiary information.
        
    2.  Click **Submit**. A success banner is displayed, indicating that Avalara company creation is complete.
        
    3.  If another subsidiary with the same OBN ID already has an Avalara company set up, you can synchronize the existing Avalara company instead of creating a new one by clicking **Sync**.
        
    

## Reusing OBN and Avalara Setup for Subsidiaries With the Same Legal Name {#subsect_0810104219}

If your company has multiple subsidiaries that share the same legal entity information, you don't need to repeat the same setup for each subsidiary.

The system can reuse existing setup information from another eligible subsidiary. Depending on the setup stage, you can sync:

-   OBN registration details
    
-   Avalara company information
    
-   Mandate activation information
    

Reusing existing setup information helps you avoid duplicate configuration, reduces setup time, and keeps subsidiary information consistent.

## Before You Begin {#subsect_51224352347}

A subsidiary is eligible for synchronization only when another subsidiary already contains the required setup information.

The following table shows the requirements for each synchronization type:

| Sync Type | Requirement |
| --- | --- |
| OBN registration details | Another subsidiary with the same legal name has completed OBN registration. |
| Avalara company | Another subsidiary with the same OBN ID already has an Avalara company set up. |
| Mandate | Another subsidiary with the same Avalara Company ID already has the required mandate activated. |

## Sync OBN Registration Details {#bridgehead_5224458730}

You can synchronize OBN registration information from another subsidiary that has the same legal name.

## To sync OBN registration details: {#bridgehead_46224501801}

1.  Log in to NetSuite.
    
2.  Go to Setup > Electronic Business > OBN Registration for the subsidiary that you want to configure.
    
3.  If an eligible subsidiary exists, review the OBN information displayed on the OBN Registration page.
    
4.  Check the consent box.
    
5.  Click **Sync**.
    

## Example Scenario: {#bridgehead_88225128518}

-   You want to register subsidiary A with OBN.
    
-   Subsidiary B with legal name XYZ has already completed OBN registration.
    
-   Subsidiary A has the same legal name XYZ as Subsidiary B.
    

## Result: {#bridgehead_80225121354}

When you begin OBN registration for subsidiary A, NetSuite detects the existing registration and displays the Sync OBNDetails page. After you click **Sync**, the OBN information is copied from subsidiary B to subsidiary A.

## Sync Avalara Company Information {#bridgehead_27225113423}

If another subsidiary already has an Avalara company associated with the same OBN ID, you can reuse that company instead of creating a new one.

## To sync Avalara company information: {#bridgehead_85225106854}

1.  Log in to NetSuite.
    
2.  Go to Setup > Electronic Business > Avalara Company Creation
    
3.  If NetSuite detects an existing Avalara company for the same OBN ID, review the company information on the Company Sync page.
    
4.  Check the consent box.
    
5.  Click **Sync**.
    

## Example Scenario: {#bridgehead_81225059623}

-   You want to associate subsidiary A with the existing Avalara company.
    
-   Subsidiary B already has an Avalara company set up.
    
-   Subsidiary A shares the same OBN ID.
    

## Result: {#bridgehead_80225053262}

When you begin company creation for subsidiary A, NetSuite detects the existing Avalara company and displays the Company Sync page. After you click **Sync**, the Avalara company information is copied to subsidiary A.

## Sync Mandate Information {#bridgehead_66225033028}

If another subsidiary has already activated a mandate for the same Avalara Company ID, you can reuse that activation.

## To sync mandate information: {#bridgehead_86225009725}

1.  Log in to NetSuite.
    
2.  Go to Setup > Electronic Business > Avalara Mandate Activation
    
3.  Select the mandate that you want to activate.
    
4.  If an eligible mandate already exists, review the information on the Mandate Sync page.
    
5.  Click **Sync**.
    

## Example Scenario: {#bridgehead_2224933598}

-   You want to activate a CTC or PEPPOL mandate for subsidiary A.
    
-   Subsidiary B has already activated any CTC or PEPPOL mandate.
    
-   Subsidiary A shares the same Avalara Company ID as subsidiary B.
    

## Result {#bridgehead_55224925386}

When you activate the CTC or PEPPOL mandate for subsidiary A, NetSuite detects the existing activation and opens the Mandate Sync page. After you click **Sync**, the mandate information is synchronized to subsidiary A, and you don't need to activate the mandate again.

If multiple subsidiaries share the same legal entity information, you can reuse existing OBN and Avalara setup information for eligible subsidiaries. For more information, see [Reusing OBN and Avalara Setup for Subsidiaries With the Same Legal Name](#subsect_0810104219)
