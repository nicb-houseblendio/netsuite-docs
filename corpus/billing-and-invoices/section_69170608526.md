| Area | Limitation |
| --- | --- |
| Billing and invoices | Additional item information entered for fulfillable items are only carried over to the invoice when you use the Billing Operations tool. Go to Transactions > Billing > Process Billing Operations. For more information, see [Billing Operations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4063198073.html). The billing of items using the Bill function in the item fulfillment record does not support the additional item information entered for fulfillable items. |
| The **Add Charges** button in the invoice is not supported for use with this SuiteApp. |
| Returns of fulfillable items | Update of related subscriptions for returned items are only supported when returns originate from the associated sales order. Standalone return authorization forms are not supported. |
| Fulfillable item types | Lot-numbered fulfillable items are not supported for linking to a subscription item. |
| Update of subscription for deleted item fulfillment or item receipt records | If you delete an item fulfillment or item receipt record for fulfillable items that have been shipped to customers, the additional item information entered for fulfillable items are not deleted or updated in the related subscription. If you want to reuse the additional item information entered for items with deleted item fulfillment or item receipt record, you can manually remove the additional item information in the related subscription record. To do this, edit the subscription line and then delete the additional item information for the fulfillable items. |
| Splitting of subscription line items into multiple lines | Splitting is only supported for sales orders with a status of **Pending Approval**. |
| If you replace or choose another subscription item in a previously saved sales order, all subscription line items that have been previously split will remain as split. |
| Splitting is only supported for subscription items that are optional. Splitting does not happen for subscription lines that are required in the subscription plan. |
| When a sales order with previously split subscription line items is edited and the box for splitting subscription line items into multiple lines is unchecked, all previously split lines are not merged back. If you want to modify or merge subscription line items when they have been split, you can either remove the subscription in the sales order or create another sales order. |
| Splitting of subscription line item amounts is only accurate for whole numbers. Splitting of amounts with decimal quantity is not exact. |
| The SuiteApp can split subscription line item quantities of up to 200. It approximately takes up to 7 minutes to display the split lines in the sales order. For optimal performance, the maximum recommended line item quantity is 50. It approximately takes up to 2 minutes to display split lines in the sales order for this quantity. |
| Sales orders for use with the SuiteApp | Only sales orders created from the user interface or through CSV import are supported for use with the SuiteApp. Sales orders created through WebServices, SuiteScript, or ODBC are not supported. |
| Subscription termination | Termination of subscription because of a returned item is not supported by the SuiteApp If you want to terminate a subscription because of a returned item, you must manually do it. For instructions, see [Terminating a Subscription Line Item](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1547760916.html). |
| Subscription renewals | The SuiteApp only supports the Extend Existing Subscription renewal method. Additional item information entered for fulfillable items in the original subscription are retained when this is the renewal method used. |
| Item field mappings | Only the serial numbers native field is supported for item field mappings. Other native fields and custom fields are not supported. |
| Creating replacement sales order | The **Create Replacement Sales Order** button in return authorization form is only available when a returned item has an accompanying item receipt record. |
| Revenue arrangements | The revenue arrangement for sales orders and subscriptions are separate. There is no auto-merging. |
