If the Installments feature is enabled, you can also enable the Invoice Groups feature, but an invoice with an installment term can't be grouped. If you select an installment term on a sales order or invoice for a customer with invoice grouping enabled, the transaction won't save and you'll see an error message.

To save a transaction with an installment term, you must clear the **For Invoice Grouping** box. If the term changes from installments to a different term, check the **Group Invoices** box to mark the invoice for grouping.

If you mark an invoice for grouping, the **Term** field is dimmed.

For more information about the Installments feature, see [Creating Installments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1540928779.html)
