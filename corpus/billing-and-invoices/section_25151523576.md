Fulfillable Items with SuiteBilling SuiteApp only supports the following item types.

| Fulfillable Items | Subscription Items |
| --- | --- |
| 
-   Serialized inventory items
-   Inventory items
-   Non-inventory items that can be fulfilled
    -   For purchase
    -   For resale
    -   For sale

 | 

-   Non-inventory items that cannot be fulfilled
    -   For resale
    -   For sale
-   Service items

 |

For information about these item types, see [Item Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N2222944.html).
