SuiteBilling has a collection of features to enable.

Before you enable SuiteBilling features, ensure:

-   You're logged in to NetSuite using an Administrator role.
    
-   You've set the SuiteBilling preferences as instructed in [Setting the SuiteBilling Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1546981168.html).
    

For high-level overview diagrams of the workflows that include this procedure, see [Subscription Plan Creation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1555109813.html), [New Stand-Alone Subscription Creation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1558547441.html), and [Subscription Creation from a Sales Order](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1555109939.html).

#### To enable SuiteBilling features:

1.  Go to _Setup > Company > Enable Features_.
    
2.  Click the **Transactions** subtab.
    
3.  In the Billing section, check the following boxes:
    
    -   **Bill Costs to Customers**
        
    -   **Advanced Billing**
        
    -   **Charge-Based Billing**
        
    -   **Billing Accounts**
        
    -   **Billing Operations**
        
    -   **Subscription Billing**
        
    -   **Advanced Subscription Billing**
        
    
    You need Charge-Based Billing is required to see subscription line charge pricing details.
    
    You can check the following boxes for optional features:
    
    -   Add-on Items
        
    -   Time-Based Pricing for creating multiple time-based pricing intervals. For more information about how to use time-based pricing, see [Time-Based Pricing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1546981356.html#subsect_0725100327).
        
        With Time-Based Pricing enabled, you can use the Subscription Billing Enhanced UI SuiteApp. This SuiteApp has the same Time-Based Pricing as SuiteBilling, but with a better user interface. For more information about the Subscription Billing Enhanced UI SuiteApp, see [Subscription Billing Enhanced UI](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1552954533.html).
        
    -   Add-on Items is required to create a subscription without a subscription plan or price book.
        
        For more information about how to create a subscription without a subscription plan or price book, see [Optional Subscription Plan and Price Book](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1547668165.html#subsect_0903055113).
        
    -   Invoice Groups, for creating and managing invoice groups. You can group multiple invoices before sending them to a customer.
        
    -   Commit Plus Overage, for charging prepayment for a contracted minimum usage amount at a negotiated rate.
        
        For more information about commit plus overage charges, see [Commit Plus Overage Charges](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4543482439.html#subsect_0807061958).
        
    -   Uplift Pricing, for creating price increases for subscription lines using an uplift percentage at defined times during a subscription term.
        
        Warning:
        
        The **Uplift Pricing** feature requires time-based pricing to be enabled.
        
        For more information about how to use uplift pricing, see [Uplift Pricing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1547668165.html#subsect_0130081332).
        
    -   Prepaid Usage with Drawdown, a service type for when consumable services can be billed in advance, and usage is drawn down from the assigned service lines.
        
        For more information about prepaid usage with drawdown, see [Prepaid Usage with Drawdown](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0903123502.html).
        
4.  On the Company tab in the Classifications section, you can optionally check any of the following boxes to help segment your recurring revenue:
    
    -   **Departments**
        
    -   **Locations**
        
    -   **Classes**
        
5.  Click **Save**.
    

## Enabling the Multi-Subsidiary Customer Feature for SuiteBilling {#subsect_0809104937}

With billing accounts across subsidiaries, you can use the Multi-Subsidiary Customer feature. For more information, see [Assigning Subsidiaries to a Customer](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N276747.html).

To enable Multi-Subsidiary Customer for SuiteBilling, see [Enable the Multi-Subsidiary Customer Feature](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1509460991.html).

If the Multi-Subsidiary Customer feature is enabled, the billing account field isn't automatically populated on the Subscription record.
