The following table shows the error messages that you can receive from the RESTlet.

| Error Code | Error Message |
| --- | --- |
| MISSING\_REQUEST\_DATA | Request data is missing. |
| MISSING\_REQUEST\_PROPERTY | The {0} property is missing in {1} object. |
| INVALID\_REQUEST\_METHOD | Request method is invalid: {0} |
| EMPTY\_REQUEST\_OBJECT | The {0} object is empty. |
| EMPTY\_REQUEST\_PROPERTY | The {0} property is empty. |
| INVALID\_PROPERTY\_FORMAT | The value for {0} property has invalid format. Format must be: {1}. |
| SUBSCRIPTION\_NOT\_FOUND | Subscription record isn't found using the {0} property. |
| SUBSCRIPTION\_LINE\_NOT\_FOUND | Subscription Line record isn't found using the {0} property. |
| REQUIRED\_VALUE\_NOT\_FOUND | {0} isn't found in the usage object. |
| MULTIPLE\_VALUES\_NOT\_MATCH | Multiple values of {0} don't match. |
| FIELD\_DOES\_NOT\_EXIST | The field {0} doesn't exist. |
| REQUEST\_NOT\_FOUND | Request {0} isn't found using the {1} property |
| MULTIPLE\_RECORDS\_FOUND | Multiple records found for {0} using the {1} property. |
