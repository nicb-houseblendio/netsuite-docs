After creating the custom templates for e-document email, an administrator can select the templates in a particular subsidiary on the Electronic Invoicing Preferences page. The selected template will be used in sending the e-documents by email to customers or vendors.

#### To select an e-document email custom template in OW account:

1.  Go to Setup > E-Documents > Electronic Invoicing Preferences. Click the required subsidiary link you want to select the **E-document Email Customization Template** for.
    
2.  Click **Edit**.
    
3.  From the **E-document Email Customization Template** list, select the required custom template.
    
4.  Click **Save**.
    

#### To select an e-document email custom template in accounts without OneWorld:

1.  Go to Setup > E-Documents > Electronic Invoicing Preferences. Click the parent company link.
    
2.  Click on **Edit**.
    
3.  From the **E-document Email Customization Template** dropdown list, select the required custom template.
    
4.  Click **Save**.
    

Note:

You can select e-document custom templates from both subsidiary and parent company records in the Electronic Invoicing Preferences page for the following combinations:

-   If you select a different template on both subsidiary record and parent company record, then the template you selected on the Subsidiary record is used.
    
-   If you select a template on the parent company record and not on the subsidiary record, then the same template is applied on transactions of all the subsidiaries.
    
-   If you select a template on the subsidiary record for a transaction, then the selected template is used for all transactions that are created for this subsidiary. It overrides the template selected on the parent company record.
    

Note:

If you don't select a template in subsidiary or parent company record, then system generated default template is used in the e-document email. This email is sent to customers or vendors during the outbound e-document sending process.

Note:

Email templates with their record type populated can be selected in a customer or vendor record.

An email template can be used in the E-Document Sending Method plug-in implementation, enabling them to use custom templates for customers or vendors.
