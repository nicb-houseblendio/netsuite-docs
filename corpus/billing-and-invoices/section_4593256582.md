The following tables show the permissions and access levels for features provided by the Electronic Invoicing SuiteApp:

**Administrator and Setup Tasks**

| Tasks or Functionality | Role and Permission |
| --- | --- |
| [Creating E-Document Packages](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4576918342.html) | By default, only the Administratorcan create, edit, or delete e-document packages. All other roles can only view e-document packages. |
| [Creating E-Document Templates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4536871429.html) | By default, only the Administratorcan create, edit, or delete e-document template records. All other roles can only view e-document template records. |
| [Creating E-Document Sending Methods](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4536875049.html) [Creating a Custom Plug-in Implementation for Sending E-Documents](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4536881298.html#bridgehead_1543233892) | By default, only the Administratorcan create, edit, or delete e-document sending methods. All other roles can only view e-document sending methods. |
| [Selecting a Designated E-Document Sender](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4592468256.html) | By default, only the Administratorcan select a designated e-document sender. |
| [Assigning E-Document Packages to Customer or Vendor Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4592483798.html) | Roles with access to customer and vendor and contact records can assign e-document packages to customer and vendor records. |
| [Creating a Custom Plug-in for Inbound E-Document Validation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1495190263.html#bridgehead_1495190369) | By default, only the Administratorcan create a custom plug-in for inbound e-document validation. |
| [Processing E-Documents Automatically for Individual Transactions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163197335497.html) | By default, only the Administrator can select the required **E-Document Automation Type** for a particular subsidiary. You can access the subsidiary under the **Subsidiaries** field group in the Electronic Invoicing Preferences page for OW accounts. In accounts without OneWorld, the **E-Document Automation Type** field can be set on the parent company in the Electronic Invoicing Preferences page. |

**Outbound Processing Permissions and Access Levels**

| Tasks or Functionality | Role and Permission |
| --- | --- |
| [Defining E-Document Email Recipients](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4592483197.html) | Roles with **Edit** or **Full** access to customer and vendor contact records can define e-document email recipients on customer or vendor records. |
| [Setting Up Custom Roles to Send E-Documents](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4615883600.html) [Customizing Roles to Restrict E-Document Generation or Sending](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1526454388.html) | The Administrator can restrict the default permission of roles to generate or send outbound e-documents. |
| [Generating E-Documents for Single Transactions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4536887456.html#bridgehead_4592492640) [Regenerating E-Documents for Single Transactions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4536887456.html#bridgehead_4592513986) | Roles with minimum permission to view supported transaction records, can generate and regenerate e-documents for single transactions. An administrator can grant custom roles the permission to generate e-document for sending to customers and vendors. |
| [Deploying the Bulk Generation Script for E-Documents](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4536902188.html) | Only the Administrator role can configure the script used to generate and regenerate e-documents in bulk. |
| [Sending the E-Document of a Single Transaction](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4576956606.html#bridgehead_4592516631) [Resending the E-Document of a Single Transaction](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4576956606.html#bridgehead_4592517695) | Roles with minimum permission to view supported transaction records, can send and resend e-documents for single transactions. |
| [Setting Up Custom Roles to Send E-Documents](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4615883600.html) [Resending E-Documents in Bulk](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4576956606.html#bridgehead_4592519521) | The following roles can send and resend e-documents in bulk:
-   A/P Clerk
-   A/R Clerk
-   Accountant
-   Administrator
-   Bookkeeper
-   CFO

An administrator can grant custom roles the permission to send bulk e-documents. An administrator can grant custom roles the permission to send e-documents to customers/vendors. |
| Template and Sending Method Auto-selection For more information about Template and Sending Method Auto-selection, see [Multi-subsidiary Support in the Outbound Process](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1543231067.html) | Roles with **Edit** or **Full** access to customer and vendor records can have access to template and sending method auto-selection feature. |
