| Message | Error on User Interface | Description | Solution |
| --- | --- | --- | --- |
| Subsidiary name is already in use by another subsidiary. Enter a different subsidiary name. | Banner on the record | A red banner displays on the registration page indicating failed registration. | Enter a different Subsidiary name and try again |
|  |  |  |  |
|  |  |  |  |
| Unable to create an account in Oracle Business Network. Please try again. | Banner on the record | A red banner displays on the registration page indicating failed registration due to network error. | Retry the registration. |
| There is no Email ID is available for this request. You can add the email in the corresponding employee record. | Banner on the record | A red banner displays on the registration page indicating there is no email id available. | Add email in corresponding employee record. |
| OBN Manager Selection Required. | Banner on the record | A red banner displays showing the OBN manager is not selected. | Select OBN Manager from the dropdown. |
| Errors in page are preventing you from being able to save. You might want to check the field in the corresponding subsidiary record and employee record | Banner on the record | A red banner displays due to multiple errors. | Enter country details in subsidiary record, and provide email id in employee record. |
