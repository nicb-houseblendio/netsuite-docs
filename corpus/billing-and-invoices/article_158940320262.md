Use SuiteFlow to set up and run a workflow for invoice group records. Any workflows that include the invoice group record appear under the System Information subtab on the invoice group record. You can't use SuiteFlow specifically to create an invoice group record.

#### To create an invoice groups workflow:

1.  Go to _Customization > Worfklow > Workflows > New_.
    
2.  From the **Record Type** field, select **Invoice Group**.
    
3.  Complete the following steps:
    
    Note:
    
    For detailed information about completing these steps, see [SuiteFlow (Workflow)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/book_N2723865.html).
    
    1.  Define basic information for your workflow.
        
    2.  Define initiation information for your workflow.
        
    3.  Define conditions for your workflow.
        
    4.  Create workflow states.
        
    5.  Create actions.
        
    6.  Create a transition.
        
    7.  Initiate and validate the workflow.
        
4.  Click **Save**.
