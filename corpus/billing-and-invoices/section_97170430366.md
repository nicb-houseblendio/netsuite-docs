The subscription line splitting event record lets administrators view the status of the bulk-splitting of subscription line items into multiple lines.

#### To view the subscription line splitting event record:

1.  Go to Customization > Lists, Records, & Fields > Record Types.
    
2.  Click **List** in the Subscription Line Splitting Event record line.
    
    A table is displayed with the following information:
    
    | Column | Description |
    | --- | --- |
    | Subscription | This column displays the subscription with line items that are split into multiple lines. |
    | Processing Status | This column displays the status of bulk-splitting subscription line items into multiple lines.
    -   **Pending** - The subscription line items are being prepared to be split into multiple lines.
    -   **In-Progress** - The bulk-splitting of subscription line items into multiple lines is ongoing.
    -   **Completed** - The bulk-splitting of subscription line items into multiple line is complete.
    
     |
    | Sales Order | This column displays the sales order number of the subscription with line items that have been split into multiple lines. |
