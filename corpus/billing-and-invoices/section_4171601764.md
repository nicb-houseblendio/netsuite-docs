This section shows you how to edit or add conditions, actions, transitions, and other components of the Invoice Approval Workflow. Most customization happens within the workflow states. To learn more about the states, [Invoice Approval Workflow States](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4171578435.html). For more information about workflow customization, see [Editing a Workflow](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4101529978.html). For more options on customization, see [Disabling Exception Criteria](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4171641243.html).

Note:

When you change the workflow components or reorder the sequence of actions, take note of any dependent conditions or triggers that might affect the process flow.

After creating your custom workflow, disable the original Invoice Approval Workflow if it's still running. To do this, set the release status to **Not Running**. When the original workflow is already disabled, you can run your custom workflow by setting its release status to **Released**. For instructions on running a workflow, see [Running the Invoice Approval Workflow](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4171556721.html#bridgehead_4171569863).

## Modifying a condition {#bridgehead_4171616743}

You can edit or add a condition for a workflow, group, action, and transition. On the workflow or state page, click the Edit link next to the component you want to customize. The specific component page contains the Condition section where you can edit or add a condition.

![screen shot of Workflow Action page with 'Next Approver is Not Empty' condition entered](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/OrderManagement/BillingInvoices/IAW_editcondition.png)

In the Condition section, you can use the Visual Builder or enter your own formula. To edit or add using the Visual Builder, click the Visual Builder icon located beside the **Condition** field. To use the formula, select the **Custom Formula** radio button. In the **Formula** field, enter a new formula or edit the existing one. For more information about adding and editing conditions, see [Working with Conditions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4103074843.html).

## Reordering an action {#bridgehead_4171619528}

Actions are listed within the state where they're executed. On the Workflow State page, drag and drop the action before or after another one.

![screen shot of Actions subtab showing a list of actions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/OrderManagement/BillingInvoices/IAW_reorderaction.png)

You can also reorder actions by editing the specific Action page. On the Workflow State page, click the Edit link for the action you want to reorder. On the Workflow Action page, in the **Insert Before** field, select the action that should run after the one to be transferred. For more information, see [Reordering Actions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4103058104.html).

On the Workflow State page, you can also add a new action to the state. Click the **New Action** button to start creating an action. For more information about workflow actions, see [Working with Actions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4103048460.html).

## Changing an exception message {#bridgehead_4171623957}

You can set up or change an existing exception message within the workflow state where its action runs.

#### To change an exception message:

1.  On the Workflow State page, click the Edit link for the NAW Create Exception Record WS action.
    
2.  On the Workflow Action page, in the Parameters section, enter the new message in the Value column for the exception field.
    
    ![screenshot of Workflow State window showing example states 'Set Field Value' and 'NAW Create Exception Record WS'](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/OrderManagement/BillingInvoices/IAW_changemessage.png)
3.  Click **Save**.
