This section lists the errors caused for Avalara processes and gives solutions on how to resolve the errors.

## Common Errors {#bridgehead_0315075039}

The following table lists the common error messages that appear when performing the Avalara processes:

| Message | Error on User Interface | Description | Solution |
| --- | --- | --- | --- |
| Request Failed | Banner on the record | A red banner displays indicating the request has been failed. | Try provisioning again after some time. |
| Address 1 Unavailable | Banner on the record | A red banner displays indicating the **Address** field is empty | Add Address 1 in the corresponding subsidiary record |
| City Unavailable | Banner on the record | A red banner displays indicating the **City** field is empty | Add City in the corresponding subsidiary record. |
| ZIP Unavailable | Banner on the record | A red banner displays indicating the **Zip** field is empty | Add ZIP in the corresponding subsidiary record. |
| Last Name Unavailable | Banner on the record | A red banner displays indicating the **Last Name** field is empty | Access the employee record to give last name value |
| Job Title Unavailable | Banner on the record | A red banner displays indicating the **Job Title** field is empty | Access the employee record to give Job title details |
| Avalara Manager Selection Required | Banner on the record | A red banner displays indicating the Avalara Manager is not selected | Select the Avalara manager from the list before clicking submit |
| To proceed with the provisioning, the registration of the parent company is a prerequisite. | Banner on the record | A blue banner displays indicating the registration of parent company did not happen with OBN | To complete the registration process for parent company, please visit the OBN Registration page (Setup > Electronic Business > OBN Registration) to register the Parent company as a trading partner in Oracle Business Network. |

## Provisioning Errors {#bridgehead_0315075610}

The following table lists the provisioning error messages that appear when performing the Avalara processes:

| Message | Error on User Interface | Description | Solution |
| --- | --- | --- | --- |
| Provisioning is required only for the parent company. As the parent company is registered as a trading partner at Oracle Business Network, the parent company will be able to proceed with the provisioning process. | Information banner on record | A blue banner displays about provisioning of parent company | Add required details for Provisioning of parent company |
| The Tenant account already generated successfully for the parent company. Check your email for Avalara Tenant account details along with instructions and a link to access the Avalara ELR portal. After completing the required steps, Company ID will be updated automatically in the Parent Company Subsidiary Record. | Information banner on Record | A blue banner displays about steps to be done in provisioning | Follow the instructions |

## Company Creation Errors {#bridgehead_0315075736}

The following table lists the common company creation error messages that appear when performing the Avalara processes:

| Message | Error on User Interface | Description | Solution |
| --- | --- | --- | --- |
| To initiate the company creation, register the parent company in Oracle Business Network. After the parent company is registered, you can proceed with the provisioning exclusively for the parent company. | Information banner on Record | A blue banner displays about company creation is done only after provisioning | Complete provisioning for parent company |
| To proceed with the Avalara company creation, initially set up the OBN registration for the parent company | Information banner on Record | A blue banner displays about company creation is done only after OBN registration | Complete OBN Registration for parent company followed by parent company provisioning and then do company creation. |

## Mandate Activation Errors {#bridgehead_0315075901}

The following table lists the mandate activation error messages that appear when performing the Avalara processes:

| Message | Error on User Interface | Description | Solution |
| --- | --- | --- | --- |
| To continue with the Avalara mandate activation, you must first set up the Avalara Provisioning for the parent company. | Information banner on Record | A blue banner displays about Mandate activation | User needs to complete provisioning for parent company |
| To proceed with the Avalara mandate activation, initially set up the OBN registration for the parent company | Information banner on Record | A blue banner displays about Mandate activation | User needs to do OBN Registration then perform parent company provisioning and should perform mandate activation |
