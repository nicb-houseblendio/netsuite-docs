Use the Subsidiary Setup List page to:

-   Start setup for a subsidiary.
    
-   Continue a setup in progress.
    
-   Search, filter, or sort subsidiaries with setup in progress.
    
-   Review the current setup status.
    
-   Open a subsidiary summary to review Oracle Business Network and Avalara information.
    

After all the subsidiaries are set up, the Avalara Setup page displays an Avalara Setup Complete message.
