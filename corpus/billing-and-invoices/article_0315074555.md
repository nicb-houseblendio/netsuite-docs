The Avalara manager must provide a NetSuite parent company to connect with Avalara.

#### To provision a parent company:

1.  Go to Setup > Electronic Business > Avalara Provisioning.
    
    The company details of the parent company which is registered with OBN will be displayed.
    
2.  On the Avalara Provisioning page, from the **Avalara Manger** list, select a user.
    
3.  Click **Submit**.
    

## Provisioning Completion in Avalara {#subsect_0320013113}

The user selected in the **Avalara Manager** list is registered as a NetSuite user for the provisioned company.

A Provisioning Pending status displays on the Avalara Provisioning page.

A successful tenant account registration message displays on the Avalara Provisioning page. The message also displays following information which is added to the OBN trading partner account of the parent subsidiary:

-   Tenant ID - ID of the tenant.
    
-   Organization ID - ID of the organization
    
-   User ID - ID of the user
    
-   Avalara Provisioning ID - ID of Avalara provisioning
    
-   Company ID - Blank - The company ID is updated after the Avalara provisioning is completed
    
-   Provisioning Status - Pending provisioning status displays.
    

If you are registered as the Avalara Manager, you'll get an email with your Avalara account details, next steps, and a link to the Avalara ELR portal.

After accessing the Avalara portal, generate the client ID and secret. If you have access to the OBN Manager role, manually add the client ID and secret in the OBN trading partner account. After completing these steps, the system automatically updates the company ID in the parent company subsidiary record and the Avalara provisioning is completed successfully. As you complete these steps, leave the Avalara portal and go back to NetSuite, the following updated information is available on the Avalara Provisioning page:

-   The generated Company ID
    
-   The Provisioning Status is updated to Successful
    

If the Avalara Manager and OBN Manager are different users, then the Avalara Manager must provide the generated client ID and secret to the OBN manager. Then, the OBN manager must manually add the client ID and secret in the OBN trading partner account to generate the Company ID.

Learn more about completing the Avalara provisioning in this SuiteAnswers article, [Adding Avalara Client Application API Credentials to OBN Accounts](https://suiteanswers.custhelp.com/app/answers/detail/a_id/1014964).
