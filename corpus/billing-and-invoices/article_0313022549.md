NetSuite Electronic Business (NSEB) SuiteApp provides the foundation for NetSuite users to configure and participate in global business networks like Oracle Business Network (OBN) and PEPPOL. The SuiteApp provides global electronic invoicing solutions for country mandates worldwide by partnering with Avalara.

Using the NSEB SuiteApp, you're able to do the following:

-   Enable NetSuite users to connect with potential customers or trading partners.
    
-   Enable NetSuite to integrate electronically with all member companies, both Oracle and external, on the Oracle Business Network.
    
-   Enable NetSuite accounts to issue invoices compliant with electronic invoice registration and control regulations in the supported countries.
    
-   Enable the participating NetSuite users to be linked to the PEPPOL network by partnering with Avalara, without the need to sign up for access points in each country. For more information, see [NetSuite Guide to Integrate with Avalara](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0313104928.html).
    

NetSuite accounts and subsidiaries must register as trading partners in the Oracle Business Network. For more information, see [NetSuite Guide to Integrate with OBN](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0314102955.html).

## NetSuite Electronic Business SuiteApp Availability and License Client {#bridgehead_90161155366}

The NetSuite Electronic Business SuiteApp can be installed for free in any NetSuite account from the marketplace.

The following table provides prerequisites to use features in NetSuite Electronic Business SuiteApp.

| Feature | Prerequisite |
| --- | --- |
| OBN Registration | No license required. |
| Avalara Provisioning | 
-   Install the NetSuite SuiteApps License Client. (Bundle ID: 116144)

 |
| Avalara Company Creation | 

-   Install the NetSuite SuiteApps License Client. (Bundle ID: 116144)
-   Purchase the required licenses like NetSuite Electronic Business Network Extension and NetSuite Electronic Document Processing Cloud Service.

 |
| Avalara Mandate Activation | 

-   Install the NetSuite SuiteApps License Client. (Bundle ID: 116144)
-   Purchase the required licenses like NetSuite Electronic Business Network Extension and NetSuite Electronic Document Processing Cloud Service.

 |

If you have active licenses, you're able to use the licensed features. However, you cannot use them if:

-   NetSuite SuiteApps License Client is not installed, or
    
-   NetSuite SuiteApps License Client is installed but your license is expired.
    

Information:

The NetSuite SuiteApps License Client allows your NetSuite account to access features in NetSuite Electronic Business SuiteApp. Upon installation, the SuiteApp communicates with the NetSuite SuiteApps License Server to obtain active licenses information.

Note:

You must do the OBN Registration and Avalara Provisioning in the production and then perform the linking in sandbox.
