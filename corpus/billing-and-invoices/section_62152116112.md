## Required Features {#bridgehead_0723061050}

Before installing Fulfillable Items with SuiteBilling SuiteApp, enable the following required features. For more information, see [Enabling Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N232138.html).

| Subtab | Feature |
| --- | --- |
| Accounting | Accounting |
| Transactions | Subscription Billing |
| Charge-based Billing |
| Add-on Items |
| Pick, Pack, and Ship |
| Items & Inventory | Inventory |
| Lot Tracking |
| CRM | Customer Relationship Management |
| SuiteCloud | Custom Records |
| Advanced PDF/HTML Templates |
| Server SuiteScript |

## Required Module {#bridgehead_0723061110}

Fulfillable Items with SuiteBilling SuiteApp requires the Advanced Inventory Module. Contact your account manager for details.
