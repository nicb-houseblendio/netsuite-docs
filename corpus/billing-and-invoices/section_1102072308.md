The supported item types for the CTT: Purchase Outbound Template are:

-   Inventory items (lot numbered, serialized, inventory)
    
-   Non-inventory items (for purchase, for resale)
    
-   Discount
    
-   Markup
    
-   Service (for purchase, for resale)
    
-   Expense
    
-   Other charges (for purchase, for resale)
    

This template does not support few elements which are mentioned in the CTT: Purchase Template mappings table.

The below points must be followed when creating a CTT: Purchase Outbound Template.

-   To use the CTT: Purchase Outbound Template, paste the XML in the **Template for Outbound E-Documents** field of the new E-Document Template page.
    
-   When creating the template, select **CTT Purchase Outbound CDS** from the **Custom Data Source Plugin Implementation** list.
    

Important:

You must provide the PEPPOL ID field as part of CTT: Sales PEPPOL template setup in SuiteTax.

To know more about PEPPOL ID field, see [PEPPOL ID](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1116115058.html#bridgehead_60184912676).

Limitation- Shipping charges are not supported for CTT: Purchase.
