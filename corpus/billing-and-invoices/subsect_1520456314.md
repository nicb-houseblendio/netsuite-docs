## Default Permissions for Subscription Records {#subsect_157663543228}

By default, you have permission to view subscription records. Create and Edit are optional permission levels. Roles with full permission can perform these actions:

-   View
    
-   Create
    
-   Edit
    
-   Delete
    

All roles can view or edit these records:

-   Price book
    
-   Price plan
    
-   Subscription change order
    

Customized roles keep their existing permissions for subscriptions and subscription plans when new permissions are given.

System Administrators can grant full permissions to subscription records. Only System Administrators can set up custom records and templates for SuiteBilling subscription processes and grant access to them. For instructions on granting permissions to subscription processes, see [Setting Permissions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N288727.html).
