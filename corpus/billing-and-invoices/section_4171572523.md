You can modify the Invoice Approval Workflow by enabling only the features that suit your specific business requirements. You can choose which exception criteria to use in your custom workflow, reorder the sequence of actions, and add more components to the workflow.

When planning your customization, review the states and exception criteria in these topics:

-   [Invoice Approval Workflow States](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4171578435.html)
    
-   [Invoice Approval Workflow Exception Criteria](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4171586942.html)
    

To start the customization, you need to create a copy of the workflow. On the workflow page, point to the More link and then click Make Copy. The default workflow states, actions, and other components are copied to your custom workflow. The exception criteria and fields appear in their default settings. For more information, see the topic [Copying a Workflow](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4103046853.html). For instructions on customization, see the following topics:

-   [Creating a Custom Invoice Approval Workflow](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4171601764.html)
    
-   [Disabling Exception Criteria](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4171641243.html)
    

After completing your customization, you need to run the workflow. For instructions on running the workflow, see [Running the Invoice Approval Workflow](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4171556721.html#bridgehead_4171569863).
