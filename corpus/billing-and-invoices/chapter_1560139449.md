This topic has details about SuiteBilling features provided by two SuiteApps:

-   [Subscription Billing Enhanced UI](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1552954533.html) - This SuiteApp provides an enhanced user interface for Subscription Billing records.
    
-   [SuiteBilling Enhancements](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1534294364.html) - This SuiteApp enables you to:
    
    -   create usage records using a RESTlet
        
    -   perform subscription billing bulk operations, and
        
    -   process bulk customer payments
