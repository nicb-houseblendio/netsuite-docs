The following diagram illustrates the flow for using Fulfillable Items with SuiteBilling SuiteApp.

![Fulfillable Items with SuiteBilling Process Flow](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/OrderManagement/BillingInvoices/FulfillableItemsSuiteBillingSuiteApp_Diagram.png)

Refer to the following table for more information about each of the processes in Fulfillable Items with SuiteBilling SuiteApp.

| Process | Description | Help Topic |
| --- | --- | --- |
| (Optional) Link fulfillable item to a subscription item | You can optionally link a fulfillable item to a subscription item when creating the fulfillable item record. You can do this step to display the subscription item as a counterpart of the fulfillable item when creating a sales order. | [(Optional) Linking a Fulfillable Item to a Subscription Item](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_51145124314.html) |
| Create additional item information fields in transaction records | To enter additional item information for fulfillable items, you must first create the fields where you can enter the additional item information. Create additional item information fields for the following records:
-   Sales order
-   Item fulfillment
-   Item receipt
-   Subscription
-   Invoice

 | 

-   [Additional Item Information for Fulfillable Items](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_40142258985.html)
-   [Creating Additional Item Information Fields in Sale and Subscription Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1192811255.html)

 |
| Set item field mappings | You must set item field mappings so that the additional item information fields in item fulfillment and item receipt records are mapped and linked to their related subscription and invoices. | [Setting Item Field Mappings](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_56163451492.html) |
| Create sales order | Create a sales order through the sales order form in NetSuite or through CSV import. In the sales order, do the following:

-   Check the **Split Subscription Line Items Into Multiple Lines** box. When subscription line items are split, you can enter unique additional item information for each of the fulfillable items in the item fulfillment record. If the quantity of the subscription items is 50 or more, a map/reduce script splits the subscription line items into multiple lines in bulk. Split subscription line items also makes it easier to handle partial fulfillment, activation, and returns.
-   Link fulfillable items to a subscription for the fulfillable item to be included in its associated subscription record.

 | 

-   [Linking a Fulfillable Item to a Subscription](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_49192434292.html)
-   [Best Practices When Creating a Sales Order for use with Fulfillable Items with SuiteBilling](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_67154943586.html)
-   [Fulfillable Items with SuiteBilling Support for CSV Import](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_90160916104.html)

 |
| Create an item fulfillment record | Create an item fulfillment record to track the shipment of fulfillable items to the customer. You can then enter additional item information such as brand, product key, or serial number in the item fulfillment record. The additional item information you enter ensures that the fulfillable items delivered are properly identified, tracked, and reflected in the subscription. For the additional item information to be reflected in the associated subscription, the fulfillable items must be marked as shipped in the item fulfillment record. | 

-   [Entering Additional Item Information in an Item Fulfillment Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_51193402706.html)
-   [Additional Item Information in the Subscription](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1154744009.html)

 |
| Set subscription activation reminders | You can set subscription activation reminders by setting up a reminder in the Reminders portlet of the dashboard or by setting up email reminders. | 

-   [Setting Dashboard Reminders for Subscriptions Pending Activation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_84154808375.html)
-   [Setting up a Subscription Activation Email Reminder](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_46175358269.html)

 |
| Activate subscription | You must activate the subscription after fulfillable items are delivered to customers. When a subscription is activated, you can then initiate billing through the Process Billing Operations tool. When the subscription that includes the fulfillable items is billed, an invoice is generated containing the additional item information entered for fulfillable items. You have the option to merge same items with the same rates and subscription when you print the invoice. Additional item information entered for fulfillable items are also merged in the printed invoice if they are the same. | 

-   [Activating a Subscription](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1547759628.html)
-   [Billing Operations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4063198073.html)
-   [Merging Same Items in the Printed Invoice](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_32171121257.html)

 |
| Return fulfillable items | Defective or faulty fulfillable items delivered that are part of a subscription can be returned replaced and the associated subscription is accordingly updated by the SuiteApp at each transaction record update. | [Returning and Replacing Fulfillable Items](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_40150958866.html) |
