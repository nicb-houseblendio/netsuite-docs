Read the following steps to understand how to install and get started with the Electronic Invoicing SuiteApp.

1.  Install Electronic Invoicing SuiteApp-
    
    You must install the Electronic Invoicing SuiteApp from the Suite Bundler. Make sure you have the prerequisites set for using the Electronic Invoicing. For more information about the same, see [https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section\_4592549826.html#bridgehead\_4580987033](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4592549826.html#bridgehead_4580987033)
    
2.  Install License Client-
    
    The NetSuite SuiteApps License Client (Bundle ID: 116144) must be installed before you install the Electronic Invoicing SuiteApp (Bundle ID: 436209). To install, see [https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section\_N3395142.html](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3395142.html)
    
    If you don't have the license, define the Free Country at the Subsidiary level.
    
3.  Define the Template-
    
    Create an e-document template. Both outbound and inbound e-document templates can be created on the E-Document Templates record. For more information about the same, see [https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section\_4536871429.html#Related-Topics](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4536871429.html#Related-Topics)
    
4.  Define the Sending Methods-
    
    Create an e-document sending method for selection on the transaction record and the e-document package record. See, [https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section\_4536875049.html](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4536875049.html) for more information.
    
5.  Define the Package-
    
    A package defines a set of formats used for various transactions. See, [https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section\_4593256917.html#Related-Topics](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4593256917.html#Related-Topics) for more information about understanding e-document packages.
    
6.  Install Localization SuiteApp-
    
    You may have a dedicated localization SuiteApp depending on the country you choose which will cover steps 3,4,5 automatically. The list of available localization SuiteApps are as follows:
    
    -   Malaysia Electronic Invoicing
        
    -   Israel Electronic Invoicing
        
    -   Mexico Localization
        
    -   India Localization
        
    -   Brazil Localization
        
7.  Configure Customer/ Vendor records-
    
    You must follow the below steps to configure customer/ vendor records for assigning e-document packages:
    
    1.  Assign the package to the customer or the vendor-
        
        For more information about this step, see [https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section\_4592483798.html](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4592483798.html)
        
    2.  Define E-document email recipient-
        
        If you are using an email sending method, you must define the e-document email recipients. For more information about the same, see [https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section\_4592483197.html](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4592483197.html)
        
    3.  Set the Auto-population
        
8.  Configure Electronic Invoicing Preferences-
    
    The EI preferences are account level and applicable to all subsidiaries. You must configure these preferences for performing further steps. See, [https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section\_0619104200.html#bridgehead\_33225319345](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0619104200.html#bridgehead_33225319345) for more information about the same.
    
9.  Give permissions to custom role-
    
    If you are using custom roles for daily usage, you are required to give required electronic invoicing permissions to the custom roles. See, [https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section\_4615883600.html#Related-Topics](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4615883600.html#Related-Topics) and [https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section\_1526454388.html#To-restrict-the-permission-of-standard-and-custom-roles-to-generate-and-send-outbound-e-documents%3A](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1526454388.html#To-restrict-the-permission-of-standard-and-custom-roles-to-generate-and-send-outbound-e-documents%3A) for more information about the same.
    
10.  Configure Map/Reduce-
     
     If you want scheduled generation or sending, configure the Map/Reduce script for automatic scheduled sending of outbound e-documents. For more information about the steps for configuration, see [https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section\_1495611216.html#To-deploy-the-script-for-scheduled-sending-of-e-documents%3A](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1495611216.html#To-deploy-the-script-for-scheduled-sending-of-e-documents%3A)
