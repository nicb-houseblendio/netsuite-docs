Item field mappings allow you to map additional item information fields in item fulfillment records so they are linked to their related subscription and invoices. You can also set other preferences for additional item information fields when you set item field mappings. For more information about additional item information fields, see [Additional Item Information for Fulfillable Items](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_40142258985.html).

Only Administrators can set item field mappings.

#### To set item field mappings:

1.  Go to Setup > Fulfillable Items with SuiteBilling > Item Field Mappings > New.
    
2.  In the **Name** field, enter a descriptive name for the field mapping.
    
3.  (Optional) Check the **Inactive** box to make the record inactive.
    
    Only do this step if you do not want to use the item field mapping.
    
4.  In the **Subsidiary** field, select one or more subsidiaries where to apply the item field mappings.
    
    Note:
    
    You can only create one item field mapping per subsidiary.
    
    For non-OneWorld accounts, the **Subsidiary** field is not available and only one item field mapping can be created.
    
5.  Fill out the following columns in the Item Field Mappings page.
    
    | Column Name | Description |
    | --- | --- |
    | **Field Mapping Name** | Enter a name for the field mapping. For example, enter **Product Key** here if you created an additional item information field named Product Key. For more information, see [Creating Additional Item Information Fields in Sale and Subscription Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1192811255.html). The **Serial Numbers** field mapping is present by default and is automatically checked as a field identifier. This field mapping supports native serialized inventory items and the system assigns the serial numbers. You can choose to delete this item field mapping. If you want to use this default **Serial Numbers** item field mapping, all columns for this mapping must have values. |
    | **Field Identifier** | Check this box for the field mapping that you want to set as a field identifier. A field identifier lets you identify a fulfillable item through the unique additional item information entered for the item such as its serial number. You must select a field mapping that can contain unique values and set it as a field identifier, such as the fulfillable item's serial number or product key. Field identifiers let you quickly identify fulfillable items and is useful such as in the case of returns. You must select at least one and a maximum of two field mappings as field identifiers. Note: Changing the field identifier after the item field mappings have been saved may affect the update of related subscriptions when there are returns. Be sure to select the correct field mappings as field identifiers when setting item field mappings for the first time. |
    | **Item Fulfillment Line Field ID** | Enter the script ID of the additional item information field that you created in the item fulfillment record. For more information about creating additional item information fields in an item fulfillment record, see [Creating Additional Item Information Fields in Sale and Subscription Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1192811255.html). |
    | **Distribute Values to Subscription Lines** | Check this box to distribute comma-delimited additional item information entered for fulfillable items in the item fulfillment or item receipt record into individual subscription lines in the subscription record. Note: This feature only applies if the quantity of the fulfillable item is greater than one and if the **Split Linked Subscription Items Into Multiple Lines** box in the associated sales order is checked. |
    | **Subscription Line Field ID** | Enter the script ID of the additional item information field that you created in the subscription record. For more information about creating additional item information fields in a subscription record, see [Creating Additional Item Information Fields in Sale and Subscription Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1192811255.html). |
    | **Invoice Line Field ID** | Enter the script ID of the additional item information field that you created in the invoice record. For more information about creating additional item information fields in an invoice record, see [Creating Additional Item Information Fields in Sale and Subscription Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1192811255.html). |
    | **Include in Printed Invoice** | Check this box to include additional item information fields in the printed invoice. You must check this box if you want to merge same items in the printed invoice. For more information, see [Setting the Preference to Merge Same Items in the Printed Invoice](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_32171121257.html#subsect_55154048726). |
    
6.  Click **Save**.
