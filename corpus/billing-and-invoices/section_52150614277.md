There are no custom roles included with the Fulfillable Items with SuiteBilling SuiteApp. An administrator must customize standard roles and set the permissions for those roles.

#### To set permissions for Fulfillable Items with SuiteBilling:

1.  Go to Setup > Users/Roles > Manage Roles.
    
2.  Click **Customize** beside the role and set permissions for the role.
    
    For a role to execute the entire process flow for using this SuiteApp, you must customize a role to have the following minimum permissions.
    
    | Subtab | Permission | Permission Level | Purpose |
    | --- | --- | --- | --- |
    | Transactions | Sales Order | Edit | To enter and approve sales orders. |
    | Sales Order Approval | Edit |
    | Item Fulfillment | Edit | To create item fulfillment records and enter additional item information for fulfillable items. |
    | Fulfill Orders | Edit |
    | Return Authorization | Edit | To facilitate the return and replacement of fulfillable items. |
    | Return Auth. Approval | Edit |
    | Receive Returns | Edit |
    | Item Receipt | Edit |
    | Charge | View | To view charges. |
    | Find Transaction | View | To validate items in an item fulfillment record. |
    | Lists | Items | View | To view items. |
    | Subscription Change Orders | Edit | To activate or modify the status of a subscription. |
    | Subscriptions | Edit | To create a subscription. |
    | Subscription Plan | Edit | To create a subscription plan. |
    | Price Plan | Edit |
    | Price Book | Edit |
    | Custom Record Entries | View | To view the subscription line splitting event record. |
    | Perform Search | View | To execute the saved search that displays subscriptions that are pending activation. |
    | Setup | Import CSV File | Full | To create a sales order through CSV. |
    | Control SuiteScript and Workflow Triggers per CSV Import | Full |
    | Custom Record Types | View | To view the SuiteApp's custom records. |
    | Custom Record | FIS Item Lines Data Map | View | To access the SuiteApp's custom records. |
    | Item Field Mappings | View |
    | Subscription Line Splitting Event | View |
    
3.  Click **Save**.
