Only the OBN Manager role can authorize NetSuite accounts and add subsidiaries on the OBN Registration page.

Important:

The OBN Manager must be authorized on behalf of the organization to accept the terms and conditions in the OBN portal. The OBN Manager can then proceed with OBN registration. For more information, see [Connecting a NetSuite Account with OBN](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0315115701.html#subsect_0315101957).

After the registration, the OBN manager receives an email with user name and password required to access the OBN application. After accessing the OBN application with the user credentials, the manager is responsible for the document exchange process.

The following table lists the roles and permissions granted to perform the required OBN processes:

| Process | Role Access | Permissions |
| --- | --- | --- |
| Authorize connection between NetSuite and OBN | OBN Manager | By default, only the OBN manager has the permission to authorize NetSuite accounts. |
| Register parent company or subsidiary as trading partners on OBN | OBN Manager | By default, only the OBN manager has the permission to register the parent company and subsidiaries. |
| Login to OBN page | OBN Manager | The OBN manager receives the user name and password to access the OBN application. |

Note:

Don't delete or deactivate the OBN Manager role. If the current OBN Manager role is deactivated, another user with access to the role should take over the responsibilities.
