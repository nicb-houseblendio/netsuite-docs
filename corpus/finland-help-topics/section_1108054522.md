The International Tax Reports SuiteApp provides a localized Intrastat Dispatches and Arrivals reports for NetSuite accounts with a Finland nexus. For more information about generating the Intrastat report for businesses based in Finland, see .

The information displayed on the Intrastat Dispatches and Arrivals reports are based on your transaction and item records in NetSuite. To know more about the Intrastat Report fields, see [Finland Intrastat Report Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1108050955.html).

The following table lists the information that appear on the generated Intrastat Dispatches and Arrivals report for Finland.

| Intrastat Dispatches (Sales) Report | Intrastat Arrivals (Purchases) Report |
| --- | --- |
| Line Number | Line Number |
| Trading Partner | Supplier VAT Number |
| Commodity Code | Member State |
| Country of Destination | Commodity Code |
| Country of Origin | Country of Origin (Import) |
| Nature of Transaction Code | Nature of Transaction |
| Mode of Transport | Mode of Transport |
| Net Mass (kg) | Net Mass (kg) |
| Supplementary Unit | Supplementary Unit |
| Invoice Value | Invoice Value |
| Statistical Value | Statistical Value |
| Reference Number |  |

For more details about the Intrastat Report field descriptions, see [Intrastat Reporting Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4150707116.html).

You can also customize an Intrastat report. You can access these custom reports from Reports > Saved Reports.

-   Intrastat Purchases Report \[Custom\]
    
-   Intrastat Sales Report \[Custom\]
    

For information about customizing a report, see [Report Customization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N736328.html).
