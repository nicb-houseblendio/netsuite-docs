Important:

This content is about Finland tax reports for accounts with SuiteTax. For content relevant for accounts without SuiteTax, see [Finland Help Topics](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_157849439820.html).

Tax codes determine how much tax is paid on each transaction line item. In accounts with SuiteTax, Finland tax codes are automatically mapped to NetSuite tax codes.

Renaming or otherwise editing a tax code will render the tax code unsupported. Any transaction with an unsupported tax code will be excluded from Finland VAT Return report.

#### To view tax code properties:

1.  Go to Setup>Tax>Tax Codes
    
2.  Click **+** in the **Filters** tab.
    
3.  In the **Country** list, select **Finland**.
    
4.  Click **View** next to the tax code you want to inspect.
    

## Finland Tax Codes (accounts with SuiteTax) {#bridgehead_052305190710}

The following tax codes are provisioned and supported for use with Finland VAT Return:

Important:

Effective from 1 September 2024, the standard tax rate in Finland increased from 24% to 25.5%.

The Finland VAT Return calculates VAT with the 24% standard tax rate for the data up until 31 August 2024. As of 1 September 2024 the 25.5% standard tax rate is applied.

This change is reflected in the updated label of the standard tax return in the first row of the VAT Return report.
