The Intrastat Report gets the following information from the **Tax Reporting** subtab and **Items** sublist of transaction forms and item records:

-   Commodity Code
    
-   Supplementary Unit
    
-   Nature of Transaction Code
    
-   Country of Origin
    
-   Partner ID
    
-   Delivery Terms
    
-   Mode of Transport
    
-   Statistical Value
    

You must fill in these fields to generate a fulfilled Intrastat Dispatches and Arrivals reports.

## Finland Intrastat Report Fields on Transaction Forms {#subsect_32171417220}

The **Tax Reporting** subtab on transaction forms only appears if you're transacting with an EU vendor or EU customer.

This subtab contains the following fields which are used for Intrastat reporting:

-   **Delivery Terms** - Refers to international commercial terms (Incoterms) defined by the International Chamber of Commerce (ICC). For more information, see [Delivery Terms](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2071234.html).
    
-   **Nature of Transaction Code** - Type of transaction in the Intrastat declaration. For more information, see [Nature of Transaction Code](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2070738.html).
    
-   **Mode of Transport** - This indicates the active vehicle that moves goods for every arrival or dispatch transaction. For more information, see [Mode of Transport](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1505110665.html).
    
-   **Country of Origin** - Country where the goods were harvested, manufactured, or substantially changed. For more information, see [Country of Origin](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164377962805.html).
    
-   **Partner ID** - This refers to the VAT number of the party receiving the goods in the EU member state of destination. For more information, see [Partner ID](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164377982356.html).
    
-   **Statistical Value** - Value of goods without value-added tax crossing the free German border. For more information, see [Statistical Value](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164377925900.html).
    
    Note:
    
    The Statistical Value field is only available in the Items sublist on the transaction form and not on the **Tax Reporting** subtab.
    
    If the amount in the **Statistical Value** field is zero or blank, then the report will display the amount from the Invoice Value field.
    

For more information about EU Intrastat Report Fields on transaction forms, see [Intrastat Reporting Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4150707116.html).

## Finland Intrastat Report Fields on Item Records {#subsect_69173459060}

The Tax Reporting subtab on item records contains the following fields:

-   **Commodity Code** - The 8-digit number that identifies the type of goods or commodity on the item record. For more information, see [Commodity Code](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2070438.html).
    
-   **Supplementary Unit** - Unit used in measuring the quantity of goods or commodity on the item record. For more information, see [Supplementary Unit](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4605983594.html).
    

For more information about EU Intrastat Report Fields on item records, see [Intrastat Reporting Fields on Item Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4150707116.html#bridgehead_4150717128).
