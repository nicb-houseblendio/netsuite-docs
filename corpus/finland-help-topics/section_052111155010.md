Each Finland VAT Return report is generated with a unique VAT Return Number to help the Finland Tax Administration to identify it among other reports of the same type. The number is automatically created upon generation and included in the output file.

The report name consists of the subsidiary name, report type, reporting period, and a time stamp of the report's generation divided by an underscore (\_).

## Finland VAT Return

Finland VAT Return generated for subsidiary Finland VAT for September 2023 on May 21 2024 will have a name "Finland VAT\_Finland VAT Return\_Sep 2023\_052124020103".
