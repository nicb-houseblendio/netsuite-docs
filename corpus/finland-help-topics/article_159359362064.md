Posting of inventory value through P&L (Profit and Loss) required by Finnish GAAP (Generally accepted accounting principles). This feature supports the following transaction types:

-   Item Receipt
    
-   Bill
    
-   Vendor Return Shipment (Item Fulfillment)
    
-   Work Order Completion
    
-   Work Order Issue
