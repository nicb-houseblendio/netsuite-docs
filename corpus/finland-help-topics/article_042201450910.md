Important:

This content is about Finland tax reports for accounts with SuiteTax. For content relevant for accounts without SuiteTax, see [Finland Help Topics](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_157849439820.html).

Finland Tax Reports SuiteApp enables you to configure, generate, and export tax reports required by the Finnish Tax Administration (Vero Skatt) from businesses with subsidiaries in Finland.

Finland Tax Reports is a shared SuiteApp. Contact Customer Support Services for permission to install it from the SuiteApp Marketplace.

Finland Tax Reports SuiteApp contains the following reports:

| Name | Description |
| --- | --- |
| Finland VAT Return | Finland VAT Return country tax report allows you to configure, generate, and export the VAT return report for submission to Finnish Tax Administration. For more information, see [Finland VAT Return](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_042201461110.html) |

Finland VAT Return SuiteApp is available for accounts with SuiteTax. For more information about SuiteTax, see [SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/preface_1496364245.html).
