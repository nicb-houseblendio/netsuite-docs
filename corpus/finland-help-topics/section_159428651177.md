Before installing this SuiteApp, you must ensure that the following prerequisites are met:

## Licenses {#bridgehead_159359268158}

The following steps describe how to obtain a license for the Finland Localization SuiteApp.

#### To access the features of the Finland Localization SuiteApp:

1.  Install the NetSuite SuiteApps License Client (Bundle ID 116144).
    
2.  Obtain a license for the Finland Localization SuiteApp. To do this, contact your account manager who will arrange for a license to be generated.
    
3.  Verify that the NetSuite SuiteApps License Client has the license 'NetSuite Finland Localization' active.
    

If the license client isn't installed or your license expires, you won't be able to use the features of the SuiteApp. For more information, see the [NetSuite SuiteApps License Client Guide for Administrators](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4635371677.html). Contact your account representative to reinstate any stale licenses.

## Features {#bridgehead_159359269022}

Before installing the Finland Localization SuiteApp, you must ensure the following features have been enabled.

#### To enable required features for Finland Localization SuiteApp:

1.  Go to Setup > Company > Enable Features.
    
2.  On the **CRM** subtab, enable Customer Relationship Management.
    
3.  On the **SuiteCloud** subtab, enable following features:
    
    -   Custom Records
        
    -   Advanced HTML/PDF Templates
        
    -   Client SuiteScript
        
    -   Server SuiteScript
        
    -   SuiteFlow
        

For more information, see [Enabling Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N232138.html).

## SuiteApps {#bridgehead_159359273362}

Before installing the Finland Localization SuiteApp, the following SuiteApps must be installed:

-   [Electronic Bank Payments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N1585433.html)
    
-   [NetSuite SuiteApps License Client](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4635371374.html)
    
-   [International Tax Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2051341.html)
    
    Note:
    
    This SuiteApp is not required. Localization SuiteApps supplement International Tax Reports SuiteApp by providing more enhanced features for VAT. You can use VAT in NetSuite only after installing this SuiteApp.
    
    If your NetSuite account is using SuiteTax, don't install International Tax Reports. If it's already installed, you must uninstall it to enable SuiteTax.
    
    You may need to install the following SuiteTax bundle if not installed:
    
    -   SuiteTax Engine - 237702
