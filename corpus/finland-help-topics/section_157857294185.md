In NetSuite, users can define their personal preferences. NetSuite can also be localized based on the specific country requirements and preferences.

Note:

Make sure that your NetSuite role has the appropriate permissions to set up company preferences specific to Finland.

To set personal preferences tailored for users using NetSuite in Finland, follow the procedure:

#### To adjust NetSuite company settings:

1.  Go to _Setup > Company > Setup Tasks > States/Provincies/Counties_, and add the following cantons, if required:
    
    -   Turku and Pori (Turun ja Porin lääni)
        
    -   Nyland and Tavastehus (Uudenmaan ja Hämeen lääni)
        
    -   Ostrobothnia (Pohjanmaan lääni)
        
    -   Viborg and Nyslott (Viipurin ja Savonlinnan lääni)
        
    -   Kexholm (Käkisalmen lääni)
        
    -   Kymmenegård and Nyslott (Savonlinnan ja Kymenkartanon lääni)
        
    -   Savolax and Kymmenegård (Kymenkartanon ja Savon lääni)
        
    -   Vaasa (Vaasan lääni)
        
    -   Oulu (Oulun lääni)
        
    -   Kymmenegård (Kymenkartanon lääni)
        
    -   Savolax and Karelia (Savon ja Karjalan lääni)
        
    -   Viipuri (Viipurin lääni)
        
    -   Uusimaa (Uudenmaan lääni)
        
    -   Häme (Hämeen lääni)
        
    -   Mikkeli (Mikkelin lääni)
        
    -   Kuopio (Kuopion lääni)
        
    -   Åland (Ahvenanmaan lääni)
        
    -   Petsamo (Petsamon lääni)
        
    -   Lapland (Lapin lääni)
        
    -   Kymi (Kymen lääni)
        
    -   Central Finland (Keski-Suomen lääni)
        
    -   North Karelia (Pohjois-Karjalan lääni)
        
    -   Southern Finland (Etelä-Suomen lääni)
        
    -   Western Finland (Länsi-Suomen lääni)
        
    -   Eastern Finland (Itä-Suomen lääni)
        
2.  Go to _Setup > Company > General Preferences_:
    
    -   In the **Date Format** fields specify the date format (DD/MM/YYYY) and long date format (DD Month YYYY).
        
    -   Specify the number format.
        
    -   On the **Languages** subtab, select the languages to which you want to translate information that appears on your website or printed transactions. English and Finnish are available but other languages can be added if you want to translate sales documents or your website in foreign language. For more information, see [Configuring Multiple Languages](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N247147.html).
        
    -   If your group (main) chart of accounts isn't the statutory Finland CoA (Chart of Accounts), create an accounting context (for example called Finland) which would allow mapping to the Finland account numbers. For more information on this functionality, see [Accounting Context](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4739558119.html).
        
    -   For more information on localizing preferences in NetSuite, see [General Personal Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N475661.html).
        
    -   Click **Save**.
        
3.  Go to _Setup > Company > Setup Tasks > Company Information_:
    
    -   Set the currency for Finland (this would be the currency of the top parent subsidiary if you have multiple subsidiaries)
        
    -   Set the VAT registration number for the parent subsidiary
        
    -   Specify the appropriate time zone: (GMT+01:00) Brussels, Copenhagen, Madrid, Paris
        
4.  Click **Save**.
    

#### To adjust NetSuite subsidiary settings:

1.  Go to _Setup > Company > Subsidiaries_.
    
2.  Create a subsidiary record for each of your legal entities. For more information, see [Creating Subsidiary Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N272471.html).
    
3.  On the Subsidiary page define the following preferences:
    
    -   Fill in the **VAT registration number** field (if you use accounts without SuiteTax)
        
    -   Check the **GL Impact Locking** box to enable this feature on the subsidiary. (This option is visible in NetSuite OneWorld and only when the GL Audit Numbering feature is enabled. When you use GL Impact Locking for a company or a subsidiary, any change to a general ledger impacted field or entity field on a transaction with a GL audit number assigned, automatically generates copy and reversal transactions. These transactions display on the **GL Impact** subtab on the edited transaction.)
        
4.  Under the **Preferences** subtab, in the **General** subtab:
    
    -   In the **Date Format** fields specify the date and long date format: typically DD/MM/YYYY and DD MM YYYY
        
    -   Specify the number format
        
    -   Specify the appropriate time zone: (GMT +01:00) Brussels, Copenhagen, Madrid, Paris
        
5.  Under the **Preferences** subtab, in the **CSV** subtab:
    
    -   Select the delimiter in the **CSV column delimiter** and the **CSV decimal delimiter** fields.
        
6.  Go to _Setup > Company > Setup Tasks > Enable Features_.
    
7.  In the **Accounting** subtab, go to **Advanced Features** subtab and check the **Period End Journal Entries** box. Additional settings for this feature can be defined in the Subsidiary Settings Manager. The Period End Journals Entries processes and posts subsidiary consolidation and income statement closing using a transaction type called Period End Journal. Period End Journals are generated automatically when you complete the Create Period End Journals task on the Period Close Checklist.
    

Note:

If you have subsidiaries in different countries with different format settings, you can select language preferences for each subsidiary. Go to _Setup > Company > General Preferences_ and select the language in **Languages** subtab. For setting up multiple languages, see [Configuring Multiple Languages](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N247147.html).

## Adjusting NetSuite User Preferences {#bridgehead_157858067690}

The best practice is to define these settings at company or subsidiary level. The users inherit the settings from the subsidiary they're linked to. However, preferences can also be defined at user level. The personal preferences you set normally take precedence over the other preferences set for a role, subsidiary, or company. Refer to [Setting Personal Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N475297.html) to find out more.

#### To set personal preference for users in Finland:

1.  Go to _Home > Set Preferences_.
    
2.  Go to the **General** subtab:
    
    -   In the **Localization** subtab, you can set up language and time preferences.
        
    -   In the **Formatting** subtab, you can set up date and time formats.
        
3.  Click **Save**.
