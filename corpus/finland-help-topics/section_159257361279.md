The following reports with the corresponding report layout templates are available in the Finland Localization SuiteApp:

| Report Name | Layout Name |
| --- | --- |
| Finnish Balance Sheet (ENG) | Finnish Balance Sheet Template ENG |
| Finnish Balance Sheet (FI) | Finnish Balance Sheet Template FI |
| Finnish Income Statement (ENG) | Finnish Income Statement Template ENG |
| Finnish Income Statement (FI) | Finnish Income Statement Template FI |

## Financial Reports: Row Layout Assignment Page {#subsect_159257363890}

The **Financial Reports: Row Layout Assignment** page lists financial statements and layouts, indicating the layout assigned to each financial statement. To display this page, go to Reports > Financial > Financial Row Layouts and click **View Assignments** in the last column on a layout record.

You can change a layout assigned to either a customer or standard financial statement by clicking the **Edit** button, clicking directly on a layout in the Row Layout column, and selecting a different layout.

Important:

You must ensure the reports available in the Finland Localization SuiteApp are linked to their respective report layouts, as depicted in the summary table above.

You can filter this page to display only a selected financial statement type, a selected layout, or if you are using NetSuite OneWorld, a selected subsidiary:

-   To display assignments for a specific type of financial statement, select that statement from the **Report Type** list. To display assignments for all types of statements, select **All**.
    
-   To display assignments for a specific layout, select that layout from the **Row Layout** list. To display assignments for all layouts, select **All**.
    
-   To display assignments for layouts relevant to a specific subsidiary, select that subsidiary from the **Subsidiary Context** list. To display assignments for layouts relevant to all subsidiaries, select **All**.
    

## Mapping Accounts to Report Headings {#subsect_158997434986}

To set up the reports, first map the chart of accounts to report headings (this can be done using Excel). To export to Excel, open the report and export to the XML format selecting the bottom right icon.
