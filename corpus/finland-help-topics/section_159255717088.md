With the Finland Localization SuiteApp, you can create a dummy tax code.

Note:

If your NetSuite account is using SuiteTax, Creating a Dummy Tax Code is no longer needed. Please skip setting this up.

#### To create a dummy tax code:

1.  Go to Setup > Accounting > Tax codes > New.
    
2.  Select a country.
    
3.  In the **Tax Code** field, enter **EC-DUMMY-FI** for Finland.
    
4.  In the **Description** field, you can write, for example, that this tax code placeholder is used with Automatic EU Tax Code Selection for EC Sales feature.
    
5.  In the **Rate** field, enter **0.00**.
    
6.  From the **Subsidiaries** list, select all subsidiaries in Finland (pressing Ctrl).
    
7.  From the **Tax Agency** list, select **Tax Agency FI**.
    
8.  From the **Tax Type** list, select **VAT**.
    
9.  From the **Available On** list, select **Sales Transactions**.
    
10.  Click **Save**.
     

If it's required to use Notional VAT or to set up reverse charges, the default ES-FI tax code for EU standard sales/purchases for goods must be split into two. One tax code must be set for sales and one for purchases, as the setup would only apply on the purchase side. The tax codes must be set up as follows (example is given for Denmark):

![Split ES-DK tax code settings, ESS-DK for sales, ESP-DK for purchases.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/CountrySpecificFeatures/Nordic_TaxCodes.png)

The **Available On** field must be set to **Sales Transactions** and **Purchase Transactions** accordingly.
