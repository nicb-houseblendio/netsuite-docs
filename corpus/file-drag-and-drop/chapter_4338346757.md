File Drag and Drop SuiteApp lets you upload one or more files from your desktop to the file cabinet or a record page. You can also use it to attach multiple files directly to editable sublists on supported and custom records.

Consider the following limitations when using File Drag and Drop:

-   File Drag and Drop only works on records and transactions that are in the old NetSuite UI. Make sure the preference to show the project in the new NetSuite UI is turned off.
    
    Go to Setup > Company > General Preferences and check that the Show Project In New UI box isn't checked.
    
-   You can upload files with a maximum size of up to 10MB. If the upload takes too long, you can abort or cancel the upload and try again.
    

Important:

Your administrator must install and configure File Drag and Drop SuiteApp in your account before you can use it.
