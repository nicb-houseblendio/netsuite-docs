If you have a New Zealand subsidiary and the International Tax Reports SuiteApp, you can generate the GST101A return. Use this report to fill in the official tax form for the tax agency. You can also see sales and purchase reports by tax code.

For more information, read the following New Zealand tax topics:

-   [New Zealand Tax Codes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1947661.html)
    
    [Tax Code Table for New Zealand](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1947661.html#bridgehead_N1947720)
    
-   [New Zealand GST Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1948109.html)
    
    [What goes into each box - New Zealand GST Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4114553962.html)
    

For more information about the International Tax Reports SuiteApp, see [International Tax Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2051341.html).
