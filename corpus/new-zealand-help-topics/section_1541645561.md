Setting up an account for an organization doing business in New Zealand usually requires enabling several features and installing some additional SuiteApps.

## Enabling Features for New Zealand Account {#subsect_161216179808}

Some NetSuite features are especially useful for New Zealand users. If they're inactive, think about turning them on. Use the steps below to turn on the most useful features for New Zealand users. However, if you want to get access to some specific product area, go to the [Functional Areas](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4198378244.html#subsect_161216102611) help topic and check the exact requirements.

Note:

If you do not have sufficient permissions to enable features, please contact your account administrator.

#### To enable features:

1.  In NetSuite, go to _Setup > Company > Setup Tasks > Enable Features (Administrator)_.
    
2.  On the **SuiteCloud** subtab, enable the following features:
    
    1.  Under **SuiteBuilder**, check the following boxes:
        
        -   Item Options
            
        -   Custom Records
            
        -   Advanced PDF/HTML Templates
            
    2.  Under **SuiteScript**, check the following boxes:
        
        -   Client SuiteScript
            
        -   Server SuiteScript
            
    3.  Under **SuiteGL**, check the following boxes:
        
        -   Custom GL Lines
            
        -   Custom Transactions
            
        -   Custom Segments
            
    4.  Under **SuiteTalk (Web Services)**, check the following boxes:
        
        -   SOAP Web Services
            
        -   REST Web Services
            
    5.  Under **SuiteCloud Development Framework**, check the **SuiteCloud Development Framework** box.
        
    
    To learn more about SuiteCloud features, see [SuiteCloud Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N239332.html).
    
3.  If you are using NetSuite OneWorld, do the following:
    
    1.  On the **Company** subtab, go to the International section and check the **Multi-language** and **Multiple Currencies** boxes.
        
    2.  On the **Tax** subtab, check the **Advanced Taxes** box.
        
    
    To learn more about NetSuite OneWorld, see [Introduction to NetSuite OneWorld](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N266468.html).
    
4.  Click **Save**.
    

## Relevant SuiteApps {#subsect_161216191083}

Some extra features need you to install a specific SuiteApp. SuiteApps are apps that add features for certain industries or business needs. For information about the required SuiteApps for specific product areas, see [Functional Areas](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4198378244.html#subsect_161216102611).

New Zealand-specific features are currently available in the following SuiteApps:

| SuiteApps | Area | Description |
| --- | --- | --- |
| [Country-Specific Address Forms](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4135282978.html) | SuiteBuilder (Customization) | Provides address forms formatted for New Zealand. |
| [Payment Gateway](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3803057063.html) | Payments | Integrate with AsiaPay, eWAY Rapid, SecurePay, and SecurePay FraudGuard credit card payment gateways in New Zealand. |
| [Electronic Bank Payments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N1585433.html) | Payments | Enables bank payments of vendor bills, employee expenses, partner and employee commissions, customer refunds, and customer payments within New Zealand. |
| [International Tax Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2051341.html) | Taxation Features For Accounts Without SuiteTax | Generates GST reports in New Zealand format, sales and purchase reports by tax code, and pre-configured tax codes for newly-created nexus. If your account has the SuiteTax feature enabled, you do not need to install this SuiteApp. |
| [ANZ Localization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_158677153915.html) | Taxation Features For Accounts Without SuiteTax | Provides the localization features like customized transaction fields, records, and report templates specific to Australia and New Zealand. |
| [SuiteTax Engine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1557396965.html) | Taxation Features For Accounts With SuiteTax | Sets default tax codes based on local tax requirements. This SuiteApp is required for accounts in [SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/preface_1496364245.html). |
| [Tax Reporting Framework](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1528262949.html) | Taxation Features For Accounts With SuiteTax | Provides the permissions, setup options, and tax reporting features to country tax reports. |
| [SuiteTax Country Tax Reports APAC](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156739606850.html) | Taxation Features For Accounts With SuiteTax | Provides the report template needed to generate and customize the GST Return 101A. |

For more information about SuiteApps, go to [SuiteApps](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_3134602194.html).

To learn about SuiteApp installation, see [Installing a Bundle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3395142.html).
