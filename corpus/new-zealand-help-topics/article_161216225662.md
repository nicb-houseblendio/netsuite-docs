You can make your NetSuite account fit New Zealand by setting your personal preferences. Use these steps to set user preferences like system language, date format, and time zone for New Zealand.

#### To set up New Zealand-specific User Preferences:

1.  In NetSuite, go to _Home > Set Preferences_.
    
2.  On the Set Preferences page, go to the **General** subtab. In the Localization section, set the following preferences:
    
    1.  Select British as **Spelling Locale**.
        
    2.  Select GMT +12:00 Auckland, Wellington as **Time Zone**.
        
3.  In the Formatting section, select your preferred **Date Format** and **Long Date Format**.
    
4.  Go to the **Custom Preferences** subtab, General section. In the **ABN Verification Warnings** dropdown list, set your preference for handling invalid NZBNs on customer or vendor records:
    
    -   **No Warnings** - You will not be alerted of an invalid NZBN and you can save the record.
        
    -   **Warn** - A warning banner will display to alert you of an invalid NZBN but you can still save the record.
        
    -   **Warn and Block** - An error banner will display to alert you of an invalid NZBN and you cannot save the record until you corrected the NZBN.
        
    
    Note:
    
    Your account must have the [ANZ Localization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_158677153915.html) SuiteApp installed to set this preference.
    
5.  Click **Save**.
    

For more information about setting personal preferences in NetSuite, see [General Personal Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N475661.html).
