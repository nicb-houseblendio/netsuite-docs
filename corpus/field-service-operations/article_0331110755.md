Operations managers use the Schedule Board to track task status and technician activity as work progresses. The Schedule Board gives you an operational view of tasks and resources, and uses color coding to highlight the priority and status of each task.

As an operations manager, you might:

-   Track work in progress and address exceptions like late or blocked work, or repeated save issues in Field Service Management (FSM) Mobile.
    
-   Use task status and other operational signals to escalate issues to dispatch or service leaders.
    

## Example Use Cases {#subsect_0331112733}

-   **Spot stalled work using visual signals on the Schedule Board.**
    
    Use color groups for Task Status and Task Priority so at-risk work stands out. You can spot overdue tasks or tasks with unsaved changes, and investigate them.
    
-   **Monitor the Unassigned panel for new and urgent tasks.**
    
    Use the Unassigned panel on the Schedule Board to ensure new work is scheduled and to move tasks off the board if you need to reschedule.
    
-   **Monitor completion patterns without losing context.**
    
    Use the Schedule Board's Completed Task display to review newly completed work or confirm what still needs attention.
    
-   **Contact a technician from the Schedule Board when you detect an exception.**
    
    Start an email draft or place a call using your default apps from the actions available on the resource row. You can follow up with the technician to resolve blockers or confirm task status.
    
-   **Triage FSM Mobile issues.**
    
    Work with an administrator to troubleshoot issues. The administrator can inspect the mobile network requests and payloads in browser developer tools for the emulator. This review can help to determine whether the issue involves events (jobs), inventory (dropdown options), or resources (tab data).
