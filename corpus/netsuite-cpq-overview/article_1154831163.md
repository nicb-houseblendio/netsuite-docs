NetSuite CPQ (Configure, Price, Quote) is a sales solution that helps you automate, accelerate, and increase accuracy in the process of configuring, quoting, and ordering complex products and services based on your business logic. By quoting and selling complex configurable items quickly, sales teams can improve customer experience and satisfaction while investing the saved time in enhancing the sales process.

NetSuite CPQ is available on the SuiteApp Marketplace as a shared and managed collection of SuiteApps:

Note:

NetSuite CPQ was previously available as a collection of bundles. The NetSuite CPQ SuiteApps will be released in phases to customer accounts. If you already have one or more NetSuite CPQ bundles in your account, contact NetSuite Customer Support before attempting to install the NetSuite CPQ SuiteApps.

-   **NetSuite CPQ Configurator** - Lets users configure complex items according to your business logic and add these items to transactions. For more information, see [NetSuite CPQ Configurator](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_7121343557.html).
    
    -   **NetSuite CPQ AI Assistant** - Extends the functionality of NetSuite CPQ Configurator by providing generative AI-driven, conversational guidance that simplifies and streamlines product and service configuration. For more information, see [NetSuite CPQ AI Assistant](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_9094751090.html).
        
    -   **NetSuite CPQ Manufacturing** - Extends the functionality of NetSuite CPQ Configurator by letting you create work orders based on the information provided for materials and routing steps. For more information, see [Creating Work Orders for Configured Items](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_8155327253.html).
        
    -   **NetSuite CPQ Ecommerce Integration** - Extends the functionality of NetSuite CPQ Configurator by validating and processing configuration data in the background. The Ecommerce Integration is the former Background Configurator. For more information, see [NetSuite CPQ Ecommerce Integration](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_3102531504.html).
        
    -   **NetSuite CPQ Proposal Generator** - Extends the functionality of NetSuite CPQ Configurator by letting you leverage HTML and CSS code to create customized documents related to your transactions. NetSuite CPQ Proposal Generator also works with transactions that don't contain configured items. For more information, see [NetSuite CPQ Proposal Generator](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_5132447427.html).
        
-   **NetSuite CPQ SuiteCommerce Integration** - Lets you launch NetSuite CPQ Configurator from a SuiteCommerce product page and add configured items to the shopping cart when submitting the configuration. For more information, see [NetSuite CPQ SuiteCommerce Integration](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_25182351521.html).
    
-   **NetSuite CPQ Guided Selling** - Lets you create catalogs with advanced filters-like those used in e-commerce platforms-to search for items and add them to transactions. NetSuite CPQ Guided Selling can work independently from NetSuite CPQ Configurator. For more information, see [NetSuite CPQ Guided Selling](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_173345162.html).
    

Note:

Documentation for the NetSuite CPQ SuiteApps is currently in progress and is being added to this page as it becomes available. You can continue to refer to the documentation for the bundles to work with the SuiteApps.

## Bundle Guides {#subsect_0213034444}

You can access the documentation for the NetSuite CPQ bundles under the **Support** subtab on the options record. The following table describes how to reach the options record in the bundles or the SuiteApps.

| **NetSuite CPQ Configurator bundle** | Configurator > System > Global Settings |
| --- | --- |
| **NetSuite CPQ Guided Selling bundle** | Guided Selling > System > Global Settings |
| **NetSuite CPQ Configurator SuiteApp** | CPQ > Configurator > Settings |
| **NetSuite CPQ Guided Selling SuiteApp** | Guided Selling > System > Global Settings |

The following PDF bundle guides are available:

-   **CPQ Administration Guide** - Describes how to install the CPQ Configurator and perform administrator tasks related to setting up CPQ in your NetSuite account.
    
-   **CPQ Configurator User Guide** - Describes how to use the CPQ Configurator including how to set a main item, manage manufacturing routings, and define qTables.
    
-   **Managing CPQ Products** - Describes how to work with CPQ products including how to create a CPQ product, configure images, and define actions.
    
-   **CPQ Guided Selling** - Describes how to install Guided Selling, provides an overview of guided selling with NetSuite CPQ, and includes information about how to manage guided selling products.
    
-   **CPQ SuiteCommerce Extension Guide** - Describes how to install and set up the SuiteCommerce Extension for NetSuite CPQ.
    
-   **CPQ Configurator Release Notes** - Provides release notes since version 2020.2.1.1.
    
-   **CPQ Guided Selling Release Notes** - Provides release notes since version 2020.1.4.0.
    
-   **CPQ SuiteCommerce Extension Release Notes** - Provides release notes since version 1.1.25.
    
-   **CPQ CE Functions Reference** - Provides information about each code exec function.
