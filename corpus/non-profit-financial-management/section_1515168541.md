Set a restriction type for contributions. This is required for transactions. When entering donations, pledges, and grants, tag the transaction with the right restriction from the donor. You can set the restriction using the right Segment Code.

The restriction type can be set to:

-   Without Donor Restrictions
    
-   With Donor Restrictions
    

Using the time restriction segment, set a restriction by fiscal year.

You can also select any other fund type that you have added to the restriction custom segment.

For details, see [Custom Segments for NFP Financials](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1519241750.html)

You can also generate FASB reports.
