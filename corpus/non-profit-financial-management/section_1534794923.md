You can install NFP Financials as a SuiteApp in your account.

## Deployment Considerations for NFP SuiteApps {#section_1526407226}

Keep these deployment considerations in mind before installing or updating the NFP SuiteApps:

-   Before you install NFP Financials, reach out to your NetSuite sales or account rep to get the SuiteApp provisioned for your account.
    
-   Only users with the Administrator role can install NFP SuiteApps.
    
-   Don't rename classifications (Department, Class, Location, Subsidiary, or Account) with the same names as the custom segments in the NFP Financials SuiteApp. Otherwise, you might run into issues when updating the NFP SuiteApps. For more information, read the topic [Custom Segments for NFP Financials](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1519241750.html).
    
-   Custom Segments are unlocked, so you can change them and their related Custom Record definitions. However, when you update the bundle, any changes you made to Custom Segments go back to how they are in the SuiteApp, except for these field values:
    
    -   Label
        
    -   Mandatory check box
        
    -   Default Selection
        
    -   Default Record Access Level
        
    -   Default Search/Reporting Access Level
        
    -   Sourcing lists from Transactions, Transaction Columns, Entities, CRM, and Items
        

#### To install NFP Financials:

For more information about installing a SuiteApp from the SuiteApp Marketplace, see [Installing from the SuiteApp Marketplace](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1539799323.html).

1.  Go to **SuiteApps**.
    
2.  In the **Search SuiteApps** field, enter **NFP Financials** to search for the SuiteApp.
    
3.  Click the NFP Financials tile.
    
4.  On the top right corner of the page, click **Install**.
    

NFP Financials is a managed SuiteApp that is automatically updated whenever enhancements or new features are added.
