The Giving Statistics by Program report shows donations for each program, including the number of gifts, total amount, and average gift size. You can run the report for any date range and filter the results.

The report is a saved search. Saved searches are NetSuite queries that let you filter and sort data in advanced ways. For information about saved searches, see [Saved Searches](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N675442.html).

#### To view the Giving Statistics by Program report:

1.  Go to NFP Financial Center > Revenue Reports > Giving Statistics by Program.
    
    NetSuite displays the report.
    
2.  To view the details for a program, click on the program name.
    
    NetSuite displays the list of donations from the selected program.
    
    Donations can include invoice, journal, or cash sale transaction types.
    

To print the report, click the print icon ![Print button](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SocialImpact/FooterIconPrint.png) at the bottom of the page.
