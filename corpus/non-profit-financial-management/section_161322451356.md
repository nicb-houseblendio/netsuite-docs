The NFP Financials bundle includes the following saved search reports:

-   **LYBUNT (Last Year But Not This Year)** - This report lists constituents who donated in the last fiscal year but did not donate again in this fiscal year. The report includes only the transactions that have **Revenue Type** set to **Donation**.
    
-   **SYBUNT (Some Year But Not This Year)** - This report lists constituents who donated before the first day of last fiscal year but did not donate again in the last or current fiscal year. The report includes only the transactions that have **Revenue Type** set to **Donation**.
    

You can access the saved searches from Reports > Saved Searches > All Saved Searches.
