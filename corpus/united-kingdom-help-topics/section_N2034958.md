Note:

This topic is for NetSuite accounts that use the EU Sales List Report page to submit the EU Sales List. If you are using the Country Tax Report page, see [EC Sales List](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_156888850442.html).

A common error that occurs during ESL online submission is an incorrect customer or vendor VAT registration number. To avoid this error, ensure that your customer records have VAT numbers. Each EU country has its own VAT number format so be sure you enter the correct VAT number formats. Also verify that the VAT numbers are valid on the current date by clicking the VIES link on the Financial tab of the customer record. Doing so will help avoid errors in your EU sales list reports.

Each EU country has its own VAT prefix and numbering format. For information, refer to this [VAT identification number structure](http://ec.europa.eu/taxation_customs/vies/faqvies.do) published by the European Commission.

Another common error is an incorrect CSV file. When a CSV file is generated, don't open it in Microsoft Excel because the format changes, which results in errors in your submission. If you need to open the file, use a text editor such as Notepad. Go to the HMRC Web site to download a guide on Troubleshooting CSV Files.

If the submission was a partial success (fewer than 30% of the line items on the report failed), then you must fix the failed line items, run the report again, and resubmit it. Make sure you exclude the successful line items when you resubmit.

If the entire submission was a failure (greater than 30% of the line items on the report failed), then you have to correct all line items with errors and resubmit the entire report.

You must fix and resubmit all line item failures for the same tax period. You can manually correct late transactions or errors using form VAT101B, which can be downloaded from the HMRC Web site.

For more information, consult the HMRC Web site for guidelines on correcting errors on your ESL online submission.
