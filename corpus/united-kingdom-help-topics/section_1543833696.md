Note:

This topic is for NetSuite accounts that use the Tax Reports (International) page to generate the United Kingdom VAT100 Return. If you are using the Country Tax Report page, see [Making Tax Digital](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1555090419.html).

The Making Tax Digital for VAT feature also lets you export the United Kingdom VAT100 Return to an Excel file (.xls).

Companies with business records outside of NetSuite can use this feature to export VAT records from NetSuite and consolidate the VAT100 Return in another spreadsheet. For more information about submitting a consolidated VAT Return, see [Submitting an MTD VAT Return in a CSV File](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1547520822.html).

Note:

Be sure to use an MTD API-enabled software in consolidating your VAT100 Return before submitting to HMRC.

#### To export a United Kingdom VAT100 Return to Excel:

1.  Go to Reports > VAT/GST > Tax Reports (International).
    
2.  If you are using a OneWorld account, select the United Kingdom VAT-registered subsidiary.
    
3.  In the **Country Form** field, select **United Kingdom**.
    
4.  Choose the tax period and click **Refresh** to generate the report.
    
5.  Click **Export to XLS** to download the report in an Excel file.
