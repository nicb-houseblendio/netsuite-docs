If you want to use the Tax Reporting Framework delivered by the United Kingdom Localization SuiteApp, make sure that your NetSuite is properly configured. Please check the following:

-   Accounting periods must be set for United Kingdom subsidiary. For more information, see [Setting Up Accounting Periods for a Year](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1446183.html).
    
-   The SuiteTax Plug-In must be enabled. Enabling the SuiteTax Plug-In permits you to select SuiteTax as your tax engine. For more information, see [Enabling the SuiteTax Plug-In](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557399475.html).
    
-   Tax registration must be assigned to a subsidiary. To add a tax registration for a subsidiary, see the help topic [Assigning Tax Registrations to a Subsidiary in SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4296038273.html).
