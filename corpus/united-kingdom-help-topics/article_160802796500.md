Note:

This topic is for NetSuite accounts that use the EU Intrastat Report page to generate the Intrastat report. If you are using the Country Tax Report page, see [United Kingdom Intrastat](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_157164884789.html).

To use the Intrastat Reporting feature, the International Tax Reports SuiteApp must be installed in your NetSuite account. For more information, see [International Tax Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2051341.html).

The United Kingdom Intrastat report can be generated for monthly tax periods only. If you have multiple months to generate, you must generate the report one month at a time.

#### To generate the United Kingdom Intrastat report:

1.  Go to Reports > VAT/GST > EU Intrastat Report.
    
2.  Select your United Kingdom subsidiary.
    
3.  In the **Report Type** field:
    
    -   If you select **Sale** (for Dispatches), the **Country Form** displays **United Kingdom (English) 2022**.
        
    -   If you select **Purchase** (for Arrivals), choose **Northern Ireland (English) 2022** on the **Country Form**.
        
4.  Select a reporting period. Using the date selector, select the start date in **Tax Period** (from) field and the end date in **To** field.
    
5.  In the **Accounting Book** field, select the accounting book to be used to generate the report. The dropdown list shows all active books associated with the selected subsidiary.
    
    Note:
    
    This field is available if the Multi-Book Accounting feature is enabled in your account. For more information, see [Multi-Book Accounting for International Tax Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4108426899.html).
    
6.  To display the report, click **Refresh**. Note that you have to click **Refresh** each time you change the reporting criteria.
    
    Transaction lines with the same values of Commodity Code, Nature of Transaction, and Delivery Terms are consolidated and declared as one transaction. For consolidated transactions, Net Mass, Value, and Supplementary Unit columns are added.
    
    Important:
    
    For the saved reports in the International Tax Reporting SuiteApp, results are limited to 25,000 rows. A truncated report will display this note at the bottom of the page:
    
    'The results of this report are too large. Please narrow your results.' If you want to request for an increase in the limit, you must file a support case through the NetSuite Partner Center.
    
7.  Review the report. Take note of the following when reviewing reports:
    
    -   Review all pages of the report.
        
    -   To specify the number of rows displayed on each page, go to the **General** subtab in _Home > Set Preferences_.
        
    -   You can click the customer name to view the customer record or click the reference number to view the transaction record.
        
8.  Check the **Exclude** box for each transaction that you want to omit from your report. You can also click **Mark All** or **Unmark All**.
    
9.  To save the report, click any of the following options:
    
    -   **Print** - to generate a PDF version of the report that you can print or save for your own records. Lines with the checked Exclude box are not included in the PDF.
        
    -   **Export to Excel** - to save the Intrastat report as a Microsoft Excel (.xls) file. Lines with the checked Exclude box are not included in the .xls file.
        
    
    When you save an EU Intrastat Report, NetSuite saves it as a PDF in the File Cabinet folder that you specified on the Tax Filing Setup page as the Output Folder for Intrastat. The default name for this folder is United Kingdom Intrastat, and it is stored in the root folder of the file cabinet. Go to Documents > Files > File Cabinet and click the Intrastat folder to download and view the report.
    
    For information about the Tax Filing Setup page, see [Setting Up Tax Filing for United Kingdom](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2029554.html).
    

To export the United Kingdom Intrastat report in a format acceptable for upload to the tax agency website, see [Exporting the United Kingdom Intrastat Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160802803773.html).
