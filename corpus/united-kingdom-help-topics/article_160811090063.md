Note:

This topic is for NetSuite accounts that use the EU Intrastat Report page to generate the Intrastat report. If you are using the Country Tax Report page, see [United Kingdom Intrastat](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_157164884789.html).

The International Tax Reports SuiteApp provides localized Intrastat Dispatches and Arrivals reports for NetSuite accounts with a United Kingdom nexus.

The information displayed on the Intrastat Dispatches and Arrivals reports are based on your transaction and item records in NetSuite.

Note:

The U.K. subsidiaries located in Great Britain or has a Great Britain address are no longer required to submit the Intrastat Report for Dispatches and Arrivals starting January 1, 2022.

You can generate the Intrastat report for Arrivals and Dispatches for businesses based in Northern Ireland. Refer to [Generating the United Kingdom Intrastat Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160802796500.html).

The following table lists the information that appear on the generated Intrastat Dispatches and Arrivals report for Northern Ireland.

| Intrastat Dispatches (Sales) Report | Intrastat Arrivals (Purchases) Report |
| --- | --- |
| Line Number | Line Number |
| Description of Goods | Commodity Code |
| Item | Value |
| Commodity Code | Delivery Terms |
| Value | Nature of Transaction |
| Delivery Terms | Net Mass (kg) |
| Nature of Transaction | Supplementary Unit |
| Net Mass (kg) | Goods Received from |
| Supplementary Unit | Vendor Name |
| Goods Sent to | Reference No. |
| Partner VAT ID |  |
| Country of Origin |  |
| Customer Name |  |
| Reference No. |  |

For more details about the Intrastat Report field descriptions, see [Intrastat Reporting Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4150707116.html).

You can also customize an Intrastat report. You can access these custom reports from Reports > Saved Reports.

-   Intrastat Purchases Report \[Custom\]
    
-   Intrastat Sales Report \[Custom\]
    

For information about customizing a report, see [Report Customization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N736328.html).

Consult your tax authority for any changes in Intrastat codes and reporting requirements. The U.K. publishes updates to the Intrastat General Guide, Notice 60.
