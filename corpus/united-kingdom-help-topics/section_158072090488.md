Important:

This feature requires SuitePeople. For more information, see [SuitePeople Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1495573671.html).

With the SuitePeople U.K. Localization (SUL) SuiteApp you can monitor information and use it to comply with employment obligations in the United Kingdom. You can use the forms, fields, and saved searches available with the SuiteApp as reference when you need to fill regulatory forms.

For more information, see:

-   [SuitePeople U.K. Localization Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158078260378.html)
    
-   [Setting Up SuitePeople U.K. Localization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158078263868.html)
