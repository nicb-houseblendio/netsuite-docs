To use SuitePeople U.K. Localization (SUL), you must first complete specific prerequisites and then install the SuiteApp. If you want to use SUL for custom roles, you must add the fields to a permission. You can also add the SUL fields to your existing employee forms.

To set up SUL, follow the steps on the table.

| Step | Related Help Topic |
| --- | --- |
| 1\. Log in as a NetSuite administrator. | [Roles and Accounts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N295370.html) |
| 2\. Complete the prerequisites. | [SuitePeople U.K. Localization Prerequisites](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158078272683.html) |
| 3\. Install SuitePeople U.K. Localization. | [Installing SuitePeople U.K. Localization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158078275469.html) |
| 4\. (Optional) Add fields to custom permissions and roles. | [Adding SuitePeople U.K. Localization Fields to Custom Permissions and Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158078279937.html) |
| 5\. (Optional) Customize forms. | [Adding SuitePeople U.K. Localization Fields to Forms](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158080200213.html) |
