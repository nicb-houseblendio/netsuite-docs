United Kingdom Localization is a SuiteApp that delivers templates for generating United Kingdom tax reports. These reports include the Periodic VAT Return - VAT100 report, EC Sales List, and Intrastat. You can also submit these reports digitally to His Majesty's Revenue and Customs (HMRC). To use these tax reports, you must have the SuiteTax SuiteApps installed.

Also, the United Kingdom Localization SuiteApp delivers several United Kingdom and Jersey-specific payment templates originally provided by the Electronic Bank Payments SuiteApp. Please note that to use these templates, you must have the Electronic Bank Payments SuiteApp installed.

## Tax Reporting Framework {#subsect_158936137458}

This SuiteApp works with the Tax Reporting Framework SuiteApp by providing United Kingdom tax report templates which you can choose from the country-specific templates at Reports > Tax > Country Tax Reports. To use the features of United Kingdom Localization, you need to install EMEA Localization. For more information, see [EMEA Localization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_157122959910.html).

Note:

Oracle NetSuite supports Making Tax Digital for VAT (MTD for VAT) submission to HMRC. This functionality enables businesses to comply with UK government requirements by submitting VAT returns electronically through NetSuite's certified MTD integration.

The following tax reports are supported by the United Kingdom Localization SuiteApp:

-   [Periodic VAT Return - VAT100](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156775976739.html) - You have the option to file this report to HMRC, see [Making Tax Digital](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1555090419.html) and for importing custom report file to NetSuite, see [UK Submit VAT Return via CSV](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162643004330.html)
    
-   [Intrastat Supplementary Declaration](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_156889008497.html) - For information about the codes required in the Intrastat declaration, see [United Kingdom Intrastat](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_157164884789.html).
    
-   [EC Sales List](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_156888850442.html) - It can be exported in PDF, XLS, and CSV formats. CSV format can be used for bulk upload on the HMRC portal.
    

To generate tax reports, read the following topics:

For more information, see [United Kingdom Tax Reporting Framework](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157598390063.html).

For other tasks that you can do with UK tax templates on the Country Tax Reports page, see the following topics:

## Electronic Bank Payments Formats {#subsect_158936145180}

The United Kingdom Localization SuiteApp delivers several payment formats provided by the Electronic Bank Payments SuiteApp. This SuiteApp provides payment file formats for payments, receivables, and Positive Pay transactions. Before you can use a file format, you need to set it up with the relevant bank details and other information that the system requires.

If your NetSuite account already has the Electronic Bank Payments SuiteApp, it includes payment templates compatible with the United Kingdom. Installing the United Kingdom Localization SuiteApp updates those templates to formats that comply with UK standards.

To learn more about the payment file formats provided by the Electronic Bank Payments SuiteApp, go to [Payment File Formats](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1675118.html).
