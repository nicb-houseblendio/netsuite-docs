You can view and export the results of saved searches included with SuitePeople U.K. Localization (SUL). For more information about the fields included with each report, read [SuitePeople U.K. Localization Forms and Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158078789277.html).

#### To view a SuitePeople U.K. Localization report:

1.  Go to Reports > Saved Searches > All Saved Searches.
    
2.  From the list, click **View** beside one of the following SUL saved searches or a customized search.
    
    -   TEMPLATE U.K. Pay Equity Report
        
    -   TEMPLATE U.K. Employee Report
        
    
    For more information, read [SuitePeople U.K. Localization Saved Searches](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158079698798.html).
    
3.  To export the results as files that you can open in external applications, click **Export**. For more information, read [Exporting Search Results](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N663983.html).
