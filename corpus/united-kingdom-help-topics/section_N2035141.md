Note:

This topic is for NetSuite accounts that use the EU Sales List Report page to submit the EU Sales List. If you are using the Country Tax Report page, see [EC Sales List](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_156888850442.html).

When an ESL is successfully submitted from NetSuite to HMRC, this report is saved as a PDF file in the NetSuite File Cabinet. If the submission is partially successful, then the saved PDF will contain only the data from the successfully submitted lines.

The default name for the file cabinet folder is United Kingdom ESL and it is stored in the root folder of the file cabinet. You can provide a different name for this folder in the **Output Folder ESL** field on the EU Sales Filing Setup page. For more information, see [United Kingdom EU Sales List (ESL) Online Filing Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2029554.html#bridgehead_4404016733).

When you successfully submit your ESL online to HMRC, NetSuite sends you a notification email that includes a link to the PDF file.

Go to Documents > Files > File Cabinet and click the ESL Report folder to download and view the report.
