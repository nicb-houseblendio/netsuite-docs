Note:

This topic is for NetSuite accounts that use the Tax Reports (International) page to generate and submit the United Kingdom VAT100 Return. If you are using the Country Tax Report page, see [Making Tax Digital](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1555090419.html).

The Making Tax Digital for VAT feature enables you to view previously submitted United Kingdom VAT100 Returns from HMRC up to four years back. The retrieved return is saved in an Excel file (.xls) in the File Cabinet.

To set up the VAT100 output folder in the File Cabinet, go to the Tax Filing Setup page and enter the folder name in the Output Folder for VAT100 field. If no folder is specified in this field, a default folder is created for storing your United Kingdom VAT100 Returns. You may check [Restricting Access to File Cabinet Folders](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N542073.html) for information about how to manage access of the VAT Return files in the output folder.

Note:

Only VAT100 Returns submitted through MTD can be retrieved using this feature.

#### To view previously submitted MTD VAT Returns:

1.  Ensure that MTD feature is enabled. See [MTD for VAT Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1543833477.html#bridgehead_1551763546).
    
2.  Go to Reports > VAT/GST > Tax Reports (International).
    
3.  If you are using a OneWorld account, select the United Kingdom VAT-registered subsidiary.
    
4.  In the **Country Form** field, select **United Kingdom**.
    
5.  Choose the tax period that you want to retrieve and click **Refresh**.
    
6.  Click **Retrieve Return**.
    
7.  You'll be redirected to the HMRC website. Click **Continue** to grant authority to NetSuite and connect your account to HMRC. If you are not redirected to the HMRC website after clicking Retrieve Return, check your browser settings and ensure that popups coming from NetSuite are not blocked.
    
8.  On the HMRC Sign in page, enter your User ID and Password and click **Sign In**.
    
9.  Click **Grant Authority** to allow NetSuite to interact with HMRC on your behalf and continue with the VAT100 Return retrieval.
    
    Logging in HMRC is done only one time at every session. Logging out of NetSuite ends the connection with HMRC.
    
10.  The Online Filing page will confirm your VAT Return retrieval. Check your email for the result. A successful retrieval includes a VAT file link to the retrieved Return in the email.
     

A successful Retrieve Return changes the status on the MTD System Notes to **Retrieved**. To know more about MTD System Notes and other status messages, see [Viewing the MTD VAT Return Submission History](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1543833748.html).

Important:

For more information about MTD service availability and issues, see [Making Tax Digital for VAT: Service Availability and Issues](https://www.gov.uk/government/publications/making-tax-digital-for-vat-service-availability-and-issues/making-tax-digital-for-vat-service-availability-and-issues).
