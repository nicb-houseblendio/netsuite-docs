Note:

This topic is for NetSuite accounts that use the Tax Reports (International) page to generate and submit the United Kingdom VAT100 Return. If you are using the Country Tax Report page, see [Making Tax Digital](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1555090419.html).

To check the status of your previously submitted United Kingdom MTD CSV files, follow these steps:

#### To view previously submitted United Kingdom MTD CSV Files

1.  Go to Reports > VAT/GST > United Kingdom MTD Submit Via CSV.
    
2.  The **United Kingdom MTD Submit Via CSV** page appears and displays the following subtab options: **Setup**, **Submit CSV** and **Submission History**.
    
3.  Click the **Submission History** subtab. A table appears and displays the following columns:
    
    -   **Date** - date of submission
        
    -   **User Name** - name of the user who filed the CSV VAT return
        
    -   **From Period** - tax period start date on the VAT report
        
    -   **To Period** - tax period end date on the VAT report
        
    -   **Status** - action status
        
        -   **Submitted** means that the MTD CSV online submission was accepted by HMRC. VAT100 Returns submitted using a CSV file won't display a **Submitted** stamp on the VAT Return form.
            
        -   **For User Authorization** means that the MTD VAT100 Return online submission was revoked. Closing the HMRC website upon online submission causes this status. You must permit your browser to be redirected to the HMRC website and allow popups on your browser settings.
            
        -   **Failed** means that the MTD VAT100 Return online submission or retrieval was not accepted by HMRC due to any type of transmission failure. Check the table on [Handling MTD VAT Return Submission Errors](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156385546699.html) for your error scenario and follow the recommended actions to resolve the error. If your MTD request continues to fail after following the recommended actions, please contact Support through your normal support channels for assistance on how to resolve the error.
            
            Important:
            
            For information about MTD service availability and issues, see [Making Tax Digital for VAT: service availability and issues](https://www.gov.uk/government/publications/making-tax-digital-for-vat-service-availability-and-issues/making-tax-digital-for-vat-service-availability-and-issues).
            
4.  Click the Status link of the submission record to view more information.
    
    Note:
    
    The Submission Details subtab inside each submission record contains information about the submitted data and results.
