Note:

This topic is for NetSuite accounts that use the EU Intrastat Report page to generate the Intrastat report. If you are using the Country Tax Report page, see [United Kingdom Intrastat](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_157164884789.html).

The Intrastat Report gets the following information from the **Tax Reporting** subtab and **Items** sublist of transaction forms and item records:

-   Nature of Transaction Code
    
-   Delivery Terms
    
-   Commodity Code
    
-   Supplementary Unit
    
-   Partner ID
    
-   Country of Origin
    

## United Kingdom Intrastat Report Fields on Transaction Forms {#subsect_160811345833}

The **Tax Reporting** subtab on transaction forms only appears if you are transacting with an EU vendor or EU customer. This subtab contains the following fields which are used for Intrastat reporting:

-   **Nature of Transaction Code** - Select the type of your transaction. For more information, see [Nature of Transaction Code](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2070738.html).
    
-   **Delivery Terms** - Select the delivery term (Incoterm) used in the transaction. For more information, see [Delivery Terms](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2071234.html).
    
-   **Country of Origin** - The country where the goods were harvested, manufactured, or substantially changed. For more information, see [Country of Origin](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164377962805.html).
    
-   **Partner ID** - This refers to the VAT number of the party receiving the goods in the EU member state of destination. For more information, see [Partner ID](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164377982356.html).
    

Note:

The Partner ID and Country of Origin fields are shown on the Tax Reporting subtab and on the Items sublist of the transaction.

You must fill out these fields to generate a fulfilled Intrastat Dispatches and Arrivals reports. For more information about EU Intrastat Report Fields on transaction forms, see [Intrastat Reporting Fields on Transaction Forms](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4150707116.html#bridgehead_4150716738).

## United Kingdom Intrastat Report Fields on Item Records {#subsect_160811403621}

The Tax Reporting subtab on item records contains the following fields:

-   **Commodity Code** - The 8-digit number that identifies the type of goods or commodity on the item record. For more information, see [Commodity Code](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2070438.html).
    
-   **Supplementary Unit** - Unit used in measuring the quantity of goods or commodity on the item record. For more information, see [Supplementary Unit](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4605983594.html).
    

For more information about EU Intrastat Report Fields on item records, see [Intrastat Reporting Fields on Item Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4150707116.html#bridgehead_4150717128).
