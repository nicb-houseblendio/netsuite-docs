Note:

This topic is for NetSuite accounts that use the EU Sales List Report page to generate the EU Sales List. If you are using the Country Tax Report page, see [EC Sales List](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_156888850442.html).

Effective January 1, 2021, businesses located in Great Britain are no longer required to submit EU Sales List. However, it is still required for businesses located in Northern Ireland.

Online submission of the EU sales list to His Majesty's Revenue and Customs (HMRC) is a feature available in NetSuite upon installation of the International Tax Reports SuiteApp.

Before generating an EU sales report and submitting it online, be sure to check the preferences on your EU Sales Filing Setup page. For information, see [Setting Up Tax Filing for United Kingdom](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2029554.html).

Important:

Before submitting the EU Sales List online, you need to perform the following steps to update the URL in the system.

#### To update the URL:

1.  Go to Reports > VAT/GST > EU Sales List Report.
    
2.  On the EU Sales List (ESL) Report page, click **Setup** and select **EU Sales Filing**.
    
3.  On the EU Sales Filing Setup window, click **Save**.
    

United Kingdom customers have the following options for submitting an EU sales list to HMRC using NetSuite:

-   **Export (HMRC)** - to save the ESL as a CSV file that you can upload to the HMRC Web site. This option converts the ESL into a CSV file that complies with the format required by HMRC. This file is saved in your NetSuite File Cabinet. For information, refer to the HMRC Web site article on Submitting ECSL declarations by CSV.
    
-   **Submit Online** - to submit the ESL directly to HMRC using NetSuite
    
    For information about setting up the online submission feature, see [Setting Up Tax Filing for United Kingdom](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2029554.html).
    
    When you submit the ESL directly to HMRC from NetSuite:
    
    -   You'll receive an email about the status of your submission. The email message tells informs you whether your submission was a success, partial success, or failure. The email also includes error messages and a link to the PDF file of the successfully submitted ESL report.
        
    -   A submission history is saved in NetSuite. For information, see [Viewing the ESL Submission History](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2034719.html).
        
    -   Successfully submitted lines are stored in PDF format in your NetSuite File Cabinet.
