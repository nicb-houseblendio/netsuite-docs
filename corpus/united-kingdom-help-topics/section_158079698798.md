You can use the following saved searches as templates to create employee-related reports.

| Saved Search Title | Saved Search ID | Fields |
| --- | --- | --- |
| TEMPLATE U.K. Pay Equity Report | customsearch\_suk\_pay\_equity | Shows the following:
-   Employee Name
-   Job Title
-   Department
-   Contract Type
-   Gender
-   Ethnic Origin (U.K)
-   Base Salary Type
-   Compensation Currency
-   Base Salary

 |
| TEMPLATE U.K. Workforce Employee Report | customsearch\_suk\_workforce\_employee | Shows the following:

-   Employee Name
-   Job Title
-   Department
-   Contract Type
-   Gender
-   Ethnic Origin (U.K)

 |

For information about creating and editing the saved searches, read [Working with SuitePeople U.K. Localization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158078268506.html).

To install and set up the SuiteApp as an Administrator, read [Setting Up SuitePeople U.K. Localization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158078263868.html).
