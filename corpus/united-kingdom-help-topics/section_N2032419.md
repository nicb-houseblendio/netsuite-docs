Important:

Beginning April 8, 2021, HMRC no longer accepts non-MTD VAT submissions. Refer to [Making Tax Digital for VAT](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1543299566.html) for the complete information of U.K.'s VAT direct filing solution.

The successfully submitted VAT100 report is saved as a PDF file in a file cabinet folder specified on the Tax Filing Setup page as the Output Folder for VAT100. The default name for this folder is United Kingdom VAT Returns and it is stored in the root folder of the file cabinet.

When you successfully submit your VAT100, NetSuite sends you a notification email that includes a link to the PDF file.
