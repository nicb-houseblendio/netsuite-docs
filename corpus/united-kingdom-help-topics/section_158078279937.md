Important:

Enable the Advanced Employee Permission feature so you can add SuitePeople U.K. Localization (SUL) fields to custom permissions and roles.

SuitePeople U.K. Localization (SUL) fields are available to specific roles by default. For more information, read [SUL Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158078260378.html#subsect_158078784094).

To give custom roles access to SUL fields, you must first add the fields to a permission. Then, assign the permission to the custom role. If you've already created custom CPO and HRG roles before installing the SuiteApp, you'll need to add the fields to a permission and assign the permission to these roles as well.

#### To add custom SUL fields to a permission:

1.  Log in with an Administrator role.
    
2.  Go to Setup > Users/Roles > User Management > Manage Permissions.
    
3.  From the Manage Permissions page, choose any of the following:
    
    -   To create a new permission without inherited standard and sublists, click **New Permission**.
        
    -   To create a new permission with inherited standard fields and sublists, click **Customize** in the corresponding row.
        
    
    To edit an existing custom permission, click **Edit** in the corresponding row.
    
4.  On the Permission page, add the custom SUL fields.
    
    1.  On the **Fields** subtab, click **Custom Fields**.
        
    2.  From the **Record Type** list, select **Employee**.
        
    3.  From the **Field** list, select a field from the table. For more information, read [SuitePeople U.K. Localization Forms and Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158078789277.html).
        
        | Field | Description |
        | --- | --- |
        | Ethnic Origin (U.K.) | Lets you select the ethnic origin or group of the employee. |
        | Community Background | Lets you select the community where the employee belongs. |
        | Method of Monitoring | Select the method used to determine the employee's community background. |
        | Determination Date | Lets you select or enter the date when the employee's community background was determined. |
        
    4.  Click **Add**.
        
    5.  Repeat steps a to d for each field that you want to include.
        
5.  Enter or edit values in the other fields on the page.
    
6.  Click **Save**.
    

After you add the custom SUL fields to a permission, set the permission to a custom role. For more information, read [Setting Employee Access for Advanced Employee Permissions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1494598267.html).

To continue setting up the SuiteApp, read [Setting Up SuitePeople U.K. Localization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158078263868.html).
