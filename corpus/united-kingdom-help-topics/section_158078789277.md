You can use the following forms and their corresponding fields with SuitePeople U.K. Localization.

| Form | Field | Description |
| --- | --- | --- |
| U.K. Employee Form | Ethnic Origin (U.K.) | This field lets you select the ethnic origin or group of the employee. |
| Northern Ireland Employee Form | Ethnic Origin (U.K.) | This field lets you select the ethnic origin or group of the employee. |
| Community Background | This field lets you select the community where the employee belongs. |
| Method of Monitoring | This field lets you select the method used to determine the employee's community background. |
| Determination Date | This field lets you select or enter the date when the employee's community background was determined. |

For information about adding an employee record using the forms, read [Adding an Employee Record for U.K. Monitoring](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158078284995.html).

To install and set up the SuiteApp as an Administrator, read [Setting Up SuitePeople U.K. Localization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158078263868.html).
