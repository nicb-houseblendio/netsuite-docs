Note:

This topic is for NetSuite accounts that use the Tax Reports (International) page to generate and submit the United Kingdom VAT100 Return. If you are using the Country Tax Report page, see [Making Tax Digital](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1555090419.html).

You can view the submission history of your MTD VAT Return by clicking the MTD System Notes tab on the VAT form.

Warning:

If you uninstall the International Tax Reports SuiteApp from your account, the VAT submission history is deleted and cannot be recovered.

#### To view the MTD VAT Return submission history:

1.  Go to Reports > VAT/GST > Tax Reports (International).
    
2.  On the Tax Reports page, select the United Kingdom VAT-registered subsidiary.
    
3.  Select the **United Kingdom** country form.
    
4.  On the VAT Return tax form, click the **MTD System Notes** tab.
    
5.  Review the information in the following columns:
    
    -   **User Name** - name of the user who filed the VAT return
        
    -   **Date** - date of submission
        
    -   **Status** - action status
        
        -   **Submitted** means that the MTD VAT100 Return online submission was accepted by HMRC. This status is indicated by a **Submitted** stamp on the VAT Return form. However, if the VAT100 Return is submitted using a CSV file, the VAT Return form won't display a Submitted stamp.
            
        -   **Failed** means that the MTD VAT100 Return online submission or retrieval was not accepted by HMRC due to any type of transmission failure. Check the table on [Handling MTD VAT Return Submission Errors](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156385546699.html) for your error scenario and follow the recommended actions to resolve the error. If your MTD request continues to fail after following the recommended actions, please contact Support through your normal support channels for assistance on how to resolve the error.
            
            Important:
            
            For information about MTD service availability and issues, see [Making Tax Digital for VAT: service availability and issues](https://www.gov.uk/government/publications/making-tax-digital-for-vat-service-availability-and-issues/making-tax-digital-for-vat-service-availability-and-issues).
            
        -   **Retrieved** means that the requested MTD VAT100 Return was retrieved successfully.
            
        -   **For User Authorization** means that the MTD VAT100 Return online submission was revoked. Closing the HMRC website upon online submission causes this status. You must permit your browser to be redirected to the HMRC website and allow popups on your browser settings.
            
    -   **From Period** - tax period start date on the VAT report
        
    -   **To Period** - tax period end date on the VAT report
        
    -   **Action** - view and print the submitted VAT report
        
        Note:
        
        If your sales or purchases exceeded the field limitation of one million characters, you may not be able to view the transaction details of the report. For more information, see [Viewing the VAT Return Submission History](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3721544005.html).
        
    -   **Type** - type of VAT Return process
        
        -   **Submit** - VAT Return form is submitted
            
        -   **Submit\_CSV** - VAT Return is submitted in a CSV file
            
        -   **Retrieve** - VAT Return is retrieved
            
6.  Click the Status link of the submission record to view more information.
