Before installing the United Kingdom Localization SuiteApp, your account administrator must enable several features and preferences in your NetSuite account.

## SuiteApps {#bridgehead_158824618172}

To use the additional functions of the United Kingdom Localization SuiteApp, install the following SuiteApps in required order as per below:

-   **SuiteTax** - You should install this SuiteApp only if you want to use Tax Reporting Framework. This SuiteApp helps meet the tax determination and reporting requirements. To install, see [Installing the SuiteTax Engine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557397007.html).
    
-   **Tax Reporting Framework** - You should install this SuiteApp only if you want to use Tax Reporting Framework. This SuiteApp provides the permissions, setup options, and tax reporting features to country tax reports. To install, see [Installing Tax Reporting Framework](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1528245293.html).
    
-   **Electronic Bank Payments** - You should install this SuiteApp only if you want to be able to generate payment files for your bank. Charges may apply if you need to produce files for multiple countries. This SuiteApp enables you to process bank payments of your vendor bills, employee expenses, partner and employee commissions, and customer refunds, and also enables you to produce direct debit files. To install, see [Electronic Bank Payments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N1585433.html).
    
-   **EMEA Localization SuiteApp** - A required SuiteApp. To install the United Kingdom Localization SuiteApp, you must first install the EMEA Localization SuiteApp. This SuiteApp provides the framework for local VAT reports in SuiteTax and other EMEA-specific functionality. For more information, see [Installing the EMEA Localization SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157201390489.html).
    

For more information about installing SuiteApps, see [Installing a Bundle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3395142.html).

## Enabling Features for United Kingdom Localization {#bridgehead_158857801153}

To install United Kingdom Localization and use UK-specific functionality, you must enable the required features.

Note:

Some of the required features have already been enabled when you have installed the EMEA Localization SuiteApp.

#### Enabling required features:

1.  Go to _Setup > Company > Setup Tasks > Enable Features_.
    
2.  (Optional) On the **Company** subtab, check the **Multiple Currencies** box.
    
3.  (Optional) On the **Transactions** subtab, check the **Purchase Orders** box.
    
4.  On the **Tax** subtab, check the **SuiteTax** box.
    
5.  On the **SuiteCloud** subtab, check the following boxes:
    
    -   Custom Records
        
    -   Advanced PDF/HTML Templates
        
    -   Client SuiteScript
        
    -   Server SuiteScript
        
6.  Click **Save**.
    

Important:

If the Multiple Currencies feature is disabled, some reports may not work as intended. For more information, see [Using United Kingdom Localization with the Multiple Currencies Feature Enabled](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_163516121417.html).
