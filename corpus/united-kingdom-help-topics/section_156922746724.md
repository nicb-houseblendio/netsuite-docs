Important:

To use this feature, you must have the [Electronic Bank Payments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N1585433.html) SuiteApp installed in your NetSuite account. This SuiteApp already contains several payment formats common in the United Kingdom. However, without the [United Kingdom Localization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157131293913.html) SuiteApp installed in your NetSuite account, these formats won't be regularly updated. Also, the United Kingdom Localization SuiteApp delivers additional payment templates that are not provided by the Electronic Bank Payments SuiteApp.

The United Kingdom Localization SuiteApp delivers several payment formats used by the Electronic Bank Payments SuiteApp. To use this feature, you must have the [Electronic Bank Payments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N1585433.html) SuiteApps installed in your NetSuite account.

For more information, see [Prerequisites for Installing the United Kingdom Localization SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157131471666.html).

The Electronic Bank Payments SuiteApp lets businesses in the United Kingdom to pay vendor bills, employee expenses, and customer refunds within the United Kingdom by generating payment files formats.

The United Kingdom Localization SuiteApp supports the following payment file formats:

| Payment Formats | Notes |
| --- | --- |
| BACSTEL - IP (internet service variation of BACS) | Compatible with the BACSTEL-IP format used by NatWest and RBS. |
| BACS - Albany ALBACS-IP (Albany ePAY Bureau) | Applicable to Albany ePAY Bureau, Barclays Bank, and (BACS Multiple Fixed Length) Lloyds Bank. No customization needed for Barclays customers. |
| BACS - Bank of Ireland |  |
| BACS - Bank of Scotland (Bank of Scotland PLC) |  |
| BACS (standard 18) | Applicable if your bank uses the original variation of the BACS payment file format specification of BACS Payment Schemes Limited. (for example, HSBC). |
| HSBC Faster Payments | XML 20022 |
| HSBC Faster Payments | CSV for manual upload. |
| HSBC UK CHAPS | XML 20022 |
| HSBC UK BACS | XML 20022 |
| HSBC UK BACS | CSV for manual upload. |
| HSBC BACS or Faster Payments | XML 20022 |
| SVB BACS | Needs to be submitted directly through Transact Gateway using the SFTP Connector SuiteApp. For more information, see [SFTP Connector SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_159722755550.html): |
| SVB CHAPS | Needs to be submitted directly through Transact Gateway using the SFTP Connector SuiteApp. For more information, see [SFTP Connector SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_159722755550.html): |
| SEPA Credit Transfer (ABN AMRO) |  |
| SEPA Credit Transfer (HSBC) | XML 20022 |
| SEPA Credit Transfer (SVB) | Needs to be submitted directly through Transact Gateway using the SFTP Connector SuiteApp. For more information, see [SFTP Connector SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_159722755550.html): |
| SVB Faster Payments | Needs to be submitted directly through Transact Gateway using the SFTP Connector SuiteApp. For more information, see [SFTP Connector SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_159722755550.html): |
| SVB BACS or Faster Payments | Needs to be submitted directly through Transact Gateway using the SFTP Connector SuiteApp. For more information, see [SFTP Connector SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_159722755550.html): |
| HSBC UK International | XML 20022 Note: Be sure to enter either **Account Number** or **IBAN** and **Bank Code** or **SWIFT/BIC Code** in the Entity Bank Details to prevent validation errors. |
| Lloyds BACS | Applicable for submission in Commercial Banking Online portal only. |
| SVB BACS, MULTIBACS or Faster Payments | Combines three payment types: BACS, MULTIBACS and Faster Payments. You can choose which one to use using the dropdown field in the Company Bank Details record. |

Additional payment formats for EMEA countries are delivered by EMEA Localization SuiteApp (which is a prerequisite for the United Kingdom Localization SuiteApp). For more information, see [EMEA Localization Payment Templates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158858392029.html).
