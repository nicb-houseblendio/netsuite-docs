If you are using Tax Reporting Framework, you can generate the following United Kingdom-specific tax reports:

-   [Periodic VAT Return - VAT100](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156775976739.html)
    
    [Periodic VAT return - VAT100 (pre-2021)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161132411599.html)
    
    -   If you want to import a custom created VAT return report to NetSuite, see [UK Submit VAT Return via CSV](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162643004330.html)
        
    -   You can submit the United Kingdom VAT100 Return directly to HMRC's Making Tax Digital (MTD) system. For more information, see [Making Tax Digital](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1555090419.html).
        
    -   To view a list of error scenarios that lead to submission errors of your United Kingdom VAT100 Return to HMRC's Making Tax Digital system, see [Making Tax Digital: Submission Errors in Tax Reporting Framework](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1552967912.html).
        
-   [United Kingdom Intrastat](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_157164884789.html) - For information about the codes required in the Intrastat declaration, see [United Kingdom Nature of Transaction Code](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_159065700009.html).
    
-   [EC Sales List](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_156888850442.html) - It can be exported in PDF, XLS, and CSV formats. CSV format can be used for bulk upload on the HMRC portal.
