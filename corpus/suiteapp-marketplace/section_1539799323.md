You can install SuiteApps to your account to take advantage of customizations and settings that are useful for your organization.

Important:

Some SuiteApps installed from the SuiteApp Marketplace can be managed SuiteApps. By installing the managed SuiteApp, you're giving the publisher or solution provider permission to upgrade it at any time. Upgrades for managed SuiteApps are pushed automatically to your account.

Consider the following information regarding SuiteApp installation:

-   The most recent version of the SuiteApp that works with your account is installed.
    
-   If you don't want a SuiteApp after it's installed, you can uninstall it from the Installed SuiteApps page.
    
-   Objects included in the SuiteApp are created in your NetSuite account.
    
-   Validation is performed before installation. For more information, see [SuiteCloud Project Validation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4719750997.html).
    
-   You can start installing more SuiteApps while others are still in progress. SuiteApps install in the order you click Install.
    
-   Although SuiteApp bundles are listed in the SuiteApp Marketplace, you must install them from the Bundle Details page.
    
-   For the SuiteApp to install successfully, your role needs the necessary permissions for any custom components in the SuiteApp. If you get a `Permission Violation` error, switch to a role with those permissions and try again.
    
-   The SuiteApp that you want to install might include terms of service (ToS). To continue with the installation, you are required to read and accept the terms of service.
    

#### To install a SuiteApp from the SuiteApp Marketplace:

1.  Go to SuiteApps.
    
    Note:
    
    The SuiteApps menu isn't available for these centers:
    
    -   Advanced Partner Center
        
    -   Customer Center
        
    -   Employee Center
        
    -   Partner Center
        
    -   Support Center
        
    -   Vendor Center
        
    
2.  From the list, find the SuiteApp you want to install and click its tile. The SuiteApp details page appears.
    
3.  In the top right of the SuiteApp details page, click one of the these actions:
    
    -   **Install** (for SDF SuiteApps)
        
        (Optional) SuiteApp Terms of Service window appears. To continue with the installation process, you are required to read and accept the terms of service.
        
    -   **View SuiteApp** (for SuiteApp Bundles)
        
    
    The installation process begins.
    
    Installation of a SuiteApp may take some time.
    
    To check the installation status, see [Viewing SuiteApp Installation or Uninstallation Status](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1539867271.html).
    
    Important:
    
    Although SuiteApp bundles are listed in the SuiteApp Marketplace, you must install them from the Bundle Details page. When viewing a SuiteApp bundle on the SuiteApp details page, click **View SuiteApp** to view and install it from the Bundle Details page. For more information, see [Installing a Bundle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3395142.html).
    
    Note that you might see these messages instead of the Install action:
    
    -   If you see Not Compatible instead of Install, your NetSuite account doesn't support the SuiteApp. This usually means the SuiteApp doesn't support your NetSuite version.
        
    -   If you see Limited Access instead of Install, you don't have permission to install the SuiteApp.
