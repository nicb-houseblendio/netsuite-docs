The SuiteApp status shows the current state of the SuiteApp workflow after you start an install, upgrade, or uninstall.

You can see some SuiteApp states in the SuiteApp Marketplace, but all states are visible on the Installed SuiteApps page.

To check the SuiteApp installation status in the SuiteApp Marketplace, go to SuiteApps. Click the SuiteApp tile you want, and you'll see the status in the top right of the details page.

Only these states can show up on the SuiteApp details page in the SuiteApp Marketplace:

-   **Installation Failed** - The SuiteApp failed to install. Check the installation log for details. For more information, see [Deployment Logs for SuiteCloud Projects](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4715369474.html).
    
-   **Installing** - The SuiteApp is currently being installed.
    
-   **Installed** - The SuiteApp was installed successfully. If an upgrade fails validation, you'll still see this state because the previous version is still working.
    
-   **Validation Failed** - The SuiteApp didn't pass validation, so it wasn't installed. If it's a new install, nothing changes in your account. If it's an upgrade, the previous version is still installed and working. Check the installation log for more info. For more information, see [Deployment Logs for SuiteCloud Projects](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4715369474.html).
    

You can see more intermediate states on the Installed SuiteApps page by going to _Customization > SuiteCloud Development > Installed SuiteApp List_. For more information, see [Viewing and Uninstalling SDF SuiteApps in a NetSuite Account](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4849371107.html) and [Deployment Logs for SuiteCloud Projects](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4715369474.html).
