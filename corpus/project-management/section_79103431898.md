You must have the following modules and features to use the Project Cost-to-Cost Percent Complete SuiteApp:

Note:

You can use the Project Cost-to-Cost Percent Complete SuiteApp only in **[NetSuite OneWorld](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/preface_1540397395.html)** accounts.

## Required Modules {#bridgehead_79121930869}

You must have the following modules in your account to use the Project Cost-to-Cost Percent Complete SuiteApp:

-   Project Management SKU
    
-   Project Accounting and Management Module
    
-   Advanced Revenue Management (Essentials) Module
    

If you don't have these modules, contact NetSuite Customer Support.

## Enable Features {#bridgehead_11122107879}

You must enable the following features using the Administrator role:

1.  Go to Setup > Company > Enable Features.
    
2.  Check the box for each of the following features.
    
    | Subtab | Feature Name |
    | --- | --- |
    | **Company** | 
    -   Projects
    -   Project Management
    
     |
    | **Accounting** | 
    
    -   Accounting
    -   Accounting Periods
    -   Advanced Revenue Management (Essentials)
    
     |
    | **Analytics** | 
    
    -   SuiteAnalytics Workbook
    
     |
    | **SuiteCloud** | 
    
    -   Custom Records
    -   Client SuiteScript
    -   Server SuiteScript
    
     |
    
3.  Click **Save**.
