You can set a default invoice presentation template (IPT) for a subsidiary on the IPT Preference page. You can select a default template from the IPTs that are assigned to the subsidiary and IPTs that are not assigned to any subsidiary. For more information, see [Setting Up the Invoice Presentation Template Preference](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164130247448.html).

The SuiteApp provides you the flexibility to select your desired IPT for a customer, project, or invoice if you do not want to set a default IPT for a subsidiary.

For example, if you have set IPT1 as the default IPT for subsidiary A, the customers, projects, and invoices for subsidiary A will use IPT1 as default. However, this is only true if you have not changed the default IPT or changed the subsidiary on customer, project, or invoice records.

To understand the selection of default of IPT on customer, project, or invoice records work in detail, read the following sections:

## Customer Record {#bridgehead_164130291789}

The IPT set as default for a subsidiary is used as default for the customers associated with the subsidiary.

If no default IPT has been set for the subsidiary selected for the customer, no IPT is used as default. You can always select or change the IPT from the **Invoice Presentation Template** field.

#### To assign an invoice presentation template to a customer:

1.  Go to the customer record.
    
2.  Click the **Classification** subtab.
    
3.  From the **Primary Subsidiary** field, select a subsidiary.
    
4.  Click the **Financial** subtab.
    
5.  From the Account Information section, select an IPT from the **Invoice Presentation Template** field.
    
6.  Click **Preview**.
    
7.  Click **Save**.
    

## Project Record {#bridgehead_164130293751}

The IPT set as default for a customer is used for the projects associated with the customer.

However, if no default IPT has been set for a customer or the subsidiaries in the customer and project are different, the IPT associated with the subsidiary selected on the project is used as default.

If no default IPT has been set for the subsidiary selected on the project, no IPT is used as default.

You can always select or change an IPT from the **Invoice Presentation Template** field.

#### To assign an invoice presentation template to a project:

1.  Go to the project.
    
2.  Click the **Classification** subtab.
    
3.  Select the subsidiary on the **Primary Subsidiary** field.
    
4.  Click the **Financial** subtab.
    
5.  From the Billing Information section, select an IPT from the **Invoice Presentation Template** field.
    
6.  Click **Preview**.
    
7.  Click **Save**.
    

## Invoice Record {#bridgehead_164130294512}

The IPT set as default for a project is used as default for the invoices associated with the project.

However, if no default IPT has been set for a project or the subsidiaries in the project and invoice are different, the default IPT associated with the customer selected on the invoice is used as default.

If no default IPT has been set for the customer or the subsidiaries in the customer and invoice are different, the default IPT associated with the subsidiary selected on the invoice is used as default.

If no default IPT has been set for the subsidiary selected for the invoice, no IPT is used as default.

You can always select or change an IPT from the **Invoice Presentation Template** field.

#### To assign an invoice presentation template to an invoice:

1.  Go to the invoice.
    
2.  Click the **Billing** subtab.
    
3.  In the Billing Address section, from the **Invoice Presentation Template** field, select an invoice presentation template.
    
4.  Click **Preview**.
    
5.  Click **Save**.
    

## Generating an Invoice without an Invoice Presentation Template {#bridgehead_164598900355}

To generate an invoice without an invoice presentation template (IPT), set the **Invoice Presentation Template** field to blank.
