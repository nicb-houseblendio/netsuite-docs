The default values for **Department**, **Class**, and **Location** fields are set from the project, the line level, or left blank. The selection of these default values in a transaction is based on the following criteria:

| Transaction | Channel | Navigation Path | Project Classification - Department, Class, and Location Values |
| --- | --- | --- | --- |
| Bill Credit | UI | Transactions > Payables > Enter Vendor Credits | Expense Sublist
-   Project
-   Blank

Item Sublist

-   Item
-   Blank

-   Item
-   Blank

-   Item
-   Blank
