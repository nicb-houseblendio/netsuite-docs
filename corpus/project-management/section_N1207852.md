Note:

If your account has the SuiteAnalytics Connect feature enabled, you also can use external reporting tools such as Crystal Reports and Microsoft Excel to report on project tasks data. See [SuiteAnalytics Connect Access to Project Tasks Data](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1214805.html).

For quick access to project report information, add a snapshot for any Project Management reports to your dashboard. See [Adding a Report Snapshot Portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N626371.html) and [Standard Report Snapshots Table](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N626685.html).
