Name of the **Actual Cost** column should always contain the language specific label in the **Project Profitability** configuration in Setup > Accounting > Project Profitability:

| Language | Actual Cost |
| --- | --- |
| Chinese (Simplified) | 实际成本 |
| Chinese (Traditional) | 實際成本 |
| Czech | Skutečné náklady |
| Danish | Faktisk omkostning |
| Dutch | Werkelijke kosten |
| English (U.S.) | Actual Cost |
| Finnish | Toteutuneet kustannukset |
| French | Coût réel |
| French (Canada) | Coût réel |
| German | Istkosten |
| Indonesian | Biaya Aktual |
| Italian | Costo effettivo |
| Japanese | 実績原価 |
| Korean | 실제 비용 |
| Norwegian | Faktisk kostnad |
| Portuguese (Brazilian) | Custo real |
| Russian | Фактические затраты |
| Spanish | Costo real |
| Spanish (Latin America) | Costo real |
| Swedish | Faktisk kostnad |
| Thai | ต้นทุนตามจริง |
| Turkish | Fiili Maliyet |
| Vietnamese | Chi phí thực tế |
