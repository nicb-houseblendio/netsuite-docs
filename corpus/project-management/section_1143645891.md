If you create a transaction in the UI, the **Department**, **Class**, and **Location** values from the project you pick at the line level update the header fields. Any other fields are left blank. Only active values get updated.

If you create a transaction from other channels, the active project's **Project Classification Department**, **Project Classification Class**, and **Project Classification Location** update the header fields, but only if those fields are blank.

In **Create** mode, the last updated line of the transaction is copied to the header.

The **Department**, **Class**, and **Location** values at the header only update if they're empty.

No default values are pulled from other segments or what you enter manually.

If you select a project at the header, the header **Department**, **Class**, and **Location** values are replaced with active **Project Classification Department**, **Project Classification Class**, and **Project Classification Location** values of the project.

Note:

For more information about other channels, see [CSV Imports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/book_4470700566.html), [REST Web Services](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158022624537.html), and [SOAP Web Services Traffic Health](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_157167127021.html).
