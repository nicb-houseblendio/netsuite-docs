When you enable Advanced Project Budgets, a new Project Work Breakdown Structure (WBS) subtab becomes available on project records. A work breakdown structure (WBS) separates the work on a project into parts, called work items. You can assign values to every work item, revenue, and cost. When you fill an estimate to complete values for cost and revenue, you can save the work breakdown structure and convert it to a budget. You can choose a global or monthly timeline type. Global timeline is the default option. The monthly timeline enables you to select a start and end date for the WBS. The values from the budget appear in the [Budget vs. Actual Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2097218.html).
