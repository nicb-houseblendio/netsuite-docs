You can view a project complete execution log from the Project Percent Complete Execution Log List page, which shows the audit trails.

#### To view a project complete execution log:

1.  Go to the Project Percent Complete Execution Log List page.
    
    1.  (Administrator) Go to Transactions > Customers > Percent Complete Execution Log.
        
    2.  (Accountant) Go to Financial > Lists > Percent Complete Execution Log.
        
2.  The log shows details such as **Name**, **ID**, **Executed By**, **Executed On**, **Progress**, and **Context**.
    
    Note:
    
    The progress status could be:
    
    -   Failed
        
    -   Completed
        
    -   Not Started
        
    -   In Progress
        
    
    The progress status is **Completed** after the total or partial success of the execution of projects. The status is **Failed** if the execution of all projects fails.
    
    You can see read-only details after the status is **Completed**.
    
    Note:
    
    **Executed By** column will be empty if the project ran through other channels.
    
    Note:
    
    **Context** is the channel of execution of the project. It displays one of the following options:
    
    -   UI
        
    -   Other Channels
        
    
    For more information about the other channels, see [CSV Imports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/book_4470700566.html), [REST Web Services](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158022624537.html), and [SOAP Web Services Traffic Health](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_157167127021.html).
    
3.  Click **View** to view the project complete execution log.
    

The **Project Filters** subtab and **Project Details** sublist displays for the project complete execution log.

Note:

The **Project Filters** subtab is similar to the one on the Update Project Cost Percent Complete page. The following fields are added to the Project Execution Log page:

-   **Name** - This is automatically generated and includes the accounting period plus a variable that goes up each time projects run for the same period.
    
-   **Log ID** - This is the execution log ID, and you'll also get it in the email notification after execution.
