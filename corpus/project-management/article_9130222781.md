The Project Classification SuiteApp enables organizations to associate their projects with financial segments such as **Project Classification Department**, **Project Classification Class**, and **Project Classification Location**. You can use these segments as default values in transactions. You can also show the correct cost or profit center to ensure your financial reports are accurate.

Watch the following video for information about the Project Classification SuiteApp.

<a id="kaltura_player_101"></a>

## Project Classification Features {#bridgehead_13144900754}

The Project Classification SuiteApp enables you to:

-   Assign financial segments such as **Project Classification Department**, **Project Classification Class**, and **Project Classification Location** to the project.
    
-   Filter segments based on the project subsidiary.
    
-   Use these segments as default values in a list of transactions when you select the related project, whether created through the UI or other channels.
    
-   Override any default values on transactions with the segments linked to your projects.
    
-   Get accurate and robust project finances.
