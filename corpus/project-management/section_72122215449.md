Before using the Project Cost-to-Cost Percent Complete SuiteApp, be aware of the following limitations:

-   You can only create the project's cost-to-cost rule in the NetSuite UI.
    
-   The **Actual Cost** column name should always contain the language-specific label in the **Project Profitability** configuration in Setup > Accounting > Project Profitability. For more information, see [Language Specific Actual Cost Label](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_98113109087.html).
    
-   Don't select more than about 5,000 (approximately) projects for execution at one time.
    
-   To use the **Project Percent Complete Actual Labor** dataset, enable the **Require Approvals on Time Records** and **Advanced Approvals on Time Records** features in Setup > Accounting > Accounting Preferences > Time & Expenses.
    
-   If the role doesn't have permission to access particular custom records, transactions, and standard permissions, and if you want to access the datasets created from those transactions, you can provide access in the following ways:
    
    -   If the custom records, custom transactions, and standard permissions aren't locked, edit the custom record or transaction and give permission to **Project Cost Percent Complete Internal Role**. Click **Save**.
        
    -   If the custom records, custom transactions, and standard permissions are locked:
        
        1.  Go to Setup > Users/Roles > Manage Roles.
            
        2.  **Customize** the **Project Cost Percent Complete Internal Role**.
            
        3.  Click **Permissions** subtab.
            
        4.  Select the transaction from the **Transactions** sublist and the custom record from the **Custom Record** sublist.
            
        5.  Click **Add**.
            
        6.  Click **Save**.
            
        7.  Go to Customization > Scripting > Script Deployments.
            
        8.  Edit the **C2C\_SL\_Dataset\_Handler** script.
            
        9.  Select the newly customized role as **Execute as Role**.
            
        10.  Click **Save**.
             
-   When a project is executed through other channels, the email notification will always be in English and not translated.
    
-   Projects with inactive customers are not supported.
