Configure the project classification preferences from the Project Classification page:

#### To configure Project Classification Preferences:

1.  Go to Setup > Accounting > Project Classification.
    
2.  To select all transactions, check the **Select All Transactions** box.
    
3.  For each transaction, check the **Apply On Select** or **Apply After Save** box based on your requirements.
    
    ![Project Classification Preferences Page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Projects/project_classification_preferences_new.png)
    
    Note:
    
    Select **Apply On Select** if the record will be created using the UI.
    
    Select **Apply After Save** if the record will be created using other channels (such as a CSV file or web service).
    
4.  To update **Department**, **Class**, and **Location** on the header when the project is at line level, check the **[Update Header Based on Line](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1143645891.html)** box.
    
5.  Click **Save**.
