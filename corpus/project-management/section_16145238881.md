You must have the following modules and enable the following features to use the Project Classification SuiteApp.

## Required Modules {#bridgehead_97113701515}

You must have the following modules in your account to use the Project Classification SuiteApp:

-   Project Management SKU
    
-   Project Accounting and Management Module
    

If you don't have these modules, contact NetSuite Customer Support.

Note:

You can use the Project Classification SuiteApp only in **[NetSuite OneWorld](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/preface_1540397395.html)** accounts.

## Enable Features {#bridgehead_48113840147}

You must enable the following features using the Administrator role:

1.  Go to Setup > Company > Enable Features.
    
2.  Check the box for each of the following features.
    
    | Subtab | Feature Name |
    | --- | --- |
    | **Company** | 
    -   Departments
    -   Locations
    -   Classes
    -   Projects
    -   Project Management
    
     |
    | **SuiteCloud** | 
    
    -   Custom Records
    -   Client SuiteScript
    -   Server SuiteScript
    
     |
    
3.  Click **Save**.
