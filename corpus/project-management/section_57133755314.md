The segments you select in a project are used as default values in transactions. If the project doesn't have some or all values, it uses default values from other records or leaves them blank, depending on the transaction.

## Supported Transactions {#bridgehead_23113508396}

The SuiteApp supports the following transactions.

-   Bill Credit
    
-   Cash Sale
    
-   Credit Memo
    
-   Estimates
    
-   Expense Report
    
-   Inventory Adjustment
    
-   Invoice
    
-   Journals
    
-   Project Charges
    
-   Purchase Order
    
-   Revenue Arrangement
    
-   Sales Order
    
-   Time Entry
    
-   Vendor Bill
    
-   Weekly Timesheet
    
-   Write Check
    

For more information regarding the supported transactions, refer to [Selecting Default Values in a Transaction](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_43124847143.html).

## Transaction Modes {#bridgehead_45113722110}

The SuiteApp supports the following transaction modes.

-   Create
    
-   Edit
    
-   Copy
    
-   Transform
