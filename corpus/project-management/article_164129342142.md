The Invoice Presentation Template (IPT) SuiteApp provides project-based businesses the flexibility to present data in multiple formats using invoice presentation templates. The SuiteApp also lets you add different levels of details about charges on invoices.

## Features {#subsect_0722025226}

The IPT SuiteApp lets you:

-   Select default invoice print, email, and presentation templates for a subsidiary. To learn more, see [Setting Up the Invoice Presentation Template Preference](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164130247448.html).
    
-   Create, copy, edit, delete, and view an invoice presentation template. To learn more, see [Working with the Invoice Presentation Template SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164130255906.html).
    
-   Configure charge tables to display charges incurred on a project. To learn more, see [Configuring a Charge Table](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164733940925.html).
    
-   Assign an invoice presentation template to a subsidiary, customer, project, or invoice. To learn more, see [Assigning Invoice Presentation Templates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164130288184.html).
    
-   Include expense receipts on an invoice. To learn more, see [Including Expense Receipts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164783492549.html).
    
-   Preview the invoice presentation template on customer, project, and invoice records. To learn more, see [Previewing Invoice Presentation Templates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164559825013.html).
    
-   Print and email invoices with charge details. To learn more, see [Printing and Emailing Invoices with Charge Details](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164130310830.html)
