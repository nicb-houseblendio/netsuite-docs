You can install the Invoice Presentation Template (IPT) SuiteApp from the SuiteApp Marketplace.

#### To install the SuiteApp:

1.  Go to the **SuiteApps** tab.
    
2.  In the **Search Apps** field, enter **Invoice Presentation Template SuiteApp**.
    
3.  Click the Invoice Presentation Template SuiteApp tile.
    
4.  In the top right of the Invoice Presentation Template SuiteApp details page, click **Install**.
    

The IPT SuiteApp is managed, so it updates automatically when there are new features or improvements.

The SuiteApp provides Invoice Presentation Print and Invoice Presentation Email templates, enabling you to display invoice presentation features on invoices. Refer to the steps in the [Prerequisites](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164758898994.html) section to select these templates in your preferred invoice transaction form.
