You can print or email invoices with charge details using an invoice presentation template (IPT). When you print or email an invoice with charges, the footer information about an IPT matches with the selected default templates for the subsidiary.

To successfully print or email invoices with charge details successfully, make sure the following tasks are performed:

-   Complete the prerequisites of using the Invoice Presentation Template SuiteApp. For more information, see [Prerequisites](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164758898994.html).
    
-   Select default invoice print and email templates for a subsidiary on the IPT Preference page. The SuiteApp continues to use the default templates even when the subsidiary is inactivated provided the set up is done before inactivation. For more information, see [Setting Up the Invoice Presentation Template Preference](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164130247448.html).
    
    If already selected, ensure that the default templates are not missing or deleted.
    
-   You must select an IPT at the subsidiary, customer, project, or invoice level.
    

If you have marked the root subsidiary inactive before setting the default templates, a warning message appears.
