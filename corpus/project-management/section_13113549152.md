Before using the Project Classification SuiteApp, be aware of the following limitations:

-   The **Project Charges** and **Revenue Arrangement** transactions are disabled in the Project Classification Preferences page for transactions using the UI.
    
-   **Weekly Timesheet** transaction is disabled in the Project Classification Preferences page for transactions using other channels.
    
-   Default values update only when you create a **Revenue Arrangement** from the project.
    
-   The Project Classification SuiteApp doesn't support custom roles with department, class, or location segment restrictions.
