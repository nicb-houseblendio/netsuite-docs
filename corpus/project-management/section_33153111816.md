To run a project from the Update Project Cost Percent Complete page, complete the following steps.

#### To update a Project Cost Percent Complete in the UI:

1.  Go to the Update Project Cost Percent Complete page.
    
    1.  (Administrator) Go to Transactions > Customers > Project Cost Percent Complete.
        
    2.  (Accountant) Go to Financial > Lists > Project Cost Percent Complete.
        
2.  On the **Project Filters** subtab, from the **Subsidiary** list select the required subsidiaries.
    
    Note:
    
    Subsidiaries for your role are available and selected automatically.
    
3.  (Optional) Select **Project**, **Customer**, and **Project Manager**.
    
    Note:
    
    The project list is filtered by the **Subsidiary**, **Customer**, and the **Project Manager** selected.
    
    Projects with **Pending** or **In Progress** status appear on the Updating Project Cost Percent Complete page if you've checked **Enable Project Cost-to-Cost Percent Complete** on their Project page.
    
    Note:
    
    Only employees with the **Project Manager** box checked in Lists > Employees > Employees > Human Resources appear in the **Project Manager** list.
    
4.  In the **Period** list, select the accounting period.
    
5.  Check the **Allow Reexecution** box to show only projects run in the selected period. This applies to all projects in the **Project Details** sublist.
    
    Note:
    
    A project is reconsidered for processing when:
    
    -   The **Percent Complete Override** sublist under the **Financial** subtab in the Project record is updated manually with the correct accounting period, with or without the **Cumulative Percent Complete** value.
        
    -   The project is submitted for processing with a **Percent Complete** value (not an em-dash) from the Update Project Cost Percent Complete page.
        
    
    Note:
    
    The **Allow Reexecution** box is checked by default. If it's not checked, you'll only see projects that haven't been run before for that accounting period.
    
    If **Allow Reexecution** is checked and there's no accounting period entry, the period was either deleted from the project or the project hasn't been processed yet.
    
6.  Check the **Allow Percent Complete Override** box so you can edit the **Percent Complete** and **Override Reason** columns in the **Project Details** sublist.
    
7.  Submit the projects.
    
    1.  Click **Submit** to submit the selected projects in the **Project Details** sublist. You must select at least one project.
        
    2.  Click **Submit All** to submit all the projects in the **Project Details** sublist.
        

The **Project Details** sublist provides a detailed view of each project with the following columns:

-   Project
    
-   Customer
    
-   Subsidiary
    
    Note:
    
    You can sort project details by **Project**, **Subsidiary**, and **Customer** columns.
    
-   Last Execution Period
    
-   Last Percent Complete
    
    Note:
    
    The **Last Execution Period** and **Last Percent Complete** columns are populated using the **Accounting Period** and **Cumulative Percent Complete** columns in the **Percent Complete Override** sublist.
    
    You can find the sublist on the **Project Cost-to-Cost Percent Complete** subtab under Lists > Relationship > Projects > Financial.
    
-   Cost Budget
    
-   Actual Cost
    
    Note:
    
    If you select **Custom Criteria** in the **Budget Basis** or **Actual Cost Basis** list, ensure the **Percent Complete Project**, **Percent Complete Date**, and **Percent Complete Amount** aliases are present. Map these aliases to the project type, date type, and amount type columns. For more information, see [Creating and Updating a Project Cost Percent Complete Dataset](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_48115943842.html).
    
    If the mapping is incorrect, you'll see an em dash (-) in the **Actual Cost** and **Cost Budget** columns, or a value based on other datasets.
    
    Note:
    
    If you select an inactive rule is selected for a project in the Projects page, you'll see an em dash (-) in the **Actual Cost** and **Cost Budget** columns.
    
-   Percent Complete
    
    Note:
    
    The **Percent Complete** is calculated as:
    
    Percent Complete = Actual Cost till Date/ Cost Budget
    
    Percent complete is based on the actual cost and cost budget for the project. You can edit the field if the **Allow Percent Complete Override** box is checked. The value must be numeric and from 0 to 100.
    
    Note:
    
    If the **Percent Complete** column for a submitted project contains an em dash (-), the **Percent Complete Override** sublist isn't updated for that accounting period in the project record. Since the sublist isn't updated in the project record, the project will not be considered for further processing.
    
-   Override Reason
    
    Note:
    
    Enter your reason for overriding the project completion percentage (up to 99 characters).
    

An email is sent to the user after processing, with details of which projects succeeded and which failed.

Note:

For processing through the UI channel, enter a **From Email Address** in Home > Set Preferences. The entered email in **From Email Address** is used as the author, and the logged-in user's email remains the recipient. If left blank, the logged-in user's email is used as both the author and recipient.

Note:

All projects for an execution ID will fail to process in the following scenarios:

-   The project's execution mode is set to other channels and the accounting period isn't available.
    
-   Only 20 users can submit project execution at one time. The remaining executions will fail, and no email will be sent for the remaining executions.
    

#### To update a Project Cost Percent Complete through other channels:

1.  Go to Customization > Scripting > Script Deployments.
    
2.  Click **Edit** for the **customdeploy\_c2c\_scheduled\_mr\_script** ID.
    
3.  Click the **Parameters** subtab.
    
4.  In the **Employee** list, select an employee whose email will be used to send the notification after project processing.
    
    Note:
    
    If there's no email address, no email will be sent.
    
5.  Click **Save**.
    

For more information, refer to [Deploying a Script by using the Script Deployment Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0706024425.html).
