You can install the Project Cost-to-Cost Percent Complete SuiteApp from the [Installing from the SuiteApp Marketplace](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1539799323.html).

#### To install the Project Cost-to-Cost Percent Complete SuiteApp:

1.  Go to **SuiteApps**.
    
2.  In the **Search Apps** field, enter **Project Cost-to-Cost Percent Complete SuiteApp**.
    
3.  Click the **Project Cost-to-Cost Percent Complete** tile.
    
4.  In the top right of the Project Cost-to-Cost Percent Complete SuiteApp details page, click **Install**.
    

The Project Cost-to-Cost Percent Complete SuiteApp is managed and updates automatically whenever there are new features or improvements.
