You can preview an Invoice Presentation Template when you create a new template, on customer, project, and invoice records. However, the data displayed on the template varies based on the record used to preview the template.

The following table illustrates the data displayed on different records:

| Record | Template Data | Footer Information |
| --- | --- | --- |
| New Invoice Presentation Template page | Static | Static |
| Customer record | Static | Derived from subsidiary |
| Project record | Static | Derived from subsidiary |
| Invoice record without charges | Static | Derived from subsidiary |
| Invoice record with charges | Real-time | Derived from subsidiary |

Note the following points when you preview a template:

-   For preview, the SuiteApp uses the default invoice template set for a subsidiary on the IPT Preference page. For more information, see [Setting Up the Invoice Presentation Template Preference](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164130247448.html).
    
-   If a subsidiary does not have a default invoice template, the SuiteApp uses the default template used by the root subsidiary. If a default template is not set for both the subsidiary and the root subsidiary, a warning message appears.
    
-   If the primary details (for example, address, telephone, and email) are unavailable for a subsidiary, the footer of the IPT will not contain the primary details during preview.
    
-   To preview an invoice presentation template (IPT), you must select a value other than **None** in one of the columns on the charge table.
    
-   If you have set the default templates for a subsidiary and then marked as inactive, the SuiteApp uses the templates for preview.
