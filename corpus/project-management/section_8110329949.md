You can install the Project Classification SuiteApp from SuiteApp Marketplace.

#### To install the Project Classification SuiteApp:

1.  Go to the **SuiteApps** tab.
    
2.  In the **Search Apps** field, enter **Project Classification SuiteApp**.
    
3.  Click the **Project Classification** tile.
    
4.  In the top right of the Project Classification SuiteApp details page, click **Install**.
    

The Project Classification SuiteApp is managed and updates automatically whenever there are new features or improvements.
