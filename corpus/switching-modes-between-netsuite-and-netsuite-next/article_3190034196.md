Note:

If you change something when viewing a list in NetSuite, the changes will be available in NetSuite Next when you switch back.

Some lists and records in NetSuite Next might not have all the features or options of the same list or record when viewing it in NetSuite. When needed, you can switch back to NetSuite to view the list or record with those features.

To switch between modes, click the **Switch list mode** button at the top of the list or record, then click the **NetSuite Next features** toggle. Note that the **Switch list mode** button only appears for saved search list views that you have created.

Note:

The Switch mode button at the top of the page only affects your current view of the list or record. If you want to switch back to NetSuite, go to the user menu and click **Exit NetSuite Next**. To learn more about the user menu, see _Ask Oracle Toolbar_.
