The following table gives an overview of calendar icons for available calendar item types. The type of icon is determined by the item type and the current status of that item.

**Event icons**

| Accepted | ![Screenshot of the NetSuite for Android Event Accepted icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteMobile/calendar_icon_event_accepted.png) |
| --- | --- |
| Tentative | ![Screenshot of the NetSuite for Android Event Tentative icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteMobile/calendar_icon_event_tentative.png) |
| Awaiting Response | ![Screenshot of the NetSuite for Android Event Awaiting Response icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteMobile/calendar_icon_event_awaiting_response.png) |

**Task icons**

| Completed | ![Screenshot of the NetSuite for Android Task Completed icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteMobile/calendar_icon_task_completed.png) |
| --- | --- |
| In progress | ![Screenshot of the NetSuite for Android Task in Progress icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteMobile/calendar_icon_task_in_progress.png) |
| Not started | ![Screenshot of the NetSuite for Android Task Not Started icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteMobile/calendar_icon_task_not_started.png) |

**Phone Call icons**

| Completed | ![Screenshot of the NetSuite for Android Phone Call Completed icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteMobile/calendar_icon_phone_call_completed.png) |
| --- | --- |
| Scheduled | ![Screenshot of the NetSuite for Android Phone Call Scheduled icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteMobile/calendar_icon_phone_call_scheduled.png) |

Note:

Cancelled events do not appear in the app.
