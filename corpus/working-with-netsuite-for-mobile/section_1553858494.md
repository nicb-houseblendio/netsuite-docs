NetSuite for Mobile enables you to configure and use all web dashboards. It also provides a native My Dashboard that serves as the center of your mobile workflow. In a browser session, configure the dashboards with mobile-supported portlets to access them on your device. You can customize the mobile dashboards to fit your workflow and tasks. For example, you can set up your Home dashboard to display a general overview of key metrics along with important reminders and your Lists dashboard contains custom searches you frequently access.

To switch dashboards, tap the current dashboard's name, then choose the one you want.

Tip:

To add a web portlet to My Dashboard, tap the Star icon on a portlet on one of the web dashboards.

For more information about how to set up and customize your dashboards, see the following help topics:

-   [Dashboards in NetSuite for iOS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158686457118.html)
    
-   [Dashboards in NetSuite for Android](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158686488368.html)
