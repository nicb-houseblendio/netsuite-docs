NetSuite for Mobile supports logging in with a biometric ID. There are some differences in biometric ID types for iOS and Android as described in the following section.

## Setting up Face and Touch ID login for iOS {#subsect_157952142008}

NetSuite for iOS supports Face and Touch ID.

#### To set up Face and Touch ID login for iOS:

1.  Be sure to enable Face and Touch ID in system settings.
    
2.  Enter your log in credentials.
    
3.  Tap **Remember Me**.
    
4.  Tap **Log in**.
    
    No further setup is required.
    

## Setting up Fingerprint Login for Android {#subsect_157952137103}

NetSuite for Android supports logging in with fingerprint.

#### To set up fingerprint login for Android: {#procedure_1556011800}

1.  Be sure to enable Fingerprint system settings.
    
2.  Enter your log in credentials.
    
3.  Tap **Remember Me**.
    
4.  Tap **Log In**.
    
5.  In the popup window, tap **OK**.
    
6.  Touch the fingerprint sensor to confirm and complete the setup.
