Note:

Please note this feature is unavailable on Android due to API restrictions enforced by Google.

Phone Call Logging lets you track all calls initiated from the iOS version of the app. Phone Call logging can also remind you to log your last call. As soon as a call ends, a popup alert reminds you to log the call. The feature is on by default. To configure the Phone Call logging feature see [Configuring Phone Call Logging in NetSuite for iOS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156163479756.html).

If you enable Phone Call Logging the Recent Calls portlet displays on your dashboard. This portlet lists your most recent outbound calls and provides a simple route to accessing all unlogged calls. See [NetSuite for Mobile Dashboards](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1553858494.html).

See the following sections for more information about phone call logging with NetSuite for iOS.

-   [Logging a Phone Call in NetSuite for iOS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158694433796.html)
    
-   [Viewing a List of Recent Calls in NetSuite for iOS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158694437054.html)
    
-   [Viewing a List of Logged Phone Calls in NetSuite for iOS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158694442765.html)
