Follow this procedure to log a phone call.

#### To log a phone call: {#procedure_4120768919}

1.  Tap on the call in the Recent Calls portlet. See [NetSuite for Mobile Dashboards](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1553858494.html).
    
2.  In the Log New Phone Call screen, enter details about the call. You can edit populated fields can if required.
    
3.  After you enter the call details, tap **Save** to log the record. This removes the call from the list of unlogged calls in the Recent Calls portlet.
    

Note:

Your administrator decides which fields you see and if they're required.

Logged calls are displayed in the Phone Calls list. If a call you recently logged is not showing in the list, refresh the screen data and check the filters you have set for that list. See [Viewing a List of Logged Phone Calls in NetSuite for iOS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158694442765.html).
