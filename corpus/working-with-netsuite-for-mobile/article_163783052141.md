My Dashboard is a native mobile dashboard that serves as the center of your mobile workflow. My Dashboard can have up to four mobile-only portlets, depending on your role and permissions. You can also add any portlet from other Dashboards by tapping the Star icon on the portlet.

You can rearrange and hide portlets on My Dashboard, see [Arranging My Dashboard in NetSuite for iOS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_163783222000.html).

The following table describes the four mobile-only portlets available with NetSuite for iOS.

Note:

The portlets you see on My Dashboard depend on your role and permissions.

| Portlet Name | Description | Screenshot |
| --- | --- | --- |
| **My Time** | Displays the amount of time to report in timer logs, and time entries you have reported this week. For more information, see [NetSuite for Mobile Time Tracking](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1554297914.html). Note: This portlet is only available if you enable the Track Time permission, and if you enable either Time Sheet or Time Tracking in your account. | ![NetSuite for iOS My Time portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteMobile/iOS_My_Time_Portlet.png) |
| **My Expenses** | Displays the number of expenses not yet reported, and the total value of outstanding expenses. For more information, see [NetSuite for Mobile Expense Reporting](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1554107695.html). | ![NetSuite for iOS My Expenses portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteMobile/iOS_My_Expenses_Portlet.png) |
| **My Approvals** | Displays the number of records awaiting your approval. For more information, see [My Approvals in NetSuite for Mobile](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1554194643.html). | ![NetSuite for iOS My Approvals portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteMobile/iOS_My_Approvals_Portlet.png) |
| **Phone Calls** | This portlet displays the last three calls initiated from your NetSuite for iOS application. Tap the Arrow icon ![NetSuite for iOS Arrow icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteMobile/iOS_View_List_icon.png) to see the full list of recent calls. Tap on any call in the list to log the call. For more information, see [Tracking Calls with Phone Call Logging in NetSuite for iOS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4120642128.html). | ![NetSuite for iOS Phone Calls portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteMobile/iOS_Phone_Calls_portlet.png) |
