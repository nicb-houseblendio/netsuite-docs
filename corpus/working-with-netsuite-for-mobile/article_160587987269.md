NetSuite for iOS enables you to use all web dashboards. If you add portlets available in NetSuite for iOS to any of your dashboards in a browser session, the portlets display on your corresponding mobile dashboard. See [Dashboard Personalization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N578457.html).

To switch between dashboards, tap the name of the currently displayed dashboard, and then tap the dashboard you want to access from the list.

The following table lists portlets available with NetSuite for iOS.

Tip:

To add a portlet to My Dashboard, tap the Star icon.

| Portlet Name | Description | Screenshot |
| --- | --- | --- |
| **Reminder** | Displays the first three reminders you would see on your browser session dashboard. To see the full list of reminders, tap the Arrow icon ![NetSuite for iOS Arrow icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteMobile/iOS_View_List_icon.png). All reminders based on a saved search display natively within the app. Reminders with a launch icon alongside them are not natively supported. In such cases, the app prompts you to view the results in a browser session. The system often includes launch icons for reminders that are generated by custom workflows. See [Setting Up Reminders](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N581945.html). | ![NetSuite for iOS Reminders portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteMobile/iOS_Reminders_portlet.png) |
| **Key Performance Indicators** | The default behavior is to display the first three KPIs from your browser session Dashboard. If you have set up headline KPIs, their settings override this behavior. tap the Arrow icon ![NetSuite for iOS Arrow icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteMobile/iOS_View_List_icon.png) to see the full list of dashboard KPIs. For more information, see [Highlighting KPIs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N600850.html). | ![NetSuite for iOS KPIs portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteMobile/iOS_KPIs_Portlet.png) |
| **KPI Scorecard** | Displays KPI scorecards as configured on your browser session dashboard. To browse through your scorecards, swipe left or right. Tap a scorecard to access the chart detail. To see your full list of KPI Scorecards, tap the Arrow icon ![NetSuite for iOS Arrow icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteMobile/iOS_View_List_icon.png). See [Adding a KPI Scorecard Portlet to a Dashboard](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N612018.html). | ![NetSuite for iOS KPI Scorecard portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteMobile/iOS_KPI_Scorecard_portlet.png) |
| **KPI Meter** | The portlet displays the first KPI Meter as configured in your browser session. To browse through your KPI meters, swipe left or right. For more information, see [KPI Meters](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N605338.html). | ![NetSuite for iOS KPI Meter portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteMobile/iOS_KPI_meter_portlet.png) |
| **Report Snapshot** | The portlet displays the first report snapshot from your browser session Dashboard. Tap the Arrow icon ![NetSuite for iOS Arrow icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteMobile/iOS_View_List_icon.png) to see your full list of report snapshots. To display report snapshots on your app, make sure that the Display Type is set to Graph in the portlet set-up options in your browser session. The app does not support the List view. For more information, see [Setting Up a Report Snapshot Portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N632502.html). | ![Screenshot of the NetSuite for iOS Report Snapshot portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteMobile/iOS_report_snapshots_portlet.png) |
| **Custom Searches** | The portlet displays the first three custom search portlets from your browser session Dashboard. Tap the Arrow icon ![NetSuite for iOS Arrow icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteMobile/iOS_View_List_icon.png) to access the full list of your custom searches. For more information, see [Displaying Saved Search Results in Dashboard Portlets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N690632.html). | ![NetSuite for iOS Custom Searches portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteMobile/iOS_Custom_Searches_portlet.png) |
| **Trend Graphs** | The portlet displays the first trend graph from your browser session dashboard. To browse through your trend graphs, swipe left or right. Tap a trend graph to access the chart detail. To see your full list of trend graphs, tap the Arrow icon ![NetSuite for iOS Arrow icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteMobile/iOS_View_List_icon.png). For more information, see [Setting Up Trend Graph Portlets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N606898.html). | ![NetSuite for iOS Trend Graphs portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteMobile/iOS_Trend_Graphs_portlet.png) |
