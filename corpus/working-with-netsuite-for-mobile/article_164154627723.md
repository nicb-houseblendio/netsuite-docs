Your expense reporting capabilities depend on your access level. See the following tables for an overview of expense reporting capabilities available for each access level.

-   [NetSuite for iOS Expense Reporting Access Levels](#subsect_164154636229)
    
-   [NetSuite for Android Expense Reporting Access Levels](#subsect_164154642929)
    

## NetSuite for iOS Expense Reporting Access Levels {#subsect_164154636229}

| Permission | Access Level | Expense Reporting Capabilities |
| --- | --- | --- |
| Expense Report | None | 
-   The My Expenses portlet is unavailable for this access level
-   Expense logging is available from the login screen

Note: To submit expense reports you need to switch to a role that includes an access level that includes the ability to create expense reports. |
| Expense Report | View | 

-   The My Expenses portlet is unavailable for this access level
-   Expense logging is available from the login screen and the My Expenses portlet

Note: To submit expense reports you need to switch to a role that includes an access level that includes the ability to create expense reports. |
| Expense Report | Create | 

-   The My Expenses portlet is available for this access level
-   Expense logging is available from the login screen and the My Expenses portlet
-   You can create and submit expense reports

 |
| Expense Report | Edit | 

-   The My Expenses portlet is available for this access level
-   Expense logging is available from the login screen and the My Expenses portlet
-   You can create, submit, and edit expense reports.

 |
| Expense Report | Full | 

-   The My Expenses portlet is available for this access level
-   Expense logging is available from the login screen and the My Expenses portlet
-   You can create and submit expense reports
-   You can edit expense reports

 |

## NetSuite for Android Expense Reporting Access Levels {#subsect_164154642929}

| Permission | Access Level | Portlet Capabilities |
| --- | --- | --- |
| Expense Report | None | 
-   The My Expenses portlet is unavailable for this access level
-   Expense logging is available from the login screen

Note: To submit expense reports you need to switch to a role that includes an access level that includes the ability to create expense reports. |
| Expense Report | View | 

-   The My Expenses portlet is available for this access level
-   Expense logging is available from the login screen and the My Expenses portlet
-   Creating expense reports is not permitted

Note: To submit expense reports you need to switch to a role that includes an access level that includes the ability to create expense reports. |
| Expense Report | Create | 

-   The My Expenses portlet is available for this access level
-   Expense logging is available from the login screen and the My Expenses portlet
-   You can create and submit expense reports

 |
| Expense Report | Edit | 

-   The My Expenses portlet is available for this access level
-   Expense logging is available from the login screen and the My Expenses portlet
-   You can create and submit expense reports
-   You can edit expense reports

 |
| Expense Report | Full | 

-   The My Expenses portlet is available for this access level
-   Expense logging is available from the login screen and the My Expenses portlet
-   You can create and submit expense reports
-   You can edit expense reports

 |
