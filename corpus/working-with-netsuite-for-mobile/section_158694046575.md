Follow this procedure to edit an item in your calendar.

#### To edit a calendar item:

1.  Tap the Navigation Menu icon ![Screenshot of the NetSuite for Android Navigation Menu icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteMobile/Android_menu_icon.png), and then tap **Calendar**.
    
2.  Go to the item you want to edit.
    
3.  Tap the required event to access the event detail screen.
    
4.  Tap the More icon ![Screenshot of the NetSuite for Android More icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteMobile/android_more_icon_2.png), and then tap **Edit**.
    
    Note:
    
    Only the event organizer can edit an event.
    
5.  Edit the item as required.
    
6.  To save your changes, tap the Tick icon ![Screenshot of the NetSuite for Android Tick icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteMobile/android_tick_icon.png).
