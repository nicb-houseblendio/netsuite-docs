Follow this procedure to add a shared calendar in your app.

Note:

You can only view one calendar at a time.

#### To add a shared calendar: {#procedure_4403389408}

1.  Tap the Navigation Menu icon ![Screenshot of the NetSuite for Navigation Menu icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteMobile/Android_menu_icon.png), and then tap **Calendar**.
    
2.  Tap the More icon ![Screenshot of the NetSuite for Android More icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteMobile/android_more_icon_2.png), and then tap **Customize**.
    
3.  Tap the Add icon ![Screenshot of the NetSuite for Android Add icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteMobile/android_add_icon_2.png).
    
4.  Tap the type of calendar you want to view the available calendars for that type.
    
5.  Tap the calendar you want to add.
    
6.  This adds the selected calendar to the **Calendars** list in the Customize Calendar screen, and sets it as the currently selected calendar in the calendar view.
    
7.  Tap the Back icon ![Screenshot of the NetSuite for Android Back icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteMobile/android_back_icon.png) to return to view the selected calendar.
    

Note:

You can confirm the currently selected calendar by choosing a radio button in the **Customize Calendar**.
