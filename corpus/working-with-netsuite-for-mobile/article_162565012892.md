NetSuite for Android enables you to select a list of favorite record lists that you can access from the Navigation Menu.

#### To add a record list to Favorites:

1.  Tap the Navigation Menu icon ![Screenshot of the NetSuite for Android Navigation Menu icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteMobile/Android_menu_icon.png), and then tap **Records**.
    
2.  Tap the record type you want to customize.
    
    Note:
    
    If you want to add customizations to your list, add them before setting the list as your favorite. For more informations, see [Customizing a List in NetSuite for Android](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_162565053492.html).
    
3.  On the record list screen, tap the More icon ![Screenshot of the NetSuite for Android More icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteMobile/android_more_icon_2.png), and then tap **Add to Favorites**.
    
4.  In the confirmation message, enter a name for your list.
    
5.  Tap **OK**.
    
    You can now access the list from the Favorites list in the Navigation Menu.
