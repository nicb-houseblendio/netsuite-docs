NetSuite Connector needs a custom field for each account to act as a storefront flag for product sync. By setting this field's value in NetSuite, you can sync data to your storefront items.

The following table lists the values that you can select for flag fields:

| Internal ID | Value | Definition | Notes |
| --- | --- | --- | --- |
| None | (blank) | Ignored by NetSuite Connector. | NetSuite Connector does not load data from NetSuite if the flag field is blank. |
| 1 | Add/Update Item | Add or update product data to the storefront. | . |
| 2 | Remove Item | Delete product or listing from storefront. | If an item is flagged as **Y**, and later you decide to delist the item, you must flag it to **N**. Note: If you are using price and quantity sync, setting the item to **Remove Item** does not delete the item from the marketplace or cart. The **Remove Item** setting only stops syncing the item. |
| 3 | Ignore Item | Ignored by NetSuite Connector. | NetSuite Connector does not load data from NetSuite if the flag field is blank. |
| 4 | Post Children as Stand-Alone | Parent of stand-alone items. **C** means post only children. | Used for NetSuite matrix item parents. Child items are posted as stand-alone (non-variation) items. NetSuite Connector needs the parent data to populate child items. This setting enables NetSuite Connector to load, but not post the parent data. To use this setting, set the parent item to **C** and child item to **Y**. |
| 5 | Post Inventory Only | Inventory-only flag. Supported only for eBay connector. | This value is used for posting only inventory updates to eBay when you do not want full product updates. |
| 6 | Post Price Only | Price-only flag. Supported only for eBay connector. | This value is used for posting only price updates to eBay when you do not want full product updates. |
| 7 | Post Price/Inventory Only | Price and inventory flag. Supported only for eBay connector. | This value is used for posting only price and inventory updates to eBay when you do not want full product updates. |

Note:

The internal ID of the flag fields defines the behavior in NetSuite Connector and in the storefront. Do not change the values that are selectable from the dropdown list. Changing the values can cause syncing issues.

For leading practices on using storefront flag field, read [Storefront Flag Field Leading Practices](#subsect_164880440040).

If you are not using one of the following marketplaces of carts, you need to create the storefront flag field manually:

-   Amazon
    
-   BigCommerce
    
-   ChannelAdvisor
    
-   eBay
    
-   Jet
    
-   Magento
    
-   Magento2
    
-   Miva
    
-   Shopify
    
-   Walmart
    
-   WooCommerce
    

To manually create a list-based storefront flag field, read [Creating a List-Based Storefront Flag Field Manually](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162980729832.html).

## Storefront Flag Field Leading Practices {#subsect_164880440040}

Follow these leading practices when using storefront flag field for syncing items from NetSuite:

-   The behavior of the flag fields is predefined in NetSuite Connector. If you create flag fields manually, ensure that you use the values and internal IDs listed in the table.
    
-   To list an item, change the item's flag field value from blank to **Add/Update Item** (or **Y**).
    
-   To remove an item, change the item's flag field value from **Add/Update Item** to **Remove Item** (or from **Y** to **N** ).
    
-   Do not change the flag field from blank to **Remove Item** (or **N**). This change can cause errors.
    
-   To remove an item, do not change the flag field from **Add/Update Item** (or **Y**) to blank.
    
-   When using matrix items in Price/Qty sync, don't sync the parent item. Set the child item flag field to **Add/Update Item** (or **Y**).
    
-   When using matrix items in full product sync, set the flag fields of both parent as well as child items to **Add/Update Item** (or **Y**).
    

For additional information, read the following topics:

-   For information about flagging an item to sync, read [Flagging Existing NetSuite Items to Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162929018121.html).
    
-   For information about creating flag fields, see [Creating a Flag Field for Product Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162943431179.html)
