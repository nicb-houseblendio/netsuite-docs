The NetSuite Connector dashboard displays information that helps you determine the stage of processing of your order. You can also use advanced filters to narrow down the orders you see on the dashboard.

Advanced view filters are different from order filters. Order filters decide which orders are imported from your storefront (or NetSuite, if you're using a 3PL connector).

## Order Status {#bridgehead_162737593449}

The following are the order statuses:

-   **Scheduled to Post to NetSuite** - Appears when an order is in queue to post to NetSuite. This status appears in the following cases:
    
    -   When an order is first imported into NetSuite Connector and it tries to send it to NetSuite.
        
    -   When there was an error with an order before, and you're trying to send it again with the latest batch of orders.
        
-   **Error Posting to NetSuite** - Appears when there is an error posting an order to NetSuite. Hover the pointer over this error to view details.
    
-   **Order Posted, Waiting for Shipment** - Appears when the order successfully posts from your storefront to NetSuite. NetSuite Connector then checks if the order has been fulfilled. If it has, NetSuite Connector sends the fulfillment data back to your storefront. If you can't find the order in NetSuite, click **Show NetSuite Transaction ID** to see the NetSuite order ID.
    
-   **Error Posting Fulfillment** - Appears when there is an error posting a fulfillment to an order. The status appears in the following cases:
    
    -   A fulfillment in your 3PL failed to post to NetSuite.
        
    -   A fulfillment in NetSuite failed to post to the storefront.
        
    
    Hover over the error to see more details.
    
-   **Complete** - This status means the order has been sent from your storefront to NetSuite, and the fulfillment data has been sent back to your storefront.
    
-   **Canceled** - Orders with this status don't try to send data to NetSuite or your storefront. The orders are canceled in the following cases:
    
    -   When you click the pencil icon next to an order and then click **Cancel**.
        
    -   When you try to send an order too many times, it gets canceled automatically.
        
-   **Held** - Orders with this status do not attempt to post to NetSuite. The orders are held in the following cases:
    
    -   When you click the pencil icon next to an order with the status **Schedule to Post to NetSuite** or **Error Posting to NetSuite** and click **Hold**.
        
    -   If your account settings are set to hold orders when there are errors.
        
    
    Note:
    
    You can't hold orders that are already posted to NetSuite.
    

## Filters {#bridgehead_162788140963}

You can filter orders by clicking **Filter Orders** on the Orders page. Following are the options and the status for each option:

| Filter | Status |
| --- | --- |
| All | 
-   Scheduled to Post to NetSuite
-   Error Posting to NetSuite
-   Order Posted, Waiting for Shipment
-   Error Posting Fulfillment
-   Complete
-   Held
-   Canceled

 |
| Open | 

-   Scheduled to Post to NetSuite
-   Error Posting to NetSuite
-   Order Posted, Waiting for Shipment

 |
| Error | 

-   Error Posting to NetSuite
-   Error Posting Fulfillment

 |
| Complete | Complete |
| Canceled | Canceled |
| Held | Held |

## Advanced Order Filter {#bridgehead_162788631862}

You can also filter orders by a specific storefront field and value. For example, you can filter orders by Status/Region when the field is set to North Carolina. This will show all orders from North Carolina.

You can add more filters by clicking **Add Filter Row** to narrow down the orders you see. When you use multiple filters, an order will only show up if it meets all the filter criteria.
