There are several different types of product mappings you can create. You can find the mapping type in the left-most column on the Product Mappings page.

When creating a product mapping, you have several options to choose from:

-   **Use Default**
    
    This is the simplest type of mapping. Enter a value in the **Default Value** column. NetSuite Connector will automatically fill in the corresponding field when creating or updating products for the current channel and category. Don't use a NetSuite field name with this type, or it'll post the literal field name to the destination field.
    
-   **Item Field Mapping**
    
    This lets you map a field from NetSuite to an item field on your sales channel by entering its Field ID under the **NetSuite Field ID** column. For example, you can map **itemId** (Item Name/Number) to the SKU, or **storeDisplayName** to the title. You can also enter a default value, which will be used if the NetSuite field is empty for an item.
    
-   **Item Field Translation Mapping**
    
    Sometimes, the value you have in NetSuite for a field may not be the value you want to map to your sales channel. With this option, you can set up translations between NetSuite values and the values posted to the sales channel. When you choose Item Field Translation Mapping, the NetSuite Field ID column changes into a link. Clicking the link opens a popup where you can set up the translations
    
-   **Logic**
    
    Logic mapping uses conditional checks or other logical calculations. These are typically IF-THEN type mappings. Two more types might be displayed, even though you can't select them from the list.
    
-   **Special**
    
    The Special type appears for certain mappings that open a popup window, such as Shopify's multi-location inventory mappings. You can edit these mappings, but NetSuite Connector determines whether a field gets a special mapping.
    
-   **Custom**
    
    If NetSuite Connector support has worked on your mappings before, you might see some with this type. This means your mapping for that field is a bit unusual. If you need to edit one of these mappings, contact NetSuite Customer Support.
    
    Note:
    
    NetSuite Connector no longer supports custom mappings. Existing custom mappings will still work, but if you need to make changes, you'll need to replace them with standard mappings.
    

For an example of mapping a field please see [Mapping Required and Optional Fields for Product Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164500136779.html).
