When importing items from NetSuite, NetSuite Connector determines the set of mapping fields that should be used for the product. This process is called categorization, and you need to create mappings for the **Category** fields for each product.

After importing an item, you can see how it's categorized or the set of fields used by the item. You can use only a single category for all items at a time.

The following table provides details of category mapping for each connector type:

| Product Type or Connector | Details |
| --- | --- |
| Wayfair, OverStock, and shopping carts (such as Shopify, Magento, and others) | In shopping carts, you have two category options: Full Product Sync and Price/Qty. Full product sync category names are denoted as **<cart name>** and Price/Qty category names are denoted as **<cart name>PriceQty**. For category mapping information, read the topic [Mapping Cart Categories in NetSuite Connector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162989341143.html). |
| Marketplaces (Amazon, Walmart, NewEgg) | When using full product sync, marketplaces create one of the following:
-   Amazon creates a custom category.
-   For Walmart and NewEgg, a category is added with a name that includes the product type, like **WalmartHomeOther3.2**, if needed.

For Price/Qty mapping, the category name is the marketplace name followed by PriceQty, like **<marketplace name>PriceQty**. For example, Walmart uses the name **WalmartPriceQty**. For Amazon, the category names is **AmazonListingsPriceQty**. For category mapping information of Amazon connector, see [Amazon Listings API Categories in NetSuite Connector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1106052345.html). |
| eBay | eBay doesn't require category mappings. Products are automatically categorized based on whether they're variation items or not. Variation items, also known as matrix items, are categorized under **eBayVariations**. Standalone items are categorized under **eBayFixedPrice** category. |
