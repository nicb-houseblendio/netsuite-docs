NetSuite lets you assign or map the quantity available to your marketplace or cart. This is the total number of units for a specific SKU that are available to fill new orders. Setting a quantity buffer makes the marketplace/cart show a lower available quantity than you have in stock, helping prevent overselling.

You can set up a buffered quantity in two ways:

-   **Specific amount for the buffer** - You can set a specific buffer amount, like 50, which would make the quantity posted to the marketplace/cart 50 less than what's available in NetSuite.
    
-   **Percentage-based amount buffer** - You can also set a percentage-based buffer, like 50%, which would make the quantity posted to the marketplace/cart 50% of what's available in NetSuite.
    

You can do this using arithmetic mapping. For more information about arithmetic mapping, see [Configuring Quantity Calculations Before Sync in NetSuite Connector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162936679890.html).

You can also set up a box on your items to decide if the buffered quantity mapping applies to that item. If the box is checked, the buffer applies; if not, it doesn't. You can control which items the buffer quantity mapping will affect through this box.

To set up a buffered quantity through this feature, contact NetSuite Customer Support and provide the NetSuite field ID for the box, along with two SKUs to test the mappings. One of the SKUs will have the box selected and the other not selected.
