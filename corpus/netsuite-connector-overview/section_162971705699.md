NetSuite Connector provides two types of product sync, namely, Full Product sync and Price/Quantity sync. At any given time, you can only run one type of sync per connector and account combination. This topic provides details all the sync types to enable you to decide the type of sync for your account.

Important:

You cannot switch between Price/Qty sync and Full Product sync by clicking the buttons on the Product Mappings page or the Manage Data Syncs page. If you want to change the product sync type, contact your Professional Services representative.

## Price/Quantity Sync {#bridgehead_162971756420}

Following are the key features of the price/quantity sync:

-   You can sync either price, quantity, or both.
    
-   Only items with a valid value in the designated flag field sync.
    
-   When you use Price/Quantity sync, the SKU needs to exist in the marketplace or cart for the price and quantity to sync.
    
-   Connectors with certain price tiers also include real-time price and quantity sync on supported connectors. Real-time price and quantity sync enables the price and quantity updates reach the marketplace or cart immediately without waiting for the scheduled sync to run.
    
-   The real-time sync happens on the servers, so you won't see it in the NetSuite Connector product dashboard.
    
-   You don't need to sync parent items for matrix items.
    

## Full Product Sync {#bridgehead_163402923044}

Following are the key features of the full product sync:

-   You can sync all item fields that are available through the API.
    
-   Only items with a valid value in the designated flag sync.
    
-   Don't switch to price/quantity sync if you want to send price or quantity values. If you have mapped the price and quantity fields, the values will be sent as part of the full product sync.
    
-   Each marketplace or cart defines certain set of fields required for a full product sync. Other than the required fields, you can optionally include or exclude other fields.
    
-   Not mapping a field or not populating a mapped field does not change the data for the field in the marketplace or cart. If you don't create a mapping for a field or leave it blank, NetSuite Connector won't send data for that field.
    
-   NetSuite Connector uses the SKU to sync to the existing product in the marketplace or cart. If there's no SKU, NetSuite Connector creates a new product using the available data from the mapped fields in NetSuite.
    
-   For matrix items in NetSuite, you need to set a value in the parent item's flag field.
    
-   For Amazon, values that you send for many fields must match the existing values in Amazon. If these values do not match, the sync fails and NetSuite Connector provides details on which fields should be changed and to what values. Sending the ASIN product identifier can reduce the number of fields Amazon requires to match.
    
    For more information, read [Configuring NetSuite Connector to Use Amazon Standard Identification Number (ASIN) When Posting Products on Amazon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163722737017.html).
