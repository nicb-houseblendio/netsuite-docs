This section contains best practices to ensure the proper sync of product images from NetSuite to the marketplace.

## NetSuite Configuration {#bridgehead_162885663033}

NetSuite has a built-in item image field for images. If you want to sync more images, you can create custom fields for them.

For more information about adding custom fields, read [Adding NetSuite Custom Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164440685050.html).

Ensure that your products are set up properly in NetSuite and their image fields are populated with the images or image URLs you want to sync. For more information about setting images on your NetSuite items, see [Adding Product Images for NetSuite Connector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162789570252.html).

## NetSuite Connector Configuration {#bridgehead_162885670045}

With the images set up in the NetSuite, you must update the mappings to pull the image fields into NetSuite Connector to post them to the marketplace or cart. Most connectors have a standard image field you can choose from the NetSuite Connector mapping dropdown.

## Updating Images Hosted in NetSuite {#bridgehead_162885779681}

When updating images, it's best to delete the old ones first, then add the new ones, rather than updating the existing images. If you do not delete the old images first, the marketplace or cart will not recognize that a change has been made and will keep the old image displayed. To avoid this, delete the images from NetSuite, then upload the new ones, which will reset their internal IDs.

For more information, see [Deleting Images](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2595264.html) and Uploading Images in [Images](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2592452.html).

## Preserving Existing Images in the Marketplace or Cart {#bridgehead_162885827706}

You can keep existing images by not mapping them in NetSuite Connector. With this, the syncs will not add or update the images and therefore will not update the image field in the marketplace or cart.

If you don't want to delete the image, you can clear the data in the mapped image field on the product, leaving it blank. This will stop NetSuite Connector from sending the image data.
