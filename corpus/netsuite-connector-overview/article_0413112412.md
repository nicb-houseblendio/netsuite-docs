The Enhanced Storefront Error Messages feature uses generative AI to improve error messages received from storefronts. The enhanced messages are clearer, more user-friendly, and include actionable guidance when possible.

Important:

Currently, only Shopify error messages are AI-enhanced. Support for additional storefronts is in development. This feature is enabled by default - no setup or configuration required.

## How it Works {#subsect_0413113415}

When the Shopify Connector receives an error message from Shopify, the error message is processed through an Oracle NetSuite AI service. The technical error is interpreted, rewritten in plain language, and if possible, next steps are suggested. The enhanced message is displayed in the NetSuite Connector UI along with the original error message.

This feature only affects message clarity and has no impact on connector behavior, sync logic, or data processing.

Here's an example of an enhanced error message from Shopify:

| Error Received from Shopify | AI-Enhanced Message |
| --- | --- |
| Line item price does not match variant price. | The price for this item in NetSuite doesn't match the variant price configured in Shopify. Please verify pricing in both systems or update your mapping accordingly. |
