The following SuiteApp is required when using NetSuite Connector with SuiteTax:

-   SuiteTax Engine (237702)
    

For more information, see [Installing the SuiteTax Engine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557397007.html).
