NetSuite Connector can sync item quantity updates to your storefront in the following situations:

-   If you haven't set up warehouses or locations in NetSuite, you can use the native **quantityAvailable** field or a custom field.
    
-   If you have set up warehouses or locations, you can use the quantity available in a specific warehouse
    
-   If you have multiple warehouses or locations set up, you can add up the quantity available from each one.
    

For more information about mapping inventory and quantity, see [Mapping Inventories in NetSuite Connector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162989752594.html).
