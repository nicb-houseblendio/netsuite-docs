This section describes the conditions of the sourcing strategy for Modelo 303, Modelo 349, Modelo 390, and Modelo 347.

The following conditions apply to these Spain VAT reports provided by this SuiteApp:

-   All amounts presented in the reports are sourced from transaction tax lines.
    
-   The transactions included in your report are filtered by the **Tax Point Date** field and the period selected on the **Country Tax Report** page.
    
    Note:
    
    By default, the **Tax Point Date** field value is the same as the **Date** field value. However, you can manually alter the **Tax Point Date** field value if you want to include or exclude certain transactions from your generated report.
    
-   The report generation process supports transactions in non-euro currencies. All transactions in non-euro currencies are converted to euros and included in the generated reports. For more information about using the Multiple Currencies feature in the Spain Localization SuiteApp, see [Optional Prerequisites for Using the Spain Localization SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0808031724.html#subsect_79094207607).
    
    The exchange rate values that are automatically provided by NetSuite are shown on the transaction record. For more information about providers of these rates, see [Integrated Exchange Rate Providers](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4320491322.html).
    
    Note:
    
    You can also manually edit these exchange rate values. For more information, see [Setting Exchange Rates Directly on Transactions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1404249.html).
    
-   The Spain VAT report generation only considers posting transactions, which are those that directly affect the balance of what your company is worth. Even though all types of posting transactions are considered, we strongly encourage you to only use the following transaction types when you generate reports:
    
    -   Bill
        
    -   Cash Sale
        
    -   Bill Credit
        
    -   Credit Memo
        
    -   Expense Report
        
    -   Invoice
        
    -   Journal Entry
        
    
    Note:
    
    To exclude specific transactions from your generated reports, you can set their Approval Status to either **Pending Approval** or **Rejected**. This automatically sets their Posting column value on the GL Impact subtab to **No**. For more information, see [Setting the Approval Status on Transactions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0923125544.html).
    
-   The report generation process only considers the following:
    
    -   Paid source transactions, such as invoices and bills. Their corresponding payments, such as customer payments and bill payments, are disregarded.
        
    -   Transactions with set tax transaction type. In most cases, SuiteTax automatically sets the tax transaction type for you. However, for a journal entry, you must set it manually. For more information, see [Tax Transaction Types in the SuiteTax Engine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557735490.html).
        
    -   Transactions where the **Tax Item Type** field is set for all existing items. Transactions where this field isn't set won't be included in the generated report. For more information, see [Assigning Tax Item Type for your Transactions with Item Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_88082846157.html).
        
        Note:
        
        Because expense report transactions don't have item or tax item categories, they're an exception to this rule.
        
-   If the Multi-Book Accounting features are enabled in your account, your generated Spain-specific reports only source information from the primary book of your selected subsidiary. This is true for all reports provided by the Spain Localization SuiteApp.
    
-   All reports include expense lines, which are categorized as services and are included even if their Tax Item Type field isn't set.
    
-   To ensure accurate sourcing and reporting of the Spain reports, you can only use the predefined SuiteTax tax codes for Spain. For more information, see [Known Limitations of the Spain VAT Reports Provided by the Spain Localization SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0907071308.html) and [Spain Tax Codes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0916013503.html).
