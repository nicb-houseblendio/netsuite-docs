The following table lists possible error situations that occur when the SuiteApp fails to generate the Modelo 303 report, and suggests solutions for these problems.

| NetSuite Error Message | Suggested Solution |
| --- | --- |
| The name of the subsidiary is too long. For Modelo 303 report generation, choose a name that doesn't exceed 80 characters. If you set both Name and Legal Name fields, only the latter must be compliant. You can update the name on the Subsidiary page. | This error message includes a clickable link that takes you directly to the Subsidiary page of the subsidiary that you selected for your report generation. You can also access this page by going to Setup > Company > Subsidiaries, and then selecting the subsidiary name from the list.
#### To Change the Subsidiary Name: {#procedure_0907112713}

1.  On the Subsidiary page, click **Edit**.
2.  In the field **Legal Name**, fill in the legal name of your subsidiary that complies with the maximum limit of 80 characters.
3.  Click **Save**.

For more information, see [Setting the Name for Your Spanish Subsidiary](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_66132323505.html). |
| The fiscal year that you selected is invalid. For Modelo 303 report generation, only periods from the fiscal year 2022 onwards are supported. Make sure you only select a period within said time frame. | 

#### To Resolve this Error: {#procedure_0908120741}

1.  Go back to Reports > Spain Reports > Country Tax Reports, where you previously tried to generate the Modelo 303 file.
2.  In the required fields **Start Period** and **End Period**, only select periods from the year 2022 onwards.
3.  Fill in the rest of the fields as you did for your last generation attempt.
4.  Click **Generate**.

 |
| The period that you selected is invalid. Make sure you only select a single quarter or a month. | Because Modelo 303 file has a quarterly or monthly reporting frequency, you can only choose to generate it for a specific quarter or a month.

#### To Resolve this Error: {#procedure_6001708465}

1.  Go back to Reports > Spain Reports > Country Tax Reports, where you previously tried to generate the Modelo 303 file.
2.  In the required fields **Start Period** and **End Period**, select either a single quarter or a month.
3.  Fill in the rest of the fields as you did for your last generation attempt.
4.  Click **Generate**.

 |
| To generate a Modelo 303 report for the last period of the fiscal year, you must declare your main business activity on the Subsidiary page. Optionally, you can also add up to five additional activities. | For more information about adding business activities, see [Setting Activities for Your Spanish Subsidiary](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_31132441151.html). |
