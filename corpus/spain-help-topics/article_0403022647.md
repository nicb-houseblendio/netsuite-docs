To access the Spain Localization SuiteApp documentation in Spanish of Spain (español de España), see [Spain Localization](https://system.netsuite.com/app/help/helpcenter.nl?fid=SpainLocalization.pdf).

The generation process of the Modelo 390 report also includes a **Modelo 390 Configuration** page. To access this page, go to Reports > Tax > Country Tax Reports, and click on **Configure 390** button before generating your Modelo 390 report. This page includes the configuration of the following fields:

Note:

If you fill out negative numeric values to fields where they're not allowed, an error is shown and the Save button is disabled.

Note:

If you don't fill anything in the required fields, they will be set to their default values.

| Field Label | Required Field | Editable Field | Numeric Values |
| --- | --- | --- | --- |
| Record of monthly return in any period of the fiscal year | Y | Y | \- |
| Have you been declared bankrupt in this fiscal year? | Y | Y | \- |
| Compensation of previous year's tax amounts (Box 85) | N | Y | Only 0 or positive. If you enter a negative value, it's automatically set to 0. |
| Total monthly VAT returns requested by taxpayers registered in the record of monthly return (Box 96) | Y | Y Only editable if **Record of monthly return in any period of the fiscal year** is set to **Yes**. | Only 0 or positive. |
| If the result of the self-assessment for the last period is to be compensated or returned, enter its amount: | To compensate (Box 97) | Y | Y Only editable if **Box 98** is set to **0**. | Only 0 or positive. |
| To return (Box 98) | Y | Y Only editable if **Record of monthly return in any period of the fiscal year** is set to **No** and **Box 97** is set to **0**. | Only 0 or positive. |
| Tax amount pending compensation generated in the fiscal year and different from the amount included in box 97 (Box 662) | Y | Y | Only 0 or positive. |

The values that you fill in these fields are later reflected in your generated Modelo 390 report.

For more information about supported Modelo 390 fields, see [Modelo 390 - What Goes into Each Box](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0403101051.html).
