Note:

To access the Spain Localization SuiteApp documentation in Spanish of Spain (español de España), see [Spain Localization](https://system.netsuite.com/app/help/helpcenter.nl?fid=SpainLocalization.pdf).

After you open your generated report on the **Country Tax Report - Spain** page, you can see the report preview and verify its details. Click on the underlined numeric values in individual fields of the report, if you want to view the details on a **Detailed Report** page. Both the **Country Tax Report - Spain** and **Detailed Report** pages show numeric values with up to two decimal places.

This preview is available for the following Spain VAT reports:

-   Modelo 303
    
-   Modelo 349
    
-   Modelo 390
    
-   Modelo 347
    

If you generate Modelo 349 or Modelo 347, you can view details about individual operators in your report. Access them by clicking on the numeric values of their corresponding tax bases.

Note:

By default, the **Detailed Report** page doesn't display the transaction numbers. If you want to see transaction numbers on this page, you must configure transaction type options on the **Set Up Auto-Generated Numbers** page. For more information, see [Auto-Generated Transaction Numbers](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4340444343.html).
