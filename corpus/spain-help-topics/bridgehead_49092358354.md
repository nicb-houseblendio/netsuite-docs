Note:

The following table describes taxation features for companies in Spain. These features are for NetSuite accounts with SuiteTax. For more information about these features, see [Spain Localization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_2111427100.html).

| Feature | Description | Prerequisites |
| --- | --- | --- |
| Tax Reporting for Accounts with SuiteTax | The tax reporting feature provides generation of the following Spain-specific reports based on SuiteTax:
-   Modelo 303
-   Modelo 349
-   Modelo 390
-   SII - Registration: Issued Invoice
-   SII - Correction: Issued Invoice
-   SII - Registration: Received Invoice
-   SII - Correction: Received Invoice

These tax reports are generated in NetSuite accounts only when the SuiteTax feature is enabled. For more information, see [Generating Spain VAT Reports in the Spain Localization SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0815012915.html). | Enable the following features:

-   Custom Records See [Custom Records Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N2875173.html).
-   Advanced PDF/HTML Templates See [Enabling the Advanced PDF/HTML Templates Feature](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2862977.html).
-   SuiteScript
    -   Client SuiteScript
    -   Server SuiteScript
-   SuiteAnalytics Workbook See [Enabling SuiteAnalytics Workbook in Your NetSuite Account](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1504014192.html).
-   Customer Relationship Management
-   Inline Editing

Disable the following feature:

-   Multiple Calendars

Install the following SuiteApps:

-   SuiteTax Engine SuiteApp See [Installing the SuiteTax Engine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557397007.html).
-   Tax Reporting Framework SuiteApp See [Installing Tax Reporting Framework](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1528245293.html).
-   Localization Assistant SuiteApp See [Installing the Localization Assistant SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163092361565.html).

 |
| Visual Drill-down and Electronic Format | The SuiteApp offers a visual drill-down of Spain-specific tax reports to validate which transactions are included in each box. It also offers a downloadable machine-readable report format that's ready for upload to the AEAT online portal. For more information, see [Exporting Spain VAT Report Files in a TXT Format](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0913044438.html). |
| Interpretation of AEAT Response XML Files | After the SII report generation and manual submission to the AEAT online portal, you'll receive an XML file as a response from AEAT regarding your submission. The Spain Localization SuiteApp provides you with a platform where you can upload this response and let the system interpret it for you. For more information, see [SII - AEAT Response](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1115024329.html). |
