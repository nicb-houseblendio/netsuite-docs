If you need to access the electronic invoicing features specific to Spain that are provided by the European Union Electronic Invoicing SuiteApp, see the following help topics:

-   [European Union Electronic Invoicing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_7122551804.html)
    
-   [Spain-Specific Electronic Invoicing Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0306033812.html)
    

Note:

The features linked above belong to a different SuiteApp, and the setup instructions in the linked articles don't apply to Spain Localization.

Important:

The electronic invoicing features linked above are mutually exclusive with the SII features provided by the Spain Localization SuiteApp. If you use the SII features, you can't use the linked electronic invoicing features at the same time.
