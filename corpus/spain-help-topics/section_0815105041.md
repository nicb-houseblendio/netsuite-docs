Note:

To access the Spain Localization SuiteApp documentation in Spanish of Spain (español de España), see [Spain Localization](https://system.netsuite.com/app/help/helpcenter.nl?fid=SpainLocalization.pdf).

The Spain Localization SuiteApp supports the following standard roles:

-   Administrator
    
-   CFO
    
-   Accountant
    

## Further Assignment of Access and Permissions to Standard Roles {#subsect_29105621382}

After you install the Tax Reporting Framework SuiteApp, proceed with the following steps:

-   After the installation, each of these supported roles can view all transaction types on the generated reports and the Detailed Report page. For that reason, we encourage you to give access to Accountant and CFO roles to view these transaction types on other NetSuite pages too.
    
    #### To give access to transaction types relevant for your company: {#procedure_0525013626}
    
    1.  Go to Setup > Users/Roles > Manage Roles.
        
    2.  Choose a role.
        
        -   Click **Edit** to add permissions to a custom role.
            
        -   Click **Customize** to create a custom role from a standard role.
            
    3.  Click the **Permissions** subtab.
        
    4.  Click the **Transactions** subtab.
        
    5.  From the **Transactions** list, select transaction types relevant for your company that this role doesn't have the access to.
        
    6.  After you add the transaction type, the level of access is automatically set to **View**. If you want to select a different level, select it from the **Level** list.
        
    7.  Click **Add**.
        
    8.  Click **Save**.
        
    
-   Add Tax Reporting Framework permissions to standard and custom roles. For more information, see [Assigning Tax Reporting Framework Permissions to a Role](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1528249899.html#bridgehead_1550729884).
