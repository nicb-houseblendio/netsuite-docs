Note:

To access the Spain Localization SuiteApp documentation in Spanish of Spain (español de España), see [Spain Localization](https://system.netsuite.com/app/help/helpcenter.nl?fid=SpainLocalization.pdf).

The Spain Localization SuiteApp is a managed SuiteApp available in the SuiteApp Marketplace.

#### To install the Spain Localization SuiteApp: {#procedure_0815104708}

1.  Go to SuiteApps.
    
2.  In the search bar, enter **Spain Localization**.
    
3.  Click the Spain Localization image.
    
4.  Click **Install**.
    
5.  Read the information on the alert, and click **Install** if you want to proceed, or **Cancel** if you don't want to install the SuiteApp.
    

Note:

The Administrator, Accountant and CFO standard roles must be set to active so the installation can run properly.
