To be able to correctly see all the available dropdown entries for Spain-specific fields, you need to set the Maximum Entries in Dropdown preference.

#### To set the Maximum Entries in Dropdown preference:

1.  Log in to NetSuite from a browser session, and then go to Home > Set Preferences.
    
2.  In the **General** subtab, under Optimizing NetSuite, enter a value in the **Maximum Entries in Dropdowns** field.
    
    If the list has more items than this value, you'll see a popup list. Otherwise, you'll get a roll selector.
    
3.  Click **Save**.
