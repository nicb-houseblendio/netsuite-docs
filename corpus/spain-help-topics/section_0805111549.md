-   The Spain Localization SuiteApp enables you to generate VAT report forms, which are used for VAT report submissions in Spain. The SuiteApp currently provides the following reports:
    
    | Report | Availability | Further Details |
    | --- | --- | --- |
    | Modelo 303 for monthly or quarterly VAT reporting | You can generate these reports on the **Country Tax Report** page provided by the Tax Reporting Framework SuiteApp. For more information, see [Generating Spain VAT Reports in the Spain Localization SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0815012915.html) and [SII - Immediate Supply of Information](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0718090242.html). | You can preview these reports in NetSuite, and export them in a TXT file format. You can then upload and submit these files to the Spanish Tax Administration Agency online portal. Note: When you upload the generated TXT report file to this portal, you may see a simplified version of the VAT report. In this report version, some of the boxes aren't displayed. |
    | Modelo 349 for quarterly or monthly provision of details about intracommunity transactions |
    | Modelo 390 for annual summary VAT statement. |
    | Modelo 347 for annual declaration of transactions with third parties. |
    | SII - Registration: Issued Invoice | You can generate these reports in an XML file format. You can then upload and submit these files to the Spanish Tax Administration Agency online portal. |
    | SII - Correction: Issued Invoice |
    | SII - Registration: Received Invoice |
    | SII - Correction: Received Invoice |
    | Spain-Specific Financial Reports | These reports are available on the **Reports** and **Analytics** tabs. For more information, see [Spain-Specific Financial Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0510065253.html). |  |
    
    Note:
    
    Remember that the sourcing of boxes and fields in these reports is already configured for you. For that reason, you can't manually change these configurations.
    
-   The Spain Localization SuiteApp enables you to submit your generated SII reports to AEAT. You can either submit your SII reports manually after you've generated a report, or use the new SII Report Scheduling feature to set automated submissions.
    
    For more information, see the following articles:
    
    -   [Manual Submission of SII Reports to AEAT](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1022012701.html)
        
    -   [Automated Submission of SII Reports to AEAT](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1022012821.html)
        

Note:

Features of the Spain Localization SuiteApp work only with NetSuite OneWorld accounts with SuiteTax. Therefore, you'll need to enable the SuiteTax feature in your NetSuite account.

Account administrators can now enable the feature by going to Setup > Company > Enable Features > Tax subtab. When you enable the feature, you can't undo the action. Therefore, you should enable the feature in your Sandbox account first before enabling it in your production account. For more information, see [Enabling the SuiteTax Feature](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1513063459.html)

## Known Limited and Supported Settings of the Spain Localization SuiteApp {#article_0907114201}

The Spain Localization SuiteApp has the following limited and supported settings:

| Limited Settings | Supported Settings |
| --- | --- |
| 
-   NetSuite accounts where the SuiteTax feature is disabled.
-   Non-OneWorld NetSuite accounts.
-   Subsidiaries with the country and nexus set to a value other than Spain.
-   Subsidiaries with the currency set to a value other than EUR.

Important: If you install the Spain Localization SuiteApp with these settings, the generation of your Spain documents won't work. | 

-   NetSuite accounts where the Multi-Book Accounting feature is enabled.
-   NetSuite accounts where the Multiple Currencies feature is enabled.
-   NetSuite accounts where the Multiple Calendars feature is enabled.

Important: If you install the Spain Localization SuiteApp with these settings, the generation of your Spain documents will work without any issues. |

For information about limitations of Spain VAT reports, see [Known Limitations of the Spain VAT Reports Provided by the Spain Localization SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0907071308.html).

## Supported Languages in the Spain Localization SuiteApp {#section_0808024334}

The Spain Localization SuiteApp supports the following languages:

-   English (U.S.)
    
-   Español (España)
    
-   Español (Latinoamérica)
    

For information about selecting your preferred language, see [Setting Language Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1543591052.html).

Note:

If you set the localization preference to a language that's not supported, the pages will be displayed in English (U.S.).
