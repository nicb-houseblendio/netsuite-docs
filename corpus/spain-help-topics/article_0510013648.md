#### To access this set of financial reports: {#procedure_0814014419}

1.  -   For roles that use the accounting center, go to **Reports > Spain Reports > Book of Issued and Received Invoices for Spain**.
        
    -   For roles that use other types of centers, go to the **Analytics** tab on the NetSuite navigation menu.
        

On these pages, the Spain Localization SuiteApp provides you with the Spain-specific workbook **Book of Issued and Received Invoices for Spain**. This workbook displays information about your sales and purchases. Use pivot tables within the workbook to monitor your issued and received invoices and customize them by adding, reordering, or removing fields from related records. Click on this workbook to access it. After that, you can see the following datasets that belong to this workbook:

-   Book of Issued Invoices
    
-   Book of Received Invoices
    

Important:

Currently, this workbook and datasets can only be accessed by the Administrator roles. If you want the Accountant and CFO roles to have access to these reports, you need to share the workbook and datasets with them. For more information, see [Accessing and Sharing Workbooks and Datasets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1531766899.html).

The root record type for these datasets is a transaction. You can filter your workbook using the following parameters:

| Filter | Data Parameters |
| --- | --- |
| Date | The date must be on or after the start of the last fiscal year. The filtered value is sourced from the **Date** field on the transaction record. |
| Transaction Type | Filters transactions based on their transaction type. |
| Tax Rate | The filtered value is sourced from the **Tax Rate** field on the **Tax Details** subtab of the transaction record. |
| Accounting Book | Only the primary accounting book is considered. |
| Nexus Country | Nexus must be Spain. The filtered value is sourced from the **Nexus** field on the **Tax Details** subtab of the transaction record. |

Using filters allows you to generate issued and received invoices for a specific period or transactions. If you want to hide some of the tax codes from the report, such as the Reverse Charge tax codes, you can filter them out.

Important:

Even though this workbook and datasets are editable, you should always make a copy if you want to customize them. To make a copy, click **Save > Save As** in the upper right corner of your **Workbook** page. Saving your workbook before customizing it also prevents losing these customizations when a new version of the SuiteApp is released.

| Formula Title | Book of Issued Invoices | Book of Received Invoices |
| --- | --- | --- |

-   Credit Memo
-   Cash Refund

 | Net amount per item with a positive sign. Exception, which has a negative sign is the following:

-   Bill Credit

 |
| Tax Base (EUR) | Tax Base field converted to euros using the exchange rate values provided by NetSuite. | Tax Base field converted to euros using the exchange rate values provided by NetSuite. |
| Tax Amount Sign (EUR) | (Tax Amount) x (-1) Tax amount per item with a negative sign. Exceptions, which have a positive sign are the following:

-   Credit Memo
-   Cash Refund

Note: These amounts need to change to negative. For this reason, the **Tax Amount Sign** formula is applied. This value is shown in euros. | \- |
| Total Amount | (Tax Base) - (Tax Amount) | (Tax Base) + (Tax Amount) |
| Total Amount (EUR) | Total Amount field converted to euros using the exchange rate values provided by NetSuite. | Total Amount field converted to euros using the exchange rate values provided by NetSuite. |
