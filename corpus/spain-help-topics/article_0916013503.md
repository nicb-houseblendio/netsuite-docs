Tax codes determine how much tax is paid on each transaction line item. For NetSuite to calculate correct values on transaction records and tax reports, make sure that the tax codes for Spain are set up correctly.

For more information about tax codes, see [Understanding Tax Types and Tax Codes in SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4283869397.html).

## Tax Code Table for Spain {#subsect_46140258194}

The following table shows the tax properties required to correctly generate the Spain tax reports provided by the Spain Localization SuiteApp. The tax code names or letters presented in the table are suggested names or default system preferences. Tax reports identify transactions by looking at the tax code properties, and the tax code names. For this reason, you shouldn't change the tax code names or properties.

Note:

You can't update tax codes that are used to generate Spain reports in the Spain Localization SuiteApp. This means that you can only use the existing tax codes listed in the table below.

Note:

Please note that you must manually set the OSS tax codes for them to be used for report generation. For more information, see [Setting Up OSS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4162081368.html). The Spain Localization SuiteApp only supports the Union scheme of OSS. When using OSS, make sure you only use this scheme.

| Tax Code | Description | Rate | Available On |
| --- | --- | --- | --- |
| ES\_ZR | Zero rate for Spain | 0% | Both (Sales and Purchases) |
| OSS(ES)\_ZR | OSS for Spain - Tax on sales | 0% | Sales |
| ES\_SRR | Super reduced rate for Spain | 4% | Both (Sales and Purchases) |
| ES\_SRR\_RC | Reverse charge - Super reduced rate for Spain | 4% | Purchases |
| OSS(ES)\_SRR | OSS for Spain - Tax on sales | Tax rate is assigned based on rates applicable in customer's country | Sales |
| ES\_SSRR | Extra super reduced for Spain | 5% | Both (Sales and Purchases) |
| ES\_SSRR\_RC | Reverse charge - Extra super reduced for Spain | 5% | Purchases |
| OSS(ES)\_SSRR | OSS for Spain - Tax on sales | Tax rate is assigned based on rates applicable in customer's country | Sales |
| ES\_RR | Reduced rate for Spain | 10% | Both (Sales and Purchases) |
| ES\_RR\_RC | Reverse charge - Reduced rate for Spain | 10% | Purchases |
| OSS(ES)\_RR | OSS for Spain - Tax on sales | Tax rate is assigned based on rates applicable in customer's country | Sales |
| ES\_SR | Standard rate for Spain | 21% | Both (Sales and Purchases) |
| ES\_SR\_RC | Reverse charge - Standard rate for Spain | 21% | Purchases |
| OSS(ES)\_SR | OSS for Spain - Tax on sales | Tax rate is assigned based on rates applicable in customer's country | Sales |
| ES\_RCS | Reverse charge for sales for Spain | 0% | Sales |
| ES\_NL | Not liable to tax in Spain | 0% | Both (Sales and Purchases) |
| OSS(ES)\_NL | OSS for Spain - Tax on sales | 0% Not liable to tax in Spain | Sales |
