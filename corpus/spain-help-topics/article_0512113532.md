To access the Spain Localization SuiteApp documentation in Spanish of Spain (español de España), see [Spain Localization](https://system.netsuite.com/app/help/helpcenter.nl?fid=SpainLocalization.pdf).

The following table lists possible error situations that occur when the SuiteApp fails to generate the Modelo 390 report, and suggests solutions for these problems.

| NetSuite Error Message | Suggested Solution |
| --- | --- |
| The period that you selected is invalid. Make sure you only select an entire fiscal year, and that the values selected in Start Period and End Period fields are the same. | Because Modelo 390 file has an annual reporting frequency, you can only choose to generate it for a specific fiscal year.
#### To resolve this error: {#procedure_47124027816}

1.  Go back to Reports > Spain Reports > Country Tax Reports, where you previously tried to generate the Modelo 390 file.
2.  In the required fields **Start Period** and **End Period**, select a single fiscal year.
3.  Fill in the rest of the fields as you did for your last generation attempt.
4.  Click **Generate**.

 |
| The name of the subsidiary is too long. For Modelo 390 report generation, choose a name that doesn't exceed 60 characters. If you set both Name and Legal Name fields, only the latter must be compliant. You can update the name on the Subsidiary page. | This error message includes a clickable link that takes you directly to the Subsidiary page of the subsidiary that you selected for your report generation. You can also access this page by going to Setup > Company > Subsidiaries, and then selecting the subsidiary name from the list.

#### To Change the Subsidiary Name: {#procedure_18124208483}

1.  On the Subsidiary page, click **Edit**.
2.  In the field **Legal Name**, fill in the legal name of your subsidiary that complies with the maximum limit of 60 characters.
3.  Click **Save**.

For more information, see [Setting the Name for Your Spanish Subsidiary](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_66132323505.html). |
| You did not select any activity in the Main Activity dropdown list on the Activity subtab of the Subsidiary page. Make sure you select an activity in this list to be able to generate Modelo 390. | Setting main activity for your subsidiary is required for the Modelo 390 report generation. This error message includes a clickable link that takes you directly to the Subsidiary page of the subsidiary that you selected for your report generation. For more information about setting the main activity on this page, see [Setting Activities for Your Spanish Subsidiary](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_31132441151.html). |
