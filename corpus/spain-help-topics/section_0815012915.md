Note:

To access the Spain Localization SuiteApp documentation in Spanish of Spain (español de España), see [Spain Localization](https://system.netsuite.com/app/help/helpcenter.nl?fid=SpainLocalization.pdf).

This section details the process of generating Spain VAT reports provided by the Spain Localization SuiteApp. The reports are generated on the Country Tax Report page provided by the Tax Reporting Framework SuiteApp. Follow the procedure below to generate the following Spain VAT reports:

-   Modelo 303
    
-   Modelo 349
    
-   Modelo 390
    
-   Modelo 347
    
-   SII - Registration: Issued Invoice
    
-   SII - Correction: Issued Invoice
    
-   SII - Registration: Received Invoice
    
-   SII - Correction: Received Invoice
    

Before the generation, verify that the reporting frequency for Modelo 303 and Modelo 349 reports is set correctly. For more information, see [Setting the Reporting Frequency for Spain VAT Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_32143832368.html).

Note:

Remember that the sourcing of boxes and fields in these reports is already configured for you. For that reason, you can't manually change these configurations.

#### To Generate a Spain VAT Report: {#procedure_0815034824}

1.  For roles that use the accounting center and classic center, go to Reports > Spain Reports > Country Tax Reports.
    
    For roles that use other types of centers, go to Reports > Tax > Country Tax Reports.
    
2.  In the Subsidiary field, select the name of your Spain subsidiary or parent company for which you want to generate the report.
    
    You can only select one subsidiary for every file-generating action.
    
    Note:
    
    If you enable the Multi-Book Accounting features in your account, your generated reports only source information from the primary book of your selected subsidiary. This is true for all reports provided by the Spain Localization SuiteApp.
    
3.  If your selected subsidiary ties to more than one nexuses, select **Spain** in the Nexus field. For subsidiaries only tied to the nexus Spain, this field is preset.
    
4.  In the Report Name field, select the report that you want to generate.
    
    Note:
    
    If it's your first time using the Spain Localization SuiteApp, you should configure the following reports before generation:
    
    -   Modelo 303 - See [Modelo 303 Report Configuration](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1205110907.html)
        
    -   Modelo 390 - See [Modelo 390 Report Configuration](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0403022647.html)
        
    
    Note:
    
    If you generate one of the SII reports, first set the required fields on the **SII Reporting** subtab of the transaction record. For more information, see [SII - Transaction Record Information](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1114102907.html).
    
    Note:
    
    For the SII report generation:
    
    -   Select **Registration** report types if:
        
        -   It's your first time generating the SII report for this date range and the SII reporting status of your transaction is **Pending Submission**.
            
        -   The SII reporting status of your previous submission is **Rejected**.
            
    -   Select **Correction** report types if the SII reporting status of your previous submission is:
        
        -   **Partially Correct**.
            
        -   **Rejected After Resubmission**.
            
        -   **Pending Correction**.
            
    
    For more information, see [SII - AEAT Response](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1115024329.html).
    
5.  -   For the following reports, set the Start Period field. If you're generating a report that allows for a prior configuration, make sure you select the same period:
        
        -   For **VAT Modelo 303**, select a quarter or a month.
            
        -   For **VAT Modelo 349**, select a quarter or a month.
            
        -   For **VAT Modelo 390**, select a fiscal year.
            
        -   For **VAT Modelo 347**, select a fiscal year.
            
        
        The End Period field is set automatically.
        
    -   For the following reports, set the Start Date field:
        
        -   SII - Registration: Issued Invoice
            
        -   SII - Correction: Issued Invoice
            
        -   SII - Registration: Received Invoice
            
        -   SII - Correction: Received Invoice
            
        
        The End Date field is automatically set to the last day of the selected month.
        
        Note:
        
        The report generation process retrieves transactions based on the considered date field value that falls within your selected date range.
        
        -   For the Issued Invoices reports, the **Date** field on the transaction record is considered.
            
        -   For the Received Invoices reports, the **Accounting Registration Date** field on the SII Reporting subtab is considered.
            
        
6.  Click **Generate**.
    
    Generating the file may take a few minutes.
    
7.  On the **Report Execution Log** subtab, locate the generated report. The latest generated report is displayed at the top of the list.
    
8.  In the **View/Download** column, wait for the loading bar to complete and change to a **View/Download** link.
    
    If the report covers a long period, the report generation may take a few minutes to complete. You'll be notified by email when the report is available.
    
9.  -   For Modelo 303, Modelo 349, Modelo 390, and Modelo 347, click **View** to open the report on the **Country Tax Report - Spain** page. If the file is generated successfully, you can see the report preview on this page. For more information, see [Spain VAT Report Preview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1115031520.html).
        
        Note:
        
        If you see an error message titled **Failed Report Generation** instead of a generated report, then your report couldn't be generated. For more information about specific cases of generation failures, see:
        
        -   [Resolving Errors in Generating Spain VAT Report Files](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0831031353.html)
            
        -   [Resolving Errors in Generating Modelo 303 Report File](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1130110950.html)
            
        -   [Resolving Errors in Generating Modelo 349 Report File](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1130111538.html)
            
        -   [Resolving Errors in Generating Modelo 390 Report File](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0512113532.html)
            
        -   [Resolving Errors in Generating Modelo 347 Report File](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_57112337194.html)
            
        -   [Resolving Errors in Uploading Reports to the AEAT Online Portal](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0920100817.html)
            
        
        For more information about exporting your generated report, see [Exporting Spain VAT Report Files in a TXT Format](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0913044438.html).
        
    -   For SII reports, click **Download** to download the generated XML file. For more information about the content of SII reports, see [SII - Registration/Correction: Issued Invoice](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1114102240.html) and [SII - Registration/Correction: Received Invoice](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1114102546.html).
        

Important:

Depending on your server workload and the number of transaction lines, each report can contain approximately 1500 to 6000 transactions. Note that if you use customizations and extensions on your reports, these numbers will decrease.

For more information, see [Customization of Spain VAT Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0511122611.html).
