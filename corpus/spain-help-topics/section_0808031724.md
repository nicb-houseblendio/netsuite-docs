Note:

To access the Spain Localization SuiteApp documentation in Spanish of Spain (español de España), see [Spain Localization](https://system.netsuite.com/app/help/helpcenter.nl?fid=SpainLocalization.pdf).

Before you install the Spain Localization SuiteApp, you must do the following:

1.  Enable the following required features:
    
    | Feature | Enablement Procedure |
    | --- | --- |
    | Custom Records | 
    #### To enable the feature:
    
    1.  Go to Setup > Company > Setup Tasks > Enable Features > SuiteCloud.
    2.  On the SuiteCloud subtab, check the **Custom Records** box.
    3.  Click **Save**.
    
     |
    | Advanced PDF/HTML Templates | See [Enabling the Advanced PDF/HTML Templates Feature](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2862977.html). |
    | SuiteScript
    
    -   Client SuiteScript
    -   Server SuiteScript
    
     | 
    
    #### To enable the feature: {#procedure_2114903923}
    
    1.  Go to Setup > Company > Setup Tasks > Enable Features (Administrator).
    2.  On the **SuiteCloud** subtab in the **SuiteScript** section, check the **Client SuiteScript** and **Server SuiteScript** boxes.
    3.  Click **Save**.
    
     |
    | SuiteAnalytics Workbook | See [Enabling SuiteAnalytics Workbook in Your NetSuite Account](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1504014192.html). |
    | Customer Relationship Management | 
    
    #### To enable the feature: {#procedure_0728110831}
    
    1.  Go to Setup > Company > Setup Tasks > Enable Features, and click the **CRM** subtab.
    2.  Under the **Basic Features** section, check the **Customer Relationship Management** box.
    3.  Click **Save**.
    
     |
    | Inline Editing | 
    
    #### To enable the feature: {#procedure_76144815996}
    
    1.  Go to Setup > Company > Setup Tasks > Enable Features (Administrator).
    2.  On the **Company** subtab in the **Data Management** section, check the **Inline Editing** box.
    3.  Click **Save**.
    
     |
    
2.  Install the following required SuiteApps:
    
    | SuiteApp | ID | Installation Procedure |
    | --- | --- | --- |
    | SuiteTax Engine SuiteApp | Bundle ID: 237702 | See [Installing the SuiteTax Engine](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557397007.html). Note: Make sure you follow the whole installation procedure. |
    | Tax Reporting Framework SuiteApp | Bundle ID: 237699 | See [Installing Tax Reporting Framework](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1528245293.html). |
    | Localization Assistant SuiteApp | SuiteApp ID: com.netsuite.localizationassistant | See [Installing the Localization Assistant SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163092361565.html). |
    

Important:

Without the required SuiteApps and features, you can't install the Spain Localization SuiteApp.

## Optional Prerequisites for Using the Spain Localization SuiteApp {#subsect_79094207607}

Some features provided by the Spain Localization SuiteApp require additional optional prerequisites. This means you can install and use the SuiteApp without any issues, even without these prerequisites in your account.

If you want transactions in non-euro currencies to be included in your generated reports, you need to enable the following feature:

| Feature | Enablement Procedure |
| --- | --- |
| Multiple Currencies | See [Enabling the Multiple Currencies Feature](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1395677.html). |
