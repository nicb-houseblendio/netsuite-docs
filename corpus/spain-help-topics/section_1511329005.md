You can use the Exclude from VAT Reports property on tax code records if you don't want to include the transactions where the tax code is used in the Spain Online VAT Register Reports.

Important:

Excluding Transactions from Spain Online VAT Register Reports isn't applicable to Spain Cash Collections report.

#### To exclude from VAT Reports {#procedure_97125542069}

1.  Go to Setup > Accounting > Taxes > Tax Codes.
    
2.  Click **Edit** next to the tax code.
    
3.  On the Tax Code page, check **Exclude from VAT Reports**.
    
4.  Click **Save**.
    

Transactions with tax codes that have the Exclude from VAT Reports property checked aren't included in the Spain Online VAT Register Reports.
