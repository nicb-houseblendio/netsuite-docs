To access the Spain Localization SuiteApp documentation in Spanish of Spain (español de España), see [Spain Localization](https://system.netsuite.com/app/help/helpcenter.nl?fid=SpainLocalization.pdf).

The following table lists possible error situations that occur when the SuiteApp fails to generate the Modelo 347 report, and suggests solutions for these problems.

| NetSuite Error Message | Suggested Solution |
| --- | --- |
| The period that you selected is invalid. Make sure you only select an entire fiscal year, and that the values selected in Start Period and End Period fields are the same. | Because Modelo 347 file has an annual reporting frequency, you can only choose to generate it for a specific fiscal year.
#### To resolve this error: {#procedure_70165352606}

1.  Go back to Reports > Spain Reports > Country Tax Reports, where you previously tried to generate the Modelo 347 file.
2.  In the required fields **Start Period** and **End Period**, select a single fiscal year.
3.  Fill in the rest of the fields as you did for your last generation attempt.
4.  Click **Generate**.

 |
| The name of the subsidiary is too long. For Modelo 347 report generation, choose a name that doesn't exceed 40 characters. If you set both Name and Legal Name fields, only the latter must be compliant. You can update the name on the Subsidiary page. | This error message includes a clickable link that takes you directly to the Subsidiary page of the subsidiary that you selected for your report generation. You can also access this page by going to Setup > Company > Subsidiaries, and then selecting the subsidiary name from the list.

#### To Change the Subsidiary Name: {#procedure_61165503303}

1.  On the Subsidiary page, click **Edit**.
2.  In the field **Legal Name**, fill in the legal name of your subsidiary that complies with the maximum limit of 40 characters.
3.  Click **Save**.

For more information, see [Setting the Name for Your Spanish Subsidiary](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_66132323505.html). |
| The contact information of your subsidiary is missing or invalid. Make sure you fill out Addressee and Phone fields by going to the Subsidiary page. The Phone field must contain 9 numeric characters. | To resolve this error, see [Setting the Contact Information for Your Spanish Subsidiary](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_73132229706.html). |
| The generation of Modelo 347 failed because there were no transactions found. This report can only be generated if there's at least one transaction available. | When generating the report, make sure that there's at least one transaction in your selected fiscal year. |
| The generation of Modelo 347 failed because the following customers/vendors are missing a ZIP code: {X}. Check your email for the full list, and fill in the missing information on the Customer/Vendor page. Note: {X} is a placeholder for the list of customers/vendors with missing ZIP codes. | To resolve this error, see [Setting the Customer/Vendor Address](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_3132623267.html). |
