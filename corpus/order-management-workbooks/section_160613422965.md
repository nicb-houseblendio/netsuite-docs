The sales (invoiced) analytical record type is designed for analytics. This record type combines fields from the transaction, transaction line, and transaction accounting line record types, and includes data that meets these criteria:

          `Transaction type is not one of Check, Deposit, InvAdjst, InvReval, InvDistr, InvWksht, Build, Unbuild, WOIssue, WOCompl, WOClose, VendPymt, BinTrnfr, BinWksht, Commissn, FxReval, CustDep, CustRfnd, DepAppl, InvTrnfr, ItemShip, ItemRcpt, CustPymt, YtdAdjst, PurchOrd, TaxPymt, TaxLiab, Transfer, TrnfrOrd, VendAuth, WorkOrd, Payroll, Paycheck, LiaAdjst, LiabPymt, Sync, RevComm, RevComRv, Custom, Opprtnty, Estimate, SalesOrd, RtnAuth AND Transaction posting is 'T' AND Account accttype is one of Income, OthIncome, DeferRevenue, UnbilledRec` 
        

This is the root record type on the [Sales (Invoiced) Dataset](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158279516081.html). Some fields depend on features or custom formulas.

For more information about the fields included in this type, see the following table:

| Item | Transaction Line | Item | N/A |
| Location | Transaction Line | Location | Displayed only with Locations feature enabled |
| Memo | Transaction Line | Memo | N/A |
| Partner | Transaction | Partner | N/A |
| Posting Period | Transaction | Posting Period | Displayed only with Accounting Periods feature enabled |
