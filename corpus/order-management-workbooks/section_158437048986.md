The sales (ordered) dataset includes predefined criteria and fields from the sales (ordered) record type. The sales (ordered) record type includes the following fields from the transaction, transaction line, and transaction accounting line record types:

| **Field** | **Source Record** | **Source Field** |
| --- | --- | --- |
| Unique key | Transaction line | Unique key |
| Date | Transaction | Date |
| Amount | Transaction line | Net amount |
| Quantity | Transaction line | Quantity |
| Account | Transaction accounting line | Account |
| Transaction line | Transaction line | ID |
| Transaction | Transaction | Transaction |
| Item | Transaction line | Item |
| Customer | Transaction line | Entity |
| Subsidiary | Transaction line | Subsidiary |
| Memo | Transaction | Memo |
| Partner | Transaction | Partner |
| Classification | Transaction line | Classification |
| Department | Transaction line | Department |
| Location | Transaction line | Location |
| Sales rep | Transaction line | Sales rep |

Additionally, the following criteria are predefined as part of the sales (ordered) record type. Only transactions that meet this criteria are included in the sales (ordered) dataset:

-   The total amount (transaction currency) is not 0 (zero), except for work orders
    
-   Field ID does not equal 0 (zero)
    
-   Primary accounting book is not empty, or the transaction lines include a kit or package item. For more information, see [Kit/Package Items](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2225190.html).
    
-   Primary accounting book type is income, other income, defer revenue, or unbilled rec
    
    Note:
    
    If you've enabled Multi-Book Accounting, only the primary accounting book's data is included in the dataset.
    

The sales (ordered) dataset is the source data for the [Sales (Ordered) Workbook](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158437050695.html).

## Dataset Configuration {#subsect_158437072421}

By default, the sales (ordered) dataset combines the following fields and one criteria filter. To edit the dataset, see [Defining a Dataset](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544122173.html).

| Root Record Type | Joined Record Type | Custom Formula Field | Data Grid | Criteria Filters |
| --- | --- | --- | --- | --- |
| Sales (ordered) | (none) | (none) | The following fields are included in the dataset.
-   Amount (Net)
-   Class
-   Customer
-   Date
-   Item
-   Location
-   Quantity
-   Sales Rep
-   Transaction
-   Transaction type

 | The following criteria is used to filter the dataset:

-   **Date** on or after same day last fiscal year

 |
