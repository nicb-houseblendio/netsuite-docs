The sales (invoiced) dataset template includes predefined criteria and fields from the sales (invoiced) record type. The sales (invoiced) record type includes the following fields from the transaction, transaction line, and transaction accounting line record types:

| **Field** | **Source Record Type** | **Source Field** |
| --- | --- | --- |
| Date | Transaction | Date |
| Amount | Transaction Line | Amount |
| Amount (Net) | Transaction Line | Net Amount |
| Quantity | Transaction Line | Quantity |
| Account | Transaction Accounting Line | Account |
| Transaction Line | Transaction Line | Transaction Line |
| Transaction | Transaction | Transaction |
| Item | Transaction Line | Item |
| Customer | Transaction Line | Customer |
| Subsidiary | Transaction Line | Subsidiary |
| Memo | Transaction Line | Memo |
| Partner | Transaction | Partner |
| Posting Period | Transaction | Posting Period |
| Class | Transaction Line | Class |
| Department | Transaction Line | Department |
| Location | Transaction Line | Location |
| Sales Rep | Transaction Line | Sales Rep |
| Posting Period | Transaction | Posting Period |
| Promotion Combinations | Transaction | N/A (concatenation of all applied promotions) |

Additionally, the following criteria are predefined as part of the sales (invoiced) record type. Only transactions that meet this criteria are included in the sales (invoiced) dataset:

-   Transaction lines post to the general ledger
    
-   Primary accounting book type is Income, Other Income, Defer Revenue, or Unbilled Rec
    
    If you've enabled the Bill Costs To Customers and Include Reimbursements in Sales and Forecast Reports features, transactions with a primary accounting book type of Expense and Other Expense are also included in the workbook.
    
    Note:
    
    If you've enabled Multi-Book Accounting, only the primary accounting book's data is included in the workbook.
    
-   Transaction type is none of the following:
    
    -   Any transaction type specified by the **Transaction Types To Exclude From Sales Reports** accounting preference
        
    -   Opportunity
        
    -   Estimate
        
    -   Sales Order
        
    -   Return Authorization
        
    -   Build
        
    -   Unbuild
        
    -   Vendor Payment
        
    -   Bin Transfer
        
    -   Bin Worksheet
        
    -   Commission
        
    -   Foreign Currency Revaluation
        
    -   Customer Deposit
        
    -   Customer Refund
        
    -   Deposit Application
        
    -   Inventory Transfer
        
    -   Item Shipment
        
    -   Item Receipt
        
    -   Customer Payment
        
    -   Year To Date Adjustment
        
    -   Purchase Order
        
    -   Tax Payment
        
    -   Tax Liability
        
    -   Transfer
        
    -   Transfer Order
        
    -   Vendor Authorization
        
    -   Work Order
        

The sales (invoiced) dataset is the source data for the [Sales (Invoiced) Workbook](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158279518332.html).

## Dataset Configuration {#subsect_158279604884}

By default, the sales (invoiced) dataset combines the following fields and one criteria filter. To edit the dataset, see [Defining a Dataset](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544122173.html).

| Root Record Type | Joined Record Type | Custom Formula Field | Data Grid | Criteria Filters |
| --- | --- | --- | --- | --- |
| Sales (Invoiced) | (none) | (none) | The following fields are included in the dataset. Sales (Invoiced):
-   Amount (Net)
-   Class
-   Customer
-   Date
-   Item
-   Location
-   Quantity
-   Sales Rep
-   Transaction
-   Transaction Type

 | The following criteria is used to filter the dataset:

-   **Date** on or after same day last fiscal year

 |
