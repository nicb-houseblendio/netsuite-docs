You must setup a tax code for Legacy Tax accounts to include tax information in an e-invoice when the reverse charge code applies to self-billed transactions.

Note:

Make sure you've setup the Malaysia tax code before setting up the reverse charge tax code. For more information, see [Setting Up Malaysia Tax Code](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0718021004.html).

#### To setup the Malaysia reverse charge tax code for Legacy Tax accounts:

1.  Go to Setup > Accounting > Tax codes.
    
2.  Click **Edit** next to the tax code you use for your business in Malaysia.
    
3.  On the Tax Code page, check the **Reverse Charge Code** box to enable reverse charge for the tax code.
    
4.  From the **Notional Rate Derived From** list, select **Tax Code**.
    
5.  Click **Save**.
