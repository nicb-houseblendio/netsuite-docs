To use the Malaysia Electronic Invoicing SuiteApp, ensure your account meets all the prerequisites listed on this page:

-   Install the NetSuite SuiteApps License Client. For more information, see [NetSuite SuiteApps License Client](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4635371374.html)
    
-   Install the Localization Assistant SuiteApp. For more information, see [Localization Assistant SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_163092114640.html)
    
-   Install the Electronic Invoicing SuiteApp. For more information, see [Electronic Invoicing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4536869488.html)
    
-   Install the NetSuite Electronic Business SuiteApp. For more information, see [NetSuite Electronic Business](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_3140642944.html)
    
    Note:
    
    In addition to installing the NetSuite Electronic Business SuiteApp, you must perform the following actions to use e-invoicing for Malaysia:
    
    -   **OBN Registration** - To register with OBN, see [NetSuite Guide to Integrate with OBN](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0314102955.html).
        
    -   **Avalara Provisioning** - To set up Avalara provisioning, see [NetSuite Guide to Integrate with Avalara](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0313104928.html).
        
    
-   You must setup Avalara as an intermediary in MyInvois Portal.
    
    To setup Avalara as intermediary, check out [Setting Up Avalara as Intermediary in MyInvois Portal](https://suiteanswers.custhelp.com/app/answers/detail/a_id/1019646/kw/1019646).
