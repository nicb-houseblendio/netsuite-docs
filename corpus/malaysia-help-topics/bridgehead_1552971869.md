Before installing the Southeast Asia Localization SuiteApp, the following SuiteCloud features must be enabled in your account:

-   Advanced PDF/HTML Templates
    
-   Server SuiteScript
    

For more information on enabling SuiteCloud features, see [Enabling Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N232138.html) and [SuiteCloud Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N239332.html).
