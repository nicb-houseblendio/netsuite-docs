You can link a Malaysia Classification Code to an expense category and have it auto-populate on e-documents for self-billed transactions.

#### To link the Malaysia Classification Code to an expense category

1.  Go to Setup > Accounting > Expense Categories.
    
2.  Click **Edit** next to the required expense category record.
    
3.  On the expense category record, do one of the following to add the Malaysia Classification Code:
    
    -   Select an item from the **Expense Item** list. The **Malaysia Classification Code** field value will auto-populate from the expense item record.
        
        Note:
        
        The **Expense Item** list only appears on the expense category record if the Charge-based Billing feature is enabled in your account. If it's not available, you must manually add the Malaysia Classification Code.
        
    -   From the **Malaysia Classification Code** list, select the required code.
        
4.  Click **Save**.
