An item fulfillment transaction records the shipment of some or all items on an order to the customer. The processes for item fulfillment transactions depend on whether the Advanced Shipping feature is enabled.

-   If Advanced Shipping isn't enabled, the fulfillment and invoicing processes are combined. When an item fulfillment is created, a related invoice is created at the same time.
    
-   If Advanced Shipping is enabled, fulfillment and invoicing are two independent processes, and shipments can be recorded separately from billing
    

Note:

Whether Advanced Shipping is enabled or not, order fulfillments should always be entered against sales orders to track the status of items and orders.

In addition to the possibility of bulk fulfilling orders using a CSV import as described in [Bulk Fulfilling Orders Using a CSV Import](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1226924.html), you can also use the Import Assistant for it.

## Item Fulfillment Import Example for the Import Assistant {#subsect_0320053127}

The following table shows how you might structure a file for importing an item fulfillment record using the Import Assistant.

| Created From | External ID | Status | Date | Items : Location | Items : Order Line |
| --- | --- | --- | --- | --- | --- |
| Sales Order #1 | ItemFulfillment\_example\_1 | Packed | 11/08/2024 | Location US 2 | 1 |
| Sales Order #1 | ItemFulfillment\_example\_1 |  |  | Location US 2 | 2 |

The Created From field is a required field, so it cannot have a NULL value, and a default value would mean that all item fulfillments are created from the same sales order, which is not common. The edit button next to the Created From field in the mapping page of the import assistant enables select the proper reference type (Name, Internal ID or External ID).

The Import Assistant is available at Setup > Import/Export > Import Tasks > Import CSV Records (Administrator). You select the import type Transactions and record type Item Fulfillment, then character encoding. For more information, see [Choose Import Character Encoding](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N344158.html).
