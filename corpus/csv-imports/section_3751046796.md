Check this box if you want the import to ignore read-only fields. Enabling this option lets you import CSV files with values for read-only fields, like auto-generated numbers, without getting errors. The option is enabled by default.

Important:

For imports of entities and contacts together (Customers and Contacts Together, Leads and Contacts Together, Prospects and Contacts Together), the option **must** be enabled.
