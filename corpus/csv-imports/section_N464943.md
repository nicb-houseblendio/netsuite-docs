NetSuite doesn't support data imports using smbXML.

You can use either CSV Import or NetSuite's REST or SOAP web services instead of smbXML. Most people go with the CSV Import Assistant since it has a UI and doesn't need any programming. You can also use REST or SOAP web services, but you'll need programming skills for that. Web services are better if you want automated, system-to-system integration.

To learn about the CSV Import Assistant, see [Additional Import and Export Options](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N463253.html). You can find this topic in the NetSuite Help Center at Account Administration > CSV Imports > CSV Imports Overview.

To start learning about SOAP Web Services, see [SuiteTalk SOAP Web Services Platform Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N3412777.html).
