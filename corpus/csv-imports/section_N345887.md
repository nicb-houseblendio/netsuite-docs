On the Import Options page, expand the Advanced Options menu to set preferences for your current import job. The following advanced options are available:

-   [Log System Notes For Custom Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3751051117.html)
    
-   [Overwrite Missing Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3751050565.html)
    
-   [Validate Mandatory Custom Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3751048115.html)
    
-   [Overwrite Sublists](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3751046270.html)
    
-   [Ignore Read Only Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3751046796.html)
    
-   [Prevent Duplicate Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3751045493.html)
    
-   [Custom Multi-Select Value Delimiter](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3751045259.html)
    
-   [CSV Decimal Delimiter](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4341202053.html)
    
-   [Custom Form](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3751044597.html)
    
-   [Server Scripting and Workflow Execution](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4676525683.html)
    
-   [Use Multi-Threading](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3751043993.html)
    
-   [Queue Number](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3751039561.html)
    

Some of these options are also on the CSV Import Preferences page, where administrators and other users with the Set Up CSV Preferences permission can set preferences for all imports. For more information, see [Setting CSV Import Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N355760.html).

Advanced Options settings for a single import override the general preferences from the CSV Import Preferences page.

Important:

Imports always populate dependent field values automatically when related field values are set, in the same manner that dependent field values are populated in the user interface. For updates, be sure to include all necessary values in CSV files, so you don't accidentally change something to a default value.
