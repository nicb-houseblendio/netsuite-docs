By default, the Import Assistant expects the pipe '|' to be the delimiter for multi-select field values. You can also use any other single character as a custom multi-select delimiter. To use a different character instead of the pipe, enter it in this field. The Import Assistant will use your custom character for multi-select values in this import job. The character you enter here overrides any account-level character setting from the CSV Import Preferences page.
