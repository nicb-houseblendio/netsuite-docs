Use one of the following options to resolve the error.

**Option 1**

1.  Go to _Setup > Accounting > Accounting Lists_.
    
2.  Set Type to Price Level.
    
3.  Make sure that the Price Level set in the CSV file is:
    
    1.  Not set to Inactive
        
    2.  Correctly spelled
        

**Option 2**

When performing the import, on the Mapping Page:

1.  Select Item Pricing > Item Pricing 1.
    
2.  Map Pricing 1 to Price Level (Req).
    
3.  Click the edit icon and select the correct Price Level from the dropdown list.
