Your administrator specifies which roles can't change the server SuiteScripts and workflow triggers setting for individual CSV imports. For more information, see [Run Server SuiteScript and Trigger Workflows](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N355760.html#bridgehead_N356029). If you see the Run Server SuiteScript and Trigger Workflows box, you can change the setting for this import. Disable it to turn off all server SuiteScripts and workflow triggers during the import. Enable it to let them run during the CSV import.

The Run Server SuiteScript and Trigger Workflow box option is set to the company preference by default, but you can change it for the current import. If you save the import, your preference for this field is saved too.

Warning:

Use this setting with caution. Disabling the running of server scripts and workflow triggers can result in data corruption.
