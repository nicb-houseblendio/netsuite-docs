Important:

This option is available only in accounts that have purchased a SuiteCloud Plus license.

By default, every import job goes to queue 1. To speed things up, you can select other queues (2 to 5) to spread out the processing. This option is available in Step Two Import Options of the Import Assistant, under the Advanced CSV Import Options.

The queue number you select shows up in the Queue column on the import Job Status page. For information about this page, see [Checking CSV Import Status](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N350581.html).

If you want to change an import's queue number during the time that the import is running, you'll need to cancel the job and resubmit it with the new queue number.

-   If the job has a status of Pending, you can step through the Import Assistant again to change the queue number and resubmit.
    
-   If the job is Processing, you must download the CSV results file, which has entries for every canceled CSV file row. You must use this results file as the CSV file when you step through the Import Assistant again to change the queue number and resubmit.
    

Your queue number selection is preserved if the import is saved and rerun is the same account. The queue number is always defaulted back to 1 for a saved CSV import that is bundled, so that users in a target account where the bundle is installed can make their own queue selection.

For more information, see [Use Multiple Threads and Multiple Queues to Run CSV Import Jobs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N347015.html).
