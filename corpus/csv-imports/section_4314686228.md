The following table shows the subrecords for which you may be able to add or update data through CSV imports. These subrecords depend upon the features enabled in your account. You can see the subrecords available in your account for a particular record type on the Import Assistant's Field Mapping page.

Note:

Some related data may be structured as a sublist rather than as a subrecord of a record type. If you don't see a subrecord in the table below, see [Supported Sublist Imports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N439528.html) to check if the data is set up as a sublist instead.
