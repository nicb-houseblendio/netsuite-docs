On the Import Assistant Field Mapping page, you need to map CSV file columns to NetSuite fields, so that data is imported into records correctly. For a matrix items import, the key fields that you need to map are:

-   Item Name/Number
    
-   Matrix Type
    
-   Subitem of
    
-   Each matrix option field
    

Depending on your CSV file column names, the first three fields may be mapped automatically. You must manually map each matrix option field. Notice that in the NetSuite Fields pane, matrix option fields have names with the format **Matrix Option - <Custom\_List\_Name>**.
