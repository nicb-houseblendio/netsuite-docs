Important:

This option is available only in accounts that have purchased a SuiteCloud Plus license.

By default, a single thread is used to process an import job, and all CSV file rows are submitted in order. The Use Multi-Threading option for an import enables the use of multiple threads to process the import, to optimize performance. By default, this option is disabled.

Only check the Use Multi-Threading box if your CSV rows don't need to be in order. With multi-threading, you can't predict the order rows will be submitted.

If you save the import, your choice for this option is kept both when you reuse it in the same account and when it's bundled and used in another account.

For more information, see [Use Multiple Threads and Multiple Queues to Run CSV Import Jobs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N347015.html).
