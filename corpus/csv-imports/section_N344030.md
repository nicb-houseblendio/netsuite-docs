After you select an import type, you'll see the record types for that category in the Record Type dropdown list. Select a record type from the dropdown list.

![Record Type dropdown list.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/AccountAdministration/CSVImports/RecordType.png)

You should read the CSV file guidelines for your record type and prepare your CSV files before you import. For more details, see [Supported Record Types for CSV Import](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N356360.html).
