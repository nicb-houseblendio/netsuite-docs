A cash refund transaction records the return of funds to customers for an overpayment or credit balance refund request. Each cash refund record can include information such as refund amount, associated customer or credit, payment method, and line items.

The cash refund import feature provides an efficient way to add or update cash refund data in bulk. This feature is useful during historical data migration or when integrating with external systems. Manually entering each cash refund is time-consuming and increases the risk of errors, especially in high-volume operations. By using the CSV Import Assistant, you can import or update all mapped fields available for cash refunds in the UI, REST, or SuiteScript.

For more information about preparing your data and templates, see [Guidelines for CSV Import Files](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N356211.html).

To start an import, go to Setup > Import/Export > Import CSV Records. In Step 1 of the Import Assistant, select **Transactions** as the import type and **Cash Refund** as the record type.

No additional permissions are required to use this feature. Existing cash refund permissions and account settings also apply to CSV imports.

Important:

To link imported cash refunds to other records, such as credits or payments, use unique IDs, preferably external IDs. Only internal and external IDs can be used to link records. Transaction IDs aren't unique and can't be used for linking.

## Supported Cash Refund Sublist Data Imports {#bridgehead_0304033939}

The cash refund import supports the following sublist data:

| Sublist | Notes |
| --- | --- |
| Items | You must import at least one line item for each new cash refund record. On the Field Mapping page, map the required fields for this sublist. For more information, see [Required Items Sublist Fields for Transactions Imports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N451547.html#bridgehead_N451690). You can selectively update line items using the Line/Order Line field or the Item field as the key. For more information, see [Line Item Updates on Transactions Imports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N451889.html). |
| Partners | Available when the Multi-Partner Management feature is enabled. For more information, see [Setting Up the Multi-Partner Management Feature](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1167284.html). You can selectively update line items using the Internal ID, External ID, or Partner field as the key. |
| Sales Team | Available when the Team Selling feature is enabled. For more information, see [Team Selling](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1037318.html). |

## Supported Cash Refund Subrecord Data Imports {#bridgehead_0304035322}

The cash refund import supports the following subrecord data:

| Subrecord | Notes |
| --- | --- |
| Billing Address | By default, the subrecord Address field is read-only, and data from other subrecord fields is copied into it. If you map the Override field and set it to Yes (true), you can import data for the Address field. |
| Items - Inventory Detail | Available when the Advanced Bin/Numbered Inventory Management feature is enabled. For more information, see [Advanced Bin / Numbered Inventory Management](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2271791.html). |
| Shipping Address | By default, the subrecord Address field is read-only, and data from other subrecord fields is copied into it. If you map the Override field and set it to Yes (true), you can import data for the Address field. |

## Cash Refund Import Example {#bridgehead_0304035646}

Here's a sample structure for a cash refund CSV file:

| External ID | Customer | Date | Posting Period | Location | Currency | Item | Amount |
| --- | --- | --- | --- | --- | --- | --- | --- |
| Refund-00001 | Customer ABC | 01/10/2026 | January 2026 | Los Angeles | USD | Winter Jacket | 100 |
| Refund-00002 | Customer DEF | 01/11/2026 | January 2026 | Chicago | USD | Summer Dress | 200 |
