This section describes errors that you may see on an item demand plan import. For more information, see [Invalid Location Reference Key xxx for Subsidiary xxx](#subsect_161520636225).

## Invalid Location Reference Key xxx for Subsidiary xxx {#subsect_161520636225}

The first xxx in the error message is the reference key and the second xxx is the subsidiary. See below the example of the error message:

Invalid location reference key Item no Tax 2 Lbs(US) - BinUSA1\_and\_BinUSA2 for subsidiary `1`

Updating the item demand plan without using an external ID is not possible due to the nature of the record.

Important:

You should use the external ID for the import as it is a straightforward solution for these type of issues.
