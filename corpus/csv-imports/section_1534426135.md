You might see errors like: Invalid purchaseunit reference key xx for unitstype <NULL>, Invalid saleunit reference key xx for unitstype <NULL>, or Invalid stockunit reference key xx for unitstype <NULL>

This error occurs when the Purchase Units, Sales Unit, or Stock Units field is updated without mapping the Units Type field. The Units Type field is set to Null (Blank) on the item record. To fix the error, include the Units Type field on the Field Mapping page as shown below, selecting the appropriate unit type:

Internal ID = Internal ID

Purchase Units = Purchase Units

Sales Units = Sales Units

Stock Units = Stock Units

Units Type = Units Type

Note:

In the UI, you can't select values for Stock, Purchase or Sale Units without first selecting a value in the Units field.
