Specialized two-step Import Assistants are available for the following imports:

-   [Single Journal Entry Import](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N433632.html)
    
-   [Budget Import](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N433988.html)
    
-   [Single Inventory Worksheet Import](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N434282.html)
    
-   [Project Tasks Import](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N438898.html)
    
-   [Web Site Redirects Import](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N439127.html)
    

Note:

These simple imports don't support the SuiteScript API that's available to automate CSV imports through scripting, because they don't support saved import maps.
