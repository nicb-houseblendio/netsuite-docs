Instead of enabling the Overwrite Missing Fields, you can set null values for fields that don't have CSV data. For information, see [Assign Null Values during Field Mapping](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N350094.html).

Keep in mind that Overwrite Missing Fields and Overwrite Sublists work differently. Overwrite Sublists replaces sublist data as a whole, rather than checking for individual fields mapped to CSV file fields without data.
