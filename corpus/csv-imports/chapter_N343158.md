You can use the Import Assistant for most imports of CSV data to NetSuite. The Import Assistant is available at _Setup > Import/Export > Import CSV Records_, if you have the Import CSV File permission.

Before an import, review the information available in [Guidelines for CSV Import Files](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N356211.html) to make sure your CSV files are formatted correctly.

The Import Assistant includes five steps:

-   [Step One Scan & Upload File](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N343532.html)
    
    -   [Select an Import Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N343713.html)
        
    -   [Select a Record Type for Import](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N344030.html)
        
    -   [Choose Import Character Encoding](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N344158.html)
        
    -   [Choose CSV Column Delimiter](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4341195935.html)
        
    -   [Select a File for Import](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N344348.html)
        
-   [Step Two Import Options](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N344550.html)
    
    -   [Choose Data Handling for Import](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N345294.html)
        
    -   [Set Advanced CSV Import Options](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N345887.html)
        
-   [Step Three File Mapping](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N347303.html) (required only for multi-file imports)
    
-   [Step Four Field Mapping](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N347418.html)
    
-   [Step Five Save Mapping & Start Import](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N350233.html)
    

The Assistant verifies each step and doesn't let you proceed if it finds any errors. After you complete these steps, you can run the import job right away or save it to run later.

Warning:

CSV Import of Published Saved Searches is not supported.
