This error happens when the parent item you're referencing is a different item type (like Inventory, Description, and so on) than the item you're importing. The parent item has to be the same type as the items you're importing.

There are two ways to resolve this error:

**Option One**

If the parent item was set up with the wrong item type, delete or inactivate it, then create a new one with the right type.

1.  Go to _List > Accounting > Items_.
    
2.  Check the **Show Inactives box**.
    
3.  Choose an option:
    
    -   Inactivate the parent item by checking the **Inactive** box.
        
    -   Delete the item by editing the item and selecting More Actions > Delete.
        
4.  Go to _Lists > Accounting > Items_.
    
5.  Create the correct item type.
    

**Option Two**

If the parent item being referenced has been set up correctly, select the appropriate record type in the Import Assistant.
