On the Scan & Upload File page, select the delimiter that separates the columns in your CSV file. You can choose from:

-   Comma (,) (the default separator)
    
-   Semicolon (;)
    
-   Pipe (|)
    
-   Space ( )
    
-   Tab
    

The separator you select here overrides any account-level column separator preferences set on the CSV Import Preferences page and your subsidiary's Preferences subtab.
