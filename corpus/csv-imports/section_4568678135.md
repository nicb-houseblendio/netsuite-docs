This section covers errors you might see when importing prospects and contacts. For more information, see [That Record Does Not Exist](#bridgehead_4570154926).

## That Record Does Not Exist {#bridgehead_4570154926}

The error occurs when phone numbers aren't mapped correctly.

To fix the error:

1.  Go to _Lists > Search > Saved Searches_.
    
2.  Click **Customer**.
    
3.  On the Criteria > Standard subtab, add the **Stage is Prospect** filter in addition to any other required fields.
    
4.  In the Results > Columns subtab, add the following fields:
    
    -   Name
        
    -   Phone Number
        
    -   Contact Fields: Name
        
    -   Contact Fields: Internal ID
        
    -   Other required fields
        
5.  Click **Preview**.
    
6.  Click **Export - CSV**.
    
7.  Save the CSV file.
    
8.  Open the CSV file and edit as required (for example, update the phone number field).
    
9.  Save the CSV file.
    

When importing the CSV file, map the fields as follows:

| Your Fields | NetSuite Fields |
| --- | --- |
| Internal ID | Internal ID (Internal ID of Prospect) |
| Company | Company Name (Prospect Folder) |
| Phone | Phone (Prospect Folder) |
| Contact | Contact (Contact Folder) |
| Contact Phone Number | Main Phone (Contact Folder) |
| Internal ID of Contacts | Internal ID (Contact Folder) |
