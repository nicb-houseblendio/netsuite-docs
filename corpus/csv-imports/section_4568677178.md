This section covers errors you might see when importing customers and contacts. For more information, see [Illegal ID. Please enter a name.](#bridgehead_4568677405).

## Illegal ID. Please enter a name. {#bridgehead_4568677405}

This error happens if all these are true when adding a new customer:

-   The customer type is Individual.
    
-   You're also adding a contact
    
-   You selected **Customers and Contacts Together** as the record type in the Import Assistant.
    

You can't add individual customers and contacts together. Only use Customers and Contacts Together for customers with the Company type.

To fix the error and successfully add the individual customer record, in the Import Assistant, choose the following:

**Import Type = Relationship** s

**Record Type = Customers Onl** y

## Invalid company reference key \*\*\*. {#bridgehead_157080493290}

This error happens if the customer you're importing is set to inactive.

To fix it, import the customer and contacts with the customer set to active, then do a mass update to inactivate the customer.
