When the Multiple Currencies feature is enabled, the import of Currency field values is supported for newly created sales orders. The Currency value for a sales order must be one of the currencies defined for the transaction's customer, on the Customer Currencies sublist. See [Currency Management](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N1395057.html) and [Setting Multiple Transaction Currencies for Customers](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N383794.html#bridgehead_N385568).

If the Multiple Currencies feature isn't enabled, the Currency field value for a sales order isn't editable.
