On the Scan & Upload CSV File page of the Import Assistant, select the record category you want to import from the Import Type dropdown list. Record types available for import are grouped into categories, listed alphabetically:

![Import Type dropdown list.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/AccountAdministration/CSVImports/ImportType.png)

The following import types are available. Click on a link below to see the record types available for each import type, so you can select the right type for your import:

-   [Accounting Import Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N357752.html)
    
-   [Activities Import Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N359586.html)
    
-   [Classification Import Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N360930.html)
    
-   [Communications Import Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N363101.html)
    
-   [Custom Records Import](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N363599.html)
    
-   [Customization Import Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N363750.html)
    
-   [Employees Import](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N369952.html)
    
-   [Items Import](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N370470.html)
    
-   [Relationships Import Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N383063.html)
    
-   [Rules Setup Import Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557337546.html)
    
-   [Subscription Billing Import Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1489599497.html)
    
-   [Supply Chain Import Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N394620.html)
    
-   [Support Import Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N404668.html)
    
-   [Transactions Import Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N405613.html)
    
-   [Website Import Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N433102.html)
    

For a list of all record types sorted by import type, see [Supported Record Types for CSV Import](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N356360.html).
