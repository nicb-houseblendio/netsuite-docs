A custom transaction is an instance of a custom transaction type. A custom transaction type lets you adjust your general ledger in ways that differ from the standard transaction types available in NetSuite.

This import is available when both of the following are true:

-   The Custom Transactions feature is enabled at _Setup > Company > Enable Features_, on the SuiteCloud subtab.
    
-   At least one custom transaction type exists in your NetSuite account.
    

To import a custom transaction instance, set the Import Type dropdown list to Transactions. In the Record Type dropdown list, choose the name of the type you want to import.

For details about working with custom transaction types in the UI, see [Custom Transactions Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4172599049.html).
