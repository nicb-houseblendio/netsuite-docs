This section describes errors that you may see on a website import. For more information, see [Invalid category reference key Information for website <NULL>](#bridgehead_4570051625).

## Invalid category reference key Information for website <NULL> {#bridgehead_4570051625}

In the UI, you have to pick a site before you can select a site category for an item.

Because Site is a required field, be sure to include the site name in your CSV and map it during import. Use the name given to the site when it was created in NetSuite.

If you don't want to include the site name in every CSV, you can set a default value for the Site field on the mapping page by clicking the edit icon and choosing a site. Setting a default will fix the error.
