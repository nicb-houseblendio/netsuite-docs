To import CSV data, your role needs the Import CSV File permission. An administrator can assign the permission to a role.

#### To assign the Import CSV File permission to a role: {#procedure_1548425023}

1.  Go to _Setup > Users/Roles > User Management > Manage Roles_.
    
2.  Find the role you want to change. Click the **Edit** or **Customize**.
    
3.  On the Permissions subtab, click Setup.
    
4.  In the Permissions dropdown list, select Import CSV File.
    
5.  Click Add.
    
6.  Click Save.
    

To learn how to view the permissions assigned to a role, see [Reviewing Permissions Assigned to Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N326209.html).
