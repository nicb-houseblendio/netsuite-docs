This section describes errors that you may see on a kit or package import. For more information, see [Invalid item reference key xx](#bridgehead_4570007648).

## Invalid item reference key xx {#bridgehead_4570007648}

To fix the error, verify the following:

-   In your CSV file, use the same format for the member item as you see in the Item dropdown under _Lists > Accounting > Items_.
    
-   You can use the internal ID instead of the member item name. On the Field Mapping page, click the edit icon for the **Members xx : Item (Req) field and** **Choose Reference Type =** **Internal ID**.
    
-   Make sure the member item exists and is active.
