An event record stores details about an activity such as an appointment or meeting. You can create and update event records using the CSV Import Assistant.

On page 1 of the Import Assistant, 'Events' appears as an option in the Record Type dropdown list when you set Import Type to Activities.

In the UI, you can view the event record by going to _Activities > Scheduling > Events_ > New. For details on how to manually create an event record, see [Creating a New Event Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N501988.html).
