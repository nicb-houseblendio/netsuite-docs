This error happens when you import a quantity greater than zero (like Qty 1), but there's no quantity pricing information set for Qty 0 in the item record.

To fix it, make sure you import pricing informtion for Qty 0 first. You can import both Qty 0 and Qty 1 pricing info at the same time.
