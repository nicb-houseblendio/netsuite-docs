The shipping items record is used to specify settings for the plug-in, labels, and tax schedule. Depending on the plug-in, you can assign a carrier account for each shipping item or for each location. For more information, see [Ship Central Plugins for Shipping Items](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111040332.html#subsect_0219024811).

-   If you have a Commerce website, you can add settings for the **Display in Website** column.
    
-   If you use the Shipping Label Integration feature, you can include the following columns in your CSV file: **Shipping Partner (Label), Service Group (Label), and Service (Label)**. Be sure to assign the same plug-in for the label and rating columns.
    
    If you set the Print Return Labels preference, you can also include the **Service (Return Label)** column. Note that this column applies to direct shipping on fulfillments for FedEx, UPS, or USPS only. See [Setting Ship Central Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0219032354.html).
    
-   After you import records, you can set the **Shipping Label Integration** box if you use the Shipping Label Integration feature for FedEx, UPS, or USPS only. Be sure to check this box on each shipping item for which you want to enable direct packing and shipping on fulfillments. For more information, see [Setting Up Direct Packing and Shipping on Fulfillments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0219030324.html).
    

The shipping item record is available for import if you use the NetSuite Ship Central SuiteApp. You can create and update it using the CSV Import Assistant. Within the Import Assistant, on the Scan & Upload CSV File page, Shipping Items (Ship Central) appears as an option in the Record Type field.

Within the NetSuite UI, you can access and create a shipping item record at Lists > Accounting > Shipping Items. For help working with this record manually, see [Creating Shipping Items for your Shipping Services](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111040332.html).

The Import Assistant is available at Setup > Import/Export > Import Tasks > Import CSV Records. After you select the record type for import, choose the import character encoding. For more information, see [Select a Record Type for Import](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N344030.html) and [Choose Import Character Encoding](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N344158.html).
