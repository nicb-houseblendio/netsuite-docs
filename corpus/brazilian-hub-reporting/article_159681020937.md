Access to Brazilian Hub Reporting (BRHub Reporting) features requires several specific permissions. The roles assigned to users include these required permissions.

For more information about roles, see [NetSuite Users & Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N284861.html).

When you install the Brazilian Hub Reporting SuiteApp, the following standard NetSuite roles automatically include the required permissions to access BRHub Reporting features.

-   A/P Clerk
    
-   A/R Clerk
    
-   Accountant
    
-   Accountant (Reviewer)
    
-   Administrator
    
-   Bookkeeper
    
-   Buyer
    
-   CEO
    
-   CEO (Hands Off)
    
-   CFO
    
-   Chief People Officer (CPO)
    
-   Customer Center
    
-   Employee Center
    
-   Full Access
    
-   Human Resources Generalist
    
-   Intranet Manager
    
-   NetSuite Support Center (Basic)
    
-   Online Form User
    
-   Partner Center
    
-   Retail Clerk
    
-   Retail Clerk (Web Services Only)
    
-   Sales Administrator
    
-   Sales Manager
    
-   Sales Person
    
-   Sales Vice President
    
-   Shopper
    
-   Store Manager
    
-   System Administrator
    
-   Vendor Center
    

The following Brazilian Hub SuiteApp custom roles are also granted permissions to access Brazilian Hub Reporting features:

-   BRHub - Admin
    
-   BRHub - Contador
    

For more information about Brazilian Hub SuiteApp Roles and Permissions, see [Roles and Permissions for Brazilian Hub](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_159896342406.html).

You must use these standard and custom roles as references to create your own roles, in accordance with your company's security policies.

The roles created from the aforementioned standard roles and from the SuiteApp's custom roles inherit the permissions assigned to the original roles.

If you create any roles from standard or custom roles not listed in this section, the required permissions aren't inherited.

For more information about the creation and customization of roles, see [Customizing or Creating NetSuite Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N285937.html).

If you need to review or customize roles in your account, consider the required permissions to access Brazilian Hub Reporting features.
