NetSuite uses status requests to verify that the R-2099 event was succesfully sent and collect the receipts. The system executes the process of requesting the status automatically.

If you created the EFD-Reinf - R-2099 e-document template, you must also create the R-2099 status request template.

#### To create the R-2099 status request template:

1.  Go to Setup > E-Documents > E-Document Templates > New.
    
2.  In the **Name** field, enter **EFD-Reinf - R-2099 Consulta**.
    
3.  In the **E-Document Package** field, select **BRHub E-Document**.
    
    For more information, see [Creating the Brazilian E-Document Package for Electronic Invoices for Goods (Brazilian Hub SuiteApp)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160106176419.html).
    
4.  In the **Custom Data Source Plugin Implementation** field, select **BRHub Certification Data Source Plug-in**.
    
5.  In the **Transaction Type** field, select **Invoice**.
    
6.  In the **Subsidiary** field, select the Brazilian subsidiaries that send EFD-Reinf events.
    
7.  In the **Content Type** field, verify that the displayed option is **XML**.
    
8.  In the **Template for Outbound E-Documents** field, enter the XML content of the outbound e-document template.
    
    The XML file is available in the File Cabinet of your NetSuite account. For more information, see [Predefined E-Document Template Files for Brazil (Brazilian Hub SuiteApp)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161773143849.html).
    
9.  Click **Save**.
