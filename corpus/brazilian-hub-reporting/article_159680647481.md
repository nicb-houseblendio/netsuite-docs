This topic guides you through the installation of the Brazilian Hub Reporting SuiteApp (BRHub Reporting).

Note:

BRHub Reporting is a shared bundle and can only be installed in previously authorized accounts. For more information, contact your account manager.

-   [Brazilian Hub Reporting Installation Prerequisites](#subsect_158100184032)
    
-   [Installing the Brazilian Hub Reporting SuiteApp](#subsect_158100186578)
    

## Brazilian Hub Reporting Installation Prerequisites {#subsect_158100184032}

To install the Brazilian Hub Reporting SuiteApp, first you must install the following SuiteApps:

-   NetSuite SuiteApps License Client
    
    For more information, see [Installing the NetSuite SuiteApps License Client](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4635371677.html#bridgehead_4635397694).
    
-   Former Brazil Localization
    
    For more information, see [Installing the Former Brazil Localization SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4658913680.html#bridgehead_4658916845).
    
-   Electronic Invoicing
    
    For more information, see [Installing and Setting Up Electronic Invoicing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4592549826.html).
    
-   LATAM E-Document Certification
    
    For more information, see [LATAM E-Document Certification SuiteApp Installation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160320094693.html).
    
-   Brazil Certification Tax Authorities
    
    For more information, see [Brazil Certification Tax Authorities SuiteApp Installation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160518990089.html).
    
-   Brazilian Hub
    
    For more information, see [Brazilian Hub](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_158773778810.html).
    

Note:

If you need to issue electronic invoices to more than one country, contact your account manager to acquire additional licenses.

For additional information, contact your account manager.

## Installing the Brazilian Hub Reporting SuiteApp {#subsect_158100186578}

The Brazilian Hub Reporting SuiteApp (Bundle ID: 334884) is a managed bundle. Whenever there are enhancements or new features added, your account is automatically updated. You can install the Brazilian Hub Reporting SuiteApp by performing the following steps:

#### To install the Brazilian Hub Reporting SuiteApp:

1.  Go to _Customization > SuiteBundler > Search & Install Bundles_.
    
2.  In the **Keywords** field, enter **Brazilian Hub Reporting**, or **334884**, the Bundle ID.
    
3.  Click **Search**.
    
    Brazilian Hub Reporting, Bundle ID 334884, should appear in the search results.
    
4.  Click on the **Brazilian Hub Reporting** link.
    
5.  On the Bundle Details page, click **Install**.
    

For more information about installing SuiteApps, see [Installing a Bundle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3395142.html).

To uninstall the bundle, see [Uninstalling a Bundle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3400972.html).
