To set up your NetSuite account according to business requirements in Luxembourg, you must adjust your NetSuite company, and subsidiary settings.

Note:

If you don't have the permissions to set up company preferences specific to Luxembourg, please contact your account administrator.

#### To adjust NetSuite company settings:

1.  Go to _Setup > Company > Setup Tasks > State/Provinces/Counties_.
    
2.  Add a record for each of the following cantons:
    
    -   Bertrange
        
    -   Contern
        
    -   Hesperange
        
    -   Luxembourg
        
    -   Niederanven
        
    -   Sandweiler
        
    -   Schuttrange
        
    -   Steinsel
        
    -   Strassen
        
    -   Walferdange
        
    -   Weiler-la-Tour
        
3.  Go to _Setup > Company > Preferences > General Preferences_
    
    1.  In the **Date Format** field, select the format DD/MM/YYYY. In the **Long Date Format** field, select DD Month YYYY (J Mois AAAA).
        
    2.  In the **Number Format** field, select the number format used in Luxembourg.
        
    3.  On the Accounting Contexts subtab, create an accounting context (for example, you can call it Luxembourg) if your main Chart of Accounts isn't the statutory Luxembourg Chart of Accounts. For more information, see [Accounting Contexts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4640155582.html).
        
    4.  On the **Languages** subtab, select the languages to which you want to translate information that appears on your website or printed transactions. French (France), Deutsch, and English are available.
        
    
    For more information about localizing preferences in NetSuite, see [General Personal Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N475661.html).
    
4.  Click **Save**.
    
5.  Go to _Setup > Company > Setup Tasks > Company Information_
    
    1.  Set the currency for Luxembourg. For more information, see [Setting a Base Currency](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1397082.html).
        
        This will be the currency of the top parent subsidiary if you have multiple subsidiaries.
        
    2.  Enter the VAT registration number for the parent subsidiary.
        
    3.  Select the time zone: (GMT+01:00) Brussels, Copenhagen, Madrid, Paris
        
6.  Click **Save**.
    

#### To adjust NetSuite subsidiary settings:

1.  Go to _Setup > Company > Classifications > Subsidiaries_
    
2.  Create a subsidiary record for each of your legal entities. For more information, see [Creating Subsidiary Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N272471.html).
    
3.  On the Subsidiary page:
    
    -   (For NetSuite accounts without SuiteTax) On the **VAT Registration No.** field, fill in the VAT registration number.
        
        (For NetSuite accounts with SuiteTax) On the Tax Registrations subtab, add your VAT registration number, the country, nexus, and the tax agency of the country.
        
    -   (Optional) Check the **GL Impact Locking** box to enable this feature on the subsidiary.
        
        This option is visible in NetSuite OneWorld and only when the GL Audit Numbering feature is enabled. When you use GL Impact Locking for a company or a subsidiary, any change to a general ledger impacted field or entity field on a transaction with a GL audit number assigned automatically generates copy and reversal transactions. These transactions display on the **GL Impact** subtab of the original general ledger impacted transaction. For more information, see [GL Impact Locking](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4725785967.html).
        
    -   (Optional, if you've enabled the Period End Journal Entries feature) Check the **Enable Period End Journal Entries** box. Define additional settings for the Period End Journal Entries feature through the Subsidiary Settings Manager page. For more information, see [Defining Subsidiary Settings for the Period End Journal Entries Feature](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1552310613.html).
        
        The Period End Journal Entries feature processes and posts subsidiary consolidation and income statement closing using a transaction type called Period End Journal. Period End Journals are generated automatically when you complete the Create Period End Journals task on the Period Close Checklist. For more information, see [Period End Journal Entries](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1531269686.html).
        
4.  (Optional) If you have subsidiaries in different countries, which require different format settings such as date, number, time zone, and CSV column delimiter, set those preferences on the **Preferences** subtab.
    
    Note:
    
    If you have subsidiaries in different countries with different format settings, you can select language preferences for each subsidiary. Go to Setup > Company > Preferences > General Preferences and select the language in the **Languages** subtab. For more information, see [Configuring Multiple Languages](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N247147.html).
    

## Adjusting NetSuite User Preferences {#bridgehead_156820521059}

As a best practice, define preferences at the company or subsidiary level. User preferences usually take precedence over the other preferences set for role, subsidiary, or company. If a user is linked to a subsidiary, that user will inherit the settings set on the subsidiary record. For more information, see [General Personal Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N475661.html).

#### To set user preferences for Luxembourg Account:

1.  Go to _Home > Set Preferences_.
    
2.  Go to the **General** subtab:
    
    1.  In the **Localization** subtab, set your language and time preferences.
        
    2.  In the **Formatting** subtab, set the date and time formats.
        
3.  Click **Save**.
