## Quality Inspections {#subsect_45161308035}

-   For [Creating a Data Field](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0516024831.html):
    
    -   **Limitation** - You can only create up to 40 data fields per inspection.
        
    -   **Optimal practice** - You should create 30 data fields per inspection.
        
    
    For more information, see [Quality Inspections](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1525966493.html).
    
-   By default, an inspection with simple sampling includes the **Defect Count** and **Samples Inspected** inspection data fields.
    
    You can delete these fields and the associated pass/fail criteria from the corresponding inspection, but you should avoid this practice.
    
-   Only mark an inspection as **Is Inactive** if you don't want it to be processed.
    
    You shouldn't collect data or do evaluations on an inactive inspection. You also can't change or select an inactive inspection for a new specification. For more information, see [Assigning a Quality Inspection to a Specification](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0609082642.html).
    
-   For [Quality Inspection Sampling for CSV](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159343551243.html):
    
    -   **Sample Row Threshold for CSV** - The default value is 25.
        
        To configure the threshold sample row count to enable the CSV upload option for sample data, complete [Configuring Sample Row Threshold for CSV](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163708719556.html).
        
    -   **Optimal practice** - You should create the following:
        
        -   30 data fields per sample for CSV upload
            
        -   500 maximum sample rows for CSV upload
            

## Quality Specifications {#subsect_8161326660}

-   For [Creating a Quality Inspection](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0516021348.html):
    
    -   **Limitation** - You can only create up to 35 inspections per specification.
        
    -   **Optimal practice** - You should create 20 inspections per specification.
        
-   Only mark a specification as **Is Inactive** if you do not want it to be processed.
    
    You can't change or select an inactive specification for a new context definition. For more information, see [Adding a Specification Conformance Rule](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0609082652.html).
    
-   When [Creating a Specification Context](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0520024952.html), you should only select **Production Result** as the **Transaction Type** if you report data through Advanced Manufacturing.
    

## Ad Hoc Inspection Queues {#subsect_29162925336}

-   Make sure you manually create [Ad Hoc Inspection Queues](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_164133114727.html) to trigger ad hoc inspections.
    
-   To trigger inspection queue generation for inventory transactions with reference to relevant NetSuite parent transactions, complete [Creating an Ad Hoc Inspection Queue With a Transaction Reference](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_164133124036.html).
    
-   If you want to inspect an item available in inventory from a specific bin or inventory status, complete [Creating an Ad Hoc Inspection Queue Without a Transaction Reference](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_164133132194.html).
    

## Quality Management Saved Searches and Workflows {#subsect_89162639709}

-   [Quality Management Saved Searches](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_164133163593.html) and [Quality Management Workflows](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_164133175329.html) are automated in your account. Some saved searches and workflows require action before you can use them.
    
    Review the respective topics and configure the necessary steps.
    
-   Quality Management saved searches and workflows are not integrated with ad hoc inspection queues with a parent transaction reference.
    
-   You can only implement either the Receipt Quarantines or Enhanced Receipt Quarantines workflow at one time.
    
    For more information, see the following topics:
    
    -   [Receipt Quarantines Workflows](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0711042151.html)
        
    -   [Enhanced Receipt Quarantine Workflow](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0713044724.html)
        
-   To configure the Enhanced Receipt Quarantines workflow properly, you need to assign the same **Pre-Inspection Bin** for the **Fail**, **After Data Creation**, and **Pass** states.
    
    For more information, see [Configuring the Enhanced Receipt Quarantines Workflow](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0712050051.html).
    

## Certificate of Analysis (COA) {#subsect_42162346922}

If you add a COA data field to an inspection, make sure you report all lots during inspection because the system ignores skip lot functionality. For more information, see the following topics:

-   [Creating a Quality Inspection](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0516021348.html)
    
-   [Defining a Certificate of Analysis (COA) Field](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163595953790.html)
    

## Derived Field Plug-in Implementation {#subsect_50162302326}

-   Only use the [Derived Field Plug-in Implementation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163346884060.html) if you know JavaScript and have experience with it.
    
-   Set up the right people to get an email if your plug-in fails.
    
    For more information, see [Email Recipients for a Derived Field Plug-in Implementation Failure](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163708713800.html).
    

## Quality Management Tablet Interface {#subsect_59130053565}

-   For [Quality Management Mobile Data Collection](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1503422114.html), with a network speed of 25 MB/s, you can upload images up to 7MB.
    
-   You have to enter data field values manually during inspection.
    
-   You can't customize the tablet header.
