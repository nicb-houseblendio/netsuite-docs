The following table the scenarios, action taken by the user, and their impact. The Smart Count SuiteApp lets you count inventory items, serialized items, and lot numbered items.

| Scenarios | User Action | Impact |
| --- | --- | --- |
| Change in quantity on hand for an item during count. | On the Smart Count Preference page you have set the Default Action for On-Hand Change During Count preference. If this preference is set, the SuiteApp provides options based on the preferences set. For more information, see [Setting Up Smart Count Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_46154957887.html). | If you choose to continue count, the SuiteApp updates the existing item count record. |
| If you choose to recount, the SuiteApp creates a new item count record and cancels the existing record. |
| Recounting an item with **Pending Approval** or **Tolerance Error** statuses. | You performed spot count to recount the item. | The SuiteApp creates a new item count record and cancels the existing item count record upon recount. |
| You performed spot count to update the item's count quantity. | The SuiteApp updates the existing item count record. |
| Recounting an item with the status **Approved**. | You performed spot count to recount the item. | The SuiteApp creates a new item count record with the count type as **Nondirected Count**. |
| Rescanning an item whose count is already complete. If you want to rescan an item whose count is complete, the SuiteApp provides you options to either recount or update the existing count. | You performed spot count to recount the item. | The SuiteApp creates a new item count record and cancels the existing record. |
| You performed spot count to update the item's count quantity. | The SuiteApp updates the existing item count record. when the item is rescanned the same day and the status of the item count record is still **Pending Approval** or **Tolerance Error**. However, if the item is rescanned the following day, |
| Recounting an item with **Pending Approval** or **Tolerance Error** statuses on the same day. | \- | The SuiteApp updates the existing item count record |
| Recounting an item with **Pending Approval** or **Tolerance Error** statuses on the following day. | \- | The SuiteApp creates a new item count record for the item. The status of the existing item count record is changed to **Count Superseded** when you complete count. |
