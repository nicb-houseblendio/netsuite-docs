FEFO Lot Assignments preferences are set separately for each location. Following are the preferences:

| Preference | Description |
| --- | --- |
| Location | Select the location for which you want to apply the FEFO lot assignments preferences. |
| Assign Lots on Order Fulfillment | Check this box to assign lots on order fulfillment for orders for the selected location. If this box is not checked, the SuiteApp commits and assigns lots for orders for the selected location. |
| Validate Expiry Date when Fulfilling from UI | Check this box to validate the expiry date on lots when fulfilling sales order line items from the following:
-   Assign and Fulfill Orders page
-   **Assign & Fulfill Orders** button in the view mode of the sales order

This check box is available only when **Assign Lots on Order Fulfillment** box is checked. |
| Validate Expiry Date when Fulfilling from CSV or Web Services | Check this box to validate the expiry date on lots when fulfilling sales order line items using the following:

-   CSV Import - Assign and Fulfill Orders page
-   Web services integration

This check box is available only when **Assign Lots on Order Fulfillment** box is checked. |

Note:

If you do not want a preference record for a location, you should delete the record. You must not make the record inactive.
