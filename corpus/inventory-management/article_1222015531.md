Each Smart Count role comes with a set of required permissions. You can also create or customize roles as needed. You can create or customize roles as needed using the Administrator role. For more information, see [Customizing and Creating Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N286284.html).

Note:

Some permissions require enabling features such as Bin Management, Inventory Status, Classes, and Multiple Calendars. Go to Setup > Company > Enable Features to enable these features.

After assigning the required permissions, provide access to the following:

-   Count Review and Dashboard pages
    
-   Deployment records
    
-   Mobile app (for employees with custom inventory counter roles)
    

For information, see [Providing Access for Custom Smart Count Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1222015535.html).
