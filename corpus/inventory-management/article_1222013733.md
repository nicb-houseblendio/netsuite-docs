Complete the following prerequisites in the order specified:

1.  Ensure you have a OneWorld account. For more information, see [Introduction to NetSuite OneWorld](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N266468.html).
    
2.  Enable the required features. For more information, see [Enabling Features](#subsect_22150131613).
    
3.  Install the SCM Mobile SuiteApp.
    
    For more information, see [Installing the SCM Mobile SuiteApp](#subsect_9170454555).
    
4.  Install the Smart Count Foundation SuiteApp. For more information, see [To install the Smart Count Foundation SuiteApp:](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0620114413.html#procedure_23150907131)
    

## Enabling Features {#subsect_22150131613}

You must enable the following features before installing the Smart Count SuiteApp.

To enable the features, go to Setup > Company > Enable Features.

-   Advanced Inventory Management
    
-   Advanced Item Location Configuration
    
-   Bar Coding and Item Labels
    
-   Bin Management
    
-   Client SuiteScript
    
-   Custom Records
    
-   Inventory
    
-   Inventory Count
    
-   Locations
    
-   Lot Tracking
    
-   Multi-Location Inventory
    
-   Serialized Inventory
    
-   Server SuiteScript
    

## Installing the SCM Mobile SuiteApp {#subsect_9170454555}

To use your mobile device for inventory counting, you must install the SCM Mobile SuiteApp prior to installing the Smart Count SuiteApp.

For information about the mobile device hardware and software requirements, see [Hardware and Software Requirements](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161495429711.html#subsect_161495524434).
