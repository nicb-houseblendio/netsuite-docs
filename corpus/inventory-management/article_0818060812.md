When Supply Allocation sets the Expected Ship Date on order transactions, it also assigns the Expected Receipt Date on transfer orders and inter-company transfer orders. NetSuite calculates the receipt date based on the Expected Ship Date and the corresponding lead time.

You can set the lead time using the Override Lead Time (In Days) field on the transfer order record itself. Using this field, NetSuite calculates the Expected Receipt Date by adding the Override Lead Time (In Days) to the Expected Ship Date.

If the Override Lead Time (In Days) field is blank, NetSuite calculates the lead time using the selected Replenishment Method for the item, such as:

-   **Master Production Schedule** or **Material Requirements Planning** - If you use the Material Requirements Planning feature:
    
    For both methods, Supply Allocation uses the lead time from a planning rule group that applies to the item, to location, and from location of the order.
    
    Before applying other rule groups, NetSuite gives priority to your Default Planning Rule Group preference from Accounting Preferences > Items/Transactions > Inventory.
    
    Note:
    
    A planning rule group may be applied indirectly to an item through a planning item group. See the help topic [Creating Planning Item Groups](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_161944820656.html).
    
-   **Time Phased** - If you use the [Setting Up Distribution Resource Planning](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4049500343.html) feature:
    
    For items replenished through the time-phased method, Supply Allocation uses the lead time from the related Bill of Distribution record based on these transfer order details:
    
    -   From Location
        
    -   To Location
        
    -   Line Item
        
-   **Reorder Point**
    
    Supply Allocation uses the lead time for the transfer order from the Default Lead Time Between Locations preference.
    
    For more information about this preference, see the help topic [Setting Transfer Order Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2310077.html).
    

To manually set the Expected Ship Date and the Expected Receipt Date, set the Allocation Strategy column to **Do Not Allocate** on the line item.

To assign a replenishment method to an item, see the help topic [Entering Inventory Management Details](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1504284487.html).

If none of the above is set, NetSuite derives the lead time from the Default Lead Time Between Locations preference. You can find this at Accounting Preferences > Order Management > Transfer Orders.
