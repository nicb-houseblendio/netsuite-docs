The Inventory Optimization Results Dataset displays stored optimization results for each item-location combination. It includes service level information, demand and lead-time metrics, and stored planning values for Reorder Point planning. The Inventory Optimization Results Workbook uses this dataset as its data source. SuiteAnalytics doesn't recalculate the stored planning values.

## Dataset Configuration {#subsect_0807045545}

The Inventory Optimization Results Dataset is based on the Inventory Optimization Result record. It provides joins to Item, Location, Item Location Configuration, and Inventory Optimization Segment. To customize the standard dataset, use **Save As** to create your own version. For more information, see [Defining a Dataset](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544122173.html).

Consider the following information before you use or customize the dataset:

-   Before you use this dataset, enable Advanced Inventory Management and Inventory Optimization on the Enable Features page. To segment inventory by item-location, also enable Advanced Item Location Configuration. For instructions, see [Enabling Inventory Optimization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_2201400988.html).
    
-   The displayed results reflect completed inventory level calculations. If calculation inputs change, the displayed results update only after a scheduled or manual calculation successfully processes the item-location.
    
-   Your role needs the SuiteAnalytics Workbook permission at the Edit level and the Inventory Optimization permission at the View level or higher. By default, the standard dataset is shared with all users. Only administrators can change the permissions.
    
-   The standard dataset shows stored Inventory Optimization Result records whose Inactive field is false. Inventory optimization processing writes these values; SuiteAnalytics doesn't recalculate them.
    
-   The standard dataset doesn't include current item-location quantity fields.
