You can view, but not manually create or edit, item count records in the Smart Count SuiteApp. To view an item count record, go to Transactions > Smart Count > Item Count.

When a count starts, the SuiteApp creates an item count record.

The record status is set to **In Progress**.

When the count is completed, the SuiteApp updates the **Last Count Date** and **Last Count Reason** fields in the Item Location configuration.

Important:

Item count records can only be created through the mobile application, not through the user interface.

Each item count record includes the following fields:

| Field | Description |
| --- | --- |
| Item | Displays the item being counted. |
| Location | Shows where the item is stored. |
| Bin | Indicates the bin associated with the item. |
| Status | Displays the current status of the count. For more information, see [Item Count Statuses](#subsect_1224044337). |
| Count Type | Shows if the count is directed or a spot count. |
| Configuration Reference | Links to the related count configuration record. |
| Inventory Adjustment | Links to the inventory adjustment record. This is created automatically when a count is approved. If not approved, this field is blank. |
| ID | Shows the unique identifier for the item count record. |
| Owner | Displays the name of the employee who performed the count. |
| Date Created | Shows when the record was created. |
| Last Modified | Displays the date and time of the last modification. |
| By | Shows the name of the employee who last modified the record. |
| Remarks | Displays comments entered by the counter during the count. |
| System Remarks | Shows system-generated comments. For more information, see [System-Generated Comments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0701030107.html). |
| Count Reason | Displays the reason for the count. |
| Reviewed By | Shows the name of the employee who reviewed the count. |
| Reviewer Comments | Displays comments from the reviewer. |
| Inventory Status Change | Links to any related inventory status change record. |
| Bin Transfer | Links to any related bin transfer record. |
| Inventory Transfer | Links to any related inventory location transfer record. |
| Recount Assigned To Employee | Shows the name of the employee assigned to perform a recount. |
| Zone | Displays the zone assigned to the item in its bin record. |
| Aisle | Shows the aisle assigned to the item in its bin record. |
| Item Count Details (subtab) | Displays a detailed breakdown of the item's count. |
| Notes (subtab) | Lists changes made to the record. |
| Workflow (subtab) | Shows active workflows and workflow history for the item. |

## Item Count Statuses {#subsect_1224044337}

-   **In Progress** - The count is currently underway.
    
-   **Pending Approval** - The count is waiting for approval.
    
-   **Tolerance Error** - The counted quantity exceeds the allowed tolerance.
    
-   **Approved** - The count has been approved.
    
-   **Rejected** - The count has been rejected.
    
-   **Recount Suggested** - A recount is required for the item.
    
-   **Canceled** - The record was canceled by the user or system.
    
-   **Paused** - The count is temporarily paused.
    
-   **Count Superseded** - A new count was performed before the previous day's count was approved or resolved. The earlier record is marked as **Superseded**.
