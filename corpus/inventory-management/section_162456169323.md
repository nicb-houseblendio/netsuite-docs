The Supply Plan Definition feature enables you to establish supply planning criteria. To perform MRP calculations, you need to define a list of planning parameters as a plan definition.

#### To create a supply plan definition:

1.  Go to _Transaction > Supply Planning > Supply Plan Definitions_ > New.
    
2.  Enter the Supply Plan Definition **Name**.
    
3.  To define how transfer orders work for the plan, select a **Planning Rule Group**.
    
4.  To define how far into the future you want to plan, enter a planning **Horizon (in Days)**. For example, 180 days.
    
5.  To specify a set of items you want in the same plan, select a **Planning Item Group**.
    
6.  Enter a supply plan definition **Description**.
    
7.  To enable pegging, check the **Generate Pegging** box.
    
8.  On the **Scope** subtab, select the **Location** you want to include in this plan.
    
9.  For each location, select a **Demand Source Type**.
    
10.  If sales orders and demand plans are used as demand, check the **Forecast Consumption** box.
     
11.  Click **Save**.
     
     For more information, see [Creating a Supply Planning Definition and Schedule](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159180786193.html).
