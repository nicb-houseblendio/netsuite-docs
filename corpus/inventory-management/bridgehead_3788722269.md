When the Item Commitment Transaction Ordering preference is set to Order by Order Priority, lines on the following transactions display a Firmed box:

-   work order
    
-   sales order
    
-   transfer order
    

When the Firmed box is checked, the line items are no longer eligible for reallocation to another order. The items must remain committed to the firmed order.

You can also use the Mass Update function to firm orders.
