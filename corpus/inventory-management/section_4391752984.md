The return materials authorization (RMA) lets the customer send defective products back to the supplier for a refund, replacement, or repair. When you've decided what action to take for a claim, you can create an RMA to start processing it.

See the following topics for creating the RMA:

-   [Creating Return Authorizations for Warranty Claims](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4391869751.html)
    
-   [Viewing Related Warranty Claim Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_3938321665.html)
    
-   [Approving Return Authorizations for Warranty Claims](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_3938324114.html)
    

On the RMA record, you can create an item receipt for the warranty item the customer returned. You can also create a transaction to handle the refund, repair, or replacement. For more information about processing the claim after you receive the warranty item, see the following topics:

-   [Creating Item Receipts from Warranty Return Authorizations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4391872321.html)
    
-   [Managing Refund, Repair, and Replacement Claims](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4391753773.html)
