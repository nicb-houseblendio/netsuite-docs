## Overview {#bridgehead_59122929357}

The Smart Count SuiteApp enables real-time inventory counts during business hours, so operations continue uninterrupted. As you count, the SuiteApp records on-hand quantities and notifies you of any changes, allowing you to set default actions for such events.

Supported item types include lot-numbered and serialized Assembly/Bill of Materials and inventory items (lot-numbered, serialized).

Smart Count works with the SCM Mobile SuiteApp, allowing you to perform both directed counts (from a task list) and spot counts (ad hoc). It supports bins, units of measure, and inventory status tracking.

After counting, you can review, approve, reject, or assign recounts for discrepancies. The Smart Count dashboard provides visibility into counts and variances across locations.

### Smart Count Features {#subsect_1222122103}

The Smart Count SuiteApp lets you:

-   Perform directed inventory count using a system-generated task list based on user-defined saved searches. For more information, see [Creating and Managing Count Configurations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0620044529.html) and [Performing Inventory Count on Mobile Devices](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_49120505206.html)
    
-   Enforce blind count to prevent displaying expected item quantity for a specific item or all items. For more information, see [Setting Up Smart Count Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_46154957887.html).
    
-   Define quantity, amount, quantity percentage, and amount percentage tolerances of inventory items at the item and company levels. For more information, see [Setting Up Smart Count Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_46154957887.html).
    
-   Automatically approve item count variance within tolerance at the item, bin, and inventory status levels. For more information, see [Setting Up Smart Count Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_46154957887.html).
    
-   Review item count records to approve, reject, or mark items for recount. For more information, see [Working with Smart Count Review](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0620044825.html).
    
-   Perform spot counting by picking any item for count. For more information, see [Performing Inventory Count on Mobile Devices](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_49120505206.html).
    
-   Automatically increment the count quantity by one through tally scanning. For more information, see [Item Count Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_2145847230.html).
    
-   Perform inventory counting during business hours without having to stop business operations. For more information, see [Item Count Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_2145847230.html).
    
-   Scan GS1 bar codes to perform inventory count. For more information, see [GS1 Barcode Scanning for Inventory Counts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1222055829.html).
    

### Quick Start Guide {#subsect_1222123951}

Following is a summary of the tasks you perform to work with Smart Count.

1.  **Prerequisites**
    
    -   Ensure you have a NetSuite OneWorld account.
        
    -   Install the SCM Mobile and Smart Count SuiteApps.
        
    -   Assign appropriate roles and permissions to employees (such as Inventory Manager, Counter).
        
2.  **Set Up**
    
    -   Configure Smart Count preferences (such as tolerances, blind count, manual entry) at company or item level.
        
    -   Create or use a default count configuration to generate a task list for inventory counting.
        
3.  **Perform Inventory Count**
    
    -   Access the Smart Count app on your mobile device.
        
    -   Select location, zone, and aisle (if using bins).
        
    -   Scan or enter item/bin details and input quantities (manual or tally scan).
        
    -   Tap **Complete** to finish each count.
        
4.  **Review and Approve Counts**
    
    -   Go to Transactions > Smart Count > Count Review.
        
    -   Approve, reject, or assign recounts for item counts.
        
    -   Approved counts update inventory and create adjustment records if needed.
        
5.  **Monitor Progress**
    
    Use the Smart Count Dashboard to track counts, approvals, and variances.
