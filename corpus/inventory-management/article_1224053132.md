After you've reviewed your data, you can approve, reject, or assign items for recount-all from the Report section on the Smart Count Review page.

These actions are available for item count records with **Pending Approval**, **Paused**, or **Tolerance Error** statuses.

Before you start approving count, ensure to read [Considerations Before Approving Item Counts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1224075415.html).

#### To approve or reject an item count record. {#procedure_1223124310}

1.  Go to Transactions > Smart Count > Count Review.
    
2.  Check the box beside the item count record that you want to approve or reject.
    
3.  Click **Approve** or **Reject**.
    
4.  If you have set the Confirm Before Approving, Rejecting, or Selecting Recount preference, a confirmation message appears. Click **OK**.
    

## Bulk Approve or Reject Item Counts {#subsect_1224074345}

Use the arrow next to **Approve** or **Reject** for **Approve All** or **Reject All**.

## Assigning Items for Recount {#subsect_1224074449}

On the Smart Count Review page, you can mark item count records for recount and assign these recount tasks to specific employees.

To enable employee assignment, first set the **Confirm Before Approving, Rejecting, or Selecting Recount** preference on the Smart Count Preferences page.

After this preference is enabled, the SuiteApp prompts you to select an employee whenever you choose items for recount.

#### To select an item for recount and assigning the task to an employee: {#procedure_1226112934}

1.  Go to Transactions > Smart Count > Count Review.
    
2.  Check the boxes beside the item count records that you want to recount.
    
3.  Check the box beside the item count record that you want to select for recount.
    
4.  Click **Recount**.
    
5.  If you have set the Confirm Before Approving, Rejecting, or Selecting Recount preference:
    
    1.  A confirmation message appears. Click **OK**.
        
    2.  In the Assign Recount popup window, select an employee's name for assignment. If no employee is selected, the task will be assigned to all employees.
        
    3.  Click **OK**.
        
6.  Click **OK**.
    

### Bulk Assign Items for Recount {#subsect_76200820263}

To select all item count records for recount in one go, click the arrow next to the **Recount** button and choose **Recount All**.

When you mark items for recount on the Smart Count Review page, the **Recount** option will appear for those items in the task list.
