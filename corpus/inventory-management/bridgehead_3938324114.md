A return authorization with **Pending Approval** status can be approved or cancelled. On the RMA record, you'll see the approve and cancel options only in view mode. For instructions on accessing an RMA, see [Viewing Related Warranty Claim Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_3938321665.html).

#### To approve a return authorization for a warranty claim:

1.  On the Return Authorization page, make sure the details are correct and complete.
    
    You can edit some details before approving the RMA. For more information about the claim fields that you can edit, see [Creating Return Authorizations for Warranty Claims](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4391869751.html).
    
2.  Click **Approve Return**.
    

After you approve an RMA, you can create an item receipt. If you cancel, the RMA isn't tracked on the claim record and can't be resubmitted for approval or further processing.
