This workbook displays outbound transactions that include sales orders and item fulfillments. These transactions enable you to monitor outbound inventory levels.

## Outbound Pivot Tables {#subsect_157004891270}

The Outbound Workbook contains the predefined pivot table, Sales Orders to Fulfill.

| Pivot Table | Description | Default Value Filters | Default Fields or Rows |
| --- | --- | --- | --- |
| **Sales Orders to Fulfill** | List of unfulfilled and partially fulfilled sales orders | Type: Sales Order Status: Pending Fulfillment, Partially Fulfilled, Pending Billing/Partially Fulfilled | Document Number/ID Date Memo |

You can edit these tables according to your business requirements. For more information, see [Customizing Inventory SuiteAnalytics Workbooks](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156708798705.html).
