When creating item fulfillment for sales order using web service integration, add the following parameters when requesting sales order in edit mode:

| Parameter Name | Parameter ID | Parameter Type | Supported Values | Default Value | Description |
| --- | --- | --- | --- | --- | --- |
| Create IF from Integration | custbody\_fefo\_createif\_frm\_so\_intgrtn | Boolean | 
-   true
-   false

 | false | Determines whether the item fulfillment record should be created. |
| Apply Expiry Date Validation | custbody\_fefo\_apply\_expirydate\_intgrtn | Integer | 

-   **1 or no value** - Take value from FEFO location preference.
-   **2** - Always apply expiry date validation
-   **3** - Never apply expiry date validation

 | 1 | Determines whether expiry date validation should be considered when assigning lots. |
| Fulfillment Date | custbody\_fefo\_fulfill\_date\_fm\_ingrtn | Date | Timestamp | Today's date | Fulfillment date on the item fulfillment record. |
| Posting Period | custbody\_fefo\_post\_period\_fm\_ingrtn | Posting Period | Available accounting periods in the account | Default posting period of the account | Posting period on the item fulfillment record. |
| Shipping Status | custbody\_fefo\_ship\_status\_fm\_ingrtn | Shipment Status | 

-   Shipped
-   Picked
-   Packed

 | Default shipping status | Shipping status on the item fulfillment record. |
