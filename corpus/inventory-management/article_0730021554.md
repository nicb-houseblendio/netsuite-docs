The Pegging Analysis dataset provides demand and supply planning details for items that are assigned the Material Resources Planning replenishment method. You can view pegging chains with single or multiple levels, which enable tracking of dependencies. Using this dataset, you can access pegging data available from the Supply Planning Workbench. To review setup requirements and guidelines, see [Supply Planning Workbench](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159187932855.html).

## Dataset Configuration {#subsect_0730021733}

The Pegging Analysis dataset combines fields shown on the following table. To edit the dataset, see [Defining a Dataset](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544122173.html).

Note the following details about the data available from this dataset:

-   Supply records include all transaction types supported by the Material Requirements Planning feature. Aside from work orders, they include planned orders, inbound shipments, and item demand plans, among others.
    
-   With the Supply Planning feature enabled, only source records with allocated quantity are included in the dataset.
    
-   Independent demand records include sales orders, demand forecasts, and safety stock, among others.
