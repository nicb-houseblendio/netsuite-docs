The Smart Count SuiteApp enables you to perform directed inventory counts using a task list generated from count configuration records.

Tip:

Here are some helpful tips on counting items and reviewing serial or lot numbers.

-   To count items using bins, enable the Bin Management feature and select the Use Bins box on the item record.
    
-   To review scanned serial or lot numbers, click the View Serial Numbers or View Lot Numbers link.
    

Note:

Here are some points to note when counting items:

-   If you select an incorrect zone or aisle, the SuiteApp shows an error but still lets you complete the count. The original zone and aisle values appear in the count record and Count Review page. If you change these values during the count, the SuiteApp updates them accordingly.
    
-   If a zone includes bins without aisle values, select **No Aisle** to view those bins. This option is unavailable if all bins in the zone have aisle values.
    
-   When counting matrix child items, enter items in the following format **Parent Item Name : Child Item Name**.
    

#### To perform directed count using a mobile device: {#procedure_1222013227}

1.  Log in to NetSuite using your mobile device.
    
2.  Based on the role you are using, do any of the following:
    
    -   Go to Setup > Custom > Mobile - App.
        
    -   Go to Mobile Emulator > Mobile Emulator > Mobile Screen.
        
3.  Tap **Smart Count**.
    
4.  Tap a location. Administrators can view task list of all subsidiaries.
    
5.  (WMS users only) If the item uses bins, select the zone and aisle.
    
6.  (Optional) In the **Count Configuration** field, select a count configuration. The default value is **All**.
    
7.  On the task list, under the Action column, tap **Count** beside the item you want to count. The task list displays all items that are due for count on the current day.
    
8.  In the **Scan or Enter Bin** field, scan or enter the bin number if applicable.
    
9.  In the **Scan or Enter Item** field, scan or enter the item's number or UPC code.
    
10.  In the **Inventory Status** field, select the inventory status if the feature is enabled.
     
11.  In the **UOM** field, select the unit of measure lot numbered and inventory items.
     
12.  (Optional) Do these steps when counting serial or lot items if:
     
     -   You didn't set the Ignore Serial Number Until Variance or Ignore Lot Number Until Variance preferences.
         
     -   You selected Recount for items with quantity variance.
         
     
     1.  For serial items, enter serial numbers in the in the **Scan or Enter Serial Number** field.
         
     2.  For lot items, enter lot number in the **Scan or Enter Lot Number** field, or select one from the **Available Lot Numbers** list.
         
13.  Choose your entry method:
     
     -   **Manual Entry** - Press **Tab** to enter the count for lot-numbered items or to increment serial item quantity. Manual entry requires the Allow Manual Count Entry preference.
         
     -   **Tally Scanning** - Press **Enter** for tally scanning to increment the quantity by 1 for each scan.
         
14.  In the **Current Quantity** field, enter the quantity. The **Total Quantity Counted** field updates with the cumulative total and can be edited if needed. For more information, see examples in [Managing Directed and Spot Inventory Counts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1222062601.html).
     
15.  Repeat Step 8 through Step 12 to count items with different inventory statuses and units of measure.
     
16.  Tap **Complete** to finish the count.
     

After completing an item count, the count status is set to **Done**. The Counted Items page lists all items with status **Done**. Items that are in **Approved** state are removed from the task list.

To access the Counted Items page, tap **Counted Items** from the Smart Count menu on a mobile device.
