The Manufacturing Dispatch List shows outstanding operation tasks that you can give to teams.

On the Manufacturing Operation Task record, the **Dispatched** box is automatically checked after the task is included and printed out on a Dispatch List.

#### To print a manufacturing dispatch list:

1.  Go to Transaction > Management > Supply Chain Management.
    
    Alternatively, you can go to Transaction > Manufacturing > Print Manufacturing Dispatch List.
    
2.  On the Supply Chain Management page, under Manufacturing, click **Dispatch List**.
    
    Note:
    
    When you first open the Print Manufacturing Dispatch List page, the table shows forms with the following Work Order and Task Statuses:
    
    -   Work Order Status - In Process (and/or) Released
        
    -   Task Status - In Progress (and/or) Not Started
        
    
3.  On the Print Manufacturing Dispatch List page, select values for the following filters to refine the list of work orders:
    
    -   **Subsidiary**
        
    -   **Location**
        
    -   **Work Center**
        
    -   **Assembly Item**
        
    -   **Work Order Status** - **Released** or **In Process**
        
    -   **Task Status** - **In Progress** or **Not Started**
        
    -   **Dispatched** - **Yes** or **No**
        
4.  To select a dispatch record from the list, do one of the following:
    
    -   On the **Dispatch List** subtab, in the **Select Order Number** field, enter the work order number for the dispatch record you want to print. Press **Enter** after each entry.
        
        NetSuite automatically checks the **Print** box for the selected work order.
        
    -   Check the **Print** box next to to the work order you want to print.
        
    -   Click **Mark All** to select all work orders in the list.
        
5.  Click **Print** or, to return to the Supply Chain Management page, click **Go to Main**.
    

For more information about viewing the printing status, see [Viewing the Form Printing Status](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_3836205962.html).
