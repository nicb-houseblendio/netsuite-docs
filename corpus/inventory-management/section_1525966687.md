The quality administrator designates a file cabinet folder to control image access and manage storage limits.

For more information, see [Creating File Cabinet Folders](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N541665.html).

Quality engineers can use the tablet to take pictures during an inspection and save them for review or to support quality findings. NetSuite automatically uploads images to the chosen folder in the File Cabinet and records them against the inspection.

For more information about storing quality images, see the following topics:

-   [Setting Up Quality Management File Storage](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0617012017.html)
    
-   [Store Quality Management Image Files](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0617012021.html)
    
-   [Data Fields for Quality Management Images](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0617012028.html)
