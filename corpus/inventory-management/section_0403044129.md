You must enable additional features in your NetSuite account before installing the Supply Chain Management SuiteApp. To enable features, go to _Setup > Company > Enable Features_. For more information, see [Enabling Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N232138.html).

| Enable Features Subtab | Features |
| --- | --- |
| Transactions | Advanced Shipping |
| Items & Inventory | Bar Coding and Item Labels |
| Serialized Inventory |
| Lot Tracking |
| Bin Management |
| Inventory Count |
| Manufacturing Routing and Work Center |
| Manufacturing Work in Process |
| CRM | Online Forms Note: This feature is required to avoid errors related to the Available Without Login URL. For more information, see [Errors Related to the Available Without Login URL](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_1524084097.html). |
| SuiteCloud | Advanced PDF/HTML Templates |

To access the Supply Chain Management reports, make sure that Advanced Inventory is provisioned in your NetSuite account. For more information about the reports, see [Printing Supply Chain Management Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4083535108.html).
