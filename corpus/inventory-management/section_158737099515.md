Saved searches help you monitor UPC code usage and item status.

You can also exclude items from automatic UPC assignment as needed.

| Search Name | Description |
| --- | --- |
| UPCs Assigned by System Today | Displays UPCs that are assigned by system in the current date. |
| UPCs not in Use | Displays UPCs that are available for assignment. |
| Items Needing UPC Code | Displays items for which the **UPC Code Assignment** field is set to **Assign New UPC Code** when creating the items. |
| All Assigned UPCs with Item | Displays UPCs that are in use and the items associated with them. |

## Disabling Automatic UPC Assignment {#subsect_1230052251}

If you don't exclude an item, it'll remain inactive until a UPC is assigned.

To exclude an item from automatic assignment, do the following:

-   When creating an item manually, check **Exclude from Auto Assign UPC** on the **Item UPC** subtab.
    
-   When importing through CSV:
    
    1.  Include **Exclude from Auto-Assign UPC** in your CSV and set it to **Yes**.
        
    2.  In Advanced Options, ensure the **Run Server SuiteScript and Trigger Workflows** box is checked.
