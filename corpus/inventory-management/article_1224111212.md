The SuiteApp lets you scan GS1 bar codes to count inventory items, serialized items, and lot numbered items. The following table lists

| Scenarios | User Action | Impact |
| --- | --- | --- |
| Tally Scan for an inventory item | \- | On the item count page, you will notice:
-   Count quantity is automatically populated when you scan a GS1 bar code with quantity details.
-   After scanning, the **Scan/Enter Item** field no longer displays the GS1 bar code.

 |
| Manual count entry for an inventory item | On the Smart Count Preferences page, you have set the Allow Manual Count Entry preference. | On the item count page, you will notice:

-   Count quantity is not populated when you scan a GS1 bar code with quantity details. You need to enter the count quantity manually.
-   After scanning, the **Scan/Enter Item** field continues to display the GS1 bar code.

 |
| Tally scan for lot and serial items | On the Smart Count Preferences page, you have set either of the following preferences:

-   Ignore Lot Number Until Variance
-   Ignore Serial Number Until Variance

 | On the item count page, you will notice:

-   The SuiteApp does not display the **Scan or Enter Lot Number** or **Scan or Enter Serial Number** fields.
-   When you scan a GS1 bar code with quantity, quantity is automatically populated.
-   After scanning, the **Scan/Enter Item** field no longer displays the GS1 bar code.

 |
| Manual count entry for lot and serial items | On the Smart Count Preferences page, you have set the following preferences:

-   Allow Manual Count Entry
-   Ignore Lot Number Until Variance or Ignore Serial Number Until Variance

 | On the item count page, you will notice:

-   The SuiteApp does not display the **Scan or Enter Lot Number** or **Scan or Enter Serial Number** fields.
-   When you scan a GS1 bar code with quantity, quantity is not populated. You need to enter the count quantity manually.
-   After scanning, the **Scan/Enter Item** field continues to display the GS1 bar code.

 |
| Tally scan for lot items | You have performed any of the following actions:

-   On the Smart Count Preferences page, you did not set the ignore Lot Number Until Variance preference.
-   On the Smart Count Preferences page, you have set the Ignore Lot Number Until Variance preference. In addition, you selected the **Recount** option for an item with quantity variance.

 | On the item count page, you will notice:

-   The SuiteApp displays the **Scan or Enter Lot Number** field.
-   When you scan a GS1 bar code with quantity and lot number, quantity and lot number are automatically populated.
-   After scanning, the **Scan/Enter Item** field no longer displays the GS1 bar code.

 |
| Manual count entry for lot items | On the Smart Count Preferences page, you have set the Allow Manual Count Entry. You performed either of the following actions:

-   You did not set the Ignore Lot Number Until Variance preference.
-   On the Smart Count page, you have set the Ignore Lot Number Until Variance preference. In addition, you chose the **Recount** option for an item with quantity variance.

 | On the item count page, you will notice:

-   The SuiteApp displays the **Scan or Enter Lot Number** field.
-   When you scan a GS1 bar code with quantity and lot number, only lot number is populated. You need to enter the count quantity manually.
-   After scanning, the **Scan/Enter Item** field continues to display the GS1 bar code.

 |
| Tally scan for serial items | You have performed any of the following actions:

-   On the Smart Count Preferences page, you did not set the Ignore Serial Number Until Variance preference.
-   On the Smart Count Preferences page, you have set the Ignore Serial Number Until Variance preference. In addition, you selected the **Recount** option for an item with quantity variance.

 | On the item count page, you will notice:

-   The SuiteApp displays the **Scan or Enter Serial Number** field.
-   When you scan a GS1 bar code with quantity and serial number, serial number is populated. Quantity is set as **1**.
-   After scanning, the **Scan/Enter Item** field no longer displays the GS1 bar code.

 |
| Manual count entry for serial items | On the Smart Count Preferences page, you have set the Allow Manual Count Entry. You performed either of the following actions:

-   You did not set the Ignore Serial Number Until Variance preference.
-   On the Smart Count page, you have set the Ignore Serial Number Until Variance preference. In addition, you chose the **Recount** option for an item with quantity variance.

 | On the item count page, you will notice:

-   The SuiteApp displays the **Scan or Enter Serial Number** field.
-   When you scan a GS1 bar code with quantity and serial number, only serial number is populated. You need to enter the count quantity manually.
-   After scanning, the **Scan/Enter Item** field continues to display the GS1 bar code.

 |
