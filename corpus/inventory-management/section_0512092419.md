In an item record, you can clear the **Use Bins** box if you do not use bins or do not store on-hand quantities of the item in bins. If you use the Advanced Bin/Numbered Inventory Management feature, you can disable this setting for one or more locations. You can disable it in location records that have no associated bins and no transactions that reference those bins.

Note the following guidelines to avoid issues when disabling bins:

-   Do not disable bins for an item when you have on-hand quantities and pending transactions that reference them.
    
    Disabling the setting does not include automatic quantity transfers or clearing out of bins. On-hand quantities that remain in bins do not become available for fulfillment and other inventory processes.
    
-   Do not disable either the Bin Management or Advanced Bin/Numbered Inventory Management feature to disable the Use Bins setting for multiple items or locations.
    
-   Avoid switching the Use Bins setting to enable or disable it repeatedly when processing transactions for an item. It may cause quantity discrepancies and processing issues, especially if you have pending transactions that reference the bins.
    

See the following instructions in this topic:

-   [To disable the Use Bins setting for items:](#procedure_43093419600)
    
-   [To disable the Use Bins setting for locations:](#procedure_96093540579)
    
-   [To disable bin features:](#procedure_13093856725)
    

#### To disable the Use Bins setting for items: {#procedure_43093419600}

1.  Verify that you have no pending transactions that reference bins for the item and that affect inventory levels, like fulfillments and adjustments.
    
    Depending on your business requirements, complete or close these transactions.
    
2.  Open the item record in edit mode, and then on the **Inventory Detail** subtab, do the following:
    
    1.  View the list of bins per location and look for bins with on-hand quantities.
        
    2.  To remove and clear out quantities in bins, create an inventory adjustment for each location.
        
        For instructions, see [Entering an Inventory Adjustment](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161981111273.html).
        
        Note:
        
        If you check the **Use Bins** box without removing all on-hand quantities, they appear again on this subtab along with their previous bin assignments.
        
3.  On the **Purchasing/Inventory** subtab, do the following:
    
    1.  On the **Bin Numbers** subtab, remove each bin from the list.
        
    2.  Clear the **Use Bins** box.
        
4.  Click **Save**.
    
5.  Based on your business requirements and features that you use, you can also complete the following procedures:
    
    -   If you do not use the bins for other items, you can access each bin record to inactivate or delete it.
        
    -   If you use the Advanced Bin/Numbered Inventory Management feature, you can disable bins for locations. For instructions, see [To disable the Use Bins setting for locations:](#procedure_96093540579)
        

#### To disable the Use Bins setting for locations: {#procedure_96093540579}

1.  Verify that you do not have transactions that reference bins in the location. Then, check your inactive and active bin records to make sure that none of them are assigned to the location.
    
2.  Open the location record in edit mode.
    
3.  Clear the **Use Bins** box.
    
4.  Click **Save**.
    

#### To disable bin features: {#procedure_13093856725}

1.  Before you disable any of the bin features that you use, review any dependent features and capabilities associated with them.
    
    For more information about bin features, see the following topics:
    
    -   [Bin Management](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2270284.html)
        
    -   [Financial Impact of Disabling Bin Management Feature](https://suiteanswers.custhelp.com/app/answers/detail/a_id/33668/loc/en_US)
        
2.  To access features that you want to disable, see [Enabling Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N232138.html).
    
    If you use both bin features, you can disable the Advanced Bin Management feature before the basic Bin Management feature. For more information, see [Disable Advanced Bin Management Feature](https://suiteanswers.custhelp.com/app/answers/detail/a_id/30972/kw/30972).
