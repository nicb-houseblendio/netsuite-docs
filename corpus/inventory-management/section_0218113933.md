If you use the Purchase Contracts feature, you must designate an entire contract to consigned inventory purchases. You can't combine both consigned and non-consigned items in a single contract.

To add consigned items to a purchase contract, do the following:

1.  At the header of the contract, check the **Consigned** box.
    
    If you check the **Consigned** box on an existing contract that has non-consigned items, a message appears to confirm automatic removal of these items.
    
    If you clear this box, all items in the contract must be non-consigned instead.
    
2.  In each item line that you add, you can select only a consigned item that you want to include in the contract.
    

To create purchase contracts, see [Creating Purchase Contracts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4077190978.html).
