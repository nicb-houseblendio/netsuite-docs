After you create a count configuration record, you can use it to generate a task list for inventory counting.

-   The Smart Count SuiteApp lets you update the **Inventory Count Interval** and **Next Inventory Count Date** fields using the Mass Updates feature.
    
    -   On the Mass Updates page, select a location in the **Inventory Location** field. This updates these fields for items in that location.
        
    -   If you don't select a location, updates apply to items across all locations.
        
-   To deactivate a count configuration record, check the **Inactive** box on the record.
