Running the **SC MR Compute Dashboard Data** script keeps your Smart Count dashboard data current and reduces page load times for key portlets, including:

-   **Approval Summary**
    
-   **Reminders**
    
-   **Smart Count Summary**
    

For more information about the portlets, see [Smart Count Dashboard Portlets Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1224100517.html).

You can schedule this script to process dashboard data at specific times. Set the schedule directly on the script record. The script will then run automatically as scheduled, update the dashboard data, and display a banner message when complete.

To view current data, click **Refresh** on the banner message.

Only users with the Administrators can view dashboard data for all subsidiaries.

## Prerequisites {#subsect_1226112747}

The prerequisites include:

-   You must have the Administrator or Smart Count Inventory Manager roles to access the Smart Count Dashboard and run this script.
    
-   Enable the **Schedule Dashboard Data Processing** preference on the Smart Count Preferences page.
    

Note:

The script uses your company's time zone settings when it runs.

#### To schedule and run the SC MR Compute Dashboard Data script: {#procedure_25153628948}

1.  Go to Customization > Scripting > Scripts.
    
2.  Beside the SC SS Count Review Data script, click **View**.
    
3.  Click the **Deployments** subtab.
    
4.  Click **SC MR Compute Dashboard Data**.
    
5.  Click **Edit**.
    
6.  Under the **Schedule** subtab, set the schedule when you want to run the script.
    
7.  From the **Save** menu, select **Save and Execute**.
