When an RMA is approved or doesn't need approval, the record is set to **Pending Receipt** status. You'll only see the option to create an item receipt in view mode. For instructions on accessing an RMA, see [Viewing Related Warranty Claim Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_3938321665.html).

Note:

For replacement claims, if your account has the **Ship Replacement in Advance** preference enabled, you can create a sales order. This preference lets you send the replacement item to the customer before you receive the warranty item.

For more information about the preference, see [Setting Warranty Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4389382197.html).

For instructions on creating a sales order, see [Creating a Sales Order for a Replacement Claim](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_3938326430.html).

#### To create an item receipt from a return authorization:

1.  On the Return Authorization page, verify that the details are correct and complete.
    
    If you need to edit the RMA before creating the item receipt, click **Edit** to update the record.
    
2.  Click **Receive**.
    
3.  On the Item Receipt page, under the **Items** subtab, enter or select values for the following columns:
    
    1.  **Receive** - Check this box for the warranty item.
        
    2.  **Location** - Select the location for the received item if the Multi-Location Inventory feature is enabled.
        
    3.  **Quantity** - Verify if the quantity of received items is correct.
        
    4.  **Inventory Detail** - Enter the details for serialized and lot numbered items, as indicated on the claim.
        
    5.  **Restock** - Check this box for repair claims. This box means you're going to return the item to inventory.
        
4.  Click **Save** to create the item receipt record.
    
    Tip:
    
    When saving item receipts, click **Save** instead of Save & Refund. The SuiteApp doesn't support cash refunds. For more information, see [Warranty and Repairs Management Considerations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4389346541.html).
    

After you create an item receipt, you can go back to the RMA to process the claim for a refund, replacement, or repair. For more information, see [Managing Refund, Repair, and Replacement Claims](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4391753773.html).

For partially received items, you can process a refund for the returned items or receive more warranty items. The **Receive** option isn't available when you've received all the warranty items or closed the line item.

Item receipts are tracked on their related RMA and claim record. On both records, you'll find item receipts in the **Related Records** subtab. For more information about viewing item receipts on claims, see [Viewing Related Warranty Claim Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_3938321665.html).
