Aside from the default **Consigned - Good** status, you can add more inventory statuses to assign to your vendor consigned items. You can create statuses for all or specific locations. Inventory statuses assigned to a location can't be used for other locations.

When you create or edit your own inventory status, check the **Use for Consigned Inventory** box. You must assign a unique name for each inventory status record, even for those that you inactivate. You can select the default or your own status on transactions and records used for Consigned Inventory Management.

Note the following guidelines when you create or use consigned inventory statuses:

-   If you have items that use regular statuses, make sure that you're able to distinguish them from consigned item statuses. You can append a common label to the name of your consigned item statuses.
    
-   You can neither inactivate nor delete the default inventory status, but you can rename it. Even if you rename it, you can't assign the standard name, **Good** or **good**, to consigned inventory statuses that you create.
    
-   You can't delete your own inventory statuses if you have open transactions that use them. For more information, see [Disabling Consigned Inventory Management](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0218110516.html).
    
-   On transactions that have existing inventory statuses, you can't choose a regular status for consigned quantities of an item. You can only choose a different consigned status for such items.
    

For detailed instructions and other inventory status settings, see [Creating Inventory Status Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1498074763.html).
