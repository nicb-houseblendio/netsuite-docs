The Inventory Count Sheet generates a list of items that you need for inventory counts and inspections. You can print the Inventory Count Sheet only when Inventory Count status is set to **Started**.

#### To print an inventory count sheet:

1.  Go to Transaction > Management > Supply Chain Management.
    
    Alternatively, you can go to Transaction > Inventory > Print Inventory Count Sheet.
    
2.  On the Supply Chain Management page, under Inventory, click **Inventory Count Sheet**.
    
3.  On the Print Inventory Count Sheet page, select values for the **Subsidiary** and **Location** filters to refine the list of available inventory count sheet records.
    
4.  To select an inventory count sheet from the list, do one of the following:
    
    -   On the **Inventory Count Sheet** subtab, in the **Select Inventory Count** field, enter the Inventory Count value for the inventory count sheet you want to print. Press **Enter** after each entry.
        
        NetSuite automatically checks the **Print** box for the selected inventory count sheet record.
        
    -   Check the **Print** box next to the inventory count sheet you want to print.
        
    -   Click **Mark All** to select all inventory count sheet in the list.
        
5.  Click **Print** or, to return to the Supply Chain Management page, click **Go to Main**.
    

For more information about viewing the printing status, see [Viewing the Form Printing Status](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_3836205962.html).
