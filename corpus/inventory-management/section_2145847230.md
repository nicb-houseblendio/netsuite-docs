The Smart Count SuiteApp includes the following count features:

-   **Tally Scanning** - This feature lets you automatically increment the count quantity by one every time an item is scanned.
    
-   **Live Counting** - This feature lets you perform inventory count in real time during business hours. At the start of the count, the SuiteApp records the inventory quantity for each item.
    
    If there are on-hand quantity changes for an item due to transactions taking place during count, the SuiteApp automatically notifies the counter of the change. In addition, the SuiteApp provides options to take an appropriate action for on-hand quantity changes based on the preferences set by the administrator. This helps to continue the inventory count process without pause.
    
-   **Inventory Counting for Different Items in a Bin** - This feature lets you count different items from the same bin and allows you to complete count for all items or for only the item currently selected on the count page.
    
    The SuiteApp lets you choose between **Complete All** and **Complete Selected** options when you try to complete count.
    
    If you choose **Complete All**, count is completed for all counted items in the bin.
    
    If you choose **Complete Selected**, count is completed only for the item currently selected on the count page. The count is paused for all other items counted from the bin.
