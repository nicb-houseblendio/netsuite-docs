When you're working with thousands of records, the Smart Count Review page may load slowly.

To keep the page responsive, schedule the **SC SS Count Review Data** script.

This script processes count data in the background and updates the page with a banner message.

Tip:

To view real-time data, click **Refresh** on the banner message after the script runs.

Prerequisites:

-   Set the **Schedule Dashboard Data Processing** preference on the Smart Count Preferences page.
    
-   Use the Smart Count Inventory Manager or Administrator role.
    

#### To schedule and run the SC SS Count Review Data script: {#procedure_33152654053}

1.  Go to Customization > Scripting > Scripts.
    
2.  Beside the SC SS Count Review Data script, click **View**.
    
3.  Click the **Deployments** subtab.
    
4.  Click **SC SS Count Review Data**.
    
5.  Click **Edit**.
    
6.  Under the **Schedule** subtab, set the schedule when you want to run the script.
    
7.  From the Save menu, select **Save and Execute**.
    

With your data up-to-date and the page loading quickly, you're ready to filter and analyze your inventory counts.
