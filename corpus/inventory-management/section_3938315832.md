You can register any supported item if warranty tracking is turned on in the item record.

-   For serialized items, create one warranty registration per unit.
    
-   For regular inventory, assembly, or lot numbered items, you can have more than one unit per registration.
    

You can create a warranty registration from an invoice, by entering it manually, or by importing details. You can also use SuiteScript and web services.

See the following topics for details and steps for each registration method:

-   [Generating a Warranty Registration](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4391652419.html)
    
-   [Creating a Manual Warranty Registration](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4391653003.html)
    
-   [Importing Warranty Registration Details](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4391653401.html)
    

You can also register warranties for invoice records processed through SuiteScript or web services.

The SuiteApp also automatically registers warranties on invoices made through bulk processing or billing schedules. Make sure you turn on the **Automatically Register Warranty on Invoice** preference for tracked items created through these processes. For more information, see [Enabling Required Features for Warranty and Repairs Management](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_3938301917.html).

After you register a warranty, go to Lists > Warranty and Repairs > Warranty Registration List to see your registrations. You can view the record or edit certain registration details.

For more information about updating a registration, see [Editing a Warranty Registration](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4391653646.html). To create a claim from a warranty registration, see [Warranty Claims](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3938319263.html).
