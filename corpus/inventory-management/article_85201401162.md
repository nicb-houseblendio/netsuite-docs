Inventory Optimization segments combine ABC categories for annual consumption value and 123 categories for demand variability.

NetSuite provides nine Inventory Optimization segment records. You can edit the name, description, and service level settings.

Note:

You cannot create or delete segment records.

| Segment | Default Service Level |
| --- | --- |
| A1 | 98% |
| A2 | 96% |
| A3 | 95% |
| B1 | 94% |
| B2 | 93% |
| B3 | 90% |
| C1 | 90% |
| C2 | 87% |
| C3 | 85% |

The **Segmentation Calculation** section on each segment record shows these read-only values from the latest completed run:

-   ABC Category Business Metric
    
-   Last Modified Date
    
-   123 Category Threshold
    
-   Number of Items (or Item Locations) Assigned
    
-   % of Items (or Item Locations) Assigned
    
-   ABC Category Threshold
    

Segment records do not retain results from earlier runs.
