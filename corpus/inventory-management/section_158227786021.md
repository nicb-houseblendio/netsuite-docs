This dataset combines fields from the Transaction and Transaction Line record types to display open inventory counts and completed counts for approval, including the items for each transaction. It forms the source data for the [Warehouse Inventory: Counts & Adjustments Workbook](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156708518969.html).

## Dataset Configuration {#subsect_158219506899}

The Warehouse Inventory: Counts & Adjustments dataset combines fields from two record types and multiple criteria filters. To edit the dataset, see [Defining a Dataset](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544122173.html).

| Root Record Type | Joined Record Type | Custom Formula Fields | Data Grid | Criteria Filters |
| --- | --- | --- | --- | --- |
| Transaction | Transaction Line | (none) | The following fields are included in the dataset. Transaction:
-   Date
-   Document Number/ID
-   Entity
-   Memo
-   Status
-   Total Amount (Transaction Currency)
-   Transaction
-   Type

Transaction Line:

-   Item

 | The following criteria is used to filter the dataset:

-   **Transaction: Type** is Inventory Count
-   **Transaction Line: Line Type** contains COUNTQUANTITY

 |
