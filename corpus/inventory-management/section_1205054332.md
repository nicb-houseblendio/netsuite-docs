The Item 360 Dashboard SuiteApp is designed and tested mainly for use with NetSuite OneWorld.

To use the Item 360 Dashboard SuiteApp, enable the following features:

| Subtab | Feature Name |
| --- | --- |
| Items & Inventory | Inventory |
| Items & Inventory | Multi-Location Inventory |
| Company | Locations |
| Transactions | Purchase Order |
| Transactions | Advanced Receiving |

For more information, see [Enabling Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N232138.html).
