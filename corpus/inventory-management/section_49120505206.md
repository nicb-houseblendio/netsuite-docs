The Smart Count SuiteApp enables you to perform both directed and spot inventory counts using your mobile device for the following item types:

-   Assembly/Bill of Materials
    
    -   Lot Numbered
        
    -   Serialized
        
-   Inventory Item
    
    -   Lot Numbered
        
    -   Serialized
        

The SuiteApp supports the following for inventory counting:

-   You can perform spot count for items.
    
-   You can complete counts for multiple items on the Complete All Counts page.
    
-   You can view counted items on the Counted Items page.
    
-   You can scan GS1 bar codes when counting inventory items, serialized items, and lot numbered items.
    
-   You can filter a list of items to count, list of counted items, and list of items to complete count based on a count configuration.
    
    The **Count Configuration** field appears on the Task List, Counted Items, and Complete All Counts pages on the mobile app, and includes the following values:
    
    -   **All** - If you select this value, the list includes items from active count configurations, inactive count configurations, and spot counts.
        
    -   **Inactive Count Configurations/Spot Counts** - If you select this value, the list includes items from inactive count configurations and spot counts.
        
    -   The field also lists all active count configurations.
        
-   You can perform live counting of items while transactions are ongoing. The SuiteApp notifies the counter about on-hand quantity changes during count. For more information about the counting features, see [Item Count Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_2145847230.html).
    
-   You can enter quantity manually or perform tally scan based on the preferences set.
    
-   You can handle various count scenarios such as recounting an item or counting an item with on-hand quantity change during count. Some of the count scenarios are listed in the [Item Count Scenarios](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0701030012.html).
    
-   You need not enter item serial numbers and lot numbers during count unless items have quantity variance. For more information, see [Setting Up Smart Count Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_46154957887.html).
    
-   If you are a WMS user, you can select a zone and aisle before starting a count. The zone and aisle values are derived from the bin record.
    
-   You can complete an item count with zero quantity. The SuiteApp displays a confirmation message before completing the count.
    

If you encounter errors during count, read [Smart Count Error Messages](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0816013247.html) to understand the errors.

To perform count using your mobile device, install the SCM Mobile SuiteApp. For information about the mobile device hardware and software requirements, see [Hardware and Software Requirements](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161495429711.html#subsect_161495524434)
