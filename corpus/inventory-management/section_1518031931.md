If you use the Advanced Bin/Numbered Inventory Management feature, you can enable and set up Inventory Status. In addition to using the standard **Good** status, you can create additional ones to assign to your items.

Set up Inventory Status by completing the following procedures:

1.  Enable the Inventory Status feature.
    
    For instructions, see [Enabling Features for Inventory Management](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161963741628.html).
    
2.  Create inventory statuses.
    
3.  (Optional) If you have existing transactions prior to enabling the feature, set the inventory status of the items to replace the default Good status.
    
    For instructions and limitations on creating, assigning, and deleting your custom statuses, see [Creating Inventory Status Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1498074763.html).
