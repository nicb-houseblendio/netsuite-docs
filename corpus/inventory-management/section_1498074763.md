Create one inventory status record for each status you want to be able to assign to items within your location.

Statuses can be in one of three states: default, active, or inactive.

When you enable the Inventory Status feature, the standard **Good** status is available by default. This status is automatically associated with all existing and incoming items at all locations until a transaction changes an item's status. All inventory associated with this status is available to be allocated to orders. You can rename this status and add a description. You cannot delete this standard status.

When you create your custom inventory statuses, you can set them to be active or inactive. You can delete your custom statuses that are not used in any items on completed or pending transactions, records, or workflows. If any non-default inventory statuses exist, you cannot disable the Inventory Status feature.

Note:

Existing fulfillment records for items with no available quantity cannot be assigned an inventory status. When inventory becomes available, you can update the fulfillment through one of the following ways:

-   Create an inventory adjustment for the item, which also enables you to assign it an inventory status. Then, you can update the fulfillment to select the status for the available quantity.
    
-   Remove the item from the fulfillment. When you fulfill the order again for the specific item, you can assign the status to the available quantity.
    

For more information, see [Inventory Status Assignment or Selection](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1515696627.html#subsect_0306030902).

In the list of inventory statuses at _Lists > Supply Chain > Inventory Status_, the State column identifies the status: default, inactive, or active. A label with one of these three words also appears next to the status name on the inventory status record.

To search for inventory statuses, go to _Reports > New Search > Inventory Status_.

#### To create an inventory status record:

1.  Go to _Lists > Supply Chain > Inventory Status > New_.
    
2.  In the **Name** field, enter a name for this status.
    
    The name you enter is the name that shows in inventory status lists on records and transactions.
    
3.  To make on-hand inventory associated with this status available for NetSuite to commit to orders, check the **Make Inventory Available for Commitment** box.
    
    If you prefer that on-hand inventory associated with this status is excluded from the available count, clear this box.
    
    After your custom status is associated with items on completed or pending transactions, you cannot check or clear this box.
    
    Important:
    
    This setting does not apply to items on drop shipments and special order purchases. Items with an unavailable status can be allocated to sales orders marked as drop shipments or special orders. You can also receive unavailable items on the associated purchase order created from a drop shipment or special order sales order. For more information about drop shipments and special orders, see [Drop Shipment and Special Order Purchases](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2409296.html).
    
4.  To make on-hand inventory associated with this status available for Supply Allocation to allocate to orders, check the **Make Inventory Available for Allocation** box.
    
    If you prefer that on-hand inventory associated with this status is excluded from being allocated to orders using Supply Allocation, clear this box.
    
    After your custom status is associated with items on completed or pending transactions, you cannot check or clear this box.
    
    Note:
    
    This field shows only when the Supply Allocation feature is enabled in your account. For details, read [Supply Allocation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156424975823.html).
    
    Important:
    
    This setting does not apply to items on drop shipments and special order purchases. Items with an unavailable status can be allocated to sales orders marked as drop shipments or special orders. You can also receive unavailable items on the associated purchase order created from a drop shipment or special order sales order. For more information about drop shipments and special orders, see [Drop Shipment and Special Order Purchases](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2409296.html).
    
5.  Optionally enter a **Description** for this status.
    
6.  Check the **Inactive** box to not show this status in search lists on records and forms.
    
7.  Click **Save**.
    

To assign inventory status to items, see [Inventory Status Assignment or Selection](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1515696627.html#subsect_0306030902).

For more information, see [Inventory Allocation Based on Status](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1517948058.html).
