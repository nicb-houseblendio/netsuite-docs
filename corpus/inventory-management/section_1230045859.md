Following are some best practices for managing UPCs:

-   **Using a retired code** - Don't reuse retired UPCs. If needed, delete and re-import the code.
    
-   **Leaving a UPC assignment record on inactive items** - If you mark an item as inactive but leave its UPC Assignment Record unchanged, the record remains for auditing and tracking.
    
    This does not affect system operations or other items, and the UPC code is not retired if the item is not deleted. If the item is deleted, the UPC code will retire.
    
-   **Retiring a UPC Code assigned to active items** - Removing a UPC code from an active item retires the code. If the code is used by other active items, retiring it may impact them.
    
-   **Removal through CSV import** - For removal through CSV, use the UI or contact your account administrator if confirmation prompts block the process.
    

Now, explore how to automate UPC assignment and retirement using scripts. For information, see [Automating UPC Assignment and Retirement](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158753804968.html).
