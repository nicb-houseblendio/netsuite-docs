The Manufacturing Traveler includes all work orders with **In Process** or **Released** status. For each work order, the operation sequence, name, and other details are provided.

#### To print a manufacturing traveler:

1.  Go to Transaction > Management > Supply Chain Management.
    
    Alternatively, you can go to Transaction > Manufacturing > Print Manufacturing Traveler.
    
2.  On the Supply Chain Management page, under Manufacturing, click **Traveler**.
    
3.  On the Print Manufacturing Traveler page, select values for the following filters to refine the list of work orders:
    
    -   **Subsidiary**
        
    -   **Location**
        
    -   **Work Order**
        
    -   **Assembly Item**
        
    -   **Work Order Status** - **Released** or **In Process**
        
    -   **Start Date From** - Select any date, whether it is before the current date, today's date, or a future date.
        
    -   **Start Date To** - Select an end date, which can be the same as the Start Date From or a future date.
        
4.  To select a work order from the list, do one of the following:
    
    -   On the **Manufacturing Traveler** subtab, in the **Select Order Number** field, enter the work order number you want to print. Press **Enter** after each entry.
        
        NetSuite automatically checks the **Print** box for the selected work order.
        
    -   Check the **Print** box next to the work order you want to print.
        
    -   Click **Mark All** to select all work orders in the list.
        
5.  Click **Print** or, to return to the Supply Chain Management page, click **Go to Main**.
    

For more information about viewing the printing status, see [Viewing the Form Printing Status](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_3836205962.html).
