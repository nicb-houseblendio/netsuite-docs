All challenges to the supply plan are listed on the display only Exceptions tab. These challenges are called exceptions because the supply plan process estimates that no action to these orders will support demand.

The Exceptions tab displays the following columns:

-   **Exception** - the exception message text.
    
    For example, 'Insufficient lead time for proposed Planned Purchase Order scheduled for 06/07/2020 by 1 day(s).'
    
-   **Date** - the due date of the exception alert record.
    
-   **Item** - the item name followed by the item description.
    
-   **Location** - the location where the affected item is stored.
    
-   **Quantity** - the number of items.
    
-   **UOM** - if units of measure is enabled, this column displays how the item is measured.
