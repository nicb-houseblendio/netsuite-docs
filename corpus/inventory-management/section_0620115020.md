The Smart Count SuiteApp provides the following roles to help you manage inventory counting efficiently. This topic introduces the available roles, outlines the required permissions, and explains the steps to provide access for custom roles.

Roles included:

-   **Smart Count Inventory Manager**
    
-   **Smart Count Inventory Counter**
    

For details on permissions and setup, see the following sections.

-   [Permissions Required for Smart Count Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1222015531.html)
    
-   [Providing Access for Custom Smart Count Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1222015535.html)
