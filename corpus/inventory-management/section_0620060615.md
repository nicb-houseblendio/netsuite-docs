The Smart Count Dashboard is a central location for managing inventory count activities at a location. It provides a summary of all inventory counts, reminders, and visual reports to analyze and effectively manage inventory.

To keep your dashboard data current, see [Optimizing Performance of Smart Count Dashboard](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1224100513.html).

To learn about the Smart Count dashboard's features, see [Smart Count Dashboard Portlets Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1224100517.html).

Users with the Administrator or Smart Count Inventory Manager roles and administrators can view data across all subsidiaries.
