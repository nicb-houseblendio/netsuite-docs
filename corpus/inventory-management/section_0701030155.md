The Smart Count SuiteApp includes the following saved searches:

-   **Last Count Date vs. Next Count Date by Item** - This saved search returns the last versus next count dates by item.
    
-   **Smart Count - Variance Tolerance Report** - This saved search returns the quantity, amount, quantity percentage, and amount percentage tolerance values for items in the selected date range.
    
    To see the tolerance values of items whose next inventory count date is not set, select **All** in the **Date** field and leave the **From** and **To** fields blank.
    
-   **Total Items Counted vs. Variance by Employee** - This saved search displays the total items counted versus the variance amount and quantity by inventory counters in a location. When you click a location, it displays the list of employees who performed item counts in that location. When you click an inventory counter's name, it displays the multiple locations where that counter has performed count.
    
-   **Item Count Variance Detail Report** - This saved search displays all Item Count records with variances per location.
    
-   **Smart Count - Default Item Saved Search** - This default saved search is used to generate a list of items to count included in the Items Due for Count configuration record.
