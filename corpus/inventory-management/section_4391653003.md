Create a manual stand-alone warranty registration, without generating it from a NetSuite invoice. Enter your own registration, invoice, and serial or lot numbers for these warranty items.

Before creating a manual registration, review the limitations and requirements in the following topics:

-   [Enabling Required Features for Warranty and Repairs Management](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_3938301917.html)
    
-   [Warranty Preferences and Item Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3938299291.html)
    
-   [Warranty and Repairs Management Considerations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4389346541.html)
    

Review the following guidelines for creating a manual registration:

-   You can't create registration records with the same item and reference serial number.
    
    For example, if you already have a registration for Serial Item 1 with Serial Number 100-WRM-001, you can't make another one for that same combination.
    
-   You can create registrations with the same reference invoice, even if the customer is the same or different.
    
-   When you select a warranty item, its default warranty information appears automatically in their corresponding fields. For more information, see [Setting Warranty Information on Items](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4389395959.html).
    
-   For the list of required and editable fields, see [Editing a Warranty Registration](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4391653646.html).
    

#### To create a manual warranty registration:

1.  Go to Lists > Warranty and Repairs > Enter Warranty Registration.
    
    Alternatively, if you are on the Warranty Registration List, click **New Warranty Registration**. If a registration is open in view mode, go to Actions > New.
    
2.  On the Warranty Registration page, enter or select values for the following fields in the Primary Information section:
    
    1.  **Registration No.** - Enter the warranty registration number.
        
        Note:
        
        If the **Auto Generate Registration No.** preference is turned on, you can't update the registration number during creation. For more information, see [Setting Warranty Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4389382197.html).
        
    2.  **Customer** - Select the customer or owner of the warranty item.
        
        In a NetSuite OneWorld account, selecting a customer shows their subsidiary in the **Subsidiary** field.
        
    3.  **Class** - Select a class that's linked to the subsidiary.
        
    4.  **Department** - Select a department that's linked to the subsidiary.
        
    5.  **Location** - Select a location that's linked to the subsidiary.
        
3.  In the Warranty Information section, enter or select values for the following fields:
    
    Note:
    
    The **Manual Registration** box is checked automatically for records not generated from an invoice.
    
    1.  **Reference Invoice** - Enter the invoice number for the warranty.
        
    2.  **Item** - Click the double arrows, and then select **List**. Select the warranty item from the list.
        
        This field only shows items with Track Warranty turned on in the item record.
        
    3.  **Quantity** - Enter or update the item quantity. A negative or zero quantity isn't allowed.
        
        For serialized warranty items, quantity is always set to 1 and can't be changed.
        
    4.  **Units** - If the Multiple Units of Measure feature is enabled, select the unit for the quantity.
        
        For serialized warranty items, the unit is always set to the base unit and can't be changed.
        
    5.  **Reference Serial/Lot No.** - For serial or lot numbered items, enter the serial or lot number. Only hyphens, letters, and numbers are allowed.
        
    6.  **Invoice Date** - Enter the transaction or posting date of the invoice.
        
    7.  **Original Warranty Terms** - Shows the item's default term. Selecting another term may change or remove values in these fields:
        
        -   Original Warranty Start Date
            
        -   Warranty Expiration
            
    8.  **Original Warranty Start Date** - Shows the calculated start date based on the preference you set. For more information, see [Setting Warranty Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4389382197.html).
        
        To change the warranty start date, enter or select a date that isn't after the expiration date. Changing the default start date may change or remove the default value in the **Warranty Expiration** field.
        
    9.  **Warranty Expiration** - Shows the item's default expiration date. This field is disabled for Lifetime terms.
        
        To change the warranty expiration date for fixed and calculated terms, enter or select a date that isn't before the warranty start date. The expiration date can't be before today's date.
        
    10.  **Warranty Document** - Click the double arrows, and then select **List**. Select the warranty document from the list.
         
         To upload a document, click the plus icon and create a new record to upload it.
         
    11.  **Remarks** - Enter any additional warranty information.
         
    12.  **Ship To Address** - Enter your current delivery address for repaired or replacement items.
         
         You can enter this information only when creating a warranty registration. It's disabled in edit mode.
         
    13.  **New Address** - This field is disabled for new registrations. You can add an address here only when editing existing registrations.
         
4.  Click **Save**.
    

After you save a registration, the status is **Under Warranty**. When it expires, the status changes to **Out of Warranty**.
