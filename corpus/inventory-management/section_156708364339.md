Inventory workbook templates provide predefined analysis based on inventory records, transactions, and planning results. Depending on the template, a workbook can include table views, pivot tables, and charts.

The workbooks available to you depend on the features enabled in your account, your permissions, and template sharing.

-   [Consignment Purchases Workbook](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0305095907.html)
    
-   [Inventory Optimization Results Workbook](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0807050821.html)
    
-   [Warehouse Inventory: Counts & Adjustments Workbook](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156708518969.html)
    
-   [Warehouse Inventory: Inbound Workbook](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156708489689.html)
    
-   [Warehouse Inventory: Outbound Workbook](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156708607969.html)
    

For more information about SuiteAnalytics Workbooks, see [SuiteAnalytics Workbook Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1503949328.html).

## Guidelines on Feature and Transaction Dependencies {#subsect_156708380467}

Before you access inventory workbooks, review the following feature and transaction dependencies:

-   Access to standard inventory workbooks and pivot tables depends on the features enabled in your account. For example, you can access the Counts & Adjustments workbook if you use the Inventory Count feature.
    
-   On pivot tables, you can view the data and value filters when you have existing transactions that meet the predefined criteria. Otherwise, the blank table viewer will display a message informing you that no results are found.
    

## Accessing Inventory SuiteAnalytics Workbooks {#subsect_156708387516}

To access workbooks, you can go to Analytics. On the Workbooks listing page, expand Standard Workbooks to display the list of inventory workbooks. Click a workbook's name to access and open it. Within each workbook, you can view the data set and pivot tables.

Note:

Only users with the Analytics Administrator and SuiteAnalytics Workbook permissions can access and edit standard workbooks. If you have these permissions, you can also share workbooks to other users. For more information about workbook permissions, see [The Analytics Administrator Permission](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1536693720.html).

For more information, see [Accessing and Sharing Workbooks and Datasets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1531766899.html).

## Retrieving Updates for Workbooks {#subsect_156708393326}

To view current data on a pivot table, clear the cached data first before retrieving the updates. At the upper-right corner of the pivot table viewer, you can access the option to clear the cache from the Menu icon ![Inventory Workbooks More](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/InventoryManagement/InventoryWorkbooks_More.png). After you clear the cache, you can retrieve updates by clicking the refresh icon ![Refresh](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/InventoryManagement/InventoryWorkbooks_ClickRefresh.png) on the workbook toolbar.
