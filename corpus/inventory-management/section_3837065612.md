Supply Chain Management SuiteApp consolidates real-time data for supply chain processes. Enabling subsidiaries access to shared information, which improves efficiency and transactions workflow.

When you install the SuiteApp, you can print the following supply chain form and reports:

-   **Inventory Count Sheet** - This form provides information about items that need to be counted. Warehouse personnel can use the inventory count sheet to perform physical inventory counts and inspections. For more information, see [Inventory Count Sheet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_3836205846.html).
    
-   **Daily Shipment Detail Report** - This report provides daily high-level visibility into shipment activities in the warehouse. It lists recipients and shipping information for each package with summary totals and daily information about new shipments per status. For more information, see [Daily Shipment Detail Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4083560088.html).
    
-   **Manufacturing Dispatch List** - This report consolidates manufacturing operation tasks and provides details of outstanding operations by work center. For more information, see [Manufacturing Dispatch List](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4083560935.html).
    
-   **Manufacturing Traveler** - This report provides information about products that need to be created or repaired, and the specific tasks required to create a product. This report is passed to the next work center as each manufacturing task is completed. For more information, see [Manufacturing Traveler](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4083561088.html).
    

The SuiteApp also includes the following features that must be set up individually:

-   **Customer Part Number** - Assigns customer part numbers to item records. For more information, see [Customer Part Number](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4575965810.html).
    
-   **Estimated Landed Cost** - Automates the calculation of landed cost estimates for each transaction line item. For more information, see [Estimated Landed Cost](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4576786578.html).
    
-   **Engineering Change Order** - Generates Engineering Change Order (ECO) records. These records document changes to your Bill of Materials (BOMs) and authorize the implementation of those changes. For more information, see [Engineering Change Order](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1531288763.html).
    
-   **Item Substitution on Sales Orders** - Creates substitute items for supported item types. For more information, see [Item Substitution on Sales Orders](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1527058829.html).
