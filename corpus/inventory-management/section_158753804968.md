Automation scripts help you manage UPC code assignment and retirement efficiently. To schedule the script, see [Scheduling a Map/Reduce Script Submission](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1509578930.html)

## AAUPC MR Auto Assign UPC Script {#subsect_1230051051}

-   Runs daily at 5:00 a.m. Pacific Time by default.
    
-   Assigns UPCs to eligible items automatically.
    

#### To manually run the script:

1.  Go to Customization > Scripting > Script Deployment.
    
2.  From the **Script** column, find **AAUPC MR Auto Assign UPC**.
    
3.  Click **Edit**.
    
4.  Set the **Status** field to **Not Scheduled**.
    
5.  Click the **Parameters** subtab.
    
6.  To receive a summary of the UPC Code assignment updates in a specific email address, check the **Email Summary Results?** box.
    
7.  Enter the email address in the **Email Summary Results To** field to which the results will be sent.
    
8.  To receive a summary of the UPC assignment updates only when there are results, check the **No Email If No Results** box.
    
9.  Click **Save and Execute** to run the script.
    
10.  On the **Map/Reduce Script Status** page, click **Refresh** to verify the status of the script.
     
     The **Status** column displays **Complete** after the script has finished running.
     

## AAUPC MR Retire UPC Without Items Script {#subsect_1230051055}

-   Runs daily at 4:00 a.m. Pacific Time by default.
    
-   Retires UPCs from child matrix items if the parent is deleted.
