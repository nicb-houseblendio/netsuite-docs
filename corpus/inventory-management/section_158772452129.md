Mass update lets you efficiently update multiple item records for UPC code assignment, removal, or exclusion from automation.

## Options for UPC Assignment {#subsect_1230044329}

You must not select **Blank** for the **UPC Code Assignment** field. Choose from the following options:

-   **Assign New UPC Code** - Triggers automatic assignment. If you select this option, see [Automating UPC Assignment and Retirement](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158753804968.html) to perform the next steps.
    
-   **Remove UPC Code** - Retires the code and updates item status.
    
-   **Do not Assign New UPC Code** - Excludes item from auto-assignment.
    

Important:

Don't select **Blank** for **UPC Code** and **UPC Code Assignment** fields.

#### To update item records using mass updates:

1.  Click **General Updates**.
    
2.  Set any necessary criteria.
    
3.  Click the **Mass Update Fields** subtab.
    
4.  You can check the following:
    
    1.  **Exclude from Auto-Assign UPC**
        
    2.  **UPC Code Assignment**
        
5.  Click **Preview**.
    
6.  Click **Perform Update**.
    

For more details on mass updates, see [Mass Updates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1103335211.html).
