After the Auto Assign UPC SuiteApp is set up, you can start managing UPCs for your items.

You'll be able to automate assignments, track code status, and use saved searches for monitoring.

## Key Tasks {#subsect_1229051645}

Most tasks require access to the Administrator role. For details on each task, see the following sections:

-   Set custom preferences for UPC assignment. For information, see [Setting Custom Auto Assign UPC Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159300061789.html).
    
-   Assign UPCs automatically or manually. For information, see [Assigning UPCs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158753744894.html).
    
-   View and manage UPCs and their statuses. For information, see _Viewing UPC Codes_ and [Assigning UPCs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158753744894.html).
    
-   Update item records in bulk. For more information, see [Updating Item Records Using Mass Update](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158772452129.html).
    
-   Deploy scripts for assignment and retirement. For more information, see [Automating UPC Assignment and Retirement](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158753804968.html).
    
-   Remove UPCs as needed. For information, see [Removing UPCs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158753778335.html).
    

Continue with [Setting Custom Auto Assign UPC Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159300061789.html) to manage assignment of UPCs to new items.
