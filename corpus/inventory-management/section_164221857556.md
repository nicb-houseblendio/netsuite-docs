If a location has **Assign Lots on Order Fulfillment** option not selected in the FEFO Lot Assignments preferences, following is the workflow:

| Task | Help Topic |
| --- | --- |
| Create FEFO shelf life groups | [Creating FEFO Shelf Life Groups](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160257422910.html) |
| Create commit groups | [Creating Commit Groups](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160257433064.html) |
| Assign commit groups and FEFO shelf life groups to items | [Assigning Commit Groups and FEFO Shelf Life Groups to Items](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160257449374.html) |
| (Optional) Create FEFO customer shelf life groups | [Creating FEFO Customer Shelf Life Groups](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160257469553.html) |
| (Optional) Set minimum fulfillment percentage for a customer | [Setting Minimum Fulfillment Percentage for a Customer](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164741088359.html) |
| Schedule the lot assignments script | [Lot Assignments Script](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160258037286.html) |
