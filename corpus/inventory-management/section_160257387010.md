The following are the prerequisites for using the FEFO Lot Assignments SuiteApp:

| Feature | Access | Prerequisite |
| --- | --- | --- |
| Supply Allocation Setup | Setup > Order Management > Supply Allocation | 
-   Clear the **Perform Supply Allocation After Transaction Entry, Update or Delete** box
-   The sorting sales of orders for lot allocation depends on the sorting configuration set in the Supply Allocations Setup page.

 |
| Location | Setup > Company > Classifications > Location | For each location record, check the **Make Inventory Available** box. When you create the location from Setup > Company > Classifications > Locations > New, this box is checked by default. However, if you create a location from a sales order or some other record, you must explicitly check the box. |
| Items | Lists > Accounting > Items | The value in **ATP Lead Time** field must be set to 0 for lot numbered items. On SuiteApp installation, this field is set to 0 for all lot items. |
| Order Allocation Schedules | Transactions > Order Management > Allocate Orders > Schedule | For lot numbered items that have location configured to commit and assign mode, do not use order allocation schedule. For addressing only nonlot and other item types, choose the **Select Orders Using a Saved Search** option and then select **FEFO\_customsearch** in the **Saved Search** list. When using a different saved search, make sure the saved search filters line items containing lot numbered items for the locations marked as commit and assign. For other locations, select all sales order line items. |
| Allocate Orders and Reallocate Items | 

-   Transactions > Inventory > Allocate Orders.
-   Transactions > Order Management > Reallocate Items

 | Do not add line items containing lot numbered items for locations set with Commit and Assign mode. |

Note:

When using FEFO Lot Assignments, you must **not** use the standard NetSuite Allocate Orders and Reallocate Orders pages, accessible from Transactions > Order Management.
