The Inventory Optimization Results Workbook includes predefined criteria and one table view. The Inventory Optimization Results table displays active stored results for each item-location combination. It includes service level information, demand and lead-time metrics, and stored planning values for Reorder Point planning. The workbook doesn't recalculate planning values in SuiteAnalytics.

## Workbook Configuration {#subsect_0807050845}

The Inventory Optimization Results Workbook uses the Inventory Optimization Results Dataset as its source. The dataset provides joins to Item, Location, Item Location Configuration, and Inventory Optimization Segment. To customize the standard workbook, use **Save As** to create a copy. Don't overwrite the standard workbook. In your copy, you can edit each component on the corresponding workbook tab. Shared recipients must save their own dataset copy before editing the dataset.

Consider the following information before you use or customize the workbook:

-   Before you use this workbook, enable Advanced Inventory Management and Inventory Optimization on the Enable Features page. To segment inventory by item-location, also enable Advanced Item Location Configuration. For instructions, see [Enabling Inventory Optimization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_2201400988.html).
    
-   The displayed results reflect completed inventory level calculations. If calculation inputs change, the displayed results update only after a scheduled or manual calculation successfully processes the item-location.
    
-   Your role needs the SuiteAnalytics Workbook permission at the Edit level and the Inventory Optimization permission at the View level or higher. By default, the standard workbook is shared with all users. Only administrators can change the permissions.
    
-   The standard table view contains the fields listed in the Data Grid column, in the specified order. Created Date, Analysis Period End Date, and Override Service Level remain available in the dataset but don't appear in this view.
    
-   The standard workbook shows stored Inventory Optimization Result records whose Inactive field is false. Inventory optimization processing writes these values; SuiteAnalytics doesn't recalculate them.
    
-   The standard workbook doesn't include current item-location quantity fields.
    
-   The workbook doesn't include a pivot table, chart, or dashboard page.
