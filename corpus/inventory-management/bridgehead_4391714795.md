This section shares best practices for importing or updating warranty registrations.

-   Make sure your import file's fields match those on the Warranty Registration form. The same validations used for manual registration also apply to imports. For more information about warranty registration fields, see [Creating a Manual Warranty Registration](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4391653003.html).
    
-   To update a warranty registration, get the internal ID of the record. For more information, see [Finding Internal IDs of Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_0416030736.html).
    
-   To update records, export the list of registrations. Use the Export-CSV icon on the Warranty Registration: Results page. Make sure the Internal ID column is displayed on the page before you export. For more information, see [Enabling Required Features for Warranty and Repairs Management](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_3938301917.html).
    
-   Imported information replaces default values. For example, when the **Auto Generate Registration No.** preference is turned on, importing your own registration numbers will overwrite the autogenerated ones.
    
    To check your warranty preferences, go to Lists > Warranty and Repairs > Warranty Setup. For more information, see [Setting Warranty Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4389382197.html).
    
-   You can use a scheduled script to blank out editable fields, but all record validations still apply. You can't edit certain fields if the registration is already tied to a claim. For a list of editable fields, see [Editing a Warranty Registration](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4391653646.html).
    
    Note:
    
    You can't set editable fields to blank through CSV import. Existing details stay the same if you leave the fields blank in your CSV file.
    
-   For more information about importing files, limitations, and tips, see the following topics:
