Warranty and Repairs Management lets you register item warranties and handle warranty claims. The SuiteApp automatically checks your claims against warranty terms, so you can process them faster.

Warranty and Repairs Management provides the following features:

-   Multiple ways to register a warranty
    
    -   Registration generated from an invoice (autogenerated registration) - Register a warranty for supported items right after you create an invoice.
        
    -   Manual registration - Create a standalone warranty registration.
        
    -   Import of warranty registration details - Import warranty registration details from a CSV file using a scheduled script or web service.
        
-   Warranty tracking on the item record - Track warranties on the item record by setting up default warranty information.
    
-   Warranty claims validation and processing
    
    -   Create a claim from a warranty registration.
        
    -   The SuiteApp checks claims against warranty registration information, so only valid claims are processed for refunds, repairs, or replacements.
        
    -   Create a return authorization for warranty items from the claim record.
        
    -   Create a credit memo or sales order for claims from the return authorization record.
        

## Availability {#bridgehead_3938301576}

Warranty and Repairs Management is a SuiteApp you can install in your NetSuite account. You get access to the SuiteApp if you have the Advanced Inventory module.
