KPIs give you a quick overview of your inventory count status, based on your filter selections.

Clicking a KPI updates the Report section with more details.

| KPI | Description |
| --- | --- |
| Total Counts with Zero Variance | Items counted with no difference from expected quantity. |
| Total Counts Pending | Counts in **Paused** or **In Progress** state. |
| Total Items/Locations Count | Total counts performed in selected/all locations (such as 10/5 for 10 counts in 5 locations). |
| Total Unapproved Counts | Counts awaiting approval. |
| Unapproved Counts with Variance Over Tolerance | Unapproved counts where the quantity variance exceeds the set tolerance limit. |
| Unapproved Counts with On-hand Change | Unapproved counts where on-hand quantity changed. |
| Unapproved Counts with Variance Within Tolerance | Unapproved counts where the quantity variance is within the set tolerance limit. |

KPIs help you spot issues quickly, so you can drill down into the details in the next step.

## The Report Section {#T_change_me_4}

The Report section displays detailed information about item counts, filtered by your selections.

The Report section displays detailed information about item counts, filtered by your selections.

You can search, customize columns, and view legends for quick insights.

Note:

Canceled item counts older than 30 days are automatically removed.

Features:

-   **Over Threshold** - Highlights variance quantity/amount over the threshold.
    
-   **Search** - Find specific item counts.
    
-   **Show Comments Popup on Action** - Prompts for comments when approving, rejecting, or recounting.
    

| Field/Portlet | Description |
| --- | --- |
| Aisle | Aisle assigned to item (if **Select Zone** and **Aisle for Counting** preferences are set). |
| Actual Count/Approved Count | Actual or approved count quantity. |
| Bin | Bin containing the item (if applicable). |
| Counted By | Employee who counted the item. |
| Count Reason | Reason for item count. |
| Count Status | Statuses such as Pending Approval, Tolerance Error and others. The Smart Count SuiteApp removes the canceled item counts that are 30 days old from the Smart Count Review page. |
| Item Description | Description of the item. |
| Item Number | Item's number. |
| Location | Location where count is performed (based on filter selection). |
| On-hand Change During Count | On-hand quantity change during count. |
| Picked/Packed | Quantity in picked or packed status for item,bin, and location. |
| System Remarks | System-generated remarks for the count. |
| User Comments | Counter's remarks entered during count. |
| Variance Amount | Variance in amount for the item. |
| Variance Quantity | Variance in quantity for the item. |
| Variance Quantity in Stock Units | Variance in stock units. |
| Zone | Zone assigned to item (if Select Zone and Aisle for Counting preferences are set). |

Now that you've analyzed the data, you're ready to approve, reject, or assign items for recount.
