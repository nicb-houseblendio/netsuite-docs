The SuiteApp includes a scheduled script that runs daily to clean up process requests that are terminated unexpectedly. You can change the schedule based on your preferences.

#### To edit the script deployment schedule:

1.  _Customization > Scripting > Script Deployments_.
    
2.  Click the **Edit** link next to SCM Background Cleanup Process SS.
    
3.  On the **Schedule** subtab, in the **Start Time** field, select a time according to your preference.
    
4.  Click **Save**.
    

For more information about scheduled scripts, see [SuiteScript 2.1 Scheduled Script Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4387799491.html).
