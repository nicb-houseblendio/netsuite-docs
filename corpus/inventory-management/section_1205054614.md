The Item 360 Dashboard SuiteApp supports the following browsers and operating systems:

| Browser | Operating System |
| --- | --- |
| Google Chrome | 
-   Windows 10
-   Mac OS 10.15 or newer

 |
| Microsoft Edge (Chromium-based) | Windows 10 |
| Mozilla Firefox | 

-   Windows 10
-   Mac OS 10.15 or newer

 |
| Safari | Mac OS 10.15 or newer |
