The Smart Count SuiteApp includes the following scripts:

-   **SC MR Bulk Update** - This MR script triggers when multiple Item Count records are selected to approve, reject, or perform recount.
    
-   **SC MR Deactivate Count Configuration** - This MR script deactivates Count configuration records that are marked for one time use, provided that counting of all items in the count configuration record are complete.
    
-   **SC MR Item Count CleanUp** - This MR script cancels Item Count records with **Pending Approval** or **Tolerance Error** statuses after a specific number of days. In addition, the script cancels the counts with **In Progress** or **Paused** statuses after a day.
    
    You can specify the number of days you want to keep records before cancellation. To do that, go to the **SC MR Item Count CleanUp** script deployment page. Click the **Parameters** subtab, and then enter the number of days in the **Count Pending for Approval** field.
