Transactions with an item sublist include the Inventory Detail column for entry or display of quantities per bin. For items that use or don't use bins, you can also view or enter serial numbers, lot numbers, or inventory status depending on the features you use.

If you use the Advanced Bin feature, the Inventory Detail icon in this column displays the popup window on the following transactions:

| 
-   Assembly Build
-   Assembly Unbuild
-   Bin Transfer
-   Bin Putaway
-   Cash Refund
-   Cash Sale
-   Check
-   Credit Card Charge
-   Credit Card Refund
-   Credit Memo

 | 

-   Inventory Adjustment
-   Inventory Count
-   Inventory Distribution
-   Inventory Transfer
-   Inventory Worksheet
-   Invoice
-   Item Receipt
-   Item Fulfillment

The Inventory Detail icon appears in one of two ways:

-   **Arrow** ![Inventory arrow icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/InventoryManagement/InventoryDetailIconBlue.png) - The arrow icon indicates that the inventory detail is available for the item and needs to be configured. It appears only in Edit mode for a transaction.
    
-   **Check mark** ![Inventory check icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/InventoryManagement/InventoryDetailIconGreen.png) - The check mark icon indicates that you have already configured the inventory detail for this item. It appears in View mode for transactions, or in Edit mode after you configure the inventory detail.
    
    This icon also appears on transactions where entry of inventory details may be optional. For item receipts or adjustments, you may use the Bin Putaway Worksheet to assign new quantities of an item to bins, along with any lot numbers, serial numbers, or inventory statuses.
    

After you click the **Inventory Detail** icon, in the popup window, you can do either of the following:

-   Select the bin that contains the items you want to process or in which you want to add items. Then, enter the number of items you want to process or add to the bin.
    
    If you want to enter quantities for multiple bins, you can refer to the **Quantity** field at the header for the quantity in the item line. The total quantity that you enter across all the bins must match this quantity.
    
-   In the Inventory Detail popup window for bin transfers, you can specify the originating bin and receiving bin.
    

The **Bin** column displays the preferred bin by default. The list of available bins to select updates based on the transaction's associated location.

The popup window includes filters to limit bin choices available for selection within a large set of bins. These filters include the following:

-   All bins
    
-   Preferred bin
    
-   Associated bin
    

If the associated transaction adds to your on-hand inventory, the following filters also appear:

-   Bins with quantity
    
-   Previously used Bins
    

In the Inventory Detail popup window on bin transfers, you can also specify the originating bin and receiving bin.

**Inventory Details for Inventory Status**

When you use the Inventory Status feature, a **Status** field appears in the Inventory Detail popup window. For both items that use and don't use bins, this field enables you to view or select an inventory status.

**Inventory Details for Serial and Lot Numbered Items**

When you use serialized or lot numbered items, whether they use bins or not, additional buttons are provided in the Inventory Detail popup window.

When you click the **Inventory Detail** icon, you can use the following options to enter multiple numbers at the same time:

-   **Express Entry** - You can click this button to use a text box to cut and paste numbers to increase and decrease inventory. When you click **OK**, the inventory detail populates in the list.
    
-   **Autogenerate Numbers** - For transactions that increase inventory, you can use this button to generate a list of serial or lot numbers. These transactions include item receipts and assembly builds for assembly completions.
    
    Set the following fields to define the components of your lot or serial number:
    
    -   **Prefix** - the prefix of the serial or lot numbers
        
    -   **Minimal Digits** - the least amount of digits to be used
        
    -   **Starting Number** - the first serial or lot number in the sequence
        
    -   **Quantity** - the quantity to enter for each inventory number
        

The total quantity you enter across the numbers and inventory detail lines must match the quantity in the item line.

For more information about inventory details for the Advanced Bin feature, see [Inventory Detail Subrecord](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2271791.html#procedure_N2271907).
