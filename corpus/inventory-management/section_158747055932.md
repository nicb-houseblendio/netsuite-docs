You can create UPCs manually or import them in bulk using CSV files. All codes are tracked in a central list, with status indicators.

## Creating UPCs Manually {#subsect_1230012649}

You must be logged in as an Administrator or have a custom role with the required permissions. For information about permissions, see [Auto Assign UPC Roles and Permissions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158573839837.html#subsect_86173010628).

#### To create UPCs manually:

1.  Go to Lists > Custom > UPC Code.
    
2.  In the **UPC Code** field, enter a code.
    
3.  Click **Save**.
    

## Importing UPCs {#subsect_1230023433}

You can import up to 24,999 items using one CSV file. Before importing, read the following:

-   Ensure the **Run Server SuiteScript and Trigger Workflows** preference is enabled. For information about steps, see [Setting CSV Import Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N355760.html).
    
    This setting is critical for data validation and for the SuiteApp to process your UPCs correctly.
    
    If this preference isn't enabled, your import may fail or skip important validations.
    
-   To exclude items from automatic UPC assignment during import, include the **Exclude from Auto-Assign UPC** field in your CSV file and set it to **Yes**.
    

#### To import UPCs using a CSV file:

1.  Go to Setup > Import/Export > Saved CSV Imports.
    
2.  The Saved CSV Imports page lists all of the saved import mappings to which you have access. These include mappings you have saved as well as those saved by others that include you in the audience.
    
3.  Click **Import UPCs**.
    
4.  In the Scan & Upload CSV File step, select your CSV file (up to 24,999 items per file) to upload.
    
5.  Click **Next**.
    
6.  In the Import Options step, expand **Advanced Options** to display additional settings.
    
7.  Ensure the **Run Server SuiteScript and Trigger Workflows** box is checked.
    
8.  Click **Next**.
    
9.  In the Field Mapping step, click **UPC Code(Req)** and map your data to the **UPC Code** field.
    
    The **External ID** field is optional.
    
10.  Click **Next**.
     
11.  In the Save mapping & Start Import step, review your settings and run the import.
     

## Viewing UPCs {#subsect_1230032109}

After import or manually creating UPCs:

-   To view all UPCs, go to Lists > Custom > UPC Code.
    
-   You can only edit UPCs with an **Unused** status.
    
-   The status of a UPC code can be:
    
    -   **InUse** - Assigned to an item.
        
    -   **Unused** - Available for assignment.
        
    -   **Retired** - Removed from an item or the item was deleted.
        

After your UPCs are created or imported, you can assign them to items automatically or manually. For information about detailed steps, see [Assigning UPCs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158753744894.html).
