If you use Distribution Resource Planning (DRP) and want to use NetSuite Supply Planning, you must set up transfer planning rules. Transfer rules are used in place of a distribution network to define how the system creates transfer orders.

#### To set up transfer rules:

1.  Go to _Lists > Supply Planning > Planning Rule Groups_ > New.
    
2.  Enter a planning rules group **Name**.
    
3.  Enter a planning rules group **Description**.
    
4.  On the **Planning Rule** subtab, select an **Item Type**.
    
5.  Select an **Item/Category**.
    
6.  Select a **Location**.
    
7.  Select a **Source Location**.
    
    The location you are transferring items from.
    
8.  Enter **Lead Time in Days**.
    
    Lead time represents the in-transit lead time, or how long it takes to ship the item from its source location.
    
9.  Click **Save**.
    
    For more information, see [Supply Planning Process](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159172577944.html).
