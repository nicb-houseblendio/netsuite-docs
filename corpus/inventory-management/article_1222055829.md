The Smart Count SuiteApp lets you scan GS1 bar codes when counting inventory items, serialized, and lot numbered inventory items.

## Prerequisites of Using the GS1 Bar Code Feature {#subsect_73113937809}

To use the GS1 bar code feature that the Smart Count SuiteApp provides, perform the following steps in the order specified.

1.  Install the NetSuite WMS SuiteApps (required for this feature). For more information, see [NetSuite WMS Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_156382465711.html).
    
2.  Set the Enable Advanced Bar Code Scanning preference Setup > Smart Count Preferences.
    
3.  Create item alias records to map GTIN-14 codes to items. Item aliases provide an alternate name for an item that is used in the warehouse. For more information, see [Creating Item Aliases](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1541433516.html).
    
4.  Set up item bar codes for scanning. For more information, see [Bar Code Setup for NetSuite WMS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158264895870.html).
    
5.  Configure custom application identifiers for GS1 bar code scanning. For more information, see [Setting Up Custom Application Identifiers for GS1 Bar Code Scanning](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158264983840.html).
    

After completing the steps, you can count inventory by scanning GS1 bar codes.

Watch the following help video for information about using the Smart Count SuiteApp to scan GS1 bar codes for inventory counting.

#### To scan GS1 bar codes for inventory counting: {#procedure_0904034845}

1.  Log in to NetSuite using your mobile device.
    
2.  Based on the role you are using, do any of the following:
    
    -   Go to Setup > Custom > Mobile - App.
        
    -   Go to Mobile Emulator > Mobile Emulator > Mobile Screen.
        
3.  Tap **Smart Count**.
    
4.  Tap a location. Administrators can view task list of all subsidiaries.
    
5.  (WMS users only) If the item uses bins, select the zone and aisle.
    
6.  In the **Count Configuration** field, select a count configuration to display items due for count based on the selected value.
    
7.  Do one of the following:
    
    1.  For directed count, tap **Count** beside an item on the task list.
        
    2.  For spot count, tap **Spot Count** from the Smart Count menu.
        
8.  In the **Scan or Enter Bin** field, scan or enter the bin number if applicable.
    
9.  In the **Scan or Enter Item** field, scan or enter the item's GTIN.
    
    The SuiteApp will automatically fill in item details (like name, number, unit, quantity, lot, or serial number) from the Item Alias page. If the GTIN matches more than one item, you'll be asked to choose which item to count.
    
    Note:
    
    For serial items, select the base unit in the **Alias Unit** field on the Item Alias page.
    
10.  In the **Inventory Status** field, select the inventory status if the feature is enabled.
     
11.  In the **UOM** field, select the unit of measure lot numbered and inventory items.
     
12.  In the **Current Quantity** field, enter the quantity. The **Total Quantity Counted** field updates with the cumulative total and can be edited if needed. For more information, see examples in [Managing Directed and Spot Inventory Counts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1222062601.html).
     
13.  Tap **Complete** to finish the count.
