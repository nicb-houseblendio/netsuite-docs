The SuiteApp automatically adds details about count activity to the **System Remarks** field. These system-generated comments appear for the following count scenarios.

Important:

In scenarios having tolerance errors, the Smart Count SuiteApp will generate remarks only if the Inventory Status feature is enabled. To enable the Inventory Status feature, go to Setup > Company > Enable Features. Click the **Items & Inventory** subtab and check the **Inventory Status** box.

| Scenario | Message on Old Record | Message on New Record |
| --- | --- | --- |
| The system automatically approves an item count based on preferences. | Autoapproved | \- |
| An item count is within tolerance levels, but not approved because automatic approval is not enabled in preferences. | Pending approval. | \- |
| An employee updates the count for an item while the previous count record is still in **Pending Approval** or **Tolerance Error** status. | Resumed after submit. | \- |
| An employee updates an item count that was automatically approved. | New count <item count record ID> created by <user> after autoapproval. | Created after approved count posted. Original count <item count record ID>. |
| An employee chooses to recount an item while the previous count record is still in **Pending Approval** or **Tolerance Error** status. | Replaced by new count <item count record ID> created by <user>. | Replaces count <item count record ID>. |
| **Force Recount** is set in preferences for on-hand quantity changes during a count. | Count replaced due to on-hand change. Count <item count record ID> by <user>. | Replaces count <item count record ID> due to on-hand change. |
| **Continue** is set in preferences for on-hand quantity changes during a count. | On-hand quantity changed during count. | \- |
| An employee chooses to recount when there is a change in on-hand quantity during the count. | Replaced by <item count record ID> due to on-hand change during count. | Replaces<item count record ID>. |
| An employee chooses to submit or continue the count when there is a change in on-hand quantity during the count. | On-hand quantity changed during count. | \- |
| An employee counts an item with zero on-hand quantity. | Zero quantity on hand. | \- |
