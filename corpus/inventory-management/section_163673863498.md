If you want to view an example of a plug-in implementation script before you create one for the Derived Field Plug-in, follow this procedure.

#### To view a plug-in implementation script example:

1.  Go to Customization > Plug-ins > Plug-in Implementations.
    
2.  Next to **CalculateDerivedFiledValuePluginImplemen**, click **qm\_calculate\_derived\_field\_value\_plugin\_implementation.js**.
    
3.  Click **Download**.
    
4.  Open the downloaded file.
    

Next, complete the procedure in [Creating a Derived Field Plug-in Implementation Script](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163673865977.html).
