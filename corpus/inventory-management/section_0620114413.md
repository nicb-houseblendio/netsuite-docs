Important:

The Smart Count SuiteApp doesn't support cloning or customization.

The Smart Count SuiteApp is a paid, managed application that automatically updates for enhancements and new features. To install the SuiteApp from the SuiteApp Marketplace, you must use the Administrator role. Before installation, contact your NetSuite account manager to provision the Smart Count Foundation SuiteApp in your account. After the Foundation SuiteApp is provisioned, follow these steps to complete the installation.

#### To install the Smart Count Foundation SuiteApp: {#procedure_23150907131}

1.  Go to Customization > SuiteBundler > Search & Install Bundles.
    
2.  In the **Keywords** field, enter **Smart Count Foundation**.
    
3.  Click the **Smart Count Foundation** link.
    
4.  On the Bundle Details page, click **Install**.
    
5.  On the Preview Bundle Install page, click **Install Bundle**.
    
6.  Click **OK**.
    

After installing the Smart Count Foundation SuiteApp, perform the following steps to install the Smart Count SuiteApp from the SuiteApp Marketplace.

#### To install the Smart Count SuiteApp: {#procedure_0620114608}

1.  Go to SuiteApps.
    
2.  In the **Search Apps** field, enter **Smart Count**.
    
3.  Click the SuiteApp tile.
    
4.  On the SuiteApp Details page, click **Install**.
    
5.  Click **OK**.
    

To uninstall the SuiteApp, see [Uninstalling the Smart Count SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0701030216.html).
