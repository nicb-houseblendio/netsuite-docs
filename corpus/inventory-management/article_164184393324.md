To help improve vendor performance analysis, NetSuite enables you to create a Vendor Performance History list view based on a system notes saved search.

To learn more, see [Saved Searches](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N675442.html).

The following is an example of a custom saved search that can display vendors who have negative performance trends:

![Vendor Saved Search](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/InventoryManagement/VendorSavedSearch.png)

You can use the NetSuite Dashboard to create a reminder based on your search requirements. The saved search example shows vendors that have declining delivery performance. Buyers needs to know when vendors are producing negative performance trends.
