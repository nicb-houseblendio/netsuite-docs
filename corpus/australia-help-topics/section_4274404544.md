This section includes the instructions for registering your Australia Post account.

Important:

You can have only one active Australia Post account per location. If your NetSuite account uses the Locations feature, each location in Australia can have its own Australia Post account.

After you register your Australia Post account, you can set up shipping preferences, create package types, and add shipping items. For more information, see the following topics:

-   [Setting Up Shipping Preferences for Australia Post](#bridgehead_4413352401)
    
-   [Creating Package Types for Australia Post](#bridgehead_4274416155)
    
-   [Creating Australia Post Shipping Items](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4274416641.html)
    

#### To register your Australia Post account in NetSuite:

1.  Go to _Setup > Accounting > Setup Tasks > Shipping_.
    
2.  On the Set Up Shipping page, click the **Partner Registration** subtab and then click **Add Shipping Partner Registration**.
    
3.  On the Select Shipping Partner page, click the link for Australia Post in the Shipping Partner column.
    
4.  On the Shipping Partner Registration page, select the service group for your account under Service Group.
    
5.  On the Registration Details section, enter the values in the following fields:
    
    1.  In the **Name** field, enter a name for the registration record. You can enter the name in your Australia Post account.
        
        Note:
        
        The registration name must be unique. You must not assign this name to another shipping registration.
        
    2.  In the **Location** field, select the location to be associated with the Australia Post account if you use the Locations feature.
        
    3.  In the **Company Name** field, enter the name of your company.
        
    4.  The following phone and address fields are automatically populated based on the selected location. However, you can still change the information. If you do not use the Locations feature, enter the values in the following fields:
        
        | Field | Description |
        | --- | --- |
        | Phone Number | Enter the contact number for the shipping location. |
        | Email | Enter the email address for the shipping location. |
        | Address Line 1 | Enter up to 40 characters for physical address of the shipping location. |
        | Address Line 2 | Enter up to 60 characters for additional physical address details of the shipping location. |
        | Suburb | Enter the city, suburb, or town that corresponds to the postcode of the address. |
        | State Code | Enter the state or territory code for the address. |
        | Postcode | Enter the postcode for the address. |
        | Country | Enter the country for the address. |
        
        Important:
        
        The address must be the same as the one in your Australia Post account. This address is used as the default shipping address to calculate the shipping rates on your transactions.
        
6.  On the General Preferences section, enter the values in the following fields.
    
    Note:
    
    The preferences you set apply to all Australia Post shipping items. You can also set preferences for a specific shipping item by updating its record. For more information, see [Creating Australia Post Shipping Items](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4274416641.html).
    
    | Field | Description |
    | --- | --- |
    | Markup or Discount Rate | Enter the discount rate, in decimal form, to offer a markup or discounted shipping rate. The value you enter must be greater than 0 and not equal to 1.00. For example, if you want to add a 20% markup, enter 1.20 in the **Markup or Discount Rate** field. If you want to offer a 25% discount, enter 0.75 in this field. Multiply this rate by the real-time rate to compute for the total discount rate. |
    | Customer Reference 1 | Select the information you want to include in packages shipped using Australia Post from the following options: Customer Email, Customer Name, Customer Phone #, Item Name, Order Number, or Purchase Order Number. |
    | Customer Reference 2 | Select additional information you want to include in packages shipped using Australia Post from the following options: Customer Email, Customer Name, Customer Phone #, Item Name, Order Number, or Purchase Order Number. |
    |  |  |
    
7.  On the Label Layout Preferences section, enter the values for Parcel services, Express services, or both:
    
    | Field | Description |
    | --- | --- |
    | Parcel Services Label Layout | Select a page size and number of shipping labels per page from the following options: **A4-4pp**, **A4-1pp**, or **A6-1pp**. |
    | Print Australia Post Brand | For Parcel services, check the **Print Australia Post Brand** box to include the Australia Post brand when printing labels. If you are using stationery purchased from Australia Post, you do not need to add the Australia Post brand anymore. |
    | Parcel Services Left Offset | Enter the value, in millimeters, to adjust the horizontal margins of the label. Enter a positive number to move the margins to the right. Enter a negative number to move the margins to the left. |
    | Parcel Services Top Offset | Enter the value, in millimeters, to adjust the vertical margins of the label. Enter a positive number to move the margins down. Enter a negative number to move the margins up. |
    | Express Services Label Layout | Select a page size and number of shipping labels per page from the following options: **A4-1pp**, **A4-3pp**, **A4-4pp**, or **A6-1pp**. |
    | Print Australia Post Brand | For Express services, check the **Print Australia Post Brand** box to include the Australia Post brand when printing labels. Take note of the following guidelines for branding with Express services:
    -   If you are using stationery purchased from Australia Post, you do not need to add the Australia Post brand anymore.
    -   This branding option is not available for the A6-1pp layout. The A6-1pp layout must use the pre-printed stationery, to ensure that the Express Post labelling is in color.
    
     |
    | Express Services Left Offset | Enter the value, in millimeters, to adjust the horizontal margins of the label. Enter a positive number to move the margins to the right. Enter a negative number to move the margins to the left. |
    | Express Services Top Offset | Enter the value, in millimeters, to adjust the vertical margins of the label. Enter a positive number to move the margins down. Enter a negative number to move the margins up. |
    
8.  On the Credential Fields section, enter the values for the following fields:
    
    1.  In the **Account** field, enter your valid 10-digit Australia Post account number.
        
    2.  In the **API Key** field, enter the API key given by Australia Post.
        
    3.  In the **Password** field, enter the password or credentials given by Australia Post.
        
9.  Click **Save**.
    

The newly created Shipping Partner Registration record is displayed with a confirmation message. When you return to the Set Up Shipping page, you should see the registration listed on the **Partner Registration** subtab. If you need to update the record, click the link for the registration to open the record. You can also delete a registration if there are no dependent records associated with it.

## Setting Up Shipping Preferences for Australia Post {#bridgehead_4413352401}

Aside from registering the Australia Post account, you can also set shipping preferences on the Set Up Shipping page. To access the page, go to _Setup > Accounting > Setup Tasks > Shipping_. You can select any of the following settings that suit your business requirements:

-   In the **Default Shipping Carrier** field, select **FedEx/USPS/More** for Australia Post.
    
-   In the **Default Shipping Method** field, select the Australia Post service to be assigned as your default shipping method.
    
-   If you use the Pick, Pack, and Ship feature, you can select the stages in the **Default Item Fulfillment Stage** and **Shipping Label Creation Stage** fields. For more information about this feature, see [Shipping Integration with Pick, Pack, and Ship](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1265431.html).
    
-   In the **Default Item Weight in LBS** field, enter the value in pounds. This value is automatically converted to kilograms on your transactions.
    

For more information about shipping preferences, see [Setting Up Shipping](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1257579.html).

## Creating Package Types for Australia Post {#bridgehead_4274416155}

If you use the Shipping Label Integration feature, you can create package types and set one as your default. For more information, see [Prerequisites](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4413330369.html#bridgehead_4274392864). For limitations on packages, see [Limitations for Australia Post Integration](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4274389015.html#bridgehead_4286404588).

To create packages for Australia Post, go to _Setup > Accounting > Setup Tasks > Shipping_. On the Set Up Shipping page, click the **Packages** subtab. Enter the name, dimensions, and the maximum number of items that could ship the package. For more information about creating package types, see [Packages Subtab](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1257579.html#bridgehead_N1258591).

The default package type is automatically assigned to new item fulfillment records, unless you have set a default package on the item record. For specific item types, you can assign a default package on the item record. For more information about default packages on the item record, see [Sales and Shipping Information for Items](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2171993.html).

Note:

If no default package has been set up, the following dimensions of an Australia Post medium box are used: 31 cm (width) by 22.5 cm (depth/length) by 10.2 cm (height).
