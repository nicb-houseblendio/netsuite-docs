The ANZ Localization SuiteApp provides the following advanced PDF/HTML templates. These templates comply with the content and layout guidelines specified by the Australian Tax Office (ATO).

-   ANZ Tax Invoice
    
-   ANZ Invoice
    
-   ANZ Sales Order
    
-   ANZ Packing Slip
    
-   ANZ Credit Adjustment Note
    
-   ANZ Purchase Order
    
-   ANZ Remittance Advice
    

You can use the ANZ templates to print documents and send them through email.

The following table lists the transaction types, ANZ templates, and their use.

| Transaction Type | PDF/HTML Template | Use |
| --- | --- | --- |
| Tax Invoice | ANZ Tax Invoice | Use this template for invoices. |
| ANZ Invoice | Use this template for invoices that contain WEG items only. |
| Sales Order | ANZ Sales Order | Use this template for sales orders. |
| Packing Slip | ANZ Packing Slip | Use this template for packing slips. |
| Credit Adjustment Note | ANZ Credit Adjustment Note | Use this template for credit adjustment notes. |
| Purchase Order | ANZ Purchase Order | Use this template for purchase orders with expenses and without expenses. To add expenses to purchase orders, you must enable the Allow Expenses on Purchase Orders preference. For more information, see [Receiving Expenses](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2416180.html). |
| Remittance Advice | ANZ Remittance Advice | Use this template for remittance advices. |

## Assigning ANZ HTML/PDF Templates to Transaction Forms {#subsect_94195832493}

To start using the ANZ templates, you must assign an appropriate ANZ template to a transaction form.

#### To assign an ANZ template to a transaction form: {#procedure_0908015508}

1.  Go to Customization > Forms > Transaction Forms.
    
2.  To update or assign a template to a transaction form, click **Customize** or **Edit** beside the transaction form.
    
3.  (Optional) In the **Name** field, enter a name for this form.
    
4.  From the **Printing Type** options, choose **Advanced**.
    
5.  In the **Print Template** field, select an appropriate ANZ template to print transactions.
    
6.  In the **Email Template** field, select an appropriate ANZ template to send transactions through email.
    
7.  Click **Save**.
    

Note:

You can also set a transaction form and template as preferred. For more information, see [Advanced PDF/HTML Templates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4453550706.html) and [Advanced Templates Customization in the Template Editor](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2863632.html).

When you click **Print** or **Email** on a transaction record, the SuiteApp uses the print and email templates assigned to the transaction form selected on the record.

After assigning the ANZ templates to transaction forms, you can also configure the document printing preferences on the ANZ Document Printing Preferences page.

## Configuring Document Printing Preferences for Australia {#subsect_11195912812}

The ANZ Localization SuiteApp lets you configure preferences for printing Australia-specific documents. On the ANZ Document Printing Preferences page, you can configure the following preferences for a company and subsidiary:

-   Customize footer message and bank details to be printed on documents. For accounts with OneWorld, you can customize the footer message and bank details for each subsidiary.
    
-   Enter the header height to adjust the space between the header and body fields in the PDF template. You can increase or decrease the header height as needed.
    
-   Enter the phone number, email, and URL to be printed on documents.
    
-   Print documents inclusive or exclusive of GST.
    
-   Print user ID and generation date on printed documents.
    
-   Use transaction number instead of document number when printing a remittance advice.
    

The ANZ Localization SuiteApp also supports printing multicurrency, location address, customer message, and vendor message on documents.

You can only use the Administrator role to configure the printing preferences. The preferences set on the ANZ Document Printing Preferences page apply to all printed documents that the SuiteApp supports. Refer to the table in [Using ANZ Advanced PDF/HTML Templates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0816112253.html) help topic for a list of supported documents.

To access the ANZ Document Printing Preferences page, you must install the ANZ Localization SuiteApp. For more information, see [Installing ANZ Localization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_158677437293.html).

When using a NetSuite OneWorld account, you can configure the printing preferences per subsidiary on the ANZ Document Printing Preferences page.

#### To configure the document printing preferences: {#procedure_0908020838}

1.  Go to Setup > ANZ Localization > ANZ Document Printing Preferences.
    
2.  Enter information in each field as necessary.
    
3.  Click **Save**.
    

You can also configure ANZ document printing preferences on the ANZ Landing page from Setup > ANZ Localization > ANZ Landing Page. In the left pane, under Preferences, click **ANZ Document Printing Preferences**.
