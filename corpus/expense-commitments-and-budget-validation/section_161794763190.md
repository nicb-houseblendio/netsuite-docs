## Setting Up Budget Preferences {#subsect_163945143968}

#### To set budget preferences:

1.  Go to Budgets > Setup > Budget Preferences.
    
2.  In the Budget Preferences List page, click **Edit**.
    
3.  In the Budget Preferences page, set the following preferences:
    
    | Preference | Description |
    | --- | --- |
    | Enable Budget Validation | Check this box to enable budget validation. |
    | Budget Validation Source | Select the source of budget validation. Following are the options:
    -   **Standard Budget** - Budgets from the standard budgets functionality.
    -   **Custom Budget** - Custom budget created using the Budget Management SuiteApp.
    
    Note: Don't select any value other than **Standard Budget** or **Custom Budget**, or the budgets won't get validated. |
    | Budget Category | When you enable the Multiple Budget feature and select **Standard Budget** in the **Budget Validation Source** field, select the budget category from this field. When you have a budget category selected, only budgets with the same category are validated. Note: The budget category in the subsidiary record overrides the one you select in this preference. |
    | Budget Control for Validation | Select the budget control record. The SuiteApp only considers the budgets created using this budget control record for validation. |
    | Saved Search for Budget Validation | Select the saved search for budget validation. Depending on your selection in the **Budget Validation Source** field, select the saved search for a standard budget or custom budget. For more information, read [Creating a Budget Validation Saved Search](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161794595451.html). |
    | Fields and Segments for Budget Validation | Enter the IDs of the fields or segments to which you want to compare transactions for budget validation. Select fields or segments that are available from the saved search selected in the **Saved Search for Budget Validation** field. For example, your transaction has seven segments but you want to validate the budget only using three segments. Enter the IDs of those three segments in this field. For custom budget custom segments, the format for entering ID is: `{Line.Id}|{Label}` For standard budget custom budgets other fields, the format for entering ID is: `{Id}|{Label},{Id}|{Label}` Following is an example of a field and a custom budget custom segment: `department|department,line.cseg1|customsegment` If you're using custom budgets and wants to limit the consumed amount by a specific account, you must add the account to Fields and Segments for Budget Validation. Following is an example of a field and a custom budget custom segment to include the account: `account|account,class|class` Note: The field must only contain the columns available in the custom budget lines except for amount and budget periods. (E.g: Apr 2024, Q1 2024, FY 2024, etc.) |
    | Budget Not Found Message | Enter the message that appears when a matching budget isn't found for the transaction line. |
    | Save Transaction On No Budget | Check this box to save the transaction even if the budget doesn't exist for it. |
    
    Click **Save**.
    

## Setting Up a Budget Account {#subsect_163945163374}

Set up a chart of account as the budget account. This account acts as a credit account for custom budget transactions. The amount in this account isn't considered as budget amount.

#### To set up a budget account:

1.  Go to Setup > Accounting > Chart of Accounts > New.
    
2.  Check the **Budget Account** box.
    
3.  Enter general accounting information.
    
    For more information, read [Creating Accounts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1440518.html).
    
4.  Click **Save**.
    

## Setting Up Accounting Preferences {#subsect_163945181496}

Set up the accounting preferences for using the SuiteApp.

#### To set up accounting preferences:

1.  Go to Setup > Accounting > Accounting Preferences.
    
2.  Set the following in the Accounting Preferences page:
    
    | Subtab | Section | Preference | Description |
    | --- | --- | --- | --- |
    | Items/Transactions | Accounts | Custom Budget Account | Select a custom budget account. If you want to use the SuiteApp for multiple subsidiaries, don't select a single subsidiary account from this list. |
    | Order Management | Purchasing | Allow Expenses on Purchase | Check this box to allow expenses on transactions. |
    
3.  Click **Save**.
    

## Setting Up Subsidiary Record Preferences {#subsect_163945199070}

Set up the preferences in each subsidiary record.

#### To set up subsidiary record preferences:

1.  Go to Setup > Company > Subsidiaries.
    
2.  Click **Edit** next to each subsidiary record and set the following preferences:
    
    | Preference | Description |
    | --- | --- |
    | Allow Saving When Budget Does Not Exist | Check this box to save the transaction even if a budget doesn't exist for the transaction of the subsidiary. |
    | Enable Budget Validation | Check this box to enable budget validation of the subsidiary. |
    | Budget Category | When you enable the Multiple Budget feature and select **Standard Budget** in the **Budget Validation Source** field, select the budget category from this field. For this subsidiary, only budgets with the same category are validated. Note: The budget category you select in this field overrides the one from budget preferences. |
    
    For more information, read [Editing Subsidiary Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N273122.html).
    

To enable the budget validation fields on purchase order, purchase request, and vendor bill transactions for a subsidiary and perform budget validations, you must:

-   Check the **Enable Budget Validation** box in the Budget Preferences page.
    
-   Check the **Enable Budget Validation** box in the subsidiary record.
    

To save a transaction even if budget isn't found on a transaction line for a subsidiary, you must:

-   Check the **Save On No Budget** in the Budget Preferences page.
    
-   Check the **Allow Saving When Budget Does Not Exist** box in the subsidiary record.
