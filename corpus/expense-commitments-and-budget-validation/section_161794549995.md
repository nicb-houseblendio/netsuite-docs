To set up Expense Commitments and Budget Validation, perform the following tasks:

1.  Create a saved search for budget validation. For details, see [Creating a Budget Validation Saved Search](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161794595451.html).
    
2.  Add user-defined custom segments to transaction columns and custom budgets. For details, see [Adding User-Defined Custom Segments to Custom Budgets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161794613557.html).
    
3.  Create a saved search for budget control. For details, see [Creating a Budget Control Saved Search](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161794691161.html).
    
4.  Create a budget control. For details, see [Creating a Budget Control Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161794703618.html).
    
5.  Set budget preferences. For details, see [Setting Expense Commitments and Budget Validation Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161794763190.html).
    

Warning:

Custom transactions, center tabs, and center categories are unlocked. However, you must not customize the custom budget transaction, center tab, and center categories delivered with the SuiteApp.
