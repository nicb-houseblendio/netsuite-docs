You can import custom budgets using CSV files. When importing, consider the following:

-   In the Scan & Upload CSV File page:
    
    -   Select **Transactions** from the **Import Type** list.
        
    -   Select **Custom Budget** from the **Record Type** list.
        
-   In the **Advanced Options** section of the Import Options page, check the **Run Server SuiteScript and Trigger Workflows** box. For more information, read [Importing CSV Files with the Import Assistant](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N343158.html).
    
-   In the CSV file, for custom budgets with multiple lines, add the budget header data to only the first row of the transaction. For example, in the CSV file image below, the yellow cells contain budget header data and the green cells contain budget line data:
    
    ![A Custom Budget CSV file sample.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteApps/CustomBudgetSampleCSV.png)
-   When creating a custom budget using import, you must enter an external ID for the custom budget. This ID must be unique across all versions of all custom budgets.
    
-   You can update a custom budget using CSV import only if the budget status is **Pending Approval.** Also, you must provide the same external id of the existing custom budget during import. The version of the custom budget remains the same.
    
-   Make sure the budget period is within the period range for the custom budget.
    
-   You can't delete a custom budget or a version of the custom budget using the CSV Import feature.
