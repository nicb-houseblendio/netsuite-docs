The Expense Commitments and Budget Validation SuiteApp provides predefined saved searches for custom budget and standard budget. If you require different fields or segments for budget validation, you can create a new saved search by customizing the saved searches provided by the SuiteApp.

## Creating a Custom Budget Saved Search for Budget Validation {#bridgehead_162729415517}

For custom budgets, the SuiteApp provides a default saved search **Custom Budget Transaction Search**, with budget fields and segments set to **Account**.

#### To create a custom budget saved search for budget validation:

1.  Go to Lists > Search > Saved Searches.
    
2.  Click **Edit** next to the **Custom Budget Transaction Search** saved search.
    
3.  In the **Search Title** field, enter a new name for the saved search.
    
4.  Click the **Results** subtab.
    
5.  In the **Columns** sublist, add fields and segments that you want to use for budget validation.
    
6.  Click **Save As**.
    

## Creating a Standard Budget Saved Search for Budget Validation: {#bridgehead_162729431943}

For standard budgets, the SuiteApp provides a default saved search **BM Standard Budget Search**.

#### To create a standard budget saved search for budget validation:

1.  Go to Lists > Search > Saved Searches.
    
2.  Click **Edit** next to the **BM Standard Budget Search** saved search.
    
3.  In the **Search Title** field, enter a new name for the saved search.
    
4.  Click the **Results** subtab.
    
5.  In the **Columns** sublist, add fields and segments that you want to use for budget validation.
    
    Standard budgets don't work with custom segments.
    
    For native segments such as department, class, and location, select the options with the same names from the list.
    
6.  Click **Save As**.
    

## Important Things to Note When Creating a Custom or Standard Budget Validation Saved Searches {#bridgehead_163480650325}

-   In a custom budget saved search, select the segment column when you add a custom segment. For example, for restriction segment, select **Restriction (Custom Column)**.
    
-   Standard budget does not work with custom segments.
    
-   For native segments such as department, class, and location, select the options with the same names from the list.
    
-   You can't use the **Item** field for budget validation. To validate items, enter the applicable transaction fields.
