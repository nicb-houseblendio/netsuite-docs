#### To edit a report schedule: {#procedure_4156322791}

1.  Go to _Reports > Scheduled Reports > Report Schedules_.
    
2.  On the Report Schedules page, locate the report schedule you would like to edit and click **Edit**.
    
3.  Edit the existing report schedule's **Recipients**, **Message**, **Attachments**, and **Audit Trail** tabs that are associated with the report. For more information, review [Scheduling a Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N735311.html).
    
4.  Click **Save**.
