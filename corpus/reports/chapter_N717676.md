To see a report's results, you can preview or run it and wait for the results to show up on your desktop. Reports with a lot of records might take longer to finish. For these reports, you have the following options:

-   If a report takes a long time, a message pops up as it runs on your desktop, giving you the option to click **Alert me when ready**. The report then runs in the background and you'll get an email with a link to the results when it's done. See [Report Results Page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N735894.html).
    
-   You can schedule a report to run on a certain date or on a recurring basis. See [Scheduling a Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N735311.html).
    
-   You can't run more than one instance of the same report at a time. If you rerun a report that's already running, the first instance is canceled and the second is started. If you try to run the same report twice in a short time, you'll get a message telling you to wait for the first report to finish.
    
-   You can't run more than two different reports at one time. If you try to run a third report while two are running, you'll get an error. Wait for one to finish or cancel one, then try again. For some reports, you can save them and schedule them to be run later and have the results emailed to you.
    
-   Report results that exceed system row limitations are truncated. See [Row Limitations for Report Results](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N719691.html).
    
-   Values in report results are rounded to your currency's precision, based on your company or subsidiary's currency format. This rounding applies to both currency and non-currency values, including formula columns.
    

## Viewing and Adjusting Report Results {#subsect_0412020827}

After you've run a report, NetSuite gives you lots of tools to help you view and adjust results to best fit your business.

-   Report navigation tools include expandable and collapsible sections, drilling into rows, a Find field, and a navigation pane with section headings. See [Navigating a Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N718860.html) and [Drilling Down to Records or Transactions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N719130.html).
    
-   For accounts in supported locations and for users whose language preference is set to English, in some reports you can use generative AI to summarize the results of your reports. For more information, see [Narrative Insights Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_135342304.html).
    
-   In the footer of each report results page, you can change the data and look of a report without using the Report Builder. These options include a date range selector. See [Setting Report Footer Options](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N720025.html).
    
-   You can display a graph of report results. See [Graphing a Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N734603.html).
    
-   You can print report results. See [Printing a Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N734828.html).
    
-   You can email report results to yourself and others. See [Emailing a Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N734970.html).
    
-   You can export report results to an external application. See [Exporting a Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N736119.html).
    
-   After viewing most report results, you can click a Customize button on the report results page to open the Report Builder, where you can make changes to the report's definition. See [Report Customization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N736328.html). For financial statements, you can click the Customize button to open the Financial Report Builder. See [Financial Report Builder](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N2105415.html).
    

Note:

When you view a report filtered by a specific date or period range, it might show different data for users in different time zones.
