Click Customize to:

-   Create and save a custom version of a report.
    
-   Define filtering and sorting options.
    
-   Enter a custom title and description for the report.
    
-   Select, order, and rename the columns that appear on your report.
    

For more information, see [Financial Report Builder](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N2105415.html) (for financial statements) or [Report Customization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N736328.html) (for other reports).

Note:

If you are viewing the results of a scheduled report, this button will be disabled.
