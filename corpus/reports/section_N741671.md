You can choose to remove decimals from values on your report.

To remove decimals, click Customize in the report footer. With the Edit Columns page selected, check the Drop Decimals box and click Preview or Save.

When you remove decimals, all values on the report are rounded to the nearest dollar.

**Example:**

-   When this box **is not checked**, value is 12,345.67.
    
-   When the box **is checked**, value is 12,346.
