NetSuite includes a variety of reporting capabilities that you can use to retrieve, present, and analyze real-time business results. You can run standard reports as is, or modify them with user preferences, per-report viewing options, or customizing reports in the Report Builder tool.

## Reporting Functions in NetSuite {#subsect_0409033311}

Reporting functions are available from the NetSuite Reports tab, for users with access to this tab. [The Reports Page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N700985.html) includes all applicable standard and ad hoc report links. Menu links on other tabs give access to reports related to specific business areas and tasks.

-   Your reports access depends on the permissions assigned to your role, the center to which you log in, and the features enabled in your account. See [Access to Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N698946.html).
    
-   A large number of [Standard Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N701428.html), with predefined data and formatting, are available for different areas of your business.
    
-   Also available are more informal [Ad Hoc Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N708927.html), for which you can select formatting options and choose from data metrics for selected business areas.
    
-   You can set your own preferences that affect the output for reports you run. See [Setting Preferences for Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N716347.html).
    
-   You have many choices for viewing reports. Each report's footer shows formatting options, as well as buttons for printing, emailing, and exporting to .csv, .xlsx, .doc or .pdf files. See [Working with Report Results](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N717676.html).
    
-   You can also add a Report Snapshot portlet to some dashboard pages. This portlet lets you view a summary of a report's results for a selected date or time period. See [Report Snapshots](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N625749.html).
    
-   For long-running reports with a large amount of data, a popup option lets you run the report in the background. The system alerts you when the report is completed. You also have the option of scheduling reports to run at specific times. See [Scheduling a Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N735311.html).
    
-   If prebuilt reports don't exactly meet your needs, you can use the Report Builder to customize reports' data and formatting. You also can allow Web Query for some reports, so that you can modify them in Microsoft® Excel. See [Report Customization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N736328.html). A specialized interface also is available for financial statement customization. See [Financial Report Builder](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N2105415.html).
    
-   NetSuite offers analytic tools other than reports; these other tools may better fit your requirements. For information, see [Alternatives to Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N698706.html).
    
-   For accounts in supported locations and for users whose language preference is set to English, you can use generative AI to summarize the results of your reports. For more information, see [Narrative Insights Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_135342304.html).
    
-   For more information about Sales Forecasting, see [Sales Forecasting](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N1045230.html).
    

Warning:

After you've started running a report, don't start other reports until the first one is complete. Executing multiple reports at the same time can cause significant performance issues. If a report is slow, it is best to schedule it, if possible.
