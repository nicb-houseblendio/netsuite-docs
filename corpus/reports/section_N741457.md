When customizing a report, you can format values on the Edit Columns page of the Report Builder (or Financial Report Builder). See [Financial Report Builder](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N2105415.html).

![Formatting preferences available on the Edit Columns page of the Report Builder.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Reports/drop1.png)

For example, you can check the Negatives in Red box to show negatives values in red on your report. You can also check Show Currency Symbol to add the correct currency symbol next to each value.

Use the links below to learn more about each formatting preference:

-   [Drop Decimals on Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N741671.html)
    
-   [Divide Report Values by 1000](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N741835.html)
    
-   [Negative Numbers on Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N742001.html)
    
-   [Currency Symbols on Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N742205.html)
