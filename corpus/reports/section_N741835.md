The Divided by 1000 preference lets you divide your report values by 1000. This option is usually used to simplify values on financial reports.

To select this option, click **Edit Columns** in the Report Builder (or Financial Report Builder). You can find this preference in the Report Preview pane.

**Example:**

-   When the box **is not checked**, value is 1,234.56.
    
-   When the box **is checked**, value is 1.23.
