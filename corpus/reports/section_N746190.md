You can delete or update a report with a few clicks on the Saved Reports page. But if you have a lot of reports, it's easier to use the Mass Update feature.

## Mass Update of Report Ownership {#subsect_162186176345}

If you need to change the owner of many reports, you can use mass update to change report ownership.

#### To mass update report ownership: {#procedure_N746202}

1.  Go to _Lists > Mass Update > Mass Updates_.
    
2.  In the Mass Updates list, expand General Updates and click **Report**.
    
3.  If you're saving this mass update, enter a descriptive name in the **Title of Action** field.
    
4.  In the **Criteria** subtab, select the Owner filter.
    
5.  In the Mass Update popup, select all the owners you want to change, then click **Set**.
    
6.  In the **Mass Update Fields** subtab, check the **Owner** box and select the user you want to transfer ownership to.
    
7.  Click **Preview** to see a list of affected reports.
    
8.  In the preview footer, click **Perform Update** to run your mass update
    

Important:

You can only change the owner to an account administrator.

## Mass Deleting Reports {#subsect_162186219408}

If you have reports in your account that you don't use anymore, you can mass delete them.

#### To mass delete reports: {#procedure_N746268}

1.  Go to _Lists > Mass Update > Mass Updates_.
    
2.  Expand the Reports category and select Delete Reports.
    
3.  In the **Criteria** subtab, select the Owner filter.
    
4.  In the mass update popup, select all the owners you want to change, then click **Set**.
    
5.  Click **Preview** to see a list of affected reports.
    
6.  In the preview footer, click Perform Update to run the mass delete.
