After you've customized and saved a report, you can view or edit it.

#### To view or edit your saved reports:

1.  Go to _Reports > Saved Reports > All Saved Reports_.
    
2.  When the Saved Reports page opens, you can:
    
    -   Click the **View** link to see the report.
        
    -   Click the **Edit** link to change your custom report settings.
        
    -   If you don't use a custom report anymore, click the **Delete** icon ![Delete report icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Reports/DeleteReport_icon.png) in the **Delete** column for that report.
        

Note:

If you've customized a report, be sure to save it before selecting **Alert me when ready**. If you select that option before saving, the last saved version will run instead.
