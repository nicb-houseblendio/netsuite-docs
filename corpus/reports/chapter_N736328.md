You can use the Report Builder to customize most standard and ad hoc reports. NetSuite also provides a specialized Financial Report Builder so that you can customize financial statements only. For information, see [Financial Report Builder](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N2105415.html).

## Customizing Reports in NetSuite {#subsect_0413024826}

You can change how a report looks and the information it shows to meet your needs. The Report Builder lets you see your changes before you save the report. You then can run the saved report anytime to quickly get the information you need in the format that's most useful to you.

To edit a report in the Report Builder, you can click Customize on the Reports page or click Customize button on the report page itself. For ad hoc reports, click More Customization on the new report definition page. These links appear only if you have permission to customize reports. Sometimes, you see a Customize link even if you don't have permission to customize a report. To avoid this issue, you may need changes to your access level for the Report Customization permission. For information, see [Report Customization Permission](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N738489.html).

On the Report Builder pages, you can edit the default columns, filter, and sorting options applied to the report. You can define new options to apply to the report. If you choose to save and share your custom report, you can choose who can access it. The available customization options depend on which report you choose, your role, permissions for that role, and the features enabled in your account. To see what the Report Builder looks like, see [Report Builder Interface](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N736822.html).

Note:

If you have customized a report, save it before you select the Alert me when ready option. If you select this option before you save your report customizations, the last saved report is run instead.

Note:

You can't customize accounting register reports, and there may be other reports you can't customize either. If you don't see a Customize link, either the report can't be customized, or you don't have permission to customize it. For information about permissions issues, see [Report Customization Permission](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N738489.html).
