A Report Navigation pane is added to the right side of a report when that report exceeds one page in length. The navigation pane includes markers to help you locate the top level information in all report sections.

Point to a marker to display its corresponding section name.

![Point to a marker to get more information](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Reports/icon112.png)

Click the ![Expand navigation pane icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Reports/reporticon1.png) button to expand the navigation pane to view links to sections of the report. For example, the report navigation pane of the Sales by Item Detail report contains links for each item and subitem listed on the report.

![Click the expand icon to expand a section of the report.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Reports/icon113.png)

Click a link to expand and highlight a particular section or line in a report.

![Click a link to expand a section of the report.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Reports/icon114.png)

The navigation pane works with the Find field in the footer to highlight only the data relevant to the keyword you entered. For example, if you enter an item name in the Find field, the navigation pane only shows markers for data relevant to that item. You can click the marker and the item name is highlighted to help you find the data.

Note:

If a report has more than 50 top-level headings, you won't see any markers in the navigation pane. To find what you need, collapse all report levels or enter a keyword in the Find field at the bottom of the report.
