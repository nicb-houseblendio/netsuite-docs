Available for financial statement reports, if Locations feature is enabled.

![Location any of footer option.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Reports/location1.png)

-   Select one or more locations to see account data only for those locations. For selecting multiple values see [Selecting Values for a Multi-Select Option](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N734449.html#bridgehead_N734479).
    
-   With NetSuite OneWorld, available locations are limited by any subsidiary restrictions for the user.
    
-   Note:
    
    Inactive locations are available to provide historical reporting and avoid unbalanced totals.
    
-   You can define location values to filter individual financial sections' data on the [Financial Report Builder Edit Layout Page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2106362.html). See [Financial Statement Sections](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2112804.html).
