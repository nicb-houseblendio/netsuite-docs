When customizing a report, you can use the **Display Negative Numbers** and **Negatives in Red** fields to format negative numbers.

The **Display in Negatives** numbers field offers the four options listed below:

-   Normal **\-123**
    
-   Parentheses **(123)**
    
-   Trailing Minus **123-**
    
-   Absolute Value **123**
    

You can also check the **Negatives in Red** box to show negative values in red.

You can use this option alone or combine it with a Display in Negatives format. Both preferences are available in the Report Preview pane when you select Edit Columns in the Report Builder (or Financial Report Builder).
