NetSuite sorts all reports by one or more columns by default. You can remove these default settings, add your own sorting options, or do both.

Important:

For financial statements, use sorting on the [Financial Report Builder Edit Layout Page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2106362.html) instead of the Sorting page. Sorting you set on the Edit Layout page overrides any Sorting page settings.

#### To remove sorting options from your report: {#procedure_N743187}

1.  Click **Customize** in the footer of the report.
    
2.  On the Report Builder (or Financial Report Builder) page, click Sorting.
    
3.  In the Choose Sort Order pane, click the **X** next to the sorting option you want to remove.
    
4.  Click **Save**.
    

#### To add sorting options to your report: {#procedure_N743224}

1.  Click **Customize** in the footer of the report.
    
2.  On the Report Builder (or Financial Report Builder) page, click **Sorting**.
    
3.  In the Add Fields pane, select the field you want to sort the report by.
    
    You can browse the Add Fields pane or type the name of the field in Search Fields and click **Search**.
    
    When you select the field, it automatically adds a line for that field to the sorting options list.
    
4.  (Optional) Check the **Descending** box to sort the data in descending order.
    
5.  Click **Add**.
    
6.  Repeat steps 3-5 to add more sorting options.
    
7.  Click **Save**.
    

Sorting options are applied in the order they're listed. Use the **Move Up** and **Move Down** buttons or drag the columns to set the sort order.

Warning:

If you sort report data by a field that can have a null value, such as Department, records with null values for the sorted field are listed last for ascending sort order and first for descending sort order. Also, null field values show as **0**.
