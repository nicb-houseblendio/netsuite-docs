Available for budget reports, if Multiple Budgets feature is enabled.

![Budget Approved box footer option.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Reports/budget1.png)

If you have defined categories for budgets at _Setup > Accounting > Setup Tasks > Accounting Lists_, select a budget category to see income and expenses for only that budget category.
