The Saved Reports page lists all the reports you've customized and saved, whether in the Report Builder or Financial Report Builder. It also shows reports customized by others who added you to the audience of their saved report.

#### To view the Saved Reports page: {#procedure_N748223}

1.  Click the **Reports** tab.
    
2.  On the Reports page, under the Saved Reports heading, click **All Saved Reports**.
    

The saved reports list includes these columns:

-   **Edit:** Click this link to edit the custom report in the Report Builder or Financial Report Builder.
    
    -   This link is only available to users with Edit or Full Report Customization permission.
        
    -   The report owner and the account administrator can edit the custom report and save it.
        
    -   Other users with permission can make changes but can only use "Save As" to save the edited report under a new name.
        
-   **View:** Click this link to view the report.
    
-   **Title:** Title entered for the custom report in Report Builder or Financial Report Builder.
    
-   **Description:** Description entered for the custom report on the More Options page in Report Builder or Financial Report Builder.
    
-   **Owner:** The saved report's owner. By default, the owner is the user who created the report. If you hover over the owner's name, you'll see more details about them.
    
    -   After a report is saved, an account administrator or the report owner can change ownership on the More Options page in Report Builder or Financial Report Builder. These users can also change the owner right in this list using inline editing.
        
    -   Only account administrators can change the owner of a report.
        
-   **Report Type:** The name of the report that was customized to create the custom report.
    
-   **Delete:** Click this link to delete the custom report.
    
    This link is only available to the report owner and account administrators.
    
-   **Save:** The Save button saves changes to the current report. If you want to rename the report, change the name in the customization form and click **Save**.
    
-   **Save As:** Clicking **Save As** creates a copy of the report with the name you enter.
    

You can click a column heading to sort the reports by title, description, owner, or report type.

If inline editing is turned on, you can edit the report's title and description directly. See [Inline Editing of Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N746084.html). Administrators can also edit the report's owner.

At the bottom of the Saved Reports page, you can filter reports by owner. If you only want to see the reports that you own, select **Mine** in the **Owner** field.

If you don't want a saved report to appear on the Reports page or Reports > Saved Reports menu, open the report for editing and clear the Show on Reports Page option on the More Options tab.
