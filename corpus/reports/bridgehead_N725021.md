Available for inventory reports, if Multi-Location Inventory feature enabled.

![Location: Name not any of footer option.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Reports/location2.png)

-   Select the name of the location you want to view activity for. The location name will be added to the header of the report.
    
-   If you select **All**, the report will show totals for each location and sublocation.
    
-   If you select **Total Only**, the report will show a combined total for all locations.
