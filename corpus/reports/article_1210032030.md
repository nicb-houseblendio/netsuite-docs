Prior to 2021.2, only default report footer filters were applied to results generated for scheduled reports or reports executed in the background. Custom footer filters that you added to the report were not applied. Now, both custom and default report footer filters are used to generate the results.

This update only affects newly scheduled reports or larger reports that are executed in the background when you select the Alert me when ready option. Existing scheduled reports aren't affected unless you create a new schedule for them. Also, if you want the next scheduled report to apply the selected footer filters, you must run the report first from the results page.

For information about how to add custom footer filters that appear when viewing report results, see [Adding Custom Filters to a Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_3842896248.html).

For information about scheduling a report, see [Scheduling a Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N735311.html).
