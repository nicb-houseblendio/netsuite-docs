If your report contains amounts, it shows currency symbols by default. To learn more about currency symbol formats and how to modify them, see [Assigning Currencies to Entities](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1397405.html).

![Currency symbols on reports.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Reports/income3.png)

If you want to hide currency symbols, in the Report Builder (or Financial Report Builder), click the **More Options** tab and clear the **Show Currency Symbol** box.

![Report with hidden currency symbols.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteAnalyticsDashboardsSearchesReports/Reports/income4.png)

Note:

For financial statements, a row-level Show Currency preference is available. The setting for a row overrides the report-level preference setting for that row.
