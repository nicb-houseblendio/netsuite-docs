The Records Catalog is available for all users with the Records Catalog permission. To assign the Records Catalog permission, first select the role you want to allow access to the Records Catalog in Setup > Users/Roles > Manage Roles. On the role page, you can then add the permission to view the Records Catalog under Permission > Setup > Add (Records Catalog).

To open the Records Catalog go to Setup > Records Catalog or [https://system.netsuite.com/app/recordscatalog/rcbrowser.nl](https://system.netsuite.com/app/recordscatalog/rcbrowser.nl).

Once you're in the Records Catalog, select a record type from the left pane to view its overview page. The left pane shows the available channels for the record type. If a certain channel is not available for a record, the functionality appears dimmed, and is unavailable. The available supported channel - SuiteScript and REST Query API - includes data for creating queries. For more information, see [SuiteScript and Rest Query API in Records Catalog](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_159376859035.html). The right pane displays the record type's name and general information.

![An example of the record type overview for account record type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/RecordsCatalog/Record_Type_Overview_v2025.png)

1.  **Available channels** - List of available channels, for example, APIs. For more information, see [SuiteScript and Rest Query API in Records Catalog](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_159376859035.html).
    
2.  **Record Type Name and script ID** - The name and script ID of the record type. The script ID is the identifier of record types in all APIs.
    
3.  **Original Name** - Original name of the record type, in case you changed the record type name. For more information about renaming records, see [Change Record and Transaction Names](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N252023.html).
    
4.  **Record Family** - Record family to which the record belongs. Record family can be either CRM, Entity, Item, Transaction, or Other.
    
5.  **ID** - Script ID.
    
6.  **Origin** - Origin of the record, either System (provided by NetSuite) or Custom (additional record type created in this specific account).
    
7.  **Show Unavailable Items** - Allows to see records, subrecords, fields, sublists, and joins not available in the current context. The dynamic NetSuite model reflects the customizations and features enabled or disabled in your account.
