The Records Catalog currently supports the SuiteScript and Rest Query API channels. You can find other channels with other tools. The following table lists tools that support other channels.

|  | **SuiteScript Records Browser** | **REST API Browser** | **Records Catalog** |
| --- | --- | --- | --- |
| Data Compatible with N/query and SuiteQL API | No | N/A | Yes |
| Data Compatible with SuiteQL Queries for REST Web Services | No | Yes | Yes |
| Data Compatible with all other SuiteScript 2.0 Modules | Yes | No | No |

For more information about the other browsers, see separate Help topics:

-   [SuiteScript Records Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1218120414.html#section_1527577879)
    
-   [SuiteAnalytics Connect Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1218120414.html#section_1527577905)
    
-   [SuiteTalk SOAP Schema Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1218120414.html#section_1527577939)
    
-   [REST API Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157797198485.html)
    

For more information, see [SuiteCloud Reference Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1527577831.html).
