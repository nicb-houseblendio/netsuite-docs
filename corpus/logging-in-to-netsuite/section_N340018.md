Important:

This topic covers browser support only for the NetSuite application, which is different from the browser support for Commerce websites. For more information, see [Supported Browsers for Commerce Websites](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160979742962.html#subsect_161229675996).

## Browsers by Platform {#bridgehead_4273872803}

NetSuite is supported in the following browsers and operating systems:

| Browser | Versions | Platform |
| --- | --- | --- |
| Google Chrome | Two most recent stable major versions. | Windows 10 or newer Mac OS 10.15 or newer2 |
| Microsoft Edge (Chromium-based) | Two most recent stable major versions. | Windows 10 or newer |
| Mozilla Firefox | Two most recent stable major version. The latest stable Extended Support Release (ESR). | Windows 10 or newer Mac OS 10.15 or newer2 |
| Safari1 | Two most recent stable major versions. | Two most recent stable major versions. |

1 Your cookies settings may affect the ability to use this browser when accessing help. If you run into any issues, open your Safari browser, go to Safari > Preferences > Privacy and turn off the Prevent cross-site tracking option. Then close Safari and reopen it.

You should be able to access SuiteAnswers through NetSuite.

2 If you're a Mac OS user, it's possible you don't see scroll bars on longer NetSuite pages, regardless of your browser. To make the scroll bar visible, on your device go to System Settings > Appearance > Show scroll bars and select **Always**.

Important:

Some third-party plugins and extensions in your browser can cause problems with the NetSuite interface.

Note:

Some ad blockers can stop you from creating pivot tables or charts in SuiteAnalytics Workbook, no matter which browser you use. To avoid errors with SuiteAnalytics Workbook, turn off these plug-ins. For more information about SuiteAnalytics Workbook, see [SuiteAnalytics Workbook Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1503949328.html).

## Touch Screen Device Support {#bridgehead_4289186626}

Most user interface actions are supported on touch screen devices, but you might run into minor issues.

## Mobile Devices {#bridgehead_162989843615}

There's a NetSuite app for mobile devices. For information about system requirements for mobile devices, see [System Requirements](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156518940453.html).
