When you process customer returns using NetSuite, you can set preferences for handling customer returns at _Setup > Accounting > Preferences > Accounting Preferences_ > Order Management.

The following customer return management preferences are available:

## Default Return Authorization Status {#bridgehead_N1305039}

Choose your default return authorization status:

-   Select **Pending Approval** if your company uses the approval process for return authorizations.
    
-   Select **Pending Fulfillment** if your company doesn't use the approval process for return authorizations.
    

## Refund in Advance of Return {#bridgehead_N1305083}

Enable this preference to allow a purchase to be refunded before the item is returned.

In some cases, companies prefer to wait until a return is received back into stock before crediting or refunding an amount to the customer. However, if you enable this preference, you can issue credit or a refund for the item before it is received.

For more information about refunding returns, read [Refunding an Authorized Customer Return](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1313511.html).

## Restock or Write-off Returned Items {#bridgehead_N1305112}

When you use the Advanced Receiving feature and receive inventory items returned by customers, you can set a preference for whether the item is restocked in inventory or written off as an expense.

For more details on these preferences, read [Accounting Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1384948.html).

## Minimum Return Quantity {#bridgehead_1524842735}

If an item has a minimum order quantity (which is the minimum number of units of an item that a customer must buy), you can require that returns also comply with the same minimum quantity. For example, if the minimum quantity of an item is five, a customer must also return a quantity of at least five. See [Sales and Shipping Information for Items](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2171993.html) for information about setting the minimum quantity on an item record.

To enable this preference, go to _Setup > Accounting > Preferences > Accounting Preferences_, and then on the Items/Transactions tab under Other Item Preferences, check the **Enforce Minimum Quantity on Return Authorizations** box.
