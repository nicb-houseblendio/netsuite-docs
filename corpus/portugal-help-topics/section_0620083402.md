This section refers to resolving the failure to update ATDocCodeIDs in your Portugal shipping documents. This can happen either due to a system failure preventing the update or due to the occurrence of unmatched Transaction IDs.

## Resolving Failed ATDocCodeIDs Update due to a System Failure {#subsect_64083928248}

This error occurs after the ATDocCodeIDs Update failed due to a system failure. It means that in this scenario, there was no problem found in the shipping documents you selected for the update.

Tip:

To resolve this error, you can either retry the update, or access the item fulfillments list and enter the missing ATDocCodeIDs manually.

## Resolving Failed ATDocCodeIDs Update due to Unmatched Transaction IDs {#subsect_92084201917}

This error occurs after the ATDocCodeIDs Update failed because Portugal Transaction IDs in the XML file did not match any ID of the selected subsidiary's transactions. The Portugal Transaction ID was not found either because the user selected an incorrect subsidiary, or because the item fulfillment transaction was deleted.

Tip:

To resolve this error, verify that all transaction records exist, and that they belong to the selected subsidiary.
