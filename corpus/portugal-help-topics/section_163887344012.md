A document series is required for creating a Portugal transaction. Thus, it must be assigned for each of the following transactions with a Portugal subsidiary: invoice, customer payment, sales order, item fulfillment, credit memo, cash sale, and cash refund.

Important:

If a document series isn't assigned, the transaction creation will fail.

Important:

Document series can only be assigned to Portugal subsidiaries. This limitation also applies to the unique document code ATCUD, whose structure is dependent on the document series. For more information, see [ATCUD Unique Document Code](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1031022226.html).

You must set up at least one document series per transaction type and subsidiary. You also have to assign a date when the document series starts to be effective. For more information, see [Creating a Portugal Document Series](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163887394059.html).

For information about the legal basis of the document series feature, see [FAQ: Portugal Document Series](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_164561285107.html).

Note:

The document series identifier can't be filled in automatically for bulk item fulfillment transactions. You have to fulfill orders individually and select a document series identifier one item fulfillment transaction at a time. For more information about item fulfillments, see [Fulfilling Orders Individually](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4576030995.html).
