To ensure that your documents will be printed with the correct formats and placement of certification information, a PDF template for each transaction type is provided. The PDF templates print the following certification information:

-   Portugal Transaction ID
    
-   Printout copy indicator: **Original** if it's a first PDF printout, or **Cópia do documento original** if it's a subsequent printout.
    
-   Four hash characters derived from the transaction's digital signature
    
-   NetSuite certification number assigned by DGCI
    
-   QR code
    

#### To format the PDF documents to the correct layout: {#procedure_98160351475}

1.  Go to Customization > Forms > Advanced PDF/HTML Templates.
    
2.  Click **Customize** next to the template that you want to copy.
    
    The following templates are available:
    
    -   Portugal Invoice PDF/HTML Template
        
    -   Portugal Cash Sale PDF/HTML Template
        
    -   Portugal Cash Refund PDF/HTML Template
        
    -   Portugal Credit Memo PDF/HTML Template
        
    -   Portugal Sales Order PDF/HTML Template
        
    -   Portugal Packing Slip PDF/HTML Template
        
    -   Portugal Payment PDF/HTML Template
        
    
    Note:
    
    You can't use the provided PDF templates directly. You can only make a copy of the provided PDF templates.
    
3.  Click **Template Setup**.
    
4.  In the Title field, change the text to the title of your choosing.
    
5.  Click **Save**.
    
    This will create a copy of the PDF template.
    
6.  Check the **Preferred** box of the PDF template copy you created.
    
    This will set this PDF template as the print format for transactions that use this template.
    

Alternatively, if you already have a PDF template that you only want to update, you can copy the source code from the provided PDF template to your customized PDF template.

#### To copy the PDF template's source code: {#procedure_68160401186}

1.  Click **Customize** next to the template that you want to copy.
    
2.  Enable **Source Code**.
    
3.  Copy the source code to your template.
    
4.  On your customized PDF template, click **Save**.
