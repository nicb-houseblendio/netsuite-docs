To be able to use the custom records listed below, you're required to grant permissions to them for your existing custom roles. Granting permissions prevents you from experiencing issues with accessing these custom records by all the necessary roles. For standard supported NetSuite roles, this action isn't required.

| Custom Record | ID |
| --- | --- |
| PT SAFT - Shipping Report | customrecord\_ptsaft\_ship\_report |
| PT SAFT - Shipping Report Line | customrecord\_ptsaft\_ship\_report\_line |
| Portugal Certification Sequence | customrecord\_ptl\_certification\_sequence |
| Portugal Document Series | customrecord\_ptl\_document\_series |
| Portugal Transaction | customrecord\_ptl\_transaction |
| Portugal Transaction Details | customrecord\_ptl\_transaction\_details |
| Portugal Localization Preferences | customrecord\_ptl\_preferences |
| Compliance - Portugal Record | customrecord\_ptl\_portugal |

#### To grant permissions to your custom roles:

1.  Log into NetSuite from an Administrator role.
    
2.  Go to Setup > Users/Roles > User Management > Manage Roles.
    
3.  On the Manage Roles page, click **Edit** for your selected custom role.
    
4.  On the Permissions subtab, click **Custom Record**.
    
5.  In the Record table column, select a custom record name from the list and set your preferred permission level.
    
6.  Click **Add**.
    
7.  Click **Save**.
    
8.  Repeat this process for all custom roles from the table above.
