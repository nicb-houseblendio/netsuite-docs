Creating transactions with a Portugal customer, vendor, or subsidiary requires that you set up your Portugal tax codes correctly. Requirements include tax code property and fiscal space.

Setting the correct tax code property is important for ensuring that the QR code on your transaction contains the correct VAT values and grouping.

For information about the QR code contents, see [Portugal QR Code](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160750657258.html).

Tax code properties define a tax code and determine the correct tax rate applied on each item of a transaction record and VAT-related fields of the QR code. For Portugal tax codes, you can select any of the following properties:

-   **Blank** - Indicates that no tax code property has been set. You must select a property other than Blank, otherwise, you can't save the tax code record. You're also not allowed to save a transaction with an item that uses the tax code with a property of Blank.
    
-   **Normal** - Used for goods and services that will be imposed a standard VAT rate based on Portugal taxation rules. In mainland Portugal, the normal tax rate is 23%.
    
-   **Intermediate** - Used for certain items, such as foodstuff supplies, admission to shows, and wine, that will be imposed an intermediate VAT rate. In mainland Portugal, the intermediate rate is 13%.
    
-   **Reduced** - Used for items, such as basic foodstuff supplies, pharmaceutical products, and agricultural goods among others, where the applicable tax rate is reduced from the normal tax rate. In mainland Portugal, the reduced rate is 6%.
    
-   **Nontaxable** - Used to identify transactions that aren't subject to the tax law.
    
-   **Exempt** - Used to indicate that the item will be exempt from tax.
    
-   **Not Applicable** - Used for cases when you don't want to include the tax code in the QR code, such as for testing purposes.
    

For more information about the tax codes, see [Portugal Tax Codes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1973379.html).

-   **PT** - Indicates mainland Portugal.
    
-   **PT-AC** - Indicates Autonomous Region of the Azores.
    
-   **PT-MA** - Indicates Autonomous Region of Madeira.

## Setting Portugal Tax Code Information {#subsect_160751263756}

For compliance purposes, you aren't allowed to save a transaction if you haven't set a tax code for an item, and if the tax code's property and fiscal space haven't been set.

#### To set the fiscal space and property of a Portugal tax code: {#procedure_0529032507}

1.  Go to Setup > Accounting > Taxes > Tax Codes.
    
2.  Click **Edit** next to the Portugal tax code that you want to set up.
    
3.  In the **Portugal Tax Code** field, select the property for the tax code you're editing.
    
4.  In the **Portugal Fiscal Space** field, keep or change the default code according to the fiscal area associated with the tax code.
    
5.  Click **Save**.
