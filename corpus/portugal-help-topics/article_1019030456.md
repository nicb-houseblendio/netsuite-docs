This section is dedicated to the PDF document templates for Portugal transactions provided by the Portugal Localization SuiteApp. The table below describes areas of these PDF document templates for each of the supported transactions, fields that are located within them, and field data sourcing.

Note that some fields in the PDF document templates are provided by the Advanced Localization Features SuiteApp. These fields are marked as **ALF FIELD** in the table below, and if you want to know more about their data sourcing, see [Fields and Placeholders in ALF Templates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161529420241.html).

Blank spaces in the table mean that the respective fields aren't supported in the PDF template for the described Portugal transaction.
