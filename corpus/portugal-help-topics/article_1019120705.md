The printing feature of the Portugal Localization SuiteApp provides you with PDF document templates that include watermarks and page numbering.

Watermarks are applied to your document based on the set number of printed copies. You can choose to set a preference for printing 1, 2, 3, or 4 copies of the same document in a single PDF file. These documents will be marked with corresponding watermarks **ORIGINAL**, **DUPLICATE**, **TRIPLICATE**, **QUADRUPLICATE**, respectively. The watermark of each copy can be found in the upper right corner of the PDF file.

Note:

For information about setting the number of printed copies, see [Portugal Printing Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1102122136.html#article_0901083542).

The page numbering of Portugal printed documents can be found in the lower right corner of the PDF document. If the transaction receipt you choose to print out has more than one page, this printing feature marks these pages accordingly.

For example, if a transaction receipt contains 3 pages, the numbering of these pages is **Page 1 of 3**, **Page 2 of 3**, and **Page 3 of 3**.

If you decide to print more copies of this exemplary three-page-long transaction receipt, the page numbering restarts on the page, where a new copy of the transaction receipt begins. In the exemplary table below, you can see the case of applying a triplicate printing preference to a three-page-long transaction receipt. The document contains 3 sets of 3 pages corresponding to the 3 copies of a three-page-long transaction receipt.

| Copy Number | Page Numbering | Watermark |
| --- | --- | --- |
| 1 | Page 1 of 3 | ORIGINAL |
| Page 2 of 3 | ORIGINAL |
| Page 3 of 3 | ORIGINAL |
| 2 | Page 1 of 3 | DUPLICATE |
| Page 2 of 3 | DUPLICATE |
| Page 3 of 3 | DUPLICATE |
| 3 | Page 1 of 3 | TRIPLICATE |
| Page 2 of 3 | TRIPLICATE |
| Page 3 of 3 | TRIPLICATE |

Besides the watermarks mentioned above, there are two additional watermarks **DRAFT** and **COPY** that may be applied to your Portugal documents. However, these two watermarks are only available for printing **Invoice** and **Credit Memo** transactions.

If you print a document for the first time, and use the **Preview PDF** button for printing, a document with an additional watermark **DRAFT** is generated. If you print a document that was already printed using the **Print** button, a document with additional watermark **COPY** is generated. Both of these watermarks appear in the middle of each page of the document.

Note:

Note that these watermarks are additional watermarks, and they don't replace watermarks **ORIGINAL**, **DUPLICATE**, **TRIPLICATE**, and **QUADRUPLICATE**.
