In Portugal, all invoicing software must be certified by the Portuguese tax authority DGCI, as mandated by Decree nº 363/2010 of the 23rd June Series I nº 120, and by Circular Letter Nº: 50 000/2012. NetSuite has been duly certified by DGCI as meeting the compliance requirements for issuing and printing invoices.

In addition, all companies in Portugal are required to submit on a monthly basis a Standard Audit File for Tax Purposes (PT SAF-T), which reports sales invoice data. NetSuite provides users the ability to generate the PT SAF-T in the required XML format for submission to the tax agency.

All Portugal invoices and cash sale transactions in NetSuite comply with the following requirements:

-   Portugal Transaction ID on PDF printouts
    
-   Portugal QR code on PDF printouts
    
-   NetSuite or NetSuite OneWorld certification number on the footer of the PDF printout
    
-   'Original' stamp on the first PDF printout
    
-   'Cópia do documento original' stamp on subsequent PDF printouts of the invoice or cash sale
    

The NetSuite certification numbers assigned by DGCI are as follows:

-   For NetSuite: 1690
    
-   For NetSuite OneWorld: 1691
    

To view the complete certification information for NetSuite, you can visit the [Lista de Programas Certificados](http://www.portaldasfinancas.gov.pt/pt/consultaProgCertificadosM24.action) page in the tax portal. You can also go to the [Portuguese tax system page](http://info.portaldasfinancas.gov.pt/pt/docs/Conteudos_1pagina/NEWS_Portuguese_Tax_System.htm) which contains relevant documents such as Decree nº 363/2010 of the 23rd June Series I nº 120 and Circular Letter Nº: 50 000/2012.

## Required SuiteApps {#bridgehead_N1970734}

Meeting the Portuguese certification requirements includes the installation of the following SuiteApps in your NetSuite or NetSuite OneWorld account:

Important:

Before installing the SuiteApps, you need to enable certain SuiteCloud features in your account. Refer to [Prerequisites](#bridgehead_N1970898) for a list of the required features.

-   [International Tax Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2051341.html) - provides the periodic VAT return (Declaração de IVA), EU Intracommunity Sales and Intrastat reports, as well as sales and purchase VAT reports grouped by tax code
    
    To install the International Tax Reports SuiteApp, see [Installing and Setting Up International Tax Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2051712.html).
    
-   To install the Portugal Localization SuiteApp, see [Installing the Portugal Localization SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161822927486.html).
    
    Important:
    
    The Portugal Localization SuiteApp isn't compatible with the SuiteTax feature. If the SuiteTax feature is enabled in your NetSuite account, please don't install this SuiteApp.
    
-   [Tax Audit Files](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N2073244.html) - provides the Standard Audit File for Tax Purposes (PT SAF-T) that follows the XML schema defined by the Portuguese tax authority
    
    To install the Tax Audit Files SuiteApp, see [Installing the Tax Audit Files SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2074100.html).
    
    Note:
    
    Currently, the Tax Audit File SuiteApp doesn't support the Multiple Calendars feature.
    

For guidance on installing SuiteApps, see [Installing a Bundle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3395142.html).

## Prerequisites {#bridgehead_N1970898}

Before installing the SuiteApps, go to Setup > Company > Enable Features and enable the following SuiteCloud features:

-   Custom Records
    
-   Client SuiteScript
    
-   Server SuiteScript
    

For information about SuiteCloud features, see [SuiteCloud Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N239332.html).
