Before installing the Portugal Localization SuiteApp, you must do the following:

-   Install the following prerequisite SuiteApps:
    
    | SuiteApp | ID | Installation Procedure |
    | --- | --- | --- |
    | Advanced Localization Features SuiteApp | 359132 | See [Installing the Advanced Localization Features SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160691065745.html). |
    | Tax Audit Files SuiteApp | 47492 | See [Installing the Tax Audit Files SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2074100.html). |
    | Tax Reporting Framework SuiteApp | 237699 | See [Installing Tax Reporting Framework](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1528245293.html). |
    
-   Enable the following features:
    
    | Feature | Procedure |
    | --- | --- |
    | GL Audit Numbering | See [Enabling GL Audit Numbering and Setting Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4805169812.html). |
    | Custom Transactions | See [Enabling the Custom Transactions Feature](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4230577490.html). |
    | Server SuiteScript | 
    #### To enable the feature: {#procedure_12114438025}
    
    1.  Go to Setup > Company > Setup Tasks > Enable Features (Administrator).
    2.  On the **SuiteCloud** subtab in the **SuiteScript** section, check the **Server SuiteScript** box.
    3.  Click **Save**.
    
     |
    | Advanced PDF/HTML Templates | See [Enabling the Advanced PDF/HTML Templates Feature](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_1496243531.html). Note: The Portugal Localization SuiteApp provides PDF document templates with the required formatting and placement of certification information. Enable this feature to be able to print the QR Code and other certification information about your documents. |
    | Inline Editing | 
    
    #### To enable the feature: {#procedure_0801113004}
    
    1.  Go to Setup > Company > Setup Tasks > Enable Features (Administrator).
    2.  On the **Company** subtab in the **Data Management** section, check the **Inline Editing** box.
    3.  Click **Save**.
    
     |
    | Custom Records | 
    
    #### To enable the feature: {#procedure_15113952040}
    
    1.  Go to Setup > Company > Setup Tasks > Enable Features (Administrator).
    2.  On the **SuiteCloud** subtab in the **SuiteBuilder** section, check the **Custom Records** box.
    3.  Click **Save**.
    
     |
    | SuiteAnalytics Workbook | See [Enabling SuiteAnalytics Workbook in Your NetSuite Account](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1504014192.html). |
    | Multiple Currencies | See [Enabling the Multiple Currencies Feature](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1395677.html). |
    | Accounting | 
    
    #### To enable the features: {#procedure_81122002814}
    
    1.  Go to Setup > Company > Setup Tasks > Enable Features (Administrator).
    2.  On the **Accounting** subtab in the **Basic Features** section, check the **Accounting** and **A/R** boxes.
    3.  Click **Save**.
    
     |
    | A/R |
    | Advanced Receiving | 
    
    #### To enable the feature: {#procedure_88121952749}
    
    1.  Go to Setup > Company > Setup Tasks > Enable Features (Administrator).
    2.  On the **Transactions** subtab in the **Shipping & Receiving** section, check the **Advanced Receiving** box.
    3.  Click **Save**.
    
     |
    | Sales Orders | 
    
    #### To enable the feature: {#procedure_79110306763}
    
    1.  Go to Setup > Company > Setup Tasks > Enable Features (Administrator).
    2.  On the **Transactions** subtab in the **Basic Features** section, check the **Sales Orders** box.
    3.  Click **Save**.
    
     |
    
-   Activate all standard roles supported by this SuiteApp. For more information about supported roles, see [Roles with Access to Portugal Localization Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164129078963.html).
    
    #### To activate a role:
    
    1.  Go to Setup > Users/Roles > User Management > Manage Roles.
        
    2.  Check the **Show Inactives** box at the top of the list.
        
    3.  In the **Inactive** column, clear the box next to any role you want to activate.
        
    4.  Click **Submit**.
        
    

Important:

Without these prerequisites, the Portugal Localization SuiteApp can't be installed.

## Optional Prerequisites for Using the Portugal Localization SuiteApp {#subsect_47155240939}

Some features provided by the Portugal Localization SuiteApp require additional optional prerequisites. This means that you can install and use the SuiteApp without any problems even without these prerequisites in your account.

If you plan on using the [Assignment of Certification Accounting Books](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1102122136.html#subsect_59131625195), you need to enable the following features:

| Feature | Procedure |
| --- | --- |
| Adjustment Only Book | 
#### To enable the feature: {#procedure_93160914051}

1.  Go to Setup > Company > Setup Tasks > Enable Features (Administrator).
2.  On the **Accounting** subtab in the **Multi-Book Accounting** section, check the **Adjustment Only Book**, **Full Multi-Book Accounting**, and **Foreign Currency Management** boxes.
3.  Click **Save**.
