This section is dedicated to the resolution of possible issues that you might encounter while printing your Portugal documents using the updated PDF templates. Currently, there's only one known issue described below.

## Resolving Missing Fields in the Delivery (Packing Slip) PDF Template {#bridgehead_53145646949}

The following procedure describes the process of resolving missing fields in the **Delivery** (Packing Slip) template derived from the item fulfillment transaction. In particular, these include **Ordered**, **Back Ordered**, or **Shipped** fields in the **Lines** area of the template. You can perform this procedure from the Administrator role in your NetSuite account.

#### To Manually Customize an Incomplete Delivery (Packing Slip) Template: {#procedure_1026100414}

1.  Go to Customization > Forms > Advanced PDF/HTML Templates.
    
2.  In the list of templates, find the template with the name **Portugal Packing Slip PDF/HTML Template**, and click **Edit** in the **EDIT** column.
    
3.  From the **Actions** list, select **Download Template**.
    
4.  Save the file **custtmpl\_pt\_packingslip.template.xml**.
    
5.  Open the saved file in the Notepad editor, and copy its entire content.
    
6.  Go back to **Advanced PDF/HTML Templates** page, and find the template with the name **Standard Packing Slip PDF/HTML Template**.
    
7.  Click **Customize** in the **EDIT** column.
    
8.  Click on **Template Setup** button.
    
9.  In the **Template Setup** popup window, fill out the name **Portugal Account Packing Slip Template** in the **Name** field.
    
10.  Click **Save**.
     
11.  Switch **Code Source** toggle.
     
12.  Select the entire code that appears on the screen and delete it.
     
13.  Paste the code that you copied in step 5 to replace the previous code with the new one.
     
14.  Click **Save**.
     
15.  Go to Customization > Forms > Transaction Forms.
     
16.  On the **Custom Transaction Forms** page, find the form with the name **Portugal Packing Slip**, and with the checked box in the **Preferred** column.
     
17.  Click **Edit** in the **EDIT** column next to this transaction form.
     
18.  In the **Print Template** dropdown list, select **Portugal Account Packing Slip Template** created in step 9.
     
19.  Click **Save**.
