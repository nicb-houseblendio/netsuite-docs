If you have the Period End Journal Entries feature enabled in your NetSuite account, period end journals (PEJ) can be used to close your profit or loss accounts. You can include these PEJ entries in the PT SAF-T files. For more information, see [Enabling the Period End Journal Entries Feature](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1513209294.html).

To include PEJ entries in the PT SAF-T files, you must set the PEJ preferences for your Portugal subsidiary.

#### To set the PEJ preferences for PT SAF-T:

1.  Go to Setup > Tax Reporting > Country Tax Report Preferences.
    
2.  In the Subsidiary field, select your Portugal subsidiary.
    
3.  In the Nexus field, select a Portugal nexus.
    
4.  On the **Tax Audit Files Data Filters** subtab, check the PEJ type that you want to include in a specific report.
    
    The Portugal Localization SuiteApp supports all three types of PEJ.
    
5.  Click **Save**.
    

For more information, see [Period End Journals Support in Tax Reporting Framework](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161350128986.html).
