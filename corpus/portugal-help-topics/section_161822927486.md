The Portugal Localization SuiteApp is a managed SuiteApp that's available through the SuiteApp Marketplace.

#### To install the Portugal Localization SuiteApp:

1.  Go to SuiteApps.
    
2.  In the search bar, enter **Portugal Localization**.
    
3.  Click the Portugal Localization image.
    
4.  Click **Install**.
    
5.  Read the information about the alert, and click **Install** if you want to proceed, or **Cancel** if you don't want to install the SuiteApp.
    

Important:

The Portugal Localization SuiteApp cannot be uninstalled. Removing this SuiteApp will result in the loss of all certification-related data, which cannot be recovered.

After the installation, you must configure your NetSuite account and perform some mappings. For more information, see [Setting Up for a Compliant PT SAF-T](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161822954055.html).
