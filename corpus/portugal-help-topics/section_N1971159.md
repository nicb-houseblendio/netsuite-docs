Important:

This topic pertains to the Portugal SAF-T files generation feature, which is no longer supported as of Tax Audit File SuiteApp version 1.85.0. You can only use this SuiteApp to generate Portugal SAF-T files from 2022 and earlier. To generate this report, see [Generating the PT SAF-T File in Portugal Localization SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161831214836.html).

Note:

If you're using the Portugal Localization SuiteApp to generate the PT SAF-T for Accounting in XML version 1.04\_1, see [Portugal Localization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161822794592.html).

In Portugal, businesses are required to submit a monthly Standard Audit File for Tax Purposes (PT SAF-T) to the tax authority. For more information about Portugal compliance requirements, see [Portugal Tax Topics In Accounts Without SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161044164894.html).

Before you can generate the PT SAF-T, you need to do the following:

-   Install the necessary SuiteApps. See [Required SuiteApps](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161044164894.html#bridgehead_N1970734).
    
-   Set up the required preferences and commercial registry office information, and map standard NetSuite fields into PT SAF-T required categories. See [Setting Up the PT SAF-T](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3958232661.html).
    
-   Format your printed sales transactions using the copied PDF template source code. See [Formatting Portugal PDF Documents](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1972506.html) in [Portugal Localization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161822794592.html).
    

After installing the SuiteApps and completing the setup requirements, you can generate the PT SAF-T for submission to the tax agency. See [Generating the PT SAF-T](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1973237.html).

## Invoice Numbering for Portugal {#bridgehead_N1971262}

When you install the Portugal Localization SuiteApp, NetSuite automatically generates a Portugal Transaction ID and unique digital signature for transactions of a Portugal subsidiary. The Portugal Transaction ID and digital signature are included when you generate the PT SAF-T for transactions. The Portugal Localization SuiteApp only generates the Portugal Transaction ID and digital signature for transactions dated in the fiscal year when the SuiteApp was installed and onwards. The SuiteApp doesn't generate transaction IDs and digital signatures for transactions created before the year that the SuiteApp was installed. The reason is that the accounting periods of previous fiscal years must be closed already. For more information, refer to [Certification Data on the Portugal Transaction Subtab](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157190470583.html) in [Portugal Localization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161822794592.html).

## Portugal Invoice Printing {#bridgehead_N1971296}

All Portugal invoices and cash sale transactions printed from NetSuite show the information required by the tax authority. For details, see [Portugal Tax Topics In Accounts Without SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161044164894.html).
