The Portugal Localization SuiteApp generates certification data to certify a specific customer transaction. These certification elements are generated only to the supported transactions that are dated in the fiscal year when the SuiteApp was installed and onwards. The SuiteApp doesn't generate this data for existing transactions created before the year the SuiteApp was installed because previous fiscal years have been already closed.

You can find the transaction certification data in the fields on the Portugal Transaction subtab. The data is generated in one of the following ways based on the SuiteApp version installed in your account:

-   For Portugal Localization SuiteApp in version **other than 2.3.0**, the certification data is automatically generated after the Document Series Identifier is selected, and the transaction is saved.
    
-   For Portugal Localization SuiteApp in version **2.3.0**, the certification data is generated after the Document Series Identifier is selected, and the transaction is finalized. For more information, see [Portugal Transaction Finalization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0606050028.html).
    
-   In version 3.1.0 of Portugal Localization the logic for generating the Portugal transaction ID has changed to depend on the selected Document Series Identifier:
    
    -   If the Transaction Code field in the Document Series Identifier is blank, the first two letters of the ID are based on the transaction type (as before).
        
    -   If not blank, the Transaction Code value is used as the prefix.
        
    
    After selecting a Transaction Type, the Transaction Code dropdown is automatically populated with relevant options and a default value, allowing users to select a different code if needed. While it is not required by default, the Transaction Code must be correctly filled when creating or editing a Document Series that hasn't been used for certification, or when creating a Document Series via script.
    

Important:

Remember that you can't delete any transaction that was successfully certified with the Portugal certification data. This action would cause a gap in the transaction sequence within the same document series.

The following describes the fields on the Portugal Transaction subtab:

-   **Document Series Identifier** - ID of the document series assigned to the transaction.
    
-   **Portugal Transaction ID** - Consists of the transaction type code, document series identifier, and the transaction's sequence number.
    
    Note:
    
    Transactions dated before January 1, 2022 are assigned a Portugal Transaction ID that consists of the transaction type code, subsidiary ID, the Fiscal Year the transaction was created, and the transaction's sequence number. For more information, see [Changes in Portugal Transaction ID in 2022](#subsect_163887939584).
    
-   **ATCUD** - Document code that makes it possible to uniquely identify a document. It's set at the moment of creating your Portugal transaction. For more information, see [ATCUD Unique Document Code](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1031022226.html).
    
-   **Certification Date** - Refers to the date and time the transaction was certified.
    
    Note:
    
    The certification date and time of the transaction are expressed as YYYY-MM-DD 'T' hh:mm:ss. The certification time reflects the Western European Time (UTC±00:00) and doesn't consider the daylight saving time scheme.
    
-   **Signature** - A unique string of characters based on the information you filled in on the transaction record. The signature signifies that the document is final and has not been tampered with. It also serves to ensure the correct sequence of the documents. Some characters are used for the Q field of the QR code. For more information, see [Portugal QR Code](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160750657258.html).
    

## Changes in Portugal Transaction ID in 2022 {#subsect_163887939584}

For transactions dated January 1, 2022 or later, the Portugal Transaction ID information changes to include the document series identifier, which becomes required also on this date.

The following table summarizes the changes in the contents of the Portugal Transaction ID starting from January 1, 2022:

| Property | Up to December 31, 2021 | 2022 |
| --- | --- | --- |
| Two-letter transaction type code for Cash Refund. | NC | CR |
| Two-letter transaction type code for Cash Sale. | VD - for Cash Sale transactions dated before January 1, 2022. FR - for Cash Sale transactions dated on January 1, 2022 and onward. |
| Subsidiary ID and Fiscal Year | included | not included |
| Document series identifier | not included | included |
| One ID sequence is generated per transaction type per year | True | Dependent on the document series start and end dates |
