Important:

Transactions with a Portugal subsidiary that are dated January 1, 2022 or later are required to have a document series. This requirement applies to invoice, sales order, cash sale, credit memo, customer payment, item fulfillment, and cash refund.

-   For Portugal Localization SuiteApp in version **other than 2.3.0**, the transaction can't be saved if the Document Series Identifier isn't selected. The document series identifiers of these transactions are used in the generation of Portugal certification data.
    
-   For Portugal Localization SuiteApp in version **2.3.0**, transactions can be saved without the Document Series Identifier, but can only be certified if the field is set. For more information, see [Portugal Transaction Finalization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0606050028.html).
    

If the transaction is dated before January 1, 2022, you can still select a document series identifier on the transaction record, but it's not required. Transactions dated before January 1, 2022 are also certified with a Portugal Transaction ID in the format that contains transaction type code, subsidiary ID, Fiscal Year, and sequence number. For more information, see [Changes in Portugal Transaction ID in 2022](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157190470583.html#subsect_163887939584).

On the **Portugal Transaction** subtab of the transaction record, you can select a document series identifier from the **Document Series Identifier** list.

These are the possible reasons why the **Document Series Identifier** list on the transaction record is disabled:

-   The transaction isn't associated with a Portugal subsidiary.
    
-   No document series record has been created for the transaction type you're using.
    
-   The transaction date is before the start date of the document series, or the transaction date is after the end date of the document series.
    
-   No document series record has been created for the selected subsidiary on the transaction.
    
-   The document series record for the selected transaction type and subsidiary is inactive. This means that the **Inactive** box is checked for this document series record.
    
    To see which document series records are inactive, go to Setup > Accounting > Tegata > Portugal Document Series (Administrator) or Setup > Other Setup > Portugal Document Series (Accounting Center). Enable **Show Inactives**.
    

Important:

The document series identifier can't be filled in for bulk item fulfillment transactions. You have to fulfill orders individually and select a document series identifier one item fulfillment transaction at a time. For more information about item fulfillments, see [Fulfilling Orders Individually](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4576030995.html).
