The Portugal Localization SuiteApp supports the following standard roles:

-   Administrator
    
-   CFO
    
-   Bookkeeper
    
-   Accountant
    
-   A/R Clerk
    

Important:

Remember that all standard roles supported by this SuiteApp must be active. For more information, see [Prerequisites for Installing the Portugal Localization SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161822935439.html).

Besides these roles you can assign a role to generate, view, and download the PT SAF-T files provided by the Portugal Localization SuiteApp. For more information, see [Assigning a Role for Generating a PT SAF-T File](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162133824433.html).
