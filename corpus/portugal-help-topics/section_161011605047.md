In addition to the general Portugal account setup, you must also enable some features and perform mappings specifically to ensure that the PT SAF-T file contains the complete required information in the correct formats.

The Portugal Localization SuiteApp and the Tax Audit Files SuiteApp provide the SAF-T files required in Portugal in different XML schema versions. This means that each SuiteApp can have different setup requirements. It's important that you read the help topics specific to each SuiteApp.

If you use the Portugal Localization SuiteApp to generate the PT SAF-T for Accounting file version 1.04\_1, read the following topics:

-   [Prerequisites for Installing the Portugal Localization SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161822935439.html)
    
-   [Setting Up for a Compliant PT SAF-T](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161822954055.html)
    

If you use the Tax Audit Files SuiteApp to generate the PT SAF-T files version 1.03, read the following topics:

-   [Portugal Standard Audit File for Tax Purposes (PT SAF-T)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1971159.html)
    
-   [Setting Up the PT SAF-T](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3958232661.html)
