Use the checklist below to help you quickly set up your knowledge base.

| # | Task |
| --- | --- |
| 1 | [Creating Knowledge Base Topics](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2447915.html) |
| 2 | [Creating Knowledge Base Solutions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2448156.html) |
| 3 | [Publishing a Knowledge Base](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2448614.html) |

Administrators can complete each item on the checklist.

Support staff create topics and solutions, but cannot approve solutions.

Support Managers or Support Administrators approve solutions and publish content.
