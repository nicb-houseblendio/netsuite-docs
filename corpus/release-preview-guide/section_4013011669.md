The following tables describe features that are available for testing in Release Preview.

Note:

The main goal of a Release Preview account is for you to test your business workflows to prevent any potential issues you might encounter and to ensure everything functions as expected with the newly released NetSuite features. If you find any issues during testing, see [How to Report Release Preview Issues](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4013029002.html). You are **not** expected to test the new features for NetSuite.

Only modules that you have purchased and enabled in your production account are available in your Release Preview. Make sure you understand the limitations of the Release Preview account when you use it to test features with your business workflows.

Note:

'No actions taken' in the Testing Notes column indicates the feature is available, but no email is sent, no campaigns are executed, and no payments are processed.

Note: The From header on email you send from your sandbox account will be rewritten to use the SMTP-related email address (netsuite.com). | OpenID Connect (OIDC) | For instructions, see [OpenID Connect (OIDC) Single Sign-on](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_156399873235.html). |

Note: The company preference for Release Preview email is evaluated after the report is executed and prepares to send email. Depending on the preference specified, the email is sent to a specific user or not sent at all. Note: The company preference for Release Preview email is evaluated after the report is executed and prepares to send email. Depending on the preference specified, the email is sent to a specific user or not sent at all. Note: Do not attempt to reuse domains that are already deployed in your production account. You must set up a unique domain for each of your accounts: production, sandbox, and Release Preview. For more information, see [Secure Domain Licenses](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_1498574038.html), [Manual Certificates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2485854.html) and [Set Up Domains for Web Stores](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2484898.html). |

## Features Available for Limited Testing in Release Preview Accounts {#subsect_163761128300}

The following table lists features that are available in only a limited form in Release Preview accounts.

| Feature | Testing Notes |
| --- | --- |
| Alternative Payment Methods | No actions taken (no payment sent). Test mode is on for all payment processing profiles. |
| Credit Card Processing | Real credit card numbers are not copied. They are replaced with test numbers; for example, 1111111111111117. To create billing processes or credit card processing for testing in your Release Preview, use only test credit card numbers and a valid expiration date. Important: For more information, see [Credit Card Processing in Release Preview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1549916016.html#subsect_162376776054). |
| Direct Deposit | No actions taken. |
| NetSuite Connector | You cannot connect multiple NetSuite accounts (production, sandbox, Release Preview) to the same NetSuite Connector account. You can only connect one NetSuite account to a NetSuite Connector account at a time. For more information, see [General NetSuite Connector FAQ](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164025511298.html) and [Checking Accounts for NetSuite Connector Deployment](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163004074146.html). |
| PayPal Integration | No actions taken. |
| Perquest | No actions taken. |
| SAML Single Sign-on | SAML configuration is not copied from the production account to the Release Preview. You must configure SAML in your Release Preview account. For more information, see [SAML SSO in Multiple NetSuite Account Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4430963939.html). |
| Scheduled SuiteScripts | Scripts scheduled in production, such as scheduled and map/reduce scripts, are copied to Release Preview accounts, but are not scheduled or run automatically. However, they can be run manually. Automated scheduled scripts can only be tested in sandbox accounts. For details, see [Scheduled Script Execution](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4664470832.html). |
| SSN or TIN (Social Security Number or Tax Information Number) | Real numbers are not copied. Use only test numbers. |
| SuiteAnalytics Connect | When testing SuiteAnalytics Connect, you must change the Connect Service host name and ensure that you are logged in to a Release Preview account. The host name of Release Preview accounts contains 'rp' as part of the name. For more information, see [Test Your SuiteAnalytics Connect Connection](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4471784137.html). |
| Token-based Authentication | Tokens created using the Token-based Authentication feature in your production account are not copied to your Release Preview account. To test this feature, you must create tokens in that Release Preview account. For more information, see [Manage TBA Tokens in the NetSuite UI](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4254975694.html). |
| UPS/FedEx Integration for Shipping Labels | No actions taken. |
| Website and Web Store | Domains are not copied from your production account to your Release Preview account. You must set up domains in the Release Preview account. For more information, see [Manual Certificates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2485854.html) and [Set Up Domains for Web Stores](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2484898.html). Note: If you have multiple Release Preview accounts, ensure that the domains are unique across all of your Release Preview accounts. An error message is generated if there are duplicate domains. |

## Features Not Available for Testing in Release Preview Accounts {#subsect_163761208964}

The following features are not available for testing in Release Preview accounts:

-   Fax
    
-   Intelligent Recommendations
    
-   NetSuite Analytics Warehouse (NSAW)
    
-   Outlook Integration
    
-   Payroll
