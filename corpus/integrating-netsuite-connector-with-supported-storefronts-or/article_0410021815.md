To set up Loop Returns with NetSuite Connector, you must generate an API token. This token enables NetSuite Connector to communicate securely with the Loop Returns API, allowing it to fetch, process, cancel, and flag returns.

#### To generate the API token:

1.  Log in to the Loop Returns Administrator Dashboard.
    
2.  On the left sidebar, go to Return Management > Tools & Integrations > Developer Tools.
    
3.  Click **Generate API Key**.
    
4.  When prompted, select all the required access scopes like Create Returns (read), Create Returns (write), Return.
    
5.  Provide a descriptive token name. For example, NSC Integration Token.
    
6.  Click **Generate**, then copy and securely store the token for later use.
    

#### To integrate NetSuite Connector with Loop Returns:

1.  Log in to [connector.netsuite.com](https://connector.netsuite.com/).
    
2.  Click **Add Connector**.
    
    Note:
    
    The Loop connector account name must match the Shopify store account name.
    
3.  Select Loop Returns connector.
    
4.  Provide the account name.
    
5.  Go to Loop > Mange Data Sync > Activate Connector and enable the connector.
    
6.  Go to Settings > Credentials and update the following details:
    
    -   Shopify store name- this field is used to map the associated Shopify account.
        
    -   Loop API token- provide the API token generated.
        
7.  Click **Save** and **Test Connection**.
