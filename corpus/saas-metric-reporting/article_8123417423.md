NetSuite SaaS Metrics Reporting supports the import of legacy or external subscription data using historical imports. This ensures your analytics reflect a complete business history, even for subscriptions managed outside of the current solution.

## What are Historical Imports? {#subsect_54130808977}

Historical Imports let you load past or external subscription activity into the system in bulk. This is typically done using a CSV file format designed to create Analytical Impact Records for each imported event.

## How are Terms Defined? {#subsect_27130759421}

The term (start and end dates) for each record is specified directly in the CSV import file.

## Data Source {#subsect_66130753107}

The data source for historical imports is **CSV Import**. CSV Import creates Analytical Impact records for each subscription-related event.

## Impact Categories for Historical Imports {#subsect_91130743987}

When loading historical data, each entry must be manually assigned an Impact Category and Subcategory in the CSV file to ensure data integrity for analytics. Customer Impact Levels will automatically be assigned, so only the Contract Impact Level needs to be assigned on historical imports using the CSV file.

| Impact Category | Impact Subcategory | Example Scenario |
| --- | --- | --- |
| New | New Contract | Imported as a new contract |
| Upsell | Price Increase | Price increase on existing item |
| Upsell | Quantity Increase | Quantity increase |
| Upsell | Add-on | Additional item/feature added |
| Downsell | Price Decrease | Price reduction or discount |
| Downsell | Quantity Decrease | Quantity reduction |
| Downsell | Item Removal | Service or item removed |
| Churn | Contract Churn | Subscription terminated |
| No Impact | Renewal | Contract renewal |
| Other | Ignored | Events not to be included in analytics |

Important:

All impact category and subcategory values are determined and specified by you during the CSV file preparation process. Data accuracy depends on these assignments.

## Renewal Assignment {#subsect_96130732595}

Renewal events are also manually assigned in the import file. The system does not auto-link renewals during historical import, so be sure to set these relationships clearly in your CSV template.
