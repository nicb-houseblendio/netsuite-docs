The following table shows the transactions supported for recurring revenue and financial metrics.

| Transaction | Recurring Revenue | Financial Metrics |
| --- | --- | --- |
| Cash Sales | Yes | No |
| Contract Renewal | Yes | No |
| Credit Memo | No | Yes |
| Customer Charge (Statement Charge) | No | Yes |
| Deposit | No | Yes |
| Expense Reports | No | Yes |
| Invoices | Yes | No |
| Journal Entries | No | Yes |
| Sales Order | Yes | No |
| Sales Order with Billing Schedules | No | Yes |
| Subscription | Yes | No |
| Vendor Bill | No | Yes |
| Vendor Credit | No | Yes |
