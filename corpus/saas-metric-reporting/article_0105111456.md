To let your custom roles access the SuiteApp, assign the required permissions to those roles. The following table lists the required permissions and their minimum access levels.

| Permission | Subtab | Minimum Access Level |
| --- | --- | --- |
| Analytical Impact | Lists | View |
| Bills | Transactions | View |
| Cash Sale | Transactions | View |
| Cash Refund | Transactions | View |
| Check | Transactions | View |
| Credit Memo | Transactions | View |
| Credit Card | Transactions | View |
| Credit Returns | Transactions | View |
| Customer Deposit | Transactions | View |
| Customer Payment | Transactions | View |
| Deposit | Transactions | View |
| Enter Vendor Credits | Transactions | View |
| Expense Report | Transactions | View |
| Find Transaction | Transactions | View |
| Invoice | Transactions | View |
| Item Receipt | Transactions | View |
| Make Journal Entry | Transactions | View |
| Purchase Order | Transactions | View |
| Return Authorization | Transactions | View |
| SaaS Metric | Lists | View |
| Vendor Returns | Transactions | View |
| Vendor Return Authorization | Transactions | View |

#### To assign permissions to your custom roles:

1.  Go to Setup > User/Roles > Manage Roles.
    
2.  Click **Edit** next to the role you want to update.
    
3.  On the **Permissions** subtab, assign the required permissions and set their access levels.
    
4.  Click **Add**.
    
5.  Click **Save**.
    

After setup, you can use the Subscription Metrics dashboards. For more information, see [Working with the Subscription Metrics Dashboards](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0105111711.html).
