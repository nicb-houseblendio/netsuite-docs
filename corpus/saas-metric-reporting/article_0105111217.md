To track subscription metrics for specific items or services, configure the following fields on each item or service item record.

Note:

When you configure subscription metrics-related fields, note the following:

-   If you have many items, configure the subscription metrics-related fields for items in small batches to help prevent system performance issues.
    
-   If you renamed **SaaS Metrics** to **Subscription Metrics** during setup, the field labels appear as:
    
    -   **Subscription Metric Tracking**
        
    -   **Subscription Metric Start Date**
        
    -   **Subscription Metric End Date**
        

If you didn't rename the fields, they retain the original **SaaS Metric** names. For instructions on renaming, see [Prerequisites and Post-Installation Tasks for Subscription Metrics SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0105111158.html).

-   **Subscription Metric Tracking** - Check this box to include an item's or service item's recurring revenue in subscription metrics when used in subscriptions or transactions, such as sales orders.
    
-   **Subscription Metric Start Date** - Enter the date when tracking for subscription metrics should begin for this item. Only transactions or subscriptions with a start date on or after this date will be included in subscription metrics.
    
-   **Subscription Metric End Date** - Enter the date when tracking for subscription metrics should end for this item. Transactions or subscriptions with a start date after this date won't be included in subscription metrics. This field is optional.
