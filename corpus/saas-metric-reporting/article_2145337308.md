The Acquisition Date field on the Financial subtab of the Customer record enhances SaaS metric reporting and supports customer cohort analysis. Scheduled jobs can be used to load or manually update the Acquisition Date field, and any changes immediately update all related reporting records.

This is how the Acquisition Date field works:

-   **Manual Entry or Automatic Assignment -** You can enter the Acquisition Date manually for each customer. If this field is left blank, NetSuite automatically assigns the date of the customer's first transaction as the Acquisition Date.
    
-   **Analytical Impact Imports -** If analytical impact data has been imported, NetSuite sets the Acquisition Date to the earliest start date from those imports.
    
-   **Acquisition Month End Date -** This value is calculated on Analytical Impact records. It represents the end of the month in which the customer's Acquisition Date falls. NetSuite uses this date for grouping customers by acquisition month in SuiteAnalytics and Subscription Metrics reporting.
    

Use cases for the Acquisition Date include:

-   **Cohort Analysis -** The Acquisition Date and the associated Acquisition Month End Date enable grouping and filtering customers based on when they were acquired, making cohort analysis and customer segmentation easier.
    
-   **SaaS Metric Reporting -** The Acquisition Date provides accurate timing for when customers are first accounted for in Subscription Metrics and financial reporting.
    

Administrators can use the admin docs tool to manually run scheduled jobs and load or update Acquisition Date data for multiple customers if bulk changes are needed.
