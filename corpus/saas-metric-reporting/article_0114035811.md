You can view the renewal performance of each item over time on the Renewal Rate by Item trend graph. The period can be set to monthly, quarterly, and yearly.

The Renewal Rate by Item portlet is affected by both the dashboard filters and the portlet filters. When you use the Renewal Rate by Item portlet and change the portlet filters, the dashboard filters are overridden. The portlet filters gets overridden by the dashboard filters again after applying the dashboard filters.

#### To view item renewal rates:

1.  Log in to NetSuite.
    
2.  Go to the [Accessing the Retention Metrics Dashboard](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0205035256.html).
    
3.  In the Renewal Rate by Item portlet, select the item you want to view from the list. You can select multiple items.
    
4.  Optional. Set the duration, start period, and end period. By default, the Renewal Rate by Item portlet displays the item renewal rate monthly from January to December of the current year.
