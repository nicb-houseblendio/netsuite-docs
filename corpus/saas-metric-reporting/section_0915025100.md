The Subscription Metrics SuiteApp provides primary filters such as metric, subsidiary, and customer to refine your data. You can also use secondary filters, such as date range and period, in each portlet for further selection. As you set filters, the dashboard updates in real time. All portlets, reports, and charts reflect the filtered data.

If you want to reset filters, click **Reset Filters**.

Note:

When working with dashboard filters, note the following:

-   Filters only display data you are permitted to view based on your NetSuite role and permissions. Currently, you can't save or share custom filter sets or dashboard views.
    
-   Adjust filters to see the correct data.
    

You can filter data on the dashboard by the following criteria.

| Filter Type | Description |
| --- | --- |
| Metric | Use CMRR or CARR for committed future recurring revenue analysis. Use MRR or ARR for currently active recurring revenue analysis. Committed monthly recurring revenue (CMRR) and Committed annual recurring revenue (CARR) show expected recurring revenue that has been contracted but not yet active as recognized MRR or ARR. |
| Subsidiary | View data for a specific subsidiary or consolidated group:
-   **Filter options** - Supports individual subsidiaries and consolidated (group) views.
    -   **Individual** - Shows data for a single subsidiary.
    -   **Consolidated** - Aggregates data across multiple subsidiaries based on your access permissions.
-   Subsidiaries that are inactive or marked for elimination are excluded.
-   **Reporting periods** - If the Multiple Calendars feature is enabled, reporting periods use the fiscal calendar of the lowest common parent. If the Multiple Calendars feature is disabled, reporting periods use the standard fiscal calendars.

 |
| Customer | Focus on metrics for a specific customer or group of customers. Only active customers appear in the filter options. |
| Item | Analyze data for specific products or services. Only active items appear in the filter options. |
| Location | Filter by business location or region. Only active locations appear in the filter options. |
| Department | View metrics for a particular department such as sales, marketing, or support. Only active departments appear in the filter options. |
| Class | Segment data by class, such as product line or business unit. Only active classes appear in the filter options. |

#### To use filters on the Subscription Metrics dashboards:

1.  Go to Subscription Metrics > Revenue Metrics > View.
    
2.  In the Filters section, fill out any or all the following fields.
    
    1.  In the **Metric** field, select a metric. To set a default metric, see [Setting Subscription Metrics Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0206025703.html).
        
    2.  In the **Subsidiary** field, select a subsidiary.
        
        When you select one or more subsidiaries, the dashboard consolidates and displays data for the parent subsidiary and its associated child subsidiaries. If the parent and child subsidiaries use different currencies, transactions are converted to the lowest common parent company's currency using the posting month's consolidated exchange rate.
        
        For more information, see [Viewing Consolidated Exchange Rates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1405950.html).
        
    3.  Select the following. The field options depend on the selected subsidiary.
        
        1.  **Customer**
            
        2.  **Item**
            
        3.  **Department**
            
        4.  **Class**
            
        5.  **Location**
            
3.  Click **Apply Filters**.
