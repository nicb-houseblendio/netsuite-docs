The Subscription Metrics SuiteApp is a managed SuiteApp, which automatically updates for new features or enhancements. You can install the Subscription Metrics SuiteApp from the SuiteApp Marketplace using the Administrator role.

Note:

Before you install the SuiteApp, go to Setup > Company > Enable Features and enable the Subscription Metrics Reporting feature. If you don't enable the feature, the SuiteApp displays an error message. The error message displays in English, regardless of your account's language setting.

#### To install the Subscription Metrics SuiteApp:

1.  Go to SuiteApps.
    
2.  In the Search box, enter **Subscription Metrics.**
    
3.  Click the SuiteApp tile.
    
4.  Click **Install**.
    

The installation of a SuiteApp may take some time. To check the installation status, see [Viewing SuiteApp Installation or Uninstallation Status](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1539867271.html).
