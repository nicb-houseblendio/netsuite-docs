By default, the **Period** field is set to **This Month**, and the **Comparison Period** field is set to **Last Month**. You can compare values for a selected period against a comparison period.

The following table lists the options available for the **Period** and **Comparison Period** fields.

| Period | Comparison Period |
| --- | --- |
| This Month | 
-   Last Month
-   Month Before Last
-   Same Last Year

 |
| This Quarter | 

-   Last Quarter
-   Same Last Year
-   Quarter before last

 |
| This Year | 

-   Last Year
-   Year Before Last

 |
| Last Month | Month Before Last |
| Last Quarter | Quarter Before Last |
| Last Year | Year Before Last |
| Trailing Twelve Months (TTM) | Last TTM |
| Year to Last Month (YTM) | Last YTM |
