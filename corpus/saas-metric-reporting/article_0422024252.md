The Subscription Metrics dashboards provide drilldown reports for the following KPIs:

-   Churn
    
-   Customer Acquisition Cost (CAC)
    
-   Growth Rate
    
-   Net Revenue Retention (NRR)
    
-   Lifetime Value (LTV)
    

To analyze a KPI drilldown report, review the report from summary to detail:

1.  Confirm the KPI result in the Breakdown section.
    
2.  Review the Summary section for key observations.
    
3.  Check the Components section to identify the main contributors.
    
4.  Review the trend graphs to understand timing and patterns.
    
5.  Group chart data by subsidiary, item, class, or location for analysis.
    
6.  Use the Transactions table to review transaction level details.
    

## Opening a KPI Drilldown Report {#subsect_0427123434}

To open a KPI drilldown report, go to a Subscription Metrics dashboard and click the value of a supported KPI, such as **NRR** or **Churn**. The drilldown report for the selected KPI opens in a new page.

### Filters {#subsect_0428023616}

A KPI drilldown report uses the same settings as the main dashboard.

These settings include:

-   Currency
    
-   Period
    
-   Comparison Period
    
-   Metric
    

Note:

The Growth Rate drilldown report doesn't support comparison period.

### Chart View Selector {#subsect_0428023629}

The drilldown report inherits the selected primary dashboard filters. You can additionally use the **Select Chart View** filter to change how chart data is grouped. Use this filter to identify which business dimension contributes to the KPI result or trend.

For example, you can compare results by subsidiary, identify concentration by item, or isolate issues in a specific location.

Chart views include:

-   Class
    
-   Item
    
-   Location
    
-   Subsidiary
    

Note:

If the Class and Location features aren't enabled, you can't view charts based on class or location.

## Reviewing Drilldown Report {#subsect_0427123520}

Drilldown reports include sections that help you review KPI results, identify contributing factors, analyze trends, and validate transaction-level detail.

### Breakdown Tiles {#subsect_0428024820}

The Breakdown tiles at the top of the page provide a summary of the selected KPI and related values.

Use the tiles to:

-   Confirm the current KPI result.
    
-   Review related supporting values.
    
-   Compare key values such as beginning recurring revenue and ending recurring revenue, before you review detailed analysis.
    

### Summary Section {#subsect_0428024836}

The Summary section provides an AI-generated overview of the KPI result and notable data patterns. The section includes:

-   Key insights
    
-   Key drivers
    
-   Alerts
    

Note:

Consider the following points about the Summary section:

-   The Summary section uses Prompt Studio (a generative AI feature) to generate summaries. For more information, see [Generative AI Feature Availability in NetSuite](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_3132707887.html).
    
-   If the Prompt Studio feature isn't enabled, the Summary section displays an error message.
    
-   For the Growth Rate KPI, the Summary section doesn't support the filters.
    

Use the summary as a starting point for analysis. Confirm significant conclusions by reviewing the Components section, trend graphs, and transactions table.

### Components Section {#subsect_0428024851}

The Components section shows the values or factors that contribute to the KPI result. Use this section to understand how the KPI value is derived and identify the main drivers of change.

Depending on the KPI, this section can help you determine whether the result was driven by retention, expansion, contraction, churn, or other KPI-specific factors.

### Trend Graphs {#subsect_0428024910}

Each drilldown report includes trend graphs that help you analyze KPI performance over time. The types of trend graphs vary by KPI. You can use these graphs to identify:

-   KPI patterns over time
    
-   Timing of increases or decreases.
    
-   Concentration across business dimensions
    

### Transaction Table {#subsect_0428024921}

The Transactions table shows the transaction-level detail for the selected KPI and current filters. The table structure and columns are consistent across KPI drilldown reports.

Note:

The LTV drilldown report doesn't contain the transaction table.

Use the table to:

-   Validate summary-level findings.
    
-   Inspect the records behind the KPI result
    
-   Identify the transactions that contributed to a change
