SaaS Metric Reporting automatically generates the new, upsell, downsell, and churn impacts for tracked items across transactions and subscriptions.

#### To start SaaS metric tracking:

1.  Open the item you want to collect data about.
    
2.  Click **Edit**.
    
3.  On the **Sales/Pricing** subtab, check the **SaaS Metric Tracking** box. The **SaaS Metric Start Date** and **SaaS Metric End Date** fields are displayed.
    
4.  In the **SaaS Metric Start Date** field, set the date to begin tracking SaaS metrics for transactions and subscriptions that contain the selected items.
    
    If you need historical SaaS metric reporting for transactions that already include these items, you can set the start date in the past.
    
5.  In the **SaaS Metric End Date** field, set the date to stop SaaS metric tracking.
    
    Adding an end date helps to prevent errors in reporting and gives you greater control in defining what's included in the report.
    
6.  Click **Save**.
