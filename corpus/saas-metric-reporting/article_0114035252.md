The **Churn Rate Trend** graph displays the percentage churn rate and value of the churned revenue over time. You can select either gross churn rate or net churn rate. The period can be set to monthly, quarterly, and yearly.

You can use this portlet either in current view or committed view. When viewing churn rate trends, ensure that the appropriate metric is selected from the dashboard filters.
