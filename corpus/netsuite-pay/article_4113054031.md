You can set up NetSuite Pay in your sandbox account to test it before implementing it in production.

The following NetSuite features work with NetSuite Pay in a sandbox account:

-   **Customer Payments** - Submit manual transaction through customer payments. For more information, see [Customer Payments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1285644.html).
    
-   **Payment Link** - Send invoices and process transactions. For more information, see [Payment Link](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_162516600357.html).
    
-   **My Account** - Make payments on My Account. For more information, see [My Account](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/preface_158100703898.html).
    

Statement generation is not available in sandbox accounts.

## Prerequisites {#subsect_0604122507}

Before using NetSuite Pay in a sandbox account, ensure the following prerequisites are met:

-   Request a NetSuite sandbox account. For more information, see [Requesting a Sandbox Account for the First Time](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0901111723.html).
    
-   Install NetSuite Pay SuiteApp version 1.0.11 or higher. The COMP ID must contain SB, TSTDRV, or TD.
    
    -   Install NetSuite Pay directly in your sandbox account or
        
    -   Install NetSuite Pay in your production account and refresh your sandbox
        

#### To set up NetSuite Pay in sandbox:

1.  In your sandbox account, submit a merchant account application. For more information, see [Submitting a Merchant Account Application](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_2122140403.html).
    
    -   A merchant account application in your sandbox account is required even if an application has already been submitted in your production account.
        
    -   The application status will change from **Processing** to **Provisionally Approved** in approximately 15 minutes.
        
2.  Configure the NetSuite Pay Payment Processing Profile. See [Configuring the NetSuite Pay Payment Processing Profile](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_3093631811.html).
    
    Note:
    
    Payment processing profiles from your production account will not work in sandbox. Configure a new payment processing profile in your sandbox account.
    
3.  Set the NetSuite Pay payment processing profile to Test Mode.
    
    1.  Go to Setup > Accounting > Payment Processing Profiles.
        
    2.  Click **Edit** next to your NetSuite Pay payment processing profile.
        
    3.  In the **Primary** section, check the **Test Mode** box.
        
    4.  Click **Save**.
        
4.  Test credit card and ACH data.
    
    Note:
    
    Real account data should not be used for testing in your sandbox account. For test data, see [Testing Order Transactions](https://developers.versapay.com/#tag/Testing-Order-Transactions).
