The Daily Settlement Batch is configured to run daily at 5:00 am by default. You can modify the schedule's timing and frequency as required.

#### To schedule the Daily Settlement Batch: {#procedure_1005031157}

1.  Go to Customization > Scripting > Script Deployments.
    
2.  Locate the Veraspay Settlement and Fee Recon script with ID **customdeploy\_versapay\_settlement\_recon** and click **Edit**.
    
    Tip:
    
    Use the filter to search for script type of "Map/Reduce."
    
3.  Set **Status** to **Scheduled**.
    
4.  On the **Schedule** subtab:
    
    -   Select **Daily Event**.
        
    -   Set a **Start Time**.
        
    -   Set a **Repeat** of every 6 or 12 hours.
        
    -   Select **No End Date**.
        
5.  Click **Save**.
    

The map script runs at the selected intervals. If you have verified that these steps have been completed and you're still not receiving the Settlement and Fee Report, contact NetSuite support.
