You must enable the following features to use NetSuite Pay:

-   **Accounting**
    
    To enable, go to _Setup > Company > Enable Features_ > Accounting subtab > Accounting.
    
    For more information, see [Accounting Features and Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N1383640.html).
    
-   **Custom Records**
    
    To enable, go to _Setup > Company > Enable Features_ > SuiteCloud subtab > Custom Records.
    
    For more information, see [Custom Records Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N2875173.html).
    
-   **Client SuiteScript**
    
    To enable, go to _Setup > Company > Enable Features_ > SuiteCloud subtab > Client SuiteScript.
    
    For more information, see [Enable Required Features for SuiteScript 1.0 SSP Applications](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2492346.html).
    
-   **Server SuiteScript**
    
    To enable, go to _Setup > Company > Enable Features_ SuiteCloud subtab > Server SuiteScript.
    
    For more information, see [Enable Required Features for SuiteScript 1.0 SSP Applications](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2492346.html).
    
-   **SOAP Web Services**
    
    To enable, go to _Setup > Company > Enable Features_ > SuiteCloud subtab > SOAP Web Services.
    
    For more information, see [Enabling the SOAP Web Services Feature](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3419926.html).
    
-   **Payment Instruments**
    
    To enable, go to _Setup > Company > Enable Features_ > Transaction subtab > Payment Instruments.
    
    For more information, see [Enabling the Payment Instruments Feature](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1538492538.html#subsect_160692583086).
