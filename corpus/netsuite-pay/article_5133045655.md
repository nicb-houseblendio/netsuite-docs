To implement NetSuite Pay, follow these steps:

## Install NetSuite Pay {#subsect_0227011055}

-   Install NetSuite Pay from the SuiteApp Marketplace. See [Installing NetSuite Pay](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_6123604680.html).
    
    Note:
    
    The SuiteApp is automatically installed for new customers in the United States.
    
-   Sign the Estimate/Order Form. See [Signing Forms for NetSuite Pay](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_3145439547.html).
    
    Important:
    
    Customers in the United States and Canada (excluding Quebec) can download the SuiteApp and sign the Estimate/Order Form using DocuSign. Customers in Quebec must contact their account manager to complete the signing process.
    
-   Enable all prerequisite features. See [Prerequisite Features for NetSuite Pay](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_7100838260.html).
    

## Apply for a Merchant Account {#subsect_0227011117}

-   Complete your Versapay merchant account application. See [Submitting a Merchant Account Application](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_2122140403.html).
    
-   Receive notice of application approval. The processing partner's underwriting team will respond within 48 hours of receiving a complete application. You may receive a phone call or email for any questions or document needs. Delays in response may result in a slower application approval time. See [Checking Merchant Account Application Status](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_2123636382.html).
    

## Configure and Test {#subsect_0227011839}

-   Configure your payment processing profile. See [Configuring the NetSuite Pay Payment Processing Profile](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_3093631811.html).
    
-   Configure automated settlement reconciliation. See [Automated Settlement Reconciliation for NetSuite Pay](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_6145552647.html).
    
-   (Optional) Set up Payment Link. This can be done in parallel to waiting for your merchant account approval. See [Payment Link](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_162516600357.html).
    
-   Connect to a Versapay Test Payment Gateway. Use this connection to test NetSuite Pay functionality before processing real transactions. See [Connecting to a Test Payment Gateway](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_7135858032.html).
    
-   Test your first payment.
    
    -   To test using NetSuite, create a cash sale for a $1.00 item. See [Cash Sales](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1244343.html).
        
    -   (Optional) To test with Payment Link, see [Payment Link](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_162516600357.html).
        

## Review Data Requirements {#subsect_1118012551}

NetSuite Pay is compliant with Visa's Commercial Enhanced Data Program (CEDP). This interchange program is designed to improve transaction data quality for business-to-business (B2B) purchases. NetSuite Pay includes automated scripting and logic to populate most required fields, but you should review and improve your data in NetSuite, where required.

Required fields:

-   **Line-item data** - Item description, quantities, unit cost (rate), amount (ensure this equals quantity \* unit cost)
    
-   **Item record data** - SKU or item codes (UPC code), unit of measure
    
-   **Required if you're taxable** - Merchant Tax ID or Supplier Tax ID
    
-   **Required if you're using shipping** - Shipping Amount or Shipping Item, Destination Address (Ship To), Ship From Postal Code
    

The following fields are optional but highly recommended:

-   **Financial fields** - Customer Reference Number or Purchase Order Number
    

Generic placeholders such as 'Product' or dummy values will disqualify your transaction from verified status.

For more information about CEDP, see [Versapay's information about CEDP](https://www.versapay.com/cedp).

Tip:

NetSuite Pay can also be configured in your sandbox account to test the NetSuite Pay experience prior to full implementation in production. For more information, see [Setting Up NetSuite Pay in Sandbox](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_4113054031.html).
