You should use URLs that include account-specific domains in PDF templates. Data center-specific URLs found in printing templates are automatically updated to use the appropriate account-specific domain URL for each PDF printout. However, your configuration doesn't change. You should update all URLs in stored templates to use account-specific domains. For example, you should change a **system.eu2.netsuite.com** link in your template link to _<accountID>_.app.netsuite.com, where _<accountID>_ is a variable representing your account ID.
