The following case record synthetic fields are available for templates used in case notifications.

| Field/Sublist | Description |
| --- | --- |
| updatedBy | Name of user who last updated a case. |
| messages | Sublist containing all message records entered for a case. |
| externalMessages | Sublist containing all external message records entered for a case. |
