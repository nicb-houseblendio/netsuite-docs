The following sublist is available for customer, vendor, contact, employee, and partner records if you have the Subscription Categories feature enabled.

| Sublist (where applicable) | Field and Description |
| --- | --- |
| **subscriptions** | subscription : This is the name of a subscription category. |
| \- | subscribed : This is the subscription status for a campaign subscription category. |
