You can reference the following synthetic fields in any context that includes the customer record:

| Sublist (where applicable) | Field and Description |
| --- | --- |
| \- | url : The URL for the customer record in your NetSuite account. |
| **relatedItems** | 
-   purchasedItem : Name of the item purchased. Used to determine related items.
-   upsellItem : Name of related item.
-   sellable : Indicates whether the item is available for sale.

 |
| **correlatedItems** | 

-   purchasedItem : Name of the item purchased. Used to determine upsell items.
-   upsellItem : Name of the upsell item.
-   sellable : Indicates whether the item is available for sale.
-   correlation : Calculated correlation between upsell item and item purchased.
-   count : Number of times the upsell item and correlated item have both been purchased by the same customer.

 |
