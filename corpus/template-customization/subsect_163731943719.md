In the advanced template editor, you can click the Template Setup button to display a Template Setup window where you can change:

-   Basic template properties, including:
    
    -   Title (name)
        
    -   Description
        
    -   Whether the template is preferred for the transaction type
        
    -   Script ID, which is assigned automatically if you leave this field blank
        
    -   Saved Search Template, which generates a template based on an existing saved search (only available for Saved Search templates)
        
    -   Template inactivation, if required
        
-   Template layout settings, including:
    
    -   Page orientation
        
    -   Page size
        
    -   Margins
        

![Template Setup popup window](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/TemplateCustomization/AdvPrintingTemplateSetup.jpg)

For information about options for saving templates, see [Saving an Advanced Template](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156580675374.html)
