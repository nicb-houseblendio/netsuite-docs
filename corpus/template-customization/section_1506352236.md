The buttons on the New Element tab let you add fields, images, and tables, or printing elements such as text, page numbers, page breaks, horizontal lines, headers, and footers. If you're not sure what element a button represents, you can point to the button to see a tooltip. The following table describes each toolbar button in detail.

| Button | Description |
| --- | --- |
| ![Add Field button](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/TemplateCustomization/AdvPDFHTMLToolField.png) | Add a field to the template. For more information, see [Adding and Removing Fields in Advanced Templates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2864695.html). |
| ![Add Text button](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/TemplateCustomization/AdvPDFHTMLToolText.png) | Add text to the template. For more information, see [Adding and Formatting Text in Advanced Templates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2865176.html). |
| ![Add Image button](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/TemplateCustomization/AdvPDFHTMLToolImage.png) | Add an image to the template. For more information, see [Including Images in Advanced Templates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3957689146.html). |
| ![Add Table button](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/TemplateCustomization/AdvPDFHTMLToolTable.png) | Add a table to the template. For more information, see [Adding Tables to Advanced Templates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2865736.html). |
| ![Add Page Number button](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/TemplateCustomization/AdvPDFHTMLToolPageNo.png) | Add the page number to the template. |
| ![Add Total Pages button](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/TemplateCustomization/AdvPDFHTMLToolNumPage.png) | Add the total number of pages to the template. |
| ![Add Page Break button](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/TemplateCustomization/AdvPDFHTMLToolEndPg.png) | Add a page break to the template. If you want to remove the page breaks, you must switch to Source Code view. |
| ![Add Horizontal Line button](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/TemplateCustomization/AdvPDFHTMLToolLine.png) | Add a horizontal line to the template. |
| ![Add Template Header Toggle button](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/TemplateCustomization/AdvPDFHTMLToolHeader.png) | Click button to remove or add the template header. Note: If you remove the header from the template and then add it again, the header content is erased. |
| ![Add Template Footer Toggle button](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/TemplateCustomization/AdvPDFHTMLToolFooter.png) | Click button to remove or add the template footer. Note: If you remove the footer from the template and then add it again, the footer content is erased. |
