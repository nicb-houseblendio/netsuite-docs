You can use these fields to include information about the user who sends the email using the template.

| Field | Description |
| --- | --- |
| 
-   isSystem

 | This field indicates whether the email is initiated by a user or is system-generated. This field is set to True when NetSuite sends the email automatically, for example with system notification templates. When email is initiated by a specific user, this field is set to False. |
| 

-   firstName
-   middleName
-   lastName
-   phone
-   email
-   altEmail

 | These fields are available only for email initiated by a specific user. These tags refer to fields on the user's employee record. |
