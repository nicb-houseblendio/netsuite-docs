When saving an advanced template, you have the following options:

-   **Save** - Saves the template using the existing file name
    
-   **Save As** - Makes a copy of the template
    
-   **Save & Edit** - Saves the template and remains in edit mode
    

## Creating a Copy of an Advanced Template {#subsect_163732301941}

If you want to use an existing customized advanced template as the basis for a new template, you can use the **Save As** button to save a template under another name.

1.  On the Advanced PDF/HTML Template List page, click **Edit** next to the template that you want to copy.
    
2.  The Template editor appears. Click **Template Setup** and name the new template. For more information, see [Template Setup Window](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_163731943719.html).
    
3.  Click **Save**.
    
4.  In the template editor, click **Save As** to save the new template.
    

![Sample advanced template with the Save As button outlined in red.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/TemplateCustomization/AdvPDFHTMLSaveAs.png)

## Saving Your Template and Continuing to Make Edits {#subsect_156631744956}

If you want to save your progress but continue making further edits, click **Save & Edit**. A message will appear to let you know whether your template's been saved successfully.

![Sample advanced template with Save & Edit outlined in red.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/TemplateCustomization/AdvPDFHTMLSaveAndEdit.png)

## Template Errors When Saving {#subsect_156631749022}

After clicking Save, Save As, or Save & Edit, if your template contains errors, an error message appears, and you're asked if you want to submit anyway. Choose from the following options:

-   To override the error and save the template, click **Save**. The template is saved. Sometimes a template may work in production even if it fails validation.
    
-   To cancel the save and fix the error, click **Cancel**. The template isn't saved, and you go back to edit mode to fix any issues.
