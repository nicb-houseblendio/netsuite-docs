The following sublist is available for campaign email templates and templates for customer, partner, and user access notifications.

| Code | Description |
| --- | --- |
| subscriptionCenter.unsubscribeURL | The URL to unsubscribe from subscriptions. It opens the Campaign Subscription Center with all subscription options unchecked. |
| subscriptionCenter.manageURL | The URL to manage subscriptions. It opens the Campaign Subscription Center with subscription options checked according to the user's settings. |
