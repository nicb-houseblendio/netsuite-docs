You can see the fields available to include on an advanced template by reviewing the template in the template editor.

Note:

Sublists displayed in the field selector are dimmed and appear for reference only. You can't add sublists to a template from the field selector. Instead, you must edit the markup source to add a sublist. In addition, you can reference fields on a sublist only at the first level. Referencing sublists at the second level isn't supported, with the exception of addresses. For more information about adding sublists to a template, see [Source Code Editing in the Template Editor](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4454200103.html).

You can add and remove fields as needed, and also add currency symbols in front of fields, by following the steps in the following procedures:

-   [Adding a Field to an Advanced Template](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_163732036124.html)
    
-   [Adding and Removing Currency Symbols in Advanced Template Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_163732053152.html)
    
-   [Removing a Field from an Advanced Template](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_163732067128.html)
