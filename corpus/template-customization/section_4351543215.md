The editor for advanced PDF/HTML templates lets you preview templates so you can see how template changes affect PDF output as you're editing a template. You can preview the template from both WYSIWYG and markup source editing modes.

![Sample template in WYSIWYG mode with the Preview option outlined in red.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/TemplateCustomization/AdvPDFHTMLPreview.png)

Click the **Preview** button to generate and display a PDF based on the current template definition. The PDF that appears uses sample data that simulates the real values as follows:

-   $9,999.99 represents dollar values.
    
-   6/22/2015 represents a date value in U.S. date format.
    
-   Lorem ipsum represents text values.
    

![Sample Invoice PDF preview.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/TemplateCustomization/AdvTempPreviewPDF.png)

If the template can't be previewed, you'll see an error message.
