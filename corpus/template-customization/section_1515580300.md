You can find the Change ID button on the advanced PDF/HTML templates configuration page for custom templates. To change the script ID of a custom advanced PDF/HTML template, click **Change ID**.

On the Change ID page, enter the new script ID for the template. Script IDs for custom templates start with **custtmpl**.

Click **Save**.

Note:

You can't change the script ID of standard templates.
