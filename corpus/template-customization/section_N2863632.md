To customize your advanced template, you can use the WYSIWYG template editor provided, or you can enter source code markup. For more information about editing, see [WYSIWYG Editing in the Template Editor](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4454197641.html) and [Source Code Editing in the Template Editor](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4454200103.html).

Note:

For some customization options such as adding a bar code or sublist data to your advanced template, you must edit the source code. For more information, see [Source Code Editing to Customize Advanced Templates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4454208098.html).

NetSuite provides a WYSIWYG template editor that lets you review and edit standard advanced templates to create your own custom templates. In WYSIWYG, you can drag items to move them around on the template.

The template editor supports current industry standards for HTML-based editing, including rich text editing and HTML markup source editing. For more details, see:

-   [Viewing an Advanced Template in the Template Editor](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_163731932934.html)
    
-   [Template Setup Window](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_163731943719.html)
    
-   [Previewing Advanced PDF/HTML Templates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4351543215.html)
    
-   [Saving an Advanced Template](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156580675374.html)
    
-   [Error Messages in Advanced Templates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1499441399.html)
    
-   [WYSIWYG Editing in the Template Editor](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4454197641.html)
    
-   [Source Code Editing in the Template Editor](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4454200103.html)
    

Note:

The template editor uses FreeMarker-based syntax. For more information, see the [FreeMarker documentation](http://freemarker.apache.org/docs/index.html).
