The following synthetic fields are available on the **Item Fulfilment** record for email sent to web site customers.

| Field and Description | Available for Email Type |
| --- | --- |
| 
-   trackingLink : This field contains the order tracking message.
-   overviewTable : List of items included in the order.

 | Order Fulfilled |
