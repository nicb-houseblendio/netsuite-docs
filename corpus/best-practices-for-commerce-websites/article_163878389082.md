To finish the order quote approval workflow, use the **Workflow Manager** to set up states, actions, and transitions. To learn more, see [Workflow Manager Interface](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4068295521.html).

In the **Workflow Manager** workspace, follow these steps to create states for the order quote approval workflow.

#### To create workflow states:

1.  Go to _Customization> Workflow> Workflows_ and click **Edit** next to the order quote approval workflow.
    
2.  In the **Workflow Manager** workspace, double click **State 1** to edit it, and rename it to **Estimate Creation**.
    
3.  Click the **New State** button to create three new states: **Pending Approval**, **Approved**, and **Rejected**.
    
4.  Set up the states in the process flow as shown in the following screenshot.
    
    ![Workflow States](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/BestPracticesCommerceWebsites/workflows_step5.png)

After you create the states, configure each state using the links in the following table.

| State | Actions | Transitions |
| --- | --- | --- |
| [Estimate Creation State](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_163906088860.html) | 
-   Set Field Value: Set the **Approval Status** field to **Pending Approval**

 | Transitions to the following states:

-   **Pending Approval** if the estimate shows a default sales rep and that sales rep has a supervisor on their employee record.
-   **Approved** if the estimate shows a default sales rep and that sales rep has no supervisor on their employee record.

 |
| [Pending Approval State](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_163906094256.html) | 

-   Add Button: Add an **Approve** button
-   Add Button: Add a **Reject** button

 | Transitions to the following states:

-   **Approved** if the supervisor clicks the **Approved** button.
-   **Rejected** if the supervisor clicks the **Reject** button.

 |
| [Approved State](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_163906114754.html) | 

-   Set Field Value: Set the **Approval Status** field to **Approved**
-   Send Email: Send email to the sales rep

 | \- |
| [Rejected State](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_163906116625.html) | 

-   Set Field Value: Set the **Approval Status** field to **Reject**
-   Send Email: Send email to the sales rep

 | \- |
