Get the external URL for the FSM Mobile Suitelet. You'll use this URL as the redirect URI when you create the FSM integration record for OAuth 2.0 authentication.

#### To get the FSM Mobile Suitelet external URL:

1.  Go to Customization > Scripting > Script Deployments.
    
2.  On the Script Deployments page, find the **Field Service Mobile Suitelet** (ID: `customdeploy_nx_mobile`), then click **View**.
    
3.  From the **External URL** field, copy the link.
    
    You'll need it when you create the FSM integration record.
