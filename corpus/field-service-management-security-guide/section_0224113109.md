Certain core product functions within the FSM code base can be overwritten by the configuration record. This was previously used as a method to apply temporary patch-fixes directly into an account. Some of these older patch fixes still exist in older accounts, many of which are no longer required.

This functionality should not be used moving forward. It will soon be removed from the product. If you identify any configuration entries that override product JavaScript functions, check with your FSM support contact whether that entry should be removed from your account.
