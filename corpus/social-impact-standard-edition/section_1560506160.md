The Program Manager manages the Not for Profit Programs. The Program Manager is responsible for monitoring the program performance including:

-   financial planning
    
-   management of financial risks
    
-   revenue stream distribution by program
    
-   tracking program beneficiaries
    
-   reporting cost per mission outcome
    

The Program Manager role includes custom dashboards. The following table highlights the key portlets on the Home dashboard.
