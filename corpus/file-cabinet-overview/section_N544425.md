## Unrecognized File Types {#subsect_163724008464}

NetSuite accepts all file formats in the File Cabinet, but if it doesn't recognize a file format, it lists the file type as **Other Binary File**. NetSuite can't identify unrecognized file formats if you upload them in a .zip file. If you see other binary files in a folder, but want to ensure that the file extension displays, then upload those files one at a time.
