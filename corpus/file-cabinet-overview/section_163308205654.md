When the File Cabinet feature is enabled, users with the Administrator role and users with the Documents and Files permission can access File Cabinet files. Roles and permissions affect which document folders are visible to users. For more information, see the following topics:

-   [Enabling Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N232138.html)
    
-   [Setting Permissions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N288727.html)
    
-   [Permissions and File Cabinet Files](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4799276714.html)
    

To access the File Cabinet, go to _Documents > Files > File Cabinet_.

The File Cabinet page consists of two main panes. The left pane shows a full table of contents which you can use to browse the folder structure and find the files you need. The right pane provides more detailed information about the folders or files such as size, last modified date, and type. To download a file or the contents of a folder, click the related Download link.

On the File Cabinet page, you can also:

-   Create new folders
    
-   Add, copy, delete and move files
    
-   Search for files
    

Note:

You must have the Full level of the Documents and Files permission to delete files from the File Cabinet.
