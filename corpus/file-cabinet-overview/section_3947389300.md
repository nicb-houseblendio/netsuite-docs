Users with the Administrator role and users with the full Documents and Files permission can delete File Cabinet folders. For more information, see [Setting Permissions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N288727.html).

You can delete a folder that contains files and subfolders, or you can delete an empty folder. If the folder contains a file that's attached to a record, the delete operation fails. A popup alert displays indicating that you must remove the file from the record to continue.

## Deleting a Folder Containing Files {#subsect_161963472323}

You can delete a folder that contains files you no longer need.

#### To delete a folder containing files:

1.  Go to _Documents > Files > File Cabinet_.
    
2.  Locate and click the parent folder of the folder you want to delete.
    
3.  Click **Delete Files**.
    
    ![Delete Files button on the File Cabinet page.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteBasics/FC_DeleteFolder.png)
4.  A list displays of files and subfolders in the parent folder. Check the box next to the folder you want to delete.
    
    ![Delete button on the Folder Contents page.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteBasics/FC_DeleteFolder2.png)
5.  Click **Delete**.
    

## Deleting an Empty Folder {#subsect_161963481641}

You can delete empty folders from the File Cabinet.

#### To delete an empty folder:

1.  Go to _Documents > Files > File Cabinet_.
    
2.  Locate the empty folder you want to delete.
    
3.  Click **Edit** next to the folder name.
    
4.  Expand the **Actions** menu.
    
5.  Click **Delete**.
