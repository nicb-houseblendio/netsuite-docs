You can use both NetSuite and Data Exchange to manage data load rules for your NetSuite Enterprise Performance Management (EPM) applications. This help topic shows which data load tasks you can complete using each user interface for the following NetSuite EPM applications:

-   [NetSuite Planning and Budgeting](#article_0328121540)
    
-   [NetSuite Account Reconciliation](#article_0328121907)
    

Note:

In NetSuite EPM, Data Load Rule jobs are called Data Integration jobs.

Tip:

NetSuite is the preferred user interface for managing data load rules in your NetSuite EPM application.

Important:

If you change your NetSuite EPM password or it expires, you need to re-enter the password in NetSuite. To avoid this, you can use OAuth 2.0 to connect to NetSuite Account Reconciliation. OAuth 2.0 isn't currently supported for connecting to NetSuite Planning and Budgeting.

## NetSuite Planning and Budgeting {#article_0328121540}

The following table lists standard data load tasks for NetSuite Planning and Budgeting and shows whether NetSuite or Data Exchange can support each tasks:

| Task | Supported by NetSuite? | Supported by Data Exchange? |
| --- | --- | --- |
| Run a batch job (data and metadata loads) | Yes | Yes |
| Run a data load rule job | Yes | Yes |
| Check data load rule progress | Yes | Yes |
| View/Download job logs | Yes | Yes |
| Schedule jobs | Yes | Yes |
| Update substitution variables | Yes | Yes |
| Check monthly substitution variables | Yes | Yes |
| Check Planning and Budgeting account balance data | Limited functionality | Yes |
| Check the integration status | Yes | Yes |
| Get email notifications about jobs | Yes (using saved searches) For instructions, see [Enabling Saved Search Email Alerts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N681962.html). | Yes (using pipelines) |
| Load data back into NetSuite | Yes | No |
| Manage pipelines | No | Yes |
| Create group jobs | Yes For instructions, see [Group](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_160470269371.html). | No |

## NetSuite Account Reconciliation {#article_0328121907}

The following table lists standard data load tasks for NetSuite Account Reconciliation and shows whether NetSuite or Data Exchange can support each tasks:

| Task | Supported by NetSuite? | Supported by Data Exchange? |
| --- | --- | --- |
| Load periods | Yes | No |
| Load profiles | Yes | No |
| Load balances for reconciliation | Yes | No |
| Load transactions for transaction matching | Yes | Yes |
| Load exchange rates | Yes | No |
| Load data back into NetSuite | Yes | No |
