To clone a source environment to a NetSuite Cloud EPM (target) environment, you have two options:

-   Use the Clone Environment feature in your application. This feature is a screen-based way to clone an environment. See [Clone Environment Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0830083855.html).
    
-   Use the cloneEnvironment EPM Automate command. See [cloneEnvironment](https://docs.oracle.com/pls/topic/lookup?ctx=en/cloud/saas/enterprise-performance-management-common/epmss&id=CEPMA-GUID-299CD2B5-7468-4844-A2FA-EB2FE913514B).
