Important:

Before connecting to the NetSuite AI Connector Service, it's important to familiarize yourself with [Associated Risks, Controls, and Mitigation Strategies](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_9002708453.html) when working with AI clients and LLMs.

This section explains how to connect to the NetSuite AI Connector Service using Claude or ChatGPT.

#### Connect using Claude (MCP Standard Tools SuiteApp)

1.  Go to **claude.ai** in your browser and login to your Claude account.
    
2.  Go to Search and tools > Add connectors.
    
3.  In the Connectors section under the **Web** tab select the **NetSuite** AI connector.
    
4.  Click **Connect**
    
5.  Paste the Server URL below with the account ID of your account:
    
    https://_<accountid>_.suitetalk.api.netsuite.com/services/mcp/v1/suiteapp/com.netsuite.mcpstandardtools
    
6.  Click **Continue**
    
7.  Go to Search and tools > Manage connectors.
    
8.  Under **Your connectors**, go to NetSuite and click **Connect**.
    
9.  On the first connection, you're prompted to allow or deny access to your NetSuite account. Make sure you review [Associated Risks, Controls, and Mitigation Strategies](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_9002708453.html) before proceeding. After you allow access, on subsequent connections you're informed that Claude already has access and you're asked to go back or continue. If connected successfully, a popup message appears.
    

#### Connect using Claude (Custom Tools)

1.  Open a browser window and log in to your NetSuite account.
    
2.  Open a new tab in your browser and go to **claude.ai**.
    
3.  Log in to your Claude account.
    
4.  In Claude, go to Settings > Connectors.
    
5.  In the Connectors section, click **Add custom connector**.
    
6.  Enter the name of your connector and your remote NetSuite AI Connector Service URL. To learn where to obtain this URL, see [Server URL and SuiteApp Namespacing](#bridgehead_0804033331).
    
7.  Click **Add**. Your custom NetSuite connector is visible in the list of connectors.
    
8.  Click **Connect**.
    
    On the first connection, you're prompted to allow or deny access to your NetSuite account. Make sure you review [Associated Risks, Controls, and Mitigation Strategies](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_9002708453.html) before proceeding. After you allow access, on subsequent connections you're informed that Claude already has access and you're asked to go back or continue. If connected successfully, a popup message appears.
    
9.  You can now see your connector in Claude by clicking the Search and tools icon on your new chat page. You can disable this functionality by removing the MCP Server Connection permission.
    

#### Connect using ChatGPT (MCP Standard Tools SuiteApp)

1.  In ChatGPT, go to **Apps** on the sidebar.
    
2.  Search for **NetSuite** and select the NetSuite app in the search results.
    
3.  Go to **Connect** and in the pop-up dialog, select **Sign in to NetSuite**.
    
4.  Sign in using your NetSuite credentials.
    
5.  Make sure you have selected the correct, non-administrator role to sign in, and click **Continue**.
    
6.  When you have successfully signed in to NetSuite, the NetSuite AI Connector is available in your ChatGPT and you can start interacting with NetSuite.
    

Important:

To connect to NetSuite using ChatGPT with **Custom Tools**, a new integration record is needed for every new connection.

In SuiteAnswers you can find information about [How to connect ChatGPT to NetSuite using the NetSuite AI Connector service](https://suiteanswers.custhelp.com/app/answers/detail/a_id/1025062/kw/1025062).

For other AI agents, you must adjust the instructions accordingly, and before you connect you must read and familiarize yourself with the [NetSuite AI Connector Service-specific Integration Record](#bridgehead_0804033316).

In SuiteAnswers you can also find additional information about how to [Connect to the NetSuite AI Connector Service using Postman](https://suiteanswers.custhelp.com/app/answers/detail/a_id/1022684/loc/en_US), [Connect Codex to NetSuite Using the NetSuite AI Connector](https://suiteanswers.custhelp.com/app/answers/detail/a_id/1045686/loc/en_US), [Connect Claude Code to NetSuite Using the NetSuite AI Connector](https://suiteanswers.custhelp.com/app/answers/detail/a_id/1045678/loc/en_US), [Connect Copilot Studio to NetSuite Using the NetSuite AI Connector](https://suiteanswers.custhelp.com/app/answers/detail/a_id/1046882/loc/en_US).

## Server URL and SuiteApp Namespacing {#bridgehead_0804033331}

To establish a connection, you need a remote NetSuite AI Connector Service URL. This URL is unique to your NetSuite account and an Administrator can provide you with this URL.

Depending on your use case, your URL uses one of the following formats:

-   **https://<**_accountid_**\>.suitetalk.api.netsuite.com/services/mcp/v1/suiteapp/<**_applicationid_**\>** - Returns only the custom tools exposed by the specified SuiteApp.
    
    For example, the **URL for the MCP Standard Tools SuiteApp** is: https://_<accountid>_.suitetalk.api.netsuite.com/services/mcp/v1/suiteapp/com.netsuite.mcpstandardtools
    
    Where you must replace _<accountid>_ with the ID of your account.
    
    The structure of <_applicationid_\> is: <_publisherid_\>.<_projectid_\> where <_publisherid_\> could be, for example, "com.netsuite", and <_projectid_\>, for instance, "mcpstandardtools".
    
-   **https://<**_accountid_**\>.suitetalk.api.netsuite.com/services/mcp/v1/all** - Returns all available custom tools in the account from both SuiteApps and account customization projects (ACPs). Replace <_accountid_\> with your real account ID, for example "TD12345678".
    

To learn more about URLs used for different types of accounts, see [URLs for Account-Specific Domains](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1498251763.html).

## NetSuite AI Connector Service-specific Integration Record {#bridgehead_0804033316}

An integration record is automatically installed in your account after the first connection with Claude. After the installation, users with the Administrator role and all other users with appropriate permissions can view the record by going to Setup > Integration > Manage Integrations. This record is enabled automatically regardless of account settings. This record differs from other integration records in the following ways:

-   The name of the integration is populated.
    
-   The **Public Client** box is checked.
    
-   The **Redirect URI** field is populated.
    
-   The **Authorization Code Grant** box is checked.
    
-   The **NetSuite AI Connector Service** scope is enabled.
    
-   The **State** and **Concurrency Limit** fields are editable, which means you can disable the integration record, or allocate part of your total concurrency limit to it.
    

If you're using a different AI client, other that Claude or ChatGPT, you must confirm the following:

-   If you have installed a SuiteApp, go to your Integrations page in NetSuite, and confirm whether a new Integration record has been created during the SuiteApp installation.
    
    -   If not, you must create one manually.
        
    -   If an integration record has been created, and the NetSuite AI Connector Service scope is enabled, the integration record is initially in a pending state. An administrator must manually enable the integration record by accessing it directly. When enabled, the integration record can't revert to the pending state; it can only be disabled if needed.
        
    -   If an integration record has been created, but the NetSuite AI Connector Service scope isn't enabled, you must recreate the integration record.
        
-   If you have not installed a SuiteApp, you need to build your own MCP tools and manually create the Integration record.
    

For more information, see also [Creating Custom Tools for the NetSuite AI Connector Service](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_162020236.html) and [Create Integration Records for Applications to Use OAuth 2.0](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157771733782.html).

## NetSuite AI Connector Service (MCP) Execution Log {#bridgehead_0216045724}

Each integration record includes an Execution Log tab with the subtabs: SOAP Web Services, REST Web Services, RESTlets, and AI Connector Service (MCP).

The AI Connector Service (MCP) subtab displays logs of AI Connector Service (MCP) calls associated with the current integration record.

The log entries shown are filtered by the application ID of the integration record you are viewing.

For each request, the log includes the following details:

-   The date and time that the request was made.
    
-   The duration of the request.
    
-   The status of the request (such as success or failure).
    
-   The email address of the user who sent the request.
    
-   The HTTP status code returned.
    
-   The method used for the request.
    
-   The URL path of the request.
    

This data helps you monitor and troubleshoot calls made by the AI Connector Service for each specific integration record.

Note:

In production environments, data in the Execution Log is available for 21 days. In sandbox environments, the data is accessible for seven days.
