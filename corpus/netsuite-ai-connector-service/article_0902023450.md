Important:

The MCP Standard Tools SuiteApp is a managed SuiteApp and is automatically updated whenever enhancements or new features are released. The tools provided in the SuiteApp may be modified over time. If you have customizations or workflows that use these tools, be aware that some updates may change how the tools operate.

This topic guides you through the installation of the MCP Standard Tools SuiteApp.

## Prerequisites for the MCP Standard Tools SuiteApp {#subsect_90090238176}

Ensure that you have set up the required features and permissions to use the NetSuite AI Connector Service. For more information, see [Required Features and Permissions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0714080625.html).

Before you install the MCP Standard Tools SuiteApp, you must enable the **Server SuiteScript** and **REST Web Services** features.

### To enable the required features: {#subsect_49090203180}

1.  Go to _Setup > Company > Enable Features_.
    
2.  On the **SuiteCloud** subtab:
    
    -   Under SuiteScript, check the **Server SuiteScript** box.
        
    -   Under SuiteTalk (Web Services), check the **REST Web Services** box.
        
3.  Click **Save**.
    

## Installing the MCP Standard Tools SuiteApp {#subsect_50090207346}

The MCP Standard Tools SuiteApp is a managed SuiteApp and is automatically updated whenever enhancements or new features are released.

### To install the MCP Standard Tools SuiteApp: {#subsect_62090210547}

1.  Go to the **SuiteApps** tab.
    
2.  In the **Search SuiteApps** field, enter **MCP Standard Tools**.
    
3.  Click the **MCP Standard Tools** icon.
    
4.  On the top right of the SuiteApp details page, click **Install**.
    
5.  Wait for the installation to complete.
    

For more information about installing a SuiteApp from the SuiteApp Marketplace, see [Installing from the SuiteApp Marketplace](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1539799323.html).

## Accessing MCP Standard Tools {#subsect_91090213447}

After installing the SuiteApp, connect to your AI client to start using the tools. To connect and return only the tools provided by the MCP Standard Tools SuiteApp, use the following URL and replace `_<accountid>_` with your NetSuite account ID: `https://``_<accountid>_``.suitetalk.api.netsuite.com/services/mcp/v1/suiteapp/com.netsuite.mcpstandardtools`. For more information, see [Connect to the NetSuite AI Connector Service](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0714082142.html).

The tools you see in your AI client depend on the permissions defined for each tool. A tool is visible only if your role has all the required permissions for that tool. However, access to data and the ability to execute tool actions still depend on your NetSuite role and permissions. You can only access data and perform operations that your NetSuite role allows, regardless of tool visibility.

If the AI client shows an empty list of tools, the SuiteApp may not have been installed successfully or your role doesn't have the permissions required to view the tools. For information about required permissions, see [Available Tools in the MCP Standard Tools SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0902023508.html) and [Available MCP Apps in the MCP Standard Tools SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0415010513.html). To check the installation status of the SuiteApp, see [Viewing SuiteApp Installation or Uninstallation Status](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1539867271.html).

Note:

In addition, to use the tools, your role must have access to the SuiteApp folder in the File Cabinet. If you receive an access denied error when accessing the tools from the AI client, verify that access to the SuiteApp folder in the File Cabinet is not restricted for your role. For more information, see [Restricting Access to File Cabinet Folders](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N542073.html).
