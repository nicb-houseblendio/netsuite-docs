| **Tool Description** | Updates the customer information in NetSuite. |
| --- | --- |
| **Annotation** | Update Customer Information |

## Properties {#subsect_74201253452}

| Property | Type | Required or Optional | Description |
| --- | --- | --- | --- |
| `customerId` | string | Required | ID of the customer that you want to edit. |
| `firstname` | string | Optional | Customer's first name. |
| `lastname` | string | Optional | Customer's last name. |
| `email` | string | Optional | Customer's email address. |
| `phone` | string | Optional | Customer's phone number. |
| `companyname` | string | Optional | Customer's company name. |
| `creditlimit` | string | Optional | Customer's credit limit. |
| `subsidiary` | string | Optional | ID of the customer's subsidiary. |
| `isperson` | string | Optional | Indicates whether the customer is a person (**T**) or a company (**F**). |

## Permissions {#subsect_4201257674}

Only user roles with the following permissions can see this tool in the AI client.

| Permission ID | Permission Name | Level |
| --- | --- | --- |
| TRAN\_FIND | Find Transaction | VIEW |
| TRAN\_CUSTINVC | Invoice | VIEW |
| TRAN\_SALESORD | Sales Order | VIEW |
| LIST\_CUSTJOB | Customers | EDIT |
| LIST\_CONTACT | Contacts | VIEW |
