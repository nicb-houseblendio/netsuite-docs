| **Tool Description** | Generates a simple financial performance summary of your NetSuite account. Use the date format MM/DD/YYYY when specifying the dates. |
| --- | --- |
| **Annotation** | Get Financial Performance |

## Properties {#subsect_83203639073}

| Property | Type | Required or Optional | Description |
| --- | --- | --- | --- |
| `dateFrom` | string | Required | Start date for the date range filter in the format MM/DD/YYYY. |
| `dateTo` | string | Required | End date for the date range filter in the format MM/DD/YYYY. |

## Permissions {#subsect_33203646989}

Only user roles with the following permissions can see this tool in the AI client.

| Permission ID | Permission Name | Level |
| --- | --- | --- |
| TRAN\_FIND | Find Transaction | VIEW |
| TRAN\_SALESORD | Sales Order | VIEW |
| REPO\_FINANCIALS | Financial Statements | VIEW |
