MCP Apps are interactive applications built on the Model Context Protocol (MCP) that allow AI clients to render embedded user interfaces in the chat experience. The following table lists the MCP Apps available in the MCP Standard Tools SuiteApp.

| MCP App Tool Name | Description | Required Permission | Related Tools |
| --- | --- | --- | --- |
| [Prompt Library MCP App](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0505095144.html) | ns\_prompt\_library\_app | Provides an interactive UI for browsing, selecting, and using prompt templates from the NetSuite AI Connector Service Companion SuiteApp in your AI client. For more information about the prompt templates and the SuiteApp, see [NetSuite AI Connector Service Companion SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_9091153093.html). | \- | \- |
| [Record Selector MCP App](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0415010614.html) | ns\_selector\_app | Provides an interactive UI for selecting an existing record from your NetSuite account in any workflow that requires record selection. | REST Web Services (Full) | [Record Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0905122629.html) |
| [Report Filters MCP App](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0415010546.html) | ns\_report\_filters\_app | Provides an interactive UI for choosing the filters needed to run a report in your NetSuite account. | \- | [Report Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0905122640.html) |
