| **Tool Description** | Returns a list of all standard and custom reports in your NetSuite account. For each report, the tool returns the name, internal ID, and additional properties that indicate which filters are available and required to run the report. If you have not specified which report to run or which report filters are needed, the AI client may use the [Report Filters MCP App](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0415010546.html) to help you select and confirm the report and its required parameters. |
| --- | --- |
| **Annotation** | List All Reports |

## Permissions {#subsect_80114439298}

There are no specific permission requirements to see this tool in the AI client. However, the data you can see depends on the permissions assigned to your NetSuite role.
