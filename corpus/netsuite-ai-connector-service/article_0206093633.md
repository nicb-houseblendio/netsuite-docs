The System Administration prompt samples include common tasks and workflows such as:

-   Analyzing custom records and fields
    
-   Analyzing workflows and scripts
    
-   Analyzing reports and searches
    
-   Analyzing integration and external connections
    
-   Obsolete or redundant customization suggestions
    

| Prompt Name | Suggested Roles | Prompt Sample |
| --- | --- | --- |
| **System Customization Analysis** | 
-   Administrator

 | `Analyze our current NetSuite instance customizations. Focus on identifying dependencies and relevancy of all customizations, including: 1. Custom Records & Fields: Identify which custom records, fields, and lists are actively used and critical for business processes. Highlight those with dependencies on other records, workflows, or scripts. 2. Workflows & SuiteScripts: Determine which workflows and scripts are essential, based on current usage, process impact, and interdependencies with other modules. 3. Reports & Saved Searches: Identify reports and searches that drive decision-making and have dependencies on custom records, fields, or workflows. 4. Integrations & External Connections: Highlight integrations that rely on customizations or are critical for core processes. 5. Obsolete or Redundant Customizations: Identify customizations that are unused, redundant, or could be replaced with native functionality. For each customization, provide: * Its description and purpose * Dependencies on other objects or processes * Current usage metrics or relevancy score * Recommendation: Keep, replace with native functionality, or retire Organize results by module (Finance, Inventory, Sales, Procurement, etc.) and prioritize customizations critical for business continuity.` |
| **User Audit** | 

-   Administrator

 | `Identify all user accounts that haven't logged in within the last 90 days, showing their assigned roles, last login date, and whether they have Give Access privileges. Flag users with Administrator or Full Access roles separately.` |
| **Role Permission Audit** | 

-   Administrator

 | `Generate a comprehensive matrix showing which roles have access to which record types (create, view, edit, delete permissions). Highlight roles with Full Access or Administrator privileges and identify permission overlaps between roles.` |
| **Users with Conflicting Roles** | 

-   Administrator

 | `Find users assigned to multiple roles that create segregation of duties conflicts (e.g., AP Clerk + Accountant, Sales + Finance, Administrator + Standard User). Show the conflicting role combinations and affected users.` |
| **Login Anomaly Detection: IP Address** | 

-   Administrator

 | `Identify logins from new IP addresses from the last 30 days and present the results in a table.` |
| **Login Anomaly Detection: 5+ Failed Login Attempts** | 

-   Administrator

 | `Identify failed login attempts exceeding 5 per day from the last 30 days and present the results in a table.` |
| **Login Anomaly Detection: Concurrent Sessions** | 

-   Administrator

 | `Identify concurrent login sessions from different locations in the past 30 days and present the results in a table.` |
| **Unused Custom Fields Inventory** | 

-   Administrator

 | `How many custom fields are owned by the system vs actual users?` |
| **SuiteScript Deployment Health Check:** **Low Activity** | 

-   Administrator

 | `Please compile a report with SuiteScripts that have not been run in the past month.` |
| **SuiteScript Reporting:** **Script Type** | 

-   Administrator

 | `Please complie a report with all SuiteScripts grouped by script type.` |
| **SuiteScript Reporting:** **Source Bundle** | 

-   Administrator

 | `Please compile a report with all SuiteScripts grouped by source bundle.` |
| **SuiteScript Reporting:** **Script Owner** | 

-   Administrator

 | `Please compile a report with all SuiteScripts grouped by script owner.` |
| **Field-Level Audit Trail** | 

-   Administrator

 | `For [RECORD TYPE] and [FIELD NAME], generate a complete audit history showing all changes in the last [PERIOD], including: record ID, field name, old value, new value, changed by (user), timestamp, and business reason if available.` |
| **User Access Recertification Report** | 

-   Administrator

 | `Generate a quarterly access recertification report for management showing: all active users, their roles and permissions, systems accessed in the last 90 days, high-risk transactions performed (JEs, wire transfers, vendor adds), and manager approval status.` |
| **Saved Search Performance Review:** **High Results** | 

-   Administrator

 | `Analyze all saved searches with [>1000] results to identify performance risks. Show: search name, owner, record type, criteria count, result count, whether it's used in dashboards/reports/scripts and last run date.` |
| **Saved Search Performance Review:** **High Criteria** | 

-   Administrator

 | `Analyze all saved searches with [>5] criteria to identify performance risks. Show: search name, owner, record type, criteria count, result count, whether it's used in dashboards/reports/scripts and last run date.` |
| **Record Lock Analysis** | 

-   Administrator

 | `Identify records currently locked for editing, showing: record type, record ID, locked by (user), lock timestamp, duration locked, and whether the user is still actively logged in. Flag locks >2 hours old.` |
| **Required Field Compliance Audit** | 

-   Administrator

 | `Analyze [RECORD TYPE] to find records missing values in required custom fields that were made mandatory after record creation. Show: record ID, missing fields, created date, last modified date, and record owner.` |
| **Mass Update Impact Analysis** | 

-   Administrator

 | `Before performing a mass update on [RECORD TYPE], analyze the scope by showing: number of records to be updated, fields that will change, workflows/scripts that will trigger, required system notes entries, and estimated processing time.` |
| **Integration Activity Monitor** | 

-   Administrator

 | `Track all integration activity over the last 7 days showing: integration name/source, record types affected, success/failure rates, average response time, peak usage times, and error patterns. Flag integrations with <95% success rate.` |
| **Form Customization Inventory:** **Transaction Forms** | 

-   Administrator

 | `Catalog all customized transaction forms showing which subsidiaries/roles they're assigned to, number of custom fields added, whether they use custom tabs, scripting on forms, and last modified date.` |
| **Form Customization Inventory:** **Entry Forms** | 

-   Administrator

 | `Catalog all customized entry forms showing which subsidiaries/roles they're assigned to, number of custom fields added, whether they use custom tabs, scripting on forms, and last modified date.` |
| **Form Customization Inventory:** **Custom Field Count** | 

-   Administrator

 | `Identify forms with >10 custom fields.` |
| **Subsidiary Hierarchy** | 

-   Administrator

 | `Show me the complete subsidiary hierarchy including parent-child relationships, currencies, which subsidiaries are elimination entities, and the number of distinct currencies used in transactions for each subsidiary.` |
