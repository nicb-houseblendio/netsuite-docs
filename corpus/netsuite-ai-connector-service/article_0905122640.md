The report tools enable you to access and run NetSuite reports from your AI client. With these tools, you can retrieve a list of standard and custom reports and run any report that you have access to based on your current permissions. These tools support custom reports and most of the standard reports available in [Standard Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N701428.html).

The report tools support report filters and footer options available in the NetSuite UI. In addition, the MCP Standard Tools SuiteApp includes a Report Filters MCP App, which provides an interactive UI for selecting report filters. For more information, see [Report Filters MCP App](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0415010546.html).

For accounts with one or more subsidiaries, the reports use the currency of the subsidiary selected in the report. For accounts without subsidiaries, the reports use the base currency set up on the Company Information page.

Note:

Accounting periods are not supported. Currently, the report tools ignore the Report by Period user preference. The AI client won't be able to see the accounting periods that you have set up in your NetSuite account, and may use the calendar year as the fiscal year or ask you to provide more details about your fiscal year.

The following report tools are available:

| Name | Description |
| --- | --- |
| [ns\_getAccountingBooks](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_32155211296.html) | Returns a list of accounting books in your NetSuite account that can be used to filter report results. |
| [ns\_getAccountingContexts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_72155229519.html) | Returns a list of accounting contexts in your NetSuite account that can be used to filter report results. |
| [ns\_getNexusIds](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_9212629699.html) | Returns a list of nexuses in your NetSuite account that can be used to filter report results. |
| [ns\_getSubsidiaries](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1124044101.html) | Returns a list of subsidiaries in your NetSuite account that can be used to filter report results. |
| [ns\_listAllReports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0905091622.html) | Returns a list of all standard and custom reports in your NetSuite account. |
| [ns\_runReport](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0905091732.html) | Runs a report in your NetSuite account and displays the results. |

## Support for Consolidated Reporting {#subsect_0417025856}

You can run reports that display data for individual, consolidated, or context subsidiaries.

-   The [ns\_getSubsidiaries](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1124044101.html) tool returns a list of subsidiaries available in your NetSuite account. This list shows:
    
    -   Positive internal IDs for individual subsidiaries.
        
    -   Negative internal IDs for consolidated or context subsidiaries.
        
-   To run a report with the [ns\_runReport](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0905091732.html) tool:
    
    -   For an individual subsidiary, use its positive internal ID in the `subsidiaryId` parameter.
        
    -   For a consolidated subsidiary, use its negative internal ID in the `subsidiaryId` parameter. Reports for a consolidated subsidiary display data for the selected subsidiary and its child subsidiaries.
        
    -   For a context subsidiary (when you only have access to a child subsidiary but want to see its data in the currency of a parent or related context subsidiary), use its negative internal ID in the `subsidiaryId` parameter. Reports for a context subsidiary display data for any child subsidiary you have access to, in the currency of the selected context subsidiary.
        

For information about how consolidated reporting and subsidiary context work in the NetSuite UI, see [Consolidated Reporting in OneWorld](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N278654.html) and [Subsidiary Context for Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N278946.html).

## Known Limitations of the Report Tools {#subsect_1006055815}

Report tools may return null values for custom reports that use custom segments for column segmentation. Custom filters are also not supported.
