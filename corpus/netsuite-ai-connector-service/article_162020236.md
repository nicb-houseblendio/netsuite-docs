By building custom tools, you can automate tasks and extend NetSuite's capabilities. Custom tool scripts let you define the operations a tool can perform and configure it to work with external AI clients that support the Model Context Protocol (MCP). With custom tools, you can build solutions for data retrieval, process automation, and integration with AI clients. For information about the custom tool script type, see [SuiteScript 2.1 Custom Tool Script Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1185045525.html).

NetSuite also supports MCP Apps, which enable you to build custom tools with interactive user interfaces. With MCP App support, your custom tool can provide a bundled HTML UI that is rendered directly in compatible AI chat clients, allowing for richer and more dynamic workflows. For more information, see [Building MCP Apps (Interactive UI) with Custom Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0324030845.html).

This topic outlines the workflow for developing and deploying custom tools using SuiteScript and the SuiteCloud Development Framework (SDF).

You can also find sample implementations of custom tools in the [MCP-Sample-Tools](https://github.com/oracle-samples/netsuite-suitecloud-samples/tree/main/MCP-Sample-Tools) directory of the [SuiteCloud Project Repository on Oracle Samples GitHub](https://github.com/oracle-samples/netsuite-suitecloud-samples).

The following table shows the workflow for creating custom tools in NetSuite:

| Procedure | Related Help Topic |
| --- | --- |
| Step 1: Create a SuiteCloud project using either a SuiteApp project or an account customization project (ACP). | [SuiteCloud Project Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4706651345.html) |
| Step 2: Write your custom tool script. Custom tool scripts don't have predefined entry points, so you must define all tool entry points in a single script. | [SuiteScript 2.1 Custom Tool Script Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1185045525.html) [SuiteScript 2.1 Custom Tool Script Type Reference](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0724071739.html) [Custom Tool Script Requirements](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_13192014863.html) [SuiteScript 2.1 Custom Tool Script Type Code Samples](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0724092648.html) |
| Step 3: Define your tools in a JSON-RPC schema file. Important: The method name and description for each tool help the AI client decide the tool's purpose and when it should be used. If you want to add an interactive UI (MCP App) to your custom tool:
-   Add the `_meta.ui.resourceUri` property to the tool definition in the JSON-RPC schema.
-   Include a bundled, self-contained HTML UI file in your SuiteCloud project.

## Viewing and Deleting Custom Tools {#subsect_1230105631}

You can view the tools available in your NetSuite account by going to Customization > Scripting > Custom Tools. This page displays tools from SuiteApps and ACPs, organized by toolset. You can delete toolsets that are part of ACPs directly from this page by clicking the delete icon for the toolset. For more information, see [Managing Custom Tools in NetSuite](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1201042732.html).

To remove toolsets that are part of SuiteApps, you need to uninstall the SuiteApp. For more information, see [Viewing and Uninstalling SDF SuiteApps in a NetSuite Account](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4849371107.html).
