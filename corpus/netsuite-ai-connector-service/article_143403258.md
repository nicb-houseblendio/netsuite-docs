The MCP Standard Tools SuiteApp is designed for use with the [NetSuite AI Connector Service](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_7200233106.html). It provides a set of tools that let you interact with your NetSuite data - including working with records, reports, saved searches, and SuiteQL queries - through an AI client using the Model Context Protocol (MCP). With this SuiteApp, you can get insights from your NetSuite data and perform a wide range of tasks in NetSuite using natural language input.

The SuiteApp is designed to work with your existing NetSuite roles and permissions. It uses the same access controls as the NetSuite UI, so you can only see data and take actions allowed by your assigned roles.

Important:

The MCP Standard Tools SuiteApp includes tools that can create and update records in NetSuite using REST Web Services. Users with roles that already have the MCP Server Connection permission can perform these actions on any records available through REST, if their current permissions allow it.

Before installing the SuiteApp, consider reviewing which users and roles are assigned this permission and ensure that these roles are authorized to perform record actions in the AI client through MCP. For a more granular access control, you can create a separate role with the MCP Server Connection permission and add specific permissions for the records and actions that users are allowed to perform through the AI client.

For information about roles and permissions for the NetSuite AI Connector Service, see [Required Features and Permissions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0714080625.html) and [Associated Risks, Controls, and Mitigation Strategies](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_9002708453.html).

## Key Features {#subsect_0902023538}

-   **Query NetSuite in natural language** - Describe the data you need, and your AI client will automatically construct and run the appropriate SuiteQL query to retrieve it.
    
-   **Access NetSuite reports** - View and interact with NetSuite reports directly from your AI client.
    
-   **Create and update records** - Use your AI client to create new NetSuite records or update existing ones.
    
-   **Access saved searches** - Run saved searches through your AI client.
    
-   **Permission compliance** - All data access and actions are determined by your NetSuite role and permissions. The tools don't provide any additional access beyond what your NetSuite role allows. Your ability to view data, perform operations, or use specific tools depends on the permissions assigned to the NetSuite role you use to connect.
    

## How MCP Standards Tools Work {#subsect_35143612317}

The MCP Standard Tools SuiteApp enables you to interact with NetSuite data using conversational AI. The typical workflow includes the following steps:

1.  **Install the MCP Standard Tools SuiteApp**
    
    Install the MCP Standard Tools SuiteApp from the SuiteApp Marketplace. For installation instructions, see [Installing the MCP Standard Tools SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0902023450.html).
    
2.  **Invoke Tools through Conversational AI**
    
    After installing the SuiteApp and connecting to the NetSuite AI Connector Service, you can access the available tools in your AI client. Open your AI client and start a conversation using natural language commands or queries.
    
    The AI client interprets your request and presents a set of available tools and actions. For more information about the available tools, see [Available Tools in the MCP Standard Tools SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0902023508.html).
    
3.  **Perform Operations**
    
    When you make a request through the AI client, the SuiteApp translates your command into the appropriate NetSuite API calls or operations.
    
    The SuiteApp performs the task in NetSuite and returns the results to your AI client, where you can view the outcome directly in your conversation interface.
