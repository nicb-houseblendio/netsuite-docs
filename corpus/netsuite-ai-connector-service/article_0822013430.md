| **Tool Description** | Retrieves the transaction history for a specific customer. Use the date format MM/DD/YYYY when specifying the dates. Returns a list of transaction with the following fields:
-   ID
-   Date
-   Document Number
-   Type
-   Customer ID
-   Amount
-   Status
-   Memo
-   Reference

 |
| --- | --- |
| **Annotation** | Get Customer Transactions |

## Properties {#subsect_53201158893}

| Property | Type | Required or Optional | Description |
| --- | --- | --- | --- |
| `customerId` | string | Required | ID of the customer in NetSuite. |
| `dateFrom` | string | Optional | Start date in the format MM/DD/YYYY. |
| `dateTo` | string | Optional | End date in the format MM/DD/YYYY. |

## Permissions {#subsect_11201204211}

Only user roles with the following permissions can see this tool in the AI client.

| Permission ID | Permission Name | Level |
| --- | --- | --- |
| TRAN\_FIND | Find Transaction | VIEW |
| TRAN\_CUSTINVC | Invoice | VIEW |
| TRAN\_SALESORD | Sales Order | VIEW |
| LIST\_CUSTJOB | Customers | EDIT |
| LIST\_CONTACT | Contacts | VIEW |
