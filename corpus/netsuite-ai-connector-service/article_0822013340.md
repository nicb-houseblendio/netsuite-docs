| **Tool Description** | Retrieves sales orders with an option to filter by customer, date range, and status. Use the date format MM/DD/YYYY when specifying the dates. |
| --- | --- |
| **Annotation** | Get Sales Order with Filters |

## Properties {#subsect_22203347568}

| Property | Type | Required or Optional | Description |
| --- | --- | --- | --- |
| `customerId` | string | Optional | Filter by specific customer internal ID. |
| `dateFrom` | string | Optional | Start date for the date range filter in the format MM/DD/YYYY. |
| `dateTo` | string | Optional | End date for the date range filter in the format MM/DD/YYYY. |

## Permissions {#subsect_67203352305}

Only user roles with the following permissions can see this tool in the AI client.

| Permission ID | Permission Name | Level |
| --- | --- | --- |
| TRAN\_FIND | Find Transaction | VIEW |
| TRAN\_SALESORD | Sales Order | VIEW |
| LIST\_CUSTJOB | Customers | VIEW |
| LIST\_EMPLOYEE\_RECORD | Employee Record | VIEW |
| LIST\_EMPLOYEE | Employees | VIEW |
| TRAN\_CUSTINVC | Invoice | VIEW |
| REPO\_BOOKINGS | Sales Order Reports | VIEW |
