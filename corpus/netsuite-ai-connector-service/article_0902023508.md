The MCP Standard Tools SuiteApp includes the following tools:

-   [Record Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0905122629.html) - Create, retrieve, and update NetSuite records.
    
-   [Report Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0905122640.html) - Access and run reports from your NetSuite account.
    
-   [Saved Search Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0905122646.html) - List and run saved searches in NetSuite.
    
-   [SuiteQL Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0905122702.html) - Run custom SuiteQL queries to gather and analyze data in NetSuite.
    

## How To Invoke a Tool {#subsect_32122157179}

You can use natural language in your AI client to invoke a tool. Use the tool description as a guide on how to write your message. For example: Create a customer record in NetSuite for <first name> <last name>.

The client then shows a pop-up asking for permission to use an external integration tool.

## Permissions for Available Tools {#subsect_43122202278}

The permissions defined for each tool determine the visibility of the tool in the AI client. A tool is visible only if your NetSuite role has all the required permissions for that tool. However, access to data and the ability to execute tool actions still depend on your NetSuite role and permissions. You can only access data and perform operations that your NetSuite role allows, regardless of tool visibility.

For information about the permissions required to view each tool, see [List of Available Tools](#subsect_0905122216) or the tool-specific help topics.
