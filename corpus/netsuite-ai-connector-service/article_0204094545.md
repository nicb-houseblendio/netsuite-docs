Important:

The NetSuite AI Connector Service Companion is a managed SuiteApp and is automatically updated whenever enhancements or new features are released. The tools and features available in the SuiteApp may be modified over time. If you have customizations or workflows that use these tools or features, be aware that some updates may change how the prompts operate.

The NetSuite AI Connector Service Companion SuiteApp provides a curated set of prompt samples you can reuse and augment with a supported AI client. These prompts help you get started with NetSuite Model Context Protocol (MCP) tools and capabilities. This topic describes how to install the SuiteApp and access the Companion's prompt samples.

## Prerequisites for the NetSuite AI Connector Service Companion SuiteApp {#subsect_0206092539}

The prompt samples included in the Companion SuiteApp can be used in any large language model (LLM) instance, but they're designed specifically to instruct the AI client to use tools only available through the MCP Standard Tools SuiteApp.

Before you install the NetSuite AI Connector Service Companion SuiteApp, complete the following:

1.  **Familiarize yourself with the benefits and risks of using external AI clients with NetSuite**
    
    AI clients act on behalf of users to access data and perform NetSuite functions on their own. For more information about configuring NetSuite and managing an external AI client, see [Associated Risks, Controls, and Mitigation Strategies](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_9002708453.html).
    
2.  **Set up the NetSuite AI Connector Service**
    
    Follow your company's process to obtain the remote NetSuite AI Connector Service URL for your account and connect from your supported AI client. For more information, see [Get Started with the NetSuite AI Connector Service](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_3200541651.html).
    
3.  **Install the MCP Standard Tools SuiteApp**
    
    Ensure that you have installed the MCP Standard Tools SuiteApp and set up the required features and permissions for the tools provided by the SuiteApp. For more information, see [Installing the MCP Standard Tools SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0902023450.html).
    

## Permissions and Tools Required to Use the Companion {#subsect_0206093203}

The NetSuite AI Connector Service Companion SuiteApp provides you with prompt samples that are written for an AI client connected to the MCP Standard Tools SuiteApp through the NetSuite AI Connector Service. The prompt samples instruct the AI client to use the appropriate tools provided by the MCP Standard Tools SuiteApp.

A tool from the MCP Standard Tools SuiteApp is visible to your AI client only if your NetSuite role has all the required permissions for that tool. You can only access data and perform operations that your NetSuite role allows, regardless of whether a tool is visible to your AI client.

### Optional NetSuite AI Companion Roles {#subsect_0309064913}

To help you get started quickly, NetSuite provides the following roles that include the required MCP tool permissions. These roles are not required. Any role can use the Companion if it has the required permissions and the required setup is complete.

-   **AI Companion Controller** - Designed for typical NetSuite financial controller-level access with the required MCP tool permissions.
    
-   **AI Companion View Only** - Designed for read-only access to NetSuite records and reporting data with the required MCP tool permissions.
    

For example, the Current Period Financial Overview prompt sample (in the [Financial Prompts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0204100919.html) category) instructs the AI client to use the [ns\_runReport](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0905091732.html) tool from the MCP Standard Tools SuiteApp:

            `Use the ns_runReport tool to analyze the Income Statement for [current period] in [subsidiary] and identify any notable financial metrics and trends. Highlight any significant line items that require attention.` 
          

If your NetSuite role doesn't have the required permissions for report tools in the MCP Standard Tools SuiteApp, the AI client can't run this prompt as intended. For more information about MCP Standard Tools permissions and available tools, see [Available Tools in the MCP Standard Tools SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0902023508.html).

## Installing the NetSuite AI Connector Service Companion SuiteApp {#subsect_0206092647}

The NetSuite AI Connector Service Companion SuiteApp is a managed SuiteApp and is automatically updated whenever enhancements or new features are released.

#### To install the NetSuite AI Connector Service Companion SuiteApp:

1.  Go to the **SuiteApps** tab.
    
2.  In the **Search SuiteApps** field, enter **NetSuite AI Connector Service Companion**.
    
3.  Click the **NetSuite AI Connector Service Companion** icon.
    
4.  In the upper-right corner of the SuiteApp details page, click **Install**.
    
5.  Wait for the installation to complete.
    

For more information about installing a SuiteApp from the SuiteApp Marketplace, see [Installing from the SuiteApp Marketplace](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1539799323.html).

To check the installation status of the SuiteApp, see [Viewing SuiteApp Installation or Uninstallation Status](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1539867271.html).
