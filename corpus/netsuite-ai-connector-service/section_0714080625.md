Before you try anything else, you must make sure that you have the correct features enabled. Go to _Setup > Company > Enable Features_, then click the SuiteCloud subtab and make sure the following features are enabled:

-   Server SuiteScript
    
-   OAUTH 2.0
    

Important:

The NetSuite AI Connector Service has not been assessed for compliance with the U.S. Health Insurance Portability and Accountability Act (HIPAA). Accordingly, this feature is not represented or warranted as having the administrative, physical, or technical safeguards necessary to create, receive, maintain, transmit, or otherwise process electronic protected health information (ePHI). You must not use this feature to store, process, or transmit ePHI unless and until you have independently determined that such use is consistent with your own HIPAA compliance obligations and applicable law.

Also, you must give the required permissions to all roles in your account that should be able to use the NetSuite AI Connector Service. To do that, go to _Setup > Users/Roles > Manage Roles_, and edit each role that needs the NetSuite AI Connector Service by adding the required permissions under the Permissions > Setup subtab:

-   MCP Server Connection
    
-   Log in using OAuth 2.0 Access Tokens - Do not confuse it with the Log in using Access Tokens permission.
    

Important:

To prevent unwanted results in case the external AI client's security is at risk, it is not possible to run the NetSuite AI Connector Service if you've logged in to NetSuite with the Administrator role or roles that have full permissions to access NetSuite features.

Important:

If you want to install the MCP Standard Tools SuiteApp, in addition to the required features and permissions for the NetSuite AI Connector Service, you must also enable the **REST Web Services feature**. If you want your users to also be able to use the SuiteApp to create, retrieve, and update NetSuite records, you must give the **REST Web Services permission** to the specific role. For more information, see [MCP Standard Tools SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_143403258.html).
