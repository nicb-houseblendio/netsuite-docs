The following tools let you access saved searches from your AI client.

| Name | Description |
| --- | --- |
| [ns\_listSavedSearches](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0905091635.html) | Returns a list of all saved searches in your NetSuite account. |
| [ns\_runSavedSearch](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0905091703.html) | Runs an existing saved search from your NetSuite account. |

Only users with the following permissions can see the saved search tools in the AI client.

| Permission ID | Permission Name | Level |
| --- | --- | --- |
| `LIST_FIND` | Perform Search | View |
