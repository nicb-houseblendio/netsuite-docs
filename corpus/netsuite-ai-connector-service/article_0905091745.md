| **Tool Description** | Updates an existing record in NetSuite. Before updating the record, this tool uses [ns\_getRecordTypeMetadata](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0905091603.html) to retrieve information about available fields and their types. If a required reference field is missing, the AI may use the [Record Selector MCP App](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0415010614.html) to display the available values for that field so you can choose one. |
| --- | --- |
| **Annotation** | Update Record |

## Properties {#subsect_93142328243}

| Property | Type | Required or Optional | Description |
| --- | --- | --- | --- |
| `recordType` | string | Required | The NetSuite record type you want to update. |
| `recordId` | string | Required | The internal ID of the record you want to update. |
| `data` | string | Required | The list of record data to update, specified in JSON format as key-value pairs for field names and values. |

## Permissions {#subsect_61142324110}

Only user roles with the following permissions can see this tool in the AI client. However, your ability to update records depends on the permissions assigned to your NetSuite role.

| Permission ID | Permission Name | Level |
| --- | --- | --- |
| `ADMI_RESTWEBSERVICES` | REST Web Services | Full |
