The record tools let you interact with any records that you have access to based on your current permissions. With these tools, you can view and update existing records, and create new ones.

The record tools use REST Web Services to create and update records in NetSuite. These tools support the same record types and actions that are available in REST Web Services and are subject to the same limitations. For example, if a record or field is read-only in REST Web Services, this restriction also applies when using these tools from the AI client.

For information about the working with records using REST Web Services, read the following topics:

-   [Overview of SuiteTalk REST Web Services](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1540391670.html)
    
-   [REST Web Services Supported Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1558962745.html)
    
-   [Working with Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1540811107.html)
    

In addition, the MCP Standard Tools SuiteApp includes a Record Selector MCP App, which provides an interactive UI for selecting existing records when needed for create or update record workflows. For more information, see [Record Selector MCP App](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0415010614.html).

The following record tools are available:

| Name | Description |
| --- | --- |
| [ns\_createRecord](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0905091322.html) | Creates a new record in NetSuite. |
| [ns\_getRecord](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0905091550.html) | Retrieves a record in NetSuite. |
| [ns\_getRecordTypeMetadata](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0905091603.html) | Retrieves metadata for all NetSuite record types or for a specific record type, including available fields and their data types. |
| [ns\_updateRecord](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0905091745.html) | Updates an existing record in NetSuite. |

Only users with the following permissions can see the record tools in the AI client.

| Permission ID | Permission Name | Level |
| --- | --- | --- |
| `ADMI_RESTWEBSERVICES` | REST Web Services | Full |
