Note:

Make sure you assign Enhanced Sales Center roles to Administrators before you perform the following configuration tasks.

## Setting Up Appearance Preferences {#bridgehead_N231633}

You should set up the following appearance preferences for each Enhanced Sales Center role to take advantage of the user interface enhancements.

#### To set up appearance preferences: {#procedure_N231646}

1.  Go to _Home > Set Preferences_.
    
2.  Click the **Appearance** subtab, and then select the following values for the following fields:
    
    | Preference | Setting |
    | --- | --- |
    | Color Theme | Custom: New Sales Color Theme |
    | Screen Font | Arial |
    | Limit Entry Forms to Two Columns | Yes |
    | Expand Tabs on Entry Forms | Yes |
    
3.  Click **Save**.
    

## Duplicating Custom Center Tabs {#bridgehead_N231898}

If you added custom center tabs to your sales center, you can make copies of these tabs to add to the Enhanced Sales Center. For more information, see [Creating Center Tabs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2890512.html).

#### To duplicate a center tab: {#procedure_N231918}

1.  Go to _Customization > Centers and Tabs > Center Tabs_.
    
2.  Click **Edit** next to the name of the custom tab that you want to duplicate. The Custom Center tab form appears.
    
3.  In the **Center** field, change the selection from **Classic Center** to **Enhanced Sales Center**.
    
4.  Under the **Save** button list, select **Save a Copy**.
    

## Recreating Custom Categories {#bridgehead_N231964}

If you created custom categories in the standard Sales Center, you must create them again in the Enhanced Sales Center. You can't edit the custom categories on the standard Sales Center and duplicate them for use in the Enhanced Sales Center.

To create custom categories, go to Setup > Customization > Center Categories > New. Enter the values to the Custom Center Category fields. For information about how to create Custom Categories, see [Creating Center Categories](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2890916.html).

## Adding Custom Center Links {#bridgehead_N231984}

Center link takes users to other NetSuite pages, custom records, Suitelets, or external websites. You can add links that you used in the standard Sales Center categories to the Enhanced Sales Center categories.

#### To add center links: {#procedure_N231996}

1.  Log in to NetSuite using the Enhanced Sales Center - Publisher role.
    
2.  Click the tab you want to add the link to.
    
3.  On the upper-right corner, below the tabs, click **Edit Custom Tab**.
    
4.  Click **Save**.
    
5.  If you receive a prompt to submit an unchanged record, click **OK**.
    
6.  Click **Edit** next to the center category you want to add the link to.
    
7.  Add the links that you previously used in the standard Sales Center.
    
8.  Click **Save**.
    

For more information, see [Creating Center Links](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2891250.html).
