The list of other name records is a collection of records for people or companies who aren't vendors, customers, or employees. This lets you keep records for other people or companies if you write checks to or receive deposits from them.

For example, your company might donate money to a favorite charity, so you create an other name record for the charity. You might also list your owners and partners here if they contribute or withdraw equity.

#### To add to the list of other names: {#procedure_N1096990}

1.  Go to _Lists > Relationships > Other Names > New_.
    
2.  Choose the type of record you're creating by selecting **Company** or **Individual** in the **Type** field.
    
    This selection determines which fields and subtabs are used on this record.
    
3.  To enter the name of this record:
    
    -   If this record's for a company, enter the name of the entity in the **Company Name** field,
        
    -   If this entity is an individual, enter the name of the entity in the name fields. You can also enter the entity's company in the **Company Name** field.
        
    
    The name you enter is used to generate the entity ID in the **Other Name** field. To enter an entity ID manually, clear the **Auto** box and enter the ID.
    
4.  Enter the phone, fax, and email address for this other name company or person.
    
5.  Select the **Other Name** category in the **Category** field.
    
    You can create other name categories at Setup > Accounting > Accounting Lists.
    
6.  Enter the name you want to print on checks made out to this entity.
    
7.  In the **Email Preference** field, select the email format you want to send to this company.
    
8.  Enter the **Tax ID** number.
    
9.  In the **Comments** field, enter any notes about this individual or company.
    
10.  If this is a company record, enter the company's website address in the **URL** field.
     
11.  Select an image to associate with this company.
     
     Click the **+** symbol to upload a new image to your file cabinet.
     
12.  On the **Relationships** subtab, you can create contacts to associate with this record.
     
     To attach existing contacts to this record, you must first save the record. Then you can choose and attach any contact to this record.
     
13.  On the **Communications** subtab, you can attach phone calls, tasks, events, notes, and files. For more information, see [Attaching Events, Tasks, and Calls to Records and Transactions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1084924.html).
     
14.  On the **Address** subtab:
     
     1.  Clear the box in the **Default Shipping** column if this isn't the address packages are usually sent to.
         
     2.  Clear the box in the **Default Billing** column if this isn't the address bills are usually sent to.
         
         Default billing and shipping addresses are selected when you enter a transaction for this record.
         
     3.  In the **Label** column, enter a descriptive name for this location. For example Branch Office, Ohio.
         
         These labels appear on the **Ship Select** field on the **Shipping** subtab of transaction records. They are used to set the shipping address for that transaction.
         
     4.  Click the pencil icon in the **Edit** column to enter address information for this record.
         
     5.  Fill in the address information for this record. In the **Attention** field, enter the name of the person who receives mail at this location.
         
         The complete address is shown in the **Address** field.
         
     6.  Check the box next to **Override** if you want to change the address as it appears in the **Address** field.
         
     7.  Click **OK**. The address appears in the **Address** column.
         
     8.  Click **Add**.
         
     9.  Repeat these steps for each address location for this record.
         
15.  On the **Marketing** subtab:
     
     1.  In the **Global Subscription Status** field, select the status you want to assign this record.
         
         If this entity hasn't subscribed or unsubscribed to campaigns, set this status to **Soft Opt-In** or **Soft Opt-Out**. If this status is set to **Confirmed Opt-Out**, you can't change it.
         
         Note:
         
         Certain jurisdictions have regulations regarding whether you can contact entities if you don't have their explicit permission to do so. For example, the European Union (EU). You should check that your global subscription status adheres to the regulations in the recipient's jurisdiction.
         
         For more information about global subscription statuses, see [Subscription Management](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N994827.html).
         
     2.  If you use the **Subscription Categories** feature, you can see this record's subscription status for each category.
         
16.  On the **Financial** subtab:
     
     1.  Select this entity's currency.
         
     2.  In the **Opening Balance** field, enter the total opening balance of all accounts for this other name.
         
     3.  In the **Opening Balance Date** field, enter or pick the date of the balance in the **Opening Balance** field.
         
     4.  In the **Opening Balance Account** field, select the account for this balance.
         
     5.  In the **Terms** field select the terms for this record.
         
     6.  In the **Account ID** field, enter the name or number for this person or company's account.
         
     7.  In the **Credit Limit** field, enter the credit limit for this account.
         
17.  Click **Save**.
