The Forecast by Item Summary report shows the sales forecast by item for the date range on the report.

The report includes the quantity sold and the calculated forecast amounts for each item. For more information about forecasting, read [Sales Forecasting](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N1045230.html).

Note:

If you use the Advanced Forecasting feature, only estimates with the forecast type set to the medium (Most Likely) are calculated in this report.

Important:

If you customize this report by adding an additional column, make sure you know what type of information the new column will provide. Columns with similar descriptive headings provide different values. For example, the Est. Gross Profit (transaction) column provides results that are different from the Est. Gross Profit (Line) column. The Est. Gross Profit (transaction) column searches lines that satisfy the criteria and then sums the transaction level gross profit for each line. The Est. Gross Profit (Line) column searches lines that satisfy the criteria and then sums the line level gross profit for each line.

## To view the Forecast by Item Summary report: {#bridgehead_N1059874}

Go to _Forecast > Reports > Forecast by Item_.

A popup message appears in the middle of your screen to let you know your report is loading. You can click **Cancel** next to the status bar to stop the report from loading. Reports can take some time to load. If you'd like to work on something else while your report loads, click **Alert me when ready** at the bottom of the message. You'll get an email with a link to the report when it's ready to view.
