When you create a quota, you can choose to base it on one of the Commissionable Item searches.

When you use the Quota feature, you can create a quota that has custom criteria to measure sales transactions for calculating the quota.

Note:

To be able to base a quota on a saved search, you must have the **Employee Commission** feature enabled. See [Commissions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N1122333.html).

#### To create a search-based quota:

1.  Create a Commissionable Item search. For details, read [Setting Up a Sales Territory](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N1042578.html).
    
2.  Create a new quota at _Forecast > Setup > Establish Quotas_.
    
3.  In the **Saved Search** list, select **Custom Commissionable Item Search**.
    

After you save the new quota, NetSuite calculates a quota for the items in the search results.

Note:

If categorized items aren't measured against a quota, make sure the correct search appears on the quota record for the sales rep.
