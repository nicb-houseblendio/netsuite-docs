This report compares the calculated forecast to the actual sales for the period.

The report shows the calculated forecast for each rep alongside the actual sales for the period. The % Var column shows the variances for each forecast amount. This variance is calculated by dividing the forecast by the actual sales amount.

You can select different column options in the Column filter at the footer of the report. If you choose Week, the saved forecast from the Forecast Accuracy (Weekly View) field is compared to the actual sales for the period. An administrator can set this at _Setup > Sales > Preferences > Sales Preferences_.

## To view the Calculated Forecast Accuracy report: {#bridgehead_N1063094}

Go to _Forecast > Reports > Calculated Forecast Accuracy_.

A popup message appears in the middle of your screen to let you know your report is loading. You can click **Cancel** next to the status bar to stop the report from loading. Reports can take some time to load. If you'd like to work on something else while your report loads, click **Alert me when ready** at the bottom of the message. You'll get an email with a link to the report when it's ready to view.

Note:

This report doesn't support reporting by period even when the Report by Period preference is set to All Reports. You can configure the Report by Period preference. Go to _Home > Set Preferences_ > Analytics subtab.
