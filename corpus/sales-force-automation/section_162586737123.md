You should avoid creating multiple records for the same lead if possible. Run a search before you create a new lead record.

#### To search for existing lead records:

1.  Go to _Lists > Relationships > Leads > Search_.
    
    A Customer Search page opens with **Stage** set to **Lead**.
    
2.  (Optional) Check or clear the **Use Advanced Search** box.
    
3.  (Optional) Narrow the search results by adding criteria for a commonly used field, such as **Email**, **Name/ID**, or **State/Province**.
    
    For example, a search with the **Name/ID** field set to **has keyword Green** returns both company or individual lead records. If the company Green Corp. and the individual John Green had existing lead records, both records would appear in the search results.
    
4.  Click **Submit**.
    

For more information about finding records in NetSuite, see [Search Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N635877.html).
