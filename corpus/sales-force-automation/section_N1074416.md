The Estimates Register report shows a record of all estimates created within the specified period. The information is retrieved from a non-posting account, which NetSuite creates when an administrator enables the Estimates feature.

You can use the estimates register to find existing transactions and analyze the sales pipeline. Clicking on a listed estimate will load the relevant Estimate record.

To view the Estimates Register report, go to _Reports > Pipeline Analysis > Estimates Register_

Note:

This report doesn't support reporting by period even when the Report by Period preference is set to All Reports. You can configure the Report by Period preference. Go to _Home > Set Preferences_ > Analytics subtab.
