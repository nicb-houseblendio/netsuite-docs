The Preferences subtab on the customer record has settings for language, number format, shipping, and other preferences for the customer.

#### To enter customer preferences: {#procedure_N1079052}

1.  Click the **Preferences** subtab on the customer record.
    
    Note:
    
    The subtabs that appear on a customer record vary depending on the features you've enabled in your account and your user role permissions.
    
2.  If you use the Multi-Language feature, in the **Language** field, select the primary language of this customer.
    
    Transaction documents for this customer are printed in this language.
    
3.  In the **Number Format** and **Negative Number Format** fields, select the customer's number format preferences if they're different from your other preferences.
    
    The number format controls the thousands separator and decimals display. The negative number format controls whether the negative number is preceded by the minus sign (-) or is enclosed in parentheses ( ). The customer's preferences override other preferences for transaction documents for this customer.
    
4.  In the **Email Preference** field, select the format for forms you email to this customer.
    
    The default option refers to the preference you set on the **Transactions** subtab at _Home > Set Preferences_.
    
5.  In the **Print On Check As** field, enter the name that should be printed on the Pay to the Order of line of any check for the customer.
    
6.  For **Send Transactions Via**, check the appropriate boxes:
    
    -   **Email** - Check this box to check the **To Be Emailed** box by default on this customer's transactions.
        
    -   **Print** - Check this box to check the **To Be Printed** box by default on this customer's transactions.
        
    -   **Fax** - Check this box to check the **To Be Faxed** box by default on this customer's transactions.
        
    
    For more information, see [Preferred Transaction Delivery on Customer and Vendor Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N558109.html).
    
7.  Check the **Ship Complete** box if you want to ship only completely fulfilled orders to this customer.
    
8.  Select the customer's preferred shipping company from the **Shipping Carrier** field.
    
9.  From the **Shipping Method** field, select the default carrier.
    
    Administrators can create new shipping methods at _Lists > Accounting > Shipping Items > New_.
    
    Additional shipping-related fields may appear on this subtab, depending on the Shipping Carrier and Shipping Method you select. Use the field-level help to complete these fields. See [Getting Field-Level Help](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N336742.html). For general information about shipping, see [Shipping](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N1257369.html).
    

For more information about adding customer records, see [Creating a Customer Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161860867711.html).
