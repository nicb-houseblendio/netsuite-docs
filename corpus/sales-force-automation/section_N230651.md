The Enhanced Sales Center includes saved searches. You can use these searches as default search forms and results list views when you search for these record types:

-   Activity
    
-   Contact
    
-   Customer
    
-   Document
    
-   Event
    
-   Group
    
-   Item
    
-   Opportunity
    
-   Phone Call
    
-   Task
    
-   Transaction
    

The standard Sales Center, by default, uses a search form with a system-defined set of fields that you can use as search filters.

![Screenshot of the Opportunity Search page in the standard Sales Center.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/MarketingSalesForceAutomationPartners/SalesForceAutomation/StdSalesCtr_stdoppsearchform.png)

The Enhanced Sales Center saved search forms include only search filters that are commonly used by sales persons when they search for sales records.

![Screenshot of the Opportunity Search page in the Enhanced Sales Center.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/MarketingSalesForceAutomationPartners/SalesForceAutomation/EnhancedSalesCtr_enhancedoppsearchform.png)

Global and quick search results for the previously mentioned records use the saved search list view included in the SuiteApp.

For more information about setting the default search forms and results list view, see [Setting Search Defaults for a Role](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N288948.html).

For general information about views, see [Working with List Views, Sublist Views, and Dashboard Views](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N495842.html).
