Team quotas measure the sales made by the manager and everyone on their team.

For more information about setting up a sales team, read [Setting Up a Sales Team](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1039448.html).

#### To set up a team quota: {#procedure_N1043899}

1.  Go to _Forecast > Setup > Establish Quotas_.
    
2.  Select the year for this quota.
    
3.  In the **Rep** field, select the supervisor of the sales team for this quota.
    
4.  If this quota is for an item, department, class, or location, select the corresponding data.
    
5.  If you use NetSuite OneWorld, select the subsidiary associated with transactions measured by this quota.
    
    If you select a parent subsidiary, this quota measures sales associated with the parent and all of its child subsidiaries. For more information, see [Set up NetSuite OneWorld](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N268052.html).
    
6.  To enter quota amounts, you can do one of the following:
    
    -   Enter a total sales dollar amount for the year, and click **Distribute** to divide this total evenly to each period.
        
    -   In the **Amount** column for the first period, enter the quota you want for each period. Click **Fill Down** for this amount to fill in the **Amount** column for each period. The sum of all period quotas appears in the **Total** field.
        
    -   Enter individual sales quotas for each period below, and the **Total** field fills in automatically.
        
7.  Check the **Team Quota** box.
    
8.  Check the **Alt.Sales** box if this quota measures alternate sales amounts.
    
    For more information, see [Alternate Sales Amounts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1049780.html).
    
9.  Click **Save**.
    

If you use the Commissions feature, you can assign commission schedules based on team quotas to your sales managers. For more information, see [Manager Commission Schedules](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1130290.html).

For more information about quotas and setting up quotas for individual sales reps, see [Quotas](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1043179.html).
