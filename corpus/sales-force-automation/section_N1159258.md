You can run a Commissionable Item search to find commissionable items based on item type. You should use this search with commission schedules and quotas.

The available criteria filters for this search include the following:

-   Amount
    
-   Amount (Alt.Sales)
    
-   Amount (Transaction Total)
    
-   Class
    
-   Class (Main)
    
-   Customer
    
-   Date
    
-   Department
    
-   Department (Main)
    
-   Item
    
-   Lead Source
    
-   Quantity
    
-   Rev. Rec. End Date
    
-   Rev. Rec. Start Date
    
-   Rev. Rec. Term in Months
    
-   Sales Rep
    
-   Status
    
-   Type
    

Some best practices and considerations for setting up a Commissionable Item search are:

-   Keep the search criteria straightforward for better maintenance.
    
-   Use key-based criteria for high performance.
    
-   Name the search to indicate clearly the category and purpose.
    
-   Ensure you receive only the results you need. Pay close attention to the search criteria.
    

#### To create a new Commissionable Item search: {#procedure_N1159437}

1.  Go to _Lists > Search > Saved Searches > New_.
    
2.  Click **New Saved Search**.
    
3.  Click **Commissionable Item**.
    
4.  Enter a name for this search.
    
5.  Enter search criteria.
    
6.  Click **Save**.
    

## Commissionable Item Searches on Commission Schedules {#bridgehead_N1159486}

If you select Custom when you create a commission schedule, you can associate one of the Commissionable Item searches with the schedule. This association provides greater flexibility with your schedule. See [Search-Based Commission Schedules](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1125679.html).

## Commissionable Item Searches and Quotas {#bridgehead_N1159507}

When you create a quota, you can base it on one of the Commissionable Item searches for greater flexibility with your quota. See [Search Based Quotas](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N1043664.html).
