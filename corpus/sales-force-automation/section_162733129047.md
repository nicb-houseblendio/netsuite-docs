When you click the Save & Convert button, NetSuite opens the Convert Lead page. On this page, you can convert the lead to a prospect and create a contact record for the individual. NetSuite automatically associates the contact record with the prospect record.

#### To convert a lead on the Convert Lead page: {#procedure_N1087075}

1.  Open the lead record you want to convert.
    
2.  Ensure that the **First Name**, **Last Name**, and **Company** fields have values.
    
3.  Click the **Save & Convert** button to open the Convert Lead page.
    
    The Convert Lead page looks similar to the lead record.
    
4.  Resolve potential duplicate prospect records or create a new prospect record as follows:
    
    If existing prospect records match the lead you are converting, NetSuite shows a list of the possible matches. If no existing records match, NetSuite creates a new prospect record and you can assign a sales representative.
    
    1.  Click **Compare Duplicates** to see more information about each of the possible duplicates.
        
    2.  Do one of the following:
        
        -   Select the existing record you want to attach this lead to.
            
        -   Select **Create a New Prospect** to create a new prospect record from the lead.
            
            When you create a new prospect, the name is the company name from the lead record, but you can complete the following fields at this point:
            
            -   **Sales Rep** - By default, the prospect is reassigned to sales representatives based on your existing sales territories. However, you can select and assign a sales representative or team to the prospect.
                
            -   **Role** - Select the contact role for the new contact record.
                
5.  Resolve potential duplicate contact records, if any.
    
    If existing contact records match the lead you are converting, NetSuite presents a list of the possible matches. If no existing records match, NetSuite creates a new contact record and you can select the role.
    
    1.  Click **Compare Duplicates** to see more information about each of the possible duplicates.
        
    2.  You can do one of the following:
        
        -   Select an existing record you want to merge with this lead.
            
            If you select this option, you'll need to choose how to merge the data. You can choose one of the following:
            
            -   **Replace all contact info** - Select this option to move fields with data on the lead record into the corresponding fields on the contact record.
                
            -   **Add missing contact info** - Select this option to maintain the data on the existing contact record. However, if there are fields on the contact record that contain no data, data is copied from the lead record.
                
            -   **Do not update** - Select this option to merge the lead with the existing contact, but doesn't add any new data from the lead.
                
        -   If none of the possible duplicates match this lead, select **Create a New Contact** to create a new contact record from the lead.
            
6.  (Optional) After you complete the prospect and contact steps, you can select the following options:
    
    -   **Create Opportunity** - When you check this box, the following fields appear:
        
        -   **Title** - Enter a name for this opportunity. When you submit the page, NetSuite adds a number.
            
        -   **Status** (Required) - **In Discussion** is commonly used as the initial status for an opportunity.
            
        -   **Expected Close** (Required) - Enter the date you think this opportunity will close.
            
        -   **Projected Total** (Required) - Enter an estimated value for the opportunity.
            
        -   **Details** - Enter additional information about the opportunity. For example, you could note the prospect's general requirements.
            
        -   **Contact Role** - If you know the contact's role associated with the prospect during conversion, select the role.
            
    -   **Create Task** - When you check this box, the following fields appear. All these fields are required:
        
        -   **Title** - Enter a title that describes the task.
            
        -   **Priority** - Select the appropriate priority for this task.
            
        -   **Start Date** - Enter or select the start date for this task.
            
        -   **Due Date** - Enter or select the date when this task should be completed.
            
7.  After you complete the prospect, contact, and any optional records, click **Submit**.
    

After you submit the page, the new prospect record opens. The opportunity appears on the Sales subtab in the Opportunities list. The task appears on the Communication subtab in the Activities list.
