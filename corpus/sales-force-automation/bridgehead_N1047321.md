If the estimate is the only estimate associated with an opportunity, NetSuite includes it in the forecast category selected on the estimate. NetSuite also includes the estimate in each higher forecast category.

## Example {#bridgehead_N1047333}

An estimate is created from an opportunity. The estimate total is $100.

| Forecast Type | Worst Case Forecast | Most Likely Forecast | Upside Forecast |
| --- | --- | --- | --- |
| Worst Case | $100 | $100 | $100 |
| Most Likely |  | $100 | $100 |
| Upside |  |  | $100 |

If an estimate is in the worst case category, it appears in each forecast. If it's in the most likely category, it appears in the Most Likely and Upside forecast. Upside estimates only appear in the Upside forecast.
