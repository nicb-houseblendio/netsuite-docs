The Enhanced Sales Center SuiteApp provides user interface enhancements to the standard NetSuite Sales Center. The new Sales Center makes relevant information for sales users available through better organized tabs, forms, links, and dashboards. For more information about the enhancements introduced in the Enhanced Sales Center, see [Sales Center Enhancements](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N137107.html).

If you're new to NetSuite and you want to learn more about the NetSuite user interface and Standard Centers, see [Centers Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N131898.html).
