Note:

This section is about System Notes only. For information about the System Notes v2 dataset, see [System Notes v2 Workbook](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156623525551.html).

You can create a custom dataset with System Note as the root record to analyze system notes, enter formulas, and set criteria filters. For more information about editing datasets, see [Defining a Dataset](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544122173.html).

You can add the following fields to the Data Grid:

-   Context
    
-   Field
    
-   Line ID
    
-   Name
    
-   New Value
    
-   Old Value
    
-   Record
    
-   Record ID
    
-   Record Type
    
-   Role
    
-   Line Transaction ID
    
-   Type
    

To make sure that Line Transaction ID displays an accurate value, create a formula field defined as `{linetransactionid#raw}` to display raw field values. For more information about using formulas in SuiteAnalytics, see [Creating Formula Fields in SuiteAnalytics Workbook](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158798424898.html).

Alternatively, you can use SuiteQL to query Line Transaction ID and Line ID in the system note record. For more information, see [SuiteQL in the N/query Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157960623712.html).
