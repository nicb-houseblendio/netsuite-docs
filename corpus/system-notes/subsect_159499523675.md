System Notes v2 supports the following record types and configuration pages:

-   Authorization Consent
    
-   Custom Transaction Types
    
-   Expense Report Policy
    
-   Imported Employee Expense
    
-   Manage Roles
    
-   Netting Statement
    

For information about viewing System Notes v2, see [Viewing System Notes v2](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_158108595525.html).
