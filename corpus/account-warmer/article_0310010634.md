To install the Account Warmer Portlet, complete the following steps:

#### Install Account Warmer Portlet

1.  From your NetSuite Home page, click **Personalize**.
    
2.  Select the **SuiteApps** tab.
    
3.  Click **Account Warmer**.
    
    Note:
    
    If you have a previous version of the Account Warmer Portlet, remove the existing portlet first to refresh the list, then try steps 1-3 again.
