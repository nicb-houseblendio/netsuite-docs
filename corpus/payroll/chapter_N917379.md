This chapter outlines the steps to enable and implement SuitePeople U.S. Payroll, helping you get started with payroll in NetSuite.

## Implementing the Payroll Feature {#bridgehead_N917539}

To use NetSuite to process your payroll, you must enable and implement SuitePeople U.S. Payroll. Implementing Payroll requires the assistance of a SuitePeople U.S. Payroll Professional Services Consultant. As a part of the setup process, you will submit forms and contracts to your consultant. Contact your NetSuite account manager for details about implementing Payroll.

Important:

Implementing Payroll requires 45-60 business days. You must begin the implementation process at least 60 business days before your first intended check date.

For details on setting up payroll, see [Setting Up Payroll](#section_N917684).

When you finish setting up payroll, you can generate payroll transactions in NetSuite. For more information, see [Payroll Transactions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N945815.html).

NetSuite provides several reports and forms to help you track payroll data. For more information, see [Payroll Reports and Workbooks](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N959965.html).

## Setting Up Payroll {#section_N917684}

Review the following steps to enable and set up the Payroll feature. You may have completed some of these steps when you first set up your NetSuite account, but must enter more information to process payroll.

#### To set up payroll in NetSuite: {#procedure_N917716}

1.  Enable the Payroll feature. For the steps, see [Enabling Payroll](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N917966.html).
    
2.  Enter basic identifying information about your company. For the steps, see [Entering Company Information for Payroll](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N918232.html).
    
3.  Create workplace records for each location where you have a tax ID and maintain paid employees. For the steps, see [Entering Workplace Records for Payroll](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N918520.html).
    
4.  Update your payroll information to commit payroll changes and updates to the payroll tax engine. For more information, see [Updating Payroll Information](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N930407.html)
    
    Note:
    
    You must repeat this step every time you make changes to workplace records, payroll preferences, payroll items, or employee records.
    
5.  Set up your payroll preferences. For the steps, see [Payroll Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N920073.html).
    
6.  Set up 401(k) retirement plans to automatically calculate employee contributions and employer match. For the steps, see [Retirement Plan Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162558111263.html).
    
7.  Create and set up payroll items to pay employees and track payroll liabilities. For more information, see [Payroll Items Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N930985.html).
    
8.  Set up your employees for payroll. For the steps, see [Payroll Setup for Employees](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N921632.html).
    
9.  Verify payroll calculation by running test payroll batches. For the steps, see [Running Test Payroll Batches](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N944846.html).
    
10.  Record year-to-date (YTD) federal and state tax liabilities in NetSuite. For more information, see [Setting up Year-To-Date Information From Your Previous Payroll System](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N944369.html).
     
11.  Enter a start date for your payroll. For the steps, see [Entering a Payroll Start Date](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N945629.html).
