After you set up SuitePeople U.S. Payroll, you must enter a start date for Payroll.

You should complete this task after you turn off test payroll mode. For more information, see [Turning Off Payroll Test Mode](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N945490.html).

When you select a start date for Payroll, you become a full payroll service user. After that date, payroll is processed and funded using SuitePeople U.S. Payroll. and enter the payroll start date.

#### To enter a payroll start date:

1.  Go to _Setup > Payroll > Set Up Payroll_.
    
2.  In the field **When Do You Want the Payroll Service to Begin**, enter the start date.
    
3.  Click **Save**.
    

Note:

On your service start date, you must report any unpaid liabilities.
