Create payroll items for each type of earning, deduction, and contribution you use in your organization. Then, assign payroll items to employees.

#### To create payroll items:

1.  Go to _Lists > Employees > Payroll Items > New_.
    
2.  If you have a NetSuite OneWorld account, from the **Subsidiary** list, select a subsidiary.
    
3.  In the **Item Type** field, select a payroll item type. For more information see [Payroll Item Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_N931377.html).
    
4.  In the **Item Name** field, enter a name for the payroll item.
    
5.  To add a description, which appears on the Summary subtab of employees' paychecks, enter it in the **Description** field.
    
    Descriptions can help employees understand the different items on their paychecks.
    
    Note:
    
    Employees view their paycheck records in the Employee Center. To let employees with Employee Center access see descriptions, go to _Setup > Payroll > Set Up Payroll_. Check the **Show Payroll Item Descriptions on Summary Tab of Paychecks** box.
    
6.  If you see the **Account Category** list, select the type of account to associate with this payroll item.
    
    Note:
    
    This option appears for Earning and Deduction payroll items only if the **Expand Account List for Payroll Items** box is checked. Go to _Setup > Payroll > Set Up Payroll_.
    
7.  From the **Expense Account**, **Liability Account**, or **Asset Account** list, select the general ledger account to associate with the payroll item.
    
    Note:
    
    For employer contribution payroll items, you must select both a liability account and an expense account.
    
8.  If the payroll item is associated with a liability account, from the **Agency** list, select the tax agency to which this deduction is paid. The Agency ID for this tax vendor is pulled automatically from the vendor record. For more info, see [Vendor Records Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2360495.html) and [Associating a Vendor With a Payroll Item](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2367472.html).
    
9.  From the **Pay Code** list, select the appropriate pay code for the payroll item. The pay code controls how the payroll item is taxed, reported, and if it shows up on employees' W-2s. For more information, see [Standard Pay Codes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N935979.html).
    
10.  Depending on the payroll item type, you might also be able to do the following:
     
     -   Set a limit for the payroll item. For more information, see [Setting a Limit for a Payroll Item](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1556732383.html).
         
     -   Derive the rate for the payroll item from a payroll item, item group, or retirement plan. For more information, see [Payroll Item Derivation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4387116642.html).
         
     -   Apply a default pay rate to the payroll item. For more information, see [Applying a Default Rate to a Payroll Item](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1556733170.html).
         
11.  To specify where this payroll item amount should appear in payroll reports, from the **Report Section** list, select a report.
     
12.  Click **Save**.
     

After you create a payroll item, update payroll information. For more information, see [Updating Payroll Information](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N930407.html).
