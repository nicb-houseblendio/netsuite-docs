If you use NetSuite OneWorld, you can specify the subsidiary or root-parent company where you'll run payroll. After you select a subsidiary, the other preferences you set on the Set Up Payroll page apply only to that subsidiary.

Each subsidiary must have:

-   Unique Employer Identification Number (EIN) from the U.S. Internal Revenue Service (IRS)
    
-   Unique Vendor Name for each tax agency. For example, if you have two subsidiaries in California, you'll need two uniquely named Vendors for the IRS and two for the California Franchise Tax Board.
    

For more information about subsidiaries and OneWorld, see [NetSuite OneWorld](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/preface_1540397395.html)

#### To select a subsidiary for payroll:

1.  Go to _Setup > Payroll > Setup Tasks > Set Up Payroll_.
    
2.  From the **Subsidiary** list, select a subsidiary. This list only shows US subsidiaries.
