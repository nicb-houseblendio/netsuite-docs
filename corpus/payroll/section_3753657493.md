You can create a one-time payroll based on any payroll items defined in your system. For more information about creating payroll items, see [Payroll Items Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N930985.html).

#### To create an off-cycle payroll batch:

1.  Go to _Transactions > Employees > Create Payroll_.
    
2.  On the Payroll Batch page, do the following:
    
    1.  If you have a NetSuite OneWorld account, select a subsidiary from the **Subsidiary** list.
        
    2.  Check the **Off Cycle** box.
        
    3.  In the **Pay Frequency** list, select the pay frequency for the employees who are receiving the one-time payroll.
        
    4.  In the **Period Ending** field, enter the date that the pay period ends in the format MM/DD/YYYY.
        
    5.  Click **Create**.
        
    
    For more information, see [Creating a Payroll Batch](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N947366.html).
    
3.  In the popup window that appears, check the boxes beside the employees to include in the one-time payroll, and then click **Save**.
    
4.  Click **Bulk Edit**.
    
    Note:
    
    If you are including only one employee in the one-time payroll, you can edit the employee on the Payroll Batch page, without clicking Bulk Edit.
    
    1.  From the **Payroll Item** list, select the payroll item that you want to use for this one-time payroll.
        
    2.  In the **Employee ID** column, select an employee.
        
    3.  Enter a rate or an amount to pay the employee:
        
        -   If the one-time payroll is based on hours worked, enter the number of hours in the **Hours/Base** column. Then, then enter a pay rate in the **Rate** column.
            
        -   If the one-time payroll is an amount, enter the total amount in the **Amount** column.
            
    4.  Click **Add**.
        
    5.  Repeat steps b-d for additional employees.
        
    6.  Click **Save**.
        
5.  On the Payroll Batch page, in the **Check Date** field, change the check date to the date that the employees will be paid.
    
6.  (Optional) You can select a custom list of payroll items to include in an off-cycle payroll batch. To include specific payroll items in an off-cycle batch:
    
    1.  Check the **Include Specific Payroll Items** box.
        
    2.  Click **Select Items**.
        
    3.  Under the **Select Items** column, check the boxes beside each payroll item you want to include.
        
    4.  Click the ![Right Arrow](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/EmployeeManagement/Payroll/RightArrowSelectItems.png) button to move the selected items to the **Items Included** column.
        
    5.  Click **Save**.
        
    
    Note:
    
    Payroll items added through bulk edit, paycheck edit, and paycheck import are processed in the batch, even if you do not include them. If you include specific items in the batch, only payroll items assigned to employees on their employee records will be processed.
    
7.  Verify and make changes to individual paychecks as necessary, making sure that the one-time payroll item is included in each paycheck.
    
    For more information, see [Viewing Payroll Batches](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N948008.html) and [Editing an Individual Paycheck from a Payroll Batch](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4791610184.html).
    
8.  After you review your payroll, click **Calculate**.
    
9.  After you review your payroll calculations, click **Commit**. For more information, see [Committing a Payroll Batch](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4791611139.html).
    
    If you need to make changes to a payroll batch after it is committed, you must enter an adjustment or a reversal. For more information, see [Creating Payroll Adjustments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N952992.html) and [Creating a Payroll Reversal](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N951968.html).
    
    Note:
    
    Only those user roles that include **Process Payroll** with the **Full** option can commit a payroll. These user roles include Payroll Manager: Full, and Payroll Setup: Full. For more information, see [NetSuite Roles Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N285436.html), [Showing Role Permission Differences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N292157.html), and [Standard Roles Permissions Table](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N295396.html).
    
    To print checks, go to _Transactions > Management > Print Checks and Forms_, and click **Paychecks**. For more information, see [Printing Paychecks](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N950744.html) and [Printing Checks and Other Transactions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N566722.html).
