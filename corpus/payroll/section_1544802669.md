The Payroll Dashboard SuiteApp provides home page portlets that help you to perform regular payroll tasks and manage employees who are included in payroll. These tasks include the ability to run payroll batches, track changes in employee pay, and quickly find other payroll-related features. The portlets can be added by an Administrator or a Payroll Manager.

For more information about dashboards and portlets, see [Dashboards](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4320707520.html).

## Installing the Payroll Dashboard SuiteApp {#subsect_1556636797}

For information about installing SuiteApps, see [Installing a Bundle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3395142.html). You can search for the Payroll Dashboard SuiteApp using the following information:

-   Bundle Name: **Payroll Dashboard**
    
-   Bundle ID: 202156
    

The Payroll Dashboard SuiteApp is a managed bundle and is automatically updated whenever fixes and enhancements are available.

## Adding a Custom Role {#subsect_17114751245}

In the payroll dashboard, custom roles can be created for accessing the SuiteApp. An administrator can perform the following steps to add the custom role for payroll dashboard.

#### To add a custom role: {#procedure_0531042214}

1.  Go to Customization > Lists, Records, & Fields > Record Types > Payroll Dashboard Permission > List.
    
2.  Edit the existing Payroll Dashboard Permission record.
    
3.  Select the role from the Roles field. The Administrator and Payroll Manager roles should always be selected together with the custom role.
    

## Setting Up the Payroll Dashboard {#subsect_1544803111}

Personalize your dashboard by adding payroll portlets such as Employee Net Pay Variances, Payroll Links, and Run Payroll portlet.

#### To add a payroll portlet:

1.  Click **Personalize** in the upper right corner of your dashboard or use **Personalize Dashboard** in the **Settings** portlet.
    
2.  On the **SuiteApps** tab of the Personalize Dashboard palette, click the portlet you want to add or drag it onto the dashboard.
    

### Payroll Dashboard Portlets {#subsect_1544803489}

You can rearrange the dashboard portlets in the order of your choice. The portlets that are part of the Payroll Dashboard include:

-   [Run Payroll](#subsect_1544813188)
    
-   [Payroll Links](#subsect_1544815161)
    
-   [Employee Net Pay Variances](#subsect_1544816982)
    

The portlets offer at-a-glance metrics and action items, letting you manage employee information right from the dashboard.

#### Run Payroll {#subsect_1544813188}

This portlet enables you to view your payroll batches that are in progress or initiate a new one. To see the batches in progress, you can filter the batch list by pay frequency, or by subsidiary if you have a OneWorld account. Each batch has a batch number and a status, of which can be **Edited** or **Error**. Payroll batches in **Edited** status can be calculated from the portlet. Each batch includes information such as subsidiary, pay frequency, check date, period ending, funding account, batch summary, off cycle, and number of employees.

Click **View** on a payroll batch to see all components with more detail. You can see more information for each employee in the batch, and you can also filter the employees by name, class, and department. At the top of the page, you can calculate or edit the batch.

#### Payroll Links {#subsect_1544815161}

This portlet offers a collection of quick links that take you to other Payroll features. The portlet includes the following default categories:

-   Payroll Setup and Reporting
    
-   Time and Expense
    
-   Employee Management
    
-   Payroll Processing
    
-   SuiteAnswers
    

Clicking on each link under the categories opens a new tab for your convenience.

The portlet also lets you add and remove categories and links or restore the default layout by clicking **Categories and Links** under the Configure section.

Note:

Payroll Dashboard can only support a maximum of five (5) categories.

#### Employee Net Pay Variances {#subsect_1544816982}

The Employee Net Pay Variances portlet shares similar capabilities as the Run Payroll portlet.

With this portlet, you can quickly track any changes in your employee payment. The pay changes are tracked in a table that displays the name of the employee, employee ID, and pay frequency. It also displays the last pay date, previous amount, current amount, and the variance between the previous amount and current amount.
