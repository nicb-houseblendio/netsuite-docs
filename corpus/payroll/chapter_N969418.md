The Paycheck Journal feature supports different payroll capabilities, including the tracking of payroll data for employees in countries other than the U.S.

The Paycheck Journal feature is intended for use by NetSuite partners. It enables partners to:

-   Use SOAP web services to build integrations between NetSuite and existing external payroll solutions. For more information, see [SOAP Web Services and Paycheck Journal Transactions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N972028.html).
    
-   Use SuiteScript to build custom payroll solutions. For more information, see [SuiteScript and the Paycheck Journal Feature](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N972189.html).
    
-   Customize payroll forms and fields. For more information, see [Custom Payroll Forms and Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N972394.html).
    

After partners create payroll scripts, custom forms, and custom fields, they can use SuiteApp Development Framework to package these custom objects into SuiteApps that can be installed in NetSuite customer accounts. For more information, see [SuiteCloud Development Framework](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4702622163.html).

Important:

The Paycheck Journal feature is not intended for direct use by NetSuite customers without a partner payroll solution.

The Paycheck Journal feature is independent from SuitePeople US Payroll, although both features can be enabled in a single account. For example, in a OneWorld account, SuitePeople US Payroll can process payroll for a U.S. subsidiary, and the Paycheck Journal feature can track international payroll transactions for non-U.S. subsidiaries.

To get started with the Paycheck Journal feature, see [Getting Started with Payroll Solutions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N969660.html).
