The paycheck journal transaction is exposed in SOAP web services so that it can act as a payroll interface for integrations with external payroll systems. The payroll item record is also exposed to support these integrations. Both of these record types support basic create, read, update, delete, and search operations.

For more information, including usage notes and sample SOAP requests and Java code, see the SOAP web services reference topics [Paycheck Journal](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3687114.html) and [Payroll Item](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3751811.html).
