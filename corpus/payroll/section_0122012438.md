The Payroll Compliance SuiteApp provides customizations that support the [SuitePeople U.S. Payroll](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1495573671.html#subsect_1109073238) feature.

The SuiteApp provisions payroll fields that are used by SuitePeople U.S. Payroll Compliance for the following features:

-   Adding geographic codes for Alaska workplaces. For more information, see [Entering Workplace Records for Payroll](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N918520.html).
    
-   Updating standard Occupational Classification (SOC) codes for employees. For more information, see [Adding Standard Occupational Classification Codes for Employees](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1506349052.html).
    
-   Reclassifying employees for paid family leave (PFML) Contribution. For more information, see [Paid Family and Medical Leave Contributions for Employees](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0113124114.html).
    

Before you can use this SuiteApp, you must have the [SuitePeople U.S. Payroll](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1495573671.html#subsect_1109073238) feature enabled in your account. For more information, see [Payroll Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N295396.html#subsect_0425062306).

To continue, see [Prerequisites for Installing the Payroll Compliance SuiteApp](#subsect_0122014037).

## Prerequisites for Installing the Payroll Compliance SuiteApp {#subsect_0122014037}

Important:

Before you can use this SuiteApp, you must have the [SuitePeople U.S. Payroll](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1495573671.html#subsect_1109073238) feature enabled in your account. For more information, see [Payroll Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N295396.html#subsect_0425062306).

Before installing Payroll Compliance, you must use an Administrator role to enable additional features.

#### To enable features:

1.  1.  Go to Setup > Company > Setup Tasks > Enable Features.
        
    2.  Click the **SuiteCloud** subtab.
        
    3.  Check the box for each of the following features:
        
        -   Custom Records
            
        -   Client SuiteScript
            
        -   Server SuiteScript
            
        -   SOAP Web Services
            
        -   Token-Based Authentication
            
        -   SuiteCloud Development Framework
            
        -   OAuth 2.0
            
    4.  Click **Save**.
        

For more information about how to enable features, see [Enabling Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N232138.html).
