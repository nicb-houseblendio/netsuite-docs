Before you install the SuiteApp, make sure you've completed all prerequisite steps. For more information, see [Prerequisites for Installing the Payroll Compliance SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0122012438.html#subsect_0122014037).

To install the SuiteApp, you need an Administrator role.

#### To install the Payroll Compliance SuiteApp

1.  Go to Customization > SuiteBundler > Search & Install Bundles.
    
2.  In the **Keywords** field, enter **Payroll Compliance** or the Bundle ID **202280**.
    
3.  Click **Search**. Then click the SuiteApp link.
    
4.  On the Bundle Details page, click **Install**.
    

The Payroll Compliance SuiteApp is a managed bundle. It's automatically updated when new features or improvements are added. For more information, see [Installing a Bundle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3395142.html).
