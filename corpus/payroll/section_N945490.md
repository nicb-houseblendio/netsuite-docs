After you finish running test payrolls and verifying your data, you can complete your setup by turning off test mode in your account.

After test mode is turned off, you can start paying employees with SuitePeople U.S. Payroll.

#### To turn off Test Mode: {#procedure_N945512}

1.  Go to _Setup > Payroll > Set Up Payroll_.
    
2.  Clear the **Run Payroll in Test Mode** box.
    
    If this box is not available, it is because of the following:
    
    -   You have not set up YTD information.
        
    -   You have no YTD information to report.
        
    -   You have not run at least one test payroll.
        
3.  Click **Save**.
