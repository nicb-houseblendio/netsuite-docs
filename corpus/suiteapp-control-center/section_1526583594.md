You can edit the definition of a SuiteApp to view its properties and change its name.

#### To edit a SuiteApp definition:

1.  Go to Control Center > My SuiteApps > My SuiteApps.
    
2.  Do one of the following:
    
    -   For a SuiteApp, click ![the three-dot menu](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/SuiteAppControlCenter/SCCEllipsisButton.png) and select **Edit Definition**.
        
    -   Click the SuiteApp name to view the SuiteApp details.
        
    
    The **Definition** tab appears.
    
3.  To modify the SuiteApp name, change the value for **SuiteApp Name** and click **Update**.
    
    You can't change the Project ID, Publisher ID, or Upgrades. For more information, see [Creating a SuiteApp Definition](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1526316405.html).
    
4.  When you're done making changes, click **Done**.
