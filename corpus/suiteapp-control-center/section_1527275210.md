Managed SuiteApps are upgraded in accounts by a Push operation performed on the SuiteApp version. Pushing the SuiteApp installs that SuiteApp version to accounts and replaces the previously existing version.

You can push a SuiteApp version upgrade to accounts in a couple of ways:

-   [Pushing Upgrades From the Version History](#subsect_1542122666)
    
-   [Pushing Upgrades From the Upgrades Tab](#subsect_1542122698)
    

## Pushing Upgrades From the Version History {#subsect_1542122666}

You can push upgrades to users from the version history of a managed SuiteApp.

#### To push upgrades from the version history:

1.  Go to Control Center > My SuiteApps > My SuiteApps. The My SuiteApps page appears.
    
2.  Do one of the following:
    
    -   For a SuiteApp, click ![SCC ellipsis button](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/SuiteAppControlCenter/SCCEllipsisButton.png) and select **Manage Versions**.
        
    -   Click the SuiteApp name to view the SuiteApp details, then click the **Versions** tab.
        
3.  In the **Version** column, find the SuiteApp version you want to push, and click **Upgrade Install Base**. The New Upgrade page appears.
    
    Note:
    
    The **Upgrade Install Base** action is only available for managed SuiteApps. For more information, see [Developing Managed SuiteApps](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1526582924.html).
    
4.  To change the version you want to push, pick one from the **SuiteApp Version** list. All released versions for the SuiteApp are available. Then, select the accounts you want to upgrade.
    
    Before you pick accounts to upgrade, keep this things in mind:
    
    -   To add a note about the upgrade, type it in the Memo field. Memos can be helpful when you're looking at upgrades on the Upgrades tab.
        
    -   To filter the list of accounts available to upgrade, use this options:
        
        -   **Company** - filter by company ID or company name.
            
        -   **Status** - filter by installation status.
            
        -   **SuiteApp Version** - filter by the SuiteApp version.
            
        -   **NetSuite Version** - filter by the NetSuite version.
            
5.  Select the accounts that are to receive the SuiteApp installation.
    
    To push the SuiteApp version to the selected accounts, click **Push to Selected**.
    
    Pushing the SuiteApp version replaces the version those accounts currently have installed. To confirm, click **Push** on the Confirm Action popup window.
    
    The push starts for the selected accounts, and the SuiteApp installation status updates when the process begins. For information about the installation status, see [Viewing SDF SuiteApp Installation Status](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1527799570.html).
    
6.  (Optional) Click **Done** to close the SuiteApp details and go back to the My SuiteApps page.
    

## Pushing Upgrades From the Upgrades Tab {#subsect_1542122698}

You can push new upgrades from the same place where you manage all upgrades.

Note:

The **Upgrades** tab is only available for managed SuiteApps. For more information, see [Developing Managed SuiteApps](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1526582924.html).

#### To push upgrades from the Upgrades tab:

1.  Go to Control Center > My SuiteApps > My SuiteApps. The My SuiteApps page appears.
    
2.  Do one of the following:
    
    -   For a SuiteApp, click ![SCC ellipsis button](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/SuiteAppControlCenter/SCCEllipsisButton.png) and select **Manage Upgrades**.
        
    -   Click the SuiteApp name to view the SuiteApp details, then click the **Upgrades** tab.
        
3.  Click **Create New**. The New Upgrade page appears.
    
4.  To change the version you want to push, pick one from the **SuiteApp Version** list field selection. All released versions for the SuiteApp are available. Then, select the accounts you want to upgrade.
    
    Before you pick accounts to upgrade, keep these things in mind:
    
    -   To add a note about the upgrade, type it in the Memo field. Memos can be helpful when you're looking at upgrades on the Upgrades tab.
        
    -   To filter the list of accounts to upgrade, use this options:
        
        -   **Company** - filter by company ID or company name.
            
        -   **Status** - filter by installation status.
            
        -   **SuiteApp Version** - filter by SuiteApp version.
            
        -   **NetSuite Version** - filter by the NetSuite version.
            
5.  Select the accounts that are to receive the SuiteApp installation.
    
    To push the SuiteApp version to the selected accounts, click **Push to Selected**.
    
    Pushing the SuiteApp version replaces the version those accounts currently have installed. To confirm, click **Push** on the Confirm Action popup window.
    
    The push starts for the selected accounts, and the SuiteApp installation status updates when the process begins. For information about the installation status, see [Viewing SDF SuiteApp Installation Status](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1527799570.html).
    
6.  (Optional) Click **Done** to close the SuiteApp details and go back to the My SuiteApps page.
