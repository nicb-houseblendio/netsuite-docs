The SuiteApp definition lets you set properties and control the availability of your SuiteApp for users. SuiteApps are created with the SuiteCloud Development Framework (SDF) and then defined in SuiteApp Control Center for distribution.

See the following topics:

-   To define SuiteApp properties, see [Creating a SuiteApp Definition](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1526316405.html).
    
-   To edit existing SuiteApp properties, see [Editing a SuiteApp Definition](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1526583594.html).
    
-   To view the SuiteApp publishing requirements, see [Requirements for SuiteApp Marketplace Availability](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1559316827.html).
    
-   To specify which company accounts can access the SuiteApp, see [Setting SuiteApp Marketplace Access](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1526316461.html).
