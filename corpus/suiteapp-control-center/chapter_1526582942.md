SuiteApp Control Center is a single place to define and manage your SuiteApp distribution process. You can upload SuiteApp projects to SuiteApp Control Center and distribute them as SuiteApp versions to the SuiteApp Marketplace. Your users can install SuiteApps from the SuiteApp Marketplace and either perform manual upgrades for unmanaged SuiteApps or get upgrades automatically for managed SuiteApps.

Here's an overview of how to use SuiteApp Control Center:

<a id="svg_1"></a>

                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   

1.  **SuiteApp Definition** - You define SuiteApps in SuiteApp Control Center. For information, see [Creating a SuiteApp Definition](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1526316405.html). To view all SuiteApps, see [Viewing All SDF SuiteApps](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1526316436.html).
    
    You can also set SuiteApp Marketplace access for each SuiteApp. For information, see [Setting SuiteApp Marketplace Access](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1526316461.html).
    
2.  **SuiteApp Project** - SuiteApp Control Center distributes SuiteApps based on SuiteApp projects. The projects contain NetSuite customizations and can be validated in SDF prior to distribution. For information about creating a project, see [Creating a SuiteApp Project in SuiteCloud IDE Plug-in for WebStorm](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530903307.html).
    
3.  **SuiteApp Versions** - SuiteApps are distributed as specific versions, each containing the corresponding version of the SuiteApp project. For more information, see [SuiteApp Versions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1526582725.html).
    
    Actions you can perform include:
    
    -   Create new versions of the SuiteApp to plan for distribution. For information, see [Creating a SuiteApp Version](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1526583775.html).
        
    -   Delete versions that are not needed and have not been released. For information, see [Deleting a SuiteApp Version](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1526583916.html).
        
    -   Release versions to distribute upgrades to the SuiteApp Marketplace. For information, see [Releasing a SuiteApp Version](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1526583869.html).
        
    -   Push upgrades to your managed SuiteApp install base. For information, see [Pushing a SuiteApp Version Upgrade to Users](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1527275210.html).
        
    -   Deprecate versions that are no longer supported. For information, see [Deprecating a SuiteApp Version](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1526583975.html).
        
4.  **Terms of Service** - Define terms of service (ToS) for your SuiteApp. For more information, see [Terms of Service](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_6141238491.html).
    
5.  **SuiteApp Marketplace** - Users install SuiteApps from the SuiteApp Marketplace. For information, see [Installing SDF SuiteApps](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1525982323.html).
    
6.  **Install Base** - Manage the SuiteApp install base in SuiteApp Control Center. For information, see [Viewing the SDF SuiteApp Install Base](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1527799607.html).
    
    You can also view the installation status of SuiteApps. For information, see [Viewing SDF SuiteApp Installation Status](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1527799570.html).
    

For more information about getting started with SuiteApp Control Center, see the following topics:
