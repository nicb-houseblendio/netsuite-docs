The version history provides a single location to view and manage your SuiteApps.

Note:

Deleted versions don't show up in the SuiteApp version history. For more information, see [Deleting a SuiteApp Version](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1526583916.html).

#### To view the SuiteApp version history:

1.  Go to Control Center > My SuiteApps > My SuiteApps.
    
2.  Do one of the following:
    
    -   For a SuiteApp, click ![SCC ellipsis button](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/SuiteAppControlCenter/SCCEllipsisButton.png) and select **Manage Versions**.
        
    -   Click the SuiteApp name to view the SuiteApp details, then click the **Versions** tab.
        
    
    The Version History list appears and shows the following information:
    
    -   **Version** - is the version number, which is populated by the projectversion field value in the manifest of the SuiteApp project contained in the SuiteApp archive ZIP. For more information, see [Creating a SuiteApp Version](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1526583775.html) and [Managing SuiteCloud Projects as Compressed Files in SuiteCloud IDE Plug-in for WebStorm](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159709033768.html).
        
    -   **Status** - is the current state of the version. For version states and their descriptions, see [SuiteApp Version States](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1526582725.html#section_1526583759).
        
    -   **Phase** - shows the version phase, which can be Leading or Lagging. For information about those phases, see [SuiteApp Version Phases](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1526582725.html#subsect_1537984829).
        
    -   **Minimal Required NetSuite Version** - is the minimum NetSuite version required for the install base to install this version of the SuiteApp.
        
    -   **Release Date** - is the date and time when the version was released, displayed in your current time zone.
        
    -   **Installation Count** - is the number of accounts that have a SuiteApp version installed.
        
        Note:
        
        SuiteApp installations that failed validation aren't included in the total SuiteApp version installation count when the following scenarios occur:
        
        -   A SuiteApp installation failed validation during an install attempt when a user didn't have a SuiteApp version installed yet.
            
        -   A SuiteApp installation failed validation when a user tried to upgrade an existing SuiteApp. In this case, the installation count still includes the failed upgrade attempt in the previous SuiteApp version's count.
            
        
    -   **Action** - lists actions you can take on the version. See [SuiteApp Version Actions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1526582725.html#subsect_1527430721).
        
3.  (Optional) Click **Done** to close the SuiteApp details and go back to the My SuiteApps page.
