Users can install SuiteApps from their accounts by going to the SuiteApp Marketplace. For information, see [SuiteApp Marketplace in NetSuite](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1539797981.html), [SuiteApp Installation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1540236668.html) and [Requirements for SuiteApp Marketplace Availability](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1559316827.html).

The latest version of the SuiteApp that works with the user's NetSuite version shows up on the SuiteApp Marketplace. If the account's NetSuite version doesn't meet the minimum required version for the SuiteApp (leading or lagging), the latest SuiteApp version still appears but is labeled 'Not compatible.'

You can also use SuiteScript to get information about installed bundles and SuiteApps. For more information, see [N/suiteAppInfo Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160236086332.html).

Note:

The administrator account shown in the Installed By column on the Installed SuiteApps page depends on the following:

-   When you install a SuiteApp from the SuiteApp Marketplace, the Installed By column on the Installed SuiteApps page shows the administrator account that triggered the installation.
    
-   When you upgrade an unmanaged SuiteApp from the SuiteApp Marketplace, the Installed By column on the Installed SuiteApps page shows the administrator account that triggered the upgrade.
    
-   When a SuiteApp release manager upgrades a managed SuiteApp from the SuiteApp Control Center, the Installed By column on the Installed SuiteApps page shows the first active administrator on a target account. The administrator account can change with each managed upgrade.
    

Note:

Installing from the SuiteApp Marketplace works the same for Sandbox and Release Preview accounts as for the parent account. For example, if you can install a SuiteApp from sCompId "12345", you can also install it from "12345\_SB" and "12345\_RP".
