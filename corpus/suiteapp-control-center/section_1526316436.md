You can view a list of all of the SDF SuiteApps created by your account. SuiteApps can't be deleted from the list. If you don't want a SuiteApp to be available on the SuiteApp Marketplace, you can deprecate it. For information, see [Deprecating a SuiteApp Version](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1526583975.html).

#### To view a list of all SDF SuiteApps in your account:

1.  Log in to NetSuite using the SuiteApp Release Manager role. If you're already logged in with a different role, switch to the SuiteApp Release Manager role. For information, see [Roles and Accounts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N295370.html).
    
2.  Go to Control Center > My SuiteApps > My SuiteApps.
    
    To find a SuiteApp in the list, enter the name in the **Search For a SuiteApp By Name** field.
    
    The following information is available for each SuiteApp:
    
    -   **SuiteApp Name** - is the name of the SuiteApp specified in the SuiteApp definition. For information, see [Editing a SuiteApp Definition](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1526583594.html).
        
    -   **Application ID** - is an ID for the SuiteApp that is based on the publisher ID and project ID. SuiteApps created with SuiteCloud Development Framework (SDF) are always represented by an application ID (app ID). For more information about app ID notation, see [Properties of a SuiteApp Project](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1509931104.html#subsect_1520876235).
        
    -   **SuiteApp Type** - displays the type of SuiteApp: Commercial or Implementation. [SuiteCloud Developer Network](https://www.netsuite.com/portal/developers/overview.shtml).
        
    -   **Access** - is the SuiteApp Marketplace availability setting for the SuiteApp. For information, see [Setting SuiteApp Marketplace Access](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1526316461.html).
        
    -   **Status** - displays the current status of the SuiteApp. Possible statuses are:
        
        -   **Released** - the SuiteApp is currently available on the SuiteApp Marketplace for users to install.
            
        -   **Deprecated** - the SuiteApp is not available on the SuiteApp Marketplace.
            
            Note:
            
            For a SuiteApp to be available to users on the SuiteApp Marketplace, it must meet the SuiteApp publishing requirements. For information, see [Requirements for SuiteApp Marketplace Availability](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1559316827.html).
            
    -   **Leading Version** - displays the currently released leading version of the SuiteApp. For more information, see [SuiteApp Version Phases](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1526582725.html#subsect_1537984829).
        
    -   **Lagging Version** - displays the currently released lagging version of the SuiteApp.
        
    
    For each SuiteApp, you can do the following actions from the ![Three-dot](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/SuiteAppControlCenter/SCCEllipsisButton.png) menu button:
    
    -   **Edit Definition** - for information, see [Editing a SuiteApp Definition](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1526583594.html).
        
    -   **Manage Access** - for information, see [Setting SuiteApp Marketplace Access](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1526316461.html).
        
    -   **Manage Versions** - for information, see [SuiteApp Versions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1526582725.html).
        
    -   **Manage Install Base** - for information, see [Viewing the SDF SuiteApp Install Base](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1527799607.html).
        
    -   **Manage Terms of Service** - for information, see [Terms of Service](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_6141238491.html).
        
    -   **Manage Upgrades** - for information, see [Viewing SDF SuiteApp Upgrades](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1542121822.html).
        
        Note:
        
        The **Manage Upgrades** action is only available for managed SuiteApps. For more information, see [Developing Managed SuiteApps](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1526582924.html).
        
    
    To create a new SuiteApp, click **Create New**. For information, see [Creating a SuiteApp Definition](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1526316405.html).
