You can view the SuiteApp status from the **Install Base** tab in the SuiteApp details. For information about viewing the install base, see [Viewing the SDF SuiteApp Install Base](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1527799607.html).

The SuiteApp status shows the current state of the SuiteApp workflow after you start an install, upgrade, or uninstall.

To view all the state transitions in SuiteApp workflow, see [SuiteApp Workflow](#subsect_1531405874).

For definitions of each state in the workflow, see [SuiteApp States](#subsect_1531405711).

The following topics cover the installation, upgrade, and uninstall process:

-   To install a SuiteApp, see [Installing SDF SuiteApps](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1525982323.html).
    
-   To upgrade a SuiteApp, see [Pushing a SuiteApp Version Upgrade to Users](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1527275210.html).
    
-   To view the upgrade status, see [Viewing SDF SuiteApp Upgrades](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1542121822.html).
    
-   To uninstall a SuiteApp, see [Viewing and Uninstalling SuiteApps from a NetSuite Account](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530795257.html).
    
-   To view the version history, see [Viewing the SuiteApp Version History](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1526584029.html).

## SuiteApp States {#subsect_1531405711}

The table below describes the possible states for a SuiteApp during the installation, upgrade, or uninstallation process:

| Status | Description |
| --- | --- |
| Initialization Failed | Shows an error occurred, preventing one of the following:
-   A SuiteApp installation or upgrade was requested, but the initialization failed before the validation step. For more information, see [Addressing SuiteApp Installation Failures](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1527799595.html).
-   A SuiteApp uninstall was requested, but the initialization failed before starting the uninstall. For information about the failure, consult the Deployment Audit Trail page. Documentation for that page is available in the [Deployment Logs for SuiteCloud Projects](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4715369474.html).

 |
| Installation Failed | The SuiteApp failed to install. Check the installation log for more information. For information about the log, see [Addressing SuiteApp Installation Failures](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1527799595.html). |
| Installed | The SuiteApp was installed successfully in the account. From here, you can request to upgrade or uninstall the SuiteApp. |
| Installing | The SuiteApp installation is in progress. If the SuiteApp successfully installs, it moves to the Installed state. If the SuiteApp fails to install, it moves to the Installation Failed state. |
| Pending | A request to install or upgrade the SuiteApp has started, but the installation hasn't begun yet. If the process is successfully initialized, the SuiteApp moves to the Validating state. If it fails, the SuiteApp moves to the Initialization Failed state. |
| Pending Uninstall | A request to uninstall the SuiteApp has started, but the uninstallation hasn't begun yet. If the process is successfully initialized, the SuiteApp moves to the Uninstalling state. If the initialization process fails, the SuiteApp moves to the Initialization Failed state. |
| Uninstalling | The SuiteApp uninstallation is in progress. If the SuiteApp successfully uninstalls, it's removed from the Installed SuiteApps list. If the SuiteApp fails to uninstall, it moves to the Uninstall Failed state. |
| Uninstall Failed | The SuiteApp failed to uninstall. Check the Deployment Audit Trail page for more information. For information about the page, see [Deployment Logs for SuiteCloud Projects](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4715369474.html). |
| Validating | The SuiteApp install or upgrade process was initialized successfully and the SuiteApp contents are being validated. If the SuiteApp passes validation, it moves to the Installing state. If the SuiteApp fails validation, it moves to the Validation Failed state. |
| Validation Failed | The SuiteApp failed validation and didn't install. The target account is unchanged. Check the installation log for more information. For information about the log, see [Addressing SuiteApp Installation Failures](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1527799595.html). |
| Failed | Shows an error has occurred. To view the error, click the tooltip icon (![Tooltip icon.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/SuiteAppControlCenter/SCCSuiteAppApprovalWidgetUITooltipIcon.png)). |
| Request Access | This SuiteApp isn't shared with your account. Please contact the SuiteApp publisher for more info. |
| Not Compatible | The NetSuite version for your account doesn't meet the minimal required version for the SuiteApp version. |
