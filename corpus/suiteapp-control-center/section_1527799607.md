You can see all company accounts that have installed a SuiteApp from one central spot in the SuiteApp details.

#### To view the SuiteApp install base:

1.  Go to Control Center > My SuiteApps > My SuiteApps. The My SuiteApps page appears.
    
2.  Do one of the following:
    
    -   For a SuiteApp, click ![SCC ellipsis button](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/SuiteAppControlCenter/SCCEllipsisButton.png) and select **Manage Install Base**.
        
    -   Click the SuiteApp name to view the SuiteApp details, then click the **Install Base** tab.
        
    
    The Install Base panel appears and shows the following information:
    
    -   **Company ID** - is the company ID for the account that installed the SuiteApp.
        
    -   **Company Name** - is the company name for the account that installed the SuiteApp.
        
    -   **Account Type** - is the account type for the account that belongs to Install base and has the SuiteApp installed.
        
        It can be one of the following:
        
        1.  Production
            
        2.  Release Preview
            
        3.  Sandbox
            
        4.  Development
            
        
        For more information about NetSuite account types, see [Understanding NetSuite Account Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4413974567.html).
        
    -   **Status** - is the current SuiteApp installation status. For information about the list of statuses, see [Viewing SDF SuiteApp Installation Status](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1527799570.html).
        
    -   **SuiteApp Version** - is the version of the SuiteApp that matches the current SuiteApp status.
        
    -   **NetSuite Version** - is the NetSuite version for the account that installed the SuiteApp.
        
    -   **Last Updated** - is the date of the last successful SuiteApp installation or upgrade.
        
    
    You can filter the list by:
    
    -   **Company** - filter by a company ID or company name. Enter a company ID or company name.
        
    -   **Status** - filter by installation status. Pick a status from the list. For information about SuiteApp installation status, see [Viewing SDF SuiteApp Installation Status](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1527799570.html).
        
    -   **SuiteApp Version** - filter by SuiteApp version. Select the version number from the list.
        
    -   **NetSuite Version** - filter by NetSuite version. Select the version number from the list.
        
3.  (Optional) Click **Done** to close the SuiteApp details and go back to the My SuiteApps page.
    

You can also use SuiteScript to get information about installed bundles and SuiteApps. For more information, see [N/suiteAppInfo Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_160236086332.html).
