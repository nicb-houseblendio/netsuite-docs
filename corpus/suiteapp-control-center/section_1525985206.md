## SuiteApp Control Center Interface {#subsect_1527881888}

This topic gives you examples of the SuiteApp Control Center interface so you can get familiar with it and take action.

Here's an example of the My SuiteApps page:

![My SuiteApps pae with List of SuiteApps and Action Menu highlighted.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/SuiteAppControlCenter/SCCSuiteAppsUI.png)

For information about the list of SuiteApps and the available actions, see [Viewing All SDF SuiteApps](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1526316436.html).

Click the SuiteApp name to view its details. Here's an example of the SuiteApp details in SuiteApp Control Center:

![SuiteApp with SuiteApp Name, navigation tabs, phase versions, status messages, and SuiteApp publishing requirements list highlighted.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/SuiteAppControlCenter/SCCReleasesUI.png)

The preceding example includes the following information:

-   **SuiteApp Name** - displays the name of the SuiteApp. For more information, see [Creating a SuiteApp Definition](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1526316405.html).
    
-   **Phase Versions** - displays the currently released leading and lagging versions, if they exist. For information, see [SuiteApp Version Phases](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1526582725.html#subsect_1537984829).
    
-   **Navigation Tabs** - provide navigation to the following aspects of the SuiteApp and its distribution:
    
    -   **Definition** - manages the SuiteApp definition. For information, see [Editing a SuiteApp Definition](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1526583594.html).
        
    -   **Access** - manages account access to the SuiteApp on the SuiteApp Marketplace. For information, see [Setting SuiteApp Marketplace Access](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1526316461.html).
        
    -   **Versions** - manages SuiteApp versions. For information, see [SuiteApp Versions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1526582725.html).
        
    -   **Terms of Service** - manages the terms of service (ToS) for your SuiteApp. For more information, see [Terms of Service](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_6141238491.html).
        
    -   **Install Base** - manages the install base for managed and unmanaged SuiteApps. For information, see [Viewing the SDF SuiteApp Install Base](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1527799607.html).
        
    -   **Upgrades** - manages the SuiteApp upgrades that are in progress for managed SuiteApps. For information, see [Viewing SDF SuiteApp Upgrades](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1542121822.html).
        
        Note:
        
        The **Upgrades** tab is only available for managed SuiteApps. For more information, see [Developing Managed SuiteApps](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1526582924.html).
        
-   **SuiteApp Publishing Requirements List** - gives you one place to see the current publishing status of the SuiteApp, including all required actions to make it available on the SuiteApp Marketplace. For more information, see [Requirements for SuiteApp Marketplace Availability](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1559316827.html)
    
-   **Status Messages** - displays system status regarding the current SuiteApp.
    
-   **Close SuiteApp Details** - closes the SuiteApp and takes you back to the My SuiteApps page.
    

## SuiteApp Distribution Process {#subsect_1527881867}

With SuiteApp Control Center, you can get started on the tasks you need to distribute SuiteApps.

Here are the steps in the SuiteApp distribution process for SuiteApp Control Center:

<a id="svg_3"></a>

                                                                                                                                                                                                                                                                                                       

1.  Get a SuiteApp project to distribute. To create one, see [Creating a SuiteApp Project in SuiteCloud IDE Plug-in for WebStorm](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530903307.html).
    
2.  Define a SuiteApp in SuiteApp Control Center. For information, see [Creating a SuiteApp Definition](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1526316405.html).
    
3.  Set SuiteApp Marketplace access for the SuiteApp by configuring who can install it. For information, see [Setting SuiteApp Marketplace Access](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1526316461.html).
    
4.  Create a SuiteApp version to represent a specific version of the SuiteApp. For information, see [Creating a SuiteApp Version](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1526583775.html).
    
5.  Release the SuiteApp version to the SuiteApp Marketplace. For information, see [Releasing a SuiteApp Version](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1526583869.html).
    
6.  When distributing a managed SuiteApp, push it to the install base. For information, see [Pushing a SuiteApp Version Upgrade to Users](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1527275210.html).
