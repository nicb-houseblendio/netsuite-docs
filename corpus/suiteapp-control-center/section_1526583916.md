If a SuiteApp version doesn't need to be released, you can delete it from the version history. You can only delete a version when it's in the Pending state, meaning it hasn't been released yet. Not allowing deletion of released versions helps keep your SuiteApp's version history intact. To remove a released version from the SuiteApp Marketplace, see [Deprecating a SuiteApp Version](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1526583975.html).

#### To delete a SuiteApp version:

1.  Go to Control Center > My SuiteApps > My SuiteApps.
    
2.  Do one of the following:
    
    -   For a SuiteApp, click ![SCC ellipsis button](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/SuiteAppControlCenter/SCCEllipsisButton.png) and select **Manage Versions**.
        
    -   Click the SuiteApp name to view the SuiteApp details, then click the **Versions** tab.
        
3.  Find the SuiteApp version by its version number in the Version History list. In the **Action** column, click **Delete**.
    
    Warning:
    
    You can't undo deleting a version. But you can create another version with the same version number as the deleted one by uploading a SuiteApp archive with that project version.
    
    To confirm, click **Delete**. The version is deleted from the Version History list and you'll see a confirmation that it was deleted.
    
4.  (Optional) Click **Done** to close the SuiteApp details and go back to the My SuiteApps page.
