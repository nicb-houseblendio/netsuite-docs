You can set the SuiteApp Marketplace access for the SuiteApp by configuring who can install it.

#### To set SuiteApp Marketplace access for a SuiteApp:

1.  Go to Control Center > My SuiteApps > My SuiteApps.
    
2.  Do one of the following:
    
    -   For a SuiteApp, click ![the three-dot menu](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SuiteCloudCustomizationScriptingWebServices/SuiteAppControlCenter/SCCEllipsisButton.png) and select **Manage Access**.
        
    -   Click the SuiteApp name to view the SuiteApp details, and click the **Access** tab.
        
    
    The SuiteApp Marketplace Availability page appears.
    
3.  Set the availability of the SuiteApp on the SuiteApp Marketplace to one of the following:
    
    -   **Public** - lets all NetSuite customers install the SuiteApp.
        
    -   **Shared** - lets only specific companies install the SuiteApp. When set to Shared, all NetSuite customers can still see the SuiteApp.
        
    -   **Hidden from Marketplace** - only specific companies can view and install the SuiteApp.
        
        Note:
        
        The **Hidden from Marketplace** option is available only when you set the SuiteApp marketplace availability to Shared.
        
    
    If you later decide to change the SuiteApp Marketplace access for a SuiteApp from **Hidden from Marketplace** to **Shared** or **Public**, the SuiteApp becomes publicly visible on the SuiteApp Marketplace to all NetSuite users immediately.
    
    Note:
    
    When a managed SuiteApp is configured as shared or hidden from marketplace, upgrades can be pushed only to company accounts that are listed in the Allowed Accounts list.
    
    For information about managing company accounts that are allowed to install SuiteApps that are shared or hidden from marketplace, see [Managing Allowed Accounts for SuiteApps That Are Shared or Hidden from Marketplace](#subsect_156828604284).
    
4.  (Optional) Click **Done** to close the SuiteApp details and go back to the My SuiteApps page.
    
    Note:
    
    For a SuiteApp to be available to users on the SuiteApp Marketplace, it must meet the SuiteApp publishing requirements. For information, see [Requirements for SuiteApp Marketplace Availability](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1559316827.html).
    

Note:

You don't need to share a SuiteApp in SuiteApp Control Center with Sandbox and Release Preview accounts as they're automatically included.

Note:

SuiteApp Marketplace visibility for a SuiteApp is the same for Sandbox and Release Preview accounts as for a parent account. For example, if a shared SuiteApp is shared with sCompId "12345", it's visible for "12345\_SB" and "12345\_RP" as well.

## Managing Allowed Accounts for SuiteApps That Are Shared or Hidden from Marketplace {#subsect_156828604284}

The Allowed Accounts list is where you enable installation of shared or hidden SuiteApps from the SuiteApp Marketplace for specific company accounts.

To add a company account to the Allowed Accounts list, enter its NetSuite account ID in the **New Company ID** field and click **Add**.

Note:

If you don't add any company accounts to the Allowed Accounts list when **Shared** or **Hidden from Marketplace** is enabled, no users can install the released SuiteApp version.

The following fields and actions are available in the Allowed Accounts list:

-   **Company ID** - is the NetSuite account ID for the company you intend to share your SuiteApp with. Only users of the specified companies can install the SuiteApp from the SuiteApp Marketplace.
    
-   **Added Date** - is the date and time the company account was added to the Allowed Accounts list, presented in your local time zone.
    
-   **Action** - lists the actions you that can perform on the company account.
    
    The **Revoke** action removes the account's access to the SuiteApp from the SuiteApp Marketplace. Users who have installed the SuiteApp still retain it after the Revoke action has been performed, but do not receive any new version upgrades. When an account is revoked, it's removed from the Allowed Accounts list, but you can add it back again later if needed.
    

Consider the following when configuring the SuiteApp Marketplace access for a SuiteApp:

-   Company accounts you add to the Allowed Accounts list stay there even if you change the SuiteApp Marketplace access type later.
    
-   The release manager can still see the install base of all company accounts that have the **Shared** or **Hidden from Marketplace** SuiteApp installed, even after those accounts are removed from the Allowed Accounts list.
