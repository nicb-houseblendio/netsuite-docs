Setting up a new case alert has two main steps. First, create a case saved search to track the required performance criteria. Second, create a new case alert, assign the various recipients, and select the required email template.

## Four Hour Response Time

For example, Wolfe Electronics recently implemented a four-hour response time pledge on all customer support cases. If they don't reply to a customer within four hours of the case being created, the shift supervisor starts investigating the case. In the following procedure, we'll set up a case alert that notifies the shift supervisor and support manager about any cases that breached this commitment.

#### To create a case saved search:

1.  Go to _Lists > Search > Saved Searches > New_.
    
2.  Select **Case** as the search type.
    
3.  Enter a name for the search in the **Search Title** field (Four Hour Reply Breaches).
    
4.  From the Filter list, select **Support First Reply**.
    
5.  Select **empty** from the list in the popup, and click **Set**.
    
6.  From the Filter list, select **Time Elapsed (hours)**.
    
7.  Select **greater than** from the list.
    
8.  Insert 4 in the **Value** field, and click **Set**.
    
9.  From the Filter list, select **Status**.
    
10.  Select **any of** and include all statuses except Closed. Click **Set**.
     
11.  Click **Save**.
     

After you've created the saved search, proceed to the Case Alerts page to complete the set up. You can also proceed to this page if you want to use a previously prepared search.

#### To set up a case alert:

1.  Go to Setup > Support > Case Alerts (Beta) > New.
    
2.  Enter a name for the alert.
    
3.  Optionally, you can add a brief description of what the alert is for.
    
4.  Select your previously saved search from the **Saved Search** list.
    
5.  Use the Standard Case Alert template, or select a customized system email template.
    
    For information about adding system email templates, see [Customizing Templates for System-Automated Email](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N515295.html).
    
6.  Select the owner of the alert.
    
    Alerts will be sent to them by default, and their name will be used on the unsubscribe link on the Standard Case Alert template.
    
7.  Optionally, check **Send to Case Assignee** so the assigned support rep also receives the alert.
    
8.  From the **Recipient** list, select employees or groups you want to receive the alert, then click **Add**.
    
9.  Click **Save**.
    

Active case alerts refresh approximately every five minutes. If a saved search already has a send schedule, the case alert will override it.
