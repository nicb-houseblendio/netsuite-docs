The Closed Issues Detail report shows all issues with a base status of Closed for the time period you set. Issues are listed by number and grouped by the employee they were last assigned to.

This report provides details for each closed issue, including the product team, status, severity, priority, broken in version and target version.

## To see the Closed Issues Detail report: {#bridgehead_N2452499}

Go to _Reports > Issue Management > Closed Issues > Detail_.

A message appears indicating that your report is loading, and a status bar in the footer shows the progress. You can click **Cancel Report** next to the status bar to stop the report from loading.

Note:

This report doesn't support reporting by period, even if you set the Report by Period preference to All Reports. You can set this preference at _Home > Set Preferences_, the Analytics subtab.
