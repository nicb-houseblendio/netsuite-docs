The SuiteApp lets you make a copy of an existing distribution template.

The copy will have the exact values of the existing distribution template, except for the template name.

#### To make a copy of an existing distribution template:

1.  Go to Setup > Accounting > Transaction Distribution Templates.
    
2.  Click **View** next to the template that you want to copy.
    
3.  From the **Actions** list, select **Make Copy**.
    
    A copy of the selected distribution template opens in **Edit** mode.
    
4.  In the **Template Name** field, enter a unique name for the copied template.
    
    You can now edit the sourced values in the template to your preference.
