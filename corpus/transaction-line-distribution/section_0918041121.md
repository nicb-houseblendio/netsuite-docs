When distributing transaction lines in an invoice, you have the option to use a distribution template for easier distribution calculation.

Only users assigned with Custom CFO and Custom A/R Clerk roles can distribute lines and apply distribution templates to invoices.

Important:

You must first ensure that Invoice is enabled in the transaction distribution preferences. For more information, see [Setting Up Transaction Distribution Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1015124816.html).

#### To distribute transaction lines in an invoice:

1.  Go to Transactions > Sales > Create Invoices.
    
2.  Enter the required values in the Primary Information and Sales Information sections when creating invoices. For more information, see [Creating an Invoice](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1238506.html).
    
3.  In the Classification section, from the **Default Distribution Template** list, select a distribution template to be applied to the invoice.
    
    The following fields will be populated based on the distribution template selected:
    
    -   Distribution Type
        
    -   Rate Type
        
4.  (Optional) To disable the line level distribution template or quick rule and have all transaction lines based on the default distribution template, check the **Disable Line Distribution Rule** box.
    
5.  Click the **Items** subtab.
    
    To add items on an invoice, see [Adding Items on a Sales Transaction](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4588373194.html).
    
6.  To apply a distribution template for an item line, select a template in the **Line Dist. Template** field. The field lists the templates based on the values selected in the **Distribution Type** and **Rate Type** fields in the Primary Information section.
    
7.  (Optional) To create a line-level distribution rule for this item line, click Enter Quick Distribution. For further instructions, see [Applying Quick Distribution Rule](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0927021730.html).
    
8.  Click **Save**.
    

For more information about invoices in general, see [Invoices](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1235134.html).
