This section includes the prerequisites and instructions for installing the Transaction Line Distribution SuiteApp.

## Prerequisites {#subsect_69123049095}

The Transaction Line Distribution SuiteApp is developed and tested for use primarily with NetSuite OneWorld. For more information about NetSuite OneWorld, see Introduction to NetSuite OneWorld.

The following prerequisites are only needed if you want to use the intercompany distribution type on your transactions:

-   Enable the following features by going to Setup > Company > Enable Features. For more information, read [Enabling Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N232138.html).
    
    | Subtab | Section | Feature |
    | --- | --- | --- |
    | Accounting | Advanced Features | Automated Intercompany Management |
    | Company | Classifications | Departments |
    | Locations |
    | Classes |
    | ERP General | Multi Subsidiary Customer |
    
-   Enable the custom segments feature in your account. For more information, see [Enabling the Custom Segments Feature](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4313465000.html).
    
-   The account must have one elimination subsidiary. For more information, see [Elimination Subsidiaries](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N268759.html).
    

## Installation {#subsect_87123217195}

Any role with access to the SuiteApp Marketplace in NetSuite can install the Transaction Line Distribution SuiteApp. For more information about the SuiteApp Marketplace, see [SuiteApp Marketplace in NetSuite](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1539797981.html).

#### To install the Transaction Line Distribution SuiteApp: {#procedure_0927123609}

1.  Go to the **SuiteApps** tab.
    
2.  In the **Search Apps** field, enter **Transaction Line Distribution**.
    
3.  Click the **Transaction Line Distribution SuiteApp** tile.
    
4.  On the top right area of the Transaction Line Distribution SuiteApp details page, click **Install**.
    

For more information about installing a SuiteApp from the SuiteApp Marketplace, see [Installing from the SuiteApp Marketplace](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1539799323.html).

The Transaction Line Distribution SuiteApp is a managed SuiteApp and is automatically updated whenever there are enhancements or new features added.
