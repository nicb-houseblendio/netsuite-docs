When distributing transaction lines in a vendor bill, you have the option to use a distribution template for easier distribution calculation.

Only users assigned with Custom CFO and Custom A/P Clerk roles can distribute lines and apply distribution templates to vendor bills.

Important:

You must first ensure that Vendor Bill is enabled in the transaction distribution preferences. For more information, see [Setting Up Transaction Distribution Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1015124816.html).

#### To distribute transaction lines in a vendor bill: {#procedure_0927015624}

1.  Go to Vendors > Purchases > Enter Bills.
    
2.  Enter the required values in the Primary Information section when entering a vendor bill.
    
    For more information, see Primary Information section of [Entering a Vendor Bill](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161968486146.html).
    
3.  In the Classification section, from the **Default Distribution Template** list, select a distribution template to be applied to the vendor bill.
    
    The following fields will be populated based on the distribution template selected:
    
    -   Distribution Type
        
    -   Rate Type
        
    
    Note:
    
    If a default distribution template is assigned to the vendor, the **Default Distribution Template** field will be populated.
    
4.  To disable the line level distribution template or quick rule and have all transaction lines based on the default distribution template, check the **Disable Line Dist. Rule** box.
    
5.  Click the **Expenses and Items** subtab.
    
6.  On the **Expenses** subtab:
    
    1.  From the **Account** list, select an account.
        
    2.  In the **Amount** field, enter an amount.
        
    3.  To apply a distribution template for an expense line, select a template in the **Line Dist. Template** field. The field lists the templates based on the values selected in the **Distribution Type** and **Rate Type** fields in the Primary Information section.
        
    4.  (Optional) To create a line-level distribution rule for this expense, select a line and click **Enter Quick Distribution**. For further instructions, see section [Applying Quick Distribution Rule](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0927021730.html).
        
    5.  (Optional) To exclude a line from getting distributed, check the **Line Dist. Exclude** box.
        
    6.  For each expense you want to add, repeat the steps **6(a)** to **6(d)**.
        
7.  On the **Items** subtab:
    
    1.  From the **Item** list, select an item to add.
        
    2.  In the **Quantity** field, enter the quantity of the item.
        
    3.  To apply a distribution template for an item line, select a template in the **Line Dist. Template** field. The field lists the templates based on the values selected in the **Distribution Type** and **Rate Type** fields in the Primary Information section.
        
    4.  (Optional) To create a line-level distribution rule for this item, select a line and click **Enter Quick Distribution**. For further instructions, see section [Applying Quick Distribution Rule](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0927021730.html).
        
    5.  (Optional) To exclude a line from getting distributed, check the **Line Dist. Exclude** box.
        
    6.  For each item you want to add, repeat the steps **7(a)** to **7(d)**.
        
8.  Click **Save**.
    
9.  To see the summary of the vendor bill's distribution according to the selected distribution template, click the **Distribution List** subtab.
    

After a line is added to the transaction, the **Rate Type** and **Type** fields will be dimmed and changes cannot be made. You must clear all lines first before changes can be made.

On the Distribution List subtab, the values for **Distribution Percentage** and **Distribution Amount** fields can be edited if the approval status is still Pending Approval.

When editing the distribution list and the selected rate type is **Amount**, ensure that the transaction line amount matches the distribution template's total amount.

For transactions with **Distribution Weight** as the selected rate type, ensure that the total percentage of the transactions lines are 100%. Otherwise, the transaction will still be saved, but the distribution will not be processed.
