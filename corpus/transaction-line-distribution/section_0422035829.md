When distributing transaction lines in a check, you have the option to use a distribution template for easier distribution calculation.

Only users assigned with Custom CFO and Custom A/P Clerk roles can distribute lines and apply distribution templates to checks.

Important:

You must first ensure that Write Check is enabled in the transaction distribution preferences. For more information, see [Setting Up Transaction Distribution Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1015124816.html).

#### To distribute transaction lines in a check:

1.  Go to Vendors > Accounts Payable > Write Checks.
    
2.  Enter the required values in the Primary Information section when entering a check transaction.
    
    For more information, see step 2 of [Writing Checks](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1543875.html).
    
3.  In the Classification section, from the **Distribution Default Template** list, select a distribution template to be applied to the check.
    
    The following fields will be populated based on the selected distribution template:
    
    1.  Dist. Type
        
    2.  Dist. Rate Type
        
4.  To disable the line level distribution template or quick rule and have all transaction lines be based on the default distribution template, check the **Disable Line Dist. Rule** box.
    
5.  Click the **Expenses and Items** subtab.
    
6.  On the **Expenses** subtab:
    
    1.  From the **Account** list, select an account.
        
    2.  In the **Amount** field, enter an amount.
        
    3.  To apply a distribution template for an expense line, select a template in the **Line Dist. Template** field. The field lists the templates based on the values selected in the **Distribution Type** and **Rate Type** fields in the Primary Information section.
        
    4.  Optional) To create a line-level distribution rule for this expense, select a line and click **Enter Quick Distribution**. For further instructions, see section [Applying Quick Distribution Rule](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0927021730.html).
        
    5.  (Optional) To exclude a line from getting distributed, check the **Line Dist. Exclude** box.
        
    6.  For each expense you want to add, repeat the steps **6(a)** to **6(d)**.
        
7.  On the **Items** subtab:
    
    1.  From the **Item** list, select an item to add.
        
    2.  In the **Quantity** field, enter the quantity of the item.
        
    3.  To apply a distribution template for an item line, select a template in the **Line Dist. Template** field. The field lists the templates based on the values selected in the **Distribution Type** and **Rate Type** fields in the Primary Information section.
        
    4.  (Optional) To create a line-level distribution rule for this item, select a line and click **Enter Quick Distribution**. For further instructions, see section [Applying Quick Distribution Rule](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0927021730.html).
        
    5.  (Optional) To exclude a line from getting distributed, check the **Line Dist. Exclude** box.
        
    6.  For each item you want to add, repeat the steps **7(a)** to **7(d)**.
        
8.  Click **Save**.
    
9.  To see the summary of the check's distribution according to the selected distribution template, click the **Distribution List** subtab.
