You can import transactions using CSV files. When importing, consider the following:

-   You must check the Run Server SuiteScript and Trigger Workflows box in Advanced Options section of the Import Options page. For more information, read [Importing CSV Files with the Import Assistant](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N343158.html).
    
-   When importing new transactions, ensure that each transaction has an external id.
    
-   When updating an existing transaction using import:
    
    -   Add the external id of the existing transaction
        
    -   Add the line number of the transaction line that you want to update. If you do not add the line number, the SuiteApp creates a new transaction line.
