The Transaction Line Distribution SuiteApp supports the following transactions:

-   **Vendor bills** - see [Distributing Transaction Lines in Vendor Bills](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0927015020.html).
    
-   **Vendor credits** - see [Distributing Transaction Lines in Vendor Credits](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0927020453.html).
    
-   **Purchase orders** - see .[Distributing Transaction Lines in Purchase Orders](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0422033203.html)
    
-   **Expense reports** - see [Distributing Transaction Lines in Expense Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0422035227.html).
    
-   **Checks** - see [Distributing Transaction Lines in Checks](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0422035829.html).
    
-   **Credit card (Charge transactions only)** - see [Distributing Transaction Lines in Credit Card Charges](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0422040220.html).
    
-   **Sales orders** - [Distributing Transaction Lines in Sales Orders](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0918035606.html)
    
-   **Cash sales** - [Distributing Transaction Lines in Cash Sales](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0918040339.html)
    
-   **Invoices** - [Distributing Transaction Lines in Invoices](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0918041121.html)
    
-   **Credit memos** - [Distributing Transaction Lines in Credit Memos](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0918041906.html)
    
-   **Purchase requisitions** - [Distributing Transaction Lines in Purchase Requisitions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0918042602.html)
    
-   **Journal entries** - [Distributing Transaction Lines in Journal Entries](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0920054257.html)
