When distributing transaction lines in a purchase order, you have the option to use a distribution template for easier distribution calculation.

Only users assigned with Custom CFO and Custom A/P Clerk roles can distribute lines and apply distribution templates to purchase orders.

Important:

You must first ensure that Purchase Order is enabled in the transaction distribution preferences. For more information, see [Setting Up Transaction Distribution Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1015124816.html).

#### To distribute transaction lines in a purchase order:

1.  Go to Vendors > Purchases > Enter Purchase Orders.
    
2.  Enter the required values in the Primary Information and Classification sections when entering a purchase order.
    
    For more information, see [Entering a Purchase Order](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2400504.html).
    
3.  In the Intercompany Management section, in the **Dist. Default Template** list, select a distribution template to be applied to the purchase order.
    
    The following fields will be populated based on the selected distribution template:
    
    1.  Dist. Type
        
    2.  Dist. Rate Type
        
4.  To disable the line level distribution template or quick rule and have all transaction lines be based on the default distribution template, check the **Disable Line Dist. Rule** box.
    
5.  Click the **Items** subtab.
    
    If you use multiple currencies, the current exchange rate for this vendor's currency appears in the Exchange Rate field.
    
    1.  From the **Item** list, select an item to add.
        
    2.  In the **Quantity** field, enter the quantity of the item.
        
    3.  To apply a distribution template for an item line, select a template in the **Line Dist. Template** field. The field lists the templates based on the values selected in the **Distribution Type** and **Rate Type** fields in the Primary Information section.
        
    4.  (Optional) To create a line-level distribution rule for this item, click **Enter Quick Distribution**.
        
        For further instructions, see section [Applying Quick Distribution Rule](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0927021730.html).
        
    5.  (Optional) To exclude a line from getting distributed, check the **Line Dist. Exclude** box.
        
    6.  For each item you want to add, repeat the steps **5(a)** to **5(d)**.
        
6.  Click **Save**.
    
7.  To see the summary of the purchase order's distribution according to the selected distribution template, on the **Distribution List** subtab, click **Items** subtab.
