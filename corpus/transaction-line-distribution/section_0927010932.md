Transaction distribution templates help users to process transaction distributions across subsidiaries, classic segments, or custom segments.

Review the following for information about transaction distribution templates:

-   For instructions on how to create distribution templates, see [Creating Distribution Templates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0422031728.html).
    
-   For help importing distribution template as CSV, see [Importing Transaction Distribution Template CSV](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0422032120.html).
    
-   For information about making a copy of an existing distribution template, see [Making a Copy of an Existing Distribution Template](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0422032353.html).
