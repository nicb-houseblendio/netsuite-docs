There are two permission types for the Personal Information Removal feature:

-   Remove Personal Information Create - User can create, edit, and delete requests.
    
-   Remove Personal Information Run - User can approve, run and delete requests.
    

For more information, see [NetSuite Permissions Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N325094.html) and [Permissions Documentation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N326485.html).
