The following table summarizes possible context values for data changes.

| Context | Change Initiated Through | Corresponding Help Topic |
| --- | --- | --- |
| Bulk Processing | Any of the pages in the user interface that let you mark multiple records for simultaneous processing. Such pages include the Authorize Commissions page (at _Transactions > Commissions > Authorize Employee Commissions_) and the Mark Work Orders Built page (at _Transactions > Manufacturing > Mark Work Orders Built_). | \- |
| Campaign Response | A campaign response | [Tracking Campaign Responses](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N990539.html) |
| CSV | The CSV Import Assistant | [CSV Imports Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N342646.html) |
| Mass Update | The utility at Lists > Mass Update > Mass Updates | [Mass Updates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1103335211.html) |
| Mobile | The mobile interface. However, not all changes initiated through the mobile interface have this context label. For details, see [Some Contexts Occur Within Other Contexts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4032860783.html#bridgehead_4075064788). | \- |
| Scheduled Workflow | A workflow configured to run at a specific time or interval. See also Workflow. | [Initiating a Workflow on a Schedule](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2730900.html) |
| Script (Client) | A script that runs in the browser | [SuiteScript 2.1 Client Script Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4387798404.html) |
| Script (Mass Update) | A script that initiates a Mass Update | [SuiteScript 2.1 Mass Update Script Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4460452911.html) |
| Script (Portlet) | A script rendered in the NetSuite dashboard | [SuiteScript 2.1 Portlet Script Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4387799288.html) |
| Script (RESTlet) | A script invoked by an HTTP request to a system-generated URL | [SuiteScript 2.1 RESTlet Script Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4387799403.html) |
| Script (Scheduled) | A script configured to run at a specific time or interval | [SuiteScript 2.1 Scheduled Script Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4387799491.html) |
| Script (SSP Application) | A script implemented using the SuiteScript Server Pages feature | [SSP Application Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N2490486.html) |
| Script (Suitelet) | A script that operates in a request-response model using extensions of the SuiteScript API | [SuiteScript 2.1 Suitelet Script Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4387799600.html) |
| Script (User Event) | A script triggered by an action performed on a record | [SuiteScript 2.1 User Event Script Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4387799721.html) |
| Script (Workflow Action) | A script invoked as a custom action from a workflow state | [SuiteScript 2.1 Workflow Action Script Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4460429314.html) |
| UI | The user interface. However, not all changes initiated through the user interface have this context label. For details, see [Some Contexts Occur Within Other Contexts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4032860783.html#bridgehead_4075064788). | \- |
| SOAP Web Services | A SOAP web services request | [SuiteTalk SOAP Web Services Platform Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N3412777.html) |
| Web Store | A SuiteCommerce website | [Commerce Product Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4258759122.html) |
| Workflow | A SuiteFlow workflow that occurs asynchronously. Examples include workflows initiated by SuiteScript and workflows invoked because they're subscribed to other records. If a workflow is triggered synchronously, by an event, the resulting changes generally share the same context as the triggering event. For examples, see [Related Changes May Share a Single Context](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4032860783.html#bridgehead_4075066010). Changes made by scheduled workflows have a context of Scheduled Workflow. | [Subscribe To Record Action](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2751816.html) |
