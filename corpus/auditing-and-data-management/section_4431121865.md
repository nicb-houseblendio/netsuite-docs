To avoid duplicate processing of memorized transactions in a bulk update, customize a Memorized Transaction Search form:

1.  Go to _Transactions > Management > Enter Memorized Transactions > List ( Administrator )_.
    
2.  In the header, click **Search**.
    
3.  On the Memorized Transaction Search page, click **Personalize Search**.
    
4.  On the custom search form, enter a search title.
    
5.  Click the **Results** subtab.
    
6.  Select **Being Processed** for the result column.
    
    ![Being Processed field outlined in red on the Results subtab.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/AccountAdministration/AuditingDataManagement/AuditingDataManagement_MemorizedTransactionsAvoidDuplicates.png)
7.  Click **Add**.
    
8.  Click **Save**.
    

In the results of this search, the Being Processed column displays Yes or No to indicate if a memorized transaction is being processed as part of a bulk update. If you select a transaction with Yes in the Being Processed column, it can lead to duplicate processing. Best practice is to avoid processing transactions that display Yes in the Being Processed column.

If you submit a memorized transaction that's currently in a processing state, NetSuite displays an error message on the Processed Orders page and doesn't process the memorized transaction.

Note:

To access memorized transactions, you need View access level for the Memorized Transaction permission.
