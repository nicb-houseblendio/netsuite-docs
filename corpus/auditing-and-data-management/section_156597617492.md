Note:

This topic applies to System Notes only. For information about System Notes v2, see [System Notes v2 Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158108495822.html).

If your company uses the Personal Information Removal feature, where available, you can see PI removal results in the record's system notes. The location and path to access the system notes information varies depending on the type of record. In the following example, a change was made to the Acme Medical Supplies contact record. To view the system notes, you would go to _Lists > Relationships > Contacts_ and click View beside Acme Medical Supply. Then you would click the System Information subtab and then the System Notes subtab.

The system notes show that a field value was replaced with a replacement text of PI\_Removed.

![Sample PI Removal with system notes results outlined in red.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/AccountAdministration/AuditingDataManagement/PIRemovalSysNotesResults.png)
