Important:

To use the Activity Log feature, you must install the Compliance 360 SuiteApp. The Compliance 360 SuiteApp gives customers access to user activity logs produced by the NetSuite Compliance 360 Cloud Service for security and compliance monitoring. For more information, see [Compliance 360 SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_7153807491.html).

The Activity Log lets you to see who accesses the personal information of your customers and what actions they perform.

The Activity Log feature:

-   Improves compliance with regulatory standards.
    
-   Helps monitor all actions on customer data.
    
-   Allows users to register and react to suspicious activity.
    

Within NetSuite, you can see the data that was accessed, the user who accessed it, when the data was accessed, the IP address that was used, and the action that was taken. The Activity Log provides information about data accessed in the last 12 months.

The Activity Log feature monitors only record types that may contain customer-related sensitive information.

Important:

You can't delete customer records when the Activity Log feature is enabled. If you try to delete a customer record, NetSuite displays a dependency error.

For information about installation, required permissions, and limitations, see [Compliance 360 SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_7153807491.html).

The Personal Information Access Logs dataset is related to the Activity Log feature. This dataset enables you to make use of all SuiteAnalytics capabilities in NetSuite, in addition to the visualizations provided by the Compliance 360 SuiteApp. For more information, see [Personal Information Access Logs Dataset and Workbook](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0522124117.html).
