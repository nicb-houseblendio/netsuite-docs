The Personal Information Removal feature works with the following field types:

-   Hyperlink
    
-   Long Text
    
-   Phone Number
    
-   Rich Text Object
    
-   Text Area
    
-   Date
    
-   Email Address
    
-   Free-Form Text
    
-   Security Number
    
-   Address
    

Note:

The Personal Information Removal feature doesn't support removing details on sublist fields. For information about how to remove sublist field details, see [Removing Personal Information on a Sublist Field](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0505041319.html).
