To monitor changes made to NetSuite data, you can search system notes records.

Note:

This topic applies to System Notes only. For information about searching System Notes v2, see [Searching and Filtering System Notes v2](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159499608205.html).

You can use the following tools to access system notes records:

-   A general system notes search can return system notes for all record types. You can also filter search results by record type. For more information, see [Searching System Notes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N673560.html).
    
-   Searches of record types that support system notes can include system notes details in results. For example, a customer search can include values for system notes fields related to customer record changes in results. This support is based on a join between system notes records and their related parent records. See [Defining an Advanced Search](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N646177.html).
    
-   An audit trail link, available at the top of most list pages, returns system notes for a particular record type. See [Viewing an Audit Trail for a Record Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N675070.html).
    
-   The audit trail for transaction records is available at _Transactions > Management > View Audit Trail_. See [Using the Transaction Audit Trail](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N556825.html).
    
-   Running saved searches doesn't create system notes since it doesn't change any data. However, each saved search has a log that lists the users who ran or exported the search. This log shows who used the search in the past 60 days, including the date and time of when the user ran the search. You can also see an audit trail about changes made to each saved search. For more information, see [Audit Trail for Saved Searches, Reports and Schedules](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N688127.html).
    
    **Known Limitations:** If you search for System Notes Fields and you use Type = Change as a filter, NetSuite will return all results having type Change, Set or Unset as these are all considered a change. As a workaround, you can also use the following formula: Formula (text): is change: {systemnotes.type}.
    

Additionally, the Deleted Record search type lets you retrieve details about records that have been deleted. For information about searching for deleted records, see [Searching for Deleted Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4031815869.html).

Note:

To search System Notes, you must have View permissions and only an administrator or another user with Notes Tab permission can use it. For more information about permissions for system notes, see [Accessing System Notes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_158644279544.html#subsect_0310125020) and [NetSuite Permissions Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N325094.html).
