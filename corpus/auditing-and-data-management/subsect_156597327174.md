Use the icons on the Personal Information Removal Request page to view details of a request, make a copy of a request, or approve, edit or delete a request. Available options depend on the request status.

For requests with the Created status, the following icons are available:

-   For the Create role: Make Copy, Edit, Delete
    
    ![PI Removal Create Role icons](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/AccountAdministration/AuditingDataManagement/PIRemovalCreateRoleIcons.png)
-   For the Run role: View, Delete, Approve
    
    ![PI Removal Run Role icons.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/AccountAdministration/AuditingDataManagement/PIRemovalRunRoleIcons.png)

For requests with the Pending or Complete status, Make Copy and View icons are available:

![PI Removal Pending Complete icons.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/AccountAdministration/AuditingDataManagement/PIRemovalPendingCompleteIcons.png)

**Make Copy** - Make changes if needed and click **Create**. A copy of the request is created. For example, you may want to duplicate a previous selection if you forgot to include one of the items for removal.

**Edit** - Make changes as needed and click **Save**. Your changes are saved.

**Delete** - A confirmation message appears. To remove a request, click **Delete**.

**Approve** - A message warns you that all data will be lost **permanently**. To continue with the approval, click **Yes, Proceed**. The request status changes to Pending until the removal has been processed. Then the status changes to Complete.

**View**\- The new PI Removal Request Page appears in view-only mode. View the information as needed.
