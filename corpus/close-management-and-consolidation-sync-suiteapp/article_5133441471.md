Customers in NetSuite can use EPM Consolidation Class Category values to group classes into different categories and create their own custom hierarchy. When you import Class metadata to your Financial Consolidation and Close, the EPM Consolidation Class Category values are used to build the Class metadata hierarchy.

You can define the EPM Consolidation Class Category on a class record.

The Class metadata hierarchy is built with the following logic:

-   If a class from NetSuite has a parent, the parent of the class is used in your Financial Consolidation and Close as the parent.
    
-   If a class from NetSuite doesn't have a parent, but has an EPM Consolidation Class Category, the EPM Consolidation Class Category is used in your Financial Consolidation and Close as the parent.
    
-   If a class from NetSuite has neither a parent nor an EPM Consolidation Class Category, the top-level class is used in your Financial Consolidation and Close as the parent.
