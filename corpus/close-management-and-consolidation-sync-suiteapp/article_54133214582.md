The Close Management and Consolidation Sync SuiteApp enables you to extract metadata from NetSuite entities and use the metadata in your Financial Consolidation and Close. Metadata from each entity can be exported to a CSV file instead of being displayed in the NetSuite UI. You can then use the exported CSV file to import the metadata to your Financial Consolidation and Close.

To export selected metadata from NetSuite entities, you have the following options:

-   You can customize and export metadata manually, as described in [Saved Search Settings in Close Management and Consolidation Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_3002017224.html).
    
-   After configuring Data Exchange in your Financial Consolidation and Close for automated metadata synchronization, you can use saved searches included in the SuiteApp to export metadata as CSV files from NetSuite to your Financial Consolidation and Close.
    
    For the list of the supported metadata saved searches, see [Supported Metadata Saved Searches in Close Management and Consolidation Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_77133235333.html).
