You can create a group of Data Exchange or Financial Consolidation and Close jobs that you want to run from NetSuite. The group can only contain jobs that you've previously added in NetSuite. See [Adding a Job in Close Management and Consolidation Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_54163337626.html). The job parameters you set for the group override the parameters set for the data load rules executed as part of the group.

The jobs in the group are executed one by one in 15-minute intervals. The next job can't start until the previous job is completed and the nearest 15-minute interval begins.

To use NetSuite to schedule and run a group of jobs configured in Data Exchange or your Financial Consolidation and Close, you need to create and configure the group in NetSuite.

#### To create and configure a group of jobs:

1.  In NetSuite, go to NetSuite EPM > Close Management and Consolidation > Manage Jobs.
    
2.  Click the **Add Job** button.
    
3.  From the **Job Type** list, select **Group**.
    
4.  In the **Job Name** field, enter a unique name for this group of jobs.
    
5.  In the **Description** field, enter a description to help you identify this group of jobs in NetSuite.
    
6.  Click **Next**.
    
7.  On the **Members** subtab, do the following:
    
    1.  In the **Job Name** column, add the jobs that you want to include in the group. You can only add jobs that you've added and configured in NetSuite for the integration. See [Job Types in Close Management and Consolidation Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_95163533223.html).
        
        The members of the group will be executed in the order in which you add them to the column.
        
    2.  Check the **Stop on Failure** box if you want to stop executing the sequence of jobs after a job in the group fails. If you clear the box, and a member of the group fails, the group job continues executing the next and the subsequent jobs in the sequence.
        
8.  To specify the accounting period during which the group of jobs should be executed, click the **Job Parameters** subtab, and do the following:
    
    1.  From the **Period Type** list, select one of the following target date periods:
        
        -   **Relative** to specify an accounting period that is relative to the current date.
            
            Important:
            
            Ensure that the periods configured in Data Exchange match those defined in NetSuite at Setup > Accounting > Manage Accounting Periods. For information about managing accounting periods, see [Manage Accounting Periods Page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1445839.html).
            
        -   **Absolute** to set up a specific date range.
            
        -   **Substitution Variables** to use the substitution variables configured in your Financial Consolidation and Close to set up the start and end month and year of the accounting period.
            
            Note:
            
            The Substitution Variables period type is only supported for data load rules loading data. For data load rules loading metadata, the Absolute or Relative period types need to be used.
            
        
        For **Relative** and **Absolute**, you have the following options:
        
        -   **Start Period**
            
        -   **End Period**
            
        
        From the **Start Period** and **End Period** lists, select the accounting periods as follows:
        
        -   If you've selected **Absolute** as the **Period Type**, select from the list of available accounting periods. For more information about managing accounting periods, see [Manage Accounting Periods Page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1445839.html).
            
        -   If you've selected **Relative** as the **Period Type**, select one of the following accounting periods:
            
            -   **This Period**
                
            -   **Last Period**
                
            -   **Period Before Last**
                
        
        For Substitution Variables, you have the following options:
        
        -   **Start Period Month**
            
        -   **Start Period Year**
            
        -   **End Period Month**
            
        -   **End Period Year**
            
    2.  Specify the **Import Mode** and **Export Mode** of the job execution, as defined in Data Exchange.
        
    3.  To apply the parameters set for each data load rule in the group, check the **Use Values from Member** box. Leaving the box clear overrides the data load rule parameters with the group parameters.
        
        Note:
        
        This option applies only to the data load rules within the group and doesn't impact other jobs in the group.
        
9.  To schedule the group execution, click the **Schedule** subtab, and follow step 3 in [Scheduling a Job in Close Management and Consolidation Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_85163503218.html).
    
10.  Click **Save**.
