To view the status of job execution, you need to access the job execution logs in NetSuite. In the logs, you can also find detailed information about an error in case of failure.

#### To view the log of an executed job or troubleshoot:

1.  In NetSuite, go to NetSuite EPM > Close Management and Consolidation > Manage Jobs.
    
2.  To access the execution log of a job, click **Logs** next to the job. This opens the Close Management and Consolidation: Job Execution Log page where you can see the following:
    
    -   Details and the status of the executed job and plug-in script.
        
    -   Basic description of the job failure or plug-in error.
        
3.  Clicking the **View** link takes you to a NetSuite page with the content of the log file.
    
    Note:
    
    The **View** link is not available for Ruleset and Import Enterprise Journal jobs.
    
    Then, you can do the following:
    
    1.  Choose between the **Full** or **Summary** view of the log file content.
        
    2.  Click the **Download** button to save the required log file to disk.
        
    3.  If an Import Data/Metadata job was completed with **Error**, clicking the **Download** link saves the latest error log to disk.
        
    4.  To return to the Close Management and Consolidation: Job Execution Log page, click **Back**.
        
4.  To troubleshoot plug-in execution of an Import Enterprise Journal job, do the following:
    
    1.  In the upper-right corner of the page, click the **Plugin Execution Logs** link to the **NSFC | MR Resume Job Execution** script deployment record.
        
    2.  To view all your script logs, click the **Execution Log** subtab.
        
    3.  To view your debug level logs for troubleshooting, click the **Deployments** subtab, and do the following for all the listed script deployment records:
        
        1.  Click the link to a script deployment record.
            
        2.  On the script deployment record, click the **Edit** button.
            
        3.  Set the **Log Level** field to **Debug**.
            
        4.  Click **Save**.
            
        5.  To return to the list of script deployment records, click the **NSFC | MR Resume Job Execution** link at the top of the page.
            
        6.  Click the **Deployments** subtab, and repeat these steps for all the other script deployment records in the list.
            
        
        Important:
        
        When you finish troubleshooting, make sure you change the log level to **Audit**. This ensures that your data is not exposed in the logs.
