To successfully load account metadata into your Financial Consolidation and Close, you need to download and customize the `FCCS Account Type Mapping Template.csv` file. Then, you need to use the Import Assistant to import the customized file into the **NSFC | Account Type Mapping** record type.

For detailed information about importing CSV files in NetSuite, see [CSV Imports Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N342646.html).

#### To download and import the template for account metadata load:

1.  In NetSuite, go to NetSuite EPM > Close Management and Consolidation > Integration Artifacts.
    
2.  Click the **Templates** subtab.
    
3.  Click **Download** to save the `FCCS Account Type Mapping Template.csv` template to your disc.
    
    Important:
    
    Make sure you update the template before importing so the values correspond to your Financial Consolidation and Close environment setup.
    
4.  Use the Import Assistant in NetSuite to import the customized CSV file into the **NSFC | Account Type Mapping** record type:
    
    -   For instructions about using the Import Assistant, see [Importing CSV Files with the Import Assistant](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N343158.html).
        
    -   For information about the account type mapping functionality provided with the Close Management and Consolidation Sync SuiteApp, see [Account Type Mapping in Close Management and Consolidation Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_22133754008.html).
        

Note:

With every new version of the Close Management and Consolidation Sync SuiteApp, you may need to repeat the process of downloading, customizing, and re-attaching the template provided with the SuiteApp.
