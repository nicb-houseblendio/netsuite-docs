This help topic summarizes the recent changes to the Close Management and Consolidation Sync SuiteApp. Here you may also find instructions on how to troubleshoot your issues, or what actions to take to ensure the integration works for you.

## Version 26.1.2 {#subsect_0730073805}

### August 4, 2026 {#subsect_0730073818}

This release enhances the security of OAuth 2.0 configurations for NetSuite EPM integrations. The OAuth 2.0 connection to Financial Consolidation and Close now includes a token scope that is specific to each Cloud EPM service that your NetSuite integration uses.

Review the following information:

-   For the updated connection setup procedure, see [Using OAuth 2.0 to Connect to Financial Consolidation and Close](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0212112713.html).
    
-   For required updates to existing OAuth 2.0 configurations, see [Required OAuth 2.0 Configuration Updates for NetSuite EPM Integrations](https://suiteanswers.custhelp.com/app/answers/detail/a_id/1047055), SuiteAnswers ID 1047055.
    

## Version 26.1.1 {#subsect_0701091309}

### July 7, 2026 {#subsect_0701091324}

This release includes a security-related improvement.

## Version 26.1 {#subsect_1111045356}

### January 13, 2026 {#subsect_1215110458}

This release of the Close Management and Consolidation Sync SuiteApp introduces the following new features and enhancements:

-   You can check the **Use Entered URL to Verify Inbound Connections** box to verify that the correct Financial Consolidation and Close application connects to NetSuite. See step 4 in [Setting Up the Connection to Financial Consolidation and Close](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_3232205961.html).
    
-   You no longer need to manually add the **customsearch\_nsfc\_** prefix for saved searches and the **custdataset\_nsfc\_** prefix for datasets to the allowlist in NetSuite EPM Connector. The SuiteApp now adds these prefixes automatically when you create default saved searches and datasets. See [Data Source Allowlist](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_9115749534.html).
    
-   You can write SuiteQL queries to load data from NetSuite into your Financial Consolidation and Close. See [Managing SuiteQL Queries in Close Management and Consolidation Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_5165545662.html).
    
-   Options for Relative period selection in Data Load Rule, Group, and Import Enterprise Journal jobs are renamed from 'month' to 'period'. The following has changed:
    
    -   **This Month** changes to **This Period**
        
    -   **Last Month** changes to **Last Period**
        
    -   **Month Before Last** changes to **Period Before Last**
        
    -   **Period Before Last** is now available for Data Load Rule and Group jobs
        
    
    For the updated lists of available Relative period options, see the following help topics:
    
    -   [Data Load Rule in Close Management and Consolidation Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_25163933832.html)
        
    -   [Group in Close Management and Consolidation Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_14164108832.html)
        
    -   [Import Enterprise Journal in Close Management and Consolidation Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0122054649.html)
        
-   The **Help On This Topic** link is available in the upper-right corner or under the More menu on every NetSuite page. Selecting this link opens the relevant help topic for that page.
    
-   The Close Management and Consolidation Sync SuiteApp is localized in all supported languages.
    

## Version 25.1.1 {#subsect_0401090119}

## April 8, 2025 {#bridgehead_0401090138}

This release resolves an issue that prevented Import Enterprise Journal jobs from running successfully for customers using basic authentication in NetSuite to connect to Financial Consolidation and Close.

Important:

To apply this fix, you need to re-enter your basic authentication credentials in NetSuite. For instructions, see [Using Basic Authentication to Connect to Financial Consolidation and Close](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0212112442.html).

## Version 25.1 {#subsect_56104713456}

## March 18, 2025 {#bridgehead_84104731548}

The initial version of the Close Management and Consolidation Sync SuiteApp has been released. For information about installing and configuring the SuiteApp, and about the functionality of the SuiteApp, see [Close Management and Consolidation Sync Installation and Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_98111940878.html).

Before you start installing and configuring the Close Management and Consolidation Sync SuiteApp, read the following information:

-   The Close Management and Consolidation Sync SuiteApp requires installation of the NetSuite EPM Connector SuiteApp in your NetSuite account. For instructions on the installation and setup of NetSuite EPM Connector, see [NetSuite EPM Connector Installation and Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0095112426.html).
    
-   After installing the NetSuite EPM Connector SuiteApp, the **NetSuite EPM** tab appears in your NetSuite account. If you then install the Close Management and Consolidation Sync SuiteApp, the **NetSuite EPM** tab will contain the **Close Management and Consolidation** navigation menus for the SuiteApp.
