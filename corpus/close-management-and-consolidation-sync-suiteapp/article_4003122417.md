The Close Management and Consolidation Sync SuiteApp includes predefined saved searches that you can use to load data and metadata from NetSuite to your Close Management and Consolidation. The saved searches are listed in the following groups:

-   **FCCS - Metadata Saved Searches**
    
    The following table shows the names and IDs of the saved searches included in this group:
    
    | **Saved Search Name** | **Saved Search ID** |
    | --- | --- |
    | FCCS Sync (Metadata) Balance Sheet Accounts | customsearch\_nsfc\_sync\_acbs |
    | FCCS Sync (Metadata) Class | customsearch\_nsfc\_sync\_clss |
    | FCCS Sync (Metadata) Customer | customsearch\_nsfc\_sync\_cust |
    | FCCS Sync (Metadata) Department | customsearch\_nsfc\_sync\_dept |
    | FCCS Sync (Metadata) Income Statement Accounts | customsearch\_nsfc\_sync\_acis |
    | FCCS Sync (Metadata) Item | customsearch\_nsfc\_sync\_item |
    | FCCS Sync (Metadata) Location | customsearch\_nsfc\_sync\_loc |
    | FCCS Sync (Metadata) Subsidiary | customsearch\_nsfc\_sync\_sub |
    | FCCS Sync (Metadata) Vendor | customsearch\_nsfc\_sync\_vend |
    
-   **Miscellaneous Saved Searches**
    
    The following table shows the name and ID of the saved search included in this group:
    
    | Saved Search Name | Saved Search ID |
    | --- | --- |
    | FCCS Job Execution Search | customsearch\_job\_nsfc\_execution |
    

To use the saved searches included in the Close Management and Consolidation Sync SuiteApp, you need to create them in NetSuite for your integration with Close Management and Consolidation. You can then review or customize the saved searches in NetSuite. For information, see [Managing the Close Management and Consolidation Saved Searches](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_5122158780.html).

To create custom saved searches to use with your Close Management and Consolidation Sync, see the following help topics:

-   [Creating Custom Saved Searches for Financial Consolidation and Close](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0213124037.html)
    
-   [Creating Custom Saved Searches from Close Management and Consolidation Sync Record Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0213124214.html)
