You need to assign the FCCS Integration role to an existing or new user that will be used for the integration with your Close Management and Consolidation. You also need to set up the user properly in NetSuite.

#### To set up an integration user record:

1.  Go to _Lists > Employees > Employees_.
    
2.  Click **Edit** next to the employee you want to use with Close Management and Consolidation Sync.
    
    Important:
    
    Make sure the employee you choose for the integration is an active employee. The integration won't work if the employee has been disabled or removed.
    
3.  In the **Subsidiary** field, select the top-level parent subsidiary.
    
    Note:
    
    The top-level parent subsidiary selection ensures that searches return all data. If you can't select the top-level parent subsidiary, go to _Setup > Users/Roles > Manage Roles_ to customize the **FCCS Integration** role or your custom role, and select **All** in the Subsidiary Restrictions section.
    
4.  Click the **Access** subtab.
    
5.  In the **Role** column, select **FCCS Integration**, and click **Add**.
    
    For information about customizing the role you want to use for the integration, see [Customizing the FCCS Integration Role](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0212114843.html).
    
6.  Click **Save**.
    

Note:

This employee record isn't used by the employee to log in to NetSuite. It's used by the Close Management and Consolidation Sync SuiteApp to integrate with your Close Management and Consolidation.

Important:

Check that the restrictions on the File Cabinet folders are set correctly for the integration user. For instructions, see [Restricting Access to File Cabinet Folders](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N542073.html).

If you need to create a new user record for the integration, follow instructions in the NetSuite Help Center topic [Adding an Employee](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N894212.html). Then, set up the record as described in this help topic.
