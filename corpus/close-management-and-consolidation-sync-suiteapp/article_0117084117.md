The Close Management and Consolidation Sync SuiteApp provides a template with tasks to streamline the setup of Task Manager in Oracle Cloud Enterprise Performance Management. You can customize the template and import it to Task Manager.

For detailed information about Task Manager in Oracle Cloud Enterprise Performance Management, see the Oracle Help Center topic [Managing Task Manager](https://docs.oracle.com/en/cloud/saas/financial-consolidation-cloud/agfcc/tm_managing_task_manager.html).

#### To download and import the template for Task Manager setup:

1.  In NetSuite, go to NetSuite EPM > Close Management and Consolidation > Integration Artifacts.
    
2.  Click the **Templates** subtab.
    
3.  Click **Download** to save the `Accounting Monthly Task Template - Task Import.csv` template to your disc.
    
    Important:
    
    Make sure you update the template before importing so the values correspond to your Financial Consolidation and Close environment setup.
    
4.  In your Close Management and Consolidation application, click the **Navigator** icon ![This icon takes you to the main menu in your NetSuite EPM Close Management and Consolidation application.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/CloseManagementAndConsolidation/NSFCMenuIcon.png), and then click **Task Manager**.
    
5.  Click the **Templates** tab ![This icon lets you access task templates in your Financial Consolidation and Close environment.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/CloseManagementAndConsolidation/NSFCTaskTemplates.png) on the left, and import the customized template. For instructions, see [Importing Tasks into Templates](https://docs.oracle.com/en/cloud/saas/financial-consolidation-cloud/agfcc/cm_tasks_import_to_templates.html).
    
    For detailed information about working with task templates in Oracle Cloud Enterprise Performance Management, see the Oracle Help Center topic [Managing Task Templates](https://docs.oracle.com/en/cloud/saas/financial-consolidation-cloud/agfcc/cm_templates_managing.html).
    

Note:

With every new version of the Close Management and Consolidation Sync SuiteApp, you may need to repeat the process of downloading, customizing, and re-attaching the template provided with the SuiteApp.
