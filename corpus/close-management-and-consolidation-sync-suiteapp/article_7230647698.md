To make sure you have configured Close Management and Consolidation Sync properly, you can use a checklist of tasks to help you quickly set up any missing features. To access the checklist, go to NetSuite EPM > Close Management and Consolidation > Configuration Checklist. You need to complete each task on the checklist. You can also use this checklist to validate your current Close Management and Consolidation Sync setup.

For details on the checklist, refer to the following table:

| NetSuite Column Label | Description |
| --- | --- |
| Feature | The list of Close Management and Consolidation Sync features to configure. |
| Status | The configuration status for each feature can be one of the following:
-   If configured correctly, the feature is denoted with a green check mark icon ![A green tick icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/CloseManagementAndConsolidation/NSFCGreenTick.png) and the status is **Success**.
-   If not configured, or configured incorrectly, the feature is denoted with a red cross icon ![A red cross icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/CloseManagementAndConsolidation/NSFCRedCross.png) and the status is **Failed**.
-   Features where you should check the configuration are denoted with a dash ![A dash icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteEPM/CloseManagementAndConsolidation/NSFCDash.png).

 |
| Link | Clicking the **View** link for each feature takes you to the NetSuite page where you can configure the feature. |
| Instruction | This column shows relevant information about what you need to do to configure a particular Close Management and Consolidation Sync feature properly. |

For your convenience, you can access the checklist also through the [Close Management and Consolidation Sync Checklist Portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0221032717.html).
