Close Management and Consolidation Sync provides a sample script file `pi_journal_entry_v1.js` to facilitate import of journal entries from Financial Consolidation and Close into NetSuite. You can customize the script file in NetSuite to better suit your needs. To use the script file with Close Management and Consolidation Sync, you need to add it as a plug-in script to an Import Enterprise Journal job in NetSuite. For information about setting up the job, see [Import Enterprise Journal in Close Management and Consolidation Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0122054649.html).

For detailed information about Enterprise Journals in Oracle Cloud Enterprise Performance Management, see the Oracle Help Center topic [Managing Enterprise Journals](https://docs.oracle.com/en/cloud/saas/financial-consolidation-cloud/agfcc/ent_journals_managing_journals.html).

#### To import journal entries into NetSuite:

1.  In NetSuite, go to NetSuite EPM > Close Management and Consolidation > Integration Artifacts.
    
2.  On the **Plugin Scripts** subtab, click **Download** to save the `pi_journal_entry_v1.js` script file to your disc.
    
    If needed, use any plain text editor, for example Notepad++, to open and customize the script file.
    
3.  Go to _Customization > Plug-ins > Plug-in Implementations_.
    
4.  Click **New Plug-in Implementation**.
    
5.  Click the plus (+) sign to upload the script file, and then click **Save**.
    
    Important:
    
    Make sure you're uploading a file with the .js extension.
    
6.  Click **Create Plug-in Implementation.**
    
7.  From the list of plug-in types, click **NSFC | PI Job Post Process**.
    
8.  In the **Name** field, enter a name for your custom plug-in script.
    
9.  Set the Status field to **Released**.
    
10.  (Optional) Set the Log Level field to **Debug**.
     
     Note:
     
     You should use **Debug** only during implementation. For production, you should use **Error**.
     
11.  Click **Save**.
     
12.  To customize the script file:
     
     1.  Go back to _Customization > Plug-ins > Plug-in Implementations_.
         
     2.  Locate the `pi_journal_entry_v1.js` script file in the displayed list.
         
         Tip:
         
         If NetSuite displays a long list of plug-in scripts, you can narrow the list by doing the following:
         
         1.  Expand the Filters area if the filters aren't displayed.
             
         2.  From the **Script File** filter, select the script file name.
             
         
     3.  In the **Script** column, click the link to the script file details.
         
     4.  To update the script file directly in NetSuite, in the Media item section, click **Edit** next to the script file name. When finished, click **Save** to submit your changes.
         
13.  Add the plug-in script to an Import Enterprise Journal job in NetSuite:
     
     1.  Go to NetSuite EPM > Close Management and Consolidation > Manage Jobs.
         
     2.  On the Close Management and Consolidation: Manage Jobs page, do one of the following:
         
         -   In the list of jobs, click **Edit** next to the Import Enterprise Journal job of your choice.
             
         -   If you don't see the job in the list, click the **Add Job** button, and follow steps 3 through 6 in [Adding a Job in Close Management and Consolidation Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_54163337626.html).
             
     3.  Click the **Options** subtab.
         
     4.  From the **Post-Processing Plug-ins** list, select the created custom plug-in script.
         
     5.  Click **Save**.
         
14.  Go back to NetSuite EPM > Close Management and Consolidation > Manage Jobs.
     
15.  In the displayed list, locate the Import Enterprise Journal job with the attached plug-in script, and then click **Execute**.
     
     To see the newly imported journal entries, go to Transactions > Financial > Make Journal Entries > List.
     

To find detailed information about the plug-in script status or errors, you can access job execution logs in NetSuite. See [Viewing and Troubleshooting Job Execution Logs in Close Management and Consolidation Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_9130119275.html).

Note:

With every new version of the Close Management and Consolidation Sync SuiteApp, you may need to repeat the process of downloading, customizing, and re-attaching the sample script file provided with the SuiteApp.
