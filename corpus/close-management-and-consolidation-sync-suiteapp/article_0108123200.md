If you want to use a saved search provided by the SuiteApp, you need to create it in NetSuite.

#### To create a Close Management and Consolidation Sync saved search:

1.  In NetSuite, go to NetSuite EPM > Close Management and Consolidation > Manage Saved Searches.
    
2.  In the upper-right corner of the page, click **Create Default Saved Searches**.
    
3.  From the **Saved Search Group** list, select the saved search group you want to view. The available options include the following:
    
    -   **FCCS - Metadata Saved Searches**
        
    -   **Miscellaneous Saved Searches**
        
4.  Check the **Select** box next to the saved search you want to create.
    
    Note:
    
    You can only select a saved search that is in the **Not Created** status. If you want to select a saved search that is in the **Created** status, you need to recreate it as described in the help topic [Recreating a Close Management and Consolidation Sync Saved Search](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0114020606.html).
    
    Tip:
    
    To check the boxes for all saved searches in the **Not Created** status, click the **Mark All** button. To clear the boxes for all the saved searches in the **Not Created** status, click the **Unmark All** button.
    
5.  Click **Submit**.
    
    In the list of saved searches, the status of the saved search changes to **Created**.
    

You can click the created saved search to review or customize it. To customize the saved search, see the help topic [Customizing a Close Management and Consolidation Sync Saved Search](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0114020746.html).
