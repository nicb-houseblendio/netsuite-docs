This topic lists features you need to turn on when using the Effective Date Pricing SuiteApp. If any of these features is turned off, price updates won't be processed.

| Feature | Notes |
| --- | --- |
| Multiple Currencies | All supported currencies can be updated. |
| Quantity Pricing | All supported quantity price levels can be updated. |
| Multiple Prices | All supported price levels can be updated. |
| Custom Records | \- |
| Client SuiteScript | \- |
| Server SuiteScript | \- |
