The Price Detail Update page in the Effective Date Pricing SuiteApp lets you specify the new item price for the price update. You can specify the new price for the update type you created in the price update record. The Price Update section displays the information about the price update record along with the status and price update ID. For more information about price update records, see [Update Types for Creating Price Update Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1516009562.html).

Refer to the following topics for information about how to set a price detail update on each update type:

-   [Creating a Price Detail Update for Item Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1521727587.html)
    
-   [Creating a Price Detail Update for Item Category Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1521727688.html)
    
-   [Creating a Price Detail Update for Customer Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1523469360.html)
    
-   [Creating a Price Detail Update for Customer Group Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1523469385.html)
    

You can access the Price Detail Update page after saving the price update record. The **New Price Detail Update** button becomes available in the **Prices** subtab.

Note:

You can edit or delete a price detail update only if the Price Update status is Not Started.
