This dataset provides details for item pricing, and lets you monitor pricing and margin trends over a specified time period. Use this dataset to focus on pricing problems so you can make the necessary adjustments right away. Prices include line-level and header-level discounts.

The record includes the following fields:

-   Item Name
    
-   Current Base Price
    
-   Estimated Average Cost in Period
    
-   Average Cost Change %
    
-   Average Profit Margin in Period
    
-   Profit Margin Change %
    
-   Target Profit Margin %
    
-   Margin Gap
    
-   Sell-Through Rate in Period
    
-   Sell-Through Rate Change %
    
-   Units Sold in Period
    
-   Revenue in Period
    
-   Revenue Change %
    

Revenue is based on the base currency of the selected parent company or subsidiary.

## Dataset Configuration {#subsect_89143831011}

The item-level pricing dataset combines fields from one record type and one criteria field. To edit the dataset, see [Defining a Dataset](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544122173.html).
