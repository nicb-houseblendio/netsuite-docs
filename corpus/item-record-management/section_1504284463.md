Use the following procedure to enter shipping details. These fields are available only if you use Multiple Shipping Routes.

#### To enter shipping details:

1.  Select a default shipping **Carrier** for the item.
    
2.  In the **Shipping Methods** list, select the shipping methods allowed when adding the item to a sales order. You can override the allowed shipping methods and enter any shipping method when you're fulfilling an order.
    
3.  In the **Default Shipping Method** list, select the shipping method to display by default when adding this item to a sales order. You can override the default and allowed shipping methods when you're fulfilling an order For more information, see [Setting a Default Shipping Method Per Item](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1263649.html).
