This dataset provides details for transaction lines from invoice, cash sale, cash refund and credit memo transactions. Use this dataset to analyze sales pricing by transaction, price level, subsidiary, amount, and other options.

The record includes the following fields:

-   Calculated Rate
    
-   Date
    
-   Description
    
-   Expected Amount
    
-   Item
    
-   Net Amount
    
-   Price Level
    
-   Quantity
    
-   Subsidiary
    
-   Transaction
    
-   Trans Rate
    
-   Trans Type
    
-   Variance Amount
    

This template is not based on an existing saved search.

## Dataset Configuration {#T_change_me_3}

The Sales Pricing Overview dataset combines fields from one record type and one criteria field. To edit the dataset, see [Defining a Dataset](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1544122173.html).

The template is configured as follows:

| Root Record Type | Joined Record Types | Custom Formula Fields | Data Grid | Criteria Filters |
| --- | --- | --- | --- | --- |
| PriceLevel | PriceLevelLineItem | (none) | The following record fields are included in the dataset:
-   Calculated Rate
-   Date
-   Description
-   Expected Amount
-   Item
-   Net Amount
-   Price Level
-   Quantity
-   Subsidiary
-   Transaction
-   Trans Rate
-   Trans Type
-   Variance Amount

 | The following criteria is used to filter the dataset:

-   Subsidiary joined with Price Level

 |
