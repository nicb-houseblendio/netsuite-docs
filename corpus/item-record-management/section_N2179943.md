When you're viewing at item records, you can see related transactions and other data about the item.

-   Click the Related Records subtab to see transactions related to the item. You can filter the list by transaction type.
    
-   Click the Communications subtab to view or add user notes for tracking item details.
    
-   In the System Information subtab, click the System Notes subtab to view automatic notes NetSuite enters to track updates to fields on the item record. You can filter the list of notes by selecting a field.
    
    Updates to the following fields are tracked:
    
    -   Description
        
    -   Display Name
        
    -   Expense Account
        
    -   Handling Cost
        
    -   Income Account
        
    -   Liability Account
        
    -   Deferred Revenue Account

    -   Amortization Period
        
    -   Drop Ship Item
        
    -   Special Order Item
        
    -   Featured Item
        
    -   Inactive
        
    -   Is VSOE Bundle?
        
    -   Display in Web Site
        
    -   Product
        
    -   Taxable

    -   Item Weight
        
    -   Preferred Stock Level
