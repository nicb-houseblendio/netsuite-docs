Note:

Enable the Matrix Items feature before mapping additional lot or serial fields to specific items using the **Item-Element Mapping** button. For more information about how to enable Matrix Items feature, see [Matrix Items](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2227654.html).

Use the following procedure to map additional lot or serial fields to specific items.

#### To map additional lot or serial fields to selected items:

1.  Go to Lists > Lot Auto Numbering > Additional Lot/Serial Fields.
    
2.  Click **Edit**.
    
3.  Click the **Item-Element Mapping** button.
    
4.  In the popup window, do one of the following to select items for mapping:
    
    -   From the **Items** list, select the items to which you want to map the elements.
        
    -   If you have a saved search to select items, you can use the saved search. Choose the **Select Items Using Saved Search** radio button and then select a saved search from the **Saved Search for Selecting Items** list.
        
        Note:
        
        The **Saved Search for Selecting Items** list only shows searches not locked by other SuiteApps.
        
5.  In the **Elements** sublist, make the following selections:
    
    1.  From the **Element** list, select the item number field that you want to use as additional lot or serial field.
        
        To create item number field, see [Create Item Number Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162798687226.html).
        
    2.  From the **Purchase Order** list, select the applicability of the element in a purchase order.
        
    3.  From the **Work Order** list, select the applicability of the element in a work order.
        
    4.  Click **Add**.
        
    5.  To add more fields, repeat steps a to d.
        
6.  Click **Submit**.
    
    A banner shows your mapping progress. When it's complete, the banner provides you a link to see the mapping report with results and any item-mapping error messages.
    
    Depending on the system resources and concurrency limit, you may face delay in item element mapping appearing on the item record.
    
    Depending on the selection in the purchase order and work order columns, the additional lot and serial fields appear in the custom Inventory Detail popup window.
    

You can also map elements to an item from the **Item Additional Fields** sublist in **Lot/Serial Numbering** subtab of the item record.

## Map Additional Lot and Serial Fields Using CSV Import {#bridgehead_162799130493}

You can use the CSV import feature to map additional lot and serial fields with items. The import type is **Custom Records** and record type is **Item Additional Fields**. When using CSV import, you must:

-   Choose **Add** as the **Data Handling** option.
    
-   Check the **Run Server SuiteScript and Trigger Workflows** box.
    

For more information about the CSV import feature, see [CSV Imports Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N342646.html).

### Guidelines for Mapping Additional Lot and Serial Fields to Matrix Items {#bridgehead_162804654109}

When mapping additional lot and serial fields to matrix items, note the following:

-   When you map additional lot and serial fields to matrix items using CSV import and include the parent item in the import, the subitems are automatically mapped.
    
-   For matrix items, the additional lot or serial fields defined in **Item Additional Fields** sublist of the parent item are propagated to the child items.
    
-   You can use CSV import to map an item's lot or serial info only for matrix items and subitems that already exist. CSV import can't map info for parent-child relationships that weren't created before the import.
    
-   When you map a parent matrix item using CSV import, the SuiteApp can map up to 499 child items.
