In NetSuite Advanced Pricing, you can create price rules to group items for faster price updates and to sell items at different prices.

Note:

You can only create, edit, or delete price rules if you have Administrator permissions. This restriction ensures that pricing data remains secure and accurate.

#### To create a price rule for Advanced Pricing:

1.  Make sure Advanced Pricing is enabled (see [Enabling Advanced Pricing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_9154128713.html)).
    
2.  Go to Lists > Pricing > Price Rules > New.
    
3.  In the **Name** field, enter a name for the price rule.
    
4.  In the **Description** field, enter a description that will let you easily identify this rule in a list.
    
5.  To make this rule date-specific, click **Select Dates.**
    
    1.  In the **Start Date** field, select a date for this price rule to take effect.
        
    2.  In the **End Date** field, select a date for the price rule to become inactive.
        
6.  From the list in the **Price Level** field, select a price level.
    
    Tip:
    
    To create a new price level, click the + sign beside the field to display the Price Level pop-up. For more information about setting up price levels, see [Setting Up Price Levels in Advanced Pricing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_6103534687.html).
    
7.  (Optional) If this rule is a work in progress, check the **Inactive** box. When you're ready to activate the rule, see [Editing a Price Rule](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_2104514852.html).
    
8.  (Optional) To make this rule applicable only to specific customers or customer groups, on the **Customers** subtab, choose **Apply Only to Selected Customers**.
    
    -   To add a customer, from the list on the line, select a customer, and then click **Add**.
        
    -   To add multiple customers, click **Add Multiple**, then click each customer name to select it. When finished, click **Add Customers**.
        
    -   To specify a customer group, click **Customer Groups**. From the list on the line, select a customer group, and then click **Add**.
        
9.  (Optional) To make this rule applicable only to specific items or item collections, on the **Items/Item Collections** subtab, choose **Apply Only to Selected Items**.
    
    -   To add an item collection, from the **Item Collections** list on the line, select an item collection, and then click **Add**.
        
    -   To add a single item, from the **Item** list on the line, select an item, and then click **Add**.
        
    -   To add multiple items, click **Add Multiple**. If desired, use the list at the top of the Add Multiple Items box to filter by item type. Click each item name to select it. When finished, click **Add Items**.
        
    
    Note:
    
    Only items that have a price defined for the item at the selected price level are available to select.
    
10.  Click **Save**.
