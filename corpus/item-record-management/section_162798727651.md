Use the Lot/Serial Number Format Elements page to create additional lot and serial number format elements.

#### To create a lot or serial number format element:

1.  Go to Lists > Lot Auto Numbering > Lot/Serial Number Format Elements > New.
    
2.  From the **Item Number Field**, click the double arrow to list the item number fields, and then select the item number field.
    
3.  (Optional) In the **Description** field, enter the description for the lot or serial number format element.
    
4.  (Optional) For date elements such as **Expiration Date**, **Receipt Date**, **Manufacturing Date, and custom date elements**, select the format from the **Date Format** list. The SuiteApp will show dates in that format. By default, the format YYMMDD is used to display dates.
    
    Following are the available date format types:
    
    -   YYMMDD
        
    -   DDMMMYYYY
        
    -   DDMMYY
        
    -   DDMMYYYY
        
    
    When the **Date Format** field is empty, the SuiteApp considers the default YYMMDD format for the date elements. Also, for the custom date elements, you can select the required date format from the **Date Format** field.
    
5.  Click **Save**.
