Use the Lot/Serial Number Formats page to create lot and serial number formats and apply the format to items.

#### To create a lot or serial number format:

1.  Go to Lists > Lot Auto Numbering > Lot/Serial Number Formats > New.
    
2.  In the **Name** field, enter the name of the lot or serial number format.
    
3.  In the sublist, add elements.
    
    1.  From the **Element** list, select an element.
        
        Note:
        
        To create a serial number format for serialized items, you must add **Sequence Number** as one of the format element.
        
    2.  (Optional) If you select **Text** element, to add text to the lot or serial number, enter the text in the **Text** field.
        
    3.  Click **Add**.
        
    4.  To add more elements, repeat steps a to c.
        
4.  (Optional) To see a preview sample of the lot or serial number generated from the selected elements, click **Preview**.
    
    Note:
    
    **Preview** option is available only when NetSuite is used in English (US) language.
    
5.  Click **Save**.
