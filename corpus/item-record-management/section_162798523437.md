Install the Lot Auto Numbering SuiteApp from the SuiteApp Marketplace. For more information, see [Installing from the SuiteApp Marketplace](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1539799323.html).

Lot Auto Numbering is a managed SuiteApp that automatically updates whenever enhancements or new features are added.

Note:

Do not use the AutoLot\_Custom\_Role role delivered with the SuiteApp. The role is provided for internal processing and you must not use the role.

## Prerequisites for Lot Auto Numbering {#bridgehead_162798575509}

The Lot Auto Numbering SuiteApp is designed and tested mainly for use with NetSuite OneWorld. For more information about NetSuite OneWorld, see [Introduction to NetSuite OneWorld](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N266468.html).

To use the Lot Auto Numbering SuiteApp, an administrator must enable the features described in the following table.

| Subtab | Feature Name |
| --- | --- |
| Items & Inventory | 
-   Advanced Bin/Numbered Inventory Management
-   Lot Tracking (check this box to use the SuiteApp for generating lot numbers)
-   Serialized Inventory (check this box to use the SuiteApp for generating serial numbers)

 |
| SuiteCloud | 

-   Custom Records
-   Client SuiteScript
-   Server SuiteScript
-   SuiteCloud Development Framework

 |

For more information, see [Enabling Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N232138.html).

Important:

Make sure that you do not have existing additional lot or serial fields with any of the following names:

-   Heat Code
    
-   Manufactured Date
    
-   Supplier Lot Number
    
-   Country of Origin
    

If you have existing fields with any of the above names, you must rename them.

## Required Inventory Features {#bridgehead_0803010426}

Before you install You'll need to enable certain NetSuite inventory features based on your business needs. Go to Setup > Company > Setup Tasks > Enable Features. On the **Items & Inventory** subtab, enable one or both of the following features:

-   **Lot Tracking**\- Enable this feature to generate auto lot numbers.
    
-   **Serialized Inventory**\- Enable this feature to generate auto serial numbers for individual serialized items.
    

When you install the SuiteApp, it detects and configures itself based on the features you've enabled in your NetSuite account. If only one of these features is enabled at the time of installation, the SuiteApp configures itself to support that feature only.

For example, if you enable only the Serialized Inventory feature before installing the SuiteApp, the SuiteApp provides only auto serial number generation. If you also want to use the Lot Tracking feature, the SuiteApp won't support it. In that case, you'll need to uninstall and reinstall the SuiteApp after enabling Lot Tracking.

Note:

To avoid reinstalling, make sure you enable both the Lot Tracking and Serialized Inventory features in your NetSuite account before installing the Lot Auto Numbering SuiteApp.

## Roles and Permissions to Use the Lot Auto Numbering SuiteApp {#bridgehead_162798594701}

Administrators can create new roles or customize existing roles to use the Lot Auto Numbering SuiteApp. For more information, see [Assigning Roles to an Employee](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N897798.html) and [Customizing or Creating NetSuite Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N285937.html).

The following table provides minimum access levels for different permissions required to use the Lot Auto Numbering SuiteApp.

| Subtab | Permissions | Minimum Access Level |
| --- | --- | --- |
| Transactions | Find Transaction | View |
| Lists | Custom Record Entries | Full |
| Documents and Files | View |
| Locations | View |
| Items | Edit |
| Setup | Custom Entity Fields | Full |
| Custom Fields | View |
| Custom Item Number Fields | Full |
| Set Up Company | View |
| SuiteScript | View |
| SuiteScript Scheduling | Full |
| Custom Record | Auto Format Element Mapping | View |

If your role doesn't have Edit access for Items permission, the following procedure helps to update the custom roles with Execute As Role for deployment. Follow the steps below to update the role in deployments:

#### To Update Custom Roles for Deployments:

1.  Go to Customizations > Scripting > Scripts.
    
2.  On the ALN UE Transaction script record, click **Deployments** . The script id for this record is customscript\_aln\_ue\_transaction.
    
3.  On the customdeploy\_aln\_ue\_txn link record, click **Edit**.
    
4.  From the **Execute As Role** dropdown list, select **AutoLot\_Custom\_Role**.
    
5.  Click **Save**.
    
6.  Perform the steps 3 to 5 for the below deployments:
    
    -   customdeploy\_aln\_ue\_transaction
        
    -   customdeploy\_aln\_ue\_transaction\_po
        
    -   customdeploy\_aln\_ue\_inbound
        
    -   customdeploy\_aln\_wo\_cmplt
        

### Center Category and Center Types {#bridgehead_162798631161}

For a custom role, you can add the Lot Auto Numbering center category and links. Use the following information when creating the center category:

-   **Center category label** - Label the center category as Lot Auto Numbering.
    
-   **Center type** - Select the desired center type.
    
-   **Center tab** - Select the desired center tab.
    
-   **Links** - Add the links described in the following table.
    
    | Link | Label |
    | --- | --- |
    | Lot/Serial Number Format | Lot/Serial Number Formats |
    | Lot/Serial Number Format Element | Lot/Serial Number Format Elements |
    | Additional Lot/Serial Fields | Additional Lot/Serial Fields |
    

For more information, see [Creating Center Categories](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2890916.html) and [Creating Center Links](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2891250.html).

### Multi-Language Support for Lot Auto Numbering SuiteApp {#subsect_28101850716}

If you enable the **Multi-Language** feature on the Enable Features page after installing the Lot Auto Numbering SuiteApp, follow the below procedure.

### Running a Script for Supporting Multi-Language {#bridgehead_69112558615}

If you have enabled the multi-language feature, you must run the **ALN Multi Language Support Suitelet** script. This step ensures that the lot and serial number format elements available as part of the SuiteApp are also updated for translation.

#### To run a script for supporting Multi-Language: {#procedure_0829112400}

1.  Go to Customization > Scripting > Script Deployments.
    
2.  On the **ALN Multi Language Support Suitelet** script deployment, click **View**.
    
3.  On the deployment page, click the hyperlink in the **URL** field.
