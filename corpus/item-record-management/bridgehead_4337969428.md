If you write a custom script to override a standard NetSuite function, the script can trigger a cost recalculation. This can cause errors for costing and general ledger postings for transactions associated with the custom script.

Important:

If your custom script accesses or updates inventory transactions in ways you can't do through the user interface, please use extreme caution. The script can negatively impact your inventory costing.

## Best Practice {#subsect_163223469129}

For the preference **Allow Transaction Date Outside of Posting Period**, select **Disallow**. For more information, see [General Accounting Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1385293.html).
