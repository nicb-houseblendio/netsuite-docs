Create additional lot and serial fields that you want to add to your inventory details. You can then map these additional fields to specific items.

#### To create an additional lot or serial field:

1.  Go to Lists > Lot Auto Numbering > Additional Lot/Serial Fields.
    
2.  Click **Edit**.
    
3.  In the sublist, make the following selections:
    
    1.  From the **Element** list, select the item number field that you want to use as an additional lot or serial field.
        
        To create item number field, see [Create Item Number Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162798687226.html).
        
    2.  From the **Purchase Order** list, select how you want the element to apply in a purchase order.
        
        -   **Not Applicable** (default selection)- This field does not display in the **Inventory Detail** popup window.
            
        -   **Optional**\- This field displays as a column but entering a value in it is optional.
            
        -   **Required**\- This field displays as a column and you must enter a value in the column.
            
    3.  From the **Work Order** list, select the way in which the element applies in a work order. To know more about the options, refer to the step b.
        
    4.  Click **Add**.
        
    5.  To add more lot and serial fields, repeat steps a to d.
        
4.  Click **Save**.
    
    The additional lot and serial fields are mapped to all items.
    
    Based on what you select in the purchase order and work order columns, the additional lot or serial fields appear as columns in the **Inventory Detail** popup window.
    

Depending on system resources and concurrency limits, you may experience delays when updating lot or serial records with additional information after saving a transaction.
