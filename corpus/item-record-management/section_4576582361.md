To print transactions with customer part numbers, make sure you set up the required features and custom forms. Review the following topics on printing transactions:

-   [Prerequisites for Customer Part Number](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4575970034.html#bridgehead_4575971271)
    
-   [Setting Up Custom Forms for Printing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4576003899.html)
    
-   [Printing a Sales Order](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1221008.html)
    
-   [Printing an Invoice](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1242104.html)
    

With advanced print templates, you can print transactions with customer part numbers in PDF format. Following standard printing limitations, long names or labels might not fit completely in a column.

![CPN Printout](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/ItemRecordManagement/CPNprintout.png)

On the printout, the **Customer Part Number** column shows up to the right of the **Item** column.

If you want to move the columns, check the instructions for customizing print templates to add the **Customer Part Number** column. For more information, see [Setting Up Custom Forms for Printing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4576003899.html).
