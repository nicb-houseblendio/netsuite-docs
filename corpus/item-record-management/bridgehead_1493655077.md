You can use multiple prices and currencies if you use the Multiple Prices or Multiple Currencies features.

#### To use multiple prices:

1.  Enter a base price for this item to use as the default for transactions.
    
2.  Enter alternative prices for this item. You can assign these price levels to certain customers, like privileged or club members.
    
    You can rename and create new price levels at _Setup > Accounting > Setup Tasks > Accounting Lists_. Select **Price Levels** in the **Type** field.
    
3.  Enter an online price to set the default item price in your web store.
    
4.  If you use quantity pricing, set the number of items needed for a new price break in the **Qty** fields. Then, enter the corresponding price per item below it.
    

#### To use multiple currencies:

1.  In the **Currency** column, select a currency.
    
2.  In the **Amount** column, enter a price for this assembly in that currency.
    
3.  Click **Add**.
    
4.  Repeat these steps to add prices for more currencies.
    
    You can only enter one price per currency.
    
    To add new currencies, go to _Lists > Accounting > Currencies > New_.
    

#### To use multiple prices and multiple currencies:

1.  In the **Price Level** column, select a price level.
    
    You can rename and create new price levels at _Setup > Accounting > Setup Tasks > Accounting Lists_. Select **Price Levels** in the **Type** field.
    
    If you've set a default discount percentage for a price level, it shows up in the **Default Discount %** column.
    
2.  In the **Currency** column, select a currency for this price level.
    
    To add new currencies, go to _Lists > Accounting > Currencies > New_.
    
3.  In the **Amount** column, enter a price for this price level and currency.
    
4.  Click **Add**.
    
5.  Repeat these steps to add prices for more price levels and currencies.
    

## Inclusive or Exclusive Taxes {#bridgehead_1493654934}

This information is specific to NetSuite accounts (except US and Canada) that do not use the Advanced Taxes feature. The item record has a **Prices Include Tax** box that lets you save the item price as either tax-inclusive or tax-exclusive.

To save the base price as tax-inclusive, check this box.

To save the base price as tax-exclusive, clear this box.
