On assembly and inventory item records, you can add the customer part number and the associated customer.

You can set up customer part numbers directly on the item record or import using CSV files, scheduled scripts, or web service.

Review the following guidelines for setting up customer part numbers on item records and through import:

-   Valid characters for the customer part number name:
    
    -   Alphanumeric
        
    -   Hyphen (-)
        
    -   Underscore (\_)
        
-   You can't use inactive customer or item records to set up customer part numbers.
    
-   For accounts with subsidiaries:
    
    -   The item and customer both need to belong to the same subsidiary.
        
    -   The customer part number and customer combo for each item has to be unique within each subsidiary.
        
    -   If the **Include Children** option is turned on for the item, the customer needs to be in the same subsidiary as the parent and its children.
        
        If you turn off **Include Children** on the item record, make sure the subsidiaries for the item and customers used for part numbers match.
        
    -   For matrix subitems, the subitem and customer need to be in the same subsidiary as the parent item.
        

#### To add customer part numbers to item records:

1.  Go to _Lists > Accounting > Items_.
    
2.  On the Items list, click **Edit** to open an existing item record.
    
    Click **New Item** to create an item record. For more information, see [Creating Item Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2166469.html).
    
    Note:
    
    Select **SCM Assembly Item - Customer Part No.** as your custom form for assembly item records if you want to use customer part number validations for assembly items.
    
3.  On the **Customer Part Number** subtab:
    
    1.  In the **Customer Part Number Name** field, enter the customer part number or code.
        
    2.  In the **Customer** field, select the name of the customer to be associated with the part number.
        
    3.  Click **Add**.
        
4.  Click **Save**.
    
    Each customer part number shows the customer's subsidiary.
    
    The Supply Chain Management SuiteApp currently lets you add up to 2,000 customer part numbers per item record.
    

#### To edit customer part numbers:

1.  Go to the **Customer Part** **Number** subtab.
    
2.  Enter the details in the sublist.
    
    Alternatively, click the Edit link to update details on each customer part number record.
    
    Here's what happens when you update customer part number records that have already been used in transactions:
    
    -   Any changes you make to the customer part number name show up on line items in related transactions.
        
    -   If you change the customer linked to the part number, it creates a mismatch between the customer on the transaction and the part number record.
        
        Don't change the customer when a part number's already been used on a transaction, unless the customer on the transaction was updated.
        

Note:

You can delete item records if none of their customer part numbers have any transactions.

You can delete a customer part number from an item record only if there aren't any transactions linked to that customer part number.

## Import Customer Part Numbers for Items {#bridgehead_4575997153}

You can add customer part numbers for items by importing a CSV file, using scheduled scripts, or using web services.

Refer to the following guidelines for importing customer part numbers for items using a CSV file:

-   When creating your import file, include the following CSV file columns:
    
    | CSV File Column | Value |
    | --- | --- |
    | Item | Enter the Internal ID or Item Name/Number for the item record where you want to add a customer part number. If you use the item internal ID in your CSV file, set the field's Reference Type to **Internal ID** during field mapping. For more information, see [Select Reference Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N349594.html) and [Finding Internal IDs of Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_0416030736.html). |
    | Customer | Enter the Customer ID value for the customer record associated with the customer part number. |
    | Customer Part Number | Enter the customer part number to associate with the item. |
    
    You can add up to 2,000 customer part numbers per item record. For more information, see [Adding Customer Part Numbers to Item Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4575980825.html).
    
-   When using the Import Assistant:
    
    -   For [Step One Scan & Upload File](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N343532.html), select the following:
        
        -   Select **Custom Records** for import type.
            
        -   Select **Customer Part Number** for record type.
            
    -   For [Step Two Import Options](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N344550.html), in the Advanced Options section, select **Standard Customer Part Number Form** as the custom form.
        

For more information, see [Importing CSV Files with the Import Assistant](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N343158.html).
