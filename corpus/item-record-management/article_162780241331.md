The Lot Auto Numbering SuiteApp enables you to define lot and serial numbering formats and select items that require auto numbering. You can also configure additional information such as supplier lot number, sequence number, and manufactured date, and maintain this information in the inventory detail.

The following video gives an introduction to Lot Auto Numbering SuiteApp:

<a id="kaltura_player_139"></a>

The SuiteApp supports lot and serial numbering for both assembly and inventory items.

## Transaction Types {#bridgehead_162807152582}

The SuiteApp autogenerates lot and serial numbers for new lots or serial items that are created within the following transaction types:

-   Purchase order
    
-   Item receipt
    
-   Receive inbound shipment
    
-   Work order completion
    
-   Assembly build
    
-   Outsourced manufacturing
    

Note:

When you install the SuiteApp and provide the required permissions and minimum access levels to your role, a custom Inventory Detail popup window appears during the transaction entry. This custom Inventory Detail popup window lets you use the Lot Auto Numbering SuiteApp features. If the role does not have the required permissions and minimum access levels, you get an alert and the standard Inventory Detail popup window opens.

For more information, read [Roles and Permissions to Use the Lot Auto Numbering SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162798523437.html#bridgehead_162798594701).

## Lot and Serial Number Formats {#bridgehead_162798550720}

Lot and serial number formats are custom numbering formats. You create these formats using lot or serial number format elements. You can assign a single lot number format to one or more items. Similarly, you can assign a serial number format to one or more items.

Once you set up a lot or serial number format for an item, the SuiteApp automatically generates the lot or serial numbers when you enter inventory details.

## Lot and Serial Number Format Elements {#bridgehead_162798527779}

Lot and serial number format elements are used to build lot and serial number formats respectively. There are 17 default number format elements delivered with the SuiteApp. You can create additional lot and serial number format elements using item number fields. For more information, see [Creating Lot and Serial Number Format Elements](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162798727651.html).

Note:

All 17 default lot and serial number format elements are supported as a part of the WMS PO (purchase order) receiving process.

Each number format element used in a lot or serial number format appears as a required field in the Inventory Detail popup window.

The SuiteApp provides the default lot and serial number format elements described in the following table:

| Format Element | Description |
| --- | --- |
| Country of Origin | Country of origin of the lot numbered item, or serialized item. |
| Day | Two-digit day in the transaction date. |
| Expiration Date | Expiration date of the lot numbered item, or serialized item. |
| Heat Code | Heat code for an item. |
| Internal ID | Internal Id of the lot numbered item, or serialized item. |
| Julian Days | Number of days from January 1 in that year to the transaction date. |
| LDY | Last digit of transaction year. |
| Location | Receiving or manufacturing location of the transaction. |
| Manufactured Date | Date of manufacturing of the lot numbered item or serialized item. |
| Month | Two-digit transaction month. |
| Order Number | Purchase order or work order number. |
| Receipt Date | Date of item receipt. |
| Sequence Number | Number uniquely defined on each item record that automatically increments by one for each new lot number. |
| Supplier Lot Number | Lot number received from the supplier. |
| Text | Free format text that can be up to 12 characters in length. |
| YY | Last two digits of the transaction year. |
| YYYY | Last four digits of the transaction year. |

Following are some additional notes on the lot and serial number format elements:

-   For outsourced manufacturing, the SuiteApp derives values for the following elements from the receipt date. For other transaction types, it derives the values from the transaction date:
    
    -   Julian Days
        
    -   Month
        
    -   Day
        
    -   LDY
        
    -   YY
        
    -   YYYY
        
-   For purchase order transactions, the receipt date element will be blank when determining the lot or serial number.
    
-   If you include a lot or serial number format element in a number format, be sure to add that element as an additional lot or serial field, either globally or at the item level.
    
-   The lot and serial number format element names are translatable, except for abbreviations like LDY, YY, and YYYY. However, you cannot translate the description of the lot and serial number format elements.
    
-   For new custom date elements, you'll see a blank value in the **Date Format** column on the Lot/Serial Number Format Elements list page and Lot/Serial Number Format page. You can change the date format by editing the custom date element and selecting required format.
    

## Additional Lot and Serial Fields {#bridgehead_162798558047}

The SuiteApp enables you to configure an item to capture additional lot and serial information and maintain this information in inventory detail. The SuiteApp provides the following default additional lot and serial fields:

-   Country of Origin
    
-   Manufactured Date
    
-   Heat Code
    
-   Supplier Lot Number
    

You can create additional lot and serial fields using item number fields at the global level to apply them to all items. You can also create these fields at the item level to apply them to one item only. These additional lot and serial fields are visible only when you create or edit a transaction. For more information, see [Creating Additional Lot and Serial Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162798764642.html).

Note:

The additional lot and serial fields **Country of Origin** and **Heat Code** are editable.

## Known Limitations {#bridgehead_162809262146}

The SuiteApp has the following known limitations:

-   You cannot import the following using the CSV import feature:
    
    -   Lot and serial number formats
        
    -   Lot and serial number format elements
        
    -   Additional lot and serial fields in inventory detail
        
-   You cannot perform the following operations using SOAP or REST web services:
    
    -   Create or update lot numbered item and serialized item information
        
    -   Create or update additional lot and serial fields
        
    -   Import additional lot and serial fields in inventory detail
