If you enter an item distribution and then backdate a transaction before the distribution, this can cause problems with inventory costing. It can also result in a negative on-hand count for the item in a null location. This is true especially for lot-numbered or serial-numbered inventory.

## Best Practice {#subsect_163223479478}

If you have problems with inventory due to backdating an item distribution, inactivate the item record and then create a new one. For more information, see [Creating Item Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2166469.html).
