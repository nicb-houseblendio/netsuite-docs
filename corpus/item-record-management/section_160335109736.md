You can import price update data into NetSuite using CSV import.

The CSV import process saves time and prevents errors by submitting data in a CSV file. This data can add or update many records at the same time, avoiding the need for manual data entry.

Important:

When importing price update data using CSV import, do not enter an end date for permanent price changes. Permanent price changes are not expected to have end dates. Entering end dates for permanent price changes may cause inconsistent price updates.

For more information and guidelines on importing CSV files, refer to the following help topics:

-   [CSV Imports Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N342646.html)
    
-   [Importing CSV Files with the Import Assistant](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N343158.html)
    
-   [Guidelines for CSV Import Files](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N356211.html)
    

Important:

To ensure all added and updated data using the CSV import are valid, check the **Run Server SuiteScript and Trigger WorkFlows** box. This box shows up when you complete [Step Two Import Options](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N344550.html).
