After creating lot and serial number formats, you can add these formats to items. The **Lot/Serial Numbering** subtab in the item record provides the following settings for adding the lot or serial number formats to items.

## Lot Numbered Items {#bridgehead_0217122555}

The settings applicable to lot numbered items are described in the following table.

| Setting | Description |
| --- | --- |
| Enable Lot/Serial Numbering | Check this box to apply lot autonumbering for lot numbered item. |
| Number Format | Select the lot number format for an item. |
| Initial Sequence Number | If sequence number is part of the lot number format, enter the number from which you want to start the sequence number. |
| Current Lot Sequence Number | Shows the number that will be assigned as part of the lot number in the next transaction. |
| Additional Lot/Serial Fields | Click **View** to open the Additional Lot/Serial Fields page. On the Additional Lot/Serial Fields page, you can set up how custom columns show in the Inventory Details popup window. |
| Item Additional Fields | In this sublist, select additional lot or serial fields that you want to display in the Inventory Detail popup window. Note: When you create a copy of the item, additional lot and serial fields are not copied to the item's copy. |

When you create or update items using the CSV import feature, note the following:

-   Using the CSV import feature, you can add and update the **Item Additional Fields** sublist information.
    
-   If the **Enable Lot/Serial Numbering** field is set to **No**, the **Lot/Serial Number Format** field and the **Initial Sequence Number** field values are ignored.
    
-   If the **Enable Lot/Serial Numbering** is set to **Yes**, but the lot number format does not contain a sequence number, the **Initial Sequence Number** value is ignored.
    
-   When updating an item, if the **Initial Sequence Number** field already has a value, any value for this field in the CSV file is ignored.
    

When importing non lot inventory and assembly items using CSV import, the fields in the **Lot/Serial Numbering** subtab appear on the Field Mapping page. However, any data for these fields is ignored when importing.

## Serialized Items {#bridgehead_0217122634}

The settings applicable to serialized items are described in the following table.

| Setting | Description |
| --- | --- |
| Enable Lot/Serial Numbering | Check this box to apply serial autonumbering for a serialized item. |
| Set Serial Sequence Automatically | Check this box to automatically generate sequence numbering for serial items. By default, it's not checked. If you clear this box, you can enter the initial sequence in the **Starting Sequence Number** field in the **Lot/Serial Inventory Detail** pop-up window. |
| Number Format | Select the serial number format for an item. |
| Initial Sequence Number | Enter the initial sequence number you want to use for the serial items. Note: You can set the serial number sequence for serial items only if you check the **Set Serial Sequence Automatically** box. The initial sequence number you enter appears in the **Starting Sequence Number** field in the **Lot/Serial Inventory Detail** pop-up window. |
| Increase Serial Sequence By | Enter the value you want each new serial number to increase by. For example, enter 1 to increment by one each time, or 5 to increment by five for each new serial number. |
| Last Serial Sequence Number | Displays the last serial number generated for a serial item. For example, if **Increase Serial Sequence By** is set to 5 and the last serial number was 20, the next serial number will be 25. The SuiteApp doesn't use the **Initial Sequence Number** value; it only considers the last serial number to generate the next one. |
| Additional Lot/Serial Fields | Click **View** to open the Additional Lot/Serial Fields page. On the Additional Lot/Serial Fields page, you can configure the display of custom fields in the custom Inventory Details popup window. |
| Item Additional Lot/Serial Fields | In this sublist, select additional lot or serial fields that you want to display in the custom Inventory Detail popup window. Note: When you create a copy of the item, additional lot and serial fields are not copied to the item's copy. |

When you create or update items using the CSV import feature, note the following:

-   The CSV import feature does not add or update the **Item Additional Fields** sublist information.
    
-   If the **Enable Lot/Serial Numbering** field is set to **No**, the **Lot/Serial Number Format** field value is ignored.
    

Note:

If **Sequence Number** element is missing in a number format, you cannot map that format to a serial item.

When importing non serialialized inventory and assembly items using CSV import, the fields in the **Lot/Serial Numbering** subtab appear on the Field Mapping page. However, any data for these fields is ignored when importing.
