You'll need Item number fields to create lot and serial number format elements, and additional lot and serial fields. You can create item number fields from the Item Number Field page. Go to Customization > Lists, Records, & Fields > Item Number Fields > New. When creating an item number field, you must make the following selections on the Item Number Field page:

-   Choose the **All Items** radio button (required for additional lot and serial fields created at the global level).
    
-   Check the **Lots** box (required for additional lot fields created at the global level).
    
-   Check the **Serialized** box (required for additional serial fields created at the global level).
    
-   Make sure the **Default Access Level** list in the **Access** subtab is set to **Edit**.
    

Lot and serial number format elements work with the following item number field types:

-   Check Box
    
-   Date
    
-   Decimal Number
    
-   Free-Form text
    
-   Integer Number
    
-   List/Record
    
-   Percent
    
-   Time of Day
    

Additional lot and serial fields work with the following item number field types:

-   Check Box
    
-   Currency
    
-   Date
    
-   Decimal Number
    
-   Email
    
-   Free-Form text
    
-   Hyperlink
    
-   Integer Number
    
-   List/Record
    
-   Percent
    
-   Phone Number
    
-   Text Area
    
-   Time of Day
    

Note:

After you add an item number field to an additional lot or serial field, do not change the item number field to an unsupported type.

## Edit Item Number Field Name or Type {#bridgehead_162798703421}

If you have to edit the type of an item number field that's part of a lot or serial number format element, check the recommendations in the table below.

| Change in Item Number Field | Recommended Actions |
| --- | --- |
| Additional Lot/Serial Fields Page | Lot/Serial Number Format Page and Lot/Serial Number Format Elements Page |
| --- | --- |
| To a type supported for lot or serial number format element | No action required | Remove the item number field from the lot or serial number format element that uses the item number field and add it back. Also, remove the lot or serial number format element from the lot or serial number format and add it back again. |
| To a type not supported for lot or serial number format element but supported for additional lot and serial fields | No action required | Remove the element from the lot or serial number format and delete the lot or serial number format element. |
| To a type not supported for additional lot or serial fields | Choose from the following options:
-   Remove the item number field from additional lot or serial fields
-   Revert the item number field to the previous type

 | Choose from the following:

-   Remove the element from the lot or serial number format
-   Revert the item number field to the previous type

 |

For an item number field name change, you must update the lot or serial number format element that uses the item number field. Remove the item number field from the lot or serial number format element and add the same item number field again.
