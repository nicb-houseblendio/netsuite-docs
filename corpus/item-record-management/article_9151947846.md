This pivot table gives users a clear view of how your Advanced Pricing strategy is performing over time. The table aggregates the total value of invoiced transactions and breaks them down by each active price rule within a selected date range. With this view, you can:

-   Quickly compare which rules are driving the most revenue
    
-   Identify trends across different pricing tiers
    
-   Make more informed decisions about pricing optimization and sales strategy
    

Note:

Transactions with no price rule applied are included in this view.

This pivot table includes the following rows and measures:

## Rows (Default) {#subsect_5153337261}

| Label | Contents |
| --- | --- |
| Item | Item sold on the transaction line. |
| Transaction | Transaction record reference used for drilldown to the source record. |
| Price Rule | Price rule name. |
| Trans. ID | Unique identifier on the transaction line. |
| Correct Line Amount | Net Amount ÷ Quantity. |
| Quantity | Quantity sold on the transaction line. |

## Measures (Default) {#subsect_30153345266}

| Label | Contents |
| --- | --- |
| Expected Amount (Sum) | Total of the Expected Amounts (Transaction Rate × Quantity). |
| Net Amount (Sum) | Total of the net amounts for all transaction lines (Net Amount = Amount - Posting Discount). |
| Variance Amount (Sum) | Total of the Variance Amounts (Variance Amount = Difference between actual revenue and expected amount). |
