The the Standard Costing feature lets you create inventory cost templates. These templates contain the list of material overheads you want to associate with an inventory item or an assembly item that can be purchased.

If you use the Landed Cost feature, you can include landed cost in your inventory cost templates. For more information, see [Landed Cost](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2416930.html).

Before you create inventory cost templates, you need to define cost categories and other charge for purchase items for your overheads. For each inventory cost template, you can assign only one material or landed cost category that has the % of Total overhead type.

See the following topics to set up these template components:

-   [Creating Cost Categories](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2201059.html)
    
-   [Creating a Landed Cost Item](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2418506.html)
    
-   [Other Charge Items](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2249208.html)
    

#### To create an inventory cost template:

1.  Go to Lists > Accounting > Inventory Cost Template > New.
    
2.  On the Inventory Cost Template page, enter values in the following fields:
    
    -   In the **Subsidiary** field, select the subsidiary to which you want to associate this template.
        
    -   In the **Name** field, enter a unique name for this template.
        
3.  On the **Costs** subtab, select values in the following columns:
    
    1.  In the **Cost Category** column, select the material overhead or landed cost category.
        
    2.  In the **Item** column, select the other charge item for the material overhead or landed cost category.
        
    3.  Click **Add**.
        
        Repeat this step to add more costs to your template.
        
4.  Click **Save**.
    
    On item records that use the standard costing method, you can select an inventory cost template for each location. For more information, see [Setting Up Item Records for Standard Costing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2201836.html).
