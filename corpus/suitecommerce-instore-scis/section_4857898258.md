To complete printer setup for SuiteCommerce InStore (SCIS), you must configure printer settings on the **SCIS Settings** custom record. Enter printer names and set paper sizes for the printers you are using with SCIS. You can also set up automatic printing, so that receipt printing is automatically initiated when an order is submitted.

For step-by-step instructions, read [Setting Up Receipt Printers for SCIS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4298266164.html).

Important:

Printing configuration is required for each location.

Note:

For details about printing checks (outside of SCIS), see [Printing Checks](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1545292.html).
