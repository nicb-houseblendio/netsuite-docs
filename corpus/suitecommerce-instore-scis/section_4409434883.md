SuiteCommerce InStore (SCIS) includes a set of saved searches you can use as reports. The saved searches installed with the SuiteApp are locked. To modify any SCIS saved search you must first make a copy, and then create a customized report for your organization. See the following sections to learn more about SCIS reporting capabilities:

-   [Modifying Included Saved Searches](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4401961202.html)
    
-   [Custom SCIS Sales Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4409437631.html)
    
-   [Publishing Saved Searches to SCIS Users](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4557388463.html)
    
-   [SCIS Audit Log](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4332845108.html)
