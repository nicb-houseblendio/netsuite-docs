## Prerequisites {#subsect_1524162779}

Before you can install SCIS, contact your NetSuite sales rep or account manager. Ensure that you have access to NetSuite Commerce features such as SuiteCommerce InStore and the SuiteCommerce InStore SuiteApp.

## Partner Implementations with Customizations {#subsect_161196016613}

Some SCIS implementations might include installing a SuiteApp or other bundles to customize a setup. If a third-party NetSuite partner handles the implementation, the partner should check if a specific SuiteApp or bundle version is supported in SCIS before applying any customizations.

Partners can confirm if a version is supported by contacting their NetSuite Product representative or Customer Support.

Tip:

Partners should always confirm if a SuiteApp or bundle version is supported for use with SCIS before installing it.

For general information, see [SuiteApp Versions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1526582725.html) and [Viewing the SuiteApp Version History](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1526584029.html).

## First Installation of SuiteCommerce InStore {#subsect_1524163656}

For detailed instructions on installing the SuiteApp, see [Beginning the Installation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1525913096.html).

Note:

After installation, you must configure SCIS for your business needs. Configuration steps include defining SCIS Settings, configuring receipt templates, employee records, item records, cash drawer management settings, and SCIS custom records. For more information about configuration, see [SCIS Configuration](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1488583544.html).

## Managed Bundle Updates and Phased SCIS Release {#subsect_1524171115}

After you've installed the SuiteCommerce InStore SuiteApp in your account, it's updated periodically. Major releases of new features and enhancements occur twice a year. Minor releases can occur every two weeks. Minor releases are typically used to correct issues an to deliver version updates to a set of accounts. Major and minor releases are delivered directly to your account in managed bundle updates.

For more information, see [Managed Bundle Updates of SCIS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1525974944.html).

## SCIS App for iOS (iPadOS) and SCIS App for Windows {#subsect_1525975580}

Depending on the operating system (OS) of the mobile devices you'll use for SCIS, you'll install one of the SCIS app versions on those devices. For more information about how to install and configure the mobile apps for your account, see [SCIS for iOS (iPadOS) and SCIS for Windows Mobile Applications](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4782202096.html).

## SCIS on Sandbox {#subsect_1525975740}

You should install and configure SCIS on a sandbox account before using it in production. Testing on sandbox lets you make sure your business processes run smoothly before you start taking orders with SCIS in your store.

For more information, see [Working with SCIS on Sandbox](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4773470562.html).
