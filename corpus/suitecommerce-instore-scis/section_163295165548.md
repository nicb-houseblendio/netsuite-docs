These features are required for SuiteCommerce InStore (SCIS) setups that will run SuiteScript 2.X:

-   Return Authorizations
    
-   Store Pickup
    

Store pickup must also be set up in locations that allow shoppers to order items online and pick up the order in a physical store.

#### To enable required features:

1.  Go to Setup > Company > Enable Features.
    
2.  Open the **Transactions** subtab.
    
3.  Under **Basic Features**, check the **Return Authorizations** box.
    
4.  Scroll to the **Shipping & Receiving** section.
    
5.  Check the **Store Pickup** box.
    
6.  Click **Save**.
