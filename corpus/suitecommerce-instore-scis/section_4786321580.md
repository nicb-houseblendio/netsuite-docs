The SCIS Mobile Certificates and SCIS Domain Safelist custom records are installed by the SuiteCommerce InStore SuiteApp. Administrators can add or remove values from the default settings on these records as needed. For example, as certificates expire, administrators will need to periodically manage updates to the domain and certificates records. Also, you might need to add a domain to the safelist so that sales associates can visit an approved website.

See the following topics for more information and detailed instructions:

-   [SCIS Mobile Certificates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1528743124.html)
    
-   [SCIS Domain Safelist Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1528742779.html)
