The following custom records are used to configure the mobile device you use to run SCIS. You configure these custom records after installing the SCIS POS application. For more information, see [Installing the SCIS Mobile App](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161842677458.html).

## SCIS Mobile Device {#bridgehead_4698298330}

-   **ID**: customrecord\_ns\_pos\_mobile\_device
    
-   **Description**: Use this record immediately after installing the SCIS POS application on a mobile device. This custom record stores the mobile device ID. It also stores the SCIS website and printer technology associated with the mobile device.
    

## SCIS Domain Safelist {#bridgehead_4744060924}

-   **ID**: customrecord\_ns\_domain\_whitelist
    
-   **Description**: This custom record contains a list of domains that are allowed access to SCIS. These safelisted domains are global to your account, regardless of location or subsidiary. The following domains are available by default and can't be disabled. These domains are required for SCIS to function properly:
    
    -   system.netsuite.com
        
    -   system.na1.netsuite.com
        
    -   system.na2.netsuite.com
        
    -   sandbox.netsuite.com
        
    
    Note:
    
    After applying any configuration changes, including changes to the Domain Safelist or Certificates, the user must log out and log in again to refresh the updated settings to the device.
    

## SCIS Mobile Certificate {#bridgehead_4744060055}

-   **ID**: customrecord\_ns\_pos\_certificate
    
-   **Description**: This custom record stores the list of authorizing certificates. When certificates go out of date, you must add updated certificates to the list. After applying any configuration changes, the user must log out and log in again to refresh the updated settings to the device.
