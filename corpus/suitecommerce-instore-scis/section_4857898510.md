Administrators can customize the SuiteCommerce (SCIS) user interface by displaying additional field attributes on certain pages. Placeholders, or **zones** define areas in SCIS that can be customized. Administrators define the fields, or **attributes** that should appear in each zone.

For more information, see [Creating SCIS Custom Attributes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4700706288.html).
