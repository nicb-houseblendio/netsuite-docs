If your catalog might exceed the iOS or Windows device storage limits, you can use the **Fallback Open Item** solution. This option uses a single generic item instead of the item being sold. Your other catalog items aren't loaded for Fallback.

Fallback relies on a downloaded copy of your item and price catalog. This copy is refreshed each time a sales associate logs in to the device.

However, mobile iOS and Windows devices have storage limits for a Fallback catalog. Exceeding the storage limit can cause the SCIS application to fail on a device. This limit often applies to catalogs with more than 20,000 items. See [Fallback and Storage Limits for Mobile Apps](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_157894549839.html) for more information about storage limits.

![Fallback Open Item QuickAdd Bar](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/SCIS/SCIS_Fallback_open_QuickAdd_bar.png)

Sales associates can scan an item's barcode to add an Open Item instead of the real item, or search for it using the term `Fallback Open Item`.

The sales associate process is:

1.  Shopper presents items for purchase.
    
2.  Associate scans an item or, if the bar code won't scan, adds an Open Item from a search.
    
3.  Associate manually enters the item's price.
    
4.  If the item didn't scan, associate opens a Note and enters the ScannedUPC digits.
    
5.  Associate repeats these steps for each item.
    
6.  Associate tenders payment and provides receipt.
    
    ![Fallback Open Item Price and Receipt](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/SCIS/SCIS_Fallback_open_item_price_and_receipt.png)

Note that the receipt lists Fallback Open Items with the UPC for each item purchased.

Important:

For accounting purposes, the price that is entered manually remains the price in the transaction, even it if doesn't match the catalog price. You might want to have a pricing worksheet available for offline events that require using Fallback.

## Capturing the UPC {#bridgehead_159491980476}

SCIS captures the UPC from the scan and saves it as a **ScannedUPC Note** that is included in the transaction record. Before manually entered UPCs can be automatically reconciled, you must set up a ScannedUPC Note type. See [Enabling Associates to Manually Enter a Reconcilable UPC](#subsect_159491780811).

## Using the QuickAddBar {#bridgehead_159423252271}

In addition to scanning an item's barcode or searching, you can choose to make the Open Item available in the QuickAdd Bar. See [Adding the Fallback Open Item to the QuickAdd Bar](#subsect_159422953074) for the steps to enable this option.

## Reconciliation {#bridgehead_159491976766}

Open Item transactions must be reconciled later to replace generic items with real items from your NetSuite catalog. Most transactions can be automatically reconciled from the ScannedUPC Note. See [Reconciling Fallback Open Item Transactions](#subsect_159111795078).

## Enabling the Fallback Open Item option {#subsect_159111764118}

This option becomes active when you enable the Fallback Catalog feature. See [Setting up a Fallback Catalog Limit and Open Item option](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159803463480.html#subsect_159906478896).

Tip:

To view the steps store associates take at the point-of-sale, see [Entering an Order using a Fallback Open Item](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1518651979.html#subsect_159102688958) in the SCIS User Guide.

Warning:

The Fallback Open Item ns\_pos\_fallbackitem is saved as a **Non-inventory item for Sale** in NetSuite. Do **not** change the item name or details. Doing so will cause the Open Item process to fail.

## Adding the Fallback Open Item to the QuickAdd Bar {#subsect_159422953074}

You can add a Fallback Open Item by scanning an item's barcode, searching for **Fallback Open Item**, or selecting the Open Item from the QuickAdd Bar.

Items don't appear in the QuickAdd bar automatically. Instead, you must add the item to a QuickAdd Group as a QuickAdd Key. See [Configuring QuickAdd Keys](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4091457905.html) for more information.

#### To create a QuickAdd Key for the Fallback Open Item:

1.  Go to Customization > Lists, Records, & Fields > Record Types.
    
2.  First, review your **QuickAdd Groups** to determine in which group to include the Fallback Open Item.
    
    1.  Find the **SCIS QuickAdd Group** record.
        
    2.  Click **List**.
        
    3.  Determine the correct group to use.
        
    4.  Go back to the **Record Types** list.
        
3.  Find the **SCIS QuickAdd Key** record and click **List**.
    
4.  Click **New SCIS QuickAdd Key**.
    
5.  Select a **QuickAdd Group** from the **Key Group** list.
    
6.  In the **Item** field, start typing or search for the name **ns\_pos\_fallbackitem**.
    
7.  Click the **Filters** subtab, and select filters for **Locations**, **Websites**, and **Subsidiaries**.
    
    Filters determine where the Fallback Open Item will appear in the QuickAdd Bar. For most businesses, you can select **Apply to All** for the three filters.
    
    Important:
    
    Filter settings are required. If a filter isn't set up for **Locations**, **Websites**, and **Subsidiaries**, NetSuite will ignore this SCIS custom record.
    
    Selecting **Apply to All** meets the filter requirement.
    
8.  (Optional) Select from the **Search Criteria** subtab options as needed. For details about the options, see [QuickAdd Keys](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4091457905.html#bridgehead_4314720807).
    
9.  Click **Save**.
    

## Enabling Associates to Manually Enter a Reconcilable UPC {#subsect_159491780811}

Automatic reconciliation uses the UPC saved from a scan as a ScannedUPC Note. Because some items might not be scannable, you can enable your sales associates to enter a ScannedUPC Note manually. Without this setup, manual notes can't be automatically reconciled.

#### To enable manual ScannedUPC Note entries:

1.  Go to Commerce > InStore > Transaction Notes.
    
2.  Click **New SCIS Transaction Notes Types**.
    
3.  In the **Name** field, enter `ScannedUPC`, without a space.
    
    Important:
    
    Enter the characters `ScannedUPC` exactly as shown here.
    
4.  Open the **Filters** subtab.
    
5.  Select the **Locations**, **Websites**, and **Subsidiaries** in which the manual note type will be used.
    
    For most setups, you'll select **Apply to All** for each choice.
    
6.  Click **Save**.
    

After setup, the sales associate will see the following after tapping the **Note** icon to manually enter a UPC.

![SCIS Custom Note Icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/SCIS/SCIS_Custom_Note.png) ![Fallback Auto Reconcile Scanned UPC Field](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/SCIS/SCIS_Fallback_Auto_Reconcile_ScannedUPC_Note.png)

They should tap **+ScannedUPC** and enter the UPC using digits only.

## Reconciling Fallback Open Item Transactions {#subsect_159111795078}

Fallback transactions won't appear in NetSuite until the point-of-sale (POS) device is back online and the sales associate logs in. The SCIS POS device uploads transactions to NetSuite for processing into Cash Sale or Invoice records. Processing occurs every 15 minutes.

After the transactions are processed into records, the individual transaction lines that contain a Fallback Open Item must be updated to replace the Open Item with the real item from your catalog. The process of updating line items is called reconciliation.

### Automatic Reconciliation {#subsect_159422956643}

Most transaction lines can be reconciled automatically without manual intervention. This process for Fallback Open Items uses the UPC captured as a **ScannedUPC Note** to replace the generic item name (ns\_pos\_fallbackitem or Fallback Open Item) with the item from your NetSuite catalog. The UPC is captured in the note by the sales associate scanning an item's barcode or entering a UPC manually.

Important:

If a sales associate enters a UPC manually, the note must contain the UPC digits only. Entering other characters, such as dashes (hyphens, the minus sign), will prevent the transaction line from being automatically reconciled.

Automatic reconciliation begins soon after the Fallback transaction records are received in NetSuite. For accounting purposes, the price that was entered manually remains the price in the transaction, even it if doesn't match the catalog price.

Auto-reconciliation will reconcile items from most transactions, including inventory items, non-inventory items, and matrix inventory items.

Certain non-standard item types, such as lot or kit items, require manual reconciliation. See [Item Types That Won't Automatically Reconcile](#subsect_159527151016). UPCs not found in your catalog and manual UPC entries with extra characters also require manual reconciliation.

-   Inventory Item
    
-   Non-Inventory Item
    
-   Matrix Inventory
    

Note:

Automatic reconciliation runs as a script in the background of your NetSuite environment. The script is called: `NS_RP_Fallback_Create_Transaction_Inner.js`.

### Reviewing Fallback Open Item Auto-reconciliation Success {#subsect_159430464162}

Follow these steps to verify whether all lines in a Fallback Open Item transaction were reconciled successfully.

#### To review Fallback Open Item transaction lines:

1.  In NetSuite, in the search bar at the top, enter **SCIS Fallback Transaction**.
    
2.  Click **Page: SCIS Fallback Transaction** (near the list bottom).
    
    The **SCIS Fallback Transaction List** displays.
    
3.  If not in date order, click the **Transaction Date** column to sort by recent transactions.
    
    The transactions to review will show:
    
    -   **Status** - Transaction Completed
        
    -   **Final Transaction** - Cash Sale or Invoice
        
4.  Click **Cash Sale** or **Invoice** for the first transaction to verify.
    
5.  Open the **SCIS Fallback** subtab. A message displays if any Open Items failed to automatically reconcile.
    
6.  If some items weren't automatically reconciled, see the next steps: [Performing Manual Open Item Reconciliation](#subsect_159422960341).
    
    If all items reconciled successfully:
    
    1.  Click **Back** to return to the **SCIS Fallback Transaction List**.
        
    2.  Review the next Fallback transaction to confirm reconciliation.
        

### Performing Manual Open Item Reconciliation {#subsect_159422960341}

Follow these steps to reconcile transaction lines that failed automatic reconciliation. Manual reconciliation must always be performed for certain non-standard item types, such as lot or kit items.

The **Note** column is often helpful for identifying why auto reconciliation failed for a line. The column holds the scanned or manually-entered UPC.

Other reasons that automatic reconciliation failed might not be obvious without viewing the transaction line details.

In these steps, you'll add catalog items and quantities to replace the unreconciled Open Item lines.

#### To manually reconcile a Fallback Open Item transaction:

1.  Use the previous steps to display the Fallback transaction.
    
2.  Open the **Items** subtab.
    
    Open Items that didn't reconcile have the **Item** name **ns\_pos\_fallbackitem**.
    
3.  Click **Edit**.
    
4.  Scroll right to display the **Item Note** column. This column holds the ScannedUPC from the bar code scan or manual entry.
    
    Tip:
    
    The **Items** subtab has its own scroll bar.
    
5.  Copy the UPC numbers. For example, copy `055555333332` only.
    
6.  Click **Add Multiple**.
    
7.  Paste the UPC and click **Search**.
    
    Tip:
    
    If the UPC isn't available, enter any part of the item name.
    
8.  Highlight the item you want and enter the **Qty** (quantity) purchased.
    
9.  Click **Done** to add the catalog item to the Fallback transaction.
    
10.  Ensure that the catalog **Price** matches the price entered for the Open Item. If not, replace the catalog price.
     
     Important:
     
     For accounting purposes, you should use the price entered for the purchase when the device was in Fallback.
     
11.  If appropriate, edit other catalog line fields with details from the Open Item line.
     
12.  Click **OK** if needed to close the new catalog item line.
     
13.  Highlight the Open Item line you're replacing and click **Remove**.
     
14.  Use **Add Multiple** to replace the next Open Item line.
     
15.  Continue until all lines are reconciled with your catalog items.
     
16.  Click **Save**.
     

### Item Types That Won't Automatically Reconcile {#subsect_159527151016}

Certain non-standard item types, such as lot or kit items, will always require manual reconciliation. These are:

-   Down-loadable Items
    
-   Gift Cards
    
-   Item Groups
    
-   Kit Items
    
-   Lot Items
    
-   Serial Items
    
-   Service Items
    
-   Discount Items (defined in NetSuite to use for promotions)
