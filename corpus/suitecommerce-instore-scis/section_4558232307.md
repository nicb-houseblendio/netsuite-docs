SCIS provides localization support for Canada, Australia, New Zealand, UK, France, Germany, Italy, Japan, and Spain. This section includes setup information for localizing SCIS.

The following general capabilities are supported in SCIS:

-   Currency
    
-   Decimal precision
    
-   Item pricing
    
-   Taxes
    
-   Receipts
    
-   Cash rounding
    
-   Address formats
    
-   Phone formats
    
-   Date formats
    

Note:

Set the date format at _Setup > Company > General Preferences._ . For OneWorld accounts, the date format is specified on the default website subsidiary record. To modify this setting, edit the subsidiary record at _Setup > Company > Subsidiary_, and change the date format on the Preferences subtab.

## Custom Billing Address Form Templates {#bridgehead_4740614537}

SCIS supports custom form templates for the customer profile billing address. Account administrators and other users with the Custom Address Form permission can create customized versions of a billing address form and assign it to be used in one or more countries.

Creating custom address forms is a task associated with NetSuite customization, and not specifically with SCIS. For more information about custom address forms, see [Customizing Address Forms](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2874310.html).

In SCIS, the custom billing address forms that you create display in the customer profile only.

## Taxes and Localization {#bridgehead_4558577956}

Typically, applicable taxes are displayed in the cart, checkout pages, and order confirmation. Alternately, you can set the website preference, **Prices Include Tax** to include tax in item prices displayed in SCIS.

Note:

The **Prices Include Tax** check box is only applicable to the United Kingdom and International editions of NetSuite.

#### To include tax in item prices:

1.  Go to _Commerce > Websites_.
    
2.  Click **Edit** next to your SCIS website.
    
3.  Click the **Shopping** subtab.
    
4.  Check the box next to **Prices Include Tax**.
    
5.  Click **Save**.
    

When this preference is set, tax is included in the price of each item. If shipping and handling also include tax, then tax is included in the cost of shipping and handling. However, a separate line for tax still displays in the SCIS transaction summary.
