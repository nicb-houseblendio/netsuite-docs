You can customize your SuiteCommerce InStore (SCIS) implementation in these ways:

-   Change optional settings in the CustomConfiguration.js file. For more information, see [Customizing the Configuration File](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1541812069.html).
    
-   Display additional item attributes in the cart, search result lists, and on product detail pages. You can also display additional customer information in the Customer Profile or customer search results. For more information, see [Creating SCIS Custom Attributes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4700706288.html).
    
-   Web developers can write custom scripts that run before or after a specific event occurs in the shopping cart. For more information, see [SCIS Event Validators](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1498501603.html).
    
-   Web developers can create custom popup windows that can be displayed in the SCIS shopping cart. For more information, see [SCIS Extensions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1533259236.html) and [SCIS Extensibilty API](https://system.netsuite.com/help/helpcenter/en_US/APIs/SuiteCommerce/Extensibility/SCIS/index.html).
    

Note:

SCIS only supports client scripts for use with AvaTax integrations. You're responsible for testing and maintaining the client scripts you create. Ensure your scripts work properly with each managed bundle update.
