To make changes to the CustomConfiguration.js file in SuiteCommerce InStore (SCIS), you must perform the same general steps.

#### To edit the CustomConfiguration.js file: {#procedure_4299016618}

1.  Go to Commerce > Hosting > Website Hosting Files.
    
2.  Find the **SuiteCommerce InStore folder** in the File Cabinet. Go to Web Site Hosting Files > Live Hosting Files > SSP Applications > NetSuite Inc. - POS > SuiteCommerce InStore
    
3.  Click **Edit** next to **CustomConfiguration.js**.
    
4.  In the file record, click **Edit** in the Media Item section, next to the file name.
    
5.  When you're finished making changes, click **Save** on the file record.
