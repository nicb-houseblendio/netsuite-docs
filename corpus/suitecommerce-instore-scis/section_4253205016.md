SCIS users need specific permissions set up on roles from the SuiteCommerce InStore SuiteApp. This section describes SCIS roles and role-based permissions.

This section include Information about the following:

-   [SCIS Clerk](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1522784118.html)
    
-   [SCIS Support](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1522784166.html)
    
-   [SCIS Store Manager](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1522784177.html)
    
-   [Creating Custom Roles for SCIS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1522784187.html)
    

Employees also require authorization to perform certain operations in SCIS, defined on SCIS Permission records. For more information, read [SuiteCommerce InStore Permissions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4253205125.html).

For secure authentication, roles for employees who will be using SCIS on tablets must also be restricted by Device ID. For more information about Device ID setup, see [Device ID and the SCIS SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4404543878.html).
