To sell a gift card or gift certificate in SuiteCommerce InStore (SCIS), an administrator must configure a gift certificate item record in NetSuite. A check box on this item record defines the gift certificate as a physical gift card or a digital gift certificate. The digital gift certificate is redeemable with only the authorization code. The gift certificate can be configured so that the sales associate sets the amount at the time of sale. For more information, see [Configuring Gift Certificates for SCIS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4290640521.html).

An administrator can also modify the CustomConfiguration.js file to set the default values displayed in fields on gift certificates. Changing the default values in these fields is optional. For more information, see [Setting Gift Certificate Attributes For SCIS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4440657982.html).

## Selling Gift Certificates {#bridgehead_4302732684}

After Gift Certificates are configured in NetSuite, they're treated as items in SCIS. After the gift certificate is added to the cart, the sales associate can click the line item to change the information, if needed. When a **gift card** is added to the cart, SCIS prompts the sales associate to swipe the card and enter the price (if the gift card is configured with a variable amount). For more information useful for sales associates, see [Working with Gift Cards in SCIS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4333546846.html).

Selling a **digital gift certificate** is similar, except there's no card to swipe. Also, the sales associate is prompted to enter information for the notification email message sent to the recipient. The sales associate enters the names of the gift certificate giver and recipient, the recipient's email address, the authorization code, and a message. When the order is complete, the authorization code is sent to the gift recipient in an email message and printed on the receipt.

## Applying a Gift Certificate as Payment {#bridgehead_4302814354}

After adding items to an order, the sales associate clicks the Other Payment button in SCIS, and selects Gift Certificate. Next, the sales associate swipes the gift card, or enters the authorization code for a digital gift certificate. After the authorization code is entered, the transaction summary window shows the gift certificate amount applied to the order and the remaining amount due. For more information useful for sales associates, see [Paying With a Gift Card](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4333561976.html).
