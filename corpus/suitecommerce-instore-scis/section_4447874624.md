## Tablet Models {#bridgehead_4447875914}

These Windows® and Apple ® tablet models are compatible with SCIS:

| Compatible Models | Operating System |
| --- | --- |
| Surface Pro 5.x and later | Microsoft Windows |
| iPad Generation 5.x and later | Apple iOS |

SCIS for iOS or SCIS for Windows application is required for use with these tablets. For more information, read [SCIS for iOS (iPadOS) and SCIS for Windows Mobile Applications](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4782202096.html).

Important:

Ensure that unauthorized individuals do not have access to a tablet running SCIS. Note that the definitions for client-side security measures are stored in a local configuration file on the device.

## Cash Drawers {#bridgehead_4447880741}

The following cash drawer models are compatible with SCIS:

| Brand | Series | Model |
| --- | --- | --- |
| Birch/Firich |  | POS-203 6P24V, RJ12 |
| APG | Vasario Series | Drawer: P/N: VBS320-BL1616 Cable: APG CD-101A Printer Cable |
| MMF | Advantage Series | Drawer: P/N: ADV113B11331004 Cable included: 226199EPST1000 KwickKable RJ12 Data Transfer Cable for Star and Epson POS Printer. |
|  | Value line | Drawer: PN: MMF-VL1616E-04 Cable included: 226-199EPSN10-00 |

The cash drawer is identified based on your printer technology setting on the SCIS Mobile Device record.

Your setting on each SCIS Payment Method record defines whether the cash drawer opens automatically. The cash drawer opens based on the SCIS Payment Method used to pay for the order. Sales associates can also open the cash drawer by selecting the **No Sale** option in the User Menu.
