This section includes reference information about the custom records used for SCIS Fallback. See this section to learn about how the custom records are used with SCIS Fallback and reconciliation. To view or configure custom fields in NetSuite, go to Customizaton > Lists, Records, & Fields, and then make a selection from the list.

## SCIS Fallback Settings {#subsect_1513121014}

-   **ID**: customrecord\_ns\_pos\_fallback\_settings
    
-   **Description**: Configuring the SCIS Fallback Settings record is the first step in setting up Fallback. For more information, see [SCIS Fallback Settings](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1507134293.html).
    

## SCIS Fallback Transaction {#subsect_1513120996}

-   **ID**: customrecord\_ns\_pos\_fallback\_proto\_tran
    
-   **Description**: This record captures all the data from a transaction submitted in Fallback. This is the parent record to the SCIS Fallback Line and SCIS Fallback Payment records. For more information, see [Transaction Creation Process](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1522090558.html).
    

## SCIS Fallback Line {#subsect_1513120644}

-   **ID**: customrecord\_ns\_pos\_fallback\_line
    
-   **Description**: This record displays data from each line of every transaction submitted using Fallback. It's a child record of the SCIS Fallback Transaction record. You can view data from SCIS Fallback Line records on SCIS Fallback Transactions. For more information, see [Fallback Data Delivery](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1511999705.html).
    

## SCIS Fallback Payment {#subsect_1513120655}

-   **ID**: customrecord\_ns\_pos\_fallback\_payment
    
-   **Description**: This record captures payment information from orders submitted using SCIS Fallback. It's a child record of the SCIS Fallback Transaction record. For more information, see [SCIS Fallback Payment Methods](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1511999683.html).
    

## SCIS Fallback Session {#subsect_1513121007}

-   **ID**: customrecord\_scis\_fallback\_session
    
-   **Description**: This record represents each new session created every time a sales associate logs in to Fallback. For more information, see [SCIS Fallback Session and SCIS Transmission Batch Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1511999705.html#subsect_1518658086).
    

## SCIS Fallback Transmission Batch {#subsect_1513121202}

-   **ID**: customrecord\_scis\_fb\_transmission\_batch
    
-   **Description**: SCIS Transmission Batch records are grouped according to session and linked to SCIS Fallback Session records.
