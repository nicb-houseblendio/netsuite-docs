Configuring item images is an important task in setting up SuiteCommerce InStore (SCIS). As with Commerce web stores, image files automatically match with item records in NetSuite based on criteria that you include in the image file name. The criteria that you include in the image file name is the item identifier. You can match images to items based on the value in a field that appears on item records in NetSuite. Choose one of the following fields:

-   Display Name/Code
    
-   UPC Code
    
-   URL Component
    
-   Additional UPCs
    

After you decide on the item identifier and the format you want to use for image file names, rename your image files and upload them to the file cabinet.

To learn how to configure item images for SCIS, see [Example of Item Image Configuration](#bridgehead_4428610739).

## Best Practice for Setting up Image Size Parameters for SCIS {#subsect_1537221064}

You can't define custom Image Size IDs for the SCIS website. You must use the Image Size IDs that are installed by the SCIS SuiteApp. Changing or removing any Image Size IDs for SCIS will result in distorted images on the site.

You should only change image size parameters by adjusting the Maximum Width and Maximum Height values.

## Using a Keyword to Support Multiple Images {#bridgehead_1490124068}

In other cases, you must set a keyword as a placeholder category to map images to items correctly. You can create your own keyword. The only requirement is that all images must contain the **same** keyword. For example, you can use the following structure to name your image files, but make sure all your image file names use the same structure.

          `[Display Name/Code]_media-[number].[file extension]` 
        

## Example of Item Image Configuration {#bridgehead_4428610739}

For example, you have two .jpg images to add for the item "Plastic Spatula." You can choose Item Display Name/Code as the item identifier. Next, rename the image files you plan to use for items. Use the following naming convention for your image files based on the preceding image file:

          `[Display Name/Code]_media-[number].[file extention]` 
        

If your NetSuite account has another Commerce web stores site, you can copy the image mapping criteria and use it for your SCIS site. If your only Commerce web stores website is used for SCIS, see the following steps to set up image mapping criteria. In this case, you must rebuild the search index to update all the items with the image files uploaded.

The following steps use the item from the previous example. You can replace image file names and folder names with file and folder names that correspond with your account.

#### Sample steps to configure item images:

1.  On your computer, rename the image files using the naming convention from the preceding example.
    
    1.  Rename the primary image to **PlasticSpatula\_media-0.jpg**
        
    2.  Rename the second image to **PlasticSpatula\_media-1.jpg**
        
    3.  Create a ZIP file for all your image files.
        
    
    Note:
    
    Using numbers in your image file names lets you use more than one image for each item. Sequential numbers help you organize your images.
    
2.  Go to Commerce > Websites > Website List.
    
    1.  Click **Edit** next to your SCIS website and click the **Images** subtab.
        
    2.  In the **Item Identifier** field, select **Display Name/Code**.
        
        Warning:
        
        All images you upload must use the same item identifier. If you change it, some product images won't appear on your SCIS website.
        
    3.  In the **Image Domain** field, select the domain you use for SCIS.
        
    4.  In the **Image Folder** field, select Web Site Hosting Files > Live Hosting Files > Images.
        
        Note:
        
        This is the folder you create in the Live Hosting Files folder to store item images.
        
    5.  Click **Save**.
        
3.  Upload your image files from Step 1 to Web Site Hosting Files > Live Hosting Files > Images.
    
    1.  Go to the folder at Commerce > Hosting > Website Hosting Files > Live Hosting Files > images.
        
    2.  Click **Advanced Add**.
        
    3.  In the **ZIP Archive to Add** field, choose the ZIP file on your computer.
        
    4.  Verify the **Destination Folder** is where you intend to upload files.
        
    5.  Check the **Unzip Files** box.
        
    6.  Check the **Make all Files Available Without Login** box.
        
    7.  Check the **Overwrite Files with Same Name** box to avoid uploading duplicate files in this folder. Files with the same name are automatically updated with the latest version you upload.
        
    8.  Click **Add**.
        
4.  Rebuild the search index. This step is required if you're adding item images, you only have one Commerce web stores website, and you use that site for SCIS.
    
    1.  Go back to Commerce > Websites > Website Lists.
        
    2.  Click the **Actions** menu.
        
    3.  Select **Rebuild Search Index**.
        
        The time it takes to rebuild the search index depends on the number of items in the account and your network connection. To check the status of the search index, go to Commerce > Websites > Website List. Click **View** under **Search Status Index**.
        

When the search index status is completed, you can verify that images are correctly associated with item records. Go to the item record at Lists > Accounting > Items. Click Edit next to an item record. Confirm that images are listed on the **Web Store** subtab, under **Associated Images**.

For more detailed instructions on configuring images, see [Item Images](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_162137155579.html).
