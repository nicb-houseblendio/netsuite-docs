The following custom fields apply to item records used with SuiteCommerce InStore (SCIS). You can find these custom fields in NetSuite, and then modify them as needed.

## SCIS Gift Card {#bridgehead_4394176052}

-   **ID**: custitem\_ns\_pos\_physical\_item
    
-   **Description**: Used exclusively for gift certificates, this check box differentiates gift certificates in card form from digital gift certificates. You can access this field on gift certificate item records in NetSuite. For more information, see [Configuring Gift Certificates for SCIS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4290640521.html).
    

## Additional UPCs {#bridgehead_4398352903}

-   **ID**: custitem\_ns\_pos\_additional\_upcs
    
-   **Description**: Defines additional UPC codes for items. You can enter a comma-separated list of UPC codes in this custom field on item records. For more information, see [Configuring Item Records for SCIS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4111609105.html).
