This list provides details about the typical workflow. Use the links to find more information.

1.  **Log in to SuiteCommerce InStore.**
    
    After you enter your login credentials, depending on your system configuration, you might need to enter an opening drawer transaction. From the **User menu**, you can pick a printer and select a Sales Rep. If you have been assigned more than one role, you can select which one you want to use when you log in. For more information, see [SuiteCommerce InStore Login](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4111457151.html).
    
2.  **Select a customer for a transaction.**
    
    You can use the search bar in SCIS to find existing customers. This search includes customers who bought through SCIS, customers in NetSuite, or anyone who bought from the online store. For more information, see [Adding Customers To Sales Transactions in SCIS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4333543476.html). See also, [Working with Customer Profile Information](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4111458550.html).
    
3.  **Add items to the cart.**
    
    You can use the search bar or the QuickAdd bar to find items in SCIS. To add items to a transaction, you can use a barcode scanner or tap an item QuickAdd Key. For more information, see [Adding Items to a Sales Transaction in SCIS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3971553201.html).
    
4.  **Apply discounts.**
    
    (Optional) You can add a discount to a particular item or to the entire order. Alternatively, you can apply a promotion code. For more information, see [Discounts and Markups in SCIS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3971553854.html).
    
5.  **Accept payment.**
    
    SCIS supports all payment methods your system administrator has set up. For more information, see [Accepting Payments for Purchases in SCIS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3971564447.html).
