Before you create an SCIS Gateway record, you should already have a payment processing profile in NetSuite for your payment services provider. For more information about creating payment processing profiles, see [Setting Up Payment Processing Profiles in NetSuite](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1572588.html).

The SuiteCommerce InStore SuiteApp adds the SCIS Gateway custom record type. This custom record lets you use payment processing profiles in SCIS. When you set up SCIS Gateway records, you add location info for each payment processing profile.

#### To configure the SCIS Gateway custom record:

1.  Go to Commerce > InStore > Payment Gateways.
    
2.  Click **New SCIS Gateway**.
    
3.  In the **Name** field, enter a name for the SCIS Gateway. You may consider a name that includes the payment processing profile name.
    
4.  Select a **Location** from the list. The SCIS Gateway will be available for the location you choose.
    
5.  Select a payment processing profile from the **Gateway** list.
    
6.  Click **Save**.
    

It's important to set the location where certain payment services are available, especially if you use international payment services for some locations. After you've set up SCIS Gateway records, you can define SCIS Payment Method records.
