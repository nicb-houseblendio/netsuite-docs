Fallback is included in SuiteCommerce InStore (SCIS) and runs locally on the mobile device you use for point-of-sale transactions. To start using Fallback, an administrator must perform some configuration tasks in NetSuite.

To prepare for using Fallback, complete the following steps:

## Prerequisites {#subsect_1518650200}

To prepare for using Fallback, administrators must complete some steps. Note the following:

-   Configure Fallback in NetSuite at Commerce > Instore > Fallback Mode Settings. See [SCIS Fallback Settings](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1507134293.html).
    
-   If you use SCIS on an iPad, ensure that SCIS mobile apps are up to date. See [SCIS for iOS (iPadOS) and SCIS for Windows Mobile Applications](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4782202096.html).
    
-   If your devices use iPadOS 14 or later, ensure that you have and maintain at least 1 GB of free space on each device.
    
-   If an external PIN-pad payment method is available, ensure that its setup is complete. See [SCIS Fallback Payment Methods](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1511999683.html).
