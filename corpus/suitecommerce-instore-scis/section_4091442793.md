This section includes information about first-time installation of SuiteCommerce InStore (SCIS).

You use SuiteApps to install the components required to run SCIS, including custom records and fields, JavaScript files, and other assets. The SuiteApp installation process checks for required features.

You should install **SuiteCommerce InStore** and the **Reference Product List**/**Review** bundles:

-   Reference Product List Records (Bundle ID 53051)
    
-   Reference Product Review Records (Bundle ID 53053)
    
-   SuiteCommerce InStore (perform Search to find latest bundle)
    

Tip:

If the **SuiteCommerce InStore** bundle fails to install, make sure you've enabled all the required features and preferences, then try again. See [Required Features and Settings for SCIS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1518825554.html).

#### To install SCIS bundles using SuiteApps:

1.  Go to _Customization > SiteBundler > Search & Install Bundles_.
    
2.  Stay on the **Basic** tab.
    
3.  For **Keywords**, enter the Bundle ID or a portion of the bundle name.
    
4.  Click **Search**.
    
5.  Use the **Version** number to find the latest bundle for the SuiteApp you want.
    
6.  Click the bundle **Name**.
    
7.  Review the **Bundle Details** and then click **Install**.
    
    If prompted, click **OK** to give permission for NetSuite to install bundle updates.
    
8.  After a short wait, the **Preview Bundle Install** page displays. Click **Install Bundle**.
    
    If prompted, click **OK** to install the bundle and its objects.
    
9.  When the **Status** on the **Installed Bundles** page changes from **Pending** to a green check mark, the installation is complete.
    
10.  Repeat these steps for other bundles as needed.
     

After you've installed the SuiteApp, finish configuring your SuiteCommerce InStore website. For more information, see [Setting Up the SCIS Website](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4425996079.html).

To view a list of SCIS installation tasks, see [SuiteCommerce InStore Installation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4111569414.html).

Note:

Bundles with **Yes** in the **Managed** column are updated automatically.
