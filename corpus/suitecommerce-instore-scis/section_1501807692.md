An SCIS User Settings custom record is automatically created for each employee after they log in to SCIS for the first time. The SCIS User Settings record links the employee record to other records critical to SCIS transactions, such as the default customer record and the employee's cash drawer account.

#### To view the SCIS User Settings custom record:

1.  Go to Customization > Lists, Records, & Fields > Record Types.
    
2.  Find **SCIS User Settings** and click **List** in that row.
    
3.  Click **View** next to a name in the list of employees to check the settings. If you want to change or update them, click **Edit**.
    
4.  Note the following user settings:
    
    -   **Employee** - Shows the employee name. This field is automatically populated, and is linked to the employee record.
        
    -   **Default Customer** - Shows the default customer record associated with the employee. For more information, see [Default Customer](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4231811858.html#subsect_1530894345).
        
        Important:
        
        Don't change the default value in the **Default Customer** field. Changing this can affect the ability to track sales transactions submitted for customers who don't provide personal information such as name or email address.
        
    -   **Default Sales Rep** - Defines the default sales rep for the employee.
        
    -   **Account** - Defines the cash drawer account assigned to the employee.
        
    -   **EULA Version Presented** - Shows the ID of the latest version of the End-User License Agreement (EULA) presented to the user. This field is automatically updated each time a new version of the EULA is displayed in SCIS.
        
    -   **EULA Review Date** - Shows the date and time when the user accepted the terms of the EULA.
        
    -   **EULA Acceptance** - This box is checked if the SCIS user accepted the terms of the EULA. If the box is cleared, the SCIS user hasn't accepted the EULA.
        
5.  Click **Save**.
