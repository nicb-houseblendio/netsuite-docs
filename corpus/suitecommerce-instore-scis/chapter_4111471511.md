These topics cover making point-of-sale (POS) transactions using SuiteCommerce InStore (SCIS).

Most tasks are for sales associates and cashiers having the SCIS Clerk Role, but others can be used by store managers with the SCIS Store Manager Role. To learn more about Roles, see [SCIS Roles and Permissions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4230734733.html).
