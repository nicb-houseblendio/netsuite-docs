This section includes information about first-time installation of SuiteCommerce InStore (SCIS). When you install the SuiteApp, the following basic components are automatically set up and configured:

-   Website for SCIS, including search fields and field sets
    
-   SCIS Quick Cash Denominations
    
-   Image resize preferences on the Images subtab of the Web Site Setup page
    

If you don't enable certain features required by the SuiteApp, the installation fails. To identify required features and settings, see [Required Features and Settings for SCIS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1518825554.html).

The installation consists of two tasks:

1.  [Installing SuiteApps for SCIS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4091442793.html)
    
2.  [Setting Up the SCIS Website](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4425996079.html)
