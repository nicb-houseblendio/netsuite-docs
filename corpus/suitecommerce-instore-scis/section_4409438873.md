In SuiteCommerce InStore (SCIS), the SCIS Location and SCIS Inventory Location searches affect location data displayed on the Product Detail Page in the Nearby Stores tab and the All Locations tab. You can modify the location data by creating new location searches with criteria that you select. After you have created your own modified saved search, use the new saved search ID in the CustomConfiguration.js file to change the default location searches used in SCIS.

#### To create a location search for the Product Detail Page:

1.  Select your own criteria for the location search. Follow the instructions in [Modifying Included Saved Searches](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4401961202.html).
    
2.  Go to _Reports > All Saved Searches_. Remember the ID for your modified SCIS location search.
    
3.  Go to Web Site Hosting Files > Live Hosting Files > SSP Applications > NetSuite Inc. - POS > SuiteCommerce InStore.
    
4.  Click **Edit** next to **CustomConfiguration.js**.
    
5.  Replace the default value for `locationSearch` with the ID for your own custom saved search.
    
                    `location: { // Id of the search for displaying locations in Nearby stores and in Pick up locations locationSearch: 'customsearch_ns_pos_locations_2',` 
                  
    
    You can also replace the value for `inventoryLocationSearch` with a modified version of the SCIS Inventory Location search.
    

For more information, see [Customize Location Display](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4301646891.html#bridgehead_4369361615).
