The following custom fields are associated with transactions entered using SuiteCommerce InStore (SCIS). Data displayed in custom fields on transaction records in NetSuite provide more information about each transaction.

## SCIS Transaction Line-Item Fields {#bridgehead_4394218555}

Transaction line fields are used to store and retrieve information about the line items within a transaction. These fields are typically displayed on the Items subtab on Invoices and Cash Sales generated from SCIS.

## Void Quantity {#bridgehead_4394202636}

-   **ID**: custcol\_ns\_pos\_voidqty
    
-   **Description**: Stores the quantity of a voided item on an order. This field is used when you add an item back to the order, so the item retains its original quantity.
    

## Void % {#bridgehead_4394203424}

-   **ID**: custcol\_ns\_pos\_voidpct
    
-   **Description**: Stores the ID for the percent discount applied to a line item voided from an order. The field is blank if the discount is a fixed amount.
    

## Voided Item {#bridgehead_4394203458}

-   **ID**: custcol\_ns\_pos\_voideditem
    
-   **Description**: Stores the ID of the item voided in a transaction.
    

## Returned Quantity {#bridgehead_4394203492}

-   **ID**: custcol\_ns\_pos\_returnedqty
    
-   **Description**: Stores the quantity of items returned. Used on validated returns to calculate returnable items.
    

## SCIS Return Reason (TX) {#bridgehead_4394203526}

-   **ID**: custcol\_ns\_pos\_returnreason
    
-   **Description**: Stores the reason for the return. If an item is returned, a reason must be set.
    

## Unvalidated Return {#bridgehead_4394203555}

-   **ID**: custcol\_ns\_pos\_unvalidated\_return
    
-   **Description**: Used during a return transaction, this field stores the return validation setting. This hidden field applies to an item on a sales transaction. For more information, see [Returns and Refunds](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4111389902.html).
    

## Custom Subtab on Transaction Records {#bridgehead_4398356425}

The following fields show on the Custom subtab on sales transactions. These custom fields may or may not be populated based on the type of transaction submitted in SuiteCommerce InStore. For example, if a credit memo wasn't issued, the SCIS Returns Credit Memo field remains empty.

## SCIS Returns Credit Memo {#bridgehead_4394195906}

-   **ID**: custbody\_ns\_pos\_returns\_creditmemo
    
-   **Description**: Stores information about the credit memo used in a return transaction when another item was purchased. This field is populated on an invoice form generated from an exchange transaction. It links the invoice with the return by showing the credit memo transaction number.
    

## SCIS Created From {#bridgehead_4394195865}

-   **ID**: custbody\_ns\_pos\_created\_from
    
-   **Description**: Used to create a reference to the original transaction. This field applies to sales transactions, for example, an invoice created from a sales order.
    

## Sales Associate {#bridgehead_4394195811}

-   **ID**: custbody\_ns\_pos\_sales\_associate
    
-   **Description**: Stores the sales associate's name on the transaction.
    

## POS Status {#bridgehead_4394192107}

-   **ID**: custbody\_ns\_pos\_transaction\_status
    
-   **Description**: Defines the status of a transaction. The POS Status field appears on all transactions entered with SCIS. This field contains values that aren't part of the standard transaction record. This is a read-only field that's set automatically as transactions are created and processed with SCIS. It requires no configuration. For more information, see [POS Status Definitions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4290511404.html#bridgehead_4409743150).
    

## Billing Subtab on Transaction Records {#bridgehead_4399390473}

The following fields are displayed on the Billing subtab of sales transactions.

## Total Tendered {#bridgehead_4394192211}

-   **ID**: custbody\_ns\_pos\_total\_tendered
    
-   **Description**: Stores the total amount of money accepted from the customer to complete a transaction. This field applies to sales and customer payments.
    

## Credit Card Signature {#bridgehead_4394192057}

-   **ID**: custbody\_ns\_pos\_signature\_image
    
-   **Description**: Stores the electronic signature provided by the customer after performing a credit card transaction.
    

## Change Due {#bridgehead_4394191976}

-   **ID**: custbody\_ns\_pos\_change\_due
    
-   **Description**: Lists the amount of change due when performing a cash transaction.
    

## Suspended Total {#bridgehead_4398360275}

-   **ID**: custbody\_ns\_pos\_suspended\_total
    
-   **Description**: Stores the total for each suspended transaction. This field stores the total of the transaction at the moment it was suspended, and displays it in the list of suspended orders. For more information about suspended transactions, see [Saving (Suspending) an Order](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4333543087.html#bridgehead_4364041908).
    

## Other Custom Lists and Records for Transactions {#bridgehead_4394904269}

The following custom lists and records are also associated with transactions, but they don't appear on the transaction record.

## SCIS Transaction Status {#bridgehead_4394905619}

-   **ID**: customlist\_ns\_pos\_transaction\_status
    
-   **Description**: Used internally to store the status of transactions generated by SCIS. The values in this list are displayed in the POS Status field on transactions. Don't modify the values in this list. The POS Status field is updated automatically as transactions are submitted and processed.
    

## SCIS Audit Log {#bridgehead_4394929308}

-   **ID**: customrecord\_ns\_pos\_audit\_log
    
-   **Description**: Stores information about every transaction generated from SuiteCommerce InStore related to authorization requests based on permissions.
    
    To view the audit log, go to Customization > Lists, Records, & Fields. Next, find SCIS Audit Log in the list. Then, click List in that row. You can click a column header on the list page to sort data. For more information, see [SCIS Audit Log](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4332845108.html).
    

## SCIS Open Credit Memos {#bridgehead_4395035370}

-   **ID**: customsearch\_ns\_pos\_open\_credit\_memos
    
-   **Description**: Saved search that returns Open Credit Memos for a specific customer. Supports the refund to Credit Memo feature.
    

## SCIS Transaction Notes Types {#bridgehead_4683581920}

-   **ID**:customrecord\_ns\_pos\_notes\_types
    
-   **Description**: This record is configured by administrators, and then used by sales associates to capture additional information about orders. For more information about configuring SCIS Transaction Note Types, see [Defining SCIS Transaction Notes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4683541317.html).
