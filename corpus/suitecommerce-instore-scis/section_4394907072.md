QuickAdd keys are used in SuiteCommerce InStore (SCIS) to add items to a transaction. Configuration of QuickAdd Groups and QuickAdd Keys is required. For more information, see [Configuring QuickAdd Keys](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4091457905.html).

## SCIS QuickAdd Group {#bridgehead_4394909090}

-   **ID**: customrecord\_ns\_pos\_hotkeygroup
    
-   **Description**: List that defines the tabs that appear in the QuickAdd bar on the main application screen. You can configure QuickAdd Groups as filters to hide or show products based on criteria such as user role, location, or customer. To define a QuickAdd Group, go to Customization > Lists, Records, & Fields > Lists. Click SCIS QuickAdd Group, and then add or modify values in the list.
    

## SCIS QuickAdd Key {#bridgehead_4394909147}

-   **ID**: customrecord\_ns\_pos\_hotkey
    
-   **Description**: Used to configure QuickAdd Keys. You configure one custom record for each QuickAdd Key associated with a product for sale. To define a QuickAdd Key, go to Customization > Lists, Records, & Fields > Record Types.
