In addition to delivering the same experience as the web application, SCIS mobile applications include robust security and remote configuration options for administrators. SCIS for iOS and SCIS for Windows use custom records in NetSuite to update the configuration settings on your mobile device. Remote configuration enables administrators to make subsequent configuration changes after the first-run setup has been completed on the device.

Important:

SuiteCommerce InStore is only supported on mobile devices running SCIS for iOS or SCIS for Windows. Installation of either SCIS for iOS or SCIS for Windows is **required**.

Note the following:

-   [Application Requirements - SCIS for iOS (iPadOS) Mobile App](#subsect_1518214039)
    
-   [Application Requirements - SCIS for Windows Mobile App](#subsect_1518036362)
    

Tip:

The acronyms iOS and IPadOS are used interchangeably in this guide. An iOS update for your Apple iPad is downloaded in the IPadOS format. For the topics used in this guide, either operating system (OS) term will apply.

## Best Practice for Applying Settings {#subsect_163001736392}

The best practice for applying settings to an iPad or Windows tablet is to update one device, run acceptance tests on that device, and then apply the settings to other devices. See [Mobile App Testing for Operating System & Other Updates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1508181185.html).

## Application Requirements - SCIS for iOS (iPadOS) Mobile App {#subsect_1518214039}

SCIS for iOS version 5.1.0 has been verified as compatible with iPadOS 13.x, 14.x, 15.2 or greater, and 16.1. These iPadOS releases are supported by Oracle NetSuite for use with the SCIS application.

Note:

iPadOS 15.0 and 15.1 aren't supported due to issues with printing compatibility.

Important:

Free space issues for iPadOS 13.x and later can affect the storage required for Fallback catalog downloads. Under certain circumstances, these issues can cause the SCIS for iOS mobile app to fail. See [Fallback and Storage Limits for Mobile Apps](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_157894549839.html).

Warning:

**Recording a video that includes a login.** It's been found that for iPadOS versions prior to iPadOS 14.3, using the included iOS Screen Recorder utility to record the act of logging into an application can expose the keystrokes and characters used to enter a password. To avoid having a password exposed when recording a video, you should upgrade your devices to iPadOS 14.3 or later.

### Wait Before Updating to New iPadOS Versions {#subsect_163001727001}

Always wait for notification from NetSuite before you update to a major version that's not listed here as 'compatible.' Versions with a number and single decimal place are considered "major." Waiting lets NetSuite ensure SCIS will work with the new version.

Note:

Because minor iPadOS versions usually contain bug fixes, SCIS doesn't test minor versions for compatibility. For example, if X.X is tested as compatible, X.Xx is normally not tested.

## Application Requirements - SCIS for Windows Mobile App {#subsect_1518036362}

Tablets that use the SCIS for Windows mobile app must have the following system applications installed:

-   Windows 10 operating system (version 1607 or newer)
    
-   .NET Framework version 4.7.1
    

### Supported Windows Operating System {#subsect_1518045389}

The following table identifies whether specific versions of the Windows 10 operating system (OS) are compatible with the current SCIS for Windows mobile app release.

| SCIS Mobile App Version | Minimum .NET Framework Required | Windows OS Support for SCIS for Windows |
| --- | --- | --- |
| Windows 10 64-bit (Version 1507) | Windows 10 64-bit November Update (Version 1511) | Windows 10 64-bit Anniversary Update (Version 1607) | Windows 10 64-bit Creators Update (Version 1703) | Windows 10 64-bit Fall Creators Update (Version 1709) |
| --- | --- | --- | --- | --- |
| 5.1.6 | .NET 4.7.1 | No | No | Yes | Yes | Yes |

#### Wait Before Updating to New Windows Versions {#subsect_163001779422}

Always wait for notification from NetSuite before you update to a version that's not listed here as 'compatible.' Waiting lets NetSuite ensure SCIS will work with the new version.
