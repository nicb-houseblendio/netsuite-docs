Web developers can use the Extensibility API to customize the display of popup windows in the SCIS shopping cart. Layout and cart components enable web developers to create option and information windows that provide users with feedback about an operation. These windows fill only the amount of space required for the message, so users can still see what they're doing in the cart.

For more information, see the following topics:

-   [Option Windows and Information Windows](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1541202328.html)
