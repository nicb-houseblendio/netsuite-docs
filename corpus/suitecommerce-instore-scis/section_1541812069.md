SuiteCommerce InStore (SCIS) includes the CustomConfiguration.js file where you can change optional settings. This section includes instructions on how to change the file to meet your business needs:

-   For step-by-step instructions, see [Editing the CustomConfiguration.js File](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4369040602.html).
    
-   For more information about optional settings, see [Optional Settings in CustomConfiguration.js](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4301646891.html).
    

## Managed SuiteApp Updates not Applied to CustomConfiguration.js {#bridgehead_4369047571}

SuiteCommerce InStore is a managed SuiteApp, which means that updates and enhancements to the SuiteApp are pushed automatically to your account. However, the JavaScript configuration file for SuiteCommerce InStore is an exception. The CustomConfiguration.js file isn't updated automatically.

When you add or change a section of code in CustomConfiguration.js, those changes remain in place through subsequent automatic upgrades.
