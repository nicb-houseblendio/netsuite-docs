This section describes testing SCIS after applying an update to a tablet's operating system. You should also run these tests after upgrading the SCIS mobile app.

Update one device, then run acceptance tests for your SCIS implementation. Ensure that you test any peripherals you use with SCIS, such as printers and barcode scanners.

If you encounter errors when running any of the acceptance tests, contact Customer Support.

Important:

You must wait for a notification from NetSuite before you update the iOS version on your iPad or the SCIS for iOS mobile application. NetSuite sends a notification after new iOS updates from Apple have been tested on SCIS, and when an updated version of the mobile app is available.

#### Acceptance testing for mobile app updates:

1.  Test the device configuration.
    
    1.  Download the SCIS for iOS app or SCIS for Windows app on a device that hasn't yet been configured.
        
    2.  Follow the instructions on the configuration screen.
        
    3.  Check that you can successfully configure the device.
        
    
    Note:
    
    If the SCIS mobile app has been downloaded and installed on all devices, uninstall the mobile app on one device. Check that you can successfully configure the device.
    
2.  Test the printer configuration. Run the following tests using the printer you configured for SCIS.
    
    1.  When you log in to the SCIS mobile app, select a printer from the menu. The following printer types are supported: Star, Epson, Airprint. If you use OPrint or Printopia, also test with these.
        
    2.  Enter a test transaction. Add an item to the cart, and then process a payment.
        
    3.  Print the receipt.
        
    4.  Check the receipt is printed as expected.
        
3.  Test a barcode scanner:
    
    1.  Connect a barcode scanner to the device running SCIS.
        
    2.  Log in to SCIS.
        
    3.  Scan a barcode.
        
    4.  Check that the corresponding item is added automatically.
        
    5.  Process a test payment.
        
    6.  Print the receipt.
        
    7.  Check the receipt is printed as expected.
        
4.  Test cash drawer operations:
    
    1.  Connect a cash drawer to a printer.
        
    2.  Log in to SCIS.
        
    3.  Perform a cash sale, or perform another drawer operation, such as an Initial Loan or End of Day transaction.
        
    4.  Check that the cash drawer opens automatically.
        
5.  Test fingerprint or Touch ID (iOS mobile app):
    
    1.  On the iPad, go to System Settings. Add a fingerprint in Touch ID & Passcode.
        
    2.  Open SCIS and check the Touch ID box on the login screen.
        
    3.  Log in to SCIS.
        
    4.  Log out of SCIS.
        
    5.  Log in to SCIS a second time.
        
    6.  Check that the Touch ID option populates the email and password automatically.
        
    
    Note:
    
    For more information about configuring Touch ID for SCIS, see [Setting Up SCIS Touch ID for iOS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1495833825.html).
