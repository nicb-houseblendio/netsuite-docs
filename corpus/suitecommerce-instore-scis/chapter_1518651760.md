Fallback lets sales associates perform basic point-of-sale operations when SuiteCommerce InStore (SCIS) isn't available. Sales associates can continue entering orders in Fallback, but some features normally available from the shopping cart aren't available.

For more information about using Fallback, read the following:

-   [Logging into Fallback](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1520271424.html)
    
-   [Handling Fallback Transactions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1518651979.html)
