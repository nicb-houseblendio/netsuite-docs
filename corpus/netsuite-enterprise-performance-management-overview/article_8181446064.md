If you want to load data from NetSuite searches to Oracle Cloud Enterprise Performance Management (EPM) products, read the following help topics:

-   To facilitate connection between NetSuite and the Oracle Cloud EPM products, see [NetSuite EPM Connector SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_6113927158.html).
    
-   To integrate NetSuite and Oracle Cloud EPM Planning and Budgeting, see [NetSuite Planning and Budgeting](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_8124016549.html).
    
-   To integrate NetSuite and Oracle Cloud EPM Account Reconciliation, see [NetSuite Account Reconciliation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1122027339.html).
    
-   To integrate NetSuite and Oracle Cloud EPM Financial Consolidation and Close, see [Close Management and Consolidation Sync SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_33112718443.html).
