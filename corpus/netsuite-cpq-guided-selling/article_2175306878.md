Users can open catalogs from eligible transactions. For more information about eligible transactions, see [NetSuite CPQ Guided Selling Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_7173421493.html).

The basic workflow to search for items from catalogs is as follows:

1.  Open or create an eligible transaction.
    
2.  Complete the required fields.
    
3.  Click the **Guided Selling** button.
    
4.  On the Select Product page, select a catalog.
    
    This page offers an overview of all available catalogs.
    
    Note:
    
    Catalogs are called products on the user interface.
    
5.  To add items to the transaction, click the **Add** button.
    
    For configurable items, users can click the **Configure** button if you've enable it. For more information, see [Working with Configurable Items from Catalogs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_3183653934.html).
    
6.  To exit the catalog interface, click the **Close** button.
    
7.  Save the transaction.
    

If you enable the wish list (called the cart), users first add items there to review their choices. Then, they can click the **Submit** button to add items to the transaction. For more information about the wish list, see [Working with the Wish List (Called the Cart)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_182530422.html#subsect_0110115711).
