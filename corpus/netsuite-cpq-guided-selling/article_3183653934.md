If configurable items match the options users select on the catalog interface, they're automatically included in the search results. The item used for the search is the base item, which is the placeholder item that's added to the transaction and is attached to the configuration. In catalogs, configurable items are associated with an **Add** button by default.

To let users configure these items from catalogs and add them to transactions, you must associate them with the **Configure** button instead. To display this button for configurable search results, go to the item record associated with each configurable item. Under the **Custom** subtab, select a product in the **CPQ Configurator Product** field.

By setting this option, users will see a **Configure** button for the configurable item and can open it from the catalog to configure it. For more information about configurable items, see [NetSuite CPQ Configurator Products](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_6124716984.html).
