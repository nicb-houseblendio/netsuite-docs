Note:

Filter options are called answers on the user interface.

Filter options (called answers) show users the available item attributes and let them express their preferences. Depending on the parent filter type, filter option settings may vary. For example, you can add a text field to a checkbox option or an image to a tile filter option.

Each filter option has an internal name and a corresponding label for the catalog interface. Use the sequence number to sort filter options within a filter. To identify filter options in rules and actions, you can use a shortened version of the name as a code.

#### To create a filter option (called an answer):

1.  In NetSuite, go to Guided Selling > Product > Product Maintenance.
    
2.  Edit a catalog (called a product).
    
3.  Go to the **Questions** subtab.
    
4.  Click the name of the filter (called the question) for which you want to create an option (called an answer).
    
5.  On the **Answers** subtab, click **New CPQG Answer**.
    
6.  Enter a descriptive name for the filter option.
    
    This name is automatically copied to the **Label HTML** field.
    
    To change the name visible to users, edit the text in the **Label HTML** field.
    
7.  In the **Code** field, enter a unique identifier for this filter option.
    
    The code must contain only uppercase letters, numbers, and underscores. You can use a shortened version of the name as the code.
    
8.  In the **Label HTML** field, enter the text displayed on the catalog interface for this filter option.
    
    You can format the text by changing the paragraph font and size, or by making the text bold, italic, or underlined. HTML code can be used to add images or links, but script tags aren't supported.
    
9.  Provide a sequence number to sort the filter option within the filter.
    
    You can enter a negative or positive number, for example, -2 or 5. Filter options are sorted from lowest to highest sequence number.
    
10.  In the **Hide Rule** field, enter the conditions that determine when the filter option should be hidden.
     
     To write conditions, enter filter and filter option codes separated by a forward slash character, for example, A/1. Use operators to combine multiple conditions, for example, A/1&B/2. For more information, see [Activating or Hiding Building Blocks with Rules](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_4145355833.html).
     
11.  In the **Answer Spans** field, enter a number between 1 and 12 to define how many columns the filter option can occupy within the filter space.
     
12.  If you work with options for checkbox or radio button filters, the following options are available:
     
     -   **Add text input** - Adds a single-line text field.
         
     -   **Show input when unchecked** - Always shows the text field, even if users haven't selected the filter option.
         
13.  If you work with filter options for tiles, two options are available to add an image:
     
     -   In the **Image** field, select an image from the File Cabinet.
         
     -   In the **Image URL** field, enter the URL of the image.
         
     
     Note:
     
     If you select an image and provide a URL, only the image from the URL is displayed on the catalog interface.
     
14.  If you work with an input box filter, select one of the following option types:
     
     -   **Free-form text** - Creates a text field.
         
     -   **Dropbox** - Creates a popup list. For more information, see [Working with Popup Lists for Input Box Filters](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_4180618443.html).
         
15.  Depending on whether you work with the default or advanced catalog template, define a basic or an advanced filter expression. For more information, see [Working with Basic or Advanced Filter Expressions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_5181520569.html).
     
16.  Click **Save**.
