Note:

NetSuite CPQ Guided Selling can work independently from NetSuite CPQ Configurator.

NetSuite CPQ Guided Selling lets you create catalogs with advanced filters to search for items and add them to transactions. With catalogs, sales teams can quickly find the best products or services for their customers and close deals faster.

With NetSuite CPQ Guided Selling, you can:

-   Use the default catalog template and let sales teams search for items right away.
    
-   Create advanced catalog templates that provide item selections based on customers' needs.
    
-   Create filters to let users refine search results, which are automatically updated to reflect their preferences.
    
-   Up-sell and cross-sell with additional items.
    
-   Prevent quoting and selling incomplete solutions with required items.
    

After installing NetSuite CPQ Guided Selling, set up basic and additional options. For more information, see [NetSuite CPQ Guided Selling Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_7173421493.html).

After setting up NetSuite CPQ Guided Selling, you can create catalogs, which are the main working units in this SuiteApp. Catalogs represent collections of items that users can search. Each catalog is made up of several building blocks activated or hidden by rules. For more information, see [Creating Catalogs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_2180226163.html) and [Activating or Hiding Building Blocks with Rules](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_4145355833.html).

Catalogs gather all the filters required to display a specific collection of items and offer users an interface and to search for items based on their needs. For more information, see [Working with the Catalog User Interface](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_182530422.html) and [Creating and Organizing Search Filters for the Catalog User Interface](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_4182823513.html).

When catalogs are ready, users can open them from transactions and search for items. For more information, see [Searching for Items from Transactions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_2175306878.html).
