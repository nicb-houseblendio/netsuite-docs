Site Management Tools implements its own file structure in the file cabinet. When you login for the first time, this file structure's set up for you automatically. Images and content templates are stored in the file cabinet. For more information about logging in to Site Management Tools, see [Logging into Site Management Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4163262385.html).

Warning:

Don't move or rename any of the Site Management Tools folders in the file cabinet.

## Location of Site Management Tools Images and Templates {#bridgehead_1117121629}

When you add image content, the images are stored in the file cabinet at the following location:

-   Web Site Hosting Files > Live Hosting Files > SSP Applications > NetSuite Inc.-CMS > CMS > Site- \[Site Number\] > files
    

When you add templates, the templates are stored in the file cabinet at the following location:

-   Web Site Hosting Files > Live Hosting Files > SSP Applications > NetSuite Inc.-CMS > CMS > \[application\] > Published > Templates
    

Warning:

Image and template files stored here are maintained by Site Management Tools. You should never manually add, edit or delete files from these locations.
