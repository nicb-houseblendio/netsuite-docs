To manage content with Site Management Tools, you'll need a valid NetSuite user account with the right permissions. The two roles that provide these permissions by default are the Administrator role and the Store Manager role. There are only a few users with the Administrator role. If you manage content, you'll need the Store Manager role or a custom role with the Site Management Tools permission.
