A catalog is the top level of organization for your categories. Before adding categories to your website, you'll need to set up a catalog. Each website can have only one catalog. To access Commerce catalogs, go to _Commerce > Content Management > Catalog & Categories > Commerce Catalogs_. For more information, see [Set Up Commerce Catalog](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4655070976.html).

Note:

If you create a category before a catalog, a default catalog is automatically created for you.
