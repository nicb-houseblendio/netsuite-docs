You can set up subcategories to override the default category record values. For example, if a subcategory is under two different parents, you might want one page title when viewed through one parent category and a different title through the other.

When you edit a subcategory that appears in more than one place in the category hierarchy, you'll see an Edit Category Overrides option in the More Actions menu. Click this option to override the default subcategory settings for that specific spot in the hierarchy.

Any overrides you set are saved in the category record in NetSuite. For more information, see [Create Subcategories for a Commerce Category](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4655026863.html).
