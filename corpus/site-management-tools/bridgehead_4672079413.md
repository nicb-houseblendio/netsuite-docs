With Site Management Tools (SMT), you can edit a category or subcategory's settings. Any changes you make in SMT show up on the commerce category record in NetSuite.

Warning:

Changing the URL fragment also changes the URL used to access the page. This can cause broken links and page not found errors, so be sure to set up redirects and update any links that go to the page. For more information, see [SEO and Redirects](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2637891.html).

#### To edit a category or subcategory:

1.  Log in to SMT. For details, see [Logging into Site Management Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4163262385.html).
    
2.  Click the Overview Mode icon ![Overview Mode Icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/SiteManagement/OverviewModeIcon.png) on the site management toolbar.
    
3.  In the category list, go to the category or subcategory and click **Edit**. You can also click the ellipsis and select **Edit Settings** from the More Actions menu.
    
4.  Edit the settings.
    
5.  Click **Save**.
