If your account is using Aconcagua or earlier, use the Theme Customizer to manage themes and skins. If you are using the 2019.2 release of SuiteCommerce and SuiteCommerce Advanced or later, see [Theme Skin Manager](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1512491665.html).

The Theme Customizer lets you edit the appearance of your website. You can make subtle changes like font color, or something more dramatic like a dark background. There are various controls for customizing website attributes. The elements you can customize can vary from theme to theme, and even between different skins in the same theme. You'll see these elements listed in the side panel when you select the Theme Customizer from the SMT Settings menu. As you make edits, you'll see the changes in the preview pane.

Note:

Only Store Manager or Administrator roles can use the Theme Customizer. If one of these roles creates a custom role, and gives that custom role access to the SMT, that role is unable to access the Theme Customizer.

## Theme Customizer Prerequisites {#subsect_1518635629}

To use the Theme Customizer in Site Management Tools (SMT), your domain and theme must meet the following requirements:

-   You must implement version 3 of SMT.
    
-   Your web store must use a release of SuiteCommerce or SuiteCommerce Advanced prior to 2019.2.
    
-   The theme deployed to the domain must include elements that can be edited, such as heading fonts and background color.
    

## Selecting a Skin in Theme Customizer {#subsect_158768465818}

A theme can include one or more skins. A skin is a group of elements that are designed to compliment each other. You can quickly change the appearance of your domain, simply by choosing a different skin. To choose a skin, you select it from the **Skin** dropdown menu at the top of the Theme Customizer. When you select a skin two things happen:

1.  The site preview updates to reflect the attributes of the skin. The variables are reset to their defaults for each new skin selected.
    
2.  The Theme Customizer displays the attributes that can be customized for the selected skin.
    

Some themes have no skins. In this case, the **Skin** dropdown menu is not displayed, and the Theme Customizer shows the attributes that can be customized for the current theme.

### Restoring a Theme in Theme Customizer {#subsect_158773979238}

If you made changes and later decide you prefer the original theme, click Restore Defaults at the bottom of the Theme Customizer in the side panel.
