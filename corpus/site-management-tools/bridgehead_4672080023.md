With Site Management Tools (SMT), you can move and reorder categories and subcategories directly from the category list. This includes:

-   Moving a root level category to a subcategory position under a different root level category
    
-   Moving a subcategory to a root level category position
    
-   Reordering categories and subcategories
    

Warning:

Moving a category or subcategory changes the page's URL, as well as the URLs for any subpages (like item detail pages). This can cause broken links and page not found errors, so be sure to set up redirects and update any links. For more information, see [SEO and Redirects](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2637891.html).

A few important things to remember when moving categories or subcategories:

-   You can't move a subcategory to the root level in the category hierarchy if a copy of the subcategory already exists somewhere else in the hierarchy tree.
    
-   You also can't make a subcategory its own subcategory.
    

#### To move a category or subcategory:

1.  Log in to SMT. For details, see [Logging into Site Management Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4163262385.html).
    
2.  Click the Overview Mode icon ![Overview Mode Icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/SiteManagement/OverviewModeIcon.png) on the site management toolbar.
    
3.  In the category list, point to the category or subcategory you want to move and click the ellipsis to display the **More Actions** menu.
    
4.  Click **Move**.
    
5.  In the category list, point to the location where you want to move the category or subcategory. A drop indicator marks the location where you can place the category or subcategory. Click the indicator to move the category or subcategory to the new location.
    
    Note:
    
    If you want to move a category to a subcategory location, expand the parent level category and then click the subcategory position where you want to drop the category.
    
6.  Click **Save**.
