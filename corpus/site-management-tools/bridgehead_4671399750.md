If a subcategory is linked to more than one parent category, you can use the Remove From Parent option to break the link between the subcategory and parent category.

When removing a category from a parent, there are some situations to be aware of, specifically when the subcategory is nested several levels below the root category and the same subcategory structure exists for multiple root level categories.

Consider the following category hierarchy:

![An example of subcategories in a parent category.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/SiteManagement/RemoveFromParentExampleTree.png)

In this example the root level categories are **Men's** and **Hiking**. The category structure beneath the root level categories are the same:

-   /shoes/dress
    
-   /shoes/boots
    

If you remove the **Dress** subcategory from the **Hiking** category branch, it is also removed from the **Men's** category branch. This occurs because the subcategory **Dress** has the same parent category of **Shoes** assigned to it.

To keep the category in the **Men's** branch, create a new category called **Men's Shoes**, then move **Dress** and **Boots** under it. Now you can safely remove **Dress** from **Hiking** without affecting **Men's**.

Note:

The **Remove From Parent** option is only available if the subcategory has more than one parent. If the subcategory has only one parent, use the **Move** option to move the category to a root level category or to a subcategory position under a different parent category. If the category is no longer needed, then you can delete it or you can use the **Hide in Site** option to leave the subcategory assignment unchanged but make the subcategory unavailable on the website.

#### To remove a subcategory from a parent: {#procedure_4671265427}

1.  Log in to Site Management Tools (SMT). For details, see [Logging into Site Management Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4163262385.html).
    
2.  Click the Overview Mode icon ![Overview Mode Icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/SiteManagement/OverviewModeIcon.png) on the site management toolbar.
    
3.  In the category list, go to the subcategory you want to remove from the parent and click the ellipsis to display the **More Actions** menu.
    
4.  Click **Remove from Parent**.
    
5.  In the pop up that appears, click **OK**.
