There are currently two supported versions of Site Management Tools (SMT), versions 2 and 3. Two important differences between the versions are the available features and native compatibility with different versions of SuiteCommerce and SuiteCommerce Advanced. By default, SuiteCommerce Kilimanjaro and greater use SMT version 3. Versions of SuiteCommerce prior to Kilimanjaro, use SMT version 2.

For documentation specific to Version 2 of SMT, see [Site Management Tools Version 2](https://system.netsuite.com/app/help/helpcenter.nl?fid=SiteManagementToolsV2.pdf).

## Determine Your Version of SMT {#bridgehead_4806935576}

You can determine which version of SMT is enabled by inspecting the admin URL. The admin URL is displayed in the browser's address bar when you are logged in to SMT. In the following URL, the number between **/cms/** and **/admin/** is **3**. This indicates SMT version 3 is enabled on the site. If SMT version 2 is enabled on the site, then this number would be 2.

`http://my.webstore/cms/3/admin/cms.jsp`

## SuiteCommerce and SuiteCommerce Advanced Releases and New Features {#subsect_1549999815}

The following headings identify each release of SuiteCommerce and SuiteCommerce Advanced. For each release, you see the SMT features introduced and a link to the corresponding help topic.

### 2021.1 Release {#subsect_161038473652}

[Merchandising Zone Content](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_159561426850.html) - This lets you display complementary, cross-sell or up-sell products. The functionality of the enhanced merchandising zone is similar to that of the legacy merchandising zone, however it includes a configurable display, support for multiple languages, and it is compatible with SuiteCommerce Themes.

[Exporting and Importing Bulk Translation Content in Site Management Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161013787933.html) - You can export bulk content that requires translation on your web store and import the translated content back into SMT from the **Translations** subtab in overview mode.

### 2020.2 Release {#subsect_160259611740}

[Enhanced Pages](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4344038220.html) - You can now preview and manage enhanced pages from the Overview Pages list.

[Field Type Descriptions for Custom Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2842731.html) - When creating a custom field type the List/Record and Multi-Select types now include the ability to add and remove items directly from the list in SMT. It also includes the ability to search the list directly in SMT. Also, longer lists are loaded in succession as the list is scrolled through.

[CMS Page Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1540560212.html) - The CMS Page Types feature now supports child records.

### 2020.1 Release {#subsect_158048313626}

[Commerce Category Customer Segment Assignment](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157919236673.html) - This lets you assign a commerce category to a specific customer segment inside Site Management Tools.

[Multi-Language Sites](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_159847476054.html) - This lets you assign customized translation names for your commerce categories.

### 2019.2 Release {#subsect_156267697952}

[Site Management Toolbar](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_4193574559.html) - Click the Oracle NetSuite logo to log in to your NetSuite account.

[SMT Links Portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156201804002.html) - Use the portlet to access preview and edit modes of all your available domains.

[CMS Page Import](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1560800028.html) - This lets you use CSV Import for pages and tags.

[Content Tags and Filter Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1524601707.html) - Tags are available to use with commerce categories and CSV imports.

[Pages](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1524601707.html#subsect_1556049710) - Pagination is integrated with the sort and filter tools to make finding content easier.

[Site Management Tools Custom Content Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4809772539.html) - The ability to associate child records to parent records lets you use more complex data sets for custom content types.

[Page Types Domain Level Data](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1546462905.html#subsect_1553026443) - This lets you assign specific page types to specific domains instead of to the NetSuite account.

[Using SMT Advanced Preview to Verify Personalized Catalog Views](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1560334720.html) - This lets you preview your site based on how a specific customer would see your site.

[Exclude Empty Commerce Categories](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156260198217.html) - This lets you conditionally hide categories based on the number of items returned.

[Site Management Tools Page Layout Selector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1549386933.html) - This lets you override any page types having a default template to any other available page type.

[Theme Skin Manager](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1512491665.html) - You can create, save, and reuse multiple skins for your currently installed theme.

### 2019.1 Release {#subsect_1548277547}

[Published Content in Site Management Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4140813799.html#subsect_1513889549) - Manage published content in new ways on your site using the URL, tags, visibility dates, and more.

[CMS Page Types](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1540560212.html) - Create specific, custom parameters for grouping together and identifying new pages.

### 2018.2 Release {#subsect_1548277521}

[CMS Page Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1497970526.html) - Delete a page record without logging into SMT.

[Visibility Dates for Categories](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1529516508.html) - Control when commerce categories are visible on the site by specifying start and end dates.

[Image Manager](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1530202893.html) - Upload images from your computer to the file cabinet or from the file cabinet or computer to your site using the Image Manager.

[Landing Pages](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4344038011.html) - Create Landing Pages and edit them in either their unpublished or published states.

[Content Tags and Filter Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1524601707.html) - Add tags to content and use the filter for bulk actions such as publishing or editing content.

[Site Management Tools Text Content](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4123521463.html) - Add images, perform text alignment, and view in HTML in this update to the text editor.

### Aconcogua Release (2018.1) {#subsect_1548277466}

[View Site as of a Specific Date in Site Management Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1513783026.html) - Control when content and landing pages are visible by specifying start and end dates.

[Theme Customizer (Aconcagua or Earlier)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159078539047.html) - Customize the look and feel of your site by changing the attributes of certain elements on your sites such as the size and color of headings and other text.

### Kilimanjaro Release (2017.2) {#subsect_1548277427}

[Site Management Tools Custom Content Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4809772539.html) - Create custom website applications and features.

[Internationalization of Site Management Tools Administration](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1495655910.html) - Choose your SMT admin language.
