Note:

The Site Management Tools (SMT) administrator interface supports the following web browsers: Chrome, Firefox, and Microsoft Edge. Starting with release 2024.2, access to SMT administration is blocked if third-party cookies are enabled in your browser. For more information, see [Site Management Tools Browser Requirements](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4654863580.html).

Site Management Tools (SMT) lets you manage your web store's content and appearance. SMT provides a flexible user interface to organize, edit, preview, and publish site content efficiently. When you log into SMT, you'll see the site management toolbar, where you can manage your content.
