With Site Management Tools (SMT), you can enable and disable core content types and custom content types. For a list of the different types of content that area available, see [Content Type Table](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1536699874.html).

#### To enable content types in Site Management Tools:

1.  Click the Edit Page Settings icon, denoted by the gear icon.
    
2.  Select **Custom Content Types** to open the Custom Content Type Settings.
    
3.  From Inactive Content Types, click and drag the content type you want to enable to Active Content Types. This content type will now appear in edit mode when you click the Add icon ![Add icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/SiteManagement/SiteMangementToolsAddIcon.png) from the site management toolbar.
    
4.  To exit, select a different mode from the toolbar.
    

#### To disable content types in Site Management Tools:

1.  Click the Edit Page Settings icon, denoted by the gear icon.
    
2.  Select **Custom Content Types** to open the Custom Content Type Settings.
    
3.  From Active Content Types, click and drag the content type you want to disable to Inactive Content Types.
    
    When you disable a content type, you can't add new content of that type, but existing content of that type still appears on your site.
    
4.  To exit, select a different mode from the toolbar.
