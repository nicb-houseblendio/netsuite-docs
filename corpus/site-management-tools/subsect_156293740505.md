Click the Overview Mode icon ![Overview Mode Icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/SiteManagement/OverviewModeIcon.png) on the site management toolbar to manage categories, pages, published and expired content, and translations. The following screenshot shows the options you have when working in overview mode:

![Site Management Tools Overview Mode](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/SiteManagement/SiteManagementToolsOverviewMode.png)

| Item | Description |
| --- | --- |
| 1 | Click **Categories** to manage commerce categories, which are used to create a hierarchical structure of product categories, subcategories, and products. For details, see [Commerce Categories in Site Management Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4567835433.html). |
| 2 | Click **Pages** to manage landing pages and custom pages, or edit existing enhanced pages. For details, see [Pages](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4314594735.html). |
| 3 | Click **Published Content** to view all current published content. For details, see [Published Content in Site Management Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4140813799.html#subsect_1513889549). |
| 4 | Click **Expired Content** to view all expired content. For details, see [Reuse Expired (Discarded) or Deleted Content](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163899988342.html). |
| 5 | Click **Translations** to view all content for translations, including both published and unpublished content. For details, see [Managing Your Translation Content](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161487645303.html). |
