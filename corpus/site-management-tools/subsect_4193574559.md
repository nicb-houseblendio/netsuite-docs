Note:

The Site Management Tools administrator interface supports the following web browsers: Chrome, Firefox, and Microsoft Edge. Starting with release 2024.2, access to SMT administration is blocked if third-party cookies are enabled in your browser. For more information, see [Site Management Tools Browser Requirements](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4654863580.html).

When you log in to Site Management Tools (SMT), you'll see the site management toolbar at the top of the screen. For details about logging into SMT, see [Logging into Site Management Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4163262385.html). The following screenshot shows the options that are available from the toolbar:

![Site Management Toolbar](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/SiteManagement/SiteManagementToolbar.png)

| Item | Description |
| --- | --- |
| 1 | Click the Oracle NetSuite logo to open a new tab and automatically log in to your NetSuite account. |
| 2 | Click the Overview Mode icon to manage categories, pages, published and expired, and translations. For details, see [Site Management Tools Overview Mode](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_156293740505.html). |
| 3 | Click the Preview Mode icon to see how your site looks to visitors. In preview mode, area highlighting and the edit and remove buttons are hidden. For details, see [Site Management Tools Preview Mode](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_156417532993.html). |
| 4 | Click the Edit Mode icon to change, remove, or add new content. For details, see [Site Management Tools Edit Mode](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_156417533466.html). |
| 5 | Click the Review & Publish Changes icon to view all unpublished changes and any content that displays or expires in the future. For details, see [Review and Publish Content in Site Management Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4419210472.html) and [View Site as of a Specific Date in Site Management Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1513783026.html). |
| 6 | Click the gear icon to access Custom Content Types and Page Layout Settings. For details, see [Enabling or Disabling Content Types in Site Management Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4815773002.html) and [Site Management Tools Page Layout Selector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1549386933.html). If your account has an active theme, you can also access the Theme Skin Manager from here. For more information, see [Theme Skin Manager](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1512491665.html). |
| 7 | Click the help icon to go to the NetSuite Help Center. |
| 8 | Click the user icon and select **Sign Out** to log out of SMT. When you sign out, you're also logged out of your NetSuite account. |
| 9 | This displays the URL fragment of the current page. |
| 10 | In preview and edit modes, you can select a date and time to preview or edit your site. This lets you see content with a future start date or time that's not shown yet. For details, see [View Site as of a Specific Date in Site Management Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1513783026.html). |
| 11 | In preview or edit modes, click the Preview Screen Sizes icon to see how your site is looks on different devices. For details, see [Previewing Screen Sizes in Site Management Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4480324379.html). |
| 12 | In preview mode, click **Include Unpublished Changes** to see any unpublished changes on your site. For details, see [Include Unpublished Changes in Site Preview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1513888465.html). |
| 13 | In preview mode, click **Advanced Preview** to view your site based on different customer groups. For details, see [Site Management Tools Preview Mode](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_156417532993.html). |
