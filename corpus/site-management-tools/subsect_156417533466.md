Click the Edit Mode icon ![Edit Mode Icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/SiteManagement/EditModeIcon.png) on the site management toolbar to change, remove, or add content to your site. In edit mode, the option to add content and edit page settings is displayed in the toolbar. The option to include unpublished changes only appears in preview mode. The following screenshot shows the toolbar options when working in edit mode:

![Site Management Toolbar Edit Mode](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/SiteManagement/SiteMangementToolsEditMode.png)

| Item | Description |
| --- | --- |
| 1 | Click the Add icon to add content. This will open a side panel where you can select the type of content, like a blog post or image text overlay. For information about the different types of content you can add, see [Website Content](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/preface_1536077865.html). |
| 2 | Click the Preview Screen sizes icon to simulate and preview how your site is displayed on different devices and screen sizes. For details, see [Previewing Screen Sizes in Site Management Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4480324379.html). |
| 3 | Click the Edit Page Settings icon to edit or remove enhancements from a page. For details, see [Enhanced Pages](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4344038220.html). |
