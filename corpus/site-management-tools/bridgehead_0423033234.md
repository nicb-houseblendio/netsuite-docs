The SMT Core Content Types bundle (Bundle ID 190323) lets you create the core content types in Site Management Tools. Core content types include image, text, merchandising zone, and HTML. These content types help in the build-out of your SuiteCommerce site. For details, see [Site Management Tools Content Options](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4165977748.html).

When you install the bundle, you must activate the Core Content Extension. If you don't activate the extension, the core content types are unavailable in Site Management Tools.

#### To install the SMT Core Content Types bundle:

1.  Go to _Customization > SuiteBundler > Search & Install Bundles_.
    
2.  In the **Keywords** Keywords field, enter SMT Core Content Types.
    
3.  Click **Search**.
    
4.  Select SMT Core Content Types from the search results.
    
5.  Click **Install**.
    
6.  When the bundle install is complete, go to Commerce > Extensions > Extension Manager.
    
7.  Click **Edit** next to the website and domain where you want to install the bundle.
    
    Note:
    
    If you're creating a new activation, see [Creating a New Activation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1549026512.html).
    
8.  Select the **Extensions** tab.
    
9.  Check the **Active** box next to Core Content Extension.
    
10.  Click **Activate**.
     
11.  If this is the initial activation for a domain, clear the domain's cache by triggering a cache invalidation request. For details, see [Cache Invalidation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4169406426.html).
