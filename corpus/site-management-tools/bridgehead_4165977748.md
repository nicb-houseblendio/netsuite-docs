Managing your web store means organizing information and visuals so customers can easily find what they need. Site Management Tools (SMT) provide several content types you can add to your site. When you install the SMT Core Content Types bundle (Bundle ID 190323), the following core content types are available:

-   **Image Content** - Use this to add images like home page banners, promotional graphics, or images that link to product categories. Each image can link to a specific URL, and you can add alternate text to use when an image doesn't load for page readers. For details, see [Site Management Tools Image Content Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4123521956.html).
    
-   **Text Content** - Add blocks of text, headers, footers, and hyperlinked text. This is useful for section titles, descriptions, and informational paragraphs anywhere on your site. For details, see [Site Management Tools Text Content](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4123521463.html).
    
-   **Merchandising Zone Content** - Show lists of products based on the merchandising rules you set in NetSuite. For example, feature certain products or best-sellers. You can choose between two merchandising zone types:
    
    -   Legacy merchandising zone
        
    -   Enhanced merchandising zone, which offers more customization, supports multiple languages, and works with SuiteCommerce Themes. With the enhanced merchandising zone you can present your products in a consistent way, but also have the choice to display products differently throughout your web site to match your brand quality.
        
    
    For details, see [Merchandising Zone Content](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_159561426850.html).
    
-   **HTML Content** - Add custom code to display videos, social media feeds, forms, or other interactive features. For details, see [Site Management Tools HTML Content Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1537278615.html).
    

Note:

If the core content types appear dimmed out when you sign in to Site Management Tools make sure that you have correctly installed the SMT Core Content Types bundle and activated the accompanying Core Content Extension. For details, see [Site Management Tools Installation and Implementation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4098551783.html).

Note:

Template files control the structure of your website pages. Commerce web stores include page templates that already have set areas. You can use these areas as they are, edit the areas, or add new areas to the templates. For details, see [Site Management Tools Templates and Areas](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4237799135.html).

Tip:

If you need something not covered by the core content options, you can create Custom Content Types. These let you add entirely new content or features developed specifically for your store. For more information, see [Site Management Tools Custom Content Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4809772539.html).
