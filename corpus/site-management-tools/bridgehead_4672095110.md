Deleting a category removes it, and it can no longer be used. Delete a category only when you are certain that you no longer need it. You can't delete a category that has subcategories. To delete the category you must first delete or move its subcategories. You can delete a category if it has items assigned to it. If you delete a category with items, only the category is deleted and not the items.

Warning:

If you delete a subcategory, it's removed from all parent categories it's linked to. If you want to remove the subcategory from only one parent, then use the **Remove From Parent** option instead. For details, see [Removing a Subcategory from a Parent Category](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4671399750.html).

If you want to hide a category but not delete it, you can either hide it in the site or make it inactive by selecting the **Inactive** box on the Commerce Categories page (Commerce > Content Management > Commerce Categories). For more information, see [Hiding a Category or Subcategory](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4672093582.html) and [Commerce Categories](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4673202005.html).

#### To delete a category or subcategory:

1.  Log in to Site Management Tools (SMT). For details, see [Logging into Site Management Tools](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_4163262385.html).
    
2.  Click the Overview Mode icon ![Overview Mode Icon](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Commerce/SiteManagement/OverviewModeIcon.png) on the site management toolbar.
    
3.  In the category list, go to the category or subcategory you want to delete and click the ellipsis to display the **More Actions** menu.
    
4.  Click **Delete**.
    
5.  In the pop up that appears, click **OK**.
