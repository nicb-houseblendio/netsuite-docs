Custom employee roles need Full permission to edit custom records for Site Management Tools, while custom customer roles need View permission to see the content. Content types include text, images, HTML, and merchandising zones. For details, see [Custom Record for CMS Content](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1498661236.html).

#### To change the custom record permissions for custom roles:

1.  Go to Setup > Users/Roles > Manage Roles.
    
2.  Next to the custom employee role or the custom customer role, click **Edit**.
    
3.  Select the **Permissions** tab.
    
4.  Select the **Custom Record** subtab.
    
5.  For each custom record listed below, set Full permission for custom employee roles and View permission for custom customer roles in the **Level** column.
    
    -   CMS\_HTML
        
    -   CMS\_IMAGE
        
    -   CMS\_MERCHZONE
        
    -   CMS\_MERCHZONE2
        
    -   CMS\_TEXT
        
6.  Click **Save**.
    

For more information about custom records, see [Custom Record for Custom Content Type](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4809772578.html).
