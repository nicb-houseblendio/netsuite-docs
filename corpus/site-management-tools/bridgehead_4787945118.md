Note:

This feature is available in Elbrus and later releases.

The Escape to Login feature that's set on the SuiteCommerce Configuration record lets you choose if you want to access Site Management Tools by pressing the Esc key or using the administrator URL. For more information, see [Configuring Escape to Log In](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1488385475.html).

When Disable Esc Key to Login is enabled, you can go to the home page of your site and press the Esc key to display the login screen. If you've already logged in to your NetSuite account, pressing the Esc key displays the Site Management Tools toolbar.

When Disable Esc Key to Login is disabled, the Esc key functions normally, and you access Site Management Tools for your site at the following administrator URL:

-   For Kilimanjaro or later, http://my.webstore/cms/3/admin/cms.jsp
    
-   For Elbrus or earlier, http://my.webstore/cms/2/admin/cms.jsp
    

If you don't know which version you're running, check your Commerce web stores configuration and make sure the CMS Adapter version matches. Go to Commerce > Websites > Configuration > \[Select Site\] and \[Select Domain\] > Integrations > Site Management Tools.

When you go to the administrator URL, you'll see the Site Management Tools login page where you can enter your NetSuite credentials.
