Note:

Note that DKIM keys aren't copied to non-production accounts. You can set up DKIM keys in non-production accounts but it's not necessary. Based on the email preferences set in sandbox or Release Preview accounts, email is usually delivered only to a specified list of addresses, or to the logged-in user. For more information, see [Setting Preferences for Sandbox Email](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N334772.html) or [Setting Preferences for Release Preview Email](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1549916016.html#subsect_162376811938).
