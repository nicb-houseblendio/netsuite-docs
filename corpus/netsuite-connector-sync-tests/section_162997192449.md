You can activate order and fulfillment sync after successfully testing them.

Before you activate your syncs, make sure you've read and understood the process in [NetSuite Connector Deployment to Production](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163003075284.html).

This procedure will activate order and fulfillment sync.

#### To activate order and fulfillment sync:

Your order and fulfillment sync will now run. NetSuite Connector will now handle all the processes you tested manually.

1.  Log in to NetSuite Connector.
    
2.  On the left panel, select the relevant connector or account.
    
3.  Click **Data Flows** > **Manage Data Syncs**.
    
4.  Set **Order Sync** to **On**.
    
    You'll see a message about completing order mappings.
    
5.  Click **Enable**.
    
6.  Set **Fulfillment Sync** to **On**.
    

Note:

Before using Price/Qty or Full Product Sync, you'll need to activate it first before using it in live production.
