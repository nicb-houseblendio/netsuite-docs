Note:

Before setting up 3PL sync, make sure you've added and authorized your 3PL connector as described in [Adding a Connector to a NetSuite Connector Account](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162754916161.html).

To test 3PL sync, you'll need a sales order in NetSuite with a **Pending Fulfillment** status. If you're using NetSuite Connector for order sync, choose an order that's already been synced.

When you have identified the order record to use for test, note down its transaction ID found in the **Order #** field.

Proceed to [Testing NetSuite Connector ShipStation Sync](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162746504739.html).
