When validating settlement sync, consider the following:

-   Ensure the test report shows **Complete** status in NetSuite Connector. Fix or cancel any errors you find. If there are no errors, the synced data should be accurate.
    
-   If an order has cancelled postings, the data won't be accurate.
    
-   Check both a refunded and non-refunded order to ensure the records in NetSuite match Amazon's data.
    
    Note:
    
    NetSuite Connector syncs data from the Amazon settlement report (v2). Amazon Seller Central should show the same data as the report. If you find a mismatch, download the report from Amazon Seller Central and check the data.
    

## Enabling Settlement Sync {#bridgehead_163064657317}

After completing steps 1 and 2, you can activate settlement sync. Activate settlement sync after the Amazon connector is live, since it needs orders that were previously synced by NetSuite Connector. If you're setting up Amazon order sync and settlement sync for the first time, review the going live topics before activating. For more information, read [NetSuite Connector Deployment to Production](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163003075284.html).

Before enabling settlement sync, consider adjusting the cutoff date for settlement reports.

For more information, read [Setting the Amazon Settlement Report Cutoff Date](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162884600373.html#section_164180043919).

#### To enable settlement sync:

1.  Log in to [app.farapp.com](https://app.farapp.com).
    
2.  Select Amazon connector and the relevant account.
    
3.  Go to Data Flows > Manage Data Syncs.
    
4.  Click the Settlement Sync switch to enable the settlement sync.
    
    The Settlement Sync now runs. NetSuite Connector will now automatically handle all the processes you tested manually.
