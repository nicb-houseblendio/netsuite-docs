Amazon usually releases settlement reports every two weeks. The report includes transactions with settlement fees and credits from the past two weeks.

To start testing, check if you have any settlement reports ready to download.

Note:

Choose a report that includes orders that NetSuite Connector has already synced with NetSuite. If the report includes orders that NetSuite Connector hasn't synced, you'll get errors. To stop the error notifications, you'll need to cancel the postings for those orders.

If you don't have any reports, ask Amazon to generate a report for you. For more information, read [Importing Amazon Settlement Reports in NetSuite Connector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162884600373.html).

After you get report ID of the report that you want to use for testing, proceed with the following procedure.

#### To test settlement sync:

1.  Log in to [app.farapp.com](https://app.farapp.com).
    
2.  Select Amazon connector and the relevant account.
    
3.  Go to Data Flows > Settlements.
    
4.  Click **Retrieve**.
    
    The Retrieve Settlement Report into FarApp window opens.
    
5.  In the **Settlement Report ID** field, enter the report ID.
    
6.  Click **Retrieve**.
    
    NetSuite Connector pulls the settlement report from Amazon. This may take a few minutes.
    
    You'll see a success message, and the report will be added to your list of settlement reports.
    
7.  Click **Close**.
    
8.  Locate the imported report and click the **Action** menu (pencil icon) and select **Post**.
    
    NetSuite Connector will sync the report in the background. This may take a few minutes. Larger reports might take up to a day to sync and update the status.
    
    After NetSuite Connector attempts to post each settlement fee and credit, the status of the report appears. If the status of the sync is **Complete**, skip the remaining part of the procedure. If there are errors in the sync, the report displays the errors.
    
9.  If the report shows errors in the status, check each error and take one of the following actions:
    
    1.  Cancel the posting.
        
        If you decide to cancel the posting, the settlement data for that posting does not sync with NetSuite.
        
    2.  Fix the error.
        
10.  Repeat the posting from step **8**.
     

After the settlement report shows **Complete** status, you can activate the settlement sync.
