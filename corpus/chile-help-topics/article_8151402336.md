## Overview {#bridgehead_g4p_sdq_1fc}

The following help topics provide information about NetSuite features that are specific to companies doing business in Chile. The NetSuite International Edition can be configured with capabilities and reports specific to a Chilean business setting and requirements.

To know more about localized editions of NetSuite, as well as setting up NetSuite accounts and subsidiaries, refer to the following help topics:

-   [NetSuite Editions Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N270055.html)
    
-   [Set up NetSuite OneWorld](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N268052.html)
    
-   [Creating Subsidiary Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N272471.html)
    
-   [Introduction to NetSuite OneWorld](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N266468.html) - for companies using NetSuite across multiple subsidiaries and countries
    

Please note that general NetSuite features are covered in other chapters and topics.

## Required Licenses {#bridgehead_0703030852}

To install the Chile Localization SuiteApp, make sure you have the NetSuite SuiteApps License Client and a OneWorld account set up.

#### To access the features of the Chile Localization SuiteApp:

1.  Install the NetSuite SuiteApp License Client (Bundle ID 116144)
    
2.  Obtain a license for the Chile Localization SuiteApp - Contact your account manager, who will arrange for a license to be generated.
    
3.  Verify that the NetSuite SuiteApp License Client has the license 'NetSuite Chile Localization.'
    

If the license client is not installed or your license expires, you will not be able to use the features of the SuiteApp. For more information see [NetSuite SuiteApps License Client Guide for Administrators](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4635371677.html)

Contact your account representative to reinstate any state licenses.
