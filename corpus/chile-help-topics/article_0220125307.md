Chile Localization reports withholding taxes and other deductions on transaction records.

Map the applicable tax codes so that NetSuite reports these amounts correctly.

## Mapping Standard NetSuite Fields to Categories Required by the SII {#subsect_0220010900}

#### To map standard NetSuite fields to categories required by the SII:

1.  Go to Setup > Chile Localization > Chile Field Mapping.
    
2.  In the **Category** field, select **Taxes List**.
    
3.  In the mapping area, enter the following information:
    
    1.  In the **Values** field, select **CL IVA Taxes**, **CL Exempt Taxes**, or **CL Withholding Taxes**.
        
    2.  In the **CL Código de Impuesto o Retención** field, select a withholding code. This value applies only to **CL Withholding Taxes**.
        
    3.  Map each **Values** option to the applicable **Tax Code**. These mappings are available when you run Libro de Honorarios.
        
4.  Click **Save**.
