The following information from your Belgium subsidiary record are included in the Fiche 281.50 report and are subject to the Fiche report's character limitations:

Important:

Spaces count as characters. For example, **(123) 456 789 101** has 17 characters.

| Field Name | Maximum Number of Characters | Used in this Tag |
| --- | --- | --- |
| **Legal Name** (legalname) If blank, the entry in **Name** (name) field is used. | 28 | 
-   v0014\_naam
-   a1011\_naamnl1 /a1027\_naamfr1 / a1032\_naamde1

 |
| **BCE/KBO/ZDU Number** | 10 | 

-   v0024\_nationaalnr
-   a1005\_registratienummer

 |
| **Address 1** (addr1) | 32 | 

-   v0015\_adres
-   a1013\_adresnl /a1029\_adresfr / a1034\_adresde

 |
| **Zip** (zip) | 4 | 

-   v0016\_postcode
-   a1014\_postcodebelgisch

 |
| **City** (city) | 27 | 

-   v0017\_gemeente
-   a1015\_gemeente / a1030\_gemeentefr / a1035\_gemeentede

 |

To edit a subsidiary record, go to Setup > Company > Classifications > Subsidiaries. Then, click **Edit** next to the name of the subsidiary record that you want to edit.

To edit the subsidiary's address information (zip, city), go to the Addresses subtab and edit the **Address** field.
