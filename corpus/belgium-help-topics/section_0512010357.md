This section refers to the issue of a disabled XML export icon for the SuiteTax-based Belgium VAT report provided by the Belgium Localization SuiteApp.

The XML export icon may be disabled if you're using a custom template for the tax report filters. As a workaround, you can disable **Use Custom Template** and reconfigure the filters before generating the VAT report.

#### To resolve the issue of a disabled XML export for the VAT report: {#procedure_0512011557}

1.  Go to Setup > Tax Reporting > Tax Returns.
    
2.  Click **View** next to Periodic VAT return - 625.
    
3.  Print or take a screenshot of the full page so that you can reliably reconfigure the filters with the same setup:
    
    1.  For Firefox browsers, you can right-click on the page and click **Take screenshot**.
        
    2.  For Chrome, you can right-click on the page and click **Print** or use the GoFullPage chrome extension.
        
4.  Disable **Use Custom Template**.
    
5.  Set up the report filters following the setup shown on the screenshot from step 3.
    
    Note:
    
    When you click **Save** after adding a filter, you'll notice that the **Use Custom Template** is switched back on. You can disregard this behavior.
    
6.  Go to Reports > Tax > Country Tax Reports.
    
7.  Generate the Belgium VAT 625 report again.
    
8.  When the report is ready for viewing, click **View**.
    
9.  Click the XML export icon to export the report to XML format.
