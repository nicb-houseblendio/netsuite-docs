You can make corrections to the Fiche 281.50 report you submitted to the Belgium tax administration. Revisions to the report must be identified with a reference code that you received from the Belgium tax administration. This reference code will appear in the **v0026\_referte** tag in the Fiche report after you generate the report with the revisions.

#### To make revisions to the Fiche 281.50 report: {#procedure_0417030118}

1.  Make the necessary corrections to your entity or transactional information on their respective records.
    
2.  Go to Reports > Tax > Country Tax Reports.
    
3.  In the Subsidiary field, select the same Belgium subsidiary that you selected when you last generated the Fiche report.
    
4.  In the Report Name field, make sure **Fiche 281.50** is selected.
    
5.  Click **Revise Fiche Report**.
    
6.  In the Reference Code field, enter the code that you obtained from the Belgium tax administration when you first submitted the report. The reference code is at most 6 characters.
    
7.  Click **Save**.
    
8.  Generate the report again.
    

Note:

If you haven't submitted the revised report yet and you want to make another set of revisions, enter the same reference code again. Whenever you submit any version of your Fiche report to the tax administration, you'll get a reference code. Use the reference code you received to make subsequent revisions to your report.
