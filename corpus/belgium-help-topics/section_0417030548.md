The date and number formats in the preview of the Fiche 281.50 report depends on your formatting preferences. If you want to change the formatting, go to Home > Set Preferences. On the Formatting subtab, set your preferred formatting in the **Date Format** and **Number Format** fields.

Your formatting preferences don't affect the date and number formats in the XML file of the Fiche report. The XML file follows the statutory specifications in formatting.
