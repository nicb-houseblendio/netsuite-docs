Note:

This topic is for NetSuite accounts that use the EU Intrastat Report page to generate the Intrastat report. If you're using the Country Tax Report page, see [Belgium Intrastat](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157538424588.html).

The Intrastat Report gets the following information from the **Tax Reporting** subtab and **Items** sublist of transaction forms and item records:

-   Region of Origin
    
-   Nature of Transaction Code
    
-   Delivery Terms
    
-   Mode of Transport
    
-   Commodity Code
    
-   Supplementary Unit
    
-   Country of Origin
    
-   Partner ID
    

You must fill out these fields on the **Tax Reporting** subtab and in the **Items** sublist to generate fulfilled Intrastat Dispatches and Arrivals reports.

## Belgium Intrastat Report Fields on Transaction Forms {#bridgehead_1553741645}

If your NetSuite account nexus is a member of the European Union (EU), expect the following system behavior upon installation of the International Tax Reports SuiteApp:

-   If you choose an EU vendor or EU customer on a transaction form, the Tax Reporting subtab is displayed on the form.
    
-   If you choose a non-EU vendor or customer on a transaction form, the Tax Reporting subtab isn't displayed on the form.
    

The Tax Reporting subtab on transaction forms on the Belgium Intrastat Report contains the following fields:

-   **Region of Origin** - Region of an EU member state of dispatch where the goods were produced or manufactured, assembled, processed, repaired or maintained, or where the commercial process took place.
    
-   **Nature of Transaction Code** - Type of transaction in the Intrastat declaration. For more information, see [Nature of Transaction Code](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2070738.html).
    
-   **Delivery Terms** - International commercial terms (Incoterms) defined by the International Chamber of Commerce (ICC). For more information, see [Delivery Terms](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2071234.html).
    
-   **Mode of Transport** - Active vehicle that moves goods for every arrival or dispatch transaction. For more information, see [Mode of Transport](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1505110665.html).
    
-   **Country of Origin** - Country where the goods were harvested, manufactured, or substantially changed. For more information, see [Country of Origin](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164377962805.html).
    
-   **Partner ID** - This refers to the Counterparty VAT number. This is the VAT number of the party receiving the goods in the EU member state of destination. For more information, see [Counterparty VAT Number](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1553147823.html).
    

For more information about other EU Intrastat Report Fields on Transaction Forms, see [Intrastat Reporting Fields on Transaction Forms](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4150707116.html#bridgehead_4150716738).

## Belgium Intrastat Report Fields on Item Records {#bridgehead_1553075599}

If the International Tax Reports SuiteApp is installed in your account, the following fields are displayed on some item record types:

-   **Commodity Code** - The 8-10 digit number to identify the type of goods or commodities for every arrival or dispatch transaction. For more information, see [Commodity Code](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2070438.html).
    
-   **Supplementary Unit** - Unit used in measuring quantity of goods or commodity on the item record. For more information, see [Supplementary Unit](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4605983594.html).
    

For more information about other EU Intrastat Report Fields on Item Records, see [Intrastat Reporting Fields on Item Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4150707116.html#bridgehead_4150717128).
