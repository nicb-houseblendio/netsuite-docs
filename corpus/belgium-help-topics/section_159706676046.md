Note:

This topic is for NetSuite accounts that use the Country Tax Report page to generate the SuiteTax-based EU Sales List. If you're using the EU Sales List Report page, see [EU Sales List (ESL) Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2068052.html).

The Belgium EU Sales List 723 is a report of your company's supplied goods and services to another EU member state. The report template is provided by the Belgium Localization SuiteApp and is generated using the Tax Reporting Framework SuiteApp. To generate this report, see [Generating Localized Country Tax Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1528250223.html). You can also export this report to PDF, XLS, and XML. For more information, see [Exporting a Country Tax Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_156645000208.html).

The EU Sales List 723 template contains the following information:

-   **Company Name** - The legal name or, if the legal name isn't filled, the name of the subsidiary whose transactions you're reporting in the EU Sales List.
    
-   **VAT Registration Number** - The Tax Registration Number associated with the Belgium Nexus indicated on the Company Information page for non-OneWorld accounts, or Subsidiary page for OneWorld accounts.
    
-   **Reporting Period**
    

| Report Label | Description |
| --- | --- |
| Country | The customer's country as indicated by the two-letter prefix from the Customer Tax Registration Number on the invoice or cash sale. |
| Customer | Name of customer. |
| Customer's VAT Registration Number | The Customer Tax Registration Number without the two-letter country code or prefix. |
| Value of Supplies | Total value of all the supplies of goods or services made in the indicated period. There's a separate value for each customer and type of supply. |
| Indicator | The type of supply:
-   **L**\- B2B Goods
-   **S**\- Services
-   **T**\- Triangular trade

 |
