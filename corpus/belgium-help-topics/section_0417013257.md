For information about the maximum number of characters for certain fields, see [Character Limitations in Fiche 281.50 Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0417020637.html).

The Fiche 281.50 form requires you to include in the report certain information about the following entities:

-   Subsidiary (also referred to as debtor in Fiche reporting)
    
-   Employee or individual who generated the report
    
-   Vendors, to whom you've awarded commissions, allowances, and other benefits that are covered in Fiche 281.50 requirements
    

Ensure that you have the following fields filled in on each entity record:

| Entity | Field Name | Location |
| --- | --- | --- |
| Subsidiary | Name | Go to Setup > Company > Classifications > Subsidiaries, then edit your Belgium subsidiary record. |
| Official Language Note: You can select Dutch, French, or German. |
| BCE/KBO/ZDU Number | On your Belgium subsidiary record, go to the Addresses subtab. Click **Edit** next to the Address field. |
| Address 1 Note: The Fiche 281.50 form requires the street details. In NetSuite, you can enter the street name and number in the Address 1 or Address 2 fields. |
| Employee | Name | Go to Lists > Employees > Employees to edit the record of the individual who generated the Fiche report. |
| Email |
| Office Phone |
| Vendor | Address 1 Note: The Fiche 281.50 form requires the street details. In NetSuite, you can enter the street name and number in the Address 1 or Address 2 fields. | Go to Lists > Relationships > Vendors, then edit a specific vendor record.On the vendor record, go to the Address subtab. |

The following fields on the vendor record aren't required, but the SuiteApp checks if they're filled:

-   **Zip** - Zip code of the subsidiary's and vendor's addresses.
    
-   **City**\- City of the subsidiary's and vendor's addresses.
    
-   **City of Birth**\- This field only applies to vendors categorized as natural persons. To fill in this field, go to the Fiche 281.50 subtab on the vendor record.
    

You can still generate and download the Fiche report without this information, but the report may not pass the Belgium tax audit file validation.
