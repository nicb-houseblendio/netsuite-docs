The International Tax Reports SuiteApp provides a localized Intrastat Dispatches and Arrivals Form for the Belgium Intrastat Report.

The information displayed on the Dispatches and Arrivals Forms are based on your transaction and item records in NetSuite.

| Field | Appears in Dispatches (Sales) Form? | Appears in Arrivals (Purchases) Form? |
| --- | --- | --- |
| Line Number | Yes | Yes |
| Member State | Yes | Yes |
| Nature of Transaction Code | Yes | Yes |
| Region of Dispatch | Yes | No |
| Region of Arrival | No | Yes |
| Commodity Code | Yes | Yes |
| Net Mass (KG) | Yes | Yes |
| Supplementary Unit Note: The Supplementary Unit for Belgium is derived from the quantity of the items in the transaction. | Yes | Yes |
| Value in Euro | Yes | Yes |
| Supplier VAT No. | No | Yes |
| Mode of Transport | Yes | Yes |
| Incoterms (Delivery Terms) | Yes | Yes |
| Country of Origin (only in Sale) | Yes | No |
| Counterparty VAT number Note: If you don't provide the Partner ID on the item sublist and Tax Reporting subtab, the value is derived from the Tax Registration Number field. Otherwise, the default value **QV999999999999** displays on the Intrastat Report. | Yes | No |

For more details about the Intrastat Report field descriptions, see [Intrastat Reporting Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4150707116.html).
