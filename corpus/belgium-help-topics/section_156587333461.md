To set up your NetSuite account so that it's tailored to Belgian business requirements, you must adjust the Company, and Subsidiary settings.

Note:

Make sure that your NetSuite role has the appropriate permissions to set up company preferences.

#### To adjust NetSuite Company settings:

1.  Go to _Setup > Company > Setup Tasks > States/Provinces/Counties_.
    
2.  Add a record for each of the [the Provinces of Belgium](https://www.belgium.be/en/about_belgium/government/provinces).
    
3.  Go to _Setup > Company > Preferences > General Preferences_.
    
    1.  In the **Date Format** field, specify the date format (DD/MM/YYYY) and long date format (DD Month YYYY).
        
    2.  In the **Number Format** field, specify the number format in Belgium.
        
    3.  On the **Accounting Contexts** subtab, create an accounting context (for example, call it Belgium) if your main Chart of Accounts isn't the statutory Belgium Chart of Accounts. For more information, see [Accounting Contexts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4640155582.html).
        
    4.  On the **Languages** subtab, make sure that Francais (France), and Dutch are selected.
        
        You can also select other languages that you would like to use on your website or on printed transactions. For information about localizing preferences in NetSuite, see [General Personal Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N475661.html).
        
4.  Go to _Setup > Company > Setup Tasks > Company Information_.
    
    1.  Set the currency to Euro.
        
        For more information, see [Setting a Base Currency](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1397082.html).
        
    2.  Specify VAT registration number for the parent subsidiary.
        
    3.  Select the appropriate time zone: (GMT+01:00) Brussels, Copenhagen, Madrid, Paris.
        
5.  Click **Save**.
    

#### To adjust NetSuite Subsidiary settings:

1.  Go to _Setup > Company > Classifications > Subsidiaries_.
    
2.  Create a subsidiary record for each of your legal entities. For more information, see [Creating Subsidiary Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N272471.html).
    
3.  On the Subsidiary page, set the following preferences:
    
    -   If your NetSuite account doesn't have the SuiteTax feature enabled, on the **Tax Registrations** subtab, enter the VAT registration number.
        
    -   Check the GL Impact Locking box.
        
        This option is visible in NetSuite OneWorld accounts only (when the GL Audit Numbering feature is enabled). When you use GL Impact Locking for a company or a subsidiary, any change to a general ledger impacted field or entity field on a GL numbered impacting transaction (after running a GL audit numbering sequence) automatically generates copy and reversal transactions. These transactions are displayed on the GL Impact subtab of the original general ledger impacted transaction. For more information, see [GL Impact Locking](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4725785967.html).
        
    -   Enable the Period End Journal Entries feature. You can define additional settings for the Period End Journal Entries feature through the Subsidiary Settings Manager page. For more information, see [Defining Subsidiary Settings for the Period End Journal Entries Feature](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1552310613.html).
        
        The Period End Journal Entries feature processes and posts subsidiary consolidation and income statement closing using a transaction type called Period End Journal. Period End Journals are generated automatically when you complete the Create Period End Journals task on the Period Close Checklist. For more information, see [Period End Journal Entries](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1531269686.html).
        
4.  (Optional) If you have subsidiaries in different countries, which require different format settings such as date, number, time zone, and CSV column delimiter, set those preferences on the **Preferences** subtab.
    
    Note:
    
    If you have subsidiaries in different countries with different format settings, you can select language preferences for each subsidiary. Go to _Setup > Company > Preferences > General Preferences_ and select the language in the **Languages** subtab. For more information, see [Configuring Multiple Languages](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N247147.html).
    
5.  Click **Save**.
    

## Adjusting NetSuite User Preferences {#bridgehead_156587335037}

As a best practice, define preferences at the company or subsidiary level. User preferences usually take precedence over the other preferences set for a role, subsidiary, or company. If a user is linked to a subsidiary, that user will inherit the settings set on the subsidiary record. For more information, see [General Personal Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N475661.html).

#### To set user preferences for Belgium Account:

1.  Go to _Home > Set Preferences_.
    
2.  Go to the **General** subtab.
    
    1.  On the **Localization** subtab, set your preferred settings.
        
    2.  On the **Formatting** subtab, set your preferred settings.
        
3.  Click **Save.**
