The Belgium Localization SuiteApp is available in the SuiteApps Marketplace.

#### To install the Belgium Localization SuiteApp {#procedure_157503457609}

1.  Go to SuiteApps.
    
2.  In the Search field, enter **Belgium Localization**.
    
3.  Click the Belgium Localization image.
    
4.  Click **Install**.
    

Note:

The Belgium Localization SuiteApp is automatically updated whenever enhancements or new features are added. Previous versions of this SuiteApp (1.05.0 and earlier) are no longer supported and aren't automatically upgraded.

To install the latest version from the SuiteApps Marketplace, uninstall version 1.05.0 or earlier (Bundle ID: 307195) from SuiteBundler. For more information, see [Uninstalling a Bundle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3400972.html). You won't lose your custom SuiteTax-based reports setup and Belgium Chart of Accounts when you uninstall the Belgium Localization SuiteApp from SuiteBundler.
