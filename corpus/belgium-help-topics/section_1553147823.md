The Counterparty VAT Number refers to the VAT number of the client or the party receiving the goods in the EU member state of destination.

The Counterparty VAT Number column in the Belgium Intrastat Dispatch report gets the value from the **Partner ID** field found on transaction forms of EU member states. For more information, see [Partner ID](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164377982356.html). and [Belgium Intrastat Report Fields on Transaction Forms](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1552986948.html#bridgehead_1553741645).
