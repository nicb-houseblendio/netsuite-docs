The Belgium Localization SuiteApp provides Belgium tax reports for NetSuite accounts with the SuiteTax feature enabled. Before generating the reports, you must first set up your account for tax reporting. For more information, see [SuiteTax-Based Reports Setup for Belgium Localization](#subsect_157503394883).

Using the Country Tax Reports page provided by the Tax Reporting Framework SuiteApp, you can generate the following Belgium-specific SuiteTax-based reports:

-   [Periodic VAT Return 625](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156775521116.html)
    
-   [Annual Client Listing 725](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156775647909.html)
    
-   [Belgium Intrastat](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157538424588.html)
    
-   [EU Sales List 723](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_159706676046.html)
    

To generate tax reports, see [Generating Localized Country Tax Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1528250223.html).

For other tasks that you can do with Belgium tax reports on the Country Tax Reports page, see the following topics:

-   [Viewing a Generated Country Tax Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_1528251207.html)
    
-   [Making Adjustments on a Country Tax Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_156647155234.html)
    
-   [Exporting a Country Tax Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_156645000208.html)
    

## SuiteTax-Based Reports Setup for Belgium Localization {#subsect_157503394883}

To use the tax-related features of Belgium Localization, you should also do the following:

-   Set up an accounting period. For more information, see [Setting Up Accounting Periods for a Year](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N1446183.html).
    
-   Enable the SuiteTax Plug-In. For more information, see [Enabling the SuiteTax Plug-In](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1557399475.html).
    
-   Assign tax registration to a Belgium subsidiary. For more information, see [Assigning Tax Registrations to a Subsidiary in SuiteTax](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4296038273.html).
    
-   Set up Belgium tax reporting preferences. For more information, see [Setting Up Country Tax Reporting Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/bridgehead_1557127083.html).
    
-   Set the Belgium Periodic VAT 625 preferences. For more information, see [Setting the Preferences for Belgium SuiteTax VAT Report](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0808125912.html).
