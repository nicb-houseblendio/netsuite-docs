When you start the Financial Report Builder, the current layout is displayed in the Edit Layout page. The layout may be a standard layout, a shared custom layout, or a custom layout that is used only in a single custom financial statement.

When you customize a standard financial statement, the edits you make on the Financial Report Builder's Edit Layout page are stored in a custom layout. A custom layout begins as a duplicate version of one of the standard layouts and is modified as you make edits to its financial sections and rows.

When you open a report to customize it, you can select a different layout, but you can't edit the initial current layout. See [Accessing the Financial Report Builder](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2105846.html).

To enable layout editing, click **Edit Layout**. When the button is dimmed, editing is enabled.

You can't edit standard layouts. If you've selected a standard layout, you receive a prompt to change the name of the layout when you click Edit Layout. If you attempt to edit a shared custom layout, the prompt gives you the option of editing the shared layout or creating a duplicate for editing with a different name.

Note:

In NetSuite OneWorld, the layout displayed in the Financial Report Builder is the one assigned to the subsidiary context you last selected. The subsidiary context is displayed to the left of the **Layout** field. To customize a layout for a different subsidiary context, rerun the financial statement with the desired subsidiary context, and click **Refresh**. Then click **Customize** to restart the Financial Report Builder. See [OneWorld Financial Statements](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N2119691.html).

You need both the Financial Statements and the Report Customization permissions to customize reports in the Financial Report Builder. If you don't have the necessary permissions, contact your account administrator. For more information, see [Giving Access to Financial Statements](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N327139.html).
