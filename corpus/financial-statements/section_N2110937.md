In the Financial Report Builder, you can use the Layout list on the Edit Layout page to select a different layout. For example, you can select a previously created custom layout for the new custom financial statement. Each custom layout includes all customizations made on the Edit Layout page, so selecting a different layout can result in significant changes.

The Layout list is shown in the following screenshot.

![Screenshot of the Layout list on the Edit Layout page of the Financial Report Builder](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/Accounting/FinancialStatements/FRBLayoutList.png)

You may not be able to edit the layout you select immediately. If you can't make changes on the Edit Layout page after you select a layout, click the Edit Layout button. See [Making a Layout Editable in the Financial Report Builder](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2111099.html).

You can't rename a layout on the Edit Layout page. To rename a layout, go to Reports > Financial > Financial Row Layouts and enable editing. See [Renaming a Custom Financial Statement Layout](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2112121.html).

The layout in the Financial Report Builder for NetSuite OneWorld is based on the subsidiary context you last selected for the financial statement. The Subsidiary Context is displayed to the left of the Layout list. If you want to customize a layout for a different subsidiary context, first run the financial statement using the desired subsidiary context. See [Subsidiary-Specific Financial Layouts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2123802.html).

You need both the Financial Statements permission and the Report Customization permission to customize reports in the Financial Report Builder. If you don't have the necessary permissions, contact your account administrator. For more information, see [Giving Access to Financial Statements](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N327139.html).
