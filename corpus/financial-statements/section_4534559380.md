Whenever a report with a financial layout is edited, the details about the layout changes are logged in the audit trail. You can use the Analytics Audit Trail search to review these changes. For more information, see [Audit Trail Search](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N688379.html).
