A financial statement layout is a set of definitions for financial sections and rows. Each layout can be shared among multiple financial statements. When you create a custom financial statement, most of your customizations are to the statement's assigned layout.

You can make changes to a layout on the [Financial Report Builder Edit Layout Page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2106362.html). To display a layout for editing, see:

-   [Accessing the Financial Report Builder](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2105846.html)
    
-   [Making a Layout Editable in the Financial Report Builder](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2111099.html)
    

To complete specific layout editing tasks, see:

-   [Financial Statement Sections](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2112804.html)
    
-   [Financial Statement Rows](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2115374.html)
    

To review the financial statement layouts available in your account, see:

-   [Financial Row Layouts Page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2111900.html)
    

To rename layouts, see:

-   [Renaming a Custom Financial Statement Layout](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2112121.html)
    

To review and change the assignments of layouts to financial statements, see:

-   [Financial Reports: Row Layout Assignment Page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2112344.html)
    
-   [Assigning a Layout to a Financial Statement](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2112565.html)
    

Note:

If you're using NetSuite OneWorld, the layout displayed in the Financial Report Builder is the one assigned to the subsidiary context you last selected. The selected subsidiary context is displayed at the top of the page. To customize a layout for a different subsidiary context, rerun the financial statement, select the desired subsidiary context from the footer list, and click **Refresh**. Then click **Customize** to restart the Financial Report Builder. See [OneWorld Financial Statements](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N2119691.html).

You need both the Financial Statements permission and the Report Customization permission to customize reports in the Financial Report Builder. If you don't have the necessary permissions, contact your account administrator. See [Giving Access to Financial Statements](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N327139.html) for more information.
