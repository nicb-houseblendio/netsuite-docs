The Financial Reports: Row Layout Assignment page lists financial statements and layouts, indicating the layout assigned to each financial statement. To display this page, go to Reports > Financial > Financial Row Layouts, or click the View Assignments link on the [Financial Row Layouts Page](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N2111900.html).

You can change a layout assigned to a custom or standard financial statement by clicking the Edit button. Then click a layout in the Row Layout column and select a different layout.

You can filter this page to display only a selected financial statement type, a selected layout, or if you're using NetSuite OneWorld, a selected subsidiary.

-   To display assignments for a specific type of financial statement, select that statement from the **Report Type** list. To display assignments for all types of statements, select **All**.
    
-   To display assignments for a specific layout, select that layout from the **Row Layout** list. To display assignments for all layouts, select **All**.
    
-   To display assignments for layouts relevant to a specific subsidiary, select that subsidiary from the **Subsidiary Context** list. To display assignments for layouts relevant to all subsidiaries, select **All**.
    

You need both the Financial Statements permission and the Report Customization permission to modify financial statement layouts. If you don't have the necessary permissions, contact your account administrator. See [Giving Access to Financial Statements](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N327139.html) for more information.
