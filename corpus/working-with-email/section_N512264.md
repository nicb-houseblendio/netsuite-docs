Email sent from NetSuite uses one of the following as the **From** address:

-   the email address set in the From Email Address field at _Home > Set Preferences_ > General under User Profile, or
    
-   if there's no from email address entered on the Set Preferences page, the employee's login email address
    

When the recipient replies to your email, the reply goes to the address you used to send the original message.

For more information about where to find the sent email list, see [Using the Sent Email List](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156569944168.html).

To generate the list of all email, you can use the Message record to define a saved search. For more information, see [Saved Searches](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N675442.html).

You can also send personalized email messages in bulk using the Email Merge feature. For more information, see [Working with Mail Merge](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N523426.html).

## Working with Files Attached to Email Messages {#bridgehead_N512478}

Files attached from your computer to email you send from within NetSuite are stored by default in the Attachments Sent and the Attachments Received folders in the File Cabinet. These folders are also used when you save messages you receive outside of NetSuite to a record.

The attachment folders are system-generated folders in the File Cabinet only used to hold these files, so files in these attachment folders aren't available to select as attachments when sending email. If you want to attach a file from one of these folders to an email message, you must move the file to another folder prior to sending the email message.

For more information, see [Moving and Copying Files in the File Cabinet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N543817.html). See also, [Sending Email from Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N512629.html).
