The Partner Activity Detail report lists each partner's activity with each customer. If you are a partner with access to the Advanced Partner Center, you only see activity related to the customers you do business with.

Activities are defined as tasks, events, notes, campaigns or messages involving the customer and partner. The Partner Activity Detail Report provides the type of activity in the Type column, and the title or details of the activity in the Note column. This report also lists the date of each action.

## To view the Partner Activity Detail report: {#bridgehead_N1176635}

Go to _Reports > Marketing > Partner Activity > Detail_.

You'll see a message that your report is loading. The status bar at the bottom shows the progress as your report loads. You can click Cancel Report next to the status bar if you want to stop the report from loading.

Note:

This report does not support reporting by period even when the Report by Period preference is set to All Reports. You can set the Report by Period preference at _Home > Set Preferences_ > the Analytics subtab.
