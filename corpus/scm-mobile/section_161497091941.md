You can access mobile apps through your account-specific login page URL. Your URL automatically redirects to the standard NetSuite login page.

Before you try to access a mobile app, make sure that you have completed the setup procedures for the features or SuiteApps you want to use. Missing features and roles may cause issues regarding logging into the app or accessing mobile pages. See [SCM Mobile SuiteApp Installation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161495429711.html#subsect_161495552374) and [Setting Up the Online Form User Role](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0814113835.html).

If you want to log in through the single sign-on option, see [Logging into NetSuite for Mobile with Single Sign-on](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158642089675.html). For setup information, see [SAML Single Sign-on](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N3825119.html).

## Accessing the SCM Mobile Login Page URL {#subsect_161497100649}

On mobile devices, you can access SCM Mobile apps using the login page URL provided for your account. If you do not receive this URL from your NetSuite account manager, you can access it from your account.

#### To access the SCM Mobile login page URL:

1.  Using the Adminstrator role, go to Customization > Scripting > Scripts.
    
    Tip:
    
    Alternatively, you can go to Setup > Custom > Mobile - Login URL. On the Mobile - Login URL page, copy your login page URL. You can skip the rest of the steps. To access the URL from your mobile device browser, see [Accessing SCM Mobile Apps on Your Device](#subsect_161497112331).
    
2.  On the Scripts list, next to the Mobile - Get Login Page script, click **Deployments**.
    
3.  On the Script Deployments list, next to the customdeploy\_mobile\_sl\_get\_login\_page deployment ID, click **View**.
    
4.  On the Script Deployment page, in the **External URL** field, copy the URL for the SCM Mobile app login page.
    

## Accessing SCM Mobile Apps on Your Device {#subsect_161497112331}

After you set up your language preferences and other mobile app capabilities, you can use the SCM Mobile login page URL to access the mobile apps. If you do not receive this account-specific URL from your NetSuite account manager, you can access it from your NetSuite account. If you see a blank screen when you try to log in on your mobile device, verify that you have the correct login page URL. See [Accessing the SCM Mobile Login Page URL](#subsect_161497100649) or [Language Preference Setup for SCM Mobile](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161495570632.html).

#### To access SCM Mobile apps on your device:

1.  On your mobile device, open an internet browser.
    
2.  Go to your SCM Mobile app login page URL.
    
    The SCM Mobile login page appears.
    
3.  Log in by entering your NetSuite account username and password.
    
4.  On the Select Application page, do the following:
    
    1.  If you want to change the role, tap the Menu icon, and then tap **Switch Role**. From the Roles table, tap the role you want to select
        
        If you switch to a role that has access to a page in the NetSuite UI but not in the mobile app, you can choose another role
        
    2.  To choose an app, on the Select Application page, tap the app you want to select.
        
5.  On the Select Warehouse page, tap the location you want to select.
    
6.  If you have enabled Weighing Scale Support with PrintNode integration, you can do the following to select a scale:
    
    1.  Tap the main menu icon, and then tap **Select Weighing Scale**.
        
    2.  On the Select Weighing Scale page, tap the scale you want to use.
        
    
    You can change your selection at any time.
    
7.  (Optional) On your browser, you can set the Main Menu page as your home page and create a shortcut to the page on your device's home screen.
    
8.  (Optional) You can configure your mobile device to automatically perform an Enter action after an item scan.
    
    This configuration removes the extra step of tapping the **Enter** button to move to the next page after you scan an item.
    

You can switch to a different mobile app or location at any time.
