The required Online Forms feature provides the Online Form User role required to access the mobile app using the login URL. If you use Mobile Printing with PrintNode integration, it also enables you to access NetSuite records used for printing. To enable features required to log in to an SCM Mobile app, see [SCM Mobile SuiteApp Installation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161495429711.html#subsect_161495552374).

Without this role, you may encounter issues when logging in or accessing any of the standard mobile apps. With PrintNode integration, you may not be able to print or update your printing settings. For more information, see [Troubleshooting Mobile Printing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162499375334.html) or [Mobile Printing Setup Procedures](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161495837530.html#subsect_161495863496).

#### To set up the Online Form User role:

1.  Using the Administrator role, go to Customization > Scripting > Script Deployments.
    
2.  On the Script Deployments list, click **Edit** next to each of the following deployments:
    
    -   ID - **customdeploy\_mobile\_sl\_get\_login\_page**
        
    -   ID - **customdeploy\_print\_sl\_fileserver**
        
3.  On the Script Deployment page, make sure that the **Available Without Login** box is checked.
    
4.  On the **Audience** subtab, in the **External Roles** field, select **Online Form User**.
    
5.  Click **Save**.
