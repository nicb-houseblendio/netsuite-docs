You can configure default mobile app settings that include the table row size, logging, debug state, among others. These settings apply to all standard mobile apps supported by SCM Mobile.

Depending on the mobile app you use, you can enable printing and weighing scale support for your mobile device. If you have set up PrintNode integration, the app provides additional settings and options for your printers. Be sure to set up PrintNode integration first, before you enable Mobile Printing. For more information, see [Enabling Mobile Printing with PrintNode Integration](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161495837530.html#subsect_0303092855).

Without PrintNode integration, the app provides capabilities that enable you to save generated labels and documents. For more information, see [Enabling Mobile Printing without PrintNode Integration](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161495837530.html#subsect_29152053486).

For either Mobile Printing setting, you can specify the apps for which you want to enable printing or saving.

#### To configure SCM Mobile app settings:

1.  Using the Administrator role, go to Setup > Custom > Mobile - Settings.
    
    The Mobile - Settings page appears.
    
2.  Check the box next to the SCM Mobile capability you want to use:
    
    -   **Enable Mobile Printing** - available in Warehouse Management and Ship Central
        
        Aside from printing through an SCM Mobile app, this setting also enables printing through the NetSuite UI, which is configured separately. For more information, see [Adding a Print Button to NetSuite Pages](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162930057806.html).
        
        Without PrintNode integration, you can enable this setting to use the **Print to File** record and save soft copies of labels or documents.
        
    -   **Enable Weighing Scale Support** - available in Ship Central and Warehouse Management for accounts with PrintNode integration
        
3.  If you enable Mobile Printing, in the **Printable File Retention (In Hours)** field, enter the maximum number of hours that you want printable files to remain in your file cabinet before they get deleted.
    
    You cannot enter a negative value in this field.
    
    You cannot reprint deleted files. For more information about reprinting, see [Reprinting Labels](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158681935610.html).
    
4.  (Optional) If you enable Mobile Printing with PrintNode integration, enter values in the following fields:
    
    -   **PrintNode URL for View Printers API** - In case PrintNode changes their default URL, enter the new PrintNode URL for the view printers API.
        
        This API enables you to retrieve the list of printers.
        
    -   **PrintNode URL for Create Print Job API** - In case PrintNode changes their default URL, enter the new PrintNode URL for the create print job API.
        
        This API enables you to submit print requests.
        
    -   **Print Server Connection Timeout** - Enter the maximum number of seconds that you want to enable NetSuite to establish a printer server connection before it times out.
        
        You cannot enter a negative value in this field.
        
    -   **Enable for These Apps Only** - Select the SCM Mobile apps to which you want to provide Mobile Printing access, or you can select **None**.
        
        This setting neither provides nor removes access to printing through the NetSuite UI.
        
5.  If you enable Mobile Printing without PrintNode integration, you can set the **Enable Print to File for These Apps Only** field. In this field, you can select the mobile apps for which you want to provide Print to File access.
    
6.  (Optional) For your default account settings, enter or select values in any of the following fields:
    
    -   Check the **Debug State** box if you want to set the mobile application to debug state and display state fields on mobile pages.
        
    -   Check the **Always Allow App Selection** box to always display the application selection page on a mobile device, regardless if you have not configured multiple mobile applications.
        
    -   To include empty and null values in the generated configuration file for the app, check the **Include Null Values in Configuration Files** box.
        
        If you clear this box to not include null field values, you decrease the configuration file size. For more information about configuration files, see [Mobile Customization Guidelines and Limitations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_163614460343.html#subsect_92112734571).
        
    -   In the **Account Mode for Logging** field, select one of the following account modes in which you want to run the mobile app: **Production**, **Development**, or **Debug**.
        
    -   In the **Batch Size of Logs for Storage (GB)** field, enter the batch size, in GB, that must be reached before NetSuite automatically transfers the logs for storage.
        
    -   In the **Table Row Size** field, enter the default number of rows you want to display in a table at each mobile page load.
        
7.  Click **Save**.
    
8.  If you enable mobile printing or weighing scale support, be sure to begin a new session or reload the browser on your mobile device to reflect the updates.
    

For each additional capability that you enable, you must complete the required setup procedures in the following topics:

-   [SCM Mobile Printing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161495837530.html)
    
-   [Weighing Scale Support](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161523537011.html)
