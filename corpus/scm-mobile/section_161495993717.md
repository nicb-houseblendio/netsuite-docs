Through the PrintNode client installed on your local computers, NetSuite connects to your network printers and weighing scales. To establish the connection, you must configure your PrintNode API key and safelist the IP address of your computers.

By default, you can add static IP addresses of printers to your safelist. If you enable the setting for dynamic IP addresses, you can also add each or a range of these addresses. To enable support for dynamic addresses, see [Configuring SCM Mobile App Settings](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161496866735.html).

You can add up to 99 addresses only at a time. So, when setting address ranges, note the following:

-   Only the last section for the device ID can vary.
    
    Example: **1.2.3.200 to 1.2.3.210** to **1.2.3.200 - 1.2.3.210**
    
-   You can include special characters, such as ? and \*, to replace the last two digits of a range, as shown in the following examples:
    
    Examples: **1.2.3.20\*** (1.2.3.200 to 1.2.3.209) or **1.2.3.2?** (1.2.3.20 to 1.2.3.29)
    

#### To configure security settings:

1.  Access the Print Security Settings page through one of the following paths that applies to your role:
    
    -   Using the Mobile Administrator role, go to Setup > Label Printing > Print API Key.
        
    -   Using the Packing Administrator role, go to Setup > Printing Setup > Print API Key.
        
2.  (Optional) If you enable mobile printing, enter values in the following fields:
    
    -   **Support for Dynamic IP Address** - Check this box if you want to set up dynamic IP addresses of printers.
        
3.  On the Print Security Settings page, add the IP Address of each computer installed with the PrintNode client.
    
    Tip:
    
    You can view the list of available IP addresses in the Logs tab of the PrintNode client installed on your local machine. See [Mobile Printing Requirements for PrintNode Integration](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161495837530.html#subsect_161495851722).
    
    1.  Click **Add IP Address**.
        
    2.  On the Printer IP Address page, in the **IP Address** field, enter the computer's IP address or a range that you want to safelist.
        
    3.  Click **Add**.
        
        NetSuite redirects you to the Print Security Settings page on which you can review the safelist of static or dynamic IP addresses. If you want to remove an IP Address from the list, click **Delete IP Address**.
        
    
    For each IP Address you want to add, repeat steps a to c.
    
4.  In the **Print API Key** field, enter the API Key for your PrintNode account.
    
    The same key applies to both the Mobile Printing and Weighing Scale capabilities of SCM Mobile.
    
    Tip:
    
    In the message below the buttons, click the link to go to the PrintNode site and access your account to get the API Key.
    
5.  Click **Submit API Key**.
