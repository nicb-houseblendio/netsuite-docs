Instead of running the script for one transaction at a time, you can create a deployment to attach files to multiple transactions. You can create separate deployments for transactions associated with the same mobile process. You can also group together transactions based on the frequency of uploads, volume, or file sizes. You can set the deployment schedule to attach files during certain periods. For more information about image capture or file upload through the app, see [Setting Up Image Capture or File Upload](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0205024910.html).

On deployment records, choose the ID of target transactions that you set up in one or more Capture Image or Upload File icons. You can choose custom records that you set up within a mobile process as the target. To view the supported target transactions, see [Supported Standard Target Transactions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0205024910.html#subsect_0122031102).

Instead of defining your own deployment, if you want to update target transactions one at a time, see [Capturing and Attaching Files Through the App](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0205030545.html).

#### To create deployments for target transactions:

1.  Using the Administrator role, go to Setup > Custom > Attach Mobile App File.
    
2.  On the Attach Mobile App File page, click **Attach in New Deployment**.
    
3.  On the Script Deployment page, do the following:
    
    1.  Set the basic deployment fields to suit your business requirements.
        
    2.  Make sure that the **Script** field shows the name of the standard script, **Mobile - Update Pending Transactions**.
        
    3.  On the **Schedule** subtab, specify the frequency and dates in the appropriate fields.
        
    
    For detailed instructions, see [Deploying a Script by using the Script Deployment Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0706024425.html).
    
4.  On the **Parameters** subtab, in the **Transaction Type** field, enter the IDs of the target transactions, separated by a comma.
    
5.  Click **Save**.
    

If you want to create another deployment, click **Actions**, and then select **Make Copy**.

The Attach Mobile App File page provides the **View Deployments** option, which gives you access to the list of existing deployments.
