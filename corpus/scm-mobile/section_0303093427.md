Without PrintNode integration, you can save soft copies of ZPL or PDF files generated through the mobile app. You can use the standard templates or create your own to specify the details and layout of your labels or documents.

During printing, you can choose the Print to File option as your printer to save soft copies of the files. The app saves the label or document files in the local storage folder of your handheld device or computer.

You can set up print to file by completing the following procedures:

1.  Enable Mobile Printing - Enable the Mobile Printing setting and choose the apps to which you want to provide access to it. See [Configuring SCM Mobile App Settings](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161496866735.html).
    
    SCM Mobile automatically creates the Print to File record with the **All Types** printer setting to support both ZPL and PDF formats. To view this record, using the Mobile Administrator role, go to Setup > Label Printing > Printers. In the **Not PrintNode Integrated** column, the Print to File record has a **Yes** setting. You cannot directly set up records for your printer devices, which you can do through PrintNode integration.
    
2.  (Optional) Create custom print templates - If you want to create your own label and document templates, you can customize the standard print files and templates. For instructions, see [Creating Custom Print Templates and Files](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0206031419.html).
    
3.  (Optional) Assign default templates and Print to File as the default printer on print reports - Assign Print to File as the default printer when you print labels and documents through the app. You can also choose default standard or custom print templates on print reports. For instructions, see [Setting Up Printing Settings on Print Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161496026645.html).
    
4.  (Optional) Add printing rules to print reports - On each print report, you can add printing rules to specify conditions for using a Print to File record or template. For instructions, see [Configuring Rules for Printers, Templates, or Number of Copies](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161496136236.html).
    
5.  (Optional) Create printer groups - You can assign the Print to File printer to specific printer groups that you create. For instructions, see [Creating Printer Groups](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0826023922.html).
