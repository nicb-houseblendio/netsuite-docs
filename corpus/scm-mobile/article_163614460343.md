Mobile customization enables you to create your copy of a standard process and modify it according to your business requirements. Aside from page elements, which you can modify through mobile configuration, it lets you modify more components, including processes, actions, information screen elements, and source data. On your copy of a mobile process, you can also add or remove pages and page elements, like buttons and fields.

As you plan your customization, you can address the following questions to identify the components and how you want to customize them:

Note:

Mobile customization does not support creation of custom mobile apps. For more information, see [Mobile Customization Guidelines and Limitations](#subsect_92112734571).

-   Which mobile process, page, or page element do you want to customize?
    
    Identify the existing mobile process you want to update or modify.
    
    -   If you want to modify a page or element, identify the process that contains it.
        
    -   Choose the process within which you want to add a page or element that enables you to complete a task and meet your business requirements.
        
    
    On the mobile app, you can view the processes and pages that you can customize. To view the common pages and components, see [SCM Mobile App Basics](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161556703949.html).
    
-   What customizations do you want to perform?
    
    Within your custom mobile process, you can perform the following customizations:
    
    -   **Mobile processes** - Define process settings, such as the name and first page of your custom process. Choose the roles that can access the process. See [Customizing Mobile Processes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163614423814.html).
        
    -   **Mobile pages** - Define page settings, such as the title and load events. Add or modify process or independent types of pages. See the following topics:
        
        -   [Customizing Mobile Pages](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163614512507.html)
            
        -   [Customizing Information Screen Elements](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0916012938.html)
            
        -   [Customizing Mobile Popup Windows](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0908113722.html)
            
    -   **Mobile page elements** - Add fields, buttons, tables, and other elements. Set up mobile actions for tasks associated with page elements, such as loading of data or data submission. See the following topics:
        
        -   [Customizing Mobile Page Elements](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163614572439.html)
            
        -   [Customizing Mobile Table Elements](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164874151392.html)
            
        -   [Customizing Mobile Actions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0808031458.html)
            
        -   [Dynamically Displaying Action Buttons](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0402115110.html)
            
        -   [Time Settings for Date Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0722032742.html)
            
        -   [Displaying Messages in Dynamic Text Elements](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0318015507.html)
            
        
        Most mobile pages contain an info screen from which you can view data retrieved from previous pages within the same process. To customize this screen, see [Customizing Information Screen Elements](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0916012938.html).
        
        If you enable Mobile Printing, you can customize templates, printing settings, and the print action. See the following topics:
        
        -   [Creating Custom Print Templates and Files](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0206031419.html)
            
        -   [Setting Up Printing Settings on Print Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161496026645.html)
            
        -   [Mobile Printing Customization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162506469317.html)
            
    
    ## Example
    
    On your custom item receipt form, you add a custom field for country of origin. You want this field to be populated during purchase order receiving. On your mobile device, when you enter the quantity to receive, you also want to capture the country of origin.
    
    For this scenario, customization involves adding a field to a page of your custom mobile process. It also includes customizing field and button elements to capture and save the data. To view the instructions for this sample scenario, see [Setting Up Additional Fields Through Mobile Customization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156633029520.html).
    

## Mobile Customization Guidelines and Limitations {#subsect_92112734571}

SCM Mobile creates a configuration file that includes details about configurations or customizations for each mobile app that you update. The file is generated and stored in your file cabinet when you update the app.

Important:

Within your file cabinet, don't change or edit the name of standard folders used by standard app components. You may encounter issues when updating standard records, system rules, and other app components.

Configuration files have a file size limit of 10MB, following the limitation for files that can be created in the file cabinet. If this limit is exceeded, you may encounter errors or the app update fails. Custom mobile processes not included in the file cannot be accessed on the app. For more information about updating apps, see [Compiling Mobile Customizations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164182364659.html).

Here are some guidelines and options for maintaining these files:

-   Configuration files can't be used for any custom mobile apps, which SCM Mobile doesn't support whether through mobile customization or configuration. For information about standard mobile apps supported by SCM Mobile, see [SCM Mobile Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161495429711.html).
    
-   Inactivate or delete custom mobile processes that you do not use. These are removed from configuration files.
    
    For instructions, see [Customizing Mobile Processes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163614423814.html).
    
-   If you only want to change the settings of existing page elements in standard processes, you can make the changes through mobile configuration. See [Configuring Mobile Page Elements](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161549215472.html).
    
-   You can disable the **Include Null Values in Configuration Files** setting to exclude empty and null field values from configuration files. This setting applies to all mobile apps on your account
    
    For instructions, see [Configuring SCM Mobile App Settings](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161496866735.html).
    

You can export and import custom or standard mobile processes to migrate or test them on different accounts. See the following topics:

-   [Exporting Mobile Processes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162618184323.html)
    
-   [Importing Mobile Processes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162618211501.html)
    
-   [Restoring Mobile Processes with Imported Updates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0903025607.html)
    

For limitations on additional page elements, see [Setting Up Additional Fields Through Mobile Customization](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156633029520.html).
