You can add the Print button to a NetSuite page or to a custom page of a custom mobile process. For more information, see the following topics:

-   [Adding a Print Button to NetSuite Pages](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162930057806.html)
    
-   [Adding a Print Button to Custom Mobile Pages](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162506635562.html)
    

When you add the Print button, you also add the Print popup window that appears for labels or documents that you manually print. On the Print popup window, you can specify your printing options such as the printer, template, and number of copies. If you have multiple printers or templates, you can customize the options that appear on the popup window.

To set up the print action of buttons that add to a custom mobile page, see [Setting Up Print Button Actions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162506769568.html).

If you want to edit print buttons or modify printing settings of standard mobile processes, refer to the Action Button element and Action Settings in the tables under [Configuring Mobile Page Elements](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161549215472.html).
