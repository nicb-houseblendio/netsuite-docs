If you set up the Image Capture Icon or File Upload Icon for a mobile process, you can access the icon on the associated mobile page. To capture or upload a file, you can tap the icon to open the camera or file browser, respectively. After you capture an image or upload a file, you can view the file ID and filename, which appears as a hyperlink. If you want to retake an image or delete a file, you can tap the delete icon next to it. After you complete the mobile process, the app saves it to your file cabinet, within the Images folder. From this folder, you can access the subfolder for the specific SCM Mobile app to view the captured or uploaded files. For more information about these icons, see [Setting Up Image Capture or File Upload](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0205024910.html).

Images and documents that you capture and upload cannot be more than 10 MB so that they could be saved in your file cabinet. The app automatically compresses images that exceed 10 MB by reducing the width to 600 pixels, maintaining the aspect ratio.

The app supports the following file formats only:

| Image formats | Document formats | Other formats |
| --- | --- | --- |
| BMPIMAGE GIFIMAGE ICON JPGIMAGE PJPGIMAGE PNGIMAGE SVG TIFFIMAGE | CSV EXCEL FREEMARKER PDF PLAINTEXT POWERPOINT RTF WORD | APPCACHE AUTOCAD JSON MSPROJECT VISIO XMLDOC XSD |

Your icon might be set up to attach images or files to NetSuite transactions not directly or immediately updated through the associated mobile process. An example would be mobile processes that may not directly or immediately update item fulfillments in NetSuite.

SCM Mobile provides a scheduled script to update the target NetSuite transaction separately from the mobile process. You can run this script after you capture or upload the file and complete the mobile process. Prior to running the script, also make sure that the target transaction has been created or is already existing.

If you want to define your own deployment to update multiple transactions based on a schedule, see [Creating Deployments for Target Transactions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0307113222.html).

Complete the following procedure to attach files through the scheduled script.

#### To attach captured or uploaded files from mobile devices: {#procedure_0205031546}

1.  Using the Administrator role, go to Setup > Custom > Attach Mobile App File.
    
2.  On the Attach Mobile App File page, in the **Target Transaction Type** field, select the type of transaction you want to update with the file attachments.
    
3.  Click **Attach**.
    
    Depending on the quantity of files, it may take a few moments to completely attach them all to the transactions.
    
4.  To view the status of a job, within in the Processing banner, click the **here** link.
    
5.  To view the image or document attachments, you can open the target transactions and go to the **Mobile App Attachments** subtab.
    

To view the file attachment records and statuses, open the Mobile - App Attachment list by going to Customization > Lists, Records & Fields > Record Types. For each reference transaction in the list, you can view the target transactions, including the processing and attachment statuses. A record without a target transaction ID means that the target transaction has not been created yet. In case of issues with attachments, you can also view the failure reason.
