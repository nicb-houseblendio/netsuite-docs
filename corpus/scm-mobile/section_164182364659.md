After you save all your customizations, you must compile them to update the mobile app.

#### To compile your mobile customizations: {#procedure_15143509770}

1.  Go to Setup > Custom > Mobile - Applications.
    
2.  On the Mobile - Applications List, click the **Update App** link next to the mobile application.
    

Wait for the confirmation message to appear before you try to access the mobile app. To view the status of your update, click the link on the processing message at the top of the page.

If you encounter an error or if you do not see the updated process on the app, the updates may have exceeded the file size limit. For more information, see [Mobile Customization Guidelines and Limitations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_163614460343.html#subsect_92112734571).
