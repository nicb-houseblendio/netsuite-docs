Aside from Mobile Printing, Ship Central and Warehouse Management integrates with PrintNode to provide access to weighing scale data. Through the Ship Central app, you can capture the weight of a packed carton and display it in the weight unit of your choice. Through the NetSuite WMS app, you can capture item weights during the PO Receiving process.

## Weighing Scale Support Requirements {#subsect_161523545493}

Note the following hardware and software requirements:

Note:

If you already use PrintNode for Mobile Printing, you do not need a separate API key for Weighing Scale Support. You can set up the PrintNode client on any additional computers used for weighing scales.

-   Active PrintNode account and valid PrintNode API key
    
-   Local computers installed and set up with the PrintNode client software
    
    The PrintNode client detects all the weighing scales from your local computer and syncs them with their servers and your PrintNode account. From your PrintNode client, you can track and view the status of your weighing scales.
    
-   Weighing scales must be supported by PrintNode.
    

For more information about weighing scales and PrintNode integration, see [NetSuite Ship Central FAQs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0831022109.html).

## Weighing Scale Support Setup Procedures {#subsect_161523569567}

After you set up your devices and PrintNode client, you can connect them to your NetSuite account. Complete the following procedures, some of which depend on your mobile app requirements.

1.  For your SCM mobile settings, check the **Enable Weighing Scale Support** box. See [Configuring SCM Mobile App Settings](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161496866735.html).
    
2.  Configure your PrintNode API key and safelist the IP addresses of computers installed with the PrintNode client. See [Configuring Security Settings](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161495993717.html).
    
    Note:
    
    If you have already configured PrintNode for Mobile Printing, you do not have to re-enter your PrintNode API key. You must safelist the IP addresses of any additional computers used for weighing scales.
    
3.  Depending on the mobile app you want to set up, do the following:
    
    -   For NetSuite WMS, activate the **Enable Weighing Scale Support for WMS App** system rule. See [System Rules for NetSuite WMS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156406918320.html).
        
    -   (Optional) For Ship Central, you can activate the **Set default weight unit rule**. Then, you can change the default unit for packed cartons, which is initially set to **kilogram**. See [Configuring Ship Central Rules](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111041523.html).
        
4.  On the mobile app, you can select the scale you want to use when you pack or receive items. You can change your selection at any time. See [Accessing SCM Mobile Apps on Your Device](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161497091941.html#subsect_161497112331).
