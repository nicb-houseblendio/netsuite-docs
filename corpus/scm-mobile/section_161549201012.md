Mobile Configuration enables you to modify the settings of standard mobile processes available in an SCM mobile app. You can configure the page elements used on the mobile pages of a process. You can change the preconfigured action of a button element. You can perform other configurations that suit your mobile app requirements.

Unlike Mobile Customization, you do not need to clone a mobile process to configure its settings. However, you can update more settings through customization. Also, you can't add all element types or fields to a mobile page through Mobile Configuration.

If you use Mobile Printing, you can set basic settings through Mobile Configuration.
