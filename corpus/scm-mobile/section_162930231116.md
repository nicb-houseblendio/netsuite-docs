You can create your user event and client script to configure printing for one or more records at the same time.

#### To add buttons through a user event script: {#procedure_29161259458}

1.  Prepare your user event and client scripts.
    
    For reference, you can view the sample user event and client scripts. See [SCM Mobile Scripts for Printing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162972692491.html).
    
2.  After you complete your custom scripts, you can create their script records. For the deployment record of your user event script, note the following:
    
    -   You can select the records in which you want to display a print button.
        
    -   For the event type, you can choose whether to run the script and display the print button in view or edit mode. If you do not specify an event type, the records display the button in both modes.
        
    
    For detailed instructions, see the following topics:
    
    -   [Creating a Script Record](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4489062315.html)
        
    -   [Methods of Deploying a Script](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4519293976.html) or [Deploying a Script by using the Deployments Sublist](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4490584904.html)
