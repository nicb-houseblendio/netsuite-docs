For labels or documents that you do not set to Automatic printing mode, you can manually print or save them from the mobile app. If you set up Mobile Printing on a NetSuite page, you can follow the same manual printing steps.

#### To manually print labels from your mobile device:

1.  Begin by performing the tasks within one of the following processes until you reach the mobile page on which you can print the label:
    
    -   [Receiving Orders](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1541435923.html)
        
    -   [Receiving Inbound Shipment Orders](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158212308061.html)
        
    -   [Searching for Inventory](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1541441790.html)
        
    -   [Building Assembly Items for a Work Order](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_155993396614.html)
        
    -   [Replenishing Primary Bin Locations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1541442264.html)
        
    -   [Picking Orders](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1541442950.html)
        
    -   For Ship Central, see [Ship Central Packing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111042907.html) or [Ship Central Shipping](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111051105.html).
        
2.  On the mobile page, tap **Print**.
    
3.  On the Print popup window, do the following:
    
    Note:
    
    The default settings in printing fields depend on the print report you use for the mobile process. See [Setting Up Printing Settings on Print Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161496026645.html) or [Setting Up Automatic or Required Printing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161496236607.html).
    
    1.  If you set up printer groups, in the **Printer Group** field, select the group in which the printer belongs to.
        
        List options in the Printer field appear based on both the printer type from the print report and the printer group of your choice. For more information, see [Creating Printer Groups](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0826023922.html).
        
    2.  In the **Printer** field, select the printer you want to use, or without PrintNode integration, select **Print to File**.
        
        If you do not find the printer you want to use, verify that it is set up correctly. See [Setting Up Your Printers](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161496008247.html) or [Setting Up Print to File](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0303093427.html).
        
    3.  In the **Template** field, select the print template file.
        
        If you select a supported PDF template, you can preview it before you print or save, as described in Step 3f.
        
    4.  In the **Number of Copies** field, enter a number greater than **0** for the copies you want to print.
        
    5.  In the **Page** field, enter the page number or a range of pages from the document you want to print. You can include a comma (,) or dash (-) symbol to specify multiple pages.
        
        Note:
        
        This field appears for print reports that you set up with selective page printing. See [Setting Up Printing Settings on Print Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161496026645.html).
        
        Refer to the following examples of valid entries:
        
        -   **1** - prints page 1
            
        -   **3,10** - prints pages 3 and 10
            
        -   **4-8** - prints pages 4 up to 8
            
        -   **4-** - prints page 4 up to the last page
            
        -   **\-5** - prints from the first page up to page 5
            
        -   **4, 8-** - prints page 4, then page 8 up to the last page
            
    6.  Tap **Print**.
        
        Alternatively, if Required printing is not set up for the process and you want to skip printing, tap **Skip**. If you want to preview a PDF file, tap the page icon beside the Print button.
        
        Tip:
        
        To open the Preview page for a PDF file, make sure that your browser doesn't have any popup blockers.
        
        If you encounter printing issues, see [Troubleshooting Mobile Printing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162499375334.html).
        
    
    You can repeat these steps to print other labels that you have configured for the process.
    
4.  After you print the labels, documents, or both, continue with the rest of the mobile process flow.
    
    For some processes, you can proceed to additional Print options for packing lists and international shipping documents, among others.
    

If you want additional copies or if you encounter a printing issue, you can reprint the label. See [Reprinting Labels](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158681935610.html).
