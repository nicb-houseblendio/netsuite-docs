If you use the Multi-Language feature, ensure that your language preference for the NetSuite UI matches the one for the app. To match your language preferences, choose the same language to apply to mobile pages and menu options within an SCM mobile app. For more information about the feature, see [Configuring Multiple Languages](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N247147.html).

The following table contains the list of supported languages that you can match with your language preference for the NetSuite UI:

| Language | Language Code | Language | Language Code |
| --- | --- | --- | --- |
| Chinese (Simplified) Chinese (Traditional) Czech Danish Dutch English (AU) English (CA) English (International) English (UK) English (U.S.) Finnish French French (Canada) German | zh\_CN zh\_TW cs\_CZ da\_DK nl\_NL en\_AU en\_CA en en\_GB en\_US fi\_FI fr\_FR fr\_CA de\_DE | Indonesian Italian Japanese Korean Norwegian Portuguese (Brazil) Russian Spanish Spanish (Latin America) Swedish Thai Turkish Vietnamese | id\_ID it\_IT ja\_JP ko\_KR no\_NO pt\_BR ru\_RU es\_ES es\_AR sv\_SE th\_TH tr\_TR vi\_VN |

To set the language for mobile apps, see the following topics:

-   [Adding Language Options for Mobile App Translation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161522893749.html)
    
-   [Selecting and Applying a Language](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161522879248.html)
    

If you encounter issues with language mismatches, see [SuiteApp Updates for SCM Mobile Apps](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0528015518.html).
