SCM Mobile provides the mobile capabilities and user interface for the following standard mobile apps:

-   **NetSuite WMS** - For use with the [Warehouse Management](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/book_156356229851.html) feature, it enables inbound, inventory, and outbound processing within your location.
    
-   **[Manufacturing Mobile](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/part_158644016906.html)** - Enables data collection for work order assignments and reporting of consumption and production data.
    
-   **[NetSuite Ship Central](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_90092747693.html)** - Optimized for kiosk and tablet devices, it enables carton and pallet packing, as well as order shipping.
    
-   **[Smart Count](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_83123952246.html)** - Enables directed or spot counting regardless of ongoing transactions that may affect on-hand inventory levels.

## Availability {#subsect_161495519706}

SCM Mobile is not a standalone SuiteApp. It is shared along with each SuiteApp required by its supported mobile apps: NetSuite WMS, Ship Central, Manufacturing Mobile, or Smart Count. For assistance regarding availability, you may contact your NetSuite account manager.

## Hardware and Software Requirements {#subsect_161495524434}

For use with NetSuite WMS, Manufacturing, and Smart Count, refer to the following requirements for handheld bar code scanners:

-   At least 256 MB flash memory
    
-   Only devices that have iOS (iPadOS 18 or higher versions for iPad; latest version for iPhone 13 or newer models) or Android (7.0 and higher versions) are supported. Support for versions may change subject to updates from their respective developers.
    
-   1D bar code scanner
    
-   4 inch or larger touch screen
    
-   802.11a/b/g enabled
    
-   Bluetooth enabled
    
-   HTML 5 & JavaScript enabled browser (TLS 1.2 compliant)
    
    Only the Google Chrome and Safari browsers are supported. You should use the latest version of the browser.
    
-   Interactive Sensor Technology (IST)
    
-   Ruggedized or semi-ruggedized (optional)
    

For use with Ship Central, refer to the following kiosk or tablet device requirements:

-   Device software -
    
    -   Kiosks: Windows 10.0 or higher
        
    -   Tablets: Only devices that have iOS ((iPadOS 18 or higher versions for iPad) or Android (7.0 or higher versions) are supported. Support for versions may change subject to updates from their respective developers.
        
    
    Only the Google Chrome and Safari browsers are supported. You should use the latest version of the browser.
    
-   Recommended screen resolution - 1280 x 800 up to 1920 x 1080
    
-   Optimized for horizontal user interfaces or the landscape display mode
    

If you enable the Mobile Printing capability with PrintNode integration, view the [Mobile Printing Requirements for PrintNode Integration](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161495837530.html#subsect_161495851722).

## SCM Mobile SuiteApp Installation {#subsect_161495552374}

Before you can install the SCM Mobile SuiteApp, be sure to enable the following required features:

-   Custom Records
    
-   Client SuiteScript
    
-   Server SuiteScript
    
-   Online Forms
    

Note:

If you do not find these features in your account, you may contact your account manager.

In case you need to uninstall the SCM Mobile SuiteApp, make sure that these features are still enabled when you do so.

To enable features, see [Enabling Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N232138.html).

You must install the SCM Mobile SuiteApp before you install the SuiteApp for any of the supported features. Install the latest bundle version, with the following details:

-   **Bundle name** - SCM Mobile
    
-   **Bundle ID** - 590761
    

To install the SuiteApps for the supported features, see the following topics:

-   [Installing the NetSuite WMS SuiteApps](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156399372911.html)
    
-   [Manufacturing Mobile for Administrators](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_158404110084.html)
    
-   [Installing the SuiteApps for NetSuite Ship Central](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111031232.html)
    
-   [Installing the Smart Count SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0620114413.html)
    

After you install the required SuiteApps, you must also complete the other setup requirements for each mobile app. Also make sure that you set up the Online For User role. See [Setting Up the Online Form User Role](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0814113835.html).

If you encounter issues with bundle updates or for more information, see [SuiteApp Updates for SCM Mobile Apps](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0528015518.html).
