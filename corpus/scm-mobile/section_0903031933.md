If you use colors to highlight table rows, you can group together rows that have the same color. On a Data Table element, you can tap the table icon to display the table configuration popup window. Then, you can tap the **Group By Color** toggle to display select a color.

On a Data Table element, you can also apply the color filter to view only rows of a certain color. You can tap the search icon to display the search box and filter selector. From the filter selector, tap **Colors** and then tap the box next to the color you want to select. Tap **Done** to apply your color filter.

Beside the table icon, you can tap the info icon to view the descriptions that you set up for one or more colors.

To set up colors for Data Table rows, see [Setting Up Table Row Colors](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0903023743.html).
