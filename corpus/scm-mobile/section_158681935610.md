You can reprint the documents printed from a mobile device, even those that failed the initial printing. You can send reprint requests from a mobile device or from the NetSuite user interface, as described in the following topics in this section:

-   [Reprinting from Your Mobile Device](#subsect_158681944034)
    
-   [Reprinting from the NetSuite User Interface](#subsect_158681956027)
    

Your file cabinet stores files for reprinting until they reach the retention time defined on your printing settings. By default, NetSuite WMS retains printable files in your file cabinet for 24 hours before it deletes them. If you want to view or update your file retention setting, see [Configuring Mobile App Settings](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158411380821.html).

Print or audit logs in your mobile device or NetSuite user interface display the list of files for reprinting. You can access the reprint link in these logs until the printable files get deleted from your file cabinet. You can also view printing errors from these logs.

## Reprinting from Your Mobile Device {#subsect_158681944034}

Follow the steps in this procedure to reprint existing labels or reports from your mobile device.

#### To reprint labels and reports from your mobile device:

1.  From the Main Menu, tap **Print Log**.
    
2.  On the Print Log page, in the **Scan/Enter Print Reference** field, scan or enter the transaction number, the item, lot, or serial number. If you enter the data, press **Enter** to proceed.
    
    For item bar code scanning, composite and GS1 bar code formats are not supported
    
3.  On the Print Log page, tap the date link for the document you want to reprint.
    
4.  On the Print Record page, enter or select values in any of the following fields:
    
    -   **Printer Group** - If you set up printer groups, select the one in which the printer belongs to.
        
        List options in the Printer field appear based on the printer type from the print report and the printer group of your choice. For more information, see [Creating Printer Groups](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0826023922.html).
        
    -   **Printer** - Select the name of the printer or without PrintNode integration, select **Print to File**.
        
        If you do not find the printer you want to use, you can verify that it is set up correctly. See [Setting Up Your Printers](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161496008247.html) or [Setting Up Print to File](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0303093427.html).
        
    -   **Number of Copies** - Enter a number greater than 0 for the copies you want to reprint.
        
    -   **Page** - Enter the page number or a range of pages from the document you want to print. You can include a comma (,) or dash (-) symbol to specify multiple pages.
        
        Note:
        
        This field appears for print reports that you set up with selective page printing. See [Setting Up Printing Settings on Print Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161496026645.html).
        
        Refer to the following examples of valid entries:
        
        -   **1** - prints page 1
            
        -   **3,10** - prints pages 3 and 10
            
        -   **4-8** - prints pages 4 up to 8
            
        -   **4-** - prints page 4 up to the last page
            
        -   **\-5** - prints from the first page up to page 5
            
        -   **4, 8-** - prints page 4, then page 8 up to the last page
            
5.  Tap **Reprint**.
    
    If you encounter reprinting issues, see [Troubleshooting Mobile Printing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162499375334.html).
    

Your reprint request is sent to the printer.

## Reprinting from the NetSuite User Interface {#subsect_158681956027}

Follow the steps in this procedure to reprint existing labels or reports within the NetSuite user interface.

#### To reprint labels and reports from the NetSuite user interface:

1.  Using the Mobile Administrator role, go to Setup > Label Printing > Audits.
    
2.  From the Print - Audits List, click the reprint URL link for the document you want to reprint.
    
    The Print - Reprint page appears.
    
3.  (Optional) In the Reprint Details section, you can change the values in any of the following printing fields:
    
    -   **Printer Group** - If you set up printer groups, select the one in which the printer belongs to.
        
        List options in the Printer field appear based on the printer type from the print report and the printer group of your choice. For more information, see [Creating Printer Groups](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0826023922.html).
        
    -   **Printer** - Select the name of the printer or without PrintNode integration, select **Print to File**.
        
        If you do not find the printer you want to use, you can verify that it is set up correctly. See [Setting Up Your Printers](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161496008247.html) or [Setting Up Print to File](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0303093427.html).
        
    -   **Copies** - Enter a number greater than 0 for copies you want to reprint.
        
    -   **Page** - Enter the page number or a range of pages from the document you want to print. You can include a comma (,) or dash (-) symbol to specify multiple pages.
        
        Note:
        
        This field appears for print reports that you set up with selective page printing. See [Setting Up Printing Settings on Print Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161496026645.html).
        
        Refer to the following examples of valid entries:
        
        -   **1** - prints page 1
            
        -   **3,10** - prints pages 3 and 10
            
        -   **4-8** - prints pages 4 up to 8
            
        -   **4-** - prints page 4 up to the last page
            
        -   **\-5** - prints from the first page up to page 5
            
        -   **4, 8-** - prints page 4, then page 8 up to the last page
            
    -   **Description** - Enter a short description of this reprint request for the audit logs.
        
4.  Click **Reprint**.
    
    If you encounter reprinting issues, see [Troubleshooting Mobile Printing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162499375334.html).
