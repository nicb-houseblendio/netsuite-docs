Independent mobile pages, which do not depend on a mobile process, are usually set up as menus using icon elements and images. The icons provide access to mobile processes or to additional menu options.

You can configure a standard independent page to modify the settings of its icons. You can change the display settings and the image of an icon. If you want to restrict access to a standard mobile process, you can choose which roles can access its icon.

If you customize a mobile process, you can hide the icon for the standard process and keep the one for your custom process.

Updates to independent pages apply to standard mobile processes only.

#### To configure menu icons independent mobile pages: {#procedure_0804040852}

1.  Access the Mobile - Process List page by doing the following:
    
    1.  Using the Administrator role, go to Setup > Custom > Mobile - Applications.
        
    2.  On the Mobile - Applications List page, click **View** next to a mobile app.
        
2.  On the Mobile - Process List page, click **Configure Independent Pages**.
    
3.  On the Mobile Configuration page, from the **Page** field, select the name of the independent page.
    
4.  On the **Page Element** subtab, from the **Mobile Page Element** field, select the name of the icon element on the independent page.
    
5.  In the Element Settings section, you can update the following fields:
    
    -   **Label** - Select a different label, or to create a new one, click the plus icon.
        
    -   **Element Icon** - Enter the file cabinet path to the image you want to display for the icon.
        
        Example: **~/src/Images/binTransfer.svg**
        
    -   **Visibility Condition** - Enter **true** or keep the field blank to show the icon, or enter **false** to hide it from the independent page. Alternatively, you can enter a condition through which you can control the icon's visibility on the independent page.
        
    -   **Roles** - Select the roles to which you want to provide access to the icon.
        
    -   **Display Order** or **Layout** - See [Arranging Page Elements](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163614572439.html#subsect_163614622483).
        
    
    For more information about these page element settings, see [Customizing Mobile Page Elements](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163614572439.html).
    
6.  Click **Save**.
