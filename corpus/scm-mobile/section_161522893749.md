Before you can apply your language preference to the mobile app interface, verify that you have added the language to your translation list.

To view the list of supported languages that you can add to your translation list, see [Language Preference Setup for SCM Mobile](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161495570632.html). NetSuite can translate text on the mobile app interface to any of these languages.

#### To add language options for mobile app translation:

1.  Using the Administrator role, go to _Setup > Company > General Preferences_.
    
2.  On the General Preferences page, click the **Languages** subtab, and then do the following:
    
    1.  In the **Language** column, select the language that matches your language preference in the NetSuite UI..
        
    2.  Click **Add**.
        
        If you have accounts in other languages, repeat steps a - b to add more language options for translation.
        
3.  Click **Save**.
    
    If you don't use the NetSuite WMS app, you can proceed to step 5.
    
4.  After you add one or more languages to the NetSuite WMS app, you must sync the system rules by doing the following:
    
    1.  Using the WMS Warehouse Manager role, go to WMS Configuration > Configure Warehouse > Sync System Rules Translations.
        
    2.  On the System Rules Translations page, click **Update System Rules Translations**.
        
    3.  In the confirmation message, click the link to verify that the sync job has been completed.
        
    
    After you set up and sync the languages, update the mobile app.
    
5.  To update the mobile app, do the following:
    
    1.  Using the WMS Warehouse Manager role, go to WMS Configuration > Configuration > Applications. Alternatively, using the Ship Central Manager role, go to Ship Central Setup > Apps Setup > Applications.
        
    2.  On the Mobile - Applications List, next to the mobile app, click **Update App**.
        
    
    To update other apps within your NetSuite account, repeat this step.
    

Your mobile application update might take a few minutes to complete. In the processing message, click the link to view the progress.

After adding the language to your list, you can set the language preference for your mobile app interface. See [Selecting and Applying a Language](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161522879248.html).
