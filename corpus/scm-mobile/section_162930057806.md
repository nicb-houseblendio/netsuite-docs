When you enable Mobile Printing, you can set up a print button on standard and custom NetSuite forms, transactions, and records, including those not used in the mobile apps. On NetSuite pages, you can display a print button that submits your print requests through PrintNode. To configure the print action for your button, create a client script that invokes the SCM Mobile RESTlet for printing.

## Prerequisites for Print Button Setup {#subsect_39150807546}

Before you configure your print button and client script, verify that you have set up the Mobile Printing capability. If you want to use custom print templates for PDF labels or documents, be sure to create your XML or Advanced PDF print files. For more information, see the following topics:

1.  [Mobile Printing Requirements for PrintNode Integration](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161495837530.html#subsect_161495851722)

## Print Button Configuration Options {#subsect_27151052921}

You can add print buttons to a NetSuite page through either of the following configuration options:

-   [Adding Print Buttons Through a User Event Script](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162930231116.html) - This option involves creating a user event script, aside from the client script. You can apply the user event to one or more NetSuite records at the same time. It enables you to control whether to display the button in view, edit, or both modes.
    
-   [Adding a Print Button to a Custom Form](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162930234840.html) - If you want to set up a print button and client script in a single entry or transaction form, you can choose this approach. It involves configuring a custom form, which displays the print button in edit mode only.
    

Note that if you apply both approaches to a transaction, it displays duplicate print buttons in edit mode.

## Accessing Printed Labels or Documents {#subsect_85151242255}

SCM Mobile stores a soft copy of documents that you print in the PrintDocuments folder of your file cabinet.

Important:

The PrintDocuments folder contains the PrintDocument.xml file, which is used internally. Do not edit or modify this file.

When you access your file cabinet, you can view this folder through the following path: SuiteBundles > Bundle <SCM Mobile bundle ID> > com.netsuite.mobile > PrintDocuments. To view the SCM Mobile bundle details, see [SCM Mobile SuiteApp Installation](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161495429711.html#subsect_161495552374).
