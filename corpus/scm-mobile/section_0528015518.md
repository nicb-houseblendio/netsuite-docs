After an upgrade to your NetSuite account, the SCM Mobile SuiteApp is updated along with the SuiteApps for the mobile apps you use. SuiteApo updates start automatically, so you must not uninstall any of them during and right after your NetSuite account upgrade.

See the following topics for information about these SuiteApp updates:

-   [SuiteApp Update Schedule](#subsect_0528020110)
    
-   [Notifications for SuiteApp Updates](#subsect_0528020153)
    
-   [Reporting SuiteApp Update and Login Issues](#subsect_0528021048)
    
-   [Viewing the Update Status and SuiteApp Versions](#subsect_0406011813)
    

For information about SuiteApps for SCM Mobile, see [SCM Mobile Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161495429711.html).

## SuiteApp Update Schedule {#subsect_0528020110}

SCM Mobile and its supported SuiteApps are updated automatically after your NetSuite account upgrade. If not immediately, it may begin within seven business days after your NetSuite account upgrade, depending on the number of accounts in the queue.

For installation or update in Release Preview or Sandbox accounts, you can review the availability schedules in their corresponding SuiteAnswers articles. See [Notifications for SuiteApp Updates](#subsect_0528020153).

## Notifications for SuiteApp Updates {#subsect_0528020153}

Before any SuiteApp update, the following notifications are sent to your NetSuite account contacts:

-   **Pre-Release Notice** - informs you about the availability of enhancements to SCM Mobile and the related mobile app you use in Release Preview accounts.
    
-   **Upgrade Notice** - provides details about which SuiteApps will be updated in your account and their new bundle IDs.
    

Both of these notices include an overview of enhancements to SCM Mobile and the mobile app you use. Separate notices are sent for each mobile app, such as NetSuite WMS or NetSuite Ship Central.

In addition to these notices, you can view the SuiteApp availability schedules in the following SuiteAnswers articles:

-   [Ship Central: Availability of the Ship Central SuiteApp During Account Upgrades](https://suiteanswers.custhelp.com/app/answers/detail/a_id/100694/loc/en_US), SuiteAnswers ID: 100694
    
-   [NetSuite WMS: Availability of the Oracle NetSuite WMS and SCM Mobile SuiteApps During Account Upgrades](https://suiteanswers.custhelp.com/app/answers/detail/a_id/87598/loc/en_US), SuiteAnswers ID: 87598
    

From these articles, you can review the availability schedule for the leading or lagging version of a SuiteApp during NetSuite account upgrades.

For example, based on the availability schedules, if your NetSuite account has not been upgraded to the latest version, you can do the following:

-   Install only the lagging SuiteApp version in a production or Sandbox account.
    
-   Install or update the leading SuiteApp version in your Release Preview account at certain dates and times only
    

## Reporting SuiteApp Update and Login Issues {#subsect_0528021048}

You may encounter the following issues after a SuiteApp update due to mismatched versions or failures:

-   No access to a mobile app or could not log in
    
-   Permission violations
    
-   Features not available to a role
    
-   Language mismatch
    

You can start resolving them by viewing your SuiteApp versions. Make sure that you have the latest version of the SCM Mobile SuiteApp and the supported SuiteApps for the mobile apps you use. For instructions, see [Viewing the Update Status and SuiteApp Versions](#subsect_0406011813).

For example, you may have SCM Mobile SuiteApp version 2025.1.xx and Oracle NetSuite WMS version 2024.2.xx.

If you don't have the latest version or if they don't match, you may contact NetSuite Support to request a bundle repush.

After you obtain matching versions of the latest SuiteApps, you can review your settings for the components related to the issue. These may include roles, permissions, login URL, and language preferences. For more information, see the following topics:

-   [Setting Up the Online Form User Role](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0814113835.html)
    
-   [SCM Mobile App Access](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161497091941.html)
    
-   [Language Preference Setup for SCM Mobile](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161495570632.html)
    
-   [Showing Role Permission Differences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N292157.html)
    

## Viewing the Update Status and SuiteApp Versions {#subsect_0406011813}

Using the Administrator role, you can go to Customization > SuiteBundler > Search & Install Bundles > List to view the Installed Bundles page. In the Version column, you can view the current version number for SCM Mobile and its related SuiteApp for the mobile app you use. If a new version of a SuiteApp has been released, the info icon appears beside the version number. You can click the info icon to view the new version number.
