SCM Mobile provides the following components for each mobile process:

-   **Mobile process icon** - From the Main Menu, you can access a mobile process by tapping its icon.
    
-   **Mobile pages** - To complete a task within a mobile process, you can go through a set of pages arranged in a sequence according to a process flow. Process flows vary depending on features that you use or how you complete a task. You might see additional pages if you use bins, use pallets, process lot items, or tally scan item bar codes.
    
    A page includes an information screen that you can access to view details captured from previous pages. Mobile processes may also include popup windows for additional information or tasks. Error messages or warnings may appear on popup windows or below the page header.
    
    Within a mobile process, the last page is a summary page that shows a confirmation message for the completed task. It also includes an overview of submitted or processed details. Depending on the mobile process, you can reach the summary page by entering or scanning the last required detail to complete a task.
    
-   **Mobile page elements** - Mobile pages contain page elements, which include fields, buttons, and tables. Details you provide through a page element may be required or optional. You can access succeeding pages based on actions that you perform on page elements, until you complete a task. You can also return to previous pages using the Back button on mobile pages.
    

Some mobile pages or page elements appear based on system rules, preferences, and other settings that you enable for the mobile app.
