For the NetSuite WMS app only, you can activate the **Add Date Filtering** rule for Data Table elements that display transactions. On the app, the **Filter By Date** field appears on the Table Configuration popup window. Based on your rule configuration, you can select from this field the filter that you want to apply to the table data. It includes the an **All** option that displays all relevant transactions. For more information about the rule, see [System Rules for NetSuite WMS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156406918320.html).

The following image shows the **Filter By Date** field for the Open Purchase Orders table within the PO Receiving process. The filtering options configured on the system rule include **Past 2 months**, **Past 3 months**, and **Past 6 months**.

![Filter by date](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/WarehouseManagement/SCMMobile/Basics_filterbydate.png)

Applying the **Past 2 months** filter displays only open purchase orders dated up to 2 months prior to the current date. Even when you log out of the mobile app, the date filter for a table persists unless you clear the browser's cache.

For mobile pages that include both an entry or scan field and a table for selection, transactions that you can enter or scan in the field may depend on the date filter. If a scanned transaction couldn't be found from the table, you can try choosing another date filter or the **All** option.

![Table filter](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/WarehouseManagement/SCMMobile/Basics_tablefilter.png)
