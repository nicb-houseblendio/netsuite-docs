You can clone a standard mobile process to create your custom process and customize it according to your business requirements. Within your custom mobile process, you can add pages or page elements, set up the actions of a button, and perform other such customizations.

When you clone a mobile process, you create a duplicate version of its standard pages. If you modify a standard process through Mobile Configuration, your configurations do not carry over to the resulting custom process.

The pages of your custom process contain the same elements that appear on the standard process. By default, the same names are assigned to the custom processes and pages followed by an autogenerated sequence number.

For example, if you create a third clone of the purchase order receiving process, the following default names are assigned:

-   Custom process - NSWMS\_POReceiving\_3
    
-   Page name (Enter Bin page) - poReceiving\_enterBin\_3
    

#### To customize mobile processes: {#procedure_80144335716}

1.  Using the Administrator role, go to Setup > Custom > Mobile - Applications.
    
2.  On the Mobile - Applications List page, click **View** next to the mobile app that contains the process you want to customize.
    
    The Mobile - Process List page appears.
    
3.  Clone the standard mobile process that you want to customize by doing the following:
    
    1.  Next to the process you want to clone, click **Clone**.
        
    2.  On the Clone Process page, click **Clone**.
        
    
    It may take a few minutes to completely clone the process.
    
    Your custom mobile process appears on the Mobile - Process List page. To return to this page, repeat from step 1.
    
4.  On the Mobile - Process List page, click **Edit** next to your custom process.
    
    The Mobile - Process page appears.
    
5.  In the following fields, you can customize the default settings for the process:
    
    -   **Name** - Enter the name of the process that you want to appear on a mobile device.
        
    -   **Parent Application** - For new processes, select the mobile app to which you want to associate this process.
        
        Note:
        
        You should not change the standard mobile app associated with existing processes. It might break the process flows and cause errors.
        
        You can't select or set up any custom mobile apps in this field. For information about standard mobile apps supported by SCM Mobile, see [SCM Mobile Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_161495429711.html).
        
        Also, make sure you select the same mobile app for a process and all of its pages.
        
    -   **First Page** - Select the custom mobile page that you want to assign as the first page for this process.
        
        Alternatively, to create a new first page, click the plus icon beside the field. See step 6.
        
    -   **Accessible Roles** - (Optional) Select the roles to which you want to provide access to this process.
        
        If you do not select a role, the custom process becomes accessible to all available roles. Make sure you select an appropriate role for the mobile app. To view the list of roles, see the following topics:
        
        -   NetSuite WMS app roles - [Warehouse Management Roles and Permissions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156520467974.html)
            
        -   NetSuite Ship Central app roles - [NetSuite Ship Central Roles and Permissions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111033438.html)
            
        -   Manufacturing Mobile app roles - [Manufacturing Mobile for Administrators](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_158404110084.html)
            
6.  On the **Pages** subtab, you can view, customize, or add pages within the mobile process. For instructions, you can proceed to step 2 of the procedure under [Customizing Mobile Pages](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163614512507.html).
    
7.  After you complete your mobile process customizations, click **Save**.
    
8.  If you want to remove access to the standard mobile process and show only your custom process, you can hide the icon of the standard one from the menu. For instructions, see [Configuring Menu Icons on Independent Mobile Pages](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0804040635.html).
    
    On your mobile device, you can access your custom process on the same menu page that displays the standard process.
    
9.  After you complete all your mobile customizations, update the app, See [Compiling Mobile Customizations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_164182364659.html).
