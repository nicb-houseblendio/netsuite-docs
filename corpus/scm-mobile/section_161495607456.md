If you use the Bar Code Scanning and Item Labels feature, you can scan bar codes when processing orders through a mobile app. You can also set up advanced bar code scanning to scan item bar codes in specific formats, depending on the mobile app.

For Warehouse Management, you can scan item bar codes in the following advanced formats:

-   Composite (linear and Data Matrix)
    
-   GS1 (GS1-128 and GS1 DataMatrix)
    
-   HIBC (Code 128 and Data Matrix)
    

To set up, see [Bar Code Setup for NetSuite WMS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158264895870.html).

For Ship Central, you can scan item bar codes in the following advanced format:

-   GS1 DataMatrix
    

To set up, see [Bar Code Scanning for Ship Central](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0726023627.html).
