Within standard mobile processes, you can add buttons on mobile pages that perform additional actions according to your app requirements. When you configure a button, specify its label, position, and the mobile action that performs a task when you click it. For supported action types, you can also add your own loading text for your new button's action.

Note the following guidelines and requirements for adding buttons:

-   You can configure Action Button element types only.
    
-   Buttons that you configure can be displayed on the body or footer of a mobile page. You cannot display them on popup windows associated with the mobile page.
    
-   If you want to provide your own button image, upload it into your file cabinet. Buttons that use custom images can be displayed only on the body of the page.
    
-   You can assign a standard mobile action or create a custom one for your button. You can also clone a standard action and configure your copy according to your button requirements.
    
    Common button actions that you can configure include printing, navigation, message display, and table data display.
    

#### To add Action Buttons through Mobile Configuration:

1.  Access the standard mobile page on which you want to add a button.
    
    For instructions, see [Configuring Mobile Page Elements](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161549215472.html).
    
2.  On the Mobile Configuration page, you can do the following:
    
    -   If you want to clone a standard action that you want to set up for new button, see [Cloning Standard Mobile Actions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0130020330.html).
        
        When you set up the click action for your button, you can configure your copy of the action according to your button requirements.
        
    -   To add your button, click the **Additional Page Elements** subtab. Beside the **Configuration Page** field, you can click the new icon. If you have existing custom elements configured within the same process, you can click the open icon.
        
3.  On the Mobile - Page page, on the **Page Elements** subtab, click **New Mobile - Page Element**.
    
    On this subtab, you can view other custom page elements within the standard mobile process.
    
4.  On the Mobile - Page Element page, do the following:
    
    1.  In the **Type** field, select **Action Button**.
        
    2.  Set values in the basic button fields, like the **Name** and **Label**.
        
    3.  To use your own button image, in the **Icon Path** field, enter the path to the file cabinet folder that contains it.
        
    4.  In the **On Click Action** field, click the plus icon.
        
    
    For more information about button fields, see [Customizing Mobile Page Elements](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163614572439.html). For Print buttons, see [Adding a Print Button to Custom Mobile Pages](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162506635562.html).
    
5.  On the Mobile - Action page, do the following based on the type of mobile action you want to assign to the button:
    
    1.  In the **Type** field, select the type of mobile action you want to assign to the button.
        
    2.  Set the appropriate action fields based on the type of mobile action.
        
        For supported action types, you can add your own loading text. See [Setting Up Custom Loading Text for Mobile Actions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0730100731.html).
        
    3.  For actions that use RESTlets or saved searches, you can set up the one you want to run during a button click.
        
    4.  (Optional) On the **Input Parameters** or **Output Parameters** subtabs, you can set up parameters for your mobile action.
        
    
    For detailed instructions, see the following topics:
    
    -   [Customizing Mobile Actions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0808031458.html)
        
    -   If you want to set up a Print action, with automatic or required printing modes, see [Setting Up Print Button Actions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162506769568.html).
        
    -   [Retrieving Messages Through Mobile Actions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0318015507.html#subsect_0318020000)
        
6.  (Optional) On the Mobile - Page Element page, you can set the **Autoclick Condition** field to run your click action automatically.
    
    For instructions, see [Setting Up Autoclick for Buttons](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0205033216.html).
    
7.  After you complete all your configurations, on the Mobile Configuration page, update the app by clicking **Save and Update**.
