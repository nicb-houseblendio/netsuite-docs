SCM Mobile provides a specific Mobile - Page page on which you can add supported page elements to standard processes through Mobile Configuration. From this page, you can also delete page elements that you no longer use. However, you cannot delete the mobile page itself.

If you don't want to show a page element on a mobile page without deleting it, you can update the visibility fields instead. For instructions, see [Page Element Visibility and Loading](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163614572439.html#subsect_163614607521).

#### To delete configured page elements from a standard process:

1.  Access the standard mobile page that contains page elements that you want to delete.
    
    For instructions, see Steps 1 to 3 of this procedure, [To configure mobile page elements:](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161549215472.html#procedure_4143315991)
    
2.  On the Mobile Configuration page, go to the **Additional Page Elements** subtab, and then next to the **Configuration Page** field, click the open icon.
    
    The Mobile - Page page appears.
    
3.  On the **Page Elements** subtab, next to a page element that you want to delete, click **Edit**.
    
4.  On the Mobile - Page Element page, do the following:
    
    1.  To delete a table, on the **Table Columns** subtab, delete all the columns. Then, check the other subtabs for the table to delete all the entries.
        
    2.  If the page element has records on the **No Code Settings** subtab, delete all of them.
        
    3.  From the **Actions** submenu, click **Delete**.
        
    4.  If the Notice page appears, you can click the **dependent records** link to view other records that you have not deleted from the page element's subtabs. Refer to Steps 4a and 4b.
        
5.  On the Mobile - Page page, you can verify that the page element has been removed from the list. You can also delete another page element.
    
6.  On the Mobile Configuration page, if you want to delete page elements from another mobile page, do the following:
    
    1.  Click **Save** to save your updates for the current page.
        
    2.  In the **Page** field, select another mobile page.
        
    3.  Repeat Steps 2 to 6.
        
7.  After deleting all the page elements from the mobile pages, click **Save and Update App**.
    
8.  If you delete an Action Button type of element that has an icon, you can also delete the icon from your file cabinet.
