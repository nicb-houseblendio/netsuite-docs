You can enable and set up Mobile Printing to print or save labels and documents for supported mobile apps. Depending on the apps you use, it provides preconfigured templates for labels and documents. You can customize these templates to add details for your labels and documents. You can add rules to specify when you want to use them and assign default printing settings. For more information about labels and documents available for Mobile Printing, see the following topics:

-   [Mobile Printing for NetSuite WMS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158411462538.html)
    
-   [Mobile Printing and Weighing Scale Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0131112602.html)
    

## Enabling Mobile Printing without PrintNode Integration {#subsect_29152053486}

Without PrintNode integration, you can save soft copies of generated labels and documents for shipping, including returns. You cannot set up printers and send print requests through the mobile app. Also, you cannot set up weighing scales and capture weights through the mobile app. For more information, see [Setting Up Print to File](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0303093427.html).

## Enabling Mobile Printing with PrintNode Integration {#subsect_0303092855}

Oracle NetSuite integrates with PrintNode, a third-party provider of hosted printing services. Through computers installed with the PrintNode client, PrintNode can access your network printers. You can submit your print requests from the app through PrintNode, which manages the requests and routes them to the appropriate printers.

When you enable Mobile Printing with PrintNode integration, you can also enable support for weighing scales.

For more information about PrintNode integration, see [NetSuite Ship Central FAQs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0831022109.html).

## Mobile Printing Requirements for PrintNode Integration {#subsect_161495851722}

Before you begin your Mobile Printing setup, make sure that the following requirements are met:

-   Online Forms and Advanced PDF/HTML Templates features enabled on your NetSuite account
    
    For instructions, see [Enabling Features](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N232138.html).
    
    Note:
    
    If you don't find the Online Forms or Advanced PDF/HTML features in your NetSuite account, contact your account manager.
    
-   Active PrintNode account and valid PrintNode API key
    
    For PrintNode requirements, you can visit the home page at [https://www.printnode.com](https://www.printnode.com).
    
-   Printers configured for network printing
    
    Note:
    
    Make sure your printer drivers are up to date.
    
-   Local computers installed and set up with the PrintNode client software
    
    The PrintNode client detects the printers from a local computer and syncs them with their servers and your PrintNode account. From your PrintNode client, you can track and view the status of your printers.
    
-   If you use ZPL printers for Ship Central, choose the following printing preferences when you print labels:
    
    -   Page size - 4 x 6 in
        
    -   Orientation - Portrait
        
    -   Printing position - 0.00 in (no offsets)
        
    
    For more information, see [Shipping Labels and Documents for Mobile Printing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0131112602.html#subsect_53113621200).
    

## Mobile Printing Setup Procedures {#subsect_161495863496}

If you set up Mobile Printing for Warehouse Management, you can use the same basic settings for Ship Central. If you use PrintNode integration, verify that your printing and printer settings for Warehouse Management apply to Ship Central.

Without PrintNode integration, skip the procedures and settings for printer devices and the Online Forms feature. For more information, see [Setting Up Print to File](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0303093427.html).

With PrintNode integration, you can complete the following procedures to set up Mobile Printing for Warehouse Management, Ship Central, or both:

1.  After you enable the Online Forms feature, verify that the Online Form User role is configured properly. See [Setting Up the Online Form User Role](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0814113835.html).
    
2.  For your SCM Mobile settings, check the **Enable Mobile Printing** box. See [Configuring SCM Mobile App Settings](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161496866735.html).
    
3.  Configure your PrintNode API key and IP addresses of computers installed with the PrintNode client. See [Configuring Security Settings](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161495993717.html).
    
    Note:
    
    If you have configured Mobile Printing for Warehouse Management and you want to set it up for Ship Central, you don't have to re-enter your PrintNode API key.
    
4.  Verify that all the printers you want to use for each app appear in your account. Assign each a printer type to designate the ones you want to use for label printing or regular printing. See [Setting Up Your Printers](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161496008247.html).
    
    Optionally, if you create printer groups, you can assign printers to them. See [Creating Printer Groups](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0826023922.html).
    
5.  For NetSuite Ship Central, make sure that you set your preferences for international and local shipping labels, default logo, and return labels for local shipments. You can also activate the rule for brand names. See [Details on Shipping Labels and Documents](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1111051105.html#subsect_85095144742).
    
6.  If you want to create your own custom templates for labels or documents, see [Creating Custom Print Templates and Files](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0206031419.html).
    
7.  Assign a default printer, template, and number of copies for labels or documents you want to print. If you create a custom template and file, you can assign it as the default template for printing. You can set up these default settings in a print report type. See [Setting Up Printing Settings on Print Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161496026645.html).
    
    On print report types, you can enable page number entry. You can also add rules to specify which printers or templates to use for a label or document. See [Configuring Rules for Printers, Templates, or Number of Copies](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161496136236.html).
    
8.  (Optional) You can change the default printing mode to automatic and required for each standard or custom label or document. If you want to exclude a label or document from printing, you can inactive the associated print report. See [Setting Up Automatic or Required Printing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161496236607.html).
    

If you encounter setup or printing errors, see [Troubleshooting Mobile Printing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162499375334.html) or [Resyncing Printer Connections](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0722022508.html).

If you want to add a Print button to a page, see the following topics:

-   To set up Print buttons and actions on custom mobile pages within the app, see [Adding a Print Button to Custom Mobile Pages](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162506635562.html).
    
-   To set up printing on NetSuite pages, see [Adding a Print Button to NetSuite Pages](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162930057806.html).
