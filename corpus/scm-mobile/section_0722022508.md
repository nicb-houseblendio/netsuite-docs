SCM Mobile provides the Resync Printers tool for keeping your printers list up to date based on the active printers in your PrintNode client. By default, it syncs your printers automatically every 15 minutes. At any time, you can run the tool to resolve issues due to disconnected, offline, or inactive printers..

Using the Administrator role, you can access and start the Resync Printers tool by going to Setup > Custom > Resync Printers. Using other roles, you may access it from the Printing Setup submenu. It immediately runs the **Print - Print List Sync Scheduler** script to obtain active printers from your PrintNode client. It also opens the Scheduled Script Status page that contains the list of manual and automatic default resync jobs. On this page, you can view the progress and status of a job. After you see a job switch to Complete status, you can view your list of updated printers and set up any new ones. For instructions, see [Setting Up Your Printers](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161496008247.html).

In case you manually add printer records to the Printers List, the sync script inactivates them automatically. SCM Mobile uses only printer records that it automatically generates from the active printers in your PrintNode client. For more information, see [Troubleshooting Mobile Printing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162499375334.html).
