For Date page elements within mobile processes, time fields that you add appear beside the field for date entry. They follow your Time Zone general preference and appears in UTC format.

Through Mobile Configuration or Customization of a Date page element, you can check the following boxes for time settings:

-   **Show Time Field** - To display the time field, check this box.
    
    For Mobile Configuration, this box appears only if the **Is Preconfigured for Time** box is checked for the Date page element.
    
-   **Make Time Mandatory** - If you check the **Show Time Field** box, you can check this box to require time entry in the time field.
    

For the following time value settings, you can enter a specific time or a state path for a dynamic value:

-   **Default Time** - The value you want to appear in the time field initially and if no value is entered on the app.
    
-   **Earliest Possible Time** - The earliest time that you can enter in the time field.
    
-   **Latest Possible Time** - The latest time that you can enter in the time field.
    

To specify a static value in any of these fields, enter it in 24-hour (UTC) format, HH:mm. Based on this format, HH ranges from **0** to **23** and mm ranges from **0** to **59**.

To specify a dynamic value, enter a state path to the time key, as in the following default path: **{{state.dataRecord.scriptParams.time}}**.

To access these settings on the Mobile - Page Element page for customization, see [Customizing Mobile Page Elements](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_163614572439.html). To access them on the Mobile Configuration page, see [To configure mobile page elements:](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161549215472.html#procedure_4143315991)
