With the Mobile Printing capability, you can print as you process tasks on the mobile app. Depending on your printing setup, you can print a hard copy or save a soft copy of a label or document. Before you print supported labels in PDF format only, you can preview them.

To enable Mobile Printing, see the following topics:

-   [Enabling Mobile Printing without PrintNode Integration](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161495837530.html#subsect_29152053486)
    
-   [Enabling Mobile Printing with PrintNode Integration](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161495837530.html#subsect_0303092855)
    

Depending on the app you use, you can print standard labels and documents, such as item labels, packing lists, and shipping labels, as listed in the following topics:

-   [Mobile Printing for NetSuite WMS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158411462538.html)
    
    If you use pick cartons for the order picking processes, you can print pick carton labels. If you activate the Advanced bar code rule for GS1 formats, you can print them for item labels during the Search Inventory process. For setup instructions, see [System Rules for NetSuite WMS](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_156406918320.html).
    
-   [Mobile Printing and Weighing Scale Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0131112602.html) for Ship Central
    
    To print packing labels and documents in bulk, see [Printing Multiple Packing Labels and Documents](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0304105236.html).
    
    To set preferences that enable additional shipping labels and documents, see [Mobile Printing and Weighing Scale Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0131112602.html).
    
    If you enable preferences for return labels, refer to any of the following printing instructions
    
    -   [Generating and Printing Return Labels](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0812082039.html)
        
    -   [Generating Return Labels from an RMA](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0717031709.html)
        
    
    Ship Central also enables you to print shipping manifests after you process shipments, as described in this topic: [Generating and Printing Shipping Manifests](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0304032632.html).
    

SCM Mobile provides the same printing options and settings across its supported apps, as well as Mobile Printing from a NetSuite page. The default optional printing mode displays the Print button on a mobile page. It opens a popup window on which you can modify printing settings such as the printer and template you want to use. By default, it also provides you with the option to skip printing. If you customize Mobile Printing or change the default settings, your printing flow may vary. To set your printing mode and view the list of mobile processes that contain the Print button by default, see [Setting Up Automatic or Required Printing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161496236607.html). If you want to assign printer groups, see [Creating Printer Groups](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0826023922.html).

For PDF files or documents that you print using a regular printer, you can set up the option to specify the pages to print. To enable this setting, as well as assign default printers, standard or custom templates, and number of pages, see [Setting Up Printing Settings on Print Reports](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161496026645.html).

For printing instructions, see the following topics:

-   [Manually Printing Labels from Your Mobile Device](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158681903713.html)
    
-   [Reprinting Labels](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158681935610.html)
    

If you encounter setup or printing issues, see [Troubleshooting Mobile Printing](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_162499375334.html)
