For an Action field, such as the On Click Action or On Row Click Action, you can set up your own custom loading text that appears on the app. You can enter it on the Mobile - Action page that contains the **Loading Text** field. Your entry in this field replaces the default 'Loading…' message, which appears after you perform an action on the app.

For example, you can begin by accessing the Enter Bin button element that appears on the Enter Bin page within your custom PO Receiving process. To provide your loading text, you can click the On Click Action of this button to open the Mobile - Action page. On this page, in the **Loading Text** field, you can enter '**Submitting receiving details…**'.

Refer to the instructions in the following Mobile Customization or Mobile Configuration topic:

-   For custom mobile processes, see [Customizing Mobile Actions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0808031458.html).
    
-   For standard mobile processes, see [Cloning Standard Mobile Actions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0130020330.html).
    
    Unless you want to create your custom action, you can clone a standard mobile action first, and then assign your loading text to your copy. Either way, you can set up a copy or custom action for similar Action fields, such as the On Click Custom Action of a standard button element.
    
    To set up loading text for your copy or custom action that you want to add to a new page element, see the following topics:
    
    -   [Adding Action Buttons Through Mobile Configuration](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0303101529.html)
        
    -   [Configuring Mobile Table Elements](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0303103129.html)
        
    -   [Configuring Mobile Page Elements](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161549215472.html)
        

If you want to create a custom mobile action for a standard or custom process, you can assign it your own loading text. Make sure that the mobile action you want to set up doesn't belong to the following types: Restlet, Saved Search, Send to State, State, and URL Navigation.

For the Action Sequence type of mobile action, you can enter separate loading texts for each sub-action regardless of its type. To apply one loading text for all sub-actions, click the **Apply Loading Text to All Sub-Actions** box. It overrides any loading text that you set up for all sub-actions. It also displays the **Loading Text** field in which you can provide your own generic loading text. If you leave this field blank, the app applies the standard "**Loading...**" text for all sub-actions instead.
