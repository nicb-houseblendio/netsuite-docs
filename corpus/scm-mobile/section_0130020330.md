Through Mobile Configuration, you can create a copy of a standard mobile action, including its parameters. It includes the print report settings of standard Print actions. For mobile action types that support action sequences, it also copies the sub-actions.

You can clone only mobile actions that you set up for page elements. Actions that you set up only for mobile pages can't be cloned.

To copy an action, on the Mobile Configuration page, you can select the page and page element that contains the standard mobile action. Based on the page element associated with the action you want to copy, you can do the following:

Tip:

For instructions on accessing and navigating the Mobile Configuration page, see [Configuring Mobile Page Elements](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_161549215472.html).

-   Beside the Mobile Page Element field, in the **Standard Actions** field, select the action, and then click **Clone**. When you see the confirmation message, refresh the page.
    
-   For columns of Data Table elements, on the **Table Columns** subtab, select a column. In the **Standard Actions** field, select the action, and then click **Clone**. When you see the confirmation message, refresh the page.
    

Note:

The **Standard Actions** field is disabled for page elements that don't have any standard mobile action set up by default. This behavior may also happen if you set up a custom mobile action on the page element. The standard action is overridden and removed from the page element.

By default, your custom action has the same name but it starts with the date of cloning. Through Mobile Customization, you can assign it to action fields of a custom process such as an On Click Action or On Select Action. Through Mobile Configuration, standard page elements include fields for custom actions, like the On Click Custom Action or On Validate Custom Action. These action fields vary depending on the page element type.

To update your copy of the action, beside the action field, click the open icon to open the Mobile - Action page. On this page, you can make the following changes:

-   You can change default settings, like its name and label.
    
-   For specific action types, you can also add more input or output parameters to suit your mobile app requirements.
    
    For detailed instructions, see [Customizing Mobile Actions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0808031458.html).
    
-   If you want to provide your own loading text for certain action types, see [Setting Up Custom Loading Text for Mobile Actions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0730100731.html).
    

After you complete all your updates to your custom action, apply them to the app by clicking **Save and Update App** on the Mobile Configuration page.
