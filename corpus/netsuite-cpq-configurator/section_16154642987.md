You can assign an item creation record to a material, an additional item (formerly called a breakout item), or a product. When users submit the configuration, the new item will serve as a material, additional item, or the base item (formerly called the base generic product) in the configuration.

On the product interface, materials and additional items associated with an item creation record are highlighted in their corresponding sections in the Audit menu. Their description let users know that these items will be created when submitting the configuration.

To assign item creation records, edit a product at CPQ > Configurator > Product Maintenance. For more information, see the following help topics:

-   [Assigning Item Creation Records to Products](#subsect_0208023658)
    
-   [Assigning Item Creation Records to Additional Items](#subsect_0208023814)
    
-   [Assigning Item Creation Records to Materials](#subsect_0208023745)
    

## Assigning Item Creation Records to Products {#subsect_0208023658}

When you assign an item creation record to the product, the new item will become the base item (formerly called the base generic product). This approach is useful to create a unique main configured item with a new item name or number for each submitted configuration.

As the base item, the new item is displayed as the main configured item on the transaction after users submit the configuration. For more information about base items, see [Assigning Base Items to Products](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_0703012812.html).

To assign an item creation record to a product, edit a product record at CPQ > Configurator > Product Maintenance. Then, select an item creation record in the **Base Item (Item Creation Record)** field and save the product record.

## Assigning Item Creation Records to Additional Items {#subsect_0208023814}

If you want to automatically create an additional item (formerly called a breakout item) for a configuration, assign an item creation record to an additional item. When users submit the configuration, the new item will become an additional item and will be assigned its own line on the transaction after the main configured item. For more information about additional items, see [Including Additional Items Related to the Configurable Item](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_5155412660.html).

#### To assign an item creation record to an additional item:

1.  In NetSuite, go to CPQ > Configurator > Product Maintenance.
    
2.  Edit the product you want to modify.
    
3.  Go to the **Additional Items** subtab.
    
4.  Edit the additional item to which you want to assign the item creation record.
    
5.  In the **Item Creation Record** field, select an item creation record.
    
6.  Click **Save**.
    

## Assigning Item Creation Records to Materials {#subsect_0208023745}

If you want to automatically create a material for a configuration, assign the item creation record to the material. For more information about materials, see [Defining Materials for the Configurable Item](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_7143710234.html).

When users create a work order after submitting the configuration, the newly created material is added as a component under the **Items** subtab on work order. For more information about work orders for configured items, see [Creating Work Orders for Configured Items](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_8155327253.html).

#### To assign an item creation record to a material:

1.  In NetSuite, go to CPQ > Configurator > Product Maintenance.
    
2.  Edit the product you want to modify.
    
3.  Go to the **Materials** subtab.
    
4.  Edit the material to which you want to assign the item creation record.
    
5.  In the **Item Creation Record** field, select an item creation record.
    
6.  Click **Save**.
