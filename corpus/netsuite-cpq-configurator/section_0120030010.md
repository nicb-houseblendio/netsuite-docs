You can combine a standard subscription plan with configurable subscriptions. When working with a standard subscription plan, you'll manually create the subscription plan and any dependent records with SuiteBilling. You must also follow the specific requirements outlined in this help topic. These requirements ensure that the subscription plan is compatible with configurable subscriptions.

The following table sums up the steps to combine a standard subscription plan with configurable subscriptions.

| Step Number | Name | Description | This Help Topic | SuiteBilling Help Topic |
| --- | --- | --- | --- | --- |
| 1 | **Subscription plan member items** | Manually create the member items for the subscription plan. Alternatively, you can use existing items from your account. | [Creating Member Items for the Standard Subscription Plan](#subsect_0117012818) | [Creating Items for Subscription Plans](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1546981209.html) |
| 2 | **Subscription plan** | Create a standard subscription plan. Alternatively, you can use an existing subscription plan in your account. | [Creating the Standard Subscription Plan](#subsect_0117012912) | [Creating Subscription Plans](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1546981256.html) |
| 3 | **Price book** | Create a standard price book. | [Creating the Price Book and Price Plan for the Standard Subscription Plan](#subsect_0120021314) | [Creating Price Books](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1546981356.html) |
| 4 | **Price plan** | Create a standard price plan for each price book line. | [Creating the Price Book and Price Plan for the Standard Subscription Plan](#subsect_0120021314) | [Creating Price Plans](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1546981313.html) |
| 5 | **Link between the standard subscription plan and the product or an additional item** | Assign the standard subscription plan as the base item for the product. Alternatively, you can assign the subscription plan to an additional item. | [Assigning the Standard Subscription Plan to the Product or an Additional Item](#subsect_0120112914) | \- |

After working with the standard subscription plan, create the configurable subscription. For more information, see [Creating a Configurable Subscription](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0120024826.html).

## Creating Member Items for the Standard Subscription Plan {#subsect_0117012818}

Manually create the items that you'll select as member items for the subscription plan. These member items will be inherited by all configurable subscriptions created from that subscription plan. If no item should be inherited, create at least one placeholder item with the minimum information required to save it. Without member items, the subscription plan can't be saved. For more information, see [Creating Items for Subscription Plans](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1546981209.html).

## Creating the Standard Subscription Plan {#subsect_0117012912}

Manually create a standard subscription plan with SuiteBilling. Go to Lists > Subscriptions > Subscription Plans > New. Under the **Lines** subtab, add the required member items or the placeholder item. Complete all required fields and any additional fields as needed. For more information, see [Creating Subscription Plans](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1546981256.html).

If you use a placeholder line item, don't check the **Required** box. If you don't set this option, the placeholder line item won't be added to the transaction. However, it'll still be inherited by the subscription.

## Creating the Price Book and Price Plan for the Standard Subscription Plan {#subsect_0120021314}

After creating the subscription plan, manually create the price book for the subscription plan with SuiteBilling. Add a price plan for each price book line. During the setup, complete all required fields and any additional fields as needed. For more information, see [Creating Price Plans](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1546981313.html) and [Creating Price Books](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1546981356.html).

## Assigning the Standard Subscription Plan to the Product or an Additional Item {#subsect_0120112914}

After creating the standard subscription plan and all associated records, assign the subscription plan to the product as the base item. Use this option to add a single subscription plan to the transaction.

In NetSuite CPQ Configurator, edit a product record. In the **Base Item** field, select the standard subscription plan you previously created. For more information about base items, see [Assigning Base Items to Products](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_0703012812.html).

Alternatively, if you need to add multiple subscription plans to the transaction, create an additional item (formerly called a breakout item) for each subscription plan. On the additional item record, you can find the **Item** field. In this field, select the subscription plan you want to link the additional item. For more information about additional items, see [Including Additional Items Related to the Configurable Item](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_5155412660.html).
