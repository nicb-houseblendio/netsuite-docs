Note:

Use item creation records to create items required by the configuration. If you work with assembly items, item creation records can use existing material items in the bill of materials and the routing steps in the manufacturing routing. For more information, see [Creating Items Required by the Configuration](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_7115625340.html) and [Working with Assemblies on Item Creation Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_26154717376.html).

NetSuite CPQ Configurator can automatically create records required by the configuration using information from creation records. Creation records store the data for the potential new record to be created, such as the type, the key field, and the rule that determines whether it will be created. Using resolve expressions, you can include information from the product interface to set field values for the new record. For more information, see [Obtaining Answer Data with Resolve Expressions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_2144102668.html).

Creation records are also provided with subrecords to let you include sublists and sublist lines in the new record to be created. These subrecords are called RCR sublist and RCR sublist line (formerly called an RCR sublist component).

With creation records, you no longer need to manually create every record that may be required by the configuration. After submitting the configuration, NetSuite CPQ Configurator will create them for you based on users' choices during the configuration process. Using resolve expressions, NetSuite CPQ Configurator can create a different record from the same creation record every time a user submits a configuration.

Additionally, NetSuite CPQ Configurator reduces manual work by letting you copy information from existing records and set only the fields you want to change for the new record. You can also update existing records with new information from creation records.

During the configuration process, users can view the active creation records under the **Record Creation** option in the **Audit** menu on the product interface. Active creation records have a rule that matches the answers selected by users on the interface.

When users submit the configuration, NetSuite CPQ Configurator creates the record only if the rule of the creation record matches the answers selected by users on the interface. After submitting the configuration, users can monitor the records through a progress bar on the product user interface.

Note:

If your account includes more than 300 records of the type you want to create, new records are automatically added to the transaction fields. However, if your account has fewer than 300 records of the same type, you must enable an option to add the new records to transaction fields. Update the setup by going to CPQ > Configurator > Settings. Under the **Submit** subtab, check the **Add new resources to transaction fields** box. This option may be incompatible with custom scripts deployed on transactions.
