Products are organized into building blocks, such as questions, answers, and images. Many building blocks are rule-based, and they're activated under certain conditions. For more information about rules, see [Activating or Hiding Building Blocks with Rules](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_4124359628.html).

Create the user interface with the following building blocks:

-   **Questions and answers** - Gather and display information about the configurable item. For more information, see [Gathering Information with Questions and Answers](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1110827049.html).
    
-   **Validation messages** - Provide additional information or let users know about any inconsistencies or issues in the configuration. For more information, see [Displaying Validation Messages on the User Interface](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_2144413823.html).
    
-   **Images** - Help users visualize the final look and feel of the configurable item. For more information, see [Displaying Preview Images of the Configurable Item](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_4144942951.html).
    
-   **Tabs and groups** - Organize questions to guide users through the configuration process. [Organizing Questions into Tabs and Groups](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0155926195.html).
    

If you install NetSuite CPQ Manufacturing, you can use the following building blocks to create work orders:

-   **Materials** - Make up the configurable item. For more information, see [Defining Materials for the Configurable Item](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_7143710234.html).
    
-   **Routing steps** - Represent the tasks required to build the configurable item. [Defining Routing Steps to Build the Configurable Item](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_4143750867.html).
    

Other building blocks:

-   **Prices** - Create the final price for the configurable item. For more information, see [Calculating the Final Pricing for the Configurable Item](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_5155430879.html).
    
-   **Additional items** (formerly called breakout items) - Complete the main configurable item. For more information, see [Including Additional Items Related to the Configurable Item](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_5155412660.html).
    
-   **Tables** - Provide structured data for answers. For more information, see [Storing Answer Options in Tables](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_5102306887.html).
    
-   **Item creation records** - Contain information to create items required by the configuration. For more information, see [Creating Items Required by the Configuration](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_7115625340.html).
    
-   **Creation records** - Contain information to create records required by the configuration. For more information, see [Creating Records Required by the Configuration](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_2131623448.html).
    
-   **Mapping records** - Contain information to set transaction body and line fields based on configuration data. For more information, see [Setting Transaction Body and Line Fields Based on Configuration Data](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_8153202018.html).
    
-   **Actions** - Let you personalize products with scripts that can automate a repetitive tasks or perform advanced tasks. For more information, see [Customizing Products with Scripts Using Action Records and Functions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_4131356210.html).
    

After creating a building block instance, you can copy or delete it. By copying a building block instance, you can reuse information and save you manual work.

#### To copy a building block:

1.  On the building block subtab, click the name of the building block you want to copy.
    
2.  Select **Make a Copy** in the **Actions** dropdown menu.
    
3.  Edit the building block name, code, and sequence number if available.
    
4.  On the **Rules** or **Rule** subtab, update the rules to match the requirements for this new building block.
    
5.  Make changes to other fields and subtabs, and add new data as needed.
    
6.  Click **Save**.
    

If you no longer need a building block instance, you can delete it permanently. Edit the building block and select **Delete** under the **Actions** dropdown menu. Then, click **OK** in the popup window to confirm that you want to delete the building block.
