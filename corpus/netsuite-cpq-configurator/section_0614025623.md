Note:

If you don't update actions, they will no longer work with future versions of NetSuite CPQ Configurator.

Complete the following steps to implement client-side and server-side actions:

1.  In your sandbox account, verify that products and actions work as expected with the latest version of NetSuite CPQ Configurator. For more information, see [Verify the Compatibility with Client-Side and Server-Side Actions](#subsect_19155022615).
    
2.  Separate non-working actions into client-side and server-side. For more information, see [Separating Actions into Client-Side and Server-Side](#subsect_98155026513).
    
3.  If you use common actions, separate client-side and server-side functions into different common actions. For more information, see [Separating Client-Side and Server-Side Functions in Common Actions](#subsect_79155031407).
    
4.  Update any custom event handlers attached to user interface elements or any CPQ modules that directly call server-side functions. For more information, see [Calling Actions from Event Handlers Attached to User Interface Elements](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0614031816.html#subsect_19152919427) and [Calling Actions from CPQ Modules](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0614031816.html#subsect_39153057708).
    
5.  If products work as expected after implementing client-side and server-side actions, apply the changes to your production account with the latest version of NetSuite CPQ Configurator. For more information, see [Applying Changes to Production Accounts](#subsect_0618094105).
    

## Verify the Compatibility with Client-Side and Server-Side Actions {#subsect_19155022615}

In your sandbox account, verify that your implementations are compatible with client-side and server-side actions.

#### To verify the compatibility with the new action types:

1.  In your sandbox account, make a copy of the existing products:
    
    1.  Go to the options record at CPQ > Configurator > Settings.
        
    2.  Export the products to your computer.
        
    3.  Import the products back into your sandbox account.
        
    
    For more information about exporting and importing products, see [Exporting Products](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_0703031853.html) and [Importing Products](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_0203091006.html).
    
2.  On each product record, check the **Block database functions in client-side actions** box.
    
    This option prevents functions that read and write data to the database from working on the client.
    
3.  Make sure products and actions continue to work as expected. You should test the products using typical end-to-end scenarios in your business. These scenarios may include:
    
    1.  Launching the product from a transaction or a website.
        
    2.  Configuring all aspects of a product.
        
    3.  Saving the configured product to a transaction or the shopping cart.
        

## Separating Actions into Client-Side and Server-Side {#subsect_98155026513}

If products and actions don't work as expected with the latest version of NetSuite CPQ Configurator, separate actions into client-side and server-side. For more information about specific use cases, see [Code Examples](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0614031816.html).

#### To separate actions into client-side and server-side:

1.  In NetSuite, go to CPQ > Configurator > Product Maintenance.
    
2.  Edit a product record.
    
3.  Go to the **Actions** subtab:
    
    -   Click **Edit** to modify actions.
        
    -   Click **New CPQC Action** to create actions.
        
4.  Create or edit actions as required to obtain client-side or server side actions. For more information see [Customizing Products with Scripts Using Action Records and Functions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_4131356210.html) and [Using Client-Side and Server-Side Actions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_4131356210.html#subsect_0614023159).
    
5.  In client-side actions, store:
    
    -   Client-side functions.
        
        For more information, see [List of Functions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_37154604037.html).
        
    -   Asynchronous functions in JavaScript ES6.
        
6.  In server-side actions:
    
    -   Store server-side functions.
        
    -   Check the **Run on server** box.
        
7.  Decide how to establish the communication between client and server. For more information, see [Establishing Client-Server Communication](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_4131356210.html#subsect_0614024721).
    
8.  Rearrange sequence numbers so actions run in the correct order.
    
9.  Make sure products continue to work as expected.
    
10.  If products continue to work as expected, export the new product versions from the options record.
     
11.  On the options record, import the new production versions back into the old product versions using the **Target Product** field.
     
     This option preserves the product ID.
     
     For more information, see [Exporting Products](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_0703031853.html) and [Importing Products](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_0203091006.html).
     

## Separating Client-Side and Server-Side Functions in Common Actions {#subsect_79155031407}

Common actions inherit their type from the action to which they are linked. Common actions linked to server-side actions can only include server-side functions, while common actions linked to client-side actions can only include client-side functions. For more information about common actions, see [Sharing Code with Common Actions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_4131356210.html#subsect_0805111536).

#### To work with client-side and server side functions in common actions:

1.  Go to CPQ > Configurator > Common Actions.
    
    -   Click **Edit** next to a common action to modify it.
        
    -   Click **New CPQC Common Action** to create a common action.
        
2.  Separate client-side and server-side functions into separate common actions. Create new common actions when necessary. For more information, see [Code Examples](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0614031816.html).
    
3.  Decide how to establish the communication between client and server. For more information, see [Establishing Client-Server Communication](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_4131356210.html#subsect_0614024721).
    
4.  Modify the actions linked to common actions to be a server-side or a client-side action. For more information, see [Separating Actions into Client-Side and Server-Side](#subsect_98155026513).
    
5.  Create new client-side or server-side actions to link to the new common actions.
    

Common actions are automatically included in the product export.

## Applying Changes to Production Accounts {#subsect_0618094105}

If products work as expected after implementing client-side and server-side actions in your sandbox account, apply the changes to your production account using the latest version of NetSuite CPQ Configurator.

#### To apply the changes to your production account:

1.  In your sandbox account, go to the options record at CPQ > Configurator > Settings.
    
2.  Export the products with client-side and server-side actions to your computer.
    
3.  In your production account, go to the options record.
    
4.  Import new products into the original ones using the **Target Product** field. This option preserves the product ID.
    

For more information about exporting and importing products, see [Exporting Products](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_0703031853.html) and [Importing Products](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_0203091006.html).
