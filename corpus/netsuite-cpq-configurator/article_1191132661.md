Each product is provided with an interface where users can configure complex items based on their preferences. The following image shows a simplified product user interface with its main elements.

<a id="svg_1"></a>

                                                                                                                                                                                                                                                                                                                                                             

You can find the following elements on a product user interface:

1.  **Top bar** - Displays the subtotal (the price of a single configured item), the quantity of the main configured item, and the total price (the subtotal multiplied by the quantity).
    
    When users finish configuring the item, they can click one of the **Submit** buttons to add it to a transaction. Depending on which submit button they click, users can close the interface, start configuring another item, or duplicate the configuration.
    
2.  **Audit menu** - Contains information about every building block that has been activated from the user interface and included in the current configuration. This menu is updated every time users select options and features on the user interface.
    
    The Audit menu includes information about prices, materials, additional items, items to be created, records to be created, product images, routing steps, actions, and transaction fields to be set. The **Data** option provides information about every activated rule in the configuration. You can also search the rules by question and answer codes or by the answer value.
    
3.  **Favorites menu** - Lets you save a configuration to use later or define a default configuration that loads when users open a specific product. For more information, see [Creating Favorite And Default Configurations](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_5170907894.html).
    
4.  **Tab line** - Displays the tabs that organize questions in different panes. For more information, see [Organizing Questions into Tabs and Groups](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0155926195.html) and [Changing the Appearance of Tabs, Groups, and the Image Container](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_6145652659.html#subsect_0525042125).
    
5.  **Question space** - Displays the questions and answers that help you gather information about configurable items and guide the configuration process. For more information, see [Gathering Information with Questions and Answers](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1110827049.html) and [Organizing the Question Space](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_6145652659.html#subsect_0525033748).
    
6.  **Information bar** - Displays the configurable item image, the validation messages, and the summary. For more information about changing the information bar appearance, see [Changing the Information Bar Width and Position](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_6145652659.html#subsect_0526044636)
    
7.  **Configurable item image** - Shows the configurable item while it's being configured (composite image) or a gallery of images. For more information, see [Displaying Preview Images of the Configurable Item](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_4144942951.html).
    
8.  **Validation messages** - Provide information to guide users in the configuration process. This section is only displayed if there's at least one validation message. For more information, see [Displaying Validation Messages on the User Interface](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_2144413823.html).
    
9.  **Summary** - Provides detailed information about the price for a single main configured item. The subtotal in the summary is copied to the **Subtotal** field in the top bar. For more information, see [Calculating the Final Pricing for the Configurable Item](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_5155430879.html).
    

For information about changing the user interface look and feel, see [Changing the Product Interface Look and Feel](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_6145652659.html).
