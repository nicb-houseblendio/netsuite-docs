Users can access configurable items from eligible transactions. For more information about eligible transactions, see [Selecting Eligible Transactions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_9124208079.html#subsect_0515013646).

The basic workflow to configure items is the following:

1.  Open or create an eligible transaction.
    
2.  Click the **Configure** button.
    
3.  Select a configurable item on the Configurable Items page.
    
    This page provides an overview of all products that represent configurable items.
    
4.  Alternatively, click the arrow on the **Configure** button and select a specific configurable item or a category.
    
5.  Configure the item on the user interface.
    
6.  Click **Submit & Close** to add the configured item to the transaction. This button also closes the product interface.
    
7.  Save the transaction.
    

To modify a configured item, edit the transaction and click the **Edit Config** button on the configured line item. If you convert a transaction, the converted transaction will contain a copy of the original configurations. You'll be able to edit the configured items in one transaction without affecting the other.
