When users make a selection in a popup table or list (formerly called picklists and picklist dropboxes), they select an entire row from the product table. The input box field will display the value of the column you chose during the setup. You can map other values from the same row to other questions or answers. For more information about product tables, see [Storing Answer Options in Tables](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_5102306887.html).

Using mapping options, you can dynamically complete questions or answers based on user selections on popup tables or popup lists. This option eases the configuration process for users and ensures that questions and answers are filled in according to the established requirements.

To complete questions and answers dynamically by using popup table or list data, go to the Mapping section on the **Popup Tables & Lists** subtab of the answer record.

For more information, see the following help topics:

-   [Mapping Popup Table or List Selections to Questions or Answers](#subsect_0428121458)
    
-   [Mapping Popup Table Selections to QTables](#subsect_0428121553)
    
-   [Mapping QTable Popup List Selections to Questions or Answers](#subsect_0616013815)
    

## Mapping Popup Table or List Selections to Questions or Answers {#subsect_0428121458}

You can map product table values to questions and answers based on what users select in popup tables or lists. When setting up the mapping, specify:

-   The product table column that provides the values for the popup table or list.
    
-   The question or answer where you want map the additional values from the same row.
    

#### To map popup table or list selections to questions and answers:

1.  Edit the popup table or list answer.
    
2.  On the **Popup Tables & Lists** subtab, go to the Mapping section.
    
3.  Click the open icon next to the **Mapping to Questions/Answers** field.
    
4.  In the popup window, select the product table column from which you want to take the value.
    
5.  Select the question or answer where you want to map the value.
    
6.  To map multiple columns to question or answers, click **Add Mapping**. Repeat steps 4 - 5.
    
7.  To clear the mapped value and add a new one each time users select an option in the popup table or list, check the **Clear mapped questions/answers on reset** box.
    
8.  To save your mapping preferences, click **OK**.
    
9.  Click **Save**.
    

## Mapping Popup Table Selections to QTables {#subsect_0428121553}

You can map product table values to qTables based on user selections on popup tables (formerly called picklists).

Each user selection in the popup table fills a different cell in the selected qTable column -one cell after the other. To have user selections always appear in the same cell and delete the previously mapped value, check the **Clear qTable cell before mapping** box.

#### To map a popup table selection to a qTable:

1.  Edit the popup table answer.
    
2.  On the **Popup Tables & Lists** subtab, go to the Mapping section.
    
3.  In the **Target QTable** field, select the qTable where you want to map values.
    
4.  Click the open icon next to the **Mapping to QTable** field.
    
5.  In the popup window, select the product table column you want to map to the qTable.
    
6.  Select the qTable column in which you want to map the product table column.
    
7.  To add more columns, click **Add Column** and repeat steps 5 - 6.
    
8.  To save your preferences, click **Done** in the popup window.
    
9.  Click **Save**.
    

## Mapping QTable Popup List Selections to Questions or Answers {#subsect_0616013815}

You can map values from product table columns to questions or answers based on what users select on qTable popup lists.

#### To map a qTable popup list selection to questions and answers:

1.  On the **Answers** subtab, edit a qTable popup list.
    
2.  Click the **Popup Tables & Lists** subtab.
    
3.  In the Mapping section, click the open icon next to the **Mapping to Questions/Answers** field.
    
4.  In the popup window, select the product table column from which you want to take the values.
    
5.  Select the question or answer where you want to map the values.
    
6.  To add more columns, click **Add Mapping** and repeat steps 4 - 6.
    
7.  To save your preferences, click **Done**.
    
8.  Click **Save**.
