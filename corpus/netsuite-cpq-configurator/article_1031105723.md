If you use the Customer Center, ensure that users will be able to configure items from transactions when logged in to the Customer Center. To achieve this, assign all the required roles to the relevant NetSuite CPQ Configurator script deployments.

The following table sums up the required roles for each script deployment with their purpose.

Note:

If you use custom Customer Center roles, make sure you select the correct one. You can verify the role on the customer record by going to **System Information** > **Access** and review the **Role** field.

| Script Name | Script Deployment ID | Script Type | Role | Description |
| --- | --- | --- | --- | --- |
| CPQC-ST-Client | customdeploy\_cpqc\_st\_client | Client | Customer Center | Configure items from transactions when users are logged in to the Customer Center. |
| CPQC-CL-SalesOrder | Note: Add the role to the transaction deployments used in the Customer Center.
-   customdeploy\_cpqc\_cl\_creditmemo
-   customdeploy\_cpqc\_cl\_rtnauth
-   customdeploy\_cpqc\_cl\_quote
-   customdeploy\_cpqc\_cl\_invoice
-   customdeploy\_cpqc\_cl\_sales\_order

 | Client | Customer Center | Configure items from transactions when users are logged in to the Customer Center. |
| CPQC-UE-SalesOrder | Note: Add the role to the transaction deployments used in the Customer Center.

-   customdeploy\_cpqc\_ue\_creditmemo
-   customdeploy\_cpqc\_ue\_rtnauth
-   customdeploy\_cpqc\_ue\_quote
-   customdeploy\_cpqc\_ue\_invoice
-   customdeploy\_cpqc\_ue\_sales\_order

 | User Event | Customer Center | 

-   Configure items from transactions when users are logged in to the Customer Center.
-   Add newly created items to transactions when there are fewer than 300 items in the Customer Center.

 |

#### To add the required roles to each script deployment:

1.  Go to Customizations > Scripting > Script Deployments.
    
2.  In the **Type** field in the Filters section, select the script deployment type.
    
3.  Find and edit the required script deployment.
    
4.  Go to the **Audience** subtab.
    
5.  In the **External Roles** field, select the required roles.
    
6.  Click **Save**.
