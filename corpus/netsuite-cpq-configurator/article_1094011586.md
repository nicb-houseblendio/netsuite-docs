The `resetTab()` function (client-side) sets the SOLE/TAB and SOLE/SELECTED\_TAB predefined answers to `false`.

## Syntax {#subsect_33211611242}

Use this syntax for the `resetTab()` function:

            `resetTab();` 
          

## Return Value {#subsect_18211616594}

The `resetTab()` function returns `true` after completing the reset task.

## Parameters {#subsect_45211621890}

The `resetTab()` function doesn't require any parameters.
