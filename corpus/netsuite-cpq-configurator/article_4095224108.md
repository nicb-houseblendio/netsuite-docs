The `scopeRefresh()` function (client-side) updates the product interface, runs actions, and refreshes building blocks, such as questions, additional items, and materials.

## Syntax {#subsect_83214457561}

Use this syntax for the `scopeRefresh()` function:

            `scopeRefresh();` 
          

## Return Value {#subsect_98214504136}

The `scopeRefresh()` function returns `undefined`.

## Parameters {#subsect_72214509761}

The `scopeRefresh()` function doesn't require any parameters.
