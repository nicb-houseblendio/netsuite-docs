NetSuite CPQ Configurator includes updated labels for some elements you see on the user interface. Clearer and more informative labels provide a consistent user experience across the platform. Labels have been updated for the following elements:

-   records
    
    Note:
    
    Record labels no longer include hyphens.
    
-   fields
    
-   field options
    
-   sections
    
-   subtabs
    
-   columns
    

Note:

The changes only affect the labels you see on the user interface. The IDs of all records and fields remain unchanged. Scripts that reference those IDs will continue to run as expected.

The following table summarizes the updated labels for records.

| Previous Record Label | New Record Label |
| --- | --- |
| Composite-Image | Image |
| Component-Field-Mapping | Line Field Mapping |
| Breakout-Item | Additional Item |
| Category | Rule Category |
| Progress | Progress Popup |
| RCR Sublist Component | RCR Sublist Line |

Most records include a **Rule** or **Rules** section or subtab. Several fields and options in those sections or subtabs have been renamed. For more information, see [Updated Labels for Rule-Related Fields and Options](#subsect_0628032546).

Similarly, translation records and some of their fields have been renamed as well. For more information, see [Updated Labels for Translation Records and Fields](#subsect_0701125207).

Additionally, the **General** section has been renamed to **Primary Information** on all records. The **Notes** subtab has been renamed **System Notes** on all records.

Some fields on the product user interface have also been renamed. For more information, see [Updated Labels on the Product User Interface](#subsect_0703124256).

NetSuite CPQ Configurator creates fields on some external records. Some of those fields have been renamed. For more information, see [Updated Labels on External Records](#subsect_0709020056).
