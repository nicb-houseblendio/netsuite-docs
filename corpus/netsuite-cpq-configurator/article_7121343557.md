Your account lets you create all kinds of items, such as inventory items, non-inventory items, and assemblies. To work with configurable items, you can use NetSuite CPQ Configurator.

NetSuite CPQ Configurator lets users configure complex items according to your business logic by selecting features and characteristics from a predefined set of options. After configuring the items, users can add them to transactions.

With NetSuite CPQ Configurator, you can:

-   Define a visual space where users can configure complex items with thousands of possible combinations.
    
-   Gather information about users' preferences with questions and answers on the product interface.
    
-   Guide the configuration process by providing real-time feedback on users' choices with validation messages.
    
-   Work with a complex price structure, which calculates and updates the final price for the main configurable item in real time based on users' choices.
    
-   Display a dynamic 2D visual preview of the item while it is being configured.
    
-   Automatically create items and records required by the configuration.
    
-   Automatically set body and line field values for transactions with configured items.
    
-   Save frequently used configurations and define a default configuration that automatically loads predefined options and features.
    
-   Add accessories for the configured item to transactions.
    
-   Use the interactive generative AI tool, NetSuite CPQ AI Assistant, that help users work with configurable items by suggesting valid options, clarifying configuration constraints, and prefilling answers based on user intent. Configure where and when the assistant appears, and ensure AI-generated content meets quality standards with tools like Text Enhance. For details, see [NetSuite CPQ AI Assistant](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_9094751090.html).
    

If you install NetSuite CPQ Manufacturing, you can create work orders based on materials and routing steps from NetSuite CPQ Configurator. For more information, [Creating Work Orders for Configured Items](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_8155327253.html).

After installing NetSuite CPQ Configurator, set up basic and additional options. For more information, see [NetSuite CPQ Configurator Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_9124208079.html).

After setting up NetSuite CPQ Configurator, you can create products. A product is the main working unit in this SuiteApp and represents the configurable item. Each product is made up of several building blocks activated by rules. For more information, see [NetSuite CPQ Configurator Products](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_6124716984.html) and [Activating or Hiding Building Blocks with Rules](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_4124359628.html).

When products are ready, users can configure the associated complex items from transactions. For more information, see [Configuring Items From Transactions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_5085131325.html).
