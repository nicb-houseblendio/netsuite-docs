As the last step for configurable subscriptions, you must ensure that the subscription will be associated with the subscription plan line on the transaction. To associate the subscription with the subscription plan line, you need to link the subscription to the base item (or the additional item) corresponding to the subscription plan using a mapping record. To link the two:

1.  Create a line field mapping record (formerly called component field mapping record). For more information about mapping records, see [Setting Transaction Body and Line Fields Based on Configuration Data](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_8153202018.html).
    
2.  Link the mapping record to the base item (or the additional item) tied to the subscription plan.
    

On the transaction, the mapping record will set the **Subscription** line field for the subscription plan by adding the internal ID of the subscription.

#### To associate a subscription with the subscription plan line:

1.  Edit a product record.
    
2.  Go to the **Data Mapping** subtab and then to the **Line Field Mapping** subtab.
    
3.  Click **New CPQC Line Field Mapping**.
    
4.  Complete all required fields and any additional fields as needed.
    
5.  Go to the **Transaction Line Fields** subtab.
    
6.  In the **Field Name** column, add the **Subscription** field.
    
7.  In the **Value** column, specify the internal ID of the created subscription record. Enter the answer where you saved the value as a resolve expression {Q/A}.
    
8.  Click **Save**.
    
9.  Associate the mapping record with the base item (or the additional item) linked to the subscription plan.
    
    1.  Go to the product record for the base item (or the additional item record).
        
    2.  In the **Line Field Mapping Records** field, select the mapping record you have created.
        
    3.  Click **Save**.
        

By completing this step, you have finished the setup for configurable subscriptions.
