With NetSuite CPQ Configurator, you can gather and display information about the configurable item with questions and answers and guide users through the configuration process. Questions represent the item features, aspects, or characteristics that require user input. For each question, answers show the available options to users and let them express their preferences.

The question types available are:

-   **Checkbox** - Lets users select multiple answers from a predefined list by checking the box next to each answer. This question type is useful when users can express multiple preferences from a limited set of answers.
    
    The following image shows a checkbox question:
    
    ![A checkbox question for NetSuite CPQ Configurator with two boxes checked.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteCPQ/Configurator/CPQ_CheckboxQuestion.png)
    
    For more information, see [Checkbox and Radio Button Questions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0726121124.html#subsect_0726121219).
    
-   **Radio button** - Lets users select a single answer from a predefined list of mutually exclusive options by choosing the radio button next to each answer. This question type is helpful when only one option or feature is available within a limited answer list.
    
    The following image shows a radio button question:
    
    ![A radio button question for NetSuite CPQ Configurator.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteCPQ/Configurator/CPQ_RadioButtonQuestion.png)
    
    For more information, see [Checkbox and Radio Button Questions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0726121124.html#subsect_0726121219).
    
-   **Dropdown list** - Lets users select a single answer from a predefined list, which appears when they click the arrow. When there is a long list of answers, you can choose this question type to save space on the user interface. For more information, see [Dropdown List Questions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0726121124.html#subsect_0726121327).
    
    The following image shows a dropdown list question:
    
    ![A dropdown list question for NetSuite CPQ Configurator.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteCPQ/Configurator/CPQ_DropdownListQuestion.png)
-   **Input box** - Lets you create various types of fields where users can enter text, such as text fields or text boxes, or select options from a popup table or a popup list (formerly called a picklist and a picklist dropbox). This question type is useful to let users freely express their preferences, give feedback, or choose an item feature from an extensive lists of combined options stored in product tables. See [Storing Answer Options in Tables](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_5102306887.html).
    
    The following image shows an input box question with its answer types:
    
    ![An input box question for NetSuite CPQ Configurator with all its answer types.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteCPQ/Configurator/CPQ_InputBoxQuestionWithAnswers.png)
    
    For more information, see [Input Box Questions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0726121124.html#subsect_0727094151).
    
-   **QTable** - Lets you create a question in the form of a table where columns represent the answers. Columns can store varied answer types, such as text fields, checkboxes, and dropdown lists. This question type is useful for gathering information about various aspects of the configurable item at the same time or to add a long list of additional items to transactions.
    
    The following image shows a qTable question with columns corresponding to its different answer types:
    
    ![A qTable question type for NetSuite CPQ Configurator.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteCPQ/Configurator/CPQ_QTableQuestion.png)
    
    For more information, see [QTable Questions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0726121124.html#subsect_0727101113).
    
-   **Tile** - Lets users select one or multiple answers from a collection of labeled images. To select multiple answers, users can hold the Ctrl key. You can use this question type when the item options or features have a relevant visual element. For example, tiles are useful when choosing colors or textures.
    
    The following image shows a tile question type:
    
    ![A tile question type for NetSuite CPQ Configurator](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteCPQ/Configurator/CPQ_TilesQuestion.png)
    
    For more information, see [Tile and Tile Dropdown List Questions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0726121124.html#subsect_0726121411).
    
-   **Tile dropdown list** - Lets users select one or multiple answers from a dropdown list with labeled images. To select multiple answers, users can hold the Ctrl key. When you have a long list of visual elements, this question type is helpful to save space on the user interface.
    
    The following image shows a tile dropdown list question:
    
    ![A tile dropdown list question for NetSuite CPQ Configurator.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteCPQ/Configurator/CPQ_TileDropdownListQuestion.png)
    
    For more information, see [Tile and Tile Dropdown List Questions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0726121124.html#subsect_0726121411).
    
-   **Custom HTML** - Lets users view the custom content that you created with HTML code. For example, you can add images or links.
    
    The following image shows an inline HTML question:
    
    ![A custom HTML question for NetSuite CPQ Configurator.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteCPQ/Configurator/CPQ_CustomHTMLQuestion.png)
    
    For more information, see [Custom HTML Questions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0726121124.html#subsect_0726121446)
    
-   **Attachment** - Lets users attach files to the configuration. You can let them add a single file or one file for each additional item. Files are uploaded to the File Cabinet. For more information, see [Attachment Questions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0726121124.html#subsect_1204080021).
    
    ![An attachment question for NetSuite CPQ Configurator.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/NetSuiteCPQ/Configurator/CPQ_AttachmentQuestion.png)

Depending on the question type you create, the answer options vary accordingly. For example, you can add a text field to a checkbox answer or show placeholder text in an input box answer. After saving a question or an answer, they're automatically displayed on the product user interface.
