Important:

During the export process, NetSuite CPQ bundles and their records are locked, and you can't use the bundles or apply changes.

After updating the bundle to the latest version and installing the migration bundle for NetSuite CPQ Configurator, you can export bundle data from NetSuite CPQ Configurator and Guided Selling bundles. You must export data separately for each bundle.

If you want to make changes after the export completes, unlock the bundle by clicking **Unlock** in the Migration popup window. However, you must run the export process again to update the backup data.

If you run into issues during the export process, you can repeat some or all of the export steps. For more information, see [Solving Possible Export Issues](#subsect_1021014633). To access the export log files, see [Accessing the Complete Export Log Files](#subsect_0729063242).

#### To export data from the bundle:

1.  Access the options record of the bundle:
    
    -   To export data from NetSuite CPQ Configurator, go to Configurator > System > Global Settings.
        
    -   To export data from NetSuite CPQ Guided Selling, go to Guided Selling > System > Global Settings.
        
2.  Click the **Global Export** button.
    
3.  In the Migration popup window, click **Start**.
    
4.  Verify that the export progress is marked as completed.
    

After exporting bundle data, uninstall the latest bundle version. For more information, see [Uninstalling the Latest Bundle Version](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_0206020315.html).

## Solving Possible Export Issues {#subsect_1021014633}

Issues may arise when exporting bundle data. If some export steps don't finish or fail, repeat these steps by clicking the **Restart** button on the export window.

If no bundle data is found or some export steps still have issues, click the **Restart All** button to run the export process again.

If issues continue after repeating the entire export process:

1.  Download the issue reports from the export window.
    
2.  Open a NetSuite support case.
    
3.  Include the issue reports in the support case.
    

## Accessing the Complete Export Log Files {#subsect_0729063242}

If you run into issues when downloading the issue reports, you can get the complete export log files from the File Cabinet.

The following table lists the main export log files for each bundle or set of features.

| Bundle/Set of Features | File Name |
| --- | --- |
| NetSuite CPQ Configurator | \_BACKUP:exportRes\_configurator.json |
| NetSuite CPQ Proposal Generator | \_BACKUP:exportRes\_propgen.json |
| NetSuite CPQ Guided Selling | \_BACKUP:exportRes\_gs.json |

#### To access the log files:

1.  Go to Documents > Files > File Cabinet.
    
2.  Click the following folders:
    
    1.  **SuiteScripts**
        
    2.  **CPQ**
        
    3.  **ProjectsBackup**
        
3.  Select one of the following folders:
    
    -   **Configurator**
        
    -   **GS**
        
    
    Note:
    
    You can find the log file for Proposal Generator in the **Configurator** folder.
    
4.  Select the **Migration Data** folder.
    
5.  Click **Download** next to the required log file.
    
6.  Download all the additional log files from the **ErrorsData** folder.
