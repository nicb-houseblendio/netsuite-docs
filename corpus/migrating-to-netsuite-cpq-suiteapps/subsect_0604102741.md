Important:

If you don't install the migration bundle, the NetSuite CPQ Configurator bundle can't be uninstalled. Skip this step for NetSuite CPQ Guided Selling.

After updating the NetSuite CPQ Configurator bundle to the latest version, install the **NSCPQ Bundle Migration** (Bundle ID: 596110) to preserve its configuration records and transaction field data. This migration bundle is public and managed.

Warning:

To edit configured items added to transactions by the NetSuite CPQ Configurator bundle, you must keep the migration bundle installed in your account after the migration. If you uninstall the migration bundle, transaction field data and configuration data from the NetSuite CPQ Configurator bundle will be permanently deleted.

#### To install the migration bundle:

1.  Go to Customization > SuiteBundler > Search & Install Bundles.
    
2.  In the **Keywords** field, enter **NSCPQ Bundle Migration**.
    
3.  Under the **Name** column, click **NSCPQ Bundle Migration**.
    
4.  On the Bundle Details page, click **Install**.
    

For more information about installing a bundle, see [Installing a Bundle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3395142.html).

After installing the migration bundle for NetSuite CPQ Configurator, you can export bundle data. For more information, see [Exporting Bundle Data](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_66180229818.html).
