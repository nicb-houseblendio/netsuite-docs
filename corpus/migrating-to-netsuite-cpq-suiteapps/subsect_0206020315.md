Warning:

Before uninstalling a NetSuite CPQ bundle, update the bundle to the latest version and export bundle data. To migrate to the NetSuite CPQ Configurator SuiteApp, also install the migration bundle before exporting data. If you uninstall an old bundle version, all associated information is permanently deleted from your account. No backup data is created.

When the bundle backup is ready, you can uninstall the latest bundle version of NetSuite CPQ Configurator or Guided Selling from your account. You won't be able to uninstall the bundles until complete data backup is available.

#### To uninstall the bundle:

1.  Go to Customization > SuiteBundler > Search & Install Bundles > List.
    
2.  Search for the NetSuite CPQ bundle you want to uninstall.
    
3.  In the **Action** dropdown menu, click **Uninstall**.
    
4.  In the confirmation popup window, click **OK**.
    

For more information about uninstalling a bundle, see [Uninstalling a Bundle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3400972.html). If you want to permanently delete the bundle and its data because you no longer need them, see [Uninstalling the Bundle without Backup Data](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1018034636.html).

After uninstalling the latest bundle version, install the SuiteApps and import bundle data. For more information, see [Installing the SuiteApp and Importing Bundle Data](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_84183004875.html).
