Warning:

If you uninstall an old version of a NetSuite CPQ Configurator or Guided Selling bundle, any related information-such as custom records, forms, and scripts-is deleted permanently from your account. No backup data is created.

The first step in the migration process is to update the NetSuite CPQ Configurator and Guided Selling bundles to the latest version. After the update, the bundles can create backup data in the export step of the migration.

Only the latest version automatically starts the export process if you try to uninstall the NetSuite CPQ Configurator or Guided Selling bundles without backup data. You can still verify the export progress under each bundle menu at System > Global Settings by clicking the **Global Export** button. You'll receive emails when the export starts and finishes.

Note:

If you have a managed bundle version installed in your account, request the latest bundle version to be pushed to your production account.

#### To update an unmanaged bundle to the latest version: {#procedure_0130052326}

1.  Go to Customization > SuiteBundler > Search & Install Bundles > Lists.
    
2.  Search for the NetSuite CPQ bundle you want to update.
    
3.  Verify if there's an asterisk in the **Version** column. The asterisk means a new version is available.
    
4.  If a new version is available, click **Update** in the **Action** dropdown menu.
    

After updating the NetSuite CPQ Configuator bundle to the latest version, install the dedicated migration bundle. For more information, see [Installing the Migration Bundle for NetSuite CPQ Configurator](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_0604102741.html). For Guided Selling, move directly to the export step. For more information, see [Exporting Bundle Data](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_66180229818.html).
