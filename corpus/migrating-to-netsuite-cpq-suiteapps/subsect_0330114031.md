Note:

Depending on the amount of data, the migration process may take a while. NetSuite CPQ bundles and SuiteApps aren't available during this time. You should plan the migration process outside your business hours when possible.

Migrating the NetSuite CPQ Configurator and Guided Selling bundles to SuiteApps requires a specific process. You must repeat the migration process for each bundle separately. For NetSuite CPQ Configurator, you'll also have to install a migration bundle.

Moving the SuiteCommerce extension from bundle to SuiteApp requires a different process. For more information, see [Moving the SuiteCommerce Extension from Bundle to SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_0330114432.html).

To migrate the NetSuite CPQ Configurator and Guided Selling bundles to SuiteApps, follow these steps:

Note:

Complete the steps in your sandbox account first. If the migration process is successful, migrate the bundles to SuiteApps in your production account.

1.  Update the bundle to the latest version. For more information, see [Updating to the Latest Bundle Version](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_67175151134.html).
    
2.  Install the migration bundle for NetSuite CPQ Configurator. For more information, see [Installing the Migration Bundle for NetSuite CPQ Configurator](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_0604102741.html).
    
    Note:
    
    This step is only required for the NetSuite CPQ Configurator bundle.
    
3.  Export data from the bundle. For more information, see [Exporting Bundle Data](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_66180229818.html).
    
4.  Uninstall the bundle. For more information, see [Uninstalling the Latest Bundle Version](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_0206020315.html).
    
5.  Install the SuiteApp and import bundle data. For more information, see [Installing the SuiteApp and Importing Bundle Data](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_84183004875.html).
    

If you run into issues when exporting or importing data, file a support case and include the issue reports or the log files. For more information, see [Solving Possible Export Issues](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_66180229818.html#subsect_1021014633) and [Accessing the Import Log Files](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_84183004875.html#subsect_24184434493).

After importing data into the NetSuite CPQ Configurator SuiteApp, you may need to complete or update product information. For more information, see [Fixing Possible Import Issues on NetSuite CPQ Configurator Records](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_84183004875.html#subsect_0330104744).

After installing the NetSuite CPQ Configurator SuiteApp, you can continue to work as usual with transactions that include items configured with the NetSuite CPQ Configurator bundle. For more information, see [Working with Existing Configured Items on Transactions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_84183004875.html#subsect_0330104824).

If you no longer need data from NetSuite CPQ bundles, you can uninstall them without following the migration process. For more information, see [Uninstalling the Bundle without Backup Data](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_1018034636.html).
