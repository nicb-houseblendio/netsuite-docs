Warning:

If you uninstall a NetSuite CPQ bundle without creating backup data, all associated information will be permanently deleted from your account. Only uninstall bundles without backup data if you no longer need their data.

Some bundle implementations on sandbox accounts may include testing data you no longer need. In such cases, you can uninstall the NetSuite CPQ bundle without creating backup data. Then, you can install the NetSuite CPQ SuiteApps. To keep bundle data, see [Exporting Bundle Data](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/subsect_66180229818.html).

#### To uninstall the bundle without backup data:

1.  Access the options record of the bundle:
    
    -   In NetSuite CPQ Configurator, go to Configurator > System > Global Settings.
        
    -   In NetSuite CPQ Guided Selling, go to Guided Selling > System > Global Settings.
        
2.  Go to the **Info** subtab.
    
3.  Check the **Allow uninstalling bundle without records migration** box.
    
    Warning:
    
    If you enable this option, the NetSuite CPQ bundle data will be permanently deleted without any backup data.
    
4.  Click **Save**.
    
5.  Follow the standard steps to uninstall a bundle. For more information, see [Uninstalling a Bundle](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3400972.html).
