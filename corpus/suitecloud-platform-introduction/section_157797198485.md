The REST API Browser is a separate browser that provides a visual overview of the REST web services Record API. The data in the REST API Browser is based on OpenAPI 3.0 metadata.

The REST API Browser provides the available operations, field names, field types, and the structure of possible HTTP responses. It also provides a summary of all records, sublists, schema definitions, and other objects. For more information, see [The REST API Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157373386674.html).

**[Go to the REST API Browser](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2026.1/index.html)**.
