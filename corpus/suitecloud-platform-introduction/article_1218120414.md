Find detailed schema metadata for scripting and integration.

## Record and Schema Browsers {#subsect_164806348428}

With every release, metadata for records, fields, sublists, search joins, and other data is collected in a browser. This metadata is available through SuiteScript and SOAP web services. The browser is a single tool with separate tabs, and each tab gives you access to a different schema:

-   The Records Browser tab provides the information you need to query data sources for the N/query module in SuiteScript.
    
-   The Schema Browser tab provides the information you need to query data sources for the search module in SOAP web services.
    

Note:

The Connect Browser is no longer updated and shows only tables and columns available up to 2021.2.

You can access the browser from the Help Center records pages or by using the following direct link: [SuiteScript Records Browser](https://system.netsuite.com/help/helpcenter/en_US/srbrowser/Browser2026_1/script/index.html).

The browser tool is separate from the Help Center, and you don't need to be logged in to NetSuite to use it. A new version of the browser tool is released twice a year with each NetSuite version.

For details about the various SuiteCloud record reference tools available, see the following topics.

## SuiteScript Records Browser {#section_1527577879}

The SuiteScript Records Browser shows which records are generally available for you to use in SuiteScript. It includes a reference page for every supported record.

Use the SuiteScript Records Browser with the SuiteScript reference guide. In the Records Browser, you'll find all the fields, sublists, and search filter fields for each record. The Records Browser also provides field-level help for many fields and shows the IDs you need to reference NetSuite records, fields, sublists, search filters, permissions, features, and more, in SuiteScript.

Only the Records Browser for the most recent NetSuite release is supported. Older versions may still be available, but they're not supported. For more information, see [Working with the SuiteScript Records Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N3169369.html).

**[Go to the SuiteScript Records Browser](https://system.netsuite.com/help/helpcenter/en_US/srbrowser/Browser2026_1/script/index.html)**.

## SuiteTalk SOAP Schema Browser {#section_1527577939}

The SOAP Schema Browser gives you a summary of all records you can use in SOAP web services. You can also find details of sublists, search objects, enumerations, and data types such as RecordRef and BaseRef. Each object is shown as a series of tables, both for ease of browsing and to provide more details than the WSDL.

The SOAP Schema Browser isn't maintained after it's released. Older versions of the browser are still available, but they are not updated. For more information, see [SOAP Schema Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3639052.html).

**[Go to the SOAP Schema Browser](https://system.netsuite.com/help/helpcenter/en_US/srbrowser/Browser2025.2/schema/index.html)**.

## SuiteAnalytics Connect Browser {#section_1527577905}

Important:

As of 2026.1, the NetSuite.com data source will be removed, and you must use the NetSuite2.com data source to access the Connect Service.

For more information, see [NetSuite2.com Data Source](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_163465025391.html).

The Connect Browser is no longer updated and shows only tables and columns that were available up to 2021.2. Older versions may still be accessible, but the data may not be accurate.

For more information, see _Working with the Connect Browser_.

**[Go to the SuiteAnalytics Connect Browser](https://system.netsuite.com/help/helpcenter/en_US/srbrowser/Browser2026_1/odbc/index.html)**
