The Records Catalog provides information about the record types, fields, and relationships for a specific NetSuite channel. The Records Catalog includes the custom records, forms, and fields in your account, displaying data based on the features you have enabled. For more information, see [SuiteCloud Development Framework](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4702622163.html).

Access the Records Catalog in NetSuite from _Setup > Records Catalog_.

For each record type, you can view the SuiteScript and REST Query API channels. The SuiteScript and REST Query API includes data for creating constructed queries and SuiteQL queries with the SuiteScript [N/query Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510275060.html), and for working with the [Workbook API](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_159414531069.html). You'll also find fields and joins available for SuiteScript and REST Query API. For more information about the SuiteScript and REST Query API, see [SuiteScript 2.1 Analytic APIs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_159524581218.html).
