## SuiteApp Control Center {#subsect_157959631630}

Use the SuiteApp Control Center to define and manage your SuiteApp distribution process. You can upload SuiteApp projects to the SuiteApp Control Center and distribute them as SuiteApp versions to the SuiteApp Marketplace. Your users can install SuiteApps from the SuiteApp Marketplace and perform manual upgrades for unmanaged SuiteApps or receive upgrades for managed SuiteApps.

For more information about getting started with SuiteApp Control Center, see [Getting Started with SuiteApp Control Center](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1525985206.html).

## SuiteApp Marketplace {#subsect_157924873394}

The SuiteApp Marketplace is where you can find and install SuiteApps created with the SuiteCloud Development Framework (SDF) or SuiteBundler. SuiteApps can include customizations and configuration settings that are useful for your organization. In the SuiteApp Marketplace, you can install and upgrade SuiteApps as well as view the status of your SuiteApps.

You can view all public and shared SuiteApps in the SuiteApp Marketplace, available at [SuiteApp.com](https://suiteapp.com). Each SuiteApp is represented by a tile with its name, publisher, and first release date. You can sort the tiles by name, publisher, or latest release date.

To learn about the information that is available for each SuiteApp, see [Viewing SuiteApps in the SuiteApp Marketplace](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1539797977.html).
