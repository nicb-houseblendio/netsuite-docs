Use Advanced PDF/HTM Templates to customize printed and emailed transactions. Associate advanced templates with custom transaction forms to format print and email versions of transactions.

Each standard PDF/HTML template has specific fields and sublists available. The Advanced Template Reference provides information about which printable fields and sublists are available for each template, including name, type, and ID. For more information, see [Advanced PDF/HTML Templates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4453550706.html).

**Go to the [Advanced Templates Reference](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/SBADVTemplates.html).**
