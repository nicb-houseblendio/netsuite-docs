SuiteCloud Development Framework (SDF) lets you create XML representations of NetSuite objects, such as custom record types, custom record instances, workflows, and other customizations, for both internal use and for commercial distribution.

With SDF, you can define each SDF-supported NetSuite object in an XML file. The SDF XML Reference Guide describes how to structure these XML files and what fields are available. It includes information about feature requirements and fields, such as their structure, properties, possible values, default values, attributes, and other details.

For more information, see [Customizations Supported by SuiteCloud Development Framework](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4706653920.html) and [SuiteScript Development Framework XML Reference](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1527577957.html).

**Go to the [SuiteCloud Development Framework XML Reference](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/SDFxml.html)**.
