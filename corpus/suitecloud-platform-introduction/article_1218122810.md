The analytics data source, NetSuite2.com, lets you analyze your NetSuite data with SuiteQL queries. SuiteQL lets you run complex queries using SuiteAnalytics Connect, SuiteScript, and SuiteTalk REST web services. For more information about the analytics data source NetSuite2.com, see [Analytics Data Source Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1543418336.html).
