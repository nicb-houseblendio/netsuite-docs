When you need to find information about your business, you have several tools available.

## Workbook {#subsect_158093096175}

Use SuiteAnalytics Workbook to create customized workbooks that combine datasets, tables, pivot tables, and charts in a single tool. With the SuiteAnalytics Workbook user interface, users with limited knowledge of record schemas and query language can create complex workbooks and datasets using drag-and-drop editing. Workbook provides multiple options for formatting, filtering, and visualizing your data. For more information, see [SuiteAnalytics Workbook Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1503949328.html).

## NetSuite Analytics Warehouse {#subsect_36114052743}

With NetSuite Analytics Warehouse, you can go beyond what SuiteAnalytics Workbook offers and analyze your NetSuite data in new ways. Analytics Warehouse lets you analyze historical data from multiple sources to identify opportunities for improving your business. You can blend your NetSuite data with data from other sources and analyze it using a wide range of visualizations. For more information, see [NetSuite Analytics Warehouse Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_159309442275.html).

## Dashboards {#subsect_158093121793}

You can create custom dashboards to help your NetSuite users work efficiently. A dashboard is a visual workspace with tabbed pages that display real-time data. The information shown is relevant to the role of the person viewing the page. Dashboard content is displayed in different portlets, or dynamic data display windows. Some portlets provide direct access to raw data. Other portlets display critical business metrics, such as key performance indicators (KPIs), performance scorecards, trend graphs, chart-based workbooks, and report snapshots. For more information, see [Dashboards Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N576403.html).

## Searches {#subsect_158093066800}

To find information in NetSuite, you can use a simple search to find instances of specific record types. Then, you can filter the results by one or more field values.

If you or other users need to run the same search often, create a saved search. Saved searches support advanced search features such as formulas containing SQL expressions and joins to other records. You can search in the UI or create searches using SuiteScript or REST web services.

For more information about performing searches, see the following topics:

-   [Search Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N635877.html)
    
-   [Defining a Saved Search](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N676039.html)
    
-   [N/query Module](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1510275060.html) for SuiteScript 2.1
    

## Reports {#subsect_158093080463}

NetSuite includes a variety of reporting capabilities to retrieve, present, and analyze real-time business results. You can run standard reports, or modify them by setting per-user preferences, selecting per-report viewing options, or defining custom reports in the Report Builder. For more information, see [Reporting Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N698474.html) and [Working with Report Results](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N717676.html).

## Connect {#subsect_158093071530}

If you want to use a third-party reporting tool, the SuiteAnalytics Connect Service provides a read-only method to access NetSuite data. Oracle NetSuite offers drivers so you can archive, analyze, and report on NetSuite data using a third-party tool or a custom-built application. For more information, see [SuiteAnalytics Connect](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_3963845427.html).
