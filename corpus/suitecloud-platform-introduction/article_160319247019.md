The Application Performance Management (APM) SuiteApp lets you monitor and troubleshoot the performance of your NetSuite customizations and business-critical operations with performance dashboards. APM includes dashboards for page time summaries, SuiteScript analysis, SuiteCloud processor monitoring, web services analysis, and search performance.

Using APM, you can analyze the performance of the following SuiteCloud platform areas:

| SuiteCloud Platform Area | APM Tool | Description |
| --- | --- | --- |
| Scripts | SuiteScript Analysis | See the history and performance of scripts. For more information, see [Analyzing Scripts](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4299098804.html). |
| Page Time Summary | Measures the performance of user event scripts, client scripts, and workflows, so you can identify customizations that take too long to run. For more information, see [Monitoring Performance with the Page Time Summary](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4299098714.html). |
| SuiteCloud Processors (map/reduce and scheduled scripts) | SuiteCloud Processor Monitor | View and analyze the performance of your map/reduce and scheduled script jobs in SuiteCloud Processors. For more information, see [Monitoring SuiteCloud Processors Performance](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1526955932.html). |
| Web Services | SOAP Web Services Analysis | Monitor the performance of top SOAP web services operations and record processing. For more information, see [Analyzing Web Services Performance](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1504676182.html). |
| REST Web Services Analysis | Monitor the performance of REST web services operations. For more information, see [Analyzing Web Services Performance](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1504676182.html). |
| Web Services and RESTlet Concurrency | Concurrency Monitor | Monitor peak levels, errors, and concurrency data for web services and RESTlet integrations in your account. For more information, see [Monitoring Web Services and RESTlet Concurrency](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1526956019.html). |
| Searches | Search Performance Analysis | Monitor how multiple saved searches perform and identify potential issues. For more information, see [Analyzing Search Performance](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1508294507.html). |

For more information, see [Application Performance Management (APM)](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4283522055.html).
