Note:

This topic applies to System Notes only. For information about System Notes v2, see [System Notes v2 Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_158108495822.html).

Every record in NetSuite has a System Notes subtab that tracks any changes made to the record. A system note logs information such as the date of the change, the type of change, and the old and new values. For more information, see [System Notes Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_158644279544.html).

A system note also captures the execution context in which a change was made. Examining this context can help you troubleshoot unexpected changes. The following screenshot shows the System Notes subtab on a customer record, with the Context column listing the execution context for each change.
