Adapt forms, fields, workflows, templates, and record types in the UI to fit your specific business needs.

## Custom Templates and Objects {#subsect_158093024246}

Customization lets you adapt NetSuite to meet your company's business process using a point-and-click interface. For information about Customization, see [Customization Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N2824008.html).

You can create the following to meet the needs of your business:

-   Custom fields and forms to enter information in NetSuite. See [Custom Fields](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N2826978.html) and [Custom Forms](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N2852749.html).
    
-   Custom record types. See [Custom Records Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N2875173.html).
    
-   Custom transaction types. See [Custom Transactions Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4172599049.html).
    
-   Custom segments, which are custom classification fields similar to class and department. See [Custom Segments](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4313464438.html).
    
-   Advanced PDF/HTML templates to customize printed and emailed transactions. See [Advanced PDF/HTML Templates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4453550706.html).
    
-   Scriptable templates to create personalized email marketing campaigns and system email. See [Scriptable Templates](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_3775087812.html).
    
-   Dashboards and custom centers to provide each user with the pages and links they need to do their jobs. See [Dashboards Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N576403.html) and [Custom Centers](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N2890160.html).
    

## SuiteFlow {#section_1529089933}

Workflows automate custom business processes for NetSuite records, such as transaction approval, lead nurturing, and record management.

You define workflows for a record type and its stages, or states, as it moves through a business process. You also specify when a workflow should start, when actions should run, and when a record should move to another state. You can also schedule workflows to run automatically.

For more information, see the following topics:

-   [SuiteFlow Overview](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_4068260113.html)
    
-   [Workflow Elements](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4071953058.html)
    
-   [Workflow Samples](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N2796642.html)
    

## Copy to Account {#section_1549562348}

Copy to Account is an administrator tool that enables you to copy one custom object (for example, a custom record) from one account to another. You can select a target account, choose dependencies, select record instances, and then preview and deploy the custom object. The tool copies one custom object (including its dependencies and instances) at a time to any account where you have administrator access. For more information, see [Copy to Account](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1544019532.html).

Copy to Account runs on the SuiteCloud Development Framework (SDF) and is available for production, development, and sandbox account types. You can use Copy to Account if the object is supported by SDF and isn't locked, hidden, or part of another SuiteApp. For a list of supported object types, see [Customizations Supported by SuiteCloud Development Framework](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_4706653920.html).

If you want to use code to customize objects and deploy them to an account, or bundle and distribute custom objects to multiple accounts, use the following tools:

-   [SuiteCloud Development Framework](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1556765316.html#section_1529089821)
    
-   [Distribution](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1529089772.html)
