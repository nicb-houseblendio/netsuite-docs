The workbook uses the Expense Transaction Detail dataset and shows your cost allocation data.

#### To access the Indirect Cost Allocations Workbook: {#procedure_0307052400}

1.  Go to Analytics > Workbooks subtab.
    
2.  In the **Search** field, enter **Indirect Cost Allocations Workbook**.
    
3.  Click the Indirect Cost Allocations Workbook tile. The workbook opens.
    

To get accurate data groupings in the dataset and the workbook, you must select Grant as your allocation segment in Indirect Cost Allocation for Grants Preferences page. For more information, see [Setting Up the Indirect Cost Allocation for Grants Preferences](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0106052333.html#subsect_35172910150).

## Adding Grant Field to Dataset and Workbook {#subsect_27172613751}

After selecting Grant as allocation segment in the preferences, you must add and apply the Grant field to the dataset and workbook.

#### To add the Grant field to the dataset and workbook: {#procedure_0307052700}

1.  Go to Analytics > Workbooks subtab.
    
2.  In the **Search** field, enter **Indirect Cost Allocations Workbook**.
    
3.  Click the Indirect Cost Allocations Workbook tile.
    
    The workbook opens.
    
4.  Next to Expense Transaction Detail dataset name, click the menu icon, and then select **Open Dataset**.
    
    ![A portion of the dataset that shows the menu icon and the Open Dataset option outlined in red.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SocialImpact/ICA_Workbook_OpenDataset.png)
5.  In the **Search** field, enter Grant.
    
6.  From the **Fields** list, drag the **Grant** field next to Transaction Line and move it to the data grid.
    
    ![A portion of the Field list showing the Grant field next to Transaction line outlined in red.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SocialImpact/ICA_TransactionLineGrant.png)
    
    A new column for **Transaction Line: Grant** should appear in the data grid.
    
    ![A portion of the data grid with the Transaction Line: Grant column outlined in red.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SocialImpact/ICA_Screenshot_DataGrid.png)
7.  Click **Apply to Workbook**. The dataset builder closes.
    
    The **Grant** field lists under the **Dataset** column.
    
    ![A portion of the dataset column with Grant field outlined in red.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SocialImpact/ICA_WorkbookGrant.png)
8.  Drag the **Grant** field to the **Rows** section of the **Layout** column.
    
    ![A portion of the dataset with the Grant fields in the Dataset and Layout column outlined in red.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SocialImpact/ICA_GrantDrag.png)
9.  Next to the timestamp, click the menu icon, and then click **Clear Cache**.
    
    ![A popup message from the menu icon with the Clear Cache button outlined in red.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SocialImpact/ICA_Workbook_ClearCache.png)
10.  Click the **Refresh** icon. The preview now shows grouped indirect cost allocation transactions according to grant, posting period, and subsidiary. Here is an example.
     
     ![A preview of the Workbook showing ICA transactions grouped according to grant, posting period and subsidiary](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SocialImpact/ICA_FInalPreviewWorkbook.png)
     
     Note:
     
     When multiple currencies are involved, the workbook automatically converts the amounts to a root subsidiary currency using a consolidated exchange rate.
     
     This conversion may result in slight rounding-off differences in the amounts.
     
11.  To save the dataset, click the menu icon next to **Expense Transaction Detail** dataset and select **Save Changes**.
     
     ![A portion of the menu icon showing the Save Changes option outlined in red.](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/img/SocialImpact/ICA_Dataset_SaveChanges.png)
12.  To save the workbook, click **Save**.
     

For more information about navigating workbooks and editing datasets, see [Workbooks and Datasets](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0801122037.html).
