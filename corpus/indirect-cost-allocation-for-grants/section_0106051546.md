The following permissions are required to use the Indirect Cost Allocations for Grants SuiteApp:

| Subtab | Permission | Minimum Access Level |
| --- | --- | --- |
| Transaction | Indirect Cost Allocation | Full |
| Setup | Custom Segment | Full |
| Custom Record | Full |
| SuiteApp Deployment | Full |
| SuiteScript | Full |
| SuiteScript Scheduling | Full |
| Suite Sign-on | Full |
| Custom Record | ICA Method and Rates | Full |
| ICA Allocation Preferences | Full |
| Allowable Costs | Full |
| Cost Categories | Full |

For more information, see [Assigning Roles to an Employee](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N897798.html) and [Customizing or Creating NetSuite Roles](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N285937.html).
