This section includes the prerequisites and instructions for installing the Indirect Cost Allocation for Grants SuiteApp.

## Prerequisites {#subsect_9170509266}

The Indirect Cost Allocation for Grants SuiteApp is developed and tested for use primarily with NetSuite OneWorld. For more information about NetSuite OneWorld, see [Introduction to NetSuite OneWorld](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_N266468.html).

## Installation {#subsect_64171012450}

Any role with access to the SuiteApp Marketplace in NetSuite can install the Indirect Cost Allocations for Grants SuiteApp. For more information about the SuiteApp Marketplace, see [SuiteApp Marketplace in NetSuite](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1539797981.html).

To install the Indirect Cost Allocations for Grant SuiteApp, see [Installing from the SuiteApp Marketplace](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1539799323.html).

The Indirect Cost Allocation for Grants SuiteApp is a managed SuiteApp and is automatically updated whenever there are enhancements or new features added.

For more information about the SuiteApp Marketplace, see [SuiteApp Marketplace in NetSuite](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1539797981.html).
