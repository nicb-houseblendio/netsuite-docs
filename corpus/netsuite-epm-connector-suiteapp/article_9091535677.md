NetSuite EPM Connector lets you use NetSuite to view the history of successfully executed searches called from Data Exchange. You can also roll back to any of the previous data loads, for example, if a search execution fails in Data Exchange.

Note:

You can't roll back to the most recent data load.

#### To roll back to a search request: {#procedure_0213050617}

1.  In NetSuite, go to NetSuite EPM > EPM Connector > Reset Search Request Load.
    
2.  Select the date range using the **From** and **To** fields.
    
    NetSuite displays saved searches for which you've enabled incremental data load. For information, see [Customizing the Executed Account Reconciliation Sync Saved Searches](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_44130817717.html).
    
3.  If NetSuite displays a large number of logs, you can narrow the list by selecting one or more of the following:
    
    -   The source Oracle Cloud Enterprise Performance Management (EPM) product, which currently is Account Reconciliation
        
    -   The source instance
        
    -   The title of the search
        
    -   The page index to determine which pages to display in the list
        
4.  Check the **Select** box next to the search request you want to reload.
    
5.  Click **Reset Load Date**. This rolls the selected search request back to the previous data load date.
    
6.  (Optional) Click **Reset to Starting Point**. This resets the search request date and time in NetSuite to the first data load date.
    

In the **Load History** section, you can view the following information about the search request loads:

| Column | Description |
| --- | --- |
| Data From | The start date and time of each search execution in the selected date range. |
| Data To | The end date and time of each search execution in the selected date range. |
| Source App | The source Oracle Cloud Enterprise Performance Management (EPM) product. Note: Acronyms ARCS and NSAR both represent Account Reconciliation. |
| Source Instance | The source instance in the target Oracle Cloud Enterprise Performance Management (EPM) product. |
| Source ID | The source ID in the target Oracle Cloud Enterprise Performance Management (EPM) product. |
| Search Request ID | The search request ID in Data Exchange. |
| Criteria | Criteria selected when loading data incrementally is enabled. See [Customizing the Executed Account Reconciliation Sync Saved Searches](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_44130817717.html). |
