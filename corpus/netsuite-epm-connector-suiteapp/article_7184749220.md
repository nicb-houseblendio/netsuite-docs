Temporary search and data files are stored in NetSuite at Documents > Files > File Cabinet. To ensure that NetSuite EPM Connector deletes these files from your File Cabinet, you should schedule deployment of the following script properly in NetSuite:

| Script Deployment Name | Script Deployment ID | Script File Name |
| --- | --- | --- |
| NSEPM | SS Cleanup | customscript\_nsepm\_ss\_cleanup | ss\_cleanup.js |

#### To schedule the script deployment: {#procedure_1216064943}

1.  In NetSuite, go to Customization > Scripting > Script Deployments.
    
2.  Expand the Filters area if the filters aren't displayed.
    
3.  From the **Script** filter, select NSEPM | SS Cleanup.
    
4.  Click **Edit** next to the script deployment.
    
5.  On the **Schedule** subtab, do the following:
    
    1.  Set the **Start Time** field to **12:00 am**.
        
    2.  Set the **Repeat** field to **every 2 hours**.
        
6.  Click **Save**.
