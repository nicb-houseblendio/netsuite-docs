You can import NetSuite EPM Connector configuration into your NetSuite account from a previously exported file.

#### To import NetSuite EPM Connector configuration:

1.  In NetSuite, go to NetSuite EPM > EPM Connector > Import/Export Configuration.
    
2.  Choose the **Import** radio button.
    
3.  Under **File to Import**, select a JSON file you exported as described in [Exporting NetSuite EPM Connector Configuration](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1106030015.html).
    
4.  If you want to overwrite your existing configuration with the content of the import file, check the **Overwrite Existing Values** box.
    
5.  Click **Submit**.
    
    This imports the configuration into your NetSuite account. Details and the import history appear on the **Logs** subtab.
    
    When importing, you can expect the following behavior:
    
    -   If an error occurs with any configuration during the import, it doesn't affect the import of the rest of the configurations in the file. You can view the related error logs on the **Logs** subtab.
        
    -   If you check the **Overwrite Existing Values** box and the import file contains no configuration, you receive an error message indicating that the import file is empty.
