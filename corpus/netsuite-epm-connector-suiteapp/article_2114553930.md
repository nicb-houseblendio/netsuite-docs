If you have the Administrator role, you can assign the **NSEPM Implementer** role to a new or existing user in NetSuite. This role allows the user to perform the following tasks on a NetSuite account:

-   Set or change the file encryption password. See [Setting Up a File Encryption Password for NetSuite EPM Connector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_3115159270.html).
    
-   Schedule the required script deployments. See [Scheduling the Script Deployment for NetSuite EPM Connector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_7184749220.html).
    
-   View and download log details of searches called from Data Exchange. See [Search Activity Logs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_5115536052.html).
    
-   Place prefixes of search IDs on an allowlist. See [Data Source Allowlist](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_9115749534.html).
    
-   View the history of successfully executed searches called from Data Exchange, and roll back to a previously executed search. See [Resetting the Search Request Load](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_9091535677.html).
    
-   Configure a connection to an external SFTP server, and then upload data from the SFTP server to your Cloud EPM application. See [Configuring External Connections](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_2143945831.html).
    
-   Compare a custom role to an existing role and add missing permissions. See [Managing User Role Permissions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1023031026.html).
    

#### To assign the NSEPM Implementer role to a user:

1.  Go to _Lists > Employees > Employees_.
    
2.  Click **Edit** next to the employee to whom you want to assign the **NSEPM Implementer** role.
    
3.  Click the **Access** subtab.
    
4.  In the **Roles** column, select **NSEPM Implementer**, and then click **Add**.
    
5.  Click **Save**.
    

You can customize the NSEPM Implementer role to better suit your needs. For more information, see [Customizing the NSEPM Implementer Role](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1025104830.html).

The NetSuite EPM Connector features available to you depend on your assigned roles and permissions. The navigation paths to the available features in NetSuite vary depending on the NetSuite center associated with the role you use to log in to NetSuite:

-   If you log in to NetSuite using a role with the Classic Center, for example the Administrator role, go to NetSuite EPM > EPM Connector. You have full permissions to use all the available NetSuite EPM Connector features.
    
-   If you log in to NetSuite using a role other than the Classic Center, for example the Accountant role, you can only perform the following tasks on a NetSuite account:
    
    -   View log details of searches called from Data Exchange. See [Search Activity Logs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_5115536052.html).
        
        Important:
        
        If you log in using your role and cannot access this NetSuite EPM Connector feature, ask your Administrator to assign your role to the **NSEPM | Data Source Allow List** custom record.
        
    -   View the history of successfully executed searches called from Data Exchange. See [Resetting the Search Request Load](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_9091535677.html).
        
        Important:
        
        If you log in using your role and cannot access this NetSuite EPM Connector feature, ask your Administrator to assign your role to the **NSEPM | Search Request** custom record.
