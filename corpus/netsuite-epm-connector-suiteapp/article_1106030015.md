You can export all available NetSuite EPM Connector configurations, or select specific configurations you want to export. The following configurations are available for export:

| Configuration Label | Description |
| --- | --- |
| Data Source Allowlist | The prefixes of search IDs you placed on EPM products' allowlists. See [Data Source Allowlist](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_9115749534.html). |
| Server Connection List | The connections to external SFTP servers you configured in NetSuite. See [Configuring External Connections](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_2143945831.html). |

#### To export NetSuite EPM Connector configuration:

1.  In NetSuite, go to NetSuite EPM > EPM Connector > Import/Export Configuration.
    
2.  Choose the **Export** radio button.
    
3.  On the **Configurations to Export** subtab, do any of the following:
    
    1.  In the **Select** column, check the box next to each configuration you want to export.
        
        Tip:
        
        To select all configurations, click the **Mark All** button. To clear all selections, click the **Unmark All** button.
        
    2.  To review configuration details, click the **View** link to access the specific configuration page.
        
4.  Click **Submit**.
    
    This exports the configuration to a JSON file and saves it to your local disk.
    
    Note:
    
    If the export contains no configuration, you receive an error message indicating that at least one configuration is required for the export.
    
5.  Click the **Logs** subtab to view details and the history of your exported configurations.
