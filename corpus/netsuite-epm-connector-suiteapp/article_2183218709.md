This help topic describes the recent changes to the NetSuite EPM Connector SuiteApp.

## Version 26.1.1 {#subsect_0123093103}

### February 3, 2026 {#subsect_0123093155}

This release fixes an issue where manual search requests, after clicking Download on the Manage Saved Searches or Manage Datasets page, could fail. This error occurred when inbound connection URL verification was enabled.

## Version 26.1 {#subsect_1107030221}

### January 13, 2026 {#subsect_1218081707}

This version of the NetSuite EPM Connector SuiteApp includes the following:

-   Updates required for the 26.1 releases of the following NetSuite Enterprise Performance Management (EPM) SuiteApps:
    
    -   **Close Management and Consolidation Sync**
        
    -   **Planning and Budgeting Sync**
        
    -   **Account Reconciliation Sync**
        
-   Possibility to export your NetSuite EPM Connector configuration to a single file. You can use the file as a configuration backup or import it into another NetSuite account. See [Import/Export Configuration in NetSuite EPM Connector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_7145643730.html).
    

## Version 25.1.4 {#subsect_1104061205}

## November 4, 2025 {#bridgehead_1104061228}

This release fixes a connectivity issue that caused an error when only NetSuite EPM Connector was installed.

## Version 25.1.3 {#subsect_1013082826}

## October 14, 2025 {#bridgehead_1013082841}

This release resolves a connection issue between Data Exchange and NetSuite accounts with a large number of saved searches.

## Version 25.1.2 {#subsect_59092633619}

## September 23, 2025 {#bridgehead_1092641456}

This release fixes an issue with the Fetch File via SFTP job functionality.

## Version 25.1.1 {#subsect_0704040549}

## August 5, 2025 {#bridgehead_0704040622}

This version of the NetSuite EPM Connector SuiteApp includes the following:

-   Updates required for the 25.1 releases of the Account Reconciliation Sync and Planning and Budgeting Sync SuiteApps.
    
-   Additional authentication methods provided for connecting to external SFTP servers from NetSuite:
    
    -   **SSH Private Key and Password**
        
    -   **SSH Private Key and API Secret**
        
    
    See [Configuring External Connections](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_2143945831.html).
    
-   Possibility to place the `custsql_` prefix for SuiteQL queries on the Planning and Budgeting allowlist. See [Data Source Allowlist](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_9115749534.html).
    

## Version 25.1 {#subsect_0228080851}

## March 18, 2025 {#bridgehead_0228080926}

This version of the NetSuite EPM Connector SuiteApp brings the following changes:

-   The NetSuite EPM Connector SuiteApp now supports installation of the Close Management and Consolidation Sync SuiteApp. For information about the new SuiteApp, see [Close Management and Consolidation Sync SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_33112718443.html).
    
-   You can access your Financial Consolidation and Close environment from the NetSuite EPM Access portlet. For information, see [NetSuite EPM Access Portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_2112635593.html).
    
-   The NSEPM Implementer role can no longer be used to set up token-based authentication (TBA) for connecting your Enterprise Performance Management application to NetSuite. To set up TBA, use the integration role of the installed NetSuite Enterprise Performance Management integration SuiteApp, or its customized version.
    
    The available integration roles include:
    
    -   **NSPB Integration** for Planning and Budgeting Sync
        
    -   **NSAR Integration** for Account Reconciliation Sync
        
    -   **FCCS Integration** for Close Management and Consolidation Sync
