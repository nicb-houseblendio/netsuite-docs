The NetSuite EPM Connector SuiteApp facilitates connection between NetSuite and applications in Oracle Cloud Enterprise Performance Management (Cloud EPM, hereafter). The SuiteApp enables Data Exchange to load data from NetSuite to your applications in Cloud EPM.

For information about Cloud EPM, and about using Data Exchange for applications in Cloud EPM, see the following Oracle Help Center topics:

-   [Oracle Enterprise Performance Management (EPM)](https://docs.oracle.com/en/cloud/saas/epm-cloud/index.html)
    
-   [Administering Data Integration](https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/diepm/index.html#Oracle%C2%AE-Fusion-Cloud-EPM)
    

For information about installing, configuring, and using NetSuite EPM Connector, see [NetSuite EPM Connector Installation and Setup](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0095112426.html).

For information about the changes in each release, see [NetSuite EPM Connector Release Notes](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_2183218709.html).
