To install and set up NetSuite EPM Connector, you must use the Administrator role and complete the following consecutive steps:

1.  Enable the required features in your NetSuite account. See [Required Features for Installing NetSuite EPM Connector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1163231276.html).
    
2.  Install the NetSuite EPM Connector SuiteApp. See [Installing the NetSuite EPM Connector SuiteApp](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_4120644213.html).
    
3.  Assign roles to NetSuite EPM Connector users. See [Role Permissions for NetSuite EPM Connector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_2114553930.html).
    
4.  Set the file encryption password. See [Setting Up a File Encryption Password for NetSuite EPM Connector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_3115159270.html).
    
5.  Schedule the required script deployment properly. See [Scheduling the Script Deployment for NetSuite EPM Connector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_7184749220.html).
    

After installing and setting up NetSuite EPM Connector, use your role to access the NetSuite EPM Connector functionality. For details about what tasks your role can perform on your NetSuite account, see [Role Permissions for NetSuite EPM Connector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_2114553930.html).

-   View log details of searches called from Data Exchange, and download log files. See [Search Activity Logs](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_5115536052.html).
    
-   View the history of successfully executed searches called from Data Exchange, and roll back to a previously executed search. See [Resetting the Search Request Load](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_9091535677.html).
    
-   Create allowlists for searches that your applications in Cloud EPM should acknowledge. See [Data Source Allowlist](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_9115749534.html).
    
-   Configure a connection to an external SFTP server, and upload data from the SFTP server to your Cloud EPM application. See [Configuring External Connections](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_2143945831.html).
    
-   Export and import your NetSuite EPM Connector configuration. See [Import/Export Configuration in NetSuite EPM Connector](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_7145643730.html).
    
-   Use the NetSuite EPM Access portlet to go to your NetSuite Enterprise Performance Management environments directly from NetSuite. See [NetSuite EPM Access Portlet](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_2112635593.html).
