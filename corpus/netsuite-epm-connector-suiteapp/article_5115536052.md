NetSuite EPM Connector lets you use NetSuite to view log details of searches called from Data Exchange.

To view the log details, go to NetSuite EPM > EPM Connector > Search Activity Logs. If NetSuite displays a large number of logs, you can narrow the list by selecting one or more of the following:

-   The target Oracle Cloud Enterprise Performance Management (EPM) product
    
-   The title of the search
    
-   The page index to determine which pages to display in the list
    

The default option **All** lists all data.

To find specific data in the list, you can sort each column in the displayed list of searches by the following characteristics:

-   The internal ID of the search in NetSuite.
    
-   The search request ID in Data Exchange.
    
-   The target Cloud EPM product.
    
    Note:
    
    Acronyms ARCS and NSAR represent Account Reconciliation. Acronyms PBCS, NSPB, and EPBCS represent Planning and Budgeting. Acronym FCCS represents Financial Consolidation and Close.
    
-   The title of the search.
    
-   The search type for saved searches and record type for datasets, for example, Transaction.
    
-   The total number of records each search contains. The count of records includes the header row.
    
-   The execution parameters, as defined for each search in Data Exchange.
    
-   The start date and time of each search execution.
    
-   The end date and time of each search execution.
    
-   The status of each search execution, which is either Success or Failure.
    
-   The user who last ran each search, as configured in Data Exchange.
    

The **Download** link is displayed in the **Output File** column for successfully executed searches. Clicking the link downloads the CSV file that was sent to Data Exchange when the specific search was executed from NetSuite or from Data Exchange. You can open the file and view the data that was sent in this file to Data Exchange.

Tip:

If the downloaded CSV file doesn't contain the expected data, read the following troubleshooting tips before contacting support:

-   Review information available in the **Execution Parameters** column at NetSuite EPM > EPM Connector > Search Activity Logs.
    
-   Check for any missing permissions for the role that was used to set up the integration with NetSuite. See [Managing User Role Permissions](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1023031026.html).
    

Important:

The generated CSV file doesn't contain records created less than five minutes before search execution. Make sure your data load job is run at least five minutes after you created new records in NetSuite.
