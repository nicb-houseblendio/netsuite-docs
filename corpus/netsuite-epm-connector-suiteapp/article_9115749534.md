To use NetSuite searches in Oracle Cloud Enterprise Performance Management (EPM) products, you can place prefixes of the search IDs on an allowlist.

#### To place a search on an allowlist:

1.  In NetSuite, go to NetSuite EPM > EPM Connector > Data Source Allowlist.
    
2.  From the **EPM Product** list, select the Cloud EPM product for which you want to create the allowlist. The available options include the following:
    
    -   **Account Reconciliation** for searches you want to use in NetSuite Account Reconciliation
        
    -   **Close Management and Consolidation** for searches you want to use in Financial Consolidation and Close
        
    -   **Planning and Budgeting** for searches you want to use in NetSuite Planning and Budgeting
        
    -   **Profitability and Cost Management** for searches you want to use in Enterprise Profitability and Cost Management
        
    -   **Tax Reporting** for searches you want to use in Tax Reporting
        
    -   **All EPM Products** for searches you want to use in any Cloud EPM product
        
3.  In the **List of ID Prefixes** field, enter the prefixes of search IDs that your Cloud EPM product should acknowledge, separated by commas:
    
    -   To use the predefined saved searches for NetSuite Account Reconciliation, the prefixes should begin with **customsearch\_nsar\_**.
        
    -   To use the predefined searches for Financial Consolidation and Close, the prefixes should begin with:
        
        -   **customsearch\_nsfc\_** for saved searches
            
        -   **custdataset\_nsfc\_** for datasets
            
    -   To use the predefined searches for NetSuite Planning and Budgeting, the prefixes should begin with:
        
        -   **customsearch\_nspb\_** for saved searches
            
        -   **custdataset\_nspb\_** for datasets
            
        -   **custsql\_nspb\_** for SuiteQL queries
            
    -   To use searches other than the predefined ones, add your custom prefixes that the Cloud EPM product should acknowledge.
        
4.  When you finish, click **Submit**.
    

All searches the IDs of which begin with these prefixes will be available in Data Exchange. If you change these prefixes in NetSuite after running the searches from Data Exchange, your changes might stop data load jobs from running successfully. To reflect the changes in Data Exchange, you have to make corresponding updates in Data Exchange.
